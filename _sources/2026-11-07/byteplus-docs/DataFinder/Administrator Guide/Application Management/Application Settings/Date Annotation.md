# 1. Introduction to the concept

Date annotations refer to important/major changes that users can make at certain time points (such as version releases, operational activities, online incidents, etc.).

<span id="_2-使用说明"></span>
# 2. Instructions for use

<span id="_2-1-管理页面"></span>
## 2.1 Administration page


* Click "Management \- Date Annotation" to enter the management page;

* You can use the annotation name to search, add annotations, delete annotations in batches, and edit and delete individual annotations again;

* Without permission restrictions, members of the project can add or delete comments on important dates and dates.
