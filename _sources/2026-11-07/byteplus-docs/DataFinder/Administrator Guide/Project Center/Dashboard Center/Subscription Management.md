DataFinder provides you with a project\-granular subscription management page, where you can view a list of currently subscribed Dashboard boards and the status of subscription pushes, making it easy to efficiently view and handle subscriptions in abnormal states. This article introduces you to the page features of subscription management.

<span id="ce447a0e"></span>
# Function Description


1. After logging into the DataFinder console, click the top navigation "Project Center \> Dashboard Center \> Subscription Management" to enter the subscription management page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d627beb860cc468c8d94d6323ffda408~tplv-goo7wpa0wc-image.image) </span>

2. Review the subscription list and push status.

   * You can quickly search to find the corresponding subscription task by subscription task name in the top search box.

   * On the subscription management page, you can view basic information such as the creator of the subscription task, the push frequency, and the current push status. If the push status is "push failed", you can check whether there is any abnormality in the subscription configuration, Dashboard data, etc. in time, and check and deal with it in time.

3. You can click the "Pause", "Edit", and "Delete" buttons after subscribing to the task to pause, edit, and delete the subscription task. The configuration instructions for editing Yes can be found in the operation instructions of Dashboard Subscription: [Dashboard Subscription](https://docs.byteplus.com/docs/DataFinder/Dashboard_Subscription).
