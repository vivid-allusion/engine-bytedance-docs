<span id="_1-概述"></span>
# 1. Overview

Dashboard Center contains three modules: Dashboard, Charts, Folder Management. Each module supports batch or single\-content operations to help manage Dashboard content within an application efficiently.

<span id="_2-看板功能说明"></span>
# 2. Dashboard function description

<span id="_2-1-入口"></span>
## 2.1 Entrance

You can enter the module by clicking [Dashboard Catalog \- Dashboard Center] or [Application Management \- Dashboard Center].

<span id="_2-2-看板管理"></span>
## **2.2 Dashboard management**

Here you can filter the Dashboard content you need through search or option filtering, and support [Authorize, Transfer, Delete] operations for a single Dashboard or multiple Dashboard.

**Quick operation demonstration:** 

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8ceb5d55a66f40e4bf0c20597ad5fea1~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/02a2dc215cf44200bd497b0aed3da632~tplv-goo7wpa0wc-image.image) </span>


* **Common filter paths**

   * Through the number of visits/people in the past 30 days of Dashboard (all T + 1 day data), locate the Dashboard without traffic access, and delete it in batches to keep the Dashboard directory clean

   * Authorization or transfer through Dashboard directory, creator location Dashboard

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b058e4a01624424a4e4be2acbed433b~tplv-goo7wpa0wc-image.image) </span>

* **Delete operation**


You can locate Dashboard by filtering or searching, and support the removal of a single or multiple Dashboard boards.

Note: The administrator has the operation rights of all Dashboard boards, and members only support the operation of Dashboard boards created by themselves or with editing rights.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9b56dd574a914dcb83c91d82df289f90~tplv-goo7wpa0wc-image.image) </span>


* **Authorization operation**


You can edit & view permissions for single or multiple Dashboard boards, and authorize objects to support individuals or roles (roles created within the app, such as the marketing department).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8d7fbd2a819040babf0b03ce122a48aa~tplv-goo7wpa0wc-image.image) </span>


* **Transfer operation**


Allows you to perform creator transfers for single or multiple Dashboard boards, with only one user being handed over. If you need to hand over multiple Dashboard boards to different users, proceed in batches.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1f551fd815ab4b8ca54b49af9dc39d66~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-3-图表管理"></span>
## **2.3 Chart management**

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3963309c224048e4a80533a34e6126f9~tplv-goo7wpa0wc-image.image) </span>


* Here you can filter the chart by searching, filtering the source of the chart (Advanced Analysis Module), and the chart I created.

* Support you to delete and authorize single or multiple charts; support setting Chinese and English display names for single or multiple charts.

* You can click on the chart to enter the advanced analysis module to view the details, or click on the name of the board to enter the board where the chart is located to view.


<span id="_2-4-文件夹管理"></span>
## 2.4 Folder management

Here you can filter the folder contents you need by searching or option filtering, and support [Authorize, Transfer, Delete] operations for a single folder or multiple folders.

Note: Deleting a folder does not delete the dashboard under the folder simultaneously.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0be81c05f62440adb83895d490790aa0~tplv-goo7wpa0wc-image.image) </span>
