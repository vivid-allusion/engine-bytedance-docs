# 1. Overview

The application list is a display of all applications currently under the group, and all applications of all products under the group can be entered through the application list. For example, if you purchased BytePlus' "Growth Analysis" and "AB Test" products, you can quickly enter these two products through the application list.

<span id="_2-如何找到应用列表？"></span>

* The page in the application list will show you the application information of the permissions you have under the group, as shown below:

<span id="_3-首次进入产品如何创建应用？-如何创建新应用？"></span>
# 3. How to create an application when entering the product for the first time? How to create a new application?


* **Enter the application list and click Add Access.** 

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/335b301bcd0b4f959de34c8bfab825b2~tplv-goo7wpa0wc-image.image) </span>

* **Select the product you need to access**

   * Select according to the product you purchased. If you purchased a growth analysis product, click "Integrate" below the growth analysis, as shown below:

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d445381e3cfb4cfea7eddea2e756e497~tplv-goo7wpa0wc-image.image) </span>

* **Create an app**

   * Fill in the application name: The application name is the name of the application you need to access (the application name of your own product), such as "Jinri Toutiao" and "Douyin", required;

   * Fill in the English name of the App, required;

   * You can click the advanced option to select "User Size" and "App Package Name";

   * After completing the information, click "Create App";

* **Created successfully**


After clicking "Create App", it will prompt that the app has been successfully created, and you can select "Enter App".
