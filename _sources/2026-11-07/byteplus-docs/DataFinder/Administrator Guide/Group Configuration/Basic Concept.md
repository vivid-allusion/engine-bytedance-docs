# Group

**Group refers to a company**, such as Beijing ByteDance Network Technology Co., Ltd. is a group.

When registering:


* If the company name is filled in, the company name is the group name.

* If the company name is not filled in, the group name will be "Your Name Group".


**Group founder:** 


* By default, it has group administrator privileges, and the permissions can be modified later;

* Group administrators can view group information on the group information page, including: group ID, group name, group members, and other group information.


A group can have multiple group users, and if a company has multiple applications, it can also integrate multiple applications into the same group for unified management.

# Application

<span id="什么是应用？"></span>
## What is an app?

**Application** refers to a product that belongs to the user (or the user's team) and needs to be monitored for changes and fluctuations in data.

Each app you create can be found in the app list, as follows:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c07e71eb3a8745708d0159cf2717b7db~tplv-goo7wpa0wc-image.image) </span>

Each application has a unique ID on BytePlus Growth Analysis: appid.


* If an app is accessing BytePlus Growth Analysis for the first time, we will ask you to apply for an appid for that app.

* Click "Add Project" in the app list to apply for an appid for the new app.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0d9786c8579249e69019cd5916c7019e~tplv-goo7wpa0wc-image.image) </span>


<span id="申请-appid-时，需要填写什么信息？"></span>
## What information do I need to fill in when applying for appid?

When applying for appid, you need to fill in detailed information.

<span id="_1-填写您应用的中文名称以及app-name。"></span>
### **1. Fill in the Chinese name and App Name of your app.** 

The Chinese name and App Name are also unique in the BytePlus Growth Analysis (and related data products such as game growth analysis, A/B testing, and application performance analysis) platform. If your app has the same name as another company's app, you can distinguish it by adding a suffix.

Please note that the Chinese and English names here are only the names used in the BytePlus Growth Analysis (and related data products game growth analysis, A/B testing and application performance analysis) platform, and do not represent the name of your application in major app stores or distribution channels.

<span id="_2-对应填写您应用的包名。"></span>
### **2. Fill in the package name of your application accordingly.** 


* If your app is a mobile end app, we strongly recommend that you fill in the package name of your app.
