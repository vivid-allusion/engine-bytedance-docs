DataFinder provides you with event classification capabilities, allowing you to categorize and display events with the same characteristics, allowing you to quickly find and use corresponding events. This article shows you how to classify events.

<span id="_1-概述"></span>
# Operation entrance


* You can enter the indicator configuration area of each function in **Analysis Tools \> Advanced Analysis** , and enter the event classification management page through the event drop\-down box (the figure below shows the event analysis indicator configuration area).

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6736965157df4388b778a14ecdc079cf~tplv-goo7wpa0wc-image.image) </span>

* You can select a category for an event by clicking the Edit or Add button under the Event Classification Actions column on the **metadata management** \> **General Event** List page, or by clicking **Manage Event Classification** at the bottom of the drop\-down list.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e947c5783ab244bca3f94a37bc291747~tplv-goo7wpa0wc-image.image) </span>


In the event classification module, you can create, edit, and delete categories, adjust the display order of categories, and modify the categories to which events belong.

<span id="_2-功能介绍"></span>
# Event classification type: public classification, private classification

DataFinder provides two categories of pages:


* Public category pages: visible to all, editable and maintained by only group administrators/administrators.

* Private category pages: visible only to yourself, and editable and usable only by yourself...


You can freely switch between two category pages, or you can choose which category page to use as the default page. After setting the default page, every time you enter the analysis page and the event category page, the categories under this category page will be displayed by default.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e10fdd2ce0854ca691a1e2f9da1b5a59~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-2-分类创建-编辑-删除-排序"></span>
# Create/edit/delete/sort event categories

DataFinder provides you with a default **Uncategorized** event classification, by default, all events will be under " **Uncategorized** ", you can create a new event classification according to the actual classification needs, and modify the event attribution to the new classification; when the event is classified, the event will be automatically removed from the **Uncategorized**.


* Regardless of "Uncategorized", up to 20 categorization labels can be set under each category page.

* Each event can belong to only one category in a category page.


<span id="26b76eac"></span>
## Create event categories and sort them


* Click **Add Category** in the top right corner of the page, you can configure the event classification parameters in the pop\-up page to create a new category.

* Click on the **category sorting** in the upper right corner of the page to sort the event categories you have created to suit your usage habits.


The specific operation is as follows:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6efe29f902524334a36d62d9dafa9202~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-3-修改事件所属分类"></span>
## Modify the category to which the event belongs

If you need to change the category to which an event or events belong, just find the target category that has been adjusted, click Edit, and add the event that needs to be adjusted to that category.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0f6044caa30a4b96ac1ce9f459da6541~tplv-goo7wpa0wc-image.image) </span>
