# Why real\-time event tracking and circling cannot be entered

When the real\-time event tracking detection, App circle selection and App heat map functions cannot be entered, you can ask the R & D students to check whether the SDK access is correct.

<span id="_1-android"></span>
## 1. Android

The dependent SDK packages are as follows:


* Event tracking verification: lite + scheme, all + scheme

* Circle event: all + scheme


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Before starting, please check whether the initialized channel is empty. This field is required.</div>


The inspection steps are as follows:


1. Check whether there is scheme module code in the integration code; check whether the appid and url scheme are correct.

   For specific instructions see: [Configuration Scheme (optional)](https://docs.byteplus.com/docs/DataFinder/Android_SDK_Integration_Scenario_Practice#ed6151e2).

2. If all the above are consistent, you can try the following: Open the app on your phone first, and then scan the code to test whether it is successful.


<span id="_2-ios"></span>
## 2. iOS

The inspection steps are as follows:


1. Check that the appid (including the appid in the handleurl and the initialized appid), url_scheme, and appname are configured correctly, please refer to the specific instructions [Configuration Scheme](https://docs.byteplus.com/docs/DataFinder/iOS_SDK_Integration_Scenario_Practice#e1985aa2).

2. Check that the pod settings are consistent with the help documentation.

   `pod 'RangersAppLog','6.17.x',:subspecs => ['Host/CN','Core','UITracker','Log','Picker']`

3. The method of handleurl must be written, please refer to the relevant instructions [Override callback method](https://docs.byteplus.com/docs/DataFinder/iOS_SDK_Integration_Scenario_Practice#c61195a3).


<span id="_3-小程序"></span>
## 3. Mini Program

The inspection steps are as follows:


1. Whether to add the secure domain name (you can check whether there is an error in consolve).

2. Determine if the generated QR code is correct.

   Make sure that the generated QR code is generated by the Mini Program entrance page plus the parameters of the corresponding page.

3. Whether the Mini Program integrates the SDK, whether the appID is correct, and whether the SDK is successful.

4. Has the ws of the network requested to issue it?
