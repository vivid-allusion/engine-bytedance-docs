DataFinder provides you with event tracking real\-time verification function. When using this function to successfully establish an event tracking detection connection, each subsequent event trigger will be displayed in real time on the event tracking real\-time verification page. It realizes real\-time detection and quick verification of whether the event tracking is correct and the data upload situation. It is often used for research and development or tester debugging verification. This article shows you how to use the event tracking real\-time verification feature.

<span id="f868ed38"></span>
# Attention and limitations


* Current end types supported by the real\-time event tracking validation feature include:

   * Mobile end App: Support Android, iOS.

   * WeChat Mini Program: Only supported by SaaS\-non\-cloud native environments, not supported by SaaS\-cloud native environments.

   * Web Side: Web/JS SDK version of web integration is 5.1.2 and above.

   * Server level: Currently only supports Java; Golang and PHP currently do not support real\-time verification using event tracking.

* Events generated by real\-time verification through event tracking are not built into the project database and do not consume event usage.

* The event tracking real\-time verification function does not currently support verifying app_launch, app_terminate events.

* Event tracking real\-time verification function supports collecting event tracking screenshots.

   * At present, this function is turned off by default. If you want to use this function, you need to contact the technical support staff to turn on the function switch first.

   * At present, this function only supports the North China 2\-Beijing region of the SaaS\-cloud native environment, and other regions and environments are not supported for the time being.

   * At present, this function is only supported by the mobile end App\-Android end, and other ends are not supported for the time being.

   * When using the event tracking real\-time verification function, when the **verification rule** of the current operation interface is selected as **verification by metadata** and **verification by demand** , this function is supported.

# Establish event tracking real\-time verification connection

<span id="_2-2-建立埋点实时验证连接"></span>
## **Web app**

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">When using the real\-time event tracking verification function to verify the event tracking data of the webpage, it is necessary to ensure that the Web/JS SDK version of the webpage integration is 5.1.2 and above.</div>



1. Refer to the above entry guidelines, after entering the real\-time event tracking verification page of the web page, enter the address of the web page to be verified in the page, and click to **generate QR code**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6be41f55635e493fba1be21a29101ff9~tplv-goo7wpa0wc-image.image) </span>

2. The page will generate the URL address and QR code of the verification test page for you.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bb032468895a4d68a167eef29a3899f1~tplv-goo7wpa0wc-image.image) </span>

   You can:

   * Scan the QR code generated by the mobile phone, enter the page to be tested through the mobile phone, and trigger the test event through the mobile phone to verify the correctness of the event tracking report.

   * You can click to open the URL address through the computer, and trigger a test event after opening the visit page in the browser through the computer to verify the correctness of the event tracking report.

3. After completing the event tracking real\-time verification connection, you can view the verification results in the real\-time event tracking verification page. For details, please refer to the **View event tracking real\-time verification** section below.

## View event tracking log details

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">DataFinder has upgraded the event tracking real\-time verification function to provide more detailed verification process data and reporting capabilities. Among them, the fast verification capability is the standard version function (does not support generating reports), and the metadata verification and on\-demand verification need to be turned on at a fee (automatically verifies data abnormalities, supports automatic generation of verification reports).    * Verify by metadata: Verify whether the events and attributes that have been entered in the metadata management can be reported normally. If the events and attributes you trigger in the test page in the future are not entered in advance in the metadata management, the triggered test events and attribute data will not be displayed here.

   * Verify on demand: Verify that events in a specific event tracking requirement and whether attributes can be reported normally. If the events and properties that you trigger in the test page later are not in the corresponding event tracking requirement, the triggered test events and property data will not be displayed here.

2. After you start verification, you can randomly click on the test page to trigger some test events, and check whether the report meets expectations in the real\-time verification page.

   * You can view the overall reporting of the currently triggered test events in the upper right corner of the page, with an overview of how many events succeeded, how many failed, and so on.

   * You can view the behavior flow data of the test event on the left side of the page. For example, after the test events such as product exposure, product search, and order purchase are triggered in the test page, you can view the behavior flow of the corresponding event in the event list of the event tracking fact verification page.

   * By clicking on an event in the behavior flow, you can see in the event log details what event properties were reported for the corresponding event association, and you can see in the validation results whether the report was successfully validated.

3. Pause/end/clear event tracking. During the testing process, you can click Pause, End, and Clear event tracking as needed to control the testing process.

# Save report

If you want to solidify this verification process, you can click **Save as Report** in the upper right corner to save this test verification process as a verification report, and you can continue to view the verification details in the verification report later.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">The current verification report function is a value\-added function turned off by default, and only supported by SaaS\-cloud native environment. If you want to use this function, you can contact BytePlus technical support staff for consultation, and it can be used after purchase and activation.</div>


* <div data-tips="true" data-tips-type="warning">When the event tracking verification is in progress, saving the report is not supported. You need to pause the verification process before saving it as a report.</div>


* <div data-tips="true" data-tips-type="warning">Current Quick Validation does not support saving as a report.</div>


1. After the verification process is paused, click "Save Report" in the upper right corner of the page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fb2b0e075efc4e52952cb09653bdf3c0~tplv-goo7wpa0wc-image.image) </span>

3. After completing the configuration, click "Generate Report" to save this verification process as a report. See activity details for subsequent validation report viewing and management [Verification Report](https://docs.byteplus.com/docs/DataFinder/Verification_Report).
