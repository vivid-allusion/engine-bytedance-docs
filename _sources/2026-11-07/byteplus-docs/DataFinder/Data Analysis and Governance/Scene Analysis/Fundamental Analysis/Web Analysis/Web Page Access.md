In the "Web page access" module, you can understand the situation of your website being visited by users through different metrics and dimensions.

<span id="_1-快速入门"></span>
# Precautions


* The analysis module will only appear after accessing the web/JavaScript data.

* At present, DataFinder has upgraded the interface function of the source analysis module. This article introduces the operation points of the new version of source analysis.


<span id="_1-1-概述"></span>
# Configuration metrics

In the "Source Analysis" module, we can configure metrics, dimensions, etc. through the sections at the top of the page. As shown below:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/957a228189014556b998cfda47529eb5~tplv-goo7wpa0wc-image.image) </span>


* Support "5\-minute level", "hour level", "day level", "week level", "month level" time granularity, and can select the corresponding analysis time range according to the time granularity.

* You can check the indicators you are concerned about through the drop\-down menu; multiple selections are supported, and up to 6 indicators can be selected.

* Device type, user type, and source type can be determined according to the interface prompts.

   * Devices: PC, mobile devices.

   * Visitors: New visitors, old visitors.

   * Sources: direct sources, search engines, external links, in\-app jumps, social networks.

   * When you choose to filter by search engine/social network, you can select the specific search engine/social network in the drop\-down menu at the back.

* Support for configuring segmentation filtering. Support adding multiple filter conditions. The logical relationship between filter conditions is "AND". You can click the Batch Enter button to enter batches.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c44480c4f73544fda4f7f96cbe1f60f2~tplv-goo7wpa0wc-image.image) </span>


<span id="_1-2-2-数据展示"></span>
# View the resulting data

Access to the overview is presented through data cards and data tables.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/230d955a0a974d92bd072dbadae1cea4~tplv-goo7wpa0wc-image.image) </span>


* The card shows the cumulative value of each indicator within the time frame you selected.

   * Hover over the icon on the card to display the indicator description copy.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2dec21b3832d4e3192ef013347eb1768~tplv-goo7wpa0wc-image.image) </span>

* The detailed data table presents the following:

   * The URL of the page.

   * All the indicator data selected at the top are displayed by page.

* The data in the table can be downloaded locally.
