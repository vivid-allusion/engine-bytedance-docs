# 1. Introduction to the concept

<span id="_1-1-留存"></span>
## 1.1 Retention

**Retention refers to the user returning to the product after starting (adding or using the product) for a period of time.** 

**Retention rate refers to the ratio of the number of users who return to the product to the number of initial users.** 


* The rate of users returning to the product on the same day after adding or using the product is counted as the **same\-day retention rate**.

* The percentage of users returning to the product on the 2nd day after adding or using the product is calculated as the **Day Retention Ratio at Day 1**.

* The rate at which users return to the product on the nth day after adding or using the product is calculated as the **n\-day retention rate**.

* The ratio of users returning to the product from 8th to 14th days after adding or using the product is counted as the **retention rate for the next week**.

* The rate at which users return to a product within n weeks of adding or using it is calculated as the **n\-week retention rate**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The week here refers to the 7\-day week, not the natural week.   </div>
   

User retention is one of the key metrics for improving product and operational efforts. Therefore, after product upgrades and operational activities, it is often necessary to monitor and analyze the retention rate of the client base affected by upgrades or activities.

<span id="_1-2-新用户留存"></span>
## 1.2 New user retention

**New user retention is calculated with "new user" as the retention starting condition**.

That is, if 50 of the 100 new users added yesterday return to the product today, the new user Day Retention Ratio at Day 1 yesterday is 50%.

New user retention is the most commonly used retention calculation. In most cases, unless otherwise specified, "retention = retention of new users".

<span id="_1-3-活跃用户留存"></span>
## 1.3 Active user retention

**Active user retention is calculated with "active user" as the retention starting condition.** 

If 50 of the 100 users who were active yesterday return to the product today, the Day Retention Ratio at Day 1 is 50%.

<span id="_2-2-留存条件设定"></span>
## 2.2 Setting of retention conditions

Set the retention type, time, etc. to analyze.

Conditions that can be set include:


* Select the retention metric type: new user retention or active user retention;

* Select the retention level "Day/Week/Month" and the analysis period;

* Set up the operating system, software version, and channel to analyze the retained data.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1a3da1b4870743f3b6c15eb1c5b79b15~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-3-留存分析图表"></span>
## 2.3 Retention analysis charts

Analyze the statistical results of retention analysis.


* Retention rates can be viewed either overall or by day/week/month.

* You can choose whether to display the number of users.

* Statistical results can be downloaded as an Excel file.
