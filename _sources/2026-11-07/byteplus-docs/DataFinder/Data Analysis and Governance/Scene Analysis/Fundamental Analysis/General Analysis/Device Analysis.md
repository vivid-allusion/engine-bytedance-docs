# 3. Mini Program

<span id="_3-1-功能介绍"></span>
## 3.1 Function introduction

In the end point analysis module you can:


* Filter the range of end points you want to analyze, filter dimensions including time, and support fine filtering by common attributes;

* View the statistical results and trends of end points that match the selected public attributes. The end point analysis dimensions include: device model, mobile phone brand, operating system, network type, resolution, language environment, system version, base library version and WeChat version number;

* View and download detailed data for filtered end points, including: device model, new users, number of visitors, views, number of opens, and average usage time.


<span id="_3-2-页面介绍"></span>
## 3.2 Introduction to the page
