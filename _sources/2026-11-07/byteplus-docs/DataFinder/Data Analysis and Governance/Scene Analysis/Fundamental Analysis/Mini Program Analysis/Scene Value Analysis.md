# 1. Introduction to the concept

In scene values, you can perform a unified analysis of Mini Program scene values across multiple platforms through BytePlus Growth Analysis.

The current available operations include:


* View the statistical results of the product + all Mini Program scenes, and analyze the statistical results of multiple indicators from multiple dimensions;

* View and download detailed data for scene values.


<span id="_2-使用说明"></span>
# 2. Instructions for use

<span id="_2-1-功能简介"></span>
## 2.1 Function Introduction

In the scene value analysis module, you can:


* Filter the dimensions you want to analyze the scene values for, including time, platform, and visitor type.

* Filter the indicators that want to analyze the scene value, and the filter indicators include the number of viewers, the number of pages viewed, the number of openings, the number of openings per capita, the number of pages viewed per capita, the average usage time and the average screen time;

* Review the statistical results and trends of the selected dimensions and indicators.

* View and download detailed data for each scene value, including scene value ID, scene name, and selected metrics.


<span id="_2-2-页面简介"></span>
## 2.2 Introduction to the page

The "Scene Value Analysis" page, taking WeChat channel as an example, is as follows:


* You can filter the time range for statistics and perform custom intertemporal comparisons.

* Analytical indicators that can be selected for statistical purposes.

* Mini Program platform that can be screened for statistics;

* You can filter the types of visitors for statistics.
