DataFinder provides you with data analytics related to Mini Program access, such as the number of Mini Program visits, the number of views, the number of shares, etc. After accessing the Mini Program data and reporting it, you can conveniently access the relevant data analytics on the Mini Program access tool page.

<span id="5c67cd62"></span>
# Prerequisite

You need to complete the data access of the Mini Program before you can use the analysis module for data analytics.

<span id="_1-功能介绍"></span>
# Configure filter conditions

In the page access module, you can filter the range of pages you want to analyze by time, platform, and visitor type.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4e3fae546e0c4b78b4bf8c63ca900811~tplv-goo7wpa0wc-image.image) </span>


* You can filter the time range for statistics and customize the time range.

* Mini Program platform that can be screened for statistics;

* You can filter the types of visitors for statistics.


<span id="e4444bcd"></span>
# Access overview analysis

You can view and download detailed data for individual pages on the **access overview** page, such as number of visitors, views, exits, shares, exit rate, page URL, etc.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5e0966eb36f84a938b29d5a63a387b5f~tplv-goo7wpa0wc-image.image) </span>


* You can view the statistical results of each indicator of filtered page visits, as well as detailed data such as page URLs and the number of visitors.

* After clicking the search button, you can search and view the detailed data of a specific page by entering the page URL.

* You can click the Download Data button in the upper right corner to download the detailed data of the page visit locally.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Click <strong>Download Data</strong> The data downloaded to the local area is the full amount of data, and the results of searching through the URL only affect the data displayed on the page, not the data downloaded to the local area.   </div>

# Landing page analysis

You can view and download the detailed data of the entrance page on the **landing page analysis** page, such as: number of visitors, number of views, number of entrance pages, etc.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/232aa62f77b14a2b83495b055ee27866~tplv-goo7wpa0wc-image.image) </span>


* You can view the statistical results of each indicator on the entry page, as well as detailed data such as the page URL and the number of visitors.

* After clicking the search button, you can search and view the detailed data of a specific page by entering the page URL.

* You can click the Download Data button in the upper right corner to download the detailed data of the page visit locally.
