# 1. Introduction to the concept

In Share Analysis, you can conduct a unified analysis of user shares of Mini Programs across multiple platforms through BytePlus Growth Analysis.

The current available operations include:


* View the overall sharing trend statistics of Mini Program, and analyze the statistical results from multiple dimensions.

* View the shared fission meter results of the Mini Program and analyze the statistical results from multiple dimensions.

* View the list of users who have brought back traffic to the Mini Program, and analyze the list results from multiple dimensions.

* Check out the Mini Program's list of page shares, including the share page path and the share page title.

## 2.1 Sharing trends

<span id="_2-1-1-功能介绍"></span>
### 2.1.1 Function introduction

In the Share Trends module, you can:


* Filter the range of sharing trends you want to analyze, and the filtering dimensions include: platform and time;

* View the statistical results and trends of all shares, including: number of shares, number of shares, return traffic, share return ratio and new shares;

* View and download detailed data shared by Mini Program for each time frame, including: time period, number of shares, number of shares, return traffic, share return ratio, and new shares.

## 2.3 Sharing users

<span id="_2-3-1-功能介绍"></span>

* Filter the range of sharing users you want to analyze, and the filtering dimensions include: platform and time;
