# 1. Introduction to the concept

**Component analysis refers to the analysis of what a target user is made of and what components are there.**  For example, when I choose to do a compositional analysis of "old and new users," it means I want to see how many new users and how many old users are in the target group.

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-常见使用场景"></span>
## **2.1 Common usage scenarios**

**Component analysis can help us gain a comprehensive understanding of the distribution of users' common attributes and assist us in further optimizing our operating strategies.**  Typical use cases for component analysis include (but are not limited to):


* Check the distribution of new and old users in the target group, such as: check the distribution of new and old users among users who purchased annual membership;

* Check the urban distribution of the target group, such as: check the urban distribution of an Internet celebrity fan (users who often watch Internet celebrity videos), so that it is convenient to choose the location of the roadshow;

* Check the distribution of mobile phone brands in target groups, such as: check the distribution of mobile phone brands in fifth\-tier cities, so as to formulate new product strategies, better adapt to such models, and understand users' consumption levels.

## **3.2 Select View... Ingredient Distribution**


* The left "View the XX component distribution, which indicates what we want to group the target group by;

* You can choose to view the component distribution of new and old users, operating system, system version, software version, age, gender, province, city, etc.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1870d17f8e19423abbcfaaa51bd8cec8~tplv-goo7wpa0wc-image.image) </span>


<span id="_3-3-过滤用户"></span>
## **3.3 Filtering users**


* Filter the range of target users to be analyzed;

* You can copy or manually add a new control group, which is equivalent to displaying the results in groups, up to 2 groups;

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/75f5ac868317468ea68726b54b302f0b~tplv-goo7wpa0wc-image.image) </span>


Specifically, users to be analyzed can be filtered according to the following conditions or a combination of conditions:


* By user group: Select "By user group" as the filter criterion and specify the user group to filter.

* Global Filtering: Select user attributes (e.g. operating system, software version, etc.) as the filter criteria and refine the filter criteria.

* You can select and set multiple conditions simultaneously, and the relationship between these conditions is "and", that is, to filter users who meet these conditions at the same time.


<span id="_3-4-分析图"></span>
## **3.4 Analysis chart**

Review the visualization chart of the analysis results and make adjustments as required.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aed0bf0eba344834a9e7aae0710079d3~tplv-goo7wpa0wc-image.image) </span>

By default, the system automatically displays the last 30 days of statistical results in a circular graph. You can make the following adjustments to the analysis chart as required:


* Set the analysis time period: You can set it by "last n days/weeks/months" or "time range";

* Select the visual chart type: ring chart, column chart;


<span id="_3-5-表格"></span>
## **3.5 Forms**

Detailed data table showing statistical results.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/133bec8ac16c4ab6a3c2c27860caa647~tplv-goo7wpa0wc-image.image) </span>

The detailed data table supports the following operations:


* Select one or more rows to correlate with the data displayed in the component analysis chart.

* It can be downloaded as an excel file.
