# Capability overview

<span id="c95f2fc5"></span>
## Smart user details

DataFinder user details provides you with AI intelligent user behavior details capabilities. Based on AI large model capabilities, it can realize intelligent user analysis of user behavior flow semantics:


* **Analysis Intent Clarification:**  Based on the preliminary results of the current review, recommend the content applicable to the user's analysis; or after multiple rounds of dialogue, gradually refine the goal of clarifying the analysis with the user.

* **Key event tracking extraction:**  Match the associated event tracking according to the analysis target, and users can do manual intervention based on business knowledge.

* **Behavioral characteristic analysis:**  According to the analysis idea, the characteristic analysis is automatically carried out from the user's qualified behavior stream, and the analysis conclusion is semantically output.

* **Quantitative rule linkage:**  For the conclusion of the analysis, it can be extracted into the form of individual labels or screening conditions, and returned to the traditional UBA analysis tools.

## Basic concept


|Term |Detailed description |
|---|---|
|UUID、SSID |UUIDs and SSIDs are both unique identifiers for users. The main difference is that UUIDs are assigned and managed by you and your team, while SSIDs are assigned and managed by DataRanges.<br><br><br>* **UUID** : that is, User Unique Id, generally corresponds to the user's login id (such as mobile phone number, email) one\-to\-one, UUID is maintained by you and the team;<br><br>* **SSID** : that is, Standardized Service ID (Standardized Service Id), is the user identity provided by BytePlus Growth Analysis products to mark and identify users. SSIDs are generated and maintained by BytePlus Growth Analysis and can be used by you and your team as needed.<br><br>* **WEB_ID** : Unique identification of the device, mainly used on the web and Mini Program.<br><br>* **DID** : The unique identifier of the device, mainly used in APP mobile end.<br><br>* **ANONYMOUS_ID** : Anonymous ID, optional reporting, mainly used to report the anonymous ID generated by the customer.<br><br>* Other custom reported ID types: If there are other caliber custom user_unique_id (such as the existence of multiple ID systems, etc.), the SDK provides the ability to customize ID types. If you configure other ID types synchronously, the corresponding ID type will be displayed in the user review list and queried.<br><br><br>For more information on each ID type, see [Supported User Unique Identifiers](https://docs.byteplus.com/docs/DataFinder/Supported_User_Unique_Identifiers). See the Development Guide \> Important Basics (Required Reading) \> Supported User Unique Identifiers section. |
|Behavioral flow |Behavior flow, which is a detailed behavioral trajectory of a single user presented in chronological order of events occurring on the client side. |

## Application scenario

Behavioral details are an extremely efficient tool for studying users and their behavior. Typical usage scenarios include (but are not limited to):


* Product & user experience team: understand the process of users using the product and make personas;

* Operations & Growth team: understand the user's conversion path, identify issues and improvement points that affect conversion.

* Service team: replay the user's behavior before encountering problems, and understand the product usage process of the served user.

* R & D team: Replay the user's crash or abnormal usage behavior stream and restore the problem scene.

You can combine the user behavior characteristics conclusions to further initiate in\-depth pop\-up analysis.

* Usually, intelligent user analysis can be used in combination with other analysis tools of DataFinder, DataTester and other capabilities according to the actual business analysis goals to achieve in\-depth analysis and result verification of the business. ## Query user

The user review page shows you the last 100 users who had events that day, and the page shows 20 by default.


* You can configure filters for user queries in Filters at the top of the page, including setting the query time range, query template, and event range for participating in the analysis (default is all).

   Among them, the scope of the query template storage includes the configuration of query conditions and query results. You can set up scenario\-based detailed examination configuration templates such as event tracking troubleshooting, feedback analysis, and abnormal reproduction. In the future, you only need to change the query ID to reuse the scene. The template will also be synchronized with other members of the project for experience precipitation.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/017468f6ee1644e4bb725c360b903aa9~tplv-goo7wpa0wc-image.image) </span>

* You can also query specific users directly by user ID, and currently supports filtering to find users by multiple user ID types, such as UUID, SSID, WEB_ID, DID, ANONYMOUS_ID and other custom reported ID types.

* Click the user name in the user list to jump to the user information and behavior flow details page to view the corresponding details.

## View user behavior flow

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6068581a07454641b48c748bb366d380~tplv-goo7wpa0wc-image.image) </span>

## Download user behavior stream data

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/29b909f445104565b6a1781a467cb098~tplv-goo7wpa0wc-image.image) </span>


* You can click the "Download" button in the behavior flow page module to download the user behavior events in the current time range locally.

* Supports downloading offline files in CSV format.

* You can control the time period for downloading data through the time component at the top of the page. The maximum download time period is 30 days.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">The data downloaded on the current page is the corresponding user's behavior "event" data. If you want to download the event and event attribute data at the same time, you can go to the SQL custom query page and query the events table in the SQL custom query. After restricting the user and time, query the content field (the content field contains all the attributes of the event), and then download the query results to the local. However, this method can only query the property details within the last 30 days, and the data content field for more than 30 days will be cleared.</div>
