# 1. Overview

In BytePlus Growth Analysis, a **user portrait** is a calculation of the characteristics of a label for all or subdivided users of a product.

User portraits are a common tool in marketing, operations, and product work. Typical usage scenarios include (but are not limited to):


* Study the characteristics of segmented user groups in order to develop targeted marketing strategies.

* Contrast the profile characteristics of different user groups to guide operation.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The "gender distribution" and "age distribution" profile data are only available in the SaaS version, not in the privatized version.</div>

# 3. Function usage

<span id="_3-1-功能界面组成"></span>
## 3.1 Functional interface composition

The user portrait function interface consists of the following parts:


* Image conditions: select the user group, time, etc. for the portrait;

* Portrait results: View user portrait results.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b9bc3385912a43bf830a4be5d52479a5~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-1-1-画像条件"></span>
### 3.1.1 Image conditions

Select the user group, time, etc. for the profile.

The specific use is as follows:


* Select the portrait time: Default is the last 7 days. Even for the same subgroup of users, the distribution of their label features varies over time.

* Select user grouping: Default is all users. You can choose one or more user groups.

* Select Split filter: Select Include event public properties.


<span id="_3-1-2-画像结果"></span>
### 3.1.2 Image results

View the label distribution for the target user base.

Currently available to view:


* Gender distribution (Mini Program only)

* Geographical distribution;

* User loyalty (currently only the Mini Program).
