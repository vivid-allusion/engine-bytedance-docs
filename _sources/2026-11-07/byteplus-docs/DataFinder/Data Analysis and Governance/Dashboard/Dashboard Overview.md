# 1. What is a Dashboard?

Dashboard is a tool to help you manage commonly used charts, which is used to monitor product market data on a daily basis and save the layout of high\-frequency usage charts.

<span id="_2-公共空间看板"></span>
# 2. Public space Dashboard


* Usage scenario

   The public space directory is managed and maintained by the administrator in a unified manner. It is suitable for Dashboard boards that require the common attention of all members. It is suitable for building a systematic report system. It is usually created by data analysts, project owners, administrators, and other members.

* Usage restrictions

   Users must have the "Public Space Management" permission to create a public space dashboard. If you need it, please contact the administrator to open it. All members are visible by default when created.


<span id="_3-个人空间看板"></span>
# 3. Personal space Dashboard


* Usage scenario

   The personal space dashboard is managed and maintained by the user personally, and is suitable for managing dashboards created by individuals and those shared by others.

* Usage restrictions

   All users can create, and after creation, only they can see it by default. They can share it with other users for viewing or editing together.
