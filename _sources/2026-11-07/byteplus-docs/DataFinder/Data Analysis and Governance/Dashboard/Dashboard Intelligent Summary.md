Dashboard is based on large model capabilities and built\-in standard templates, providing intelligent summary functions and automatically generating key indicator analysis reports to help you efficiently gain insight into key Dashboard data and trends. This article provides instructions for the operation of the intelligent summary function.

<span id="2c8e6087"></span>
# Function permission


* If the currently logged in user has the permission to view the Dashboard, the intelligent summary function can be turned on.

* Dashboard owners or users with Dashboard editing privileges can edit and save the built\-in standard templates.

* Users who only have Dashboard viewing permission, but no editing permission, can modify the built\-in standard template and save it as a personal interpretation template.


<span id="e397aafb"></span>
# Operating instructions

<span id="20ba20a0"></span>
## Turn on smart summary


1. Log in to the Growth Analysis DataFinder Console and go to the designated group.

2. In the navigation bar at the top of the page, select **Dashboard**.

3. In the left space list, enter the designated Dashboard space.

4. Click at the top of the page **to open Smart Summary**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a788ebf3c7a5405c8c06acbb01180ce4~tplv-goo7wpa0wc-image.image) </span>


<span id="7b3d34d1"></span>
## View the summary report

After turning on the intelligent summary, wait for the AI automatic analysis to complete, and then you can view the summary report.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5c92da67dfd94ee9b7efcfae6755793e~tplv-goo7wpa0wc-image.image) </span>


* In the report, it is supported to view the analysis and trends of various key indicators; drill down the data by dimension, such as the top 5 dimension values, month\-on\-month growth and month\-on\-month decline, etc.

* If there are multiple charts in the Dashboard board, click Position Chart on the corresponding analysis content to locate the chart corresponding to the analysis content.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e7e5996b6118444e8a1f4778c9b7b2a4~tplv-goo7wpa0wc-image.image) </span>
