# Main API Description

<span id="068d02d5"></span>
## setUserUniqueId


* **Function:**  Set user login status. Set user_unique_id value after initialization and the SDK will save it, so it only needs to be set when changes occur.

* **Definition:**  setUserUniqueId (userUniqueID: string or null): void

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |userUniqueID |String or null |Yes, null. |When null, exit user mode |
   

* **Example:** 

   * Login user mode

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   //Set the ID of your account system when logging in and ensure its uniqueness
   RangersAppLogModule.setUserUniqueId('{{USER_UNIQUE_ID}}');
   ```
   

   * Exit user mode

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   //Set uuid to null when logging out
   RangersAppLogModule.setUserUniqueId(null);
   ```
   


<span id="b2d173ef"></span>
## onEventV3


* **Function:**  Report the event and call it after initialization.

* **Definition:**  onEventV3 (eventName: string, params?: Record < string, string or number or boolean \>): void

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |eventName |string |Yes |Event name, cannot empty string |
   |params |Record < string, string or number or boolean \> |No |event parameters<br><br>```JSON```<br>```{```<br>```    "key_string": "value_string",```<br>```    "key_int": 10```<br>```}```<br> |
   

* **Example:** 

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   //Example: Report event event_name , the event does not contain properties
   RangersAppLogModule.onEventV3("event_name");
   
   //Example: Report event event_name with two properties
   //A property of type string, the property name is key_string, and the property value is value_string
   //a property of type int, the property name key_int, the property value is 10
   RangersAppLogModule.onEventV3("event_name", {
       "key_string": "value_string",
       "key_int": 10
   });
   ```

# AB test API Description

The SDK provides AB test capabilities and provides a series of methods: getABTestConfigValueForKey, getAbSdkVersion, getAllAbTestConfigs.

<span id="79c73ebc"></span>
## Open AB test

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">The corresponding AB setting needs to be enabled during the initialization of the native code.</div>


<span id="fcc01dd4"></span>
## getABTestConfigValueForKey


* **Function:**  Get the configuration value of the AB test, which can only be called after initialization.

* **Definition:**  getABTestConfigValueForKey (key: string, defaultValue: any): Promise < any \>

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |key |string |Yes |AB test key to configure experimental parameters |
   |defaultValue |any |Yes |Default values for experimental parameters for bottom\-line A/B experiments. If the A/B experiment is not enabled, or the experimental parameters corresponding to the A/B experiment are not configured with parameter values, the default value is returned through this method. |
   

* **Return value:** 

   
   |Type |Explain |
   |---|---|
   |Promise |Returns AB test configured value asynchronously |
   

* **Example:** 

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   RangersAppLogModule.getABTestConfigValueForKey('ab_test_key', 'default_value').then((value) => {
       console.log(value);
   });
   ```

# User Attributes Features API Description

Provides the ability to set user properties and provides a series of methods: profileSet, profileSetOnce, profileUnset, profileIncrement, profileAppend.

<span id="2eb3011d"></span>
## profileSet


* **Function:**  Set user properties, overwrite if they exist, and create if they don't exist.

* **Definition:**  profileSet (profileDict: Record < string, string or number or string [] \>): void

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |profileDict |Record < string, string or number or string [] \> |Yes |The set user property, the value of the property is in the format of the parameter dictionary, and the value of the parameter dictionary can only be of the following types: string, integer, floating\-point, string array |
   

* **Example:** 

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   RangersAppLogModule.profileSet({"key": "value"});
   ```
   


<span id="f0fba200"></span>
## profileSetOnce


* **Function:**  Set user properties, do not set if they exist, create if they do not exist, suitable for first\-time related user properties, such as first access time. Unlike the profileSet interface, if a profile has been successfully set through the profileSetOnce interface, it is invalid to call the profileSetOnce interface again on the profile.

* **Definition:**  profileSetOnce (profileDict: Record < string, string or number or string [] \>): void

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |profileDict |Record < string, string or number or string [] \> |Yes |Parameter dictionary values can only be of the following types: string, integer, floating\-point, string array |
   

* **Example:** 

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   RangersAppLogModule.profileSetOnce({"key_once": "value_once"});
   ```
   


<span id="958365b9"></span>
## profileIncrement


* **Function:**  Set the properties of the numeric type to accumulate.

* **Definition:**  profileIncrement (profileDict: Record < string, number \>): void

* **Parameters:** 

   
   |Parameter name |Type |Required |Explain |
   |---|---|---|---|
   |profileDict |Record<string, number\> |Yes |Can only increment integers (can be negative integers). If a floating\-point number is passed in, the SDK will ignore it. |
   

* **Example:** 

   ```TypeScript
   import { NativeModules } from 'react-native';
   const { RangersAppLogModule } = NativeModules;
   
   RangersAppLogModule.profileSetOnce({"key": 1});
   ```
