### Web

<span id="框架支持范围"></span>
#### Framework support range

As long as it is a standard browser environment that supports native JavaScript, the SDK can be used, regardless of the framework.

Some framework\-specific features, rather than browser\-specific features, are not supported by the SDK. For example, if React has JSX, the browser does not recognize JSX, and the SDK cannot recognize it.

Cross\-platform frameworks (such as RN) cannot be directly integrated with the Web SDK, but can be integrated directly into the browser\-side pages generated by the framework.


|Framework |Support Notes |
|---|---|
|Vue2 |✅ |
|Vue3 |✅ |
|React |✅ |
|Angular |✅ |


<span id="服务端框架支持范围"></span>

<span id="浏览器支持范围"></span>
#### Browser support range

As long as it is a standard browser environment that supports native JavaScript (no ES6 required), it can be used regardless of the operating system, platform type, browser type, or browser version. There is no guarantee that some niche browsers do not implement standard JavaScript, causing some properties to vary depending on the operating system, platform type, browser type, and browser version.

Some features require relatively new browsers to support, such as batch sending requires LocalStorage storage. If some features (such as batch sending) are not supported in the version browser, the SDK will not report an error, but will automatically downgrade (use image sending), or remove this function.
