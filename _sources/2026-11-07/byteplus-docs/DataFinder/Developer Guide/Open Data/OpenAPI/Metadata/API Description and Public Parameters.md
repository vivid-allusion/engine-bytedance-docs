# 1. Overview

This document provides interfaces for metadata\-related operations such as applications, events, virtual events, event properties, user properties, and virtual properties.


* All write operations (create, modify, delete) require administrative privileges.


<span id="3d6396de"></span>
# 2. API public parameters

**Context\-path**: /datafinder


|**Parameter** |**Type** |**Description** |**Required** |
|---|---|---|---|
|app_id |int |App ID |true |
