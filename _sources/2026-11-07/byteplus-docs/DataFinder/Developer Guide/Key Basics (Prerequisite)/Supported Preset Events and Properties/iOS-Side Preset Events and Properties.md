# Background information


* Environment description: The current DataFinder provides you with a variety of environments, and the list of preset events and preset properties supported by each environment varies slightly. You can view the preset events and preset property capabilities supported by the corresponding environment according to your current environment. If you are unsure which environment you are currently using, see [SaaS Cloud-Native & Privatized Environments](https://docs.byteplus.com/docs/DataFinder/SaaS_Cloud-Native_Privatized_Environments).

* Event/Attribute Type Description: The current introduction to you is the "preset event" and "preset event properties" supported by each end. In addition, DataFinder also supports preset event public properties and preset user properties. Please refer to the introduction of each type of property [Preset Property Summary Table](https://docs.byteplus.com/docs/DataFinder/Preset_Property_Summary_Table).

* Reporting mechanism: See details [Product logic: data reporting & caching strategy](https://docs.byteplus.com/docs/DataFinder/DataFinder_Data_Access_Overview#e98b6846).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The app_launch event that is finally queried on the DataFinder is the app_launch event when the app_launch event occurs in the foreground when the application is started, that is, the DataFinder has a built\-in attribute <code>is_background</code>used to mark whether the event occurs in the background, and finally the app_launch data when you analyze the query is filtered out <code>is_background = true</code>data.</div>


<div data-tips="true" data-tips-type="tip">Therefore, if you compare the app_launch data queried by the DataFinder analysis tool and directly export the app_launch data in the DataFinder database, there may be some differences, which may be caused by the filtering of the data <code>is_background = true</code>on the DataFinder side.</div>
