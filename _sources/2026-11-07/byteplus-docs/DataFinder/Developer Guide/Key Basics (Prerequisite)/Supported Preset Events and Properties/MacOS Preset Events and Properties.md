## Application Launch Event (app_laucn)


|**Event name** |**Monitoring timing** |**Event description** |**Property name** |**Property display name** |**SaaS\-cloud native** |**Privatization** |**Property type** |**Property description** |**Version** |**Remarks** |
|---|---|---|---|---|---|---|---|---|---|---|
|app_launch |application foreground |Apply cold start, and report when entering the foreground from the background, and also report when setting user_unique_id |session_id |Session ID |support |support |string |session_id is randomly generated by the SDK and a new one is generated each time it comes back to the foreground. |1.3.12+ |Example: a829cc7f\-c86c\-462d\-971e\-0710e9ff66bd |
||||$resume_from_background |Cold start/hot start |support |support |bool |Marks whether the Launch event was generated from a background recovery, false is a cold start, and true is a hot start | | |
