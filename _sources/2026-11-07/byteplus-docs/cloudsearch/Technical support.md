If you encounter problems that are difficult to solve while using Cloud Search, you can submit a ticket for consultation.

<span id="72bd3270"></span>
## Create a ticket


1. Log on to [Ticket Center](https://console.byteplus.com/workorder/create).

2. Select **Create Ticket** in the left navigation bar, then enter **Cloud Search** in the search box and click **Cloud Search** in the search results box.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/52b360ae8cdc48138ccdcfdc32cac89e~tplv-goo7wpa0wc-image.image) </span>

3. Select the issue type and click **Create Now**.

4. Fill in the issue description and select the issue priority, set the notification method, etc., and then click **Submit Ticket**.


<span id="03a8022f"></span>
## View tickets


1. Log on to [Ticket Center](https://console.byteplus.com/workorder/create).

2. Select **Ticket List** in the left navigation bar.

3. On the **Ticket List** page, you can search and view the status and progress of tickets based on the ticket number, type, and other conditions.
