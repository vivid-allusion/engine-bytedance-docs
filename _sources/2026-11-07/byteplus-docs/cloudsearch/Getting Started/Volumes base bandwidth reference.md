When you add bandwidth packages for data nodes, the actual throughput of the volumes is limited by the instance I/O bandwidth. Please confirm whether the selected instance node specification supports sufficiently high volumes bandwidth. Otherwise, the volumes cannot deliver all performance. This topic describes the base bandwidth of volumes for your reference.
