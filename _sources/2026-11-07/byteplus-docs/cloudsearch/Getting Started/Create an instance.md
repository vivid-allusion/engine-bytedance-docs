This topic introduces the preparations before using Cloud Search for the first time and the steps to create an instance.

## Notice

Before creating a Cloud Search instance, you need to understand the following notices:

* **Instances with 1 core and 4 GiB nodes are prohibited in production environments**: 1 core and 4 GiB nodes are suitable for testing scenarios. Instances of this small specification are prohibited in production environments because they are prone to CPU overload or OOM issues.

* **Single\-node instances are prohibited in production environments**: Single\-node instances are only suitable for testing scenarios. If you use a single\-node instance for testing and want to switch to production use, it is recommended to upgrade to 3 nodes or more. For more information, see [Upgrade an instance](https://docs.byteplus.com/docs/cloudsearch/upgrading).

* **Instances with two nodes are prohibited**: Two\-node instances risk split\-brain issues, so Cloud Search prohibits creating such instances.

This section only covers precautions when creating an instance. For details on index replicas, disk capacity, and other considerations, refer to [Before use](https://docs.byteplus.com/docs/cloudsearch/Before-Use).

## Preparations

* Before using Cloud Search, register a BytePlus account and complete  enterprise authentication.

* When creating an instance in the console for the first time, complete cross\-service authorization to allow Cloud Search to access other cloud product resources. For authorization instructions, see [Cross-service authorization](https://docs.byteplus.com/docs/cloudsearch/cross-service-authorization).

## Create an instance

1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the project and region where you want to create an instance.

3. On the **Instances** page, click **Create instance**.

4. On the **Create instance** page, set the instance name, deployment method, node type and quantity, access method, and other parameters, then click **Confirm order**.

5. On the **Confirm order** page, review the instance configuration details, read and check the **Service\-Specific Terms for BytePlus Database Products and Services**, then click **Buy now** to complete the instance creation.

   After the instance is purchased successfully, click **Go to the console**. The page will automatically redirect to the instance list page, allowing you to view the newly created instance. The instance will be created within a few minutes.

   > **tip**

   > When confirming the order, individual users must also check the **Explanation of unsubscription or change fees**. If you need to use an enterprise account, complete the enterprise verification.

## What's next

After the instance is created, you can connect to it and start using Cloud Search services, such as defining indexes, importing data, and searching data. You can access the instance through the following methods:

* [Access the instance through Kibana in the management console](https://docs.byteplus.com/docs/cloudsearch/accessing-by-Kibana)

* [Access the instance via Elasticsearch RESTful API](https://docs.byteplus.com/docs/cloudsearch/accessing-by-API)

* [Access the instance using clients in various programming languages](https://docs.byteplus.com/docs/cloudsearch/accessing-by-client)
