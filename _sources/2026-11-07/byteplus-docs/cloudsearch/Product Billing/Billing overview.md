This topic introduces the billing information for Cloud Search instances, including the billing methods, instance lifecycle, and billable items.

<span id="计费类型"></span>
## Billing Method


|**Billing Method** |**Description** |
|---|---|
|Pay\-as\-you\-go |You are charged for your instance based on the node specifications. Bills are generated on an hourly basis, and fees are automatically deducted from your BytePlus account. If you no longer need an instance, you can release it to save costs. This billing method is suitable for short\-term usage. For more information, refer to [Pay-as-you-go](https://docs.byteplus.com/en/docs/cloudsearch/pay-as-you-go). |
|Subscription |You must pay an upfront fee when you create an instance. This billing method is cheaper than pay\-as\-you\-go and suitable for long\-term usage. For more information, refer to [Subscription](https://docs.byteplus.com/en/docs/cloudsearch/subscription). |


<span id="实例生命周期"></span>
## Instance lifecycle

The billing method that you select determines how the lifecycle of a Cloud Search instance is calculated.


* **Pay\-as\-you\-go**: The lifecycle of an instance starts when you create it and ends when you release it.

* **Subscription**: The lifecycle of an instance starts when you create it. The instance is automatically released upon expiration.


For more information, refer to [Pay-as-you-go](https://docs.byteplus.com/en/docs/cloudsearch/pay-as-you-go) and [Subscription](https://docs.byteplus.com/en/docs/cloudsearch/subscription).

<span id="计费项"></span>
## Billable items

For more information on the billable items of Cloud Search instances, refer to [Billable items](https://docs.byteplus.com/en/docs/cloudsearch/billing-items).

<span id="更多操作"></span>
## More operations


* Changing the billing method: Cloud Search allows you to change the billing method of an instance only from pay\-as\-you\-go to subscription. For more information, refer to [Changing the billing method from pay-as-you-go to subscription](https://docs.byteplus.com/en/docs/cloudsearch/changing-billing-method).

* Renewing an instance: A subscription instance is automatically released upon expiration. If you want to continue using the instance, you can renew it. For more information, refer to [Instance renewal](https://docs.byteplus.com/en/docs/cloudsearch/renewal).

* Unsubscribing from an instance: If you no longer need a Cloud Search instance, you can unsubscribe from it. For more information, refer to [Costs for unsubscription or changing node specifications](https://docs.byteplus.com/en/docs/cloudsearch/Costs-of-unsubscription).
