Cloud Search offers the task center feature. You can use it to record important, non\-real\-time instance operations, such as creating an instance, modifying instance specifications, modifying configurations, and installing plugins. In the task center, you can view various information on each task, such as the task type, start time, and status.

<span id="查看任务"></span>
## Viewing tasks


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

3. In the left\-side navigation pane, choose **Task Center**.

4. View the task list.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7f2976bafc3f4dcd92fb3092ef5f3067~tplv-goo7wpa0wc-image.image) </span>

   * Task time: specify a start time and an end time to view the tasks within this period.

   * Action target instance ID: specify an instance ID to view the tasks that were performed on this instance.

5. Click the plus icon before a task to view its information at different stages, such as the progress, time spent, and completion time.
