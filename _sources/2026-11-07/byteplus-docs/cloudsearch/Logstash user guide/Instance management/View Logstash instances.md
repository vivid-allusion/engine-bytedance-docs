This article describes how to view Logstash instances.

<span id="S7Ex2OiS"></span>
## Operation steps


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. In the upper\-left corner of the top menu bar, select the project and region where the Logstash instance belongs.

   If the instance is not assigned to a project, select **All account resources**.

3. In the left navigation pane, select **Data Processing** \> **Logstash** to view the Logstash instances.

   The Logstash instances list displays information about each instance, such as its name, ID, and status. By default, the Logstash instances list displays all fields. You can customize the fields displayed in the list. The following table describes each field in the instances list.

   
   |Field |Note |
   |---|---|
   |Instance name/ID |The name and ID of the Logstash instance. Click the instance name to view the instance details. |
   |Status |The running status of the Logstash instance. |
   |Availability zone |The availability zone where each node of the Logstash instance is located. |
   |Tags |The tag information associated with the Logstash instance. The number of tags associated with the Logstash instance. Hover over the number of tags to view the tag keys and values associated with the Logstash instance in the tooltip. |
   |Instance specifications |The specifications of the Logstash instance. |
   |Number of nodes |The number of nodes in the Logstash instance. |
   |Monitoring |Click the Monitoring icon to view the monitoring dashboard of the Logstash instance. |
   |Virtual Private Cloud |The Virtual Private Cloud associated with the Logstash instance. Hover over the Virtual Private Cloud name to view its ID. |
   |Version |The version of the Logstash instance. |
   |Creation time |The time when the Logstash instance was created. |
   |Project |The project to which the Logstash instance belongs. |
   |Billing type |The billing type of the Logstash instance. The supported billing types are Pay\-as\-you\-go and Subscription. For more information about billing types, refer to<br><br>[Product billing](https://docs.byteplus.com/en/docs/cloudsearch/billing). |
   |Actions |The actions supported for the Logstash instance.<br><br><br>* [Upgrade a Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Upgrade_a_Logstash_instance)<br><br>* [Restart a Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Restart_a_Logstash_instance)<br><br>* [Cancel a Subscription Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Cancel_a_subscription_Logstash_instance)<br><br>* [Change a Pay-as-you-go Logstash instance to a Subscription](https://docs.byteplus.com/en/docs/cloudsearch/Convert_a_pay-as-you-go_Logstash_instance_to_a_subscription)<br><br>* [Delete a Pay-as-you-go Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Delete_a_pay-as-you-go_Logstash_instance) |
