You can manually cancel subscription Logstash instances that you no longer need. This topic describes how to cancel a subscription Logstash instance.

<span id="Li1Qk9tR"></span>
## Prerequisites


* A Logstash instance has been created, and the billing type is subscription. For more information, refer to [Create a Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_Logstash_instance).

* Deletion protection is disabled for the Logstash instance you want to cancel. For more information, refer to [View Logstash instance details](https://docs.byteplus.com/en/docs/cloudsearch/View_Logstash_instance_information).


<span id="ujo6mHkd"></span>
## Notice


* After you cancel a Logstash instance, all data in the instance is deleted and cannot be recovered. Proceed with caution.

* After you unsubscribe from a Logstash instance, the system will issue a refund according to the refund rules.


<span id="Zpr8cG4b"></span>
## Operation steps


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. In the upper\-left corner of the top menu bar, select the project and region of the Logstash instance.

3. In the left\-side navigation pane, select **Data Processing** \> **Logstash**.

4. In the Logstash Instances list, click  **...**  in the **actions** column of the target Logstash instance. \> **Unsubscribe**.

5. In the pop\-up prompt, click **Confirm**.

6. On the **Unsubscribe** page, confirm the Logstash instance information and refund amount, and click **Confirm Unsubscription**.

7. In the pop\-up dialog box, click **Confirm**.
