You can manually delete a pay\-as\-you\-go Logstash instance based on your business needs. This topic describes how to delete a pay\-as\-you\-go Logstash instance.

<span id="DPervFnH"></span>
## Prerequisites


* A pay\-as\-you\-go Logstash instance is created. For more information, refer to [Create a Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_Logstash_instance).

* Deletion protection is disabled for the Logstash instance that you want to delete. For more information, refer to [View Logstash instance information](https://docs.byteplus.com/en/docs/cloudsearch/View_Logstash_instance_information).


<span id="0xzHX6qI"></span>
## Notice


* After you delete a Logstash instance, all its data is deleted and cannot be recovered. Proceed with caution.

* No refund is provided for deleting a pay\-as\-you\-go Logstash instance.


<span id="a77s7OA5"></span>
## Operation steps


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. In the upper\-left corner of the top menu bar, select the project and region for the Logstash instance.

3. In the left navigation pane, select **Data Processing** \> **Logstash** to view the Logstash Instances.

4. In the Logstash Instances, click  **...**  in the **actions** column for the target Logstash instance. \> **delete**.

5. In the confirmation dialog box, click **confirm**. The Logstash instance enters the **Deleting** state. After the deletion is complete, the Logstash instance is removed from the Instances.
