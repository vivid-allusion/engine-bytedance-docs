This topic describes how to view Logstash instance information.

<span id="D1yiJSoe"></span>
## Prerequisites

You have created a Logstash instance. For specific steps, refer to [Create a Logstash instance](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_Logstash_instance).

<span id="JYP9pJRX"></span>
## Operation steps


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. In the upper\-left corner of the top menu bar, select the project and region of the Logstash instance.

3. In the left\-side navigation pane, select **Data Processing** \> **Logstash**.

4. On the Logstash Instances page, click the name of the target instance to go to the **Basic Information** tab, where you can view its **Basic Information**, **Instance Specifications**, **Network Information**, **Billing Information**, and **Architecture Diagram**.

   
   |Category |Details |
   |---|---|
   |Basic information |Basic information includes the instance name, version, instance ID, region, project, availability zone, deletion protection, tags, and maintenance window. To unsubscribe from a Subscription Logstash instance or delete a Pay\-as\-you\-go Logstash instance, click **disable** next to **deletion protection** to disable deletion protection. |
   |Instance specifications |Instance specifications include node specifications, number of nodes, storage specifications, and storage capacity. |
   |Network information |Network information includes the Virtual Private Cloud and subnets. |
   |Billing information |Billing information includes the creation time, billing type, expiration time, and time until expiration.<br><br>The expiration time and time until expiration are displayed only when the Logstash instance billing type is Subscription. |
   |Architecture diagram |The system provides an architecture diagram of the Logstash instance, which visually displays the running status and specifications of the instance and its nodes. Hover over an instance or a node to view its status and specifications. |
