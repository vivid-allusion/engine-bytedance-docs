Logstash pipelines are divided into standard pipelines and metadata migration pipelines. This article introduces the standard pipeline.

<span id="4fH64GgN"></span>
## Processing target

The standard pipeline handles the actual data content itself, which is the core data generated by business operations. For more details, see  [Logstash official supported pipelines](https://www.elastic.co/guide/en/logstash/8.17/configuration-file-structure.html).

<span id="a8Q0DiYi"></span>
## Compatibility

See [Differences in output plugins between Elasticsearch and OpenSearch](https://docs.byteplus.com/en/docs/cloudsearch/Differences_Between_Plugins_in_Elasticsearch_and_OpenSearch).
