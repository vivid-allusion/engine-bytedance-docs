Cloud Search provides out\-of\-the\-box capabilities and has the following benefits.

<span id="一键部署"></span>
## Easy deployment

You can create an instance by simply clicking **Create Instance** in the Cloud Search console and selecting the specifications and network configurations as needed. The entire creation process can be completed in minutes. You do not need to deploy or debug software or hardware, which saves a lot of time.

<span id="弹性扩容"></span>
## Elastic scalability

Cloud Search instances support auto scaling. You can change the instance type, number of nodes, and disk capacity as needed to meet the requirements of your changing business scenarios.

The advanced features such as Security, SQL, and Alerting provided by Open Distro plugins effectively ensure the security of instances and improve the efficiency of O&M management and operations.

<span id="高安全性"></span>
## High security

Cloud Search allows you to deploy instances in virtual private clouds (VPCs) and access instances over HTTPS to ensure the security of data during transmission. The Security plugin provides the multi\-tenant capability to ensure the security of your resources.
