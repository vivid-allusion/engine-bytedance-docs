This topic introduces the features of Cloud Search.

<span id="数据存储"></span>
## Data storage


* Cloud Search provides different instance types and high\-performance volumes. This effectively ensures your data read and write performance.

* Cloud Search instances can be scaled elastically. You can increase the number of nodes and upgrade the disk size and instance type of your node as needed. This helps meet the requirements of your changing business scenarios.

* Cloud Search supports instance monitoring. This helps you reduce O&M costs and ensures the availability of instances.


<span id="数据检索分析"></span>
## Data retrieval and analysis


* Cloud Search provides stable, reliable real\-time search services, including full\-text retrieval, analysis, aggregation, and highlighting. Cloud Search also provides SQL analysis capabilities through plugins. You can perform queries by complex combinations and conditions or perform fuzzy queries. This allows you to easily deal with the query and analysis scenarios where various text, numbers, dates, IP addresses, and geographic data are involved.

* Cloud Search provides a RESTful API and clients in different programming languages. You can find matching information from petabytes of data in milliseconds. This helps you build search businesses efficiently.


<span id="数据可视化"></span>
## Data visualization

Cloud Search is integrated with Kibana services. In Kibana, you can build visual O&M panels, perform statistics and classification of business data, and create dashboards for data visualization. This allows you to efficiently perform statistics and analyses of massive data and explore the value of your business data.

<span id="f313750f"></span>
## **Vector search**

Cloud Search supports k\-NN to offer vector search and vector storage capabilities. On the basis of Cloud Search clusters, k\-NN vector databases can offer large\-scale distributed capabilities, bringing users with vector search capabilities that can be scaled out by orders of magnitude.

Meanwhile, Cloud Search also supports Hybrid Search, which is more in line with the needs of the search scenario.
