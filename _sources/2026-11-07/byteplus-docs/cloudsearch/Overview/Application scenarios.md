This topic describes the applicable scenarios for Cloud Search.

<span id=".5pel5b-X5YiG5p6Q"></span>
### Log analysis

Cloud Search provides SQL analysis capabilities through plugins, enabling effective analysis of various log information generated during your use of different products, helping you quickly identify issues.

<span id=".5L-h5oGv5qOA57Si"></span>
### Information retrieval

Cloud Search offers RESTful APIs and clients for various languages, allowing you to find matching information within PB\-level data in milliseconds, facilitating efficient construction of search services.

<span id=".5pWw5o2u5Y-v6KeG5YyW"></span>
### Data visualization

Cloud Search integrates Kibana services, enabling you to build visual operation panels through Kibana dashboards and realize the construction of data visualization dashboards.

<span id="4adacc46"></span>
### Vector retrieval

Cloud Search supports k\-NN, offering vector search, vector storage, and embedding capabilities. Built on the Cloud Search cluster, the k\-NN vector database delivers large\-scale distributed capacity, providing users with scalable vector search. Additionally, Cloud Search supports "text + vector" hybrid search, better meeting search scenario requirements.
