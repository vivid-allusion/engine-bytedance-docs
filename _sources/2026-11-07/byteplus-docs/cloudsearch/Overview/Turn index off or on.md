The index is turned on by default after creation. If you do not use the index temporarily, you can turn it off and turn it back on when needed. This article explains how to turn the index off or on.

<span id="cr2idD4v"></span>
## Prerequisites


* Created an OpenSearch 2.9.0 or later version instance. For more information, see [Create an instance](https://docs.byteplus.com/en/docs/cloudsearch/creating-instance).

* Created AI search. For specific actions, see [Create AI Search](https://docs.byteplus.com/en/docs/cloudsearch/Create_an_AI_search_service).

* Created an index. For more information, see [Create an index](https://docs.byteplus.com/en/docs/cloudsearch/Create_index).


<span id="DIh47bfG"></span>
## Turn off index

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">After turning off the index, data will not be queryable; operate with caution.</div>



1. Log on to the[Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the target project and region.

3. Select **AI search** in the left navigation bar, then find and click the target service name.

4. In the left navigation bar, select **Index management**, then click **turn off** in the **actions** column of the target index.

5. In the popup dialog, click **OK**.


<span id="XEQKFx8C"></span>
## Turn on index


1. Log on to the[Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the target project and region.

3. Select **AI search** in the left navigation bar, then find and click the target service name.

4. Select **Index management** in the left navigation bar, then click **turn on** in the **Operation** column of the target index.

5. In the popup dialog, click **OK**.
