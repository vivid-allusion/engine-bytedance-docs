Once deletion protection is enabled for an instance, the instance cannot be deleted using the API or through the console. This feature prevents your instance from being accidentally deleted, thereby enhancing your instance and data security.

<span id="d563e4a9"></span>
## Enabling deletion protection

If you have enabled deletion protection during instance creation, ignore the following steps.


1. Log into the [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the Project and Region where the desired instance resides.

3. On the **Instances** page, click the name of the instance.

4. On the **Basic information** page, click **Enable** next to **Delete protection**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/47514e0222e14e108d633f1782692165~tplv-goo7wpa0wc-image.image) </span>

5. In the dialog box that appears, click **OK**.


<span id="7d09c784"></span>
## Disabling deletion protection

Instances with deletion protection enabled cannot be deleted. If you must delete an instance, disable deletion protection first.


1. Log into the [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the Project and Region where the desired instance resides.

3. On the **Instances** page, click the name of the instance.

4. On the **Basic information** page, click \*\*Disable \*\*next to **Delete protection**.
