If you forget or want to change the password for the admin user, reset the password in the Cloud Search console.

<span id="3fac1ea3"></span>
## Precautions

Resetting the password causes the instance to restart, and services to be temporarily unavailable. We recommend that you perform this operation during off\-peak hours.

<span id="d427ad4b"></span>
## Procedure


1. Log into the [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the Project and Region where the desired instance resides.

3. On the ** Instances** page, click the name of the instance.

4. In the **Service access** pane of the **Basic** **information** page, click **Reset** next to **Password**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bad346b36ee644c8857fd5d0214b556d~tplv-goo7wpa0wc-image.image) </span>

5. In the **Reset password** dialog box, type a new password, confirm the password, and then click **OK**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The new password must:   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Contain at least three of the following types of characters: uppercase letters, lowercase letters, digits, and special characters (such as <code>_#!@$%^&*()+=-</code>).   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Be between 8 to 32 characters in length.   </div>
