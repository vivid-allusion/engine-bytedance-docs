This topic describes how to modify the parameters of a Cloud Search instance.

<span id="046e95f3"></span>
## Precautions

Parameter modification results in instance restart and the modified parameters take effect afterwards. During the restart process, services may become temporarily unavailable. We recommend that you perform this operation during off\-peak hours.

<span id="48fc976e"></span>
## Procedure


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c11209b6da4c40859894dea23a18eaf7~tplv-goo7wpa0wc-image.image) </span>

3. On the instance list table of **Instances** page, click the desired Instance name and the instance details page is displayed.

4. Click **Instance management \> Parameter management** and all the system parameters are displayed.

5. On the upper\-left corner of **Parameter configuration** page, click **Modify parameters**, and the parameter values show in editing mode. Then, modify the parameter values, and click **Submit**.
