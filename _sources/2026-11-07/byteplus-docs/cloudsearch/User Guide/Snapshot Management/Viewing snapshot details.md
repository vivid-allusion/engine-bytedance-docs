After a snapshot is created, you can view the snapshot details, including the snapshot name, snapshot status, storage bucket, storage path, indexes contained in the snapshot, and the start and end time of the snapshot.

<span id="c248fd8e"></span>
## **Prerequisites**

Automatic creation of snapshots or manual creation of snapshots has been completed. For documentation, refer to [Creating snapshots automatically](https://docs.byteplus.com/docs/cloudsearch/36403) and [Creating a snapshot manually](https://docs.byteplus.com/docs/cloudsearch/36402).

<span id="5bf6e775"></span>
## **Viewing snapshot details**


1. Log on to the [Cloud Search console](https://console.volcengine.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

3. On the left navigation bar, select **Snapshot management**, filter the snapshot by snapshot name, instance name or instance ID, and then click the target snapshot name.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can also select <strong>Instance management \> Snapshot management</strong> in the left navigation bar of the instance details page.   </div>
   

4. Under the **Details** tab, you can view the snapshot details, including the snapshot name, snapshot status, storage bucket, storage path, indexes contained in the snapshot, and the start and end time of the snapshot.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e9df1d1bfe8248568b840242fa759afd~tplv-goo7wpa0wc-image.image" width="1464px" />   </div>
   

5. Under the **Recovery Information** tab, you can view the recovery history of the snapshot.
