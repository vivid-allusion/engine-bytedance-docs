---
title: "Canceling data refresh tasks"
product: "Cloud Search"
product_code: "cloudsearch"
source: "https://docs.byteplus.com/en/docs/cloudsearch/cancel-data-refresh"
---

Data refresh operation may impact instance stability, and is recommended to perform during off\-peak hours. In case the impact occurs, you can cancel the data refresh task in **Task Center** page.


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

3. On the left navigation bar, select **Task Center.** 

4. Find the desired task whose Task type is `Refresh Data`, and click **Cancel task** in the **Actions** column.

5. View the progress of task canceling. When the task status is changed from canceling to canceled, it means that the cancel operation is completed.
