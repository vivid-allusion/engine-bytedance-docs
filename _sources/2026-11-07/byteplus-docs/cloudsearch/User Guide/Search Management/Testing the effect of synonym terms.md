Cloud Search service provides analyzer/synonym test feature allowing you to test the effect of the configured synonym and analyzer terms. This topic describes the effect test process of synonym terms.

<span id="73bb50a9"></span>
## Prerequisites

Synonym terms are configured in advance. For more information, please see [Configuring synonym terms via GUI](https://docs.byteplus.com/docs/cloudsearch/configure-synonym-terms) or [Managing synonym files](https://docs.byteplus.com/docs/cloudsearch/uploading-synonym-files).

Here we take the following synonym term as an example:

## Procedure


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c11209b6da4c40859894dea23a18eaf7~tplv-goo7wpa0wc-image.image) </span>

3. On the **Instances** page, click the name of the desired instance.

4. On the left navigation bar of **Instance details** page, select **Search management \> Synonym management**, and click **Analyzer/synonym test** in the right side of the page.

5. In the displayed dialog box, enter the test word in the **Test statement** pane, and click **Test now**. Then view the testing result in the **Test Result** pane.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/662c1cd7bd964f15b4796207830fa26d~tplv-goo7wpa0wc-image.image) </span>
