After a snapshot is created, you can view detailed information about the snapshot, including the snapshot name, snapshot status, bucket, storage path, included indices, snapshot start time, and end time.

<span id="948eceb5"></span>
## Before you begin

Create a snapshot automatically or manually. For more information, refer to [Setting up automatic snapshots](https://docs.byteplus.com/en/docs/cloudsearch/automatic-snapshots) or [Setting up manual snapshots](https://docs.byteplus.com/en/docs/cloudsearch/manual-snapshots).

<span id="fa9c9aef"></span>
## Procedure


1. On the **Backup management** tab, click **Details** next to the snapshot that you want to view.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/076bb204321a4825b82716c8a9924142~tplv-goo7wpa0wc-image.image) </span>

2. On the **Backup information** tab, view detailed information about the snapshot, including the snapshot name, snapshot status, bucket, storage path, included indices, snapshot start time, and end time.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d2865dc6f83143258f57b6d8ebad3e0f~tplv-goo7wpa0wc-image.image) </span>

3. On the **Recovery information** tab, view restoration information about the snapshot, including the restoration status, instance where data is being restored, restoration progress, start time, and end time.
