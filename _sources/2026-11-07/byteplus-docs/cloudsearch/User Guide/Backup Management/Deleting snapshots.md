title: "Deleting snapshots"
product: "Cloud Search"
product_code: "cloudsearch"
source: "https://docs.byteplus.com/en/docs/cloudsearch/Deleting-snapshots"
---

An automatically created snapshot is automatically deleted after the specified retention period. We recommend that you do not delete it manually. However, you can manually delete a snapshot that was created manually when it is no longer needed.

A deleted snapshot cannot be restored. Exercise caution when you perform this operation.


1. In **Instance management \> Backup management**, select the snapshot that you want to delete, click **Delete** next to it.

2. In the dialog box that appears, confirm the operation, click **OK**.
