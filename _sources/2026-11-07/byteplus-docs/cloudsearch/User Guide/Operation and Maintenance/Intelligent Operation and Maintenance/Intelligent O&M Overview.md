BytePlus Cloud Search supports intelligent operation and maintenance (O&M) which provides health check capabilities in multiple dimensions including instances, nodes, indexes and so on. Intelligent O&M performs periodical or instant health diagnostics, and generates diagnostic reports automatically. The reports show the potential risks of instances, and help you grasp the latest status of instances.

<span id="a04ab9b8"></span>
## Features

Intelligent O&M offers the following capabilities:


* Enable or disable Intelligent O&M

   For more information, please see [Enabling Intelligent O&M feature](https://docs.byteplus.com/docs/undefined/66fa07043c09f003283d69f0) and [Disabling Intelligent O&M feature](https://docs.byteplus.com/docs/cloudsearch/32008).

* View instance health status

   The health overview shows the overall health status of a Cloud Search instance. For more information, please see [Viewing instance health overview](https://docs.byteplus.com/docs/cloudsearch/32012).

* Perform instance health diagnostics

   Scheduled and custom health diagnostics can be applied to a Cloud Search instance as needed, and diagnosis reports are generated afterwards. For more information, please see [Performing a diagnostic on an instance](https://docs.byteplus.com/docs/cloudsearch/32009).

* View diagnosis reports

   All diagnosis reports within 30 days can be viewed. A diagnostic report describes the diagnostic items, shows the diagnostic result, and provides suggestions. For more information, please see [Viewing diagnosis reports](https://docs.byteplus.com/docs/cloudsearch/32010).

* Specify the automatic diagnostic time

   The time to perform automated diagnostics can be modified based on the actual business scenarios. For more information, please see [Modifying the automatic diagnostic time](https://docs.byteplus.com/docs/cloudsearch/32011).
