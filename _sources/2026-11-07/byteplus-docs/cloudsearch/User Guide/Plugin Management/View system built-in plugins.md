Cloud Search offers more than 20 plugins, including open\-source and proprietary plugins, providing you with rich plugin features.

<span id="7fd1c62b"></span>
## View plugin list


1. Log on to the [Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the target project and region.

3. On the **Instances** page, click the target instance name.

4. In the left navigation bar, select **Instance management \> Plugin management**, and then click the **System built\-in plugin** tab.

5. View supported system default plugin information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can click the <strong>+</strong> icon to the left of the plugin name to see the version update details (e.g., version number, update description).   </div>
