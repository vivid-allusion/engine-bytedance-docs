Cloud Search console provides an instance architecture diagram visually illustrating the specification details and operating status of instance and nodes.

This topic describes how to view the instance architecture diagram in Cloud Search console.

<span id="86bba7e2"></span>
## Procedure


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c11209b6da4c40859894dea23a18eaf7~tplv-goo7wpa0wc-image.image) </span>

3. On the **Instances** page, click the name of the desired instance.

4. On the **Configuration diagram** pane of **Basic information** page, view the specification details and operating status of instance and nodes.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/af6213f9570c445eb1f9ab53f481b077~tplv-goo7wpa0wc-image.image) </span>

5. (Optional) Perform restart operation as needed.

   When hovering over the icon of the instance or a certain node, the status, specification details and the **Restart** operation button will be displayed. You can perform restart operation on a certain node or the whole instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Since restart operation may result in service interruption, it is recommended to perform restart operation during off\-peak hours.   </div>
