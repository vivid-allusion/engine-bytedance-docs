This topic describes how to export instance data. The exported data can be customized from two aspects, namely instance and field. You can choose to export the data of all instances, multiple instances or a certain instance. You can also specify which instance fields to be exported.

<span id="042f3728"></span>
## Procedure


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c11209b6da4c40859894dea23a18eaf7~tplv-goo7wpa0wc-image.image) </span>

3. On the upper\-right corner of **Instances** page, click the download icon.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e13ce46c365d40ddbc6df9807a35e625~tplv-goo7wpa0wc-image.image) </span>

4. In the dialog box of **Export instances**, configure the exporting parameters including instance scope and fields as needed, and then click **OK**.

   Three options of **Export scope** are available as listed below.

   * Export all data: all records on the instance list will be exported.

   * Export selected data: only the currently selected instances will be exported (this option is enabled when the check box of the instance is ticked).

   * Export current search results: only the instances matching the searching results will be exported (this option is enabled when you have searched for instances by instance name or ID).

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/565caf5076b148d29f215355a12861d9~tplv-goo7wpa0wc-image.image) </span>
