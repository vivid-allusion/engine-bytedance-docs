You can view detailed instance information in the console, including basic information, network information, instance access information, payment information, and configuration diagram. This article explains how to view instance details.

## Procedure

1. Log on to the [Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the target project and region.

3. On the **Instances** page, click the target instance name.

4. On the **Basic information** page, you can view the following information.

   |**Category** |**Description** |
   |---|---|
   |Basic information |* Instance name: displays the current instance's name. You can click the Modify or Copy button to change or duplicate the instance name.<br><br>* Version: displays the instance version.<br><br>* Instance ID: the unique identifier of the instance. You can click the Copy button to copy the ID information.<br><br>* Region: the region where the instance is located; this cannot be changed.<br><br>* Maintainable time: the time period during which the instance is allowed to undergo maintenance, defaulting to 02:00–06:00. You can change the maintainable time period according to your business needs; see [Modify maintainable time](https://docs.byteplus.com/en/docs/cloudsearch/maintenance-window).<br><br>* Availability zone: the availability zone where the instance is located. If the instance enables a dedicated master node, you can increase the quantity of availability zones. See [Add availability zone](https://docs.byteplus.com/docs/cloudsearch/add-availability-zone) for how to add an availability zone.<br><br>* Project: the cloud resource management project to which the instance belongs.<br><br>* Deletion protection: whether deletion protection is enabled for the instance. If deletion protection is enabled, the instance cannot be deleted. You can click the **Enable** or **Disable** button to modify the deletion protection status. See [Configure delete protection for an instance](https://docs.byteplus.com/en/docs/cloudsearch/deletion-protection).<br><br>* label: shows the current instance labels and supports editing. An instance supports configuring up to 20 labels.<br><br>* patch version: the instance's patch version. BytePlus Cloud Search periodically optimizes the kernel and performance. Manual update to the latest kernel version is recommended.<br><br>* Scenario: usage scenario of the instance.<br><br>* Instance architecture: displays the instance architecture. |
   |Network information |* Transport protocol: the transport protocol used by the instance, supporting protocol switching. For related documentation, see [Changing the transfer protocol of an instance](https://docs.byteplus.com/docs/cloudsearch/changing-transfer-protocol).<br><br>* Virtual Private Cloud: the virtual private cloud the instance belongs to.<br><br>* Subnet: the subnet to which the instance belongs. |
   |Instance access information |* Username: the username for logging in to the instance and visual tools, default is admin.<br><br>* Password: the user’s password. If you forget or need to change the password, you can reset it. For detailed steps, see [Reset password](https://docs.byteplus.com/docs/cloudsearch/resetting-password).<br><br>   > **warning**<br>   <br><br>   > Resetting the service access password will cause existing service connections to fail; proceed with caution.<br>   <br><br>* EIP line type: the EIP type specified when enabling public network access.<br><br>* Password\-free login: example status of password\-free login, off by default. You can click **Enable password\-free login**, check **Confirm to enable instance password\-free login** in the popup dialog, then click **OK** to enable password\-free login.<br><br>   > **warning**<br>   <br><br>   * > This is a high\-risk operation prone to network attacks or data loss; pay attention to network security management.<br>   <br><br>   * > Issues caused by data loss or leakage from using password\-free login are not covered by the SLA.<br>   <br><br>   * > After enabling password\-free login, if no account is entered, it defaults to an anonymous account, allowing access without a password.<br>   <br><br>   * > For security reasons, password\-free login and public network IP cannot be enabled simultaneously. Enabling password\-free login disables the instance’s public network IP feature.<br>   <br><br>   * > Password\-free login is currently unavailable to individual users. To use it, complete enterprise authentication.<br>   <br><br>* Private network address: the address used to access the instance within the VPC. By default, all devices within the same VPC can access the instance. You can also click **IP allowlist configuration** to set device IPs allowed to access the instance within the VPC. For detailed operations, see [Configure instance private network IP allowlist](https://docs.byteplus.com/en/docs/cloudsearch/IPallowlist-for-instance). If you need to access via dedicated line using the instance's private network address, click **Enable public network resolution**. For details, see [Configure instance private network address public network resolution](https://docs.byteplus.com/en/docs/cloudsearch/enabling-DNS).<br><br>* Public network access: when enabled, you can access the instance through the specified public network address. For specific operations, see [Configure instance public network access](https://docs.byteplus.com/en/docs/cloudsearch/enabling-public-access).<br><br>* Public service zone access address: the instance's public service zone access address.<br><br>* Public access address: the address used to access the instance via the public network. By default, all public network devices can access the instance. You can restrict access by configuring an IP allowlist. For detailed steps, refer to [Configure instance public network IP allowlist](https://docs.byteplus.com/docs/cloudsearch/public-IPallowlist-for-instance). |
   |Payment information |* Creation time: the time when the instance was created.<br><br>* Billing type: the billing method of the instance. |
   |Configuration diagram |The system provides an architecture diagram that visually displays the running status and specification information of instances and nodes. Hover over an instance or node to view its status and specifications, with support for the **restart** operation.<br><br>> **tip**<br><br><br>> During instance restart, some services will be unavailable. It is recommended to perform the restart during off\-peak hours.<br> |
