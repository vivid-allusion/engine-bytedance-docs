BytePlus Cloud Search service offers two types of instances based on different search engines, i.e. ElasticSearch (ES) instance and OpenSearch instance. This topic describes how to create a Cloud Search instance.

## Precautions

Before creating an instance, please pay attention to the following instructions:

* **1C4GiB nodes are prohibited in production environments**: small\-scale instances are particularly prone to CPU overload or out of memory (OOM), and normally used in testing environments only.

* **Single\-node instances are prohibited in production environments**: single\-node instances are also suitable for testing environments only. When coming to production phase, it is recommended to upgrade the number of nodes to 3 or more. For more information, please see [Upgrading Instance Specifications](https://docs.byteplus.com/en/docs/cloudsearch/upgrading).

* **Two\-node instances are prohibited**: two\-node instances have potential risk of split\-brain so that the service provisioning of such instances is also prohibited.

The above listed are the precautions closely related to instance creation. For more information, please see [Before Use](https://docs.byteplus.com/en/docs/cloudsearch/Before-Use).

## Prerequisites

* You have a BytePlus account qualified with real\-name authentication.

* Your BytePlus account is assigned with cross\-service authorization for Cloud Search service to access other BytePlus product resources. For information about how to authorize access across services, please see [Cross-service Authorization](https://docs.byteplus.com/en/docs/cloudsearch/cross-service-authorization).

## Procedure

1. Log on to the [Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the project and region where you want to create an instance.

3. On the **Instances** page, click **Create instance**.

4. On the **Create instance** page, configure the parameters as listed below, and then click **Confirm order**.

5. On the **Confirm order** page, check the configuration details, read and confirm the terms of service, and then click **Buy now**.

6. On the **Submit payment** page, check the payment details including product, configuration, payment method (postpaid for pay\-as\-you\-go, and prepaid for subscription), etc., and then click **Next step** to submit and pay for the order.

   After the payment is successful, click **Go to product console**. On the **Instances** page, you can view the newly created instance with the running state showing creating. It may take a few minutes to complete the creation process. When the state is changed to **Running**, the instance is successfully created.
