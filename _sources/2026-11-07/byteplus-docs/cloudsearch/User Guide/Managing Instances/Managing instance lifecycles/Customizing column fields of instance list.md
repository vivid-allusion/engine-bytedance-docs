This topic describes how to customize the column fields of the instance list in order to display the key information according to your concerns.

<span id="047bef20"></span>
## Procedure


1. Log into [BytePlus Cloud Search console](https://console.byteplus.com/es).

2. In the top menu bar, select the **Project** and **Region** where the desired instance resides.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c11209b6da4c40859894dea23a18eaf7~tplv-goo7wpa0wc-image.image) </span>

3. On the upper\-right corner of **Instances** page, click the setting icon.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/08cc414daa8241968cde4013bb443506~tplv-goo7wpa0wc-image.image) </span>

4. On the dropdown list, select the desired column fields that you want to display in the instance list.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ae70c5bf766c4ab7ada39bf400fa2d00~tplv-goo7wpa0wc-image.image) </span>
