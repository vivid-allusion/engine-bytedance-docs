After creating a custom model, you can view the created custom model. This topic describes how to view a custom model.

<span id="Ya0XxQYG"></span>
## Prerequisites

A custom model is created. For specific actions, see [Create a custom model](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_custom_model).

<span id="vrMcOWm4"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. In the left navigation pane, select **ContextSearch \> Model and reasoning \> Model management**, click the **Custom model** tab, then click the target model.

4. In the model details panel, select the **Model properties** or **Performance index** tab to view model information.
