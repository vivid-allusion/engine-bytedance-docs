You can delete the model when your custom model is no longer needed. This topic describes how to delete a custom model.

<span id="AgDG88sE"></span>
## Prerequisites

Created custom model. For details, see [Create a custom model](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_custom_model).

<span id="crXQfS0K"></span>
## Notice


* You cannot delete a model if it has associated inference services. To delete, you must first delete the associated inference services. For details, see [Delete a custom inference service](https://docs.byteplus.com/en/docs/cloudsearch/Delete_a_custom_inference_service).

* custom model deletion cannot be recovered. Proceed with caution.


<span id="crXQfS0K"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. In the left navigation bar, select **ContextSearch \> Model and reasoning \> Model management**, click the **Custom model** tab, then click **Delete** in the **Operation** column of the target model.

4. In the popup dialog, click **OK**.
