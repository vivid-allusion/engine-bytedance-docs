In ContextSearch, the system provides preset common models, including various types such as Embedding, Rerank, and LLM, for example, the Doubao 1.6 model. You can directly associate common models when you create inference services. This topic describes how to view common models.

<span id="88UTAN7h"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Model and reasoning \> Model management** in the left navigation bar, then click the target model under the **Public models** tab.

4. In the model details panel, select the **Model properties** or **Performance index** tab to view model information.
