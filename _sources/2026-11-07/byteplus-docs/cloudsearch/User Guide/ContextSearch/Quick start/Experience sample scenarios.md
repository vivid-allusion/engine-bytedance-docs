ContextSearch provides three preset example scenarios: **enterprise knowledge intelligent search**, **e\-commerce picture search**, and **intelligent video search**. You can experience the usage process and retrieval effect without adding data or any configuration. This topic describes how to experience the sample scenarios.

<span id="iMACbwoR"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Home** in the left navigation bar.

4. In the **Scene Experience** area, click **Experience now** on the target sample scenario card.

5. In the **Conversational Q&A** area, enter text and upload pictures to experience the search effect.
