ContextSearch supports quick search based on created scenes, covering different scenarios such as knowledge base, picture search, and video search. This topic describes how to perform a quick search.

<span id="vty7ntWa"></span>
## Prerequisites

Scenes are created, configured, and started. For specific actions, refer to [Quickly create and use scenarios](https://docs.byteplus.com/en/docs/cloudsearch/Quickly_create_and_use_scenarios) and [Manage scenario development](https://docs.byteplus.com/en/docs/cloudsearch/Manage_scenario_development).

<span id="A9B7GoUZ"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Home** in the left navigation bar.

4. Enter  **@**  in the text box, select the scene to search from the dropdown list, enter your question or request, then click the send icon.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">ContextSearch offers search options for different types of scenes:   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Knowledge base: You can choose <strong>quick</strong>, <strong>standard</strong>, or <strong>depth</strong> mode.   </div>
   

      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Quick: Completes retrieval faster, suitable for lightweight tasks focused on efficiency.   </div>
   

      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Standard: Balances speed and quality for most everyday needs.   </div>
   

      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Deep: Provides more comprehensive and detailed deep reasoning, a high\-precision mode designed for demanding scenarios.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Picture search, video search: Click <strong>Upload image</strong> to search or ask questions based on the image.   </div>
