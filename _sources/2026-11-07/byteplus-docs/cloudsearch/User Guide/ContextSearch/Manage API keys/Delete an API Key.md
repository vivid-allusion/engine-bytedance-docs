You can delete an API Key promptly when it is no longer needed to avoid security risks. This topic describes how to delete an API Key.

<span id="jJBCLcRE"></span>
## Notice

After deleting an API Key, you cannot continue to use it to call the inference service, nor can it be recovered. Proceed with caution.

<span id="AYXCONON"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> API Key** in the left navigation bar, then click **Delete** in the Actions column for the target API Key.

4. In the pop\-up dialog, confirm the Name of the API Key to delete, then click **Delete**.
