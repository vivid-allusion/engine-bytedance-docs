After creating an API Key, you can view the created API Key. This topic describes how to view an API Key.

<span id="uSdaSGjp"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> API Key** in the left navigation bar, then view the target API Key. You can click the icon on the right side of the API Key to show or hide the API Key. After displaying the API Key, you can copy the API Key for service calls.
