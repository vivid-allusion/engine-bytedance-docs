In ContextSearch, the API Key is your essential credential for using the inference service. You must create an API Key before calling the model. This topic describes how to create an API Key.

<span id="MI8hD8AY"></span>
## Notice


* The API Key is valid for a long time. Do not share the key information publicly. Keep it secure and rotate keys regularly to avoid security risks from unauthorized use.

* A single project supports up to 5 API Keys.


<span id="tq8CXwAf"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. In the left navigation bar, select **ContextSearch \> API Key**, then click **Create API Key**.

4. Configure the following parameters, then click **OK**.

   
   |**Parameter** |**Description** |
   |---|---|
   |Affiliated project |Project to which the API Key belongs. You cannot switch when creating the API Key; to switch, close the dialog and modify it from the top navigation bar. |
   |Name |Set the name of the API Key. Naming rules are as follows:<br><br><br>* Must start with a letter.<br><br>* Can only contain letters, digits, hyphens (\-), and underscores (_).<br><br>* Length must be between 2 and 32 characters. |
