You can stop a custom inference service when you temporarily do not need it. This topic describes how to stop a custom inference service.

<span id="w9JmVMHT"></span>
## Notice

After stopping the custom inference service, it cannot be called anymore. Please operate carefully. If you need to continue using it, you can restart it. For specific operations, see [start custom inference service](https://docs.byteplus.com/en/docs/cloudsearch/Start_custom_inference_service).

<span id="s9YxNcqu"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Model and reasoning \> Inference service** in the left navigation bar, click the **Custom Inference Service** tab, then click **Stop** in the **Actions** column of the target inference service.

4. In the popup dialog, click **OK**.
