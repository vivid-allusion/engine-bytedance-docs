ContextSearch supports calling the inference service via API and provides call examples. This article introduces how to call the inference service.

<span id="s1eXZWr4"></span>
## Notice

Inference services associated with some models do not support call examples.

<span id="s1eXZWr4"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. In the left navigation pane, select **ContextSearch \> Model and reasoning \> Inference service**, click the **Pre\-built inference service** or **Custom inference service** tab, then click **API call** in the **Operation** column of the target inference service.

4. In the inference service details panel, under the **API example** tab, view the example code. For more information, see the [View inference service](https://docs.byteplus.com/en/docs/cloudsearch/View_an_inference_service) tab for **API example**.
