After creating a custom inference service, you can edit its configuration information. If the custom inference service is running, the modified configure parameters take effect immediately. This topic describes how to edit a custom inference service.

<span id="nwVbcBZB"></span>
## Prerequisites

Inference service created. For specific actions, refer to [Create a custom inference service](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_custom_inference_service).

<span id="nwVbcBZB"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Models and reasoning \> Inference service** in the left navigation bar, click the **Custom inference sService** tab, then choose  **... \> Edit** in the **Operation** column of the target inference service.

4. Modify the configuration information of the inference service in the **Edit inference service** panel, then click **Save**

   For details on configuring parameters for inference services, see [Create a custom inference service](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_custom_inference_service).
