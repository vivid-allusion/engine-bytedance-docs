When you no longer need a custom inference service, you can delete it to save resources. This topic describes how to delete a custom inference service.

<span id="SuZsqSbm"></span>
## Notice

Deleting a custom inference service is irreversible; proceed with caution.

<span id="7qLVqtzx"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. Select **ContextSearch \> Model and reasoning \> Inference service** in the left navigation bar, click the **Custom Inference Service** tab, then choose  **... \> Delete** in the **Actions** column of the target inference service.

4. In the popup dialog, click **OK**.
