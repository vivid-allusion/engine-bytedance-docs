After creating a custom inference service, you need to start it before use. This article explains how to start a custom inference service.

<span id="HteGbcLb"></span>
## Prerequisites

A custom inference service has been created, and its status is **Stopped**. For specific steps, refer to [Create a custom inference service](https://docs.byteplus.com/en/docs/cloudsearch/Create_a_custom_inference_service).

<span id="m18lMNlv"></span>
## Procedure


1. Log in to the [Cloud Search console](https://console.byteplus.com/es).

2. On the top navigation bar, select the target project and region.

3. In the left navigation bar, select **ContextSearch \> Model and reasoning \> Inference service**. Click the **Custom inference service** tab, then click **Start** in the **Operation** column of the target inference service.

4. In the popup dialog, click **OK**.
