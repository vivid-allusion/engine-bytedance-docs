ContextSearch provides a complete method for scene building, including data preprocessing, retrieval service, and Q&A summary generation. You can quickly build knowledge base, picture search, and video search applications through simple configuration. This topic describes how to create a scenario.

<span id="EgyXJqYl"></span>
## Procedure


1. Log on to the[Cloud Search console](https://console.byteplus.com/es).

2. In the top navigation bar, select the target project and region.

3. Select **ContextSearch \> My Scene** in the left navigation bar, then click **Create scene**.

4. In the **Create scene** panel, configure the following parameters, then click **Create**.

   
   |**Parameter** |**Description** |
   |---|---|
   |Select type |Select the type of the scene. Currently supports **Knowledge Base**, **Picture search**, and **Video search**. |
   |Name |Set the name of the scene. Naming rules are as follows:<br><br><br>* Cannot start with a number or a hyphen (\-).<br><br>* Length must be between 1 and 128 characters.<br><br>* Contain letters, digits, underscores (_), and hyphens (\-). |
   |Description (optional) |Description of the scene setup. Length must not exceed 255 characters. |
   |Affiliated project |Project the scene belongs to. You cannot switch when creating a scene. To switch, close the dialog and modify it from the top navigation bar. |
   |Tag (optional) |Add tags to the scene to identify and manage it more easily. You can click **Add row** multiple times to add several tags. |
