This topic describes how to download and install the Cloud Search Go SDK.

<span id="LwGM49QB"></span>
## **Prerequisites**

Go 1.14 or later is required, and Go 1.12 or later is recommended.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can run the <code>go version</code> command to check your current Go version.</div>


<span id="urEZzI98"></span>
## **SDK download address**

For the source code of the SQL Server Go SDK, see [Cloud Search Go SDK](https://github.com/byteplus-sdk/byteplus-go-sdk-v2/tree/main/service/escloud).

<span id="vmcgiKTv"></span>
## **Install the SDK**

In your target Go project, run the following command to install the Go SDK.

```Go
go get github.com/byteplus/byteplus-go-sdk-v2/byteplus/credentials
go get github.com/byteplus/byteplus-go-sdk-v2/byteplus/byteplusutil
```
