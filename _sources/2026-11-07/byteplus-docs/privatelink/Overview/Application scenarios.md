## Secure cross\-VPC access

The service provider's VPC only grants the service consumer access to specified services, which avoids data transmission over the internet while strictly limiting the access scope, effectively reducing network security risks.

## Accessing cloud services from a data center

Furthermore, when integrated with a VPN connection, Cloud Enterprise Network (CEN), or Direct Connect, PrivateLink can enable on\-premises data centers to access service resources hosted within endpoint services on the cloud.
