## Secure and controllable

PrivateLink enables one\-way access between different Virtual Private Clouds ** (** VPCs) via private networks, eliminating potential risks associated with internet exposure. It also supports granular access control at the level of source IP ranges, individual users, or single connections, making cross\-VPC access management both secure and flexible.

<span id=".5oCn6IO95LyY6LaK"></span>
## Superior performance

By forwarding traffic within the same Availability Zone, PrivateLink achieves the lowest possible network latency.

<span id=".6YWN572u566A5Y2V"></span>
## Simple configuration

It provides flexible cross\-account and cross\-VPC access configuration without complex routing setups. Multiple endpoints can share the same endpoint service, simplifying maintenance for the service provider when serving multiple consumers.

<span id=".5a6e5pe255uR5o6n"></span>
## Real\-time monitoring

Integrated with CloudMonitor services, PrivateLink enables real\-time tracking of key metrics for both endpoint services and endpoints. Through customizable metric thresholds and alert notifications, anomalies are detected promptly to ensure stable business operations.
