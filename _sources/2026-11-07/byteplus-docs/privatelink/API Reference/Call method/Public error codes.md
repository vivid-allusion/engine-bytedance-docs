This topic introduces the public error codes that may be returned when you call the PrivateLink API. For more information on platform\-specific error codes, refer to [Public error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).


|HTTP Status Code |Error Code |Error Message |Description |
|---|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported, or cannot be used. |The request contains an invalid or unsupported parameter value. |
|400 |MissingParameter |The request is missing a required parameter. |The request is missing required parameters. Ensure that all required parameters are specified when making the request. |
|500 |InternalError |An internal error has occurred. |An internal error has occurred. |
