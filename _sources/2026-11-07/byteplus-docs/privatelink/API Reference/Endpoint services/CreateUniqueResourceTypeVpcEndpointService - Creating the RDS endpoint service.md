Call the CreateUniqueResourceTypeVpcEndpointService API to create an endpoint service associated with an RDS type service resource.

> Notes

> Support for RDS\-type service resources is currently in beta stage. If you need to use it, contact your account manager.

[去调试](https://api.byteplus.com/api-explorer/debug?action=CreateUniqueResourceTypeVpcEndpointService&serviceCode=privatelink&version=2020-04-01&groupName=)

## Request parameters

**Action ** String必选 `Example: CreateUniqueResourceTypeVpcEndpointService`

Action to execute. Set the value to **CreateUniqueResourceTypeVpcEndpointService**.

**Version ** String必选 `Example: 2020-04-01`

API version. The current version is **2020\-04\-01**.

**IpAddressVersions.N ** String`optional` `Example: ipv4`

IP protocol type of the endpoint service.

* IPv4 (default)

* IPv6: This value is currently in beta stage. For trial requests, contact your account manager.

> **tip**

* > When only **ipv4** is specified, it indicates that the endpoint service is the IPv4 type and only provides IPv4 services.

* > When both **ipv4** and **ipv6** are specified, it indicates that the endpoint service is a dual\-stack type, supporting both IPv4 and IPv6 services. The system will automatically assign an IPv6 address to it.

   > If you need to specify **IPv6**, ensure the following conditions are met:

   * > The IPv6 functionality for the PrivateLink service has been activated.

   * > The specified service resource supports dual\-stack.

* > Currently, specifying only **IPv6** is not supported.

**ServiceResourceType ** String`optional` `Example: RDSMySQL`

Service resource type. Valid values:

* RDSMySQL: Cloud Database MySQL Edition.

**Resource.InstanceId ** String`optional` `Example: mysql-bp1o94dp5i6ea****`

The ID of the RDS instance to which the RDS type service resource to be added to the endpoint service belongs. You can call the [DescribeDBInstances](https://docs.byteplus.com/en/docs/RDS_for_MySQL/describedbinstances) API to view the RDS instance ID.

**Resource.ResourceId ** String必选 `Example: mysql-bp1o94dp5i6ea****-cluster-qhwjs67hbmsj****`

The ID of the RDS type service resource to be added to the endpoint service. You can call the [DescribeDBInstanceDetail](https://docs.byteplus.com/en/docs/RDS_for_MySQL/describedbinstancedetail) API to obtain the ID of the RDS instance connection endpoint.

**AutoAcceptEnabled ** Boolean`optional` `Example: false`

Auto\-accept endpoint connection. Valid values:

* True: The endpoint service automatically accepts endpoint connection requests.

* False (default): The endpoint service does not automatically accept endpoint connections; you need to manually accept them by calling the [EnableVpcEndpointConnection](https://docs.byteplus.com/en/docs/privatelink/EnableVpcEndpointConnection) API.

**ZoneIds.N ** String必选 `Example: cn-guangzhou-a`

The availability zone IDs supported by the endpoint service.

* Parameter \- N: Indicates the serial number of the Availability Zone, ranging from 1 to 20.

* Separate multiple availability zones with ampersands ( & ).

**ClientToken ** String `optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.

* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, idempotency check is not performed.

**Description ** String`optional` `Example: EndpointService`

The description of the endpoint service, with the default value being an empty string.

* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), full\-width commas ( ， ), and full\-width periods ( 。 ).

* The length limit is 0 to 255 characters.

**ProjectName ** String `optional` `Example: default`

The name of the project to which the endpoint service belongs.

**Tags.N.Key ** String `optional` `Example: k1`

The tag key for the endpoint service user.

* Must be 1 to 128 characters.

* Case\-sensitive. Must not start with `volc:` or `sys:` in any case form.

* Must not start or end with a space.

* May include letters, numbers, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), and at signs (@).

> **tip**

> Duplicate tag keys are not allowed for the same resource.

**Tags.N.Value ** String`optional` `Example value: v1`

The tag value for the endpoint service user.

* Must be 0 to 255 characters.

* Case\-sensitive. Must not start or end with a space.

* May include letters, numbers, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).

> **tip**

> To provide this parameter, provide `Tags.N.Key` first.
