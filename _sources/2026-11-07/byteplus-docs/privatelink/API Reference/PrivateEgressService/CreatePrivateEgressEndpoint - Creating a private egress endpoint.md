Call the CreatePrivateEgressEndpoint API to create a private egress endpoint in the Virtual Private Cloud (VPC) of your enterprise service. This endpoint is used by Claw instances to access your enterprise service over the private network.

<span id=".5L2_55So6K-05piO"></span>
## Instructions


* When creating an endpoint in the VPC hosting enterprise services, the system creates elastic network interfaces in one or more specified subnets. Each network interface occupies 6 private IP addresses from its subnet.

* After creating the private endpoint, call the [ModifyPrivateEgressEndpoint](https://docs.byteplus.com/en/docs/privatelink/ModifyPrivateEgressEndpoint) API to enable private access for the endpoint and specify the accessible CIDR blocks.

* Each private network egress can have only one endpoint.​

## Request parameters



**Action ** <span data-label="purple"> String  </span><span data-api-tag="require|oppOzH">必选</span> `Example: CreatePrivateEgressEndpoint`

The action to perform. Value: **CreatePrivateEgressEndpoint**.



**Version ** <span data-label="purple"> String  </span><span data-api-tag="require|4rfFs3">必选</span> `Example: 2020-04-01`

The API version. The current version is **2020\-04\-01**.



**PrivateEgressId ** <span data-label="purple"> String  </span><span data-api-tag="require|qMnAUL">必选</span> `Example: pre-p6q7r8s9t0****`

The ID of the private network egress.



**VpcId ** <span data-label="purple"> String </span><span data-api-tag="require|ZcGKln">必选</span> `Example: vpc-bp1b1llp3ve5yze****`

The ID of the VPC to which your enterprise service belongs.

You can call the [DescribeVpcs](https://docs.byteplus.com/en/docs/vpc/DescribeVpcs) API to obtain the VPC ID.



**ZoneMappings.N.ZoneId ** <span data-label="purple"> String </span><span data-api-tag="require|2gLipf">必选</span> `Example: cn-beijing-a`

The subnet availability zone of the VPC to which your enterprise service belongs.


* N represents the sequence number of an availability zone. Valid values: 1\-2.

* Separate multiple availability zone IDs with ampersands (&).

* You can see [Regions and Availability Zones](https://docs.byteplus.com/en/docs/vpc/Regions-and-Availability-Zones) to obtain the availability zone ID.



**ZoneMappings.N.SubnetId ** <span data-label="purple"> String </span><span data-api-tag="require|XzkScV">必选</span> `Example: subnet-bp1nhbnpv2blyz8dl****`

The subnet ID within the VPC to which your enterprise service belongs.


* N represents the sequence number of a subnet. Valid values: 1\-2.

* The subnet corresponds to the availability zone specified in ZoneMappings.N.ZoneId.

* An network interface is created in each subnet. It occupies 6 private IP addresses per subnet.

* You can call the [DescribeSubnets](https://docs.byteplus.com/en/docs/vpc/DescribeSubnets) API to obtain the subnet ID.



**DestinationCidrs ** <span data-label="purple"> String  </span><span data-api-tag="require|4OgHE8">必选</span> `Example: 192.168.0.0/16`

The CIDR block where the enterprise service is located.



**SecurityGroupIds ** <span data-label="purple"> String </span>`optional` `Example: ["sg-bp1fg655nh68xyz9****"]`

The security group associated with the endpoint's network interface.



**ClientToken ** <span data-label="purple"> String </span>`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

A client token used to ensure idempotency of requests.​


* This value is auto\-generated by the client, and must be unique across different requests. This prevents duplicate actions caused by client retries when an API call times out or encounters a server\-side error.

* Must not exceed 64 ASCII characters.

* If you do not provide ClientToken, this API call does not verify idempotency.
