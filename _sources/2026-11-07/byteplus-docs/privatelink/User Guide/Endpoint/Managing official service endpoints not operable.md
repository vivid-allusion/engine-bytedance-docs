## Introduction

The BytePlus official service endpoint not operable is an interface endpoint created by [BytePlus official service](https://docs.byteplus.com/en/docs/privatelink/Overview-endpoint-services), providing an entrance for the service consumer's VPC to access this BytePlus official service.

<span id="operation-limits"></span>
## Operation Limits

The BytePlus official service endpoints not operable are created by BytePlus official services and belong to the service consumer's account. The service provider and the service consumer have different permission for management actions on this BytePlus official service endpoint not operable, as shown in the following table.


|Operation of console |Supported |
|---|---|
|Creating a BytePlus official service endpoint not operable | **×**  |
|Managing associated security groups | **×**  |
|Modifying the name or description | **×**  |
|Modifying the private DNS name | **×**  |
|Modifying Availability Zones | **×**  |
|Modifying the IP address type | **×**  |
|Modifying the project | **×**  |
|Deleting a BytePlus official service endpoint not operable | **×**  |
|Modifying the tag |✓ |
