After an endpoint service is created, you can enable/disable automatic connection acceptance as needed.

<span id="enabling-automatic-connection-acceptance"></span>
## Enabling automatic connection acceptance


1. Log on to [Endpoint Service console](https://console.byteplus.com/pl/endpointServices) using the BytePlus account of the service provider.

2. In the top menu bar, select the target project and Region.

3. Click the ID of the target endpoint service.

4. In **Service information**, enable the **Auto accept connection** switch.

5. Click **OK**.


<span id="disabling-automatic-connection-acceptance"></span>
## Disabling automatic connection acceptance


1. Log on to [Endpoint Service console](https://console.byteplus.com/pl/endpointServices) using the BytePlus account of the service provider.

2. In the top menu bar, select the target project and Region.

3. Click the ID of the target endpoint service.

4. In **Service information**, disable the **Auto accept connection** switch.

5. Confirm the information and click **OK**.
