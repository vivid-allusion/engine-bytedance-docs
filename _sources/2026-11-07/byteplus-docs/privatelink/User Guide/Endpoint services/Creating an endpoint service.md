## Action notes

The maximum number of endpoint services a single account can create is 100. If the default quota cannot meet your needs, go to [Quota Center](https://console.byteplus.com/quota/productList) to increase the corresponding quota.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* Ensure you have created the service provider's VPC and its subnets. For the operation, see [Creating a VPC](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC).

* Ensure you have configured a Classic Load Balancer (CLB) as the service resource. For the operation, see [Quickly setting up a Classic Load Balancer](https://docs.byteplus.com/en/docs/clb/Getting-Started).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Use the service provider's account to log in to the [Endpoint Service console](https://console.byteplus.com/pl/endpointServices).

2. Accounts that have not completed cross\-service role authorization must follow the steps below to grant the required role.

   1. On the **Cross\-service access request** page, click **Authorize**.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">The authorized role will be displayed in the role list of the Identity and Access Management (IAM) platform. Deleting the authorized role may cause cross\-service access failures. Proceed with caution.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">If the authorization role is deleted and you need to continue using the PrivateLink service, you must re\-authorize the role.      </div>
      

   1. In the left\-side navigation pane, click **Endpoint Service** again.

3. In the top menu bar, select the target project and region.

4. Click **Create Endpoint Service** and configure the basic information of the endpoint service according to the table below.

5. Click **Clone** to complete the action.

## What to do next

After the endpoint service is successfully created, you still need to attach an endpoint to this endpoint service. For detailed actions, see [Creating an endpoint](https://docs.byteplus.com/en/docs/privatelink/Endpoint-02).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If the endpoint service has enabled a private DNS name, see <a href="https://docs.byteplus.com/en/docs/privatelink/Modifying-Verifying-private-DNS-names">Verifying the private DNS name</a> to complete the private DNS name ownership verification. Otherwise, the endpoint cannot enable the private DNS name.</div>
