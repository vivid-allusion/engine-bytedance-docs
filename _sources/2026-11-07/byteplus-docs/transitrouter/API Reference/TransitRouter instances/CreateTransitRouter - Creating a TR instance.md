Call CreateTransitRouter to create a Transit Router (TR) instance.

<span id=".5L2_55So6K-05piO"></span>
## Instructions

In a request parameter such as Tags.N.a, the "N" represents the sequence number of a tag entry. It must be assigned a value in strict numerical order, starting from 1 up to 50. Separate multiple tags with ampersands (&).

## Request parameters

The following only details request parameters specific to this API and key common parameters. For more information, see [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">String </span><span data-api-tag="require|B3043S">必选</span> `Example: CreateTransitRouter`

The interface name. The current API name is `CreateTransitRouter`.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|ReKHiO">必选</span> `Example: 2020-04-01`

The interface version. The current API version is `2020-04-01`.



**TransitRouterName ** <span data-label="purple">String </span>`optional` `Example: transitrouter-01`

The name of the TR instance.


* Must start with a letter, digit, or Chinese character. May include letters, digits, Chinese characters, and the following symbols: periods (.), underscores (_), and hyphens (\-).

* Must be 1 to 128 characters in length.

* If you do not provide this parameter or leave it unset, it defaults to the TR instance ID.



**Asn ** <span data-label="purple">Integer </span>`optional` `Example: 64512`

The TR ASN. Valid ranges: 64512 to 65534 and 4200000000 to 4294967294. Default: 64512.



**Tags.N.Key ** <span data-label="purple">String </span>`optional` `Example: k1`

The custom tag key of the TR instance.


* Must be 1 to 128 characters.

* Case\-sensitive. Must not start with `volc:` or `sys:` in any case combination.

* Must not start or end with a space.

* May include letters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Duplicate tag keys are not allowed for the same resource.</div>


* <div data-tips="true" data-tips-type="tip">If you do not provide this parameter or leave it unset, it defaults to empty.</div>




**Tags.N.Value ** <span data-label="purple">String </span>`optional` `Example: v1`

The custom tag value of the TR instance.


* Must be 0 to 255 characters.

* Case\-sensitive. Must not start or end with a space.

* May include letters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">To provide this parameter, provide <code>Tags.N.Key</code> first.</div>




**MulticastEnabled ** <span data-label="purple">Boolean </span>`optional` `Example: false`

Specify whether to enable multicast for the TR.


* true: Enable

* false (default): Disable



**Description ** <span data-label="purple">String </span>`optional` `Example: This transit router is used for test.`

The description of the TR instance.


* Must start with a letter, digit, or Chinese character. May include letters, digits, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), Chinese commas ( ， ), and Chinese periods ( 。 ).

* Must be 0 to 255 characters.

* If you do not provide this parameter or leave it unset, it defaults to an empty string.



**ProjectName ** <span data-label="purple">String </span>`optional` `Example: default`

The name of the project to which the TR instance belongs.

If you do not provide this parameter or leave it unset, it defaults to "default".



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, idempotency check is not performed.
