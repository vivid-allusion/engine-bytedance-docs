Call the CreateTransitRouterTrafficQosQueueEntry API to add queues to a traffic queue policy.

<span id=".5L2_55So6K-05piO"></span>
## Instructions

A traffic queue policy consists of 1 default queue and additionally supports up to 64 custom queues.​

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

​​If the allocated bandwidth is insufficient for actual business requirements after adding a queue, normal service forwarding may be impacted.​

## Request parameters

The following only details request parameters specific to this API and key common parameters. For more information, see [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">String </span><span data-api-tag="require|865G93">必选</span> `Example: CreateTransitRouterTrafficQosQueueEntry`

The interface name. The current API name is `CreateTransitRouterTrafficQosQueueEntry`.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|urJmpC">必选</span> `Example: 2020-04-01`

The interface version. The current API version is `2020-04-01`.



**TransitRouterTrafficQosQueuePolicyId ** <span data-label="purple">String </span><span data-api-tag="require|r85jgd">必选</span> `Example: tr-tqp-hy13n2l4c6c0v****`

ID of the traffic queue policy. You can call the [DescribeTransitRouterTrafficQosQueuePolicies](https://docs.byteplus.com/en/docs/transitrouter/DescribeTransitRouterTrafficQosQueuePolicies) API to obtain the traffic queue policy ID.



**Dscps.N ** <span data-label="purple">Integer </span><span data-api-tag="require|4ysET0">必选</span> `Example: 1`

​​The DSCP value that the queue should match.​ Value range: 0\-63.


* N represents the serial number of the DSCP value, ranging from 1 to 64.

* Separate multiple DSCP values with ampersands (&).



**BandwidthPercent ** <span data-label="purple">Integer </span>`optional` `Example: 10`

The percentage of cross\-region bandwidth available for the queue. Value range: 0\-100.

If the value is 0, traffic that successfully matches the queue will be discarded.



**TransitRouterTrafficQosQueueEntryName ** <span data-label="purple">String </span><span data-api-tag="require|eryF4C">必选</span> `Example: tqe-02`

The queue name.


* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: periods (.), underscores (_), and hyphens (\-).

* Must be 1 to 128 characters.

* If you do not provide this parameter or leave it unset, it defaults to empty.



**Description ** <span data-label="purple">String </span>`optional` `Example: This traffic qos queue entry is used for test.`

The description of the queue.


* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), Chinese commas ( ， ), and Chinese periods ( 。 ).

* Must be 0 to 255 characters.

* If you do not provide this parameter or leave it unset, it defaults to an empty string.



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, the idempotency check is not performed.



**Priority ** <span data-label="purple">String </span>`optional` `Example: High`

The priority of the traffic queue.


* `Normal`: Normal priority.

* `High`: High priority.
