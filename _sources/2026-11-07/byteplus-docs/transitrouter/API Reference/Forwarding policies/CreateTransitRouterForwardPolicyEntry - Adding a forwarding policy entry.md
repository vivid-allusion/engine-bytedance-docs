Call the CreateTransitRouterForwardPolicyEntry API to add a policy entry to the specified forwarding policy.

## Request parameters

The following only details request parameters specific to this API and key common parameters. For more information, see [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action** <span data-label="purple"> String </span> <span data-api-tag="require|QepL37">必选</span> `Example: CreateTransitRouterForwardPolicyEntry`

The interface name. The current API name is `CreateTransitRouterForwardPolicyEntry`.



**Version** <span data-label="purple"> String </span> <span data-api-tag="require|TnNydM">必选</span> `Example: 2020-04-01`

The interface version. The current API version is `2020-04-01`.



**TransitRouterForwardPolicyTableId** <span data-label="purple"> String </span> <span data-api-tag="require|MS_8I7">必选</span> `Example: tr-fpt-hy13n2l4c6c0v****`

The ID of the forwarding policy. You can call the [DescribeTransitRouterForwardPolicyTables](https://docs.byteplus.com/en/docs/transitrouter/DescribeTransitRouterForwardPolicyTables) API to get the forwarding policy ID.



**TransitRouterRouteTableId** <span data-label="purple"> String </span> <span data-api-tag="require|3vmIoy">必选</span> `Example: tr-rtb-hy13n2l4c6c0v****`

The ID of the route table associated with the TR instance. You can call [DescribeTransitRouterRouteTables](https://docs.byteplus.com/en/docs/transitrouter/DescribeTransitRouterRouteTables) to obtain the TR route table ID.



**SourceCidrBlock** <span data-label="purple"> String </span> <span data-api-tag="require|PB8Gud">必选</span> `Example: 192.168.XX.XX/24`

The source CIDR block of the forwarding policy entry. Allow IPv4 and IPv6 CIDR blocks.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">The IPv6 feature of TR is in the beta stage. If you need a trial, please contact your account manager.</div>




**DestinationCidrBlock** <span data-label="purple"> String </span> `可选` `Example: 192.168.XX.XX/24`

The destination CIDR block of the forwarding policy entry. Allow IPv4 and IPv6 CIDR blocks.

This parameter defaults to an empty string, meaning it matches all destination addresses.



**Priority** <span data-label="purple"> Integer </span> <span data-api-tag="require|4FOX21">必选</span> `Example: 100`

The priority of the forwarding policy entry. Value: 1\-10000. A lower priority value indicates higher precedence.

Priority values of policy entries cannot duplicate within the same forwarding policy. If duplicate priority values are typed in, the system will automatically remove duplicates.



**Description** <span data-label="purple"> String </span> `可选` `Example: This route entry is used for test.`

The description of forwarding policy entry.


* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), Chinese commas ( ， ), and Chinese periods ( 。 ).

* Must be 0 to 255 characters.

* If you do not provide this parameter or leave it unset, it defaults to an empty string.



**ClientToken** <span data-label="purple"> String </span> `可选` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, idempotency check is not performed.
