Call CreateTransitRouterLocalPeerAttachment to create a local peer attachment that links two Transit Router (TR) instances within the same region.

<span id=".5L2_55So6K-05piO"></span>
## Instructions

In a request parameter such as Tags.N.a, the "N" represents the sequence number of a tag entry. It must be assigned a value in strict numerical order, starting from 1 up to 50. Separate multiple tags with ampersands (&). Each tag key pairs one tag value.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* You can create up to 10 local peer attachments for a single TR instance by default.

* Local peer attachments incur attachment fees separately on both TR instances, with no traffic processing fees charged. For details, see [Billing notes](https://docs.byteplus.com/en/docs/6979/155973).

* IPv6 is enabled for local peer attachments by default and cannot be disabled. If the IPv6 feature is unavailable in the region of the local peer attachment, IPv6 is not supported by default.

* When creating a local peer attachment, the local TR instance must not be a shared instance.

* When creating a cross\-account local peer attachment, obtain the peer TR instance ID and its account in advance.

The tag key.

* May include letters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), and at signs (@).
