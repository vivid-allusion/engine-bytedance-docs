Call CreateTransitRouterBandwidthPackage to create a Transit Router (TR) bandwidth package that provides bandwidth for cross\-region interconnection.

## Request parameters

The following only details request parameters specific to this API and key common parameters. For more information, see [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">String </span><span data-api-tag="require|ZLN4BI">必选</span> `Example: CreateTransitRouterBandwidthPackage`

The interface name. The current API name is `CreateTransitRouterBandwidthPackage`.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|AKfgJ1">必选</span> `Example: 2020-04-01`

The interface version. The current API version is `2020-04-01`.



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, idempotency check is not performed.



**Line Operator ** <span data-label="purple">String </span>`optional` `Example: ChinaUnicom`

The provider of cross\-border bandwidth packages.


* ChinaUnicom (default): China Unicom.

* ChinaTelecom: China Telecom.



**LocalGeographicRegionSetId ** <span data-label="purple">String </span><span data-api-tag="require|Qv9aDK">必选</span> `Example: China`

Local Geographic Region ID for TR bandwidth package interconnection. Values:


* China: Mainland China.

* Asia: Asia Pacific.



**PeerGeographicRegionSetId ** <span data-label="purple">String </span><span data-api-tag="require|syPP0C">必选</span> `Example: China`

Peer Geographic Region ID for TR bandwidth package interconnection. Values:


* China: Mainland China.

* Asia: Asia Pacific.



**Bandwidth ** <span data-label="purple">Integer </span>`optional` `Example: 2`

The peak bandwidth of the TR bandwidth package. Valid range: 2 to 10000 Mbps. Default: 2 Mbps.



**TransitRouterBandwidthPackageName ** <span data-label="purple">String </span>`optional` `Example: trbp-test`

The name of the TR bandwidth package.


* Must start with a letter, digit, or Chinese character. May include letters, digits, Chinese characters, and the following symbols: periods (.), underscores (_), and hyphens (\-).

* Must be 1 to 128 characters in length.

* If you do not provide this parameter or leave it unset, it defaults to the TR bandwidth package ID.



**Description ** <span data-label="purple">String </span>`optional` `Example: namedesc`

The description of the TR bandwidth package.


* Must start with a letter, digit, or Chinese character. May include letters, digits, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), Chinese commas ( ， ), and Chinese periods ( 。 ).

* Must be 0 to 255 characters.

* If you do not provide this parameter or leave it unset, it defaults to an empty string.



**BillingType ** <span data-label="purple">Integer </span>`optional` `Example: 1`

The metering method for the TR bandwidth package. Values:


* 1 (default): Subscription.



**PeriodUnit ** <span data-label="purple">String </span>`optional` `Example: Month`

The biliing cycle for the TR bandwidth package. Values:


* Month (default): Billing by month.

* Year: Billing by year.



**Period ** <span data-label="purple">Integer </span>`optional` `Example: 1`

The purchase duration for the TR bandwidth package. Default: 1. Values:


* When `PeriodUnit` is set to Month, valid values are 1 to 9, 12, 24, and 36.

* When `PeriodUnit` is set to Year, valid values are 1 to 3.



**ProjectName ** <span data-label="purple">String </span>`optional` `Example: default`

The name of the project to which the TR bandwidth package belongs. If you do not provide this parameter or leave it unset, it defaults to "default".



**Tags.N.Key ** <span data-label="purple">String </span>`optional` `Example: k1`

The custom tag key of the TR bandwidth package.


* Must be 1 to 128 characters.

* Case\-sensitive. Must not start with `volc:` or `sys:` in any case combination.

* Must not start or end with a space.

* May include letters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Duplicate tag keys are not allowed for the same resource.</div>


* <div data-tips="true" data-tips-type="tip">If you do not provide this parameter or leave it unset, it defaults to empty.</div>




**Tags.N.Value ** <span data-label="purple">String </span>`optional` `Example: v1`

The custom tag value of the TR bandwidth package.


* Must be 0 to 255 characters.

* Case\-sensitive. Must not start or end with a space.

* May include letters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">To provide this parameter, provide Tags.N.Key first.</div>
