Call the CreateTransitRouterTrafficQosMarkingPolicy API to create a traffic marking policy.

<span id=".5L2_55So6K-05piO"></span>
## Instructions


* You can create up to 10 traffic marking policies for a single Transit Router (TR) instance by default.

* A traffic marking policy comprises at least one marking entry and, by default, supports a maximum of 100 entries.​ If the default quota is insufficient, [create a quota modification application](https://docs.byteplus.com/en/docs/6837/129542) to request a quota increase.

* You can add up to 10 marking entries when creating a new traffic marking policy.

* Currently, only inter\-region attachments support traffic marking policies.
