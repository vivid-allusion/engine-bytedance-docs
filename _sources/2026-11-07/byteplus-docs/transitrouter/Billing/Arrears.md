Account arrears will affect network instance attachments on Pay\-as\-you\-go Transit Router (TR) resources.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">When your account is in arrears, BytePlus will send a notification by SMS, email, or internal message based on your reminder settings.</div>


* <div data-tips="true" data-tips-type="default">The specific suspension time is subject to the actual situation. Regardless of whether your instances are suspended or released, you shall settle the issued bills based on the actual usage.</div>



<span id="e5fbbbd2"></span>
## Impact of account arrears

Upon account arrears, the status and limits on permissible actions for TR instances and attachments vary depending on the time elapsed since arrears. Details are shown in the following diagram.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">Cross\-account network instance attachments are affected by arrears in the network instance account (recipient account) only when the fee payer for the TR instance is set to the network instance account. If the target TR instance contains no cross\-account attachments, you can ignore the impact of sharer's account arrears.</div>


* <div data-tips="true" data-tips-type="default">If the fee payer for the TR instance is set to TR owner account, cross\-account network instance attachments are affected by arrears in the TR owner account (sharer account), but not by arrears in the network instance account (recipient account).</div>


* <div data-tips="true" data-tips-type="default">In the diagram below, the sharer account refers to the account that owns the TR instance, and the recipient account refers to the account that owns the network instance attached to this TR instance.</div>
