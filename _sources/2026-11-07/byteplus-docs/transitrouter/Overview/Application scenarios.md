## Interconnectivity and isolation between multiple VPCs

By attaching multiple Virtual Private Clouds (VPCs) to a Transit Router (TR) and configuring flexible policies as needed, the TR service helps you achieve flexible private interconnectivity and isolation between VPCs. [Learn more](https://docs.byteplus.com/en/docs/transitrouter/Quick-start-01)

## Interconnectivity and isolation between multiple VPCs and an on\-premises data center

By attaching VPCs and a Virtual Private Network (VPN) or Direct Connect (DC) Gateway to a TR and flexibly selecting route configuration as needed, the TR service helps you achieve interconnectivity between each VPC and the on\-premises data center, while maintaining isolation between VPCs. [Learn more](https://docs.byteplus.com/en/docs/transitrouter/Best-Practices-02)

## Unify Internet egress for multiple VPCs

By allowing multiple VPCs to share an Internet NAT gateway via the TR and use a unified Elastic IP Address (EIP) to access the Internet, the TR service facilitates centralized management of Internet egress and enhances business security. [Learn more](https://docs.byteplus.com/en/docs/natgateway/Configuring-multiple-VPCs-to-share-an-Internet-NAT-Gateway-using-TR)

## Dynamic routing and failover

By flexibly configuring routes on the TR, the TR service helps you achieve dynamic multi\-path selection and automatic link failover in the event of an outage:


* Enabling load balancing between two dedicated DC links, providing high reliability for services.

* Enabling active\-standby redundancy between two dedicated DC links or between a DC link and a VPN link. This enables automatic failover when one link fails and avoids service disruption.

## Secure communication between VPCs

By forwarding bidirectional traffic between VPCs to security devices via the TR, the TR service helps you achieve secure communication between VPCs. [Learn more](https://docs.byteplus.com/en/docs/transitrouter/Secure-intercommunication-between-different-VPCs)

## Hybrid cloud scenarios

By associating VPCs, VPNs, and DC Gateways with respective TRs and configuring routes for intercommunication, the TR service helps you implement cross\-region hybrid networking scenarios, achieving interconnectivity between VPCs, between VPC and data center, and between data centers.
