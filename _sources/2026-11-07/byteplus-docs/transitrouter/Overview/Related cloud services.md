This topic describes cloud products related to the Transit Router (TR).

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_512e05f19f40b7a3703f59343a18020f.png) </span>

The related cloud services in the above diagram are detailed in the following table.


|Service name |Relationship description |Documentation |
|---|---|---|
|VPC |Connect a VPC to a TR, enabling intercommunication between cloud networks. |[Virtual Private Cloud overview](https://docs.byteplus.com/en/docs/vpc/What-is-VPC) |
|VPN Connect |IPsec\-VPN connection is a component of the VPN service. Connect an IPsec\-VPN connection to a TR. This enables intercommunication between VPN\-connected data center networks and cloud networks. |[VPN Connect overview](https://docs.byteplus.com/en/docs/vpn/What-is-Virtual-Private-Network) |
|Direct Connect (DC) |Connect a DC Gateway to a TR. This enables intercommunication between DC\-connected data center networks and cloud networks. |[Direct Connect overview](https://docs.byteplus.com/en/docs/directconnect/What-is-Direct-Connect) |
|Cloud Firewall |Configure Cloud Firewall for the TR. It will protect bidirectional traffic between network instances. |[Cloud Firewall overview](https://docs.byteplus.com/en/docs/cloud_firewall/What-is-BytePlus-Cloud-Firewall) |
|Identity and Access Management (IAM) |Control access permissions of separate accounts to the TR resources, enabling delegated management. |[IAM overview](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-3) |
|Quota management |Centrally manage the TR resource quotas under an account. It allows you to query quota limits and resource usage, apply online to adjust quotas as needed, and set alert rules. |[Quota Center overview](https://docs.byteplus.com/en/docs/resourcemanagement/Quota_Overview) |
|Tag management |You can classify and manage TR resources through tags. |[Tag overview](https://docs.byteplus.com/en/docs/resourcemanagement/Tag_Overview) |
|Cloud Monitor |Through Cloud Monitor, you can view real\-time metric data of TR instances and TR attachments. Through customizable metric thresholds and alert notifications, anomalies are detected promptly to ensure stable business operations. |[Cloud Monitor overview](https://docs.byteplus.com/en/docs/cloudmonitor/What-is-Vitality-Cloud-Monitor) |
