## Prerequisites

A cross\-account peering attachment has been created and its status under a Recipient account is **Pending acceptance**. For procedure, see [Creating an inter-region attachment](https://docs.byteplus.com/en/docs/transitrouter/Inter-region-peering-attachments-01).

<span id="ImpF2Qt4"></span>
## Procedure


1. Use the Recipient account to log in to [the Transit Router console](https://console.byteplus.com/tr/transitRouter).

2. Click the name of the target TR instance.

3. In the section below **Basic Information**, select the **Inter\-region attachment ** tab.

4. Click **Accept** to the right of the target cross\-account peering attachment, and confirm the resource information.

6. Click **Migrate** to complete the action.


<span id="bb8iUoBU"></span>
## What to do next

Configure routing for the peer TR instance as described in [Create an association forwarding rule](https://docs.byteplus.com/en/docs/transitrouter/Route-tables-07) and [Create a route learning rule](https://docs.byteplus.com/en/docs/transitrouter/Route-tables-06).
