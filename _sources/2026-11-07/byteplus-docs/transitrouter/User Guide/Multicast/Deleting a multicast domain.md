## Prerequisites

Make sure no subnets are associated with the multicast domain. If any, disassociate them first. For procedure, see [Disassociate a subnet from a multicast domain](https://docs.byteplus.com/en/docs/transitrouter/Attaching-or-detaching-subnet-for-multicast-domain#vmkDoyWR).

<span id="0HyldKDc"></span>
## Procedure


1. Log in to [the Transit Router console](https://console.byteplus.com/tr/transitRouter).

2. Click the name of the target TR instance.

3. In the zone below **Basic information**, select the **Multicast domain** tab.

4. Click **Delete** to the right side of the target multicast domain.

5. Click **Delete** to complete the action.
