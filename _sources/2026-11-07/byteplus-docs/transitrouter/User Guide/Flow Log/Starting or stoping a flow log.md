## Start a flow log

<span id="VArBFRjV"></span>
### Instructions


* Only flow logs in **Stopped** status support the start action.

* After starting a flow log, the TR resumes collecting and generating log information.


<span id="atZ1absj"></span>
### Procedure


1. Log in to [the Transit Router console](https://console.byteplus.com/tr/transitRouter).

2. Click the name of the target TR instance.

3. In the zone below **Basic information**, select the **Flow Log** tab.

4. Click **Start** to the right of the target flow log.

5. Click **Start** to complete the action.


<span id="66GgfX1G"></span>
## Stop a flow log

<span id="gRpjovu3"></span>
### Instructions


* Only flow logs in **Started** status support the stop action.

* After stopping the flow log, the TR will no longer collect or generate new log information. However, you can still view logs already delivered to the Torch Log Service (TLS).


<span id="y5Mqi2hu"></span>
### Procedure


1. Log in to [the Transit Router console](https://console.byteplus.com/tr/transitRouter).

2. Click the name of the target TR instance.

3. In the zone below **Basic information**, select the **Flow Log** tab.

4. Click **Stop** to the right of the target flow log.

5. Click **Stop** to complete the action.
