## Scenarios

After creating TR flow logs, you can configure indexes and retrieval syntax based on business needs to obtain TR flow log search and analysis results.

<span id="uB3kzeNk"></span>
## Prerequisites

Make sure [index configuration](https://docs.byteplus.com/en/docs/tls/Configure-indexes-2) is complete. The index configuration determines how logs are searched and the accuracy of search results.

<span id="TIupgKpe"></span>
## Procedure


1. Log in to [the Transit Router console](https://console.byteplus.com/tr/transitRouter).

2. Click the name of the target TR instance.

3. In the zone below **Basic information**, select the **Flow Log** tab.

4. Click the target log topic name to navigate to the Torch Log Service (TLS) console, and view TR flow logs by seeing [Log analysis](https://docs.byteplus.com/en/docs/tls/Analyze-logs-2).
