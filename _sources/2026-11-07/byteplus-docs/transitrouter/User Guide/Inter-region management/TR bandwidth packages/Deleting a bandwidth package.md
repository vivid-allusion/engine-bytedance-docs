## Prerequisites


* Subscription bandwidth packages can only be deleted after they are suspended upon expiration. To delete a bandwidth package before expiration, see [Unsubscription](https://docs.byteplus.com/en/docs/transitrouter/Expiration#.6YCA6K6i5LuL57uN).

* Ensure the bandwidth package is not associated with any inter\-region attachments. If associated, first [remove it from the bandwidth package](https://docs.byteplus.com/en/docs/transitrouter/Inter-region-peering-attachments-02#.56e75Ye65bim5a695YyF).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to [the Bandwidth Package console](https://console.byteplus.com/trbandwidthpkg/trbp).

2. In the top menu bar, select the target project.

3. Click **Delete** to the right of the target bandwidth package, and confirm resource information.

4. Click **Delete** to complete the action.
