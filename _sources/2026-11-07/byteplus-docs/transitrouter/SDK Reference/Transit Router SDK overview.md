This topic introduces the SDK language versions provided by Transit Router (TR) and lists the download addresses of the latest SDK versions.

<span id=".U0RL5LuL57uN"></span>
## SDK overview

TR SDK encapsulates all API interfaces of Transit Router ([Transit Router API overview](https://docs.byteplus.com/en/docs/transitrouter/API-overview)). It identifies the caller's identity using the access key (AK) and offers features like automatic signature, facilitating API\-based creation and management of resources.
