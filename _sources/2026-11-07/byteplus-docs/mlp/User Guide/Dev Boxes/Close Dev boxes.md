If the Dev boxes are no longer in use, you can close the Dev boxes. After the development machine is shut down, the computing power of the Dev boxes will be released, the previous operations, downloaded data and configuration environment will be saved, and the computing instances can also be switched across specification families

<span id="使用前提"></span>
## Premise of use


* Dev boxes are `in the running`state

* Only creator operations are supported


<span id="操作步骤"></span>
## Procedure


1. Log in to the Machine Learning Platform and click [Dev boxes] in the left navigation bar to enter the Dev boxes list page

2. Click the operation item [Shutdown] on the Dev boxes list page/details page to enter the shutdown process.

3. After the development machine is turned off, you can edit the configuration items of the Dev boxes. The configuration can be modified as follows

   * Concept

   * Description

   * queue

   * calculation specification

   * Cloud disk capacity (or increase cloud disk capacity through expansion)

   * access configuration

   * Shared file system mount
