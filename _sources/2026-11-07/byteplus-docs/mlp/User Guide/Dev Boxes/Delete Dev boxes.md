If the use of Dev boxes has ended, you can delete the Dev boxes. After the Dev boxes are deleted, the computing power and cloud disk resources of the Dev boxes will be released.

<span id="使用前提"></span>
## Premise of use


* Dev boxes support deletion in all states

* Delete operations are supported only by administrators who create people or queues where Dev boxes are located.


<span id="操作步骤"></span>
## Procedure


1. Log in to the Machine Learning Platform and click [Dev boxes] in the left navigation bar to enter the Dev boxes list page

2. Click the operation item [Delete] on the Dev boxes list page/details page to enter the deletion process.
