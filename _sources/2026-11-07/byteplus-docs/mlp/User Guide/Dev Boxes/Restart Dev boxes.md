The restart of the Dev boxes will save the previous operations, downloaded data and configuration environment, etc.

<span id="使用前提"></span>
## Premise of use


* Dev boxes are `in the running`state

* Only creator operations are supported


<span id="操作步骤"></span>
## Procedure


1. Log in to the Machine Learning Platform and click [Dev boxes] in the left navigation bar to enter the Dev boxes list page

2. Click the operation item [Restart] on the Dev boxes list page/details page, and then the Dev boxes can enter the restart. You can continue to use the Dev boxes after the restart.
