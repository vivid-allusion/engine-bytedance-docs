The BytePlus Machine Learning Platform (hereinafter referred to as MLP) supports the registration of inference services as inference access points (hereinafter referred to as Endpoints) of the BytePlus Large Model Service Platform Ark (hereinafter referred to as Ark), which facilitates the use of Ark's platform capabilities:


* **Multi\-access point shunting** : An inference service can Create multiple Ark Endpoints, support according to the limited viewership of Endpoints, realize service shunting (such as large\-scale traffic scheduling, service level distinction, etc.).

* **Evaluation and iteration** : one\-click evaluation, comparative performance (response speed, accuracy), auxiliary model optimization.

* **Permission control** : Support fine grain permission control, such as Access Key, API key authentication, project, label dimension permission configuration, etc.


<span id="ae7b42bf"></span>
# support model

Support: Inference services deployed by large language models, including text generation and deep thinking capability models.

Not supported: Visual understanding model, picture generative model, video generative model and other deployed inference services will report an error of 500 when calling the API.

# Procedure

<span id="fd26949f"></span>
## Step 1: Create the Ark Endpoint

Prerequisites: Your trained LLM model or tripartite model has been deployed as inference services , see the detailed steps [Deploy the model as a service (new)](https://docs.byteplus.com/docs/mlp/Deploy_the_model_as_a_service_new).

> The links in the steps are all North China 3 (Beijing) regional links, please pay attention to switching regions on demand.


1. Use the administrator account or main account to complete cross\-service authorization for Volcano Ark in the [MLP global settings](https://console.byteplus.com/ml-platform/region:ml-platform+ap-southeast-1/globalConfig), and follow the console guidelines to Add corresponding inference services.

2. On the [inference services ](https://console.byteplus.com/ml-platform/region:ml-platform+ap-southeast-1/serviceNew?current=1&pageSize=10)page, click the **inference services name** , and in the top right corner of the open **service details** page, click the **Ark inference access point** button.

3. Configure Ark Endpoint information according to console guidelines, where business requirements and resource capabilities configure limited viewership of access points.

4. (Optional) Repeat step 3 to Create 1 or more inference access points as needed, configured to correspond to the limited viewership of Endpoints.


<span id="304f3c22"></span>
## Step 2: View & Call Ark Endpoint


1. Click **Ark inference access points** \> **View associated Ark access points** , jump to Ark, and view the Create Endpoint invocation model service.

2. Click the API calls link in the actions col\*\*API calls link in the actions \*\*column to view the call sample code for the corresponding access point.

# More details

The Ark inference access point registered by MLP inference services is somewhat different from the Ark native inference access point, as shown in the following aspects.


* API call:

   * For MLP inference services registered with Ark, only **API calls through MLP Endpoint ID are supported** , and model names or Model I D calls are not supported.

   * Volcano Ark does not check and intercept parameters, please confirm the parameter range supported by the model in advance.

   * When using Ark App Square, whether to support plug\-in capabilities such as web page parsing is determined by the model's capabilities (for example, models that do not support Function Calling cannot support web page parsing plug\-ins).

* Cost Usage:

   * From MLP\-registered inference access points, Volcano Ark does not charge for tokens generated by inference.

   * If you use the Volcano Ark plugin/knowledge base, you will incur related fees.

* Security capabilities:

   * Content Security: It is your own responsibility, and Volcano Ark is not responsible for content review.

   * Data Security: Ark and MLP will not use your inference data, and all data will only be used for your inference service and will not be used for any other purpose.

   * Product Safety: Guaranteed by MLP, does not support the use of Ark Safety Sandbox related capabilities.

* Limited viewership of SLA:

   * Support setting limited viewership of MLP Endpoint, but the actual effect of limited viewership is also limited by the corresponding service resource decision.

   * **Actual inference service availability is determined by resources, and ARK cannot** **guarantee** **and commit to SLAs.**
