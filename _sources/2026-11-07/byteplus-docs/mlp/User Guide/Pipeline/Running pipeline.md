The platform supports running the pipeline through the console (Web page) and SDK. Here is how to run the pipeline through the console. Please check the [Using the pipeline through the SDK](https://docs.byteplus.com/docs/mlp/Using_the_pipeline_through_the_SDK).


* On the pipeline details page, click [Run] in the upper right corner of the page, fill in the operation name of the pipeline and the operation parameters of the pipeline, and then submit the operation.

* You can view all the operation records of the current pipeline in [Operation Records]

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_83f06a054e15168b756c78f37241ace1.png) </span>

   * The list on the left shows the overall operation status of the pipeline

   * You can view the running status of each node of the pipeline on the right, and support switching to table form to view

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/99c479f2978846398a938f01ec9d199c~tplv-goo7wpa0wc-image.image) </span>

   * Click on the node to view the task details/log

   * You can switch to the running configuration to view the detailed pipeline configuration information.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/75c2cca1f94342fab3d0877b4e40629f~tplv-goo7wpa0wc-image.image) </span>
