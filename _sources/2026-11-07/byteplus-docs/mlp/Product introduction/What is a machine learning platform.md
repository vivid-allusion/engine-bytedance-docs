Byteplus machine learning platform is an enterprise\-level development platform for machine learning application developers, providing rich modeling tools such as [developer computer] and [custom training], and multi\-framework high\-performance model inference services. It supports the full life cycle workflow from data hosting, code development, model training, and model deployment.

# Product advantages

**Very Large Distributed Training**

Support for running large\-scale distributed tasks, including a variety of pre\-built algorithm frameworks and custom algorithm frameworks. Provide a stable, flexible, and high\-performance machine learning training environment.

**multi\-framework high\-performance inference**

The one\-click deployment of models that support multiple frameworks on heterogeneous hardware has the characteristics of high throughput, low latency, real\-time volume expansion and contraction, making inference services more elastic and fault\-tolerant.

**Cost\-effective computing resources**

Provide a cost\-effective Prepaid resource group, support quota allocation, Task management, view resource utilization and other functions in the resource group, and improve the overall resource utilization.

**High\-efficiency development and debugging tools**

Provides a cloud\-based machine learning development environment \- developer computers with built\-in images of multiple mainstream machine learning frameworks. Combining elastic resources and the same environment as distributed training can greatly enhance the efficiency of development and debugging. At the same time, it provides command\-line tools to support the end\-cloud collaborative development environment, which can initiate and manage training tasks with one click from the local environment.

# First use

Users who are using the machine learning platform for the first time are advised to use the following materials as needed to understand and learn.

**basic knowledge**

To avoid users blocking the actions process due to unfamiliar nouns or concepts, the main functional modules of the machine learning platform are explained in the [Feature Overview](https://docs.byteplus.com/docs/mlp/Feature_Overview)[ ](https://www.volcengine.com/docs/6459/72379), and some additional common nouns are explained in the [Common concepts](https://docs.byteplus.com/docs/mlp/76491). For information related to Product billing, please refer to the [example specifications and pricing ](https://docs.byteplus.com/en/docs/mlp/Instance_Specifications_and_Pricing). Users can learn about "What's in a machine learning platform?" through the above section.

**Quick start**

In order to facilitate users to quickly understand the whole process of machine learning platform development, the [quick start ](https://docs.byteplus.com/en/docs/mlp/Quick_Start)chapter expounds the actions method from a series of processes such as create account, configuration permission, preparing data, training model, and deploying services.

**Guidelines for each module**

After reading the above chapters, users have a basic understanding of the main functions and actions of the platform. In subsequent use, they can solve the problems encountered by viewing the detailed function introduction of each module in the [user guide ](https://docs.byteplus.com/en/docs/mlp/Overview2). With the in\-depth use of the platform, users may need to divide specific permissions for different sub\-accounts. At this time, you can refer to [permission management ](https://docs.byteplus.com/en/docs/mlp/rights_management).

**Best practices**

Some best practices for developing projects on machine learning platforms are listed, such as reference [Overview](https://docs.byteplus.com/docs/mlp/53958) to understand how large\-scale data is stored on machine learning platforms, and by consulting the demo in th [More Examples](https://docs.byteplus.com/docs/mlp/More_examples), you can become more familiar with the common training paradigm of machine learning.
