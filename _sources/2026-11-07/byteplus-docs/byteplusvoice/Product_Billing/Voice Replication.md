## Character


* Definition: 1 character = 1 Chinese character = 1 English letter = 1 punctuation mark = 1 special symbol = 1 space = 1 carriage return

* Speech Synthesis Markup Language (SSML) will be counted as characters.

## Concurrency

Default quota is 10 and additional concurrency can be purchased (we provide 3 concurrency when in trial).
