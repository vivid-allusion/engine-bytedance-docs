1. # Overview <span id="m1IsHNb7"></span>


General speech\-to\-text can ensure accuracy to a certain degree but has the following pain points due to complexities in the environment, context, and vertical domain:


* Performance degradation in noisy environments.

* Failure to distinguish between homophones.

* Failure to recognize proper nouns, such as place names and industrial terms.

* Difficulty in maintaining the contextual consistency of names, pronouns (he/she/it), and more.


Thus, ByteDance Seed team upgrades large model speech\-to\-text capabilities based on industry\-leading proprietary technologies and industrial big data benefits.

2. # Streaming ASR <span id="xxqK697o"></span>

   1. **Input/Output:**  Long audio files are transcribed in real time, suitable for scenarios such as conference live captioning, live stream captioning, and intelligent outbound calls.

   2. **Input:**  Audio files are streamed to the speech\-to\-text engine, which returns sentence\-level results, suitable for scenarios such as conversations with an agent, IM voice message transcription, and voice typing.

   3. **Language Support: ** 

   * Bi\-directional Streaming ASR

      * English

      * Chinese

   * Uni\-directional Streaming ASR

      * English

      * Chinese

      * Cantonese

      * Japanese

      * Portuguese

      * Spanish

      * Indonesian Bahasa

      * German

      * French

      * Korean

      * Filipino

      * Malay

      * Thai

      * Arabic

3. # Audio File ASR <span id="Z9cqVRvG"></span>

   Audio files no longer than four hours are transcribed and processed with predefined features such as automatic punctuation, semantic smoothing, inverse text normalization (ITN), and intelligent sentence segmentation. This is suitable for non\-real\-time speech\-to\-text scenarios, such as meeting summarization, intelligent outbound call moderation, after\-school tutoring, and student analysis.
