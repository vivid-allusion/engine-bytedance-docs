This document introduces the registrant profile in BytePlus Domains.

<span id="overview"></span>
## Overview

For domains managed by BytePlus Domains, the registrant information is stored separately in the registrant profile. In addition to the registrant information, the registrant profile also contains contact information.

When you register a domain, transfer a domain into BytePlus Domains, or change the domain registrant, you need to specify a registrant profile that contains the domain registrant information. If the registrant profile does not exist, you need to create it first.

The same individual or company can own multiple domains. These domains can use the same registrant profile.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">When creating a registrant profile, you need to specify an email address that has completed email verification. See <a href="https://docs.byteplus.com/en/docs/domain-names/email-verification_en">Email Verification</a>.</div>


* <div data-tips="true" data-tips-type="tip">Once a registrant profile is created, it cannot be changed. If you need to change the content of a registrant profile, you can only create a new registrant profile to include the updated content.</div>



<span id="steps"></span>
## Steps


1. Visit [BytePlus Domains](https://console.byteplus.com/domain-service/search).

2. In the left navigation bar, click **Registrant profiles**.

3. On the **Registrant profiles** page, click **Create profile**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260330094840-1522021005757.webp) </span>

4. On the **Create profile** page, complete the required configurations according to the instructions below, and then click **Submit**.

   ||City |Indicates the city in the registrant's address. |

   ||Zip code / Postal code |Indicates the postal code of the registrant's address. |
