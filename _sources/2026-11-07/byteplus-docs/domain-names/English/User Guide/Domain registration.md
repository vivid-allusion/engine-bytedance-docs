This document introduces how to register a domain in BytePlus Domains.

<span id="overview"></span>
## Overview

To own a domain, you need to register it with a domain registrar. The registration period for a domain is at least 1 year and up to 10 years.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For domains ending with .ai, the minimum registration period is 2 years. The domain suffixes ending with .ai include .ai, .com.ai, .off.ai, .net.ai, and .org.ai.</div>


BytePlus collaborates with the domain registrar Domainipr to provide domain registration services. The domains you register in BytePlus Domains will show Domainipr as the registrar, and the domains are managed by BytePlus Domains.

<span id="registrant-profile"></span>
## Registrant Profile

When registering a domain, you need to specify a registrant profile. The registrant profile contains information about the registrant and the contact. If you are using BytePlus Domains for the first time, please create a registrant profile before registering a domain.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">If you are registering a <strong>.hk</strong> or <strong>.com.hk</strong> domain, you must select a registrant profile that has the required identification information configured under <strong>Required information for other ccTLDs </strong>in <a href="https://docs.byteplus.com/en/docs/domain-names/registrant-profile_en#steps">Registrant profile</a>.</div>


For more information about registrant profiles, see [Registrant Profile](https://docs.byteplus.com/en/docs/domain-names/registrant-profile_en).

<span id="domain-naming-conventions"></span>
## Domain Naming Conventions

<span id="naming-conventions-for-english-domains"></span>
### Naming Conventions for English Domains


* Domains can include letters, numbers, and hyphens (\-). Letters are case\-insensitive.

* Domains cannot start or end with a hyphen (\-).

* Consecutive hyphens (\-) are not allowed in domains.

* The length of the domain (excluding the suffix) cannot exceed 63 characters.


<span id="naming-conventions-for-chinese-domains"></span>
### Naming Conventions for Chinese Domains

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">In this article, "Chinese domains" refers to internationalized domain names (IDNs) that contain Chinese characters.</div>



* Domains must include at least one Chinese character and can include letters, numbers, and hyphens (\-). Letters are case\-insensitive.

* The simplified and traditional forms of the same Chinese character are considered the same. For example, if `簡體-axy-123.com` is registered, you cannot register `简体-axy-123.com`.

* Domains cannot start or end with a hyphen (\-).

* Consecutive hyphens (\-) are not allowed in domains.

* After converting Chinese characters in the domain to Punycode, the length of the domain (excluding the suffix) cannot exceed 63 characters.


<span id="domain-registration-process"></span>
## Domain Registration Process


1. Search for the domain you want to register. The search results include the availability, recommended suffixes, pricing, and other information for the domain.

2. Add the domain you want to register to the shopping cart.

3. Specify the registration period and a registrant profile.

4. Confirm the order and pay the fees.


<span id="steps"></span>
## Steps

<span id="step-1-domain-search"></span>
### Step 1: Domain Search


1. Visit [BytePlus Domains](https://console.byteplus.com/domain-service/search).

2. In the left navigation bar, click **Domain registration**.

3. In the domain search box, enter the domain you want to register, and then click search.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_0fe6dd492f02ee33d01f0d89fa43cac4.png) </span>

   If you have multiple domains to register, you can click **Search for multiple domains**, enter one domain per line, and then click search. You can search up to 10 domains at a time.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_53cbd031a90f21e816108c81a40ed20a.png) </span>


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">In the search results, if a domain is marked as <strong>Registered</strong>, it means the domain has been registered by someone else. You can choose a domain with a different suffix or change the domain name to search again.</div>


* <div data-tips="true" data-tips-type="tip">In the search results, you can hover over the displayed price to view the complete price list, which includes the price for each registration period.</div>


   <div data-tips="true" data-tips-type="tip"><img src="https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_02392210b90eed4aced051c5b70c13b9.png" width="742px" />   </div>
   


<span id="step-2-add-to-cart"></span>
### Step 2: Add to Cart


1. In the search results, for the domains you want to register, click **Add to Cart** to add these domains to the shopping cart.

2. Click **Proceed to checkout**.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_de9ce97c866b9c9c1d505b8b3dd504f0.png) </span>


<span id="step-3-complete-domain-registration-information"></span>
### Step 3: Complete Domain Registration Information


1. On the **Order details** page, complete the configuration according to the instructions below.

2. Check the agreement, and then click **Submit**.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_e173455ecf7cc7355931de18da7bf24b.png) </span>

<span id="step-4-confirm-order-to-complete-registration"></span>
### Step 4: Confirm Order to Complete Registration

On the order confirmation page, please check the order information. If the order information is correct, click **Next**, and then follow the on\-screen instructions to complete the payment.

After the payment is completed, you can visit [Domain list](https://console.byteplus.com/domain-service/domain-service/domain) to view and manage your registered domains.
