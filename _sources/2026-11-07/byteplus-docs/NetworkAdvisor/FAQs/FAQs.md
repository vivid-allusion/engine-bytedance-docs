## Diagnostic item execution exception?

For some Classic Load Balancers (CLBs) of specific beta specifications, the Network Advisor (NA) cannot perform diagnostics on items such as CLB inbound/outbound bandwidth utilization, maximum supported connections, maximum new connections per second, and maximum queries per second. The diagnostic report will indicate Diagnostic Item Execution Exception. Please navigate to the monitoring page to view relevant data. For specific steps, see [Viewing the monitoring data](https://docs.byteplus.com/en/docs/clb/Viewing-monitoring-data).
