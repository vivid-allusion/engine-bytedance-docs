## Introduction

Terraform is an open\-source IT infrastructure orchestration tool that supports defining infrastructures or applications using configuration files.

With Terraform, you can easily orchestrate BytePlus cloud resources, For example, create, manage, maintain, etc., and perform version control on them.

<span id=".5Lqn5ZOB5LyY5Yq_"></span>
## Benefits


* Infrastructure as Code

   Describe infrastructure using advanced configuration language, enabling its codification and versioning, and facilitating sharing and reuse.

* Multi\-cloud deployment

   You can deploy similar infrastructures to BytePlus, other cloud providers, or data center (IDC), and manage cloud resources of different providers simultaneously through the same configuration file.

* Execution plan

   Execution planTerraform can generate an execution plan to display its state when the apply command is called. This avoids incidents when Terraform performs operations on the infrastructure.

* Resource graph

   Resource graphTerraform can build a graph of all resources for creating and modifying non\-dependency resources in parallel. This improves infrastructure construction efficiency and helps operators gain a deep insight into dependencies within the infrastructure.
