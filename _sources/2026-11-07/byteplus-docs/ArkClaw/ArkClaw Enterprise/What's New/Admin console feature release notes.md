This topic describes release updates for feature modules of the ArkClaw Enterprise console for administrators.

## October 2026

|Release time |Feature |Feature description |Documentation |
|---|---|---|---|
|10\-21 |Managing templates |Adds the "Controlled access" visibility scope for enterprise\-recommended agent templates. It enables you to perform fine\-grained authorization by department, user group, and individual user. |[Agent templates](https://docs.byteplus.com/en/docs/ArkClaw/Agent_templates) |
