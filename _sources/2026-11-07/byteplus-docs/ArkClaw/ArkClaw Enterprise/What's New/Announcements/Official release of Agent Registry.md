## Overview

With the rapid growth of internal assets within enterprises, e.g., AI Agent and MCP Server, challenges such as resource discovery and governance have become increasingly prominent. Agent Registry delivers an **enterprise\-grade data and control plane for Agent resources**, with cataloging, intelligent discovery, security governance, and centralized management across protocols and runtimes. For more information and best practices, see [Best practices for resource registration and use in the Application Center](https://docs.byteplus.com/en/docs/ArkClaw/Best_practices_for_resource_registration_and_use_in_the_Application_Center).

### Agent asset catalog

Covers all agent\-related resources within the enterprise:


* Resource types: Agent (A2A), ArkClaw, MCP Server, Skill

* Establishes the single source of truth for enterprise Agent assets.

### Intelligent discovery

Provides intelligent search capabilities for both humans and Agents:


* MCP / A2A supports semantic vector retrieval and resource discovery by capability, scenario, and tool description.

### Security control

Built\-in security control:


* Security capabilities: Integrated with Gateway and Identity, providing APIKey and OAuth\-based invocation to ensure secure and controlled resource access.

</columnsItem>
<columnsItem zoneid="71TsaOh3">

### Protocol\-based interface

The Registry does not directly execute Agents, but is responsible for discovery, resolution, and governance.


* Exposes capabilities such as search and invocation via MCP Server.

* Provides CLI / REST for integration platforms and toolchains
