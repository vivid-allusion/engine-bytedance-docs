This topic summarizes the new features, improvements, and bug fixes across all ArkClaw client versions, so you can review upgrade and optimization details by version.

Conversation history remains viewable, and a "Pair" entry is provided to navigate directly to "Device management".<br><br>   * Updated custom file permissions. All permission levels can now read local files. The "Custom" permission level now only manages directories allowed for writing. The authorization callback method was adjusted to ensure authorization results are correctly returned to the client. |

When a command matches the "Require confirmation" policy, the actual command is displayed in the interface, and you can choose to allow it once or always allow it.<br><br>   * The desktop client permission system has been upgraded to two tiers: file system permissions and command execution permissions. Command execution supports request approval mode, custom permissions, and full access, with execution policies configurable per project.<br><br>   * Optimized the prompt displayed when a local project directory is deleted. Existing conversations remain viewable, but starting or continuing conversations, file access, opening directories, and Git operations are suspended. Once the directory is restored, it can be re\-detected and used again. |

A prompt appears automatically when a new version is ready. It can be manually dismissed and can be viewed by hovering over it at any time.<br><br>   * The version number in the sidebar now syncs to the latest version in real time, eliminating the need to manually check the current version.<br><br>   * Optimized the icon display for "View file directory" in the local project menu. |

When a local browser capability error occurs, silent repair is supported, and your original browser task is automatically retried upon successful repair.<br><br>   * Enhanced local file capabilities. Precise text replacement and batch partial editing are now supported, large file writes are more stable, and the risk of write failures or content being overwritten is reduced.<br><br>* **Optimizations and bug fixes**<br><br>   Optimized the system stability and underlying performance. |

Dismissed update prompts are now persisted to avoid repeated interruptions.<br><br>   * Fixed an issue where the sandbox did not take effect on some Windows versions. |
