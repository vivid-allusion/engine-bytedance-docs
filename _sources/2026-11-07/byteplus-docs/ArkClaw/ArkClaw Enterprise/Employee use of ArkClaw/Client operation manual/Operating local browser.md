ArkClaw Janus is a browser extension that connects the Chrome browser installed on your local computer to the locally deployed ArkClaw client, enabling ArkClaw to perform operations on the local browser. This topic describes how to install and use ArkClaw Janus.

<span id="a44YEmbC"></span>
## Install the Janus extension


1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw page and click the details icon in the upper\-right corner.

3. Click the "Operate local browser" button.

4. In the dialog box that appears, click "Download latest extension" and decompress it locally.

5. Open Google browser, enter `chrome://extensions/` in the address bar to open the extension center, check "Developer mode" in the upper\-right corner, and click the "Load unpacked" button.

6. Select the extracted extension package, and click the "Select" button.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you download and extract the Janus installation package on a Windows system, select the corresponding Janus browser extension package in the extracted Janus folder for installation.   </div>
   

7. After the extension is loaded, you can view the installed Janus extension in the All extensions list, as shown in the figure.


<span id="f3C8gSxP"></span>
## Start the Janus extension


1. After the installation is complete, find "Janus Preview" in the Chrome extension list and click the extension icon to open the extension panel.

2. In the "Janus Preview" card, confirm that the local browser is connected to the ArkClaw client, and then click "Open ArkClaw client".

3. In the conversation input box, send prompts directly to the Janus browser.

   * **Sample prompt:** 

      Open the browser, go to www.baidu.com, and check today's weather in Beijing.

   4. The Janus extension drives the local browser to execute the task and displays the execution process in real time.

   5. After the command is executed, you can view the execution result in the ArkClaw chat box.
