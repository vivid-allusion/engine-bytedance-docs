Security logs record security handling events on the device, including command output, file changes, processing and execution results of tool calls and online search, as well as security configuration changes and system events. The logs are stored only on the current device and are not automatically synchronized to other devices.

## Application scenarios

We recommend checking security logs first in the following scenarios:

* Determine why a command, tool call, or file access did not run successfully.

* Trace security interception records in a session to locate the specific point in time and the object involved.

* Export the security handling records on the device for auditing, feedback, or troubleshooting.

## Procedure

1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw.

3. Click "![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_733c3e75c42df2726b84b0bb6a1cd7bc.png)\> Security management".

4. Select the Security logs tab. On this page, we recommend viewing logs in the following order to locate records more quickly.

   1. **Narrow the time range first**. Prefer the last 7 days or another target time range to avoid too many results.

   2. **Add filtering conditions**. Select a behavior, stage, session, and processing result type as needed.

      * Behavior: The type of operations triggered while the assistant is running. The platform classifies logs into behavior types such as command, file, tool, skill, and network based on the object and method involved in the operation.

      * Stage: The phase of the assistant behavior in the security protection process, including pre\-assessment, in\-progress approval, and post\-execution.

      * Session: The session context in which the assistant behavior occurs, used to distinguish security logs generated by different conversations.

      * Processing result: The handling status of the assistant behavior after security rule evaluation, user confirmation, or related configuration operations. It indicates how the operation is currently handled and whether the operation continues.

   3. **Search by keyword**. Enter a command, tool name, or path in the search box to further locate the target record.

   4. **View processing results**. In the log list, focus on the time, behavior, and details. In the Process column of the target entry, click the ![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_02da0f85255987ef74fd99979bb12cb0.png) icon to expand and view more information about the record.

   5. **Export as needed**. To perform auditing, troubleshooting, or other operations, click "Export" to export the log records in the current view.
