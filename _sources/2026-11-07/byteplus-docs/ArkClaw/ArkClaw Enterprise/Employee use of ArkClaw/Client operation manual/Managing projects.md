The ArkClaw client supports adding local folders as projects, allowing you to work on tasks within a fixed working directory. Once a project is added, you can quickly switch between projects in the left navigation pane, view the file directory, or open the corresponding location in the system file manager, without having to re\-locate the path or manually authorize access each time.

This topic describes how to add and remove projects, as well as how to view the file directory and open file locations.

## Prerequisites

[have authorized the local device](https://docs.byteplus.com/en/docs/ArkClaw/Installing_and_using_the_client?lang=en#ZJ0j4Jsu).

## Add a project

1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw page and click the "Initiate task" button.

3. Click "Enter project space \> Add project" below the ArkClaw input box, and select the local folder you want to allow ArkClaw to access in the dialog box that appears.

4. (Optional) Set local command execution permissions.

   > **tip**

   > The dialog box displays the default system permission and network access permission for the current session. To set other permissions, see [Switching file access permissions](https://docs.byteplus.com/en/docs/arkclaw/Managing_local_file_access_permissions?lang=en#dbhS6CRE) or [Configuring network access](https://docs.byteplus.com/en/docs/arkclaw/Managenetworkpermissions?lang=en#w006Xbiy).

## Remove a project

> **warning**

> Removing a project revokes the directory authorization for that project, but does not delete any files on your local device.

1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw page.

3. In the left navigation pane, click "··· \> Remove from list" next to the target project name.

4. In the dialog box that appears, click "Remove" to complete the operation.

## View a file directory

1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw page.

3. In the left navigation pane, select "Project \> [target project folder]".

4. Click "··· \> View file directory".

5. In the panel that expands on the right, you can view all files in the file directory.

6. (Optional) Reference a file.

   You can click the "Copy" button or the  **+**  button to the right of a file to insert the file path into the conversation input box. Then, add a task description in the input box and send it to ArkClaw for execution.

## Open a folder

You can open a folder to view and manage the local directory associated with a project in your local file manager.

1. Log in to the ArkClaw client locally.

2. Switch to the target ArkClaw page.

3. In the left navigation pane, go to "Project" and select the target project folder.

4. Click the "··· \> Open folder" button.

5. The local file manager opens automatically, showing the directory associated with the project, where you can view and manage your local files.
