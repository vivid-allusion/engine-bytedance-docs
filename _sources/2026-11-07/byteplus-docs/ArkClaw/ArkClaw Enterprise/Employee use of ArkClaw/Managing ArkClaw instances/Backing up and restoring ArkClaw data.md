If ArkClaw experiences anomalies such as interface freezes or unresponsive operations that cannot be resolved by [restarting](http://volcengine.com/docs/87732/2431033?lang=zh) or [auto healing](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_of_ArkClaw__?lang=en), and you do not want to restore ArkClaw to factory settings, you may try restoring it from a backup to resolve the issue.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">This feature can fully restore the<strong> entire system and all data </strong>to the state at the time corresponding to your selected backup. After restoration, the system will be the same as its state when the backup was created.</div>


<span id="jviGykbv"></span>
## Auto\-backup


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Switch to the target ArkClaw page. In the upper\-right corner of the page, click the more icon.

3. Select the "Data backup" tab.

4. Perform the corresponding operations as needed.

   Automatic backups are generated by the system based on the preset rules. You can enable auto\-backup for 24\-hour uninterrupted auto\-backup, restore backups, or disable auto\-backup at any time.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The maximum retention period for auto\-backups is 24 hours, and they will be automatically deleted after 24 hours.   </div>
   

   
   <Tabs>
   <Tab zoneid="T68APpju8k" title="Enable auto-backup">
   <TabTitle>Enable auto-backup</TabTitle>
   
   By default, auto\-backup is enabled for new ArkClaw instances. If auto\-backup is disabled for your ArkClaw instance (for example, you have manually disabled it or auto\-backup is not automatically enabled), you can click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_2fb5397e4359f2ce08d78d74ba660840.png) </span> button to enable auto\-backup. After auto\-backup is enabled, the system automatically creates a backup for you every 24 hours.
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">The system only retains the latest backup each day. After a new daily backup is generated, it will automatically overwrite the backup of the previous day.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">By default, the auto\-backup time is set to the previous hour before the feature is enabled. When auto\-backup is enabled for the first time, no historical backup exists. The first backup will be created approximately 24 hours after auto\-backup is enabled.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">To adjust the backup Time, contact the administrator.</div>
   
   
   
   
   
   
   </Tab>
   <Tab zoneid="wzyMdsd5z1" title="Disable auto-backup">
   <TabTitle>Disable auto-backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After auto\-backup is disabled, the system will no longer perform auto\-backup. Existing backup data will be retained for 24 hours and then automatically cleared.</div>
   
   
   
   1. Click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9a98e99a5b359a22c5a14ac7a48c8476.png) </span> button on the "Auto\-backup" tab to disable auto\-backup.
   
   2. Click the "Confirm" button to complete the operation.
   
   
   </Tab>
   <Tab zoneid="ch9qvTOuYK" title="Restore automatic backup">
   <TabTitle>Restore automatic backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After you perform the auto\-backup restoration operation, the current data will be overwritten and restored to the time point corresponding to the backup. Proceed with caution.</div>
   
   
   
   1. On the "Automatic backup" tab, select the backup file to restore ArkClaw, and click the "Restore" button.
   
   2. Confirm the backup to restore and click the "Confirm" button to complete the operation.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After restoration, Arkclaw will restart. Please wait patiently.   </div>
      
   
   3. View the restoration result.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Archive restoration takes 1–2 minutes. Please wait patiently.   </div>
      
   
      * **Restored**: If "Arkclaw backup restored" appears, you can start a normal chat.
   
      * **Recovery failed**: If "Failed to restore ArkClaw backup" appears, you can retry restoration following the steps above, or access support via [feedback](https://docs.byteplus.com/en/docs/ArkClaw/Feedback_?lang=zh).
   
   
   </Tab>
   </Tabs>

## Manual backup

Manual backup requires you to actively create backup files. You can manually create a backup of the current system or data at any time as needed for subsequent restoration. This method can improve operational flexibility, effectively reduce exceptions caused by misoperations, and safeguard your data security.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">Manual backups have a maximum retention period of 30 days and will be automatically deleted after 30 days.</div>


* <div data-tips="true" data-tips-type="default">Each time you manually create or update a backup, a new backup is generated. When you create a new backup or perform a re\-backup, the system automatically overwrites the original backup and retains only the latest manual backup.</div>


* <div data-tips="true" data-tips-type="default">If auto\-backup is enabled, the system suspends auto\-backups while a manual backup is in progress, and resumes them after the manual backup completes.</div>


* <div data-tips="true" data-tips-type="default" data-wrapper-indent="0">Data automatically backed up when employees upgrade ArkClaw will overwrite data manually backed up by employees.</div>


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter to access the ArkClaw conversation page.

2. Switch to the target ArkClaw page and click the more icon.

3. Select the "Data backup" tab.

4. Perform the corresponding operations as needed.

   
   <Tabs>
   <Tab zoneid="i6nVQStU" title="Create manual backup">
   <TabTitle>Create manual backup</TabTitle>
   
   1. You can manually create a backup of the current system or data at any time as needed for subsequent restoration. This method can improve operational flexibility, effectively reduce exceptions caused by misoperations, and safeguard your data security.
   
   1. In the manual backup area, click the "Create backup" button.
   
   2. Enter the backup Name, and click "Confirm" to complete the procedure.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Backup creation is expected to take 2\-3 minutes. Please wait patiently.   </div>
      
   
   3. (Optional) Select the target backup, and click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_230120cf5b3576b528e7e79065649b4e.png) </span> icon to change the backup name.
   
   
   </Tab>

   1. Click the "Back up again" button on the "Manual backup" tab.
   
   2. Specify the backup name, and then click the "Confirm" button to complete the operation.
   
   
   </Tab>
   <Tab zoneid="WZUqYRbot5" title="Delete manual backup">
   <TabTitle>Delete manual backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After you delete a backup, it cannot be restored. Proceed with caution.</div>
   
   
   
   1. On the "Manual backup" tab, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_24415465a0f14dc8d04bf98bef3f9872.png) </span>.
   
   2. Confirm the backup to be deleted and click the "Confirm" button to complete the operation.
   
   
   </Tab>

   <TabTitle>Restore manual backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After restoration, current data will be lost and the system will be restored to the state corresponding to the backup. Proceed with caution.</div>
   
   
   
   1. On the "Manual backup" tab, select the backup file to restore ArkClaw, and click the "Restore" button.
   
   2. Confirm the backup to restore and click the "Confirm" button to complete the operation.

   3. View the restoration result.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Archive restoration takes 1–2 minutes. Please wait patiently.   </div>

      * **Recovery failed**: If "Failed to restore ArkClaw backup" appears, you can retry restoration following the steps above, or access support via [feedback](https://docs.byteplus.com/en/docs/ArkClaw/Feedback_?lang=zh).
