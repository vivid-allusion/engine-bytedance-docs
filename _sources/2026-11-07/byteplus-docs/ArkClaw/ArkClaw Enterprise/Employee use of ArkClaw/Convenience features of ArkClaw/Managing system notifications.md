To ensure you stay updated with the latest developments of ArkClaw in real time, BytePlus provides a system notification mechanism. When ArkClaw releases version updates and new features, the platform will push relevant information to you in a timely manner. Additionally, you can configure third\-party message channels (such as Feishu and WeChat) to receive relevant notifications anytime and anywhere.

<span id="V79jfrho"></span>
## View system notification details

This section uses viewing system notification details in ArkClaw as an example. You can also [modify system notification settings](https://docs.volcengine.com/docs/87732/2431037#PnVKTGTu) to receive and view notification details through third\-party message channels.


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Switch to the target ArkClaw page.

3. At the bottom of the left directory tree, click the system notification icon to view an overview of notifications related to the current ArkClaw.

4. You can click the target notification as needed to view its details in the pop\-up window.

## Modify system notification settings

After you configure Feishu, WeChat, and other [third-party message channels](https://docs.volcengine.com/docs/87732/2431025), the system will enable these channels for message push by default. You can enable or disable third\-party push services at any time based on your actual needs.


* **Enable**: Recommended. This can greatly improve notification delivery efficiency and avoid missing critical business information.

* **Disable**: To reduce message distractions, or if cross\-channel notification is not required in the current scenario, you can disable it at any time.

1. At the bottom of the left directory tree, click the "System notification icon \> Settings" icon.

2. In the pop\-up window, modify the message channels for receiving system notifications and notification preferences as needed.

   
   |Configuration item |Description |
   |---|---|
   |Receiving channel |Enable or disable third\-party message channels for receiving system notifications. <br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Make sure that the corresponding message channels have been configured for your ArkClaw. <a href="https://docs.volcengine.com/docs/87732/2430974?lang=zh">Learn more</a>.</div><br> |
   

3. Once ArkClaw completes the update, your new configuration will take effect immediately.
