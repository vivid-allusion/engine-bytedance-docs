ArkClaw supports viewing all outputs generated by the current session and uploaded reference files, previewing their content, downloading them to local devices, transferring them to the cloud disk, and sharing with department employees.

<span id="qwtOVqle"></span>
## View task outputs


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Switch to the target ArkClaw and select the target session task.

3. On the right side of the page, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_281f143fcb08591281d748b862f1a06c.png) </span>.

4. In the **Generated outputs** section, you can view all files generated in the current session.


<span id="iQdhndNx"></span>
## View uploaded files

In the task panel, you can view reference files uploaded in this session, making it easy to review the inputs used for the task at any time.


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Switch to the target ArkClaw and select the target session task.

3. On the right side of the page, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_281f143fcb08591281d748b862f1a06c.png) </span>.

4. In the **Upload files** section, you can view all files uploaded in the current session.


<span id="nDAT7KMK"></span>
## Preview files

<div data-tips="true" data-tips-type="default">Supports previewing PDF, web pages, code, and directory files.</div>


In the output file list, click the target file to preview its content. You can also click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ab3851edff2638bb56472ed9d602d5eb.png) </span> button to view in full screen. If the file cannot be previewed, you can download it locally to view.

<span id="ySOsHtVR"></span>
## Download outputs

After the task is completed, the output is only temporarily saved. Please download it to your local device or transfer it to your cloud disk promptly.

> If you do not have a personal cloud disk, you can [activate the personal cloud disk service](https://docs.byteplus.com/en/docs/ArkClaw/Personal_cloud_disks?lang=en) first.



1. In the output file list, click the target file.

2. Click the "Download" or "Save to cloud disk" button in the top toolbar to save the output file permanently.


<span id="E9iiYwNY"></span>
### Share outputs

You can share the generated output (PPT, PDF, image, static website, etc.) in the form of link for preview by enterprise internal employees as needed.

> When employees open the shared link, they need to log in via enterprise SSO first. Employees without Claw accounts cannot view the content. Contact the enterprise administrator to grant them access permissions.



1. In the output file list, click the target file.

2. On the opened file preview page, click the "Share" button.

3. In the pop\-up dialog box, click the "Copy link" button.

4. Send the copied link to the personnel who need to view the content.

   > The maximum size for a single shared file is 20 MB. If the size exceeds this limit, sharing is not supported. Download the file directly or streamline the content and try again.   
   

   5. (Optional) Download the output file to local storage or transfer it to the cloud disk.

   > To transfer to the cloud disk, you need to activate the personal cloud disk. If you have not activated it yet, refer to [How to activate personal cloud disk](https://docs.byteplus.com/en/docs/ArkClaw/Personal_cloud_disks?lang=en).
