If you encounter unsolvable issues while using ArkClaw or have new suggestions for ArkClaw, you can report issues or submit improvement suggestions to the administrator through the built\-in feedback feature.

<span id="emym87af"></span>
## Procedure


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter to access the ArkClaw conversation page.

2. Go to the target ArkClaw page.

3. At the bottom of the directory tree on the left, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_aa365bae9df3c0f32c230169b4b7834b.png) </span>.

4. In the dialog box that appears, select an issue type and describe the issue you encountered or the improvement suggestion.

5. (Optional) Upload a screenshot. To describe the issue more clearly, you can attach screenshots. You can add screenshots by clicking the upload button, dragging files, or pasting the screenshots directly.

   * **Supported formats**: PNG, JPG, and GIF.

   * **Size and quantity limits**: Each file must not exceed 10 MB, and you can upload up to 5 files.

6. Click the "Submit" button to complete the operation.

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Your feedback is submitted directly to the enterprise administrator, who will investigate the issue or optimize the feature configuration based on the feedback.   </div>
