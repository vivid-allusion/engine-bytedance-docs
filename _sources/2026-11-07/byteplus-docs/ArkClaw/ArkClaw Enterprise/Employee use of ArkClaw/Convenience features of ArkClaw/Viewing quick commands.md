ArkClaw includes preset commands for common operations, such as creating a new conversation, viewing system status, and clearing the context. You can send these commands with one click to let ArkClaw perform the corresponding operations.

<span id="BS60Xecf"></span>
## Procedure


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Go to the target ArkClaw page.

3. Enter the / symbol in the chat box to call up and view available quick commands and their purposes.

4. You can select the intended command using arrow keys and press Enter to confirm, or directly select it with your mouse.

5. You can view the command execution result based on the ArkClaw reply.
