## Installation of the Hermes Agent plugin

<span id="DcL3Kixj"></span>
### What should I do if ArkClaw fails to be upgraded?

ArkClaw must be upgraded to version `ark-1.2.3` or later to support installation of the Hermes Agent plugin. Upgrade failures may occur during the upgrade due to issues such as compatibility problems or network fluctuations. If the upgrade fails, ArkClaw (including partially upgraded system/components) will automatically roll back to the pre\-upgrade version. You can attempt the upgrade again by following the instructions in [Upgrading ArkClaw system/component versions](https://docs.byteplus.com/en/docs/ArkClaw/Upgrading_ArkClaw_version_), or seek technical support via [Feedback](https://docs.byteplus.com/en/docs/ArkClaw/Feedback_).

<span id="8Z0x2KRh"></span>
### How do I resolve the "The current disk space is less than 7 GB" error when I install the Hermes Agent plugin?

Installing the Hermes Agent requires **at least 7 GB** of available storage space. You can chat with ArkClaw and ask it to help identify safe, deletable cache and temporary files, and then delete them after your confirmation to free up storage.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="0">warning</div>


<div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">File deletion is a high\-risk operation. We recommend that you <a href="https://docs.byteplus.com/en/docs/ArkClaw/Backing_up_and_restoring_ArkClaw_data__?#iq0BqGqZ">manually back up</a> ArkClaw data and fully understand the purpose of the files to be deleted before deleting any data.</div>


1. You can view the current available storage space of ArkClaw on the "Status and usage" tab of the ArkClaw details page.

2. Ask ArkClaw to find and clean up safely deletable npm download cache.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The npm cache stores local copies of installation packages. Cleaning this cache is safe and typically frees up 3–5 GB of storage. The only impact is that dependencies with the same name will need to be downloaded again during the next installation.   </div>
   

   1. Detect and evaluate safely deletable files.

      **Prompt** **: ** Check the system npm cache directory (such as ~/.npm), and list the safely deletable npm download cache files with their sizes, purposes, and deletion risks.

   2. Clean up files.

      **Prompt:**  Safely clean up the above npm download cache files. After cleanup, recheck and tell me how much storage space has actually been freed.

3. If available storage is still less than 7 GB after cleaning the npm cache, you can clean up unused ArkClaw plugins.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Deleting ArkClaw plugins is a <strong>high\-risk</strong> operation. Many core ArkClaw features depend heavily on certain built\-in plugins. Accidental deletion may cause corresponding features to become unavailable. We strongly recommend that you perform this operation only when storage capacity is extremely limited.   </div>
   

   1. Detect and evaluate safely deletable files.

      **Prompt** **:**  Scan and list the currently installed plugins on ArkClaw with their disk usage, and briefly describe their purpose and deletion risks. We recommend that you prioritize the deletion of old backup directories and unused message channel plugins. [Strict security constraints]: lancedb, apmplus, arkclaw\-mode\-switch, ai\-assistant\-security, env\-logger, skill\-switch, and many others are core dependencies and must not be deleted. Based on the above constraints, filter and output a "recommended safe deletion list".

   2. Clean up files.

      **Prompt:**  I confirm that I no longer need the <mark>XX</mark> plugin. Safely uninstall it and completely delete its directory and residual cache. Do not modify any core dependencies. After completion, tell me how much storage space has been freed.

      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="default" data-wrapper-indent="2">Replace <mark>XX</mark> with the actual plugin name you want to delete, such as <code>qqbot</code>.      </div>

### How do I resolve Hermes Agent plugin installation failures?

The Hermes Agent plugin may fail to be installed due to compatibility issues. You can:


1. Follow the guidance in [Auto healing of ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_of_ArkClaw__) to repair ArkClaw, and then try installing the Hermes Agent plugin again.

2. If the plugin still fails to be installed, you can obtain technical support via [feedback](https://docs.byteplus.com/en/docs/ArkClaw/Feedback_).


<span id="qOI3A1YN"></span>
### How do I resolve the "plugin already exists" error during the Hermes Agent plugin installation?

This issue occurs because the Hermes Agent plugin has already been installed on your ArkClaw. You can:


1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_).

2. Execute the following commands to download and run the Hermes Agent plugin uninstall script.

   ```Bash
   REGION=$(curl --connect-timeout 5 --max-time 10 -s "http://100.96.0.96/latest/region_id"); curl -fsSL "https://scarif-${REGION}.tos-${REGION}.ivolces.com/arkclaw/hermes/hermes-uninstall.sh" -o hermes-uninstall.sh
   bash hermes-uninstall.sh --yes
   ```
   

3. Install the Hermes Agent plugin again.


<span id="v1lLvfKi"></span>
### How do I resolve ArkClaw restart failure after I install the Hermes Agent plugin?

After the Hermes Agent plugin is installed, the ArkClaw gateway must be restarted for it to take effect. The restart may fail due to various compatibility issues. In this case, you can manually [restart ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Restarting_ArkClaw__). Once the restart is complete, the Hermes Agent plugin will take effect automatically.

### How do I view the installation logs of the Hermes Agent plugin?

The installation logs of the Hermes Agent plugin are stored in the `/var/log/hermes-agent/` directory. You can check the installation process and detailed error information through these log files.


<Tabs>

1. Disable Hermes.

2. Send a prompt to ArkClaw to view related logs. For example: Help me view the latest Hermes installation log in the /var/log directory.


</Tab>

<TabTitle>View via the terminal</TabTitle>

1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_).

2. Execute the following command to view the latest 200 installation logs.

   ```Bash
   sudo tail -n 200 "$(ls -1t /var/log/hermes-agent/upgrade-*.log | head -n 1)"
   sudo docker logs --tail 200 hermes-agent
   ```

### Will the installation files of the Hermes Agent plugin be automatically deleted after installation?

No, the installation files of the Hermes Agent plugin will not be automatically deleted. They are stored in the `/var/cache/hermes-agent` directory. You can delete them as needed:


<Tabs>
<Tab zoneid="Ch7KBnZ5" title="Via the conversation">
<TabTitle>Via the conversation</TabTitle>

1. Disable Hermes.

2. Send a prompt to ArkClaw to delete related files. For example: Delete the /var/cache/hermes\-agent directory and all files in it.


</Tab>
<Tab zoneid="IgakfCpX" title="Via the terminal">
<TabTitle>Via the terminal</TabTitle>

1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_).

2. Execute the following command to forcibly delete the Hermes Agent cache directory and its files.

   ```Bash
   rm -rf /var/cache/hermes-agent
   ```
   





</Tab>
</Tabs>

## Usage of Hermes Agent

<span id="r0g2dejP"></span>
### How do I resolve issues such as "Failed to enable/disable Hermes", "Failed to read configuration file" or "Failed to parse configuration file" when I enable or disable Hermes Agent?

This issue is usually caused by compatibility issues resulting from manual modifications to the ArkClaw configuration file. You can follow the guidance in [Auto healing of ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_of_ArkClaw__) to repair ArkClaw, and then try enabling or disabling Hermes Agent.

<span id="UstZAXzH"></span>
### Where is the data generated by Hermes Agent?

The output results, accumulated skills, and other data generated by Hermes Agent after task execution are stored in the `/opt/hermes-data` directory by default.

<span id="0lbPKxm7"></span>
### Will the historically generated data still exist after I delete the Hermes Agent container?

The output results, accumulated skills, and other data generated by Hermes Agent after task execution are stored in the `/opt/hermes-data` directory by default. Deleting the Hermes Agent Docker container will not delete the data.

<span id="vKpCetXN"></span>
### How do I uninstall the Hermes Agent plugin?


1. Hermes Agent plugin.

   1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_).

   2. Execute the following command to uninstall the Hermes Agent plugin and delete its cache and historical data.

      ```Bash
      REGION=$(curl --connect-timeout 5 --max-time 10 -s "http://100.96.0.96/latest/region_id"); curl -fsSL "https://scarif-${REGION}.tos-${REGION}.ivolces.com/arkclaw/hermes/hermes-uninstall.sh" -o hermes-uninstall.sh
      bash hermes-uninstall.sh --yes
      ```
      

2. Confirm that the Hermes Agent plugin has been completely uninstalled.

   
   <Tabs>
   <Tab zoneid="XVxRM3ps" title="Via the conversation">
   <TabTitle>Via the conversation</TabTitle>
   
   1. Disable Hermes.
   
   2. Send a prompt to ArkClaw and check whether related documents still remain. For example: Help me check whether the Hermes container, cache, and data directory still exist.
   
   
   </Tab>
   <Tab zoneid="bvYYKrAz" title="Via the terminal">
   <TabTitle>Via the terminal</TabTitle>
   
   Execute the following command to check whether the Hermes container, cache, and data directory still exist.
   
   ```Bash
   docker ps -a | grep hermes-agent
   docker images | grep hermes-agent
   ls -la /root/.openclaw/extensions | grep openclaw-plugin-hermes
   ```
   
   
   If none of the commands returns any output, it indicates that the Hermes Agent plugin has been completely uninstalled.

### Can Hermes Agent be used through channels integrated with ArkClaw (such as Feishu and WeChat)?

Yes. After enabling the Hermes feature in the ArkClaw console, you can add the instruction "Assign the task to Hermes for execution" when sending messages via channels integrated with ArkClaw (such as Feishu and WeChat).

**Sample prompt:** 

Assign the task to Hermes for execution: Use the bash/shell command in the terminal to randomly generate an English string of 100 characters, and then count and output the number of occurrences of the lowercase letter a.

<span id="6HeLHSiz"></span>
### How do I read files generated by Hermes?

Hermes currently runs inside a Docker container. For file pass\-through, Hermes can generate or move files to the /opt/data directory, and you can view the files under /opt/data\-hermes in the terminal.

<span id="f4kcCsGc"></span>
### How do I ensure that ArkClaw sends the original prompt directly to Hermes Agent?

If you want ArkClaw not to modify your prompt information at all and send it completely to Hermes Agent for execution, you can explicitly tell ArkClaw **not to add additional instructions** in the prompt.

**Sample prompt:** 

Send this command to Hermes (do not add any additional instructions): Use the bash/shell command in the terminal to randomly generate an English string containing 100 characters, and then count and output the number of occurrences of the lowercase letter a.

<span id="6LH9RvYe"></span>
### **Why are tasks still** processed by ArkClaw when the Hermes switch is turned on?

In some scenarios, context in the conversation may lead to incorrect routing decisions by ArkClaw, so that tasks are not properly routed to Hermes. You can correct this by sending the following prompt in the conversation: **Let Hermes execute this instruction: <your specific instruction content\>** .

<span id="IURskC9F"></span>
### **Why are tasks still processed by Hermes when the Hermes switch is turned off?** 

In some scenarios, context in the conversation may lead to incorrect routing decisions by ArkClaw, so that tasks are not properly routed to ArkClaw. You can correct this by sending the following prompt in the conversation: **Execute this instruction by yourself. There is no need to dispatch it to Hermes**.

### How do I replace the model used by Hermes Agent?

You currently cannot update the model used by Hermes Agent through the ArkClaw console. You can follow these steps to change the model:


1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_?lang=en).

2. Execute the following command to download the script for changing the model used by Hermes Agent.

   ```Bash
   REGION=$(curl --connect-timeout 5 --max-time 10 -s "http://100.96.0.96/latest/region_id"); curl -fsSL "https://scarif-${REGION}.tos-${REGION}.ivolces.com/arkclaw/hermes/hermes-model-switch.sh" -o hermes-model-switch.sh
   ```
   

3. Execute the corresponding command as needed to change the model used by Hermes Agent via scripts.

   
   <Tabs>
   <Tab zoneid="ANblbe6f" title="Replace model only">
   <TabTitle>Replace model only</TabTitle>
   
   Use this method if you only need to change the model without adjusting the provider or URL.
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">In this scenario, executing the command <strong>restarts</strong> the Docker container where Hermes Agent runs, which might interrupt running tasks. Perform this operation when Hermes Agent is idle.</div>
   
   
   ```Bash

   ```

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="0">If you use a model from <a href="https://console.byteplus.com/ark/region:ark+cn-beijing/model?groupType=ModelGroups&vendor=Bytedance&view=DEFAULT_VIEW">ModelArk "Foundation models"</a>, enter the target model ID.</div>
   
   
   
   </Tab>
   <Tab zoneid="fFywJpyN" title="Replace both model and service provider">

### How do I resolve the error "ACP error [\-32603]: Internal error" when Hermes executes a task?

This issue usually occurs because the inference model used by Hermes is incorrectly configured or has reached the model quota limit. Accordingly, you can:


* [Change the model used by Hermes Agent](https://docs.byteplus.com/en/docs/ArkClaw/Hermes_Agent_FAQ__?lang=en#v74PxqcF).

* Wait for the model quota to be restored. For example, if you are using the ModelArk Coding Plan, you can go to the [Coding Plan console ](https://console.byteplus.com/ark/region:ark+cn-beijing/openManagement?LLM=%7B%7D&advancedActiveKey=subscribe)to view quota\-related details and the quota refresh time.

### How do I view information about the inference model used by Hermes Agent?

You can view information about the inference model used by Hermes Agent in the configuration file `/opt/hermes-data/config.yaml`.


1. [Open the ArkClaw terminal](https://docs.byteplus.com/en/docs/ArkClaw/Accessing_ArkClaw_from_terminals_?lang=en).

2. Execute the following command to view the inference model used by Hermes Agent.

   ```Bash
   cat /opt/hermes-data/config.yaml | grep default: | head -n 1
   ```
   

   When an output similar to the following is displayed, the current model used by Hermes Agent is `doubao-seed-2-0-code-preview-260215` .
