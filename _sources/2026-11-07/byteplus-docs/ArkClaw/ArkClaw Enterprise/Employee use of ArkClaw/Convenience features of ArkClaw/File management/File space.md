During daily use, ArkClaw generates a large number of files (such as PPTs, documents, images, videos, and code) in its workspace (path: `/root/.openclaw/workspace`) based on your task requirements. The platform provides the "File space" feature, allowing you to upload, download, browse, and delete files in this directory while ensuring system security.

<span id="q6VyNyWh"></span>
## File category description

Workspace files are displayed in three categories in your file space. ** Output files ** are shown by default, and you can switch to ** Uploaded by me ** and **All files** categories to view files under the corresponding category.


|**Type** |Description |
|---|---|
|Output files |Output files generated by a task or an agent that you pay close attention to (such as PPTs, documents, images, and code generated by ArkClaw). |
|Uploaded by me |Files or folders that you proactively upload to the workspace (including files uploaded through a conversation), as well as folders that you create yourself. |
|All files |Displays all files in the workspace, including output files, your uploads, and system files. |


<span id="146n9nQS"></span>
## View workspace file information


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter to access the ArkClaw conversation page.

2. Switch to the target ArkClaw Enterprise page, and select "File management" in the left\-side directory tree.

3. Select the "File space" tab.

4. You can quickly locate a target file in the following ways.

   > If you are prompted that the claw\-prism\-plugin plugin is not installed or its version is outdated, click the "Check for updates" button. In the dialog box that appears, confirm the plugin update and click "Confirm" to complete the upgrade.   
   

   * Filter by category: Click the "Output files" button, and then select "Output files", "Uploaded by me", or "All files" from the drop\-down list.

   * Filter by file type: Click the "All types" button and then select Document, PPT, PDF, Image, Video, Audio, Website, Markdown, Code, Compressed package, or Other from the drop\-down list.

   * Filter by agent type: Click the "All agents" button and select the target agent from the drop\-down list. This feature is available only when the file category is set to Output files.

   * Search by keyword **:**  Enter a file name keyword in the search box, and the system matches files within the current view.

## Upload/Download files

You can upload local corpus, configuration files, and other data to the workspace for ArkClaw to use. For files generated by ArkClaw in the workspace, you can also download them to your local devices without transfers via the personal cloud disk.


<Tabs>
<Tab zoneid="kxq3TlCl" title="Upload file/folder">
<TabTitle>Upload file/folder</TabTitle>

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">You can upload files only in certain formats, including <code>.md</code>, <code>.txt</code>, <code>.pdf</code>, <code>.json</code>, <code>.yaml</code>, <code>.csv</code>, <code>.py</code>, <code>.png</code>, and <code>.jpg</code>.</div>


* <div data-tips="true" data-tips-type="warning">You can only upload files or folders up to <strong>2 GB </strong>in size.</div>


* <div data-tips="true" data-tips-type="warning">Ensure that your ArkClaw has sufficient storage capacity to store files to be uploaded. Otherwise, the upload fails.</div>


1. On the **File space** tab, click the "Upload" button and select "Upload file" or "Upload folder" as needed.

   > To upload files to a specific directory, first enter the target directory and then perform the upload.   
   

2. In the pop\-up window, select the local file or folder you need to upload to ArkClaw.

3. You can view the upload progress in the lower right corner. Before the upload is complete, you can pause or delete the upload task as needed.

4. After the file is uploaded, click "... \> Reference to task" on the right of the file to reference it in the chat box and have ArkClaw use this file to complete the task. For details, refer to [Reference files to tasks](https://docs.byteplus.com/en/docs/394/104388#ccaUG1n7).


</Tab>
<Tab zoneid="qcpA6lCD" title="Download workspace file/folder">
<TabTitle>Download workspace file/folder</TabTitle>

1. You can instruct ArkClaw via prompts to save generated results to a specific workspace directory.

   * **Sample prompt:** 

      Help me research the top 10 most downloaded skills in ClawHub, and summarize their features, highlights, installation methods, and other information into a document, and place the document in your .openclaw/ai_news folder.

2. In the file space, click the "Output files" button.

3. Click "... \> Download" on the right of the target file/folder.

4. The file is then automatically downloaded through your browser.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">ArkClaw then automatically compresses the folder into <code>.tar</code> format. The folder is downloaded through your browser.   </div>
   


</Tab>
</Tabs>

## More operations

You can also create, delete, share, and move files or folders within your ArkClaw workspace or transfer them to your cloud disk.


|Actions |Description |
|---|---|
|Reference files to tasks |You can reference files from file space directly to a task, without uploading them again.<br><br><br>1. In the file list, select one or more files to be referenced.<br><br>   * Single file: Select "··· \> Reference to task" on the right of the target file.<br><br>   * Multiple files: Select the target files, and click "Reference to task" at the bottom of the page.<br><br>2. In the pop\-up dialog box, select a reference method:<br><br>   * **Reference to a new task**: Use the selected file as input to create a new task conversation.<br><br>   * **Reference to an existing task**: Add the selected file to the conversation context of an existing task.<br><br>3. After you make your selection, click the "Confirm" button. The system redirects you to the corresponding task page, where you can continue entering commands and interacting with ArkClaw. |
|Preview files |You can preview files in the workspace directly in file space without downloading them locally first.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Only certain file types can be previewed. Actual supported file types take precedence.</div><br><br><br><br>1. In the file list, click the name of the target file.<br><br>2. A preview window pops up in the center of the page, where you can view the file content.<br><br>3. To view in full screen, click the "Full screen" button in the upper\-right corner of the preview window to switch to the full\-screen preview.<br><br>4. During preview, you can perform the following operations from the toolbar in the upper\-right corner:<br><br>   * **Edit**: Click the "Edit" button to visually edit the file content.<br><br>   * **Download locally**: Click the "Download" button to save the currently previewed file to your local device.<br><br>   * **Share**: Click the "Share" button to generate a short link for the current file and share it.<br><br>   * **Copy**: Click the "Copy" button to copy the current file.<br><br>   * **Save to cloud disk**: Click the "Save to cloud disk" button to save the current file to the cloud disk.<br><br>5. Click the  **×**  button in the upper\-right corner to close the preview window and return to the file list. |
|Share outputs |To share output files or uploaded files with external collaborators, generate a link and send it to them for file viewing.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="default">You can share only the following file types: web pages, code files, images, PDFs, and PPTs.</div><br><br><br>* <div data-tips="true" data-tips-type="default">Files larger than 8 MB cannot be shared.</div><br><br><br>1. In the file list, select the file to be shared.<br><br>2. In the pop\-up dialog box, click "Copy link" and share the link with collaborators. |
|Move a file/folder |To archive files by project or category, you can move uploaded or newly created files and folders to another directory in the workspace.<br><br><br>1. In the file list, click "... \> Move" on the right of the file or folder to be moved.<br><br>2. In the directory tree of the dialog box, select the target directory (for example, git), and then click "Confirm" ** to ** complete the operation. |
|Rename a file/folder |You can rename your uploaded or newly created files and folders for semantic categorization as needed.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Only files under the "All files" category can be renamed. The renaming operation is unavailable after you switch to the "Output files" or "Personal files" category.</div><br><br><br><br>1. In file space, click the category drop\-down menu at the top, and then select "All files".<br><br>2. In the file list, locate the file or folder you want to rename, and click "... \> Rename" on the right of the target file or folder.<br><br>3. Enter the new name in the pop\-up window ** and** click the "Confirm" button to complete the operation. |
|Transfer to cloud disk |If you need to store uploaded project files or output files for the long term, you can save them using the "My cloud disk" feature.<br><br><br>1. In the file list, locate the target file and click the "... \> Transfer to cloud disk" button on the right.<br><br>2. When the system returns "Transferred to cloud disk", the file has been transferred.<br><br>   > The system will automatically create a folder named **Transferred files** in **My cloud disk \> Personal cloud disk**.   <br>   <br><br>3. Select the "My cloud disk" tab, and then click "Transferred files" to view transferred files. |
|Create folders |If you plan to upload files of different projects or categories, you can create multiple folders to categorize, making it easier for ArkClaw to read files from the corresponding directories as needed for different tasks.<br><br><br>1. Click the "Create folder" button.<br><br>2. Enter the folder name in the pop\-up window and click the "Confirm" button to complete the operation. |
|Delete a file/folder |If you no longer use a specific folder and all the files within it, you can delete the folder to free up storage space.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">To ensure the operational security of your ArkClaw instance, you cannot delete the core files, such as system and environment configuration files. For example, you cannot delete files such as <code>openclaw.json</code>, <code>.env</code>, and <code>update-check.json</code>.</div><br><br><br><br>1. Click "... \> Delete" on the right of the target file/folder.<br><br>2. After confirming the risk information in the pop\-up window, click the "Confirm" button to complete the operation. |
