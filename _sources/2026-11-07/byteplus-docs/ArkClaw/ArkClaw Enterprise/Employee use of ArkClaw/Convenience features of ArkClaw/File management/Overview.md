ArkClaw offers a variety of features for file\-related operations, including cloud storage for large files and local workspace file management. This topic discusses the features and differences of each feature, as well as its use cases, to help you select the best method for your needs.

<span id="FprNbr1t"></span>
## Feature summary


|**Feature** |**Description** |Use cases |
|---|---|---|
|Managing ArkClaw workspace files |You can manage files directly in the ArkClaw workspace (`/root/.openclaw/workspace` directory) through the file space. |This feature is ideal for **simple, everyday file management**. You can manipulate files directly in the ArkClaw workspace, eliminating the need for a conversation or cloud storage. This feature is free.<br><br>For example, you can upload a PDF of a contract to the workspace, and ArkClaw will extract the key clauses and generate a summary. |
|* Claw cloud disks<br><br>* Personal cloud disks |In ArkClaw, you can mount a TOS bucket as an independent cloud disk for uploading, downloading, and storing files.<br><br><br>* Personal cloud disk: The storage space of a personal cloud disk is shared by all Claw instances under the current account.<br><br>* Claw cloud disk: A Claw cloud disk contains only the disk space of the current Claw instance. |This feature is ideal for exchanging **large files** with ArkClaw or for **long\-term, format\-agnostic file storage**. The cloud disk is mounted as a separate disk, so it does not consume ArkClaw's storage space.<br><br>For example, you can upload a 3 GB video clip to the cloud disk and use ArkClaw's intelligent editing features. |
|Uploading and processing files |This feature supports local file uploads, file selection from cloud storage, file previews, intelligent processing, and zoomed previews. You can incorporate file content directly into conversations for analysis and processing, which improves information processing efficiency. |This feature is ideal for scenarios in which you need to quickly upload local files to ArkClaw for **AI processing**.<br><br>It can be used for document interpretation, image analysis, material organization, content extraction, and Q&A. |
