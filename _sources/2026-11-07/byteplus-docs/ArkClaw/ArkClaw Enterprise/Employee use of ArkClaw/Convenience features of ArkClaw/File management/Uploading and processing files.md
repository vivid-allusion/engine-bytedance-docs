ArkClaw offers local file uploads, file selection from cloud storage, file previews, intelligent processing, and zoomed previews. You can easily identify files and perform in\-depth analyses by selecting cloud disk files, uploading local files, or copying and pasting files. This enriches your chat scenarios and improves processing efficiency.

<span id="CL3j0BBE"></span>
## Notes


* You can upload as many images as you like, but the total size cannot exceed 5 MB.

* You can adjust the inference model flexibly based on your business scenario and usage needs to achieve the most suitable interaction effect. The Doubao large model is recommended.

   > The minimax\-m2.5, glm\-4.7, and deepseek\-v3.2 models do not currently support this feature.   
   

<span id="roPHrXRN"></span>
## Steps


1. Open a browser, enter the ArkClaw login link in the address bar, and press "Enter" to access the ArkClaw chat interface.

2. Paste or upload the file you want to analyze into the chat box.

   * Paste the file directly into the chat box.

   * Upload the file

      1. Click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_bd930518b0eeceff4f16c923ebe3a3bd.png) </span> icon in the lower\-left corner of the chat box.

      2. Click either "Select cloud disk file" or "Upload local file" and select the desired file.

3. Specify your processing requirements for the file in one of the following ways.

   * Choose from the recommended prompts: In the box that appears, refer to the system recommendations to select an image processing prompt.

      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="default" data-wrapper-indent="2">ArkClaw provides three predefined prompts for image files: "Explain the image", "Extract text from the image", and "Analyze the key points of the image". Selecting a prompt enables you to swiftly generate an image analysis instruction, eliminating the need for manual editing and enhancing efficiency.      </div>
      

   * Enter your requirements manually: Type your specific processing requirements for the file directly into the chat box.

4. View the file processing result in the ArkClaw response.

5. (Optional) You can also perform the following operations on image files:

   * Preview an image: Click the image to view it.

   * Switch between multiple images: Click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e6bde34ca6eba7d5c9d429fece908228.png) </span> or <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_41065c289eaa7696d9d93854f26879da.png) </span> icon to switch freely between different images to compare or view them.

   * Zoom an image: Scroll the mouse wheel to zoom in or out of an image to see more details.
