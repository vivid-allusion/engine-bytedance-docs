ArkClaw provides cloud disks that allow you to manage files, including uploading and downloading them.

<span id="GXUSG2yt"></span>
## Prerequisites

You will have access to this feature once the administrator assigns you cloud disk permissions.

<span id="CufFU8fX"></span>
## Notes


* We recommend clicking the refresh icon ( **↻** ) in the upper\-right corner after a file operation to manually refresh the list and get the most up‑to‑date view.

* The files in the "Enterprise cloud disk" at `/public/arkclaw-team` are used to store agent templates. To manage these files, go to "Agent Center \> Agent Square".

* The maximum size allowed for a single file upload is 5 GB.

* The maximum size for a single file in image search is 10 MB.

* The maximum size allowed for a single file download is 512 MB. The maximum size for a batch download is 1 GB.

* The name cannot end with a space or a period (`.`), and it cannot contain any of the following characters: `\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `|`, or `'`.


<span id="eselCPh6"></span>
## Cloud disk types

"Personal cloud disk": A private storage space accessible only to the owner, suitable for storing personal work files.

"Enterprise cloud disk": A shared storage space accessible to all organization members. It is suitable for storing public documents and collaborative files. Each organization can create one enterprise cloud disk.

"Team cloud disk": A team\-level shared storage space accessible only to team members. It supports collaborative access by multiple members. It is ideal for collaborating and sharing files within a specific user group or project. Administrators can create multiple team spaces from the ArkClaw Enterprise console.

<span id="qu8UeaGo"></span>
## Configure a cloud disk


1. Open a browser, enter the ArkClaw login link in the address bar, and press "Enter" to access the ArkClaw chat interface.

2. Select the desired ArkClaw instance. Then, select "File management" in the left navigation pane.

3. On the "My cloud disk" page, select "Personal cloud disk", "Enterprise cloud disk", or "Team cloud disk", and then click "Mount now" to enable the cloud disk feature.


<span id="GeRADwdc"></span>
## Search for a file

On the "My cloud disk" page, click the search box or the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_639c2dd3c1cb922421736cd948adc9db.jpeg) </span> icon. Then, select a search method based on your needs:


* "Semantic search"

   1. In the upper\-right corner of the pop\-up window, select the search type. The default is all types, but you can switch to video, image, document or file name.

   2. Enter the file information you want to search for in the box and click the search icon <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8b861279f853cb97a9f28e6a15235210.jpeg) </span>.

* "Image search"

   Upload an image using any of the following methods, and click "Search now":

   * Click "Click to upload". Then, choose the file you want to upload and click "Open".

   * Click "Select from cloud disk". In the "Please select a cloud disk file" dialog box, choose the file you want to upload and click "Select".

On the "My cloud disk" page, you can quickly upload and download files and create new folders.


|Supported operations |Steps |

Then, choose the file you want to upload and click "Open".<br><br>3. Alternatively, navigate to the target directory and drag and drop the file directly into it. |
|Download files |* To download a single file:<br><br>   Select the file you want to download and click "... \> Download" in the "Actions" column. |Delete files |* To delete a single file:<br><br>   1. Select the file you want to remove and click "... \> Delete" in the "Actions" column.<br><br>   2. In the "Delete confirm" dialog box, click "Delete" to delete the file.<br><br>* To delete files in batches:<br><br>   1. Select the files you want to delete and click "Delete" at the bottom.<br><br>   2. ## Transfer history

You can quickly view task history from the cloud disk page.


|Supported operations |Steps |
|---|---|
|View upload tasks |1. On the "Team cloud disk" page, click "Upload \> Transfer history" in the upper\-right corner **.** <br><br>2. In the "transfer history" panel, click the "Upload" tab to view the list of ongoing tasks and file upload progress. |
|View delete tasks |1. On the "Team cloud disk" page, click "Upload \> Transfer history" in the upper\-right corner **.** <br><br>2. In the "transfer history" panel, click the "Delete" tab. You can then find the deleted files or folders in the list. |
