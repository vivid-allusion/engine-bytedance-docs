ArkClaw provides the enterprise application feature, enabling employees to use unified enterprise applications.

<span id="cCPD9GH8"></span>
## Procedure


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Go to the target ArkClaw page on the left.

3. Call an application and initiate a request.

   
   <Tabs>
   <Tab zoneid="a4opLlnkHg" title="Agent applications">
   <TabTitle>Agent applications</TabTitle>
   
   * **Application sources**
   
         * **My agents**: In the left pane, click "Agent Gallery". On the "BytePlus featured" or "Enterprise templates" tab, hover over the target agent application card, and click "Add and initiate task".
   
         * **Public agents**: Enterprise public agent applications are registered by the enterprise administrator and made available to employees. To use more applications, contact the administrator to register.
   
   * **Procedure**
   
      1. Enter `@` in the input box to call an agent application, and select the type corresponding to the agent you need to call.
   
      2. Click the target agent application name, enter the command to be executed, and send the command.
   
         * Call an agent application from "My agents"
   
         * Call an agent application from "Public agents"
   
            <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="3">tip         </div>
            
   
            <div data-tips="true" data-tips-type="default" data-wrapper-indent="3">Plugin installation is required for first\-time use of the "Public agents" feature. Click the "Install" button and wait for the installation to complete. Then, you can use multiple public agents.         </div>
            
   
      3. (Optional) OAuth authorization is required for some agent applications on the first call. If the ArkClaw conversation page displays the prompt "Please complete authorization first", click the "Authorize now" button and follow the on\-screen instructions to complete the authorization.
   
         > To re\-initiate the authorization, click the "Reopen authorization page" button and complete the authorization.      
         
   
      4. ArkClaw will use the relevant agent application to execute the command and return the result.
   
   
   </Tab>
   <Tab zoneid="WrXwQ6jnaG" title="MCP applications">
   <TabTitle>MCP applications</TabTitle>
   
   <div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>
   
   
   <div data-tips="true" data-tips-type="default">All MCP applications are registered by the enterprise administrator and made available to employees. To use more MCP applications, contact the administrator to register.</div>
   
   
   
   1. Click " **+** " below the command input box, click "MCP", and select the MCP application you need to use.
   
   2. Enter `/` in the input box, and click the "MCP" tab to call MCP applications quickly.
   
   3. For the first\-time use, plugin installation is required. Click the "Install" button and wait for the installation to complete.
   
   4. (Optional) OAuth authorization is required for some MCP applications on the first call. If the ArkClaw conversation page displays the prompt "Please complete authorization first", click the "Authorize now" button and follow the on\-screen instructions to complete the authorization.
   
      > To re\-initiate the authorization, click the "Reopen authorization page" button.   
      
   
   5. Click the target MCP name, send the target command. ArkClaw will use the MCP application to execute the command and return the result.
   
   
   </Tab>
   </Tabs>
