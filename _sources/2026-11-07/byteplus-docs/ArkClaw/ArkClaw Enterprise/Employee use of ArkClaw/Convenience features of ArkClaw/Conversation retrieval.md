Conversation retrieval allows you to quickly search historical task content by keyword and jump to the corresponding conversation with one click. Whether you need to review previous communication details or continue a conversation in a previous conversation, this feature helps you locate information efficiently. This feature covers various retrieval scenarios, including titles, body text, phrases, multiple keywords, entities, and code.

<span id="pdbApSeK"></span>
## Limits

The time range and quantity limits for conversation retrieval are as follows:


* **Time range**: You can retrieve conversations within the past 30 days.

* **Quantity limit**: You can retrieve the most recent 1,000 conversations.


<span id="pYhTOCag"></span>
## Procedure


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Go to the target ArkClaw page.

3. In the left navigation pane, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9cbdb192341f2ce88f23747e4ce93b18.png) </span> button or use the shortcut key `⌘ + K` (macOS)/`Ctrl + K` (Windows/Linux).

4. If the **New version available** dialog box appears, click the "Update now" button to complete the installation of the conversation retrieval plugin. After the installation is complete, you can start using the conversation retrieval feature.

5. In the pop\-up input box, enter the name of the target task or conversation keyword **.** 

6. Select and enter:

   * In the search result list, click the target task.

   * Use the keyboard arrow keys ↑/↓ to switch the selected item, and press **Enter** to confirm navigation.
