Based on industry best practices, BytePlus has multiple high\-quality templates preset in the ArkClaw platform. This aims to help enterprises implement AI capabilities quickly and cost\-effectively.

<span id="wp3zjKkU"></span>
## **Step 1: Enter Agent Gallery**


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. In the left\-side navigation pane, click "Agent Center".

3. Click the Agent Gallery tab to open it.


<span id="sRzn93KD"></span>
## Step 2: Find and locate a template

Quickly locate an agent template by global browsing, template type, or precise search.


* **Global browsing**: All expert templates are displayed as cards, with each card corresponding to a specific business scenario (for example, video generation expert and document parsing expert).

* **Template types**: Three types of templates are supported: BytePlus featured, enterprise templates, and enterprise shared templates.

   * **BytePlus featured**: Preset templates curated and maintained by BytePlus. They cover common business scenarios (such as Product expert, Technical review expert, and A\-share analyst) and are verified by the platform for out\-of\-the\-box use.

      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="default" data-wrapper-indent="2"><strong>BytePlus featured</strong> templates are visible to all users by default. If this capability is not visible on the template center page, it may have been disabled by the enterprise administrator. Contact your enterprise administrator to re‑enable it.      </div>
      

   * **Enterprise templates**: Exclusive custom templates created and maintained by your enterprise. They are typically designed for specific internal business workflows or role requirements. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Adding_agents_and_managing_my_agents?lang=en#BkjHP8CY).

   * **Enterprise shared**: Templates shared with the team by your enterprise administrator. 

* **Precise search**: Enter the template name or a core keyword in the search box at the top\-right corner of the page to quickly locate the target template.


<span id="0JF895qF"></span>
## Step 3: Evaluate and select the target template

View template details, then evaluate and select the appropriate target template.

**Capability details**

Select the target template and click "View details" to view the template details, including "My introduction", "What can I do for you?", "You can start like this", and "Built\-in skills". This helps you decide whether the template matches your business scenario.


* **My introduction**: Provides a brief description of the agent's core feature to help you quickly determine whether it meets your current business needs.

* **What can I do for you?** : Lists major applicable scenarios of the agent for your reference.

* **You can start like this**: Provides a variety of preset example scenarios and automatically fills in example prompts, helping you quickly try out the agent and experience its capabilities and performance. Procedure:

   1. Click the example scenario that meets your needs.

   2. Try the agent and view the execution results:

      **If the agent has been added**

      If the agent [has been added to the target agent team](https://docs.byteplus.com/en/docs/ArkClaw/Adding_agents_and_managing_my_agents?lang=en), the system will automatically prefill the example prompt (prefilled content) in the input box of a new conversation. You can manually send the prefilled content directly, or edit and optimize the prompt (prefilled content) based on your business needs before manual submission and sending.

      **If the agent has not been added**

      If the agent has not yet been added to the target agent team, the system will automatically [add it to your agent team](https://docs.byteplus.com/en/docs/ArkClaw/Adding_agents_and_managing_my_agents?lang=en) and prefill the example prompt (prefilled content) in the input box of a new conversation. You can manually send the prefilled content directly, or edit and optimize the prompt (prefilled content) based on your business needs before manual submission and sending.

&nbsp;

* **Built\-in scheduled tasks**: Preset automatic scheduling tasks for the agent. For more information, see [Viewing and adding scheduled tasks preset in agent templates](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_and_adding_scheduled_tasks_preset_in_agent_templates_01?lang=en).

   > Currently, only some agent templates have scheduled tasks preset.   
   

* **Built\-in skills**: Integrated tools and analytical capabilities of the agent. They are automatically invoked on demand during conversation execution and require no manual configuration.

* **Task demo:**  You can preview how the agent is used and its output, and quickly replicate the same configuration.

   > The task demo feature is currently preset only in some agent templates. We are continuously iterating and refining other templates, and this feature will be and will supported by them gradually.   
   

   * **Replay**: Displays a sample task to intuitively show how this agent is used and its typical output. By viewing the task demo before adding an agent or when using an agent for the first time, you can determine in advance whether it meets your business needs, thus reducing situations where a capability mismatch is discovered after integration.

      1. Hover the mouse over the target demo task card and click the "Replay" button.

      2. View the session trace and output to further evaluate this agent's capabilities and applicable scope.

   * **Replicate**: Task demonstration supports quickly reusing the same configuration based on a preset example, enabling rapid creation and demonstration of actual tasks that are identical or similar to the sample task. This reduces repetitive configuration overhead and improves trial and setup efficiency.

      1. Hover the mouse over the target demo task card and click the "Replicate" button.

      2. The system prefills relevant content based on the demo task.

      3. After you confirm the prefilled content is correct, send directly or adjust as needed before sending.

* **Update date:**  The bottom of the card shows the release date of the template's latest version (for example, `2026-05-18`). This helps check whether a template is being continuously iterated and optimized​.

## Step 4: Use the template

Select the target card and click the "Add and initiate task" button. The system automatically returns to the chat box, uses this agent to initiate the task, and adds the agent to "My agents". You can then specify this agent for subsequent tasks. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Adding_agents_and_managing_my_agents?lang=en)
