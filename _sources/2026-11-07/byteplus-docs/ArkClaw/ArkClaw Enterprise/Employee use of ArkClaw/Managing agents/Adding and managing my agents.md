This topic describes how to add multiple specialized agents to your ArkClaw instance. By expanding your agent list, you can cover a wider range of business scenarios and flexibly assign the most suitable expert role when handling specific tasks.

<span id="0R1xVICx"></span>
## Build my agents

<span id="03Gtx0U4"></span>
### Add an agent from Agent Gallery and start a task

Agents you can add include platform\-prest agent templates and [employee-published enterprise templates](https://docs.byteplus.com/en/docs/ArkClaw/Adding_agents_and_managing_my_agents?lang=en#BkjHP8CY).


1. Open the browser, enter the ArkClaw login URL in the address bar, and then press Enter.

2. Switch to the target ArkClaw page, and select "Agent Center" in the left\-side navigation pane.

3. Click the Agent Gallery tab and select a template that suits your business scenario. Then, click the "Add and initiate task" button. You are automatically redirected to the chat page where the current agent is selected, and the task is initiated. Meanwhile, the agent is automatically added to the My agents list. At this point, the agent is built. You can then specify this agent to execute tasks when starting future tasks.

   > * You can add multiple agents by using this method.

   > * For more information about Agent Gallery, see [Viewing Agent Gallery information](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_Agent_Gallery_templates?).


<span id="ijV7GfgB"></span>
### Create a custom agent

If the preset agents in Agent Gallery do not meet your business goals, job responsibilities, or workflow requirements, you can create a custom agent. Two methods are supported:


* **Create with AI**

   Describe your business requirements in natural language. The system automatically generates an initial agent configuration, which can also be configured manually and refined further afterward.

* **Upload agent**

   Upload a local agent configuration file for quick deployment, suitable for configuration migration or reuse in different environments.


<span id="kVV7lMAO"></span>
#### Method 1: Create with AI (recommended)


1. Open the browser, enter the ArkClaw login URL in the address bar, and then press Enter.

2. Switch to the target ArkClaw page, and select "Agent Center" in the left\-side navigation pane.

3. In the upper\-right corner of the page, select "Add custom agent  **\>**  Create with AI".

4. Choose to quickly generate an agent using a prompt or natural language, or create one manually through the user interface.

   
   <Tabs>
   <Tab zoneid="KMWF70KFNr" title="Quickly generate via prompt or natural language (recommended)">
   <TabTitle>Quickly generate via prompt or natural language (recommended)</TabTitle>
   
   Create agents quickly using natural language or preset prompts. This approach is easy to get started with, efficient to set up, and applicable to a wide range of scenarios, with no complex manual configuration required. It significantly reduces the cost of creating and maintaining agents. Most suitable for quickly creating general\-purpose agents.
   
   
   1. **Initiate a creation request:**  On the left side of the "Create agent" page, select whether to generate the initial agent configuration using a **natural language description** or a **quick prompt**.
   
      * **Quick prompt**: Select the corresponding prompt as instructed on the page and send it.
   
      * **Natural language description**: Enter the natural language description of the target agent in the chat box and send it.
   
   3. **Confirm the solution outline and initiate the build:**  After the system generates the solution outline, review the proposed agent name, core feature list, and other content, and confirm or adjust them based on business requirements:
   
      * **Adjust the outline**: If the solution fails to meet your expectations, click the "Request changes" button and add detailed revision comments to let the system regenerate the content.
   
      * **Confirm the build**: If the solution meets your business requirements, click the "Build" button. The system will automatically complete the basic configuration and initialization of the agent based on the solution outline, and output the change summary of the build process on the left.
   
   4. **Confirm and adjust the agent capabilities.** 
   
      After the build is complete, the full configuration panel for the agent appears on the right side of the page. You can review and adjust the following content as needed:
   
      * **Agent name/Description**: Confirm whether the name and description generated by the system are accurate. If adjustments are required, directly modify the corresponding content. Modifications take effect immediately.
   
      * **Model**: The agent uses the ArkClaw model by default. If the administrator has configured multiple models, you can switch to another inference model for the current agent from the drop\-down list based on your business needs. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_models_for_my_agents).
   
      * **Tools**: By default, tools are preset and enabled. You can click "Edit all" in the **Tools** section to make adjustments based on actual needs. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_tools_for_my_agents).
   
      * **Skills**: If the automatically generated skills do not fully cover your scenarios, click "+ Add" in the **Skills** section to add skills. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_skills_for_my_agents).
   
      * **Code of conduct/Workflow/Agent profile/User profile:**  Check whether the content generated by the system meets your expectations. If adjustments are required, click the corresponding tab (e.g. "Agent profile") to switch to the configuration page, and directly modify the content in the text editing area. Modifications take effect immediately. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_md_files__?lang=en).
   
   5. **Debug agent configuration:**  To verify whether the configuration meets expectations, we recommend that you perform debugging before completing the creation.
   
      1. Click the "Debugging" button. In the pop\-up chat box, enter and send commands in natural language.
   
      2. View the debugging results:
   
         * If the results meet your expectations, click the "Create" button.
   
         * If the results do not meet your expectations, click the "Exit debugging" button and reconfigure the agent.
   
   6. After confirming that the configuration is correct, click the "Create" button to finish creating the custom agent.
   
   
   </Tab>
   <Tab zoneid="QybG9BMQoe" title="Create manually via user interface">
   <TabTitle>Create manually via user interface</TabTitle>
   
   Visual manual creation supports fine\-grained customization of all parameters, enabling precise debugging and standardized management. Most suitable for complex, highly customized business scenarios.
   
   
   1. **Specify the agent name and description**: On the right side of the "Create agent" page, enter the agent name and description in the "Name" and "Description" fields, respectively.
   
      * **Name**: Enter a name for the agent. We recommend that you use a clear and easy\-to\-understand name to facilitate subsequent identification and management.
   
      * **Description**: Briefly describe the core features and application scenarios of the agent to facilitate subsequent matching with corresponding business requirements.
   
   3. **Configure agent capabilities.** 
   
      * **Model**: The agent uses the ArkClaw model by default. If the administrator has configured multiple models, you can switch to another inference model for the current agent from the drop\-down list based on your business needs. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_models_for_my_agents).
   
      * **Skills**: By default, skills are preset. You can click "Edit all" or "+ Add" in the **Skills** section to add skills. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_skills_for_my_agents).
   
      * **Tools**: By default, tools are preset and enabled. You can click "Edit all" in the **Tools** section to make adjustments based on actual needs and grant the agent the necessary capabilities to call external tools. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_tools_for_my_agents).
   
      * **Code of conduct/Workflow/Agent profile/User profile**: Switch to the corresponding configuration page (e.g., "Agent profile"), and edit the code of conduct, workflow, agent profile, and user profile separately to give ArkClaw a dedicated identity, response guardrails, standard operating procedures, and user\-awareness capabilities. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_md_files__?lang=en).
   
   4. **Debug agent configuration:**  To verify whether the configuration meets expectations, we recommend that you perform debugging before completing the creation.
   
      1. Click the "Debugging" button. In the pop\-up chat box, enter and send commands in natural language.
   
      2. View the debugging results:
   
         * If the results meet your expectations, click the "Create" button.
   
         * If the results do not meet your expectations, click the "Exit debugging" button and reconfigure the agent.
   
   5. After confirming that the configuration is correct, click the "Create" button to finish creating the custom agent.
   
   
   </Tab>
   </Tabs>

#### Method 2: Upload agent

Import an agent configuration by **uploading a local compressed package**. After the upload is complete, the system automatically parses the package contents and initializes the agent. This method is primarily suitable for migrating an existing agent across environments.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">The agent's compressed package for upload has been prepared. The file must be in <strong>.zip</strong> format and must not exceed <strong>10 MB</strong>.</div>



1. **Go to the upload page.** 

   1. Open the browser, enter the ArkClaw login URL in the address bar, and then press Enter.

   2. Switch to the target ArkClaw page, and select "Agent Center" in the left\-side navigation pane.

   3. In the upper\-right corner of the page, select "Add custom agent  **\>**  Upload agent".

2. **Upload agent**: Click the upload area and follow the on\-screen instructions to select a local file, or drag and drop the .zip file directly into the dashed box, and then wait for the upload to complete.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you are unsure about the package structure, click "Download and view sample .zip" to refer to the sample file's directory structure and configuration format before preparing your file.   </div>
   

3. **Confirm and adjust the agent capabilities.** 

   After the upload is complete, the full configuration panel for the agent is displayed on the right side of the page. You can check or adjust the following as needed:

   * **Agent name/description**: To make adjustments, modify the content directly. Modifications take effect immediately.

   * **Model**: The default model used by this agent. If the administrator has configured multiple models, you can switch to a different inference model for this agent from the drop\-down list based on your business needs. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_models_for_my_agents).

   * **Tools**: The tools currently supported by this agent. Click "Edit all" in the **Tools** section to adjust as needed. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_tools_for_my_agents).

   * **Skills**: The skills currently supported by this agent. Click "+ Add" in the **Skills** section to add a skill. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_skills_for_my_agents).

   * **Code of conduct/Workflow/Agent profile/User profile:**  The code of conduct, workflow, agent profile, and user profile currently supported by this agent. If adjustments are required, click the corresponding tab (e.g., "Agent profile") to switch to the configuration page, and directly modify the content in the text editing area. Modifications take effect immediately. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_md_files__?lang=en).

4. **Debug agent configuration:**  To verify whether the configuration meets expectations, we recommend that you perform debugging before completing the creation.

   1. Click the "Debugging" button. In the pop\-up chat box, enter and send commands in natural language.

   2. View the debugging results:

      * If the results meet your expectations, click the "Create" button.

      * If the results do not meet your expectations, click the "Exit debugging" button and reconfigure the agent.

<TabTitle>Use an agent to initiate a task</TabTitle>

On the card, click "Initiate task". The system automatically returns to the chat box and specifies this agent for the task.


</Tab>

#### Publish as an enterprise template

Package a custom agent as an enterprise template for quick reuse by members within the enterprise.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="0">tip</div>


* <div data-tips="true" data-tips-type="default" data-wrapper-indent="0">If the message "Please contact your administrator to enable this feature" appears, contact your administrator to enable it before you try again.</div>


* <div data-tips="true" data-tips-type="default" data-wrapper-indent="0">If the message "Template publishing requires the enterprise disk to be enabled and mounted..." appears, see <a href="https://docs.byteplus.com/en/docs/ArkClaw/Claw_cloud_disk?lang=en#qu8UeaGo">My cloud disk</a> to complete the activation and mounting operations.</div>


* <div data-tips="true" data-tips-type="default" data-wrapper-indent="0">Publishing as an enterprise template is only supported for custom agents. Agents added from the Agent Gallery do not support this operation.</div>



Click the "··· ** \>**  Publish as enterprise template" button on the card. The system will submit the agent to the enterprise administrator for review. Once approved, the template will appear in the **enterprise template list** of the "**Agent Gallery**".

#### Publish a new version of an enterprise template

Modify the content of a published enterprise template and update the template version. Each time an update is published, the system **generates a new independent version**, making it easy to view and manage configurations across different stages.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Publishing a new version is only supported for custom agents. Agents added from the Agent Gallery do not support this operation.</div>



1. Click the "···  **\> ** Publish new version" button on the card.

2. Enter a description of the changes and click "Update and publish". The system will submit the agent to the enterprise administrator for review. Once approved, the template will appear in the **enterprise template list** of the "**Agent Gallery**".


</Tab>

## What to do next

After adding agents, you can choose between two scheduling modes, team collaboration mode and prioritized sub\-agent processing mode, to intelligently match the specialized sub\-agent for cross\-domain collaborative processing and improve task handling efficiency. The applicable scenarios for each mode are as follows:


* **Team collaboration mode**

   This mode is suitable for complex, open\-ended tasks that require multiple roles working in a complementary and collaborative manner. In this mode, multiple sub\-agents divide responsibilities to handle content completion, cross\-validation, and multi\-dimensional integration. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_agent_team_collaboration_mode?lang=en)

* **Prioritized sub\-agent processing mode**

   This mode is suitable for focused tasks with clear objectives and fixed areas of expertise. The corresponding specialized sub\-agent can be directly scheduled to handle a task independently, precisely matching a single business capability requirement. For details, refer to [Setting sub-agent scheduling priority](https://docs.byteplus.com/en/docs/ArkClaw/Setting_sub-agent_scheduling_priority).
