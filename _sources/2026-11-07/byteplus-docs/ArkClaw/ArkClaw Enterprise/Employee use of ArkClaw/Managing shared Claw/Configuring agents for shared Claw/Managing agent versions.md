This topic describes how a shared Claw administrator can view the historical versions and change records of an agent, and how to roll back an agent to an earlier version.

<span id="aWfBR2ti"></span>
## View agent versions and change records


1. Log in to the ArkClaw console as the shared Claw administrator and switch to the target shared Claw instance page in the left pane.

2. In the left navigation pane, select "Agent center".

3. Click the "View details" button on the target card.

4. At the top of the details page, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_84cfb99377809305aa7d679564dd4341.png) </span> to view the version number, change time, and operator of each version.

5. Click the "View change record" button next to the target version to view the version change details.


<span id="4wH0V2Lt"></span>
## Roll back versions

After the agent is released, if the current agent does not meet expectations, you can quickly roll back to a prior successful release version.


1. Click the "Roll back" button next to the target released version.

2. In the dialog box that pops up, click "Roll back" to complete the operation.
