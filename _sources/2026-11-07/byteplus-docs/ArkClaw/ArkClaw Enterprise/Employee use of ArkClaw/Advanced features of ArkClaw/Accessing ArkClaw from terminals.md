You can access ArkClaw from a terminal and use Shell commands to perform various operations (such as viewing directories and files in the current path, creating tasks, and so on). **This is suitable for technical developers who need in\-depth usage.** 

<span id="jHwhV8Ko"></span>
## Procedure


1. Open your browser, enter the ArkClaw login URL in the address bar, and press Enter.

2. Switch to the target ArkClaw page and click the details icon in the upper\-right corner.

3. Click the "View terminal" button to access the terminal.

4. Enter the target command and execute it to complete the corresponding operation.

   Example: Execute the `openclaw --version` command to view the current OpenClaw version.
