To better support your network access, management, and security control needs, ArkClaw Enterprise has upgraded its network configuration capabilities. The new version offers richer traffic management features for both public and private networks. See the table below for a feature comparison between the new and old versions.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">If you are unable to use the new version of Network Configuration, go to <a href="https://console.byteplus.com/arkclaw/enterprise">the ArkClaw Enterprise console</a> to find your Space ID, and <a href="https://console.byteplus.com/workorder/create">submit a ticket</a> to upgrade the Space.</div>



|Feature ||Description |Documentation (new version) |Documentation (old version) |
|---|---|---|---|---|
|Public network ingress |Custom domain |Bind your own registered and ICP\-filed domain to hide platform information, creating a completely enterprise\-branded dedicated login portal. |[Configuring a custom enterprise domain (new version)](https://docs.byteplus.com/en/docs/ArkClaw/configuring-a-custom-enterprise-domain-new-version) |[Configuring a custom enterprise domain (old version)](https://docs.byteplus.com/en/docs/ArkClaw/configuring-a-custom-enterprise-domain-old-version) |
||Custom domain prefix |Add a custom prefix before the platform's fixed domain suffix to obtain a concise, memorable enterprise\-specific access address. No your own domain required. |[Configuring a custom domain prefix (new version)](https://docs.byteplus.com/en/docs/ArkClaw/configuring-a-custom-domain-prefix-new-version) |[Configuring a custom domain prefix (old version)](https://docs.byteplus.com/en/docs/ArkClaw/configuring-a-custom-domain-prefix-old-version) |
|Private network ingress |Account allowlist |Add the business account to the allowlist to grant private network access to ArkClaw services. |[Configuring account allowlist](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-account-allowlist) |Not support |
||Custom domain name |Administrators can modify the system\-assigned private ingress domain prefix or configure a custom domain. This helps business staff identify and remember it easily. |[Configuring a custom domain](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-a-custom-domain-prefix) |Not support |
||Connection management |Administrators can manually accept or reject connection requests. For example, before removing an account from the private network ingress allowlist, its connection should first be disconnected. Previously rejected or disconnected connections can also be manually accepted to re\-establish access. |[Accepting or rejecting a connection](https://docs.byteplus.com/en/docs/ArkClaw/Accepting-or-rejecting-a-connection) |Not support |
|Public network egress |Public network egress |The public network egress is enabled by default​ after the ArkClaw Enterprise service is activated. To mitigate security risks associated with data traversing the public network, enterprises can disable the public egress. |[Enabling or disabling public network egress (new version)](https://docs.byteplus.com/en/docs/ArkClaw/Enabling-or-disabling-public-network-egress-new) |[Enabling or disabling public network egress (old version)](https://docs.byteplus.com/en/docs/ArkClaw/Enabling-or-disabling-public-network-egress-old) |
||Access log |Records key information for all pubic network access events to enable traceability of security incidents and provide a complete evidentiary chain for compliance auditing, meeting enterprise requirements for security review and issue tracking. |[Enabling or disabling access log for public network egress](https://docs.byteplus.com/en/docs/ArkClaw/Enabling_or_disabling_access_log_for_public_network_egress) |Not support |
||Network access policy |Controls Layer\-4 traffic from Claw instances to pubic networks. Configuring differentiated public network access rules per ArkClaw instance enables precise control over public Layer\-4 traffic. |[Configuring network access policy for public network egress](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_network_access_policy_for_public_network_egress) |Not support |
||Web access policy |Controls Layer\-7 traffic from Claw instances to pubic networks. Configuring differentiated public network access rules per ArkClaw instance enables precise control over public Layer\-7 traffic. |[Configuring Web access policy for public network egress](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-Web-access-policy-for-public-private-network-egress-non-cross-border) |Not support |
||Cross\-border acceleration policy |An acceleration service for cross\-border access. Once enabled, traffic is directed to Asia\-Pacific nodes, ensuring low\-latency and stable access to overseas services. |[Configuring cross-border acceleration policy (new version)](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-cross-border-acceleration-policy-new-version) |[Configuring cross-border acceleration policy (old version)](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-cross-border-acceleration-policy-old-version) |
|Private network egress |Private network egress |Enables ArkClaw to access enterprise internal network resources over the private network, preventing data exposure to the public network. This helps meet strict compliance requirements such as "Data must remain the region" for industries like finance and government. |[Enabling or disabling private network egress (new version)](https://docs.byteplus.com/en/docs/ArkClaw/Enabling-or-disabling-the-private-egress-New-version) |[Enabling or disabling private network egress (old version)](https://docs.byteplus.com/en/docs/ArkClaw/Enabling-or-disabling-the-private-egress-Old-version) |
||Private access to apps |Enables ArkClaw to access enterprise AI assets over the private network, such as Agents and MCP (Method, Capability, Plugin). This helps employees to discover, invoke, and manage enterprise AI assets securely and efficiently via ArkClaw. |[Enabling or disabling private access to apps](https://docs.byteplus.com/en/docs/ArkClaw/Enabling_or_disabling_private_access_to_apps) |Not support |
||DNS custom resolution |After private network egress is enabled, ArkClaw forwards DNS queries from the Space to BytePlus DNS servers (`100.96.0.2` and `100.96.0.3`) by default. DNS custom resolution allows DNS queries from the Space to be forwarded to a specified external DNS server. |[Configuring DNS custom resolution for private network egress (new version)](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-the-private-egress-domain-resolution-New-version) |[Configuring DNS custom resolution for private network egress (old version)](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-the-private-egress-domain-resolution-Old-version) |
||Access log |Records key information for all private network access events. This enables traceability of security incidents and provides a complete evidentiary chain for compliance auditing. It helps meet enterprise requirements for security review and issue tracking. |[Configuring access log for private network egress](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-a-private-egress-access-log) |Not support |
||Network access policy |Controls Layer\-4 traffic from Claw instances to private networks. Configuring differentiated private network access rules per ArkClaw instance enables precise control over private Layer\-4 traffic. |[Configuring network access policy for private network egress](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-a-private-egress-network-access-policy) |Not support |
||Web access policy |Controls Layer\-7 traffic from Claw instances to private networks. Configuring differentiated private network access rules per ArkClaw instance enables precise control over private Layer\-7 traffic. |[Configuring Web access policy for private network egress](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-a-private-egress-web-access-policy) |Not support |
||DNS access policy |Blocks​ Claw instances from resolving specified domains. |[Configuring DNS access policy](https://docs.byteplus.com/en/docs/ArkClaw/Configuring-DNS-access-policy) |Not support |
