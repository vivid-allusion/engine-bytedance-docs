After enabling public network egress, you can enable access log for public network traffic. You can view logs such as destination IPs, destination ports, and accessed domains in [ArkClaw Log analysis](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_log_analysis).

<span id="bi2tF9VU"></span>
## Before you begin

Public Network Egress must be [enabled](https://docs.byteplus.com/en/docs/ArkClaw/Enabling_or_disabling_access_log_for_public_network_egress).

<span id="wRYBbYhk"></span>
## Procedures


1. Log in to the [ArkClaw Enterprise Edition console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Resource Configuration \> Network Configuration".

3. On the Network Configuration page, click the "Space Egress" tab.

4. In the "Public network egress" section, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b4801ed68f363d255f8acaecb67192fa.png) </span>icon of "Configuration \> Access log".

5. In the pop\-up dialog box, enable or disable access log.

6. Click "OK" to complete the action.
