Under the platform\-hosted authentication mode, if employees forget their login passwords, they have two methods to address the situation:


* **Retrieve by employees**: If the employee has registered a valid phone number, he/she can retrieve the password on the login page via SMS verification code, without administrator intervention.

* **Reset by administrator**: If the employee has not registered a phone number or the phone number is temporarily unavailable, the administrator can reset the login password for the employee via the user management feature. See below for detailed instructions.


<span id="xalU606t"></span>
## Prerequisites


* The ArkClaw space uses the **platform\-hosted** authentication method.

* You have obtained administrator permissions and activated the ArkClaw Enterprise. For details, see [Platform hosting](https://docs.byteplus.com/en/docs/87732/2356405).


<span id="jzlgx0yt"></span>
## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Organizations \> Users".

3. On the Users page, select the "All users" tab, and click the "Reset password" button in the Actions column for the target user.

4. In the pop\-up window, click the "Reset" button to confirm the password reset.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">After resetting the user's password, the original password will be invalid. Please proceed with caution.   </div>
   

5. In the pop\-up window, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_63c193a480ce090a432f5bbb65b83c5e.png) </span> to copy the new password to the clipboard. After confirming that it has been properly stored, click the "I acknowledge" button to complete the operation.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After clicking the "I acknowledge" button and closing the pop\-up window, the password cannot be viewed again. If the password is not lost or forgotten, the administrator can reset the password again.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After the password reset is completed, deliver the new password to the target user as soon as possible via the organization's internal secure channel, and remind the user to change it to a custom password immediately after their first login.   </div>
