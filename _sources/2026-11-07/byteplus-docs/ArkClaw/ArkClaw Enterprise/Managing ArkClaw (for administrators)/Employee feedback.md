This topic describes how enterprise administrators can view and manage employee\-submitted feedback in the ArkClaw console. Administrators can use the feedback list to promptly understand issues encountered by employees during use. They can filter, search, and export feedback data based on conditions to help continuously improve the product experience.

<span id="HFPxokSB"></span>
## Description

The feedback feature provides a unified entry point for administrators to view employee\-submitted issue tickets, establishing a closed\-loop feedback mechanism from the "employee side" to the "administrator side". This helps administrators promptly identify and address employee feedback and suggestions, reducing instances where employees cannot report or resolve issues.

<span id="0tgwCatc"></span>
## Procedure

<span id="NO5DUY6R"></span>
### View the feedback list


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, select "To\-dos \> Feedback."

3. On the feedback page, you can see a list of all feedback records submitted by employees.

   
   |**Field** |**Description** |
   |---|---|
   |**Submitter/ID** |The username and user ID of the employee who submitted the feedback. |
   |**Claw instance** |The name and ID of the Claw instance where the issue occurred. |
   |**Issue type** |The issue category label selected by the employee. |
   |**Issue description** |The detailed issue description provided by the employee. If left empty, "\-" is displayed. |
   |**Creation time** |The time when the feedback was submitted. |
   |**Export status** |Indicates whether this feedback has been exported. |
   |**Screenshot** |Screenshots or screen recordings attached by the employee during submission, supporting image (jpg, gif) and video (mp4) formats. Click it to preview. If no screenshot is available, "\-" is displayed. |
   

4. Through the filters and search, you can quickly locate feedback from a specific employee.

   
   |**Actions** |**Description** |
   |---|---|
   |**Display period** |Click the time filter dropdown and select the time range to view. By default, feedback data for the "All" time range is displayed. |
   |**Search users** |Enter a username or user ID in the search box to quickly retrieve feedback submitted by the corresponding user. |
   |**Filter by issue type** |Click the filter icon in the "Issue type" column to filter by issue type. Supported issue types include: inaccurate or incomplete response, failure to follow instructions, tool or plugin invocation errors, slow or laggy response, inappropriate tone or expression, legal issues such as security and compliance, and others. |
   |**Filter by export status** |Click the filter icon in the "Export status" column to filter by export status (Exported / Not exported). |

### Export feedback data


1. In the left navigation pane of the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise), select "To\-dos \> Feedback."

2. On the feedback page, set filter criteria as needed (e.g., display period and export status).

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The export operation supports selecting a time range and filtering by export status (exported/not exported), helping you flexibly manage exported content.   </div>
   

3. Click the "Export" button in the upper\-right corner of the page.

4. After export is completed, the status of the corresponding feedback record will automatically change to "exported."
