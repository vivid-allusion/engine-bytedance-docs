The security protection version of the current ArkClaw Enterprise Edition instance is set to Standard Edition by default. To upgrade to the Advanced Edition, you can purchase Advanced Edition ClawSentry seats and then manually switch the protection version of the corresponding ArkClaw instance to the Advanced Edition. Additionally, if an ArkClaw instance no longer requires Advanced Edition protection, you can also change the protection version to switch the ArkClaw instance from the Advanced Edition back to the Standard Edition.

<span id="tMyUQl08"></span>
## Caution


* After purchasing Advanced Edition seats, when a new ArkClaw instance is connected, it is by default bound to a Standard Edition seat.

* If there are remaining Advanced Edition seats, you can manually upgrade the seat version of the instance to the Advanced Edition.


<span id="E06sFfyg"></span>
## Step 1: Purchase Advanced Edition seats

To upgrade ClawSentry to the Advanced Edition, perform the seat change operation directly on the instance management page, then purchase the specified number of Advanced Edition seats to allocate to different ArkClaw instances.


1. Log in to the [ClawSentry console](https://console.byteplus.com/clawsentry).

2. In the left navigation bar, select **System Settings \> Instance Management**.

3. Click **Change Seats**, then select the number of **Advanced Edition** protection seats.

   The system will automatically calculate the upgrade fee based on your changes.

4. Read and check the box to agree to the relevant agreements, then click **Confirm Change**.

5. Confirm the upgrade details and fees, and complete the payment.


<span id="eWPM9zPh"></span>
## Step 2: Change the protection version

If there are remaining seats, you can manually upgrade the protection version of an ArkClaw instance to the Advanced Edition. You can perform the change in the instance management list or go to the assistant list to perform the change.

**Change conditions**: The protection version can only be changed when the AI assistant's security plugin status is online.


1. Log in to the [ClawSentry console](https://console.byteplus.com/clawsentry).

2. In the left navigation bar, select **System Settings \> Instance Management**.

3. Select the target assistant name, click **Change Protection Version**, or select multiple assistants to change the protection version in bulk.

4. Select the version that can be changed, and click **OK**.


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">When performing a batch change, if the remaining seats in the target version are insufficient to cover the number of currently selected AI assistants, a prompt indicating insufficient seats will appear. For example, if there are currently 2 Standard Edition assistants and only 1 seat remaining in the Advanced Edition, a batch change cannot be performed.</div>
