This topic explains how to configure custom ArkClaw Enterprise employee\-side pages. BytePlus ArkClaw Enterprise has default branding elements for employee login and application pages. You can modify these elements to reflect your corporate identity.

<span id="0H3u159X"></span>
## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, select "Enterprise customization" \> "Custom branding".

3. Click "Customize branding". On the page that appears, configure custom branding settings.

   
   |Configuration information |Description |
   |---|---|
   |**General configuration** ||
   |Configuration name |Set a name for this custom configuration. You can use this name to locate the configuration. |
   |① Enterprise name |The enterprise name displayed on the employee login page and initialization page. An example is "ArkClaw". |
   |② Enterprise logo |The enterprise's logo image displayed in the upper\-left corner after an employee logs in to the ArkClaw session page. |
   |**Login page configuration** ||
   |③ Main slogan |The positioning slogan for ArkClaw displayed on the employee login page and initialization page.<br><br>An example is "Your dedicated intelligent partner (24/7 online)". |
   |④ Sub\-slogan |A short message that communicates the positioning of ArkClaw on the employee login page.<br><br>An example is "Let AI truly get your job done, from chat to task execution". Deeply integrated with BytePlus and Feishu ecosystems, this assistant centrally manages multiple AI agents. |
   |⑤ Documentation link |The link to the ArkClaw documentation. If you set a link, an employee can access the documentation by clicking "Learn more" on the login page. |
   |⑥ Login background |The background picture displayed on the employee login page.<br><br><br>* The picture size is 2880 x 1800px and cannot exceed 10 MB.<br><br>* The login page text is in white. Avoid using a picture with a white background, as this may affect the visibility of the slogan. |
   |**Configuration details page** ||
   |⑦ Welcome message |A welcome message on the sessions page. This message is displayed when an employee has no session or starts a new session.<br><br>An example is "Welcome to ArkClaw". |
   |⑧ Security and privacy settings |After employees log in to the ArkClaw session page, they can view the **security/privacy terms** at the bottom of the page. |
   |**Other optimizations** ||
   |User\-side iframe embedding switch |If enabled, other systems are allowed to embed the ArkClaw employee\-side console via iframe.<br><br><br>* If an employee has already logged into the ArkClaw via a non\-iframe method with this feature disabled, he/she needs to log out and then log back in after it is enabled.<br><br>* The embedded URL is the employee\-side login link for ArkClaw Enterprise. It can be found in the Space Overview of the ArkClaw console.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">ArkClaw only provides the iframe embedding switch and the required URL. Enterprises need to complete the actual development work for embedding.</div><br> |
   |Skills Center [Enterprise featured skills] |Administrators can customize the name of the "Enterprise featured skills" tab. After employees log in to the ArkClaw chat page, they can view the configured new name on the "Skills Center" page **.** <br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">For example, if the name is customized to "Enterprise selection," employees can view it in the interface shown below.</div><br> |
   

4. Click "Save" to save this customization configuration.

5. On the "Custom branding" page, locate your desired custom configuration and click "Release" to apply it.
