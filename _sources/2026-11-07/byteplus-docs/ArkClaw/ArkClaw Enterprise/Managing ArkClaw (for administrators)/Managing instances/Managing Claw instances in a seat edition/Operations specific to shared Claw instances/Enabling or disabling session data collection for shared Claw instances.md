Enterprise administrators can enable or disable session data collection for shared Claw instances as needed. If this feature is enabled, administrators can access ‌usage statistics‌, ‌task performance analysis, and ‌issue diagnostics‌ for shared Claws. If this feature is disabled, the system no longer generates insight analytics from related conversation data.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">You can configure insight analytics only for shared Claws, not for employee Claws and enterprise service agents.</div>


* <div data-tips="true" data-tips-type="default">If you enable this feature, the system processes conversation data from shared Claws within the scope described in the data usage scope. The system uses this data to generate the task insights dashboard, which helps administrators monitor usage, analyze task performance, and troubleshoot issues.  .Data usage scope description.</div>


* <div data-tips="true" data-tips-type="default">If you do not want the system to generate insight analysis results based on relevant conversation data, you can manually disable this feature.</div>

## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane​, click "Claw Management" \> "Claws".

3. On the "Shared Claw" tab, find the target shared Claw instance and click the toggle in the "Session collection" column to enable or disable session collection.

4. After configuration is complete, the system determines whether to generate insight analysis results for the shared Claw based on the current toggle status. You can adjust this configuration at any time as needed.
