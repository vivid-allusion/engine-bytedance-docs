Enterprise administrators can designate employees as administrators for a specified shared Claw instance. Enterprise employees designated as administrators can use and manage the shared Claw instance, enabling daily O&M tasks to be delegated to the corresponding teams without requiring intervention from the enterprise administrators each time.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">You can designate administrators only for shared Claw instances, not for employee Claw instances.</div>


* <div data-tips="true" data-tips-type="default"><strong>The capability to configure administrators for shared Claw instances</strong> takes effect for instances created on or after <strong>June</strong> <strong>4</strong>, <strong>2026</strong>. For an instance created before this date, you need to first <a href="https://docs.byteplus.com/en/docs/ArkClaw/Managing_applications?lang=en#cUBogHKm">unregister its associated agent application</a> and <a href="https://docs.byteplus.com/en/docs/ArkClaw/Application_management?lang=en#Mxxy9IhZ">re\-register the agent</a> before you can configure an administrator. Note that unregistration and re\-registration will affect all employees currently using this shared Claw. Perform these operations during off\-peak business hours and notify all relevant personnel in advance.</div>



<span id="8Y6S7ywV"></span>
## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane​, click "Claw Management" \> "Claws".

3. On the "Shared Claw" tab, find the target shared Claw and click "Administrator" in the "Actions" column.

4. In the pop\-up dialog box, select the users that you want to designate as administrators.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you cannot find the target employee, the employee's information may be missing. Go to "User management" to check and complete the employee's information. For details, see <a href="https://docs.byteplus.com/en/docs/ArkClaw/Manage_user_information?lang=en#wAIx9Wfy">Updating user information</a>.   </div>
   

5. Click "Confirm" to complete the operation. After the configuration is complete, you can view the administrators of the shared Claw in the "Administrator" column. To change or remove administrators, repeat the steps to enter the selection box, adjust the settings, and save the changes.
