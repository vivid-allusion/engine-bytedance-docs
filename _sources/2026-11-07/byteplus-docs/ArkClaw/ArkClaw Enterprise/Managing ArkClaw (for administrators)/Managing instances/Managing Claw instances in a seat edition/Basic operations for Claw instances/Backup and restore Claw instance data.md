When a Claw instance encounters exceptions such as interface freezing or unresponsive actions, and neither restart nor auto healing resolves the issue, the administrator can restore a backup to roll back the instance to normal status while retaining historical data (unlike restoring factory settings, which will clear all data). **This document describes how to configure an automatic backup policy, manually create a backup, restore backup data, and delete backups.** 

<span id="O7ZTEzlM"></span>
## **Recommended priority order for recovery options**


1. [Restart Claw instance](https://docs.byteplus.com/en/docs/ArkClaw/Restart_Claw_instance?lang=en) (no data loss)

2. [Auto healing](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_for_Claw_instances?lang=en) (roll back to the last available state)

3. **Restore backup** (this document, roll back to the specified backup time point)

4. [Restore factory settings](https://docs.byteplus.com/en/docs/ArkClaw/Restore_Claw_instance_to_factory_settings?lang=en) (clear all data)


<span id="iPkTFLD3"></span>
## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise)[ArkClaw Group console](https://console.byteplus.com/arkclaw/enterprise/group/)[ArkClaw OMNI console](https://console.byteplus.com/arkclaw/enterprise/omni).

2. In the left\-side navigation pane, choose "Claw Management \> Claw Instances".

3. The "Instances" tab displays the list of created employee Claw and shared Claw instances.

   
   <Tabs>
   <Tab zoneid="zVeXrdDW" title="Enable or disable automatic backup">
   <TabTitle>Enable or disable automatic backup</TabTitle>
   
   Automatic backup is performed by the system according to preset rules to generate backup data. You can enable the automatic backup service and set the automatic backup time, and you can also restore backup data or disable automatic backup at any time.
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="0">warning</div>
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">If automatic backup is enabled without setting the backup time, the system will select a random hour to perform automatic backup.</div>
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">The maximum retention period for automatic backup is 24 hours. When a new backup is generated on the same day, the system will automatically overwrite the original backup, retaining only the latest backup.</div>
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">After automatic backup is disabled, the system will no longer perform automatic backup. Existing backup data will be retained for 24 hours and then automatically deleted.</div>
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">It is recommended to set the automatic backup time during off\-peak business hours (for example, 2:00–5:00 AM) to ensure the Claw instance is in idle status during backup, making the backup data more stable.</div>
   
   
   1. Switch on or switch off "Automatic Backup" for the target Claw instance as needed.
   
      * **Enable automatic backup feature**
   
         * **Single operation:**  Switch on automatic backup, select the target backup time from the drop\-down list, and then click "OK". The system generates backup data at the configured time.
   
         * **Batch operation:**  Select multiple target Claw instances, choose "... \> Enable automatic backup", select the target backup time from the drop\-down list, and then click "Enable". The system generates backup data at the configured time.
   
      * **Disable automatic backup feature**
   
         * **Single operation**: Switch off automatic backup, and then click "OK".
   
         * **Batch operation**: Select multiple target Claw instances, choose “...  \> Disable automatic backup”, confirm the information is correct, then click the “Disable” button to complete the operation.
   
   2. Return to the Claw list page and click the target Claw instance name. On the details page, click the "Configuration information" tab and view backup data in the "Backup" section. Data whose source is marked as "Automatic Backup" is generated by automatic backup.
   
   
   </Tab>
   <Tab zoneid="EZFdhMSS" title="Manually create a backup">
   <TabTitle>Manually create a backup</TabTitle>
   
   Manual backups require you to actively create backup files. You can manually create backups of the current system or data at any time as needed, so you can restore them later. This approach increases operational flexibility, effectively reduces errors caused by incorrect actions, and helps ensure the security of your data.
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   
   * <div data-tips="true" data-tips-type="warning">Manual backups are retained for up to 30 days. Backups older than 30 days will be automatically deleted.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">Each time you manually create or update a backup, a new backup is generated. When you create a new backup or perform a backup again, the system automatically overrides the previous backup and retains only the latest manual backup data.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">If automatic backup is currently enabled, the system will automatically pause the automatic backup task while a manual backup is being performed, and resume it after the manual backup is completed.</div>
   
   
   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="0">When the administrator upgrades Claw instance versions in bulk, the automatically backed up data will override the administrator's manual backup data.</div>
   
   
   1. In the Claw list, click the 'More \> Create backup' button in the 'Actions' column for the target Claw.
   
   2. After confirming that the information is correct, click the 'Create' button in the popup window to start creating the backup.
   
   3. Return to the Claw instance list page, click the name of the target Claw instance, go to the details page, and view the backup data in the 'Configuration information' tab under the 'Backup' section. Data with the source marked as 'administrator' is backup data generated by the administrator's manual backup.
   
   
   </Tab>
   <Tab zoneid="qsfzlqsn" title="Restore backup data">
   <TabTitle>Restore backup data</TabTitle>
   
   Restoring backup data will result in the loss of current data and will fully restore the entire system and all data to the state at the backup time. After restoration, the system status will be identical to the status at the time of backup.
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   
   * <div data-tips="true" data-tips-type="warning">Restoring a backup will override the current status (including configuration and data) of the Claw instance with the backup data. This operation is irreversible.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">During restoration, the Claw instance will be temporarily unavailable. The estimated time required is about 1 to 2 minutes.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">It is recommended to manually create a backup of the current status before restoring, so that you can restore if needed.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">If data restoration fails, you can retry restoration following the steps above or contact technical support for assistance.</div>
   
   
   1. Click the target Claw instance name, go to the details page's "Backup" tab, and view the backup data list.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The "Backup" tab can contain up to three backup files. The administrator can use any backup file to restore.   </div>
      
   
      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Data labeled as "Automatic Backup" refers to backups created after the automatic backup switch is enabled. Both the administrator and employee can modify the automatic backup switch.   </div>
      
   
      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Data labeled as "Administrator" refers to backups manually created by the administrator or backups automatically created before instance upgrade.   </div>
      
   
      * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Data labeled as "Employee" refers to backups manually created by the employee.   </div>
      
   
   2. Click "Restore Backup" in the Actions column on the right side of the target backup data to start restoring data.
   
   
   </Tab>
   <Tab zoneid="t1r53268" title="Delete backup data">
   <TabTitle>Delete backup data</TabTitle>
   
   The administrator is allowed to delete backup data from any source. If backup data is no longer needed, it can be deleted to release space.
   
   <div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>
   
   
   <div data-tips="true" data-tips-type="danger">Backup data cannot be restored after deletion. Please proceed with caution.</div>
   
   
   
   1. Click the target Claw instance name, go to the details page's "Backup" tab, and view the backup data list.
   
   2. Click the "delete" button in the Actions column on the right side of the target backup data. After confirming, click "delete" in the popup window to permanently delete the backup data.
   
   
   </Tab>
   <Tab zoneid="GaJjXskhIf" title="Configure the initial automatic backup time for Claw instances">
   <TabTitle>Configure the initial automatic backup time for Claw instances</TabTitle>
   
   The administrator can configure the initial automatic backup time for Claw instances. After the configuration takes effect, newly created Claw instances will automatically back up daily at the specified time, while existing instances are not affected.
   
   
   1. Click the "Global Configuration" button in the upper right corner of the page.
   
   2. Change the initial automatic backup time for Claw instances from the system random hour to the target hour.
   
      1. Click the "Change" button.
   
      2. Select the target hour in the "Execution time period" dropdown box, then click the "OK" button in the Actions column to complete the operation.
   
   3. You can reset the target hour to the system random hour.
   
      1. Click the "Change" button.
   
      2. Hover the mouse over the dropdown box, click the delete icon that appears, then click the "OK" button in the Actions column to complete the operation.
   
   
   </Tab>
   </Tabs>
