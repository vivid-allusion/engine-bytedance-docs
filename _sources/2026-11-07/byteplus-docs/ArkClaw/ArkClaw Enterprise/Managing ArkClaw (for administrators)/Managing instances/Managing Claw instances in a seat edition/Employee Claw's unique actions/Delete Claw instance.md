When an employee Claw instance is no longer in use, the administrator can delete that employee's Claw instance to release resources. **This article describes how to delete a Claw instance by either moving it to the recycle bin or permanently deleting it.** 

<span id="wYDox1S9"></span>
## Operation instructions


* Only "employee Claw" instances created by enterprise employees can be deleted. To delete a shared Claw, go to the Application Center to [unregister the application](https://docs.byteplus.com/en/docs/ArkClaw/Managing_applications?lang=en#cUBogHKm).

* You can delete Claw instances by either moving them to the recycle bin (recommended) or permanently deleting them (physical deletion).

   * **Move to recycle bin (recommended)** : The instance will stop running, and configuration and data will be retained in the recycle bin for 7 days. **After 7 days, the system will automatically permanently delete the instance, which cannot be restored.**  To restore, refer to [recycle bin management](https://docs.byteplus.com/en/docs/ArkClaw/Managing_recycle_bins?lang=en).

   * **Permanently delete (physical deletion)** : Immediately release the Claw instance and clear related configuration and internal instance data.

      ## Procedure

1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise)[ArkClaw Group console](https://console.byteplus.com/arkclaw/enterprise/group/)[ArkClaw OMNI console](https://console.byteplus.com/arkclaw/enterprise/omni).

2. In the left\-side navigation pane, select "Claw Management \> Claw List".

3. Under the "Instances \> Employee Claw" tab, you can view employee Claw instances created by enterprise employees.

4. Click the "More \> Delete" button in the "Actions" column for the target Claw instance.

5. In the dialog box that appears,  Click the "Delete" button to complete the operation.

6. After the operation is complete, go back to the Claws page to confirm that the target instance has been removed from the list. If you select "Move to recycle bin", you can go to "recycle bin management" to confirm the instance exists.
