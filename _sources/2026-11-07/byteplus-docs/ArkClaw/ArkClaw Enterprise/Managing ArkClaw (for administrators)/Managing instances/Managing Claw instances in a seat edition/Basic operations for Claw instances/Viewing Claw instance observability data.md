Administrators can view comprehensive observability data for a single Claw instance, including token usage, sessions, traces, logs, and more. **This article describes how to enter the Claw instance details page and view various monitoring information by tab.** 

<span id="q2kuuZ81"></span>
## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, choose "Claw Management \> Claw List".

3. The "Instances" tab displays the list of currently created employee Claw and shared Claw instances.

4. Click the target Claw instance name and navigate to each of the tabs to view various observability information.

   * **Monitoring: To evaluate the resource usage of a Claw instance or analyze Token consumption anomalies, you can go to this tab.** 

      You can monitor and view comprehensive usage data for each Claw instance in real time, covering task execution analysis, Token usage statistics, Token consumption trend visualization, and other core operational information. This supports fine\-grained usage management and cost control.

      Go to the "Monitoring" tab to view comprehensive usage data for the current Claw instance. For details, see [Viewing the monitoring dashboard for an ArkClaw instance](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_the_monitoring_dashboard_for_an_ArkClaw_instance?lang=en).

   * **Session analysis: To trace the complete context of a conversation or locate answer anomalies, you can go to this tab.** 

      You can view session analysis for a single Claw instance, which is used to track the complete interaction process of the Claw instance within a specific time period, facilitating problem location.

      Go to the "Session analysis" tab to view session analysis data related to the current Claw instance. For more details, see [Viewing ArkClaw sessions](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_sessions).

   * **Trace analysis: To troubleshoot request chain timeout or call failure issues, you can go to this tab.** 

      You can view Trace analysis for a single Claw instance, which is used to track the complete call chain of the Claw instance, making it easy to query call relationships and analyze chain issues.

      Go to the "Trace analysis" tab to view Trace analysis data related to the current Claw instance. For more detailed description, refer to: [View Claw instance Trace analysis](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_traces).

   * **Log analysis: To search Claw runtime logs by keyword or quickly locate the root cause of a failure, go to this tab.** 

      This feature provides log search and log analysis features for a single Claw instance, making it easy to search the logs of the Claw instance, quickly locate the root cause of failures, monitor system performance, and more.

      Go to the "Log analysis" tab to view log data related to the current Claw instance. For more details, see: [View Claw instance log analysis](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_log_analysis).

   * **Audit logs: To trace who performed which actions at what time for compliance audit requirements, go to this tab.** 

      You can view the audit logs of a single Claw instance, recording various historical operations during the use of the Claw instance. This is mainly intended for administrators, security compliance managers, and auditors, and is used for tracing operations and determining operation responsibility, while also meeting platform compliance management and external audit requirements.

      Go to the "Audit logs" tab to view audit logs related to the current Claw instance. For more details, see: [View Claw instance audit logs](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_audit_logs).

   * **Configuration changes: To confirm the time, content, and operator of a configuration modification, go to this tab.** 

      You can view the configuration change records of a single Claw instance, enabling configuration actions to be auditable and traceable, meeting compliance management requirements and maintaining stable system operation.

      Go to the "Configuration changes" tab to view configuration change records related to the current Claw instance. For more details, see: [View configuration change records of a single Claw instance](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_the_configuration_modification_records_for_an_ArkClaw_instance)..
