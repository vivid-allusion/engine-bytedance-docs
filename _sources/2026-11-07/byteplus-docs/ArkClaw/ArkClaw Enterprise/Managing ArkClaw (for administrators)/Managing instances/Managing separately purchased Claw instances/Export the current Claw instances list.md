This article describes how to export the full or filtered Claw instances list.

<span id="r9212rxV"></span>
## Procedure


1. Log in to [ArkClaw Enterprise Edition console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, select "Claw management \> Claw list".

3. In the upper right corner of the list, click the "Export current list" button.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If there are multiple tabs on the Claw list page, perform actions under the "Independently purchased instance" tab.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The data range exported by "Export current list" covers all Claw instances that have been created.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">To export instances based on specific conditions, first narrow the range using the search or filter feature, select the target instances, and then click the "Export" button in the bulk action bar at the bottom of the page.   </div>
   

4. Select the fields to be exported.

   The exported file can contain the following field information. You can select the necessary fields as needed.

   
   |**Field** |**Explain** |
   |---|---|
   |Name/ID |The name and unique ID of the Claw instance are mandatory fields for export. |
   |State |The current status of the Claw instance, such as "Running", "Inactive", and so on. |
   |User |The name of the enterprise employee to whom the Claw instance belongs. |
   |User email |The user's enterprise email address. |
   |User group |The user group to which the user belongs. |
   |Department |The name of the organizational department to which the user belongs, which facilitates statistics of instance distribution by organizational structure. |
   |Instance type |The specifications of the Claw instance. |
   |Creation time |The creation time of the Claw instance. |
   

5. Click the "Export" button and wait for the system to generate the export file. Once the file is generated, it will be automatically downloaded to your local device.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The exported file format is <code>.xlsx</code> (Excel), encoded in UTF\-8. If the number of instances is large, the export process may take several seconds. Please wait patiently.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The exported data contains employee names, email addresses, departments, and other information. Please keep the exported file safe to prevent data leakage.   </div>
