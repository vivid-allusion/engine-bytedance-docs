This article introduces how to manage Claw instances.

<span id="vRnmCr0w"></span>
## Procedure


1. Log in to [ArkClaw Enterprise Edition console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, select "Claw management \> Claw list".

3. On the Claw list page, manage Claw instances.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If there are multiple tabs on the Claw list page, perform operations under the "Independently purchased instances" tab.   </div>
   

   
   |Configuration reference |Application scenarios |
   |---|---|
   |[Automatically repair Claw instance](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_for_Claw_instances?lang=zh) |When a Claw instance becomes unavailable due to task exceptions, configuration adjustments, or other reasons, the administrator can use the auto healing feature to restore Claw to the most recent available status. |
   |[Use terminal to manage Claw instances](https://docs.byteplus.com/en/docs/ArkClaw/Use_the_terminal_to_manage_Claw_instances?lang=zh) |The administrator can access the Claw instance environment via terminal and use Shell commands to perform various O&M operations, such as creating tasks and configuring skills. |
   |[View Claw instance monitoring information](https://docs.byteplus.com/en/docs/ArkClaw/View_Claw_instance_observational_data?lang=zh) |The administrator can view comprehensive monitoring data for a single Claw instance, including Token usage, sessions, traces, logs, and more. |
   |[Restart Claw instance](https://docs.byteplus.com/en/docs/ArkClaw/Restart_Claw_instance?lang=zh) |When the administrator needs the Claw instance to load the latest configuration, or the Claw instance is responding slowly or tasks are frozen, the administrator can manually restart the target Claw instance. |
   |[Back up/restore Claw instance data](https://docs.byteplus.com/en/docs/ArkClaw/Backing_up_and_restoring_ArkClaw_instances?lang=zh) |When a Claw instance encounters interface freezing, unresponsive actions, or other exceptions that cannot be resolved by restart and auto healing, the administrator can restore a backup to roll back the instance to a normal status. |
   |[Restore Claw instance to factory settings](https://docs.byteplus.com/en/docs/ArkClaw/Restore_Claw_instance_to_factory_settings?lang=zh) |When a Claw instance experiences configuration corruption resulting in service crash, system failure, or abnormal status that cannot be resolved by restart and auto healing, the administrator can restore the Claw instance to factory settings and reset it to the initial available status. |
   |[Unified model switching for Claw instances](https://docs.byteplus.com/en/docs/ArkClaw/Bulk_switching_models_for_Claw_instances?lang=zh) |After the administrator modifies the available model or default model in model management, the change to the default model only takes effect for newly created Claw instances; existing instances are not updated automatically. |
   |[Claw instance global configuration](https://docs.byteplus.com/en/docs/ArkClaw/Global_settings_for_Claw_instances?lang=zh) |The administrator can configure data backup policies, data masking policies, and more for Claw instances with a single click. |
