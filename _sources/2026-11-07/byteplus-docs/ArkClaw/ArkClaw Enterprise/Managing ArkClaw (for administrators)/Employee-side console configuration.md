This topic describes how enterprise administrators can configure ArkClaw features available to employees in the ArkClaw console. By following the instructions in this topic, you can independently enable or disable specific features to meet requirements in different business scenarios.

<span id="lK4QihdR"></span>
## Operation instructions


* Configuration changes take effect immediately for all ArkClaw instances of enterprise employees. For spaces where ArkClaw instances already exist, confirm with the ArkClaw owners in advance before modifying configurations to avoid business disruption.

* Access to basic capabilities is non\-configurable **.**  These basic capabilities are essential for ensuring the normal functionality of ArkClaw, such as creating ArkClaw, adding new sessions, restarting ArkClaw, and logging out of ArkClaw.

* To lower the learning curve for new users, some commonly used or recommended features are enabled by default. Administrators can disable them manually as needed. Some advanced, scenario\-specific, or potentially cost\-incurring features are **disabled** by default. Administrators can **enable** them manually as needed.

## Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left\-side navigation pane, select "Enterprise Customization" \> "Employee Console Control".

4. After completing all settings, save the changes to apply them.

   * **Save changes**: Click "Save changes" in the upper\-right corner of the page. When the changes are saved, they take effect immediately for the employee\-side ArkClaw console.

   * **Discard changes**: To cancel all changes made in this edit operation, click "Discard changes" in the upper\-right corner. The page will revert to its original settings before you enter edit mode.
