The Sandbox Center provides enterprises with a secure code execution environment. After an administrator activates the sandbox service, when an employee initiates tasks that require code execution, the system automatically allocates available sandboxes without manual environment configuration. This ensures system stability while completing code tasks safely.

This topic describes how administrators activate the sandbox service, view preset sandbox settings and perform common management operations (such as deleting sandboxes) in the ArkClaw Enterprise Console.

<span id="TaGy3WCi"></span>
## Usage notes


* Sandbox instances are automatically created by the system based on end user tasks. Therefore, administrators do not need to manually create instances.

* The availability period of an instance is determined by the instance lifecycle settings. Upon expiration, the system automatically releases the instance.

## Activate the sandbox service

<span id="FmjNlqAC"></span>
### Scenarios

If you go to the "Capability Center \> Sandbox Center" page for the first time and the sandbox service has not been activated for the current workspace, you need to activate the sandbox service first. After the service is activated, the system will automatically preset a default sandbox for subsequent tasks.

<span id="nxRY79iN"></span>
### Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, click "Capability Center \> Sandbox Center".

3. On the activation guide page, read the on\-screen instructions and then click "Activate now".

   The page will display that the service is being activated. Wait about 1 to 2 minutes.

4. After the service is activated, you will be automatically redirected to the sandbox list page where the preset sandboxes are displayed.

## View preset sandboxes

<span id="gVQxitpr"></span>
### Scenarios

After the sandbox service is activated, the system will automatically preset a default sandbox. You can check whether the sandbox is available in the list and go to the details page to view the configuration and instance details.

<span id="vSPN1wYG"></span>
### Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, click "Capability Center \> Sandbox Center".

3. In the list, view the preset sandbox card and confirm that the sandbox is in the **Running** state. This indicates that it is available.

4. Click the target sandbox name or the "Details" button in the Actions column to view the sandbox configuration details.

## Delete sandboxes

<span id="Age2pjpb"></span>
### Scenarios

When a sandbox is no longer in use, you can delete it in the Sandbox Center to reduce unnecessary management costs.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Sandbox deletion is a high\-risk operation.‌ Upon deletion, the sandbox and all its running instances will be ‌permanently terminated without recovery, potentially affecting the results of active task executions. Verify that no users are currently relying on related tasks before proceeding.</div>


<span id="nlvsgEtA"></span>
### Procedure


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, click "Capability Center \> Sandbox Center".

3. In the sandbox list, find the target sandbox and click "Delete" in the Actions column.

4. In the confirmation pop\-up window, confirm the information and click the "Delete" button to complete the deletion.
