This topic explains how to view, install, and manage skills in the ArkClaw console.

<span id="YXfsZfMi"></span>
## Background information

ArkClaw Enterprise Skill Center is a marketplace where ArkClaw offers skills. Administrators can centrally configure commonly used skills, such as code review, document translation, and data querying, for their employees' Claw instances. This improves team productivity. All public skills have passed platform security checks, and administrators can manage and control the skills they upload.

<span id="FGwcjMyM"></span>
## Skill Square

Skill Square offers a variety of skills. You can view a list of these skills and their details, upload private enterprise skills, and download and install them on specific Claw instances. You can also add skills to the featured list or a skills library.

Skill Square presents skills in two categories:


|Category |Content |
|---|---|
|Visibility |All, Enterprise Upload, Public Skills, and Personal Upload.<br><br><br>* Enterprise Upload: Skills uploaded by administrators using the ArkClaw Enterprise console. To make these skills visible to employees, administrators must assign them the necessary permissions.<br><br>* Personal Upload: Skills uploaded by employees using the employee console. They are visible only to the uploaders and administrators. To make these skills visible to other employees, administrators must assign them the necessary permissions.<br><br>* Public Skills: ArkClaw's pre\-built skills, which are visible to all users. |
|Use cases |All skills, recommended skills, featured skills, and skills for specific scenarios, such as design, multimedia processing, and document processing. |


<span id="dIB8ZDak"></span>
### View skills


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. The "Skill Center" page allows administrators to search for, sort, add skills to the featured list, and switch view on the "Skill Square" tab.

   
   |Operation |Description |
   |---|---|
   |Search for skills |You can search for skills using natural language or by featured status. |
   |Sort skills |Skills can be sorted in two ways: by rating or by download count. |
   |Switch view |The Skill Center page offers both card and list views. Card view is selected by default. |
   

4. (Optional) Click a skill card to access its details page.

   On the skill details page, view the skill's basic information and assessment report. On this page, administrators can add the skill to the featured list and download it to their devices.

   
   |Feature |Description |
   |---|---|
   |View basic information |The following basic information is displayed:<br><br><br>* Featured: Indicates whether the skill is featured. Administrators can set or remove a skill as featured in the upper\-right corner of the skill details page.<br><br>* Type: Indicates whether the skill is public.<br><br>* Downloads: Indicates the number of times the skill has been downloaded.<br><br>* Scene: Displays the best use cases that are automatically assigned by the system.<br><br>* Source: Indicates the source of the skill.<br><br>* Installation prompt: Displays the prompt that employee users can send to ArkClaw to install the skill.<br><br>* Update time: Indicates the time when the skill was last updated.<br><br>* Slug: Displays the skill's unique short identifier in English. |
   |Skill assessment report |A skill assessment report is an automated report that evaluates the quality of the skills submitted by a large group of users. The report **compares scenarios with and without a skill** to demonstrate actual improvements in areas such as **task pass rates, time, and token usage**. Transforming subjective validation into objective metrics is a key feature of the report.<br><br>All assessment data is **manually reviewed** before publication to ensure reliability and security. |

Administrators can add a skill to the featured list or remove it from the list. For more information, see [Featured skills](https://docs.byteplus.com/en/docs/ArkClaw/Managing_skills?lang=zh&TagIDs=2,522,512#mpYPOxxB).

### Add a skill to a skills library

Administrators can choose to add a skill to one or more skills libraries. For more information, see [Skills libraries](https://docs.byteplus.com/en/docs/ArkClaw/Managing_skills?lang=zh&TagIDs=2,522,512#RZZhKjPf). To add a skill:


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the "Skill Square" tab, select the desired skill card and click "Join The Skills Library".

4. In the panel that appears, select the desired skills library and click "Join The Selected Skills Library".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">In Skill Square, you can select multiple skill cards and click "Join The Skills Library" at the bottom of the page to add skills in bulk.   </div>
   

<span id="fLSuNgvb"></span>
### Download a skill

Administrators can download the skill package directly to local devices.


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. Select "... \> Download" from either the skill card or the skill list. This will save the package to your local device.


<span id="NCt0sU5J"></span>
### Install a skill

Administrators can install skills directly onto ArkClaw instances.


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. Select "... \> Install to Claw" from either the skill card or the skill list.

4. In the "Select Claw" panel that appears, select one or more ArkClaw instances and click "Install to Selected Claw".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">In Skill Square, you can select multiple skill cards and click "Install to Claw" at the bottom of the page to install skills in bulk.   </div>

### Upload skills

Administrators can upload skills to Skill Center.

Skills uploaded by administrators using the console are classified as private enterprise skills and are visible only to administrators. To make these skills visible to employees, administrators must add them to a skills library and configure employee permissions. For more information about configuring permissions, see [Managing resource permissions](https://docs.byteplus.com/en/docs/ArkClaw/Managing_resource_permissions?).


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the "Skill Square" page, click "Upload Skill". Then, specify the skill parameters in the right pane.

   
   |Parameter |Description |
   |---|---|
   |Upload Skill |Currently, you can only upload compressed files for skill packages.<br><br>Administrators can click or drag a skill package to the upload area. Requirements for the skill package:<br><br><br>* Only the .zip format is supported, with a maximum file size of 25 MB.<br><br>* After extracting the zip file, you should find that there is precisely one folder. The folder name corresponds to the skill name specified in SKILL.md.<br><br>* SKILL.md must be placed directly inside the root directory of that folder.<br><br>* The skill name must meet these requirements:<br><br>   * Must not be empty;<br><br>   * Maximum of 64 characters;<br><br>   * Must only contain lowercase letters, numbers, and hyphens (\-);<br><br>   * Must not contain XML tags;<br><br>   * Must not contain the platform reserved word "agentkit".<br><br>* The skill description must meet these requirements:<br><br>   * Must not be empty;<br><br>   * Maximum of 10,000 characters;<br><br>   * Must not contain XML tags;<br><br>   * The skill name and description must be placed in the YAML Frontmatter of the SKILL.md file.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Administrators can click "Download sample" to view the detailed requirements for skill packages.</div><br> |
   |Name |It is automatically filled in once the compressed file has been uploaded. It cannot be modified. |
   |Description |It is automatically filled in once the compressed file has been uploaded. Manual modification is supported. |
   |Skills Libraries |You can add the skill to an existing skills library. You can also choose not to add the skill to a library now and add it manually later if needed. For instructions, see [Add skills to a skills library](https://docs.byteplus.com/en/docs/ArkClaw/Managing_skills?&TagIDs=2,522,512,502#y6VtK9jw). |
   

4. Once you have finished configuring, click "OK".

## Featured skills

The Featured tab is used to centrally manage and display skills recommended by administrators. From this tab, you can view and adjust the order of the featured skills, or remove them. For information about adding skills to the featured list, see [Add a skill to the featured list](https://docs.byteplus.com/en/docs/ArkClaw/Managing_skills?lang=zh&TagIDs=2,522,512,502#PlgQtyvc).

Once a skill is added, employees can view and use it on the "Skill Square" tab of "Skill Center" in the employee console.

<div data-tips="true" data-tips-type="default">Up to 100 skills can be featured.</div>



1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the "Skill Center" page, click the "Featured" tab. From there, administrators can perform various operations, such as sorting featured skills or removing a skill from the featured list.

## Skills libraries

A skills library is used to manage and control permissions for a group of skills.

In Skill Center, administrators can create a skills library and add specific skills from Skill Square for batch management and maintenance. They can also install skills in batches from the library onto one or more ArkClaw instances.

<span id="Jz81Kj4n"></span>
### Create a skills library


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the "Skill Center" page, navigate to the "Skills Libraries" tab and click "Create skills library".

4. Enter the name and description of the skills library, and click "Create skills library".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">You can delete a skills library by clicking "Delete" in the "Operation" column of the skills library list.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Deleting a skills library will not delete the associated skills.   </div>
   


<span id="y6VtK9jw"></span>
### Add skills to a skills library

A skills library can have up to 50 skills.


* Add skills when creating a skills library

   After creating a skills library, you will be redirected to the skills library page. Click "Add skill", select the desired skills, and then click "Add".

* Add skills to an existing skills library

   1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

   2. In the left navigation pane, select "Capabilities \> Skill Center".

   3. On the "Skill Center" page, navigate to the "Skills Libraries" tab. Then, click "Management Skills" in the "Operation" column of the skills library you want to manage.

   4. Click "Add Skills".

   5. Select the desired skills and click "Confirm add".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">You can remove a skill from the library by clicking "Remove" in the "Operation" column of the skill on the skills library page.   </div>
   

<span id="IUgfZvbp"></span>
### Install skills from a skills library

This operation installs all skills in the library onto the ArkClaw instances that you select. Installing a single skill is not supported.


1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the "Skill Center" page, navigate to the "Skills Libraries" tab. Then, click "Install to Claw" in the "Operation" column of the skills library you want to use.

   Alternatively, click "Management Skills" in the "Operation" column. On the skills library page, click "Install all skills" in the upper\-right corner.

4. In the "Select Claw" panel that appears, select the ArkClaw instances where you want to install the skills and click "Install to Selected Claw".

## Advanced configuration

Advanced configuration is used to set and manage the visibility of skills, as well as configure employee permissions to upload skills to the enterprise space.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Advanced configuration only applies to the current space and does not affect other spaces.</div>



1. Log in to the [ArkClaw Enterprise console](https://console.byteplus.com/arkclaw/enterprise).

2. In the left navigation pane, select "Capabilities \> Skill Center".

3. On the **Advanced configuration** tab, perform the following operations as needed:

   
   |Operation |Description |
   |---|---|
   |Allow employees to view and install open skills |Turn on **Allow employees to view and install open skills**.<br><br><br>* On: Employees can view and install all public skills.<br><br>* Off: Employees can only view and install skills that have been added to **skills libraries** by administrators.<br><br>   We recommend turning this off if your organization is subject to strict security and compliance requirements so that employees can only use skills that have been reviewed by administrators. |
   |Allow employees to upload skills to corporate space |Turn on **Allow employees to upload skills to corporate space**.<br><br><br>* On: Employees can upload skills that they created as private enterprise skills. This allows administrators to add the skills to skills libraries for other employees to use.<br><br>* Off: Only administrators can upload skills as private enterprise skills. |
