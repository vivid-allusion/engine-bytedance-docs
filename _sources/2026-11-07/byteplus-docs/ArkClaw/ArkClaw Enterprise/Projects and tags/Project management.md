ArkClaw supports activating independent ArkClaw spaces under different projects to facilitate unified multi\-project management. Resources (such as seats and Coding Plan packages) and billing (renewal and configuration changes) of each space are fully isolated and operate independently. Project management is a resource management method provided by the platform. This method allows you to group and manage resources based on businesses or projects. With Identity and Access Management (IAM), you can grant permissions to users by project (i.e., a group of resources) to ensure resource isolation and data security. You can also view resource bills by project to facilitate the calculation of resource costs.

For more information about projects, see [Managing projects](https://docs.byteplus.com/en/docs/6649/94333#%E9%A1%B9%E7%9B%AE%E7%AE%A1%E7%90%86).

## **Considerations**


* A space can only belong to one project, and only one space can be created under a project.

* Among ArkClaw\-related resources, only **spaces** support project management. Seats, Coding Plan, and Claw instances under a space are migrated together with the space.

* To assign different management permissions to multiple spaces for differentiated permission control, you can attach permission policies to IAM users and limit the resource scope to which those permissions apply.

## **Project management process**


1. [Create a project](https://docs.byteplus.com/en/docs/6649/94336#%E6%96%B0%E5%BB%BA%E9%A1%B9%E7%9B%AE): Create a project to manage an ArkClaw space.

2. [Activate a space](https://docs.byteplus.com/en/docs/ArkClaw/Quick_start_guide?lang=en#rH30UfdE): Activate a space under the target project.

3. [Grant permissions to IAM users on ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Authorizing_an_IAM_user_to_use_ArkClaw_Enterprise#5qQx0Wfg): Grant permissions to different IAM users on the ArkClaw space under the specified project.

4. (Optional) [View bills by project](https://docs.byteplus.com/en/docs/byteplus-platform/docs-bill-details#.5LiA44CB6LSm5Y2V5piO57uG): Filter bills based on projects.


<span id="sq6Ct79T"></span>
## View resource details of projects

You can view the project to which the current space belongs on the "Space overview" page of the ArkClaw Enterprise console.
