## File processing and material space

Learn how to process multimodal files, access professional databases, and obtain real\-time information from the web.


|Type |Feature |Description |Related documents |
|---|---|---|---|
|File and storage management |Uploading and processing files |ArkClaw provides convenient features such as local file upload, file preview, intelligent processing, and zoom preview. You can quickly complete intelligent identification and in\-depth analysis of files by uploading local files or copying and pasting files, enriching chat scenarios and boosting processing efficiency. |[Uploading and processing files](https://docs.byteplus.com/en/docs/87732/2280226) |
||Cloud disk |You can use a [Torch Object Storage (TOS)](https://docs.byteplus.com/en/docs/6349) bucket from TOS as a cloud disk to quickly upload files to and download files from the cloud. ArkClaw can use files from the cloud disk as task materials, and can also place files generated after task execution (such as documents, images, and videos) into the cloud disk. This makes the files available for you to download locally. |[Using cloud disk feature to upload/download files](https://docs.byteplus.com/en/docs/87732/2266928) |
||File space |During daily use, ArkClaw generates various files (such as presentations, documents, images, videos, and code) in its workspace (.openclaw/) based on your task requirements. The **file space** feature allows you to perform complete file management operations such as uploading, downloading, browsing, and deleting files in this directory while ensuring system security. |[Managing ArkClaw workspace files](https://docs.byteplus.com/en/docs/ArkClaw/Managing_ArkClaw_workspace_files_) |
|Data and information retrieval |Using professional databases |The ** professional database ** feature is available. This allows ArkClaw to quickly retrieve key information, such as A\-share market data, commercial risks, and macroeconomic metrics. The data comes from professional databases deeply integrated with authoritative data sources across various domains (including finance, economy, enterprise, and meteorology). This improves information retrieval efficiency and accuracy in demanding decision\-making scenarios. |[Using professional databases](https://docs.byteplus.com/en/docs/ArkClaw/Using_professional_databases_) |
||Online search |Real\-time online search capability is available. This allows ArkClaw to retrieve publicly available internet information during responses to obtain the latest external and real\-time information. |[Online search](https://docs.byteplus.com/en/docs/ArkClaw/Managing_online_search) |
