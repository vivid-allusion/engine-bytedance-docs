## May 2026


|**Release date** |**Version number** |**Update content** |
|---|---|---|
|05\-21 |Ark\-BP\-26.5.21 |**New features:** <br><br><br>* Added the collaboration mode that supports multi\-user collaboration within the same project, which improves the parallel task efficiency of the team. The specific capabilities include:<br><br>   * Collaboration mode usage: Provides the basic entry point for using the collaboration mode and allows multiple members to access the same task context.<br><br>   * Project management: Allows you to create, configure, and archive collaboration projects.<br><br>   * Project member management: Allows you to add or remove members for a project and configure operation permissions of project members.<br><br>   * Custom expert management: Allows you to configure and manage custom expert roles at the project level.<br><br>   * Memory inheritance and experience feedback: Added a memory inheritance mechanism that allows team members to share historical context within a project. This enables experience accumulation and knowledge feedback.<br><br>* Added the ability to enable and disable ArkClaw plugins. You can now enable or disable plugins as needed.<br><br>* Added a one\-click cleanup feature to quickly clear the local storage cache data of ArkClaw and effectively free up space. |
