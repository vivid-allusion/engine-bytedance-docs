Based on industry best practices, BytePlus has multiple high\-quality templates preset in the ArkClaw platform. This aims to help enterprises implement AI capabilities quickly and cost\-effectively.

Each template has preconfigured the required skills plugin and soul settings. You only need to select a template that fits your business scenario to [create an agent team with one click](https://docs.byteplus.com/en/docs/ArkClaw/Building_agent_teams_with_one_click_),This offers a true "out\-of\-the\-box" experience.

<span id="MZzeKOLy"></span>
## Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/management).

2. In the left navigation pane, click "Agent Center". On the Agent Gallery page, you can perform the following operations.

   
   |Operation |Description |
   |---|---|
   |Search and locate templates |Locate templates quickly through either global browsing or precise search:<br><br><br>* **Global browsing**: All expert templates are displayed as cards, with each card corresponding to a specific business scenario (for example, video generation expert and document parsing expert).<br><br>* **Precise search**: Enter the template name or a core keyword in the search box at the top\-right corner of the page to quickly locate the target template. |
   |Evaluate and select templates |Evaluate and select the appropriate target template by viewing template details and usage popularity.<br><br><br>* **Capability details**: Select the target template and click "Details" to view the template details, such as "My introduction", "What can I do for you?", "You can start like this", and "Built\-in skills". This helps you decide whether the template matches your business scenario.<br><br>   * **My introduction**: Provides a brief description of the agent's core feature to help you quickly determine whether it meets your current business needs.<br><br>   * **What can I do for you?** : Lists major applicable scenarios of the agent for your reference.<br><br>   * **You can start like this**: Provides a variety of preset example scenarios and automatically fills in example prompts, helping you quickly try out the agent and experience its capabilities and performance. Procedure:<br><br>      1. Click the example scenario that meets your needs.<br><br>      2. Try the agent and view the execution results:<br><br>         * **If the agent has been added**<br><br>            If the agent [has been added to the target agent team](https://docs.byteplus.com/en/docs/ArkClaw/Building_agent_teams_with_one_click_), the system will automatically prefill the example prompt (prefilled content) in the input box of a new conversation. You can manually send the prefilled content directly, or edit and optimize the prompt (prefilled content) based on your business needs before manual submission and sending.<br><br>         * **If the agent has not been added**<br><br>            If the agent has not yet been added to the target agent team, the system will automatically [add it to your agent team](https://docs.byteplus.com/en/docs/ArkClaw/Building_agent_teams_with_one_click_) and prefill the example prompt (prefilled content) in the input box of a new conversation. You can manually send the prefilled content directly, or edit and optimize the prompt (prefilled content) based on your business needs before manual submission and sending.<br><br>   * **Built\-in scheduled tasks**: Preset automatic scheduling tasks for the agent. For more information, see [Viewing and adding scheduled tasks preset in agent templates](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_and_adding_scheduled_tasks_preset_in_agent_templates).<br><br>      > Currently, only some agent templates have scheduled tasks preset.      <br>      <br><br>   * **Built\-in skills**: Integrated tools and analytical capabilities of the agent. They are automatically invoked on demand during conversation execution and require no manual configuration.<br><br>* **Update date:**  The bottom of the card shows the release date of the template's latest version (for example, `2026-05-18`). This helps check whether a template is being continuously iterated and optimized​. |
   |Use the template |After you select a template card, click the "Add and initiate task" button to quickly create an ArkClaw instance. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Building_agent_teams_with_one_click_). |
