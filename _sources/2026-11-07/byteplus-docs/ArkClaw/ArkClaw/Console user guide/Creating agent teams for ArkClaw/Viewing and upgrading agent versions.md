The ArkClaw platform continuously iterates on agent templates to expand and refine the business capabilities and improve runtime stability. You can check the current version of a template at any time and upgrade it as needed to access the latest capabilities.

<span id="pjrgOrlS"></span>
## Usage notes


* New versions offer additional capabilities, optimizations, and stability improvements. We recommend that you upgrade promptly when a new version becomes available.

* If an error occurs during the upgrade or the upgrade fails, the system automatically retains the previous version. This enables your template and business to continue to run normally.


<span id="RtABlC84"></span>
## Procedure

<span id="4Z2B2MBk"></span>
### Step 1: View agent template versions and update details


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/) and switch to the target ArkClaw page.

2. In the left navigation pane, click "Agent Gallery" to open the template list.

   * **View the current agent version**

      Select the target template and click the "Details" button to view the current version (for example, v1.0.0) of your agent.

   * **Check for an available update and update details**

      1. **Check for an available update**: If a new version is available for an agent template, a blue **New version** button appears in the bottom\-right corner of the agent template card.

         <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="3">tip         </div>
         

         <div data-tips="true" data-tips-type="default" data-wrapper-indent="3">A blue <strong>New version</strong> button appears on an agent template card only when a new version is available for the corresponding template.         </div>
         

      2. Click the "New version" button to view the latest version of the template and relevant information, such as updated content and historical versions.


<span id="DepAjU9b"></span>
### **Step 2: Upgrade the agent version**


1. To upgrade the agent version of a template, click the "Upgrade now" button.

2. (Optional) If a new version of the agent team plugin is available, click the "Upgrade now" button to update the plugin.

   > The system automatically validates the underlying dependencies of the current ArkClaw. If the agent team plugin is not the latest version, the message "Upgrade the agent team plugin before upgrading the agent template" appears. If the plugin version is already the latest, this step is automatically skipped.   
   

3. After the plugin upgrade completes, click "Upgrade now" again to upgrade the agent template.
