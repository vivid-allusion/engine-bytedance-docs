On the ArkClaw management platform, you can quickly view an overview of your created ArkClaw instances, and perform operations such as unsubscription and renewal. You can also enter the target ArkClaw details page to view its token usage, security logs, and other information, and manage advanced configurations such as agent teams, message channels, souls, and workflows.

<span id="BU4WvDVQ"></span>
## Feature overview


|**Feature** ||**Description** |**Reference** |
|---|---|---|---|
|Viewing ArkClaw details |Status and usage |View the health status, basic information, token usage, reserved storage capacity, number of processed messages, and trends of ArkClaw. |[Viewing ArkClaw status and usage](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_status_and_usage_) |
||Security logs |Enable or disable AI security assistant to view ArkClaw\-related risk events. |[Viewing ArkClaw security logs](https://docs.byteplus.com/en/docs/ArkClaw/Viewing_ArkClaw_security_logs_) |
|Modifying ArkClaw configuration |.md file |By configuring content in Markdown (MD) format, you can set independent codes of conduct, workflows, agent profiles, and user profiles for ArkClaw and all agents in your team. This enables your ArkClaw to evolve into a dedicated intelligent assistant with a clear identity, defined boundaries, and standardized work habits. |[Configuring Markdown files](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_md_files?lang=en) |
||Message channel |If you have created an agent team for ArkClaw, in addition to configuring message channels (such as Feishu and DingTalk) for the primary agent, you can also configure independent message channels for other agents in the team. |[Configuring independent message channels for agents in team](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_message_channels_1) |
||ArkClaw plugins |ArkClaw feature extension components can be flexibly enabled or disabled, allowing you to use various extended service capabilities as needed. |[Enabling/Disabling ArkClaw plugins](https://docs.byteplus.com/en/docs/ArkClaw/Enabling_Disabling_ArkClaw_plugins) |
|Specification change |Upgrade specification |Upgrade the current ArkClaw to a higher configuration for greater computing power, larger storage capacity, and more features. Upgrade Starter/Standard edition to a higher specification to gain greater computing power and larger storage capacity. |[Upgrading ArkClaw specification](https://docs.byteplus.com/en/docs/ArkClaw/Upgrading_ArkClaw_specification_) |
|Lifecycle management |Instance deletion |During the resource retention period, you can proactively delete ArkClaw to release idle resources in a timely manner and optimize your usage experience. |[Deleting ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Deleting_ArkClaw_) |
||Activate upon expiration |This provides exclusive post\-expiration activation for ArkClaw instances obtained as complimentary benefits with ModelArk Coding Plan subscriptions. Users can activate the service within the benefit validity period to enable related features. |[Activating ArkClaw upon expiration](https://docs.byteplus.com/en/docs/ArkClaw/Activate_upon_expiration) |
||Renewal |To ensure your ArkClaw can be used continuously for a long period, renew it before expiration to extend its validity. |[Renewing ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Renewing_ArkClaw) |
||Unsubscribe |To avoid unnecessary fees, unsubscribe from ArkClaw if you no longer need it. |[Unsubscribing from ArkClaw](https://docs.byteplus.com/en/docs/ArkClaw/Unsubscribing_from_ArkClaw) |
|Disaster recovery and backup |Backing up and restoring ArkClaw data |This feature can fully restore the ** entire ArkClaw system and all data** to the state at the time corresponding to your selected backup. After restoration, the system will be the same as its state when the backup was created. |[Backing up and restoring ArkClaw data](https://www.volcengine.com/docs/87732/2275232?lang=zh) |
| |Clearing ArkClaw storage cache data |You can use the one\-click cleanup feature to safely and quickly free up storage capacity on your ArkClaw. This feature only clears temporary cache data generated during ArkClaw runtime. It does not affect your personal data, installed skills, or plugins. |[Clearing ArkClaw storage cache data](https://docs.byteplus.com/en/docs/ArkClaw/Clearing_ArkClaw_storage_cache_data0?lang=en) |
