If ArkClaw experiences anomalies such as interface freezes or unresponsive operations that cannot be resolved by [restarting ](https://docs.byteplus.com/en/docs/ArkClaw/Restarting_ArkClaw_1)or [auto healing](https://docs.byteplus.com/en/docs/ArkClaw/Auto_healing_of_ArkClaw_), and you do not want to restore ArkClaw to factory settings, you may try restoring from a backup to fix the issue.

This feature can fully restore the ** entire system and all data ** to the state at the time corresponding to your selected backup. After restoration, the system will be the same as its state when the backup was created.

<span id="zp6Fr8X3"></span>
## Back up ArkClaw data

<span id="mPbyo10W"></span>
### Enable or disable automatic backup

Automatic backups are generated by the system based on the preset rules. No manual creation is required. Once enabled, backups are generated automatically every 24 hours.


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page and click the Claw details page icon in the upper\-right corner.

3. Click the "Data backup" tab.

4. Perform the corresponding operations as needed.

   
   <Tabs>
   <Tab zoneid="9mOoN6nv" title="Enable automatic backup">
   <TabTitle>Enable automatic backup</TabTitle>
   
   ArkClaw has automatic backup enabled by default for round\-the\-clock, uninterrupted automatic backup. If automatic backups are not currently enabled for your ArkClaw (for example, disabled manually or not enabled automatically), you can manually enable the feature as needed.
   
   
   > * For ArkClaw purchased at or after 20:32 on March 27, 2026, **automatic backup is enabled by default ** after purchase.
   
   > * For ArkClaw purchased before March 30, 2026, automatic backup can be ** automatically enabled ** or **manually enabled​** :
   
   >    * **Automatically enabled**: If your ArkClaw was purchased before 20:32 on March 27, 2026, and **had** activity records within the 7 days before this date (for example, you used ArkClaw and received a reply), the system automatically enables backups at a random exact hour (such as 15:00) on March 28. After that, subsequent backups are performed at this time by default.
   
   >    * **Manually enabled**: If your ArkClaw was purchased before 20:32 on March 27, 2026, and had **no** activity records within the 7 days before this date, you can manually enable automatic backups. After you enable them, subsequent backups are performed at this time by default.
   
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   
   * <div data-tips="true" data-tips-type="warning">After a new daily backup is generated, the system automatically overwrites the previous backup and retains only the latest one.</div>
   
   
   * <div data-tips="true" data-tips-type="warning">When automatic backup is enabled for the first time, no historical backup exists.</div>
   
   
   
   In the automatic backup section, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_2fb5397e4359f2ce08d78d74ba660840.png) </span> button to enable auto\-backup. After auto\-backup is enabled, the system automatically creates a backup for you every 24 hours.
   
   
   </Tab>
   <Tab zoneid="sDPFEb4k" title="Disable automatic backup">
   <TabTitle>Disable automatic backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After automatic backup is disabled, the system will no longer perform automatic backup. Existing backup data will be retained for 24 hours and then automatically cleared.</div>
   
   
   
   1. In the manual backup zone, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_3cf48aef7337a215cd0f0995b97bdc8b.png) </span>.
   
   2. Click the "Confirm" button to complete the operation.
   
   
   </Tab>
   </Tabs>

### Manage manual backups

Manual backup requires you to actively create backup files.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">Manual backups have a maximum retention period of 30 days and will be automatically deleted after 30 days.</div>


* <div data-tips="true" data-tips-type="default">Each time you manually create or update a backup, a new backup is generated. When you create a new backup or perform a re\-backup, the system automatically overwrites the original backup and retains only the latest manual backup.</div>


* <div data-tips="true" data-tips-type="default">If auto\-backup is enabled, the system suspends auto\-backups while a manual backup is in progress, and resumes them after the manual backup completes.</div>


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page and click the Claw details page icon in the upper\-right corner.

3. Click the "Data backup" tab.

4. Perform the corresponding operations as needed.

   
   <Tabs>
   <Tab zoneid="aHvGAsSn" title="Create manual backup">
   <TabTitle>Create manual backup</TabTitle>
   
   You can manually create a backup of the current system or data at any time as needed for subsequent restoration. This method can improve operational flexibility, effectively reduce exceptions caused by misoperations, and safeguard your data security.
   
   
   1. In the manual backup area, click the "Create backup" button.
   
   2. Enter the backup Name, and click "Confirm" to complete the procedure.
   
      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
      
   
      <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Backup creation is expected to take 2\-3 minutes. Please wait patiently.   </div>
      
   
   3. (Optional) Select the target backup, and click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_230120cf5b3576b528e7e79065649b4e.png) </span> icon to change the backup name.
   
   
   </Tab>
   <Tab zoneid="xc1T3wjY" title="Re-create manual backup">
   <TabTitle>Re-create manual backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">Updating the backup again will overwrite your current backup. Please proceed with caution.</div>
   
   
   
   1. In the manual backup zone, click the "Back up again" button.
   
   2. Enter the backup name, and click "Confirm" to complete the procedure.
   
   
   </Tab>
   <Tab zoneid="cTV06G0m" title="Delete manual backup">
   <TabTitle>Delete manual backup</TabTitle>
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">After you delete a backup, it cannot be restored. Proceed with caution.</div>
   
   
   
   1. In the manual backup zone, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_24415465a0f14dc8d04bf98bef3f9872.png) </span> icon in the lower\-left corner.
   
   2. Confirm the backup to be deleted and click the "Confirm" button to complete the operation.
   
   
   </Tab>
   </Tabs>

## Restore ArkClaw

You can restore ArkClaw data using automatically generated or manually created backups as needed.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">After restoration, current data will be lost and the system will be restored to the state corresponding to the backup. Proceed with caution.</div>



1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page and click the Claw details page icon in the upper\-right corner.

3. Click the "Data backup" tab.

4. Select the backup file to restore ArkClaw.

   * To use an automatically generated backup file: In the automatic backup area, click the "Restore" button.

   * To use a manually created backup file: In the manual backup area, click the "Restore" button.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">For ArkClaw purchased at or after 20:32 on March 27, 2026, no backups are currently available. The system starts the first automatic backup at approximately 9:00 on the same day. If ArkClaw is purchased at or after 9:00 on that day, the first backup is postponed to be generated at approximately 9:00 on the next day.   </div>
   

   * <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">For ArkClaw purchased before 20:32 on March 27, 2026, the automatic backup time is based on when it was automatically or manually enabled.   </div>
   

5. Confirm the backup to restore and click the "Confirm" button to complete the operation.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After restoration, Arkclaw will restart. Please wait patiently.   </div>
   

6. View the restoration result.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Archive restoration takes 1–2 minutes. Please wait patiently.   </div>
   

   * **Restored**: If "Arkclaw backup restored" appears, you can start a normal chat.

   * **Recovery failed**: If "Failed to restore ArkClaw backup" appears, you can retry restoration following the steps above, or access support via [feedback](https://docs.byteplus.com/en/docs/ArkClaw/Feedback__).
