Tools are callable extended capabilities that ArkClaw provides to help agents perform specific tasks. Once a specific tool is enabled, your agent can invoke external features as needed during conversations to perform extended operations beyond the capabilities provided by the model itself.

ArkClaw is pre\-installed with a set of tools by default, which are ready to use out of the box. However, not every agent requires all tools. For example, an agent dedicated to code review might not need a file management tool. After you ** build an agent team** for ArkClaw, you can enable and disable ** tools for each agent ** to retain only the capabilities the agent truly needs. This ensures both security and efficiency.


* **Enable a tool**

   After you enable a tool, ArkClaw can invoke the corresponding external capabilities during conversations and provide extended services based on the features.

* **Disable a tool**

   After you disable a tool, ArkClaw will no longer invoke the capabilities of this tool during conversations.

## Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page and click the Claw details page icon in the upper\-right corner.

3. On the ArkClaw details page, click the "Agent team" tab.

4. Select the target agent from the agent list on the left.

5. In the "Tools" section, click the "Edit all" button.

6. In the All tools dialog, enable or disable the tool capabilities for the target agent as needed.

   * **Enable/batch enable**:

      * Enable individually: Click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_036005a10ca27ca2322c30b2c2317f38.png) </span> icon to the right of the target tool to enable it.

      * Enable in batches: Select multiple tools, click "Batch enable", and then click "Enable" to complete the operation.

   * **Disable/batch disable**

      * Disable individually: Click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_4e49b8d191341a5353e9a4be1685fc9d.png) </span> icon to the right of the target tool to disable it.

      * Disable in batches: Select multiple tools, click "Batch disable", and then click "Disable" to complete the operation.
