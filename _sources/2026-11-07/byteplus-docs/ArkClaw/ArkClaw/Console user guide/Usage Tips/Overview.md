To help you use ArkClaw more efficiently, BytePlus provides a variety of features. Convenience features are designed for daily scenarios, allowing you to perform common tasks without accessing the ArkClaw deployment environment. Advanced features address more complex ArkClaw control needs, suitable for scenarios such as troubleshooting, repair, and environmental adjustments.

<span id="jxZbXsfU"></span>
## Convenience features


|Feature |Description |
|---|---|
|[Initiating tasks](https://docs.byteplus.com/en/docs/87732/2277078) |By default, purchased ArkClaw has only one conversation task. If you want to start a new task unrelated to the current conversation while keeping your existing conversation for parallel task processing, you can create a new conversation. |
|[Using quick commands](https://docs.byteplus.com/en/docs/87732/2275055) |ArkClaw includes preset commands for common operations, such as creating a new conversation, viewing system status, and clearing the context. You can send these commands with one click to let ArkClaw perform the corresponding operations. |
|[Learn and use skills](https://docs.byteplus.com/en/docs/87732/2266925) |ArkClaw includes some commonly used built\-in skills that can be automatically matched and called based on task requirements. You can install skill plugins for ArkClaw from channels such as ClawHub and BytePlus exclusive Skill Hub. You can expand new skills for ArkClaw in multiple fields, such as programming, browser operations, office work, and expert roles as needed. |
|[Viewing and configuring scheduled tasks](https://docs.byteplus.com/en/docs/87732/2266926) |ArkClaw can not only passively answer and address your questions in real time, but also execute the scheduled tasks you set and **proactively send you reminders**. |
|[Uploading and processing files](https://docs.byteplus.com/en/docs/87732/2280226) |ArkClaw provides convenient features such as local file upload, file preview, intelligent processing, and zoom preview. You can quickly complete intelligent identification and in\-depth analysis of files by uploading local files or copying and pasting files, enriching chat scenarios and boosting processing efficiency. |
|[Use cloud disk feature to upload/download files](https://docs.byteplus.com/en/docs/87732/2266928) |You can use a TOS bucket from [Torch Object Storage (TOS)](https://docs.byteplus.com/en/docs/tos/docs-what-is-tos) as a cloud disk to quickly upload files to and download files from the cloud. ArkClaw can use files from the cloud disk as task materials, and can also place files generated after task execution (such as documents, images, and videos) into the cloud disk. This makes the files available for you to download locally. |
|[Using Hermes Agent](https://docs.byteplus.com/en/docs/87732/2356398) |ArkClaw and Hermes complement each other perfectly. ArkClaw can integrate with message channels, makes decisions, and schedules tasks, while Hermes executes tasks and accumulates reusable skills. This allows you to enjoy the convenient cloud experience brought by ArkClaw, while also having an exclusive intelligent assistant that continuously learns and grows alongside you. |
|[Switching thinking mode](https://docs.byteplus.com/en/docs/87732/2277815) |You can flexibly switch among Fast, Standard, and Expert thinking modes based on task complexity and response time requirements. This helps match scenarios on demand, reduce redundant thinking time, and improve conversation efficiency. |
|[Taking over cloud PC](https://docs.byteplus.com/en/docs/87732/2300665) |A cloud PC is a fully functional cloud\-based virtual computer hosted in the ArkClaw environment. It provides a complete desktop operating environment, allowing you to browse the web pages and run or manage various applications just like on a local computer. |
|[Taking over cloud browsers](https://docs.byteplus.com/en/docs/87732/2276717) |ArkClaw may execute browser automation tasks or encounter graphical interface interactions that it cannot handle independently. These include complex graphic captchas, QR code login, high\-risk permission confirmation, and other similar scenarios. You can then manually take over the cloud browser and enter split\-screen mode to complete verification and processing. |
|[Accessing OpenClaw console](https://docs.byteplus.com/en/docs/87732/2300672) |ArkClaw is a cloud edition built on OpenClaw. It supports one\-click access to the **OpenClaw console** via cloud PCs, providing a visual operation and management experience. |
|[Switching execution mode of cloud PC](https://docs.byteplus.com/en/docs/87732/2306536) |Supports flexible switching among the auto mode, OpenClaw native mode, browser mode, cloud desktop mode, and OpenCli mode to match task complexity. |
|[Automated office capabilities of cloud PC](https://docs.byteplus.com/en/docs/ArkClaw/Automated_office_capabilities_of_cloud_PC_0) |Supports directly calling and running Office components in the cloud to automate the creation and processing of documents, spreadsheets, slides, and other files. |
|[Desktop operation recording and prompt generation](https://docs.byteplus.com/en/docs/ArkClaw/Desktop_operation_recording_and_prompt_generation) |Supports the generation of structured prompts via cloud PC operation recording. The prompts can be executed automatically in real time or saved as dedicated skills for reuse. |
|[Conversation retrieval](https://docs.byteplus.com/en/docs/ArkClaw/Conversation_retrieval_?lang=en) |This feature allows you to quickly search historical task content by keyword and jump to the corresponding conversation with one click. Whether you need to review previous communication details or continue a conversation in a previous session, this feature helps you locate information efficiently. |
|[Managing system notifications](https://docs.byteplus.com/en/docs/87732/2356378) |To ensure you stay updated with the latest developments of ArkClaw in real time, BytePlus provides a system notification mechanism. When ArkClaw releases version updates and new features, the platform will push relevant information to you in a timely manner. Additionally, you can configure third\-party message channels (such as Feishu and WeChat) to receive relevant messages anytime, anywhere. |
|[Feedback](https://docs.byteplus.com/en/docs/87732/2275227) |If you encounter unsolvable issues while using ArkClaw, or have new suggestions for ArkClaw, you may inform us via the feedback feature. |

## Advanced features


|Feature |Description |
|---|---|
|[Configure message channels](https://docs.byteplus.com/en/docs/87732/2279763) |ArkClaw supports integration with Telegram, Feishu, and Discord robots and other message channels. After the integration, you can chat with ArkClaw through the corresponding message channel. ArkClaw can also use bot capabilities to help you perform operations such as creating documents and scheduling calendar events. |
|[Restarting ArkClaw](https://docs.byteplus.com/en/docs/87732/2266924) |You can manually restart ArkClaw when you need to load new ArkClaw configuration or when ArkClaw responds slowly. |
|[Troubleshooting ArkClaw failures through AI diagnosis](https://docs.byteplus.com/en/docs/ArkClaw/Troubleshooting_ArkClaw_failures_through_AI_diagnosis) |AI diagnosis is a set of troubleshooting and recovery capabilities provided by ArkClaw. You can use this feature to identify and fix common operational issues in ArkClaw. When ArkClaw exceptions occur, such as no response or startup failure, you can manually trigger AI diagnosis, and the system will automatically perform troubleshooting and repair. |
|[Auto healing of ArkClaw](https://docs.byteplus.com/en/docs/87732/2270355) |When your ArkClaw becomes unavailable due to tasks, setting adjustments, or other reasons, you can use the auto healing feature to attempt to restore it to the latest available state. |
|[Restoring ArkClaw to factory settings](https://docs.byteplus.com/en/docs/87732/2270307) |You can reinitialize the ArkClaw service and reset it to its initial available state when the configuration is corrupted and causes a service crash, or when system failures or abnormal states occur and cannot be recovered. |
|[Accessing ArkClaw from terminals](https://docs.byteplus.com/en/docs/87732/2270411) |You can use terminals of the instance where ArkClaw is deployed to access ArkClaw and Shell commands to perform various operations (such as viewing directories and files in the current path, creating tasks, and so on). **This is suitable for technical developers who require advanced usage of ArkClaw**. |
