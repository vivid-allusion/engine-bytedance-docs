To facilitate saving, archiving, sharing, and summarizing the content of the current conversation, ArkClaw provides the "Download conversation" feature, which allows you to download the complete history of the current conversation to your local device.

<span id="OvO4psmk"></span>
## Usage notes

Downloading is supported only when there is chat history in the current conversation.

<span id="8iwHLFlc"></span>
## Procedure


1. Log in to[ the ArkClaw console](https://console.byteplus.com/arkclaw/), and switch to the target ArkClaw page.

2. In the "My tasks" module, select the target task for which you want to download the conversation content.

3. Click the "... \> Download conversation" button in the upper\-right corner to export the corresponding chat history as an .md file via your browser and download it to your local device.

4. After the download, you can view the corresponding conversation content on your local device.
