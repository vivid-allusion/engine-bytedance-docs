You can access ArkClaw from terminals and use Shell commands to perform various operations (such as viewing directories and files in the current path, creating tasks, and so on). **This is suitable for technical developers who require advanced usage of ArkClaw**.

<span id="ok2zMVi8"></span>
## Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page, click “··· ** \>**  View terminal” to enter the terminal page.

3. Enter the target command and execute it to complete the corresponding operation. Example:

   Execute the following command to view the current OpenClaw version.

   ```Bash
   openclaw --version
   ```
