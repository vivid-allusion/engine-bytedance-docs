ArkClaw is a cloud\-hosted version built on OpenClaw. It provides quick access to the OpenClaw console and offers visual resource operation and management capabilities.

<span id="HXwY8PRS"></span>
## Supported operations

> For more information on OpenClaw, refer to [OpenClaw official documentation](https://docs.openclaw.ai/zh-CN/web/control-ui).



|Operation |Description |
|---|---|
|View system status monitoring data |Allows you to monitor the Gateway service health, current session information, token consumption statistics, and resource usage in real time to fully track the system status. |
|Skill and plugin management |* Supports visually managing installed skills and plugins.<br><br>* Supports installing new skills from the ClawHub app store or enabling/disabling existing extension capabilities. |
|Configuration management |Allows you to visually edit system configuration parameters and configure integrations with third\-party channels such as Feishu, WeCom, and Telegram, as well as services like Notion and GitHub. |
|Task management |Allows you to view, create, edit, and delete cron jobs and reminders to manage automated tasks. |
|Memory management |Allows you to search, view, edit, and delete stored long\-term memory to manage personal data assets. |
|Troubleshooting |Allows you to view system runtime logs to diagnose tool invocation failures, authorization errors, response exceptions, and other issues. Use the troubleshooting skills to quickly locate issues. |
|Sessions |Allows you to view session history, manage isolated sub\-sessions, and debug multi\-session collaboration logic. |


<span id="EW2yuePb"></span>
## Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw.

3. In the upper\-right corner of the page, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_74d1fff235a715532181049f4c1f7cc3.png) </span>\> OpenClaw console".

4. (Optional) When accessing the OpenClaw console, you may need to install dependent system components. Click the "Auto healing" button to complete the installation.

   > The installation takes approximately 1\-2 minutes. Please wait until the installation finishes. After installation is complete, click "<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_4f429a026e85dfbbdb04997d75e5474b.png) </span>\> OpenClaw console" again.   
   

5. Enter the OpenClaw console to manage cloud resources visually.

   > [Read the documentation](https://docs.openclaw.ai/zh-CN/web/control-ui) before proceeding, and operate with caution.
