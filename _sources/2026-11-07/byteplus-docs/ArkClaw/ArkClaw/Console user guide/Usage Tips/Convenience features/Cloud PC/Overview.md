A cloud PC is a fully functional cloud\-based virtual computer hosted in the ArkClaw environment. Unlike a cloud browser, which is mainly used to perform browser tasks, a cloud PC provides a complete desktop operating environment that allows you to not only browse web pages but also run and manage various applications just like on a local computer.

## **Relationship between cloud PC and cloud browser**

To enhance the automated office experience, the **cloud browser** feature of ArkClaw has been fully upgraded to **cloud PC**. The two are not parallel modules, but have an inclusive relationship:


* **Cloud PC (recommended):**  The cloud PC has **fully integrated** the cloud browser feature. You can not only directly perform tasks such as web access and data extraction, but also manage various desktop applications just like operating a local computer.

* **Cloud browser**: You can still issue and execute web automation\-related commands. However, we recommend that you [upgrade to the cloud PC with one click](https://docs.byteplus.com/en/docs/ArkClaw/Using_cloud_PC_) to unlock the full desktop\-level environment.

## Usage notes


* It is only supported on **PCs**, **Feishu**, and **WeChat**.

* When you use an ArkClaw Starter instance, cloud PC operations may experience lag due to instance resource limitations. For better performance and smoother cloud experience, we recommend that you purchase a higher\-specification instance package. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Creating_your_dedicated_ArkClaw_with_one_click_).

* When cloud PC tasks are concurrently executed in multi\-agent or multi\-session scenarios, operation conflicts and mutual interference may occur. We recommend that you run only one cloud PC task at any given time within the same ArkClaw instance to ensure task execution stability.

* A cloud browser or cloud PC is not supported when the ArkClaw runtime environment is being modified or its business logic is unavailable. Specific scenarios include:

   * ArkClaw is in the initialization phase.

   * ArkClaw is in the process of restarting.

   * ArkClaw is being fixed.

   * ArkClaw is restoring factory settings.

   * The ArkClaw account is in arrears.
