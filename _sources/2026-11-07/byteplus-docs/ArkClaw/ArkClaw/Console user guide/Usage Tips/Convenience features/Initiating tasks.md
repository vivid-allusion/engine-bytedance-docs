By default, purchased ArkClaw provides only one conversation page for initiating conversation tasks. You can create a new conversation to start a brand\-new task unrelated to the current conversation while keeping your existing conversation for parallel conversation task processing. This allows you to switch task scenarios and avoid interference from historical conversations, and also supports categorized archiving and later review.

<span id="wYE48NPi"></span>
## Usage notes

To create multiple conversation tasks, you need to complete the first interaction in the newly created conversation before creating the next one.

**For example**: If you first create Conversation A, you need to complete the initial interaction in this conversation (i.e. send at least one message). After the operation takes effect, you can proceed to create Conversation B. By following this rule, you can create more new conversations in sequence.

<span id="OHGSaKor"></span>
## Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page. In the directory tree on the left, select "Initiate task" to create a new conversation.

3. You can also view the created conversations in the left navigation pane:

   * The first new conversation is named "New chat" by default. After the first round of conversation, the system will automatically rename it to the content of the first round of interaction, truncating any content beyond 60 characters. You can also[ manually rename](https://docs.byteplus.com/en/docs/ArkClaw/Initiating_tasks_#k40EXkE3) the conversation.

   * Subsequent conversations are automatically named using the content of the first message (truncated to a maximum of 60 characters). You can also[ manually rename](https://docs.byteplus.com/en/docs/ArkClaw/Initiating_tasks_#k40EXkE3) the conversation.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">You can view the new conversations created under an ArkClaw instance only after you switch to the ArkClaw page.   </div>
   

4. Enter the newly created conversation page to get started with ArkClaw.

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The platform provides a variety of preset scenario prompts. You can select them to start conversations quickly.   </div>
   

   1. <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Click the preset prompt (prefilled content).   </div>
   

   2. <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After confirming that the prompt (prefilled content) is correct, manually send the content directly, or edit and optimize the prompt (prefilled content) based on your business needs before manual submission and sending.   </div>
