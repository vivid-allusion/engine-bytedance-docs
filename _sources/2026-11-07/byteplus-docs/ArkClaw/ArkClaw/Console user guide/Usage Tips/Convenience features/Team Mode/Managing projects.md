After you create a collaborative project, you can manage the project based on your needs.

<span id="CKiRyrwd"></span>
## Create a new collaborative project


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Switch to the target ArkClaw page, and select "Initiate task" in the directory tree on the left.

3. In the ArkClaw chat box, switch to collaboration mode to create a new project. For detailed operations, refer to [Creating and initiating projects](https://docs.byteplus.com/en/docs/ArkClaw/Using_collaboration_mode_#q3VQe0ts).


<span id="id6xbIWj"></span>
## Modify project name

You can modify the project name based on your needs.


1. In the left navigation pane, click the name of the target collaborative project for which you want to modify the name.

2. Click "···  **\>**  Edit name" **.** 

3. Enter the name in the pop\-up dialog box, and click the "Confirm" button to complete the operation.


<span id="4bCWjsyb"></span>
## Suspend a project

You can suspend a project in **Running** or **Planning** status based on your actual business requirements.


1. In the left navigation pane, click the name of the project you want to suspend.

2. In the main chat interface of the project, click the "Project running" button at the top.

3. In the dialog box that pops up, click "Confirm" to complete the operation.

4. Click the "···  **\>**  Suspend" button to complete the operation.


<span id="7xS8eKld"></span>
## Resume a project

You can resume a project in **Suspended** status based on your actual business requirements.


1. In the left navigation pane, click the name of the project you want to resume.

2. In the main chat interface of the project, click the "Project suspended" button at the top to resume the project.


<span id="lagkA6nG"></span>
## Restart a project

You can restart a **failed** project based on your needs.


1. In the left navigation pane, click the name of the project you want to resume.

2. In the main chat interface of the project, click the "Restart" button at the top to resume the project.


<span id="9UnDLdLq"></span>
## Delete a project

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">You cannot delete a project that is being created.</div>


* <div data-tips="true" data-tips-type="warning">After a project is deleted, related historical messages and project outputs cannot be restored. Please proceed with caution.</div>


1. In the left navigation pane, click the name of the project to be deleted.

2. Click "···  **\>**  Delete" **.** 

3. In the dialog box that appears, click "Confirm" to complete the operation.
