ArkClaw provides multiple preset common experts. If they do not fit your use cases, you can configure custom experts in a new project. This topic describes how to manage custom experts.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">To add or update members for a running project, refer to <a href="https://docs.byteplus.com/en/docs/ArkClaw/Managing_projects_">Managing project members</a>.</div>


<span id="upi2w5h2"></span>
## Add a custom expert


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/welcome).

2. Switch to the target ArkClaw page, and select "Initiate task" in the directory tree on the left.

3. In the ArkClaw chat box, click the "+" button, and then click the "Enable" button next to **Collaboration mode** to enter collaboration mode.

4. In the **Create project** dialog box, click the "+ Custom member \> Custom member \> Custom expert" button.

5. Click the "Add expert" button. In the pop\-up dialog box, specify the **Name**, **Role**, **Skill**, and **Persona settings** parameters, and then click the "Confirm" button to complete the operation.

   * **Skill**: Grants the expert specific execution capabilities. You can select a skill from enterprise featured skills, BytePlus featured skills, and the skill marketplace. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Learning_and_using_skills_-?lang=en).

   * **Soul settings**: Defines the expert's unique identity, tone, and behavior, enabling it to maintain a consistent style and role across conversations. [Learn more](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_md_files).


<span id="VDUxWNWO"></span>
## Edit a custom expert


1. In the **Create project** dialog box, click the "+ Custom member \> Custom member \> Custom expert" button.

2. Click the "···  **\>**  Edit" button next to the target member.

3. In the pop\-up dialog box, update the name, role, skill, or soul settings of the expert.

4. Click "Confirm" to complete the operation.


<span id="egm7ysqk"></span>
## Delete a custom expert

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Before deleting a custom expert, confirm that it is not being called by any running project. If you delete a custom expert directly, all projects that depend on this expert may report errors or experience task interruptions. Please proceed with caution.</div>



1. In the **Create project** dialog box, click the "Custom member \> Custom expert" button.

2. Click the "···  **\>**  Edit" button next to the target member.

3. In the dialog box that pops up, click "Confirm" to complete the operation.
