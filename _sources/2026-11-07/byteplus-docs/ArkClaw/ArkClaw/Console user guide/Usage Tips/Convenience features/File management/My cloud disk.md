ArkClaw provides personal cloud disks that allow you to manage files, including uploading and downloading them.

<span id="dyZUAkgE"></span>
## Notes


* The maximum size allowed for a single file download is 512 MB. The maximum size for a batch download is 1 GB.

* The name cannot end with a space or a period (`.`), and it cannot contain any of the following characters: `\`, `/`, `:`, `*`, `?`, `"`, `<`, `>`, `|`, or `'`.


<span id="JUVIrHIj"></span>
## Use my cloud disk


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the desired ArkClaw instance. Then, select "File Management" in the left navigation pane.

3. On the file management page, select the "My cloud disk" tab on the right.


<span id="KrVXo0Zk"></span>
## Search for a file

Enter the full file name in the search box to locate the file. If the file name is incomplete, the search will fail.

<span id="y64TAXir"></span>
## Manage files

On the "My cloud disk" tab, you can quickly upload and download files and create new folders.


|Supported operations |Steps |
|---|---|
|Upload a file |1. On the "My cloud disk" tab, click "Upload" in the upper\-right corner **.** <br><br>2. From the drop\-down list, select "Upload File". Then, choose the file you want to upload and click "Open".<br><br>3. Alternatively, navigate to the target directory and drag and drop the file directly into it. |
|Download files |* To download a single file:<br><br>   On the "My cloud disk" tab, select the file you want to download and click "... \> Download" in the "Operation" column. This will download the file to your local device.<br><br>* To download files in batches:<br><br>   On the "My cloud disk" tab, select the files you want to download and click "Download" at the bottom. This will download the files to your local device. |
|Preview a file |On the "My cloud disk" tab, click the name of the file that you want to preview. On the "Details" page, you can view the file type, file size and modification time to verify the file status. |
|Delete files |* To delete a single file:<br><br>   1. On the "My cloud disk" tab, select the file you want to remove and click "... \> Delete" in the "Operation" column.<br><br>   2. In the "Delete confirm" dialog, click "Delete" to delete the file.<br><br>* To delete files in batches:<br><br>   1. On the "My cloud disk" tab, select the files you want to delete and click "Delete" at the bottom.<br><br>   2. In the "Delete confirm" dialog, click "Delete" to delete them all.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Exercise caution when deleting files. Once deleted, files cannot be recovered.</div><br> |
|Rename a file |1. On the "My cloud disk" tab, select the file you want to rename and click "... \> Rename" in the "Operation" column.<br><br>2. In the "Rename" dialog, enter the file name and click "Save" to rename the file. |
|Change file types |1. On the "My cloud disk" tab, select the file you want to manage and click "... \> Rename" in the "Operation" column.<br><br>2. In the "Rename" dialog, modify the file extension, and click "Save" to change the file type. |

On the "My cloud disk" tab, you can quickly upload, create, or delete folders.


|Supported operations |Steps |
|---|---|
|Upload a folder |1. On the "My cloud disk" tab, click "Upload" in the upper\-right corner **.** <br><br>2. From the drop\-down list, select "Upload Folder". Then, choose the folder you want to upload and click "Upload".<br><br>3. Alternatively, navigate to the target directory and drag and drop the folder directly into it.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">If the folder you are uploading is empty, the system will automatically skip it. |Delete folders |* To delete a single folder:<br><br>   1. On the "My cloud disk" tab, select the folder you want to remove and click "... \> Delete" in the "Operation" column.<br><br>   2. In the "Delete confirm" dialog, click "Delete" to delete the folder.<br><br>* To delete folders in batches:<br><br>   1. On the "My cloud disk" tab, select the folders you want to delete and click "Delete" at the bottom.<br><br>   2. In the "Delete confirm" dialog, click "Delete" to delete them all.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Exercise caution when deleting folders. |Rename a folder |1. On the "My cloud disk" tab, select the folder you want to rename and click "... \> Rename" in the "Operation" column.<br><br>2. In the "Rename" dialog, enter the folder name and click "Save" to rename the folder. |

## Transfer history

You can quickly view task history from "My cloud disk".


|Supported operations |Steps |
|---|---|
|View upload tasks |1. On the "My cloud disk" tab, click "Upload \> Transfer history" in the upper\-right corner **.** <br><br>2. In the "transfer history" panel, click the "Upload" tab to view the list of ongoing tasks and file upload progress. |
|View delete tasks |1. On the "My cloud disk" tab, click "Upload \> Transfer history" in the upper\-right corner **.** <br><br>2. In the "transfer history" panel, click the "Delete" tab to view deleted files and folders. |
