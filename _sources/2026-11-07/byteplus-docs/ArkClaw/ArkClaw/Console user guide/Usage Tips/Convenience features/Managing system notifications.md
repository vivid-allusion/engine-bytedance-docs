To ensure you stay updated with the latest developments of ArkClaw in real time, BytePlus provides a system notification mechanism. The platform will promptly push relevant information to you whenever ArkClaw undergoes version updates or feature releases. Additionally, you can configure third\-party message channels (such as Feishu and WeChat) to receive relevant notifications anytime and anywhere.

<span id="RBmGkDU9"></span>
## Prerequisites

By default, BytePlus only pushes system notifications to the ArkClaw console. To receive system notifications through third\-party message channels, [configure the message channels](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_independent_message_channels_for_my_agents_1) first.

<span id="V79jfrho"></span>
## View system notification details

This section uses viewing system notification details in ArkClaw as an example. You can configure message channels to receive and view notification details through third\-party message channels.


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/) and switch to the target ArkClaw page.

2. At the bottom of the directory tree on the left side of the ArkClaw conversation page, click the system notification icon to view an overview of notifications related to the current ArkClaw.

3. You can click the target notification as needed to view its details in the pop\-up window.


<span id="PnVKTGTu"></span>
## Modify system notification settings

After you configure Feishu, WeChat, and other [third-party message channels](https://docs.byteplus.com/en/docs/ArkClaw/Configuring_independent_message_channels_for_my_agents_1), the system will enable these channels for message push by default. You can enable or disable third\-party push services at any time based on your actual needs.


* **Enable**: Recommended. This can greatly improve notification delivery efficiency and avoid missing critical business information.

* **Disable**: To reduce message distractions, or if cross\-channel notification is not required in the current scenario, you can disable it at any time.

1. At the bottom of the directory tree on the left side of the ArkClaw conversation page, click the "System notification \> Settings" icon.

2. In the pop\-up window, modify the message channels for receiving system notifications and notification preferences as needed.

   
   |Configuration item |Description |
   |---|---|
   |Receiving channel |Enable or disable third\-party message channels for receiving system notifications. .<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Make sure that the corresponding message channels have been configured for your ArkClaw.</div><br> |
   |Notification preference |Select categories of ArkClaw\-related messages to be pushed by BytePlus. Supported:<br><br><br>* **Service and maintenance notification:**  **Enabled** by default and **cannot be disabled**. Includes core information such as ArkClaw version upgrades, feature updates, and system maintenance.<br><br>* **Benefits and promotion notification:**  **Enabled** by default and **can be disabled as needed**. Includes operational information such as promotional activities and product benefits. |
   

3. Once ArkClaw completes the update, your new configuration will take effect immediately.
