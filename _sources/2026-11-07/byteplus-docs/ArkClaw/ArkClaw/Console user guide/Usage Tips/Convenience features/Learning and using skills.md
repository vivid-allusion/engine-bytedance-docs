ArkClaw comes with a set of pre\-built skills for common tasks. It can automatically match and invoke these skills based on your requirements. At the same time, ArkClaw supports skill plugins from channels such as SkillHub and ClawHub. This lets you add new skills in areas such as programming, browsing and office tasks, as well as expert roles.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Essentially, skills are units of capability that encapsulate the logic for performing specific tasks. For example, using Python, performing addition, or speaking English are all skills. Similar to how you would select Python or English while coding, ArkClaw automatically selects the necessary skills from its "learned" skill set to complete a task. <a href="https://agentskills.io/home">Learn more</a>.</div>

## View installed skills

You can view your existing skills, including pre\-built and installed ones.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">ArkClaw provides a pre‑built browser and the necessary skills to help you quickly obtain and summarize the latest relevant information from websites. <a href="https://docs.byteplus.com/en/docs/ArkClaw/Using_ArkClaw_built-in_browser_to_obtain_webpage_information">Learn more</a>.</div>



1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the target ArkClaw instance.

3. You can view all installed skills in the following ways.

   * **Use a shortcut key**

      In the chat box, type "/". In the box that appears, select the "Skills" tab to view the skills you have installed.

   * **Use the "Add skills" module**

      Click "+ \> Add skills" at the bottom of the chat box to view the skills you have installed.

## Add skills to Agent

Skills represent ArkClaw's capabilities. Adding new skills expands its capabilities, enabling ArkClaw to assist you with a broader range of tasks.


<Tabs>
<Tab zoneid="DD79NDIkX4" title="Add a skill to multiple agents">
<TabTitle>Add a skill to multiple agents</TabTitle>

This section applies when you have created multiple agents for your ArkClaw instance and want to add a skill to them in a batch.


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the target ArkClaw instance. Then, select "Skills Center" in the left navigation pane.

3. In "Skill Marketplcace", click "+" on the skill card for the skill you want ArkClaw to learn.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you are prompted to upgrade the ArkClaw skill plugins, click "Upgrade now". After upgrading, add the skill again.   </div>
   

4. In the box that appears, select the agents in the current ArkClaw instance to whom you want to add the skill. Then, click "Add".


</Tab>
<Tab zoneid="v22kj16zrD" title="Add multiple skills to multiple agents">
<TabTitle>Add multiple skills to multiple agents</TabTitle>

This section applies when you have created multiple agents for your ArkClaw instance and want to add multiple skills to them in a batch.


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the desired ArkClaw instance. Then, select "Skills Center" in the left navigation pane.

3. On the "All scenarios" tab, click "Batch add" at the bottom. Select the skill cards for the skills you want ArkClaw to learn and click "Add to Agent".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you are prompted to upgrade the ArkClaw skill plugins, click "Upgrade now". After upgrading, add the skills again.   </div>
   

4. In the box that appears, select the agents in the current ArkClaw instance to whom you want to add the skills. Then, click "Add".


</Tab>

## Manage skills

<span id="6SXentNg"></span>
### Disable or enable pre\-built skills


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the desired ArkClaw instance.

3. At the bottom of the chat box, click "+ \> Add skills \> Management skills".

4. On the editing agent page, click "Edit All" in the "Skills" section.

5. In the "All skills" dialog, click "Built\-in skills". Then, enable or disable the corresponding skill in the "Operations" column. Alternatively, check the boxes for multiple skills and click "Batch Disable" or "Batch Enable."


<span id="H25MWZgp"></span>
### Delete manually added skills


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the desired ArkClaw instance.

3. At the bottom of the chat box, click "+ \> Add skills \> Management skills".

4. On the agent details page, click "Edit All" in the "Skills" section.

5. In the "All skills" dialog, click "Agent skills". Then, delete the corresponding skill in the "Operations" column. Alternatively, check the boxes for multiple skills and click "Batch Deletion".

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Click "Add skills" to add a specific skill to the agent by following the instructions.   </div>

## Upload skills

The "My Agents" tab allows you to upload your own skills. For instructions on how to manage agent skills, see [Configuring skills for my agents](https://docs.volcengine.com/docs/87732/2477473).


1. Open a browser, enter the ArkClaw login link in the address bar, and press "Enter" to access the ArkClaw chat interface.

2. Select the desired ArkClaw instance. In the left navigation pane, click "Agent Center", and then click "My Agents".

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260701092455-1291580151463.png) </span>

3. Click "View Details" on the agent card. We will use the primary agent (**ID**: main) to demonstrate the process.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260701092521-688315379716.png) </span>

4. On the agent details page, select "Add \> Upload skills" in the "Skills" section.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260701092655-765971269432.png) </span>

5. Drag and drop a compliant local `.zip` file (up to 25 MB) into the box that appears to upload and apply it.

   > File requirements:

   > After extracting the zip file, you should see precisely **one folder** in the root directory. The folder name corresponds to the skill name specified in SKILL.md.

   > SKILL.md must be placed directly inside the **root directory** of that folder and meet the following requirements:

   > * Skill name:

   >    * Required. The length cannot exceed 64 characters.

   >    * Only lowercase letters, numbers, or hyphens (\-) are allowed.

   >    * It must not contain XML tags or platform reserved words, such as "agentkit".

   > * Skill description:

   >    * Required. The length must not exceed 10,000 characters.

   >    * It must not contain XML tags.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260701092744-424534860801.png) </span>
