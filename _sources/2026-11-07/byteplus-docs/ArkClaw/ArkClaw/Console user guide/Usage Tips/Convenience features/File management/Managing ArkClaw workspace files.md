ArkClaw generates a large number of files, such as presentations, documents, images, videos, and code files, in its workspace located at `.openclaw/` during daily use, depending on your task requirements. The platform provides a **file space** feature that allows you to upload, download, browse, and delete files in this directory while maintaining system security.

<span id="zfvdtgtx"></span>
## Feature comparison

The following table summarizes the differences between file space and [cloud disk](https://docs.byteplus.com/en/docs/ArkClaw/Uploading_or_downloading_files_using_cloud_disks_?lang=en) to help you choose the one that best meets your needs.


|Feature |Differences |Use cases |
|---|---|---|
|File space |* There are no additional charges.<br><br>* It uses ArkClaw storage space.<br><br>* Only certain file formats are supported.<br><br>* Each file you upload cannot exceed 2 GB in size.<br><br>* It only allows you to manage files in the ArkClaw workspace (i.e., `.openclaw/`). |**Simple, everyday file processing**: This feature is ideal for quickly feeding small files, such as text, code, and configuration files, to ArkClaw for processing. It is also useful for downloading result files generated by ArkClaw to your local device.<br><br>For example, you can upload a CSV file for ArkClaw to analyze or download a presentation that ArkClaw generated. |
|Cloud disk |* Additional charges apply.<br><br>* It does not occupy ArkClaw storage space.<br><br>* There are no restrictions on file formats.<br><br>* Each file you upload cannot exceed 5 GB in size.<br><br>* It is mounted as an independent disk to ArkClaw. |**Large file processing and long\-term storage**: This feature allows you to upload large files, such as videos or datasets, and store materials long\-term without occupying ArkClaw storage space.<br><br>For example, you can upload a 3 GB video clip for ArkClaw to edit or save project data to the cloud disk for long\-term access. |

## View workspace file information


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Select the desired ArkClaw instance. Then, select "File management" in the left navigation pane.

3. Select the "File space" tab.

4. The first time you use this feature, click "Install now" to install the file space system components.

5. The file space tab will then display the directory structure and file information of the current ArkClaw workspace.


<span id="4mZkvKCU"></span>
## Upload or download files in the workspace

Rather than asking ArkClaw to upload local corpora, configuration files, and other files in the chat box, you can upload them directly to the workspace for ArkClaw to use. Similarly, you can download files generated by ArkClaw directly to your local device from the workspace.


<Tabs>
<Tab zoneid="lPlCU6R0tu" title="Upload a file or folder">
<TabTitle>Upload a file or folder</TabTitle>

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">The following file formats are supported: <code>.md</code>, <code>.txt</code>, <code>.pdf</code>, <code>.json</code>, <code>.yaml</code>, <code>.csv</code>, <code>.py</code>, <code>.png</code>, and <code>.jpg</code>.</div>


* <div data-tips="true" data-tips-type="warning">Each file or folder you upload cannot exceed <strong>2 GB</strong> in size.</div>


* <div data-tips="true" data-tips-type="warning">Make sure your ArkClaw instance has enough storage space for the files you are uploading. Otherwise, the upload will fail.</div>


1. In the file space, select the directory to which you want to upload a file or folder.

2. Click "Upload" and select "Upload Files" or "Upload Folder" depending on what you want to upload.

3. In the box that appears, select the local file or folder you want to upload to ArkClaw.

4. You can check the upload progress in the lower\-right corner. Before the upload is complete, you can pause or cancel it.

5. Once the upload is complete, you can instruct ArkClaw to use the relevant file to perform tasks.

   * **Example prompt:** 

      Find the "AI Market Analysis Report" in the ".openclaw/ai_news" folder, summarize it, and send me your conclusions.


</Tab>
<Tab zoneid="MgpkzfLZlU" title="Download a workspace file or folder">
<TabTitle>Download a workspace file or folder</TabTitle>

1. Use a prompt to instruct ArkClaw to save its output to a specific directory in the workspace.

   * **Example prompt:** 

      Research the ten most downloaded skills on ClawHub. Then, compile their functions, features, installation methods, and other relevant information in a document. Save the document to the ".openclaw/ai_news" folder.

2. In the file space, select the folder where the ArkClaw\-generated file is stored.

3. Locate the file and click "... \> Download" on the right side.

4. ArkClaw automatically downloads the file through your browser.

5. To download a folder, first select it. Then, click "Download" at the bottom of the page.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">ArkClaw automatically compresses the folder into a <code>.tar</code> file and downloads it through your browser.   </div>
   


</Tab>

## Related operations

In the ArkClaw workspace, you can also create or delete files or folders.


|Operation |Description |
|---|---|
|Delete a file |ArkClaw generates a large number of temporary files while performing tasks, which can occupy significant storage space. You can manually clean up unused files to free up space.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">To ensure normal, secure operation of your ArkClaw instance, deleting core system or environment configuration files is not supported. For example, you cannot delete files such as <code>openclaw.json</code>, <code>.env</code>, or <code>update-check.json</code>.</div><br><br><br><br>1. To delete a file, click "... \> Delete" on the right side.<br><br>2. In the confirmation dialog, read the risk notice and click "Confirm". |
|Create a folder |If you plan to upload materials for different projects or categories, you can create multiple folders to store related files separately. This gives ArkClaw access to the appropriate directories for different tasks.<br><br><br>1. To create a folder, click "New Folder".<br><br>2. In the box that appears, enter a name for your folder and click "Confirm". |
|Delete a folder |You can delete a category folder and all its contents when you no longer need them to free up storage space.<br><br><br>1. To delete a folder, click "... \> Delete" on the right side.<br><br>2. In the confirmation dialog, read the risk notice and click "Confirm". |
