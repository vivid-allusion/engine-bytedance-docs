ArkClaw provides features for managing files, such as image processing, cloud storage for large files, and local workspace file management. This topic discusses the features and differences of each feature, as well as its use cases, to help you select the best method for your needs.

<span id="FprNbr1t"></span>
## Feature summary


|**Feature** |**Description** |Use cases |
|---|---|---|
|[Uploading and processing files](https://docs.byteplus.com/en/docs/87732/2280226) |This feature supports local file uploads, file previews, intelligent processing, and zoomed previews. You can incorporate file content directly into conversations for analysis and processing, which improves information processing efficiency. |This feature is ideal for scenarios in which you need to quickly upload local files to ArkClaw for **AI processing**.<br><br>It can be used for document interpretation, image analysis, material organization, content extraction, and Q&A. |
|[My cloud disk](https://docs.byteplus.com/en/docs/87732/2266928) |ArkClaw provides personal cloud disks that allow you to manage files, including uploading and downloading them. |This feature is ideal for exchanging **large files** with ArkClaw or for **long\-term, format\-agnostic file storage**. The cloud disk is mounted as a separate disk, so it does not consume ArkClaw's storage space.<br><br>For example, you can upload a 3 GB video clip to the cloud disk and use ArkClaw's intelligent editing features. |
