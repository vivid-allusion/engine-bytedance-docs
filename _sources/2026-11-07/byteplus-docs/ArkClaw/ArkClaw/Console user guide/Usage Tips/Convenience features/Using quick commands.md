ArkClaw includes preset commands for common operations, such as creating a new conversation, viewing system status, and clearing the context. You can send relevant commands with one click as needed to let ArkClaw perform corresponding operations.

<span id="DULFv7jc"></span>
### Procedure


1. Log in to the [ArkClaw console](https://console.byteplus.com/arkclaw/).

2. Go to the target ArkClaw page, and select "Initiate task" in the directory tree on the left.

3. Enter the / symbol in the chat box to call up and view available quick commands and their purposes.

4. You can select the intended command using arrow keys and press Enter to confirm, or directly select it with your mouse.

5. You can view the command execution result based on the ArkClaw reply.
