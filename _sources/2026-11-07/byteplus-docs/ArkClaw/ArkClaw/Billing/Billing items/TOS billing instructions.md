The fast file transfer feature uses a TOS bucket as a cloud disk. You are charged for each billing item separately. For example, you are charged for storage capacity when you store files. You are charged for the number of requests when you perform read and write operations on files. You are charged for public network traffic when you access files stored in TOS over the public network.

<span id="mTgw8b3D"></span>
## Fee composition
