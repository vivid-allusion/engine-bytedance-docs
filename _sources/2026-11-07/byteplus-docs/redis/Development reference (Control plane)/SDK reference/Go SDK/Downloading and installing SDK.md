This topic describes how to download and install Redis Go SDK.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

Go v1.14 or higher is required.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can run <code>go version</code> command to check your current Go version.</div>


<span id=".c2RrLeS4i-i9veWcsOWdgA=="></span>
## SDK download address

Redis Go SDK source code address, refer to [Redis Go SDK](https://github.com/byteplus-sdk/byteplus-go-sdk-v2/tree/main/service/redis).

<span id=".5a6J6KOFLXNkaw=="></span>
## Install SDK

Run the following command in the target Go project to install the Go SDK.

```Bash
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/service/redis
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/byteplus/credentials
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/byteplus/byteplusutil
```
