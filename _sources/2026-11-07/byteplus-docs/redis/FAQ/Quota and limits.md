This topic summarizes the FAQs related to the quota and use limit of Cache for Redis.

<span id=".5pyA5aSa5pSv5oyB5Yib5bu65aSa5bCR5Liq57yT5a2Y5pWw5o2u5bqTLXJlZGlzLeeJiOWunuS-i--8nw=="></span>
### How many Redis instances can be created?

Cache for Redis supports creating instances in batch. You can create up to 20 instances simultaneously each time. For specific procedures, refer to [Creating instance](https://docs.byteplus.com/en/docs/redis/create-instance).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Each primary account of BytePlus can buy up to 50 Redis instances in each region by default. If you need to adjust the quota to purchase more instances, please go to the <strong>Quota center</strong> to submit a <a href="https://console.byteplus.com/quota">Quota application</a>.</div>

### How many shards can be used in Redis instances with sharding cluster enabled?

Currently, up to 256 shards can be enabled for each Redis instance.

<span id=".5q-P5LiqLXJlZGlzLeWunuS-i-acgOWkmuWFgeiuuOS9v-eUqOWkmuWwkeS4qi1kYu-8nw=="></span>
### How many databases can be used in Redis instances?

Each Redis instance can use up to 256 databases.
