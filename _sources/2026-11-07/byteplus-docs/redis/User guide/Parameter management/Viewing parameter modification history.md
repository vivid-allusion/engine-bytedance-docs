After successfully modifying the parameters, you can view the modification records of the parameters on the Redis console, including the name of the modified parameters, the values before and after modification, the status of the parameter modification, and the modification time. This topic describes how to view parameter modification history.

## Prerequisites

Parameter modification has already been executed. You can batch modify parameters or by applying a parameter template to multiple instances. For specific procedures, refer to [Setting instance parameters](https://docs.byteplus.com/en/docs/redis/set-parameter) and [Applying parameter template](https://docs.byteplus.com/en/docs/redis/apply-parameter-template).

## Precautions

You can only view parameter modification history from the last 7 days.

## Procedure

1. Log in to the [Redis console](https://console.byteplus.com/db/redis).

2. In the top menu bar, select the project and region to which the instance belongs.

3. On the **Instances** page, click the target instance.

4. On the instance details page, click the **Parameters** tab.

5. Click the **Parameter modification history** sub\-tab to view the modification records of all the instance parameters modified, including the name of the modified parameters, the values before and after modification, the status of the parameter modification, and the modification time.
