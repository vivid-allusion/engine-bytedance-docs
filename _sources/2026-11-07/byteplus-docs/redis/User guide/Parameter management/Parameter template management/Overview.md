Cache for Redis provides the parameter template function. When you need to configure one or more Redis instances with the same parameter values for the same database version, you can use the parameter template feature to centralize the management of parameters and quickly apply the parameters in the template to the target instance to improve the efficiency of parameter management and instance configuration.

## Type of parameter template

Cache for Redis supports two types of parameter templates: **Customized templates** and **System templates**. The table below specifies the differences between the two types of templates in terms of use cases, quantitative restrictions, and supported operations for your reference.


|Type of parameter template |Customized templates |System templates |
|---|---|---|
|Scenario |Place one or more parameter configurations in a parameter template according to your service requirements. Batch applies these configurations to instances of the same database version to improve the efficiency of parameter management and instance configuration. |Cache for Redis provides a default parameter template for each database version, which includes all parameters and default parameter values supported by the version. You can use the system parameter template to quickly restore all parameters of the instance to their default values. |
