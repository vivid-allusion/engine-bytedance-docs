Cache for Redis supports backup downloads. This article describes how to download backups on console.

## Prerequisite

The instance type is the **Primary\-secondary** instance. Backup download is not available in single\-node instances. For details about the feature differences between the two instance types, refer to [Feature differences](https://docs.byteplus.com/en/docs/redis/feature-faq#.5Li75aSH5a6e5L6L5ZKM5Y2V6IqC54K557G75Z6L5a6e5L6L5pSv5oyB55qE5Yqf6IO954m55oCn5pyJ5L2V5beu5Yir77yf).

## Usage scenario

You can download backup files in the following scenarios:

* Backup files of Cache for Redis are retained for seven days by default. If a longer retention period is required (for example, for regulatory or information security purposes), the backup file can be downloaded and stored locally.

* You can recover the downloaded backup file into an offline self\-built database and execute data analysis or business testing tasks.

* When the [RDB analysis](https://docs.byteplus.com/en/docs/redis/rdb-analysis) cannot meet the service performance analysis requirements, you can download the backup file to a local device and then use open\-source tools to analyze the backup file offline.

## Billing instructions

All backups generated by Cache for Redis are stored in the BytePlus [TOS](https://docs.byteplus.com/en/docs/tos/docs-what-is-tos) service, do not occupy the storage space of the Redis instance, and are not charged currently. We will inform you, on our website or via a product notification, before a service charge is officially introduced.

For more information about Redis instance billing items, refer to [Billing items and prices](https://docs.byteplus.com/en/docs/redis/billing-item-price).

## Procedure

1. Log in to the [Redis console](https://console.byteplus.com/db/redis).

2. In the top menu bar, select the project and region to which the instance belongs.

   You can choose any of the following methods to find the target backup to download.

   * **Method 1**

      1. On the **Instances** page, click the name of the target instance.

      2. On the instance details page, click **Backups**.

      3. On the **Backups** tab, under the **Basic backups** sub\-tab, you can filter out the target backup according to the start and end times in the upper right corner of the backup list.

   * **Method 2**

      4. In the left navigation bar, select **NoSQL Database \> Redis \> Backups**.

      5. Under the **Basic backups** tab of the **Backups** page, you can filter out the target backup through the filtering conditions in the upper right corner of the list, as well as fields such as **Backup status** and **Instance status** in the list.

   > **tip**

   > For more information about backup filtering conditions or fields, refer to [Viewing backups](https://docs.byteplus.com/en/docs/redis/view-backup).

3. In the **Actions** column to the right of the target backup, click **Download**.

4. Find the RDB file to be downloaded in the pop\-up **Backup download ** panel, and perform the following actions to complete the download according to business needs.

   > **tip**

   * > The default validity period of the copied private network or public network download link is 7200 seconds (that is, 2 hours). After the validity period expires, you need to click **Copy private network download link** or **Copy public network download link** again to obtain the latest backup download link.

   * > If sharding cluster is enabled for the Redis instance type, you should select and download the backup files for all the shards in the instance to ensure data consistency.

   |Business scenario |Procedure |
   |---|---|
   |Download via private network |1. Click **Copy private network download link** in the **Actions** column on the right.<br><br>2. The browser will automatically complete the download.<br><br>   * Linux: Execute the following command to download.<br><br>      ```Bash```<br>```      wget -c '<Private network download address of data backup file>' -O <Custom file name>.<Extension>```<br>```      ```<br>      <br><br>      Example is as follows.<br><br>      ```Bash```<br>```      wget -c '<Private network download address of data backup file>' -O backupdownloadtest.rdb```<br>```      ```<br>       |
   |Download via public network |1. Click **Copy public network download link** in the **Actions** column on the right.<br><br>2. Paste the URL in the browser address bar and press enter. The browser will automatically complete the download. |
   |Download to local device |Click **Download** in the **Actions** column on the right. |
