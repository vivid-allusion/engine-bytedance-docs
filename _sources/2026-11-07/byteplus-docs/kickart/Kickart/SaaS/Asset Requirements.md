To ensure that your product assets can be uploaded and processed correctly, make sure your image and video files meet the following requirements.

<span id="FgFQDSXl"></span>
## Image Requirements


|**Parameter** |**Requirement** |
|---|---|
|Supported formats |JPEG, PNG, WebP, BMP |
|Maximum file size |30 MB per image |
|Aspect ratio (W/H) |0.4–2.5 |
|Width and height |300–6,000 px |
|Total pixel count |90,000–36,000,000 pixels |


<span id="axueUCwT"></span>
## Video Requirements


|**Parameter** |**Requirement** |
|---|---|
|Supported formats |MP4, MOV |
|Maximum file size |200 MB per video |
|Resolution |480p–4K |
|Aspect ratio (W/H) |0.4–2.5 |
|Width and height |300–6,000 px |
|Total pixel count |409,600–8,295,044 pixels |
|Frame rate |24–60 FPS |


&nbsp;

<span id="eL6WYI5M"></span>
## Before You Upload


* Check that the file format is supported.

* Make sure the file size, dimensions, aspect ratio, total pixel count, and frame rate are within the supported ranges.

* If an asset does not meet these requirements, edit or re\-export the file before uploading it again.
