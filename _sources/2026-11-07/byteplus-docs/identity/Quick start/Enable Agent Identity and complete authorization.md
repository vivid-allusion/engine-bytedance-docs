Before using Agent Identity for the first time, you need to enable the service and complete authorization.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="default">Service activation is a global one\-time operation. After completion, you can use the features of Agent Identity in all supported regions, and it will automatically be available in newly added service regions.</div>


<span id="9ddc7e52"></span>
## Prerequisites

You already have a BytePlus account and have completed enterprise verification.

<span id="88ffb972"></span>
## Steps


1. Log in to BytePlus Agent Identity Platform.

2. On the service activation page, check the box to agree to the service terms.

3. Click **Enable and Authorize**.


<span id="63d5c420"></span>
## Result

After the service is enabled, the system will automatically create the necessary service\-linked role `ServiceRoleForID` for you, allowing Agent Identity to work with other cloud services, such as the Key Management Service.
