|[Virtual Private Cloud](https://docs.byteplus.com/en/docs/vpc/What-is-VPC) |The Virtual Private Cloud (VPC) service allows you to build an isolated and self\-configured virtual network environment for cloud resources. You can customize CIDR blocks, security groups, route policies, and other network settings in your VPCs. This helps you manage cloud resources in a simple, efficient, and secure manner. |* [Changing VPC or subnet of an ECS instance](https://docs.byteplus.com/en/docs/ecs/Changing-the-VPC-or-subnet-of-an-ECS-instance)<br><br>* [Modifying security group rules](https://docs.byteplus.com/en/docs/ecs/Modifying-security-group-rules)<br><br>* [Changing security group](https://docs.byteplus.com/en/docs/ecs/Changing-security-groups) |
|[EIP](https://docs.byteplus.com/en/docs/eip/What-is-EIP) |Elastic IP Address (EIP), with Bandwidth Package configured, is an IP connectivity service designed for cloud resources. This service can be separately purchased and held for cloud resources. |[Associate an EIP](https://docs.byteplus.com/en/docs/ecs/associating-an-EIP) |
|Security Center |The security center provides enterprises with unified security protection and management. It provides capabilities such as intrusion detection, asset exposure mapping, vulnerability scanning and repair, and configuration risk checks. This way, it helps enterprises protect cloud hosts and build a user\-friendly security operation system. |[Enabling security enhancement and viewing security status](https://docs.byteplus.com/en/docs/ecs/Security-enhancement) |
|[Load Balancer](https://docs.byteplus.com/en/docs/clb/Product-Overview-01) |CLB (Classic Load Balancer) is a service that distributes access traffic to multiple backend servers according to configured policies. It helps scale the external service capacity of your system, eliminates single points of failure, and thereby improves overall system availability. |* [Backend server group overview](https://docs.byteplus.com/en/docs/clb/Server-group-overview)<br><br>* [Adding backend server](https://docs.byteplus.com/en/docs/clb/Adding-a-server) |
|[Auto Scaling](https://docs.byteplus.com/en/docs/as/What-is-Auto-Scaling) |Auto Scaling (AS) offers a pool of ECS resources that scale on demand. |[Cloud Monitor](https://docs.byteplus.com/en/docs/cloudmonitor/Release-notes) |The Cloud Monitor service is a one\-stop alerting and monitoring solution on the cloud. It collects and visualizes the resource status of all cloud products, helping you understand their health status. In addition, it can timely identify exceptions and send alert notifications, ensuring smooth business operations and enhancing O&M efficiency. |* [Monitoring overview](https://docs.byteplus.com/en/docs/ecs/Monitoring-overview)<br><br>* [For details, refer to Viewing instance health status.](https://docs.byteplus.com/en/docs/ecs/Viewing-instance-health-status)<br><br>* [Metric monitoring](https://docs.byteplus.com/en/docs/ecs/Monitoring-metrics)<br><br>* [Event monitoring](https://docs.byteplus.com/en/docs/ecs/Event-monitoring) |

This helps you solve problems such as limited resources, unmet business needs, and low scalability. |* [Migration process overview](https://docs.byteplus.com/en/docs/smc/Migration_Process_Overview)<br><br>* [Migrating ECS instances within an account or between accounts](https://docs.byteplus.com/en/docs/smc/Same-Account-or-Cross-Account-migration-of-ECS) |

|[Identity and Access Management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-3) |Identity and Access Management (IAM) is a free permission management system provided by BytePlus. You can create IAM users under your main user and grant them appropriate permissions based on specific purposes. This enables controlled access to cloud resources for different identities, facilitates delegated management of resources, improves administrative efficiency, and mitigates the risk of information exposure. |[ECS IAM policy type](https://docs.byteplus.com/en/docs/ecs/Accessing-resources-with-Identity-and-Access-Management) |
