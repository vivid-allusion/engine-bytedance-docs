This topic describes the release notes for ECS instance types.

> **tip**

* > The "Beta" products or features are not available to all users. To help you understand the products, some documents for "Beta" products or features have been made available to all users. Note that certain documents for "Beta" products or features are only accessible to users with access permission to such products. If you need to use Beta products or features, please contact your account manager to apply.

* > To view the release notes for ECS feature versions, please refer to [Release notes](https://docs.byteplus.com/en/docs/ecs/New-feature-release-notes).
