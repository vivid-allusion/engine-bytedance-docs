To improve service quality, the snapshot feature of BytePlus Elastic Block Storage will start charging gradually by region, with the first charges applied at 00:00 on July 14, 2025.

<span id="billing-start-time"></span>
### Billing start time

Charges will be applied starting at 00:00 on July 14, 2025. For the specific charging start time in each region, please refer to the release note on the console.

<span id="billing-instructions"></span>
### Billing instructions

The snapshot feature of Elastic Block Storage only supports pay\-as\-you\-go billing, which is a post\-payment method. After billing begins, the costs of both existing and newly added snapshots are calculated based on capacity used and length of time. See [Snapshot billing](https://docs.byteplus.com/en/docs/ecs/Snapshot_billing) for pricing and other information.

<span id="notes"></span>
### Notes

Before the end of the public beta period, a notice will be sent to you to confirm whether you would like to continue using the snapshot feature.


* If you have created snapshots during the public beta period and have not deleted the snapshot resources before the period ends, it's assumed that you wish to continue using this feature. On July 14, 2025, Elastic Block Storage will start calculating snapshot\-related fees based on your actual usage. Please make sure that there is sufficient balance in your account to prevent the service from being shut down due to overdue payments. For details on overdue payments, please refer to [Arrears](https://docs.byteplus.com/en/docs/ecs/Arrears).

* If you have deleted all snapshot resources before the public beta period ends, you will not incur any snapshot\-related fees.


If you have any questions or problems, please [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00001244). Thank you for your support and understanding.
