Dear BytePlus user, in order to provide you with higher \- quality and more extensive services, the Elastic Compute Service will launch a new tag OpenAPI interface on December 09, 2024.

<span id="the-new-interface-is-launched"></span>
## The new interface is launched

The new tag OpenAPI interface is as follows:


* [TagResources](https://docs.byteplus.com/en/docs/ecs/TagResources)

* [ListTagsForResources](https://docs.byteplus.com/en/docs/ecs/ListTagsForResources)

* [UntagResources](https://docs.byteplus.com/en/docs/ecs/UntagResources)


<span id="the-old-interface-will-be-retained"></span>
## The old interface will be retained

Considering that there are still existing users calling the old tag interface at present, in order to avoid affecting your business, the old tag interface will still be retained and used normally after the new interface is launched, including:


* [CreateTags](https://docs.byteplus.com/en/docs/ecs/CreateTags)

* [DescribeTags](https://docs.byteplus.com/en/docs/ecs/DescribeTags)

* [DeleteTags](https://docs.byteplus.com/en/docs/ecs/DeleteTags)


<span id="differences-between-the-new-and-old-interfaces"></span>
## Differences between the new and old interfaces

Compared with the old \- version interface, the new \- version interface has obvious Advantages. The scenarios of the new \- version interface are more extensive. It is not only limited to tag actions on resources such as instance, image and key pair before, but also will support tag management of multiple computing \- service \- related resources such as Monitoring and Auto Scaling (AS). This means that you can use a unified tag interface to manage more types of resources, which greatly improves the convenience and efficiency of resource management.

<span id="impact-on-you"></span>
## Impact on you

It is recommended that new users give priority to using the new tag interface in order to fully enjoy more extensive features and a better user experience. For the existing users of the old interface, if you hope to expand the application scenarios of tags, you can also gradually migrate to the new interface. During the use process, if you encounter any problems, you can contact technical support at any time, and we will serve you wholeheartedly.
