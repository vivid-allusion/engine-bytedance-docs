This topic describes how to adjust the screen resolution in a Linux\-based ECS instance.

<span id="v1tqsXs6"></span>
## Prerequisites


* You have [created an ECS instance](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

* The ECS instance status is **Running**.

* The operating system has [a graphical interface installed](https://docs.byteplus.com/en/docs/ecs/Install-a-GUI-in-Linux).


<span id="2vbHRtUl"></span>
## Procedure


1. Log in to the target instance via VNC. For detailed steps, refer to [Logging in to Windows instances through ECS console](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Linux-instance).

2. Right\-click the blank area of the screen, and then click the "Display settings" button.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">In the example provided in this topic, Ubuntu 22.04 image is used. The actual operating system of your image shall prevail.   </div>
   

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9fd6b4c2521b93ae6aa471da6a1d3bda.png) </span>

3. On the "Displays" tab, in the "Resolution" section, click the current resolution and select the target resolution in the pop\-up window.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c981d79f1da5fcc9209bf42c2b5238f3.png) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the common screen resolutions provided by BytePlus do not meet your business requirements, you can apply for other resolutions. <a href="https://docs.byteplus.com/en/docs/ecs/Overview_05#q18wWcgf">Learn more</a>.   </div>
   

5. In the upper right corner of the tab, click the "Apply" button to apply the change.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b5c1676fce3caf435ba7d3095e3a70d8.png) </span>

6. In the pop\-up window, click the "Keep Changes" button to save the change.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d5426a4d4cd7c6ae57b22aa4ffb1a99d.png) </span>
