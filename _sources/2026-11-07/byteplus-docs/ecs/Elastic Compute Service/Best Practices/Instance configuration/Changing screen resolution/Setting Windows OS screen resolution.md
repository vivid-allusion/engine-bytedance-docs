This topic describes how to adjust the screen resolution on a Windows\-based ECS instance.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* You have [purchased an ECS instance](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

* The ECS instance is in the **Running** status.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the target instance via VNC. For detailed steps, refer to [Logging in to instances through ECS console](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Windows-instance).

2. Right\-click any blank area on the screen, and then click "Display settings".

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">In the example provided in this topic, Windows Server 2022 Datacenter Edition 64 bit English image in BIOS boot mode is used. The actual paths may vary depending on your operating system.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">To change the screen resolution of a Windows operating system in UEFI boot mode, refer to <a href="https://docs.byteplus.com/en/docs/ecs/Failure_to_change_screen_resolution_for_Windows_instances_in_UEFI_boot_mode">Solution</a>.   </div>
   

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8741f354021c57994719a5417e124719.png) </span>

3. On the "Settings" page, in the "Display" section on the right, locate the "Scale and layout" option.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_92975fd2de81fe3cff7438e1115165f8.png) </span>

4. Click the current resolution, and then in the pop\-up window, select the target resolution.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_6c29a68525acd1791fe478659102f3db.png) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the common screen resolutions provided by BytePlus do not meet your business requirements, you can apply for other resolutions. <a href="https://docs.byteplus.com/en/docs/ecs/Overview_05#q18wWcgf">Learn more</a>.   </div>
   

5. In the pop\-up window, click the "Keep changes" button to save the change.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_a82fff0636a2f41f5ec721464b1cfd5f.png) </span>
