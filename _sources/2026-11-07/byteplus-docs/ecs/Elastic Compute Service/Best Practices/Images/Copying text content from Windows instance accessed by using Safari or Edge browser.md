This topic describes how to copy text content after you log in to a Windows instance via the ECS Terminal in the Safari or Edge browser.

<span id=".5pON5L2c5Zy65pmv"></span>
## Applicable scenario

Due to restrictions in the Safari and Edge browsers, after you log in to a Windows ECS instance via the ECS Terminal, you cannot directly copy text content into the instance or directly copy text content from the instance to your local device. However, you can use the Clipboard Capture applet to help you complete the text copying operation.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure

<span id=".U2FmYXJp5rWP6KeI5Zmo"></span>
### Safari browser


<Tabs>
<Tab zoneid="rji3lyHBBh" title="Copy local text content to an ECS instance">
<TabTitle>Copy local text content to an ECS instance</TabTitle>

1. In the Safari browser, log in to the target Windows instance via the ECS Terminal. For more information, see [Logging in to Windows instances through ECS console](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Windows-instance).

2. Press `control` +`command`+ `shift` to open the Clipboard Capture applet.

3. Paste into the clipboard the content you want to copy into the ECS instance.

4. Press `control` +`command`+ `shift` again to close the clipboard.

5. Within the ECS instance, press `control` +`v` to paste the text content.


</Tab>
<Tab zoneid="JmdnqahuHf" title="Copy content from an ECS instance to the local PC">
<TabTitle>Copy content from an ECS instance to the local PC</TabTitle>

1. In the Safari browser, log in to the target Windows instance via the ECS Terminal. For more information, see [Logging in to Windows instances through ECS console](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Windows-instance).

2. Copy the target text content within the ECS instance.

3. Press `control` +`command`+ `shift` to open the Clipboard Capture applet.

4. After the target text is copied to the clipboard, you can paste it on your local PC.





</Tab>
</Tabs>

</Tab>

2. Copy the target text content within the ECS instance.
