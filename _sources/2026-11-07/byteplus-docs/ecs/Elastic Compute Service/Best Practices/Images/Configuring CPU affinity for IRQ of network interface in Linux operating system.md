This topic describes how to use the irqbalance\-ng feature provided by the platform to automatically configure CPU affinity for the interrupt requests (IRQs) of physical network interfaces, thereby improving network performance.

<span id=".5pON5L2c5Zy65pmv"></span>
## Applicable scenario

In high network traffic scenarios, a large number of network interface IRQs may concentrate on a single CPU, causing delays in packet transmission and reception. irqbalance\-ng operates in a periodic scanning mode, automatically checking and configuring the CPU affinity (via /proc/irq/{irq_id}/smp_affinity) of physical network interfaces. This prevents uneven CPU load when network interface IRQs are processed, thereby improving network performance.

In scenarios where multiple Network Namespaces are configured, irqbalance\-ng can automatically identify network interface information for each namespace and configure CPU affinity for the network interface IRQs.

## Concepts


|Concept |Description |
|---|---|
|IRQ |An interrupt request (IRQ) refers to an electrical signal actively sent by a device to the CPU, causing the CPU to stop its current task and process the received interrupt request. |
|irqbalance |A daemon used to help balance the CPU load generated by interrupts across all system CPUs. |
|CPU affinity |CPU affinity, also known as CPU binding, refers to the tendency of processes or IRQs to run on a specified CPU for an extended period without being migrated to other processors. |
|NUMA |Non\-Uniform Memory Access (NUMA) is a memory architecture designed for multiprocessor computers. The memory access speed depends on the location of memory relative to the processor. |
|Network Namespace |A method provided by Linux for isolating system\-wide resources. The method works by placing global resources of the system into different namespaces to achieve isolation. Programs in different namespaces can have their own independent set of system resources. |

#### Configure rules for running the tool

You can modify the configuration file of irqbalance\-ng to adjust settings such as the interval at which irqbalance\-ng checks or adjusts CPU affinity for network interface IRQs, and the list of CPUs that handle network interface IRQs.


1. [Log in to the target Linux instance](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Linux-instance).

2. Execute the following command to edit the configuration file.

   ```Plain Text
   vim /etc/default/irqbalance-ng
   ```
   

3. Press the `i` key to enter edit mode, and modify the irqbalance\-ng configuration based on your needs.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b5823973f2c7d417f8534402e3c3e421.png) </span>

   |---|---|---|
   |debug |The level of logs printed by the irqbalance\-ng service. Valid values:<br><br><br>* 0: Logs of the error level are printed.<br><br>* 1: Logs of the info and error levels are printed. 4. Press `Esc`, enter `:wq`, and then press Enter to save the modifications and close the file.

5. After you modify the file, execute the following command to restart irqbalance\-ng for the modifications to take effect.

   ```Bash
   systemctl restart irqbalance-ng
   ```
   

6. You can execute the following command to view the binding information between IRQs and CPUs.

   > This command retrieves IRQ information from `/proc/interrupts` and uses `cat /proc/irq/$i/smp_affinity_list` to configure or read the CPU affinity of IRQs. You can adjust the command based on your needs.   
   

   ```Plain Text
   for i in `cat /proc/interrupts | grep -E "input|output" | awk -F ' ' '{print $1}' | awk -F ':' '{print $1}'` ;do echo "irq_"$i ":" `cat /proc/irq/$i/smp_affinity_list` ;done
   ```

#### Stop irqbalance\-ng

You can execute the following command to stop periodic CPU affinity configuration for IRQs performed by irqbalance\-ng.

```Plain Text
systemctl stop irqbalance-ng.service
```


You can also execute the following command to disable irqbalance\-ng from starting automatically when the instance starts.

```Plain Text
systemctl disable irqbalance-ng.service
```
