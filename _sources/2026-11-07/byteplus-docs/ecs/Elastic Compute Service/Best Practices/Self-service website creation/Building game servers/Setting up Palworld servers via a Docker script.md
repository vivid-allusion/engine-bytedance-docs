This topic describes how to quickly set up a Palworld server on a Linux\-based ECS instance by using a Docker script.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Currently, you can set up a Palworld server using a Docker script only on Linux\-based instances. We recommend using the Ubuntu 22.04 operating system for your instance.</div>


<span id=".5LuA5LmI5piv5bm75YW95biV6bKB"></span>
## What is Palworld?

Palworld is an open\-world game developed by Pocketpair. It combines survival and construction, exploration and combat, creature catching, training, and business manufacturing. This game supports multiplayer online play. Players need to collect mysterious "Pals" in a vast world, use "Pals" for combat, construction, farming, and other tasks, and build their dream bases.

<span id=".5pON5L2c5Zy65pmv"></span>
## Applicable scenario

Palworld is an open\-world game that allows you to set up a dedicated server using an ECS instance. You and your friends can log in to and play on the server. The dedicated server can offer better privacy and help avoid issues like game crashes caused by overcrowding on official servers.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* You have [created an ECS instance](https://docs.byteplus.com/en/docs/ecs/Overview-of-methods-for-buying-ECS-instances).

* The target instance must be associated with an EIP. For information about how to associate an EIP with an ECS instance, see [Associating EIPs](https://docs.byteplus.com/en/docs/ecs/associating-an-EIP).

## Procedure

<span id=".5q2l6aqk5LiA77ya6YWN572u5a6J5YWo57uE"></span>
### Step 1: Configure the security group

Since the Palworld server uses UDP port 8211 for data transmission, you need to allow inbound `UDP` traffic on port `8211` in the security group of the target instance.


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left\-side navigation pane, select "Instances & Images \> Instances".

3. In the top menu bar, select the project and region of the target instance.

4. On the Instances page, find the target instance, and click the instance name to go to the instance details page.

5. Select the "Security Group" tab, and click the "Edit rule" button.

6. On the security group details page, select "Access rules \> Inbound rules". Then, on the "Inbound rules" tab, configure a security rule as follows.

   1. Click the "Add rule" button.

   2. On the "Add Inbound rule" page, perform the following operations in sequence: specify "Protocol type" as `UDP`, copy `8211` into the "Port range" field, and copy `0.0.0.0/0` into the "Source" field. Then, click the "Confirm" button to complete the configuration.


<span id=".5q2l6aqk5LqM77ya5pCt5bu6UGFsd29ybGTmnI3liqHlmag="></span>
### Step 2: Set up a Palworld server


1. Log in to [ECS console](https://console.byteplus.com/ecs/instance).

2. In the top navigation bar, select the project and region where the purchased instance is located.

3. In the left\-side navigation pane, select "Maintenance & Monitoring \> Cloud Assistant".

4. Select the "Job management" tab, and click the "Create a job" button.

5. On the Create a job page, configure the parameters as follows. For parameters not covered, please use the default configuration.

   * **Command source**: Select **Manual input**.

   * **Command type**:

      * Select "Linux Shell".

      * Copy the following commands to the content box to override existing content.

         ```Plain Text
         #!/bin/bash
         wget -q -O - https://palworld.tos-cn-beijing.volces.com/auto_install_palworld_docker.sh | bash
         ```
         

   * **Timeout**: We recommend specifying the timeout to "5 MM". This helps avoid command execution failures caused by ​time\-consuming download and installation processes.

   * **Execute object**: Select the target ECS instance(s) to install Palworld. Then, click the "Confirm" button to start Palworld configuration.

6. After execution starts, you will be redirected to the job list page. Then, click the "Execution result" button in the "Action" column to enter the Execution result page. For the target instance, click the "Run log" button in the "Action" column to view the execution progress and details.

   If the following output is displayed, the Palworld server is set up.

   The `admin_password` parameter value is an administrator password of the game server, which is randomly generated by the script. You can use the password in Palworld.


<span id=".5q2l6aqk5LiJ77ya5byA5aeL5ri45oiP"></span>
### Step 3: Start the game


1. Start Palworld in Steam.

2. On the game home page, click the "Join multiplayer game (dedicated server)" button.

3. On the start page, select "Community server", and at the bottom of the page, input the `ECS instance EIP:8211`. Click the "Contact" button to enter the dedicated server and start the game.


<span id=".5pu05paw5ri45oiP"></span>
## Update the game


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the top navigation bar, select the project and region where the purchased instance is located.

3. In the left\-side navigation pane, select "Maintenance & Monitoring \> Cloud Assistant".

4. Select the "Job management" tab and find the job used to set up the Palworld server with a Docker script.

5. No configuration changes are needed. Simply click the "Confirm" button at the bottom of the page to start updating the game.

   If the following output is displayed, Palworld has been successfully updated and you can start the game.

   The `admin_password parameter` value is a random game server administrator password generated by the script. You can use it in Palworld.
