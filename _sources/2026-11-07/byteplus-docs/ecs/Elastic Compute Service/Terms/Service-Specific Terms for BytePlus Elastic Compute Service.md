### 1. **Definitions and Interpretation**

**1.1** The following terms shall have the meanings assigned to each of them as below, unless otherwise provided hereunder.

"**ECS**" means Elastic Compute Service, which provides scalable computing capacity. An instance is equivalent to a virtual machine, including basic computing components such as CPU, memory, operating system, network, and volume. Using ECS eliminates your need to invest in hardware up front, so you can develop and deploy applications faster, and also enables you to scale up or down to handle changes in requirements or spikes in popularity, reducing your need to forecast traffic. BytePlus provides a variety of instance types for you to choose from. Different types of instances provide different computing and storage capabilities and are suitable for different application scenarios.

The Elastic Compute Service package includes cloud servers, GPU servers, elastic bare metal servers, and other types of cloud server services listed on the BytePlus official website, subject to the actual product and service specifications you have ordered.
