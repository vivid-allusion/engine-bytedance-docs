## request parameters

Only parameters specific to this API and some common parameters are listed below. For more information, see [Common Parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|m5zqXw">必选</span> `Example: CreateVolume`

Action to be performed: CreateVolume.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|DZM17U">必选</span> `Example value: 2020-04-01`

The version of the API is: 2020\-04\-01.



**VolumeType ** <span data-label="purple">string </span><span data-api-tag="require|IC3uge">必选</span> `Example value: PTSSD`

Cloud disk type, with the following values:


* ESSD_PL0: High\-speed SSD volume of PL0 specification.

* Extreme Speed SSD Cloud volume, FlexPL specification.

* Throughput SSD Volume


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For detailed information on volume specifications, see <a href="https://docs.byteplus.com/en/docs/ecs/Volume-specifications">volume specifications</a>.</div>




**Size ** <span data-label="purple">integer </span><span data-api-tag="require|Y0mDam">必选</span> `Example: 40`

Data disk size in GiB. The capacity range for different types of data disks is as follows:


* ESSD_PL0：10~65536 GiB

* ESSD_FlexPL：10~65536 GiB

* TSSD_TL0：40~65536 GiB



**Kind ** <span data-label="purple">string </span>`Optional` `Example value: data`

Volume attribute; "data" represents a data volume. The default value is "data".

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Only data volumes are supported.</div>




**VolumeChargeType ** <span data-label="purple">string </span>`Optional` `Example value: PostPaid`

Payment method. The default is pay\-as\-you\-go. See description below:


* PostPaid: Pay\-as\-you\-go

* PrePaid: Subscription based



**ZoneId ** <span data-label="purple">string </span>`Optional` `Example value: cn-beijing-a`

Available zone ID.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">If you do not set InstanceId, ZoneId is required. If both InstanceId and ZoneId are set and the region of the instance differs from the region specified by ZoneId, the request fails.</div>




**Description** <span data-label="purple">string</span> `Optional` `Example value: Volume for testing`

The description of the volume defaults to empty and must be between 1 and 255 characters.



**ClientToken ** <span data-label="purple">string </span>`optional` `Example value: 123e4567-e89b-12d3-a456-42665544****`

Used to ensure the idempotency of the request. This string is generated by your client to ensure uniqueness between different requests. ClientToken is a case\-sensitive string with no more than 64 ASCII characters.



**VolumeName ** <span data-label="purple">string </span><span data-api-tag="require|jIrqXf">必选</span> `Example: test-volume`

Volume display name. The naming conventions are as follows:


* The first character can only be a Chinese character, letter, or underscore (_).

* You can use Chinese characters, letters, numbers, underscores (_), or hyphens (\-).

* The length must be between 1 and 128 characters.



**ExtraPerformanceTypeId ** <span data-label="purple">string </span>`Optional` `Example value: IOPS`

The type of extra performance varies for different volumes. See details below:


* The extra performance options for ESSD FlexPL data volumes are as follows:

   * Balance: Balanced extra performance.

   * IOPS: IOPS extra performance.

   * Throughput: Throughput extra performance.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For a detailed introduction to the extra performance of ESSD FlexPL data volumes, see <a href="https://docs.byteplus.com/en/docs/ecs/essd_flexpl_volume">extra volume performance</a>.</div>



* The TSSD_TL0 data volume only supports the Throughput value, which indicates the extra throughput configured for the TSSD_TL0 volume. For details, see [volume specifications - Throughput SSD volume](https://docs.byteplus.com/en/docs/ecs/Volume-specification-tssd-tl0-Volume).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Only ESSD FlexPL data volumes of 500 GiB or more support configuring extra performance.</div>


* <div data-tips="true" data-tips-type="tip">Only TSSD_TL0 data volumes of 100 GiB or more support configuring extra performance.</div>




**ExtraPerformanceIOPS ** <span data-label="purple">integer </span>`Optional` `Example value: 100`

Extra IOPS performance, measured in operations per second. The value range for each type is as follows:


* IOPS\-type additional performance: 0–50000

* Balance\-type additional performance: 0–50000


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The ExtraPerformanceIOPS parameter can only be configured when the ExtraPerformanceTypeId parameter value is Balance or IOPS.</div>




**ExtraPerformanceThroughputMB ** <span data-label="purple">integer </span>`Optional` `Example value: 100`

Extra throughput performance, measured in MB/s.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Throughput\-type SSD volumes with different capacities offer different purchasable additional throughputs.</div>


* <div data-tips="true" data-tips-type="tip">The ExtraPerformanceThroughputMB parameter can only be configured when the ExtraPerformanceTypeId parameter value is Throughput.</div>




**PlacementGroupId ** <span data-label="purple">string </span>`optional` `Example value: pg-d5ard493uxd44up7****`

Storage placement group ID.



**SubgroupNumber** <span data-label="purple">integer</span> `Optional` `Example: 2`

Storage subgroup number.



**Tags.N.Key ** <span data-label="purple">string[] </span>`Optional` `Example value: Tags.1.Key=tag`

The tag key of the label.


* Tags.N.Key: N represents the serial number of the tag key. Value range: 1\-20.

* Use "&" to separate multiple tag keys.



**Tags.N.Value ** <span data-label="purple">string[] </span>`Optional` `Example: Tags.1.Value=test`

Tag value of the label.


* Tags.N.Value: N indicates the index of the tag value. Value range: 1\-20.

* Use & to separate multiple tag values.



**DeleteProtection ** <span data-label="purple">boolean </span>`Optional` `Example value: true`

Enable delete protection on the volume.



**DeleteProtectionRetentionDays ** <span data-label="purple">integer </span>`Optional` `Example: 3`

Snapshots involved in delete protection are kept permanently by default. You can also set a specific retention period between 1 and 65,536 days (default is 30 days). Snapshots are automatically deleted after the retention period ends.



**SnapshotId ** <span data-label="purple">string </span>`Optional` `Example value: snap-ass6qd6tmm8gjme1****`

Snapshot ID.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Set this parameter when creating a volume from a snapshot.</div>




**InstanceId ** <span data-label="purple">string </span>`Optional` `Example value: i-ybliv8vfkzlbzah6****`

The ECS instance ID to which the volume is mounted during creation.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">This parameter is required when creating a subscription volume, and the attached ECS instance must also be a subscription instance.</div>


<div data-tips="true" data-tips-type="warning">The region and availability zone of the subscription volume must match those of the attached instance. If both InstanceId and ZoneId are specified, the request fails if the region of the instance does not match the region specified by ZoneId.</div>




**ProjectName ** <span data-label="purple">string </span>`Optional` `Example: default`

The name of the Project to join the volume.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If you do not set a ProjectName when creating the volume, it will be added to the default project by default.</div>

```text

Host: open.volcengineapi.com
Region: cn-beijing
ServiceName: storage_ebs
```
