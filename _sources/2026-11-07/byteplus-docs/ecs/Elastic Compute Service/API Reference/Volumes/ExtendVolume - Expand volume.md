## request parameters

Only unique request parameters and selected common parameters for this API are listed below. For more information, see [Common Parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|7utsdu">必选</span> `Example value: ExtendVolume`

Action to perform: ExtendVolume.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|g4iFx6">必选</span> `Example: 2020-04-01`

The version of the API is: 2020\-04\-01.



**ClientToken ** <span data-label="purple">string </span>`Optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

Used to ensure the idempotency of the request. This string is generated by your client to ensure uniqueness between different requests. ClientToken is a case\-sensitive string with no more than 64 ASCII characters.



**NewSize ** <span data-label="purple">integer </span><span data-api-tag="require|AiFSdZ">必选</span> `Example: 80`

Volume capacity, unit: GiB. The new size should be greater than the original size. The volume capacity ranges for different types are as follows:


* System disk:

   * PTSSD：10~500 GiB

   * ESSD_PL0：20~2,048 GiB

   * ESSD_FlexPL：20~2,048 GiB

   * TSSD_TL0：40～2048 GiB

* Data disk:

   * PTSSD：20~8,192 GiB

   * ESSD_PL0：10~65536 GiB

   * ESSD_FlexPL：10~65536 GiB

   * TSSD_TL0：40～65536 GiB



**VolumeId ** <span data-label="purple">string </span><span data-api-tag="require|j0F16c">必选</span> `Example value: vol-3thhlu8byl4bwbha****`

ID of the volume to be expanded.

Region: ap-southeast-1
