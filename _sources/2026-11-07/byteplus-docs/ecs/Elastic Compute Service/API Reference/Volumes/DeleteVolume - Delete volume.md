Use the DeleteVolume API to remove a pay\-as\-you\-go data volume.

## request parameters

Below are unique request parameters for this API and some common parameters. For more information, see [Common Parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|sVAbEa">必选</span> `Example value: DeleteVolume`

Operation to perform, value: DeleteVolume.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|wqTLAZ">必选</span> `Example value: 2020-04-01`

The version of the API is: 2020\-04\-01.



**ClientToken ** <span data-label="purple">string </span>`Optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

Used to ensure the idempotency of the request. This string is generated by your client to ensure uniqueness between different requests. ClientToken is a case\-sensitive string with no more than 64 ASCII characters.



**VolumeId ** <span data-label="purple">string </span><span data-api-tag="require|q8LRna">必选</span> `Example: vol-3tiefmkskq3vj0x0****`

ID of the volume to be deleted.
