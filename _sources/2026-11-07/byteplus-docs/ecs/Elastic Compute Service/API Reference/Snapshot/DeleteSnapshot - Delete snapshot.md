Delete a snapshot by calling the DeleteSnapshot interface.

<span id=".5rOo5oSP5LqL6aG5"></span>
## precautions

Only snapshots with the status "available" or "error" can be deleted. Snapshots with the status "creating" or "rolling back" can not be deleted.

**Version ** <span data-label="purple">string </span><span data-api-tag="require|Marhs7">必选</span> `Example value: 2020-04-01`

The version of the API is: 2020\-04\-01.



**ClientToken ** <span data-label="purple">string </span>`Optional` `Example value: 123e4567-e89b-12d3-a456-42665544****`

Used to ensure the idempotency of the request. This string is generated by your client to ensure uniqueness between different requests. ClientToken is a case\-sensitive string with no more than 64 ASCII characters.



**SnapshotId ** <span data-label="purple">string </span><span data-api-tag="require|wryMV2">必选</span> `Example value: snap-bp1s5fnvk4gn2****`
