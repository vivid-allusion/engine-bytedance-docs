Call the CreateSnapshot API to create a snapshot for a volume.

<span id=".5L2_55So6K-05piO"></span>
## Usage notes


* Only ultra\-fast SSD and throughput SSD volumes support snapshot creation.

* Before creating a snapshot, the volume must be in the "Available" or "Attached" state.

* If the volume is in the "Attached" state, the instance attached to the volume must be in the "Running" or "Stopped" state.

* Each volume can have up to 256 manual snapshots. For more information, see [Create snapshot](https://docs.byteplus.com/en/docs/ecs/Create-a-snapshot).

## request parameters

Below are the specific request parameters for this API and some common parameters. For more information, see [Public Parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|msMnF2">必选</span> `Example value: CreateSnapshot`

The action to be performed: CreateSnapshot.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|Oeak26">必选</span> `Example value: 2020-04-01`

The version of the API is: 2020\-04\-01.



**SnapshotName ** <span data-label="purple">string </span><span data-api-tag="require|2yinOU">必选</span> `Example: testSnapshotName`

Snapshot name. The name should meet the following requirements:


* Length limit is 1 to 128 characters.

* Only Chinese characters, letters, numbers, underscores (_), hyphens (\-), and periods (.) are allowed.

* To avoid conflicts with the names of automatic snapshots, the name cannot start with "auto".



**ClientToken ** <span data-label="purple">string </span>`Optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

Used to ensure the idempotency of the request. This string is generated by your client to ensure uniqueness between different requests. ClientToken is a case\-sensitive string with no more than 64 ASCII characters.



**Description ** <span data-label="purple">string </span>`Optional` `Example: testDescription`

The snapshot description is empty by default and must be between 1 and 255 characters.



**Tags.N.Key ** <span data-label="purple">string[] </span>`Optional` `Example value: Tags.1.Key=tag`

Snapshot tag key.


* Tags.N.Key: N indicates the sequence number of the tag key. Value range: 1\-20.

* Use & to separate multiple tag keys.



**Tags.N.Value ** <span data-label="purple">string[] </span>`Optional` `Example value: Tags.1.Value=test`

Snapshot Tag Value.


* Tags.N.Value: where N is the tag value number. Value range: 1\-20.

* Separate multiple tag values with &.



**RetentionDays ** <span data-label="purple">integer </span>`Optional` `Example: 30`

Snapshot retention period, measured in days. Details are as follows:


* Empty: Retain snapshots permanently.

* 1~65536: Specify the number of retention days.


The default is empty, meaning snapshots are retained permanently by default.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The snapshot retention period starts from the time the snapshot is created.</div>




**VolumeId ** <span data-label="purple">string </span><span data-api-tag="require|rWgy4o">必选</span> `Example value: vol-bp1s5fnvk4gn2tws0****`

ID of the volume for which you want to create a snapshot.



**ProjectName ** <span data-label="purple">string </span>`Optional` `Example: default`

Snapshot belongs to the project.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Snapshots do not inherit the project's volume; a snapshot and its volume can belong to different projects.</div>


* <div data-tips="true" data-tips-type="tip">If you do not set ProjectName when creating a snapshot, the snapshot will be added to the default project by default.</div>
