Invoke the CreateSnapshotGroup interface to create a snapshot consistency group.

<span id=".5rOo5oSP5LqL6aG5"></span>
## precautions

The number of manual snapshots for a single volume is limited to 256. If the total number of consistency group snapshots and other manual snapshots exceeds 256, you cannot create new snapshots.

## request parameters

Only unique parameters for this interface and some common parameters are listed below. For more information, see [Common Parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|nCnNNV">必选</span> `Example value: CreateSnapshotGroup`

The operation to perform is: CreateSnapshotGroup



**Version ** <span data-label="purple">string </span><span data-api-tag="require|unHTSe">必选</span> `Example: 2020-04-01`

The version of the API is: 2020\-04\-01.



**ProjectName ** <span data-label="purple">string </span>`Optional` `Example: default`

The name of the project to which the snapshot consistency group will be added.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If you do not set ProjectName when creating the snapshot consistency group, it will be added to the default project by default.</div>




**VolumeIds.N ** <span data-label="purple">string[] </span><span data-api-tag="require|cuF9wh">必选</span> `Example: vol-bp1s5fnvk4gn2tws0****`

Volume ID, as described below:


* The volume must be in the "Attached" state.

* If multiple volumes are specified, they must be mounted to the same ECS instance.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">N refers to the sequence number of the volume ID. For multiple volume IDs, separate them with "&". The valid range is 1–16.</div>




**InstanceId ** <span data-label="purple">string </span>`Optional` `Example: i-ycwyd2mvpcs6iplj****`

The corresponding ECS instance ID for the mounted cloud disk.



**Name ** <span data-label="purple">string </span>`Optional` `Example value: testName`

Name of the snapshot consistency group. Details are as follows:


* It can only start with Chinese characters, letters, or an underscore (_).

* Only Chinese characters, letters, numbers, underscores (_), hyphens (\-), and periods (.) are allowed.

* The length limit is 1 to 128 characters.


If this parameter is not set, the default name for the snapshot consistency group in the console is "\-".



**Description ** <span data-label="purple">string </span>`Optional` `Example value: testDescription`

Description of the snapshot consistency group is as follows:


* It can only start with Chinese characters, letters, or an underscore (_).

* Only Chinese characters, letters, numbers, underscores (_), hyphens (\-), and periods (.) are allowed.

* The length limit is 1 to 255 characters.



**ClientToken ** <span data-label="purple">string </span>`Optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

Ensure request idempotence. This string is generated by your client to ensure uniqueness between different requests. Description as follows:


* Case sensitive.

* Not more than 64 ASCII characters.



**Tags.N.Key ** <span data-label="purple">string[] </span>`Optional` `Example: testKey`

Label key of the snapshot consistency group.


* Tags.N.Key: N indicates the index number of the label key. Value range: 1\-20.

* Use & to separate multiple label keys.



**Tags.N.Value ** <span data-label="purple">string[] </span>`Optional` `Example value: testValue`

Label value of the snapshot consistency group.


* Tags.N.Value: N indicates the index of the label value. Value range: 1\-20.

* Separate multiple tag values with &.
