Call the RollbackSnapshotGroup API to roll back one or more volumes in a snapshot consistency group.

<span id=".5rOo5oSP5LqL6aG5"></span>
## precautions

Before rolling back a snapshot consistency group using the RollbackSnapshotGroup API, ensure the following steps are complete:


* The snapshot consistency group has been created; the system disk has not had its operating system replaced since the group was created.

* The instance status is “Stopped.” For instructions on stopping an instance, see [Stop Instance](https://docs.byteplus.com/en/docs/ecs/Stopping-instances).

* None of the source volumes corresponding to all snapshots in the snapshot consistency group have been deleted, and the source volumes remain “Attached.”

* All snapshots in the snapshot consistency group have the status “Available.”
