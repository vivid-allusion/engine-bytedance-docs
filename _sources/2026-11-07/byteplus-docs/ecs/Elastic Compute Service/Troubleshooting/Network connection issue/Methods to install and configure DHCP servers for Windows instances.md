If the DHCP service of a Windows instance is disabled, you may fail to renew the IP address for the instance after the IP address expires. As a result, issues such as network interruptions may occur. This topic describes how to install and configure the DHCP server for an instance.

## Procedure


1. Log in to the target instance. For more information, see [Login overview](https://docs.byteplus.com/en/docs/ecs/Overview-1).

2. For more information about installing and configuring a DHCP server, see the [official documentation](https://learn.microsoft.com/zh-cn/troubleshoot/windows-server/networking/install-configure-dhcp-server-workgroup).
