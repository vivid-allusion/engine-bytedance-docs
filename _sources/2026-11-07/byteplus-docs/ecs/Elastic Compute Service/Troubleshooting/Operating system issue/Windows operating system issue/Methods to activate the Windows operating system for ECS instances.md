## Procedure


1. Log in to the target instance. For more information, see [Login overview](https://docs.byteplus.com/en/docs/ecs/Overview-1).

2. Activate the Windows operating system. For more information about activation methods, see the [official documentation](https://support.microsoft.com/zh-cn/windows/%E6%BF%80%E6%B4%BB-windows-c39005d4-95ee-b91e-b399-2820fda32227).
