## Background

If third\-party software (such as third\-party antivirus software) is installed on a Windows instance, some management operations (such as password reset and remote connection) may fail and thereby cause instance exceptions.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure

**Method 1: Uninstall from "Settings"** 


1. Log in to the target instance. For more information, see [Login overview](https://docs.byteplus.com/en/docs/ecs/Overview-1).

2. In the lower\-left corner of the desktop, click the "Start" icon and select "Settings \> System \> Apps & features".

3. Click the application you want to delete or uninstall, and then click the "Uninstall" button.

4. Click the "Uninstall" button again to complete the operation.


**Method 2: Uninstall from "Control Panel"** 


1. Log in to the target instance. For more information, see [Login overview](https://docs.byteplus.com/en/docs/ecs/Overview-1).

2. In the search box on the taskbar, enter "Control Panel".

3. Select "Programs \> Programs and Features".

4. Select the program you want to delete and click "Uninstall" or "Uninstall/Change".

5. Follow the interface instructions to complete the uninstallation.
