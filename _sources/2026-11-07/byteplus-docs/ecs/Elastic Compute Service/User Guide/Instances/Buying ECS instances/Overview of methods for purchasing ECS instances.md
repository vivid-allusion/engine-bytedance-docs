This topic describes different methods that you can use to purchase ECS instances, and applicable scenarios of each method. You can choose a method based on your business needs.


|Purchase method |Applicable scenario |
|---|---|
|[Purchasing an instance by following the wizard](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances) |Purchase an instance with custom configurations. This method allows you to select the billing method, image, instance type, storage capacity, network, and security group based on your needs in different scenarios. |
|[Purchasing an ECS instance with the same configuration](https://docs.byteplus.com/en/docs/ecs/Buying-ECS-instances-that-use-the-same-configuration) |If you need a new instance with the same configuration as the current instance, you can use this method to quickly create a new instance. |
|[Purchasing an instance based on an instance launch template](https://docs.byteplus.com/en/docs/ecs/Buying-ECS-instances-with-a-launch-template-or-version) |You can create an instance launch template and purchase an instance based on the template with one click. This method simplifies the configuration process and reduces the configuration time. |
|[Purchasing an instance based on a custom image](https://docs.byteplus.com/en/docs/ecs/Buying-ECS-instances-with-custom-images) |If you have a preferred operating system, applications, or other configurations, you can create a custom image. When you create an instance, you can use this custom image to improve configuration efficiency. |
