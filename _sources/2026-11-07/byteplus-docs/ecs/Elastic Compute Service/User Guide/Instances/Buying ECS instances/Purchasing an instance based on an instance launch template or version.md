## Applicable scenarios

You can use an instance launch template or version to purchase an ECS instance with one click, reducing the time required for manual configuration.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

You have [created a launch template](https://docs.byteplus.com/en/docs/ecs/Creating-launch-templates) or a [launch template version](https://docs.byteplus.com/en/docs/ecs/Creating-launch-template-versions).

<span id=".6YCa6L-H5a6e5L6L5ZCv5Yqo5qih5p2_6LSt5Lmw5a6e5L6L"></span>
## Purchase instances by using an instance launch template

If you use a launch template to purchase an ECS instance, the instance automatically uses configurations of the template.


1. Log in to [the Launch Templates console](https://console.byteplus.com/ecs/template).

2. In the top menu bar, select a region.

3. In the template list, click "Create instance" of the target template in the "Actions" column. Then, the "Confirm" page appears.

4. Confirm the configurations. If you need to change the configurations, click the<span>![图片](https://lf3-volc-editor.volccdn.com/obj/volcfe/sop-public/upload_761d50efa63019e6e502a1316fa70e78.png) </span>icon to go to the configuration page. For more information, refer to [Purchasing an instance by following the wizard](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

5. Follow the console guidance to review and confirm the agreements.

6. Click "Buy now".


<span id=".6YCa6L-H54mI5pys6LSt5Lmw5a6e5L6L"></span>
## Purchase instances by using a version

You can manually select configuration information of a specified version to purchase an ECS instance.


1. Log in to the [Launch Templates console](https://console.byteplus.com/ecs/template).

2. In the top menu bar, select a region.

3. Click the name of the target template, and then click the "Version" tab.

4. On the right side of the target version list, click "Create instance" to go to the "Confirm" page.

5. Confirm the configurations. If you need to change the configurations, click the<span>![图片](https://lf3-volc-editor.volccdn.com/obj/volcfe/sop-public/upload_761d50efa63019e6e502a1316fa70e78.png) </span>icon to go to the configuration page. For more information, refer to [Purchasing an instance by following the wizard](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

6. Follow the console guidance to review and confirm the agreements.

7. Click "Buy now".
