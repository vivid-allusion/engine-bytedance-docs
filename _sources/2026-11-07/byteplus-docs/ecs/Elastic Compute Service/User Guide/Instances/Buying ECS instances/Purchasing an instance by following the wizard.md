## Scenarios

If you need to purchase one or multiple ECS instances, this topic is for your reference.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure 


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance). 

2. In the left\-side navigation pane, select "Instances & Images \> Instances".

3. In the top menu bar, select the region and project.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After you select a project, ECS instances that you create can be associated only with the selected project. If you select "All Resources", ECS instances that you create can be associated with any project under the current account.   </div>
   

4. Select "Create instance " to start purchasing an ECS instance.

5. Then, you can follow the page wizard to complete the [Basic configuration](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances#.5Z-656GA6YWN572u), [Network configuration](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances#.572R57uc6YWN572u), and [Custom configuration](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances#.6Ieq5a6a5LmJ6YWN572u) in sequence. The configuration description below is for your reference.

6. After you configure parameters, click "Next" to go to the **Confirm** page. On this page, confirm the instance configuration and enter the purchase information.

   * Quantity: the number of ECS instances to be purchased this time.

   * Purchase time and Automatic renewal (only for instances with the "Subscription" billing method): Select a subscription duration for the subscription\-based instance, and then set whether to "Enable automatic renewal". Once you enable automatic renewal, the system automatically deducts the renewal fee before the instance expires.

   * Agreement: follow the console instructions to review and confirm the legal agreements.

   * Configuration fee: Hover over the question mark next to the configuration fee at the bottom of the page. Then, you can view cost details and discount amounts, such as fees for instance type, system volume, data volume, and EIP.

7. (Optional) If you need to save the selected configuration as a launch template, click the "Save as Template" button in the upper right corner.

   1. Select to save the configuration as "Template" or "Version". If you need to save it as the template, specify the template name. If you need to save it as the latest version of an existing template, select the name of that existing template.

   2. Click the "Save" button to complete the operation.

      * If you need to continue instance creation, click "Return to Create Instances" to go back to the **Confirm** page.

      * If you need to view the newly created template or version, click "View new template/version" to go to the "Launch Templates" page.

8. After you verify that the information is correct, click "Buy now" to navigate to the submission page. Then, you can check whether the instance is created.

9. Click "Go to the console" to view the ECS instance on the "Instances" page.
