Instance metadata contains the fundamental information of an ECS instance on the cloud platform, such as hostname, instance ID, IP address, and network information. Instance metadata can be used for configuring or managing the instance.

For information on how to view metadata and the metadata items that can be viewed, refer to [Viewing instance metadata](https://docs.byteplus.com/en/docs/ecs/Viewing-instance-metadata).

You can also flexibly manage the startup of ECS instances through setting instance custom data. For more details, please refer to [Custom data overview](https://docs.byteplus.com/en/docs/ecs/Custom-data-overview).
