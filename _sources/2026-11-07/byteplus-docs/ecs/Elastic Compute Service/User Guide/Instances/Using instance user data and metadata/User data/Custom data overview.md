For ECS instances, you can set custom data. You can use custom data when creating an ECS instance or modify the custom data for an existing ECS instance. This enables the ECS instance to automatically obtain software packages, install web servers, or pass in data during the initial startup. This provides you with more flexible operations to meet complex technical and scenario requirements.

You can use the custom data feature through the ECS console or OpenAPI. Custom data can be written using various types of scripts and passed to the instance as text. After import, you can view the custom data content of the instance through instance metadata. For more information, see Setting custom data. For more information, please refer to [Configuring custom data](https://docs.byteplus.com/en/docs/ecs/Configuring-custom-data).

For more information on instance metadata, please refer to [Instance metadata overview](https://docs.byteplus.com/en/docs/ecs/Instance-metadata-overview).
