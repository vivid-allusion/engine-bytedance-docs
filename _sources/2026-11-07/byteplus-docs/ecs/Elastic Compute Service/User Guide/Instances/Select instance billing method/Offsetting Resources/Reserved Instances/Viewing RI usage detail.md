This topic mainly describes how to view usage details of Reserved Instances (RI).

<span id="7SdYyzmh"></span>
## Procedure


1. Log in to the [Offsetting resources console](https://console.byteplus.com/ecs/ri).

2. In the top menu bar, select the region and project of your business.

3. On the RI list page under the "Compute" tab, click the "Usage details" button in the "Actions" column on the right side of the target RI. You can then be redirected to "Billing center \> Resource package" to view the resource usage details.
