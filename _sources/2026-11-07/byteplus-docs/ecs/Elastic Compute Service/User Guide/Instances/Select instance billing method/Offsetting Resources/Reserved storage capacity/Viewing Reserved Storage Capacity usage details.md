This topic explains how to view usage details of Reserved Storage Capacity (RSC).

<span id=".5p-l55yL5Z-656GA5L-h5oGv"></span>
## Viewing basic information


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the top menu bar, select the region where the RSC voucher resides.

3. In the left navigation pane, click "Offsetting Resources".

4. Click the "Reserved Storage Capacity" tab to view basic information about your RSC vouchers, including specifications, reserved and remaining capacities, and effective time.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Remaining capacity represents the portion of purchased RSC that has not been used, and it helps you understand your RSC usage. The formula is as follows:   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Remaining capacity = (Total capacity – Deducted capacity – Expired capacity) ÷ Total capacity   </div>
   

<span id=".5p-l55yL5L2_55So5piO57uG"></span>
## **Viewing usage details**


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the top menu bar, select the region where the RSC voucher resides.

3. In the left navigation pane, click "Offsetting Resources".

4. On the "Offsetting resources" page, click the "Reserved Storage Capacity" tab. Then, click "Usage details" in the "Actions" column of the RSC voucher that you want to check.

5. On the "Resource package" page, navigate to the "Reserved Storage Capacity" tab. Then, click the "Details" tab to view the usage details.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For more information on relevant parameters, see <a href="https://docs.byteplus.com/en/docs/byteplus-platform/docs-viewing-deduction-details">Deduction details</a>.   </div>
