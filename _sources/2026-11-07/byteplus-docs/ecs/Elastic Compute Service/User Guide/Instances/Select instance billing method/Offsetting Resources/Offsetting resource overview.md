Offsetting resources include Reserved Instances (RI) and Reserved Storage Capacity (RSC). They serve as vouchers with deduction and reservation capabilities, mainly used to offset the charges for compute resources (vCPU and memory) and block storage of pay\-as\-you\-go instances. Using them in combination significantly reduces the cost of pay\-as\-you\-go instances.

<span id=".6aKE55WZ5a6e5L6L5Yi4"></span>
## RI

After you purchase an RI, you can use it to offset the bills for compute resources (vCPU and memory) of pay\-as\-you\-go instances (excluding spot instances), and to reserve instance resources for stable supply. For more information, refer to [Reserved Instances overview](https://docs.byteplus.com/en/docs/ecs/Reserved-instances-overview).

For the billing method and deduction rules of RI, refer to [Billing method - Reserved instances](https://docs.byteplus.com/en/docs/ecs/Reserved-instances).

<span id=".6aKE55WZ5a2Y5YKo5a656YeP5YyF"></span>
## RSC

After you purchase RSC, you can use it to offset the bills for block storage of pay\-as\-you\-go instances, and to reserve block storage resources for stable supply. For more information, refer to [Reserved Storage Capacity overview](https://docs.byteplus.com/en/docs/ecs/Reserved-storage-capacity-overview).

For the billing method and deduction rules of RSC, refer to [Billing method - Reserved Storage Capacity](https://docs.byteplus.com/en/docs/ecs/Reserved-storage-capacity).
