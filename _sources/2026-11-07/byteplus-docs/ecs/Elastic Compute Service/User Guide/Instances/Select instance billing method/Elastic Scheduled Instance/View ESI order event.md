This document describes how to view and receive event notifications related to Elastic Scheduled Instances (ESI).

<span id=".5o6l5pS25LqL5Lu26YCa55-l"></span>
## Receive event notifications

After an ESI order is created, the corresponding system event will be generated. You can [subscribe to event notifications](https://docs.byteplus.com/en/docs/ecs/Receiving-event-notifications#.6K6i6ZiF5LqL5Lu26YCa55-l) to receive event notifications via internal message, SMS, email, and other channels at different stages, such as order creation, instance delivery, and order cancellation.

For Elastic Scheduled event types, please refer to [Event type summary](https://docs.byteplus.com/en/docs/ecs/Event-type-overview).

<span id=".5p-l55yL5LqL5Lu255uR5o6n"></span>
## View event monitoring


1. Log in to the [Elastic Scheduled Instances console](https://console.byteplus.com/ecs/esi).

2. In the top menu bar, select the region and project for your business.

3. On the reservation order list page, click the name of the target reservation order to view its details page.

4. Click the "Event monitoring" tab, filter event information by time range or event ID, and process it.

5. Click the "View details" button in the "Actions" column of the target event to view information such as the event occurrence time, type, and other details.
