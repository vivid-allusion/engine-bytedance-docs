The normalization factor measures the computing power of an instance and is used in RI change and bill deduction. Total amount that can be deducted with one RI per hour = Normalization factor for the instance type \* Instance quantity \* 3,600 seconds. This topic describes how to view the normalization factor.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Offsetting resources console](https://console.byteplus.com/ecs/ri).

2. In the top menu bar, select the region and project of your business.

3. On the RI list page under the "Compute" tab, click the "View normalization factor table" button in the upper\-right corner.

4. In the pop\-up normalization factor table, select the target instance type family from the drop\-down list to view the normalization factors of all instance types in the target family. To view detailed RI deduction rules for pay\-as\-you\-go instances, click the "View detailed deduction rules" button to open the [bill deduction](https://docs.byteplus.com/en/docs/ecs/Reserved-instances) documentation.
