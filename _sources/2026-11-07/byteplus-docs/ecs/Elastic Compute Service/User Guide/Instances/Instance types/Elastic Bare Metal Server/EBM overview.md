Elastic Bare Metal (EBM) provides elastic and scalable high\-performance computing services with the same performance as traditional physical servers and secure physical isolation. With minute\-level provisioning, EBM helps you improve the efficiency of your core business and achieve rapid business growth.

<span id=".5Lqn5ZOB5LyY5Yq_"></span>
## Benefits


* **Dedicated computing power**

   Bare metal instances run on a dedicated physical server and are powered by the extreme performance of the dedicated computing host.

* **High performance**

   No virtualization overhead or performance loss and 100% utilization of computing resources. This enables high bandwidth & low\-latency cloud storage and cloud network access.

* **Quick delivery**

   Compared to traditional physical machines, EBM allows resource delivery within a few minutes. With smooth access to the public cloud VPC network and block storage, EBM allows you to access cloud resources easily.

* **High security and reliability**

   User resources are physically isolated to meet security and compliance requirements. In addition, EBM is configured with security infrastructure same as ECS and integrates Cloud Monitor service. The comprehensive network monitoring service secures your network.

* **Efficient management**

   You can flexibly manage instance resources through the console or by calling OpenAPI operations. EBM is integrated with the Auto Scaling service, allowing you to scale resources elastically.
