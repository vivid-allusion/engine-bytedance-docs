An **instance** is a virtual machine that consists of essential computing components such as CPU, memory, operating system, network, and disk. You have complete control over your instances and can easily customize and change the instance configuration.

The cloud platform provides multiple instance types for you to choose from. These instance types vary in computing and storage capabilities to suit different scenarios.

You can scale in/out the compute resources in real time based on your business needs. This way, you can build an efficient, reliable, and secure computing environment. Additionally, this significantly reduces the cost of your organization in software and hardware procurement and simplifies IT operations and maintenance.

The purchase of ECS instances is a self\-service process. You only need to specify the configuration information.


* For information on the states an instance undergoes from creation to release, refer to [Instance lifecycle management](https://docs.byteplus.com/en/docs/ecs/Instance-lifecycle).

* For more information on instance types, refer to [Instance types](https://docs.byteplus.com/en/docs/ecs/Introduction-to-instance-types).
