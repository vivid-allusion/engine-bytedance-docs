## Applicable scenarios

On the "Instances" page, you can view the information about all ECS instances in a selected region. For example, you can view the instance name/ID, instance status, monitoring status, primary IP address, image, availability zone, instance type, billing method, and renewal method. You can also follow the steps below to customize the list

<span id=".6Ieq5a6a5LmJ5a6e5L6L5YiX6KGo6aG1"></span>
## Customize the Instances page


1. Log in to the  [ECS console](https://console.byteplus.com/ecs/instance). 

2. In the left\-side navigation pane, select "Instances & Images \> Instances".

3. In the top menu bar, select the project and region.

4. On the Instances page, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9cec7dc8d8eaa59c8a1f36746ffc85cc.png) </span>icon on the upper\-right corner.

5. Select the list items that you want to display, such as the project, key pair, and EIP billing method.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">To restore to the default settings, click "Restore default" at the bottom.   </div>
   

6. Click "Apply" to complete the operation. The system will display the corresponding information in the Instances page based on the list items you have set.


<span id=".6Ieq5a6a5LmJ5a-85Ye65a6e5L6L5YiX6KGo"></span>
## Exporting specified information


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance). 

2. In the left\-side navigation pane, select "Instances & Images \> Instances".

3. In the top menu bar, select the project and region.

4. On the instance list page, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d6e827de19f4af38f17cf6486400a666.png) </span>icon on the upper\-right corner.

5. In the "Export Instances List" dialog box, select the export range and export content.

   * Export range: By default, all instances are exported. You can also customize the range.

   * Export content: Select the list items that you want to export.

6. Click "OK" to complete the operation.
