This topic describes how to change the metering method and maximum bandwidth for pay\-as\-you\-go EIPs associated with an ECS instance in the ECS console.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Usage notes

For pay\-as\-you\-go EIPs, the metering methods include pay\-by\-bandwidth and pay\-by\-data\-transfer based on billing items. For detailed descriptions, refer to [EIP - Pay-as-you-go](https://docs.byteplus.com/en/docs/eip/Pay-as-you-go).

<span id="f3dgcHVS"></span>
## Procedure 


* **EIP \- change the metering method**: Change the metering method in the EIP console. For details, refer to [Changing billing methods](https://docs.byteplus.com/en/docs/eip/Billing-methods-change).

* **EIP \- change the maximum bandwidth** **:** 

   1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance). 

   2. In the left\-side navigation pane, select "Instances & Images \> Instances".

   3. In the top menu bar, select the region and project of the target instance.

   4. On the Instances page, click the target EIP, or hover over the target EIP and click the "Change bandwidth" to change the bandwidth. For detailed operations, refer to [EIP - Changing the maximum bandwidth](https://docs.byteplus.com/en/docs/eip/Modifying-the-maximum-bandwidth).
