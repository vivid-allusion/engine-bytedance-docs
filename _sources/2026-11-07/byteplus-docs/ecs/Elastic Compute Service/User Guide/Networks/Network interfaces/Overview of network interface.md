## Description

A network interface is also called a virtual network interface (VNI). In the Virtual Private Cloud (VPC), a network interface is a network interface mounted on cloud resources like Elastic Compute Service (ECS) or Classic Load Balancer. It serves as an essential component for enabling network communication.

Each network interface has one primary private IP address. If necessary, multiple secondary private IP addresses can be manually allocated to it. For details, refer to [IP address overview](https://docs.byteplus.com/en/docs/vpc/IP-address-Overview).

<span id=".572R5Y2h57G75Z6L"></span>
## Network interface types


|Type |Description |
|---|---|
|Primary network interface |The primary network interface is generated by default when creating an ECS instance. It cannot be detached from the ECS and is automatically deleted along with the ECS instance. |
|Secondary network interface |The secondary network interface is manually created by the user, supporting mount, unmount, and delete operations, offering flexibility. |
|BytePlus Network Interface |The BytePlus Network Interface is automatically created by the system when you create services such as Transit Router (TR) or NAT Gateway. It enables private network connectivity for backend services. You can only modify the tags of the BytePlus Network Interface. You cannot delete, mount, or unmount the BytePlus Network Interface. The lifecycle of the BytePlus Network Interface is aligned with that of the associated ECS instance. |

## Applicable scenarios


* **Building high\-availability clusters**

   Multiple network interfaces can be deployed on a single ECS instance to build a high\-availability architecture, thereby improving system stability and reliability.

* **Low\-cost failover**

   The private IP address, EIP, and security group rules of a secondary network interface are all closely associated with the secondary network interface. In the event of a failure, the secondary network interface can be unmounted from the failed ECS instance and mounted to a standby ECS instance. This allows for the rapid transfer of business traffic from the failed instance to the standby one, enabling quick service recovery.

* **Granular traffic management**

   You can configure multiple network interfaces on an ECS instance and use different interfaces for different scenarios, such as internal access and Internet\-facing services. Precise security group rules can be configured for each network interface based on business scenarios to effectively control the traffic direction of each network interface.

* **Multiple private IP addresses for a single ECS instance**

   Multiple private IP addresses can be assigned to the network interfaces of an ECS instance. If your ECS instance hosts multiple applications, a separate external IP address can be assigned to each application, which significantly enhances the utilization of the ECS instance.

* **Multiple EIPs for a single ECS instance**

   When multiple IP addresses are assigned to a network interface of an ECS instance, multiple EIPs can be associated with those IP addresses. This helps prevent business interruptions caused by blocked EIPs.

## Limits


* You can mount a secondary network interface to only one ECS instance.

* The number of private IPv4 addresses and private IPv6 addresses that you can assign to the primary network interface or to any secondary network interface mounted to an ECS instance is limited by the private IP address quota of a single network interface. The quota is determined based on the [ECS instance type](https://docs.byteplus.com/en/docs/ecs/Introduction-to-instance-types).

   > For example, you can assign up to six private IPv4 addresses (including the primary private IPv4 address) and six private IPv6 addresses to the primary or secondary network interface of an ECS instance whose type is [ecs.g3i.large](https://docs.byteplus.com/en/docs/ecs/General-purpose#.6YCa55So5Z6LZzNp).   
   

* You can manually assign up to nine secondary private IPv4 addresses and ten private IPv6 addresses to a secondary network interface that has never been mounted to an ECS instance.

* You can associate each private IPv4 address of a network interface with an EIP.

* By default, IPv6 addresses of a network interface only support private network communication. To access the Internet over IPv6, you need to first enable IPv6 Internet access.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">IPv6 gateways and Dual\-Stack VPC are currently in beta. If you need a trial, contact your account manager.   </div>
   

* Each network interface has only one globally unique MAC address.


For more information about network interface limits, refer to [Limits](https://docs.byteplus.com/en/docs/vpc/Limits#.572R5Y2h).

## Configuration procedure


<Tabs>
<Tab zoneid="wJKZkxIK" title="Secondary network interface">
<TabTitle>Secondary network interface</TabTitle>

If you need to assign and configure secondary private IPv4 or IPv6 addresses for the secondary network interface, perform the following steps:


1. [Create a secondary network interface.](https://docs.byteplus.com/en/docs/vpc/Creating-a-secondary-network-interface)

2. [Mount the secondary network interface to an ECS instance.](https://docs.byteplus.com/en/docs/vpc/Loading-or-unloading-a-secondary-network-interface#.5oyC6L296L6F5Yqp572R5Y2h)

3. [Configure the secondary network interface for the ECS instance.](https://docs.byteplus.com/en/docs/ecs/Configuring-auxiliary-network-interfaces-for-ECS-instances)

4. (Optional) Assign and configure secondary private IPv4 or IPv6 addresses for the secondary network interface.

   * IPv4:

      1. [Assign IPv4 addresses.](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address) 

      2. [Configure private IPv4 addresses for the ECS instance.](https://docs.byteplus.com/en/docs/ecs/Configuring-secondary-private-IPv4-addresses-for-ECS-instances)

      3. If the IP addresses assigned to the secondary network interface need to communicate with the Internet, you can [associate EIPs with the IP addresses.](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP)

   * IPv6:

      4. [Assign IPv6 addresses.](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address)

      5.  [Configure private IPv6 addresses for the ECS instance.](https://docs.byteplus.com/en/docs/ecs/Configuring-private-IPv6-addresses-for-ECS-instances)

      6. If the IP addresses assigned to the secondary network interface need to communicate with the Internet, you can [enable IPv6 Internet bandwidth.](https://docs.byteplus.com/en/docs/IPv6/Enable_IPv6_internet_bandwidth)

5. [Delete the network interface.](https://docs.byteplus.com/en/docs/vpc/Deleting-a-network-interface)


</Tab>

   1. [Assign IPv4 addresses.](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address)

   3. (Optional) If the IP addresses assigned to the primary network interface need to communicate with the Internet, you can [associate EIPs with the IP addresses.](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP) 

* IPv6:

   1. [Assign IPv6 addresses.](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address)

   2.  [Configure private IPv6 addresses for the ECS instance.](https://docs.byteplus.com/en/docs/ecs/Configuring-private-IPv6-addresses-for-ECS-instances)

   3. (Optional) If the IP addresses assigned to the primary network interface need to communicate with the Internet, you can [enable IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/IPv6/Enable_IPv6_internet_bandwidth).
