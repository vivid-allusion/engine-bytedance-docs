This topic is about the event monitoring capability offered by Elastic Block Storage (EBS).

> **tip**

> The system events module of DataInsights is currently in closed beta. Contact your account manager to have your account added to the allowlist and start using it.

## Prerequisites

You have enabled the [DataInsights](https://docs.byteplus.com/en/docs/ecs/data-insights-overview) feature.

## Introduction

This module continuously identifies risks related to volume stability, performance, and data protection. It summarizes event status, affected resources, and recommended actions. You can filter events, view details, and quickly resolve issues based on AI\-generated recommendations.

## Notes

* We recommend first prioritizing "Serious" events with a "Waiting for response" status, followed by "Warning" events. After resolving an event, return to the list to confirm its status.

* Before addressing a "Serious" event, verify the associated resources and business impact. If the event involves replacing or deleting a failed volume, follow the instructions on the page to complete the necessary data protection and business confirmation steps.

## Viewing system event data

1. Log in to the [ECS console](https://console.byteplus.com/ebs).

2. In the top menu bar, select the region that you want to check.

3. In the left navigation pane, select "Storage \> DataInsights" **.**

4. On the "DataInsights" page, select "System events \> System event".

5. On the "System event" tab, set the filter conditions to view risks and anomalies related to the desired volume(s). This allows you to quickly identify performance bottlenecks and stability issues and reduce diagnostic effort with AI\-generated recommendations.

   * Event statistics

      |Parameter |Description |

      |Pending response event |Displays the total number of pending events for the current account — that is, events that have been triggered but not yet handled or ignored. |
      |Serious event |Displays the total number of "Serious" events for the current account. These events typically pose a high risk and should be addressed first. |
      |Warning event |Displays the total number of "Warning" events for the current account. These events indicate potential risks and should be monitored and addressed promptly. |

## Handling an event

On the "System event" tab, you can find the diagnostic conclusion and risk description of a volume event in the "AI processing suggestions" column.

1. On the "DataInsights" page, select "System events \> System event". Then, set the filter conditions, such as event ID, event level, and time range.

2. In the filtered list, click "To deal with" in the "Actions" column of an event. Then, select the appropriate action based on the event type.

   For a list of event types and recommended actions, see [Supported events](https://docs.byteplus.com/en/docs/ecs/system-events?lang=en#oJQItlYU).

## Ignoring an event

You can ignore events that do not require attention or handling. After ignoring an event, you will no longer receive alerts of that type.

1. On the "DataInsights" page, select "System events \> System event". Then, set the filter conditions, such as event ID, event level, and time range.

2. In the filtered list, click "Ignore" in the "Actions" column of an event.

3. In the "Ignore event" dialog box, click "OK".

   For a list of event types and recommended actions, see [Supported events](https://docs.byteplus.com/en/docs/ecs/system-events?lang=en#oJQItlYU).

## Configuring events

The "Event configuration" tab lets you control which event types are monitored for which volumes. You can configure the scope of a single event type or update the scope of multiple event types in batches.

1. On the "DataInsights" page, select "System events \> Event configuration".

2. On the "Event configuration" tab, enable or disable alerts for one or more event types and modify their applicable volume as needed.

### Enabling or disabling alerts

You can turn alerts on or off for specific event types based on your needs.

* To enable or disable alerts for a single event type, turn the "Enabled status" switch on or off.

* To enable or disable alerts for multiple event types:

   1. Select the event types you want to manage.

   2. Click “Modify status” at the bottom of the page.

   3. In the "Batch modification of enabled status" dialog box, turn the "Enabled status" switch on or off.

   4. Click "OK" to apply the changes.

### Changing the effective resources

Based on your needs, you can change which volumes an event type applies to. When editing the effective resources, you can select up to 50 volumes per operation.

* To change the effective resources for a single event type:

   1. Click the edit icon in the "Effective resources" column.

   2. In the "Edit Active Resources" dialog box, adjust the scope on either the "Effective Volume List" or "Not valid Volume list" tab:

      * On the "Effective Volume List" tab, select the volume you want to exclude from the effective scope and click "Cancelled effective".

      * On the "Not valid Volume list" tab, select the volume you want to include in the effective scope and click "Set to take effect".

* To change the effective resources for multiple single event types:

   1. Select the event types whose effective resources you want to adjust.

   2. Click "Modify effective resource" at the bottom of the page.

   3. In the "Batch editing of active resources" dialog box, adjust the scope on either the "Effective Volume List" or "Not valid Volume list" tab:

      * On the "Effective Volume List" tab, select the volumes you want to exclude from the effective scope and click "Cancelled effective".

      * On the "Not valid Volume list" tab, select the volumes you want to include in the effective scope and click "Set to take effect".
