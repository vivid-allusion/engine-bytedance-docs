When you start an instance by using an instance launch template, the default version is automatically used. We recommend that you specify the commonly used version of the instance launch template as the default version. This eliminates the repetitive task of manually selecting a version each time.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Launch Templates console](https://console.byteplus.com/ecs/template).

2. In the top menu bar, select a region.

3. Click the name of the target template, and then click the "Version" tab.

4. Click the "Set as Default" button on the right side of the target version. The version is specified as the default version.
