## Password\-free & login\-free: Secure and efficient

Cloud assistant allows you to run O&M commands on your instances without passwords, login operations, or jump servers. This is convenient and efficient, and also reduces the risk of login password leakage.

<span id="ZJeQukap"></span>
## Batch execution: Improve efficiency

Cloud assistant supports batch execution of O&M commands across multiple target instances, significantly improving your O&M efficiency.

<span id="XAX6wBuJ"></span>
## Custom commands: Customized O&M

Cloud assistant comes with preset common O&M commands for you to use, and offers a custom command feature. You can write your own O&M commands based on actual needs and run them in batches via the cloud assistant.

<span id="YwyeaFCQ"></span>
## Visualized execution results: Track progress intuitively

You can view execution results directly in the console and quickly locate issues.
