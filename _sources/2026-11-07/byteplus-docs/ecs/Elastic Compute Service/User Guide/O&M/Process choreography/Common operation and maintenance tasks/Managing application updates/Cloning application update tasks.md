You can use the clone feature to copy the selected instance, configuration method, corresponding model information, and other information from an existing application update task.

<span id="VJDK0NHA"></span>
## Procedure 


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left\-side navigation pane, click "Maintenance & Monitoring \> Orchestration".

3. In the top menu bar, select the region where your business is located.

4. On the "CloudOps Orchestration" page, click the "Common O&M tasks" tab and select "App update".

5. In the "Actions" column of the target task, click the "Clone" button.

6. (Optional) Modify the parameters based on your business requirements. For more information, see [Creating application update tasks](https://docs.byteplus.com/en/docs/ecs/Creating_application_update_tasks).

7. Click the "Clone" button to complete the operation.
