This topic describes the types, naming format, and general attributes of actions.

<span id="bgETH8Yw"></span>
## Action types

Actions are classified into atomic actions and cloud product actions. [Learn more](https://docs.byteplus.com/en/docs/ecs/Action_list).


* Atomic actions (Atom Action)

   * API actions (API)

   * Trigger actions (Trigger)

   * Control actions (Control)

   * Function execution actions (Function)

   * Nested actions (Template)

* Cloud product actions (Product Action)

   * ECS

   * VPC

   * AS


<span id="hYpaEQxQ"></span>
## Naming format

The naming format for actions is VOS::<name\>.

<span id="TptjRWBM"></span>
## General attributes

Unless otherwise specified, each action has general attributes described in the following table. For more information, see [Tasks description](https://docs.byteplus.com/en/docs/ecs/Overview_of_custom_template_syntax#iLk2JfAg).


|Parameter name |Description |
|---|---|
|Name |The action name. |
|Type |The action type. |
|Description |The description. |
|Parameters |The parameters​. |
|Outputs |The outputs. |
