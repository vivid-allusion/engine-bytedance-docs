You can view the execution results and status of tasks for batch image operations, as well as the basic information, log, and workflow for each task.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left\-side navigation pane, select the "Maintenance & Monitoring \> Orchestration" menu.

3. In the top menu bar, select the region where your business is located.

4. On the "CloudOps Orchestration" page, click the "Common tasks" tab.

5. Click the "Batch operations on images" menu.

6. Click the target task name to view information in the following table.

   
   |Parameter |Description |
   |---|---|
   |Basic information |In the "Basic information" section, you can view the task name, task ID, and role. |
   |Task Logs |In the "Task Logs" section, you can view the execution logs of the current task. |
   |Task flow |In the "Task flow" section, you can view the execution status of the task flow. You can also view its basic information, input/output parameters, and log details. |
