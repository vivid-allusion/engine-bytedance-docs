You can view the execution result, state, overview, and other information of each application update task.

<span id="OGtXmRhQ"></span>
## Procedure


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left\-side navigation pane, click "Maintenance & Monitoring \> Orchestration".

3. In the top menu bar, select the region where your business is located.

4. On the "CloudOps Orchestration" page, click the "Common O&M tasks" tab and select "App update".

5. Click the target task name to view information in the following table.

   
   |Parameter |Description |
   |---|---|
   |Basic information |Display the name, ID, role, and other information of the task. |
   |Task logs |Display the execution logs of the current task. |
   |Task flow |Display the execution status of the task flow, as well as its basic information, input/output parameters, and log details. |
