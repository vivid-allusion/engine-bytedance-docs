This topic summarizes the cloud product steps provided by Orchestration (including their purposes, input, and output arguments), which you can use as needed in orchestration tasks.

<span id=".5LqR5pyN5Yqh5Zmo5a6e5L6L55u45YWz"></span>
## Steps related to ECS instances


|Step |Description |Input parameter |Output parameter |
|---|---|---|---|
|Create an instance with the same configuration as an existing instance |You can use this step to create an instance with the same configuration as an existing instance.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">You cannot use this step to associate an EIP with an instance. For information about how to associate an EIP with a new instance, see <a href="https://docs.byteplus.com/en/docs/ecs/associating-an-EIP">Associating EIP</a>.</div><br> |* Instance ID: The instance serving as a template to create an instance.<br><br>* Agent: Select whether to install the Cloud assistant Agent when creating the instance.<br><br>* Number of instances: The number of new instances that you want to purchase.<br><br>* Purchase duration: When you create a subscription instance, you need to specify this parameter.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">When the source instance uses password\-based login, you need to specify the login password for the new instance:</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Login password: Enter the login password for the new instance.</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Confirm password: Re\-enter the login password.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If the source instance uses key pair\-based login, the new instance automatically uses the key pair of the source instance for login.</div><br> |Instance ID: The IDs of new instances, arranged in a list. |
|Create an instance |You can use this step to create an ECS instance.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">A successfully created instance is in the <strong>Running</strong> status and does not need to be started manually.</div><br> |* Billing method: Select a billing method for the instance.<br><br>* Availability zone: Select the availability zone where the new instance is created.<br><br>* Computing specification: Select the computing specification that meets your business requirements.<br><br>* Image: Select the required image.<br><br>* VPC: Select an existing VPC based on your business requirements. You can also manually create a new VPC. For more information, see [Creating VPCs](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC).<br><br>* Subnet: Select a subnet to assign a primary private IP address to the primary network interface of the instance. You can manage the instance network by using the network interface.<br><br>* Secondary network interface: Select a subnet to assign a secondary network interface to the instance. After the instance is created, enable the secondary network interface and configure the network interface route. For more information, see [Configuring network routes](https://docs.byteplus.com/en/docs/vpc/Configuring-a-network-interface-and-a-private-address).<br><br>* Security group: Select the security group where the instance resides.<br><br>* Login credentials: Select the security credentials for logging in to the ECS instance.<br><br>* Instance name: Specify the name of the ECS instance. By default, the system automatically generates instance names based on the product name. You can also change the name based on your needs.<br><br>* Custom data: Configure custom data for the instance. You can use instance custom data to make the system automatically configure the instance or pass in data when the instance starts up.<br><br>* Number of instances: The number of instances that you want to purchase.<br><br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">To reduce parameter configuration time, the system automatically assigns some parameters. You can modify these parameters based on your business requirements after the instance is created. The following items describe the parameters automatically assigned by the system and the parameters that are not automatically configured.</div><br><br><br><br>* <div data-tips="true" data-tips-type="warning">Region: The region of the new instance is the region displayed before you go to the "Create orchestration task" or "Create orchestration plan" page.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">EBS Volume: By default, the instance is allocated a 40 GiB ESSD as the system volume. No data volumes are allocated.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">Project: The default project is automatically used.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">Parameters such as the EIP, Tag, and Deployment set parameters are not configured.</div><br> |Instance ID: The IDs of new instances, arranged in a list. |
|Delete multiple ECS instances at one time |You can use this step to delete multiple ECS instances at one time. |Instance ID: The ID of the instance that you want to delete.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><br>* <div data-tips="true" data-tips-type="warning">You can delete only pay\-as\-you\-go instances.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">If you select "Custom input", you can select multiple instances.</div><br> |\- |
|Stop multiple instances at one time |You can use this step to stop multiple ECS instances at one time. |* Instance ID: The ID of the instance that you want to stop.<br><br>* How to stop: The method used to stop the instance. The following options are supported:<br><br>   * Stop: the default and regular method that follows the standard procedure for stopping ECS instances.<br><br>   * Forced stop: The running ECS instances are forced to stop, which is equivalent to a power\-off operation. Bare metal instances currently only support forced stop.<br><br>      > Performing a forced stop will cause all cached data not stored to storage devices to be lost. We recommend that you do not perform this operation on instances running normally.      <br>      <br><br>* Stop mode: The stop mode. The following options are supported.<br><br>   * Normal Mode: After the instance is stopped, the instance is retained and you are charged for the instance.<br><br>   * Economical Mode: If you have enabled the allowlist policy and the selected instances include pay\-as\-you\-go instances without mounted local volumes, you can select Economical Mode. For more information, see [Economical Mode description](https://docs.byteplus.com/en/docs/ecs/Economical-mode-for-pay-as-you-go-instances).<br><br>      > Subscription instances, bare metal instances, and HPC\-optimized instances do not currently support Economical Mode. |Stop result: Whether each instance is stopped, arranged in a list. |
|Start multiple instances at one time |You can use this step to start multiple ECS instances at one time. |* Instance ID: Specify the ID of the instance that you want to start. |Start results: Whether each instance is started, arranged in a list. |
|Change the operating system for multiple instances at one time |You can use this step to change the operating system of multiple existing instances at one time. |* Instance ID: The ID of the instance for which you want to change the operating system.<br><br>* Image: The new image. You can select "Public Image", "Custom Image", or "Shared Image".<br><br>* Login credentials: The credentials for logging in to the new system. You can select "Password", "Key pair" or "Keep image logged in".<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Before you change the operating system, stop the target instance.</div><br> |Instance status: The status of each instance, arranged in a list. |
|Restart multiple instances at one time |You can use this step to restart multiple ECS instances at one time. |* Instance ID: Specify the ID of the instance that you want to restart.<br><br>* How to restart: Specify the restart method for the instance. The following options are supported:<br><br>   * Restart: the default and standard restart mode.<br><br>   * Forced restart: Forcibly power off the running instance and then restart it.<br><br>      > For instances other than bare metal instances, performing a forced restart will result in the loss of all cached data not stored to storage devices to be lost. Therefore, we recommend against performing this operation on instances running normally.      <br>      <br><br>      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div><br>      <br><br>      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Bare metal instances currently can only be restarted in forced restart mode.      </div><br>       |Start result: Whether each instance is restarted, arranged in a list. |
|Change the billing method to subscription for multiple instances at one time |You can use this step to change the billing method of multiple instances from pay\-as\-you\-go to subscription at one time.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For information on the conditions and restrictions, see <a href="https://docs.byteplus.com/en/docs/ecs/Converting-from-pay-as-you-go-to-subscription">Changing from pay\-as\-you\-go to subscription</a>.</div><br> |* Instance ID: The ID of the instance for which you want to change the billing method.<br><br>* Purchase duration: Select a subscription duration.<br><br>* Automatic renewal: Select whether to enable automatic renewal. This option is not selected by default.<br><br>* Storage Volume: Select whether to convert the pay\-as\-you\-go data volumes mounted on the instance to subscription data volumes. This option is not selected by default. |* Instance ID: The IDs of instances for which you want to change the billing method, arranged in a list.<br><br>* Billing method: The current billing methods of instances, arranged in a list.<br><br>* Order ID: The order IDs corresponding to this change, arranged in a list. |
|Change the types of multiple instances at one time |You can use this step to upgrade or downgrade the configuration of multiple instances at one time.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Before you change the type of an instance, stop the instance first.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When you change the type of an instance, the instance starts immediately. Confirm the impact on your business and proceed with caution.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Before the instance type change is completed, do not perform any other operations on the instance. Otherwise, the instance type change may fail.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">For more information on conditions and restrictions, see <a href="https://docs.byteplus.com/en/docs/ecs/Overview-2">Changing instance types</a>.</div><br> |* Instance ID: Specify the ID of the instance whose type you want to change.<br><br>* Billing method: Confirm the billing method of the selected instance. After the step is executed, you cannot change the billing method.<br><br>* Availability zone: Confirm the availability zone of the selected instance. After the step is executed, you cannot change the availability zone.<br><br>* Computing specification: Select the new type. |* Instance ID: The IDs of the instances whose types are changed, arranged in a list.<br><br>* Specification: The types of the instances, arranged in a list.<br><br>* Status: The status of the instances, arranged in a list. |
|Deliver commands to an instance for execution. |You can include Cloud assistant tasks in the O&M orchestration through this step. |For more information about input parameters, see [Creating tasks](https://docs.byteplus.com/en/docs/ecs/Creating-a-job).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Currently, manual input of commands is not supported.</div><br> |Task ID: The ID of the cloud assistant task. The value of this parameter is a string. |

## Steps related to images


|Step |Description |Input parameter |Output parameter |
|---|---|---|---|
|Create a custom image based on an existing instance |You can use this step to create a custom image from the system volume of an existing instance. |* Instance ID: The ID of the instance for which you want to create a custom image.<br><br>* Image Name: The name for the newly generated custom image.<br><br>* Description  **(optional)** : The description of the newly generated custom image. |Image ID: The ID of the generated custom image. The value of this parameter is a string. |
|Copy a custom image across regions |You can use this step to copy the source custom image and its configuration to another region. |* Image ID: The custom image that you want to copy.<br><br>* Target Region: The region where the target image is located.<br><br>   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div><br>   <br><br>   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The target region must be different from the region where the source custom image resides.   </div><br>   <br><br>* Image Name: The name of the target custom image.<br><br>* Image description: The description of the target image. If you do not configure this parameter, the description of the target image is the same as that of the source custom image.<br><br>* Project: The project to which the resource belongs. |Image ID: The ID of the new custom image generated by replication. The value of this parameter is a string. |
|Share an image |You can use this step to share an existing custom image with other BytePlus accounts. |* Image ID: The custom image that you want to share.<br><br>* Account ID: Other BytePlus accounts with which you want to share the image.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Each image can be shared with up to 50 BytePlus accounts.   </div><br>    |\- |

## Steps related to EIPs


|Step |Description |Input parameter |Output parameter |
|---|---|---|---|
|Apply for multiple EIPs at one time |You can use this step to apply for an EIP. |* Name: The name of the EIP.<br><br>* Billing method: The billing method for the specified EIP.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">By default, each account can create up to 20 EIPs in each region.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">The EIPs that you create at one time have the same name but different IDs.</div><br><br><br>* Safety protection: Select the security protection type for the EIP.<br><br>   > EIPs with enhanced protection are in the beta stage. If you need a trial, contact your account manager.   <br>   <br><br>* ISP: Select the ISP for the EIP.<br><br>* Metering method: Select the metering method for the EIP.<br><br>* Bandwidth upper limit: The bandwidth upper limit of the EIP.<br><br>* Add EIP to Bandwidth Package: Select whether to join the Bandwidth Package.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you select "Add EIP to Bandwidth Package", select the name of the Bandwidth Package you want to join.   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The Bandwidth Package feature is currently in Beta. If you need a trial, contact your account manager.   </div><br>   <br><br>* Quantity: Specify the number of EIPs to apply for.<br><br>* Project: The project to which the specified EIP belongs. |* EIP: The ID of each successfully assigned EIP, arranged in a list.<br><br>* IP address: The IP address of each successfully assigned EIP, arranged in a list.<br><br>* Status: The status of each successfully assigned EIP, arranged in a list. |
|Associate an EIP |You can use this step to associate an existing EIP with the specified cloud resource. |* EIP: Select the EIP to associate.<br><br>* Instance Type: Select the type of cloud resource with which you want to associate the EIP.<br><br>* Project: Select the project where the instance is located.<br><br>* Select instances: Select the cloud resources with which you want to associate EIPs. |* EIP: The ID of the EIP. The value of this parameter is a string.<br><br>* Internet status: The status of the EIP after association. The value of this parameter is a string.<br><br>* Instance ID: The ID of the associated instance. The value of this parameter is a string. |
|Disassociate multiple EIPs at one time |You can use this step to disassociate EIPs from cloud resources. |EIP: Select the EIP to disassociate. |* EIP: The disassociated EIPs, arranged in a list.<br><br>* Status: The status of the EIPs after disassociation, arranged in a list. |
|Modify the bandwidth for multiple EIPs at one time |You can use this step to modify the bandwidth upper limit of existing EIPs. |* EIP: The EIP for which you want to modify the bandwidth.<br><br>* Maximum bandwidth: The target bandwidth upper limit for the EIP. |EIP: The IDs of the EIPs, arranged in a list. |
|Release multiple EIPs at one time |You can use this step to delete EIPs. |EIP: The EIP that you want to delete. |EIP: The IDs of the EIPs, arranged in a list. |
