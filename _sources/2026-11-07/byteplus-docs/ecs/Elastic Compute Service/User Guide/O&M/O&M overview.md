To improve the stability of ECS instances, BytePlus platform offers you O&M services. This helps you quickly address instance exceptions and ensures service stability.

<span id=".6I635Y-W5a6e5L6L57O757uf5pel5b-X5LiO5bGP5bmV5oiq5Zu-"></span>
## Instance system logs and screenshots

This feature allows you to view system logs and screenshots of ECS instances. This helps you troubleshoot issues such as instance malfunctions and failed remote login. For details, refer to [Accessing instance system logs and screenshots](https://docs.byteplus.com/en/docs/ecs/Obtaining-instance-system-logs-and-screenshots).

<span id=".5om56YeP5L2c5Lia"></span>
## Cloud assistant

The cloud assistant is a native tool for automatic O&M, which is developed by the BytePlus platform. With the cloud assistant, you can perform operation commands on one or multiple objects. You do not need to input passwords, log in, or use a jump server. For details, refer to [Cloud assistant overview](https://docs.byteplus.com/en/docs/ecs/Overview-of-cloud-assistant).

<span id="J3spcKKQ"></span>
## Orchestration

Orchestration is an automatic O&M service for cloud products provided by BytePlus. With this service, you can orchestrate task workflows based on your business requirements for auto\-execution. You can also centrally manage these tasks and view their execution progress and results. For details, refer to [Orchestration overview](https://docs.byteplus.com/en/docs/ecs/Overview_of_Process_Orchestration).

<span id=".5a6e5L6L6K-K5pat"></span>
## Instance diagnosis

This feature is used to check instance performance, the status of the network, volumes, and other items. This helps you timely identify and understand common issues with ECS instances to ensure the normal operation of your instance. For details, refer to [Instance diagnosis overview](https://docs.byteplus.com/en/docs/ecs/Instance_diagnosis_overview).
