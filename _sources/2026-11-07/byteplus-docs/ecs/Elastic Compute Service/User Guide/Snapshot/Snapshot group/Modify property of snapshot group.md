After a snapshot group is created, you can modify the name or description of the group.

<span id="procedure"></span>
## Procedure


1. Log on to the [ECS console](https://console.byteplus.com/ecs).

2. In the top menu bar, select the target Region.

3. In the left\-side navigation pane, select **Storage** \> **Snapshots**.

4. On the **Snapshots** page. click the **Snapshot Group** tab.

5. On the **Snapshot Group** tab, click the name of target snapshot group.

6. In the **Snapshot Group** pane, click the edit icon following **Snapshot group name** and **Description** to modify the target parameters. The following table describes the parameters.

   
   |Parameter |Description |
   |---|---|
   |Snapshot group name |(Required) Set the name of your snapshot group. Make sure the name meets the following requirements:<br><br><br>* The name starts with a Chinese character, a letter, or an underscore ( _ ).<br><br>* The name can contain Chinese characters, letters, digits, underscores ( _ ), and hyphens ( \- ).<br><br>* The name is 1 through 128 characters in length. |
   |Description |(Optional) Set the description of your snapshot group. Make sure the description meets the following requirements:<br><br><br>* The description starts with a Chinese character, a letter, or an underscore ( _ ).<br><br>* The description can contain Chinese characters, letters, digits, underscores ( _ ), and hyphens ( \- ).<br><br>* The description is 0 through 255 characters in length. |
   

7. After you set the target parameters, click <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_e7740750509cbcff88c943b09015b695.png) </span> icon.
