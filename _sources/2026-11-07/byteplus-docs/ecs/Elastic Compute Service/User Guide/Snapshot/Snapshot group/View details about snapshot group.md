This topic describes how to view details about a snapshot group.

<span id="procedure"></span>
## Procedure


1. Log on to the [ECS console](https://console.byteplus.com/ecs).

2. In the top menu bar, select the target Region.

3. In the left\-side navigation pane, select **Storage** \> **Snapshots**.

4. On the **Snapshots** page. click the **Snapshot Group** tab.

5. On the **Snapshot Group** tab, click the name of target snapshot group.

6. In the **Snapshot Group** pane, view the details about the group, including information in **Snapshot group name**, **Description**, **Snapshot group ID**, Created time, and the **Snapshots** list.
