After a snapshot is created, you can modify its name and description. This topic describes how to modify snapshot properties.

<span id="procedure"></span>
## Procedure

<span id="modifying-properties-on-the-volume-list"></span>
### Modifying properties on the volume list


1. Log on to the [ECS console](https://console.byteplus.com/ecs).

2. In the left\-side navigation pane, click **Storage** \> **Volumes**.

3. In the top menu bar, choose the project and the Region of the target volume.

4. On the volume list, find the target volume. Then, in the **Actions** column, click the **ellipsis** icon \> **Check snapshot chain**.

5. On the snapshot chain list, find the target snapshot. Then, in the **Actions** column, click the **ellipsis** icon \> **Modify properties**.

6. In the dialog box that appears, type the desired name and description, then click **Edit snapshot properties**.


<span id="modifying-properties-on-the-snapshot-list"></span>
### Modifying properties on the snapshot list


1. Log on to the [ECS console](https://console.byteplus.com/ecs).

2. In the left\-side navigation pane, click **Storage** \> **Snapshots**.

3. In the top menu bar, choose the project and the Region of the target snapshot.

4. Find the target snapshot. Then, in the **Actions** column, click the **ellipsis** icon \> **Modify properties**.

5. In the dialog box that appears, type the desired name and description, then click **Edit snapshot properties**.
