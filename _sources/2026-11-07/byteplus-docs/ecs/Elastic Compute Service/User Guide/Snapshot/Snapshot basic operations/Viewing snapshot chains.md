A snapshot chain illustrates the relationships among all the snapshots within a single volume. Each volume corresponds to one such chain. This topic explains how to view a snapshot chain.

<span id=".5LuO5LqR55uY5YiX6KGo5p-l55yL"></span>
## From the Volumes page


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left navigation pane, select "Storage \> Volumes".

3. In the top menu bar, select the project and region where the volume resides.

4. On the "Volumes" page, click "... \> View snapshot chain" in the "Actions" column of the volume. Then, you can view all snapshots of the volume and their relationships. This includes the number and size of all the snapshots in the snapshot chain.


<span id=".5LuO55uu5qCH5b-r54Wn5p-l55yL"></span>
## From the Snapshots page


1. Log in to the [ECS console](https://console.byteplus.com/ecs/instance).

2. In the left navigation pane, select "Storage \> Snapshots".

3. In the top menu bar, select the project and region where the snapshot resides.

4. On the "Snapshots" page, click "... \> View snapshot chain" in the "Actions" column of the snapshot. Then, you can view details about the snapshot chain to which the snapshot belongs. This includes the number and size of all the snapshots in the snapshot chain.
