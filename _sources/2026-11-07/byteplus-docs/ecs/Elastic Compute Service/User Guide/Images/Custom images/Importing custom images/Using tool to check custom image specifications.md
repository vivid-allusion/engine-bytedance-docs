BytePlus provides a custom image specification check tool (hereinafter referred to as "the check tool"), which automatically checks whether Linux operating system configurations comply with the requirements for creating ECS instances, shortens the time required to create custom images, and helps prevent ECS instances created from custom images from having incomplete features.

This topic describes how to use the check tool and the metrics involved in the checks.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Usage notes


* The check tool supports only Linux images, including Ubuntu, CentOS, Debian, OpenSUSE, Fedora, veLinux, Rocky Linux, and other Linux distributions. It does not support Windows images.

* The check tool primarily checks whether a custom image can be used to create a fully featured ECS instance. For information about the requirements for importing images, see [Requirements for importing custom images](https://docs.byteplus.com/en/docs/ecs/Importing-custom-images-1).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to your server, virtual machine, or ECS instance on other cloud platforms.

2. Execute the following command to download the check tool package to the current directory over the Internet.

   ```Plain Text
   wget https://image-check-shanghai.tos-cn-shanghai.volces.com/image_check.tar
   ```
   

3. Execute the following command to extract files from the check tool package.

   ```Plain Text
   tar -xvf image_check.tar
   ```
   

4. Execute the following command to add executable permission to the check tool file.

   ```Plain Text
   cd image_check
   chmod +x image_check
   ```
   

5. Execute the following command as root to run the check tool. This ensures that the tool can read configuration files specified with access permissions.

   ```Plain Text
   sudo <path_to_inspection_tool>/image_check -p [inspection_report_output_path]
   ```
   

6. Wait for the check tool to check the system configuration.

   ```Plain Text
   Detecting your system...
   date: 2023-04-10 11:42:12
   --------------------------------------------------
   your system: centos
   Version: 7
   Disk size: 40 GB
   --------------------------------------------------
   [ Check virtio driver ]                      [  OK  ] 
   [ Check cloud init ]                         [  OK  ] 
   [ Check /etc/shadow ]                        [  OK  ] 
   [ Check disk uuid ]                          [  OK  ] 
   [ Check password command ]                   [  OK  ] 
   [ Check disk size ]                          [  OK  ] 
   [ Check disk use rate ]                      [  OK  ] 
   [ Check inode use rate ]                     [  OK  ] 
   [ Check reset-authentication ]               [  OK  ] 
   --------------------------------------------------
   ok count : 9
   failed count : 0
   warning count : 0
   --------------------------------------------------
   the path generated by the report is :image_check/linux_image_check_report_2023-04-10_11-42-12.txt
   Please query the report to get the specific check result information
   ```
   

   The check tool returns a result of `OK`, `FAILURE`, or `WARNING` for each check item. If a check item indicates that the image does not comply with the specifications, you can fix the image by following the recommendations provided in "Check items".

   * `OK`: The image complies with the specifications.

   * `FAILURE`: The image does not comply with the specifications. ECS instances created by using the custom image cannot start as expected. We recommend that you fix the reported errors before you create the image to improve instance startup efficiency.

   * `WARNING`: The image does not comply with the specifications. ECS instances created by using the custom image can start safely, but ECS cannot effectively intervene in your instance configuration. You can address the reported issue immediately, or temporarily ignore the issue and create the image.

7. You can execute the following command to view the check report generated by the check tool.

   Only the `.txt` format is supported for reports. The check tool displays the path to the report in the output. The report file is named in the format of `image type_image_check_report_date_time.txt`.

   You can execute the following command to view the check report.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Replace the report path with the content next to <code>the path generated by the report is:</code>.   </div>
   

   ```Plain Text
   cat image_check/linux_image_check_report_2023-04-10_11-42-12.txt
   ```

## Check items


|Check item |Severity |Description |Suggestion |
|---|---|---|---|
|virtio driver |FAILURE |Check whether the Virtio driver is installed.<br><br>If you want to import a custom image to BytePlus, the custom image must be installed with the virtualization driver. |[Install the Virtio driver.](https://docs.byteplus.com/en/docs/ecs/Creating-Linux-images#5VeObo5n) |
|cloud init |WARNING |Check whether Cloud\-init is installed.<br><br>To import a custom image to BytePlus, Cloud\-init must be installed and the data source of Cloud\-init must be the BytePlus source. |[Install Cloud-init.](https://docs.byteplus.com/en/docs/ecs/Creating-Linux-images#.56ys5Zub5q2l77ya5Zyo6Jma5ouf5py65LiK5a6J6KOFQ2xvdWQtaW5pdA==) |
|/etc/shadow |FAILURE |Check whether the password file is modifiable.<br><br>This file must be modifiable. Otherwise, the user cannot reset the password in the BytePlus ECS console. |Do not use the `chattr` command to lock files. |
|disk size |FAILURE |Check whether the volume capacity meets the requirements.<br><br>The size of the system volume of the ECS instance that you create by using the custom image is determined based on the total capacity (not the used capacity) of the system volume in the image. The total capacity of the system volume in the image cannot exceed 500 GiB.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">If the capacity of the system volume in your image is less than 40 GiB, when you use this image to create an ECS instance, the BytePlus platform creates a system volume with a capacity of 40 GiB by default.</div><br> |\- |
|disk uuid |WARNING |Check whether partitions are mounted by volume UUID. |Mount partitions by UUID. |
|password command |WARNING |Check whether the password command exists.<br><br>The passwd and chpasswd commands must be retained. Otherwise, the password cannot be changed. |\- |
|disk use rate |WARNING |Check whether the disk usage is normal.<br><br>The disk usage must not exceed 98%. |Delete unnecessary files. |
|inode use rate |WARNING |Check whether the inode resource usage is normal.<br><br>The inode resource usage cannot exceed 98%. |Delete unnecessary files. |
|reset\-authentication |WARNING |Check whether the password plugin is installed.<br><br>You need to install the password plugin to modify or change the password of the ECS instance created by using the image. |[Install the password plugin.](https://docs.byteplus.com/en/docs/ecs/Installing-the-password-plug-in) |
