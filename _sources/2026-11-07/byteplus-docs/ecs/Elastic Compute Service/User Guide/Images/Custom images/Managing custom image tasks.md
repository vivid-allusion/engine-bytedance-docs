You can use the task management feature provided by the platform to centrally manage and view the progress and details of custom image creation, replication, import, export, and repair tasks in a region.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Executions console](https://console.byteplus.com/image/tasks).

2. In the top menu bar, select the region where the task that you want to manage resides.

3. O​n the Executions page, you can view the status, progress, and name of the task, and the resource ID generated.

   > You can click the resource ID to quickly navigate to the target custom image details page. If the image is deleted, "Image does not exist" is displayed.   
   

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_cefdd0992f70fe844f9a629fe1da65fa.png) </span>

4. You can also search for the target task by task ID or resource ID, and click the target task name to view task details.
