This topic describes the SDK programming language versions provided by ECS and lists the addresses of the latest SDK​s.

<span id=".U0RL5LuL57uN"></span>
## SDK introduction

ECS SDKs encapsulate all ECS APIs ([ECS API overview](https://docs.byteplus.com/en/docs/ecs/Elastic-Compute-Service-API-overview)), and authenticate the identity of the callers via the AccessKey. ECS SDKs offer features such as automatic signature, making it easier to create and manage resources by calling API operations.
