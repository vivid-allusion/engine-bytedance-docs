This topic describes how to search and view the SDK sample code of desired API operations through the BytePlus OpenAPI Center.

<span id=".5q2l6aqk5LiA77ya6I635Y-W5a-55bqUQVBJ55qE5L2_55So6K-05piO"></span>
## Step 1: Obtain API usage description

View the [API overview](https://docs.byteplus.com/en/docs/ecs/Elastic-Compute-Service-API-overview), select the required API operation, and review its documentation to understand the configuration instructions and limitations for the request parameters.

<span id=".5q2l6aqk5LqM77ya6I635Y-WU0RL5Luj56CB56S65L6L"></span>
## Step 2: Obtain SDK sample code


1. Visit the [ECS API Explorer](https://api.byteplus.com/api-explorer/?action=DescribeRegions&data=%7B%7D&groupName=%E5%9C%B0%E5%9F%9F&query=%7B%7D&serviceCode=ecs&version=2020-04-01).

2. In the left API overview, search by the target API name to match the corresponding API.

3. In the middle Debugging section, select the service region, and enter request parameters.

4. On the right, select the "SDK sample code" tab to view the SDK sample code for your programming language. In the example provided in the following figure, the Java programming language is used to call the DescribeRegions operation.
