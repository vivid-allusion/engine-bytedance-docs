---
title: "When encountering an xxxx instance with security control enabled and the current user lacks the [Operation and Maintenance Read-Only] permission, contact the administrator for authorization or apply for the [Operation and Maintenance Read-Only] permission"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/operation_and_maintenance_read-only"
---

This error indicates that the current account does not have permission for instances with security control enabled. You need to apply for permission for the target instance. For detailed steps, refer to [Applying for operation permissions for RDS for MySQL](https://docs.byteplus.com/en/docs/DBW/creating-an-operation-permission-ticket),  [Applying for operation permissions for NDB for MySQL](https://docs.byteplus.com/en/docs/DBW/Creating_an_operation_permission_ticket), [Applying for operation permissions for RDS for PostgreSQL](https://docs.byteplus.com/en/docs/DBW/Create_operation_permission_ticket), and [Applying for operation permissions for RDS for SQL Server](https://docs.byteplus.com/en/docs/DBW/creating-an-operation-permission-ticket_).
