---
title: "How to view the historical commit records of a MySQL instance in the cloud database?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/historical_commit_records"
---

To view records of operations not executed in the DBW data interaction console or work orders, you need to enable database auditing in advance. Database auditing only supports recording operations after it is enabled, and operations before enabling cannot be queried. Additionally, only audit data within the saved duration of the database audit can be viewed.
