---
title: "What database instances does the Data Interaction Platform feature of Database Workshop DBW support?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/what-database-instances-can-i-connect-to-the-data-interaction-platform-of-database-workbench"
---

The Data Interaction Platform feature of Database Workshop DBW currently supports database instances from RDS for MySQL, NDB for MySQL, RDS for SQL Server, RDS for PostgreSQL, Cache for Redis, and Document Database for MongoDB.
