---
title: "Does modifying the approval process of an instance affect the already generated work orders?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/what-should-i-do-if-i-encounter-an-error-when-submitting-a-work-order"
---

Yes, it does. If you modify the approval process of an instance in the instance list, the already generated approvals will still follow the previous approval process, and the changes will only apply to newly generated approval processes.
