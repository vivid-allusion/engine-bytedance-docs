Database Workshop DBW currently only supports databases, as listed below:


* Relational databases

   * RDS for MySQL

   * veDB for MySQL

   * NDB for MySQL

   * RDS for PostgreSQL

   * RDS for SQL Server

* Non\-relational databases

   * Cache for Redis

   * Document Database for MongoDB
