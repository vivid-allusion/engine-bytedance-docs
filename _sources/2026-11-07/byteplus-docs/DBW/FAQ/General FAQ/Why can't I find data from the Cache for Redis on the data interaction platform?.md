---
title: "Why can't I find data from the Cache for Redis on the data interaction platform?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/cache_for_redis_SQL_console"

If you executed the `HGETALL` command, it only works for hash\-type keys. When the key is of string or list type, it returns empty and no data is found.
