---
title: "What should I do if I encounter insufficient permissions when logging into the Data Interaction Platform DBW?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/insufficient_permissions_SQL_console"
---

* **Possible Cause 1**: The IP address of the DBW backend service host has not been added to the instance's whitelist.

   **Solution**: Log in to the corresponding instance and add the IP address of the DBW backend service host to the instance's whitelist. For whitelist IP information, refer to [DBW bound allowlist IPs](https://docs.byteplus.com/en/docs/DBW/allowlist-IP-bound-to-DBW).

* **Possible Cause 2**: Incorrect username or password was entered when logging into the Data Interaction Platform.

   **Solution**: Ensure the accuracy of the entered username and password.
