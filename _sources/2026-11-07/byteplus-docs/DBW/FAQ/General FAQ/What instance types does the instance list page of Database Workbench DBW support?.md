The instance list page of Database Workbench DBW supports the following instance types from BytePlus:


* Relational databases

   * RDS for MySQL

   * veDB for MySQL

   * NDB for MySQL

   * RDS for PostgreSQL

   * RDS for SQL Server

* Non\-relational databases

   * Cache for Redis

   * Document Database for MongoDB
