---
title: "Why can't instances with security control enabled be successfully called via the API interface?"
product: "Database Workshop"
product_code: "DBW"
source: "https://docs.byteplus.com/en/docs/DBW/security_control_enable_via_API"
---

**Possible reason**: Your account may not have been added as a DBW user and lacks permissions for the target instance.

**Solution**: You can apply to become a DBW administrator or regular user, then request permissions for the target instance. For detailed steps, refer to [Role permission application](https://docs.byteplus.com/en/docs/DBW/role-permission-request) and [Instance permission application](https://docs.byteplus.com/en/docs/DBW/role-permission-request).
