This article introduces the IP information of the allowlist associated with the system to the instance by default when logging into the instance through the session management of the database workshop (DBW) or the data interaction platform.


|Database type |**Allowlisted IPs** |
|---|---|
|RDS for MySQL |`100.64.0.0/10`、`11.0.0.0/8`、`172.0.0.0/8` |
|NDB for MySQL |`100.64.0.0/10`、`11.0.0.0/8`、`172.0.0.0/8` |
|RDS for PostgreSQL |`100.64.0.0/10` |
|RDS for MySQL Server |`100.64.0.0/10` |
|Cache for Redis |`100.64.0.0/10` |
|Document Database for MongoDB |`100.64.0.0/10` |
