Call the GenerateSQLFromNL API to generate SQL statements from natural language.

<span id="Yh2xlS9W"></span>
## Request type

Synchronize request.

<span id="aAKWK96o"></span>
## Request parameters


|**Name** |**Type** |**Required?**  |**Sample** |**Description** |
|---|---|---|---|---|
|InstanceID |String |Yes |mysql\-bf120f\*\*\*\*\*\* |Database instance ID<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">You can select the following APIs to query the instance ID as needed:</div><br><br><br><br>* <div data-tips="true" data-tips-type="default">You can call the <a href="https://docs.byteplus.com/en/docs/RDS_for_MySQL/describedbinstances">DescribeDBInstances</a> API to query the instance ID of RDS for MySQL.</div><br><br><br>* <div data-tips="true" data-tips-type="default">Call the <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/DescribeDBInstances">DescribeDBInstances</a> API to query the instance ID of veDB for MySQL.</div><br> |
|InstanceType |String |Yes |MySQL |Database types. The following database types are supported:<br><br><br>* `MySQL`: RDS for MySQL.<br><br>* `VeDBMySQL`: veDB for MySQL.<br><br>* `Postgre`: RDS for PostgreSQL.<br><br>* `Mongo`: Document Database for MongoDB. |
|Database |String |Yes |company |Database name, which specifies the database to query. |
|Query |String |Yes |Query all employee information for employees working in the Beijing workplace |The natural language of the SQL statement to be generated. |
|Tables |List\<String\\> |No |["employee"] |Data table, which specifies the data tables to query.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">When InstanceType is Mongo, you must specify a value for Tables; when InstanceType is not Mongo, it is suggested not to specify a specific value. If no table is specified, the table to be queried is automatically associated.</div><br> |
|IsStream |Bool<br><br> |No |false<br><br> |Specifies whether the server uses SSE streaming to return data.<br><br><br>* false: The server does not use SSE streaming to return data.<br><br>* True: The server uses SSE for streaming return. |


<span id="GOrfkOLB"></span>
## Response parameters


|**Name** |**Type** |**Sample** |**Description** |
|---|---|---|---|
|SQL |String<br><br> |`select * from employee where base_city = 'Beijing';` |The SQL statement generated by LLM based on natural language. |

Authorization: HMAC-SHA256 Credential=AKLTYmYwNjAzYjFmMjRkNDQwZWI4MzI1MzhjZGYyM******/20210328/cn-beijing/dbw/request, SignedHeaders=x-date, Signature=e1d274292f8b36eb096e1d2fec02822bd2e5cb3435699938adb7341861******
