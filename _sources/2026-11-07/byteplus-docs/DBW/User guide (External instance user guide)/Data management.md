This topic describes how to manage data on the Database Workshop (DBW) console.

<span id="VZXx9Cyl"></span>
## Prerequisites

The database instance from other cloud or self\-built has been connected to DBW. For more information, see [External instance management](https://docs.byteplus.com/en/docs/DBW/self-managed-database-administration?lang=en).

<span id="5tHCig3B"></span>
## Data management


<Tabs>
<Tab zoneid="ZlgLGSEOWQ" title="SQL window">
<TabTitle>SQL window</TabTitle>

1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the project and region.

3. Select one of the following methods to log in to the **SQL Window** as needed:

   * Method 1: On the left navigation bar, select **Data management** \> **SQL window**.

   * Method 2;

      1. On the **Instance list** page, locate the target instance.

      2. In the **Actions** column of the target instance, click **Login**.

4. In the **Database Workshop** dialog box, click **Log in**.

5. On the data interaction platform page of the target instance, you can perform the following operations:

   * MySQL: [Command operations](https://docs.byteplus.com/en/docs/DBW/executing-commands-for-mysql?lang=en), [Database management](https://docs.byteplus.com/en/docs/DBW/database-management-for-mysql1-for-mysql?lang=en), [Table management](https://docs.byteplus.com/en/docs/DBW/table-management-for-mysql?lang=en), [View management](https://docs.byteplus.com/en/docs/DBW/view-management-for-mysql?lang=en), [Trigger management](https://docs.byteplus.com/en/docs/DBW/trigger-management-for-mysql?lang=en), [Stored procedure management](https://docs.byteplus.com/en/docs/DBW/stored-procedure-management-for-mysql?lang=en), [Function management](https://docs.byteplus.com/en/docs/DBW/function-management-for-mysql?lang=en), and [Event management](https://docs.byteplus.com/en/docs/DBW/event-management-for-mysql?lang=en).

   * PostgreSQL: [Command operations](https://docs.byteplus.com/en/docs/DBW/command-operation-for-PG?lang=en), [Database management](https://docs.byteplus.com/en/docs/DBW/database-management-for-PG?lang=en), [Mode management](https://docs.byteplus.com/en/docs/DBW/schema-management-for-PG?lang=en), [Table management](https://docs.byteplus.com/en/docs/DBW/table-management-for-PG?lang=en).


</Tab>
