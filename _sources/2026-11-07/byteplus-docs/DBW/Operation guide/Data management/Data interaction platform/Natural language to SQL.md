The Database Workshop (DBW) data interaction platform supports the natural language to SQL function, which helps you generate standard SQL from natural language and lowers the barrier to SQL writing and learning. This article takes cloud database RDS for MySQL as an example to introduce how to enable and use the natural language to SQL function in the data interaction platform of Database Workshop DBW.

<span id=".5Yqf6IO95LyY5Yq_"></span>
## Feature advantages

Using the natural language to database query statement conversion function has the following advantages:


* **Reduce learning costs**: Learning a database query language requires time and effort. For users without a technical background, learning database query statements may take more time and effort. With natural language query, you can directly use a language you are already familiar with to query the database, thereby reducing learning costs.

* **Improve efficiency**: You can directly express your needs in natural language without spending time writing complex query statements, thereby improving work efficiency.

* **Improve availability**: For some specific applications, such as voice assistants or mobile applications, natural language query can provide a better user experience.

* **Popularize the use of database statements**: The natural language query function not only allows database experts or IT staff to use the database, but also allows people who do not understand the database to use the database.


<span id=".5L2_55So6ZmQ5Yi2"></span>
## Limitations


* Currently, only the data interaction platforms of RDS for MySQL, NDB for MySQL, RDS for PostgreSQL, and Document Database for MongoDB support the DB AI assistant.

* In the data interaction platform of Document Database for MongoDB, the SQL assistant currently only supports natural language to SQL, and does not support using the Text\-to\-SQL function in the command execution area.

* The following SQL statements are currently supported only:

   * DML statements: `SELECT`, `INSERT`, `UPDATE`, `DELETE`.

   * DDL statements: `CREATE`, `ALTER`, `DROP`, `TRUNCATE`.


<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* A small number of natural language conversion results may be inaccurate, and high concurrency may cause performance issues.

* When using the natural language to SQL feature, to improve answer accuracy, it is recommended to refine the naming and comments of tables and columns.

* When using the natural language to SQL feature, you need to confirm the relevant disclaimers and follow the relevant usage rules. For details, see [Natural Language to SQL Disclaimer and Service Usage Rules](https://docs.byteplus.com/en/docs/DBW/disclaimer-and-service-terms-of-natural-language-to-SQL-conversion).

* The conversion results of a small amount of natural language may be inaccurate. The SQL content is generated by AI model and is for reference only. High concurrency may cause performance problems.

* If security control is enabled for instance, you need to ensure that the current account has read and write permissions for the database table. To learn how to view the permissions of the current account, see [View my permission](https://docs.byteplus.com/en/docs/DBW/Viewing_my_permissions).

## Prerequisites


* An instance has been created and is in the Running state. For detailed steps, see [Creating an instance](https://docs.byteplus.com/en/docs/RDS_for_MySQL/creating_an_instance_1).

* A database account with read\-only or read\-write permissions for the target database has been created. For detailed operations, see [Create database account](https://docs.byteplus.com/en/docs/RDS_for_MySQL/creating_and_managing_an_account).

## Procedure


1. Log on to the [data interaction platform for RDS for MySQL](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-rds-for-mysql).

2. On the **Data interaction platform** page, click **DB AI assistant** in the top right corner.

3. In the **DB AI assistant** dialog box, enable the **DB AI assistant** feature.

   1. Read and select the relevant Agreement.

   2. Click **Get started**.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">After the first activation, you will not need to activate it again.      </div>
      

1. In the **DB AI assistant** dialog box, select the target database from the **Select database** drop\-down list.

2. Enter natural language in the input box, then press the Enter key.

3. After the SQL is generated, you can copy the converted SQL statement to the command execution area for execution or click **Execute now** to execute the SQL statement directly.
