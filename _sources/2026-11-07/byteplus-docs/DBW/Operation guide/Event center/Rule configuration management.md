Alarm rules detect database anomalies in real time using preset thresholds. They support flexible configuration by business module, alarm level, and notification object, and automatically push notifications by severity level. This helps you quickly detect and resolve issues before they affect your business, ensuring stable system operation. This topic describes how to configure alarm rules in Database Workshop DBW.

<span id="EApnl2xe"></span>
## Prerequisite


* A notification policy has been created. For detailed operations, see [Notification policy management](https://docs.byteplus.com/en/docs/DBW/Notification_policy_management).

* Cloud monitor contacts have been configured for the user roles of Database Workshop DBW. For detailed operations, see [Personal user management](https://docs.byteplus.com/en/docs/DBW/Personal_user_management?lang=en).

## Procedure


<Tabs>
<Tab zoneid="KwDOdBM4Yi" title="Creating event rules">
<TabTitle>Creating event rules</TabTitle>

1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the region.

3. In the left\-side navigation pane, select **Event center** \> **Rule configuration**.

4. On the **Rule Configuration** page, click **Create Rule**.

5. In the Create Event Rule dialog box, configure the following parameters.

   
   |**Parameter** |**Description** |
   |---|---|
   |**Rule name** |The rule name is generated by default based on the database type, business module, and business status. You can also customize it, but the length must not exceed 128 characters. |
   |**Database type** |From the drop\-down list, select the target database type. |
   |**Associated instance** |You can currently select **All instances** or **Specify instance** as the associated instances.<br><br>When you select All instances, the rule applies to all instances under the selected database type. When you select Specify instance, you need to select the target instances from the drop\-down list. |
   |**Business module** |From the drop\-down list, select the business module where the rule takes effect. Currently, **Operation and maintenance management** and **Ticket tasks** are supported. The two business modules cannot be selected at the same time, but multiple functions within each business module can be selected. |
   |**Business status** |From the drop\-down list, select the business status for which the rule takes effect. You can select **All business statuses**, **Inspection non\-standard items**, **Auto scaling started**, **Auto scaling ended**, **Auto scaling failed**, or **Rate limiting task triggered**. |
   |**Alarm level** |Select the alarm level for the rule as needed. Options include **Normal**, **Warning**, and **Serious**. |
   |**Notification policy** |From the drop\-down list, select a notification policy. For more information, see [Notification policy management](https://docs.byteplus.com/en/docs/DBW/Notification_policy_management). |
   

6. Click **OK**.


</Tab>
<Tab zoneid="cGDktEIJnE" title="Viewing event rules">
<TabTitle>Viewing event rules</TabTitle>

1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the region.

3. In the left\-side navigation pane, select **Event center** \> **Rule configuration**.

4. On the **Rule configuration** page, view the event rule list and the details of the target event rule.

   * View the event rule list: On the **Rule configuration** page, view all event rules you created, including **Rule name**, **Event scope**, **Notification policy**, **Notification level**, **State**, and **Update time**.</a\>

   * View details of a target event rule: In the **Actions** column of the target rule, click **Details**. On the **Event rules details** page, view the specific information of the event rule, as follows:

      * **Basic information**: Includes **Rule name**, **Rule ID**, **Notification level**, **Notification policy**, **State**, **Creation time**, **Last operation time**, and **Description**.

      * **Event scope**: Includes **Database engine**, **Event scope**, and **Business status**.

      * **Applied to**: Includes **Associated instance**.


</Tab>
<Tab zoneid="D99wDnILRx" title="Deactivating event rules">
<TabTitle>Deactivating event rules</TabTitle>

1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the region.

3. In the left\-side navigation pane, select **Event center** \> **Rule configuration**.

4. On the **Rule configuration** page, click **Deactivate** in the **Actions** column of the target event rule to deactivate the event rule.


</Tab>
<Tab zoneid="AvuMowRgOB" title="Enabling event rules">
<TabTitle>Enabling event rules</TabTitle>

1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the region.

3. In the left\-side navigation pane, select **Event center** \> **Rule configuration**.

4. On the **Rule Configuration** page, click **Enable** in the **Actions** column of the target event rule to enable the event rule.


</Tab>
