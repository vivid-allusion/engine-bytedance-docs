The Database Workshop (DBW) supports automated operation and maintenance (O&M) management. This feature not only helps you achieve automated O&M and management of databases, but also enhances the efficiency of database system O&M, strengthening the reliability and maintainability of the database system.

<span id=".5LyY5Yq_"></span>
## Advantages


* **Improved efficiency**: reduce repetitive manual operations, minimize human errors, and enhance operational efficiency.

* **Ensured consistency**: ensure standardization and consistency in all operations, avoiding issues caused by task oversight.

* **Enhanced reliability**: promptly identify and address issues through automated monitoring and alert systems, improving system reliability.

* **Cost reduction**: decrease the size of the required operations team, controlling operational costs.

* **Strengthened emergency responses**: develop and test emergency procedures in advance to ensure a swift response in critical situations.


<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* Before automated O&M, you need to ensure that the account has a sufficient balance to support changes in instance configurations.

* During configuration changes, the database instance may experience brief connection interruptions.


<span id=".5pSv5oyB55qE5pWw5o2u5bqT57G75Z6L"></span>
## Supported database types


* RDS for MySQL

* NDB for MySQL

* Cache for Redis
