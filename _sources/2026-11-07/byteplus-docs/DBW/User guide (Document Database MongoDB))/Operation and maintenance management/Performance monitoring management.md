The Database Workshop (DBW) supports the performance monitoring feature, which can provide a wide range of performance metrics. With these metrics, you can view the performance trends of your database instances and identify possible risks in your database instances in a timely manner. This topic describes performance monitoring metrics and procedures to view performance monitoring, helping you understand the operation of database instances.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

DBW has been granted permissions to access other cloud service resources. For more information, refer to [Primary account permission management](https://docs.byteplus.com/en/docs/DBW/managing-permissions-of-a-main-account).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

While using the performance monitoring feature, avoid modifying instance configurations, as this may prevent the normal display of performance monitoring.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [DBW console](https://console.byteplus.com/dbw).

2. On the top menu bar, select the project and region.

3. On the left navigation bar, select **Operation and maintenance management** \> **Observation and diagnosis**.

4. On the Observation and diagnosis page, switch the instance type and ID.

   1. In the upper right corner of the Observation and diagnosis page, switch the instance type to Document Database for MongoDB.

   2. In the upper left corner of the Observation and diagnosis page, switch the target instance based on the instance ID or instance name.

5. On the Observation and diagnosis page, click Performance monitoring to view the instance's monitoring information.

   For details about monitoring metrics, refer to [Monitoring metrics](https://docs.byteplus.com/en/docs/mongodb/monitoring-metric).
