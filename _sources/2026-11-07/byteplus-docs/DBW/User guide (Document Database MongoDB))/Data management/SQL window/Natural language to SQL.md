The Database Workshop (DBW) data interaction platform supports the natural language to SQL function, which helps you generate standard SQL from natural language and lowers the barrier to SQL writing and learning. This article describes how to enable and use the natural language to SQL function in the Database Workshop (DBW) data interaction platform.

<span id="I0K8rRCM"></span>
## Feature advantages

Using the natural language to database query statement conversion function has the following advantages:


* **Reduce learning costs**: Learning a database query language requires time and effort. For users without a technical background, learning database query statements may take more time and effort. With natural language query, you can directly use a language you are already familiar with to query the database, thereby reducing learning costs.

* **Improve efficiency**: You can directly express your needs in natural language without spending time writing complex query statements, thereby improving work efficiency.

* **Improve availability**: For some specific applications, such as voice assistants or mobile applications, natural language query can provide a better user experience.

* **Popularize the use of database statements**: The natural language query function not only allows database experts or IT staff to use the database, but also allows people who do not understand the database to use the database.


<span id="cHSdlcVe"></span>
## Limitations

Currently, the natural language to SQL feature is not supported in the command execution area of Document Database for MongoDB.

<span id="ur1594Yh"></span>
## Precautions


* When using the natural language to SQL feature, you need to confirm the relevant disclaimers and follow the relevant usage rules. For details, see [Natural Language to SQL Disclaimer and Service Usage Rules](https://docs.byteplus.com/en/docs/DBW/disclaimer-and-service-terms-of-natural-language-to-SQL-conversion).

* The conversion results of a small amount of natural language may be inaccurate. The SQL content is generated by AI model and is for reference only. High concurrency may cause performance problems.

* If security control is enabled for instance, you need to ensure that the current account has read and write permissions for the database table. To learn how to view the permissions of the current account, see [View my permission](https://docs.byteplus.com/en/docs/DBW/Viewing_my_permissions).


<span id="34yYM2wk"></span>
## Prerequisites


* A MongoDB instance is created and is in the running state. For detailed steps, refer to [Creating an instance](https://docs.byteplus.com/en/docs/mongodb/creating_an_instance).

* A database account with read\-only or read\-write permissions for the target database has been created. For detailed steps, refer to [Creating an account](https://docs.byteplus.com/en/docs/mongodb/create-account).


<span id="MIsOxCxX"></span>
## Procedure


1. [Log on to the data interaction console of Document Database for MongoDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-documentdb-for-mongodb).

2. In the upper\-right corner of the **Data interaction platform** page, click **SQL assistant**.

3. In **DBCopilot** **SQL assistant** dialog box, enable the DBCopilot **SQL assistant** function.

   1. Read and select the relevant Agreement.

   2. Click **Get started**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After the first activation, you will not need to activate it again.   </div>
   

4. In **DBCopilot** In the **SQL assistant** dialog box, **Select database and select collection** from the drop\-down lists to select the target database and target collection.

5. Enter natural language in the input box. For example, write a query data statement, and then press enter.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_50c31ac7eabce41a9baaa867ae9faa25.png) </span>

6. After the SQL is generated, you can copy the converted SQL statement to the command execution area for execution or click **Execute now** to execute the SQL statement directly.
