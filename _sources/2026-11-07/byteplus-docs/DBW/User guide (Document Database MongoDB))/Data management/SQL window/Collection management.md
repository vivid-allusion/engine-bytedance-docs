This topic describes how to visually create, delete, and edit collections in the command execution window of the Database Workshop (DBW) console to achieve full lifecycle management of collections.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* A BytePlus account has been registered and completed verification. For the detailed method, refer to [Sign up and verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* As per the regulations in the Chinese mainland, you must have completed real name registration before you can activate and use cloud services on regions in the Chinese mainland through BytePlus. For more details, refer to [Real name registration](https://docs.byteplus.com/en/docs/byteplus-platform/docs-real-name-registration)..

* An instance for Document Database for MongoDB has been created and its `root` account password has been set. For detailed steps, refer to [Creating an instance](https://docs.byteplus.com/en/docs/mongodb/creating_an_instance).


<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

The creation, deletion, and other operations you perform may affect the online business operation. It is recommended to perform them during off\-peak hours.


|**Actions** |**Precautions** |
|---|---|
|Create a collection |Creating collections on system databases is not recommended. |
|Query a collection |Commands such as the `use`, `set`, `it`, and `show` series cannot be executed together with other commands. To execute, run them individually. |
|Rename a collection |After renaming the collection, you will not be able to access it using the original collection name. Proceed with caution. |
|Delete a collection |* Collections cannot be recovered once deleted. And deleting collections may degrade database performance because the database needs to process more files. Exercise caution when performing this operation.<br><br>* After all collections in a database are deleted, the database is also deleted by default. |

## Create a collection


1. Log on to the [data interaction platform for Document Database for MongoDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-documentdb-for-mongodb).

2. On the top menu bar of the **Data interaction platform** page, click the<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8fc8cdb512061347c970a02fd4daf5aa.jpeg) </span> icon next to the database and select the target database.

3. In the visual area of the **Data interaction platform**, right\-click the target collection and select **Create collection**.

4. In the **Create collection** dialog box, customize the **Collection name**.

5. Click **OK**.

6. In the **Execute**  **SQL** dialog box, confirm the SQL command to create a collection.

7. Click **Execute**.


After the collection is created, you can view the collection in the visual area on the left. In the meantime, an `_id_` index is generated by default within this collection.

<span id=".5p-l6K-i6ZuG5ZCI"></span>
## Query a collection


1. Log on to the [data interaction platform for Document Database for MongoDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-documentdb-for-mongodb).

2. On the top menu bar of the **Data interaction platform** page, click the<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8fc8cdb512061347c970a02fd4daf5aa.jpeg) </span> icon next to the database and select the target database.

3. In the visual area of the **Data interaction platform**, right\-click the target collection and select **Query collection**.

4. On the **Session** tab, click **Execute (F8)**  or press **F8**.


In the **Execution result** area, you can view the detailed information of the collection.

<span id=".6YeN5ZG95ZCN6ZuG5ZCI"></span>
## Rename a collection


1. Log on to the [data interaction platform for Document Database for MongoDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-documentdb-for-mongodb).

2. On the top menu bar of the **Data interaction platform** page, click the<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8fc8cdb512061347c970a02fd4daf5aa.jpeg) </span> icon next to the database and select the target database.

3. In the visualization area of the **Data interaction platform**, right\-click the target collection and select **Rename**.

4. In the **Rename collection** dialog box, locate the **New collection name** input box and set a new name for the collection.

5. Click **OK**.

6. In the **Execute**  **SQL** dialog box, confirm the SQL statement for renaming the collection.

7. Click **Execute**.

## Delete a collection

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Collections cannot be recovered once deleted. And deleting collections may degrade database performance because the database needs to process more files. Exercise caution when performing this operation.</div>



1. Log on to the [data interaction platform for Document Database for MongoDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-for-documentdb-for-mongodb).

2. On the top menu bar of the **Data interaction platform** page, click the<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8fc8cdb512061347c970a02fd4daf5aa.jpeg) </span> icon next to the database and select the target database.

3. In the visual area of the **Data interaction platform**, right\-click the target collection and select **Delete collection**.

4. In the **Delete collection** dialog box, enter the name of the collection to be deleted in the **Confirm to delete** input box.

5. Click **OK**.

6. In the **Execute**  **SQL** dialog box, confirm the SQL statement for deleting the collection.

7. Click **Execute**.
