This topic explains how to delete import/export tasks on the Database Workshop (DBW) console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

An import or export task has already been created. For detailed steps, refer to [Creating a data import task](https://docs.byteplus.com/en/docs/DBW/Creating_a_data_import_task) and [Creating a data export task](https://docs.byteplus.com/en/docs/DBW/Creating_a_full_database_export_task).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

Deleted tasks cannot be recovered, so proceed with caution.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [NDB](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-vedb-for-mysql)[ for MySQL data interaction platform](https://docs.byteplus.com/en/docs/DBW/logging-on-to-the-data-interaction-platform-vedb-for-mysql).

2. In the upper\-right corner of the **Data interaction platform** page, click **Import/Export**.

3. On the **Import/Export** tab, click **Delete** under the **Actions** column for the target task.

4. In the **Delete confirmation** dialog box, click **Confirm**.
