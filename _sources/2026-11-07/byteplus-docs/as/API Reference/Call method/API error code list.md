This topic describes how to query the information of all error codes involved when you call Auto Scaling APIs.

<span id="dfHMJERa"></span>
## Error code type

The platform supports the following two error code types.

<span id="NjjvaHvE"></span>
### Common error codes of the platform

CodeN starts with `1000`. Please refer to [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes) for details.

<span id="4CA105iQ"></span>
### Product error codes

Error codes relating to business logic of the cloud product. Such error codes include public error codes of cloud products and API\-specific error codes. Http Code is `4xx` or `5xx`. You can visit [OpenAPI Center](https://api.volcengine.com/api-docs/view/errorcode?serviceCode=auto_scaling&version=2020-01-01) for details.

On the right of "Error code", click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_65183e460835e9b275060a725a2d4df0.png) </span> button to query information.
