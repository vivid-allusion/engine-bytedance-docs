## Scenarios

You can delete tasks that have been completed or cancelled by following the steps below.

<span id=".5pON5L2c6K-05piO"></span>
## Operation instruction

This feature is supported only when the status of the target task is "Cancelled", "Success", or "Fail".

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the region of your target resource.

3. Click the "Delete" button on the right side of the task to be deleted in the task list.

4. Click the "Confirm" button to complete the operation.
