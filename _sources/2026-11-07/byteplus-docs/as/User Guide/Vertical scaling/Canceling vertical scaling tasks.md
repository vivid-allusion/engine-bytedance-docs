## Scenarios

For scheduled and periodic tasks, you can cancel the task at any time if you no longer need to modify the instance type. After cancellation, the task will no longer run.

<span id=".5pON5L2c6K-05piO"></span>
## Operation instruction

You can cancel a vertical scaling task only when the task is in the "Waiting" status.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the region of your target resource.

3. In the task list, click "Cancel" on the right side of the task to be cancelled that is in the "Waiting" status.

4. Click the "Confirm" button to complete the operation. At this point, the task status changes to "Cancelled".
