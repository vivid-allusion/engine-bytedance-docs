## Scenarios

You can perform this operation to modify the configuration of a lifecycle hook (the hook name cannot be changed). The new configuration takes effect immediately after modification. Then, it only takes effect on the next triggered scaling adjustment.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the project and region of the target resource.

3. Click the name of the scaling group and select the "Lifecycle hook" tab.

4. Click the "Edit" button on the right side of the target lifecycle hook in the lifecycle hook list.

5. For detailed instructions, refer to [Creating lifecycle hooks](https://docs.byteplus.com/en/docs/as/Creating-a-lifecycle-hook).

6. Click the "Confirm" button to complete the operation.
