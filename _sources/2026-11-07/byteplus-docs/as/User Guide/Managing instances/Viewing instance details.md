## Scenario

You can perform this operation to view all instances in a scaling group, including the name/ID, status, availability zone, image/instance type, and IP address of each instance.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the project and region of the target resource.

3. Click the name of the scaling group and select the "Instance Management" tab to view basic information of the instances.

4. Click the name of an instance to go to the [ECS console](https://console.byteplus.com/ecs/instance). You can view details of the instance in the ECS console, such as the monitoring data of associated network interfaces, volumes, and basic metrics.
