## Scenarios

You can perform this operation to enable an inactive scaling rule.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can enable multiple scaling rules for one scaling group. When multiple scaling rules are triggered simultaneously, they take effect in a competitive manner. Only the adjustment specified in the first triggered rule is executed. For a scaling group in the <strong>Cooling </strong>status, adjustments are not allowed.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the project and region of the target resource.

3. Click the name of the scaling group and select the "Scaling Rules" tab.

4. Click the "Enable" button on the right side of the scaling rule that you want to enable.

5. Click "Confirm" to complete the operation.
