## Scenarios

You can perform this operation to delete a scaling rule. Deletion is irreversible. If you need to use the scaling rule later, we recommend that you [disable the scaling rule](https://docs.byteplus.com/en/docs/as/Disabling-a-scaling-policy).

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Scaling Group console](https://console.byteplus.com/as/group). 

2. In the top menu bar, select the project and region of the target resource.

3. Click the name of the scaling group and select the "Scaling Rules" tab.

4. Click the "Delete" button on the right side of the scaling rule that you want to delete.

5. Click "Delete" to complete the procedure.
