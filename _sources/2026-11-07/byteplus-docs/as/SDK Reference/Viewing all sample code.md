This topic describes how to search and view the SDK sample code of desired API operations through the BytePlus OpenAPI center.

<span id=".5q2l6aqk5LiA77ya6I635Y-W5a-55bqUQVBJ55qE5L2_55So6K-05piO"></span>
## Step 1: Obtain API usage description

View the [API overview](https://docs.byteplus.com/en/docs/as/API-overview), select the required API operation, and review its documentation to understand the configuration instructions and limitations for the request parameters.

<span id=".5q2l6aqk5LqM77ya6I635Y-WU0RL5Luj56CB56S65L6L"></span>
## Step 2: Obtain SDK example code


1. Go to the [Auto Scaling API Explorer](https://api.byteplus.com/api-explorer?auto_scaling&version=2020-01-01).

2. In the left API overview, search by the target API name to match the corresponding API.

3. In the middle Debugging section, select the service Region, and enter request parameters.

4. On the right, select the "SDK sample code" tab to view the SDK sample code for your programming language. In the example provided in the following figure, the Java programming language is used.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_2346b05a7dc8af24b2ab38dfbc151b04.png) </span>


<span id=".5q2l6aqk5LiJ77ya6YWN572u5Luj56CB"></span>
### Step 3: Configure the code

In the following figure, the EnableScalingGroup operation is used as an example to demonstrate how to read and use the sample code.

You only need to replace the content in the red box. That is, replace `Your AK` and `Your SK` with the actual AccessKey ID and AccessKey secret, respectively.
