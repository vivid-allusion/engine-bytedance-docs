This topic describes the SDK programming language versions provided by Auto Scaling (AS) and lists the addresses of the latest SDK​s.

<span id=".U0RL5LuL57uN"></span>
## SDK introduction

The Auto Scaling SDK encapsulates all API operations of Auto Scaling ([AS API overview](https://docs.byteplus.com/en/docs/as/API-overview)). It identifies the caller based on the AccessKey pair and provides features like automatic signature, enabling you to create and manage resources easily by using the API operations.
