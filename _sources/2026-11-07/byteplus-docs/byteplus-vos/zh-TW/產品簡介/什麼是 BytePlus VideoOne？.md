## 媒體 SDK

VideoOne 提供多種媒體 SDK 供您選擇與組合，輕鬆為應用新增直播、影片播放、視訊通話、美顏特效等功能。

**MediaLive 推流 SDK**

支援從客戶端裝置進行推流。互動版支援多人連麥。

**特效 SDK**

為您的應用增強貼紙特效與濾鏡功能。

**RTC SDK**

提供高畫質音影片通訊能力。

**MediaLive 播放器 SDK 與 VOD 播放器 SDK**

支援播放直播流或點播內容。MediaLive 播放器 SDK 的互動版支援多人連麥。

## 影片雲服務

全球分發您的內容，實現超低延遲，並根據業務需求進行處理。VideoOne 提供以下雲服務：

**BytePlus MediaLive**


* 超低延遲流媒體，也稱為實時媒體（RTM）

* 增值服務，如低位元速率高畫質轉碼、錄製、截圖、時移

* 資料分析


**BytePlus RTC**


* 大規模音影片通訊

* 穩定可靠的實時信令服務，低延遲、高併發

* 先進音訊處理能力，涵蓋聲學回聲消除（AEC）、自動增益控制（AGC）、自動降噪（ANC）


**BytePlus VOD**


* 媒體上傳、儲存與播放

* 媒體服務，包括低位元速率高畫質轉碼、水印、影片質量增強

* 質量洞察
