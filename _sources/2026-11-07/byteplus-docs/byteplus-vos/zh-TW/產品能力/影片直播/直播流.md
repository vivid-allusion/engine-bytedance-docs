為實現直播推流與拉流，本指南介紹如何結合 VideoOne 與 BytePlus MediaLive Broadcast SDK 及 Player SDK。本指南提供整體概覽，並連結至詳細的實現指南與程式碼示例，幫助您快速搭建直播推流與觀看功能。

<span id="a53bbaf7"></span>
# MediaLive 整合指南

<span id="99037d3e"></span>
## 生成直播流地址

要實現完整的直播流程，您需要推流 URL 將實時影片和音訊資料傳送至伺服器，以及拉流 URL 用於獲取並播放直播流。請參閱[生成直播流地址](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generating-live-stream-addresses)以生成推流和拉流 URL。

<span id="0fc04b5e"></span>
## 功能實現

<span id="807a6c98"></span>
### 直播推流

VideoOne 演示如何使用 BytePlus MediaLive Broadcast SDK，將採集、編碼和封裝後的直播流推送至 MediaLive 服務。目前支援四種推流方式：攝像頭採集、純音訊直播、螢幕共享，以及本地或線上媒體檔案推流。有關這些功能的詳細實現，請參閱以下文件：


|平臺 |Android |iOS |
|---|---|---|
|Broadcast SDK 參考文件 |* [基礎功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features)<br><br>* [高階功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features) |* [基礎功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-1)<br><br>* [高階功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-1) |


<span id="3bb31ef3"></span>
### 直播拉流

VideoOne 演示如何使用 BytePlus MediaLive Player SDK，從伺服器獲取實時音影片資料並進行播放。目前支援透過多種流媒體協議（如 FLV、HLS、RTMP）進行直播拉流與播放。有關這些功能的詳細實現，請參閱以下文件：


|平臺 |Android |iOS |
|---|---|---|
|Player SDK 參考文件 |* [基礎功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-2)<br><br>* [高階功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-2) |* [基礎功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-3)<br><br>* [高階功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-3) |
