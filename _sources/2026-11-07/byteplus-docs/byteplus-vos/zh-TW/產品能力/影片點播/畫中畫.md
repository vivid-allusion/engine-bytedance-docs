為了讓使用者能夠在使用其他應用的同時，透過浮動視窗觀看影片實現多工處理，您可以實現畫中畫（PiP）功能。本指南為您提供在 Android 和 iOS 平臺的影片播放器中新增 PiP 支援的詳細分步說明及程式碼示例。

您可以透過[試用 Demo 應用](https://docs.byteplus.com/docs/byteplus-vos/docs-byteplus-videoone-demo-app-1-zh-TW)下載 Demo 程式，並進入 `功能` \> `影片播放器`，播放任意影片。點選播放頁面後，點選畫中畫圖示以開啟該功能。影片播放時，點選 Home 按鈕返回主螢幕。將出現如下畫中畫效果：

# 畫中畫應用支援

<span id="7edabed5"></span>
## Android

<span id="447e0b70"></span>
### 系統要求


* 執行 Android 8.0（API 等級 26）或更高版本的實體移動裝置。


<span id="2e64f88d"></span>
### 實現


1. **宣告畫中畫支援**


在 `AndroidManifest.xml` 中，將影片活動的 `android:supportsPictureInPicture` 宣告為 `true`。

```XML
<activity android:name=".SampleVideoActivity"
    android:supportsPictureInPicture="true"
    android:configChanges=
        "screenSize|smallestScreenSize|screenLayout|orientation"
    ...
```



2. **新增播放控制**


畫中畫視窗中的播放控制可按如下方式自定義。詳情請參見[MiniPlayerLayer.java](https://github.com/byteplus-sdk/VideoOneSolutions/blob/main/Client/Android/solutions/vod/vod-scenekit/src/main/java/com/byteplus/vod/scenekit/ui/video/layer/MiniPlayerLayer.java)：

```Java
void updatePictureInPictureActions(
        @DrawableRes int iconId, String title, int controlType, int requestCode
) {
    final ArrayList<RemoteAction> actions = new ArrayList<>();

    final PendingIntent intent =
            PendingIntent.getBroadcast(
                    getContext(),
                    requestCode,
                    new Intent(ACTION_PLAYER_CONTROL).putExtra(EXTRA_CONTROL_TYPE, controlType),
                    0);
    final Icon icon = Icon.createWithResource(getContext(), iconId);
    actions.add(new RemoteAction(icon, title, title, intent));
    
    // ... Add other actions.
   // Call the getMaxNumPictureInPictureActions() method to get the maximum number of actions.

    mPictureInPictureParamsBuilder.setActions(actions);

    setPictureInPictureParams(mPictureInPictureParamsBuilder.build());
}
```



3. **切換影片活動至畫中畫**


呼叫[Activity.enterPictureInPictureMode()](https://developer.android.com/reference/android/app/Activity#enterPictureInPictureMode())以切換至畫中畫模式。詳情請參見[BaseActivity.java](https://github.com/byteplus-sdk/VideoOneSolutions/blob/main/Client/Android/solutions/vod/vod-scenekit/src/main/java/com/byteplus/vod/scenekit/ui/base/BaseActivity.java)：

```Java
@Override
public void onUserLeaveHint () {
    Rational aspectRatio = new Rational(mVideoView.getWidth(), mVideoView.getHeight());
    mPictureInPictureParamsBuilder.setAspectRatio(aspectRatio).build();
    enterPictureInPictureMode(mPictureInPictureParamsBuilder.build());
}
```



4. **監控畫中畫模式變更事件**


當活動進入或退出**畫中畫**模式時，Android 系統會呼叫[Activity.onPictureInPictureModeChanged(boolean, android.content.res.Configuration)](https://developer.android.com/reference/android/app/Activity#onPictureInPictureModeChanged(boolean,%20android.content.res.Configuration))或[Fragment.onPictureInPictureModeChanged(boolean, android.content.res.Configuration)](https://developer.android.com/reference/android/app/Fragment#onPictureInPictureModeChanged(boolean,%20android.content.res.Configuration))。詳情請參見[MiniPlayerLayer.java](https://github.com/byteplus-sdk/VideoOneSolutions/blob/main/Client/Android/solutions/vod/vod-scenekit/src/main/java/com/byteplus/vod/scenekit/ui/video/layer/MiniPlayerLayer.java)：

```Java
@Override
public void onPictureInPictureModeChanged(
        boolean isInPictureInPictureMode, Configuration configuration) {
    super.onPictureInPictureModeChanged(isInPictureInPictureMode, configuration);
    if (isInPictureInPictureMode) {
        // Starts receiving events from action items in Picture-in-Picture mode.
        mReceiver =
                new BroadcastReceiver() {
                    @Override
                    public void onReceive(Context context, Intent intent) {
                        if (intent == null
                                || !ACTION_MEDIA_CONTROL.equals(intent.getAction())) {
                            return;
                        }

                        // This is where we are called back from Picture-in-Picture action items.
                        final int controlType = intent.getIntExtra(EXTRA_CONTROL_TYPE, 0);
                        switch (controlType) {
                            case CONTROL_TYPE_PLAY:
                                mVideoView.play();
                                break;
                            case CONTROL_TYPE_PAUSE:
                                mVideoView.pause();
                                break;
                        }
                    }
                };
        registerReceiver(mReceiver, new IntentFilter(ACTION_MEDIA_CONTROL));
    } else {
        // We are out of PiP mode. We can stop receiving events from it.
        unregisterReceiver(mReceiver);
        mReceiver = null;
    }
}
```

## iOS

<span id="912ce25e"></span>
### 系統要求


* 執行 iOS 14 或更高版本的實體移動裝置。


<span id="2a8a818a"></span>
### 實現


1. 啟用畫中畫後臺模式。


在您的 Xcode 專案中，導航至 `Signing & Capabilities` 標籤，新增 `Background Modes` 能力，並啟用 `音訊、AirPlay 和畫中畫`，如下所示：

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cedebb4f61df4451a8d4af17e7af91a4~tplv-goo7wpa0wc-image.image" width="1872px" /></div>



2. 配置並建立 AVPlayer，然後初始化 AVPictureInPictureController。詳情請參見[PIPManager.m](https://github.com/byteplus-sdk/VideoOneSolutions/blob/main/Client/iOS/Component/ToolKit/VodPlayer/VEPlayerUIModule/Classes/PIPManager/PIPManager.m)：


```objectivec
// Setting AVAudioSession
@try {
    NSError *error = nil;
    [[AVAudioSession sharedInstance] setCategory:AVAudioSessionCategoryPlayback error:nil];
    [[AVAudioSession sharedInstance] setActive:YES error:&error];
  } @catch (NSException *exception) {
   // Handle errors that occur when setting the AVAudioSession.
  }
  
 // Create AVPlayer
AVAsset *asset = [[AVURLAsset alloc] initWithURL:[NSURL URLWithString:self.currentAVPlayerURL] options:@{AVURLAssetPreferPreciseDurationAndTimingKey: @YES}];
AVPlayerItem *playItem = [AVPlayerItem playerItemWithAsset:asset];
self.avPlayer = [AVPlayer playerWithPlayerItem:playItem];

// Initialize AVPictureInPictureController
AVPlayerLayer *layer = [AVPlayerLayer playerLayerWithPlayer:self.avPlayer];
UIView *playContainerView = [self.dataSource containerView];
layer.frame = playContainerView.bounds;
self.pipController = [[AVPictureInPictureController alloc] initWithPlayerLayer:layer];
self.pipController.delegate = self;
```



3. 啟動畫中畫


```objectivec
[self.pipController startPictureInPicture];
```



4. 監控 AVPictureInPictureController 回撥事件。詳情請參見[PIPManager.m](https://github.com/byteplus-sdk/VideoOneSolutions/blob/main/Client/iOS/Component/ToolKit/VodPlayer/VEPlayerUIModule/Classes/PIPManager/PIPManager.m)：


