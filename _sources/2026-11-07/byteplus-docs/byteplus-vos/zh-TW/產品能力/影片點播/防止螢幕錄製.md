為保護您的影片內容在直播或點播等平臺免受未經授權的錄製，您可以實施防螢幕錄製和防截圖保護。本指南提供在 Android 和 iOS 平臺上實現此安全功能的操作說明及程式碼示例，確保您的應用播放器被錄製的影片或截圖會顯示黑屏。

本文介紹如何在您的應用中實現防螢幕錄製和防截圖保護。按照這些指導原則，您可以增強影片內容的安全性，為使用者提供更安全的觀看體驗。

<span id="b557bb9a"></span>
# 演示

整合並啟用防螢幕錄製功能後，應用使用者在錄屏過程中仍可正常觀看影片。但錄製完成後，錄製的螢幕影片或截圖將在應用的影片播放視窗區域顯示黑屏。

# 實現方式

<span id="cf0446e5"></span>
## Android

我們提供兩種在 Android 平臺防止螢幕錄製的方法。這種靈活性允許開發者根據應用需求定製最適合的防螢幕錄製解決方案。

<span id="d0119721"></span>
### 視窗防螢幕錄製/防截圖

VideoOne 利用 Android 系統提供的 [Window.addFlags(int)](https://developer.android.com/reference/android/view/Window#addFlags(int)) 方法實現視窗保護。此方法側重於保護應用整個視窗內顯示的內容。透過向視窗新增 [WindowManager.LayoutParams.FLAG_SECURE](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#FLAG_SECURE) 標誌，視窗內的所有內容，包括任何檢視或表面，都會受到保護。


* 使用 `Window.addFlags(int)` 新增 `WindowManager.LayoutParams.FLAG_SECURE` 標誌以保護視窗內容。

   ```Java
   Window window = getWindow();
   window.addFlags(WindowManager.LayoutParams.FLAG_SECURE);
   ```
   

* 使用 `Window.clearFlags(int)` 清除 `WindowManager.LayoutParams.FLAG_SECURE` 標誌以移除內容保護。

   ```Java
   Window window = getWindow();
   window.clearFlags(WindowManager.LayoutParams.FLAG_SECURE);
   ```
   


<span id="cc4a38fb"></span>
### SurfaceView 防螢幕錄製/防截圖

此方法專門針對 SurfaceView 內顯示內容的保護。透過在 SurfaceView 上設定 [SurfaceView.setSecure(boolean)](https://developer.android.com/reference/android/view/SurfaceView#setSecure(boolean)) 標誌，SurfaceView 渲染的內容將受到保護。當應用中有特定區域或元素需要保護時，此方法尤為適用。


* 將 secure 標誌設定為 true 以保護 SurfaceView 內容。

   ```Java
   surfaceView.setSecure(true);  
   ```
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">必須在包含 SurfaceView 的視窗掛載到視窗管理器之前設定此項。   </div>
   

* 將 secure 標誌設定為 false 以移除內容保護。

   ```Java
   surfaceView.setSecure(false);  
   ```
   


<span id="03f9a0a0"></span>
## iOS

在 iOS 平臺，VideoOne 採用一種變通方法，利用 [isSecureTextEntry](https://developer.apple.com/documentation/uikit/uitextinputtraits/1624427-issecuretextentry) 屬性於 [UITextField](https://developer.apple.com/documentation/uikit/uitextfield)。雖然該屬性用於密碼欄位文字遮蔽，但其副作用是防止檢視內容被截圖或螢幕錄製捕獲。

```objectivec
UITextField *textField = [[UITextField alloc] init];
textField.secureTextEntry = YES;
self.textField = textField;

// Add the player view to the text field's content view.
UIView *contentView = textField.subviews.firstObject;
contentView.userInteractionEnabled = YES;
[contentView addSubview:playerView];

// Add contentView to your UI layout as needed.
```
