影片播放提供全面的音影片服務套件，包括影片特效、媒體上傳與管理、多媒體處理、內容分發加速以及影片播放功能等。透過利用 BytePlus VOD 提供的基礎設施和媒體處理能力，您可以快速構建點播平臺和應用，同時專注於滿足業務需求並提升使用者體驗。

## 亮點

影片播放是一站式解決方案，提供媒體上傳和影片播放功能。您可以探索完整的影片播放功能，並將其整合到您的應用中。

<span id="251b768a"></span>
## 架構

本節介紹該方案的技術架構。具體而言，內容創作者使用 Video Editor SDK 進行影片拍攝和編輯。這些影片隨後透過 Upload SDK 上傳至媒體伺服器，觀眾則使用 Player SDK 獲取並播放影片。

### 影片播放

BytePlus VOD Player 引擎負責影片播放。它是一套多平臺 SDK，旨在實現無縫的媒體流播放。該引擎提供豐富功能，確保高質量且穩定的播放體驗。Player SDK 具有小包體和高效記憶體使用的特點。其高效架構的 API 使整合短影片、資訊流影片和長影片播放應用變得簡單。

更多詳情，請參閱[Player SDK 概覽](https://docs.byteplus.com/en/byteplus-vod/docs/player-sdk-overview)。

<span id="76952eb4"></span>
### 影片編輯器

BytePlus Video Editor 是一款影片處理 SDK。它提供企業級解決方案，幫助開發者減少開發時間和資源，快速為應用新增先進的短影片功能。

BytePlus Video Editor SDK 套件具備廣泛且強大的影片拍攝、錄製、編輯和合成能力。此外，還提供多種特效，如基於人臉、人體和背景分割的 2D/3D AR 貼紙、基於機器學習的音訊/字幕功能，以及高質量美顏和濾鏡選項。

更多詳情，請參閱[BytePlus VideoEditor 概覽](https://docs.byteplus.com/en/byteplus-video-editor-sdk/docs/one-pager-overview?version=v.4.0.2)。

<span id="22460df9"></span>
### 媒體上傳

BytePlus VOD Upload SDK 支援將您的媒體資產（資源）上傳至 BytePlus VOD，提供上傳控制、加速和後設資料提取等豐富功能。Upload SDK 可無縫整合至 Android、iOS 或 Web 應用，是 UGC 和 PGC 場景的理想選擇。

更多詳情，請參閱[Upload SDK 概覽](https://docs.byteplus.com/en/byteplus-vod/docs/upload-sdk-overview)。
