BytePlus VideoOne 演示支援自定義源影片播放。透過輸入特定的影片 ID 或 URL，您可以以短影片或中影片形式播放指定影片，並進行個性化定製。

# 操作說明


1. 安裝並登入 [BytePlus VideoOne Demo 應用](https://docs.byteplus.com/en/docs/byteplus-vos/docs-byteplus-videoone-demo-app-1-zh-TW)。

2. 點選 **影片播放與編輯**場景，透過點選 **立即體驗**按鈕，再點選位於右下角的 **設定**按鈕進入設定頁面。

3. 點選 **輸入媒體源**按鈕，並按照以下格式輸入自定義影片源：

   1. 僅使用 URL 播放影片

      ```Plain
      // To play a single video.
      https://example.com/video1.mp4
      
      // To play multiple videos, start a new line for each video URL.
      https://example.com/video1.mp4
      https://example.com/video2.mp4
      ```
      

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">參考 <a href="https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_vod_play_service_test.go">demo_vod_play_service_test.go</a> 檔案中的程式碼獲取 URL。      </div>
      

   2. 同時使用影片 ID 和 URL 播放影片。使用 JSON 陣列，其中每個 JSON 物件代表一個影片源。

      ```JSON
      [
        {
          "type":0,
          "vid":"v110ed...m0",
          "playAuthToken":"eyJH...ifQ==",
          "title":"My Example 1"
        },
        {
          "type":1,
          "httpUrl":"https://example.com/video3.mp4",
          "title":"My Example 2"
        }
      ]
      ```
      

      
      |欄位 |必填 |描述 |備註 |
      |---|---|---|---|
      |type |是 |影片源型別。<br><br><br>* 0：透過影片 ID（或影片 ID 與 URL 組合）播放。<br><br>* 1：僅透過 URL 播放。 |/ |
      |vid |當型別為 0 時必填 |影片 ID。<br><br>您可以在 VOD 控制檯的 VOD 空間中找到影片的 ID（`vid`）。 |/ |
      |playAuthToken |當型別為 0 時必填 |影片播放令牌。<br><br>參考 [demo_auth_token_test.go](https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_auth_token_test.go) 檔案中的程式碼獲取令牌。 |在獲取影片源資訊前，請確保已下載 [BytePlus VOD Server SDK](https://docs.byteplus.com/en/byteplus-vod/docs/go-sdk?version=v1.0) 作為前置條件。 |
      |httpUrl |當型別為 1 時必填 |影片 URL。<br><br>參考 [demo_vod_play_service_test.go](https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_vod_play_service_test.go) 檔案中的程式碼獲取 URL。 ||
      |title |是 |自定義影片標題。 |/ |
      

4. 點選 **進入短影片**，以短影片形式開始播放影片，或點選 **進入資訊流影片**，以中影片資訊流形式播放。
