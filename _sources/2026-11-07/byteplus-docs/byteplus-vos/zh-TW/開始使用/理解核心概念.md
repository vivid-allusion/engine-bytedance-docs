BytePlus Video One Solution 提供了一個全面的架構，用於構建影片應用，架構分為高層級的解決方案和基礎產品能力。本指南將解釋這些核心概念，包括我們的基礎產品（MediaLive、VOD 和 RTC），以及您的應用如何透過 SDK 和 API 與這些產品進行互動。理解這一結構是高效構建應用的第一步。

<span id="8c099f14"></span>
## 解決方案與產品能力

BytePlus VideoOne 為應用開發提供了兩種不同的抽象層級：**解決方案**和**產品能力**。選擇哪種方式取決於您的開發速度需求和定製化程度。


* **解決方案**：這些是為特定業務場景設計的高層級端到端套件，例如短劇或互動直播。解決方案整合了某一用例所需的全部客戶端和服務端元件，旨在顯著加快開發和上市程序。

* **產品能力**：這些是 VideoOne 平臺的基礎、模組化服務，提供核心功能。它們提供細粒度控制和最大靈活性，允許您按需組合，構建高度定製化且非預設解決方案覆蓋的應用。


<span id="d155935a"></span>
## 我們的基礎產品

我們的產品能力分為三大基礎產品。理解它們各自的職責是高效使用 BytePlus Video One Solution 的關鍵。


* **BytePlus MediaLive**：該產品負責管理所有與**直播影片流**相關的功能。適用於內容實時創作並向一對多觀眾播出的場景，如直播活動、體育賽事轉播或標準主播流。

* **BytePlus Video On Demand (VOD)** ：該產品處理所有與**預錄影片檔案**相關的工作流程。適用於媒體上傳、儲存、處理和使用者隨時回放的場景，如短劇應用、電影流媒體服務或線上課程庫。

* **BytePlus Real\-Time Communication (RTC)** ：該產品實現**互動、多向通訊**，重點關注超低延遲。適用於一對一視訊通話、多人語音聊天或主持人與觀眾透過影片直接互動（連麥）的直播場景。

## 如何與 VideoOne 互動：SDK 與 API

您的應用將透過兩種主要方式與我們的產品連線：


* **客戶端 SDK**：這些是可直接整合到您的客戶端應用（Android、iOS 或 Web）的軟體開發工具包。SDK 提供實現所有面向客戶端功能所需的介面，如發起直播、播放影片、啟用美顏效果或加入視訊通話。

* **服務端 API**：這些是您從自有後端伺服器呼叫的 OpenAPI。用於管理任務、安全操作（如為客戶端生成認證令牌），以及透過 webhook 從 VideoOne 平臺接收事件通知。典型整合需要客戶端應用使用我們的 SDK 與伺服器端使用我們的 API 協同配合。

## 整合應用：典型工作流程

以下示例說明這些概念如何應用於實際場景：構建短劇應用。


1. **業務需求**：建立一個短影片應用，使用者可以在垂直影片劇集流中滑動瀏覽。

2. **方案選擇**：在查閱文件後，短劇解決方案被確定為最適合的套餐，因為它已針對該特定場景預配置。

3. **元件分析**：對該方案的分析顯示，主要基於 BytePlus 影片點播（VOD）產品來儲存、管理和分發影片檔案。

4. **客戶端實現**：在客戶端應用中，開發者整合了 VideoOne 客戶端 SDK。隨後使用 SDK 的播放器元件實現面向使用者的功能：在影片流中播放、暫停及滑動切換影片。

5. **服務端整合**：在後端伺服器上，開發者使用服務端 API 管理影片內容庫，並生成安全的播放憑證傳遞給客戶端應用。
