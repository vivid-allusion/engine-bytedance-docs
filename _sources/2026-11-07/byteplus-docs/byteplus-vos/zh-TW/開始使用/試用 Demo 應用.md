BytePlus VideoOne Demo 應用是一款功能完善的預構建應用，能夠讓您親身體驗我們的核心解決方案和能力，無需編寫任何程式碼。該應用整合了我們完整的媒體 SDK 套件和影片雲服務，展示了多種行業場景和功能。

<span id="970f821e"></span>
## Android 和 iOS 原生 Demo 應用

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f56dc4203f964319aaca34a7d4313e3a~tplv-goo7wpa0wc-image.image) </span>

<span id="8515e9dd"></span>
### 場景

**場景**標籤頁包含一系列典型的音影片場景。


* 短劇

* 影片播放

* 互動直播

* 賽事直播


<span id="96cf5f9c"></span>
### 功能

**功能**標籤頁列出了每個媒體 SDK 的核心功能。


* 直播

* 影片播放器（含 ABR）

* RTC

* 投屏（Android 上使用 Chromecast，iOS 上使用 AirPlay）


<span id="184b7fac"></span>
## 網頁 Demo 應用

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/521885cc00c54bffa162551bc645554c~tplv-goo7wpa0wc-image.image) </span>

<span id="c60167a0"></span>
### 互動影片

VideoOne 網頁 Demo 應用提供互動影片解決方案，具備以下功能：


* 透過上下滑動播放短影片

* 為觀眾提供互動功能，如評論和點贊


<span id="fce59df4"></span>
## 下載 Demo 應用

您可以直接在網頁上訪問 Demo 應用，或從官方應用商店在移動裝置上安裝原生應用。請在下方選擇相應標籤以獲取直接連結或掃描二維碼。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">BytePlus VideoOne Demo 應用目前僅在部分國家和地區提供下載。如果 App Store 或 Google Play 顯示“此應用在您的國家或地區不可用”，建議您下載專案原始碼並自行構建 Demo 應用。請參閱<a href="https://docs.byteplus.com/docs/byteplus-vos/build-your-first-app-zh-TW">構建您的第一個應用</a>。</div>
