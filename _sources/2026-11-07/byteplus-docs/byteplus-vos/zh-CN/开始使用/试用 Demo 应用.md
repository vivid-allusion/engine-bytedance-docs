BytePlus VideoOne Demo 应用是一款功能完善的预构建应用，能够让您亲身体验我们的核心解决方案和能力，无需编写任何代码。该应用集成了我们完整的媒体 SDK 套件和视频云服务，展示了多种行业场景和功能。

<span id="970f821e"></span>
## Android 和 iOS 原生 Demo 应用

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f56dc4203f964319aaca34a7d4313e3a~tplv-goo7wpa0wc-image.image) </span>

<span id="8515e9dd"></span>
### 场景

**场景**标签页包含一系列典型的音视频场景。


* 短剧

* 视频播放

* 互动直播

* 赛事直播


<span id="96cf5f9c"></span>
### 功能

**功能**标签页列出了每个媒体 SDK 的核心功能。


* 直播

* 视频播放器（含 ABR）

* RTC

* 投屏（Android 上使用 Chromecast，iOS 上使用 AirPlay）


<span id="184b7fac"></span>
## 网页 Demo 应用

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/521885cc00c54bffa162551bc645554c~tplv-goo7wpa0wc-image.image) </span>

<span id="c60167a0"></span>
### 互动视频

VideoOne 网页 Demo 应用提供互动视频解决方案，具备以下功能：


* 通过上下滑动播放短视频

* 为观众提供互动功能，如评论和点赞
