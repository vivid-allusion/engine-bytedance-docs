BytePlus Video One Solution 提供了一个全面的架构，用于构建视频应用，架构分为高层级的解决方案和基础产品能力。本指南将解释这些核心概念，包括我们的基础产品（MediaLive、VOD 和 RTC），以及您的应用如何通过 SDK 和 API 与这些产品进行交互。理解这一结构是高效构建应用的第一步。

<span id="8c099f14"></span>
## 解决方案与产品能力

BytePlus VideoOne 为应用开发提供了两种不同的抽象层级：**解决方案**和**产品能力**。选择哪种方式取决于您的开发速度需求和定制化程度。


* **解决方案**：这些是为特定业务场景设计的高层级端到端套件，例如短剧或互动直播。解决方案集成了某一用例所需的全部客户端和服务端组件，旨在显著加快开发和上市进程。

* **产品能力**：这些是 VideoOne 平台的基础、模块化服务，提供核心功能。它们提供细粒度控制和最大灵活性，允许您按需组合，构建高度定制化且非预设解决方案覆盖的应用。


<span id="d155935a"></span>
## 我们的基础产品

我们的产品能力分为三大基础产品。理解它们各自的职责是高效使用 BytePlus Video One Solution 的关键。


* **BytePlus MediaLive**：该产品负责管理所有与**直播视频流**相关的功能。适用于内容实时创作并向一对多观众播出的场景，如直播活动、体育赛事转播或标准主播流。

* **BytePlus Video On Demand (VOD)** ：该产品处理所有与**预录视频文件**相关的工作流程。适用于媒体上传、存储、处理和用户随时回放的场景，如短剧应用、电影流媒体服务或在线课程库。

* **BytePlus Real\-Time Communication (RTC)** ：该产品实现**互动、多向通信**，重点关注超低延迟。适用于一对一视频通话、多人语音聊天或主持人与观众通过视频直接互动（连麦）的直播场景。


<span id="bc40d4a8"></span>
## 如何与 VideoOne 交互：SDK 与 API

您的应用将通过两种主要方式与我们的产品连接：


* **客户端 SDK**：这些是可直接集成到您的客户端应用（Android、iOS 或 Web）的软件开发工具包。SDK 提供实现所有面向客户端功能所需的接口，如发起直播、播放视频、启用美颜效果或加入视频通话。

* **服务端 API**：这些是您从自有后端服务器调用的 OpenAPI。用于管理任务、安全操作（如为客户端生成认证令牌），以及通过 webhook 从 VideoOne 平台接收事件通知。典型集成需要客户端应用使用我们的 SDK 与服务器端使用我们的 API 协同配合。

## 整合应用：典型工作流程

以下示例说明这些概念如何应用于实际场景：构建短剧应用。


1. **业务需求**：创建一个短视频应用，用户可以在垂直视频剧集流中滑动浏览。

2. **方案选择**：在查阅文档后，短剧解决方案被确定为最适合的套餐，因为它已针对该特定场景预配置。

3. **组件分析**：对该方案的分析显示，主要基于 BytePlus 视频点播（VOD）产品来存储、管理和分发视频文件。

4. **客户端实现**：在客户端应用中，开发者集成了 VideoOne 客户端 SDK。随后使用 SDK 的播放器组件实现面向用户的功能：在视频流中播放、暂停及滑动切换视频。

5. **服务端集成**：在后端服务器上，开发者使用服务端 API 管理视频内容库，并生成安全的播放凭证传递给客户端应用。
