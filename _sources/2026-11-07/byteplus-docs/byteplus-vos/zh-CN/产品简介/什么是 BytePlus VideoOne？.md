## 媒体 SDK

VideoOne 提供多种媒体 SDK 供您选择与组合，轻松为应用添加直播、视频播放、视频通话、美颜特效等功能。

**MediaLive 推流 SDK**

支持从客户端设备进行推流。互动版支持多人连麦。

**特效 SDK**

为您的应用增强贴纸特效与滤镜功能。

**RTC SDK**

提供高清音视频通信能力。

**MediaLive 播放器 SDK 与 VOD 播放器 SDK**

支持播放直播流或点播内容。MediaLive 播放器 SDK 的互动版支持多人连麦。

## 视频云服务

全球分发您的内容，实现超低延迟，并根据业务需求进行处理。VideoOne 提供以下云服务：

**BytePlus MediaLive**


* 超低延迟流媒体，也称为实时媒体（RTM）

* 增值服务，如低码率高清转码、录制、截图、时移

* 数据分析


**BytePlus RTC**


* 大规模音视频通信

* 稳定可靠的实时信令服务，低延迟、高并发

* 先进音频处理能力，涵盖声学回声消除（AEC）、自动增益控制（AGC）、自动降噪（ANC）


**BytePlus VOD**


* 媒体上传、存储与播放

* 媒体服务，包括低码率高清转码、水印、视频质量增强

* 质量洞察
