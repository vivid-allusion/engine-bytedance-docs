为实现直播推流与拉流，本指南介绍如何结合 VideoOne 与 BytePlus MediaLive Broadcast SDK 及 Player SDK。本指南提供整体概览，并链接至详细的实现指南与代码示例，帮助您快速搭建直播推流与观看功能。

<span id="a53bbaf7"></span>
# MediaLive 集成指南

<span id="99037d3e"></span>
## 生成直播流地址

要实现完整的直播流程，您需要推流 URL 将实时视频和音频数据发送至服务器，以及拉流 URL 用于获取并播放直播流。请参阅[生成直播流地址](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generating-live-stream-addresses)以生成推流和拉流 URL。

<span id="0fc04b5e"></span>
## 功能实现

<span id="807a6c98"></span>
### 直播推流

VideoOne 演示如何使用 BytePlus MediaLive Broadcast SDK，将采集、编码和封装后的直播流推送至 MediaLive 服务。目前支持四种推流方式：摄像头采集、纯音频直播、屏幕共享，以及本地或在线媒体文件推流。有关这些功能的详细实现，请参阅以下文档：


|平台 |Android |iOS |
|---|---|---|
|Broadcast SDK 参考文档 |* [基础功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features)<br><br>* [高级功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features) |* [基础功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-1)<br><br>* [高级功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-1) |


<span id="3bb31ef3"></span>
### 直播拉流

VideoOne 演示如何使用 BytePlus MediaLive Player SDK，从服务器获取实时音视频数据并进行播放。目前支持通过多种流媒体协议（如 FLV、HLS、RTMP）进行直播拉流与播放。有关这些功能的详细实现，请参阅以下文档：


|平台 |Android |iOS |
|---|---|---|
|Player SDK 参考文档 |* [基础功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-2)<br><br>* [高级功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-2) |* [基础功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-basic-features-3)<br><br>* [高级功能](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-implementing-advanced-features-3) |
