为保护您的视频内容在直播或点播等平台免受未经授权的录制，您可以实施防屏幕录制和防截图保护。本指南提供在 Android 和 iOS 平台上实现此安全功能的操作说明及代码示例，确保您的应用播放器被录制的视频或截图会显示黑屏。

本文介绍如何在您的应用中实现防屏幕录制和防截图保护。按照这些指导原则，您可以增强视频内容的安全性，为用户提供更安全的观看体验。

<span id="b557bb9a"></span>
# 演示

集成并启用防屏幕录制功能后，应用用户在录屏过程中仍可正常观看视频。但录制完成后，录制的屏幕视频或截图将在应用的视频播放窗口区域显示黑屏。

# 实现方式

<span id="cf0446e5"></span>
## Android

我们提供两种在 Android 平台防止屏幕录制的方法。这种灵活性允许开发者根据应用需求定制最适合的防屏幕录制解决方案。

<span id="d0119721"></span>
### 窗口防屏幕录制/防截图

VideoOne 利用 Android 系统提供的 [Window.addFlags(int)](https://developer.android.com/reference/android/view/Window#addFlags(int)) 方法实现窗口保护。此方法侧重于保护应用整个窗口内显示的内容。通过向窗口添加 [WindowManager.LayoutParams.FLAG_SECURE](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#FLAG_SECURE) 标志，窗口内的所有内容，包括任何视图或表面，都会受到保护。


* 使用 `Window.addFlags(int)` 添加 `WindowManager.LayoutParams.FLAG_SECURE` 标志以保护窗口内容。

   ```Java
   Window window = getWindow();
   window.addFlags(WindowManager.LayoutParams.FLAG_SECURE);
   ```
   

* 使用 `Window.clearFlags(int)` 清除 `WindowManager.LayoutParams.FLAG_SECURE` 标志以移除内容保护。

   ```Java
   Window window = getWindow();
   window.clearFlags(WindowManager.LayoutParams.FLAG_SECURE);
   ```
   


<span id="cc4a38fb"></span>
### SurfaceView 防屏幕录制/防截图

此方法专门针对 SurfaceView 内显示内容的保护。通过在 SurfaceView 上设置 [SurfaceView.setSecure(boolean)](https://developer.android.com/reference/android/view/SurfaceView#setSecure(boolean)) 标志，SurfaceView 渲染的内容将受到保护。当应用中有特定区域或元素需要保护时，此方法尤为适用。


* 将 secure 标志设置为 true 以保护 SurfaceView 内容。

   ```Java
   surfaceView.setSecure(true);  
   ```
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">必须在包含 SurfaceView 的窗口挂载到窗口管理器之前设置此项。   </div>
   

* 将 secure 标志设置为 false 以移除内容保护。

   ```Java
   surfaceView.setSecure(false);  
   ```
   


<span id="03f9a0a0"></span>
## iOS

在 iOS 平台，VideoOne 采用一种变通方法，利用 [isSecureTextEntry](https://developer.apple.com/documentation/uikit/uitextinputtraits/1624427-issecuretextentry) 属性于 [UITextField](https://developer.apple.com/documentation/uikit/uitextfield)。虽然该属性用于密码字段文本遮蔽，但其副作用是防止视图内容被截图或屏幕录制捕获。

```objectivec
UITextField *textField = [[UITextField alloc] init];
textField.secureTextEntry = YES;
self.textField = textField;

// Add the player view to the text field's content view.
UIView *contentView = textField.subviews.firstObject;
contentView.userInteractionEnabled = YES;
[contentView addSubview:playerView];

// Add contentView to your UI layout as needed.
```
