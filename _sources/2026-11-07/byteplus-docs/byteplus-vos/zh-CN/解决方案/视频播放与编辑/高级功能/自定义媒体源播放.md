BytePlus VideoOne 演示支持自定义源视频播放。通过输入特定的视频 ID 或 URL，您可以以短视频或中视频形式播放指定视频，并进行个性化定制。

# 操作说明


1. 安装并登录 [BytePlus VideoOne Demo 应用](https://docs.byteplus.com/en/docs/byteplus-vos/docs-byteplus-videoone-demo-app-1-zh-CN)。

2. 点击 **视频播放与编辑**场景，通过点击 **立即体验**按钮，再点击位于右下角的 **设置**按钮进入设置页面。

3. 点击 **输入媒体源**按钮，并按照以下格式输入自定义视频源：

   1. 仅使用 URL 播放视频

      ```Plain
      // To play a single video.
      https://example.com/video1.mp4
      
      // To play multiple videos, start a new line for each video URL.
      https://example.com/video1.mp4
      https://example.com/video2.mp4
      ```
      

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">参考 <a href="https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_vod_play_service_test.go">demo_vod_play_service_test.go</a> 文件中的代码获取 URL。      </div>
      

   2. 同时使用视频 ID 和 URL 播放视频。使用 JSON 数组，其中每个 JSON 对象代表一个视频源。

      ```JSON
      [
        {
          "type":0,
          "vid":"v110ed...m0",
          "playAuthToken":"eyJH...ifQ==",
          "title":"My Example 1"
        },
        {
          "type":1,
          "httpUrl":"https://example.com/video3.mp4",
          "title":"My Example 2"
        }
      ]
      ```
      

      
      |字段 |必填 |描述 |备注 |
      |---|---|---|---|
      |type |是 |视频源类型。<br><br><br>* 0：通过视频 ID（或视频 ID 与 URL 组合）播放。<br><br>* 1：仅通过 URL 播放。 |/ |
      |vid |当类型为 0 时必填 |视频 ID。<br><br>您可以在 VOD 控制台的 VOD 空间中找到视频的 ID（`vid`）。 |/ |
      |playAuthToken |当类型为 0 时必填 |视频播放令牌。<br><br>参考 [demo_auth_token_test.go](https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_auth_token_test.go) 文件中的代码获取令牌。 |在获取视频源信息前，请确保已下载 [BytePlus VOD Server SDK](https://docs.byteplus.com/en/byteplus-vod/docs/go-sdk?version=v1.0) 作为前置条件。 |
      |httpUrl |当类型为 1 时必填 |视频 URL。<br><br>参考 [demo_vod_play_service_test.go](https://github.com/byteplus-sdk/byteplus-sdk-golang/blob/master/example/vod/demo_vod_play_service_test.go) 文件中的代码获取 URL。 ||
      |title |是 |自定义视频标题。 |/ |
      

4. 点击 **进入短视频**，以短视频形式开始播放视频，或点击 **进入信息流视频**，以中视频信息流形式播放。
