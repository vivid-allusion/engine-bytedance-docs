You can delete a user using the BytePlus Console.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">A user cannot be deleted if it has been bound with role(s).</div>


**To delete a user:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User**.

   The user list appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085503-1746279318644.png) </span>

4. In the Actions column, click **Delete**.

   The warning message box appears.

5. Click **Delete**.

   The user is deleted.
