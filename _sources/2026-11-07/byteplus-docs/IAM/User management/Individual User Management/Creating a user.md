You can create a user using the BytePlus Console.

**To create a user:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User**.

   The user list appears.

4. Click **Create new user**.

   The create new users screen appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085140-1323667347589.png) </span>

5. Enter a username.

6. (Optional) Enter a display name, email, or description if needed.

7. Enable **Programmatic access** and assign a password to the user.

   The user is able to log in to the BytePlus Console with this password.

8. (Optional) Enable **Console access**.

   An AccessKey is generated and assigned to the user.

9. Click **Next**.

10. (Optional) Add one or multiple roles and policies for the user.

11. Click **Next**.

12. Review user settings.

13. Click **Submit**.

   The IAM user is created.


The IAM user can sign in to the BytePlus Console through the following steps:


1. Go to the [BytePlus Home](https://www.byteplus.com/).

2. Click **Sign in**.

3. On the **Sign in** screen, click **IAM user** under the **Sign in** button.

   You will see the IAM sign in screen.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085225-555322383731.png) </span>

4. Enter the main account's username/email, the sub\-account's username and password.

5. Click **Sign in**.
