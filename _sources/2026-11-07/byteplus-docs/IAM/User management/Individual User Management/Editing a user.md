You can edit a user's basic information, role, policy, AccessKey, and console settings using the BytePlus Console.

**To edit a user:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085417-183601878357.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User**.

   The user list appears.

4. In the Username column, click the name of a user.

   The User details screen appears.

5. Click **Edit** to edit the user's basic information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The username is not editable.   </div>
   

6. Edit the following settings for the user as needed:

   1. Under the Policy tab, add or remove policies including global and project policies. Click here for more details about policies.

   2. Under the User group tab, add the user to or remove the user from user group(s). Click here for more details about user groups.

   3. Under the Access key tab, add, disable or delete AccessKey(s). Click here for more details about AccessKey.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You must disable a key before deleting it.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You can assign no more than two access keys to a user.      </div>
      

   4. Under the Login settings tab, enable or disable console login for this user.
