You can edit a user group including adding users to it and binding policies to it using the BytePlus Console.

**To edit a user group:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User group**.

   The user group list appears.

4. Click the user group name.

   The User group details screen appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085913-1203010295199.png) </span>

5. Click **Edit** to edit the display name and description of this user group.

6. Under the User tab, add user(s) to or remove user(s) from this user group. Click here for more details about users.

7. Under the Policy tab, manage policies for the user group, including adding policies to this user group, modifying the policy scope, and removing policies from this user group. Click here for more details about policies.
