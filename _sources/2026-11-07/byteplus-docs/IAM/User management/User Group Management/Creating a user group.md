You can create a user group using the BytePlus Console.

**To create a user group:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User group**.

   The user group list appears.

4. Click **Create** **new** **user group**.

   The Create new user group panel appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085752-866513820219.png) </span>

5. Enter a user group name.

6. (Optional) Enter a display name if needed.

7. (Optional) Enter the description if needed.

8. Click **Submit**.

   A user group is created.
