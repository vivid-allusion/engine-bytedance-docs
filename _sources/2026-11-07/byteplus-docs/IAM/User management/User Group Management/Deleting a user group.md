You can delete a user group using the BytePlus Console if needed.

**To delete a user group:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User group**.

   The user group list appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085952-1512989095914.png) </span>

4. In the Actions column, click **Delete**.

   The warning message box appears.

5. Click **Delete**.

   The user group is deleted.
