You can create an access key through the user details screen or the key management screen.

<span id="876ca5aa"></span>
## Create an access key through the user details screen


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **User management** \> **User**.

   The user list appears.

4. In the Username column, click the name of a user.

   The user details screen appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522090847-1350092251403.png) </span>

5. Under the Access key tab, click **Create access key**.

   An access key is created and the notification pop\-up window appears.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can create no more than two AccessKeys for a user.   </div>
   

6. (Optional) Click **Download key certificate** to locally save the certificate of the access key generated.


<span id="6ed7e3e0"></span>
## Create an access key through the key management screen


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **Key management**.

   The key list appears.

4. Click **Create access key**.

   The security risk alert pop\-up window appears.

5. Click **Continue**.

   An access key is created and the notification pop\-up window appears.
