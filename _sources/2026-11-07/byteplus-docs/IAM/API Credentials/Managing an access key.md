You can manage an access key using the BytePlus Console, including showing/hiding its secret access key, and disabling/enabling/deleting it.

**To manage an access key:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **Access key management**.

   The key list appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522091007-1135409496505.png) </span>

4. Perform the following operations as needed:

   * In the Secret Access Key column, click the eye icon to toggle the visibility of your secret access key.

   * In the Actions column, click **Disable** to disable the access key.

   * In the Actions column. click **Enable** to re\-enable the access key.

   * In the Actions column, click **Delete** to delete the access key.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You must disable an access key before deleting it.      </div>
