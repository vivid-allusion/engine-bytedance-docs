Policies are used to define permissions. BytePlus IAM provides identity\-based and resource\-based policies. After policies have been attached to users and roles, these users and roles are granted the permissions defined in these policies. BytePlus IAM supports two types of policy:


* **System Default Policy**

   System default policies are general policies created and managed by BytePlus. They are used for authorization purposes only and are not editable.

* **User Custom Policy**

   User custom policies are created and managed by users to meet individual permission management needs.
