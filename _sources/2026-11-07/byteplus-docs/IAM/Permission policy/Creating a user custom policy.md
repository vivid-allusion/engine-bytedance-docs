You can create a user custom policy using the BytePlus Console.

**To create a user custom policy:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **IAM**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522085108-935060956253.png) </span>

   The IAM dashboard appears.

3. On the left navigation pane, click **Permission policy**.

   The Permission policy screen appears.

4. Click **Create policy**.

   The Create policy pop\-up window appears.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260522090610-780761169637.png) </span>

5. Enter a policy name.

6. (Optional) Enter the description.

7. (Optional) Enter the policy content.

8. Click **Submit**.


The user custom policy is added.
