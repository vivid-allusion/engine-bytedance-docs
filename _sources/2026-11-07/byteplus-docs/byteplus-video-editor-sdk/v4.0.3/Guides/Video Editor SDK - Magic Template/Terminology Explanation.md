Glossary of Magic Template Terms


|**Term** |**Definition** |
|---|---|
|Magic Template |A video template for template editing. It is a collection of prototype video information for generating a final video. |
|Template category |The category of a template, such as classic, hot, latest, and beat sync. |
|Media assets |Photo and video resources provided by users for exporting a final video. |
|Frame extracting |A process of extracting images from a video at a specified time point. |
|Effect assets |Effect resources in video templates. |
|Model algorithm file |An execution file used to apply effect assets to videos. |
|Model mappings |A mapping table of model algorithm files and the local SDKs. |
|Asset clip metadata |The metadata of a video clip includes the video thumbnail and length. The metadata of a text clip includes the thumbnail of the video frame at the start time of the text. |
