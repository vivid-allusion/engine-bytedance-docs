<span id="Prepare the development environment"></span>
# **Prepare the development environment**

Install the following environments on macOS:


* CocoaPods

* Xcode


<span id="Procedure"></span>
# **Procedure**


1. Unzip **CutSameDemo\-20210617.zip**.

2. Open the folder and run **pod repo update**.

3. Run **pod install**.

4. Open **CutSameDemo.xcworkspace.xcworkspace**.

# **Notes**


1. On\-device running is required.

2. The certificate authorization file is bound to the bundle ID. Authentication fails if it is modified.
