## **Notes**

**Do not change the Gradle version**


* The sample package has a specified Gradle version. Do not change the Gradle version of the sample package. Otherwise, problems like NDK incompatibility may occur.


**Do not change applicationId**


* Ensure that **applicationId** matches the license file that is generated based on the app ID. Otherwise, you cannot be authorized to use the functions of the sample.

* To test your own license file, change **applicationId** in the app\-level **build.gradle** file based on your app ID and license file.
