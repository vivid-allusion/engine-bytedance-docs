**Feature**

Initializes the VE SDK and its authentication information before you use it.

**Interface definition**


* VESDK.init


```Java
/**
 * Initialize the SDK.
 *
 * @param context       Context that you need to provide.
 * @param workspace SDK workspace path that you need to provide.
 * @since 2.0.1
 */
public static void init(@NonNull Context context, @NonNull String workspace) {
```



* VEAuth.init: initializes the authentication information


```Java
/**
 * Verify the license file of the SDK. licensePath specifies the path of the license file.
 */
public static void init(String licensePath) 
```


**Sample code**

```java
// Initialize the VE SDK environment.
VESDK.init( application , Environment.getExternalStorageDirectory().getAbsolutePath());
VESDK.setAssetManagerEnable(true);  // Set whether the SDK reads model files from the asset directory using assetManager.
// Set a local directory for saving algorithm models (for the recognition of faces, gestures, objects, and more). You can place required models in the local directory or deliver them from your server.
VESDK.setEffectResourceFinder(new FileResourceFinder("Local directory for saving model files"));
// License file information.
File licenseDir = application.getExternalFilesDir("license");
File licenseTarget = new File( licenseDir , LICENSE_NAME); // 0/Android/data/com.ss.android.vesdk.vedemo/files/license/ve_tob.licbag
boolean copy = FileUtil.copyAssetFile(application, LICENSE_NAME, licenseTarget.getAbsolutePath());
if ( !copy){
    ToastUtils.show("Failed to copy the license file.");
    LogUtils.e("Failed to copy the license file…");
}

LogUtils.d("License file exist: " + licenseTarget.exists() + ",path:" + licenseTarget.getAbsolutePath()
        + " ,file size:" + licenseTarget.length());

// Perform authentication.
VEAuth.init(licenseTarget.getAbsolutePath());

// Set the log level.
VESDK.setLogLevel(LOG_LEVEL_D);
VESDK.setEffectLogLevel(BEF_LOG_LEVEL_DEBUG);
VESDK.registerLogger(null, true);
```


**Note**


* Call VEAuth.init only after you have called VESDK.init.

* Set the model directory before using the SDK because some effects such as beauty effects and body shaping can be implemented only under model support.

* Call **VESDK.init** and **VEAuth.init** before you use **VERecorder** or create **VEEditor**. Otherwise, the call is invalid.

```java
/**
 * Initialize VERecorder and configure recording preview.
 *
 * @param cameraCapture Camera capture. If the value is null, the camera is not bound to the recorder; otherwise, the camera is bound to the recorder.
 * @param videoEncodeSettings Video encoding settings.
 * @param audioEncodeSettings Audio encoding settings.
 * @param previewSettings Video preview settings.
 * @return
 *
 * @since 2.9.0
 */
public int init(@Nullable ICameraCapture cameraCapture, @NonNull VEVideoEncodeSettings videoEncodeSettings,
                @NonNull VEAudioEncodeSettings audioEncodeSettings,@NonNull VEPreviewSettings previewSettings) 
```


**Sample code**

```java
   // Enable a new recorder.
    VESDK.enableNewRecorder(true);

    int[] size = {720, 1280};
    // Set the camera.
    VECameraSettings cameraSettings = new VECameraSettings.Builder()
            .setCameraType(VECameraSettings.CAMERA_TYPE.TYPE1)  // Use camera 1.
            .setCameraFacing(VECameraSettings.CAMERA_FACING_ID.FACING_FRONT) // Set the camera to face front.
            .setPreviewSize(size[0], size[1]) // Set the camera preview resolution. The actual resolution will be optimized based on the camera model.
            .build();

    // Set video recording.
    VEVideoEncodeSettings videoEncodeSettings = new VEVideoEncodeSettings.Builder(VEVideoEncodeSettings.USAGE_RECORD)
            .setVideoRes(size[0], size[1]) // Video recording resolution.
            .build();

    // Set audio recording. This step can be skipped. By default, the SDK generates a dual-channel audio file at the sample rate of 44100Hz.
    VEAudioEncodeSettings audioEncodeSettings = new VEAudioEncodeSettings.Builder()
            .Build();


    // Set the preview policy.
    VEPreviewSettings previewSettings = new VEPreviewSettings.Builder()
            .setRenderSize(new VESize(size[0], size[1])) // Set the render resolution for the SDK.
            .blockRenderExit(true)
            .enableCheckStatusWhenStopPreview(true)
            .build();

    // Create a VECameraCapture.
    capture = new VECameraCapture();

    // Initialize the VECameraCapture.
    capture.init(DemoApplication.context(), cameraSettings);

    // Enable the camera.
    capture.open();


    File vesdk = new File(Environment.getExternalStorageDirectory(), "vesdk");
    if (!vesdk.exists() || !vesdk.isDirectory()) {
        if (!vesdk.mkdirs()) {
            ToastUtils.show("Failed to create the work directory.");
        }
    }
    String workSpace = vesdk.getAbsolutePath();

    // Create VERecorder. Set a work directory or custom ResManager.
    // Use ApplicationContext rather than other contexts to prevent leakage.
    // Set VERenderView. Then the SDK will automatically register a callback to bind the life cycle of the recorder in the specific callback period.
    recorder = new VERecorder(workSpace, DemoApplication.context(), surfaceView);
    // Set the recorder status listener to be called before initialization.
    recorder.setRecorderStateListener(new VEListener.VERecorderStateExtListener() {
        @Override
        public void onInfo(int infoType, int ext, String msg) {
            if (infoType == VEInfo.TET_RENDER_CREATED) { // Recorder render environment created.

                recorder.startCameraPreview(capture); // Enable video preview for the camera.

            } else if (infoType == VEInfo.TET_RENDER_DESTROYED) { // Recorder render environment destroyed.

                capture.stopPreview();  // Disable video preview for the camera.

            } else if (infoType == VEInfo.TET_INIT) { // Recorder render module initialized.
            }

        }

        @Override
        public void onError(int ret, String msg) {

        }

        @Override
        public void onNativeInit(int ret, String msg) {
            LogUtils.d("onNativeInit...ret:" + ret + "  msg:" + msg );
            recorder.setComposerMode(1, 0); // Use the composer interface to load effects such as beauty effects.
            restoreComposer(); // Restore the filter and beauty effects. If an app switches from the foreground to the background and then switches back, you need to reload the stored filter and beauty effects.
        }

        @Override
        public void onHardEncoderInit(boolean success) {

        }
    });

    // Initialize the recorder. If VECameraCapture is null, the camera and recorder will be separately controlled. In this case, you can control the life cycle of the camera.
    // Otherwise, the recorder will be bound to the camera, and their life cycles will be coupled, which is not recommended.

    int ret = recorder.init((VECameraCapture) null, videoEncodeSettings, audioEncodeSettings, previewSettings);

    if (ret != VEResult.TER_OK) {
        ToastUtils.show("Failed to initialize the recorder.");
        // If the initialization failed, you need to handle the error based on the error message.
        return;
    }
    // The temporary files generated upon multi-scene recording are stored in workSpace/segments specified in new VERecorder(workSpace). 
    // If enableRecordingMp4 is true, only temporary files n_frag_v (with both video and audio) will be generated. Otherwise, both temporary files n_frag_v (with video only) and n_frag_a (with audio only) will be generated.
    recorder.enableRecordingMp4(true);
```

## Life cycle


* Add the following code for the recorder and capture in the specific life cycle of the activity:


```java
 @Override
    protected void onDestroy() {
        super.onDestroy();
        // Exit the camera capture.
        if ( capture != null ){
            capture.destroy();
        }
        // Exit the recorder.
        if ( recorder != null ){
            recorder.onDestroy();
        }
    }

    @Override
    protected void onStop() {
        super.onStop();
        capture.close(); // Disable the camera.
    }

    @Override
    protected void onRestart() {
        super.onRestart();
        capture.open(); // Enable the camera.
    }
```

## Combination

**Feature**

Combines multiple video recordings generated in **workSpace/segments** into one file with both video and audio, or into one video file and one audio file.

**Interface definition**


* Method 1: Combine multiple recordings into one MP4 file (with both video and audio).

* Prerequisites: You have called **recorder.enableRecordingMp4(true)**  after you called **recorder.init**.

* Temporary files n_frag_v (with both video and audio) have been generated. They can be combined into an MP4 file (with both video and audio).


```java
// recorder.getRecordedVideoPaths(): path for storing recordings.
VEUtils.concatVideo(recorder.getRecordedVideoPaths(),"/sdcard/vesdk/test.mp4");
```



* Method 2: Combine multiple recordings into one video file and one audio file.

* Prerequisites: You have not called **recorder.enableRecordingMp4(true)** .

* Temporary files **n_frag_v** (without audio) and **n_frag_a** (audio file) have been generated. You can call **recorder.concatAsync** to combine them into one **concat/concat.mp4** video file (without audio) and one **concat/concat.wav** audio file in **workSpace/concat**.


```java
// The callback is in a sub-thread.
// ret: total duration of the combined video file; videoPath: path of the video file; audioPath: path of the audio file.
recorder.concatAsync(new VEListener.VEConcatListener() {
    @Override
    public void onDone(final int ret, String videoPath, String audioPath) {
        // ret: total duration of the combined video file, in milliseconds.
        Log.d(TAG, "Combination result, total duration: " + ret +" videoPath: "+videoPath+" audioPath: "+audioPath);
    }
});
```


**Note**

VEUtils.concatVideo is time\-consuming. To prevent ANR, it is recommended that you execute it in a sub\-thread.

# Duet

<span id="36d12145"></span>
## Note

The Duet feature needs support from asset resource packages. For example, you can use specified resource packages to implement the left/right and up/down layouts on the screen.

<span id="75021ffa"></span>
## Preprocessing


* Preprocess the video you'd like to Duet. That is, extract audio from this video, and convert the audio file from the AAC format to the PCM format to improve the performance. For more information, see the following sample code.

* **params.saveto**: video file generated after preprocessing; **params.outputWav**: audio file generated after preprocessing.

* Refer to the **reEncodeVideo** method in the **ReEncodeUtil** class.


```java
// Preprocess the video to be Dueted.
public static void reEncodeVideo(final Activity context, final String path, final ReEncodeInterface callBack) {
    new Thread(new Runnable() {
        @Override
        public void run() {
            LogUtils.d("Preprocessing the video...");
            final FFMpegManager.RencodeParams params = new FFMpegManager.RencodeParams();
            params.readfrom = path;
            params.saveto = videoPath;
            params.outputWav = audioPath;
            params.inpoint = 0;
            params.outpoint = 20000;
            params.screenWidth = 540;
            params.fullScreen = false;
            params.pos = 0;
            params.rotateAngle = 0;
            params.isCPUEncode = true;
            // Extract audio from the video to be Dueted, and convert the audio file from the AAC format to the PCM format to improve the performance.
            final int ret = FFMpegManager.getInstance().rencodeAndSplitFile(params);
            context.runOnUiThread(new Runnable() {
                @Override
                public void run() {
                    if (callBack != null) {
                        callBack.complete(ret, params.saveto, params.outputWav);
                    }
                }
            });
        }
    }).start();
}
```

## NLE overview

<span id="c4924206"></span>
### NLE

Distinguished from linear editing introduced in the 20th century, non\-linear editing (NLE) is a method for non\-linear video editing (NLVE) or non\-linear audio editing (NLAE) without destructing the raw data.

<span id="ce61c458"></span>
### NLE model

NLEPlatform is a library mainly used to:


* Package interfaces that provide the audio and video edit functions.

* Provide the redo and undo capabilities.

* Standardize cross\-device draft protocols.


The following shows its basic data model:

<span>![图片](https://p-vcloud.byteimg.com/tos-cn-i-em5hxbkur4/300b91fcb8f24a5098fdc84e5e30ee5f~tplv-em5hxbkur4-noop.image) </span>

A model (**NLEModel**) is a top\-level container and its sub\-nodes are tracks (**NLETrack**).

A track (**NLETrack**) can be considered as a layer (Z\-axis). Different tracks are located at different layers.

A track slot (**NLETrackSlot**) can be considered as a time segment. Except for key\-frame scenes, assets in the same time segment must have the same parameter settings.

An asset description segment (**NLESegment**) describes the secondary processing status of assets, for example, time\-based edit and filter intensity.

Asset metadata (**NLEResourceNode/NLEResourceAV**) describes the URIs (local or remote) of assets as well as preset thresholds.

As shown in figure :


* A **NLEModel** can have multiple **NLETracks**, and a **NLETrack** can have multiple **NLETrackSlots**.

* A **NLETrack** uses a **NLETrackSlot** to describe assets or present all its effects such as video effects (**NLEVideoEffect**).

* Asset metadata is stored in **NLEResourceNode/NLEResourceAV**.


A **NLEModel** is in a tree structure, which can be illustrated using the panels required for editing as follows:

<span>![图片](https://p-vcloud.byteimg.com/tos-cn-i-em5hxbkur4/b155ce576e6a4092a815cf925d78a362~tplv-em5hxbkur4-noop.image) </span>

**NLEPlayer**

Currently, a **NLEModel** can precisely describe assets and operations on asset elements. When the **NLEModel** changes, you can determine that assets have changed or operations have been performed on assets. Such changes will proactively trigger incremental rendering in **NLEPlayer**, for example, adding videos or video masks.

<span>![图片](https://p-vcloud.byteimg.com/tos-cn-i-em5hxbkur4/49ab824df684493abf3925cf7742cd60~tplv-em5hxbkur4-noop.image) </span>

**NLEModel** is a data entry that carries information such as assets for editing and time layers.

**NLEEditor** is key for us to operate **NLEModel** to implement undo/redo and draft\-related operations. When **NLEModel** changes, you can call the commit() method of **NLEEditor** to temporarily save the current operation. When **NLEEditor** detects the data change, it uses **NLEEditorListener** to listen on data changes and then asks **NLEPlayer** to incrementally update the rendering effects.

### Import pictures/videos

**Feature**

Imports assets selected for editing. The assets will be added to the main track and played in sequence. You can customize the playback duration for pictures.

**Interface definition**


* NLESegmentVideo: describes video fragments, through **timeClipStart**, **timeClipEnd**, and **keepTone** (indicating whether to keep pitch during speed change).

   **timeClipStart**: video fragment start time, in microseconds.

   **timeClipEnd**: video fragment end time, in microseconds.

* NLETrackSlot: time segment for playing a video on the track, which is determined by **startTime** and **endTime**.

   **startTime**: start time for playing a video on the track, in microseconds.

   **endTime**: end time for playing a video on the track, in microseconds.

* addSlot: adds **NLETrackSlot** to the **NLETrack** object.

* NLEResourceAV: describes metadata of a video asset.

   **resourceType**: resource type. For its options, see resource types enumerated in **NLEResType**.

   **duration**: total duration of a resource, in microseconds. For picture resources, you need to set the default playback duration.

   **height** and **width**: height and width of a video.

   **resourceFile**: local path of a resource.

* nleEditor.commitDone(): extension of the **commit()**  and **Done()**  methods of the **NLEEditor** object.


**Sample code**

```kotlin
/**
 * @param media Resource selected from the video/picture selector, including the path and type of the resource.
 */
 fun importMedia(val path: String, val isVideo: Boolean) {
    val videoInfo = fileInfo(path, isVideo） ?: return  
    // 1. Each video fragment corresponds to a slot.
    val videoSlot = NLETrackSlot().also { slot ->
        // 2. Add video fragments to slots.
        slot.mainSegment = NLESegmentVideo().also { segment ->
            // Video resource.
            segment.avFile = NLEResourceAV().also { resource ->
                resource.resourceType = if (isVideo) NLEResType.VIDEO else NLEResType.IMAGE
                // The unit is millisecond.
                // Total duration of the current video. If the resource is a picture, add a default value.
                resource.duration = if (isVideo) TimeUnit.MILLISECONDS.toMicros(videoInfo.duration.toLong()) else TimeUnit.MILLISECONDS.toMicros(DEFAULT_PICTURE_TIME.toLong())
                // Actual height and width of a video.
                resource.height = videoInfo.height.toLong()
                resource.width = videoInfo.width.toLong()
                // Path of a video or a picture.
                resource.resourceFile = media.path
            }
            // Entire video. If you only need a part of the video, set the start time and end time only.
            segment.timeClipStart = 0
            segment.timeClipEnd = if (isVideo) TimeUnit.MILLISECONDS.toMicros(videoInfo.duration.toLong()) else TimeUnit.MILLISECONDS.toMicros(DEFAULT_PICTURE_TIME.toLong())
            // Indicates whether to keep pitch during speed change. The value true indicates yes.
            segment.keepTone = true
    
            // 3. Set the canvas style. 
            setCanvasStyle(segment)
        }
        // 4. Set the duration of a video slot on the entire canvas.
        slot.startTime = currentSlotStartTime
    
        currentSlotStartTime += slot.duration
    
    }
    
    // 6. Add video slots to the main track.
    nleMainTrack.addSlot(videoSlot)
    
    // 7. Delete all videos.
    nleModel.clearTrack() 
    
    
    // 8. Add a track to the model.
    nleModel.addTrack(nleMainTrack) 
    
    
    // 9. Set the canvas aspect ratio.
    nleModel.canvasRatio = 9F / 16F
    
    // 10. Update data changes to NLEEditor in a timely manner.
    nleEditor.commitDone()
 }
    
// Set the canvas style.
fun setCanvasStyle(segment: NLESegmentVideo) {
        // Set the canvas style of a video.
       // Set the canvas type to color.
        val canvasStyle = NLEStyCanvas().also {
            it.type = NLECanvasType.COLOR
            it.color = Color.parseColor("#181718").toLong()
        }
        segment.canvasStyle = canvasStyle
    }
    
```


**Note**


* You do not need to create a NLETrack object for each video fragment on the same track.

* During NLE, the time unit must be microsecond. If time in milliseconds is obtained, use the **TimeUnit.MILLISECONDS.toMicros()**  method to convert it into time in microseconds. For example, the value 6 milliseconds needs to be converted into 6000 microseconds.

```kotlin
 *
 * @param speed Speed at which a video is played. The value must be greater than 0.1 and less than or equal to 100.
 * @param changeTone Indicates whether to change pitch. If the value of speed is greater than 5, pitch is forcibly changed.
 */
fun changeSpeed(speed: Float?, changeTone: Boolean?）{
    selectedNleTrackSlot?.apply {
        // Set a fixed frame rate (in fps) for preview. Otherwise, when a video is played at 10x to 100x speed, audio playback may be completed before image playback.
        editorContext.videoPlayer.player!!.setPreviewFps(30)

        NLESegmentVideo.dynamicCast(mainSegment)?.also { videoSeg ->
            val nleSpeed = speed ?: videoSeg.absSpeed

                // Indicates whether to change pitch during speed change.
                videoSeg.keepTone = nleChangeTone
                nleEditor.commitDone()
            }
        listener?.onChanged(nleSpeed, nleChangeTone)
        }
   }
}
```

```kotlin
private fun reverseClip(replaceVideoPath: String, track: NLETrack, slot: NLETrackSlot, isReverse: Boolean = true): Int {

    return NLESegmentVideo.dynamicCast(slot.mainSegment)?.let {
        // Use the original video as a reference.
        val duration = fileInfo(it.resource.resourceFile, it.type)?.duration
            ?: throw IllegalArgumentException("obtain file duration failed!,check file is valid video file")

        // Record the settings in NLE.
        if (isReverse) {
            track.setExtra(it.resource.resourceFile, replaceVideoPath)
            it.reverseVideoPath = replaceVideoPath
        } else {
            it.reverseVideoPath = null
        }

        it.rewind = isReverse
        val timeClipStart = duration.toLong().toMicro() - it.timeClipEnd
        it.timeClipEnd =  duration.toLong().toMicro() - it.timeClipStart
        it.timeClipStart =  timeClipStart
        nleEditor.commitDone()
        return 0
    } ?: throw IllegalStateException("video segment is null, invalid data")
}
```

**Sample code**

```kotlin
/**
 * Mask of a video segment.
 *
 * @param maskWidth Mask width.
 * @param maskHeight Mask height.
 * @param maskCenterX X coordinate of the mask center (ranging from –0.5 to 0.5).
 * @param maskCenterY Y coordinate of the mask center (ranging from –0.5 to 0.5).
 * @param maskRotate Mask rotation angle (ranging from 0 to 360).
 * @param maskRoundCorner Radius of each rounded corner, which takes effect only for rectangle masks.
 * @param invert Indicates whether to invert the mask.
 * @param maskFeather Radius of a feather mask.
*/
 fun mask(
    maskWidth: Float?, maskHeight: Float?,
    maskCenterX: Float?, maskCenterY: Float?,
    maskRotate: Float?, maskRoundCorner: Float?,
    invert: Boolean?, maskFeather: Float?,

)  {
   // 1. Locate the slot (selectedNleTrackSlot).
   // 2. Set the mask in mainSegment.
    NLESegmentVideo.dynamicCast(selectedNleTrackSlot?.mainSegment)?.apply {

        var maskSegment = selectedNleTrackSlot?.masks?.firstOrNull()?.segment
        
        // 3. Create a mask (NLESegmentMask) if no mask is available.
        if (maskSegment == null) { // Not initialized.
            maskSegment = NLESegmentMask()
            val nleMask = NLEMask().apply {
            // Set the segment into the NLEMask.
                segment = maskSegment
            }
            // Add mask information.
            selectedNleTrackSlot?.addMask(nleMask)
        }
        
        // 4. Modify mask attributes.
        maskSegment?.apply {
            maskCenterX?.apply { maskSegment.centerX = maskCenterX }
            maskCenterY?.apply { maskSegment.centerY = maskCenterY }
            maskWidth?.apply { maskSegment.width = maskWidth }
            maskHeight?.apply { maskSegment.height = maskHeight }
            maskRoundCorner?.apply { maskSegment.roundCorner = maskRoundCorner }
            maskRotate?.apply { maskSegment.rotation = maskRotate }
            invert?.apply { maskSegment.invert = invert }
            maskFeather?.apply { maskSegment.feather = maskFeather }


        }
        // 5. Call commitDone() in time.
        nleEditor.commitDone()
    }

}
```

"filterName" is for the adjustment type

### Replacement

**Description**

Select the main track and click "Replace". The album page will appear so that the user can replace the original main track material with local materials. The replacement rules are as follows:

Image \-\> Image: No time limit

Image \-\> Video: The video length is longer than the length of the currently selected image. (The image length is not necessarily 3s, but any length set by the user.)

Video \-\> Image: No time limit. The image has the same duration as the video.

Video \-\> Video: The length is longer than the original video.

To put it simply, the replacement is unlimited for images. For videos, the new material needs to be longer than the slot of the old material, or the material will be greyed out and become unselectable.

**Interface definition**

Change the specific parameters of the selected slot. The parameters are provided by the material selected in the album.

```kotlin
/**
* Replace track
 */
override fun slotReplace(select: MutableList<EditMedia>): Boolean {
    val media = select[0]
    val videoInfo = fileInfo(media.path, if (media.isVideo) 3 else 4) ?: return false
    selectedNleTrackSlot?.also { slot ->
        slot.mainSegment = NLESegmentVideo().also { segment ->
            segment.avFile = NLEResourceAV().also { resource ->
                resource.resourceType =
                    if (media.isVideo) NLEResType.VIDEO else NLEResType.IMAGE
                resource.duration = 1000 * videoInfo.duration.toLong()
                resource.height = videoInfo.height.toLong()
                resource.width = videoInfo.width.toLong()
                resource.resourceFile = media.path
            }
            segment.timeClipStart = 0
            segment.timeClipEnd = TimeUnit.MILLISECONDS.toMicros(slot.duration / 1000)
            segment.keepTone = true
            EditorCoreUtil.setDefaultCanvasColor(segment)
        }
    }
    selectedNleTrack!!.timeSort()
    nleEditor.commitDone()
    return true
}
```

## Curved speed change

**Feature**

Speeds up or down a video at a variable rate (described through a curve), which helps highlight certain parts of a video.

Currently, the following curves are supported: montage, hero, bullet, jump cut, ease in, and ease out.

**Related concepts**

Segment point: anchor point in the coordinate system of the asset time. For example, for a 10s video, PointA(0.5, 2.0) indicates that the 5th second is played at 2x speed. Note that the editing panel for curved speed change processes segment points.

Sequence point: anchor point in the coordinate system of the playback time. For example, for a 10s video whose actual playback duration decreases to 4s after curved speed change, PointA(0.5, 2.0) indicates that the 2nd second is played at 2x speed. Note that after curved speed change, **videoPlayer** obtains the play progress based on sequence points and that the **seekTo()**  method deals with sequence points.

## Keyframe

<span id="Overview"></span>
### Overview

You can set all the supported effect parameters in each keyframe to achieve simultaneous movements or changes of these parameters between two keyframes.

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/f3651cf-20220308-153302.png) </span>

<span id="Non-linear edit (NLE) data model"></span>
### Non\-linear edit (NLE) data model

A keyframe object is inherited from an NLETrackSlot object and is specified in the KeyframeList parameter of the NLETrackSlot object. A keyframe is similar to a snapshot at a specific point in time in an asset fragment. You can add multiple keyframes in one asset fragment. The point in time of a keyframe is indicated by the StartTime parameter in the keyframe object. This point in time is relative to the beginning of the fragment instead of the absolute position on the timeline.

```Plain
/**
 * Locally calculate the linear changes of the keyframes and return the keyframe range that the current point in time belongs to and the corresponding ratio, so as to calculate the values of keyframe parameters at the current position on the timeline.
 */
fun calculateKeyframeDate(slot: NLETrackSlot, curTime: Long): KeyframeCalResult {
    val keyframes = slot.keyframes
    var percent = 1.0f
    var leftKeyframe: NLETrackSlot? = null
    var rightKeyframe: NLETrackSlot? = null
    var left = -1L
    var right = Long.MAX_VALUE

    keyframes.forEachIndexed { index, keyframe ->
        val start = slot.startTime + keyframe.startTime
        if (start in left..curTime) {
            leftKeyframe = keyframe
            left = start
        } else if (start in curTime..right) {
            rightKeyframe = keyframe
            right = start
        }
    }
    if (leftKeyframe != null && rightKeyframe != null) {
        percent = (curTime - left).toFloat() / (right - left)
    }
    return KeyframeCalResult(leftKeyframe, rightKeyframe, percent)
}
```

```Plain
fun refreshAllKeyframeInfo(filterIndex: Int, info: String, curTrack: NLETrack, curSlot: NLETrackSlot) {
    val keyframeInfo = getKeyframeInfo(filterIndex) ?: return

    // The same type of keyframes in all slots on the main track uses the same filter index, hence the need for distinguishing.
    if (curTrack.mainTrack) {
        if (curTrack.nleId != keyframeInfo.trackId || curTrack.getSlotIndex(curSlot) < 0) {
            return
        }
    } else {
        if (curTrack.nleId != keyframeInfo.trackId || curSlot.nleSlotId != keyframeInfo.slotId) {
            return
        }
    }

    when (keyframeInfo.filterType) {

        in FilterType.FILTER_TYPES -> {
            val intensity: IntensityProperty = gson.fromJson(info, IntensityProperty::class.java)
            curSlot.filters.firstOrNull {
                it.segment.filterName == keyframeInfo.filterType
            }?.let {
                it.segment.intensity = intensity.intensity.value.toFloat()
                it.setTransientExtra(NLEKeyFrameTransientExtrakey.getFilterIntensity(),it.segment.intensity.toString())

            }
        }


    }
}
```
