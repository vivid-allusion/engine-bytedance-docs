The overview page provides insights into the security posture of your network assets. It offers a detailed view of Cloud Firewall's protection capabilities and includes information about inbound and outbound traffic, such as asset protection status, log capacity, traffic statistics, security event data, and security event trends.

<span id="Asset protection status"></span>
### Asset protection status

The Asset status section displays the number of protected assets, the number of unprotected assets, and the remaining number of assets that can be protected for the current Cloud Firewall instance specification.

<span id="1e7a55a1"></span>
## Logs

Displays the logging service's total capacity and used capacity, allowing for timely planning and adjustment of log storage space.

<span id="Network traffic"></span>
### Peak network traffic bandwidth

The network traffic section presents the current network's peak bandwidth. Peak bandwidth refers to the maximum bandwidth of inbound and outbound traffic within the last 24 hours.

<span id="Security events"></span>
### Security events

The Security event section displays the number of interceptions of both inbound and outbound traffic performed by the current access control policy at the edge. It also presents the count of blocked external domains and IP addresses. From the trend chart below, you can also see the traffic trend and interceptions within a specific period. This enables you to stay informed about the security posture of your assets.


* Supports displaying security event data for up to the last 7 days.

* Supports filtering data by asset and time dimension.
