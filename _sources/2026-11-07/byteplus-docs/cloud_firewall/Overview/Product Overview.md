## What is a cloud firewall? 

Byteplus Cloud Firewall (CFW) is a cloud\-native network security protection product that provides capabilities such as internet boundary, VPC boundary, unified security access control for cloud and on\-premises, traffic visibility, and log auditing. It is the most basic and important network security facility for your business in the cloud.

<span id="8f447850"></span>
## **Access Control**


* **Internet boundary access control**: The internet boundary cloud firewall supports unified management of all public IP traffic entering and exiting the internet. You can use the internet boundary cloud firewall to reduce the exposure of public assets on the internet and lower the security risks of business traffic.

* **VPC boundary access control**: The VPC firewall manages traffic control between VPCs, VPC and VPN, and VPC and dedicated line by controlling the TR transit router, achieving traffic security protection across VPCs in the cloud, between VPCs and local IDC, and between VPCs and third\-party clouds.

* **NAT** **Boundary firewall**: The NAT firewall uniformly controls the inbound and outbound traffic between resources within the VPC (ECS, ENI, etc.) and the NAT gateway, ensuring the security protection of private IP traffic going to and from the internet.

* **Host boundary firewall**: The host firewall corresponds to the security group and controls communication among ECS instances. Once the access control policy of the host boundary firewall is published, it automatically syncs to the ECS security group and takes effect.

## **Traffic Visibility**


* **Proactive External Link Analysis**: Proactive external link analysis displays the current status of external links for your assets in real\-time, showing detailed information about external link domains and IPs. The cloud firewall can also actively identify risky domains and risky IPs, helping you to timely discover suspicious assets.

* **Asset Exposure Analysis**: On the asset exposure analysis page, you can view the access status of all public IPs to your cloud assets, including information about access sources, open ports, and accessed assets, helping you manage and control asset exposure.

* **VPC** **Inter\-VPC Analysis**: VPC inter\-visit analysis presents the traffic access relationships between VPCs in real\-time, helping you discover illegal access between VPCs.


<span id="3dfafc92"></span>
## **Log Audit**


* **Access Control Log**: The cloud firewall supports a 180\-day log retention feature for rule hits, recording all log information that hits the access control policies, assisting you in auditing and post\-event tracing work.

* **Traffic Log**: The cloud firewall supports detailed recording of all traffic logs for 180 days, automatically collecting and storing traffic logs entering and exiting the internet, helping you complete security analysis work.
