## **Internet boundary access control** 

Internet exposure surface reduction：The Internet Firewall supports configuring access control policies based on IP address, port, protocol, and geographic location to manage inbound traffic, reduce the exposure of public assets on the internet, and lower the risks of external attacks. 

Proactive outbound control: The Internet Firewall supports configuring access control policies based on IP address, port, protocol, or geographic location to manage outbound traffic, reduce violations of asset outbound behaviors, and protect asset security.

<span id="d8c21b56"></span>
## Hybrid cloud (IDC + cloud) boundary traffic security control

VPC Firewall can provide unified security control for dedicated line or VPN traffic between cloud VPCs and between cloud VPCs and IDC, reducing security risks of lateral movement of threats and unauthorized access.

<span id="271b87f2"></span>
## **Compliance with equal protection regulations or internal security audit compliance**

The cloud Firewall supports east\-west and north\-south traffic access control, as well as supporting log auditing and tracing capabilities, to meet boundary protection and access control requirements in equal protection regulations.
