This article introduces the feature release dynamics of various versions of the cloud firewall. We welcome you to experience it.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



1. <div data-tips="true" data-tips-type="tip">The "invitation to test" products or features are not yet open to all users. To facilitate understanding of the products, some accompanying documents for "invitation to test" products or features are only visible to users with activated product capabilities. If you need to use the "invitation to test" products or features, please contact your account manager to apply.</div>


2. <div data-tips="true" data-tips-type="tip">During the invitation to test period, BytePlus will support service availability and reliability, but does not guarantee any service availability or reliability. The <a href="https://docs.byteplus.com/en/docs/cloud_firewall/SLA">Service Level Agreement</a> will take effect after you activate and start using the officially released version of the product and services.</div>

## January 2025


|**Release date** |Feature  |**Note** |
|---|---|---|
|2025\-01\-23 |Policy backup rollback |The cloud firewall provides backup and rollback functionality for access control policies, allowing you to roll back policies to a specified time point according to business needs, effectively improving policy migration and operational efficiency. |
|2025\-01\-23 |Strategy validation |The cloud firewall provides a policy verification query function. When encountering network anomalies, you can quickly confirm whether the traffic is allowed or blocked by the firewall policy by entering the network five\-tuple information (source IP, destination IP, protocol, source port, destination port), which facilitates fault troubleshooting. |
