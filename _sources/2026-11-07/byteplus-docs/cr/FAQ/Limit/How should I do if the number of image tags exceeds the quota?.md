---
title: "How should I do if the number of image tags exceeds the quota?"
product: "Container Registry"
product_code: "cr"
source: "https://docs.byteplus.com/en/docs/cr/How_should_I_do_if_the_number_of_image_tags_exceeds_the_quota"
---

Once the number of image tags exceeds the quota, subsequent creation of image tags will not be supported. It is recommended to automatically clean up image tags using tag retention rules. For details, please refer to [Creating Tag Retention Rules](https://docs.byteplus.com/en/docs/cr/Creating_tag_retention_rules).
