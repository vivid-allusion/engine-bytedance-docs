Only the Standard Edition supports quota scale\-out. Quota scale\-in is not supported after scaling out, and additional charges will apply for the scaled\-out portion. For details on instance quota increase, please refer to [Increasing Instance Quota](https://docs.byteplus.com/en/docs/cr/increase-instance-quota).
