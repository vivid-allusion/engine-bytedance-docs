---
title: "How do I delete the private DNS record and ENI created when I create a VPC?"
product: "Container Registry"
product_code: "cr"
source: "https://docs.byteplus.com/en/docs/cr/How_to_delete_private_domain_names_and_network_interfaces_when_you_create_a_private_network_VPC"
---

The **private DNS record** and **elastic network interface (ENI)**  automatically created during this operation cannot be deleted separately. After you delete the specified VPC from CR, the corresponding **private DNS record** and **ENI** are deleted automatically.
