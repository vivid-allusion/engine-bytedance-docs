The signature method for the Container Registry (CR) OpenAPI is the same as the signature method in the BytePlus unified API call specification.

For the common signature method of BytePlus OpenAPI, refer to [Signature method](https://docs.byteplus.com/en/docs/byteplus-platform/reference-how-to-calculate-a-signature).
