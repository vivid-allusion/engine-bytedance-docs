This document introduces the SDK language versions provided by the Container Registry and lists the download links for the latest version of the SDK.

## Prerequisites


* The account has passed the enterprise real\-name authentication. For detailed instructions, refer to  [Sign Up and Verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Only users who have completed enterprise real\-name authentication are eligible to use the BytePlus Container Registry (CR) Product.   </div>
   

* The Container Registry Product has been activated. If not activated yet, please log in to the [Container Registry Console](https://console.byteplus.com/cr) and follow the system prompts to activate the product.

* If IAM users are required to operate the Container Registry, ensure that the relevant policies and role authorizations for the Container Registry have been completed. For specific operating instructions, please refer to [Managing Authorizations](https://docs.byteplus.com/en/docs/cr/permission-management).

* Docker has been installed. For specific operations, please refer to [Installing Docker](https://docs.docker.com/engine/install/centos/).

* When pushing and pulling images using a Standard Edition instance, it is necessary to first create a Standard Edition instance. For specific operations, please refer to [Purchasing a Standard Edition Instance](https://docs.byteplus.com/en/docs/cr/create-a-container-registry-enterprise-edition-instance). Besides, the operations for pushing and pulling images using a standard instance are similar to those using a  the operations with a trial instance.
