This document describes the usage limits of Container Registry CR.


|Limitation item |Description |Standard instance ||
|---|---|---|---|
|||Standard |Micro Edition |
|Number of Instances |Maximum number of instances that can be created by a BytePlus root user. |* China (Beijing): 3<br><br>* China (Guangzhou): 2<br><br>* China (Shanghai): 2<br><br>* China (Hong Kong): 2<br><br>* Asia Pacific (Johor): 2<br><br>* Asia Pacific (Jakarta): 2 |1 |
|Number of Namespaces |Maximum number of namespaces that can be created under a single instance. |50 |5 |
|Namespace Storage Capacity |The maximum storage capacity supported by a namespace. |Unlimited |500 GiB |
|Number of OCI Artifact Repositories |Maximum number of OCI artifact repositories that can be created under a single instance. |3,000 |300 |
|Number of Image Tags |The maximum number of image tags that can be uploaded to a single OCI artifact repository. |5,000 |100 |
|Data Volume per Image Layer |The data volume of a single layer in an image. |40 GiB |200 |
|Upper Limit of Public Network Bandwidth |The upper limit of inbound and outbound bandwidth on the public network for the EIP corresponding to the Container Registry instance. |200 Mbps |50 Mbps |
|VPC access quota |Supports applying for additional VPC usage quota to meet business needs. |5 |Not supported |
