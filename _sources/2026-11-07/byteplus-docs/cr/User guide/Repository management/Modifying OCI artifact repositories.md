You can adjust the public/private types of artifacts in an OCI artifact repository by modifying the repository. This topic describes how to modify an OCI artifact repository.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">You can modify only the <strong>Type</strong> and <strong>Description</strong> parameters of the OCI artifact repository.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the target instance.

   1. Log in to the [CR console](https://console.byteplus.com/cr).

   2. Select the target region in the top navigation bar.

   3. In the left navigation bar, click **List of instances**, find the target instance, and click **Enter instance**.

2. In the left navigation bar of the instance page, click **OCI artifact repository**.

3. On the **OCI artifact repository** page, find the OCI artifact repository to be modified, and click **Actions** in the column to the right of the namespace Name, then click `···` \> **Modify**.

4. In the system dialog box, modify the OCI artifact repository parameters. For parameter description, see [Create OCI artifact repository](https://docs.byteplus.com/en/docs/cr/create-an-OCI-repository?lang=en).
