This topic describes how to delete a CR namespace.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Before deleting a namespace, you first need to delete all OCI artifact repositories. For details, see <a href="https://docs.byteplus.com/en/docs/cr/delete-an-oci-repository">Delete OCI artifact repository </a>.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the target instance.

   1. Log in to the [CR console](https://console.byteplus.com/cr).

   2. Select the target region in the top navigation bar.

   3. In the left navigation bar, click **List of instances**, find the target instance, and click **Enter instance**.

2. In the left navigation bar of the instance page, click **Namespace**.

3. On the **Namespace** page, find the target namespace and select `···` \> **Delete** in the **Actions** column.

4. In the confirmation message that appears, confirm the namespace information, and then click **Confirm** to complete the deletion.
