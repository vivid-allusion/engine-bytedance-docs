Supports modifying the configuration information of the CR namespace based on business requirements, for example, project ownership, registry type, storage capacity, and more. This topic describes how to update the namespace configuration.

<span id="X4VFNAjd"></span>
## Procedure


1. Log in to the target instance.

   1. Log in to the [CR console](https://console.byteplus.com/cr).

   2. Select the target region in the top navigation bar.

   3. In the left navigation bar, click **List of instances**, find the target instance, and click **Enter instance**.

2. In the left navigation bar of the Standard Edition instance page, click **Namespace**.

3. On the **Namespace** page, find the target namespace and click` ...` in the **Actions** column. Then, select **Modify**.

4. Modify the namespace configuration information. For parameter descriptions, see [Create namespace](https://docs.byteplus.com/en/docs/cr/create-a-namespace?lang=en).

5. Click **Confirm** to complete the modification.
