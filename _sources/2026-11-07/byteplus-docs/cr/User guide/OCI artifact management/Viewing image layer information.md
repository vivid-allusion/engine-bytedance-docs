You can view the layer information of an image on the image tag details page. The layer information includes the size, identifier, and build command for each image layer.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">This action is only applicable to Standard Edition instances.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the target instance.

   1. Log in to the [CR console](https://console.byteplus.com/cr).

   2. Select the target region in the top navigation bar.

   3. In the left navigation bar, click **List of instances**, find the target instance, and click **Enter instance**.

2. Log in to the OCI artifact overview page.

   1. In the left navigation bar of the Standard Edition instance page, click **OCI Artifact Repositories**.

   2. On the **OCI artifact repository** page, click the name of the target OCI artifact repository.

3. View image layer information.

   1. In the **Image list** section, click the target image tag.

   2. On the OCI artifact details page, click **layer information**.

   3. On the **layer information** page, view the size, identifier, and build command of the image layer.
