You can batch modify the public/private types of OCI artifacts in the same namespace.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the target instance.

   1. Log in to the [CR console](https://console.byteplus.com/cr).

   2. Select the target region in the top navigation bar.

   3. In the left navigation bar, click **List of instances**, find the target instance, and click **Enter instance**.

2. On the left navigation bar of the instance page, click **OCI artifact repository**.

3. On the **OCI artifact repository** page, select the namespace where the target OCI artifact is located.

4. Select the target OCI artifact.

5. Click **Edit**.

6. On the **Batch editing** page, select the new public/private type.

7. Click **confirm** to complete the operation.
