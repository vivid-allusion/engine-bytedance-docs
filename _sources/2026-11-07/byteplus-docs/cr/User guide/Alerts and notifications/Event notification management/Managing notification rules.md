This article describes methods for disabling, enabling, editing, and deleting notification rules.

<span id="Kz2Fcg1S"></span>
## Disable/enable rules

You can release the quota used by enabled rules by disabling them; disabled rules can be enabled again.


1. Log in to the CR consoleCR console.

2. Select the target region in the top navigation bar.

3. In the left navigation bar, click **Event notification**.

4. In the Actions column of the target rule, click **disable** or **enable**.

5. On the secondary confirmation page, click confirm.


<span id="QEQIaIJ0"></span>
## Edit rules

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">You cannot update the instance to which the rule applies.</div>



1. Log in to the CR consoleCR console.

2. Select the target region in the top navigation bar.

3. In the left navigation bar, click **Event notification**.

4. In the Actions column of the target rule, click **edit**.

5. Modify the rule configuration information. For parameter descriptions, see [Create image push notification rule](https://docs.byteplus.com/en/docs/cr/Create_notification_rules?lang=en).

6. Click **Confirm**.


<span id="oVPNubF5"></span>
## Delete a rule

You can delete currently unused rules to free up quota slots. You can release the quota of rules by deleting them.


1. Log in to the CR consoleCR console.

2. Select the target region in the top navigation bar.

3. In the left navigation bar, click **Event notification**.

4. In the Actions column of the target rule, click ** ...**  \> Delete.

5. In the confirmation dialog box, click **delete**.
