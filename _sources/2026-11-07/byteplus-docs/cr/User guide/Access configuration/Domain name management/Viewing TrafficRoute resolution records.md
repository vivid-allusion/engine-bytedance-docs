When you create a custom domain name through TrafficRoute, the system automatically configures the relevant resolution records for you. This topic describes how to view the resolution records that are automatically configured.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure

Domain name resolution records can be viewed by using the following two methods, based on the access source of the domain name.

<span id="VPC"></span>
### VPC


1. Log in to the [PrivateZone console](https://console.byteplus.com/TrafficRoute/dns/private-zone).

2. On the **Domain management** page, search for and click the target domain name.

3. On the **DNS records** tab, view the resolution record.


<span id=".5YWs572R"></span>
### Public


1. Log in to the [DNS console](https://console.byteplus.com/TrafficRoute/dns/public-zone).

2. On the **Domain management** page, click the target domain name.

3. On the **DNS records** tab, view the resolution record.
