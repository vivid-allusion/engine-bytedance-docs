TRAE Enterprise Console provides a data analytics dashboard that displays overall usage data for your enterprise, including member data, member activity trend, core usage metrics, and more.

<span id="c209b6ec"></span>
## Open the dashboard

Use the following steps to open the dashboard on TRAE Enterprise Console.


1. Log in to the [TRAE Enterprise Console](https://console.enterprise.trae.ai/).

2. Go to **Enterprise management** \> **Data Analytics**.

   This directs you to the following dashboard.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/1e9492a249d64c239d1460e18f96fcc3) </span>

3. (Optional) Set filter options, including members and time range.

4. (Optional) Click the **Export** button in the upper\-right corner to export the data analytics report.


<span id="987c4ac3"></span>
## Statistics reference

The statistical definitions for each data analytics dashboard are as follows:


|**Category** |**Metric** |**Statistical definition** |
|---|---|---|
|Member Data |Total Active Members |The number of members who use AI features in TRAE IDE or TRAE Plugin (deduplicated by account). |
||IDE Active Members |The number of members who use AI features in TRAE IDE (based on account). |
||Plugin Active Members |The number of members who use AI features in TEAE Plugin (based on account). |
|Member Activity Trend |Total users |The total number of users using TRAE IDE and TRAE Plugin per day within the selected time range. |
||IDE users |The number of members using TRAE IDE per day within the selected time range. |
||Plugin users |The number of members using TRAE Plugin per day within the selected time range. |
|Core Usage Metrics |AI Generation Rate |Accepted AI\-generated code / (manually written code + <br><br>accepted AI\-generated code) x 100%. |
||AI Generated Lines of Code |Total lines of code generated by chats and auto\-completions. |
||CUE Recommendation Count |Total number of code recommendations. |
|Code Generation Trends in Conversations |Generated code lines |The number of lines of code generated by chats within the selected time range. |
||Accepted code lines |The number of lines of code generated by chats that were accepted, within the selected time range. |
|CUE Recommended Code Trends |Recommended code count |The number of code recommendations given by CUE within the selected time range. |
||Accepted code count |The number of code recommendations given by CUE that were accepted, within the selected time range. |
|MCP Ranking |\- |MCP servers with the highest number of calls within the selected time range (call count is aggregated by tool). |
|Enterprise Agent Ranking |\- |The call count ranking of enterprise agents. |
|LLM Call Distribution |\- |The distribution of models used in chats. |
|Programming Language Distribution |\- |The distribution of programming languages for accepted code in chats. |
