Agents are programming assistants designed for various development scenarios. TRAE provides built\-in agents and also supports creating custom agents—by flexibly configuring prompts and toolsets, they can assist you more efficiently in completing complex development tasks.

In TRAE Enterprise, you can create enterprise agents. After creation, these agents will be visible and available to all members of your enterprise, facilitating team collaboration and the sharing of agent capabilities.

<span id="b83d1cdd"></span>
## Create an enterprise agent

You can build custom agents using either intelligent generation or manual creation.


1. In the chat input box, enter  **@** , then click the **Create Agent** button at the bottom of the pop\-up panel.

   This directs you to the **Create Agent** panel.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/bac61724c96a44abb23f35f63a090db1) </span>

2. Set **Type** to **Enterprise\-dedicated Agents**.

3. Select a method to create the agent, including smart generation and manual creation. For detailed instructions, refer to [this article](https://docs.trae.ai/ide/agent).

4. Click the **Save** or **Save and Submit** button at the bottom.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">Note   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Enterprise\-dedicated agents will automatically pass review upon submission.   </div>

## Enable/disable an enterprise agent

An enterprise agent is enabled by default after creation. All members of the enterprise can use it in TRAE IDE and TRAE Plugin. You can manage its enabled status in the TRAE Enterprise Console.


1. Log in to the [TRAE Enterprise Console](https://console.enterprise.trae.ai/).

2. Go to **Enterprise Setup** \> **Enterprise Agent**.

   You will enter the enterprise agent list, which displays all agents created by members within the enterprise.

3. Find the target agent, then toggle its switch on in the **Enable** column.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/8ec80126c9de4a0a99d9f45f872931f8) </span>

## Edit/delete an enterprise agent

Only the agent creator can edit or delete agents they have created.


1. Open TRAE IDE or TRAE Plugin.

2. Go to **Settings** \> **Agents**.

3. In the **Enterprise\-dedicated Agents** list, find the to\-be\-deleted agent created by you.

4. Click the gear icon on its right side.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/03de590d5be34a44a3a6849aee559927) </span>

5. In the menu, select **Edit** or **Delete**, then complete the corresponding operation.
