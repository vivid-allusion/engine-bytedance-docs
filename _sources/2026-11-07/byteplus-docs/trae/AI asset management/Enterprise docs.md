To use in\-house enterprise knowledge as context for AI chat, you can create enterprise document sets. These document sets are visible and available to all members of your enterprise, helping the team unify knowledge base and improve the accuracy of AI responses.

<span id="83ac8b1c"></span>
## Storage space limit

2 GB

<span id="4f924b8b"></span>
## Create an enterprise doc set


1. Log in to the [TRAE Enterprise Console](https://console.enterprise.trae.ai/).

2. Go to **Enterprise Setup** \> **Enterprise Docs**.

3. In the upper\-right corner of the page, click the  **+ New Document Set** button.

   This directs you to the document set creation panel.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/8f86438c7993401aa8ebad7091c3786c) </span>

4. Enter a name and description for the document set, then upload files (supported formats: .md, .txt, .pdf; individual file size ≤ 10 MB).

5. Click the **Save** button.

   In the **Indexing & Docs** \> **Enterprise Doc** section of the IDE, all enterprise members can see and use the documents you have added.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/ff05aeebc10c445d8240f0da3de3a252) </span>


<span id="c40206a9"></span>
## Edit/delete an enterprise doc set

You can edit or delete the document sets you have created as needed.


1. Log in to [TRAE Enterprise Console](https://console.enterprise.trae.cn/).

2. Go to **Enterprise Setup** \> **Enterprise Docs**.

3. In the document set list, find the target document set.

4. In the **Actions** column, click  **···**  \> **Edit**/**Delete**, then complete the relevant operation.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/f796577e754d47da88e390837f5557db) </span>

## Use an enterprise doc set in chat

In the chat input box, use  **#Doc** to reference one or more document sets as context.
