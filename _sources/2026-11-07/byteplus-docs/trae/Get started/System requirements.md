Before installing and using TRAE Enterprise clients, ensure your device meets the following system requirements. TRAE Enterprise clients support the three major operating systems: Windows, macOS, and Linux, and specifies corresponding minimum and recommended hardware configuration.

<span id="37ac30bf"></span>
## Operating system


|**Type** |**Supported Versions** |**Supported Architectures** |
|---|---|---|
|Windows |Windows 10, Windows 11 (recommended) |64\-bit (x64) |
|macOS |macOS 10.14 and above (12.0 and above recommended) |Apple Silicon (M series), Intel x64 |
|Linux |Debian/Ubuntu series, RHEL/CentOS/Fedora series |x64、ARM64 |


<span id="c7d61f4e"></span>
## **System configuration**


|**Level** |**Requirements** |**Expected Result** |
|---|---|---|
|Minimum configuration |* **Processor**: Intel i3 or AMD processor with equivalent performance<br><br>* **Memory**: 4GB RAM<br><br>* **Storage**: 2GB available disk space<br><br>* **Network**: Stable internet connection (AI features require connectivity) |Enables smooth day\-to\-day use of TRAE Enterprise clients, including code editing, project management, and basic AI capabilities. Response times may be slower when handling large projects or frequently invoking AI features. |
|Recommended configuration |* **Processor**: Intel i5 or AMD processor with equivalent performance<br><br>* **Memory**: 8GB or more RAM (16GB recommended for complex projects)<br><br>* **Storage**: 4GB or more available disk space (including AI model cache)<br><br>* **Version**: Windows 11, macOS 12.0 and above, Ubuntu 20.04 and above |Delivers a much smoother development experience, with faster response times for code completion, code generation, multi\-file analysis, and AI chat in medium to large projects. |
