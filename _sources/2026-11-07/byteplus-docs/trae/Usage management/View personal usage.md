In the [TRAE Enterprise Console](https://console.enterprise.trae.ai/), go to **Account Center** \> **Personal Usage** panel to view your session usage, CUE usage, and usage details.

## **Session usage**

On the **Session Usage** tab, you can view statistics for your session usage:


|**Category** |**Statistic** |**Description** |
|---|---|---|
|TRAE Built\-in Models |Basic usage |Amount consumed by TRAE built\-in models from the basic usage quota of the subscribed plan. This statistic includes total usage, and you can view the individual usage for each model. |
||Excess usage |Amount consumed by TRAE built\-in models outside the basic usage quota of the subscribed plan. This statistic includes total usage, and you can view the individual usage for each model. |
|Enterprise Built\-in Models |\- |Token usage for third\-party models integrated by the enterprise. This statistic includes total usage, and you can view the individual usage for each model. |
|Code Generation Trends in Conversations |Generated code lines |Total number of code lines generated by models in sessions. |
||Accepted code lines |Total number of code lines generated by models in all sessions that were accepted by you. |

## **CUE usage**

On the **CUE Usage** tab, you can view statistics for your usage of CUE:


|**Category** |**Statistic** |**Description** |
|---|---|---|
|CUE Usage |CUE total consumption |Total number of tokens consumed by CUE. |
|CUE Recommended Code Trends |Recommended code count |Total number of suggested edits provided by CUE. |
||Accepted code count |Total number of suggested edits provided by CUE that were accepted by you. |

## **Usage details**

On the **Usage Details** tab, you can view detailed information about your usage of TRAE built\-in models. Each record includes the following fields:


|Time |The time when the session occurred. |
|---|---|
|Member |The username and email address of the member who initiated the session. |
|Client |The client where the session occurred: TRAE IDE or TRAE plugins. |
|TRAE Built\-in Model |The TRAE built\-in model used in the session. |
|Session ID |The unique identifier for each complete session. Double\-click the TRAE avatar in the session flow to view detailed information. |
|Token Consumption |The total number of tokens consumed in each complete session. To view detailed input and output data, you need to export the usage data. |
|Amount Spent |The amount corresponding to the total number of tokens consumed in each complete session. Calculated based on the list price of the invoked model. |
|Model Calls |The total number of times the model is called in each complete session. |
|Consumption Source |The source of token and amount consumption: basic usage or excess usage. |
