A resource package is a prepaid USD balance that can be used to cover AI model usage beyond the token quota included in an enterprise plan. Once the plan quota is exhausted, usage fees are deducted from the resource package balance, allowing enterprise members to continue using AI features in TRAE clients without interruption.

Usage fees are calculated based on the actual number of tokens consumed and the list price of the model used. Formula: token usage × model token list price.

For more information about resource packages, refer to [Resource package](https://docs.byteplus.com/docs/trae/billing-items).

The steps to purchase a resource package are as follows:


1. Log in to the [TRAE Enterprise Console](https://console.enterprise.trae.ai/).

2. Go to **Enterprise Management** \> **Subscription Management**.

3. In the **Resource package** area, click the **Buy resource package** button.

   This directs you to the resource package purchase page of TRAE Console on BytePlus

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/bc203a12917347f6a920bbc92f1a0c9f) </span>

4. Select a resource package of a desired quota, set a quantity, then follow the on\-screen instructions to complete the purchase process.

   Afterwards, you can click the **Subscription details** button on the **Resource package** area on TRAE Enterprise Console to view the details of each resource package, including used quota, remaining quota, expiration time, and more.
