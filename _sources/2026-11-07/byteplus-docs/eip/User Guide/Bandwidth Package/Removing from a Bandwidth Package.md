This topic describes how to remove an Elastic IP Address (EIP) from a Bandwidth Package.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [EIP console](https://console.byteplus.com/eip/eips).

2. In the top menu bar, select the region and project of your target EIP.

3. In the EIP list, click  **··· \> Remove from Bandwidth Package** to the right of the target EIP. A confirmation dialog box appears.

4. Click **Remove** to complete the action.


<span id=".5pON5L2c57uT5p6c"></span>
## Result


* The EIP is removed from the Bandwidth Package without affecting the service. The original maximum bandwidth of the EIP is reactivated.

* For the billing items (the bandwidth fee and traffic fee) for the EIP before it is added to a Bandwidth Package, they are billed immediately.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">An EIP applied from the Bandwidth Package console will be billed on <a href="https://docs.byteplus.com/en/docs/eip/Pay-as-you-go#.5oyJ5a6e6ZmF5rWB6YeP6K6h6LS5">pay\-by\-data\-transfer</a> basis after being removed from the Bandwidth Package, with a maximum bandwidth of 100 Mbps.   </div>
