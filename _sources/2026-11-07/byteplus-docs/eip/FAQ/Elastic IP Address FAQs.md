## Features & limits

<span id=".5LiA5Liq6LSm5Y-35pyA5aSa5Y-v55Sz6K-35aSa5bCR5Liq5YWs572RSVDvvJ8="></span>
### What is the maximum number of EIPs a single account can apply for?

You can apply for up to 20 Elastic IP Addresses (EIPs) in a single region under a single account.

<span id=".55Sz6K-35YWs572RSVDlpLHotKXmmK_ku4DkuYjljp_lm6DvvJ8="></span>
### Why does applying for an EIP fail?

Possible causes:


|Cause |Description |
|---|---|
|Quota exceeded |* If you reach the quota limit on the EIP quantity under the current account, the EIP application will fail.<br><br>* If the AllocateEipAddress calls of the day exceed twice the quota limit, the EIP application will fail. |
|Insufficient balance |* When the sum of your account's available balance and coupons applicable to the EIP is less than USD 100.00, or the available balance is 0, the application for a Pay\-as\-you\-go EIP will fail.<br><br>* When the sum of your account's available balance and coupons applicable to the EIP is insufficient to cover the cost of a Subscription EIP, its application will fail. |
|Network lag |If payment for a Subscription EIP fails due to network lag, the application may also fail. |
|Request parameter error |When calling AllocateEipAddress, incorrect request parameters will cause the failure of EIP application. |


<span id=".5YWs572RSVDlnLDlnYDmmK_lkKbkvJrlj5jljJbvvJ8="></span>
### Will an EIP change?

No. The EIP does not change when an Elastic Compute Service (ECS) instance is started or stopped. However, it may be released upon resource expiration or account arrearage. Once released, the EIP cannot be recovered.​

<span id=".5YWs572RSVDliqDlhaXliLDlhbHkuqvluKblrr3ljIXpnIDopoHmu6HotrPku4DkuYjopoHmsYLvvJ8="></span>
### What are the requirements for adding an EIP to a Bandwidth Package?

To add an EIP to a Bandwidth Package, the following conditions must be met:


* Both are in the same region.

* Both have the same protection type.

* The billing method of the EIP is Pay\-as\-you\-go.

* The protocol of the Bandwidth Package is IPv4.


<span id=".5YWs572RSVDjgIHnp4HnvZFJUOOAgemrmOWPr-eUqOiZmuaLn0lQ5LmL6Ze05pyJ5L2V5Yy65Yir77yf"></span>
### What is the difference between EIP, Private IP, and HAVIP?


|IP type |Description |
|---|---|
|EIP |BytePlus Elastic IP Address is a cloud resource that includes EIPs and Internet egress bandwidth, used by ECS instances to access the Internet. For more details, see [What is Elastic IP Address](https://docs.byteplus.com/en/docs/eip/What-is-EIP). |
|Private IP |A BytePlus Private IP is an IP address in a CIDR block allocated by a VPC. It is for local area network (LAN) and wide area network (WAN) communication within private network. It cannot be used to access the Internet. For more details, see [Network planning](https://docs.byteplus.com/en/docs/vpc/Network-planning). |
|HAVIP |A special private IP resource that you can separately create and release. It is for switching primary and secondary ECSs or network interfaces. For more information, see [High-Availability Virtual IP Address overview](https://docs.byteplus.com/en/docs/vpc/HAVIP-overview). |


<span id=".5YWs572RSVDor6_ph4rmlL7lkI7mlK_mjIHmib7lm57lkJfvvJ8="></span>
### Can I recover an EIP after mistaken release?

Yes. You can recover EIPs with common BGP (multi\-ISP) released after May 28, 2024, that have not been applied for by another users. For more information, see [Applying for a specified EIP](https://docs.byteplus.com/en/docs/eip/Apply-for-a-designated-EIP).

In the following scenarios, you cannot recover released EIPs:


* EIPs with enhanced protection and Anycast EIPs cannot be recovered once released.

* This month, the number of EIP recovery requests in the same region has reached the limit (3 requests) for this account.

* This EIP is in an IP address pool and has been allocated to another user.


<span id="OhISsxXY"></span>
### Why does the execution of EIP Direct script report errors or fail?

Before running the script, confirm that your private network environment can access the data source address (100.96.0.96). If the network is unreachable, the configuration will fail. If you need help, please[ submit a ticket](https://console.byteplus.com/workorder/create/).

<span id="Q5BlByn6"></span>
### How do I check the traffic of an EIP? What should I do if traffic is abnormal?

After associating an EIP with a cloud resource, you can view its traffic in the **Data Monitoring** tab of the EIP instance. Abnormal traffic on a Pay\-as\-you\-go EIP may incur unexpected charges. Refer to the following table for troubleshooting steps.


|Troubleshooting step |Anomaly |Solution |
|---|---|---|
|Log in to the EIP console, and view [traffic monitoring](https://docs.byteplus.com/en/docs/eip/Viewing-monitoring-data) details. |Persistent abnormal traffic |Check whether background processes or public network services are still running on the ECS. |
||Sudden abnormal traffic |Check the source of the abnormal traffic and choose a solution.<br><br><br>* Sudden increase due to normal business traffic:​<br><br>   * Increase the bandwidth cap:​ If the current EIP bandwidth cap cannot meet business demand, [add the EIP to a Bandwidth Package](https://docs.byteplus.com/en/docs/eip/Adding-an-EIP-to-a-Bandwidth-Package) for bandwidth increase.<br><br>   * Purchase a Traffic Package: For Bandwidth Packages **billed by main traffic** and EIPs **billed by outbound traffic**, we recommend purchasing a flexible, cost\-effective [Traffic Package](https://docs.byteplus.com/en/docs/Trafficpackage/What_is_Shared_Traffic_Package) during traffic spikes.<br><br>* Abnormal traffic caused by network attack: Your EIP may experience sudden bandwidth or traffic spikes due to malicious attacks or traffic scraping, resulting in charges higher than usual. Abnormal charges confirmed to be caused by attacks will not be refunded after the EIP bill is issued.​ We recommend enabling access control (IP/UA blocklists/allowlists, Referer hotlink protection), security protection (DCDN edge protection), and usage alerts (cost/traffic alarms).  |

### What is the BytePlus ASN?

An Autonomous System Number (ASN) is a unique identifier used to identify an autonomous system on the Internet. Select the BytePlus ASN according to the region:


* Within China: **AS137718**.

* Overseas regions: **AS150436**.

## Association

<span id=".5YWs572RSVDmlK_mjIHnu5Hlrprlk6rkupvkupHotYTmupDvvJ_mmK_lkKbmlK_mjIHlnKjkuI3lkIzkupHotYTmupDkuYvpl7TliIfmjaLvvJ8="></span>
### Which cloud resources support EIP association? Can I switch the association between different cloud resources?

EIPs can be associated with the following cloud resources: Elastic Compute Service (ECS), Classic Load Balancer (CLB), Network Load Balancer (NLB), Application Load Balancer (ALB), NAT Gateway, secondary network interface, IP address, and High\-Availability Virtual IP Address (HAVIP). And EIPs support switching between them.

You can query an EIP in the console and view its associated cloud resource on the details page. To switch the associated resource, [disassociate](https://docs.byteplus.com/en/docs/eip/Disassociating-Cloud-Resource-from-an-EIP) the EIP from the current resource first, then [associate](https://docs.byteplus.com/en/docs/eip/Associating-Cloud-Resources-with-an-EIP) it with the new one.

### How many ECSs can one EIP serve?

An EIP can be associated with only one ECS in the same region. However, multiple servers within the same Virtual Private Cloud (VPC) can share one EIP through an Internet NAT gateway to communicate with the Internet. For more information, see [What is NAT Gateway](https://docs.byteplus.com/en/docs/natgateway/What-is-NAT-Gateway) .

<span id=".5aaC5L2V5pu05o2i5LqR5pyN5Yqh5Zmo55qE5YWs572RSVDvvJ8="></span>
### How do I change the EIP of an ECS?

To change the EIP associated with the primary private IPv4 address of an ECS's primary network interface, you first [apply for an EIP](https://docs.byteplus.com/en/docs/eip/Applying-for-an-EIP), [disassociate](https://docs.byteplus.com/en/docs/ecs/Disassociating-an-EIP) the current EIP from the ECS, and [associate](https://docs.byteplus.com/en/docs/ecs/associating-an-EIP) a new EIP with the ECS.

To change the EIP associated with the secondary private IPv4 address of an ECS's primary network interface or with the secondary network interface of the ECS, see [Network Interface > Associating/Disassociating an EIP](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP).

<span id=".5YWs572RSVDmmK_lkKbmlK_mjIHot6jlj6_nlKjljLrnu5HlrprvvJ8="></span>
### Can I associate an EIP across availability zones?

Yes. EIPs have no availability zone attribute. You can associate an EIP with a cloud resource as long as this target cloud resource is in the same region as the EIP.

<span id=".5YWs572RSVDmmK_lkKbmlK_mjIHot6jlnLDln5_nu5HlrprvvJ8="></span>
### Can I associate an EIP across regions?

No. For example, you cannot associate an EIP in China (Beijing) with an ECS in China (Shanghai).

## Access to Internet

<span id=".5aaC5L2V6K6_6Zeu5YWs572R77yf"></span>
### How to access the Internet?

By default, a Virtual Private Cloud (VPC) you build is isolated from the Internet, and different VPCs cannot communicate with each other. To connect to the Internet, you must [establish Internet access](https://docs.byteplus.com/en/docs/vpc/Application-scenarios).

<span id=".5Li65LuA5LmI5LqR5pyN5Yqh5Zmo5a6e5L6L57uR5a6a5YWs572RSVDku43nhLbml6Dms5Xov57mjqXkupLogZTnvZHvvJ8="></span>
### Why can't an ECS instance still connect to Internet after associating an EIP?

Possible causes:


* The security group does not allow required traffic. Check whether the security group associated with your ECS instance allows your target outbound and inbound traffic. For procedure, see [Managing a security group rule](https://docs.byteplus.com/en/docs/vpc/Managing_a_security_group_rule).

   > If you configure a firewall within the ECS instance, you must also configure traffic ports for the firewall.   
   

* Network Access Control List (ACL) does not allow required traffic. Check whether the Network ACL associated with the subnet of your ECS instance allows your target traffic. For more details, see [Network ACL overview](https://docs.byteplus.com/en/docs/vpc/Network-ACL-overview) and [Adding/Deleting a Network ACL rule](https://docs.byteplus.com/en/docs/vpc/Managing-network-ACL-rules).

* The EIP is in an abnormal status, such as Suspended due to expiration or account arrearage.

* After allowing new ports, restarting the ECS is required to apply the changes.


<span id=".5Li65LuA5LmI5LqR5pyN5Yqh5Zmo572R57uc6K6_6Zeu5bu26L-f6auY77yf"></span>
### Why is the network latency of the ECS high?

Possible causes:


* Cross\-border access: When your ECS is deployed in China, accessing international websites may cause higher or unstable network delays.

* High remote connection latency: Depends on your network environment, computer performance, and remote connection settings. Troubleshoot and optimize based on the following:

   * Switch to a better network, and close other high\-traffic applications or devices to reduce network pressure.

   * Adjust remote connection settings: Higher resolution and color depth increase data transmission volume and delay. We recommend lowering the display settings of the remote desktop, such as resolution and color depth.

   * Identify if bandwidth rate limiting exists by [viewing monitoring data](https://docs.byteplus.com/en/docs/eip/Viewing-monitoring-data). You can [increase the maximum bandwidth](https://docs.byteplus.com/en/docs/eip/Modifying-the-maximum-bandwidth) or [add to a Bandwidth Package](https://docs.byteplus.com/en/docs/eip/Adding-an-EIP-to-a-Bandwidth-Package) to improve bandwidth utilization.

* Shared ECS instance limits: In [shared instances](https://docs.byteplus.com/en/docs/ecs/Shared) with non\-associated CPU scheduling mode, the system randomly allocates each vCPU to any idle CPU hyper\-threading. vCPUs from different instances may compete for physical CPU resources, leading to unstable compute performance under high load. We recommend using a non\-shared instance to resolve this issue.


<span id=".5aaC5L2V6YCa6L-H5LqR5pyN5Yqh5Zmo6L6F5Yqp572R5Y2h57uR5a6a55qE5YWs572RSVDorr_pl67lhaznvZHvvJ8="></span>
### How to access the Internet via EIP associated with the ECS's secondary network interface?


1. Attach the secondary network interface to the ECS. For procedure, see [Attaching/Detaching a secondary network interface](https://docs.byteplus.com/en/docs/vpc/Loading-or-unloading-a-secondary-network-interface#.5oyC6L296L6F5Yqp572R5Y2h).

2. Log in to the ECS to configure the secondary network interface. For procedure, see [Configuring secondary network interfaces for ECS instances](https://docs.byteplus.com/en/docs/ecs/Configuring-auxiliary-network-interfaces-for-ECS-instances).

3. Check whether the secondary network interface route meets the requirements. If not, configure its route. For procedure, see [Modify network interface routes](https://docs.byteplus.com/en/docs/ecs/Configuring-auxiliary-network-interfaces-for-ECS-instances#WeoBIl26).

4. Associate an EIP. For procedure, see [Associate an EIP](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP#.57uR5a6a5YWs572RSVA=).

5. Log in to the ECS and execute the command `ping 8.8.8.8 -I <ENI, such as eth1>` to specify accessing the Internet through the EIP associated with the secondary network interface.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">To set the secondary network interface's EIP as the default for Internet access, you must set the priority of secondary network interface route to the highest.   </div>
   

<span id=".5LqR5pyN5Yqh5Zmo5pei6YWN572u5LqGTkFU572R5YWz77yM5Y-I57uR5a6a5LqG5YWs572RSVDvvIzlhbbpgJrov4flk6rnp43mlrnlvI_orr_pl67lhaznvZHvvJ8="></span>
### If an ECS has both a NAT gateway and an EIP configured, which method does it use to access the Internet?

The ECS accesses the Internet through the EIP.

<span id=".5Li65LuA5LmI5peg5rOVUGluZ-mAmue7keWumuWFrOe9kU5BVOe9keWFs-eahOWFrOe9kUlQ77yf"></span>
### Why can't I ping the EIP associated with the Internet NAT gateway?

Because the Internet NAT gateway does not support ICMP reply packets. That is, when an internet client `pings` the EIP associated with the Internet NAT gateway, the Internet NAT gateway does not return any data.

<span id="usU3InLp"></span>
### How to access the Internet using an IPv6 address?

If you need to use an IPv6 address for Internet access, please contact your account manager to enable the IPv6 feature. Once enabled, you can apply for an IPv6 address for Internet access. For details, see [Configuring an IPv6 Gateway for IPv6 Internet access](https://docs.byteplus.com/en/docs/IPv6/Configure_an_IPv6_gateway_to_access_the_IPv6_public_network).

## Access control

<span id=".5a2Q55So5oi36L-b5YWs572RSVDliJfooajpobXpnaLvvIzkuLrku4DkuYjmmL7npLrlvZPliY3lrZDnlKjmiLfmmoLml6DmnYPpmZDvvJ8="></span>
### Why does an IAM user see "No permission" when accessing the EIP list page?​

When accessing the EIP list, the system selects all projects by default. Switch to a specific project or contact the root account for authorization as prompted.​

<span id=".5a2Q55So5oi36LCD55SoIERlc2NyaWJlRWlwQWRkcmVzc2VzIOaOpeWPo--8jOaPkOekuuaXoOadg-mZkO-8nw=="></span>
### Why does an IAM user get a "No permission" error when calling the DescribeEipAddresses API?

Two scenarios:


* The IAM user lacks both global and project\-scoped query permissions for the EIP. Contact your root account for authorization or use an IAM user with proper permissions.

* The IAM user has query permissions for the EIP only at the project scope (not global). When calling the DescribeEipAddresses API, you must provide the `ProjectName` or `AllocationIds.N` parameter.


<span id=".5Li65LuA5LmI5a2Q55So5oi35peg5rOV5p-l55yL55uR5o6n5pWw5o2u77yf"></span>
### Why can't IAM users view monitoring data?

If an IAM user has permissions for the EIP and wants to view its monitoring data, the root account to which the IAM user belongs must also grant the required CloudMonitor permissions to the IAM user.


1. Log in to the [IAM console](https://console.byteplus.com/iam/identitymanage/user) using the root account to which the IAM user belongs.

2. In the left\-side navigation pane, select **User management \> User** to access the User page.

3. Click the username of the IAM user to be authorized.

4. In the **Policy \> Directly Add Policy**, click **Authorize** to access the Add authorization page, and check system\-managed CloudMonitor permissions for the IAM user as needed.

   
   |Policy name |Supported action |
   |---|---|
   |CloudMonitorFullAccess |Management permissions for CloudMonitor. With this policy, the IAM user can both view monitoring data and use features of the CloudMonitor. |
   |CloudMonitorReadOnlyAccess |Access permissions for CloudMonitor. With this policy, the IAM user can view monitoring data only. |
   

5. Click **Submit** to complete the action.

### How can IAM users use tag features?

<span id=".5q2l6aqk5LiA77ya5Yib5bu65qCH562-562W55Wl"></span>
#### Step 1: Create a tag policy


1. Log in to the[ IAM console](https://console.byteplus.com/iam/identitymanage/user) using the root account to which the IAM user belongs.

2. In the left\-side navigation pane, select **Permission policy**.

3. On the **Permission policy** page, click **Create Policy**, and type the policy name and content. The reference content is as follows:

   ```Plain Text
   {        
             "Statement":[        
                          {        
                            "Effect":"Allow",        
                            "Action":[        
                                       "vpc:TagResources",
                                       "vpc:UntagResources",
                                       "vpc:ListTagsForResources"
                                      ],        
                                       "Resource":[        
                                                    "*"
                                                    ]
                             }
                           ]
           }
   ```
   

4. Click **Submit** to complete the action.


<span id=".5q2l6aqk5LqM77ya5Li65a2Q55So5oi35re75Yqg5qCH562-562W55Wl"></span>
#### Step 2: Add the tag policy to the IAM user


1. Log in to the [IAM console](https://console.byteplus.com/iam/identitymanage/user) using the root account to which the IAM user belongs.
