Elastic IP Address (EIP) and its internet egress bandwidth are IP connectivity services provided by BytePlus that can be purchased and held independently for cloud resources. An EIP supports direct attachment to cloud servers, including Elastic Compute Service (ECS), Elastic Bare Metal (EBM) servers, and GPU cloud servers. It also supports attachment to Internet NAT Gateway, Classic Load Balancer (CLB), secondary network interfaces, and other components to provide internet connectivity for cloud servers, meeting various business scenarios.
