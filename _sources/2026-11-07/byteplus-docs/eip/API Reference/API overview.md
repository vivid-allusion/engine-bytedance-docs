Elastic IP address (EIP) provides the following OpenAPI.

<span id="A4GHUm8X"></span>
## EIP instances


|API name |Feature |
|---|---|
|[AllocateEipAddress](https://docs.byteplus.com/en/docs/eip/AllocateEipAddress) |Apply for an EIP. |
|[ModifyEipAddressAttributes](https://docs.byteplus.com/en/docs/eip/ModifyEipAddressAttributes) |Modify the name, description, and maximum bandwidth of an EIP. |
|[DescribeEipAddresses](https://docs.byteplus.com/en/docs/eip/DescribeEipAddressAttributes) |Query EIPs that meet the specified conditions. |
|[DescribeEipAddressAttributes](https://docs.byteplus.com/en/docs/eip/DescribeEipAddresses) |View details of the EIP |
|[AssociateEipAddress](https://docs.byteplus.com/en/docs/eip/AssociateEipAddress) |Associate an EIP with a cloud resource. |
|[DisassociateEipAddress](https://docs.byteplus.com/en/docs/eip/DisassociateEipAddress) |Disassociate the EIP with the cloud resource. |
|[TemporaryUpgradeEipAddress](https://docs.byteplus.com/en/docs/eip/TemporaryUpgradeEipAddress) |Temporarily increase the maximum bandwidth of a Subscription EIP |
|[ReleaseEipAddress](https://docs.byteplus.com/en/docs/eip/ReleaseEipAddress) |Release an EIP. |


<span id="zVjiuvzF"></span>
## IP address pools


|API name |Feature |
|---|---|
|[CreateIpAddressPool](https://docs.byteplus.com/en/docs/eip/CreateIpAddressPool) |Create an IP address pool. |
|[DescribeIpAddressPools](https://docs.byteplus.com/en/docs/eip/DescribeIpAddressPools) |Query details of created IP address pools by conditions. |
|[DescribeIpAddressPoolAttributes](https://docs.byteplus.com/en/docs/eip/DescribeIpAddressPoolAttributes) |View details of the specified IP address pool. |
|[AddIpAddressPoolCidrBlock](https://docs.byteplus.com/en/docs/eip/AddIpAddressPoolCidrBlock) |Add IP address CIDR blocks to the specified IP address pool. |
|[DescribeIpAddressPoolCidrBlocks](https://docs.byteplus.com/en/docs/eip/DescribeIpAddressPoolCidrBlocks) |Query CIDR block information of the specified IP address pool. |
|[ModifyIpAddressPoolAttributes](https://docs.byteplus.com/en/docs/eip/ModifyIpAddressPoolAttributes) |Modify the name and description of an IP address pool. |
|[DeleteIpAddressPoolCidrBlock](https://docs.byteplus.com/en/docs/eip/DeleteIpAddressPoolCidrBlock) |Delete the specified IP CIDR blocks from the IP address pool. |
|[DeleteIpAddressPool](https://docs.byteplus.com/en/docs/eip/DeleteIpAddressPool) |Delete the IP address pool. |
