To help developers and operators using the APMPlus SDK (hereinafter referred to as "you") carry out third\-party SDK business in compliance with applicable laws, regulations, policies, and standards, and to better implement the requirements for personal information protection, and also to facilitate your clearer understanding of the compliance of the APMPlus data business and the security protection technologies we have adopted, especially the methods and measures for protecting personal information and privacy, we, as the provider of the APMPlus SDK, Beijing BytePlus Technology Co., Ltd. (hereinafter referred to as "BytePlus" or "we"), have formulated the "APMPlus SDK Developer Compliance Specifications" (hereinafter referred to as the "Compliance Specs") to help you meet the corresponding compliance requirements during your use of the APMPlus SDK.

# 1. Compliance requirements for developers regarding personal information protection

The following content mainly provides an interpretation of the key compliance requirements regarding the collection and use of personal information during your use of the APMPlus SDK.

<span id="xyXkyJT5"></span>
## 1. SDK business functions and optional information configuration description

**Integration instructions**: SDK initialization does not collect personal information. Ensure the APMPlus SDK is initialized only after the user has agreed to your app's privacy policy. Before the user agrees to the privacy policy, avoid dynamically applying for sensitive device permissions that involve user personal information. And before that, you should avoid privately collecting and reporting personal information. When your app is not providing services to users, for example, when the app is running in the background, do not request services from the APMPlus SDK. For specific initialization timing, see the relevant documentation for details. For the Android platform, see [Integrating SDK into Android applications](https://docs.byteplus.com/en/docs/apmplus/Integrate_the_Android_SDK_into_the_application). For the iOS platform, see [Integrating SDK into iOS applications](https://docs.byteplus.com/en/docs/apmplus/Integrate_the_iOS_SDK_app).

### Optional personal information configuration (Android)

You can select whether to use the APMPlus SDK to obtain optional personal information for data calculation and analysis purposes. For Android, you can disable the collection of certain device information using the following API:

```Java
import com.apm.applog.AppLog;

// Disable device OAID collection (optional)
AppLog.setOAIdEnabled(false);
// Disable device GAID collection (optional)
AppLog.setGAIdEnabled(false);
// Disable OS version collection (optional)
AppLog.setEnableOsVersion(false);
// Disable device model collection (optional)
AppLog.setEnableDeviceModel(false);
// Disable screen resolution collection (optional)
AppLog.setEnableDisplay(false);
```


**Note**:


* All the above configuration items are optional. Developers can decide whether to disable the corresponding information collection based on their own business scenarios and privacy compliance requirements.

* If developers wish to further reduce the scope of personal information collection on the device side, we recommend completing the above configuration before SDK initialization.

* Developers should ensure consistency among notification, authorization, and the actual collection scope, based on their own privacy policy, pop\-up authorization logic, and actual collection practices.


Different versions of the SDK may obtain different field information. To ensure end\-user security and service feasibility, BytePlus will continuously update the SDK version to enhance security. BytePlus will notify you of SDK version updates via internal messages or other means. Please update the SDK version in a timely manner. Any issues arising from failure to update promptly shall be resolved by you, and you shall bear full responsibility.

4.
