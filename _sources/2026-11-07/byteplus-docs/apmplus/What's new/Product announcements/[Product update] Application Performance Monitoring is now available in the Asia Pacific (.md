Starting from 00:00:00 Beijing time on April 20, 2026, Application Performance Monitoring will officially be available for sale in the Asia Pacific (Jakarta) region. To ensure stability and fault tolerance, it is recommended to select the region closest to the target resources to reduce network latency and improve access speed. For more information about service availability, see: [Service region](https://docs.byteplus.com/en/docs/apmplus/server-launching_region).


* The Asia Pacific (Jakarta) region currently does not support features related to service topology.

* The pricing in Asia Pacific (Jakarta) is the same as in other overseas regions. For more details about pricing, see: [Server side billing explanation](https://docs.byteplus.com/en/docs/apmplus/Server_side_billing_instructions).
