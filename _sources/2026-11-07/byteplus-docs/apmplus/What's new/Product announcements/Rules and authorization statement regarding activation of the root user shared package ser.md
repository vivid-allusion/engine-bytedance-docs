Dear  customer,

The root user shared package service ("this service") is a customized service provided to you by  Application Performance Management Plus ("APMPlus"). This service enables all applications created under the same root user to preferentially consume resources from the shared package.

If you need to activate this service, you understand and agree to the following service usage rules and authorization statement (the "Statement"):


1. You understand that the prerequisite for activating this service is that any application created by your root user account [account name & ID] in the APMPlus console already has a corresponding monitoring package for its platform.

2. You understand that after this service is activated, if there is no data reporting or the reporting switch is disabled, this service will not consume any resources.

3. When you create a new application under your root user account, you understand and agree to authorize us to generate a postpaid billing order for you in order to fulfill the purpose of this service.

4. You understand that once this service is activated, it cannot be undone. This means you cannot revert to purchasing and consuming packages independently for each application. This is a one\-way activation process.


Matters not expressly stipulated in this statement will be governed by the provisions of other applicable agreements or service rules entered into between you and the  platform.

If you require activation, please **submit a ticket** to inquire about activation.
