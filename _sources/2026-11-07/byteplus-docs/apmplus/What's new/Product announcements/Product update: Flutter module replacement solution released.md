Dear user,

The Flutter module in client monitoring reached EOM on October 22, 2024, and the official Flutter SDK is no longer provided. Currently, to facilitate unified invocation on the Flutter side, developers have designed the `APMPlusBridge` class, which encapsulates all details of native platform communication and allows reporting and monitoring of custom errors, custom events, custom logs, and other monitoring data related to Flutter applications via the Flutter\-to\-Native bridge method. For more details, see: [APMPlus Flutter bridge native SDK integration guide](https://docs.byteplus.com/en/docs/apmplus/APMPlus_Flutter_bridge_native_SDK_integration_guide).
