This topic describes how to query the full list of error codes when calling the APMPlus API.

<span id="HWUYs8bZ"></span>
## Error code types

The platform supports two types of error codes.

<span id="xcL5ngLr"></span>
### Platform\-level public error codes

CodeN starts with `1000`. For details, see [Public error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).

<span id="dvIyycrV"></span>
### Cloud product error codes

Error codes specific to a cloud product include public error codes of the cloud product and API\-specific error codes. The HTTP status codes include `4xx` and `5xx`. See [OpenAPI Center](https://api.volcengine.com/api-docs/view/errorcode?serviceCode=apmplus_server&version=2026-01-01) for details.

To the right of "Error code", click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_65183e460835e9b275060a725a2d4df0.png) </span> icon to query the desired information.<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_367e4e94c0de0b066dddf5aa9ae269fd.png) </span>
