The console provides OpenAPIs for applications, resource usage, services, and other targets. By calling these APIs, you can use the corresponding features on the console.

<span id=".5bqU55So"></span>
## Application


|**API name** |**Feature** |
|---|---|
|[CreateApp](https://docs.byteplus.com/en/docs/apmplus/CreateApp) |Create an application |
|[GetAppList](https://docs.byteplus.com/en/docs/apmplus/GetAppList) |Get the application list |
|[DeleteApp](https://docs.byteplus.com/en/docs/apmplus/DeleteApp) |Delete applications |
|[UpdateApp](https://docs.byteplus.com/en/docs/apmplus/UpdateApp) |Update applications |


<span id=".6LWE5rqQ55So6YeP"></span>
## Resource usage


|**API name** |**Feature** |
|---|---|
|[GetAccountQuotaUsedTrend](https://docs.byteplus.com/en/docs/apmplus/GetAccountQuotaUsedTrend) |Get the resource usage trend of the root user |
|[GetAidQuotaUsedTrend](https://docs.byteplus.com/en/docs/apmplus/GetAidQuotaUsedTrend) |Get the resource usage trend of a specified service for a specified application |
