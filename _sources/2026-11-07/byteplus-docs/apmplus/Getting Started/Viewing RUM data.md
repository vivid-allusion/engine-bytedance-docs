After integrating an application and activating the service, you can view the monitoring data of the integrated application in the console. This helps you troubleshoot crash issues, check health status, and optimize performance. This topic describes how to view monitoring data in the console by using App Monitoring.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [RUM console](https://console.byteplus.com/observe/apmplus-client).

2. On the **Client Monitoring** page, click **App Monitoring** for the target application.

3. Click **All functions \> Real\-time Statistic** to view statistics on commonly used core metrics and alerts. This provides a dashboard with real\-time data refresh, which is commonly used to observe metric changes in real time after a version is released.

4. Click **All functions \> Crash trend** to view the collection and analysis results of multiple crash types on both iOS and Android platforms. This helps you accurately analyze issues.

5. Click **All functions \> Lag trend** to monitor whether main thread message execution times out. This effectively helps you analyze smoothness issues that users experience while using the App.

6. Click **All functions \> Event trend** to view reported custom metrics. This helps you better monitor and analyze application performance issues.

   For more features, see [Feature overview](https://docs.byteplus.com/en/docs/apmplus/What_is_App_Monitoring).
