APMPlus provides benefits such as low\-cost integration, end\-to\-end monitoring, and comprehensive coverage for AI scenarios across the entire chain. This enables you to quickly locate issues and improve service quality. This topic describes the typical application scenarios of APMPlus.

<span id="PzohUDQD"></span>
## AI cloud\-native inference

AI\-ServingKit enables enterprises to run mainstream inference models efficiently, stably, and cost\-effectively on large\-scale GPU clusters through container orchestration, AI gateways, end\-to\-end inference observability, and distributed caching.

Leveraging features such as non\-intrusive SDKs, automatic framework instrumentation, automatically generated TraceIDs, and preset dashboards and alert rules that fully cover the end\-to\-end path from inference engines to GPUs, APMPlus provides end\-to\-end observability in the AI\-ServingKit solution. It collects metrics for APIG instances, inference engines, GPUs, and other resources to detect SLO metric fluctuations in a timely manner. Compared with traditional observability, end\-to\-end observability reduces integration time by 80 percent and reduces troubleshooting time by 70 percent. This achieves transparent end\-to\-end instrumentation and minute\-level inference issue localization.

## LLM end\-to\-end monitoring

APMPlus features transparent integration without instrumentation, compatibility with mainstream open\-source frameworks, and end\-to\-end monitoring for self\-managed inference scenarios. It provides a low\-cost observability solution for LLMs and supports end\-to\-end monitoring for LLMs across various deployment modes.
