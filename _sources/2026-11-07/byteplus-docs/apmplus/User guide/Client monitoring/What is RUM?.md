APMPlus RUM provides comprehensive monitoring and analysis capabilities, including app, WebPro, Mini Program Pro, Mini Program, PC, and OS monitoring.

## App Monitoring

App Monitoring supports tracking and analyzing exception scenarios via exclusive technical methods. It comprehensively monitors and analyzes applications on iOS, Android, and HarmonyOS. This covers various crash types, comprehensive performance analysis, custom event logging, memory optimization, event analysis, battery analysis, and error analysis. For more details, see [What is app Monitoring?](https://docs.byteplus.com/en/docs/apmplus/What_is_App_Monitoring)

## WebPro Monitoring

WebPro Monitoring generally refers to web monitoring. It supports monitoring for browser pages, in\-app H5 pages, and Electron applications. It offers flexible data collection and consumption methods. Additional capabilities include support for multi\-page applications, single\-page applications, micro frontend applications, and cross\-platform applications, as well as diverse lifecycle monitoring and more flexible customization. Key capabilities include blank screen monitoring, custom monitoring, and version management. Additionally, it supports blank screen root cause analysis, performance analysis, detailed user action replay, and real\-time alerts for new errors in specified versions. For more details, see [What is WebPro monitoring?](https://docs.byteplus.com/en/docs/apmplus/What_is_monitoring_on_the_WebPro_platform)

## Mini Monitoring

Mini Monitoring provides free JS error analysis and page load performance analysis for Douyin Mini Programs, WeChat Mini Programs, and Alipay Mini Programs.

## Mini Pro Monitoring

Mini Pro Monitoring analyzes startup performance, requests, page performance, JS errors, and page loading performance for mini programs on platforms such as Douyin, WeChat, Alipay, Baidu, and Feishu. It supports native mini programs and third\-party frameworks such as UniApp and Taro. Key features include setData frequency monitoring, custom monitoring, and performance monitoring. In addition, an overall performance score quantifies the performance of mini programs, helping you quickly track and analyze issues. For more details, see [What is Mini Pro monitoring?](https://docs.byteplus.com/en/docs/apmplus/What_is_Mini_Pro_Monitoring)
