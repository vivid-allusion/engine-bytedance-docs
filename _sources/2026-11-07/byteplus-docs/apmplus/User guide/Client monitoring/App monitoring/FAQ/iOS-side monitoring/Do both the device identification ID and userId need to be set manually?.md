---
title: "Do both the device identification ID and userId need to be set manually?"
product: "Application Performance Management Plus"
product_code: "apmplus"
source: "https://docs.byteplus.com/en/docs/apmplus/Do_both_the_device_identification_ID_and_userId_need_to_be_set_manually"
---

The apmConfig.deviceIDSource in the settings can be either automatically generated or customized. If it is automatically generated, you do not need to manually set the device identifier. For details, refer to [iOS SDK integration](https://docs.byteplus.com/en/docs/apmplus/Integrate_the_iOS_SDK_app). You must set the userID manually.
