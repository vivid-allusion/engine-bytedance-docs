---
title: "If two mini programs are connected to the same App Monitoring (using the same AppID), how can you distinguish between them?"
product: "Application Performance Management Plus"
product_code: "apmplus"
source: "https://docs.byteplus.com/en/docs/apmplus/If_two_mini_programs_are_connected_to_the_same_App_Monitoring_how_can_you_distinguish_between_them"
---

Using the same AppID makes it impossible to distinguish between different mini programs. You can try using the major version of the app to distinguish between different programs; however, this method is not recommended in production environments.
