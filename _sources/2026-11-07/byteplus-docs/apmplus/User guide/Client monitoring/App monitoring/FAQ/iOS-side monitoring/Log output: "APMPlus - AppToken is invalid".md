**Logs output**


* Integrate the iOS SDK: `APMPlus - AppToken is invalid`

* Integrate the iOS component monitoring SDK: `APMPlus - *{appid}* 's AppToken is invalid`


**Processing step** Please check whether the AppToken entered when integrating the SDK into the application is correct. For detailed actions, please view [How to view AppID and AppToken?](https://docs.byteplus.com/en/docs/apmplus/Query_AppID_and_AppToken).
