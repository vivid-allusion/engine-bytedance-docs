---
title: "Can Android be initialized in a background thread?"
product: "Application Performance Management Plus"
product_code: "apmplus"
source: "https://docs.byteplus.com/en/docs/apmplus/Can_Android_be_initialized_in_a_background_thread"
---

Except for the initialization of performance\-related features, which must be initialized on the main thread, there is no strict requirement for other initializations. They can be initialized on a secondary thread. For details, refer to [Android SDK integration](https://docs.byteplus.com/en/docs/apmplus/Integrate_the_Android_SDK_into_the_application).
