---

* By importing the 'OOM' module, you can view OOM crashes. To view leaks and large objects, you need to import the 'MemoryGraph' module.

* If you have introduced 'MemoryGraph' but still cannot see the data, please first check whether the trigger method is correct in the *Memory optimization* section of *Access validation*.

* Because the memory files generated by MemoryGraph are relatively large, the backend samples the data during reception. After triggering memory analysis, you can restart multiple times, then go to the platform and view the data.
