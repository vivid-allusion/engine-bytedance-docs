---

Yes. You can filter data in crash analysis using the custom dimension **Is 64\-bit device**.


1. Log in to the [Application Performance Monitoring End-to-End Edition Console](https://console.byteplus.com/observe/apmplus-client).

2. Click **App Monitoring** under the target application.

3. In the upper left corner of the console, select **All features \> Crash analysis**.

4. On the **Crash Analysis** page, under custom dimensions, add a filter for **whether it is a 64\-bit device**, and assign values according to business needs.

5. View data in crash trends and crash details.
