---
title: "Is real device testing required for iOS, lag, and page experience, or is it not possible to collect data for these using a simulator?"
product: "Application Performance Management Plus"
product_code: "apmplus"
source: "https://docs.byteplus.com/en/docs/apmplus/Is_real_device_testing_required_for_iOS_lag_and_page_experience"
---

iOS OOM testing must be performed on a real device. There are no requirements to test for lag or page experience, but testing on a real device is still recommended for optimal results.
