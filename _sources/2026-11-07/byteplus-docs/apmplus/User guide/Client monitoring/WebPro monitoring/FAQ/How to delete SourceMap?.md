title: "How to delete SourceMap?"
product: "Application Performance Management Plus"
product_code: "apmplus"
source: "https://docs.byteplus.com/en/docs/apmplus/How_to_delete_SourceMap"
---

Currently, SourceMap does not support deletion. If the wrong SourceMap is uploaded, you can overwrite the original SourceMap file by re\-uploading it with the same file name and version number.
