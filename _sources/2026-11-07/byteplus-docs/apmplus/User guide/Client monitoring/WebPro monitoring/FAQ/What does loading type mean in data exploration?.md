In data exploration, the loading type indicates the source of PV event triggers and includes four types: init, hash, history, and user_set.


* **init**: PV triggered when first entering the page.

* **hash**: PV reporting triggered by hash changes.

* **history**: PV reporting triggered by changes in history.

* **user_set**: Manually reported PV.
