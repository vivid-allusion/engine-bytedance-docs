If you have reported data but it is not displayed on the platform, you can use the **Reporting self\-monitoring** feature to troubleshoot and resolve the issue yourself. For more information, refer to [Report from Monitoring](https://docs.byteplus.com/en/docs/apmplus/report_self-monitoring).
