White screen monitoring targets white screens that occur due to unexpected page errors.

<span id=".55m95bGP5oC76KeI"></span>
## The white screen overview

Indicator descriptions are as follows:


|**Metric** |**DescriptionS** |
|---|---|
|Number of white screens |Number of white screen occurrences under filter conditions |
|The number of users affected by white screen |Number of unique visitors who encountered a white screen under filter conditions |



* The white screen overview displays the number of white screens and, for users affected by white screens, the trends and attribution.

* The white screen trend displays a bar chart showing the number of white screen incidents caused by four factors: JavaScript errors, request exceptions, static resource exceptions, and unknown causes.

* White screen attribution displays a pie chart showing the proportion of white screens caused by JavaScript errors, static resource exceptions, request exceptions, and white screens with unknown cause.


<span id=".55m95bGP5Y6f5Zug"></span>
## Causes of a white screen

<span id=".SlPplJnor68="></span>
### JavaScript error


* The JS error page displays error details, start and end time, number of blank screens, and number of users affected by blank screens.

* Expanding the error details allows you to view the aggregated url, DOM score, screenshot, pid, and reporting time for the same type of JS error that caused a blank screen. Click **Go to data exploration** to view more reporting information.

   The parameter description is as follows:

   
   |**Metric** |**DescriptionS** |
   |---|---|
   |url |The URL when a white screen occurs. |
   |dom score |Traverse the DOM tree starting from document.body. Each time a visible DOM element is encountered, increment the score based on the element's level, and calculate the resulting score sequentially. The smaller the value, the higher the white screen count. |
   |Screenshot |The picture generated by capturing the interface when a white screen occurs allows users to observe the actual effect of the white screen. |
   |pid |The pid corresponding to the SDK at the time of reporting. |
   |Report time |The time when the white screen occurs. |
   

* Click the error content to navigate to the error details page, where you can view detailed information and stack trace information, making it easier to troubleshoot issues.


<span id=".6K-35rGC5byC5bi4"></span>
### Request error


* The request exception page displays the request path, the distribution of exception status codes, the number of blank screens, and the number of users affected by blank screens.

* Expand the request path to view the request URL, DOM score, screenshot, PID, and reporting time. Click **Jump to Data Exploration** to view more reporting information.

* Click the request path to navigate to the request list, where you can view detailed information and stack information to facilitate better troubleshooting.


<span id=".6Z2Z5oCB6LWE5rqQ5byC5bi4"></span>
### Static resource exceptions


* The static resource page displays the static resource path, the number of blank screens, and the number of users affected by blank screens.

* Expanding the static resource path allows you to view the static resource URL, DOM score, screenshot, PID, and reporting time. Click **Jump to Data Exploration** to view more reporting information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">On the data exploration page, you can view information under the <strong>Resource Errors</strong> tab and analyze the causes of static resource exceptions.   </div>
   

* Click the static resource path to navigate to the static resource list and view detailed request information and stack traces, making it easier to troubleshoot issues.


<span id=".5peg5rOV5b2S5Zug"></span>
### Unattributable


* The unattributable page supports clicking **jump to data exploration** to view the session details for each white screen occurrence. You can identify the cause of each white screen by analyzing the session context.

   For example, you can check whether any JS errors occurred before the white screen event. Click the logs under JS errors to view the error details.
