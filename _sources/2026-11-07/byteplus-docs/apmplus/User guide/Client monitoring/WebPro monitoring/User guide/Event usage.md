Event usage is closely related to billing. You can periodically view event usage in the webpro interface and make adjustments based on your business needs.


1. Log in to the [Application Performance Management Plus console](https://console.byteplus.com/observe/apmplus-client/console/overview).

2. Click the target application name to enter the **Application Service Management** page.

3. Under **WebPro Monitoring**, click **usage details**.

4. In **Usage Trends**, view event usage for the webpro side.

   Usage trends page supports filtering event usage by time.

5. (Optional) If you want to adjust the event sampling rate for a specific class, please make adjustments in the **project configuration** according to the table below.

   
   |**Metric** |**Modify paths** |**Affected feature modules** |
   |---|---|---|
   |static resources |resources monitor |resources overview \> all resources |
   |Ajax request |request monitor |Request overview \> All requests |
   |longtask |Not supported yet |\- |
   |Performance |Site performance |site performance overview |
   |custom event |custom monitor |custom monitor |
   |custom log |||
   |Action |Not supported |\- |
   |PV |Not supported yet |\- |
   |JS error |JavaScript error |JavaScript overview |
   |static resource error |Monitoring static resource errors |Resources overview \> Error resources |
   |blank screen |blank screen monitoring |blank screen monitoring |
