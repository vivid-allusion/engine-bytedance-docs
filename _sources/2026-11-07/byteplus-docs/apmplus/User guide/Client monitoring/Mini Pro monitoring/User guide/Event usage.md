Event usage is closely related to billing. You can regularly view event usage in Mini Program Pro Monitoring and make adjustments based on your actual business scenarios.


1. Log in to the [Application Performance Management Plus console](https://console.byteplus.com/observe/apmplus-client/console/overview).

2. Click the target application name to enter the **Application Service Management** page.

3. Under **Mini Program Pro Monitoring**, click **Usage details**.

4. In **Usage trends**, view the event usage for Mini Program Pro.

   The usage trend page supports filtering event usage by time.

5. Optional: If you want to adjust the event sampling rate for a specific class, please make the adjustment in the **project configuration** according to the table below.

   
   |**Metric** |**Modify paths** |**Affected feature modules** |
   |---|---|---|
   |Performance |performance monitor |performance monitor |
   |request |request monitor |request overview |
   |PV |Not supported |\- |
   |JavaScript error |JavaScript error |JavaScript overview |
   |custom event |custom monitor |custom monitor |
   |custom log |||
