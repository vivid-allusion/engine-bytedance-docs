This article introduces the SDK's compatibility with native mini programs and third\-party frameworks.

<span id=".5Y6f55Sf5bCP56iL5bqP5YW85a655oCn"></span>
## Native mini programs compatibility


|**Feature** |**WeChat Mini Program** |**TikTok Mini Program** |**Alipay Mini Program** |**Baidu Mini Program** |**Lark Mini Program** |
|---|---|---|---|---|---|
|Basic features |Base version ≥ v2.x |Base version ≥ v1.x |≥ v2.x |≥ v3.x |The host must have Lark version ≥ 5.0 |
|Performance(FP、FCP、LCP) |Base version ≥ v2.21.2 |Base version ≥ 1.60.0 |Not supported |Not supported |Not supported |
|Http profile |Base library version ≥ 2.10.4 |Base library version ≥ 2.42.0 |Not supported |Not supported |Not supported |

|**Frameworks** |**Taro** |**Uni App** |
|---|---|---|
|Supported versions |≥ v3.x |≥ v3.x |
