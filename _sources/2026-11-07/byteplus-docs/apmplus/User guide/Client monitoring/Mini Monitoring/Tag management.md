In JavaScript error monitoring, in addition to assigning an assignee and updating the status for a large number of error issues, it is necessary to add custom tags to different issues from both a business perspective and a feature module perspective.

<span id=".5Yqf6IO95YWl5Y-j"></span>
## Feature entry point

You can go to **platform setting \> tag management** to add modules and tags, then select the corresponding content in the issue list.

<span id=".5Yqf6IO95L2_55So"></span>
## Feature usage

After adding a tag to an issue, you can quickly filter issues by tag using the filter at the top of the issue list.
