Use page analysis to view page data and analyze page exceptions to improve user experience.

<span id=".6aG16Z2i5qaC6KeI"></span>
## page overview

The page overview displays the core metrics for all pages in the mini program. Pages are displayed according to Pid (Page_id).

For pages you want to focus on, you can click the checkbox in the first column on the left to pin it to the top. You can sort by each metric.


* Click **network request error rate** to navigate to the **page analysis \> error statistics and tracking \> network error** page, where you can view the trend, distribution, and details for individual errors of network errors.

* Click **JavaScript error rate** to navigate to the **Page analysis \> Error statistics and tracking \> JavaScript error** page, where you can view the trends, distribution, and details for individual JavaScript errors.

* Click **slow page rate** to be redirected to **Page analysis \> Error statistics and tracking \> Slow page analysis**, where you can view the trends, distribution, and single\-point information of slow pages.


<span id=".5byC5bi457uf6K6h5ZKM6L-96Liq"></span>
## error statistics and tracking

At the bottom of the page, single\-point information is displayed by default.

 &nbsp;

If "Aggregate by error type" is checked, the related issue list will be displayed.

 &nbsp;

Above the list, you can query three types of fields: URL, user ID, and session ID.
