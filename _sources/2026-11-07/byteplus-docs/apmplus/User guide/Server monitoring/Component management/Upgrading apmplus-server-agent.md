The server\-agent primarily collects observability data, such as host metrics, business logs, and traces. New feature releases or bug fixes typically accompany add\-on version updates. We recommend upgrading to the latest version to ensure that the add\-on functions normally.

The server\-agent add\-on requires manual upgrading. The procedure is as follows:


1. Log in to the [VKE console](https://console.byteplus.com/vke/overview). Click **Cluster** in the left navigation pane and click the target cluster.

2. In the cluster management page, select **Addons** in the left navigation pane, and find the apmplus\-server\-agent add\-on in the Monitoring tab.

3. Click **Upgrade** in the upper\-right corner of the add\-on card to upgrade the add\-on to the latest version.
