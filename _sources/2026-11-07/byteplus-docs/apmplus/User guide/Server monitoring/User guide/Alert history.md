## View alert history


1. Log in to the [Application Performance Management Plus](https://console.byteplus.com/observe/apmplus-server/console/overview) console.

2. In the left navigation bar, click **server\-side monitoring**.

3. Select the region for server launch

4. Click the **Click to enter the server side list** button next to **server\-side monitoring**.

5. In the upper left corner of the console, select **alert management \> alert history**.

6. On the alert history page, view the trigger history of all alert tasks.

   Alert history supports two display methods: aggregated display and tiled display.

   * Aggregated display: Multiple triggers of the same alert are consolidated into a single row to prevent the alert histories of different rules from being interleaved, thereby increasing information density.

      Expand the event overview to view an individual alert history entry under this alert rule.

   * Flat view: Display a single alert history entry in reverse chronological order.
