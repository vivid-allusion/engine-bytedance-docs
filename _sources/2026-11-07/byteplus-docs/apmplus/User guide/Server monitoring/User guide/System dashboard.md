The application performance monitor provides preset dashboards for host performance, disk, and platform service self\-monitoring.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">All system dashboards provide features such as filtering by workspace and time range.</div>


<span id="57c89ff3"></span>
## Host performance

Provides trend charts for the host's **machine load**, **CPU usage**, and **memory usage**.


* Supports filtering by workspace, time, and host name.

* Supports modifying the refresh time.


<span id="d406d4c1"></span>
## Disk

Provides trend charts for the disk's **iowait**, **io latency**, **read throughput**, **write throughput**, **read QPS**, and **write QPS**.


* Supports filtering by workspace, time, and host name.

* Supports modifying the refresh time.


<span id="39c0abb8"></span>
## Platform self\-monitoring

Provides trend charts for the **backend data receiving service** and **server agent**.


* Supports filtering by workspace and time.

* Supports modifying the refresh time.
