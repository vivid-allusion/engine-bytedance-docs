### **1. Product Overview**

Material management is divided into 3 parts, namely Regular Materials, Trajectory Material, and My material. **Regular Materials** allow for the upload of images/videos/audio/copy, which can be conveniently used in future marketing strategy scenarios; **Trajectory Material** is used in the context of Enterprise WeChat, where after sending a web page link of the trajectory material to the customer, user visit information can be acquired; **My material** allows for the import of some material data (such as basic information of financial products), which can be directly inserted into the content reached.

### **3. Function Explanation**

 **(1) Regular Materials**

Material Management Center can support adding, grouping, viewing, and editing resources. Click 'Add Article' to add new image/video/audio/copy materials.

 **(1.1) Add Article**

Click "Add Article" to upload resources, supporting either single or batch uploads. Supports uploading text, images, videos, and audio resources. Multiple files can be uploaded at a time, each file must be less than 2GB.


* Image formats supported include png/jpg/jpeg/bmp/gif.

* Video format supported is mp4.

* Audio format is limited to wav/mp3.

* Copy needs to be bulk imported according to the template requirements.

 **(1.2) Use of resources after uploading**

In Placement, Official Account Group Message, Public Account Active Message, App Pop\-up, Webhook, and other functions, resources can be cited.


* Landing Page: Supports calling resources from the material library while editing the landing page.

* Placement: Supports invoking resources from the material library while editing placements.

* Webhook: supports the selection of material packages to send during webhook option insertion

* Intelligent Touchpoint: supports the selection of Material Library content on personalized placement

* Message Delivery \- Image Upload Widget: supports calling materials from the Material Library when editing the Message Delivery\-Image Upload Widget

* Process Canvas \- The Image Upload Widget supports calling materials from the Material Library during Process Canvas\-Image Upload Widget editing
