#### Process Canvas Data Analysis

After the task runs, you can click "Data Analysis" to view the data performance of the task.

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/15550b1a7b614ed0a8a438a3aa87588c~tplv-goo7wpa0wc-image.image" width="439px" /></div>


Process Canvas data analysis includes two parts: overall performance and step\-by\-step performance. Overall performance allows viewing of the entire Process Canvas data, whereas step\-by\-step performance enables viewing of data for each node of the Process Canvas.

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f528494b274641c78720d20418616258~tplv-goo7wpa0wc-image.image" width="1919px" /></div>


Data fields for each atomic node:


| |Field meaning and purpose |
|---|---|
|Node name |Displays the configured node name; clicking on configuration details can expand the configuration page for that node. |
|Node ID |The node name is followed by the node ID |
|Entry Volume |The number of times or people entering this node |
|Ready to Send Volume |The number of IDs/people that meet the conditions of this node and the filtering criteria (do not disturb, frequency control, etc.) |
|Send Volume |The number of messages sent by GMP. |
|Delivered Volume |The actual number delivered by the downstream channel, this indicator depends on the receipt data from the downstream channel. |
|Key Metrics Data |If focused metrics are set in the node, the data of the focused metrics will be displayed below the metrics |
