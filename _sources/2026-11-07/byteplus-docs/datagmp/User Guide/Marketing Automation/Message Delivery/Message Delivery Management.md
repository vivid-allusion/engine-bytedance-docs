### **1. Product Overview**

On the "Message Delivery" page, you can filter and view by Task Type, Channels, Group, Task Name, Creator, Approval Status, and Task Status.

<span id="d00a67a4"></span>
### **2. Usage Restrictions**


| |Detailed description |
|---|---|
|**Activate GMP permissions** |Admin grants permission to create tasks; Permission path: Message Delivery \- Message Delivery Task \- Edit |


<span id="723aeec5"></span>
### **3. Function Description**

In the list, you can manage Message Delivery Tasks; different management methods apply depending on the task status:


* In Approval tasks: Supports view, copy, approve, and expedite operations.

* Rejected tasks: Supports view, copy, and rejection reason (view) operations

* Draft tasks: Supports view, edit, copy, and delete operations.

* Running tasks: Supports view, copy, data analysis, pause, and cancel operations.

* Task paused: Supports viewing, copying, data analysis, restarting, and canceling operations

* Task canceled: Supports operations for viewing, copying, and data analysis

* Task completed: Supports operations for viewing, copying, and data analysis

* Abnormal task: Supports operations for viewing, copying, and data analysis
