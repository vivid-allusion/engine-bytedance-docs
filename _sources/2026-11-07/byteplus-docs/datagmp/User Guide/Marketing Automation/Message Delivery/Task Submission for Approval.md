### **1. Feature Description**

**1.1 Submit for Approval**

After task creation is complete, it needs to be submitted for approval. The approval process can be configured in "Approval Management".

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0107ac0893bc4a3d8a829970980b2e45~tplv-goo7wpa0wc-image.image" width="439px" /></div>



| |Field Definitions and Purposes |
|---|---|
|Approver |Confirm approvers when submitting: the applicant can preview approval nodes and corresponding approvers when submitting; once confirmed, the approver will not change.<br><br>Initiator's Choice: In the——, set the approver as "Initiator's Choice".<br><br><br>* Clicking on the Initiator's Choice node will display the configured approver candidates on the right side.<br><br>* The initiator can select appropriate approvers from the set approver candidates.<br><br><br>Designated Members: In the——, set the approver as "Designated Members".<br><br><br>* Applicants do not need to choose an approver, they only need to confirm the approver. |


All the requests I submitted can be viewed in "My Requests" at the top right corner.

**1.2 Perform Approval**

All tasks that need my approval can be viewed in "My Approvals". The number of pending approvals updates every 5 minutes.
