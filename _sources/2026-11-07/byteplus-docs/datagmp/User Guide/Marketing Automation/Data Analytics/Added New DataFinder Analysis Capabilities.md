If you have purchased datafinder, you can contact the Volcano staff to activate this capability; if not purchased, you can add this module.

### **Retention Analysis**

**Retention Analysis is a method used to analyze the user engagement and activity level over a specific period to understand their ongoing usage of products or services**.


| |Description |
|---|---|
|**Entry to Retention Analysis** |If you need to perform Retention Analysis, you can find the entry for 'Retention Analysis' on the navigation bar. Clicking on it will take you to the event analysis page |
|**About retention related concepts** |**Starting event and revisit event**<br><br><br>* Starting event: Refers to a key action completed by users within a specific period, such as registration, downloading the application, purchasing products, etc. This event marks the beginning of user interaction with your product or service.<br><br>* Return event: Refers to a specific action completed again by the user within a certain period after the initial event. For example, users logging in again after registering, using the application again after downloading, purchasing again after buying a product, etc.<br><br><br>By analyzing the time interval between the initial event and the return visit event, you can understand user retention. For instance, you can calculate how many users completed the return event within a specific time frame after the initial event and the proportion of these users. This helps assess user loyalty, engagement, and retention rate, and identifies factors that may affect users' re\-engagement.<br><br>**Analysis metric: Retention rate**<br><br><br>* **Retention: Refers to the users returning to the product after some time following the initial (new or user of the product) event.** <br><br>* **Retention rate: Refers to the ratio of the number of users returning to the product to the number of initial users.** <br><br>   * The rate at which users return to the product on the same day they add or use the product is counted as **daily retention rate**.<br><br>   * The rate of users returning to the product on the second day after adding or using it, referred as **next\-day retention rate**.<br><br>   * The rate of users returning to the product on the nth day after adding or using it, referred as **n\-day retention rate**.<br><br>   * The rate of users returning to the product between days 8 to 14 after adding or using it, termed as **next\-week retention rate**.<br><br>   * The rate of users returning to the product within the nth week after adding or using it, termed as **n\-week retention rate**. |
