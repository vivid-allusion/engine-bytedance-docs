# Application Scenarios


|**Application Scenarios** |**Business Scenario Application Instructions** |
|---|---|
|New User Incentives |* **User Introduction Period Breakpoint Marketing**<br><br><br>When a user arrives on the platform but has not yet completed registration, real\-name authentication, card binding, or other key behaviors affecting the first conversion, immediately guides the user to complete the corresponding actions through Benefits.<br><br><br>* **New User First Conversion Guidance and Incentives**<br><br><br>When a new user registers as a member, immediately distribute a new user gift package via the Benefit Platform to guide the user to complete the first conversion. |
|Old User Activation |* **Retention of Active Old Users**<br><br><br>For active old users, maintain their engagement through Marketing Strategy methods such as daily sign\-in tasks, benefit reminders, and level\-up guidance.<br><br><br>* **Activation/Recall of Silent and Lost Users**<br><br><br>Using intelligent algorithm models, predict silent/lost users’ potential interests in activities, products, content, or benefits, and achieve precise activation/recall. |
|Top Product Recommendations |* **Manual Selection by Operators**<br><br><br>Operators manually select top products and deliver messages to potential audiences preferring these categories but not yet purchasing them, alongside targeted in\-app placements to drive conversions.<br><br><br>* **Automatic Selection by Algorithm**<br><br><br>Using leading intelligent algorithms to model preferences of audiences and products, achieving personalized product recommendations for thousands of individuals, making "every item a top product, unique to each person." |
|Daily Operational Activities |* **Single Event Notification**<br><br><br>One\-time notifications for promotions, urgent alerts, or new features, delivered accurately to segments.<br><br><br>* **Recurring Event Notification**<br><br><br>Automated execution of recurring loop events, such as daily timed sign\-in reminders, weekly members' day flash sales, and monthly members' benefits collection, all set up once.<br><br><br>* **Automatic Trigger Notification**<br><br><br>Whenever a user places an order but does not complete payment within a certain time or when a purchase is successful, a follow\-up reminder is sent to eligible users to facilitate final conversion. |
