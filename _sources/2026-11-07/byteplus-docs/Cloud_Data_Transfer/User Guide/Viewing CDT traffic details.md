You can view traffic usage details for cloud products that have Cloud Data Transfer (CDT) billing enabled, across all regions, in the Cloud Data Transfer console.

## Procedures

1. Log in to the [Cloud Data Transfer console](https://console.byteplus.com/cdt).

2. In the top menu bar, select the target region and project.

3. Select the **Products & Services** tab to view CDT traffic statistics and details.

   * Traffic statistics: Cross\-region service supports filtering by a specified date and interconnection type to view traffic distribution charts (distribution by interconnection type and product usage).

      * Internet services: Specify a date​ and region. View the total traffic and a pie chart (usage distribution by region and product), filtered by line type.

      * Cross\-region services: Specify a date​ and interconnection type. View a traffic distribution chart (distribution by interconnection type and product usage).

   * Traffic details: Supports viewing traffic generated by all products within the last four months (including the current month).
