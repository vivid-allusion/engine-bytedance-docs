## Instructions

* After a cloud product is enabled for Cloud Data Transfer (CDT) billing, you cannot switch back​ to its original pay\-as\-you\-go billing. Proceed with caution.

* Once a cloud product is enabled for CDT billing, its existing and newly created pay\-by\-data\-transfer instances will be automatically enabled for CDT.

   > For CDT billing rules and price details, see [Billing](https://docs.byteplus.com/en/docs/Cloud_Data_Transfer/Billing_overview).

* Before creating a cross\-border resource, ensure that your cross\-border qualification has been approved.

## Enable CDT

1. Log in to the [Cloud Data Transfer console](https://console.byteplus.com/cdt).

2. In the top menu bar, select the target region and project.

3. Select the **Products & Services** tab.

4. Click **Enable** to the right of the target cloud product in the **CDT billing status for cloud products** list.

5. Click **Confirm** to complete the action.
