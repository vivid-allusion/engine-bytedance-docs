To reduce the risk of data deletion and effectively safeguard your data security, the TOS console supports security settings. This article describes the safety setup instructions and operation steps.

<span id="6160e3d9"></span>
## Function Description

The security configuration is the dangerous operation prompt level setting. When set to a high level, when deleting data through the console, you need to manually enter confirmation information, which can effectively reduce the possibility of your misoperation. When set to a low level, there will also be a pop\-up window prompt risk, but there is no need to manually enter confirmation information.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This security configuration is only effective for buckets and will not affect your other products.</div>


<span id="d068e757"></span>
## **Procedure**

The dangerous operation prompt level is high by default. If you need to adjust it to low, please refer to the following steps to set it.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This article only describes the steps to set the prompt level on the object storage console. You can also use the TOS Browser tool to complete the security configuration. Specific steps, please refer to the <a href="https://docs.byteplus.com/docs/tos/System-settings">System Settings</a>.</div>



1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Security configurations**.

3. On the **Security configurations** page,turn off **High Level**.
