A bucket policy grants users relevant permissions on a bucket and its resources.

<span id="f363cb3d"></span>
## Applicable scenarios

Use a bucket policy if you need to:


* Authorize other accounts.

* Authorize all users.

* Set authorization conditions.

* Set different permissions for users or resources.


<span id="7cfcbe88"></span>
