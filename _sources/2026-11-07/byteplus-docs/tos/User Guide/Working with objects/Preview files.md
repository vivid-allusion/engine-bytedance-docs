TOS supports previewing images, audio, and video files in the console, allowing you to quickly view file contents. This article describes the steps to preview files.

<span id="BCVvPbst"></span>
## File formats

TOS currently supports previewing images and audio\-video files such as JPEG, PNG, MP3, MP4, and other types in the console. The TOS console relies on your current browser to preview files. If the browser can recognize the file format, you can preview it in the console; if not, the TOS console cannot preview the file. Therefore, the specific file formats previewable in the TOS console depend on your current browser's support.

<span id="5HLeoJtL"></span>
## Procedure


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation bar, click **Buckets**, then on the **Buckets** page, click the target bucket name.

3. On the **Objects** page, click **Details** under the **Actions** column of the target file to view the file content in the file details panel.

   * For audio and video files, you can click the play button to play the file in the file details panel; click  **... \> Download**, download the file; click  **...**   **\> Playback speed**, adjust the playback speed of the file.

   * For image files, you can view the image content in the file details panel.
