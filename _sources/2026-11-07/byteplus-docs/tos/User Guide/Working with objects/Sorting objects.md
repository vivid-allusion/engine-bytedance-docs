The TOS console allows you to sort objects in a bucket by filename, size, or modification time, helping you manage them more easily. This topic explains how to do that.

<span id="66d93fef"></span>
## Steps


<Tabs>
<Tab zoneid="GNnfAg2N7Z" title="Sort by filename">
<TabTitle>Sort by filename</TabTitle>

1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. In the left navigation pane, click **Buckets**. 

3. In the top menu bar, select the project of the bucket you want to manage.

4. In the Buckets list, click the bucket you want to manage.

5. On the **Objects** page, click the sort icon in the **Filename** column to sort the objects by name.

   * Ascending order

      Click the upward triangle icon to sort the objects in ascending alphabetical order by name.

   * Descending order

      Click the downward triangle icon to sort the objects in descending alphabetical order by name.


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">If the first character of multiple filenames is the same, then the second character is used for sorting, and so on.</div>



</Tab>
<Tab zoneid="I19iWMewB8" title="Sort by size">
<TabTitle>Sort by size</TabTitle>

1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. In the left navigation pane, click **Buckets**. 

3. In the top menu bar, select the project of the bucket you want to manage.

4. In the Buckets list, click the bucket you want to manage.

5. On the **Objects** page, click the sort icon in the **Size** column to sort the objects by size.

   * Ascending order

      Click the upward triangle icon to sort the objects by size, from smallest to largest.

   * Descending order

      Click the downward triangle icon to sort the objects by size, from largest to smallest.


</Tab>
<Tab zoneid="K8yYYJXzpf" title="Sort by modification time">
<TabTitle>Sort by modification time</TabTitle>

1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. In the left navigation pane, click **Buckets**. 

3. In the top menu bar, select the project of the bucket you want to manage.

4. In the Buckets list, click the bucket you want to manage.

5. On the **Objects** page, click the sort icon in the **Modification time** column to sort the objects by last modified time.

   * Ascending order

      Click the upward triangle icon to sort the objects by last modified time, from earliest to latest.

   * Descending order

      Click the downward triangle icon to sort the objects by last modified time, from latest to earliest.


</Tab>
</Tabs>
