You can search a bucket for files (by prefix) in the TOS console.

<span id="3904dc98"></span>
## **Procedure**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. In the search box in the upper\-right corner of the **Objects** page, type a file prefix and press Enter or click Refresh to get a list of files with the prefix.
