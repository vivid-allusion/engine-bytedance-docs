SenseFlow rules allow you to associate scenario\-based templates with various data scopes within a bucket, providing an intelligent, end\-to\-end experience. This experience includes data upload, automatic content awareness and indexing, multimodal retrieval, event notifications, and content generation all in one place.

This topic explains how to create a SenseFlow rule.

<div data-tips="true" data-tips-type="default">SenseFlow is currently in closed beta and is only available in China (Beijing). Please contact your account manager for access.</div>

## Steps


1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. Navigate to the **Rule management** page by doing one of the following:

   * In the left navigation pane, select **Content perception and processing** \> **Rule management**.

   * In the left navigation pane, click **Buckets**. Then, select the bucket you want to manage and click **Content perception and processing** in the left navigation pane.

3. On the **Rule management** page, click **Create rule** and configure the following parameters.

   
   |Category |Parameter |Description |
   |---|---|---|
   |Basic information |Rule name |Enter a name for the SenseFlow rule. Requirements:<br><br><br>* Length must not exceed 255 characters.<br><br>* Chinese characters, letters, numbers, hyphens (\-), and underscores (_) are supported.<br><br>* Each rule name must be unique within the same account. |
   ||Describe |Provide additional information about the rule. The description cannot exceed 50 characters. |
   |Data range |Specified range |Select the data scope to which the rule applies.<br><br><br>* **The whole bucket**: The rule applies to all objects in the bucket.<br><br>* **Specify ObjectSet**: The rule applies to the specified ObjectSet.<br><br>* **Specify Prefix**: The rule applies to objects with the specified prefix. |
   ||Bucket |Select the bucket to which the rule applies. |
   ||ObjectSet |Select the ObjectSet to which the rule applies.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">This option is available only when <strong>specified range</strong> is set to <strong>Specify ObjectSet</strong>.</div><br> |
   ||Prefix |Enter the object prefix to which the rule applies.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">This option is available only when <strong>specified range</strong> is set to <strong>Specify Prefix</strong>.</div><br> |
   ||Artifact output path |Specify where the output files (such as indexing files, summaries, and tags) will be stored within the bucket.<br><br>You can enter the path manually or click **Select folder** to choose one from the current bucket. |
   |Template parameter configuration |Template |Select a scenario\-based template for the rule.<br><br>The available system presets are the **Intelligent Security Template** and the **Media Asset Management Template**. You can also select your own custom templates. |
   

4. Click **Select** to finish creating the rule.

## Other operations

From the **Rule management** page, you can perform the following operations:


|Supported operations |Steps |
|---|---|
|View rule details |In the rule list, click the name of a rule to view its basic information. This includes **Rule name**, **Owned bucket**, **Description**, **Creation time**, **Range type**, **Scope content**, **Artifact relative path**, and **Workflow**. |
|Experience now |In the rule list, click **experience now** in the **Actions** column of a rule to select a data retrieval method and view the retrieval results.<br><br><br>* **Chat to SenseFlow**: Quickly find out how the rule works by chatting with TOS Agent. For more information, see [TOS Agent overview](https://docs.byteplus.com/en/docs/tos/TOS-Overview?lang=en).<br><br>* **Multi\-modal retrieve**: Perform multimodal retrieval on the bucket's data based on the current rule's indexing results. |
|Configure a rule |1. In the rule list, click **Configuration** in **Actions** column of the rule you want to manage.<br><br>2. On the **Edit rule** page, you can modify **Rule name**, **Description**, and **Workflow parameter configuration**.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">After creating a SenseFlow rule, you cannot change the <strong>data range</strong> to which it applies.</div><br> |
|Delete a rule |1. In the rule list, click  **... \> Delete** in the **Actions** column of the rule you want to remove.<br><br>2. In the box that appears, confirm the deletion by clicking **Delete**. |
