This topic introduces bucket\-level monitoring metrics that provide insight into traffic, billable capacity, raw capacity, and other bucket\-specific information.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Bucket\-level metrics are divided into two categories: non\-billable and billable. Non\-billable metrics do not incur charges, while billable metrics do. For example, the raw capacity of Archive storage type is a billable metric, because TOS charges for data storage.</div>
