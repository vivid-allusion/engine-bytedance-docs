This topic introduces account\-level monitoring metrics that provide insight into traffic, billable capacity, raw capacity, and other account\-specific information.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Account\-level metrics are divided into two categories: non\-billable and billable. Non\-billable metrics do not incur charges, while billable metrics do. For example, the standard retrieval capacity for Cold Archive is a billable metric, because TOS charges for data retrieval.</div>
