BytePlus Cloud Monitoring provides performance monitoring for object storage. This article describes the monitoring items related to TOS and the steps to view performance monitoring.

<span id="8e42e882"></span>
## Prerequisites

The [Cloud Monitor](https://console.byteplus.com/cloud-monitor/overview) service has been activated.

<span id="6061e9f0"></span>
## Description of monitoring items

For the description of TOS monitoring items, please refer to [Monitoring Metrics Description](https://docs.byteplus.com/en/docs/tos/Monitoring-indicator-description).

<span id="f006c87e"></span>
## View bucket monitoring data


1. Log in to [Cloud Monitor console](https://console.byteplus.com/cloud-monitor/overview).

2. In the left navigation bar, select **Cloud Service Monitor**, and choose the product name **TOS**.

3. On the **TOS** Monitoring page, select the bucket name you wish to view.

4. On the **Monitor** tab, you can view monitoring data on dimensions such as **Storage** , **QPS**, **Bandwidth**, **Latency**, and **Bucket** **status codes**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For detailed monitoring metrics, please log in to the <a href="https://console.byteplus.com/cloud-monitor/overview">Cloud Monitoring Console</a> to view.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The default view is of the monitoring data within the last 1 day. You can customize the time range for viewing, down to the minute.   </div>
