The Event Center of Cloud Monitoring offers fault monitoring capabilities. When a TOS event occurs, information such as the event time, source, name, and details are saved in the Event Center. By viewing event information, you can promptly discover and resolve issues. This article explains how to view event information.

<span id="f6be4229"></span>
## Precautions

Events that have occurred are by default saved for 30 days.

<span id="026ce3d0"></span>
## Action Steps


1. Log in to [Cloud Monitor console](https://console.byteplus.com/cloud-monitor/overview).

2. In the left navigation bar, select **Event Center \> Cloud Service Event**.

3. On the **Cloud Service Event** page, set the time range and select **object storage**.

4. Click the **Actions** column of a specific event to view detailed information about that event.
