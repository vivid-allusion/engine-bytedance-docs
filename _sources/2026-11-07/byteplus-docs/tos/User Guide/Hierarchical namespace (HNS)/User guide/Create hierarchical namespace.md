This article describes the steps to create a hierarchical namespace.

<span id="7e4c9724"></span>
## Prerequisites


* Before using TOS, make sure that you have signed up for BytePlus. For more information, refer to [Signing up for BytePlus accounts](https://docs.byteplus.com/byteplus-platform/docs/signing-up-your-account).

* For regions currently supporting the hierarchical namespace feature, see [Supported Regions](https://docs.byteplus.com/docs/tos/What-is-hierarchical-namespace#a9f27159).


<span id="98ce0124"></span>
## Precautions


* Each account and its sub account(s) can create up to 100 buckets.

* For bucket naming rules, see [Bucket](https://docs.byteplus.com/docs/tos/docs-common-concepts#bucket).

* Hierarchical buckets currently support only the standard storage type.

* For more precautions, see [Usage Notes](https://docs.byteplus.com/docs/tos/Usage-instructions).


<span id="004bcf14"></span>
## Procedure


1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. In the left navigation bar, click **Buckets**, and at the top left of the page, click **Create Bucket**.

3. In the create bucket page, set the bucket parameters and in the advanced settings area, turn on the **Hierarchical namespace** switch.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_a7d6f402a20ab89c707892281933fc6c.png) </span>

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">For further details on creating a bucket's additional parameters, see <a href="https://docs.byteplus.com/docs/tos/docs-create-a-bucket">Creating a Bucket</a>.</div>



4. After setting the parameters, click **Create**.
