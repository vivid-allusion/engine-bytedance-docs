TOS supports operations such as uploading objects to HNS buckets via Java SDK. This article introduces information such as Java SDK installation.

<span id="f1c2099b"></span>
## Install SDK

For SDK installation address and steps, see [Install Java SDK](https://docs.byteplus.com/docs/tos/Install-java-sdk).

<span id="5c2f2a4c"></span>
## Initialize client

Before using the SDK, initialize the client first. For detailed steps, see [Initialize client (Java SDK)](https://docs.byteplus.com/docs/tos/Initialize-client-side-java-sdk).

<span id="eb8eac31"></span>
## Supported features

HNS and flat buckets share most SDK features. Refer to the following documents to understand the SDK feature list and differences:


* For a complete overview of Java SDK features, see [Java SDK introduction](https://docs.byteplus.com/docs/tos/Java_sdk_introduction).

* For detailed differences, see the [API list (HNS buckets)](https://docs.byteplus.com/docs/tos/API-list-hierarchical-bucket).

* For common SDK operations, see the table below.



|Operation |Reference |
|---|---|
|CreateBucket |[Create hierarchical namespace (Java SDK)](https://docs.byteplus.com/docs/tos/Create-a-hierarchical-namespace-java-sdk) |
|ListBuckets |[List hierarchical namespaces (Java SDK)](https://docs.byteplus.com/docs/tos/List-hierarchical-namespaces-java-sdk) |
|ListObjects |[List objects in the hierarchical namespace (Java SDK)](https://docs.byteplus.com/docs/tos/List-objects-within-hierarchical-namespace-java-sdk) |
|ListObjectsV2 |[List objects in hierarchical namespace V2 (Java SDK)](https://docs.byteplus.com/docs/tos/List-objects-in-hierarchical-namespace-v2-java-sdk) |
|RenameObject |[Rename objects in the hierarchical namespace (Java SDK)](https://docs.byteplus.com/docs/tos/Rename-objects-within-hierarchical-namespace-java-sdk) |
