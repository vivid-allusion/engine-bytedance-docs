After an image style is created, you can use it to uniformly process multiple images to simplify operations. This topic describes how to use an image style.

<span id="c951c704"></span>
## **Prerequisites**

You have created an image styleas instructed in [Image Style](https://docs.byteplus.com/en/tos/docs/creating-an-image-style?version=1.0.0).

<span id="5e5fb38b"></span>
## Precautions

The image style function is in the invitation\-based testing state. If you need to use it, please contact your account manager.

<span id="5967285f"></span>
## Explanation of Fees

Image styles are free of charge, but using them to process images will incur data processing, request, and traffic fees. Specifically:


* The data processing fee covers image processing and advanced image compression.

   * The image processing fee is incurred by image resizing, watermarking, and other image processing operations. It is charged based on the actual size of the original image processed. For more information, see [Data Processing Fee](https://docs.byteplus.com/en/tos/docs/data-processing-fee?version=1.0.0).

   * The advanced image compression fee is charged separately based on the number of processing operations. It is charged only if advanced image compression is used. If you perform both resizing and advanced compression, you need to pay for processing, advanced compression, the number of requests, and traffic. For more information, see [Data Processing Fee](https://docs.byteplus.com/en/tos/docs/data-processing-fee?version=1.0.0).

* The request fee is charged by the number of GetObject requests. One GetObject request is generated by an image processing operation. For more information, see [Request Fee](https://docs.byteplus.com/en/tos/docs/request-fee?version=1.0.0).

* The outbound traffic fee over the public network is charged by processed image size. For more information, see [Traffic Fee](https://docs.byteplus.com/en/tos/docs/traffic-fee?version=1.0.0).

## **Procedure**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. Get the style name.

   1. In the left navigation pane, select **Data processing** \> **Image processing**.

   2. On the **Image processing** page, click **style** tab,get the name of the target style.

4. Get the image URL.

   In this example, the image is put in the first\-level directory of the file list.

   1. In the left navigation pane, click **Objects**.

   2. On the **Objects** page, click **Details** in the **Actions** column of the target image.

   3. In the **Basic Information** pane, click the Copy icon to the right of the **URL** to copy it.

5. Use the style to process the image.

   1. Open the image URL in your browser.

   2. Append `?x-tos-process=style/<style name>` to the image URL to get the image processed using that style.

      For example, if the image URL is `https://tos-tools.tos-ap-southeast-1.bytepluses.com/misc/sample.png` and the style is `test`, the URL of the processed image will be `https://tos-tools.tos-ap-southeast-1.bytepluses.com/misc/sample.png?x-tos-process=style/test`.
