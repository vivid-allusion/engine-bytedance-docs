TOS supports viewing multiple basic data of storage buckets, including usage, traffic, and number of requests. This article introduces the data supported by TOS and the steps to view it.

<span id="f9c9c8aa"></span>
## Precautions


* The basic overview data of a bucket comes from Cloud Monitor and there is a delay in data statistics. This data is for monitoring purposes and not for billing. It is for reference only.

* You need to have Cloud Monitor read\-only permissions to view usage statistics.


<span id="8584f38b"></span>
## Data description

The data supported by TOS are described as follows.


|**Type** |**Description** |
|---|---|
|Storage capacity |Bucket shows the raw and billed capacities for various storage types over a certain period. You can switch the statistical period at the top of the page. Description as follows:<br><br><br>* Original capacity: The actual physical capacity of this storage type.<br><br>* Billing capacity: The chargeable volume of this storage type.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">A minimum charge applies to objects in Infrequent Access Storage, Flashback Archive, Archive, Cold Archive, and Deep Cold Archive based on object size. Objects smaller than 64 KiB are charged as if they were 64 KiB. If you store objects smaller than 64 KiB in Infrequent Access Storage, Flashback Archive, Archive, or Cold Archive, the billing capacity will exceed the raw capacity.   </div><br>    |
|Retrieve capacity |Bucket: Statistics on data retrieval capacity over a certain period. Description of data retrieval capacities are as follows:<br><br><br>* IA storage data retrieval capacity: The amount of data transferred from TOS to the client when performing read operations on Infrequent Access Storage objects.<br><br>* Flashback Archive data retrieval capacity: The amount of data transferred from TOS to the client when performing read operations on Flashback Archive objects.<br><br>* Archive storage data retrieval capacity: The amount of data retrieved produced by the restore operation on Archive objects.<br><br>* Cold Archive quick retrieval capacity:The amount of data retrieved when performing a restore operation on Cold Archive objects using the fast retrieval mode.<br><br>* Cold Archive standard retrieval capacity:The amount of data retrieved when performing a restore operation on Cold Archive objects using the standard retrieval mode.<br><br>* Cold Archive batch retrieval capacity:The amount of data retrieved when performing a restore operation on Cold Archive objects using the batch retrieval mode.<br><br>* Deep Cold Archive standard retrieval capacity:The amount of data retrieved when performing a restore operation on Deep Cold Archive objects using the standard retrieval mode.<br><br>* Deep Cold Archive batch retrieval capacity:The amount of data retrieved when performing a restore operation on Deep Cold Archive objects using the batch retrieval mode. |
|Traffic |Bucket: Statistics of various types of traffic over a certain period. The explanations of each type of traffic are as follows:<br><br><br>* Outflow traffic from public network: Traffic generated when data is transmitted from TOS to the client via the internet.<br><br>* Public Network Inflow Traffic: Traffic generated when data is transmitted to TOS from the client via the internet.<br><br>* Intranet outflow traffic: Traffic generated by data transmission from TOS to the client through the BytePlus intranet.<br><br>* Intranet inflow traffic: Data transmitted from the client to TOS through the BytePlus intranet.<br><br>* CDN Back\-to\-origin Outflow Traffic: Traffic generated when data from TOS is transmitted to BytePlus CDN service through CDN acceleration download.<br><br>* CDN Back\-to\-Origin Inflow Traffic: Traffic generated when using CDN to accelerate the upload of data to TOS, flowing from BytePlus CDN service to TOS.<br><br>* CRR Traffic: Traffic occurs when data is replicated from the source storage bucket to the target storage bucket via the cross\-region replication feature. |
|Number of requests |Statistics on the total number of write and read requests in the bucket within a given time period. |
|Bandwidth |Statistics on the intranet outbound bandwidth and internet outbound bandwidth of a bucket over a certain period. The default interval between data points is 3 minutes. |
|Status code |Statistics on the number of status codes generated by accessing TOS within a certain period from a bucket. |

## Procedure


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. In the left navigation bar, select **Usage statistics** \> **Basic data**, set the time range at the top, and then view the statistics as needed.

   Hover the mouse over the column corresponding to the date on the line chart to view specific statistical data.
