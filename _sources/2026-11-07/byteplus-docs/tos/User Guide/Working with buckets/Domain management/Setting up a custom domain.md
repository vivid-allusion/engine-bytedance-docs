This article describes the specific steps for setting up a custom domain name on TOS.

<span id="b71ceb20"></span>
## Background information

After you upload a file to TOS, you can access or download it using the file URL automatically generated by TOS. If you want to use your own domain name to access objects stored in TOS, you can associate your custom domain with the bucket. After association, you can use the corresponding domain name to access your objects.

For example, if you have associated the `www.test.com` domain with the `test` bucket in the China (Beijing) region and the association has taken effect, you can access the `object.png` file in the `test` bucket in the following ways:


* URL automatically generated by TOS: `https://test.tos-cn-beijing.bytepluses.com.cn/object.png`

* Custom domain address: `https://www.test.com/object.png`


<span id="5db048cd"></span>
## Prerequisite

You have obtained an Internet content provider (ICP) license for your custom domain.

<span id="0e05da2e"></span>
## Precautions


* Each domain name can only be associated with one bucket.

* Each bucket can hold up to 100 associated domain names.

* By default, the owner of an account has full permissions. IAM users have no permissions by default. If an IAM user needs to perform any of the following operations, the account owner must grant the user the appropriate permissions using an [IAM](https://docs.byteplus.com/en/docs/tos/docs-overview_6) or [Bucket policy](https://docs.byteplus.com/en/docs/tos/docs-overview_5).

   * Associate custom domains: `tos:PutBucketCustomDomain`

   * View custom domains: `tos:GetBucketCustomDomain`

   * Disassociate custom domains: `tos:DeleteBucketCustomDomain`


<span id="aef9021c"></span>
## Procedure


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. In the left navigation pane,click **Domain name and transfer acceleration** \> **Domain management**.

4. On the **Custom domain** page, click **Associate domain name**.

5. In the dialog box that pops up, set the domain name, click **Advanced settings**, select a **protocol**.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Wildcard domains, such as <code>*.test.com</code> are not supported.   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">After associating a custom domain, you must configure DNS records for your domain. Create a CNAME record pointing to the bucket's public access domain name. Then, the custom domain will become active.   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">To access the custom domain via HTTPS, associate an HTTPS certificate with the domain. For specific steps, see <a href="https://docs.byteplus.com/docs/tos/Manage-https-certificates">Managing HTTPS certificates</a>.   </div>
   

6. click **Verify and bind**.
