If a bucket is no longer in use, you can delete it on the bucket list page.

<span id="2c4d1c56"></span>
## **Prerequisites**


* Delete any files from the bucket before deleting the bucket. For detailed directions, see [Deleting Files](https://docs.byteplus.com/en/tos/docs/deleting-a-file?version=1.0.0).

* Delete parts that are not merged during upload from the bucket before deleting the bucket. For detailed directions, see [Deleting parts](https://docs.byteplus.com/en/tos/docs/managing-parts?version=1.0.0).


<span id="2b1af198"></span>
## **Procedure**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. Then, click **Delete** in the **Actions** column on the right of the target bucket.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you have a large number of buckets, search for them by name in the <strong>Search</strong> box in the upper\-right corner.   </div>
   

3. In the pop\-up dialog box, click **Delete**.
