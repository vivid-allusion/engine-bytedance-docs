This topic describes how to enable and suspend versioning.

<span id="e29f9ede"></span>
## **Enabling versioning**

You can enable versioning using the following methods:

<span id="91681c8d"></span>
### **Enabling versioning when creating a bucket**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. In the upper\-left corner of the displayed page, click **Create Bucket**.

3. On the **Create Bucket** page, configure the bucket parameters ，and set **Versioning** to Active.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For more information on other parameters, see <a href="https://docs.byteplus.com/en/tos/docs/create-a-bucket?version=1.0.0">Creating a Bucket</a>.   </div>
   

4. Click **Create**.


<span id="fb3dbc88"></span>
### **Enabling versioning for an existing bucket**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. In the left navigation pane, select **Fault tolerance and disaster recovery \> Versioning**. On the **Versioning** page, click **Edit**.

4. Select **Enable** and click **Select**.

5. In the pop\-up dialog box, click **Save**.


<span id="849eeb13"></span>
## **Suspending versioning**


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. On the bucket list page, click the target bucket name.

3. In the left navigation pane, select **Fault Tolerance and Disaster Recovery \> Versioning**. On the **Versioning** page, click **Edit**.

4. Select **Disable** and click **Select**.

5. In the pop\-up dialog box, click **Save**.
