TOS supports the Intelligent Tiered Storage type, which automatically switches the access tier of objects based on their access frequency, thus reducing your storage costs. This topic describes the scenarios and precautions related to Intelligent Tiered Storage.

<span id="534fd0e3"></span>
## **Feature overview**

If you are uncertain about the access frequency of an object, you can store it in Intelligent Tiered Storage. Then, TOS automatically monitors the access frequency of the object and, according to the Intelligent Tiered Storage rules, transitions it to the Infrequent Access or Flashback Archive tier, effectively reducing your storage costs.

## **Use methods**

Intelligent Tiered Storage works out of the box. You can select Intelligent Tiered Storage as the storage type in the following methods:


* [Uploading a File](https://docs.byteplus.com/en/tos/docs/uploading-a-file?version=1.0.0): When uploading a file, select **Intelligent Tiered Storage** as the **storage type**.

* [Changing the File Storage Type](https://docs.byteplus.com/en/tos/docs/changing-the-file-storage-type?version=1.0.0): Change the **storage type** of an existing file to **Intelligent Tiered Storage**.

* [Setting Lifecycle Rules](https://docs.byteplus.com/en/tos/docs/setting-lifecycle-rules?version=1.0.0): Transition a file from **Standard Storage** or **Infrequent Access Storage** to **Intelligent Tiered Storage** based on lifecycle rules.


<span id="98a649a1"></span>
## **Intelligent Tiered Storage transition rules**

Files uploaded or transitioned to Intelligent Tiered Storage the first time are stored in the Frequent Access tier by default. They will be automatically transitioned to the Infrequent Access or Flashback Archive tier based on the transition rules. For more information, see [Viewing Intelligent Tiered Storage Transition Rules](https://docs.byteplus.com/en/tos/docs/viewing-intelligent-tiering-storage-transition-rules?version=1.0.0).

Below are the transition rules:


* Files that have not been accessed for 30 consecutive days will sink to the Infrequent Access tier of Intelligent Tiered Storage.

* Files that have not been accessed for 90 consecutive days will sink to the Flashback Archive tier of Intelligent Tiered Storage.

## **FAQs**

<span id="9e5e29ff"></span>
#### **What is the difference between Intelligent Tiered Storage rules and lifecycle rules?** 


1. Intelligent Tiered Storage rules are for transitions between different tiers of this storage type. Specifically, TOS automatically transitions its files to the Infrequent Access or Flashback Archive tier based on the access frequency.

2. Lifecycle rules are for transitions between different storage types. Specifically, TOS transitions files from Standard Storage or Infrequent Access Storage to Intelligent Tiered Storage based on the rules.


<span id="d51fa9d7"></span>
#### **Is there a minimum storage duration for files in the Infrequent Access or Flashback Archive tier of Intelligent Tiered Storage?Is there a penalty fee for early deletion?** 

There is no minimum storage duration or penalty fee.

<span id="259972d4"></span>
#### **Will I be charged for retrieving files from the Infrequent Access or Flashback Archive tier of Intelligent Tiered Storage?** 

No.

<span id="f7996cbb"></span>
#### **Will files in the Infrequent Access or Flashback Archive tier of Intelligent Tiered Storage be automatically transitioned to the Frequent Access tier once they are accessed or updated?** 

Yes.
