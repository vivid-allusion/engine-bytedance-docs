A bucket is a container that holds your data as objects. You must create a bucket before uploading any objects.

<span id="74fb24ad"></span>
## Prerequisites


1. Make sure that you have created a BytePlus account and completed real name verification. For more information, see [Sign Up and Verify BytePlus account](https://docs.byteplus.com/byteplus-platform/docs/signing-up-your-account).

2. Make sure that your account or sub\-account has activated TOS. For details, see [Activate TOS](https://docs.byteplus.com/en/docs/tos/docs-quick-start_1#5b9d7cdc).


<span id="3c1dbda5"></span>
## Note


* By default, the owner of an account has full permissions. IAM users have no permissions by default. If an IAM user needs to perform this operation, the account owner must grant the user the `tos:CreateBucket` permission using an [IAM](https://docs.byteplus.com/en/docs/tos/docs-overview_6) or [Bucket policy](https://docs.byteplus.com/en/docs/tos/docs-overview_5).

* You can create up to 100 buckets for each account and its sub\-account(s).


<span id="09be14c1"></span>
## Procedure


1. Log in to the [TOS console](https://console.byteplus.com/tos/bucket).

2. In the left navigation pane, click **Buckets**. Then, in the upper\-left corner of the displayed page, click **Create bucket**.

3. Set the bucket parameters and click **Create**.
