You can delete a dataset on the dataset list page if you no longer need it.

<span id="b563345a"></span>
## Notes

This feature is currently in closed beta. Please contact your account manager for access.

<span id="fcabf5b5"></span>
## Prerequisites

Before deleting a dataset, ensure that no data sources are bound to it. If the dataset has bound data sources, unbind them by following the [relevant procedures](https://docs.byteplus.com/docs/tos/Bind_data_source#2f499c2b).

<span id="cf0fd02e"></span>
## Steps


1. Log in to the [TOS console](https://console.byteplus.com/tos).

2. In the left navigation pane, select **Intelligent retrieve** \> **Data set management**.

3. In the dataset list, click  **...**  \> **Delete** in the **Actions** column of the dataset you want to remove.
