This section describes how to adjust the sharpness of the original image. The following table lists the parameters and examples.

<span id="22277667"></span>
## Parameters


|**Parameter** |**Description** |**Setting** |**Required** |
|---|---|---|---|
|value |Sharpening strength. |[50,399]<br><br>The larger the value, the clearer the image. A larger value may distort the image. The recommended value is 100 for the optimal effect. |Yes |


<span id="23ab4ff5"></span>
## Examples

Set the sharpening parameter to 100.
