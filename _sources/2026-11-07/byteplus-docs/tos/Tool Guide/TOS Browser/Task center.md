You can manage upload, copy/move, download, and delete tasks through the Task Center.

<span id=".5pON5L2c5q2l6aqk"></span>
## Steps


1. [Log in to TOS Browser](https://docs.byteplus.com/docs/tos/Log-in-to-tos-browser).

2. Click the target bucket name on the **Buckets** page.

3. On the file list page, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c8df82a179ad7e704e6cbbd34f90be5c.png) </span> icon at the top right of the page.

4. In the **Task schedule management** panel, you can perform the following actions:

   * **Pause**: Click **Pause** in the **Actions** column of the target file to pause the task.

   * **Continue**: After pausing the task, you can click on the **Continue** button in the target file's action column to continue executing the task.

   * **Cancel**: After pausing a task, click **Cancel** in the **Actions** column of the target file to cancel the task.

   * **Retry**: if a task fails and you need to run it again, click **Retry** in the **Actions** column of the target file to rerun the task.

   * **Clear Upload Record**: Click on the **Clear the record** button in the target file **Actions** column to clear the task record. Deleting the upload record of a file will not result in the deletion of the file.

   * **Clear All Records**: Click on **Clear** **all** at the top of the panel to delete all tasks in the list at once.

   * **Open Folder**: After the file download is complete, you can click on the **Open Folder** in the target file **Actions** column on the download task page tab to open the local folder where the file is located.
