You can use TOS Browser to manage objects, such as uploading objects and setting object metadata.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


1. [Install TOS Browser](https://docs.byteplus.com/docs/tos/Install-tos-browser)

2. [Log in to TOS Browser](https://docs.byteplus.com/docs/tos/Log-in-to-tos-browser)

3. [Create a bucket](https://docs.byteplus.com/docs/tos/Quickly-use-the-tos-browser)


<span id=".5pSv5oyB5pON5L2c"></span>
## Supported operations

After logging in to TOS browser and selecting a bucket, you can perform the following operations on its objects.


|Operation |Steps |
|---|---|
|Uploading objects |1. On the Objects page, click **Upload file** in the upper\-right\-corner.<br><br>2. Select the file you want to upload, and then click **Upload**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">For more information on parameters when uploading an object, see <a href="https://docs.byteplus.com/docs/tos/docs-uploading-a-file">Uploading objects</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">You can also drag multiple files or folders to the Objects page and click <strong>Upload</strong> in the box that appears.</div><br> |
|Downloading objects |On the Objects page, either click **Download** in the **Actions** column or check the box next to the object and click **Download** at the top. Then, choose where to save it.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">You can also download objects using the following two methods.</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">If the bucket where the object resides was created after January 3, 2024, scan the object's QR code to download it. For instructions on obtaining an object's QR code, see <a href="https://docs.byteplus.com/docs/tos/Quickly-use-the-tos-browser#.5q2l6aqk5Zub77ya6I635Y-W5paH5Lu25Zyw5Z2A">Obtaining object links</a>.</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Right\-click the object name, select <strong>Download</strong>, and choose where to save the object.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Use TOS Browser 1.8.1 or later to download symlinks.</div><br> |
|Creating a text file |1. On the Objects page, click **Create file** in the upper\-left corner.<br><br>2. In the **Create file** dialog, enter a filename. **File type** is set to **text/plain** by default and cannot be changed. Then, click **Create**.<br><br>3. In the **Create success** dialog, click **Edit**.<br><br>4. Type your content into the text box. When you're finished, click **Save** and then click the close button to exit. |
|Previewing objects |On the Objects page, click the name of an object to preview it. TOS Browser displays the full path when you preview an object, which makes it easier to locate.<br><br>You can perform operations such as zooming in and out on images. Steps:<br><br>On the Objects page, click the name of an image file. In the **Preview** dialog, click the image. Then, click the corresponding icons at the bottom of the image to perform operations such as full\-screen view, rotate right, rotate left, zoom in, zoom out, and restore to original size.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">TOS Browser only supports previewing objects in the following formats:</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Documents: txt and json.</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Images: png, jpg, jpeg, gif, and svg.</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">Audio/video: mp3, mp4, webm, mov, and mkv.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When previewing text files larger than 10 MiB, only the first 10 MiB can be displayed. The rest of the file cannot be shown.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">The preview feature is available only when you log in to TOS Browser with AK/SK. Other login methods are not supported.</div><br> |
|Editing objects online |1. On the Objects page, click the object you want to manage.<br><br>2. Edit the text in the box. When you're finished, click **Save**.<br><br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">The online editing feature only supports <strong>text files</strong>, such as .txt and .json files.</div><br> |
|Copying pre\-signed URLs |Pre\-signed URLs allow you to share objects temporarily. After you generate a pre\-signed URL, others can use it to download the object. Steps:<br><br>On the Objects page, click **Copy pre\-signed link** in the **Actions** column of the object you want to share.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">The default validity period for a pre\-signed URL is 1 hour.</div><br> |
|Customizing pre\-signed URLs |TOS Browser lets you generate pre\-signed URLs using either a custom domain associated with the bucket or the default TOS domain. Steps:<br><br><br>1. On the Objects page, click  **... \> Get address** in the Actions column of the object you want to manage.<br><br>2. In the **Get Address** dialog, select **Pre\-signed link**.<br><br>3. Set the **URL valid period** to a range between 0 and 7 days. Select a custom domain. Then, click **Generate and copy links**.<br><br>   Then, both a **URL** and a **Custom domain URL** will be displayed. Click the copy icon to copy the pre\-signed URL for the default TOS domain or the custom domain associated with the bucket.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Depending on the type of object, you can preview or download it using the pre\-signed URL if the bucket containing the object was created on or before January 3, 2024.   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the bucket was created after January 3, 2024, the pre\-signed URL only allows you to download the object.   </div><br>    |
|Obtaining object links |You can obtain an object link via TOS Browser, which provides direct access to the object. This link will not expire, so you do not need to set an expiration date.<br><br>If your bucket policy conflicts with an object's access control list (ACL) policy — for instance, if an object's ACL policy is set to **Public read** but your bucket policy denies access — your bucket policy takes precedence, and you cannot access the object through the link. Create a **pre\-signed URL** to access the object instead.<br><br><br>1. On the Objects page, click  **... \> Get address** in the **Actions** column of the object you want to manage.<br><br>2. In the **Get address** dialog, select **File address**.<br><br>   Then, both a **URL** and a **Custom domain URL** will be displayed. Click the copy icon to copy the URL for the default TOS domain or the custom domain associated with the bucket.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Depending on the type of object, you can preview or download it using the share link if the bucket containing the object was created on or before January 3, 2024.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If the bucket was created after January 3, 2024, the share link only allows you to download the object.</div><br> |
|Renaming objects |1. On the **Objects** page, hover over the object you want to rename, and click the edit icon that appears.<br><br>2. In the box that appears, enter the new name and click **OK**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">TOS Browser does not support renaming an object larger than 5 GB.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If the original filename has a suffix, keep it in the new filename.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-renaming-files">Renaming objects</a>.</div><br> |
|Modifying object metadata |1. On the **Objects** page, click  **... \> Custom Metadata** in the **Actions** column of the object you want to manage.<br><br>2. In the box that appears, edit the metadata as needed and click **Edit**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-managing-file-metadata">Modifying object metadata</a>.</div><br> |
|Editing object permissions |1. On the **Objects** page, select  **··· \> Modify Access Permission** in the **Actions** column of the object you want to manage.<br><br>2. In the box that appears, select the desired **Access Permission**. Then, click **Save**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-modifying-the-file-access-permission">Editing object permissions</a>.</div><br> |
|Deleting objects |1. On the Objects page, select  **··· \> Delete** in the **Actions** column of the object you want to remove.<br><br>2. In the box that appears, click **Delete**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Alternatively, right\-click the object name, and select <strong>Delete</strong>. In the box that appears, confirm the deletion by clicking <strong>Delete</strong>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If you have enabled versioning for your bucket, first turn on the <strong>Display version</strong> option in the upper\-right corner of the Objects page. Then, select the version of the object you want to delete. Otherwise, the deletion operation will only add a <strong>deletion mark</strong> to the object rather than permanently delete it.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">TOS Browser lets you delete objects in batches. To do so, select the objects you want to remove, click <strong>··· \> Delete</strong> in the upper\-left corner of the Objects page, and then click <strong>Delete</strong>. For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-deleting-a-file">Deleting objects</a>.</div><br> |
|Sharing objects using normal links |1. On the Objects page, select  **··· \> Share** in the **Actions** column of the object.<br><br>2. In the **Share** dialog, set **Permission** to **Read\-only**, select a **Valid period type**, and specify the **URL valid period**.<br><br>   * **Effective time**: The share link will expire automatically after the specified duration.<br><br>   * **Target time**: The share link will expire automatically after the specified date and time.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For more information, see <a href="https://docs.byteplus.com/docs/tos/Sharing-files">Sharing objects</a>.   </div><br>   <br><br>3. Click **Create share**.<br><br>4. Select Copy link, and click **OK**.<br><br>   Then, you can share this link with other users, who can access the object through TOS Browser or other browsers. For instructions, see [Logging in to TOS Browser with a share link](https://docs.byteplus.com/docs/tos/Log-in-to-tos-browser).<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">The object sharing feature is available only when you log in to TOS Browser with AK/SK. Other login methods are not supported.</div><br> |
|Sharing objects using trackable links |1. On the Objects page, select  **··· \> Share** in the **Actions** column of the object.<br><br>2. In the **Share** dialog, set **Permission** to **Read\-only**, select a **Valid period type**, and specify the **URL valid period**. Then, enable log tracing and configure the following parameters: **Log AK**, **Log SK**, **Log Hosting**, **Log Region** and **Topic ID**.<br><br>3. Click **Test send log**.<br><br>4. After the page displays **Logs sent successfully**, click **Create URL**.<br><br>5. Select Copy link, and click **OK**.<br><br>   You can share this link with other users. They can use it to log in to TOS Browser and download the corresponding object. Torch Log Service (TLS) will collect information about download behavior through the link. You can then search and analyze these records in TLS.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">TLS only collects data on object downloads via trackable links through TOS Browser, not through any other browsers. For instructions, see <a href="https://docs.byteplus.com/docs/tos/Log-in-to-tos-browser">Logging in to TOS Browser with a share link</a>.   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The object sharing feature is available only when you log in to TOS Browser with AK/SK. Other login methods are not supported.   </div><br>    |
|Changing object storage type |1. On the **Objects** page, select  **··· \> Change Storage Type** in the **Actions** column of the object you want to manage.<br><br>2. In the box that appears, select the desired storage type. Then, click **Save**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">For more information on how to change object storage type, see <a href="https://docs.byteplus.com/docs/tos/docs-changing-the-file-storage-type">Changing object storage type</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">For more information on storage types, see <a href="https://docs.byteplus.com/docs/tos/docs-storage-type">Storage type</a>.</div><br> |
|Copying objects |TOS Browser allows you to copy objects or folders to a different location, including moving them from a subdirectory to a parent directory.<br><br><br>1. On the **Objects** page, select the object or folder you want to copy by checking the box next to it. Then, click  **... \> Copy to**.<br><br>2. In the **Copy To Folder** dialog, select a folder, and then click **Copy**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-copying-files">Copying objects</a>.</div><br> |
|Moving objects |1. On the **Objects** page, select the object or folder you want to move by checking the box next to it. Then, click  **... \> Move to**.<br><br>2. In the **Move to folder** dialog, select a folder, and then click **Move**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-moving-files">Moving objects</a>.</div><br> |
|Searching for objects |To search for an object, enter its prefix into either the search box in the upper\-right corner or the address bar in the upper\-left corner of the Objects page.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">When searching in the address bar, you must search within the current path. For example, if the current path is <code>tos://test/</code>, enter the prefix after <code>tos://test/</code> to perform the search.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Clearing the path in the address bar will automatically navigate TOS Browser to the <strong>Buckets</strong> page.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">The address bar path supports copying.</div><br> |
|Restoring objects |* Restoring an object<br><br>   1. On the Objects page, click **Restore** in the **Actions** column of the object you want to restore.<br><br>   2. In the **File restore** dialog, specify the **Copy Validity Period**, select a **Restore mode**, and click **Restore**.<br><br>* Restoring objects in batches<br><br>   1. On the objects page, select the objects you want to restore, and select  **··· \> Restore**.<br><br>   2. Select a **Restore mode**, specify the **Copy Validity Period**, and click **Restore**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Archive, Cold Archive, and Deep Cold Archive support different restoration modes. If you select objects from multiple storage types for batch restoration, only those in types that support the selected mode will be restored. An error will occur for objects in unsupported storage types. For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-restoring-files">Restoring objects</a>.</div><br> |
|Sorting objects |* Sorting objects in a bucket by filename<br><br>   On the Objects page, click the ascending icon next to the **Filename** column to sort the objects alphabetically, or click the descending icon for reverse order.<br><br>* Sorting objects in a bucket by size<br><br>   On the Objects page, click the ascending icon next to the **Size** column to sort objects from smallest to largest, or click the descending icon for the opposite order.<br><br>* Sorting objects in a bucket by modification time<br><br>   On the Objects page, click the ascending icon next to the **Modification time** column to sort objects from oldest to newest, or click the descending icon to sort them from newest to oldest. |
|Adding a path to your favorites |* Adding a path to your favorites<br><br>   On the Objects page, click the star icon in the top address bar to add a path to your favorites.<br><br>* Viewing favorite paths<br><br>   On the Objects page, click the **Favorites** tab in the upper\-left corner. This will allow you to view your favorite paths. Click a path to quickly navigate to the object underneath it.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">The favorites feature is available only when you log in to TOS Browser with AK/SK. Other login methods are not supported.</div><br> |
|Changing the number of objects displayed |In the lower\-right corner of the Objects page, select the number of objects to display per page. You can choose from the following options: 20, 50, 100, or 200. |
|Creating folders |1. On the Objects page, click **Create folder**.<br><br>2. In the box that appears, enter the folder name and click **Create**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-creating-a-folder">Creating folders</a>.</div><br> |
|Deleting folders |1. On the Objects page, select  **··· \> Delete** in the **Actions** column of the folder you want to remove.<br><br>2. In the box that appears, click **Delete**.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Alternatively, right\-click the folder name, and select <strong>Delete</strong>. In the box that appears, confirm the deletion by clicking <strong>Delete</strong>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If you have enabled versioning for your bucket, first turn on the <strong>Display version</strong> option in the upper\-right corner of the Objects page. Otherwise, the deletion operation will only add a <strong>deletion mark</strong> to the folder rather than permanently delete it.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">TOS Browser lets you delete folders in batches. For more information, see <a href="https://docs.byteplus.com/docs/tos/docs-deleting-a-folder">Deleting folders</a>.</div><br> |
|Sharing folders using normal links |1. On the Objects page, click **Share** in the **Actions** column of the folder.<br><br>2. In the **Share** dialog, set **Permission** to **Read\-only**, select a **Valid period type**, and specify the **URL valid period**.<br><br>   * **Effective time**: The share link will expire automatically after the specified duration.<br><br>   * **Target time**: The share link will expire automatically after the specified date and time.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For more information, see <a href="https://docs.byteplus.com/docs/tos/Sharing-files">Sharing objects</a>.   </div><br>   <br><br>3. Click **Create share**.<br><br>4. Select Copy link, and click **OK**.<br><br>   Then, you can share this link with other users, who can access the folder contents through TOS Browser or other browsers. For instructions, see [Logging in to TOS Browser with a share link](https://docs.byteplus.com/docs/tos/Log-in-to-tos-browser).<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The folder sharing feature is available only when you log in to TOS Browser with AK/SK. |Sharing folders using trackable links |1. On the Objects page, click **Share** in the **Actions** column of the folder.<br><br>2.
