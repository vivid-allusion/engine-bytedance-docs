You can use the `netdig` command for one\-click network diagnosis to help identify network issues.

<span id="288b33fd"></span>
## Considerations


* Network diagnosis commands are supported only on Linux and macOS systems.

* The network diagnosis commands rely on several local command\-line tools, including:

   * dig command

   * ping command

   * traceroute command

   * curl command

   * tcpdump command


<span id="3856f873"></span>
## Command syntax

```Bash
./tosutil netdig domain/ipaddress [-aoe] [-ipv6] [-w] [-we=xxx] [-p] [-pss=xxx] [-tr] [-c] [-dp=xxx] [-di=xxx] [-u] [-ucl=xxx]
```


<span id="17e6d615"></span>
## Parameters


|**Parameter name** |**Type** |**Description** |
|---|---|---|
|domain |String |Target host domain name. TOS\-supported regions and access domain names, see [Region and Endpoint](https://docs.byteplus.com/docs/tos/docs-region-and-endpoint). |
|ipaddress |String |Target host IP address. |
|\-aoe |Bool |Stop the command on error during execution. |
|\-ipv6 |Bool |Select IPv6 addresses when resolving domains. |
|\-w |Bool |Use the `dig` command to check the DNS lookup exit point. |
|\-we |String |Check the dig address used for `DNS lookup` exit, default is `whoami.byte008.com`. |
|\-p |Bool |Use the `ping` command to test MTU for large and small packets. |
|\-pss |String |Use the list of packet sizes specified when using the `ping` command, separated by`#`commas. Defaults to `64#1295#1472`. |
|\-tr |Bool |Use the `traceroute` command to detect routing paths for UDP/ICMP protocols. |
|\-c |Bool |Use the `curl` command to test request latency. |
|\-dp |String |Use the `tcpdump` command to capture network packets generated by the `probe` command. The parameter value is an optional argument for probe.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">The parameter value must be enclosed in double quotes <code>""</code>.</div><br> |
|\-di |String |Specify the network interface name when using the `tcpdump` command. |
|\-u |Bool |Package and upload the collected network information to the TOS bucket. |
|\-ucl |String |Use this parameter to specify the bucket and prefix for batch upload, formatted as `tos://bucket/[prefix]`. |


<span id="8767b057"></span>
## Usage example

Run the command to perform network diagnostic tests, collect relevant information, and upload the package to the specified bucket. The example is as follows:


* Command


```Plain
./tosutil netdig tos-cn-beijing.bytepluses.com.cn -w -p -tr -c -dp "-pt upload -timeout 15" -u -ucl tos://bucket-test
```
