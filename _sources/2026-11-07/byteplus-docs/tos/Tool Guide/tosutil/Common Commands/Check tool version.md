You can use the `version` command to check the current version number of the tosutil tool.

<span id="命令语法"></span>
## Command syntax


<Tabs>
<Tab zoneid="z3ZsqPWj" title="Linux/macOS">
<TabTitle>Linux/macOS</TabTitle>

&nbsp;

```Bash
./tosutil version
```





</Tab>
<Tab zoneid="V81ZdFgC" title="Windows">
<TabTitle>Windows</TabTitle>

&nbsp;

```Bash
tosutil version
```





</Tab>
</Tabs>


<span id="0OI3nHZc"></span>
## Parameters

None.

<span id="运行示例"></span>
## Example


* Command


```Plain
./tosutil version
```



* Output


```Plain
tosutil version: v1.1.0
operating system: darwin, arch: amd64
```
