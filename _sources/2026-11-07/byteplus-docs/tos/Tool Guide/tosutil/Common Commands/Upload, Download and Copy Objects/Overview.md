You can use the cp command to upload, download, copy objects, and resume previously failed tasks.


* For command instructions and usage examples on uploading objects, see [Upload Objects](https://docs.byteplus.com/docs/tos/Upload-object-cp).

* For command instructions and usage examples on downloading objects, see [Download Objects](https://docs.byteplus.com/docs/tos/Download-object-cp).

* For command instructions and usage examples on copying objects, see [Copy Objects](https://docs.byteplus.com/docs/tos/Copy-object-cp).

* For command instructions and usage examples on resuming failed tasks, see [Resume Failed Tasks](https://docs.byteplus.com/docs/tos/Resume-failed-tasks--cp).
