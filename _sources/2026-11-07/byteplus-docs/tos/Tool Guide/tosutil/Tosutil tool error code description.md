This article explains the error codes returned when using the tosutil tool.


|**Exit Code** |Description |
|---|---|
|0 |Operation succeeded without exceptions. |
|1 |The uploaded or downloaded file or folder does not exist. |
|2 |Task ID does not exist. |
|3 |Incorrect input runtime parameters. |
|4 |Failed to verify bucket status error. |
|5 |Configuration initialization error. |
|6 |Command execution error. |
|7 |Operation not supported error. |
|8 |Partial failure occurred during command execution, usually in batch operations. |
|9 |Execution was interrupted error. |
|\-1 |Unknown error. |
