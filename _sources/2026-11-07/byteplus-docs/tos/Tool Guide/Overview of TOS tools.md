This topic introduces the various tools that TOS offers to help you manage buckets and objects.

|Tool |Description |
|---|---|
|[tosutil](https://docs.byteplus.com/docs/tos/overview) |tosutil is a command\-line tool used to access and manage TOS resources. This tool allows you to perform batch data processing between local storage and TOS. You can use it to upload and download small\- to medium\-sized data to and from the cloud, as well as integrate automated scripting tasks. |
|[TOS Browser](https://docs.byteplus.com/docs/tos/Overview3) |TOS Browser is a graphical user interface (GUI) tool designed for TOS. You can use this tool to manage buckets and objects. |
|[TOS FSX](https://docs.byteplus.com/docs/tos/Overview) |FSX is a client that enables you to mount a TOS bucket as a local file system on a Linux system. This makes storing and managing your data easy. |
|[TOS PyTorch Connector](https://docs.byteplus.com/docs/tos/TOS_PyTorch_Connector_Overview) |Designed for AI training workloads, TOS PyTorch Connector delivers high\-performance data access to TOS data. By enabling efficient reads of large\-scale training data, it dramatically accelerates data loading for machine learning and deep learning projects using the PyTorch framework. |
|[tosfsspec](https://docs.byteplus.com/docs/tos/tosfsspec_overview) |`tosfsspec` is a Python library that adheres to the pythonic file systems specification ([fsspec](https://github.com/fsspec)). This enables developers to read from and write to TOS as conveniently and efficiently as they would with a local file system. Whether you are a data analyst or a backend developer, `tosfsspec` provides a standard, concise, and feature\-rich interface for using TOS as the storage backend in Python applications. |
|[ve-tos-cli](https://docs.volcengine.com/docs/6349/2563182) |`ve-tos-cli` is the official command\-line tool for TOS. It supports the entire TOS workflow, including file transfer, bucket configuration, advanced feature invocation, and control plane operations. It also provides low\-level APIs, bucket configuration commands, advanced feature commands, and control plane commands to meet varying requirements. |
