This topic describes TOS features.


|**Feature** |**Description** |
|---|---|
|Storage type |TOS supports multiple storage types for different business scenarios. For more information, see [Storage type](https://docs.byteplus.com/en/tos/docs/storage-type?version=1.0.0). |
|Working with buckets |TOS supports bucket creation, deletion, and other bucket management operations. For more information, see [Working with buckets](https://docs.byteplus.com/docs/tos/Bucket-type). |
|Working with objects |TOS supports object upload, deletion, and other object management operations. For more information, see [Working with objects](https://docs.byteplus.com/tos/docs-uploading-a-file). |
|Image processing |TOS supports image resizing, watermarking, and other image processing operations. For more information, see [Image processing overview](https://docs.byteplus.com/en/tos/docs/overview_2?version=1.0.0). |
