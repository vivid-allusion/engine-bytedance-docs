This topic describes the applicable scenarios of TOS.

<span id="88325bff"></span>
## **Video storage**

TOS can store massive videos. With TOS and the smart multimedia processing service, you can transcode videos, extract frames, and add watermarks online; with TOS and CDN, you can download and distribute massive data, enjoying an integrated solution of video storage, processing, and access.

<span id="5d281402"></span>
## **Static and dynamic content separation for web pages and mobile apps**

TOS stores static and dynamic resources of web pages or mobile apps, such as JavaScript scripts, CSS files, images, videos, and audio. With CDN, TOS can well support concurrent access to the same web page or mobile app from massive users.
