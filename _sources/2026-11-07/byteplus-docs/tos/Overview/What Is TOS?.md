BytePlus Torch Object Storage (TOS) is a highly reliable and available distributed cloud storage service, featuring massive capacity, security, cost effectiveness, and ease of use. You can use TOS through RESTful APIs, SDKs, or tools. In addition, you can manage and access TOS data over the internet on any application anytime, anywhere.

<span id="3624a9c6"></span>
## **Strengths**


* **Massive capacity**

   TOS leverages proprietary distributed object storage technology as well as leading architecture and technical support. It can house tens of thousands of object storage servers, offering more than exabyte storage. Conventionally, a self\-built object storage system has insufficient nodes to scale at the 100\-petabyte level; it also has bottlenecks for managing the metadata of buckets and objects, for example, low concurrent write performance per bucket and a limited number of objects per bucket. In contrast, TOS provides infinite storage capacity per bucket to help you easily store and manage massive data.

* **High persistence**

   TOS adopts a distributed architecture to store data and redundant data of each object on multiple devices in the same region, ensuring high data persistence when hardware fails. It regularly checks data integrity through verification and other means to detect data corruption caused by hardware failure and other reasons in time. Any corrupted or lost data will be rebuilt or restored with redundant data. In addition, TOS supports cross\-region data replication for remote disaster recovery. The data reliability is 99.999999999%.

* **High security**

   Data access is protected at multiple levels. Access control policies such as ACL are provided for all buckets and objects, and all connections are encrypted based on SSL. The system authenticates accessing users to ensure data security.
