## Introduction

This interface is used to set tags for a bucket. By setting bucket tags, you can categorize and manage buckets. For example, you can add certain cost tags to the bucket, which will then be included in the billing statements generated by this bucket, enabling detailed classification filtering and more thorough cost analysis of detailed statements.

<span id="0de528b4"></span>
## Precautions

Only the owner of the storage bucket and users with PutBucketTagging permission can create bucket tags.

<span id="15e6051a"></span>
## Tag setting rules


|**Category** |**Description** |
|---|---|
|Tag key |* Supports letters or characters from any language (such as Chinese, English letters, etc.), numbers, spaces; supports special characters: `_.:/=+-@`.<br><br>* `volc:` and `sys:` are reserved tag keys for the system, the beginning of the tag key cannot be set to any form of `volc:` or `sys:` in upper or lower case.<br><br>* The length of the tag key must be between 1 to 128 characters. |
|Tag value |* Supports letters or characters from any language (such as Chinese, English letters, etc.), numbers, spaces; supports special characters: `_.:/=+-@`.<br><br>* The length of the tag value must be between 0 to 256 characters, meaning the tag value can be empty. |
|Tag quantity |* There is no limit to the total number of tags, but each bucket can have a maximum of 50 tags attached. |

## **Request syntax**

```JSON
PUT /?tagging HTTP/1.1
Host: bucketname.tos-ap-southeast-1.bytepluses.com
Date: GMT Date
Content-MD5: OolRtfRnEQlFUQVcEd5Q****
Content-Length: 262
Authorization: authorization string

{
        "TagSet": {
                "Tags": [{
                        "Key": "key1",
                        "Value": "value1"
                }, {
                        "Key": "key2",
                        "Value": "value2"
                }]
        }
}
```


<span id="da1081eb"></span>
## **Request parameters and headers**

The request requires setting the Content\-MD5 value of the request element in the message header to compare with the MD5 value of the uploaded request element. If they do not match, an error will be returned. For other common request headers used, please refer to [Common parameters](https://docs.byteplus.com/en/tos/reference/common-parameters).


|**Name** |**Location** |**Type** |**Required** |**Sample value** |**Description** |
|---|---|---|---|---|---|
|tagging |Query |String |Yes |\- |A special identification for the PutBucketTagging request. |


<span id="6f956005"></span>
## **Request body elements**


|**Name** |**Type** |**Required** |**Sample value** |**Description** |
|---|---|---|---|---|
|TagSet |Object |Yes |\- |Bucket label collection information. |
|Tags |Array |Yes |\- |Bucket label list information. |
|Key |String |Yes |owner |Value of the tag key. For specific setting rules, please see [Setting bucket tags](https://docs.byteplus.com/docs/tos/Set-bucket-tag). |
|Value |String |Yes |zhangsan |Value of the tag value. For specific setting rules, please see [Setting bucket tags](https://docs.byteplus.com/docs/tos/Set-bucket-tag). |
