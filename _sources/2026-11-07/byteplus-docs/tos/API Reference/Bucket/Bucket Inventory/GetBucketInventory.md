## Description

This interface is used to view the specified bucket inventory rules in a bucket.

<span id="04b09194"></span>
## **Request syntax**

```JSON
GET /?inventory&id=report HTTP/1.1
Host: BucketName.tos-ap-southeast-1.bytepluses.com
Date: Sat, 07 Oct 2023 09:53:11 GMT
Authorization: authorization string
```


<span id="ff37db9f"></span>
## **Request parameters and headers**

For common request headers, see [Common Parameters](https://docs.byteplus.com/en/tos/reference/common-parameters).


|**Name** |**Location** |**Type** |**Required** |**Sample Value** |**Description** |
|---|---|---|---|---|---|
|inventory |Query |String |Yes |\- |A special identifier representing a GetBucketInventory request. |
|id |Query |String |Yes |report |Bucket inventory name. |


<span id="ad960c6c"></span>
## **Request body elements**

No elements are used.

<span id="23caf538"></span>
## **Response headers**

For common response headers, see [Common Parameters](https://docs.byteplus.com/en/tos/reference/common-parameters).

<span id="92894819"></span>
## **Response body elements**


|**Name** |**Type** |**Sample Value** |**Description** |
|---|---|---|---|
|InventoryConfiguration |Array |\- |Bucket inventory rules. |
|Id |String |report |Bucket inventory name. |
|IsEnabled |Bool |true |Whether to enable the bucket inventory feature. The values are as follows:<br><br><br>* `True`:  Enable the bucket inventory feature.<br><br>* `False`:  The bucket inventory feature is not enabled. |
|Destination |Array |\- |Information about the manifest file. |
|TOSBucketDestination |Array |\- |Bucket\-related information for the manifest file.<br><br>Parent Node: `Destination` |
|Role |String |TosArchiveTOSInventory |Role name that grants the object store permission to read all files in the source bucket and write files to the target bucket. This role must have TOS read and write permissions and service access, or you can use the TOS default role `TosArchiveTOSInventory`. |
|Format |String |CSV |The format of the manifest file. The value is `CSV`, that is, the format of the manifest file is CSV format compressed using GZIP.<br><br>Parent Node: `TOSBucketDestination` |
|AccountId |String |200000\*\*\*\* |The account ID of the bucket owner.<br><br>Parent Node: `TOSBucketDestination` |
|Bucket |String |bucket_0001 |The bucket where the manifest file is saved.<br><br>Parent Node: `TOSBucketDestination` |
|Prefix |String |prefix1 |The storage path prefix for the manifest file.<br><br>Parent Node: `TOSBucketDestination` |
|Schedule |Array |\- |Bucket inventory export cycle information. |
|Frequency |String |Daily |Cycle of the manifest file export. The values are as follows:<br><br><br>* `Daily`: Export manifest files by day.<br><br>* `Weekly`: Export manifest files by week.<br><br>* `Once`: Export manifest files all at once.<br><br><br>Parent Node: `Scheduled` |
|Instant |Bool |true |Whether to enable the instant inventory feature. The values are as follows:<br><br><br>* `true`: Enable the instant inventory feature.<br><br>* `false`: The instant inventory feature is not enabled.<br><br><br>Parent Node: `Schedule` |
|IncludedObjectVersions |String |All |The exported object version. The values are as follows:<br><br><br>* `All`: Export all versions of object information.<br><br>* `Current`: Exports the current version of the object information. |
|Filter |Array |\- |Prefix for bucket list filtering. After specifying the prefix, the bucket manifest exports objects that match the prefix setting. |
|Prefix |String |Pics/ |Export file prefix matching information, if not set, a manifest of all objects in the bucket is generated by default.<br><br>Parent Node: `Filter` |
|OptionalFields |Array |\- |Information exported from the manifest file. |
|Field |String |Size |The manifest file needs to export the information. Multiple selection is supported, and the values are as follows:<br><br><br>* `Size`: The size of the object.<br><br>* `LastModifiedDate`: The last modification time of the object.<br><br>* `ETag`: The ETag value of the object, used to identify the content of the object.<br><br>* `StorageClass`: The storage type of the object.<br><br>* `IsMultipartUploaded`: Whether it is an object uploaded by sharding.<br><br>* `EncryptionStatus`: Whether the object is encrypted.<br><br>* `ReplicationStatus`: Cross\-region replication or co\-region replication status of the object.<br><br><br>Parent Node: `OptionalFields` |
