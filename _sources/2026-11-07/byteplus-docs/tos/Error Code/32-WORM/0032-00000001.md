# Problem description

Deleting or overwriting objects that are in a locked state. 

<span id="8ec508e0"></span>
# Root cause

Once an object is locked, it receives protection against deletion and overwriting. Before the retention period expires, no one can delete or overwrite the object. 

<span id="dd3bc6be"></span>
# Example


* Deleting a locked object

   ```Plain
   DELETE /objectName HTTP/1.1 
   Host: <Bucket name>.<TOS endpoint>    
   Date: GMT Date 
   Authorization: authorization xxx
   ```
   

* Overwriting a locked object

   ```Plain
   PUT /abc HTTP/1.1 
   Host: <Bucket name>.<TOS endpoint>   
   Date: GMT Date 
   Authorization: authorization xxx
   ```
   


<span id="1e8e0ab4"></span>
# Solution

After the retention period expires, perform deletion or overwriting operations on the object. For details, see [Setting Retention Policy (WORM)](https://docs.byteplus.com/docs/tos/Configure-retention-policy).
