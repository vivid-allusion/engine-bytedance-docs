# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When the user sets the static website configuration, the Key in the ErrorDocument setting is empty.

<span id="76b07535"></span>
# Example

When you configure the static website, the Key in the ErrorDocument setting is empty.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "IndexDocument": {
        "Suffix": "index.html"
    },
    "ErrorDocument": {
        "Key": ""
    }
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly construct the static website configuration and ensure the Key in the ErrorDocument setting is not empty.
