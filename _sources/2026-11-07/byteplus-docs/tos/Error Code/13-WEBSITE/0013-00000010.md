# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When configuring a static website, the HttpErrorCodeReturnedEquals value in the redirect rule is outside the range [400, 599].

<span id="76b07535"></span>
# Example

During static website configuration, the HttpErrorCodeReturnedEquals value in the redirect rule is set to an invalid value of 200.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html",
        "ForbiddenSubDir": "false"
    },
    "ErrorDocument": {
        "Key": "error.html"
    },
    "RoutingRules": [
        {
            "Condition": {
                "KeyPrefixEquals": "abc",
                "HttpErrorCodeReturnedEquals": 200
            },
            "Redirect": {
                "HostName": "example.com",
                "HttpRedirectCode": 301,
                "Protocol": "http",
                "ReplaceKeyWith": "redirect.html"
            }
        }
    ]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to correctly configure the static website, ensuring the HttpErrorCodeReturnedEquals value in the redirect rule is valid.
