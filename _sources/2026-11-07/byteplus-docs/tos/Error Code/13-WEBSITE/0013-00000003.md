# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting static website configuration, the `RedirectAllRequestsTo` field conflicts with the `IndexDocument`, `ErrorDocument`, and `RoutingRules` fields.

<span id="76b07535"></span>
# Example

If you include the `RedirectAllRequestsTo` field in your static website configuration, the `IndexDocument` field should not be present.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html"
    }
 }
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) for properly constructing static website configuration.
