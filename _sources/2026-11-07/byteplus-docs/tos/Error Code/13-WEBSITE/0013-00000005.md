# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set the static website configuration, the HostName value in the RedirectAllRequestsTo option is empty.

<span id="76b07535"></span>
# Example

When configuring a static website, the HostName value in the RedirectAllRequestsTo option is empty.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "Protocol": "http"
    }
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to correctly construct the static website configuration, ensuring the HostName value in the RedirectAllRequestsTo option is not empty.
