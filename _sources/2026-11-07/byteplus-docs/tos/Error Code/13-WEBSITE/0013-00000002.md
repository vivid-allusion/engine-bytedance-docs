# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set static website configuration, both RedirectAllRequestsTo and IndexDocument configurations are missing.

<span id="76b07535"></span>
# Example

When configuring a static website, neither RedirectAllRequestsTo nor IndexDocument configurations are included.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "ErrorDocument": {
        "Key": "error.html"
    }
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly configure the static website settings.
