# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set up a static website configuration, both HttpErrorCodeReturnedEquals and KeyPrefixEquals are empty in the redirect rules.

<span id="76b07535"></span>
# Example 

When setting up a static website, both HttpErrorCodeReturnedEquals and KeyPrefixEquals are empty in the redirect rules.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html",
        "ForbiddenSubDir": "false"
    },
    "ErrorDocument": {
        "Key": "error.html"
    },
    "RoutingRules": [
        {
            "Condition": {
                "KeyPrefixEquals": ""
            },
            "Redirect": {
                "HostName": "example.com",
                "HttpRedirectCode": 301,
                "Protocol": "http",
                "ReplaceKeyWith": "redirect.html"
            }
        }
    ]
}
```


<span id="b28ad357"></span>
# Solution  

See [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to correctly construct a static website configuration and ensure HttpErrorCodeReturnedEquals and KeyPrefixEquals have valid values in the redirect rules.
