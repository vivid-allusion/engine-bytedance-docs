# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set up a static website configuration, the `IndexDocument` configuration's `Suffix` value is empty or contains a forward slash (/).

<span id="76b07535"></span>
# Example

When configuring a static website, the `IndexDocument` configuration's `Suffix` value is empty or contains a forward slash (/).

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "IndexDocument": {
        "Suffix": "/index.html"
    },
    "ErrorDocument": {
        "Key": "error.html"
    }
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to correctly configure the static website and ensure the `IndexDocument` configuration's `Suffix` value is valid.
