# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting up the static website configuration, the HttpRedirectCode value in the redirect rules is not within the range [301, 399].

<span id="76b07535"></span>
# Example

When configuring the static website, the HttpRedirectCode value in the redirect rules is set to an invalid value 403.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html",
        "ForbiddenSubDir": "false"
    },
    "ErrorDocument": {
        "Key": "error.html"
    },
    "RoutingRules": [
        {
            "Condition": {
                "KeyPrefixEquals": "abc",
                "HttpErrorCodeReturnedEquals": 403                
            },
            "Redirect": {
                "HostName": "example.com",
                "HttpRedirectCode": 403,
                "Protocol": "http",
                "ReplaceKeyWith": "redirect.html"
            }
        }
    ]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to correctly construct the static website configuration and ensure the HttpRedirectCode value in the redirect rules is valid.
