# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set static website configuration, both ReplaceKeyPrefixWith and ReplaceKeyWith are present in the redirect rules.

<span id="76b07535"></span>
# Example

When configuring a static website, both ReplaceKeyPrefixWith and ReplaceKeyWith are present in the redirect rules.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html",
        "ForbiddenSubDir": "false"
    },
    "ErrorDocument": {
        "Key": "error.html"
    },
    "RoutingRules": [
        {
            "Condition": {
                "KeyPrefixEquals": "abc",
                "HttpErrorCodeReturnedEquals": 403                
            },
            "Redirect": {
                "HostName": "example.com",
                "HttpRedirectCode": 301,
                "Protocol": "http",
                "ReplaceKeyPrefixWith": "redirect/",
                "ReplaceKeyWith": "redirect.html"
            }
        }
    ]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly configure the static website. Ensure that only one of ReplaceKeyPrefixWith or ReplaceKeyWith is used in the redirect rules.
