# Problem description

The static website configuration structure is invalid.

<span id="3616764e"></span>
# Root cause

The configuration structure in the request body is invalid when the user sets the static website configuration.

<span id="76b07535"></span>
# Example

The configuration structure in the request body is invalid when you configure the static website.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly construct the static website configuration.
