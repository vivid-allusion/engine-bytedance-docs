# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

The user set more than 50 redirect rules when configuring the static website.

<span id="76b07535"></span>
# Example

You set the static website configuration with a RoutingRules array length exceeding 50.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "RedirectAllRequestsTo": {
        "HostName": "example.com",
        "Protocol": "https"
    },
    "IndexDocument": {
        "Suffix": "index.html",
        "ForbiddenSubDir": "false"
    },
    "ErrorDocument": {
        "Key": "error.html"
    },
    "RoutingRules": [...51 redirect rules omitted here...]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly construct the static website configuration and ensure the number of redirect rules does not exceed 50.
