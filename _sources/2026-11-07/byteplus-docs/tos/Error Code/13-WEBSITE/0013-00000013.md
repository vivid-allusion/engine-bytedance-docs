#  Problem description

Static website configuration does not exist.

<span id="e09e016e"></span>
# Root cause

The user calls the GetBucketWebsite interface to access a bucket, but the bucket has not yet been configured with static website rules, resulting in this error.

<span id="72905f38"></span>
# Example

None.

<span id="bfe9d116"></span>
# Solution  

After configuring static website rules for the bucket, query again.
