# Problem description

Static website configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting up static website configuration, the `Protocol` field value is not `http` or `https`.

<span id="76b07535"></span>
# Example

During static website configuration, the `Protocol` field value is not `http` or `https`.

```Go
PUT /?website HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "IndexDocument":{
        "Suffix":"index.html"
    },
    "ErrorDocument":{
        "Key":"error.html"
    },
    "RoutingRules":[
        {
            "Condition":{
                "KeyPrefixEquals":"key_prefix"
            },
            "Redirect":{
                "HostName":"xxx.xx",
                "Protocol":"xxx",
                "ReplaceKeyPrefixWith":"key_prefix"
            }
        }
    ]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketWebsite](https://docs.byteplus.com/en/docs/tos/Putbucketwebsite) to properly configure static website settings, ensuring the `Protocol` field value is valid.
