# Problem description

Bucket policy denies by default.

<span id="3616764e"></span>
# Root cause

When a user accesses TOS, if the request does not match any Allow policy in the bucket policy, it is denied by default.

<span id="76b07535"></span>
# Example

If you perform a list objects operation on the bucket but no Allow policy in the bucket allows this operation, this error will be returned.

<span id="75acbc76"></span>
# Solution

Check the bucket policy configuration.
