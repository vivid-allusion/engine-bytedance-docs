# Problem description

No permission to list objects.

<span id="3616764e"></span>
# Root cause

The user attempts to list objects but lacks the permission to do so.

<span id="76b07535"></span>
# Example

If you try to list objects in a bucket but neither the bucket policy nor the IAM policy contains an Allow rule for this operation, or the bucket ACL does not permit it, this error occurs.

<span id="75acbc76"></span>
# Solution

Check the bucket policy, IAM policy, and bucket ACL configuration.
