# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is List, the second element's value is neither "$key" nor "$bucket".

<span id="76b07535"></span>
# Example

Assuming the X\-Tos\-Policy parameter text is constructed as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket1","examplebucket"]
  ]
}
```


Using it to construct the X\-Tos\-Policy parameter to access TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed instructions, see [URL presigning with the query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
