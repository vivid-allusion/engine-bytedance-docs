# Problem description

IAM policy denied access.

<span id="3616764e"></span>
# Root cause

When a user accesses TOS, the request is denied because the IAM policy does not authorize it.

<span id="76b07535"></span>
# Example

Assuming the IAM policy is configured as follows:

```Go
{
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["tos:DeleteObject"],
      "Resource": [
        "trn:tos:::test/abc*"
      ]
    }
  ]
}
```


This policy allows the IAM user to delete objects with the prefix abc in the bucket test. If the user requests to delete objects with the prefix aaa, this error is returned.

<span id="75acbc76"></span>
# Solution

Check the IAM policy configuration.
