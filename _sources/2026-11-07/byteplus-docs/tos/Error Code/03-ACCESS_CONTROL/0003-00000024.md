# Problem description

The account is overdue on payment.

<span id="3616764e"></span>
# Root cause

The resource owner’s account is overdue on payment, causing the request to be denied.

<span id="76b07535"></span>
# Example

You initiate an upload object request to a bucket, but the bucket owner’s account is overdue on payment, resulting in this error.

<span id="75acbc76"></span>
# Solution

Recharge the account before attempting access again.
