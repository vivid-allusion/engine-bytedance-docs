# Problem description

Object is disabled.

<span id="3616764e"></span>
# Root cause

The object you accessed has been disabled.

<span id="76b07535"></span>
# Example

You initiated a download operation for object abc from the bucket, but object abc has been disabled, so this error is returned.

<span id="75acbc76"></span>
# Solution

Confirm whether the bucket is overdue or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
