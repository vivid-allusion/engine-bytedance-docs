# Problem description

Missing Access\-Control\-Request\-Method header.

<span id="3616764e"></span>
# Root cause

The user initiates a CORS request, but it either lacks the Access\-Control\-Request\-Method header or the header value is empty.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Include the Access\-Control\-Request\-Method header correctly.
