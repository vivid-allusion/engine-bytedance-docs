# Problem description

Anonymous users do not have permission to access the related interface.

<span id="3616764e"></span>
# Root cause

Called CreateBucket, ListBuckets, GetBucketLocation, and other interfaces without valid signature information.

<span id="76b07535"></span>
# Example

You called the ListBuckets interface to get the bucket list without valid signature information.

```Go
GET / HTTP/1.1
Host: <TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
```


<span id="75acbc76"></span>
# Solution

The request must include valid signature information.
