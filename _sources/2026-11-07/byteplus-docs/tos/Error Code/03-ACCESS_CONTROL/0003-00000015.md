# Problem description

Request denied.

<span id="3616764e"></span>
# Root cause

The user request to TOS was denied because it did not match any bucket policy, bucket ACL, or object ACL.

<span id="76b07535"></span>
# Example

If you attempt to upload an object to a bucket but neither the bucket policy nor the bucket ACL grants you write permission, this error will be returned.

<span id="75acbc76"></span>
# Solution

Check the bucket policy, bucket ACL, or object ACL configuration.
