# Problem description

The URL parameter X\-Tos\-Policy is incorrect.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is List, the List length is not 3.

<span id="76b07535"></span>
# Example

Assuming the constructed text for the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket","examplebucket","abc"]
  ]
}
```


Using it to build the X\-Tos\-Policy parameter to access TOS will return this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For specific operations, see [URL pre-signing with the query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
