# Problem description

When retrieving the bucket list, although an IAM policy with an Allow rule matches, all bucket Project policies deny access.

<span id="3616764e"></span>
# Root cause

The user requests to list all buckets. Although the IAM policy check passes, all bucket Project policies deny the request, causing it to be rejected.

<span id="76b07535"></span>
# Example

None

<span id="75acbc76"></span>
# Solution

Check the Project policy configuration.
