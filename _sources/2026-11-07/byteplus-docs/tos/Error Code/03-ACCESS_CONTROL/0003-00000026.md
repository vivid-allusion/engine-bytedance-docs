# Problem description

SCP policy denied the request.

<span id="071bdd8f"></span>
# Root cause

The enterprise organization administrator configured an SCP policy for this account. The request does not meet the policy's allowed conditions, resulting in denial.

<span id="3426b836"></span>
# Example

Assume the SCP policy associated with account A is configured as follows:

```JSON
{
  "Statement": [
    {
      "Effect": "Deny",
      "Action": ["tos:PutBucketPolicy"],
      "Resource": [
        "trn:tos:::*"
      ]
    }
  ]
}
```


This policy prohibits account A and its sub\-users from performing bucket policy configuration on any bucket. If any user attempts this operation, this error occurs.

<span id="2f620a83"></span>
# Solution

Contact the enterprise organization administrator to review the SCP policy configuration.
