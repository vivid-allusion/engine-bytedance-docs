# Problem description

Path access method is not supported.

<span id="3616764e"></span>
# Root cause

TOS service does not allow the Path access method and only supports the VirtualHost access method.

<span id="76b07535"></span>
# Example

You sent a request using the Path method.

```Go
PUT <TOS endpoint>/bucketName/objectName HTTP/1.1
Host: <TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="75acbc76"></span>
# Solution

Access TOS using the VirtualHost method.
