# Problem description

No matching CORS rule found.

<span id="3616764e"></span>
# Root cause

The user initiated a CORS request, but none of the bucket's CORS rules matched.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Check the bucket's CORS configuration and adjust the CORS request header fields.
