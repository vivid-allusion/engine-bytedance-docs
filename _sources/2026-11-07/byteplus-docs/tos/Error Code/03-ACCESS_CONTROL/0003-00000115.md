# Problem description

The request does not support carrying the X\-Tos\-Policy parameter.

<span id="3616764e"></span>
# Root cause

The URL parameter X\-Tos\-Policy is only supported in GetObject, HeadObject, ListObjects, and ListObjectVersions interfaces.

<span id="76b07535"></span>
# Example

If you initiate an object upload request and include the X\-Tos\-Policy parameter in the request URL, this error will be returned.

<span id="75acbc76"></span>
# Solution

Remove the X\-Tos\-Policy parameter from the request URL.
