# Problem description

When retrieving the bucket list, if no Allow or Deny IAM policies match and there is no Allow Project policy, the request is denied.

<span id="3616764e"></span>
# Root cause

The user requests to list all buckets but neither matches any Allow or Deny IAM policy nor has an Allow Project policy, causing the request to be rejected.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Check the Project policy configuration.
