# Problem description

Both bucket policy and IAM policy deny access by default.

<span id="3616764e"></span>
# Root cause

When users access TOS, if the request does not match any Allow policy in the bucket policy or IAM policy, access is denied by default.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Check the configurations of the bucket policy and IAM policy.
