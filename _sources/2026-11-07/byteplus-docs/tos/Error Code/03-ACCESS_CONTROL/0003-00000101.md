# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

URL parameter X\-Tos\-Policy contains unsupported fields.

<span id="76b07535"></span>
# Example

Assume the JSON text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    {"bucket": "examplebucket"},
    ["eq", "$key", "exampleobject"]
  ],
  "test":"abc"
}
```


This JSON text contains the unsupported field "test". Using it to construct the X\-Tos\-Policy parameter to access TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For specific operations, see [URL pre-signing with the X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
