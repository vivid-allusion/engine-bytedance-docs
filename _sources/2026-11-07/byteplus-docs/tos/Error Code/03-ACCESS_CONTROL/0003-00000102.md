# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, the conditions field value is not a list.

<span id="76b07535"></span>
# Example

Assuming the constructed JSON text for the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": "abc"
}
```


Using it to construct the X\-Tos\-Policy parameter to access TOS will return this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed instructions, refer to [URL presigning with the X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
