# Problem description

no permission to access the bucket.

<span id="3616764e"></span>
# Root cause

you initiated an operation request on a bucket that does not belong to your account, but the operation is only allowed for the bucket owner.

<span id="76b07535"></span>
# Example

none.

<span id="75acbc76"></span>
# Solution

confirm that the request initiator account is the bucket owner.
