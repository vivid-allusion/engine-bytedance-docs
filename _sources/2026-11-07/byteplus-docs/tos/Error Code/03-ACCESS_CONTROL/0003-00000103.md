# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

The URL parameter X\-Tos\-Policy is not constructed from valid JSON text.

<span id="76b07535"></span>
# Example

Assume the following text constructs the X\-Tos\-Policy parameter:

```JSON
"conditions": "abc"
```


Using it to construct the X\-Tos\-Policy parameter when accessing TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter using the correct method. For specific operations, see [URL presigning with X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
