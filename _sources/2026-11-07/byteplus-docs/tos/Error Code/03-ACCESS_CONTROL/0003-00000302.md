# Problem description

missing origin header.

<span id="3616764e"></span>
# Root cause

the user initiates an OPTIONS request, but the request lacks the origin header or the header value is empty.

<span id="76b07535"></span>
# Example

none.

<span id="75acbc76"></span>
# Solution

include the origin header correctly.
