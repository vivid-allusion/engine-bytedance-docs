# Problem description

Bucket policy denied.

<span id="3616764e"></span>
# Root cause

The user's request to access TOS was blocked by the bucket policy, causing the request to be rejected.

<span id="76b07535"></span>
# Example

Assume the bucket policy is configured as follows:

```Go
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "Bucket rejection policy",
            "Effect": "Deny",
            "Principal": ["210004xxxx"],
            "Action": ["tos:PutObject"],
            "Resource": ["trn:tos:::test/*"]
        }
    ]
}
```


This policy denies the `210004xxxx` account from uploading objects to the test bucket. If this user initiates an object upload request, this error will be returned.

<span id="75acbc76"></span>
# Solution

Check the bucket policy configuration.
