# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is Map and the key is "bucket," the value is empty.

<span id="76b07535"></span>
# Example

Assuming the text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    {"bucket": ""}
  ]
}
```


Using it to construct the X\-Tos\-Policy parameter to access TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed instructions, refer to [URL presigning with the query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
