# Problem description

Anonymous access is not allowed for buckets with requester pays enabled.

<span id="071bdd8f"></span>
# Root cause

Your anonymous request to access a bucket with requester pays enabled was denied.

<span id="3426b836"></span>
# Example

&nbsp;

```Go
GET /test HTTP/1.1
Host: bucket.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
```


<span id="2f620a83"></span>
# Solution

To access a bucket with requester pays enabled, you must include valid signature information. Additionally, if you are not the bucket owner, you must include the `x-tos-request-payer` header in your request and set its value to `requester`.
