# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type of conditions is List and the second element is "$bucket," the third element is empty.

<span id="76b07535"></span>
# Example

Assuming the constructed text of the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket",""]
  ]
}
```


Using it to construct the X\-Tos\-Policy parameter to access TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed instructions, see [URL presigning with query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
