# Problem description

AssumeRole denied.

<span id="3616764e"></span>
# Root cause

Accessing TOS using STS token authentication, but the associated AssumeRole lacks permission for the operation.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Check the permission settings of AssumeRole associated with the STS token.
