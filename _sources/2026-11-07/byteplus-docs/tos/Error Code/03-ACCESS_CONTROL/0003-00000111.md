# Problem description

Incorrect URL parameter X\-Tos\-Policy.

<span id="3616764e"></span>
# Root cause

Within the URL parameter X\-Tos\-Policy, when the data type in conditions is a List, the third element is not a string.

<span id="76b07535"></span>
# Example

Assuming the text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket",123]
  ]
}
```


Using this to construct the X\-Tos\-Policy parameter to access TOS returns this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed operations, see [URL pre-signing with the X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
