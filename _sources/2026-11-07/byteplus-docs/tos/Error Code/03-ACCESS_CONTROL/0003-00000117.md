# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

The object specified in the URL parameter X\-Tos\-Policy does not match the requested object.

<span id="76b07535"></span>
# Example

You request to download object abc from the bucket, but the X\-Tos\-Policy parameter in the request URL specifies object exampleobject, triggering this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly to ensure it matches the requested object.
