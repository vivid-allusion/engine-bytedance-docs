# Problem description

The bucket is disabled.

<span id="3616764e"></span>
# Root cause

The bucket you are trying to access has been disabled.

<span id="76b07535"></span>
# Example

If you initiate an upload operation to the bucket but the bucket has been disabled, this error is returned.

<span id="75acbc76"></span>
# Solution

Confirm whether the bucket is overdue on payment, or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
