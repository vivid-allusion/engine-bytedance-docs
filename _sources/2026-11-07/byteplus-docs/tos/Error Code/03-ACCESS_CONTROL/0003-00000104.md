# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type of conditions is Map, the Map size is not 1.

<span id="76b07535"></span>
# Example

Assuming the text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    {"bucket": "examplebucket","key":"abc"}
  ]
}
```


If used to construct the X\-Tos\-Policy parameter to access TOS, this error will be returned.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed operations, see [URL pre-signing with query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
