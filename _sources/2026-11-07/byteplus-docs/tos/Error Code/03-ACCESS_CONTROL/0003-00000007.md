# Problem description

VPC policy denied.

<span id="3616764e"></span>
# Root cause

After configuring the dual fixed\-end policy, if the request does not meet the policy, the request will be denied.

<span id="76b07535"></span>
# Example

Assume the VPC endpoint is configured as follows:

```JSON
{
  "Statement": [
    {
      "Effect": "Deny",
      "Principal": ["*"],
      "Action": ["tos:PutObject"],
      "Resource": [
        "trn:tos:::tos-example/*"
      ]
    }
  ]
}
```


This policy prohibits servers within the VPC from uploading objects to the bucket tos\-example using any account. If a user attempts to upload an object, this error will be returned.

<span id="75acbc76"></span>
# Solution

Check the VPC endpoint configuration.
