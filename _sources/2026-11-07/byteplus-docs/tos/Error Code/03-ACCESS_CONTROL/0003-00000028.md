# Problem description

Accessing a Requester Pays bucket without including the correct `x-tos-request-payer` parameter.

<span id="071bdd8f"></span>
# Root cause

You accessed a Requester Pays bucket. Since you are not the bucket owner and the request does not include the correct `x-tos-request-payer` parameter, the request was denied.

<span id="3426b836"></span>
# Example

Account A accesses an object in Account B's bucket. Because the bucket enables Requester Pays but the request either lacks the `x-tos-request-payer` header or this header's value is not `requester`, this error is returned.

```Go
GET /test HTTP/1.1
Host: bucket.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
```


<span id="2f620a83"></span>
# Solution

Non\-bucket owners accessing a Requester Pays bucket must include the `x-tos-request-payer` header in their request and set it to `requester`.
