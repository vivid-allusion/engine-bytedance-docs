# Problem description

URL parameter X\-Tos\-Policy is incorrect.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, the number of bucket\-related matching condition configurations is not 1.

<span id="76b07535"></span>
# Example

Assuming the text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    {"bucket":"examplebucket"},
    ["eq","$bucket","examplebucket"]
  ]
}
```


If used to access TOS with this X\-Tos\-Policy parameter, this error is returned.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For specific operations, see [URL presigning carrying the query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
