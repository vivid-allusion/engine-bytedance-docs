# Problem description

The URL parameter X\-Tos\-Policy is incorrect.

<span id="3616764e"></span>
# Root cause

The bucket specified in the URL parameter X\-Tos\-Policy does not match the bucket being accessed in the request.

<span id="76b07535"></span>
# Example

If you request object download from bucket test, but the X\-Tos\-Policy parameter in the request URL specifies the bucket as examplebucket, this error occurs.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly to ensure the bucket specified in X\-Tos\-Policy matches the accessed bucket.
