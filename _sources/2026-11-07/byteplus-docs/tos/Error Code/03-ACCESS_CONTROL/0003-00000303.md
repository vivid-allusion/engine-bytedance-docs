# Problem description

the bucket is not configured with CORS rules.

<span id="3616764e"></span>
# Root cause

the user initiates a CORS request, but the bucket has no CORS rules configured.

<span id="76b07535"></span>
# Example

none.

<span id="75acbc76"></span>
# Solution

remove CORS request headers or configure CORS rules for the bucket before accessing it.
