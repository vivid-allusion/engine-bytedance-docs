# Problem description

The account is not authorized to use the Intelligent Tiering feature.

<span id="3616764e"></span>
# Root cause

This error occurs in two cases, explained as follows:


* When using the lifecycle feature in the bucket to convert other storage types to Intelligent Tiering, the request fails due to account restrictions.

* When uploading, copying normal objects, or merging parts, specifying the object's storage type as Intelligent Tiering, the request fails due to account restrictions.


<span id="76b07535"></span>
# Example

None.
