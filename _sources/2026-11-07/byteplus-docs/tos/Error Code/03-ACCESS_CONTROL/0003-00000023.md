# Problem description

uploading data to the bucket is forbidden.

<span id="3616764e"></span>
# Root cause

the bucket you are accessing has been forbidden from uploading data.

<span id="76b07535"></span>
# Example

if you initiate an upload object request to the bucket but uploading data is forbidden, this error will be returned.

<span id="75acbc76"></span>
# Solution

please [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
