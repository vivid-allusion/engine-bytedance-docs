# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is List and the first element is "starts\-with", the second element is "$bucket".

<span id="76b07535"></span>
# Example

Assuming the following text constructs the X\-Tos\-Policy parameter:

```JSON
{
  "conditions": [
    ["starts-with","$bucket","examplebucket"]
  ]
}
```


If this is used to construct the X\-Tos\-Policy parameter for TOS access, this error occurs.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed instructions, see [URL pre-signing with query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
