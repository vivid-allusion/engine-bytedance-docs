# Problem description

The requester is not the resource owner and is prohibited from accessing this resource.

<span id="3616764e"></span>
# Root cause

The user accessed TOS resources but is not the resource owner, resulting in the request being denied.

<span id="76b07535"></span>
# Example

You tried to download object abc from the bucket, but since you are not the owner of object abc, this error is returned.

<span id="75acbc76"></span>
# Solution

Verify that the account being used is the resource owner.
