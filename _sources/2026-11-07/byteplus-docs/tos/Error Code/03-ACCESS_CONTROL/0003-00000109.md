# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is a List, the first element value is neither "eq" nor "starts\-with".

<span id="76b07535"></span>
# Example

Assuming the text used to construct the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    ["www","$bucket","examplebucket"]
  ]
}
```


If used to construct the X\-Tos\-Policy parameter to access TOS, this error returns.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed steps, see [URL pre-signing with the X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
