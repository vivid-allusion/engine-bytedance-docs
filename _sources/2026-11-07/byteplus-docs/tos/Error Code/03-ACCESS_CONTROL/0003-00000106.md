# Problem description

URL parameter X\-Tos\-Policy error.

<span id="3616764e"></span>
# Root cause

In the URL parameter X\-Tos\-Policy, when the data type in conditions is Map, the Key value is neither "bucket" nor "key".

<span id="76b07535"></span>
# Example

Assuming the constructed text for the X\-Tos\-Policy parameter is as follows:

```JSON
{
  "conditions": [
    {"bucket1": "examplebucket"}
  ]
}
```


Using this to construct the X\-Tos\-Policy parameter to access TOS will return this error.

<span id="75acbc76"></span>
# Solution

Construct the X\-Tos\-Policy parameter correctly. For detailed steps, see [URL presigning with the query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
