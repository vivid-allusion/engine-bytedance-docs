# Problem description

IAM policy denial.

<span id="3616764e"></span>
# Root cause

The request is rejected because the IAM policy blocks user access to TOS.

<span id="76b07535"></span>
# Example

Assuming the IAM policy is configured as follows:

```Go
{ 
    "Statement": [
        {
            "Effect": "Deny",
            "Action": ["tos:PutObject"],
            "Resource": ["trn:tos:::test/*"]
        }
    ]
 }
```


This policy prohibits object upload operations to the bucket test. If a user initiates an object upload request, this error is returned.

<span id="75acbc76"></span>
# Solution

Check the IAM policy configuration.
