# Problem description

The number of custom domains bound to the bucket exceeds the limit.

<span id="3616764e"></span>
# Root cause

The number of custom domains bound to the bucket exceeded 20 when the user configured custom domains.

<span id="76b07535"></span>
# Example

None.

<span id="fffeba05"></span>
# Solution 

Delete unused custom domains and try again.
