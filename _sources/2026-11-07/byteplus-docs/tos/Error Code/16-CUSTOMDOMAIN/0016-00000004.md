# Problem description

The custom domain is not registered for ICP filing.

<span id="3616764e"></span>
# Root cause

The custom domain provided by the user during configuration has not been registered for ICP filing.

<span id="76b07535"></span>
# Example

None.

<span id="fffeba05"></span>
# Solution 

Retry after completing the ICP filing for the custom domain.
