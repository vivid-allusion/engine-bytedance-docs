# Problem description

The custom domain is already in use.

<span id="3616764e"></span>
# Root cause

When configuring a custom domain, the provided domain is already in use.

<span id="76b07535"></span>
# Example

None.

<span id="fffeba05"></span>
# Solution 

Ensure the custom domain is not already in use.
