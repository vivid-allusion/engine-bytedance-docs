# Problem description

The custom domain configuration structure is invalid.

<span id="3616764e"></span>
# Root cause

When setting a custom domain, the configuration structure in the request body is invalid.

<span id="76b07535"></span>
# Example

The configuration structure in the request body is invalid when setting a custom domain.

```Go
PUT /?customdomain HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="b28ad357"></span>
# Solution 

See [PutBucketCustomDomain](https://docs.byteplus.com/en/docs/tos/Putbucketcustomdomain) for properly constructing the custom domain configuration.
