# Problem description

The custom domain configuration is invalid.

<span id="3616764e"></span>
# Root cause

The Domain field value in the configuration is not a valid domain format when the user sets a custom domain.

<span id="76b07535"></span>
# Example

The Domain field value is not a valid domain format when you configure a custom domain.

```Go
PUT /?customdomain HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
   "CustomDomainRule": {
      "Domain": "123",
      "CertId": "certID"
   }
}
```


<span id="b28ad357"></span>
# Solution 

Refer to [PutBucketCustomDomain](https://docs.byteplus.com/en/docs/tos/Putbucketcustomdomain) to correctly create a custom domain configuration and ensure the Domain field value is in a valid domain format.
