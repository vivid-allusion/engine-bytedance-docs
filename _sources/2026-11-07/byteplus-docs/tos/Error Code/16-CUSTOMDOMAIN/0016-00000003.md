# Problem description

The custom domain has been disabled.

<span id="3616764e"></span>
# Root cause

The custom domain provided by the user when configuring the custom domain has been disabled.

<span id="76b07535"></span>
# Example

None.

<span id="fffeba05"></span>
# Solution 

Verify the custom domain is correct, or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
