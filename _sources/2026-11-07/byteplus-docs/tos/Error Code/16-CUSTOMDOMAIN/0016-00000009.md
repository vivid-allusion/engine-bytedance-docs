# Problem description

The custom domain to be deleted is empty.

<span id="3616764e"></span>
# Root cause

The user calls the DeleteBucketCustomDomain API to delete a custom domain, but the URL parameter customdomain is empty.

<span id="a1d30231"></span>
# Example

The custom domain provided when deleting the custom domain is empty.

```Go
DELETE /?customdomain= HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
```


<span id="da5461e9"></span>
# Solution 

Refer to [DeleteBucketCustomDomain](https://docs.byteplus.com/en/docs/tos/Deletebucketcustomdomain) to construct a correct request for deleting the custom domain.
