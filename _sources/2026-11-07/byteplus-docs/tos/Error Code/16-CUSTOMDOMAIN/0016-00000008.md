# Problem description

custom domain configuration does not exist.

<span id="3616764e"></span>
# Root cause

this error occurs when a user accesses a bucket using the GetBucketCustomDomain API, but the bucket has not configured a custom domain.

<span id="a1d30231"></span>
# Example

none.

<span id="da5461e9"></span>
# Solution

after configuring the bucket with a custom domain, query again.
