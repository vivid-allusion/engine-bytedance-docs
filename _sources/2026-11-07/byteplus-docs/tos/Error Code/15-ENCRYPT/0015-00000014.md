# Problem description

Incorrect parameters when accessing the KMS service.

<span id="1f81a0c9"></span>
# Root cause

Incorrect parameters when accessing the KMS service.

<span id="b151f133"></span>
# Example

The specified KMS key TRN is invalid when uploading an object.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: kms
x-tos-server-side-encryption-kms-key-id: trn:kms:cn-beijing:20***1:keyrings/ring1/keys/!#$key

......
```


<span id="514131d4"></span>
# Solution

When using SSE\-KMS encryption, provide the correct key TRN. The KMS key TRN format is: `trn:kms:{region}:{accountId}:keyrings:{ringName}:keys:{keyName}`.
