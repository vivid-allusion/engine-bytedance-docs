# Problem description

The KMS key status does not allow this operation.

<span id="1f81a0c9"></span>
# Root cause

The KMS key status does not allow this operation.

<span id="b151f133"></span>
# Example

When uploading an object, the specified KMS key has expired or been disabled.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: kms
x-tos-server-side-encryption-kms-key-id: trn:kms:cn-beijing:20***1:keyrings/ring1/keys/delete-key

......
```


<span id="514131d4"></span>
# Solution

Use a valid and active KMS key.
