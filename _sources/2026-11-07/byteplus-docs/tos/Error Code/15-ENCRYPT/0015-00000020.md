# Problem description

KMS service is not activated.

<span id="1f81a0c9"></span>
# Root cause

KMS service must be activated before use.

<span id="b151f133"></span>
# Example

Uploading SSE\-KMS encrypted objects without activating KMS service.

<span id="514131d4"></span>
# Solution

Activate KMS service before use.
