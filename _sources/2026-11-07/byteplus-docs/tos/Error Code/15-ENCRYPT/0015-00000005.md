# Problem description

The encryption algorithm provided by SSE\-C or SSE\-TOS encryption is not AES256.

<span id="1f81a0c9"></span>
# Root cause

The encryption algorithm is not specified as AES256 when using SSE\-C or SSE\-TOS encryption.

<span id="b151f133"></span>
# Example

When uploading an object, the value of the `x-tos-server-side-encryption` header is not AES256.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: RSA

......
```


<span id="514131d4"></span>
# Solution

Specify AES256 as the encryption algorithm when using SSE\-C or SSE\-TOS encryption.
