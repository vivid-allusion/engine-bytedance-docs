# Problem description

The current operation does not support server\-side encryption.

<span id="1f81a0c9"></span>
# Root cause

The current operation does not support server\-side encryption.

<span id="b151f133"></span>
# Example

When uploading an Append Object, related encryption headers such as `x-tos-server-side-encryption` are included.

```HTTP
POST /object?append HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: AES256


......
```


<span id="514131d4"></span>
# Solution

Interfaces like Append Object, image processing, and document processing do not support encrypted objects.
