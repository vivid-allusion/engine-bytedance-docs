# Problem description

The specified encryption algorithm is not supported at present.

<span id="1f81a0c9"></span>
# Root cause

The specified encryption algorithm is not supported at present.

<span id="b151f133"></span>
# Example

When uploading an object, the `x-tos-server-side-encryption` header carries a value for an unsupported encryption method.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: RSA

......
```


<span id="514131d4"></span>
# Solution

Use an encryption algorithm supported by the encryption method. For more information, see [Overview of server-side encryption](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview).
