# Problem description

KMS service API call frequency limit.

<span id="1f81a0c9"></span>
# Root cause

KMS service API call frequency is too high, reaching the limit.

<span id="b151f133"></span>
# Example

Using 500 concurrent operations to upload or download SSE\-KMS encrypted objects triggers KMS service API rate limiting.

<span id="514131d4"></span>
# Solution

Reduce the frequency of KMS service API calls.
