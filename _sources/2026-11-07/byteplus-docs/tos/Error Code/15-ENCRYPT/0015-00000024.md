# Problem description

The bucket's default encryption configuration is missing.

<span id="1f81a0c9"></span>
# Root cause

The current bucket does not have a default server\-side encryption property set.

<span id="b151f133"></span>
# Example

The bucket lacks a default encryption property, and the query for the bucket's default encryption configuration fails.

```HTTP
GET /?encryption HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

......
```


<span id="514131d4"></span>
# Solution

Set server\-side encryption for the bucket. For detailed steps, see [Server-Side Encryption Overview](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview).
