# Problem description

The key provided for SSE\-C encryption does not match its MD5.

<span id="1f81a0c9"></span>
# Root cause

The provided key does not match its MD5 when using SSE\-C encryption.

<span id="b151f133"></span>
# Example

The `x-tos-copy-source-server-side-encryption-customer-key` included during object upload does not match its MD5.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-algorithm: AES256
x-tos-copy-source-server-side-encryption-customer-key: YWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWE=
x-tos-copy-source-server-side-encryption-customer-key-md5: BVdH+Fu9K3HlXdIUBu8GdA==

......
```


<span id="514131d4"></span>
# Solution

Provide the Base64\-encoded 128\-bit MD5 digest of the encryption key when using SSE\-C encryption.
