# Problem description

The source object to be copied is SSE\-C encrypted, but the request does not contain a decryption key.

<span id="1f81a0c9"></span>
# Root cause

The source object to be copied is SSE\-C encrypted, but the request does not contain a decryption key.

<span id="b151f133"></span>
# Example 

Copy SSE\-C encrypted object without including the `x-tos-copy-source-server-side-encryption-customer-key` header.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-copy-source: bucketname/sse-c-object
```


<span id="514131d4"></span>
# Solution

Include the decryption key when copying an SSE\-C encrypted source object.
