# Problem description

The key provided for SSE\-C encryption is empty.

<span id="1f81a0c9"></span>
# Root cause

The encryption key was not provided when using SSE\-C encryption.

<span id="b151f133"></span>
# Example

When uploading an object, the `x-tos-server-side-encryption-customer-key` header field was not included.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-algorithm: AES256
x-tos-copy-source-server-side-encryption-customer-key-md5: ACdH+Fu9K3HlXdIUBu8GdA==

......
```


<span id="514131d4"></span>
# Solution

When using SSE\-C encryption, provide TOS with a 256\-bit, Base64\-encoded encryption key using the `x-tos-server-side-encryption-customer-key` header field to encrypt or decrypt your data. For more information, refer to [server-side encryption with customer-provided keys (SSE-C)](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview#.5L2_55So55So5oi35o-Q5L6b5a-G6ZKl55qE5pyN5Yqh56uv5Yqg5a-G77yIc3NlLWPvvIk=).
