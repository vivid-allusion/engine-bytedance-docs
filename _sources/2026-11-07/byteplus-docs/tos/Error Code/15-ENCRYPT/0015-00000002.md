# Problem description

The algorithm value provided for SSE\-C encryption is empty.

<span id="1f81a0c9"></span>
# Root cause

When using SSE\-C encryption, the encryption algorithm is not provided.

<span id="b151f133"></span>
# Example

When uploading an object, the `x-tos-server-side-encryption-customer-algorithm` header is not included.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-key: YWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWE=
x-tos-copy-source-server-side-encryption-customer-key-md5: xxx

......
```


<span id="514131d4"></span>
# Solution

When using SSE\-C encryption, set the encryption algorithm to AES256 using the `x-tos-server-side-encryption-customer-algorithm` header. For more information, see [server-side encryption with customer-provided keys (SSE-C)](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview#.5L2_55So55So5oi35o-Q5L6b5a-G6ZKl55qE5pyN5Yqh56uv5Yqg5a-G77yIc3NlLWPvvIk=).
