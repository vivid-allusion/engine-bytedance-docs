# Problem description

KMS service is being activated, please try again later.

<span id="1f81a0c9"></span>
# Root cause

KMS service is being activated and is temporarily unavailable.

<span id="b151f133"></span>
# Example

Activating the KMS service for the first time and immediately uploading an SSE\-KMS encrypted object.

<span id="514131d4"></span>
# Solution

Wait until the KMS service activates to use it normally.
