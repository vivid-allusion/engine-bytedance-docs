# Problem description

The current Region does not support the server\-side encryption feature.

<span id="1f81a0c9"></span>
# Root cause

The current Region does not enable the server\-side encryption function, causing it to be unavailable.

<span id="b151f133"></span>
# Example

Uploading an SSE\-KMS encrypted object, but the current Region does not support the server\-side encryption feature.

<span id="514131d4"></span>
# Solution

Select a Region that supports server\-side encryption to upload server\-side encrypted objects. For details, see [Server-side encryption overview](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview).
