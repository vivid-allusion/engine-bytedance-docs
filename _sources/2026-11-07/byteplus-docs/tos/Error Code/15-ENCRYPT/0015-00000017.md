# Problem description

KMS service master key call rate limit.

<span id="1f81a0c9"></span>
# Root cause

KMS service master key call frequency is too high, reaching the limit.

<span id="b151f133"></span>
# Example 

Using 500 concurrent uploads of SSE\-KMS encrypted objects triggers KMS service key rate limiting.

<span id="514131d4"></span>
# Solution

Reduce the call frequency of SSE\-KMS encryption.
