# Problem description

SSE\-KMS encryption does not support default keys yet.

<span id="1f81a0c9"></span>
# Root cause

Currently, SSE\-KMS only supports custom keys created by customers and does not support default keys managed by TOS services.

<span id="b151f133"></span>
# Example

When uploading an object encrypted with SSE\-KMS, the `x-tos-server-side-encryption-kms-key-id` header is not included.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: kms

......
```


<span id="514131d4"></span>
# Solution

Use a custom key created through KMS to complete SSE\-KMS encryption.
