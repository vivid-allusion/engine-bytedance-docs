# Problem description

The format of the SSE\-KMS encryption key provided in the request is incorrect.

<span id="1f81a0c9"></span>
# Root cause

The key format is incorrect when using SSE\-KMS encryption.

<span id="b151f133"></span>
# Example

When uploading an object, the TRN format of the key specified in `x-tos-server-side-encryption-kms-key-id` is incorrect.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: kms
x-tos-server-side-encryption-kms-key-id: trn:kms:cn-beijing:20***1:ring1/key1

......
```


<span id="514131d4"></span>
# Solution

When using SSE\-KMS encryption, provide the correct key format. The KMS key trn format is: `trn:kms:{region}:{accountId}:keyrings:{ringName}:keys:{keyName}`.
