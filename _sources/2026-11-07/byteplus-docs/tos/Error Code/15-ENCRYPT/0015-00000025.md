# Problem description

The bucket's server\-side encryption configuration format is invalid.

<span id="1f81a0c9"></span>
# Root cause

The bucket's server\-side encryption configuration format is invalid.

<span id="b151f133"></span>
# Example

Configuring the bucket's server\-side encryption with invalid request parameters.

```HTTP
PUT /?encryption HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rule": {
        "ApplyServerSideEncryptionByDefault": {
        }
    }
}
```


<span id="514131d4"></span>
# Solution

Configure the bucket using the correct server\-side encryption format. For more information, see [Setting bucket encryption](https://docs.byteplus.com/en/docs/tos/Set-server-side-encryption-for-the-bucket).
