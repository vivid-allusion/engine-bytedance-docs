# Problem description

The authentication information is missing when executing SSE\-KMS encryption or decryption requests.

<span id="1f81a0c9"></span>
# Root cause

An anonymous user executed the SSE\-KMS encryption or decryption request.

<span id="b151f133"></span>
# Example

No signature information is included when uploading an SSE\-KMS encrypted object.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
x-tos-server-side-encryption: kms
x-tos-server-side-encryption-kms-key-id: trn:kms:cn-beijing:20***1:keyrings/ring1/keys/key1

......
```


<span id="514131d4"></span>
# Solution

Use a user with KMS key access permissions to perform SSE\-KMS encryption or decryption requests.
