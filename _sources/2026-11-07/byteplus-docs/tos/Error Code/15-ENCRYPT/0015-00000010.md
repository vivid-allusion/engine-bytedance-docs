# Problem description

The server\-side encryption interface was requested without using the HTTPS protocol.

<span id="1f81a0c9"></span>
# Root cause

The server\-side encryption interface request did not use the HTTPS protocol.

<span id="b151f133"></span>
# Example

Uploading SSE\-C or SSE\-KMS encrypted objects using the HTTP protocol.

<span id="514131d4"></span>
# Solution

Use the HTTPS protocol to initiate the server\-side encryption request.
