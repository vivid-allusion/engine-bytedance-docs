# Problem description

The encryption key or method provided in the request does not match the object's encryption status.

<span id="1f81a0c9"></span>
# Root cause

The encryption key or method provided in the request does not match the object's encryption status.

<span id="b151f133"></span>
# Example

Downloading an SSE\-C encrypted object without including the `x-tos-server-side-encryption-customer-key` header or including the `x-tos-server-side-encryption` header.

```HTTP
GET /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption: AES256

......
```


<span id="514131d4"></span>
# Solution

Use the encryption method or key that matches the object's encryption status. For details on encryption methods supported by TOS, see the [server-side encryption overview](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview).
