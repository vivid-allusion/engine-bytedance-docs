# Problem description

The key format provided for SSE\-C encryption is invalid.

<span id="1f81a0c9"></span>
# Root cause

The key format provided during SSE\-C encryption is invalid.

<span id="b151f133"></span>
# Example

The `x-tos-server-side-encryption-customer-key` header value included when uploading the object is in an invalid format.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-algorithm: AES256
x-tos-copy-source-server-side-encryption-customer-key: aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
x-tos-copy-source-server-side-encryption-customer-key-md5: ACdH+Fu9K3HlXdIUBu8GdA==

......
```


<span id="514131d4"></span>
# Solution

Provide a 256\-bit, Base64\-encoded encryption key when using SSE\-C encryption.
