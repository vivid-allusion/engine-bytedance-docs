# Problem description

Request parameters include both SSE\-C, SSE\-KMS, or SSE\-TOS encryption.

<span id="1f81a0c9"></span>
# Root cause

Request parameters include both SSE\-C, SSE\-KMS, or SSE\-TOS encryption.

<span id="b151f133"></span>
# Example

When uploading an object, both `x-tos-server-side-encryption-customer-key` and `x-tos-server-side-encryption` headers are included.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-key: YWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWE=
x-tos-server-side-encryption: AES256

......
```


<span id="514131d4"></span>
# Solution

Set only one encryption method. For details on server\-side encryption, see [Server-Side Encryption Overview](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview).
