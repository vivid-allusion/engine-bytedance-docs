# Problem description

MD5 value of the key provided by SSE\-C encryption is empty.

<span id="1f81a0c9"></span>
# Root cause

When using SSE\-C encryption, the Base64\-encoded 128\-bit MD5 digest of the encryption key is not provided.

<span id="b151f133"></span>
# Example

When uploading an object, the `x-tos-server-side-encryption-customer-key-MD5` header is missing.

```HTTP
PUT /object HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-server-side-encryption-customer-algorithm: AES256
x-tos-copy-source-server-side-encryption-customer-key: YWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWFhYWE=

......
```


<span id="514131d4"></span>
# Solution

When using SSE\-C encryption, use the `x-tos-server-side-encryption-customer-key-MD5` header to provide TOS with the Base64\-encoded 128\-bit MD5 digest of the encryption key to ensure the key is transmitted correctly. For more information, see [Server-Side Encryption with Customer-Provided Keys (SSE-C)](https://docs.byteplus.com/en/docs/tos/Server-side-encryption-overview#.5L2_55So55So5oi35o-Q5L6b5a-G6ZKl55qE5pyN5Yqh56uv5Yqg5a-G77yIc3NlLWPvvIk=).
