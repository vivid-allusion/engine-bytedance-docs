# Problem description

The account is overdue and cannot use the KMS service.

<span id="1f81a0c9"></span>
# Root cause

The account is overdue, preventing use of the KMS service.

<span id="b151f133"></span>
# Example

The account is in overdue status when accessing TOS to upload SSE\-KMS encrypted objects.

<span id="514131d4"></span>
# Solution

Recharge and settle the overdue bill within the specified time to resume normal use of the KMS service.
