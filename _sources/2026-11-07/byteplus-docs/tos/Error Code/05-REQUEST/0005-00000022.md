# Problem description

The request `x-tos-hash-crc64ecma` checksum does not match.

<span id="3616764e"></span>
# Root cause

The user request contains `x-tos-hash-crc64ecma`, but it does not match the server\-calculated crc64.

<span id="76b07535"></span>
# Example

You initiated an object upload request with `x-tos-hash-crc64ecma` to verify that the message content is consistent with the sent data.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization xxx
Content-Length: 100
x-tos-hash-crc64ecma: 123
<put content>
```


<span id="ff6eb7cf"></span>
# Solution

Make sure the `x-tos-hash-crc64ecma` value is correct.
