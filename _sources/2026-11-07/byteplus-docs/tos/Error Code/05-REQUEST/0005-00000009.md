# Problem description

The request body size exceeds the limit.

<span id="3616764e"></span>
# Root cause

The request body size in the user's request exceeds the interface limit.

<span id="76b07535"></span>
# Example

You initiated a request to bind a custom domain, but the request body size exceeds the interface limit.

```Go
PUT /?customdomain HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 1048576

{
   "CustomDomainRule": {
      "Domain": ...About 1MB of content omitted here...,
      "CertId": "certID"
   }
}
```


<span id="404c6ef3"></span>
# Solution

Confirm that the request body does not exceed the interface limit.
