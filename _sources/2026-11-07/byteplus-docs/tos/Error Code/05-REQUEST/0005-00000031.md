# Problem description

The Content\-Length header does not match the size of the request body.

<span id="3616764e"></span>
# Root cause

The user request includes a Content\-Length header, but its value does not match the size of the request body.

<span id="76b07535"></span>
# Example

You initiated a request to bind a custom domain, but the Content\-Length header value does not match the size of the request body.

```Go
PUT /?customdomain HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 2048
[1024 bytes of config]
```


<span id="e983d4a4"></span>
# Solution

Check the Content\-Length calculation logic to ensure it matches the size of the request body.
