# Problem description

The value of `x-tos-copy-source-if-unmodified-since` or `If-Unmodified-Since` in the request is invalid.

<span id="3616764e"></span>
# Root cause

The user request includes `x-tos-copy-source-if-unmodified-since` or `If-Unmodified-Since`, but the value is not in GMT format.

<span id="76b07535"></span>
# Example

You initiated an object download request, but the `If-Unmodified-Since` header value is not in GMT format.

```Go
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
If-Unmodified-Since: abc
Authorization: authorization xxx
```


<span id="103ff35e"></span>
# Solution

Ensure the value of `x-tos-copy-source-if-unmodified-since` or `If-Unmodified-Since` is in GMT format.
