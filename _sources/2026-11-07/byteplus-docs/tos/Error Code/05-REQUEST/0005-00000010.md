# Problem description

The request lacks the Content\-MD5 header or the header value is empty.

<span id="3616764e"></span>
# Root cause

The user\-initiated request does not include the Content\-MD5 header or its value is empty.

<span id="76b07535"></span>
# Example

Your request to configure bucket encryption is missing the Content\-MD5 header.

```Go
PUT /?encryption HTTPS
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx

{
    "Rule":{
        "ApplyServerSideEncryptionByDefault":{
            "SSEAlgorithm":"KMS",
            "KMSMasterKeyID":"trn:kms:cn-beijing:200000****:keyrings/ring-test/keys/key-test"
        }
    }
}
```


<span id="404c6ef3"></span>
# Solution

Include the correct Content\-MD5 header as required by the interface.
