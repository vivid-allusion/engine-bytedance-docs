# Problem description

Conditional request parameters are not met.

<span id="3616764e"></span>
# Root cause

The user request contains conditional request parameters such as `If-Modified-Since` and `If-Match`, but one of these parameters is not met, resulting in a request error.

<span id="76b07535"></span>
# Example

None.

<span id="5956024b"></span>
# Solution

Adjust the parameters that do not meet the conditions according to the error message.
