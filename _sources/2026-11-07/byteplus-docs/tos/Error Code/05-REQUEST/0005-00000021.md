# Problem description

The `x-tos-hash-crc64ecma` field value in the request is invalid.

<span id="3616764e"></span>
# Root cause

The user request includes `x-tos-hash-crc64ecma`, but the field value is invalid, such as a non\-valid integer.

<span id="76b07535"></span>
# Example

You initiate an object upload request carrying `x-tos-hash-crc64ecma` to verify that the message content matches what was sent.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization xxx
Content-Length: 100
x-tos-hash-crc64ecma: abc
<put content>
```


<span id="ff6eb7cf"></span>
# Solution

Ensure the `x-hash-crc64ecma` value is correct.
