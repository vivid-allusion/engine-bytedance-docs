# Problem description

The streaming upload data format is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiated a streaming upload object request, but the data format was incorrect, causing the request to fail.

<span id="76b07535"></span>
# Example

None.

<span id="5956024b"></span>
# Solution

Ensure the streaming upload chunk data format is correct.
