# Problem description

The request carries the header field x\-tos\-traffic\-limit and the URL parameter x\-tos\-traffic\-limit simultaneously.

<span id="3616764e"></span>
# Root cause

The user includes x\-tos\-traffic\-limit settings in both the request header and the URL.

<span id="76b07535"></span>
# Example

You initiate a download object request with x\-tos\-traffic\-limit settings in both the header and the URL.

```Go
GET /objectName/obj?x-tos-traffic-limit=819200 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
x-tos-traffic-limit: 819200
```


<span id="75acbc76"></span>
# Solution

Use either the header or the URL parameter to carry the x\-tos\-traffic\-limit setting.
