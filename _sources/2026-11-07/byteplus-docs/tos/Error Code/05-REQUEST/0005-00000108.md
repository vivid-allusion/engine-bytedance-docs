# Problem description

When listing multiple versions of objects, the URL parameter `key-marker` is empty.

<span id="3616764e"></span>
# Root cause

When users list multiple versions of objects, the URL parameter `version-id-marker` is not empty, but the `key-marker` parameter is empty.

<span id="76b07535"></span>
# Example

You send a request to list multiple versions of objects, where the `version-id-marker` field in the request is not empty, but the `key-marker` field is empty.

```Go
GET /?versions&version-id-marker=123&key-marker= HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="e436534d"></span>
# Solution

When the `version-id-marker` field is not empty, ensure the `key-marker` field is also not empty.
