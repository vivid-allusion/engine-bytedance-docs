# Problem description

The request does not support carrying the Range header.

<span id="3616764e"></span>
# Root cause

The user initiated an object copy request and included the Range header in the request headers.

<span id="76b07535"></span>
# Example

You initiated an object copy request including the Range header.

```Go
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Range: bytes=0-4
x-tos-copy-source: /sourcebucketname/SourceObjectName
```


<span id="404c6ef3"></span>
# Solution

Remove the Range header from the request.
