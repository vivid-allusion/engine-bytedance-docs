# Problem description

The request is missing the Content\-Length header.

<span id="3616764e"></span>
# Root cause

The user omits the Content\-Length header when uploading an object.

<span id="76b07535"></span>
# Example

When uploading an object with the `x-tos-content-sha256` header, the request lacks the Content\-Length header.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization xxx
x-tos-content-sha256: xxx
<put content>
```


<span id="ff6eb7cf"></span>
# Solution

Include the correct Content\-Length header.
