# Problem description

Invalid value in request header x\-tos\-website\-redirect\-location.

<span id="3616764e"></span>
# Root cause

The user request carries the x\-tos\-website\-redirect\-location header, whose value does not start with "http://", "https://", or "/".

<span id="76b07535"></span>
# Example

You initiate an AppendObject request with an invalid value in the x\-tos\-website\-redirect\-location header.

```Go
POST /objectName?append&offset=Offset HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
x-tos-website-redirect-location: abc
<append data>
```


<span id="75acbc76"></span>
# Solution

Ensure the x\-tos\-website\-redirect\-location header has a valid value.
