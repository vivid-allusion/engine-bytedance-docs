# Problem description

The URL parameters `marker`, `key-marker`, or `start-after` have illegal values when listing objects.

<span id="3616764e"></span>
# Root cause

When users list objects, the URL parameters `marker`, `key-marker`, or `start-after` have values that are not UTF\-8 encoded.

<span id="76b07535"></span>
# Example

None.

<span id="a0a66e48"></span>
# Solution

Ensure the URL parameters `marker`, `key-marker`, or `start-after` use UTF\-8 encoding for their values.
