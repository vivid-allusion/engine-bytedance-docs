# Problem description

URL parameter `max-uploads` has an invalid value.

<span id="3616764e"></span>
# Root cause

The URL parameter `max-uploads` in the user request has a non\-numeric value.

<span id="76b07535"></span>
# Example

You initiated a request to list multipart upload tasks, but the URL parameter `max-uploads` has a non\-numeric value.

```Go
GET /?uploads&max-uploads=abc HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="01ab3c0d"></span>
# Solution

Ensure the URL parameter `max-uploads` has a valid value.
