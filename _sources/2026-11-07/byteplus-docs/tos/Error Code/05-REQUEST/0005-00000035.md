# Problem description

The `partNumber` field value in the request is invalid.

<span id="3616764e"></span>
# Root cause

When a user sends a Head or Get request to a multipart object, the `partNumber` field value in the request does not match any uploaded part number in the multipart object.

<span id="76b07535"></span>
# Example

None.

<span id="d7d9fc64"></span>
# Solution

Ensure the `partNumber` value matches an uploaded part number in the multipart object.
