# Problem description

The `versionId` parameter in the request is invalid.

<span id="3616764e"></span>
# Root cause

The `versionId` parameter value is invalid, causing the request to fail. A valid `versionId` parameter consists of 20 uppercase hexadecimal characters.

<span id="76b07535"></span>
# Example

In the following object copy request, the `versionId` parameter in the x\-tos\-copy\-source header contains illegal characters.

```Go
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
x-tos-copy-source: /sourcebucketname/SourceObjectName?versionId=%%%%aaa
```


<span id="404c6ef3"></span>
# Solution

Ensure the `versionId` parameter value is valid.
