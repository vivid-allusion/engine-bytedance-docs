# Problem description

website domain request restrictions.

<span id="3616764e"></span>
# Root cause

The user initiates requests other than GET or HEAD using the website domain.

<span id="76b07535"></span>
# Example

You initiate an object upload request using the website domain.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
Content-length: length
<put data>
```


<span id="404c6ef3"></span>
# Solution

Use the correct domain to initiate requests. The website domain only supports GET and HEAD requests.
