# Problem description

URL parameter `uploadId` is invalid.

<span id="3616764e"></span>
# Root cause

The URL parameter `uploadId` in the user request exceeds 100 characters in length.

<span id="76b07535"></span>
# Example

None.

<span id="c46b9b9e"></span>
# Solution

Ensure the URL parameter `uploadId` is less than 100 characters long.
