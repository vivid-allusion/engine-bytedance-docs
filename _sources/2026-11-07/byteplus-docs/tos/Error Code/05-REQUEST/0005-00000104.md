# Problem description

The URL parameter `max-keys` has an invalid value when listing objects.

<span id="3616764e"></span>
# Root cause

When users list objects, the `max-keys` field in the request contains a non\-integer value.

<span id="76b07535"></span>
# Example

You sent a list objects request, but the `max-keys` field in the request has an invalid value:

```Go
GET /?max-keys=abc HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="e436534d"></span>
# Solution

Ensure the URL parameter `max-keys` is set to an integer value.
