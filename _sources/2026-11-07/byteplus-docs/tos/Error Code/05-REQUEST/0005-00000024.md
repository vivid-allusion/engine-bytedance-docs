# Problem description

URL parameter `encoding-type` specifies an invalid encoding method.

<span id="3616764e"></span>
# Root cause

The URL parameter `encoding-type` in the user request has an invalid value; currently, only "url" is supported.

<span id="76b07535"></span>
# Example

You initiated a request to list objects in a bucket, but the URL parameter `encoding-type` is set to a value other than url.

```Go
GET /?encoding-type=base64 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="01ab3c0d"></span>
# Solution

Ensure the URL parameter `encoding-type` has a valid value.
