# Problem description

The value of the `x-tos-copy-source-part-number` field in the request is invalid.

<span id="3616764e"></span>
# Root cause

The user request includes `x-tos-copy-source-part-number`, but its value is invalid, such as a non\-valid integer or not within the [1,10000] range.

<span id="76b07535"></span>
# Example

None.

<span id="5956024b"></span>
# Solution

Ensure the value of the `x-tos-copy-source-part-number` field is valid.
