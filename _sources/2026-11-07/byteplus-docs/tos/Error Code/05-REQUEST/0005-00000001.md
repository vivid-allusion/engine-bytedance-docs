# Problem description

The request Content\-MD5 validation does not match.

<span id="3616764e"></span>
# Root cause

The user's request includes Content\-MD5, but it does not match the MD5 calculated by the server.

<span id="76b07535"></span>
# Example

You initiate an object upload request with Content\-MD5 to verify that the message content matches what was sent.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
Content-length: length
Content-MD5: 1B2M2Y8AsgTpgAm***
<put data>
```


<span id="75acbc76"></span>
# Solution

Verify that the Content\-MD5 calculation method is correct.
