# Problem description

When listing objects, the URL parameter `prefix` has an invalid value.

<span id="3616764e"></span>
# Root cause

When users list objects, the `prefix` field in the request either exceeds 1024 characters in length or contains the 0x00 character.

<span id="76b07535"></span>
# Example

None.

<span id="e436534d"></span>
# Solution

Ensure the URL parameter `prefix` field has a valid value.
