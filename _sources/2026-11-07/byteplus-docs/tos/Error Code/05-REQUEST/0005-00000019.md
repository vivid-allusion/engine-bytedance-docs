# Problem description

Request x\-tos\-content\-sha256 verification does not match.

<span id="3616764e"></span>
# Root cause

The user includes x\-tos\-content\-sha256 in the request when uploading an object, but it does not match the SHA256 calculated by the server.

<span id="76b07535"></span>
# Example

You send an object upload request carrying x\-tos\-content\-sha256 to verify that the message content matches what was sent.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization xxx
Content-Length: 100
x-tos-content-sha256: xxx
<put content>
```


<span id="ff6eb7cf"></span>
# Solution

Verify that the calculation method for x\-tos\-content\-sha256 is correct.
