# Problem description

URL parameter `partNumber` has an invalid value.

<span id="3616764e"></span>
# Root cause

The URL parameter `partNumber` in the user request is either not a valid integer or is out of the range [1, 10000].

<span id="76b07535"></span>
# Example

In the following multipart upload requests, the `partNumber` parameter has an invalid value.

```Go
PUT /objectName?partNumber=10001&uploadId=UploadId HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
Content-Length: length
<part content>
```


<span id="3a322c70"></span>
# Solution

Ensure the URL parameter `partNumber` has a valid value.
