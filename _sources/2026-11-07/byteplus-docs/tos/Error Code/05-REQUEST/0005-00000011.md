# Problem description

The Content\-Length header value is not a valid integer or is out of the allowed range.

<span id="3616764e"></span>
# Root cause

The Content\-Length header in the user request is either not a valid integer or is outside the allowed range for the interface.

<span id="76b07535"></span>
# Example

You initiated a request to bind a custom domain, but the Content\-Length header value is negative.

```Go
PUT /?customdomain HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: -1

{
   "CustomDomainRule": {
      "Domain": "example.com",
      "CertId": "certID"
   }
}
```


<span id="404c6ef3"></span>
# Solution

Check if the Content\-Length header value is an integer and within the valid range.
