# Problem description

Range header contains invalid value.

<span id="3616764e"></span>
# Root cause

The user request includes a Range header with an invalid value.

<span id="76b07535"></span>
# Example

You initiated an object download request with a Range header, but the header value is invalid.

```Go
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Range: bytes=a-b
Authorization: authorization xxx
```


<span id="5956024b"></span>
# Solution

Refer to the [GetObject](https://docs.byteplus.com/en/docs/tos/reference--getobject) API parameter description and correctly specify the Range header value.
