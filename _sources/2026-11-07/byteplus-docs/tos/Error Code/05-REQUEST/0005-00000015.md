# Problem description

The request carries both the URL parameter `partNumber` and the header Range.

<span id="3616764e"></span>
# Root cause

The user requests with both the URL parameter `partNumber` and the header Range, causing the request error.

<span id="76b07535"></span>
# Example

None.

<span id="3a322c70"></span>
# Solution

When making a request, choose either the URL parameter `partNumber` or the header Range.
