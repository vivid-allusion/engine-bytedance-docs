# Problem description

When listing objects, the URL parameter `delimiter` has an illegal value.

<span id="3616764e"></span>
# Root cause

When users list objects, the length of the `delimiter` field value in the request exceeds 56 or contains a 0x00 character.

<span id="76b07535"></span>
# Example

None.

<span id="e436534d"></span>
# Solution

Ensure the URL parameter `delimiter` field value is valid.
