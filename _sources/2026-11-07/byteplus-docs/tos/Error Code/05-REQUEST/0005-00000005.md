# Problem description

concurrent modification of objects or bucket configuration.

<span id="3616764e"></span>
# Root cause

users concurrently modify objects or bucket configuration, causing conflicts.

<span id="76b07535"></span>
# Examples

none.

<span id="404c6ef3"></span>
# Solution

do not modify objects or bucket configuration concurrently.
