# Problem description

The amount of custom metadata headers x\-tos\-meta\-\* is too large.

<span id="3616764e"></span>
# Root cause

The amount of custom metadata headers x\-tos\-meta\-\* carried in the user request is too large, exceeding the interface limit.

<span id="76b07535"></span>
# Example

You initiated an object metadata update request carrying too many custom metadata fields.

```Go
POST /ObjectName?metadata HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization string
Content-Type: application/x-www-form-urlencoded
x-tos-meta-test: meta_modify
x-tos-meta-aaa: ...10KB content omitted here ...
```


<span id="404c6ef3"></span>
# Solution

Ensure the data volume in custom metadata headers does not exceed the interface limit.
