# Problem description

The configuration in the request body is invalid.

<span id="3616764e"></span>
# Root cause

The configuration information in the request body provided by the user does not match the format defined by the server.

<span id="76b07535"></span>
# Example

None.

<span id="103ff35e"></span>
# Solution

Adjust the configuration in the request body according to the interface definition.
