# Problem description

When listing objects, the URL parameter `reverse` has an invalid value.

<span id="3616764e"></span>
# Root cause

When users list objects, the `reverse` field in the request has a non\-bool value.

<span id="76b07535"></span>
# Example

You initiated a request to list objects, but the `reverse` field in the request has an invalid value.

```Go
GET /?reverse=123 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="e436534d"></span>
# Solution

Ensure the URL parameter `reverse` field value is of bool type.
