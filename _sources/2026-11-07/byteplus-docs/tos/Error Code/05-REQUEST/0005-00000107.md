# Problem description

When listing objects, the URL parameter `continuation-token` has an invalid value.

<span id="3616764e"></span>
# Root cause

When using the ListObjectsV2 interface to list objects, the `continuation-token` field in the request contains an invalid value.

<span id="76b07535"></span>
# Example

You use the ListObjectsV2 interface to list objects, but the `continuation-token` field in the request has an invalid value.

```Go
GET /?list-type=2&continuation-token=123 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="e436534d"></span>
# Solution

Ensure the `continuation-token` field value comes from the `NextContinuationToken` value in the response of the previous ListObjectsV2 request.
