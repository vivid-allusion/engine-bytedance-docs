# Problem description

The value of the `x-tos-copy-source-if-modified-since` or `If-Modified-Since` field in the request is invalid.

<span id="3616764e"></span>
# Root cause

The user request includes `x-tos-copy-source-if-modified-since` or `If-Modified-Since`, but the value is not in GMT format.

<span id="76b07535"></span>
# Example

You initiated an object download request, but the `If-Modified-Since` header value in the request is not in GMT format.

```Go
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
If-Modified-Since: abc
Authorization: authorization xxx
```


<span id="103ff35e"></span>
# Solution

Ensure that the value for `x-tos-copy-source-if-modified-since` or `If-Modified-Since` is in GMT format.
