# Problem description

When listing objects, the URL parameters `marker`, `key-marker`, or `start-after` do not use the value of the `prefix` parameter as a prefix.

<span id="3616764e"></span>
# Root cause

When listing objects, the `marker`, `key-marker`, or `start-after` fields in the request do not use the value of the `prefix` field as a prefix.

<span id="76b07535"></span>
# Example

You send a list objects request with an invalid value in the `marker` field.

```Go
GET /?marker=abc&prefix=aaa HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="d7d9fc64"></span>
# Solution

Ensure that the URL parameters `marker`, `key-marker`, or `start-after` use the value of the `prefix` field as a prefix.
