# Problem description

The network connection was closed.

<span id="3616764e"></span>
# Root cause

The user actively canceled or the request connection was closed due to network issues.

<span id="76b07535"></span>
# Example

None.

<span id="404c6ef3"></span>
# Solution

Confirm the network environment is normal and try again.
