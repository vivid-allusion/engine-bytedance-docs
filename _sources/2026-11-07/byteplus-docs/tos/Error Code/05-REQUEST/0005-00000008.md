# Problem description

The request body is empty.

<span id="3616764e"></span>
# Root cause

The user request contains an empty body.

<span id="76b07535"></span>
# Example

You sent a batch delete objects request without a valid body.

```Go
POST /?delete HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization xxx
Content-MD5: md5 xxx
```


<span id="404c6ef3"></span>
# Solution

Send the request with a valid body.
