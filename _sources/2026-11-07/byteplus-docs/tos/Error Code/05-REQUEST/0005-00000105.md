# Problem description

The URL parameter `version-id-marker` contains an invalid value when listing multiple version objects.

<span id="3616764e"></span>
# Root cause

The `version-id-marker` field value in the request is invalid when the user lists multiple version objects. This field should contain 20 uppercase hexadecimal digit characters.

<span id="76b07535"></span>
# Example

You sent a request to list multiple version objects, but the `version-id-marker` field value in the request is invalid.

```Go
GET /versions?key-marker=abc&version-id-marker=123 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="e436534d"></span>
# Solution

Ensure the URL parameter `version-id-marker` field value is valid.
