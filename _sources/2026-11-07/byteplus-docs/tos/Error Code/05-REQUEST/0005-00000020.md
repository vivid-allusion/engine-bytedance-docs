# Problem description

The Content\-MD5 header field value is invalid.

<span id="3616764e"></span>
# Root cause

The user request includes a Content\-MD5 header, but its value is invalid, such as when the length after Base64 decoding is less than 16.

<span id="76b07535"></span>
# Example

You initiate an object upload request with Content\-MD5 to verify that the message content remains unchanged during transmission.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
Authorization: authorization xxx
Content-Length: 100
Content-MD5: 123
<put content>
```


<span id="ff6eb7cf"></span>
# Solution

Verify that the Content\-MD5 calculation method is correct.
