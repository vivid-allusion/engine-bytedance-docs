# Problem description

The URL parameters `marker`, `key-marker`, or `start-after` have illegal values when listing objects.

<span id="3616764e"></span>
# Root cause

The URL parameters `marker`, `key-marker`, or `start-after` have values longer than 1024 characters or contain the 0x00 character when listing objects.

<span id="76b07535"></span>
# Example

None.

<span id="a0a66e48"></span>
# Solution

Ensure the URL parameters `marker`, `key-marker`, or `start-after` have legal values.
