# Problem description

Invalid x\-tos\-traffic\-limit setting.

<span id="3616764e"></span>
# Root cause

The x\-tos\-traffic\-limit value in the request header or URL parameter is not a valid number or falls outside the range of [245760, 838860800].

<span id="76b07535"></span>
# Example

You initiate an object download request with the x\-tos\-traffic\-limit value set to 1 in the URL parameter.

```Go
GET /objectName/obj?x-tos-traffic-limit=1 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
x-tos-traffic-limit: 1
```


<span id="75acbc76"></span>
# Solution

Ensure the x\-tos\-traffic\-limit parameter value is valid.
