# Problem description

The object size uploaded via the PostObject interface does not meet the request policy requirements.

<span id="3616764e"></span>
# Root cause

The user uploads an object using the PostObject request and restricts the object size in the request policy through the `content-length-range` field. The request fails because the uploaded object does not meet this size restriction.

<span id="76b07535"></span>
# Example

You initiate a PostObject request, with the policy field roughly encoded as follows:

```JSON
{
    "conditions": [["content-length-range",1048576,10485760]]
    ...The remaining fields are omitted here...
}
```


If the uploaded object does not meet the minimum limit of 1,048,576 bytes set by `content-length-range`, this error is returned.

<span id="e983d4a4"></span>
# Solution

Ensure the object size uploaded by PostObject meets the requirements of the `content-length-range` field.
