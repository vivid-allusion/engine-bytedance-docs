# Problem description

In lifecycle rules, there are multiple `AbortIncompleteMultipartUpload` fields with overlapping prefixes.

<span id="598a4e0a"></span>
# Root cause

Lifecycle rules do not support overlapping prefixes among multiple `AbortIncompleteMultipartUpload` fields.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
            "ID": "id",
            "Prefix": "prefix",
            "Status": "Enabled",
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 1
            }
        },
        {
            "ID": "id1",
            "Prefix": "prefix/1",
            "Status": "Enabled",
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 1
            }
        }
    ]
}
```


<span id="56e6e048"></span>
# Solution

The `prefix` values of multiple `AbortIncompleteMultipartUpload` rules must not overlap.
