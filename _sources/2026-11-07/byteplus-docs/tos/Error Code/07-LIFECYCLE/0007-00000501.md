# Problem description

The `NoncurrentVersionTransitions` field in the configured lifecycle rule has an invalid `StorageClass` parameter value.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionTransition` field in the configured lifecycle rule has an invalid `StorageClass` parameter value.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransition": [
        {
          "StorageClass": "STANDARD-IA",
          "NoncurrentDays": 30
        }
      ]
    }]
}
```


<span id="5a552874"></span>
# Solution

The `StorageClass` parameter values configured in the `NoncurrentVersionTransitions` field are as follows:


* `IA`: Infrequent Access storage.

* `INTELLIGENT_TIERING`: Intelligent tiered storage.

* `ARCHIVE_FR`: archive flashback storage.

* `ARCHIVE`: archive storage.

* `COLD_ARCHIVE`: cold archive storage.

* `DEEP_COLD_ARCHIVE`: deep cold archive storage.
