# Problem description

The `NoncurrentVersionExpiration` field's `NoncurrentDate` parameter in the lifecycle rule does not use UTC midnight as its value.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionExpiration` field's `NoncurrentDate` parameter in the lifecycle rule does not use UTC midnight as its value.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionExpiration": { 
          "NoncurrentDate": "2024-02-27T08:00:00.000Z"
      }
    }]
}
```


<span id="516264f2"></span>
# Solution

Set the value of the `NoncurrentDate` parameter to UTC midnight.
