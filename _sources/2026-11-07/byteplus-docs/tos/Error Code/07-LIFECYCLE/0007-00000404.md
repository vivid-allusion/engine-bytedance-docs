# Problem description

The configured lifecycle rule's `Transitions` field contains both `Days` and `Date` parameters.

<span id="4fe7465e"></span>
# Root cause

The configured lifecycle rule's `Transitions` field contains both `Days` and `Date` parameters.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Days": 30,
          "Date": "2024-02-27T00:00:00.000Z"
        }
      ]
    }]
}
```


<span id="9c931fb1"></span>
# Solution

When configuring lifecycle rules, only one of `Days` or `Date` can be set in `Transitions`. You must configure either `Days` or `Date`, not both.
