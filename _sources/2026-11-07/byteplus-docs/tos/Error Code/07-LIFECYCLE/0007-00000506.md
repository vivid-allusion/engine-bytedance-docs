# Problem description

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field `NoncurrentDays` is set to a value less than 0; it must be greater than 0.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field `NoncurrentDays` is set to a value less than 0; it must be greater than 0.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransitions": [
        {
          "StorageClass": "IA",
          "NoncurrentDays": -1
        }
      ]
    }]
}
```


<span id="6ce54277"></span>
# Solution

set the value of `NoncurrentDays` to greater than 0.
