# Problem description

The configured lifecycle rule's `Transitions` field is missing the `Days` or `Date` parameter.

<span id="4fe7465e"></span>
# Root cause

The configured lifecycle rule's `Transitions` field is missing the `Days` or `Date` parameter.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transition": [{
          "StorageClass": "IA"
      }]
    }]
}
```


<span id="3d8e6dc7"></span>
# Solution

Only one of `Days` or `Date` must be present.
