# Problem description

The `NoncurrentVersionExpiration` field's `NoncurrentDate` parameter value in the lifecycle rule is not in ISO8601 format.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionExpiration` field's `NoncurrentDate` parameter value in the lifecycle rule is not in ISO8601 format.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionExpiration": { 
          "NoncurrentDate": "2006-01-02"
      }
    }]
}
```


<span id="80a4eff8"></span>
# Solution

The value of `NoncurrentDate` must be set in the `2024-02-27T00:00:00.000Z` format.
