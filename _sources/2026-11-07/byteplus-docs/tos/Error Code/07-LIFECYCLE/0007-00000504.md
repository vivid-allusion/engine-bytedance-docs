# Problem description

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field contains both `NoncurrentDays` and `NoncurrentDate` parameters.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field contains both `NoncurrentDays` and `NoncurrentDate` parameters, but only one of them is allowed.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransitions": [
        {
          "StorageClass": "IA",
          "NoncurrentDays": 30,
          "NoncurrentDate": "2024-02-27T00:00:00.000Z"
        }
      ]
    }]
}
```


<span id="30800cd6"></span>
# Solution

When configuring the lifecycle rule, choose either `NoncurrentDays` or `NoncurrentDate`. That is, configure only `NoncurrentDays` or only `NoncurrentDate`.
