# Problem description

lifecycle rule configuration format is invalid.

<span id="4fe7465e"></span>
# Root cause

the lifecycle rule content format is invalid.

<span id="104cff06"></span>
# Example

the format of the Transitions field must be set as a JSON array.

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": {
          "StorageClass": "IA",
          "Days": 30
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

set the format of the Transitions field as a JSON array. for details, see [PutBucketLifecycle](https://docs.byteplus.com/en/docs/tos/reference-putbucketlifecycle).
