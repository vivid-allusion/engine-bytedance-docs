# Problem description

The `NoncurrentVersionTransitions` field in the configured lifecycle rule has a `NoncurrentDate` parameter value that is not in ISO8601 format.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionTransitions` field in the configured lifecycle rule has a `NoncurrentDate` parameter value that is not in ISO8601 format.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransitions": [
        {
          "StorageClass": "IA",
          "NoncurrentDate": "2006-01-02"
        }
      ]
    }]
}
```


<span id="caf528f9"></span>
# Solution

Set the value of `NoncurrentDate` to the `2024-02-27T00:00:00.000Z` format.
