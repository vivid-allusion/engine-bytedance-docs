# Problem description

In the configured lifecycle rules, the `Transitions` field's `Date` parameter is not in ISO8601 format.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rules, the `Transitions` field's `Date` parameter is not in ISO8601 format.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Date": "2006-01-02"
        }
      ]
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the value of `Date` to the format `2024-02-27T00:00:00.000Z`.
