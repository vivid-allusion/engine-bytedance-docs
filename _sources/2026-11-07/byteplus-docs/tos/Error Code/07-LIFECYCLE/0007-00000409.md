# Problem description

The configured lifecycle rules have less than 30 days difference between transitioning to Infrequent Access storage and Intelligent Tiering storage.

<span id="4fe7465e"></span>
# Root cause

The configured lifecycle rules require at least a 30\-day gap between transitioning to Infrequent Access storage and Intelligent Tiering storage; that is, Intelligent Tiering storage can only be used at least 30 days after transitioning to Infrequent Access storage.

<span id="104cff06"></span>
# Example

The following setup transitions to Infrequent Access storage after 3 days and to Intelligent Tiering storage after 30 days, a 27\-day difference, which does not meet the requirement.

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Days": "3"
        },
        {
          "StorageClass": "INTELLIGENT_TIERING",
          "Days": "30"
        }
      ]
    }]
}
```


<span id="074fce06"></span>
# Solution

When configuring lifecycle rules, set the days for transitioning to Infrequent Access storage and Intelligent Tiering storage to differ by at least 30 days. For example, set the transition to Intelligent Tiering storage to occur after 33 days.

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Days": "3"
        },
        {
          "StorageClass": "INTELLIGENT_TIERING",
          "Days": "33"
        }
      ]
    }]
}
```
