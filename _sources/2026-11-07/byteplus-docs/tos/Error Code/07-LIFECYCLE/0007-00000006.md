# Problem description

Invalid value in the `Status` field of the lifecycle rule.

<span id="4fe7465e"></span>
# Root cause

The `Status` field in the lifecycle rule has an invalid value; it must be `Enabled` or `Disabled`.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enable",
      "Expiration": { "Days": 120 }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the `Status` field value to `Enabled` or `Disabled`.
