# Problem description

The lifecycle rule ID exceeds 255 characters in length.

<span id="4fe7465e"></span>
# Root cause

The lifecycle rule ID exceeds 255 characters in length.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": { "Days": 120 }}]
}
```


<span id="9c931fb1"></span>
# Solution

Limit the lifecycle rule ID length to within 255 characters.
