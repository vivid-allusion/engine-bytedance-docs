# Problem description

The `Expiration` field's `Date` parameter in the lifecycle rule does not use ISO8601 format.

<span id="4fe7465e"></span>
# Root cause

The `Expiration` field's `Date` parameter in the lifecycle rule does not use ISO8601 format.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": { 
          "Date": "2006-01-02"
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the value of `Date` to the `2024-02-27T00:00:00.000Z` format.
