# Problem description

The number of lifecycle rules configured is 0 or exceeds 1000.

<span id="4fe7465e"></span>
# Root cause

The number of created lifecycle rules is 0 or exceeds 1000.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": []
}
```


<span id="9c931fb1"></span>
# Solution

Add at least one lifecycle rule.
