# Problem description

Multi\-AZ buckets do not support transitioning objects to archive storage, cold archive, or deep cold archive types.

<span id="4fe7465e"></span>
# Root cause

Multi\-AZ buckets do not support transitioning objects to archive storage, cold archive, or deep cold archive types.

<span id="104cff06"></span>
# Example

The lifecycle rules configured for the multi\-AZ bucket are as follows:

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "COLD_ARCHIVE",
          "Days": 30
        }
      ]
    }]
}
```


<span id="9c931fb1"></span>
# Solution

When configuring lifecycle rules for multi\-AZ buckets, set `StorageClass` to values other than `DEEP_COLD_ARCHIVE`, `COLD_ARCHIVE` and `ARCHIVE`. the options are as follows:


* `IA`: low\-frequency access storage

* `INTELLIGENT_TIERING`: intelligent tiering storage

* `ARCHIVE_FR`: archive flash recovery storage
