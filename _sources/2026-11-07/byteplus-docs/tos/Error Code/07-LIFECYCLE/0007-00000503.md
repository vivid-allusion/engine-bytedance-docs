# Problem description

Within the same lifecycle rule or among multiple rules with the same prefix, the `NoncurrentVersionTransitions` field contains duplicate values for the `StorageClass` parameter.

<span id="ca23212a"></span>
# Root cause

Within the same lifecycle rule or among multiple rules with the same prefix, the `NoncurrentVersionTransitions` field contains duplicate values for the `StorageClass` parameter.

<span id="e89b2e04"></span>
# Example


* **Scenario 1**: The same rule includes transition rules to infrequent access storage at 30 days and 40 days.

   ```JSON
   {
       "Rules": [{
         "ID": "id",
         "Prefix": "prefix",
         "Status": "Enabled",
         "NoncurrentVersionTransitions": [
           {
             "StorageClass": "IA",
             "NonCurrentDays": 30
           },
           {
             "StorageClass": "IA",
             "NonCurrentDays": 40
           }
         ]
       }]
   }
   ```
   

* **Scenario 2**: Multiple rules with the same prefix configure transition rules to infrequent access storage at 30 days and 40 days respectively.

   ```JSON
   {
       "Rules": [
           {
               "ID": "id",
               "Prefix": "prefix",
               "Status": "Enabled",
               "NoncurrentVersionTransitions": [
                   {
                       "StorageClass": "IA",
                       "NonCurrentDays": 30
                   }
               ]
           },
           {
               "ID": "id1",
               "Prefix": "prefix",
               "Status": "Enabled",
               "NoncurrentVersionTransitions": [
                   {
                       "StorageClass": "IA",
                       "NonCurrentDays": 40
                   }
               ]
           }
       ]
   }
   ```
   


<span id="7a4b71ca"></span>
# Solution

Ensure the `StorageClass` field values are unique across multiple configurations of `NoncurrentVersionTransitions`.
