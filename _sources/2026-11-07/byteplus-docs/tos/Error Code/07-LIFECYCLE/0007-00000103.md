# Problem description

The `Expiration` field's `Days` parameter in the lifecycle rule is set to a value less than 0.

<span id="4fe7465e"></span>
# Root cause

The `Expiration` field's `Days` parameter in the lifecycle rule is set to a value less than 0; it requires a value greater than 0.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": { 
          "Days": -1
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the `Expiration` field's `Days` parameter to a value greater than 0.
