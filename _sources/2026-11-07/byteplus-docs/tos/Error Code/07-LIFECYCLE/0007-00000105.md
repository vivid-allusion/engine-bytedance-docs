# Problem description

The `Expiration` field's `Date` parameter in the lifecycle rule is not set to UTC midnight.

<span id="4fe7465e"></span>
# Root cause

The `Expiration` field's `Date` parameter in the lifecycle rule is not set to UTC midnight.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": { 
          "Date": "2024-02-27T08:08:08.000Z"
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the `Date` value to UTC midnight.
