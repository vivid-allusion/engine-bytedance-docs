# Problem description

The configured lifecycle rules contain multiple `Expiration` entries or multiple `NoncurrentVersionExpiration` entries with the same prefix.

<span id="4fe7465e"></span>
# Root cause

The configured lifecycle rules contain multiple `Expiration` entries or multiple `NoncurrentVersionExpiration` entries with the same prefix. Before enabling the **prefix overlap** option, rule prefixes are not allowed to overlap.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
          "ID": "id",
          "Prefix": "prefix",
          "Status": "Enabled",
          "Expiration": { "Days": 120 }
        },
        {
          "ID": "id1",
          "Prefix": "prefix",
          "Status": "Enabled",
          "Expiration": { "Days": 120 }
        }
    ]
}
```


The `id` of rule and the `id1` of rule share the same `prefix` and both have `Expiration`.

<span id="9c931fb1"></span>
# Solution

It is recommended to keep only one lifecycle rule. If your actual scenario requires prefix overlapping, you can also enable the prefix overlapping feature. For detailed instructions, please refer to [Enabling prefix overlap](https://docs.byteplus.com/en/docs/tos/Set-prefix-overlap).
