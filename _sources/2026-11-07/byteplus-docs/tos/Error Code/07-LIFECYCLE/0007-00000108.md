# Problem description

There are multiple `Expiration` entries in the configured lifecycle rules with overlapping prefixes.

<span id="6ba2c5ea"></span>
# Root cause

There are multiple `Expiration` entries in the configured lifecycle rules with overlapping prefixes. Before enabling the **prefix overlap** option, rules with overlapping prefixes are not allowed.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
          "ID": "id",
          "Prefix": "prefix",
          "Status": "Enabled",
          "Expiration": { "Days": 120 }
        },
        {
          "ID": "id1",
          "Prefix": "prefix/a",
          "Status": "Enabled",
          "Expiration": { "Days": 120 }
        }
    ]
}
```


The `id` of rule and rule `id1` have overlapping `prefixes`, and both have `Expiration`.

<span id="07c2254b"></span>
# Solution

It is recommended to keep only one lifecycle rule. If prefix overlap is needed in your scenario, you can enable the prefix overlap feature. For detailed instructions, see [Enabling prefix overlap](https://docs.byteplus.com/en/docs/tos/Set-prefix-overlap).
