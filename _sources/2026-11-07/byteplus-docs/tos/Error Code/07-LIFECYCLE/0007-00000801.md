# Problem description

The file size rule in the lifecycle policy is set incorrectly: the minimum value cannot be greater than or equal to the maximum value.

<span id="51d11e16"></span>
# Root cause

The file size rule in the lifecycle policy is set with the minimum value greater than or equal to the maximum value.

<span id="104cff06"></span>
# Example

The following rule configures objects larger than 100 bytes and smaller than 50 bytes to transition to infrequent access storage after 30 days. The object size range is invalid.

```JSON
{
    "Rules": [
        {
            "ID": "1",
            "Prefix": "",
            "Status": "Enabled",
            "Transitions": [
                {
                    "StorageClass": "IA",
                    "Days": 30
                }
            ],
            "Filter": {
                "ObjectSizeGreaterThan": 100,
                "ObjectSizeLessThan": 50,
                "GreaterThanIncludeEqual": "Disabled"
            }
        }
    ]
}
```


<span id="9c931fb1"></span>
# Solution

The object size range configured within a single rule uses an AND relationship. The minimum value must be less than the maximum value. To apply rules for objects larger than 100 bytes or smaller than 50 bytes, configure two separate rules and select the prefix overlap option. For details, see [Enabling prefix overlap](https://docs.byteplus.com/en/docs/tos/Set-prefix-overlap).

The configuration example is as follows: rule rule1 transfers objects smaller than 50 bytes to infrequent access storage after 30 days, and rule rule2 transfers objects larger than 100 bytes to infrequent access storage after 30 days.

```JSON
{
    "Rules": [
        {
            "ID": "rule1",
            "Prefix": "",
            "Status": "Enabled",
            "Transitions": [
                {
                    "StorageClass": "IA",
                    "Days": 30
                }
            ],
            "Filter": {
                "ObjectSizeLessThan": 50,
                "GreaterThanIncludeEqual": "Disabled"
            }
        },
        {
            "ID": "rule2",
            "Prefix": "",
            "Status": "Enabled",
            "Transitions": [
                {
                    "StorageClass": "IA",
                    "Days": 30
                }
            ],
            "Filter": {
                "ObjectSizeGreaterThan": 100,
                "GreaterThanIncludeEqual": "Disabled"
            }
        }
    ]
}
```
