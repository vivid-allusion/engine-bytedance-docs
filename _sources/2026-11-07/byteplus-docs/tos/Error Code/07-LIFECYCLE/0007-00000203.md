# Problem description

The `NoncurrentVersionExpiration` field in the lifecycle rule has a `NoncurrentDays` parameter with a value less than 0.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionExpiration` field in the lifecycle rule has a `NoncurrentDays` parameter with a value less than 0, but it requires a value greater than 0.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionExpiration": { 
          "NoncurrentDays": -1
      }
    }]
}
```


<span id="489e063e"></span>
# Solution

Set `NoncurrentDays` to a value greater than 0.
