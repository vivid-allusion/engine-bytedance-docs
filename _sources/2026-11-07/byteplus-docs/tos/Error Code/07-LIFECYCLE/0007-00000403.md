# Problem description

Within the same lifecycle rule or multiple rules with the same prefix, the `Transitions` field contains duplicated `StorageClass` parameter values.

<span id="4fe7465e"></span>
# Root cause

Within the configured lifecycle rules or rules with the same prefix, the `Transitions` field contains duplicated `StorageClass` parameter values.

<span id="104cff06"></span>
# Example


* **Scenario 1**: A single rule configures transitions to low\-frequency storage at 30 days and 40 days simultaneously.

   ```JSON
   {
       "Rules": [{
         "ID": "id",
         "Prefix": "prefix",
         "Status": "Enabled",
         "Transitions": [
           {
             "StorageClass": "IA",
             "Days": 30
           },
           {
             "StorageClass": "IA",
             "Days": 40
           }
         ]
       }]
   }
   ```
   

* **Scenario 2**: Multiple rules with the same prefix separately configure transitions to low\-frequency storage at 30 days and 40 days.

   ```JSON
   {
       "Rules": [
           {
               "ID": "id",
               "Prefix": "prefix",
               "Status": "Enabled",
               "Transitions": [
                   {
                       "StorageClass": "IA",
                       "Days": 30
                   }
               ]
           },
           {
               "ID": "id1",
               "Prefix": "prefix",
               "Status": "Enabled",
               "Transitions": [
                   {
                       "StorageClass": "IA",
                       "Days": 40
                   }
               ]
           }
       ]
   }
   ```
   


<span id="9c931fb1"></span>
# Solution

Ensure the `StorageClass` field in multiple `Transitions` configurations remains unique.
