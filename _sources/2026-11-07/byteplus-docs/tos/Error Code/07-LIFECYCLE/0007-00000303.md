# Problem description

There are multiple `AbortIncompleteMultipartUpload` fields with the same prefix in the lifecycle rules.

<span id="4fe7465e"></span>
# Root cause

Lifecycle rules do not support multiple `AbortIncompleteMultipartUpload` fields having the same prefix.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
            "ID": "id",
            "Prefix": "prefix",
            "Status": "Enabled",
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 1
            }
        },
        {
            "ID": "id1",
            "Prefix": "prefix",
            "Status": "Enabled",
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 1
            }
        }
    ]
}
```


<span id="9c931fb1"></span>
# Solution

Only one `AbortIncompleteMultipartUpload` rule with the same `prefix` can be retained.
