# Problem description

The `NoncurrentVersionExpiration` field in the lifecycle rule lacks the `NoncurrentDays` or `NoncurrentDate` parameter.

<span id="4fe7465e"></span>
# Root cause

The `NoncurrentVersionExpiration` field in the lifecycle rule requires exactly one of `NoncurrentDays` or `NoncurrentDate` parameters.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionExpiration": {
      }
    }]
}
```


<span id="bd47181c"></span>
# Solution

Only one of `NoncurrentDays` or `NoncurrentDate` should be present.
