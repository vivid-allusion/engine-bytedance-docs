# Problem description

The `Expiration` field in the lifecycle rule contains both `Days` and `Date` parameters.

<span id="4fe7465e"></span>
# Root cause

The `Expiration` field in the lifecycle rule contains both `Days` and `Date` parameters, but only one of them is allowed.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": { 
          "Days": 120,
          "Date": "2024-02-27T00:00:00.000Z"
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the `Expiration` field value to either `Days` or `Date`.
