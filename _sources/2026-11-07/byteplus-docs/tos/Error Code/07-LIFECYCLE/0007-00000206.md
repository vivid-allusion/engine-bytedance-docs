# Problem description

Multiple `NoncurrentVersionExpiration` rules in the lifecycle configuration have overlapping prefixes. Before enabling the **prefix overlap** option, creating rules with overlapping prefixes is not allowed.

<span id="4fe7465e"></span>
# Root cause

Multiple `NoncurrentVersionExpiration` rules in the lifecycle configuration have overlapping prefixes. Before enabling the **prefix overlap** option, creating rules with overlapping prefixes is not allowed.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
          "ID": "id",
          "Prefix": "prefix",
          "Status": "Enabled",
          "NoncurrentVersionExpiration": { "NoncurrentDays": 120 }
        },
        {
          "ID": "id1",
          "Prefix": "prefix/a",
          "Status": "Enabled",
          "NoncurrentVersionExpiration": { "NoncurrentDays": 120 }
        }
    ]
}
```


Rules `id` and `id1` have overlapping `prefixes` and include `Expiration`.

<span id="dbaff2da"></span>
# Solution

It is recommended to keep only one lifecycle rule. If lifecycle rule prefixes need to overlap in practical scenarios, you can enable the prefix overlap feature. For detailed instructions, see [Enabling prefix overlap](https://docs.byteplus.com/en/docs/tos/Set-prefix-overlap).
