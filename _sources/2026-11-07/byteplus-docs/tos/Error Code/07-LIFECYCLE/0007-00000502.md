# Problem description

Multi\-AZ buckets do not support transitioning historical versioned objects to Archive, Cold Archive, or Deep Cold Archive storage classes.

<span id="4fe7465e"></span>
# Root cause

Multi\-AZ buckets do not support transitioning historical versioned objects into Archive, Cold Archive, or Deep Cold Archive storage classes.

<span id="104cff06"></span>
# Example

Setting lifecycle rules in multi AZ buckets to transition historical versioned objects to Cold Archive, for example:

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransition": [
        {
          "StorageClass": "COLD_ARCHIVE",
          "NoncurrentDays": 30
        }
      ]
    }]
}
```


<span id="ed908caa"></span>
# Solution

When configuring lifecycle rules in multi AZ buckets, select values other than `ARCHIVE`, `COLD_ARCHIVE`,

`DEEP_COLD_ARCHIVE`. The specific valid values are as follows:


* `IA`: low\-frequency access storage.

* `INTELLIGENT_TIERING`: intelligent tiering storage.

* `ARCHIVE_FR`: archive flash retrieval storage.
