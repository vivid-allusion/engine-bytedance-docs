# Problem description

The bucket has no lifecycle rules.

<span id="51d11e16"></span>
# Root cause

When calling the `GetBucketLifecycle` API, an error occurs if the bucket has no lifecycle rules (either not configured or deleted after configuration).

<span id="104cff06"></span>
# Example

None.

<span id="9c931fb1"></span>
# Solution

Use the `PutBucketLifecycle` API to configure the bucket’s lifecycle rules. After configuration, calling the `GetBucketLifecycle` API retrieves the configured rules.
