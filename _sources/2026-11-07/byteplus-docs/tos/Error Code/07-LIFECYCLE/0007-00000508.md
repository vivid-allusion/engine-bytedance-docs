# Problem description

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field’s `NoncurrentDate` parameter is set to a non\-UTC midnight time.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `NoncurrentVersionTransitions` field’s `NoncurrentDate` parameter is set to a non\-UTC midnight time.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransitions": [
        {
          "StorageClass": "IA",
          "NoncurrentDate": "2024-02-27T08:00:00.000Z"
        }
      ]
    }]
}
```


<span id="ea0496af"></span>
# Solution

Set the `NoncurrentDate` value to the `2024-02-27T00:00:00.000Z` format, which is UTC midnight.
