# Problem description

In the configured lifecycle rule, the `Transitions` field's `Days` parameter value is less than 0.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `Transitions` field's `Days` parameter value is less than 0, but it must be greater than 0.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Days": -1
        }
      ]
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the value of `Days` to greater than 0.
