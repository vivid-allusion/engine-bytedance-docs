# Problem description

In the configured lifecycle rule, the `AbortIncompleteMultipartUpload` field has a `DaysAfterInitiation` parameter value less than or equal to 0.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `AbortIncompleteMultipartUpload` field has a `DaysAfterInitiation` parameter value less than or equal to 0. It must be greater than 0.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 0 }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the value of `DaysAfterInitiation` to greater than 0.
