# Problem description

In the configured lifecycle rule, the `Transitions` field's `Date` parameter is not set to midnight in UTC.

<span id="4fe7465e"></span>
# Root cause

In the configured lifecycle rule, the `Transitions` field's `Date` parameter is not set to midnight in UTC.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "IA",
          "Date": "2024-02-27T08:00:00.000Z"
        }
      ]
    }]
}
```


<span id="6f170661"></span>
# Solution

Set the value of `Date` to the format `2024-02-27T00:00:00.000Z`, which is midnight in UTC.
