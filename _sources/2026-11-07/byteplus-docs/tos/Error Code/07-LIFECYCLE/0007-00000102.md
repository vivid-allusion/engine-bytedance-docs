# Problem description

The `Expiration` field in the lifecycle rule lacks either the `Days` or `Date` parameter.

<span id="4fe7465e"></span>
# Root cause

The `Expiration` field in the lifecycle rule must contain exactly one parameter: either `Days` or `Date`.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Expiration": {
      }
    }]
}
```


<span id="9c931fb1"></span>
# Solution

Set the `Expiration` field to either `Days` or `Date`.
