# Problem description

Both the `AbortIncompleteMultipartUpload` and `tag` fields are configured simultaneously in the lifecycle rule.

<span id="4fe7465e"></span>
# Root cause

The lifecycle rule does not support having both the `AbortIncompleteMultipartUpload` field and the `tag` field simultaneously.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [
        {
            "ID": "id",
            "Prefix": "prefix",
            "Status": "Enabled",
            "Tags": [
                {
                    "Key": "a",
                    "Value": "b"
                }
            ],
            "AbortIncompleteMultipartUpload": {
                "DaysAfterInitiation": 1
            }
        }
    ]
}
```


<span id="48c46bf2"></span>
# Solution

When configuring lifecycle rules, choose either the `AbortIncompleteMultipartUpload` field or the `tag` field, meaning only configure the `AbortIncompleteMultipartUpload` field or only the `tag` field.
