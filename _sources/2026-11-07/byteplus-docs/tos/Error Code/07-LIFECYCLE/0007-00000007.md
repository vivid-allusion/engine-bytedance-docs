# Problem description

Invalid lifecycle rule configuration.

<span id="4fe7465e"></span>
# Root cause

The lifecycle rule configuration is invalid and must include at least one rule for expiration deletion, storage type conversion, or expired fragment cleanup.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled"
    }]
}
```


<span id="9c931fb1"></span>
# Solution

The lifecycle rules must include at least one rule for expiration deletion, storage type conversion, or expired fragment cleanup.
