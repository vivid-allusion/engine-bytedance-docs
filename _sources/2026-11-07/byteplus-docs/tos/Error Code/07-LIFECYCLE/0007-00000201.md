# Problem description

The `NoncurrentVersionExpiration` field in the lifecycle rule contains both `NoncurrentDays` and `NoncurrentDate` parameters.

<span id="6814407d"></span>
# Root cause

The `NoncurrentVersionExpiration` field in the lifecycle rule contains both `NoncurrentDays` and `NoncurrentDate` parameters, but only one of them should be set.

<span id="ba518f88"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionExpiration": { 
          "NoncurrentDays": 120,
          "NoncurrentDate": "2024-02-27T00:00:00.000Z"
      }
    }]
}
```


<span id="c6697996"></span>
# Solution

When setting lifecycle rules, choose either `NoncurrentDays` or `NoncurrentDate`, meaning set only `NoncurrentDays` or only `NoncurrentDate`.
