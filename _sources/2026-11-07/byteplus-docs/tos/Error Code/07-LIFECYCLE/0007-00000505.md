# Problem description

The configured lifecycle rule's `NoncurrentVersionTransitions` field lacks `NoncurrentDays` or `NoncurrentDate` parameters.

<span id="4fe7465e"></span>
# Root cause

The configured lifecycle rule's `NoncurrentVersionTransitions` field lacks `NoncurrentDays` or `NoncurrentDate` parameters.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "NoncurrentVersionTransitions": [{
          "StorageClass": "IA"
      }]
    }]
}
```


<span id="34c1b2f3"></span>
# Solution

Exactly one of `NoncurrentDays` or `NoncurrentDate` is required.
