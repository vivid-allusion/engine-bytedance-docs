# Problem description

The `StorageClass` parameter configured in the `Transitions` field of the lifecycle rule is invalid.

<span id="4fe7465e"></span>
# Root cause

The `StorageClass` parameter configured in the `Transitions` field of the lifecycle rule is invalid.

<span id="104cff06"></span>
# Example

```JSON
{
    "Rules": [{
      "ID": "id",
      "Prefix": "prefix",
      "Status": "Enabled",
      "Transitions": [
        {
          "StorageClass": "STANDARD-IA",
          "Days": 30
        }
      ]
    }]
}
```


<span id="9c931fb1"></span>
# Solution

The `StorageClass` parameter values configured in the `Transitions` field are as follows:


* `IA`: Infrequent access storage.

* `INTELLIGENT_TIERING`: Intelligent tiering storage.

* `ARCHIVE_FR`: archive flashback storage.

* `ARCHIVE`: archive storage.

* `COLD_ARCHIVE`: cold archive storage.

* `DEEP_COLD_ARCHIVE`: deep cold archive storage.
