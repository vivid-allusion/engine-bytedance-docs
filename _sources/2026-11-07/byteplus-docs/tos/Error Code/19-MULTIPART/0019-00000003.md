# Problem description

The part task status is incorrect when merging parts.

<span id="3616764e"></span>
# Root cause

Users concurrently request AbortMultipartUpload and CompleteMultipartUpload interfaces for the same part task, causing the part task to be aborted or completed during the merging process, resulting in request errors.

<span id="76b07535"></span>
# Example

None.

<span id="eb4ef436"></span>
# Solution

Do not perform concurrent abort or complete operations during the part merging process.
