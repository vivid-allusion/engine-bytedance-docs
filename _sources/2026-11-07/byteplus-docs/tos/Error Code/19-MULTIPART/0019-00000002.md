# Problem description

Incorrect part task status during part upload.

<span id="3616764e"></span>
# Root cause

Concurrent requests to UploadPart, AbortMultipartUpload, or CompleteMultipartUpload for the same part task cause the part task to be aborted or completed during the upload, resulting in request errors.

<span id="76b07535"></span>
# Example

None.

<span id="eb4ef436"></span>
# Solution

Do not perform concurrent abort or complete operations during part upload.
