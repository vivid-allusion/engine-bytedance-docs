# Problem description

The chunk task corresponding to the URL parameter `uploadId` does not exist.

<span id="3616764e"></span>
# Root cause

The user initiates a request related to chunk upload and specifies the chunk task to operate via the URL parameter `uploadId`. However, the chunk task for the provided `uploadId` does not exist, causing the request to fail.

<span id="76b07535"></span>
# Example

You initiate the following request:

```Go
PUT /objectName?partNumber=10&uploadId=00db1329615326ddb1b901c72e2c95b8 HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization xxx
Content-Length: length

<part content>
```


If the provided `uploadId` is incorrect or the corresponding chunk task has been aborted or completed, this error is returned.

<span id="eb4ef436"></span>
# Solution 


* Make sure the provided `uploadId` is accurate and correct.

* Ensure the provided `uploadId` corresponds to a chunk task that has not been aborted or completed.
