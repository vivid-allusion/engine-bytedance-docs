# Problem description

The request body structure is invalid when merging parts.

<span id="3616764e"></span>
# Root cause

The user initiated a request to merge parts, but the structure of the part information in the request body is invalid, causing the request to fail.

<span id="76b07535"></span>
# Example

The request body structure is invalid when you merge parts.

```Go
POST /objectName?uploadId=UploadId HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:38 GMT
Authorization: authorization xxx
Content-Length: 100

...Random string...
```


<span id="157eada5"></span>
# Solution

Refer to [CompleteMultipartUpload](https://docs.byteplus.com/en/docs/tos/reference-completemultipartupload) to correctly construct the part merge request.
