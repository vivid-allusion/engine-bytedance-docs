# Problem description

The part upload status is incorrect when canceling the part upload task.

<span id="3616764e"></span>
# Root cause

The user sends concurrent requests of AbortMultipartUpload and CompleteMultipartUpload APIs for the same part upload task, causing the task to be completed during cancellation and resulting in incorrect requests.

<span id="76b07535"></span>
# Example

None.

<span id="eb4ef436"></span>
# Solution 

Do not perform concurrent Abort or Complete operations during part upload cancellation.
