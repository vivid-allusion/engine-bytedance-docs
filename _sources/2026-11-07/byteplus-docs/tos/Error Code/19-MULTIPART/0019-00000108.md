# Problem description

Shard ETag verification failed.

<span id="3616764e"></span>
# Root cause

The provided shard ETag information in the user's merge request does not match the server's records, causing the request to fail.

<span id="76b07535"></span>
# Example

None.

<span id="789d23d8"></span>
# Solution

Ensure the shard ETag in the merge request is accurate. You can obtain the uploaded shard information via the [ListParts](https://docs.byteplus.com/en/docs/tos/reference-listparts) interface.
