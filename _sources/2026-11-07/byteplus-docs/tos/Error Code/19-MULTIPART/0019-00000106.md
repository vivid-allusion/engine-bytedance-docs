# Problem description

Partial shard merging is not allowed.

<span id="3616764e"></span>
# Root cause

The error occurs because the merge shard request contains only partial shard information.

<span id="76b07535"></span>
# Example

None.

<span id="789d23d8"></span>
# Solution 

Ensure the merge shard request includes all shard information.
