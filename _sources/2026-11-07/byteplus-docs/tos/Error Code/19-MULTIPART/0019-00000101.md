# Problem Description

Request includes both the x\-tos\-complete\-all header and body for multipart upload completion.

<span id="3616764e"></span>
# Root cause

The user sent a multipart upload completion request containing both the x\-tos\-complete\-all header (set to `yes`) and a body, causing the request to fail.

<span id="76b07535"></span>
# Example

The following multipart upload completion request you sent causes this error.

```Go
POST /objectName?uploadId=UploadId HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: Fri, 30 Jul 2021 13:59:38 GMT
Authorization: authorization xxx
x-tos-complete-all: yes
Content-Length: 100

{
    "Parts":[{
        "PartNumber":partNumber,
        "ETag":"ETag"
    }]
}
```


<span id="eb4ef436"></span>
# Solution

When completing the multipart upload, use either the x\-tos\-complete\-all header or the body, but not both.
