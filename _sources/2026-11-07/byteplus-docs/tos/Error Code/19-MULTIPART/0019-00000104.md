# Problem description

When merging shards, the request body contains more than 10,000 shards.

<span id="3616764e"></span>
# Root cause

The user initiated a shard merge request with more than 10,000 shards in the request body, causing the request to fail.

<span id="76b07535"></span>
# Example

The request body contains more than 10,000 shards when you merge shards.

```Go
POST /objectName?uploadId=UploadId HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:38 GMT
Authorization: authorization string
Content-Length: 100

{
    "Parts":[{
        "PartNumber":partNumber,
        "ETag":"ETag"
    }...Omitting 10,000 shard details...]
}
```


<span id="157eada5"></span>
# Solution

Check the request body structure and ensure the number of shards does not exceed 10,000.
