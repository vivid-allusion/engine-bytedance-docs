# Problem description

Concurrent shard merging.

<span id="3616764e"></span>
# Root cause

The user sends multiple shard merge requests for the same shard task simultaneously, causing request errors.

<span id="76b07535"></span>
# Example

None.

<span id="789d23d8"></span>
# Solution 

Do not merge shards concurrently.
