# Problem description

No parts were uploaded before merging parts.

<span id="3616764e"></span>
# Root cause

The user initiated a merge request for parts but has not uploaded any parts for this task, causing the request to fail.

<span id="76b07535"></span>
# Example

None.

<span id="789d23d8"></span>
# Solution 

Retry after uploading parts.
