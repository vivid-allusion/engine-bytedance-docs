# Problem description

The chunk size is too small.

<span id="3616764e"></span>
# Root cause

When users merge chunks, the server confirms that all chunks except the last one have a size of at least 4MB. If any chunk in the request does not meet this requirement, this error will be returned.

<span id="76b07535"></span>
# Example 

None.

<span id="789d23d8"></span>
# Solution

Ensure that when uploading chunks, all chunks except the last one have a size of at least 4MB.
