# Problem description

When merging parts, the request lacks both the x\-tos\-complete\-all header and the body.

<span id="3616764e"></span>
# Root cause

The user initiated a parts merge request without including the x\-tos\-complete\-all header (value: `yes`) or a body, causing the request to fail.

<span id="76b07535"></span>
# Example

None.

<span id="157eada5"></span>
# Solution

When merging parts, the request must include a valid x\-tos\-complete\-all header or a body.
