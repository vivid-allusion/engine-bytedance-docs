# Problem description

The RocketMQ topic does not exist.

<span id="5c88e09d"></span>
# Root cause

The provided RocketMQ topic does not exist in the created RocketMQ event notification rule.

<span id="5676f3ed"></span>
# Example

None.

<span id="b7e4cabe"></span>
# Solution  

Check whether the provided topic exists. If it does not, create the corresponding topic and try again.
