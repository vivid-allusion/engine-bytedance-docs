# Problem description

Event notification rule does not include an event type.

<span id="18011e95"></span>
# Root cause

No subscription event type is set when creating the event notification rule.

<span id="63ea043a"></span>
# Example


* [PutBucketNotification](https://docs.byteplus.com/en/docs/6349/764776) interface has an empty `Events` field.

   ```JSON
   PUT /?notification HTTP/1.1
   Host: <Bucket name>.<TOS endpoint>
   Date: GMT Date
   Authorization: authorization string
   {
     "CloudFunctionConfigurations": [
       {
         "Events": [],
         "Filter": {
           "TOSKey": {
             "FilterRules": [
               {
                 "Name": "prefix",
                 "Value": "test_"
               },
               {
                 "Name": "suffix",
                 "Value": ".jpg"
               }
             ]
           }
         },
         "RuleId": "string",
         "CloudFunction": "string"
       }
     ]
   }
   ```
   

* [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2) interface has an empty `Events` field.

   ```JSON
   PUT /?notification_v2 HTTP/1.1
   Host: <Bucket name>.<TOS endpoint>
   Date: GMT Date
   Authorization: authorization string
   {
       "Rules":[
           {
               "Events":[],
               "Filter":{
                   "TOSKey":{
                       "FilterRules":[
                           {
                               "Name":"prefix",
                               "Value":"test_"
                           },
                           {
                               "Name":"suffix",
                               "Value":".jpg"
                           }
                       ]
                   }
               },
               "RuleId":"string",
               "Destination":{
                   "VeFaaS":[
                       {
                           "FunctionId":"function_id"
                       }
                   ]
               }
           }
       ],
       "Version": "1698031811529301000"
   }
   ```
   


<span id="c9cb9a4d"></span>
# Solution

Select the appropriate event type to subscribe to.
