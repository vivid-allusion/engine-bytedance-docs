# Problem description

veFaaS function service does not allow trigger creation.

<span id="18011e95"></span>
# Root cause

The trigger creation fails because the specified function service in the event notification rule of the created function service type does not permit trigger creation.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

Check whether the function service configuration and authorization are correct.
