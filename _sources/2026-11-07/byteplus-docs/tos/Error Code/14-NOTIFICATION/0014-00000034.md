# Problem description

Setting and reading event rules for single rules with multiple target types is currently not supported.

<span id="18011e95"></span>
# Root cause

If the bucket already contains event notifications with single rules and multiple target types, reading and setting through the v1 interface is not supported.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

Use the corresponding v2 interfaces for these operations:


* [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2)

* [GetBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/GetBucketNotificationV2)
