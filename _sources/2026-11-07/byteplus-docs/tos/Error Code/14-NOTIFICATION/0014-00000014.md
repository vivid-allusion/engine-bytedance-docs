# Problem description

The number of push targets for a single event notification rule exceeds the limit.

<span id="18011e95"></span>
# Root cause

By default, a single rule can push to only one target. Exceeding this limit causes an error (after supporting multiple targets, a single rule can push to up to five targets).

<span id="63ea043a"></span>
# Example


* The [PutBucketNotification](https://docs.byteplus.com/en/docs/6349/764776) API allows only one push target per rule.

* The [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2) API allows up to five push targets per rule (the total number of all target types cannot exceed five).


```JSON
PUT /?notification_v2 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
    "Rules":[
        {
            "Events":[
                "tos:ObjectCreated:*",
                "tos:ObjectRemoved:*"
            ],
            "Filter":{
                "TOSKey":{
                    "FilterRules":[
                        {
                            "Name":"prefix",
                            "Value":"test_"
                        },
                        {
                            "Name":"suffix",
                            "Value":".jpg"
                        }
                    ]
                }
            },
            "RuleId":"string",
            "Destination":{
                "VeFaaS":[
                    {
                        "FunctionId":"function_id"
                    },
                    {
                        "FunctionId":"function_id2"
                    },
                    {
                        "FunctionId":"function_id3"
                    },
                    {
                        "FunctionId":"function_id4"
                    },
                    {
                        "FunctionId":"function_id5"
                    },
                    {
                        "FunctionId":"function_id6"
                    }
                ]
            }
        }
    ],
    "Version": "1698031811529301000"
}
```


<span id="c9cb9a4d"></span>
# Solution 

Check whether the number of targets exceeds the threshold. If it does, reduce the number of targets.
