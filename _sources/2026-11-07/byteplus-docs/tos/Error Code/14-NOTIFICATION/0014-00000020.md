# Problem description

The event notification rule's `FilterRule` is invalid.

<span id="18011e95"></span>
# Root cause

The `FilterRules` set when creating the event notification rule are invalid. For example:


* The number of rules exceeds 2.

* The rule `Name` is not equal to `prefix` or `suffix`.

* The elements in `FilterRules` contain the same type of element, such as two `prefix` or two `suffix`.


<span id="63ea043a"></span>
# Example

The following example contains two `prefix` entries, causing failure.

```JSON
PUT /?notification HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
  "CloudFunctionConfigurations": [
    {
      "Events": [
        "tos:ObjectCreated:*",
        "tos:ObjectRemoved:*"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            },
            {
              "Name": "prefix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "RuleId": "string",
      "CloudFunction": "string"
    }
  ]
}
```


<span id="c9cb9a4d"></span>
# Solution

Set the corresponding FilterRule subscription rule as needed.
