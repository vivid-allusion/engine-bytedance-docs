# Problem description

There are duplicate targets in event notification push.

<span id="18011e95"></span>
# Root cause

When setting multi\-target event notification rules, there are duplicate push targets.

<span id="63ea043a"></span>
# Example

Taking the [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2) API as an example, the `Destination` field contains duplicate targets.

```JSON
PUT /?notification_v2 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
    "Rules":[
        {
            "Events":[
                "tos:ObjectCreated:*",
                "tos:ObjectRemoved:*"
            ],
            "Filter":{
                "TOSKey":{
                    "FilterRules":[
                        {
                            "Name":"prefix",
                            "Value":"test_"
                        },
                        {
                            "Name":"suffix",
                            "Value":".jpg"
                        }
                    ]
                }
            },
            "RuleId":"string",
            "Destination":{
                "VeFaaS":[
                    {
                        "FunctionId":"function_id"
                    },
                    {
                        "FunctionId":"function_id"
                    }
                ]
            }
        }
    ],
    "Version": "1698031811529301000"
}
```


<span id="c9cb9a4d"></span>
# Solution

Verify the correctness of the push targets.
