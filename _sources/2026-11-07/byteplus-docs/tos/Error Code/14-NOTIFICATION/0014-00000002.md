# Problem description

The RocketMQ instance lacks access endpoints for the internal or public service zones.

<span id="5c88e09d"></span>
# Root cause

The RocketMQ instance provided in the created RocketMQ event notification rule lacks access endpoints for the internal or public service zones.

<span id="5676f3ed"></span>
# Example

None

<span id="b7e4cabe"></span>
# Solution 

Check whether the RocketMQ instance has internal or public service zone access options selected.
