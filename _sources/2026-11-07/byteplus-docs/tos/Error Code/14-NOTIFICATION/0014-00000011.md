# Problem description

This cluster does not currently support RocketMQ type event notifications.

<span id="18011e95"></span>
# Root cause

An error occurs when creating this type of event notification rule because the cluster does not support RocketMQ event notifications.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution  

Select another event notification type or contact customer support for assistance.
