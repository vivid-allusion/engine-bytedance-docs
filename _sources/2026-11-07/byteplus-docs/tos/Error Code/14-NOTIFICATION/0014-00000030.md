# Problem description

Event notification rule does not have a push target set.

<span id="18011e95"></span>
# Root cause

The push target was not set when creating the event notification rule.

<span id="63ea043a"></span>
# Example

The [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2) interface did not set a target when configuring the event notification rule; the `Destination` field was empty.

```JSON
PUT /?notification_v2 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
    "Rules":[
        {
            "Events":[
                "tos:ObjectCreated:*",
                "tos:ObjectRemoved:*"
            ],
            "Filter":{
                "TOSKey":{
                    "FilterRules":[
                        {
                            "Name":"prefix",
                            "Value":"test_"
                        },
                        {
                            "Name":"suffix",
                            "Value":".jpg"
                        }
                    ]
                }
            },
            "RuleId":"string",
            "Destination":{}
        }
    ],
    "Version": "1698031811529301000"
}
```


<span id="c9cb9a4d"></span>
# Solution

Fill in the appropriate push target information.
