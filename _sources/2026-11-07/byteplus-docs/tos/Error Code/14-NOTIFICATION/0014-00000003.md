# Problem description

The RocketMQ role does not have permission to operate RocketMQ.

<span id="5c88e09d"></span>
# Root cause

In the created RocketMQ event notification rule, the provided RocketMQ role lacks permission to operate RocketMQ.

<span id="5676f3ed"></span>
# Example

None.

<span id="b7e4cabe"></span>
# Solution  

Check if the provided Role includes the **RocketMQAccessForTOS** policy (Object Storage TOS access to RocketMQ permissions).
