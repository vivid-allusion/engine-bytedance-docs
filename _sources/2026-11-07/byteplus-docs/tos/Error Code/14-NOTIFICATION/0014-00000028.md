# Problem description

The veFaaS function service has not been published yet.

<span id="18011e95"></span>
# Root cause

Creation of function service type event notification rules failed because the function service was not published.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

Find the corresponding function service and publish it, then try again.
