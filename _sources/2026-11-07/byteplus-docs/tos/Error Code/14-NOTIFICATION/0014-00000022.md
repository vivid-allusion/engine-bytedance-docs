# Problem description

The configured rule ID length exceeds the limit.

<span id="18011e95"></span>
# Root cause

When creating an event notification rule, the configured rule ID length exceeds 255 characters.

<span id="63ea043a"></span>
# Example

When creating an event notification rule, the corresponding `RuleId` value exceeds 255 characters.

<span id="c9cb9a4d"></span>
# Solution

Verify the correctness of the rule ID.
