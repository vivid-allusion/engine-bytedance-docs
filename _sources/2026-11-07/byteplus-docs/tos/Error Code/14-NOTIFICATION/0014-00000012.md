# Problem description

Invalid request parameters.

<span id="18011e95"></span>
# Root cause

An error occurs during event notification rule creation due to invalid request parameters.


* It may not include event notification rules.

* It may lack bucket information.


<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution  

Check if the request parameters are correctly filled in according to the documentation. For detailed information, see [PutBucketNotificationV2](https://docs.byteplus.com/en/docs/tos/PutBucketNotificationV2).
