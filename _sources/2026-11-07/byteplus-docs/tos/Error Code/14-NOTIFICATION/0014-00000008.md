# Problem description

The RocketMQ role lacks permission to operate RocketMQ.

<span id="5c88e09d"></span>
# Root cause

The RocketMQ role provided in the created RocketMQ\-type event notification rule does not have permission to operate RocketMQ.

<span id="5676f3ed"></span>
# Example

In the example below, missing `RocketMQ:DescribeAuthKey`, `RocketMQ:GetSk`, or `RocketMQ:GetTopic` permissions will cause failure. At minimum, it must include these four actions: `RocketMQ:GetInstance`, `RocketMQ:DescribeAuthKey`, `RocketMQ:GetSk`, and `RocketMQ:GetTopic`.

```JSON
{
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "RocketMQ:GetInstance"
            ],
            "Resource": [
                "*"
            ]
        }
    ]
}
```


<span id="b7e4cabe"></span>
# Solution  

Verify whether the provided Role includes the **RocketMQAccessForTOS** policy (object storage TOS access permission for RocketMQ).
