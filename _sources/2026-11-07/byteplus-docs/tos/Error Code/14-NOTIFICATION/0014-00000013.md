#  Problem description

The number of event notification rules for a single bucket exceeds the limit.

<span id="18011e95"></span>
# Root cause

The number of event notification rules contained in a single bucket exceeds the limit. A maximum of 10 event notification rules can be created per bucket.

<span id="63ea043a"></span>
# Example

The number of event notification rules in the bucket exceeds 10

<span id="c9cb9a4d"></span>
# Solution 

Check for deprecated event notification rules and replace them.
