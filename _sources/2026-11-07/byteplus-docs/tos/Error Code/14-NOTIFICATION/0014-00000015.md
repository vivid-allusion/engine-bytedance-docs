# Problem description

Event notification rule has no push target set.

<span id="18011e95"></span>
# Root cause

No push target information was set when creating the event notification rule.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

Specify the notification target when creating an event notification rule.
