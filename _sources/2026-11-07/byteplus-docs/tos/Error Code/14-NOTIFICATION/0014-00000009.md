# Problem description

AccessKey does not exist.

<span id="18011e95"></span>
# Root cause

The provided AccessKey in the created RocketMQ type event notification rule either does not exist or does not match the account.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution  

Verify whether the provided AccessKey is correct.
