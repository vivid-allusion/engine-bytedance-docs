# Problem description

duplicate event notification rule name.

<span id="18011e95"></span>
# Root cause

duplicate event notification rule name within the same bucket.

<span id="63ea043a"></span>
# Example 

duplicate event notification rule names across different rules. the example below contains two event notification rules, but both have the name "rule," causing duplication.

```JSON
PUT /?notification HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
  "CloudFunctionConfigurations": [
    {
      "Events": [
        "tos:ObjectRemoved:*"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            },
            {
              "Name": "suffix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "RuleId": "rule",
      "CloudFunction": "string"
    },
    {
      "Events": [
        "tos:ObjectCreated:*"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            },
            {
              "Name": "suffix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "RuleId": "rule",
      "CloudFunction": "string"
    }
  ]
}
```


<span id="c9cb9a4d"></span>
# Solution

Change to a new rule name or leave the rule name blank.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">if no rule name is set, the system will generate a random string by default.</div>
