# Problem description

The event notification rules set are duplicated.

<span id="18011e95"></span>
# Root cause

A single object cannot match multiple rules containing the same event type. In other words, within the same bucket, the combination ranges of **type + prefix and suffix** across different rules cannot overlap.

<span id="63ea043a"></span>
# Example

Taking the [PutBucketNotification](https://docs.byteplus.com/en/docs/6349/764776) interface as an example, creating two event notification rules where the event types are the same and although the `FilterRules parameter` differs, a single object (such as test_xxx.jpg) may meet both rules simultaneously, which is invalid.

```JSON
PUT /?notification HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
  "CloudFunctionConfigurations": [
    {
      "Events": [
        "tos:ObjectCreated:*"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            }
          ]
        }
      },
      "CloudFunction": "function1"
    },
    {
      "Events": [
        "tos:ObjectCreated:*"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "suffix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "CloudFunction": "function1"
    }
  ]
}
```


<span id="c9cb9a4d"></span>
# Solution

Check whether there are any duplicate event notification rules.
