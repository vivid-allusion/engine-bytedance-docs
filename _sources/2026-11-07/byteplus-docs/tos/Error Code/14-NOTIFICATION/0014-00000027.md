# Problem description

veFaaS function service triggers exceed the limit.

<span id="18011e95"></span>
# Root cause

In the created function service event notification rules, the number of function service triggers exceeds the defined threshold.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

The following options are available:


* Remove unnecessary triggers.

* Replace the veFaaS function
