# Problem description

No permission to operate veFaaS functions.

<span id="18011e95"></span>
# Root cause

The created function service type event notification rule does not have permission to operate the corresponding function ID.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution

Check whether the function ID permissions are correct, for example, whether the function belongs to the current account.
