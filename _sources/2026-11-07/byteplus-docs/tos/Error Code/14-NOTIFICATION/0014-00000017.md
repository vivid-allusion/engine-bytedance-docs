# Problem description

the event notification rule contains an invalid event type.

<span id="18011e95"></span>
# Root cause

an invalid event notification type was included when creating the event notification rule.

<span id="63ea043a"></span>
# Example

for example, the event notification type `tos:ObjectCreated:Append` is not supported. please refer to [event notification overview](https://docs.byteplus.com/en/docs/tos/Event-notification-overview) for supported event notification types.

```JSON
PUT /?notification HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
  "CloudFunctionConfigurations": [
    {
      "Events": [
        "tos:ObjectCreated:Append"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            },
            {
              "Name": "suffix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "RuleId": "string",
      "CloudFunction": "functionid" 
    }
  ]
}
```


<span id="c9cb9a4d"></span>
# Solution

check if the subscribed event notification types are valid.
