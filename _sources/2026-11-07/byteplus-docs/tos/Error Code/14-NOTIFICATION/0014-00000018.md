# Problem description

Event notification types are duplicated within the event notification rule.

<span id="18011e95"></span>
# Root cause

Event notification types are duplicated within the event notification rule.

<span id="63ea043a"></span>
# Example

As shown, the `Events` element already includes `tos:ObjectCreated:*` which covers `tos:ObjectCreated:Put`.

```JSON
PUT /?notification HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
{
  "CloudFunctionConfigurations": [
    {
      "Events": [
        "tos:ObjectCreated:*",
        "tos:ObjectCreated:Put"
      ],
      "Filter": {
        "TOSKey": {
          "FilterRules": [
            {
              "Name": "prefix",
              "Value": "test_"
            },
            {
              "Name": "suffix",
              "Value": ".jpg"
            }
          ]
        }
      },
      "RuleId": "string",
      "CloudFunction": "string"
    }
  ]
}
```


<span id="c9cb9a4d"></span>
# Solution

Adjust the event notification types to remove duplicates.
