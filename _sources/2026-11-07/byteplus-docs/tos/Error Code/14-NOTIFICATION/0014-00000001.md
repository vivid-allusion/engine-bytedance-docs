# Problem description

The AccessKey does not have permission to publish messages.

<span id="5c88e09d"></span>
# Root cause

The provided AccessKey in the created RocketMQ event notification rule does not have permission to publish messages.

<span id="5676f3ed"></span>
# Example

None.

<span id="b7e4cabe"></span>
# Solution 

Check whether the provided AccessKey has publish permission for the corresponding topic.
