# Problem description

This cluster does not support veFaaS type event notifications yet.

<span id="18011e95"></span>
# Root cause

The error occurs because the cluster currently does not support veFaaS type event notifications when creating such event notification rules.

<span id="63ea043a"></span>
# Example

None.

<span id="c9cb9a4d"></span>
# Solution  

Choose another event notification type or contact customer support for assistance.
