# Problem description

The Host field is missing in the request header.

<span id="fd761bb8"></span>
# Root cause

The required Host field is missing in the request header for signature.

<span id="85b94601"></span>
# Example

You made a request with signature information in the Authorization header or URL parameter, but the Host field is missing in the request header.

```Go
PUT /objectName HTTP/1.1
Date: GMT Date
x-tos-content-sha256: abc***
x-tos-date: 2022***
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322/cn-beijing/tos/request,SignedHeaders=host;x-tos-content-sha256;x-tos-date,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```


<span id="e4e3712c"></span>
# Solution

Add the Host header in the request and calculate the signature correctly. For detailed operations, refer to the [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
