# Problem description

The time difference between the client's request initiation and the server's request reception is too large.

<span id="ba9bae35"></span>
# Root cause

The value of the Date field or the x\-tos\-date field deviates significantly from the time the server receives the request.

<span id="85b94601"></span>
# Example

A sample request is as follows:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Tue, 20 Mar 2022 08:48:18 GMT
Authorization: TOS4-HMAC-SHA256 ***
```


If the server receives the request in 2023, this error is returned because the time in the Date field deviates significantly from the server's request reception time.

<span id="e4e3712c"></span>
# Solution

Ensure that the Date header or the x\-tos\-date field in the request contains the correct time parameter.
