# Problem description

URL parameter X\-Tos\-Expires has an invalid value.

<span id="bf0672fe"></span>
# Root cause

The X\-Tos\-Expires parameter value in the URL signature is invalid.

<span id="85b94601"></span>
# Example

You initiated a request using URL signature authentication, but the X\-Tos\-Expires parameter value in the URL is invalid.

```JSON
PUT https://<Bucket name>.<TOS endpoint>/object
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20130721T201207Z
&X-Tos-Expires=-1
&X-Tos-SignedHeaders=host
&X-Tos-Signature=<signature> 
&X-Tos-Security-Token=<security-token>
```


The X\-Tos\-Expires parameter specifies the URL validity duration in seconds, with an acceptable range of [1, 2592000]. The parameter value in the request above is `-1`, which is invalid.

<span id="e4e3712c"></span>
# Solution

Ensure the X\-Tos\-Expires parameter value in the request URL is within the valid range.
