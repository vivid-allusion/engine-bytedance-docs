# **Problem description**

Invalid signature format.

<span id="bf0672fe"></span>
# Root cause

Incorrect signature format.

<span id="85b94601"></span>
# Example

You sent a request carrying signature information in the Authorization header, URL parameter X\-Tos\-Signature, or form element x\-tos\-signature, but the Signature information could not be decoded as hexadecimal.

```Go
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-content-sha256: abc***
x-tos-date: 2022***
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322/cn-beijing/tos/request,SignedHeaders=host;x-tos-content-sha256;x-tos-date,Signature=%2A%2B%2C
```


The Signature information in the above signature is `Signature=%2A%2B%2C`, where `%2A%2B%2C` cannot be decoded as hexadecimal.

<span id="e4e3712c"></span>
# Solution

Calculate the signature using the correct method.For detailed operations, refer to the [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
