# Problem description

URL parameter X\-Tos\-Policy is not supported.

<span id="bf0672fe"></span>
# Root cause

When accessing TOS using the S3 protocol, the request contains the URL parameter X\-Tos\-Policy.

<span id="85b94601"></span>
# Example

You access TOS via the S3 protocol and include the X\-Tos\-Policy parameter in the request URL.

```JSON
GET https://<Bucket name>.<TOS endpoint>/
?X-Amz-Algorithm=AWS4-HMAC-SHA256
&X-Amz-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Amz-Date=20220101T000000Z
&X-Amz-Expires=86400
&X-Tos-Policy=<policy>
&X-Amz-Signature=<signature>
&X-Amz-Security-Token=<security-token>
```


<span id="e4e3712c"></span>
# Solution

Send the request using the TOS protocol. For detailed steps, see [URL pre-signing with query parameter X-Tos-Policy](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
