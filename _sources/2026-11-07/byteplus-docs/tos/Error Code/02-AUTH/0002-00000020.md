# Problem description

the AccessKey provided in the request does not exist.

<span id="ba9bae35"></span>
# Root cause

the request accessed TOS using a non\-existent AccessKey.

<span id="85b94601"></span>
# Example

you initiated a request carrying signature information in the Authorization header, URL parameter X\-Tos\-Credential, or form element x\-tos\-credential, but the AccessKey in the signature Credential information does not exist.

<span id="e4e3712c"></span>
# Solution

check the AccessKey used in the request to ensure it is correct.
