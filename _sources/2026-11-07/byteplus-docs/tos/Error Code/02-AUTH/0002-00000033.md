# Problem description

The PostObject form field contains signature elements but lacks a policy element.

<span id="bf0672fe"></span>
# Root cause

When uploading an object using POST, the form lacks a `policy` element but includes `x-tos-signature`, `x-tos-date`, `x-tos-credential`, and `x-tos-algorithm` elements.

<span id="85b94601"></span>
# Example

None.

<span id="21fac22e"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and construct the request properly.
