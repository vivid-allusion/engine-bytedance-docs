# Problem description

The signature format is invalid.

<span id="fd761bb8"></span>
# Root cause

The signature format is incorrect.

<span id="85b94601"></span>
# Example

You sent a request carrying signature information in the Authorization header, URL parameter X\-Tos\-Credential, or form element x\-tos\-credential, but the Date format in the signature Credential is not yyyymmdd.

```Java
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-content-sha256: abc***
x-tos-date: 2022***
Authorization: TOS4-HMAC-SHA256 Credential=testAK/2022-03-22/cn-beijing/tos/request,SignedHeaders=host;x-tos-content-sha256;x-tos-date,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```


The Credential information in the above signature is `Credential=testAK/2022-03-22/cn-beijing/tos/request`, where the Date is 2022\-03\-22, which is incorrectly formatted.

<span id="e4e3712c"></span>
# Solution

Calculate the signature correctly.For detailed instructions, see [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
