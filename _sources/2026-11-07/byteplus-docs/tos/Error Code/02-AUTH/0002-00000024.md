# Problem description

Signature mismatch.

<span id="bf0672fe"></span>
# Root cause

The signature carried in the request does not match the signature calculated by the server.

<span id="85b94601"></span>
# Example

You initiated a request with signature information carried in the Authorization header, URL parameter X\-Tos\-Signature, or form element x\-tos\-signature, but the signature calculation of the Signature information was incorrect, causing it to not match the server's calculated signature.

<span id="e4e3712c"></span>
# Solution

Calculate the signature correctly. For detailed operations, refer to the [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
