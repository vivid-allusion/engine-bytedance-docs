# Problem description

Invalid signature format.

<span id="ba9bae35"></span>
# Root cause

The signature format is incorrect.

<span id="85b94601"></span>
# Example

You initiated a request carrying signature information in the Authorization header and URL parameter X\-Tos\-SignedHeaders, but the SignedHeaders in the signature does not include all x\-tos\-\* headers.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-content-sha256: abc***
x-tos-date: 2022***
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322/cn-beijing/tos/request,SignedHeaders=host;x-tos-content-sha256,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```


The SignedHeaders information in the above signature is `SignedHeaders=host;x-tos-content-sha256`, which does not include the x\-tos\-date request header.

<span id="e4e3712c"></span>
# Solution

Ensure the signature SignedHeaders includes all x\-tos\-\* headers and that the signature is correctly calculated. For detailed operations, refer to the [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
