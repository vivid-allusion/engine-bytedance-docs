# **Problem description**

The URL parameter X\-Tos\-Expires exceeds the threshold value.

<span id="bf0672fe"></span>
# Root cause

The value of the X\-Tos\-Expires parameter in the URL signature exceeds the threshold.

<span id="85b94601"></span>
# Example

You initiated a request using URL\-based signatures, but the X\-Tos\-Expires parameter value in the URL exceeds the threshold.

```JSON
PUT https://<Bucket name>.<TOS endpoint>/object
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20130721T201207Z
&X-Tos-Expires=32832000
&X-Tos-SignedHeaders=host
&X-Tos-Signature=<signature> 
&X-Tos-Security-Token=<security-token>
```


The X\-Tos\-Expires parameter specifies the URL's valid duration, in seconds, with a valid range of [1, 2592000]. In the above request, this parameter value is `32832000`, which exceeds the threshold.

<span id="e4e3712c"></span>
# Solution

Ensure the X\-Tos\-Expires parameter value in the request URL is within the valid range.
