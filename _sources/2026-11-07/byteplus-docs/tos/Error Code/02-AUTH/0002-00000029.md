# Problem description

Required parameters are missing in the URL signature.

<span id="bf0672fe"></span>
# Root cause

The request uses URL signature authentication, but the URL lacks necessary parameters.

<span id="85b94601"></span>
# Example

You initiate a request using URL signature, but the URL does not include required pre\-signing parameters.

```JSON
PUT https://<Bucket name>.<TOS endpoint>/object
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20130721T201207Z
&X-Tos-Expires=86400
&X-Tos-SignedHeaders=host
&X-Tos-Security-Token=<security-token>
```


In URL signature authentication, the parameters `X-Tos-Algorithm`, `X-Tos-Credential`, `X-Tos-Date`, `X-Tos-Expires`, `X-Tos-SignedHeaders`, and `X-Tos-Signature` are mandatory. The above request is missing the required parameter `X-Tos-Signature`.

<span id="e4e3712c"></span>
# Solution

Construct URL signatures using the correct method. For detailed instructions, see [Signing URLs](https://docs.byteplus.com/en/docs/tos/reference-including-a-signature-in-the-url).
