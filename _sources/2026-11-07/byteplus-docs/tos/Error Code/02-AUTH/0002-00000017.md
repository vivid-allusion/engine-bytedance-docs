# **Problem description**

The Date or x\-tos\-date field has an invalid format.

<span id="ba9bae35"></span>
# Root cause

The Date field value does not comply with GMT format, or the x\-tos\-date field value does not comply with ISO 8601 format.

<span id="85b94601"></span>
# Example

A sample request is as follows:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: 20220322T084818Z
x-tos-content-sha256: abc***
x-tos-date: Tue, 22 Mar 2022 08:48:18 GMT
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322/cn-beijing/tos/request,SignedHeaders=host;x-tos-content-sha256;x-tos-date,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```



* Date must meet the GMT format, such as `Tue, 20 Mar 2022 08:48:18 GMT`. For example, a request with `Date` set to `20220322T084818Z` does not meet the format requirements.

* x\-tos\-date must meet the ISO 8601 format, such as `20220322T084818Z`. For example, a request with `x-tos-date` set to `Tue, 22 Mar 2022 08:48:18 GMT` does not meet the format requirements.


<span id="e4e3712c"></span>
# Solution

The Date field value must comply with the GMT format, the x\-tos\-date field value must comply with the ISO 8601 format, and the signature must be calculated correctly.
