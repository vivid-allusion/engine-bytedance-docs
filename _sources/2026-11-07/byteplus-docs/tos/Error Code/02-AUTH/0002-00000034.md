# Problem description

The PostObject form is missing required signature elements.

<span id="bf0672fe"></span>
# Root cause

When uploading an object via POST, the form is missing required signature elements such as `x-tos-signature`, `x-tos-date`, `x-tos-credential`, and `x-tos-algorithm`.

<span id="85b94601"></span>
# Example

None.

<span id="21fac22e"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and construct the request correctly.
