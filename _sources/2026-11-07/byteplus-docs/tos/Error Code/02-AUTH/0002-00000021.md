# Problem description

The requested STS token has expired.

<span id="ba9bae35"></span>
# Root cause

The STS token authentication method is used to access TOS, but the provided STS token has expired.

<span id="85b94601"></span>
# Example

You applied for an STS token with a one\-hour validity period through the STS service. If you use this STS token to access TOS after two hours, this error occurs.

<span id="e4e3712c"></span>
# Solution

Access TOS with a valid STS token. For detailed instructions, refer to [Using STS Temporary AK/SK+Token to Access Volcengine TOS](https://docs.byteplus.com/en/docs/tos/Accessing-tos-with-temporary-credentials-of-security-token-service).
