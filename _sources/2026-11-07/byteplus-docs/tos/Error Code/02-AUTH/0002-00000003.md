# Problem description

Invalid signature format in the Authorization header.

<span id="fd761bb8"></span>
# Root cause

The signature format provided in the Authorization header is incorrect.

<span id="85b94601"></span>
# Example

You sent a request with a signature in the Authorization header, but the signature format is incorrect. For example, splitting the signature by commas (,) does not result in an array length of 3.

```Java
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322/cn-beijing/tos/request,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```


<span id="e4e3712c"></span>
# Solution

Calculate the signature correctly. For details, see [signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
