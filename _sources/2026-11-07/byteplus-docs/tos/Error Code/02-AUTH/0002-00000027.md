# **Problem description**

URL parameter X\-Tos\-Policy is not supported.

<span id="bf0672fe"></span>
# Root cause

Accessed TOS with non\-GET or non\-HEAD requests and included the X\-Tos\-Policy parameter in the request URL.

<span id="85b94601"></span>
# Example

You accessed TOS via PUT method and included the X\-Tos\-Policy parameter in the request URL.

```JSON
PUT https://<Bucket name>.<TOS endpoint>/
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220101T000000Z
&X-Tos-Expires=86400
&X-Tos-Policy=<policy>
&X-Tos-Signature=<signature>
&X-Tos-Security-Token=<security-token>
```


<span id="e4e3712c"></span>
# Solution

Send requests using GET or HEAD methods, or remove the X\-Tos\-Policy parameter from the request URL.
