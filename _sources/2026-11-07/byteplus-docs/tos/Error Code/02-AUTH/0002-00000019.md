# Problem description

The requested STS token is invalid.

<span id="ba9bae35"></span>
# Root cause

The STS token authentication method was used to access TOS, but the provided STS token is invalid.

<span id="85b94601"></span>
# Example

The x\-tos\-security\-token value in the request header or URL signature does not match the STS service return value when using the STS token to initiate the request.

<span id="e4e3712c"></span>
# Solution

Access TOS with the correct STS token. For specific steps, see: [Use STS temporary AK/SK+Token to access Volcengine TOS](https://docs.byteplus.com/en/docs/tos/Accessing-tos-with-temporary-credentials-of-security-token-service).
