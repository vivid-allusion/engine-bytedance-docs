# Problem description

The pre\-signed URL with the X\-Tos\-Policy parameter is missing required parameters.

<span id="bf0672fe"></span>
# Root cause

The pre\-signed URL containing the X\-Tos\-Policy parameter lacks necessary parameters when accessing TOS.

<span id="85b94601"></span>
# Example

You used a pre\-signed URL with the X\-Tos\-Policy parameter to make a request, but the URL does not include the required pre\-signing parameters.

```JSON
GET https://<Bucket name>.<TOS endpoint>/
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220101T000000Z
&X-Tos-Expires=86400
&X-Tos-Policy=<policy>
&X-Tos-Security-Token=<security-token>
```


The required parameters in the pre\-signed URL include `X-Tos-Algorithm`, `X-Tos-Credential`, `X-Tos-Date`, `X-Tos-Expires`, `X-Tos-Policy`, and `X-Tos-Signature`. The above request is missing the required parameter `X-Tos-Signature`.

<span id="e4e3712c"></span>
# Solution

Construct a URL carrying the `X-Tos-Policy` parameter in the correct way. For detailed steps, see [URL pre-signing with the X-Tos-Policy query parameter](https://docs.byteplus.com/en/docs/tos/reference-presigned-url-with-the-x-tos-policy-query-parameter).
