# **Problem description**

The signature algorithm in the Authorization header does not support the S3 V2 algorithm.

<span id="fd761bb8"></span>
# Root cause

The signature algorithm in the Authorization header uses the S3 V2 algorithm.

<span id="85b94601"></span>
# Example

You initiated a request signed with the S3 V2 algorithm.

```Java
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: AWS testAK:testSig
```


The signature algorithm in the Authorization header is AWS, which is the V2 algorithm of the S3 protocol.

<span id="e4e3712c"></span>
# Solution

Use the correct signature algorithm. For specific operations, see [Signature Mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
