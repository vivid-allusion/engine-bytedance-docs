# Problem description

Invalid signature format.

<span id="fd761bb8"></span>
# Root cause

Incorrect signature format.

<span id="85b94601"></span>
# Example

You sent a request carrying signature information in the Authorization header, URL parameter X\-Tos\-Credential, or form element x\-tos\-credential, but the Region in the signature Credential information is empty.

```Go
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-content-sha256: abc***
x-tos-date: 2022***
Authorization: TOS4-HMAC-SHA256 Credential=testAK/20220322//tos/request,SignedHeaders=host;x-tos-content-sha256;x-tos-date,Signature=d40b66cf0054d1642843670d10fa095e1609c7896f25df217770b0abe717693b
```


The Credential information in the signature above is `Credential=testAK/20220322//tos/request`, which lacks Region information.

<span id="e4e3712c"></span>
# Solution

Calculate the signature using the correct method. For detailed instructions, see [Signature mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
