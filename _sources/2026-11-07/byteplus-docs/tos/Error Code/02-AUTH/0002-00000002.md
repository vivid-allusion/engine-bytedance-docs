# **Problem description**

The signature algorithm in the Authorization header is invalid.

<span id="fd761bb8"></span>
# Root cause

The signature algorithm in the Authorization header uses an algorithm not supported by TOS.

<span id="85b94601"></span>
# Example

You used a signature algorithm not supported by TOS.

```Java
GET /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: HMAC-SHA256 xxx
```


<span id="e4e3712c"></span>
# Solution

Use the correct signature algorithm. For detailed steps, see [Signature Mechanism](https://docs.byteplus.com/en/docs/tos/reference-signature-mechanism_1).
