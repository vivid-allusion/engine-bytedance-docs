# **Problem description**

The signed URL has expired.

<span id="bf0672fe"></span>
# Root cause

A request was sent using an expired signed URL.

<span id="85b94601"></span>
# Example

You initiated a request using a URL with a signature based on the URL, but the URL has expired.

```JSON
GET https://<Bucket name>.<TOS endpoint>/object
?X-Tos-Algorithm=TOS4-HMAC-SHA256
&X-Tos-Credential=<access-key-id>/<YYYYMMDD>/<region>/tos/request
&X-Tos-Date=20220721T201207Z
&X-Tos-Expires=604800
&X-Tos-SignedHeaders=host
&X-Tos-Signature=<signature> 
&X-Tos-Security-Token=<security-token>
```


The request time is `20220721T201207Z`, the URL validity period is `604800`, and sending a request using this URL in 2023 results in this error.

<span id="e4e3712c"></span>
# Solution

Ensure the signed URL is still valid.
