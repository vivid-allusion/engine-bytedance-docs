# Problem description

Hierarchical buckets do not support renaming a parent directory into its subdirectory.

<span id="1fef7721"></span>
# Root cause

The source directory is the parent directory of the target directory when initiating a RenameObject request.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /a/b/?name=a/b/c/&rename HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Check if the source and target directories are as expected.
