# Problem description

URL parameter `offset` has an invalid value.

<span id="1fef7721"></span>
# Root cause

When modifying an object, the URL parameter `offset` value does not match the `x-tos-next-modify-offset` value from the last object modification.

<span id="bde5a78a"></span>
# Example 

If the previous object modification response returned an `x-tos-next-modify-offset` value of `100`, but your next modification request uses an `offset` value of `80`, this error will occur.

<span id="384bc520"></span>
# Solution 

Ensure the `offset` value in the next ModifyObject request matches the `x-tos-next-modify-offset` value from the previous ModifyObject response.
