# Problem description

Modify object upload data is too small.

<span id="19aad453"></span>
# Root cause

The user initiated a ModifyObject request with data that is too small, such as empty data.

<span id="26f40c53"></span>
# Examples

None.

<span id="78c3716c"></span>
# Solution

Ensure that the data written during each modification is not empty.
