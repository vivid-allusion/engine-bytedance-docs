# Problem description

UploadPartCopy does not support source objects that are directory\-type in a hierarchical bucket or objects ending with / in a regular bucket when the target is an object in a hierarchical bucket.

<span id="1fef7721"></span>
# Root cause

When initiating an UploadPartCopy request, the following situations may occur:


* The source is a directory\-type object in a hierarchical bucket, and the target is an object in a hierarchical bucket.

* The source is an object ending with / in a regular bucket, and the target is an object in a hierarchical bucket.


<span id="bde5a78a"></span>
# Example

```JSON
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
x-tos-copy-source: /sourcebucketname/SourceObjectName
```


<span id="384bc520"></span>
# Solution

If the source is a hierarchical bucket, use an object that is not a directory type; if the source is a regular bucket, use an object that does not end with /.
