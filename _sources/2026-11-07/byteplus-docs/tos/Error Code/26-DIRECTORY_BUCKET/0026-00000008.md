# Problem description

The size of the modified write object exceeds 48 TiB.

<span id="592e24d3"></span>
# Root cause

The size of the modified write object exceeds 48 TiB.

<span id="602f11ad"></span>
# Example

None.

<span id="4346910b"></span>
# Solution

Ensure that the size of a single object does not exceed 48 TiB.
