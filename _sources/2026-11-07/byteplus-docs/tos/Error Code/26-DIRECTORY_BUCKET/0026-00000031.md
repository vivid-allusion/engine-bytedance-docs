# Problem description

Layered buckets do not support streaming object uploads.

<span id="0e0a05e3"></span>
# Root cause

The user uploads objects using streaming.

<span id="8276d94a"></span>
# Example 

None.

<span id="94cb4b6d"></span>
# Solution

Upload objects using a non\-streaming method.
