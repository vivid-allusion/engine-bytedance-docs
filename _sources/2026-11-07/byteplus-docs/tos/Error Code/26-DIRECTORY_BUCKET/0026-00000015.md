# Problem description

Batch deletion in hierarchical buckets does not support deleting directory\-type objects.

<span id="1fef7721"></span>
# Root cause

The DeleteMultiObjects request included directory\-type objects.

<span id="bde5a78a"></span>
# Example

```JSON
POST /?delete HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization string
Content-MD5: md5 string

{
  "Objects": [{
    "Key": "dir1",
    "VersionId": "string"
  }],
  "Quiet": false
}
```


<span id="384bc520"></span>
# Solution

Use the DeleteObject API to delete directory\-type objects.
