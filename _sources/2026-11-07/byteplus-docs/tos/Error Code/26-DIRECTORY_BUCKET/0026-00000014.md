# Problem description

In the hierarchical bucket, when listing objects with the parameter `delimiter`, the value of `delimiter` must be`/`.

<span id="1fef7721"></span>
# Root cause

When initiating ListObjectsV2/ListObjects requests, the value of `delimiter` is not `/`.

<span id="bde5a78a"></span>
# Example

```Go
GET /?delimiter=# HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Set `delimiter` to`/`.
