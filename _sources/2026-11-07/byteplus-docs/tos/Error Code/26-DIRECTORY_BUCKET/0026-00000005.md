# Problem description

ModifyObject does not support this storage type for the object.

<span id="237bf615"></span>
# Root cause

The user sends a ModifyObject request, but the object's storage type is nonstandard, causing the request to fail.

<span id="393e35e0"></span>
# Example

You send a ModifyObject request specifying the object storage type as archive instant retrieval.

```Go
POST /objectName?modify&offset=Offset HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-storage-class: ARCHIVE_FR
Authorization: authorization xxx

<modify data>
```


<span id="4d45e04c"></span>
# Solution

Ensure the storage type for the appended write object is standard storage.
