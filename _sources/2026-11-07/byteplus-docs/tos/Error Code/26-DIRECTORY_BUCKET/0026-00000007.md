# Problem description

Buckets with archive storage class do not support modifying objects for writing.

<span id="31292389"></span>
# Root cause

The request fails because the target bucket is set to archive storage when modifying a writable object.

<span id="b055d063"></span>
# Example

None.

<span id="2efd0f3f"></span>
# Solution

Change the bucket storage class to standard storage.
