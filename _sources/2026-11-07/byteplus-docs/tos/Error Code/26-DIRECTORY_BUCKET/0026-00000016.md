# Problem description

Uploading directory\-type objects in hierarchical buckets does not support carrying data.

<span id="1fef7721"></span>
# Root cause

The user initiates a PutObject request with an object of directory type that carries data.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
Content-length: length

<put data>
```


<span id="384bc520"></span>
# Solution

Do not carry data when uploading directory\-type objects.
