# Problem description

copying non\-empty objects from standard buckets to directory\-type objects in hierarchical buckets is not supported.

<span id="1fef7721"></span>
# Root cause

when sending a CopyObject request, the source is a non\-empty object in a standard bucket, and the destination is a directory\-type object in a hierarchical bucket.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
x-tos-copy-source: /sourcebucketname/SourceObjectName
```


<span id="384bc520"></span>
# Solution

specify the source object as an empty object.
