# Problem description

Modifying a write object does not support carrying the URL parameter `versionId`.

<span id="b7664741"></span>
# Root cause

The user initiates a ModifyObject request where the request URL contains the `versionId` parameter.

<span id="4791f213"></span>
# Example

Modifying a write object with the `versionId` parameter.

```Go
POST /objectName?modify&offset=0&versionId=5787DD26CC44761A964F HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

<modify data>
```


<span id="bd4b3e69"></span>
# Solution

Remove the `versionId` parameter from the request URL.
