# Problem description

ModifyObject does not support server\-side encryption.

<span id="0ed241f8"></span>
# Root cause

The user sends a ModifyObject request and applies server\-side encryption to the object, causing the request to fail.

<span id="2f5ae555"></span>
# Example

You send a ModifyObject request specifying SSE\-KMS encryption for the object.

```Go
POST /objectName?modify&offset=0 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-server-side-encryption: kms
Authorization: authorization xxx

<modify data>
```


<span id="b743088d"></span>
# Solution

Remove the server\-side encryption headers or the bucket’s encryption configuration.
