# Problem description

Layered buckets do not support renaming a file to a directory or renaming a directory to a file.

<span id="1fef7721"></span>
# Root cause

When making a RenameObject request, one of the source or target is a directory, and the other is a file.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /a/b?name=a/b/c/&rename HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Check if the source and target meet the expected conditions.
