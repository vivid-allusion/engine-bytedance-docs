# Problem description

Renaming the parent directory is not supported before merging multipart tasks.

<span id="1fef7721"></span>
# Root cause

The rename operation was applied to the parent directory of a multipart task while sending the CompleteMultipartUpload request.

<span id="bde5a78a"></span>
# Example

```JSON
POST /objectName?uploadId=UploadId HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization string
Content-Length: length

{
    "Parts":[{
        "PartNumber":partNumber, 
        "ETag":etag
    }]
}
```


<span id="384bc520"></span>
# Solution

Perform the rename operation after completing the data upload.
