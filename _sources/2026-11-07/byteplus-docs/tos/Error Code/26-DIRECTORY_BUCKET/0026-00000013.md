# Problem description

In a hierarchical bucket, deletion is not supported when a directory\-type object contains subdirectories or subfiles.

<span id="1fef7721"></span>
# Root cause

The DeleteObject request is initiated for a directory\-type object that contains subdirectories or subfiles.

<span id="bde5a78a"></span>
# Example

```Go
DELETE /ObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Ensure all subdirectories or subfiles are deleted before deleting the object.
