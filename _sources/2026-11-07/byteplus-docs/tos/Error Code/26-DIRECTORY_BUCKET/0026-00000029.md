# Problem description

Creating multi\-AZ redundant tiered buckets is not supported yet.

<span id="1fef7721"></span>
# Root cause

When sending the CreateBucket request, the header `x-tos-az-redundancy` is set with the value `multi-az`.

<span id="bde5a78a"></span>
# Example 

```JSON
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
x-tos-az-redundancy: multi-az
x-tos-acl: ACL
Content-Length: 0
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Check whether the value of `x-tos-az-redundancy` meets the expected requirements.
