# Problem description

When initializing a multipart upload task in a hierarchical bucket, `objectName` cannot end with a`/`forward slash (/).

<span id="77974ed9"></span>
# Root cause

When initiating a CreateMultipartUpload request, `objectName` ends with a`/`forward slash (/).

<span id="18bca102"></span>
# Example

```Go
POST /dir/?uploads HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="6eb6aa1e"></span>
# Solution 

Avoid `objectName` ending with a`/`ending.
