# Problem description

Creating non\-standard tiered buckets is currently not supported.

<span id="1fef7721"></span>
# Root cause

When initiating a CreateBucket request, the header `x-tos-storage-class` is set to a value other than `STANDARD`.

<span id="bde5a78a"></span>
# Example 

```JSON
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
x-tos-storage-class: ARCHIVE_FR
x-tos-acl: ACL
Content-Length: 0
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Check whether the value of `x-tos-storage-class` meets the expected criteria.
