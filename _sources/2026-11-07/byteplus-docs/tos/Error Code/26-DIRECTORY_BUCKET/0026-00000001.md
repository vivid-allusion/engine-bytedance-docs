# Problem description

Modify write requests for layered buckets do not currently support streaming upload data.

<span id="93dc24eb"></span>
# Root cause

Users use streaming upload data.

<span id="93b2e656"></span>
# Example

None.

<span id="31ea55af"></span>
# How to fix it

Use non\-streaming upload data.
