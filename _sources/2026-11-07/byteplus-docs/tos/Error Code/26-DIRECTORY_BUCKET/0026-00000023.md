# Problem description

When listing objects in a layered bucket, the header `delimiter` must be included.

<span id="1fef7721"></span>
# Root cause

The ListBucket request was made without the header `delimiter`.

<span id="bde5a78a"></span>
# Example

```JSON
GET / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution 

Include the header `delimiter` when making the ListBucket request.
