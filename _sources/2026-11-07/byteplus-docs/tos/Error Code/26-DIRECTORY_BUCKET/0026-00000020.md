# Problem description

The path of the accessed object does not support having a file with the same name as an intermediate directory.

<span id="1fef7721"></span>
# Root cause

During the PUT request, the object's key (full path) has a file with the same name as an intermediate directory.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /a/b/c HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
Content-length: length

<put data>
```


<span id="384bc520"></span>
# Solution

Check whether the object's access path matches the expected format.
