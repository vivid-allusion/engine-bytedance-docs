# Problem description

The current user lacks permission to initiate a DeleteObject request without the `recursive` parameter.

<span id="1fef7721"></span>
# Root cause

A DeleteObject request was initiated with the `recursive` parameter.

<span id="bde5a78a"></span>
# Example 

```JSON
DELETE /ObjectName?recursive HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution 

Contact technical support.
