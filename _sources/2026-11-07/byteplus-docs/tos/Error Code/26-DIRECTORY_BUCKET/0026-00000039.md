# Problem description

The parent directory at a certain level of the tiered bucket does not exist.

<span id="1fef7721"></span>
# Root cause

Deleting a nonexistent key whose parent directory at a certain level does not exist.

<span id="bde5a78a"></span>
# Example

```Plain
DELETE /a/b/c HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


The directory a/b/ does not exist

<span id="384bc520"></span>
# Solution

Contact technical support by [submitting a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245).
