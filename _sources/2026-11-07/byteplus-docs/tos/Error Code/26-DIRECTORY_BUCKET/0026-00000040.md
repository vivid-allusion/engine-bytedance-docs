# Problem description

The requested key in the layered bucket does not exist.

<span id="1fef7721"></span>
# Root cause

The key does not exist and was deleted.

<span id="bde5a78a"></span>
# Example

```Plain
DELETE /a/b/c HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


Key a/b/c does not exist

<span id="384bc520"></span>
# Solution

Please [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
