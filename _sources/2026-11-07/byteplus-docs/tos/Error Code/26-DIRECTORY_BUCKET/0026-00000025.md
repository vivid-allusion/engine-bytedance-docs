# Problem description

Layered buckets do not support renaming to overwrite an object of an existing directory type.

<span id="1fef7721"></span>
# Root cause

The RenameObject request is initiated when the renamed object is an existing directory\-type object.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /objectName?name=Name&rename HTTP/1.1
Host: <Bucket name>.<TOS endpoint>   
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution 

Check whether the target file after renaming needs to be overwritten.
