# Problem description

Layered buckets do not support encryption, callbacks, or related parameters such as `versionId`.

<span id="1fef7721"></span>
# Root cause

The user request included encryption, callback, and parameters related to `versionId`.

<span id="bde5a78a"></span>
# Example

```JSON
GET /objectName?versionId=12345 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
Content-length: length
```


<span id="384bc520"></span>
# Solution

Check if the request Query contains encryption, callback, or parameters related to `versionId`.
