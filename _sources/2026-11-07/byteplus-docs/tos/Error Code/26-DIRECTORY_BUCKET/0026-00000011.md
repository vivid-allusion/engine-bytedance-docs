# Problem description

Hierarchical buckets do not support this action with specific headers.

<span id="1fef7721"></span>
# Root cause

When using hierarchical buckets, unsupported headers such as encryption or callback\-related headers are included.

<span id="bde5a78a"></span>
# Example 

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-server-side-encryption: kms
Authorization: authorization xxx
```


<span id="384bc520"></span>
# Solution

Avoid using headers that hierarchical buckets do not support.
