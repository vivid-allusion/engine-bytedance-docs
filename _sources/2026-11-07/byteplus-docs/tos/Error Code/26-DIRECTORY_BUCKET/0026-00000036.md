# Problem description

Renaming does not allow overwriting if the target file exists.

<span id="1fef7721"></span>
# Root cause

If the `x-tos-forbid-overwrite` header is set to `true` and a file with the same name as the `rename` target exists, overwriting the file is not allowed.

<span id="bde5a78a"></span>
# Example 

```JSON
PUT /src-object?name=dst-object&rename HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Date: GMT Date
Authorization: authorization string
```


<span id="384bc520"></span>
# Solution

Verify if this request matches the expected behavior.
