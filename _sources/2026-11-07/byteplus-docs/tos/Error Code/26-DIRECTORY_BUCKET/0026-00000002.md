# Problem description

URL parameter `offset` has an invalid value.

<span id="78c32619"></span>
# Root cause

When users modify an object, the URL parameter `offset` is set to a non\-positive integer.

<span id="0fd068f5"></span>
# Example

You send a ModifyObject request with the URL parameter `offset` set to the invalid value \-1.

```Go
POST /objectName?modify&offset=-1 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>   
Date: GMT Date
Authorization: authorization xxx

<modify data>
```


<span id="504e8d5b"></span>
# Solution

Ensure the URL parameter `offset` has a valid value when sending a ModifyObject request.
