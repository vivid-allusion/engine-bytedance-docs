# Problem description

The current user is not allowed to create a tiered bucket.

<span id="1fef7721"></span>
# Root cause

The current user lacks permission to create a tiered bucket.

<span id="bde5a78a"></span>
# Example

```JSON
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Authorization: authorization string
Date: Fri, 30 Jul 2021 06:45:39 GMT
x-bucket-type: hns
x-tos-acl: ACL
x-tos-grant-full-control: GrantFullControl
x-tos-grant-read: GrantRead
x-tos-grant-read-acp: GrantReadACP
x-tos-grant-write: GrantWrite
x-tos-grant-write-acp: GrantWriteACP
x-tos-storage-class: STANDARD
```


<span id="384bc520"></span>
# Solution

Contact technical support.
