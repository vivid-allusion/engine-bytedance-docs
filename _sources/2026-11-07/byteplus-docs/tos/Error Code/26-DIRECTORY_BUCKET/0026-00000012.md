# Problem description

ModifyObject does not support append writes to directory\-type objects in hierarchical buckets.

<span id="1fef7721"></span>
# Root cause

The ModifyObject request was initiated on an object of directory type.

<span id="bde5a78a"></span>
# Example

```Go
POST /objectName?modify&offset=0 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

<modify data>
```


<span id="384bc520"></span>
# Solution

Perform ModifyObject operations only on non\-directory objects.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can determine whether an object is a directory type by checking the response header <code>x-directory</code> from HeadObject. If the returned header <code>x-directory</code> has the value <code>true</code>, the object is a directory type; if the header is absent, the object is not a directory type.</div>
