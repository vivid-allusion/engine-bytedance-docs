# Problem description

When the target is a tiered bucket, copying between directory\-type objects and non\-directory\-type objects is not supported.

<span id="1fef7721"></span>
# Root cause

The CopyObject request fails because the source and target objects have different directory types.

<span id="bde5a78a"></span>
# Example

```JSON
PUT /dir/ HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
x-tos-copy-source: /sourcebucketname/file
```


<span id="384bc520"></span>
# Solution

Ensure the source and target objects have the same directory type.
