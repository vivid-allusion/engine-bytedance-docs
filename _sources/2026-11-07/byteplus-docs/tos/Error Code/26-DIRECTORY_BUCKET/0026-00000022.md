# Problem description

Failed to acquire directory lock when accessing objects in a layered bucket.

<span id="1fef7721"></span>
# Root cause

Creating the same directory or file concurrently at a high rate is not supported.

<span id="bde5a78a"></span>
# Example

NA

<span id="384bc520"></span>
# Solution 


1. Avoid uploading the same object simultaneously;

2. Create the file path first, then upload files concurrently.
