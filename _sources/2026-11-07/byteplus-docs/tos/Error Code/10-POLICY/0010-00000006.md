# Problem description

Bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting a bucket policy, the `Principal` or `NotPrincipal` value in a policy is invalid, such as being empty or not matching the request protocol format.

<span id="76b07535"></span>
# Example

You set an empty `Principal` value in a bucket policy.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal": "",
            "Action": ["tos:Get*"],
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to properly construct the bucket policy and ensure the `Principal` or `NotPrincipal` values are valid in a single policy.
