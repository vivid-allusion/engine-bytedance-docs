# Problem description

The bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

User sets the bucket policy where the `NotPrincipal` configuration is paired with `Effect":"Allow`.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, the `Effect` is set to `Allow` while `NotPrincipal` is included.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "NotPrincipal": "*",
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket policy templates and parameter description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to construct the bucket policy correctly, ensuring no `NotPrincipal` is included when `Effect` is set to `Allow`.
