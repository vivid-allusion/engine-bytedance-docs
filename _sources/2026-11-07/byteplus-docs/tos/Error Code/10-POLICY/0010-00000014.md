# Problem description

Bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set the bucket policy, the `Effect` value in the policy is not `Allow` or `Deny`.

<span id="76b07535"></span>
# Example

The `Effect` value in the bucket policy you configured is invalid.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "xxx",
            "Action": ["tos:*"],
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to the [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters), correctly construct the bucket policy configuration, and ensure the `Effect` value in the policy is valid.
