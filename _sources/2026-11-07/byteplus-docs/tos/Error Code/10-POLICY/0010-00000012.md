# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, the values of `Resource` or `NotResource` in the policy are invalid, such as empty values or formats that do not match the request protocol.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, the `Resource` configuration in the policy is empty.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "Principal": "*",
            "Resource": [""]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy configuration and ensure that the values of `Resource` or `NotResource` in the policy are valid.
