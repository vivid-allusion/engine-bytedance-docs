# Problem description

Bucket policy configuration does not exist.

<span id="3616764e"></span>
# Root cause

This error occurs when a user accesses a bucket using the GetBucketPolicy API, but the bucket has no policy configured.

<span id="76b07535"></span>
# Example

None.

<span id="b28ad357"></span>
# Solution

Configure a bucket policy for the bucket, then query again.
