# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When users set a bucket policy, the `Condition` configuration contains invalid condition values, such as mismatched condition keys.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, the condition key in the `Condition` is set to `SourceIP`, but the condition value does not comply with the IP format.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"],
            "Condition": {"IpAddress":{"SourceIP": "123"}}
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to properly construct the bucket policy configuration and ensure condition values are valid.
