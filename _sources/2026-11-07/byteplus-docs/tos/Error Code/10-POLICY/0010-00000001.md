# Problem description

Bucket policy configuration structure is invalid.

<span id="3616764e"></span>
# Root cause

The configuration structure in the request body is invalid when the user sets the bucket policy.

<span id="76b07535"></span>
# Example

The configuration structure in the request body is invalid when you set the bucket policy.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket policy template and parameter description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy configuration.
