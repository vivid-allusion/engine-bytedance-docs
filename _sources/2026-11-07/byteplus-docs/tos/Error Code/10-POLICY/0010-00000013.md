# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

The `Condition` setting in the bucket policy is invalid. The valid `Condition` configuration should be a Map type, where the Map's key must be a string, and the value must be another Map (with string keys and values that are either strings or lists of strings).

<span id="76b07535"></span>
# Example

The `Condition` setting in your bucket policy configuration is invalid.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"],
            "Condition": {"abc":123}
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Templates and Parameter Descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy and ensure the `Condition` setting is valid.
