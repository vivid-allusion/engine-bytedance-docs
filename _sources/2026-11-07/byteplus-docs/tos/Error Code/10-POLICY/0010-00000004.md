# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, a single policy lacks both `Principal` and `NotPrincipal` configurations at the same time.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, a single policy lacks both `Principal` and `NotPrincipal` configurations at the same time.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:Get*"],
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Templates and Parameter Description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy configuration, ensuring each policy contains either a `Principal` or a `NotPrincipal` configuration, but not both.
