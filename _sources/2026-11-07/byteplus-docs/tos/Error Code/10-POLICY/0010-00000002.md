# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

The user lacks the `Statement` configuration when setting the bucket policy.

<span id="76b07535"></span>
# Example

You are missing the `Statement` configuration when configuring the bucket policy.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": []
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Templates and Parameter Description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy and ensure a valid `Statement` configuration exists.
