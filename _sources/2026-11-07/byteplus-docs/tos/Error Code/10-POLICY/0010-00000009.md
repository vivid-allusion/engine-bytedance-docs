# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When users set a bucket policy, the `Action` or `NotAction` value in a single policy entry is invalid, such as empty values or formats that do not match the request protocol.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, the `Action` field in a single policy entry is empty.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": [""],
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to the [Bucket Policy Template and Parameter Description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly construct the bucket policy and ensure the `Action` or `NotAction` values in a single policy entry are valid.
