# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, multiple policies have the same value in the `Sid` field.

<span id="76b07535"></span>
# Example

You have duplicate values in the `Sid` field when configuring the bucket policy.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal":"*",
            "Action": ["tos:Get*"],
            "Resource": ["trn:tos:::bucketname/*"]
        },
        {
            "Sid": "1",
            "Effect": "Deny",
            "Principal":"*",
            "Action": ["tos:Delete*"],
            "Resource": ["trn:tos:::bucketname/*"]
        }
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to the [bucket policy template and parameter explanation](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to correctly create the bucket policy configuration and ensure the `Sid` field values are unique.
