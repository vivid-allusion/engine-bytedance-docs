# Problem description

The bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, a single policy contains both `Principal` and `NotPrincipal` configurations.

<span id="76b07535"></span>
# Example

You configured the bucket policy with both `Principal` and `NotPrincipal` configurations in the same policy.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal": "*",
            "NotPrincipal": "*",
            "Action": ["tos:Get*"],
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Templates and Parameter Description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to construct the bucket policy correctly, ensuring each policy contains only one `Principal` or `NotPrincipal` configuration.
