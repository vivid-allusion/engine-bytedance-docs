# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, a single policy contains both `Resource` and `NotResource` configurations.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, a single policy contains both `Resource` and `NotResource` configurations.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal": "*",
            "Action": ["tos:*"],
            "Resource": ["trn:tos:::bucketname/*"],
            "NotResource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket policy templates and parameter description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to construct the bucket policy correctly, ensuring a single policy contains only either `Resource` or `NotResource` configuration.
