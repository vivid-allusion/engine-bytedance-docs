# Problem description

Invalid bucket policy configuration.

<span id="3616764e"></span>
# Root cause

When setting a bucket policy, a policy simultaneously lacks both `Resource` and `NotResource` configurations.

<span id="76b07535"></span>
# Example

When configuring a bucket policy, a policy simultaneously lacks both `Resource` and `NotResource` configurations.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "Principal": "*"
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Template and Parameter Description](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) for correct bucket policy configuration. Ensure that each policy contains either a `Resource` or `NotResource` configuration.
