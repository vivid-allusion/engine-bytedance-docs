# Problem description

bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

when setting the bucket policy, the condition key value in a `Condition` configuration is invalid.

<span id="76b07535"></span>
# Example

when configuring the bucket policy, the condition key value in the `Condition` configuration is an invalid value `xxx`.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Action": ["tos:*"],
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"],
            "Condition": {"IpAddress":{"xxx": "192.168.0.0/24"}}
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

refer to [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to properly construct the bucket policy configuration and ensure valid condition key values.
