# Problem description

The bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting the bucket policy, a single statement lacks both `Action` and `NotAction` configurations.

<span id="76b07535"></span>
# Example

When configuring the bucket policy, a single statement lacks both `Action` and `NotAction` configurations.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal": "*",
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [Bucket Policy Templates and Parameter Instructions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to properly construct the bucket policy configuration. Ensure each statement contains either an `Action` or `NotAction` configuration.
