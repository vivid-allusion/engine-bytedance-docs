# Problem description

Bucket policy configuration is invalid.

<span id="3616764e"></span>
# Root cause

The user sets a bucket policy with both `Action` and `NotAction` configurations in the same policy statement.

<span id="76b07535"></span>
# Example

You configure a bucket policy with both `Action` and `NotAction` configurations in the same policy statement.

```Go
PUT /?policy HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "1",
            "Effect": "Allow",
            "Principal": "*",
            "Action": ["tos:*"],
            "NotAction": ["tos:*"],
            "Resource": ["trn:tos:::bucketname/*"]
        }        
    ]
}
```


<span id="7e307bcb"></span>
# Solution

Refer to [bucket policy templates and parameter descriptions](https://docs.byteplus.com/en/docs/tos/docs-templates-and-parameters) to properly construct the bucket policy, ensuring each policy statement contains only one `Action` or `NotAction` configuration.
