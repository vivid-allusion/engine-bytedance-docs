# Problem description

Updating the batch job status to the specified value is not allowed.

<span id="0a17e82c"></span>
# Root cause

The tenant only allows setting two job statuses: Ready and Cancelled.

<span id="075e4c9f"></span>
# Example

The value of the job status modification does not comply with the specifications. Check if it is correct.

<span id="41bd95c9"></span>
# Solution

Check whether the job status meets expectations.
