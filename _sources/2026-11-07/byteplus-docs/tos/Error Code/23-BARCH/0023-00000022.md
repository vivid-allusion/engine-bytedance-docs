# Problem description

The specified `TRN` format is incorrect.

<span id="0a17e82c"></span>
# Root cause

The `TRN` format is incorrect. The correct format is `trn:iam::{account ID}:role/{role name}`.

<span id="075e4c9f"></span>
# Example

The `TRN` format does not meet the requirements, for example, `trn:iam::1:role/` lacks role name information.

<span id="41bd95c9"></span>
# Solution

Check if the `TRN` format meets the requirements.
