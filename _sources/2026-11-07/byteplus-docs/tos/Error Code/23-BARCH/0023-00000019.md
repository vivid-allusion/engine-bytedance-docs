# Problem description

The specified `ClientRequestToken` for creating the task already exists.

<span id="0a17e82c"></span>
# Root cause

Repeated identical requests cause subsequent requests to fail.

<span id="075e4c9f"></span>
# Example

Request duplication caused this; check whether the related batch task has already been created.

<span id="41bd95c9"></span>
# Solution

Verify whether the corresponding task has been successfully created. If yes, ignore it; if not, contact customer service.
