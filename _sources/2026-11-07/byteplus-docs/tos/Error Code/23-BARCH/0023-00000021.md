# Problem description

The batch task status has transitioned to a terminal state, so updating its task status is not allowed.

<span id="0a17e82c"></span>
# Root cause

Generally, tasks fall into the following two status categories:


* Transitional states: created, preparing, pending start, ready, running, paused

* Terminal states: completed, failed, canceled


Attempting to modify a task already in a terminal state will cause an error.

<span id="075e4c9f"></span>
# Example

Changing the status of a task in a terminal state causes failure.

<span id="41bd95c9"></span>
# Solution

The terminal task status cannot be modified. Verify whether the task and status are correct.
