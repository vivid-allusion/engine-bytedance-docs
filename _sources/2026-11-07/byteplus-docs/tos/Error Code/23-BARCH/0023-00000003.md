# Problem description

The parameters included when requesting the TOS control domain name are invalid.

<span id="0a17e82c"></span>
# Root cause

The request parameters are invalid.

<span id="075e4c9f"></span>
# Example

Viewing batch tasks without including the `jobID` parameter.

<span id="41bd95c9"></span>
# Solution

Refer to the relevant API documentation to check whether the parameters are valid.
