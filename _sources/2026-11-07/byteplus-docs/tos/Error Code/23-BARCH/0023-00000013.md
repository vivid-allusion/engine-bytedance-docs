# Problem description

The request body for creating the batch task is too large.

<span id="0a17e82c"></span>
# Root cause

The request body size exceeded 32 KiB when creating the task.

<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution 

Check the request body size and simplify parameters like task descriptions.
