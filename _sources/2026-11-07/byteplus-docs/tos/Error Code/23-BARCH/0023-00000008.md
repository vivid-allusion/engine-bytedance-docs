# Problem description

Batch tasks cannot be deleted unless they are in a terminal state.

<span id="dd34efa5"></span>
# Root cause

The task to be deleted is not in a terminal state (completed, failed, or cancelled) but in a transitional state (created, preparing, pending start, ready, running, or paused).

<span id="1c879d2f"></span>
# Example

Delete a task in a transitional state.

<span id="67bc4720"></span>
# Solution 

Wait for the task to reach a terminal state before performing the delete operation.
