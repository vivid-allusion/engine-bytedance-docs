# Problem description

The specified `Operation` parameter is invalid when creating a batch task.

<span id="0a17e82c"></span>
# Root cause

Currently, batch tasks support the following operation types; any others are invalid.


* Batch Data Copy (TOSPutObjectCopy)

* Batch Replace Object ACL (TOSPutObjectAcl)

* Batch Process Object Tagging (TOSPutObjectTagging)

* Batch Restore Archive Objects (TOSRestoreObject)


<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution 

Check whether the batch task operation type is valid.
