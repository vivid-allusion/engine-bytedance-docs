# Problem description

When creating a batch task, the specified `Report` parameter is invalid.

<span id="0a17e82c"></span>
# Root cause

When creating a batch task, the specified `Report` parameter is invalid.

<span id="075e4c9f"></span>
# Example

For example, parameters like `Enabled`, `Format`, `ReportScope`, and `Bucket` are invalid.

<span id="41bd95c9"></span>
# Solution 

Select valid values according to the corresponding settings.
