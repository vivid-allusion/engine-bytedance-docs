# Problem description

The priority parameter specified for creating the batch task is invalid.

<span id="0a17e82c"></span>
# Root cause

The task priority is outside the valid range (1~1073741824).

<span id="075e4c9f"></span>
# Example

When creating a task or setting the task priority, the priority value is outside the valid range (1~1073741824).

<span id="41bd95c9"></span>
# Solution 

Set a reasonable priority.
