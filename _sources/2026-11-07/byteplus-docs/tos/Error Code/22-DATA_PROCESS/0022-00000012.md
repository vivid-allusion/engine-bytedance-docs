# Problem description

Triggered data processing service tenant concurrency throttling.

<span id="0a17e82c"></span>
# Root cause

The data processing concurrency limit has been reached.

<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution 

Reduce the data processing concurrency.

If you have a compute\-intensive workload or usage that exceeds these limits, [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to consult with our technical team or your designated account manager.
