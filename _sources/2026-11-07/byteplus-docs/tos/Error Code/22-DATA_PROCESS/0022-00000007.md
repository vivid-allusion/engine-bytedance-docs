# Problem description

The image exceeds the maximum processable size.

<span id="0a17e82c"></span>
# Root cause

The image used during processing exceeds the size limit.

<span id="075e4c9f"></span>
# Example

The original image exceeds the maximum size limit for processing. The default size limit for the original image is 20 MB.

<span id="41bd95c9"></span>
# Solution

For image processing usage limits, see [Usage Limits](https://docs.byteplus.com/en/docs/tos/docs-overview_2#.5L2_55So6ZmQ5Yi2).

If you want to increase the original image size limit, please [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support or your account manager for evaluation.
