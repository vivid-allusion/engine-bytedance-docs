# Problem description

The request parameters for data processing save\-as are incorrect.

<span id="0a17e82c"></span>
# Root cause

The parameters are incorrect when performing the data processing save\-as operation.

<span id="075e4c9f"></span>
# Example

The target object name or target bucket name for save\-as is not a valid base64 URL\-encoded string. For example, the request is `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/resize,w_100&x-tos-save-object=YWJjLnBuZw==ttttttt`, and `YWJjLnBuZw==ttttttt` is not a valid base64 URL\-encoded string.

<span id="41bd95c9"></span>
# Solution

Use Base64 URL encoding to correctly encode the target object name and target bucket name.
