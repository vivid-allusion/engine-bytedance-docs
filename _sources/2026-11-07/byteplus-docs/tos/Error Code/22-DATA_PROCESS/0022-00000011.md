# Problem description

Triggered data processing service tenant QPS flow control.

<span id="0a17e82c"></span>
# Root cause

Data processing QPS has reached its limit.

<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution 

Reduce data processing frequency. For QPS limits details, see [Usage limits](https://docs.byteplus.com/en/docs/tos/docs-overview_2#.5L2_55So6ZmQ5Yi2).

If you have a compute\-intensive workload or usage that exceeds these limits, submit a ticket to consult with our technical team or your designated account manager.
