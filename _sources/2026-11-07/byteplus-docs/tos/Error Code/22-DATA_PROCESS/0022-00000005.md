# Problem description

The image processing request parameters are invalid.

<span id="0a17e82c"></span>
# Root cause

Request parameters are invalid during image processing.

<span id="075e4c9f"></span>
# Example


* During image processing, the request parameters are outside the valid range, for example, `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/invalid-param`, where `invalid-param` is an invalid request parameter. For valid parameters, see [Image Processing Overview](https://docs.byteplus.com/en/docs/tos/docs-overview_2).

* During image processing, the target file is corrupted or not in an image format, for example, `https://tos-tools.tos-cn-beijing.volces.com/misc/example.doc?x-tos-process=image/resize,w_100`, where the target file is a document.


<span id="41bd95c9"></span>
# Solution 

Use the correct image processing request parameters. For more information, see [Image Processing Overview](https://docs.byteplus.com/en/docs/tos/docs-overview_2).
