# Problem description

Image style name is invalid.

<span id="0a17e82c"></span>
# Root cause

Image style name is invalid.

<span id="075e4c9f"></span>
# Example


* The style name in the request contains illegal characters, for example, `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=style/style*123`, where the style name `style*123` contains illegal characters `*`.

* The style name length in the request exceeds the limit, for example, `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=style/`, where the style name length is 0, but the allowed length is 1 to 256 characters.


<span id="41bd95c9"></span>
# Solution

Use style names that follow naming conventions. For more information, see [Creating image styles](https://docs.byteplus.com/en/docs/tos/docs-creating-an-image-style).
