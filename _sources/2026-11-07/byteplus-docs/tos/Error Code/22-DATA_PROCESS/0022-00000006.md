# Problem description

The image watermark request parameters are invalid.

<span id="0a17e82c"></span>
# Root cause

The image watermark feature received invalid request parameters.

<span id="075e4c9f"></span>
# Example

Invalid parameters related to the image watermark feature, such as:


* The parameter value exceeds the range. The parameter `size`, representing the font size of the text watermark, must be within (0,1000]. Illegal values trigger this error code. For example, in `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/watermark,text_SGVsbG8,size_10000`, the size is 10000, exceeding the limit.

* Parameter encoding error. The watermark image for image watermarking or the text content for text watermarking requires URL\-safe Base64 encoding. An illegal encoded string triggers this error code. For example, in `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/resize,p_60/watermark,image_==xxx` and `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/resize,p_60/watermark,text_==xxx`, the encoded fields `==xxx` are not valid URL\-safe Base64 strings.


<span id="41bd95c9"></span>
# Solution 

Use the correct image watermark parameters. For more information, see [Image Watermark](https://docs.byteplus.com/en/docs/tos/docs-watermarking).
