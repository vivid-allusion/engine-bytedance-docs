# Problem description

Access to protected original image is forbidden.

<span id="0a17e82c"></span>
# Root cause

The image you are trying to access has original image protection enabled and cannot be accessed.

<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution

Access the image using a URL with image style parameters or a pre\-signed URL. For more information, see [original image protection](https://docs.byteplus.com/en/docs/tos/docs-original-image-protection).
