# Problem description

The watermark image required in the image processing request does not exist.

<span id="0a17e82c"></span>
# Root cause

The watermark image required in the image processing request does not exist.

<span id="075e4c9f"></span>
# Example

Current status: The example bucket tos\-tools contains images misc/sample.png and misc/watermark1.png, but misc/watermark1.jpg does not exist.

Operation: When using the non\-existent watermark image misc/watermark1.jpg, misc/watermark1.jpg is encoded as `bWlzYy93YXRlcm1hcmsxLmpwZw==`. The request link `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/watermark,image_bWlzYy93YXRlcm1hcmsxLmpwZw==` returns an error indicating the watermark image does not exist.

<span id="41bd95c9"></span>
# Solution

Add a watermark using an existing watermark image.

For the problem example, you can add the image watermark misc/watermark1.png in the bucket. misc/watermark1.png is encoded as `bWlzYy93YXRlcm1hcmsxLnBuZw==`. And use the link `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.png?x-tos-process=image/watermark,image_bWlzYy93YXRlcm1hcmsxLnBuZw==`.
