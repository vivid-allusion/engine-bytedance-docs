# Problem description

Video processing request denied access to the original video.

<span id="0a17e82c"></span>
# Root cause

Access to the original video is denied during video processing.

<span id="075e4c9f"></span>
# Example

None.

<span id="41bd95c9"></span>
# Solution

Use a video with access permission to complete video processing. If you want to access a private video, you can complete the video processing using a pre\-signed URL.
