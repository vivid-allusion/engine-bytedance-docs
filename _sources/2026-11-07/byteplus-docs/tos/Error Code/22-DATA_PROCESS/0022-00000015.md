# Problem description

Video processing request parameters are invalid or the target video decoding failed.

<span id="0a17e82c"></span>
# Root cause

Video processing request parameters are invalid or the target video decoding failed.

<span id="075e4c9f"></span>
# Example

Check whether the parameters in `x-tos-process` are valid or if the target video content is correct, for example:


* Current video processing only supports `info` and `snapshot` operations, for example, the request `https://tos-tools.tos-cn-beijing.volces.com/misc/video.mp4?x-tos-process=video/snap,t_26000,w_400,h_200,f_jpg`, in which `snapshot` is incorrectly filled as `snap`.

* The target file being accessed is not a video or the video content is corrupted, for example, the request `https://tos-tools.tos-cn-beijing.volces.com/misc/sample.jpg?x-tos-process=video/snapshot,t_26000,w_400,h_200,f_jpg`, where the target file accessed is not a video.

* Parameter is incorrectly specified, for example, `https://tos-tools.tos-cn-beijing.volces.com/misc/video.mp4?x-tos-process=video/snapshot,t_26000,w_400,h_200,f_webp`, where the output image format is specified as WebP.`f`Filled in as unsupported `webp`.


<span id="41bd95c9"></span>
# Solution 

Use the correct video processing parameters. For more information, see [video processing overview](https://docs.byteplus.com/en/docs/tos/docs-overview_7).
