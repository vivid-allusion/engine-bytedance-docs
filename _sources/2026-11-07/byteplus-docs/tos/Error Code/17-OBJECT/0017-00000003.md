# Problem description

object does not exist.

<span id="3616764e"></span>
# Root cause

the object or a specific version of the object does not exist when the user tries to access it.

<span id="76b07535"></span>
# Example

none.

<span id="eee483d4"></span>
# Solution

make sure the requested object exists. you can verify the existence of the object through the [HeadObject](https://docs.byteplus.com/en/docs/tos/reference-headobject) interface.
