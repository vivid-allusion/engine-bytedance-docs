# Problem description

The current object's storage type does not support the restore operation.

<span id="3616764e"></span>
# Root cause

The user sends a RestoreObject request for an object stored in non\-archive or cold archive storage, causing the request to fail.

<span id="cf2ef955"></span>
# Example

None.

<span id="a7d1f211"></span>
# Solution

Objects stored in non\-archive or cold archive storage can be accessed without restoration.
