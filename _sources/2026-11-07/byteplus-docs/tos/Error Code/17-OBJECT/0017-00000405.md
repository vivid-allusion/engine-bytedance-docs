# Problem description

Error in policy form field in PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the policy form field is not constructed from valid JSON text.

<span id="cf2ef955"></span>
# Example

Assume the text used to construct the policy form field is as follows:

```JSON
"conditions": "abc"
```


If this text is used to construct the policy form field and send the request, this error will be returned.

<span id="332095b8"></span>
# Solution

See [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) for correctly constructing the request form field and ensuring the policy form field contains valid values.
