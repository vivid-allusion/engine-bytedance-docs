# Problem description

The Tier parameter value in the RestoreObject request is invalid.

<span id="3616764e"></span>
# Root cause

The user sent a RestoreObject request, but the `Tier` parameter value was not `Standard`, `Expedited`, or `Bulk`.

<span id="cf2ef955"></span>
# Example

When restoring an object, the `Tier` parameter value in the request is invalid.

```Go
POST /objectname?restore&versionId=***
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue

{
    "RestoreRequest": {
        "Days": 10
    },
    "GlacierJobParameters": {
        "Tier": "ABC"
    }
}
```


<span id="332095b8"></span>
# Solution

Ensure the `Tier` parameter has a valid value.
