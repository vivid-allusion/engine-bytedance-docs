# Problem description

URL parameter offset has an illegal value.

<span id="3616764e"></span>
# Root cause

When a user uploads an append object, the URL parameter offset is not a positive integer.

<span id="76b07535"></span>
# Example

You initiate an AppendObject request with URL parameter offset set to illegal value \-1.

```Go
POST /objectName?append&offset=-1 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

<append data>
```


<span id="fcfb65f8"></span>
# Solution

Ensure the URL parameter offset has a legal value.
