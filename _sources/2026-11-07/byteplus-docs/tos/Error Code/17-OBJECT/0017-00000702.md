# Problem description

[GetSymlink](https://docs.byteplus.com/en/docs/tos/Getsymlink) request failed.

<span id="3616764e"></span>
# Root cause

The user initiated a GetSymlink request, but the specified object is not a symbolic link.

<span id="cf2ef955"></span>
# Example

In the following request, the specified object common\-object is not a symbolic link, causing the request to fail.

```Go
GET /common-object?symlink
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue
```


<span id="cf2ef955"></span>
# Solution 

Ensure the requested object is a symbolic link. You can check if the object is a symbolic link by the x\-tos\-object\-type in the [HeadObject](https://docs.byteplus.com/en/docs/tos/reference-headobject) response.
