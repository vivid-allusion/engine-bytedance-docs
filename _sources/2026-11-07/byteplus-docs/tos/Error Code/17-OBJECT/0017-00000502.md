# Problem description

The Days parameter value in the RestoreObject request is invalid.

<span id="3616764e"></span>
# Root cause

The user initiated a RestoreObject request, but the Days parameter value is outside the [1, 365] range.

<span id="cf2ef955"></span>
# Example

The Days parameter value in your object restore request is invalid.

```Go
POST /objectname?restore
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue

{
    "RestoreRequest": {
        "Days": 400
    }
}
```


<span id="332095b8"></span>
# Solution

Ensure the Days parameter value is within the range of [1, 365].
