# Problem description

policy form field error in PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but in the policy form field, when an element in conditions is of Map type, the Map size is not 1.

<span id="cf2ef955"></span>
# Example

Assuming the policy form field text is constructed as follows:

```JSON
{
  "conditions": [
    {"bucket": "examplebucket","key":"abc"}
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If you use it to construct the policy form field and send the request, this error will be returned.

<span id="332095b8"></span>
# Solution

See [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) for correctly constructing the request form field and ensuring the policy form field values are valid.
