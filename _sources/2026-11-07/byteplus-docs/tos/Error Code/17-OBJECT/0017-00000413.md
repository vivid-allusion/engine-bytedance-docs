# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiated a PostObject request, but in the policy form field, when the data type of an element in `conditions` is a List and the first element is `eq` or `starts-with`, the second element is neither a string type nor starts with $.

<span id="cf2ef955"></span>
# Example

Assume the text for constructing the policy form field is as follows:

```JSON
{
  "conditions": [
    ["eq",123,"examplebucket"]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If used to construct the policy form field and the request is sent, this error is returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to correctly construct the request form field, ensuring the policy form field value is valid.
