# Problem description

The number of objects in batch deletion exceeds 1000.

<span id="3616764e"></span>
# Root cause

The user initiates a DeleteMultiObjects request, and the request body contains more than 1000 objects.

<span id="76b07535"></span>
# Example

None.

<span id="7dc48ecd"></span>
# Solution  

Ensure that the number of objects in each batch deletion does not exceed 1000.
