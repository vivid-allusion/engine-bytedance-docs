#  Problem description

Appending write objects does not support stream upload.

<span id="3616764e"></span>
# Root cause

The user uploads appending write objects using streaming.

<span id="76b07535"></span>
# Example

None.

<span id="fcfb65f8"></span>
# Solution  

Upload appending write objects using a non\-streaming method.
