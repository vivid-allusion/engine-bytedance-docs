# Problem description

Incorrect policy form field in the PostObject request.

<span id="3616764e"></span>
# Root cause

The user sends a PostObject request, but the policy form field’s conditions include non\-existent form fields.

<span id="cf2ef955"></span>
# Example

Assume the constructed policy form field text is as follows:

```JSON
{
  "conditions": [
    ["eq","$acl","private"]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If the PostObject request lacks an acl form field, this error is returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject). Construct the request form fields correctly and ensure the policy form field contains valid values.
