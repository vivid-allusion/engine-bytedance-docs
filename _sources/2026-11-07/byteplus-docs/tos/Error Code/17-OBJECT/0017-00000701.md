# Problem description

PutSymlink request failed.

<span id="3616764e"></span>
# Root cause

The user initiated a PutSymlink request, but the request header field `x-tos-symlink-target` has an invalid value.

<span id="cf2ef955"></span>
# Example

The following request failed because `x-tos-symlink-target` has an invalid value.

```Go
PUT /link-object?symlink
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue
x-tos-symlink-target: a%
```


<span id="cf2ef955"></span>
# Solution

Include the `x-tos-symlink-target` header with a valid value.
