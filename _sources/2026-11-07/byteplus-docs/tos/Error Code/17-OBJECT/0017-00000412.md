# Problem description

Error in the policy form field of the PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiated a PostObject request, but in the policy form field, when the element data type in conditions is a List and the first element is content\-length\-range, the second or third element is not a valid natural number, or the second element is greater than the third element.

<span id="cf2ef955"></span>
# Example

Assume the text used to construct the policy form field is as follows:

```JSON
{
  "conditions": [
    ["content-length-range",20,10]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If used to construct the policy form field and send the request, this error will be returned.

<span id="332095b8"></span>
# Solution

See [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) for correct construction of the request form field, ensuring the policy form field value is valid.
