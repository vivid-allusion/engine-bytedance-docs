# Problem description

The uploaded object or part size exceeds 5GB.

<span id="3616764e"></span>
# Root cause

The user uploaded an object or part larger than 5GB.

<span id="76b07535"></span>
# Example

None.

<span id="eee483d4"></span>
# Solution  

Make sure the size of a single object or part does not exceed 5GB.
