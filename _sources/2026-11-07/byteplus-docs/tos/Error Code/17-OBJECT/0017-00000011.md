# Problem description

When copying an object, the source object does not exist.

<span id="3616764e"></span>
# Root cause

The user tries to copy an object, but the requested source object does not exist.

<span id="76b07535"></span>
# Example

None.

<span id="eee483d4"></span>
# Solution

Ensure the source object exists when copying an object.
