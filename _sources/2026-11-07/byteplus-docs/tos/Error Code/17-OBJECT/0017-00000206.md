# Problem description

When uploading an AppendObject, the appended data size is too small.

<span id="3616764e"></span>
# Root cause

The user initiates an AppendObject request, but the data size carried in the request is too small, such as empty data.

<span id="76b07535"></span>
# Example

None.

<span id="bba9b530"></span>
# Solution 

Ensure the appended data is not empty each time.
