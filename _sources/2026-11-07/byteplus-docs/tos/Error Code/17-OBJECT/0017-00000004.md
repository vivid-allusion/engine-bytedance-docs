# Problem description

The target object already exists.

<span id="3616764e"></span>
# Root cause

The upload request fails because the object being written through interfaces like PutObject or CopyObject already exists.

<span id="76b07535"></span>
# Example

You initiated the following request:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
Content-length: length
x-tos-forbid-overwrite: true

<put data>
```


<span id="eee483d4"></span>
# Solution


* Before uploading, verify if the object exists using the [HeadObject](https://docs.byteplus.com/en/docs/tos/reference-headobject) interface.

* If you want to overwrite a file with the same name, remove the `x-tos-forbid-overwrite` parameter from the request or set its value to `false`.
