# Problem description

Uploading an appended object does not support carrying the URL parameter versionId.

<span id="3616764e"></span>
# Root cause

The user initiates an AppendObject request, and the request URL contains the parameter versionId.

<span id="76b07535"></span>
# Example

You upload an appended object carrying the versionId parameter.

```Go
POST /objectName?append&offset=0&versionId=5787DD26CC44761A964F HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

<append data>
```


<span id="bba9b530"></span>
# Solution 

Remove the versionId parameter from the request URL.
