# Problem description

Buckets with the archive storage class do not support uploading appendable objects.

<span id="3616764e"></span>
# Root cause

When users upload appendable objects, requests fail because the bucket is set to archive storage class.

<span id="76b07535"></span>
# Example

None.

<span id="34a0513b"></span>
# Solution    

Change the bucket storage class to standard storage.
