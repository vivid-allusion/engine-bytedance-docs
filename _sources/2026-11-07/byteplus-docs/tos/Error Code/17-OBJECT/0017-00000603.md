# Problem description

Legacy objects do not support rename.

<span id="3616764e"></span>
# Root cause

The user initiates an object rename request, but the requested object is a legacy object (uploaded before enabling the RenameObject feature on the bucket). This error is returned.

<span id="cf2ef955"></span>
# Example

None.

<span id="cf2ef955"></span>
# Solution

Ensure the object is newly uploaded after enabling the RenameObject feature on the bucket.
