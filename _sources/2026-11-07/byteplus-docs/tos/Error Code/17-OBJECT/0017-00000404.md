# Problem description

Policy form field error in PostObject request.

<span id="3616764e"></span>
# Root cause

The user sent a PostObject request with the conditions field in the policy form not set as a list.

<span id="cf2ef955"></span>
# Example

Assume the JSON text used to build the policy form field is as follows:

```JSON
{
  "conditions": "abc"
}
```


If this is used to build the policy form field and the request is sent, this error will occur.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject). Construct the request form fields correctly and ensure the policy form field value is valid.
