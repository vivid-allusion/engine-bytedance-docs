# Problem description

The policy field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but in the policy form field, when the element in conditions is a List and the first element is `eq` or `starts-with`, the third element is not a string type.

<span id="cf2ef955"></span>
# Example

Assuming the text for the policy form field is constructed as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket",123]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If this text is used to build the policy form field and a request is sent, the error will be returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and correctly construct the request form field, ensuring the policy form field value is valid.
