# Problem description

PostObject request form field format is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the request form fields do not meet interface requirements.

<span id="76b07535"></span>
# Example

None.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and correctly construct the request form fields.
