# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiated a PostObject request, but the policy form field has expired.

<span id="cf2ef955"></span>
# Example

Assume the text used to construct the policy form field is as follows:

```JSON
{
  "expiration":"2006-01-02T15:04:05Z"
}
```


If the policy form field is constructed and used in 2023 to initiate a request, this error occurs.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) for correctly constructing the request form field and ensuring the policy form field value is valid.
