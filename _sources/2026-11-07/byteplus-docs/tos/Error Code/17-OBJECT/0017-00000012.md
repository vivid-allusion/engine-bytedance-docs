# Problem description

No permission to operate the source object when copying the object.

<span id="3616764e"></span>
# Root cause

The user lacks permission to operate the source object during the copy operation.

<span id="76b07535"></span>
# Example

None.

<span id="eee483d4"></span>
# Solution  

Ensure the requesting user has permission to operate the source object. you can confirm permission by downloading the source object.
