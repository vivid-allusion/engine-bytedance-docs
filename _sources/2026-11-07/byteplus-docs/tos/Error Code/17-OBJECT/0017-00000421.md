# Problem description

PostObject request lacks the file form field.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the file form field is missing in the request.

<span id="cf2ef955"></span>
# Example

None.

<span id="332095b8"></span>
# Solution 

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to correctly construct the request form fields, ensuring the file form field exists and is the last form field.
