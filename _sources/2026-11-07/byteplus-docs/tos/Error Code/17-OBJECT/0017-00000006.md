# Problem description

The x\-tos\-copy\-source parameter value is invalid.

<span id="3616764e"></span>
# Root cause

The x\-tos\-copy\-source parameter value in the request is invalid when the user copies objects.

<span id="76b07535"></span>
# Example

You sent the following request:

```Go
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
x-tos-copy-source: /sourcebucketname
```


x\-tos\-copy\-source sets the source bucket and object information for copying. The correct format is /source\-bucket/source\-key. The x\-tos\-copy\-source value in the request above is invalid.

<span id="eee483d4"></span>
# Solution 

Ensure the x\-tos\-copy\-source parameter value is correct.
