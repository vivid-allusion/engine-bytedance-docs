# Problem description

URL parameter `append-last-time` has an invalid value.

<span id="3616764e"></span>
# Root cause

When the user uploads an appendable object, the value of the `append-last-time` parameter in the URL is neither `true` nor `false`.

<span id="76b07535"></span>
# Example

You sent an AppendObject request with an invalid value for the URL parameter `append-last-time`.

```Go
POST /objectName?append&offset=101&append-last-time=abc HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

<append data>
```


<span id="fcfb65f8"></span>
# Solution

Ensure the URL parameter `append-last-time` has a valid value.
