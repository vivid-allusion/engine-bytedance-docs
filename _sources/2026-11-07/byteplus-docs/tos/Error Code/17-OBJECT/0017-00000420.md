# Problem description

PostObject request is missing the key form field.

<span id="3616764e"></span>
# Root cause

The user sent a PostObject request missing the key form field.

<span id="cf2ef955"></span>
# Example

None.

<span id="332095b8"></span>
# Solution    

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to correctly construct the request form fields and ensure the key form field is present.
