# Problem description

When batch deleting objects, the request body format is invalid, or the number of objects to delete is 0.

<span id="3616764e"></span>
# Root cause

The user sends a DeleteMultiObjects request with an invalid request body format or zero objects to delete.

<span id="76b07535"></span>
# Example

You performed a batch delete operation with an invalid request body format.

```Go
POST /?delete HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
Content-MD5: md5 xxx

...random string...
```


<span id="eee483d4"></span>
# Solution 

Refer to [DeleteMultiObjects](https://docs.byteplus.com/en/docs/tos/reference-deletemultiobjects). Construct the request body properly and ensure the number of objects to delete is greater than zero.
