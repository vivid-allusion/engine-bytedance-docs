# Problem description

Appending an object does not support server\-side encryption.

<span id="3616764e"></span>
# Root cause

The user initiated an AppendObject request and applied server\-side encryption to the object, causing the request to fail.

<span id="76b07535"></span>
# Example

You initiate an AppendObject request and specify SSE\-KMS encryption for the object.

```Go
POST /objectName?append&offset=0 HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-server-side-encryption: kms
Authorization: authorization xxx

<append data>
```


<span id="fcfb65f8"></span>
# Solution

Remove the server\-side encryption headers or the bucket encryption configuration.
