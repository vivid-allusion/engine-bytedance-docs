# Problem description

object name length exceeds 1024.

<span id="3616764e"></span>
# Root cause

when accessing an object, the provided object name length exceeds 1024.

<span id="76b07535"></span>
# Example

none.

<span id="eee483d4"></span>
# Solution

ensure the object name length in the request does not exceed 1024.
