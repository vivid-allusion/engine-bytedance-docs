# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the policy form field contains unsupported fields. The valid policy form field is a JSON text encoded to include expiration and conditions fields.

<span id="cf2ef955"></span>
# Example

Assuming the JSON text constructing the policy form field is as follows:

```JSON
{
  "conditions": [
    {"bucket": "examplebucket"},
    ["eq", "$key", "exampleobject"]
  ],
  "test":"abc"
}
```


If this is used to construct the policy form field and initiate the request, this error is returned.

<span id="332095b8"></span>
# Solution

See [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) for properly constructing request form fields and ensuring the policy form field contains valid values.
