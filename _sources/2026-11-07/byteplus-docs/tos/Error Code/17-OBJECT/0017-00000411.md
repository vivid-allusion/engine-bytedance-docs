# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but in the policy form field, when an element in conditions is a list, its first item's value is not `eq`, `starts-with`, or `content-length-range`.

<span id="cf2ef955"></span>
# Example

Assume the text of the constructed policy form field is as follows:

```JSON
{
  "conditions": [
    ["abc","$bucket","examplebucket"]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If this is used to construct the policy form field and send the request, this error will be returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to properly construct the request form field and ensure the policy form field values are valid.
