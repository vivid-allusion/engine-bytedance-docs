# Problem description

The symlink feature is in invitation\-only testing and is not yet available to all users.

<span id="3616764e"></span>
# Root cause

The symlink feature is in invitation\-only testing and is currently available only to a subset of users.

<span id="cf2ef955"></span>
# Example issue

A user called the PutSymlink API to create a symlink, but this API is not yet available to the user, causing the request to fail.

```Go
PUT /link-object?symlink
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
x-tos-symlink-target: target-key
Authorization: SignatureValue
```


<span id="cf2ef955"></span>
# Solution

If you confirm that you are on the invitation list for this feature, please submit a ticket to contact technical support.
