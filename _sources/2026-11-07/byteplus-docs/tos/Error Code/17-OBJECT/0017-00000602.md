# Problem description

Renaming objects is not supported for buckets with versioning enabled.

<span id="3616764e"></span>
# Root cause

The rename request fails because the bucket is either versioning\-enabled or suspended.

<span id="cf2ef955"></span>
# Example

None.

<span id="cf2ef955"></span>
# Solution

Ensure the bucket requested does not have versioning enabled.
