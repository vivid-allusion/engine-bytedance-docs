# Problem description

Appending to an archived append object is not supported.

<span id="3616764e"></span>
# Root cause

The user tries to append again to an archived append object, causing a request error.

<span id="76b07535"></span>
# Example

If you completed the last append to the object using the URL parameter append\-last\-time during the previous append request, and then initiate another append request, this error will be returned.

<span id="34a0513b"></span>
# Solution

None.
