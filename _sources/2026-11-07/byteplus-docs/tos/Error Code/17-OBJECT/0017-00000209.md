# Problem description

Append write object does not support this operation.

<span id="3616764e"></span>
# Root cause

The request fails because the user tries to operate on an append write object with an unsupported operation.

<span id="76b07535"></span>
# Example

None.

<span id="34a0513b"></span>
# Solution

Make sure the requested object is not an append write object.
