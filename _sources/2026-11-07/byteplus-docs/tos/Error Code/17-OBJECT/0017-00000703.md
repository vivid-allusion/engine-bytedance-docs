# Problem description

The target file pointed to by the symbolic link does not exist.

<span id="3616764e"></span>
# Root cause

The user requests access to a symbolic link, but the target file it points to does not exist.

<span id="cf2ef955"></span>
# Example 

You request to download a symbolic link, but the target file it points to does not exist, causing the request to fail.

```Go
GET /link-nothing HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue
```


<span id="cf2ef955"></span>
# Solution

Ensure the target file pointed to by the symbolic link exists. You can check the target file and its bucket through the GetSymlink interface and verify the target file’s existence using the HeadObject interface.
