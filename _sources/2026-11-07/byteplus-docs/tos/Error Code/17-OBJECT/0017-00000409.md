# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but in the policy form field, when an element in conditions has a Map data type, its value is not a string.

<span id="cf2ef955"></span>
# Example

Assume the policy form field text is constructed as follows:

```JSON
{
  "conditions": [
    {"bucket": 123}
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If the policy form field is constructed this way and the request is sent, this error will be returned.

<span id="332095b8"></span>
# Solution 

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to construct the request form field correctly and ensure the policy form field value is valid.
