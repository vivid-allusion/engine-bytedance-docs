# Problem description

Soft links do not support RestoreObject operations.

<span id="3616764e"></span>
# Root cause

The request fails because the user initiates a RestoreObject operation on a soft link.

<span id="cf2ef955"></span>
# Example

If the requested object (link\-file) is a soft link in the following request, this error is returned.

```Go
POST /link-file?restore
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue

{
    "RestoreRequest": {
        "Days": 10
    },
    "RestoreJobParameters": {
        "Tier": "Standard"
    }
}
```


<span id="cf2ef955"></span>
# Solution

Ensure the requested object is not a soft link. You can check if an object is a soft link by the x\-tos\-object\-type in the HeadObject response.
