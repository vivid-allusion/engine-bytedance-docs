# Problem description

Downloading this object using the bucket's default domain is prohibited.

<span id="3616764e"></span>
# Root cause

Users preview arbitrary file types or download files with the .apk or .ipa suffix directly by signing URLs or anonymously using the bucket's default domain.

<span id="76b07535"></span>
# Example

none.

<span id="eee483d4"></span>
# Solution  

Access this object through a custom domain. For detailed steps, see [Set up a custom domain](https://docs.byteplus.com/en/docs/tos/Set-up-a-custom-domain-name).
