# Problem description

The [RestoreObject](https://docs.byteplus.com/en/docs/tos/reference-restoreobject) request body contains an invalid structure.

<span id="3616764e"></span>
# Root cause

The user initiated a RestoreObject request, but the request body has an invalid structure.

<span id="cf2ef955"></span>
# Example

The request body has an invalid structure when restoring the object.

```Go
POST /objectname?restore
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue

...Random string...
```


<span id="332095b8"></span>
# Solution 

Refer to RestoreObject to ensure the request body structure is valid.
