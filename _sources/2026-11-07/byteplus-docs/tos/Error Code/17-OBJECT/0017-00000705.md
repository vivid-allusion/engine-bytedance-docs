# Problem description

PutSymlink request failed.

<span id="3616764e"></span>
# Root cause

The user initiated a PutSymlink request, but the request header field x\-tos\-symlink\-bucket contains an invalid value or is not in the same Region as the target bucket.

<span id="cf2ef955"></span>
# Example

In the following request, the header field x\-tos\-symlink\-bucket uses a value that does not meet the bucket naming rules, causing the request to fail.

```Go
PUT /link-object?symlink
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
x-tos-symlink-target: common-object
x-tos-symlink-bucket: -invalid-bucket
Authorization: SignatureValue
```


<span id="cf2ef955"></span>
# Solution

Ensure the header field x\-tos\-symlink\-bucket value complies with bucket naming rules and is in the same Region as the target bucket.
