# Problem description

The policy form field in the PostObject request is incorrect.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the conditions in the policy form field contain fields that do not meet the specified matching conditions.

<span id="cf2ef955"></span>
# Example

Assume the policy form field text is constructed as follows:

```JSON
{
  "conditions": [
    {"success_action_status": "200"}
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If the success_action_status form field value in the PostObject request is not 200, this error is returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and construct the request form fields correctly to ensure the policy form field value is valid.
