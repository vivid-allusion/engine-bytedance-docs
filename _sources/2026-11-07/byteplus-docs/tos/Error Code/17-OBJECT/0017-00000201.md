# Problem description

Appending object is not supported for this storage type.

<span id="3616764e"></span>
# Root cause

The user initiates an AppendObject request, but the object's storage type is not standard, causing the request to fail.

<span id="76b07535"></span>
# Example

You initiate an AppendObject request specifying the storage type as archive instant retrieval.

```Go
POST /objectName?append&offset=Offset HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
x-tos-storage-class: ARCHIVE_FR
Authorization: authorization xxx

<append data>
```


<span id="7dc48ecd"></span>
# Solution 

Ensure the storage type for the appended object is standard storage.
