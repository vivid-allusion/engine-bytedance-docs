# Problem description

This storage type is not supported when restoring objects from Archive.

<span id="3616764e"></span>
# Root cause

The user initiates a RestoreObject request for an object stored in Archive, but the `Tier` parameter is not set to `Standard`.

<span id="cf2ef955"></span>
# Example

None.

<span id="a7d1f211"></span>
# Solution

When restoring objects from Archive, ensure the `Tier` parameter is set to `Standard`.
