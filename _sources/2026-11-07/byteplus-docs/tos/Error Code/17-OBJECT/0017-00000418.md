# Problem description

PostObject request `Content-Type` parameter is invalid.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the `Content-Type` parameter value in the request does not meet the interface requirements. The `Content-Type` field must be in the format `multipart/form-data; boundary={boundary}`, where `boundary` is the boundary string.

<span id="cf2ef955"></span>
# Example

None.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject), construct the request form fields correctly, and ensure the `Content-Type` parameter has a valid value.
