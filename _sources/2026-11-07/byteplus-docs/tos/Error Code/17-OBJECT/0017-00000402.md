# Problem description

Policy form field error in PostObject request.

<span id="3616764e"></span>
# Root cause

The user sent a PostObject request, but the policy form field value is not a valid Base64 encoding.

<span id="76b07535"></span>
# Example

None.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject). Construct the request form fields correctly and ensure the policy form field value is valid.
