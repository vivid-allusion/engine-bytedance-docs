# Problem description

Object does not support rename.

<span id="3616764e"></span>
# Root cause

The user initiated an object rename request, but the bucket has not enabled the RenameObject feature, resulting in this error.

<span id="cf2ef955"></span>
# Example

You initiated an object rename request, but the target bucket has not enabled the RenameObject feature, causing the request to fail.

```Go
PUT /objectName?name=Name&rename HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization string
```


<span id="cf2ef955"></span>
# Solution

Enable the RenameObject feature for the bucket and try again. You can use [GetBucketRename](https://docs.byteplus.com/en/docs/tos/Getbucketrename) to check if the bucket has enabled the RenameObject feature.
