# Problem description

Repeated submission of object restore request.

<span id="3616764e"></span>
# Root cause

The user has successfully called the RestoreObject API, and the server is restoring the object when a repeated RestoreObject request is submitted.

<span id="cf2ef955"></span>
# Example

None.

<span id="a7d1f211"></span>
# Solution

Wait until the object is restored to access it; avoid submitting multiple restore requests.
