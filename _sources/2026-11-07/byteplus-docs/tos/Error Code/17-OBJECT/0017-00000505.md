# Problem description

The unrecovered object does not support the current operation.

<span id="3616764e"></span>
# Root cause

The request is made to archive storage or cold archive storage objects, but the request fails because the object has not been recovered.

<span id="cf2ef955"></span>
# Example

None.

<span id="a7d1f211"></span>
# Solution

Perform object recovery first, then retry after the object has been recovered.
