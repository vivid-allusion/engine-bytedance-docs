# Problem description

Deleting a delete marker is not supported for this operation.

<span id="3616764e"></span>
# Root cause

The user specifies the target object version to operate on via the versionId parameter, but the versionId corresponds to the object's delete marker, which does not support this operation, causing the request to fail.

<span id="76b07535"></span>
# Example

You send the following request:

```Go
GET /abc?versionId=5787DD26CC44761A964F HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


If the versionId in the above request corresponds to the delete marker of the abc object, this error occurs.

<span id="eee483d4"></span>
# Solution 

Check if the versionId in the request is a delete marker for the object.
