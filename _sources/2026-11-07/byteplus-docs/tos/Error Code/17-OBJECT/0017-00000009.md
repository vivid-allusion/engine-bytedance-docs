# Problem description

invalid object name.

<span id="3616764e"></span>
# Root cause

the object name for the user's requested operation is not encoded in UTF\-8.

<span id="76b07535"></span>
# Example

none.

<span id="eee483d4"></span>
# Solution  

ensure the object name is encoded in UTF\-8.
