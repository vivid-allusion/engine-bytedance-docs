# Problem description

Incorrect policy form field in PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but in the policy form field, when the element data type in conditions is a List, the List length is not 3.

<span id="cf2ef955"></span>
# Example

Assume the text used to construct the policy form field is as follows:

```JSON
{
  "conditions": [
    ["eq","$bucket","examplebucket","abc"]
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If this is used to build the policy form field and the request is sent, this error will be returned.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and properly construct the request form field to ensure the policy form field values are valid.
