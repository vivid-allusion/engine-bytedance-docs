# Problem description

policy form field error in PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the conditions in the policy form field do not include all form fields (excluding x\-tos\-signature, file, policy, and x\-ignore\-\* form fields).

<span id="cf2ef955"></span>
# Example

Assume the policy form field text is constructed as follows:.

```JSON
{
  "conditions": [
    {"success_action_status": "200"}
  ],
  "expiration":"2023-12-28T15:04:05Z"
}
```


If the x\-tos\-date form field exists in the PostObject request, this error returns.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) to construct the request form fields correctly and ensure the policy form field value is valid.
