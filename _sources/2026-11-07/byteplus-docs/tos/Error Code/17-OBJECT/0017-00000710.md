# Problem description

Custom response header fields in anonymous GET requests.

<span id="3616764e"></span>
# Root cause

This error occurs when an anonymous GET request includes custom response header fields.

<span id="cf2ef955"></span>
# Example

You sent the following request:

```Go
GET /object?response-content-disposition=attachment
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
```


<span id="cf2ef955"></span>
# Solution 

Ensure the GET request is not anonymous, or avoid using custom response header fields.
