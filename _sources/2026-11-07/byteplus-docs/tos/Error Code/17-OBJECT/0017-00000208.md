# Problem description

URL parameter offset has an invalid value.

<span id="3616764e"></span>
# Root cause

When a user uploads an append object, the offset value in the URL parameter does not match the x\-tos\-next\-append\-offset value from the previous append operation.

<span id="76b07535"></span>
# Example

For example, if the x\-tos\-next\-append\-offset value returned from the last append request is 100, but the offset parameter in your next append request is 80, this error occurs.

<span id="34a0513b"></span>
# Solution

Ensure that the offset value in the next AppendObject request matches the x\-tos\-next\-append\-offset value from the previous AppendObject response.
