# Problem description

The copy source specified by the x\-tos\-copy\-source parameter in the UploadPartCopy request is a symbolic link.

<span id="3616764e"></span>
# Root cause

You send an UploadPartCopy request to copy data from an existing object to upload a part, but the copy source specified by the x\-tos\-copy\-source parameter is a symbolic link, causing this error.

<span id="cf2ef955"></span>
# Example

You send the following request:

```Go
PUT /multipart-object?partNumber=2&uploadId=20211931ab891b2fe0f10118e****
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
x-tos-copy-source: /examplebucket/link-object
Authorization: SignatureValue
```


This error occurs if the copy source /examplebucket/link\-object in the request is a symbolic link.

<span id="cf2ef955"></span>
# Solution 

Ensure the copy source specified by the x\-tos\-copy\-source parameter in the request is not a symbolic link. You can check if the object is a symbolic link by looking at the x\-tos\-object\-type field in the HeadObject response.
