# Problem description

Policy form field error in PostObject request.

<span id="3616764e"></span>
# Root cause

The user initiates a PostObject request, but the expiration field value in the policy form field is not in RFC3339 format.

<span id="cf2ef955"></span>
# Example 

Assuming the policy form field text is constructed as follows:

```JSON
{
  "expiration":"abc"
}
```


If it is used to construct the policy form field and send the request, this error will be returned.

<span id="332095b8"></span>
# Solution 

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and correctly construct the request form field to ensure the policy form field value is valid.
