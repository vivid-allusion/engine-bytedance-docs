# Problem description

PostObject request form field size exceeds the limit.

<span id="3616764e"></span>
# Root cause

The user sends a PostObject request, but the form field size exceeds 20KB.

<span id="cf2ef955"></span>
# Example

None.

<span id="332095b8"></span>
# Solution

Refer to [PostObject](https://docs.byteplus.com/en/docs/tos/reference-postobject) and properly construct the request form fields to ensure the form field size does not exceed the interface limit.
