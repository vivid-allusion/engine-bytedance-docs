# Problem description

RestoreObject does not support shortening the replica retention period for restored objects.

<span id="3616764e"></span>
# Root cause

A RestoreObject request to shorten the replica retention period on an already restored object causes the request to fail.

<span id="cf2ef955"></span>
# Example

If you first initiate a RestoreObject request with the Days parameter set to 10, indicating a 10\-day replica retention period, and after the server completes the object restoration on the same day, you send a request to shorten the replica retention to 2 days, the request will return this error.

```Go
POST /objectname?restore
Host: <Bucket name>.<TOS endpoint>
Date: Mon, 18 Mar 2019 08:25:17 GMT
Authorization: SignatureValue

{
    "RestoreRequest": {
        "Days": 2
    }
}
```


<span id="a7d1f211"></span>
# Solution

The replica retention period can only be extended, not shortened.
