# Problem description

Setting the bucket storage class to intelligent tiering is not supported.

<span id="3616764e"></span>
# Root cause

When the user initiates a CreateBucket or PutBucketStorageClass request, the `x-tos-storage-class` header value is `INTELLIGENT_TIERING`, causing the request to fail.

<span id="76b07535"></span>
# Example

If the `x-tos-storage-class` header value is `INTELLIGENT_TIERING`, which is an invalid storage class, this error is returned.

```Go
PUT /?storageClass HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
x-tos-storage-class: INTELLIGENT_TIERING
```


<span id="789d23d8"></span>
# Solution

Ensure the storage class in the request is not `INTELLIGENT_TIERING`.
