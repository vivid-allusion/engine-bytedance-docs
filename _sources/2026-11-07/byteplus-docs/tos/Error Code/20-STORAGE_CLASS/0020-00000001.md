# Problem description

Invalid storage type.

<span id="3616764e"></span>
# Root cause

The request carries an invalid storage type when the user performs bucket or object operations. The currently supported storage types on the server are as follows:


* STANDARD: Standard Storage.

* IA: Infrequent Access Storage.

* ARCHIVE_FR: Flashback Archive.

* ARCHIVE: Archive.

* COLD_ARCHIVE: Cold Archive.


<span id="76b07535"></span>
# Example

The request header `x-tos-storage-class` has the value `test`, which is not a valid storage type and causes the request to fail.

```Go
PUT /?storageClass HTTP/1.1
Host: bucketname.tos-cn-beijing.volces.com
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
x-tos-storage-class: test
```


<span id="789d23d8"></span>
# Solution

Ensure the storage type in the request is valid.
