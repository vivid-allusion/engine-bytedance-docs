# Problem description

Buckets with multi\-AZ redundancy do not support archive storage or cold archive storage.

<span id="3616764e"></span>
# Root cause

The request carries a storage type of archive storage or cold archive storage when the user operates on a bucket or object, but the target bucket is of the multi\-AZ redundancy type, causing the request to fail.

<span id="76b07535"></span>
# Example

None.

<span id="584ca571"></span>
# Solution

Ensure the requested bucket is not multi\-AZ redundancy type or modify the storage type carried in the request.
