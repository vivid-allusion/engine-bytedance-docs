# Problem description

creation of a bucket with the same name failed.

<span id="3616764e"></span>
# Root cause


* the user has reached the maximum limit of 100 buckets and attempted to create a bucket that the user already owns.

* concurrent creation of buckets with the same name by the user.


<span id="76b07535"></span>
# Example

none.

<span id="2e74f099"></span>
# Solution


* retrieve the user's bucket list, confirm that the bucket to be created is not in the list, then proceed with the bucket creation operation.

* Do not create buckets with the same name concurrently
