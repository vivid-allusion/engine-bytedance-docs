# Problem description

Request header field x\-tos\-az\-redundancy has an illegal value.

<span id="3616764e"></span>
# Root cause

The user initiates a bucket creation request. The request header field `x-tos-az-redundancy` has a non `single-az` or `multi-az`.

<span id="76b07535"></span>
# Example

You initiate a CreateBucket request. The request header field `x-tos-az-redundancy` has an illegal value.

```Go
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
x-tos-az-redundancy: 123
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization xxx
```


<span id="2e74f099"></span>
# Solution

Ensure the header field `x-tos-az-redundancy` has a value of `single-az` or `multi-az`.
