# Problem description

The bucket does not exist.

<span id="3616764e"></span>
# Root cause

The user is accessing a bucket that does not exist.

<span id="76b07535"></span>
# Example

If you request to download object abc from bucket test, but bucket test does not exist, this error will be returned.

```Go
GET /abc HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx
```


<span id="a0a66e48"></span>
# Solution

Check if the bucket name in the request is misspelled and ensure the bucket exists.
