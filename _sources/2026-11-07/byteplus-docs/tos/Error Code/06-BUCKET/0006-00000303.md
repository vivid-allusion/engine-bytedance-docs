# Problem description

Bucket without enabled versioning cannot be set to suspended state.

<span id="3616764e"></span>
# Root cause

User attempts to set bucket versioning status to suspended without ever enabling versioning.

<span id="76b07535"></span>
# Example

You request to suspend bucket versioning, but if the bucket has never had versioning enabled, this error occurs.

```Go
PUT /?versioning HTTP/1.1 
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

{ 
    "Status":"Suspended"
}
```


<span id="2e74f099"></span>
# Solution

Enable bucket versioning first, then set the versioning status to suspended.
