# Problem description

Invalid multi\-version status configuration.

<span id="3616764e"></span>
# Root cause

When configuring multiple versions, the multi\-version status value is not `Enabled` or `Suspended`.

<span id="76b07535"></span>
# Example

You submitted a multi\-version configuration request with an invalid multi\-version status value.

```Go
PUT /?versioning HTTP/1.1 
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

{ 
    "Status":"abc"
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketVersioning](https://docs.byteplus.com/en/docs/tos/Putbucketversioning) to correctly set the bucket's multi\-version configuration.
