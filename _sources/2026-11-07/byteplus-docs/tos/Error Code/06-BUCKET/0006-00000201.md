# Problem description

Buckets containing objects or parts cannot be deleted.

<span id="3616764e"></span>
# Root cause

The user initiates a DeleteBucket request, but the bucket contains objects or parts that have not been cleared.

<span id="76b07535"></span>
# Example

If you initiate a DeleteBucket request while the bucket still contains objects or parts that have not been cleared, this error will be returned.

```Go
DELETE / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization xxx
```


<span id="2e74f099"></span>
# Solution

Ensure objects or parts are cleared before deleting the bucket:


* If the number of objects is small, delete them manually. For specific operations, refer to [Deleting files](https://docs.byteplus.com/en/docs/tos/docs-deleting-a-file).

* If the number of parts is small, you can delete them manually. For specific operations, refer to [Managing parts](https://docs.byteplus.com/en/docs/tos/docs-managing-parts).

* If there are many objects or parts, we recommend deleting them using lifecycle rules. For specific operations, refer to [Configuring lifecycle rules](https://docs.byteplus.com/en/docs/tos/Lifecycle-rules-overview).
