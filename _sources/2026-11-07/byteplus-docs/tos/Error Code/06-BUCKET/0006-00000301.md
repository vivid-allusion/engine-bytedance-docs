# Problem description

The multi\-version configuration format is invalid.

<span id="3616764e"></span>
# Root cause

The multi\-version configuration structure in the request is invalid when the user sets up multi\-version configuration.

<span id="76b07535"></span>
# Example

Your multi\-version configuration request contains an invalid multi\-version configuration structure in the request body.

```Go
PUT /?versioning HTTP/1.1 
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

...Random string...
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketVersioning](https://docs.byteplus.com/en/docs/tos/Putbucketversioning) to properly construct the bucket's multi\-version configuration.
