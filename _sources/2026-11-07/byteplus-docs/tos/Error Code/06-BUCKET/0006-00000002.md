# Problem description

The bucket name is invalid.

<span id="3616764e"></span>
# Root cause

The bucket name accessed by the user is invalid. Bucket naming rules are as follows:


* Length must be between 3 and 63 characters.

* It must contain only lowercase letters, numbers, and hyphens (\-).

* It cannot start or end with a hyphen (\-).


<span id="76b07535"></span>
# Example

Your CreateBucket request specifies the bucket name ABC, which does not comply with the bucket naming rules.

```Go
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Authorization: authorization string
Date: Fri, 30 Jul 2021 06:45:39 GMT
```


<span id="a0a66e48"></span>
# Solution

Use a valid bucket name according to the bucket naming rules.
