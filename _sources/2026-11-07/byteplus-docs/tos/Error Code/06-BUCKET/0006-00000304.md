# Problem description

buckets configured with cross\-region replication rules cannot have their versioning status modified.

<span id="3616764e"></span>
# Root cause

when configuring bucket versioning, users cannot change the versioning status if the bucket already has cross\-region or same\-region replication rules applied.

<span id="76b07535"></span>
# Example

none.

<span id="164cfe63"></span>
# Solution

delete the cross\-region replication rules before modifying the bucket’s versioning status.
