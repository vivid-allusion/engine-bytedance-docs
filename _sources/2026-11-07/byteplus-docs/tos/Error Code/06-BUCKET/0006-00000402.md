# Problem description

rename configuration format is invalid.

<span id="3616764e"></span>
# Root cause

The configuration structure carried in the rename request by the user is invalid.

<span id="f8c2025d"></span>
# Example

You initiated a rename configuration request, but the configuration structure in the request body is invalid.

```Go
PUT /?rename HTTP/1.1 
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

{ 
    "RenameEnable1":true
}
```


<span id="2e74f099"></span>
# Solution

Correctly construct the bucket rename configuration.
