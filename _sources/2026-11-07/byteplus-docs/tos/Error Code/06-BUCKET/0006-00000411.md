# Problem description

When configuring the cross\-region replication rule, the accelerated transfer link is selected, but the bucket transfer acceleration is not yet effective.

<span id="3616764e"></span>
# Root cause

After enabling the transfer acceleration feature, it takes about 30 minutes to take effect. Only after it becomes effective can the cross\-region replication rule use the accelerated transfer link.

<span id="76b07535"></span>
# Example

You issue a PutBucketReplication configuration request with the `TransferType` field set to tos_acc, but the bucket transfer acceleration has not yet taken effect.

```HTTP
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
Content-Length: 120
Content-MD5: XrY7u+Ae7tCTyyK7j1rNww==
{
  "Role": "ServiceRoleforReplicationAccessTOS",
  "Rules": [{
      "ID": "1",
      "Status": "Enabled",
      "PrefixSet": ["prefix_1", "prefix_2"],
      "Destination": {
        "Bucket": "Target Bucket Name",
        "Location": "cn-beijing",
        "StorageClass": "STANDARD"
      },
      "TransferType":"tos_acc",
      "HistoricalObjectReplication": "Enabled",
      "AccessControlTranslation": {
        "Owner": "BucketOwnerEntrusted"
      }
   }]
}
```


<span id="2e74f099"></span>
# Solution

Wait until the bucket transfer acceleration takes effect before configuring the cross\-region replication rule.
