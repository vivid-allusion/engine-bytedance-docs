# Problem description

The `RenameEnable` field in the rename configuration is set to a value other than `true`.

<span id="3616764e"></span>
# Root cause

When the user configures rename, the `RenameEnable` field is set to a value other than `true`.

<span id="76b07535"></span>
# Example

You initiated a rename configuration request with an invalid value for the `RenameEnable` field.

```Go
PUT /?rename HTTP/1.1 
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Authorization: authorization xxx

{ 
    "RenameEnable":false
}
```


<span id="2e74f099"></span>
# Solution

Ensure the `RenameEnable` field is set to `true` when configuring rename.
