# Problem description

The created bucket already belongs to another user.

<span id="3616764e"></span>
# Root cause

The user initiated a bucket creation request, but the specified bucket has already been created by another user.

<span id="76b07535"></span>
# Example

You send a CreateBucket request, but the bucket already belongs to another user, so this error is returned.

```Go
PUT / HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 06:45:39 GMT
Authorization: authorization xxx
```


<span id="2e74f099"></span>
# Solution

Use another bucket name that is not already taken.
