# Problem description

Bucket configuration conflict. Adjust according to the error message.

<span id="3616764e"></span>
# Root cause

When configuring the bucket, the user's settings conflict with an existing bucket configuration, causing a conflict.

<span id="76b07535"></span>
# Example

None.

<span id="164cfe63"></span>
# Solution

Adjust the conflicting bucket configuration based on the error message.
