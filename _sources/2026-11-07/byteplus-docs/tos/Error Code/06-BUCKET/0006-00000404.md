# Problem description

The accelerated transfer domain was used, but the bucket transfer acceleration was not enabled.

<span id="d47971c3"></span>
# Root cause

The accelerated transfer domain was used, but the bucket transfer acceleration was not enabled.

<span id="fd465a29"></span>
# Example

None.

<span id="727cee8b"></span>
# Solution

Enable bucket transfer acceleration and wait for it to take effect before use; or switch to the TOS standard domain.
