# Problem description

The bucket is still in use and cannot be recreated.

<span id="3616764e"></span>
# Root cause

If the bucket was recently deleted, it cannot be recreated within a certain time. Attempting to create a bucket with the same name during this period will return this error.

<span id="76b07535"></span>
# Example

None.

<span id="8534a953"></span>
# Solution

Use a different unused bucket name, or wait for some time before retrying (currently around 30 minutes, but this duration may vary).
