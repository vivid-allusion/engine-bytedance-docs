# Problem description

User's bucket creation exceeds the limit.

<span id="3616764e"></span>
# Root cause

A user can create up to 100 buckets globally. Creating more buckets thereafter returns this error.

<span id="76b07535"></span>
# Example

None.

<span id="2e74f099"></span>
# Solution

Optimize bucket usage by avoiding creating many buckets for different business scenarios.
