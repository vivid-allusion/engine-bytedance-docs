# Problem description

CORS rule is invalid.

<span id="3616764e"></span>
# Root cause

When users set bucket CORS rules, the value of `AllowedMethods` in the CORS rule is not `PUT`,`GET`,`POST`,`HEAD`, or `DELETE`.

<span id="76b07535"></span>
# Example

The value of `AllowedMethods` in the CORS rule is invalid when you configure bucket CORS.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx

{
    "CORSRules":[{
        "AllowedOrigins":["http://www.example.com"],
        "AllowedMethods":["abc"],
        "AllowedHeaders":["*"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":1024}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors) and correctly construct the CORS rules to ensure the `AllowedMethods` values are valid.
