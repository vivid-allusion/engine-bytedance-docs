# Problem description

CORS rule is invalid.

<span id="3616764e"></span>
# Root cause

The user set an invalid value in the bucket CORS rule's `AllowedOrigins`, such as more than one asterisk (\*).

<span id="76b07535"></span>
# Example

When configuring the bucket CORS, the value of `AllowedOrigins` in the CORS rule is invalid.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx

{
    "CORSRules":[{
        "AllowedOrigins":["*.*"],
        "AllowedMethods":["PUT", "GET"],
        "AllowedHeaders":["Authorization"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":1024}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors) to correctly construct CORS rules and ensure the values of `AllowedOrigins` are valid.
