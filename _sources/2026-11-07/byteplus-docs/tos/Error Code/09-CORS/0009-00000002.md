# Problem description

Invalid CORS rule.

<span id="3616764e"></span>
# Root cause

When the user sets the bucket CORS rule, the rule is missing `AllowedOrigins`.

<span id="76b07535"></span>
# Example

When configuring the bucket CORS, the rule is missing `AllowedOrigins`.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx

{
    "CORSRules":[{
        "AllowedMethods":["PUT", "GET"],
        "AllowedHeaders":["Authorization"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":1024}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors). Properly construct the CORS rule and ensure `AllowedOrigins` is included.
