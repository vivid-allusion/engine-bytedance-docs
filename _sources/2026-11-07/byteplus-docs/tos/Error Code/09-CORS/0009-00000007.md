# Problem description

CORS rule is invalid.

<span id="3616764e"></span>
# Root cause

The user set the bucket CORS rule with `MaxAgeSeconds` less than 0 in the CORS rule.

<span id="76b07535"></span>
# Example

When configuring bucket CORS, the `MaxAgeSeconds` value in the CORS rule is less than 0.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string

{
    "CORSRules":[{
        "AllowedOrigins":["http://www.example.com"],
        "AllowedMethods":["PUT"],
        "AllowedHeaders":["*"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":-1}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors) to correctly construct the CORS rule and ensure the `MaxAgeSeconds` value is valid.
