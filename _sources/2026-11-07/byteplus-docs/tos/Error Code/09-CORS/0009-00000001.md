# Problem description

CORS rule format is invalid.

<span id="3616764e"></span>
# Root cause

The CORS rule structure in the request body is invalid when setting bucket CORS rules.

<span id="76b07535"></span>
# Example

The CORS rule structure in the request body is invalid when configuring bucket CORS.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors) for correctly constructing CORS rules.
