# Problem description

CORS rule does not exist.

<span id="3616764e"></span>
# Root cause

The user calls the GetBucketCORS interface to access a bucket, but the bucket has not configured CORS rules, resulting in this error.

<span id="76b07535"></span>
# Example

None.

<span id="7e307bcb"></span>
# Solution

Configure CORS rules on the bucket, then query again.
