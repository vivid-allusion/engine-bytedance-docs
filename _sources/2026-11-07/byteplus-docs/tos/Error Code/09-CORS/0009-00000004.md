# Problem description

CORS rule is invalid.

<span id="3616764e"></span>
# Root cause

When users set bucket CORS rules, the CORS rule lacks `AllowedMethods`.

<span id="76b07535"></span>
# Example

When configuring bucket CORS, the CORS rule lacks `AllowedMethods`.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string

{
    "CORSRules":[{
        "AllowedOrigins":["*"],
        "AllowedHeaders":["Authorization"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":1024}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors) to correctly construct CORS rules and ensure `AllowedMethods` is configured.
