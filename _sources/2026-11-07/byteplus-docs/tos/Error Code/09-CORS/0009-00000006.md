# Problem description

CORS rule is invalid.

<span id="3616764e"></span>
# Root cause

When setting bucket CORS rules, the user enters an invalid value for `AllowedHeaders`, such as using more than one asterisk (\*).

<span id="76b07535"></span>
# Example

You configured the bucket CORS with an invalid value for `AllowedHeaders`.

```Go
PUT /?cors HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string

{
    "CORSRules":[{
        "AllowedOrigins":["http://www.example.com"],
        "AllowedMethods":["PUT"],
        "AllowedHeaders":["*.*"],
        "ExposeHeaders":["x-tos-test"],
        "MaxAgeSeconds":1024}
    ]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketCORS](https://docs.byteplus.com/en/docs/tos/reference-putbucketcors). Construct the CORS rules correctly to ensure the `AllowedHeaders` value is valid.
