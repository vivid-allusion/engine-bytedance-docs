# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The Role field is empty when the user sets the bucket data replication rule.

<span id="76b07535"></span>
# Example

The Role field is empty when you configure the bucket data replication rule.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["prefix_1", "prefix_2"],
        "Destination":{
            "Bucket":"Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to correctly construct the bucket data replication rule and ensure the Role field is not empty.
