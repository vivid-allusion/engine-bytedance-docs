# Problem description

The bucket data replication rule is invalid.

<span id="3616764e"></span>
# Root cause

When the user sets the bucket data replication rule, the `Destination` configuration has an empty `Location` field.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, the `Destination` configuration has an empty `Location` field.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to correctly construct the bucket data replication rule, ensuring the `Location` field in the `Destination` configuration is not empty.
