# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The target bucket's region currently does not support data replication when the user sets the bucket data replication rule.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, the target bucket's region temporarily does not support data replication. For example, the target bucket is in the cn\-beijing region, which does not support data replication yet.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution

Use a target bucket in another region.
