# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

When setting bucket data replication rules, the `StorageClassInheritDirective` field value is neither `DESTINATION_BUCKET` nor `SOURCE_OBJECT`.

<span id="76b07535"></span>
# Example

When configuring bucket data replication rules, the `StorageClassInheritDirective` field has an invalid value.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "abc"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to properly construct bucket data replication rules, ensuring that the `StorageClassInheritDirective` field value is valid.
