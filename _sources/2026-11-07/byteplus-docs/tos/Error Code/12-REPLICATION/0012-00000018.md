# Problem description

Bucket data replication rule is invalid.

<span id="3616764e"></span>
# What it means

The user set the bucket data replication rule with the source bucket and target bucket being identical.

<span id="76b07535"></span>
# Example

You configured a replication rule for bucket bucketname with the target bucket still set to bucket bucketname.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket":"bucketname",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution 

Ensure the target bucket in the replication rule is different from the bucket accessed in this request.
