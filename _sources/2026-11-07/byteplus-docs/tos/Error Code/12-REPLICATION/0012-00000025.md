#  Problem description

The bucket replication rule does not exist.

<span id="9284e18b"></span>
# Root cause

The user accesses a bucket using the GetBucketReplication API, but the bucket has no replication rule configured, resulting in this error.

<span id="4b9d0d31"></span>
# Example

None.

<span id="e3316413"></span>
# Solution  

Configure the bucket replication rule, then query again.
