# Problem description

invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

when the user sets the bucket data replication rule, the length of the PrefixSet array exceeds 10.

<span id="76b07535"></span>
# Example

when configuring the bucket data replication rule, the length of the PrefixSet array exceeds 10.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": [...11 elements omitted here...],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution

refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to properly construct the bucket data replication rule and ensure the PrefixSet array length is less than 10.
