# Problem description

the specified bucket replication rule does not exist.

<span id="9284e18b"></span>
# Root cause

the user uses the GetBucketReplication API to access a bucket expecting a specific replication rule, but that rule does not exist, so this error is returned.

<span id="4b9d0d31"></span>
# Example

none.

<span id="e3316413"></span>
# Solution  

configure the specified data replication rule on the bucket, then query again.
