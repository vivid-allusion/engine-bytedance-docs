#  Problem description

Bucket data replication rule is invalid.

<span id="3616764e"></span>
# Root cause

The user sets a bucket data replication rule with the `Status` field value other than `Enabled` or `Disabled`.

<span id="76b07535"></span>
# Example

You set an invalid value in the `Status` field when configuring the bucket data replication rule.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled1",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket":"Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to correctly construct the bucket data replication rule and ensure the `Status` field value is valid.
