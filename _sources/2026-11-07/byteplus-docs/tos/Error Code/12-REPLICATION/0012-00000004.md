# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The user set more than 100 bucket data replication rules.

<span id="76b07535"></span>
# Example

You configured bucket data replication rules exceeding 100 entries.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[...101 rules omitted here...]
}
```


<span id="b28ad357"></span>
# Solution

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to correctly construct bucket data replication rules, ensuring the number of rules does not exceed 100.
