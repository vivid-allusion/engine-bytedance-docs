# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

When setting the bucket data replication rule, both the source and target buckets are in a suspended multi\-version state.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, both the source and target buckets are in a suspended multi\-version state.

<span id="3d1d0a0f"></span>
# Solution  

Ensure that the source and target buckets have consistent multi\-version states and are not in a suspended multi\-version state.
