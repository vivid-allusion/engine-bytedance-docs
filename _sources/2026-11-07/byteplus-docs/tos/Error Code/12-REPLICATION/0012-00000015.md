# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

When users set bucket data replication rules, the value of the `Bucket` field in the `Destination` configuration does not comply with bucket naming rules.

<span id="76b07535"></span>
# Example

When you configure bucket data replication rules, the value of the `Bucket` field in the `Destination` configuration does not meet bucket naming requirements.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "_abc",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to properly construct bucket data replication rules and ensure the value of the `Bucket` field in the `Destination` configuration is valid.
