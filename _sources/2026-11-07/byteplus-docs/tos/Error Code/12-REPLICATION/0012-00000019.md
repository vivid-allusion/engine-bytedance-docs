# Problem description

The bucket data replication rule is invalid.

<span id="3616764e"></span>
# Root cause

The target bucket in the replication rule set by the user does not exist.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, the target bucket specified in the rule does not exist.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "aaa",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Make sure the target bucket in the replication rule exists.
