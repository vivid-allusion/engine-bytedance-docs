# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

User lacks specific Rules configuration when setting bucket data replication rules.

<span id="76b07535"></span>
# Example

You miss the specific Rules configuration when configuring bucket data replication rules.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[]
}
```


<span id="b28ad357"></span>
# Solution

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to properly construct the bucket data replication rules.
