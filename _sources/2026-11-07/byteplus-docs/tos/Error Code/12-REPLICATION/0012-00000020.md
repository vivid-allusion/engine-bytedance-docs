# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The target bucket and target bucket region in the user's bucket data replication rule do not match.

<span id="76b07535"></span>
# Example

When configuring bucket data replication rules, the target bucket and target bucket region do not match. For example, the target bucket region is originally cn\-beijing, but the rule sets the target bucket region as cn\-guangzhou.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc"],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "cn-guangzhou",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the target bucket and target bucket region in the replication rule match.
