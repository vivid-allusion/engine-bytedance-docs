# Problem description

The bucket data replication rule structure is invalid.

<span id="3616764e"></span>
# Root cause

The configuration structure in the request body is invalid when the user sets the bucket data replication rule.

<span id="76b07535"></span>
# Example

The configuration structure in the request body is invalid when you configure the bucket data replication rule.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="b28ad357"></span>
# Solution

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to correctly construct the bucket data replication rule.
