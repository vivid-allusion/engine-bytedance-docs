# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

When setting the bucket data replication rule, the versioning status of the source and destination buckets is inconsistent.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, the versioning status of the source and destination buckets differs. For example, the source bucket has versioning enabled while the destination bucket does not.

<span id="6a290766"></span>
# Solution  

Ensure the versioning status of the source and destination buckets is consistent.
