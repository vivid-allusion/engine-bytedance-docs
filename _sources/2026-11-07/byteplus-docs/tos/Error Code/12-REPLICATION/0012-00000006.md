# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The rule ID field value is duplicated when the user sets the bucket data replication rule.

<span id="76b07535"></span>
# Example

Multiple rules have the same ID when configuring the bucket data replication rule.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization string
Content-Length: 120
Content-MD5: XrY7u+Ae7tCTyyK7j1rNww==
{
    "Role": "Your role",
    "Rules":[
    {
        "ID": "1",
        ...The remaining configurations are omitted here...
    },
    {
        "ID": "1",
        ...The remaining configurations are omitted here...
    }]
}
```


<span id="b28ad357"></span>
# Solution

See [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) for correctly constructing bucket data replication rules and ensuring the rule ID field value is unique.
