# Problem description

bucket data replication rule is invalid.

<span id="3616764e"></span>
# Root cause

when setting bucket data replication rules, multiple rules have the same destination bucket.

<span id="76b07535"></span>
# Example

when configuring bucket data replication rules, multiple rules have the same destination bucket.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[
    {
        ...The remaining configurations are omitted here....
        "Destination":{
            "Bucket":"abc"
            ...The remaining configurations are omitted here....
        }
    },
    {
        ...The remaining configurations are omitted here....
        "Destination":{
            "Bucket":"abc"
            ...The remaining configurations are omitted here....
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution  

refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) to properly construct bucket data replication rules and ensure that the destination buckets differ between rules.
