# Problem description

Invalid bucket data replication rule.

<span id="3616764e"></span>
# Root cause

The user set the bucket data replication rule with a rule ID value length exceeding 254.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rule, the rule ID value length exceeded 254.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "...255 characters omitted here...",
        "Status": "Enabled",
        "PrefixSet": ["prefix_1", "prefix_2"],
        "Destination":{
            "Bucket":"Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) and correctly construct the bucket data replication rule, ensuring the rule ID length is less than 255.
