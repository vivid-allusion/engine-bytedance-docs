#  Problem description

The bucket data replication rule is invalid.

<span id="3616764e"></span>
# Root cause

When the user sets the bucket data replication rule, the `PrefixSet` array elements have inclusion relationships.

<span id="76b07535"></span>
# Example

When configuring the bucket data replication rules, the `PrefixSet` array elements are `abc`, `abcd`, `abc` already includes `abcd`.

```Go
PUT /?replication HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
Authorization: authorization xxx
Content-Length: 120
Content-MD5: xxx
{
    "Role": "Your role",
    "Rules":[{
        "ID": "1",
        "Status": "Enabled",
        "PrefixSet": ["abc", "abcd"],
        "Destination":{
            "Bucket": "Target Bucket Name",
            "Location": "cn-beijing",
            "StorageClass": "STANDARD",
            "StorageClassInheritDirective": "DESTINATION_BUCKET"
        },
        "HistoricalObjectReplication": "Enabled"
    }]
}
```


<span id="b28ad357"></span>
# Solution  

Refer to [PutBucketReplication](https://docs.byteplus.com/en/docs/tos/Putbucketreplication) and correctly construct the bucket data replication rule, ensuring no inclusion relationship among `PrefixSet` array elements.
