# Problem description

Triggered bandwidth control for the bucket group.

<span id="93541ff5"></span>
# Root cause

The user's request traffic exceeded the bandwidth limit of the assigned bucket group.

<span id="145e1572"></span>
# Example

None.

<span id="23ff2f07"></span>
# Solution

Reduce the request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
