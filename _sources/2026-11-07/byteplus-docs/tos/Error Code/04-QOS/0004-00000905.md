# Problem description

QosPolicy QPS flow control.

<span id="5ad87364"></span>
# Root cause

User request volume exceeds QosPolicy flow control limits.

<span id="c3e9d5f8"></span>
# Example

None.

<span id="7a6d596f"></span>
# Solution

Reduce the request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
