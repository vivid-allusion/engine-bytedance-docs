# Problem description

MRAP requests exceed the Account\-level bandwidth flow control limit.

<span id="04b05c0a"></span>
# Root cause

User requests from Multi\-Region Access Points exceed the Account\-level bandwidth flow control limit.

<span id="837b585e"></span>
# Example

None.

<span id="869714fb"></span>
# Solution

Reduce the request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
