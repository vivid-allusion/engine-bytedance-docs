# Problem description

The transfer acceleration request exceeds the tenant bandwidth flow control limit.

<span id="5ad87364"></span>
# Root cause

The user’s transfer acceleration request exceeds the tenant bandwidth flow control limit.

<span id="c3e9d5f8"></span>
# Example

None.

<span id="7a6d596f"></span>
# Solution

Reduce the number of requests appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
