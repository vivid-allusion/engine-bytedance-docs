# Problem description

Triggered bucket group QPS flow control.

<span id="93541ff5"></span>
# Root cause

The user request traffic exceeded the QPS limit of the bucket group.

<span id="145e1572"></span>
# Example

None.

<span id="23ff2f07"></span>
# Solution

Reduce the request rate appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
