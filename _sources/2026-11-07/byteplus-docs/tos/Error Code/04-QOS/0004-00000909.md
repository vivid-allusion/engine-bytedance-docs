# Problem description

MRAP requests exceed alias\-level bandwidth throttling limits.

<span id="04b05c0a"></span>
# Root cause

User Multi\-Region Access Point requests exceed alias\-level bandwidth throttling limits.

<span id="837b585e"></span>
# Example

None.

<span id="869714fb"></span>
# Solution

Reduce request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
