# Problem description

QPS rate limiting for regular users.

<span id="3616764e"></span>
# Root cause

the request volume initiated by regular users exceeds the rate limit.

<span id="76b07535"></span>
# Example

none.

<span id="75acbc76"></span>
# Solution

reduce the request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
