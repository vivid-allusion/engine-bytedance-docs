# Problem description

TOS internal component (Modular) triggers QPS flow control.

<span id="e3d1a10d"></span>
# Root cause

Exceeds Modular flow control QPS limit.

<span id="199ba0c4"></span>
# Example

None.

<span id="30e2e66b"></span>
# Solution

Reduce the request volume appropriately or adjust the corresponding Modular flow control quota.
