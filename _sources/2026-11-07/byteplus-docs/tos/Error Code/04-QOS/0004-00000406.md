# Problem description

CRR requests exceed the source bucket's QPS rate limit.

<span id="3616764e"></span>
# Root cause

User's CRR requests exceed the source bucket's QPS limit.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Reduce the request rate appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
