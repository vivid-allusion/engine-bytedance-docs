# Problem description

public user public network bandwidth flow control.

<span id="3616764e"></span>
# Root cause

public users initiated requests from the public network with request traffic exceeding flow control limits.

<span id="76b07535"></span>
# Example

none.

<span id="75acbc76"></span>
# Solution

reduce requests appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
