# Problem description

Single\-machine flow control for mirror back\-to\-origin.

<span id="3616764e"></span>
# Root cause

User's back\-to\-origin request volume exceeds single\-machine flow control limits.

<span id="76b07535"></span>
# Example

None.

<span id="75acbc76"></span>
# Solution

Reduce request volume appropriately or [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000245) to contact technical support.
