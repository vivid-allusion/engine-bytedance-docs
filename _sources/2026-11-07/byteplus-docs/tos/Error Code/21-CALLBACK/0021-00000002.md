# Problem description

Failed to execute the upload callback request.

<span id="0a17e82c"></span>
# Root cause

Failed to execute the upload callback request.

<span id="075e4c9f"></span>
# Example

The Callback URL provided during object upload is unreachable.

```HTTP
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
x-tos-callback: xxx
Authorization: authorization_string
Content-Type: text/plain
Content-Length: 10

......
```


<span id="41bd95c9"></span>
# Solution

Callback failures can have multiple causes; first, check whether the specified callback server responds properly.
