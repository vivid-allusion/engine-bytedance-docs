# Problem description

The request carries an incorrectly formatted upload callback parameter.

<span id="0a17e82c"></span>
# Root cause

The request carries an incorrectly formatted upload callback parameter.

<span id="075e4c9f"></span>
# Example

The callback parameter `x-tos-callback` carried during object upload is not Base64 encoded.

```HTTP
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 +0000
x-tos-callback: xxx
Authorization: authorization_string
Content-Type: text/plain
Content-Length: 10

......
```


<span id="41bd95c9"></span>
# Solution

Use the correct parameter format for upload callbacks. For details, refer to [Upload Callback (Java SDK)](https://docs.byteplus.com/en/docs/tos/Upload-callback-java-sdk).
