# Problem description

The number of object tags exceeds the limit.

<span id="3616764e"></span>
# Root cause

The user set more than 10 tags on the object, causing the request error.

<span id="76b07535"></span>
# Example

None.

<span id="eb4ef436"></span>
# Solution

Make sure the number of tags on the object does not exceed 10.
