# Problem description

Invalid tag.

<span id="3616764e"></span>
# Root cause

When users set object tags using the x\-tos\-tagging header, the header value is invalid. For example, splitting each tag by an equal sign (=) results in an array length greater than 2.

<span id="76b07535"></span>
# Example

You initiated the following request:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: key1=a=b=c
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="eee483d4"></span>
# Solution

Ensure the x\-tos\-tagging header value is valid.
