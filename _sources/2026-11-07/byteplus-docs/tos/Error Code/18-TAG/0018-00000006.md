# Problem description

Tag key length exceeds 128.

<span id="3616764e"></span>
# Root cause

The tag key length exceeds 128 when users set tags on buckets or objects.

<span id="76b07535"></span>
# Example

None.

<span id="e66026da"></span>
# Solution

Ensure the tag key length does not exceed 128.
