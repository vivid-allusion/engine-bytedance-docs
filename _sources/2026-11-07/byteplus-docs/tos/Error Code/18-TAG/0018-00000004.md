# Problem description

The number of bucket tags exceeds the limit.

<span id="3616764e"></span>
# Root cause

The number of tags set by the user for the bucket exceeds 50, causing a request error.

<span id="76b07535"></span>
# Example

None.

<span id="46e8f647"></span>
# Solution 

Ensure the number of tags for the bucket does not exceed 50.
