# Problem description

Tag value encoding format is invalid.

<span id="3616764e"></span>
# Root cause

The user's tag value for the bucket or object does not comply with URL encoding format.

<span id="76b07535"></span>
# Example 

You initiated the following request:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: aa=bb%3
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="eee483d4"></span>
# Solution

Ensure the tag value encoding format is valid.
