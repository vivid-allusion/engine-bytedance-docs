# Problem description

The tag value contains illegal characters.

<span id="3616764e"></span>
# Root cause

The tag value contains illegal characters when the user sets tags for the bucket or object.

<span id="76b07535"></span>
# Example

You initiated the following request, in which the tag value contains an illegal character question mark (?).

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: a=?bb
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="e66026da"></span>
# Solution

Ensure the tag value is valid.
