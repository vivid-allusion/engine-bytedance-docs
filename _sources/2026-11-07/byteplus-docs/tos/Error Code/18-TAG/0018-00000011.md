# Problem description

Illegal value in `x-tos-tagging-directive` header field.

<span id="3616764e"></span>
# Root cause

The user initiated an object copy request, but the `x-tos-tagging-directive` header field value in the request was neither `Copy` nor `Replace`.

<span id="76b07535"></span>
# Example

You initiated the following request in which the `x-tos-tagging-directive` header field value is illegal.

```Go
PUT /DestObjectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:55:03 +0000
Authorization: authorization xxx
x-tos-copy-source: /sourcebucketname/SourceObjectName
x-tos-tagging-directive: ABC
```


<span id="e66026da"></span>
# Solution

Remove the `x-tos-tagging-directive` header field or ensure that its value is valid.
