# Problem description

Tag key contains invalid characters.

<span id="3616764e"></span>
# Root cause

When users set tags on buckets or objects, the tag key contains invalid characters.

<span id="76b07535"></span>
# Example

You issued a request where the tag key contains an invalid character: a question mark (?).

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: a?=bb
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="e66026da"></span>
# Solution

Ensure the tag key values are valid.
