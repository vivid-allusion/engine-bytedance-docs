# Problem description

duplicate tag key.

<span id="3616764e"></span>
# Root cause

the user sets duplicate tag keys when tagging a bucket or object.

<span id="76b07535"></span>
# Example

you initiated a request containing duplicate tag keys.

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: a=bb&a=cc
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="e66026da"></span>
# Solution

ensure tag keys are not duplicated.
