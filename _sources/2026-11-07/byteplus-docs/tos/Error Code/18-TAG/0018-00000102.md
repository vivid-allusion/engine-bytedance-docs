# Problem description

Illegal bucket tagging configuration.

<span id="3616764e"></span>
# Root cause

The user omitted specific tag configurations when setting bucket tags.

<span id="76b07535"></span>
# Example

You omitted specific tag configurations when applying bucket tagging.

```Go
PUT /?tagging HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Content-MD5: ContentMD5
Authorization: authorization xxx

{"TagSet": {"Tags": []}}
```


<span id="eb4ef436"></span>
# Solution

Refer to [PutBucketTagging](https://docs.byteplus.com/en/docs/tos/Putbuckettagging) to properly construct the bucket tagging configuration.
