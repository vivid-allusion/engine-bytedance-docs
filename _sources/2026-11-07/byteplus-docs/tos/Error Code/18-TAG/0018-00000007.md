# Problem description

Tag value length exceeds 256.

<span id="3616764e"></span>
# Root cause

The tag value length exceeds 256 when the user sets tags on the bucket or object.

<span id="76b07535"></span>
# Example

None.

<span id="e66026da"></span>
# Solution

Ensure the tag value length does not exceed 256.
