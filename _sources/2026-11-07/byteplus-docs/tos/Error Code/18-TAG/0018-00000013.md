# Problem description

Tag keys start with `volc:`

<span id="3616764e"></span>
# Root cause

When users set tags for buckets or objects, if the tag key starts with `volc:`, the request will fail because `volc:` is a system\-reserved key.

<span id="76b07535"></span>
# Example

None.

<span id="eb4ef436"></span>
# Solution

Ensure the tag key value is valid.
