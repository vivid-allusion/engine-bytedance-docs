# Problem description

Tag key encoding format is invalid.

<span id="3616764e"></span>
# Root cause

The tag key does not meet URL encoding format requirements when setting tags on buckets or objects.

<span id="76b07535"></span>
# Example

You submitted the following request:

```Go
PUT /objectName HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 08:05:36 GMT
x-tos-tagging: aa%3=a
Authorization: authorization xxx
Content-Length: 100

[100 Byte data content]
```


<span id="eee483d4"></span>
# Solution 

Ensure the tag key encoding format is valid.
