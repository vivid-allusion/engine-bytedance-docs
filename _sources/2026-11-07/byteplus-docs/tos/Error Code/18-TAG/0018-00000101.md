# Problem description

Bucket tag configuration structure is invalid.

<span id="3616764e"></span>
# Root cause

The configuration structure in the request body is invalid when the user sets bucket tags.

<span id="76b07535"></span>
# Example

The configuration structure in the request body is invalid when you configure bucket tags.

```Go
PUT /?tagging HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: GMT Date
Content-MD5: ContentMD5
Authorization: authorization xxx

...Random string...
```


<span id="eb4ef436"></span>
# Solution

Refer to [PutBucketTagging](https://docs.byteplus.com/en/docs/tos/Putbuckettagging) for properly constructing the bucket tag configuration.
