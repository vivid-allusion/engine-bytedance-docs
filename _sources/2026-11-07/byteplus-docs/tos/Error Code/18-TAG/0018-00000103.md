# Problem description

Bucket tag configuration does not exist.

<span id="3616764e"></span>
# Root cause

When a user calls the GetBucketTagging API on a bucket without configured tags, this error is returned.

<span id="67a2c38b"></span>
# Example

None.

<span id="b272db89"></span>
# Solution

Configure tags for the bucket, then query again.
