# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket mirror origin rules, the KeyPrefix value length in the Transform configuration exceeds 512.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, the KeyPrefix value length in the Transform configuration exceeds 512.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,  
            "KeyPrefix":"object-key-prefix",  
            "KeySuffix": "object-key-suffix"  
        },
        "Redirect":{
            "RedirectType": "Mirror",        
            "FetchSourceOnRedirect": false,
            "PublicSource":{      
                "SourceEndpoint":{ 
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery": true,     
            "FollowRedirect": true, 
            "MirrorHeader":{       
                "PassAll": true,
                "Pass": ["aaa", "bbb"],
                "Remove": ["xxx", "yyy"]
            },
            "Transform": { 
               "WithKeyPrefix": "addtional-key-prefix", 
               "WithKeySuffix": ".addtional-key-suffix",  
               "ReplaceKeyPrefix": { 
                  "KeyPrefix": "...513 characters omitted here...",
                  "ReplaceWith": "replace-with"
               }
            }
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the KeyPrefix value in the Transform configuration is valid.
