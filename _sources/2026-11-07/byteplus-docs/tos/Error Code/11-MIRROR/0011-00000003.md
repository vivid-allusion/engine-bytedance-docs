# Problem description

Invalid mirror back to origin configuration.

<span id="3616764e"></span>
# Root cause

The total number of bucket mirror back to origin rules set by the user exceeds 20.

<span id="76b07535"></span>
# Example

You configured bucket mirror back to origin rules with more than 20 entries.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[...21 rules omitted here...]
}
```


<span id="b28ad357"></span>
# Solution

Ensure that the number of mirror back to origin rules does not exceed 20.
