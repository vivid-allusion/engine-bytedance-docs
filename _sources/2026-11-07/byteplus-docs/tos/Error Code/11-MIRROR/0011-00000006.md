# Problem description

Illegal mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket mirror origin rules, the KeySuffix value length in the Condition configuration of a certain rule exceeds 512.

<span id="76b07535"></span>
# Example

You set an illegal KeySuffix value in the Condition configuration when configuring bucket mirror origin.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"xxx",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"...513 characters omitted..."
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the KeySuffix value in the Condition configuration is valid.
