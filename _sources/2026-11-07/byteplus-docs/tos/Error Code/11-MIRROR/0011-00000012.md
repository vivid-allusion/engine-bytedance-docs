# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When users set bucket mirror origin rules, the length of the Primary array in the Redirect configuration is not within the range [1, 5].

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, the length of the Primary array in the Redirect configuration is not within the range [1, 5].

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":[]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the length of the Primary array in the Redirect configuration is within the range [1, 5].
