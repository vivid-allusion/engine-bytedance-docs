# Problem description

Illegal mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When the user sets the bucket mirror origin rule, the length of the Remove array in the MirrorHeader configuration exceeds 64.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, the length of the Remove array in the MirrorHeader configuration exceeds 64.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"Remove":[...65 elements are omitted here...]}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the length of the Remove array in the MirrorHeader configuration does not exceed 64.
