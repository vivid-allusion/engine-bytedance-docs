# Problem description

Bucket mirror back configuration does not exist.

<span id="3616764e"></span>
# Root cause

The user accesses a bucket using the GetBucketMirrorBack interface, but if the bucket has no mirror back rule configured, this error is returned.

<span id="76b07535"></span>
# Example

None.

<span id="55f35746"></span>
# Solution

After configuring the bucket mirror back rule, query again.
