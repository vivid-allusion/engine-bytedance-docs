# Problem description

Illegal mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When users set bucket mirror origin rules, both the `FixedEndpoint` and `FetchSourceOnRedirect` fields are set to `true`, causing request errors.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, both the `FixedEndpoint` and `FetchSourceOnRedirect` fields are set to `true`.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404
        },
        "Redirect":{
            "FetchSourceOnRedirect": true,
            "PublicSource":{
                "FixedEndpoint": true,
                "SourceEndpoint":{ 
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery": true,     
            "MirrorHeader":{"PassAll": true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure that when the `FixedEndpoint` field is set to `true`, the `FetchSourceOnRedirect` field is set to `false`.
