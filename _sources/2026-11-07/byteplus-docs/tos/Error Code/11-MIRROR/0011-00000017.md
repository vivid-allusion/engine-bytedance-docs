# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When the user sets the bucket mirror origin rule, the elements in the Follower array of the Redirect configuration do not start with http:// or https://.

<span id="76b07535"></span>
# Example

When configuring the bucket mirror origin, the elements in the Follower array of the Redirect configuration do not start with http:// or https://.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["https://abc.com"],
                    "Follower":["abc.com"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the elements in the Follower array of the Redirect configuration are valid.
