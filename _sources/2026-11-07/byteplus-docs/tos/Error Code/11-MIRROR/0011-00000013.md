# Problem description

Illegal mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket mirror origin rule, the Primary array element in the Redirect configuration does not start with http:// or https://.

<span id="76b07535"></span>
# Example

You configured the bucket mirror origin, but the Primary array element in the Redirect configuration is invalid.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["abc.com"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the Primary array elements in the Redirect configuration are valid.
