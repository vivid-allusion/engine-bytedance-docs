# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket mirror origin rules, multiple rules use duplicate IDs.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, multiple rules use duplicate IDs.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        ...The rest of the configuration is omitted here...
    },
    {
        "ID":"1",
        ...The rest of the configuration is omitted here...
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure rule IDs are unique.
