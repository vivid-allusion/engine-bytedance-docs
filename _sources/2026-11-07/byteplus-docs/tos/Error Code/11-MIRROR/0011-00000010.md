# Problem description

mirror origin configuration is invalid.

<span id="3616764e"></span>
# Root cause

when users set bucket mirror origin rules, elements in the Pass array of the MirrorHeader configuration are invalid, such as those prefixed with `x-tos-` or values like `host`, `content-length`, `date`, `authorization`, `x-url-style`.

<span id="76b07535"></span>
# Example

you configured the bucket mirror origin, but the elements in the Pass array of the MirrorHeader configuration are invalid.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"Pass":["host"]}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

ensure all elements in the Pass array of the MirrorHeader configuration are valid.
