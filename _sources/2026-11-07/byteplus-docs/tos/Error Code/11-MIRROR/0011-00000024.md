# Problem description

Invalid image origin pull configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket image origin pull rule, the length of the ReplaceWith value in the Transform configuration exceeds 512.

<span id="76b07535"></span>
# Example

When configuring the bucket image origin pull, the length of the ReplaceWith value in the Transform configuration exceeds 512.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,  
            "KeyPrefix":"object-key-prefix",  
            "KeySuffix": "object-key-suffix"  
        },
        "Redirect":{
            "RedirectType": "Mirror",        
            "FetchSourceOnRedirect": false,
            "PublicSource":{      
                "SourceEndpoint":{ 
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery": true,     
            "FollowRedirect": true, 
            "MirrorHeader":{       
                "PassAll": true,
                "Pass": ["aaa", "bbb"],
                "Remove": ["xxx", "yyy"]
            },
            "Transform": { 
               "WithKeyPrefix": "addtional-key-prefix", 
               "WithKeySuffix": ".addtional-key-suffix",  
               "ReplaceKeyPrefix": { 
                  "KeyPrefix": "key-prefix",
                  "ReplaceWith": "...513 characters omitted here..."
               }
            }
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure that the ReplaceWith value in the Transform configuration is valid.
