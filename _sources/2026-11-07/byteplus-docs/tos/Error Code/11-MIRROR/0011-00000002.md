# Problem description

mirror back\-to\-origin configuration is invalid.

<span id="3616764e"></span>
# Root cause

when setting bucket mirror back\-to\-origin rules, specific Rules configuration is missing.

<span id="76b07535"></span>
# Example

when configuring bucket mirror back\-to\-origin, specific Rules configuration is missing.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[]
}
```


<span id="b28ad357"></span>
# Solution

refer to [PutBucketMirrorBack](https://docs.byteplus.com/en/docs/tos/Putbucketmirrorback) to properly construct bucket mirror back\-to\-origin rules.
