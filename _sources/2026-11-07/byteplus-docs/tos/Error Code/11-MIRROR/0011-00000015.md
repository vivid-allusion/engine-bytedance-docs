# Problem description

Illegal mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When the user sets a bucket mirror origin rule, the Primary array element's value length in the Redirect configuration exceeds 255.

<span id="76b07535"></span>
# Example

When configuring the bucket mirror origin, the Primary array element's value length in the Redirect configuration exceeds 255.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["https://abc..255 characters omitted here..com"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the Primary array elements in the Redirect configuration are valid.
