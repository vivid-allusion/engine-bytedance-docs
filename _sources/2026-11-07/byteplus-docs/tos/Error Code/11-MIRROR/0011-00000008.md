# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket mirror origin rules, the rule ID field contains an invalid value, such as not matching the regular expression `^[\\w-_]*$`.

<span id="76b07535"></span>
# Example

The rule ID field value is invalid during your bucket mirror origin configuration.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"@@",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the rule ID field value is valid.
