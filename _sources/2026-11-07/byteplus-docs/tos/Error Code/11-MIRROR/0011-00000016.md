# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket mirror origin rules, the length of the Follower array in the Redirect configuration exceeds 5.

<span id="76b07535"></span>
# Example

The length of the Follower array in the Redirect configuration exceeds 5 when you configure bucket mirror origin settings.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404,
            "KeySuffix":"object-key-prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["https://abc.com"],
                    "Follower":[...6 elements are omitted here...]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the Follower array length in the Redirect configuration does not exceed 5.
