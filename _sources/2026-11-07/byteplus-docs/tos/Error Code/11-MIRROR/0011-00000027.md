# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket mirror origin rule, the length of the FetchHeaderToMetaDataRules array in the Redirect configuration exceeds 10.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, the length of the FetchHeaderToMetaDataRules array in the Redirect configuration exceeds 10.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404
        },
        "Redirect":{
            "PublicSource":{      
                "SourceEndpoint":{ 
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery": true,     
            "MirrorHeader":{"PassAll": true},
            "FetchHeaderToMetaDataRules": [...11 elements are omitted here...]
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the length of the FetchHeaderToMetaDataRules array in the Redirect configuration is less than 10.
