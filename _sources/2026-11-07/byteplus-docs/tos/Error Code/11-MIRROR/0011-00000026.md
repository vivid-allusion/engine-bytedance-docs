# Problem description

Mirror origin configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting the bucket mirror origin rule, if the `FixedEndpoint` field is set to `true`, but the `RedirectType` field is not set to `Async`, it causes a request error.

<span id="76b07535"></span>
# Example

When configuring the bucket mirror origin, if the `FixedEndpoint` field is set to `true`, but the `RedirectType` field is not set to `Async`.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"1",
        "Condition":{
            "HttpCode":404
        },
        "Redirect":{
            "RedirectType": "Mirror",
            "PublicSource":{      
                "FixedEndpoint": true,
                "SourceEndpoint":{ 
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery": true,     
            "MirrorHeader":{"PassAll": true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Make sure that when the `FixedEndpoint` field is set to `true`, the `RedirectType` field is set to `Async`.
