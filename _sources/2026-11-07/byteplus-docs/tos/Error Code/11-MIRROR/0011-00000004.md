# Problem description

Invalid mirror origin configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket mirror origin rule, the Condition configuration for a rule has an `HttpCode` value that is not `404`.

<span id="76b07535"></span>
# Example

When configuring bucket mirror origin, the `HttpCode` value in Condition is set to an invalid value `403`.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{
    "Rules":[{
        "ID":"xxx",
        "Condition":{
            "HttpCode":403,
            "KeyPrefix":"prefix"
        },
        "Redirect":{
            "PublicSource":{
                "SourceEndpoint":{
                    "Primary":["http://abc.123/"]
                }
            },
            "PassQuery":true,
            "FollowRedirect":true,
            "MirrorHeader":{"PassAll":true}
        }
    }]
}
```


<span id="b28ad357"></span>
# Solution

Ensure the `HttpCode` value in Condition is `404`.
