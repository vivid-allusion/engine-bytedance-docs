# Problem description

illegal mirror back\-to\-origin configuration.

<span id="3616764e"></span>
# Root cause

the configuration structure in the request body is illegal when the user sets the bucket mirror back\-to\-origin rule.

<span id="76b07535"></span>
# Example

the configuration structure in the request body is illegal and does not meet the JSON format when you configure the bucket mirror back\-to\-origin.

```Go
PUT /?mirror HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="b28ad357"></span>
# Solution

construct the bucket mirror back\-to\-origin rule correctly. for details, see [PutBucketMirrorBack](https://docs.byteplus.com/en/docs/tos/Putbucketmirrorback).
