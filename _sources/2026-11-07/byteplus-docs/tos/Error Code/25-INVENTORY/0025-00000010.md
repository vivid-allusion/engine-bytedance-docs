# Problem description

When using GetBucketInventory or ListBucketInventory to view bucket inventory rules, the query returns no matching bucket inventory rules.

<span id="70e05290"></span>
# Root cause

There are no bucket inventory rules matching the query criteria.

<span id="1d3e5f0b"></span>
# Example

You didn't find any bucket inventory rules that meet the criteria when querying.

```JSON
GET /?inventory&id=Id HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Authorization: authorization string
```


<span id="4021cb4f"></span>
# Solution 

Check the query conditions and use the correct bucket inventory ID for querying.
