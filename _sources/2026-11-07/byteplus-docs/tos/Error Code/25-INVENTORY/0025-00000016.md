# Problem description

The number of created bucket inventory rules exceeds the maximum limit.

<span id="70e05290"></span>
# Root cause

The number of created bucket inventory rules exceeds the maximum limit.

<span id="1d3e5f0b"></span>
# Example

After exceeding the bucket inventory rule limit, you initiate the PutBucketInventory request again.

```HTML
PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint> 
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="4021cb4f"></span>
# Solution

Once the bucket inventory limit is exceeded, no more bucket inventory rules can be created. For detailed limit information, refer to [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/PutBucketInventory).
