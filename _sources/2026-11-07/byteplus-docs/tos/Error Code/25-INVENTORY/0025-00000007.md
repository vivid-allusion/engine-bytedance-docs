# Problem description

The bucket inventory rule format is invalid.

<span id="70e05290"></span>
# Root cause

The configuration structure in the request body is invalid when setting the bucket inventory rule.

<span id="1d3e5f0b"></span>
# Example

The rule format you set for the bucket inventory cannot be parsed.

```HTML
 PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
...Random string...
```


<span id="4021cb4f"></span>
# Solution

Fill in the bucket inventory rule according to the specification. For detailed format, see [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/PutBucketInventory).
