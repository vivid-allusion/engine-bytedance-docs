# Problem description

The bucket inventory rule being created overlaps with an existing bucket inventory rule in its filtering prefix.

<span id="70e05290"></span>
# Root cause

Bucket inventory rules cannot have overlapping filtering prefixes. The values of prefix matching in the filtering settings of the bucket inventory rule being created overlap with those of an existing rule.

<span id="1d3e5f0b"></span>
# Example

The first call to PutBucketInventory sets the prefix (`Prefix`) in the destination bucket settings (`Destination`) to `prefix1`.

```HTML
PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


The second call to PutBucketInventory sets the prefix (`Prefix`) in the destination bucket settings (`Destination`) to `prefix1/prefix2`.

```HTML
PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1/prefix2"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="4021cb4f"></span>
# Solution

Do not set bucket inventory rules with overlapping filtering prefixes. If necessary, delete the existing conflicting bucket inventory rule before creating a new one.
