# Problem description

When creating a bucket inventory rule, the source bucket and destination bucket are not in the same region.

<span id="70e05290"></span>
# Root cause

The source bucket and destination bucket in the bucket inventory rule are not in the same region.

<span id="1d3e5f0b"></span>
# Example

When creating a bucket inventory rule, the specified source bucket and destination bucket are not in the same region. For example, the source bucket belongs to cn\-beijing while the destination bucket belongs to cn\-shanghai.

```HTML
PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="4021cb4f"></span>
# Solution

Ensure that the source bucket and destination bucket in the bucket inventory rule are in the same region.
