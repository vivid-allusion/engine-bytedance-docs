# Problem description

Target bucket configuration is incorrect in the bucket inventory rule.

<span id="4fe7465e"></span>
# Root cause

When creating a bucket inventory rule, the target bucket's configuration does not comply with the rule. Possible reasons include:


* Target bucket name `RoBucket` is invalid.

* The target bucket's account ID `AccountId` is empty.

* The authorized role `Role` is empty.

* The output format `Format` is not set to `CSV`.


<span id="104cff06"></span>

# Solution


* The target bucket name `RoBucket` is set incorrectly. Please refer to the [Create Bucket](https://docs.byteplus.com/en/docs/tos/Create-bucket-c-sdk) naming rules to correctly fill in the bucket name.

* The output format `Format` currently only supports CSV.
