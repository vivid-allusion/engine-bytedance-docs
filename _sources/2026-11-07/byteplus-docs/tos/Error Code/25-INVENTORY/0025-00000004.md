# Problem description

The export schedule configuration in the bucket inventory rule is invalid.

<span id="70e05290"></span>
# Root cause

The export schedule of the inventory report was not set to `Daily` or `Weekly`, but to other parameter values.

<span id="1d3e5f0b"></span>
# Example 

When setting the bucket inventory rule, the export schedule (`Schedule`) of the inventory report was set to values other than `Daily` and `Weekly`.

```HTML
  PUT /?inventory&id=report1 HTTP/1.1
  Host: <Bucket name>.<TOS endpoint>
  Date: Mon, 31 Oct 2016 12:00:00 GMT
  Authorization: authorization string
  Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "TwoDays" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
   }
  }
```


<span id="4021cb4f"></span>
# Solution

Set the export schedule of the inventory report correctly. Currently, only `Daily` and `Weekly` are supported. For details, refer to [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/Create-bucket-c-sdk).
