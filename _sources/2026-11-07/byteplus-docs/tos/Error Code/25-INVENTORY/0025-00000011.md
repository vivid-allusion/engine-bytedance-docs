# Problem description

The `ContinuationToken` format included in the request to list bucket inventory rules is incorrect.

<span id="70e05290"></span>
# Root cause

The request to list bucket inventory rules contains an invalid `ContinuationToken` parameter.

<span id="1d3e5f0b"></span>
# Example 

When listing bucket inventory rules, you passed an invalid `ContinuationToken`.

```JSON
GET /?inventory&continuation-token=notValidToken HTTP/1.1
Host: <Bucket name>.<TOS endpoint> 
Authorization: authorization string
```


<span id="4021cb4f"></span>
# Solution

Please provide the correct `ContinuationToken`. For detailed specifications, refer to [ListBucketInventory](https://docs.byteplus.com/en/docs/tos/ListBucketInventory).
