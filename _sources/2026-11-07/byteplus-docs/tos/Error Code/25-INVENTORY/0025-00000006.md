# Problem description

The bucket inventory rule ID is invalid.

<span id="70e05290"></span>
# Root cause

The bucket inventory rule ID is set incorrectly. The bucket inventory rule ID must meet the following requirements:


* Length must be between 0 and 64 characters.

* Only lowercase letters a\-z, uppercase letters A\-Z, digits 0\-9, hyphens (\-), underscores (_), and periods (.) are allowed.

* The first and last characters must be lowercase letters a\-z, uppercase letters A\-Z, or digits 0\-9.


<span id="1d3e5f0b"></span>

# Solution

Enter the correct bucket inventory ID according to the specifications. For detailed format, refer to [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/PutBucketInventory).
