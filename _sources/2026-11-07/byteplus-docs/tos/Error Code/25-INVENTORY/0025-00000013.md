# Problem description

The target bucket is not in the current Region when creating a bucket inventory rule.

<span id="70e05290"></span>
# Root cause

The target bucket in the bucket inventory rule is not in the current Region.

<span id="1d3e5f0b"></span>
# Example

When creating a bucket inventory rule, the target bucket you specify is not in the current Region. For example, if the target bucket destination\-bucket is in cn\-shanghai, and you set the bucket rule in the cn\-beijing Region but select destination\-bucket as the target bucket.

```HTML
 PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
  Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="4021cb4f"></span>
# Solution

Select a bucket in the current Region as the target bucket.
