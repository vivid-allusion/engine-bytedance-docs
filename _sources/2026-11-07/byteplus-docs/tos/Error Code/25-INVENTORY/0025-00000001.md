# Problem description

The target bucket\-related configuration in the bucket inventory rule is empty.

<span id="4fe7465e"></span>
# Root cause

The target bucket\-related configuration is empty when creating the bucket inventory rule.

<span id="104cff06"></span>
# Example

You did not fill in the target bucket content (Destination) when setting the bucket inventory rule.

```HTML
PUT /?inventory&id=report1 HTTP/1.1
  Host: <Bucket name>.<TOS endpoint>
  Date: Mon, 31 Oct 2016 12:00:00 GMT
  Authorization: authorization string
  Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="9c931fb1"></span>
# Solution  

Please correctly set the bucket inventory rule. For details, see [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/PutBucketInventory).
