# Problem description

Invalid object version configuration in bucket inventory rule.

<span id="70e05290"></span>
# Root cause

The object version is not set to `All` and `Current`, but to other parameter values.

<span id="1d3e5f0b"></span>
# Example

When setting the bucket inventory rule, the object version is not set to `All` and `Current` but to other parameter values.

```HTML
 PUT /?inventory&id=report1 HTTP/1.1
 Host: <Bucket name>.<TOS endpoint>
 Date: Mon, 31 Oct 2016 12:00:00 GMT
 Authorization: authorization string
 Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "AllObject",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
 }
```


<span id="4021cb4f"></span>
# Solution

Set the exported object version correctly. Currently, only `All` and `Current` are supported. For details, see [PutBucketInventory](https://docs.byteplus.com/en/docs/tos/PutBucketInventory).
