# Problem description

The inventory report prefix for the target bucket in the bucket inventory rule cannot end with a forward slash (/).

<span id="4fe7465e"></span>
# Root cause

When creating a bucket inventory rule, the inventory report prefix for the target bucket ends with a forward slash (/).

<span id="104cff06"></span>
# Example

When setting the bucket inventory rule, the inventory report prefix (Prefix) of the target bucket (Destination) ends with a forward slash (/).

```HTML
  PUT /?inventory&id=report1 HTTP/1.1
  Host: <Bucket name>.<TOS endpoint>
  Date: Mon, 31 Oct 2016 12:00:00 GMT
  Authorization: authorization string
  Content-Length: length
{
  "InventoryConfiguration": {
    "Id": "id",
    "IsEnabled": "true",
    "Filter": {
      "Prefix": "prefix"
    },
    "Destination": {
      "TOSBucketDestination": {
        "Format": "CSV",
        "AccountId": "2000000000000000", 
        "Role": "TosArchiveTOSInventory",
        "Bucket": "destination-bucket",
        "Prefix": "/prefix1"
      }
    },
    "Schedule": { "Frequency": "Daily" },
    "IncludedObjectVersions": "All",
    "OptionalFields": {
      "Field": [
        "Size",
        "LastModifiedDate",
        "ETag",
        "StorageClass",
        "IsMultipartUploaded",
        "EncryptionStatus",
        "CRC64",
        "ReplicationStatus"
      ]
    }
  }
}
```


<span id="9c931fb1"></span>
# Solution 

Set the target bucket inventory report prefix correctly by removing the preceding forward slash from the prefix.
