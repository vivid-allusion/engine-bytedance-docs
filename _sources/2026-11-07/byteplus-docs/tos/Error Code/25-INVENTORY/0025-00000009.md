# Problem description

When querying or deleting bucket inventory rules by bucket inventory, the `id` parameter in the Query is empty.

<span id="70e05290"></span>
# Root cause

This error occurs in the following two cases:


* When using the GetBucketInventory API to query bucket inventory rules, the `id` is empty, causing the error.

* When using the PutBucketInventory API to create bucket inventory rules, the `id` is empty, causing the error.


<span id="1d3e5f0b"></span>
# Example


* When querying bucket inventory rules, the passed `id` is empty.

   ```JSON
   GET /?inventory&id= HTTP/1.1
   Host: <Bucket name>.<TOS endpoint>
   Authorization: authorization string
   ```
   

* When deleting bucket inventory rules, the passed `id` is empty.

   ```JSON
   DELETE /?inventory&id= HTTP/1.1
   Host: <Bucket name>.<TOS endpoint>
   Authorization: authorization string
   ```
   


<span id="4021cb4f"></span>
# Solution

Fill in the bucket inventory rules according to the specification. For the specific format, refer to [GetBucketInventory](https://docs.byteplus.com/en/docs/tos/GetBucketInventory) and [DeleteBucketInventory](https://docs.byteplus.com/en/docs/tos/DeleteBucketInventory).
