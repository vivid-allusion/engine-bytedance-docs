# Problem description

ACL configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set bucket or object ACLs, if the `Type` field is set to `Group`, the `Canned` field must be set to either `AllUsers` or `AuthenticatedUsers`.

<span id="76b07535"></span>
# Example

When you configure the bucket ACL, if the `Type` field is set to `Group`, the `Canned` field is invalid.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "Group",
          "Canned": "abc"
        },
        "Permission": "FULL_CONTROL"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to properly construct the ACL configuration. Ensure that when the `Type` field is set to `Group`, the `Canned` field has a valid value.
