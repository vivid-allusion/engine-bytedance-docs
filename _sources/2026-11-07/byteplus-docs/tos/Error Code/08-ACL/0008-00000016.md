# Problem description

Invalid value format in x\-tos\-grant\-\* header field.

<span id="3616764e"></span>
# Root cause

When the user sets bucket or object ACL, the x\-tos\-grant\-\* header value split by the equal sign (=) does not result in an array of length 2.

<span id="76b07535"></span>
# Example

Your x\-tos\-grant\-\* header value is invalid when configuring bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-grant-read: canned=everyone=all
```


<span id="2e74f099"></span>
# Solution

Ensure the x\-tos\-grant\-\* header value format is valid.
