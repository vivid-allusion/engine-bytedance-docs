# Problem description

Invalid ACL configuration structure.

<span id="3616764e"></span>
# Root cause

The ACL configuration structure in the request body is invalid when the user sets the bucket or object ACL.

<span id="76b07535"></span>
# Example

The ACL configuration structure in the request body is invalid when you configure the bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

...Random string...
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to construct the ACL configuration correctly.
