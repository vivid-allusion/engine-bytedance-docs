# Problem description 

The request forbids carrying both x\-tos\-acl and x\-tos\-grant\-\* headers simultaneously.

<span id="3616764e"></span>
# Root cause

The user includes both x\-tos\-acl and x\-tos\-grant\-\* headers in the request when setting bucket or object ACL.

<span id="76b07535"></span>
# Example

When configuring bucket ACL, the request includes both x\-tos\-acl and x\-tos\-grant\-\* headers simultaneously.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-acl: public-read
x-tos-grant-read: canned=everyone
```


<span id="2e74f099"></span>
# Solution

When sending the request, choose either x\-tos\-acl or x\-tos\-grant\-\* header.
