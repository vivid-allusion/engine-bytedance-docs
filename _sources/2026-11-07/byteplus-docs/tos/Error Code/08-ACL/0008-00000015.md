# Problem description

Invalid value in the x\-tos\-acl header.

<span id="3616764e"></span>
# Root cause

The x\-tos\-acl header contains an invalid value when users set the bucket or object ACL using this header. The valid values for this header are as follows:


* private

* public\-read

* public\-read\-write

* authenticated\-read

* bucket\-owner\-read

* bucket\-owner\-full\-control

* bucket\-owner\-entrusted

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Only object ACL supports bucket\-owner\-entrusted.   </div>
   

<span id="76b07535"></span>
# Example

The x\-tos\-acl header contains an invalid value when configuring bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-acl: abc
```


<span id="2e74f099"></span>
# Solution

Ensure the x\-tos\-acl header has a valid value.
