# Problem description

The x\-tos\-grant\-\* header contains an invalid value.

<span id="3616764e"></span>
# Root cause

The x\-tos\-grant\-\* header contains an invalid value when the user sets the bucket or object ACL. Valid values are as follows:


* canned=AllUsers

* canned=AuthenticatedUsers

* id=xxx, where xxx is the account ID


<span id="76b07535"></span>
# Example

The x\-tos\-grant\-\* header contains illegal values when configuring the bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-grant-read: canned=aaa
```


<span id="2e74f099"></span>
# Solution

Make sure the x\-tos\-grant\-\* header contains valid values.
