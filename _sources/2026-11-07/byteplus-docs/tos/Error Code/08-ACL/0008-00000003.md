# Problem description

The request forbids carrying both ACL headers (x\-tos\-acl, x\-tos\-grant\-\*) and body simultaneously.

<span id="3616764e"></span>
# Root cause

The user sets bucket or object ACL while the request contains both ACL headers and body.

<span id="76b07535"></span>
# Example

When configuring bucket ACL, the request includes both ACL headers and body.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-acl: public-read
<acl body>
```


<span id="2e74f099"></span>
# Solution

When sending the request, choose either ACL headers or body, not both.
