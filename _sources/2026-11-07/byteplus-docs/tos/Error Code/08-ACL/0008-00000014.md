# Problem description

When setting the bucket ACL, the value of `x-tos-acl` is invalid.

<span id="3616764e"></span>
# Root cause

The user sets the bucket ACL using the `x-tos-acl` header with the value `bucket-owner-entrusted`. However, the bucket ACL does not support this setting, causing the request to fail.

<span id="76b07535"></span>
# Example

When configuring the bucket ACL, the `x-tos-acl` header value is set to `bucket-owner-entrusted`.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
x-tos-acl: bucket-owner-entrusted
```


<span id="2e74f099"></span>
# Solution

Change the `x-tos-acl` header value to one of the following: `private`, `public-read`, `public-read-write`, or `authenticated-read`.
