# Problem description

Invalid bucket ACL configuration.

<span id="3616764e"></span>
# Root cause

When setting the bucket ACL, the `BucketOwnerEntrusted` field is set to `true`. However, the bucket ACL does not support this setting, causing the request to fail.

<span id="76b07535"></span>
# Example

Your bucket ACL configuration sets the `BucketOwnerEntrusted` field to `true`.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "BucketOwnerEntrusted": true
}
```


<span id="2e74f099"></span>
# Solution

Remove the `BucketOwnerEntrusted` field from the bucket ACL configuration.
