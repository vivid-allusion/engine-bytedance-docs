# Problem description

Invalid ACL configuration.

<span id="3616764e"></span>
# Root cause

When users set bucket or object ACLs, if the `Type` field is set to `CanonicalUser`, the `ID` field is empty.

<span id="76b07535"></span>
# Example

When you configure the bucket ACL, if the `Type` field is set to `CanonicalUser`, the `ID` field is empty.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "CanonicalUser",
          "ID": ""
        },
        "Permission": "FULL_CONTROL"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to correctly configure the ACL. Ensure the `Type` field is `CanonicalUser` and the `ID` field is not empty.
