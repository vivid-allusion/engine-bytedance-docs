# Problem description

Invalid ACL configuration.

<span id="3616764e"></span>
# Root cause

The user set an invalid value for the `Permission` field when configuring bucket or object ACL. The valid values are as follows:


* READ

* WRITE

* READ_ACP

* WRITE_ACP

* FULL_CONTROL


<span id="76b07535"></span>
# Example

The `Permission` field contains an invalid value when configuring the bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "CanonicalUser",
          "ID": "test-cid"
        },
        "Permission": "abc"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to properly construct the ACL configuration and ensure the `Permission` field is valid.
