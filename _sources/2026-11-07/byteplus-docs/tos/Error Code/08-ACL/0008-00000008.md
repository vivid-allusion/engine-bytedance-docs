# Problem description

ACL configuration is invalid.

<span id="3616764e"></span>
# Root cause

When setting the bucket or object ACL, the ACL configuration lacks the Grantee entry.

<span id="76b07535"></span>
# Example

You omitted the Grantee entry when configuring the bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Permission": "FULL_CONTROL"
    }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl), correctly construct the ACL configuration, and ensure the Grantee entry is included.
