# Problem description

The request lacks both ACL headers (x\-tos\-acl, x\-tos\-grant\-\*) and body.

<span id="3616764e"></span>
# Root cause

When users set bucket or object ACLs, the request does not include ACL headers or body.

<span id="76b07535"></span>
# Example

You configured the bucket ACL but the request contains neither ACL headers nor body.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx
```


<span id="2e74f099"></span>
# Solution

When sending a request, you must set either ACL headers or body.
