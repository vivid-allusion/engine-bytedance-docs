# Problem description

ACL configuration is invalid.

<span id="3616764e"></span>
# Root cause

When users set bucket or object ACL, the ACL lacks Owner or Grants configuration.

<span id="76b07535"></span>
# Example

When you configure ACL, the ACL in the request body does not include the Owner configuration.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Grants": [{
        "Grantee": {
          "Type": "CanonicalUser",
          "ID": "test-cid"
        },
        "Permission": "FULL_CONTROL"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to properly construct the ACL configuration.
