# Problem description

invalid ACL configuration.

<span id="3616764e"></span>
# Root cause

when setting the bucket or object ACL, the length of the Grants array in the ACL configuration exceeds 100.

<span id="76b07535"></span>
# Example

when configuring bucket ACL, the length of the Grants array exceeds 100.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "CanonicalUser",
          "ID": "test-cid"
        },
        "Permission": "FULL_CONTROL"
      }...Omit the remaining 100 elements...]
}
```


<span id="2e74f099"></span>
# Solution

construct the ACL configuration correctly and ensure the Grants array length does not exceed 100.
