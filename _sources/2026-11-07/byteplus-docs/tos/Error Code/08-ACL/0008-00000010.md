# Problem description

Invalid ACL configuration.

<span id="3616764e"></span>
# Root cause

When setting bucket or object ACL, the `Type` field value is not one of `CanonicalUser` or `Group`.

<span id="76b07535"></span>
# Example

The Type field value is invalid when configuring the bucket ACL.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "abc",
          "ID": "test-cid"
        },
        "Permission": "FULL_CONTROL"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to correctly construct the ACL configuration and ensure the `Type` field value is valid.
