# Problem description

Invalid ACL configuration.

<span id="3616764e"></span>
# Root cause

When users set the bucket or object ACL, if the `Type` field value is `CanonicalUser`, the `Canned` field must be empty.

<span id="76b07535"></span>
# Example

When you configure the bucket ACL, if the `Type` field value is `CanonicalUser`, the `Canned` field must be empty.

```Go
PUT /?acl HTTP/1.1
Host: <Bucket name>.<TOS endpoint>
Date: Fri, 30 Jul 2021 13:59:18 GMT
Authorization: authorization xxx

{   
    "Owner": { "ID": "test-cid" },
    "Grants": [{
        "Grantee": {
          "Type": "CanonicalUser",
          "ID": "test-cid",
          "Canned": "AllUsers"
        },
        "Permission": "FULL_CONTROL"
      }]
}
```


<span id="2e74f099"></span>
# Solution

Refer to [PutBucketACL](https://docs.byteplus.com/en/docs/tos/reference-putbucketacl) or [PutObjectACL](https://docs.byteplus.com/en/docs/tos/reference-putobjectacl) to correctly construct the ACL configuration, ensuring the `Type` field is set to `CanonicalUser` and the `Canned` field is empty.
