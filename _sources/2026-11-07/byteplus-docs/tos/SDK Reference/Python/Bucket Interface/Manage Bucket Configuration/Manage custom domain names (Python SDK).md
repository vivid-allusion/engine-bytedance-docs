After you upload a file to TOS, you can access or download it using the file URL automatically generated by TOS. If you want to use your own domain name to access files stored in TOS, you can bind your own domain name to the bucket. After binding, the file can be accessed using the corresponding domain name.

## Set up custom domain rules

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">A domain name can only be bound to one bucket.</div>


* <div data-tips="true" data-tips-type="warning">A single bucket can bind up to 20 domain names.</div>



<span id=".56S65L6L5Luj56CB"></span>
### **Sample code**

The following code sets custom domain rules for `bucket-test`.

```python
import os
import tos

from tos.models2 import CustomDomainRule

# Retrieve AKSK information from environment variables.
ak = os.getenv('TOS_ACCESS_KEY')
sk = os.getenv('TOS_SECRET_KEY')
endpoint = "your endpoint"
region = "your region"
bucket_name = "bucket-test"
try:
    # Create a TosClientV2 object to perform operations on buckets and objects.
    client = tos.TosClientV2(ak, sk, endpoint, region)
    domain = CustomDomainRule(domain='example1.test.com')
    client.put_bucket_custom_domain(bucket_name, domain)
except tos.exceptions.TosClientError as e:
    # Operation failed, catch client error, usually caused by invalid request parameters or network issues
    print('fail with client error, message:{}, cause: {}'.format(e.message, e.cause))
except tos.exceptions.TosServerError as e:
    # Operation failed, catch server error, detailed error information can be obtained from the response
    print('fail with server error, code: {}'.format(e.code))
    # request id can be used to locate specific issues, it is strongly recommended to save it in the log.
    print('error with request id: {}'.format(e.request_id))
    print('error with message: {}'.format(e.message))
    print('error with http code: {}'.format(e.status_code))
    print('error with ec: {}'.format(e.ec))
    print('error with request url: {}'.format(e.request_url))
except Exception as e:
    print('fail with unknown error: {}'.format(e))
```

## List custom domain name rules

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">To enumerate custom domain name rules for buckets, you must be the bucket owner by default.</div>


<span id=".56S65L6L5Luj56CB"></span>
### **Sample code**

The following code enumerates custom domain rules for `bucket examplebucket`.

import os
import tos

# Retrieve AKSK information from environment variables.
ak = os.getenv('TOS_ACCESS_KEY')

endpoint = "your endpoint"
region = "your region"
bucket_name = "bucket-test"
try:
    # Create a TosClientV2 object to perform operations on buckets and objects.
    client = tos.TosClientV2(ak, sk, endpoint, region)
    out = client.list_bucket_custom_domain(bucket_name)
    for rule in out.rules:
        print(rule.domain)
