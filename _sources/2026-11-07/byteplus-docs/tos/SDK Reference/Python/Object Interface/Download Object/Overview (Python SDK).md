The TOS Python SDK supports downloading objects through standard download or range download, etc. You can choose the appropriate download method according to your business needs and the scenarios applicable to different methods.

<span id=".5LiL6L295pa55byP6K-05piO"></span>
## Download methods


* [Standard Download (Python SDK)](https://docs.byteplus.com/docs/tos/Normal-download-python-sdk): It is generally used to download small objects.

* [Conditional Download (Python SDK)](https://docs.byteplus.com/docs/tos/Limited-download-python-sdk): If the condition is met, it will be downloaded. If it is not met, an exception will be thrown and the download behavior will not be triggered.

* [Range Download (Python SDK)](https://docs.byteplus.com/docs/tos/Scope-download-python-sdk): When you only need to download a portion of an object's data, you can use range download.

* [Resumable Download (Python SDK)](https://docs.byteplus.com/docs/tos/Breakpoint-resume-download-python-sdk): When downloading large objects, you can use resumable download.
