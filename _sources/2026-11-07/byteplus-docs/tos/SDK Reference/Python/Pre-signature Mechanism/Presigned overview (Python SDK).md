you can add signature information to query parameters in a URL. such a URL carries information such as the AK, validity period, target resource, operation, and signature. anyone who uses the URL can perform the indicated operation within the validity period. this method is called presigning.


* [standard presigning](https://docs.byteplus.com/docs/tos/Normal-pre-signature-python-sdk): you can use the SDK to generate presigned links to access TOS services.

* [post form presigning](https://docs.byteplus.com/docs/tos/Post-form-pre-signature-python-sdk): TOS supports browser\-based POST upload requests, allowing you to upload content directly to TOS using Post form presigned parameters generated by the SDK.
