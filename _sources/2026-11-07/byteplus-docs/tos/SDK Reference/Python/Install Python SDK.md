This article introduces the download links and installation methods for the TOS Python SDK.

<span id=".546v5aKD5YeG5aSH"></span>
## Environment preparation

TOS Python SDK supports Python versions 3.5, 3.6, 3.7, 3.8, and above.

<span id=".5LiL6L295Zyw5Z2A"></span>
## Download links


* Latest source code: [source code](https://github.com/volcengine/ve-tos-python-sdk)

* Version revision history: [revision history](https://github.com/volcengine/ve-tos-python-sdk/blob/main/CHANGELOG.rst)

* Historical versions: [historical versions](https://pypi.org/project/tos/#history)


<span id=".5a6J6KOF5pa55byP"></span>
## Installation methods

TOS Python SDK currently supports installation via pip and source code.

<span id=".6YCa6L-HLXBpcC3lronoo4U="></span>
### Install via pip

Run the following command.

```bash
pip install tos
```


<span id=".6YCa6L-H5rqQ56CB5a6J6KOF"></span>
### Install from source

Download the corresponding version of the SDK package from [Github](https://github.com/volcengine/ve-tos-python-sdk). After extracting, enter the directory and run the following command.

```bash
python3 setup.py install
```
