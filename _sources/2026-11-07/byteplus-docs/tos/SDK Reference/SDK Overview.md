This article describes the BytePlus object storage TOS supported SDK and its description.

<span id="sdk-信息"></span>
## SDK information


* **SDK name** : Object Storage SDK

* **SDK developer** : Beijing BytePlus Technology Co., Ltd

* **Main functions** : Provide massive, secure, low\-cost, easy\-to\-use, highly reliable, and highly available distributed cloud storage services, and provide SDKs in multiple mainstream languages to greatly improve your development efficiency.


<span id="前提条件"></span>
## Prerequisite


1. Registered BytePlus account and completed real\-name authentication. For specific steps, please refer to [Sign Up and Verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account)

2. TOS service has been opened, please refer to the specific steps [Quick Start](https://docs.byteplus.com/docs/tos/docs-quick-start_1)。

3. The AccessKey of the account has been obtained. For specific steps, see [Obtaining AccessKey ](https://docs.byteplus.com/en/docs/byteplus-platform/docs-managing-an-accesskey).
