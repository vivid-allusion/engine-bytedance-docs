This article provides an overview of the environment, download link, and installation procedure for the TOS .NET SDK.

<span id=".546v5aKD5YeG5aSH"></span>
## Environmental Preparation

This document is prepared based on TOS .NET SDK 2.1.8. The environment requirements are as follows:


* Windows

   * Applicable to .NET Framework version 2.0 and above.

   * Applicable to .NET Core 2.0 and later versions.

   * Applicable to Visual Studio 2019 and later versions

* Linux/macOS

   Applicable to Mono version 6.12 and above


You can download .NET Framework and other content from the [.NET official website](https://dotnet.microsoft.com/zh-cn/download). After completing the installation, you can use the following command to view .NET version information.

```C#
dotnet --info
```

## Installation Method

<span id=".5ZyoLXdpbmRvd3Mt546v5aKD5a6J6KOF"></span>
### Installation in the Windows Environment

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This document uses Visual Studio as the integrated development environment (IDE). To compile this project, Visual Studio 2019 or later is recommended.</div>



* **Installation via NuGet**

   1. Install [Nuget](https://learn.microsoft.com/zh-cn/nuget/install-nuget-client-tools).

   2. In Visual Studio, open or create a project, then select **Tools \> NuGet Package Manager \> Manage NuGet Packages for Solution**.

   3. Search for and install a NuGet package:

      1. .Net Core 5.0 and later versions are recommended: search for BytePlus .TOS.SDK.NetCore, locate BytePlus .TOS.SDK.NetCore in the results, select the latest version, and click **Install**.

      2. Other versions: Search for BytePlus .TOS.SDK, locate BytePlus .TOS.SDK in the results, select the latest version, and click **Install**.

* **Installation via DLL reference**

   1. Download the latest version of the TOS .NET SDK project code from Github.

   2. In the TOS .NET SDK codebase, both the .NET Framework and .NET Core versions share a single set of code, with projects selected for compilation as required.

      * The project compiled for the .NET Framework version: `TOS/TOS.csproj`.

      * Compile `TOSNetCore/TOSNetCore.csproj` using .Net Core versions earlier than 5.0.

      * Compile `TOSNetCore/TOSNetCoreNew.csproj` using .Net Core 5.0 or later.

   3. Select the Release configuration, compile the ve\-tos\-dotnet\-sdk project, and generate the DLL.

   4. Open or create a project in Visual Studio, select your project, right\-click the project, then choose **References \> Add Reference**. In the dialog box that appears, select **Browse**.

   5. Locate the file `Volcengine.TOS.dll` in the `bin` directory generated by the steps above, and click **OK**.

* **Installation via project reference**

   1. Download the latest version of the TOS .NET SDK project code from GitHub.

   2. In Visual Studio, open or create a project, right\-click **Solution**, and click **Add Existing Project**.

   3. In the TOS .NET SDK codebase, the .NET Framework and .NET Core versions share a unified codebase, allowing users to select the appropriate project as needed.

      * For the .NET Framework version, select the `TOS.csproj` file in the dialog box that appears, then click **Open**.

      * For .Net Core versions below 5.0, in the pop\-up dialog box, select the `TOSNetCore.csproj` file and click **Open**.

      * For .Net Core 5.0 and later versions, select the `TOSNetCoreNew.csproj` file in the pop\-up dialog box and click **Open**.

   4. Open or create a project in Visual Studio, select your project, right\-click the project, and choose **References \> Add Reference**. In the dialog box that appears, select the **Projects tab**, check the project opened in the previous step, and click **OK**.

### Installation in Linux/macOS Environments


1. Install [Nuget](https://learn.microsoft.com/zh-cn/nuget/install-nuget-client-tools).

2. In Xamarin, create a new project or open an existing one, then select the tool **Add NuGet Packages**.

3. Search for and install the NuGet Package:

   1. .Net Core 5.0 and later versions are recommended: Search for BytePlus .TOS.SDK.NetCore, locate BytePlus .TOS.SDK.NetCore in the results, select the latest version, and click **Install**.

   2. Other versions: Search for BytePlus .TOS.SDK, locate BytePlus .TOS.SDK in the results, select the latest version, and click **Install**.
