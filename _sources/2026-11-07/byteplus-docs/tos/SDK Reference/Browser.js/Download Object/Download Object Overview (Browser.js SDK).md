The TOS Browser SDK supports various methods for downloading objects, including direct download, range download, and others. You can choose the most appropriate download method based on your business requirements and the specific scenarios in which each method is applicable.

<span id=".5LiL6L295pa55byP6K-05piO"></span>
## Download Instructions


* [Standard Download](https://docs.byteplus.com/docs/tos/Normal-download-browser-js-sdk): Directly download the entire object from the specified bucket.

* [Conditional Download](https://docs.byteplus.com/docs/tos/Limited-download-browser-js-sdk): The download will proceed only if the specified conditions are met; otherwise, an exception will be thrown and the download action will not be triggered.

* [Range Download](https://docs.byteplus.com/docs/tos/Scope-download-browser-js-sdk): If you do not need to download the entire object and only require part of the information within the object, you can use range download to download data within the specified range.
