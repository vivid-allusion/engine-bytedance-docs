You can add signature information to query parameters in a URL. This URL contains information such as AK, validity period, resource, operation, and signature. Anyone who uses this URL within the validity period can perform the operation associated with the URL. This method is called presigning.


* [Standard Pre-signed Link](https://docs.byteplus.com/docs/tos/Normal-pre-signature-browser-js-sdk): You can access TOS services by generating a pre\-signed link using the Browser SDK.

* [POST Form Presigning](https://docs.byteplus.com/docs/tos/Post-form-pre-signature-browser-js-sdk): TOS supports browser\-based POST object upload requests, allowing you to upload content directly to TOS. You can use the POST form presigning parameters generated by the Browser SDK.
