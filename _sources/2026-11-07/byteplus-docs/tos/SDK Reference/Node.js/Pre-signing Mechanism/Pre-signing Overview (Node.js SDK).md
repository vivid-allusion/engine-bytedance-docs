You can add signature information to the query parameters of a URL. The URL contains the access key (AK), the validity period, the resource, the operation, the signature, and other information. Anyone with the URL can perform the corresponding operation within the validity period. This method is called pre\-signing.


* [Pre-signed URL](https://docs.byteplus.com/docs/tos/Normal-pre-signature-node-js-sdk): You can access the TOS service by generating a pre\-signed URL using the Node.js SDK.

* [Pre-signed POST Form](https://docs.byteplus.com/docs/tos/Post-form-presignature-node-js-sdk): TOS supports browser\-based POST object upload requests, enabling you to upload content directly to TOS. You can use the pre\-signed POST form parameters generated by the Node.js SDK.
