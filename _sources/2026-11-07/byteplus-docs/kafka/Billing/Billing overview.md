This topic introduces the billing methods, prices, and lifecycle of Kafka instances.

<span id="计费类型"></span>
## Billing methods


|**Billing Method** |**Description** |
|---|---|
|Pay\-as\-you\-go |You are charged for your instance based on the instance specifications. Bills are generated on an hourly basis, and fees are automatically deducted from your BytePlus account. If you no longer need a Kafka instance, you can release it to save costs. This billing method is suitable for short\-term usage. For more information, refer to [Pay-as-you-go](https://docs.byteplus.com/en/docs/kafka/pay-as-you-go). |


For information on prices, refer to [Billable items and prices](https://docs.byteplus.com/en/docs/kafka/billable-items).

<span id="实例生命周期"></span>
## Instance lifecycle

The billing method that you select determines how the lifecycle of a Kafka instance is calculated.


* **Pay\-as\-you\-go**: The lifecycle of an instance starts when you create it and ends when you release it. For more information, refer to [Pay-as-you-go](https://docs.byteplus.com/en/docs/kafka/pay-as-you-go).
