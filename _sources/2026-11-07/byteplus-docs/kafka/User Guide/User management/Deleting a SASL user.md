You can promptly delete a SASL user that is no longer needed. This topic describes how to delete a SASL user.

<span id="注意事项"></span>
## Precautions

Before deleting an account, make sure that no related running producer and consumer instances use the user for authentication.

<span id="操作步骤"></span>
## Procedure


1. Log on to the [Message Queue for Kafka console](https://console.byteplus.com/kafka).

2. In the top menu bar, select the Region of your instance.

3. On the **Instances** page, click the name of the instance.

4. On the **User Management** tab, locate the SASL user you want to delete, and click **Delete** in the **Actions** column.

5. Verify the phone number.

6. Confirm the user information and click **Delete**.
