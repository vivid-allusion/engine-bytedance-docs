We recommend that you regularly maintain allowlists and IP address lists, and delete allowlists that are no longer needed in time. This topic describes how to delete an allowlist in the console.

<span id="前提条件"></span>
## Before you begin

Make sure that the allowlist you want to delete is not associated with a Kafka instance.

<span id="操作步骤"></span>
## Procedure


1. Log on to the [Message Queue for Kafka console](https://console.byteplus.com/kafka).

2. On the upper\-left corner of the top menu bar, select the Region of the instance.

3. In the left\-side navigation pane, click **Allowlist**.

4. Locate the target allowlist, and click **Delete** in the **Actions** column.

5. In the pop\-up dialog box, confirm the name and ID of the allowlist you want to delete and click **OK**.
