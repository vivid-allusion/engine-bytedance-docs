## Out of the box

Message Queue for Kafka is fully compatible with Apache Kafka. You can connect to Message Queue for Kafka by using an endpoint of your instance without code modification. Message Queue for Kafka helps you quickly migrate business to BytePlus.

<span id="高可用性"></span>
## High availability

Message Queue for Kafka maintains a high throughput of messages that are sent and received even if a large number of messages are accumulated. It allows you to reuse consumed messages or clear accumulated messages. This eliminates the need to be concerned about data operations and maintenance (O&M) and helps easily recover your business from failures.

<span id="数据高可靠"></span>
## High data reliability

Message Queue for Kafka supports persistent storage of messages and offers a multi\-replica data storage mechanism. Messages are stored in three replicas by default, which ensures high data reliability.

<span id="无忧运维"></span>
## O&M\-free feature

Message Queue for Kafka is integrated with Vitality Cloud Monitor (VCM) to offer automatic deployment and a complete set of O&M systems and after\-sales services. VCM monitors relevant service data such as instance status, resource usage, and the amount of time used for sending and receiving messages. You can use custom alarm services to receive alarm notifications in various scenarios through diversified channels. This way, you can focus more on business development without caring about service deployment and O&M.

<span id="数据安全"></span>
## Data security


* Message Queue for Kafka supports access management based on access control lists (ACLs) and is fully compatible with the built\-in permission policies of Apache Kafka. You can create and manage PLAIN and SCRAM users in the Message Queue for Kafka console to manage and control data subscriptions and consumption permissions by topic. This ensures the security of your data and business while giving you more configuration flexibility.

* Message Queue for Kafka offers an account management and authentication mechanism at the control plane level. It is fully integrated with Identity and Access Management (IAM) and supports permission management based on BytePlus accounts and IAM users. You can attach different policies to different IAM roles for accessing Kafka instances. This facilitates fine\-grained permission management in various scenarios.

* In terms of message communication, Message Queue for Kafka allows you to perform data authentication and authorization at the data plane level by managing user permissions. Message Queue for Kafka works with Virtual Private Cloud (VPC) to strengthen network access control and offer enterprise\-grade security protection.
