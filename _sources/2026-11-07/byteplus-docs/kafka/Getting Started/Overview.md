This topic describes the process for getting started with Message Queue for Kafka.

<span id="操作流程"></span>
## Process

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ecd9e1f3f37b4c2fabb0922961c333aa~tplv-goo7wpa0wc-image.image) </span>

The basic process includes setting up the development environment, creating resources, and connecting to the Kafka instance.


1. [Setting up the development environment](https://docs.byteplus.com/en/docs/kafka/setting-up-environment).

   Create a BytePlus account and complete the enterprise real\-name authentication. In addition, setting up the development environment, such as creating an Elastic Compute Service (ECS) instance and a virtual private cloud (VPC).

2. [Creating resources](https://docs.byteplus.com/en/docs/kafka/creating-resources).

   Create a Kafka instance and all related resources in the Message Queue for Kafka console. Related resources include topics and Simple Authentication and Security Layer (SASL) users.

3. Connect to Kafka instance.

   Use the default endpoint or a SASL endpoint to connect to the instance as needed. After the instance is connected, produce and consume messages.

   * [Connecting to an instance by using the default endpoint](https://docs.byteplus.com/en/docs/kafka/connecting-by-default)

   * [Connecting to an instance by using a SASL_PLAINTEXT endpoint](https://docs.byteplus.com/en/docs/kafka/connecting-by-SASL_PLAINTEXT)

   * [Connecting to an instance by using a SASL_SSL endpoint](https://docs.byteplus.com/en/docs/kafka/connecting-by-SASL_SSL)
