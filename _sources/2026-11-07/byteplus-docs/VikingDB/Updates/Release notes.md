# Release date: Sep 10, 2025


|**Update Type** |**Description** |**Screenshot** | |
|---|---|---|---|
|New feature |1. **Video Retrieval Feature Launched, Enabling End\-to\-End Full\-Modal Writing and Retrieval**<br><br><br>To support a wider range of multi\-modal retrieval scenarios, the vector database has officially launched the full\-modal retrieval feature. Datasets now support the creation of video vectorization fields and hybrid multi\-modal vectorization. When ingesting videos, you can customize the FPS.<br><br>**Note**: Currently, this is a whitelist\-only feature. It is available via API V2 and only supports synchronous writing for the time being. It will be fully open to all by the end of the month.<br><br><br>* Retrieval Context Limit: 128k<br><br>* Video Limits: A single video file must be within 50MB. Supported formats include MP4, AVI, and MOV. Processing of audio information in video files is not currently supported.<br><br>* Support for Specified FPS: It supports controlling the frame rate for image extraction from videos, with a configurable range of 0.2\-5.<br><br>2. **Optimization of Multi\-Modal Data Upload Methods**<br><br><br>To facilitate data upload for users, in addition to TOS links, uploading images or videos via any public HTTP/HTTPS link is now supported.<br><br><br>3. **Dataset\-Index Association Display**<br><br><br>All associated indexes can now be directly queried from the dataset details page. |*  | |
