# Benefits

<span id="85a5ad1f"></span>
# **Higher performance**

Vector database supports millisecond\-level retrieval of billions of vector data. Common indexing methods such as HNSW, IVF, and DiskANN have significantly improved compared to open source engines, delivering **a threefold improvement in performance and cost\-effectiveness while ensuring index accuracy. Its performance is highly competitive.**  At the same time, high\-performance filtering and post\-processing engines can maintain good performance under different data distributions, and the conditional filtering ability is **10 times** higher than open source ES.

<span id="13dfd34c"></span>
# **Larger scale**

This product is built on the same vector database technology used by core ByteDance products like Doubao/Douyin, which manages trillions of vectors and easily meets the storage and retrieval needs for various AI scenarios.


> * Separate storage and computing architecture to support massive data storage, scaling from billions to trillions of entries

> * Index building and service separation to take advantage of better heterogeneous hardware capabilities: up to 100GB monolithic index


<span id="d041c4fb"></span>
# **Stronger retrieval**

Supports rich retrieval capabilities, allowing for the mixed use of vector, scalar, and statistical retrieval, while remaining compatible with traditional keyword retrieval.

It supports multimodal machine learning retrieval for text and images, which, when combined with multimodal embedding models, delivers improved performance in complex scenarios.

It is also the first Cloud Services product to provide dense + sparse vector retrieval, with better performance and effectiveness than traditional BM25 keyword retrieval + vector retrieval.

<span id="804b87ff"></span>
# **Better Models**


* Integrated with Doubao embedding models and open\-source models for **advanced** vector search.


<span id="34962e0e"></span>
# **Lower Cost**


* Lower cost than **Tencent and Alibaba Cloud**, comparable to **Milvus**.

* Supports multi\-site disaster recovery at minimal cost.


<span id="2ddce7d5"></span>
# **Ease of Use**


* **Web Console**: Complete data ingestion to retrieval in minutes.

* **API/SDK**: Intuitive, developer\-friendly integration.

* **Comprehensive Documentation**: Usage practices, parameter tuning guides.


<span id="041f0f4c"></span>
# Stability and efficiency

VikingDB adopts an architecture with separate storage and computing resources. The same dataset can be used in multiple scenarios, reducing computing overhead while enhancing online stability and high availability.

<span id="a58832ee"></span>
# Best practices in various scenarios

Using multiple large models, VikingDB powers data search across large databases for more than 50 business lines in the ByteDance ecosystem—such as Douyin (TikTok China), Toutiao, and Lark—and in business areas like search, risk control, and advertising.
