# Overview

<span id="e3ecb698"></span>
# What is VikingDB?

VikingDB is a vector database system built on the cloud infrastructure of BytePlus. It is designed for storing, indexing, and analyzing massive vector data generated by machine learning (ML) models. VikingDB integrates multiple proprietary indexing algorithms developed by BytePlus and has empowered diverse business lines of ByteDance in multiple scenarios involving massive amounts of data. It supports data search from tens of billions of vectors and can be deployed for intelligent Q&A, intelligent search, recommendation, and data deduplication.

# Concepts

<span id="742ccfd3"></span>
## Unstructured data

Unstructured data is a type of data that does not have a predefined data model or regular structure, making it impossible to be represented in two\-dimensional relational database tables. Typical unstructured data includes images, videos, audio, and natural language. Unstructured data can be transformed into vectors by AI or ML models.

<span id="e1d14c4d"></span>
## Vector

In mathematics, a vector is a quantity with magnitude and direction. In ML or deep learning, features of unstructured data, such as text, images, audio, and videos, are extracted by embedding models and represented by vectors.

<span id="1b707df1"></span>
## Feature vector

A feature vector contains the key characteristics of an object. A well\-known example is the RGB color representation. Each color is defined by the intensity of its red (R), green (G), and blue (B) components. This way, we can define a feature vector like this: color=[R, G, B]. If we define white=[255, 255, 255] and black=[0, 0, 0] for a pixel, the two vectors are the feature vectors describing the pixel.

<span id="b0f00e98"></span>
## Embedding

Embedding is the process where a deep neural network extracts the content and semantics of unstructured data, such as text, images, audio, and videos, and converts it into feature vectors.

<span id="7611ce4f"></span>
## Vector similarity search

Similarity search compares a target object against the data in a database to retrieve the most similar matches. Likewise, vector similarity search is a method that calculates and compares the similarity between vectors based on a vector space model, and retrieves the most similar vectors. If two vectors are highly similar, their source data, two images, for example, are also alike. The following table describes the vector similarity search algorithms supported by VikingDB.


|**Algorithm** |**Description** |
|---|---|
|Inner product (IP) |This algorithm calculates the inner product of two vectors by multiplying the corresponding components of the vectors. A larger value indicates a higher similarity. |
|Euclidean distance (L2) |This algorithm calculates the Euclidean distance between two vectors. A smaller value indicates a higher similarity. |
|Cosine similarity |This algorithm calculates the cosine of the angle between two high\-dimensional vectors. A smaller cosine value indicates a larger angle between the vectors, which means a lower similarity. |
