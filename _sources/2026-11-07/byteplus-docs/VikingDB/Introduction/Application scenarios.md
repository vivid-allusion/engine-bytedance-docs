# Intelligent search

Search for similar text, images, audio, and videos

Text and semantic search: Natural Language Processing (NLP) models convert text into semantic vectors, capturing contextual meaning of words. Users can search for relevant information using natural language and the same models without knowing the exact keywords.

Image search: VikingDB searches massive databases for images that are visually similar to an uploaded image and returns the results instantly.

Video search: You can convert keyframes of a video into vectors and search for similar videos, which is useful in making real\-time video recommendations.

Audio search: VikingDB can quickly search massive amounts of audio files for data that is similar to the input audio, such as speeches, music, and sound effects.

Cross\-modal and multimodal retrieval of AI\-generated content (AIGC): VikingDB supports applications such as text\-to\-image and text\-to\-video.

Hybrid search: VikingDB supports hybrid search that involves both structured and unstructured data, which enables search services that are more accurate, comprehensive, and business\-specific. Typical examples are product search and recommendation in e\-commerce, case retrieval and document analysis in legal affairs, and news categorization and recommendations in the media industry.

# Data Annotation

Multi\-modal data annotation is applied in scenarios such as intelligent security and autonomous driving. The annotated data is converted into vectors and stored in the vector database, which models can retrieve and match to perform accurate identification and decision\-making.
