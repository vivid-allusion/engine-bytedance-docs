|Code |CodeN |Message |Error Description and Solution |Status |
|---|---|---|---|---|
|MissingParameter |100002 |The request is missing %s parameter. |Critical parameters missing, such as missing Action or Version parameters. Please refer to the API documentation to add the Action or Version parameters. |400 |
|MissingRequestInfo |100004 |The request is missing %s information. |Missing necessary request information, e.g., X\-Date |400 |
|InvalidTimestamp |100006 |The signature of the request is expired. |The request has expired or the request timestamp is in the future. Please check if the local time is normal and if UTC time (accurate to the second, using the format following the ISO 8601 standard: YYYYMMDD'T'HHMMSS'Z') is used. |400 |
|ServiceNotFound |100007 |The service [%s] was not found. |The requested service does not exist. Please refer to the product's API documentation to check if the Service is filled in correctly. |404 |
|InvalidActionOrVersion |100008 |Could not find operation %s for version %s. |The requested interface does not exist. Please refer to the product's API documentation to check if the Action is filled in correctly. |404 |
|InvalidAccessKey |100009 |The Access Key [%s] included in the request is invalid. |The requested Access Key is invalid. Please check if the Access Key ID and Secret Access Key are correct, and note that there should be no extra space characters. |401 |
|SignatureDoesNotMatch |100010 |The request signature we calculated does not match the signature you provided. Check your Secret Access Key and signing method. Consult the service documentation for details. |The signature result is incorrect. Check the signature steps. It is recommended to use the SDK to avoid encoding and constructing the signature by yourself. If you need to construct the signature, you can refer to the signature code examples. |401 |
|AccessDenied |100013 |User is not authorized to perform: %s on resource: %s. |The user's permissions do not support the current operation. Please refer to the access control documentation to add IAM policy permissions for the user. |403 |
|InternalError |100014 |The service has some internal errors. Please contact the administrator. |Internal error. System error, generally does not occur. If the occurrence frequency exceeds the SLA, you can contact us through our ticketing system. |500 |
|InternalServiceTimeout |100016 |The internal service has timed out. Please contact the administrator. |Service execution timeout. System error, generally does not occur. If the occurrence frequency exceeds the SLA, you can contact us through our ticketing system. |504 |
|FlowLimitExceeded |100018 |Request was rejected because the request rate for this OpenAPI is beyond the current flow control limit. |The request is too frequent and exceeds the speed limit. Please reduce the request QPS. If you need to increase the speed limit, you can contact us through our ticketing system. |429 |
|ServiceUnavailableTemp |100019 |Service is busy, please try again later. |The service is in a circuit\-breaking state and is temporarily unavailable. Retry later. The service is in an unavailable state, generally does not occur. If this occurs, you can contact us through our ticketing system. |503 |
|InternalServiceError |100023 |The service has some internal errors. Please contact the administrator. |The service has a fault. Generally does not occur. If this occurs, you can contact us through our ticketing system. |502 |
|InvalidAuthorization |100024 |Invalid 'Authorization' header, Please check the authorization header. |The format of the Authorization header is incorrect. The constructed Authorization Header is incorrect, such as not filling in the Region field or having characters not in the legal character set. Please check the Authorization header. It is recommended to use the SDK to avoid encoding and constructing the signature by yourself. If you need to construct the signature, you can refer to the signature code examples. |400 |
|InvalidCredential |100025 |Invalid credential in 'Authorization', Please check the credential in the authorization header. |The format of the Credential in the Authorization header is incorrect, such as the Access Key not being in the legal character set. Check the Credential field. It is recommended to use the SDK to avoid encoding and constructing the signature by yourself. If you need to construct the signature, you can refer to the signature code examples. |400 |
|InvalidSecretToken |100026 |Invalid secret token, msg: %s. |Invalid STS (temporary security credentials). This can be caused by various issues, such as a signature error or expired credentials. Please check if the temporary credentials generated by AssumeRole have expired and if the signature is correct. It is recommended to use the SDK to avoid encoding and constructing the signature by yourself. If you need to construct the signature, you can refer to the signature code examples. |401 |


For other non\-public error codes, please refer to the specific product API documentation.
