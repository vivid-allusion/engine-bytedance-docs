# Getting started with vector databases

VikingDB is a vector database system built on the cloud infrastructure of BytePlus. It provides core capabilities for producing, storing, indexing, and analyzing massive vector data generated by machine learning (ML) models.

This topic describes how to configure your first vector database in a few minutes, and helps you create a collection and an index, and perform vector retrieval.

<span id="b5b6a847"></span>
# Step 1: Create a collection

You can use either of the following methods to **create a collection**.

Method 1: On the homepage of BytePlus, click VikingDB. On the **Get started** page of the Vector Database console, click **Create collection** in Step 1 of the tutorial section at the top.

Method 2: On the homepage of BytePlus, click VikingDB to go to the Vector Database console. On the left navigation pane, click **Collection**. On the Collection page, click **Create collection** at the upper\-left.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90f231c8e1f94d83970b21fcaa4fd94e~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e96ede8f114241db83c1db1f3aa190a8~tplv-goo7wpa0wc-image.image) </span>

You can create a collection by selecting either the **Vectorize data** or **Existing vector data** option.

To import an existing vector, select **Existing vector data** and click Create.

If you have only raw text or multimodal data, select **Vectorize data** and click Create. If you select this method, Vector Database will automatically vectorize the data that you import to the vector fields using the specified models.

This example describes how to create a collection using the **Vectorize data** option.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5a841784f5124a21986ac568b62fdb9e~tplv-goo7wpa0wc-image.image) </span>

On the Create collection page, configure parameters in the Basic information, Vector information, and Field settings sections. Refer to the figure on the right for an example.

Click **Submit** in the lower\-right corner after you have configured all required parameters.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9d25d80b7f71461786a497d810b5acb2~tplv-goo7wpa0wc-image.image) </span>

<div style="text-align: center">
(Example)</div>


To add a sparse vector field, you must configure a dense vector field.

Do not input the data to be vectorized in fields other than the vector fields. Data in the `text` and `image` type fields other than the vector fields is stored, but will not be vectorized. The names of the vector fields must be unique.

> When using embedding models to create vectorized data, your uploaded data may be sent to BytePlus servers in Malaysia for processing. BytePlus does not store your data, including any processed data, on our servers in Malaysia.

## Collection parameters


|**No.**  |**Parameter** |**Description** |
|---|---|---|
|1 |Basic information |You must specify the collection name. Alias and description are optional. |
|2 |Vector information |Configure the vector fields. Parameters in this section are required. |
|3 |Field settings |Configure the non\-vector fields. Parameters in this section are optional.<br><br><br>* Field name: The name can contain letters, digits, and underscores (_). It must be unique and start with a letter.<br><br>* Field type: Select a type from the drop\-down list. The options are string, bool, list, int64, float32, text, and image.<br><br>* Default value: You can enter a default value for a field that is not the text or image type. If you do not specify a default value and the field data is missing during data writing, the system default value is used. |
||||
||||
||||
|4 |Primary key |The primary key is used to uniquely identify a row of data. If you have configured any fields in the Field settings section, you must specify a primary key.<br><br>You can specify to generate a primary key automatically, or select a field of the string or int64 type from **Other fields** as the primary key. |
||||
|5 |Pricing rules |If you have configured a vectorization model, the model pricing information is displayed.<br><br>Offline storage resources will be billed based on the amount of stored data after an index is created. |

# Step 2: Create an index

You can use either of the following methods to go to the **index creation** page.


* Method 1: On the **Get started** page of the Vector Database console, click **Create index** in Step 2 of the tutorial section at the top.

* Method 2: On the left navigation pane, click **Indexes** to open the Indexes page. On the page that appears, click **Create index** in the upper\-left corner.

* Method 3: Click **Collection** on the left navigation pane. Find the target collection, click the ... icon in the upper\-right corner of the collection card, and select **Create index** from the drop\-down menu.

<Tab zoneid="TM9YdCn3qT" title="Python">
<TabTitle>Python</TabTitle>

```Python

collection = vikingdb_service.get_collection("example")

def gen_random_vector(dim):    
    return [random.random() - 0.5 for _ in range(dim)] 
field = {
    "doc_id": "11",
    "text_vector": gen_random_vector(12),     "like": 1,
    "price": 1.11,
    "author": ["gy"],
    "aim": True,
}
data = Data(field)
collection.upsert_data([data])  

async def upsert_data():
    collection = await vikingdb_service.async_get_collection("async")  
    field = {
        "doc_id": "111",
        "text_vector": gen_random_vector(10), 
        "like": 1,
        "price": 1.11,
        "author": ["gy"],
        "aim": True,
    }
    data = Data(field)
    await collection.async_upsert_data([data])  
asyncio.run(upsert_data())
```
