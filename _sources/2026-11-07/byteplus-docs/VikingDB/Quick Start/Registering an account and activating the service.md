# Register a BytePlus account

Go to the [BytePlus official website](https://www.byteplus.com/en) and click Sign In in the upper right corner.

Provide the required information in the form to complete the registration. For more information, refer to [Account registration procedure](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

<span id="1a6517cf"></span>
# Activate the vector database service

Perform the following steps:

Log in to the [BytePlus console](https://console.byteplus.com/home). Find and click **VikingDB Vector Database**. Then, activate the vector database or knowledge base service as prompted.
