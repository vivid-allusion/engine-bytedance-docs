This section explains how to add memories to a Memory Store.

<span id="Steps"></span>
# Steps

Click the **Write Data** button on the page to open the data writing options. Currently, writing data directly from the console is not supported. Please obtain your AK/SK from the Byteplus official website and write the data programmatically in your local environment.
