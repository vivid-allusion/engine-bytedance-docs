This section explains how to view memory details in a Memory Collection.

<span id="Steps"></span>
# Procedure

After successfully adding memories, you can view their details in the console. The homepage displays the number of profiles and events in the Memory Collection, along with a user list.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9b055bfdb0934f76a1816603479eb9cc~tplv-goo7wpa0wc-image.image) </span>

Click on a user's row to view their memory details. Profile and event memories can be filtered by both **Group ID** and **Assistant ID**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c0b03b50c93d45a8b369c8c7047147c8~tplv-goo7wpa0wc-image.image) </span>

Click the **Settings** button to view memory extraction rules and Memory Collection information.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5641157ef64941df8cb508747945a65d~tplv-goo7wpa0wc-image.image) </span>
