This section explains how to retrieve existing memories from a Memory Collection.

<span id="Steps"></span>
# Steps

Each memory is associated with a unique user, so you must first select the user whose memories you want to retrieve.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0a0109775be84f5b94d8c3f13ad81707~tplv-goo7wpa0wc-image.image) </span>

You can configure retrieval conditions in the left sidebar as needed. After completing the settings, enter a search query in the search box, and the system will return the most relevant text fragments.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e37e9992b314aa58f1d888b7e569cd7~tplv-goo7wpa0wc-image.image) </span>
