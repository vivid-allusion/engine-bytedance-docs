This section explains how to delete a Memory Collection.

<span id="Steps"></span>
# Steps

There are two ways to delete a Memory Collection:

On the **Memory Collection Details** page, click the **More Actions** icon in the upper\-right corner and select **Delete Memory Collection**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9f903e99ebf24ce2851dafa78664b56f~tplv-goo7wpa0wc-image.image) </span>

On the **Memory Collection Home** page, click the **More Actions** icon on the corresponding Memory Collection card and select **Delete Memory Collection**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7161e06074784de1b46541ad730ee305~tplv-goo7wpa0wc-image.image) </span>
