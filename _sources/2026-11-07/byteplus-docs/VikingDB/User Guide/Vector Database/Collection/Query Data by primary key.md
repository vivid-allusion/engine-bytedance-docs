# Querying data

This topic describes how to **query data** in a specified collection.

<span id="a16ea692"></span>
# Procedure


1. On the **Collection** page, click the target collection card.

2. On the collection details page, enter an array of primary key values in the search box. Then click Search.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9f8954a3477e4092825f5d10238946bc~tplv-goo7wpa0wc-image.image) </span>


3. The results are displayed in the data preview section below. You can perform **Retrieval test, Edit, and Delete** actions by clicking the corresponding button in the Actions column.
