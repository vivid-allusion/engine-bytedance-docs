# Viewing collection details

This topic describes how to view the details of a specific collection.

<span id="19982f94"></span>
# Procedure


1. Click **Collection** in the left navigation pane.

2. On the Collections page, click the target collection. On the collection details page, click **Details** next to the collection description. A panel appears, showing information about the collection and its fields.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef3413585e7e446aa146052174b0e994~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f3c4d8dfa2484c2fa523ac5f2e37558e~tplv-goo7wpa0wc-image.image) </span>


|**Area** |**Description** |
|---|---|
|1 |Displays information about the last configuration update and data update. |
|2 |Displays vector information. |
|3 |Displays the list of vector and other fields in the collection. |



3. Click the "x" icon in the upper\-right corner to close the panel.
