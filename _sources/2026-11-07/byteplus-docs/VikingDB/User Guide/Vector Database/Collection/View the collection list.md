# Viewing the collection list

This topic describes how to view the list of created collections.

<span id="cde3d762"></span>
# Procedure


1. Click **Collections** in the left navigation pane.

2. On the Collections page, view the list of created collections.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b202ec4fa9ac4d3e85e6ff8c11a0d59a~tplv-goo7wpa0wc-image.image) </span>

The following table describes information on each collection card.


|**Item** |**Description** |
|---|---|
|Name |The name of the collection. |
|Updated by |The user who last updated the collection. |
|Updated on |The time when the collection was last updated. |
|Data volume |The number of data records written to the collection. |
|Index |The number of indexes created for the collection. You can click this number to view the list of indexes created for the collection. |
|Scenario |Indicates whether it is a text or multi\-modal collection. |
|Vector type |Indicates whether dense or sparse vectors are stored in the collection. |
|Actions |* **Create index**: Select this option to create an index for the collection. During index creation, the collection information cannot be modified.<br><br>* **Edit**: Select this option to modify the collection description and add fields.<br><br>* **Drop**: Select this option to drop the collection. In the dialog box that appears, click **OK**. Only collections without indexes can be dropped.<br><br>* **Write data**: Select this option to synchronously and asynchronously write data to the collection and import data from local directories. |
