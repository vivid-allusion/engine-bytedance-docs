# Inserting data

This topic describes how to **insert data** into a specified collection.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This document shows you how to use the collection details page to add data one row at a time. Bulk data import is supported during the collection creation process. For more information, see Creating a collection.</div>


<span id="8eb5baab"></span>
# Procedure


1. On the **Collection** page, click the target **collection card**. On the collection details page, click **Insert data** in the upper\-right corner.

2. In the pop\-up window, **enter the value for each field**. Then click **Insert**.
