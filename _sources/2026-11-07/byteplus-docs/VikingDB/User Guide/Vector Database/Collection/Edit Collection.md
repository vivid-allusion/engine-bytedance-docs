# Editing a collection

To enhance or update your data structure, you can edit an existing collection by adding new fields or modifying its description and alias. This guide provides step\-by\-step instructions for this process and highlights the important limitation that existing fields cannot be modified later.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can add fields to a collection and modify its description, but cannot modify added fields.</div>


<span id="898d7c40"></span>
# Procedure


1. Click **Collection** in the left navigation pane.

2. Find the target collection, click the "..." icon in the upper\-right corner of the collection card, and select **Edit** from the shortcut menu.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/59456bc5f42b46f48a554bcc391b654b~tplv-goo7wpa0wc-image.image) </span>


3. On the collection editing page, modify the collection description and alias and click **Add field** to add fields as needed.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/67b82c331a744bb0bcb1e626992ce81f~tplv-goo7wpa0wc-image.image) </span>


4. Click **Update collection** on the right side of the page after you finish editing.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f11b250b109d4a1faf9db90859130722~tplv-goo7wpa0wc-image.image) </span>

Existing fields, including vector fields, cannot be modified. You can, however, modify the collection's alias and description and add new fields.
