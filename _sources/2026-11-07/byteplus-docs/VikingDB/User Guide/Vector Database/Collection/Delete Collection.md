# Dropping a collection

This topic describes how to drop a collection.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">All data in a collection will be permanently deleted 30 days after you drop the collection. Proceed with caution.</div>


* <div data-tips="true" data-tips-type="warning">You cannot drop a collection until you drop all indexes associated with it.</div>



<span id="518dfe33"></span>
# Procedure


1. Click **Collections** in the left navigation pane.

2. On the Collections page, click the target collection card. Click the ... icon on the card and select **Drop** from the shortcut menu. A confirmation dialog box appears, informing you that data in the collection will be cleared 30 days after the collection is dropped.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/45998a9e8faf4b46b335955fed249b36~tplv-goo7wpa0wc-image.image) </span>

Click **OK** to drop the collection after confirming the message.
