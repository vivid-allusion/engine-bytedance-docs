# Viewing index details

This topic describes how to view the details of a specific index.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">When the index is in <strong>Ready</strong> status, you can click the Retrieval Test tab on the index details page to view the test details and perform related operations.</div>


* <div data-tips="true" data-tips-type="tip">When the index is in <strong>Initializing</strong> or <strong>Failed</strong> status, you can only view its basic information on the index details page.</div>



<span id="eff1f09d"></span>
# Procedure


1. Click **Indexes** in the left navigation pane.

2. On the **Indexes** page, click the target index. The Basic info tab appears by default, which shows the basic information and configurations of the index.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4518b64db7224a6f965bd5afdb54d3eb~tplv-goo7wpa0wc-image.image) </span>


3. Click the **Retrieval test** tab. On this tab, you can configure query conditions and click **Search** to view query results. For more information, see Retrieval test.
