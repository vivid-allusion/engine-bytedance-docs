# Viewing the index list

This topic describes how to view the index information of all collections.

<span id="e8dfcee8"></span>
# Procedure


1. Click **Indexes** in the left navigation pane.

2. On the Indexes page, view the list of created indexes. You can enter the index name or collection name in the search box in the upper\-right corner of the page to perform a fuzzy search.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7f67933337b849d8b75d80698c21ab5c~tplv-goo7wpa0wc-image.image) </span>

The following table describes columns in the list on the Indexes page.


|**Column Name** |**Description** |
|---|---|
|Name |The name of the index. |
|Status |The status of the index. Valid values:<br><br><br>* Initializing: The index is being created.<br><br>* Ready: The index has been created and is ready for data retrieval.<br><br>* Failed: The index creation failed. If this happens, contact BytePlus technical support. |
|||
|||
|||
|Collection |The collection to which the index belongs. |
|Updated By |The user who last updated the index. |
|Updated On |The time when the index was last updated. You can sort this column in ascending or descending order. |
|Description |The description of the index. |
|Action |* Test: Click this button to configure query conditions and view query results.<br><br>* Edit: Click this button to edit the description, CPU quota, and scalar fields for the index.<br><br>* Drop: Click this button to drop the index. In the dialog box that appears, click **OK**. |
