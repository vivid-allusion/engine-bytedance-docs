# Dropping an index

This topic describes how to drop an index.

<span id="2d93bb35"></span>
# Procedure


1. Click **Indexes** in the left navigation pane.

2. On the Indexes page, find the target index and click **Drop** in the Action column. A confirmation dialog box appears, with a message informing you that once dropped, the index will no longer support retrieval and its related resources will be released.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/46052bd39aff4211a0867fb1e1ee1f50~tplv-goo7wpa0wc-image.image) </span>


3. Click **Delete** to confirm and drop the index.
