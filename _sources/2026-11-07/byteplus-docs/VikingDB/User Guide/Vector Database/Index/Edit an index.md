# Editing an index

<span id="29c546b2"></span>
# Scenarios

This topic describes how to edit the description, CPU quota, number of shards, and scalar fields for an index.

<span id="d2a7181b"></span>
# Procedure


1. Click **Indexes** in the left navigation pane.

2. On the **Indexes** page, find the target index and click **Edit** in the **Action** column.\*\*\*\*


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7a2feede18db436d9e4686926aec9fb9~tplv-goo7wpa0wc-image.image) </span>


3. On the **Edit index** page, modify the settings as needed. Only the index description, CPU quota, number of shards, and scalar fields can be modified.
