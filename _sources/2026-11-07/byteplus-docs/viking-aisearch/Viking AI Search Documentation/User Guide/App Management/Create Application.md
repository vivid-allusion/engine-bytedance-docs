# **Overview**

On the Viking AI Search platform, an application is the core unit through which you access and utilize search capabilities. To get started, create an application and associate it with one to three item datasets of the same type. These datasets serve as the source of searchable content and must go through index configuration and build processes before they can be queried. Once configured, the application can deliver both standard search and intelligent conversational search via API.

# Create application

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/a7f644c41efe4046be51e2dd91019fd1) </span>

&nbsp;

After activating the AI Search service, you can create an AI Search application. The application serves as the foundation for all subsequent data and experience configuration.


1. In the AI Search & Recommendation Console, go to the **Application Management** page.

2. Click **Create Application**, enter an application name, and select the industry that corresponds to your use case. Complete the creation by configuring the parameters below



|**Parameter name** |**Required** |**Parameter description** |
|---|---|---|
|Application name |Yes |The name of the application to create. <br><br><br>* Supports Chinese, English, digits, and special characters. <br><br>* Length: 1–128 characters. <br><br>* Application names must be unique. |
|Industry |Yes |Select the industry that matches your business scenario: <br><br><br>1. **E\-commerce** — For retail platforms building product search, image search, personalized recommendations, and AI shopping assistants. <br><br>2. **Image Platform** — For image asset libraries and platforms that provide commercial asset downloads and purchases, supporting image and text\-based asset search and personalized recommendations. <br><br>3. **News Platform** — For news and media platforms supporting article search, content recommendations, and on\-site Q&A. <br><br>4. **Social Content** — For social media platforms supporting multimodal search and personalized recommendations for image and text posts. <br><br>5. **Video Platform** — For video\-on\-demand platforms offering end\-to\-end movie and series search, recommendations, and intelligent viewing assistants. |
|Application Language |Yes |Supports English, Chinese, Japanese. Will be the language used for default configurations and API response language.  |


After the application is created, you must create or associate at least one item dataset or document dataset before proceeding with further configuration. You can choose to associate an existing dataset or create a new one.
