This chapter will guide you through the process of deleting applications that are no longer needed. Before performing this action, please read the following important notices carefully.

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">Warning</div>


<div data-tips="true" data-tips-type="danger"><strong>Application deletion is irreversible.</strong> Once deleted, any search API calls routed to this application will fail. Please ensure that the deletion will not impact your live services before proceeding.</div>


&nbsp;

Once you have verified the target application and understand the irreversible consequences:


1. Navigate to the **Application Management** page.

2. Click `...` on the **Application Card**, and select **Delete application**. A confirmation pop\-up will be triggered. 


<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/f6641cc5dbec4d0db2a802971e6a0a03" width="410px" /></div>



3. Click **OK** within the pop\-up to successfully delete the application.
