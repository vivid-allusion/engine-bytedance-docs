# Function Overview

Viking AI Search utilises advanced Large Language Model (LLM) understanding and multi\-modal embedding technologies. By combining the precision of traditional keyword matching with the semantic flexibility of vector\-based matching, it meets the diverse search requirements of e\-commerce, commercial asset repository platforms, content platforms, and other scenarios:


<columns>
<columnsItem zoneid="buIgXlPj5m">

<div style="text-align: center">
<strong>More than keyword matching</strong></div>


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/1ce73bf41b554555a901aedf83b21ff6) </span>

AI search combines the precise query ability of keyword matching with the conceptual query ability of semantic matching, enabling natural language queries in the search box.

While maintaining the accuracy of keywords, it enhances search generalization and diversity, improves matching for long\-tail search terms, and reduces searches with no results.

The native cross\-modal understanding and matching ability of large models frees search engines from relying on heavy image keyword tagging. Simply import multimodal data to quickly build indexes and integrate multimodal search capabilities, including:


* **Text cross\-modal search:**  match each data item's image and text information with the user's query term simultaneously.

* **Image\-to\-Image Search:**  find similar images and product content.

# Function Advantages


* **Easy configuration, test immediately after data import:**  Simply import data and configure fields to start testing search right away. It requires no coding, no heavy data labeling, or detailed index control. The generalization ability of large models supports content search across various industries.

* **Native cross\-modal capability:**  Items containing image data can utilise visual features for search out\-of\-the\-box. Support for text and image\-based queries is native, requiring no prior model training.

* **Flexible configuration with real\-time adjustments:**  Provides no\-code configuration for recall and ranking, combined with the **Experience Workstation** for instant strategy testing. Publish the strategy with one click once the results meet your requirements.

* **Standardized deployment process**: Supports one\-click configuration launch and offers stable API interfaces for online business system integration, enabling rapid deployment and strategy iteration.
