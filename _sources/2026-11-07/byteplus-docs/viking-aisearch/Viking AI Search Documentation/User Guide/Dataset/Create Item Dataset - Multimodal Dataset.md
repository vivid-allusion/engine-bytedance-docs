### 1. Start creating the dataset


1. In the Viking AI Search console, select **Datasets** from the left navigation pane.

2. Click **Create Dataset**.

3. On the dataset type selection page, select **Multimodal Data** under **Data Type**.

4. Under **Content Type**, select the template that best matches your business scenario: **General**, **E\-commerce**, **Content**, or **Long\-form Video**.

5. Under **Data Language**, select the primary language of the dataset, such as Chinese.

6. Under **Data Upload Method**, upload sample data by using a JSONL file, CSV file, or JSON code.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/0a440e29766c4fbb98ea679e57ba3f55) </span>

After you upload the sample data, click **Next**. The system automatically analyzes the data structure by reading the sample records, identifying field types and semantics, mapping item attributes, and inferring the index configuration.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default"><strong>Before you upload data:</strong></div>



1. <div data-tips="true" data-tips-type="default">Use JSONL files to import JSON objects in batches. JSON objects can contain up to three levels of nesting.</div>


2. <div data-tips="true" data-tips-type="default">Field names can contain only letters, digits, and underscores. A field name must start with a letter and cannot start with an underscore.</div>


3. <div data-tips="true" data-tips-type="default">Store image URLs and video URLs in separate fields. Each field can contain an array of URLs.</div>



<span id="878069be"></span>
### 2. Review the basic information generated by AI


1. Review the AI\-generated dataset name and description, and verify that they accurately describe your data.

2. Click **Next** to continue.

### 3. Review field descriptions and semantics generated by AI


1. Verify that the inferred field type is correct for each field.

2. Review the AI\-generated field description and make sure it is accurate and sufficiently detailed.

3. For fields that contain enumerated values, add a definition for each value.

4. Click **Next** to continue to attribute mapping.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/f6a3347232404150a6434e3e588fe3fe) </span>

### 4. Map fields to item attributes

The system maps the fields identified in the previous step to predefined item attributes and automatically suggests mappings. Review each mapping and adjust it as needed.

Fields that contain image URLs or video URLs are labeled **Multimodal**. Use the  **+**  button to map multiple fields to the same attribute. For example, you can map both a primary\-image field and a detail\-image field to the **Image URL** attribute. For more information, see [Multimodal Dataset](https://docs.byteplus.com/docs/viking-aisearch/117710).

<span id="52859a70"></span>
### 5. Configure the invalid\-data handling policy and create the dataset

Click **Finish and Create Dataset**. In the **Invalid Data Handling Policy** dialog box, select one of the following options based on your business requirements:


* **Do not process and mark as invalid data:**  The record is treated as invalid when a multimodal field cannot be processed.

* **Skip invalid modalities and continue processing:**  The system skips the invalid image or video and continues processing the remaining valid content.


Click **OK**. After the dataset is created, the console displays an **Item dataset created** message and redirects you to the dataset details page.

### 6. View the dataset

After you create the multimodal dataset, open it from the dataset list. The dataset details page contains the following tabs:

**Data configuration:**  View and update field names, field types, item attributes, and field descriptions. After you make changes, manually confirm them before they take effect. The confirmed configuration is then synchronized to associated Viking AI Search applications, and the index configuration is updated.

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/7766d7e5b3124bafa735739086492903) </span>

&nbsp;

**Data preview: ** View multimodal processing statistics, including the number of imported records, valid records, invalid records, successfully processed images, and valid video duration. You can also update the invalid\-data handling policy on this tab.

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/e6b6906ef189477084f700fa9dedc452) </span>

&nbsp;

**Activity history: ** View key operations performed on the dataset, such as configuration changes and data import tasks. Use these records to track the dataset change history.

**Dataset Monitoring: ** View runtime monitoring information for the dataset.

### 7. Next steps


* **Import more data:**  On the **Data Import** tab, add more records to the dataset. For data format requirements, see [Import and Update Item Data in Real Time](https://docs.byteplus.com/docs/viking-aisearch/Import_and_Update_Item_Data_in_Real_Time)

* **Associate the dataset with an application:**  When you create or edit an application, associate the dataset as an item pool. For instructions, see [Create and Link Item Dataset](https://docs.byteplus.com/docs/viking-aisearch/Create_an_Application_and_Link_Item_Datasets)
