This section will guide you through the process of deleting datasets that are no longer needed. Before performing this action, please read the following important notices carefully.

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">Warning</div>



<div data-tips="true" data-tips-type="danger"><strong>Dataset deletion is irreversible.</strong> Once executed, all raw data, processed vector data, and related information contained within the dataset will be permanently removed from the platform.</div>



**Prerequisites for Deletion**


* **The dataset must not be linked to any application.**  If a dataset is currently being used by one or more applications, the system will not allow its deletion to prevent impact on live services.

* **Required Action:**  Before attempting to delete a dataset, you must go to the management page of **all linked applications** and click **Unlink** to remove the association.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/9e21aecdc53e4b1caea84a77de16ce19) </span>

&nbsp;

Once you have verified the target dataset and understand the irreversible consequences: 


1. Ensure the dataset has been unlinked from all applications.

2. Locate the target dataset in the **Datasets** section

3. Click **`Delete`** button in the **actions** column of its row, and a deletion prompt will appear. 

4. Carefully read the pop\-up warning message, then click **`Delete`** to complete the deletion.
