## Detailed Steps for Configuration

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Prerequisite: before starting the following steps, at least one item dataset must be active within the application.</div>


&nbsp;

Upload the item dataset. If the personalized Q&A function needs to be enabled, upload behavioral data as well.

**Core Explanation:** 


* **Item Dataset:**  This is the foundation to activate the conversational search module. Once uploaded, you can experience basic Q&A and shopping guidance services.

* **Behavioral Data:**  This is a prerequisite for the **personalized conversation ** feature. If it is not uploaded, only general Q&A can be used, and it will not be possible to precisely match users' personalized needs.

* Ensure the dataset format is correct and the content is complete to avoid functional issues caused by data discrepancies.


&nbsp;

&nbsp;

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="default">To enable <strong>personalized search</strong> and <strong>initial item recommendation</strong> features, user behavioral data must be uploaded. These features cannot be activated without valid behavioral data.</div>


<div data-tips="true" data-tips-type="default">After modifying <strong>instructions</strong> or adjusting <strong>search strategies</strong>, the configuration must be saved for the changes to take effect.</div>


<div data-tips="true" data-tips-type="default">The <strong>keyword blocklist</strong> can be dynamically updated based on business needs; it is recommended to regularly review and add new terms that require blocking.</div>


&nbsp;

This concludes the guide for conversational search capabilities. If you need to configure search and recommendation features, or to perform API integrations, please refer to the respective configuration sections in the help documentation.
