## Process Overview

To deploy and optimize multimodal search capabilities, this guide breaks down the process into four core modules: **Text Search Configuration**, **Image Search Configuration**, **Result Ranking**, and **Query Intelligence & Auxiliary Features**.

By following the sequential video tutorials for each step, you can efficiently build a powerful search engine tailored to your specific business requirements.

## 1. Text Search Configuration & Testing

Once your item dataset is uploaded, navigate to  **"Experience"**  to test the search functionality. The system provides default search strategies while allowing you to create and compare multiple custom configurations. 

Choose from three preset modes — **Semantic, Keyword, or Balanced ** — along with custom settings to tailor your unique business scenarios. 

&nbsp;

<span id="615de4fb"></span>
## 2. Image Search Configuration & Testing

The platform provides three specialized image search modes based on **visual details, object similarity, and custom commands**. In the configuration panel, you can also define the maximum number of results for flexibility in diverse application scenarios.

&nbsp;

<span id="96140ae7"></span>
## 3. Search Result Ranking & Re\-ranking

We support four flexible sorting methods for search results to suit different business scenarios:


* **Prioritized Recall Protection:**  Ensures high\-quality baseline results.

* **Recall Reordering:**  Utilizes AI semantic optimization for precision ranking.

* **Boosting and Burying Rules:**  Dynamically elevates or suppresses specific items based on strategic priorities.

* **Field\-Based Sorting:**  Supports multi\-weight scoring and ascending/descending orders based on specific field logic.


&nbsp;

&nbsp;

<span id="2f968188"></span>
## 4. Query Intelligence & Auxiliary Features

Enhance search accuracy and the search experience with three intelligent features:


* **Synonym Mapping:**  Bridges the gap between different terminologies.

* **Typo Correction:**  Automatically rectifies user input errors.

* **Query Completion:**  Suggests relevant terms in real\-time.


&nbsp;

&nbsp;

This concludes the guide to multimodal search capabilities. To configure Recommendation and Q&A modules, or to perform API Integrations, please refer to the respective configuration sections in the help documentation.
