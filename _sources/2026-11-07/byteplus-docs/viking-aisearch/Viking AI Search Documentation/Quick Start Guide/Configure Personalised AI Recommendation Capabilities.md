# Process Overview

To rapidly build and deploy personalized recommendation capabilities, this guide provides a complete workflow covering three key areas: **Recommendation Scope Configuration**, **Ranking Configuration**, and **Recommendation Scripts Configuration**. Follow the accompanying video tutorials for each step to quickly set up and deploy recommendations tailored to your specific business scenarios.

Each step is accompanied by a dedicated hands\-on video. We recommend following the video tutorials during configuration to efficiently complete the setup and deployment, allowing you to adapt quickly to precise recommendation requirements across various business scenarios.

## 1. Detailed Steps for Recommendation Scope Configuration

Upon completing the search configuration, upload your behavior data and proceed to the experience configuration to test homepage and detail\-page recommendation strategies. You may also customise recommendation rules, filter results, set fallback strategies, and adjust the maximum number of recommendations to meet specific scenario requirements.

 &nbsp;

<span id="2814346a"></span>
## 2. Detailed Steps for Recommendation Ranking Configuration

The recommendation results support features such as boosting and burying, dual\-layer deduplication, diversification rules, and manual pinning of items. These allow for flexible adjustment of item ranking, prevention of repetitive recommendations, and ensuring result diversity. Additionally, custom filter conditions and pinned products can be defined to meet the display requirements of various scenarios.

&nbsp;

<span id="55d43571"></span>
## 3. Detailed Steps for Recommendation Scripts Configuration

The "Intelligent Analysis of User Preferences" feature supports custom recommendation scripts. You can adjust the output content via natural\-language prompts based on your specific business scenarios.

&nbsp;

The above constitutes the complete guide for personalized recommendation capabilities. To configure search or Q&A functions, or to perform API Integrations, please refer to the respective configuration sections in the help documentation.
