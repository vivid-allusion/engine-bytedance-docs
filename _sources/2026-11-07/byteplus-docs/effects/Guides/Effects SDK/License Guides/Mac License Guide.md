<span id="Certificate generation tool"></span>
## Certificate generation tool

<span id="1. Unzip license-tools.zip to get LicGenerator"></span>
### 1. Unzip license\-tools.zip to get LicGenerator

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/881438d-1.png) </span>

<span id="2. Open Terminals to input the command"></span>
### 2. Open Terminal to input the command

```Bash
cd   [path where  ‘licgenerator’  located ]
./licgenerator   [your key]  [your secret]  [your output directory]
```


The first parameter key and the second parameter secret are required. If the output directory is empty, the license will be generated under the current Terminals directory.

<span id="3. Done"></span>
### 3. Done

If it displays, the following will be shown:

```Plain
FINISH! generate license succeed, check “{output directory} license.licbag”
```


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/adeb8f7-2.png) </span>

it indicates that the certificate has been generated successfully. If an incorrect number is generated, please consult technical support.

For detailed information about the online license, please refer to [Online License Guide](https://byteplus-docs.readme.io/effects/docs/online-license-guide).
