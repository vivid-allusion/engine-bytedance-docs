# Online Licensing Guide

This article will describe Online Licensing's basic concepts and operating procedures. By reading this article, you will have a full understanding of the online licensing mechanism and how to use our software properly with our online licensing scheme.

<span id="What is a software license?"></span>
## What is a software license?

Software License is a certificate of the right to use software. A legal software license has the following characteristics:


1. Licensed functions


A certificate that corresponds to licensing a set of functions. All software functions within the licensing scope can be activated.


2. Licensed period


A license has a validity period. Only a license within its validity period can activate the software.


3. Licensed individual devices


To prevent any loss caused by license leakage, each independent device has its own unique license, and the license of one device cannot be used on another device.


4. Group by service


Licenses under the same service category have the same functions, validity period, and other attributes.

Software licenses are generally stored in the device file system in file format.

<span id="What is online licensing"></span>
## What is online licensing

Online licensing is a network distribution method for software certificate. With this mechanism, devices can quickly and safely obtain software licenses through the network.

<span id="Why is online licensing needed"></span>
## Why is online licensing needed

Online licensing is not the only license distribution method. For example, you can still obtain software licenses by means of manual review and by contacting our commercial staff via email. Compared to the manual method, online licensing comes with a more efficient licensing process, balancing both automation and security.

## Online licensing process

An online licensing process is illustrated in the figure below:

<span>![图片](https://p-vcloud.byteimg.com/tos-cn-i-em5hxbkur4/2ad10056d3c340cb9732561e70df72c0~tplv-em5hxbkur4-noop.image) </span>


1. Get authMsg from SDK.


```Plain
   //bef_effect_ai_auth_msg.h
   bef_effect_ai_get_auth_msg( char** buf, int* len)
```



2. Construct a message body and send a request to ByteDance online licensing service.


URL: https://cv\-tob.bytedance.com/v1/api/sdk/tob_license/getlicense

HTTP method: POST

Content format: JSON

Message example:

```Plain
   POST /v1/api/sdk/tob_license/getlicense HTTP/1.1
   Host: cv-tob.bytedance.com
   Content-Type: application/json

   {
       "key": <key>,
       "authMsg": <authMsg>,
       "nonce": <nonce>,
       "timestamp": <timestamp>,
       "digest": <digest>
   }
```


Field explanation:

key : Service ID, corresponding to the service type activated by the user.

authMsg : Verification message, a device\-related identifier generated by SDK.

nonce : Random number.

timestamp : Unix timestamp (the number of seconds that have elapsed since January 1, 1970)

digest : digital signature, as described below.

To guarantee message authority and integrity, HMAC_SHA256 is used as the signature algorithm here.

```Plain
   digest = HMAC_SHA256(<secret>, key + nonce + timestamp + aughMsg)
```


secret : service key, obtained together with key when creating the service.


* : is the string concatenation operation ("a" + "b" = "ab")

3. The licensing server returns the response message


Message example:

```Plain
   //Success
   {
       'data': <base64 encoded license>,
       'digest': <digest>
   }

   //Failure
   {
       'error': <error message>,
       'code': <code>
   }
```


If the request is successful, data is the license content in base64 encoding (to obtain the license content, it is necessary to perform base64 decoding).

Repeat Step 2 for digest = HMAC_SHA256(, data)secret.

If the request fails, error is the error prompt, and code is the corresponding error code. Please refer to common errors or contact us.


4. Set the obtained license into SDK to activate relevant modules.

```Python
def getLicense(key, secret, authMsg):
    payload = {
        "key": key,
        "authMsg": authMsg,
        "nonce": random.randint(0, 999999999),
        "timestamp": int(time.time())
    }
    payload['digest'] = crypto.HMAC_SHA256(secret, bytes(key + str(payload['nonce']) + str(payload['timestamp']) + authMsg).encode('utf-8'))

    url = "https://cv-tob.bytedance.com/v1/api/sdk/tob_license/getlicense"
    headers = {
        'Content-Type': "application/json",
        'cache-control': "no-cache"
    }

    response = requests.request("POST", url, data=json.dumps(payload), headers=headers)
    resp_json=json.loads(response.text)
    print("{}".format(resp_json['data']))
    raw = base64.b64decode(resp_json['data'])
    print('{}'.format(raw))

    a = resp_json['data']
    b = resp_json['digest']
    h = crypto.HMAC_SHA256(secret,a)
    if h == b:
        print("crypto.HMAC_SHA256 match")
    print('getLicense !')
```

```C++
#include <openssl/hmac.h>;
#include <openssl/sha.h>;
#include <curl/curl.h>;

//Aquire HMAC_SHA256, Ditial Signature
std::vector<uint8_t>
HMAC_SHA256(const std::vector<uint8_t>&amp; key
           ,const std::vector<uint8_t>&amp; value)
{
    unsigned int len = SHA256_DIGEST_LENGTH;
    unsigned char hash[SHA256_DIGEST_LENGTH];
    size_t keyLen = key.size();
    size_t valueLen = value.size();

    HMAC_CTX *hmac = HMAC_CTX_new();

    HMAC_Init_ex(hmac, (unsigned char*)key.data(), keyLen, EVP_sha256(), NULL);
    HMAC_Update(hmac, (unsigned char*)value.data(), valueLen);
    HMAC_Final(hmac, hash, &amp;len);
    HMAC_CTX_free(hmac);

    return std::vector<uint8_t>((uint8_t*)hash,(uint8_t*)hash+SHA256_DIGEST_LENGTH);
}
    
// Rewrite binary content into Hexdecimal String in Capital
std::string hexitize(const std::vector<unsigned char>&amp; input, const char* const digits = "0123456789ABCDEF")
{
    std::ostringstream output;

    for (unsigned char gap = 0, beg = input[gap]; gap < input.size(); beg = input[++gap]) {
        output << digits[beg >> 4] << digits[beg &amp; 15];
    }

    return output.str();
}


//Use CURL to request
int request_license(
    const char* key,
    const char* secret,
    const char* authMsg,
    char** license,
    int* size) {

    CURL *curl;
    CURLcode res;
    curl = curl_easy_init();
    std::string readBuffer;

    auto payload_str = _get_request_content(key, secret, authMsg);

    if(curl) {
        curl_easy_setopt(curl, CURLOPT_CUSTOMREQUEST, "POST");
        curl_easy_setopt(curl, CURLOPT_URL, "https://cv-tob.bytedance.com/v1/api/sdk/tob_license/getlicense");
        curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
        struct curl_slist *headers = NULL;
        headers = curl_slist_append(headers, "Content-Type: application/json");
        curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);
        curl_easy_setopt(curl, CURLOPT_POSTFIELDS, payload_str.c_str());
        curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, WriteCallback);
        curl_easy_setopt(curl, CURLOPT_WRITEDATA, &amp;readBuffer);
        res = curl_easy_perform(curl);
    }
    curl_easy_cleanup(curl);

    if (readBuffer.length() > 0) {
        auto ret = json::parse(readBuffer);
        int code = ret["status_code"];
        if (code != 0) {
            std::string msg = ret["error"];
            *license = new char[msg.length()+1];
            memcpy(*license, msg.c_str(), msg.length()+1);
            *size = msg.length();
            return code;
        }

        std::string lic = ret["data"];
        std::string digest = ret["digest"];

        //verify digest
        auto re_hash = HMAC_SHA256(
            Misc::concat(secret, ""),
            Misc::concat(lic, "")
        );
        if (hexitize(re_hash).compare(digest) == 0) {
            vector<uint8_t> lic_b = base64_decode(lic);
            *license = new char[lic_b.size()];
            memcpy(*license, lic_b.data(), lic_b.size());
            *size = lic_b.size();
            return code;
        }

        //digest verified failure, corrupted message
        const char m[] = "Detecting data corruption, please reissue the request.";
        *license = new char[strlen(m)+1];
        *size = strlen(m);
        memcpy(*license, m, (*size)+1);
        return -1;
    }


    *license = nullptr;
    *size = 0;
    return res;  
}
```

|47829 |invalid business |The service has been disabled/suspended. Please contact our commercial personnel. |

|47831 |business expired |The service has expired. Please contact our commercial personnel. |

|47837 |request expired |The request timestamp timestamp has expired. Please check whether the system time is correct. |
