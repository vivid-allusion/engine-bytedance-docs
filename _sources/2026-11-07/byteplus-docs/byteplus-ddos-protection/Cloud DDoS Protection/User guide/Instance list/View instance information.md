To effectively monitor and manage your Cloud DDoS Protection  instances, you can use the instance list page for a centralized view. This page displays key details such as specifications, attack data, and billing status, which helps you make timely decisions like upgrading specifications or renewing subscriptions. This document explains how to find the instance list and understand the information it contains.

<span id="77c8d5fb"></span>
## Prerequisites

You have successfully purchased a Cloud DDoS Protection  instance.

<span id="6072a24c"></span>
## **Procedure**


1. Log in to [Cloud DDoS Protection Console](https://console.byteplus.com/ddos-protection/).

2. On the left side of the page, select **Cloud DDoS Protection**  **\>**  **Instance list**.

3. View purchased instance information.

   
   |Configuration |Description |
   |---|---|
   |Instance name |The name and region of the Cloud DDoS Protection  instance are displayed. The name can be modified. |
   |Instance specifications |Package specifications and details of the instance.<br><br><br>* Click the number of protected IPs to open the protection resource list, where you can view details of protected EIPs.<br><br>* Color key for specification items<br><br>   * Green: Normal<br><br>   * Red: Service suspended due to overdue payment (applies only to postpaid items, such as elastic protection bandwidth)<br><br>   * Gray: not enabled or expired |
   |DDoS attack statistics |You can view the peak value and number of DDoS attacks for the instance. Click **View report** to open the corresponding instance traffic report page. |
   |Expiration time |Displays the instance's effective start and expiration dates, along with its auto\-renewal status. |
   |Billing status |The billing status of the instance, including<br><br><br>* Running<br><br>* Deactivation upon expiration<br><br>* Suspended due to overdue payment (only for postpaid items, such as elastic protection bandwidth) |
   |Billing methods |All current instances are on annual or monthly subscription plans. |
   |Actions |* Click **Add EIP** to navigate to the protection resources page and add an EIP to the corresponding instance. For more details, refer to [Add an EIP to your instance](https://docs.byteplus.com/docs/byteplus-ddos-protection/Add_an_EIP).<br><br>* More actions: Upgrade specifications, renew, enable, or disable auto\-renewal. For more details, refer to [Manage instances](https://docs.byteplus.com/docs/byteplus-ddos-protection/manage_instances). |
