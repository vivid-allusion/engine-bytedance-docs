To enable Cloud DDoS Protection for your Elastic IP (EIP), you must add it to a protection instance. This guide provides step\-by\-step instructions for adding an EIP, which activates the default protection policy and ensures the security and stability of your cloud\-based business.

<span id="bc87f8a5"></span>
## Prerequisites


* You have purchased a Cloud DDoS Protection instance. For instructions on purchasing, refer to [Step 1: Create a Cloud DDoS Protection instance](https://docs.byteplus.com/docs/byteplus-ddos-protection/Get_started_with_Cloud_DDoS_Protection#f147827f).

* You have purchased a BytePlus EIP. For purchase instructions, see [Apply for an EIP](https://docs.byteplus.com/en/docs/eip/Applying-for-an-EIP).


<span id="3b923c2c"></span>
## Procedure


1. Log in to the [Cloud DDoS Protection console](https://console.byteplus.com/ddos-protection/).

2. In the left navigation pane, select **Cloud DDoS Protection \> Protected resource**.

3. At the top of the list, select the Cloud DDoS Protection instance to which you want to add an EIP.

4. Click **Add EIP**, select available EIPs and configure the protection rule group.

   <span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/71bddfb97f3f425e9048528d7df085ca) </span>

   * **Select EIPs to be protected**: Select the EIP to protect from the list.

      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="2">Note      </div>
      

      <div data-tips="true" data-tips-type="default" data-wrapper-indent="2">If no EIPs are available, purchase one from the <a href="https://console.volcengine.com/eip/region:eip+cn-beijing/eips/create">EIP product console</a>.      </div>
      

      The following table describes the parameters for adding an EIP.

      
      |Parameter |Description |
      |---|---|
      |Resource types |Filter resource types associated with EIP to quickly select resources that require protection.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">Note</div><br><br><br><div data-tips="true" data-tips-type="default">If you are adding many resources in the Internet channel, we recommend using the search function. Currently, each Internet channel supports displaying up to 20,000 data entries. Using the search function avoids frequent paging and prevents display issues that can occur with large datasets.</div><br> |
      |Available EIPs |This page lists enabled EIPs in the instance's region that are not yet protected. The number in parentheses indicates the total number of selectable EIPs in the current region. For example, "Available (3)" indicates that there are still 3 EIPs available for selection in the current region. |
      |Selected / Available |This field shows the number of selected EIPs versus the total number of available EIPs in parentheses. For example, "Selected/Available (1/47)" indicates that you have selected 1 of the 47 available EIPs in the current region. |
      

   * **Add a protection rule group**: Apply a protection rule group to the selected resources.

      * If you do not select a protection rule group, the system enables the **default rule group**. The default rule group includes general protection rules generated by the BytePlus DDoS protection engine. These rules are based on extensive data from real\-world attack and defense scenarios and are used to mitigate DDoS attacks on the network and transport layers. For notes on different rule groups, please refer to[ ](https://docs.byteplus.com/docs/byteplus-ddos-protection/Overview_of_protection_policies).

      * You can also associate custom protection rule groups with protected resources. For information on how to create custom protection rule groups, refer to[Create a custom rule group](https://docs.byteplus.com/docs/byteplus-ddos-protection/Create_a_custom_rule_group).

5. Click **Save**.


<span id="e26f5c8d"></span>
## What's next

After an EIP instance is added to a Cloud DDoS Protection instance, you can view and manage protected EIPs in the **Protected Resources** list. For details, refer to [Manage protection resources](https://docs.byteplus.com/docs/byteplus-ddos-protection/Manage_protection_resources).
