To enable HTTPS for a domain name under Advanced DDoS Protection, you must associate it with an SSL certificate. This guide provides step\-by\-step instructions on how to select an existing certificate or upload a new one for your domain to ensure the secure forwarding of HTTPS requests.

<span id="f05bfc53"></span>
## Before you begin


* Add a domain name to be protected. For more details, see [Adding a domain name](https://docs.byteplus.com/en/docs/byteplus-ddos-protection/docs-adding-a-domain-name-to-the-instance).

* Upload an SSL certificate. For more details, see [Uploading an SSL certificate](https://docs.byteplus.com/en/docs/byteplus-ddos-protection/docs-uploading-an-ssl-certificate).


<span id="0343b3b5"></span>
## Procedure


1. Log in to the [BytePlus Advanced DDoS Protection Console](https://console.byteplus.com/ddos-protection/advance/instances).

2. In the left\-side navigation pane, choose **Advanced DDoS Protection** \> **Provisioning**.

3. On the **Website config** tab, click the edit icon for the domain name.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aae051f16d614a1b98cf7eff9bb33e2e~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">Tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If you do not have a certificate to add, upload a new one. For more details, see <a href="https://docs.byteplus.com/en/docs/byteplus-ddos-protection/docs-uploading-an-ssl-certificate">Uploading an SSL certificate</a>.   </div>
   

4. Select a certificate or upload a new one.

5. Click **OK**.
