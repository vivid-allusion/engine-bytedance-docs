After creating an Advanced DDoS Protection instance, you can view the basic information of the instance in **Instance list**, including instance name (which is editable), ID, IP, specifications, expiration time, and status.

<span id="f7b31dbb"></span>
## **Before you begin**

Create an instance of BytePlus Advanced DDoS Protection.

<span id="0aebf671"></span>
## **Procedure**


1. Log in to the [BytePlus Advanced DDoS Protection Console](https://console.byteplus.com/ddos-protection/advance/instances).

2. In the left\-side navigation pane, choose **Advanced DDoS Protection** \> **Instance list**.

3. View the instance information.

   
   |**Configuration** |**Description** |
   |---|---|
   |Instance name/ID |The name, ID, and region of the instance. The instance name is editable. |
   |Instance specifications |The protection capability of the instance. |
   |Instance IP |The IP address of your Advanced DDoS Protection instance. |
   |Expiration time |The start time and expiration time of the instance. |
   |Status |The running status of the instance.<br><br><br>* Running: The instance functions normally.<br><br>* To be discontinued: The instance is approaching its expiration date.<br><br>* Expired: The service is not accessible, and your settings and data will be deleted. |
   |Billing model |A service for which you pay on a monthly or yearly basis. |
   |Action |* Click **Protection settings** to set policies for the selected instance.<br><br>* Click `···`\> **Renew** to extend the service period of the instance beyond its current expiration date. |
