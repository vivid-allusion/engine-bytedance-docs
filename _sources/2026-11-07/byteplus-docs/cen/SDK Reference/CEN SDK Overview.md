<span id="VGxHMA8j"></span>
## SDK Introduction

The CEN SDK encapsulates all the APIs of the CEN  (see [CEN API overview](https://docs.byteplus.com/en/docs/cen/API-Reference-03)), uses an access key (AK) to identify the caller's identity, and provides features like automatic signing. This facilitates creation and management of resources through APIs.
