## Overview

Cloud Enterprise Network (CEN) enables you to create a fully meshed networking scenario where multiple Virtual Private Clouds (VPC) can communicate with each other. When used in conjunction with the Direct Connect service, it can also establish a fully interconnected network between your on\-premises and cloud environments.

This topic describes how to use CEN to quickly achieve private connectivity between your VPCs.
