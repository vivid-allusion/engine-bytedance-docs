Cloud Enterprise Network (CEN) is billed based on the inter\-region bandwidth (i.e., the bandwidth of the bandwidth package).

CEN is billed based on inter\-region bandwidth allocated by CEN bandwidth packages. You must use CEN bandwidth packages if you want to use CEN to allow instances to communicate across Regions. No CEN bandwidth package is needed for intra\-region communication. This means that CEN does not charge any fees for intra\-region communication.

## Metering method

CEN cross\-region bandwidth packages support the Subscription billing type. For detailed information, see [Subscription](https://docs.byteplus.com/en/docs/cen/Subscription).

## Specification changes

During the use of CEN, you can modify the bandwidth size of the bandwidth package based on business needs. For billing details after the bandwidth modification, see [Specification changes](https://docs.byteplus.com/en/docs/cen/Specification-changes).

## Expiration

After a CEN Subscription bandwidth package expires, its status and the restricted operations on resources under your account vary depending on the expiration period. For details, see [Expiration](https://docs.byteplus.com/en/docs/cen/Expiration).
