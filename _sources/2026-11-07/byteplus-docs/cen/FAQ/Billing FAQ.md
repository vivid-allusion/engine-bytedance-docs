## Is CEN a charged service?

CEN is billed based on the inter\-region bandwidth of the bandwidth package. You can decide whether to purchase a bandwidth package based on the regions where the network instances that need to interconnect are located.

* If you only need to enable interconnection between network instances within the same region, CEN is free of charge.

* If you need to enable interconnection between network instances across different regions, you must purchase a bandwidth package. Bandwidth packages support the Subscription billing method. For details, see [Subscription](https://docs.byteplus.com/en/docs/cen/Subscription).

## How is billing handled for cross\-account connectivity in CEN?

Cross\-account connectivity in CEN includes both cross\-account same\-region and cross\-account cross\-region network instance interconnection. CEN is billed based on the inter\-region bandwidth of the bandwidth package.

* Cross\-account interconnection between network instances within the same region does not require a bandwidth package and is therefore free of charge.

* Cross\-account, cross\-region network interconnection requires purchasing a corresponding bandwidth package and allocating inter\-region bandwidth. Therefore, the bandwidth package fees apply. For details, see [Subscription](https://docs.byteplus.com/en/docs/cen/Subscription).
