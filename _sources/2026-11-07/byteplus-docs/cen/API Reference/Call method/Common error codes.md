This topic describes the common error codes you may encounter when calling the Cloud Enterprise Network (CEN) API. For the platform's full list of common error codes, see [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).


|<div style="text-align: center"><br>HttpCode</div><br> |Error codes |Error |Description |
|---|---|---|---|
|<div style="text-align: center"><br>400</div><br> |MissingParameter |The request is missing a required parameter. Ensure that you have supplied all the required parameters. |This request does not contain required parameters. Ensure all required parameters are provided when initiating the request. |
|<div style="text-align: center"><br>400</div><br> |InvalidParameter |A parameter specified in the request is not valid, unsupported or cannot be used. |The request contains invalid or unsupported parameters. |
|<div style="text-align: center"><br>500</div><br> |InternalError |Request failed with internal server error. |Internal system error. |
