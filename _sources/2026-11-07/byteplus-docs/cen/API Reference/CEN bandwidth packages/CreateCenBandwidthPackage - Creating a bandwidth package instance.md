Call the CreateCenBandwidthPackage API to create a bandwidth package.

[去调试](https://api.byteplus.com/api-explorer/?action=CreateCenBandwidthPackage&groupName=%E5%B8%A6%E5%AE%BD%E5%8C%85&serviceCode=cen&version=2020-04-01)

## Request parameters

The following only details request parameters specific to this API and key common parameters. More information can be found in [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).

**Action ** string必选 `Example: CreateCenBandwidthPackage`

Action to execute. Set the value to CreateCenBandwidthPackage.

**Version ** string必选 `Example: 2020-04-01`

The API version. Value: 2020\-04\-01.

**Bandwidth ** integer`optional` `Example: 2`

Peak bandwidth of the bandwidth package. Valid range: 2 to 10000 Mbps. Default: 2 Mbps.

**Period ** integer`optional` `Example: 1`

The purchase duration of the bandwidth package, with a default value of 1. Valid values:

* When `PeriodUnit` is set to Month, valid values are 1 to 9, 12, 24, and 36.

* When `PeriodUnit` is set to Year, valid values are 1 to 3.

**CenBandwidthPackageName ** string`optional` `Example: cbp-test`

Name of the bandwidth package.

* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: periods (.), underscores (_), and hyphens (\-).

* Must be 1 to 128 characters.

* If left blank, it defaults to the Bandwidth Package ID.

**BillingType ** integer`optional` `Example: 1`

Billing method of the bandwidth package. Valid values:

* 1 (default): Subscription.

* 4: Pay\-as\-you\-go \- Pay\-by\-95\-peak.

**Description ** string`optional` `Example: namedesc`

Description of the bandwidth package.

* Must start with a letter, number, or Chinese character. May include letters, numbers, Chinese characters, and the following symbols: commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), full\-width commas ( ， ), and full\-width periods ( 。 ).

* Must be 0 to 255 characters.

* If left blank, it defaults to an empty string.

**CenId ** string`optional` `Example: cen-7qthudw0ll6jmc****`

The ID of the CEN instance to bind.

You can call the [DescribeCens](https://docs.byteplus.com/en/docs/cen/DescribeCens) API to query the CEN instance ID.

**ClientToken ** string`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

The Client Token that is used to ensure the request idempotency.

* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If you do not set this parameter, idempotency check is not performed.

**PeriodUnit ** string`optional` `Example: Month`

Billing cycle of the bandwidth package. Valid values:

* Month (default)

* Year.

**LocalGeographicRegionSetId ** string必选`Example: China`

The local geographic region ID for CEN interconnection. Valid values:

* China: Mainland China.

* Asia: Asia Pacific.

**PeerGeographicRegionSetId ** string必选 `Example: China`

The peer geographic region ID for CEN interconnection. Valid values:

* China: Mainland China.

* Asia: Asia Pacific.

**Tags.N.Key ** string`optional` `Example: key1`

The tag key of the custom tag.

* N represents the serial number of the tag key. Valid range: 1 to 20.

* Separate multiple tag keys with ampersands (&).

* Must not start with `volc:` or `sys:` in any case form.

* Must be 1 to 128 characters. May include characters (any language), numbers, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), hyphens (\-), and at signs (@).

* If a tag key contains leading or trailing spaces, the system will automatically delete them.

**Tags.N.Value ** string`optional` `Example: value1`

The tag value of the custom tag.

* N represents the serial number of the tag value. Valid range: 1–20.

* Separate multiple tag values with ampersands (&).

* Must be 0 to 256 characters. If left blank, this parameter defaults to an empty string.

* The following characters are allowed: characters from all languages, numbers, spaces ( ), underscores (_), periods (.), colons (:), forward slashes (/), equal signs (=), plus signs (+), hyphens (\-), and the at symbol (@).

* Case\-sensitive.

* If a tag value starts or ends with a space, the system will automatically delete them.

**LineOperator ** string`optional` `Example: ChinaUnicom`

The provider of cross\-border bandwidth packages.

* If the values of `LocalGeographicRegionSetId` and `PeerGeographicRegionSetId` are the same, this parameter is not supported.

* If the values of `LocalGeographicRegionSetId` and `PeerGeographicRegionSetId` are different, the values are as follows:

   * ChinaUnicom (default): China Unicom.

   * ChinaTelecom: China Telecom.

**ProjectName ** string`optional` `Example: default`

Name of the project to which the bandwidth package belongs. If left blank, it defaults to default.
