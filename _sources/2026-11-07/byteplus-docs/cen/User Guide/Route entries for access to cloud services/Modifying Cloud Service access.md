## Scenarios

By modifying the Cloud Service Access configuration, you can update its published settings and description.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">The feature that publishes cloud service routes to VPC instances within the same region is in Beta. If you need to use it, please contact your account manager.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the top navigation bar, select the target project.

3. Click the target CEN instance name.

4. On the **Cloud Services** tab, click **Modify** on the right side of the target access to cloud service entry to modify the advertisement scope or description.

5. Click **Save** to complete the action.
