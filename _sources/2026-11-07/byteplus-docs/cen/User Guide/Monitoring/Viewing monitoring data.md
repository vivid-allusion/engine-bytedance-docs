You can view monitoring data through the Cloud Enterprise Network (CEN) console, Bandwidth Package console, or CloudMonitor console. 

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">IAM users may not be able to directly view monitoring data of the CEN Product. To enable viewing, ensure cloud monitor permission has been authorized to the IAM user. For specific actions, see <a href="https://docs.byteplus.com/en/docs/cen/Monitoring-faq#.5Li65LuA5LmI5a2Q55So5oi35peg5rOV5p-l55yL55uR5o6n5pWw5o2u77yf">Why IAM users cannot view monitoring data</a>.</div>


<span id=".5LqR5LyB5Lia572R5o6n5Yi25Y-w5p-l55yL"></span>
## View via CEN console


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the top navigation bar, select the target project.

3. Click the monitoring icon in the row of the target CEN instance.

4. Switch between the **Inter\-region bandwidth** or **CEN bandwidth package** tabs as needed. Select the target resource to view the corresponding monitoring data.


<span id=".5bim5a695YyF5o6n5Yi25Y-w5p-l55yL"></span>
## View data via the Bandwidth Package console


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the left navigation pane, select **Bandwidth Package**.

3. In the top navigation bar, select the target project.

4. Click the monitor icon in the row of the target bandwidth package.

5. On the monitoring data page, you can view the monitoring metric charts of the target Bandwidth Package.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the target bandwidth package is not bound to any CEN instance, then the monitoring metric charts for that bandwidth package will display no data.   </div>
