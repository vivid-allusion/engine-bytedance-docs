## Scenarios

You can perform this operation to delete a Cloud Enterprise Network (CEN) instance when it is no longer needed.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* The CEN instance must not have any network instances attached. If attached, first [detach the network instance](https://docs.byteplus.com/en/docs/cen/Network-instances-02).

* The CEN instance must not be bound to any bandwidth package. If attached, first [disassociate the bandwidth package](https://docs.byteplus.com/en/docs/cen/CEN-bandwidth-packages-02#.6Kej57uR5bim5a695YyF).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the top navigation bar, select the target project.

3. Click **Delete** on the right side of the target CEN Instance.

4. Click **Delete** to complete the action.
