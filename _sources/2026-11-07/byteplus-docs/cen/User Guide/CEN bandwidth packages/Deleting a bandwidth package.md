## Scenarios

You can delete a bandwidth package when it is no longer needed.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* The bandwidth package is billed on a pay\-as\-you\-go basis, or its subscription term has expired. Subscription CEN bandwidth packages cannot be deleted before expiration. To release them early, see [Unsubscription notes](https://docs.byteplus.com/en/docs/cen/Unsubscription).

* The bandwidth package has no inter\-region bandwidth allocated. If already allocated, first [Delete](https://docs.byteplus.com/en/docs/cen/Inter-region-bandwidth-03).

* This bandwidth package is not associated with a CEN instance. If already associated, first [Detach](https://docs.byteplus.com/en/docs/cen/CEN-bandwidth-packages-02#.6Kej57uR5bim5a695YyF).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the left navigation tree, select **Bandwidth Package**.

3. In the top navigation bar, select the target project.

4. Click  **··· \> Delete** to the right of the target Bandwidth Package.

5. Click **Delete** to complete the action.
