## Scenarios

If the allocated inter\-region bandwidth between two regions is insufficient, you can follow this topic to modify it.

## Instructions

For BytePlus accounts blocked by the line operator due to illegal use of cross\-border services, modifying the cross\-border Bandwidth Package is not supported.

## Procedure

1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the top menu bar, select the target project.

3. Click the target CEN instance name.

4. Select the **Inter\-region bandwidth** tab.

5. In the **Inter\-region bandwidth** section, click **Modify** bandwidth on the right side of the target inter\-region bandwidth.

6. Modify the bandwidth value of the target inter\-region bandwidth.

   > **tip**

   > If configured through bandwidth package, the modified bandwidth value cannot exceed the allocatable bandwidth of the associated bandwidth package. Otherwise, the modification will fail.

7. Click **Save** to complete the action.
