## Scenarios

When you no longer require cross\-region connectivity between network instances in two specific regions, you may delete the configured inter\-region bandwidth.

<span id=".5pON5L2c6K-05piO"></span>
## Action description

After deleting the inter\-region bandwidth, the attached network instances in the corresponding regions will no longer be able to communicate across regions.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CEN console](https://console.byteplus.com/cen/EnterpriseNetwork).

2. In the top navigation bar, select the target project.

3. Click the target CEN instance name.

4. Select the **Inter\-region bandwidth** tab.

5. In the **Inter\-region bandwidth** zone, click **Delete** on the right side of the target inter\-region bandwidth

6. Click **Delete** to complete the action.
