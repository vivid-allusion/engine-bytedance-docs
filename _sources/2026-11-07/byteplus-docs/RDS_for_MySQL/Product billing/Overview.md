This topic explains the billing methods, life cycle and prices of RDS for MySQL.

<span id="billing-method"></span>
## Billing method


|Billing method |**Description** |
|---|---|
|Yearly/Monthly Subscription |* Fees are paid upfront when creating an instance.<br><br>* The price is lower than that of post paid billing, making this option suitable for meeting long\-term needs.<br><br>* Yearly/monthly subscription instances cannot be released, and do not currently support unsubscription. |
|Pay\-As\-You\-Go Billing |* A charge order is generated every hour, and the fee is deducted from the BytePlus account according to the instance specification at the time of order generation.<br><br>* The instance can be released when no longer needed, which saves costs and meets short\-term needs. |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="tip">For more information about prices, refer to <a href="https://docs.byteplus.com/en/docs/RDS_for_MySQL/charge_items_and_price">Billing items and prices</a>.</div>


<span id="instance-life-cycle"></span>
## Instance life cycle

The billing method determines how the MySQL instance life cycle is calculated, where:


* **Post paid billing**: The life cycle of an instance starts from the time when you create the instance successfully to the time when you release it.

* **Yearly/monthly subscription**: The life cycle of the instance starts from the time when you create the instance successfully, and the instance will be released automatically when it expires.
