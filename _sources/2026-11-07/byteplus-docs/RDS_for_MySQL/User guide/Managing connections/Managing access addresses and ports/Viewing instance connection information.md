MySQL provides public and private addresses for you to access MySQL instances. This topic describes how to view public and private addresses and ports.

<span id="prerequisites"></span>
## Prerequisites


* The instance has been created and is in the **Running** status.For specific operations, refer to [Creating an instance](https://docs.byteplus.com/en/docs/RDS_for_MySQL/creating_an_instance_1).

* If you must view a public address, you must enable internet access for the connection endpoint. For the steps to enable internet access, refer to [Enabling internet access](https://docs.byteplus.com/en/docs/RDS_for_MySQL/enabling_internet_access).


<span id="procedure"></span>
## Procedure


1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If no project is set, you should select the option <strong>All resources</strong> at this step.</div>



3. Click **Instances** in the left\-side navigation bar.

4. Click the name of the target instance on the **Instances** page to go to the **Summary** page.

5. In the **Endpoints** area of the **Connectivity** tab, click **View** in the **Actions** column of the target endpoint to view the public and private domains, IP addresses, and ports of the endpoint.
