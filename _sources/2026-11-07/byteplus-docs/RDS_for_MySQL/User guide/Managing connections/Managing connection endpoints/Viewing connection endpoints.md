This topic introduces the operation steps for viewing the specific configuration of the connection endpoint.

<span id="background"></span>
## Background

On the details page of the connection endpoint, the connection information of the private network and the public network of the connection endpoint, the endpoint information, and the associated node information are displayed.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Instances that have not enabled the database proxy function do not support the automatic addition of new nodes function. Therefore, on the connection endpoint details page of an instance that has not enabled the database proxy function, the activation status of the automatic addition of new nodes function is not displayed.</div>


<span id="steps"></span>
## Steps


1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the top menu bar on the upper left, select the project and region to which the instance belongs.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project to which the instance belongs is not set, this operation should select the project as <strong>All resources</strong>.   </div>
   

3. Click **Instances** on the left navigation bar.

4. On the **Instances** page, click the name of the target instance to enter the instance.

5. In the **Instance topology** area below the **Connectivity** tab, click **View** on the target connection endpoint card to view the details of the connection endpoint.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">On the connection endpoint details page, in addition to viewing the configuration information of the connection endpoint, you can click the <strong>Edit</strong> button in the lower right corner of the page to enter the <strong>Edit endpoint</strong> page. For detailed information on editing the connection endpoint, refer to <a href="https://docs.byteplus.com/en/docs/RDS_for_MySQL/editing_connection_endpoints">Editing connection endpoints</a>.   </div>
