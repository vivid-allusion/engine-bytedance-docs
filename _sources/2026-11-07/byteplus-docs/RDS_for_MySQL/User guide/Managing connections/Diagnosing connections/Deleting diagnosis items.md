This topic describes the procedure for deleting connection diagnosis items for an RDS for MySQL instance.

<span id="prerequisites"></span>
## Prerequisites

Diagnosis items have been added to the MySQL instance and it has been confirmed that the diagnosis item is no longer needed.

<span id="procedure"></span>
## Procedure


1. Log on to the [RDS for MySQL Console](https://console.byteplus.com/db/rds-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region to which the instance belongs.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project to which the instance belongs has not been set, for this operation, you should select the project as <strong>All Resources</strong>.   </div>
   

3. Click **Instances** on the left navigation bar.

4. On the **Instances** page, click the name of the target instance to enter the **Summary** tab.

5. On the **Summary** page, click the **Connectivity** tab to enter the **Connectivity** page.

6. In the **Endpoints** area of the **Connectivity** page, click **Connection diagnosis** to enter the **Connection diagnosis** page.

7. On the **Connection diagnosis** page, after selecting the **Connection method**, click **Delete** in the **Actions** column of the target diagnosis item.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can also select multiple diagnosis items in the <strong>Diagnosis items</strong> list, and then click <strong>Delete</strong> at the lower left corner of the list.   </div>
   

8. In the pop\-up dialog box, click **OK** to complete the deletion of the diagnosis items.
