This topic describes how to view the list of instances for which the cross\-regional backup feature is enabled.

## Background

The cross\-regional backup instance list displays instances for which the cross\-regional backup feature is or has been enabled. The list shows the instance name and ID, database version, running status, cross\-regional data backup status, cross\-regional binlog backup status, latest cross\-regional backup region, latest service enable time, and number of days to retain backup. You can modify the cross\-region backup configuration of an instance in the **Actions** column of the **Cross\-regional backup instances** list. For details about modifying the cross\-region backup configuration of an instance, refer to [Modifying cross-region backup configuration](https://docs.byteplus.com/en/docs/RDS_for_MySQL/Modify_cross-region_backup_configuration).

## Procedure

1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the top menu bar on the upper left, select the region.

3. On the left navigation bar, select **MySQL** \> **Backups**.

4. Click the **Cross\-region backups** tab at the top of the page to view the list of cross\-regional backup instances in the current region.
