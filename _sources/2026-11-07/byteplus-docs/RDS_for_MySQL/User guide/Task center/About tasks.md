In order to facilitate instance management and improve operation and maintenance efficiency, RDS for MySQL provides a task center to record and display various management operations performed on MySQL instances. These operations are named tasks in the task center with the corresponding Open API name of the operation.

In the task list, you can view the instance associated with the task, task status, task progress, task creation time, task start and end time, and time consumption. For some tasks, you can also postpone the execution time and cancel the task.
