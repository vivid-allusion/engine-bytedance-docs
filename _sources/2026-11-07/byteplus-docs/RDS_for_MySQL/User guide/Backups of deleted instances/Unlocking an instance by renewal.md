After a MySQL instance is locked due to expiration or arrears, you can unlock the instance by renewal in **Backup of deleted instance** within 7 days. The instance will be released upon expiration, and you can also renew the instance for unlocking.

<span id="procedure"></span>
## Procedure

For more information on how to renew an instance, refer to [Instance renewal](https://docs.byteplus.com/en/docs/RDS_for_MySQL/renewal_management).


1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. Select the region in the upper\-left corner of the top menu bar.

3. Click **Instance list** in the left\-side navigation bar.

4. On the **Instance list** page, click  **... \> Renewal**.

5. Jump to the Renewal management page to confirm the information of the instance to be renewed.

6. Select the renewal time and amount.

7. Click **To pay** to pay the fees.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="tip">You can also go to the <a href="https://console.byteplus.com/finance/renew">Renewal management</a> page directly to find the target instance for renewal, and the instance will be restored to the normal status after renewal.</div>
