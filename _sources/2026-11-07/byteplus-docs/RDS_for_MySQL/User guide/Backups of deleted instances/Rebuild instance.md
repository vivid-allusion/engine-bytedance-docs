This topic introduces the operation steps for rebuilding an instance from the backup of deleted instances.

## Precautions

* The type, database version, backup settings, table name case settings, and time zone settings of the restored instance are the same as those of the original instance.

* The data information in the restored instance is consistent with the information at the backup point in time.

* The restored instance contains the account information at the point in time the backup was used.

* If you want to create a pay\-as\-you\-go instance, make sure your account balance is greater than or equal to 100 USD.

* If you want to create a yearly or monthly subscription instance, make sure your account balance is sufficient to pay the order amount.

## Prerequisites

The instance is deleted and the status of the deleted instance backup is **Recycled**.

## Procedure

1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the top menu bar, select the region.

3. In the left navigation bar, choose **MySQL** \> **Backups**.

4. Click the **Backups** of deleted instances page at the top of the page, and in the Backups of deleted instances list, click the **Rebuild instance** of the target instance **Action** column.

5. On the **Data recovery** page, after setting the following parameters for the new instance, click **Confirm order**.

Naming rules are as follows:<br><br><br>* The length should be between 1 and 128 characters.<br><br>* It cannot start with a digit or hyphen (\-).<br><br>* The name consists of Chinese characters, English letters, digits, underscores (_), and hyphens (\-). |
   |Storage type<br><br> |Select the storage type for the instance. RDS for MySQL offers three storage types: **Local SSD, FlexPL cloud disk**, and **PL0 cloud disk**. If the storage type of the original instance is different, the supported storage types when restoring to the new instance are different. The specific rules are as follows:<br><br><br>* If the original instance storage type is local SSD or FlexPL, changing the storage type is not supported.<br><br>* If the original instance storage type is PL0, you can select either FlexPL or PL0. |

CPU utilization is maximized through resource reuse, with high cost performance.<br><br>* **Dedicated type**: Fully exclusive use of allocated CPU, memory, and storage resources, with stable performance, not affected by other instances in the physical machine.<br><br>* **General type (ARM)** : A general type based on ARM architecture.<br><br><br>> **tip**<br><br><br><br>* > If the storage type of the original instance is Cloud ESSD PL0 or Cloud ESSD FlexPL, only **General type** is available for the restored new instance.<br><br><br>* > For details about different specifications, refer to [Product specifications](https://docs.byteplus.com/en/docs/RDS_for_MySQL/product_specifications).<br> |

You can manually adjust the assignment as needed. The default availability zone is not fixed and is periodically adjusted by RDS for MySQL.<br> |
   |Storage space |Storage space includes data space, system file space, Binlog file space, and transaction file space. Enter a storage space in the range of 20 GB to 32,000 GB, with a step size of 10 GB. Select a value based on your business needs.<br><br>> **tip**<br><br><br>> Different storage types and specifications have different storage space value ranges.    |Associate allowlist |Set the way the instance associates with the allowlist, **Immediately** or **Later** is optional. |
   |Allowlists |If the way to select the associating allowlist is Immediate, you need to associate the allowlist for the instance on the **Create instance** page. You can also select the **MySQL 5.7 asynchronous parameter template ** or **MySQL 5.7 high performance parameter template**.<br><br>* You can click **View parameter template** on the right to go to ** Parameter template** page to create a custom template.    |Subscription duration |If you choose subscription, you need to select the purchase duration. Support monthly purchase (can purchase 1~9 months) and yearly purchase (can purchase 1~3 years). |
   |Automatic renewal |If you choose **Subscription**, you can check the box of **Automatic renewal**, and the platform will automatically renew the subscription on a monthly basis before the expiration of the instance, so there is no need to renew the subscription manually. You can also modify the renewal configuration at [Renewal Management](https://console.byteplus.com/finance/renew/). |

6. Complete the subsequent steps based on the billing type selected.

   1. If **Pay\-as\-you\-go** is selected: on the **Confirm order** page, confirm the order details, read and check **Database Products and Services Terms** and **Unsubscription rules**, and click **Buy now** to restore the backup to a new instance.

   2. If **Subscription** is selected:

      * On the **Confirm order** page, confirm the order details, read and check the **Database Products and Services Terms** and **Unsubscription rules**, and click **Submit the order**.

      * On the **Confirm order information** page, reconfirm the order information, and click **Next step**.

      * On the **Submit payment information** page, confirm the payment details and select the payment method, click **Go to payment**, and complete the payment according to the prompts to restore to a new instance.

   > If you are using a root account, point your mouse to ![](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_a8e8b2ede59e969d5e0f5f63054bb5f5.png)to the right of the Configuration fee at the bottom of the page to view the fee details for purchasing the instance with the current configuration, including the original price, discount, and discounted price. If you are using a IAM account and do not have the policy that allows the QueryDiscountPrice action, you can only view the original price. For more information about policies, refer to [About policies](https://docs.byteplus.com/en/docs/byteplus-platform/docs-managing-policies).
