This topic describes how to view the instance topology.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.</div>



3. Click **Instances** in the left navigation bar.

4. Click the name of the target instance on the **Instances** page to go to the **Summary** page.

5. You can view details of instance nodes (Primary Node, Secondary Node, and Read‑only Node) and **connection topology** in the instance topology area on the **Connection Management** tab.
