After associating tags with an instance, you can enable tags in the bill and apply the corresponding tags to the bill details. This topic describes how to split bills for instances by tags.

<span id="prerequisites"></span>
## Prerequisites

Tags have been associated with instances. For more information, refer to [Associating a tag](https://docs.byteplus.com/en/docs/RDS_for_MySQL/associating_a_tag).

<span id="precautions"></span>
## Precautions

You can enable up to 100 custom tags in the Billing Center.

<span id="procedure"></span>
## Procedure


1. Log on to the [Billing center console](https://console.byteplus.com/finance/overview).

2. On the left navigation bar, click **Bill management**\>**Fee tag** to go to the **Fee tag** page.

3. In the tag list of the **Fee tag** page, locate the target tag.

4. In the **Action** column of the target tag, click the switch to enable the tag.
