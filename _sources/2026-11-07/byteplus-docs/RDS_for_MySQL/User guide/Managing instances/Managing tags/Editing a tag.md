After associating a tag for a specified instance, you can modify the tag key or tag value at any time according to business needs. This topic describes how to edit tags.

<span id=".5Li65Y2V5Liq5a6e5L6L5L-u5pS55oiW6Kej57uR5qCH562-"></span>
## Modifying or disassociating tags for a single instance


1. Log on to the [RDS for MySQL console](https://console.byteplus.com/db/rds-mysql).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.</div>



3. In the left navigation bar, choose **MySQL** \> **Instances**.

4. Find the target instance in **Instances** page and click on the edit icon in the **Tag** column.

   You can also click the name of a target instance, and in the **Summary** section, click the edit icon in the **Tag** row.

5. Set the **Tag key** or **Tag value** in the **Edit tag** pop\-up window. Follow the tag setting rules. For details, refer to [Tag setting rules](https://docs.byteplus.com/en/docs/RDS_for_MySQL/associating_a_tag#.5qCH562-6K6-572u6KeE5YiZ).

6. Click **OK**.
