## General internet scenarios

As the ultimate storage location of data, MySQL provides a Read/Write Splitting architecture type with one primary node and multiple read\-only nodes. This supports the elastic expansion of data read capability according to business needs, and shares the data read workload of the primary node among the other nodes, providing an effective solution for business scenarios with more read than write requests.

<span id="e-commerce-scenarios"></span>
## E\-commerce scenarios

Aiming to address the high concurrency and high performance needs of new retail E\-commerce scenarios, RDS for MySQL provides elastic, stable and high\-performance database services to deal with the storage, query, and management of relational data with strong correlations, with the flexibility to meet the capacity demands businesses at different stages and improve their resource utilization rates.

<span id="game-scenarios"></span>
## Game scenarios

To support quick server launching and batch rollback in game scenarios, RDS for MySQL offers elastic expansion and rich backup recovery functions. It also provides deployment expansion and point\-in\-time recovery capabilities precise to the minute.
