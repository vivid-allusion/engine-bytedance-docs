This topic describes the test indexes used to stress test RDS for MySQL.

<span id=".5rWL6K-V5oyH5qCH"></span>
## Test metrics


* **Test Metrics TPS (Transaction Per Second)** : The number of transactions executed by the database per second.

* **QPS (Query Per Second)** : The number of SQL statements that the database executes per second, including `INSERT`, `SELECT`, `UPDATE`, and `DELETE` statements.
