RDS for MySQL is an elastic and reliable online relational database service for BytePlus based on the open\-source MySQL database. This topic describes the process of creating, configuring, and connecting to an RDS for MySQL instance to help you quickly get started.

<span id=".5YeG5aSH5bel5L2c"></span>
## Preparation

A BytePlus account has been registered with real name authentication completed. For account registration and real name authentication, refer to [How to Register an Account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account) and [Real-name authentication](https://docs.byteplus.com/en/docs/byteplus-platform/docs-real-name-registration)。

<span id=".5L2_55So5rWB56iL"></span>
## Usage process


1. **Select architecture type**: Select the architecture type: RDS for MySQL supports high\-availability instances and adopts the classic high\-availability architecture of one primary node and one secondary node, making it suitable for the internet, Internet of Things, retail and e\-commerce, logistics, gaming, and other sectors.

2. **Select instance specification**: The parameters of an instance specification include the number of CPU cores, memory size, and maximum number of connections. For more information, refer to [Instance specifications](https://docs.byteplus.com/en/docs/RDS_for_MySQL/product_specifications).

3. **Create instance**: Determine the instance version, instance specification, and parameters. For specific procedures, refer to [Creating an instance](https://docs.byteplus.com/en/docs/RDS_for_MySQL/create_instance).

4. **Create allowlist**: Only devices added to an allowlist that is associated with an instance can access the instance. For details, refer to [Creating an allowlist](https://docs.byteplus.com/en/docs/RDS_for_MySQL/creating_an_allowlist) and [Associating an instance with an allowlist](https://docs.byteplus.com/en/docs/RDS_for_MySQL/associating_instances_to_allowlists).

5. **Creating a database and an account**: Create the relevant databases and accounts based on business needs, and configure account permissions. For more information, refer to [Creating databases and accounts](https://docs.byteplus.com/en/docs/RDS_for_MySQL/creating_databases_and_accounts).

6. **Connecting to an instance:**  Multiple methods are supported for connecting to instances. You can connect to the instance using a client or a command line. For specific connection procedures, refer to [Connect to the instance](https://docs.byteplus.com/en/docs/RDS_for_MySQL/connect_instance).
