This topic describes the kernel minor version release notes for RDS for MySQL.

> **tip**

> The lifecycle of a kernel minor version for BytePlus RDS for MySQL is at least six months and has no fixed duration. After six months, RDS for MySQL temporarily ignores the upgrade policy settings for the kernel minor version and may retire historical minor versions as needed.

**MySQL 8.0 kernel minor version release notes**

> **warning**

> BytePlus RDS for MySQL previously released a version series based on MySQL Community 8.0.26, which is now in maintenance mode and no longer receives feature updates. You can manually upgrade to the new version mentioned above. The new version incorporates changes from the official community's 8.0.27 and later versions, adds a series of features such as thread pooling, kernel health detection, and hidden primary keys (GIPK), and fixes bugs found in earlier versions. For details on the version upgrade, refer to [Manually upgrading instance kernel minor versions](https://docs.byteplus.com/en/docs/RDS_for_MySQL/upgrading_instance_kernel_minor_version).

> When upgrading from previous versions based on MySQL Community 8.0.26 to the new version, note that MySQL began gradually replacing `utf8` with `utf8mb3` in version 8.0.29. For details, refer to [MySQL 8.0.29 Character Set Support](https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-29.html#mysqld-8-0-29-charset). This may have the following impacts on users:

* > Query results for tables in the Information Schema will use utf8mb3 instead of utf8. Connector/Net versions prior to 8.0.28 do not support utf8mb3 and will report an error: `Character Set 'utf8mb3' is not supported by .Net Framework`. If your application uses Connector/Net, upgrade Connector/Net to version 8.0.28 or later before the version upgrade. For details, refer to [MySQL 8.0.29 Character Set Support](https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-29.html#mysqld-8-0-29-charset) and [Changes in MySQL Connector/NET 8.0.28](https://dev.mysql.com/doc/relnotes/connector-net/en/news-8-0-28.html).

* > If you validate the MySQL encoding format in the client program, adjust the validation method to support `utf8mb3`.
