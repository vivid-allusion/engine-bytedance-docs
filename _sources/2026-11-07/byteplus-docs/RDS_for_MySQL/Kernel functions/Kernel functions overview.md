RDS for MySQL uses a deeply optimized MySQL kernel based on BytePlus, fully compatible with all the functions of native MySQL, and integrates advanced features such as enterprise\-level stability, reliability, backup and recovery, data security, and performance optimization. This topic lists the main kernel functions provided by RDS for MySQL in each version.

## Kernel function list
