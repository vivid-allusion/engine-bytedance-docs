Call the ModifyDBInstanceTDE API to enable the Transparent Data Encryption (TDE) feature for an instance.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Asynchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* MySQL 8.4 instances do not support SSL encryption.

* To enable the TDE function, the instance must be restarted.

* Once the TDE function is enabled, it cannot be disabled.

* Only double\-node instances support the TDE feature.
