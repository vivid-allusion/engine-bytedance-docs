This topic describes how to download and install the Python SDK of RDS for MySQL.

<span id="prerequisites"></span>
## Prerequisites

Python 2.7 or above is installed.

<div data-tips="true" data-tips-type="tip">You can check the current version of Python by running the <code>python --version</code> command.</div>

<span id="install-the-sdk"></span>
## Install the SDK

You can install the SDK in any of the following ways:


* Run the following command to install the SDK for specified users.

   ```python
   python setup.py install --<username>
   ```
   

* Run the following command to install the SDK for all users.

   ```python
   sudo python setup.py install
   ```
