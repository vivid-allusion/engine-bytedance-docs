This topic describes how to download and install the MySQL Go SDK.

<span id="prerequisites"></span>
## **Prerequisites**

GO v1.5 or higher is required, and GO v1.12 or higher is recommended.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">说明</div>


<div data-tips="true" data-tips-type="tip">You can check the Go version information with the <code>go version</code> command.</div>

<span id="install-the-sdk"></span>
## **Install the SDK**

Under the target Go project, execute the following command to install the Go SDK.

```go
go get github.com/volcengine/volcengine-go-sdk/volcengine/credentials
go get github.com/volcengine/volcengine-go-sdk/volcengine/volcengineutil
```
