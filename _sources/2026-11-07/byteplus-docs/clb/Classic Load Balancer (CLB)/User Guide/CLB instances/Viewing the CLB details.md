## Scenarios

After creating a CLB instance, you can view at any time the configurations and this CLB instance and its associated resources, such as listeners and backend server groups.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CLB console](https://console.byteplus.com/clb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Enter the relevant information of the target instance in the search box above the instances list, then press Enter to find the target instance.

4. Click the target instance name to enter the instance details page, where you can view related information as needed.

   
   |Tab |Explanation |
   |---|---|
   |Shared Line overview |You can view basic information such as the VPC, subnet, and Region to which the CLB instance belongs, as well as the billing information and other attribute configurations for that instance. |
   |Listener |You can view the basic information of all listeners associated with the CLB instance. You can also perform configuration operations such as [create](https://docs.byteplus.com/en/docs/clb/Creating-a-TCP-listener), [modify](https://docs.byteplus.com/en/docs/clb/Editing-the-listener), and [delete](https://docs.byteplus.com/en/docs/clb/Deleting-the-listener) on listeners. |
   |Server group |You can view all backend server groups associated with the CLB instance and their backend servers' basic information. You can also perform configuration operations such as [Creating a server group](https://docs.byteplus.com/en/docs/clb/Creating-a-server-group) and [Adding a backend server](https://docs.byteplus.com/en/docs/clb/Adding-a-server). |
   |Monitor |You can view monitoring data of the CLB instance and all its associated listeners. For detailed explanations of monitoring metrics, see [Viewing monitoring data](https://docs.byteplus.com/en/docs/clb/Viewing-monitoring-data). |
