## Operation scenario

After configuring the health check log function, you can view the relevant health check logs as needed.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to[ the CLB console](https://console.byteplus.com/clb/LoadBalancer). 

2. In the top menu bar, select the target region and target project.

3. From the left\-side navigation pane, select **Health check log**.

4. Click the name of the log project.

5. Find the target log topic, then click **search and analysis** icon.

   By default, the raw log content of the past 5 minutes is displayed in the query result. You can also choose a logging time as needed. For more information about fields in the log, refer to [Log format and description](https://docs.byteplus.com/en/docs/clb/Health-check-log-01#.5pel5b-X5a2X5q61).
