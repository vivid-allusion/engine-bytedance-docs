## Instructions

Modifying a backend server group may have an impact on running services. Therefore, perform this operation with caution.

<span id=".5L-u5pS55ZCO56uv5pyN5Yqh5Zmo57uE56uv5Y-j44CB5p2D6YeN"></span>
## Modifying the backend server's port and weight


1. Log in to[ the CLB console](https://console.byteplus.com/clb/LoadBalancer). 

2. In the top menu bar, select the Target Region.

3. Click the target CLB instance name.

4. On the **Server Group** tab, click the target server group's name.

5. Click the edit icon on the right side of the target backend server.

6. Modify ports and weights.

7. Click **OK** to complete the action.
