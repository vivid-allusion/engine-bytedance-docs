Use this action to delete a certificate when it is no longer needed.

## Prerequisites

The certificate is not currently associated with any listener.

## Procedures

### Certificate Center Delete Operation

If a certificate is uploaded to the Certificate Center, please go to the Certificate Center to delete.

### CLB Console Delete Operation

If the certificate is uploaded to the certificate management module on the CLB side, follow this procedure to delete the certificate.

1. Log in to the [CLB console](https://console.byteplus.com/clb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. In the left\-side navigation pane, select **Certificate**.

4. Click Delete on the right side of the target certificate.

5. Click **Delete** to complete the action.
