## Scenarios

To modify configuration for the existing listener, you may edit the listener directly to update all modifitable settings, or individually adjust specific components by Editing its health check settings, Access control lists, or Certificate configurations.

This topic introduces how to edit a listener.

<span id=".5pON5L2c6K-05piO"></span>
## Action description


* Modifying the listener's protocol and listening port is not supported.

* Modifications take effect immediately.

* Modifying the listener may impact running services. Proceed with caution.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CLB console](https://console.byteplus.com/clb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click Edit Listener to the right of the target CLB instance.

4. Click Edit Listener on the right side of the target listener.

5. Modify the configuration according to the listener protocol, see [Creating a listener](https://docs.byteplus.com/en/docs/clb/Creating-a-TCP-listener).

6. Click **Add** to complete the action.
