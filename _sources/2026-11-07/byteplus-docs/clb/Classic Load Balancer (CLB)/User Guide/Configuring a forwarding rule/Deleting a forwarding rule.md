## Action description


* Deleting a forwarding rule affects running services. Proceed with caution.

* Default forwarding rules cannot be deleted.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [CLB console](https://console.byteplus.com/clb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click Edit Listener to the right of the target CLB instance.

4. Click Configure forwarding rule to the right of the target Layer 7 listener.

5. Click Delete on the right of the target rule.

6. Click **Delete** to complete the action.
