## Will I still be charged for bandwidth after an ECS instance with a bound EIP joins a backend server group?

Yes, you will. The billing for the CLB instance and the ECS instance are independent and do not affect each other.

<span id=".5LiD5bGC6LSf6L295Z2H6KGh6K6_6Zeu5pel5b-X5Yqf6IO96ZyA6KaB5LuY6LS55ZCX77yf"></span>
## Is there a fee for the Layer\-7 CLB access log feature?

CLB does not charge for this feature itself. However, you will incur fees from the associated Torch Object Storage (TOS) for the generated logs.

<span id=".6LSf6L295Z2H6KGh5piv5ZCm5a-55YWs572R5YWl572R5rWB6YeP6K6h6LS577yf"></span>
## Does CLB charge for inbound internet traffic?

No. No, it does not. Only the internet fee for public CLB instances involves pay\-by\-traffic billing. The internet fee is calculated based on outbound traffic. Inbound traffic is not billed.

<span id=".5YGl5bq35qOA5p-l5Lqn55Sf55qE5rWB6YeP5piv5ZCm6K6h6LS577yf"></span>
## Is traffic generated by health checks billed?

No. The traffic generated by health checks is intranet traffic and is not billed separately.

## Will adding an ECS instance to a CLB backend server group affect its billing?

No. CLB fees are independent of backend servers. The billing rules for a CLB instance remain the same regardless of whether you add backend servers, or how many you add. For detailed billing information, see [CLB billing](https://docs.byteplus.com/en/docs/clb/Billing-01).

## **Will charges continue to accrue if the BytePlus account owning the CLB instance has an overdue payment?** 

Yes. If the account is overdue but the CLB instance continues to operate normally, charges will continue to accrue. Charges stop only after the CLB instance enters the "Stopped" state.

If you still need to use the CLB instance, please Recharge your account promptly. If you no longer need it, it is recommended to delete the CLB instance as soon as possible.

<span id="21bwqtmR"></span>
### Why am I still being charged after the CLB instance has been deleted?

After deletion, CLB will no longer incur charges. Please switch regions to check if there are CLB instances in other regions.
