This topic describes the feature release updates for each version of Network Load Balancer (NLB). New features will be gradually released in all regions. Welcome to try them out.

> **tip**

* > Products or features in beta stage are not yet available to all users. To help users understand the product, documentation for some beta products/features is open to all users, while documentation for others is visible only to users who have the corresponding product capability enabled. To request access to a beta product or feature, please contact your account manager to apply.

* > Supported regions may vary by product or feature. Please see the actual availability shown in the console.

## July 2026

|Serial number |Feature |Description |Stage |Documentation link |
|---|---|---|---|---|
|1 |NLB instance |NLB instances support creation within VPCs shared by other accounts. |GA |[Shared VPC Overview](https://docs.byteplus.com/en/docs/vpc/Shared-VPC-Overview) |
|2 |Server Group |When deleting a backend server from a server\-type server group, the system automatically removes it from the group. |GA |[Add or remove backend server](https://docs.byteplus.com/en/docs/clb/NLB-Adding-removing-backend-server) |

## November 2025

|Serial number |Feature |Description |Stage |Documentation link |
|---|---|---|---|---|
|1 |Resource package |NLB resource package is officially launched. |GA |[NLB resource package](https://docs.byteplus.com/en/docs/clb/NLBPackages) |
|2 |Single availability zone NLB |When creating an NLB, the restriction of "at least 2 Availability Zones" is removed, allowing configuration of a single Availability Zone. |GA |[Create NLB instance](https://docs.byteplus.com/en/docs/clb/Creating-an-NLB-instance) |
