## Mainstream protocol support

Specializing in providing Layer\-4 load balancing services, supporting listening and traffic forwarding capabilities for TCP and UDP protocols, improving the fluency and fault tolerance of access to application systems.

<span id=".54G15rS76LCD5bqm"></span>
## Flexible scheduling

Supports multiple scheduling algorithms, and you can select algorithms and rules as needed to allocate user traffic, improving the flexibility of application systems.

<span id=".6LaF6auY5oCn6IO9"></span>
## Ultra\-high performance

A single instance supports up to 100 million concurrent connections and 100 Gbps bandwidth.

<span id=".5by55oCn6L2s5Y-R"></span>
## Elastic forwarding

There is no need to manually specify or adjust specifications, as performance adapts elastically. You can flexibly reuse security group and Network Access Control List features to implement elastic Identity and Access Management (IAM).

<span id=".6auY5Y-v55So5oCn"></span>
## High availability

The instance availability is ensured through various mechanisms such as multiple Availability Zones, health checks, session persistence, and connection draining.
