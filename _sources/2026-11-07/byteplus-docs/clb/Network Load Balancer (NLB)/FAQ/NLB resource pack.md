## Is there a quantity limit on purchasing NLB resource pack?

There is no quantity limit, but larger specifications of NLB resource pack offer better discounts. After evaluating your business needs, select the appropriate NLB resource pack. It is recommended to , , and set surplus alerts for the NLB resource pack to facilitate timely purchase of the NLB resource pack.

<span id="H24dH9Yh"></span>
## Does the NLB resource pack support specification modification?

No, you cannot associate an EIP with a cloud resource that is deployed in a different region.

<span id="4mxxPAwc"></span>
## Does the NLB resource pack support renewal?

No, you cannot associate an EIP with a cloud resource that is deployed in a different region. For NLB resource packs that are not fully deducted, the platform will send expiration reminder messages 7 days, 3 days, 1 day, and on the day of expiration via SMS, email, or internal message based on the [notification method](https://console.byteplus.com/message/setting) you set. Please pay attention.

<span id="2m1pBb5C"></span>
## Is the NLB resource pack deducted on a first\-come, first\-served basis?

No, the deduction time of the NLB resource pack is based on the effective time set at the time of [purchase](https://docs.byteplus.com/en/docs/clb/NLBPackages#okRA6tad), and deductions will start from that point.

<span id="YWDMsnGh"></span>
## Do multiple resource packs get deducted simultaneously?

The NLB resource pack is divided into two zones: the Chinese mainland and non\-Chinese mainland.

Within the same zone, only one NLB resource pack will be deducted at a time. Once that NLB resource pack is exhausted, the next NLB resource pack will be used for deductions.

There is no impact between different zones, and simultaneous deductions may occur.

<span id="i7GXhjGV"></span>
## Does the resource pack support unsubscription?

The NLB resource pack only supports a 7\-day unconditional refund, with the following limits:


* No deductions occurred.

* Each account is eligible for a maximum of 10 unconditional NLB resource pack refunds per calendar year.


Refer to [Unsubscribing NLB resource pack](https://docs.byteplus.com/en/docs/clb/NLBPackages#iuAeUzDu) actions.

<span id="6PIZjR9n"></span>
## Does the NLB resource pack that remains unused upon expiration support refunds?

No, the NLB resource pack that remains unused upon expiration will be automatically cleared.
