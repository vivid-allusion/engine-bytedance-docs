## Scenarios

You can delete a server group that is no longer in use. Deleting a server group will automatically remove all servers within it.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

Ensure no listeners are attached to the server group. If it is already attached, disassociate or delete the listener first.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [NLB console](https://console.byteplus.com/nlb/LoadBalancer).

2. In the left navigation pane, select **Server Group**.

3. In the top menu bar, select the target project and region.

4. Click ··· \> Delete on the right side of the target Server Group.

5. Click **Delete** to complete the action.
