## Scenarios

After a listener is created, it starts automatically by default. You can stop or re\-enable it as needed.

<span id=".5pON5L2c6K-05piO"></span>
## Action description

After the listener is stopped, it will no longer receive client access requests forwarded by the NLB instance.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [NLB console](https://console.byteplus.com/nlb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click **Edit Listener** on the right side of the target NLB instance.

4. Click ··· \> Start or ··· \> Stop on the right side of the target listener.

5. Click **Confirm** to complete the action.
