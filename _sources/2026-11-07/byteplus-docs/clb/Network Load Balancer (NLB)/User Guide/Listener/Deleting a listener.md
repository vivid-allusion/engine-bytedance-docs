## Scenarios

You can delete a listener that is no longer in use. After deletion, the listener will no longer receive and forward access traffic.

<span id=".5pON5L2c6K-05piO"></span>
## Action description

Deleting a listener will automatically detach the associated server group from the listener.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [NLB console](https://console.byteplus.com/nlb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click **Edit Listener** on the right side of the target NLB instance.

4. Click ··· \> Delete on the right side of the target listener.

5. Click **Delete** to complete the action.
