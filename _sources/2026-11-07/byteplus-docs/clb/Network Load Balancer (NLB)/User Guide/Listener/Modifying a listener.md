After a listener is created, you can modify its name, timeout settings, connection rate limit for new connections, concurrent connection limit, and the associated server group as needed.

<span id=".57yW6L6R55uR5ZCs5Zmo"></span>
## Edit listener


1. Log in to the [NLB console](https://console.byteplus.com/nlb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click **Edit listener** to the right of the target NLB instance.

4. Click **Edit listener** to the right of the target listener to modify the name, established timeout, new connection rate limiting, and concurrent connection rate limiting.

5. Click **Confirm** to complete the action.


<span id=".5pu05o2i5pyN5Yqh5Zmo57uE"></span>
## Change server group


1. Log in to the [NLB console](https://console.byteplus.com/nlb/LoadBalancer).

2. In the top menu bar, select the target project and region.

3. Click **Edit listener** to the right of the target NLB instance.

4. Click **Edit server group** to the right of the target listener to reselect the server group.

5. Click **Confirm** to complete the action.
