This topic describes the public error codes involved when calling Network Load Balancer (NLB) OpenAPIs. For platform\-wide common error codes, see [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).


|HttpCode |Error codes |Error message |Description |
|---|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported or cannot be used. |The request contains invalid or unsupported parameters. |
|400 |MissingParameter |The request is missing a required parameter. |This request does not contain required parameters. |
|400 |InvalidResourceId.Malformed |The specified resource ID is malformed. |The specified resource ID is invalid. |
|500 |InternalError |An internal error has occurred. |An internal error occurred. |
