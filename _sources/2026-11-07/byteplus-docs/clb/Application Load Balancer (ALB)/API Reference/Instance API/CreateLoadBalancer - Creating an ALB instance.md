Call the CreateLoadBalancer API to create an ALB instance.

## Instructions

Submit up to 10 API requests per second.

## Debug

[去调试](https://api.byteplus.com/api-explorer/?action=CreateLoadBalancer&groupName=%E5%AE%9E%E4%BE%8B&serviceCode=alb&version=2020-04-01)

## Request parameters

The following only details request parameters specific to this API and key common parameters. More information can be found in [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).

**Action ** string必选 `Example: CreateLoadBalancer`

Action to execute. Set the value to CreateLoadBalancer.

**Version ** string必选 `Example: 2020-04-01`

The API version. Value: 2020\-04\-01.

**ModificationProtectionReason ** string`optional` `Example: This is modification protection`

Reason for enabling instance modification protection.

* Must start with a letter or Chinese character and may include numbers, commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), Chinese commas (，), and Chinese periods (。).

* Length limit: 0 to 128 characters.

> **tip**

* > The value of the `ModificationProtectionReason` parameter is valid only when the `ModificationProtectionStatus` parameter is set to `ConsoleProtection`.

**ModificationProtectionStatus ** string`optional` `Example: NonProtection`

Enable instance modification protection feature. Valid values:

* NonProtection (default): Instance modification protection is not enabled.

* ConsoleProtection: Enable instance modification protection. After enabling this, you cannot modify the instance configuration through the ALB console; you can only modify the instance configuration by calling the API.

**LoadBalancerEdition ** string`optional` `Example: Standard`

ALB instance edition. Different versions have different functional limitations and billing policies. Values:

* **Basic** (default): Basic edition.

* **Standard**: Standard edition.

**ClientToken ** string`optional` `Example: 123e4567-e89b-12d3-a456-42665544****`

A client token used to ensure the idempotence of the request. A client token can prevent the following issue: when an API call times out or an internal server error occurs, multiple client retries may lead to clone resource creation.

* This parameter value is generated by the client. Ensure that the value is unique across different requests.

* Must not exceed 64 ASCII characters.

* If this parameter is not specified, idempotence validation will not be performed by system.

**AddressIpVersion ** string`optional` `Example: DualStack`

IP type of the ALB instance. Valid values:

* IPv4 (default): IPv4 type.

* DualStack: IPv4 & IPv6 dual\-stack type.

> **tip**

> To specify the AddressIpVersion parameter as DualStack, please contact your account manager.

**ZoneMappings.N.ZoneId ** string[]`optional` `Example: ZoneMappings.1.ZoneId=cn-beijing-a&ZoneMappings.2.ZoneId=cn-beijing-b`

Availability zone ID of the ALB instance.

* You can obtain the availability zone ID by calling the [DescribeZones](https://docs.byteplus.com/en/docs/clb/ALB-DescribeZones) API.

* SubnetId and ZoneId must match.

> **tip**

> The SubnetId parameter is being deprecated. Please use the ZoneMappings.N.SubnetId and ZoneMappings.N.ZoneId fields to specify the availability zone and subnet information for deployment. (duplicate as in original)

**VpcId ** string`optional` `Example: vpc-bp1aevy8sofi8mh1****`

VPC ID to which the ALB instance belongs.

If not specified, the default is the VPC ID to which the subnet belongs.

**Ipv6EipBillingConfig.Bandwidth ** integer`optional` `Example: 200`

The bandwidth upper limit of the IPv6 internet bandwidth for the public ALB instance. Default value: 1 Mbps. This parameter is required when creating an IPv4&IPv6 dual\-stack public ALB instance. Value range:

* When the Ipv6EipBillingConfig.BillingType parameter value is 2, the valid range is 1 to 500.

* When the Ipv6EipBillingConfig.BillingType parameter value is 3, the valid range is 1 to 200.

**EipBillingConfig.SecurityProtectionTypes ** string`optional` `Example: AntiDDoS_Enhanced`

When creating a public ALB instance, ALB allows you to purchase multiple EIP protection resources. The specific rules for EIP protection resources are as follows:

* Separate multiple protection resources with commas (,).

* Values for protection resources:

   * AntiDDoS_Enhanced: You are applying for an EIP address of the enhanced protection type; you can add this IP to a Cloud DDoS Protection instance.

   * Not filled: You are applying for an EIP address of the basic protection type.

* Currently, the purchase of EIP protection resources is only available to allowlisted users. If you have business requirements, please contact your account manager.

**Ipv6BandwidthPackageId ** string`optional` `Example: bwp-2d6dcpvaeq9s058****`

When creating a public ALB instance, specify the ID of the bandwidth package to which the IPv6 internet bandwidth should be added.

**EipBillingConfig.EipBillingType ** integer`optional` `Example: 2`

Billing method for the IPv4 EIP of the public ALB instance. Valid values:

* 2 (default): Pay\-as\-you\-go (Pay\-by\-bandwidth).

* 3: Pay\-by\-data\-transfer.

**Description ** string`optional` `Example: This is an ALB instance.`

Description of the ALB instance.

* If left blank, this parameter defaults to an empty string.

* Must start with a letter or Chinese character and may include numbers, half\-width commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), full\-width commas (，), and full\-width periods (。)

* Must be 1 to 255 characters.

**Type ** string必选 `Example: private`

Type of ALB instance. Valid values:

* public: A public load balancer instance is created. The system assigns one EIP address and one private IP address, which can be used to forward both public and private requests.

* private: A private load balancer instance is created. The system assigns a private IP address, which is used only to forward private requests.

**Tags.N.Value ** string[]`optional` `Example: Tags.1.Value=v1&Tags.2.Value=v2`

The tag value of the custom tag. To provide this parameter, provide Tags.N.Key first. The specific rules are as follows:

* The length limit is 0 to 256 characters.

* Case\-sensitive.

* Must not start or end with a space.

* May include characters (any language), numbers, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).

**Tags.N.Key ** string[]`optional` `Example: Tags.1.Key=k1&Tags.2.Key=k2`

The tag key of the custom tag. The specific rules are as follows:

* Must be 1 to 128 characters.

* Case\-sensitive.

* It cannot start with volc: or sys: in any case form.

* Must not start or end with a space.

* May include characters (any language), numbers, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), minus signs (\-) and at signs (@).

* Tag keys of the same resource must be unique.​

**RegionId ** string必选 `Example: cn-beijing`

Request region.

**LoadBalancerName** string `optional` `Example: alb-bp1o94dp5i6ea****`

Name of the ALB instance.

* Must start with a letter or Chinese character. May include numbers, periods (.), underscores (_), and hyphens (\-).

* Length limit is 1 to 128 characters.

* If left blank, it defaults to the instance ID.

**LoadBalancerBillingType ** integer`optional` `Example: 1`

ALB billing method. Valid values:

* 1 (default): Pay\-by\-LCU.

**Ipv6EipBillingConfig.ISP ** string`optional` `Example: BGP`

ISP of the IPv6 internet bandwidth for the public ALB instance. Valid values:

* BGP (default): BGP (Multi\-ISP).

**Ipv6EipBillingConfig.BillingType ** integer`optional` `Example: 2`

Billing method for IPv6 Internet Bandwidth of the ALB instance. Valid values:

* 2: Pay\-by\-bandwidth\-cap.

* 3 (default): Pay\-as\-you\-go (Pay\-by\-data\-transfer).

**EipBillingConfig.ISP ** string`optional` `Example: BGP`

The IPv4 EIP ISP of the public ALB instance. Valid values:

* BGP (default): BGP (Multi\-ISP).

**EipBillingConfig.Bandwidth ** integer`optional` `Example: 10`

The bandwidth cap of the IPv4 EIP for the public ALB instance.

* Default value: 1 Mbps.

* Value range:

   * When the EipBillingConfig.EipBillingType parameter value is 2, the value range is 1 to 500.

   * When the EipBillingConfig.EipBillingType parameter value is 3, the value range is 1 to 200.

**DeleteProtection ** string`optional` `Example: off`

Enable the delete protection feature for the ALB instance. Valid values:

* off (default): Disable delete protection.

* on: Enable delete protection.

**BandwidthPackageId ** string`optional` `Example: bwp-6248cim0mayon3gd5tv****`

When creating a public ALB instance, specify the ID of the bandwidth package to which the IPv4 EIP address should be added.

**ProjectName ** string`optional` `Example: default`

The name of the project to which the ALB belongs.

**SubnetId ** string`optional` `Example: subnet-bp12mw1f8k3jgy****`

The subnet ID within the VPC to which the ALB instance belongs.

The private IP address of the ALB instance will be allocated from the CIDR block of this subnet.

> **tip**

> The SubnetId parameter is being deprecated. Please use the ZoneMappings.N.SubnetId and ZoneMappings.N.ZoneId fields to specify the availability zone and subnet information for deployment. (duplicate as in original)

**ZoneMappings.N.SubnetId ** string[]`optional` `Example: ZoneMappings.1.SubnetId=subnet-bp12mw1f8k3jgy****&ZoneMappings.1.SubnetId=subnet-bp12mw1f8k3jgy****`

Subnet ID. The private IP address of the ALB instance in this availability zone will be allocated from the subnet CIDR block of this subnet.

> **tip**

> The SubnetId parameter is being deprecated. Please use the ZoneMappings.N.SubnetId and ZoneMappings.N.ZoneId fields to specify the availability zone and subnet information for deployment. (duplicate as in original)

**EipBillingConfig.SecurityProtectionInstanceId ** long`optional` `Example: 123132`

When creating a public ALB instance, if IP protection resources are used, you need to specify the ID of an Anti\-DDoS Origin instance.

**ArkClawEnabled ** string`optional` `Example: off`

Enable ArkClaw feature. Valid values:

* off (default): Disable.

* on: Enable.

> **tip**

> This parameter is currently in Beta stage. For trial requests, please contact your account manager.

**SpaceNetworkId ** string`optional` `Example: csn-bpkdt37pq72zv****`

ID of the SpaceNetwork where the ArkClaw instance resides. The parameter is valid only when ArkClawEnabled is set to on.

> **tip**

> This parameter is currently in Beta stage. For trial requests, please contact your account manager.
