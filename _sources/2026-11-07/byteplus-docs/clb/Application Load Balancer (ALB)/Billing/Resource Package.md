## Package overview


* ALB provides you with prepaid resource packages. After purchasing a resource package, the system will automatically use it to offset your service usage during billing. The billing type for resource packages is prepaid. They take effect immediately upon purchase, automatically offsetting the generated Instance Fees and LCU Fees proportionally.

* ALB resource packages support various specifications from 1,000 LCU to 100,000 LCU, and you can purchase multiple packages as needed.

* Compared to the pay\-as\-you\-go postpaid billing method, ALB resource packages offer greater discounts. If your enterprise has prepaid requirements, you may consider purchasing them.

## Resource Package Deduction Rules


* Resource packages can offset Instance Fees and LCU Fees.

* Resource packages can be purchased in multiples, with no purchase limit. Resource packages become effective immediately upon successful purchase.

* If you purchase multiple ALB resource packages, the system will prioritize using the package with the earliest expiration date for deductions.

* Deduction Method:

   
   |Instance edition |Instance fee |LCU Fee |
   |---|---|---|
   |Basic edition |Fixed deduction of 1 LCU per hour |LCU fees are deducted at a 1:1 ratio based on the actual number of LCUs generated per hour |
   |Standard |||
   


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">If you create a public network instance, the resource package cannot offset the public network fees generated by that instance.</div>


* <div data-tips="true" data-tips-type="tip">If the actual LCU consumption of your service exceeds the specification of the purchased ALB resource package, the excess LCUs will be billed at the pay\-as\-you\-go rate.</div>

### Billing example

Assume you purchase a Micro Resource Package (containing 1,000 LCUs) and create a private network ALB instance. Within a billing cycle, the system records that the instance consumed 36 LCUs. During settlement, the system will automatically deduct 37 LCUs from the resource package: 36 LCUs to offset the LCU fees and 1 LCU to offset the instance fee. In this case, the remaining LCU balance in the resource package becomes 963.

## Resource Package Purchase, Management, and Unsubscription

<span id=".6LSt5Lmw6LWE5rqQ5YyF"></span>
### Purchase a package


1. Log in to the [ALB console](https://console.byteplus.com/alb).

2. In the left navigation tree, select **Resource Package**.

3. Click **Purchase resource pack**, then select the package specification and purchase quantity.

4. Click Buy to complete the action.


<span id=".566h55CG6LWE5rqQ5YyF"></span>
### Manage resource packages

After successfully purchasing a resource package, you can view information such as the Resource Package ID, Status, Usage, Validity Period, Purchase Time, and Expiration Time on the **Resource Package** page in the ALB console. You can also view all resource package information [under your account in the ](https://console.byteplus.com/finance/resource-package/)Billing Center within the console.

<span id=".6YCA6K6i6LWE5rqQ5YyF"></span>
### Unsubscribe from a resource package

ALB supports unsubscribing from resource packages that were purchased within the last 7 days and have not started being used for deductions. To unsubscribe, click **Unsubscribe** in the Actions column for the corresponding resource package on the **Resource Package** page.

## FAQs

<span id=".YWxiLei1hOa6kOWMheS9v-eUqOiMg-WbtO-8nw=="></span>
### What is the scope of the ALB Resource Package?

The ALB Resource Package only supports offsetting the Instance Fees and LCU Fees for instances in mainland China regions. It does not support offsetting fees for Finance Cloud or Private Cloud.

<span id=".YWxiLei1hOa6kOWMheaYr-WQpuaUr-aMgeaKteaJo-aMh-WumueahOWunuS-i-S6p-eUn-eahOi0ueeUqO-8nw=="></span>
### Can the ALB Resource Package offset fees for specific instances?

Currently, it does not support offsetting fees for specific designated instances. After your purchased resource package takes effect, fees generated by all ALB instances will be automatically deducted from it.

<span id=".YWxi6LWE5rqQ5YyF5piv5YWI6LSt5Lmw5YWI5oq15omj5ZCX77yf"></span>
### Is the ALB Resource Package used on a first\-purchase, first\-deduction basis?

Deductions are made based on the expiration time of the resource packages after they become active. Packages that expire earlier are used first. After a resource package is exhausted, service will not be suspended; it will automatically switch to the pay\-as\-you\-go billing mode, and charges will be deducted from your account balance.

<span id=".YWxi6LWE5rqQ5YyF5pSv5oyB5a-85Ye65oq15omj5piO57uG5ZCX77yf"></span>
### Can I export the deduction details for the ALB Resource Package?

You can export the deduction details from the [Resource Package Management page in the Billing Center](https://console.byteplus.com/finance/resource-package/).

<span id=".YWxiLei1hOa6kOWMheaUr-aMgemAgOasvuWQl--8nw=="></span>
### Does the ALB Resource Package support refunds?

Resource packages can be refunded without reason within 7 days of purchase, provided they have not started being used for deductions.

<span id=".YWxiLei1hOa6kOWMheWNleS7t-avlOWNleeLrOS9v-eUqC1hbGIt5oyJ6YeP5LuY6LS55pu05LyY5oOg5ZCX77yf"></span>
### Is the unit price of the ALB Resource Package more cost\-effective than using ALB on a pure pay\-as\-you\-go basis?

The Micro ALB Resource Package has the same price as the pay\-as\-you\-go rate. All other specifications of resource packages are more cost\-effective than pure pay\-as\-you\-go billing, with larger specifications offering greater discounts.

<span id=".YWxiLei1hOa6kOWMheaUr-aMgeWPoOWKoOi0reS5sOWQl--8nw=="></span>
### Can ALB Resource Packages be purchased multiple times and stacked?

Yes, they can be purchased and stacked. Deductions will be applied in order of their expiration times.

<span id=".YWxiLei1hOa6kOWMhei0reS5sOWujOaIkOWQjumcgOimgeiuvue9ruWQl--8nw=="></span>
### Does the ALB Resource Package require any setup after purchase?

No configuration is needed. After purchase, it becomes active automatically and deductions will be applied automatically.

<span id=".5aaC5L2V5p-l55yLLWFsYi3otYTmupDljIXnmoTkvb_nlKjmg4XlhrXvvJ8="></span>
### How can I view the usage status of my ALB Resource Package?

You can check the consumption of your resource packages on both the ALB Resource Package Management page and the Resource Package Management page in the Billing Center.
