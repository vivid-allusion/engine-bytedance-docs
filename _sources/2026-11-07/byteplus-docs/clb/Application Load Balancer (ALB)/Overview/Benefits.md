### High stability

The Application Load Balancer (ALB) instance adopts a cluster deployment. Multiple nodes within the cluster provide mutual backup, ensuring system stability and continuous availability.

<span id=".6LaF5by65a656YeP"></span>
### High capacity

The ALB possesses powerful processing capabilities at the application layer. A single instance can support millions of Queries Per Second (QPS). Therefore, ALB can be utilized in large\-scale, high\-concurrency scenarios. For example, e\-commerce, interactive entertainment, and gaming.

<span id=".5Y2P6K6u5Liw5a-M"></span>
### Rich protocol support

ALB supports application\-layer protocols including HTTP, HTTPS, HTTP/2, WebSocket, WebSocket Secure, and QUIC, catering to diverse business requirements.

<span id=".54G15rS76YWN572u"></span>
### Flexible configuration

In ALB, server groups, health check templates, access control policies, certificates, and instances are all independent components. A single server group can be associated with any instance within the same VPC, and a health check template can be applied to any server group. This architecture enables more flexible configuration and easier use of ALB.

<span id=".57K-57uG6LCD5bqm"></span>
### Granular traffic scheduling

Leveraging characteristics of the application\-layer protocols, ALB allows you to configure forwarding rules based on request attributes. This enables fine\-grained traffic distribution at the application layer, meeting advanced Load Balancer needs in complex scenarios.

<span id=".5a6J5YWo5Y-v6Z2g"></span>
### Safe and reliable

You can associate an ALB instance with WAF in one click. By combining WAF's risk control capabilities, ALB can block and intercept malicious attacks. ALB's access control feature allows for filtering and restricting traffic sources, preventing network attacks. These measures collectively ensure the security of backend servers.
