## What is an Application Load Balancer


* Cloud Load Balancer is a technology that distributes client requests to multiple servers during network transmission. This helps improve service performance and reliability. Cloud Load Balancer can operate at different layers in the OSI seven\-layer model, typically at the application layer (Layer 7) and the transport layer (Layer 4).

* Application Load Balancer (ALB) is a Cloud Load Balancer service that operates at the application layer in the OSI model. Application\-layer (Layer 7) protocols include HTTP, HTTPS, HTTP/2, WebSocket, and QUIC.

* BytePlus ALB applies to application\-layer websites, audio and video applications, and other high\-traffic distribution scenarios. ALB enables fine\-grained, balanced data transfer routing and eliminates the impact of single server failures. Therefore, ALB enhances your system’s overall service performance, including stability and reliability.

## Product features

<span id=".5aSa5Y2P6K6u5pSv5oyB"></span>
### Multi\-protocol support

BytePlus ALB supports multiple application\-layer protocols including HTTP, HTTPS, HTTP/2, WebSocket, WebSocket Secure, and QUIC to meet different scenario requirements.

<span id=".6LCD5bqm566X5rOV"></span>
### Scheduling algorithm

BytePlus ALB offers three routing algorithms: Weighted Round Robin (WRR), Weighted Least Connections (WLC), and Source Address Hash (SH). These algorithms enable balanced data transfer distribution.

<span id=".5a6J5YWo6Ziy5oqk"></span>
### Security protection

You can enable WAF (Web Application Firewall) protection for your ALB instance with one click, or use access control to filter and restrict request sources. This provides real\-time defense against malicious requests.

<span id=".5YGl5bq35qOA5p-l"></span>
### Health check

BytePlus ALB monitors the health status of backend servers to promptly detect and isolate those with abnormal health. This ensures the stability of your backend services.

<span id=".6K-B5Lmm566h55CG"></span>
### Certificates

BytePlus ALB offers certificate management features. For HTTPS protocol, ALB allows you to select certificates already uploaded to the BytePlus Certificate Center or directly upload your own certificates. This lets you attach SSL certificates to your listeners with one click.

<span id=".6K6_6Zeu5pel5b-X"></span>
### Access Log

BytePlus Application Load Balancer provides a logging feature to collect application\-layer access logs. Access logs include information such as client IP address and server response. You can analyze user behavior based on access logs and perform precise maintenance and rapid troubleshooting of applications.
