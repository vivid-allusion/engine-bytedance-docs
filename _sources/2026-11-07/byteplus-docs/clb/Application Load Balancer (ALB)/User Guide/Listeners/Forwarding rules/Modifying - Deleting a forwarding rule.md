This topic explains how to modify and delete forwarding rules in the console.

<span id="cc947237"></span>
## Modify forwarding rule

<span id="8g4mcMpw"></span>
### Action description

The domain name and path parameters of a forwarding rule cannot be modified.

<span id="41e02241"></span>
### **Procedures**


1. Log in to the [ALB console](https://console.byteplus.com/alb).

2. In the top menu bar, select the target project and region.

3. In the left\-side navigation pane, select Instances.

4. Click **Listener** to the right of the target ALB instance.

5. On the **Listeners** tab, click **Edit forwarding rules** to the right of the target listener.

6. On the forwarding rules tab, click the **Edit** icon to the right of the target forwarding rule.

7. On the **Edit forwarding rules** page, modify the forwarding rule according to your actual business requirements. For explanations of relevant parameters, see [Creating a forwarding rule (Basic)](https://docs.byteplus.com/docs/clb/Creating-a-forwarding-rule) or [Creating a forwarding rule (Standard)](https://docs.byteplus.com/docs/clb/Creating-a-forwarding-rule_Standard-edition).

8. Click Save to complete the action.


<span id="2b00a138"></span>
## **Delete forwarding rule**

<span id="AMLZXKst"></span>
### Action description


* Default forwarding rules cannot be deleted.

* Deleting Forwarding rules is irreversible. Please proceed with caution.


<span id="58830ec1"></span>
### **Procedures**


1. Log in to the [ALB console](https://console.byteplus.com/alb).

2. In the top menu bar, select the target project and region.

3. In the left\-side navigation pane, select Instances.

4. Click **Listener** to the right of the target ALB instance.

5. On the **Listeners** tab, click **Edit forwarding rules** to the right of the target listener.

6. On the forwarding rules tab, click the **Delete** icon to the right of the target forwarding rule.

7. Click Delete to complete the action.
