This topic describes the common error codes that may be returned when you call Virtual Private Cloud (VPC) APIs. For platform error codes, see [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).

|HttpCode |Error codes |Error message |Description |
|---|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported, or cannot be used. |This request contains an invalid or unsupported parameter. |
|400 |MissingParameter |The request is missing a required parameter. |The request is missing a required parameter. |
|409 |InvalidOperation.Conflict |The specified resource operation conflicts. |The specified resource operation conflicts. |
|429 |RateLimited |Too many requests, please try again later. |Too many requests, please try again later. |
|500 |InternalError |An internal error has occurred. |An internal error occurred. |
