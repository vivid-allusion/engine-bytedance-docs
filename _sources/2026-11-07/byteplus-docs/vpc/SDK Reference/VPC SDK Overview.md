This article introduces the SDK language versions provided by the  VPC and lists the addresses to obtain the latest SDK versions.

<span id="CATtxYNq"></span>
## SDK Introduction

The VPC SDK encapsulates all the APIs of the VPC  (see [VPC API overview](https://docs.byteplus.com/en/docs/vpc/API-overview-1)), uses an access key (AK) to identify the caller's identity, and provides features like automatic signing. This facilitates creation and management of resources through APIs.
