## Prerequisites


* The High\-Availability Virtual IP Address (HAVIP) is not bound to any Elastic Compute Service (ECS) instance, Network Interface, or Elastic IP Address (EIP). If bound, see [Disassociate from a cloud resource](https://docs.byteplus.com/en/docs/vpc/Binding-or-unbinding-cloud-resources#04ZFfFTD).

* There are no routes pointing to this HAVIP. If there are, see [Delete route entry](https://docs.byteplus.com/en/docs/vpc/Managing-a-route-entry#.5Yig6Zmk6Lev55Sx5p2h55uu).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **HaVip**.

3. In the top menu bar, select the target project and region.

4. Click **Delete** on the right side of the target HAVIP.

5. Click **Delete** to complete the action.
