## Action description

When creating a Flow Log, you must configure an index to analyze the log. If automatic index creation is not selected, you must manually configure the index.

## Procedures

1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **Flow Log**.

3. In the top menu bar, select the target project and region.

4. Click the topic name under the **Log topic** column of the target flow log.

5. Click the search and analysis icon to the right of the target log topic.

6. Click **Index configuration** in the top right corner.

7. Turn on the **Enable index** switch and select **Key\-value index**.

8. See the [Flow log fields](https://docs.byteplus.com/en/docs/vpc/Flow-log-overview), configure each **field** and its **field type** in sequence, and enable statistics for each field.

9. Click **Enable** to complete the action.
