## Instruction

Three sampling intervals are currently supported: 1 minute, 5 minutes, and 10 minutes.

<span id="mSnSppcs"></span>
## Procedures


1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **Flow Log**.

3. In the top menu bar, select the target project and region.

4. Click the edit icon next to the time in the target sampling interval column of the flow log.

5. Select the target sampling interval and click **Confirm** to complete the action.
