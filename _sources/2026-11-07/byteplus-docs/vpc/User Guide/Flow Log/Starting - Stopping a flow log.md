## Start a flow log

<span id=".5pON5L2c6K-05piO"></span>
### Instruction

Flow Logs are automatically started after creation.

<span id=".5pON5L2c5q2l6aqk"></span>
### Procedures


1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **Flow Log**.

3. In the top menu bar, select the target project and region.

4. Click **Start** on the right side of the target flow log.

5. Click **Start** to complete the action.


<span id=".5YGc5q2i5rWB5pel5b-X"></span>
## Stop a flow log

<span id=".5pON5L2c6K-05piO"></span>
### Instruction

After disabling flow log, the system will no longer generate flow log data, so there will be no VPC flow log generation fees. However, the Torch Log Service (TLS) associated with the flow log will continue normal billing. 

<span id=".5pON5L2c5q2l6aqk"></span>
### Procedures


1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **Flow Log**.

3. In the top menu bar, select the target project and region.

4. Click **Stop** on the right side of the target flow log.

5. Click **Stop** to complete the action.
