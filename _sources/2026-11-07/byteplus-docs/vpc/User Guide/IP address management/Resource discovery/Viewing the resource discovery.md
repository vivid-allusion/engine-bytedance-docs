## Scenarios

Regularly check resource usage through Resource Discovery, maintain IP addresses in a timely manner, and ensure stable network operation.

## Instructions

Currently, resource discovery updates every 5 minutes, displaying the latest resource data.

### Procedure

1. Log in to the [IPAM console](https://console.byteplus.com/ipam/ipam).

2. In the top menu bar, select the Region.

3. In the left navigation pane, select **Resource Discovery**.

4. Click the name of Resource Discovery.

5. Select the **Resource discovered** tab and click to view the IP usage rates of all VPCs and subnets in the current region.
