## Scenarios

View the IP information of a VPC to facilitate subsequent planning and adjustments.

## Procedure

1. Log in to the [IPAM console](https://console.byteplus.com/ipam/ipam).

2. In the top menu bar, select the Region.

3. In the left navigation pane, select **IPAM Scope**.

4. Click the target scope name.

5. On the **Resource details** tab, click the target VPC name. View the usage details of the VPC:

   * On the **Overview** tab: Check the IPv4 address utilization of the VPC.

   * On the **IP space visualization** tab: Statuses such as Pending allocation, Partially allocated, and Allocated within a VPC.

   * On the **Resource CIDR** tab: View the VPC's IP user count/IP total.

   * On the **Monitoring chart** tab: For details, see [Scope monitoring chart](https://docs.byteplus.com/en/docs/vpc/Viewing_the_scope_monitoring_chart).
