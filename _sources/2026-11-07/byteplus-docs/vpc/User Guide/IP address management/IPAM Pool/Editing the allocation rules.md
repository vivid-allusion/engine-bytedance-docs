## Scenarios

When business needs change and the original address pool allocation rules can no longer meet requirements, you can modify the allocation rules.

## Instructions

After modification, the system will re\-validate the compliance of allocated resources according to the new allocation rules. For more compliance information, see [Scope overview](https://docs.byteplus.com/en/docs/vpc/Scope-overview).

## Procedure

1. Log in to the [IPAM console](https://console.byteplus.com/ipam/ipam).

2. In the top menu bar, select the Region.

3. In the left navigation pane, select **IPAM Address Pool**.

4. Click **Edit Allocation Rules** to the right of the target pool.

5. Enter **Minimum netmask length**, **Default netmask length**, and **Maximum netmask length** as needed.

6. Click **OK** to complete the action.
