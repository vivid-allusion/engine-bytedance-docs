## Scenarios

After an address pool is shared with a business account, you can view its usage to facilitate CIDR monitoring and management.

## Procedure

1. Log in to the [IPAM console](https://console.byteplus.com/ipam/ipam).

2. In the top menu bar, select the region.

3. In the left navigation pane, select **IPAM Address Pool**.

4. Click the name of the target pool.

5. You can view allocated CIDRs by selecting the **CIDR Allocated** tab.
