## Introduction​

A network interface is also called a virtual network interface (vENI). In the Virtual Private Cloud (VPC), a network interface is a network interface mounted on cloud resources like Elastic Compute Service (ECS) or Classic Load Balancer. It serves as an essential component for enabling network communication.

Each network interface has one primary private IP address. If necessary, multiple secondary private IP addresses can be manually allocated to it. For details, see [IP address overview](https://docs.byteplus.com/en/docs/vpc/IP-address-Overview).

## Network interface type

|Topic |Explanation |
|---|---|
|Primary network interfaces |The primary network interface is generated by default when creating an ECS instance. It cannot be detached from the ECS and is automatically deleted along with the ECS instance. |
|Secondary network interfaces |The secondary network interface is manually created by the user, supporting mount, unmount, and delete operations, offering flexibility. |
|Volcengine Official Service Network Interface<br><br> |BytePlus Official Service Network Interfaces are automatically created by the system when services such as Transit Routers or PrivateLink are created. They provide private network connectivity for backend services, support only modifying tag information, and do not support deletion, attachment, or detachment. Their lifecycle matches that of the corresponding cloud product instance. |

## Application scenarios

* **Build a high availability cluster**

   This meets the requirement for multiple network interfaces on a single ECS in high\-availability architectures, helping to enhance system stability and reliability.

* **Low\-cost failover**

   The private IP, EIP, and security group policies of the secondary Network Interface are tightly and strongly associated with the secondary Network Interface itself. In the event of a failure, you can detach the secondary Network Interface from the faulty ECS instance and attach it to a standby instance. This enables rapid transfer of business traffic from the failed instance to the standby instance, facilitating quick service recovery.

* **Granular traffic management**

   An ECS instance can be configured with multiple Network Interfaces, and different Network Interfaces can be used for different business scenarios, such as internal access and internet business. Based on business requirements, you can configure precise security group rules for each Network Interface, effectively controlling the traffic flow of individual network interfaces.

* **Multiple private IP addresses for a single ECS**

   Multiple private IP addresses can be assigned to the Network Interface of an ECS instance. If your ECS hosts multiple applications, each application can be assigned an independent IP address, significantly improving the utilization efficiency of the ECS.

* **Multiple EIP addresses for a single ECS**

   When multiple IP addresses are assigned to an ECS network interface, multiple EIPs can be bound to it. This effectively prevents service disruptions caused by the blocking of an EIP.

## Limits

* A single secondary network interface can only be mounted to one ECS.

* The primary network interface and secondary network interface of the ECS can be assigned private IPv4 addresses and private IPv6 addresses, which are limited by the [ECS instance type](https://docs.byteplus.com/en/docs/ecs/Introduction-to-instance-types)'s **Private IP address for each network interface** quota.

   > Such as [ecs.g3i.large](https://docs.byteplus.com/en/docs/ecs/General-purpose#.6YCa55So5Z6LZzNp) single Network Interface private IP quota is 6. That is, the specification of the ECS primary Network Interface or secondary Network Interface can be assigned up to 6 private IPv4 addresses (including the main private IPv4 address) and 6 private IPv6 addresses.

* An unmounted secondary network interface can be custom\-assigned up to 9 Secondary Private IPv4 addresses and 10 private IPv6 addresses.

* Each private IPv4 address on a network interface can be associated to one EIP.

* The IPv6 address of a network interface supports private network communication only by default. Internet access is enabled only after IPv6 internet bandwidth is activated.

   > **tip**

   > The IPv6 gateway and dual\-stack VPC are currently in beta stage. If you need a trial, please contact the account manager.

* Each network interface has only one globally unique MAC address.

For more usage limits on network interfaces, see [Limits](https://docs.byteplus.com/en/docs/vpc/Limits#.572R5Y2h).

## Configuration procedures

**Secondary network interfaces**

The configuration procedure for secondary network interfaces is as follows:

1. [Create secondary network interface](https://docs.byteplus.com/en/docs/vpc/Creating-a-secondary-network-interface)

2. [Mount to ECS](https://docs.byteplus.com/en/docs/vpc/Loading-or-unloading-a-secondary-network-interface#.5oyC6L296L6F5Yqp572R5Y2h)

3. [Configuring a Secondary Network Interface for ECS](https://docs.byteplus.com/en/docs/ecs/Configuring-auxiliary-network-interfaces-for-ECS-instances)

4. (Optional) Assign and configure secondary private IPv4 addresses or private IPv6 addresses for the secondary network interface:

   1. [Assign IPv4 address](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address) or [assign IPv6 address](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address).

   2. [Configure Private IPv4 Address ](https://docs.byteplus.com/en/docs/ecs/Configuring-secondary-private-IPv4-addresses-for-ECS-instances)or [Configure Private IPv6 Address for ECS instance](https://docs.byteplus.com/en/docs/ecs/Configuring-private-IPv6-addresses-for-ECS-instances).

5. (Optional) If the IP addresses assigned to the secondary network interface need to communicate with the Internet, you can [Associate EIP](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP) or [Enable IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/IPv6/Enable_IPv6_internet_bandwidth).

6. [Delete network interface](https://docs.byteplus.com/en/docs/vpc/Deleting-a-network-interface)

**Primary network interfaces**

If the primary network interface requires assigning and configuring secondary private IPv4 or IPv6 addresses, you can refer to the following process:

1. [Allocate IPv4 address](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address) or [Allocate IPv6 address](https://docs.byteplus.com/en/docs/vpc/Adding-or-releasing-a-private-IP-address)

2. [ECS configures private IPv4 address](https://docs.byteplus.com/en/docs/ecs/Configuring-secondary-private-IPv4-addresses-for-ECS-instances) or [ECS configures private IPv6 address](https://docs.byteplus.com/en/docs/ecs/Configuring-private-IPv6-addresses-for-ECS-instances)

3. (Optional) If the IP addresses assigned to the primary network interface need to communicate with the Internet, you can [Associate EIP](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-an-EIP) or [Enable IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/IPv6/Enable_IPv6_internet_bandwidth)
