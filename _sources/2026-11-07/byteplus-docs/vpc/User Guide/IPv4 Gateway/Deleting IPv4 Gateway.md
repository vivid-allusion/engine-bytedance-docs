## Prerequisites

IPv4 Gateway is not associated with a VPC. if associated, [unlink](https://docs.byteplus.com/en/docs/vpc/Associating-Disassociating-a-VPC).

## Procedures

1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left navigation tree, select **IPv4 Gateway**.

3. In the top menu bar, select your target Region.

4. Click **Delete** to the right of the target IPv4 Gateway.

5. Click **OK** to complete the action.
