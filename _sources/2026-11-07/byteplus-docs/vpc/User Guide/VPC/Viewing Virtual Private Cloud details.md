## Scenarios

You can view VPC's basic information, associated resources, and cross\-account authorization details.

## Procedures

1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the top menu bar, select the target project and region.

3. Click the target VPC's name to access its **Overview** page for detailed configuration

4. Navigate to the **CEN cross\-account authorization** tab to view cross\-account authorization information of the VPC. For more information about cross\-account authorization, see [Managing cross-account authorization](https://docs.byteplus.com/en/docs/vpc/Managing-CEN-cross-account-authorization).
