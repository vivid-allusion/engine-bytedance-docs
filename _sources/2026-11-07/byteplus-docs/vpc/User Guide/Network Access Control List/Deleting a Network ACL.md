## Scenarios

You can delete Network Access Control Lists that are no longer required.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

Network Access List is not associated with any subnets. If associated, please [Disassociate](https://docs.byteplus.com/en/docs/vpc/Associating-or-disassociating-with-subnet-with-a-network-ACL#.6Kej6Zmk5YWz6IGU5a2Q572R) first.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedures


1. Log in to the [VPC console](https://console.byteplus.com/vpc/vpc).

2. In the left\-side navigation pane, select **Network ACL**.

3. In the top menu bar, select the target project and region.

4. Click **Delete** to the right of the target Network Access Control List.

5. Click **Delete** to complete the action.
