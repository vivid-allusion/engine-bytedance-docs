You can refer to the Getting Started Documentation to quickly learn the procedure for using the Virtual Private Cloud (VPC). This article describes the preparations required before you begin using the product.

## Preparations

* Account registration and real\-name authentication are complete.

* Complete network planning. For related actions, see [Network planning](https://docs.byteplus.com/en/docs/vpc/Network-planning).

## Procedures

* Building an IPv4 VPC

   1. [Create a VPC and subnet.](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv4-VPC#.5q2l6aqk5LiA77ya5Yib5bu6VlBD5Y-K5a2Q572R)

   2. [Create ECS and associate an EIP](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv4-VPC#.5q2l6aqk5LqM77ya5Yib5bu65LqR5pyN5Yqh5Zmo5bm257uR5a6a5YWs572RSVA=)

   3. [View and allow security group](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv4-VPC#.5q2l6aqk5LiJ77ya5p-l55yLL-aUvumAmuWuieWFqOe7hA==)

* Set up an IPv6 VPC

   1. [Create VPC and subnet](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv6-VPC#.5q2l6aqk5LiA77ya5Yib5bu656eB5pyJ572R57uc5Y-K5a2Q572R)

   2. [Create ECS and associate an EIP](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv6-VPC#.5q2l6aqk5LqM77ya5Yib5bu65LqR5pyN5Yqh5Zmo)

   3. [Configure the private IPv6 address](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv6-VPC#.5q2l6aqk5LiJ77ya6YWN572u56eB572RSVB2NuWcsOWdgA==)

   4. [Enable IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv6-VPC#.5q2l6aqk5Zub77ya5byA6YCaSVB2NuWFrOe9keW4puWuvQ==)

   5. [View and allow security group](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv6-VPC#.5q2l6aqk5LqU77ya5p-l55yLL-aUvumAmuWuieWFqOe7hA==)
