## Action notes


* If a peering connection initiated by another account is not accepted within 7 days, the peering connection will become invalid and must be recreated.

* Peering connections are accepted by default within the same account, but cross\-account peering connections require manual acceptance.


<span id="KWw4taZs"></span>
### **Accept**/Deny connection request


1. Log in to the [Peering Connection console](https://console.byteplus.com/vpc/region:vpc+cn-beijing/peerConnection).

2. In the top menu bar, select the target region and project.

   * **Accept connection**: Click **Accept **  on the right of the target peering connection.

   * **Deny connection**: Click **Deny ** on the right of the target peering connection.

3. Click **Save** to complete the action.
