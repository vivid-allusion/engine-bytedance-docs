## Stable and secure

VPC supports deployment across all zones, allowing the user to build a disaster recovery system between different availability zones to ensure business stability. Meanwhile, VPC leverages Overlay technology to achieve network logical isolation between different VPCs, ensuring network environment independence and security.

## Easy to use

The VPC is equipped with numerous commonly used features, such as default security group rules, which significantly lower the usage threshold for users. It also provides batch processing features like prefix lists that greatly reduce users' operation and maintenance time.

## Highly scalable

The virtual private cloud (VPC) has exceptional scalability. When paired with other products, it not only enables communication between VPCs on the cloud to promote cross\-region business collaboration, but also allows intercommunication between cloud VPCs and the data center (IDC), building a hybrid cloud to meet the diverse needs of enterprises.

## Controllable Traffic

The security group can precisely control network interface traffic of Elastic Compute Service (ECS) based on default policy, strictly filtering inbound and outbound network data. Users can also flexibly choose to have the Network Access Control List work in coordination with a security group. The Network Access Control List further manages traffic at the subnet level, complementing each other to establish a refined traffic control system, meeting diverse traffic control needs in various business scenarios.
