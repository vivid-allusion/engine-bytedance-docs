DataLeap is a one\-stop data mid\-platform suite that helps users quickly implement a complete data mid\-platform, covering data integration, development, operation, governance, asset management, and security.

DataLeap currently offers Professional Edition product solutions and services, which include a wide range of functional modules such as Data Integration, Data Development, Intelligent Operation and Maintenance, Data Catalog, Data Quality, Data Security, and Healer. When executing tasks, DataLeap Professional Edition also requires the use of resource groups such as the Data Integration Resource Group, Scheduling Resource Group, or Computing Resource Group.

DataLeap will measure and bill separately for the product service plan you purchase and the Resource Groups you use. Billing methods include pay\-as\-you\-go and annual or monthly subscription：


* For details on product service plan billing, see [Billing Instructions for Version Services](https://docs.byteplus.com/docs/dataleap/Billing_Instructions_for_Version_Services).

* For details about Resource Group billing, see [Resource Group Billing Instructions](https://docs.byteplus.com/en/docs/dataleap/resource_group_billing).

<div data-tips="true" data-tips-type="tip">During the process of running a DataLeap task, if you use additional products such as compute engines, storage, or network products, the charges for these products are billed separately and are not included in DataLeap's billing. You need to estimate and pay the corresponding usage fees based on the billing methods for these products.</div>
