DataLeap Tenant Management Console provides an overview, project management, resource group management, engine management, and quick entries to Smart Markets and other operations. Here is a description of the main functions of each module:


* Onboarding

   Onboarding displays the operating instructions when binding different engines with DataLeap, including combinations like DataLeap on EMR Serverless Spark, DataLeap & ByteHouse, helping users quickly understand data integration, development, operation, asset management, and security.

* Overview

   The Overview displays the DataLeap services that have been activated for the current tenant and the projects the current user has joined. Also, it provides quick entries to create new projects and go to data integration, data development, data catalog, data quality, data security, data governance, and other products.

* Project Management

   DataLeap divides and manages tasks by project. Project Management features are used to display and manage projects that the current tenant has created in the selected region. Here, the main tenant account can display all created projects, while other sub\-accounts only show the projects they have joined.

   If you are an admin of a project, you can modify project configuration, manage members, set parameter information, and manage Datasources, among other actions.

* Resource Group Management

   This displays the Resource Groups bound to the tenant, categorized into Exclusive Resource Group, Public resource group, and Intelligent Assistant services.

   * Exclusive resource group: includes Exclusive Integrated Resource Group, Exclusive computing resource group, Exclusive scheduling resource group, and Exclusive Data Services Resource Group.

   * Public resource group: includes Common Computing Resource Group and Public scheduling resource group.

* Engine Management

   This displays the Engine information bound to the tenant. Click on the specific engine type to jump to the corresponding engine console, where you can view and manage the engine instances opened by the tenant.
