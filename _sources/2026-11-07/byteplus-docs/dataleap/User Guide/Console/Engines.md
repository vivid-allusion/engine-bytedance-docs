This feature displays the management entry for engine services available in the current DataLeap region. You can quickly jump to the corresponding console to manage engine information as needed. This article introduces how to operate.

<span id="65d12396"></span>
## Supported Engines

Currently, DataLeap supports the following engine types:


|Engine |Description |
|---|---|
|EMR Serverless |Supports connection to the following two types:<br><br><br>* Spark: for managing EMR Serverless Spark engine instances.<br><br>* Presto: for managing EMR Serverless Presto engine instances. |
|Serverless Flink |For managing Stream Computing Flink Edition engines. |
|ByteHouse CDW |For managing ByteHouse Cloud Data Warehouse Edition engines. |
|ByteHouse CE |Used to manage the ByteHouse CE engine. |


<span id="ca3fe33d"></span>
## Operation Steps

Take the LAS engine management as an example. The operation steps are as follows:


1. Log in to the DataLeap console.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bb2ce7d0b7a54c71b263e673f310d702~tplv-goo7wpa0wc-image.image) </span>

2. Choose **Engines \> ByteHouse CDW Console** to enter the ByteHouse CDW console.

   * If the engine service is activated, it will directly jump to the corresponding management console.

   * If the engine service is not activated, it will go to the service purchase page.

3. You can manage the ByteHouse CDW engine as needed. For detailed operation instructions of each function, refer to [ByteHouse CDW](https://docs.byteplus.com/en/docs/bytehouse/docs-docs).

   For management instructions of other engines, refer to related operation instructions.
