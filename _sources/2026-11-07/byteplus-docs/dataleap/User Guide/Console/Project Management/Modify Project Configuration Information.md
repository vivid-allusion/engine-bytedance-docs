Through this feature, you can modify the project configuration information.

<span id="_1-约束限制"></span>
## Limitations

Only project administrators can modify the project configuration information.

<span id="_2-操作步骤"></span>
## Prerequisites

A project has been created.

<span id="4ca4cacf"></span>
## Operation Steps


1. Log in to the DataLeap Console.

2. Click **Projects** in the left navigation bar to enter the **Project Management** page.

3. Select the **My managed projects** option to display a list of projects you manage.

4. Click on the **Action** Column's **Config** button in the project list to enter the **Configuration** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7055c862ba71413c8b8bab61304a08f1~tplv-goo7wpa0wc-image.image) </span>

5. Click the **Edit** button to adjust the project's configuration, including basic info, control information, and service binding.

   For explanations of the project's relevant parameter configuration, refer to the configuration description section of [Create a Project](https://docs.byteplus.com/docs/dataleap/create_project).


<span id="a4e7b21e"></span>
## Operation Result

After modifying the project configuration, the updated information will be synchronized to the **Data Development** page. You need to manually refresh the Data Development page to view the updated information.
