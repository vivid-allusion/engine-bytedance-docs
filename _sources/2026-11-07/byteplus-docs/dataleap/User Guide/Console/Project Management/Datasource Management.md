Through the data source management feature, you can configure multiple source types such as MySQL, HDFS, Hive, SQLServer, Oracle, TOS, Doris, Kafka, etc., facilitating the subsequent configuration of corresponding data integration sync tasks.

<span id="_1-约束限制"></span>
## Constraints

Only project administrators can manage data source information.

<span id="_2-操作步骤"></span>
## Prerequisites

A project has been created.

<span id="6ca23aeb"></span>
## Operation steps


1. Log in to the DataLeap console.

2. Click on **Projects** in the left navigation bar to enter the **Project Management** page.

3. Select the **My managed projects** option to display the list of projects you manage.

4. Click any button in the **Action** column in the Project list to enter the **Project Console**.

5. Click **Datasource** in the left navigation bar to enter the **Custom Data Source** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3eb7ea1064f144ce9b33719612f42159~tplv-goo7wpa0wc-image.image) </span>

6. You can configure the data source information to be synchronized through Data integration tasks as needed under the project.

   For detailed configuration instructions, please refer to [Configure Datasource](https://docs.byteplus.com/docs/dataleap/configure_datasource).
