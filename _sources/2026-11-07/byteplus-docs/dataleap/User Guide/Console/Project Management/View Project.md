Through this feature, you can find projects on demand and view their detailed information. This article will introduce how to perform query operations.

<span id="e6adda0d"></span>
## Prerequisites

You have created a project.

<span id="ef25e0ab"></span>
## Operation Steps


1. Log in to the DataLeap Console.

2. Click **Projects** in the left navigation bar to enter the **Project Management** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d12013ac3fc74c8685cd92b9c535d10e~tplv-goo7wpa0wc-image.image) </span>

3. The following actions can be performed:

   * Search for items

      When setting multiple search criteria, the intersection of all criteria is taken for the query.

      * From the **All resources** dropdown at the top of the page, select the Volcano Engine project to view all project lists that belong to that Volcano Engine project.

      * By selecting the **My joined projects** option, you can view all the projects you have joined.

      * By selecting the **My managed projects** option, you can view all the projects where you are an admin.

      * After entering the related information of the project name in the search box, the list will show all projects containing that information.

      * Clicking the up/down buttons of the parameter name in the list allows viewing of the projects in ascending/descending order according to the corresponding parameter.

      * Clicking on the filter button of the parameter name in the list, choose the filtering information, then click the **Confirm** button to view the projects based on the filtering results.

   * View the details of the project binding services.

      Hover your mouse over the **Service** column's binding service in the list, and in the popup floating window, click the **Details** button to jump to the corresponding page for viewing.

   * View the tasks under the project.

      Click on the **Project name** in the Project List to manage the project, and access the Data Development page to view the development tasks under the project.

   * View the details of the associated BytePlus project

      Click on the **BytePlus project** name in the Project List to manage the project, which will jump to the Detail page of that BytePlus project to view its information.
