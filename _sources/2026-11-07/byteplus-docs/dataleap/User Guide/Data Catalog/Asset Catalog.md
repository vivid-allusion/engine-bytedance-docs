The Asset Catalog lets you organize the data assets produced within a team into categorized displays after systematic arrangement.

<span id="0e6eff7a"></span>
## Background Information

If a business team wants to **structure all data assets produced within the group**, organizing them by supported business, problems solved, implemented functions, and other categories, they can use the **Asset Catalog** and [Asset Album](https://docs.byteplus.com/docs/dataleap/Asset_Album)form the asset portal for this business. Establishing an asset portal helps consolidate dispersed data for unified management and enables data consumers to systematically access data, improving retrieval efficiency.

<span id="19216813"></span>
## Prerequisites

The business line has been created and related assets configured. For detailed steps, refer to [Create Business Line](https://docs.byteplus.com/docs/dataleap/Create_Business_Line) and subsequent operations.

<span id="8cd03848"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Select **Overview \> Catalog \> Asset Catalog** to enter the **Asset Catalog** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/122108b061934bfaa3a8e1b451429898~tplv-goo7wpa0wc-image.image) </span>

3. Use the business line dropdown in the upper\-right corner to select the business line you want to view.

4. You can view the following assets:

   * Click **Site\-wide assets** to see the full list of site\-wide assets.

   * Click the current business line name to view the asset data list under the current business line.

5. You can also perform the following operations as needed to search for assets and view their details.

   * Enter asset keywords in the search box, including name, field, owner, description, and other keywords, then click **Search** to view matching search results. You can also check options on the right side of the search box to narrow the search scope:

      * Search by title only: shows only assets with keywords in the title.

      * Search by field only: shows only assets where fields contain the keywords.

   * Select **My Favorites** to view the current user's favorited assets.

   * Set the Quick query

      * Add a quick query name and execute quick query

         1. Search for keywords, search range, theme directory, or filter settings in the search box，and then click the  **+**  button of **Quick query**, set a quick query name of this search in the pop\-up window to save the current search.

         2. After adding is completed, click the query name to perform the corresponding quick query.

      * Delete a quick query

         Hover over a quick query name, click the **X** icon button displayed in the upper right corner, and confirm the action to delete the quick query.

   * Click the Asset Type tab to view the asset list under the corresponding type.

   * Click the **Settings** icon button on the asset type row to adjust the order of owned asset types and filter which types to display.

   * The following filters apply only on the current line of business assets page:

      * Select a configured business line tag from the **Business Line Tags** dropdown to view assets under that tag. See the operation instructions [Label Management](https://docs.byteplus.com/docs/dataleap/Tag_Management) for configuring tags.

      * Click the data category name in the left directory to view assets under the corresponding data category.

      * From the **Dimensions** dropdown, select dimensions in order to view assets sorted by those dimensions.

         The sorting dimensions include **creation time**, **update time**, **heat**, and **shelf time**. You can combine these to sort as needed.
