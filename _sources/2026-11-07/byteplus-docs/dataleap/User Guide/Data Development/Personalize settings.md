DataLeap allows developers to customize the theme of the development environment. You can customize the main interface and editor according to your preferences.

<span id="_2-功能入口"></span>
## 1 Feature access


1. Log in to the [DataLeap Tenant Console](https://console.byteplus.com/dataleap/console/region:dataleap-console+ap-southeast-1/project/list?administrator=mine&current=1&isMine=true&pageSize=20&projectName=&projectOrOwnerName=&sortColumn=createTime&sortOrder=desc) **.** 

2. On the **Overview** page, in the joined projects, click **IDE Development** to enter the corresponding project.

3. On the **Data Development** page, at the bottom of the left navigation bar, click the **Preferences** button to open the personalization settings.

<span id="_3-功能介绍"></span>
## 2 Feature introduction

<span id="_3-1-设置"></span>
### 2.1 Settings

Click the **Settings** button to open the editor settings page. Here, you can customize **Data IDE, Text Editor, Workbench, Application** settings.


* Data IDE: Set SQL formatting styles, such as comma position formatting and keyword capitalization options.

* Text Editor: Customize efficiency features while coding, like auto\-inserting the closing bracket after an opening bracket and enabling code folding.

* Workbench: Set the number of recent commands to retain in the command panel. Set to 0 to disable command history.

* Application: Choose the key dispatch logic between the "code" type (recommended) and the "keyCode" type.


<span id="_3-2-键盘快捷方式"></span>
### 2.2 Keyboard Shortcuts


1. Click the **Keyboard Shortcuts** button to configure shortcut keys for the data development task editing interface.

2. Hover over the **command** name and click the **Edit** button, or double\-click the shortcut command you want to change to customize key bindings.

<span id="_3-3-颜色主题"></span>
### 2.3 Color Theme

Click the **color theme** button to select the **Light theme** or **Dark theme** in the interface.

<span id="_3-4-编辑器主题"></span>
### 2.4 editor theme

Click the **editor theme** button to choose from six themes: Dark (Visual Studio), Light (Visual Studio), Contrast Dark, CodeMirror Light, Monokai, and Dracula.
