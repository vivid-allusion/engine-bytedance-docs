The recycling bin stores deleted nodes under the current project, allowing tasks to be restored after deletion through the recycling bin.

The recycling bin only shows tasks deleted within the last 30 days; tasks deleted earlier cannot be recovered.

<span id="00f0da80"></span>
## 1 Prerequisite

Tasks must be deleted in the Data Development module. See details [2 Task Directory Tree Management](https://docs.byteplus.com/docs/undefined/682aa63c0c301504ff09c61a#_2-%E4%BB%BB%E5%8A%A1%E7%9B%AE%E5%BD%95%E6%A0%91%E7%AE%A1%E7%90%86).

<span id="_2-功能介绍"></span>
## 2 Function introduction

<span id="_2-1-功能入口"></span>
### 2.1 Function entry


1. Log in to the [DataLeap Tenant Console](https://console.byteplus.com/dataleap/console/region:dataleap-console+ap-southeast-1/project/list?administrator=mine&current=1&isMine=true&pageSize=20&projectName=&projectOrOwnerName=&sortColumn=createTime&sortOrder=desc) **.** 

2. In the **Overview** interface, locate your joined projects and click **Data Development** to enter the corresponding project.

3. In the **Task development** interface, click **Recycling bin** in the left navigation bar to enter the recycling bin task list.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6dbd8cc3fd9349d69c6932a1c38afdae~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-2-恢复任务"></span>
### 2.2 Restore task


1. After deleting task A in the Data Development module, click and enter **Recycling bin** in the left navigation bar.

2. Use the search box above to find task A by searching keywords and other methods.

3. Hover the mouse to the right of the task name over the **More** icon, then click the **Restore** button.

4. In the pop\-up dialog, click the **Confirm** button to complete the restoration. The task code and configuration information will be fully restored, the interface will automatically switch to the path before the task was deleted, and the task will be automatically located. If the original folder has been deleted, it will be restored to the root directory.


<span id="_2-3-彻底删除"></span>
### 2.3 Delete permanently

If a task in the recycling bin is no longer needed, hover over the **More** icon on the right, click the **Delete** button, and the task will be permanently deleted and cannot be restored.

<span id="_2-4-重命名删除的文件"></span>
### 2.4 Rename deleted files

In the Recycling bin, hover the mouse over the **More** icon to the right of the task name, click the **Rename** button, enter the new task name in the **Rename** popup, and click the **Confirm** button to complete renaming the deleted task.
