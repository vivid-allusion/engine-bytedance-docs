When performing data synchronization using DataLeap's Data Integration feature, the data synchronization task will run using the **Scheduling resource group** and the **Exclusive Integrated Resource Group**.

This article will introduce the prerequisites for using Resource Groups related to data integration tasks, basic concepts, classification, as well as connectivity and performance issues.

<span id="_1-使用前提"></span>
## 1 Use prerequisites


1. **The actual execution of data integration tasks depends on the Exclusive Data Integration Resource Group**. Therefore, before using the data integration feature, you must first enable the Exclusive Data Transmission Service Resource Group in the Console. See details: [Exclusive Integrated Resource Group Management](https://docs.byteplus.com/docs/dataleap/exclusive_integrated_resource_group).

2. Currently, the Datasource and the Exclusive Data Transmission Service Resource Group must be in the same VPC network or use the public network. For details, see [Network connectivity solution](https://docs.byteplus.com/docs/dataleap/network_connectivity_solution).


<span id="_2-基本概念"></span>
## 2 Basic concepts


1. Data Integration Resource Group:

   This refers to the computing resource group where the Data Integration task actually runs. A Resource Group is typically represented in the form of a machine, that is, by the size of the CPU, memory, and bandwidth.

2. Scheduling resource group:

   Batch data integration tasks need to be dispatched through the **Scheduling resource group** so that they run on the Data Integration Resource Group.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">For streaming integration tasks, use of a scheduling resource group is not required; these tasks can run solely by relying on the <strong>Exclusive Integration Resource Group</strong>.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d332cf140e6140dbaf06bd4aad493624~tplv-goo7wpa0wc-image.image) </span>

3. The process for executing a data synchronization task is as follows:

   1. Extract data from the machine where the data source is located to the machine where the Resource Group is located.

   2. The machine where the Resource Group is located pushes data to the machine where the target Datasource is located.


<span id="_3-计费说明"></span>
## 3 Step 3: Billing instructions

<span id="_3-1-调度资源组："></span>
### 3.1 Scheduling resource group:

A public scheduling resource group is automatically provided immediately after you enable the DataLeap product service, and the billing method is **pay per volume**.

The billing item for the public scheduling resource group is the scheduling instance. All types of instances generated by submission to the scheduling system and that run successfully will be included in the measurement range. No distinction is made between instance types; each instance that runs successfully is counted as one instance.

See details about billing for scheduling resource groups at: [Public resource group billing instructions](https://docs.byteplus.com/docs/dataleap/Billing_Instructions_for_Public_Resource_Group).

<span id="_3-2-独享集成资源组："></span>
### 3.2 Exclusive Integrated Resource Group:

The Exclusive Integrated Resource Group must be purchased separately. The billing method is **annual or monthly subscription**. For purchase instructions, see [Exclusive Integrated Resource Group Management](https://docs.byteplus.com/docs/dataleap/exclusive_integrated_resource_group).

The Exclusive integrated resource group with a 1 CU specification is priced at $31/month. The minimum specification available for sale is 4 CUs. For more billing and performance metrics, see details [Billing information for exclusive resource groups](https://docs.byteplus.com/docs/dataleap/Billing_Instructions_for_Exclusive_Resource_Groups).

<span id="_4-独享集成资源组使用"></span>
## 4 Use the Exclusive Integrated Resource Group

After purchasing an appropriately specified **Exclusive Integrated Resource Group** and ensuring that its state is **Running**, you need to bind it to the corresponding project before you can proceed with subsequent use.

An Exclusive Integrated Resource Group can be bound to multiple projects, and a project can also be bound to multiple resource groups. The following are two ways to bind Resource Groups:


1. Bind a resource group to a new project: In **New Project \> Service binding \> Data integration resource group settings**, select the resource group to bind.

2. Modify the resource group of an existing project: [DataLeap Tenant Console ](https://console.byteplus.com/dataleap/console/region:dataleap-console+ap-southeast-1/overview) **\> Project Management \> Configuration information for the specific project**. After entering, click the **Edit** button in the upper right corner. In the edit interface, modify the data integration resource group settings under Service binding.

   For details about the service binding action, see [Configure Service Binding Information](https://docs.byteplus.com/docs/dataleap/create_project#54f5e209).


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



1. <div data-tips="true" data-tips-type="warning">When modifying the service binding interface to replace an existing Exclusive Integrated Resource Group, if there are tasks already running on the original Exclusive Integrated Resource Group, those tasks will continue to run on the original group after the replacement.</div>


2. <div data-tips="true" data-tips-type="warning">On the <strong>Resource Group Management</strong> interface, after you delete an Exclusive Integrated Resource Group, existing tasks will be in the <strong>Failed</strong> state. You need to replace the old Exclusive Integrated Resource Group with a new one in the task configuration before resubmitting the publishing task.</div>


   <div data-tips="true" data-tips-type="warning">See details on the Delete Resource Group action:<a href="https://docs.byteplus.com/docs/dataleap/exclusive_integrated_resource_group">Exclusive Integrated Resource Group Management</a>   </div>
