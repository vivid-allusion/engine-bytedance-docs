This function manages the run results of dual\-data\-source validation rules. The following introduces its features.

<span id="_1-前提条件"></span>
## Prerequisites

Monitoring rules have been run.

<span id="_2-操作步骤"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Choose **Overview \> Quality \> Rules \> Batch Data Monitor \> run results** to enter the run results page.

3. Click the **Dual\-data\-source validation** tab to enter the dual\-data\-source validation rule run results page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7f6c91be85ba4ae4a30562e45dfb0bfb~tplv-goo7wpa0wc-image.image) </span>

4. Select the project to manage from the project dropdown menu at the top right of the page.

5. View all rule detection records and perform the following management actions:

   * Set search criteria to find matching rule monitor results.

   * Click the **Log** button in the **Action** column of a monitoring entry to view the rule’s running log for troubleshooting and analysis.

   * Click the  **...**   **\> Rerun** button in the **Action** column of a monitoring entry to rerun the monitor rule after confirmation.

   * Click the  **...**   **\> Stop** button in the **Action** column of a running rule to stop the current monitor rule running.

   * Click the  **...**   **\> Rules details** button in the **Action** column of a rule to display the rule details and allows test runs, reruns, and other operations.
