This feature manages the run results of Hive customized rules. The following introduces its use.

<span id="_1-前提条件"></span>
## Prerequisites

Monitoring rules have been run.

<span id="_2-操作步骤"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Select **Overview \> Quality \> Rules \> Batch \> run result** to enter the run result page.

3. Click the **Hive customized rules** tab to enter the Hive customized rules run result page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/16096575cc7e4e12950d82a49bd822b9~tplv-goo7wpa0wc-image.image) </span>

4. In the project dropdown at the top right, select the project you want to manage.

5. View all rule detection records and perform the following management actions:

   * Set search criteria to find matching rule monitor results.

   * Click the **Result** button in the **Action** column to view monitor result details and perform the following actions:

      * Click the **View Rule** button to see the rule details.

      * Click the **Run Log** button to view the rule’s monitor run log for identifying and analyzing issues.

      * Click the  **...**   **\> Execution Records** button to view detection execution records.

      * Click the  **...**   **\> View SQL** button to see the SQL execution statements of the rule on the detection day.

      * Click the  **...**   **\> rerun** button to rerun this monitoring rule after confirmation.

   * Click the **Log** button in the **Action** column of a monitoring record to view the rule’s monitoring run log and analyze issues.

   * Click the  **...**   **\> Rerun** button in the **Action** column of a monitoring record to rerun this monitoring rule after confirmation.

   * Click the  **...**   **\> Stop** button in the **Action** column of a running rule to stop the current monitoring rule run.

   * Click the  **...**   **\> Rules Details** button in the **Action** column of a rule to show the rule details and allows test runs, reruns, and other actions.
