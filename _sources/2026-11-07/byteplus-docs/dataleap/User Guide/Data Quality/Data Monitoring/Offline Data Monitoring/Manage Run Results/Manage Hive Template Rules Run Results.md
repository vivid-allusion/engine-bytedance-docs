This feature manages the run results of Hive template rules. The following is an introduction.

<span id="_1-前提条件"></span>
## Prerequisites

Monitor rules have been run.

<span id="_2-操作步骤"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Select **Overview \> Quality \> Rules \> Offline Rule \> Run result** to enter the run result page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bd060ffad91b4a7eb9ce98e3bd0d5b81~tplv-goo7wpa0wc-image.image) </span>

3. In the project dropdown list at the top right of the page, choose the project to manage.

4. You can view all rule check records and perform the following management actions:

   * Set search information to find monitoring results that match the conditions.

   * Click the **Result** button in the **Action** column on any monitoring information to view the monitoring details and perform the following actions:

      * Click the **View Rule** button to see the details of the rule.

      * Click the **Run log** button to view the monitoring run log of the rule and analyze issues.

      * Click the  **...**   **\> Execution records** button to view the detection execution records.

      * Click the  **...**   **\> View SQL** button to see the SQL statements executed by the rule on that day.

      * Click the  **...**   **\> Rerun** button and confirm to rerun this monitoring rule.

   * Click the **Log** button in the **Action** column of a monitoring entry to view the monitoring running log of the rule and analyze the problem.

   * Click the  **...**   **\> Rerun** button in the **Action** column of a monitoring entry to rerun the monitoring rule after a second confirmation.

   * Click the  **...**   **\> Stop** button in the **Action** column of a running rule to stop the current monitoring rule run.

   * Click the  **...**   **\> Rules Details** button in the **Action** column of a rule to view the rule details and perform test runs, reruns, and other operations.
