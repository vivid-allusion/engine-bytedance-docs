On this page, you can view all the work orders you have approved.

<span id="adee69f8"></span>
## Prerequisites

The work order has been approved; see [Approve Applications](https://docs.byteplus.com/docs/dataleap/Approval_Applications) related operations.

<span id="26ad9d9e"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Choose **Overview \> Security \> Approval Hub \> Applications \> Approval History** to enter the **Approval History** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b11bab60241948e9ad88f06421054c5a~tplv-goo7wpa0wc-image.image) </span>

3. Set search criteria such as Application ID, applicant, request resources information, parameters filtering, and ascending or descending order to view the work orders you approved that match the criteria.

   When multiple search criteria are set, their intersection will be queried.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the filtering option <strong>I actually approved</strong> is not selected, the list shows all applications at nodes including you; if selected, it only shows applications you actually approved, meaning applications approved by others at nodes with multiple approvers are not displayed.   </div>
   

4. Click the **Application ID** of an application to open its application details page, where you can view the application details and approval status, and perform the following actions:

   1. Click the resource name of an application in the list to view detailed information about the requested resource.

   2. Click the **View** button in the **Approval Flow** column of a record to view the approval flow for the resource permission.
