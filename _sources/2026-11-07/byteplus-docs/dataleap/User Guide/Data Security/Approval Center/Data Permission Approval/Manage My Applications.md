Use the My Applications feature to view all your submitted tickets, including application content and status. You can also withdraw or expedite requests. Applications for DB, table, row\-level\-access, and sensitive columns will be reviewed separately and do not affect each other.

<span id="00f86cb8"></span>
## Prerequisites

You must have requested resource permissions. For related operating instructions, see [Apply Permission](https://docs.byteplus.com/docs/dataleap/Apply_Permission).

<span id="994fdec3"></span>
## Operation Steps


1. Log in to the DataLeap console.

2. Select **Overview \> Security \> Approval Hub \> Applications \> My Applications** to enter the **My Applications** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/715f64e0066b44f5aeef61474721d843~tplv-goo7wpa0wc-image.image) </span>

3. The following operations can be performed:

   * View application tickets

      Set search criteria such as application time, request resources, ticket ID, parameters filtering, and sorting order to view matching application tickets. When multiple search criteria are set, the query takes the intersection of all conditions.

   * View ticket details

      Click an **Application ID** or **Request Resource** in the list to open a side panel showing ticket details, including application details, requested resources, approval status, and resource details.

   * Withdraw

      Click the **Withdraw** button in the **Action** column or on the ticket details page. In the confirmation dialog, click **OK** to withdraw the corresponding resource application. Withdrawing will recall all pending resource applications within the ticket; resources already approved are not affected.

   * Expedite Request

      Click the **Expedite Request** button in the **Action** column of an item in the list or on the application details page. In the pop\-up confirmation dialog, click the **OK** button. The approver will receive another approval notification. You can expedite once every 2 hours.

   * Reapply

      Click the **Reapply** button in the **Action** column of an item in the list or on the application details page to jump to the application page. All previously requested resources will be automatically filled in. Modify the relevant information as needed before submitting the application.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You can reapply after the application completes approval, is withdrawn, or closed.      </div>
      

   * Copy Link

      Click the **Copy Link** button in the **Action** column of an item in the list or on the application details page to copy the current application link for sending to the approver you wish to expedite. Only the applicant and those in the approval node can open this link; others do not have access rights.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If the applicant and the approver are the same person, the application will be automatically approved. On this page, you can only view the information of this application.</div>
