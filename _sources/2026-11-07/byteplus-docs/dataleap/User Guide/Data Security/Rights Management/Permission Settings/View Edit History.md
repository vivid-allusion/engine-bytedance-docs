As the authority owner of DB, table, row, and column resources, you can configure related permissions for each resource through permission settings, including authority owner, confidentiality level, application restrictions, renewal rule, and more. You can also set the approval flow others use when applying for permissions to this resource.

This function allows you to view the history of all actions.

<span id="c620649f"></span>
## Constraints

Only authority owners of DB, table, row, and column resources have this operation permission.

<span id="bc7e42fc"></span>
## Operation Steps

The process of viewing edit history for various resources is basically the same. Taking the table as an example, the steps to view edit history are as follows:


1. Log in to the DataLeap console.

2. Select **Overview \> Security \> Authorization Management \> Authority Settings \> Table** to enter the **Table** page.

3. Click the **Edit History** button in the **Action** column for a record to open the Edit History side panel.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/22a84ddb40954b1fad1bd532c72d6345~tplv-goo7wpa0wc-image.image) </span>

4. You can view past records and select 2 to 3 versions of the same operation type, then click the **Version comparison** button to compare information. Changed content appears in red font.
