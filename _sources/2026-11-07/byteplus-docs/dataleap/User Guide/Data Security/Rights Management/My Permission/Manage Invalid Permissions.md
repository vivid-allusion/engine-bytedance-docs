This feature allows you to view and manage resources with expired permissions.

<span id="259afdf2"></span>
## Constraints

Only resources with expired access rights you have applied for can be viewed and managed. The reasons for expiration include the following:


* Expired

* Permission reclamation

* Returned by grantee

* Leave user group

* Delete user group

* Warehouse handover

* Table owner handover


<span id="89f9984f"></span>
## Operation Steps


1. Log in to the DataLeap Console.

2. Select **Overview \> Security \> Authorization Management \> My Authorizations \> Invalid Permissions** to enter the **Invalid Permissions** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4a925687a783483d967df5c5de851e52~tplv-goo7wpa0wc-image.image) </span>

3. The following operations can be executed:

   * View invalid permission resources

      Set search criteria to view the resource list of matching expired invalid permissions.

   * Reapply

      * Click the **Reapply** button in the **Action** column of an item in the list to jump to the application page, which automatically fills in all resources from the last application. Modify the related information as needed before submitting the application.

      * After selecting one or more items, click the **Reapply** button below the list to perform batch reapplication.
