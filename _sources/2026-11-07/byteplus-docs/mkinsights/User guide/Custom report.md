Custom reports offer a higher level of flexibility than market communication analysis reports and reputation analysis reports. You can upload your own analysis data and define the report outline and analytical dimensions manually.

The following section explains how to use the custom report feature.


|Console screenshot |Process overview |
|---|---|
|Enter the custom report task page<br><br><div style="text-align: center"><br><img src="https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260603132332-1561816274468.png" width="1930px" /></div><br> |After entering the product page, the default function is **Monitoring task**. Manually click **Reporting task** and select **Custom report**. Enter the event name to be created based on your needs, then click the button on the right to enter the report task generation page. |
|Requirement analysis<br><br><div style="text-align: center"><br><img src="https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260603132333-1218742611651.png" width="1929px" /></div><br><br><br> |Agent experts will interpret and analyze the requirement based on the content you enter. If the analysis is accurate, click **Continue** to proceed to the next step. If the analysis is incorrect, you can revise it using natural language. |
|Data selection and outline confirmation \- 1<br><br><div style="text-align: center"><br><img src="https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260603132333-1567443570928.png" width="1928px" /></div><br> |After confirming the requirement, you can choose the corresponding report data source, directly filter different sources, or upload your own data based on the template. Then click **Next** in the lower\-right corner. |
|Data selection and outline confirmation \- 2<br><br><div style="text-align: center"><br><img src="https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260603132332-553413625643.png" width="1929px" /></div><br><br><br> |For the report outline, you can choose either a **System template**, which automatically generates an analysis framework based on the input requirement, or a **Custom template**, which allows you to define the report dimensions, outline structure, and analytical sections manually. You can drag and sort the outline by using the handle button on the left side of the title, or click the icon on the right side of the corresponding title to add a new analysis framework or subsection. You can also edit and delete the framework or section titles. Please refer to the template example if needed. Once completed, click **Confirm requirement** on the right. |
|Report generation<br><br><div style="text-align: center"><br><img src="https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260603132332-1110521777618.png" width="1929px" /></div><br> |After the report is generated, it can be exported to your local device. Currently supported formats are Word and PDF, which you can download as needed. |
