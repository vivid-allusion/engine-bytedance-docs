Reputation analysis reports are divided into two types: event analysis reports and periodic reports. Event analysis reports are mainly used to provide professional and in\-depth analysis for specific breaking or key events, helping users comprehensively understand the event timeline, impact, and public opinion across the web. Periodic reports are linked to active Monitoring tasks and provide daily or weekly reports for the corresponding time range.

The following sections explain how to use each type of report.
