# What is Canvas Pro?

Canvas Pro is an all\-in\-one creative workspace where users can bring together text, images, video, audio, and music in one place. It helps with layout, editing, asset organization, and exporting, so teams can turn ideas into polished content more easily.

Instead of relying on traditional manual design workflows, Canvas Pro makes creative production faster and more flexible. It supports users with different skill levels and helps them build content in a more intuitive way.

From **creative ideation** to **asset assembly**, **layout design**, and **final output**, Canvas Pro covers the full workflow.

**In short:**  Canvas Pro helps users create faster, present ideas more professionally, and produce content that is more compelling across different scenarios.

# **Agent makes Canvas Pro truly intelligent**

With , users can build workflows by connecting **nodes** and **components**. This already makes it possible to deliver creative outputs at scale with greater consistency and stability.

But in real projects, users often run into bigger questions:


*  Can workflow building be made simpler? 

*  Can one  automatically choose the right path for different scenarios? 

*  Can it generate strong prompts more consistently, without jumping between multiple tools? 

*  Can a single Canvas Pro support the full pipeline from **script → storyboard → video**? 


This is where **Agent** becomes powerful.

Think of Agent as the **control center** of Canvas Pro.

It can understand natural language instructions, decide what needs to be done, and accurately call the right tools—or even entire workflows—to complete the task.

In other words, Agent turns Canvas Pro from a manual workflow builder into a more intelligent, automated creative system.
