<span id="operator-introduction"></span>
# Operator introduction

<span id="description"></span>
## Description

**Specialized Processor for Large Model Text Generation (Doubao/DeepSeek)** 

<span id="core-features"></span>
## Core Features:


* Pure text scenario optimization: Automatically constructs a model\-compliant message structure based on user input text data

* Input simplification mechanism: Natively supports str\-type input, automatically encapsulating it into {role: user, content: text} format

* Multi\-task support: Ready\-to\-use for NLP scenarios like translation, summarization, Q&A, etc.

* Dual prompt system:

   * system_content: System\-level behavior guidance (e.g., translation style control)

   * prompt: User\-level instruction template (supports {query} placeholder replacement)


<span id="input-and-output-specifications"></span>
## Input and Output Specifications:


* Input format: Plain text data

* Output format:

   * Default mode: str\-type generation result

   * Diagnostic mode: Set the environment variable LAS_LLM_FINISH_REASON_CHECK=true to return the complete generation result and the model's finish reason:

* llm_result: str\-type, generation result

* finish_reason: str\-type, the finish reason of the model result, possible values: stop, length, content_filter

<span id="output"></span>
## Output

(By default) When the environment variable LAS_LLM_FINISH_REASON_CHECK=false, the returned field type is str.

When the environment variable LAS_LLM_FINISH_REASON_CHECK=true, the returned field type is struct, containing the following fields:


* llm_result: Model output result

* finish_reason: Reason for model output termination


<span id="parameters"></span>
## Parameters

If a parameter does not have a default value, it is a required parameter.


|Parameter name |Type |Default value |Description |
|---|---|---|---|
|model |str | |Model name Supported models are: Doubao models and DeepSeek models. Example: doubao\-1.5\-lite\-32k |
|version |str or None | |Model version Enter the version information corresponding to the model. Example: 250115 |
|inference_type |str |batch |Inference type, supports online inference and batch inference. Default value is batch, meaning batch inference is used \- online: Use the online inference module provided by the Ark platform for inference \- batch: Use the batch inference module provided by the Ark platform for inference |
|max_tokens |int or None | |Maximum length of model response (unit: token). The total length of input and output is limited by the model's context |
|max_completion_tokens |int or None | |Upper limit of tokens generated by the model, including chain\-of\-thought content (reasoning_content) and answer content (content), excluding incoming information (messages). When exceeded, the model stops outputting chain\-of\-thought content and answers, and returns finish_reason field as length. |
|stop |list or None | |When the model encounters the strings specified in the stop field, it stops generating further. The strings themselves are not output. Supports up to 4 strings. Example: ["Hello", "Weather"] |
|frequency_penalty |float |0 |Frequency penalty coefficient. If positive, penalizes new tokens based on their frequency in the text, reducing the likelihood of verbatim repetition. Value range [\-2.0, 2.0], default 0. |
|presence_penalty |float |0 |Presence penalty coefficient. If positive, penalizes new tokens based on whether they have appeared so far, increasing the likelihood of discussing new topics. Value range [\-2.0, 2.0], default 0. |
|temperature |float |1 |Sampling temperature. Controls the degree of smoothing applied to the probability distribution of each candidate token when generating text. \- When set to 0, the model only considers the token with the highest log probability. \- Higher values (e.g., 0.8) make the output more random, while lower values (e.g., 0.2) make it more focused and deterministic. It is usually recommended to adjust only temperature or top_p, not both. Value range [0, 2], default 1. |
|top_p |float |0.7 |Nucleus sampling probability threshold. The model considers token results whose cumulative probability mass is within top_p. When set to 0, the model only considers the token with the highest log probability. 0.1 means only the top 10% of tokens by probability mass are considered. Higher values increase randomness, lower values increase determinism. Usually adjust only temperature or top_p, not both. Default value 0.7 |
|logit_bias |dict or None | |Adjusts the probability of specified tokens appearing in the model output to make the generated content more aligned with specific preferences. The logit_bias field accepts a map where each key is a token ID from the vocabulary (obtained using the tokenization interface), and each value is the bias for that token, ranging from [\-100, 100]. \-1 reduces the likelihood of selection, 1 increases it; \-100 completely prohibits selection, 100 forces only that token to be selected. The actual effect may vary by model. |
|tools |list or None | |List of tools to be called, which can be included in the model's return information. Configure this structure when you need the model to return tools to be called. |
|llm_config |dict or None | |Custom LLM configuration Except for the above parameters, other parameters are passed through to the model. The above parameters will override values in llm_config. |
|request_timeout |int |1200 |Timeout time Timeout for a single request (seconds) |
|max_concurrency |int |100 |Concurrency count Maximum concurrency per process |
|system_content |str or None | |System prompt content System prompt content, input to the model as the system role |
|prompt |str or None | |User prompt User prompt used to guide the model's behavior. When configured, it is concatenated with the input text and sent to the model as the user role. Also, this field can be set to {query}, where the input text will replace this field. |


<span id="examples"></span>
## Examples

下面的代码展示了如何使用 daft访问火山方舟 文本生成 模型进行批量推理。请注意每次大模型推理结果可能不同。

```python
from __future__ import annotations

import os

import daft
from daft import col
from daft.las.functions.ark_llm.ark_llm_text_generate import ArkLLMTextGenerate
from daft.las.functions.udf import las_udf

if os.getenv("DAFT_RUNNER", "native") == "ray":
    import logging

    import ray

    def configure_logging():
        logging.basicConfig(
            level=logging.INFO,
            format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
            datefmt="%Y-%m-%d %H:%M:%S.%s".format(),
        )
        logging.getLogger("tracing.span").setLevel(logging.WARNING)
        logging.getLogger("daft_io.stats").setLevel(logging.WARNING)
        logging.getLogger("DaftStatisticsManager").setLevel(logging.WARNING)
        logging.getLogger("DaftFlotillaScheduler").setLevel(logging.WARNING)
        logging.getLogger("DaftFlotillaDispatcher").setLevel(logging.WARNING)

    ray.init(dashboard_host="0.0.0.0", runtime_env={"worker_process_setup_hook": configure_logging})
    daft.set_runner_ray()

daft.set_execution_config(min_cpu_per_task=0)

if __name__ == "__main__":
    # 需配置环境变量 LAS_API_KEY ： LAS_API_KEY 通过在 LAS 服务页面上创建获取
    queries = {
        "query": [
            "中国的首都在哪里",
            "十字花科植物有哪些",
        ]
    }

    ds = daft.from_pydict(queries)
    ds = ds.with_column(
        "llm_result",
        las_udf(
            ArkLLMTextGenerate,
            construct_args={
                "model": "doubao-1.5-pro-32k",
                "inference_type": "online",
            },
        )(col("query")),
    )
    ds.show()

    #  输出(每次大模型推理结果可能不同)
    # ╭────────────────────┬───────────────────────────────────────╮
    # │ query              ┆ llm_result                            │
    # │ ---                ┆ ---                                   │
    # │ Utf8               ┆ Utf8                                  │
    # ╞════════════════════╪═══════════════════════════════════════╡
    # │ 中国的首都在哪里      ┆ 中国的首都是北京。                       │
    # │                    ┆                                       │
    # │                    ┆ 北京是中国的政治中心、文化中心、国际…       │
    # ├╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┼╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┤
    # │ 十字花科植物有哪些    ┆ 十字花科植物种类繁多，常见的有：           │
    # │                    ┆ 1. **蔬菜类**                          │
    # │                    ┆  …                                    │
    # ╰────────────────────┴───────────────────────────────────────╯
```
