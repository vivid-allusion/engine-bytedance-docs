<span id="operator-introduction"></span>
# Operator introduction

<span id="description"></span>
## Description

**Specialized Processor for Large Model Text Generation (Doubao/DeepSeek)** 

<span id="core-features"></span>
## Core Features:


* Plain Text Scenario Optimization: Automatically constructs a message structure compliant with model specifications based on user input text data.

* Input Simplification Mechanism: Natively supports str\-type input and automatically encapsulates it into {role: user, content: text} format.

* Multi\-task Support: Ready\-to\-use for NLP scenarios such as translation, summarization, and Q&A.

* Dual Prompt System:

   * system_content: System\-level behavior guidance (e.g., translation style control).

   * prompt: User\-level instruction template (supports {query} placeholder replacement).


<span id="input-and-output-specifications"></span>
## Input and Output Specifications:


* Input Format: Plain text data.

* Output Format:

   * Default Mode: str\-type generation result.

   * Diagnostic Mode: Set the environment variable LAS_LLM_FINISH_REASON_CHECK=true to return the complete generation result and the finish reason of the model result:

* llm_result: str\-type, generation result.

* finish_reason: str\-type, finish reason of the model result, possible values: stop, length, content_filter.

<span id="output"></span>
## Output

(By default) When the environment variable LAS_LLM_FINISH_REASON_CHECK=false, the returned field type is str.

When the environment variable LAS_LLM_FINISH_REASON_CHECK=true, the returned field type is struct, which includes the following fields:


* llm_result: Model output result

* finish_reason: Reason for model output termination


<span id="parameters"></span>
## Parameters

If a parameter does not have a default value, it is a required parameter.


|Parameter name |Type |Default value |Description |
|---|---|---|---|
|model |str | |Model name Supported models: Doubao models and DeepSeek models. Example: doubao\-1.5\-lite\-32k |
|version |str or None | |Model version Enter the version information corresponding to the model. Example: 250115 |
|inference_type |str |batch |Inference type, supports online inference and batch inference. The default value is batch, which uses batch inference \- online: Uses the online inference module provided by the Ark platform for inference \- batch: Uses the batch inference module provided by the Ark platform for inference |
|max_tokens |int or None | |Maximum length of model response (unit: token), total length of input and output is limited by model context |
|max_completion_tokens |int or None | |Upper limit of the number of tokens generated by the model, including chain\-of\-thought content (reasoning_content) and answer content (content), excluding incoming information (messages). When exceeded, stop the model from outputting chain\-of\-thought content and model answers, and return the finish_reason field as length. |
|stop |list or None | |The model will stop generating when it encounters the strings specified in the stop field, and the strings themselves will not be output. Supports up to 4 strings. For example ["你好", "天气"] |
|frequency_penalty |float |0 |Frequency penalty coefficient Frequency penalty coefficient. If the value is positive, it will penalize new tokens based on their frequency of occurrence in the text, thereby reducing the possibility of the model repeating verbatim. Value range [\-2.0, 2.0], default is 0 |
|presence_penalty |float |0 |Presence penalty coefficient Presence penalty coefficient. If the value is positive, it will penalize new tokens based on whether they have appeared in the text so far, thereby increasing the possibility of the model talking about new topics. Value range is [\-2.0, 2.0]. Default value is 0 |
|temperature |float |1 |Sampling temperature Sampling temperature. Controls the degree of smoothing applied to the probability distribution of each candidate token when generating text. \- When the value is 0, the model only considers the token with the maximum log probability. \- Higher values (e.g., 0.8) make the output more random, while lower values (e.g., 0.2) make the output more focused and deterministic. It is usually recommended to adjust only one of temperature or top_p, not both. Value range is [0, 2]. Default value is 1 |
|top_p |float |0.7 |Nucleus sampling probability threshold Nucleus sampling probability threshold. The model considers token results whose probability mass is within top_p. When the value is 0, the model only considers the token with the maximum log probability. 0.1 means only the top 10% of tokens with the highest probability mass are considered; the larger the value, the higher the randomness of the generation, and the lower the value, the higher the determinism. It is usually recommended to adjust only one of temperature or top_p, not both. Default value is 0.7 |
|logit_bias |dict or None | |Adjusts the probability of specified tokens appearing in the model's output content so that the generated content better meets specific preferences. The logit_bias field accepts a map value, where each key is the token ID in the vocabulary (obtained using the tokenization interface), and each value is the bias value for that token, with a value range of [\-100, 100]. \-1 reduces the possibility of selection, 1 increases the possibility of selection; \-100 completely prohibits selecting the token, and 100 results in only that token being selectable. The actual effect of this parameter may vary depending on the model. |
|tools |list or None | |List of tools to be called, which can be included in the model's returned information. Configure this structure when you need the model to return tools to be called. |
|llm_config |dict or None | |Custom LLM configuration Except for the above parameters, other parameters are passed through to the model. The above parameters will override the values in llm_config |
|request_timeout |int |1200 |Timeout period Timeout period for a single request (in seconds) |
|max_concurrency |int |100 |Maximum concurrency Maximum number of concurrent requests per process |
|system_content |str or None | |System prompt content System prompt content, input to the model as the system role |
|prompt |str or None | |User prompt User prompt used to guide the model's behavior. When this field is configured, it will be concatenated with the input text and input to the model as the user role. Additionally, this field can be configured as {query}, in which case the input text will replace this field. |


<span id="examples"></span>
## Examples

The following code shows how to use daft to access the Volcano Ark text generation model for batch inference. Note that the results of each large model inference may vary.

```python
from __future__ import annotations

import os

import daft
from daft import col
from daft.las.functions.ark_llm.ark_llm_text_generate import ArkLLMTextGenerate
from daft.las.functions.udf import las_udf

if os.getenv("DAFT_RUNNER", "native") == "ray":
    import logging

    import ray

    def configure_logging():
        logging.basicConfig(
            level=logging.INFO,
            format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
            datefmt="%Y-%m-%d %H:%M:%S.%s".format(),
        )
        logging.getLogger("tracing.span").setLevel(logging.WARNING)
        logging.getLogger("daft_io.stats").setLevel(logging.WARNING)
        logging.getLogger("DaftStatisticsManager").setLevel(logging.WARNING)
        logging.getLogger("DaftFlotillaScheduler").setLevel(logging.WARNING)
        logging.getLogger("DaftFlotillaDispatcher").setLevel(logging.WARNING)

    ray.init(dashboard_host="0.0.0.0", runtime_env={"worker_process_setup_hook": configure_logging})
    daft.set_runner_ray()

daft.set_execution_config(min_cpu_per_task=0)

if __name__ == "__main__":
    # 需配置环境变量 LAS_API_KEY ： LAS_API_KEY 通过在 LAS 服务页面上创建获取
    queries = {
        "query": [
            "中国的首都在哪里",
            "十字花科植物有哪些",
        ]
    }

    ds = daft.from_pydict(queries)
    ds = ds.with_column(
        "llm_result",
        las_udf(
            ArkLLMTextGenerate,
            construct_args={
                "model": "deepseek-v3",
                "inference_type": "online",
            },
        )(col("query")),
    )
    ds.show()

    #  输出(每次大模型推理结果可能不同)
    # ╭────────────────────┬─────────────────────────────────────────────────────────╮
    # │ query              ┆ llm_result                                              │
    # │ ---                ┆ ---                                                     │
    # │ Utf8               ┆ Utf8                                                    │
    # ╞════════════════════╪═════════════════════════════════════════════════════════╡
    # │ 中国的首都在哪里   ┆ 中国的首都是**北京**。北京是中国的政治、文化、国际交往… │
    # ├╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┼╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┤
    # │ 十字花科植物有哪些 ┆ 十字花科（Brassicaceae或Cruciferae）…                   │
    # ╰────────────────────┴─────────────────────────────────────────────────────────╯
```
