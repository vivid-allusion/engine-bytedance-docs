Video subtitle translation operator that supports extracting subtitles from videos and translating them into multiple languages. Users can choose to extract subtitles from on\-screen text via OCR or from audio via ASR, then refine and translate the subtitles, outputting subtitle files in multiple formats.

<span id="operator-introduction"></span>
# Operator introduction

> Operator ID: `las_video_subtitle_translate`


<span id="application-scenarios"></span>
## Application scenarios


* **Video Globalization**: Cross\-border video communication covering short dramas, animations, movies, e\-commerce videos, and more.

* **Education**: Translating professional videos that feature different accents, expression habits, or complex terminology.


<span id="core-capabilities"></span>
## Core capabilities


* **Dual Subtitle Sources**: Supports OCR for extracting on\-screen subtitles and ASR for extracting audio subtitles.

* **Multiple Precision Levels**: Each subtitle source supports both low and high precision configurations to meet different scenario requirements.

* **Multilingual Translation**: Supports subtitle translation in 25 languages including Chinese, English, Japanese, Korean, French, German, Spanish, and more.

* **Multiple Format Output**: Supports outputting subtitle files in multiple formats simultaneously.

* **Bilingual Subtitle Recognition**: OCR mode supports recognizing translation\-type bilingual subtitles (i.e., multi\-language parallel subtitles with identical semantics, automatically semantically deduplicated during extraction to prevent redundant output) and dialogue\-type bilingual subtitles (i.e., mixed\-language subtitles generated by alternating speakers of different languages).

<span id="advantages"></span>
## Advantages


* **Comprehensive**: Provides diverse subtitle generation methods, including audio\-based subtitles for videos without on\-screen subtitles.

* **Accurate**: Offers higher subtitle extraction accuracy, especially effective in educational scenarios with complex terminology and heavy accents; provides more accurate translation for videos with various accents.

* **Cost\-effective**: Offers multiple modes to choose from, providing the most cost\-effective solution for different scenarios.


<span id="subtitle-source-description"></span>
## Subtitle source description

&nbsp;


|Subtitle Source |Description |Applicable Scenarios |
|---|---|---|
|ocr_low_precision |OCR low precision, extracting on\-screen subtitles from video frames |Videos with at least 360p resolution where subtitle text occupies more than 5% of the screen, suitable for fast processing |
|ocr_high_precision |OCR high precision, extracting on\-screen subtitles from video frames |Videos with significant non\-subtitle text on screen or subtitles occupying less than 5% of the screen, requiring higher subtitle accuracy |
|asr_low_precision |ASR low precision, extracting subtitles from audio |Videos without on\-screen subtitles or with unclear subtitles, clear articulation |
|asr_high_precision |ASR high precision, audio extraction + video understanding for subtitle refinement |Educational scenarios with complex terminology and heavy accents |

<span id="rest-api-call"></span>
# Rest API call

<span id="api-call-instructions"></span>
## API call instructions


* This operator uses asynchronous task APIs. Call the Submit interface to obtain a `task_id`, then call the Poll interface with that `task_id` to query the task status and retrieve subtitle files after the task completes.


<span id="submit"></span>
## Submit

<span id="interface-description"></span>
### Interface description

Submit an asynchronous task for video subtitle translation, supporting subtitle extraction, translation, and multi\-format output.

<span id="request-parameters"></span>
### Request parameters



**operator_id** <span data-label="purple">string</span> <span data-api-tag="require|MQYqvQ">必选</span> `Example value: las_video_subtitle_translate`

Operator ID



**operator_version** <span data-label="purple">string</span> <span data-api-tag="require|gEKlyB">必选</span> `Example value: v1`

Operator version



**data** <span data-label="purple">VideoCaptioningInfo</span> <span data-api-tag="require|Z33kd4">必选</span>

Video captioning request parameters


**video_url** <span data-label="purple">string</span> <span data-api-tag="require|nlD6Ya">必选</span> `Example value: tos://example.com/video.mp4`

Input video URL, must be accessible by the service. Supports `http/https` and `tos://bucket/key`. Supported formats: `mp4`, `mov`, `avi`, `mkv`, `flv`, `webm`. Duration limit: 10 seconds to 4 hours. Invalid files will return error codes in the Poll phase.



**caption_source** <span data-label="purple">string</span> <span data-api-tag="require|2qwlZL">必选</span> `Example value: ocr_high_precision`

Subtitle source type.

\- `ocr_low_precision`: OCR low precision, extracts on\-screen subtitles. Suitable for ≥360p resolution and subtitle area \>5%, fast processing.

\- `ocr_high_precision`: OCR high precision, extracts on\-screen subtitles. Suitable for subtitle area <5% and high accuracy requirements.

\- `asr_low_precision`: ASR low precision, extracts subtitles from audio. Suitable for standard videos with clear articulation.

\- `asr_high_precision`: ASR high precision, audio extraction + video understanding refinement. Suitable for complex terminology and heavy accents, longer processing time.



**output_language** <span data-label="purple">list of string</span> <span data-api-tag="require|enNE2c">必选</span> `Example value: [en-US]`

Output language list, at least 1 language required. More languages increase processing time and cost. Refer to the `Supported Languages` section above for supported language codes.



**audio_language** <span data-label="purple">string</span> `Optional` `Example value: zh-CN`

Audio language of the input video, required when `caption_source` is `asr_low_precision` or `asr_high_precision`. Ignored in OCR mode. Refer to the `Supported Languages` section above for supported language codes.



**caption_output_path** <span data-label="purple">string</span> <span data-api-tag="require|I3H2Er">必选</span> `Example value: tos://bucket/output/`

Subtitle output directory. Currently supports TOS Bucket directories under the same main account and in the same region with write permissions.



**caption_format** <span data-label="purple">list of string</span> `Optional` `Example value: [.srt]`

Subtitle format, options: `.txt`, `.srt`, `.xml`, `.vtt`. Empty arrays are not supported. Duplicates will be deduplicated. Default is `.srt`. Returned format field will include the leading dot.

<span id="response-parameters-1"></span>
### Response parameters



**metadata** <span data-label="purple">metadata</span>

Request metadata

Task ID in async mode.



**task_status** <span data-label="purple">string</span> `Example value: COMPLETED`

Task status in async mode.

\- PENDING: Task queued

\- RUNNING: Processing

\- COMPLETED: Completed

\- FAILED: Failed

\- TIMEOUT: Timeout



**submit_time** <span data-label="purple">string</span> `Example value: 2026-07-21T16:04:06+08:00`

Task submission time, in ISO 8601 timestamp format.



**end_time** <span data-label="purple">string</span> `Example value: 2026-07-21T16:04:06+08:00`

Task end time, in ISO 8601 timestamp format.



**business_code** <span data-label="purple">string</span> `Example value: 0`

Business code.



**error_msg** <span data-label="purple">string</span>

Error message if exception occurs.

Response data, returned only when `task_status` is `COMPLETED`. If the task fails, check `metadata.error_msg` for error details.


**video_url** <span data-label="purple">string</span> `Example value: tos://example.com/video.mp4`

Input video URL.



**video_duration** <span data-label="purple">float</span> `Example value: 98.4`

Total video duration in seconds.



**final_captions** <span data-label="purple">list of FinalCaption</span>

List of final subtitle results. Normally, one file is generated for each requested output language and subtitle format. If partial failure occurs, the failed items will not be included in the list.


**tos_path** <span data-label="purple">string</span> `Example value: tos://bucket/path/en-US_caption.srt`

TOS path of subtitle file.



**presigned_url** <span data-label="purple">string</span> `Example value: https://...`

Presigned access URL, valid for 3 days. After expiration, use `tos_path` with your own credentials to download.



**language** <span data-label="purple">string</span> `Example value: en-US`

Subtitle language.



**format** <span data-label="purple">string</span> `Example value: .srt`

Subtitle format. Includes the leading dot (e.g., `.srt`).
