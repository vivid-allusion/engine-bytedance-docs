The AI Data Lake Service (LAS) provides visual workflow capabilities, enabling visual orchestration and scheduled execution of multiple data processing tasks. A workflow is essentially a "parent task" that contains multiple subtasks; triggering the workflow triggers all its included subtasks. This document introduces how to use workflows.

# Prerequisites

* You have already created the tasks required for use in the workflow. For detailed instructions, refer to [Task management](https://docs.byteplus.com/docs/Byteplus_LAS/Task_manage).

# Create and configure workflows

## Create a workflow

1. Log in to the LAS console, select Data Processing \> Workflow \> Create workflow, then access the new workflow page.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0fb822360da244b8a4600703e7fc141a~tplv-goo7wpa0wc-topic.webp)

2. Click Add task, select the tasks to be executed in the Add task dialog, and click **Add**.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/458b245695dd491bb8274ebed3effdf7~tplv-goo7wpa0wc-topic.webp)

3. After adding, click the task node on the canvas and configure the task's Execution configuration in the sidebar that appears.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9d366cec11dd4f4a895b390c99dd95da~tplv-goo7wpa0wc-topic.webp)

   |Parameters |Configuration instructions |
   |---|---|
   |Resources |Select the queue resources used to run the current task.<br><br>> **警告**<br><br><br>> Currently, LAS AI supports two types of queue resources: dedicated queues and regular compute queues. It is recommended to use dedicated queues (that is, EMR Serverless queues) to improve queue resource utilization and flexibility. For more information about queues, see [Queue management](https://docs.byteplus.com/docs/Byteplus_LAS/queue_manage).<br> |
   |Configure resource allocation |For Daft\-type tasks, you need to allocate queue resources for the Head and Worker nodes of Daft. |
   |Entry command |The system pre\-fills the entry command for subsequent tasks based on the configuration results of the tasks you created. If there are changes, you can modify them directly. |
   |Environment variables |You can configure environment variables for the task. |
   |Task failed retry |You can configure whether to retry the current task node if it fails during workflow execution. If the switch is enabled:<br><br><br>* You also need to configure the retry strategy for task node failures, including: number of retries and retry interval.<br><br>* In subsequent workflow executions, if the current node fails, it will be rerun based on the retry strategy of the current node. |

4. After configuration, arrange upstream and downstream tasks and connect them.

5. Once configuration is complete, click **Save** and **Execute** in the upper right corner.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/862c1902889d4e478f6b0d7ef9bf55a9~tplv-goo7wpa0wc-topic.webp)

## View execution records

Viewing execution records allows you to trace information such as time, content, and results generated during task execution.

1. Enter the workflow and click the Execution Records subpage.

2. View the corresponding execution records. This displays the execution status of all nodes, as well as links to the corresponding tasks and task instances.

## Configure periodic scheduling

Users can configure periodic scheduling for specific tasks to enable repeated execution of the workflow.

1. Click **Workflow** in the upper right corner of the editing page, then click Scheduling.

2. In the Scheduling dialog, enable periodic scheduling and set the scheduling interval.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/abbe9d62039e4b67b27a9267ed4de716~tplv-goo7wpa0wc-topic.webp)

3. After configuration, click **Save** in the upper right corner.

# View workflow instances

Each workflow run generates a workflow instance. On the Workflow instance page, you can centrally query the run records, statuses, and runtime information of different workflows.

1. Log in to the LAS console, and choose **Data processing \> Workflow instance** to open the workflow instance list.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ea5e3ba18b9a449288001a227fd00d7a~tplv-goo7wpa0wc-topic.webp)

2. Configure the following filters as needed to find target workflow instances.

   * **Instance ID**: Enter a full or partial workflow instance ID.

   * **Workflow**: Select a workflow to view the instances generated by that workflow.

   * **Runner**: Select the user who ran the workflow instance.

   * **Run time**: Specify a start time and an end time to query instances that ran within the time range.

   * **Status and Trigger Type**: Click the filter icon in the corresponding list column.

3. View workflow instance details in the list.

   |Column |Description |
   |---|---|
   |Instance Name/ID |Displays the workflow name and workflow instance ID. Multiple runs of the same workflow generate different instance IDs, while the instance name uses the workflow name. Click the workflow name to open workflow details in a new page. |
   |Status |Displays the current instance status, including Done, Failed, Running, Waiting, Abnormal, and Canceled. |
   |Trigger Type |Indicates whether the instance was generated by a manual run or periodic scheduling. |
   |Run time |Displays the instance start time. |
   |Elapsed time |Displays the time elapsed from the start of the run to the current status. |
   |Person in charge |Displays the user who ran the workflow instance. |
   |Actions |Displays **Retry** for instances that support retry. A failed or abnormal instance resumes from the failed node. Retrying a completed or canceled instance creates a new instance with a new instance ID. Retry is not available for other statuses. |

# Workflow permission management

You can manage permissions for workflows you have management rights for.

1. Click the permission management button next to the corresponding workflow to grant or revoke workflow permissions for other users.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c73d1903242f43af804c7da642c5d606~tplv-goo7wpa0wc-topic.webp)

2. In the pop\-up sidebar, select or deselect users from the dropdown menu to manage permissions.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e96c20d52bc64bb6b5ccf739041e32bc~tplv-goo7wpa0wc-topic.webp)
