## View Functions

1. Log in to the LAS Console.

2. Menu selection: **Catalog**.

3. Click the required data catalog name \> database name in sequence to enter the **Database List** page.

4. On the **Database List** page, click the database name to enter the **Table** page, and select the **Function** tab.

5. On the **Function** page, click the function name you want to view to see the function details.

## Create Function

1. Log in to the LAS Console.

2. Menu selection: **Catalog**.

3. Click the required data catalog name \> database name in sequence to enter the **Database List** page.

4. On the **Database List** page, click the database name to enter the **Table** page, and select the **Function** tab.

5. Click **Create Function** in the upper right corner, fill in the function name, resource location, and other information to complete the creation of the function.

## Edit Function

> **说明**

> Users can only edit functions for which they have permission.

1. Log in to the LAS Console.

2. Menu selection: **Catalog**.

3. Click the required data catalog name \> database name in sequence to enter the **Database List** page.

4. On the **Database List** page, click the database name to enter the **Table** page, and select the **Function** tab.

5. Click **Edit** to the right of the function name to be edited, and modify the function name and other information.

## Delete Function

> **说明**

> Users can only delete functions for which they have permission.

1. Log in to the LAS Console.

2. Menu selection: **Catalog**.

3. Click the required data catalog name \> database name in sequence to enter the **Database List** page.

4. On the **Database List** page, click the database name to enter the **Table** page, and select the **Function** tab.

5. Click **Delete** to the right of the function name to be deleted, and confirm the deletion.
