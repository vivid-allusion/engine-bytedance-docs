This topic presents the feature release notes and documentation updates for BytePlus Elastic File Storage (EFS). New features will be gradually rolled out across each region. Enjoy exploring new capabilities.

<span id="mcIFcaT0"></span>
## June 2026


|**Feature** |**Description** |**Release date** |**Supported regions** |**Related documentation** |
|---|---|---|---|---|
|Data Insight |Data Insight provides a comprehensive view of your storage by quickly scanning and analyzing file system metadata. It provides insights into directory distribution, file type proportions, and access patterns. These insights help you quickly understand your current storage usage, optimize your storage strategy, and achieve granular management. |2026\-06\-22 |China (Beijing) |\- |
