You can remove the file system from a tag when it is no longer needed. This topic explains how to unbind a tag from a file system.

<span id="nE8V35Nt"></span>
## Notes

Once unbound, the tag will be automatically deleted if it is no longer associated with any resources.

<span id="aL5WwJwh"></span>
## Steps

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true"><strong>Note</strong></div>


<div data-tips="true" data-tips-type="tip">Unbinding a tag does not affect the operation of the file system.</div>



1. Log in to the [EFS console](https://console.byteplus.com/efs).

2. In the top menu bar, select the region of the file system you want to manage.

3. In the left navigation pane, select **File System**.

4. On the **File System** page, click the edit icon in the **Tag** column for the file system whose tags you want to edit.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">Alternatively, click the file system to enter the <strong>Overview</strong> page. Then, click the edit icon next to <strong>Tag</strong> in the <strong>Advanced Information</strong> section.   </div>
   

5. In the **Edit tag** dialog, verify the file system information, find the tag to unbind, and click the delete icon next to it.

6. Click **OK**.
