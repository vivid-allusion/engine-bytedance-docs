BytePlus regularly updates the FSX installation packages to provide users with access to the latest features, functionality, and security patches. This topic provides information on the latest version of FSX and its updates.

<span id="Y4SuSIBE"></span>
## Background information

Unless otherwise stated, FSX updates apply to EFS, PFS, and TOS.

<span id="7B6jXb3A"></span>
## August 2025


|Version number |Release date |Updates |
|---|---|---|
|1.2.5.311 |August 31, 2025 |* FSX now supports mounting EFS, PFS, and TOS.<br><br>* FSX now supports crash recovery. The service can automatically recover from crashes caused by various exceptions.<br><br>* FSX now supports hot upgrades. Business operations will not be interrupted during the upgrade process. |
