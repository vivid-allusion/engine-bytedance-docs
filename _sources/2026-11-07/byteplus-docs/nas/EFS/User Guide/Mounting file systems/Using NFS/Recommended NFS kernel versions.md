To ensure an optimal experience, we recommend using the kernel versions that are compatible with EFS on an NFS client.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="tip">The recommended kernel versions apply to both the NFSv3 and NFSv4 protocols.</div>



|**Operating system** |**Kernel version** |
|---|---|
|CentOS |* CentOS 7.2 64\-bit: 3.10.0\-514.26.2.el7.x86_64 or later<br><br>* CentOS 7.3 64\-bit: 3.10.0\-514.26.2.el7.x86_64 or later<br><br>* CentOS 7.4 64\-bit: 3.10.0\-693.2.2.el7.x86_64 or later<br><br>* CentOS 7.5 64\-bit: 3.10.0\-862.14.4.el7.x86_64 or later<br><br>* CentOS 7.6 64\-bit: 3.10.0\-957.21.3.el7.x86_64 or later<br><br>* CentOS 7.7 64\-bit: 3.10.0\-1062.18.1.el7.x86_64 or later<br><br>* CentOS 8.x 64\-bit: 4.18.0\-147.5.1.el8_1.x86_64 or later |
|Debian |* Debian 9.6 64\-bit: 4.9.0\-8\-amd64 or later<br><br>* Debian 9.8 64\-bit: 4.9.0\-8\-amd64 or later<br><br>* Debian 9.10 64\-bit: 4.9.0\-9\-amd64 or later |
|veLinux |veLinux 1.0 64\-bit: 5.4.143\-2\-velinux1\-amd64 or later |
