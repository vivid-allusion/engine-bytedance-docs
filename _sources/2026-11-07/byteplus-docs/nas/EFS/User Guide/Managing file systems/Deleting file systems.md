You can delete a file system that you no longer need. This topic explains how to do so.

<span id="SMaWhzIx"></span>
## Notes

All data will be permanently deleted if you remove the file system.

<span id="PGIJjR87"></span>
## Steps


1. Log in to the [EFS console](https://console.byteplus.com/efs).

2. In the top menu bar, select the region of the file system you want to manage.

3. In the left navigation pane, click **File System**.

4. On the **File System** page, click **Delete** in the **Actions** column of the file system you want to remove.

5. In the box that appears, click **Delete**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">After submitting your request, click <strong>Go to the console</strong> to open the <strong>File System</strong> page. If the file system is no longer on the list, then it has been successfully deleted.   </div>
