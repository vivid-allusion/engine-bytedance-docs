BytePlus provides performance monitoring for EFS via Cloud Monitor. This topic describes EFS monitoring metrics and the steps to view performance monitoring data.

<span id="mplOcrgf"></span>
## Prerequisites

[Cloud Monitor](https://console.byteplus.com/cloud-monitor/) has been activated.

<span id="V2TJvwlQ"></span>
## Steps

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="tip">This topic only explains how to view performance monitoring in the EFS console. You can also log in to the <a href="https://console.byteplus.com/cloud-monitor/">Cloud Monitor console</a> to view related information. For instructions, see <a href="https://docs.byteplus.com/en/docs/cloudmonitor/Basic-monitoring">Basic monitoring</a>.</div>



1. Log in to the [EFS console](https://console.byteplus.com/efs).

2. In the top menu bar, select the region of the file system you want to manage.

3. In the left navigation pane, select **File System**.

4. On the **File System** page, click the file system you want to manage.

5. In the left navigation pane, select **Monitoring alarm**.

6. On the **Monitoring alarm** page, click the performance tab you want to view to check the corresponding information.

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Note   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can specify a time range or a date for querying on the performance tab, you can select a specific time range or date to query data.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Expand the statistics chart by clicking the full\-screen icon in the upper\-right corner.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Click <strong>View more metrics</strong> in the upper\-right corner of the page to go directly to the <a href="https://console.byteplus.com/cloud-monitor/">Cloud Monitor console</a> for additional EFS alarm information.   </div>
