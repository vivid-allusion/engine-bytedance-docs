FileNAS supports exporting the relevant information of instances in the console, which facilitates operations such as statistics or archiving. This topic describes the steps to export file system information in the console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisite

The file system has been created. For specific steps, please refer to [Creating a file system](https://docs.byteplus.com/docs/nas/Creating-a-file-system).

<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the **File System List** page, click the download button located at the top right corner of the page.

4. In the pop\-up dialog box, check the parameter information that needs to be exported.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">Tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The supported export parameters include <strong>File System Name/ID</strong>, <strong>State</strong>, <strong>Tag</strong>, <strong>Availability zone</strong>, <strong>File System Type</strong>, <strong>Storage Type</strong>, <strong>File protocol</strong>, <strong>Billing type</strong>, <strong>Creation time</strong>, <strong>Affiliated project</strong>, and <strong>Total capacity</strong>.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The <strong>File System Name/ID</strong> parameter is the default export information and cannot be canceled.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The file system exports all existing instances by default and does not support custom selection of instances to export.   </div>
   

5. Click **OK** to export the instance information file to your local device.
