When you no longer need to use FileNAS, you can delete the corresponding instance.

<span id="注意事项"></span>
## Precautions

After deleting the file system, the data within it will not be recoverable. Please proceed with caution.

<span id="操作步骤"></span>
## **Procedure**


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top navigation bar, select the region where the target file system is located.

3. In the left navigation bar, select **File System** \> **File System List**.

4. On the **File System List** page, click **Delete** in the **Actions** column of the target file system.

5. In the pop\-up dialog box, click **Delete** to delete the file system.
