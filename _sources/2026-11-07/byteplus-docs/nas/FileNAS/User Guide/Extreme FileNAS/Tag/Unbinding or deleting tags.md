FileNAS adds support for tag management, tags can be used to identify resources. When an instance no longer needs a certain tag, you can remove the binding between the instance and the tag. This topic explains how to unbind tags from instances.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

After unbinding the tag, if the number of resources bound to the tag is zero, it will be automatically deleted.

<span id="84647605"></span>
## **Procedure**

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Tip</div>


<div data-tips="true" data-tips-type="tip">Unbinding tag pairs has no impact on the running of instances.</div>



1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. Find the target instance on the **File System List** page and click the edit icon in the **Tag** column.

   You can click on the target instance to enter the **File System List** page. In the **Overview** Tag, click the edit icon in the **Tag** column.

4. In the pop\-up dialog box, first confirm the instance information, find the tag that needs to be unbound, and click the delete icon on the right side of the tag.

5. Click **OK**.
