This topic introduces the operation steps to modify the automatic snapshot policy.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

After modifying the retention time of the strategy, it will only take effect on newly added automatic snapshots and will not affect the historical snapshots.

<span id=".5pON5L2c5q2l6aqk"></span>
### **Procedure**


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the left navigation bar, select **File System \> Snapshot**.

4. On the **Snapshot** page, click **Auto Snapshot Policy** tab.

5. Click **Edit** corresponding to the target strategy **Actions** column.

6. In the **Modify Auto Snapshot Policy** dialog box, modify the policy parameters and click **Modify**.
