After the snapshot creation is completed, you can modify the name and description of the snapshot. This topic describes the steps to modify the properties of a snapshot.

<span id=".5Zyo5b-r54Wn5YiX6KGo6aG16Z2i5L-u5pS5"></span>
## Modify snapshot on the snapshot list page.


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the left navigation bar, select **File System** \> **Snapshot**.

4. On the **Snapshot** list page, click **Modify Properties** in the **Actions** column of the target snapshot.

5. In the pop\-up dialog box, modify the name and description. The naming conventions for the name and description are as follows.

   
   |**Parameters** |**Description** |
   |---|---|
   |Snapshot name |Set the snapshot name, which is required. The naming convention is as follows:<br><br><br>* It cannot start with a number or hyphen (\-).<br><br>* It can only contain Chinese characters, letters, numbers, underscores (_) and hyphens (\-).<br><br>* The length should be between 1 and 128 characters.<br><br>* It cannot start with "auto". |
   |Description |Optional, length of 0~120 characters. |
   

6. After making the modifications, click **Modify**.


<span id=".5Zyo5b-r54Wn6K-m5oOF6aG16Z2i5L-u5pS5"></span>
## Modify snapshot on snapshot details page.


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the left navigation bar, select **File System** \> **Snapshot**.

4. On the snapshot list page, click the target snapshot name.

5. On the snapshot details page, click the edit button next to the snapshot name and description fields to modify the corresponding information. The naming conventions for the name and description are as follows.

   
   |**Parameters** |**Description** |
   |---|---|
   |Snapshot name |Set the snapshot name, which is required. The naming convention is as follows:<br><br><br>* It cannot start with a number or hyphen (\-).<br><br>* It can only contain Chinese characters, letters, numbers, underscores (_) and hyphens (\-).<br><br>* The length should be between 1 and 128 characters.<br><br>* It cannot start with "auto". |
   |Description |Optional, length of 0~120 characters. |
