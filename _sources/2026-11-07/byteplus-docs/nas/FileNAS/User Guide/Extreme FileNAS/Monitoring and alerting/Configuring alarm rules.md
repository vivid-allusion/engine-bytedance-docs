You can set corresponding alarm rules for the file system according to your business needs.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Tip</div>


<div data-tips="true" data-tips-type="tip">This topic only introduces the operation steps of configuring alarm strategies in the FileNAS console. You can log in to the <a href="https://console.byteplus.com/auth/login?redirectURI=%2Fcloud-monitor%2Foverview">CloudMonitor</a> console to directly configure alarm strategies. For specific steps, please refer to <a href="https://docs.byteplus.com/en/docs/cloudmonitor/Creating-an-alarm-strategy">Creating an alarm strategy</a>.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the left navigation bar, select **File System** \> **File System List**. On the **File System List** page, click on the target file system.

4. On the instance details page, click **Monitoring alarm**. On the **Monitoring alarm** tab, click on the performance tab that you want to query, and then click **Create an alert policy** at the top right corner of the page.

5. On the **Create alarm strategy** page, select the **Resource type** as fileNAS, configure other alarm parameters, and click **OK**.
