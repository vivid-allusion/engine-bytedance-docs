The BytePlus Cloud Monitor provides performance monitoring for fileNAS. This topic introduces the monitoring item descriptions related to FileNAS and the operation steps to view performance monitoring.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisite

[CloudMonitor](https://console.byteplus.com/auth/login?redirectURI=%2Fcloud-monitor%2Foverview) has been activated.

<span id=".55uR5o6n6aG56K-05piO"></span>
## Cloud Monitor metrics

For information on monitoring items related to PFS, please refer to [FileNAS Monitor metrics](https://console.byteplus.com/cloud_monitor/metricDoc?tabKey=metric&namespace=VCM_FileNAS)。

<span id="9efaf694"></span>
## **Procedure**

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Tip</div>


<div data-tips="true" data-tips-type="tip">This topic only introduces the operation steps for viewing performance monitoring on the FileNAS console. You can also view the corresponding information on the <a href="https://console.byteplus.com/auth/login?redirectURI=%2Fcloud-monitor%2Foverview">CloudMonitor</a> console. For specific steps, please refer to <a href="https://docs.byteplus.com/en/docs/cloudmonitor/Viewing-operating-system-monitoring-data">Viewing operating system monitoring data</a>.</div>



1. Log on to the [FileNAS console](https://console.byteplus.com/filenas).

2. In the top menu bar, select the region where you want to create the file system.

3. On the left navigation bar, select **File System** \> **File System List**. On the **File System List** page, click on the target file system.

4. On the instance details page, click on "Monitoring Alarms", click on the performance tab you want to query, and view the corresponding information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">Tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can select a specific time period or a specific date for querying below the Performance tab.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Click the full\-screen button in the top right corner of the chart to view the corresponding statistics chart in full screen.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can click <strong>View more metrics</strong> in the top right corner of the page to automatically redirect to the <a href="https://console.byteplus.com/auth/login?redirectURI=%2Fcloud-monitor%2Foverview">CloudMonitor</a> console and view more alarm information for FileNAS.   </div>
