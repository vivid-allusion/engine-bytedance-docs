In the FileNAS console, you can export file system details for statistics or archiving purposes. This topic outlines how to export file system details from the console.

<span id="892118ab"></span>
## Notes

Exporting a file system list includes all file systems by default. You cannot choose which ones to export.

<span id="b02e1641"></span>
## Steps


1. Log in to the [FileNAS console](https://console.byteplus.com/filenas/).

2. In the top menu bar, select the region where the target file system is located.

3. In the left navigation pane, click **File** **System** \> **File** **System** **list**.

4. On the **File System list** page, click the download icon in the upper right corner.

5. In the dialog box, check the boxes for the data categories you want to export.

   You can export information including **File System name/ID**, **Running status**, **Tag**, **Availability Zone**, **File System type**, **Storage type**, **File protocol**, **Billing type**, **Creation time**, **Affiliated project**, and **Total capacity**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><strong>File System name/ID</strong> is included by default and cannot be deselected.   </div>
   

6. Click **OK** to download the file system list to your device.
