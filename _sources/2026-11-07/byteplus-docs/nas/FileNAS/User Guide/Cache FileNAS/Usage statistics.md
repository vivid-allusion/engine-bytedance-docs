FileNAS delivers comprehensive usage analytics, enabling you to monitor the storage capacity and the number of stored files. This feature provides visibility to your Cache FileNAS resource allocation and usage patterns. This topic covers the notes and steps for viewing usage statistics.

<span id="o6QI1QCz"></span>
## Notes


* Usage statistics are updated with a delay.

* The data shown in the usage statistics are for reference only and cannot be used for billing purposes.


<span id="ADLV2ar6"></span>
## Steps

FileNAS displays statistical data on Cache FileNAS by region. Data visibility is limited to the most recent 15\-day period.


1. Log in to the [FileNAS console](https://console.byteplus.com/filenas/).

2. In the top menu bar, select the target region for data visualization.

3. In the left navigation pane, click **File System** \> **Usage statistics**.

4. On the **Usage statistics** page, select a time range and hover over the data points on the chart to view time\-correlated metrics.Data description:

   
   |Data type |Description |
   |---|---|
   |Cache Capacity |The amount of storage currently occupied in Cache FileNAS. |
   |Number of cache files used |The number of files currently stored in Cache FileNAS. |
