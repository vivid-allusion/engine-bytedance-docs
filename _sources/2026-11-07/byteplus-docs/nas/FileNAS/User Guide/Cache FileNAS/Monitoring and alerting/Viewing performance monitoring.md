BytePlus provides performance monitoring for FileNAS via Cloud Monitor. This topic is about FileNAS\-related monitoring metrics and how to view performance monitoring.

<span id="558471cd"></span>
## Prerequisites

[Cloud Monitor](https://console.byteplus.com/cloud-monitor/) has been activated.

<span id="8c5758c0"></span>
## Monitoring metric description

For more information, see [FileNAS monitoring metrics](https://console.byteplus.com/cloud_monitor/docs?namespace=VCM_veFileNAS_Cache).

<span id="38d2109d"></span>
## Steps

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This section explains the steps to view performance monitoring on the FileNAS console. Alternatively, you can find this information on the <a href="https://console.byteplus.com/cloud-monitor/">Cloud Monitoring console</a>. For more information, see <a href="https://docs.byteplus.com/en/docs/cloudmonitor/Basic-monitoring">Viewing infrastructure monitoring</a>.</div>



1. Log in to the [FileNAS console](https://console.byteplus.com/filenas/).

2. In the top menu bar, select the region where the target file system is located.

3. In the left navigation pane, select **File System** \> **File System list**. On the **File System list** page, click the target file system.

4. On the File System details page, click the **Monitoring alarm** tab. Then, on the **Monitoring alarm** tab, click the metric you want to check.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can specify a time range or a date for querying on the relevant metric tab.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Expand the statistics chart by clicking the full\-screen icon in the top right corner.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Click <strong>View more metrics</strong> in the top right corner of the page to go directly to the <a href="https://console.byteplus.com/cloud-monitor/">Cloud Monitor console</a> for additional FileNAS alarm information.   </div>
