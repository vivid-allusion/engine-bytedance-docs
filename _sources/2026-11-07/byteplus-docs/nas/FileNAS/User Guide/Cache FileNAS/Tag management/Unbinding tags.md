You can remove the file system from a tag when it's no longer needed. This topic explains how to unbind a tag from a file system.

<span id="4acc5569"></span>
## Notes

Once unbound, the tag will be automatically deleted if it is no longer associated with any resources.

<span id="e08ad798"></span>
## Steps

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Unbinding a tag does not affect the operation of the file system.</div>



1. Log in to the [FileNAS Console](https://console.byteplus.com/filenas/).

2. In the top menu bar, select the target region.

3. In the left navigation pane, click **File System ** \> ** File System list**.

4. On the **File System list** page, click the edit icon in the **Tag** column for the file system whose tags you want to edit.

   Alternatively, click the target file system to enter **File System details** page, and then click the edit icon next to **Tag** in the **Basic information** section.

5. In the dialog box, verify the file system information, find the tag to unbind, and click the delete icon next to it.

6. Click **OK**.
