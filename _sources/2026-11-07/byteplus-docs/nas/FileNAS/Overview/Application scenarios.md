File storage NAS provides you with standard access protocols and fully managed shared file system services. It provides strong storage support for low\-latency, high\-bandwidth business applications, and is used with clients such as cloud servers. It is suitable for various application scenarios such as high\-performance computing, AI data processing, container storage, content management, and Web services.

<span id="a0caa551"></span>
#### High performance computing

High access bandwidth, low latency computing applications such as biopharmaceuticals, gene sequencing, simulation, image processing, weather forecasting, etc.

<span id="13df2cbb"></span>
#### AI data processing

For I/O\-intensive applications such as image and video processing, it provides low\-latency, high\-IOPS concurrent shared access capabilities.

<span id="56cc3277"></span>
#### Container storage

For microservices, it provides fast provisioning and process\-isolated file data persistent sharing services.

Content management and web services

Stores and serves information for a wide range of applications, including websites, online distribution, and archiving.
