## Overview


|API |Description |
|---|---|
|[DescribeFileSystemOverview](https://docs.byteplus.com/en/docs/nas/DescribeFileSystemOverview) |Call the DescribeFileSystemOverview interface to list file system overview information. |

|API |Description |
|---|---|
|[DescribeFileSystems](https://docs.byteplus.com/en/docs/nas/DescribeFileSystems) |Call the DescribeFileSystems interface to enumerate file systems. |
|[CreateFileSystem](https://docs.byteplus.com/en/docs/nas/CreateFileSystem) |Call the CreateFileSystem interface to create a file system. |
|[DeleteFileSystem](https://docs.byteplus.com/en/docs/nas/DeleteFileSystem) |Call the DeleteFileSystem interface to delete the file system. |
|[ExpandFileSystem](https://docs.byteplus.com/en/docs/nas/ExpandFileSystem) |Call the ExpandFileSystem interface to expand the file system. |
|[UpdateFileSystem](https://docs.byteplus.com/en/docs/nas/UpdateFileSystem) |Call the UpdateFileSystem interface to update the file system. |

## AutoSnapshotPolicies


|API |Description |
|---|---|
|[CreateAutoSnapshotPolicy](https://docs.byteplus.com/en/docs/nas/CreateAutoSnapshotPolicy) |Call the CreateAutoSnapshotPolicy interface to create an automatic snapshot policy. |
|[DeleteAutoSnapshotPolicy](https://docs.byteplus.com/en/docs/nas/DeleteAutoSnapshotPolicy) |Call the DeleteAutoSnapshotPolicy interface to delete the automatic snapshot policy. |
|[UpdateAutoSnapshotPolicy](https://docs.byteplus.com/en/docs/nas/UpdateAutoSnapshotPolicy) |Call the UpdateAutoSnapshotPolicy interface to modify the automatic snapshot policy information. |
|[ApplyAutoSnapshotPolicy](https://docs.byteplus.com/en/docs/nas/ApplyAutoSnapshotPolicy) |Call ApplyAutoSnapshotPolicy to associate an automatic snapshot policy with the file storage instance. |
|[CancelAutoSnapshotPolicy](https://docs.byteplus.com/en/docs/nas/CancelAutoSnapshotPolicy) |Call the CancelAutoSnapshotPolicy interface to unbind the automatic snapshot policy from the file storage instance. |
