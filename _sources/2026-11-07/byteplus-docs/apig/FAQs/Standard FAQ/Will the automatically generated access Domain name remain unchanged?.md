---
title: "Will the automatically generated access Domain name remain unchanged?"
product: "API Gateway"
product_code: "apig"
source: "https://docs.byteplus.com/en/docs/apig/Will_the_automatically_generated_access_Domain_name_remain_unchanged"
---

Yes. After creating a service under the APIG instance, the system will automatically generate an access domain name. Once this domain name is generated, it will not change.
