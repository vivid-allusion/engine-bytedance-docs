After creating a service, you can view and delete it. This article introduces actions related to service management.

<span id=".5p-l55yL5pyN5Yqh"></span>
## View service

Supports viewing the default access domain name and other basic information of the service, and managing the routes associated with the service.


1. Log in to the [API Gateway Console](https://console.byteplus.com/veapig).

2. In the top navigation bar, select the target region.

3. Select **Route management \> Service list (Domain name)**  from the left navigation bar. In the service list, click on the target service name to enter the service Overview page. Supports viewing service overview, route list, monitoring, and authentication management.


<span id=".5Yig6Zmk5pyN5Yqh"></span>
## Delete Service

Supports deleting services that are no longer in use.

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>



* <div data-tips="true" data-tips-type="danger">Before deleting the service, please ensure that all routes associated with the service have been deleted.</div>


* <div data-tips="true" data-tips-type="danger">Service can not be restored after deletion. Please proceed with caution.</div>


1. Log in to the [API Gateway Console](https://console.byteplus.com/veapig).

2. In the top navigation bar, select the target region.

3. Select **Route management \> Service list (Domain name)**  from the left navigation bar. In the service list, select the service to be deleted, and click **Delete** in the **Actions** column.

4. In the popup box, click **Confirm** to delete the service.
