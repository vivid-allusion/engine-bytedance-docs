Consumer is an abstraction of the objects that access the API gateway. By using consumer, the gateway can combine one or a group of objects into a user identity, which is convenient for permission control and user management of referrers. Consumers can be various client applications, mobile applications, web applications, third\-party services, or other systems.

## Related documents

Each consumer has full credentials, which are used for authentication and authentication when accessing the gateway.


* [Creating a consumer ](https://docs.byteplus.com/en/docs/apig/Creating_a_consumer): Before enabling authentication, you need to create a consumer with the corresponding credential.

* [Generating credentials ](https://docs.byteplus.com/en/docs/apig/Generating_credentials): Based on information created by the consumer for authentication.
