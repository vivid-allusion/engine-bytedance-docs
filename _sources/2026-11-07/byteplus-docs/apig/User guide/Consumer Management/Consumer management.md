After you create a consumer, you can view, edit, and delete actions on the consumer. This article introduces you to managing consumer\-related actions.

<span id=".5p-l55yL5raI6LS56ICF"></span>
## View consumer

Support viewing consumer name, ID and other basic information and credentials.


1. Log in to the[ API Gateway console](https://console.byteplus.com/veapig).

2. In the top navigation bar, select the target region.

3. In the left navigation bar select **consumer management \> consumer list ** .

4. In the consumer list, click the target consumer name to go to the consumer details page.  You can view consumers basic information and credentials.


<span id=".57yW6L6R5raI6LS56ICF"></span>
## Edit consumer


1. Log in to the [API Gateway console](https://console.byteplus.com/veapig).

2. In the top navigation bar, select the target region.

3. In the left navigation bar select **consumer management \> consumer list ** .

4. In the consumer list, find the target consumer and click **Edit** in the **Actions** column.

5. On the edit consumer page, it is not supported to modify the **instance ** and **consumer name ** , but to modify **Notes/comments ** , then click **confirm ** .


<span id=".5Yig6Zmk5raI6LS56ICF"></span>
## Delete consumer

Support deleting consumers that are no longer used.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">Before deleting a consumer, delete all add\-ons that use that consumer.</div>


* <div data-tips="true" data-tips-type="warning">Delete consumer can not be restored, please be cautious actions.</div>


1. Log in to the API [Gateway console](https://console.byteplus.com/veapig).

2. In the top navigation bar, select the target region.

3. In the left navigation bar select **consumer management \> consumer list ** .

4. In the consumer list, find the consumer to delete and click **Delete** in the **Actions** column.
