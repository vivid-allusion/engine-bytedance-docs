This article introduces the typical application scenarios for the API gateway.

## GPU load\-based intelligent routing

Based on custom metrics, comprehensively assess the actual GPU load and schedule requests to the optimal instance to improve overall utilization.


* Supports streaming processing to reduce memory usage.

* Dynamically schedule GPU resources.

* Token\-based governance feature.

## Large model token usage limits

API\-Key\-based identity system authentication and monitoring capabilities accurately identify consumer identity and enable intelligent rate limiting.


* Compatible with OpenAI API\-Key authentication.

* Monitor token usage for different API keys

* Allocation of token usage for different consumers


<span id=".5a6J5YWo6Ziy5oqk"></span>
## Multiple model management

The AI gateway supports connecting to common large language model services and user\-built inference services, providing a unified access point to large language models.


* Hide differences in how different models are invoked and simplify the process.

* Enable fallback between different models, and enhance stability.

* Different versions of the model undergo gray testing through traffic mirroring.


<span id=".54Gw5bqm5Y-R5biD"></span>
## Multi\-cluster management & Ingress configuration synchronization

Provides both north\-south and east\-west traffic control capabilities, helps centralize API management for the business, and reduces both the number of forwarding operations and the complexity of the system.


* Supports multi\-cluster management and flexible deployment.

* Unify traffic entry points and simplify operation and maintenance management.

* Compatible with industry ingress standards, monitored resources are automatically synchronized.
