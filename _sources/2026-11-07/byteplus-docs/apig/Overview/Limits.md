This article introduces some constraints and restrictions during the use of the APIG Product. Please use your Quota reasonably to avoid affecting your business.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">If you need to adjust your Quota, please <a href="https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000170">Submit a ticket</a> to apply.</div>



|Restriction item |Description |Limit |
|---|---|---|
|Maximum number of APIG instance |Under one account, the maximum number of APIG instances that can be created per region. |10 |
|Maximum number of service |An APIG instance can create a maximum number of services. |100 |
|Maximum number of route |A Service can create a maximum number of routes. |200 |
|Maximum number of custom domain name |The maximum number of custom domain names that can be associated with one service. |10 |
