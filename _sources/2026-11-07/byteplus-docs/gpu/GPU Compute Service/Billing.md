GPU Compute Service (GPU) is a type of computing resource provided by the platform. Its metering methods (including Pay\-as\-you\-go, Subscription, and spot instances) are consistent with Elastic Compute Service. Billing items include instance type, Volumes, and EIP. For detailed billing information, please refer to [Billing overview](https://docs.byteplus.com/en/docs/ecs/Billing-overview).

If you need to know the pricing details of GPU Compute Service, you can check through the [pricing calculator](https://www.byteplus.com/en/pricing?product=ECS&tab=2). The price calculator provides reference prices. The actual costs are the fee results displayed when you order in the [ECS console](https://console.byteplus.com/ecs/region:ecs+cn-shanghai/instance).
