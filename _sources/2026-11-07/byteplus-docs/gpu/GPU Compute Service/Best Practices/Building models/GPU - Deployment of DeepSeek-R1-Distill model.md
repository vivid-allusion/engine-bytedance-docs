This article uses  and ecs.gni3cl.22xlarge instance deploying DeepSeek\-R1\-Distill\-Qwen\-7B model as examples to introduce how to deploy and run DeepSeek\-R1\-Distill models on the GPU Compute Service (GPU).

<span id="6BA8o3jQ"></span>
## Background information

<span id="68Yae9yM"></span>
### DeepSeek\-R1\-Distill

DeepSeek\-R1\-Distill is a new model fine\-tuned on the original open\-source model using 800K samples generated by DeepSeek\-R1, aiming to retain the powerful reasoning capabilities discovered by DeepSeek\-R1 at a smaller argument scale. You can follow the guidance in this article to deploy models with different argument scales as needed.


|**Model name** |**Argument magnitude** |
|---|---|
|DeepSeek\-R1\-Distill\-Qwen\-7B |7B |
|DeepSeek\-R1\-Distill\-Qwen\-32B |32B |
|DeepSeek\-R1\-Distill\-Llama\-70B |70B |


<span id="e6AfCQ8L"></span>
## Software requirements


* NVIDIA Driver:


GPU Driver: A program used to drive NVIDIA GPUs. This article takes version 535.161.08 as an example.


* Runtime environment:


vLLM: vLLM is an open\-source library that helps to more efficiently perform inference for Large Language Model (LLM). This article uses version v0.7.2 as an example.

### Step 2: Deploy and run the model


<Tabs>
<Tab zoneid="vHSCtozjjS" title="Manual deployment">
<TabTitle>Manual deployment</TabTitle>

1. [Log in to the target instance](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Linux-instance).

2. Run the following command to download vLLM.

   ```Plain Text
   pip install vllm
   ```
   

3. Run the following command to load and run the model.

   ```Plain Text
   vllm serve --host 0.0.0.0 --port 8081  --tensor-parallel-size 4   "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"
   ```
   

   Parameter description:

   * \-\-host: specify the host address for the model service to listen on. `0.0.0.0` indicates listening on all available network interfaces. Adjust as needed.

   * \-\-port: specify the <a i=1\>port number</a\> for the model service to listen on. `8081` indicates that the model service will communicate through port 8081. Adjust as needed.

      <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="default" data-wrapper-indent="2">Please ensure that you have referred to the <strong>Prepare Environment</strong> \> <strong>Modify security group configuration</strong> guide and have allowed the specified port in the inbound rules of the security group attached to the instance.      </div>
      

   * \-\-tensor\-parallel\-size: specify the number of GPUs for tensor parallel computation. The value of this argument must not exceed the number of GPUs actually available on the instance.`4`Indicating the use of 4 GPUs for tensor parallelism; please adjust as needed.

   * "": Specify the model name to load and serve. vLLM will download the model from HuggingFace and load it into memory for inference. Valid range:

      * `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B`: Download the DeepSeek\-R1\-Distill\-Qwen\-7B model and perform image\-based inference.

      * `deepseek-ai/DeepSeek-R1-Distill-Qwen-32B`: Download the DeepSeek\-R1\-Distill\-Qwen\-32B model and perform inference.

      * `deepseek-ai/DeepSeek-R1-Distill-Llama-70B`: Download the DeepSeek\-R1\-Distill\-Llama\-70B model and perform inference.


</Tab>
<Tab zoneid="j0JyFWDmxb" title="Deploy using Docker">
<TabTitle>Deploy using Docker</TabTitle>

1. [Log in to the target instance](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Linux-instance).

2. Run the following command to install and configure Docker.

   ```Plain Text
   sudo apt update
   sudo apt install ca-certificates curl gnupg lsb-release
   sudo mkdir -p /etc/apt/keyrings
   curl -fsSL https://mirrors.ivolces.com/docker/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
   echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.ivolces.com/docker/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
   sudo apt update
   sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin
   ```
   

3. Run the following command to install NVIDIA Container Toolkit.

   ```Plain Text
   curl -s https://mirrors.ivolces.com/nvidia_all/ubuntu2204/x86_64/3bf863cc.pub | sudo apt-key add -
   cat <<EOF >/etc/apt/sources.list.d/nvidia.list
   deb http://mirrors.ivolces.com/nvidia_all/ubuntu2204/x86_64/ /
   EOF
   apt update
   apt install nvidia-container-toolkit
   ```
   

4. Run the following command to configure Docker so that containers can use the GPU resources of the instance.

   ```Plain Text
   sudo nvidia-ctk runtime configure --runtime=docker
   sudo systemctl restart docker
   ```
   

5. Run the following commands to download the model.

   ```Plain Text
   docker run --runtime nvidia --gpus all \
           --name my_vllm_container \
           -v ~/.cache/huggingface:/root/.cache/huggingface \
           --env "HUGGING_FACE_HUB_TOKEN=<secret>"
           --ipc=host \
           vllm/vllm-openai:latest \
           --model deepseek-ai/DeepSeek-R1-Distill-Qwen-7B\
           --tensor-parallel-size 4
   ```
   

   Parameter description:

   * \-\-env: Configure environment variables. This command is used to configure the access token for HuggingFace. Replace `<secret>` with your token value. For more details, you can view [User access tokens](https://huggingface.co/docs/hub/security-tokens).

   * \-\-model: Specify the model name to be loaded and served. vLLM will download the model from HuggingFace and load it into memory for inference. Valid range:

      * `deepseek-ai/DeepSeek-R1-Distill-Qwen-7B`: Download the DeepSeek\-R1\-Distill\-Qwen\-7B model and perform image\-based inference.

      * `deepseek-ai/DeepSeek-R1-Distill-Qwen-32B`: Download the DeepSeek\-R1\-Distill\-Qwen\-32B model and perform inference.

      * `deepseek-ai/DeepSeek-R1-Distill-Llama-70B`: Download the DeepSeek\-R1\-Distill\-Llama\-70B model and perform inference.

   * \-\-tensor\-parallel\-size: Specify the number of GPUs for tensor parallel computation. This argument value must not exceed the actual number of GPUs available in the instance.`4`Indicates the use of 4 GPUs for tensor parallelism; please adjust as needed.

6. Execute the following commands to run the model service.

   ```Plain Text
   docker exec -it my_vllm_container bash -c "vllm serve deepseek-ai/DeepSeek-R1-Distill-Qwen-7B"
   ```

### Step 3: Call the model


1. [Log in to the target instance](https://docs.byteplus.com/en/docs/ecs/Using-the-console-to-log-on-to-a-Linux-instance).

2. Run the following command to call the model, ensuring that the deployed model can perform inference normally.

   ```Plain Text
   curl -X POST "http://localhost:8000/v1/chat/completions" \
           -H "Content-Type: application/json" \
           --data '{
                   "model": "deepseek-ai/DeepSeek-R1-Distill-Qwen-7B",
                   "messages": [
                           {
                                   "role": "user",
                                   "content": "What is the capital of France?"
                           }
                   ]
           }'
   ```
   

   **Parameter description:** 

   This document only explains the argument information used for verification. For more argument details, view [DeepSeek API Docs](https://api-docs.deepseek.com/api/create-chat-completion).

   
   |Argument |Explaination |Sample Values |
   |---|---|---|
   |model |The name of the model being used. |deepseek\-ai/DeepSeek\-R1\-Distill\-Qwen\-7B |
   |messages |The list of messages in the conversation.<br><br><br>* role: The initiating role of this message.<br><br>* content: The content of the message. |\- |
