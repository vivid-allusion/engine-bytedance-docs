We recommend using APIs to manage your cloud resources and develop your own applications.

The APIs supported by GPU instances are the same as those for ECS instances. For more information, see [API overview](https://docs.byteplus.com/en/docs/ecs/Overview-4) and [ECS API overview](https://docs.byteplus.com/en/docs/ecs/Elastic-Compute-Service-API-overview).
