Before you purchase an ECS instance, you need to understand the following requirements:


* You have completed [account registration](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* You have [topped up your account](https://docs.byteplus.com/en/docs/6269/100434) and confirmed that the balance is at least 100 RMB. Otherwise, you will not be able to purchase cloud resources such as ECS instances.

* You need to create projects based on your needs. A project is a task in your daily work. You can create multiple projects under the same account and create or purchase cloud resources for each project. Cloud resources cannot be shared or migrated between different projects. For information about how to create a project, see [Managing projects](https://docs.byteplus.com/en/docs/ecs/Managing-projects).

* You need to create a new Virtual Private Cloud (VPC) and security group in the target region to build a private network environment for the ECS instance. For more information, see [Setting up IPv4 VPCs](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv4-VPC) and [Creating security group](https://docs.byteplus.com/en/docs/vpc/Creating-a-security-group).

* The platform provides a variety of public images, which include standard operating systems and basic application data and are visible to all users. For more information, see [Image release notes](https://docs.byteplus.com/en/docs/gpu/GPU-Image-release-notes). In addition, the platform offers custom features. If you have additional requirements for images, such as preinstalled public or private applications, you can also create custom images by referring to [Image overview](https://docs.byteplus.com/en/docs/ecs/Image-overview). Custom images are exclusive to your account and only visible to you.
