This topic summarizes diagnosis items, detection items, repair suggestions, and other details about the cluster diagnosis feature.


|**Diagnosis metric ID** |Diagnosis item on the console |**Diagnosis item description** |**Impact** |**Repair suggestion** |
|---|---|---|---|---|
|GuestOS.RdmaAgentService |Stand\-alone diagnosis |Check the status of the RDMA network configurator. |If the rdma\-agent.service of the instance is in an exception status, issues may occur. For example, the RDMA network is unavailable, or RDMA network performance falls short of expectations. |[Solution for exceptions of RDMA network configurator](https://docs.byteplus.com/en/docs/ecs/Solution_for_RDMA_Network_Configurator_Not_Running_Normally) |
|GuestOS.Nvidia.DriverStatus ||Check the version of the GPU driver. |If the GPU driver is not detected and does not respond, you may fail to use GPU normally. |[Installing GPU drivers](https://docs.byteplus.com/en/docs/gpu/Installing-GPU-drivers) |
|GuestOS.Nvidia.FabricmanagerService ||Check the status of the nvidia\-fabricmanager.service on the instance. |If the nvidia\-fabricmanager.service of the instance is in an exception status, the GPU can not function normally. |[Solution for nvidia-fabricmanager.service status exception](https://docs.byteplus.com/en/docs/ecs/Solution_for_nvidia_fabricmanager_service_status_exception) |
|GuestOS.Nvidia.ModStatus ||Check whether the kernel modules required for instance GPU are loaded. |If kernel modules required for GPUs of the instance are not loaded, partial GPU features may be unavailable or the GPU performance may be degraded. |[Solution for unloading of kernel modules required by NVIDIA](https://docs.byteplus.com/en/docs/ecs/Solution_for_unloaded_NVIDIA_required_kernel_modules) |
|GuestOS.Nvidia.NicConfig ||Check whether the RDMA network interface in the instance is normally configured. |If the on\-chip configuration of instance RDMA network interfaces is incorrect, the RDMA network interface may fail to function correctly or the performance of RDMA network interface may be degraded. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.RailOptimized ||Check whether the RDMA network interface in the instance is configured for multi\-rail networking. |If the RDMA network interface in the instance is not configured for multi\-rail networking, the RDMA network performance may be degraded. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.MonitorStatus ||Check whether the BytePlus monitoring service in the instance is running normally. |If the monitoring service in the instance is not installed or is in an exception status, this may cause delayed detection of instance exceptions. |[Installing plugins](https://docs.byteplus.com/en/docs/cloudmonitor/Installing-an-agent) |
|GuestOS.Nvidia.NvmlStatus ||Check the NVIDIA NVML library in the instance for exceptions. |If the NVIDIA NVML library within the instance fails to link correctly, this may cause delayed detection of GPU exceptions in the instance. |[Solution for link exceptions in NVML link libraries](https://docs.byteplus.com/en/docs/ecs/Solution_for_NVML_link_library_link_exception) |
|GuestOS.Nvidia.OfedStatus ||Check whether the driver for the RDMA network interface is correctly installed within the instance and whether the correct driver version of RDMA network interface can be obtained. |If the driver for RDMA network interface in the instance is not detected, you may fail to use RDMA network interface normally. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.Gdr ||Check the GDR performance of the GPU for the instance. |* If an exception occurs, this may cause low GDR performance between the RDMA network interface and the GPU of the instance.<br><br>* If the performance test fails, this may affect the GDR connection between the RDMA network interface and the GPU of the instance. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.RdmaNic ||Check the performance and connectivity of RDMA network interface. |The performance of the RDMA network interface is low or the RDMA network interfaces within the instance can not connect. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.NcclTest ||Check whether the performance of NVIDIA nccl\-tests on one instance is abnormal. |The performance of the instance in NVIDIA nccl\-tests results is low. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.H2dBandwidthTest ||Check whether the bandwidth performance between GPU and the instance host is normal |The bandwidth performance between the GPU and the instance host is low. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.P2PBandwidthTest ||Check the bandwidth performance and connectivity between GPUs for exceptions. |The bandwidth performance between GPUs in the instance is low or the bandwidth connection fails. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Nvidia.DcgmTest ||Check whether exceptions occur in the NVIDIA DCGM. |If exceptions occur, this may cause other NVIDIA GPU exceptions. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Hpc.ConnectivityTest |Cluster diagnosis |Check the connectivity of RDMA network interfaces and switches within the cluster, and the connectivity of the switches. |RDMA network interfaces in the instance are not connected to the cluster. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|GuestOS.Hpc.NcclTests ||Check the connection status of instances within the cluster in nccl\-tests. |If the connection of NVIDIA nccl\-tests within the cluster fails, conduct troubleshooting and analysis based on the diagnosis results of the performance​ exceptions. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
|||Check the nccl\-tests performance between instances within the cluster. |If the performance shown in the NVIDIA nccl\-tests within the cluster is low, conduct troubleshooting and analysis based on the detection results of the exception diagnosis items of the instance performance. If there are other loads on the GPU during the test, ignore this error. If other GPU issues exist, fix and try again. |[Submit a ticket](https://console.byteplus.com/ticket/createTicketV2/) |
