After the cluster diagnosis is complete, you can use the diagnosis report feature to view historical diagnosis results. You can also perform the diagnosis again and confirm whether the exceptions have been resolved.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [instance console](https://console.byteplus.com/ecs/region:ecs+cn-beijing/instance?projectName=default).

2. In the left\-side navigation pane, select "Instances & Images \> HPC Cluster".

3. In the top navigation bar, select the project and region of the target instance.

4. Click the "Cluster diagnosis" tab to view all cluster diagnosis reports for checking details, including the report ID, status, exception type, and diagnosis time range.

5. In the "Operation" column of the target cluster diagnosis, click the "View the report" button to view the diagnosis result and details of one or more instances deployed in the cluster.

6.  **(Optional) ** If there are exceptions that you are suggested to fix, you can follow the repair suggestion or the [diagnosis item repair suggestions](https://docs.byteplus.com/en/docs/gpu/Diagnosis_summary). Then click the "Re\-diagnosis" button to confirm whether the exceptions have been resolved.
