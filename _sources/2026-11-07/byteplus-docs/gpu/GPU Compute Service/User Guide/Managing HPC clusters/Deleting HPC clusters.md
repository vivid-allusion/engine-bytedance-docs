This topic describes how to delete HPC clusters that are no longer in use.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">HPC clusters within which ECS instances are deployed can not be deleted.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [HPC Cluster console](https://console.byteplus.com/ecs/hpcCluster). 

2. In the top menu bar, select the project and region.

3. Click the "Delete" button in the "Actions" column of the target cluster.

4. After you confirm the information, click the "Delete" button.
