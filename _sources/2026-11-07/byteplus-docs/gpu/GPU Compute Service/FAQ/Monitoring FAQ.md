## How can I view the monitoring data of a GPU instance?

You can view monitoring data in the ECS console or the Cloud Monitor console. For details on viewing methods and supported monitoring metrics, refer to [Monitoring overview](https://docs.byteplus.com/en/docs/gpu/Cloud-Monitor-overview).

<span id=".R1BV5LqR5pyN5Yqh5Zmo5a6e5L6L5pSv5oyB5p-l55yLR1BV5Y2h5pWw5o2u5ZCX77yf"></span>
## Does a GPU instance support viewing GPU card data?

Yes. GPU instances support basic monitoring, operating system monitoring, and GPU card monitoring. For details, refer to [Monitoring overview](https://docs.byteplus.com/en/docs/gpu/Cloud-Monitor-overview).

<span id=".5aaC5L2V5p-l55yLR1BV5Y2h55qE5L2_55So546H77yf"></span>
## How can I view the usage rate of a GPU card?

GPU instances are integrated with Cloud Monitor, offering you visualized metrics of GPU cards. Refer to [Cloud Monitor overview](https://docs.byteplus.com/en/docs/gpu/Cloud-Monitor-overview) to install the plugin and complete authorization in the instance. This way, you can view the monitoring data.

<span id=".5aaC5L2V5p-l55yLUkRNQee9keWNoeeahOaAp-iDveaMh-agh--8nw=="></span>
## How can I view the performance metrics of an RDMA network interface?

GPU instances are integrated with Cloud Monitor, offering you visualized metrics of RDMA network interfaces. You can view the data without installing the plugin. For details, refer to [Monitoring overview](https://docs.byteplus.com/en/docs/gpu/Cloud-Monitor-overview).

<span id=".5Li65LuA5LmI5peg5rOV5p-l55yLR1BV55uR5o6n5pWw5o2u77yf"></span>
## Why can't GPU monitoring data be viewed?

To view operating system monitoring and GPU card monitoring data, you need to install the plugin and complete authorization in the instance first. For more information, refer to [ECS monitoring overview](https://docs.byteplus.com/en/docs/cloudmonitor/Overview-1).
