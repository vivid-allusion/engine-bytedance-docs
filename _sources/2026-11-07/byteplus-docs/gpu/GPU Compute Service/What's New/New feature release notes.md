This topic introduces the feature releases of various GPU feature versions and the corresponding documentation updates. New features will be gradually released in each in all regions. Welcome to explore them.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The "Beta" products or features are not available to all users. To facilitate understanding of products, some documents for "Beta" products or features have been made available to all users. Note that certain documents for "Beta" products or features are only accessible to users with access permission to such products. If you need to try Beta products or features, please contact your account manager to apply.</div>
