This data type includes information about the user that a policy is attached to. It is used as a response element in method ListEntitiesForPolicy.

<span id="b4f66480"></span>
## Structure


|**Parameter** |**Type** |**Description** |
|---|---|---|
|UserName |String |Username. |
|DisplayName |String |The user's display name. |
|AttachDate |String |The time when the policy was attached to the user. |
|Description |String |User description. |
