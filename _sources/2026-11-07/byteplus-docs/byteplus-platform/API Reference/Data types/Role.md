This data type includes information about roles. It is used as a response element in the following methods:


* [CreateRole](https://docs.byteplus.com/byteplus-platform/reference/createrole)

* [GetRole](https://docs.byteplus.com/byteplus-platform/reference/getrole)

* [ListRoles](https://docs.byteplus.com/byteplus-platform/reference/listroles)


<span id="f907ce3e"></span>
## Structure


|**Parameter** |**Type** |**Description** |
|---|---|---|
|RoleName |String |Role name. |
|Description |String |Role description. |
|Trn |String |The resource name of the role. |
|TrustPolicyDocument |String |The trust policy of the role. |
|CreateDate |String |The time when the role was created. |
