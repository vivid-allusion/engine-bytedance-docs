This data type includes information about the role that a policy is added to. It is used as a response element in method [ListEntitiesForPolicy](https://docs.byteplus.com/byteplus-platform/reference/listentitiesforpolicy).

<span id="6ce5a3d3"></span>
## Structure


|**Parameter** |**Type** |**Description** |
|---|---|---|
|RoleName |String |Role name. |
|AttachDate |String |The time when the policy was attached to the role. |
|Description |String |Role description. |
