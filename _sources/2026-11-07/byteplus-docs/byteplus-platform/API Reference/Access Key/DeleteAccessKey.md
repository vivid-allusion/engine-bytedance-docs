Deletes a specified AccessKey.

The admin account is able to delete AccessKey(s) for itself and its IAM users. The authorized IAM user(s) are able to delete AccessKey(s) for other IAM users.

<span id="09118c06"></span>
## Method

HTTP GET

<span id="259f7f00"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DeleteAccessKey` |
|Version |String |Yes |`DeleteAccessKey` |
|AccessKeyId |String |Yes |AccessKey ID. |


<span id="7ff2b009"></span>
## Response parameter

None.
