Below are AccessKey\-related APIs.


|**API** |**Description** |
|---|---|
|[CreateAccessKey](https://docs.byteplus.com/byteplus-platform/reference/createaccesskey) |Creates a new pair of AccessKey ID (AK) and secret AccessKey (SK) for the admin account or a user. |
|[UpdateAccessKey](https://docs.byteplus.com/byteplus-platform/reference/updateaccesskey) |Updates a specified AccessKey. |
|[ListAccessKeys](https://docs.byteplus.com/byteplus-platform/reference/listaccesskeys) |Gets a list of AccessKeys that belongs to the admin account or a specified IAM user. |
|[DeleteAccessKey](https://docs.byteplus.com/byteplus-platform/reference/deleteaccesskey) |Deletes a specified AccessKey. |
