A BytePlus API request consists of the following parts:

<span id="a19e01c0"></span>
## Service address

The service address of BytePlus OpenAPI is: [open.byteplusapi.com](http://open.byteplusapi.com)

<span id="85b5f73f"></span>
## Communication protocol

BytePlus API requests support both HTTP and HTTPS. It is recommended that you use HTTPS for ensuring request security.

<span id="399057ad"></span>
## Request method

Most BytePlus OpenAPI services support GET and POST.

For the request method of each API operation, refer to the API reference documentation of the target service.

<span id="b0979de0"></span>
## Request parameters

A BytePlus API request usually contains both common request parameters and service\-specific request parameters.


* Common request parameters are required for each API request.

* Service\-specific request parameters are described in the reference documentation of each API operation.


<span id="841f09ca"></span>
## Character encoding

BytePlus API requests and responses are encoded with `UTF-8`.
