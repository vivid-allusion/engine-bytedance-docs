The example of calculating a signature is as follows:

<span id="3bf77f4c"></span>
## Creating a canonical request

The format of a canonical request is as follows:

```text
CanonicalRequest = HTTPRequestMethod + '\n' + CanonicalURI + '\n' + CanonicalQueryString + '\n' + CanonicalHeaders + '\n' + SignedHeaders + '\n' + HexEncode(Hash(RequestPayload))
```


The descriptions and sample values of related fields are as follows:


|**Field name** |**Sample value** |**Description** |
|---|---|---|
|HTTPRequestMethod |`GET` |/ |
|CanonicalURI |`/` |/ |
|CanonicalQueryString |`Action=ListUsers&Limit=10&Offset=0&Version=2018-01-01` |/ |
|CanonicalHeaders |`content-type:application/x-www-form-urlencoded; charset=utf-8`<br><br>`host:iam.byteplusapi.com`<br><br>`x-content-sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`<br><br>`x-date:20201230T081805Z`<br><br>`// An extra line here` |Convert all the headers and header values that need to be included in calculating the signature into lowercase, then sort them in ASCII order in the format of key\-value pairs. |
|SignedHeaders |`content-type;host;x-content-sha256;x-date` |/ |
|HexEncode(Hash(RequestPayload)) |`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855` |Both GET and POST requests have `RequestPayload`.<br><br>In this example, `RequestPayload` is an empty string. Therefore, the hash algorithm is **sha256 []byte** . |


The resulting canonical request is as follows:

```text
GET
/
Action=ListUsers&Limit=10&Offset=0&Version=2018-01-01
content-type:application/x-www-form-urlencoded; charset=utf-8
host:iam.byteplusapi.com
x-content-sha256:e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
x-date:20201230T081805Z

content-type;host;x-content-sha256;x-date
e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```


<span id="b7a90ce1"></span>
### Extracting a signature string

The format of a signature string is as follows:

```text
StringToSign = Algorithm + '\n' + RequestDate + '\n' + CredentialScope + '\n' + HexEncode(Hash(CanonicalRequest))
```


The sample values of related fields are as follows:


|**Field name** |**Sample value** |
|---|---|
|Algorithm |`HMAC-SHA256` |
|RequestDate |`20201230T081805Z` |
|CredentialScope |`20201230/ap-singapore-1/iam/request` |
|HexEncode (Hash (CanonicalRequest)) |`4809ff4a3260bb6714f750191275cfcf0c16466951fcfd99187e69644b6ae020` |


The resulting `StringToSign` is as follows:

```text
HMAC-SHA256
20201230T081805Z
20201230/ap-singapore-1/iam/request
4809ff4a3260bb6714f750191275cfcf0c16466951fcfd99187e69644b6ae020
```

## Calculating the signing key and signature

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">In the following example, <code>HMAC</code> represents <code>HMAC-SHA256</code>.</div>


**Calculating the signing key**

See the following for calculating the signing key:

```text
HMAC(HMAC(HMAC(HMAC(kSecret,"20201230"),"ap-singapore-1"),"iam"),"request")
```


The following string is the sample signing key generated by the above HMAC hash operations, which illustrates the hexadecimal representation of each byte in this binary signature key.

```text
e7d2eb478084eaaaf8f85c161de16f13d97e52e77bd0415f33e7feb561cccffd
```


**Calculating the signature**

See the following for calculating the signature:

```text
signature = HexEncode(HMAC(Signingkey, StringToSign))
```


The sample resulting signature is as follows:

```text
28eeabbbd726b87002e0fe58ad8c1c768e619b06e2646f35b6ad7ed029a6d8a7
```


<span id="82ef1fb9"></span>
## Constructing the `Authorization` header

Add `Authorization` to the request header. The format of `Authorization` is as follows:

```text
Authorization: HMAC-SHA256 Credential={AccessKeyId}/{CredentialScope}, SignedHeaders={SignedHeaders}, Signature={Signature}
```


The composed value of `Authorization` is as follows:

```text
HMAC-SHA256 Credential=AKLTMjI2ODVlYzI3ZGY1NGU4ZjhjYWRjMTlmNTM5OTZkYzE/20201230/ap-singapore-1/iam/request, SignedHeaders=content-type;host;x-content-sha256;x-date, Signature=28eeabbbd726b87002e0fe58ad8c1c768e619b06e2646f35b6ad7ed029a6d8a7
```
