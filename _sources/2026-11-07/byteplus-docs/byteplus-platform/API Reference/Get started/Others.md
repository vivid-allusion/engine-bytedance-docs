New guidelines for product/feature communications to ensure market clarity and set proper customer expectations. Byteplus will adopt a two\-phase approach for all future product launches:


* **Phase One:**  Product will be available exclusively in the Experience Center without full API access. During this period, all partners must receive written approval from Byteplus before communicating product availability to clients. Partners need to use "Coming Soon" terminology when referring to unreleased products. Select partners may receive additional support, including sample demo creation.

* **Phase Two:**  Byteplus will provide complete API access to the product. Only after integrating official API access may partners communicate that products are available for use. The company will coordinate with select partners for joint co\-launch social announcements, with featured partners referenced in Byteplus launch materials.


&nbsp;

**Strictly Prohibited Communications:** 


1. False Availability Claims: Partners must NOT advertise that product is available on their platform or ready for usage when the product has not yet been released by Byteplus.

2. False API Access Claims: Partners must NOT claim they have API access or can provide API services to others when Byteplus has not yet released API.

3. False Usage Capacity: When the product API is initially released with rate limits (if applicable), partners must NOT advertise unlimited usage capabilities.


&nbsp;

The company emphasized that certain communications are strictly prohibited, including false availability claims, false API access claims, and misrepresentation of usage capacity. Byteplus reserves the right to take action against partners who distribute misleading information, including but not limited to, immediate termination of Partner Agreement.

For more information about Byteplus, please visit [www.byteplus.com](http://www.byteplus.com).
