Deletes a specified role.

<span id="2a884ebe"></span>
## Method

HTTP GET

<span id="4f8aed31"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DeleteRole` |
|Version |String |Yes |`2018-01-01` |
|RoleName |String |Yes |Role name. |


<span id="f2abfe20"></span>
## Response parameter

None.
