Below are role\-related APIs.


|**API** |**Description** |
|---|---|
|[CreateRole](https://docs.byteplus.com/byteplus-platform/reference/createrole) |Creates a role. |
|[GetRole](https://docs.byteplus.com/byteplus-platform/reference/getrole) |Gets the information about a specified role. |
|[UpdateRole](https://docs.byteplus.com/byteplus-platform/reference/updaterole) |Updates information for a specified role, such as the name, trust policy, and description. |
|[ListRoles](https://docs.byteplus.com/byteplus-platform/reference/listroles) |Gets a list of roles. |
|[DeleteRole](https://docs.byteplus.com/byteplus-platform/reference/deleterole) |Deletes a specified role. |
|[CreateServiceLinkedRole](https://docs.byteplus.com/byteplus-platform/reference/createservicelinkedrole) |Creates a role that is attached to a specified service. |
