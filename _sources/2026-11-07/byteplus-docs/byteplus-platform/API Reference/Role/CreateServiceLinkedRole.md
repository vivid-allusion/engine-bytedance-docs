Creates a role that is attached to a specified service.

<span id="666169b3"></span>
## Method

HTTP GET

<span id="894daed5"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`CreateServiceLinkedRole` |
|Version |String |Yes |`2018-01-01` |
|ServiceName |String |Yes |Service name. |


<span id="ce0510c0"></span>
## Response parameter

None.
