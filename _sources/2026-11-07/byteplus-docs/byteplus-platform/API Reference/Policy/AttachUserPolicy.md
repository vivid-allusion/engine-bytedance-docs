Attaches a specified policy to a specified user.

<span id="55ca8cc3"></span>
## Method

HTTP GET

<span id="b4118ab5"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`AttachUserPolicy` |
|Version |String |Yes |`2018-01-01` |
|PolicyName |String |Yes |Policy name. |
|PolicyType |String |Yes |Policy type: `System` |
|UserName |String |Yes |The name of the user that the policy is to be attached to. |


Response parameter

None.
