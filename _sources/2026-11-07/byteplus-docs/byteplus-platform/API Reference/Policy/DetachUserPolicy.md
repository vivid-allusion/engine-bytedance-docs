Detaches a specified policy from a specified user.

<span id="82b39b49"></span>
## Method

HTTP GET

<span id="113217a1"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DetachUserPolicy` |
|Version |String |Yes |`2018-01-01` |
|PolicyName |String |Yes |Policy name. |
|PolicyType |String |Yes |Policy type: `System` |
|UserName |String |Yes |The name of the user that the policy is to be detached from. |


Response parameter

None.
