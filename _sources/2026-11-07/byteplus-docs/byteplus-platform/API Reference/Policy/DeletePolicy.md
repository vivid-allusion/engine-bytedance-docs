Deletes a user custom policy.

<span id="9ab1e0ca"></span>
## Method

HTTP GET

<span id="cef6cc7d"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DeletePolicy` |
|Version |String |Yes |`2018-01-01` |
|PolicyName |String |Yes |Policy name. |


<span id="510e4bd0"></span>
## Response parameter

None.
