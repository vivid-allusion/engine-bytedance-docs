Detaches a specified policy from a specified role.

<span id="604a5c68"></span>
## Method

HTTP GET

<span id="b82a3f7c"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DetachRolePolicy` |
|Version |String |Yes |`2018-01-01` |
|RoleName |String |Yes |Role name. |
|PolicyName |String |Yes |Policy name. |
|PolicyType |String |Yes |Policy type: `System` |


<span id="96defbdb"></span>
## Response parameter

None.
