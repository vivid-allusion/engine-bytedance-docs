Below are policy\-related APIs.


|**API** |**Description** |
|---|---|
|[CreatePolicy](https://docs.byteplus.com/byteplus-platform/reference/createpolicy) |Creates a user custom policy. |
|[GetPolicy](https://docs.byteplus.com/byteplus-platform/reference/getpolicy) |Get the information about a specified policy. |
|[UpdatePolicy](https://docs.byteplus.com/byteplus-platform/reference/updatepolicy) |Updates a user custom policy. |
|[ListPolicies](https://docs.byteplus.com/byteplus-platform/reference/listpolicies) |Gets a list of policies, including system default policies and user custom policies. |
|[DeletePolicy](https://docs.byteplus.com/byteplus-platform/reference/deletepolicy) |Deletes a user custom policy. |
|[AttachUserPolicy](https://docs.byteplus.com/byteplus-platform/reference/attachuserpolicy) |Attaches a specified policy to a specified user. |
|[DetachUserPolicy](https://docs.byteplus.com/byteplus-platform/reference/detachuserpolicy) |Detaches a specified policy from a specified user. |
|[ListAttachedUserPolicies](https://docs.byteplus.com/byteplus-platform/reference/listattacheduserpolicies) |Gets a list of policies that are attached to a specified user, including system default policies and user custom policies. |
|[AttachRolePolicy](https://docs.byteplus.com/byteplus-platform/reference/attachrolepolicy) |Attaches a specified policy to a specified role. |
|[DetachRolePolicy](https://docs.byteplus.com/byteplus-platform/reference/detachrolepolicy) |Detaches a specified policy from a specified role. |
|[ListAttachedRolePolicies](https://docs.byteplus.com/byteplus-platform/reference/listattachedrolepolicies) |Gets a list of policies that are attached to a specified role, including system default polices and user custom policies. |
|[ListEntitiesForPolicy](https://docs.byteplus.com/byteplus-platform/reference/listentitiesforpolicy) |Gets a list of users and roles that a specified policy is attached to. |
