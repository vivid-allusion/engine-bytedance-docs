Deletes a user.

<span id="a2ef3a27"></span>
## Method

HTTP GET

<span id="ab466051"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DeleteUser` |
|Version |String |Yes |`2018-01-01` |
|UserName |String |Yes |The name of the to\-be\-deleted user. |


<span id="5abcd1e4"></span>
## Response parameter

None.
