Below are user\-related APIs.


|**API** |**Description** |
|---|---|
|CreateUser |Creates a user. |
|GetUser |Gets the information about a specified user. |
|UpdateUser |Updates information for a specified user. |
|ListUsers |Gets a list of users. |
|DeleteUser |Deletes a user. |
|CreateLoginProfile |Sets up console login configuration for a specified user. |
|GetLoginProfile |Gets the console login configuration for a specified user. |
|UpdateLoginProfile |Updates console login configuration for a specified user. |
|DeleteLoginProfile |Deletes the console login configuration for a specified user. |
