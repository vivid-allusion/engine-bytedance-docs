Deletes the console login configuration for a specified user.

<span id="6b95cfd3"></span>
## Method

HTTP GET

<span id="80945a64"></span>
## Request parameters


|**Parameter** |**Data Type** |**Required (Yes/No)**  |**Description** |
|---|---|---|---|
|Action |String |Yes |`DeleteLoginProfile` |
|Version |String |Yes |`2018-01-01` |
|UserName |String |Yes |Username. |


<span id="d364025c"></span>
## Response parameter

None.
