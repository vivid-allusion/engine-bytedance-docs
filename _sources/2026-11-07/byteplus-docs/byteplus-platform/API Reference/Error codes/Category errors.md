Below are category related error codes.


|**Error** |**Message** |**HTTP Status Code** |
|---|---|---|
|CategoryNotExist |Category `%s` can not be found. |404 |
|CategoryAlreadyExists |Category `%s` already exists. |409 |
|InvalidCategoryName |Invalid CategoryName `%s`, err: `%s`. |400 |
|InvalidCategoryDisplayName |Invalid CategoryDisplayName `%s`, err: `%s`. |400 |
|CategoryNameAlreadyExists |CategoryName `%s` already exists, err: `%s`. |400 |
|InvalidIsInner |Invalid IsInner `%s`, err: `%s`. |400 |
