# Feature Overview

You can tag cloud resources such as cloud server instances and container clusters. Each tag consists of a key and a value. You can define and use custom tags to categorize cloud resources or split bills based on the cost management and analysis dimensions within your enterprise. To use tags to split bills, you can manage tags in [Bill tags](https://console.byteplus.com/finance/bill/tag) and then use the tags in bill details and other data.

<span id="dWRdVrRU"></span>
# Operation Procedure


1. Add a tag to a cloud resource. When you create or purchase a resource, you can set a tag key and value on the configuration page. After purchase, you can modify the tag information on the resource details page.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7b3e97f529517f2fce6a3409d1e9163f.png) </span>


2. Enable a bill tag.


After adding a tag, go to the [Bill tags](https://console.byteplus.com/finance/bill/tag) page to enable the tag key as a bill tag. The bill tag will be displayed in the "Tag" column in bill details and other data.<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260623062536-1176043925308.png) </span>


3. View tag data in bill details.


On pages such as the bill details page and the splitting bill page, you can view tag data in the "Tag" column. You can also export detailed data for further statistical analysis.

Note: In bill details, select the "Billing item" or "Instance" dimension to display the "Tag" column. If different tags exist when data is aggregated, the "Tag" column is empty. We recommend that you select "Details" for when viewing or exporting tag data.
