You can set a card as the default payment method, and the amounts for post\-payment purchases are automatically deducted from the default payment method.

**To set the default payment method:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. On the top navigation bar, click **Billing** \> **Payment methods**.

3. Click **Three dots menu** \> **Set as default**.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/3f45a08-set_the_default_card.png) </span>

   The card is set as the default payment method.
