The descriptions of package related concepts are as follows:


|**Concept** |**Description** |
|---|---|
|Product |Product name. |
|Package Name |Package name. |
|Package ID |Package ID. |
|Quota |The total quota in the package. |
|Remaining Quota |The remaining quota in the package. |
|Effective Time (UTC+8) |The time when the package takes effect. |
|Expiry Time (UTC+8) |The time when the package expires. |
|Status |Package status, including **effective**, **expired**, **used up**, and **refunded**. |
|Type |Package type, including **periodic** and **diminishing**, which is related to the package's billing mode. |
|Note |Remarks of the package. For example, the reset cycle is presented for periodic packages. |
|Usage Period (UTC+8) |The period when the package is used. |
|Deducted Time (UTC+8) |The time when a certain amount of quota is deducted. |
|Previous Quota |The quota of the package before deduction. |
|Deducted Usage |The quota deducted from the package. |
|Remaining Quota |The remaining quota of the package. |
|Deducted Product |The product that the quota is deducted for. |
|Deducted Instance ID |The ID of the instance that the quota is deducted for. |
