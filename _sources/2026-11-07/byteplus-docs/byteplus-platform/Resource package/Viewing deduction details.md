In the Billing Center, you can view the deduction details of all packages. The details include the package name, usage period, the product for deduction, and so on.

**To view the deduction details:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. On the top navigation bar, click **Billing** \> **Resource management**.

3. Click **Details**.

   The deduction details list appears.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7751e4325dc309b03b187961ac1ff6e9.png) </span>

4. (Optional) Set **product** , **package name** , or **type** to filter resource packs.
