Integrating the BytePlus Video Editor SDK into your project using Swift Package Manager (SPM) allows for seamless and efficient implementation of video editing capabilities. This guide provides an introduction to the process, ensuring a straightforward integration experience for your application.

<span id="ec70395e"></span>
# Local integration

Local integration refers to the process of incorporating software or components directly into a system or application without relying on external or network\-based resources.

**To locally integrate the SDK into your project:** 


1. Copy and paste the `EffectOneKit_spm` folder obtained from the demo SDK package into the root directory of your project.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8ee9da7d514644ae8efc74a645caf18e~tplv-goo7wpa0wc-image.image) </span>

2. If `EffectOneKit.xcframework` does not exist in `EffectOneKit_spm`, drag `EffectOneKit.xcframework` into the `EffectOneKit_spm` folder.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7ec9ebcf324d4627b0c171b831629185~tplv-goo7wpa0wc-image.image) </span>

3. In the project, select **File** \> **Add Package Dependencies** \> **Add Local** \> **EffectOneKit_spm**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e03ce54e5f24fd4b301a17c0acf743c~tplv-goo7wpa0wc-image.image) </span>
