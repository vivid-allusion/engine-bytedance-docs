BytePlus Video Editor SDK is a comprehensive software development kit that facilitates the creation of in\-app video editors for mobile applications on Android and iOS platforms. This comprehensive software development kit simplifies the integration process for app developers by providing pre\-configured UI and UX components. With the SDK, developers are relieved from the burden of implementing complex UI/UX designs from scratch.

Developers can effortlessly customize specific UI and UX components using the standardized interface provided by BytePlus Video Editor SDK. The default customization options include:


* **Theme Color**: Adjust background and theme colors universally.

* **UI String Content**: Easily configure all display text strings.

* **UI Icon Style/Color/Display Order**: Modify icons in the video camera's sidebar and the track editor's track area according to preferences.


This streamlined process allows for efficient integration while providing flexibility for developers to tailor the user interface to their specific requirements.

## Product SDK characteristics

BytePlus Video Editor SDK has the following SDK characteristics:


|**SDK types** |**Description** |
|---|---|
|Fully offline SDK |The entire SDK and its video processing processes operate offline on the user's device, ensuring absolute privacy by not transmitting any user content or data to BytePlus servers. |
|Mobile\-Only SDK |Designed exclusively for mobile integration, the SDK seamlessly supports both Android and iOS platforms, focusing on delivering a tailored experience for mobile applications. |
|UI\-Inclusive SDK |The SDK streamlines the process of establishing an in\-app Video Editor module for mobile apps, seamlessly integrating features from the video camera, preview editor, and track editor.<br><br>Going beyond, it provides a complete video editor UI & UX inspired by a renowned short video platform. Developers benefit from a ready\-made UI, eliminating the need to construct a video editor module UI, saving valuable time. |
|UI\-Customizable SDK |The SDK not only provides a default version of UI & UX but also empowers developers to easily customize specific UI & UX components through straightforward and guided code\-level configurations.<br><br>Customization options include:<br><br><br>* **Theme Colo**r: Developers can universally adjust all background and theme colors<br><br>* **UI String Content**: All display text strings can be configured according to specific requirements.<br><br>* **UI Icon Style/Color/Display Order**: Easy adjustments can be made to icons in the video camera's sidebar and the track editor's track area, offering a personalized touch to the user interface. |

## Video Editor SDK features

BytePlus New Video Editor SDK is primarily structured into three feature modules:


|**Feature** |**Description** |
|---|---|
|[Camera feature](https://docs.byteplus.com/docs/video-editor-sdk/docs-camera-feature_1_1_0) |Focuses on capturing high\-quality video footage with precision and clarity. |
|[Preview Editor feature](https://docs.byteplus.com/docs/video-editor-sdk/docs-preview-editor-feature_1_1_0) |Allows users to review and refine captured footage, providing a range of editing tools for a polished final product. |
|[Track Editor feature](https://docs.byteplus.com/docs/video-editor-sdk/docs-track-editor-feature_1_1_0) |Enables fine\-tuning of track arrangement and synchronization, offering precise control over the video's timeline and composition. |
