# Track Editor \- Transitions

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f9ae0ec8209342c8a40876ff552932d7~tplv-goo7wpa0wc-image.image) </span>

Add smooth transitions between tracks using the Transitions feature in the Track Editor.


* Resource bundle: `transitions.bundle`

* Configuration file: `track_editor_transition.json`


```JSON
{
    "data": {
        "tabs": [
            {
                "uniqueId": "j0001",
                "titleDict": {
                    "en": "Default",
                    "zh": "默认"
                },
                "subItems": [
                    {
                        "uniqueId": "j0002",
                        "titleDict": {
                            "en": "FlashWhite",
                            "zh": "FlashWhite"
```
