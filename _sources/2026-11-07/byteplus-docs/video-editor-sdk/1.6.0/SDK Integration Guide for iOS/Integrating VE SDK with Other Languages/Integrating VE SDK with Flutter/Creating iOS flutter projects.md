This topic details how to create a Flutter project.

**Prerequisities**

Before creating the iOS flutter projects, you have to complete the following:


* Add the dependencies using Cocoapods. For details, refer to [Managing dependencies using Cocoapods](https://docs.byteplus.com/docs/video-editor-sdk/160-managing-dependencies-using-cocoapods).

* Retrieve your SDK package from your BytePlus representatives. For more information, refer to the [iOS package deliverables list](https://docs.byteplus.com/docs/video-editor-sdk/160-ios-package-deliverables-list).

* You have Android Studio installed on your system.

* You have Flutter version 3.16 or newer installed on your system.


**To create a Flutter project:** 


1. Open Android Studio.

2. Click **File** \> **New** \> **New Flutter Project**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/97efa49b3e4c43968b15e77024a12071~tplv-goo7wpa0wc-image.image) </span>

3. Under the Generators section, click **Flutter**.

   The New Project screen appears.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a2240b00c4834cbeaf46587f29e3d476~tplv-goo7wpa0wc-image.image) </span>

4. Set the Flutter SDK path.

5. Click **Next**.

   The configuration screen appears.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f25885cb00f42b3b38bc272a048d3a8~tplv-goo7wpa0wc-image.image) </span>

6. Enter your **Project name**, **Project location**, and **Description**.

7. Under the **Project type** drop\-down box, select **Application**.

8. Enter your **Organization**.

9. Under the iOS language section, select **Objective\-C** or **Swift**.

10. Under the **Platforms** section, select **iOS**.

11. Click **Create**.


The Flutter project is created.
