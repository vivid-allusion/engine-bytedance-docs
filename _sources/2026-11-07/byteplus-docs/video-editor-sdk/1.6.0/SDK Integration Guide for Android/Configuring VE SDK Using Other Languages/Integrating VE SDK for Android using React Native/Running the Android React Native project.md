You can run the React Native (RN) project on an emulator.

**Prerequisities**

Before you begin with creating React Native projects, ensure that the following requirements have been met:


* Downloaded Android Studio.

* Retrieve your SDK package from your BytePlus representatives. For more information, refer to [Android Sample SDK Deliverables List](https://docs.byteplus.com/docs/video-editor-sdk/160-android-sample-sdk-deliverables-list).

* Set up your RN environment. For more information, refer to the [RN developers guide](https://reactnative.dev/docs/set-up-your-environment?platform=ios).

* Completed the steps in: [Creating React Native projects in Android](https://docs.byteplus.com/docs/video-editor-sdk/160-creating-react-native-projects-in-android).

* Completed steps 1\-4 in: [Android SDK Quick Start Guide](https://docs.byteplus.com/docs/video-editor-sdk/160-android-sdk-quick-start-guide).


**To run the Android RN project:** 

Navigate to the root directory of your React Native project in the terminal and execute:

```Plain
npx react-native run-android 
```


Or, if you have `yarn` installed:

```Plain
yarn react-native run-android 
```
