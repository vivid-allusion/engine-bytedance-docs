Upon completing the video recording using the camera process, app users seamlessly transition into the BytePlus Video Editor SDK Preview Editor feature. This module serves as the next phase in the content creation journey, allowing users to review and fine\-tune their recorded videos before finalizing the editing process.

These are the Preview Editor features:


* Music integration

* Voice recordings

* Text customization

* Info Sticker

* Video Effects

* Filters

* Effects sticker

* Photo editing


<span id="52206be1"></span>
# Music integration

App users retain the capability to enhance their videos with music during the Preview Editor stage. The user journey mirrors the process on the camera page, allowing users to seamlessly add music to their content, thereby maintaining creative consistency throughout the editing journey.

# Filters

In the Preview Editor page, app users can further enhance their videos by applying filters. The user journey mirrors the process of adding filters on the camera page, ensuring a consistent and intuitive experience. This feature allows users to customize the visual style of their content, adding a creative flair to their edited videos.

<span id="4eb779bc"></span>
# Effects sticker

This feature is only available when you purchase BytePlus Effects SDK.

<span id="20b109e7"></span>
# Photo editing

The photo editing version of the Preview Editor page contains the following two features:


* Text

* Filter


When the user takes a photo, or selects a single image from the album, they will be directed to the photo editing version in the preview editor page, and the final export is also an image.

However, if the user selects multiple photos from the album or selects a combination of photos and videos, they will still enter the video editing version in the preview editor page. The image content will still be translated into a 3\-second video, and the final output will still be a video.
