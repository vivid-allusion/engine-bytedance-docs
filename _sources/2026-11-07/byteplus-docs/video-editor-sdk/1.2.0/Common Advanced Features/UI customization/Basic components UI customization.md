This topic guides you through the process of customizing basic components within your user interface (UI). Learn how to change these essential elements to meet the specific visual and functional requirements of your application.

# Loading icon

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/708a9a0008bb455ba57fae2edd2a71cf~tplv-goo7wpa0wc-image.image) </span>


|**No.**  |**Description** |**Changeable Item** |**Change Method** |
|---|---|---|---|
|1 |The loading status icon, which is a static image that is animated by the code in BytePlus Video Editor SDK. |Icon |* Replace the icon with another icon of the same name: `eo_base_loading`.<br><br>* **Recommended size (pixels)** : 144 × 144 |

# Resource status icon

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dbd75b6c826d483d973d76d93947ea87~tplv-goo7wpa0wc-image.image) </span>


|**No** |**Description** |**Changeable Item** |**Change Method** |
|---|---|---|---|
|1 |The icon indicating that a resource is being downloaded |Button icon |* Replace the icon with another icon of the same name: `eo_base_download_downloading`.<br><br>* **Recommended size (pixels)** : 36 × 36 |
|2 |The icon indicating that a resource is not downloaded |Button icon |* Replace the icon with another icon of the same name: `eo_base_download_remote`.<br><br>* **Recommended size (pixels)** : 36 × 36 |
