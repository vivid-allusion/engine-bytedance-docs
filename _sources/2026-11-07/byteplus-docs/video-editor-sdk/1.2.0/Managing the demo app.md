# Downloading the iOS demo app

Discover the capabilities of the BytePlus Video Editor SDK by downloading our demo app using iOS devices. Immerse yourself in a hands\-on experience, exploring a variety of features and functionalities firsthand. The demo app is designed to help you get started with BytePlus Video Editor SDK by quickly understanding the core code logic for implementing the key features offered.

<span id="1279a8b1"></span>
## Prerequisities

You have to download the TestFlight app before proceeding with the following steps.

<span id="d3392b31"></span>
## Downloading the demo app

You can download the demo app by scanning the QR code provided.

**To download the demo app:** 


1. Scan the following QR code:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/190b4558e0924627b127e1fd2f394aa9~tplv-goo7wpa0wc-image.image) </span>

   The TestFlight app appears with the EffectOne demo download screen.

2. Tap **Accept** \> **Install**.

   The Video Editor SDK demo app downloads.

3. Tap **Open**.

   The From the Developer screen appears.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8d0eb026f39e48068b7226c19b5937e8~tplv-goo7wpa0wc-image.image) </span>

4. Tap **Next** \> **Start Testing**.

   The BytePlus Video Editor app starts.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f0c8eddc76746b3a2dda78a7ba7bc7c~tplv-goo7wpa0wc-image.image) </span>

**To update the iOS demo app:**

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/190b4558e0924627b127e1fd2f394aa9~tplv-goo7wpa0wc-image.image) </span>

# Downloading or upgrading the Android demo app

Discover the capabilities of the BytePlus Video Editor SDK by downloading our demo app using Android devices. Immerse yourself in a hands\-on experience, exploring a variety of features and functionalities firsthand. The demo app is designed to help you get started with BytePlus Video Editor SDK by quickly understanding the core code logic for implementing the key features offered.

**To download or upgrade the demo app on Android devices:** 


1. Scan the following QR code:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0b38ae7dabb64d7ba7d00f6f43bd5868~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
