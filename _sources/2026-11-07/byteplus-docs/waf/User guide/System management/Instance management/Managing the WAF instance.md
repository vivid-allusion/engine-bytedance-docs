After a WAF instance is created, you can check the details or change the instance name. If your web applications do not need WAF anymore, you can release the instance in a timely manner to avoid unnecessary bills.

<span id="984e9104"></span>
## Prerequisite

A WAF instance has been created.

<span id="6d470038"></span>
## Viewing WAF instance details


1. Log in to the [BytePlus Web Application Firewall Console](https://console.byteplus.com/waf).

2. In the left\-side navigation pane, click **Instance management**.

3. Viewing the WAF instance details.

   
   |**Parameter** |**Description** |
   |---|---|
   |Instance name |The name and ID of the WAF instance. If no name is entered when you create the instance, the system will generate one automatically. |
   |Status |The working status of the instance.<br><br><br>* Normal: The WAF protects your web applications normally.<br><br>* Closed due to overdue payment: The instance will be inaccessible 2 hours after an overdue payment in your BytePlus account, during which WAF protection is not available and subscription fees are charged. Your resource will be retracted 24 hours after the inaccessible.<br><br>* Unsubscribing: The status after you submitting the unsubscription but still processing. In this status, WAF protection is not available and subscription fees are charged. |
   |Payment model |Pay\-as\-you\-go, which allows you to pay based on your usage. |
   |Creation time |The time when the instance is created. |
   |Operation |Click **Unsubscribe** to release the instance to avoid undesired fees. |
   


<span id="1f1d2803"></span>
## Editing the WAF instance name


1. Log in to the [BytePlus Web Application Firewall Console](https://console.byteplus.com/waf).

2. In the left\-side navigation pane, click **Instance management**.

3. Click the edit icon to change the instance name.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Up to 128 characters, only uppercase and lowercase letters, digits, and underscores (_) are allowed.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b9718ac80bc495b9e22efb36046ceb3~tplv-goo7wpa0wc-image.image) </span>

4. Click **OK**.


<span id="5efdb44a"></span>
## Releasing the WAF instance name


1. Log in to the [BytePlus Web Application Firewall Console](https://console.byteplus.com/waf).

2. In the left\-side navigation pane, click **Instance management**.

3. Click **Unsubcribe** to release the instance.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The protected websites and protection policies of the instance will be cleared upon release.   </div>
