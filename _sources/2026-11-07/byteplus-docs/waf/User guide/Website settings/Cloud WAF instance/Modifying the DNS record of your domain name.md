After the configuration is completed, you need to modify the DNS record of the domain name to the CNAME assigned by WAF. This will direct requests to the protected domain name to the WAF instance for protection. This document mainly introduces how to obtain the CNAME of the WAF instance and modify the DNS record of your domain name.

<span id="75a94ca2"></span>
## Background information

Your business can be integrated into WAF with the **CNAME** generated by WAF service. Navigate to your DNS resolution service provider and map the resolution of the domain name to be protected to the **CNAME** provided by WAF, so as to route the website business traffic to the WAF. Once the domain name to be protected is resolved to the WAF CNAME address, any subsequent changes to the WAF IP address will not affect the resolution of the protected domain name.

<span id="44972056"></span>
## Prerequisite

You have verified that requests to your website can be forwarded to the WAF as expected. For verification details, see [Verifying the configurations of your domain name](https://docs.byteplus.com/docs/waf/Verifying_website_settings).

<span id="d1d428cb"></span>
## **Procedure**


1. Log in to the [BytePlus Web Application Firewall Console](https://console.byteplus.com/waf).

2. In the top menu bar, select **Asia Pacific (Johor)** , \*\*\*\* the region where your cloud WAF instance is located.

3. On the left\-side navigation pane, select **Website settings**.

4. Click the domain name to view details.

5. Copy the CNAME value.

6. Proceed to the DNS resolution service provider, and add a CNAME record for the domain name to map the domain name to the WAF.


<span id="1cc3ea1f"></span>
## Verification


1. After the DNS resolution takes effect, request traffic destined for the domain name is forwarded to WAF. You can view the website information on the **Website settings** page.

2. Enter the domain name in the browser to test if the website is accessible.
