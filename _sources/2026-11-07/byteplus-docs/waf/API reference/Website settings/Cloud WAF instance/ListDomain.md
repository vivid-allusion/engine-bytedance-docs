You can use this API to query the detailed information of the protected domains added to BytePlus WAF. Both fuzzy and exact matching are supported.

<span id="PrRL2Vah"></span>
## HTTP request


* Method: POST

* URL: https://waf.byteplusapi.com/?Action=ListDomain&Version=2023\-12\-25


<span id="25aec4b3"></span>
## Request parameters


|**Parameter** |**Data type** |**Required** |**Sample value** |**Description** |
|---|---|---|---|---|
|Page |Integer |Yes |`1` |The page number you want to query. The default value is set to 1. |
|PageSize |Integer |Yes |`20` |The number of items displayed on each page. The default value is set to 10. The range is 1 to 100. |
|Domain |String |No |`example.volcwaf001.com` |The domain name to be queried. If no specific domain is requested, all domain names will be queried. |
|AccurateQuery |Integer |Yes |`0` |Matching mode.<br><br><br>* 0: Fuzzy matching<br><br>* 1: Exact matching |
|ProjectName |String |No |`default` |The name of the project to which the domain belongs. |


<span id="136f9a66"></span>
## Response parameters


|**Parameter** |**Data type** |**Sample value** |**Description** |
|---|---|---|---|
|TotalCount |Integer |`15` |The total number of items that meet the conditions. |
|PageSize |Integer |`20` |The maximum number of items displayed per page. |
|CurrentPage |Integer |`1` |The page number of the current page. |
|Count |Integer |`10` |The number of entries displayed on the current page. |
|Data |Array of [Data](https://docs.byteplus.com/docs/waf/ListDomain#a1dea893) objects |\- |Details of the rules. |
