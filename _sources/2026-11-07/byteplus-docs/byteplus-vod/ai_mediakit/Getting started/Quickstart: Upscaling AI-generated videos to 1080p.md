The AI MediaKit Video Enhancement tool improves the quality of videos generated by AI models. It combines video content analysis and intelligent decision\-making with a suite of algorithms—such as super\-resolution, frame interpolation, and color enhancement—to automatically select the best enhancement strategy for any scene. This process improves the clarity, smoothness, and overall visual quality of the output.

This quickstart shows you how to use the Video Enhancement tool to upscale an AI\-generated 480p video to 1080p.

<span id="03c99519"></span>
## Benefits for AI\-generated video

AI MediaKit provides targeted optimization for common quality issues found in videos generated by models like Seedance 2.0:


* **Upscale beyond model limits**: AI models often generate videos with a maximum resolution of 720p. With a single API call, the Video Enhancement tool can upscale your footage to 1080p or 4K, meeting requirements for large\-screen playback and commercial distribution.

* **Increase frame rate to reduce judder**: The native frame rate of generated videos is often 24 fps. The tool's frame interpolation technology can increase the frame rate to 50 fps or higher, significantly improving the smoothness of scenes with complex motion.

* **Reduce costs with an upscaling workflow**: Adopt a "generate low, restore high" strategy. First, generate a 480p video at a lower cost, then use AI MediaKit to enhance it to 720p or higher. The resulting image quality can be comparable to that of a directly generated high\-resolution video but at a significantly lower overall cost.

## Prerequisites


1. **Obtain an API key**: Before you begin, visit the [API key](https://console.byteplus.com/vodpaas/region:vodpaas+ap-southeast-1/ai-mediakit/settings?tab=apiKey) page in the AI MediaKit console to create and obtain your **AI MediaKit API Key**, which is used for authentication in media processing.

2. **Prepare a video file**: Have a publicly accessible HTTP/HTTPS URL for an AI\-generated video. The file size must not exceed 10 GB. If you need to generate a video, refer to the [BytePlus Model Ark video generation tutorial](https://docs.byteplus.com/en/docs/ModelArk/2298881) to generate one and obtain its URL.


<span id="73a1a86d"></span>
## Procedure

Video enhancement is an asynchronous process:


1. Call the `POST /api/v1/tools/enhance-video` API to submit a task. The API returns a task_id.

2. Poll the `GET /api/v1/tasks/{task_id}` API until the status field becomes completed.

3. Once the task is complete, get the download URL for the enhanced video from the `result.video_url` field in the response.


<span id="67aabc09"></span>
#### Step 1: Submit the task

Copy the following cURL command to submit a video enhancement task.

```Bash
curl -X POST 'https://mediakit.ap-southeast-1.bytepluses.com/api/v1/tools/enhance-video' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {Your_MediaKit_API_Key}' \
--data '{
  "video_url": "https://vod-ai-test.byteplus.com/demo/demo_480p.mp4",
  "scene": "aigc",
  "resolution": "1080p",
  "fps":50
}'
```


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">INFO</div>


<div data-tips="true" data-tips-type="default"><strong>Parameters to replace:</strong></div>



* <div data-tips="true" data-tips-type="default">Replace <code>{Your_MediaKit_API_Key}</code> with your valid API Key.</div>


* <div data-tips="true" data-tips-type="default">In the \-\-data JSON body, you can customize the following parameters:</div>


   * <div data-tips="true" data-tips-type="default"><code>video_url</code>: Replace with your video URL.</div>


   * <div data-tips="true" data-tips-type="default">Set the target resolution to 1080p and fps to 50.</div>



A successful submission returns a response containing a `task_id`. Save this ID to query the task status.

```JSON
{
  "success": true,
  "task_id": "amk-tool-enhance-video-1703200",
  "request_id": "20260415150000F6DE4C24A6A0D94B7FF1"
}
```


<span id="77a1975f"></span>
#### Step 2: Get the result

Video enhancement is a computationally intensive task and requires processing time. Poll the [Get task details](https://docs.byteplus.com/docs/byteplus-vod/ai-mediakit-get-task-details) API until the task `status` becomes `completed`.

```Bash
curl -X GET 'https://mediakit.ap-southeast-1.bytepluses.com/api/v1/tasks/{task_id}' \
--header 'Authorization: Bearer {Your_MediaKit_API_Key}'
```


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">INFO</div>


<div data-tips="true" data-tips-type="default"><strong>Parameter to replace</strong>: Replace <code>{task_id}</code> with the task ID returned in Step 1.</div>


A successful response for a completed task will look like this. The `result` object contains the output details. Get the download URL from the `video_url` field. By default, the output is an **MP4** file, and the URL is valid for **24 hours**.

```JSON
{
    "success": true,
    "task_id": "amk-tool-enhance-video-1703200",
    "task_type": "enhance-video",
    "status": "completed",
    "result": {
        "duration": 5.967,
        "fps": 50,
        "resolution": "1080p",
        "tool_version": "standard",
        "video_url": "https://example.byteplus.com/enhanced_video.mp4?auth_key=..."
    },
    "expires_at": 1775960452,
    "created_at": 1775787510,
    "finished_at": 1775787652,
    "request_id": "20260410102611A2F6BCCB40A5B534A302"
}
```
