This article describes how to view and modify the basic domain configurations in the VOD console.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Basic configuration applies to <strong>Playback domain name</strong>, <strong>Custom\-origin domain name</strong>, and <strong>Image domain name</strong>.</div>


<span id="b803dec2"></span>
## Procedures


1. Log in to the [VOD Console](https://console.byteplus.com/vodpaas) and select the specified space.

2. In the left navigation pane, click **Distribution acceleration** \> **Domain names**.

3. Select the **Playback domain name**, **Custom\-origin domain name**, or **Image domain name** tabs based on your domain type.

4. Find the target domain name in the list and click **Configure** in the **Action** column.

5. Under the **Basic information** tab:

   * For **Playback domain name** and **Image domain name**, the origin type is **origin**.

   * For **Custom\-origin domain name**, the origin type is **other origin**. You can click **Modify** and update the **Origin IP** and **Origin domain name**. For details, see the parameter description in [Adding a custom-origin domain name](https://docs.byteplus.com/docs/byteplus-vod/docs-domain-name-management#0f2ab068).

6. Click **Save**.
