BytePlus VOD offers referer and IP allowlists and blocklists to filter visitors. However, there are cases where referer and IP addresses can be manipulated, potentially resulting in the unauthorized use of site resources.If you have high security requirements for site content, you can use URL signing. This article introduces how to enable and configure URL signing in the BytePlus VOD console.

> **Note**

> The URL signing feature applies to **Playback domain name** and **Image domain name**.

## URL signing process

The following diagram shows the overall process of URL signing:

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5722e3818725408ca1dce74b07a31c5f~tplv-goo7wpa0wc-image.image)

The specific steps are as follows:

1. Generate the signed URL: The app server uses a shared key and algorithm to sign the URL. This signing procedure typically involves encrypting or digesting specific or all URL parameters using the key. Subsequently, the app server appends the signing parameters to the URL, creating a fully\-formed request URL.

2. Send the signed URL: The app server sends the request URL with the signing parameters to the app client.

3. Send the resource request: The app client uses the signed URL to request resources from the CDN node.

4. Verify the signing information: The CDN node uses the key and algorithm shared with the app server to verify the signing parameters. The verification process usually involves checking the validity period of the signed URL, calculating a signature based on the signing parameters, and comparing the signature with the one in the request.

   * If the verification passes, the CDN node retrieves the resource from the cache or the origin server based on the request parameters and returns it to the app client.

   * If the verification fails, the CDN node returns a 403 error and denies access.

Throughout this process, the app client is responsible for initiating the request, the app server handles the generation of the signed URL, and the CDN node is responsible for receiving the request and validating the signing information. The generation and authentication of the signing information rely on the shared key and algorithm, guaranteeing the validity and security of the request. This approach effectively safeguards CDN resources against unauthorized access.

## Enable and configure URL signing

1. Sign in to the [BytePlus VOD console](https://console.byteplus.com/vodpaas/totalOverview/) and enter a specific space.

2. Click **Distribution acceleration** \> **Domain names** on the left navigation bar.

3. Depending on the type of your domain name, click the **Playback domain name** or **Image domain name** tab.

4. Find the domain name you want to configure and click the **Configure** button in the **Action** column.

5. Click the **Access Control** tab.

6. Click the **Modify** button at the bottom of the page.

7. Under **URL signing**, switch the **Status** toggle and configure the parameters. For details, please refer to [Type A signing](https://docs.byteplus.com/docs/byteplus-vod/docs-type-a).

8. Click **Save**.

## Video preview

For playback domains, Type A URL signing can be used with video preview to limit playback to the beginning of a video. Under **URL signing**, turn on **Support preview** and set **Preview duration** in seconds. Enter a positive integer of at least 5 seconds and choose a duration shorter than the video to provide a partial preview. Request a signed URL with `NeedPreview=true` in [GetPlayInfo](https://docs.byteplus.com/docs/byteplus-vod/reference-getplayinfo). Type C signing does not support video preview.

Preview requires a resource path ending in `.mp4` or `.m3u8`. HLS playback is limited to complete TS segments within the configured duration, so a duration shorter than the first segment can return no playable content. Wait for configuration changes to take effect before obtaining new URLs. For configuration steps and limitations, see [Video preview](https://docs.byteplus.com/docs/byteplus-vod/docs-video-preview).

## FAQ

### What is the difference between the timestamp anti\-hotlinking feature and the URL signing feature in terms of the video playback address's validity duration?

The timestamp anti\-hotlinking feature determines the validity duration of the playback address you obtain from BytePlus VOD by calling [GetPlayInfo](https://docs.byteplus.com/docs/byteplus-vod/reference-getplayinfo), while the validity duration set in the URL signing feature determines the validity period of the URL generated by the BytePlus VOD CDN service.

When both the timestamp anti\-hotlinking and URL signing features are enabled, two scenarios may occur:

* If the video playback address is obtained through the [GetPlayInfo](https://docs.byteplus.com/docs/byteplus-vod/reference-getplayinfo) API, the actual validity period will be the sum of the durations set in the timestamp anti\-hotlinking and URL signing.

* If the video playback address is manually constructed, the validity period will be determined solely by the duration set in the URL signing feature.

```Go
package main

import (
        "crypto/md5"
        "encoding/hex"
        "fmt"
        "math/rand"
        "regexp"
        "strconv"
        "time"
)

func splitUrl(url string) []string {
        reg := regexp.MustCompile("^(http://|https://)?([^/?]+)(/[^?]*)?(\\?.*)?$")
        return reg.FindStringSubmatch(url)
}

func getMd5(text string) string {
        hashByte := md5.Sum([]byte(text))
        return hex.EncodeToString(hashByte[:])
}

func getRandomString(length int) string {
        b := make([]byte, length)
        rand.Read(b)
        return fmt.Sprintf("%x", b)[:length]
}

func GenTypeAUrl(url string, key string, signName string, uid string, ts int64) string {
        params := splitUrl(url)
        scheme, host, path, args := params[1], params[2], params[3], params[4]
        randstr := getRandomString(10)
        text := fmt.Sprintf("%s-%d-%s-%s-%s", path, ts, randstr, uid, key)
        hash := getMd5(text)
        authArg := fmt.Sprintf("%s=%d-%s-%s-%s", signName, ts, randstr, uid, hash)
        if args == "" {
                return fmt.Sprintf("%s%s%s?%s", scheme, host, path, authArg)
        } else {
                return fmt.Sprintf("%s%s%s%s&%s", scheme, host, path, args, authArg)
        }
}

func init() {
        rand.Seed(time.Now().UnixNano())
}

func main() {
        var url = "http://www.test.com/a.txt?a=b&c=d"
        var primaryKey = "<your_primary_key>"
        var signName = "auth_key"
        var timeName = "t"
        var uid = "0"
        var ts = time.Now().Unix() + 3600 // The default validity duration is one hour

        typeAUrl := GenTypeAUrl(url, primaryKey, signName, uid, ts)

        fmt.Println("OriginUrl: ", url)
        fmt.Println("TypeA: ", typeAUrl)
}
```

```Java
import java.math.BigInteger;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.text.SimpleDateFormat;
import java.util.regex.*;
import java.util.*;

public class url_auth {
    private static String getMd5(String text) {
        MessageDigest hash = null;
        try {
            hash = MessageDigest.getInstance("MD5");
        } catch (NoSuchAlgorithmException e) {
            e.printStackTrace();
        }
        hash.update(StandardCharsets.UTF_8.encode(text));
        return String.format("%032x", new BigInteger(1, hash.digest()));
    }

    private static String getRandomString(int length) {
        int leftLimit = 48; // numeral '0'
        int rightLimit = 122; // letter 'z'
        Random random = new Random();
        String str = random.ints(leftLimit, rightLimit + 1)
          .filter(i -> (i <= 57 || i >= 65) && (i <= 90 || i >= 97))
          .limit(length)
          .collect(StringBuilder::new, StringBuilder::appendCodePoint, StringBuilder::append)
          .toString();
        return str;
    }

    private static Map<String,String> splitUrl(String url) {
        String pattern = "^(http://|https://)?([^/?]+)(/[^?]*)?(\\?.*)?$";
        Pattern r = Pattern.compile(pattern);
        Matcher m = r.matcher(url);
        Map<String,String> result = new HashMap<>();
        String scheme = "", domain = "", uri = "", args = "";
        if (m.find()) {
            scheme = m.group(1) == null ? "http://" : m.group(1);
            domain = m.group(2) == null ? "" : m.group(2);
            uri = m.group(3) == null ? "/" : m.group(3);
            args = m.group(4) == null ? "" : m.group(4);
        }
        result.put("scheme", scheme);
        result.put("domain", domain);
        result.put("uri", uri);
        result.put("args", args);
        return result;
    }

    private static String genTypeAUrl(String url, String key, String signName, String uid, long ts) {
        Map<String,String> uriInfo = splitUrl(url);
        String scheme = uriInfo.get("scheme"), domain = uriInfo.get("domain"), uri = uriInfo.get("uri"), args = uriInfo.get("args");
        String rand = getRandomString(10);
        String text = String.format("%s-%d-%s-%s-%s", uri, ts, rand, uid, key);
        String hash = getMd5(text);
        String authArg = String.format("%s=%d-%s-%s-%s", signName, ts, rand, uid, hash);
        if (args == "") return String.format("%s%s%s?%s", scheme, domain, uri, authArg);
        else return String.format("%s%s%s%s&%s", scheme, domain, uri, args, authArg);
    }

    public static void main(String[] args) {
```

```Python
import re
import time
import random
import string
import hashlib

def getMd5(text):
    hash = hashlib.md5()
    hash.update(text.encode("utf8"))
    return hash.hexdigest()

def splitUrl(url):
    p = re.compile("^(http://|https://)?([^/?]+)(/[^?]*)?(\\?.*)?$")
    if not p:
        return None
    m = p.match(url)
    if not m:
        return "", "", "", ""
    scheme, domain, uri, args = m.groups()
    if not scheme: scheme = "http://"
    if not uri: uri = "/"
    if not args: args = ""
    return scheme, domain, uri, args

def getRandomString(n):
    x = ''.join(random.sample(string.ascii_letters + string.digits, n))
    return x

def genTypeAUrl(url, key, signName, uid, ts):
    scheme, domain, uri, args = splitUrl(url)
    rand = getRandomString(10)
    text = "%s-%d-%s-%s-%s" %(uri, ts, rand, uid, key)
    hash = getMd5(text)
    authArg = "%s=%d-%s-%s-%s" %(signName, ts, rand, uid, hash)
    if args:
        return "%s%s%s%s&%s" %(scheme, domain, uri, args, authArg)
    else:
        return "%s%s%s?%s" %(scheme, domain, uri, authArg)

def test():
    url = 'http://www.test.com/a.txt?a=b&c=d'
    primaryKey = '<your_primary_key>'
    signName = "auth_key"
    timeName = "t"
    uid = "0"
    ts = time.time() + 3600 # The default validity duration is one hour

    print("OriginUrl:{}".format(url))

if __name__ == "__main__":
    test()
```

```JavaScript
import crypto from "crypto";

// Match different parts of the link using regular expressions
function splitUrl(url) {
  const regexp = /^(http:\/\/|https:\/\/)?([^\/\?]+)(\/[^\?]*)?(\?.*)?$/g;
  return regexp.exec(url);
}

// Calculate the MD5 value of a string
function getMd5(str) {
  return crypto.createHash("md5").update(str).digest("hex");
}

// Generate a random string
function getRandomString(length) {
  const chars =
    "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
  let result = "";
  for (let i = 0; i < length; i++) {
    result += chars[Math.floor(Math.random() * chars.length)];
  }
  return result;
}

function genTimeString(ts) {
    const date = new Date(ts);
    return `${date.getFullYear()}${date.getMonth()}${date.getDate()}${date.getHours()}${date.getMinutes()}`
}

// Generate signed url
function GenTypeAUrl(url, key, signName, uid, ts) {
  const params = splitUrl(url);
  const [, scheme, host, path, args] = params;
  const randStr = getRandomString(10);
  const text = `${path}-${ts}-${randStr}-${uid}-${key}`;
  const hash = getMd5(text);
  const authArg = `${signName}=${ts}-${randStr}-${uid}-${hash}`;
  if (!args) {
    return `${scheme}${host}${path}?${authArg}`;
  } else {
    return `${scheme}${host}${path}${args}&${authArg}`;
  }
}


function main() {
  const url = "http://www.test.com/a.txt?a=b&c=d";
  const primaryKey = "<your_primary_key>";
  const signName = "auth_key";
  const timeName = "t"
  const uid = "0";
  const ts = Math.floor(Date.now() / 1000) + 3600; // 10-digit timestamp
        
  console.log("OriginUrl:", url);
  console.log("TypeA: ", GenTypeAUrl(url, primaryKey, signName, uid, ts));
}

// Execute
main()
```
