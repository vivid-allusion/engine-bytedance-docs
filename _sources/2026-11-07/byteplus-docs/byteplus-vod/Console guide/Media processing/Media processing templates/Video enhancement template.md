To improve video quality using AI\-driven enhancements, you can create a video enhancement template in the BytePlus VOD console. This guide provides step\-by\-step instructions for configuring settings such as preset scenarios, resolution, and frame rate, and saving the template for use in your media processing workflows.

## Feature overview

BytePlus VOD's video enhancement feature provides an intelligent and efficient solution for improving video quality through deep optimization using AI algorithms. It is tailored for five core scenarios: general content, UGC short videos, AIGC content, short dramas, and classic film restoration. For a comprehensive overview of the video enhancement feature, its technical principles, application scenarios, and the complete userflow, please refer to [vCube upscaling and enhancement overview](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement).

## Creating a video enhancement template

1. Sign in to the [BytePlus VOD console](https://console.byteplus.com/vodpaas/totalOverview/). Ensure you have selected the **Johor** region from the dropdown menu in the top navigation bar of the console.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d1fa1eedea854f2cad2bc9eecf59b650~tplv-goo7wpa0wc-image.image)

2. Click **Spaces** on the left navigation bar.

3. On the **Spaces** page, find the desired space and click **Enter space**.

4. Click **Media processing** \> **Templates** on the left navigation bar.

5. Click the **Video enhancement** tab.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9420a794a8bb42cbabe221f52cc10e38~tplv-goo7wpa0wc-image.image)

6. Click **Create video enhancement template**.

7. Configure the basic information of the template.

   |**Parameter** |**Description** |
   |---|---|
   |Template name |Enter a unique and descriptive name for your template. The length of the template name cannot exceed 64 characters. |
   |Template description |(Optional) Add a description to provide more context about the template's purpose or use case. The length of the template description cannot exceed 140 characters. |

8. Configure the parameter settings of the template.

   1. Choose a preset scenario for your parameter settings. This allows you to start with a recommended configuration for a specific scenario:

      * **General template:**  A balanced set of parameters for common video quality enhancements.

      * **UGC short video:**  Designed to repair impairments common in user\-generated content, such as artifacts from repeated compression.

      * **AIGC content:**  Specialized for upscaling and refining low\-resolution videos generated by AI models.

      * **Short drama:**  Focuses on enhancing portraits and details to improve the overall visual expression in short dramas.

      * **Classic film restoration:**  Analyzes and resolves issues including low resolution, motion stuttering, color distortion, scratches, and noise.

      * **Custom enhancement:**  (Legacy) Legacy quality enhancement templates supporting customizable combinations of different operators. This option is no longer available.

         ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/03ce2b5fea7d4fd6bae3685d096d3dcf~tplv-goo7wpa0wc-image.image)

   2. After selecting the preset scenario, customize the specific enhancement settings. Please note that the specific options and their availability may differ slightly based on the preset scenario you selected in the previous step.

      * **Enhancement tier:**  Choose from three processing tiers to balance speed, quality, and cost.

         * **Standard:**  Uses adaptive algorithms to provide a superior balance between visual texture and processing speed.

         * **Pro:**  Powered by large\-model\-driven restoration for cinematic\-grade image quality. This tier requires a longer processing time. For the **General template**, **UGC short video**, **AIGC content**, and **Short drama** scenarios, BytePlus VOD automatically selects the [Pro version](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#pro-versions) based on the configured output resolution. For **Classic film restoration**, the Pro tier uses a [dedicated film restoration template](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#pro-film-restoration).

         * **Fast:**  Integrates essential upscaling and basic enhancements for a good balance between processing speed and visual clarity.

      * **Enhancement intensity:**  Available for the **Standard** and **Pro** tiers. For more information, see [Enhancement intensity](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#enhancement-intensity).

         * **Natural version:**  Applies a softer enhancement while keeping the visual texture close to the source video. This setting can help reduce an oil\-paint\-like appearance in certain scenarios, such as AI\-generated human\-like videos.

         * **High definition:**  Applies a sharper enhancement style.

      * **Output format:**  Specify the combination of encoding format and color depth for the output video. This parameter is available only for the **Pro** enhancement tier. The output container is set automatically based on the combination. The following options are supported:

         * **MP4 | H.264 | 8\-bit** (default)

         * **MP4 | H.265 | 8\-bit**

         * **MP4 | H.265 | 10\-bit**

         * **MOV | ProRes | 10\-bit**

         * **MP4 | H.265 | 12\-bit**

         * **MOV | FFV1 | 16\-bit**

         * **MOV | FFV1 \- GBR | 16\-bit**

         * **EXR | EXR | 16\-bit**

         > **Note**

         * > When you select a **16\-bit** option (**MOV | FFV1 | 16\-bit**, **MOV | FFV1 \- GBR | 16\-bit**, or **EXR | EXR | 16\-bit**), the input video duration must not exceed 40 seconds.

         * > The **MOV | ProRes | 10\-bit**, **MOV | FFV1 | 16\-bit**, **MOV | FFV1 \- GBR | 16\-bit**, and **EXR | EXR | 16\-bit** options do not support the **Target bitrate** setting.

         * > For more information, see [Color depth](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#color-depth) and [Output format](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#output-format).

      * **SDR to HDR:**  Convert the output from SDR to HLG HDR. This switch is available only for the **Pro** enhancement tier and only when the selected output format uses a 10\-bit, 12\-bit, or 16\-bit color depth. When the selected output format does not meet these conditions, the switch is disabled and shows the message **Requires Pro version + 10/12/16\-bit color depth**. The **EXR | EXR | 16\-bit** output is already HDR and does not use HLG, so the switch is also disabled when you select it. When the switch is off, the output stays SDR even if the source video is HDR. For more information, see [Dynamic range and SDR to HDR](https://docs.byteplus.com/docs/byteplus-vod/docs-video-enhancement#dynamic-range-and-sdr-to-hdr).

      * **Resolution:**  Specify the resolution for the output video.

         * **Match source file:**  The output video will have the same resolution as the original.

         * **AI super resolution:**  The video will be upscaled to a higher resolution using AI.

      * **Frame rate:**  Specify the frame rate for the output video.

         * **Match source file:**  The output video will have the same frame rate as the original.

         * **AI frame interpolation:**  The frame rate will be increased to create smoother motion.

      * **Target bitrate:**  Specifies the target average bitrate for the output video. This parameter directly determines the visual quality and final file size. The value range is [10, 50000]. To maintain consistent visual quality across different scenes, the system dynamically adjusts the output. The actual bitrate will fluctuate between **0.8 and 1.5 times** your specified target based on the content complexity. Please refer to the [Recommended bitrates for different output resolutions](https://docs.byteplus.com/docs/byteplus-vod/docs-image-enhancement-template#dffd4af5) table.

9. Click **Save**.
