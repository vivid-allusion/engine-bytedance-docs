BytePlus VOD integrates with [Cloud Monitor](https://docs.byteplus.com/en/docs/cloudmonitor/What-is-Vitality-Cloud-Monitor), an all\-in\-one cloud monitoring and alert service, so that you can monitor your VOD CDN in real time. You can also configure alert policies to be notified immediately when the monitored data does not meet your expectations, helping you detect and resolve issues promptly.

This guide describes how to view VOD CDN monitoring data in the Cloud Monitor console and how to configure alert policies.

<span id="prerequisites"></span>
## Prerequisites


* You have created a space in the BytePlus VOD console. For details, see [Spaces](https://docs.byteplus.com/docs/byteplus-vod/docs-space-management).

* You have configured a domain name in the BytePlus VOD console. For details, see [Adding domain name](https://docs.byteplus.com/docs/byteplus-vod/docs-domain-name-management).


<span id="viewing-monitoring-information"></span>
## Viewing monitoring information


1. Sign in to the [Cloud Monitor console](https://console.byteplus.com/observe/cloud-monitor).

2. Click **Cloud Service Monitor** on the left navigation bar, and then select the **BytePlus VOD** product under the **Video Cloud** category.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260902025606-1319482121828.png) </span>

3. On the product page, view the alert overview and the list of spaces.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260902025947-1202604164406.png) </span>

4. Click a space name to enter its detail page. On the **Monitoring** tab, select one or more domain names from the drop\-down list, and then view data on different tabs, such as **Bandwidth traffic**, **Number of requests**, **Hit rate**, and **Status code**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260902064435-1606424850904.png) </span>


The parameters are described as follows:


|**Parameter** |**Description** |
|---|---|
|Time dimension |Supports selecting time dimensions such as 1 hour, 3 hours, 6 hours, 12 hours, 1 day, 3 days, and 7 days. |
|Time range |You can customize the time interval for viewing monitoring data, with a maximum time span of 30 days. |
|Bandwidth traffic |Supported data:<br><br><br>* Edge bandwidth: Aggregate access bandwidth generated by CDN edge nodes.<br><br>* Back\-to\-origin bandwidth: The total bandwidth generated by the back\-to\-origin nodes of the CDN.<br><br>* Edge traffic: Aggregate access traffic generated by CDN edge nodes.<br><br>* Back\-to\-origin traffic: The total traffic generated by the back\-to\-origin nodes of the CDN. |
|Number of requests |Supported data:<br><br><br>* Access requests: Aggregate number of access requests generated by CDN edge nodes.<br><br>* Back\-to\-origin requests: The total number of requests generated by the back\-to\-origin nodes of the CDN. |
|Hit rate |Supported data:<br><br><br>* Traffic hit rate: The proportion of traffic that hits and is responded to by CDN nodes in the overall edge traffic.<br><br>* Request hit rate: The proportion of requests that hit and are responded to by CDN nodes among the total number of edge requests. |
|Status code |Supported data:<br><br><br>* Edge status code 2XX / 3XX / 4XX / 5XX: The total number of aggregated 2XX, 3XX, 4XX, and 5XX status codes generated by CDN edge nodes.<br><br>* Proportion of edge status code 2XX / 3XX / 4XX / 5XX: The ratio of each aggregated edge status code to the total number of requests.<br><br>* Back\-to\-origin status code 2XX / 3XX / 4XX / 5XX: The total number of aggregated 2XX, 3XX, 4XX, and 5XX status codes generated by CDN back\-to\-origin nodes.<br><br>* Proportion of back\-to\-origin status code 2XX / 3XX / 4XX / 5XX: The ratio of each aggregated back\-to\-origin status code to the total number of back\-to\-origin requests. |


<span id="configuring-an-alert-policy"></span>
## Configuring an alert policy


1. On the space detail page, select the **Alert policy** tab, and then click **Create alert policy** to open the creation page.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260902065935-228188389190.png) </span>

2. Complete the parameter configuration as prompted. You can select resources by space using **Manually select**, **Resource name**, or **Object group**. For detailed instructions, see [Creating an alert policy](https://docs.byteplus.com/en/docs/cloudmonitor/Creating-an-alarm-strategy).

3. After you create the alert policy, you are redirected to the alert policy page, where the new policy is added to the list. For details, see [Viewing an alert policy](https://docs.byteplus.com/en/docs/cloudmonitor/Viewing-an-alarm-strategy).
