The **Endpoint tracker** feature provides user\-level and session\-level capabilities for end\-to\-end problem diagnosis and tracking. When a video plays abnormally on the Player SDK (Android, iOS, or Web), you can use this feature to quickly diagnose the issue.

This guide shows you how to view playback records, analyze performance charts like first\-frame time, and interpret detailed diagnostic information to resolve playback problems.

<span id="5f8507e5"></span>
## Feature overview


* Supports viewing playback records for a single device within a specified time range to locate and analyze endpoint problems.

* Displays a first\-frame time distribution chart for all playback records to help you analyze first\-frame time. It also detects abnormal first\-frame time. When an anomaly occurs, click the timepoint highlighted in red to quickly locate the corresponding playback record.

* Supports viewing the first\-frame time consumption for different stages.

* Supports viewing playback information and diagnostic information. You can select a playback record to enter the playback details page and check for issues in each stage.

* Supports viewing bitrate, download speed, freezes, and errors throughout the playback process, as well as the corresponding event logs.

## Prerequisites

To view playback records, integrate the Player SDK. For details, see the following documents:


* [Integrate the Android Player SDK](https://docs.byteplus.com/en/byteplus-vod/docs/getting-started-with-the-android-player-sdk) and customize the device ID [Android Player SDK: Customizing device ID](https://docs.byteplus.com/docs/byteplus-vod/docs-customizing-device-id-android) when initializing the SDK.

* [Integrate the iOS Player SDK](https://docs.byteplus.com/en/byteplus-vod/docs/getting-started-with-the-ios-player-sdk) and customize the device ID [iOS Player SDK: Customizing device ID](https://docs.byteplus.com/docs/byteplus-vod/docs-customizing-device-id-ios) when initializing the SDK.

* [Integrate the Web Player SDK](https://docs.byteplus.com/byteplus-vod/docs/getting-started-with-the-web-player-sdk) and configure [Step 5: Report playback quality logs](https://docs.byteplus.com/docs/byteplus-vod/docs-getting-started-with-the-web-player-sdk#e473800a) when instantiating the player.
