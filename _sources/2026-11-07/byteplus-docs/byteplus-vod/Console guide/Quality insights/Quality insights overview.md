The BytePlus VOD quality platform is a comprehensive tool that offers insightful metrics, real\-time data monitoring, and drill\-down analysis for your video services. It provides whole\-link issue tracking at both user and session levels, enabling you to address user demands promptly and maintain high\-quality service.

This document provides an overview of the platform's key features, including playback and upload data monitoring, issue diagnosis, and endpoint tracking.

<span id="33669657"></span>
## Playback data

The **Playback** module of the BytePlus VOD quality platform displays in\-app data collected by the BytePlus VOD Player SDK and allows Android, iOS, and Web app developers to monitor the quality of the playback experience in their apps. This module includes the following pages:


* **Dashboard**: A real\-time dashboard that displays single\-day data, helping developers monitor fluctuations in important metrics.

* **QoS**: This page displays QoS (Quality of Service) metrics that provide information on network performance, such as buffering and latency. For details, see QoS metrics.

* **QoE**: This page displays QoE (Quality of Experience) metrics that measure the overall user experience, including video and audio quality. For details, see QoE metrics.

* **Cost**: This page displays cost metrics that show how much it costs to deliver the video content to users.


<span id="631417ce"></span>
## Upload data

The **Upload** module of the BytePlus VOD quality platform displays in\-app data collected by the BytePlus VOD Upload SDK and allows Android, iOS, and Web app developers to monitor the upload data.

<span id="08dde4db"></span>
## Diagnosis

The **Analysis and diagnosis** module of the BytePlus VOD quality platform allows you to compare metrics from different periods and displays the most frequent error codes that occurred during the specified time range. It helps you troubleshoot some of the common issues you may encounter when using BytePlus VOD.

<span id="54652cca"></span>
## Endpoint tracker

The **Endpoint tracker** feature provides user\-level and playback session\-level whole\-link issue identification and tracking capabilities. If an error occurs during video playback using the BytePlus VOD SDK, you can quickly locate the problem with the **Endpoint tracker** feature.

<span id="3bc6be73"></span>
## Report subscription

The **Subscription** page allows you to subscribe to specific charts that visualize metrics according to your business needs. Subscribed charts will be sent to your email for offline data analysis.
