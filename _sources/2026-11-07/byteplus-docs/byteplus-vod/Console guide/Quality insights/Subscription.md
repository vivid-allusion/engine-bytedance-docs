To receive customized metric charts via email for offline analysis, you can use the **Subscription** feature. This guide provides step\-by\-step instructions on how to create a subscription, configure its frequency, and specify recipients to ensure you get the data you need and when you need it.

<span id="5c8512c6"></span>
## Creating a subscription


1. Sign in to the [BytePlus VOD console](https://console.byteplus.com/vodpaas/totalOverview/).

2. Select **Quality insights** \> **Subscription** on the left navigation bar.

3. Click **Create subscription**.

4. Set the subscription information:

   1. Choose your app name from the drop\-down list.

   2. Select subscription type:

      * One\-time subscription. You must specify the start date and end date for the data.

      * Periodic subscription. You must select how often the data should be sent:

         * Daily: Data is sent on the following day.

         * Weekly: Data is sent every Monday for the previous week (Monday to Sunday).

         * Monthly: Data is sent on the 1st of the next month for the previous month.

   3. Choose the appropriate operating system from the drop\-down list based on the client type:

      * If you select **Mobile** as the client type, choose Android or iOS.

      * If you select **Web** as the client type, choose Android, iOS, Linux, Mac, or Windows.

5. Configure report delivery:

   1. Enter a report name with a length between 1 and 20 characters.

   2. Enter one or more email addresses, separating each address with a newline. You can enter up to 10 email addresses.

   3. Choose the report format as **XLSX** or **CSV**.

6. Click **Submit**. The page automatically redirects to the report list.

7. Click **Enable**. You can then edit, unsubscribe, or delete the report.
