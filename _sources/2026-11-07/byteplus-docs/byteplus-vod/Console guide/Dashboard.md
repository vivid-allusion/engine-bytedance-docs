The **Dashboard** page consists of the following modules:


* **Switch time zone**: The default time zone is UTC+08:00. You can switch time zones on the page. After switching time zones, the console refreshes and reloads, and the displayed data changes to reflect the current time zone.

* **Resource usage**: Your usage of BytePlus VOD features this month, including traffic, media storage, and transcoding.

* **Usage over time**: The usage trend of the previous 7 days, which includes bandwidth, traffic, media storage, and transcoding duration.

* **Help and support**: The BytePlus VOD documentation and getting started tutorial.

* **Billing overview**: The billing method for the current account.

* **Resource package**: The resource package purchased by the current account.
