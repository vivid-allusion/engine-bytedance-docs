To effectively manage your costs and make informed financial decisions for your BytePlus VOD usage, you can view detailed bills in the billing center. This guide shows you how to access bills by charging period, examine detailed usage data, and view project\-based split bills for granular cost insights. Please note that real\-time data is for reference only; final reconciled bills are available the following month.

If your account has overdue payments, see [Processing of overdue payments](https://docs.byteplus.com/docs/byteplus-vod/docs-processing-of-overdue-payments) for service restrictions, resource reclamation, and payment instructions.

> **Warning**

* > The real\-time billing data for the current month does not include the unsettled amount of pay\-as\-you\-go resources. This data is not suitable for the purposes of cost reconciliation. The actual billing details for each month are considered accurate when you query them in the following month.

* > There may be a delay in billing data compared to actual cost consumption. Please refer to the console prompts for the specific delay time.

## Prerequisites

BytePlus offers the option to view split billing statements, which breaks down the total cost into smaller parts and shows detailed billing information. Split bills can be accessed at the project level. When it comes to BytePlus VOD, the spaces and applications in BytePlus VOD are affiliated with a specified project. For details, see [Access authorization overview](https://docs.byteplus.com/docs/byteplus-vod/docs-access-authorization). If you want to see split bills, you'll need to activate the bill splitting feature first.

## Procedure

1. Sign in to the [BytePlus VOD console](https://console.byteplus.com/vodpaas).

2. In the top navigation bar of the console, click User Profile \> **Billing**.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5c1002533a4a42f9afa8a2f60091d69d~tplv-goo7wpa0wc-image.image)

3. View the bills:

   1. Click the **Bills on charging period** tab.

   2. Set the **Billing Cycle** and **Payer**. Click the filter icon in the **Product** column and select **BytePlus VOD** to view BytePlus VOD bills.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/46721a463d62423c9018adab15e98779~tplv-goo7wpa0wc-image.image)

      You can refine your search by using filters. The following table describes the filters that you can use.

      |Filter |Description |
      |---|---|
      |Billing cycle |The period for which the bill is settled, typically monthly. |
      |Payer |The account that pays the bills. |
      |Order number/Bill number |The order number or bill number. |

4. View the billing details:

   1. Click the **Bill details** tab.

   2. Set the **Billing Cycle** and **Payer**. Click the filter icon in the **Product** column and select **BytePlus VOD**.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bf0f2eabe2b84bb688952b884ffaa5e7~tplv-goo7wpa0wc-image.image)

      You can also configure the **Items** and **Period** parameters to specify the content of bills that you want to display within the selected billing cycle. The following table describes the Item and Period parameters.

      |Parameter |Description |
      |---|---|
      |Items |Bills are aggregated based on the statistical item that you specify. Valid values:<br><br><br>* **Billing item**: Bills are aggregated by billable item. The bills that are generated by the same billable item are combined.<br><br>* **Instance**: Bills are aggregated by instance. The bills that are generated by the same instance are combined.<br><br>* **Product**: Bills are aggregated by product. The bills that are generated by the same product are combined.<br><br>* **Account**: Bills are aggregated by account. The bills that are generated by the same account are combined. |
      |Statistical period |Bills are aggregated based on the time period that you specify. Valid values:<br><br><br>* **Billing cycle**: The bills for the selected month are aggregated by billing cycle.<br><br>* **By day**: The bills for the selected month are aggregated by day.<br><br>* **Details**: The bills for the selected month are aggregated by hour. |

5. View the split bills:

   1. Click **Bill management** \> **Split bills** in the left navigation bar.

   2. Configure the following query parameters:

      2. Set the **Billing cycle**.

      3. Select the **Payer**.

      4. Select the **Project**.

      5. Click the filter icon in the **Product** column and select **BytePlus VOD**.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/59ba562d410a4d879a49f35d98a3c740~tplv-goo7wpa0wc-image.image)
