Gets the information of audio and video files for the specified `Vid` (video ID).

> **Note**

> This API can fetch up to 10,000 pieces of data based on the filters. If there are more than 10,000 pieces of data, you can specify `StartTime` and `EndTime` to fetch data in batches.

## HTTP request

Endpoint: https://vod.byteplusapi.com?Action=GetMediaList&Version=2023\-01\-01

## Request parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/docs/byteplus-vod/reference-introduction#request-structure) in addition to API\-specific parameters.

|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`GetMediaList` |The API action. For the current API, the value is `GetMediaList`. |
|Version |String |Yes |`2023-01-01` |The API version. For the current API, the value is `2023-01-01`. |
|SpaceName |String |Yes |`test` |The space name. You can call [ListSpace](https://docs.byteplus.com/docs/byteplus-vod/reference-listspace) to obtain the names of all spaces under the current account. |
|SemanticText |String |No |`Videos showing a sunset over the sea` |Natural\-language query used to search video understanding results in the specified space. Other supplied filters still apply. If empty or omitted, the existing query behavior is unchanged. |
|Vid |String |No |`v03843g1000***k9s1v0rfphkjtc0` |The video ID. After uploading the audio and video files, you can obtain the `Vid` through the [FileUploadComplete](https://docs.byteplus.com/docs/byteplus-vod/docs-fileuploadcomplete) event notification. |
|Status |String |No |`Published` |The video status. If not specified, the default is all. Supported values:<br><br><br>* `Published`: Published.<br><br>* `Unpublished`: Unpublished.<br><br><br>> **Note**<br><br><br>> To specify multiple statuses, separate them with a comma, like: `"Published,Unpublished"`.<br> |
|Order |String |No |`Asc` |Sort by the creation time. The default is `Desc`. Supported values:<br><br><br>* `Asc`: Ascending.<br><br>* `Desc`: Descending. |
|Tags |String |No |`tag1` |The tag list. Search for videos that hit one of the tags. For example, if you input `"tag1,tag2,tag3"`, this API will return videos that match any of those tags, using an OR relationship.<br><br>> **Note**<br><br><br>> Empty values or duplicate values will be filtered out.<br> |
|ClassificationIds |String |No |`0` |The category ID list. Multiple IDs are separated by commas.<br><br><br>* If left empty, no filtering.<br><br>* Pass `0` to filter only the uncategorized.<br><br>* Pass a specific category ID to filter by that ID.<br><br><br>> **Note**<br><br><br>> A maximum of 20 category IDs can be queried at one time.<br> |
|StartTime |String |No |`2021-03-18T00:00:00Z` |The start time of the creation time. The query results are greater than or equal to `StartTime`. It is represented in the RFC 3339 standard format, using UTC+0 time zone, formatted as `yyyy-MM-ddTHH:mm:ssZ`. For example: `2021-03-18T00:00:00Z`, with a default of `1999-01-01T00:00:00Z`. |
|EndTime |String |No |`2021-03-19T00:00:00Z` |The end time of creation time. It must be greater than `StartTime`. The default is now. The format is in accordance with the RFC 3339 standard, using UTC+0 time, formatted as `yyyy-MM-ddTHH:mm:ssZ`. |
|Offset |String |No |`0` |The data offset. Default is 0. Maximum is 10000. |
|PageSize |String |No |`10` |The number of records returned per page. The default is 10, and the maximum value is 100. |
|TosStorageClasses |String |No |`STANDARD` |The video storage type. Currently only support `STANDARD` (standard storage). |
|VodUploadSources |String |No |`upload` |The audio and video source. Multiple sources are separated by a comma. The values are as follows:<br><br><br>* `upload`: Videos uploaded to BytePlus VOD via the BytePlus VOD console, client\-side Upload SDKs, or Server SDKs.<br><br>* `live`: Videos recorded and stored on BytePlus VOD via [BytePlus MediaLive](https://docs.byteplus.com/en/docs/byteplus-media-live).<br><br>* `rtc`: Videos recorded and stored on BytePlus VOD via [BytePlus RTC](https://docs.byteplus.com/en/docs/byteplus-rtc).<br><br>* `url_upload`: Videos uploaded to BytePlus VOD via URL batch fetching.<br><br>* `media_process`: Videos generated by the BytePlus VOD media processing service, which will generate a new Vid. |
