This interface is used to obtain the media asset information through the `Vid` (video ID), including the basic information, source information, and the media processing output file information.

<span id="http-request"></span>
## HTTP request

Endpoint: https://vod.byteplusapi.com?Action=GetMediaInfos&Version=2023\-01\-01

<span id="request-parameters"></span>
## Request parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/en/docs/byteplus-vod/reference-introduction#request-structure) in addition to API\-specific parameters.


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`GetMediaInfos` |The API action. For the current API, the value is `GetMediaInfos`. |
|Version |String |Yes |`2023-01-01` |The API version. For the current API, the value is `2023-01-01`. |
|Vids |String |Yes |`v02b69g10000***eldb8vjafvmg` |The video ID list. Multiple Vids are separated by a comma `,`. A maximum of 20 Vids are supported at one time. |

## Response parameters

For unique API\-specific response parameters, see the table below. For more details, refer to the [Response](https://docs.byteplus.com/en/docs/byteplus-vod/reference-introduction#response) section.

|---|---|---|---|
