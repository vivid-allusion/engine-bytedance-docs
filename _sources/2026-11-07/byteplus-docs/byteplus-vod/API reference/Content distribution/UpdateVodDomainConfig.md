Call `UpdateVodDomainConfig` to update the configuration of a VOD domain name.

## Usage notes

This API overwrites configurations by module as follows:

* If you do not specify a module, its existing configuration remains unchanged after you submit the request.

* If you specify a module, its existing configuration is overwritten after you submit the request.

## Limits

* The per\-user QPS limit for this API is 10 requests per second. Requests that exceed this limit are throttled and might affect your services. Plan your request rate accordingly. For more information, see [QPS limits](https://docs.byteplus.com/docs/byteplus-vod/reference-qps-limits-on-api-calls).

## HTTP request

* Request method: **POST**

* Endpoint: **https://vod.byteplusapi.com?Action=UpdateVodDomainConfig&Version=2026\-08\-01**
