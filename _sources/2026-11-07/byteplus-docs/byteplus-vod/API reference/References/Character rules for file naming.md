This article outlines the common character rules that need to be followed for file naming in BytePlus VOD. The rules are as follows:


* Encoding: UTF\-8 encoding should be used.

* Safe Characters:

   * Uppercase and lowercase letters A\-Z, a\-z

   * Numbers 0\-9

   * Chinese parentheses `（）`

   * Chinese and English exclamation marks `！`, `!`

   * Chinese and English semicolons and colons `;`, `；`, `:`, `：`

   * Chinese question mark `？`

   * Special characters: `@`, `￥`, `……`, `-`, `_`, `=`, `、`, `{}` , `“”`, `'`, `‘`, `。`, `/`, `《》`, `.`

* Characters to avoid:

   * Cannot start with a forward slash `/` or a backslash `\`

   * Cannot contain strings like `//`, `/./`, `/../`

   * Unsupported characters: `\a`, `\b`, `\t`, `\n`, `\v`, `\f`, `\r`, space, `#`, `%`, `&`, `\`, `"`, `<`, `>`, `?`, `$`, `+`, `,`, `，`, `()`, `^`, `*`, `|`, `[]`
