Call `SubmitDirectEditTaskSync` to synchronously submit a direct editing task for simple HLS trimming.

<span id="usage-notes"></span>
## Usage notes


* This API uses direct editing rather than project\-based editing. It trims an HLS video by time range and generates a new HLS video.

* The minimum trimming precision is one TS segment. This API does not support second\-level or finer trimming precision.

* The service generates a new M3U8 file and video ID without storing duplicate TS files. Use `EditParam.Upload.StorageBind` to specify whether the generated M3U8 file is bound to its TS segments. The default value is `false`; in this case, deleting the generated M3U8 file does not delete the associated TS segments.

* Video editing is billed based on the resolution and duration of the output file. For details, see [Pay-as-you-go pricing](https://docs.byteplus.com/docs/byteplus-vod/docs-pay-as-you-go-pricing#video-editing).

* To retrieve a playback URL for the output, [add and configure a domain name](https://docs.byteplus.com/docs/byteplus-vod/docs-domain-name-configuring) and configure [automatic publishing](https://docs.byteplus.com/docs/byteplus-vod/docs-publishing-status) for the output VOD space before submitting the task.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Region availability</div>


<div data-tips="true" data-tips-type="tip">This API is currently available only in the Asia Pacific (Johor) region. Sign the request with region <code>ap-southeast-1</code>.</div>


<span id="http-request"></span>
## HTTP request


* Method: **POST**

* Endpoint: `https://vod.byteplusapi.com?Action=SubmitDirectEditTaskSync&Version=2025-01-01`


<span id="request-parameters"></span>
## Request parameters

<span id="common-parameters"></span>
### Common parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/docs/byteplus-vod/reference-introduction#request-structure) in addition to API\-specific parameters.

<span id="query"></span>
### Query


|Parameter |Data type |Required |Sample value |Description |
|---|---|---|---|---|
|`Action` |String |Yes |`SubmitDirectEditTaskSync` |The API action. |
|`Version` |String |Yes |`2025-01-01` |The API version. |


<span id="body"></span>
### Body


|Parameter |Data type |Required |Sample value |Description |
|---|---|---|---|---|
|`Uploader` |String |Yes |`your-space` |Name of the BytePlus VOD space to which the output is uploaded. |
|`Application` |String |Yes |`SimpleCut` |Editing application. For simple HLS trimming, set this parameter to `SimpleCut`. |
|`EditParam` |Object |Yes |\- |Direct editing parameters. For simple HLS trimming, specify the source and time ranges as shown in the sample request. `EditParam.Upload.SpaceName` must be the same as `Uploader`. |
|`Priority` |Integer |No |`0` |Task priority passed to the editing service. |


<span id="response-parameters"></span>
## Response parameters


|Parameter |Data type |Description |
|---|---|---|
|`Code` |Integer |Task status code. `0` indicates that the synchronous task succeeded. |
|`Output` |String |JSON string containing the editing output, such as the output video ID, URI, duration, codec, and resolution. |
|`ReqId` |String |Request ID generated by the editing service. |
