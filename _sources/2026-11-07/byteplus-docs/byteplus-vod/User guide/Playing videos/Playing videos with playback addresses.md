For audio and video files stored in the BytePlus VOD service, you can obtain their playback addresses to use with the Video On Demand SDK or other players, such as native system players, open\-source players, or custom players.

This article introduces the overall process of playback using a playback address, how to obtain the playback addresses, and playback options.

<span id="7fd0350f"></span>
## Playback process

The process of playback using a playback address is shown in the following diagram:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/820b54bc18d447e882b20e8c7afb612e~tplv-goo7wpa0wc-image.image) </span>

The process is explained as follows:


1. The app client requests the playback address from the app server.

2. The app server retrieves the playback address from the BytePlus VOD service with authentication parameters.

3. The Video On Demand service returns a static or dynamic playback address to the app server.

4. The app server sends the playback address to the app client.

5. The app client retrieves the video content from the CDN node using the playback address.

6. The CDN node returns the video content to the app client.

7. The app client plays the video.

## Obtaining playback addresses

You can obtain playback addresses from BytePlus VOD in three ways: through the console, using an API or server\-side SDK, or by manually constructing the URL.

<span id="fd88cf20"></span>
### Using the console


1. Log in to the [BytePlus VOD console](https://console.byteplus.com/vodpaas/totalOverview/) and select the desired space.

2. Navigate to the **Videos** page and click **Details** in the action column for the target video. This will take you to the **Video details** page.

3. Under the **Video address** tab, you can find the playback addresses for the original video file and its transcoded versions. You can perform the following actions:

   1. Click **Publish** or **Unpublish** to change the video's status. You cannot preview or retrieve links for unpublished videos.

   2. Click **Copy link** to copy the video's playback address.

### Using an API or Server SDK

Call the [GetPlayInfo](https://docs.byteplus.com/docs/byteplus-vod/reference-getplayinfo) API and pass the `Vid` parameter to get the playback address. You need to specify parameters such as the container format, encoding format, and resolution to retrieve the address for a specific version of the video. Here are some examples for common scenarios:


* **Example 1 (Getting HLS standard encrypted video)** : To get an HLS standard encrypted video, you need to set the following parameters to specific values:

   * `FileType`: Set to `standard_evideo`, indicating a request for an HLS standard encrypted video.

   * `Format`: Set to `hls`, indicating the use of HLS container format.

   * `Codec`: Set to either `H264` or `H265`, as needed.

   * `Definition`: Set to the desired resolution, such as `720p` or `1080p`

* **Example 2 (Getting private encrypted video)** : To get a private encrypted video, you need to set the following parameters to specific values:

   * `FileType`: Set to `private_evideo`, indicating a request for a private encrypted video.

   * `Format`: Set to `mp4`, `hls`, or `dash`, as needed.

   * `Codec`: Set to either `H264` or `H265`, as needed.

   * `Definition`: Set to the desired resolution, such as `720p` or `1080p`

   * `UnionInfo`: Set to information from the browser or device that can uniquely identify the access or device.

   * `DrmKEK`: Set to the key encryption key generated by the Player SDK.


BytePlus VOD provides server\-side SDKs, which we recommend using to call the API. For details, refer to the following documents:


* [Java SDK](https://arcosite.bytedance.net/uchbv7an/8002)

* [Python SDK](https://arcosite.bytedance.net/uchbv7an/8000)

* [PHP SDK](https://arcosite.bytedance.net/uchbv7an/7999)

* [Go SDK](https://arcosite.bytedance.net/uchbv7an/8001)

### Manually constructing the URL

You can also obtain the playback address by following these steps:


1. Call the [GetMediaInfos](https://docs.byteplus.com/docs/byteplus-vod/reference-getmediainfos) API and pass the `Vid` parameter to retrieve the `FileName`.

2. Construct the playback URL manually:

   * **URL format:**  `Protocol://PlaybackDomain/FileName?auth_key=xxx`

   * **Example:**  If your VOD acceleration domain (`PlaybackDomain`) is `play.vod.com` and the video's `FileName` is `/abc123456test.mp4`, the playback address would be `http://play.vod.com/abc123456test.mp4`. If you have enabled URL authentication in the BytePlus VOD console, you will also need to calculate the `auth_key` signature based on your authentication type. For details, see [URL signing overview](https://docs.byteplus.com/docs/byteplus-vod/docs-url-authentication-overview).

## Playback options

Once you have the playback address, you can pass it to a player. We recommend using the BytePlus VOD Player SDK for the best performance and compatibility.


* **BytePlus VOD Player SDK:**  Supports direct playback using the playback address and offers a wide range of features, including high\-quality playback and advanced playback controls. For details, refer to the following documentation:

   * [Android Player SDK: Integrating the SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-integration-android)

   * [iOS Player SDK: Quickstart](https://docs.byteplus.com/docs/byteplus-vod/docs-getting-started-with-the-ios-player-sdk)

   * [Web Player SDK: Quickstart](https://docs.byteplus.com/docs/byteplus-vod/docs-getting-started-with-the-web-player-sdk)

   * [Flutter Player SDK: Integrating the SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-flutter-player-quickstart)

   * [React Native Player SDK: Integrating the SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-rn-player-quickstart)

* **Other players:**  You can also use native system players, open\-source players, or custom players.
