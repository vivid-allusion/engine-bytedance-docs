To implement DRM encryption on your videos using the BytePlus VOD console, you must first obtain a DRM key from Intertrust. This guide provides step\-by\-step instructions on how to get the required API key from the Intertrust console.

<span id="04eaeaa2"></span>
## Prerequisite

An [Intertrust](https://portal.expressplay.com/) account. You need to activate the required services for this account, and using these services incurs charges from Intertrust. For more information, contact Intertrust or your [BytePlus sales representative](https://www.byteplus.com/en/contact).

<span id="26e67a9d"></span>
## Procedure


1. Sign in to the [Intertrust](https://portal.expressplay.com/) console.

2. Click **Manage Account** in the left navigation.

3. Click **Subscriptions**.

4. Enable your desired DRM systems.

5. Click **Api Keys / Cust. Auth.**  in the left navigation.

6. Click the **Add Api Key / Cust. Auth.**  button to create an API key. Store the key in a safe place, as you cannot retrieve it later.
