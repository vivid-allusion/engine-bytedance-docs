Client\-side uploads allow you to upload media files directly from your client apps (Android, iOS, or Web) to the BytePlus VOD server by integrating the Upload SDK. This method conserves your server resources by bypassing the need for files to pass through your own server, making it ideal for scenarios such as UGC (User Generated Content), PGC (Professionally Generated Content), and back\-end operations. This guide explains the authentication mechanism, outlines the complete upload process, and provides references to the relevant SDKs to get you started.

<span id="ed1abc5d"></span>
## Authentication

When uploading media files from the app client to the BytePlus VOD server, the files are directly sent without being forwarded by any intermediate servers. As a result, client authentication is necessary to ensure security.

To accomplish this, you need to deploy an authorization service on your app server. This service will generate a temporary upload token that is passed from the app server to the client app.

Here are some key features of temporary upload tokens:


* Local generation: Temporary upload tokens are locally generated by the AK and SK on the app server, eliminating the need for external networks. If multiple tokens are required, you can generate them by calling the appropriate method in a loop.

* High security: Customizable timeout durations allow strict control over the validity of temporary upload tokens, ensuring enhanced security.

* Easy to use: You can generate temporary upload tokens by simply configuring the AK and SK on the app server and making a simple API call.

* Flexibility: Parameters can be set to enable flexible signing and verification, providing customization options based on your requirements.


The BytePlus VOD Server SDK encapsulates the logic for issuing temporary upload tokens. You can integrate the BytePlus VOD Server SDK into your app server for issuing temporary upload tokens, and then pass them to the app client. For details, refer to the following documents:


* [Java SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-java-sdk)

* [Python SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-python-sdk)

* [PHP SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-php-sdk)

* [Go SDK](https://docs.byteplus.com/docs/byteplus-vod/docs-go-sdk)

## **Upload process**

The process of client\-side uploads is shown in the following diagram:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2ae4f4dff96f48c1904dc7503a0c8119~tplv-goo7wpa0wc-image.image) </span>

The process is explained as follows:


1. The app client sends a request for a temporary upload token to the app server.

2. The app server issues a temporary upload token locally.

3. The app server returns the temporary upload token to the app client.

4. The app client passes the temporary upload token to the Upload SDK.

5. The app client calls the APIs of the Upload SDK to construct upload parameters and start the upload.

6. The Upload SDK uses the temporary upload token to upload media assets to BytePlus VOD.

7. The BytePlus VOD service returns the upload results to the Upload SDK.

8. (Optional) The Upload SDK triggers upload\-related events.
