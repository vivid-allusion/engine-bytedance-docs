To gain precise control over the storage and organization of your media processing outputs, you can customize the default file path generation. This guide explains how to create your own file paths using a combination of fixed text strings and dynamic variables, allowing you to meet specific file management requirements.

<span id="4c6219b4"></span>
## How to customize output file path

In the BytePlus VOD console, enable **Custom file path** when configuring video, low\-bitrate HD and audio transcoding tasks, custom transcoding groups, or snapshot tasks, as shown in the figure below:

## About file path creation

File paths are created from fixed text strings and variables. The variables can be replaced dynamically, but the fixed text strings cannot. To be more specific:


* Fixed text strings can be used to display business information. For example, `watermark` for videos with watermarks or `encrypt` for encrypted videos. Fixed text strings must comply with [Character rules for file naming](https://docs.byteplus.com/docs/byteplus-vod/docs-character-rules-for-file-naming).

* Variables refer to the dynamically replaceable values of the file path obtained by the system when generating the actual file path. BytePlus VOD supports the following variables:

   
   |Variable name |Description |
   |---|---|
   |{{fileName}} |Input video file path, where the input video is saved. If a file called `123.mp4` is saved as `BucketName/Project/VideoFiles/123.mp4`, the file name will be `Project/VideoFiles/123.mp4`. |
   |{{fileTitle}} |Input video file name. For example, the file name for `123.mp4` is `123`. |
   |{{filePrefix}} |The input video file prefix is the file path before the file name, excluding the bucket name. If a file called `123.mp4` is saved as `BucketName/Project/VideoFiles/123.mp4`, the file prefix will be `Project/VideoFiles/`. |
   |{{vid}} |The input video ID. The `Vid` is automatically generated by the system when the file is uploaded to BytePlus VOD. |
   |{{templateId}} |The media processing template ID. |
   |{{random}} |A random 32\-bit text string. For example, a02befg10001c\*\*\*584k6dpdnmu87g |
   |{{count}} |A 5\-digit placeholder, for example, 00001 or 00002. Only used for sampled snapshots and sprite snapshots for categorizing multiple snapshots. |
   |{{outFormat}} |File output format. The system automatically generates suffixes based on the media processing template and container format. Please see [Output format](https://docs.byteplus.com/docs/byteplus-vod/docs-customizing-output-file-path#f222f355) for the actual mapping relationship. |
   |{{encryptionProvider}} |When **all** three of these conditions are met:<br><br><br>* DRM encryption is enabled within the media processing template.<br><br>* Multiple encryption methods are selected.<br><br>* The `{{fileName}}` variable is used to customize filenames.<br><br><br>Then the `{{encryptionProvider}}` variable must be used to differentiate between the resulting encrypted files. Its values are as follows.<br><br><br>* `PlayReady`: When using PlayReady encryption.<br><br>* `Hybrid`: When using encryption methods other than PlayReady. |

## Example

If the input video is located at `http://www.example.com/tos-vod-cn-v/20220803/demo.mp4`, the system takes sampled snapshots from the input video. If the file path for the output is set to: `{{filePrefix}}{{fileTitle}}_{{count}}.jpg`, then the URL for the snapshots will be:


* http://www.example.com/tos\-vod\-cn\-v/20220803/demo_00001.jpg

* http://www.example.com/tos\-vod\-cn\-v/20220803/demo_00002.jpg

* http://www.example.com/tos\-vod\-cn\-v/20220803/demo_00003.jpg
