To enhance the stability and performance of the BytePlus VOD service, we are planning to put limits on the queries per second (QPS) for API calls per account by December 27, 2024. If the QPS limit per account is exceeded, a throttling mechanism will be activated. To prevent service disruptions, we recommend that you be aware of this limit before making API calls. For details, see [QPS limits on API calls](https://docs.byteplus.com/en/docs/byteplus-vod/reference-qps-limits-on-api-calls).

If you have any questions or concerns about this change, please feel free to contact BytePlus support team by [creating a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00001112) at BytePlus Website.
