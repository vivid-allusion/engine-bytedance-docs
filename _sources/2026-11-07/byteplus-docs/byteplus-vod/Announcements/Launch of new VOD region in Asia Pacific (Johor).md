The new **Asia Pacific (Johor)**  region is now live as of **September 17, 2025**. This new region is now fully operational, supporting all BytePlus VOD features, including space management, media asset uploading, storage, processing, and delivery acceleration.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/492dc99c3dd8458f9804f3e65faed107~tplv-goo7wpa0wc-image.image) </span>

To ensure our customers benefit from the latest innovations, the Johor region will be the exclusive region for all future product updates and new features.

For existing customers:


* Your existing spaces, data, and services in the Singapore region remain safe and fully accessible for ongoing management and editing. You can continue to manage your spaces, data, and services in the Singapore region without interruption.

* All new spaces must now be created in the new Johor region. This will ensure your new projects have access to our latest capabilities and future enhancements.

* If you are using the BytePlus VOD Server SDKs, please note an important update for region initialization. To access services in the new **Johor** region, you must explicitly specify the region (`ap-southeast-1`) when initializing your SDK instance. The default region remains `ap-singapore-1` (Singapore) if not specified. For detailed instructions and code examples, please refer to the following documents:

   * Java SDK: [Setting the service region](https://docs.byteplus.com/docs/byteplus-vod/docs-java-sdk#37eb4f42)

   * Python SDK: [Setting the service region](https://docs.byteplus.com/docs/byteplus-vod/docs-python-sdk#15075adf)

   * PHP SDK: [Setting the service region](https://docs.byteplus.com/docs/byteplus-vod/docs-php-sdk#d8e0909a)

   * Go SDK: [Setting the service region](https://docs.byteplus.com/docs/byteplus-vod/docs-go-sdk#0e1c954a)


We encourage you to start utilizing the Johor region for your new projects to take full advantage of upcoming capabilities.

Thank you for your continued support.
