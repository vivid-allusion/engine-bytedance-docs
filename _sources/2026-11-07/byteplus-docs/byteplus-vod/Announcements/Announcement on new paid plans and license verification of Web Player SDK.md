To continue improving the Web Player SDK, we are introducing new paid plans and mandatory license verification, effective **August 20, 2025**.

<span id="c4482911"></span>
## What's changing?


* **New Paid Plans**: This means the SDK will shift to a tiered pricing structure with two distinct editions:

   * **Standard**: Core playback features for essential needs.

   * **Premium**: A richer feature set for an optimized user experience, including:

      * Preloading

      * H.265 playback with device compatibility list for hardware decoding and hardware decoding optimization

      * H.266 playback

      * Dynamic buffer

      * Adaptive Multi\-Bitrate (ABR) streaming

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For a full feature comparison, see <a href="https://docs.byteplus.com/docs/byteplus-vod/docs-player-features">Player SDK features</a>.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For pricing, see <a href="https://docs.byteplus.com/docs/byteplus-vod/docs-sdk-license-pricing">Player SDK license pricing</a>.   </div>
   

* **License verification required**: Starting with version 1.15.0, you must configure a license to use the Web Player SDK. The license authenticates your right to use the SDK and unlocks the features corresponding to your selected plan. While older versions are not affected, we strongly recommend upgrading to the latest version to access our full range of features and support.


<span id="5fc6e55c"></span>
## What you need to do

To ensure uninterrupted service, please obtain and configure your license by following the instructions in [Web Player SDK: Quickstart](https://docs.byteplus.com/docs/byteplus-vod/docs-getting-started-with-the-web-player-sdk)

If you have any questions or concerns about this change, please feel free to contact BytePlus support team by [creating a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00001112) at BytePlus Website.

Thank you for your continued support.
