Following the launch of our new **Asia Pacific (Johor)**  region on September 17, 2025, BytePlus VOD will migrate all services and data from the **Asia Pacific (Singapore)**  region to Johor.

This migration is part of our ongoing commitment to providing a more robust, scalable, and high\-performance infrastructure. The new Johor region supports all VOD features and will serve as our primary center for future innovation and resource expansion.

<span id="f198783e"></span>
## Migration schedule

The migration will be conducted in phases between the following dates:


* Start date: October 27, 2025

* End date: March 31, 2026


<span id="7f190a9f"></span>
## Migration plan and customer impact

This migration is designed to be a seamless, backend process with **no disruption to your services**.


* Scope: All media assets, metadata, and processing tasks in the `ap-singapore-1` (Singapore) region will be migrated.

* Action required: None. Your existing configurations—including domain names, API endpoints, SDK initializations, and any parameters pointing to `ap-singapore-1`—will continue to function without any changes.


<span id="bc9ec6bb"></span>
## Post\-migration details

While functionality will remain unchanged, please note the following:


* Console and API display: To ensure backward compatibility, your existing spaces and assets will continue to be labeled as `ap-singapore-1` in the VOD console and API responses.

* Underlying infrastructure: Although the display name remains `ap-singapore-1`, the actual services will be physically provisioned from and served by the upgraded infrastructure in the Johor region.

* Billing and usage: There will be no changes to your billing model or how usage is calculated.


For any questions regarding this migration, please [submit a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00001112) to contact BytePlus support team.
