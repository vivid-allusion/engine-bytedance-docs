The video download and offline playback feature allows users to save video content to their local devices for watching without an internet connection. The React Native SDK supports downloading videos in MP4 and HLS formats and provides a complete set of APIs for task creation, state management (pause, resume, delete), progress queries, and offline playback.

<span id="fb5bfe58"></span>
## Initialize the download module

Global parameters related to downloading must be configured during the SDK initialization phase via `initEnv`. It is recommended to set these based on your app's storage strategy and free space warning thresholds.

```TypeScript
import { initEnv } from '@byteplus/react-native-vod-player';

initEnv({
  // ... other initialization configurations
  DownloadDirectory: 'videos', // (Optional) Specify the subdirectory for download storage
  MaxDownloadOperationCount: 3, // (Optional) Maximum concurrent download tasks, default is 1
  LimitFreeDiskSize: 1024 * 1024 * 500, // (Optional) Set the minimum free disk space to 500MB; downloads are prohibited below this
});
```



|**Parameter** |**Type** |**Default value** |**Description** |
|---|---|---|---|
|`DownloadDirectory` |`string` |*  |The name of the subdirectory under the app's cache area for downloads. Uses the SDK's default path if not set. |
|`MaxDownloadOperationCount` |`number` |1 |The maximum number of download tasks allowed to run simultaneously. |
|`LimitFreeDiskSize` |`number` |1 GB |Sets the minimum threshold for available disk space on the device (in bytes). The default value is 1 GB. If the available disk space falls below this threshold, download tasks cannot be executed, and error code \-9947 will be triggered. Note that the calculated free space is typically less than the value displayed in the device's system settings. |
|`IOSLimitFreeDiskCount` |`number` |50 | **(iOS Only)**  The maximum number of videos that can be cached. |

## Create and start download tasks

The Player SDK supports playing both DirectUrl and Vid video sources. Correspondingly, it provides download capabilities for both data source types.


<Tabs>
<Tab zoneid="UQYVYtteAs" title="Vid mode">
<TabTitle>Vid mode</TabTitle>

Suitable for downloading **videos already uploaded to the BytePlus VOD service**. You specify the content using the video `Vid` and its corresponding temporary playback token `PlayAuthToken`. These parameters are typically issued by your business server and used directly by the client. For details, see [Playing videos with temporary playback tokens](https://docs.byteplus.com/docs/byteplus-vod/docs-playing-videos-with-temporary-playback-tokens).

```TypeScript
import { createVidDownloadTask, ResolutionType, resumeDownloadTask } from '@byteplus/react-native-vod-player';

const task = await createVidDownloadTask(
  'video_vid_here',  // Video VID
  ResolutionType.SuperHigh, // Specify download at Super High resolution
  'video_playAuthToken_here',   // Playback token
);

resumeDownloadTask(task); // Start downloading
```



</Tab>
<Tab zoneid="QLrzgHNSRK" title="DirectUrl mode">
<TabTitle>DirectUrl mode</TabTitle>

Suitable for downloading **video URLs from BytePlus or third\-party CDNs**. You specify the content by passing the direct playback URL of the video. In addition to the `url`, you must provide the following two key parameters:


* `vid`: A unique identifier for the video. This can be an ID from your own video management system or one generated by the app. This ID is used for SDK log reporting, preloading, pre\-rendering, and other features.

* `cacheKey`: The cache index key for the video. To ensure uniqueness, it is recommended to use the MD5 hash of the URL. To ensure the stability of cache and download functions, we strongly recommend following these rules for the `cacheKey`:

   * **Character range**: Use only **letters** (a\-z, A\-Z) and **digits** (0\-9).

   * **Avoid special symbols**: **Do not** use symbols such as `_`, `-`, `/`, `?`, `&`, etc.


```TypeScript
import { createUrlDownloadTask, resumeDownloadTask } from '@byteplus/react-native-vod-player';

const task = await createUrlDownloadTask(
  ['http://example.com/video.mp4'], // Supports main and backup URLs
  'your_custom_cache_key',          // A unique cache key must be provided
  'optional_video_id_for_tracking'// Associated video VID
);

resumeDownloadTask(task); // Start downloading
```

## Manage download tasks

<span id="0fad4e36"></span>
### Individual task control

Operate on a single `DownloadTask` instance by calling the following methods:


* **Start/Resume**: `resumeDownloadTask(task)`

* **Pause**: `suspendDownloadTask(task)`

* **Delete task and files**: `cancelDownloadTask(task)` (This action permanently deletes the downloaded files)


<span id="f1d0c565"></span>
### Bulk control and status restoration

When the app restarts, you can call `loadAllTasks` to retrieve all historical tasks (including incomplete ones) to display them in a UI list.

```TypeScript
import { loadAllTasks, resumeAllDownloadTasks } from '@byteplus/react-native-vod-player';

// Load the list of historical tasks
const allTasks = await loadAllTasks();

// Bulk operations
resumeAllDownloadTasks();  // Start all tasks in "waiting" or "suspended" states
suspendAllDownloadTasks(); // Pause all active downloads
cancelAllDownloadTasks();  // Delete all tasks and their downloaded files
```

## Set listeners and update the UI

Set the global listener `setDownloadListener`, which is the primary entry point for the UI layer to receive progress and state updates.

```TypeScript
import { setDownloadListener, DownloadTask, DownloadTaskState } from '@byteplus/react-native-vod-player';

setDownloadListener({
  onDownloadProgress: (task, receivedSize, totalSize) => {
    const progress = totalSize > 0 ? receivedSize / totalSize : 0;
    console.log(`Task ${task.getCacheKey()} download progress: ${(progress * 100).toFixed(2)}%`);
    // Update your UI here
  },
  onDownloadStateChanged: (task, state) => {
    console.log(`Task ${task.getCacheKey()} state changed to: ${DownloadTaskState[state]}`);
    // Update your UI here
  },
  onDownloadComplete: (task, error) => {
    if (error) {
      console.error(`Task ${task.getCacheKey()} download failed:`, error);
    } else {
      console.log(`Task ${task.getCacheKey()} download completed!`);
    }
  },
  // Other callbacks...
});
```


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When you call <code>cancelDownloadTask</code> or <code>cancelAllDownloadTasks</code> to cancel a task, every canceled task (regardless of its previous state) will trigger the <code>onDownloadComplete</code> callback. An error code of <code>-9995</code> indicates the task was actively canceled by the user.</div>

## Offline playback

The logic for offline playback is based on an automatic cache\-hit mechanism. As long as the playback source parameters match the download parameters exactly and the cache playback toggle is enabled, the player will prioritize reading the local file.


* **Enable cached source playback**: You must call `player.enablePlayCachedSource()` before setting the playback source.

* **Identifier matching**:

   * **Vid mode**: `vid`, `resolution`, and `playAuthToken` must remain consistent.

   * **URL mode**: `urls`, `cacheKey`, and `vid` must remain consistent.


```TypeScript
// 1. Enable the cache playback switch before setting the playback source
player.enablePlayCachedSource();

// 2. Construct a data source identical to the one used for the download task
// 3. Set it to the player; the SDK will automatically locate the local file
player.setVideoSource(videoSource);
player.play();
```

## References

<span id="8840ee82"></span>
### `DownloadTask` properties


|Property/Method |Return type |Description |
|---|---|---|
|`state` |`DownloadTaskState` |Current task state |
|`progress` |`number` |Progress (0.0 ~ 1.0) |
|`countOfBytesReceived` |`number` |Bytes already downloaded |
|`countOfBytesExpectedToReceive` |`number` |Estimated total size (may be \-1 for HLS initially) |
|`getCacheKey()` |`string` |The unique key for the task |
|`getVideoId()` |`string` |The associated VID |
|`getResolution()` |`ResolutionType` |The resolution selected for download |


<span id="771aae5a"></span>
### Task state enumeration


|Enum value |ID |Description |
|---|---|---|
|`Init` |0 |Task created but not yet in the queue |
|`Waiting` |1 |In the queue, waiting for an available download slot based on `MaxDownloadOperationCount` |
|`Running` |2 |Downloading in progress |
|`Suspended` |3 |Paused |
|`Canceling` |4 |Cancellation/deletion in progress |
|`Completed` |5 |Download finished |

### Code example

Below is a simplified example of a download management page.

```TypeScript
import React, { useState, useEffect } from 'react';
import { View, Text, Button, FlatList } from 'react-native';
import { 
  loadAllTasks, 
  createVidDownloadTask,
  resumeDownloadTask,
  suspendDownloadTask,
  cancelDownloadTask,
  setDownloadListener,
  DownloadTask,
  ResolutionType 
} from '@byteplus/react-native-vod-player';

const DownloadManagerScreen = () => {
  const [tasks, setTasks] = useState<DownloadTask[]>([]);

  // Load all tasks and set up listeners on initialization
  useEffect(() => {
    const init = async () => {
      const existingTasks = await loadAllTasks();
      setTasks(existingTasks);
    };

    init();

    setDownloadListener({
      onDownloadProgress: (task, receivedSize, totalSize) => {
        // Update the progress UI for a specific task
        setTasks(currentTasks => 
          currentTasks.map(t => t.getCacheKey() === task.getCacheKey() ? task : t)
        );
      },
      onDownloadStateChanged: (task, state) => {
        // Update the task list state
        setTasks(currentTasks => 
          currentTasks.map(t => t.getCacheKey() === task.getCacheKey() ? task : t)
        );
      },
      // ... other callbacks
    });
  }, []);
  
  const handleAddTask = async () => {
    const newTask = await createVidDownloadTask('your_vid_here', ResolutionType.SuperHigh, 'your_playAuthToken_here');
    if (newTask) {
      setTasks(prevTasks => [...prevTasks, newTask]);
      resumeDownloadTask(newTask); // Start immediately after creation
    }
  };

  const renderTaskItem = ({ item }: { item: DownloadTask }) => (
    <View style={{ padding: 10, borderBottomWidth: 1, borderColor: '#ccc' }}>
      <Text>ID: {item.getVideoId() || item.getCacheKey()}</Text>
      <Text>Progress: {(item.progress * 100).toFixed(2)}%</Text>
      <Text>State: {item.state}</Text>
      <View style={{ flexDirection: 'row', justifyContent: 'space-around', marginTop: 5 }}>
        <Button title="Start/Resume" onPress={() => resumeDownloadTask(item)} />
        <Button title="Pause" onPress={() => suspendDownloadTask(item)} />
        <Button title="Delete" onPress={() => {
          cancelDownloadTask(item);
          setTasks(prev => prev.filter(t => t.getCacheKey() !== item.getCacheKey()));
        }} />
      </View>
    </View>
  );

  return (
    <View>
      <Button title="Add New Download Task" onPress={handleAddTask} />
      <FlatList
        data={tasks}
        renderItem={renderTaskItem}
        keyExtractor={item => item.getCacheKey() || ''}
      />
    </View>
  );
};
```
