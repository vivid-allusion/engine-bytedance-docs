The Adaptive Multi\-Bitrate (ABR) streaming feature provides users with an "auto" resolution option in the player, where the player automatically selects the most suitable bitrate for streaming based on the user's current bandwidth and device. This enhances the viewing experience by adjusting the video quality dynamically.

<span id="3839889f"></span>
## What it looks like

VePlayer displays the "Auto" option in the resolution list. When the user switches to this option, VePlayer starts multi\-bitrate adaptive playback and displays the current actual resolution in real time.

## Prerequisites

If you need to implement multi\-bitrate playback of HLS and DASH videos in Vid mode, you can use the BytePlus VOD media processing service to [generate an adaptive bitrate streaming file](https://docs.byteplus.com/en/docs/byteplus-vod/docs-abr-streaming). Then, you can set these transcoded streams as the playback source for the player, enabling it to switch video resolution based on network conditions during playback.

<span id="783a96e7"></span>
## Play HLS adaptive bitrate streams


* DirectUrl mode: When initializing VePlayer, provide the URL of the mainstream and substreams using the `playList` parameter. You also need to configure adaptive multi\-bitrate streaming with the `autoBitrateOpts` parameter. Here is an example code snippet:

   ```JavaScript
   const playerSdk = new VePlayer({
     id: 'video',
     autoplay: true,
     streamType: 'hls',
     playList: [
       {
         // Address of sub-stream 1
         url: 'https://example.com/af2534***/*****1/stream1.m3u8',
         definition: '480p',
         bitrate: 274117,
         width: 854,
         height: 480,
         duration: 2665.698,
       },
       {
         // Address of sub-stream 2
         url: 'https://example.com/af2534***/*****1/stream2.m3u8',
         definition: '720p',
         bitrate: 502452,
         width: 1280,
         height: 720,
         duration: 2665.698,
       },
       {
         // Address of sub-stream 3
         url: 'https://example.com/af2534***/*****1/stream3.m3u8',
         definition: '1080p',
         bitrate: 502446,
         width: 1280,
         height: 720,
         duration: 2665.698,
       },
       {
         // master m3u8 main stream address
         url: 'https://example.com/af2534***/*****1/master.m3u8',
         definition: 'auto',
       },
     ],
     // Configure multi-bitrate adaptive streaming.
     autoBitrateOpts: {
       enable: true, // Whether to enable ABR function. Default is false.
       startWithAuto: true, // Whether to start playback in auto mode. Default is false.
       showRealDefinition: true, // Whether auto mode display the actual resolution, such as 'Auto (360p)'
       autoDefinitionText: '自动', // Text displayed for auto mode. Optional; defaults to the configuration of 'languages' if not provided.
       definitionTextKey: 'DEFINITION_AUTO_DESC', // Internationalization key for auto mode text, default is DEFINITION_AUTO.
     },
     languages: {
       zh: {
         // Auto mode text in Chinese.
         DEFINITION_AUTO_DESC: '自动',
       },
       en: {
         // Auto mode text in English.
         DEFINITION_AUTO_DESC: 'Auto',
       },
     },
   });
   ```
   

* Vid mode: When the application server generates a [temporary playback token](https://docs.byteplus.com/en/docs/byteplus-vod/docs-playing-videos-with-temporary-playback-tokens), set the `Definition` to `auto` and the `Format` to `hls` to play the adaptive streaming file generated by the BytePlus VOD media processing service. You can also configure multi\-bitrate adaptive playback using the `autoBitrateOpts` parameter. Example code:

   ```TypeScript
   const playerSdk = new VePlayer({
     id: 'video',
     autoplay: true,
     getVideoByToken: {
       playAuthToken: 'playAuthTokenWhichDefinitionIsAuto',  // 
       needPoster: true,
     },
     // Configure Adaptive Multi-Bitrate (ABR) playback.
     autoBitrateOpts: {
       enable: true, // Whether to enable ABR function. Default value is false
       startWithAuto: true, // Whether to start playback in auto mode. Default is false.
       showRealDefinition: true, // Whether auto mode display the actual resolution, such as 'Auto (360p)'
       autoDefinitionText: '自动', // Text displayed for auto mode. Optional; defaults to the configuration of 'languages' if not provided.
       definitionTextKey: 'DEFINITION_AUTO_DESC', // Internationalization key for auto mode text, default is DEFINITION_AUTO.
     },
     languages: {
       zh: {
         DEFINITION_AUTO_DESC: '自动',
       },
       en: {
         DEFINITION_AUTO_DESC: 'Auto',
       },
     }
   });
   ```

## Play DASH adaptive bitrate streams

For the DASH videos, VePlayer only supports multi\-bitrate adaptive playback in Vid mode. When the application server generates a [temporary playback token](https://docs.byteplus.com/en/docs/byteplus-vod/docs-playing-videos-with-temporary-playback-tokens), set the `Definition` to `auto` and the `Format` to `dash` to play the adaptive streaming file generated by the BytePlus VOD media processing service. You can also configure multi\-bitrate adaptive playback using the `autoBitrateOpts` parameter. Example code:

```TypeScript
const playerSdk = new VePlayer({
  id: 'video',
  autoplay: true,
  getVideoByToken: {
    playAuthToken: 'playAuthTokenWhichDefinitionIsAuto',
    needPoster: true,
  },
  // Configure Adaptive Multi-Bitrate (ABR) playback.
  autoBitrateOpts: {
    enable: true, // Whether to enable ABR function. Default value is false
    startWithAuto: true, // Whether to start playback in auto mode. Default is false.
    showRealDefinition: true, // Whether auto mode display the actual resolution, such as 'Auto (360p)'
    autoDefinitionText: 'Auto', // Text displayed for auto mode. Optional; defaults to the configuration of 'languages' if not provided.
    definitionTextKey: 'DEFINITION_AUTO_DESC', // Internationalization key for auto mode text, default is DEFINITION_AUTO.
  },
  languages: {
    zh: {
      DEFINITION_AUTO_DESC: '自动',
    },
    en: {
      DEFINITION_AUTO_DESC: 'Auto',
    },
  }
});
```

## Play MP4 adaptive bitrate streaming

The BytePlus VOD adaptive streaming transcoding template currently only supports HLS and DASH protocols. Therefore, you need to prepare your own playback source for the MP4 protocol. You need to ensure that the IDR frames are aligned between videos with different bitrates, that is, to ensure that all parameters of the transcoded output video are the same except for the resolution.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">An IDR (Instantaneous Decoding Refresh) frame is a special type of I\-frame that instantly refreshes the image to prevent error propagation. Unlike a normal I\-frame, all frames that follow an IDR frame cannot reference the frame content that precedes the IDR frame. This makes it easy to control the encoding and decoding processes, and also enables random access to the video. During video playback, the player usually selects the IDR frame closest to the specified location for playback to avoid the complex reverse parsing process. During multi\-bitrate transcoding, if IDR frame alignment is specified, the IDR frames of the output video can be precisely synchronized in terms of both timing and content. This achieves smooth switching between multi\-bitrate videos and prevents stuttering.</div>

## Event

When the actual resolution corresponding to the "auto" option changes, the SDK triggers the `ABR_AUTO_DESC_CHANGE` event.
