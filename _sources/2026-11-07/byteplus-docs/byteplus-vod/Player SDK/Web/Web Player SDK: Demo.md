BytePlus VOD provides an online [demo](https://demo.byteplus.com/common/veplayer/basic/example?tab=function-display) for you to unlock the exciting potential of the Web Player SDK. Here's what you can do:


* Toggle between different tabs to experiment with various features.

* Explore the sample code, make modifications, and witness how the code works by clicking the **Run** button.

* Copy the code to your own project and integrate the desired features into your app with ease.
