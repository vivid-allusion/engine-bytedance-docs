This article outlines the various limitations when using MediaLive.

<span id="3af5eacf"></span>
## Account resource quota


|**Limitation** |**Description** |
|---|---|
|Number of domain name spaces |By default, each account can create 10 domain name spaces. |
|Number of domain names |By default, up to 10 live push/pull domain names can be added under each domain name space. |
|Number of AppNames which can create value\-added feature configuration |By default, up to 50 AppNames can have feature configurations created for them under each domain name space. |
|Number of StreamNames which can create value\-added feature configuration |By default, up to 20 StreamNames can have feature configurations created for them under each domain name space. |
|Maximum concurrent number of transcoding tasks |By default, each domain name space supports a maximum of 100 concurrent transcoding tasks. |
|Maximum concurrent number of recording tasks |By default, each domain name space supports a maximum of 100 concurrent recording tasks. |
|Maximum concurrent number of screenshot tasks |By default, each domain name space supports a maximum of 50 concurrent screenshot tasks. |
|Number of relay tasks |By default, each account supports a maximum of 20 relay tasks. |
