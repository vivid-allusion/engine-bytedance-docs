BytePlus MediaLive is a secure, stable, and professional cloud\-based live\-streaming service for enterprises and individuals. Built on advanced audio/video processing and large\-scale content distribution technologies, it provides a rich set of features and value\-added services that allow you to build a complete streaming platform in just a few steps.

<span id="Product architecture"></span>
## Product architecture

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/67c49ad57a6541038c270ce47403026a~tplv-goo7wpa0wc-image.image) </span>

BytePlus MediaLive provides an end\-to\-end streaming solution:


* You can use the Broadcast SDK for Web to push streams to the server. The SDK also supports audio and video capture, ultra\-low\-latency streaming, and other capabilities.

* The server provides a wide range of services, including domain and stream management, stream and usage statistics, and value\-added services such as transcoding, recording, and screenshot capture. You can use both the [BytePlus MediaLive console](https://docs.byteplus.com/byteplus-media-live/docs/introduction-to-the-media-live-console) and [OpenAPI](https://docs.byteplus.com/byteplus-media-live/docs/getting-started-with-your-api) to access these services.

* The Player SDK provides a high\-quality viewing experience, including ultra\-high\-definition video quality, fast first\-frame rendering, and stable playback. The SDK also reports playback quality statistics to help you quickly identify issues and monitor streaming performance.
