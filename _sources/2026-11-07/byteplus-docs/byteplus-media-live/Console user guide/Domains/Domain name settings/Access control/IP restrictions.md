You can configure an IP blocklist or allowlist to restrict access to your domain names.

Follow the instructions below to configure an IP blocklist or allowlist in the BytePlus MediaLive console.


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **Domains**.

3. Find the domain name that you want to check out, and click **Settings** in the **Actions** column.

4. Click the **Access control** tab.

5. Click **Edit** to the right of the **IP restrictions** toggle.

6. In the **Edit IP blocklist and allowlist** dialog box that appears, configure the following parameters.

   * **List type**: Select **Blocklist** or **Allowlist**. Blocklist and allowlist are mutually exclusive. You can configure only one of them. If you select **Blocklist**, requests from the IP addresses in the blocklist cannot access resources. If you select **Allowlist**, only requests from the IP addresses in the allowlist are allowed to access resources.

   * **Rules**: Enter at most 100 IP addresses or subnet masks. The IP addresses you enter must be unique. To add more IP addresses, [contact technical support](https://www.byteplus.com/en/support) to apply to increase the upper limit.

7. Click **Confirm**.
