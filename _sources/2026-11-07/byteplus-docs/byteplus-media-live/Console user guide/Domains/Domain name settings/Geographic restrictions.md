This page introduces how to restrict requests from specific geographic regions in the BytePlus MediaLive console.

<span id="35cb5fdb"></span>
## Procedure


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **Domains**.

3. Find the domain name that you want to configure, and click **Settings** in the **Actions** column.

4. Click the **Access control** tab.

5. Click **Edit** to the right of the **Geographic restrictions** toggle.

6. In the **Edit geographic restrictions** dialog box that appears, configure the following parameters.

   * **Restriction type**:

      * **Blocklist**: Indicates that requests from specified regions are prohibited from accessing your domain name.

      * **Allowlist**: Indicates that only requests from specified regions are allowed to access your domain name.

   * **Regions**: Specify one or more regions from which requests will be either blocked or allowed.

7. Click **Confirm**.
