To prepare your application for a production environment or prevent service interruptions from an expired license, you need to manage your SDK license effectively. This topic provides detailed instructions on how to upgrade a trial license to a basic or premium license, and how to renew a basic or premium license.

<span id="e364f940"></span>
## Prerequisites

You have obtained your SDK license. For more information, see [Getting your SDK license](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management).

<span id="777c7de7"></span>
## Upgrading a trial license to a basic or premium license

A trial license is for testing purposes only and cannot be used for the production environment. Before the trial license expires or your app is released for production, upgrade the trial license to a basic or premium license.


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **SDK management**.

3. Click **Upgrade** in the **Action** column for the trial license.

4. Select **Basic** or **Premium** as the license type.

## Renewing a license

When your basic or premium license is about to expire or has already expired, the **SDK management** page displays an expiration reminder. Please renew the license promptly to prevent online service interruption.


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **SDK management**.

3. Click **Renew** in the **Action** column for the license you want to renew.

## FAQ

<span id="8462b9a3"></span>
### After renewing the license, do I have to release a new version of my app?


* For Android or iOS apps: No, you do not need to release a new version of the app after renewing the license. After the license renewal, the SDK will automatically detect the changes in the license file and update the validity period of the license. However, to avoid potential issues with automatic updates caused by network problems, we recommend that you manually download the new license file, replace the old license file in the current app version with the new license file, and then release a new version of your app.

* For web apps: This depends on how you configure the license when integrating the Player SDK for Web.

   * If you set the license URL: You **do not** need to do anything. The SDK automatically updates to the latest license version after you renew the license.

   * If you do not set the license URL: You **must** manually update the license file, and then **release a new version** of your app.


<span id="d22f265c"></span>
### After changing the PackageName, BundleID, wildcard domain, or WebOTT application identifier of an SDK application, do I need to replace the license?


* If the license has already been activated, the system regenerates the license based on the updated application information after the change. You need to replace the SDK license file or license URL. The original license remains valid for a period of time, and the new license keeps the same expiration time as the original one.

* If the license has expired, the system generates a new license based on the updated application information when you renew the license. You need to replace the SDK license file or license URL after the renewal is complete.


<span id="c8158ad3"></span>
### What else do I need to do after replacing the license file?

After you replace the license file, you **must** release a new version of the app. The impact on viewers is as follows:


* For Android or iOS apps: Viewers **must** update to the latest version of the app to continue using the service.

* For web apps: The browser automatically loads new resources on the next visit or page refresh, so viewers **do not** need to do anything.


<span id="ebbb6055"></span>
### How is the new validity period of a license calculated after upgrade or renewal?

The calculation method depends on the specific action:


* **Renewal**: The validity period is extended by **adding one year to the current license's original expiration date**. For example, if your license expires on May 10, 2026, and you renew the license for one year, the new expiration date will be May 10, 2027, regardless of when you perform the renewal.

* **Upgrade**: The new one\-year validity period starts from the date of the upgrade.


For more information, see [Calculating validity periods](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses#55ec08cd).

<span id="5e151cfe"></span>
### What happens if my license expires?

An expired license will cause a service interruption. To avoid any impact on your business, be sure to renew your license in a timely manner.

<span id="58f87925"></span>
### How to upgrade a basic license to a premium license?

Currently, you cannot upgrade a basic license to a premium license directly. You must create a new SDK application and bind a premium license to the application. For more information, see [Step 1: Create or bind an SDK application](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management#91608dc8).
