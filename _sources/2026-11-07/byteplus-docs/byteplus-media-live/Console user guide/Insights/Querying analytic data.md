The **Analytics** page displays statistics you use for analytical purposes, including:


* bandwidth

* traffic

* the number of pull\-stream requests

* the number of online viewers

* the HTTP status codes received.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can select a time granularity of 1 minute, 5 minutes, or 1 hour. The supported query span and range differ based on the time granularity selected.</div>


<div data-tips="true" data-tips-type="tip">You can query analytic data for deleted domain names.</div>


<span id="6a4f50ae"></span>
## Prerequisites

You must have actual push\-stream and pull\-stream data.

<span id="d14c37d3"></span>
## Procedure


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **Analytics** and select the type of data to query.

3. You can customize your query by filters, including:

   * domain name

   * time range

   * time granularity

   * streaming protocol

   * operator

   * regions that correspond to the edge servers' IP addresses

   * external IP addresses of client devices.


<span id="ddb24625"></span>
### Bandwidth statistics


1. Hover the mouse over the graph to view the upstream and downstream bandwidth data for a specific time.

2. You can display data with a line graph, a bar graph, or a list.

3. You can view or download your search results.
