MediaLive supports HLS standard encryption. This article introduces for you the implementation principle of using HLS in MediaLive and the pre\-operation for HLS encryption configuration.

<span id="6c918260"></span>
## Implementation Principle

The HLS encryption function of MediaLive uses the general encryption scheme of the HLS protocol. This scheme encrypts each TS (Transport Stream) by using the AES\-128 encryption algorithm and adds decryption information in the generated playlist file.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0bc33011b5894f68b09c66dad019c0ed~tplv-goo7wpa0wc-image.image) </span>

In this scheme, MediaLive itself integrates the KMS service to provide the functions of encryption key generation and regular rotation.

The encryption and decryption process is as follows:


1. The Player client initiates a pull\-streaming request for the encrypted live stream using the HLS pull\-streaming address.

2. After receiving the request, MediaLive encrypts the live stream with the key generated by itself and returns the M3U8 file with decryption information to the client. Among them, the `#EXT-X-KEY` tag contains the encryption information, and the URI is the address for requesting the key from the client's self\-built key management service. A partial content example of the M3U8 file is as follows.

   ```Bash
   #EXTM3U
   #EXT-X-VERSION:3
   #EXT-X-MEDIA-SEQUENCE:107326
   #EXT-X-TARGETDURATION:2
   #EXT-X-PROGRAM-DATE-TIME:2024-05-07T17:59:02.927+08:00
   #EXT-X-KEY:METHOD=AES-128,URI="https://example.kms.com/get_hls_enc_key?key_id=08e765a4da*****c4028755c3c",IV=0x00000000000000000000000000000000
   #EXTINF:2.000,
   HD_1080p_1715075942927_3070957834_107326.ts?ps=11&app=live&stream=HD_1080p&vhost=push.example.com
   ```
   

3. The client initiates a request to obtain the key to the self\-built key management service using the decryption information in the M3U8 file.

4. The self\-built key management service initiates a request to obtain the key to MediaLive.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The self\-built key management service needs to have the key caching ability, so that when there is another pull\-streaming request next time, the key can be directly returned for live streaming, without having to request and obtain from MediaLive every time.   </div>
   

5. The self\-built key management service returns the key returned by MediaLive to the pull\-streaming client, and the client decrypts and plays the M3U8 file through the obtained key.

## Prerequisites

<span id="73462349"></span>
### Self\-built key management service

If you want to use the HLS encryption function and realize the decryption and playback function, you need to build your own key management service. And it needs to have the following functions.


* Support for obtaining keys from MediaLive: The HLS encryption key is provided by the video live streaming, so your key management service needs to call the [GetHLSEncryptDataKey](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-gethlsencryptdatakey) API provided by the video live streaming to obtain the corresponding encryption key.

* Support for caching the obtained keys: In order to avoid all pull\-streaming behaviors obtaining keys from the video live streaming service, your key management service should have a caching function to realize the ability of the client to obtain keys from the key management service.


<span id="a889ced5"></span>
### Authentication (optional)

You can also use the remote authentication provided by MediaLive to authenticate the legality of the pull\-streaming request. If you want to use it, please [creating ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980) to contact technical support.

## Procedure


1. Log in to the [BytePlus MediaLive console](https://console.byteplus.com/live).

2. In the left\-side navigation pane, click **Settings** \> **Encryption**. On the **Encryption** page that appears, click the **HLS Standard** tab.

3. Click **Edit**, a dialog box will appear.

4. Fill in the Key acquisition address and Key update cycle.

5. Click **Confirm** to save the settings.
