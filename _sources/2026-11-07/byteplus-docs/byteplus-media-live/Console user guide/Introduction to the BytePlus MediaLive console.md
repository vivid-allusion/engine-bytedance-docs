This topic describes the login method and page layout of the BytePlus MediaLive console.

<span id="Logging into the console"></span>
## Logging into the console


1. Log in to the [BytePlus console](https://console.byteplus.com).

2. Click the hamburger icon in the upper\-left corner of the page and select **BytePlus MediaLive**. By default, the **Dashboard** page appears.


<span id="Learning about the console"></span>
## Learning about the console

The console consists of the following three sections: top navigation bar, left\-side navigation pane, and workspace.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/318da04f2ff04ef784435abbb6a15965~tplv-goo7wpa0wc-image.image) </span>


* 1: The top navigation bar, which allows you to switch between products, manage bills and accounts, and view notifications.

* 2: The left\-side navigation pane, which gives you access to each module page of BytePlus MediaLive.

* 3: The workspace, which allows you to use BytePlus MediaLive features.
