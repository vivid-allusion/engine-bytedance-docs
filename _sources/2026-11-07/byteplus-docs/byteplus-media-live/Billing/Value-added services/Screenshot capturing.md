You are charged both recording and screenshot\-capturing fees when using the screenshot\-capturing service. This page introduces how screenshot\-capturing fees are charged.

<span id="Pricing"></span>
## Pricing

Screenshot\-capturing fees are charged based on the number of screenshots taken, and the unit price is 0.0167 USD / 1,000 screenshots.

<span id="Billing cycle"></span>
## Billing cycle

Screenshot capturing supports both daily and monthly pay\-as\-you\-go.

<span id="Billing example"></span>
## Billing example

User A captured 11,100 screenshots on November 1st. The screenshot fees for that day were 0.0167 × (11,100 / 1,000) = 0.1854 USD.
