Video Quality Score (VQScore) will calculate the cost according to the duration of the video quality analysis task. This chapter introduces the pricing of the VQScore function.

<span id="42828345"></span>
## Pricing

The unit price is 0.002 USD/minute.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The VQScore function is free to use for the first 300 minutes each day.</div>


<span id="85a34f63"></span>
## Billing cycle

Subtitle supports both daily and monthly pay\-as\-you\-go.

<span id="1effae28"></span>
## Billing example

The customer uses the VQScore function to conduct video quality analysis on multiple streams. On November 1, all analysis tasks accumulated for 80 minutes. On November 2, all analysis tasks accumulated for 50 minutes. The picture quality evaluation function is free to use for the first 100 minutes each month. Then the bill for using the picture quality evaluation function is as follows:

• Picture quality evaluation cost on November 1 = 0.002 USD/minute x 80 minutes = 0 USD.

• Picture quality evaluation cost on November 2 = 0.002 USD/minute x (50 + 80 \- 100) minutes = 0.002 USD/minute x 30 minutes = 0.06 USD.

The fee will be deducted after the bill is generated the next day.
