## Observer

类型：`class`

用于在音视频采集和推流过程中接收各种事件回调。提供监听错误、警告、状态更新和设备切换等信息的能力，帮助实时监控推流器状态。

### 属性

|属性 |类型 |描述 |
|---|---|---|
|onError |(code: number, msg: string, extraInfo?: any) =\> void |错误通知回调。用于捕获推流或采集过程中发生的致命错误。可结合错误码用于故障排查和日志记录。 |
|onWarning |(msg: string) =\> void |警告通知回调，用于提示可能影响推流但非致命的异常情况。 |
|onCaptureFirstAudioFrame |() =\> void |完成第一帧音频采集的回调通知。用于在开始采集后确认音频源是否正常工作。 |
|onCaptureFirstVideoFrame |() =\> void |完成第一帧视频采集的回调通知。用于在开始采集后确认视频源是否正常工作。 |
|onPushStatusUpdate |(status: number, msg: string) =\> void |流状态更新回调，提供状态码和状态描述。可用于实时监控流状态（例如断连、重试中）并采取相应措施。 |
|onMicrophoneChanged |(changedDevice: MediaDeviceInfo) =\> void |切换麦克风设备的回调，返回已切换设备的信息。用于监控音频设备的状态变化，例如设备热插拔。 |
|onCameraChanged |(changedDevice: MediaDeviceInfo) =\> void |切换摄像头设备的回调，返回已切换设备的信息。适用于主播切换视频输入设备等场景，例如直播。 |
|onCaptureInterrupted |(streamId: string) =\> void |流中断回调，返回中断流的 ID。用于处理因设备异常导致流停止的情况。 |
|onPushStart |() =\> void |开始直播的回调通知。 |
|onPushStop |() =\> void |停止推流的回调通知。 |
|onStopCapture |(streamId: string) =\> void |停止采集的回调，返回已停止流的 ID。 |
