## RTMErrorCode

类型：`enum`

BytePlus MediaLive Broadcast SDK 中的错误码用于识别音视频采集和推流过程中的问题。通过这些错误码，可以快速定位问题并采取相应措施。

|属性 |值 |描述 |
|---|---|---|
|OPEN_CAMERA_FAILED |`1001` |打开摄像头失败。 |
|OPEN_MICROPHONE_FAILED |`1002` |打开麦克风失败。 |
|OPEN_SCREEN_FAILED |`1003` |启动屏幕共享失败。 |
|VIDEO_FILE_CAPTURE_FAILED |`1004` |加载视频文件失败。尝试将视频文件作为流加载时，如果文件路径不正确或格式不受支持，会发生此错误。 |
|AUDIO_FILE_CAPTURE_FAILED |`1005` |采集音频文件失败。尝试将音频文件作为流加载时，如果文件路径不正确或格式不受支持，会发生此错误。 |
|IMAGE_FILE_CAPTURE_FAILED |`1006` |采集图片文件失败。尝试将图片文件作为流加载时，如果文件路径不正确或格式不受支持，会发生此错误。 |
|VOLUME_DETECT_FAILED |`1008` |音量检测失败。当音频流不可用或检测逻辑异常时，会触发此错误。 |
|PUBLISH_FAILED |`2001` |推流失败。适用于推流地址不可达、网络不稳定或服务器返回错误的情况。 |
|UPDATE_PUBLISH_FAILED |`2002` |更新推流内容失败。在非混流场景中替换视频源失败时，会发生此错误。 |
|PUSH_CONNECT_FAILED |`2003` |流连接失败。如果网络连接失败或服务器地址不可达，将返回此错误。 |
