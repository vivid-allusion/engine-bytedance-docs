## ConfigOptions

推流 SDK 的初始化配置选项用于指定超时时间、重试次数、重试间隔时长以及推流模式。

<span id="feed78c8"></span>
### 属性


|属性 |类型 |接口行为 |
|---|---|---|
|timeout |number |请求推流地址的超时时间，单位为毫秒。 |
|retryCount |number |请求推流地址失败后的重试次数。 |
|retryDelay |number |请求推流地址重试的间隔时间，单位为毫秒（ms）。 |
|mode |[PushMode](https://docs.byteplus.com/en/docs/byteplus-media-live/ref#pushmode) |默认推流方式。<br><br><br>* `rtm`：使用 RTM 协议进行推流。 |


**类型**

```TypeScript
{
  timeout?: number;
  retryCount?: number;
  retryDelay?: number;
  mode?: PushMode;
}
```


<span id="e5e8d921"></span>
## PushMode

SDK 中使用的推流模式。


* `rtm`：使用 RTM 进行推流。


**类型**

```TypeScript
'rtm'
```

## IMixingViewConfig

类型：`interface`

合成画布的基本信息，如维度、帧率、背景色等。

<span id="60acc35d"></span>
### 属性


|属性 |类型 |接口行为 |
|---|---|---|
|width |number |合成画布的宽度。 |
|height |number |合成画布的高度。 |
|frameRate |number |合成画布的帧率，单位为 fps。建议将`frameRate`设置为 15 fps 或更高，以保证流畅性。 |
|backgroundColor |string |合成画布的背景色，默认为黑色。 |

## IVideoStreamLayoutParams

类型：`interface`

合成视频源的配置信息

<span id="31d5759c"></span>
### 属性


|属性 |类型 |接口行为 |
|---|---|---|
|x |number |布局的 x 坐标，单位为 px。 |
|y |number |布局的 y 坐标，单位为 px。 |
|width |number |布局的宽度，单位为 px。 |
|height |number |布局的高度，单位为 px。 |
|zOrder |number |布局层级越高，显示越靠上。 |
|keepRatio |boolean |是否保持视频长宽比。 |
|streamId |string |视频流的 ID。 |
|volume |number |当视频流包含音频内容时，对应音频音量范围为`[0,100]`。 |

<span id="2a6c8531"></span>

|属性 |类型 |接口行为 |
|---|---|---|
|streamId |string |音频流的 ID。 |
