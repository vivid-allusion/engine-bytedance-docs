为使观众能够在直播流期间回退并回放最近的直播内容，你可以通过拉流 SDK for Web（VePlayer）启用直播时移功能。本主题提供该功能的接入步骤，适用于讲座回放、会议复盘等场景，可提升整体观看体验。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议使用最新版本的拉流 SDK for Web。版本信息请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。历史版本请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="前提条件"></span>
## 前提条件

你已集成拉流 SDK for Web。更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="集成步骤"></span>
## 接入步骤


1. 在 BytePlus MediaLive 控制台添加直播时移配置，并生成相对时移回放地址。更多信息，请参见[管理直播时移配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-a-callback-task-zh-CN)。

2. 将上一步生成的地址传递给播放器。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">直播时移配置请参见<a href="https://docs.byteplus.com/en/byteplus-media-live/docs/1155423#timeshiftconfig">TimeShiftConfig</a>。<code>liveStartTime</code>必须设置为本地浏览器时间。   </div>
   

3. 导入直播时移插件。示例代码如下：

   
   <Tabs>
   <Tab zoneid="VHNLhRN9V8" title="通过 CDN">
   <TabTitle>通过 CDN</TabTitle>
   
   ```HTML
   <script src="https://sf-unpkg.bytepluscdn.com/obj/byteplusfe-sg/sdk/@byteplus/veplayer/2.11.2/umd/veplayer.plugin.time.shift.production.js">
   </script><link rel="stylesheet" href="https://sf-unpkg.bytepluscdn.com/obj/byteplusfe-sg/sdk/@byteplus/veplayer/2.11.2/umd/veplayer.plugin.time.shift.production.css">
   ```
   
   
   
   </Tab>
   <Tab zoneid="kgV64P6DkZ" title="通过 NPM">
   <TabTitle>通过 NPM</TabTitle>
   
   ```JavaScript
   import { timeShift } from '@byteplus/veplayer-plugin';
   import '@byteplus/veplayer-plugin/time-shift/style';
   ```
   
   
   
   </Tab>
   </Tabs>
   

4. 将直播时移插件作为配置项传入 VePlayer 对象。参数说明请参见[TimeShiftConfig](https://docs.byteplus.com/docs/byteplus-media-live/docs-1155423#timeshiftconfig)。

   
   <Tabs>
   <Tab zoneid="gkA4Jn9EkR" title="通过 CDN">
   <TabTitle>通过 CDN</TabTitle>
   
   ```JavaScript
   VePlayer.createLivePlayer({
     width: 640,
     height: 360,
     url: 'http://pull.example.com/live/test.m3u8?timeshift=300',
     timeShift: {
       liveStartTime: Date.now() / 1000 - 60,
     },
     plugins: [window.VePlayerTimeShift],
     logger: {
       appId: '5****8',
     },
   });
   ```
   
   
   
   </Tab>
   <Tab zoneid="l3G9rQKzfW" title="通过 NPM">
   <TabTitle>通过 NPM</TabTitle>
   
   ```JavaScript
   register([hlsjs]);
   
   createLivePlayer({
     width: 640,
     height: 360,
     url: 'http://pull.example.com/live/test.m3u8?timeshift=300',
     timeShift: {
       liveStartTime: Date.now() / 1000 - 60,
     },
     plugins: [timeShift],
     logger: {
       appId: '5****8',
     },
   });
   ```
   
   
   
   </Tab>
   </Tabs>
