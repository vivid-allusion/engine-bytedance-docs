为提升在不同网络类型下的回放性能，你可以通过拉流 SDK for Web（VePlayer）配置多条回源线路和多种转码档位。本文介绍如何实现该功能，支持观众手动切换或由播放器自动选择最佳转码档位或 CDN 回源线路。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议使用最新版本的拉流 SDK for Web。版本信息请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。历史版本请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="448c8a62"></span>
## 前提条件

你已集成拉流 SDK for Web。如需了解更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="98ee379c"></span>
## 配置示例

你可以通过`playlist`字段配置多条回源线路和/或多种转码档位。defaultSource 和 defaultDefinition 字段分别用于设置默认回源线路和默认转码档位。播放器创建成功后，你可以通过`switch`方法切换回源线路或转码档位。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">使用多线路或多转码档位时，不支持<code>url</code>配置。</div>


<span id="2836c6fb"></span>
### 配置多条回源线路

要配置多条回源线路，请在`playlist`数组中定义多个`source`项，并设置`defaultSource`。以下示例展示了具体实现方式。


<Tabs>
<Tab zoneid="VmZasGTahf" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({ 
  height: 360, 
  defaultSource: 'lineOne', 
  playlist: [ 
    { 
      name: 'lineOne', 
      text: { 'zh-cn': '线路一', en: 'Line 1' }, 
      definitions: ['https://pulldomain/appname/mystream_hd.m3u8'], 
    }, 
    { 
      name: 'lineTwo', 
      text: { 'zh-cn': '线路二', en: 'Line 2' }, 
      definitions: ['https://pulldomain/appname/mystream1_hd.m3u8'], 
    }, 
  ], 
  logger: { 
    appId: '5****8', 
  }, 
}).then(function (veplayer) { 
  // Switch to lineTwo
  veplayer.switch({ source: 'Line 2' }); 
});
```



</Tab>
<Tab zoneid="ABV2pGIuLM" title="通过 NPM">
<TabTitle>通过 NPM</TabTitle>

```JavaScript
import { createLivePlayer, register } from '@byteplus/veplayer';
import { hlsjs } from '@byteplus/veplayer-plugin';
import '@byteplus/veplayer/style'; 
register([hlsjs]);

      definitions: ['https://pulldomain/appname/mystream_hd.m3u8'],
    },
    {
      name: 'lineTwo',
      text: { 'zh-cn': '线路二', en: 'Line 2' },
      definitions: ['https://pulldomain/appname/mystream1_hd.m3u8'],
    },
  ],
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // Switch to lineTwo
  veplayer.switch({ source: 'Line 2' });
});
```

### 配置多种转码档位

要实现转码档位切换，请在单个回源线路下配置多个`definition`项。你可以通过`defaultDefinition`设置初始转码档位。


<Tabs>
<Tab zoneid="akwV18bNnK" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  height: 360,
  defaultDefinition: 'ld',
  playlist: [
    {
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_sd.m3u8',
          definition: 'sd',
          text: { en: 'sd', 'zh-cn': '高清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
  ],
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // Switch to high quality (HD)
  veplayer.switch({ definition: 'hd' });
});
```



</Tab>

### 配置多条回源线路和多种转码档位

要同时支持回源线路和转码档位切换，请定义多个回源线路，并在每条线路下配置多个转码档位。通过设置`defaultSource`和`defaultDefinition`指定默认项。


<Tabs>
<Tab zoneid="gCEdVp8Hf6" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  height: 360,
  defaultDefinition: 'ld',
  defaultSource: 'lineOne',
  playlist: [
    {
      name: 'lineOne',
      text: { 'zh-cn': '线路一', en: 'Line 1' },
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
    {
      name: 'lineTwo',
      text: { 'zh-cn': '线路二', en: 'Line 2' },
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream1_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream1_sd.m3u8',
          definition: 'sd',
          text: { en: 'sd', 'zh-cn': '高清' },
        },
        {
          url: 'https://pulldomain/appname/mystream1_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
  ],
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // Switch to lineTwo with HD definition
  veplayer.switch({ definition: 'hd', source: 'Line 2' });
});
```
