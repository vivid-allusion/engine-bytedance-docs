为识别问题并提升播放器的容错能力，你可以使用 Web 端拉流 SDK（VePlayer）监听回放错误。本主题提供代码示例，展示如何绑定`ERROR`事件，并在事件处理器中处理特定错误码。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议使用最新版本的 Web 端拉流 SDK。版本信息，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。历史版本，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="70cf27ae"></span>
## 前提条件

你已集成 Web 端拉流 SDK。更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="921af388"></span>
## 配置示例

创建直播播放器实例后，你可以通过绑定`ERROR`事件来监听回放错误。随后可在事件处理器中处理特定错误码。

完整错误码及其说明，请参见[Error Code Reference](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1158675)。


<Tabs>
<Tab zoneid="ZZKyWcQhfK" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://pulldomain/appname/mystream.m3u8',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  function errorHandler(error) {
    console.log('The error that occurs', error);
    console.log('The error code', error.errorCode);
    console.log('The error message', error.message);
  }
  // Listen for the ERROR event
  veplayer.on(VePlayer.live.Events.ERROR, errorHandler);
});        
```

