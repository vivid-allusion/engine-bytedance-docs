为收集回放数据以便故障排查和分析，你可以在 Web 端拉流 SDK（VePlayer）中启用回放日志记录与上报功能。该功能通过将回放相关信息发送至 BytePlus MediaLive 服务器进行诊断，有助于提升应用的稳定性和用户体验。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议你使用最新版本的 Web 端拉流 SDK。有关版本信息，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。如需历史版本，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="前提条件"></span>
## 前提条件

你已集成 Web 端拉流 SDK。如需了解更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="集成步骤"></span>
## 集成步骤


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live/main/sdk)，进入**应用管理**页面，找到你现有 Web 应用的**AppID**。

2. 将`appId`传递到播放器配置中的`logger`字段以启用日志记录。请参见下方代码示例。

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1"><code>appId</code>可唯一标识你的 Web 应用，且<strong>必须正确配置</strong>。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">自 2.5.1 版本起，未配置<code>appId</code>会触发控制台错误，且 SDK 会使用默认<code>appId</code>上报日志。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">强烈建议同时传递 userId 和 deviceId。这些标识符有助于更高效地定位回放问题。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">若未提供<code>userId</code>和<code>deviceId</code>，SDK 会根据用户浏览器生成随机值并本地存储。   </div>
   

   
   <Tabs>
   <Tab zoneid="BWMKltwE8X" title="通过 CDN">
   <TabTitle>通过 CDN</TabTitle>
   
   ```JavaScript
   VePlayer.createLivePlayer({
     width: 640,
     height: 360,
     url: 'https://pulldomain/appname/mystream.flv',
     logger: {
       appId: '2****4',
       userId: '1********6',
       deviceId: '3********7',
     },
   });
   ```
   
   
   
   </Tab>
   <Tab zoneid="fqP2OWOiMU" title="通过 NPM">
   <TabTitle>通过 NPM</TabTitle>
   
   ```JavaScript
   import { createLivePlayer, register } from '@byteplus/veplayer';
   import { flv } from '@byteplus/veplayer-plugin';
   import '@byteplus/veplayer/style'
   
   register([flv]);
   
   createLivePlayer({
     width: 640,
     height: 360,
     url: 'https://pulldomain/appname/mystream.flv',
     logger: {
       appId: '2****4',
       userId: '1********6',
       deviceId: '3********7',
     },
   });
   ```
   
   
   
   </Tab>
   </Tabs>
   

3. 如在直播流播放过程中遇到回放问题，请收集相关信息（如回放时间和观察到的症状），并[联系技术支持](https://console.byteplus.com/workorder/create)。
