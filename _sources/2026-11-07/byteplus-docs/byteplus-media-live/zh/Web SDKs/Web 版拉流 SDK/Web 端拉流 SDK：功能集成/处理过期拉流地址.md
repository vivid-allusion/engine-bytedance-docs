本文将指导你如何使用 Web 端拉流 SDK（VePlayer）在接入启用 URL 鉴权的直播系统时，检测并处理因拉流地址过期导致的回放失败，从而保障观众的流畅观看体验。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议你使用最新版本的 Web 端拉流 SDK。版本信息，参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。历史版本，参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="7af6b48c"></span>
## 应用场景

如果你的直播系统已开启[URL 鉴权](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-url-authentication)，生成的拉流地址通常会设置过期时间。当拉流地址过期（例如观众在页面停留时间过长时），可能会出现以下问题：


* 播放器无法拉取流，导致回放中断。

* 观众会看到错误提示，无法继续观看直播流。


为避免中断，你需要及时**获取新的拉流地址**并**切换播放器源**，可在当前地址过期前或检测到失败后立即执行。

<span id="实现流程"></span>
## 工作流


1. 初始化播放器时，使用有效的已鉴权拉流地址。

2. 配置错误监听器或定时器，主动检测地址过期。

3. 通过后端服务器调用[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023) API，获取新的有效拉流地址。

4. 通过`veplayer.switch()`方法切换流源。


<span id="前提条件"></span>
## 前提条件


* 你已集成 Web 端拉流 SDK。更多信息，参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

* 你的推流配置已开启[URL 鉴权](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-url-authentication)。

* 你的系统需支持调用[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023) API，动态生成新的已鉴权拉流地址。


<span id="配置示例"></span>
## 配置示例

你可以通过`veplayer.switch(newUrl)`方法动态更新拉流地址。以下示例展示了如何通过 CDN 与 NPM 两种集成方式实现该功能：


<Tabs>
<Tab zoneid="QgASEuKf0f" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://testpull.mycloud.com/live/mystream.m3u8?{authParams}',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // New pull stream address with refreshed authentication
  const newUrl =
    'https://testpull.mycloud.com/live/mystream.m3u8?{newAuthParams}';
  // Update the stream source
  veplayer.switch(newUrl);
});
```



</Tab>

```JavaScript
  },

  // New pull stream address with refreshed authentication
  const newUrl =

  // Update the stream source
  veplayer.switch(newUrl);
});
```
