自适应码率（ABR）是一种以观众为中心的视频分发技术，旨在无论网络条件如何波动，都能为观众提供无缝且高质量的回放体验。你需要预先配置多个具有不同编码格式、分辨率和码率的子流，播放器会根据观众的实时网络条件，自动选择最优流，以平衡流畅回放与转码档位质量。本主题介绍如何通过拉流 SDK for Web，为 HLS、RTM 和 FLV 流配置自适应码率功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">我们建议您使用最新版本的 Web 端拉流 SDK。有关版本信息，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。如需历史版本，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>

你已集成拉流 SDK for Web。更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

## 播放 HLS\-ABR 流

<span id="8c72c128"></span>
### Step 1: Add an ABR configuration


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏选择**功能配置**，并点击右侧的**码率自适应**标签页。

3. 在**域名空间**下拉列表中选择所需的域名空间，然后点击**添加配置**。

4. 在**基本信息**标签页，输入推流地址中的`AppName`，并在**协议类型**中选择**HLS\-ABR**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/52e6b604233348f1acedd0433ec2038e~tplv-goo7wpa0wc-image.image) </span>

5. 点击**添加子流**，为播放器可根据观众网络条件切换的每个转码档位配置子流。


其他设置请参见[管理自适应码率配置](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-CN)。

<span id="2694fc4d"></span>
### Step 2: Get the HLS\-ABR address for your ABR stream

你可以通过以下方式之一获取 HLS\-ABR 地址：


* **用于调试**：在**码率自适应**标签页，使用[地址生成器](https://console.byteplus.com/live/main/locationGenerate)获取**HLS\-ABR 地址**。更多信息，请参见[生成流地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-relay-zh-CN)。

* **用于生产环境**：调用[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023)或使用[服务端 SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-server-sdk)动态生成 HLS\-ABR 地址。


<span id="3083dd6e"></span>
### （可选）Step 3: Import and register plugins when using the NPM method

如果你通过 NPM 方式引入依赖，则必须导入并注册`abr`和`hlsjs`插件，以确保自适应码率功能和 HLS 回放可用。

示例代码如下。

```JavaScript
import { hlsjs, abr } from '@byteplus/veplayer-plugin';
register([hlsjs, abr]);
```


<span id="396240fa"></span>
### Step 4: Configure ABR

创建播放器时，你可以配置自适应码率功能，并监听转码档位切换事件。


* **配置自适应码率功能**：拉流 SDK 默认已开启自适应码率功能。你只需提供 HLS\-ABR 地址即可。播放器会请求该地址并获取主播放列表，该列表指引所有可用子流（如 1080p 和 720p）。播放器随后会持续监控观众的网络条件，并在这些子流之间自动切换。当网络条件较差时，播放器会选择较低码率的流以减少缓冲，并在网络条件改善后无缝切换回高码率流，从而确保最佳且不中断的观看体验。

* **监听转码档位切换事件**：如需在切换转码档位时实现自定义逻辑（如更新 UI 或上报切换数据），可监听以下事件：

   * `ABR_SWITCH_START`：开始切换转码档位。

   * `ABR_SWITCH_SUCCESS`：转码档位切换成功。

   * `ABR_SWITCH_FAILED`：转码档位切换失败。


示例代码如下。

    width: 640,

## 播放 RTM\-ABR 流

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如需播放 RTM\-ABR 流，请确保已集成点播 SDK 版本 2.12.0 或更高版本。</div>


<span id="ef109318"></span>
### Step 1: Add an ABR configuration


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏选择**功能配置**，并点击右侧的**码率自适应**标签页。

3. 在**域名空间**下拉列表中选择所需的域名空间，然后点击**添加配置**。

4. 在**基本信息**标签页，输入推流地址中的`AppName`，并选择**RTM\-ABR**作为**协议类型**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/987feb246fd04cb0acf9d2dbe8bcda88~tplv-goo7wpa0wc-image.image) </span>

其他设置请参见[管理自适应码率配置](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-CN)。

<span id="cd6f509c"></span>
### Step 2: 获取 RTM\-ABR 拉流地址

可通过以下方式之一获取 RTM\-ABR 拉流地址。


* **用于调试**：使用[地址生成器](https://console.byteplus.com/live/main/locationGenerate)，选择启动质量等级（后缀），在**自适应码率**标签页获取**RTM Web SDK 回放地址**。更多信息请参见[生成流地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-address-generator)。

* **用于生产环境**：调用[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023)或使用[服务端 SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-server-sdk)动态生成 RTM\-ABR 拉流地址。不同后缀对应不同的启动质量等级。选择一个地址作为播放地址。确保`协议`的值为`udp_websdk`。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">如无法获取 RTM\-ABR 拉流地址，请联系<a href="https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980">技术支持</a>。</div>


* <div data-tips="true" data-tips-type="warning">RTM\-ABR 拉流地址支持自动转码，包括 B帧移除和 AAC 到 Opus 音频转换。了解更多信息，请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses-zh-CN">生成直播流地址</a>。</div>

### Step 4: 配置 ABR

创建播放器时，可以配置 ABR 功能并监听质量等级切换事件。


* **配置 ABR 功能**：SDK 默认已开启 ABR 功能。只需提供一个 RTM\-ABR 拉流地址。RTM\-ABR 拉流地址中的后缀决定启动质量等级。回放过程中，MediaLive 会根据观众网络条件自动切换质量等级。当网络条件较差时，MediaLive 会切换到低码率流以减少缓冲，并在网络条件改善时无缝切回高码率流，确保观众获得最佳且不中断的观看体验。

* **监听质量等级切换事件**：如需在切换质量等级时实现自定义逻辑（如更新 UI 或上报切换数据），可监听以下事件：

   * `ABR_SWITCH_START`：开始切换质量等级。

   * `ABR_SWITCH_SUCCESS`：质量等级切换成功。

   * `ABR_SWITCH_FAILED`：质量等级切换失败。


示例代码如下。

## 播放 FLV 流

<span id="f93c3f0f"></span>
### Step 1: 添加 ABR 配置


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏选择**功能配置**，并点击右侧的**自适应码率**标签页。

3. 在**域名空间**下拉列表中选择所需的域名空间，然后点击**添加配置**。

4. 在**基本信息**标签页，输入推流地址中的`AppName`。

5. 点击**添加子流**，为播放器可根据观众网络条件切换的每个质量等级配置子流。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a205a874210a4d3e9b8fc9500735ef21~tplv-goo7wpa0wc-image.image) </span>


其他设置请参见[管理自适应码率配置](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-CN)。

<span id="ef0650ed"></span>
### Step 2: 获取不同质量等级的 FLV 拉流地址

使用[地址生成器](https://console.byteplus.com/live/main/locationGenerate)，在右侧生成并获取指定质量等级的 FLV 拉流地址。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/795e50db176d41db8d3a03069538a2c4~tplv-goo7wpa0wc-image.image) </span>


* **地址类型**：选择**拉流地址**。

* **域名**：在添加 ABR 配置时，选择用于拉流的域名空间中的拉流域名。

* **AppName** 和 **StreamName**：请根据你的推流地址确定这些字段的取值。若你的推流地址为 `rtmp:// push.example.com/live/test?authinfo`：

   * **AppName**：`AppName` 即地址中域名后的部分。此时应填写 `live`。

   * **StreamName**：首先从地址中识别 **base stream name**，即 `test`。然后针对每个转码档位，在该基础名称后追加对应的子流后缀。例如：

      * 对于 UHD 转码档位，填写 `test_uhd`

      * 对于 HD 转码档位，填写 `test_hd`

   以此方式记录每个转码档位的 FLV 拉流地址。


**示例**

下表列出了不同转码档位的 FLV 拉流地址及对应码率示例。


|清晰度等级 |FLV 拉流地址 |码率（kbps） |
|---|---|---|
|超高清（UHD） |https://pull.example.com/live/123456_uhd.flv |3200 |
|高清（HD） |https://pull.example.com/live/123456_hd.flv |2048 |
|标清（SD） |https://pull.example.com/live/123456_sd.flv |1638 |
|低清（LD） |https://pull.example.com/live/123456_ld.flv |1024 |

### （可选）步骤 3：使用 NPM 方式时导入并注册插件

若采用 NPM 方式导入依赖，需导入并注册 `flv` 和 `abr` 插件，以确保低延迟 FLV 和 ABR 功能可用。示例代码如下。

```JavaScript
import { flv, abr } from '@byteplus/veplayer-plugin'
register([flv, abr]);
```


由于部分移动端浏览器（如 iOS 16 之前的 Safari）无法播放 FLV 流，为确保直播流在这些设备上仍能正常播放，SDK 提供了 HLS 兜底方案。启用该方案后，播放器检测到当前浏览器不支持播放 FLV 流时，会自动切换至备用 HLS 流进行回放。为确保兜底方案正常工作，若通过 NPM 导入依赖，请务必同时导入并注册 `hlsjs` 插件。示例代码如下。

```JavaScript
import { flv, hlsjs, abr } from '@byteplus/veplayer-plugin';
register([flv, hlsjs, abr]);
```


<span id="fb64008c"></span>
### 步骤 4：在 SDK 中配置 ABR 并启用低延迟 FLV

创建播放器时，可通过以下配置为观众提供低延迟、流畅且全平台兼容的直播流体验：


* **配置 ABR 功能**：SDK 默认已开启 ABR 功能。只需提供包含多个码率及其对应 FLV 拉流地址的列表。播放器会根据观众的网络类型，在直播流过程中自动切换转码档位，确保回放流畅并提供良好的视频质量。

* **监听转码档位切换事件**：如需在切换转码档位时实现自定义逻辑（如更新 UI 或上报切换数据），可监听以下事件：

   * `ABR_SWITCH_START`：开始切换转码档位。

   * `ABR_SWITCH_SUCCESS`：转码档位切换成功。

   * `ABR_SWITCH_FAILED`：转码档位切换失败。

* **移动端 HLS 兜底方案**：部分移动端浏览器（如 iOS 16 之前的 Safari）不支持播放 FLV 流。为确保直播流在这些设备上能正常播放，可在配置 FLV 拉流地址时提供备用 HLS 拉流地址。播放器检测到当前浏览器不支持播放 FLV 流时，会自动切换至 HLS 流进行回放。


示例代码如下。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">为确保 ABR 功能正常工作，请确保您在代码中为每个清晰度等级设置的码率与控制台 ABR 配置中的码率一致。</div>


<div data-tips="true" data-tips-type="warning"><strong>请特别注意单位换算：</strong></div>



* <div data-tips="true" data-tips-type="warning"><strong>控制台中的码率单位：</strong> <code>kbps</code></div>


* <div data-tips="true" data-tips-type="warning"><strong>代码中的码率单位：</strong> <code>bps</code></div>



<div data-tips="true" data-tips-type="warning">因此，代码中设置的码率值必须是控制台中值的<strong>1000</strong>倍。</div>


<div data-tips="true" data-tips-type="warning">例如，若控制台设置为<code>3200</code> kbps，则代码中应传入<code>3200000</code>。</div>

```JavaScript
VePlayer.createLivePlayer({
    width: 640,
    height: 360,
    playlist: [
      {
        definitions: [
          // FLV pull stream address for the initial playback quality level.
          'https://pull.example.com/live/123456_uhd.flv',
          // 用于回退回放的 HLS 拉流地址，可通过控制台地址生成器生成。
          'https://pull.example.com/live/123456_uhd.m3u8',
        ],
      },
    ],
    flv: {
      abr: {
        // Bitrate for the initial playback quality level.单位为 bps。
        bitrate: 3200000,
        // 各清晰度等级的码率和 FLV 拉流地址。码率单位为 bps。
        urls: {
          3200000: 'https://pull.example.com/live/123456_uhd.flv',
          2048000: 'https://pull.example.com/live/123456_hd.flv',
          1638000: 'https://pull.example.com/live/123456_sd.flv',
          1024000: 'https://pull.example.com/live/123456_ld.flv',
         }
     }
  },
    fallback: {
      // 优先尝试播放低延迟 FLV 流。当播放器检测到当前浏览器无法播放低延迟FLV 流时，将自动回退为 HLS 流进行回放。
      fallbackOrder: ['ll-flv', 'hls'],
    }
}).then(function (veplayer) {
    // Listen for quality level switching events.
    veplayer.on(VePlayer.live.Events.ABR_SWITCH_START, function (data) {
      console.log('ABR_SWITCH_START', data.bitrate);
    });

    veplayer.on(VePlayer.live.Events.ABR_SWITCH_SUCCESS, function (data) {
      console.log('ABR_SWITCH_SUCCESS', data.bitrate);
    });

    veplayer.on(VePlayer.live.Events.ABR_SWITCH_FAILED, function (data) {
      console.log('ABR_SWITCH_FAILED', data.bitrate);
    });
})
```
