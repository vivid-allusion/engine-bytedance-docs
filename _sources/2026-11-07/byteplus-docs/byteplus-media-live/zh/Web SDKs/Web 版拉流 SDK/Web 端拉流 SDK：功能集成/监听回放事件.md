为实现播放器状态监控、日志上报和动态 UI 更新等功能，可以使用 Web 端拉流 SDK（VePlayer）监听回放相关事件。本主题提供代码示例，展示如何使用 `on`、`once` 和 `off` 方法高效添加和移除事件监听器。

## 前提条件

你已集成 Web 端拉流 SDK。更多信息，请参见 [集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="89738846"></span>
## 配置示例

Web 端拉流 SDK 支持多种回放事件，例如：


* `PLAY` – 回放开始

* `ERROR` – 回放发生错误

* `PAUSE` – 回放暂停


这些事件可用于触发 UI 更新或处理回放异常。完整支持事件列表，请参见 [事件参考](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1158676)。

成功创建直播播放器实例后，可使用 `on`、`once` 和 `off` 方法添加或移除事件监听器。


<Tabs>
<Tab zoneid="SbX2ReM6iq" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://pulldomain/appname/mystream.m3u8',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  function eventHandler(data) {
    console.log('Event callback data:', data);
  }

  // Add an event listener
  veplayer.on(VePlayer.live.Events.PLAY, eventHandler);

  // Add a one-time event listener
  veplayer.once(VePlayer.live.Events.PLAY, eventHandler);

  // Remove a specific event listener
  veplayer.off(VePlayer.live.Events.PLAY, eventHandler);

  // Remove all event listeners
  veplayer.offAll();
});
```
