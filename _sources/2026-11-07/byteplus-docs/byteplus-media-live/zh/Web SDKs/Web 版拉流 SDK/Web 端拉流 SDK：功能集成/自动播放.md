本文介绍如何使用 Web 端拉流 SDK（VePlayer）在页面加载后实现视频自动播放。内容涵盖了主流浏览器和 WebView 环境的适配策略、配置方法以及回放失败的处理方式，帮助你在多平台上实现更稳定的自动播放体验。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建议你使用最新版本的 Web 端拉流 SDK。版本信息请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-CN">Web 拉流 SDK：版本说明</a>。历史版本请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-CN">Web 端拉流 SDK：1.x 版本</a>。</div>


<span id="f443dd0b"></span>
## 功能概述

自动播放允许在页面加载时无需用户交互即可自动开始视频回放。自动播放受浏览器策略限制，是否允许自动播放取决于当前环境。允许自动播放的常见条件包括静音回放和用户交互。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">受上述限制影响，部分设备或浏览器可能会阻止自动播放。建议在应用设计时关注用户体验，避免强制自动播放。</div>


<span id="前提条件"></span>
## 前提条件

你已集成 Web 端拉流 SDK。更多信息，请参见[集成 Web 端拉流 SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN)。

<span id="配置自动播放"></span>
## 自动播放配置

VePlayer 通过`autoplay`配置项支持自动播放。详细配置项请参见[LiveVePlayerOptions](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1155423)。自动播放是否成功取决于当前环境下浏览器的自动播放策略。

<span id="浏览器环境"></span>
### 浏览器环境下

在标准 Web 浏览器中，满足以下**任一**条件时，自动播放会成功：


|条件分类 |接口行为 |
|---|---|
|静音回放 |视频为静音（`muted: true`）或音量设置为 0，这是实现自动播放最可靠的方式。 |
|用户交互 |用户与页面发生交互（点击、滚动、键盘输入等）后允许自动播放。 |
|站点白名单 |浏览器可能会根据用户的站点使用历史授予自动播放权限。 |
|用户设置 |部分浏览器允许用户为特定站点手动授予自动播放权限。 |
|权限委托 |如果视频嵌入在`<iframe>`中，且顶层页面已获得自动播放权限，则该权限可委托给 iframe。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">更多详情请参见<a href="https://www.chromium.org/audio-video/autoplay/">Google Chrome</a>和<a href="https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/">WebKit</a>的自动播放策略。</div>


<span id="WebView 环境"></span>
### WebView 环境下

在 WebView 等嵌入式浏览器中，自动播放可能需要额外配置。

<span id="Android WebView"></span>
#### Android WebView

默认情况下，Android WebView**阻止非静音自动播放**。建议按如下方式配置 VePlayer 实现**静音自动播放**：

```javascript
VePlayer.createLivePlayer({
    autoplay: { muted: true }
}).then(function(veplayer) {
    // Player instance
});
```


如需允许非静音自动播放（不推荐，除非经过充分评估），请将[setMediaPlaybackRequiresUserGesture](https://developer.android.com/reference/android/webkit/WebSettings.html#setMediaPlaybackRequiresUserGesture(boolean))设置为`false`：

```java
myWebView.getSettings().setMediaPlaybackRequiresUserGesture(false);
```


<span id="iOS WebView"></span>
#### iOS WebView

iOS WebView 也默认阻止带声音的视频自动播放。请按如下方式配置静音自动播放：

```javascript
VePlayer.createLivePlayer({
    autoplay: { muted: true }
}).then(function(veplayer) {
    // Player instance
});
```


如需允许非静音自动播放，请将[mediaTypesRequiringUserActionForPlayback](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/1851524-mediatypesrequiringuseractionfor)设置为`NO`：

```objectivec
[self.webView mediaTypesRequiringUserActionForPlayback:NO];
```


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">当 iOS 设备处于低电量模式时，自动播放可能会被阻止。</div>


<span id="微信内置浏览器环境"></span>
### 检测自动播放是否成功

由于浏览器策略较为复杂，建议通过编程方式验证自动播放是否成功。

<span id="方法一：监听 play() 方法的 Promise 返回"></span>
### 方法一：使用`play()` Promise

`veplayer.play()`方法会返回一个 Promise 对象。


* `Promise 已解决`：回放启动成功。

* `Promise 被拒绝（NotAllowedError）`：自动播放被浏览器策略阻止。


示例：

```javascript
let startPlayPromise = veplayer.play();

if (startPlayPromise !== undefined) {
  startPlayPromise
    .catch(error => {
      if (error.name === "NotAllowedError") {
        // Autoplay was blocked by the browser
        // You can retry playback with muted audio, or prompt the user to click a play button
      } else {
        // Other playback-related errors occurred
      }
    })
    .then(() => {
      // Playback started successfully
      // Continue with any post-playback logic here
    });
}
```


<span id="方法二：监听 AUTOPLAY_PREVENTED 事件"></span>
### 方法二：监听`AUTOPLAY_PREVENTED`事件

当自动播放被浏览器阻止时，Web 端拉流 SDK 会触发`AUTOPLAY_PREVENTED`事件。你可以通过处理该事件实现回退逻辑。

示例：

```javascript
VePlayer.createLivePlayer({
  autoplay: { muted: false }
}).then(function (veplayer) {
  // Listen for autoplay prevention event
  veplayer.on(VePlayer.live.Events.AUTOPLAY_PREVENTED, () => {
    console.log('Autoplay was blocked by the browser');
    // Add fallback logic here, such as prompting the user to tap a play button
  });
});
```
