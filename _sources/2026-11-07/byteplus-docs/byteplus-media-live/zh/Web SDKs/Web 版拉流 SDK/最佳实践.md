为提升移动设备上的视频回放体验，可以实施若干关键优化措施。本主题提供提升兼容性、减少实时流媒体延迟，以及通过移除特定 UI 元素和个性化错误消息来自定义播放器样式的最佳实践。

<span id="3f8f7725"></span>
## RTM 回放延迟优化

为提升在网络类型不稳定情况下的回放流畅度，可以调整缓冲延迟设置。以下是两种常见集成方式：


<Tabs>
<Tab zoneid="bUUrOWVrIw" title="通过 CDN">
<TabTitle>通过 CDN</TabTitle>

创建播放器实例时，在 RTM 模块中配置 `delayHint` 参数。代码示例：

```JavaScript
VePlayer.createLivePlayer({
    url: 'XXXX.sdp',
    rtm: {
        // 设置缓冲延迟为 1 秒
        delayHint: 1
    }
}) 
```



</Tab>
<Tab zoneid="fv1NXojvRa" title="通过 NPM">
<TabTitle>通过 NPM</TabTitle>

创建播放器实例时，在 RTM 模块中配置 `delayHint` 参数。代码示例：

```JavaScript
import { createLivePlayer, register } from '@byteplus/veplayer';
import { rtm } from '@byteplus/veplayer-plugin';
import '@byteplus/veplayer/style'

register([rtm]);

createLivePlayer({
    url: 'XXXX.sdp',
    rtm: {
        // 设置缓冲延迟为 1 秒
        delayHint: 1
    }
})
```



</Tab>
</Tabs>

## 移动设备样式配置

若需要移除移动设备上的默认 H5 样式，可按以下步骤操作。

<span id="43301374"></span>
### 移除部分图标

可通过配置 `ignores` 选项移除不需要的插件图标。这样可以自定义播放器界面上显示的图标，例如 `start`、`enter` 和 `unmute` 按钮。

<span id="6a1820b4"></span>
### 移除 H5 阴影覆盖效果

默认情况下，H5 播放器可能会在视频区域的顶部和底部显示阴影覆盖效果，如下图所示。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/696ee2f4c3974c7d8ea29ac0ec5f90df~tplv-goo7wpa0wc-image.image) </span>

如需移除该覆盖效果，请使用以下代码。

```JavaScript
mobile: {
    gradient: 'none',
}
```


<span id="24e3a121"></span>
### 自定义错误消息

若使用默认错误显示插件，有两种方式可自定义错误消息。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/58d79030e8fc4e8682a6a48b463c1683~tplv-goo7wpa0wc-image.image) </span>


<Tabs>
<Tab zoneid="vF9Q5SEGZ3" title="覆盖所有错误消息">
<TabTitle>覆盖所有错误消息</TabTitle>

如需用单一自定义消息覆盖所有错误消息，请在 `error` 部分配置 `errorTipsText` 参数，如下所示：

```JavaScript
error: {
  errorTipsText: { 'en': 'Custom Error Info' }
}
```



</Tab>
<Tab zoneid="VBpKOsCbGQ" title="为特定错误自定义消息">
<TabTitle>为特定错误自定义消息</TabTitle>

如需为特定错误类型定义自定义消息，请在 `i18n` 部分进行配置：

```JavaScript
i18n: {
          texts:{
            'en': {
              MEDIA_ERR_ABORTED: 'Custom Error Info', // 对应错误码 5101 或 1
              MEDIA_ERR_NETWORK:  'Custom Error Info', // 对应错误码 5102 或 2
              MEDIA_ERR_DECODE: 'Custom Error Info', // 对应错误码 5103 或 3
              MEDIA_ERR_SRC_NOT_SUPPORTED: 'Custom Error Info', // 对应错误码 5104 或 4
              NETWORK: 'Custom Error Info', // 对应错误码 2100
              NETWORK_TIMEOUT: 'Custom Error Info', //  对应错误码 2101
              NETWORK_FORBIDDEN: 'Custom Error Info', //  对应错误码 2103
              NETWORK_NOTFOUND: 'Custom Error Info', //  对应错误码 2104
            }
          }
        },
```



</Tab>
</Tabs>
