为提升您的基于 Web 的直播播放器，本主题提供了使用 BytePlus MediaLive 拉流 SDK for Web 实现关键功能的代码示例和操作说明。您将学习如何拉取低延迟 RTM 流、让观众通过直播时移回放内容，以及配置日志上传以便于故障排查。

## 拉取 RTM 流

您可以通过拉流 SDK 使用 Real Time Media（RTM）协议拉取流。如需详细了解 RTM，请参阅[Real Time Media 简介](https://docs.byteplus.com/docs/byteplus-media-live/docs-introduction-to-real-time-media)。


1. 使用地址生成器生成 RTM 拉流地址。详细的地址生成操作，请参阅[直播流地址生成](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses)。

2. 创建`VePlayer`实例，并将拉流地址设置为上一步获取的地址。


```JavaScript
// Check if the player supports pulling an RTM stream
const isRTMSupported = VePlayer.isRTMSupported();
// Check if H.264 is supported (H.264 is supported since v1.6.3)
const isRTMSupportH264 = await VePlayer.isRTMSupportCodec('h264');

const playerSdk = new VePlayer({
    id: 'mse',
    url: isRTMSupported && isRTMSupportH264 ? 'https://testpull.mycloud.com/live/mystream.sdp' : 'https://testpull.mycloud.com/live/mystream.m3u8',
    isLive: true,
    width: 600,
    height: 400,
    rtm: {
        // Backup address and protocol.当播放器拉取 RTM 流失败时，将使用以下地址。
        backupURL: 'https://testpull.mycloud.com/live/mystream.m3u8',
        backupStreamType: 'hls'
    }
});
```


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您可以通过将<code>backupStreamType</code>分别设置为<code>flv</code>和<code>hls</code>，将 FLV 或 HLS 流作为备流。</div>

## 直播时移

直播时移功能允许您的观众回放任何已直播的内容。如需播放时移内容，请执行以下操作：


1. 在 BytePlus MediaLive 控制台配置直播时移任务。详细配置说明请参阅[直播时移任务配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-time-shifting)。

2. 准备包含您在上一步配置的域名和 appName 的 M3U8 拉流地址。如何获取 M3U8 格式的拉流地址，请参阅[直播流地址生成](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses)。

3. 将以下代码添加到您的项目中：

   ```JavaScript
   const playerSdk = new VePlayer({
      id: 'mse',
      isLive: true,
      // The pull stream address
      url: "//testpull.mycloud.com/live/mystream.m3u8", 
      width: 600, 
      height: 400,
      // Time-shifting configurations
      TimeShiftPlugin: { 
        // The time the live stream session started
        livingStartTime: Date.now() / 1000 - 60, 
        // The maximum amount of time shifting available during playback, in seconds.
        maxMoveTime: 60
      }, 
      plugins: [VePlayer.TimeShiftPlugin], 
    });  
   ```
   


有关直播时移参数的接口行为说明，请参阅[timeShiftPlugin](https://docs.byteplus.com/docs/byteplus-media-live/docs-api-reference#2f07a993)。

## 日志上传

为便于故障排查，您可以在[liveLogger](https://docs.byteplus.com/docs/byteplus-media-live/docs-api-reference#liveLogger)中定义`appId`以启用日志上传。播放器发生错误后，您可以联系[技术支持](https://console.byteplus.com/workorder/create)，技术支持可通过应用 ID 定位问题。

我们强烈建议您将`userId`和`deviceId`设置为可唯一标识用户和设备的值。技术支持可能需要这些信息以定位问题。如果未定义`userId`和`deviceId`，SDK 会自动生成随机的用户 ID 和设备 ID，并存储在浏览器缓存中。

```JavaScript
const playerSdk = new VePlayer({
    id:'mse',
    isLive:true,
    width:600,
    height:400,
    url:'//pulldomain/appname/mainstream.flv',
    liveLogger: {
        appId: '2****4',
        userId: '1********6',
        deviceId: '3********7'
    }
});
```
