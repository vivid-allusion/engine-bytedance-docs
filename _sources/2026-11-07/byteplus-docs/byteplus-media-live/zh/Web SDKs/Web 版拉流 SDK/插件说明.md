VePlayer 通过灵活的插件系统实现所有功能，从简单的功能按钮到复杂的回放逻辑。本主题介绍如何管理这些插件，以便自定义您的播放器。您将学习如何注册新的自定义插件，禁用或配置内置插件，甚至替换默认图标和调整 UI 布局。

<span id="60b4c346"></span>
## 自定义插件

<span id="ff3164db"></span>
### 插件注册

VePlayer 支持两种插件注册方式：初始化时注册和初始化后注册。

<span id="732e560d"></span>
#### **方法一：初始化时注册**

在初始化 VePlayer 实例时，您可以直接传递插件名称来注册插件（内置插件无需注册）。示例代码如下：

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://testpull.mycloud.com/live/mystream.m3u8',
  plugins: [window.VePlayerTimeShift],
  logger: {
    appId: '5****8',
  },
});
```


<span id="e7b00151"></span>
#### **方法二：初始化后注册**

初始化 VePlayer 实例后，您可以调用 `registerPlugin` 方法并传递插件名称来注册插件（内置插件无需注册）。示例代码如下：

```JavaScript
VePlayer.createLivePlayer({
  //...
}).then(function(veplayer){
        veplayer.registerPlugin(window.VePlayerTimeShift)              
})
```


<span id="2d9e9af8"></span>
### 插件禁用

VePlayer 提供多个内置功能插件。若需禁用某个特定的内置插件，可以使用以下方法。


* 对于大多数插件，您可以在 VePlayer 配置中将插件名称（不区分大小写）传递给 `ignores` 属性以禁用该插件。例如，禁用画中画插件：

   ```JavaScript
   ignores: ['pip']
   ```
   

* 对于某些插件，也可以通过配置其专属选项来禁用。更多详情请参阅 [带 UI 的内置插件](https://docs.byteplus.com/docs/byteplus-media-live/docs-d8idjfeza4-zh-CN#f3cebefe) 的文档。


<span id="382a06f9"></span>
### 插件配置

VePlayer 支持通过传递各插件名称来配置其专属逻辑。例如，配置 error 插件及其相关参数时，可以按如下方式操作：

```JavaScript
error: {
   errorTipsText: 'error message', // error message
   showRefresh: true, // whether to refresh the button
}
```


<span id="87497923"></span>
### 插件图标替换

您可以通过配置来替换内置插件的按钮图标。支持图标替换的插件列表可在 [内置插件图标](https://docs.byteplus.com/docs/byteplus-media-live/docs-d8idjfeza4-zh-CN#2422295c) 配置中查看。例如，若需将播放/暂停按钮的图标替换为自定义图标，只需在配置中传递所需替换图片的 URL 或 DOM 节点即可。示例代码如下。

```JavaScript
import MyPlayIcon from '../icons/my-play-icon.svg';
import MyPauseIcon from '../icons/my-pause-icon.svg';

VePlayer.createLivePlayer({
  icons: {
    play: <img src={MyPlayIcon}>,
    pause: <img src={MyPauseIcon}>
  }
})
```

#### **挂载位置配置**

`position` 选项用于指定插件在用户界面中的位置，即插件 UI 元素挂载到具体 DOM 节点的位置。VePlayer 定义了以下两种挂载位置。


* **Default layout:**  插件的 UI 元素按照预设布局进行排列和显示。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f4cf056e7c7044cd82c0a102ca87b828~tplv-goo7wpa0wc-image.image) </span>

* **Flex layout:**  一种灵活布局方式，可根据屏幕尺寸和需求自动调整 UI 元素的排列。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/809477e999874cbbbd4bad4bf9b3c7f3~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果未指定 <code>position</code> 参数或 <code>root</code> 参数，插件的 UI 元素默认挂载在根节点下。这意味着插件会出现在默认位置。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">当播放器失去焦点时，位于 <code>ROOT_TOP</code>、<code>ROOT_RIGHT</code> 和 <code>ROOT_LEFT</code> 的插件会自动隐藏。这样可以提升用户体验，不遮挡视频内容。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">对于移动设备的小屏幕，在使用 <code>flex</code> 布局时，居中位置的插件会适配屏幕尺寸。常用于显示进度条等功能。确保插件功能在有限屏幕空间内正常显示。   </div>
   


<span id="cc61c91f"></span>
#### 布局模式配置

controls 插件的 `mode` 选项用于指定控制栏的布局模式。以下是三种布局模式的视觉展示：


* Normal: 控制栏中的插件按照配置顺序以普通布局模式显示。

* Flex: 灵活布局模式允许对控制栏插件的位置和大小进行灵活调整，使其适应不同屏幕尺寸和布局需求。

* 底部：底部布局模式将控制栏放置在播放器底部，适用于移动设备显示，提供更好的触控体验。


<span id="5e3f2a1d"></span>
#### **配置 index**

`index` 选项是一个数字，用于决定插件在其父节点中的显示顺序。数字越小，插件优先级越高，会在父节点序列中更早显示。当多个插件具有相同的 `index` 值时，其插入顺序将根据注册顺序决定。通过调整插件的 `index` 值，可以优化显示顺序以满足特定需求和布局要求。
