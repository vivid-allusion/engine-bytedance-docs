要在您的在线流中实施 DRM 加密，您必须首先从 Intertrust 获取 DRM 密钥。本主题提供从 Intertrust 控制台获取 API 密钥的分步说明，之后您需要将该密钥上传至 BytePlus MediaLive 控制台。

<span id="9a84e96d"></span>
## 前提条件

一个 [Intertrust](https://portal.expressplay.com/) 账户。您必须为该账户激活所需的服务。使用这些服务会产生 Intertrust 的费用。如有任何疑问，您可以直接联系 Intertrust，或联系您的 [BytePlus sales representative](https://www.byteplus.com/en/contact)。

<span id="c77d3691"></span>
## 操作流程


1. 登录 [Intertrust](https://portal.expressplay.com/) 控制台。

2. 在左侧导航栏，点击 **Manage Account**。

3. 点击 **Subscriptions**。

4. 启用您需要的 DRM 系统。

5. 在左侧导航栏，点击 **Api Keys / Cust.Auth.** 。

6. 点击 \*\*Add Api Key / Cust.Auth.\*\*按钮以创建 API 密钥。请将其本地保存，因为之后无法再次获取。
