为防止付费活动和专属在线流等高价值内容被未经授权地重新分发，业界标准的安全解决方案是数字版权管理（DRM）加密。本主题提供在 BytePlus MediaLive 中启用 DRM 保护的完整流程。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">BytePlus MediaLive 支持以下 DRM 系统：Widevine、FairPlay 和 PlayReady。</div>


<span id="d1baef6b"></span>
## 限制


* BytePlus MediaLive 仅在 HLS（MPEG\-TS）和 LL\-DASH（CMAF）中提供 DRM 加密的回放地址。

* 建议使用标准 DRM 播放器在网页浏览器上播放 DRM 加密的在线流。原生 Android 播放器或其他平台的性能可能无法保证。


<span id="7aed754a"></span>
## 流程

该流程包括以下步骤：


1. 从您的 DRM 授权提供商处获取 DRM 密钥。

2. 在 BytePlus MediaLive 控制台中配置 DRM。

3. 生成经过 DRM 加密的回放地址。

4. 为授权用户解密内容。


<span id="941c05bb"></span>
### 获取 DRM 密钥

您必须首先从[Intertrust](https://portal.expressplay.com/home)获取 DRM 密钥。有关获取密钥的详细说明，请参阅[获取 DRM 密钥](https://docs.byteplus.com/docs/byteplus-media-live/docs-acquiring-a-drm-key)。

要在 Apple 设备上启用加密，还需获取 FairPlay 证书。随后需要将证书上传至 BytePlus MediaLive 控制台和 Intertrust。有关获取证书及其他相关信息的说明，请参阅[获取 FairPlay 证书](https://docs.byteplus.com/docs/byteplus-media-live/docs-acquiring-a-fairplay-certificate)。

<span id="3b790e5c"></span>
### 在 BytePlus MediaLive 控制台中配置 DRM


1. 将 DRM 密钥和 FairPlay 证书上传至 BytePlus MediaLive。有关如何上传密钥和证书的详细说明，请参阅[管理 DRM 许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-managing-drm-licenses)。

2. 在 BytePlus MediaLive 控制台中，为您希望加密的域名和 AppName 配置转码任务。详情请参阅[配置转码任务](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。以 AppName “drm\-test” 的超高清（UHD）流为例，假设您希望加密该流。配置如下：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/107f86e4900b4fed9f8f81d50f162adb~tplv-goo7wpa0wc-image.image) </span>

   * **域名空间**：example.push.com

   * **AppName**：drm\-test

   * **后缀**：_uhd

3. 为您希望加密的域名和 AppName 配置 DRM 加密。您可参阅[配置 DRM 加密任务](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-a-drm-encryption-task)获取详细说明。在本例中，配置如下：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4a1ad5b655e54e6580fe768977e6354d~tplv-goo7wpa0wc-image.image) </span>

   * **域名空间**：example.push.com

   * **AppName**：drm\-test

   * **转码**：_uhd


<span id="4763a627"></span>
### 生成加密回放地址

您可以通过地址生成器生成 DRM 加密的回放地址。


1. 前往[地址生成器](https://console.byteplus.com/live/main/locationGenerate)并输入相应信息：

   * **选择域名**：example.pull.com。此域名应为与 example.push.com 关联的拉流域名，即您在前一步输入的域名。您可参阅[域名空间](https://docs.byteplus.com/docs/byteplus-media-live/docs-glossary#Vhost)了解这些概念之间的关系。

   * **AppName**：drm\-test

   * **流名称**：请输入您的流名称

   * **转码模版**：_uhd

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8e4db9069fee45f18bf37818642db0b7~tplv-goo7wpa0wc-image.image) </span>

2. 点击**生成地址**。

3. 定位包含 DRM 标签的 M3U8 地址。使用该地址作为回放地址。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c9d4b1f5a5f547d38e86d00745cbf60d~tplv-goo7wpa0wc-image.image) </span>


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">其他格式的回放地址未加密。为防止用户通过这些地址访问直播流，您可以为您的域名开启 URL 鉴权，或限制用户仅能访问特定协议。详情请参见<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication">URL 鉴权</a>和<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-protocol-restrictions">协议限制</a>。</div>


* <div data-tips="true" data-tips-type="tip">如需 CMAF 格式的回放地址，请<a href="https://console.byteplus.com/workorder/create">联系技术支持</a>。</div>



<span id="70daa99f"></span>
### 内容解密

为授权用户观看加密在线流，播放器需调用 BytePlus OpenAPI 获取 DRM 许可证。对于 iOS 用户，播放器还需获取 FairPlay 证书。


* 要获取 DRM 许可证，请调用[DescribeLicenseDRM](https://docs.byteplus.com/docs/byteplus-media-live/docs-describelicensedrm)接口。

* 要获取 FairPlay 证书，请调用[DescribeCertDRM](https://docs.byteplus.com/docs/byteplus-media-live/docs-describecertdrm)接口。


由于您的 BytePlus AK/SK 不能存储在客户端设备上，您需要先在服务器端生成 OpenAPI 认证信息，然后将该信息传递给客户端设备。您可以按照[签名 BytePlus MediaLive 请求](https://docs.byteplus.com/docs/byteplus-media-live/docs-signing-byteplus-medialive-requests)中的说明操作，或使用[Server SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-server-sdk)来计算签名。

假设您使用[Go SDK](https://github.com/byteplus-sdk/byteplus-sdk-golang)调用 BytePlus MediaLive OpenAPI。请使用以下代码生成客户端用于获取 DRM 许可证和 FairPlay 证书的查询 URL。


1. 定义参数值。

   ```Go
   var (
     serviceInfo = &ServiceInfo{
      Timeout: 5 * time.Second,
      Host:    "open.byteplusapi.com",
      Header: http.Header{
       "Accept": []string{"application/json"},
      },
      Credentials: Credentials{Region: RegionApSingapore, Service: "live"},
     }
     
     // API endpoints that need to be signed
     apiList = map[string]*ApiInfo{
      "DescribeLicenseDRM": {
       Method: http.MethodPost,
       Path:   "/",
       Query: url.Values{
        "Action":     []string{"DescribeLicenseDRM"},
        "Version":    []string{"2023-01-01"},
        "Vhost":      []string{"drm.test.com"},
        "Domain":     []string{"drmpull.videoarch.com"},
        "App":        []string{"app-drm"},
        "StreamName": []string{"s-drm-1221"},
        "DRMType":    []string{"fp"}, // The DRM encryption type
       },
      },
      "DescribeCertDRM": {
       Method: http.MethodGet,
       Path:   "/",
       Query: url.Values{
        "Action":  []string{"DescribeCertDRM"},
        "Version": []string{"2023-01-01"},
        "Vhost":   []string{"drm.test.com"},
        "App":     []string{"app-drm"},
       },
      },
     }
   )
   ```
   

2. 生成客户端用于获取 DRM 许可证和 FairPlay 证书的查询 URL。

   ```Go
   func TestClient_GetSignUrl(t *testing.T) {
     client := NewClient(serviceInfo, apiList)
     client.SetAccessKey("your ak")
     client.SetSecretKey("your sk")
     urlStr, _ := client.GetSignUrl("DescribeLicenseDRM", nil)
     fmt.Println("https://live-gateway-byteplus.byteintlapi.com/drm_api/?" + urlStr)
     urlStr, _ = client.GetSignUrl("DescribeCertDRM", nil)
     fmt.Println("https://live-gateway-byteplus.byteintlapi.com/drm_api/?" + urlStr)
   }
   ```
