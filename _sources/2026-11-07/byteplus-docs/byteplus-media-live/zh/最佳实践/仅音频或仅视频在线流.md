为满足特定使用场景，您可以配置 BytePlus MediaLive 以处理仅音频或仅视频流。本主题提供了使用支持的协议推流的操作说明，以及通过在拉流地址添加查询参数来拉取特定流类型的方法。

<span id="c89e0453"></span>
## 操作流程

<span id="8114c44c"></span>
### 推送在线流

您可以推送使用 **RTMP**、**RTMPS** 和 **QUIC** 协议的仅音频和仅视频在线流。

支持的流类型会根据您的直播方式有所不同。支持的流类型如下：


* 仅音频流：您可以推送仅音频流或包含音视频的常规流。

* 仅视频流：您可以推送仅视频流或包含音视频的常规流。


<span id="bba6ca8c"></span>
### 拉取在线流

您可以拉取使用 **RTMP**、**FLV** 和 **QUIC** 协议的仅音频和仅视频在线流。

要拉取仅音频或仅视频流，请为对应协议的拉流地址添加查询参数。


* 仅音频：添加查询参数 `only_audio`

   当 `only_audio=1` 时，流将以仅音频模式拉取。如果参数设置为 `0` 或未设置，则流将以常规模式拉取。

* 仅视频：添加查询参数 `only_video`

   当 `only_video=1` 时，流将以仅视频模式拉取。如果参数设置为 `0` 或未设置，则流将以常规模式拉取。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">您不能在同一个地址中同时将 <code>only_audio</code> 和 <code>only_video</code> 设置为 <code>1</code>。如果两个参数都设置为 <code>1</code>，则均不会生效。</div>


以下示例展示了使用 RTMP、FLV 和 RTM 协议的仅音频流拉流地址格式。


* RTMP: `rtmp://{Domain}/{AppName}/{StreamName}?{AuthenticationInfo}&only_audio=1`

* FLV: `https://{Domain}/{AppName}/{StreamName}.flv?{AuthenticationInfo}&only_audio=1`

* RTM: `https://{Domain}/{AppName}/{StreamName}.sdp?{AuthenticationInfo}&only_audio=1`
