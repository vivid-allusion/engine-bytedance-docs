要在 BytePlus MediaLive 中为不同团队或用户实现精细化权限控制，您可以使用 IAM（Identity and Access Management）项目。本主题演示如何创建项目、将项目与 IAM 用户（子账号）关联并分配特定策略，从而隔离资源并安全管理访问权限。

## 概念

* **主账号**：注册的 BytePlus 账号。

* **子账号**：在主账号下创建的用户。

* **用户组**：子账号组成的组。您可以为用户组设置权限，这些权限将应用于组内用户。

* **策略**：一组权限。MediaLive 支持客户自定义策略，每个产品也提供系统托管策略，以满足其特定业务需求。

## 策略类型

策略是一组权限。您可以将策略绑定到子账号，以授予相应权限。

### 系统托管策略

MediaLive 目前提供两个系统托管策略：**LIVEFullAccess** 和 **LIVEReadOnlyAccess**，您可以将其分配给子账号。

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e0c4db5b1f6247aaa2d54b8a3cf3f63d~tplv-goo7wpa0wc-image.image)

**LIVEFullAccess**：提供对 MediaLive 的完全访问权限。

**LIVEReadOnlyAccess**：提供对 MediaLive 的只读访问权限。

### 客户自定义策略

MediaLive 支持自定义策略。

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/63be25bf92c84485b7ca13e99cd3e1fe~tplv-goo7wpa0wc-image.image)

## 操作步骤

### 创建项目

1. 通过主账号登录 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左侧导航窗格中，单击 **Project \> Create Project.**

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/353601fff598406986cf0a434caa338b~tplv-goo7wpa0wc-image.image)

3. 填写 **Project name**，然后单击 **OK**。

### 创建 IAM 用户并设置权限

1. 通过主账号登录 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左侧导航窗格中，单击 **User management** \> **User**。

3. 单击 **Create New User**。在 **Create User** 页面，在 **Basic information settings** 下填写 **Username**，并配置 **Login settings**。

   * **Programmatic access**：为用户分配 Access Key，用于通过 API 请求访问。

   * **Console access**：为用户分配密码，用于通过控制台访问。

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cf3557d0d9db41359faaedf117d14d83~tplv-goo7wpa0wc-image.image)

4. 单击 **Next**。在 **Create User** 页面，在 **Permission settings** 下选择权限策略和项目。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7404f4e01bf1429f91d1d90098c4a99d~tplv-goo7wpa0wc-image.image)

5. 单击 **Next**。仔细检查您的设置，然后单击 **Submit**。

## 后续操作

### 在 MediaLive 中使用项目

* 添加域名时，选择域名空间所属的项目。参见[添加域名](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-domain)。

* 添加 HTTPS 证书时，选择证书所属的项目，参见[管理 SSL 证书](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-managing-certificates)。

* 创建 SDK 应用时，选择应用所属的项目，参见 [SDK 管理](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-sdk-management)。

* 创建转推组时，选择转推组所属的项目，参见[配置转推任务](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-relay)。

* 使用项目筛选用量统计和统计分析中的查询数据，参见[查询用量数据](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-usage-statistics)和[查询分析数据](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-statistical-analysis)。

### 以 IAM 用户身份访问控制台

1. 前往 [BytePlus](https://console.byteplus.com/auth/login) 登录页面。

2. 单击 **IAM user**，前往 **IAM user sign in** 页面。

3. 填写 **Main account username**、**Sub\-account username** 和 **Password**，然后单击 **Sign in**。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/647ae2d2199c42c58b32b3aa10887167~tplv-goo7wpa0wc-image.image)

4. 在 **Products** 列表中，单击 **BytePlus MediaLive** 以访问控制台。

### 获取 IAM 用户的 Access Key 并发起请求

1. 通过主账号登录 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左侧导航窗格中，单击 **User management** \> **User**，然后单击列表中的用户名。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c56042e5df044c789b3137215d79bcb5~tplv-goo7wpa0wc-image.image)

3. 进入 **User detail** 页面，切换到 **Access Key** 页签，查看当前 IAM 用户的 Access Key。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e3b7f97ccbca44478bf881b4901034bd~tplv-goo7wpa0wc-image.image)

   > **说明**

   * > 在密钥列表中，您可以禁用正在使用的 Access Key，或再次启用它。

   * > Access Key ID 和 Secret Access Key 是您访问 MediaLive API 的密钥。它们具有 IAM 用户的全部权限。每个 IAM 用户最多可以拥有两个处于启用状态的 Access Key。

   * > 请妥善保管您的密钥，定期更换，并删除不再使用的密钥。删除密钥是不可逆操作，请谨慎操作。

4. 使用 IAM 用户的 Access Key 调用 SDK。示例代码如下（以 `CreateDomainV2` 为例）。

   > **说明**

   * > 使用 IAM 用户的密钥初始化 LiveService 实例。Access Key 用于身份验证和授权，以访问 MediaLive 服务。

   * > 调用示例代码中的 `CreateDomainV2` 方法，发起向 MediaLive 添加域名的请求。该方法将所需参数发送到 MediaLive 服务，以创建新域名。

   * > 实例使用 IAM 用户的 Access Key 和 Secret Access Key 生成签名，并将签名添加到请求中。这可确保请求的身份验证和完整性，防止未授权访问和数据篡改。

   ```Java
   package com.byteplus.live.demo;
   
   import com.byteplus.model.live.v20230101.*;
   import com.byteplus.service.live.v20230101.LiveService;
   import java.util.ArrayList;
   import java.util.List;
   
   public class CreateDomainV2Demo {
   
     public static void main(String[] args) {
       // 强烈建议不要将 BYTEPLUS_ACCESSKEY 和 BYTEPLUS_SECRETKEY 存储在项目代码中，否则 AccessKey 可能泄露，危及您账号下所有资源的安全。
       // 本示例通过从环境变量读取 BYTEPLUS_ACCESSKEY 和 BYTEPLUS_SECRETKEY 来验证 API 访问。在运行代码示例前，请配置 BYTEPLUS_ACCESSKEY 和 BYTEPLUS_SECRETKEY 环境变量。
       LiveService service = LiveService.getInstance();
   
       service.setAccessKey(System.getenv("BYTEPLUS_ACCESSKEY"));
   
       service.setSecretKey(System.getenv("BYTEPLUS_SECRETKEY"));
   
       CreateDomainV2Body body = new CreateDomainV2Body();
   
       // 域名数组。
       // 注意：
       // 一个域名空间最多可包含 10 个域名。
       List<CreateDomainV2BodyDomainsItem> Domains = new ArrayList<>();
   
       CreateDomainV2BodyDomainsItem Domains1 =
         new CreateDomainV2BodyDomainsItem();
   
       // 加速区域。有效值包括：
       // - oversea：中国大陆境外。
       // - cn：中国大陆。 
       // - global：全球。 
       Domains1.setRegion("cn");
       Domains.add(Domains1);
       body.setDomains(Domains);
   
       try {
         CreateDomainV2Res resp = service.CreateDomainV2(body);
         System.out.println(resp);
       } catch (Exception e) {
         e.printStackTrace();
       }
     }
   }
   ```
