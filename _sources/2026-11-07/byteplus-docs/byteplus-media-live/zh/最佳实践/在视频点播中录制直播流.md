为实现在线流的按需回放及后续处理，您可以配置 BytePlus MediaLive，将其自动录制到 BytePlus 视频点播。本主题提供创建录制模版、配置回调及启动录制任务的详细操作步骤。直播流录制完成后，您可以利用视频点播的功能进行转码、编辑和添加水印，然后将最终视频分发给观众。

<span id="86d66040"></span>
## 前提条件


* 要将录制文件存储到视频点播，请开通[视频点播服务](https://console.byteplus.com/vodpaas/totalOverview/)。

* 推流域名已添加，且 CNAME 已配置。详情可参考[添加域名](https://docs.byteplus.com/docs/byteplus-media-live/docs-domain#bb9e1337)和[添加 CNAME 记录](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-adding-a-cname-record)。

* 在视频点播控制台完成域名配置，详情请参见[分发加速](https://docs.byteplus.com/en/docs/byteplus-vod/docs-accelerated-distribution)。


<span id="1d4ffeb7"></span>
## 操作流程

<span id="6791add7"></span>
### 创建录制模版

以下步骤介绍如何在控制台创建录制模版。您也可以通过调用[CreateRecordPresetV2](https://www.volcengine.com/docs/6469/1126855) API 创建录制模版。


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏选择**功能配置**，并进入**录制**标签页。

3. 在页面顶部找到**域名空间**，并从下拉菜单中选择一个域名空间。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">你需要选择视频点播作为存储位置，在面板中点击<strong>视频点播</strong>。   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ed009ab1f32f4ae78e7a724924a1ca86~tplv-goo7wpa0wc-image.image) </span>

4. 点击**添加配置**，打开**添加录制配置**对话框。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">首次操作时需要完成授权流程，以允许 MediaLive 访问视频点播服务。请按照屏幕上的指引完成流程后，再进行下一步操作。   </div>
   

5. 根据页面提示配置 AppName、视频点播空间、工作流模板等参数。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3fce24b3399d43ea808f026569e4400b~tplv-goo7wpa0wc-image.image) </span>

### 配置录制回调

以下步骤介绍如何在 BytePlus MediaLive 控制台添加回调配置。您也可以调用[UpdateCallback](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-updatecallback-2023) API 进行配置。


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏选择**设置** \> **功能配置**。点击**回调**标签页。

3. 在页面顶部找到**域名空间**，并从下拉菜单中选择一个域名空间。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c846b992def44347a4bfc578354621f7~tplv-goo7wpa0wc-image.image) </span>

4. 点击添加配置，打开添加回调配置对话框。

5. 根据页面提示配置回调地址、回调类型、AppName 等参数。

   参数说明见下表。

   
   |参数 |接口行为 |
   |---|---|
   |回调地址 |用于接收回调消息的回调地址。支持 HTTP 和 HTTPS 协议。 |
   |回调类型 |对于回调类型，请选择**录制事件**。 |
   |回调密钥 |回调密钥。支持大小写字母和数字，最大长度为 32 个字符。 |
   |AppName |应用名称。必须与创建录制模版时使用的名称一致。 |
   

6. 点击**确认**保存回调配置。您可以在列表中看到新添加的配置。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/639d18064d01434fadb769baf18d3219~tplv-goo7wpa0wc-image.image) </span>

### 生成推流地址

本节介绍如何在 BytePlus MediaLive 控制台生成推流地址。您也可以通过调用[GeneratePushURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generatepushurl-2023) API 生成推流地址。


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在导航栏选择[地址生成器](https://console.byteplus.com/live/main/locationGenerate)。

3. 根据页面提示选择地址类型和域名，并输入 AppName（需与创建录制模版时一致）、自定义 StreamName 和过期时间。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eea908c886ba4d12bb51041b411e3b6e~tplv-goo7wpa0wc-image.image) </span>

4. 点击**生成地址**，在**结果**区域获取推流地址。


<span id="3d28d39b"></span>
### 开始推流

使用生成的推流地址进行推流。MediaLive 支持以下推流配置。


* 在 BytePlus MediaLive 控制台使用[网页推流](https://console.byteplus.com/live/main/WebPushStream)功能进行推流

* 使用推流工具（如[OBS](https://obsproject.com/)）进行推流

* 使用[客户端 SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-client-sdks-4d36c282)推送流

### 获取视频 Vid

直播流结束后，录制文件会存储在对应的视频点播空间。你可以通过视频 ID（Vid）查找该视频。获取 Vid 有三种方式：


<Tabs>
<Tab zoneid="L3wPyGOJFi" title="方法一：通过 BytePlus MediaLive 控制台获取">
<TabTitle>方法一：通过 BytePlus MediaLive 控制台获取</TabTitle>

1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)

2. 选择**直播管理** \> **录制**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ff1d3c5677a142f4b8b82bd85fb23ea7~tplv-goo7wpa0wc-image.image) </span>

3. 根据提示填写域名、AppName、StreamName，并选择时间范围。点击**搜索**获取录制结果。域名空间和时间范围为必填项。

4. 点击**搜索**开始查询。

5. 你可以在结果列表中看到对应录制的 Vid。你也可以点击**进入 VOD 查看**，进入 VOD 控制台查看录制结果。


</Tab>
<Tab zoneid="HSNpS83agS" title="方法二：通过录制回调方法获取">
<TabTitle>方法二：通过录制回调方法获取</TabTitle>

若配置了录制回调，MediaLive 在生成录制文件时会将录制文件信息发送到你的回调服务器。

你可以在回调消息中获取录制文件的 Vid。有关回调消息的详细接口行为，请参考回调内容文档。


</Tab>
<Tab zoneid="S8mjMD1abM" title="方法三：通过 API 获取">
<TabTitle>方法三：通过 API 获取</TabTitle>

你可以通过调用[DescribeRecordTaskFileHistory](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-describerecordtaskfilehistory) API 获取录制文件的 Vid。


</Tab>
</Tabs>
