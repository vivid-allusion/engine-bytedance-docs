为保护您的内容免遭未经授权的使用，您可以使用 MediaLive 为转码流或自适应码率（ABR）子流添加静态或动态水印。本主题介绍如何在 MediaLive 控制台中配置水印。

## 说明

* 水印仅支持转码流或 ABR 子流。添加水印配置前，请确保目标 `AppName` 在同一域名空间内已有转码或 ABR 配置。如需为源流添加水印，请添加使用 **Original** 设置的转码配置。

* 每个 `AppName` 仅支持一个水印配置。在该配置内，您可以将水印应用到全部或指定的转码流或 ABR 子流。

* 添加、更新或删除水印配置后，变更会在 3 到 5 分钟内生效。变更生效后生成的转码流或 ABR 子流会使用最新水印配置。变更生效前已生成的现有转码流或 ABR 子流不会自动应用更新。如果变更前不存在转码流或 ABR 子流，请等待配置生效。如果变更前已存在转码流或 ABR 子流，且您需要使用更新后的配置，请在添加、更新或删除配置后等待 3 到 5 分钟，然后重新推流。

* 静态水印的实际位置由水印的绝对位置和大小决定。如果水印超出视频边缘，则完全不会显示在视频上。

## 前提条件

* 在要添加水印配置的域名空间中，为目标 `AppName` 添加转码或 ABR 配置。更多信息，请参见[管理转码配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)或[管理自适应码率配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-an-hls-abr-task)。

* JPG 或 PNG 图片，最大文件大小为 2 MB，最大分辨率为 1080 x 1080 px。PNG 图片可以包含透明度。

## 操作步骤

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，选择**设置** \> **功能配置**。单击**水印**页签。

3. 从**域名空间**下拉列表中选择已添加转码或 ABR 配置的域名空间。

4. 单击**添加配置**，打开**添加水印配置**对话框。

5. 配置相关设置，然后单击**确定**。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/22f25b46529040bdb0caaa57c8aebdb8~tplv-goo7wpa0wc-topic.webp)

   |**参数** |**说明** |
   |---|---|
   |AppName |选择与转码或 ABR 配置相同的 `AppName`。 |
   |StreamName |推流地址中的 `StreamName`。例如，如果推流地址为 `rtmp://push.example.com/live/test?authinfo`，则 `StreamName` 为 `test`。<br><br><br>* 如果配置 `StreamName`，水印仅应用到当前 `AppName` 下的指定转码流或 ABR 子流。<br><br>* 如果将 `StreamName` 留空或输入 `*`，水印会应用到当前 `AppName` 下的全部转码流或 ABR 子流。 |
   |Suffix |默认选择所有后缀，表示水印会应用到全部转码流或 ABR 子流。<br><br>您也可以选择一个或多个后缀（例如 `_uhd` 和 `_hd`），仅为带有这些后缀的转码流或 ABR 子流添加水印。 |
   |添加水印 |上传 JPG 或 PNG 图片。最大文件大小：2 MB。最大分辨率：1080 x 1080 px。<br><br>> **说明**<br><br><br>> PNG 图片可以包含透明度。<br> |
   |水印类型 |选择水印类型。<br><br><br>* **静态水印**：将水印固定在配置的位置。<br><br>* **动态水印**：在播放期间移动水印，使未经授权的录屏和复用更加困难。 |
   |水平偏移 |有关详细信息，请参见[常见问题](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-live-stream-watermarks#FAQs)。<br><br>> **说明**<br><br><br>> 仅当您选择**静态水印**作为**水印类型**时，才会显示此字段。<br> |
   |垂直偏移 |有关详细信息，请参见[常见问题](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-live-stream-watermarks#FAQs)。<br><br>> **说明**<br><br><br>> 仅当您选择**静态水印**作为**水印类型**时，才会显示此字段。<br> |

   |水印缩放 |此项用于调整水印的等比缩放。有效范围：1%\-200%。 |

## 常见问题

### 什么是水平偏移和垂直偏移？

BytePlus MediaLive 使用**水平偏移**（PosX）和**垂直偏移**（PosY）指定静态水印在视频中的位置。相关参数说明如下：

|**参数** |**说明** |
|---|---|
|PosX |**水平偏移**，即水印左边缘与转码视频左边缘之间的距离与视频宽度的比值。有效范围：0–1。 |
|PosY |**垂直偏移**，即水印上边缘与转码视频上边缘之间的距离与视频高度的比值。有效范围：0–1。 |
|RelativeWidth |水印宽度与转码视频宽度的比值。有效范围：0–1。水印高度会根据其宽度自动调整。 |
|Orientation |提供两个选项。<br><br><br>* horizontal：横屏。<br><br>* vertical：竖屏。 |

PosX 和 PosY 仅适用于静态水印。BytePlus MediaLive 控制台使用**水印缩放**调整水印大小，而我们的 API 使用**相对宽度**作为大小参数。本节仅介绍**相对宽度**。

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ee5e570a6c804de6a11c51be467367b9~tplv-goo7wpa0wc-topic.webp)

### 如何计算水印的绝对位置、宽度和高度？

假设您在横屏模式下，将一张 400 x 200 图片作为静态水印添加到 1920 x 1080 视频上，并设置以下参数：

```plain
PosX = 0.05
PosY = 0.05
RelativeWidth = 0.1
Orientation = "horizontal"
```

以下是水印绝对位置、宽度和高度的计算方法：

```plain
abs_x = 1920 * 0.05 = 96  // 水印左边缘距离视频左边缘 96 像素。
abs_y = 1080 * 0.05 = 54  // 水印上边缘距离视频上边缘 54 像素。
abs_w = 1920 * 0.1 = 192  // 水印宽度为 192 像素。
abs_h = 192 * 200 / 400 = 96  // 水印高度为 96 像素。
```

静态水印的实际位置由其绝对位置和大小决定。如果水印超出视频边缘，则完全不会显示在视频上。请调整水印的**水平偏移**、**垂直偏移**或**相对宽度**，以确保完整水印在视频内可见。

### 为什么我的水印在直播会话中不显示？

可能有以下几个原因：

* **水印配置变更尚未生效。**

   添加、更新或删除水印配置后，请等待 3 到 5 分钟，以便变更生效。

* **转码流或 ABR 子流是在水印配置变更生效前生成的。**

   现有转码流或 ABR 子流不会自动应用更新。要使用最新水印配置，请在添加、更新或删除配置后等待 3 到 5 分钟，然后重新推流。

* **您尚未为相关 AppName 添加任何转码或 ABR 配置。**

   水印只能应用到已有转码或 ABR 配置的 `AppName`。请确保已为相关 `AppName` 添加转码或 ABR 配置。

* **当前转码流或 ABR 子流的后缀不在所选后缀中。**

   如果您在水印配置中选择了指定转码后缀或 ABR 子流后缀，则水印仅显示在后缀与所选后缀匹配的转码流或 ABR 子流中。

* **水印超出视频边缘。**

   这适用于静态水印。实际位置由水印的绝对位置和大小决定。如果水印超出视频边缘，则完全不会显示在视频上。请调整水印的**水平偏移**、**垂直偏移**或**相对宽度**，以确保完整水印在视频内可见。
