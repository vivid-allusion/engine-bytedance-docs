如需接收关键直播事件的自动通知，您可以在 BytePlus MediaLive 控制台配置回调。本主题介绍如何添加、编辑和删除配置，以接收特定域名或应用的推流、录制和截图事件通知。

配置变更可能需要约 3\-5 分钟生效。

## 前提条件

用于接收回调消息的回调地址。支持 HTTP 和 HTTPS。

> **说明**

> 有关回调请求可靠性和每条回调消息中字段说明的详细信息，请参阅[回调说明](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-callback-description)。

## 操作步骤

### **添加回调配置**

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，选择**设置** \> **功能配置**。单击**回调**页签。

3. 在页面顶部找到**域名空间**，并从下拉菜单中选择一个域名空间。

4. 单击**添加配置**，打开**添加回调配置**对话框。

5. 配置相关设置。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/32a38b0f955740dca04be2319f105e36~tplv-goo7wpa0wc-image.image)

   |**参数** |**描述** |
   |---|---|
   |回调地址 |用于接收回调消息的回调地址。地址长度必须为 1\-100 个字符。支持 HTTP 和 HTTPS。 |
   |回调类型 |要接收的回调消息类型。<br><br><br>* **推流开始**：推流开始时触发回调。<br><br>* **推流结束**：推流结束时触发回调。<br><br>* **录制事件**：发生录制事件时触发回调。<br><br>* **截图事件**：发生截图相关事件时触发回调。 |
   |域名 |选择要为其配置回调的域名。<br><br>> **说明**<br><br><br>> 如果选择**推流开始**或**推流结束**作为回调类型，请配置此设置。<br> |
   |AppName |输入要为其配置回调的应用名称。<br><br>> **说明**<br><br><br>> 如果选择**录制事件**或**截图事件**作为回调类型，请配置此设置。<br> |
   |适用于转码流 |是否接收来自转码流的回调消息。<br><br>> **说明**<br><br><br>> 如果选择**推流开始**或**推流结束**作为回调类型，请配置此设置。<br> |
   |回调密钥 |用于身份验证的密钥。启用身份验证并设置此密钥后，您可以使用回调消息中的 `sign` 和 `t` 字段验证回调是否来自 BytePlus MediaLive。密钥可以包含数字和字母，最大长度为 32 个字符。 |

6. 单击**确认**以保存配置。

### 编辑回调配置

您可以单击**操作**列中的**编辑**来更新回调配置。

> **说明**

> 创建回调配置后，并非所有设置都可以编辑。可编辑项包括：

* > 回调密钥。

* > 是否为**推流开始**和**推流结束**事件启用转码流回调。

### 删除回调配置

您可以单击**操作**列中的**删除**来删除回调配置。
