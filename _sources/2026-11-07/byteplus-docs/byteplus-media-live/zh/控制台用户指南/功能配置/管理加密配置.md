为保护您的直播内容，本指南提供分步说明，介绍如何为原始流和转码流配置并启用加密。您将了解如何使用 BytePlus MediaLive 控制台应用各种加密方法，包括商业 DRM 和 HLS 标准加密。

## 费用说明

只有在输出加密视频时，才会收取转码费用。有关详细信息，请参见[转码](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-transcoding)。

## 前提条件

* 如果使用 Widevine、FairPlay 或 PlayReady 等商业 DRM 加密技术，您需要：

   * 将 API 访问密钥上传至 DRM 证书管理平台。有关说明，请参见[管理 DRM 许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-managing-drm-licenses)。

   * 上传用于 iOS 加密的 FairPlay 证书。有关说明，请参见[管理 DRM 许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-managing-drm-licenses)。

   * 如果要加密转码流，必须先为其创建转码配置。有关说明，请参见[配置转码任务](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。

* 如果使用 HLS 标准加密，您需要：

   * 为自建密钥管理服务配置密钥获取地址。有关详细信息，请参见[管理 HLS 密钥获取地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-hls-keyaddress)。

   * 如果要加密转码流，您需要为待加密的流创建转码配置，配置方法请参见[配置转码任务](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。

## 限制

当直播流的源名称（StreamName）包含下划线时，不支持加密功能。

## 操作步骤

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，选择**设置** \> **功能配置**。单击**加密**页签。

3. 在左上角找到**域名空间**，并从下拉列表中选择一个域名空间。这些配置将应用于所选域名空间内的所有域名。您可以参见[域名空间](https://docs.byteplus.com/docs/byteplus-media-live/docs-glossary#Vhost)，了解这些概念的更多信息。

4. 单击**添加配置**，打开**添加加密配置**对话框。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4d80ebdbb43d42b6ba304f000a1d6203~tplv-goo7wpa0wc-image.image)

5. 配置以下设置：

   * **AppName**：将其设置为与直播流地址中 AppName 字段相同的值。此项定义配置适用的流。

   * **加密类型**：选择要使用的加密技术。

      > **说明**

      * > 商业 DRM 加密支持三种方法：Widevine、FairPlay 和 PlayReady。

      * > 使用 HLS 标准加密时，支持 ClearKey AES\-128 加密方法。

   * **加密内容**：选择加密原始流还是转码流。您可以通过转码配置后缀识别转码流。

6. 单击**确认**。

## 后续操作
