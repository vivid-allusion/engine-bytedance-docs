为使你的应用适用于生产环境，或避免因许可证过期导致服务中断，你需要有效管理 SDK 许可证。本主题详细说明如何将试用许可证升级为基础版或高级版许可证，以及如何续费基础版或高级版许可证。

## 前提条件

你已获取 SDK 许可证。更多信息，请参见[获取 SDK 许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management)。

## 将试用许可证升级为基础版或高级版许可证

试用许可证仅用于测试，不能用于生产环境。请在试用许可证到期前，或你的应用发布到生产环境前，将试用许可证升级为基础版或高级版许可证。

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，单击 **SDK 管理**。

3. 在试用许可证的**操作**列中单击**升级**。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c065c4ff71314b508b3736c4e91807dd~tplv-goo7wpa0wc-image.image)

4. 选择**基础版**或**高级版**作为许可证类型。

   > **说明**

   > 如需了解各许可证类型支持的功能，请参见[客户端 SDK：SDK 概览](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-introduction)和 [Web 播放器 SDK：SDK 概览](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-sdk-overview)。如需了解各许可证类型的价格，请参见 [SDK 许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses)。

   **升级为基础版许可证**

基础版许可证适用于**生产环境**，有效期为**一年**。

   选择以下任一方式升级为基础版许可证：

      * 直接购买

         1. 单击**立即购买**。

            ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/341cc7e29cda40ce806cb0814b45fd80~tplv-goo7wpa0wc-image.image)

         2. 完成购买后，返回配置页面。从列表中选择基础版许可证，然后单击**确认**。

            ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a4ab8a8ff8b4d708dd4876ccf6006f9~tplv-goo7wpa0wc-image.image)

            > **说明**

            > 如果新购买的许可证未立即显示在列表中，请单击刷新图标更新页面。

            > ![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3afbc908af9f4304bae35f8dc76b10d9~tplv-goo7wpa0wc-image.image)

      * 绑定流量包：你可以通过将 100 TB 或更大的直播流量包绑定到应用，获取一个免费的一年期基础版许可证。有关直播流量包的更多信息，请参见[资源包](https://docs.byteplus.com/docs/byteplus-media-live/docs-resource-packs)。

         > **说明**

         > 此方法**仅**适用于应用类型的应用。

         * **如果你已有符合条件的流量包**：从列表中选择该流量包，然后单击**确认**。

         * **如果你没有符合条件的流量包**：

            1. 单击**立即购买**进行购买。

               ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2e3a164f1da646c99e1c6fd68cbb129b~tplv-goo7wpa0wc-image.image)

            2. 完成购买后，返回配置页面。从列表中选择该流量包，然后单击**确认**。

               > **说明**

               > 如果新购买的流量包未立即显示在列表中，请单击刷新图标更新页面。

               > ![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3afbc908af9f4304bae35f8dc76b10d9~tplv-goo7wpa0wc-image.image)

   **升级为高级版许可证**

高级版许可证适用于**生产环境**，有效期为**一年**。

   完成以下步骤，升级为高级版许可证。

      1. 单击**立即购买**。

         ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/beb9a1eb93e648e0a8bf839e7a8dd5d0~tplv-goo7wpa0wc-image.image)

      2. 完成购买后，返回配置页面。选择高级版许可证，然后单击**确认**。

         ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31b655fa42144106a5f1b0836dca473b~tplv-goo7wpa0wc-image.image)

         > **说明**

         > 如果新购买的许可证未立即显示在列表中，请单击刷新图标更新页面。

         > ![](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3afbc908af9f4304bae35f8dc76b10d9~tplv-goo7wpa0wc-image.image)

随后，你必须参见[步骤 2：获取许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management#8a4f3efc)，下载基础版或高级版许可证文件，或从 [SDK 管理](https://console.byteplus.com/live/main/sdk)页面获取许可证 URL。然后，将你用于 SDK 集成的试用许可证替换为新许可证。

## 续费许可证

当你的基础版或高级版许可证即将到期或已经到期时，**SDK 管理**页面会显示到期提醒。请及时续费许可证，以防线上服务中断。

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，单击 **SDK 管理**。

3. 在要续费的许可证的**操作**列中，单击**续费**。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5c25d6df47e745c6a18a7d882e3be71c~tplv-goo7wpa0wc-image.image)

4. 续费许可证。

   > **说明**

   > 基础版许可证只能续费为基础版许可证，高级版许可证只能续费为高级版许可证。

## 常见问题

### 续费许可证后，是否必须发布应用的新版本？

* 对于 Android 或 iOS 应用：不需要。续费许可证后，你无需发布应用的新版本。许可证续费后，SDK 会自动检测许可证文件的变化，并更新许可证的有效期。但是，为避免网络问题导致自动更新出现潜在问题，建议你手动下载新的许可证文件，用新的许可证文件替换当前应用版本中的旧许可证文件，然后发布应用的新版本。

* 对于 Web 应用：这取决于你在集成 Web 播放器 SDK 时如何配置许可证。

   * 如果你设置了许可证 URL：你**无需**执行任何操作。续费许可证后，SDK 会自动更新到最新的许可证版本。

   * 如果你未设置许可证 URL：你**必须**手动更新许可证文件，然后**发布新版本**应用。

### 更改 SDK 应用的 PackageName、BundleID、通配符域名或 WebOTT 应用标识符后，是否需要替换许可证？

* 如果许可证已激活，变更后系统会根据更新后的应用信息重新生成许可证。你需要替换 SDK 许可证文件或许可证 URL。原许可证会在一段时间内保持有效，新许可证的到期时间与原许可证相同。

* 如果许可证已过期，续费许可证时系统会根据更新后的应用信息生成新的许可证。续费完成后，你需要替换 SDK 许可证文件或许可证 URL。

### 替换许可证文件后还需要执行哪些操作？

替换许可证文件后，你**必须**发布应用的新版本。对观众的影响如下：

* 对于 Android 或 iOS 应用：观众**必须**更新到应用的最新版本，才能继续使用服务。

* 对于 Web 应用：浏览器会在下次访问或页面刷新时自动加载新资源，因此观众**无需**执行任何操作。

### 升级或续费后，许可证的新有效期如何计算？

计算方式取决于具体操作：

* **续费**：有效期会在**当前许可证的原到期日期基础上增加一年**。例如，如果你的许可证于 2026 年 5 月 10 日到期，并且你续费一年，则新的到期日期为 2027 年 5 月 10 日，无论你何时执行续费。

* **升级**：新的一年有效期从升级日期开始计算。

更多信息，请参见[计算有效期](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses#55ec08cd)。

### 如果我的许可证过期会怎样？

许可证过期会导致服务中断。为避免影响你的业务，请务必及时续费许可证。

### 如何将基础版许可证升级为高级版许可证？

目前，你无法将基础版许可证直接升级为高级版许可证。你必须创建新的 SDK 应用，并将高级版许可证绑定到该应用。更多信息，请参见[步骤 1：创建或绑定 SDK 应用](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management#91608dc8)。
