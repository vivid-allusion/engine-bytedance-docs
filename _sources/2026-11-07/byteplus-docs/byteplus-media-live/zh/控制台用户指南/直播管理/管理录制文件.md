在你的在线流被录制后，你可能需要定位并管理生成的视频文件。本主题提供了如何使用 BytePlus MediaLive 控制台搜索录制文件的分步说明。你将学习如何通过域名空间、AppName、StreamName 和时间范围筛选文件，以便快速找到所需的特定内容。

<span id="Prerequisites"></span>
## 前提条件


* 请确保你已设置至少一个录制配置，并已启动与指定流参数匹配的直播流。你的直播流将被录制并存储。详情请参见[录制配置指南](https://docs.byteplus.com/byteplus-media-live/docs/configuring-recordings)。

* 要查询录制文件，你需要域名空间、AppName 和 StreamName。

* 请注意，流结束后，文件可能需要几分钟才会显示在页面上。


<span id="Procedure"></span>
## 操作步骤


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**直播管理** \> **录制文件**。

3. 点击**VOD** 或 **TOS** 标签页，以查看存储在 VOD 或 TOS 中的录制文件。

4. 选择域名空间，并输入相应的 AppName、StreamName 和时间范围。然后点击**搜索**，以查看相关录制文件。
