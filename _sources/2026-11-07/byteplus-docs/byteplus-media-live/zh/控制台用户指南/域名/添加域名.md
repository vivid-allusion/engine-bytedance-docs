若要设置 BytePlus MediaLive 流媒体服务，必须先配置域名。本指南提供整个域名生命周期的分步操作说明，包括如何添加用于推流和拉流的必要域名，以及后续通过启用、禁用或删除来管理这些域名。

<span id="bb9e1337"></span>
## 添加域名

使用 BytePlus MediaLive 时，需至少添加**两个**域名，一个用于推流，另一个用于拉流。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">每个域名都与唯一的 BytePlus 账号 ID 关联。用户可以重新添加之前已删除的域名。但一个用户添加过的域名，其他用户无法再次添加。例如，用户 A 添加并删除 example.push 后，只有用户 A 可以再次添加该域名。</div>


<span id="0020f4f0"></span>
### 背景

MediaLive 使用域名空间来关联推流和拉流的域名。用于同一业务目的的推流和拉流域名必须处于同一个域名空间。详情请参见[域名空间](https://docs.byteplus.com/docs/byteplus-media-live/docs-glossary#Vhost)。

<span id="dfaf1970"></span>
### 前提条件


* 若要将中国大陆纳入加速区域，必须为域名申请互联网内容提供商（ICP）许可证。可在[ICP/IP 地址/域名信息备案管理系统](https://beian.miit.gov.cn/#/Integrated/index)完成验证流程。

* 若要使用 HTTPS 推流或拉流地址，需先添加 SSL 证书。添加证书后，在添加域名时即启用 HTTPS 加密。


<span id="ede4d646"></span>
### 操作步骤


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**域名**。

3. 在出现的**域名**页面，点击**添加域名**。

   下表描述了所需参数：

   
   |**参数** |**说明** |

## 管理域名

添加域名后，可在控制台禁用、启用或移除域名。

<span id="11a495d4"></span>
### 操作步骤


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**域名**。

3. 在出现的**域名**页面，找到需配置的域名，在**操作**列点击**禁用**或**启用**以禁用或启用域名，或在**操作**列点击**删除**以移除域名。


<span id="f2d5069d"></span>
### 结果


* 被删除的域名会与其域名空间解除关联。若重新添加这些域名，BytePlus MediaLive 会将其重新关联到对应的域名空间。

* 删除域名后，BytePlus MediaLive 会保留对应的域名空间以保存历史数据。

* 可查询已删除域名的使用情况、流数据及其他统计信息。


下表列出了禁用与删除域名的区别：


| |**禁用域名** |**删除域名** |
|---|---|---|
|**CNAME** |域名停止指向分配的 CNAME 地址。 |CNAME 地址被删除。 |
|**域名空间** |无变化。 |域名被删除，但域名空间保留。 |
|**证书** |无变化。 |相关证书已与域名解绑。 |
|**域名设置** |无变化。 |相关域名设置被删除。 |


假设你删除一个域名后再次将其添加到账号：


|**操作** |**结果** |
|---|---|
|删除拉流域名`pull.a.com` |* 拉流域名`pull.a.com`已从域名空间`pull.a.com`中删除。<br><br>* 关联证书不再绑定于该域名。<br><br>* 若该域名与推流域名有关联，则关联关系被移除。<br><br>* 相关配置被删除，包括 URL 鉴权、referer、IP blocklist 和 allowlist。 |
|重新添加拉流域名`pull.a.com` |* 拉流域名`pull.a.com`已添加至域名空间`pull.a.com`。<br><br>* 该域名未绑定证书。<br><br>* 该域名未与任何推流域名关联。<br><br>* 相关配置已被禁用，包括 URL 鉴权、referer、IP blocklist 和 allowlist。 |
|删除推流域名`push.a.com` |* 推流域名`push.a.com`已从域名空间`push.a.com`中删除。<br><br>* 关联证书不再绑定于该域名。<br><br>* 若该域名与拉流域名有关联，则关联关系被移除。<br><br>* 相关配置被删除，包括 URL 鉴权和 IP blocklist、allowlist。 |
|重新添加`push.a.com`作为推流域名 |* 将域名`push.a.com`添加到域名空间`push.a.com`。<br><br>* 该域名未绑定证书。<br><br>* 如果该域名在删除前曾与拉流域名关联，则会恢复该关联。<br><br>* 默认已开启 URL 鉴权。<br><br>* IP 黑名单和白名单未开启。 |
