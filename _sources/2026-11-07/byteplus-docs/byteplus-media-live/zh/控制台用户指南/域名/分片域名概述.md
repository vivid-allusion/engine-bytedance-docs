分片域名用于通过 `HLS`、`DASH`、`LL-HLS` 和 `LL-DASH` 等协议播放直播流。

> **说明**

> 如果您无法在控制台找到此功能，请联系[技术支持](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980)启用。

## 如何选择拉流域名

您可以根据业务需求选择添加分片域名或流式域名。

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eb67beb3049c488e8e834218551b38e7~tplv-goo7wpa0wc-topic.webp)

* 如果您需要通过 `HLS`、`DASH`、`LL-HLS` 和 `LL-DASH` 等协议的拉流地址观看直播流，请选择分片域名。

* 如果您需要通过 `RTM`、`FLV` 和 `RTMP` 等协议的拉流地址观看直播流，请选择流式域名。

* 如果同时需要这两类协议，请分别添加分片域名和流式域名。

> **说明**

* > 如果您已通过流式域名使用 `HLS`、`DASH`、`LL-HLS` 和 `LL-DASH` 等协议的拉流地址，可以继续使用现有地址。但是，如需为这些协议新增拉流地址，请使用分片域名。

* > 如需使用 HLS\-ABR 或 DASH\-ABR，请使用分片域名。如需使用 RTM\-ABR，请使用流式域名。

## 分片域名与流式域名的功能差异

分片域名和流式域名支持的功能存在差异。即使支持的功能相同，具体配置方法也可能不同。详情请参见对应文档。

|功能 |说明 |分片域名 |流式域名 |
|---|---|---|---|
|证书 |添加 SSL 证书以启用 HTTPS 加密。 |支持 |支持 |
|HTTP/2 协议 |使用 HTTPS 拉流地址时，通过 HTTP/2 发送拉流请求。 |支持 |支持 |
|QUIC 协议 |使用 HTTPS 拉流地址时，通过 QUIC 发送拉流请求。 |支持 |不支持 |
|强制重定向 |强制将 HTTP 拉流请求重定向到 HTTPS，或强制将 HTTPS 拉流请求重定向到 HTTP。 |支持 |不支持 |
|OCSP 装订 |针对 HTTPS 拉流请求直接返回证书状态信息。 |支持 |不支持 |
|HSTS |指示浏览器在后续拉流请求中优先使用 HTTPS。 |支持 |不支持 |
|TLS 版本范围 |指定建立 HTTPS 连接时可使用的 TLS 版本范围。 |支持 |支持 |
|IPv6 |使用 IPv6 地址发送拉流请求。 |支持 |不支持 |
|禁用 HTTP 方法 |禁用使用特定 HTTP 方法的拉流请求。 |支持 |不支持 |
|WebSocket |在浏览器和服务器之间建立 WebSocket 连接，以支持双向通信。 |支持 |不支持 |
|代理协议 |在代理转发场景中传输观众真实 IP 地址等信息。 |支持 |不支持 |
|URL 鉴权 |设置 URL 签名规则，以允许或拒绝拉流请求。 |支持 |支持 |
|地域限制 |根据观众公网 IP 地址的地理位置允许或拒绝拉流请求。 |支持 |支持 |
|IP 限制 |根据 IP 白名单或黑名单允许或拒绝拉流请求。 |支持 |支持 |
|UA 限制 |根据 UA 白名单或黑名单允许或拒绝拉流请求。 |支持 |支持 |
|Referer |根据 Referer 白名单或黑名单允许或拒绝拉流请求。 |支持 |支持 |
|Origin 限制 |根据 Origin 白名单或黑名单允许或拒绝拉流请求。 |支持 |不支持 |
|远程鉴权 |将拉流请求转发到您的鉴权服务器进行验证。 |支持 |支持 |
|HTTP 响应头 |自定义返回的 HTTP 响应头。 |支持 |支持 |
|自定义错误页面 |自定义发生访问错误时返回的错误页面。 |支持 |不支持 |
|URL 规范化 |根据规则规范化拉流请求 URL。 |支持 |不支持 |
|限速 |限制拉流请求的频率。 |不支持 |支持 |
|协议限制 |按协议禁用拉流请求。 |不支持 |支持 |
|缓存规则 |设置节点缓存规则。 |支持 |不支持 |
|缓存键 |设置查询参数是否包含在缓存键中。 |支持 |不支持 |
|状态码缓存规则 |设置错误状态码缓存规则。 |支持 |不支持 |
|浏览器缓存规则 |设置浏览器缓存规则。 |支持 |不支持 |
|源站列表 |设置主源站和备源站。 |支持 |不支持 |
|回源协议 |设置回源请求使用的协议。 |支持 |不支持 |
|IPv6 源站 |设置对配置了域名的源站发起请求时，优先使用 IPv4 地址还是 IPv6 地址。 |支持 |不支持 |
|回源 Host |设置回源请求中的 Host 头部值。 |支持 |不支持 |
|回源超时 |设置与源站建立连接以及等待源站内容的超时时间。 |支持 |不支持 |
|HTTP 请求头 |设置回源请求的 HTTP 请求头。 |支持 |支持 |
|Range 回源 |当源站支持 Range 时，分片从源站获取内容。 |支持 |不支持 |
|跟随回源重定向 |设置源站返回 301 或 302 状态码时是否跟随重定向。 |支持 |不支持 |
|回源参数 |设置回源请求中包含的参数。 |支持 |不支持 |
|回源 SNI |设置回源 HTTPS 请求使用的 SNI 域名。 |支持 |不支持 |
|回源地址改写 |根据规则改写回源请求的请求路径。 |不支持 |支持 |
|Gop 缓存 |设置图像组（GOP）缓存时长，以平衡延迟和网络波动的容错能力。 |不支持 |支持 |
|带宽限制 |设置拉流带宽限制。 |不支持 |支持 |
|HLS/LL\-HLS |设置 HLS 和 LL\-HLS 流的分片和低延迟配置。 |支持 |不支持 |
|DASH/LL\-DASH |设置 DASH 和 LL\-DASH 流的分片和低延迟配置。 |支持 |不支持 |
|地址生成器 |生成对应协议的拉流地址。 |仅支持生成 HLS、DASH、LL\-HLS 和 LL\-DASH 拉流地址。 |仅支持生成 RTMP、FLV 和 RTM 拉流地址。 |

> **说明**

> 分片域名和流式域名使用不同的源站配置方法。默认情况下，两者都可以直接用于直播播放。

> 对于自定义源站配置：

* > 对于分片域名，源站配置基于域名。

* > 对于流式域名，源站配置在流级别执行，包括按特定流（`AppName` + `StreamName`）和按流媒体协议（`AppName` + 流媒体协议）。支持按需和定时两种模式。
