BytePlus MediaLive 提供三种用于管理客户端访问的功能：URL 鉴权、IP 白名单与黑名单，以及 Referer 白名单与黑名单。只有符合规则的用户才能推流或拉流。


* [配置URL鉴权](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication-zh-CN)：通过在 URL 中添加鉴权信息来校验请求是否合法，这是一种安全性较高的机制。

* [IP 限制](https://docs.byteplus.com/docs/byteplus-media-live/docs-ip-blocklist-and-allowlist-zh-CN)：通过允许或拒绝特定 IP 地址来控制访问。

* [Referer](https://docs.byteplus.com/docs/byteplus-media-live/docs-referer-zh-CN)：通过允许或拒绝特定来源来控制访问。


由于 Referer 和 IP 地址都可能被伪造，未经授权的用户仍有可能进行推流或拉流。因此，如果您对直播内容的安全性要求较高，建议使用 URL 鉴权。
