为了保护您的服务免受高频访问，并降低 Challenge Collapsar（CC）攻击的风险，您可以为拉流的域名配置限流。此功能允许您根据 IP 地址、URL 或特定 URL 查询参数设置请求频率限制。

使用此功能时请谨慎操作，因为限流设置过低可能会导致合法请求被误拦截。因此，建议您在设置限流时，充分考虑并测试合理的限流值，以在安全性和可访问性之间取得平衡。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">请求频率限制是按边缘集群生效，而非整个网络。例如，假设将单个 IP 地址的请求频率限制设置为每秒 50 次。如果集群 A 和集群 B 在同一秒内分别收到该 IP 地址的 50 个请求，则不会有请求被拦截。但如果集群 A 在同一秒内收到 101 个请求，而集群 B 仍收到 50 个请求，则该 IP 地址后续发送至集群 A 的请求将在拦截周期内被阻断。而集群 B 不受影响。</div>

## 操作流程

请按照以下说明，在 BytePlus MediaLive 控制台为域名配置请求频率限制：


1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击 **域名**。

3. 找到需要配置的域名，在 **操作**列点击 **设置**。

4. 点击 **访问控制**标签页。

5. 在 **限流**开关右侧点击 **编辑**。

6. 在弹出的 **编辑限流**对话框中，配置以下参数。

   * **限制类型**：

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">包括 <strong>按 URL 请求频率</strong>、<strong>按指定查询参数的 URL 请求频率</strong>和 <strong>按 IP 地址对 URL 的请求频率</strong>等选项默认隐藏。请联系您的 <a href="https://console.byteplus.com/workorder/create">技术支持</a>以显示这些选项。      </div>
      

      * **按 IP 地址请求频率**：限制单个 IP 地址发送请求的频率。

      * **按 URL 请求频率**：限制单个 URL 接收请求的频率。

      * **按指定查询参数的 URL 请求频率**：限制包含指定查询参数的 URL 接收请求的频率。

      * **按 IP 地址对 URL 的请求频率**：限制单个 IP 地址对同一 URL 发送请求的频率。

   * **限制值**：每秒或每分钟允许的最大请求数。

7. 点击 **确认**。
