域名空间是直播中至关重要的概念，它将推流域名与拉流域名关联起来，使观众能够观看你的流。本主题介绍什么是域名空间，并展示如何通过在空间内添加或修改域名来管理它们。

<span id="35c4be99"></span>
## 背景

推流域名用于生成推流地址，用户（主播）可以使用该地址将直播流推送到 BytePlus MediaLive Center。

拉流域名用于生成拉流地址，用户（观众）可以使用该地址从 BytePlus MediaLive Center 拉取直播流。

要将直播流推送到 BytePlus MediaLive Center 并拉取该直播流，必须将推流域名与拉流域名进行关联。

<span id="2180543e"></span>
### 域名空间定义了推流域名和拉流域名之间的关联关系

域名空间是一组关联的推流域名和拉流域名。

用于推流和拉流的域名必须彼此关联。关联后，你可以使用推流域名将直播流推送到 BytePlus MediaLive Center。你可以使用与推流域名关联的拉流域名拉取并播放直播流。

不同服务使用不同的域名空间。因此，不同空间内的直播流是隔离的，无法互相连接。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9edf9b991ca94674abb3793a48dad69e~tplv-goo7wpa0wc-image.image) </span>

<span id="4a8ee226"></span>
### 域名空间定义了直播流服务的配置

直播流地址的结构允许你通过指定域名、AppName 和 StreamName，在域名空间内识别特定流。

因此，我们可以使用**域名空间**、**域名**、**AppName**和**StreamName**来指定增值功能配置中有效流的范围。

以下是一个直播流地址示例。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8878d07015b04a368edb5bed2e017206~tplv-goo7wpa0wc-image.image) </span>

配置仅适用于特定域名空间，无法应用于其他空间的流。下图展示了不同层级的配置如何应用于域名空间内的不同流。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0ca52ea551a74c8cb241f58c6f584b96~tplv-goo7wpa0wc-image.image) </span>


* 域名空间：该增值功能配置适用于此域名空间内的所有流。

* 域名空间 + 域名：该增值功能配置适用于此域名空间内具有该域名的所有流。

* 域名空间 + AppName：该增值功能配置适用于此域名空间内具有该 AppName 的所有流。

* 域名空间 + AppName + StreamName：该增值功能配置适用于此域名空间内具有该 AppName 和 StreamName 的流。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">不同的增值配置适用于不同范围的流。详情请参阅各自的接口行为。</div>

## 操作流程

<span id="7d13ae58"></span>
### 将域名添加到现有域名空间

添加域名时，可以将其添加到现有域名空间，从而与该空间内的其他域名关联。


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**域名**。

3. 点击**添加域名**。

4. 在**关联域名空间**下选择一个已有的域名空间，然后添加域名。有关其他设置的更多信息，请参见[添加域名](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-domain)。


<span id="4540ea9c"></span>
### 修改域名的域名空间

添加域名后，如有需要，可以更改其域名空间。


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**域名**。点击域名右侧的**设置**。

3. 在**基本信息**标签页的**域名空间**区域，点击**域名空间**右侧的编辑图标。在弹窗中输入新的域名空间，并点击**确认**。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">不包含任何域名的域名空间会被自动移除。</div>
