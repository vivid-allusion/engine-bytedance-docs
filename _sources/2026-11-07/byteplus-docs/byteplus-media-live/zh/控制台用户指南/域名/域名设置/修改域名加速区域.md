为优化在线流的性能或满足区域合规要求，你可以修改域名的加速区域。本文档为你提供在 BytePlus MediaLive 控制台中，分别为推流和拉流域名更改加速区域的分步操作说明。

<span id="ccfa0f3a"></span>
## 前提条件


* 如果你的域名当前加速区域为**中国大陆以外**，则在将区域更改为**中国大陆**或**全球加速**前，必须完成中国大陆的ICP备案流程。

* 中国大陆与非中国大陆地区的刊例价不同。请[联系支持](https://console.byteplus.com/workorder/create)。


<span id="82b42909"></span>
## 操作步骤


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏，点击**域名**。

3. 点击你想要修改的域名的**设置**。

4. 在**基本信息**区域，点击**修改**。

5. 在弹窗中，选择新的加速区域，然后点击**确认**。
