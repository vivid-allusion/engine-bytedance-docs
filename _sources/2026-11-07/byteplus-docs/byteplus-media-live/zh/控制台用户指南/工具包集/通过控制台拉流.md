要直接在控制台快速测试和对比直播流，可以使用 **Web 拉流**工具。该工具集成了 BytePlus MediaLive Player SDK for Web，可便捷地预览播放效果，并在将 SDK 集成到您自己的应用前对比流质量。

Web Pull 集成了 BytePlus MediaLive Player SDK for Web。要将 SDK 集成到您自己的应用，请参阅 [Player SDK for Web：SDK 概览](https://docs.byteplus.com/docs/byteplus-media-live/docs-introduction-to-the-player-sdk-for-web)。

## 前提条件

Web Pull 提供默认拉流地址。如果您只是想体验 BytePlus MediaLive 的功能，例如播放、静音、弹幕和画中画（PiP），请使用该地址。如果要使用您自己的拉流地址，请在启动 Web Pull 前完成以下操作：

* 已配置 SSL 证书的拉流域名。更多信息，请参阅[添加域名](https://docs.byteplus.com/docs/byteplus-media-live/docs-domain)和[添加 SSL 证书 ](https://docs.byteplus.com/docs/byteplus-media-live/docs-https)。

* 将拉流域名与推流域名关联。详情请参阅[域名](https://docs.byteplus.com/byteplus-media-live/docs/domain)。

> **说明**

> Web Pull 仅支持 HTTPS 地址。要播放 HTTP 地址，请前往 [VePlayer](https://demo.byteplus.com/common/veplayer/v2/basic/example?tab=function-display)。该页面展示了 BytePlus MediaLive Player SDK for Web 提供的更多功能。

## 操作步骤

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航窗格中，选择**工具箱** \> **Web 拉流**。

3. 在**播放**页签，在**点击播放**按钮旁边的输入框中输入拉流地址。

   > **说明**

   > 如果您还没有地址，请点击**生成地址**并填写表单，以生成 M3U8 格式的地址。您也可以使用[地址生成器](https://docs.byteplus.com/byteplus-media-live/docs/address-generator)生成所需格式的地址。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e4fa3ac0a65b4ab58d903b85a88b02ec~tplv-goo7wpa0wc-image.image)

4. 在**播放对比**页签，在**播放对比**按钮旁边的输入框中输入多个拉流地址。

   > **说明**

   * > 支持最多 4 路直播流的播放和对比。

   * > 支持使用 2x 和 4x 放大镜实时对比画面细节。

   * > 支持查看对比详情，显示直播流码率和画质评分数据。

   * > 码率对比和画质对比将在 3 分钟后自动停止。请注意，画质对比数据可能需要一些时间生成。建议等待约 5 分钟后查看最终对比结果。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e490168bc1ed4ee8b51efe13a966bad4~tplv-goo7wpa0wc-image.image)
