使用 MediaLive 控制台中的地址生成器工具，为您的直播流生成推流和拉流地址。

> **说明**

> 有关地址拼接规则和生成方法的更多信息，请参见[生成直播流地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses)。

## 前提条件

* 您已添加用于推流和拉流的域名，并完成 CNAME 配置。有关更多信息，请参见[添加域名](https://docs.byteplus.com/docs/byteplus-media-live/docs-domain)和[添加 CNAME 记录](https://docs.byteplus.com/docs/byteplus-media-live/docs-adding-a-cname-record)。

* 如需执行以下操作，请启用 HTTPS：

   * 使用 BytePlus MediaLive 控制台提供的在线推流工具。

   * 使用 BytePlus MediaLive 控制台提供的在线播放工具。

   * 使用 HTTPS 推流或拉流地址。

   * 在浏览器环境中推送或播放 RTM 流。

      有关更多信息，请参见 [HTTPS 配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-https)。

* 如需对推流或拉流地址进行 URL 鉴权，必须启用 URL 鉴权。有关更多信息，请参见[配置 URL 鉴权](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication)。

* 如需生成转码流的拉流地址，必须完成转码配置。有关更多信息，请参见[管理转码配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。

* 如需生成特定协议的 ABR 流拉流地址，必须完成 ABR 配置并选择对应的协议类型。有关更多信息，请参见[管理自适应码率配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-an-hls-abr-task)。

* 如需生成加密流的拉流地址，必须完成加密配置。有关更多信息，请参见[管理加密配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-a-drm-encryption-task)。

## 操作步骤

1. 登录 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左侧导航栏中，选择**工具箱** \> **地址生成器**。

3. 选择**地址类型**和**域名**，并输入自定义的 `AppName`、`StreamName` 和过期时间。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/305f90015f364f2e8ce96f4f455612de~tplv-goo7wpa0wc-topic.webp)

   |参数 |说明 |
   |---|---|
   |地址类型 |选择要生成的地址类型。<br><br><br>* **推流地址**：使用此地址将直播流从主播端推送到 MediaLive。<br><br>* **拉流地址**：使用此地址将直播流从 MediaLive 拉取给观众。 |
   |域名 |根据地址类型，选择用于推流或拉流的域名。 |
   |AppName |生成地址的 `AppName`，可包含字母（A\-Z、a\-z）、数字（0\-9）、下划线（_）、连字符（\-）和英文句点（.），长度范围为 1 到 30 个字符。默认值为 `live`。<br><br>> **说明**<br><br><br>> 拉取指定直播流时，推流地址和拉流地址的 `AppName` 必须相同。<br> |
   |StreamName |生成地址的 `StreamName`，可包含字母（A\-Z、a\-z）、数字（0\-9）、下划线（_）和连字符（\-），长度范围为 1 到 100 个字符。<br><br>> **说明**<br><br><br>> 拉取指定直播流时，推流地址和拉流地址的 `StreamName` 必须相同。<br> |
   |到期时间 |选择地址的过期时间。<br><br>过期后，该地址不能再用于发起新的推流或拉流请求。过期前已发起的现有请求不受影响。<br><br>> **警告**<br><br><br>> 仅当所选域名已启用 URL 鉴权时，才能配置过期时间。如需启用 URL 鉴权，请参见[配置 URL 鉴权](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication)。<br> |

4. 单击**生成推流地址**或**生成拉流地址**，在**结果**区域获取推流或拉流地址。

   * **推流地址**：支持生成带鉴权信息的推流地址。地址生成器支持以下推流协议：RTMP、TS over SRT、RTMP over SRT 和 RTM。

      > **说明**

      * > 如果您使用 OBS（Open Broadcaster Software）通过 RTMP 推流，可以从生成结果中获取 **OBS 推流地址**和 **OBS Streaming Key**，并分别填入 OBS 的 **Server** 和 **Stream Key** 字段。

      * > 如需包含鉴权信息，必须先为推流域名启用 URL 鉴权。有关更多信息，请参见[配置 URL 鉴权](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication)。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c168f4ac83b440cd85c8caffef3d8286~tplv-goo7wpa0wc-topic.webp)

* **拉流地址**：支持为源流、转码流和 ABR 流生成带鉴权信息的拉流地址。地址生成器支持以下拉流协议：RTMP、FLV、HLS（M3U8）、RTM 和 DASH。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4ba7e572d98e4d6f83fb4492893052aa~tplv-goo7wpa0wc-topic.webp)

   * 在**拉流地址**页签中，可以找到两种 RTM 拉流地址。

      * **RTM Web SDK 播放地址**：使用此地址，通过 BytePlus MediaLive Player SDK for Web 进行播放。此地址会按如下方式触发自动转码：

         * 系统会自动检测直播流是否包含 B 帧。

            * 如果存在 B 帧：直播流会被转码以移除 B 帧，并收取标准转码费用。

            * 如果不存在 B 帧：会复制源流中的视频，不收取视频转码费用。

         * 系统会自动检测音频编码格式是否为 AAC 或 Opus。

            * 如果音频编码格式为 AAC：音频会转换为 Opus。如果不涉及视频转码，则收取纯音频转码费用。有关更多信息，请参见[纯音频转码](/docs/byteplus\-media\-live/docs\-transcoding#Audio transcoding)。

            * 如果音频编码格式为 Opus：会复制源流中的音频，不收取纯音频转码费用。

      * **RTM 地址**：使用此地址，通过客户端 SDK（适用于 iOS、Android、React Native 和 Flutter 的 BytePlus MediaLive Player SDK）以及其他播放器进行播放。

   * 在**转码流**页签中，可以选择转码后缀，以获取不同的转码流地址。您还可以找到两种 RTM 拉流地址。

      * **RTM Web SDK 播放地址**：使用此地址，通过 BytePlus MediaLive Player SDK for Web 进行播放。此 RTM 拉流地址会保留原始转码配置，并增加以下处理：

         * 系统会自动检测直播流是否包含 B 帧。

            * 如果存在 B 帧：直播流会被转码以移除 B 帧，其他设置遵循原始转码配置，并按原始转码配置收取转码费用。

            * 如果不存在 B 帧：直播流会按原始转码配置转码，并按原始转码配置收取转码费用。

         * 系统会自动检测音频编码格式是否为 AAC 或 Opus。

            * 如果音频编码格式为 AAC：音频会转换为 Opus，其他设置遵循原始转码配置，并按原始转码配置收取转码费用。

            * 如果音频编码格式为 Opus：会复制音频且不进行音频转码，其他设置遵循原始转码配置，并按原始转码配置收取转码费用。

      * **RTM 地址**：使用此地址，通过客户端 SDK（适用于 iOS、Android、React Native 和 Flutter 的 BytePlus MediaLive Player SDK）以及其他播放器进行播放。

   * 在**自适应码率**页签中，如果已在 ABR 配置中启用 RTM\-ABR，请选择启动清晰度档位（后缀），以获取对应的 RTM\-ABR 地址。您还可以找到两种 RTM\-ABR 拉流地址。

      * **RTM Web SDK 播放地址**：使用此地址，通过 BytePlus MediaLive Player SDK for Web 进行播放。此 RTM\-ABR 拉流地址会保留原始 ABR 配置，并增加以下处理：

         * 系统会自动检测子流是否包含 B 帧。

            * 如果存在 B 帧：子流会被转码以移除 B 帧，其他设置遵循原始 ABR 配置，并按原始 ABR 配置收取转码费用。

            * 如果不存在 B 帧：子流会按原始 ABR 配置转码，并按原始 ABR 配置收取转码费用。

         * 系统会自动检测音频编码格式是否为 AAC 或 Opus。

            * 如果音频编码格式为 AAC：音频会转换为 Opus，其他设置遵循原始 ABR 配置，并按原始 ABR 配置收取转码费用。

            * 如果音频编码格式为 Opus：会复制音频且不进行音频转码，其他设置遵循原始 ABR 配置，并按原始 ABR 配置收取转码费用。

      * **RTM 地址**：使用此地址，通过适用于 iOS 和 Android 的 BytePlus MediaLive Player SDK 以及其他播放器进行播放。

   > **说明**

   * > 如需包含鉴权信息，必须先为拉流域名启用 URL 鉴权。有关更多信息，请参见[配置 URL 鉴权](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication)。

   * > 如果无法获取 **RTM Web SDK 播放地址**，请联系[技术支持](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980)。

5. 您还可以：

   * 单击在线推流图标，在控制台的 **Web 推流**页面开始推流。

   * 单击在线播放图标，在控制台的 **Web 拉流**页面开始播放。

   * 单击复制图标，复制地址。

   * 单击二维码图标，查看二维码。

   * 单击页面右上角的**历史记录**，查看之前生成的地址记录。
