* 生效日期：2026 年 1 月 7 日

* 适用版本：自 2.11.0 版本起，集成拉流 SDK for Web 时需配置许可。如需了解更多信息，请参见[Step 3: 配置许可证](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-CN#f1396aa0)。
