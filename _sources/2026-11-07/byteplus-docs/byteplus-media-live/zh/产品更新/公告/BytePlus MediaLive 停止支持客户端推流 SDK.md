尊敬的开发者，

即日起，BytePlus MediaLive 将停止更新并移除客户端推流 SDK 的相关文档。受影响的 SDK 包括 BytePlus MediaLive **iOS、Android 和 React Native 推流 SDK**。


* **影响范围**

   * 新用户：如需推流 SDK，建议优先评估以下替代方案：

      * Web 推流 SDK：请使用 [BytePlus MediaLive Web 推流 SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-broadcast-sdk-for-web)。

      * 客户端推流 SDK：请使用火山引擎实时音视频提供的 [客户端 SDK](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-79882)。

   * 现有用户： 已集成并正在使用 BytePlus MediaLive 客户端推流 SDK 的现有用户不会受到影响。现有用户可以继续在 BytePlus 官网续费服务，并正常使用相关 SDK。

* **持续维护**

   自 **2026 年 8 月 7 日**起，BytePlus MediaLive 客户端推流 SDK 将不再提供功能更新或新版本。但仍会持续提供常规维护和漏洞修复。


如仍需使用 BytePlus MediaLive 客户端推流 SDK，或对本次变更有任何疑问，请 [提交工单](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980)联系 BytePlus 支持团队。
