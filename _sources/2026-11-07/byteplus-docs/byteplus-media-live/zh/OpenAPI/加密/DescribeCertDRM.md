获取 FairPlay 证书。播放器会将该证书与 DRM 许可证一起使用，以在 Apple 设备上解密经过 DRM 加密的直播流。

<span id="HTTP request"></span>
## HTTP 请求


* 方法：GET

* Endpoint：https://live\-gateway\-byteplus.byteintlapi.com/drm_api/?Action=DescribeCertDRM&Version=2023\-01\-01


<span id="Request parameters"></span>
## 请求参数

<span id="Common parameters"></span>
### 通用参数

所有 API 调用时，除了 API 专属参数外，还必须包含[通用参数](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters)。

<span id="Query"></span>
### 查询


|**参数** |**数据类型** |**是否必填** |**示例值** |**接口行为** |
|---|---|---|---|---|
|Action |String |是 |`DescribeCertDRM` |API 操作。 |
|Version |String |是 |`2023-01-01` |该 API 操作的版本。当前版本：2023\-01\-01。 |
|Vhost |String |是 |`drm.example.com` |域名空间。可调用[ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API 或访问 BytePlus MediaLive 控制台的[Domains](https://console.byteplus.com/live/main/domain/list)页面，获取域名所属的域名空间。 |
|应用 |String |是 |`live` |直播流 URL 中的 AppName 字段。可包含大写字母（A\-Z）、小写字母（a\-z）、数字（0\-9）、下划线（_）、连字符（\-）和点（.），长度范围为 1 到 30 个字符。 |


<span id="Response parameters"></span>
## 返回调用结果参数

该 API 仅在返回调用结果中返回[通用参数](https://docs.byteplus.com/en/byteplus-platform/reference/request-response)。

```json
GET https://live-gateway-byteplus.byteintlapi.com/drm_api/?Action=DescribeCertDRM&Version=2023-01-01&Vhost=drm.example.com&App=live
```

### 返回调用结果示例
