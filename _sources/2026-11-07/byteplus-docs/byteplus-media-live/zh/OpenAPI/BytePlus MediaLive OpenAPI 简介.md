BytePlus MediaLive OpenAPI 允许您管理您的域名和流，使用转码、录制等增值服务，查询用量数据和流统计信息，以及更多功能。

有关 BytePlus MediaLive OpenAPI 接口的完整列表，请参见 [BytePlus MediaLive OpenAPI 概览](https://docs.byteplus.com/byteplus-media-live/docs/openapi-overview)。

我们建议您使用 [Server SDK](https://docs.byteplus.com/byteplus-media-live/docs/server-sdk) 调用 OpenAPI。Server SDK 提供签名生成和常用 OpenAPI 操作等能力。

<span id="Getting started"></span>
## 快速入门


1. 为您的 BytePlus 账号开通 BytePlus MediaLive。详情请参见 [开通服务](https://docs.byteplus.com/docs/byteplus-media-live/docs-getting-started#da5a6a63)。

2. 服务已开启后，登录 [BytePlus 控制台](https://console.byteplus.com/)，点击页面右上角的账号名称，然后选择 **IAM** \> **密钥管理**，获取您的账号的 Access Key ID（AK）和 Secret Access Key（SK），用于 API 请求鉴权。


<span id="Limitation"></span>
## 限制

每个 API 接口都有调用频率限制，超出后将触发限流。请参见各接口的参考文档以获取对应的调用频率。
