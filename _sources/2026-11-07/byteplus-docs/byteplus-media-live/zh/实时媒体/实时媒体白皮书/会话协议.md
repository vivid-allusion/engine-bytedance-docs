本节介绍用于媒体协商的 SDP 和 MiniSDP 协议。

<span id="d0ac70ba"></span>
## SDP

**关于**：SDP（会话描述协议）是一种基于文本的格式（类似于 JSON/XML），具有特殊约定。用于在传输过程中描述媒体信息。

**结构**：SDP 遵循 `<type>=<value>` 的格式，其中 `<type>` 和 `<value>` 都区分大小写，且 `=` 两侧不能有空格。SDP 由会话级接口行为和零个或多个媒体级接口行为组成。会话级从 `v=` 开始，直到出现包含媒体级 `m=` 的第一行。每个媒体级接口行为以 `m=` 开始，持续到下一个 `m=` 或 SDP 结束。

SDP 中有些字段是必填（REQUIRED），有些字段是可选（OPTIONAL）。可选字段在下例中用 `*` 标记。所有字段必须按照示例中的顺序排列，以便于错误检测和解析器实现。

以下是 SDP 描述文档中使用的格式和字段示例：

**会话接口行为**

```Plain
v= (protocol version)
o= (originator and session identifier)
s= (session name)
i=* (session information)
u=* (URI of description)
e=* (email address)
p=* (phone number)
c=* (connection information -- not required if included in all media descriptions)
b=* (zero or more bandwidth information lines)
One or more time descriptions:
("t=", "r=" and "z=" lines; see below)
k=* (obsolete)
a=* (zero or more session attribute lines)
Zero or more media descriptions
```


**时间接口行为**

```Plain
t= (time the session is active)
r=* (zero or more repeat times)
z=* (optional time zone offset line)
```


**媒体接口行为（如有）** 

```Plain
m= (media name and transport address)
i=* (media title)
c=* (connection information -- optional if included at session level)
b=* (zero or more bandwidth information lines)
k=* (obsolete)
a=* (zero or more media attribute lines)
```


RFC 规范参考：[SDP](https://datatracker.ietf.org/doc/html/rfc8866)

## MiniSDP

**关于**：MiniSDP 协议是一种用于压缩标准 SDP 的二进制编码压缩协议。

**特性**：标准 SDP 较长（约 5\-10KB），不利于快速高效传输。在直播流场景下，这会影响首帧时间。MiniSDP 通过将原生 SDP 转换为更小的二进制格式，实现标准 SDP 文本协议的压缩，可通过 UDP 包进行传输。

**优势**：


* 信令交互更快，网络传输更高效。

* 直播流拉流的首帧渲染更快。

* 提升拉流即时加载率、成功率及其他 QoS 指标。
