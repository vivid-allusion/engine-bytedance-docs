超低延时直播功能（称为 Real Time Media，简称 RTM），采用先进的音视频处理技术以及大规模内容分发技术。通过将链路传输协议转换为 UDP，并优化其他底层技术，RTM 克服了 TCP 协议的固有限制，降低了因网络抖动导致的延迟。配合 BytePlus MediaLive 拉流 SDK，RTM 在千万级并发场景下可实现毫秒级延时。其速度远快于 FLV、HLS 及其他基于 TCP 的流媒体协议，这些协议通常延时为 3 到 10 秒。此外，RTM 提供高质量的观看体验，卡顿少、加载快，并兼容行业内常用的音视频编码格式。

<span id="bc9ec5a6"></span>
## 功能亮点

**平滑集成**

RTM 兼容 BytePlus MediaLive 现有的媒体处理能力，如转码、录制和截图。

RTM 兼容 TCP 推流协议。通过 RTMP 协议推流的流，可通过 RTM、RTMP、FLV 和 HLS 协议拉流。您可以使用现有域名轻松将 RTM 功能集成到当前直播方案中。

**高质量体验**

RTM 利用 WebRTC、QUIC 等多种协议的特性，并采用 UDP，将延迟降低至一秒以内。这带来更快的首帧渲染和更少的卡顿，提升核心性能指标。

**广泛兼容**

RTM 针对直播行业的特定需求，支持 AAC、B 帧、H.265 等高级音视频编码格式。

**安全可靠**

RTM 采用基于 UDP 的 MiniSDP 信令替代 HTTP 信令，优化建联时间和成功率，尤其适用于弱网络类型环境。

**大规模高并发**

RTM 已广泛应用于字节跳动商业应用，并持续优化，经过数亿并发用户的实际场景验证。

<span id="99821b12"></span>
## 应用场景

RTM 适用于以下场景：


* 电商：通过直播提升买卖双方互动，促进销售。

* 教育：RTM 适用于大规模在线课堂。其低延迟特性使学生能够回答教师问题并获得实时反馈。

* 体育：RTM 让在线观众实时体验赛事及电竞。

* 娱乐：主播可通过 RTM 实时反馈并与送礼观众互动。


<span id="044fb363"></span>
## RTM 使用

使用 RTM 功能时，将收取直播服务费用。上行按标准流计费，下行按 RTM 流计费。详情请参见[直播服务费用](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-live-streaming-service-fees)。

<span id="12a942c4"></span>
### 服务开通

在 BytePlus MediaLive 创建域名时，RTM 服务默认已开启。无需手动开通服务。

使用 RTM 拉流无需单独域名。RTM 已与 RTMP、FLV、HLS 集成。您只需使用 RTM 专属回放地址即可。

<span id="34760cd6"></span>
### 获取 RTM 拉流地址


1. 登录[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 使用[地址生成器](https://docs.byteplus.com/en/byteplus-media-live/docs/address-generator)生成 RTM 地址。你也可以手动构建该地址。更多信息，请参见[生成直播流地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses-zh-CN)。
