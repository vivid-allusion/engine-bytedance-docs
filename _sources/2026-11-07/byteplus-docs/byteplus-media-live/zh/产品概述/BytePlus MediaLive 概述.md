BytePlus MediaLive 是一款面向企业和个人的安全、稳定、专业的云端直播服务。基于先进的音视频处理和大规模内容分发技术，平台提供丰富的功能和增值服务，让您仅需几步即可搭建完整的流媒体平台。

<span id="Product architecture"></span>
## 产品架构

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/67c49ad57a6541038c270ce47403026a~tplv-goo7wpa0wc-image.image) </span>

BytePlus MediaLive 提供端到端的流解决方案：


* 您可以使用 Web 端的 Broadcast SDK 将流推送到服务器。该 SDK 还支持音视频采集、超低延迟流传输等功能。

* 服务器提供多种服务，包括域名和流管理、流和用量统计，以及转码、录制、截图等增值服务。您可以通过 [BytePlus MediaLive 控制台](https://docs.byteplus.com/byteplus-media-live/docs/introduction-to-the-media-live-console) 和 [OpenAPI](https://docs.byteplus.com/byteplus-media-live/docs/getting-started-with-your-api) 访问这些服务。

* 拉流 SDK 提供高质量的观看体验，包括超高清视频质量、快速首帧渲染和稳定回放。该 SDK 还会上报回放质量统计，帮助您快速定位问题并监控流性能。
