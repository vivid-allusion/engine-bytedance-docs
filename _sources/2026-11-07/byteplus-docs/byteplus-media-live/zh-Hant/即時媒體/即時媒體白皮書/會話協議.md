本節說明用於媒體協商的 SDP 與 MiniSDP 協議。

<span id="d0ac70ba"></span>
## SDP

**關於**：SDP（Session Description Protocol，會話描述協議）是一種基於文本的格式（類似於 JSON/XML），並具有特殊的規則。它用於在傳輸過程中描述媒體資訊。

**結構**：SDP 採用 `<type>=<value>` 的格式，其中 `<type>` 與 `<value>` 都區分大小寫，且 `=` 周圍不能有空格。SDP 由會話層描述以及零個或多個媒體層描述組成。會話層從 `v=` 開始，直到出現第一行包含媒體層 `m=` 為止。每個媒體層描述以 `m=` 開始，並持續到下一個 `m=` 或 SDP 結束。

SDP 中有些欄位是必填（REQUIRED），有些欄位則是選填（OPTIONAL）。選填欄位在下方範例中以 `*` 標註。所有欄位必須按照範例所示順序排列，以便於錯誤檢測與解析器實現。

以下為 SDP 描述文件的格式與欄位範例：

**會話描述**

```Plain
v= (protocol version)
o= (originator and session identifier)
s= (session name)
i=* (session information)
u=* (URI of description)
e=* (email address)
p=* (phone number)
c=* (connection information -- not required if included in all media descriptions)
b=* (zero or more bandwidth information lines)
One or more time descriptions:
("t=", "r=" and "z=" lines; see below)
k=* (obsolete)
a=* (zero or more session attribute lines)
Zero or more media descriptions
```


**時間描述**

```Plain
t= (time the session is active)
r=* (zero or more repeat times)
z=* (optional time zone offset line)
```


**媒體描述（如有）** 

```Plain
m= (media name and transport address)
i=* (media title)
c=* (connection information -- optional if included at session level)
b=* (zero or more bandwidth information lines)
k=* (obsolete)
a=* (zero or more media attribute lines)
```


RFC 規範參考：[SDP](https://datatracker.ietf.org/doc/html/rfc8866)

## MiniSDP

**關於**：MiniSDP 協議是一種用於壓縮標準 SDP 的二進位編碼壓縮協議。

**特點**：標準 SDP 長度較大（約 5\-10KB），不利於快速高效傳輸。在直播場景下，這會影響首幀呈現時間。MiniSDP 通過將原生 SDP 轉換為更小的二進位格式，可在 UDP 封包中傳輸，從而實現標準 SDP 文本協議的壓縮。

**優勢**：


* 訊號交互更快，網路傳輸更高效。

* 拉流首幀渲染時間更快。

* 提升拉流即時載入率、成功率及其他 QoS 指標。
