名為即時媒體（RTM）的超低延遲直播功能，採用先進的音視頻處理技術以及大規模內容分發技術。通過將鏈路傳輸協議轉換為 UDP 並優化其他底層技術，克服了 TCP 協議的固有限制，並減少因網路抖動造成的延遲。RTM 搭配 BytePlus MediaLive Player SDK 使用時，能在數千萬並發用戶直播時實現毫秒級延遲。其速度遠快於 FLV、HLS 及其他通常延遲為 3 至 10 秒的 TCP 流媒體協議。此外，RTM 提供高品質的觀看體驗，延遲低、載入快，並兼容業界常用的多種音視頻編碼格式。

<span id="bc9ec5a6"></span>
## 功能亮點

**無縫整合**

RTM 可與 BytePlus MediaLive 現有的媒體處理能力相容，如轉碼、錄製及截圖。

其可兼容 TCP 推流協議。以 RTMP 協議推送的流，可通過 RTM、RTMP、FLV 和 HLS 協議拉取。您可利用現有的域名，輕鬆將 RTM 功能整合至目前的直播架構。

**高品質體驗**

RTM 結合 WebRTC、QUIC 等多種協議特性，並採用 UDP，將延遲降至一秒以內。這可加快首幀渲染速度並減少卡頓，提升核心性能指標。

**廣泛兼容性**

RTM 針對直播行業的特定需求，支持 AAC、B 幀、H.265 等先進音視頻編碼。

**安全可靠**

RTM 採用基於 UDP 的 MiniSDP 信令取代 HTTP 信令，優化連接時間與成功率，特別適用於弱網環境。

**大規模高並發**

RTM 已廣泛應用於 ByteDance 商業應用，並持續優化，經過數億並發用戶的實地測試。

<span id="99821b12"></span>
## 應用場景

RTM 適用於以下場景：


* 電商：直播提升買賣雙方互動並促進銷售。

* 教育：RTM 適合大型線上課堂。其低延遲讓學生能即時回答老師問題並獲得即時回饋。

* 體育：RTM 讓線上觀眾可即時體驗比賽及電競。

* 娛樂：主持人可利用 RTM 即時回饋並與送禮觀眾互動。

## RTM 使用說明

使用 RTM 功能時，將收取直播服務費。上行按標準流媒體計費，下行按 RTM 流媒體計費。詳情請參見[直播服務費](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-live-streaming-service-fees)。

<span id="12a942c4"></span>
### 服務啟用

在 BytePlus MediaLive 創建域名時，RTM 服務預設啟用。無需手動啟用服務。

使用 RTM 拉流時，無需額外域名。RTM 已與 RTMP、FLV、HLS 整合。您只需使用 RTM 專屬播放地址即可。

<span id="34760cd6"></span>
### 獲取 RTM 拉流地址


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 使用[位址產生器](https://docs.byteplus.com/en/byteplus-media-live/docs/address-generator)來產生 RTM 位址。你也可以手動建立該位址。如需更多資訊，請參閱[產生直播串流地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses-zh-TW)。
