VePlayer 透過靈活的插件系統實現所有功能，從簡單的功能按鈕到複雜的播放邏輯皆可涵蓋。本主題將說明如何管理這些插件，以便自訂您的播放器。您將學習如何註冊新的自訂插件、停用或設定內建插件，甚至替換預設圖示並調整 UI 佈局。

<span id="60b4c346"></span>
## 自訂插件

<span id="ff3164db"></span>
### 註冊插件

VePlayer 支援兩種註冊插件的方法：初始化時註冊，以及初始化後註冊。

<span id="732e560d"></span>
#### **方法一：初始化時註冊**

初始化 VePlayer 實例時，您可以直接傳入插件名稱來註冊插件（內建插件無需註冊）。範例程式碼如下：

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://testpull.mycloud.com/live/mystream.m3u8',
  plugins: [window.VePlayerTimeShift],
  logger: {
    appId: '5****8',
  },
});
```


<span id="e7b00151"></span>
#### **方法二：初始化後註冊**

初始化 VePlayer 實例後，您可以呼叫 `registerPlugin` 方法並傳入插件名稱來註冊插件（內建插件無需註冊）。範例程式碼如下：

```JavaScript
VePlayer.createLivePlayer({
  //...
}).then(function(veplayer){
        veplayer.registerPlugin(window.VePlayerTimeShift)              
})
```


<span id="2d9e9af8"></span>
### 停用插件

VePlayer 提供多個內建功能插件。若需停用特定內建插件，可使用以下方法。


* 對於大多數插件，您可以將插件名稱（不區分大小寫）傳入 VePlayer 設定中的 `ignores` 屬性來停用。例如，若要停用子母畫面插件：

   ```JavaScript
   ignores: ['pip']
   ```
   

* 對於某些插件，也可透過設定其專屬選項來停用。請參閱 [具備 UI 的內建插件](https://docs.byteplus.com/docs/byteplus-media-live/docs-d8idjfeza4-zh-TW#f3cebefe) 的文件以取得更多詳細資訊。


<span id="382a06f9"></span>
### 設定插件

VePlayer 允許您傳入各插件名稱，以設定其專屬邏輯。例如，若要設定錯誤插件及其相關參數，可依下列方式操作：

```JavaScript
error: {
   errorTipsText: 'error message', // error message
   showRefresh: true, // whether to refresh the button
}
```


<span id="87497923"></span>
### 替換插件圖示

您可以透過設定來替換內建插件的按鈕圖示。支援圖示替換的插件清單可在 [內建插件圖示](https://docs.byteplus.com/docs/byteplus-media-live/docs-d8idjfeza4-zh-TW#2422295c) 設定中查詢。例如，若要將播放/暫停按鈕的圖示替換為自訂圖示，只需在設定中傳入欲替換圖片的 URL 或 DOM 節點即可。範例程式碼如下。

```JavaScript
import MyPlayIcon from '../icons/my-play-icon.svg';
import MyPauseIcon from '../icons/my-pause-icon.svg';

VePlayer.createLivePlayer({
  icons: {
    play: <img src={MyPlayIcon}>,
    pause: <img src={MyPauseIcon}>
  }
})
```

#### **設定掛載位置**

`position` 選項用於指定插件在使用者介面中的位置，即插件 UI 元素掛載於特定 DOM 節點的位置。VePlayer 定義了以下兩種位置。


* **Default layout:**  插件的 UI 元素依預設佈局排列與顯示。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f4cf056e7c7044cd82c0a102ca87b828~tplv-goo7wpa0wc-image.image) </span>

* **Flex layout:**  一種可根據螢幕大小與需求自動調整 UI 元素排列方式的彈性佈局。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/809477e999874cbbbd4bad4bf9b3c7f3~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若未指定 <code>position</code> 參數或 <code>root</code> 參數，插件的 UI 元素將預設掛載於根節點下。這表示插件會出現在預設位置。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">當播放器失去焦點時，位於 <code>ROOT_TOP</code>、<code>ROOT_RIGHT</code> 和 <code>ROOT_LEFT</code> 的插件會自動隱藏。這能提升使用者體驗，避免遮擋影片內容。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在行動裝置的小螢幕上，使用 <code>flex</code> 佈局時，位於中央位置的插件會自動適應螢幕尺寸。這通常用於顯示進度條等功能。這可確保插件功能能在有限螢幕空間內正確顯示。   </div>
   


<span id="cc61c91f"></span>
#### 設定佈局模式

控制插件的 `mode` 選項用於指定控制列的佈局方式。以下為三種佈局模式的視覺呈現：


* Normal：控制列中的插件會依設定順序以一般佈局模式顯示。

* Flex：彈性佈局模式可靈活調整控制列中插件的位置與大小，使其適應不同螢幕尺寸與佈局需求。

* 底部：底部佈局模式會將控制列放置於播放器底部，適合於行動裝置顯示，並提供更佳的觸控體驗。


<span id="5e3f2a1d"></span>
#### **設定 index**

`index` 選項是一個數值，用於決定插件在其父節點中的顯示順序。數值越小，插件優先級越高，會在父節點序列中較早顯示。當多個插件具有相同的 `index` 值時，其插入順序將依註冊順序決定。透過調整插件的 `index` 值，可以優化顯示順序，以符合特定需求與佈局。
