為提升行動裝置上的影片播放體驗，可實施多項關鍵優化措施。本主題提供提升相容性、減少即時串流延遲，以及透過移除特定 UI 元件與自訂錯誤訊息來調整播放器樣式的最佳實踐。

<span id="3f8f7725"></span>
## RTM 播放延遲優化

為改善不穩定網路環境下的播放流暢度，可調整緩衝延遲設定。以下為兩種常見整合方式：


<Tabs>
<Tab zoneid="prD2biDBYE" title="從 CDN">
<TabTitle>從 CDN</TabTitle>

建立播放器實例時，請於 RTM 模組中設定 `delayHint` 參數。程式碼範例：

```JavaScript
VePlayer.createLivePlayer({
    url: 'XXXX.sdp',
    rtm: {
        // 設定緩衝延遲為 1 秒
        delayHint: 1
    }
}) 
```



</Tab>
<Tab zoneid="s0BTmj24Gi" title="透過 NPM">
<TabTitle>透過 NPM</TabTitle>

建立播放器實例時，請於 RTM 模組中設定 `delayHint` 參數。程式碼範例：

```JavaScript
import { createLivePlayer, register } from '@byteplus/veplayer';
import { rtm } from '@byteplus/veplayer-plugin';
import '@byteplus/veplayer/style'

register([rtm]);

createLivePlayer({
    url: 'XXXX.sdp',
    rtm: {
        // 設定緩衝延遲為 1 秒
        delayHint: 1
    }
})
```



</Tab>
</Tabs>

## 行動裝置樣式配置

若需移除行動裝置上的預設 H5 樣式，可依照下列步驟操作。

<span id="43301374"></span>
### 移除特定圖示

可透過設定 `ignores` 選項來移除不需要的插件圖示。此舉可自訂播放器介面上顯示的圖示，例如 `start`、`enter` 及 `unmute` 按鈕。

<span id="6a1820b4"></span>
### 移除 H5 陰影覆蓋效果

預設情況下，H5 播放器可能會在影片區域的上下方顯示陰影覆蓋效果，如下圖所示。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/696ee2f4c3974c7d8ea29ac0ec5f90df~tplv-goo7wpa0wc-image.image) </span>

如需移除此覆蓋效果，請使用以下程式碼。

```JavaScript
mobile: {
    gradient: 'none',
}
```


<span id="24e3a121"></span>
### 自訂錯誤訊息

若使用預設錯誤顯示插件，可透過兩種方式自訂錯誤訊息。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/58d79030e8fc4e8682a6a48b463c1683~tplv-goo7wpa0wc-image.image) </span>


<Tabs>
<Tab zoneid="qnF1tOKDYo" title="覆寫所有錯誤訊息">
<TabTitle>覆寫所有錯誤訊息</TabTitle>

如需以單一自訂訊息覆寫所有錯誤訊息，請於 `error` 區段設定 `errorTipsText` 參數，如下所示：

```JavaScript
error: {
  errorTipsText: { 'en': 'Custom Error Info' }
}
```



</Tab>
<Tab zoneid="R9Nts9Ugl5" title="自訂特定錯誤訊息">
<TabTitle>自訂特定錯誤訊息</TabTitle>

如需為特定錯誤類型定義自訂訊息，請於 `i18n` 區段進行設定：

```JavaScript
i18n: {
          texts:{
            'en': {
              MEDIA_ERR_ABORTED: 'Custom Error Info', // 對應錯誤碼 5101 或 1
              MEDIA_ERR_NETWORK:  'Custom Error Info', // 對應錯誤碼 5102 或 2
              MEDIA_ERR_DECODE: 'Custom Error Info', // 對應錯誤碼 5103 或 3
              MEDIA_ERR_SRC_NOT_SUPPORTED: 'Custom Error Info', // 對應錯誤碼 5104 或 4
              NETWORK: 'Custom Error Info', // 對應錯誤碼 2100
              NETWORK_TIMEOUT: 'Custom Error Info', //  對應錯誤碼 2101
              NETWORK_FORBIDDEN: 'Custom Error Info', //  對應錯誤碼 2103
              NETWORK_NOTFOUND: 'Custom Error Info', //  對應錯誤碼 2104
            }
          }
        },
```



</Tab>
</Tabs>
