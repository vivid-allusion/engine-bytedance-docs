為了收集播放資料以進行故障排查與分析，你可以在 Web 端播放器 SDK（VePlayer）中啟用播放日誌與報告功能。此功能會將與播放相關的資訊發送至 BytePlus MediaLive 伺服器進行診斷，有助於提升應用程式的穩定性與用戶體驗。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議你使用最新版本的 Web 端播放器 SDK。如需版本資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。如需舊版資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="前提条件"></span>
## 先決條件

你已整合 Web 端播放器 SDK。如需更多資訊，請參閱[整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="集成步骤"></span>
## 整合步驟


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live/main/sdk)，進入**應用管理**頁面，找到你現有 Web 應用的**AppID**。

2. 將`appId`傳遞給播放器設定中的`logger`欄位以啟用日誌功能。請參考下方的程式碼範例。

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1"><code>appId</code>可唯一識別你的 Web 應用，且<strong>必須正確設定</strong>。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">自 2.5.1 版本起，若未設定<code>appId</code>，將觸發主控台錯誤，且 SDK 會使用預設<code>appId</code>上報日誌。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">我們強烈建議同時傳遞 userId 與 deviceId。這些識別碼有助於更有效地定位播放問題。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">若未提供<code>userId</code>與<code>deviceId</code>，SDK 會根據用戶的瀏覽器自動生成隨機值並儲存在本地。   </div>
   

   
   <Tabs>
   <Tab zoneid="kOYWDzXg2P" title="來自 CDN">
   <TabTitle>來自 CDN</TabTitle>
   
   ```JavaScript
   VePlayer.createLivePlayer({
     width: 640,
     height: 360,
     url: 'https://pulldomain/appname/mystream.flv',
     logger: {
       appId: '2****4',
       userId: '1********6',
       deviceId: '3********7',
     },
   });
   ```
   
   
   
   </Tab>
   <Tab zoneid="SxgxTIKgJn" title="透過 NPM">
   <TabTitle>透過 NPM</TabTitle>
   
   ```JavaScript
   import { createLivePlayer, register } from '@byteplus/veplayer';
   import { flv } from '@byteplus/veplayer-plugin';
   import '@byteplus/veplayer/style'
   
   register([flv]);
   
   createLivePlayer({
     width: 640,
     height: 360,
     url: 'https://pulldomain/appname/mystream.flv',
     logger: {
       appId: '2****4',
       userId: '1********6',
       deviceId: '3********7',
     },
   });
   ```
   
   
   
   </Tab>
   </Tabs>
   

3. 若你在直播過程中遇到播放問題，請收集相關資訊（如播放時間與觀察到的現象），並[聯繫技術支援](https://console.byteplus.com/workorder/create)。
