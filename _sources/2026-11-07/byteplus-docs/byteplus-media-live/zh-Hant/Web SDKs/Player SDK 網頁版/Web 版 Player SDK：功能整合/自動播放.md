本主題說明如何使用 Player SDK for Web（VePlayer）在頁面加載後實現影片自動播放。內容涵蓋常見瀏覽器與 WebView 環境的適配策略、配置方法以及播放失敗的處理方式，協助你在多平台上提供更穩定的自動播放體驗。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議你使用最新版 Player SDK for Web。如需版本資訊，請參見<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。如需舊版資訊，請參見<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="f443dd0b"></span>
## 功能概述

自動播放允許影片在頁面加載時自動開始播放，無需用戶互動。自動播放會受到瀏覽器政策的限制，是否允許自動播放取決於當前環境。允許自動播放的常見條件包括靜音播放與用戶互動。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">由於這些限制，自動播放可能會在部分裝置或瀏覽器上被阻止。建議你在設計應用時以用戶體驗為核心，避免強制自動播放。</div>


<span id="前提条件"></span>
## 前置條件

你已集成 Player SDK for Web。如需更多資訊，請參見[整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="配置自动播放"></span>
## 自動播放配置

VePlayer 支援透過`autoplay`配置選項實現自動播放。詳細配置選項請參考[LiveVePlayerOptions](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1155423)。自動播放是否成功取決於當前環境下瀏覽器的自動播放政策。

<span id="浏览器环境"></span>
### 瀏覽器環境下

在標準網頁瀏覽器中，若符合以下**任一**條件，自動播放將會成功：


|條件類別 |說明 |
|---|---|
|靜音播放 |影片已靜音（`muted: true`）或音量設為 0。這是啟用自動播放最可靠的方法。 |
|用戶互動 |用戶與頁面互動（點擊、滾動、鍵盤輸入等）後允許自動播放。 |
|網站允許清單 |瀏覽器可能根據用戶互動歷史，對網站授予自動播放權限。 |
|用戶設定 |部分瀏覽器允許用戶手動為特定網站授予自動播放權限。 |
|權限委派 |若影片嵌入於`<iframe>`中，且頂層頁面擁有自動播放權限，則該權限可委派給 iframe。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">更多詳情請參見<a href="https://www.chromium.org/audio-video/autoplay/">Google Chrome</a>與<a href="https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/">WebKit</a>的自動播放政策。</div>


<span id="WebView 环境"></span>
### WebView 環境下

在如 WebView 等嵌入式瀏覽器中，自動播放可能需要額外配置。

<span id="Android WebView"></span>
#### Android WebView

預設情況下，Android WebView**會阻止非靜音自動播放**。建議按如下方式將 VePlayer 配置為**靜音自動播放**：

```javascript
VePlayer.createLivePlayer({
    autoplay: { muted: true }
}).then(function(veplayer) {
    // Player instance
});
```


如需允許非靜音自動播放（除非經過審慎評估，否則不建議），請將[setMediaPlaybackRequiresUserGesture](https://developer.android.com/reference/android/webkit/WebSettings.html#setMediaPlaybackRequiresUserGesture(boolean))設為`false`：

```java
myWebView.getSettings().setMediaPlaybackRequiresUserGesture(false);
```


<span id="iOS WebView"></span>
#### iOS WebView

iOS WebView 也會預設阻止帶聲音的影片自動播放。請按如下方式配置靜音自動播放：

```javascript
VePlayer.createLivePlayer({
    autoplay: { muted: true }
}).then(function(veplayer) {
    // Player instance
});
```


如需允許非靜音自動播放，請將[mediaTypesRequiringUserActionForPlayback](https://developer.apple.com/documentation/webkit/wkwebviewconfiguration/1851524-mediatypesrequiringuseractionfor)設為`NO`：

```objectivec
[self.webView mediaTypesRequiringUserActionForPlayback:NO];
```


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">當 iOS 裝置處於低電量模式時，自動播放可能會被阻止。</div>


<span id="微信内置浏览器环境"></span>
### 檢測自動播放是否成功

由於瀏覽器政策較為複雜，建議以程式方式驗證自動播放是否成功。

<span id="方法一：监听 play() 方法的 Promise 返回"></span>
### 方法一：使用`play()` Promise

`veplayer.play()`方法會回傳一個 Promise 物件。


* `已解決的 Promise`：播放已成功開始。

* `被拒絕的 Promise（NotAllowedError）`：自動播放被瀏覽器政策阻止。


範例：

```javascript
let startPlayPromise = veplayer.play();

if (startPlayPromise !== undefined) {
  startPlayPromise
    .catch(error => {
      if (error.name === "NotAllowedError") {
        // Autoplay was blocked by the browser
        // You can retry playback with muted audio, or prompt the user to click a play button
      } else {
        // Other playback-related errors occurred
      }
    })
    .then(() => {
      // Playback started successfully
      // Continue with any post-playback logic here
    });
}
```


<span id="方法二：监听 AUTOPLAY_PREVENTED 事件"></span>
### 方法二：監聽`AUTOPLAY_PREVENTED`事件

當自動播放被瀏覽器阻止時，Web Player SDK 會觸發`AUTOPLAY_PREVENTED`事件。你可以處理此事件以實現備援邏輯。

範例：

```javascript
VePlayer.createLivePlayer({
  autoplay: { muted: false }
}).then(function (veplayer) {
  // Listen for autoplay prevention event
  veplayer.on(VePlayer.live.Events.AUTOPLAY_PREVENTED, () => {
    console.log('Autoplay was blocked by the browser');
    // Add fallback logic here, such as prompting the user to tap a play button
  });
});
```
