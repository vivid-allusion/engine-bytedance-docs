自適應位元率（ABR）是一種以觀眾為中心的影片傳輸技術，旨在無論網路狀況如何波動，都能提供流暢且高品質的播放體驗。您需預先配置多個子串流，分別採用不同的編碼格式、解析度及位元率，播放器會根據觀眾的即時網路狀況自動選擇最佳串流，以兼顧播放流暢度與影片品質。本主題說明如何使用 Player SDK for Web 為 HLS、RTM 和 FLV 串流配置 ABR 功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">我們建議您使用最新版本的 Player SDK for Web。有關版本資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。如需舊版資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>

您已整合 Player SDK for Web。如需更多資訊，請參閱 [整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

## 播放 HLS\-ABR 串流

<span id="8c72c128"></span>
### Step 1: Add an ABR configuration


1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，選擇 **功能配置**，並點擊右側的 **自適應位元率** 分頁。

3. 從 **網域名稱空間**下拉選單中選擇所需的網域名稱空間，然後點擊 **新增配置**。

4. 於 **基本資訊** 分頁中，輸入您的推流地址中的 `AppName`，並將 **HLS\-ABR** 設為 **協議類型**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/52e6b604233348f1acedd0433ec2038e~tplv-goo7wpa0wc-image.image) </span>

5. 點擊 **新增子串流**，為播放器可根據觀眾網路狀況切換的每個品質等級配置子串流。


其他設定請參閱 [管理自適應位元率設定](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-TW)。

<span id="2694fc4d"></span>
### Step 2: Get the HLS\-ABR address for your ABR stream

您可透過以下方式取得 HLS\-ABR 地址：


* **除錯用途**：在 **自適應位元率** 分頁使用 [地址產生器](https://console.byteplus.com/live/main/locationGenerate)取得 **HLS\-ABR 地址**。如需更多資訊，請參閱 [產生串流位址](https://docs.byteplus.com/docs/byteplus-media-live/docs-relay-zh-TW)。

* **正式環境**：呼叫 [GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023) 或使用 [伺服器端 SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-server-sdk)動態產生 HLS\-ABR 地址。


<span id="3083dd6e"></span>
### （選用）Step 3: Import and register plugins when using the NPM method

若您使用 NPM 方法導入依賴，必須導入並註冊 `abr` 和 `hlsjs` 插件，以確保 ABR 功能與 HLS 播放可用。

範例程式碼如下。

```JavaScript
import { hlsjs, abr } from '@byteplus/veplayer-plugin';
register([hlsjs, abr]);
```


<span id="396240fa"></span>
### Step 4: Configure ABR

建立播放器時，您可配置 ABR 功能並監聽品質等級切換事件。


* **配置 ABR 功能**：SDK 預設啟用 ABR 功能。您只需提供 HLS\-ABR 地址。播放器會請求該地址並取得主播放清單，該清單作為所有可用子串流（如 1080p、720p）的導引。播放器會持續監控觀眾的網路狀況，並自動在這些子串流間切換。當網路狀況不佳時，播放器會選擇較低位元率的串流以減少緩衝，網路改善後則無縫切回較高位元率串流，確保最佳且不中斷的觀看體驗。

* **監聽品質等級切換事件**：若需在切換品質等級時實現自訂邏輯，例如更新 UI 或回報切換資料，您可監聽以下事件：

   * `ABR_SWITCH_START`：開始切換品質等級。

   * `ABR_SWITCH_SUCCESS`：品質等級切換成功。

   * `ABR_SWITCH_FAILED`：品質等級切換失敗。


範例程式碼如下。

## 播放 RTM\-ABR 串流

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">要播放 RTM\-ABR 串流，請確保已整合 Player SDK 2.12.0 或更高版本。</div>


<span id="ef109318"></span>
### Step 1: Add an ABR configuration


1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，選擇 **功能配置**，並點擊右側的 **自適應位元率** 分頁。

3. 從**Domain name space**下拉選單中選擇你想要的網域名稱空間，然後點擊**Add configuration**。

4. 在**Basic information**標籤頁，輸入你的推流地址中的`AppName`，並選擇**RTM\-ABR**作為**Protocol Type**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/987feb246fd04cb0acf9d2dbe8bcda88~tplv-goo7wpa0wc-image.image) </span>

5. 點擊**Add substream**，為播放器可根據觀眾網路狀況切換的每個畫質等級配置子流。


其他設定請參見[管理自適應位元率設定](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-TW)。

<span id="cd6f509c"></span>
### Step 2: 取得 RTM\-ABR 拉流地址

你可以透過以下方式之一取得 RTM\-ABR 拉流地址。


* **For debugging**：使用[Address generator](https://console.byteplus.com/live/main/locationGenerate)，並選擇啟動畫質等級（後綴），在**Adaptive bitrate**標籤頁取得**RTM Web SDK 播放地址**。更多資訊請參見[Generating stream addresses](https://docs.byteplus.com/docs/byteplus-media-live/docs-address-generator)。

* **For production**：呼叫[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023)或使用[server-side SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-server-sdk)動態生成 RTM\-ABR 拉流地址。不同的後綴對應不同的啟動畫質等級。選擇一個地址作為播放 URL。請確保`Protocol`的值為`udp_websdk`。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">若無法取得 RTM\-ABR 拉流地址，請聯絡<a href="https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980">技術支援</a>。</div>


* <div data-tips="true" data-tips-type="warning">RTM\-ABR 拉流地址支援自動轉碼，包括移除 B\-frame 及 AAC 音訊轉換為 Opus。如需更多資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses-zh-TW">產生直播串流地址</a>。</div>

### Step 4: 配置 ABR

建立播放器時，你可以配置 ABR 功能並監聽畫質切換事件。


* **Configure ABR feature**：SDK 預設啟用 ABR 功能。你只需提供一個 RTM\-ABR 拉流地址。RTM\-ABR 拉流地址中的後綴決定啟動畫質等級。播放期間，MediaLive 會根據觀眾的網路狀況自動切換畫質等級。當網路狀況不佳時，MediaLive 會切換至較低碼率的串流以減少緩衝，並在網路改善時無縫切回較高碼率串流，確保最佳且不中斷的觀看體驗。

* **Listen for quality level switch events**：若你要在切換畫質等級時實現自訂邏輯，例如更新 UI 或回報切換資料，可以監聽以下事件：

   * `ABR_SWITCH_START`：開始切換畫質等級。

   * `ABR_SWITCH_SUCCESS`：畫質等級切換成功。

   * `ABR_SWITCH_FAILED`：畫質等級切換失敗。


範例程式碼如下。

## 播放 FLV 串流

<span id="f93c3f0f"></span>
### Step 1: 新增 ABR 配置


1. 登入[BytePlus MediaLive console](https://console.byteplus.com/live)。

2. 在左側導覽窗格選擇**Feature configuration**，並點擊右側的**Adaptive bitrate**標籤頁。

3. 從**Domain name space**下拉選單中選擇你想要的網域名稱空間，然後點擊**Add configuration**。

4. 在**Basic information**標籤頁，輸入你的推流地址中的`AppName`。

5. 點擊**Add substream**，為播放器可根據觀眾網路狀況切換的每個畫質等級配置子流。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a205a874210a4d3e9b8fc9500735ef21~tplv-goo7wpa0wc-image.image) </span>


其他設定請參見[管理自適應位元率設定](https://docs.byteplus.com/docs/byteplus-media-live/standbystream-zh-TW)。

<span id="ef0650ed"></span>
### Step 2: 取得不同畫質等級的 FLV 拉流地址

使用[Address generator](https://console.byteplus.com/live/main/locationGenerate)，在右側生成並取得指定畫質等級的 FLV 拉流地址。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/795e50db176d41db8d3a03069538a2c4~tplv-goo7wpa0wc-image.image) </span>


* **Address type**：選擇**Pull stream address**。

* **Domain name**：選擇在新增 ABR 配置時所使用的域名空間內用於拉流的域名。

* **AppName** 和 **StreamName**：請根據你的推流地址確定這兩個欄位的值。若你的推流地址為 `rtmp:// push.example.com/live/test?authinfo`：

   * **AppName**：`AppName` 為域名之後的地址部分。此時應填寫 `live`。

   * **StreamName**：首先，從地址中識別**base stream name**，即 `test`。然後，針對每個畫質等級，在此基礎名稱後加上對應的子流後綴。例如：

      * UHD 畫質等級請填寫 `test_uhd`

      * HD 畫質等級請填寫 `test_hd`

   請以此方式記錄每個畫質等級對應的 FLV 拉流地址。


**範例**

下表列出了不同畫質等級的 FLV 拉流地址範例及對應的碼率值。


|畫質等級 |FLV 拉流地址 |位元率（kbps） |
|---|---|---|
|超高畫質（UHD） |https://pull.example.com/live/123456_uhd.flv |3200 |
|高畫質（HD） |https://pull.example.com/live/123456_hd.flv |2048 |
|標準畫質（SD） |https://pull.example.com/live/123456_sd.flv |1638 |
|低畫質（LD） |https://pull.example.com/live/123456_ld.flv |1024 |


<span id="82250019"></span>
### （可選）Step 3: 使用 NPM 方式時導入並註冊插件

若你採用 NPM 方式導入依賴，則必須導入並註冊 `flv` 和 `abr` 插件，以確保低延遲 FLV 及 ABR 功能可用。範例程式碼如下。

```JavaScript
import { flv, abr } from '@byteplus/veplayer-plugin'
register([flv, abr]);
```


由於部分行動裝置瀏覽器（如 iOS 16 之前的 Safari）無法播放 FLV 流，為確保直播在這些裝置上仍可正常播放，SDK 提供 HLS 回退方案。啟用該方案後，當播放器偵測到當前瀏覽器不支援播放 FLV 流時，會自動切換至備用的 HLS 流進行播放。為確保回退功能正常運作，若你通過 NPM 導入依賴，也請務必導入並註冊 `hlsjs` 插件。範例程式碼如下。

```JavaScript
import { flv, hlsjs, abr } from '@byteplus/veplayer-plugin';
register([flv, hlsjs, abr]);
```


<span id="fb64008c"></span>
### Step 4: 在 SDK 中配置 ABR 並啟用低延遲 FLV

建立播放器時，可使用以下配置，為觀眾提供低延遲、流暢且全平台兼容的直播體驗：


* **Configure ABR feature**：SDK 預設啟用 ABR 功能。你只需提供包含多個碼率及其對應 FLV 拉流地址的列表。播放器會根據觀眾的網路狀況，在直播過程中自動切換畫質等級，確保播放流暢並兼顧畫質。

* **Listen for quality level switch events**：如需在切換畫質等級時實現自訂邏輯（如更新 UI 或上報切換數據），可監聽以下事件：

   * `ABR_SWITCH_START`：開始切換畫質等級。

   * `ABR_SWITCH_SUCCESS`：畫質等級切換成功。

   * `ABR_SWITCH_FAILED`：畫質等級切換失敗。

* **Mobile HLS fallback solution**：部分行動裝置瀏覽器（如 iOS 16 之前的 Safari）不支援播放 FLV 流。為確保直播可在這些裝置上正常播放，配置 FLV 拉流地址時可同時提供備用的 HLS 拉流地址。當播放器偵測到當前瀏覽器不支援播放 FLV 流時，會自動切換至 HLS 流進行播放。


範例程式碼如下。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">為確保 ABR 功能正常運作，請確認您在程式碼中為每個畫質等級設定的位元率與控制台 ABR 設定一致。</div>


<div data-tips="true" data-tips-type="warning"><strong>請特別注意單位換算：</strong></div>



* <div data-tips="true" data-tips-type="warning"><strong>控制台中的位元率單位：</strong> <code>kbps</code></div>


* <div data-tips="true" data-tips-type="warning"><strong>程式碼中的位元率單位：</strong> <code>bps</code></div>



<div data-tips="true" data-tips-type="warning">因此，程式碼中設定的位元率值必須是控制台值的<strong>1000</strong>倍。</div>


<div data-tips="true" data-tips-type="warning">例如，若控制台設定為<code>3200</code> kbps，則程式碼中應傳入<code>3200000</code>。</div>

<Tab zoneid="EtAiZtSztJ" title="CDN">
<TabTitle>CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
    width: 640,
    height: 360,
    playlist: [
      {
        definitions: [
          // FLV pull stream address for the initial playback quality level.
          'https://pull.example.com/live/123456_uhd.flv',
          // 備援播放的 HLS拉流地址，可透過控制台地址生成器產生。
          'https://pull.example.com/live/123456_uhd.m3u8',
        ],
      },
    ],
    flv: {
      abr: {
        // Bitrate for the initial playback quality level.單位為 bps。
        bitrate: 3200000,
        // 各畫質等級的位元率及 FLV 拉流地址。位元率單位為 bps。
        urls: {
          3200000: 'https://pull.example.com/live/123456_uhd.flv',
          2048000: 'https://pull.example.com/live/123456_hd.flv',
          1638000: 'https://pull.example.com/live/123456_sd.flv',
          1024000: 'https://pull.example.com/live/123456_ld.flv',
         }
     }
  },
    fallback: {
      // 優先播放低延遲 FLV 串流。當播放器偵測到目前瀏覽器無法播放低延遲FLV 串流時，將自動切換為 HLS 串流播放。
      fallbackOrder: ['ll-flv', 'hls'],
    }
}).then(function (veplayer) {
    // Listen for quality level switching events.
    veplayer.on(VePlayer.live.Events.ABR_SWITCH_START, function (data) {
```
