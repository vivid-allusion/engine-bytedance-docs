本主題將指導你如何使用 Player SDK for Web（VePlayer），在連接具有 URL 驗證的直播系統時，偵測並處理因拉流地址過期導致的播放失敗，從而確保觀眾能夠順暢觀看直播。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議你使用最新版 Player SDK for Web。如需版本資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。舊版資訊請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="7af6b48c"></span>
## 使用場景

若你的直播系統已啟用[URL 驗證](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-url-authentication)，所產生的拉流地址通常會有有效期限。當拉流地址過期時（例如，觀眾在頁面停留過久），可能會出現以下問題：


* 播放器無法獲取流，導致播放中斷。

* 觀眾會看到錯誤訊息，無法繼續觀看直播。


為避免播放中斷，你必須**取得新的拉流地址**並**即時切換播放器來源**，可在現有地址過期前或偵測到失敗後立即執行。

<span id="实现流程"></span>
## 工作流程


1. 初始化播放器時，請使用有效且已驗證的拉流地址。

2. 設置錯誤監聽器或計時器，主動偵測地址過期。

3. 使用你的後端伺服器呼叫[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023) API，以取得新的有效拉流地址。

4. 使用`veplayer.switch()`方法切換流來源。


<span id="前提条件"></span>
## 先決條件


* 你已整合 Player SDK for Web。如需更多資訊，請參閱[整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

* 你的串流設置已啟用[URL 驗證](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-url-authentication)。

* 你的系統必須能夠呼叫[GeneratePlayURL](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-generateplayurl-2023) API，動態產生新的已驗證拉流地址。


<span id="配置示例"></span>
## 配置範例

你可以使用`veplayer.switch(newUrl)`方法，動態更新拉流地址。以下範例展示如何透過 CDN 與 NPM 兩種整合方式實現：


<Tabs>
<Tab zoneid="FLSdaMCQpK" title="CDN 方式">
<TabTitle>CDN 方式</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://testpull.mycloud.com/live/mystream.m3u8?{authParams}',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // New pull stream address with refreshed authentication
  const newUrl =
    'https://testpull.mycloud.com/live/mystream.m3u8?{newAuthParams}';
  // Update the stream source
  veplayer.switch(newUrl);
});
```



</Tab>
<Tab zoneid="jld10AkgIO" title="NPM 方式">
<TabTitle>NPM 方式</TabTitle>

```JavaScript
import { createLivePlayer, register } from '@byteplus/veplayer';

import '@byteplus/veplayer/style'

createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://testpull.mycloud.com/live/mystream.m3u8?{authParams}',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // New pull stream address with refreshed authentication
  const newUrl =
    'https://testpull.mycloud.com/live/mystream.m3u8?{newAuthParams}';
  // Update the stream source
  veplayer.switch(newUrl);
});
```
