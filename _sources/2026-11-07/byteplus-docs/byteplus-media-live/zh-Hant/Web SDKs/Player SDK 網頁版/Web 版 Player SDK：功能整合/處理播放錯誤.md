為了識別問題並提升播放器的容錯能力，你可以使用 Player SDK for Web（VePlayer）來監聽播放錯誤。本主題提供程式碼範例，說明如何綁定 `ERROR` 事件，並在事件處理器中處理特定錯誤碼。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議你使用最新版的 Player SDK for Web。如需版本資訊，請參見 <a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。如需舊版資訊，請參見 <a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="70cf27ae"></span>
## 先決條件

你已整合 Player SDK for Web。如需更多資訊，請參見 [整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="921af388"></span>
## 設定範例

建立直播播放器實例後，你可以透過綁定 `ERROR` 事件來監聽播放錯誤。然後你可以在事件處理器中處理特定錯誤碼。

如需完整錯誤碼及其說明，請參見 [Error Code Reference](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1158675)。


<Tabs>
<Tab zoneid="kGMLlxxr4u" title="來自 CDN">
<TabTitle>來自 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://pulldomain/appname/mystream.m3u8',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  function errorHandler(error) {
    console.log('The error that occurs', error);
    console.log('The error code', error.errorCode);
    console.log('The error message', error.message);
  }
  // Listen for the ERROR event
  veplayer.on(VePlayer.live.Events.ERROR, errorHandler);
});        
```
