為了實現播放器狀態監控、日誌上報以及動態 UI 更新等功能，您可以使用 Player SDK for Web（VePlayer）來監聽與播放相關的事件。本主題提供了程式碼範例，展示如何使用 `on`、`once` 和 `off` 方法來有效地新增與移除事件監聽器。

## 先決條件

您已整合 Player SDK for Web。如需更多資訊，請參閱 [整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="89738846"></span>
## 配置範例

Web Player SDK 支援多種播放事件，例如：


* `PLAY` – 播放開始

* `ERROR` – 播放發生錯誤

* `PAUSE` – 播放暫停


這些事件可用於觸發 UI 更新或處理播放異常。完整支援事件列表，請參閱 [事件參考](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-1158676)。

成功建立直播播放器實例後，請使用 `on`、`once` 和 `off` 方法來新增與移除事件監聽器。


<Tabs>
<Tab zoneid="Xz05O8j35w" title="來自 CDN">
<TabTitle>來自 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  width: 640,
  height: 360,
  url: 'https://pulldomain/appname/mystream.m3u8',
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  function eventHandler(data) {
    console.log('Event callback data:', data);
  }

  // Add an event listener
  veplayer.on(VePlayer.live.Events.PLAY, eventHandler);

  // Add a one-time event listener
  veplayer.once(VePlayer.live.Events.PLAY, eventHandler);

  // Remove a specific event listener
  veplayer.off(VePlayer.live.Events.PLAY, eventHandler);

  // Remove all event listeners
  veplayer.offAll();
});
```
