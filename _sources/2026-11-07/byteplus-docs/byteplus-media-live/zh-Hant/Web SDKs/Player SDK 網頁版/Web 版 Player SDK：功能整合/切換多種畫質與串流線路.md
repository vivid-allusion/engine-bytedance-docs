為提升在不同網路條件下的播放效能，您可以使用 Player SDK for Web（VePlayer）配置多條串流線路與多種畫質。本主題說明如何實現此功能，讓觀眾可手動切換，或由播放器自動選擇最佳播放畫質或 CDN 線路。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議您使用最新版本的 Player SDK for Web。如需版本資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。舊版資訊請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="448c8a62"></span>
## 前置條件

您已整合 Player SDK for Web。如需更多資訊，請參閱[整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="98ee379c"></span>
## 配置範例

您可以透過`playlist`欄位配置多條串流線路及／或多種影片畫質。defaultSource 與 defaultDefinition 欄位分別定義預設串流線路與預設影片畫質。播放器建立成功後，您可以使用`switch`方法切換串流線路或影片畫質。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">使用多條線路或多種畫質時，不支援<code>url</code>配置。</div>


<span id="2836c6fb"></span>
### 配置多條串流線路

要配置多條串流線路，請在`playlist`陣列中定義多個`source`項目，並設定`defaultSource`。以下範例展示如何實現此功能。


<Tabs>
<Tab zoneid="nzZA3LWnOF" title="從 CDN">
<TabTitle>從 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({ 
  height: 360, 
  defaultSource: 'lineOne', 
  playlist: [ 
    { 
      name: 'lineOne', 
      text: { 'zh-cn': '线路一', en: 'Line 1' }, 
      definitions: ['https://pulldomain/appname/mystream_hd.m3u8'], 
    }, 
    { 
      name: 'lineTwo', 
      text: { 'zh-cn': '线路二', en: 'Line 2' }, 
      definitions: ['https://pulldomain/appname/mystream1_hd.m3u8'], 
    }, 
  ], 
  logger: { 
    appId: '5****8', 
  }, 
}).then(function (veplayer) { 
  // Switch to lineTwo
  veplayer.switch({ source: 'Line 2' }); 
});
```



</Tab>

<TabTitle>透過 NPM</TabTitle>

```JavaScript
  ],
  logger: {

  },

  // Switch to lineTwo
  veplayer.switch({ source: 'Line 2' });
});
```

### 配置多種畫質

要啟用畫質切換，請在單一 source 中配置多個`definition`項目。您可以設定`defaultDefinition`以指定初始畫質。


<Tabs>
<Tab zoneid="fwSoqHkMC4" title="從 CDN">
<TabTitle>從 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  height: 360,
  defaultDefinition: 'ld',
  playlist: [
    {
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_sd.m3u8',
          definition: 'sd',
          text: { en: 'sd', 'zh-cn': '高清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
  ],
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // Switch to high quality (HD)
  veplayer.switch({ definition: 'hd' });
});
```



</Tab>

### 配置多條串流線路與多種畫質

若需同時支援線路與畫質切換，請定義多個 source，並於每個 source 中包含多個 definition。請設定`defaultSource`與`defaultDefinition`以指定預設值。


<Tabs>
<Tab zoneid="tWVVSNe5v1" title="從 CDN">
<TabTitle>從 CDN</TabTitle>

```JavaScript
VePlayer.createLivePlayer({
  height: 360,
  defaultDefinition: 'ld',
  defaultSource: 'lineOne',
  playlist: [
    {
      name: 'lineOne',
      text: { 'zh-cn': '线路一', en: 'Line 1' },
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
    {
      name: 'lineTwo',
      text: { 'zh-cn': '线路二', en: 'Line 2' },
      definitions: [
        {
          url: 'https://pulldomain/appname/mystream1_hd.m3u8',
          definition: 'hd',
          text: { en: 'hd', 'zh-cn': '超清' },
        },
        {
          url: 'https://pulldomain/appname/mystream1_sd.m3u8',
          definition: 'sd',
          text: { en: 'sd', 'zh-cn': '高清' },
        },
        {
          url: 'https://pulldomain/appname/mystream1_ld.m3u8',
          definition: 'ld',
          text: { en: 'ld', 'zh-cn': '标清' },
        },
      ],
    },
  ],
  logger: {
    appId: '5****8',
  },
}).then(function (veplayer) {
  // Switch to lineTwo with HD definition
  veplayer.switch({ definition: 'hd', source: 'Line 2' });
});
```
