為了讓觀眾在直播期間能夠倒退並重播近期的直播內容，您可以透過 Player SDK for Web（VePlayer）啟用直播時移功能。本主題提供此功能的整合步驟，適用於講座重播、會議回顧等場景，提升整體觀看體驗。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">建議您使用最新版本的 Player SDK for Web。如需版本資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-changelog_2-zh-TW">Player SDK for Web：發行說明</a>。如需舊版資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-1-x-versions-zh-TW">Web 端播放器 SDK：1.x 版本</a>。</div>


<span id="前提条件"></span>
## 先決條件

您已整合 Player SDK for Web。如需更多資訊，請參閱[整合 Web 端 Player SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW)。

<span id="集成步骤"></span>
## 整合步驟


1. 在 BytePlus MediaLive 控制台新增時移配置，並生成相對時移播放地址。如需更多資訊，請參閱[管理時移配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-a-callback-task-zh-TW)。

2. 將前一步取得的地址傳遞給播放器。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如需時移配置，請參閱<a href="https://docs.byteplus.com/en/byteplus-media-live/docs/1155423#timeshiftconfig">TimeShiftConfig</a>。<code>liveStartTime</code>必須設為本地瀏覽器時間。   </div>
   

3. 導入時移插件。以下提供範例程式碼：

   
   <Tabs>
   <Tab zoneid="HSo72OcW9A" title="來自 CDN">
   <TabTitle>來自 CDN</TabTitle>
   
   ```HTML
   <script src="https://sf-unpkg.bytepluscdn.com/obj/byteplusfe-sg/sdk/@byteplus/veplayer/2.11.2/umd/veplayer.plugin.time.shift.production.js">
   </script><link rel="stylesheet" href="https://sf-unpkg.bytepluscdn.com/obj/byteplusfe-sg/sdk/@byteplus/veplayer/2.11.2/umd/veplayer.plugin.time.shift.production.css">
   ```
   
   
   
   </Tab>
   <Tab zoneid="SttxMxg8GU" title="透過 NPM">
   <TabTitle>透過 NPM</TabTitle>
   
   ```JavaScript
   import { timeShift } from '@byteplus/veplayer-plugin';
   import '@byteplus/veplayer-plugin/time-shift/style';
   ```
   
   
   
   </Tab>
   </Tabs>
   

4. 將時移插件作為配置傳入 VePlayer 物件。參閱[TimeShiftConfig](https://docs.byteplus.com/docs/byteplus-media-live/docs-1155423#timeshiftconfig)以了解參數說明。

   
   <Tabs>
   <Tab zoneid="kfegoDXTs6" title="來自 CDN">
   <TabTitle>來自 CDN</TabTitle>
   
   ```JavaScript
   VePlayer.createLivePlayer({
     width: 640,
     height: 360,
     url: 'http://pull.example.com/live/test.m3u8?timeshift=300',
     timeShift: {
       liveStartTime: Date.now() / 1000 - 60,
     },
     plugins: [window.VePlayerTimeShift],
     logger: {
       appId: '5****8',
     },
   });
   ```
   
   
   
   </Tab>
   <Tab zoneid="dDLfLBXsEY" title="透過 NPM">
   <TabTitle>透過 NPM</TabTitle>
   
   ```JavaScript
   register([hlsjs]);
   
   createLivePlayer({
     width: 640,
     height: 360,
     url: 'http://pull.example.com/live/test.m3u8?timeshift=300',
     timeShift: {
       liveStartTime: Date.now() / 1000 - 60,
     },
     plugins: [timeShift],
     logger: {
       appId: '5****8',
     },
   });
   ```
   
   
   
   </Tab>
   </Tabs>
