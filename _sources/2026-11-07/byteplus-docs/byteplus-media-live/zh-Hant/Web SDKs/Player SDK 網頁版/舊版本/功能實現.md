<div data-tips="true" data-tips-type="tip">本文適用於 BytePlus MediaLive Player SDK for Web 1.x 版本。我們強烈建議您升級至最新版本，以獲得最佳播放器體驗。</div>


為提升您的網頁端直播播放器，本主題提供使用 BytePlus MediaLive Player SDK for Web 實現關鍵功能的程式碼範例與操作說明。您將學習如何拉取低延遲 RTM 流、讓觀眾透過時移功能重播內容，以及配置日誌上傳以便於故障排查。

<span id="dc41133b"></span>
## 拉取 RTM 流

您可以使用 Player SDK 透過 Real Time Media（RTM）協議拉取串流。如需 RTM 的詳細介紹，請參考[Real Time Media 介紹](https://docs.byteplus.com/docs/byteplus-media-live/docs-introduction-to-real-time-media)。


1. 使用地址生成器生成 RTM 拉流地址。請參考[直播流地址生成](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses)，獲取生成地址的詳細操作說明。

2. 創建`VePlayer`實例，並將拉流地址設為上一步獲取的地址。


```JavaScript
// Check if the player supports pulling an RTM stream
const isRTMSupported = VePlayer.isRTMSupported();
// Check if H.264 is supported (H.264 is supported since v1.6.3)
const isRTMSupportH264 = await VePlayer.isRTMSupportCodec('h264');

const playerSdk = new VePlayer({
    id: 'mse',
    url: isRTMSupported && isRTMSupportH264 ? 'https://testpull.mycloud.com/live/mystream.sdp' : 'https://testpull.mycloud.com/live/mystream.m3u8',
    isLive: true,
    width: 600,
    height: 400,
    rtm: {
        // Backup address and protocol.當播放器拉取 RTM 流失敗時，將改用以下地址。
        backupURL: 'https://testpull.mycloud.com/live/mystream.m3u8',
        backupStreamType: 'hls'
    }
});
```


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您可以將 FLV 或 HLS 流設為備用流，分別將<code>backupStreamType</code>設為<code>flv</code>與<code>hls</code>。</div>

## 時移

時移功能可讓您的觀眾重播任何已串流的內容。如需播放時移內容，請執行以下操作：


1. 在 BytePlus MediaLive 控制台配置時移任務。請參考[時移任務配置](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-time-shifting)，獲取詳細操作說明。

2. 準備包含您在前一步配置的域名及 appName 的 M3U8 拉流地址。請參考[直播流地址生成](https://docs.byteplus.com/docs/byteplus-media-live/docs-generating-live-stream-addresses)，了解如何獲取 M3U8 格式的拉流地址。

3. 將以下程式碼添加至您的專案：

   ```JavaScript
   const playerSdk = new VePlayer({
      id: 'mse',
      isLive: true,
      // The pull stream address
      url: "//testpull.mycloud.com/live/mystream.m3u8", 
      width: 600, 
      height: 400,
      // Time-shifting configurations
      TimeShiftPlugin: { 
        // The time the live stream session started
        livingStartTime: Date.now() / 1000 - 60, 
        // The maximum amount of time shifting available during playback, in seconds.
        maxMoveTime: 60
      }, 
      plugins: [VePlayer.TimeShiftPlugin], 
    });  
   ```
   


請參考[timeShiftPlugin](https://docs.byteplus.com/docs/byteplus-media-live/docs-api-reference#2f07a993)，瞭解時移參數的說明。

## 日誌上傳

為故障排查，您可以在[liveLogger](https://docs.byteplus.com/docs/byteplus-media-live/docs-api-reference#liveLogger)中定義`appId`以啟用日誌上傳。播放器發生錯誤時，您可聯繫[技術支持](https://console.byteplus.com/workorder/create)，技術支持可透過 app ID 定位問題。

我們強烈建議您將`userId`與`deviceId`設為能唯一識別用戶與設備的值。技術支持可能需要這些資訊來定位問題。若未定義`userId`與`deviceId`，SDK 將自動生成隨機用戶 ID 與設備 ID，並存儲於瀏覽器快取中。

```JavaScript
const playerSdk = new VePlayer({
    id:'mse',
    isLive:true,
    width:600,
    height:400,
    url:'//pulldomain/appname/mainstream.flv',
    liveLogger: {
        appId: '2****4',
        userId: '1********6',
        deviceId: '3********7'
    }
});
```
