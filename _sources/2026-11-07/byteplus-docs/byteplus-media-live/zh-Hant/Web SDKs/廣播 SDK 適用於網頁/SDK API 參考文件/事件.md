## 觀察者

類型：`class`

用於在音訊與視訊擷取及推流過程中，接收各種事件回呼。提供監聽錯誤、警告、狀態更新與裝置切換等資訊的能力，有助於即時監控推流器的狀態。

### 屬性

|屬性 |類型 |說明 |
|---|---|---|
|onError |(code: number, msg: string, extraInfo?: any) =\> void |錯誤通知回呼。用於擷取推流或擷取期間發生的嚴重錯誤。可搭配錯誤碼進行疑難排解與記錄。 |
|onWarning |(msg: string) =\> void |警告通知回呼，用於提示可能影響推流但非嚴重的異常狀況。 |
|onCaptureFirstAudioFrame |() =\> void |完成第一幀音訊擷取的回呼通知。用於在開始擷取後，確認音訊來源是否正常運作。 |
|onCaptureFirstVideoFrame |() =\> void |完成第一幀視訊擷取的回呼通知。用於在開始擷取後，確認視訊來源是否正常運作。 |
|onPushStatusUpdate |(status: number, msg: string) =\> void |串流狀態更新回呼會提供狀態碼與狀態描述。可用於即時監控串流狀態（例如中斷連線、重試），並採取適當動作。 |
|onMicrophoneChanged |(changedDevice: MediaDeviceInfo) =\> void |切換麥克風裝置的回呼會傳回已切換裝置的資訊。用於監控音訊裝置的狀態變更，例如裝置熱插拔。 |
|onCameraChanged |(changedDevice: MediaDeviceInfo) =\> void |切換攝影機裝置的回呼會傳回已切換裝置的資訊。適用於主持人切換視訊輸入裝置的情境，例如直播。 |
|onCaptureInterrupted |(streamId: string) =\> void |串流中斷的回呼，會傳回已中斷串流的 ID。用於處理串流因裝置異常而停止的情況。 |
|onPushStart |() =\> void |開始直播的回呼通知。 |
|onPushStop |() =\> void |停止串流的回呼通知。 |
|onStopCapture |(streamId: string) =\> void |停止擷取的回呼會傳回已停止串流的 ID。 |
