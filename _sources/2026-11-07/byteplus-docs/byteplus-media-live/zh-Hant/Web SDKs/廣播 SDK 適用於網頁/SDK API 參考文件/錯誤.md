## RTMErrorCode

類型：`enum`

BytePlus MediaLive Broadcast SDK 中的錯誤碼用於識別音訊與視訊擷取和串流過程中的問題。透過這些錯誤碼，可快速定位問題並採取適當措施。

|屬性 |值 |說明 |
|---|---|---|
|OPEN_CAMERA_FAILED |`1001` |無法開啟攝影機。 |
|OPEN_MICROPHONE_FAILED |`1002` |無法開啟麥克風。 |
|OPEN_SCREEN_FAILED |`1003` |無法啟動螢幕分享。 |
|VIDEO_FILE_CAPTURE_FAILED |`1004` |無法載入視訊檔案。嘗試將視訊檔案載入為串流時，若檔案路徑不正確或格式不支援，會發生此錯誤。 |
|AUDIO_FILE_CAPTURE_FAILED |`1005` |無法擷取音訊檔案。嘗試將音訊檔案載入為串流時，若檔案路徑不正確或格式不支援，會發生此錯誤。 |
|IMAGE_FILE_CAPTURE_FAILED |`1006` |無法擷取影像檔案。嘗試將影像檔案載入為串流時，若檔案路徑不正確或格式不支援，會發生此錯誤。 |
|VOLUME_DETECT_FAILED |`1008` |音量偵測失敗。音訊串流無法使用或偵測邏輯異常時，會觸發此錯誤。 |
|PUBLISH_FAILED |`2001` |推流失敗。適用於推流位址無法連線、網路不穩定，或伺服器傳回錯誤的情況。 |
|UPDATE_PUBLISH_FAILED |`2002` |無法更新串流內容。在非混流情境中取代視訊來源失敗時，會發生此錯誤。 |
|PUSH_CONNECT_FAILED |`2003` |串流連線失敗。若網路連線失敗或伺服器位址無法連線，將傳回此錯誤。 |
