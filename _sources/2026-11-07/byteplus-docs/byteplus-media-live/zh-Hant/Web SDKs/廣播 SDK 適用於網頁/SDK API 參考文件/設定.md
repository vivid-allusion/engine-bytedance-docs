## ConfigOptions

BytePlus MediaLive Broadcast SDK 的初始化設定選項可指定逾時時間、重試次數、間隔時長及串流模式。

<span id="feed78c8"></span>
### 屬性


|屬性 |型別 |說明 |
|---|---|---|
|timeout |number |請求推流地址的逾時時間（毫秒）。 |
|retryCount |number |請求推流地址失敗後的重試次數。 |
|retryDelay |number |重試請求推流地址的間隔時間（毫秒 ms）。 |
|mode |[PushMode](https://docs.byteplus.com/en/docs/byteplus-media-live/ref#pushmode) |預設串流方式。<br><br><br>* `rtm`：使用 RTM 協議進行串流。 |


**型別**

```TypeScript
{
  timeout?: number;
  retryCount?: number;
  retryDelay?: number;
  mode?: PushMode;
}
```


<span id="e5e8d921"></span>
## PushMode

SDK 所使用的串流模式。


* `rtm`：使用 RTM 進行串流。


**型別**

```TypeScript
'rtm'
```

## IMixingViewConfig

型別：`interface`

合併畫布的基本資訊，例如尺寸、幀率、背景顏色等。

<span id="60acc35d"></span>
### 屬性


|屬性 |型別 |說明 |
|---|---|---|
|width |number |合併畫布的寬度。 |
|height |number |合併畫布的高度。 |
|frameRate |number |合併畫布的幀率（fps）。建議將 `frameRate` 設定為 15 fps 或更高，以確保流暢度。 |
|backgroundColor |string |合併畫布的背景顏色，預設為黑色。 |

## IVideoStreamLayoutParams

型別：`interface`

合併視訊來源的設定資訊

<span id="31d5759c"></span>
### 屬性


|屬性 |型別 |說明 |
|---|---|---|
|x |number |版面配置的 x 座標（px）。 |
|y |number |版面配置的 y 座標（px）。 |
|width |number |版面配置的寬度（px）。 |
|height |number |版面配置的高度（px）。 |
|zOrder |number |版面層級越高，顯示越上層。 |
|keepRatio |boolean |是否維持長寬比例。 |
|streamId |string |視訊流的 ID。 |
|volume |number |當視訊流包含音訊內容時，對應音量範圍為 `[0,100]`。 |


<span id="d2f2db7c"></span>
## IAudioStreamLayoutParams

型別：`interface`

混音時音訊流的設定資訊。

<span id="2a6c8531"></span>
### 屬性


|屬性 |型別 |說明 |
|---|---|---|
|streamId |string |音訊流的 ID。 |
|volume |number |音訊流的音量範圍為 `[0,100]`。 |
