BytePlus MediaLive 是一款為企業與個人打造的安全、穩定且專業的雲端直播服務。基於先進的音視頻處理技術與大規模內容分發技術，該服務提供豐富的功能與增值服務，讓您只需幾個步驟即可建立完整的串流平台。

<span id="Product architecture"></span>
## 產品架構

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/67c49ad57a6541038c270ce47403026a~tplv-goo7wpa0wc-image.image) </span>

BytePlus MediaLive 提供端到端的串流解決方案：


* 您可以使用 Broadcast SDK for Web 將串流推送至伺服器。該 SDK 同時支援音訊與視訊擷取、超低延遲串流及其他功能。

* 伺服器提供多項服務，包括網域與串流管理、串流與使用統計，以及如轉碼、錄製、截圖等增值服務。您可以透過 [BytePlus MediaLive 控制台](https://docs.byteplus.com/byteplus-media-live/docs/introduction-to-the-media-live-console)、[OpenAPI](https://docs.byteplus.com/byteplus-media-live/docs/getting-started-with-your-api) 存取這些服務。

* Player SDK 提供高品質的觀看體驗，包括超高畫質的視訊品質、快速首幀渲染與穩定播放。該 SDK 亦會回報播放品質統計，協助您快速識別問題並監控串流效能。
