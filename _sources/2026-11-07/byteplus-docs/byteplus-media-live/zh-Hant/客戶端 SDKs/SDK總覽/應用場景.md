## **展示間**

客戶端 SDK 為展示間提供直播觀看功能，支援在 Android 和 iOS 上進行直播播放。SDK 通過整合互動訊息等功能，提升觀看體驗。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f63c0e8cfd74868b238315d9cbe6386~tplv-goo7wpa0wc-image.image) </span>

<span id="a7e4a6a6"></span>
## **遊戲**

基於卓越的用戶體驗，客戶端 SDK 為遊戲直播提供低延遲播放。這使得用戶能夠即時觀看直播內容，進一步提升用戶參與度。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/572a686694c8422ca570e4239bfb1678~tplv-goo7wpa0wc-image.image) </span>

<span id="c2d209d9"></span>
## 線上教育

客戶端 SDK 提供直播觀看與互動訊息功能，並結合高可用服務鏈路及動態熱鏈保護，確保教育直播的穩定性與安全性。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a36317a8a86248e2b8bbfd010a720a9a~tplv-goo7wpa0wc-image.image) </span>

<span id="4f3a9ba0"></span>
## **電子商務**

客戶端 SDK 允許觀眾在觀看直播的同時瀏覽並購買商品。SDK 亦支援商品重點回放及用戶互動等功能，實現直播流量的快速變現。
