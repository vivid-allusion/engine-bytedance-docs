在使用 BytePlus MediaLive 時，若整合其他服務（如 BytePlus VOD、RTC 或 Effects SDK），可能會產生額外費用。本主題說明這些潛在收費，詳述會產生費用的具體使用場景，並提供參考資料，協助你精確預算直播解決方案的成本。額外費用如下所示：


|**產品** |**使用場景** |**參考資料** |
|---|---|---|
|BytePlus VOD |若你將錄製檔案儲存在 BytePlus Video on Demand（VOD）中，將產生 VOD 服務費用。 |[價格總覽](https://docs.byteplus.com/en/docs/byteplus-vod/docs-pricing) |
|BytePlus RTC |若你整合 BytePlus MediaLive SDK 並使用如觀眾連麥、主播 PK 對戰等互動直播功能，則需支付 RTC 服務費用。 |[價格](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-69871) |
|BytePlus Effects SDK |若你整合 BytePlus MediaLive Broadcast SDK 並使用 Effects SDK 提供的功能（如濾鏡、美顏 AR、貼紙等），將收取相應費用。 |[請聯繫你的銷售代表](https://www.byteplus.com/en/contact)以瞭解價格詳情。 |
