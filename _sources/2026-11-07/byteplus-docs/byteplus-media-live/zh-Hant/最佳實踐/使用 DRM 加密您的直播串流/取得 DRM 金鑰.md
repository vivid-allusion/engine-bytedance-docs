若要在您的直播串流中實施 DRM 加密，您必須先從 Intertrust 取得 DRM 金鑰。本主題提供從 Intertrust 控制台取得 API 金鑰的逐步操作說明，您將會把該金鑰上傳至 BytePlus MediaLive 控制台。

<span id="9a84e96d"></span>
## 先決條件

一個 [Intertrust](https://portal.expressplay.com/) 帳戶。您必須啟用此帳戶所需的服務。使用這些服務會產生 Intertrust 的費用。若有任何疑問，您可以直接聯繫 Intertrust，或是聯絡您的 [BytePlus sales representative](https://www.byteplus.com/en/contact)。

<span id="c77d3691"></span>
## 操作流程


1. 登入 [Intertrust](https://portal.expressplay.com/) 控制台。

2. 在左側導覽列中，點選 **Manage Account**。

3. 點選 **Subscriptions**。

4. 啟用您需要的 DRM 系統。

5. 在左側導覽列中，點選 **Api Keys / Cust.Auth.** 。

6. 點選 \*\*Add Api Key / Cust.Auth.\*\*按鈕以建立 API 金鑰。請將金鑰儲存於本地，因為日後無法再次取得。
