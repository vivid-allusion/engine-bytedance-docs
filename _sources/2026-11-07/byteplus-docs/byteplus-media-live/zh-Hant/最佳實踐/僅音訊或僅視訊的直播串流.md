為滿足特定使用情境，您可以設定 BytePlus MediaLive 以處理僅音訊或僅視訊的串流。本主題提供如何使用支援的協議推送串流，以及如何透過在拉流地址中新增查詢參數來拉取特定串流類型的操作說明。

<span id="c89e0453"></span>
## 操作流程

<span id="8114c44c"></span>
### 推送直播串流

您可以推送使用 **RTMP**、**RTMPS** 和 **QUIC** 協議的僅音訊或僅視訊直播串流。

支援的串流類型會根據您的直播方式而有所不同。支援的串流類型如下：


* 僅音訊串流：您可以推送僅音訊串流，或包含音訊與視訊的常規串流。

* 僅視訊串流：您可以推送僅視訊串流，或包含音訊與視訊的常規串流。


<span id="bba6ca8c"></span>
### 拉取直播串流

您可以拉取使用 **RTMP**、**FLV** 和 **QUIC** 協議的僅音訊或僅視訊直播串流。

要拉取僅音訊或僅視訊的串流，請在對應協議的拉流地址中新增查詢參數。


* 僅音訊：新增查詢參數 `only_audio`

   當 `only_audio=1` 時，將以僅音訊模式拉取串流。若參數設為 `0` 或未設定，則以常規模式拉取串流。

* 僅視訊：新增查詢參數 `only_video`

   當 `only_video=1` 時，將以僅視訊模式拉取串流。若參數設為 `0` 或未設定，則以常規模式拉取串流。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">您不能在同一地址中同時將 <code>only_audio</code> 和 <code>only_video</code> 設為 <code>1</code>。若兩個參數都設為 <code>1</code>，則兩者皆不會生效。</div>


以下範例展示使用 RTMP、FLV 和 RTM 協議的僅音訊串流拉流地址格式。


* RTMP: `rtmp://{Domain}/{AppName}/{StreamName}?{AuthenticationInfo}&only_audio=1`

* FLV: `https://{Domain}/{AppName}/{StreamName}.flv?{AuthenticationInfo}&only_audio=1`

* RTM: `https://{Domain}/{AppName}/{StreamName}.sdp?{AuthenticationInfo}&only_audio=1`
