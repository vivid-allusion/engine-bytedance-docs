為了對 BytePlus MediaLive 中不同團隊或用戶實現細緻的權限控制，可以使用 IAM（身份與存取管理）專案。本主題將說明如何建立專案、將其與 IAM 用戶（子帳戶）關聯，並分配特定的策略，讓您能夠隔離資源並安全管理存取權限。

<span id="6803a245"></span>
## 概念


* **主帳戶**：已註冊的 BytePlus 帳戶。

* **子帳戶**：在主帳戶下建立的用戶。

* **用戶組**：子帳戶的集合。您可以為用戶組設定權限，這些權限將套用至組內的用戶。

* **策略**：一組權限。MediaLive 支援客戶自管策略，每個產品也提供符合其特定業務需求的系統自管策略。


<span id="ca576607"></span>
## 策略類型

策略是一組權限。您可以將策略綁定至子帳戶，以授予相應的授權。

<span id="5c685a50"></span>
### 系統自管策略

MediaLive 目前提供兩種系統自管策略，**LIVEFullAccess** 和 **LIVEReadOnlyAccess**，可分配給子帳戶。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e0c4db5b1f6247aaa2d54b8a3cf3f63d~tplv-goo7wpa0wc-image.image) </span>

**LIVEFullAccess**：提供對 MediaLive 的完整存取權限。

**LIVEReadOnlyAccess**：提供對 MediaLive 的唯讀存取權限。

<span id="23688bb1"></span>
### 客戶自管策略

MediaLive 支援自訂策略。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/63be25bf92c84485b7ca13e99cd3e1fe~tplv-goo7wpa0wc-image.image) </span>

## 操作流程

<span id="77fedd79"></span>
### 建立專案


1. 以主帳戶登入 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左側導覽欄，點選 **專案 \> 建立專案。** 

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/353601fff598406986cf0a434caa338b~tplv-goo7wpa0wc-image.image) </span>

3. 填寫 **專案名稱**，並點選 **確定**。


<span id="bf7e29a6"></span>
### 建立 IAM 用戶並設定權限


1. 以主帳戶登入 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左側導覽欄，點選 **用戶管理** \> **用戶**。

3. 點選 **新增用戶**。在 **建立用戶**頁面，於 **基本資訊設定**下，填寫 **用戶名**並配置 **登入設定**。

   * **程式存取**：分配 Access Key 給用戶，以便透過 API 請求存取。

   * **控制台存取**：分配密碼給用戶，以便透過控制台存取。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cf3557d0d9db41359faaedf117d14d83~tplv-goo7wpa0wc-image.image) </span>

4. 點選 **下一步**。在 **建立用戶**頁面，於 **權限設定**下，選擇權限策略及專案。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7404f4e01bf1429f91d1d90098c4a99d~tplv-goo7wpa0wc-image.image) </span>

5. 點選 **下一步**。請仔細檢查您的設定，然後點選 **提交**。

## 後續操作

<span id="310872fd"></span>
### 在 MediaLive 中使用專案


* 新增網域名稱時，請選擇該網域名稱空間所屬的專案。請參閱 [新增網域名稱](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-domain)。

* 新增 HTTPS 憑證時，請選擇該憑證所屬的專案，詳見 [管理 SSL 憑證](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-managing-certificates)。

* 建立 SDK 應用時，請選擇該應用所屬的專案，詳見 [SDK 管理](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-sdk-management)。

* 建立轉推組時，請選擇該轉推組所屬的專案，詳見 [配置轉推任務](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-relay)。

* 使用專案篩選用量統計及分析查詢資料，詳見 [查詢用量資料](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-usage-statistics)與[查詢分析資料](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-statistical-analysis)。


<span id="a41dfec3"></span>
### 以 IAM 用戶身份存取控制台


1. 前往 [BytePlus](https://console.byteplus.com/auth/login)登入頁面。

2. 點選 **IAM 用戶**，進入 **IAM 用戶登入**頁面。

3. 填寫 **主帳戶用戶名**、 **子帳戶用戶名**及 **密碼**，然後點選 **登入**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/647ae2d2199c42c58b32b3aa10887167~tplv-goo7wpa0wc-image.image) </span>

4. 在 **產品**列表中，點選 **BytePlus MediaLive**以進入控制台。


<span id="6b7816f3"></span>
### 取得 IAM 用戶的 Access Key 並發送請求


1. 以主帳戶登入 [BytePlus IAM 控制台](https://console.byteplus.com/iam/identitymanage/user)。

2. 在左側導覽欄，點選 **用戶管理** \> **用戶**，然後在列表中點選用戶名。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c56042e5df044c789b3137215d79bcb5~tplv-goo7wpa0wc-image.image) </span>

3. 前往**使用者詳細資料**頁面，切換至**Access Key**標籤，以檢視目前 IAM 使用者的存取金鑰。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e3b7f97ccbca44478bf881b4901034bd~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在金鑰列表中，您可以停用啟用中的存取金鑰，或再次啟用它。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Access Key ID 和 Secret Access Key 是您存取 MediaLive API 的金鑰。它們擁有 IAM 使用者的所有權限。每個 IAM 使用者最多可擁有兩組啟用中的存取金鑰。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">請妥善保管您的金鑰，定期更換，並刪除任何不再使用的金鑰。刪除金鑰為不可逆操作，請謹慎執行。   </div>
   

4. 使用 IAM 使用者的存取金鑰來呼叫 SDK。範例程式碼如下（以`CreateDomainV2`為例）。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">使用 IAM 使用者的金鑰初始化 LiveService 實例。存取金鑰用於驗證及授權存取 MediaLive 服務。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在範例程式碼中呼叫<code>CreateDomainV2</code>方法，以發起將網域名稱新增至 MediaLive 的請求。該方法會將必要參數傳送至 MediaLive 服務，以建立新的網域名稱。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">該實例會使用 IAM 使用者的 Access Key 和 Secret Access Key 產生簽名，並將簽名加入請求中。此舉可確保請求的驗證與完整性，防止未經授權存取及資料竄改。   </div>
   

   ```Java
   package com.byteplus.live.demo;
   
   import com.byteplus.model.live.v20230101.*;
   import com.byteplus.service.live.v20230101.LiveService;
   import java.util.ArrayList;
   import java.util.List;
   
   public class CreateDomainV2Demo {
   
     public static void main(String[] args) {
       // It's strongly advised against storing BYTEPLUS_ACCESSKEY and BYTEPLUS_SECRETKEY in the project code, or the AccessKey might leak, endangering the security of all resources under your account.
       // This example authenticates API access by reading BYTEPLUS_ACCESSKEY and BYTEPLUS_SECRETKEY from environment variables.在執行程式碼範例前，請設定 BYTEPLUS_ACCESSKEY 和 BYTEPLUS_SECRETKEY 的環境變數。
       LiveService service = LiveService.getInstance();
   
       service.setAccessKey(System.getenv("BYTEPLUS_ACCESSKEY"));
   
       service.setSecretKey(System.getenv("BYTEPLUS_SECRETKEY"));
   
       CreateDomainV2Body body = new CreateDomainV2Body();
   
       // An array of domain names.
       // note:
       // A domain name space can contain up to 10 domain names.
       List<CreateDomainV2BodyDomainsItem> Domains = new ArrayList<>();
   
       CreateDomainV2BodyDomainsItem Domains1 =
         new CreateDomainV2BodyDomainsItem();
   
       // The acceleration region.有效值包括：
       // - oversea: Outside the Chinese mainland.
       // - cn: The Chinese mainland.
       // - global: Global.
       Domains1.setRegion("cn");
       Domains.add(Domains1);
       body.setDomains(Domains);
   
       try {
         CreateDomainV2Res resp = service.CreateDomainV2(body);
         System.out.println(resp);
       } catch (Exception e) {
         e.printStackTrace();
       }
     }
   }
   ```
