為保護您的直播內容，本指南提供逐步說明，介紹如何為原始流和轉碼流配置並啟用加密。您將了解如何使用 BytePlus MediaLive 控制台套用多種加密方法，包括商用 DRM 和 HLS 標準加密。

## 費用說明

只有在輸出加密影片時，才會收取轉碼費用。詳情請參閱[轉碼](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-transcoding)。

## 前提條件

* 如果您使用 Widevine、FairPlay 或 PlayReady 加密技術等商用 DRM 加密技術，您需要：

   * 將 API 存取金鑰上傳至 DRM 憑證管理平台。如需說明，請參閱[管理 DRM 授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-managing-drm-licenses)。

   * 上傳用於 iOS 加密的 FairPlay 憑證。如需說明，請參閱[管理 DRM 授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-managing-drm-licenses)。

   * 如果您要加密轉碼流，必須先為其建立轉碼配置。如需說明，請參閱[配置轉碼任務](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。

* 如果您使用 HLS 標準加密，您需要：

   * 為您的自建金鑰管理服務配置金鑰取得地址。詳情請參閱[管理 HLS 金鑰取得地址](https://docs.byteplus.com/docs/byteplus-media-live/docs-hls-keyaddress)。

   * 如果您要加密轉碼流，您需要為要加密的串流建立轉碼配置，配置方法請參閱[配置轉碼任務](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)。

## 限制

當直播流的來源名稱（StreamName）包含底線時，不支援加密功能。

## 操作步驟

1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，選取 **Settings** \> **Feature configuration**。按一下 **Encryption** 分頁。

3. 在左上方找到 **Domain name space**，並從下拉式清單中選取一個網域名稱空間。這些配置將套用至所選網域名稱空間內的所有網域名稱。您可以參閱[網域名稱空間](https://docs.byteplus.com/docs/byteplus-media-live/docs-glossary#Vhost)，了解這些概念的更多資訊。

4. 按一下 **Add configuration**，開啟 **Add Encryption configuration** 對話方塊。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4d80ebdbb43d42b6ba304f000a1d6203~tplv-goo7wpa0wc-image.image)

5. 配置設定：

   * **AppName**：將其設定為與直播流地址中 AppName 欄位相同的值。這會定義配置套用的串流。

   * **Encryption type**：選取要使用的加密技術。

      > **说明**

      * > 商用 DRM 加密支援三種方法：Widevine、FairPlay 和 PlayReady。

      * > 使用 HLS 標準加密時，支援 ClearKey AES\-128 加密方法。

   * **Encrypted content**：選取要加密原始流或轉碼流。您可以透過轉碼配置尾碼識別轉碼流。

6. 按一下 **Confirm**。
