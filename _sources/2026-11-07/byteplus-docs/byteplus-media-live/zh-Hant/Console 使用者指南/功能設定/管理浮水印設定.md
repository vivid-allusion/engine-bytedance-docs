為保護您的內容免遭未授權使用，您可以使用 MediaLive，為轉碼串流或自適應位元率（ABR）子串流新增靜態或動態浮水印。本主題說明如何在 MediaLive 主控台中設定浮水印。

## 注意事項

* 浮水印僅支援轉碼串流或 ABR 子串流。新增浮水印設定前，請確認目標 `AppName` 已在相同網域名稱空間中具有轉碼或 ABR 設定。若要為來源串流加上浮水印，請新增使用 **Original** 設定的轉碼設定。

* 每個 `AppName` 僅支援一個浮水印設定。在該設定中，您可以將浮水印套用至所有或特定轉碼串流或 ABR 子串流。

* 新增、更新或刪除浮水印設定後，變更會在 3 到 5 分鐘內生效。變更生效後產生的轉碼串流或 ABR 子串流會使用最新的浮水印設定。變更生效前已產生的現有轉碼串流或 ABR 子串流不會自動套用更新。如果變更前不存在轉碼串流或 ABR 子串流，請等待設定生效。如果變更前已存在轉碼串流或 ABR 子串流，且您需要使用更新後的設定，請在設定新增、更新或刪除後等待 3 到 5 分鐘，然後重新推流。

* 靜態浮水印的實際位置由浮水印的絕對位置和大小決定。如果浮水印超出影片邊緣，則完全不會顯示在影片上。

## 先決條件

* 在您要新增浮水印設定的網域名稱空間中，為目標 `AppName` 新增轉碼或 ABR 設定。如需詳細資訊，請參閱[管理轉碼設定](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-transcoding)或[管理自適應位元率設定](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-an-hls-abr-task)。

* JPG 或 PNG 圖片，檔案大小上限為 2 MB，解析度上限為 1080 x 1080 px。PNG 圖片可以包含透明度。

## 程序

1. 登入 [BytePlus MediaLive 主控台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，選取 **Settings** \> **Feature configuration**。按一下 **Watermark** 分頁。

3. 從 **Domain name space** 下拉式清單中，選取已新增轉碼或 ABR 設定的網域名稱空間。

4. 按一下 **Add configuration**，開啟 **Add watermark configuration** 對話方塊。

5. 設定相關項目，然後按一下 **Confirm**。

   |**參數** |**說明** |
   |---|---|
   |AppName |選取與轉碼或 ABR 設定相同的 `AppName`。 |
   |StreamName |推流位址中的 `StreamName`。例如，如果推流位址是 `rtmp://push.example.com/live/test?authinfo`，則 `StreamName` 是 `test`。<br><br><br>* 如果您設定 `StreamName`，浮水印僅會套用至目前 `AppName` 下的特定轉碼串流或 ABR 子串流。<br><br>* 如果您將 `StreamName` 留空或輸入 `*`，浮水印會套用至目前 `AppName` 下的所有轉碼串流或 ABR 子串流。 |
   |後綴 |依預設，會選取所有後綴，表示浮水印會套用至所有轉碼串流或 ABR 子串流。<br><br>您也可以選取一個或多個後綴（例如 `_uhd` 和 `_hd`），僅將浮水印新增至具有這些後綴的轉碼串流或 ABR 子串流。 |

   |浮水印類型 |選取浮水印類型。<br><br><br>* **靜態浮水印**：將浮水印固定在設定的位置。<br><br>* **動態浮水印**：在播放期間移動浮水印，讓未授權的螢幕錄製和重複使用更加困難。 |
   |水平偏移 |如需詳細資訊，請參閱[常見問題](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-live-stream-watermarks#FAQs)。<br><br>> **說明**<br><br><br>> 此欄位僅在您選取 **靜態浮水印** 作為 **浮水印類型** 時顯示。<br> |

   |動態速度 |較低的值會產生較慢的移動，較高的值會產生較快的移動。有效範圍：1\-10。<br><br><br>* 對於 **動態曲線移動**，此項目控制浮水印移動的速度。<br><br>* 對於 **動態閃爍**，此項目控制浮水印變更位置的頻率。<br><br><br>> **說明**<br><br><br>> 此欄位僅在您選取 **動態浮水印** 作為 **浮水印類型** 時顯示。<br> |

## 常見問題

### 什麼是水平偏移和垂直偏移？

BytePlus MediaLive 使用 **水平偏移** (PosX) 和 **垂直偏移** (PosY) 指定靜態浮水印在影片上的位置。相關參數說明如下：

|**參數** |**說明** |
|---|---|
|PosX |**水平偏移**，即浮水印左邊緣與轉碼影片左邊緣之間的距離，和影片寬度的比率。有效範圍：0–1。 |
|PosY |**垂直偏移**，即浮水印上邊緣與轉碼影片上邊緣之間的距離，和影片高度的比率。有效範圍：0–1。 |
|RelativeWidth |浮水印寬度與轉碼影片寬度的比率。有效範圍：0–1。浮水印高度會依其寬度自動調整。 |
|Orientation |提供兩個選項。<br><br><br>* horizontal：橫向。<br><br>* vertical：縱向。 |

PosX 和 PosY 僅適用於靜態浮水印。BytePlus MediaLive 主控台使用 **浮水印縮放** 調整浮水印大小，而我們的 API 使用 **相對寬度** 作為大小參數。在本節中，我們僅介紹 **相對寬度**。

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ee5e570a6c804de6a11c51be467367b9~tplv-goo7wpa0wc-topic.webp)

### 如何計算浮水印的絕對位置、寬度和高度？

假設您將 400 x 200 圖片新增為 1920 x 1080 橫向模式影片上的靜態浮水印，並設定下列參數：

```plain
PosX = 0.05
PosY = 0.05
RelativeWidth = 0.1
Orientation = "horizontal"
```

以下說明如何計算浮水印的絕對位置、寬度和高度：

```plain
abs_x = 1920 * 0.05 = 96  // 浮水印左邊緣距離影片左邊緣 96 像素。
abs_y = 1080 * 0.05 = 54  // 浮水印上邊緣距離影片上邊緣 54 像素。
abs_w = 1920 * 0.1 = 192  // 浮水印寬度為 192 像素。
abs_h = 192 * 200 / 400 = 96  // 浮水印高度為 96 像素。
```

靜態浮水印的實際位置由其絕對位置和大小決定。如果浮水印超出影片邊緣，則完全不會顯示在影片上。調整浮水印的 **水平偏移**、**垂直偏移** 或 **相對寬度**，以確保完整浮水印在影片內可見。

### 為什麼我的浮水印在直播工作階段期間沒有顯示？

可能有幾個原因：

* **浮水印設定變更尚未生效。**

   新增、更新或刪除浮水印設定後，請等待 3 到 5 分鐘讓變更生效。

* **轉碼串流或 ABR 子串流是在浮水印設定變更生效前產生的。**

   現有轉碼串流或 ABR 子串流不會自動套用更新。若要使用最新的浮水印設定，請在設定新增、更新或刪除後等待 3 到 5 分鐘，然後重新推流。

* **您尚未為相關 AppName 新增任何轉碼或 ABR 設定。**

   浮水印只能套用至已具有轉碼或 ABR 設定的 `AppName`。請確認您已為相關 `AppName` 新增轉碼或 ABR 設定。

* **目前轉碼串流或 ABR 子串流的後綴不是所選後綴之一。**

   如果您在浮水印設定中選取特定轉碼後綴或 ABR 子串流後綴，浮水印只會顯示在後綴與所選後綴相符的轉碼串流或 ABR 子串流中。

* **浮水印超出影片邊緣。**

   這適用於靜態浮水印。實際位置由浮水印的絕對位置和大小決定。如果浮水印超出影片邊緣，則完全不會顯示在影片上。調整浮水印的 **水平偏移**、**垂直偏移** 或 **相對寬度**，以確保完整浮水印在影片內可見。
