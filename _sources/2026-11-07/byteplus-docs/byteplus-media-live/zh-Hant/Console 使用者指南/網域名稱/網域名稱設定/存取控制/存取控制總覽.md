BytePlus MediaLive 的存取控制可讓你透過管理誰能推送或拉取串流，來保護你的直播串流。你可以透過三種方法實現此安全性：URL 驗證、IP 允許清單與封鎖清單，以及 Referer 允許清單與封鎖清單。


* [設定 URL 驗證](https://docs.byteplus.com/docs/byteplus-media-live/docs-url-authentication-zh-TW): 透過在 URL 中加入驗證資訊來驗證請求，提供高度安全性。

* [IP 限制](https://docs.byteplus.com/docs/byteplus-media-live/docs-ip-blocklist-and-allowlist-zh-TW): 透過允許或拒絕特定 IP 位址來控制存取權限。

* [Referer](https://docs.byteplus.com/docs/byteplus-media-live/docs-referer-zh-TW): 透過允許或拒絕特定來源來控制存取權限。


由於 Referer 和 IP 位址可能被偽造，未經授權的使用者仍然可以推送或拉取串流。因此，若你對直播內容有高度安全需求，建議使用 URL 驗證。
