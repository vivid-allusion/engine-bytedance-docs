為了保護您的服務免於高頻率存取，並降低 Challenge Collapsar（CC）攻擊的風險，您可以為串流拉取的網域名稱設定頻率限制。此功能允許您根據 IP 位址、URL 或特定 URL 查詢參數，設定請求的頻率限制。

使用此功能時請謹慎，因為若設定的頻率限制過低，可能會導致合法請求被意外阻擋。因此，我們建議您仔細考量並測試適當的頻率限制，以在安全性與可用性之間取得平衡。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">頻率限制是依每個邊緣叢集套用，而非整個網路。舉例來說，假設頻率限制設定為單一 IP 位址每秒 50 次請求。若叢集 A 與叢集 B 在同一秒內各自收到該 IP 位址的 50 次請求，則不會有任何請求被阻擋。然而，若叢集 A 在同一秒內收到 101 次請求，而叢集 B 仍收到 50 次，則該 IP 位址發送至叢集 A 的後續請求將於拒絕期間被阻擋。另一方面，叢集 B 則不受影響。</div>

## 操作流程

請依照以下指示，在 BytePlus MediaLive 控制台為網域名稱設定頻率限制：


1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，點擊 **Domains**。

3. 找到您要設定的網域名稱，並在 **Actions** 欄位中點擊 **Settings**。

4. 點擊 **Access control** 分頁。

5. 在 **Rate limiting** 切換開關右側，點擊 **Edit**。

6. 於出現的 **Edit rate limiting** 對話框中，設定以下參數。

   * **限制類型**：

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">包括 <strong>依 URL 的請求頻率</strong>、<strong>依指定查詢參數的 URL 請求頻率</strong> 及 <strong>依 IP 位址發送至 URL 的請求頻率</strong> 等選項預設為隱藏。請聯絡您的 <a href="https://console.byteplus.com/workorder/create">技術支援</a>以顯示這些選項。      </div>
      

      * **依 IP 位址的請求頻率**：限制單一 IP 位址發出的請求頻率。

      * **依 URL 的請求頻率**：限制發送至單一 URL 的請求頻率。

      * **依指定查詢參數的 URL 請求頻率**：限制發送至包含指定查詢參數的 URL 的請求頻率。

      * **依 IP 位址發送至 URL 的請求頻率**：限制單一 IP 位址發送至同一 URL 的請求頻率。

   * **限制值**：每秒或每分鐘允許的最大請求數。

7. 點擊 **Confirm**。
