域名空間是直播中的關鍵概念，能將推流域名與拉流域名進行關聯，使觀眾能觀看您的直播。本主題說明什麼是域名空間，並展示如何透過新增或修改空間內的域名來管理域名空間。

<span id="35c4be99"></span>
## 背景

推流域名用於生成推流地址，使用者（主播）可利用該地址將直播推送至 BytePlus MediaLive Center。

拉流域名用於生成拉流地址，使用者（觀眾）可利用該地址從 BytePlus MediaLive Center拉取直播。

要將直播推送至 BytePlus MediaLive Center 並拉取該直播，必須將推流域名與拉流域名進行關聯。

<span id="2180543e"></span>
### 域名空間定義推流與拉流域名之間的關聯

域名空間是一組已關聯的推流與拉流域名。

用於推流與拉流的域名必須彼此關聯。完成關聯後，您可使用推流域名將直播推送至 BytePlus MediaLive Center。您可使用與推流域名關聯的拉流域名拉取並播放直播。

不同服務會使用不同的域名空間。因此，不同空間中的直播彼此隔離，無法互相連接。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9edf9b991ca94674abb3793a48dad69e~tplv-goo7wpa0wc-image.image) </span>

<span id="4a8ee226"></span>
### 域名空間定義直播服務的配置

直播地址的結構允許您透過指定域名、AppName 和 StreamName，在域名空間內識別特定的直播流。

因此，我們可以利用**Domain Name Space**、**Domain Name**、**AppName** 和 **StreamName**，在增值功能配置中指定有效直播流的範圍。

以下是直播地址的範例。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8878d07015b04a368edb5bed2e017206~tplv-goo7wpa0wc-image.image) </span>

配置僅適用於特定域名空間，無法應用於其他空間的直播流。下圖展示不同層級的配置如何應用於域名空間內的不同直播流。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0ca52ea551a74c8cb241f58c6f584b96~tplv-goo7wpa0wc-image.image) </span>


* 域名空間：此增值功能配置適用於該域名空間內的所有直播流。

* 域名空間 + 域名：此增值功能配置適用於該域名空間內所有使用此域名的直播流。

* 域名空間 + AppName：此增值功能配置適用於該域名空間內所有使用此 AppName 的直播流。

* 域名空間 + AppName + StreamName：此增值功能配置適用於該域名空間內使用此 AppName 和 StreamName 的直播流。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">不同的增值配置適用於不同範圍的串流。詳細資訊請參閱各自的說明。</div>

## 操作流程

<span id="7d13ae58"></span>
### 將域名新增至現有域名空間

新增域名時，您可以將其加入現有的域名空間，並與該空間內的其他域名進行關聯。


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，點擊**Domains**。

3. 點擊**新增網域名稱**。

4. 在**關聯網域名稱空間**下選擇現有的網域名稱空間，然後新增網域名稱。如需其他設定的詳細資訊，請參閱[新增網域名稱](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-domain)。


<span id="4540ea9c"></span>
### 修改網域名稱的網域名稱空間

新增網域名稱後，如有需要，您可以變更其網域名稱空間。


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，點擊**網域名稱**。在網域名稱右側點擊**設定**。

3. 於**基本資訊**分頁的**網域名稱空間**區塊中，點擊**網域名稱空間**右側的編輯圖示。在彈出視窗中輸入新的網域名稱空間，然後點擊**確認**。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">未包含任何網域名稱的網域名稱空間會自動移除。</div>
