為了優化您的直播效能或符合區域合規要求，您可以修改網域名稱的加速區域。本主題提供在 BytePlus MediaLive 控制台中，針對推流與拉流網域名稱更改加速區域的逐步操作說明。

<span id="ccfa0f3a"></span>
## 先決條件


* 若您的網域目前的加速區域為**中國大陸以外**，在將區域更改為**中國大陸**或**全球加速**之前，必須完成中國大陸的 ICP 備案流程。

* 中國大陸與非中國地區的價格有所不同。請[聯絡客服](https://console.byteplus.com/workorder/create)。


<span id="82b42909"></span>
## 操作流程


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，點擊**網域名稱**。

3. 在您要修改的網域名稱上，點擊**設定**。

4. 於**基本資訊**區段中，點擊**修改**。

5. 在彈出視窗中，選擇新的加速區域，然後點擊**確認**。
