如[設定回源任務](https://docs.byteplus.com/docs/byteplus-media-live/docs-configuring-origin-pull-settings)所述，當從第三方源站伺服器拉取直播流時，源站位址可能會隨時間變動。為此，你可以使用原始位址重寫功能，根據預先定義的匹配規則，從新的位址獲取串流。

<span id="8ae1c921"></span>
## 限制

此功能僅適用於隨選回源任務。支援使用 FLV、HLS 和 RTMP 協議的串流。

<span id="1ec9696b"></span>
## 操作流程

請依照以下說明，在 BytePlus MediaLive 控制台設定原始位址重寫：


1. 登入[BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，點擊**Domains**。

3. 找到你要設定的網域名稱，並在**Actions**欄中點擊**Settings**。

4. 點擊**Origin pull**分頁。

5. 在**Origin address rewrite**開關右側，點擊**Edit**。

6. 在出現的**Origin address rewrite**對話方塊中，設定重寫規則。你最多可以設定 50 條重寫規則。重寫規則的順序表示規則的優先順序。若有多條規則，將依照其優先順序執行。若有一條規則符合用戶請求，其餘規則將不再執行。

   * **Existing path**：原始路徑。路徑最多可包含五個萬用字元。但請勿使用萬用字元來表示查詢參數。

   * **Target path**：新路徑。你可以使用`${1}`、`${2}`、`${3}`、`${4}`和`${5}`分別代表第一至第五個萬用字元所匹配的內容。

      原始路徑與目標路徑還需符合以下要求：

   * 路徑不得包含協議和網域名稱，例如`http://example.domain.com`。

   * 路徑必須以`/`開頭。

   * 路徑最多可包含 1,024 個字元。

   * 路徑不得包含連續兩個星號，即`**`。

   * 路徑不得包含連續兩個`${`，即`${${`。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">查詢回源資料時，請使用原始路徑而非新路徑。</div>


<span id="cdb378e7"></span>
## 範例

假設原始路徑設定為`/app/*/*/playlist.m3u8`，目標路徑設定為`/abc/${1}/${2}.m3u8`，則原始請求`http://www.test.com/app/123/test/playlist.m3u8`將被重寫為`http://www.test.com/abc/123/test.m3u8`。
