若要讓您的應用程式準備好用於生產環境，或避免授權過期造成服務中斷，您需要有效管理 SDK 授權。本主題提供詳細指引，說明如何將試用授權升級為 basic 或 premium 授權，以及如何續約 basic 或 premium 授權。

## 前提條件

您已取得 SDK 授權。如需詳細資訊，請參閱[取得 SDK 授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management)。

## 將試用授權升級為 basic 或 premium 授權

試用授權僅供測試使用，不能用於生產環境。在試用授權到期前，或您的應用程式發佈至生產環境前，請將試用授權升級為 basic 或 premium 授權。

1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，按一下 **SDK 管理**。

3. 在試用授權的 **操作** 欄中按一下 **升級**。

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c065c4ff71314b508b3736c4e91807dd~tplv-goo7wpa0wc-image.image)

4. 選取 **Basic** 或 **Premium** 作為授權類型。

   > **说明**

   > 如需各授權類型支援的功能，請參閱[用戶端 SDK：SDK 概觀](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-introduction)和 [Player SDK for Web：SDK 概觀](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-sdk-for-web-sdk-overview)。如需各授權類型的定價，請參閱 [SDK 授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses)。

   **升級為 basic 授權**

Basic 授權適用於**生產環境**，有效期為**一年**。

   選擇以下任一方式升級為 basic 授權：

      * 直接購買

         2. 完成購買後，返回組態頁面。從清單中選取 basic 授權，然後按一下 **確認**。

            ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a4ab8a8ff8b4d708dd4876ccf6006f9~tplv-goo7wpa0wc-image.image)

            > **说明**

            > 如果您新購買的授權未立即出現在清單中，請按一下重新整理圖示以更新頁面。

      * 綁定流量包：您可以將 100 TB 或更大的直播流量包綁定至應用程式，以取得免費的一年期 basic 授權。如需直播流量包的詳細資訊，請參閱[資源包](https://docs.byteplus.com/docs/byteplus-media-live/docs-resource-packs)。

         > **说明**

         * **如果您沒有符合資格的流量包**：

            1. 按一下 **立即購買** 以購買一個。

               ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2e3a164f1da646c99e1c6fd68cbb129b~tplv-goo7wpa0wc-image.image)

            2. 完成購買後，返回組態頁面。從清單中選取該流量包，然後按一下 **確認**。

   **升級為 premium 授權**

Premium 授權適用於**生產環境**，有效期為**一年**。

   完成以下步驟以升級為 premium 授權。

      1. 按一下 **立即購買**。

之後，您必須參閱[步驟 2：取得授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management#8a4f3efc)，以下載 basic 或 premium 授權檔案，或從 [SDK 管理](https://console.byteplus.com/live/main/sdk)頁面取得授權 URL。然後，將您用於 SDK 整合的試用授權替換為新授權。

## 續約授權

當您的 basic 或 premium 授權即將到期或已到期時，**SDK 管理**頁面會顯示到期提醒。請及時續約授權，以避免線上服務中斷。

1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，按一下 **SDK 管理**。

3. 在您要續約之授權的 **操作** 欄中按一下 **續約**。

   > **说明**

## 常見問題

### 續約授權後，我是否必須發佈新版應用程式？

* 對於 Android 或 iOS 應用程式：否，續約授權後，您不需要發佈新版應用程式。授權續約後，SDK 會自動偵測授權檔案中的變更，並更新授權的有效期。不過，為避免網路問題造成自動更新的潛在問題，建議您手動下載新的授權檔案，將目前應用程式版本中的舊授權檔案替換為新的授權檔案，然後發佈新版應用程式。

* 對於 Web 應用程式：這取決於您整合 Player SDK for Web 時設定授權的方式。

   * 如果您設定授權 URL：您**不需要**執行任何操作。您續約授權後，SDK 會自動更新至最新的授權版本。

   * 如果您未設定授權 URL：您**必須**手動更新授權檔案，然後**發佈新版**應用程式。

### 變更 SDK 應用程式的 PackageName、BundleID、萬用字元網域或 WebOTT 應用程式識別碼後，我是否需要替換授權？

* 如果授權已啟用，變更後系統會根據更新後的應用程式資訊重新產生授權。您需要替換 SDK 授權檔案或授權 URL。原始授權會在一段時間內保持有效，新授權會保留與原始授權相同的到期時間。

* 如果授權已到期，續約授權時，系統會根據更新後的應用程式資訊產生新授權。續約完成後，您需要替換 SDK 授權檔案或授權 URL。

### 替換授權檔案後，我還需要做什麼？

替換授權檔案後，您**必須**發佈新版應用程式。對觀眾的影響如下：

* 對於 Android 或 iOS 應用程式：觀眾**必須**更新至最新版本的應用程式，才能繼續使用服務。

* 對於 Web 應用程式：瀏覽器會在下次造訪或重新整理頁面時自動載入新資源，因此觀眾**不需要**執行任何操作。

### 升級或續約後，授權的新有效期如何計算？

計算方式取決於具體操作：

* **續約**：有效期會透過**在目前授權的原始到期日期上增加一年**來延長。例如，如果您的授權於 2026 年 5 月 10 日到期，且您將授權續約一年，則無論您何時執行續約，新的到期日期都會是 2027 年 5 月 10 日。

* **升級**：新的為期一年有效期從升級日期開始計算。

如需詳細資訊，請參閱[計算有效期](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses#55ec08cd)。

### 如果我的授權到期，會發生什麼事？

授權到期會導致服務中斷。為避免影響您的業務，請務必及時續約授權。

### 如何將 basic 授權升級為 premium 授權？

目前，您無法直接將 basic 授權升級為 premium 授權。您必須建立新的 SDK 應用程式，並將 premium 授權綁定至該應用程式。如需詳細資訊，請參閱[步驟 1：建立或綁定 SDK 應用程式](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-management#91608dc8)。
