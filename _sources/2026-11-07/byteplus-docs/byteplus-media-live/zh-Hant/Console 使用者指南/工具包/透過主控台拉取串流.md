要在主控台中快速測試並比較您的直播串流，您可以使用 **Web pull** 工具。此工具整合了 BytePlus MediaLive Player SDK for Web，讓您在將 SDK 集成到自己的應用程式之前，方便預覽播放並比較串流品質。

Web Pull 整合了 BytePlus MediaLive Player SDK for Web。若要將 SDK 集成到您的應用程式，請參考 [Player SDK for Web: SDK overview](https://docs.byteplus.com/docs/byteplus-media-live/docs-introduction-to-the-player-sdk-for-web)。

<span id="Prerequisites"></span>
## 先決條件

Web Pull 提供預設的拉流地址。若您只想體驗 BytePlus MediaLive 的功能，例如播放、靜音、彈幕及畫中畫（PiP），可直接使用該地址。若要使用您自己的拉流地址，請在啟動 Web Pull 前完成以下操作：


* 拉流用的網域名稱，並已配置 SSL 憑證。如需更多資訊，請參考 [Adding a domain name](https://docs.byteplus.com/docs/byteplus-media-live/docs-domain) 和 [Adding an SSL certificate ](https://docs.byteplus.com/docs/byteplus-media-live/docs-https)。

* 將拉流網域名稱與推流網域名稱關聯。詳情請參考 [Domain](https://docs.byteplus.com/byteplus-media-live/docs/domain)。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Web Pull 僅支援 HTTPS 地址。若要播放 HTTP 地址，請前往 <a href="https://demo.byteplus.com/common/veplayer/v2/basic/example?tab=function-display">VePlayer</a>，該平台展示 BytePlus MediaLive Player SDK for Web 提供的更多功能。</div>


<span id="Procedure"></span>
## 操作流程


1. 登入 [BytePlus MediaLive console](https://console.byteplus.com/live)。

2. 在左側導覽窗格中，選擇 **Toolkits** \> **Web pull**。

3. 於 **Play** 標籤頁，在 **Click to play** 按鈕旁的輸入框中輸入拉流地址。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若您尚未擁有地址，請點擊 <strong>Generate addresses</strong> 並填寫表單以生成 M3U8 格式的地址，或使用 <a href="https://docs.byteplus.com/byteplus-media-live/docs/address-generator">Address generator</a> 生成您所需格式的地址。   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e4fa3ac0a65b4ab58d903b85a88b02ec~tplv-goo7wpa0wc-image.image) </span>

4. 於 **Play comparison** 標籤頁，在 **Play comparison** 按鈕旁的輸入框中輸入多個拉流地址。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">支援最多 4 路直播串流的播放與比較。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">支援使用 2 倍及 4 倍放大鏡，實時比較畫面細節。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">支援查看比較細節，顯示直播串流碼率及畫質評分數據。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">碼率比較與畫質比較將於 3 分鐘後自動停止。請注意，畫質比較數據可能需要一些時間才能產生。建議等待約 5 分鐘以查看最終比較結果。   </div>
