若要快速測試 BytePlus MediaLive 的串流功能，可在控制台使用 **Web push** 工具。本主題將說明如何從您的攝影機、螢幕分享，或本地/線上影片檔推送串流，協助您生成推流地址並於數分鐘內開始串流。

若要查看串流內容，請使用 [Web pull](https://docs.byteplus.com/byteplus-media-live/docs/web-pull) 工具。請參閱 [Domain name space](https://docs.byteplus.com/docs/byteplus-media-live/docs-glossary#Vhost)，了解推流與拉流地址的詳細關聯說明。

Web Push 整合了 BytePlus MediaLive Broadcast SDK for Web。若要將 SDK 整合至您的應用程式，請參閱 [Broadcast SDK for Web: SDK overview](https://docs.byteplus.com/docs/byteplus-media-live/docs-introduction-to-the-broadcast-sdk-for-web)。

<span id="Prerequisites"></span>
## 先決條件


* 已配置 SSL 憑證的推流網域名稱。如需詳細資訊，請參閱 [Adding a domain name](https://docs.byteplus.com/docs/byteplus-media-live/docs-domain) 及 [Adding an SSL certificate](https://docs.byteplus.com/docs/byteplus-media-live/docs-https)。

* 攝影機與麥克風。您的瀏覽器需有使用攝影機與麥克風的權限。


<span id="Procedure"></span>
## 操作流程


1. 登入 [BytePlus MediaLive 控制台](https://console.byteplus.com/live)。

2. 於左側導覽窗格，前往 **Toolkits** \> **Web push**。

3. 於 **Screen selection** 區段選擇影片來源。您可選擇攝影機、螢幕分享、本地影片檔或線上 MP4 檔作為影片來源。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/194e73ab45e0489ab68e4402274f1b98~tplv-goo7wpa0wc-image.image) </span>

4. 於 **Audio selection** 區段選擇音訊來源。您亦可上傳本地音訊檔或提供線上 MP3 檔的 URL 作為背景音訊。

5. 設定擷取與推流參數。您可使用推薦設定或自訂設定。如需推薦設定的詳細資訊，請參閱下方表格。

   影片設定：

   
   |**設定** |**解析度、幀率與位元率** |
   |---|---|
   |120p |160x120，15 fps，200 Kbps |
   |180p |320x180，15 fps，350 Kbps |
   |240p |320x240，15 fps，400 Kbps |
   |360p |640x360，15 fps，800 Kbps |
   |480p |640x480，15 fps，900 Kbps |
   |720p\-1 |1280x720，15 fps，1500 Kbps |
   |720p\-2 |1280x720，25 fps，1500 Kbps |
   |720p\-3 |1280x720，30 fps，1500 Kbps |
   |1080p\-1 |1920x1080，15 fps，2000 Kbps |
   |1080p\-2 |1920x1080，25 fps，2000 Kbps |
   |1080p\-3 |1920x1080，30 fps，2000 Kbps |
   

   音訊設定：

   
   |**設定** |**取樣率與位元率** |
   |---|---|
   |標準 |48000 Hz，40 Kbps |
   |高 |48000 Hz，128 Kbps |
   

6. 輸入 RTM 推流地址。若尚無地址，請於預覽視窗下方點選 **Generate** 以生成推流地址。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b4dc17c1aaea4a068065bd6a78e52c49~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Web Push 僅支援 HTTPS 位址。此外，請確保在推流位址中包含 9922 埠號。正確格式應為：<code>https://{DOMAIN_NAME}:9922/{APP_NAME}/{STREAM_NAME}.sdp</code>。   </div>
   

7. 點選 **Start** 開始推送串流。


<span id="Result"></span>
## 結果


* 開始串流後，**Callback notification** 區段會顯示通知，確認連線已建立。通知亦會包含詳細串流統計資訊，例如編碼器與位元率。您可閱讀、清除或暫停/恢復回調通知。

* 串流過程中，您可關閉音訊或影片、變更音訊與影片來源，或調整擷取設定。

* 若要停止串流，請點選 **Stop pushing**。


<span id="1857c856"></span>
## 常見問題

若您於點選 **Start** 後，在 **Callback notification** 區段收到錯誤訊息「[2001] Failed to fetch」，表示 SDK 推流時發生錯誤。此錯誤通常由網路問題造成。建議稍候片刻再嘗試重新開始串流。
