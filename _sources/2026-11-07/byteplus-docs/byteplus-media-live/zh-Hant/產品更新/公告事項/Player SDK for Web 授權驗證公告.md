* 生效日期：2026 年 1 月 7 日

* 適用版本：自 2.11.0 版本起，整合 Player SDK for Web 時需進行授權配置。如需更多資訊，請參閱 [Step 3: 設定授權](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1-zh-TW#f1396aa0)。
