親愛的開發者，

即日起，BytePlus MediaLive 將停止更新並移除用戶端 Broadcast SDK 的文件。受影響的 SDK 包括 BytePlus MediaLive **iOS、Android 和 React Native 的 Broadcast SDK**。


* **影響範圍**

   * 新用戶：若需要 Broadcast SDK，建議優先評估以下替代方案：

      * Web Broadcast SDK：請使用 [BytePlus MediaLive Web 端 Broadcast SDK](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-broadcast-sdk-for-web)。

      * 用戶端 Broadcast SDK：請使用 BytePlus RTC 提供的 [用戶端 SDK](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-79882)。

   * 現有用戶： 已整合並正在使用 BytePlus MediaLive 用戶端 Broadcast SDK 的現有用戶不受影響。您可繼續在 BytePlus 官網續約服務，並照常使用 SDK。

* **持續維護**

   自 **2026 年 8 月 7 日**起，BytePlus MediaLive 用戶端 Broadcast SDK 將不再提供功能更新或新版本。但仍會持續提供例行維護與錯誤修復。


若仍需使用 BytePlus MediaLive 用戶端 Broadcast SDK，或對此變更有任何疑問，請 [提交工單](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980)聯繫 BytePlus 支援團隊。
