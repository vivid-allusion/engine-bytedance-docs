呼叫 `UnBindEncryptDRM` API 以刪除已建立的加密配置。

<span id="Requirements"></span>
## 需求


* 頻率限制：每個帳戶每秒 1 次查詢。

* 生效時間：配置刪除後約 3~5 分鐘生效。


<span id="HTTP request"></span>
## HTTP 請求


* 方法：POST

* 端點：https://open.byteplusapi.com/?Action=UnBindEncryptDRM&Version=2023\-01\-01


<span id="Request parameters"></span>
