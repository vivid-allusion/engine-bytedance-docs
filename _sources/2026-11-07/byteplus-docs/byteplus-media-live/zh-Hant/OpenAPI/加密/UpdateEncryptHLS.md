呼叫 `UpdateEncryptHLS` 介面，以新增或更新用於 HLS 標準加密的自建金鑰管理服務地址，以及直播串流的金鑰更新週期。

<span id="Requirements"></span>
## 需求

頻率限制：每個帳戶每秒 1 次查詢。

<span id="HTTP request"></span>
## HTTP 請求


* 方法：POST

* 端點：https://open.byteplusapi.com/?Action=UpdateEncryptHLS&Version=2023\-01\-01


<span id="Request parameters"></span>
## 請求參數

<span id="Common parameters"></span>
### 通用參數

所有 API 除了 API 專屬參數外，還必須帶上 [通用參數](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters)。

<span id="Query"></span>
### 查詢


|**參數** |**資料型別** |**是否必填** |**範例值** |**說明** |
|---|---|---|---|---|
|Action |String |是 |`UpdateEncryptHLS` |API 操作名稱。 |
|Version |String |是 |`2023-01-01` |本 API 操作的版本。目前版本：2023\-01\-01。 |


<span id="Body parameters"></span>
### Body 參數


|**參數** |**資料型別** |**是否必填** |**範例值** |**說明** |
|---|---|---|---|---|
|URL |String |是 |`http://example.kms.com/get_key?` |客戶端建立自建金鑰管理服務後，需向金鑰管理服務請求取得金鑰的地址。 |
|CycleTime |String |是 |`60` |MediaLive 中伺服器產生金鑰的更新週期以秒為單位，取值範圍為 [60,604800]。 |


<span id="Response parameters"></span>
## 回應參數
