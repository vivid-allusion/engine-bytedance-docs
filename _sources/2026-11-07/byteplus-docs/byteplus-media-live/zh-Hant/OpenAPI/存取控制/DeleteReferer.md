呼叫 `DeleteReferer` API，以刪除 Referer 封鎖清單或允許清單組態。

## 要求

速率限制：每個帳戶每秒 1 次查詢。

## HTTP 請求

* 方法：POST

* 端點：https://open.byteplusapi.com/?Action=DeleteReferer&Version=2023\-01\-01

## 請求參數

### 通用參數

所有 API 除了 API 特定參數外，都必須搭配[通用參數](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters)呼叫。

### 查詢

|參數 |資料類型 |必填 |範例值 |說明 |
|---|---|---|---|---|
|Action |String |是 |`DeleteReferer` |API 操作。 |
|Version |String |是 |`2023-01-01` |此 API 操作的版本。目前版本：2023\-01\-01。 |

### 主體參數

|參數 |資料類型 |必填 |範例值 |說明 |
|---|---|---|---|---|
|Vhost |String |是 |`push.example.com` |網域名稱空間。您可以呼叫 [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API，或前往 BytePlus MediaLive 主控台中的 [網域](https://console.byteplus.com/live/main/domain/list) 頁面，以取得網域名稱空間。 |
|Domain |String |是 |`pull.example.com` |用於拉流的網域名稱。您可以呼叫 [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API，或前往 BytePlus MediaLive 主控台中的 [網域](https://console.byteplus.com/live/main/domain/list) 頁面，以取得網域名稱。 |

## 回應參數

此 API 在回應中僅傳回[通用參數](https://docs.byteplus.com/en/byteplus-platform/reference/request-response)。

## 範例

### 範例請求

```json
POST https://open.byteplusapi.com/?Action=DeleteReferer&Version=2023-01-01
{
    "Vhost": "push.example.com",
    "Domain": "pull.example.com"
}
```

### 範例回應

```json
{
    "ResponseMetadata": {
        "RequestId": "20230604110420****100232280022D31",
        "Action": "DeleteReferer",

        "Service": "live",
        "Region": "ap-singapore-1"
    }
}
```
