呼叫 `DeleteTranscodePreset` API 以刪除已建立的轉碼配置。

<span id="Requirements"></span>
## 需求


* 頻率限制：每個帳戶每秒最多 10 次查詢。

* 生效說明：新增、更新及刪除轉碼配置後，需於操作後（3\-5 分鐘）重新推流及拉流，才能使用已變更的配置。


<span id="HTTP request"></span>
## HTTP 請求


* 方法：POST

* 端點：https://open.byteplusapi.com/?Action=DeleteTranscodePreset&Version=2023\-01\-01
