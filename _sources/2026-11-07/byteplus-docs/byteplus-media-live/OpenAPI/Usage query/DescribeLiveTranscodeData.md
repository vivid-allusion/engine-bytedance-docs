Call the `DescribeLiveTranscodeData` API to query the transcoding duration usage of a specific live domain within a specified time range.

<span id="requirements"></span>
## Requirements


* Billing: For transcoding pricing, please refer to [Transcoding](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-transcoding).

* Limitations: Supports querying the total duration of transcoding generated by specified domains (including deleted domains).

* Rate limit: 30 queries per second per account

* Data latency: 20 minutes


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveTranscodeData&Version=2023\-01\-01
