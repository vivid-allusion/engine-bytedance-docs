Call the `DescribeLiveP95PeakBandwidthData` API to query the 95th percentile peak bandwidth usage of a specific live domain within a specified time range, including the upstream 95th percentile peak bandwidth of the push stream domain and the downstream 95th percentile peak bandwidth of the pull stream domain.

<span id="requirements"></span>
## Requirements


* Limitations: Supports querying the 95th percentile peak bandwidth usage data generated by specified domains (including deleted domains).

* Rate limit: 30 queries per second per account

* Data latency: 15 minutes

* Data metric: Bandwidth data is calculated in base 1000, for example, 1 Mbps = 1000 Kbps.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveP95PeakBandwidthData&Version=2023\-01\-01
