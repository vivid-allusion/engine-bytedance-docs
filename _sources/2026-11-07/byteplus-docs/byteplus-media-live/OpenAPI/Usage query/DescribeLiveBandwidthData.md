Call the `DescribeLiveBandwidthData` API to query the bandwidth usage of specified live streaming domains within the specified time range, including the upstream peak bandwidth of push domains and the downstream peak bandwidth of pull domains.

<span id="requirements"></span>
## Requirements


* Billing: For bandwidth pricing, please refer to [Live-streaming service fees](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-live-streaming-service-fees).

* Limitations:

   * Supports querying bandwidth usage data generated by deleted domains.

   * Bandwidth usage data is used for billing and reconciliation purposes and is collected differently from bandwidth data monitoring. Please use [DescribeLiveMetricBandwidthData](https://docs.byteplus.com/en/docs/byteplus-media-live/describeLivemetricbandwidthdata) to query live bandwidth monitoring data.

* Rate limit: 30 queries per second per account

* Data latency: 15 minutes

* Data metric: Bandwidth data is calculated in base 1000, for example, 1 Mbps = 1000 Kbps.

* Statistical rules: Bandwidth usage data is calculated every 5 minutes. Based on the query time and granularity setting, it returns the maximum value within the time range and the maximum value within the granularity.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveBandwidthData&Version=2023\-01\-01
