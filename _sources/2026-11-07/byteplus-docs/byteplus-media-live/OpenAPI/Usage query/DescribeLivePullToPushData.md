Call the `DescribeLivePullToPushData` API to query the duration usage of all relay tasks generated by the group within a specified time range.

<span id="requirements"></span>
## Requirements


* Billing: For relay pricing, please refer to [Relay](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-relay-1).

* Rate limit: 30 queries per second per account

* Data latency:

   * When the aggregation granularity is 60 seconds, the data latency is 5 minutes;

   * For other time granularities, the data latency is 15 minutes.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLivePullToPushData&Version=2023\-01\-01

<span id="body-parameters"></span>
### Body parameters


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|GroupList |Array of String |No |`["group001"]` |The list of relay task groups. The default value is empty, which indicates querying the duration usage of all relay tasks. |
|StartTime |String |Yes |`2022-03-07T00:00:00Z` |The start time of your query's range in RFC 3339 format with second precision. |
|EndTime |String |Yes |`2021-04-14T00:00:00Z` |The end time of your query's range in RFC 3339 format with second precision. |
|Aggregation |Integer |No |`3600` |The granularity of data aggregation, measured in seconds, with the following supported options:<br><br><br>* `60`: 1 minute. When aggregated every 1 minute, the maximum time span for a single query is 24 hours, and the historical query time range is 366 days;<br><br>* `3600`: 1 hour. When aggregated in 1\-hour intervals, the maximum time span for a single query is 93 days, and for historical queries, the maximum time range is 366 days.<br><br>* `86400`: (default) 1 day. When aggregated in 1\-day intervals, the maximum time span for a single query is 93 days, and for historical queries, the maximum time range is 366 days. |
|DetailField |Array of String |No |`["Group"]` |The dimension for data segmentation is empty by default, indicating no data segmentation. Currently, only the `Group` dimension is supported for data segmentation.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Data segmentation by the <code>Group</code> dimension will occur only if the <code>DetailField</code> parameter is set to <code>Group</code> and the <code>GroupList</code> parameter contains multiple values.</div><br> |
|App |String |No |`live` |The AppName field in the live stream URL. It can include uppercase letters (A\-Z), lowercase letters (a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 30 characters.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When querying stream granularity data, both the <code>App</code> and <code>Stream</code> parameters are required.</div><br> |
|Stream |String |No |`example_stream` |The StreamName field in the live stream URL. It can include uppercase and lowercase letters (A\-Z, a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 100 characters.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When querying stream granularity data, both the <code>App</code> and <code>Stream</code> parameters are required.</div><br> |

|Parameter |Data Type |Sample Value |Description |

|---|---|---|---|
