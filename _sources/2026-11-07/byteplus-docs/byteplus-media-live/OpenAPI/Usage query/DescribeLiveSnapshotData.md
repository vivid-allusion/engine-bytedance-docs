Call the `DescribeLiveSnapshotData` API to retrieve the number of snapshots generated by the screenshot feature for a specific live domain within a specified time range.

<span id="requirements"></span>
## Requirements


* Billing: For screenshot pricing, please refer to [Screenshot capturing](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-screenshot-capturing).

* Limitations: Supports querying the number of screenshots generated by all live screenshot tasks for specified domains (including deleted domains).

* Rate limit: 30 queries per second per account.

* Data latency: 15 minutes.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveSnapshotData&Version=2023\-01\-01

<span id="body-parameters"></span>
### Body parameters


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|DomainList |Array of String |No |`["push.example.com","push2.example.com"]` |List of domains. By default, it is empty, indicating that snapshot usage data for all domains under your BytePlus MediaLive will be queried. You can call the [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API or go to the [Domains](https://console.byteplus.com/live/main/domain/list) page in the BytePlus MediaLive console to obtain the domains to be queried. |
|StartTime |String |Yes |`2021-04-13T00:00:00Z` |The start time of your query's range in RFC 3339 format with second precision. |
|EndTime |String |Yes |`2021-04-14T00:00:00Z` |The end time of your query's range in RFC 3339 format with second precision. |
|Aggregation |Integer |No |`86400` |The granularity of data aggregation, measured in seconds, with the following supported options:<br><br><br>* `300`: 5 minutes. When aggregated in 5\-minute intervals, the maximum time span for a single query is 31 days, and for historical queries, the maximum time range is 366 days.<br><br>* `3600`: 1 hour. When aggregated in 1\-hour intervals, the maximum time span for a single query is 93 days, and for historical queries, the maximum time range is 366 days.<br><br>* `86400` (default): 1 day. When aggregated in 1\-day intervals, the maximum time span for a single query is 93 days, and for historical queries, the maximum time range is 366 days. |
|DetailField |Array of String |No |`["Domain"]` |The dimension for data segmentation is empty by default, indicating no data segmentation. Currently, only the `Domain` dimension is supported for data segmentation.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Data segmentation by the <code>Domain</code> dimension will occur only if the <code>DetailField</code> parameter is set to <code>Domain</code> and the <code>DomainList</code> parameter contains multiple values.</div><br> |
|App |String |No |`live` |The AppName field in the live stream URL. It can include uppercase letters (A\-Z), lowercase letters (a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 30 characters.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When querying stream granularity data, both the <code>App</code> and <code>Stream</code> parameters are required.</div><br> |
|Stream |String |No |`example_stream` |The StreamName field in the live stream URL. It can include uppercase and lowercase letters (A\-Z, a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 100 characters.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When querying stream granularity data, both the <code>App</code> and <code>Stream</code> parameters must be provided.</div><br> |

## Response parameters

For unique API\-specific response parameters, see the table below. For more details, refer to the [Request response](https://docs.byteplus.com/en/docs/byteplus-platform/reference-request-response) section.


|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|DomainList |Array of String |`["push.example.com","push.example.com"]` |List of domain names. |
|StartTime |String |`2021-04-13T00:00:00Z` |The start time of your query's range in RFC 3339 format with second precision. |
|EndTime |String |`2021-04-14T00:00:00Z` |The end time of your query's range in RFC 3339 format with second precision. |
|Aggregation |Integer |`300` |Data granularity, measured in seconds. |
|DetailField |Array of String |`["Domain"]` |The data segmentation dimension is currently limited to `Domain`, representing domain names. |
|Total |Integer |`19503380` |The total number of screenshots taken under the current query conditions. |
|SnapshotDataList |Array of [SnapshotDataList](https://docs.byteplus.com/en/docs/24/25094#snapshotdatalist) |`-` |Data at all time granularity levels. |

|App |String |`live` |The AppName field of a stream when querying stream granularity data. |
|Stream |String |`example_stream` |The StreamName field of a stream when querying stream granularity data. |


<span id="snapshotdatalist"></span>
### SnapshotDataList


|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|TimeStamp |String |`2022-04-13T00:00:00Z` |The start time of each time granularity when data is aggregated by time granularity, formatted in RFC3339 UTC time with second precision. |
|Value |Integer |`9503380` |The total number of screenshots taken within the current data aggregation time granularity. |


<span id="snapshotdetaildata"></span>
### SnapshotDetailData


|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|Domain |String |`push.example.com` |Domain name information when data is segmented by the domain dimension. |
|Total |Integer |`19503380` |The total number of screenshots taken for the current dimension after data is segmented by dimensions. |
|SnapshotDataList |Array of [SnapshotDataList](https://docs.byteplus.com/en/docs/24/25094#snapshotdatalist) |`-` |All data at every granularity level under the current dimension after data is segmented by dimensions. |
