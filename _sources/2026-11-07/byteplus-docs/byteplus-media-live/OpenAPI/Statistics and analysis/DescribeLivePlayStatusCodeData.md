Call the `DescribeLivePlayStatusCodeData` API to query the proportion of status codes for requests made to the domain within the specified time range, including push streaming requests, pull streaming requests, and source streaming requests.

<span id="requirements"></span>
## Requirements


* Limitations: Supports querying the status code distribution of push\-pull streaming requests or origin requests generated by specific domains (including deleted domains).

* Rate limit: 30 queries per second per account

* Data latency: 15 minutes


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLivePlayStatusCodeData&Version=2023\-01\-01
