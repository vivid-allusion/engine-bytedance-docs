Call the `DescribeLiveEdgeStatData` interface to query data such as upstream and downstream traffic, upstream and downstream peak bandwidth, and the number of requests generated by live streams under the specified protocol, ISP, region, and time range.

<span id="usage-scenario"></span>
## Usage scenario


* Limitations:

   * Bandwidth data is used for data monitoring and is collected differently from bandwidth usage data. Please use [DescribeLiveBandwidthData](https://docs.byteplus.com/en/docs/byteplus-media-live/eescribelivebandwidthdata) to query live bandwidth usage data.

   * Traffic data is used for data monitoring and is collected differently from traffic usage data. Please use the [DescribeLiveTrafficData](https://docs.byteplus.com/en/docs/byteplus-media-live/describelivetrafficdata) API to query live traffic usage data.

* Rate limit: 30 queries per second per account.

* Data latency:

   * When the aggregation granularity is 60 seconds, the data latency is 5 minutes;

   * For other time granularities, the data latency is 15 minutes.

* Data metric:

   * Bandwidth data is calculated in base 1000, for example, 1 Mbps = 1000 Kbps.

   * Traffic data is calculated in base 1000, for example, 1 GB = 1000 MB.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveEdgeStatData&Version=2023\-01\-01
