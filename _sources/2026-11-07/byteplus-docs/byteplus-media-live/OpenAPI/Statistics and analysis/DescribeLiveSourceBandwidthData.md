Call the `DescribeLiveSourceBandwidthData` API to query the monitoring data of source bandwidth generated by specified pull stream domains or source streams within the specified time range.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">As of February 18, 2025, we will no longer maintain this legacy API. Its documentation will be retired on May 18, 2025. We recommend transitioning to the updated UpdateUser interface. For details, see the <a href="https://docs.byteplus.com/en/docs/byteplus-media-live/describelivesourcetrafficdata">DescribeLiveSourceTrafficData</a> documentation.</div>


<span id="requirements"></span>
## Requirements


* Limitations: Support querying the bandwidth usage data generated by specified pull stream domains (including deleted domains) or specified origin streams.

* Rate limit: 30 queries per second per account

* Data latency:

   * When the aggregation granularity is 60 seconds, the data latency is 5 minutes;

   * For other time granularities, the data latency is 15 minutes.

* Data metric: Bandwidth data is calculated in base 1000, for example, 1 Mbps = 1000 Kbps.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveSourceBandwidthData&Version=2023\-01\-01
