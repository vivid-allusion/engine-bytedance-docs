Call the `DescribeLiveBatchPushStreamMetrics` API to query push\-stream statistics for one or more streams under a domain name for push streaming, including frame rates, bitrates, presentation timestamps (PTS), and more. You can use the statistics to monitor the health of a stream\-pushing session. You can query the data for deleted domain names.

<span id="requirements"></span>
## Requirements


* Limitations: Supports querying historical streaming data generated by deleted domain names.

* Rate limit: 30 queries per second per account.

* Data latency: 30 seconds.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveBatchPushStreamMetrics&Version=2023\-01\-01

<span id="metriclist"></span>
### MetricList


|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|TimeStamp |String |`2022-04-13T00:00:00+08:00` |The start time of each time granularity when data is aggregated by time granularity, formatted in RFC3339 UTC time with second precision. |
|Bitrate |Float |`20` |The video bitrate obtained by the aggregation algorithm within the data aggregation time granularity, in kbps. |
|Framerate |Float |`20` |The video frame rate obtained by the aggregation algorithm within the data aggregation time granularity, in fps. |
|AudioFramerate |Float |`20` |The audio frame rate (the number of audio data packets transmitted per second) obtained by the aggregation algorithm within the data aggregation time granularity. |
|AudioBitrate |Float |`20` |The audio bitrate obtained by the aggregation algorithm within the data aggregation time granularity, in kbps. |
|AudioPts |Double |`9558439` |The Presentation Time Stamp (PTS) of the last audio frame within the current data aggregation time granularity, unit is milliseconds. |
|VideoPts |Double |`9558438` |The Presentation Time Stamp (PTS) of the last video frame within the current data aggregation time granularity, unit is milliseconds. |
|PtsDelta |Float |`1` |The difference in display timestamps between all audio and video frames obtained by the aggregation algorithm within the current data aggregation time granularity, i.e., the maximum difference between all Audio PTS and Video PTS values, unit is milliseconds. |
|AudioFrameGap |Float |`20` |The difference between the display timestamps of adjacent audio frames obtained by the aggregation algorithm within the current data aggregation time granularity, unit is milliseconds. |
|VideoFrameGap |Float |`20` |The difference between the display timestamps of adjacent video frames obtained by the aggregation algorithm within the current data aggregation time granularity, unit is milliseconds. |
|StreamBeginTime |Long |`1723726121000` |Push start time, expressed in milliseconds using Unix timestamps. |
|FirstFrameTime |Integer |`10` |The time consumption from the establishment of the push streaming connection to the reception of the first frame, in milliseconds. |
|ClientIp |String |`127.0.0.1` |The IP address of push streaming client. |
|ServerIp |String |`127.0.0.1` |The IP address of push streaming server. |
|Resolution |String |`1280x720` |Push screen resolution. |
|VCodec |String |`H264` |Video codec. |
|ACodec |String |`AAC` |Audio codec. |
