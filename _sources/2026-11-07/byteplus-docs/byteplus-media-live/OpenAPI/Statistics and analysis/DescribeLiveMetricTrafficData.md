Call the `DescribeLiveMetricTrafficData` API to query the traffic monitoring data of live domains or live streams within the specified time range.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">As of February 18, 2025, we will no longer maintain this legacy API. Its documentation will be retired on May 18, 2025. We recommend transitioning to the updated UpdateUser interface. For details, see the <a href="https://docs.byteplus.com/en/docs/byteplus-media-live/docs-describeliveedgestatdata-2023">DescribeLiveEdgeStatData</a> documentation.</div>


<span id="requirements"></span>
## Requirements


* Limitations:

   * Supports querying traffic monitoring data generated by specified live domains (including deleted domains) or live streams.

   * Traffic monitoring data is used for data monitoring and is collected differently from traffic usage data. Please use the [DescribeLiveTrafficData](https://docs.byteplus.com/en/docs/byteplus-media-live/describelivetrafficdata) API to query live traffic usage data.

* Rate limit: 100 queries per second per account

* Data latency:

   * When the aggregation granularity is 60 seconds, the data latency is 5 minutes;

   * For other time granularities, the data latency is 15 minutes.

* Data metric: Traffic data is calculated in base 1000, for example, 1 GB = 1000 MB.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveMetricTrafficData&Version=2023\-01\-01
