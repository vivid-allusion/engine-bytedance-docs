Gets the monitoring data, such as frame rate and bitrate of audios and videos, for all or specific origin\-pull streams under specific domain name for stream pulling within specific time range. You can use the monitoring data to assess the health of origin\-pull streams.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can get historical origin\-pull stream data generated by deleted domains.</div>


<span id="requirements"></span>
## Requirements


* Rate limit: 30 requests per second per account

* Data latency: 15 minutes


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveBatchSourceStreamMetrics&Version=2023\-01\-01

<span id="metriclist"></span>
### MetricList


|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|TimeStamp |String |`2022-04-13T00:00:00+08:00` |The start time (UTC time in RFC 3339 format with second precision) of each granularity when data is aggregated by time granularity. |
|Bitrate |Float |`20` |The video bitrate obtained by the aggregation algorithm within the current data aggregation time granularity, measured in kbps. |
|Framerate |Float |`20` |The video frame rate obtained by the aggregation algorithm within the current data aggregation time granularity, measured in fps. |
|AudioFramerate |Float |`20` |The audio frame rate obtained by the aggregation algorithm within the current data aggregation time granularity, measured in fps. |
|AudioBitrate |Float |`20` |The audio bitrate obtained by the aggregation algorithm within the current data aggregation time granularity, measured in kbps. |
|AudioPts |Double |`1651831909` |The Presentation Time Stamp (PTS) of the last audio frame within the current data aggregation time granularity, measured in milliseconds. |
|VideoPts |Double |`1651831910` |The PTS of the last video frame within the current data aggregation time granularity, measured in milliseconds. |
|PtsDelta |Float |`1` |The maximum or average value of the difference between audio and video frame PTS obtained by the aggregation algorithm within the current data aggregation time granularity, namely the maximum or average value of the difference between all `AudioPts` and `VideoPts`, measured in milliseconds. |
|AudioFrameGap |Float |`20` |The average value of the maximum difference between adjacent audio frame PTS obtained by the aggregation algorithm within the current data aggregation time granularity, measured in milliseconds. |
|VideoFrameGap |Float |`20` |The maximum or average value of the difference between adjacent video frame PTS obtained by the aggregation algorithm within the current data aggregation time granularity, measured in milliseconds." |
