Call the `DeleteHTTPHeaderConfig` API to delete HTTP header configurations for a specified domain name which have been added through UpdateHTTPHeaderConfig.

<span id="requirements"></span>
## Requirements

Rate limit：10 queries per second per account.

<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DeleteHTTPHeaderConfig&Version=2023\-01\-01


<span id="request-parameters"></span>
## Request parameters

<span id="common-parameters"></span>
### Common parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters) in addition to API\-specific parameters.

<span id="query"></span>
### Query


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`DeleteHTTPHeaderConfig` |The API operation. |
|Version |String |Yes |`2023-01-01` |The version of this API operation. Current version: 2023\-01\-01. |


<span id="body-parameters"></span>
### Body parameters


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Vhost |String |Yes |`example` |The domain name space. You can call the [DescribeHTTPHeaderConfig](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-describehttpheaderconfig) API to obtain the values of the domain name space of the configuration to be deleted. |
|Domain |String |No |`example.com` |The domain name for stream pulling. You can call the [DescribeHTTPHeaderConfig](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-describehttpheaderconfig) API to obtain the values of the domain name of the configuration to be deleted. |
|Phase |Integer |Yes |`0` |The type of the HTTP header configuration. You can call the [DescribeHTTPHeaderConfig](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-describehttpheaderconfig) API to obtain the values of the type of the configuration to be deleted.<br><br><br>* `0`: Response headers.<br><br>* `1`: Request headers. |


<span id="response-parameters"></span>
## Response parameters

This API only returns [common parameters](https://docs.byteplus.com/en/byteplus-platform/reference/request-response) in the response.

    "Domain": "pull.example.com",

}
