Call the `GetHLSEncryptDataKey` API to query the key generated by the live video service server for use in HLS standard encryption.

<span id="requirements"></span>
## Requirements

Rate limit: 100 queries per second per account.

<span id="http-request"></span>
## HTTP request


* Method: GET

* Endpoint: https://open.byteplusapi.com/?Action=GetHLSEncryptDataKey&Version=2023\-01\-01


<span id="request-parameters"></span>
## Request parameters

<span id="common-parameters"></span>
### Common parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters) in addition to API\-specific parameters.

<span id="query"></span>
### Query


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`GetHLSEncryptDataKey` |The API operation. |
|Version |String |Yes |`2023-01-01` |The version of this API operation. Current version: 2023\-01\-01. |
|KeyID |String |Yes |`08e765a4da*****c4028755c3c` |The key ID for each TS segment written in the M3U8 file generated by MediaLive. |


<span id="response-parameters"></span>
## Response parameters

|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|DataKey |String |`2131dadfad23123asd` |Key. |
