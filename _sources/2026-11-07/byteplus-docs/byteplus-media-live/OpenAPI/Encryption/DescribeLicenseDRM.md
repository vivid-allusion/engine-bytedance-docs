Retrieves the DRM license. The player uses the license to decrypt a DRM\-encrypted live stream.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For sample code that shows how to generate the request URL for this API, see <a href="https://docs.byteplus.com/en/docs/byteplus-media-live/docs-encrypting-your-live-streams-using-drm#decrypting-the-content">Decrypting the content</a>.</div>


<span id="requirements"></span>
## Requirements

Rate limit: 1 query per second per account.

<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://live\-gateway\-byteplus.byteintlapi.com/drm_api/?Action=DescribeLicenseDRM&Version=2023\-01\-01

<span id="query"></span>
### Query


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`DescribeLicenseDRM` |The API operation. |
|Version |String |Yes |`2023-01-01` |The version of this API operation. Current version: 2023\-01\-01. |
|Vhost |String |Yes |`drm.example.com` |The domain name space. You can call the [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API or visit the [Domains](https://console.byteplus.com/live/main/domain/list) page in the BytePlus MediaLive console to obtain the domain name space which the domain belongs. |
|Domain |String |Yes |`pull.example.com` |The domain name for stream pulling. You can call the [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API or visit the [Domains](https://console.byteplus.com/live/main/domain/list) page in the BytePlus MediaLive console to obtain the domain name. |
|App |String |Yes |`live` |The AppName field in the live stream URL. It can include uppercase letters (A\-Z), lowercase letters (a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 30 characters. |
|StreamName |String |Yes |`stream-drm` |The StreamName field in the live stream URL. It can include uppercase letters (A\-Z), lowercase letters (a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 100 characters. |
|DRMType |String |Yes |`fp` |The DRM encryption type. Valid values include:<br><br><br>* `fp`: FairPlay<br><br>* `wv`: Widevine<br><br>* `pr`: PlayReady |


<span id="response-parameters"></span>
## Response parameters

This API only returns [common parameters](https://docs.byteplus.com/en/byteplus-platform/reference/request-response) in the response.

<span id="samples"></span>
## Samples

<span id="sample-request"></span>
### Sample request

```json
POST https://live-gateway-byteplus.byteintlapi.com/drm_api/?Action=DescribeLicenseDRM&Version=2023-01-01&Vhost=drm.example.com&Domain=pull.example.com&App=live&StreamName=stream-drm&DRMType=fp
```


<span id="sample-response"></span>
### Sample response

If the request is handled successfully, the response body contains the license file in the form of binary data.
