Call the `CreateTimeShiftPresetV2` API to create live time\-shift configuration. After configuring the live stream for time\-shift, users will be able to watch previously broadcasted content during the live process.

<span id="requirements"></span>
## Requirements


* Prerequisites: Make sure you have configured a recording task and selected the HLS storage format for the AppName.

* Effective description: For adding, updating, and deleting time\-shift configurations, you need to re\-push and pull the stream after the adding, updating, and deleting operations (3\-5 minutes) to use the changed configuration.

* Rate limit: 1 query per second per account.


<span id="http-request"></span>
## HTTP request


* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=CreateTimeShiftPresetV2&Version=2023\-01\-01


<span id="request-parameters"></span>
## Request parameters

<span id="common-parameters"></span>
### Common parameters

All APIs must be called with the [common parameters](https://docs.byteplus.com/en/byteplus-platform/reference/common-parameters) in addition to API\-specific parameters.

<span id="query"></span>
### Query


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Action |String |Yes |`CreateTimeShiftPresetV2` |The API operation. |
|Version |String |Yes |`2023-01-01` |The version of this API operation. Current version: 2023\-01\-01. |


<span id="body-parameters"></span>
### Body parameters


|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|Vhost |String |Yes |`push.example.com` |The domain name space. You can call the [ListDomainDetail](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-listdomaindetail-2023) API or visit the [Domains](https://console.byteplus.com/live/main/domain/list) page in the BytePlus MediaLive console to obtain the domain name space which the domain belongs. |
|App |String |Yes |`live` |The AppName field in the live stream URL. It can include uppercase letters (A\-Z), lowercase letters (a\-z), numbers (0\-9), underscores (_), hyphens (\-), and periods (.), with a length ranging from 1 to 30 characters. |
|MaxShiftTime |Integer |Yes |`300` |Shift time, which moves the live stream's availability by a set amount. For example, if you set `MaxShiftTime` to `86400`, then the live stream will be available as late as one day from its initial broadcast. Unit: second. The default value is `86400`. Valid range: 300–1296000. |
|Type |String |Yes |`tos` |Storage type. Always set it to `tos`. |
|Bucket |String |No |`bucket1` |The bucket of TOS storage. |
|PullDomain |String |Yes |`pull.example.com` |Domain name for stream pulling. |
