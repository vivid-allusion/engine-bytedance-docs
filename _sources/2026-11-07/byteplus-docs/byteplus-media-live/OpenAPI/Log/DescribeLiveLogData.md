Call the `DescribeLiveLogData` API to query the information of log files generated by the domain.

## Requirements

* Limitations:

   * Supports querying log file information generated under specified domains (including deleted domains).

   * Supports querying log data generated within the last 31 days.

   * Supports querying information about log packaging files. For descriptions of various log formats, please refer to [Log format](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-managing-logs#log-format).

* Rate limit: 100 queries per second per account

* Data latency: 1 hour

* Delayed Log Aggregation: Log files may experience a delay in aggregation, with ongoing content supplementation and appending. The most comprehensive log file will be available within a maximum of 24 hours.

## HTTP request

* Method: POST

* Endpoint: https://open.byteplusapi.com/?Action=DescribeLiveLogData&Version=2023\-01\-01

### Body parameters

|Parameter |Data Type |Required |Sample Value |Description |
|---|---|---|---|---|
|StartTime |String |Yes |`2022-04-13T10:00:00Z` |The end time of your query's range in RFC 3339 format with second precision.<br><br>> **说明**<br><br><br><br>* > Currently, only log data for the most recent 31 days can be queried.<br><br><br>* > Log files are split by full hours. Please ensure that the start and end times of the query contain the full\-hour time of the queried period. For example, if you need to query log data from 07:30:00 to 08:10:00 on a certain day, the start time of the log query should be earlier than 07:00:00 and the end time should be later than 09:00:00.<br> |
|EndTime |String |Yes |`2022-04-13T11:00:00Z` |The end time of your query's range in RFC 3339 format with second precision. |
|DomainList |Array of String |No |`["push.example.com","push2.example.com"]` |List of domain names. By default, it represents all push and pull domain names of the current user.<br><br>> **说明**<br><br><br>> When the log type is relay, i.e., `'Type': 'relay'`, this parameter is invalid.<br> |
|Type |String |Yes |`pull` |Log types supported include:<br><br><br>* `pull`: Pull stream logs;<br><br>* `push`: Push stream logs;<br><br>* `source`: Origin logs;<br><br>* `relay`: Pull\-to\-push stream conversion logs. |
|PageNum |Integer |No |`1` |The page number. The value must be greater than or equal to `1`. Default value: `1`. |
|PageSize |Integer |No |`20` |The number of query results per page. Valid values: [1,1000]. Default value: `20`.<br><br>> **说明**<br><br><br>> If you set this parameter to `0`, the default value is used.<br> |

### LogInfoList

|Parameter |Data Type |Sample Value |Description |
|---|---|---|---|
|Domain |String |`push.example.com` |Domain name.<br><br>> **说明**<br><br><br>> When the log type is relay, i.e., `'Type': 'relay'`, this field is empty.<br> |
|LogName |String |`example.com_2023_09_01_000000_010000_0.gz` |Log file name, following the naming conventions as below.<br><br><br>* When related to a domain name: Accelerated domain name_year_month_day_time start_time_end_time_file split number. For example, `www.example.com_2023_08_11_000000_010000_0.gz`;<br><br>* When not related to a domain name: year_month_day_time start_time_end_time_file split number. For example, `2023_08_11_000000_010000_0.gz`;<br><br>* If the number of logs generated for the current event within a certain hour exceeds 1.5 million, multiple log files will be generated, with the file split number indicating the order of the log files, for example, `2023_08_11_000000_010000_0.gz`, `2023_08_11_000000_010000_1.gz`. |
|LogSize |Integer |`12` |Size of the log file, in bytes. |
|DateTime |String |`2022-04-13T00:00:00Z` |Hour interval corresponding to the log file, in RFC3339 format UTC time, with second precision. |
|DownloadUrl |String |`http://example.com/download/20230901/example.com_2023_09_01_000000_010000_0.gz?x-expires=1693918129` |Download link for the log file. |
