## **Showroom**

The client SDK provides live viewing capabilities for showrooms, with support for live playback on both Android and iOS. The SDK enriches the viewing experience by integrating features such as interactive messaging.

## **Gaming**

Building on superior user experience, the client SDK provides low\-latency playback for game live streaming. This allows users to watch live content in real time, which increases user engagement.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/572a686694c8422ca570e4239bfb1678~tplv-goo7wpa0wc-image.image) </span>

## Online education

The client SDK provides live viewing and interactive messaging capabilities, working in conjunction with a high\-availability service link and dynamic hotlink protection to ensure the stability and security of educational live streams.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a36317a8a86248e2b8bbfd010a720a9a~tplv-goo7wpa0wc-image.image) </span>

<span id="4f3a9ba0"></span>
## **E\-commerce**

The client SDK allows viewers to browse and purchase products while watching a live stream. The SDK also supports features such as product highlight replays and user interactions, enabling quick monetization of live streaming traffic.
