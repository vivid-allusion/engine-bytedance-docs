This topic serves as the official changelog for Player SDK for Android. Here, you can find a detailed record of all version updates, including new features, improvements, and bug fixes.

|Release Date |Version |Description |
|---|---|---|
|2026\-10\-14 |1.52.200.1 |* **Improvements**:<br><br>   * Improved the RTM ABR quality level switching callback logic. The SDK now also triggers the [onResolutionSwitch](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-callback#onresolutionswitch) callback when switching between quality levels with the same resolution but different bitrates.<br><br>   * Improved `volcbaselog` handling in multi\-process environments.<br><br>* **Issues fixed**: Fixed an issue where the player could freeze when [stop](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-reference#stop) was called to stop playback. |
|2026\-09\-17 |1.52.100.5 |* **New features**:<br><br>   * Added support for configuring fallback streams for multi\-quality stream configurations used by resolution switching, ABR stream pulling (FLV streams only), and smooth quality level switching. For more information, see [Removing query parameters automatically appended by the SDK](https://docs.byteplus.com/docs/byteplus-media-live/docs-implementing-advanced-features-2#removing-query-parameters-automatically-appended-by-the-sdk).<br><br>   * Added the [onPlayerStatusUpdate](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-callback#VeLivePlayerObserver-onplayerstatusupdate-2) callback, which returns supplemental information about the current playback stream through `extraInfo`.<br><br>   * Added [delayS2sMs](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-keytype#VeLivePlayerStatistics-delays2sms), [delayE2eMs](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-keytype#VeLivePlayerStatistics-delaye2ems), and [delayS2eMs](https://docs.byteplus.com/docs/byteplus-media-live/docs-player-android-api-keytype#VeLivePlayerStatistics-delays2ems) to report SEI\-based delay.<br><br>* **Improvements**: Adapted to RTC 360.<br><br>* **Issues fixed**: Fixed an issue related to binary SEI message length. |
|2026\-08\-24 |1.51.300.2 |* **Important**: The integration method for super\-resolution (SR) and video sharpening features has changed. For more information, see [Reporting events](https://docs.byteplus.com/docs/byteplus-media-live/docs-initializing-for-android#a414e6c4).<br><br>* **Issues fixed**: An issue where HLS stream pulling failed in specific scenarios was fixed. |

|2026\-08\-03 |1.51.100.8 |* Added support for RTM\-ABR streams. For more information, see [RTM-ABR streams](https://docs.byteplus.com/docs/byteplus-media-live/docs-implementing-advanced-features-2#ff47ac00).<br><br>* Added support for audio\-only and video\-only streams. |
|2026\-06\-01 |1.50.300.1 |Fixed some issues. |
|2026\-05\-08 |1.50.200.3 |* Added support for enabling low\-latency FLV streaming. When enabled, FLV stream pulling can reduce live streaming latency to 2\-3 seconds. For more information, see [Playing low-latency FLV streams](https://docs.byteplus.com/docs/byteplus-media-live/docs-implementing-advanced-features-2#1d5784e5).<br><br>* Added support for setting custom request headers for the player’s HTTP requests. For more information, see [retryIntervalTimeMs](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-player-android-api-keytype#retryintervaltimems-2).<br><br>* Added support for configuring a stall timeout threshold to stop retries.
