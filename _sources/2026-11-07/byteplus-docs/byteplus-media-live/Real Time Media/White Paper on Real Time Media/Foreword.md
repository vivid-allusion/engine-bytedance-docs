## Preamble

RTM is an open protocol that allows third\-party access according to standards.

It is based on technologies such as WebRTC, QUIC, AAC, and H.265. We would like to take the opportunity to thank all developers who have contributed to these technologies.

<span id="a9296f28"></span>
## Background

Audiovisual streaming is a popular way of interacting online, aiming to enhance transmission versatility and efficiency. Live streaming helps to increase user engagement and retention, which is of significant value. The completion of WebRTC 1.0 has streamlined WebRTC interfaces for major web browsers, and enables real\-time communication between web browsers and devices. This white paper, based on the WebRTC framework, defines specifications in order to set RTM standards.

RTM is an emerging live streaming solution designed to enhance the interactive experience. It is characterized by lower end\-to\-end latency than traditional live streaming solutions with latency as low as 1 second, as well as reduced stuttering. This enhances the user experience in real\-time scenarios like e\-commerce, bidding, and sports commentary, driving innovation. Additionally, this technology facilitates smooth upgrades with controllable costs and risks, making it a competitive, innovative streaming solution for the future.

The recommended reference standard for RTM end\-to\-end latency is 500ms to 1500ms.
