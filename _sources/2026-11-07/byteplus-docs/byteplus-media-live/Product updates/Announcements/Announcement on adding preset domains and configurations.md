Dear BytePlus MediaLive users:

In order to provide you with a better service, MediaLive has added following preset domains and configurations for you to quickly test the push\-pull streaming function.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">The preset configurations involved in this announcement support editing configuration parameters but do not support deletion.</div>


* <div data-tips="true" data-tips-type="tip">The preset configurations involved in this announcement are only for functional testing and are not recommended for use in formal business.</div>



<span id="709b8553"></span>
## Preset domains

The following preset domains are added for your use. xxx in the domain name is randomly generated.


* **Push domain**: `xxx-push.bpmedialive.com`, SSL certificate has been configured and HTTPS secure transmission has been enabled, and URL authentication has been enabled.

* **Pull domain**: `xxx-pull.bpmedialive.com`, SSL certificate has been configured and HTTPS secure transmission has been enabled.

## Scope of use

<span id="997e4c24"></span>
### Primary Use

Quickly experience live push, live transcoding, and live pull on the welcome page on the MediaLive console.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/46dfebb65bb44d1cb7b02260fe3c509d~tplv-goo7wpa0wc-image.image) </span>

<span id="5eb73453"></span>
### Other Uses

Use it as functional testing in the MediaLive console for other features, such as the address generation tool, web push, and web pull tools.
