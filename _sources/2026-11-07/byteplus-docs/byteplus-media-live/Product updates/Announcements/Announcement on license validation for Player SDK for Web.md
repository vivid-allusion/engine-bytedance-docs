Dear developers,

To further improve the features and services of the Player SDK for Web, BytePlus MediaLive will enable license validation for the Player SDK for Web and update the billing rules. For detailed rules regarding license billing, see [Pricing](https://docs.byteplus.com/docs/byteplus-media-live/docs-sdk-licenses#6ff167b2).


* Effective date: January 7, 2026

* Applicable version: Starting from version 2.11.0, license configuration is required when integrating the Player SDK for Web. For more information, see [Step 3: Configure the license](https://docs.byteplus.com/docs/byteplus-media-live/docs-integrating-the-player-sdk-for-web_1#f1396aa0).

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Versions earlier than 2.11.0 can still be used, but we recommend upgrading to the latest version to enjoy more comprehensive services and support.   </div>
   

If you have any questions or concerns about the change, please feel free to contact the BytePlus support team by [creating a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980) on the BytePlus website.
