Dear developers,

Effective immediately, BytePlus MediaLive will stop updating and remove the documentation for client Broadcast SDKs. The affected SDKs include the BytePlus MediaLive **Broadcast SDKs for iOS, Android, and React Native**.


* **Scope of impact**

   * New users: If you need a Broadcast SDK, we recommend evaluating the following alternatives first:

      * For web Broadcast SDK: Use the [BytePlus MediaLive Broadcast SDK for Web](https://docs.byteplus.com/en/docs/byteplus-media-live/docs-broadcast-sdk-for-web).

      * For client Broadcast SDK: Use the [client SDKs](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-79882) provided by BytePlus RTC.

   * Existing users: Existing users who have already integrated and are using the BytePlus MediaLive client Broadcast SDKs will not be affected. They can continue to renew the service on the BytePlus website and use the SDKs as usual.

* **Ongoing maintenance**

   Starting from **August 7, 2026**, the BytePlus MediaLive client Broadcast SDKs will no longer receive feature updates or new versions. However, routine maintenance and bug fixes will continue to be provided.


If you still need to use the BytePlus MediaLive client Broadcast SDKs, or if you have any questions about this change, please [create a ticket](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000980) to contact the BytePlus support team.
