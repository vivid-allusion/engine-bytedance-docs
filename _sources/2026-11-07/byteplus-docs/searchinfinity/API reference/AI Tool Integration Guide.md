Searchinfinity Web Search supports integration via the skill format, enabling web search installation and usage across multiple tools such as BytePlus\-ArcClaw, Claude Code, Codex, and Agents.

&nbsp;

<span id="9XW0MpTT"></span>
## Skill Integration

<span id="h0tbD5rE"></span>
### Skill Information


* **Skill Name**: byted\-bp\-searchinfinity\-web\-search

* **Skill Type**: Web Search Skill


&nbsp;

<span id="g9TdupOt"></span>
### Access Paths

The skill can be obtained through the following two channels:


* **GitHub**

   * Repository path: [bytedance/agentkit-samples/tree/main/skills/byted-bp-searchinfinity-web-search](https://github.com/bytedance/agentkit-samples/tree/main/skills/byted-bp-searchinfinity-web-search)

* **BytePlus\-ArcClaw Enterprise Skill Center**

   * Search for: byted\-bp\-searchinfinity\-web\-search


&nbsp;

<span id="Try0ueU4"></span>
### Installation Instructions

For users of conversational AI tools such as BytePlus\-ArcClaw, you can copy the following text into the conversation and send it to the Agent:

```Bash
Please install the byted-bp-searchinfinity-web-search skill using the following command: `install-skill https://github.com/bytedance/agentkit-samples/tree/main/skills/byted-bp-searchinfinity-web-search`
```


For users who install via command line, the installation command is:

```Bash
install-skill https://github.com/bytedance/agentkit-samples/tree/main/skills/byted-bp-searchinfinity-web-search
```
