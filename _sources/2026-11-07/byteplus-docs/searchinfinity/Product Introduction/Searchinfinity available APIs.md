# Instruction

Searchinfinity is an AI\-native search for AI agents and applications. It provides multiple services to fulfill AI applications’ requirements for obtaining clean, structured web information.

&nbsp;

# Available APIs


|Service |Description |API reference |
|---|---|---|
|Web Search\-Flux |Real\-time search for accurate, structured web information. This version is faster and more flexible. |[Searchinfinity search API reference-Flux](https://docs.byteplus.com/en/docs/searchinfinity/Searchinfinity_API_Reference) |
|Web Search\-Omnira |Real\-time search for accurate, structured web information. This version supports a broader applicability. |[Searchinfinity search API reference-Omnira](https://docs.byteplus.com/en/docs/searchinfinity/Searchinfinity-Search-API-Reference-Omnira) |
