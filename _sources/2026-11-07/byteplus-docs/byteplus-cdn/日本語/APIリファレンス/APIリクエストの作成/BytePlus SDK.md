BytePlus SDKを使用すると、プログラムでBytePlus CDNと対話することができます。対話中に複雑な署名計算を処理する必要はありません。BytePlus SDKは、PHP、Go、Python、およびJava用のライブラリを提供しています。また、BytePlus SDKは、開始するためのサンプルコードも提供しています。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">現在、エッジ関数SDKは提供されていません。WAF SDKについては、最新情報を<a href="https://docs.byteplus.com/en/docs/waf/web-application-firewall-release-notes">WAFドキュメント</a>で確認してください。</div>
