BytePlus CDNでは、サイトコンテンツの配信設定は配信ポリシーで定義されます。配信ポリシーの作成過程で、オリジンサーバーを設定する必要があります。オリジンサーバーの設定にはサイトの基本情報が含まれており、CDNにサイトからコンテンツをどのように取得するかを指示します。ポリシー作成後、そのポリシーを公開する必要があります。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">このドキュメントは、<a href="https://docs.byteplus.com/en/docs/byteplus-cdn/quickstart-overview">チュートリアルの概要</a>で説明されているシナリオに基づいています。</div>



1. 配信ポリシーを作成します。

   1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

   2. 左側のナビゲーションバーで、**配信ポリシー** をクリックします。

   3. **配信ポリシー** ページで、**配信ポリシーを作成**をクリックします。

   4. **配信ポリシーを作成**ページで、 **ポリシー名**に`テストポリシー`と入力し、 **プロジェクト** に`default`を選択し、**確定**をクリックします。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_9bc97b8ab74226d057e2aaa1d5f01e23.jpeg) </span>

2. オリジンサーバーを設定します。

   1. **配信ポリシー詳細**ページで、 **オリジンサーバー** タブをクリックし、**新規オリジンサーバー** をクリックします。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_1d1c1f30f5f2e252288c333cdad8c226.jpeg) </span>

   2.  **メインオリジンサーバーの設定**ページで、以下の設定を行い、**確認**をクリックします。

      *  **オリジンサーバータイプ** を**IPアドレス** に設定します。

      *  **オリジンサーバーアドレス** に`203.0.113.8`を入力します。

         <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6e1b59f7c8fc753f831855cad3051910.jpeg) </span>

3. **配信ポリシー詳細**ページで、**保存**をクリックします。**配信ポリシー** ページで、作成したばかりの配信ポリシーがポリシーリストに表示されます。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_777fc1ae9637b18416c96463a45f689f.jpeg) </span>

4. ポリシーを公開します。

   1. そのポリシーの **アクション** 列で、**公開**ボタンをクリックします。

   2. **操作確認**ダイアログで、**確定**をクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">公開済みのポリシーは修正できません。公開済みのポリシーの設定が正しくない場合、そのポリシーをコピーして新しいポリシーを作成できます。新しいポリシーで該当する設定を修正し、その新しいポリシーを公開することができます。   </div>
   

次に、サイトの証明書をCDNにアップロードしましょう。
