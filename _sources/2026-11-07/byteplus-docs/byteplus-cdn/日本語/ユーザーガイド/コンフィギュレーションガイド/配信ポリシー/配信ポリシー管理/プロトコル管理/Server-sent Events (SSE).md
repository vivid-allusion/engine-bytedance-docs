このドキュメントでは、BytePlus CDNにおけるSSEのサポートについて説明します。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">プロトコルのメカニズムが異なるため、SSEとWebSocketを同時に有効にすることはできません。</div>


<span id="e5eee699"></span>
## SSEの概要

Server\-sent Events（SSE）は、HTTPプロトコルに基づいた、サーバーからクライアントへの**一方向**のリアルタイムプッシュ技術です。永続的なロングコネクションを介してテキストデータストリームを転送し、一方向のリアルタイム通信シナリオに適しています。

<span id="de85d6a9"></span>
### 主な利点


* 軽量で使いやすい：既存のHTTPプロトコルスタックに基づいており、クライアントはネイティブの`EventSource` APIを介して迅速に接続できます。開発コストが低く、主要なブラウザと互換性があります。

* ネイティブの信頼性：自動再接続メカニズムが組み込まれており、`id`フィールドによる中断からの再開をサポートし、データの完全性を保証します。


<span id="121d7c22"></span>
### 利用シーン


* リアルタイム通知（ソーシャルメッセージ、注文更新、運用アラートなど）、リアルタイムデータ監視（金融相場、センサーデータなど）といった一方向のデータ転送シナリオ。

* LLMのストリーミング出力：大規模言語モデルが生成した回答をセグメント化してクライアントにプッシュし、「タイプライター」のようなリアルタイムフィードバックを実現します。これにより、ユーザーの待ち時間をなくし、転送の負荷を軽減します。


<span id="febd2412"></span>
## CDNのSSEサポート

CDNは「エッジプロキシ」としてSSE転送を最適化します。その中核となる動作メカニズムは、次の3つの主要な側面に焦点を当てています。

<span id="6b9c6511"></span>
### ロングコネクションのブリッジング

クライアントのリクエストは最寄りのCDNエッジノードにルーティングされます。ノードはリクエストをオリジンサーバーに透過的に転送し、オリジンサーバーとのロングコネクションを確立します。これにより、「クライアント \- エッジノード \- オリジンサーバー」というリンクが形成され、転送距離が短縮され、遅延が低減されます。

<span id="84f98c37"></span>
### データストリームの透過的転送

「改ざんせず、キャッシュせず、即時転送する」というポリシーを採用しています。オリジンサーバーからのSSE形式のデータストリームがノードに到着すると、すぐにクライアントにプッシュされ、データのリアルタイム性と完全性が確保されます。

<span id="275ec1c5"></span>
### 接続の再利用と安定性制御

ブロードキャスト型のSSEはオリジンサーバーの接続を再利用し、オリジンサーバーの負荷を軽減します。一方、個別化されたSSEは独立した接続リンクを維持し、データの混同を防ぎます。同時に、適切なタイムアウト設定、自動再接続、およびフェイルオーバーにより、サービスの可用性を保証します。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">SSEを有効にする場合は、HTTP/2も有効にすることをお勧めします。HTTP/2の多重化機能により、エッジノードとオリジンサーバー間で確立する必要があるTCP接続は1つだけになります。この接続は、複数の「ストリーム」を介して複数のクライアントのSSEデータストリーム（各クライアントが1つのストリームに対応）を同時に伝送できるため、オリジンサーバーの接続負荷を効果的に軽減できます。</div>


<span id="71503458"></span>
## 操作手順


1. **Server\-sent Events** の設定ページを開きます。操作手順については、[ドメイン名設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_jp)を参照してください。

2. **状態** を有効に設定します。

3. 設定が完了したら、**保存** をクリックします。
