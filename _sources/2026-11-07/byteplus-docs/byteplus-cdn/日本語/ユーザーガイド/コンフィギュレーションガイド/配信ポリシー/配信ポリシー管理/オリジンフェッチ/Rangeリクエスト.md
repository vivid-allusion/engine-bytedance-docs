このドキュメントでは、CDN の Range リクエスト機能について説明します。大きなファイルのダウンロードやストリーミング再生などのシナリオでこの機能を有効にすると、ファイルの配信効率が効果的に向上し、CDN のオリジンリクエストトラフィックが削減され、オリジンサーバーの負荷が軽減されます。

<span id="656448bc"></span>
## Range リクエストについて

Range リクエストとは、Range リクエストヘッダーを含む HTTP リクエストのことです。このリクエストヘッダーは、リクエストするファイルの範囲を指定します。つまり、ファイル全体ではなく、ファイルの一部をリクエストすることを意味します。たとえば、`Range:bytes=0-149` は、ファイルの最初の 150 バイトをリクエストすることを示します。Range リクエストが成功した場合、サーバーの応答ステータスコードは 206 です。

<span id="1c7040cd"></span>
## 注意事項


* リクエストされたファイルがキャッシュ不可の場合、Range リクエストが有効になっているかどうかに関係なく、CDN はユーザーの Range リクエストをオリジンサーバーに転送します。

* オリジンサーバーが Range リクエストをサポートしていない場合、Range リクエストを有効にすると、オリジンリクエストが失敗する可能性があります。

* Range リクエストを有効にすると、同じファイルのすべてのチャンクのキャッシュ有効期限は、そのファイルの最初にキャッシュされたチャンクに基づきます。


<span id="7fcd1280"></span>
## Range リクエストが無効な場合の CDN の動作

Range リクエストが無効な場合、ユーザーからのリクエストが Range リクエストであるかどうかに関係なく、CDN が完全なファイルをキャッシュしていない限り、CDN はオリジンサーバーに完全なファイルをリクエストします。

<span id="ff4d7338"></span>
## Range リクエストが有効な場合の CDN の動作

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">2025\-09\-10 以降に追加されたドメイン名の場合、これらのドメイン名で Range リクエストを有効にすると、CDN はオリジンフェッチ時に検出メカニズムを追加します。このメカニズムにより、ファイルがキャッシュ不可の場合やオリジンサーバーのファイルが更新された場合に、オリジンサーバーの下りトラフィックが増加するのを防ぐことができます。</div>


<span id="a183c3b9"></span>
### 2025\-09\-10 以降に追加されたドメイン名に対する CDN の Range リクエストメカニズム

ユーザーの Range リクエストの場合、オリジンフェッチ時に、CDN はまずプローブ Range リクエスト（Range: 0\-0）を送信します。オリジンサーバーの応答に基づいて、CDN はリクエストされたファイルがキャッシュ可能かどうかを判断します。


* ファイルがキャッシュ不可の場合、CDN はユーザーの Range リクエストをオリジンサーバーに転送します。

* ファイルがキャッシュ可能な場合、CDN はキャッシュされたチャンクがオリジンサーバーで更新されているかどうかを確認します。

   * ファイルが更新されていない場合、CDN は指定されたチャンクサイズ（デフォルトは 1 MB）に従って、オリジンリクエストを順番に送信します。対応する数のチャンクを取得した後、CDN はユーザーがリクエストしたチャンクを返します。

   * ファイルが更新されている場合、CDN はユーザーの Range リクエストで指定されたチャンクサイズに従ってオリジンフェッチします。


<span id="750b9b8c"></span>
### 2025\-09\-10 より前に作成されたドメイン名に対する CDN の Range リクエストメカニズム

オリジンフェッチ時、CDN はユーザーの Range リクエストのチャンクの開始位置を、指定されたチャンクサイズ（デフォルトは 1 MB）に切り捨てて、**最初の** Range リクエストのチャンクの開始位置として使用します。オリジンサーバーの応答を受信すると、


* 応答ステータスコードが 200 の場合、CDN は完全なファイルを応答します。

* ステータスコードが 206 の場合、CDN はリクエストされたファイルがキャッシュ可能かどうかを判断します。

   * ファイルがキャッシュ不可の場合、CDN はユーザーの Range リクエストをオリジンサーバーに転送します。

   * ファイルがキャッシュ可能な場合、CDN はキャッシュされたチャンクがオリジンサーバーで更新されているかどうかを確認します。

      * チャンクが更新されていない場合、CDN は**後続の** Range リクエストを順番に送信します。

      * チャンクが更新されている場合、CDN はまずチャンクキャッシュをクリアしてから、**後続の** Range リクエストを順番に送信します。

         対応する数のチャンクを取得した後、CDN はユーザーがリクエストしたチャンクを返します。

* 応答ステータスコードが 416 の場合、CDN はリクエストされたファイルがキャッシュ可能かどうかを判断します。

   * ファイルがキャッシュ不可の場合、CDN はユーザーの Range リクエストをオリジンサーバーに転送します。

   * ファイルがキャッシュ可能な場合、CDN は 416 ステータスコードを応答します。

* その他のステータスコードの場合、CDN はユーザーの Range リクエストをオリジンサーバーに転送します。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Range リクエストでは、チャンクが範囲外になる可能性があります。たとえば、完全なファイルのサイズが 1.5 MB で、ユーザーがリクエストしたファイルの範囲が 14,000,000\-15,000,000 の場合です。この場合、CDN が送信する最初のRange リクエストのファイル範囲は 14,000,000\-15,048,576 となり、ファイルのサイズを超えます。</div>


<div data-tips="true" data-tips-type="tip">オリジンサーバーが Alibaba Cloud Object Storage (OSS) の場合、範囲外が発生すると OSS が予期しない応答を返すことがあります。以下の OSS 互換性構成で説明されている解決策を参照してください。</div>


<span id="9d2e5f24"></span>
## AlibabaCloud OSS 互換設定

次のシナリオを想定します。


* オリジンサーバーは OSS バケットです。

* Range リクエストのファイル範囲が完全なファイルのサイズを超えています。


このシナリオでは、OSS は 200 ステータスコードで応答し、完全なファイルを返します。これにより、OSS の下りトラフィックが増加し、OSS のレート制限がトリガーされ、オリジンリクエストのデータ転送速度に影響を与える可能性があります。

したがって、オリジンサーバーが OSS のバケットである場合は、ドメイン名に [オリジンリクエストのヘッダー](https://docs.byteplus.com/en/docs/byteplus-cdn/origin-response-header-jp) を設定することをお勧めします：`x-oss-range-behavior:standard`。[HTTP範囲リクエストをセグメント化してOSSリソースを取得する方法](https://www.alibabacloud.com/help/ja/oss/how-to-obtain-oss-resources-by-segmenting-http-range-requests) を参照してください。

## 操作手順


1. **Rangeリクエスト**  設定ペイジを開きます。手順については、[ドメイン名設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_jp) を参照してください。

2. **状態** を **有効** に設定します。

3. チャンクサイズを設定します。デフォルトは 1 MB です。チャンクサイズを大きくすると、オリジンリクエストの数を減らすことができますが、ネットワークが不安定な場合に再試行のコストが増加する可能性があります。チャンクサイズを小さくすると、その逆になります。

   * 単位が MB の場合、1〜40 MB の範囲で指定でき、整数である必要があります。

   * 単位が KB の場合、512 KB のみを指定できます。

4. **保存** をクリックします。
