本ドキュメントでは、BytePlus CDNでドメイン名に対して「リダイレクトフォロー」を有効にする方法について説明します。

<span id="機能紹介"></span>
## 機能紹介

CDNがオリジンサーバーにコンテンツを要求する際、オリジンサーバーのレスポンスステータスコードが301または302の場合、要求されたコンテンツが別のURLにリダイレクトされたことを示します。この場合、CDNはレスポンスステータスコードをユーザーのブラウザに返して処理させます。ブラウザはリダイレクト先のURLにリクエストを送信します。この設定を有効にすると、オリジンサーバーが301/302ステータスコードを返した場合、CDNはレスポンスコードを返さず、直接リダイレクト先のURLにリクエストを送信します。コンテンツを取得した後、CDNはそのコンテンツをキャッシュしてユーザーに返します。コンテンツのリダイレクトシナリオでは、リダイレクトフォローはCDNのユーザーからのリクエストへの応答速度を効果的に向上させることができます。

したがって、オリジンサーバーに301/302リダイレクトのシナリオがある場合、「リダイレクトフォロー」を有効にすることをお勧めします。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">この機能は、GETメソッドまたはHEADメソッドを使用するユーザーからのリクエストにのみ有効です。</div>


<span id="例"></span>
### 例

以下のシナリオを想定してください：


* オリジンサーバー上の `https://www.example.com/image.png` が `https://www.test.com/image.png` にリダイレクトされています。

* ユーザーAとユーザーBが順番に `https://www.example.com/image.png` をリクエストします。

* `www.example.com` はCDNに接続されています。


以下では、リダイレクトフォローが無効と有効の場合のリクエスト結果への影響について説明します。

 **「リダイレクトフォロー」が無効の場合**

リクエストプロセスは以下の通りです：


1. ユーザーAが `https://www.example.com/image.png` をリクエストします。

2. CDNがオリジンサーバーにそのファイルをリクエストします。

3. オリジンサーバーが301または302ステータスコードを返し、リダイレクトURLを含みます。

4. CDNがそのステータスコードをユーザーAに返します。

5. ユーザーAが `https://www.test.com/image.png` をリクエストします。


`www.test.com` がCDNに接続されていないため、このリクエストはCDNを経由しません。ユーザーBのリクエストプロセスも上記のステップを繰り返します。

結果として、ユーザーAとユーザーBのリクエストはどちらもデータ転送の高速化を得られません。

 **「リダイレクトフォロー」が有効の場合**

リクエストプロセスは以下の通りです：


1. ユーザーAが `https://www.example.com/image.png` をリクエストします。

2. オリジンサーバーが301または302ステータスコードを返し、リダイレクトURLを含みます。

3. CDNが `https://www.test.com/image.png` をリクエストし、そのファイルをキャッシュしてユーザーAに返します。

   この時点で、ユーザーAはより速くリクエストしたファイルを取得できます。主に以下の理由によります：

   * プロセス上、CDNがステータスコードをユーザーAに返し、ユーザーAが再度リクエストを送信するという2つのステップを避けられます。

   * CDNが `https://www.test.com/image.png` をリクエストする方が、ユーザーAがそのURLをリクエストするよりも速くレスポンスを得られます。


その後、ユーザーBが `https://www.example.com/image.png` をリクエストします。そのファイルは既にキャッシュされているため、リクエストはキャッシュにヒットします。したがって、CDNはキャッシュされたファイルをユーザーBに返します。

結果として、ユーザーAとユーザーBのリクエストはどちらもデータ転送の高速化を得られます。

<span id="操作手順"></span>
## 操作手順


1.  **リダイレクトフォロー** 設定ペイジを開きます。操作手順については[ドメイン名設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_jp)をご参照ください。

2.  **リダイレクトフォロー** の下で、**状態**を**有効**に設定します。

3. 設定が完了したら、**保存**をクリックします。
