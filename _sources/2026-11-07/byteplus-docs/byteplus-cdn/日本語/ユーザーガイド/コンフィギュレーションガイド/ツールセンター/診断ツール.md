<span id="ip検出"></span>
## IP検出

サイトがCDNに接続された後、サイトページへのアクセス速度が期待通りでない場合、このツールを使用してユーザーがアクセスするIPアドレスがCDNノードのIPアドレスであるかどうかを確認できます。

一度に最大50個のIPv4およびIPv6アドレスを照会できます。複数のIPアドレスは改行または semicolon（;）で区切ります。

IPアドレスがCDNノードのIPアドレスである場合、チェック結果にはそのIPアドレスの所在地も表示されます。所在地が中国の場合、チェック結果にはそのIPアドレスが属するネットワーク事業者も表示されます。

<span id="操作手順"></span>
### 操作手順


1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

2. 左側のナビゲーションバーで、 **ツールセンター**  \> **診断ツール** をクリックします。

3. **診断ツール** ページで、**IP検出**の下の **はじめに** をクリックします。

4. **IP位置情報**ページで、照会したいIPアドレスを入力し、 **クエリ** をクリックします。

<span id="ドメイン名設定比較"></span>
## ドメイン名設定比較

このツールは、2つのドメインなの設定の違いを比較するために使用されます。このツールはDescribeCdnConfig APIを呼び出して指定されたドメイン名の設定を取得し、API層での設定の違いをハイライト表示します。

比較結果の各パラメータの定義については、[DescribeCdnConfig](https://docs.byteplus.com/en/docs/byteplus-cdn/DescribeCdnConfig_jp)を参照してください。

<span id="操作手順"></span>
### 操作手順


1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

2. 左側のナビゲーションバーで、 **ツールセンター**  \> **診断ツール** をクリックします。

3. **診断ツール** ページで、 **ドメイン名設定比較**の下の **はじめに** をクリックします。

4. **設定の差分**ページで、比較したいドメイン名を指定し、ドメイン名設定の違いを確認します。

<span id="ポリシー比較"></span>
## ポリシー比較

このツールは、2つのポリシーの設定の違いを比較するために使用されます。比較結果は以下のタブに表示されます：


* 基本情報：2つのポリシーの基本情報の違いを表示します。

* 設定：2つのポリシーのCDN機能設定の違いを表示します。

* 関連付けるドメインリスト：2つのポリシーに関連付けるドメイン名の違いを表示します。


このツールを使用する際、ポリシータイプを指定し、2つのポリシーを選択して設定の違いを取得する必要があります。


* ポリシータイプが配信ポリシーの場合、このツールはDescribeServiceTemplate APIを呼び出して2つのポリシーの設定を取得し、これら3つのタブに設定の違いを表示します。

* ポリシータイプが暗号化ポリシーの場合、このツールはDescribeCipherTemplate APIを呼び出します。


**設定**タブでは、このツールはAPI層でのCDN機能の設定の違いをハイライト表示します。比較結果の各パラメータの定義については、


* 2つの配信ポリシーを比較している場合は、[DescribeServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeservicetemplate-00652-cn)を参照してください。

* 2つの暗号化ポリシーを比較している場合は、[DescribeCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeciphertemplate-f8c12-cn)を参照してください。


<span id="操作手順"></span>
### 操作手順


1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

2. 左側のナビゲーションバーで、 **ツールセンター**  \> **診断ツール** をクリックします。

3. **診断ツール** ページで、 **ポリシー比較**の下の **はじめに** をクリックします。

4.  **ポリシー差分**ページで、ポリシータイプを指定し、比較したいポリシーを指定します。
