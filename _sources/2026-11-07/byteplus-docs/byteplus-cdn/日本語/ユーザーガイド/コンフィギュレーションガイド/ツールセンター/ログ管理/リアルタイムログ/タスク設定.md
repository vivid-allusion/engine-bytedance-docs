このドキュメントでは、BytePlus CDN でログ配信タスクを作成する方法について説明します。最大 20 個のタスクを作成できます。

タスク作成ウィザードには、次の 2 つの手順が含まれます。


1. ログ配信情報を設定する: ログ配信を設定します。

2. ドメイン名を関連付ける: リアルタイムログを配信するドメイン名を指定します。

<span id="ステップ-1-配信情報を設定する"></span>
## ステップ 1: 配信情報を設定する

このステップでは、リアルタイムログを BytePlus Torch Log Service(TLS)、 Alibaba Cloud Simple Log Service(SLS)、またはHTTPサーバーに配信するように指定できます。

<span id="byteplus-torch-log-service-tls"></span>
### BytePlus Torch Log Service(TLS)

<span id="前提条件"></span>
#### 前提条件

初めてリアルタイムログを TLS に配信する場合、**配信先**で **BytePlus Torch Log Service(TLS)**  をクリックすると、TLS サービスを有効にしてから CDN に TLS へのアクセスを承認するように求められます。コンソール ページの指示に従ってください。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">CDN に TLS へのアクセスを承認すると、BytePlus プライマリアカウントに <code>ServiceRoleForCDN</code> ロールが追加されます。</div>


* <div data-tips="true" data-tips-type="tip">IAMユーザーにログ配信タスクを作成する権限を付与するには、IAMユーザーに <code>CDNLogsFullAccess</code> システム定義ポリシーを付与する必要があります。</div>



前提条件が満たされている場合、**配信先**で **BytePlus Torch Log Service(TLS)**  をクリックすると、CDN がリアルタイムログを指定したログ トピックに配信するように、次の設定を完了する必要があります。以下の設定手順を参照してください。

### Alibaba Cloud Simple Log Service(SLS)

<span id="前提条件"></span>
#### 前提条件

初めてリアルタイムログを SLS に配信する場合は、次の手順を完了する必要があります。


1. Alibaba Cloudアカウントで SLS サービスを有効にします。

2. SLS でプロジェクトとログストアを作成します。

3. Alibaba Cloudアカウントの AccessKey ID と AccessKey Secret を取得します。このアカウントには、SLS を操作する権限が必要です。


上記の手順を完了している場合は、**配信先**で　**Alibaba Cloud Simple Log Service(SLS)** 　をクリックすると、CDN がリアルタイムログを指定したログストアに配信するように、次の設定を完了する必要があります。以下の設定手順を参照してください。

<span id="認証プロセスとトークンアルゴリズム"></span>
#### 認証プロセスとトークンアルゴリズム

**認証プロセス** 


1. ログ配信リクエストを配信する前に、CDN は認証キーとトークンアルゴリズムに基づいてトークンを計算します。トークン計算にさらに関与するフィールドは、指定されたタイムスタンプ (timestamp)、リクエスト URL のパス (uri)、CDN がランダムに生成した整数 (rand) です。rand の範囲は 0 ～ 2147483647 です。

2. HTTPサーバーに POST リクエストを配信します。

   * リクエスト URL には `auth_key` クエリ パラメーターが含まれ、パラメーター値の形式は `timestamp-rand-token` です。

   * リクエスト URL の形式は `http://[http_server_address]:[port]/[uri]?auth_key=timestamp-rand-token` です。

      リクエスト URL の例: `http://https://www.example.com:8080/cdn-logs?auth_key=1744870608-14567-6459280fed54315c2960f9ae2e91807d`

   * リクエストの本文には複数のログが含まれ、ログは `\n` で区切られます。

3. リクエストを受信した後、HTTPサーバーは認証キー、サーバーアドレスのパス、タイムスタンプ、乱数に基づいてトークンを計算します。以下のトークンの例とサンプル コードを参照してください。

4. HTTPサーバーは、2 つのトークンが同じかどうかを判断します。トークンが同じ場合は、認証が成功したことを示します。


 **トークンアルゴリズム** 


* MD5(uri\-timestamp\-rand\-key)


 **トークンの例**

仮定:


* サーバーアドレスは `https://www.example.com:8080/cdn-logs` です。

* 認証キーは `1a2c!=A?1` です。

* リクエストの配信時刻 (timestamp) は `1744870608` です。

* CDN がランダムに生成した整数 (rand) は `14567` です。


この場合、トークンの計算式は `MD5(/cdn-logs-1744870608-14567-1a2c!=A?1)` で、計算されたトークンは `6459280fed54315c2960f9ae2e91807d` です。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">この例では、サーバーアドレスにパスが含まれていない場合、トークンの計算式は <code>MD5(-1744870608-14567-1a2c!=A?1)</code> です。</div>

## ステップ 2: ドメイン名を関連付ける

このステップでは、リアルタイムログを配信するドメイン名を指定します。


* すべてのドメイン名のリアルタイムログを配信する場合は、**関連付け方法** を  **アカウントによる関連付け**  に設定します。CDN に後で追加するドメイン名についても、これらのドメイン名のリアルタイムログが配信されます。

* 指定したドメイン名のリアルタイムログを配信する場合は、**関連付け方法** を  **ドメイン名による関連付け**  に設定し、これらのドメイン名を選択します。最大 200 個のドメイン名を選択できます。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_43713056fc469b13667f16de88a624f7.png) </span>

<span id="iamユーザーの権限の説明"></span>
### IAMユーザーの権限の説明

ステップ 2 では、IAMユーザーは操作する権限を持つドメイン名のみを追加できます。また、IAMユーザーに付与された関連ポリシーにプロジェクトの制限がある場合 (下の図を参照)、つまり、IAMユーザーは指定された BytePlus プロジェクトに属するドメイン名にアクセスする権限を持っています。この場合、IAMユーザーは  **アカウントによる関連付け**  を指定できません。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_c4818f5cd8de1921f96f35d6f5561a4d.png) </span>

<span id="ログ配信タスクの表示"></span>
## ログ配信タスクの表示

配信タスクを作成すると、タスクがタスク リストに表示されます。


* タスク設定を調整する必要がある場合は、 **アクション**  列で **編集** をクリックします。

* 配信タスクの設定を表示するには、対応するタスクの  **ログ配信情報** 列で **展開して表示** をクリックします。

* TLS に配信されたタスクについては、 **アクション**  列の **検索** をクリックし、**Query and analysis** ページでログを検索および分析できます。[ログ検索の例](https://docs.byteplus.com/en/docs/byteplus-cdn/log-query-examples_jp) を参照してください。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6d2a2c941efdde1030f528e3a754405b.png) </span>

<span id="ログ配信タスクの削除"></span>
## ログ配信タスクの削除

特定のリアルタイムログタスクが不要になった場合、まずそのタスクを無効化してから削除することができます。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">配信先がTLSであるタスクの場合、タスクが削除されると、対応するログテーマも削除されます。</div>
