このドキュメントでは、BytePlus CDNが提供する「オフラインログ転送」サービスについて説明します。このサービスを使用すると、時間単位でパッケージ化されたリクエストログを指定したオブジェクトストレージサービスのバケットに転送するようにCDNを設定できます。このバケットは、BytePlus Object Storage (TOS)、Alibaba Cloud Object Storage (OSS)、Tencent Cloud Object Storage (COS)、AWS S3、およびAWS S3互換の認証方法を使用する任意のオブジェクトストレージサービスから取得できます。

「オフラインログ転送」と他の2つのCDNログ取得方法との違いについては、[ログ管理概要](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_jp)を参照してください。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_d007ef20772b8b18a0dd4d9f2a49d6bc.png) </span>

「オフラインログ転送」を設定する際には、転送タスクを作成する必要があります。転送タスクでは、バケットのアクセス設定を提供し、どのドメイン名のリクエストログパッケージを転送するかをCDNに指定します。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDNが転送するログパッケージは、<strong>ログダウンロード</strong>タブで照会およびダウンロードできるログパッケージと同じです。</div>



* <div data-tips="true" data-tips-type="tip">ログの適時性、ログパッケージの命名規則、ログフィールドの説明などの詳細については、<a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs-logs-jp">ログダウンロード</a>を参照してください。</div>



<span id="オフラインログ転送の課金"></span>
## オフラインログ転送の課金

「オフラインログ転送」は有料サービスです。料金は以下の要素で構成されます：


* ログ配信の料金。CDNは配信されたログに対して課金します。課金単位は1万件です。ログ配信の課金の詳細については、[BytePlus CDNの課金](https://docs.byteplus.com/en/docs/byteplus-cdn/billings)を参照してください。

* オブジェクトストレージサービスの料金。配信先に基づいて、以下を参照してください：

   * [BytePlus TOSの課金](https://docs.byteplus.com/en/docs/tos/docs-billing-overview)。

   * [AWS S3の課金](https://aws.amazon.com/s3/pricing/)。

   * その他のオブジェクトストレージサービスの価格については、サービスプロバイダーのウェブサイトをご覧ください。


<span id="操作手順"></span>
## 操作手順


1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

2. 左側のナビゲーションバーで、 **ツールセンター**  \>  **ログ** をクリックします。

3.  **ログ** ページで、 **オフラインログ転送**タブをクリックします。

4.  **オフラインログ転送**タブで、**追加**をクリックして転送タスクを作成します。

5.  **タスクを作成**ページで、[設定の説明](https://docs.byteplus.com/en/docs/18/52211#%E8%A8%AD%E5%AE%9A%E3%81%AE%E8%AA%AC%E6%98%8E)を参照して**転送先**と**関連付け方法**を設定します。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><strong>転送先</strong> として <strong>BytePlus Object Storage (TOS)</strong> を指定した場合、まずCDNにTOSへのアクセスを承認する必要があります。ページ上の指示に従ってください。以前にCDNにTOSへのアクセスを承認している場合、<strong>サービス承認</strong> のステータスは<strong>承認済み</strong>になります。   </div>
   

6. タスクの設定が完了したら、**確認**をクリックします。

<span id="設定の説明"></span>
## 設定の説明

<span id="転送先がbyteplus-tos"></span>
### **転送先がBytePlus TOS**


|**設定** |**説明** |
|---|---|
|バケット |TOS内のバケットの名前を表します。バケットリストには、アカウント内のすべてのバケットが表示されます。リストからバケットを選択する必要があります。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDNが収集したログには遅延が発生する可能性があります。遅延ログについては、CDNはそれらをTOSバケット内の対応するログパッケージに追加します。したがって、バケットを選択する際には、「標準ストレージ」タイプのバケットのみを選択できます。このタイプのバケットのみが既存のファイルへのコンテンツの追加をサポートしているためです。</div><br> |
|ディレクトリ |バケット内のディレクトリパスを表します。ログパッケージはこのディレクトリパスに転送されます。例：`mylogs/cdn-logs`。<br><br>&nbsp;<br><br>ディレクトリパスの先頭と末尾はスラッシュ（/）にすることはできず、長さは256文字を超えることはできません。ディレクトリパスが存在しない場合、CDNはバケット内にそのディレクトリパスを作成します。<br><br>&nbsp;<br><br>この設定を指定しない場合、ログパッケージはバケットのルートディレクトリに転送されます。 |
|プライベートバケット |このバケットが公開アクセス可能かどうかを示します。この設定はデフォルトでオフになっています。<br><br><br>* この設定が有効になっている場合、バケットはプライベートアクセスです。CDNがこのバケットにログパッケージを転送する際、CDNはBytePlusアカウントの認証情報を使用してバケットにアクセスします。<br><br>* この設定が無効になっている場合、バケットは公開アクセスです。 |
|備考 |このタスクの備考を表し、長さは3〜45文字で、漢字、文字、数字を含めることができますが、アンダースコア（_）で開始または終了することはできません。漢字1文字は3文字としてカウントされます。<br><br>&nbsp;<br><br>タスク作成後、この備考はタスクIDの下に表示されます。<br><br><span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ec473407991b6eb4e809921f18d3ce65.png) </span> |

### **転送先がS3プロトコルオブジェクトストレージ** 


|**設定** |**説明** |
|---|---|
|ドメイン名 |ログパッケージが転送されるバケットについて、この設定はS3認証を使用するバケットのアクセスポイント（エンドポイント）を表します。<br><br>&nbsp;<br><br>アクセスポイントは`https://`で始まり、バケット名を含まず、長さは1,024文字を超えることはできません。例：`https://oss-ap-southeast-1.aliyuncs.com`。 |
|地域 |このバケットが所在する地域（リージョンコード）を表します。例：`ap-southeast`。このバケットのオブジェクトストレージサービスプロバイダーに問い合わせて、バケットの地域を確認してください。<br><br>&nbsp;<br><br>地域は64文字を超えることはできません。 |
|バケット |このバケットの名前（バケット名）を表し、長さは256文字を超えることはできません。例：`mybucket`。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDNが収集したログには遅延が発生する可能性があります。遅延ログについては、CDNはそれらをTOSバケット内の対応するログパッケージに追加します。したがって、指定するバケットは既存のファイルへのコンテンツの追加をサポートしている必要があります。</div><br> |
|ディレクトリ |バケット内のディレクトリパスを表します。ログパッケージはこのディレクトリパスに転送されます。例：`mylogs/cdn-logs`。<br><br>&nbsp;<br><br>ディレクトリパスの先頭と末尾はスラッシュ（/）にすることはできず、長さは256文字を超えることはできません。ディレクトリパスが存在しない場合、CDNはバケット内にそのディレクトリパスを作成します。 |
|プライベートバケット |このバケットが公開アクセス可能かどうかを示します。この設定はデフォルトでオフになっています。<br><br><br>* この設定が有効になっている場合、バケットはプライベートアクセスです。CDNがこのバケットにアクセスするために使用する認証情報を提供する必要があります。<br><br>* この設定が無効になっている場合、バケットは公開アクセスです。 |
|AccessKey ID |CDNがこのバケットにアクセスするために使用する認証情報について、この設定は認証情報内のAccessKey IDを表します。<br><br>&nbsp;<br><br> **プライベートバケット** が有効になっている場合にのみ、この設定が表示されます。 |
|AccessKey Secret |CDNがこのバケットにアクセスするために使用する認証情報について、この設定は認証情報内のAccessKey Secretを表します。<br><br>&nbsp;<br><br> **プライベートバケット** が有効になっている場合にのみ、この設定が表示されます。 |
|備考 |このタスクの備考を表し、長さは3〜45文字で、漢字、文字、数字を含めることができますが、アンダースコア（_）で開始または終了することはできません。漢字1文字は3文字としてカウントされます。<br><br>&nbsp;<br><br>タスク作成後、この備考はタスクIDの下に表示されます。 |


<span id="関連付け方法"></span>
### **関連付け方法**

この設定では、どのドメインのログパッケージをCDNが転送するかを指定します。この設定には以下のオプションがあります：


* ドメイン名による関連付け：アカウント内の最大200個のドメイン名を指定します。

* アカウントによる関連付け：アカウント内のすべてのドメイン名を表します。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">1つのドメインは1つのタスクにのみ含めることができます。</div>


* <div data-tips="true" data-tips-type="tip"><strong>関連付け方法</strong>が<strong>ドメイン名による関連付け</strong>のタスクが既に存在する場合、<strong>関連付け方法</strong>が<strong>アカウントによる関連付け</strong>のタスクを作成することはできません。逆も同様です。</div>

<span id="タスクの有効化-無効化"></span>
### タスクの有効化/無効化

タスクを一時停止したい場合は、そのタスクの **アクション** 列で**無効化**をクリックします。タスクが無効化されると、CDNはそのタスクに関連付けられているすべてのドメイン名のログパッケージの転送を停止します。その後、いつでも**有効化**をクリックして、CDNがこれらのドメイン名のログパッケージの転送を再開するようにできます。

<span id="ログパッケージの転送が失敗した場合のページ上のヒント"></span>
### ログパッケージの転送が失敗した場合のページ上のヒント

バケット情報を設定する際に、いずれかの設定が正しくないと、転送タスクは失敗します。また、転送タスクの実行中にバケットが何らかの制限に達した場合も、転送タスクは失敗します。

転送タスクがログパッケージをターゲットバケットに転送できない場合、タスクの左側に感嘆符が表示されます。感嘆符をクリックすると、最新の転送失敗の時点と原因が表示されます。失敗の原因を参考にして問題をトラブルシューティングできます。
