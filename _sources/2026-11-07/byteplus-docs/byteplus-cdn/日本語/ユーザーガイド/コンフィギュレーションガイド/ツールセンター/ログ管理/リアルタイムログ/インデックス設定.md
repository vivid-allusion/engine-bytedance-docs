このドキュメントでは、BytePlus CDN でログトピックのインデックスを設定する方法について説明します。このドキュメントは、ログ配信先が BytePlus Log Service (TLS) であるシナリオに適用されます。

インデックス設定は、TLS によってインデックス付けされるフィールドとインデックス付けの方法を決定します。CDN では、必要に応じてログトピックのインデックスを設定して、カスタマイズされたログ管理を実現できます。手順は次のとおりです。


1. リアルタイムログ配信タスクのリストで、インデックス設定を変更するタスクを見つけます。

2. タスク設定から、ログプロジェクト、ログプロジェクトのリージョン、およびログが保存されているログトピックを取得します。

3.  **アクション**  列で、**検索** をクリックします。

4. 開いたログサービスページの上部で、ログプロジェクトのリージョンを選択し、ページの左側で **Query and analysis** をクリックします。

5. **Query and analysis** ページの左側で、対応するログトピックを見つけて開きます。

6. ログトピックの詳細ページで、**Index configuration** をクリックします。

7. [設定手順](https://docs.byteplus.com/en/docs/18/52216#%E8%A8%AD%E5%AE%9A%E6%89%8B%E9%A0%86) を参照してインデックスを設定します。

8. 設定が完了したら、**OK** をクリックします。

## 設定手順


|設定 |説明 |
|---|---|
|Field name |ログフィールドを示します。 |
|Field type |フィールドのデータ型を示します。 |
|Field configuration |BytePlus TLS がフィールドをインデックス付けする方法を示します。Log Service は次の設定を提供します。<br><br><br>* Case sensitive: フィールド名で大文字と小文字を区別するかどうかを示します。<br><br>* Contains Chinese: フィールド値に中国語の文字が含まれているかどうかを示します。この設定をオンにすると、Log Service は中国語の構文に基づいてフィールド値をセグメント化します。たとえば、フィールド値が `msg:"文件 sample.png 打开失败"` であるとします。**Contains Chinese** がオフの場合、クエリステートメント `msg:"打开"` はログを取得できません。ログを取得するには、完全なログコンテンツ `msg:"文件 sample.png 打开失败"` を使用する必要があります。**Contains Chinese** をオンにすると、クエリステートメント `msg:"打开"` でログを取得できます。<br><br>* Delimiter: Log Service がフィールド値をセグメント化するために使用する文字を示します。セグメンテーションの目的は、検索を容易にすることです。たとえば、フィールド値が `numbers:"1\|2\|3"` であるとします。区切り文字を `\|` に指定すると、クエリステートメント `numbers:"1"` でログを取得できます。区切り文字を `,` に指定すると、クエリステートメント `numbers:"1"` はログを取得できません。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip"><strong>Contains Chinese</strong> と <strong>Delimiter</strong> のうち、設定できるのは 1 つだけです。</div><br><br><br>* <div data-tips="true" data-tips-type="tip">text 型と json 型のフィールドにのみ、<strong>Contains Chinese</strong> と <strong>Delimiter</strong> の設定があります。</div><br><br><br>* <div data-tips="true" data-tips-type="tip">現在、次の制限があります。</div><br><br><br>   * <div data-tips="true" data-tips-type="tip"><strong>Enable analytics</strong> がオンの場合、このフィールドの <strong>Contains Chinese</strong> と <strong>Delimiter</strong> のオプションはどちらも有効にならず、コンソールからも表示されなくなります。</div><br> |
|Enable analytics |フィールドを分析ステートメントで指定できるかどうかを示します。検索ステートメントの形式は `<クエリステートメント>｜<分析ステートメント>` です。分析ステートメントでフィールドを指定したくない場合は、**Enable analytics** 列でフィールドをオフにすることができます。<br><br>&nbsp;<br><br>**Enable analytics** がオンかオフかに関係なく、フィールドは常にクエリステートメントで指定できることに注意してください。たとえば、`ds_http_status` フィールドの **Enable analytics** をオフに設定したとします。この場合、次の検索ステートメントを実行することはできません。<br><br><br>* `ds_http_status:>=400 \| select ds_http_status,count(*) AS PV group by ds_http_status`<br><br><br>ただし、次の検索ステートメントは引き続き実行できます。<br><br><br>* `ds_http_status:>=400` |
|Action |フィールドをインデックス付けする必要がない場合は、**Delete** をクリックします。 |


このページの全文検索などの他のインデックス設定については、[インデックスの設定](https://docs.byteplus.com/en/docs/tls/Configure-indexes-2) を参照してください。
