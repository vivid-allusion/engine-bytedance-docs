<span id="機能紹介"></span>
## 機能紹介

BytePlus CDN は、BytePlus Web Application Firewall（WAF）のセキュリティ保護機能を統合し、追加されたドメイン名にアプリケーション層攻撃に対する保護機能を提供します。CDN は、コンテンツ配信リンクに WAF 保護モジュールを組み込むことで、アクセスリクエストのフィルタリングと制御を実現します。

CDN に追加したドメイン名で WAF 保護機能を有効にすると、そのドメイン名に対するすべての HTTP および HTTPS アクセスリクエストが WAF 保護モジュールによって処理されます。具体的なプロセスは次のとおりです。


1.  **リクエストルーティング** ：クライアントから開始されたアクセスリクエストが CDN エッジノードに到達すると、まず CDN 配信ポリシーのリクエスト制御ルールによって処理されます。その後、通過したリクエストは WAF 保護モジュールに転送され、セキュリティチェックが行われます。

2. **WAF検出**：WAF 保護モジュールは、プリセットされた保護ルールに基づいてリクエストを詳細に分析し、その分析結果に基づいてリクエストを処理します。保護ルールには、アクセス制御、CC 攻撃保護、脆弱性保護、Bot 管理、API 保護ルールなどが含まれます。

   * **正当なリクエストの処理**：WAF 保護モジュールによって正当と判断されたリクエストは許可され、CDN での処理が続行されます。CDN はキャッシュポリシーに基づいて、エッジノードのキャッシュから直接コンテンツを取得するか、オリジンサーバーにコンテンツをリクエストするかを判断します。

   * **不正なリクエストの処理**：WAF 保護モジュールによって不正と判断されたリクエストはブロックされるか、攻撃ログに記録されます。リクエストがブロックされると、システムはクライアントにカスタムレスポンスページを返し、同時に詳細な攻撃ログを生成します。攻撃ログには、攻撃されたドメイン名、攻撃元の IP アドレス、攻撃発生時刻などの情報が含まれており、その後のセキュリティ監査や追跡分析に役立ちます。


WAF 保護機能を CDN アーキテクチャに深く統合することで、CDN はコンテンツ配信の効率を確保しつつ、Web アプリケーションのリアルタイムなセキュリティ保護を実現します。

<span id="ユースケース"></span>
## ユースケース

WAF 保護機能は、主に次のシナリオで使用されます：アクセス制御、CC 攻撃保護、脆弱性保護、Bot 管理、API 保護。

<span id="アクセス制御"></span>
### アクセス制御

アクセス制御ルールは、HTTP リクエストを正確に識別し、制御することができます。カスタムルールを設定して、アクセス元と HTTP リクエストの特性に基づいて特定のリクエストを許可またはブロックすることができます。

アクセス元は、IP アドレス、IP アドレス範囲、または地理的な場所です。HTTP リクエストの特性には、リクエストパス、リクエスト URI、リクエストプロトコル、リクエストメソッド、リクエストパラメータ、リクエストヘッダー、カスタムヘッダー、カスタム Cookie などが含まれます。

<span id="cc-攻撃保護"></span>
### CC 攻撃保護

CC 攻撃（Challenge Collapsar）は、Web アプリケーションサーバーを標的としたレイヤー 7 の DDoS 攻撃の一種です。攻撃者は、一見正当に見える大量の HTTP リクエストを送信して、ターゲットサーバーのリソースを消費させ、最終的にサーバーが正当なユーザーからのリクエストに正常に応答できなくさせます。

カスタム CC 保護ルールを設定できます。システムは、設定した HTTP リクエストの特性と統計条件に基づいて、検出された CC 攻撃に対して対応するアクションを実行し、正確なトラフィックのブロックまたは制限を実現します。

<span id="脆弱性保護"></span>
### 脆弱性保護

組み込みの保護ルールは、Web アプリケーションを包括的に保護し、一般的な脆弱性（CVE で公開された脆弱性や OWASP TOP 10 の脆弱性を含む）を標的とした Web 攻撃の脅威を効果的に防御します。

保護ルールの種類は、SQL インジェクション、コマンドインジェクション、サーバーサイドリクエストフォージェリ（SSRF）、クロスサイトスクリプティング（XSS）、XML 外部実体参照（XXE）、ディレクトリトラバーサル、LDAP インジェクション、XPath インジェクション、サーバーサイドテンプレートインジェクション（SSTI）、式インジェクションなどをカバーしています。

<span id="bot-管理"></span>
### Bot 管理

Bot 管理ルールは、外部の Bot からの悪意のあるリクエストや行動を効果的にブロックし、正当なリクエストのみが正常に転送されるようにします。マネージド Bot 管理ルールは、一般的な Bot を分類し、デフォルト設定に従って対応するアクションを実行します。

また、ビジネスニーズに応じてカスタム Bot 管理ルールを設定し、HTTP リクエストの特性に基づいてきめ細かな Bot 管理を実現することもできます。

<span id="api-保護"></span>
### API 保護

API 保護ルールは、設定された API パス、リクエストメソッド、およびパラメータに基づいて API リクエストを検査し、指定された特性に一致する API リクエストに対してブロックまたは監視のアクションを実行します。

API 保護は、インテリジェントな検出と学習機能を利用して、リスクのある API リクエストの行動を特定し、関連する API を自動的に追加された API 保護ルールに記録します。手動で API 保護ルールを作成することもできます。

<span id="waf-保護の設定"></span>
### WAF 保護の設定

ドメイン名を保護するために WAF 保護機能を使用するには、次の操作を実行する必要があります。


1. [WAF インスタンスの作成](https://docs.byteplus.com/en/docs/waf/docs-system-management)。

2. [WAF インスタンスへのドメイン名の追加](https://docs.byteplus.com/en/docs/waf/Adding_a_CDN_domain_name_to_a_WAF_instance)。

3. [保護ルールの設定](https://docs.byteplus.com/en/docs/waf/docs-introduction-to-custom-waf-rules)。


<span id="追加されたドメイン名の-waf-保護ステータスの表示"></span>
### 追加されたドメイン名の WAF 保護ステータスの表示

CDN コンソールの [WAF 保護](https://console.byteplus.com/cdn/cdn-bp/security/waf-protection) ページで、CDN に追加されたドメイン名で WAF 保護が有効になっているかどうかを確認できます。
