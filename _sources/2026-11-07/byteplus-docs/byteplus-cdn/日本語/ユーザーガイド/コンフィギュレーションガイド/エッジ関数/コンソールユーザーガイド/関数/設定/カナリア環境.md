このドキュメントでは、関数のカナリーノードの追加と削除方法について説明します。

関数を公開する際、カナリーリリースまたは完全リリースを選択できます。カナリーリリースとは、新バージョンの関数をすべてのエッジノードにリリースする前に、一部のエッジノードに公開することを意味します。これらのエッジノードはカナリーノードと呼ばれます。カナリーノードを使用して、関数の機能とパフォーマンスを検証できます。期待通りであれば、すべてのエッジノードに公開できます。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">関数のリリースタイプがカナリアリリースであり、完全リリースされたことがない場合、関数に転送ルールを関連付けることはできません。<a href="https://docs.byteplus.com/en/docs/byteplus-cdn/respond-to-requests-by-edge-functions-jp">エッジ関数でリクエストに応答する</a>を参照してください。</div>


カナリーノードを選択する際は、以下の要因を考慮することをお勧めします：


*  **トラフィック分布**：全体的なビジネスへの影響を最小限に抑えるため、トラフィックが少ない地域をカナリーノードとして選択します。例えば、BytePlus CDNの[インサイト](https://console.byteplus.com/cdn/cdn-bp/report/insights)ページの **トラフィック** タブで、関数に関連するドメイン名をフィルタリングして、異なる地域におけるビジネスのトラフィック分布を確認できます。

* **機能要件**：関数が特定の地域にデプロイされる必要がある場合、関数が適切に実行されることを確認するため、対応する地域をカナリーノードとして選択する必要があります。


<span id="操作手順"></span>
## 操作手順

<span id="カナリーノードを追加する"></span>
### カナリーノードを追加する

以下の手順に従って、関数にカナリーノードを追加します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. カナリーノードを追加したい関数を見つけ、関数名をクリックします。

3. **設定**タブを選択し、次に **カナリア環境**タブを選択します。

4.  **カナリアノードを追加**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_d67b2b27ba8a1d59490d9334f154c8c0.png) </span>

5.  **カナリアノードを追加**ダイアログボックスで、追加したいカナリーノードにチェックを入れ、**確認**をクリックします。


<span id="カナリーノードを削除する"></span>
### カナリーノードを削除する

以下の手順に従って、関数からカナリーノードを削除します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. カナリーノードを削除したい関数を見つけ、関数名をクリックします。

3. **設定**タブを選択し、次に **カナリア環境**タブを選択します。

4. 削除したいカナリーノードを見つけ、 **アクション** 列の**削除**をクリックします。

5. ポップアップウィンドウで**確認**をクリックして、カナリーノードを削除します。
