このドキュメントでは、関数のCronトリガーの設定方法について説明します。

Cronトリガーを作成して、定期的なタスクを設定できます。Cronトリガーは、指定された時間に自動的に関数コード内のcronイベントをトリガーします。コード内でcronイベントをリッスンし、処理する必要があります。

<span id="cronトリガーを作成する"></span>
## Cronトリガーを作成する

以下の手順に従ってCronトリガーを作成します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. Cronトリガーを作成したい関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、**Cron**タブを選択します。

4. **Cronトリガーを追加**をクリックします。

5. **Cronトリガーを追加**ダイアログボックスで、以下の表を参照して関連する設定を入力し、**保存**をクリックして完了します。



|パラメータ |説明 |
|---|---|
|名前 |Cronトリガーの名前を入力します。命名規則は以下の通りです：<br><br><br>* 英字、数字、ハイフン（\-）のみを含むことができます。<br><br>* 128文字を超えることはできません。 |
|トリガー範囲 |cronイベントがトリガーされるエッジノードを選択します。<br><br><br>*  **グローバル** : cronイベントはすべてのエッジノードでトリガーされます。<br><br>* **単一ポイント** : cronイベントはランダムなエッジノードでトリガーされます。 |
|実行時間 |cronイベントがトリガーされる時間です。設定後、右側の**推定実行時間 (UTC+8:00)** 　で期待通りかどうかを確認できます。<br><br><br>* **Cron式**: Cron式を入力します。[サポートされているCron式](https://docs.byteplus.com/en/docs/18/36598#supportedcron)を参照してください。<br><br>*  **カスタム** : **実行頻度**と**実行時間**を選択すると、エッジ関数が自動的に対応するCron式を生成します。 |
|パラメーター |カスタムパラメータを入力します。関数実行中、エッジ関数はこのパラメータを[CronEvent](https://docs.byteplus.com/docs/byteplus-cdn/docs-CronEvent-jp)に渡します。 |


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_58b529f2884f2c3475a915d107489f2c.png) </span>


6. Cronトリガーを作成した後、有効にするために以下も必要です：

   * Cronトリガーのステータスが**有効**であることを確認します。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_c7f6999764525057795a494e9adbf73c.png) </span>

   * 関数コードでcronイベントをリッスンします。以下のサンプルコードは、cronイベントをリッスンするためのイベントリスナーを登録し、cronイベントがトリガーされたときにコールバック関数を呼び出してスケジュールされたタスクを実行する方法を示しています。

      ```JavaScript
      // Register an event listener to listen for cron event
      addEventListener('cron', onCron);
      
      // Function to be called when cron event fires
      async function onCron(event) {
        // Code logic of the scheduled task
          return 'this is log';
      }
      ```

<span id="サポートされているcron式"></span>
### サポートされているCron式

Cron式は5つのフィールドで構成される文字列です。これらのフィールドはスペースで区切られます。Cron式はデフォルトでUTC+8:00タイムゾーンで実行されます。

**Cron式フィールドの説明**


|第1フィールド |第2フィールド |第3フィールド |第4フィールド |第5フィールド |
|---|---|---|---|---|
|分 |時 |日 |月 |曜日 |


各フィールドには対応する値の範囲があります：


|フィールド |値の範囲 |許可される特殊文字 |
|---|---|---|
|分 |整数 0\-59 |,\-\*/ |
|時 |整数 0\-23 |,\-\*/ |
|日 |整数 1\-31（月の日数を考慮） |,\-\*?/L |
|月 |整数 1\-12 または大文字小文字を区別しない月の3文字略称（"JAN"、"aug"など） |,\-\*/ |
|曜日 |整数 0\-6 または大文字小文字を区別しない曜日の3文字略称（"MON"、"fri"など）。0は日曜日、1は月曜日を表します。 |,\-\*?/L |


**特殊文字**


|文字 |意味 |説明 |
|---|---|---|
|\*（アスタリスク） |フィールド内のすべての値を表す |例えば、"分"フィールドでは、毎分実行することを意味します。 |
|,（カンマ） |複数の値を指定する |例えば、"曜日"フィールドで、"MON,WED,FRI"は"月曜日、水曜日、金曜日"を意味します。 |
|\-（ハイフン） |範囲を指定する |例えば、"時"フィールドで、"10\-12"は"10時から12時まで"を意味します。 |
|?（疑問符） |不確定な値を表す |他の指定された値と組み合わせて使用します。例えば、毎月の特定の日を指定し、曜日を気にしない場合、"曜日"フィールドで?を使用できます。 |
|/（スラッシュ） |増分を表す、n/mはnから開始し、毎回mずつ増加することを意味する |例えば、"分"フィールドで、1/3は1分から開始し、3分ごとに実行することを意味します。 |
|#（ハッシュ） |毎月n番目の特定の曜日を表す、"曜日"フィールドでのみ使用可能 |他の指定された値と組み合わせて使用します。例えば、"曜日"で5#2は月の第2金曜日を意味し、5は金曜日、2は2番目を表します。 |
|L（大文字のL） |最後を表す、"日"と"曜日"フィールドでのみ使用可能 |例えば、"日"フィールドでは、毎月の最終日を意味します。"曜日"フィールドで5Lを使用すると、最後の金曜日にトリガーされることを意味します。 |


**例**


|Cron式 |説明 |
|---|---|
|\* \* \* \* \* |毎分実行 |
|\* /30 \* \* \* \* |30分ごとに実行 |
|\* 23 \* \* \* |毎日23:00に毎分実行 |
|10,20,30 \* \* \* \* |毎時10分、20分、30分に実行 |
|30 7 \* \* MON\-FRI |月曜日から金曜日まで毎日7:30に実行 |
|0 8 1 \* \* |毎月1日の8:00に実行 |
|0 8 \* JAN\-JUN \* |1月から6月まで毎日8:00に実行 |


<span id="スケジュールレコードの表示"></span>
## スケジュールレコードの表示

以下の手順に従って、Cronトリガーのスケジュールレコードを表示します。現在、過去6ヶ月分のスケジュールレコードのみ表示できます。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。表示したい関数を見つけ、関数名をクリックします。

2.  **トリガー** タブを選択し、**Cron**タブを選択します。

3. **Cronトリガー** リストで、表示したいCronトリガーを見つけ、トリガー名をクリックして **スケジュールレコード** ページに入ります。

4.  **スケジュールレコード** ページで、実行式、パラメータ、ステータス、作成時間などのスケジュールレコード情報を表示します。**式**と **パラメータ** フィールドを使用して特定のレコードを検索することもできます。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_82dcb9a12ef2fa987ccefb13d41acbb0.png) </span>

5.  **ログを表示**をクリックして、様々なノードでの関数実行の詳細ログを確認します。


<span id="cronトリガーの有効化または無効化"></span>
## Cronトリガーの有効化または無効化

Cronトリガーを有効または無効にすることができます。Cronトリガーのステータスの変更は即時に反映され、関数を再公開する必要はありません。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。表示したい関数を見つけ、関数名をクリックします。

2.  **トリガー** タブを選択し、**Cron**タブを選択します。

3. 有効または無効にしたいCronトリガーを見つけ、**状態**列のスイッチをクリックしてCronトリガーの有効状態を切り替えます。


<span id="cronトリガーを削除する"></span>
## Cronトリガーを削除する

Cronトリガーが不要になった場合は、削除することができます。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Cronトリガーを削除すると、元に戻すことはできません。慎重に操作してください。</div>



1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。削除したい関数を見つけ、関数名をクリックします。

2.  **トリガー** タブを選択し、**Cron**タブを選択します。

3. 有効または無効にしたいCronトリガーを見つけ、 **アクション** 列の**削除**をクリックします。

4. ポップアップウィンドウで、削除するCronトリガーを確認し、**確認**ボタンをクリックして操作を完了します。
