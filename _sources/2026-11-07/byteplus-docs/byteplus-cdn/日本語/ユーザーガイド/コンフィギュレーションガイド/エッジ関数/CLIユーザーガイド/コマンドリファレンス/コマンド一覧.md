エッジ関数CLIは以下のコマンドを提供します：


* [関数](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-manage-funcs-topichead-jp)

   * [nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-jp): 関数プロジェクトを作成し、関数プロジェクト内にローカル関数を作成します。

   * [関数管理](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-manage-functions-topichead-jp)

      * [nest deploy](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-deploy-jp): ローカル関数をエッジノードにデプロイします。

      * [nest upload](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-upload-jp): ローカル関数コードをリモート関数にアップロードします。

      * [nest functions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-jp): ローカル関数のCRUD操作を実行します。

   * [関数コードのデバッグ](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-local-dev-jp)

      * [nest debug](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-debug-jp): 関数コードをローカルでデバッグします。

      * [nest start](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-start-jp): 関数コードをローカルで実行します。

   * [トリガー](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-triggers-topichead-jp)

      * [nest domain](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-domain-jp): ドメイントリガーを管理します。

      * [nest cron](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-cron-jp): Cronトリガーを管理します。

   * [リリース履歴](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-history-topichead-jp)

      * [nest rollback](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-rollback-jp): 関数コードを指定した過去のバージョンにロールバックします。

      * [nest versions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-version-jp): 関数コードの過去のバージョンを取得します。

      * [nest tickets](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-ticket-jp): 関数コードのリリース記録を取得します。

   * [関数設定](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-function-config-topichead-jp)

      * [nest envs](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-env-jp): 関数の環境変数を管理します。

      * [nest canary](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-canary-jp): 関数のカナリア環境を管理します。

* [エッジKV](https://docs.byteplus.com/docs/byteplus-cdn/edge-function-cli-ref-edge-kv-topichead-jp)

   * [nest kv](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-kv-jp): エッジKVを管理します。

* [ユーティリティツール](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-others-topichead-jp)

   * [nest config](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-config-jp): エッジ関数CLIの設定を管理します。

   * [nest help](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-help-jp): ヘルプ情報を取得します。

* [グローバルパラメータ](https://docs.byteplus.com/docs/byteplus-cdn/global-parameters-jp)

   * [--config](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-c-jp)

   * [--function](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-f-jp)

   * [--verbose](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-verbose-jp)

   * [--help](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global--help-jp)
