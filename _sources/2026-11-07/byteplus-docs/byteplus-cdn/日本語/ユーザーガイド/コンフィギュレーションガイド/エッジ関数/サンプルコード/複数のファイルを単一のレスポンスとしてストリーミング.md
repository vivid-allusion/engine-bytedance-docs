この例は、単一のリクエストで複数のファイルを要求し、これらのファイルをストリームとして返す方法を示しています。

Webページが依存関係のない複数の静的ファイルをロードする必要がある場合、ブラウザは通常、各ファイルを個別にリクエストします。しかし、ブラウザには同時リソースリクエスト数の制限があります。HTTPリクエストの数を減らすために、ブラウザの静的リソースリクエストを組み合わせることができます。これは、URLクエリパラメータを使用して複数のファイルリクエストをマージすることで実装できます。

例えば、Webページ上の<script\>タグのsrc属性の値に、urllistという名前のクエリパラメータが含まれています。このクエリパラメータには、複数の.jsファイルのURLパスが含まれています。

```html
<script src="http://www.example.com/?urllist=/react/a.min.js,/react/b.min.js"></script>
```


関数がユーザーからのリクエストを受信すると、まずクエリパラメータを読み取り、各.jsファイルのURLパスを取得します。次に、これらのパスを完全なURLに連結します。その後、関数は非同期でそれぞれのURLにリクエストしてアクセスし、ファイルを取得します。ファイルの取得中、関数は取得したファイルをストリームとしてユーザーに返送します。

```JavaScript
async function handle(event) {
  const request = event.request; 
  const url = new URL(request.url);
  const fetchList = url.searchParams.get("urllist").split(",");
  const {readable, writable} = new TransformStream();
  
  (async () => {
    let idx = 0;
    for (const u of fetchList) {
      const resp = await fetch (`http://${url.host}${u}`);
      const close = (idx == fetchList.length - 1);
      resp.body.pipeTo(writable, {preventClose: close});
      idx++;
    }
  })();
  
  return new Response(readable, {
    status: 200
  });
}

addEventListener('fetch', (event) => {
  event.respondWith(handle(event));
});
```
