このドキュメントでは、関数の作成、公開、および削除方法について説明します。

<span id="関数を作成する"></span>
## 関数を作成する

エッジ関数でコードを編集する前に、まず関数を作成する必要があります。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">各BytePlusアカウントは最大100個の関数を作成できます。</div>


<span id="操作手順"></span>
### 操作手順

以下の手順に従って関数を作成します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**関数を作成**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7fad3a80f0db6bb5ab78bbf7a39b86f0.png) </span>

3. **関数を作成**ページで、以下の指示に従ってパラメータを設定します。

   
   |パラメータ |説明 |
   |---|---|
   |名前 |関数名。関数名は各BytePlusアカウント内で一意である必要があります。<br><br>名前のルールは以下の通りです：<br><br><br>* 大文字、小文字、数字、ハイフン(\-)をサポートします。<br><br>* 長さは128文字を超えないようにしてください。 |
   |説明 |オプション。関数の説明。最大128文字まで許可されます。 |
   |プロジェクト |関数が属するプロジェクト。 |
   |作成方法 |関数の作成方法。<br><br><br>* テンプレートなし: "helloworld"の例から関数の作成を開始します。<br><br>* テンプレートで作成: サンプルコードテンプレートを選択して、関数を素早く作成します。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_304130cc554175c361c98f7c03327aee.png) </span>

4. **保存**をクリックします。作成した関数が**関数**ページに表示されます。


<span id="関数を公開する"></span>
## 関数を公開する

関数を公開すると、エッジノードにデプロイできるようになります。

<span id="操作手順"></span>
### 操作手順

以下の手順に従って関数を公開します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。公開したい関数を見つけ、関数名をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_f87c6c58087748110ef9e72bc08f5799.png) </span>

2.  **コード** タブで**編集とデプロイ** をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4881e4ee4c10aa957475270f3985ac9f.png) </span>

3. ページ右上の **デプロイ** をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_44561673a588c293db89e5ed7886b91a.png) </span>

4. ポップアップダイアログボックスで、**説明**情報を入力し、リリースタイプを選択して、**確認**をクリックしてリリースを完了します。

   * カナリアリリース：指定したカナリアノードに関数を公開します。[カナリアノード](https://docs.byteplus.com/docs/byteplus-cdn/docs-canary-node-jp)を参照してください。

   * フルリリース：すべてのエッジノードに関数を公開します。

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">ドメイントリガーを使用する場合、ドメインの転送ルールも追加する必要があります。<a href="https://docs.byteplus.com/docs/byteplus-cdn/docs-domain-triggers-jp">ドメイントリガー</a>を参照してください。   </div>
   

   * <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">関数のフルリリースには通常5〜10分かかります。関数が完全にリリースされるのを待ってから、ドメインと関連付けることができます。   </div>
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_711fd8eb704dbab48877f6b8d0dc8922.png) </span>


<span id="関数を削除する"></span>
## 関数を削除する

関数が不要になった場合は、削除できます。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">関数のコードと設定がすべて削除されます。削除された関数は復元できません。</div>


<span id="前提条件"></span>
### 前提条件

関数がどのドメインにも関連付けられていないこと。[ドメイントリガー](https://docs.byteplus.com/docs/byteplus-cdn/docs-domain-triggers-jp)を参照してください。

<span id="操作手順"></span>
### 操作手順


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. 削除したい関数を見つけ、 **アクション** 列の**削除**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_20792b3ee2b17722670c2b90e9a71b58.png) </span>

3. **関数を削除**ダイアログボックスで、**削除の確認**にチェックを入れ、**削除**ボタンをクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_abf920b81bcef559f00e2ac02c4c107b.png) </span>
