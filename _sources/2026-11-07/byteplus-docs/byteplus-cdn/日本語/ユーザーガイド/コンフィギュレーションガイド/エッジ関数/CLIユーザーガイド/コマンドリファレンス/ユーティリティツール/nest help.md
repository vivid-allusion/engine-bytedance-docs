エッジ関数CLIのヘルプ情報を表示します。

<span id="概要"></span>
## 概要

```shell
npx nest help

npx nest help <command>
```


<span id="説明"></span>
## 説明

`npx nest help`を使用して、エッジ関数CLIのヘルプ情報を表示できます。また、`npx nest help <command>`を使用して、特定のコマンドのヘルプ情報を表示することもできます。
