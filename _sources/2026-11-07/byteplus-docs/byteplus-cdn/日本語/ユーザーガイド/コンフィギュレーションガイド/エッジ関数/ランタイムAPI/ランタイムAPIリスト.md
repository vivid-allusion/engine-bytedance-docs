エッジ関数ランタイムがサポートするプログラミング言語は JavaScript（ES6）です。開発者はランタイム APIを呼び出すことでエッジ関数ランタイムと対話します。ランタイム APIには、[WinterTC](https://wintertc.org/) からの一部の標準 APIと、エッジ関数固有のAPIが含まれています。
