関数のIDまたは名前を指定します。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">このグローバルパラメータは、関数関連のコマンドでのみ使用可能です。</div>


<span id="概要"></span>
## 概要

```shell
--function <function_id_or_name> 
```



* `<function_id_or_name>`: *string, optional*

   * 関数のIDまたは名前。関数のIDまたは名前は[nest function list](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-jp)を通じて取得できます。
