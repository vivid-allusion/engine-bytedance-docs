* [サポートされているアルゴリズム](https://docs.byteplus.com/docs/byteplus-cdn/docs-SupportedAlgorithms-jp)

* [digest()](https://docs.byteplus.com/docs/byteplus-cdn/docs-digest-jp)

* [sign()/verify()](https://docs.byteplus.com/docs/byteplus-cdn/docs-sign-verify-jp)

* [encrypt()/decrypt()](https://docs.byteplus.com/docs/byteplus-cdn/docs-encrypt-decrypt-jp)
