このドキュメントでは、関数に環境変数を追加し、コード内で参照する方法について説明します。

環境変数はキーと値のペアです。環境変数を使用することで、コードを更新せずに異なる環境で関数の動作を調整できます。

<span id="操作手順"></span>
## 操作手順

<span id="関数に環境変数を追加する"></span>
### 関数に環境変数を追加する

以下の手順に従って、関数に環境変数を追加します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. 環境変数を追加したい関数を見つけ、関数名をクリックします。

3. **設定**タブを選択し、次に**環境変数**を選択します。

4. **変数を追加**をクリックします。**変数を追加**ダイアログボックスで、各変数の**変数名**と**値**を入力します。1つまたは複数の環境変数を追加できます。変数名のルールは以下の通りです：

   * 英字またはアンダースコア(_)で始まる必要があります。

   * 英字、数字、アンダースコア(_)のみを含むことができます。

   * 同じ関数内で変数名は一意である必要があります。

5. **確認**をクリックします。追加した環境変数が環境変数リストに表示されます。


<span id="関数コード内で環境変数を参照する"></span>
### 関数コード内で環境変数を参照する

コード内で`env.key`を使用して、キー`key`を持つ環境変数の値にアクセスできます。例えば、以下のコードはキー`test`を持つ環境変数の値を取得します。

```JavaScript
const value = env.test;
```


環境変数の値を変更する必要がある場合、変更後に関数を再公開する必要があります。変更は関数が公開された後にのみ、関数内で有効になります。
