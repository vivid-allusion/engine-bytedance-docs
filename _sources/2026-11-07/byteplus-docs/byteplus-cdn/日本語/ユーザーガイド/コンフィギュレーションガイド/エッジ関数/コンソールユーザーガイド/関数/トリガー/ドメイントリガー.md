このドキュメントでは、関数のドメイントリガーの設定方法について説明します。

ユーザーが関数に関連付けられたドメイン名にHTTP/HTTPSリクエストでアクセスし、ユーザーからのリクエストがドメインの転送ルールに一致すると、ドメイントリガーは関数コード内のfetchイベントをトリガーします。コード内でfetchイベントをリッスンし、処理する必要があります。

<span id="使用制限"></span>
## 使用制限

1つの関数は最大100個のドメイン名に関連付けることができ、1つのドメイン名は最大50個の関数に関連付けることができます。

<span id="ドメイントリガーの設定"></span>
## ドメイントリガーの設定

関数のドメイントリガーを設定するには、以下のタスクを完了する必要があります。


* [ステップ1：ドメイン名を関数に関連付ける](https://docs.byteplus.com/en/docs/18/36597#%E3%82%B9%E3%83%86%E3%83%83%E3%83%971%EF%BC%9A%E3%83%89%E3%83%A1%E3%82%A4%E3%83%B3%E5%90%8D%E3%82%92%E9%96%A2%E6%95%B0%E3%81%AB%E9%96%A2%E9%80%A3%E4%BB%98%E3%81%91%E3%82%8B)

* [ステップ2：ドメイン名の転送ルールを設定する](https://docs.byteplus.com/en/docs/18/36597#%E3%82%B9%E3%83%86%E3%83%83%E3%83%972%EF%BC%9A%E3%83%89%E3%83%A1%E3%82%A4%E3%83%B3%E5%90%8D%E3%81%AE%E8%BB%A2%E9%80%81%E3%83%AB%E3%83%BC%E3%83%AB%E3%82%92%E8%A8%AD%E5%AE%9A%E3%81%99%E3%82%8B)

* [ステップ3：関数コードでfetchイベントをリッスンする](https://docs.byteplus.com/en/docs/18/36597#%E3%82%B9%E3%83%86%E3%83%83%E3%83%973%EF%BC%9A%E9%96%A2%E6%95%B0%E3%82%B3%E3%83%BC%E3%83%89%E3%81%A7fetch%E3%82%A4%E3%83%99%E3%83%B3%E3%83%88%E3%82%92%E3%83%AA%E3%83%83%E3%82%B9%E3%83%B3%E3%81%99%E3%82%8B)


<span id="ステップ1：ドメイン名を関数に関連付ける"></span>
### ステップ1：ドメイン名を関数に関連付ける

<span id="前提条件"></span>
#### 前提条件


* 関数が完全にリリースされ、関数の**状態**が**実行中**または**未関連付け** であること。

* ドメイン名がBytePlus CDNに追加され、ドメインの**状態**が**Enabled**であること。[ドメイン名を追加する](https://docs.byteplus.com/docs/byteplus-cdn/domain-management-jp)を参照してください。


以下の手順に従ってドメイン名を関数に関連付けます。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、 **ドメイン名**タブを選択して、 **ドメイン名を追加**をクリックします。

4.  **ドメイン名を追加**ダイアログボックスで、関連付けたい1つまたは複数のドメイン名を選択し、**保存**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_bc882376faeb4b49baf0604651309f9d.jpg) </span>


ドメイン名が正常に関連付けられると、 **トリガー** タブでドメイン名を確認できます。追加されたドメイン名には転送ルールが設定されていないため、そのステータスは**Offline**です。

<span id="ステップ2：ドメイン名の転送ルールを設定する"></span>
### ステップ2：ドメイン名の転送ルールを設定する

関数にドメイン名を追加した後、ドメイン名の転送ルールを設定する必要があります。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、 **ドメイン名**タブを選択します。

4.  **ドメイン名**タブのドメイン名リストで、転送ルールを設定したいドメイン名を選択します。この関数の下で複数のドメイン名に同じ転送ルールを設定したい場合は、複数のドメイン名をチェックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_234d14651f008c85b818e81dc387a1c7.png) </span>

5. ドメイン名リストの下の**転送ルールを設定する** をクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><strong>ドメイン名</strong>タブでは、一度に1つの転送ルールのみを増分的に設定できます。複数の設定を行うと、複数の転送ルールが作成されます。BytePlus CDNの<strong>ドメイン名</strong>ページで、ドメイン名に関連付けられたすべての転送ルールを確認できます。<a href="https://docs.byteplus.com/docs/byteplus-cdn/respond-to-requests-by-edge-functions-jp">エッジ関数でリクエストに応答する</a>を参照してください。   </div>
   

6. **転送ルールを設定する** ページで、以下の表に従って転送ルールを設定します。

   
   |パラメータ |説明 |
   |---|---|
   |ドメイン名 |転送ルールを設定するドメイン名。 |
   |関数の名前 |現在の関数の名前。変更できません。 |
   |転送ルール |転送ルールに一致するユーザーからのリクエストは、BytePlus CDNによってエッジ関数に転送されます。<br><br><br>*  **フィルタータイプ** <br><br>   ルールのタイプを選択します。設定値は以下の通りです：<br><br>   * URLパス拡張子：指定された拡張子を持つすべてのファイルにルールが適用されます。<br><br>   * URLパスディレクとり：指定されたディレクトリ内のすべてのファイルにルールが適用されます。<br><br>   * URLパス：指定されたファイルにルールが適用されます。<br><br>*  **パターン** <br><br>   指定された **フィルタータイプ** に従ってルール内容を入力します。ルール内容は1024文字を超えることはできません。1つまたは複数の設定を入力でき、セミコロン（;）で区切ります。ルール内容の要件は以下の通りです：<br><br>   * タイプが**URLパス拡張子**の場合、1つまたは複数のファイル拡張子を入力します。例：`xlsx`または`png;txt`。ファイル拡張子には英字と数字を含めることができます。<br><br>   * タイプが**URLパスディレクとり** の場合、1つまたは複数のディレクトリパスを入力します。ディレクトリパスはスラッシュ（/）で始まり、終わる必要があります。例：`/www/img/byte/;/www/doc/`。ディレクトリパスには連続したスラッシュ（//）、パーセント記号（%）、またはスペースを含めることはできません。ドメイン名の下のすべてのディレクトリを指定するには、`/`を入力します。<br><br>   * タイプが**URLパス** の場合、1つまたは複数の完全なパスを入力します。パスはスラッシュ（/）で始まります。例：`/www/img/byteplus.png;/doc/study.docx`。ファイルパスには連続したスラッシュ（//）、パーセント記号（%）、またはスペースを含めることはできません。<br><br>* **大文字小文字を無視**<br><br>   CDNがユーザーからのリクエストのファイルを転送ルールで照合する際に大文字と小文字を区別するかどうかを設定します。リクエストURLの残りの部分はこの設定の影響を受けません。デフォルト設定はオンです。オンは大文字小文字を区別しないことを意味します。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_9208e8cb6bdd920ba2bbeb7a184d5677.png) </span>

7. 転送ルールの設定後、**保存**をクリックします。


数分待つ必要があります。ドメイン名のステータスが **オンライン** に変わると、そのドメイン名に対してドメイントリガーが有効になったことを示します。この時点で、ユーザーがそのドメイン名にHTTP/HTTPSリクエストを送信し、リクエストが転送ルールに一致すると、BytePlus CDNはユーザーからのリクエストをエッジ関数に転送し、ドメイントリガーはそのドメイン名に関連付けられた関数内のfetchイベントをトリガーします。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_0b1967f7a7337d08db43d8118822d689.png) </span>

<span id="ステップ3：関数コードでfetchイベントをリッスンする"></span>
### ステップ3：関数コードでfetchイベントをリッスンする

ユーザーからのリクエストを処理するために、関数コードでfetchイベントをリッスンする必要があります。以下のサンプルコードは、fetchイベントをリッスンするためのイベントリスナーを登録し、fetchイベントがトリガーされたときにコールバック関数を呼び出してユーザーにカスタムレスポンスを返す方法を示しています。

```JavaScript
// Register an event listener to listen for fetch events
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request));
})
// This function is called when fetch event fires
async function handleRequest(request) {
    return new Response('Hello World!', { status: 200 });
}
```


<span id="関数からドメイン名を解除する"></span>
## 関数からドメイン名を解除する

<span id="前提条件"></span>
### 前提条件

 **トリガー** タブでのドメイン名のステータスが **オフライン** であること。

<span id="操作手順"></span>
### 操作手順

以下の手順に従って、関数からドメイン名を解除します。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、 **ドメイン名**タブを選択します。

4.  **ドメイン名**タブのドメイン名リストで、解除したいドメイン名を見つけ、 **アクション** 列の**削除**をクリックします。

5. ポップアップダイアログボックスで**確認**をクリックします。


解除後、ドメイン名はドメイン名リストに表示されなくなります。
