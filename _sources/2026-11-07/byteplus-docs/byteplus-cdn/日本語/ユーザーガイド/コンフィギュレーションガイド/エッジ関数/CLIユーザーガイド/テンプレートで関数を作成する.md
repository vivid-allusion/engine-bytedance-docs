本ドキュメントでは、エッジ関数CLIで関数テンプレートを使用して関数を作成する方法について説明します。

エッジ関数CLIでは、使用できる関数テンプレートは、Access Key IDとSecret Access Keyを設定しているかどうかによって異なります：


* Access Key IDとSecret Access Keyを設定していない場合、CLI内蔵テンプレートのみ使用できます。。

* Access Key IDとSecret Access Keyを設定している場合、エッジ関数がサポートするすべてのテンプレートを使用できます。


<span id="前提条件"></span>
## 前提条件


* エッジ関数CLIがインストールされていること。[CLIのインストール](https://docs.byteplus.com/en/docs/byteplus-cdn/get-started-with-edge-function-cli-jp)を参照してください。

* グローバルプロジェクト設定ファイルにAccess Key IDとSecret Access Keyが設定されていること。[Access Key IDとSecret Access Keyの設定](https://docs.byteplus.com/en/docs/byteplus-cdn/edge-functions-cli-login-jp)を参照してください。


<span id="操作手順"></span>
## 操作手順


1. デバイスで以下のコマンドを実行します。このコマンドはエッジ関数CLIをインストールし、関数プロジェクトを作成し、そのプロジェクト内にローカル関数を作成します。[nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-jp)を参照してください。


```shell
$ npx @byteplus/nest@latest init
```



2. コマンドラインのプロンプトに従って関数名を設定し、関数テンプレートを選択します。その後、Enterキーを押して確定します。



コマンドの実行が完了すると、現在のディレクトリ構造は以下のようになります：

```markdown

        └── 📁src
```

ここで、`test`ディレクトリは作成した関数プロジェクトで、`test/src/index.js`はローカル関数のエントリーファイルです。index.jsファイルの内容は、選択した関数テンプレートとなります。

`MyFolder`ディレクトリで以下のコマンドを使用して、関数テンプレートから生成されたコードファイルを確認できます。

```shell
$ cat test/src/index.js
addEventListener('fetch', event => {
  event.respondWith(onFetch(event));
})

const OLD_URL = "s.taobao.com";
const NEW_URL = "s.mynewdomain.com";

async function onFetch(event) {
  const path = event.request.path;
  const response = await fetch(`https://www.taobao.com${path}`);

  const rewrite = function(element, tag) {
    if (element.hasAttribute(tag)) {
      const href = element.getAttribute(tag);
      const new_href = href.replace(OLD_URL, NEW_URL);
      console.log(`replace(${tag}) ${href} => ${new_href}`);
      element.setAttribute(tag, new_href);
    }
  }
  const rewriteBody = createHtmlStream(
    response.body,
    undefined,
     [
        [
          'a',  // CSS selector, 'a' stands for selecting all the 'a' tags in the webpage
          {
            // This onElement callback will be triggered after 'a' tags in the webpage are parsed
            onElement(element) {
              rewrite(element, "href")
            }
          }
        ],
        [
          'img',
          {
            // This onElement callback will be triggered after 'img' tags in the webpage are parsed
            onElement(element) {
              rewrite(element, "src")
            }
          }
        ]
      ]
  );

  return new Response(
    rewriteBody,
    {
      status: response.status,
      headers: response.headers
    }
  )
```
