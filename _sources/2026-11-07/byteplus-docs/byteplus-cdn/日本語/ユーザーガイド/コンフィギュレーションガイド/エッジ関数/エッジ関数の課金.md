エッジ関数は有料機能です。本書では、エッジ関数の課金ルールを紹介し、コストの見積もりと管理に役立てていただけます。

<span id="課金方法"></span>
## 課金方法

エッジ関数は、**従量課金**の後払い方式を採用しています。

<span id="課金サイクル"></span>
## 課金サイクル

エッジ関数は、前月に発生したすべての費用を毎月決済します。

<span id="課金項目"></span>
## 課金項目

エッジ関数の課金項目は以下の通りです：


|課金項目 |説明 |
|---|---|
|**関数リクエスト数** |関数がトリガーによってトリガーされ、正常に実行された回数。 |
| **エッジKV書き込みリクエスト数** |関数が [KV.set()](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-EdgeKV-RuntimeAPI-jp#kv-set) を呼び出し、エッジKVにキーと値のペアを正常に書き込んだ回数。 |
| **エッジKV読み取りリクエスト数** |関数が [KV.get()](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-EdgeKV-RuntimeAPI-jp#kv-get) を呼び出し、エッジKVからキーと値のペアの値を正常に読み取った回数。 |
| **エッジKV削除リクエスト数** |関数が [KV.delete()](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-EdgeKV-RuntimeAPI-jp#kv-delete) を呼び出し、エッジKVからキーと値のペアを正常に削除した回数。 |
| **エッジKVストレージ容量** |エッジKVに保存されたデータの月間平均ピーク使用量。単価はGB/月です。システムは日次のストレージピークを統計し、当月の毎日のピークの平均値を当月の課金データ量とします。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">エッジ関数はサブリクエストに対して課金しません。サブリクエストとは、関数が正常に送信したHTTPまたはHTTPSリクエストを指します。実行中の関数が送信できるサブリクエストの数には制限があることに注意してください。詳細については、<a href="https://docs.byteplus.com/en/docs/byteplus-cdn/usage-limits-jp">エッジ関数の使用制限</a>をご参照ください。</div>


<span id="無料利用枠"></span>
## 無料利用枠

エッジ関数は、各BytePlusアカウントに対して毎月1回限りの無料利用枠を提供します。この無料利用枠は、毎月1日に自動的にリセットされます。


|課金項目 |月間無料利用枠 |
|---|---|
|関数リクエスト数 |200万回 |
|エッジKV書き込みリクエスト数 |2万回 |
|エッジKV読み取りリクエスト数 |200万回 |
|エッジKV削除リクエスト数 |2万回 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">無料利用枠は当月のみ有効で、未使用部分は翌月に繰り越されません。</div>


* <div data-tips="true" data-tips-type="tip">エッジKVストレージ容量には無料利用枠はありません。</div>



<span id="料金"></span>
## 料金

使用量が無料利用枠を超えた場合、システムは超過部分に対して課金を開始します。


|課金項目 |単価 |
|---|---|
|関数リクエスト数 |$0.3 / 100万回 |
|エッジKV書き込みリクエスト数 |$5 / 100万回 |
|エッジKV読み取りリクエスト数 |$0.5 / 100万回 |
|エッジKV削除リクエスト数 |$5 / 100万回 |
|エッジKVストレージ容量 |$0.5 / GB / 月 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">エッジKVの書き込み、読み取り、削除リクエストについて、リクエスト回数が100万回未満の場合は、100万回として計算されます。</div>


<span id="課金例"></span>
## 課金例

<span id="使用量"></span>
### 使用量

当月に以下の使用量が発生したと仮定します：


* 関数リクエスト数：**3,000,000回**（無料利用枠を1,000,000回超過）。

* エッジKV書き込みリクエスト数：**1,020,000回**（無料利用枠を1,000,000回超過）。

* エッジKV削除リクエスト数：**15,000回**（20,000回の無料利用枠内）。

* エッジKV読み取りリクエスト数：**1,020,000回**（2,000,000回の無料利用枠内）。

* エッジKVストレージ容量：月間平均ピーク使用量が**10 GB**。


<span id="費用"></span>
### 費用


* **関数リクエスト数**：

   超過部分 `(3,000,000 - 2,000,000) 回 / 1,000,000 回 × $0.3 = $0.30`

*  **エッジKV書き込みリクエスト数**：

   超過部分 `(1,020,000 - 20,000) 回 / 1,000,000 回 × $5 = $5.00`

*  **エッジKV削除リクエスト数**：

   超過部分は0、費用は：`$0.00`

*  **エッジKV読み取りリクエスト数**：

   超過部分は0、費用は：`$0.00`

*  **エッジKVストレージ容量**：

   `10 GB × 1 ヶ月 × $0.5/GB/月 = $5.00`


当月の総費用 = $0.30 + $5.00 + $0.00 + $0.00 + $5.00 =  **$10.30**。
