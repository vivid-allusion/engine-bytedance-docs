関数設定ファイルを指定します。デフォルトでは、ローカル関数はルートディレクトリのnest.jsonファイルを設定ファイルとして使用します。

<span id="概要"></span>
## 概要

```shell
--config <config_file_path>
```



* `<config_file_path>`: *string, required*

   * 関数設定ファイルへのパス。
