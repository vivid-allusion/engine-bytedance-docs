このチュートリアルでは、簡単な例のシナリオに基づいて、BytePlus CDNでエッジ関数を使用する方法を紹介します。

<span id="前提条件"></span>
## 前提条件

エッジ関数はすでに有効化されています。[エッジ関数を有効にする](https://docs.byteplus.com/docs/byteplus-cdn/activate_byteplus_edge_functions_jp)をご覧ください。

<span id="例のシナリオ"></span>
## 例のシナリオ

あなたは`www.example.com`というドメイン名のウェブサイトを持っています。このドメインをBytePlus CDNに追加しました。エッジ関数を使用して、オリジンサーバーから返されるエラーページを修正し、ユーザーにより分かりやすいカスタムページを送信したいと考えています。

<span id="操作手順"></span>
## 操作手順

以下の手順に従って、BytePlus CDNでエッジ関数を使用します。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_1b9985b6e3dc1001e1b2fed84d5ea8f2.png) </span>


1. **関数を作成する** ：関数を作成します。

2.  **コードを編集しデバッグする** ：関数内でコードを編集しデバッグします。

3. **関数を公開する** ：関数をBytePlus CDNのグローバルエッジノードにデプロイします。

4. **関数とドメインを関連付ける** ：関数のトリガーをドメイントリガーとして設定し、ドメイントリガーで関数をドメインに関連付けます。

5. **転送ルールを設定する** ：ドメインの転送ルールを設定します。BytePlus CDNが転送ルールに一致するユーザーリクエストを受信すると、そのユーザーリクエストをエッジ関数に転送します。

6. **関数を検証する** ：関数の実際の実行結果が期待通りであるかを確認します。


<span id="ステップ1：関数を作成する"></span>
## ステップ1：関数を作成する


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**関数を作成**をクリックします。

3. **関数を作成**ページで、以下の説明に従って関連パラメータを設定します。

   * **名前**：このチュートリアルでは、**名前**を`custom-error-page`に設定します。

   *  **プロジェクト** ：このチュートリアルでは、 **プロジェクト** を`default`に設定します。

   * **作成方法**：このチュートリアルでは、 **テンプレートで作成**を選択し、 **オリジンサーバーのカスタムエラーページ** テンプレートを選びます。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_5173e830e03af951632e5396345c494b.png) </span>

4. **保存**をクリックして関数を作成します。


次に、コードの編集とデバッグを行う必要があります。

<span id="ステップ2：コードを編集しデバッグする"></span>
## ステップ2：コードを編集しデバッグする


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **コード** タブを選択し、**編集とデプロイ** をクリックします。

4. コードエディタで`default`ファイルを表示します。必要に応じてコードを修正できます。このチュートリアルではテンプレートが提供するコードを使用します。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">このコードは<a href="https://docs.byteplus.com/docs/byteplus-cdn/docs-addEventListener-jp">addEventListener()</a>を呼び出してイベントリスナーを登録します。渡されるパラメータには<code>fetch</code>とコールバック関数<code>{event.respondWith(handleResponse(event));}</code>が含まれます：   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><code>fetch</code>は、このイベントリスナーがフェッチイベントを監視することを示します。ドメイントリガーによってフェッチイベントがトリガーされると、コールバック関数が呼び出されます。ステップ4で関数のドメイントリガーを設定します。<a href="https://docs.byteplus.com/docs/byteplus-cdn/docs-FetchEvent-jp">FetchEvent</a>を参照してください。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">オリジンサーバーのレスポンスのステータスコードが5xxの場合、コールバック関数はオリジンサーバーのレスポンスを、<code>htmlResponse</code>定数にあるHTMLコードであるカスタムHTMLページに書き換えます。   </div>
   


```JavaScript
  const htmlResponse = `
  <html>
  
    <head>Error Page</head>
    <body>The server is experiencing some issues, please try again later</body>
  </html>
  `;
  
  // Add an EventListener to listen to fetch event. A domain trigger will trigger a fetch event
  addEventListener('fetch', (event) => {
    event.respondWith(handleResponse(event));
  });
  
  function isErrorStatus(st) {
    return st >= 500;
  }
  
  async function handleResponse(event) {
    const response = await fetch(event.request);
  
    // If the origin server returns a status code >= 500, then return the custom error page
    // Otherwise, return the information from the origin server.
    if (isErrorStatus(response.status)) {
      return htmlResponse;
    } else {
      return response;
    }
  }
```



5. コードをデバッグします。このチュートリアルでは、5xxステータスコードを返すURLを入力し、**送信**をクリックして、返された結果が期待通りかを確認します。デバッグ後、**保存**をクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">HTTPタブが緑色のドットを表示している場合にのみ、関数をデバッグするためのリクエストを送信できます。長時間操作を行わなかった場合、デバッガーはサーバーから切断されます。この時、HTTPタブは赤いドットを表示し、デバッグできなくなります。ページを更新すると、デバッガーは自動的に再接続し、HTTPタブは緑色のドットを表示します。   </div>
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_44561673a588c293db89e5ed7886b91a.png) </span>


次に、関数を公開する必要があります。

<span id="ステップ3：関数を公開する"></span>
## ステップ3：関数を公開する

関数をドメインに関連付ける前に、完全に公開する必要があります。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **コード** タブを選択し、**編集とデプロイ** をクリックします。

4.  **デプロイ** ボタンをクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">関数を完全にリリースする前に、カナリアリリースを実行できます。<a href="https://docs.byteplus.com/docs/byteplus-cdn/docs-create-function-jp">関数管理</a>を参照してください。   </div>
   

5.  **デプロイ** ダイアログボックスで、 **リリースタイプ** を **フルリリース** に設定し、**確認**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_711fd8eb704dbab48877f6b8d0dc8922.png) </span>


次に、関数とドメインを関連付ける必要があります。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">関数の完全リリースには通常5〜10分かかります。関数が完全にリリースされるのを待ってから、ドメインと関連付けることができます。</div>


<span id="ステップ4：関数とドメインを関連付ける"></span>
## ステップ4：関数とドメインを関連付ける

この例では、ドメイントリガーを使用して関数の実行をトリガーします。したがって、ドメイン`www.example.com`を関数に関連付ける必要があります。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、 **ドメイン名**タブを選択して、 **ドメイン名を追加**をクリックします。

4.  **ドメイン名を追加**ページで、`www.example.com`ドメインを選択します。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_79864feb678b94f5d9883031a9c65282.png) </span>

5. **保存**をクリックします。ドメインの関連付けが完了すると、関数のステータスが**実行中**に変わります。ドメインの転送ルールをまだ設定していないため、ドメインのステータスは **オフライン** です。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ae35f90714aa461a4f261760eacfe04a.png) </span>


次に、ドメインの転送ルールを設定する必要があります。

<span id="ステップ5：ドメインの転送ルールを設定する"></span>
## ステップ5：ドメインの転送ルールを設定する

ドメインの転送ルールを設定すると、BytePlus CDNが転送ルールに一致するユーザーリクエストを受信した場合、そのリクエストをエッジ関数に転送します。さらに、ドメイントリガーが関数内のフェッチイベントをトリガーします。


1. [関数](https://console.byteplus.com/cdn/edge-function/list)ページを開きます。

2. **関数**ページで、**名前**列に作成した関数を見つけ、関数名をクリックします。

3.  **トリガー** タブを選択し、 **ドメイン名**タブを選択します。ドメイン`www.example.com`の前にあるチェックボックスをクリックし、**転送ルールを設定する** ボタンをクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_177c32ac333bd230d5356b1be76e9a7a.png) </span>

4. **転送ルールを設定する** サイドバーで、以下の表に従って**転送ルール** パラメータを設定します。この例では、ユーザーリクエストURLのパスを制限しないため、任意のパスにマッチします。

   
   |パラメータ名 |説明 |
   |---|---|
   |フィルタータイプ |このチュートリアルでは、**URLパスディレクトリ** に設定する必要があります。 |
   |パターン |このチュートリアルでは、`/`に設定する必要があります。これはドメイン下のすべてのパスにマッチすることを意味します。 |
   |大文字小文字を無視 |このチュートリアルでは、デフォルト値のままにしておく必要があります。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_19ee22afb306654174bbe48be7d4ec6f.png) </span>

5. **保存**をクリックします。数分待つ必要があります。ドメインのステータスが **オンライン** に変わったら、そのドメインに対してドメイントリガーが有効になったことを示します。この時点で、ユーザーがこのドメインにHTTP/HTTPSリクエストを送信し、そのリクエストが転送ルールに一致する場合、ドメイントリガーはそのドメインに関連付けられた関数内のフェッチイベントをトリガーします。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_bc8d51fcfa3ab2596aaa21776d0f725c.png) </span>

次に、関数の実行結果が期待通りかを確認します。

<span id="ステップ6：関数を検証する"></span>
## ステップ6：関数を検証する

www.example.comにアクセスして以下を確認できます：


* オリジンサーバーのレスポンスコードが5xxの場合、返されるHTMLページはコード内の`htmlResponse`定数の値です。

* オリジンサーバーのレスポンスコードが5xxでない場合、返されるHTMLページはオリジンサーバーからのものです。


検証が成功した場合、例のシナリオが実装されたことを意味します。
