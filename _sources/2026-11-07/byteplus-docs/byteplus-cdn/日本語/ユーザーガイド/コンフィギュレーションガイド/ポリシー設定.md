<span id="概要"></span>
## 概要

CDNでは、ポリシーの設定はバージョンで管理されています。ポリシーの設定には、CDNの特性の設定とオリジンサーバーの設定が含まれます。ポリシーを作成すると、初期バージョンが作成されます。ポリシーの設定を変更するには、以下の手順を実行する必要があります：


1. ポリシーの下書きバージョンを作成します。

2. 下書きバージョンのポリシー設定を更新します。

3. 下書きバージョンを公開します。


また、ポリシーバージョンでは、ポリシーの設定を以前のバージョンにロールバックすることができます。特定のバージョンをコピーして、コピーしたバージョンのポリシー設定を更新することもできます。バージョンの公開やロールバック時には、後の保守のために意味のある説明を追加することをお勧めします。例えば、後でバージョンの確認、コピー、または削除が必要な場合、バージョンの説明は操作対象のバージョンを特定するのに役立ちます。

<span id="バージョンの状態"></span>
###  **バージョンの状態**

ポリシーバージョンには以下の状態があります：


* 公開済み：バージョンが公開され、バージョン内のポリシー設定が有効になっていることを示します。

* 公開停止：バージョンが以前は公開されていましたが、取り下げられ、バージョン内のポリシー設定が無効になっていることを示します。

* 下書き：バージョンがまだ公開されていないことを示します。


バージョンの状態が「下書き」の場合のみ、バージョン内のポリシー設定を変更できます。

以下の表は、各状態で実行可能な操作を示しています。


| **バージョン状態** |**許可される操作（Yは許可を示す）**  ||||||
|---|---|---|---|---|---|---|
||**表示** |**編集** | **ロールバック**  |**公開** |**削除** | **コピー**  |
|下書き | |Y | |Y |Y | |
|公開済み |Y | | | | |Y |
|公開停止 |Y | |Y | |Y |Y |


<span id="バージョン番号"></span>
###  **バージョン番号**

バージョンを公開すると、CDNはそのバージョンにバージョン番号を生成します。[バージョンをロールバック](https://docs.byteplus.com/en/docs/18/40647#%E3%83%90%E3%83%BC%E3%82%B8%E3%83%A7%E3%83%B3%E3%82%92%E3%83%AD%E3%83%BC%E3%83%AB%E3%83%90%E3%83%83%E3%82%AF%E3%81%99%E3%82%8B)すると、CDNは新しいバージョンを生成して公開し、そのバージョンにバージョン番号を生成します。

バージョン番号の命名規則は `P-<publish_date>-<random_5_digits>` です。例：`P-250224.44093`。

下書き状態のポリシーにはバージョン番号がなく、 **バージョン** 列には `Latest` と表示されます。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">各ポリシーは最大50個の公開済みバージョンを記録します。</div>


<span id="操作手順"></span>
## 操作手順

<span id="バージョン内のポリシー設定を表示する"></span>
### バージョン内のポリシー設定を表示する

「公開済み」または「公開停止」状態のバージョンについて、バージョン内のポリシー設定を表示できます。ポリシーの設定はAPI パラメータ形式で表示されます。各パラメータの意味については、[UpdateServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference-updateservicetemplate)と[UpdateCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference-updateciphertemplate-ac087)をご参照ください。

特定のバージョンのポリシー設定を表示するには、以下の2つの方法があります。

<span id="方法1：ポリシー詳細ページで表示する"></span>
#### **方法1：ポリシー詳細ページで表示する** 


1. ポリシーリストから、表示したいポリシーを見つけ、そのポリシーのIDをクリックします。

2. ポリシー詳細ページの右上にあるバージョンリストから、表示したいバージョンを選択します。


バージョンを選択すると、ポリシー詳細ページにそのバージョンのポリシー設定が表示されます。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">バージョンリストのバージョンは作成日時順に並べられています。最新のバージョンが最初に表示されます。</div>


* <div data-tips="true" data-tips-type="tip">バージョンリストにはバージョン番号のみが表示され、バージョンの説明は表示されません。バージョンの説明に基づいて表示するバージョンを選択する必要がある場合は、方法2を使用してください。</div>



<span id="方法2：「ポリシーバージョン」タブで表示する"></span>
#### **方法2：「ポリシーバージョン」タブで表示する** 


1. ポリシーリストから、表示したいポリシーを見つけます。

2.  **アクション** 列で、**履歴**をクリックします。

3. **履歴**タブで、 **ポリシーバージョン** をクリックします。

4. バージョンリストから、表示したいバージョンを見つけます。

5.  **アクション** 列で、**表示**をクリックします。


<span id="バージョンを作成する"></span>
### バージョンを作成する

ポリシーバージョンを作成するには、以下の手順に従います：


1. ポリシーリストから、操作したいポリシーを見つけます。

2. ポリシーIDをクリックしてポリシー詳細ページを開きます。

3. ページ右上の**新規バージョン** をクリックします。


**新規バージョン** をクリックすると、CDNは「公開済み」状態のバージョンをコピーして、「下書き」状態の新しいバージョンを生成します。このバージョンのバージョン番号は`Latest`となります。同時に、**新規バージョン** ボタンは無効化されます。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip"><strong>新規バージョン</strong>をクリックした後、ポリシー詳細ページに表示されるのは下書きバージョンのポリシー設定ではなく、「公開済み」状態のバージョンのポリシー設定です。</div>


* <div data-tips="true" data-tips-type="tip">1つのポリシーに対して「下書き」状態のバージョンは1つしか持てません。つまり、すでに「下書き」状態のバージョンが存在する場合、<strong>新規バージョン</strong>ボタンは無効化され、新しいバージョンを作成することはできません。</div>



<span id="バージョン内のポリシー設定を変更する"></span>
### バージョン内のポリシー設定を変更する

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">「下書き」状態のバージョンのポリシー設定のみ変更できます。</div>


バージョン内のポリシー設定を変更するには、以下の手順に従います：


1. ポリシーリストから、操作したいポリシーを見つけます。

2.  **アクション** 列で、**履歴**をクリックします。

3. **履歴**タブで、 **ポリシーバージョン** をクリックします。

4. バージョンリストから、操作したいバージョンを見つけます。

5.  **アクション** 列で、**編集**をクリックします。

6. ポリシー詳細ページで、 **ポリシー設定**タブをクリックします。

7. ポリシーの設定を変更します。

8. 変更完了後、ページ右下の**保存**をクリックします。


<span id="バージョンを公開する"></span>
### バージョンを公開する

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">「下書き」状態のバージョンのみ公開できます。</div>


下書きバージョンのポリシー設定を有効にするには、そのバージョンを公開する必要があります。バージョンを公開すると、バージョン内のポリシー設定がそのポリシーに紐付けられているすべてのドメインに適用されます。

バージョンを公開するには、以下の手順に従います：


1. ポリシーリストから、操作したいポリシーを見つけます。

2.  **アクション** 列で、**履歴**をクリックします。

3. **履歴**タブで、 **ポリシーバージョン** をクリックします。

4. バージョンリストから、操作したいバージョンを見つけます。

5.  **アクション** 列で、**公開**をクリックします。

6. **公開**ダイアログで、意味のあるバージョンの説明を入力し、**確定**をクリックします。


バージョンが公開されると、そのバージョンの状態は「下書き」から「公開済み」に変わります。以前公開されていたバージョンの状態は「公開済み」から「公開停止」に変わります。

<span id="バージョンをロールバックする"></span>
### バージョンをロールバックする

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">「公開停止」状態のバージョンのみロールバックできます。</div>


「公開停止」状態のバージョンについて、そのバージョンのポリシー設定を有効にする必要がある場合は、そのバージョンをロールバックできます。ロールバック操作により、バージョン内のポリシー設定がそのポリシーに紐付けられているすべてのドメインに適用されます。

「公開停止」状態のバージョンをロールバックすると、CDNは以下の操作を実行します：


1. そのバージョンをコピーして、「下書き」状態の新しいバージョンを生成します。

2. その下書きバージョンを公開します。


バージョンをロールバックするには、以下の手順に従います：


1. ポリシーリストから、操作したいポリシーを見つけます。

2.  **アクション** 列で、**履歴**をクリックします。

3. **履歴**タブで、 **ポリシーバージョン** をクリックします。

4. バージョンリストから、ロールバックしたいバージョンを見つけます。

5.  **アクション** 列で、 **ロールバック** をクリックします。

6. **公開**ダイアログで、意味のあるバージョンの説明を入力し、**確定**をクリックします。


<span id="バージョンのコピー"></span>
### バージョンのコピー

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">「公開済み」または「公開停止」状態のバージョンのみコピーできます。</div>


特定のバージョンに基づいてポリシーの設定を変更する必要がある場合は、そのバージョンをコピーできます。

バージョンをコピーすると、CDNは以下の操作を実行します：


* コピー元のバージョンと同じ内容の新しいバージョンを作成します。作成されたバージョンの状態は「下書き」となります。


バージョンをコピーするには、以下の手順に従います：


1. ポリシーリストから、操作したいポリシーを見つけます。

2.  **アクション** 列で、**履歴**をクリックします。

3. **履歴**タブで、 **ポリシーバージョン** をクリックします。

4. バージョンリストから、コピーしたいバージョンを見つけます。

5.  **アクション** 列で、 **コピー** をクリックします。


注意：「下書き」状態のバージョンが存在する場合、コピー操作で生成されたバージョンはその下書きバージョンを上書きします。

<span id="バージョンを削除する"></span>
### バージョンを削除する

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">「公開停止」または「下書き」状態のバージョンのみ削除できます。</div>


* <div data-tips="true" data-tips-type="tip">削除したバージョンは復元できません。</div>



バージョンが不要になった場合は、そのバージョンを削除できます。
