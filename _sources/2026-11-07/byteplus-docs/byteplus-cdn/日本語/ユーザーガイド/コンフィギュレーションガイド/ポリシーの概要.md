本ドキュメントでは、BytePlus CDNのポリシーについて説明します。CDNでは、ドメイン名設定はポリシーを通じて実装されます。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">ポリシーはCDNの新しいコンソールの機能です。</div>


ポリシーは設定の組み合わせであり、設定テンプレートのような役割を果たします。ポリシーでは、オリジンサーバーとCDNの特性を設定します。ポリシーの設定をドメイン名に適用するには、ポリシーをドメイン名に関連付ける必要があります。1つのポリシーを複数のドメイン名に関連付けることができます。

<span id="ポリシータイプ"></span>
## ポリシータイプ

CDNは以下のポリシータイプを提供しています。


* 配信ポリシー：オリジンサーバーおよびHTTPS以外のCDN特性を設定するために使用します。

* 暗号化ポリシー：HTTPS関連のCDN特性を設定するために使用します。

* ルールエンジンポリシー：ルールエンジン内のルールを設定するために使用します。


CDNでは、各ドメイン名に1つの配信ポリシーと1つの暗号化ポリシーのみを関連付けられますが、複数のルールエンジンポリシーを関連付けることができます。

<span id="操作手順"></span>
## 操作手順

以下の手順は、配信ポリシーの作成を例にしています。暗号化ポリシーの作成手順も同様です。

<span id="ステップ1：配信ポリシーを作成する"></span>
### ステップ1：配信ポリシーを作成する


1. [BytePlus CDN管理コンソール](https://console.byteplus.com/cdn)にログインします。

2. 左側のナビゲーションバーで、**配信ポリシー** をクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">暗号化ポリシーを作成する場合は、<strong>セキュリティセンター</strong> \> <strong>暗号化ポリシー</strong>をクリックします。   </div>
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_39adfc5bf85c4d2ea56df3d683e66e80.jpeg) </span>

3. **配信ポリシー** ページで、 **ポリシーを作成**をクリックします。

4. **配信ポリシーを作成**ページで、ポリシー名と説明を入力します。ポリシー名の長さは100文字を超えてはならず、説明の長さは120文字を超えてはなりません。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4dc80027cbde9256f9d3bda7ec6e6761.jpeg) </span>

5.  **プロジェクト** リストで、このポリシーが属するプロジェクトを指定します。

6.  **ポリシーを設定**の下で、設定が必要なモジュールにチェックを入れ、**確認**をクリックします。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">オリジンサーバーの設定モジュールは必須です。このモジュールにはオリジンサーバー関連の設定が含まれています。   </div>
   

各ポリシーに対して、CDNはポリシーIDを作成します。ポリシーリストとポリシー詳細でポリシーIDを見つけることができます。ポリシーIDは `tpl-` で始まり、長さは10文字です。ポリシーIDは変更できません。

次に、このポリシーを設定する必要があります。

<span id="ステップ2：ポリシーを設定する"></span>
### ステップ2：ポリシーを設定する

このステップでは、オリジンサーバーとこのポリシーに含まれる他のモジュールを設定する必要があります。

オリジンサーバー設定の詳細については、[オリジンサーバー設定](https://docs.byteplus.com/docs/byteplus-cdn/configure-origin-server-jp)を参照してください。他のモジュール設定の詳細については、それぞれのモジュール設定説明を参照してください。

設定が完了したら、**保存**をクリックします。次に、このポリシーを公開する必要があります。

<span id="ステップ3：ポリシーを公開する"></span>
### ステップ3：ポリシーを公開する

ポリシーをドメイン名に関連付けるには、そのポリシーを公開する必要があります。

ポリシーを公開するには、以下の手順に従います：


1.  **ポリシー** ページのポリシーリストで、先ほど作成したポリシーを見つけます。

2.  **アクション** 列で、**公開**をクリックします。

3. ポップアップした**操作確認**ページで、**確認**をクリックします。


<span id="ステップ4：ポリシーにドメイン名を関連付ける"></span>
### ステップ4：ポリシーにドメイン名を関連付ける

ポリシーが公開されると、それをドメイン名に関連付けできます。関連付けが完了すると、ポリシーに含まれる設定がドメイン名に適用されます。

ポリシーを1つまたは複数のドメイン名に関連付けるには、以下の手順に従います：


1.  **ポリシー** ページのポリシーリストで、関連付けが必要なポリシーを見つけます。

2.  **アクション** 列で、**関連付け** をクリックします。

3. **関連付け** ページで、関連付けが必要な1つまたは複数のドメイン名にチェックを入れ、**関連付け** をクリックします。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">ポリシーが関連付けできるドメイン名数に上限はありません。ただし、コンソールでは一度に最大50個のドメイン名を選択できます。より多くのドメイン名を関連付ける必要がある場合は、<strong>ドメイン名を関連付け</strong>の手順を繰り返してください。</div>


<span id="その他のポリシー操作"></span>
## その他のポリシー操作

以下では、BytePlus CDNコンソールでポリシーに対して実行できるその他の操作について説明します。

<span id="ポリシーリストを表示する"></span>
### ポリシーリストを表示する

ポリシーリストでは、すべてのポリシーの基本情報を確認できます。これらの情報には、ポリシー名、ポリシーの説明、ポリシーのステータス、関連付けされているドメイン名数、最終更新時間が含まれます。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_04c2b23b1682b8d97610ccdd236820b7.jpeg) </span>

ポリシーIDをクリックすると、そのポリシーの詳細設定（基本情報、オリジンサーバー設定、ポリシー設定）を確認できます。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_e5728ca0dcbe21c43eca2b399f3185d8.jpeg) </span>

<span id="ポリシーを修正する"></span>
### ポリシーを修正する

ポリシーがまだ公開されていない、つまりポリシーのステータスが**下書き** の場合、ポリシーに含まれる設定を変更できます。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">公開済みのポリシーの設定は変更できません。</div>


<span id="操作手順"></span>
#### 操作手順


1. ポリシーリストで、修正が必要なポリシーを見つけます。

2.  **アクション** 列で、**変更**をクリックします。

3. 修正が完了したら、ページ右下の**保存**をクリックします。


<span id="ポリシーを削除する"></span>
### ポリシーを削除する

ドメイン名に関連付けされていないポリシーのみ削除できます。つまり、ポリシーリストで、そのポリシーの**関連付けドメイン名**列の値が0である必要があります。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">ポリシーを削除すると元に戻せません。慎重に操作してください。</div>


<span id="操作手順"></span>
#### 操作手順


1. ポリシーリストで、削除が必要なポリシーを見つけます。

2.  **アクション** 列で、**削除**をクリックします。

3. **操作の確認**ダイアログボックスで、**確認**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_253ba402fe11036fe83e9cbc77e93af0.jpeg) </span>


<span id="ポリシーをコピーする"></span>
### ポリシーをコピーする

既存のポリシーと類似した設定のポリシーを作成する必要がある場合、既存のポリシーをコピーして迅速に作成できます。

公開済みのポリシーのみコピーできます。

ポリシーのコピーによって作成されたポリシーのステータスは**下書き** になります。その後、このポリシーの設定を修正し、公開して、ドメイン名に関連付けできます。

<span id="操作手順"></span>
#### 操作手順


1. ポリシーリストで、コピーが必要なポリシーを見つけます。

2.  **アクション** 列で、 **コピー** をクリックします。

3.  **ポリシーをコピー** ダイアログボックスで、作成するポリシーの名前、説明、所属するプロジェクトを入力し、**確認**をクリックします。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_69972bc105045e9adec329ba7c9ff31d.jpeg) </span>


<span id="ポリシーを検索する"></span>
### ポリシーを検索する

ポリシーリストページで、関連付けされているドメイン名、ポリシー名、ポリシーIDを指定して条件に合うポリシーを検索できます。検索オプションには **あいまい一致**と**完全一致**があります。

以下のスクリーンショットは、www.example.comに関連付けされているすべてのポリシーを検索する方法を示しています。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_93a86a5a7d86c85db1bafce772116139.jpeg) </span>

<span id="ポリシーをエクスポートする"></span>
### ポリシーをエクスポートする

ポリシーリストの右上にあるダウンロードボタンをクリックして、既存のポリシーをエクスポートできます。

エクスポートされたリストは.csvファイルに保存されます。ファイル名の形式は

`ByteplusCDN-<Policy_Type> <Account_ID>_<Export_Time>`です。例：ByteplusCDN\-Deliver\-Policy 3000000427_20230825190817。ファイルの内容はポリシーリストと一致します。

<span id="履歴の表示"></span>
### 履歴の表示

ポリシー詳細ページで、ポリシーの系譜表と操作履歴を確認できます。

<span id="ポリシーの系譜"></span>
#### ポリシーの系譜

CDNでは、ポリシーを作成する方法は以下の2つがあります：


* ゼロからポリシーを作成する。

* 既存のポリシーをコピーする。


例えば、ゼロからポリシーAを作成し、ポリシーAをコピーしてポリシーBを作成し、その後ポリシーBをコピーしてポリシーCを作成したとします。この場合、ポリシーCの系譜表は ポリシーA \> ポリシーB \> ポリシーC となります。

系譜表には最大10個のコピー元が表示されます。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7b81550f5da8a4395de0a89e53dc5a09.jpeg) </span>

<span id="操作履歴"></span>
#### 操作履歴

ポリシーに対して、CDNは以下のタイプの操作を記録します：


* ポリシーを作成。

* ポリシーを公開。

* ドメイン名を関連付け。


操作履歴には、ポリシーに対して実行されたすべての操作が一覧表示されます。これらの操作は時系列順に並べられ、最新の操作が最初に表示されます。リストには最大10個の操作が表示されます。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4833219f87c56965bd4470e9e2916768.png) </span>

ドメイン名の関連付け操作についてはドメイン名の関連付け操作については、リストには関連付け操作の前後でそのポリシーに関連付けされていたドメイン名も表示されます。**変更を表示**をクリックすると変更内容を確認できます。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ee1562bf2e4b2bd7fcc5d323f98b53d5.jpeg) </span>
