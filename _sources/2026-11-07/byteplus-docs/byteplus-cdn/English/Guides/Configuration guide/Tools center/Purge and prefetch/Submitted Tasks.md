To monitor the progress and results of your CDN Purge and Prefetch operations, you can check their status in the console. This guide provides step\-by\-step instructions on how to find and filter your submitted tasks and interpret their execution status.

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_a170653d65456de7ca7d2da28eab4d5a.png) </span>

<span id="steps"></span>
## Steps


1. Log in to the [BytePlus CDN Management Console](https://console.byteplus.com/cdn).

2. In the left sidebar, click **Tools Center** \> **Purge and Prefetch**.

3. On the **Purge and Prefetch** page, click the **Submitted Tasks** tab.

4. Specify the filter conditions for the task, and click **Query**.

5. In the query results, check the execution status of the relevant tasks.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">In the query results, if a prefetch task shows <strong>Failed (origin server issue)</strong> in the <strong>Task Status</strong> column, it indicates that the origin server response code is 4xx or 5xx. In this case, verify that the origin server is responding to requests correctly.</div>
