To allow clients using IPv6 addresses to access your services, you can enable the IPv6 feature for your domain names within BytePlus CDN. This document guides you through the simple process of enabling this feature, which expands your service's accessibility by supporting the latest IP protocol.

<span id="steps"></span>
## Steps


1. Open the **IPv6** configuration page. For instructions, see [Domain configuration](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_en).

2. Set **Status** to **Enabled**, then click **Save**.
