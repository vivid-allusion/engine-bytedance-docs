Views help information for the Edge Functions CLI.

<span id="synopsis"></span>
## Synopsis

```shell
npx nest help

npx nest help <command>
```


<span id="description"></span>
## Description

You can use `npx nest help` to view help information for the Edge Functions CLI. You can also use `npx nest help <command>` to view help information for a specific command.
