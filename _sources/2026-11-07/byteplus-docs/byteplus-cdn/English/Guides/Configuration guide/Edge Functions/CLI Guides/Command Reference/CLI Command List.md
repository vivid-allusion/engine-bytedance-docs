The Edge Functions CLI provides the following commands:


* [Functions](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-manage-funcs-topichead-en)

   * [nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-en): Creates a function project, and create a local function within the function project.

   * [Manage Functions](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-manage-functions-topichead-en)

      * [nest deploy](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-deploy-en): Deploys a local function to edge nodes.

      * [nest upload](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-upload-en): Uploads local function code to the remote function.

      * [nest functions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-en): Performs CRUD operations on local functions.

   * [Debug Function Code](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-local-dev-en)

      * [nest debug](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-debug-en): Debugs function code locally.

      * [nest start](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-start-en): Runs function code locally.

   * [Triggers](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-triggers-topichead-en)

      * [nest domain](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-domain-en): Manages domain triggers.

      * [nest cron](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-cron-en): Manages Cron triggers.

   * [Release History](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-history-topichead-en)

      * [nest rollback](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-rollback-en): Rolls back function code to a specified historical version.

      * [nest versions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-version-en): Gets historical versions of function code.

      * [nest tickets](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-ticket-en): Gets release records of function code.

   * [Function Configuration](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-function-config-topichead-en)

      * [nest envs](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-env-en): Manages function environment variables.

      * [nest canary](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-canary-en): Manages function canary environments.

* [Edge KV](https://docs.byteplus.com/docs/byteplus-cdn/edge-function-cli-ref-edge-kv-topichead-en)

   * [nest kv](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-kv-en): Manages Edge KV.

* [Utility Tools](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-others-topichead-en)

   * [nest config](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-config-en): Manages Edge Functions CLI configuration.

   * [nest help](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-help-en): Gets help information.

* [Global Parameters](https://docs.byteplus.com/docs/byteplus-cdn/global-parameters-en)

   * [--config](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-c-en)

   * [--function](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-f-en)

   * [--verbose](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-verbose-en)

   * [--help](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global--help-en)
