The programming language supported by Edge Functions runtime is JavaScript (ES6). Developers interact with the Edge Functions runtime by calling runtime APIs. The runtime APIs include some standard APIs from [WinterTC](https://wintertc.org/) and APIs unique to Edge Functions.
