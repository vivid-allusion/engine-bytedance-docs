The [Web Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API) provides a set of methods for handling tasks related to encryption, decryption, digest, and digital signatures.


* [Supported Algorithms](https://docs.byteplus.com/docs/byteplus-cdn/docs-SupportedAlgorithms)

* [digest()](https://docs.byteplus.com/docs/byteplus-cdn/docs-digest)

* [sign()/verify()](https://docs.byteplus.com/docs/byteplus-cdn/docs-sign-verify)

* [encrypt()/decrypt()](https://docs.byteplus.com/docs/byteplus-cdn/docs-encrypt-decrypt)
