Specifies the ID or name of the function.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This global parameter is only available in function\-related commands.</div>


<span id="synopsis"></span>
## Synopsis

```shell
--function <function_id_or_name> 
```



* `<function_id_or_name>`: *string, optional*

   * The ID or name of the function. You can obtain the function ID or name through [nest function list](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-cn).
