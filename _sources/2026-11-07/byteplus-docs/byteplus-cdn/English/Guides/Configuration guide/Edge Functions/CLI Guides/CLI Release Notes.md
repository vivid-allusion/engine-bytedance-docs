This document contains the release notes of the Edge Functions CLI.

<span id="v1-3-0"></span>
## v1.3.0

This version was released on November 28, 2025.

<span id="new-features"></span>
### New Features

<span id="support-for-pages-cli"></span>
#### Support for Pages CLI

Edge Functions Pages is a static page hosting service provided by BytePlus Edge Functions, designed to help developers quickly and efficiently deploy static websites to a global network of edge nodes. You can now use Edge Functions Pages via the Edge Functions CLI. See [nest pages](https://docs.byteplus.com/en/docs/byteplus-cdn/nest_pages_en).

<span id="added-region-restriction-feature"></span>
#### Added region restriction feature

When creating functions or storage spaces, you can set whether the function's publishing region or KV data's storage region is limited to mainland China.

The following commands have a new \-\-cn parameter:


* [nest init](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-init-en): The \-\-cn parameter is used to set whether the function's publishing region is limited to mainland China.

* [nest functions create](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-function-en#create): The \-\-cn parameter is used to set whether the function's publishing region is limited to mainland China.

* [nest kv namespace create](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-kv-en#create): The \-\-cn parameter is used to set whether the KV data's storage region is limited to mainland China.


The return values of the following commands have a new REGION column:


* [nest functions list](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-function-en#list): The return value has a new REGION column, which displays whether the function's publishing region is limited to mainland China.

* [nest kv namespace list](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-kv-en#list): The return value has a new REGION column, which displays whether the KV data's storage region is limited to mainland China.


Also, the functions object and kv object in the function configuration file nest.json have a new Region field.

<span id="bug-fixes"></span>
### Bug fixes


* Fixed an issue where the `@byteplus/nest` name under `devDependencies` was incorrect in the package.json file generated by the [nest init](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-init-en) command.

* Fixed an issue where the domain status displayed by [nest domain list](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-domain-en) was inconsistent with the console.


<span id="improvements"></span>
### Improvements


* Integrated with the new version of Edge Function OpenAPI.

* The [nest domain bind](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-domain-en) command has added availability check logic for forwarding rules.

* The [nest debug source](https://docs.byteplus.com/en/docs/byteplus-cdn/cli-ref-nest-debug-en) command can debug .js files in any directory.

* When publishing Edge KV data manually edited in nest.json, you can use the `@` symbol to reference local files as values for KV key\-value pairs.
