This document introduces how to activate Edge Functions. Before using Edge Functions, you must activate it first.

<span id="prerequisites"></span>
## Prerequisites

You have activated BytePlus CDN. See [Activate BytePlus CDN](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-activate-cdn).

<span id="steps"></span>
## Steps


1. Log in to the [BytePlus Edge Functions Console](https://console.byteplus.com/cdn/cdn-bp/edge-function/).

2. On the service activation page, carefully read the content on the page to understand the billing method of Edge Functions.

3. Check the service agreement, then click **Activate**.

4. In the **Confirm Order** dialog box, click **Confirm**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Since Edge Functions is post\-paid, the price displayed on the page is $0.00. This means that activating Edge Functions is free of charge.   </div>
   

<span id="billing-information"></span>
## Billing Information

For billing details, see [Billing for Edge Functions](https://docs.byteplus.com/en/docs/byteplus-cdn/billing_edge_functions_en).
