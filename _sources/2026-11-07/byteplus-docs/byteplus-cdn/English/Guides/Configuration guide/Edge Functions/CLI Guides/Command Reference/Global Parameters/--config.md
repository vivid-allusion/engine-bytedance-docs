Specifies a function configuration file. By default, local functions use the nest.json file in the root directory as the configuration file.

<span id="synopsis"></span>
## Synopsis

```shell
--config <config_file_path>
```



* `<config_file_path>`: *string, required*

   * The path to the function configuration file.
