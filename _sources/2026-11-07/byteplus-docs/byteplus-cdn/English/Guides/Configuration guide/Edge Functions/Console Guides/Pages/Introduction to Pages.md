This document is the overview page for Pages. It introduces the product positioning, limits, and links to topic\-specific documents.

## What Is Pages

Pages is a one\-stop static site and web application hosting service provided by BytePlus. Pages brings together code hosting, automated builds, global content delivery (CDN), and lightweight dynamic capabilities in a unified console, helping you create, deploy, preview, bind domains, and continuously update projects more efficiently.

With BytePlus Pages, you can host many types of projects, including but not limited to:

* Static websites (HTML/CSS/JavaScript)

* Single\-page applications (SPAs)

* Documentation sites

* Blogs

* Frontend projects managed and deployed through Git

* Starter projects created from templates

* Lightweight dynamic sites that include a `/functions` directory

Pages distributes static assets through a global edge network to help you deliver content to end users with lower latency.

## Limits

Pages currently has the following limits:

* Each BytePlus account can create up to 5 Pages projects.

* Each Pages project can retain up to 10 historical deployments. Older deployments are automatically cleaned up when the limit is exceeded.

* Each BytePlus account includes up to 50 builds per month.

* Each BytePlus account can run 1 build at a time.

* Each build can run for up to 10 minutes.

* Each BytePlus account can bind 1 custom domain.

* Each ZIP package must not exceed 50 MB.

* Each ZIP package must not contain more than 500 files.

* Each individual file in a ZIP package must not exceed 5 MB.
