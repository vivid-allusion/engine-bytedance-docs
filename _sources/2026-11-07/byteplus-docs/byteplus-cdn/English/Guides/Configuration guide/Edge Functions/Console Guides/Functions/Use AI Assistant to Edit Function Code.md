This document describes how to use the AI assistant provided by the Edge Functions console to edit function code.

The AI assistant has built\-in sample code for the Edge Functions runtime API, which can help you generate, fix, and explain function code with the help of large language models.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">The code generated by the AI assistant is for reference only. Please check it carefully before use to ensure its accuracy and applicability.</div>


* <div data-tips="true" data-tips-type="warning">The code explanation provided by the AI assistant is for reference only. Please refer to the official documentation of Edge Functions.</div>



<span id="usage-limits"></span>
## Usage limits

Your daily usage limits are as follows:


* **Number of dialogues**: You can start up to 10 dialogues.

* **Number of messages**: You can send up to 100 messages in each dialogues.

* **Message length**: Each message cannot exceed 250 full\-width characters or 500 half\-width characters.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The message length limit does not include the code added as context.   </div>

<span id="steps"></span>
## Steps

Follow these steps to use the AI assistant.

<span id="step-1-open-the-ai-assistant-panel"></span>
### Step 1: Open the AI Assistant panel

In the Edge Functions console, you can click the AI assistant icon in the upper right corner of the code editor to open the AI assistant panel.

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_5cc2b4f5601b18ba6794e00e9f0c4850.png) </span>

<span id="step-2-generate-code-with-the-ai-assistant"></span>
### Step 2: Generate code with the AI assistant

Follow these steps to generate code with the AI assistant.


1. Enter your requirements in the dialog box of the AI assistant panel, and then click the **Send** icon. The AI assistant will generate function code that meets your requirements. For example, you can enter the following requirements:


```text
Generate code to modify the HTTP request header in the user request and the response header in the response returned to the user:
- Add a custom request header "x-via-function-start" to the request header with the current timestamp as its value.
- Add a custom response header "x-via-function-done" to the response header with the current timestamp as its value.
```


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_aa4cb885a4ab27786018e0e7a941bf30.png) </span>

2. Click the **Apply code** icon in the upper right corner of the generated code to apply the code to the editor.

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_49648d2d73463f6bae40d97b27db478b.png) </span>

Next, you can debug the code. Refer to [Edit and Debug Function Code](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-develop-and-test-function).

<span id="other-operations"></span>
## Other operations

<span id="fix-code-with-the-ai-assistant"></span>
### Fix code with the AI assistant

If you find problems during debugging and need to fix the code, follow these steps.


1. Select some or all of the code in the code editor and click **Fix code**. The AI assistant will fix the code.

2. Click the **Apply code** icon in the upper right corner of the generated code to apply the optimized or fixed code to the editor.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_fa3cdedfbad862fa1c85d7600290c569.png) </span>

<span id="explain-code-with-the-ai-assistant"></span>
### Explain code with the AI assistant

If you want to use the AI assistant to understand the logic of a code snippet or the entire code file, you can select some or all of the code in the code editor and click **Explain code**. The AI assistant will explain the code.

<span id="add-code-as-dialog-context"></span>
### Add code as dialog context

If you need to add a code snippet or the entire code file as the context of the dialogue, you can select some or all of the code in the code editor and click **Add to chat**. You can use natural language to describe your needs, such as modifying the code, optimizing the code, etc.
