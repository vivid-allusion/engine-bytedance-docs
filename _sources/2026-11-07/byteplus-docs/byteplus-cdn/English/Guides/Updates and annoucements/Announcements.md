## April 10, 2024

Released Edge Functions and Edge KV modules. In a CDN,


* You can create functions to perform specific operations on user requests that meet specified filtering conditions, such as obtaining content from the origin site, accessing other cloud services. See [Edge Functions Overview](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-overview-of-edge-function).

* You can use Edge KV to centrally store and manage the data that edge functions need to access, separating code management and data management. See [Edge KV Overview](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-EdgeKV-overview).


<span id="december-6-2023"></span>
## December 6, 2023

On December 6, 2023, a new version of the BytePlus CDN control panel was launched. The new control panel introduces policy\-based domain name configuration. See Policy Overview for more details.

If you activated CDN after December 6, 2023, you will use the new version of the control panel by default. If you activated CDN before this date and want to experience the new control panel, please [submit a ticket](https://console.byteplus.com/workorder/create).
