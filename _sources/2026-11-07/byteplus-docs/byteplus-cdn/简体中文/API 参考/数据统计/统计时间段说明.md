基于您指定的 `StartTime`、`EndTime` 和 `Interval`，CDN 采集一系列数据点。`Interval` 表示 CDN 采集这些数据点的时间间隔。例如，对于 `Interval` 是 `5min`，CDN 每 5 分钟采集 1 个数据点。

下表中的例子展示了 CDN 基于不同的 `Interval` 而采集的数据点数量以及每个数据点所对应的时间区间。


|**StartTime** |**EndTime** |**Interval** |**CDN 采集的数据点数量** |**采集的数据点所分别对应的时间区间** |**实际统计时间段** |
|---|---|---|---|---|---|
|15:07 |15:21 |5 分钟 |4 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25) |[15:05,15:25) |
|15:07 |15:25 |5 分钟 |5 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25)、[15:25,15:30) |[15:05,15:30) |
|15:05 |15:25 |5 分钟 |5 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25)、[15:25,15:30) |[15:05,15:30) |
|15:07 |18:21 |1 小时 |4 |[15:00,16:00)、[16:00,17:00)、[17:00,18:00)、[18:00,19:00) |[15:00,19:00) |
|15:07 |19:00 |1 小时 |5 |[15:00,16:00)、[16:00,17:00)、[17:00,18:00)、[18:00,19:00)、[19:00,20:00) |[15:00,20:00) |


由此可见，CDN 采集的数据点所对应的**实际统计时间段**可能与您指定的统计时间段有差异。

<span id="细分数据"></span>
#### 细分数据

CDN 基于 `Interval` 采集的数据点就是指定指标的细分数据。细分数据体现了指标数据的趋势。

<span id="汇总数据"></span>
#### 汇总数据

CDN 基于细分数据统计指标的汇总数据。不同指标的汇总方式不同，参见 [指标的定义以及统计方式](https://docs.byteplus.com/en/docs/byteplus-cdn/lHMepA)。

例子：您指定的 `StartTime` 表示 15:07，`EndTime` 表示 15:20，`Interval` 是 `5min`，指定的 `Metric` 是 `traffic`。在这个情况下，CDN 按以下步骤统计流量的汇总数据：


1. 统计以下各时间区间的流量数据：[15:05,15:10)、[15:10,15:15)、[15:15,15:20)、[15:20,15:25)。实际统计时间段是 [15:05,15:25)。

2. 对这些流量数据进行求和，作为指定统计时间段内流量指标的汇总数据。
