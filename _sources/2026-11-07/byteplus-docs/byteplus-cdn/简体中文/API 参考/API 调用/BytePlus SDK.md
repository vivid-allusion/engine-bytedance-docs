BytePlus SDK 使您以编程方式与 BytePlus CDN 进行交互。在交互过程中您无需处理复杂的签名计算。BytePlus SDK 为 PHP、Go、Python 和 Java 提供了相应的库。BytePlus SDK 也提供了示例代码方便您上手。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">目前，边缘函数 SDK 暂未提供。关于 WAF SDK，请参见 <a href="https://docs.byteplus.com/en/docs/waf/web-application-firewall-release-notes">WAF 文档</a> 获取最新动态。</div>
