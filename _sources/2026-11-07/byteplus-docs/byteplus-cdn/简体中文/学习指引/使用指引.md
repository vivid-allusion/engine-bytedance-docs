## 首次使用 CDN（必读）

如果您首次使用 CDN，您需要先创建并发布一个分发策略，然后添加您的域名。

我们准备了 CDN 快速入门，指导您将域名与 CDN 对接。您可以点击步骤中的链接查看快速入门中的相关操作。

步骤

1.

   [创建分发策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-set-up-distribution-policy-and-origin-cn)。

2.

   [发布分发策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-set-up-distribution-policy-and-origin-cn)。

3.

   [添加域名并绑定分发策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-add-your-domain-name-cn)。

4.

   [测试对 CNAME 的访问](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-test-domain-name-with-hosts-cn)。

5.

   [配置 CNAME 记录](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-set-up-cname-cn)。

> **说明**

*

   > 在创建分发策略时，您需要指定您的站点作为源站。

*

   > 您在 CDN 中添加的域名不能与您指定的源站相同。因为在第 5 步中，您需要将您 CDN 中添加的域名解析到 CDN 为您域名分配的 CNAME。如果源站也是该域名，CDN 向源站发送的请求会被 CDN 自己收到，造成请求死循环。因此，如果您的源站的确就是您要在 CDN 中添加的域名，您可以将您域名的 IP 地址指定为源站。

*

   > 第 5 步操作是在您的域名解析服务商处操作的。

## 启用 HTTPS 加密服务（推荐）

在您为域名启用 HTTPS 加密服务后，用户就能使用 HTTPS 协议访问您的域名，以加密用户与 CDN 之间的通信。

要启用 HTTPS，您需要先将一个签发给您域名的证书上传到 CDN。您在 CDN 中上传的证书是在 BytePlus 证书中心托管的。由于 CDN 和 BytePlus 证书中心是不同的 BytePlus 服务，在上传证书前，您需要授权 CDN 访问证书中心。

步骤

1.

   [授权 CDN 访问证书中心](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-authorize-byteplus-cdn-to-access-byteplus-certificate-center-cn)。

2.

   [上传证书](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-upload-certificates-certfiicate-center-cn)。

3.

   [为域名启用 HTTPS 加密服务](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-add-domain-name_1-cn)。

4.

   [关联证书与域名](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-associate-domain-name-with-certificate-cn)。

> **说明**

> 只有启用了 HTTPS 加密服务，域名才能与加密策略绑定，使您为域名配置 [HTTPS 相关的 CDN 功能](https://docs.byteplus.com/en/docs/18/29936#https-%E7%9B%B8%E5%85%B3%E7%9A%84-cdn-%E5%8A%9F%E8%83%BD)。

## 修改 CDN 功能配置（推荐）

策略承载了 CDN 中各功能的配置。通过将一个策略与您的域名绑定，您配置的 CDN 功能就会在域名上生效，成为域名的配置。

在 CDN 中，策略有以下两类：

*

   分发策略：用于配置 [常规的 CDN 功能](https://docs.byteplus.com/en/docs/18/29936#%E5%B8%B8%E8%A7%84-cdn-%E5%8A%9F%E8%83%BD)。

*

   加密策略：用于配置 [HTTPS 相关的 CDN 功能](https://docs.byteplus.com/en/docs/18/29936#https-%E7%9B%B8%E5%85%B3%E7%9A%84-cdn-%E5%8A%9F%E8%83%BD)。

> **说明**

*

   > 只有已发布的策略才能与域名绑定。

*

   > 如果一个策略已发布，您无法修改策略的配置。

*

   > 要与加密策略绑定，域名必须已启用了 HTTPS 加密服务。

步骤

由于发布后的策略无法更改，您可以通过复制已绑定的策略来创建一个策略。在新策略中，您可以更改 CDN 功能的配置。发布该新策略后，您将新策略与域名绑定。

1.

   [复制域名绑定的策略](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-policy-cn#%E5%A4%8D%E5%88%B6%E7%AD%96%E7%95%A5)。

   > **说明**

   *

   > 要修改常规的 CDN 功能，您需要复制已绑定的分发策略。

   *

   > 要修改 HTTPS 相关的 CDN 功能，您需要复制已绑定的加密策略。

   *

   > 如果您要为域名设置 HTTPS 相关的 CDN 功能，但是域名还未绑定加密策略，步骤 1 就不是复制策略，而是创建一个加密策略。

2.

   在新策略中添加或删除需要配置的 CDN 功能。参见 [功能列表](https://docs.byteplus.com/en/docs/18/29936#%E5%AE%8C%E6%95%B4-cdn-%E5%8A%9F%E8%83%BD%E5%88%97%E8%A1%A8)。

3.

   在新策略中配置 CDN 功能。在 [功能列表](https://docs.byteplus.com/en/docs/18/29936#%E5%AE%8C%E6%95%B4-cdn-%E5%8A%9F%E8%83%BD%E5%88%97%E8%A1%A8) 中点击功能的链接，了解功能的配置方法。

4.

   [发布策略](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-policy-cn#%E6%AD%A5%E9%AA%A4-3%EF%BC%9A%E5%8F%91%E5%B8%83%E7%AD%96%E7%95%A5)。

5.

   [绑定新策略与域名](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-policy-cn#%E6%AD%A5%E9%AA%A4-4%EF%BC%9A%E7%BB%91%E5%AE%9A%E5%9F%9F%E5%90%8D)。

## 使用边缘函数（可选）

通过边缘函数，您可以创建和发布函数来对满足特定条件的请求进行处理。边缘函数支持的语言是 JavaScript。

在收到用户请求时：

*

   如果请求满足您指定的条件，CDN 会将请求交给函数来处理。处理方式可以是对请求响应特定的内容，也可以是将请求转发到其他服务。

*

   如果请求未满足您指定的条件，CDN 将处理该请求。

步骤

1.

   [授权 CDN 访问 BytePlus 边缘函数](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-authorize-byteplus-cdn-to-access-byteplus-certificate-center-cn)。

2.

   [为域名启用边缘函数](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn)。

3.

   [创建函数](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-create-function-cn)。

4.

   [发布函数](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-create-function-cn)。

5.

   [关联域名](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-domain-triggers-cn)。

6.

   [创建转发规则](https://docs.byteplus.com/zh-CN/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn)。

边缘函数还提供了边缘 KV。您可以事先在边缘 KV 中创建键值对，然后在函数代码中调用运行时 API 通过键读取值。键值对的值被更新后，在函数代码中被读取的值也会是被更新后的值。您无需重新发布函数。

创建键值对的步骤如下：

1.

   [创建存储空间](https://docs.byteplus.com/en/docs/byteplus-cdn/doc-manage-namespace-cn)。

2.

   [在存储空间中创建键值对](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-manage-data-cn)。

## 使用工具（可选）

CDN 提供了以下工具：

*

   刷新预热

   *

      [缓存刷新](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-purge-cn)：CDN 将您指定的文件删除或者标记为已过期，确保用户获取源站上最新版本的文件。

   *

      [文件预热](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-prefetch-cn)：CDN 将您指定的文件事先缓存到边缘节点，使得这些文件的首次访问也能受益于数据传输加速。

*

   诊断工具：

   *

      [IP 检测](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-diagnostic-tools-cn#ip-%E6%A3%80%E6%B5%8B)：检查一个或者多个 IP 地址是否是 CDN 边缘节点的 IP 地址。

   *

      [域名对比](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-diagnostic-tools-cn#%E5%9F%9F%E5%90%8D%E5%AF%B9%E6%AF%94)：比较两个域名配置的差异。对比的配置涵盖：

      *

         与域名绑定的策略中 CDN 功能的配置。

      *

         域名的基础属性，包含域名的创建时间、CNAME、是否开启了 HTTPS 加密服务等。

   *

      [策略对比](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-diagnostic-tools-cn#%E7%AD%96%E7%95%A5%E5%AF%B9%E6%AF%94)：比较两个策略中 CDN 功能的配置差异。

## 查看 CDN 指标（推荐）

CDN 提供了以下页面展示指标数据，使您可以监控 CDN 的使用状况。

*

   [边缘监控](https://docs.byteplus.com/en/docs/byteplus-cdn/nqffUP)：基于用户请求，该页面展示了以下指标的汇总数据和数据趋势：

   * 带宽、流量、请求数、QPS、状态码、响应时间、平均速度

*

   [源站监控](https://docs.byteplus.com/en/docs/byteplus-cdn/2Dbv8V)：基于回源请求，该页面展示了以下指标的汇总数据和数据趋势：

   * 带宽、流量、请求数、QPS、状态码、响应时间

*

   [命中率](https://docs.byteplus.com/en/docs/byteplus-cdn/sVW5Ye)：基于用户请求，该页面展示了流量命中率的指标数据。

*

   [热点排行](https://docs.byteplus.com/en/docs/byteplus-cdn/wUmY41)：基于用户请求，该页面展示了以下热门对象以及这些对象的指标数据：

   * 热门请求 URL、热门 Referer 域名、热门的访问设备、热门操作系统、热门浏览器、高频访问您域名的客户端 IP 地址、热门地区

*

   [业务分析](https://docs.byteplus.com/en/docs/byteplus-cdn/W9B_Xh)：

   *

      该页面展示各指标按国家和地区划分的汇总数据、独立访客的 IP 地址的数量趋势、基于各指标汇总数据的域名排行。

   *

      基于回源请求，该页面展示了各指标汇总数据的域名排行。

## 完整 CDN 功能列表

在处理用户请求时，如果请求文件未被缓存或者已在缓存中过期，CDN 会经历以下几个阶段：

* 收到用户请求 \> 向源站请求文件 \> 收到源站响应 \> 缓存请求文件 \> 响应用户请求

![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_aff82d247fd807eb834cdc03770a1966.png)

> **说明**

> 如果请求文件在缓存中未过期，CDN 经历的阶段是：

* > 收到用户请求 \> 响应用户请求

每个 CDN 功能对应一个请求处理阶段。功能的配置影响 CDN 在特定阶段对用户请求的处理方式。

以下功能在加密策略中配置。

|**阶段** |**分类** |**CDN 功能** |**功能说明** |
|---|---|---|---|
|收到用户请求 |协议管理 |[QUIC 设置)](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-quic_1-cn) |配置 CDN 以支持 QUIC 协议。在您启用 QUIC 后，CDN 也支持了 HTTP/3。 |
|||[HTTP/2 设置](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-http-2-cn) |配置 CDN 以支持 HTTP/2。 |
|||[强制跳转设置](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-protocol-redirect_1-cn) |配置 CDN 将用户的 HTTP 请求重定向到 HTTPS 请求，或者将 HTTPS 请求重定向到 HTTP 请求。 |
||加密优化 |[OCSP 装订](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-ocsp-stapling-1-cn) |配置 CDN 在 TLS 握手阶段向客户端发送服务器证书时，将该证书的 OCSP 响应一并发送，从而缩短 TLS 握手耗时。 |

|||[访问双向认证](https://docs.byteplus.com/en/docs/byteplus-cdn/mtls_zh-cn) |配置 CDN 在 TLS 握手时校验客户端证书，以对客户端进行身份认证。 |
