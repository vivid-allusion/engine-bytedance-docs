感谢您选择 BytePlus CDN。本教程基于一个通用场景，指导您将域名接入 CDN，加速您站点内容的分发。在您的站点接入 CDN 后，用户向您站点的请求会被路由到 CDN，由 CDN 负责向您的站点获取内容并响应用户的请求。

<span id="场景"></span>
## 场景

您有一个站点 www.example.com，其 IP 地址是 203.0.113.8。站点仅允许使用 HTTPS 协议的请求。

随着业务的增长，您频繁收到用户反馈站点页面打开慢，偶尔会出现页面无法打开的情况。为了保障用户体验，您选择了 BytePlus CDN 为您站点内容的分发加速。

在使用 BytePlus CDN 之前，您首先需要注册一个 BytePlus 账号。本教程假设您已成功注册了 BytePlus 账号。
