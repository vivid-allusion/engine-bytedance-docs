<span id="计费概述"></span>
# 计费概述

BytePlus CDN 根据从 CDN 向外传输数据和 CDN 接收的请求数收费。传输的数据也称为流量。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">对于大流量或者企业客户，我们提供了定制化报价。请 <a href="https://console.byteplus.com/workorder/create">提交工单</a> 了解定制化报价详情。</div>

<span id="计费项"></span>
## 计费项

CDN 有以下计费项：


* CDN 收到的请求数，也就是用户使用客户端（例如浏览器）访问您的站点文件时发送的 HTTP 和 HTTPS 请求。

* CDN 向客户端传输的数据。

* CDN 向源站传输的数据。

* 日志投递数（离线日志）

* 日志投递数（实时日志）


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">当前，CDN 不对 Websocket 请求数计费。但是在 Websocket 建连的握手阶段，CDN 收到的那个 HTTP 请求还是会作为 HTTP 请求数计费。</div>


<span id="计费方式"></span>
## 计费方式

CDN 使用的计费方式是按量计费后付费，即先用后付。在开通了 CDN 服务后，您无需支付任何事前费用就可以开始使用。

同时，我们提供了预付费资源包。资源包可以用来抵扣传输的数据和 CDN 收到的请求数量，以帮助您降低费用支出。

<span id="计费周期"></span>
## 计费周期

默认情况下，CDN 是按小时计费的。

<span id="26e986f2"></span>
## 欠费说明

如前所述，CDN 采用按量计费后付费、按小时结算的方式，账单会在每个计费周期结束后按小时推送。如您有按月结算的需求，请联系我们的销售或售前支持团队。

当出现以下情形时，可能导致当期账单无法正常扣款，进而产生欠费：


* 在账单推送前撤销了已绑定的支付方式（例如信用卡）。

* 账户可用余额不足，不足以支付当期账单。


对于完成个人认证的账号，一旦发生欠费，CDN 将即时关停并下线相关服务，且不再单独发送通知。发生欠费后，请您及时结清欠费款项，款项结清后服务将自动恢复上线。为避免再次因欠费而被关停、保障业务的连续性，请您确保账号绑定的支付方式持续有效，或账户余额充足，使后续账单能够正常扣款。

<span id="计费示例"></span>
## 计费示例

在 `2023-09-01 00:00:00` 至 `2023-09-01 01:00:00` 内，中国内地计费区内传输的数据为 `9,960 GB`，欧洲计费区内为 `3,960 GB`。因此，这两个计费区内当月累积传输的数据均处于 `0~10TB` 这个阶梯。该时间段内的账单费用按以下方式计算：

> 9960 \* 0.035 + 3960 \* 0.044 = 522.84，单位是 USD。


然后，在 `2023-09-01 01:00:00` 至 `2023-09-01 02:00:00` 内，中国内地计费区内传输的数据为 `100 GB`，欧洲计费区内为 `1,000 GB`。因此：


* 中国内地计费区内当月累积传输的数据处于 `10~40TB` 这个阶梯。在当前时间段所传输的 100 GB 数据中，前 40 GB 处于 `0~10TB` 这个阶梯，后 60 GB 处于 `10~40TB` 这个阶梯。

* 欧洲计费区内当月累积传输的数据仍然处于 `0~10TB` 这个阶梯。


该时间段内的账单费用按以下方式计算：

> 40 \* 0.035 + 60 \* 0.033 + 1000 \* 0.044 = 47.38，单位是 USD。

# 流量与请求数资源包（预付费）

CDN 为流量和请求数提供了资源包。如果您可以预估每个月 CDN 传输的数据或收到的请求数，我们建议您购买资源包以节省开支。资源包的有效期是 30 天。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">对于流量资源包，1 GB = 1,000 MB。</div>


<span id="资源包是如何工作的"></span>
## 资源包是如何工作的


* 结算时，CDN 会优先使用您账号下的可用资源包。如果您有多个处于可用状态的资源包，CDN 会优先使用先到期的资源包。

* 如果资源包中的流量或请求数不足以抵扣已传输的流量或 CDN 收到的请求数，超出的流量和请求数会按按量计费的价格进行结算。

* 如果出现了以下任意情况，资源包将失效：

   * 资源包已过期。

   * 资源包的额度已被用尽。


已过期的资源包中的流量或请求数无法转入其他资源包，也无法退款。
