近期，我们监测到部分用户的 CDN 域名遭遇恶意流量盗刷。此类攻击主要针对视频、安装包等大文件。发起攻击的 IP 地址会高频请求此类文件，使 CDN 流量激增。这不仅会产生超出预期的高额账单，甚至可能因账号欠费引发服务暂停。对于此类事件造成的高额账单，我们无法予以免除或退款，对此我们深表歉意。为帮助您降低相关风险，您可按照本文指导采取相应的预防措施。

<span id="主要风险"></span>
## 主要风险

**高额账单**

CDN 基于缓存节点向用户传输的数据量或这些数据量所对应的带宽计费。一旦您的域名遭遇恶意攻击或盗刷，域名通过 CDN 传输的数据量会急剧增加，进而产生额外的带宽消耗。由此产生的流量或带宽费用需由您自行承担。

**服务暂停**

若恶意攻击或盗刷导致账单金额远超预期，您的账号可能会出现欠费情况，进而导致服务暂停。

<span id="防范措施"></span>
## 防范措施

为降低域名被攻击或盗刷的风险，我们建议您采取以下防范措施：

<span id="监控用量"></span>
### 监控用量

您可通过 BytePlus 云监控对 CDN 用量进行实时监控，以便及时发现异常流量和带宽。同时，在费用中心设置账单监控，可有效降低攻击或盗刷时的损失。若您已购买了资源包，还可设置余量提醒。


|**预警能力** |**说明** |
|---|---|
|[云监控](https://console.byteplus.com/cloud-monitor) |对流量和带宽进行监控并设置用量告警。 |
|[费用预警](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-2) |在 [账户总览](https://console.byteplus.com/finance/overview) 页面中，您可以设置账单金额预警，帮助您及时察觉账单金额异常。<br><br><br>* 账单金额预警：您设置一个金额阈值。若当日后付费账单累计应付金额超过该阈值，您会收到通知。 |
|资源包余量预警 |如果您购买了资源包，可在 [资源实例管理](https://console.byteplus.com/finance/resource-package) 页面右上方点击 **余量预警**，然后设置资源包余量预警，以便及时知晓资源包用量异常。 |


<span id="流量分析"></span>
### 流量分析

启用 [实时日志投递](https://docs.byteplus.com/en/docs/byteplus-cdn/log-streaming-overview_zh-cn) 并 [配置日志检索](https://docs.byteplus.com/en/docs/byteplus-cdn/log-query-examples_zh-cn)。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">实时日志投递会产生额外费用。具体可参见 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-pricing-cn#%E8%AE%A1%E8%B4%B9%E8%AF%A6%E6%83%85%EF%BC%88%E6%8C%89%E9%87%8F%E8%AE%A1%E8%B4%B9%E5%90%8E%E4%BB%98%E8%B4%B9%EF%BC%89">实时日志计费</a>。</div>


当察觉到异常的流量和带宽时，您可以通过日志检索分析原因，锁定恶意攻击或盗刷事件的特征。例如恶意请求的来源国家或地区，发生时间段，发起攻击的 IP 地址范围等。

<span id="开启访问控制"></span>
### 开启访问控制

基于已确定的恶意请求特征，您可以配置访问控制下的特性拦截此类请求。这些特性无需额外费用，但能有效降低风险。


|**特性** |**说明** |
|---|---|
|[Referer 防盗链](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-referer-restrictions-cn) |基于 Referer 头部对请求过滤，仅允许来自特定页面的用户请求。 |
|[Origin 防盗链](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-origin-restrictions-cn) |基于 Origin 头部对请求过滤，仅允许来自特定域名的用户请求。 |
|[UA 黑白名单](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-ua-restrictions-cn) |基于 User\-Agent 头部对请求过滤，仅允许包含特定 User\-Agent 头部的用户请求。 |
|[IP 黑白名单](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-ip-restrictions-cn) |基于 IP 地址对请求过滤，仅允许来自特定 IP 地址的用户请求。 |
|[URL 鉴权](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-overview-cn) |在客户端发起请求时，对请求 URL 添加签名。CDN 收到请求后对请求鉴权，仅允许通过鉴权的用户请求。 |
|[远程鉴权](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-remote-authentication_1-cn) |若您有专用的鉴权服务器对用户请求进行鉴权，您可以在 CDN 中配置远程鉴权。 |
|[地域访问限制](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-geographical-restrictions-cn) |基于 IP 地址归属地对请求过滤，仅允许来自特定地域的用户请求。 |
|[禁用 HTTP 请求方法](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-disallowed-http-method-cn) |在 CDN 配置禁止的请求方法。如果 CDN 收到使用被禁止请求方法的用户请求，会拒绝请求并响应 405 状态码。 |
|[下载限速](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-data-rate-throttling-cn) |对请求配置数据传输速度的上限。您还可以指定该特性的启用时间段。 |
|[自定义拦截规则](https://docs.byteplus.com/en/docs/byteplus-cdn/custom-restrictions_cn) |基于请求路径、查询参数和客户端 IP 地址对请求过滤，仅允许符合条件的用户请求。 |
