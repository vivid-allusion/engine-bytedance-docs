BytePlus CDN 是一个具有超过 3500 个缓存节点的内容分发网络，这些节点战略性地分布在各个地理位置。CDN 拥有超过 150 Tbps 的带宽容量，能够在接近终端用户的缓存节点缓存内容。缓存节点的这种战略性位置在降低延迟方面起着至关重要的作用，确保更快的内容分发，而从显著提高网站性能和用户体验。

CDN 旨在提供加速和更可靠的网页内容分发，有效缩短数据源与终端用户之间的距离。这种网络架构对于加快网站加载时间、提高视频流质量和减少文件下载时间至关重要。这些功能对于应对现代数据密集型在线环境的需求至关重要。

## 工作原理

当您的域名接入 CDN 后，CDN 会负责处理用户请求。如果请求的文件未被 CDN 缓存，CDN 会先向源站请求该文件。当收到来自源站的文件后，CDN 会缓存该文件。之后，如果收到了该文件的后续请求，CDN 不再向源站请求该文件，而是将缓存中的文件返回给用户。这降低了源站服务器的流量，从而降低了服务器托管的带宽成本和服务器故障概率。

假设用户请求您站点上的一个文件。文件的 URL 是 `https://www.example.com/file`。请求的过程如下：

1. 用户在浏览器的地址栏中输入 `https://www.example.com/file`。

2. 基于对 `www.example.com` 的 DNS 解析，浏览器获得一个 CDN 缓存节点的 IP 地址。该缓存节点离用户最近。

3. 浏览器向该缓存节点请求该文件。

   > **说明**

   * > 如果该缓存节点还未缓存请求的文件，CDN 会先向源站请求该文件。当收到来自源站的文件后，CDN 会缓存该文件。

4. CDN 将缓存的文件发送给用户。

## CDN 的优势

CDN 的优势包括：

* **改善用户体验**

   CDN 支持包括 HTTP/HTTPS 和 QUIC 在内的现代协议，并利用自主开发的缓存软件提升站点内容分发的性能。基于其多级缓存架构，CDN 能更快地交付大文件、静态图像和流媒体等数据。

* **高灵活性和稳定性能**

   凭借自主开发的资源规划系统和实时资源调度与分配系统，它可以智能稳定地分配用户请求并提供内容。

* **速度与安全的完美平衡**

   CDN 使用 HTTPS 实现端到端数据加密，确保数据安全传输，并保护您的网站免受盗链和会话劫持的威胁。它允许您通过提供 Referer 黑名单和白名单、IP 黑名单和白名单以及 URL 鉴权来配置访问控制。

* **多维度监控**

   CDN 与监控紧密集成，提供详细的数据传输、带宽和每日/每周/每月请求的指标。

* **支持动态资源的传输加速**

   对于动态资源，CDN 基于路径探测技术，选择最佳路径将请求转发到源站，为客户端快速获取动态资源。
