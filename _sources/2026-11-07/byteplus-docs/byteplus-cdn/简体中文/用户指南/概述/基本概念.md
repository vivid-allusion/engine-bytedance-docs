本文档列出了 BytePlus CDN 中的基本概念。


* **缓存命中**：当客户端请求的内容在缓存中时发生。

* **缓存未命中**：当客户端请求的内容不在缓存中时发生。

* **缓存节点**：CDN 存储源站内容副本的那些节点，以减少源站的流量并加快内容分发。在 CDN 架构中，缓存节点分为两级：靠近用户的边缘节点和靠近源站的回源节点。

* **CNAME**：CNAME 记录是域名系统中的一种资源记录类型。它将一个域名映射到另一个域名。

* **DNS（域名系统）** ：DNS 将域名（例如，www.byteplus.com）转换为特定的 IP 地址（例如，223.119.248.49）。

* **命中率**：通过将缓存命中的次数除以缓存命中和未命中的总次数来计算。它衡量缓存在满足内容请求方面的有效性。

* **回源**：数据从源站服务器传输到缓存节点的过程。

* **源站服务器**：运行一个或多个程序的计算机，这些程序旨在监听和响应传入的请求。在 CDN 中，源站服务器就是您的站点。

* **TTL（生存时间）** ：数据在缓存节点上存储的时间。之后，数据将被丢弃或更新。
