本文档介绍 BytePlus CDN 提供的远程鉴权功能。

<span id="远程鉴权概述"></span>
## 远程鉴权概述

如果您的站点有专属的鉴权服务器对用户请求进行鉴权，您可以在 CDN 中配置远程鉴权。

远程鉴权的流程如下：


1. 用户向您的站点发送请求。请求中包含一个鉴权参数。

2. 在收到用户请求后，CDN 将用户请求转发到鉴权服务器。

3. 鉴权服务器对用户请求进行鉴权，并将鉴权结果返回给 CDN。

4. CDN 根据鉴权结果，将用户请求的内容发送给用户或者拒绝用户请求。


<span id="远程鉴权与-url-鉴权的区别"></span>
## 远程鉴权与 URL 鉴权的区别

URL 鉴权：鉴权是由 CDN 执行的。

远程鉴权：鉴权是由鉴权服务器执行的。CDN 将请求转发到鉴权服务器获取鉴权结果。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **远程鉴权** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 设置 **状态** 为 **开启**。

3. 配置以下标签页上的设置。

   * [鉴权规则](https://docs.byteplus.com/en/docs/18/6935#%E9%89%B4%E6%9D%83%E8%A7%84%E5%88%99)

   * [鉴权请求参数](https://docs.byteplus.com/en/docs/18/6935#%E9%89%B4%E6%9D%83%E8%AF%B7%E6%B1%82%E5%8F%82%E6%95%B0)

   * [鉴权请求头](https://docs.byteplus.com/en/docs/18/6935#%E9%89%B4%E6%9D%83%E8%AF%B7%E6%B1%82%E5%A4%B4)

   * [鉴权结果](https://docs.byteplus.com/en/docs/18/6935#%E9%89%B4%E6%9D%83%E7%BB%93%E6%9E%9C)

4. 配置完成后，点击 **保存**。


<span id="鉴权规则"></span>
### 鉴权规则

在该标签页上，您可以添加一个或者多个规则。您最多可以添加 50 个规则。当 CDN 收到一个用户请求时，会根据规则的出现顺序依次将规则与请求相匹配。如果一个规则匹配了请求，该请求就会进入远程鉴权的流程。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如果您需要对所有请求进行鉴权，可以添加一条规则并指定以下配置：</div>



* <div data-tips="true" data-tips-type="tip">设置 <strong>规则类型</strong> 是 <strong>目录匹配</strong>。</div>


* <div data-tips="true" data-tips-type="tip">设置 <strong>规则</strong> 是 <strong>/</strong>。</div>



<span id="配置说明"></span>
#### 配置说明


|**配置** |**说明** |
|---|---|
|规则类型 |表示规则的匹配条件。CDN 将匹配的请求发送到鉴权服务器进行认证。该配置有以下选项：<br><br><br>* **文件后缀**：表示规则用于匹配指定扩展名的文件的请求。<br><br>* **文件目录**：表示规则用于匹配指定目录下文件的请求。<br><br>* **URL 全路径**：表示规则用于匹配指定文件的请求。 |
|是否匹配 |表示规则匹配的方式。该配置有以下选项：<br><br><br>* **匹配**：表示匹配规则的请求需要被鉴权。<br><br>* **不匹配**：表示不匹配规则的请求需要被鉴权。<br><br><br>需要留意的是，如果您添加了多条规则，这些规则需要设置为相同的匹配方式。 |
|规则 |表示规则的内容，长度不能超过 1,024 个字符，不能包含以下字符：<br><br><br>* 连续斜杠（//）、空格、美元符号（$）、问号（?）、Delete（ASCII code 127）。<br><br><br>同时，<br><br><br>* 如果规则类型是 **文件后缀**，规则内容必须是一个或者多个以分号（;）分隔的文件后缀。文件后缀无需以句点（.）开头。例如：`png;txt`。<br><br>* 如果规则类型是 **文件目录**，规则内容必须是一个或者多个以分号（;）分隔的目录路径。目录路径必须以斜杠（/）开头和结尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果规则类型是 **URL 全路径**，规则内容必须是一个或者多个以分号（;）分隔的文件路径。文件路径必须以斜杠（/）开头，可以包含星号（\*）用来表示一个或者多个字符。例如：`/chs/foods/local*sets;/us/birds/chickadee`。 |

<span id="鉴权结果"></span>
### 鉴权结果

在该标签页上，您指定 CDN 是如何处理鉴权服务器返回的鉴权结果的。

在截图所展示的配置中，缓存key 中指定的字段是 `URI` 和 `client_ip`。该配置表示 CDN 基于用户请求的以下属性对鉴权结果进行缓存：


* 请求来自的 IP 地址

* 请求的 URL


这样，之后对于来自相同 IP 地址的请求，如果请求 URL 是相同的，CDN 会使用缓存的鉴权结果。

<span id="配置说明"></span>
#### 配置说明


|**配置** |**说明** |
|---|---|
|鉴权成功响应码 |表示从鉴权服务器返回的状态码中，哪些被认为是鉴权成功。默认值是 200。<br><br>&nbsp;<br><br>您可以输入范围在 200\-299 中的一个或者多个状态码。多个状态码使用分号（;）分隔。您也可以输入 2xx 表示 200\-299 范围中的任意一个状态码。 |
|认证失败响应码 |表示从鉴权服务器返回的状态码中，哪些被认为是鉴权失败。默认值是 401。<br><br>&nbsp;<br><br>您可以输入范围在 400\-499 中的一个或者多个状态码。多个状态码使用分号（;）分隔。您也可以输入 4xx 表示 400\-499 范围中的任意一个状态码。 |
|其他状态码的操作 |该配置表示在满足以下所有条件时，CDN 对用户请求的处理方式。<br><br><br>* 鉴权服务器返回的状态码不是您指定的表示鉴权成功的状态码。<br><br>* 鉴权服务器返回的状态码不是您指定的表示鉴权失败的状态码。<br><br><br>该配置有以下选项：<br><br><br>* **默认放行**：表示 CDN 认为鉴权成功，并将请求的文件返回给用户。<br><br>* **默认拦截**：表示 CDN 认为鉴权失败，拒绝该用户请求。 |
|缓存鉴权响应 |表示 CDN 是否缓存鉴权结果。鉴权结果也就是鉴权服务器返回的鉴权状态码。默认是 **不缓存**。<br><br>&nbsp;<br><br>在开启该配置后，对于收到的用户请求，CDN 会检测该请求的鉴权状态码是否已被缓存。如果鉴权状态码已被缓存，CDN 则使用该鉴权状态码来确定是否将请求的文件发送给用户。<br><br>&nbsp;<br><br>该配置可以提升鉴权效率。 |
|缓存过期时间 |表示鉴权状态码的缓存时间，单位是秒。该配置仅在 **缓存鉴权响应** 为 **缓存** 的情况下才出现。您可以输入范围在 1\-86400 之间的一个值。86,400 秒表示 24 小时。 |
|缓存键值 |表示缓存的鉴权状态码中所包含的字段。每个缓存的鉴权状态码都有一个唯一的缓存键。该配置仅在 **缓存鉴权响应** 为 **缓存** 的情况下才出现。<br><br>&nbsp;<br><br>当收到一个请求时，CDN 尝试将请求与缓存中每个鉴权状态码的缓存键相匹配。如果找到了匹配，CDN 就使用该缓存的鉴权状态码。<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning"><strong>缓存键值</strong> 中必须包含 <code>URI</code> 这个字段。</div><br><br><br>**例子**<br><br>您在缓存该配置中指定的字段是 `URI` 和 `client_ip`。该配置表示 CDN 基于用户请求中的以下对象对鉴权结果进行缓存：<br><br><br>* 请求来自的 IP 地址<br><br>* 请求的 URL<br><br><br>这样，之后对于来自相同 IP 地址的请求，如果请求 URL 是相同的，CDN 会使用缓存的鉴权结果。 |
|鉴权失败的 CDN 响应码 |表示鉴权失败时，CDN 响应用户请求的状态码。默认的状态码是 403。<br><br>&nbsp;<br><br>您可以输入范围在 400\-499 中的任意一个状态码。 |
|鉴权请求超时 |表示鉴权请求的超时时间，单位是毫秒，默认值是 200。您可以输入的超时时间的范围是 200\-3600。 |
|异常执行策略 |该配置表示鉴权异常发生时，CDN 处理鉴权的方式。<br><br>该配置有以下选项：<br><br><br>* **默认放行**：表示 CDN 认为用户请求鉴权成功，并将请求的文件返回给用户。<br><br>* **默认拦截**：表示 CDN 认为用户请求鉴权失败，拒绝该用户请求。<br><br><br>鉴权异常包括，但不限于，以下情况：<br><br><br>* 鉴权请求超时。<br><br>* 鉴权服务器拒绝了鉴权请求。<br><br>* CDN 无法与鉴权服务器建立连接。 |
