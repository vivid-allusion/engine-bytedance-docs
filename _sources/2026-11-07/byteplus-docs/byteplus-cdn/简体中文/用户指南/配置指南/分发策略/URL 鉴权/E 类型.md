<span id="类型特点"></span>
## 类型特点

E 类型通过两个查询参数分别传递签名和时间戳，并允许选择参与签名计算的字段及其拼接顺序。适用于需要将请求参数、请求头部或客户端信息纳入签名的场景。

<span id="上线建议"></span>
## 上线建议

建议先规划独立测试文件或目录，验证客户端或签名服务器及 CDN 配置后，再在生效对象中配置正式业务中需要鉴权的资源范围，避免配置错误影响全部资源访问。

<span id="配置生效对象"></span>
## 配置生效对象

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8b0b86b5f3754c25a45d25b825811cf7~tplv-goo7wpa0wc-topic.webp) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ad28efbd7d374521938f3af8ca18acd4~tplv-goo7wpa0wc-topic.webp) </span>

开启 **URL 鉴权** 并选择 **E 类型**，然后在 **生效对象** 标签页配置。默认包含一条**文件目录**为 `/` 的规则，不能删除。您可以修改该规则的类型和内容，也可以新增规则，最多配置 10 条；多条规则可按 **或**（默认，命中任一条件）或 **且**（同时命中全部条件）组合。仅命中生效对象的请求需要鉴权。


|支持范围 |输入格式 |
|---|---|
|文件后缀 |一个或多个后缀，以分号（`;`）分隔，不带句点。例如：`png;txt`。 |
|文件目录 |一个或多个目录，以分号分隔；每项以 `/` 开头和结尾。例如：`/video/;/image/`。 |
|文件全路径 |一个或多个路径，以分号（`;`）分隔；每项以 `/` 开头，可使用 `*` 匹配一个或多个字符，包括 `/`。例如：`/video/*;/image/logo.png`。 |
|全路径正则 |一个或多个正则表达式，以分号分隔。使用前需[提交工单](https://console.byteplus.com/workorder/create)开通。 |


非正则规则不区分大小写；全路径正则区分大小写。单个条件的匹配值总长度不超过 1,024 个字符，且不能包含 `//`、空格、`$` 或 `?`。

<span id="配置鉴权"></span>
## 配置鉴权

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7647e689385b4998ba800dd34b6d7e6b~tplv-goo7wpa0wc-topic.webp) </span>

在 **鉴权配置** 标签页配置以下参数。

<span id="基础参数"></span>
### 基础参数


|配置项 |说明 |
|---|---|
|主 Key |必填，长度为 1–120 个字符，仅支持英文字母、数字和英文半角符号；不支持空格、中文或全角字符。客户端或签名服务器使用主 Key 生成签名；CDN 使用主 Key 按相同规则计算签名，并与请求中的签名比对。 |
|备 KEY |可选。当 CDN 使用主 Key 计算的签名与请求中的签名不一致时，使用备 KEY 按相同规则再次计算并比对；输入要求与主 Key 相同。可用于平滑轮换 Key。 |
|签名有效时间 |单位为秒，默认 `1800`，范围为 0–315,360,000。CDN 在 `timestamp + 有效时间 < 收到请求的时间` 时判定 URL 过期。 |
|鉴权算法 |MD5 或 SHA256，默认 MD5。客户端或签名服务器必须与 CDN 配置保持一致。 |


<span id="签名字段"></span>
### 签名字段


|配置项 |说明 |
|---|---|
|签名参数名 |承载签名，默认 `sign`，不能与时间参数名相同。区分大小写，长度为 1–100 个字符，可包含字母、数字、`_`、`-`、`.`、`,`、`!`，且至少包含一个字母。 |
|时间参数名 |默认 `t`，不能与签名参数名相同。区分大小写，长度为 1–100 个字符，可含字母、数字、`_`、`-`、`.`、`,`、`!`。 |
|时间戳进制 |十进制或十六进制 Unix 时间戳，精确到秒。 |
|签名计算规则 |必须包含 Key、`uri` 和时间戳参数；可另添加请求参数、请求头部、客户端信息和自定义变量，并调整全部字段的拼接顺序。 |
|自定义变量 |最多 50 个，类型为请求参数或请求头部，取值方式为精确匹配，变量名最长 100 个字符。请求参数名可含字母、数字、`-`、`,`、`.`、`!`；请求头名称不能含空格、双引号或冒号。 |


可选计算字段包括 `Referer`、客户端域名、`Origin`、客户端 IP、`User-Agent` 和自定义变量。客户端或签名服务器必须使用与 CDN 配置完全相同的字段值和顺序。保存配置前，可按需启用 **去除鉴权参数缓存和回源**。

<span id="m3u8-改写"></span>
## M3U8 改写

E 类型支持 **M3U8 改写**。启用后，CDN 会使用 E 类型的签名计算方式为播放列表中的资源 URI 添加签名，以支持 HLS 播放。客户端或签名服务器只需为 `.m3u8` 请求生成签名。

<span id="改写条件"></span>
### 改写条件

启用后，M3U8 改写仅在以下条件同时满足时生效：


* **生效对象**的**文件后缀**包含 `m3u8`，以及播放列表中需要通过 URL 鉴权访问的资源后缀。例如，播放列表引用 `.ts` 分片以及 `.mp4` 文件时，在 **生效对象**的**文件后缀**中配置 `m3u8;ts;mp4`。播放列表中的资源 URI 只要文件后缀命中，CDN 就会执行 URL 鉴权；即使资源 URI 不匹配目录、文件全路径或全路径正则等其他条件，CDN 仍会执行 URL 鉴权。

* 源站返回的 `.m3u8` 响应不包含 `Content-Encoding`，且 `.m3u8` 请求不命中 **智能压缩**的生效条件，因为 CDN 不会改写经压缩的 M3U8。

* 签名计算规则包含请求头部时，播放列表中的资源请求也必须携带对应请求头，且值与 `.m3u8` 请求一致；字段缺失或值不一致时，资源请求的签名校验会失败。


播放列表中的资源 URI 可以是完整 URL、以 `/` 开头的路径或相对路径。资源 URI 为相对路径时，改写后仍为相对路径。

例如，播放列表路径为 `/e-basic-m3u8-rewrite-test/playlist.m3u8`，资源 URI 为 `segment-1.ts` 时，改写后为 `segment-1.ts?<签名参数名>=<SIGNATURE>&<时间参数名>=<timestamp>`。

<span id="配置改写参数"></span>
### 配置改写参数


|配置项 |说明 |
|---|---|
|分片 URI 原参数 |控制是否保留播放列表中资源 URI 原有的查询参数。 |
|继承 M3U8 非签名参数 |控制是否将 `.m3u8` 请求 URL 中除签名和时间戳参数外的查询参数添加到播放列表中的资源 URI。签名计算规则包含请求参数时，该项保持开启且无法关闭。 |
|M3U8 标签改写 |默认情况下，CDN 仅改写 `EXTINF` 标签下的资源 URI。启用后，可指定需要改写其下资源 URI 的额外标签。播放列表必须包含 `EXTINF` 标签；否则 CDN 不会改写已指定其他标签下的资源 URI。自定义标签最多 20 个，每个长度为 1–100 个字符，且不能包含 `#` 或 `:`。 |


**分片 URI 原参数**和**继承 M3U8 非签名参数**共同决定改写后资源 URI 的查询参数。例如，资源 URI 为 `/video.ts?version=1`，设置为删除原参数并开启继承，且 `.m3u8` 请求 URL 包含 `q_m3u8=cool` 时，改写后的资源 URI 为 `/video.ts?q_m3u8=cool&<签名参数名>=<SIGNATURE>&<时间参数名>=<timestamp>`。如果设置为保留原参数，改写后的资源 URI 为 `/video.ts?version=1&q_m3u8=cool&<签名参数名>=<SIGNATURE>&<时间参数名>=<timestamp>`。

<span id="构造签名-url"></span>
## 构造签名 URL

<span id="url-格式"></span>
### URL 格式

```text
scheme://host<uri>?<签名参数名>=<SIGNATURE>&<时间参数名>=<timestamp>[&...]
```


`sign` 和 `t` 为默认名称；修改后，URL 必须使用修改后的名称。

<span id="签名计算公式"></span>
### 签名计算公式

```text
MD5:    md5(<自定义签名计算规则>)
SHA256: sha256(<自定义签名计算规则>)
```


`<自定义签名计算规则>` 是按 CDN 配置的顺序直接拼接各字段实际值的字符串，不自动添加分隔符。例如，规则依次为 Key、`uri`、时间戳参数时：

```text
key + uri + timestamp
```


`+` 仅表示拼接，不是实际字符。`uri` 为不含查询参数、以 `/` 开头的请求路径；含中文时使用实际发送的编码后路径。

<span id="参数说明"></span>
### 参数说明


|参数 |说明 |
|---|---|
|`key` |主 Key 或备 KEY，仅参与签名计算。 |
|`uri` |请求路径，不含域名和查询参数。 |
|`timestamp` |URL 中的十进制或十六进制 Unix 时间戳，格式与 CDN 配置一致。 |
|`SIGNATURE` |对自定义签名计算规则所得字符串计算的哈希值；使用 MD5 时为 32 个十六进制字符，使用 SHA256 时为 64 个十六进制字符。 |


示例：

```text
https://www.example.com/product/cdn?sign=e954e253c33634b510443af72406600f&t=1620291453&query1=value1
```


实际 `SIGNATURE` 取决于已配置的签名计算规则。

<span id="缓存和回源"></span>
## 缓存和回源

默认情况下，CDN 将 E 类型的签名和时间参数计入缓存键，并在回源请求中保留这两个参数。您可以在 URL 鉴权配置中通过 **去除鉴权参数缓存和回源** 设置缓存键和回源请求是否包含这两个参数。

<span id="验证"></span>
## 验证


1. 保存后，使用 **鉴权计算器** 选择 E 类型，输入当前域名下未带签名、且命中生效对象的完整原始 URL。

2. 输入已配置的参与字段、字段值、拼接顺序、Key、签名参数名、时间参数名、开始时间、有效时间、时间戳进制和算法，生成未过期 URL；开始时间用于生成 `timestamp`。签名计算规则包含自定义请求参数时，原始 URL 中不能包含任何自定义请求参数；在自定义变量中输入各参数的名称和值，鉴权计算器会将这些参数追加到生成的 URL。配置备 KEY 时，同时验证使用备 KEY 生成的 URL。

3. 使用客户端或签名服务器生成 URL，并与 **鉴权计算器** 的结果比对。参与字段、字段值、拼接顺序、`uri`、`timestamp`、Key 和算法必须与计算器设置一致；有效时间不参与签名计算。

4. 请求测试文件，确认可访问；分别使用篡改 `SIGNATURE` 的请求、过期 URL 请求，以及使用与 CDN 配置不一致的字段值或拼接顺序生成签名的 URL，均应返回 403。

5. 分别设置回源请求保留和不保留签名、时间参数，确认源站收到的请求符合预期；如果已在缓存键特性中排除这两个查询参数，确认缓存键符合预期。

6. 使用 HLS 时，确认播放列表中的资源 URI 已被签名，且相关资源可访问。

7. 如果签名计算规则包含请求头部，确认播放列表和资源请求均携带相同的请求头值；如果包含自定义请求参数，确认鉴权计算器生成的 URL 和改写后的资源 URI 均包含相同的参数值。

<span id="cdn-校验规则"></span>
## CDN 校验规则


* 比对签名时，CDN 会将计算结果和请求中的 `SIGNATURE` 转为小写。

* 缺少或格式错误的签名、签名不一致、签名过期均返回 403。


<span id="上线和回滚"></span>
## 上线和回滚

首次上线时，先只将生效对象覆盖测试文件或目录，验证客户端或签名服务器、CDN 配置、时间同步、缓存回源和 HLS 播放后，再逐步扩大范围。

轮换 Key 时，先将新 Key 配置为备 KEY，并让客户端或签名服务器使用新 Key 生成签名进行验证；随后将新 Key 升为主 Key、旧 Key 暂留为备 KEY，待旧 URL 全部过期后移除旧 Key。若出现大量非预期 403，立即缩小或删除生效对象；必要时关闭 URL 鉴权并保存，使未签名请求恢复访问。
