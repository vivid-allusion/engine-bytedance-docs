本文档介绍 BytePlus CDN 中的 "回源请求头设置" 特性。

在回源请求中，CDN 会包含用户请求中的所有请求头。同时，CDN 还会添加一些默认请求头。参见 [CDN 添加的默认头部列表](https://docs.byteplus.com/en/docs/18/6959#cdn-%E6%B7%BB%E5%8A%A0%E7%9A%84%E9%BB%98%E8%AE%A4%E5%A4%B4%E9%83%A8%E5%88%97%E8%A1%A8)。

除了 CDN 添加的默认请求头，如果您希望回源请求中包含更多的头部，您可以配置回源请求头。

<span id="适用场景"></span>
## 适用场景

**识别来自 CDN 的请求**

您的源站除了收到来自 CDN 的请求，也有可能收到来自其他请求方的请求。或者您的源站使用了多个云厂商的 CDN 做内容传输加速。在这些情况下，您可以在回源请求中添加一个特定的请求头。在源站的请求日志中，您可以基于该请求头统计以下数据：


* 请求方不是 CDN 的请求数量。

* 在多个云厂商中，来自 BytePlus CDN 的请求数量。


**区分来自不同域名的请求**

在 CDN 中，您为多个域名配置了相同的源站。这些域名有不同的配置，针对不同的使用场景。在这个情况下，您可以在回源请求中添加一个特定的请求头，以区分来自不同域名的请求。在源站的请求日志中，您可以基于该请求头统计数据。

**在源站实施访问控制**

您希望阻止来源不是 CDN 的用户请求。在这个情况下，您可以在回源请求中添加一个特定的请求头，然后在源站实施访问控制，阻止不包含该请求头的请求访问您的源站。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **HTTP 请求头设置** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 点击 **添加规则**。

   您最多可以添加 50 条规则。

3. 参照以下配置说明。

4. 配置完成后，点击 **保存**。

<span id="配置说明"></span>
## 配置说明


|**配置** |**说明** |
|---|---|
|回源请求头操作 |表示一个操作类型。该配置有以下选项：<br><br><br>* **设置**：表示设置一个头部。设置操作包括添加与修改。如果源站响应中已包含该头部，该头部的值会被覆盖。如果源站响应中没有包含该头部，该头部会被添加。<br><br>* **删除**：表示删除一个头部。 |
|请求头名称 |表示需要设置或者删除的一个头部。头部名称是大小写不敏感的。除了 [注意事项](https://docs.byteplus.com/en/docs/18/6959#%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9) 中列出的那些头部名称之外，您可以输入任意一个头部名称。头部名称不能超过 1,024 个字符，不能包含以下字符：<br><br><br>* 汉字、下划线（_）、空格、双引号（"）、冒号（:） |
|取值方式 |对于您在 **请求头名称** 中指定头部，该配置表示该头部值的类型，有以下选项：<br><br><br>* **常量值**：表示该头部值为一个字符串。<br><br>* **变量**：表示该头部值来自一个变量。<br><br>* **自定义**：表示该头部值是变量与字符串拼接后的一个字符串。 |
|回源请求头的值 |表示您在 **请求头名称** 中指定头部的取值。<br><br><br>* 如果 **取值方式** 是 **常量值**，您需要输入一个字符串。该字符串的长度不能超过 1,024 个字符，不能包含以下字符：<br><br>   * 汉字、下划线（_）、空格、双引号（"）、冒号（:）<br><br>* 如果 **取值方式** 是 **变量**，您需要从列表中选择一个变量。参见 [变量列表](https://docs.byteplus.com/en/docs/18/6959#%E5%8F%98%E9%87%8F%E5%88%97%E8%A1%A8)。<br><br>* 如果 **取值方式** 是 **自定义**，您需要输入由变量和字符串拼接后的一个字符串。变量需要包裹在 `{}` 中，由 `$` 开头。例如 `bind${scheme}to${client_ip}done`。 |


<span id="变量列表"></span>
## 变量列表

CDN 提供了以下变量。


|变量名称 |说明 |示例值 |
|---|---|---|
|uri |表示回源请求 URL 中的路径。 |`/dir/sample.php` |
|request_uri |表示回源请求 URL 中的路径和查询字符串（query string）。 |`/dir/sample.php?color=red&n=10` |
|http_host |表示回源请求中 Host 头部的值。 |`example.com:8080` |
|args |表示回源请求 URL 中的查询字符串。 |`color=red&n=10` |
|msec |表示 CDN 设置该回源请求头的时间，格式是 Unix 时间戳，精确到毫秒。 |`1704444754.917` |
|scheme |表示回源请求使用的协议。 |`https` |
|origin_srv_addr |表示源站的域名或者 IP 地址。 |`www.example.com` |
|query_string |与 `args` 变量的含义相同。 |`size=small&color=red` |
|host |表示回源请求中 Host 头部的值。<br><br>&nbsp;<br><br>需要留意的是，CDN 在处理请求时可能会修改该头部的值。因此，不建议您使用该头部，而是使用 `http_host`。 |`example.com:8080` |
|client_ip |表示连接到 CDN，触发了本次回源请求的客户端的真实 IP 地址。 |`127.1.1.1` |


<span id="注意事项"></span>
## 注意事项

您设置的请求头名称不能以 `x-bdcdn-` 或者 `X-Bytecdn-` 开头，也不能是以下任意头部。


* x\-tos\-request\-id

* bd\-bdcdn\-oss\-switch

* x\-storagegw\-request\-id

* x\-sign

* host

* X\-Trace\-Via


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">如果用户请求中包含以 <code>x-bdcdn-</code> 或者 <code>X-Bytecdn-</code> 开头的头部，这些头部不会包含在回源请求中。</div>


<span id="cdn-添加的默认头部列表"></span>
## CDN 添加的默认头部列表

CDN 在回源请求中默认添加以下头部。


|请求头 |描述 |示例 |
|---|---|---|
|X\-Forwarded\-For |表示发送回源请求的 CDN 节点的 IP 地址。 |`xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxx`, `xx.xx.xxx.xxx` |
|X\-Forwarded\-Protocol |表示回源请求使用的协议。 |`http` |
|X\-Real\-IP |对于触发该回源请求的用户请求，该头部表示发送该用户请求的客户端 IP 地址。 |`xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxx` |
|X\-Forwarded\-Proto |表示用户请求使用的协议。 |`http` |
|X\-Client\-Scheme |表示用户请求使用的协议。 |`http` |
|X\-Trace\-via |表示发送回源请求的 CDN 节点的标识。 |`gycm` |
|Bd\-Raw\-Host |表示用户请求的 URL 中的域名。 |`www.example.com` |
|X\-Bdcache\-Trace\-Id |表示用户请求的 ID。 |`f455f0415d901f8aee3b2c7336bfad16` |
|X\-Tt\-Trace\-Id |表示回源请求的 ID。 |`202405301714110101720050051BB69184` |
