在 CDN 中添加域名后，您需要指定内容的来源。当收到用户请求时，如果请求的文件尚未被 CDN 缓存，CDN 会向源站请求文件并进行缓存。

本文档介绍如何在 CDN 中配置源站。在创建分发策略时，您必须在策略中添加一个主源站。CDN 支持的源站类型包括 IP 地址、域名和对象存储桶。您可以配置多个源站，并为每个源站设置权重，以实现源站间的负载均衡。同时，为了保证回源的成功率，CDN 支持配置主备源站。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **源站配置** 标签页。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 点击 **新增源站** 添加一个源站配置。

   您至少添加一个主源站，备源站是可选的。

3. 参照以下配置说明对源站进行配置。

   * 如果源站的类型 **源站 IP** 或 **源站域名**，参考 [源站配置说明（类型是 "源站 IP" 和 "源站域名"）](https://docs.byteplus.com/en/docs/18/6923#ip-domain)。

   * 如果源站的类型 **对象存储源站**，参考 [源站配置说明（类型是 "对象存储源站"）](https://docs.byteplus.com/en/docs/18/6923#46d92e6c)。

4. 配置完成后，在页面右下方点击 **保存**。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">关于主源站和备源站之间的切换逻辑，参见 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/origin_retry-cn">回源重试</a>。</div>


* <div data-tips="true" data-tips-type="tip">回源时，CDN 使用的请求方法与用户请求使用的相同。默认情况下，CDN 支持的请求方法有 DELETE、GET、HEAD、POST、PUT、PATCH、CONNECT、OPTIONS。您可以在 "<a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-disallowed-http-method-cn">禁用 HTTP 方法</a>" 中配置 CDN 不允许的请求方法。例如，为了避免用户误删源站上的文件，您可以禁用 DELETE 方法。</div>


* <div data-tips="true" data-tips-type="tip">对于第三方对象存储桶源站，为了避免用户对存储桶进行误操作，建议您执行以下操作：</div>


   * <div data-tips="true" data-tips-type="tip">在提供对象存储服务的云厂商处，对相应的账号设置权限，以防止非预期操作。</div>

## 源站配置说明（类型是 "源站 IP" 和 "源站域名"）

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_448f3a62fc5c35615b26c73cf04e4734.png) </span>


|**配置** |**说明** |
|---|---|
|回源地址 |表示一个或者多个源站地址。多个地址使用分号（;）或者换行分隔。该配置的描述如下：：<br><br><br>* 当 **源站类型** 为 **源站 IP** 时，您可以输入 IPv4 和 IPv6 地址。<br><br>* 当 **源站类型** 为 **源站域名** 时，您输入的域名不能是泛域名。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">一个域名下，所有主源站的地址加上所有备源站的地址的总数不能超过 50 个。</div><br> |
|权重 |表示源站的权重，范围是 1\-100，默认值是 1。在 CDN 回源时，权重越高的源站被选中的概率也越高。例如您定义了两个主源站，权重分别为 3 和 2。权重为 3 的源站被选中的概率为 60%。 |
|HTTP 端口 |表示 CDN 使用 HTTP 协议回源时访问的源站端口，取值范围是 1\-65535，默认值是 `80`。如果源站不接受 HTTP 请求，对于该配置您保留默认值即可。参见下方 **端口配置的额外说明**。 |
|HTTPS 端口 |表示 CDN 使用 HTTPS 协议回源时访问的源站端口。该配置的取值范围是 1\-65535，默认值是 `443`。如果源站不接受 HTTPS 请求，对于该配置您保留默认值即可。参见下方 **端口配置的额外说明**。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip"><strong>端口配置的额外说明</strong></div>


<div data-tips="true" data-tips-type="tip">对于您设置的端口，您可以通过如下方式检测源站是否已开通了该端口。</div>



* <div data-tips="true" data-tips-type="tip">Windows：在命令提示符窗口中，运行命令 <code>telnet <IP/domain> <port></code></div>


   <div data-tips="true" data-tips-type="tip">如果 Telnet 命令行窗口打开了，则表示源站支持配置的协议和端口。   </div>
   

* <div data-tips="true" data-tips-type="tip">macOS 和 Linux：在 Terminal 窗口中，运行命令 <code>nc -vz -w 2 <IP/domain> <port></code></div>


   <div data-tips="true" data-tips-type="tip">如果命令返回 <code>Connection succeeded!</code>，则表示源站支持配置的协议和端口。   </div>

* <div data-tips="true" data-tips-type="tip">如果存储桶来自中国内地的第三方云厂商，请关注云厂商的相关声明。当用户使用默认桶域名访问存储桶时，云厂商的默认行为可能是：</div>


   * <div data-tips="true" data-tips-type="tip">对于特定扩展名的文件，云厂商会在响应中添加 <code>Content-Disposition: attachment</code> 头部，强制浏览器下载文件。</div>

      <div data-tips="true" data-tips-type="tip">为了让用户可以在浏览器中预览文件以及下载 APK 和 IPA 文件，您需要在云厂商的对象存储服务中创建自定义域名，然后遵循 <a href="https://docs.byteplus.com/en/docs/18/6923#8fd2d9ba">场景三中的配置步骤</a>。      </div>

### 场景一：存储桶来自 BytePlus

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如存在以下任意情况，请遵循 <a href="https://docs.byteplus.com/en/docs/18/6923#8fd2d9ba">场景三中的配置步骤</a>。</div>
