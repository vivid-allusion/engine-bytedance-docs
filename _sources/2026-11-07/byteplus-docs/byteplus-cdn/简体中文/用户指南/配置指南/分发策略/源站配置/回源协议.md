本文档介绍如何配置 CDN 访问源站时使用的协议。

回源协议配置始终启用，无法关闭，您必须完成配置。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **源站配置** 标签页。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 定位 **回源协议**。

3. 选择回源请求使用的协议。配置项说明参见 [配置说明](https://docs.byteplus.com/en/docs/18/117648#%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E)。

4. 配置完成后，在页面右下方点击 **保存**。

<span id="配置说明"></span>
## 配置说明


|配置 |说明 |
|---|---|
|回源方式 |选择回源请求使用的协议。该配置有以下选项：<br><br>&nbsp;<br><br>\* **协议跟随**：回源请求使用与用户请求相同的协议。<br><br>\* **HTTP**：回源请求始终使用 HTTP 协议。<br><br>\* **HTTPS**：回源请求始终使用 HTTPS 协议。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您配置的回源协议以及相应的源站端口必须是源站支持的。例如，您选择 <strong>HTTP</strong>，并在配置源站时将 HTTP 端口设置为 <code>8080</code>，则源站必须能够通过 <code>8080</code> 端口接收 HTTP 请求。否则，回源请求会失败。</div>
