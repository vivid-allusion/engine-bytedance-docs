本文档介绍 BytePlus CDN 中的 "自定义拦截" 功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">要使用该功能，请 <a href="https://console.byteplus.com/workorder/create">提交工单</a>。</div>


该功能使您可以对用户请求中的路径、请求中的查询参数、请求来自的的客户端 IP 地址设置匹配条件，并对符合匹配条件的请求设置 CDN 处理这些请求的方式。

<span id="功能优先级"></span>
## 功能优先级

CDN 提供的一系列访问控制功能有不同的优先级。在 CDN 处理用户请求时，这些功能按优先级对请求生效。参见 [访问控制功能的优先级](https://docs.byteplus.com/en/docs/byteplus-cdn/access-restrictions-priority_cn)。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **自定义拦截规则** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 设置 **状态** 为开启。

3. 点击 **添加规则**，然后参照 [配置说明](https://docs.byteplus.com/en/docs/18/36365#%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E) 对规则进行设置。您最多可以创建 10 条规则。

4. 配置完成后，点击 **保存**。

<span id="配置说明"></span>
## 配置说明

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">关于以下配置的内容输入要求，参见 <a href="https://docs.byteplus.com/en/docs/18/36365#%E9%85%8D%E7%BD%AE%E8%BE%93%E5%85%A5%E8%A6%81%E6%B1%82">配置输入要求</a>。</div>



|**配置** |**说明** |
|---|---|
|规则名称 |表示规则的名称。 |
|生效对象 |表示一个或者多个匹配条件，用于对请求进行匹配。点击 **添加** 创建一个匹配条件，您最多可以创建 5 个匹配条件。如果您不添加任何匹配条件，表示所有请求都匹配这条规则。<br><br>&nbsp;<br><br>在每个匹配条件中，您需要设置匹配类型、对比类型和匹配值。匹配值可以是多个。如果 **匹配类型** 是 **客户端 UA**，多个匹配值之间以竖线（\|）分隔。如果 **匹配类型** 不是 **客户端 UA**，多个匹配值之间以分号（;）分隔。多个匹配值之间的关系是 "或"。<br><br>&nbsp;<br><br>匹配类型的说明如下：<br><br><br>* **文件全路径**：表示请求 URL 中的路径。<br><br>* **文件目录**：表示路径中的一个目录。<br><br>* **文件后缀**：表示路径末尾的扩展名。<br><br>* **全路径正则**：表示请求 URL 中的路径，通过正则表达式匹配。<br><br>* **请求 FullQuery**：表示请求 URL 中的查询字符串。<br><br>* **请求 Query**：表示请求 URL 中的一个查询参数。<br><br>* **客户端 IP**：表示客户端的 IP 地址。<br><br>* **客户端 UA**：表示请求中 User\-Agent 头部。<br><br>* **自定义请求头部**：表示请求中的自定义头部。<br><br><br>如果匹配类型是 **全路径正则** 或 **请求 FullQuery**，匹配值是正则表达式。要使用这两个匹配类型，请 [提交工单](https://console.byteplus.com/workorder/create)。<br><br>&nbsp;<br><br>关于对比类型，需要留意的是：<br><br><br>* **等于、匹配**：表示如果请求匹配任意匹配值，该请求就符合匹配条件。<br><br>* **不等于、不匹配** ：表示如果请求不匹配所有匹配值，该请求才符合匹配条件。<br><br>* **属于/属于全局名单**：仅适用于 **请求 Query**，表示一个类型是 "通用列表" 的全局配置。"通用列表" 用来定义大量匹配值。 |
|拦截方式 |表示 CDN 如何处理符合匹配条件的请求。该配置的可选值有：<br><br><br>* **4xx 错误**：表示 CDN 响应一个 4xx 的错误码。<br><br>* **重定向**：表示 CDN 将请求重定向到另一个 URL。<br><br><br>如果您计划创建多条规则，每条规则中的 **拦截方式** 必须相同。 |


当 **拦截方式** 为 **4xx 错误** 时，您可以设置以下额外配置：


|**配置** |**说明** |
|---|---|
|响应状态码 |表示 CDN 对满足匹配条件的请求的响应状态码。您需要设置一个 400\-499 范围内的错误码，例如 `405`。 |
|响应 Body |表示响应正文中的内容。该配置有以下选项：<br><br><br>* **系统默认**：表示 CDN 使用 4xx 错误码的标准响应正文。<br><br>* **自定义**：表示 CDN 使用一个自定义响应页面。您可以在 **响应页面** 下拉列表中选择一个自定义页面。下拉列表中的页面来自 **全局配置** 页面下的 **自定义响应页面** 标签页。要创建自定义响应页面，请 [提交工单](https://console.byteplus.com/workorder/create)。 |


**拦截方式** 为 **重定向** 时，您可以设置以下额外配置：


|**配置** |**说明** |
|---|---|
|响应状态码 |表示 CDN 对满足匹配条件的请求的响应状态码。您可以设置 **301** 或者 **302**。 |
|Location |表示一个重定向 URL。 |


<span id="规则优先级"></span>
## 规则优先级

规则列表中的规则具有优先级，优先级最高的规则优先生效。对于一个用户请求，如果某条规则与该请求匹配，只有该规则生效，剩余规则不生效。您可以拖动规则来调整规则的优先级。

## 更多信息

<span id="配置输入要求"></span>
### 配置输入要求


|**配置** |**输入要求** |
|---|---|
|规则名称 |长度不超过 20 个字符，可以包含字母、数字、下划线（_）、连字符（\-）、汉字。一个汉字占 3 个字符。 |
|生效对象 |生效对象中，匹配值的输入要求如下：<br><br><br>* 如果匹配类型是 **文件全路径**，每个匹配值表示一个文件路径。每个文件路径必须以斜杠（/）开头。您可以在路径中使用一个或者多个星号（\*），每个星号表示一个或者多个字符。例如：`/www/img/my*image.png`。<br><br>* 如果匹配类型是 **文件目录**，匹配值中的每个目录必须以斜杠（/）开头和结尾。例如：`/www/img/`。<br><br>* 如果匹配类型是 **文件后缀**，匹配值中的每个后缀无需以句点（.）开头。例如：`png;txt`。<br><br>* 如果匹配类型是 **文件全路径**、**文件目录**、**文件后缀**，匹配值的总长度不能超过 1,024 个字符，不能包含以下字符：<br><br>   * 连续斜杠（//）、空格、美元符号（$）、问号（?）、Delete（ASCII code 127）。<br><br>* 如果匹配类型是 **请求 Query**，参数名称和匹配值的有以下要求：<br><br>   * 您只能指定一个参数名称，也只能指定一个参数值作为匹配值。<br><br>   * 参数名称和匹配值的长度都不能超过 256 个字符。<br><br>   * 参数名称和匹配值可以包含数字、字母、百分号（%）、下划线（_）、中划线（\-）。<br><br>* 如果匹配类型是 **客户端 IP**，匹配值有以下要求：<br><br>   * 总长度不能超过 30,000 个字符。<br><br>   * IP 地址的数量不能超过 50 个。<br><br>   * IP 地址可以是 IPv4 地址、IPv4 CIDR 地址、IPv6 地址或 IPv6 CIDR 地址。<br><br>* 如果匹配类型是 **自定义头部** 或 **客户端 UA** 时，匹配值有以下要求：<br><br>   * 总长度不能超过 1,024 个字符。除了开头和结尾，匹配值不能包含 \*。\* 表示一个或者多个任意字符。<br><br>   * 匹配值的数量不能超过 50 个。<br><br>* 如果匹配类型是 **全路径正则** 或 **请求 FullQuery** 时，每个匹配值都是一个正则表达式，总长度不能超过 1,024 个字符。 |
|Location |URL 必须以 `http://` 或 `https://` 开头，长度不能超过 1,024 个字符。 |
