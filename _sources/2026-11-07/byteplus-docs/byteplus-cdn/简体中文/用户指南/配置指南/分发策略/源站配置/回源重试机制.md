当 CDN 向选中的源站发起回源请求失败时，CDN 会按照配置的重试规则再次发起回源请求。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">仅当客户端请求的方法为 <code>POST</code>、<code>HEAD</code> 或 <code>GET</code>，且请求符合<a href="https://docs.byteplus.com/en/docs/18/118659#%E5%9B%9E%E6%BA%90%E5%A4%B1%E8%B4%A5%E7%9A%84%E5%88%A4%E6%96%AD%E4%BE%9D%E6%8D%AE">回源失败的判定条件</a>时，CDN 才会进行回源重试。</div>


<span id="回源重试流程"></span>
## 回源重试流程

回源时，CDN 会根据主源站的权重选择一个主源站处理请求。

如果首次回源失败，CDN 会在主源站范围内重试一次：


* 如果当前主源站是域名，且该域名可解析为多个 IP 地址，CDN 会按照轮询方式，从该域名解析出的其他可用 IP 地址中选择一个重试。

* 在其他情况下，CDN 会根据主源站的权重选择另一个主源站重试。


如果主源站重试仍然失败，且已配置备源站，CDN 会使用备源站重试一次。如果该请求也失败，CDN 将不再发起回源重试。

<span id="源站-ip-地址不可用的判定机制"></span>
### 源站 IP 地址的不可用判定机制

如果 CDN 连续 10 次无法与某个源站 IP 地址建立 TCP 连接，CDN 会将该 IP 地址标记为不可用。

在选择源站的过程中，如果选中的源站 IP 地址已被标记为不可用，CDN 会继续选择其他源站，同时异步探测该 IP 地址。若探测成功建立 TCP 连接，CDN 会将该 IP 地址重新标记为可用。

<span id="回源失败的判断依据"></span>
### 回源失败的判定条件

出现以下任一情况时，CDN 会判定回源请求失败：


* 建立 TCP 连接超时或失败。

* HTTP 请求超时。

* 源站返回 5xx 状态码，或返回您在 `https://docs.byteplus.com/en/docs/byteplus-cdn/origin_retry-cn` 中指定的状态码。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">默认情况下，TCP 建连超时时间为 2 秒，HTTP 请求超时时间为 60 秒。有关如何修改超时时间，参见 <code>https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-request-time-out-cn</code> 。</div>
