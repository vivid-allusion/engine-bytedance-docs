本文介绍如何设置 BytePlus CDN 的回源超时时间。开启回源超时配置后，您可以分别设置 TCP 建连、HTTP 首包和 HTTP 响应正文读取阶段的超时时间。

<span id="回源超时时间"></span>
## 回源超时时间

CDN 节点向源站发起请求时，需要依次建立 TCP 连接、等待源站返回首个响应字节，以及接收响应正文数据。默认超时时间如下：


|配置项 |默认值 |取值范围 |说明 |
|---|---|---|---|
|TCP 超时 |2 秒 |2–60 秒 |CDN 节点向源站建立 TCP 连接的最长等待时间。超过该时间仍未建立连接，则视为建连超时。 |
|HTTP 读取超时 |60 秒 |1–900 秒 |CDN 节点收到源站返回的首个响应字节后，持续未收到后续响应正文数据的最长等待时间。超过该时间，连接将被断开。 |
|HTTP 首包超时 |60 秒 |1–900 秒 |CDN 节点向源站发送 HTTP 请求后，等待源站返回首个响应字节的最长时间。超过该时间仍未收到首个响应字节，连接将被断开。 |


您可以根据网络状况和源站处理能力设置超时时间。设置前，请注意以下事项：


* 超时时间过短时，网络波动或源站处理时间较长可能导致回源请求频繁失败。

* 超时时间过长时，回源请求会长期占用源站连接，影响源站的服务能力。

* `HTTP 首包超时` 适用于源站处理请求耗时较长，无法及时开始返回响应的场景。

* `HTTP 读取超时` 适用于源站开始返回响应后，响应正文传输存在较长间隔的场景。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">说明</div>


<div data-tips="true" data-tips-type="tip">配置的回源超时时间表示 CDN 节点正常服务状态下的理论最大超时时间。当域名出现回源连接突增等异常情况时，CDN 会基于安全策略限制回源连接数量。</div>


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">说明</div>


<div data-tips="true" data-tips-type="tip">回源超时会导致本次回源请求失败。是否重试以及重试次数取决于回源重试配置和请求是否满足重试条件。有关回源重试的说明，参见 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/origin-retry-logic_zh-cn">回源重试机制</a>。</div>


<span id="操作步骤"></span>
## 操作步骤


1. 打开 **回源请求超时** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 在 **回源超时时间设置** 模块中，设置 **状态** 为启用。

3. 设置各项超时时间，单位为秒。

   * 设置 **TCP 超时**，取值范围为 2–60。

   * 设置 **HTTP 读取超时**，取值范围为 1–900。

   * 设置 **HTTP 首包超时**，取值范围为 1–900。

4. 配置完成后，点击 **保存**。
