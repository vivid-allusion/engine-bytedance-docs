本文档描述 BytePlus CDN 中的 "源站响应头设置" 特性。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">要使用该功能，请 <a href="https://console.byteplus.com/workorder/create">提交工单</a>。</div>


CDN 提供了 "源站响应头设置" 的特性。在 CDN 收到源站响应时，会先基于 "源站响应头设置" 更新响应中的响应头，然后再基于更新后的响应头执行相应的操作。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3370b8fec1094d47836abbd77b762c5f~tplv-goo7wpa0wc-topic.webp) </span>

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **源站响应头设置** 页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 在 **源站响应头设置** 模块中，点击 **新增**。您最多可以添加 50 条规则。

3. 参照文档下方的 [配置说明](https://docs.byteplus.com/en/docs/18/117645#%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E) 对该规则进行配置。

4. 配置完成后，点击 **保存**。


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1ba74ed7880f405b865e65f36ec514eb~tplv-goo7wpa0wc-topic.webp) </span>

<span id="配置说明"></span>
## 配置说明


|**配置** |**说明** |
|---|---|
|配置类型 |表示一个操作类型。该配置有以下选项：<br><br><br>* **设置**：表示设置一个指定的头部。如果源站响应中没有该头部，则 CDN 在响应中添加该头部。如果源站响应中有该头部，则 CDN 设置该头部为指定的值。<br><br>* **删除**：表示删除一个指定的头部。 |
|头部名称 |表示需要设置或者删除的一个头部。头部名称是大小写不敏感的。您可以从下拉列表中选择一个常用的头部，参见 [常用头部](https://docs.byteplus.com/en/docs/18/117645#%E5%B8%B8%E7%94%A8%E5%A4%B4%E9%83%A8)。您也可以输入一个任意头部，头部名称不能超过 1,024 个字符，不能包含汉字以及以下字符：<br><br><br>* 空格、双引号（"）、冒号（:） |
|取值方式 |对于您在 **头部名称** 中指定的头部，该配置表示该头部的取值方式，有以下选项：<br><br><br>* **常量**：表示设置该头部为一个字符串。<br><br>* **变量**：表示设置该头部为一个变量。<br><br>* **自定义**：表示设置该头部为一个表达式。您可以在表达式中包含字符串和变量。 |
|头部取值 |表示您在 **头部名称** 中指定头部的取值。<br><br><br>* 如果 **取值方式** 是 **常量**，您需要输入一个字符串。该字符串的长度不能超过 1,024 个字符，不能包含汉字和美元符号（$）。<br><br>* 如果 **取值方式** 是 **变量**，您需要从列表中选择一个变量。参见 [变量列表](https://docs.byteplus.com/en/docs/18/117645#%E5%8F%98%E9%87%8F%E5%88%97%E8%A1%A8)。<br><br>* 如果 **取值方式** 是 **自定义**，您需要输入一个表达式。表达式由字符串和变量组成。变量需要包裹在 `{}` 中，由 `$` 开头。例如 `bind${remote_addr}to${host}done`。<br><br><br>如果 **头部名称** 是 `Access-Control-Allow-Origin`，您可以在 **头部取值** 中输入多个以逗号（,）分隔的来源 IP 和来源域名，用于告诉浏览器哪些源的脚本可以读取跨域响应。 |
|生效范围 |表示该规则对哪些用户请求生效。该配置有以下选项：<br><br><br>* **默认范围**：表示该规则仅对源站响应中包含以下响应码的用户请求生效：<br><br>   * 200、201、204、206、301、302、303、304、307、308<br><br>* **全部请求**：表示该规则对所有用户请求生效。<br><br><br>当 **配置类型** 是 **删除** 时，该配置只能是 **全部请求**。 |

<span id="注意事项"></span>
## 注意事项

您设置的响应头名称不能以 `x-bdcdn-`、`x-byteinternal-` 或 `X-Volc-` 开头，也不能是以下任意头部。


* X\-Kfc\-Cachekey

* X\-Bdcdn\-Origin\-Err

* access\-check

* server\-timing

* via

* x\-request\-ip

* x\-tt\-trace\-tag

* x\-bdcdn\-logid

* byte\-error\-code

* x\-bdcdn\-cache\-status

* host

* X\-Exception\-Info


:::notice

如果源站响应中包含以 `x-bdcdn-`、`x-byteinternal-` 或 `X-Volc-` 开头的头部，这些头部不会包含在 CDN 响应中。

:::
