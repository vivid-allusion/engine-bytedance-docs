智能路由通过优化 CDN 节点到源站之间的回源路径，改善跨地域访问时的回源时延和稳定性。

当请求未命中 CDN 缓存时，CDN 需要向源站获取内容。动态请求无法缓存，因此每次用户请求都会触发回源。不缓存的内容以及缓存时间较短的内容也通常会产生更多回源请求。默认情况下，CDN 按默认回源路径向源站请求内容。在跨地域或跨运营商网络环境中，默认回源路径可能受到公网路由质量波动的影响。

开启智能路由后，CDN 会在可用的回源路径中动态选择网络质量更优的路径，再向源站请求内容。

<span id="工作机制"></span>
## 工作机制

智能路由只优化 CDN 节点到源站之间的回源链路，不改变客户端连接 CDN 节点的方式，也不改变已有的源站配置或源站选择逻辑。

开启功能后，CDN 节点会对源站执行轻量网络探测。对于单个域名，所有 CDN 节点探测该域名的总带宽一般小于 `100 KB/s`。系统根据探测结果评估多条回源路径的时延、稳定性和路径长度（经过的网络跳数），并为后续回源请求选择更优的路径。

例如，源站部署在欧洲，用户从亚太、欧洲和美洲访问服务。部分请求会由各区域的 CDN 节点回源。智能路由会根据各节点到该源站的实时网络情况选择回源路径，减少公网路由质量波动导致的回源时延和连接不稳定问题。

智能路由主要影响以下指标：


* 客户端首包响应时间。

* 客户端内容下载速度。

* 回源请求成功率。


用户侧的整体访问体验还受到缓存命中率、客户端到 CDN 节点的网络质量等因素影响。回源请求比例越高，智能路由的作用通常越容易在整体指标中体现。

<span id="适用场景"></span>
## 适用场景

智能路由适用于源站位置相对固定、用户接入区域分布广泛，且部分接入区域与源站之间存在跨地域或跨运营商回源链路的业务。

以下业务通常更容易从智能路由中获益：


* 使用集中式源站提供服务的 SaaS 或 Web 接口。

* 面向全球用户的动静态混合业务。

* 不缓存、缓存时间较短，或内容更新频繁的文件下载业务。

* 对客户端首包响应时间、客户端内容下载速度或回源请求成功率较敏感的业务。


对于可长时间缓存的内容，大部分请求可直接由 CDN 缓存响应，回源次数较少，因此智能路由带来的收益通常有限。

<span id="注意事项"></span>
## 注意事项


* 智能路由在 CDN 回源时生效。请求直接命中 CDN 缓存时，不会触发回源。

* 功能基于实时网络探测数据选择路径。不同源站位置、客户端接入区域和网络环境下，实际优化效果不同。


<span id="计费说明"></span>
## 计费说明

智能路由当前限时免费。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **智能路由** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 设置 **状态** 为 **开启**。

3. 点击 **保存**。


配置生效后，CDN 节点会在回源时根据实时网络探测结果选择更优的回源路径。
