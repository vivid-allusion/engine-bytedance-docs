BytePlus CDN 提供的一系列访问控制功能有不同的优先级。在 CDN 处理用户请求时，这些访问控制功能的生效顺序如下：


1. 地域访问控制

2. 禁用 HTTP Method

3. IP 黑白名单

4. Referer 黑白名单

5. UA 黑白名单

6. Origin 防盗链

7. 自定义拦截规则

8. URL 鉴权

9. 远程鉴权

10. 下载限速


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">对于一个用户请求，如果任意一个访问控制功能的结果是拒绝该请求，则其余的访问控制功能不再对该请求生效。</div>
