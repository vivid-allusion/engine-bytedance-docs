本文档介绍如何在 BytePlus CDN 中设置用户浏览器对于请求文件的缓存行为。

<span id="浏览器缓存概述"></span>
## 浏览器缓存概述

当 CDN 响应一个用户请求时，除了将请求的文件发送给用户之外，还可以指示用户浏览器如何对该文件进行缓存。通过在 CDN 中指定浏览器缓存策略，您对特定文件在用户浏览器中的缓存行为进行设置。

浏览器缓存策略与源站响应中所指示的缓存行为有关。在 CDN 向源站请求一个文件时，源站的响应头中会指示该文件的缓存行为。CDN 在缓存该文件时会记录该响应头。

<span id="浏览器缓存策略"></span>
## 浏览器缓存策略

浏览器缓存策略指定了 CDN 如何设置浏览器的缓存行为。CDN 提供了以下浏览器缓存策略：


* 缓存。该策略的逻辑如下：

   * 如果请求文件的源站响应中 `Cache-Control` 响应头不包含 `no-cache`、`no-store` 或者 `private` 指令，CDN 在响应用户请求时会包含 `Cache-Control: max-age=N` 响应头。该响应头告知浏览器需要缓存该文件，其缓存时间 `N` 就是您在策略中指定的缓存过期时间。

* 遵循源站的缓存策略。该策略的逻辑如下：

   * 在响应用户请求时，CDN 会包含请求文件的与缓存相关的源站响应头。

* 不缓存。该策略的逻辑如下：

   * CDN 指示浏览器不要对请求的文件进行缓存。在响应用户请求时，CDN 会包含 `Cache-Control: no-store` 响应头。


<span id="操作步骤"></span>
## 操作步骤


1. 打开 **浏览器缓存** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 点击 **添加规则**。

   您最多可以添加 50 条规则。

3. 参照以下配置说明。

4. 配置完成后，点击 **保存**。

<span id="配置说明"></span>
### 配置说明


|**配置** |**说明** |
|---|---|
|优先级 |表示规则的优先级。如果有多条规则，则按优先级来执行规则。如果有一条规则匹配了用户请求，剩余规则停止匹配。您可以通过拖拽调整规则的优先级。 |
|规则类型 |表示规则的匹配条件。该配置有以下选项：<br><br><br>* **文件后缀**：表示规则用于匹配指定扩展名的文件的请求。<br><br>* **URL 目录**：表示规则用于匹配指定目录下文件的请求。<br><br>* **URL 全路径**：表示规则用于匹配指定文件路径的请求。 |
|规则 |表示规则的内容，长度不能超过 1,024 个字符，不能包含以下字符：<br><br><br>* 双斜杠（//）、空格、美元符号（$）、问号（?）。<br><br><br>同时，<br><br><br>* 如果规则类型是 **文件后缀**，规则内容必须是一个或者多个以分号（;）分隔的文件后缀。文件后缀无需以句点（.）开头。例如：`png;txt`。<br><br>* 如果规则类型是 **URL 目录**，规则内容必须是一个或者多个以分号（;）分隔的目录路径。目录路径必须以斜杠（/）开头和结尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果规则类型是 **URL 全路径**，规则内容必须是一个或者多个以分号（;）分隔的文件路径。文件路径必须以斜杠（/）开头，可以包含星号（\*）用来表示一个或者多个字符。例如：`/chs/foods/local*sets;/us/birds/chickadee`。 |
|缓存策略 |设置一个缓存策略。该配置有以下取值：<br><br><br>* **缓存**<br><br>* **遵循源站**<br><br>* **不缓存**<br><br><br>关于每个策略的描述，参见 [浏览器缓存策略](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-browser-caching-cn#%E6%B5%8F%E8%A7%88%E5%99%A8%E7%BC%93%E5%AD%98%E7%AD%96%E7%95%A5)。 |
|忽略大小写 |表示匹配过程是否区分大小写。该设置默认是关闭，表示区分大小写。<br><br>**示例**：对于文件后缀规则，您设置 **忽略大小写** 为关闭。您输入的规则内容是 `png;txt`。此时，该规则可以匹配 `HTTPS://www.EXAMPLE.com/image.png` 的请求，但是不能匹配 `https://www.example.com/image.PNG` 的请求。 |
|缓存时间 |指定一个时间单位并输入缓存的时间。该配置仅当 **缓存策略** 是 **缓存** 的时候有效。该配置的说明如下：<br><br><br>* 如果您指定的时间单位是 **秒**，您可以输入的值的范围是 0 \- 31536000。31,536,000 秒是 365 天。<br><br>* 如果您指定的时间单位是 **分**，您可以输入的值的范围是 0 \- 5256000。5,256,000 分是 365 天。<br><br>* 如果您指定的时间单位是 **小时**，您可以输入的值的范围是 0 \- 8760。8,760 小时是 365 天。<br><br>* 如果您指定的时间单位是 **天**，您可以输入的值的范围是 0 \- 365。 |
