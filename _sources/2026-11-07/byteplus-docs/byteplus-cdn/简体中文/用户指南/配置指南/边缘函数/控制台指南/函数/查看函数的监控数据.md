本文档介绍如何查看函数的监控数据。

监控数据展示了函数的执行次数、资源消耗、响应事件、错误数等数据。您可以通过这些数据了解函数的运行情况并进行排障。

<span id="操作步骤"></span>
## 操作步骤

参见以下步骤查看函数的监控数据。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list)页面。

2. 找到要查看监控数据的函数，点击函数名称。

3. 选择 **概览** 标签页。您可以在该页面查看函数的监控数据。边缘函数默认展示过去 24 小时的监控数据。您可以修改时间范围，查看过去 7 天内任意时间段（精确到秒）的数据。

<span id="监控数据详情"></span>
## 监控数据详情

监控数据包括统计数据和趋势图。

<span id="统计数据"></span>
### 统计数据

边缘函数允许您查看以下统计数据。


|指标 |描述 |单位 |
|---|---|---|
|QPS |每秒钟函数执行的次数。 |/ |
|内存使用量 |函数执行过程中的平均内存消耗。 |KB |
|CPU使用率 |函数执行过程中每个请求的 CPU 时间的 P95 值。 |us |
|响应时间 |函数执行过程中每个请求的响应时间的 P95 值。 |ms |
|错误数 |每秒钟返回的在指定时间范围内失败的请求的比率。请参考 [调用状态](https://docs.byteplus.com/en/docs/18/20478#%E8%B0%83%E7%94%A8%E7%8A%B6%E6%80%81) 了解函数请求执行失败的原因。 |/ |


<span id="趋势图"></span>
### 趋势图

趋势图展示了统计数据随时间的分布，即在指定时间段内各个指标数据的波动。

<span id="qps"></span>
#### QPS

每秒钟函数执行的次数。

<span id="响应时间"></span>
#### 响应时间

每个请求的响应时间。

<span id="cpu使用率"></span>
#### CPU使用率

在指定时间范围内，函数执行的 CPU 时间。

<span id="内存使用量"></span>
#### 内存使用量

在指定时间范围内，函数的平均内存消耗。

<span id="响应状态"></span>
#### 响应状态

在指定时间范围内，HTTP 响应状态码的数量。例如，如果 HTTP 响应状态码在 [200,300)之间，2xx 响应的计数增加 1。3xx，4xx，5xx 也是如此。

如果响应状态码不在 [200,600) 内，该状态码被记录为未知。

<span id="调用状态"></span>
#### 调用状态

函数请求执行的错误状态分布。


* cpu_time_abort：由 CPU 超时引发的执行错误。

* real_time_abort：由响应时间超时引发的错误。

* memory_abort：由内存用尽引发的错误。

* other_abort：表示由于异常的客户端情况导致的错误，例如客户端过早终止请求。

* error：表示其他错误，例如租户代码中未经处理的异常。
