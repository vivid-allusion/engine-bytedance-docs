本示例展示了如何一次请求多个文件并流式返回这些文件。

网站页面中有多个没有依赖关系的静态文件需要加载时，浏览器会分别去请求对应的文件。但浏览器允许的并发请求资源数有限，为了减少 HTTP 请求的发送次数，可以合并浏览器的静态资源请求。具体的实现方式是通过 URL 查询参数来合并多个文件的请求。

例如，网站页面中的 <script\> 标签的 src 属性的值包含一个参数名为 urllist 的查询参数。该查询参数包括多个 .js 文件的 URL 路径。

```html
<script src="http://www.example.com/?urllist=/react/a.min.js,/react/b.min.js"></script>
```


函数收到用户请求时，先读取该查询参数，获取每个 .js 文件的 URL 路径。然后将其拼接为完整的 URL，再通过异步请求逐个访问 URL 获取文件。在获取文件的同时，函数把获取的文件流式返回给用户。

```JavaScript
async function handle(event) {
  const request = event.request; 
  const url = new URL(request.url);
  const fetchList = url.searchParams.get("urllist").split(",");
  const {readable, writable} = new TransformStream();
  
  (async () => {
    let idx = 0;
    for (const u of fetchList) {
      const resp = await fetch (`http://${url.host}${u}`);
      const close = (idx == fetchList.length - 1);
      resp.body.pipeTo(writable, {preventClose: close});
      idx++;
    }
  })();
  
  return new Response(readable, {
    status: 200
  });
}

addEventListener('fetch', (event) => {
  event.respondWith(handle(event));
});
```
