边缘函数 CLI 提供以下命令。


* [函数](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-manage-funcs-topichead-cn)

   * [nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-cn)：在当前目录创建一个函数项目并在函数项目中创建一个本地函数。

   * [管理函数](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-manage-functions-topichead-cn)

      * [nest deploy](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-deploy-cn)：把本地函数部署到边缘节点。

      * [nest upload](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-upload-cn)：把本地函数的代码上传到远端函数。

      * [nest functions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-cn)：对本地函数进行增删改查操作。

   * [调试函数代码](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-local-dev-cn)

      * [nest debug](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-debug-cn)：在本地调试函数代码。

      * [nest start](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-start-cn)：在本地运行函数代码。

   * [触发器](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-triggers-topichead-cn)

      * [nest domain](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-domain-cn)：管理域名触发器。

      * [nest cron](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-cron-cn)：管理 Cron 触发器。

   * [发布历史](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-history-topichead-cn)

      * [nest rollback](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-rollback-cn)：将函数代码回滚到历史发布版本。

      * [nest versions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-version-cn)：获取函数代码的历史发布版本。

      * [nest tickets](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-ticket-cn)：获取函数代码的发布记录。

   * [函数配置](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-function-config-topichead-cn)

      * [nest envs](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-env-cn)：管理函数的环境变量。

      * [nest canary](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-canary-cn)：管理函数的灰度环境。

* [边缘KV](https://docs.byteplus.com/docs/byteplus-cdn/edge-function-cli-ref-edge-kv-topichead-cn)

   * [nest kv](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-kv-cn)：管理边缘 KV。

* [辅助工具](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-others-topichead-cn)

   * [nest config](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-config-cn)：管理边缘函数 CLI 配置。

   * [nest help](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-help-cn)：获取帮助信息。

* [全局参数](https://docs.byteplus.com/docs/byteplus-cdn/global-parameters-cn)

   * [--config](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-c-cn)

   * [--function](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-f-cn)

   * [--verbose](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-verbose-cn)

   * [--help](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global--help-cn)
