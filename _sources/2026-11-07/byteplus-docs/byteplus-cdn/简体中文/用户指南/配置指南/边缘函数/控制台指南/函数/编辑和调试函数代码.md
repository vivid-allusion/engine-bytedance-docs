本文档介绍如何编辑和调试函数代码。

<span id="使用限制"></span>
## 使用限制

边缘函数的调试环境暂不支持运行 [边缘 KV 的运行时 API](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-EdgeKV-RuntimeAPI-cn)。边缘 KV 的运行时 API 只能在正式环境运行。

<span id="操作步骤"></span>
## 操作步骤

参见以下步骤编辑和调试函数代码。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 找到需要编辑和调试代码的函数并点击函数的名称。

3. 选择 **代码** 标签页，点击 **编辑和发布**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4775e07079cbbcdbcb87810d9d1f2250.jpeg) </span>

4. 使用代码编辑器编辑代码。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_1b6d28420a7642e5818a2cc5f07af82d.jpeg) </span>

5. 在 HTTP 标签页中，按以下说明对调试器进行配置。配置完成后点击 **发送**。您可以在页面的右侧区域查看函数执行结果。在页面的底部区域查看函数的日志、执行信息及性能。

   * 选择一个 HTTP 请求方法。

   * 填入用于模拟用户请求的 URL。函数默认使用 `http://a5624*****33b010b` 作为 URL，其中 `a5624*****33b010b` 是函数的 ID。该 URL 可用于触发 fetch 事件。但是，该 URL 只能用于 Debugger 内部测试，而无法通过互联网访问。另外，对于 Debugger 中模拟的用户请求，`FetchEvent.info` 中的属性值均为 `undefined`。因此，Debugger 报错并不代表您的代码出现了错误。您需要在灰度环境对 Debugger 不支持的代码进行测试。

   * （可选）添加 Header、Body。

      * Header：自定义 HTTP 请求头。

      * Body：自定义 HTTP 请求体。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">您需要在 HTTP 标签页显示绿点的情况下，发送请求调试函数。如果您长时间未操作，调试器会与服务器断开连接，此时，HTTP 标签页会显示红点，且您无法进行调试。您刷新页面后，调试器将会自动重连，HTTP 页签会显示绿点。      </div>
      

6. 在 Debugger 中发送请求后，您可以查看 **控制台**、**数据洞察** 和 **性能** 标签页了解函数的执行情况。



<Tabs>
<Tab zoneid="vhplBT1zxO" title="控制台">
<TabTitle>控制台</TabTitle>

响应的 Body 内容不会自动打印到日志中，您需要在函数的代码中使用`console.log()` /`console.info()`/`console.error()`/`console.trace()`等语句，自定义需要查看的日志信息。


</Tab>
<Tab zoneid="sAllTo2jyH" title="数据洞察">
<TabTitle>数据洞察</TabTitle>

在 **数据洞察** 页标签页下勾选 **启用数据洞察** ，发送请求之后，您可以查看函数最近一次请求所产生的代码执行信息。

<div style="text-align: center">
<img src="https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_e41a2023b2880f91f98cd8c0634af700.jpeg" width="800px" /></div>



</Tab>
<Tab zoneid="htcL61uY8j" title="性能">
<TabTitle>性能</TabTitle>

在 **性能** 页签下，您可以通过火焰图来分析函数响应性能。


1. 点击图标 ● 开始录制。

2. 点击 **发送请求** 触发代码执行。

3. 点击 **停止录制**，CPU Profiler 的火焰图会被生成。


<div style="text-align: center">
<img src="https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ed1fa98f69d703688c545c763f97bbb8.jpeg" width="800px" /></div>



</Tab>
</Tabs>



7. 调试完成后，点击 **保存**。
