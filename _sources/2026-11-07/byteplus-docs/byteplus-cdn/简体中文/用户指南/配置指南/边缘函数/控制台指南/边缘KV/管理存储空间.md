本文介绍了如何通过控制台创建、更新和删除存储空间。

<span id="创建存储空间"></span>
## 创建存储空间

参见以下步骤创建一个存储空间。


1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **边缘KV** 页面，点击 **创建存储空间** 。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_f54c3597a034c7d4b3b052a7eeb3b121.jpeg) </span>

3. 在 **创建存储空间** 对话框中，设置以下参数，然后点击 **保存** 。

   
   |参数 |描述 |
   |---|---|
   |名称 |存储空间的名称。名称的规则如下：<br><br><br>* 只能包含英文字母、数字、连字符（\-）和下划线（_）。<br><br>* 长度为 2 ~ 64 个字符。 |
   |描述 |存储空间的备注。长度不超过 80 个字符。 |
   |项目 |存储空间所属的项目。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_855f3dd52c88e18445c0c10d3c8da0be.jpeg) </span>


<span id="更新存储空间"></span>
## 更新存储空间

参见以下步骤更新一个存储空间的名称和描述。

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">您修改存储空间的名称前，需要确保访问该存储空间的 OpenAPI 或运行时 API 的参数同步更新。否则，如果 OpenAPI 或运行时 API 依然访问旧的存储空间名称，访问会失败。</div>



1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **边缘KV** 页面，找到需要更新的存储空间，然后点击 **操作** 列的 **编辑** 。

3. 在 **编辑存储空间** 对话框中，填写新的空间名称和描述，点击 **保存** 完成更新。


<span id="删除存储空间"></span>
## 删除存储空间

您可以删除不再需要的存储空间。

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">一个存储空间被删除后，该存储空间中的所有数据也会被删除。该操作不可逆。删除前请确认已经没有函数在使用该存储空间中的数据。</div>



1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **边缘KV** 页面，找到需要删除的空间，然后点击 **操作** 列的 **删除**。

3. 在弹出的对话框中，选中 **已确认**，点击 **确定** 完成存储空间删除。
