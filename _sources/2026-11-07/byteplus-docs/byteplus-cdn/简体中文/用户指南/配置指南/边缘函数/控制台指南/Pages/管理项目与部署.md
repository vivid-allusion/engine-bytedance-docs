本文档介绍如何在 Pages 中查看项目详情、修改项目配置以及管理部署记录。

<span id="查看项目详情"></span>
## 查看项目详情

进入某个 Pages 项目后，当前项目详情页包含以下页签：


* **概览**

* **部署**


<span id="管理概览页配置"></span>
## 管理概览页配置

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260520073810-1131013284923.png) </span>

**概览** 页当前包含以下管理区域：


* **通用设置**：查看或编辑 Pages 项目名称、项目描述、项目和加速区域。

* **域名管理**：查看当前已绑定域名，并添加新的自定义域名。

* **Git 管理**：查看当前仓库，并切换生产分支。

* **构建和输出设置**：修改根目录、构建输出目录、构建命令和安装命令。

* **环境变量**：添加或更新环境变量。

* **预览**：查看当前部署的预览缩略图和预览 URL。


<span id="git-管理"></span>
## Git 管理

对于通过 Git 创建的项目，您可以在 **概览 \> Git 管理** 中：


* 查看当前仓库。

* 查看当前生产分支。

* 切换生产分支。


切换生产分支后，后续新触发的部署将基于该生产分支执行。

<span id="构建和输出设置"></span>
## 构建和输出设置

在 **概览 \> 构建和输出设置** 中，您可以修改以下配置：


* **根目录**

* **构建输出目录**

* **构建命令**

* **安装命令**


这些配置决定了 Pages 如何安装依赖、执行构建，以及从哪个目录发布静态资源。

<span id="环境变量"></span>
## 环境变量

在 **概览 \> 环境变量** 中，您可以新增或修改环境变量。

当前环境变量配置具备以下特性：


* 使用 **Key / Value** 结构。

* `Value` 默认以掩码形式显示。

* 可通过右侧图标查看明文。

* 支持复制 `Value`。


<span id="查看部署记录"></span>
## 查看部署记录

在项目详情页中，单击 **部署** 页签，查看部署记录。

当前部署列表会展示以下信息：


* **部署 ID**

* **状态**

* **创建日期**

* **部署完成时间**

* **操作**


在部署列表中，您可以执行以下操作：


* **新部署**：发起一次新的部署。

* **下载**：下载指定部署的产物。

* **回滚**：将线上版本回滚到某个历史成功部署。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">只有存在可回滚的历史成功版本时，<strong>回滚</strong> 操作才可用。</div>


<span id="查看部署详情"></span>
## 查看部署详情

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260520073853-640070342480.png) </span>

在 **部署** 页签中，单击某个 **部署 ID**，进入 **Deployment Details** 页面。

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260520073944-1137620906473.png) </span>

<span id="general"></span>
### General

**General** 区域会展示该次部署的基础信息，包括：


* 项目名称

* 环境（例如 `Production`）

* 分支

* 持续时间

* 日期

* 提交信息


<span id="build-logs"></span>
### Build Logs

在 **Build Logs** 页签中，您可以查看完整的构建日志，用于排查安装、构建和发布过程中的问题。

<span id="build-summary"></span>
### Build Summary

在 **Build Summary** 页签中，您可以查看本次部署的构建产物清单，包括文件路径和文件大小。

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260520074034-850140273977.png) </span>

<span id="functions"></span>
### Functions

如果当前部署包含 `/functions` 目录，对应的函数路由也会在 **Functions** 页签中展示。有关 Functions 的详细说明，请参见 [使用 Pages Functions](https://docs.byteplus.com/docs/byteplus-cdn/use-pages-functions)。

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260520074053-1070174140257.png) </span>

<span id="说明"></span>
## 说明


* 对于通过 Git 创建的项目，修改代码仓库内容后，您需要重新触发部署才能使变更生效。

* 对于通过 ZIP 上传创建的项目，后续可以通过 **部署 \> 新部署** 重新上传新的 ZIP 包完成更新。
