指定一个函数配置文件。本地函数默认使用文件夹根目录的 nest.json 文件作为配置文件。

<span id="概述"></span>
## 概述

```shell
--config <config_file_path> 
```



* `<config_file_path>`：*string, required*

   * 函数配置文件的路径。
