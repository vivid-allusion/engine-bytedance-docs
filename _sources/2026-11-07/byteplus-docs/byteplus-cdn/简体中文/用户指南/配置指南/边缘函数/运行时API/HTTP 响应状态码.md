对于域名触发器触发的一次函数执行，函数通过 HTTP 响应状态码表示了函数执行是否成功。如果函数执行失败，对于不同的状态码，边缘函数有不同的重试策略。


|状态码 |含义 |说明 |重试策略 |
|---|---|---|---|
|200 |成功 |函数执行成功。 |无重试策略 |
|599 |函数代码出错 |可能是某个 promise 被拒绝，也可能是抛出了没有捕获的异常。运行时监听所有的 promise 异常，如果任何 promise 被拒绝或异常没有被捕获，并且发生在回复发送的过程中，那么运行时会截断回复，取消请求上下文。 |在本边缘节点内重试一次幂等请求 |
|598 |限流 |函数代码拥有过多的上下文，或资源（例如内存、CPU 执行时间等）严重不足。 |跨边缘节点重试幂等请求一次。您也可以通过 [提交工单](https://console.byteplus.com/workorder/create)申请调整资源或限流策略。 |
|597 |被封禁 |因为安全原因被封禁，一般封禁时间几分钟，几分钟后自动恢复。 |跨边缘节点重试幂等请求一次 |
|596 |全局限流 |边缘函数所在的边缘节点资源到达上限，开始熔断限流。 |跨边缘节点重试幂等请求一次 |
|594 |未识别用户 |非边缘函数用户的流量进入到运行时。 |无重试策略 |
|593 |服务发现基础设施出错 |平台服务异常。 |跨边缘节点重试幂等请求一次 |
