本文档介绍如何为函数配置域名触发器。

当用户通过 HTTP/HTTPS 请求访问函数关联的域名，且用户请求与域名的转发规则匹配时，域名触发器会触发函数代码中的 fetch 事件。您需要在代码中监听并处理 fetch 事件。

<span id="使用限制"></span>
## 使用限制

一个函数最多允许关联 100 个域名，一个域名最多允许关联 50 个函数。

<span id="配置域名触发器"></span>
## 配置域名触发器

您需要完成以下任务来为函数配置域名触发器。


* [步骤一：为函数关联域名](https://docs.byteplus.com/en/docs/18/20589#%E6%AD%A5%E9%AA%A4%E4%B8%80%EF%BC%9A%E4%B8%BA%E5%87%BD%E6%95%B0%E5%85%B3%E8%81%94%E5%9F%9F%E5%90%8D)

* [步骤二：为域名配置转发规则](https://docs.byteplus.com/en/docs/18/20589#%E6%AD%A5%E9%AA%A4%E4%BA%8C%EF%BC%9A%E4%B8%BA%E5%9F%9F%E5%90%8D%E9%85%8D%E7%BD%AE%E8%BD%AC%E5%8F%91%E8%A7%84%E5%88%99)

* [步骤三：在函数代码中监听 fetch 事件](https://docs.byteplus.com/en/docs/18/20589#%E6%AD%A5%E9%AA%A4%E4%B8%89%EF%BC%9A%E5%9C%A8%E5%87%BD%E6%95%B0%E4%BB%A3%E7%A0%81%E4%B8%AD%E7%9B%91%E5%90%AC-fetch-%E4%BA%8B%E4%BB%B6)


<span id="步骤一：为函数关联域名"></span>
### 步骤一：为函数关联域名

<span id="前提条件"></span>
#### 前提条件


* 您的函数已全量发布，且函数的状态是 **运行中** 或 **待关联**。

* 您的域名已接入 BytePlus CDN，并且 **域名状态** 是 **在线**。参见 [添加您的域名](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-add-your-domain-name-cn)。


参见以下步骤为函数关联一个域名。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **触发器** 标签页，然后选择 **域名** 标签页，点击 **添加域名**。

4. 在 **添加域名** 对话框中，选择一个或多个需要关联的域名，然后点击 **保存**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_1121b6717db5f914b4c866360ce57050.jpeg) </span>


域名关联成功后，您可以在 **触发器** 标签页查看 **域名** 。由于添加的域名没有配置转发规则，该域名的状态为 **离线**。

<span id="步骤二：为域名配置转发规则"></span>
### 步骤二：为域名配置转发规则

为函数添加域名后，您还需要为域名配置转发规则。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **触发器** 标签页，然后选择 **域名** 标签页。

4. 在 **域名** 标签页下的域名列表中，选择需要配置转发规则的域名。如果您要为该函数下的多个域名配置相同的转发规则，勾选多个域名。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ddd03751b14999484e01b8af208d4601.png) </span>

5. 点击域名列表下方的 **配置转发规则**。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">您在 <strong>域名</strong> 标签页每次只能增量配置一条转发规则。多次配置会产生多条转发规则。您可以在 BytePlus CDN 的 <strong>域名管理</strong> 页面查看域名所关联的全部转发规则。参见 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn">使用边缘函数响应</a>。   </div>
   

6. 在 **配置转发规则** 页面参见下表配置转发规则。

   
   |参数 |说明 |
   |---|---|
   |域名 |待配置转发规则的域名。 |
   |函数名 |当前函数的名称，不可修改。 |
   |转发规则 |匹配到转发规则的用户请求会被 BytePlus CDN 转发到边缘函数。<br><br><br>* **规则类型**<br><br>   选择一个规则的类型。该配置取值如下：<br><br>   * 文件后缀：规则应用于具有指定后缀名的所有文件。<br><br>   * URL目录：规则应用于指定目录下的所有文件。<br><br>   * URL全路径：规则应用于指定文件。<br><br>* **规则**<br><br>   根据指定的 **规则类型**，输入规则内容。规则内容不能超过 1024 个字符。你可以输入一个或者多个配置，多个配置以英文分号（;）分隔。 规则内容的要求如下：<br><br>   * 如果类型是 **文件后缀**，需要输入一个或者多个文件后缀。比如 `xlsx` 或者 `png;txt`。文件后缀可以包含英文字母和数字。<br><br>   * 如果类型是 **URL目录**，需要输入一个或者多个目录路径。目录路径必须以斜杠（/）开头和结尾。比如 `/www/img/byte/;/www/doc/`。目录路径不能包含连续斜杠（//）、百分号（%）、空格。如果要指定域名下的所有目录，输入 `/`。<br><br>   * 如果类型是 **URL全路径**，需要输入一个或多个完整路径。路径以斜杠（/）开头。比如 `/www/img/byteplus.png;/doc/study.docx`。文件路径不能包含连续斜杠（//）、百分号（%）、空格。<br><br>* **忽略大小写**<br><br>   设置 CDN 在使用 **规则** 匹配用户请求的文件时是否区分大小写。请求 URL 的其余部分不受该配置影响。默认设置是开启。开启表示不区分大小写。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4f6d2321d018f30a777b46b388651093.jpeg) </span>

7. 转发规则配置完成后，点击 **保存**。


您需要等待几分钟。当域名的状态变为 **在线** 时，表示域名触发器对于该域名生效。此时，如果用户向该域名发起 HTTP/HTTPS 请求且该请求匹配转发规则，那么 BytePlus CDN 会把用户请求转发到边缘函数，而且域名触发器会触发与该域名关联的函数中的 fetch 事件。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_901c7f5325c401cfe2d7fe8fed398a72.jpeg) </span>

<span id="步骤三：在函数代码中监听-fetch-事件"></span>
### 步骤三：在函数代码中监听 fetch 事件

您需要在函数代码中监听 fetch 事件来处理用户请求。下面的示例代码展示了如何注册一个事件监听器监听 fetch 事件并在 fetch 事件被触发时调用回调函数向用户返回自定义响应。

```JavaScript
// 注册一个事件监听器监听 fetch 事件
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request));
})
// fetch 事件被触发时，该回调函数被调用
async function handleRequest(request) {
    return new Response('Hello World!', { status: 200 });
}
```


<span id="解除函数与域名的关联"></span>
## 解除函数与域名的关联

<span id="前提条件"></span>
### 前提条件

域名在 **触发器** 标签页中的状态是 **离线**。

<span id="操作步骤"></span>
### 操作步骤

参见以下步骤为函数解除关联一个域名。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **触发器** 标签页，然后选择 **域名** 标签页。

4. 在 **域名** 标签页下的域名列表中，找到需要解除关联的域名，点击 **操作** 列的 **解除关联**。

5. 在弹出的对话框中点击 **确定**。


解除关联后，该域名不会再出现在域名列表中。
