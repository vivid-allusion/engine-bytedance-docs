本文档介绍如何开通边缘函数。使用边缘函数前，您必须先开通边缘函数。

<span id="前提条件"></span>
## 前提条件

您已经开通了 BytePlus CDN。参见 [开通 BytePlus CDN](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-activate-cdn-cn)。

<span id="操作步骤"></span>
## 操作步骤


1. 登录 [BytePlus 边缘函数控制台](https://console.byteplus.com/cdn/cdn-bp/edge-function/)。

2. 在服务开通页面，仔细阅读页面上的内容，了解边缘函数的计费方式。

3. 勾选服务协议，然后单击 **开通**。

4. 在 **确认订单** 对话框中，单击 **确认**。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">由于边缘函数是后付费的，页面显示的价格是 $0.00。也就是说，开通边缘函数不需要付费。   </div>
   

<span id="计费说明"></span>
## 计费说明

关于计费详情，参见 [计费说明](https://docs.byteplus.com/en/docs/byteplus-cdn/billing_edge_functions_cn)。
