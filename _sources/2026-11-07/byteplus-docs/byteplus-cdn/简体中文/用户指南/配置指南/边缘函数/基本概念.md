本文档包含边缘函数的基本概念。

<span id="边缘节点"></span>
## 边缘节点

边缘节点指的是在网络边缘处进行数据处理和提供计算服务的服务器的集群。边缘节点的位置靠近数据源和终端用户，分布广泛。BytePlus CDN 和边缘函数共享边缘节点。

<span id="函数"></span>
## 函数

边缘函数中的函数是事件驱动的。函数包括函数配置和函数代码。

<span id="触发器"></span>
## 触发器

触发器属于函数配置。触发器在满足特定条件时，会触发函数代码中的事件。边缘函数支持域名触发器和 Cron 触发器。


* 域名触发器：当用户通过 HTTP 或 HTTPS 请求访问函数关联的域名，且用户请求与域名的转发规则匹配时，域名触发器会触发函数代码中的 fetch 事件。您需要在代码中监听并处理 fetch 事件。

* Cron 触发器：定期触发函数代码中的 cron 事件。您需要在代码中监听并处理 cron 事件。


<span id="环境变量"></span>
## 环境变量

您通过环境变量可以在不更新代码的情况下调整函数的行为。环境变量通常用于存储 API 密钥等敏感信息或外部服务的 URL 等环境特定的配置信息。环境变量属于函数配置。因此，每次更改环境变量后，您都需要重新发布函数才能使新的环境变量生效。

<span id="版本"></span>
## 版本

您每次发布函数时，边缘函数都会为函数自动生成一个版本。该版本包括函数代码和函数配置的快照，不包括触发器。您可以通过版本管理函数代码和函数配置。

<span id="灰度发布"></span>
## 灰度发布

灰度发布是指将函数的新版本发布到所有边缘节点之前，先发布到一部分边缘节点。您可以通过这部分边缘节点验证函数的功能和性能，如果符合预期，就可以发布到所有边缘节点。

<span id="全量发布"></span>
## 全量发布

全量发布是指将函数一次性发布到所有边缘节点。

<span id="运行时"></span>
## 运行时

边缘函数的运行时是在 BytePlus 全球边缘节点上的函数运行环境。

<span id="运行时-api"></span>
## 运行时 API

运行时 API 是用于开发者与边缘函数的运行时交互的一套 API。

<span id="边缘-kv"></span>
## 边缘 KV

边缘 KV 提供键值对数据的分布式存储服务。

<span id="存储空间"></span>
## 存储空间

在边缘 KV 中，存储空间是一个逻辑分区，用于对键值对进行分类管理。您可以为不同应用或模块的键值对创建单独的存储空间。

<span id="键值对"></span>
## 键值对

数据在边缘 KV 中以键值对的形式存储。一个键值对的键在一个存储空间中唯一。
