边缘函数提供函数服务和边缘 KV 服务。


* 函数服务是在 BytePlus 的全球边缘节点上的无服务器计算服务。您可以为函数编写 JavaScript 代码，然后发布函数把 JavaScript 代码部署在全球边缘节点上，用于处理用户请求。

* 边缘 KV 服务是在 BytePlus 的全球边缘节点上的分布式键值存储服务。边缘 KV 适用于低频写入、高频读取的场景。


<span id="应用场景"></span>
## 应用场景

<span id="边缘侧渲染"></span>
### 边缘侧渲染

您可以使用边缘函数构建边缘网关，实现边缘侧渲染。相比服务侧渲染，边缘侧渲染降低了用户的首屏加载时间，减轻了服务端的工作负载。

例如，用户需要访问一个网页。当用户请求到达边缘网关时，边缘网关先从源站或 CDN 缓存中获取静态 HTML，并把静态 HTML 返回给用户。此时，客户端浏览器开始解析 HTML 并生成 DOM 树，并从边缘网关获取渲染资源。边缘网关从 CDN 缓存或源站获取静态资源（例如 .css 文件、.js 文件或图片文件），并通过异步请求同时从源站获取动态资源。边缘网关优先向用户返回静态资源，并把获取的动态资源拼接到静态资源，然后把拼接完成的 HTML 流式返回给用户。

<span id="在边缘侧处理用户请求"></span>
### 在边缘侧处理用户请求

您可以使用边缘函数搭建高性能、高可用的边缘网关，对用户请求进行自定义处理，例如合并或修改用户请求、实现 CORS，对用户请求进行鉴权等。

<span id="持续集成和持续交付-部署（ci-cd）"></span>
### 持续集成和持续交付/部署（CI/CD）

您可以使用边缘函数搭建针对 API 或者网站的边缘 CI/CD 流水线，用于实现数据处理、A/B 测试、根据用户特征返回个性化内容、请求重定向、错误兜底降级、健康检查、并发请求竞速、性能测试等功能。
