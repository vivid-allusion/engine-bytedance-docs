查看边缘函数 CLI 的帮助信息。

<span id="概要"></span>
## 概要

```shell
npx nest help

npx nest help <command>
```


<span id="描述"></span>
## 描述

您可以使用 `npx nest help` 查看边缘函数 CLI 的帮助信息，也可以使用 npx nest help `<command>` 查看指定命令的帮助信息。
