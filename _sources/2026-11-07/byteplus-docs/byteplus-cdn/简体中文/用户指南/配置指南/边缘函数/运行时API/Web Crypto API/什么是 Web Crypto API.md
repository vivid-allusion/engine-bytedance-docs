[Web Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Crypto_API) 提供了一系列方法用于处理加密、解密、摘要、数字签名相关的任务。


* [digest()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-digest-cn)

* [sign()/verify()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-sign-verify-cn)

* [encrypt()/decrypt()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-encrypt-decrypt-cn)

* [importKey()/exportKey()/generateKey()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-importKey-exportKey-generateKey-cn)
