本文介绍了如何在存储空间中添加、更新或删除数据。

<span id="前提条件"></span>
## 前提条件

您的 BytePlus 账号下有 [存储空间](https://docs.byteplus.com/docs/byteplus-cdn/doc-manage-namespace-cn)。

<span id="添加数据"></span>
## 添加数据

参见以下步骤在存储空间中添加数据。


1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 找到您需要添加数据的存储空间，点击该存储空间的名称。

3. 点击 **添加数据**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ce7192e71c77207b4e60fe0844dacfc0.png) </span>

4. 在弹出的 **添加数据** 对话框中，设置数据的相关参数，然后点击 **保存**。

   
   |参数 |描述 |
   |---|---|
   |键 |数据的键。只能包含英文字母、数字、连字符（\-）以及下划线（_）。不超过 512 个字节。 |
   |值 |数据的值。单个值不超过 128 KB。 |
   |TTL |可选。数据的到期时间。您可以设置为 **永久储存**，也可以设置为 **自定义**，然后设置数据的到期时间。数据到期之后将无法被访问。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_18b6ececfcc7a04235f45df06dbaee79.jpeg) </span>


<span id="更新数据"></span>
## 更新数据

参见以下步骤在存储空间中更新数据。


1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 找到您需要更新数据的存储空间，点击该存储空间的名称。

3. 找到您需要更新的数据，点击 **操作** 列的 **编辑**。

4. 在弹出的 **编辑数据** 对话框中，修改 **值** 或 **TTL**，点击 **保存** 完成修改。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您更新数据后，更新后的数据会同步到所有边缘节点。您无需重新发布函数。</div>


<span id="删除数据"></span>
## 删除数据

参见以下步骤在存储空间中删除数据。

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">在删除数据之前，请确认没有任何函数正在使用此数据。该操作不可逆。</div>



1. 打开 [边缘KV](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 找到您需要删除数据的存储空间，点击该存储空间的名称。

3. 您可以删除单个数据项或多个数据项：

   * 要删除单个数据条目，请找到要删除的数据条目，然后点击 **操作** 列中的 **删除**。在出现的对话框中，点击 **删除**。

   * 要删除多个数据条目，请选中每个数据条目 Key 前面的复选框，然后点击 **批量删除**。在出现的对话框中，点击 **确定**。
