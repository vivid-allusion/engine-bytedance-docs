本文档介绍了如何为函数添加环境变量，并在代码中引用环境变量。

环境变量是一组键值对。通过环境变量，您无需更新代码就可以调整函数在不同环境中的行为。

<span id="操作步骤"></span>
## 操作步骤

<span id="为函数添加环境变量"></span>
### 为函数添加环境变量

参见以下步骤为函数添加环境变量。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 找到您需要添加环境变量的函数，点击函数名称。

3. 选择 **配置** 标签页，然后选择 **环境变量**。

4. 点击 **添加变量**。在 **添加变量** 对话框，分别输入变量的 **变量名称** 和 **值**。您可以添加一个或多个环境变量。变量名称的规则如下：

   * 必须以英文字母或下划线（_）开头。

   * 只能包含英文字母、数字、下划线（_)。

   * 同一函数中环境变量的变量名称不能重复。

5. 点击 **确定**。您添加的环境变量会出现在环境变量列表。


<span id="在代码中引用环境变量"></span>
### 在代码中引用环境变量

您在代码中通过 `env.key` 获取键为 `key` 的环境变量的值。例如，下面的代码获取键为 `test` 的环境变量的值。

```JavaScript
const value = env.test;
```


如果您需要修改环境变量的值，您需要在修改完成后重新发布函数。函数发布完成后，改动才会在函数中生效。
