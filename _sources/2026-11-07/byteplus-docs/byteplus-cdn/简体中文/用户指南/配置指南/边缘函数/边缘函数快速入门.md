本教程基于简单的示例场景介绍如何在 BytePlus CDN 中使用边缘函数。

<span id="前提条件"></span>
## 前提条件

您已经开通了边缘函数。参见 [开通边缘函数](https://docs.byteplus.com/docs/byteplus-cdn/activate_byteplus_edge_functions_cn)。

<span id="示例场景"></span>
## 示例场景

您有一个网站，域名是 `www.example.com`。您在 BytePlus CDN 添加了该域名。您希望通过边缘函数修改源站返回的错误页面，发送更为友好的自定义页面给用户。

<span id="操作步骤"></span>
## 操作步骤

参见以下步骤在 BytePlus CDN 中使用边缘函数。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_61127becb22ede8ba4b23a31886878f0.jpeg) </span>


1. **创建函数**：创建一个函数。

2. **编辑与调试代码**：在函数中编辑和调试代码。

3. **发布函数**：将函数部署到 BytePlus CDN 的全球边缘节点。

4. **关联域名**：把函数的触发器设置为域名触发器，并在域名触发器中将函数与您的域名关联。

5. **为域名配置转发规则**：为您的域名配置转发规则，当 BytePlus CDN 收到匹配转发规则的用户请求时，会将用户请求转发到边缘函数。

6. **验证函数**：验证函数的实际执行结果是否符合预期。


<span id="步骤一：创建函数"></span>
## 步骤一：创建函数


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，点击 **创建函数**。

3. 在 **创建函数** 页面，根据以下说明配置相关参数。

   * **名称**：在本教程中，您把 **名称** 设置为 `custom-error-page`。

   * **项目**：在本教程中，您把 **项目** 设置为`default`。

   * **创建方式**：在本教程中，您选择 **从模板开始**，然后选择 **改写源站错误回复页面** 模板。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_72851d39667c28e7a258fb2ee9c1d378.jpeg) </span>

4. 点击 **保存** 创建函数。


接下来，您需要编辑和调试代码。

<span id="步骤二：编辑和调试代码"></span>
## 步骤二：编辑和调试代码


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **代码** 标签页，点击 **编辑和发布**。

4. 在代码编辑器中查看 default 文件。您可以根据需求自行修改代码。本教程使用模板提供的代码。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">代码中调用了 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-addEventListener-cn">addEventListener()</a> 用于注册一个事件监听器。参数中传入了 <code>fetch</code> 和一个回调函数 <code>{event.respondWith(handleResponse(event));}</code>：   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><code>fetch</code> 表示该事件监听器会监听 fetch 事件，如果 fetch 事件被域名触发器触发，则回调函数会被调用。您在步骤四会为函数配置域名触发器。参见 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-FetchEvent-cn">FetchEvent</a>。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果源站响应的状态码是 5xx，回调函数会把源站响应改写为您自定义的 HTML 页面，即 <code>htmlResponse</code> 常量中的 HTML 代码。   </div>
   

   ```JavaScript
   const htmlResponse = `
   <html>
   
     <head>Error Page</head>
     <body>The server is experiencing some issues, please try again later</body>
   </html>
   `;
   
   // Add an EventListener to listen to fetch event. A domain trigger will trigger a fetch event
   addEventListener('fetch', (event) => {
     event.respondWith(handleResponse(event));
   });
   
   function isErrorStatus(st) {
     return st >= 500;
   }
   
   async function handleResponse(event) {
     const response = await fetch(event.request);
   
     // If the origin server returns a status code >= 500, then return the custom error page
     // Otherwise, return the information from the origin server.
     if (isErrorStatus(response.status)) {
       return htmlResponse;
     } else {
       return response;
     }
   }
   ```
   

5. 对代码进行调试。在本教程中，您填入一个会返回 5xx 状态码的 URL，点击 **发送**，并检查返回的结果是否符合预期。调试完成后，点击 **保存**。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">您需要在 HTTP 标签页显示绿点时，发送请求调试函数。如果您长时间未操作，调试器会与服务器断开连接，此时，HTTP 标签页会显示红点，且您无法进行调试。您刷新页面后，调试器将会自动重连，HTTP 页签会显示绿点。   </div>
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_1b6d28420a7642e5818a2cc5f07af82d.jpeg) </span>


接下来，您需要发布函数。

<span id="步骤三：发布函数"></span>
## 步骤三：发布函数

您必须先将函数全量发布之后，才能将其与域名关联。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **代码** 标签页，点击 **编辑和发布**。

4. 点击 **发布** 按钮。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">您可以在全量发布函数之前进行灰度发布。参见 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-create-function-cn">管理函数</a>。   </div>
   

5. 在 **发布** 对话框中，把 **发布类型** 设置为 **全量发布** ，然后点击 **确定**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_52d90c98f114a65a72da3a2009750e60.jpeg) </span>


接下来，您需要为函数关联域名。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">函数全量发布一般需要 5 ~ 10 分钟。您必须在函数全量发布完成后才能为函数关联域名。</div>


<span id="步骤四：关联域名"></span>
## 步骤四：关联域名

在本示例中，您使用域名触发器触发函数的执行。因此，您需要为函数关联域名`www.example.com`。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **触发器** 标签页，然后选择 **域名** 标签页，点击 **添加域名**。

4. 在 **添加域名** 页面选择 `www.example.com` 域名。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_ce527cd91287df6fa53a6e2ef005c346.png) </span>

5. 点击 **保存**。与域名关联完成后，函数的状态会变为 **运行中**。由于您还没有为域名配置转发规则，该域名的状态是 **离线**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7d8fd4b8482e171f10e288219a8ca737.jpeg) </span>


接下来，您需要为域名配置转发规则。

<span id="步骤五：为域名配置转发规则"></span>
## 步骤五：为域名配置转发规则

您为域名配置转发规则后，如果 BytePlus CDN 收到一个与转发规则匹配的用户请求，会把该请求转发到边缘函数。而且，域名触发器会触发函数中的 fetch 事件。


1. 打开 [函数管理](https://console.byteplus.com/cdn/edge-function/list) 页面。

2. 在 **函数管理** 页面，在 **名称** 列找到您创建的函数，然后点击函数的名称。

3. 选择 **触发器** 标签页，然后选择 **域名** 标签页。点击您的域名 `www.example.com` 前方的复选框，然后点击 **配置转发规则** 按钮。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_7d8fd4b8482e171f10e288219a8ca737.jpeg) </span>

4. 在 **配置转发规则** 页面中，参照下表配置 **转发规则** 参数项。本示例不对用户请求的 URL 的路径进行限制，因此会匹配任意路径。

   
   |参数名称 |说明 |
   |---|---|
   |规则类型 |在本教程中，您需要设置为 **URL目录**。 |
   |规则 |在本教程中，您需要设置为 `/`，表示匹配域名下的全部路径。 |
   |忽略大小写 |在本教程中，您需要保留默认值。 |
   

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_84830939b60cf16939ddefbf2e9e7c7a.jpeg) </span>

5. 点击 **保存**。您需要等待几分钟。当域名的状态变为 **在线** 时，表示域名触发器已经对该域名生效。此时，如果用户向该域名发起 HTTP/HTTPS 请求且该请求匹配转发规则，那么域名触发器会触发与该域名关联的函数中的 fetch 事件。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_901c7f5325c401cfe2d7fe8fed398a72.jpeg) </span>

接下来，您验证函数的执行结果是否符合预期。

<span id="步骤六：验证函数"></span>
## 步骤六：验证函数

您可以访问 www.example.com，并验证：


* 源站响应码为 5xx 时，返回的 HTML 页面是代码中 `htmlResponse` 常量的值。

* 源站响应码不是 5xx 时，返回的 HTML 页面来自源站。


如果验证无误，则说明您的示例场景已实现。
