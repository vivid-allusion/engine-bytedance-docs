<span id="ip-检测"></span>
## IP 检测

在您的站点接入 CDN 后，如果您站点页面的访问的速度不达预期，可以使用该工具检查用户访问的 IP 地址是否是一个 CDN 节点的 IP 地址。

您一次最多可以查询 50 个 IPv4 和 IPv6 地址。多个 IP 地址以换行或者分号（;）分隔 。

如果一个 IP 地址是 CDN 节点的 IP 地址，检查结果还会额外显示该 IP 地址的归属地。如果归属地是中国，检查结果还会额外显示该 IP 地址所属的网络运营商。

<span id="操作步骤"></span>
### 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，点击 **工具中心** \> **诊断工具**。

3. 在 **诊断工具** 页面，点击 **IP 检测** 下方的 **开始使用**。

4. 在 **IP 归属查询** 页面，输入需要查询的 IP 地址，然后点击 **查询**。

<span id="域名对比"></span>
## 域名对比

该工具用于对比两个域名的配置差异。该工具调用 DescribeCdnConfig API 获取指定域名的配置，然后高亮显示 API 层面的配置差异。

关于对比结果中各参数的定义，参见 [DescribeCdnConfig](https://docs.byteplus.com/en/docs/byteplus-cdn/DescribeCdnConfig_zh-cn)。

<span id="操作步骤"></span>
### 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，点击 **工具中心** \> **诊断工具**。

3. 在 **诊断工具** 页面，点击 **域名对比** 下方的 **开始使用**。

4. 在 **配置差异** 页面，指定需要对比的域名，然后查看域名配置的差异。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_c6e0e67517c2293a3aa7eeccbac03d29.png) </span>

<span id="策略对比"></span>
## 策略对比

该工具用与对比两个策略的配置差异。对比结果展示在以下标签页中：


* 基础信息：展示两个策略在基础信息上的差异。

* 配置：展示两个策略在 CDN 特性配置上的差异。

* 绑定域名列表：展示两个策略所绑定的域名的差异。


在使用该工具时，您需要指定策略类型，然后选择两个策略获取配置差异。


* 如果策略类型是分发策略，该工具调用 DescribeServiceTemplate API 获取两个策略的配置，然后在这三个标签页中显示配置差异。

* 如果策略类型是加密策略，该工具调用的是 DescribeCipherTemplate API。


在 **配置** 标签页中，该工具高亮显示 API 层面 CDN 特性的配置差异。关于对比结果中各参数的定义，


* 如果您对比的是两个分发策略，参见 [DescribeServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeservicetemplate-00652-cn)。

* 如果您对比的是两个加密策略，参见 [DescribeCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeciphertemplate-f8c12-cn)。


<span id="操作步骤"></span>
### 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，点击 **工具中心** \> **诊断工具**。

3. 在 **诊断工具** 页面，点击 **策略对比** 下方的 **开始使用**。

4. 在 **策略差异** 页面，指定策略类型，然后指定需要对比的策略。
