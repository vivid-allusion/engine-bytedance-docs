本文档介绍 BytePlus CDN 提供的 "实时日志投递" 服务。关于该服务与另外两种 CDN 日志获取方式的区别，参见 [日志管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-cn)。

<span id="什么是实时日志投递"></span>
## 什么是实时日志投递

对于 CDN 收到的用户请求，也就是服务区域内各 CDN 节点收到用户请求，您可以配置 "实时日志投递"，将请求日志投递到您指定的目的地。

实时日志从日志采集到日志投递的时间间隔不超过 5 分钟。实时日志可用于监控数据指标、检测安全风险、洞察业务趋势等。关于实时日志中包含的字段，参见 [日志字段](https://docs.byteplus.com/docs/byteplus-cdn/log-streaming-overview_zh-cn#%E6%97%A5%E5%BF%97%E5%AD%97%E6%AE%B5)。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDN 集成了 TLS 中的日志检索功能。如果您将实时日志投递到 TLS，您无需离开 CDN 控制台即可对日志进行检索，参见 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/log-query-examples_zh-cn">日志检索示例</a>。</div>


<span id="使用场景"></span>
## 使用场景

[日志管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-cn) 简略描述了实时日志的使用场景。本章节描述了更具体的使用场景。

实时日志可以帮助您分析域名遇到的问题，也可以帮助您了解用户是如何访问您的域名。除了对实时日志进行过滤，您还可以对日志数据进行处理，满足不同场景下的日志分析需求。


|**日志分析场景** |**作用描述** |
|---|---|
|过滤指定条件的日志 |指定一个或多个条件过滤日志。例如，您可以基于 URL、IP地址、时间范围过滤日志，以分析某个 IP 地址在指定时间范围内对特定 URL 的请求，以便及时定位问题。 |
|监测 CDN 服务指标 |指标数据可以帮助您了解 CDN 服务的质量以及用户的访问效率，以便您及时发现异常。访问效率包括缓存命中率、CDN 响应耗时、数据传输速度等。 |
|监测 CDN 访问错误 |如果用户在访问域名时出现了问题，该数据可以帮助您定位问题的原因。例如 URL 问题、源站故障、源站文件访问异常等。 |
|获取热门访问 |该数据可以帮助您了解用户请求中的热门对象。例如热门域名、热门 URI、热门访客IP、热门 Referer 等。 |


<span id="实时日志计费"></span>
## 实时日志计费

实时日志功能是收费的。费用由以下部分组成：


* 日志投递的费用。CDN 对投递的日志进行计费。计费单位是万条。关于日志投递计费的详细信息，参见 [CDN 计费说明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-pricing-cn)。

* 日志服务（TLS）的费用。TLS 对日志存储，日志的读写流量等进行计费。关于 TLS 计费的详细信息，参见 [TLS 计费说明](https://docs.byteplus.com/en/docs/tls/billable_items)。


<span id="日志字段"></span>
## 日志字段

CDN 投递的请求日志中包含以下字段：


|**字段** |**说明** |**示例** |
|---|---|---|
|time |表示 CDN 完成响应请求的时间，也就是 CDN 传输完文件最后一个字节的时间。 |`23/Oct/2022:17:48:59 +0800` |
|client_ip |表示发送请求的客户端 IP 地址。 |`192.0.2.1` |
|client_ip_country |表示客户端 IP 地址所归属的国家。 |`印尼` |
|client_ip_isp |表示客户端 IP 地址所归属的网络运营商。 |`Tencent Cloud` |
|client_ip_province |表示客户端 IP 地址所归属的城市。 |`雅加达` |
|client_port |表示请求使用的客户端端口。 |`37030` |
|domain |表示请求 URL 中的域名，也就是您的域名。 |`cdn.example.com` |
|ds_http_bd_status_hit |表示请求是否命中 CDN 的缓存。该参数的取值如下：<br><br><br>* `HIT`：表示请求命中 CDN 的缓存。<br><br>* `MISS`：表示请求未命中 CDN 的缓存。 |`HIT` |
|ds_http_method |表示请求使用的方法。 |`GET` |
|ds_http_protocol |表示请求使用的 HTTP 协议版本。 |`HTTP/3` |
|ds_http_range |表示请求中的 Range 头部的值。如果请求不包含该头部，该参数值为 `-`。 |`bytes=200-1000` |
|ds_http_referer |表示请求中的 Referer 头部的值。如果请求不包含该头部，该参数值为 `-`。 |`https://example.com/index?version=123` |
|ds_http_resp_content_length |表示请求文件的大小。单位是 bytes。 |`500` |
|ds_http_resp_content_type |表示 CDN 响应中 Content\-Type 头部的值。如果响应不包含该头部，该参数值为 `-`。 |`image/jpeg` |
|ds_http_resp_size |表示 CDN 向用户传输的数据量，单位是 bytes。 |`573` |
|ds_http_scheme |表示请求 URL 中的 scheme。 |`HTTPS` |
|ds_http_status |表示 CDN 的响应状态码。 |`200` |
|ds_http_ua |表示请求中的 User\-Agent 头部的值。如果请求不包含该头部，该参数值为 `-`。 |`curl/7.85.0` |
|ds_http_uri |表示请求 URL 中的路径和查询字符串，以斜杠（/）开头。 |`/chickadee.png?version=1` |
|ds_http_uri_path |表示请求 URL 中的路径，以斜杠（/）开头。 |`/img/chickadee.png` |
|ds_http_uri_query |表示请求 URL 中的查询参数。 |`version=1&colar=red` |
|ds_req_time |表示 CDN 响应用户请求所耗费的平均时间，单位是秒。 对于一个用户请求，CDN 的响应耗时是以下两个时间点之间的时间跨度：<br><br><br>* CDN 完成接收用户请求的最后一个字节。<br><br>* CDN 完成传输请求文件的最后一个字节。 |`0.104` |
