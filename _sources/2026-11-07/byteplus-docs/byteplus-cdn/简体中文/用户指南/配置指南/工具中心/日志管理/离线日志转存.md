本文档介绍 BytePlus CDN 提供的 "离线日志转存" 服务。该服务允许您配置 CDN 将按小时打包的请求日志转存到您指定对象存储服务中的一个存储桶。该存储桶可以来自BytePlus 对象存储（TOS）、阿里云对象存储（OSS）、腾讯云对象存储（COS）、AWS S3 以及使用与 AWS S3 兼容鉴权方式的任何对象存储服务。

关于 "离线日志转存" 与另外两种 CDN 日志获取方式的区别，参见 [日志管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-cn)。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_010ae450ab186d1dc06810da52b24d81.png) </span>

在配置 "离线日志转存" 时，您需要创建转存任务。在转存任务中，您提供存储桶的访问设置，并指定 CDN 对哪些域名的请求日志包进行转存。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDN 转存的日志包与 <strong>日志下载</strong> 标签页中可查询到并下载的日志包是相同的。</div>



* <div data-tips="true" data-tips-type="tip">关于日志的时效性、日志包的命名规则、日志字段的说明等信息，参见 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-logs-cn">日志下载</a>。</div>



<span id="离线日志转存计费"></span>
## 离线日志转存计费

"离线日志转存" 是收费的。费用由以下部分组成：


* 日志投递的费用。CDN 对投递的日志进行计费。计费单位是万条。关于日志投递计费的详细信息，参见 [CDN 计费说明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-pricing-cn)。

* 对象存储服务的费用。基于投递目标，参见

   * [BytePlus TOS 计费](https://docs.byteplus.com/en/docs/tos/docs-billing-overview)。

   * [AWS S3 计费](https://aws.amazon.com/s3/pricing/)。

   * 关于其他对象存储服务的定价，请访问服务提供商的网站。


<span id="操作步骤"></span>
## 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，点击 **工具中心** \> **日志管理**。

3. 在 **日志管理** 页面，点击 **离线日志转存** 标签页。

4. 在 **离线日志转存** 标签页，点击 **新增** 创建一个转存任务。

5. 在 **创建任务** 页面，参照 [配置说明](https://docs.byteplus.com/en/docs/18/48156#%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E) 对 **转存对象** 和 **关联方式** 进行配置。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果您指定 <strong>转存对象</strong> 为 <strong>BytePlus 对象存储 (TOS)</strong>，您需要先授权 CDN 访问 TOS，请按页面提示操作。如果您之前已授权 CDN 访问 TOS，<strong>服务授权</strong> 的状态会是 <strong>已授权</strong>。   </div>
   

6. 任务配置完成后，点击 **确认**。

<span id="配置说明"></span>
## 配置说明

<span id="转存对象-为-byteplus-tos"></span>
### **转存对象 为 BytePlus TOS**


|**配置** |**说明** |
|---|---|
|对象存储桶 |表示 TOS 中的一个存储桶的名称。存储桶列表中展示的是您账号下的所有存储桶，您需要从列表中选择一个存储桶。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDN 采集到的日志可能会存在延迟。对于延迟日志，CDN 会将其追加到 TOS 存储桶中对应的日志包中。因此，在选择存储桶时，您只能选择存储类型是 "标准存储" 的的存储桶。因为只有该类型的存储桶支持在现有文件中追加内容。</div><br> |
|对象存储目录 |表示存储桶下的一个目录路径。日志包会被转存到该目录路径下。例如 `mylogs/cdn-logs`。<br><br>&nbsp;<br><br>目录路径的开头和结尾不能是斜杠（/），长度不能超过 256 个字符。如果目录路径不存在，CDN 会在存储桶中创建该目录路径。<br><br>&nbsp;<br><br>如果您不指定该配置，日志包会被转存到存储桶的根目录下。 |
|私有桶访问 |表示该存储桶是否是公开访问的。该配置默认是关闭。<br><br><br>* 如果该配置是启用，表示存储桶是私有访问的。当 CDN 向该存储桶转存日志包时，CDN 会使用您 BytePlus 账号的凭证访问该存储桶。<br><br>* 如果该配置是关闭，表示存储桶是公开访问的。 |
|备注信息 |表示该任务的备注，长度为 3\-45 个字符，可以包含汉字，字母，数字，但不能以下划线（_）开头或结尾。一个汉字占 3 个字符。<br><br>&nbsp;<br><br>任务创建后，该备注会显示在任务 ID 下方。<br><br><span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4b74a875d81d3fe194091962e68c43bd.png) </span> |


<span id="转存对象-为-s3-协议对象存储"></span>
### **转存对象 为 S3 协议对象存储**


|**配置** |**说明** |
|---|---|
|访问域名 |对于日志包转存到的存储桶，该配置表示该存储桶的使用 S3 鉴权方式的访问点（endpoint）。<br><br>&nbsp;<br><br>访问点必须以 `https://` 开头，不包含存储桶的名称，长度不能超过 1,024 个字符。例如：`https://oss-ap-southeast-1.aliyuncs.com`。 |
|访问地域 |表示该存储桶所在地域（region code），例如 `ap-southeast`。请咨询该存储桶的对象存储服务提供商以获取该存储桶的地域。<br><br>&nbsp;<br><br>地域不能超过 64 个字符。 |
|对象存储桶 |表示该存储桶的名称（bucket name），长度不能超过 256 个字符。例如：`mybucket`。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDN 采集到的日志可能会存在延迟。对于延迟日志，CDN 会将其追加到 TOS 存储桶中对应的日志包中。因此，您指定的存储桶必须支持在现有文件中追加内容。</div><br> |
|对象存储目录 |表示存储桶下的一个目录路径。日志包会被转存到该目录路径下。例如 `mylogs/cdn-logs`。<br><br>&nbsp;<br><br>目录路径的开头和结尾不能是斜杠（/），长度不能超过 256 个字符。如果目录路径不存在，CDN 会在存储桶中创建该目录路径。 |
|私有桶访问 |表示该存储桶是否是公开访问的。该配置默认是关闭。<br><br><br>* 如果该配置是启用，表示存储桶是私有访问的。您需要提供 CDN 访问该存储桶所使用的凭证。<br><br>* 如果该配置是关闭，表示存储桶是公开访问的。 |
|AccessKey ID |对于 CDN 访问该存储桶所使用的凭证，该配置表示凭证中的 AccessKey ID。<br><br>&nbsp;<br><br>仅当 **私有桶访问** 是启用时，该配置才会出现。 |
|AccessKey Secret |对于 CDN 访问该存储桶所使用的凭证，该配置表示凭证中的 AccessKey Secret。<br><br>&nbsp;<br><br>仅当 **私有桶访问** 是启用时，该配置才会出现。 |
|备注信息 |表示该任务的备注，长度为 3\-45 个字符，可以包含汉字，字母，数字，但不能以下划线（_）开头或结尾。一个汉字占 3 个字符。<br><br>&nbsp;<br><br>任务创建后，该备注会显示在任务 ID 下方。 |


<span id="关联方式"></span>
### **关联方式**

在该配置中，您指定 CDN 对哪些域名的日志包进行转存。该配置有以下选项：


* 按域名关联：指定最多 200 个您账号下的域名。

* 按账号关联：表示您账号下所有的域名。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">一个域名只能包含在一个任务中。</div>


* <div data-tips="true" data-tips-type="tip">如果已存在 <strong>关联方式</strong> 为 <strong>按域名关联</strong> 的任务，您就无法创建 <strong>关联方式</strong> 为 <strong>按账号关联</strong> 的任务，反之亦然。</div>

<span id="启用-停用任务"></span>
### 启用/停用任务

如果您想暂停一个任务，您可以在该任务的 **操作** 列上，点击 **停用**。任务停用后，CDN 停止转存该任务所关联的所有域名的日志包。之后，您可以随时点击 **启用** 使 CDN 继续转存这些域名的日志包。

<span id="日志包转存失败时的页面提示"></span>
### 日志包转存失败时的页面提示

在您配置存储桶信息时，如果任何配置不正确，转存任务会失败。另外，如果在转存任务的执行过程中，存储桶达到了某些限制，转存任务也会失败。

如果一个转存任务无法将日志包转存到目标存储桶，该任务左侧会出现一个惊叹号。当您点击该惊叹号时，页面会显示最近一次转存失败的时间点和原因。您可以参考失败原因对问题进行排查。
