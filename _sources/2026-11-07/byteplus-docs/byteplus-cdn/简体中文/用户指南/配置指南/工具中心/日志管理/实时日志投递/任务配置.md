本文档介绍如何在 BytePlus CDN 中创建日志投递任务。您最多可以创建 20 个任务。

任务创建向导包含两个步骤：


1. 设置投递信息：配置投递相关的设置。

2. 关联域名：选择投递哪些域名的实时日志。

## 步骤一：设置投递信息

<span id="鉴权流程与令牌算法"></span>
#### 鉴权流程与令牌算法

**鉴权流程**


1. 在发送日志投递请求前，CDN 基于鉴权 Key 和令牌算法计算令牌。额外参与令牌计算的字段有指定的时间戳（timestamp）、请求 URL 中的路径（uri）、CDN 随机生成的整数（rand）。rand 的范围是 0 \- 2147483647。

2. 向 HTTP 服务器发送 POST 请求。

   * 请求 URL 中包含 `auth_key` 查询参数，参数值的格式为 `timestamp-rand-token`。

   * 请求 URL 的格式为 `http://[http_server_address]:[port]/[uri]?auth_key=timestamp-rand-token`

      请求 URL 示例：`http://https://www.example.com:8080/cdn-logs?auth_key=1744870608-14567-6459280fed54315c2960f9ae2e91807d`

   * 请求正文中包含多条日志，日志之间使用 `\n` 分隔。

3. 收到请求后，HTTP 服务器基于鉴权 Key、服务器地址中的路径、时间戳和随机数计算令牌。参见下方的令牌示例和示例代码。

4. HTTP 服务器判断这两个令牌是否相同。如果令牌相同，则表示鉴权通过。


**令牌算法**


* MD5(uri\-timestamp\-rand\-key)


**令牌示例**

假设：


* 服务器地址为 `https://www.example.com:8080/cdn-logs`。

* 鉴权 Key 为 `1a2c!=A?1`。

* 请求的发送时间（timestamp）为 `1744870608`。

* CDN 随机生成的整数（rand）为 `14567`。


则令牌的计算公式为 `MD5(/cdn-logs-1744870608-14567-1a2c!=A?1)`，计算出的令牌为 `6459280fed54315c2960f9ae2e91807d`。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在该示例中，如果服务器地址中不包含路径，则令牌计算公式为 <code>MD5(-1744870608-14567-1a2c!=A?1)</code>。</div>

<span id="步骤二：指定域名"></span>
## 步骤二：关联域名

在该步骤中，您选择投递哪些域名的实时日志。


* 如果您要投递所有域名的实时日志，请设置 **关联方式** 为 **按账号关联**。对于您后续在 CDN 中添加的域名，这些域名的实时日志也会被投递。

* 如果您要投递指定域名的实时日志，请设置 **关联方式** 为 **按域名关联**，然后选择这些域名。您最多可以选择 200 个域名。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如果已存在按账号关联的投递任务，则无法再创建按域名关联的投递任务。反之亦然。</div>

<span id="子用户权限说明"></span>
### 子用户权限说明

在步骤二中，子用户只能添加其有权限操作的域名。另外，假设一个子用户被授予的相关策略存在项目限制（如下图所示），也就是说该子用户有权限访问的是属于指定 BytePlus 项目的域名。在这个情况下，该子用户无法指定 **按账号关联**。

<span id="查看日志投递任务"></span>
## 查看日志投递任务

在您创建投递任务后，您的任务就出现在任务列表中了。


* 如果某个任务配置需要调整，您可以在 **操作** 列上，点击 **编辑**。

* 要查看投递任务的配置，您可以在相应任务的 **投递信息** 列上，点击 **展开查看**。

* 对于投递到 TLS 的日志，您可以点击 **操作** 列上的 **检索**，然后在 **检索与分析** 页面对日志进行检索和分析，参见 [日志检索示例](https://docs.byteplus.com/docs/byteplus-cdn/log-query-examples_zh-cn)。

## 删除日志投递任务

如果您不再需要某个实时日志任务，您可以先停用该任务，然后再删除它。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">对于投递目标是 TLS 的任务，任务删除后，相应的日志主题也会被删除。</div>
