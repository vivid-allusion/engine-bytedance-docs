## 概述

BytePlus CDN 提供了 ["用量封顶" ](https://console.byteplus.com/cdn/cdn-bp/tools/consumption-limit)。在该页面中，您可以为域名创建监控配置。在监控配置中，您需要指定监控指标、统计周期以及用量阈值。监控配置创建后，CDN 就开始监控域名的用量。如果某个统计周期内域名的用量超过阈值，CDN 会停用域名一段时间，以防止用量的持续增长。每个统计周期内，CDN 最多停用域名一次。该功能主要适用于需要严格控制 CDN 成本、防止因流量突增或恶意攻击导致产生预期外费用的场景。本文将为您介绍如何配置和使用用量封顶功能。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f1b3443bc2c4b719a40502b0205d625~tplv-goo7wpa0wc-image.image) </span>

在监控配置中，您还可以指定域名的停用时长。域名停用期结束时，CDN 会重新启用该域名。此外，您还可以在监控配置中为用量设置告警阈值，以便在用量达到告警阈值时收到通知。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">域名停用期间，您可以随时手动启用您的域名。</div>


* <div data-tips="true" data-tips-type="tip">域名停用期结束时，如果存在以下任意情况，CDN 将无法重新启用您的域名。</div>


   * <div data-tips="true" data-tips-type="tip">您的账户有欠费。</div>


   * <div data-tips="true" data-tips-type="tip">您在域名停用期间修改了域名配置。</div>


   * <div data-tips="true" data-tips-type="tip">其他不常见情况。这些情况这里不一一列举。如果您的场景中不存在前两个情况，但是 CDN 仍然无法启用您的域名，请 <a href="https://console.byteplus.com/workorder/create">提交工单</a>。</div>


* <div data-tips="true" data-tips-type="tip">对于 CDN 来说，采集指标数据、分析数据、停用域名都需要一定的时间。因此，用量超过阈值的时间与 CDN 停用域名的时间之间可能会有 15 分钟的延时。期间，域名的用量仍然会计费。</div>



<span id="a6d294e6"></span>
## 通知

当域名被停用、域名被重新启用或者域名的用量达到告警阈值时，CDN 会通过邮件和站内信向您发送相应的通知。

<span id="f7bf3c26"></span>
### 通知内容

以下为通知中主要内容的示例：


* Under your BytePlus account xxxxxxxxxx /example ,Domain www.example.com was triggering the usage cap policy you configured.


<span id="de9156da"></span>
## 操作步骤


1. 打开 ["用量封顶" 页面](https://console.byteplus.com/cdn/cdn-bp/tools/consumption-limit)。

2. 点击 **新增配置** 创建一个监控配置。

## 配置说明


|**配置** |**说明** |
|---|---|
|域名 |表示待监控的域名。您需要从列表中选择一个域名。也可以输入一个域名。 |
|统计方式 |表示监控指标的数据统计方式。该配置有以下选项：<br><br><br>* 瞬间用量：表示以指标的峰值数据作为统计周期内的指标数据，应用于带宽和 QPS 这两个指标。<br><br>* 累计用量：表示以指标的累计数据作为统计周期内的指标数据，应用于流量和请求数这两个指标。 |
|统计周期 |表示指标数据的统计时间粒度。CDN 对每个统计周期内的域名用量都是分别统计的。在每个统计周期内，CDN 每 5 分钟对当前统计周期统计域名的用量。<br><br><br>* 如果 **统计方式** 是 **瞬间用量**，该配置只能是 **每 5 分钟**。<br><br>* 如果 **统计方式** 是 **累计用量**，该配置的选项有 **每小时**、**每天**、**每月**。<br><br><br>首个统计周期取决于该监控配置的创建时间或者该配置的重新启用（如果之前已停用）时间。<br><br>**示例**<br><br>假设您在 8月12日 09:22 创建了一个监控配置，<br><br><br>* 您设置 **统计方式** 是 **瞬间用量**。在这个情况下，由于统计周期是 5 分钟，首个统计周期是当天的 [09:20, 09:25)，下一个统计周期是 [09:25, 09:30)，以此类推。<br><br>* 您设置 **统计方式** 是 **累计用量**，**统计周期** 是 **每小时**。在这个情况下，首个统计周期是当天的 [09:00, 10:00)，下一个统计周期是 [10:00, 11:00)，以此类推。<br><br>* 您设置 **统计方式** 是 **累计用量**，**统计周期** 是 **每天**。在这个情况下，首个统计周期是 [8月12日 00:00, 8月13日 00:00)，下一个统计周期是 [8月13日 00:00, 8月14日 00:00)，以此类推。<br><br>* 您设置 **统计方式** 是 **累计用量**，**统计周期** 是 **每月**。在这个情况下，首个统计周期是 [8月1日 00:00, 9月1日 00:00)，下一个统计周期是 [9月1日 00:00, 10月1日 00:00)，以此类推。 |
|封顶阈值 |表示用量阈值，阈值是整数。<br><br><br>* 如果 **统计方式** 是 **瞬间用量**，您可以设置以下指标的用量阈值：<br><br>   * 带宽：表示统计周期内的带宽。您可以设置的阈值范围是 10Mbps\-100Tbps。<br><br>   * QPS：表示统计周期内的用户请求 QPS。阈值范围是 100\-1,000,000。<br><br>* 如果 **统计方式** 是 **累计用量**，您可以设置以下指标的用量阈值：<br><br>   * 流量：表示统计周期内的流量。阈值范围是 100MB\-10,000TB。<br><br>   * 请求数：表示统计周期内的用户请求数。阈值范围是 10,000\-10,000,000,000。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">1GB=1,000MB，1Gbps=1,000Mbps。</div><br> |
|处置方式 |表示当用量超过阈值时，CDN 对域名执行的操作。当前，该配置只能是 **下线域名**，表示 CDN 停用您的域名。域名被停用时，CDN 会向您发送[通知](https://docs.byteplus.com/docs/byteplus-cdn/usage-cap_zh-cn#a6d294e6)。<br><br>&nbsp;<br><br>&nbsp;<br><br>在一个统计周期内，CDN 最多停用域名一次。如果您修改了监控配置，域名的停用次数会被清零。<br><br>&nbsp;<br><br>&nbsp;<br><br>**示例**<br><br>&nbsp;<br><br>&nbsp;<br><br>您设置 **统计方式** 是 **累计用量**、**统计周期** 是 **每月**、**处置时长** 是 **1 天**。<br><br>&nbsp;<br><br>&nbsp;<br><br>在 8月12日 09:25，该域名由于当月累计流量超过阈值而被 CDN 停用，并在 8月13日 09:25 被 CDN 重新启用。启用后，虽然该域名当月的累计流量仍然超过阈值，当月内 CDN 不再停用该域名。<br><br>&nbsp;<br><br>&nbsp;<br><br>然后，您在 8月15日 09:03 更新了该监控配置，将 **处置时长** 调整为 **3 天**。当天 09:05，该域名由于当月累计流量超过阈值而再次被 CDN 停用。 |
|处置时长 |表示 **处置方式** 的生效时长。<br><br><br>* 当 **处置方式** 是 **下线域名** 时，该配置表示域名的停用时长。域名停用期结束时，CDN 会重新启用您的域名，并向您发送[通知](https://docs.byteplus.com/docs/byteplus-cdn/usage-cap_zh-cn#a6d294e6)。<br><br><br>该配置有以下选项：**1 小时**、**12 小时**、**1 天**、**3 天**、**永久**。 |
|告警策略 |表示您是否希望当指标数据达到您设置的告警阈值时收到[通知](https://docs.byteplus.com/docs/byteplus-cdn/usage-cap_zh-cn#a6d294e6)。 |
|告警阈值 |当 **告警策略** 启用时，该配置会出现，表示封顶阈值的一个百分比。当指标数据达到该百分比时，CDN 向您发送[通知](https://docs.byteplus.com/docs/byteplus-cdn/usage-cap_zh-cn#a6d294e6)。您可以设置的阈值是范围在 10\-90 内的整数。<br><br>&nbsp;<br><br>&nbsp;<br><br>当域名用量达到该阈值时：<br><br><br>* 如果 **统计方式** 是 **瞬间用量**，虽然统计周期是 5 分钟，但是 CDN 每小时最多发送一次通知。<br><br>* 如果 **统计方式** 是 **累计用量**，在每个统计周期内，CDN 最多发送一次通知。<br><br><br>如果域名由于监控配置而被 CDN 停用或重新启用、或者监控配置被更新，通知次数会被清零。<br><br>&nbsp;<br><br>&nbsp;<br><br>**示例**<br><br><br>* 您设置 **统计方式** 是 **累计用量**，**统计周期** 是 **每小时**，**封顶阈值** 是 100MB，**告警阈值** 是 60%。<br><br>   * 在 [13:00, 14:00) 这个统计周期内，域名的累计流量达到了 62MB。但是，在 14:00 之前，CDN 不再向您发送通知。<br><br>* 您设置 **统计方式** 是 **瞬间用量**，**封顶阈值** 是 100Mbps，**告警阈值** 是 60%。<br><br>   * 在 [13:05, 13:10) 期间，域名的带宽峰值达到了 62Mbps。因此，CDN 在 13:10 向您发送通知。但是，在 14:00 之前，CDN 不再向您发送通知。<br><br>      在 [13:55, 14:00) 期间，域名的带宽峰值达到 62Mbps。因此，CDN 在 14:00 向您发送通知。<br><br>   * 在 [13:05, 13:10) 期间，域名的带宽峰值达到了 62Mbps，并且之后每 5 分钟的带宽峰值保持在 60Mbps 以上，直到当天 15:10。在这个场景中，CDN 会在 13:10、14:00、15:00 分别向您发送通知。<br><br><br>**监控配置更新对告警的影响示例**<br><br>您设置 **统计方式** 是 **累计用量**，**统计周期** 是 **每小时**，**封顶阈值** 是 100MB，**告警阈值** 是 60%。<br><br><br>* 在 13:05，当前小时内域名的累计流量达到了 62MB。因此，CDN 在 13:05 向您发送通知。在 13:08，您修改了监控配置，将 **封顶阈值** 修改为 200MB。在 13:15，当前小时内域名的累计流量达到了 190MB。因此，CDN 在 13:15 向您发送通知。 |
