本文档介绍了在 BytePlus CDN 中，指标是如何定义和统计的。指标分为两大类，一类是针对 [用户请求](https://docs.byteplus.com/en/docs/18/20603#%E7%94%A8%E6%88%B7%E8%AF%B7%E6%B1%82%E6%8C%87%E6%A0%87) 的，一类是针对 [回源请求](https://docs.byteplus.com/en/docs/18/20603#%E5%9B%9E%E6%BA%90%E8%AF%B7%E6%B1%82%E6%8C%87%E6%A0%87) 的。回源请求就是 CDN 向源站发送的请求。

<span id="基础信息"></span>
## 基础信息

在阅读本文前，请留意以下定义。


* 指定的统计时间段：表示您指定的开始时间（`StartTime`）和结束时间（`EndTime`）之间的统计时间段。

* 实际统计时间段：基于您指定的开始时间（`StartTime`）、结束时间（`EndTime`）、以及统计时间粒度（`Interval`）决定的统计时间段。指标数据是基于实际统计时间段而统计的。

* 时间区间：时间粒度（`Interval`）将实际统计时间段拆分成一系列的时间区间。

* 细分数据：表示 CDN 对每个时间区间统计数据后得到的一系列的指标数据。细分数据用于展示实际统计时间段内的数据趋势。

* 汇总数据：表示 CDN 对所有时间区间的指标数据进行汇总后得到的一个汇总数据。汇总数据用于展示实际统计时间段内的数据概况。


关于这些定义的详细描述，参见 [统计时间段说明](https://docs.byteplus.com/en/docs/byteplus-cdn/G6uz94)。

<span id="用户请求指标"></span>
## **用户请求指标**

<span id="客户端向-cdn-传输的数据量（流量）"></span>
### 客户端向 CDN 传输的数据量（流量）

<span id="定义"></span>
#### **定义**

表示用户向 CDN 传输的数据量，单位是 bytes。该数据量是 CDN 对收到的用户请求而统计的，是用户请求中请求头大小和请求正文大小之和。

该指标是对满足以下条件的用户请求统计的：


* 请求方法既不是 GET，也不是 HEAD。


<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的传输数据量。


* 单个时间区间内的传输数据量 = 该时间区间内用户向 CDN 传输的数据量


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的传输数据量总和。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的传输数据量。

2. 统计这些传输数据量的总和。


<span id="cdn-向客户端端传输的数据量（流量）"></span>
### CDN 向客户端端传输的数据量（流量）

表示 CDN 向用户传输的数据量，单位是 bytes。该数据量是 CDN 响应中响应头大小和响应正文大小之和。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的传输数据量。


* 单个时间区间内的传输数据量 = 该时间区间内 CDN 向用户传输的数据量


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的传输数据量总和。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的传输数据量。

2. 统计这些传输数据量的总和。


<span id="客户端向-cdn-传输的数据量（带宽）"></span>
### 客户端向 CDN 传输的数据量（带宽）

<span id="定义"></span>
#### **定义**

表示基于用户向 CDN 传输的数据量而计算的带宽，单位是 bps。

该指标是对满足以下条件的用户请求统计的：


* 请求方法既不是 GET，也不是 HEAD。


<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的带宽。根据指定的统计时间粒度，带宽有两种计算方式：


* 如果时间粒度是 1 分钟或者 5 分钟，单个时间区间内的带宽计算公式如下：

   * （该时间区间内用户向 CDN 传输的数据量 \* 8）/（该时间区间的时长）

* 如果时间粒度是 1 小时或者 1 天，单个时间区间内的带宽计算方式如下：

   1. 以 5 分钟时间粒度对该时间区间使用以上的计算公式统计一系列的带宽。

   2. 计算这些带宽中的最大值，也就是带宽峰值。


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的带宽峰值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间的带宽。

2. 计算这些带宽中的最大值。


<span id="带宽峰值时间"></span>
#### **带宽峰值时间**

表示带宽峰值所在的时间区间的开始时间。

<span id="cdn-向客户端传输的数据量（带宽）"></span>
### CDN 向客户端传输的数据量（带宽）

表示基于 CDN 向用户传输的数据量而计算的带宽，单位是 bps。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的带宽。根据指定的统计时间粒度，带宽有两种计算方式：


* 如果时间粒度是 1 分钟或者 5 分钟，单个时间区间内带宽的计算公式如下：

   * （该时间区间内 CDN 向用户传输的数据量 \* 8）/（该时间区间的时长）

* 如果时间粒度是 1 小时或者 1 天，单个时间区间内带宽的计算方式如下：

   1. 以 5 分钟时间粒度对该时间区间使用以上的计算公式统计一系列的带宽。

   2. 计算这些带宽中的最大值，也就是带宽峰值。


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的带宽峰值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间的带宽。

2. 计算这些带宽中的最大值。


<span id="带宽峰值时间"></span>
#### **带宽峰值时间**

表示带宽峰值所在的时间区间的开始时间。

<span id="请求数"></span>
### **请求数**

<span id="定义"></span>
#### **定义**

表示 CDN 收到的所有用户请求的数量。


* 用户请求数 = 动态请求数 + 静态请求数 + CDN 响应状态码是 405 的请求数


<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的请求数量。


* 单个时间区间内的请求数 = 该时间区间内 CDN 收到的所有请求数。


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的请求数总和。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的请求数。

2. 计算这些请求数的总和。


<span id="动态请求数"></span>
### 动态请求数

该指标的定义与数据统计方式与用户请求数类似，只是指标数据是对满足以下所有条件的用户请求而统计的：


* 请求方法既不是 GET，也不是 HEAD。

* CDN 的响应状态码不是 405。405 表示请求方法不被 CDN 允许。


<span id="静态请求数（static-requests）"></span>
### 静态请求数（static_requests）

该指标的定义与数据统计方式与用户请求数类似，只是指标数据是对满足以下所有条件的用户请求而统计的：


* 请求方法是 GET 或者 HEAD。

* CDN 的响应状态码不是 405。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">当前，对于 WebSocket 请求，该指标的数据不准确。在查询该指标的数据时，请过滤掉 WebSocket 协议。</div>


<span id="请求-qps"></span>
### 请求 QPS

<span id="定义"></span>
#### **定义**

对于 CDN 收到的所有用户请求，该指标表示这些请求的 QPS。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的请求 QPS。根据指定的统计时间粒度，请求 QPS 有两种计算方式：


* 如果时间粒度是 1 分钟或者 5 分钟，单个时间区间内请求 QPS 的计算公式如下：

   * （该时间区间内的请求数）/（该时间区间的时长）

* 如果时间粒度是 1 小时或者 1 天，单个时间区间内请求 QPS 的计算方式如下：

   * 以 5 分钟时间粒度对该时间区间使用以上的计算公式计算一系列的 QPS。

   * 计算这些 QPS 中的最大值，也就是 QPS 峰值。


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的请求 QPS 峰值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的请求 QPS。

2. 计算这些请求 QPS 中的最大值。


<span id="请求-qps-峰值时间"></span>
#### 请求 QPS 峰值时间

表示请求 QPS 峰值所在的时间区间的开始时间。

<span id="状态码"></span>
### 状态码

<span id="定义"></span>
#### **定义**

在 CDN 对用户请求的响应中，该指标表示以下类别的状态码数量：


* 所有状态码的数量。

* 2xx 状态码的数量以及该类别下每个状态码的数量。

* 3xx 状态码的数量以及该类别下每个状态码的数量。

* 4xx 状态码的数量以及该类别下每个状态码的数量。

* 5xx 状态码的数量以及该类别下每个状态码的数量。


<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的每个类别的状态码数量。

<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，每个类别的状态码数量总和。

<span id="响应时间"></span>
### **响应时间**

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">当前，对于 WebSocket 请求，该指标的数据不准确。在查询该指标的数据时，请过滤掉 WebSocket 协议。</div>


<span id="定义"></span>
#### **定义**

表示 CDN 响应用户请求所耗费的平均时间，单位是毫秒（ms）。

对于一个用户请求，CDN 的响应耗时是以下两个时间点之间的时间跨度：


* CDN 向用户传输响应的第一个字节。

* CDN 传输完响应的最后一个字节。


需要留意的是，该指标不是在用户侧统计的接收响应所耗费的时间。

当 CDN 传输完响应的最后一个字节时，该时间点会被记录为该请求的响应完成时间。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的平均响应时间。该指标数据是针对每个时间区间内 CDN 完成响应的请求统计的。


* 单个时间区间内的响应时间 =（该时间区间内所有请求的响应时间总和）/（该时间区间内的请求数量）


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的响应时间平均值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的响应时间。

2. 计算这些响应时间的平均值。


<span id="平均速度"></span>
### **平均速度**

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">当前，对于 WebSocket 请求，该指标的数据不准确。在查询该指标的数据时，请过滤掉 WebSocket 协议。</div>


<span id="定义"></span>
#### **定义**

表示 CDN 向用户传输数据时的平均速度，单位是 Bps。该指标是对**响应状态码是 2xx** 的用户请求而统计的。

需要留意的是，该指标不是在用户侧统计的平均数据传输速度。

当 CDN 传输完响应的最后一个字节时，该时间点会被记录为该请求的响应完成时间。在 CDN 对一个时间区间统计下载速度时，统计对象是所有响应完成时间在这个时间区间内的请求。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的平均下载速度，是针对每个时间区间内 CDN 完成响应的那些请求而统计的。


* 单个请求的下载速度 =（CDN 向用户传输的数据量）/（CDN 响应该请求所耗费的时间）

* 一个时间区间内的下载速度 =（该时间区间内所有请求的下载速度总和）/（该时间区间内的请求数量）


在统计下载速度时，CDN 会排除响应时间小于 1 毫秒的请求，以避免数据偏差。

<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的下载速度平均值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的下载速度。

2. 计算这些下载速度的平均值。


<span id="用户请求的流量命中率（traffic-hitrate）"></span>
### **用户请求的流量命中率（traffic_hitrate）** 

<span id="定义"></span>
#### **定义**

流量命中率是基于以下传输数据量而统计的：


* CDN 向用户传输的数据量。

* 源站向 CDN 传输的数据量。


流量命中率以数值形式显示。例如，0.9999 表示 99.99%。

<span id="细分数据"></span>
#### **细分数据**

细分数据表示每个时间区间内的流量命中率。


* 单个时间区间内的流量命中率 =（该时间区间内 CDN 向用户传输的数据量 \- 该时间区间内源站向 CDN 传输的数据量）/（该时间区间内 CDN 向用户传输的数据量）


<span id="汇总数据"></span>
#### **汇总数据**

汇总数据表示在实际统计时间段内，所有时间区间内的流量命中率平均值。汇总数据的计算方式如下：


1. 基于指定的统计时间粒度，计算该时间段内每个时间区间内的流量命中率。

2. 计算这些流量命中率的平均值。
