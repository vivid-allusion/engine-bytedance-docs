本文档介绍如何在 BytePlus CDN 管理控制台管理防护域名，包括添加域名和删除域名。

<span id="添加域名"></span>
## 添加域名

当您创建了高级 DDoS 防护实例后，高级 DDoS 防护不会自动防护您 BytePlus 账号下已接入 CDN 的域名。您需要手动将需要防护的域名添加到该实例。添加域名后，高级 DDoS 防护即启用。

<span id="使用限制"></span>
### 使用限制

默认情况下，一个高级 DDoS 防护实例最多可以防护 50 个域名。

<span id="注意事项"></span>
### 注意事项


* 当您为域名开启高级 DDoS 防护后，将会产生安全流量费用。安全流量的费用按 CDN 传输给客户端的数据量计算。计费详情，请参考 [DDoS 计费说明](https://docs.byteplus.com/en/docs/byteplus-ddos-protection/docs-pricing)。

* 为域名开启高级 DDoS 防护后，您无需修改域名的 DNS 解析配置。但是，DNS 会停止将域名解析为 IPv6 地址（即使您在 CDN 的策略中启用了 IPv6）。所有流量会指向 IPv4 高防 IP 地址。

* 开启高级 DDoS 防护会带来一定的域名访问时延。客户端所在区域和网络环境会影响到时延大小。


更多信息，请参考[使用高级 DDoS 防护时的注意事项](https://docs.byteplus.com/en/docs/byteplus-cdn/DDos_protection_levels_cn#%E4%BD%BF%E7%94%A8%E9%AB%98%E7%BA%A7-ddos-%E9%98%B2%E6%8A%A4%E6%97%B6%E7%9A%84%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9)。

<span id="操作步骤"></span>
### 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，选择 **安全中心** \> **DDoS** **防护**。

3. 在 **DDoS** **防护** 页面的 **防护域名** 区域，单击 **添加CDN域名**。

4. 在全部域名列表中，选中域名，然后单击 **确定**。

   列表上方会显示域名的配额以及当前受防护的域名的数量。您可以选择的域名的数量为这两者的差值。例如，如果域名的配额为 50，当前受防护的域名的数量为 45，则您还可以添加最多 5 个域名。


<span id="40fb3cb6"></span>
### 更多信息

<span id="79e232de"></span>
#### **防护模式说明**

高级 DDoS 防护实例支持以下两种防护模式：


* **自动调度**：正常情况下，域名直接解析到 CDN 服务 IP 地址。当系统识别到流量突发时，会自动触发切换流程，域名会被解析到高级 DDoS 防护实例的 IP 地址。域名解析切换需要数分钟生效。该模式适合需要兼顾性能和安全防护需求的域名。

* **总是开启**：域名总是被解析到高级 DDoS 防护实例的 IP 地址上。该模式适合被攻击频率高的域名。


在域名被添加到高级 DDoS 防护实例后，默认启用“自动调度”防护模式。如果您的域名被攻击的频率比较高，建议您在添加域名后，手动将域名的防护模式调整为“总是开启”。

<span id="9988aa90"></span>
#### **域名状态说明**

**自动调度**防护模式下，域名可能处于以下几种状态：


* 监控中：在无攻击的常规状态下，域名解析至 CDN 服务 IP 地址，以利用分布广泛的节点提供高质量服务。此时，域名状态显示为“监控中”。

* 运行中：当系统检测到流量突增时，域名会自动解析至高级 DDoS 防护实例的 IP 地址，域名状态切换为“运行中”。在此期间，网络层 DDoS 防护服务会进行流量分析。

* 清洗中：在域名处于“运行中”状态时，若系统识别出攻击流量，将自动执行流量清洗。此时，域名状态更新为“清洗中”。

   攻击流量停止后，系统会进入一个默认的等待期以确认威胁已完全解除。等待期结束后，域名状态将自动恢复为“监控中”，域名重新被解析至 CDN 服务 IP 地址。在等待期内，如果您需要提前恢复域名解析，请[提交工单](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000735)申请。


**总是开启**防护模式下，域名可能处于“运行中”或“清洗中”状态。

<span id="删除域名"></span>
## 删除域名

如果某个域名不再需要高级 DDoS 防护，您可以将其从防护域名列表中移除，以释放相应的域名配额。

<span id="注意事项"></span>
### 注意事项

在您将域名从防护域名列表中移除后，针对该域名的高级 DDoS 防护将关闭。

<span id="操作步骤"></span>
### 操作步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，单击 **安全中心** \> **DDoS** **防护**。

3. 在 **DDoS** **防护** 页面的 **防护域名** 区域，找到需要删除的域名，然后单击 **操作** 列的 **删除**。

4. 在弹出的对话框中，单击 **确定**。
