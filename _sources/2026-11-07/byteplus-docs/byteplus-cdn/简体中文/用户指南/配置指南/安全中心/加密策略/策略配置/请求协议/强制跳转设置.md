本文档介绍如何在 BytePlus CDN 中对域名配置协议重定向。

<span id="前提条件"></span>
### 前提条件

要开启该配置，域名必须已经开启了 HTTPS 加密服务。

<span id="操作步骤"></span>
## 操作步骤


1. 打开 **强制跳转设置** 配置页面。操作步骤参见 [域名配置](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-cn)。

2. 参照以下配置说明。

3. 配置完成后，点击 **保存**。



|**配置** |**说明** |
|---|---|
|策略 |设置重定向的策略。该配置有以下选项：<br><br><br>* **不跳转**：表示不重定向用户请求使用的协议。<br><br>* **将 HTTP 重定向到 HTTPS**：表示如果用户请求使用的协议是 HTTP，则将其重定向到 HTTPS。<br><br>* **将 HTTPS 重定向到 HTTP**：表示如果用户请求使用的协议是 HTTPS，则将其重定向到 HTTP。 |
|重定向方式 |表示 CDN 返回哪个状态码进行重定向。当 **策略** 是 **将 HTTP 重定向到 HTTPS** 或者 **将 HTTPS 重定向到 HTTP** 的时候，该配置会出现。<br><br>&nbsp;<br><br>该配置的可选项有 **301**、**302**、**303**、**307**、**308**。<br><br>&nbsp;<br><br>需要留意的是：<br><br><br>* 对于 301 和 302，如果原请求使用的方法不是GET，那么客户端向新的URL发送请求时，新请求使用的方法可能变成 GET。<br><br>* 对于 303，新请求使用的方法是 GET。<br><br>* 对于 307 和 308，新请求使用的方法与原请求相同，不会被改变。 |
