本文档展示如何在 BytePlus CDN 管理控制台的 **证书中心** 页面上传证书。

如果您的证书是您在其他证书服务商处购买的，您需要在该服务商处导出该证书，然后在 **证书中心** 页面上传该证书。

<span id="操作步骤"></span>
## 操作步骤


1. 在 **证书中心** 页面，点击 **上传证书**。

2. 在 **上传证书** 页面，参考 [配置说明](https://docs.byteplus.com/en/docs/18/6979#%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E) 进行设置，然后点击 **确定**。

<span id="配置说明"></span>
### 配置说明


|**配置** |**说明** |
|---|---|
|上传方式 |表示证书的上传方式。该配置有以下选项：<br><br><br>* 手动输入：表示粘贴证书文件和私钥文件中的内容。<br><br>* 上传证书文件：表示上传证书文件和私钥文件。 |
|Public Key |表示证书文件。证书文件必须包含完整的证书链，扩展名是 .crt 或者 .pem，内容以 `-----BEGIN CERTIFICATE-----` 开头。<br><br><br>* 如果 **上传方式** 是 **手动输入**，您需要将证书文件中的内容粘贴到 **Public Key** 输入框中。<br><br>* 如果 **上传方式** 是 **上传证书文件**，您需要指定证书文件。 |
|Private Key |表示证书私钥文件。私钥文件的扩展名是 .key 或者 .pem，内容以 `-----BEGIN XXX PRIVATE KEY-----` 开头。<br><br><br>* 如果 **上传方式** 是 **手动输入**，您需要将私钥文件中的内容粘贴到 **Private Key** 输入框中。<br><br>* 如果 **上传方式** 是 **上传证书文件**，您需要指定私钥文件。 |
|描述 |表示证书的备注。证书备注是可选的。 |
