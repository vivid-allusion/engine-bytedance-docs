本文档介绍 BytePlus CDN 的全局配置功能。

<span id="功能描述"></span>
## 功能描述

全局配置用于集中管理规则列表。以下 CDN 特性支持指定全局配置：


* 规则引擎中的大部分匹配条件

* IP 黑白名单

* Referer 黑白名单

* 自定义拦截规则中的 **请求 Query** 匹配条件


全局配置支持容量较大的规则列表。例如，IP 黑名单最多可包含 30,000 条规则。

更新全局配置后，变更会立即应用到指定该全局配置的策略所关联的域名。

<span id="创建全局配置"></span>
## 创建全局配置

<span id="创建步骤"></span>
### 创建步骤


1. 登录 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左侧导航栏，点击 **高级配置** \> **全局配置**。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_444e5a29411587d3d03c0ae430801062.png) </span>

3. 在 **全局配置** 页面，点击 **新增**。

4. 在 **新增全局配置** 页面，输入配置名称，选择应用场景和项目组。

   * 配置名称可包含汉字、字母、数字和下划线（`_`），长度为 3 至 45 个字符。一个汉字占 3 个字符。

5. 根据应用场景完成规则配置：

   * [IP 黑白名单](https://docs.byteplus.com/en/docs/18/36152#ip-%E9%BB%91%E7%99%BD%E5%90%8D%E5%8D%95)

   * [Referer 黑白名单](https://docs.byteplus.com/en/docs/18/36152#referer-%E9%BB%91%E7%99%BD%E5%90%8D%E5%8D%95)

   * [通用列表](https://docs.byteplus.com/en/docs/18/36152#%E9%80%9A%E7%94%A8%E5%88%97%E8%A1%A8)

6. 单击 **提交** 创建全局配置。创建后，您可以在详情页面单击 **修改** 更新规则，或在支持该功能的配置页面中指定该全局配置。


<span id="ip-黑白名单"></span>
### IP 黑白名单

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_f76e0fdac05244ac1159ff08e76460c1.png) </span>


|配置 |说明 |
|---|---|
|应用场景 |选择以下选项之一：<br><br><br>* **IP 白名单**：仅当请求的来源 IP 地址在规则列表中时，CDN 才允许该请求。<br><br>* **IP 黑名单**：当请求的来源 IP 地址在规则列表中时，CDN 会拒绝该请求。 |
|规则 |输入 IP 地址或 CIDR 网段，支持 IPv4 和 IPv6 格式。最多可输入 30,000 条规则。多条规则使用分号（`;`）分隔或分行输入，也可以上传包含规则的 `.txt` 文件。重复规则会被自动去重，不计入规则总数。 |
|IP 判断来源 |指定 CDN 判断客户端 IP 地址时使用的来源。<br><br>&nbsp;<br><br>支持以下选项：<br><br><br>* **默认逻辑**：CDN 使用真实建连 IP 判断客户端 IP 地址。真实建连 IP 是与 CDN 节点直接建立网络连接的对端 IP 地址。<br><br>* **自定义**：从真实建连 IP、`X-Forwarded-For` 请求头和 `X-Real-IP` 请求头中选择一个或多个来源，以判断客户端 IP 地址。无法从已选请求头获取 IP 地址时，CDN 使用真实建连 IP。<br><br>   * 对于黑名单，只要任一指定来源中获取的 IP 地址在黑名单中，CDN 就拒绝请求。<br><br>   * 对于白名单，只有所有指定来源中获取的 IP 地址均在白名单中，CDN 才允许请求。 |


<span id="referer-黑白名单"></span>
### Referer 黑白名单

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_a27aef5f3de5a711cef5dce5dae2ba4d.png) </span>


|配置 |说明 |
|---|---|
|应用场景 |选择以下选项之一：<br><br><br>* **Referer 白名单**：仅当请求的 Referer 头部在规则列表中时，CDN 才允许该请求。<br><br>* **Referer 黑名单**：当请求的 Referer 头部在规则列表中时，CDN 会拒绝该请求。 |
|规则 |输入域名、IP 地址或 CIDR 网段，以匹配请求 Referer 头部中的 hostname。不支持输入 URL。IP 地址和 CIDR 网段支持 IPv4 和 IPv6 格式；域名支持泛域名。最多可输入 4,000 条规则。多条规则使用分号（`;`）分隔或分行输入，也可以上传包含规则的 `.txt` 文件。重复规则会被自动去重，不计入规则总数。 |
|忽略大小写 |表示规则中的内容是否区分大小写。 |
|空 Referer 访问 CDN 资源 |空 Referer 是指 Referer 头部为空（`""`）或请求中不包含 Referer 头部。<br><br>&nbsp;<br><br>控制台根据所选应用场景显示以下其中一个选项：<br><br><br>* 选择 **Referer 白名单** 时，显示 **不允许空 Referer 访问 CDN 资源**。勾选后，CDN 拒绝空 Referer 请求；取消勾选后，CDN 允许空 Referer 请求。<br><br>* 选择 **Referer 黑名单** 时，显示 **允许空 Referer 访问 CDN 资源**。勾选后，CDN 允许空 Referer 请求；取消勾选后，CDN 拒绝空 Referer 请求。 |


<span id="通用列表"></span>
### 通用列表

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_835cea5be71b3c57a29de6081efc5752.png) </span>

通用列表既不是白名单，也不是黑名单，主要用于判断某个对象是否存在于列表中。例如，在[自定义拦截规则](https://docs.byteplus.com/en/docs/byteplus-cdn/custom-restrictions_cn)中，可通过 **请求 Query** 匹配条件判断指定查询参数的值是否属于通用列表。


|配置 |说明 |
|---|---|
|类型 |指定规则的匹配方式。创建后不能修改。<br><br>&nbsp;<br><br>支持以下类型：<br><br><br>* **精确匹配**：使用规则中的字符串精确匹配对象。<br><br>* **正则匹配**：使用规则中的正则表达式匹配对象。<br><br>* **IP 匹配**：使用规则中的 IP 地址或 CIDR 网段匹配 IP 地址。 |
|规则 |多条规则需分行输入，也可以上传包含规则的 `.txt` 文件。重复规则会被自动去重，不计入规则总数。<br><br>&nbsp;<br><br>根据所选类型输入相应内容并遵循相应限制：<br><br><br>* **精确匹配**：输入字符串。支持使用通配符 `*` 表示任意字符，但通配符只能位于字符串首尾。最多可输入 4,000 条规则，规则总长度不超过 200,000 个字符。<br><br>* **正则匹配**：输入正则表达式。最多可输入 30,000 条规则，规则总长度不超过 200,000 个字符。<br><br>* **IP 匹配**：输入 IP 地址或 CIDR 网段。最多可输入 30,000 条规则。 |


<span id="修改全局配置"></span>
## 修改全局配置

可以通过以下方式修改全局配置中的规则：


* 全量替换：表示输入的规则会覆盖已有的所有规则。

* 仅新增：表示输入的规则会被添加到已有规则中。

* 指定删除：表示输入的规则会从已有规则中删除。


对于通用列表，创建后不能修改 **类型**。

修改后，变更会立即应用到指定该全局配置的策略所关联的域名。

<span id="操作步骤"></span>
### 操作步骤


1. 在左侧导航栏，单击 **高级配置** \> **全局配置**。

2. 找到目标全局配置，单击 **修改**。

3. 在 **配置详情** 页面选择 **修改方式**，输入相应规则，然后单击 **提交**。

<span id="导出全局配置的内容"></span>
## 导出全局配置的内容

可导出全局配置中的规则和关联域名列表。导出文件为 `.txt` 格式。


|导出内容 |文件名格式 |
|---|---|
|规则 |`CDN_<catalog-name>_Rule_<export-time>` |
|关联域名列表 |`CDN_<catalog-name>_Domain_<export-time>` |


`<export-time>` 使用 `YYYYMMDDHHMMSS` 格式。例如：`CDN_test_Rule_20230518114139`。

<span id="操作步骤"></span>
### 操作步骤


1. 在 **全局配置** 页面找到目标全局配置，单击 **修改**。

2. 在 **配置详情** 页面的 **规则清单** 上方，单击 **导出**，导出规则。

3. 在 **关联域名** 上方，单击 **导出**，导出关联域名列表。
