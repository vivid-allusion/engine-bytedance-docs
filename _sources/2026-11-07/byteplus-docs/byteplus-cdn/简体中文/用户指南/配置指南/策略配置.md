<span id="概述"></span>
## 概述

在 CDN 中，策略的配置是基于版本来管理的。策略的配置包含 CDN 特性的配置和源站配置。当您创建一个策略时，该策略就有了一个初始版本。要修改策略的配置，您需要执行以下步骤：


1. 为策略创建一个草稿版本。

2. 更新草稿版本中策略的配置。

3. 发布该草稿版本。


另外，策略版本允许您将策略的配置回滚到一个旧版本。您还可以复制特定版本并更新复制版本中的策略配置。在发布或回滚策略版本时，建议您添加有意义的说明，以便后期维护。例如，当您后期需要查看、复制或者删除一个版本时，版本说明可以帮助您定位要操作的版本。

<span id="版本状态"></span>
### **版本状态**

策略版本有以下几种状态：


* 运行中：表示版本已发布，版本中策略的配置正在生效。

* 暂停：表示版本之前是发布，但已撤回，版本中策略的配置不再生效。

* 草稿：表示版本还未发布。


只有当版本的状态是 "草稿" 时，您才能修改版本中策略的配置。

下表列出了各个状态下您可以对版本执行的操作。


|**版本状态** |**允许的操作（Y 表示允许）**  ||||||
|---|---|---|---|---|---|---|
||**查看** |**修改** |**回滚** |**发布** |**删除** |**复制** |
|草稿 | |Y | |Y |Y | |
|运行中 |Y | | | | |Y |
|暂停 |Y | |Y | |Y |Y |


<span id="版本号"></span>
### **版本号**

当您发布一个版本时，CDN 就会为该版本生成一个版本号。

版本号的命名规范是 `P-<first_publish_date>-<random_5_digits>`。例如 `P-250224.44093`。

草稿状态下的策略没有版本号，**版本号** 列显示的是 `draft`。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">每个策略最多记录 50 个已发布的版本。</div>


<span id="操作说明"></span>
## 操作说明

<span id="查看版本中策略的配置"></span>
### 查看版本中策略的配置

对于状态是 "运行中" 或 "暂停" 的版本，您可以查看版本中策略的配置。策略的配置是以 API 参数形式展示。要了解各参数的含义，参见 [UpdateServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-updateservicetemplate-cn) 和 [UpdateCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-updateciphertemplate-ac087-cn)。

要查看特定版本中策略的配置，有以下两种方法。

<span id="方法一：在策略详情页面查看"></span>
#### **方法一：在策略详情页面查看**


1. 在策略列表中，找到您要查看的策略，然后点击该策略的 ID。

2. 在策略详情页面右上方的版本列表中，选择您要查看的版本。


在您选择了要查看的版本后，策略详情页面中显示的就是该版本中策略的配置。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">版本列表中的版本按创建时间排序。最近创建的版本显示在最前面。</div>


* <div data-tips="true" data-tips-type="tip">版本列表中显示的是版本号，无版本说明。如果您需要基于版本说明来选择需要查看的版本，请使用方法二。</div>



<span id="方法二：在-策略版本-标签页中查看"></span>
#### **方法二：在 "策略版本" 标签页中查看**


1. 在策略列表中，找到您要查看的策略。

2. 在 **操作** 列，点击 **历史**。

3. 在 **版本管理** 标签页中，点击 **策略版本**。

4. 在版本列表中，找到您要查看的版本。

5. 在 **操作** 列，点击 **查看**。


<span id="创建版本"></span>
### 创建版本

要创建一个策略版本，遵循以下步骤：


1. 在策略列表中，找到您要操作的策略。

2. 点击策略 ID 打开策略详情页面。

3. 在页面右上方，点击 **创建版本**。


在您点击 **创建版本** 后，CDN 会对状态为 "运行中" 的版本进行复制，以生成一个状态为 "草稿" 的版本，版本号是 `draft`。同时，**创建版本** 按钮会置灰。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">您点击 <strong>创建版本</strong> 后，策略详情页面展示的并非草稿版本中的策略配置，而是状态为 "运行中" 版本中的策略配置，</div>


* <div data-tips="true" data-tips-type="tip">一个策略只能有一个状态为 "草稿" 的版本。也就是说，如果策略中已存在状态为 "草稿" 的版本，<strong>创建版本</strong> 按钮会置灰，您无法创建版本。</div>



<span id="修改版本中策略的配置"></span>
### 修改版本中策略的配置

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能修改状态为 "草稿" 的版本中策略的配置。</div>


要修改版本中策略的配置，遵循以下步骤：


1. 在策略列表中，找到您要操作的策略。

2. 在 **操作** 列，点击 **历史**。

3. 在 **版本管理** 标签页中，点击 **策略版本**。

4. 在版本列表中，找到您要操作的版本。

5. 在 **操作** 列，点击 **修改**。

6. 在策略详情页面，点击 **策略配置** 标签页。

7. 修改策略的配置。

8. 修改完成后，在页面右下方点击 **保存**。


<span id="发布版本"></span>
### 发布版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能发布状态为 "草稿" 的版本。</div>


要使一个草稿版本中策略的配置生效，您需要发布该版本。版本发布后，版本中策略的配置会应用于所有与该策略绑定的域名。

要发布一个版本，遵循以下步骤：


1. 在策略列表中，找到您要操作的策略。

2. 在 **操作** 列，点击 **历史**。

3. 在 **版本管理** 标签页中，点击 **策略版本**。

4. 在版本列表中，找到您要操作的版本。

5. 在 **操作** 列，点击 **发布**。

6. 在 **发布策略** 对话框，输入一个有意义的版本说明，然后点击 **确定**。


版本发布后，该版本的状态会从 "草稿" 变成 "运行中"。之前发布的版本状态会从 "运行中" 变成 "暂停"。

<span id="回滚版本"></span>
### 回滚版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能回滚状态为 "暂停" 的版本。</div>


对于一个状态为 "暂停" 的版本，如果您需要该版本中策略的配置生效，您可以对该版本进行回滚操作。当您回滚一个状态为 "暂停" 的版本时，CDN 会立刻发布该版本。

要回滚一个版本，遵循以下步骤：


1. 在策略列表中，找到您要操作的策略。

2. 在 **操作** 列，点击 **历史**。

3. 在 **版本管理** 标签页中，点击 **策略版本**。

4. 在版本列表中，找到您要回滚的版本。

5. 在 **操作** 列，点击 **回滚**。

6. 在 **发布策略** 对话框，输入一个有意义的版本说明，然后点击 **确定**。


<span id="复制版本"></span>
### 复制版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能复制状态为 "运行中" 或 "暂停" 的版本。</div>


如果您需要基于某个版本对策略的配置进行修改，您可以复制该版本。

当您复制一个版本时，CDN 执行以下操作：


* 创建一个与被复制版本相同的版本。创建后的版本状态是 "草稿"。


要复制一个版本，遵循以下步骤：


1. 在策略列表中，找到您要操作的策略。

2. 在 **操作** 列，点击 **历史**。

3. 在 **版本管理** 标签页中，点击 **策略版本**。

4. 在版本列表中，找到您要复制的版本。

5. 在 **操作** 列，点击 **复制**。


需要留意的是，如果存在状态为 "草稿" 的版本，复制操作生成的版本将覆盖草稿版本。

<span id="删除版本"></span>
### 删除版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">您只能删除状态为 "暂停" 或 "草稿" 的版本。</div>


* <div data-tips="true" data-tips-type="tip">删除后的版本无法恢复。</div>



如果您不再需要某个版本，您可以删除该版本。
