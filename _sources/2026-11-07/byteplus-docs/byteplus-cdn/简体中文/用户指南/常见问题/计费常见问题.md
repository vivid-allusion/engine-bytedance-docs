<span id="如何查看-cdn-账单"></span>
## **如何查看 CDN 账单**

您可以在 [BytePlus 费用中心](https://console.byteplus.com/financial/overview) 查看 CDN 账单。

<span id="如何免费试用或测试-cdn"></span>
## 如何免费试用或测试 CDN

在开通 CDN 后，您可以免费领取一个流量资源包和一个请求数资源包，容量分别是 1TB 和 10,000,000 个请求，有效期是自领取日开始 1 年。您可以使用这两个资源包试用或者测试 CDN。您可以在 [CDN 控制台的资源管理页面](https://console.byteplus.com/financial/resource-package) 查看资源包的余量。

<span id="如何变更-cdn-的计费方式"></span>
## **如何变更 CDN 的计费方式**

在您开通 CDN 时，默认的计费方式是按流量计费，按小时扣费，先用后付。如果您需要使用其他计费方式，请 [提交工单](https://console.byteplus.com/workorder/create)。

<span id="cdn-中间层的节点产生的流量会收费吗"></span>
## **CDN 中间层的节点产生的流量会收费吗**

CDN 仅对边缘节点响应用户请求时产生的流量收费。中间层节点产生的流量不收费。

<span id="为什么-cdn-账单中显示的流量和日志中记录的流量不一致"></span>
## **为什么 CDN** 账单中显示的流量**和日志中记录的流量不一致**

CDN 提供了账单、用量查询、监控页面、API 和日志等多种数据来源。这些数据来源的使用场景不同，统计口径和统计方式也不同。因此，您在对比同一域名、同一时间段的数据时，可能会看到流量、带宽或请求数不完全一致。


|数据类型 |适用场景 |相关文档 |
|---|---|---|
|计费用量数据 |适合用于核对账单和导出计费用量。 |[用量查询](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-usage-query-cn)、[计费说明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-pricing-cn)、[如何查看 CDN 账单](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-billing-cn#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B-cdn-%E8%B4%A6%E5%8D%95) |
|实时监控数据 |适合用于观察流量、带宽、请求数、状态码等业务趋势，数据实时性较高。 |[边缘监控](https://docs.byteplus.com/en/docs/byteplus-cdn/nqffUP)、[源站监控](https://docs.byteplus.com/en/docs/byteplus-cdn/2Dbv8V)、[业务分析](https://docs.byteplus.com/en/docs/byteplus-cdn/W9B_Xh)、[DescribeEdgeData](https://docs.byteplus.com/en/docs/byteplus-cdn/DescribeEdgeData) |
|离线日志数据 |适合用于请求级明细分析，例如按请求 URL、状态码、客户端 IP 等字段进行统计。 |[日志下载](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-logs-cn)、[离线日志转存](https://docs.byteplus.com/en/docs/byteplus-cdn/log-batch-delivery_zh-cn) |


如果您需要核对账单，请优先参考账单、用量查询或用量导出中的数据。计费用量数据对准确性要求更高，因此 CDN 会采用离线统计方案，在保证准确性的同时可能牺牲一部分实时性。

如果您对比的是计费用量数据与离线日志数据，差异主要来自统计层级不同。CDN 日志记录的是应用层请求数据，计费用量数据统计的是缓存节点响应请求时在网络传输层产生的数据。对于一个用户请求，计费用量数据中的流量通常包含以下两部分：


* 请求文件本身的流量。该流量与 CDN 日志中记录的流量相同。

* TCP/IP 包头以及 TCP 重传所产生的流量。该流量通常会使计费用量数据中的流量高于日志中记录的流量，差异约为 10%。


其中，TCP/IP 包头是操作系统内核层的协议栈在传输过程中添加的，CDN 日志无法在应用层统计到这部分数据。在不统计 TCP 重传、TCP 三次握手、TCP 四次挥手过程中的包头时，包头产生的流量大约是日志中记录的流量的 4.52%。同时，在 TCP 包传输过程中，如果因为网络抖动等原因发生丢包，服务器会重传丢失的包。重传产生的流量通常大约是日志中记录的流量的 3%\-7%。因此，计费用量数据中的流量通常会比日志中记录的流量高约 10%。

如果您对比的是实时监控数据与离线日志数据，例如使用 `DescribeEdgeData` API 查询请求数或流量，并将查询结果与离线日志统计结果进行对比，也可能会看到少量差异。虽然两者采集的都是七层数据，但实时监控数据更强调实时性，适合用于观察业务趋势；离线日志数据更适合用于请求级明细分析。由于两类数据的数据采集链路、统计口径和统计方式不同，在同一时间段内进行对比时，可能存在细微差异。

如果差异超出预期，或影响您的账单核对，请 [提交工单](https://console.byteplus.com/workorder/create) 联系我们协助排查，并提供域名、时间范围、API 请求参数、离线日志包名称和您的统计方式。

<span id="cdn-带宽使用的单位-1gbps-等于多少-mbps？"></span>
## CDN 带宽使用的单位 1Gbps 等于多少 Mbps？

带宽使用的进制是 1,000。也就是说：1Gbps = 1000 Mbps、1Mbps = 1000 Kbps、1Kbps = 1000 bps

<span id="cdn-流量使用的单位-1gb-等于多少-mb"></span>
## **CDN 流量使用的单位 1GB 等于多少 MB**

流量使用的进制是 1,000。也就是说：1GB = 1000 MB、1MB = 1000 KB、1KB = 1000 B

<div data-tips="true" data-tips-type="tip">GB 和 GiB 是不同的单位。MB 和 MiB，KB 和 KiB 也是如此。</div>


<div data-tips="true" data-tips-type="tip">GiB，MiB，KiB 使用的进制是 1,024。</div>


<span id="如何退订-cdn-服务"></span>
## **如何退订 CDN 服务**

CDN 服务开通后，您无法使用控制台或者某个 API 退订 CDN 服务。如果您需要退订 CDN 服务，请 [提交工单](https://console.byteplus.com/workorder/create)。

<span id="cdn-在响应-4xx-状态码时是否会产生费用"></span>
## CDN 在响应 4xx 状态码时是否会产生费用

简短回答：“是的”。

CDN 允许您配置访问控制规则，阻止恶意请求访问您的域名。例如，CDN 提供了 Referer 黑白名单、URL 鉴权、Origin 黑白名单、UA 黑白名单、远程鉴权、地域访问控制等访问控制功能。

当收到用户请求时，如果请求符合您配置的访问控制规则，CDN 拒绝这些请求并响应 4xx 状态码。虽然响应中没有文件，但响应中包含了响应头，响应正文也包含特定消息。这些响应被视为 CDN 向用户传输的数据。

因此，状态码为 4xx 的 CDN 响应所产生的流量和带宽使用量会被计费。同时，被拒绝的请求会被计入 CDN 收到的请求数量而被计费。您的账单中会包含这部分的费用。

需要留意的是，如果您的域名收到的恶意请求量很大，这些被拒绝的请求仍有可能在 "请求数" 这个计费项上产生高额账单。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">响应状态码非 2xx 和 4xx 的用户请求也会产生流量和带宽使用量，以及被计入请求数量而被计费。</div>
