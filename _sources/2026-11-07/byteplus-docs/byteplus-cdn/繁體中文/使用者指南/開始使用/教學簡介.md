感謝您選擇 BytePlus CDN。本教學基於一個通用情境，指導您將網域名稱接入 CDN，加速您網站內容的分發。在您的網站接入 CDN 後，使用者向您網站的請求會被路由到 CDN，由 CDN 負責向您的網站取得內容並回應使用者的請求。

<span id="情境"></span>
## 情境

您有一個網站 www.example.com，其 IP 位址是 203.0.113.8。網站僅允許使用 HTTPS 協定的請求。

隨著業務的成長，您頻繁收到使用者反饋網站頁面開啟慢，偶爾會出現頁面無法開啟的情況。為了保障使用者體驗，您選擇了 BytePlus CDN 為您網站內容的分發加速。

在使用 BytePlus CDN 之前，您首先需要註冊一個 BytePlus 帳號。本教學假設您已成功註冊了 BytePlus 帳號。
