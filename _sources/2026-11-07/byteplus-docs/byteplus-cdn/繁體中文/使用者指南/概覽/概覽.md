BytePlus CDN 是一個具有超過 3500 個邊緣伺服器的內容分發網路，這些節點戰略性地分布在各個地理位置。CDN 擁有超過 150 Tbps 的頻寬容量，能夠在接近終端使用者的邊緣伺服器快取內容。邊緣伺服器的這種戰略性位置在降低延遲方面起著至關重要的作用，確保更快的內容傳遞，從而顯著提高網站效能和使用者體驗。

CDN 旨在提供加速和更可靠的網頁內容傳遞，有效縮短數據源與終端使用者之間的距離。這種網路架構對於加快網站載入時間、提高視頻流質量和減少檔案下載時間至關重要。這些功能對於應對現代數據密集型線上環境的需求至關重要。

## 工作原理

當您的域名接入 CDN 後，CDN 會負責處理使用者請求。如果請求的檔案未被 CDN 快取，CDN 會先向來源伺服器請求該檔案。當收到來自來源伺服器的檔案後，CDN 會快取該檔案。之後，如果收到了該檔案的後續請求，CDN 不再向來源伺服器請求該檔案，而是將快取中的檔案返回給使用者。這降低了來源伺服器的流量，從而降低了伺服器託管的頻寬成本和伺服器故障機率。

假設使用者請求您站點上的一個檔案。檔案的 URL 是 `https://www.example.com/file`。請求的過程如下：

1. 使用者在瀏覽器的地址欄中輸入 `https://www.example.com/file`。

2. 基於對 `www.example.com` 的 DNS 解析，瀏覽器獲得一個 CDN 邊緣伺服器的 IP 地址。該邊緣伺服器離使用者最近。

3. 瀏覽器向該邊緣伺服器請求該檔案。

   > **说明**

   > 如果該邊緣伺服器還未快取請求的檔案，CDN 會先向來源伺服器請求該檔案。當收到來自來源伺服器的檔案後，CDN 會快取該檔案。

4. CDN 將快取的檔案發送給使用者。

## CDN 的優勢

CDN 的優勢包括：

* **改善使用者體驗**

   CDN 支援包括 HTTP/HTTPS 和 QUIC 在內的現代協議，並利用自主開發的快取軟體提升站點內容傳遞的效能。基於其多級快取架構，CDN 能更快地交付大檔案、靜態圖像和流媒體等數據。

* **高靈活性和穩定效能**

   憑藉自主開發的資源規劃系統和即時資源調度與分配系統，它可以智能穩定地分配使用者請求並提供內容。

* **速度與安全的完美平衡**

   CDN 使用 HTTPS 實現端到端數據加密，確保數據安全傳輸，並保護您的網站免受盜鏈和會話劫持的威脅。它允許您通過提供 Referer 黑名單和白名單、IP 黑名單和白名單以及 URL 驗證來配置訪問控制。

* **多維度監控**

   CDN 與監控緊密整合，提供詳細的數據傳輸、頻寬和每日/每週/每月請求的指標。

* **支援動態資源的傳輸加速**

   對於動態資源，CDN 基於路徑探測技術，選擇最佳路徑將請求轉發到來源伺服器，為用戶端快速獲取動態資源。
