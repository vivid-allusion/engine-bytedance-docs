<span id="如何查看-cdn-帳單"></span>
## **如何查看 CDN 帳單**

您可以在 [BytePlus 費用中心](https://console.byteplus.com/financial/overview) 查看 CDN 帳單。

<span id="如何免費試用或測試-cdn"></span>
## 如何免費試用或測試 CDN

在開通 CDN 後，您可以免費領取一個流量資源包和一個請求數資源包，容量分別是 1TB 和 10,000,000 個請求，有效期是自領取日開始 1 年。您可以使用這兩個資源包試用或者測試 CDN。您可以在 [CDN 控制台的資源管理頁面](https://console.byteplus.com/financial/resource-package) 查看資源包的餘量。

<span id="如何變更-cdn-的計費方式"></span>
## **如何變更 CDN 的計費方式**

在您開通 CDN 時，預設的計費方式是按流量計費，按小時扣費，先用後付。如果您需要使用其他計費方式，請 [提交工單](https://console.byteplus.com/workorder/create)。

<span id="cdn-區域伺服器產生的流量會收費嗎"></span>
## **CDN 區域伺服器產生的流量會收費嗎**

CDN 僅對邊緣伺服器回應使用者請求時產生的流量收費。區域伺服器產生的流量不收費。

<span id="為什麼-cdn-帳單中顯示的流量和日誌中記錄的流量不一致"></span>
## **為什麼 CDN 帳單中顯示的流量和日誌中記錄的流量不一致**

CDN 提供帳單、用量查詢、監控頁面、API 和日誌等多種資料來源。這些資料來源的用途不同，統計範圍與計算方式也不同。因此，當您比較同一個網域在同一段時間內的資料時，看到的流量、頻寬或請求數可能不完全一致。


|資料來源 |適用情境 |相關文件 |
|---|---|---|
|計費用量資料 |用於核對帳單及匯出計費用量。 |[用量查詢](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-usage-query-cn-tw)、[計費說明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-pricing_zh-tw)、[如何查看 CDN 帳單](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-billing-cn-tw#%E5%A6%82%E4%BD%95%E6%9F%A5%E7%9C%8B-cdn-%E5%B8%B3%E5%96%AE) |
|即時監控資料 |觀察流量、頻寬、請求數、狀態碼等指標的變化趨勢。這類資料的即時性較高。 |[邊緣監控](https://docs.byteplus.com/en/docs/byteplus-cdn/edge-report_zh-tw)、[源站監控](https://docs.byteplus.com/en/docs/byteplus-cdn/origin-server-report_zh-tw)、[業務分析](https://docs.byteplus.com/en/docs/byteplus-cdn/insight_zh-tw)、[DescribeEdgeData](https://docs.byteplus.com/en/docs/byteplus-cdn/reference-DescribeEdgeData_zh-tw) |
|離線日誌資料 |請求層級的明細分析，例如依請求 URL、狀態碼或用戶端 IP 位址彙總資料。 |[日誌下載](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-logs-cn-tw)、[離線日誌轉存](https://docs.byteplus.com/en/docs/byteplus-cdn/log-batch-delivery_zh-tw) |


如需核對帳單，請優先參考帳單、用量查詢或用量匯出資料。計費用量資料需要更高的準確性，因此 CDN 會透過離線統計流程確保準確性；相較於監控資料，資料更新的即時性可能較低。

如果您比較的是計費用量資料與離線日誌資料，差異主要來自資料量測的層級不同。CDN 日誌記錄的是應用層請求資料，計費用量資料則統計快取節點回應使用者請求時，在傳輸層產生的流量。以單一使用者請求為例，計費用量資料中的流量通常包含以下兩部分：


* 請求檔案本身的流量。這部分流量與 CDN 日誌中記錄的流量相同。

* TCP/IP 標頭以及 TCP 重傳所產生的流量。這部分流量通常會使計費用量資料中的流量比日誌中記錄的流量高約 10%。


TCP/IP 標頭是作業系統核心的協定堆疊在傳輸過程中加入的，因此 CDN 日誌無法在應用層記錄這部分資料。若不計入 TCP 重傳、TCP 三向交握，以及 TCP 連線終止（四次揮手）過程中的標頭，標頭產生的流量約為日誌記錄流量的 4.52%。此外，在 TCP 封包傳輸過程中，如果因網路不穩定或抖動導致封包遺失，伺服器會重傳遺失的封包。重傳產生的流量通常約占日誌記錄流量的 3% 到 7%。因此，計費用量資料中的流量通常會比日誌中記錄的流量高約 10%。

如果您比較的是即時監控資料與離線日誌資料，也可能會看到細微差異。例如，使用 `DescribeEdgeData` API 查詢請求數或流量，並將查詢結果與離線日誌統計結果比較時，就可能出現這種情況。雖然兩者收集的都是第 7 層（應用層）資料，但即時監控資料更重視即時性與趨勢觀察，離線日誌資料則更適合用於請求層級的明細分析。由於兩類資料的收集流程、統計範圍與計算方式不同，即使在同一時間範圍內比較，也可能出現細微差異。

如果差異超出預期，或影響您的帳單核對，請[提交工單](https://console.byteplus.com/workorder/create)。請一併提供網域、時間範圍、API 請求參數、離線日誌檔案名稱，以及您的計算方式，以便我們協助調查。

**TCP 重傳**

在 TCP 包傳輸的過程中，會因為網路抖動等原因導致 3%\-10% 的 TCP 包丟失。伺服器會重傳丟失的包。由於重傳也是由作業系統內核層的協議棧進行的，CDN 日誌無法統計到重傳的 TCP 包。一般情況下，重傳的 TCP 包所產生的流量大約是 CDN 日誌統計的流量的 3%\-7%。

<span id="cdn-頻寬使用的單位-1gbps-等於多少-mbps？"></span>
## CDN 頻寬使用的單位 1Gbps 等於多少 Mbps？

頻寬使用的進制是 1,000。也就是說：1Gbps = 1000 Mbps、1Mbps = 1000 Kbps、1Kbps = 1000 bps

<span id="cdn-流量使用的單位-1gb-等於多少-mb"></span>
## **CDN 流量使用的單位 1GB 等於多少 MB**

流量使用的進制是 1,000。也就是說：1GB = 1000 MB、1MB = 1000 KB、1KB = 1000 B

<span id="如何退訂-cdn-服務"></span>
## **如何退訂 CDN 服務**

CDN 服務開通後，您無法使用控制台或者某個 API 退訂 CDN 服務。如果您需要退訂 CDN 服務，請 [提交工單](https://console.byteplus.com/workorder/create)。

<span id="cdn-在回應-4xx-狀態碼時是否會產生費用"></span>
## CDN 在回應 4xx 狀態碼時是否會產生費用

簡短回答："是的"。

CDN 允許您配置存取控制規則，阻止惡意請求存取您的域名。例如，CDN 提供了 Referer 黑白名單、URL 鑑權、Origin 黑白名單、UA 黑白名單、遠端鑑權、地域存取控制等存取控制功能。

當收到使用者請求時，如果請求符合您配置的存取控制規則，CDN 拒絕這些請求並回應 4xx 狀態碼。雖然回應中沒有檔案，但回應中包含了回應頭，回應正文也包含特定訊息。這些回應被視為 CDN 向使用者傳輸的資源。

因此，狀態碼為 4xx 的 CDN 回應所產生的流量和頻寬使用量會被計費。同時，被拒絕的請求會被計入 CDN 收到的請求數量而被計費。您的帳單中會包含這部分的費用。

需要留意的是，如果您的域名收到的惡意請求量很大，這些被拒絕的請求仍有可能在 "請求數" 這個計費項目上產生高額帳單。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">回應狀態碼非 2xx 和 4xx 的使用者請求也會產生流量和頻寬使用量，以及被計入請求數量而被計費。</div>
