<span id="ip-檢測"></span>
## IP 檢測

在您的網站接入 CDN 後,如果您網站頁面的存取速度不達預期,可以使用該工具檢查使用者存取的 IP 位址是否是一個 CDN 節點的 IP 位址。

您一次最多可以查詢 50 個 IPv4 和 IPv6 位址。多個 IP 位址以換行或者分號（;）分隔 。

如果一個 IP 位址是 CDN 節點的 IP 位址,檢查結果還會額外顯示該 IP 位址的歸屬地。如果歸屬地是中國,檢查結果還會額外顯示該 IP 位址所屬的網路運營商。

<span id="操作步驟"></span>
### 操作步驟


1. 登入 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左側導覽列,點擊 **工具中心** \> **診斷工具**。

3. 在 **診斷工具** 頁面,點擊 **IP 檢測** 下方的 **開始使用**。

4. 在 **IP 歸屬查詢** 頁面,輸入需要查詢的 IP 位址,然後點擊 **查詢**。


<span id="網域名稱對比"></span>
## 網域名稱對比

該工具用於對比兩個網域名稱的配置差異。該工具調用 DescribeCdnConfig API 獲取指定網域名稱的配置,然後高亮顯示 API 層面的配置差異。

關於對比結果中各參數的定義,參見 [DescribeCdnConfig](https://docs.byteplus.com/en/docs/byteplus-cdn/DescribeCdnConfig_zh-tw)。

<span id="操作步驟"></span>
### 操作步驟


1. 登入 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左側導覽列,點擊 **工具中心** \> **診斷工具**。

3. 在 **診斷工具** 頁面,點擊 **網域名稱對比** 下方的 **開始使用**。

4. 在 **配置差異** 頁面,指定需要對比的網域名稱,然後查看網域名稱配置的差異。


<span id="策略對比"></span>
## 策略對比

該工具用與對比兩個策略的配置差異。對比結果展示在以下標籤頁中：


* 基礎資訊：展示兩個策略在基礎資訊上的差異。

* 配置：展示兩個策略在 CDN 特性配置上的差異。

* 綁定網域名稱列表：展示兩個策略所綁定的網域名稱的差異。


在使用該工具時,您需要指定策略類型,然後選擇兩個策略獲取配置差異。


* 如果策略類型是分發策略,該工具調用 DescribeServiceTemplate API 獲取兩個策略的配置,然後在這三個標籤頁中顯示配置差異。

* 如果策略類型是加密策略,該工具調用的是 DescribeCipherTemplate API。


在 **配置** 標籤頁中,該工具高亮顯示 API 層面 CDN 特性的配置差異。關於對比結果中各參數的定義,


* 如果您對比的是兩個分發策略,參見 [DescribeServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeservicetemplate-00652-cn)。

* 如果您對比的是兩個加密策略,參見 [DescribeCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-describeciphertemplate-f8c12-cn)。


<span id="操作步驟"></span>
### 操作步驟


1. 登入 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左側導覽列,點擊 **工具中心** \> **診斷工具**。

3. 在 **診斷工具** 頁面,點擊 **策略對比** 下方的 **開始使用**。

4. 在 **策略差異** 頁面,指定策略類型,然後指定需要對比的策略。
