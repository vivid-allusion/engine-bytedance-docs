本文件介紹 BytePlus CDN 提供的「即時日誌投遞」服務。關於該服務與另外兩種 CDN 日誌獲取方式的區別，請參見 [日誌管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-tw)。

<span id="什麼是即時日誌投遞"></span>
## 什麼是即時日誌投遞

對於 CDN 收到的使用者請求，也就是服務區域內各 CDN 節點收到使用者請求，您可以設定「即時日誌投遞」，將請求日誌投遞到您指定的目的地。

即時日誌從日誌收集到日誌投遞的時間間隔不超過 5 分鐘。即時日誌可用於監控資料指標、偵測安全風險、洞察業務趨勢等。關於即時日誌中包含的欄位，請參見 [日誌欄位](https://docs.byteplus.com/en/docs/18/48601#%E6%97%A5%E8%AA%8C%E6%AC%84%E4%BD%8D)。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDN 整合了 TLS 中的日誌檢索功能。如果您將即時日誌投遞到 TLS，您無需離開 CDN 主控台即可對日誌進行檢索，請參見 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/log-query-examples_zh-tw">日誌檢索範例</a>。</div>


<span id="使用情境"></span>
## 使用情境

[日誌管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-tw) 簡略描述了即時日誌的使用情境。本章節描述了更具體的使用情境。

即時日誌可以幫助您分析網域名稱遇到的問題，也可以幫助您了解使用者是如何存取您的網域名稱。除了對即時日誌進行過濾，您還可以對日誌資料進行處理，滿足不同情境下的日誌分析需求。


|**日誌分析情境** |**作用描述** |
|---|---|
|過濾指定條件的日誌 |指定一個或多個條件過濾日誌。例如，您可以基於 URL、IP 位址、時間範圍過濾日誌，以分析某個 IP 位址在指定時間範圍內對特定 URL 的請求，以便及時定位問題。 |
|監測 CDN 服務指標 |指標資料可以幫助您了解 CDN 服務的品質以及使用者的存取效率，以便您及時發現異常。存取效率包括快取命中率、CDN 回應耗時、資料傳輸速度等。 |
|監測 CDN 存取錯誤 |如果使用者在存取網域名稱時出現了問題，該資料可以幫助您定位問題的原因。例如 URL 問題、來源伺服器故障、來源伺服器檔案存取異常等。 |
|獲取熱門存取 |該資料可以幫助您了解使用者請求中的熱門物件。例如熱門網域名稱、熱門 URI、熱門訪客 IP、熱門 Referer 等。 |


<span id="即時日誌計費"></span>
## 即時日誌計費

即時日誌功能是收費的。費用由以下部分組成：


* 日誌投遞的費用。CDN 對投遞的日誌進行計費。計費單位是萬條。關於日誌投遞計費的詳細資訊，請參見 [（購買頁無繁中鏈接）收費說明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-pricing_zh-tw)。

* 日誌服務 (TLS) 的費用。TLS 對日誌儲存、日誌的讀寫流量等進行計費。關於 TLS 計費的詳細資訊，請參見 [TLS 計費說明](https://docs.byteplus.com/en/docs/tls/billable_items)。


<span id="日誌欄位"></span>
## 日誌欄位

CDN 投遞的請求日誌中包含以下欄位：


|**欄位** |**說明** |**範例** |
|---|---|---|
|time |表示 CDN 完成回應請求的時間，也就是 CDN 傳輸完檔案最後一個位元組的時間。 |`23/Oct/2022:17:48:59 +0800` |
|client_ip |表示傳送請求的用戶端 IP 位址。 |`192.0.2.1` |
|client_ip_country |表示用戶端 IP 位址所歸屬的國家。 |`印尼` |
|client_ip_isp |表示用戶端 IP 位址所歸屬的網路營運商。 |`Tencent Cloud` |
|client_ip_province |表示用戶端 IP 位址所歸屬的城市。 |`雅加達` |
|client_port |表示請求使用的用戶端連接埠。 |`37030` |
|domain |表示請求 URL 中的網域名稱，也就是您的網域名稱。 |`cdn.example.com` |
|ds_http_bd_status_hit |表示請求是否命中 CDN 的快取。該參數的取值如下：<br><br><br>* `HIT`：表示請求命中 CDN 的快取。<br><br>* `MISS`：表示請求未命中 CDN 的快取。 |`HIT` |
|ds_http_method |表示請求使用的方法。 |`GET` |
|ds_http_protocol |表示請求使用的 HTTP 協定版本。 |`HTTP/3` |
|ds_http_range |表示請求中 Range 標頭的值。如果請求不包含該標頭，該參數值為 `-`。 |`bytes=200-1000` |
|ds_http_referer |表示請求中 Referer 標頭的值。如果請求不包含該標頭，該參數值為 `-`。 |`https://example.com/index?version=123` |
|ds_http_resp_content_length |表示請求檔案的大小。單位是 bytes。 |`500` |
|ds_http_resp_content_type |表示 CDN 回應中 Content\-Type 標頭的值。如果回應不包含該標頭，該參數值為 `-`。 |`image/jpeg` |
|ds_http_resp_size |表示 CDN 向使用者傳輸的資料量，單位是 bytes。 |`573` |
|ds_http_scheme |表示請求 URL 中的 scheme。 |`HTTPS` |
|ds_http_status |表示 CDN 的回應狀態碼。 |`200` |
|ds_http_ua |表示請求中 User\-Agent 標頭的值。如果請求不包含該標頭，該參數值為 `-`。 |`curl/7.85.0` |
|ds_http_uri |表示請求 URL 中的路徑和查詢字串，以斜線 (/) 開頭。 |`/chickadee.png?version=1` |
|ds_http_uri_path |表示請求 URL 中的路徑，以斜線 (/) 開頭。 |`/img/chickadee.png` |
|ds_http_uri_query |表示請求 URL 中的查詢參數。 |`version=1&colar=red` |
|ds_req_time |表示 CDN 回應使用者請求所耗費的平均時間，單位是秒。 對於一個使用者請求，CDN 的回應耗時是以下兩個時間點之間的時間跨度：<br><br><br>* CDN 完成接收使用者請求的最後一個位元組。<br><br>* CDN 完成傳輸請求檔案的最後一個位元組。 |`0.104` |
