<span id="overview-tw"></span>
## 概觀

BytePlus CDN 提供了 ["用量封頂" ](https://console.byteplus.com/cdn/cdn-bp/tools/consumption-limit)。在該頁面中，您可以為網域名稱建立監控策略。在監控策略中，您需要指定監控指標、統計週期以及用量門檻值。監控策略建立後，CDN 就開始監控網域名稱的用量。如果某個統計週期內網域名稱的用量超過門檻值，CDN 會停用網域名稱一段時間，以防止用量的持續增長。每個統計週期內，CDN 最多停用網域名稱一次。該功能主要適用於需要嚴格控制 CDN 成本、防止因流量突增或惡意攻擊導致產生預期外費用的場景。本文將為您介紹如何設定和使用用量封頂功能。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_85ed82439bb8f772c355deb5cf9f0406.png) </span>

在監控策略中，您還可以指定網域名稱的停用時長。網域名稱停用期結束時，CDN 會重新啟用該網域名稱。此外，您還可以在監控策略中為用量設定告警門檻值，以便在用量達到告警門檻值時收到通知。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">網域名稱停用期間，您可以隨時手動啟用您的網域名稱。</div>


* <div data-tips="true" data-tips-type="tip">網域名稱停用期結束時，如果存在以下任意情況，CDN 將無法重新啟用您的網域名稱。</div>


   * <div data-tips="true" data-tips-type="tip">您的帳戶有欠費。</div>


   * <div data-tips="true" data-tips-type="tip">您在網域名稱停用期間修改了網域名稱設定。</div>


   * <div data-tips="true" data-tips-type="tip">其他不常見情況。這些情況這裡不一一列舉。如果您的場景中不存在前兩個情況，但是 CDN 仍然無法啟用您的網域名稱，請 <a href="https://console.byteplus.com/workorder/create">提交工單</a>。</div>


* <div data-tips="true" data-tips-type="tip">對於 CDN 來說，採集指標資料、分析資料、停用網域名稱都需要一定的時間。因此，用量超過門檻值的時間與 CDN 停用網域名稱的時間之間可能會有 15 分鐘的延遲。期間，網域名稱的用量仍然會計費。</div>



<span id="notifications-tw"></span>
## 通知

當網域名稱被停用、網域名稱被重新啟用或者網域名稱的用量達到告警門檻值時，CDN 會透過郵件和站內信向您傳送相應的通知。

<span id="notification-content-tw"></span>
### 通知內容

以下為通知中主要內容的範例：


* Under your BytePlus account xxxxxxxxxx /example ,Domain www.example.com was triggering the usage cap policy you configured.


<span id="procedure-tw"></span>
## 操作步驟


1. 開啟 ["用量封頂" 頁面](https://console.byteplus.com/cdn/cdn-bp/tools/consumption-limit)。

2. 點擊 **建立策略** 建立一個監控策略。

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_9677ec7386b5a3eac433c5cdd93e2db1.png) </span>


<span id="configuration-description-tw"></span>
## 設定說明


|**設定** |**說明** |
|---|---|
|網域名稱 |表示待監控的網域名稱。您需要從列表中選擇一個網域名稱。也可以輸入一個網域名稱。 |
|統計方式 |表示監控指標的資料統計方式。該設定有以下選項：<br><br><br>* 瞬間用量：表示以指標的峰值資料作為統計週期內的指標資料，應用於頻寬和 QPS 這兩個指標。<br><br>* 累計用量：表示以指標的累計資料作為統計週期內的指標資料，應用於流量和請求數這兩個指標。 |
|統計週期 |表示指標資料的統計時間粒度。CDN 對每個統計週期內的網域名稱用量都是分別統計的。在每個統計週期內，CDN 每 5 分鐘對當前統計週期統計網域名稱的用量。<br><br><br>* 如果 **統計方式** 是 **瞬間用量**，該設定只能是 **每 5 分鐘**。<br><br>* 如果 **統計方式** 是 **累計用量**，該設定的選項有 **每小時**、**每天**、**每月**。<br><br><br>首個統計週期取決於該監控策略的建立時間或者該策略的重新啟用（如果之前已停用）時間。<br><br>&nbsp;<br><br>**範例**<br><br>假設您在 8月12日 09:22 建立了一個監控策略，<br><br><br>* 您設定 **統計方式** 是 **瞬間用量**。在這個情況下，由於統計週期是 5 分鐘，首個統計週期是當天的 [09:20, 09:25)，下一個統計週期是 [09:25, 09:30)，以此類推。<br><br>* 您設定 **統計方式** 是 **累計用量**，**統計週期** 是 **每小時**。在這個情況下，首個統計週期是當天的 [09:00, 10:00)，下一個統計週期是 [10:00, 11:00)，以此類推。<br><br>* 您設定 **統計方式** 是 **累計用量**，**統計週期** 是 **每天**。在這個情況下，首個統計週期是 [8月12日 00:00, 8月13日 00:00)，下一個統計週期是 [8月13日 00:00, 8月14日 00:00)，以此類推。<br><br>* 您設定 **統計方式** 是 **累計用量**，**統計週期** 是 **每月**。在這個情況下，首個統計週期是 [8月1日 00:00, 9月1日 00:00)，下一個統計週期是 [9月1日 00:00, 10月1日 00:00)，以此類推。 |
|封頂門檻值 |表示用量門檻值，門檻值是整數。<br><br><br>* 如果 **統計方式** 是 **瞬間用量**，您可以設定以下指標的用量門檻值：<br><br>   * 頻寬：表示統計週期內的頻寬。您可以設定的門檻值範圍是 10Mbps\-100Tbps。<br><br>   * QPS：表示統計週期內的用戶請求 QPS。門檻值範圍是 100\-1,000,000 QPS。<br><br>* 如果 **統計方式** 是 **累計用量**，您可以設定以下指標的用量門檻值：<br><br>   * 流量：表示統計週期內的流量。門檻值範圍是 100MB\-10,000TB。<br><br>   * 請求數：表示統計週期內的用戶請求數。門檻值範圍是 10,000\-10,000,000,000。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">1GB=1,000MB，1Gbps=1,000Mbps。</div><br> |
|處置方式 |表示當用量超過門檻值時，CDN 對網域名稱執行的操作。當前，該設定只能是 **停用網域名稱**，表示 CDN 停用您的網域名稱。網域名稱被停用時，CDN 會向您傳送[通知](https://docs.byteplus.com/en/docs/18/84294#%E9%80%9A%E7%9F%A5)。<br><br>&nbsp;<br><br>在一個統計週期內，CDN 最多停用網域名稱一次。如果您修改了監控策略，網域名稱的停用次數會被歸零。<br><br>&nbsp;<br><br>**範例**<br><br>&nbsp;<br><br>您設定 **統計方式** 是 **累計用量**、**統計週期** 是 **每月**、**處置時長** 是 **1 天**。<br><br>&nbsp;<br><br>在 8月12日 09:25，該網域名稱由於當月累計流量超過門檻值而被 CDN 停用，並在 8月13日 09:25 被 CDN 重新啟用。啟用後，雖然該網域名稱當月的累計流量仍然超過門檻值，當月內 CDN 不再停用該網域名稱。<br><br>&nbsp;<br><br>然後，您在 8月15日 09:03 更新了該監控策略，將 **處置時長** 調整為 **3 天**。當天 09:05，該網域名稱由於當月累計流量超過門檻值而再次被 CDN 停用。 |
|處置時長 |表示 **處置方式** 的生效時長。<br><br><br>* 當 **處置方式** 是 **停用網域名稱** 時，該設定表示網域名稱的停用時長。網域名稱停用期結束時，CDN 會重新啟用您的網域名稱，並向您傳送[通知](https://docs.byteplus.com/en/docs/18/84294#%E9%80%9A%E7%9F%A5)。<br><br><br>該設定有以下選項：**1 小時**、**12 小時**、**1 天**、**3 天**、**永久**。 |
|告警策略 |表示您是否希望當指標資料達到您設定的告警門檻值時收到[通知](https://docs.byteplus.com/en/docs/18/84294#%E9%80%9A%E7%9F%A5)。 |
|告警門檻值 |當 **告警策略** 啟用時，該設定會出現，表示封頂門檻值的一個百分比。當指標資料達到該百分比時，CDN 向您傳送[通知](https://docs.byteplus.com/en/docs/18/84294#%E9%80%9A%E7%9F%A5)。您可以設定的門檻值是範圍在 10\-90 內的整數。<br><br>&nbsp;<br><br>當網域名稱用量達到該門檻值時：<br><br><br>* 如果 **統計方式** 是 **瞬間用量**，雖然統計週期是 5 分鐘，但是 CDN 每小時最多傳送一次通知。<br><br>* 如果 **統計方式** 是 **累計用量**，在每個統計週期內，CDN 最多傳送一次通知。<br><br><br>如果網域名稱由於監控策略而被 CDN 停用或重新啟用、或者監控策略被更新，通知次數會被歸零。<br><br>&nbsp;<br><br>**範例**<br><br><br>* 您設定 **統計方式** 是 **累計用量**，**統計週期** 是 **每小時**，**封頂門檻值** 是 100MB，**告警門檻值** 是 60%。<br><br>   * 在 [13:00, 14:00) 這個統計週期內，網域名稱的累計流量達到了 62MB。但是，在 14:00 之前，CDN 不再向您傳送通知。<br><br>* 您設定 **統計方式** 是 **瞬間用量**，**封頂門檻值** 是 100Mbps，**告警門檻值** 是 60%。<br><br>   * 在 [13:05, 13:10) 期間，網域名稱的頻寬峰值達到了 62Mbps。因此，CDN 在 13:10 向您傳送通知。但是，在 14:00 之前，CDN 不再向您傳送通知。<br><br>      在 [13:55, 14:00) 期間，網域名稱的頻寬峰值達到 62Mbps。因此，CDN 在 14:00 向您傳送通知。<br><br>   * 在 [13:05, 13:10) 期間，網域名稱的頻寬峰值達到了 62Mbps，並且之後每 5 分鐘的頻寬峰值保持在 60Mbps 以上，直到當天 15:10。在這個場景中，CDN 會在 13:10、14:00、15:00 分別向您傳送通知。<br><br><br>**監控策略更新對告警的影響範例**<br><br>&nbsp;<br><br>您設定 **統計方式** 是 **累計用量**，**統計週期** 是 **每小時**，**封頂門檻值** 是 100MB，**告警門檻值** 是 60%。<br><br><br>* 在 13:05，當前小時內網域名稱的累計流量達到了 62MB。因此，CDN 在 13:05 向您傳送通知。在 13:08，您修改了監控策略，將 **封頂門檻值** 修改為 200MB。在 13:15，當前小時內網域名稱的累計流量達到了 190MB。因此，CDN 在 13:15 向您傳送通知。 |
