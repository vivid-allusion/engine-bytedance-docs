<span id="清除快取概述"></span>
## 清除快取概述

在 BytePlus CDN 中,每個被快取的檔案都有一個快取過期時間。如果一個檔案在快取中未過期,但是來源伺服器上該檔案已被更新,CDN 還是會將快取的檔案發送給使用者。此時,如果您需要使用者能獲取來源伺服器上更新後的該檔案,您可以使用 CDN 提供的「清除快取」功能。

<span id="工作原理"></span>
## 工作原理

您使用「清除快取」為特定檔案或者目錄提交清除任務。


* 對於檔案清除,CDN 會從快取中刪除指定的檔案。之後,當收到這些檔案的請求時,CDN 會向來源伺服器請求檔案。

* 對於目錄清除,CDN 會將指定目錄下已快取的檔案標記為已過期。當收到這些檔案的請求時,CDN 會向來源伺服器發送檔案校驗請求。關於檔案校驗的流程描述,參見 [來源伺服器請求校驗](https://docs.byteplus.com/en/docs/byteplus-cdn/cdn-cache-rules_zh-tw#%E4%BE%86%E6%BA%90%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A0%A1%E9%A9%97)。


<span id="適用場景"></span>
## 適用場景

「清除快取」適用於以下場景：


* 您網站上有關鍵檔案被更新了,您需要使用者獲取最新的檔案。

* 來源伺服器上的特定檔案由於某些原因需要被刪除。然而,這些檔案可能已被 CDN 快取了。您不希望使用者存取這些檔案。


<span id="注意事項"></span>
## 注意事項


* 「清除快取」可以確保使用者獲取最新版本的檔案。但是當一個檔案被清除後,該檔案的第一次存取是無法獲得加速的。如果您需要該檔案的第一次存取能被加速,在清除任務成功執行後,您可以使用 [清除快取](https://docs.byteplus.com/en/docs/byteplus-cdn/file-prefetch_zh-tw) 功能。

* 在您提交清除任務後,其生效時間大約是 5 分鐘。

* 在您對大量檔案提交清除任務後,這些檔案的請求會觸發回源請求。因此您的來源伺服器可能會在短期內承受流量壓力,特別是在檔案體積較大的時候。

* 您不能直接對泛網域下的檔案和目錄執行清除快取操作，而是要對每個子網域進行這些操作。


<span id="清除配額"></span>
## 清除配額

您主帳號下每天可清除的檔案和目錄有以下限額：


* 如果您清除的是檔案,您每天最多可以清除 10,000 個檔案。每個清除快取任務中最多可以包含 100 個 URL。

* 如果您清除的是目錄,您每天最多可以清除 50 個目錄。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">清除配額是主帳號和子帳號共用的。</div>


<span id="操作步驟"></span>
## 操作步驟


1. 登入 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左側導覽列,點擊 **工具中心** \> **清除快取與預取快取**。

3. 在 **清除與預熱** 頁面,點擊 **清除快取** 標籤頁。

4. 參照以下配置說明。

5. 配置完成後,點擊 **提交**。

<span id="額外功能"></span>
## 額外功能

您需要 [提交工單](https://console.byteplus.com/workorder/create)啟用以下功能：


* 強制刪除

* 規則運算式清除快取


<span id="強制刪除"></span>
### 強制刪除

當 **任務類型** 是 **目錄清除快取** 時，該設定會出現，用以指定是否刪除已快取的檔案。


* 預設情況下，當您提交快取清除任務時，CDN 會將快取中相應的檔案標記為過期，而不是刪除。當收到這些檔案的請求時，CDN 會向來源伺服器發送檔案校驗請求，而不是直接向來源伺服器請求檔案。參見[來源伺服器校驗](https://docs.byteplus.com/en/docs/byteplus-cdn/cdn-cache-rules_zh-tw#%E4%BE%86%E6%BA%90%E4%BC%BA%E6%9C%8D%E5%99%A8%E6%A0%A1%E9%A9%97)。

* 開啟 **強制刪除** 後，清除快取任務會刪除快取中相應的檔案。當收到這些檔案的請求時，CDN 會直接向來源伺服器請求檔案。


<span id="規則運算式清除快取"></span>
### 規則運算式清除快取

在您指定檔案 URL 時，您可以在 URL 中使用規則運算式來匹配需要清除快取的檔案。您可以輸入一個或者多個 URL，多個 URL 使用換行分隔。每個 URL 不能超過 256 個字元。規則運算式在匹配時是區分大小寫的。

您帳號下每天可清除快取 20 個包含規則運算式的 URL。您一次最多可以提交 10 個 URL。

在 URL 中，您可以指定的規則運算式有以下限制：


* 規則運算式匹配的是檔案路徑和查詢字串，但不包含路徑開頭的 `/`。也就是說，URL 的格式只能是 `http://host/regex` 或者 `https://host/regex`。`host` 表示網域，`regex` 表示規則運算式。

* 規則運算式中只能包含以下元字元：

   * [0\-9]

   * [a\-z]

   * [A\-Z]

   * [a\-zA\-Z]

   * [^/]\*

   * .\*

   * +

   * [,?]

   * ?


<span id="注意事項"></span>
#### 注意事項

在您建構的包含規則運算式的檔案 URL 中，除了路徑開頭的 `/`，整個路徑都被認為是規則運算式。因此，只要規則運算式匹配了某個實際檔案的 URL 中的部分路徑，該檔案就會被認為是匹配，從而被 CDN 清除快取。

例如 `https://www.example.com/dir2/.*\.js` 可以匹配以下檔案的 URL：


* http://www.example.com/dir2/img1.js

* http://www.example.com/dir2/img1.js?size=small

* http://www.example.com/dir1/dir2/img1.js

* http://www.example.com/dir1/dir2/img1.jsp
