本檔案提供了日誌檢索的範例。這些範例可以幫助您了解如何檢索日誌。您可以查看檔案目錄瀏覽以及跳轉到相應的範例。

在您檢索日誌時，需要了解檢索語法。檢索陳述由查詢陳述和分析陳述兩部分組成，格式是 `<查詢陳述>｜<分析陳述>`。分析陳述是可選的。本檔案不會對檢索語法進行闡述，而是透過範例演示常見的檢索語法。關於更多日誌檢索的語法以及您可以在檢索陳述中使用的函數，參見 [日誌分析概述](https://docs.byteplus.com/en/docs/tls/Analysis-overview)。

如果您設定了將檢索結果以圖表展示，您可以將圖表新增至儀表板，方便您查看圖表。參見 [新增圖表至儀表板](https://docs.byteplus.com/en/docs/tls/Adding_charts_to_a_dashboard)。

對於範例中使用的日誌欄位的描述，參見 [日誌欄位說明](https://docs.byteplus.com/en/docs/byteplus-cdn/log-streaming-overview_zh-tw#%E6%97%A5%E8%AA%8C%E6%AC%84%E4%BD%8D)。

<span id="更新索引設定"></span>
### 更新索引設定

您需要對日誌主題的索引設定做以下更新：


* 啟用對 `ds_http_ua` 的索引。該欄位記錄的是 User\-Agent 標頭值。

* 設定 `ds_http_status` 的欄位類型為 `double`。

   在您更新索引設定後，日誌主題中新投遞的日誌就會使用更新後的索引設定。


要修改索引設定，遵循以下步驟：


1. 在 **即時日誌** 標籤頁，找到相應的任務。您設定的是該任務所投遞的日誌的索引。

2. 在 **操作** 欄，點擊 **檢索**。

3. 在 **Query and analysis** 頁面，點擊 **Index configuration**。

4. 設定 ds_http_status 的欄位類型為 double，然後設定 ds\-http_ua 為啟用。

5. 點擊 **OK** 儲存修改。


關於日誌服務中索引的詳細介紹，參見 [設定索引](https://docs.byteplus.com/en/docs/tls/Configure-indexes-2)。

<span id="統計回應總位元組數排行以及平均回應時長"></span>
### 統計回應總位元組數排行以及平均回應時長

需求：


* 基於 URL 統計 CDN 回應的總位元組數以及平均回應時長，然後根據回應的總位元組數對結果進行降序排序。


回應時長的單位是秒。

檢索語法：

```sql
* | select domain,ds_http_uri,ds_http_resp_content_type,sum(ds_http_resp_size) AS total_size,avg(ds_http_resp_size)  AS resource_size,avg(ds_req_time) as avg_resp_time, count(*) as PV group by domain,ds_http_uri,ds_http_resp_content_type  order by total_size DESC
```

### 統計回應慢的請求數佔比

   * 回應時長超過 10 秒的請求數佔比。


檢索語法：

