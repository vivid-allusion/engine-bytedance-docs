本文件介紹 BytePlus CDN 提供的「離線日誌轉存」服務。該服務允許您設定 CDN 將按小時打包的請求日誌轉存到您指定物件儲存服務中的一個儲存桶。該儲存桶可以來自 BytePlus 物件儲存 (TOS)、阿里雲物件儲存 (OSS)、騰訊雲物件儲存 (COS)、AWS S3 以及使用與 AWS S3 相容驗證方式的任何物件儲存服務。

關於「離線日誌轉存」與另外兩種 CDN 日誌獲取方式的區別，請參見 [日誌管理概述](https://docs.byteplus.com/en/docs/byteplus-cdn/logs-overview_zh-tw)。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_2ad5cbd7b8e0dc3ebec5ece6ef365563.png) </span>

在設定「離線日誌轉存」時，您需要建立轉存任務。在轉存任務中，您提供儲存桶的存取設定，並指定 CDN 對哪些網域名稱的請求日誌包進行轉存。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDN 轉存的日誌包與 <strong>日誌下載</strong> 標籤頁中可查詢到並下載的日誌包是相同的。</div>



* <div data-tips="true" data-tips-type="tip">關於日誌的時效性、日誌包的命名規則、日誌欄位的說明等資訊，請參見 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-logs-cn-tw">日誌下載</a>。</div>



<span id="離線日誌轉存計費"></span>
## 離線日誌轉存計費

「離線日誌轉存」是收費的。費用由以下部分組成：


* 日誌投遞的費用。CDN 對投遞的日誌進行計費。計費單位是萬條。關於日誌投遞計費的詳細資訊，請參見 [CDN 計費說明](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-pricing_zh-tw)。

* 物件儲存服務的費用。基於投遞目標，請參見

   * [BytePlus TOS 計費](https://docs.byteplus.com/en/docs/tos/docs-billing-overview)。

   * [AWS S3 計費](https://aws.amazon.com/s3/pricing/)。

   * 關於其他物件儲存服務的定價，請造訪服務提供商的網站。


<span id="操作步驟"></span>
## 操作步驟


1. 登入 [BytePlus CDN 管理主控台](https://console.byteplus.com/cdn)。

2. 在左側導覽列，點擊 **工具中心** \> **日誌管理**。

3. 在 **日誌管理** 頁面，點擊 **離線日誌轉存** 標籤頁。

4. 在 **離線日誌轉存** 標籤頁，點擊 **新增** 建立一個轉存任務。

5. 在 **建立任務** 頁面，參照 [設定說明](https://docs.byteplus.com/en/docs/18/48602#%E8%A8%AD%E5%AE%9A%E8%AA%AA%E6%98%8E) 對 **轉存物件** 和 **關聯方式** 進行設定。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果您指定 <strong>轉存物件</strong> 為 <strong>BytePlus 物件儲存 (TOS)</strong>，您需要先授權 CDN 存取 TOS，請按頁面提示操作。如果您之前已授權 CDN 存取 TOS，<strong>服務授權</strong> 的狀態會是 <strong>已授權</strong>。   </div>
   

6. 任務設定完成後，點擊 **確認**。

<span id="設定說明"></span>
## 設定說明

<span id="轉存物件-為-byteplus-tos"></span>
### **轉存物件 為 BytePlus TOS**


|**設定** |**說明** |
|---|---|
|物件儲存桶 |表示 TOS 中的一個儲存桶的名稱。儲存桶清單中展示的是您帳戶下的所有儲存桶，您需要從清單中選擇一個儲存桶。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDN 收集到的日誌可能會存在延遲。對於延遲日誌，CDN 會將其附加到 TOS 儲存桶中對應的日誌包中。因此，在選擇儲存桶時，您只能選擇儲存類型是「標準儲存」的的儲存桶。因為只有該類型的儲存桶支援在現有檔案中附加內容。</div><br> |
|物件儲存目錄 |表示儲存桶下的一個目錄路徑。日誌包會被轉存到該目錄路徑下。例如 `mylogs/cdn-logs`。<br><br>&nbsp;<br><br>目錄路徑的開頭和結尾不能是斜線 (/)，長度不能超過 256 個字元。如果目錄路徑不存在，CDN 會在儲存桶中建立該目錄路徑。<br><br>&nbsp;<br><br>如果您不指定該設定，日誌包會被轉存到儲存桶的根目錄下。 |
|私有桶存取 |表示該儲存桶是否是公開存取的。該設定預設是關閉。<br><br><br>* 如果該設定是啟用，表示儲存桶是私有存取的。當 CDN 向該儲存桶轉存日誌包時，CDN 會使用您 BytePlus 帳戶的憑證存取該儲存桶。<br><br>* 如果該設定是關閉，表示儲存桶是公開存取的。 |
|備註資訊 |表示該任務的備註，長度為 3\-45 個字元，可以包含漢字、字母、數字，但不能以下劃線 (_) 開頭或結尾。一個漢字佔 3 個字元。<br><br>&nbsp;<br><br>任務建立後，該備註會顯示在任務 ID 下方。<br><br><span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6815f1052cca0c5f29335879d6e60c02.png) </span> |


<span id="轉存物件-為-s3-協定物件儲存"></span>
### **轉存物件 為 S3 協定物件儲存**


|**設定** |**說明** |
|---|---|
|存取網域名稱 |對於日誌包轉存到的儲存桶，該設定表示該儲存桶的使用 S3 驗證方式的存取點 (endpoint)。<br><br>&nbsp;<br><br>存取點必須以 `https://` 開頭，不包含儲存桶的名稱，長度不能超過 1,024 個字元。例如：`https://oss-ap-southeast-1.aliyuncs.com`。 |
|存取區域 |表示該儲存桶所在區域 (region code)，例如 `ap-southeast`。請諮詢該儲存桶的物件儲存服務提供商以獲取該儲存桶的區域。<br><br>&nbsp;<br><br>區域不能超過 64 個字元。 |
|物件儲存桶 |表示該儲存桶的名稱 (bucket name)，長度不能超過 256 個字元。例如：`mybucket`。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">CDN 收集到的日誌可能會存在延遲。對於延遲日誌，CDN 會將其附加到 TOS 儲存桶中對應的日誌包中。因此，您指定的儲存桶必須支援在現有檔案中附加內容。</div><br> |
|物件儲存目錄 |表示儲存桶下的一個目錄路徑。日誌包會被轉存到該目錄路徑下。例如 `mylogs/cdn-logs`。<br><br>&nbsp;<br><br>目錄路徑的開頭和結尾不能是斜線 (/)，長度不能超過 256 個字元。如果目錄路徑不存在，CDN 會在儲存桶中建立該目錄路徑。 |
|私有桶存取 |表示該儲存桶是否是公開存取的。該設定預設是關閉。<br><br><br>* 如果該設定是啟用，表示儲存桶是私有存取的。您需要提供 CDN 存取該儲存桶所使用的憑證。<br><br>* 如果該設定是關閉，表示儲存桶是公開存取的。 |
|AccessKey ID |對於 CDN 存取該儲存桶所使用的憑證，該設定表示憑證中的 AccessKey ID。<br><br>&nbsp;<br><br>僅當 **私有桶存取** 是啟用時，該設定才會出現。 |
|AccessKey Secret |對於 CDN 存取該儲存桶所使用的憑證，該設定表示憑證中的 AccessKey Secret。<br><br>&nbsp;<br><br>僅當 **私有桶存取** 是啟用時，該設定才會出現。 |
|備註資訊 |表示該任務的備註，長度為 3\-45 個字元，可以包含漢字、字母、數字，但不能以下劃線 (_) 開頭或結尾。一個漢字佔 3 個字元。<br><br>&nbsp;<br><br>任務建立後，該備註會顯示在任務 ID 下方。 |


<span id="關聯方式"></span>
### **關聯方式**

在該設定中，您指定 CDN 對哪些網域名稱的日誌包進行轉存。該設定有以下選項：


* 按網域名稱關聯：指定最多 200 個您帳戶下的網域名稱。

* 按帳戶關聯：表示您帳戶下所有的網域名稱。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">一個網域名稱只能包含在一個任務中。</div>


* <div data-tips="true" data-tips-type="tip">如果已存在 <strong>關聯方式</strong> 為 <strong>按網域名稱關聯</strong> 的任務，您就無法建立 <strong>關聯方式</strong> 為 <strong>按帳戶關聯</strong> 的任務，反之亦然。</div>

<span id="啟用-停用任務"></span>
### 啟用/停用任務

如果您想暫停一個任務，您可以在該任務的 **操作** 列上，點擊 **停用**。任務停用後，CDN 停止轉存該任務所關聯的所有網域名稱的日誌包。之後，您可以隨時點擊 **啟用** 使 CDN 繼續轉存這些網域名稱的日誌包。

<span id="日誌包轉存失敗時的頁面提示"></span>
### 日誌包轉存失敗時的頁面提示

在您設定儲存桶資訊時，如果任何設定不正確，轉存任務會失敗。另外，如果在轉存任務的執行過程中，儲存桶達到了某些限制，轉存任務也會失敗。

如果一個轉存任務無法將日誌包轉存到目標儲存桶，該任務左側會出現一個驚嘆號。當您點擊該驚嘆號時，頁面會顯示最近一次轉存失敗的時間點和原因。您可以參考失敗原因對問題進行排查。
