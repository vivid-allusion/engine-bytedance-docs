本文檔介紹了如何在 BytePlus CDN 中設定一個日誌主題的索引。本文檔適用於日誌投遞目的地是 BytePlus 日誌服務（TLS）的場景。

索引設定決定了被 TLS 索引的欄位以及索引方式。在 CDN 中，您可以按需對一個日誌主題的索引進行設定，實現客製化的日誌管理。操作步驟如下：


1. 在即時日誌投遞任務清單中，找到您要修改索引設定的任務。

2. 從任務設定中獲取日誌專案、日誌專案所在的區域和存放日誌的日誌主題。

3. 在 **操作** 欄位上，點擊 **檢索**。

4. 在開啟的日誌服務頁面最上方，選擇日誌專案所在的區域，然後在頁面左側點擊 **Query and analysis**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/571741db015746a6aa65054fe3df08bf~tplv-goo7wpa0wc-image.image) </span>

5. 在 **Query and analysis** 頁面的左側，找到相應的日誌主題並開啟它。

6. 在日誌主題詳情頁面，點擊 **Index configuration**。

7. 參考 [設定說明](https://docs.byteplus.com/en/docs/18/49621#%E8%A8%AD%E5%AE%9A%E8%AA%AA%E6%98%8E) 對索引進行設定。

8. 設定完成後，點擊 **OK**。

<span id="設定說明"></span>
## 設定說明


|設定 |說明 |
|---|---|
|Field name |表示一個日誌欄位。 |
|Field type |表示該欄位的資料類型。 |
|Field configuration |表示 BytePlus TLS 是如何索引該欄位的。日誌服務提供了以下設定：<br><br><br>* Case sensitive：表示該欄位的名稱是否是大小寫敏感的。<br><br>* Contains Chinese：表示該欄位的值是否包含中文字元。如果您勾選了該設定，日誌服務會根據中文語法對欄位值進行分詞。例如，某個欄位的值是 `msg:"檔案 sample.png 開啟失敗"`。如果 **Contains Chinese** 未被勾選，查詢語句 `msg:"開啟"` 將無法檢索到該日誌。只有您使用完整的日誌內容 `msg:"檔案 sample.png 開啟失敗"` 才能檢索到該日誌。在您勾選了 **Contains Chinese** 後，查詢語句 `msg:"開啟"` 就可以檢索到該日誌。<br><br>* Delimiter：指示日誌服務使用哪個字元對欄位值進行分詞。分詞的目的是為了方便檢索。例如，某個欄位的值是 `numbers:"1\|2\|3"`。如果您指定分詞符為 `\|`，查詢語句 `numbers:"1"` 可以檢索到該日誌。如果您指定分詞符為 `,`，查詢語句 `numbers:"1"` 將無法檢索到該日誌。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip"><strong>Contains Chinese</strong> 和 <strong>Delimiter</strong>，您只能設定這兩個設定中的一個。</div><br><br><br>* <div data-tips="true" data-tips-type="tip">只有 text 類型和 json 類型的欄位有 <strong>Contains Chinese</strong> 和 <strong>Delimiter</strong> 設定。</div><br><br><br>* <div data-tips="true" data-tips-type="tip">目前存在以下限制：</div><br><br><br>   * <div data-tips="true" data-tips-type="tip">如果 <strong>Enable analytics</strong> 是開啟，該欄位的 <strong>Contains Chinese</strong> 和 <strong>Delimiter</strong> 選項將都不生效，也會從主控台消失。</div><br> |
|Enable analytics |表示該欄位是否能在分析語句中被指定。檢索語句的格式是 `<查詢語句>｜<分析語句>`。如果您不期待該欄位在分析語句中被指定，您可以在 **Enable analytics** 欄位上將該欄位設定為關閉。<br><br>&nbsp;<br><br>需要留意的是，無論 **Enable analytics** 是否開啟，該欄位始終是可以在查詢語句中被指定的。例如，您將 `ds_http_status` 欄位的 **Enable analytics** 設定為關閉。此時，您無法執行以下檢索語句：<br><br><br>* `ds_http_status:>=400 \| select ds_http_status,count(*) AS PV group by ds_http_status`<br><br><br>但是，您仍然可以執行以下檢索語句：<br><br><br>* `ds_http_status:>=400` |
|操作 |如果您不需要該欄位被索引，您可以點擊 **Delete**。 |


關於該頁面上的其他索引設定，例如全文索引，參見 [TLS 文檔](https://docs.byteplus.com/en/docs/tls/Configure-indexes-2)。
