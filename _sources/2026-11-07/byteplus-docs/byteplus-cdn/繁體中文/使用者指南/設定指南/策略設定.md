<span id="概述"></span>
## 概述

在 CDN 中，策略的設定是基於版本來管理的。策略的設定包含 CDN 特性的設定和來源伺服器設定。當您建立一個策略時，該策略就有了一個初始版本。要修改策略的設定，您需要執行以下步驟：


1. 為策略建立一個草稿版本。

2. 更新草稿版本中策略的設定。

3. 發布該草稿版本。


另外，策略版本允許您將策略的設定還原到一個舊版本。您還可以複製特定版本並更新複製版本中的策略設定。在發布或還原策略版本時，建議您添加有意義的說明，以便後期維護。例如，當您後期需要查看、複製或者刪除一個版本時，版本說明可以幫助您定位要操作的版本。

<span id="版本狀態"></span>
### **版本狀態**

策略版本有以下幾種狀態：


* 執行中：表示版本已發布，版本中策略的設定正在生效。

* 暫停：表示版本之前是發布，但已撤回，版本中策略的設定不再生效。

* 草稿：表示版本還未發布。


只有當版本的狀態是「草稿」時，您才能修改版本中策略的設定。

下表列出了各個狀態下您可以對版本執行的操作。


|**版本狀態** |**允許的操作（Y 表示允許）**  ||||||
|---|---|---|---|---|---|---|
||**查看** |**修改** |**還原** |**發布** |**刪除** |**複製** |
|草稿 | |Y | |Y |Y | |
|執行中 |Y | | | | |Y |
|暫停 |Y | |Y | |Y |Y |


<span id="版本號"></span>
### **版本號**

當您發布一個版本時，CDN 就會為該版本產生一個版本號。當您[還原一個版本](https://docs.byteplus.com/en/docs/18/40646#%E9%82%84%E5%8E%9F%E7%89%88%E6%9C%AC)時，CDN 會產生並發布一個版本並為發布的版本產生一個版本號。

版本號的命名規範是 `P-<first_publish_date>-<random_5_digits>`。例如 `P-250224.44093`。

草稿狀態下的策略沒有版本號，**版本號**欄顯示的是 `draft`。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">每個策略最多記錄 50 個已發佈的版本。</div>


<span id="操作說明"></span>
## 操作說明

<span id="查看版本中策略的設定"></span>
### 查看版本中策略的設定

對於狀態是「執行中」或「暫停」的版本，您可以查看版本中策略的設定。策略的設定是以 API 參數形式展示。要了解各參數的含義，請參見 [UpdateServiceTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-updateservicetemplate-cn) 和 [UpdateCipherTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/reference_cn-updateciphertemplate-ac087-cn)。

要查看特定版本中策略的設定，有以下兩種方法。

<span id="方法一：在策略詳情頁面查看"></span>
#### **方法一：在策略詳情頁面查看**


1. 在策略列表中，找到您要查看的策略，然後點擊該策略的 ID。

2. 在策略詳情頁面右上方的版本列表中，選擇您要查看的版本。


在您選擇了要查看的版本後，策略詳情頁面中顯示的就是該版本中策略的設定。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">版本列表中的版本按建立時間排序。最近建立的版本顯示在最前面。</div>


* <div data-tips="true" data-tips-type="tip">版本列表中顯示的是版本號，無版本說明。如果您需要基於版本說明來選擇需要查看的版本，請使用方法二。</div>



<span id="方法二：在「策略版本」標籤頁中查看"></span>
#### **方法二：在「策略版本」標籤頁中查看**


1. 在策略列表中，找到您要查看的策略。

2. 在**操作**欄，點擊**歷史**。

3. 在**版本管理**標籤頁中，點擊**策略版本**。

4. 在版本列表中，找到您要查看的版本。

5. 在**操作**欄，點擊**查看**。


<span id="建立版本"></span>
### 建立版本

要建立一個策略版本，遵循以下步驟：


1. 在策略列表中，找到您要操作的策略。

2. 點擊策略 ID 開啟策略詳情頁面。

3. 在頁面右上方，點擊**建立版本**。


在您點擊**建立版本**後，CDN 會對狀態為「執行中」的版本進行複製，以產生一個狀態為「草稿」的版本，版本號是 `draft`。同時，**建立版本**按鈕會變為灰色。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">您點擊<strong>建立版本</strong>後，策略詳情頁面展示的並非草稿版本中的策略設定，而是狀態為「執行中」版本中的策略設定。</div>


* <div data-tips="true" data-tips-type="tip">一個策略只能有一個狀態為「草稿」的版本。也就是說，如果策略中已存在狀態為「草稿」的版本，<strong>建立版本</strong>按鈕會變為灰色，您無法建立版本。</div>



<span id="修改版本中策略的設定"></span>
### 修改版本中策略的設定

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能修改狀態為「草稿」的版本中策略的設定。</div>


要修改版本中策略的設定，遵循以下步驟：


1. 在策略列表中，找到您要操作的策略。

2. 在**操作**欄，點擊**歷史**。

3. 在**版本管理**標籤頁中，點擊**策略版本**。

4. 在版本列表中，找到您要操作的版本。

5. 在**操作**欄，點擊**修改**。

6. 在策略詳情頁面，點擊**策略設定**標籤頁。

7. 修改策略的設定。

8. 修改完成後，在頁面右下方點擊**儲存**。


<span id="發布版本"></span>
### 發布版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能發布狀態為「草稿」的版本。</div>


要使一個草稿版本中策略的設定生效，您需要發布該版本。版本發布後，版本中策略的設定會套用於所有與該策略綁定的網域名稱。

要發布一個版本，遵循以下步驟：


1. 在策略列表中，找到您要操作的策略。

2. 在**操作**欄，點擊**歷史**。

3. 在**版本管理**標籤頁中，點擊**策略版本**。

4. 在版本列表中，找到您要操作的版本。

5. 在**操作**欄，點擊**發布**。

6. 在**發布策略**對話框，輸入一個有意義的版本說明，然後點擊**確定**。


版本發布後，該版本的狀態會從「草稿」變成「執行中」。之前發布的版本狀態會從「執行中」變成「暫停」。

<span id="還原版本"></span>
### 還原版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能回復狀態為「暫停」的版本。</div>


對於一個狀態為「暫停」的版本，如果您需要該版本中策略的設定生效，您可以對該版本進行回復操作。當您回復一個狀態為「暫停」的版本時，CDN 會立即發布該版本。

要還原一個版本，遵循以下步驟：


1. 在策略列表中，找到您要操作的策略。

2. 在**操作**欄，點擊**歷史**。

3. 在**版本管理**標籤頁中，點擊**策略版本**。

4. 在版本列表中，找到您要還原的版本。

5. 在**操作**欄，點擊**還原**。

6. 在**發布策略**對話框，輸入一個有意義的版本說明，然後點擊**確定**。


<span id="複製版本"></span>
### 複製版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您只能複製狀態為「執行中」或「暫停」的版本。</div>


如果您需要基於某個版本對策略的設定進行修改，您可以複製該版本。

當您複製一個版本時，CDN 執行以下操作：


* 建立一個與被複製版本相同的版本。建立後的版本狀態是「草稿」。


要複製一個版本，遵循以下步驟：


1. 在策略列表中，找到您要操作的策略。

2. 在**操作**欄，點擊**歷史**。

3. 在**版本管理**標籤頁中，點擊**策略版本**。

4. 在版本列表中，找到您要複製的版本。

5. 在**操作**欄，點擊**複製**。


需要留意的是，如果存在狀態為「草稿」的版本，複製操作產生的版本將覆蓋草稿版本。

<span id="刪除版本"></span>
### 刪除版本

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">您只能刪除狀態為「暫停」或「草稿」的版本。</div>


* <div data-tips="true" data-tips-type="tip">刪除後的版本無法復原。</div>



如果您不再需要某個版本，您可以刪除該版本。
