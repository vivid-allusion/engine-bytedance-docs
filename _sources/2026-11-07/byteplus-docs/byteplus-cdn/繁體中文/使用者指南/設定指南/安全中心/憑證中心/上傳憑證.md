本文件展示如何在 BytePlus CDN 管理控制台的 **憑證中心** 頁面上傳憑證。

如果您的憑證是您在其他憑證服務商處購買的，您需要在該服務商處匯出該憑證，然後在 **憑證中心** 頁面上傳該憑證。

<span id="操作步驟"></span>
## 操作步驟


1. 在 **憑證中心** 頁面，點擊 **上傳憑證**。

2. 在 **上傳憑證** 頁面，參考 [配置說明](https://docs.byteplus.com/en/docs/18/36332#%E9%85%8D%E7%BD%AE%E8%AA%AA%E6%98%8E) 進行設置，然後點擊 **確定**。


<span id="配置說明"></span>
### 配置說明


|**配置** |**說明** |
|---|---|
|上傳方式 |表示憑證的上傳方式。該配置有以下選項：<br><br><br>* 手動輸入：表示貼上憑證檔案和私密金鑰檔案中的內容。<br><br>* 上傳憑證檔案：表示上傳憑證檔案和私密金鑰檔案。 |
|Public Key |表示憑證檔案。憑證檔案必須包含完整的憑證鏈，副檔名是 .crt 或者 .pem，內容以 `-----BEGIN CERTIFICATE-----` 開頭。<br><br><br>* 如果 **上傳方式** 是 **手動輸入**，您需要將憑證檔案中的內容貼上到 **Public Key** 輸入框中。<br><br>* 如果 **上傳方式** 是 **上傳憑證檔案**，您需要指定憑證檔案。 |
|Private Key |表示憑證私密金鑰檔案。私密金鑰檔案的副檔名是 .key 或者 .pem，內容以 `-----BEGIN XXX PRIVATE KEY-----` 開頭。<br><br><br>* 如果 **上傳方式** 是 **手動輸入**，您需要將私密金鑰檔案中的內容貼上到 **Private Key** 輸入框中。<br><br>* 如果 **上傳方式** 是 **上傳憑證檔案**，您需要指定私密金鑰檔案。 |
|描述 |表示憑證的備註。憑證備註是可選的。 |
