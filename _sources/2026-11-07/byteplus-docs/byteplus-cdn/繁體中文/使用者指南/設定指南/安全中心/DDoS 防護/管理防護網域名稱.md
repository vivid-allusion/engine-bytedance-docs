本文件介紹如何在 BytePlus CDN 管理主控台管理防護網域名稱，包括新增網域名稱和刪除網域名稱。

<span id="新增網域名稱"></span>
## 新增網域名稱

當您建立了高級 DDoS 防護執行個體後，高級 DDoS 防護不會自動防護您 BytePlus 帳號下已接入 CDN 的網域名稱。您需要手動將需要防護的網域名稱新增至該執行個體。新增網域名稱後，高級 DDoS 防護即啟用。

<span id="使用限制"></span>
### 使用限制

預設情況下，一個高級 DDoS 防護執行個體最多可以防護 50 個網域名稱。

<span id="注意事項"></span>
### 注意事項


* 當您為網域名稱開啟高級 DDoS 防護後，將會產生安全流量費用。安全流量的費用按 CDN 傳輸給用戶端的資料量計算。計費詳情，請參考 [DDoS 計費說明](https://docs.byteplus.com/en/docs/byteplus-ddos-protection/docs-pricing)。

* 為網域名稱開啟高級 DDoS 防護後，您無需修改網域名稱的 DNS 解析設定。但是，DNS 會停止將網域名稱解析為 IPv6 位址（即使您在 CDN 的策略中啟用了 IPv6）。所有流量會指向 IPv4 高防 IP 位址。

* 開啟高級 DDoS 防護會帶來一定的網域名稱存取延遲。用戶端所在區域和網路環境會影響到延遲大小。


更多資訊，請參考[使用高級 DDoS 防護時的注意事項](https://docs.byteplus.com/en/docs/byteplus-cdn/DDos_protection_levels_cn_tw)。

<span id="操作步驟"></span>
### 操作步驟


1. 登入 [BytePlus CDN 管理主控台](https://console.byteplus.com/cdn)。

2. 在左側導覽列，選擇 **安全中心** \> **DDoS** **防護**。

3. 在 **DDoS** **防護** 頁面的 **防護網域名稱** 區域，按一下 **添加CDN網域名稱**。

4. 在全部網域名稱清單中，選取網域名稱，然後按一下 **確定**。

   清單上方會顯示網域名稱的配額以及目前受防護的網域名稱的數量。您可以選擇的網域名稱的數量為這兩者的差值。例如，如果網域名稱的配額為 50，目前受防護的網域名稱的數量為 45，則您還可以新增最多 5 個網域名稱。


<span id="40fb3cb6"></span>
### 更多資訊

<span id="79e232de"></span>
#### **防護模式說明**

高級 DDoS 防護執行個體支援以下兩種防護模式：


* **自動調度**：正常情況下，網域名稱直接解析到 CDN 服務 IP 位址。當系統識別到流量突發時，會自動觸發切換流程，網域名稱會被解析到高級 DDoS 防護執行個體的 IP 位址。網域名稱解析切換需要數分鐘生效。該模式適合需要兼顧效能和安全防護需求的網域名稱。

* **總是開啟**：網域名稱總是被解析到高級 DDoS 防護執行個體的 IP 位址上。該模式適合被攻擊頻率高的網域名稱。


在網域名稱被新增到高級 DDoS 防護執行個體後，預設啟用「自動調度」防護模式。如果您的網域名稱被攻擊的頻率比較高，建議您在新增網域名稱後，手動將網域名稱的防護模式調整為「總是開啟」。

<span id="9988aa90"></span>
#### **網域名稱狀態說明**

「自動調度」防護模式下，網域名稱可能處於以下幾種狀態：


* 監控中：在無攻擊的常規狀態下，網域名稱解析至 CDN 服務 IP 位址，以利用分佈廣泛的節點提供高品質服務。此時，網域名稱狀態顯示為「監控中」。

* 執行中：當系統偵測到流量突增時，網域名稱會自動解析至高級 DDoS 防護執行個體的 IP 位址，網域名稱狀態切換為「執行中」。在此期間，網路層 DDoS 防護服務會進行流量分析。

* 清洗中：在網域名稱處於「執行中」狀態時，若系統識別出攻擊流量，將自動執行流量清洗。此時，網域名稱狀態更新為「清洗中」。


攻擊流量停止後，系統會進入一個預設的等待期以確認威脅已完全解除。等待期結束後，網域名稱狀態將自動恢復為「監控中」，網域名稱重新被解析至 CDN 服務 IP 位址。在等待期內，如果您需要提前恢復網域名稱解析，請[提交工單](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000735)申請。

<span id="刪除網域名稱"></span>
## 刪除網域名稱

如果某個網域名稱不再需要高級 DDoS 防護，您可以將其從防護網域名稱清單中移除，以釋放相應的網域名稱配額。

<span id="注意事項"></span>
### 注意事項

在您將網域名稱從防護網域名稱清單中移除後，針對該網域名稱的高級 DDoS 防護將關閉。

<span id="操作步驟"></span>
### 操作步驟


1. 登入 [BytePlus CDN 管理主控台](https://console.byteplus.com/cdn)。

2. 在左側導覽列，按一下 **安全中心** \> **DDoS** **防護**。

3. 在 **DDoS** **防護** 頁面的 **防護網域名稱** 區域，找到需要刪除的網域名稱，然後按一下 **操作** 欄的 **刪除**。

4. 在彈出的對話方塊中，按一下 **確定**。
