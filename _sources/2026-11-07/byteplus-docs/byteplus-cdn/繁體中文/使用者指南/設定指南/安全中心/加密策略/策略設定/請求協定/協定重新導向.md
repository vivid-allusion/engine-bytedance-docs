本文件介紹如何在 BytePlus CDN 中對網域名稱配置協定重新導向。

<span id="前提條件"></span>
### 前提條件

要開啟該配置，網域名稱必須已經開啟了 HTTPS 加密服務。

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **協定重新導向** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **協定重新導向** 下方，參照以下配置說明。

3. 配置完成後，點擊 **保存**。



|**配置** |**說明** |
|---|---|
|策略 |設置重新導向的策略。該配置有以下選項：<br><br><br>* **不跳轉**：表示不重新導向用戶請求使用的協定。<br><br>* **將 HTTP 重新導向到 HTTPS**：表示如果用戶請求使用的協定是 HTTP，則將其重新導向到 HTTPS。<br><br>* **將 HTTPS 重新導向到 HTTP**：表示如果用戶請求使用的協定是 HTTPS，則將其重新導向到 HTTP。 |
|重新導向方式 |表示 CDN 返回哪個狀態碼進行重新導向。當 **策略** 是 **將 HTTP 重新導向到 HTTPS** 或者 **將 HTTPS 重新導向到 HTTP** 的時候，該配置會出現。<br><br>&nbsp;<br><br>該配置的可選項有 **301**、**302**、**303**、**307**、**308**。<br><br>&nbsp;<br><br>需要留意的是：<br><br><br>* 對於 301 和 302，如果原請求使用的方法不是GET，那麼客戶端向新的URL發送請求時，新請求使用的方法可能變成 GET。<br><br>* 對於 303，新請求使用的方法是 GET。<br><br>* 對於 307 和 308，新請求使用的方法與原請求相同，不會被改變。 |
