本文件介紹了在 BytePlus CDN 中，指標是如何定義和統計的。指標分為兩大類，一類是針對 [用戶請求](https://docs.byteplus.com/en/docs/18/36312#%E7%94%A8%E6%88%B7%E8%AF%B7%E6%B1%82%E6%8C%87%E6%A0%87) 的，一類是針對 [来源伺服器請求](https://docs.byteplus.com/en/docs/18/36312#%E5%9B%9E%E6%BA%90%E8%AF%B7%E6%B1%82%E6%8C%87%E6%A0%87) 的。来源伺服器請求就是 CDN 向来源伺服器發送的請求。

<span id="基礎資訊"></span>
## 基礎資訊

在閱讀本文前，請留意以下定義。


* 指定的統計時間段：表示您指定的開始時間（`StartTime`）和結束時間（`EndTime`）之間的統計時間段。

* 實際統計時間段：基於您指定的開始時間（`StartTime`）、結束時間（`EndTime`）、以及統計時間粒度（`Interval`）決定的統計時間段。指標資料是基於實際統計時間段而統計的。

* 時間區間：時間粒度（`Interval`）將實際統計時間段拆分成一系列的時間區間。

* 細分資料：表示 CDN 對每個時間區間統計資料後得到的一系列的指標資料。細分資料用於展示實際統計時間段內的資料趨勢。

* 彙總資料：表示 CDN 對所有時間區間的指標資料進行彙總後得到的一個彙總資料。彙總資料用於展示實際統計時間段內的資料概況。


關於這些定義的詳細描述，參見 [統計時間段說明](https://docs.byteplus.com/en/docs/byteplus-cdn/G6uz94)。

<span id="用戶請求指標"></span>
## **用戶請求指標**

<span id="用戶端向-cdn-傳輸的資料量（流量）"></span>
### 用戶端向 CDN 傳輸的資料量（流量）

<span id="定義"></span>
#### **定義**

表示用戶向 CDN 傳輸的資料量，單位是 bytes。該資料量是 CDN 對收到的用戶請求而統計的，是用戶請求中請求標頭大小和請求正文大小之和。

該指標是對滿足以下條件的用戶請求統計的：


* 請求方法既不是 GET，也不是 HEAD。


<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的傳輸資料量。


* 單個時間區間內的傳輸資料量 = 該時間區間內用戶向 CDN 傳輸的資料量


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的傳輸資料量總和。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的傳輸資料量。

2. 統計這些傳輸資料量的總和。


<span id="cdn-向用戶端傳輸的資料量（流量）"></span>
### CDN 向用戶端傳輸的資料量（流量）

表示 CDN 向用戶傳輸的資料量，單位是 bytes。該資料量是 CDN 回應中回應標頭大小和回應正文大小之和。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的傳輸資料量。


* 單個時間區間內的傳輸資料量 = 該時間區間內 CDN 向用戶傳輸的資料量


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的傳輸資料量總和。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的傳輸資料量。

2. 統計這些傳輸資料量的總和。


<span id="用戶端向-cdn-傳輸的資料量（頻寬）"></span>
### 用戶端向 CDN 傳輸的資料量（頻寬）

<span id="定義"></span>
#### **定義**

表示基於用戶向 CDN 傳輸的資料量而計算的頻寬，單位是 bps。

該指標是對滿足以下條件的用戶請求統計的：


* 請求方法既不是 GET，也不是 HEAD。


<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的頻寬。根據指定的統計時間粒度，頻寬有兩種計算方式：


* 如果時間粒度是 1 分鐘或者 5 分鐘，單個時間區間內的頻寬計算公式如下：

   * （該時間區間內用戶向 CDN 傳輸的資料量 \* 8）/（該時間區間的時長）

* 如果時間粒度是 1 小時或者 1 天，單個時間區間內的頻寬計算方式如下：

   1. 以 5 分鐘時間粒度對該時間區間使用以上的計算公式統計一系列的頻寬。

   2. 計算這些頻寬中的最大值，也就是頻寬峰值。


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的頻寬峰值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間的頻寬。

2. 計算這些頻寬中的最大值。


<span id="頻寬峰值時間"></span>
#### **頻寬峰值時間**

表示頻寬峰值所在的時間區間的開始時間。

<span id="cdn-向用戶端傳輸的資料量（頻寬）"></span>
### CDN 向用戶端傳輸的資料量（頻寬）

表示基於 CDN 向用戶傳輸的資料量而計算的頻寬，單位是 bps。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的頻寬。根據指定的統計時間粒度，頻寬有兩種計算方式：


* 如果時間粒度是 1 分鐘或者 5 分鐘，單個時間區間內頻寬的計算公式如下：

   * （該時間區間內 CDN 向用戶傳輸的資料量 \* 8）/（該時間區間的時長）

* 如果時間粒度是 1 小時或者 1 天，單個時間區間內頻寬的計算方式如下：

   1. 以 5 分鐘時間粒度對該時間區間使用以上的計算公式統計一系列的頻寬。

   2. 計算這些頻寬中的最大值，也就是頻寬峰值。


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的頻寬峰值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間的頻寬。

2. 計算這些頻寬中的最大值。


<span id="頻寬峰值時間"></span>
#### **頻寬峰值時間**

表示頻寬峰值所在的時間區間的開始時間。

<span id="請求數"></span>
### **請求數**

<span id="定義"></span>
#### **定義**

表示 CDN 收到的所有用戶請求的數量。


* 用戶請求數 = 動態請求數 + 靜態請求數 + CDN 回應狀態碼是 405 的請求數


<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的請求數量。


* 單個時間區間內的請求數 = 該時間區間內 CDN 收到的所有請求數。


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的請求數總和。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的請求數。

2. 計算這些請求數的總和。


<span id="動態請求數"></span>
### 動態請求數

該指標的定義與資料統計方式與用戶請求數類似，只是指標資料是對滿足以下所有條件的用戶請求而統計的：


* 請求方法既不是 GET，也不是 HEAD。

* CDN 的回應狀態碼不是 405。405 表示請求方法不被 CDN 允許。


<span id="靜態請求數（static-requests）"></span>
### 靜態請求數（static_requests）

該指標的定義與資料統計方式與用戶請求數類似，只是指標資料是對滿足以下所有條件的用戶請求而統計的：


* 請求方法是 GET 或者 HEAD。

* CDN 的回應狀態碼不是 405。


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">當前，對於 WebSocket 請求，該指標的資料不準確。在查詢該指標的資料時，請過濾掉 WebSocket 協議。</div>


<span id="請求-qps"></span>
### 請求 QPS

<span id="定義"></span>
#### **定義**

對於 CDN 收到的所有用戶請求，該指標表示這些請求的 QPS。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的請求 QPS。根據指定的統計時間粒度，請求 QPS 有兩種計算方式：


* 如果時間粒度是 1 分鐘或者 5 分鐘，單個時間區間內請求 QPS 的計算公式如下：

   * （該時間區間內的請求數）/（該時間區間的時長）

* 如果時間粒度是 1 小時或者 1 天，單個時間區間內請求 QPS 的計算方式如下：

   * 以 5 分鐘時間粒度對該時間區間使用以上的計算公式計算一系列的 QPS。

   * 計算這些 QPS 中的最大值，也就是 QPS 峰值。


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的請求 QPS 峰值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的請求 QPS。

2. 計算這些請求 QPS 中的最大值。


<span id="請求-qps-峰值時間"></span>
#### 請求 QPS 峰值時間

表示請求 QPS 峰值所在的時間區間的開始時間。

<span id="狀態碼"></span>
### 狀態碼

<span id="定義"></span>
#### **定義**

在 CDN 對用戶請求的回應中，該指標表示以下類別的狀態碼數量：


* 所有狀態碼的數量。

* 2xx 狀態碼的數量以及該類別下每個狀態碼的數量。

* 3xx 狀態碼的數量以及該類別下每個狀態碼的數量。

* 4xx 狀態碼的數量以及該類別下每個狀態碼的數量。

* 5xx 狀態碼的數量以及該類別下每個狀態碼的數量。


<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的每個類別的狀態碼數量。

<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，每個類別的狀態碼數量總和。

<span id="回應時間"></span>
### **回應時間**

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">當前，對於 WebSocket 請求，該指標的資料不準確。在查詢該指標的資料時，請過濾掉 WebSocket 協議。</div>


<span id="定義"></span>
#### **定義**

表示 CDN 回應用戶請求所耗費的平均時間，單位是毫秒（ms）。

對於一個用戶請求，CDN 的回應耗時是以下兩個時間點之間的時間跨度：


* CDN 向使用者傳輸回應的第一個位元組。

* CDN 傳輸完回應的最後一個位元組。


需要留意的是，該指標不是在用戶端統計的接收回應所耗費的時間。

當 CDN 傳輸完回應的最後一個位元組時，該時間點會被記錄為該請求的回應完成時間。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的平均回應時間。該指標資料是針對每個時間區間內 CDN 完成回應的請求統計的。


* 單個時間區間內的回應時間 =（該時間區間內所有請求的回應時間總和）/（該時間區間內的請求數量）


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的回應時間平均值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的回應時間。

2. 計算這些回應時間的平均值。


<span id="平均速度"></span>
### **平均速度**

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">當前，對於 WebSocket 請求，該指標的資料不準確。在查詢該指標的資料時，請過濾掉 WebSocket 協議。</div>


<span id="定義"></span>
#### **定義**

表示 CDN 向用戶傳輸資料時的平均速度，單位是 Bps。該指標是對**回應狀態碼是 2xx** 的用戶請求而統計的。

需要留意的是，該指標不是在用戶端統計的平均資料傳輸速度。

當 CDN 傳輸完回應的最後一個位元組時，該時間點會被記錄為該請求的回應完成時間。在 CDN 對一個時間區間統計下載速度時，統計對象是所有回應完成時間在這個時間區間內的請求。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的平均下載速度，是針對每個時間區間內 CDN 完成回應的那些請求而統計的。


* 單個請求的下載速度 =（CDN 向用戶傳輸的資料量）/（CDN 回應該請求所耗費的時間）

* 一個時間區間內的下載速度 =（該時間區間內所有請求的下載速度總和）/（該時間區間內的請求數量）


在統計下載速度時，CDN 會排除回應時間小於 1 毫秒的請求，以避免資料偏差。

<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的下載速度平均值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的下載速度。

2. 計算這些下載速度的平均值。


<span id="用戶請求的流量命中率（traffic-hitrate）"></span>
### **用戶請求的流量命中率（traffic_hitrate）** 

<span id="定義"></span>
#### **定義**

流量命中率是基於以下傳輸資料量而統計的：


* CDN 向用戶傳輸的資料量。

* 来源伺服器向 CDN 傳輸的資料量。


流量命中率以數值形式顯示。例如，0.9999 表示 99.99%。

<span id="細分資料"></span>
#### **細分資料**

細分資料表示每個時間區間內的流量命中率。


* 單個時間區間內的流量命中率 =（該時間區間內 CDN 向用戶傳輸的資料量 \- 該時間區間內来源伺服器向 CDN 傳輸的資料量）/（該時間區間內 CDN 向用戶傳輸的資料量）


<span id="彙總資料"></span>
#### **彙總資料**

彙總資料表示在實際統計時間段內，所有時間區間內的流量命中率平均值。彙總資料的計算方式如下：


1. 基於指定的統計時間粒度，計算該時間段內每個時間區間內的流量命中率。

2. 計算這些流量命中率的平均值。
