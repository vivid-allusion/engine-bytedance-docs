檢視邊緣函數 CLI 的說明資訊。

<span id="概要"></span>
## 概要

```shell
npx nest help

npx nest help <command>
```


<span id="描述"></span>
## 描述

您可以使用 `npx nest help` 檢視邊緣函數 CLI 的說明資訊，也可以使用 npx nest help `<command>` 檢視指定指令的說明資訊。
