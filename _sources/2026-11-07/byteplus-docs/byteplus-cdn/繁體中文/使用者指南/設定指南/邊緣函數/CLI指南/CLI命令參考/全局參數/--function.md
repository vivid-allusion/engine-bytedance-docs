指定函數的 ID 或名稱。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">本全域參數僅在函數相關的指令中可用</div>


<span id="概述"></span>
## 概述

```shell
--function <function_id_or_name> 
```



* `<function_id_or_name>`：*string，optional*

   * 函數的 ID 或名稱。您可以透過 [nest function list](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-cn-zh-tw) 取得函數 ID 或名稱
