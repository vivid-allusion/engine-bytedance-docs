本文檔介紹如何為函數新增環境變數，並在程式碼中引用環境變數。

環境變數是一組鍵值對。透過環境變數，您無需更新程式碼就可以調整函數在不同環境中的行為。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您對環境變數的新增、刪除、修改操作在函數被再次發佈後才會生效。</div>


<span id="操作步驟"></span>
## 操作步驟

<span id="為函數新增環境變數"></span>
### 為函數新增環境變數

參見以下步驟為函數新增環境變數。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 找到您需要新增環境變數的函數，點擊函數名稱。

3. 選擇 **設定** 標籤頁，然後選擇 **環境變數**。

4. 點擊 **新增變數**。在 **新增變數** 對話方塊，分別輸入變數的 **變數名稱** 和 **值**。您可以新增一個或多個環境變數。變數名稱的規則如下：

   * 必須以英文字母或底線（_）開頭。

   * 只能包含英文字母、數字、底線（_）。

   * 同一函數中環境變數的變數名稱不能重複。

5. 點擊 **確定**。您新增的環境變數會出現在環境變數清單中。


<span id="在程式碼中引用環境變數"></span>
### 在程式碼中引用環境變數

您在程式碼中透過 `env.key` 獲取鍵為 `key` 的環境變數的值。例如，下面的程式碼獲取鍵為 `test` 的環境變數的值。

```JavaScript
const value = env.test;
```
