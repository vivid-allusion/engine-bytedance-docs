本文檔介紹如何為函數配置網域名稱觸發器。

當用戶端透過 HTTP/HTTPS 請求存取函數關聯的網域名稱，且用戶端請求與網域名稱的轉發規則匹配時，網域名稱觸發器會觸發函數程式碼中的 fetch 事件。您需要在程式碼中監聽並處理 fetch 事件。

<span id="使用限制"></span>
## 使用限制

一個函數最多允許關聯 100 個網域名稱，一個網域名稱最多允許關聯 50 個函數。

<span id="配置網域名稱觸發器"></span>
## 配置網域名稱觸發器

您需要完成以下任務來為函數配置網域名稱觸發器。


* [步驟一：為函數關聯網域名稱](https://docs.byteplus.com/en/docs/18/44942#%E6%AD%A5%E9%A9%9F%E4%B8%80%EF%BC%9A%E7%82%BA%E5%87%BD%E6%95%B8%E9%97%9C%E8%81%AF%E7%B6%B2%E5%9F%9F%E5%90%8D%E7%A8%B1)

* [步驟二：為網域名稱配置轉發規則](https://docs.byteplus.com/en/docs/18/44942#%E6%AD%A5%E9%A9%9F%E4%BA%8C%EF%BC%9A%E7%82%BA%E7%B6%B2%E5%9F%9F%E5%90%8D%E7%A8%B1%E9%85%8D%E7%BD%AE%E8%BD%89%E7%99%BC%E8%A6%8F%E5%89%87)

* [步驟三：在函數程式碼中監聽 fetch 事件](https://docs.byteplus.com/en/docs/18/44942#%E6%AD%A5%E9%A9%9F%E4%B8%89%EF%BC%9A%E5%9C%A8%E5%87%BD%E6%95%B8%E7%A8%8B%E5%BC%8F%E7%A2%BC%E4%B8%AD%E7%9B%A3%E8%81%BD-fetch-%E4%BA%8B%E4%BB%B6)


<span id="步驟一：為函數關聯網域名稱"></span>
### 步驟一：為函數關聯網域名稱

<span id="前提條件"></span>
#### 前提條件


* 您的函數已全量發佈，且函數的狀態是 **執行中** 或 **未關聯**。

* 您的網域名稱已接入 BytePlus CDN，並且 **網域名稱狀態** 是 **啟用**。參見 [新增您的網域名稱](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-add-your-domain-name_zh-tw)。


參見以下步驟為函數關聯一個網域名稱。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **觸發器** 標籤頁，然後選擇 **網域名稱** 標籤頁，點擊 **新增網域名稱**。

4. 在 **新增網域名稱** 對話方塊中，選擇一個或多個需要關聯的網域名稱，然後點擊 **儲存**。


網域名稱關聯成功後，您可以在 **觸發器** 標籤頁查看 **網域名稱** 。由於新增的網域名稱沒有配置轉發規則，該網域名稱的狀態為 **離線**。

<span id="步驟二：為網域名稱配置轉發規則"></span>
### 步驟二：為網域名稱配置轉發規則

為函數新增網域名稱後，您還需要為網域名稱配置轉發規則。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **觸發器** 標籤頁，然後選擇 **網域名稱** 標籤頁。

4. 在 **網域名稱** 標籤頁下的網域名稱清單中，選擇需要配置轉發規則的網域名稱。如果您要為該函數下的多個網域名稱配置相同的轉發規則，勾選多個網域名稱。

5. 點擊網域名稱清單下方的 **設定轉發規則**。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您在 <strong>網域名稱</strong> 標籤頁每次只能增量配置一條轉發規則。多次配置會產生多條轉發規則。您可以在 BytePlus CDN 的 <strong>網域名稱管理</strong> 頁面查看網域名稱所關聯的全部轉發規則。參見 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn-zh-tw">使用邊緣函數回應</a>。</div>



6. 在 **設定轉發規則** 頁面參見下表配置轉發規則。



|參數 |說明 |
|---|---|
|網域名稱 |待配置轉發規則的網域名稱。 |
|函數名 |當前函數的名稱，不可修改。 |
|轉發規則 |匹配到轉發規則的用戶端請求會被 BytePlus CDN 轉發到邊緣函數。<br><br><br>* **規則類型**<br><br>   選擇一個規則的類型。該配置取值如下：<br><br>   * 檔案副檔名：規則應用於具有指定副檔名的所有檔案。<br><br>   * URL目錄：規則應用於指定目錄下的所有檔案。<br><br>   * URL完整路徑：規則應用於指定檔案。<br><br>* **規則**<br><br>   根據指定的 **規則類型**，輸入規則內容。規則內容不能超過 1024 個字元。您可以輸入一個或者多個設定，多個設定以英文分號（;）分隔。規則內容的要求如下：<br><br>   * 如果類型是 **檔案副檔名**，需要輸入一個或者多個檔案副檔名。比如 `xlsx` 或者 `png;txt`。檔案副檔名可以包含英文字母和數字。<br><br>   * 如果類型是 **URL 目錄**，需要輸入一個或者多個目錄路徑。目錄路徑必須以斜線（/）開頭和結尾。比如 `/www/img/byte/;/www/doc/`。目錄路徑不能包含連續斜線（//）、百分比符號（%）、空格。如果要指定網域名稱下的所有目錄，輸入 `/`。<br><br>   * 如果類型是 **URL 全路徑**，需要輸入一個或多個完整路徑。路徑以斜線（/）開頭。比如 `/www/img/byteplus.png;/doc/study.docx`。檔案路徑不能包含連續斜線（//）、百分比符號（%）、空格。<br><br>* **忽略大小寫**<br><br>   設定 CDN 在使用 **規則** 匹配用戶端請求的檔案時是否區分大小寫。請求 URL 的其餘部分不受該配置影響。預設設定是開啟。開啟表示不區分大小寫。 |



4. 轉發規則配置完成後，點擊 **儲存**。


您需要等待幾分鐘。當網域名稱的狀態變為 **啟用** 時，表示網域名稱觸發器對於該網域名稱生效。此時，如果用戶端向該網域名稱發起 HTTP/HTTPS 請求且該請求匹配轉發規則，那麼 BytePlus CDN 會把用戶端請求轉發到邊緣函數，而且網域名稱觸發器會觸發與該網域名稱關聯的函數中的 fetch 事件。

<span id="步驟三：在函數程式碼中監聽-fetch-事件"></span>
### 步驟三：在函數程式碼中監聽 fetch 事件

您需要在函數程式碼中監聽 fetch 事件來處理用戶端請求。下面的示例程式碼展示了如何註冊一個事件監聽器監聽 fetch 事件並在 fetch 事件被觸發時呼叫回呼函數向用戶端返回自訂回應。

```JavaScript
// 註冊一個事件監聽器監聽 fetch 事件
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request));
})
// fetch 事件被觸發時，該回呼函數被呼叫
async function handleRequest(request) {
    return new Response('Hello World!', { status: 200 });
}
```
