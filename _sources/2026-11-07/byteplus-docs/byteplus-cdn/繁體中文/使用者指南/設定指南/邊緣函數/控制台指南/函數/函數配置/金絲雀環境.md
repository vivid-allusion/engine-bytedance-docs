本文介紹如何為函數新增和刪除金絲雀節點。

您在發佈函數時，可以選擇金絲雀發佈或全量發佈。金絲雀發佈是指將函數的新版本發佈到所有邊緣伺服器之前，先發佈到一部分邊緣伺服器。這部分邊緣伺服器也稱為金絲雀節點。您可以透過金絲雀節點驗證函數的功能和效能，如果符合預期，就可以發佈到所有邊緣伺服器。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">如果您的函數的發佈類型為金絲雀發佈且從來沒有被全量發佈過，您無法為您的函數關聯轉發規則。參見 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn-zh-tw">使用邊緣函數回應</a>。</div>


在選擇金絲雀節點時，建議您綜合考慮以下因素：


* **流量分佈**：選擇流量較小的地區作為金絲雀節點，以減少對整體業務的影響。例如，您可以在 BytePlus CDN [業務分析](https://console.byteplus.com/cdn/cdn-bp/report/insights) 頁面的 **流量分析** 標籤頁，篩選函數關聯的網域名稱，查看業務在各地區的流量分佈。

* **功能需求**：如果函數需要被部署到指定地區才能滿足功能需求，您需要選擇對應的地區作為金絲雀節點，確保函數可以正常運作。


<span id="操作步驟"></span>
## 操作步驟

<span id="新增金絲雀節點"></span>
### 新增金絲雀節點

參見以下步驟為函數新增金絲雀節點。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 找到您需要新增金絲雀節點的函數，點擊函數名稱。

3. 選擇 **設定** 標籤頁，然後選擇 **金絲雀環境** 標籤頁。

4. 點擊 **新增金絲雀節點**。

5. 在 **新增金絲雀節點** 對話方塊，勾選您需要新增的金絲雀節點，然後點擊 **確定**。


<span id="刪除金絲雀節點"></span>
### 刪除金絲雀節點

參見以下步驟為函數刪除金絲雀節點。


1. 開啟 [函數清單](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 找到您需要刪除金絲雀節點的函數，點擊函數名稱。

3. 選擇 **設定** 標籤頁，然後選擇 **金絲雀環境** 標籤頁。

4. 找到您需要刪除的金絲雀節點，在 **操作** 欄點擊 **刪除**。

5. 在彈出的視窗中點擊 **確定**，即可刪除該金絲雀節點。
