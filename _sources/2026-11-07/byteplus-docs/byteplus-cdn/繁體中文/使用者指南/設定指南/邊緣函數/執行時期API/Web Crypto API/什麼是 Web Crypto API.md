* [digest()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-digest-cn-zh-tw)

* [sign()/verify()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-sign-verify-cn-zh-tw)

* [encrypt()/decrypt()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-encrypt-decrypt-cn-zh-tw)

* [importKey()/exportKey()/generateKey()](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-importKey-exportKey-generateKey-cn-zh-tw)
