本文檔包含邊緣函數的基本概念。

<span id="邊緣伺服器"></span>
## 邊緣伺服器

邊緣伺服器指的是在網路邊緣處進行資料處理和提供計算服務的伺服器叢集。邊緣伺服器的位置靠近資料來源和終端用戶，分佈廣泛。BytePlus CDN 和邊緣函數共享邊緣伺服器。

<span id="函數"></span>
## 函數

邊緣函數中的函數是事件驅動的。函數包括函數配置和函數程式碼。

<span id="觸發器"></span>
## 觸發器

觸發器屬於函數配置。觸發器在滿足特定條件時，會觸發函數程式碼中的事件。邊緣函數支援網域名稱觸發器和 Cron 觸發器。


* 網域名稱觸發器：當用戶端透過 HTTP 或 HTTPS 請求存取函數關聯的網域名稱，且用戶端請求與網域名稱的轉發規則匹配時，網域名稱觸發器會觸發函數程式碼中的 fetch 事件。您需要在程式碼中監聽並處理 fetch 事件。

* Cron 觸發器：定期觸發函數程式碼中的 cron 事件。您需要在程式碼中監聽並處理 cron 事件。


<span id="環境變數"></span>
## 環境變數

您透過環境變數可以在不更新程式碼的情況下調整函數的行為。環境變數通常用於儲存 API 金鑰等敏感資訊或外部服務的 URL 等環境特定的配置資訊。環境變數屬於函數配置。因此，每次變更環境變數後，您都需要重新發佈函數才能使新的環境變數生效。

<span id="版本"></span>
## 版本

您每次發佈函數時，邊緣函數都會為函數自動產生一個版本。該版本包括函數程式碼和函數配置的快照，不包括觸發器。您可以透過版本管理函數程式碼和函數配置。

<span id="金絲雀發佈"></span>
## 金絲雀發佈

金絲雀發佈是指將函數的新版本發佈到所有邊緣伺服器之前，先發佈到一部分邊緣伺服器。您可以透過這部分邊緣伺服器驗證函數的功能和效能，如果符合預期，就可以發佈到所有邊緣伺服器。

<span id="全量發佈"></span>
## 全量發佈

全量發佈是指將函數一次性發佈到所有邊緣伺服器。

<span id="執行時期"></span>
## 執行時期

邊緣函數的執行時期是在 BytePlus 全球邊緣伺服器上的函數執行環境。

<span id="執行時期-api"></span>
## 執行時期 API

執行時期 API 是用於開發者與邊緣函數的執行時期互動的一套 API。

<span id="邊緣-kv"></span>
## 邊緣 KV

邊緣 KV 提供鍵值對資料的分散式儲存服務。

<span id="儲存空間"></span>
## 儲存空間

在邊緣 KV 中，儲存空間是一個邏輯分割區，用於對鍵值對進行分類管理。您可以為不同應用或模組的鍵值對建立單獨的儲存空間。

<span id="鍵值對"></span>
## 鍵值對

資料在邊緣 KV 中以鍵值對的形式儲存。一個鍵值對的鍵在一個儲存空間中唯一。
