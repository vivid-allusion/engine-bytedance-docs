邊緣函數 CLI 提供以下指令。


* [函數](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-manage-funcs-topichead-cn-zh-tw)

   * [nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-cn-zh-tw)：在目前目錄建立一個函數專案並在函數專案中建立一個本地函數。

   * [管理函數](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-manage-functions-topichead-cn-zh-tw)

      * [nest deploy](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-deploy-cn-zh-tw)：將本地函數部署到邊緣節點。

      * [nest upload](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-upload-cn-zh-tw)：將本地函數的程式碼上傳到遠端函數。

      * [nest functions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-function-cn-zh-tw)：對本地函數進行新增/刪除/修改/查詢操作。

   * [偵錯函數程式碼](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-local-dev-cn-zh-tw)

      * [nest debug](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-debug-cn-zh-tw)：在本機偵錯函數程式碼。

      * [nest start](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-start-cn-zh-tw)：在本機執行函數程式碼。

   * [觸發器](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-triggers-topichead-cn-zh-tw)

      * [nest domain](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-domain-cn-zh-tw)：管理網域名稱觸發器。

      * [nest cron](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-cron-cn-zh-tw)：管理 Cron 觸發器。

   * [發佈歷史](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-history-topichead-cn-zh-tw)

      * [nest rollback](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-rollback-cn-zh-tw)：將函數程式碼回滾到歷史發佈版本。

      * [nest versions](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-version-cn-zh-tw)：取得函數程式碼的歷史發佈版本。

      * [nest tickets](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-ticket-cn-zh-tw)：取得函數程式碼的發佈記錄。

   * [函數設定](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-ref-function-config-topichead-cn-zh-tw)

      * [nest envs](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-env-cn-zh-tw)：管理函數的環境變數。

      * [nest canary](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-canary-cn-zh-tw)：管理函數的金絲雀環境。

* [邊緣KV](https://docs.byteplus.com/docs/byteplus-cdn/edge-function-cli-ref-edge-kv-topichead-cn-zh-tw)

   * [nest kv](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-kv-cn-zh-tw)：管理邊緣 KV。

* [輔助工具](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-cli-others-topichead-cn-zh-tw)

   * [nest config](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-config-cn-zh-tw)：管理邊緣函數 CLI 設定。

   * [nest help](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-help-cn-zh-tw)：取得說明資訊。

* [全域參數](https://docs.byteplus.com/docs/byteplus-cdn/global-parameters-cn-zh-tw)

   * [--config](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-c-cn-zh-tw)

   * [--function](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-f-cn-zh-tw)

   * [--verbose](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global-verbose-cn-zh-tw)

   * [--help](https://docs.byteplus.com/docs/byteplus-cdn/edge-functions-global--help-cn-zh-tw)
