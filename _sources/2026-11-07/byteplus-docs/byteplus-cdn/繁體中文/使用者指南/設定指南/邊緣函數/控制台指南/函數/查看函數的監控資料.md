本文檔介紹如何查看函數的監控資料。

監控資料展示了函數的執行次數、資源消耗、回應事件、錯誤數等資料。您可以透過這些資料了解函數的運作情況並進行除錯。

<span id="操作步驟"></span>
## 操作步驟

參見以下步驟查看函數的監控資料。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list)頁面。

2. 找到要查看監控資料的函數，點擊函數名稱。

3. 選擇 **概觀** 標籤頁。您可以在該頁面查看函數的監控資料。邊緣函數預設展示過去 24 小時的監控資料。您可以修改時間範圍，查看過去 7 天內任意時間段（精確到秒）的資料。


<span id="監控資料詳情"></span>
## 監控資料詳情

監控資料包含統計資料和趨勢圖。

<span id="統計資料"></span>
### 統計資料

邊緣函數允許您查看以下統計資料。


|指標 |描述 |單位 |
|---|---|---|
|QPS |每秒鐘函數執行的次數。 |/ |
|記憶體使用量 |函數執行過程中的平均記憶體消耗。 |KB |
|CPU使用率 |函數執行過程中每個請求的 CPU 時間的 P95 值。 |us |
|回應時間 |函數執行過程中每個請求的回應時間的 P95 值。 |ms |
|錯誤數 |每秒鐘返回的在指定時間範圍內失敗的請求的比率。請參照 [呼叫狀態](https://docs.byteplus.com/en/docs/18/44941#%E5%91%BC%E5%8F%AB%E7%8B%80%E6%85%8B) 了解函數請求執行失敗的原因。 |/ |


<span id="趨勢圖"></span>
### 趨勢圖

趨勢圖展示了統計資料隨時間的分佈，即在指定時間段內各個指標資料的波動。

<span id="qps"></span>
#### QPS

每秒鐘函數執行的次數。

<span id="回應時間"></span>
#### 回應時間

每個請求的回應時間。

<span id="cpu使用率"></span>
#### CPU使用率

在指定時間範圍內，函數執行的 CPU 時間。

<span id="記憶體使用量"></span>
#### 記憶體使用量

在指定時間範圍內，函數的平均記憶體消耗。

<span id="回應狀態"></span>
#### 回應狀態

在指定時間範圍內，HTTP 回應狀態碼的數量。例如，如果 HTTP 回應狀態碼在 [200,300)之間，2xx 回應的計數增加 1。3xx，4xx，5xx 也是如此。

如果回應狀態碼不在 [200,600) 內，該狀態碼被記錄為未知。

<span id="呼叫狀態"></span>
#### 呼叫狀態

函數請求執行的錯誤狀態分佈。


* cpu_time_abort：由 CPU 逾時引發的執行錯誤。

* real_time_abort：由回應時間逾時引發的錯誤。

* memory_abort：由記憶體用盡引發的錯誤。

* other_abort：表示由於異常的用戶端情況導致的錯誤，例如用戶端過早終止請求。

* error：表示其他錯誤，例如租戶程式碼中未經處理的異常。
