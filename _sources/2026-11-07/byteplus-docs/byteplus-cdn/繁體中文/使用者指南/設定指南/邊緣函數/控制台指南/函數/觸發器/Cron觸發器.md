本文檔介紹如何為函數配置 Cron 觸發器。

您可以建立 Cron 觸發器來建立定期任務，Cron 觸發器會在指定時間自動觸發函數程式碼中的 cron 事件。您需要在程式碼中監聽並處理 cron 事件。

<span id="建立-cron-觸發器"></span>
## 建立 Cron 觸發器

參見以下步驟建立一個 Cron 觸發器。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 找到需要建立 Cron 觸發器的函數並點擊函數的名稱。

3. 選擇 **觸發器** 標籤頁，然後選擇 **Cron** 標籤頁。

4. 點擊 **新增 Cron 觸發器**。

5. 在 **新增 Cron 觸發器** 對話方塊，參考下方表格填寫相關設定後，點擊 **儲存** 完成。



|設定項 |描述 |
|---|---|
|名稱 |填寫 Cron 觸發器的名稱。名稱規則如下：<br><br><br>* 只能包含英文字母、數字和連字元（\-）。<br><br>* 最多不能超過 128 個字元。 |
|排程類型 |選擇 cron 事件被觸發的邊緣伺服器。<br><br><br>* **全域**：cron 事件在所有邊緣伺服器被觸發。<br><br>* **單點**：cron 事件在隨機的一個邊緣伺服器觸發。 |
|執行時間 |cron 事件被觸發的時間。設定後您可以在右側 **預計執行時間（UTC）**  查看是否符合預期。<br><br><br>* **Cron 表達式**：填寫 Cron 表達式，參見 [支援的 Cron 表達式](https://docs.byteplus.com/en/docs/18/44943#supportedcron)。<br><br>* **自訂**：選擇 **執行頻率** 和 **執行時刻**，邊緣函數會自動產生對應的 Cron 表達式。 |
|參數 |輸入自訂參數。在函數執行時，邊緣函數把該參數傳遞給 [CronEvent](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-CronEvent-cn-zh-tw)。 |



6. 建立 Cron 觸發器後，為了確保 Cron 觸發器生效，您還需要：

   * 確保 Cron 觸發器的狀態為 **啟用**。

   * 在函數程式碼中監聽 cron 事件。下面的示例程式碼展示了如何註冊一個事件監聽器監聽 cron 事件並在 cron 事件被觸發時呼叫回呼函數實現定時任務。

      ```JavaScript
      // 註冊一個事件監聽器，監聽 cron 事件
      addEventListener('cron', onCron);
      
      // cron 事件被觸發時，被呼叫的回呼函數
      async function onCron(event) {
        // 這裡可以新增定時任務的具體程式碼
          return 'this is log';
      }
      ```

<span id="支援的-cron-表達式"></span>
### 支援的 Cron 表達式

Cron 表達式是一個由 5 個欄位組成的字串。這些欄位由空格分隔。Cron 表達式預設在 UTC+8:00 時區執行。

**Cron表達式欄位說明**


|第一位 |第二位 |第三位 |第四位 |第五位 |
|---|---|---|---|---|
|分鐘 |小時 |日 |月 |星期 |


其中，每個欄位都有相應的取值範圍：


|欄位 |取值範圍 |允許的特殊字元 |
|---|---|---|
|分鐘 |0\-59的整數 |,\-\*/ |
|小時 |0\-23的整數 |,\-\*/ |
|日 |1\-31的整數（需要考慮月的天數） |,\-\*?/L |
|月 |1\-12的整數或不區分大小寫的月份 3 個字母縮寫（「JAN」、「aug」等） |,\-\*/ |
|星期 |0\-6的整數或不區分大小寫的星期 3 個字母縮寫（「MON」、「fri」等）。其中0指星期日，1指星期一，以此類推。 |,\-\*?/L |


**特殊字元說明**


|字元 |含義 |說明 |
|---|---|---|
|\*（星號） |表示選擇欄位中的所有值 |例如，在「分鐘」欄位中，表示每分鐘執行。 |
|,（逗號） |指定多個值 |例如，在「星期」欄位中，「MON,WED,FRI」表示「星期一、星期三和星期五」。 |
|\-（連字元） |指定範圍 |例如，在「小時」欄位中，「10\-12」，表示從「10點到12點」。 |
|?（問號） |表示不確定的值 |與其他指定值組合使用。例如，指定了每月一個特定的日期，但不需要關注該日期是星期幾，那麼「星期」欄位就可以使用?。 |
|/（正斜線） |表示增加幅度，n/m表示從n開始，每次增加m |例如，在「分鐘」欄位中，1/3表示從1分鐘開始，每隔3分鐘執行一次。 |
|#（井號） |表示每個月第幾個星期幾，只能出現在「星期」這個欄位 |與其他指定值組合使用。例如，在「星期」中，5#2表示某月的第二個星期五，5 表示星期五，2 表示第二個。 |
|L（大寫英文字母L） |表示最後，只能出現在「日」和「星期」兩個欄位 |例如，在「日」欄位中，表示每月最後一天。在「星期」這個欄位使用 5L，表示在最後的一個星期五觸發。 |


**示例**


|Cron表達式 |說明 |
|---|---|
|\* \* \* \* \* |每一分鐘執行一次 |
|\* /30 \* \* \* \* |每隔30分鐘執行一次 |
|\* 23 \* \* \* |每日23時的每一分鐘執行 |
|10,20,30 \* \* \* \* |每個小時的10分，20分，30分執行一次 |
|30 7 \* \* MON\-FRI |週一到週五的每天7:30執行一次 |
|0 8 1 \* \* |每月第一天8:00執行一次 |
|0 8 \* JAN\-JUN \* |1月到6月每天8:00執行一次 |


<span id="查看排程記錄"></span>
## 查看排程記錄

參見以下步驟查看 Cron 觸發器的排程記錄。目前，您僅能查看最近 6 個月的排程記錄。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。找到您需要查看的函數，點擊函數名稱。

2. 選擇 **觸發器** 標籤頁，然後選擇 **Cron** 標籤頁。

3. 在 Cron 觸發器清單中，找到您需要查看的 Cron 觸發器，點擊觸發器名稱進入 **排程記錄** 頁面。

4. 在 **排程記錄** 頁面查看排程記錄資訊，包含執行表達式、參數、狀態、建立時間等資訊。您還可以透過 **表達式** 和 **參數** 欄位搜尋特定記錄。

5. 點擊 **查看日誌** 查看函數在各節點執行的日誌詳情。


<span id="啟動或停用-cron-觸發器"></span>
## 啟動或停用 Cron 觸發器

您可以啟用或停用 Cron 觸發器。切換 Cron 觸發器的狀態後立即生效，您無需重新發佈函數。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。找到您需要查看的函數，點擊函數名稱。

2. 選擇 **觸發器** 標籤頁，然後選擇 **Cron** 標籤頁。

3. 找到需要啟用或停用的 Cron 觸發器，點擊 **狀態** 欄中的開關，切換 Cron 觸發器的啟用狀態。


<span id="刪除-cron-觸發器"></span>
## 刪除 Cron 觸發器

如果您不再需要一個 Cron 觸發器，可以刪除該 Cron 觸發器。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Cron 觸發器被刪除後無法恢復，請謹慎操作。</div>



1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。找到您需要刪除的函數，點擊函數名稱。

2. 選擇 **觸發器** 標籤頁，然後選擇 **Cron** 標籤頁。

3. 找到需要啟用或停用的 Cron 觸發器，點擊 **操作** 欄中的 **刪除**。

4. 在彈出的視窗中確認待刪除的 Cron 觸發器，點擊 **確定** 按鈕完成操作。
