本示例展示如何一次請求多個檔案並以串流方式返回。

當網頁中含有多個無依賴關係的靜態檔案需要載入時，瀏覽器會分別發送請求。由於瀏覽器有併發請求數量限制，為減少 HTTP 請求次數，可透過 URL 查詢參數合併多個檔案請求。

例如，網頁中的 <script\> 標籤 src 屬性包含名為 urllist 的查詢參數，該參數包含多個 .js 檔案的 URL 路徑：

```html
<script src="http://www.example.com/?urllist=/react/a.min.js,/react/b.min.js"></script>
```


函式收到請求時，先解析查詢參數取得各檔案路徑，組合為完整 URL 後非同步請求檔案，並以串流方式即時返回給使用者。

```JavaScript
async function handle(event) {
  const request = event.request; 
  const url = new URL(request.url);
  const fetchList = url.searchParams.get("urllist").split(",");
  const {readable, writable} = new TransformStream();
  
  (async () => {
    let idx = 0;
    for (const u of fetchList) {
      const resp = await fetch(`http://${url.host}${u}`);
      const close = (idx === fetchList.length - 1);  // 修正相等運算子
      resp.body.pipeTo(writable, {preventClose: close});
      idx++;
    }
  })();
  
  return new Response(readable, {
    status: 200,
    headers: {'Content-Type': 'application/javascript'}  // 新增內容類型標頭
  });
}

addEventListener('fetch', (event) => {
  event.respondWith(handle(event));
});
```
