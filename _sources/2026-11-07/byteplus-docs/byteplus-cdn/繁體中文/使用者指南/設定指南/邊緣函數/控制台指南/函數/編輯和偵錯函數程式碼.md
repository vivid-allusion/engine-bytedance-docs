本文檔介紹如何編輯和偵錯函數程式碼。

<span id="使用限制"></span>
## 使用限制

邊緣函數的偵錯環境暫不支援執行 [邊緣 KV 的執行時期 API](https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-EdgeKV-RuntimeAPI-cn-zh-tw)。邊緣 KV 的執行時期 API 只能在正式環境執行。

<span id="操作步驟"></span>
## 操作步驟

參見以下步驟編輯和偵錯函數程式碼。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 找到需要編輯和偵錯程式碼的函數並點擊函數的名稱。

3. 選擇 **程式碼** 標籤頁，點擊 **編輯並部署**。

4. 使用程式碼編輯器編輯程式碼。

5. 在 HTTP 標籤頁中，按以下說明對偵錯器進行設定。設定完成後點擊 **發送**。您可以在頁面的右側區域查看函數執行結果。在頁面的底部區域查看函數的日誌、執行資訊及性能。

   * 選擇一個 HTTP 請求方法。

   * 填入用於模擬用戶端請求的 URL。函數預設使用類似 `http://a5624*****33b010b` 的 URL 作為模擬用戶端請求的 URL，其中 `a5624*****33b010b` 是函數的 ID。該 URL 可用於觸發 fetch 事件。但是，該 URL 只能用於 Debugger 內部測試，而無法透過網際網路存取。另外，對於 Debugger 中模擬的用戶端請求，`FetchEvent.info` 中的屬性值均為 `undefined`。因此，Debugger 報錯並不代表您的程式碼出現了錯誤。您需要在灰度環境對 Debugger 不支援的程式碼進行測試。

   * （選填）新增 Header、Body。

      * Header：自訂 HTTP 請求標頭。

      * Body：自訂 HTTP 請求體。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">您需要在 HTTP 標籤頁顯示綠點的情況下，傳送請求偵錯函數。如果您長時間未操作，偵錯器會與伺服器中斷連線，此時，HTTP 標籤頁會顯示紅點，且您無法進行偵錯。您重新整理頁面後，偵錯器將會自動重新連線，HTTP 標籤頁會顯示綠點。      </div>
      

6. 在 Debugger 中傳送請求後，您可以查看 **控制台**、**資料洞察** 和 **性能** 標籤頁了解函數的執行情況。



<Tabs>
<Tab zoneid="oFOWSabD3w" title="控制台">
<TabTitle>控制台</TabTitle>

回應的 Body 內容不會自動打印到日誌中，您需要在函數的程式碼中使用`console.log()` /`console.info()`/`console.error()`/`console.trace()`等語句，自訂需要查看的日誌資訊。


</Tab>
<Tab zoneid="VVVau6EYK1" title="資料洞察">
<TabTitle>資料洞察</TabTitle>

在 **資料洞察** 頁標籤頁下勾選 **啟用洞察** ，傳送請求之後，您可以查看函數最近一次請求所產生的程式碼執行資訊。


</Tab>
<Tab zoneid="pYfdneRjBh" title="性能">
<TabTitle>性能</TabTitle>

在 **效能** 頁籤下，您可以透過火焰圖來分析函數回應性能。


1. 點擊圖標 ● 開始錄製。

2. 點擊 **發送請求** 觸發程式碼執行。

3. 點擊 **停止錄製**，CPU Profiler 的火焰圖會被生成。


</Tab>
