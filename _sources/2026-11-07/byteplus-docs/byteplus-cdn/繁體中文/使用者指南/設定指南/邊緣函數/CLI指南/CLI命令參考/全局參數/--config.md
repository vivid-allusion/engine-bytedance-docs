指定一個函數設定檔。本地函數預設使用資料夾根目錄的 nest.json 檔案作為設定檔。

<span id="概述"></span>
## 概述

```shell
--config <config_file_path> 
```



* `<config_file_path>`：*string，required*

   * 函數設定檔的路徑
