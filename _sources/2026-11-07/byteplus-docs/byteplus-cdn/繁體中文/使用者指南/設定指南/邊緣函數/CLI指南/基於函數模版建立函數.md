本文檔介紹如何使用邊緣函數 CLI 中基於函數範本建立函數。

對於邊緣函數 CLI，您可以選擇的函數範本取決於您是否設定了 Access Key ID 和 Secret Access Key：


* 如果您沒有設定 Access Key ID 和 Secret Access Key，您只能使用內建範本。

* 如果您設定了 Access Key ID 和 Secret Access Key ，您可以使用邊緣函數支援的所有範本。


<span id="前提條件"></span>
## 前提條件


* 您已安裝了邊緣函數 CLI。參見 [安裝CLI](https://docs.byteplus.com/en/docs/byteplus-cdn/get-started-with-edge-function-cli-cn-zh-tw)。

* 您已經在全域專案設定檔中設定了您的 Access Key ID 和 Secret Access Key。參見 [設定您的 Access Key ID 和 Secret Access Key](https://docs.byteplus.com/en/docs/byteplus-cdn/edge-functions-cli-login-cn-zh-tw)。


<span id="操作步驟"></span>
## 操作步驟


1. 在您的裝置上執行以下指令。該指令會安裝邊緣函數 CLI，然後建立一個函數專案，並在函數專案中建立一個本地函數。參見 [nest init](https://docs.byteplus.com/docs/byteplus-cdn/cli-ref-nest-init-cn-zh-tw)。


```shell
$ npx @byteplus/nest@latest init
```



2. 根據命令列提示設定函數的名稱，並選擇一個函數範本。然後，按 Enter 鍵確認。


```shell
$ npx @byted/nest@latest init

```

指令執行完成後，您當前的目錄結構如下：

```markdown
└── 📁MyFolder
    └── 📁test
        └── nest.json
        └── package-lock.json
        └── package.json
        └── 📁src
            └── index.js
    └── package.json
```


其中，`test` 目錄是您建立的函數專案，`test/src/index.js` 是您的本地函數的入口檔案。index.js 檔案的內容就是您選擇的函數範本。

您可以在 `MyFolder` 目錄透過以下指令查看根據函數範本產生的程式碼檔案。

```shell
$ cat test/src/index.js
addEventListener('fetch', event => {
  event.respondWith(onFetch(event));
})

const OLD_URL = "s.taobao.com";
const NEW_URL = "s.mynewdomain.com";

async function onFetch(event) {
  const path = event.request.path;
  const response = await fetch(`https://www.taobao.com${path}`);

  const rewrite = function(element, tag) {
    if (element.hasAttribute(tag)) {
      const href = element.getAttribute(tag);
      const new_href = href.replace(OLD_URL, NEW_URL);
      console.log(`replace(${tag}) ${href} => ${new_href}`);
      element.setAttribute(tag, new_href);
    }
  }
  const rewriteBody = createHtmlStream(
    response.body,
    undefined,
     [
        [
          'a',  // CSS selector, 'a' stands for selecting all the 'a' tags in the webpage
          {
            // This onElement callback will be triggered after 'a' tags in the webpage are parsed
            onElement(element) {
              rewrite(element, "href")
            }
          }
        ],
        [
          'img',
          {
            // This onElement callback will be triggered after 'img' tags in the webpage are parsed
            onElement(element) {
              rewrite(element, "src")
            }
          }
        ]
      ]
  );

  return new Response(
    rewriteBody,
    {
      status: response.status,
      headers: response.headers
    }
  )
```
