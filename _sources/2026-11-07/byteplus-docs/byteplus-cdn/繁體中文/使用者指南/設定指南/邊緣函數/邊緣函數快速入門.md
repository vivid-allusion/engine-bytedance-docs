本教學基於簡單的示例場景介紹如何在 BytePlus CDN 中使用邊緣函數。

<span id="前提條件"></span>
## 前提條件

您已經開通了邊緣函數。參見 [開通邊緣函數](https://docs.byteplus.com/docs/byteplus-cdn/activate_byteplus_edge_functions_zh-tw)。

<span id="示例場景"></span>
## 示例場景

您有一個網站，網域名稱是 `www.example.com`。您在 BytePlus CDN 添加了該網域名稱。您希望透過邊緣函數修改來源伺服器返回的錯誤頁面，發送更為友善的自訂頁面給用戶端。

<span id="操作步驟"></span>
## 操作步驟

參見以下步驟在 BytePlus CDN 中使用邊緣函數。


1. **建立函數**：建立一個函數。

2. **編輯與偵錯程式碼**：在函數中編輯和偵錯程式碼。

3. **發佈函數**：將函數部署到 BytePlus CDN 的全球邊緣伺服器。

4. **關聯網域名稱**：把函數的觸發器設定為網域名稱觸發器，並在網域名稱觸發器中將函數與您的網域名稱關聯。

5. **為網域名稱配置轉發規則**：為您的網域名稱配置轉發規則，當 BytePlus CDN 收到匹配轉發規則的用戶端請求時，會將該請求轉發到邊緣函數。

6. **驗證函數**：驗證函數的實際執行結果是否符合預期。


<span id="步驟一：建立函數"></span>
## 步驟一：建立函數


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，點擊 **建立函數**。

3. 在 **建立函數** 頁面，根據以下說明配置相關參數。

   * **名稱**：在本教學中，您把 **名稱** 設定為 `custom-error-page`。

   * **專案**：在本教學中，您把 **專案** 設定為`default`。

   * **建立方式**：在本教學中，您選擇 **使用範本建立**，然後選擇 **改寫來源伺服器錯誤回覆頁面** 範本。

      <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_8774ceff73604702799cc1f862b931a9.png) </span>

4. 點擊 **儲存** 建立函數。


接下來，您需要編輯和偵錯程式碼。

<span id="步驟二：編輯和偵錯程式碼"></span>
## 步驟二：編輯和偵錯程式碼


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **程式碼** 標籤頁，點擊 **編輯並部署**。

4. 在程式碼編輯器中檢視 default 檔案。您可以根據需求自行修改程式碼。本教學使用範本提供的程式碼。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">程式碼中呼叫了 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-addEventListener-cn-zh-tw">addEventListener()</a> 用於註冊一個事件監聽器。參數中傳入了 <code>fetch</code> 和一個回呼函數 <code>{event.respondWith(handleResponse(event));}</code>：   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1"><code>fetch</code> 表示該事件監聽器會監聽 fetch 事件，如果 fetch 事件被網域名稱觸發器觸發，則回呼函數會被呼叫。您在步驟四會為函數配置網域名稱觸發器。參見 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-FetchEvent-cn-zh-tw">FetchEvent</a>。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果來源伺服器回應的狀態碼是 5xx，回呼函數會把來源伺服器回應改寫為您自訂的 HTML 頁面，即 <code>htmlResponse</code> 常數中的 HTML 程式碼。   </div>
   

   ```JavaScript
   const htmlResponse = `
   <html>
   
     <head>Error Page</head>
     <body>The server is experiencing some issues, please try again later</body>
   </html>
   `;
   
   // Add an EventListener to listen to fetch event. A domain trigger will trigger a fetch event
   addEventListener('fetch', (event) => {
     event.respondWith(handleResponse(event));
   });
   
   function isErrorStatus(st) {
     return st >= 500;
   }
   
   async function handleResponse(event) {
     const response = await fetch(event.request);
   
     // If the origin server returns a status code >= 500, then return the custom error page
     // Otherwise, return the information from the origin server.
     if (isErrorStatus(response.status)) {
       return htmlResponse;
     } else {
       return response;
     }
   }
   ```
   

5. 對程式碼進行偵錯。在本教學中，您填入一個會返回 5xx 狀態碼的 URL，點擊 **發送**，並檢查返回的結果是否符合預期。偵錯完成後，點擊 **儲存**。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">您需要在 HTTP 標籤頁顯示綠點時，傳送請求偵錯函數。如果您長時間未操作，偵錯器會與伺服器中斷連線，此時，HTTP 標籤頁會顯示紅點，且您無法進行偵錯。您重新整理頁面後，偵錯器將會自動重新連線，HTTP 標籤頁會顯示綠點。   </div>
   

接下來，您需要發佈函數。

<span id="步驟三：發佈函數"></span>
## 步驟三：發佈函數

您必須先將函數全量發佈之後，才能將其與網域名稱關聯。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **程式碼** 標籤頁，點擊 **編輯並部署**。

4. 點擊 **部署** 按鈕。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">您可以在全量發佈函數之前進行金丝雀發佈。參見 <a href="https://docs.byteplus.com/docs/byteplus-cdn/docs_cn-create-function-cn-zh-tw">管理函數</a>。   </div>
   

5. 在 **部署** 對話方塊中，把 **發佈類型** 設定為 **完整發佈** ，然後點擊 **確定**。


接下來，您需要為函數關聯網域名稱。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">函數全量發佈一般需要 5 ~ 10 分鐘。您必須在函數全量發佈完成後才能為函數關聯網域名稱。</div>


<span id="步驟四：關聯網域名稱"></span>
## 步驟四：關聯網域名稱

在本示例中，您使用網域名稱觸發器觸發函數的執行。因此，您需要為函數關聯網域名稱`www.example.com`。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **觸發器** 標籤頁，然後選擇 **網域名稱** 標籤頁，點擊 **新增網域名稱**。

4. 在 **新增網域名稱** 頁面選擇 `www.example.com` 網域名稱。

5. 點擊 **儲存**。與網域名稱關聯完成後，函數的狀態會變為 **設定中**。由於您還沒有為網域名稱配置轉發規則，該網域名稱的狀態是 **離線**。


接下來，您需要為網域名稱配置轉發規則。

<span id="步驟五：為網域名稱配置轉發規則"></span>
## 步驟五：為網域名稱配置轉發規則

您為網域名稱配置轉發規則後，如果 BytePlus CDN 收到一個與轉發規則匹配的用戶端請求，會把該請求轉發到邊緣函數。而且，網域名稱觸發器會觸發函數中的 fetch 事件。


1. 開啟 [函數管理](https://console.byteplus.com/cdn/edge-function/list) 頁面。

2. 在 **函數管理** 頁面，在 **名稱** 欄找到您建立的函數，然後點擊函數的名稱。

3. 選擇 **觸發器** 標籤頁，然後選擇 **網域名稱** 標籤頁。點擊您的網域名稱 `www.example.com` 前方的核取方塊，然後點擊 **設定轉發規則** 按鈕。

4. 在 **設定轉發規則** 頁面中，參照下表設定 **轉發規則** 參數項。本示例不對用戶端請求的 URL 的路徑進行限制，因此會匹配任意路徑。

   
   |參數名稱 |說明 |
   |---|---|
   |規則類型 |在本教學中，您需要設定為 **URL目錄**。 |
   |規則 |在本教學中，您需要設定為 `/`，表示匹配網域名稱下的全部路徑。 |
   |忽略大小寫 |在本教學中，您需要保留預設值。 |
   

5. 點擊 **儲存**。您需要等待幾分鐘。當網域名稱的狀態變為 **啟用** 時，表示網域名稱觸發器已經對該網域名稱生效。此時，如果用戶端向該網域名稱發起 HTTP 或 HTTPS 請求且該請求匹配轉發規則，那麼網域名稱觸發器會觸發與該網域名稱關聯的函數中的 fetch 事件。


接下來，您驗證函數的執行結果是否符合預期。

<span id="步驟六：驗證函數"></span>
## 步驟六：驗證函數

您可以存取 www.example.com，並驗證：


* 來源伺服器回應碼為 5xx 時，返回的 HTML 頁面是程式碼中 `htmlResponse` 常數的值。

* 來源伺服器回應碼不是 5xx 時，返回的 HTML 頁面來自來源伺服器。


如果驗證無誤，則說明您的示例場景已實現。
