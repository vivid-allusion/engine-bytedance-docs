邊緣函數提供函數服務和邊緣 KV 服務。


* 函數服務是在 BytePlus 的全球邊緣節點上的無伺服器運算服務。您可以為函數編寫 JavaScript 程式碼，然後發布函數把 JavaScript 程式碼部署在全球邊緣節點上，用於處理使用者請求。

* 邊緣 KV 服務是在 BytePlus 的全球邊緣節點上的分散式鍵值儲存服務。邊緣 KV 適用於低頻寫入、高頻讀取的場景。


<span id="應用場景"></span>
## 應用場景

<span id="邊緣側渲染"></span>
### 邊緣側渲染

您可以使用邊緣函數建構邊緣閘道器，實現邊緣側渲染。相比伺服器側渲染，邊緣側渲染降低了使用者的首屏載入時間，減輕了伺服器端的工作負載。

例如，使用者需要存取一個網頁。當使用者請求到達邊緣閘道器時，邊緣閘道器先從來源伺服器或 CDN 快取中獲取靜態 HTML，並把靜態 HTML 返回給使用者。此時，客戶端瀏覽器開始解析 HTML 並生成 DOM 樹，並從邊緣閘道器獲取渲染資源。邊緣閘道器從 CDN 快取或來源伺服器獲取靜態資源（例如 .css 檔案、.js 檔案或圖片檔案），並通過非同步請求同時從來源伺服器獲取動態資源。邊緣閘道器優先向使用者返回靜態資源，並把獲取的動態資源拼接到靜態資源，然後把拼接完成的 HTML 流式返回給使用者。

<span id="在邊緣側處理使用者請求"></span>
### 在邊緣側處理使用者請求

您可以使用邊緣函數搭建高效能、高可用的邊緣閘道器，對使用者請求進行自定義處理，例如合併或修改使用者請求、實現 CORS，對使用者請求進行身份驗證等。

<span id="持續整合和持續交付-部署（ci-cd）"></span>
### 持續整合和持續交付/部署（CI/CD）

您可以使用邊緣函數搭建針對 API 或者網站的邊緣 CI/CD 流水線，用於實現資料處理、A/B 測試、根據使用者特徵返回個人化內容、請求重新導向、錯誤兜底降級、健康檢查、並發請求競速、效能測試等功能。
