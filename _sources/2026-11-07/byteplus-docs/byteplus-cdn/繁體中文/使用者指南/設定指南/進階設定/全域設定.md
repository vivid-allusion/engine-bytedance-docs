本文件介紹了 BytePlus CDN 中的「全域設定」功能。

<span id="功能描述"></span>
## 功能描述

全域設定擴展了策略的設定能力，具有以下優點：


* 提升了允許/封鎖清單的容量。例如，「IP 封鎖清單」可以包含高達 30,000 個條目。

* 提升了網域名稱設定的效率。一個全域設定可與多個策略關聯，一個策略可以與多個網域名稱綁定。

* 提供了「通用清單」類型，可以在額外的網域名稱設定中被使用。


一個全域設定的修改可立即應用於其關聯的所有策略，進而應用於這些策略所綁定的網域名稱。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">目前，您可以在全域設定中建立 IP 封鎖清單、IP 允許清單、Referer 封鎖清單、Referer 允許清單和通用清單。</div>


<span id="建立全域設定"></span>
## 建立全域設定

<span id="通用操作步驟"></span>
### 通用操作步驟


1. 登入 [BytePlus CDN 管理控制台](https://console.byteplus.com/cdn)。

2. 在左側導覽列，點擊 **進階設定** \> **全域設定**。

3. 在 **全域設定** 頁面，點擊 **新增**。

4. 在 **新增全域設定** 頁面，輸入設定名稱並指定該全域設定將要歸屬的專案。

   * 全域設定的名稱可以包含漢字、字母、數字、底線（_），長度在 3\-45 個字元之間。一個漢字佔 3 個字元。

   * 您可以在 [存取控制](https://console.byteplus.com/iam/identitymanage/user) 中設定專案與權限，指定每個子使用者可以存取的全域設定。

5. 參考相應的設定說明進行設置。

   * [類型：IP 存取控制](https://docs.byteplus.com/en/docs/18/36529#ip-%E5%AD%98%E5%8F%96%E6%8E%A7%E5%88%B6%E7%9A%84%E8%A8%AD%E5%AE%9A)

   * [類型：Referer 存取控制](https://docs.byteplus.com/en/docs/18/36529#Referer-%E5%AD%98%E5%8F%96%E6%8E%A7%E5%88%B6%E7%9A%84%E8%A8%AD%E5%AE%9A)

   * [類型：通用清單](https://docs.byteplus.com/en/docs/18/36529#%E9%80%9A%E7%94%A8%E6%B8%85%E5%96%AE%E7%9A%84%E8%A8%AD%E5%AE%9A)

6. 完成設定後，點擊 **提交**。設定提交後，全域設定就建立了。此時，頁面會顯示該全域設定的詳情。您可以點擊 **返回**。如果您需要修改該全域設定所包含的條目，點擊 **修改**，然後遵循 [修改全域設定](https://docs.byteplus.com/en/docs/18/36529#%E4%BF%AE%E6%94%B9%E5%85%A8%E5%9F%9F%E8%A8%AD%E5%AE%9A) 中的步驟進行操作。接下來，您需要 [將該全域設定與一個或者多個策略關聯](https://docs.byteplus.com/en/docs/18/36529#%E9%97%9C%E8%81%AF%E5%85%A8%E5%9F%9F%E8%A8%AD%E5%AE%9A%E8%88%87%E7%AD%96%E7%95%A5) 以使該全域設定對這些策略所綁定的網域名稱生效。


<span id="ip-存取控制的設定"></span>
### IP 存取控制的設定


|**設定** |**說明** |
|---|---|
|應用場景 |對於 IP 存取控制，您可以選擇以下某個選項：<br><br><br>* **IP 允許清單**：表示只有一個請求的來源 IP 位址在 **規則** 清單中，CDN 才允許該請求。<br><br>* **IP 封鎖清單**：表示如果一個請求的來源 IP 位址在 **規則** 清單中，CDN 會拒絕該請求。 |
|規則 |表示 **應用場景** 對應的清單。清單中的條目可以是 IP 位址和 CIDR 網段。IP 位址和網段可以是 IPv4 和 IPv6 格式。您可以輸入最多 30,000 個條目，多個條目使用分號（;）分隔或者分行輸入。您也可以上傳一個包含這些條目的 .txt 檔案。清單中重複的條目會被刪除，不計入條目總數。 |


<span id="referer-存取控制的設定"></span>
### Referer 存取控制的設定


|**設定** |**說明** |
|---|---|
|應用場景 |對於 Referer 存取控制，您可以選擇以下某個選項：<br><br><br>* **Referer 允許清單**：表示只有一個請求的 Referer 標頭在 **規則** 清單中，CDN 才允許該請求。<br><br>* **Referer 封鎖清單**：表示如果一個請求的 Referer 標頭在 **規則** 清單中，CDN 會拒絕該請求。 |
|規則 |表示 **應用場景** 對應的清單。清單中的條目可以是網域名稱、IP 位址和 CIDR 網段，用來匹配請求 Referer 標頭中的 hostname。暫時不支援設定 URL 為條目。<br><br>&nbsp;<br><br>IP 位址和網段可以是 IPv4 和 IPv6 格式，網域名稱可以是萬用字元網域名稱。您可以輸入最多 4,000 個條目，多個條目使用分號（;）分隔或者分行輸入。您也可以上傳一個包含這些條目的 .txt 檔案。清單中重複的條目會被刪除，不計入條目總數。 |
|忽略大小寫 |表示 **規則** 中的內容是否是大小寫敏感的。 |
|空 Referer 處理邏輯 |"空 Referer" 的定義是 Referer 標頭的值為空（""）或者請求中不包含 Referer 標頭。<br><br><br>* 如果 **應用場景** 是 **Referer 允許清單**，該設定是 **不允許空 Referer 存取 CDN 資源**。<br><br>* 如果 **應用場景** 是 **Referer 封鎖清單**，該設定是 **允許空 Referer 存取 CDN 資源**。 |


<span id="通用清單的設定"></span>
### 通用清單的設定


|**設定** |**說明** |
|---|---|
|應用場景 |表示一個通用清單。清單中的每個條目是一個字串。該清單既不是允許清單，也不是封鎖清單，主要用於判斷某個物件是否存在於該清單中。例如，在 [自訂攔截](https://docs.byteplus.com/en/docs/byteplus-cdn/custom-restrictions_cn) 中，您可以設定生效條件為請求 URL 中的查詢參數不在您設定的通用清單中。 |
|規則 |表示一個字串清單，最多包含 4,000 個字串，總長度不能超過 200,000 個字元。多個字串需要分行輸入，您也可以上傳一個包含這些字串的 .txt 檔案。清單中重複的字串會被刪除，不計入字串總數。<br><br>&nbsp;<br><br>在 CDN 在使用 **規則** 中的字串匹配物件時，匹配方法是精確匹配。 |
|忽略大小寫 |表示 **規則** 中的內容是否是大小寫敏感的。 |


<span id="關聯全域設定與策略"></span>
## 關聯全域設定與策略

在建立一個全域設定後，您需要將其與一個或者多個分發策略關聯，才能使該全域設定對這些分發策略所綁定的網域名稱生效。

<span id="操作步驟"></span>
### 操作步驟


1. 在左側導覽列，點擊 **分發策略**。

2. 在策略清單中，找到您需要修改的分發策略。該策略的狀態必須是 **草稿**。

3. 在 **操作** 欄，點擊 **編輯策略**。

4. 在 **分發策略詳情** 頁面，點擊 **策略設定** 標籤頁。

5. 在 **策略設定** 標籤頁的左邊欄，展開 **存取管理** \> **存取控制**。

6. 根據全域設定的類型，點擊相應的 CDN 功能，例如點擊 **IP 存取控制**。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">如果該 CDN 功能不存在，您可以點擊 <strong>新增</strong>，在彈出對話框中勾選相應的 CDN 功能，然後點擊 <strong>確定</strong>。   </div>
   

7. 在該 CDN 功能的下方，設定 **狀態** 為 **開啟**。

8. 設定 **設定方式** 為 **全域設定**。

9. 在 **設定名稱** 清單中，選擇您建立的全域設定。

10. 在頁面右下方，點擊 **儲存**。

11. 對於其他需要關聯的分發策略，重複以上步驟。


<span id="修改全域設定"></span>
## 修改全域設定

您可以修改一個全域設定。CDN 控制台提供了以下幾種修改方式：


* 全量替換：表示設定的條目會覆蓋已有的所有條目。

* 僅新增：表示設定的條目會被新增到已有的條目。

* 指定刪除：表示設定的條目會從已有條目中刪除。


修改後，對於該全域設定所關聯的策略，該全域設定會立即對這些策略所綁定的網域名稱生效。

<span id="操作步驟"></span>
### 操作步驟

在左側導覽列，點擊 **進階設定** \> **全域設定**。


1. 在 **全域設定** 頁面，找到需要修改的全域設定，點擊 **修改**。

2. 在 **設定詳情** 頁面，設定 **修改方式**。

3. 輸入相應的條目。


<span id="解除全域設定與網域名稱的關聯"></span>
## 解除全域設定與網域名稱的關聯

要解除一個全域設定與一個網域名稱的關聯，有以下兩種方法：


* 在該網域名稱所綁定的策略中，確保相應的 CDN 功能是被停用的。例如，要解除一個類型為 IP 封鎖清單的全域設定與一個網域名稱的關聯，您需要確保在與該網域名稱綁定的策略中，IP 存取控制這個功能是被停用的。

* 在該網域名稱所綁定的策略中，確保該 CDN 功能設定中的 **設定方式** 為 **策略設定**。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您無法修改一個已與網域名稱綁定的策略的設定。但是，您可以基於策略複製來實現以上這些方法。</div>


<span id="操作步驟"></span>
### 操作步驟

<span id="方法一：在分發策略中關閉相應的-cdn-功能"></span>
#### 方法一：在分發策略中關閉相應的 CDN 功能

如果您不再需要對該網域名稱啟用相應的 CDN 功能，可以使用此方法。

該方法的操作步驟如下：


1. 對於與該網域名稱綁定的分發策略，遵照 [複製策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-policy_zh-tw#%E8%A4%87%E8%A3%BD%E7%AD%96%E7%95%A5) 中的步驟建立一個分發策略。

2. 對於建立的分發策略，在策略清單的 **操作** 欄上，點擊 **編輯策略**。

3. 在 **分發策略詳情** 頁面，點擊 **策略設定** 標籤頁。

4. 在 **策略設定** 標籤頁的左邊欄，展開 **存取管理** \> **存取控制**。

5. 點擊相應的 CDN 功能，例如點擊 **IP 存取控制**。

6. 在該 CDN 功能的下方，設定 **狀態** 為關閉。

7. 在頁面右下方，點擊 **儲存**。

8. 對於建立的分發策略，在策略清單的 **操作** 欄上，點擊 **發佈**。

9. 將該網域名稱與建立的分發策略綁定。


<span id="方法二：設定「設定方式」為「策略設定」"></span>
#### 方法二：設定「設定方式」為「策略設定」

如果您的場景滿足以下所有條件，您可以使用該方式。


* 您的全域設定中條目不多。與該全域設定關聯的分發策略中，這些條目可以全部設定在相應的 CDN 功能中。例如，您的全域設定中僅包含 100 條 IP 條目。這 100 個條目可以全部設定在 IP 存取控制這個 CDN 功能中。

* 您不希望其他網域名稱使用該全域設定。


該方法的操作步驟如下：


1. 對於與該網域名稱綁定的分發策略，遵照 [複製策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-policy_zh-tw#%E8%A4%87%E8%A3%BD%E7%AD%96%E7%95%A5) 中的步驟建立一個分發策略。

2. 對於建立的分發策略，在策略清單的 **操作** 欄上，點擊 **編輯策略**。

3. 在 **分發策略詳情** 頁面，點擊 **策略設定** 標籤頁。

4. 在 **策略設定** 標籤頁的左邊欄，展開 **存取管理** \> **存取控制**。

5. 點擊相應的 CDN 功能，例如點擊 **IP 允許/封鎖清單**。

6. 在該 CDN 功能中，設定 **設定方式** 為 **策略設定**，然後在規則內容中設定與全域設定中相同的條目。

7. 設定該 CDN 功能的其餘設定。

8. 在頁面右下方，點擊 **儲存**。

9. 對於建立的分發策略，在策略清單的 **操作** 欄上，點擊 **發佈**。

10. 將該網域名稱與建立的分發策略綁定。


之後，如果您不再需要該全域設定，可以將其刪除。

<span id="匯出全域設定的內容"></span>
## 匯出全域設定的內容

對於一個全域設定，您可以匯出其包含的條目以及其關聯的網域名稱清單。


* 匯出的檔案格式是 .txt。

* 匯出的包含條目的檔案使用的命名格式是：`CDN_<catalog-name>_Rule_<export-time>`

* 匯出的包含關聯網域名稱的檔案使用的命名格式是：`CDN_<catalog-name>_Domain_<export-time>`


檔案名中的時間格式是：`YYYYMMDDHHMMSS`。檔案名示例：`CDN_test_Rule_20230518114139`。

<span id="操作步驟"></span>
### 操作步驟


1. 在 **全域設定** 頁面，找到需要匯出設定內容的全域設定，點擊 **修改**。

2. 在 **設定詳情** 頁面的 **規則清單** 上方，點擊 **匯出** 按鈕匯出規則中包含的條目。

3. 在 **關聯網域名稱** 的上方，點擊 **匯出** 按鈕匯出關聯的網域名稱清單。
