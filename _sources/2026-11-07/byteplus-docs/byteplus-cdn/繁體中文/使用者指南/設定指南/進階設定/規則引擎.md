## 功能簡介

CDN 的規則引擎提供了自訂請求處理的能力。您可以透過設定一系列匹配條件和執行動作，來控制 CDN 節點對使用者請求的回應方式。例如，您可以實現自訂快取策略、URL 重寫、存取控制、以及請求標頭和回應標頭的操作。本文將詳細介紹規則引擎的核心概念、處理流程、設定優先順序以及具體設定項，並透過範例協助您快速上手。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">要使用規則引擎，請先 <a href="https://console.byteplus.com/workorder/create">提交工單</a>。</div>


* <div data-tips="true" data-tips-type="tip">並非所有 CDN 特性都支援在規則引擎中設定。例如，「回源參數設定」和「Multi\-range」等特性只能在分發策略中設定。有關規則引擎支援的 CDN 特性，請參閱 <a href="https://docs.byteplus.com/en/docs/18/41200#%E5%8B%95%E4%BD%9C%E5%88%97%E8%A1%A8">動作列表</a>。</div>

## 核心概念

規則引擎包含以下核心概念：


* **規則引擎策略**：在規則引擎中，規則在規則引擎策略中定義。每條策略包含一條規則。您最多可以建立 201 條策略。透過關聯策略與網域名稱，策略中的規則應用到網域名稱。一條策略可以關聯多個網域名稱，每個網域名稱只能關聯 1 條規則引擎策略。

* **規則**：規則是規則引擎設定的基本單位，用於定義 CDN 如何處理特定類型的請求。每條規則都包含一個 `IF...ELSE...` 結構的條件運算式。

* **子規則**：子規則巢狀在父規則的 `IF` 或 `ELSE` 分支下，用於實現更精細的邏輯控制。當請求滿足父規則的條件時，CDN 會在執行父規則中定義的動作後繼續處理父規則下的子規則。每條規則的 `IF` 和 `ELSE` 分支下總共可包含最多 10 條子規則。子規則不能再巢狀。

* **條件運算式**：條件運算式是規則的核心，用於定義匹配使用者請求的邏輯以及 CDN 需要執行的動作。條件運算式由 `IF` 和 `ELSE` 兩部分組成。如果請求滿足 `IF` 中定義的條件，則 CDN 執行 `IF` 下的動作；否則，執行 `ELSE` 下的動作。

* **匹配條件**：匹配條件用於定義 `IF` 陳述式的匹配邏輯。您可以建立一個或多個匹配條件，並定義匹配條件之間的邏輯關係。邏輯關係有 **全部滿足** 和 **滿足任意**。匹配條件有以下類型：

   * **單一條件**：由條件類型、運算子和匹配值組成。

   * **條件群組**：包含多個單一條件及單一條件之間的邏輯關係。

* **動作**：動作表示 CDN 在請求滿足匹配條件後執行的具體操作，例如重新導向 URL 或修改 HTTP 回應標頭。

## 處理流程

<span id="795773d9"></span>
### 規則執行邏輯

規則的執行邏輯如下：


* **規則下無子規則**：遵循 `IF...ELSE...` 邏輯。

* **規則下有子規則**：

   * 如果請求滿足外層 `IF` 條件，CDN 會先執行外層 `IF` 下的動作，然後按順序處理外層 `IF` 下的所有子規則。

   * 如果請求不滿足外層 `IF` 條件，CDN 會先執行外層 `ELSE` 下的動作，然後按順序處理外層 `ELSE` 下的所有子規則。


單一子規則的執行邏輯如下：


* 遵循 `IF...ELSE...` 邏輯。如果請求滿足 `IF` 條件，則 CDN 執行 `IF` 下的動作；否則，執行 `ELSE` 下的動作。

## 設定優先順序

<span id="0095bbf3"></span>
### 相同動作的優先順序

當多個子規則中設定了相同的動作時，後執行動作中的設定生效。

**範例**：

假設您有如下規則設定。當 CDN 收到對 `/docs/3.php` 的請求，且源站回應包含 `param_a`、`param_b` 和 `param_c` 三個回應標頭時，最終用戶端收到的回應將不包含 `param_a` 和 `param_b`，但會包含 `param_c`，且 `param_c` 的值被設定為 `value_2`。

### 快取索引鍵說明

在 CDN 中，您可以透過以下兩種方式設定快取索引鍵：


* **常規方式**：在網域名稱設定頁面，您可以建立快取索引鍵規則，指定快取索引鍵包含的查詢參數。更多資訊，參見 [快取索引鍵](https://docs.byteplus.com/en/docs/byteplus-cdn/cache-key_zh-tw)。

* **規則引擎**：您也可以在規則引擎中設定快取索引鍵。規則引擎提供了更豐富的設定項。除了查詢參數，您還可以：

   * 設定快取索引鍵中包含的請求標頭。

   * 設定快取索引鍵中包含的 Cookie。

   * 改寫快取索引鍵中的檔案路徑。

   * 指定快取索引鍵中的檔案路徑是否區分大小寫。

#### 快取索引鍵中的路徑改寫範例

### 變數說明

在以下兩個動作的設定中，您可以使用變數來獲取特定物件的值。


* 用戶端請求標頭設定

* HTTP 回應標頭設定


要在參數值中使用這些變數，使用的格式是 `${*變數*}`。例如，您設定某個 HTTP 回應標頭的值為 `my ${request_uri} is ${host}`.

CDN 提供的變數列表如下。


|變數名稱 |說明 |範例 |
|---|---|---|
|request_uri |表示用戶端請求 URL 中的路徑和查詢字串（query string）。 |`/dir/shoppinglist.php?color=red&n=10` |
|raw_uri |表示用戶端請求 URL 中的路徑。 |`/dir/volcano.php` |
|host |表示用戶端請求中 host 標頭的值。需要留意的是，CDN 在處理請求時可能會修改 `host` 標頭的值。因此，建議您使用 `http_host` 變數，而不是 `host` 變數。 |`www.example.com:8080` |
|http_host |表示用戶端請求中 host 標頭的值。該標頭值不會被 CDN 修改。 |`www.example.com:8080` |
|args |表示用戶端請求 URL 中的查詢字串。 |`color=red&n=10` |
|query_string |與 `args` 參數的含義相同。 |`color=red&n=10` |
|scheme |表示用戶端使用的協定。 |`https` |
|remote_addr |表示發起本次請求的用戶端的 IP 位址。 |`203.0.113.4` |
|msec |表示 CDN 設定回應標頭的時間，格式是 Unix 時間戳，精確到毫秒。該時間戳接近首包的回應時間。 |`1704444754.917` |
|http_%s |表示一個特定標頭的值，`%s` 是標頭名稱。例如 `http_hello` 表示 `hello` 標頭的值。 |`http_hello` |
|arg_%s |表示一個特定查詢參數的值，`%s` 是查詢參數名稱。例如 `arg_size` 表示查詢參數 `size` 的值。 |`arg_size` |

## 應用場景

<span id="a68b619a"></span>
### 允許或拒絕特定用戶端請求

根據用戶端請求的特徵（如請求標頭、用戶端 IP、請求 URL、用戶端所在地區等），制定黑白名單策略，並指定 CDN 的回應狀態碼。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_d97d016afe34d23e2a7f0bdc3b145731.png) </span>

<span id="79a44e77"></span>
### 設定快取策略

根據用戶端請求的特徵（如請求標頭、請求 URL、用戶端所在地區等）設定不同的快取時間。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_34351e2ed4e8be5b486cdf34c3958138.png) </span>

您還可以實現特定的快取需求，例如讓 CDN 對 `OPTIONS` 請求直接回應 200 狀態碼。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6be31319516068a196c94a5766e0e849.png) </span>

<span id="d7a0156f"></span>
### 對特定用戶端請求限速

根據用戶端請求的特徵（如請求 URL 中的參數、用戶端所在地區等）對請求進行限速。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4a983ea6f8cc56364ab1895876fed452.png) </span>

<span id="86f126e1"></span>
### 對跨域請求設定校驗策略

您可以實現複雜的跨域資源共享（CORS）策略。例如，除了標準的 HTTP/HTTPS 請求外，您還可以還允許來自微信小程式的跨域請求，並根據請求中的 `Origin` 標頭動態設定 `Access-Control-Allow-Origin` 回應標頭。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_f759c4f1f06b2a59901e0fc11d9ec282.png) </span>

<span id="6ce14797"></span>
### 修改 Content\-Disposition 回應標頭

透過修改 `Content-Disposition` 回應標頭，您可以自訂瀏覽器下載檔案時顯示的檔案名稱，這有助於防止檔案在下載過程中被劫持。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在本範例中，檔案的真實名稱保存在查詢參數 <code>filename</code> 中。您也可以使用其他物件（如 cookie 和請求標頭）來保存檔案的真實名稱，並相應地調整規則設定。</div>
