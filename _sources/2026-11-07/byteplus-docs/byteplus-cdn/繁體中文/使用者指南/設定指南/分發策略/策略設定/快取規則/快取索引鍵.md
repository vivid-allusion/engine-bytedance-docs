本文件介紹如何在 BytePlus CDN 中透過建立快取索引鍵規則來配置快取索引鍵。

<span id="快取索引鍵"></span>
## 快取索引鍵

快取索引鍵（Cache Key）是快取中每個檔案的唯一識別碼。通常情況下，快取索引鍵包含使用者請求 URL 中的主機名稱（hostname）、路徑和查詢參數。您可以設定快取索引鍵中包含的查詢參數。

當收到使用者請求時，CDN 會為所請求的檔案產生一個快取索引鍵，然後嘗試將該快取索引鍵與每個快取檔案的快取索引鍵進行比對。快取索引鍵的比對需要完整匹配請求 URL 中的主機名稱、路徑和查詢參數。查詢參數的比對包括參數出現的順序。如果 CDN 找到相符的項目，則表示該請求命中了快取。請注意，快取索引鍵的比對過程區分大小寫。

<span id="快取索引鍵配置"></span>
## 快取索引鍵配置

CDN 提供了快取索引鍵配置的功能。您可以在控制台中建立快取索引鍵規則。該功能的目的是指示 CDN 在對請求的檔案生成快取索引鍵時，快取索引鍵中包含哪些請求 URL 中的查詢參數。由於生成的快取索引鍵會被 CDN 用來匹配快取的檔案，因此快取索引鍵規則會直接影響快取命中率。

在本文最後，我們提供了一個 [配置示例](https://docs.byteplus.com/en/docs/18/36290#%E9%85%8D%E7%BD%AE%E7%A4%BA%E4%BE%8B) 幫助您更好理解快取索引鍵設置對於快取命中的影響。

<span id="使用場景"></span>
## 使用場景

如果您站點上檔案 URL 中的查詢參數並不是用來區分檔案的，您可以透過建立快取索引鍵規則來指定 CDN 在生成的快取索引鍵中需要丟棄的查詢參數，以提高快取命中率，減少回源請求。例如，URL 中包含了 `auth` 參數。其目的是用來驗證使用者的身份，不是用來區分檔案。在這個情況下，該參數就無需包含在生成的快取索引鍵中。

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **快取索引鍵** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **快取索引鍵** 下方，點擊 **添加規則**。

   您最多可以添加 50 條規則。

3. 參照以下 [配置說明](https://docs.byteplus.com/en/docs/18/36290#%E9%85%8D%E7%BD%AE%E8%AA%AA%E6%98%8E)。

4. 配置完成後，點擊 **保存**。


<span id="關於預設快取索引鍵規則"></span>
### 關於預設快取索引鍵規則

在您添加網域名稱時，CDN 會預設為您添加一條快取索引鍵規則。該規則對所有檔案的請求生效。您可以修改該規則的配置，但是無法刪除該規則。在您添加其他快取索引鍵規則時，這條規則的優先級始終是最低的，其確保了任何請求都可以匹配到一條規則。

<span id="配置說明"></span>
### 配置說明


|**配置** |**說明** |
|---|---|
|優先級 |表示規則的優先級。數字 1 的規則優先級最高。在收到請求時，CDN 按規則的優先級，從高到低嘗試將請求與規則匹配。如果請求匹配了某一條規則，CDN 就停止匹配其餘規則。您可以透過拖拽調整規則的優先級。需要留意的是，您無法調整那條預設規則的優先級。 |
|規則類型 |表示規則的匹配條件。該配置有以下選項：<br><br><br>* **檔案副檔名**：表示規則用於匹配指定副檔名的檔案的請求。<br><br>* **URL 匹配**：表示規則用於匹配指定目錄下檔案的請求。<br><br>* **URL 全路徑**：表示規則用於匹配指定檔案路徑的請求。 |
|規則 |表示規則的內容，長度不能超過 1,024 個字元，不能包含以下字元：<br><br><br>* 雙斜線（//）、空格、美元符號（$）、問號（?）。<br><br><br>同時，<br><br><br>* 如果規則類型是 **檔案副檔名**，規則內容必須是一個或者多個以分號（;）分隔的檔案副檔名。檔案副檔名無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果規則類型是 **目錄**，規則內容必須是一個或者多個以分號（;）分隔的目錄路徑。目錄路徑必須以斜線（/）開頭和結尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果規則類型是 **檔案全路徑**，規則內容必須是一個或者多個以分號（;）分隔的檔案路徑。檔案路徑必須以斜線（/）開頭，可以包含星號（\*）用來表示一個或者多個字元。例如：`/chs/foods/local*sets;/us/birds/chickadee`。 |
|目標參數 |指定 CDN 在生成的快取索引鍵中包含哪些請求 URL 中的查詢參數。該配置有以下選項：<br><br><br>* **保留全部參數**：包含請求 URL 中全部的查詢參數。<br><br>* **刪除全部參數**：不包含任何的查詢參數。<br><br>* **刪除指定參數**：包含除了指定參數以外全部的查詢參數。<br><br>* **保留指定參數**：包含指定的查詢參數。 |
|指定部分參數 |指定需要保留或者丟棄的查詢參數。多個查詢參數用英文分號（;）分隔。例如 `version;size`。<br><br><br>* 如果 **目標參數** 是 **保留全部參數** 或者 **刪除全部參數**，該配置的值必須是 `*`。`*` 表示全部查詢參數。<br><br>* 如果 **目標參數** 是 **刪除指定參數** 或者 **保留指定參數**，您可以指定一個或者多個查詢參數，但是您不能指定 `*`。同時，您指定的查詢參數不能包含雙斜線（//）、百分號（%）、空格。<br><br><br>該配置的預設值是 `*`。 |
|忽略大小寫 |表示 **指定部分參數** 是否區分大小寫。該參數僅當 **目標參數** 是 **刪除指定參數** 或者 **保留指定參數** 時有效。<br><br>&nbsp;<br><br>例子：您指定保留的參數是 `size`，**忽略大小寫** 為 **開啟**。然後，CDN 收到了一個 URL 包含 `SIZE` 參數的請求。在這個情況下，CDN 會在生成的快取索引鍵中保留 `SIZE` 參數。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">當 CDN 嘗試將請求匹配快取檔案時，匹配始終是大小寫敏感的。</div><br> |

## 更多資訊

<span id="配置示例"></span>
### **配置示例**


* 您站點根目錄下的檔案 URL 中包含 `version`，`token` 這兩個參數。

* 這兩個參數中，只有 `version` 是用來區分檔案的。例如 `/image.png?version=1` 與 `/image.png?version=2` 是兩個不同的檔案。但是 `/image.png?version=1&token=abc` 與 `/iamge.png?version=1&token=xyz` 指向相同的檔案。

* CDN 先後收到兩個該檔案的請求。請求的 URL 分別是 `/image.png?version=1&token=12345` 和 `/image.png?version=1&token=abcde`。


<span id="未創建快取索引鍵規則的結果"></span>
#### 未創建快取索引鍵規則的結果

在收到第一個請求時，CDN 快取該檔案。該檔案在快取中的快取索引鍵是 `/image.png?version=1&token=12345`。在收到第二個請求時，CDN 會使用 `/image.png?version=1&token=abcde` 去匹配快取中的檔案。由於沒有命中快取，CDN 會向来源伺服器請求該檔案。
