本文件介紹 BytePlus CDN 中的 "頁面最佳化" 功能。

<span id="功能介紹"></span>
## 功能介紹

HTML 檔案以及內嵌的 JavaScript 和 CSS 程式碼中可能會存在註解和重複的空白字元。開啟 "頁面最佳化" 後，CDN 在返回 HTML 檔案前會刪除這些空白字元，從而縮小檔案的體積、提高檔案分發效率。

該功能只對符合以下所有條件的使用者請求生效：


* 回應中的 `Content-Type` 標頭值為 `text/html`。

* 回應包含 `Content-Length` 標頭。

* 回應的狀態碼為 200。

* 使用者請求不是 Range 請求。

* "智慧壓縮" 未啟用。


<span id="操作步驟"></span>
## 操作步驟


1. 打開 **頁面最佳化** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **頁面最佳化** 下方，設定 **狀態** 為 **開啟**。

3. 配置完成後，點擊 **儲存**。
