本文件介紹了 BytePlus CDN 提供的「離線快取」功能。

如果您的來源伺服器發生故障或輪詢請求遇到未知錯誤，CDN 將無法從您的來源伺服器取得檔案。在這種情況下，無論快取檔案是否過期，如果您希望 CDN 繼續使用快取檔案回應使用者請求，您可以啟用「離線快取」功能。

啟用離線快取後，如果滿足 **觸發條件** 的設定，並且 CDN 已快取了請求的檔案，則 CDN 會將快取檔案傳送給使用者。

<span id="操作步驟"></span>
## 操作步驟


1. 開啟 \***離線快取** 設定頁面。操作步驟請參閱 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 將 **狀態** 設定為「啟用」。

3. 請參閱以下設定說明。

4. 設定完成後，按一下 **儲存**。

<span id="設定說明"></span>
## 設定說明


|**設定** |**說明** |
|---|---|
|觸發條件 |表示觸發 CDN 一律使用快取檔案回應使用者請求的條件。您可以勾選以下一個或多個條件： |
| | |
| |\- 輪詢請求異常：表示 CDN 未取得來源伺服器的回應。 |
| | |
| |\- 來源伺服器異常狀態碼：表示來源伺服器的回應狀態碼為 5xx。如果您勾選了此條件，您需要在異常狀態碼中指定具體的 5xx 狀態碼。 |
|異常狀態碼 |表示具體的 5xx 回應狀態碼，範圍為 500\-599。多個狀態碼之間請使用分號 (;) 分隔。例如 `505;504`。您也可以輸入 `5xx`，表示任何以數字 5 開頭的狀態碼。 |
| |當您在 **觸發條件** 下勾選 **來源伺re器異常狀態碼** 時，才會出現此設定。 |

<span id="離線快取與狀態碼快取"></span>
## 離線快取與狀態碼快取

如果您在「離線快取」和 [狀態碼快取](https://docs.byteplus.com/en/docs/byteplus-cdn/negative-cache_zh-tw) 中同時設定了某個 5xx 狀態碼，當來源伺服器回應中包含該 5xx 狀態碼時：


* 如果 CDN 已快取該 5xx 狀態碼，則「狀態碼快取」生效。

* 如果 CDN 未快取該 5xx 狀態碼，則 CDN 會快取該狀態碼並將該狀態碼傳送給使用者。
