本文件介紹 BytePlus CDN 提供的遠端驗證功能。

<span id="遠端驗證概述"></span>
## 遠端驗證概述

如果您的網站有專屬的驗證伺服器對使用者請求進行驗證，您可以在 CDN 中配置遠端驗證。

遠端驗證的流程如下：


1. 使用者向您的網站發送請求。請求中包含一個驗證參數。

2. 在收到使用者請求後，CDN 將使用者請求轉發到驗證伺服器。

3. 驗證伺服器對使用者請求進行驗證，並將驗證結果返回給 CDN。

4. CDN 根據驗證結果，將使用者請求的內容發送給使用者或者拒絕使用者請求。


<span id="遠端驗證與-url-驗證的區別"></span>
## 遠端驗證與 URL 驗證的區別

URL 驗證：驗證是由 CDN 執行的。

遠端驗證：驗證是由驗證伺服器執行的。CDN 將請求轉發到驗證伺服器獲取驗證結果。

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **遠端驗證** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **遠端驗證** 下方，設置 **狀態** 為 **開啟**。

3. 配置以下標籤頁上的設置。

   * [驗證規則](https://docs.byteplus.com/en/docs/18/36280#%E9%A9%97%E8%AD%89%E8%A6%8F%E5%89%87)

   * [驗證請求地址](https://docs.byteplus.com/en/docs/18/36280#%E9%A9%97%E8%AD%89%E8%AB%8B%E6%B1%82%E5%9C%B0%E5%9D%80)

   * [驗證請求參數](https://docs.byteplus.com/en/docs/18/36280#%E9%A9%97%E8%AD%89%E8%AB%8B%E6%B1%82%E5%8F%83%E6%95%B8)

   * [驗證請求標頭](https://docs.byteplus.com/en/docs/18/36280#%E9%A9%97%E8%AD%89%E8%AB%8B%E6%B1%82%E6%A8%99%E9%A0%AD)

   * [驗證結果](https://docs.byteplus.com/en/docs/18/36280#%E9%A9%97%E8%AD%89%E7%B5%90%E6%9E%9C)

4. 配置完成後，點擊 **儲存**。


<span id="驗證規則"></span>
### 驗證規則

在該標籤頁上，您可以新增一個或者多個規則。您最多可以新增 50 個規則。當 CDN 收到一個使用者請求時，會根據規則的出現順序依次將規則與請求相匹配。如果一個規則匹配了請求，該請求就會進入遠端驗證的流程。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如果您需要對所有請求進行驗證，可以新增一條規則並指定以下配置：</div>



* <div data-tips="true" data-tips-type="tip">設置 <strong>規則類型</strong> 是 <strong>目錄匹配</strong>。</div>


* <div data-tips="true" data-tips-type="tip">設置 <strong>規則</strong> 是 <strong>/</strong>。</div>



<span id="配置說明"></span>
#### 配置說明


|**配置** |**說明** |
|---|---|
|規則類型 |表示規則的匹配條件。CDN 將匹配的請求發送到驗證伺服器進行認證。該配置有以下選項：<br><br><br>* **檔案副檔名**：表示規則用於匹配指定副檔名的檔案的請求。<br><br>* **檔案目錄**：表示規則用於匹配指定目錄下檔案的請求。<br><br>* **URL 全路徑**：表示規則用於匹配指定檔案的請求。 |
|是否匹配 |表示規則匹配的方式。該配置有以下選項：<br><br><br>* **匹配**：表示匹配規則的請求需要被驗證。<br><br>* **不匹配**：表示不匹配規則的請求需要被驗證。<br><br><br>需要留意的是，如果您新增了多條規則，這些規則需要設置為相同的匹配方式。 |
|規則 |表示規則的內容，長度不能超過 1,024 個字元，不能包含以下字元：<br><br><br>* 連續斜線（//）、空格、美元符號（$）、問號（?）、Delete（ASCII code 127）。<br><br><br>同時，<br><br><br>* 如果規則類型是 **檔案副檔名**，規則內容必須是一個或者多個以分號（;）分隔的檔案副檔名。檔案副檔名無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果規則類型是 **檔案目錄**，規則內容必須是一個或者多個以分號（;）分隔的目錄路徑。目錄路徑必須以斜線（/）開頭和結尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果規則類型是 **URL 全路徑**，規則內容必須是一個或者多個以分號（;）分隔的檔案路徑。檔案路徑必須以斜線（/）開頭，可以包含星號（\*）用來表示一個或者多個字元。例如：`/chs/foods/local*sets;/us/birds/chickadee`。 |

<span id="配置說明"></span>
#### 配置說明


|**配置** |**說明** |**示例** |
|---|---|---|
|遠端驗證地址（主） |表示主驗證伺服器的 URL，長度不能超過 100 個字元。主伺服器 URL 必須採用以下格式之一：<br><br><br>* <scheme\>://<domain\><br><br>* <scheme\>://<ip\><br><br><br><scheme\> 的值是 `http` 或者 `https`。<domain\> 的值不能是 `localhost`。<ip\> 的值不能是 `127.0.0.1`。 |`https://example.com` |
|遠端驗證地址（備） |表示備用驗證伺服器的 URL，長度不能超過 100 個字元，要求與主伺服器 URL 相同。<br><br>&nbsp;<br><br>**主備切換邏輯**<br><br>對於單個請求，如果驗證異常發生，CDN **不會**將請求發送給備用驗證伺服器，而是根據 **驗證結果** 標籤頁的配置處理使用者請求。關於驗證異常的定義，參見文件最後 **異常執行策略** 配置的說明。<br><br>&nbsp;<br><br>如果在當前分鐘內**連續** 25 次發生驗證異常，則主伺服器的當前 IP 地址將被添加到黑名單。接下來，對於新收到的請求：<br><br><br>* 如果主伺服器的網域名稱解析到多個 IP 地址，CDN 會將該請求發送到另一個 IP 地址。同樣，如果在當前分鐘內連續 25 次發生驗證異常，則該 IP 地址將被添加到黑名單。<br><br>* 如果所有 IP 地址都在黑名單中，CDN 會將該請求發送到備用驗證伺服器。<br><br><br>在下一分鐘開始時，黑名單將被清空。對於新收到的請求，CDN 會將請求發送到主驗證伺服器。 | |
|驗證請求路徑 |表示驗證路徑。驗證伺服器的地址和該路徑組成了驗證 URL。CDN 把使用者請求轉發到該驗證 URL。該配置有以下選項：<br><br><br>* **跟隨請求**：表示驗證路徑與使用者請求 URL 中的路徑相同。<br><br>* **指定路徑**：表示一個指定的路徑。您需要在 **請求路徑** 中指定該路徑。 | |
|驗證路徑 |如果 **請求路徑** 是 **指定具體請求路徑**，該配置才會出現。在該配置中，您指定一個驗證路徑。驗證路徑必須以斜線（/）開頭，長度不能超過 100 個字元。驗證路徑可以包含除了以下字元的可列印 ASCII 字元：<br><br><br>* 連續的斜線（//）、百分號（%）、美元符號（$）、空格、問號（?）、Delete（ASCII code 127）。 |`/sign` |
|請求方法 |表示 CDN 轉發的請求所使用的請求方法。該配置有以下選項：<br><br><br>* **跟隨請求**：表示驗證請求使用的方法與使用者請求相同。<br><br>* **GET**：表示驗證請求使用 GET 方法。<br><br>* **POST**：表示驗證請求使用 POST方法。<br><br>* **HEAD**：表示驗證請求使用 HEAD 方法。 | |

<span id="驗證結果"></span>
### 驗證結果

在該標籤頁上，您指定 CDN 是如何處理驗證伺服器返回的驗證結果的。

在截圖所展示的配置中，快取金鑰中指定的欄位是 `URI` 和 `client_ip`。該配置表示 CDN 基於使用者請求的以下屬性對驗證結果進行快取：


* 請求來自的 IP 位址

* 請求的 URL


這樣，之後對於來自相同 IP 位址的請求，如果請求 URL 是相同的，CDN 會使用快取的驗證結果。

<span id="配置說明"></span>
#### 配置說明


|**配置** |**說明** |
|---|---|
|驗證成功回應碼 |表示從驗證伺服器返回的狀態碼中，哪些被認為是驗證成功。預設值是 200。<br><br>&nbsp;<br><br>您可以輸入範圍在 200\-299 中的一個或者多個狀態碼。多個狀態碼使用分號（;）分隔。您也可以輸入 2xx 表示 200\-299 範圍中的任意一個狀態碼。 |
|認證失敗回應碼 |表示從驗證伺服器返回的狀態碼中，哪些被認為是驗證失敗。預設值是 401。<br><br>&nbsp;<br><br>您可以輸入範圍在 400\-499 中的一個或者多個狀態碼。多個狀態碼使用分號（;）分隔。您也可以輸入 4xx 表示 400\-499 範圍中的任意一個狀態碼。 |
|其他狀態碼的操作 |該配置表示在滿足以下所有條件時，CDN 對使用者請求的處理方式。<br><br><br>* 驗證伺服器返回的狀態碼不是您指定的表示驗證成功的狀態碼。<br><br>* 驗證伺服器返回的狀態碼不是您指定的表示驗證失敗的狀態碼。<br><br><br>該配置有以下選項：<br><br><br>* **預設放行**：表示 CDN 認為驗證成功，並將請求的檔案返回給使用者。<br><br>* **預設攔截**：表示 CDN 認為驗證失敗，拒絕該使用者請求。 |
|快取驗證回應 |表示 CDN 是否快取驗證結果。驗證結果也就是驗證伺服器返回的驗證狀態碼。預設是 **不快取**。<br><br>&nbsp;<br><br>在開啟該配置後，對於收到的使用者請求，CDN 會檢測該請求的驗證狀態碼是否已被快取。如果驗證狀態碼已被快取，CDN 則使用該驗證狀態碼來確定是否將請求的檔案發送給使用者。<br><br>&nbsp;<br><br>該配置可以提升驗證效率。 |
|快取過期時間 |表示驗證狀態碼的快取時間，單位是秒。該配置僅在 **快取驗證回應** 為 **快取** 的情況下才出現。您可以輸入範圍在 1\-86400 之間的一個值。86,400 秒表示 24 小時。 |
|快取索引鍵 |表示快取的驗證狀態碼中所包含的欄位。每個快取的驗證狀態碼都有一個唯一的快取索引鍵。該配置僅在 **快取驗證回應** 為 **快取** 的情況下才出現。<br><br>&nbsp;<br><br>當收到一個請求時，CDN 嘗試將請求與快取中每個驗證狀態碼的快取索引鍵相匹配。如果找到了匹配，CDN 就使用該快取的驗證狀態碼。<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning"><strong>快取索引鍵</strong> 中必須包含 <code>URI</code> 這個欄位。</div><br><br><br>**例子**<br><br>您在快取該配置中指定的欄位是 `URI` 和 `client_ip`。該配置表示 CDN 基於使用者請求中的以下對象對驗證結果進行快取：<br><br><br>* 請求來自的 IP 位址<br><br>* 請求的 URL<br><br><br>這樣，之後對於來自相同 IP 位址的請求，如果請求 URL 是相同的，CDN 會使用快取的驗證結果。 |
|驗證失敗的 CDN 回應碼 |表示驗證失敗時，CDN 回應使用者請求的狀態碼。預設的狀態碼是 403。<br><br>&nbsp;<br><br>您可以輸入範圍在 400\-499 中的任意一個狀態碼。 |
|驗證請求逾時 |表示驗證請求的逾時時間，單位是毫秒，預設值是 200。您可以輸入的逾時時間的範圍是 200\-3600。 |
|異常執行策略 |該配置表示驗證異常發生時，CDN 處理驗證的方式。<br><br>該配置有以下選項：<br><br><br>* **預設放行**：表示 CDN 認為使用者請求驗證成功，並將請求的檔案返回給使用者。<br><br>* **預設攔截**：表示 CDN 認為使用者請求驗證失敗，拒絕該使用者請求。<br><br><br>驗證異常包括，但不限於，以下情況：<br><br><br>* 驗證請求逾時。<br><br>* 驗證伺服器拒絕了驗證請求。<br><br>* CDN 無法與驗證伺服器建立連接。 |
