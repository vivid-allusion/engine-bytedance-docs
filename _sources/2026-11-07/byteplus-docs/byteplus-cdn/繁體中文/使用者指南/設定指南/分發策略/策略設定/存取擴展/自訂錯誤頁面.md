本文件介紹 BytePlus CDN 提供的「自訂錯誤頁面」功能。

對於表示錯誤的 CDN 狀態碼，也就是範圍在 400\-599 的狀態碼，您可以指示 CDN 返回一個使用者友善頁面，而不是狀態碼的標準頁面。該使用者友善頁面上可以包含該狀態碼以及故障排除資訊，以改善使用者體驗。CDN 透過對請求回應 3xx 狀態碼，使使用者請求重新導向到使用者友善頁面。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在特定情況下，該設定不會生效。參見 <a href="https://docs.byteplus.com/en/docs/18/36306#%E4%BE%8B%E5%A4%96">例外</a>。</div>

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **自訂錯誤頁面** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **自訂錯誤頁面** 下方，設置 **狀態** 為啟用。

3. 點擊 **新增規則**。

   您最多可以新增 50 條規則。

4. 參照以下設定說明。

5. 設定完成後，點擊 **儲存**。



|**設定** |**說明** |
|---|---|
|優先順序 |表示規則的優先順序。數字 1 的規則優先順序最高。優先順序最高的規則優先生效。對於一個使用者請求，如果某條規則與該請求匹配，只有該規則生效，其餘規則不生效。您可以拖動規則來調整規則的優先順序。 |
|回應狀態碼 |輸入一個範圍在 400\-599 的狀態碼。您也可以輸入 4xx，表示 400\-499 之間的所有狀態碼。 |
|重新導向方式 |選擇重新導向的回應狀態碼。該設定的可選項有 **301**、**302**、**303**、**307**、**308**。<br><br>&nbsp;<br><br>需要留意的是：<br><br><br>* 對於 301 和 302，如果原請求所使用的方法不是 GET，那麼用戶端向新的 URL 發送請求時，新請求所使用的方法可能會改為 GET。<br><br>* 對於 303，新請求使用的方法始終是 GET。<br><br>* 對於 307 和 308，新請求所使用的方法與原請求相同，不會發生改變。 |
|目標地址 |輸入跳轉的目標 URL，長度不能超過 1,024 個字元。目標 URL 必須符合 URL 規範，包含協定，網域名稱以及路徑。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">目標 URL 的網域名稱不能與該策略要綁定的網域名稱相同，否則設定不會生效。</div><br> |


<span id="例外"></span>
## 例外

對於您設定的狀態碼，如果該狀態碼是由以下任意原因造成，則 CDN 不會將使用者請求重新導向到您設定的目標 URL，而是返回該狀態碼的標準頁面。


* 使用者請求匹配您設置的存取控制規則而被 CDN 拒絕。

* 請求 URL 已被 CDN 封鎖。


另外，如果 CDN 在向來源伺服器請求檔案時沒有收到來源伺服器的回應，CDN 也不會將使用者請求重新導向到您設定的目標 URL。
