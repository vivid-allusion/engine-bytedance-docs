本文件介紹如何在 BytePlus CDN 中設定用戶瀏覽器對於請求檔案的快取行為。

<span id="瀏覽器快取概述"></span>
## 瀏覽器快取概述

當 CDN 回應一個用戶請求時，除了將請求的檔案發送給用戶之外，還可以指示用戶瀏覽器如何對該檔案進行快取。透過在 CDN 中指定瀏覽器快取策略，您對特定檔案在用戶瀏覽器中的快取行為進行設定。

瀏覽器快取策略與來源伺服器回應中所指示的快取行為有關。在 CDN 向來源伺服器請求一個檔案時，來源伺服器的回應標頭中會指示該檔案的快取行為。CDN 在快取該檔案時會記錄該回應標頭。

<span id="瀏覽器快取策略"></span>
## 瀏覽器快取策略

瀏覽器快取策略指定了 CDN 如何設定瀏覽器的快取行為。CDN 提供了以下瀏覽器快取策略：


* 快取。該策略的邏輯如下：

   * 如果請求檔案的來源伺服器回應中 `Cache-Control` 回應標頭不包含 `no-cache`、`no-store` 或者 `private` 指令，CDN 在回應用戶請求時會包含 `Cache-Control: max-age=N` 回應標頭。該回應標頭告知瀏覽器需要快取該檔案，其快取時間 `N` 就是您在策略中指定的快取過期時間。

* 遵循來源伺服器的快取策略。該策略的邏輯如下：

   * 在回應用戶請求時，CDN 會包含請求檔案的與快取相關的來源伺服器回應標頭。

* 不快取。該策略的邏輯如下：

   * CDN 指示瀏覽器不要對請求的檔案進行快取。在回應用戶請求時，CDN 會包含 `Cache-Control: no-store` 回應標頭。


<span id="操作步驟"></span>
## 操作步驟


1. 打開 **瀏覽器快取** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **瀏覽器快取** 下方，點擊 **添加規則**。

   您最多可以添加 50 條規則。

3. 參照以下配置說明。

4. 配置完成後，點擊 **儲存**。

<span id="配置說明"></span>
### 配置說明


|**配置** |**說明** |
|---|---|
|優先級 |表示規則的優先級。如果有多條規則，則按優先級來執行規則。如果有一條規則匹配了使用者請求，剩餘規則停止匹配。您可以通過拖曳調整規則的優先級。 |
|規則類型 |表示規則的匹配條件。該配置有以下選項：<br><br><br>* **檔案副檔名**：表示規則用於匹配指定副檔名的檔案的請求。<br><br>* **URL 目錄**：表示規則用於匹配指定目錄下檔案的請求。<br><br>* **URL 全路徑**：表示規則用於匹配指定檔案路徑的請求。 |
|規則 |表示規則的內容，長度不能超過 1,024 個字元，不能包含以下字元：<br><br><br>* 連續斜線（//）、空格、美元符號（$）、問號（?）、Delete（ASCII code 127）。<br><br><br>同時，<br><br><br>* 如果規則類型是 **檔案副檔名**，規則內容必須是一個或者多個以分號（;）分隔的檔案副檔名。檔案副檔名無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果規則類型是 **URL 目錄**，規則內容必須是一個或者多個以分號（;）分隔的目錄路徑。目錄路徑必須以斜線（/）開頭和結尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果規則類型是 **URL 全路徑**，規則內容必須是一個或者多個以分號（;）分隔的檔案路徑。檔案路徑必須以斜線（/）開頭，可以包含星號（\*）用來表示一個或者多個字元。例如：`/chs/foods/local*sets;/us/birds/chickadee`。 |
|快取策略 |設置一個快取策略。該配置有以下取值：<br><br><br>* **快取**<br><br>* **遵循來源伺服器**<br><br>* **不快取**<br><br><br>關於每個策略的描述，參見 [瀏覽器快取策略](https://docs.byteplus.com/en/docs/18/36291#%E7%80%8F%E8%A6%BD%E5%99%A8%E5%BF%AB%E5%8F%96%E7%AD%96%E7%95%A5)。 |
|忽略大小寫 |表示匹配過程是否區分大小寫。該設置預設是關閉，表示區分大小寫。<br><br>&nbsp;<br><br>**示例**：對於檔案副檔名規則，您設置 **忽略大小寫** 為關閉。您輸入的規則內容是 `png;txt`。此時，該規則可以匹配 `HTTPS://www.EXAMPLE.com/image.png` 的請求，但是不能匹配 `https://www.example.com/image.PNG` 的請求。 |
|快取時間 |指定一個時間單位並輸入快取的時間。該配置僅當 **快取策略** 是 **快取** 的時候有效。該配置的說明如下：<br><br><br>* 如果您指定的時間單位是 **秒**，您可以輸入的值的範圍是 0 \- 31536000。31,536,000 秒是 365 天。<br><br>* 如果您指定的時間單位是 **分**，您可以輸入的值的範圍是 0 \- 5256000。5,256,000 分是 365 天。<br><br>* 如果您指定的時間單位是 **小時**，您可以輸入的值的範圍是 0 \- 8760。8,760 小時是 365 天。<br><br>* 如果您指定的時間單位是 **天**，您可以輸入的值的範圍是 0 \- 365。<br><br><br>如果您指定 **快取時間** 為 `0`，則表示告知瀏覽器不要快取檔案。 |
