本文檔介紹如何在 BytePlus CDN 中對域名配置來源伺服器請求中包含的查詢參數。

<span id="概述"></span>
## 概述

預設情況下，CDN 在來源伺服器請求中包含的查詢參數和使用者請求的 URL 中包含的查詢參數是相同的。比如使用者請求 URL 是 `http://www.example.com/image.png?version=1`。該 URL 包含查詢參數 `version`，參數值是 `1`。在來源伺服器請求的 URL 中，CDN 也會包含 `version=1`。

如果您需要修改來源伺服器請求中包含的查詢參數或參數值，您可以配置來源伺服器請求參數。在配置中，您需要創建規則，在規則中定義請求的匹配條件以及來源伺服器請求參數的處理方式。

<span id="預設規則"></span>
## 預設規則

來源伺服器請求參數配置中有一條預設規則。這條規則對所有檔案生效，並且優先級始終最低。如果一個使用者請求未匹配您創建的所有規則，這個使用者請求就會匹配該預設規則。您無法刪除這條預設規則，無法調整其優先級，也無法修改這條規則中的規則類型和規則內容。您僅可以修改該規則中的 **參數設定** 配置。該配置的預設是 **保留全部參數**。

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_f3c6f9ca25d8b363cb80f15c176fd172.png) </span>

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **來源伺服器請求參數設定** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **來源伺服器請求參數設定** 下方，點擊 **添加規則**。您最多可以添加 50 條規則。

3. 參照 [配置說明](https://docs.byteplus.com/en/docs/18/36301#%E9%85%8D%E7%BD%AE%E8%AA%AA%E6%98%8E) 進行設定。

4. 設定完成後，在頁面右上方點擊 **提交編輯**。


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_0a921bf080591ca7fd4581aefbddffec.png) </span>

<span id="配置說明"></span>
## 配置說明


|**配置** |**說明** |
|---|---|
|優先級 |表示規則的優先級。當收到使用者請求時，CDN 基於規則在列表中出現的順序，依次處理規則。在處理規則時，CDN 嘗試將規則與使用者請求匹配。如果任意一條規則匹配了使用者請求，CDN 就執行該規則中指定的操作，並停止處理其餘規則。您可以拖動規則調整規則在列表中的出現順序。 |
|規則類型 |表示規則中的過濾類型。該配置有以下選項：<br><br><br>* **檔案後綴**：表示請求 URL 中的擴展名。<br><br>* **檔案目錄**：表示請求路徑中的某個目錄。<br><br>* **檔案全路徑**：表示請求 URL。<br><br>* **全路徑正則**：表示通過正則表達式匹配請求 URL。 要使用該選項，請 [提交工單](https://console.byteplus.com/workorder/create)。 |
|規則內容 |表示規則的內容。內容長度不能超過 1,024 個字符，不能包含以下字符：<br><br><br>* 連續斜杠（//）、空格、美元符號（$）、問號（?）、Delete（ASCII code 127）。<br><br><br>在匹配使用者請求時，規則內容不區分大小寫。<br><br>&nbsp;<br><br>該配置的額外說明如下：<br><br><br>* 如果 **規則類型** 是 **檔案後綴**，規則內容必須是一個或者多個以分號（;）分隔的檔案後綴。檔案後綴無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果 **規則類型** 是 **檔案目錄**，規則內容必須是一個或者多個以分號（;）分隔的目錄路徑。目錄路徑必須以斜杠（/）開頭和結尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果 **規則類型** 是 **檔案全路徑**，規則內容必須是一個或者多個以分號（;）分隔的檔案路徑。檔案路徑必須以斜杠（/）開頭，可以包含星號（\*）用來表示一個或者多個字符。例如：`/chs/foods/local*sets;/us/birds/chickadee`。<br><br>* 如果 **規則類型** 是 **全路徑正則**，規則內容是一個或者多個正則表達式，用於匹配使用者請求 URL 中的路徑。參見 [配置示例](https://docs.byteplus.com/en/docs/18/36301#%E5%85%A8%E8%B7%AF%E5%BE%91%E6%AD%A3%E5%89%87%E9%85%8D%E7%BD%AE%E7%A4%BA%E4%BE%8B)。 |
|參數設定 |表示來源伺服器請求 URL 中查詢參數的設定方式。該配置有以下選項：<br><br><br>* **保留全部參數**：表示來源伺服器請求 URL 中包含使用者請求 URL 中的全部查詢參數。<br><br>* **刪除全部參數**：表示來源伺服器請求 URL 中不包含使用者請求 URL 中的任何查詢參數。<br><br>* **添加指定參數**：表示來源伺服器請求 URL 中包含使用者請求 URL 中的全部查詢參數，並額外包含 **參數內容** 中指定的那些查詢參數。<br><br>* **保留指定參數**：表示如果使用者請求 URL 中存在 **參數名稱** 中指定的查詢參數，那麼來源伺服器請求 URL 中包含這些指定的查詢參數。<br><br>* **刪除指定參數**：表示來源伺服器請求 URL 中包含使用者請求 URL 中的全部查詢參數，除了 **參數名稱** 中指定的那些查詢參數。<br><br>* **重置指定參數**：表示來源伺服器請求 URL 中包含使用者請求 URL 中的全部查詢參數。同時，對於您在 **參數內容** 中指定的查詢參數和參數值，CDN 會執行以下操作:<br><br>   * 如果這些查詢參數在使用者請求 URL 中，CDN 會在來源伺服器請求 URL 中將這些查詢數的值設定為您指定的值。<br><br>   * 如果使用者請求 URL 中不包含這些查詢參數，CDN 會在來源伺服器請求 URL 中添加這些查詢參數。 |
|參數名稱 |表示一個或者多個查詢參數，多個查詢參數之間使用分號（;）分隔，總長度不能超過 1,024 個字符。查詢參數只能包含字母、數字、下劃線（_）、逗號（,）、短橫線（\-）、句點（.）和感嘆號（!）。<br><br>&nbsp;<br><br>在匹配請求 URL 中的查詢參數時，該配置中的參數是大小寫敏感的。<br><br>&nbsp;<br><br>僅當 **參數設定** 是 **刪除指定參數** 或 **保留指定參數** 時，該配置會出現。 |
|參數內容 |表示一個或者多個鍵值對，代表查詢參數和參數值。<br><br>&nbsp;<br><br>鍵值對的格式是 `key=value`，多個鍵值對之間使用分號（;）分隔，總長度不能超過 1,024 個字符。鍵值對只能包含除了空格以外的字符。例如：`size=12-inch;food=pizza;type=pepperoni`。<br><br>&nbsp;<br><br>在匹配請求 URL 中的查詢參數時，該配置中的參數是大小寫敏感的。<br><br>&nbsp;<br><br>僅當 **參數設定** 是 **添加指定參數** 或 **重置指定參數** 時，該配置會出現。 |

### 全路徑正則配置示例


|**使用者請求** |**指定的全路徑正則** |**說明** |
|---|---|---|
|/a/bbb/image.png |^/a{1,2}.\*g$ 用於匹配以 `/` 開頭和以 `g` 結尾的路徑。 |正則表達式匹配了請求 URL 中的路徑。 |
|/aaa/bbb/image.png |/a{1,2}.\*g 用於匹配請求路徑中的特定字符串。 |正則表達式匹配了請求 URL 中的路徑。 |
|/food/aaa/pngs/image.png ||正則表達式匹配了請求 URL 中的路徑。 |
|/aaa/bbb/image.png |aaa.\* 用於匹配請求路徑中的特定字符串。 |正則表達式匹配了請求路徑中的 `aaa/bbb/image.png`。 |
|/aaa/bbb/image.png |aaa/.\* 用於匹配請求路徑中的特定字符串。 |正則表達式匹配了請求路徑中的 `aaa/bbb/image.png`。 |
