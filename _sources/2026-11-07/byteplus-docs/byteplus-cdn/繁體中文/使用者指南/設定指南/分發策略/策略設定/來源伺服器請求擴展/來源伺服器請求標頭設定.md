本文件介紹 BytePlus CDN 中的「來源伺服器請求標頭設定」特性。

在來源伺服器請求中，CDN 會包含使用者請求中的所有請求標頭。同時，CDN 還會新增一些預設請求標頭。參見 [CDN 新增的預設標頭列表](https://docs.byteplus.com/en/docs/18/36298#cdn-%E6%B7%BB%E5%8A%A0%E7%9A%84%E9%A0%90%E8%A8%AD%E6%A8%99%E9%A0%AD%E5%88%97%E8%A1%A8)。

除了 CDN 新增的預設請求標頭，如果您希望來源伺服器請求中包含更多的標頭，您可以設定來源伺服器請求標頭。

<span id="適用場景"></span>
## 適用場景

**識別來自 CDN 的請求**

您的來源伺服器除了收到來自 CDN 的請求，也有可能收到來自其他請求方的請求。或者您的來源伺服器使用了多個雲端供應商的 CDN 做內容傳遞加速。在這些情況下，您可以在來源伺服器請求中新增一個特定的請求標頭。在來源伺服器的請求日誌中，您可以基於該請求標頭統計以下資料：


* 請求方不是 CDN 的請求數量。

* 在多個雲端供應商中，來自 BytePlus CDN 的請求數量。


**區分來自不同網域名稱的請求**

在 CDN 中，您為多個網域名稱設定了相同的來源伺服器。這些網域名稱有不同的設定，針對不同的使用場景。在這個情況下，您可以在來源伺服器請求中新增一個特定的請求標頭，以區分來自不同網域名稱的請求。在來源伺服器的請求日誌中，您可以基於該請求標頭統計資料。

**在來源伺服器實施存取控制**

您希望阻止來源不是 CDN 的使用者請求。在這個情況下，您可以在來源伺服器請求中新增一個特定的請求標頭，然後在來源伺服器實施存取控制，阻止不包含該請求標頭的請求存取您的來源伺服器。

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **來源伺服器請求標頭設定** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **來源伺服器請求標頭設定** 下方，點擊 **新增規則**。

   您最多可以新增 50 條規則。

3. 參照以下設定說明。

4. 設定完成後，點擊 **儲存**。


<span id="設定說明"></span>
## 設定說明


|**設定** |**說明** |
|---|---|
|來源伺服器請求標頭操作 |表示一個操作類型。該設定有以下選項：<br><br><br>* **設定**：表示設定一個標頭。設定操作包括新增與修改。如果來源伺服器回應中已包含該標頭，該標頭的值會被覆蓋。如果來源伺服器回應中沒有包含該標頭，該標頭會被新增。<br><br>* **刪除**：表示刪除一個標頭。 |
|請求標頭名稱 |表示需要設定或者刪除的一個標頭。標頭名稱是大小寫不敏感的。除了 [注意事項](https://docs.byteplus.com/en/docs/18/36298#%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A0%85) 中列出的那些標頭名稱之外，您可以輸入任意一個標頭名稱。標頭名稱不能超過 1,024 個字元，不能包含以下字元：<br><br><br>* 漢字、底線（_）、空格、雙引號（"）、冒號（:） |
|取值方式 |對於您在 **請求標頭名稱** 中指定標頭，該設定表示該標頭值的類型，有以下選項：<br><br><br>* **常數值**：表示該標頭值為一個字串。<br><br>* **變數**：表示該標頭值來自一個變數。<br><br>* **自訂**：表示該標頭值是變數與字串拼接後的一個字串。 |
|來源伺服器請求標頭的值 |表示您在 **請求標頭名稱** 中指定標頭的取值。<br><br><br>* 如果 **取值方式** 是 **常數值**，您需要輸入一個字串。該字串的長度不能超過 1,024 個字元，不能包含以下字元：<br><br>   * 漢字、底線（_）、空格、雙引號（"）、冒號（:）<br><br>* 如果 **取值方式** 是 **變數**，您需要從列表中選擇一個變數。參見 [變數列表](https://docs.byteplus.com/en/docs/18/36298#%E8%AE%8A%E6%95%B8%E5%88%97%E8%A1%A8)。<br><br>* 如果 **取值方式** 是 **自訂**，您需要輸入由變數和字串拼接後的一個字串。變數需要包裹在 `{}` 中，由 `$` 開頭。例如 `bind${scheme}to${client_ip}done`。 |


<span id="變數列表"></span>
## 變數列表

CDN 提供了以下變數。


|變數名稱 |說明 |示例值 |
|---|---|---|
|uri |表示來源伺服器請求 URL 中的路徑。 |`/dir/byteplus.php` |
|request_uri |表示來源伺服器請求 URL 中的路徑和查詢字串（query string）。 |`/dir/byteplus.php?color=red&n=10` |
|http_host |表示來源伺服器請求中 Host 標頭的值。 |`byteplus.com:8080` |
|args |表示來源伺服器請求 URL 中的查詢字串。 |`color=red&n=10` |
|msec |表示 CDN 設定該來源伺服器請求標頭的時間，格式是 Unix 時間標記，精確到毫秒。 |`1704444754.917` |
|scheme |表示來源伺服器請求使用的協定。 |`https` |
|origin_srv_addr |表示來源伺服器的網域名稱或者 IP 位址。 |`www.example.com` |
|query_string |與 `args` 變數的意義相同。 |`size=small&color=red` |
|host |表示來源伺服器請求中 Host 標頭的值。<br><br>&nbsp;<br><br>需要留意的是，CDN 在處理請求時可能會修改該標頭的值。因此，不建議您使用該標頭，而是使用 `http_host`。 |`example.com:8080` |
|client_ip |表示連接到 CDN，觸發了本次來源伺服器請求的用戶端的真實 IP 位址。 |`127.1.1.1` |


<span id="注意事項"></span>
## 注意事項

您設置的請求標頭名稱不能以 `x-bdcdn-` 或者 `X-Bytecdn-` 開頭，也不能是以下任意標頭。


* x\-tos\-request\-id

* bd\-bdcdn\-oss\-switch

* x\-storagegw\-request\-id

* x\-sign

* host

* X\-Trace\-Via


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">如果使用者請求中包含以 <code>x-bdcdn-</code> 或者 <code>X-Bytecdn-</code> 開頭的標頭，這些標頭將不會包含在來源伺服器請求中。</div>


<span id="cdn-添加的預設標頭列表"></span>
## CDN 添加的預設標頭列表

CDN 在來源伺服器請求中預設添加以下標頭。


|請求標頭 |描述 |示例 |
|---|---|---|
|X\-Forwarded\-For |表示發送來源伺服器請求的 CDN 節點的 IP 位址。 |`xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxx`, `xx.xx.xxx.xxx` |
|X\-Forwarded\-Protocol |表示來源伺服器請求使用的協議。 |`http` |
|X\-Real\-IP |對於觸發該來源伺服器請求的用戶請求，該標頭表示發送該用戶請求的客戶端 IP 位址。 |`xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxx` |
|X\-Forwarded\-Proto |表示用戶請求使用的協議。 |`http` |
|X\-Client\-Scheme |表示用戶請求使用的協議。 |`http` |
|X\-Trace\-via |表示發送來源伺服器請求的 CDN 節點的標識。 |`gycm` |
|Bd\-Raw\-Host |表示用戶請求的 URL 中的網域名稱。 |`www.example.com` |
|X\-Bdcache\-Trace\-Id |表示用戶請求的 ID。 |`f455f0415d901f8aee3b2c7336bfad16` |
|X\-Tt\-Trace\-Id |表示來源伺服器請求的 ID。 |`202405301714110101720050051BB69184` |
