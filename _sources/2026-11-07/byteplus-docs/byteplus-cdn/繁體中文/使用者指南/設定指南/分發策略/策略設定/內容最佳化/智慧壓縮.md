本文件介紹如何在 BytePlus CDN 中啟用智慧壓縮。

開啟智慧壓縮後，您可以創建規則，指定哪些類型的檔案需要壓縮以及所使用的壓縮算法。在 CDN 收到請求時，如果請求匹配了某條規則，CDN 會根據規則的配置對請求的檔案進行壓縮，然後返回壓縮後的檔案。該功能可以減小檔案的大小，提高檔案傳輸速度，降低流量消耗。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如果請求匹配了某條智慧壓縮規則，CDN 除了返回壓縮檔案，還會快取壓縮後的檔案。也就是說，對於同一個檔案，CDN 會分別快取原始副本和壓縮副本。</div>


<span id="支援的檔案類型"></span>
## 支援的檔案類型

目前，智慧壓縮僅支援對 `Content-Type` 回應標頭是以下類型的檔案進行壓縮。如果您需要壓縮的檔案類型不在以下列表中，請 [提交工單](https://console.byteplus.com/workorder/create)。


* text/html

* text/xml

* text/plain

* text/css

* application/javascript

* application/x\-javascript

* application/rss+xml

* text/javascript

* image/tiff

* image/svg+xml

* application/json

* application/xml


<span id="注意事項"></span>
## 注意事項


* CDN 僅對 GET 請求的檔案進行壓縮。

* 如果來源伺服器開啟了壓縮功能，且來源伺服器回應中 `Content-Encoding` 標頭的值不為空且不為 `identity`，表明來源伺服器已經對該檔案進行了壓縮。在這種情況下，CDN 不再對該檔案進行壓縮。

* 如果您在智慧壓縮配置中同時勾選了 Brotli 壓縮和 Gzip 壓縮，且使用者請求中的 `Accept-Encoding` 標頭的值包含 `br` 和 `gzip` 時，有以下兩種情況：

   * 如果 `Accept-Encoding` 不包含演算法的權重，CDN 使用 Brotli 演算法對請求檔案進行壓縮。

   * 如果 `Accept-Encoding` 包含演算法的權重，CDN 使用權重高的演算法對請求檔案進行壓縮。

* 如果請求為 Range 請求並且匹配了某條智慧壓縮規則，則，

   * 如果 CDN 邊緣伺服器存在請求檔案的壓縮副本，CDN 會從壓縮副本中提取請求的分片，並返回**壓縮後**的分片。

   * 如果 CDN 邊緣伺服器不存在請求檔案的壓縮副本，CDN 會返回**未壓縮**的分片。

* 若來源伺服器檔案配置了 MD5 校驗機制，請勿開啟智慧壓縮功能。

* 所有瀏覽器都支援 Gzip。舊版本瀏覽器可能不相容 Brotli。您可以[查看 Brotli 的瀏覽器相容情況](https://caniuse.com/?search=Brotli)。

* 如果來源伺服器回應中 Vary 標頭沒有遵循 [RFC 標準](https://datatracker.ietf.org/doc/html/rfc7231#section-7.1.4)，則可能會導致壓縮功能不生效。


<span id="操作步驟"></span>
## 操作步驟


1. 打開 **智慧壓縮** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **智慧壓縮** 下方，設置 **狀態** 為 **開啟**。

3. 點擊 **新增規則**。您最多可以新增 50 條規則。

4. 參照下方 [配置說明](https://docs.byteplus.com/en/docs/18/36294#%E9%85%8D%E7%BD%AE%E8%AA%AA%E6%98%8E) 對規則進行設置。

5. 配置完成後，點擊 **儲存**。

<span id="配置說明"></span>
## 配置說明


|**配置** |**說明** |
|---|---|
|規則類型 |表示規則中的過濾類型。該配置有以下選項：<br><br><br>* **檔案副檔名**：表示路徑末尾的擴展名。<br><br>* **URL 目錄**：表示路徑中的一個目錄。<br><br>* **URL 全路徑**：表示請求 URL 中的路徑。<br><br>* **內容類型**：表示請求中的 `Content-Type` 請求標頭。<br><br><br>規則列表中只能有一條規則類型是 **內容類型** 的規則。這條規則的優先級是最低的，您也無法調整其優先級。 |
|規則 |表示規則中的過濾值，過濾值大小寫不敏感。多個過濾值之間使用分號（;）分隔，總長度不能超過 1,024 個字元，不能包含以下字元：<br><br><br>* 連續斜線（//）、空格、美元符號（$）、問號（?）、Delete（ASCII code 127）。<br><br><br>另外，<br><br><br>* 如果 **規則類型** 是 **檔案副檔名**，過濾值是一個或者多個檔案副檔名。檔案副檔名無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果 **規則類型** 是 **URL 目錄**，過濾值是一個或者多個目錄路徑。目錄路徑必須以斜線（/）開頭和結尾。例如：`/chs/foods/;/us/birds/`。<br><br>* 如果 **規則類型** 是 **URL 全路徑**，過濾值是一個或者多個檔案路徑。檔案路徑必須以斜線（/）開頭，可以包含星號（\*）用來表示一個或者多個字元。例如：`/chs/foods/local*sets;/us/birds/chickadee`。<br><br>* 如果 **規則類型** 是 **內容類型**，控制台提供以下選項：<br><br>   * **預設**：表示規則應用於以下所有檔案類型：text/html、text/xml、text/plain、text/css、application/javascript、application/x\-javascript、application/rss+xml、text/javascript、image/tiff、image/svg+xml、application/json、application/xml、text/plain; charset=utf\-8。<br><br>   * **客製化**：表示規則應用於您指定的檔案類型。您可以從列表中勾選一個或者多個檔案類型。您也可以輸入不在檔案列表中的檔案類型。 |
|檔案大小（最小） |表示一個檔案大小。如果請求檔案的大小小於該值，則 CDN 不會壓縮該檔案。該配置的取值範圍 0 \- 2,147,483,647，單位是 KB，使用的進制是 1,024。如果該配置值是 `0`，表示無論檔案大小，CDN 始終對檔案進行壓縮。 |
|壓縮演算法 |表示該規則對指定類型的符合過濾條件的請求檔案所使用的壓縮演算法。該配置有以下取值：<br><br><br>* Gzip<br><br>* Brotli<br><br><br>CDN 在使用 Brotli 演算法壓縮請求檔案時，使用的壓縮級別是 6。<br><br>&nbsp;<br><br>Brotli 提供了 12 個壓縮級別，從 0 到 11，其中 0 提供最快的壓縮速度，但壓縮比最低，11 提供最高的壓縮比，但需要更多的計算資源和壓縮時間。 |


<span id="規則生效邏輯"></span>
## 規則生效邏輯

當收到使用者請求時，CDN 基於規則在列表中出現的順序，依次處理規則。在處理規則時，CDN 嘗試將規則與請求匹配。如果任意一條規則匹配了請求，CDN 對請求檔案應用壓縮配置，並停止處理其餘規則。您可以拖動規則調整規則在列表中的出現順序。
