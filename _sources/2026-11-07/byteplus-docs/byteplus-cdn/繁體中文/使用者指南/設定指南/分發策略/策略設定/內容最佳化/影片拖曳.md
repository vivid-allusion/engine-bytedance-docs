BytePlus CDN 提供了 "影片拖曳" 功能，可以處理特定場景下播放器發送的影片分片請求。參見 [前提條件](https://docs.byteplus.com/en/docs/18/36295#%E5%89%8D%E6%8F%90%E6%A2%9D%E4%BB%B6)。

<span id="前提條件"></span>
## 前提條件


* 播放器播放的影片檔案的格式是 MP4。

* 播放器透過在請求 URL 中使用 `start` 和 `end` 查詢參數來指定請求的影片分片。例如，以下請求 URL 表示播放器請求的是從第 15 秒開始，第 120 秒結束的影片分片。

   * `http://www.example.com/4K_demo.mp4?start=15.000&end=120.000`


<span id="操作步驟"></span>
## 操作步驟


1. 打開 **影片拖曳** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **影片拖曳** 下方，設置 **狀態** 為 **開啟**。

3. 配置完成後，點擊 **儲存**。


<span id="start-end-參數說明和影片檔案的-metadata-要求"></span>
## start/end 參數說明和影片檔案的 Metadata 要求


|**影片格式** |**Metadata** |**start/end 參數** |**請求 URL 示例** |
|---|---|---|---|
|MP4 |在來源伺服器上，MP4 影片檔案必須包含 Metadata，並且 Metadata 必須出現在檔案的開頭。 |表示影片的開始和結束時間，單位是秒，精確到毫秒。 |`http://www.example.com/video.mp4?start=5.013&end=12.123` |



* 對於 `start` 和 `end` 參數，CDN 區分參數名中字元的大小寫。例如，CDN 收到了一個請求 URL 是 `http://www.example.com/sample.mp4?Start=15` 的請求。由於 `Start`參數的大小寫不正確，CDN 返回的是完整的 `sample.mp4`，而不是指定的影片分片。

* 如果 `start` 或 `end` 指定位置的影片幀不是關鍵幀，則 CDN 將從影片的早些時間中獲取離 `start` 或 `end` 最近的關鍵幀作為實際的開始和結束位置。

<span id="影片拖曳概述"></span>
### 影片拖曳概述

影片拖曳是現代影片播放器普遍支援的功能。在影片播放時，使用者可以拖動播放器中的進度條改變播放時間點。當使用者拖動進度條到一個時間點時，播放器會向伺服器請求從該時間點開始的一個影片分片，而不是請求完整的影片。這樣，在使用者觀看影片時，無需等待完整影片檔案的下載，而是在播放器獲得影片分片後就可以從相應時間點開始觀看影片了，使用者體驗好。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">當使用者在播放器中首次打開一個影片時，播放器是向伺服器請求從影片開頭開始的一個影片分片。</div>


* <div data-tips="true" data-tips-type="tip">在影片播放過程中，播放器會在當前影片分片播放結束前，提前向伺服器請求下一個影片分片。</div>



<span id="cdn-如何處理播放器的影片分片請求"></span>
### CDN 如何處理播放器的影片分片請求

當您的場景滿足 [前提條件](https://docs.byteplus.com/en/docs/18/36295#%E5%89%8D%E6%8F%90%E6%A2%9D%E4%BB%B6)，，並且開啟了 影片拖曳 特性，CDN 會根據請求中 `start` 和 `end` 參數，從快取的完整影片檔案中擷取請求的影片分片，然後返回給播放器。如果請求本身還是一個 Range 請求，CDN 會忽略 `Range` 請求標頭。

在 CDN 收到播放器發送的影片分片請求時，如果 CDN 還未快取完整的影片檔案或者快取的影片檔案已過期，CDN 會先向來源伺服器請求完整的影片檔案。因此，對於發送該影片分片請求的播放器，需要等待較長的時間才能收到 CDN 的回應。要避免這個問題，對於熱門的影片，推薦您使用 CDN 提供的 [預取快取](https://docs.byteplus.com/en/docs/byteplus-cdn/file-prefetch_zh-tw) 功能將這些影片檔案提前快取到 CDN 節點。

<span id="什麼是關鍵幀"></span>
### 什麼是關鍵幀

影片中任意一個平滑過渡是由兩個關鍵幀定義的。這兩個關鍵幀分別記錄了該平滑過渡的開始狀態和結束狀態。對於 MP4 格式的影片檔案，其元數據中指定了哪些影片幀是關鍵幀。

<span id="其他資訊"></span>
### 其他資訊


* 在 CDN 快取影片檔案時，檔案的快取鍵中既不包含 `start` 參數，也不包含 `end` 參數。

* 在 CDN 向來源伺服器請求完整影片檔案時，回源請求中既不包含 `start` 參數，也不包含 `end` 參數。
