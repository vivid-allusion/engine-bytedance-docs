本文件介紹了 BytePlus CDN 提供的設定來源伺服器請求逾時的功能。您可以對回源請求設定 TCP 逾時時間和 HTTP 逾時時間。

<span id="背景知識：http-請求的流程"></span>
## 背景知識：HTTP 請求的流程

當用戶端訪問一個網站，也就是向網站請求內容時，請求的流程包含以下步驟：


1. 透過 DNS 解析，用戶端獲取到網站伺服器的 IP 位址。

2. 用戶端向網站伺服器發送 TCP 請求以建立連線。

3. 網站伺服器回應用戶端的 TCP 請求，連線建立。

4. 用戶端向網站伺服器發送 HTTP 請求獲取網站的內容。

5. 網站伺服器回應用戶端請求，將請求的內容發送給用戶端。

6. 收到內容後，用戶端向網站伺服器發送 TCP 請求以斷開連線。

7. 網站伺服器回應用戶端的 TCP 請求，連線斷開。


在 CDN 向來源伺服器請求內容時，也是遵循這個流程。

<span id="來源伺服器請求逾時時間"></span>
## 來源伺服器請求逾時時間

在 CDN 中，預設的逾時時間設定如下：


* CDN 向來源伺服器發送 TCP 請求建立連線時，TCP 請求的逾時時間是 2 秒。

* CDN 向來源伺服器發送 HTTP 請求獲取來源伺服器的內容時，HTTP 請求的逾時時間是 60 秒。


在某些情況下，您可能需要根據網路情況以及來源伺服器的資料處理能力設定一個合理的逾時時間。在設定逾時時間前，請留意以下說明：


* 如果您設定的逾時時間過短，回源請求可能會頻繁失敗。原因可能是網路品質不佳。

* 如果您設定的逾時時間過長，回源請求會持續佔用來源伺服器的連線數，影響來源伺服器的服務能力。


<span id="操作步驟"></span>
## 操作步驟

要對一個網域名稱開啟該配置，您需要在一個未發布的分發策略中進行配置，然後發布該策略並將其綁定該網域名稱。如果該網域名稱已綁定了一個策略，可以透過 [策略複製](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-policy-cn#%E5%A4%8D%E5%88%B6%E7%AD%96%E7%95%A5) 建立一個未發布的策略。


1. 打開 **來源伺服器請求逾時** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **來源伺服器請求逾時** 下方，設定 **狀態** 為 **開啟**。

3. 分別對 TCP 和 HTTP 設定逾時時間。逾時時間的單位是 秒。

   * TCP 逾時時間的範圍是 2\-60 秒。

   * HTTP 逾時時間的範圍是 5\-60 秒。

4. 配置完成後，點擊 **儲存**。
