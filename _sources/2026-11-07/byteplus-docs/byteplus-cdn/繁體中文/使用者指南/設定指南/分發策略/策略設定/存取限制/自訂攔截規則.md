本文檔介紹 BytePlus CDN 中的「自訂攔截規則」功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">要使用該功能，請 <a href="https://console.byteplus.com/workorder/create">提交工單</a>。</div>


該功能使您可以對用戶端請求中的路徑、請求中的查詢參數、請求來源的用戶端 IP 位址設定匹配條件，並對符合匹配條件的請求設定 CDN 處理這些請求的方式。

<span id="功能優先級"></span>
## 功能優先級

CDN 提供的一系列存取控制功能有不同的優先級。在 CDN 處理用戶端請求時，這些功能按優先級對請求生效。參見 [存取限制功能的優先順序](https://docs.byteplus.com/en/docs/byteplus-cdn/access-restrictions-priority_zh-tw)。

<span id="操作步驟"></span>
## 操作步驟


1. 開啟 **自訂攔截規則** 配置頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 設定 **狀態** 為開啟。

3. 點擊 **新增規則**，然後參照 [配置說明](https://docs.byteplus.com/en/docs/18/44863#%E9%85%8D%E7%BD%AE%E8%AA%AA%E6%98%8E) 對規則進行設定。您最多可以建立 10 條規則。

4. 配置完成後，點擊 **儲存**。

<span id="配置說明"></span>
## 配置說明

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">關於以下配置的內容輸入要求，參見 <a href="https://docs.byteplus.com/en/docs/18/44863#%E9%85%8D%E7%BD%AE%E8%BC%B8%E5%85%A5%E8%A6%81%E6%B1%82">配置輸入要求</a>。</div>



|**配置** |**說明** |
|---|---|
|規則名稱 |表示規則的名稱。 |
|生效對象 |表示一個或多個匹配條件，用於對請求進行匹配。點擊 **新增** 建立一個匹配條件，您最多可以建立 5 個匹配條件。如果您不新增任何匹配條件，表示所有請求都匹配這條規則。<br><br>&nbsp;<br><br>在每個匹配條件中，您需要設定匹配類型、對比類型和匹配值。匹配值可以是多個。如果 **匹配類型** 是 **用戶端 UA**，多個匹配值之間以豎線（\|）分隔。如果 **匹配類型** 不是 **用戶端 UA**，多個匹配值之間以分號（;）分隔。多個匹配值之間的關係是「或」。<br><br>&nbsp;<br><br>匹配類型的說明如下：<br><br><br>* **檔案全路徑**：表示請求 URL 中的路徑。<br><br>* **檔案目錄**：表示路徑中的一個目錄。<br><br>* **檔案副檔名**：表示路徑末尾的擴展名。<br><br>* **全路徑正規表示式**：表示請求 URL 中的路徑，通過正規表示式匹配。<br><br>* **請求 FullQuery**：表示請求 URL 中的查詢字串。<br><br>* **請求 Query**：表示請求 URL 中的一個查詢參數。<br><br>* **用戶端 IP**：表示用戶端的 IP 位址。<br><br>* **用戶端 UA**：表示請求中 User\-Agent 標頭。<br><br>* **自訂請求標頭**：表示請求中的自訂標頭。<br><br><br>如果匹配類型是 **全路徑正規表示式** 或 **請求 FullQuery**，匹配值是正規表示式。要使用這兩個匹配類型，請 [提交工單](https://console.byteplus.com/workorder/create)。<br><br>&nbsp;<br><br>關於對比類型，需要留意的是：<br><br><br>* **等於、匹配**：表示如果請求匹配任意匹配值，該請求就符合匹配條件。<br><br>* **不等於、不匹配** ：表示如果請求不匹配所有匹配值，該請求才符合匹配條件。<br><br>* **屬於/屬於全域名單**：僅適用於 **請求 Query**，表示一個類型是「通用清單」的全域配置。「通用清單」用來定義大量匹配值。 |
|攔截方式 |表示 CDN 如何處理符合匹配條件的請求。該配置的可選值有：<br><br><br>* **4xx 錯誤**：表示 CDN 回應一個 4xx 的錯誤碼。<br><br>* **重新導向**：表示 CDN 將請求重新導向到另一個 URL。<br><br><br>如果您計劃建立多條規則，每條規則中的 **攔截方式** 必須相同。 |


當 **攔截方式** 為 **4xx 錯誤** 時，您可以設定以下額外配置：


|**配置** |**說明** |
|---|---|
|回應狀態碼 |表示 CDN 對滿足匹配條件的請求的回應狀態碼。您需要設定一個 400\-499 範圍內的錯誤碼，例如 `405`。 |
|回應 Body |表示回應正文中的內容。該配置有以下選項：<br><br><br>* **系統預設**：表示 CDN 使用 4xx 錯誤碼的標準回應正文。<br><br>* **自訂**：表示 CDN 使用一個自訂回應頁面。您可以在 **回應頁面** 下拉清單中選擇一個自訂頁面。下拉清單中的頁面來自 **全域配置** 頁面下的 **自訂回應頁面** 標籤頁。要建立自訂回應頁面，請 [提交工單](https://console.byteplus.com/workorder/create)。 |


**攔截方式** 為 **重新導向** 時，您可以設定以下額外配置：


|**配置** |**說明** |
|---|---|
|回應狀態碼 |表示 CDN 對滿足匹配條件的請求的回應狀態碼。您可以設定 **301** 或者 **302**。 |
|Location |表示一個重新導向 URL。 |


<span id="規則優先級"></span>
## 規則優先級

規則清單中的規則具有優先級，優先級最高的規則優先生效。對於一個用戶端請求，如果某條規則與該請求匹配，只有該規則生效，剩餘規則不生效。您可以拖動規則來調整規則的優先級。

## 更多資訊

<span id="配置輸入要求"></span>
### 配置輸入要求


|**配置** |**輸入要求** |
|---|---|
|規則名稱 |長度不超過 20 個字元，可以包含字母、數字、底線（_）、連字元（\-）、漢字。一個漢字佔 3 個字元。 |
|生效對象 |生效對象中，匹配值的輸入要求如下：<br><br><br>* 如果匹配類型是 **檔案全路徑**，每個匹配值表示一個檔案路徑。每個檔案路徑必須以斜線（/）開頭。您可以在路徑中使用一個或多個星號（\*），每個星號表示一個或多個字元。例如：`/www/img/my*image.png`。<br><br>* 如果匹配類型是 **檔案目錄**，匹配值中的每個目錄必須以斜線（/）開頭和結尾。例如：`/www/img/`。<br><br>* 如果匹配類型是 **檔案副檔名**，匹配值中的每個副檔名無需以句點（.）開頭。例如：`png;txt`。<br><br>* 如果匹配類型是 **檔案全路徑**、**檔案目錄**、**檔案副檔名**，匹配值的總長度不能超過 1,024 個字元，不能包含以下字元：<br><br>   * 連續斜線（//）、空格、美元符號（$）、問號（?）、Delete（ASCII code 127）。<br><br>* 如果匹配類型是 **請求 Query**，參數名稱和匹配值的有以下要求：<br><br>   * 您只能指定一個參數名稱，也只能指定一個參數值作為匹配值。<br><br>   * 參數名稱和匹配值的長度都不能超過 256 個字元。<br><br>   * 參數名稱和匹配值可以包含數字、字母、百分號（%）、底線（_）、中劃線（\-）。<br><br>* 如果匹配類型是 **用戶端 IP**，匹配值有以下要求：<br><br>   * 總長度不能超過 30,000 個字元。<br><br>   * IP 位址的數量不能超過 50 個。<br><br>   * IP 位址可以是 IPv4 位址、IPv4 CIDR 位址、IPv6 位址或 IPv6 CIDR 位址。<br><br>* 如果匹配類型是 **自訂標頭** 或 **用戶端 UA** 時，匹配值有以下要求：<br><br>   * 總長度不能超過 1,024 個字元。除了開頭和結尾，匹配值不能包含 \*。\* 表示一個或多個任意字元。<br><br>   * 匹配值的數量不能超過 50 個。<br><br>* 如果匹配類型是 **全路徑正規表示式** 或 **請求 FullQuery** 時，每個匹配值都是一個正規表示式，總長度不能超過 1,024 個字元。 |
|目標網址 |URL 必須以 `http://` 或 `https://` 開頭，長度不能超過 1,024 個字元。 |
