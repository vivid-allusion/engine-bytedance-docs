BytePlus CDN 提供的一系列存取限制功能具有不同的優先順序。在 CDN 處理使用者請求時，這些存取限制功能的生效順序如下：


1. 地理位置存取限制

2. 禁用 HTTP 方法

3. IP 存取限制

4. Referer 存取限制

5. UA 存取限制

6. Origin 存取限制

7. 自訂攔截規則

8. URL 驗證

9. 遠端驗證

10. 下載限速


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">對於一個使用者請求，如果任意一個存取限制功能的結果是拒絕該請求，則其餘的存取限制功能不再對該請求生效。</div>
