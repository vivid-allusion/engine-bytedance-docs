在 CDN 中新增網域名稱後，您需要指定內容的來源。當收到使用者請求時，如果請求的檔案尚未被 CDN 快取，CDN 會向來源伺服器請求檔案並進行快取。

本檔案介紹如何在 CDN 中設定來源伺服器。在建立分發策略時，您必須在策略中新增一個主來源伺服器。CDN 支援的來源伺服器類型包括 IP 位址、網域名稱和物件儲存桶。您可以設定多個來源伺服器，並為每個來源伺服器設定權重，以實現來源伺服器間的負載平衡。同時，為了保證來源伺服器請求的成功率，CDN 支援設定主備來源伺服器。

<span id="操作步驟"></span>
## 操作步驟


1. 打開 **來源伺服器設定** 標籤頁。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 點選 **新增來源伺服器** 新增一個來源伺服器設定。

   您至少新增一個主來源伺服器，備用來源伺服器是可選的。

3. 參照以下設定說明對來源伺服器進行設定。

   * 如果來源伺服器的類型 **來源伺服器 IP** 或 **來源伺服器網域名稱**，參考 [來源伺服器設定說明（類型是 "來源伺服器 IP" 和 "來源伺服器網域名稱"）](https://docs.byteplus.com/en/docs/18/36128#ip-domain))。

   * 如果來源伺服器的類型 **物件儲存來源伺服器**，參考 [來源伺服器設定說明（類型是 "物件儲存來源伺服器"）](https://docs.byteplus.com/en/docs/18/36128#46d92e6c)。

4. 按需設定 [來源伺服器請求協議](https://docs.byteplus.com/en/docs/18/36128#%E4%BE%86%E6%BA%90%E4%BC%BA%E6%9C%8D%E5%99%A8%E8%AB%8B%E6%B1%82%E5%8D%94%E8%AD%B0) 和 [來源伺服器請求 Hostname](https://docs.byteplus.com/en/docs/18/36128#%E4%BE%86%E6%BA%90%E4%BC%BA%E6%9C%8D%E5%99%A8%E8%AB%8B%E6%B1%82-hostname)。

5. 設定完成後，在頁面右下方點選 **儲存**。

## 來源伺服器設定說明（類型是 "來源伺服器 IP" 和 "來源伺服器網域名稱"）

|**設定** |**說明** |
|---|---|
|來源伺服器請求位址 |表示一個或多個來源伺服器位址。多個位址使用分號（;）或換行分隔。該設定的描述如下：：<br><br><br>* 當 **來源伺服器類型** 為 **來源伺服器 IP** 時，您可以輸入 IPv4 和 IPv6 位址。<br><br>* 當 **來源伺服器類型** 為 **來源伺服器網域名稱** 時，您輸入的網域名稱不能是泛網域名稱。<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">一個網域名稱下，所有主來源伺服器的位址加上所有備用來源伺服器的位址的總數不能超過 50 個。</div><br> |
|權重 |表示來源伺服器的權重，範圍是 1\-100，預設值是 1。在 CDN 請求來源伺服器時，權重越高的來源伺服器被選中的機率也越高。例如您定義了兩個主來源伺服器，權重分別為 3 和 2。權重為 3 的來源伺服器被選中的機率為 60%。 |
|HTTP 連接埠 |表示 CDN 使用 HTTP 協議請求來源伺服器時存取的來源伺服器連接埠，取值範圍是 1\-65535，預設值是 `80`。如果來源伺服器不接受 HTTP 請求，對於該設定您保留預設值即可。參見下方 **連接埠設定的額外說明**。 |
|HTTPS 連接埠 |表示 CDN 使用 HTTPS 協議請求來源伺服器時存取的來源伺服器連接埠。該設定的取值範圍是 1\-65535，預設值是 `443`。如果來源伺服器不接受 HTTPS 請求，對於該設定您保留預設值即可。參見下方 **連接埠設定的額外說明**。 |
|來源伺服器請求 Hostname |表示該來源伺服器上的站點網域名稱。該設定的說明如下：<br><br><br>* 預設值與全域的來源伺服器請求 Host 的設定相同。來源伺服器的來源伺服器請求 Host 的優先級高於全域來源伺服器請求 Host。<br><br>* 長度不能超過 1,024 個字元。<br><br>* 不同的來源伺服器請求位址可以設定不同的來源伺服器請求 Host。 |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip"><strong>連接埠設定的額外說明</strong></div>


<div data-tips="true" data-tips-type="tip">您設定的 <a href="https://docs.byteplus.com/en/docs/18/36128#%E4%BE%86%E6%BA%90%E4%BC%BA%E6%9C%8D%E5%99%A8%E8%AB%8B%E6%B1%82%E5%8D%94%E8%AD%B0">來源伺服器請求協議</a> 以及相應的來源伺服器連接埠必須是來源伺服器支援的。否則，來源伺服器請求會失敗。對於您設定的連接埠，您可以透過如下方式檢測來源伺服器是否已開通了該連接埠。</div>



* <div data-tips="true" data-tips-type="tip">Windows：在命令提示字元視窗中，執行命令 <code>telnet <IP/domain> <port></code></div>


   <div data-tips="true" data-tips-type="tip">如果 Telnet 命令列視窗開啟了，則表示來源伺服器支援設定的協議和連接埠。   </div>
   

* <div data-tips="true" data-tips-type="tip">macOS 和 Linux：在 Terminal 視窗中，執行命令 <code>nc -vz -w 2 <IP/domain> <port></code></div>


   <div data-tips="true" data-tips-type="tip">如果命令返回 <code>Connection succeeded!</code>，則表示來源伺服器支援設定的協議和連接埠。   </div>

## 來源伺服器請求協議

在 **來源伺服器請求協議** 下方，您可以設定來源伺服器請求使用的協議。該設定有以下選項：


* HTTP：表示來源伺服器請求始終使用 HTTP 協議。

* HTTPS：表示來源伺服器請求始終使用 HTTPS 協議。

* 協議跟隨：表示來源伺服器請求使用的協議與使用者請求使用的協議相同。

## 來源伺服器請求 Hostname

在來源伺服器上存在多個站點的情況下，您需要手動指定 CDN 需要存取的站點的 hostname。

該設定是全域 hostname 的設定，優先級低於來源伺服器的 hostname 設定。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">對於 <strong>來源伺服器類型</strong> 是 <strong>物件儲存來源伺服器</strong> 的來源伺服器，該設定不生效。因為 CDN 為這些來源伺服器預設了雲端廠商的 hostname。來源伺服器的 hostname 設定的優先級高於全域 hostname 設定。</div>


在 **來源伺服器請求 Host** 下方，您可以設定全域 hostname，長度不能超過 1,024 個字元，預設與網域名稱相同。
