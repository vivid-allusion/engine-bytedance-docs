本文件介紹如何在 BytePlus CDN 中設定 URL 重新導向改寫。該設定允許您對指定的請求路徑，將其重新導向到指定位址。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">要使用此功能，請 <a href="https://console.byteplus.com/workorder/create">提交工單</a>。</div>


<span id="使用情境"></span>
## 使用情境

在來源伺服器上，假設某些使用者經常存取的檔案路徑發生了變更。此時，有以下幾種解決方案：


* 在來源伺服器設定重新導向，將內容的原 URL 重新導向到新的 URL。同時在 CDN 中開啟 [來源伺服器重新導向跟隨](https://docs.byteplus.com/en/docs/byteplus-cdn/redirect-follow_zh-tw)。

* 不在來源伺服器做任何變更，而是在 CDN 設定 "URL 重新導向改寫"。如果使用者請求了原 URL，CDN 會回應您指定的 3xx 狀態碼。，指示使用者瀏覽器向新的 URL 發送請求。

* 不在來源伺服器做任何變更，而是在 CDN 設定 [來源伺服器路徑改寫](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-origin-path-rewrite_1-cn-tw)。如果使用者請求了原 URL，CDN 在來源伺服器請求中會使用新的 URL。


本文件介紹的是第二種解決方案。

<span id="請求流程"></span>
## 請求流程

在設定了某檔案的 URL 重新導向改寫後，使用者請求的流程如下：


1. 使用者使用瀏覽器向該檔案發起存取請求。

2. CDN 返回您指定的 3xx 狀態碼以及檔案的新 URL。

3. 使用者瀏覽器向新 URL 發起存取請求。


<span id="操作步驟"></span>
## 操作步驟


1. 打開 **URL 重新導向改寫** 設定頁面。操作步驟參見 [網域名稱設定](https://docs.byteplus.com/en/docs/byteplus-cdn/domain-management_zh-tw)。

2. 在 **URL 重新導向改寫** 下方，點擊 **新增規則**。

   您最多可以新增 50 條規則。

3. 參照以下設定說明。

4. 設定完成後，點擊 **儲存**。


<span id="設定說明"></span>
### 設定說明


|**設定** |**說明** |
|---|---|
|優先順序 |表示規則的優先順序。數字 1 的規則優先順序最高。在收到請求時，CDN 按規則的優先順序，從高到低嘗試將請求與規則匹配。如果請求匹配了某一條規則，CDN 就停止匹配其餘規則。您可以透過拖曳調整規則的優先順序。 |
|待重寫路徑 |表示需要被重寫的路徑，長度不能超過 1,024 個字元。路徑必須以斜線（/）開頭，並且不能包含連續斜線（//）、百分號（%）、空格。 |
|重新導向方式 |選擇重新導向的回應狀態碼。您可以根據業務需要選擇合適的狀態碼。該配置的可選項有 **301**、**302**、**303**、**307**、**308**。<br><br>&nbsp;<br><br>需要留意的是：<br><br><br>* 對於 301 和 302，如果原請求使用的方法不是GET，那麼客戶端向新的URL發送請求時，新請求使用的方法可能變成 GET。<br><br>* 對於 303，新請求使用的方法是 GET。<br><br>* 對於 307 和 308，新請求使用的方法與原請求相同，不會被改變。 |
|目標請求協定 |選擇重新導向後的請求所使用的協定。該設定有以下選項：<br><br><br>* **協定跟隨**：表示重新導向後的請求使用原請求的協定。<br><br>* **HTTP**：表示重新導向後的請求強制使用 HTTP 協定。<br><br>* **HTTPS**：表示重新導向後的請求強制使用 HTTPS 協定。 |
|目標 Host |輸入目標路徑所歸屬的網域名稱或者 IP 位址。IP 位址只能是 IPv4 類型的位址。如果輸入的是網域名稱，網域名稱的長度不能超過 1,024 個字元。需要注意的是，如果輸入的網域名稱不是網域名稱，使用者對重新導向後的 URL 的請求將無法被加速。 |
|目標路徑 |輸入重新導向後的目標路徑，長度不能超過 1,024 個字元。路徑必須以斜線（/）開頭，並且不能包含連續斜線（//）、百分號（%）、空格。 |
|目標參數 |選擇原請求 URL 中查詢參數的處理方式。該設定有以下選項：<br><br><br>* **保留全部參數**：表示新 URL 中包含原請求 URL 中所有的查詢參數。<br><br>* **刪除全部參數**：表示新 URL 中不包含原請求 URL 中的任何查詢參數。<br><br>* **保留指定參數**：表示新 URL 僅包含原請求 URL 中指定的查詢參數。<br><br>* **刪除指定參數**：表示新 URL 中不包含原請求 URL 中指定的查詢參數。 |
|指定部分參數 |指定要保留或刪除的查詢參數，長度不能超過 1,024 個字元。多個查詢參數間使用英文分號（;）分隔。<br><br><br>* 如果 **目標參數** 是 **保留全部** 或者 **刪除全部**, 該設定的值必須為 `*`。<br><br>* 如果 **目標參數** 是 **保留部分** 或者 **刪除部分**，您可以指定一個或者多個查詢參數。查詢參數不能包含連續斜線（//）、百分號（%）、雙引號（"）、空格。同時，查詢參數不能是 `*`。<br><br><br>該設定的預設值是 `*`。 |
