近期，我們監測到部分使用者的 CDN 網域遭遇惡意流量盜刷。此類攻擊主要鎖定影片、安裝包等大型檔案。發動攻擊的 IP 位址會高頻率請求此類檔案，使 CDN 流量激增。這不僅會產生超出預期的高額帳單，甚至可能因帳號欠費引發服務中斷。對於此類事件造成的高額帳單，我們無法予以免除或退款，對此我們深表歉意。為協助您降低相關風險，您可依照本文件指導採取對應的預防措施。

<span id="主要風險"></span>
## 主要風險

**高額帳單**

CDN 根據快取節點向使用者傳輸的資料量或消耗的頻寬計費。一旦您的網域遭遇惡意攻擊或盜刷，您的網域透過 CDN 傳輸的資料量會急遽增加，進而產生額外的頻寬消耗。由此產生的流量或頻寬費用需由您自行承擔。

**服務暫停**

若惡意攻擊或盜刷導致帳單金額遠超預期，您的帳號可能會出現欠費情況，進而導致服務暫停。

<span id="防範措施"></span>
## 防範措施

為降低網域被攻擊或盜刷的風險，我們建議您採取以下防範措施：

<span id="監控用量"></span>
### 監控用量

您可透過 BytePlus 雲端監控對 CDN 用量進行即時監控，以便及時發現異常流量和頻寬。同時，在費用中心設定帳單監控，可有效降低攻擊或盜刷時的損失。若您已購買了資源包，還可設定餘量提醒。


|**預警能力** |**說明** |
|---|---|
|[雲端監控](https://console.byteplus.com/cloud-monitor) |對流量和頻寬進行監控並設定用量警示。 |
|[費用預警](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-2) |在 [帳戶總覽](https://console.byteplus.com/finance/overview) 頁面中，您可以設定帳單金額預警，協助您及時察覺帳單金額異常。<br><br><br>* 帳單金額預警：您設定一個金額閾值。若當日後付費帳單累計應付金額超過該閾值，您會收到通知。 |
|資源包餘量預警 |如果您購買了資源包，可在 [資源執行個體管理](https://console.byteplus.com/finance/resource-package) 頁面右上方點擊 **餘量預警**，然後設定資源包餘量預警，以便及時知曉資源包用量異常。 |


<span id="流量分析"></span>
### 流量分析

啟用 [即時日誌投遞概述](https://docs.byteplus.com/en/docs/byteplus-cdn/log-streaming-overview_zh-tw) 並 [日誌檢索範例](https://docs.byteplus.com/en/docs/byteplus-cdn/log-query-examples_zh-tw)。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">即時日誌傳遞會產生額外費用。具體可參見 <a href="https://docs.byteplus.com/en/docs/byteplus-cdn/docs-pricing_zh-tw#%E8%A8%88%E8%B2%BB%E8%A9%B3%E6%83%85%EF%BC%88%E6%8C%89%E9%87%8F%E8%A8%88%E8%B2%BB%E5%BE%8C%E4%BB%98%E8%B2%BB%EF%BC%89">（購買頁無繁中鏈接）收費說明</a>。</div>


當察覺到異常的流量和頻寬時，您可以透過日誌檢索分析原因，鎖定惡意攻擊或盜刷事件的特徵。例如惡意請求的來源國家或地區、發生時間段、發動攻擊的 IP 位址範圍等。

<span id="開啟存取控制"></span>
### 開啟存取控制

根據已確定的惡意請求特徵，您可以設定存取控制下的特性攔截此類請求。這些特性無需額外費用，但能有效降低風險。


|**特性** |**說明** |
|---|---|
|[Referer 防盜連結](https://docs.byteplus.com/en/docs/byteplus-cdn/referer-restrictions_zh-tw) |根據 Referer 標頭對請求過濾，僅允許來自特定頁面的使用者請求。 |
|[Origin 存取限制](https://docs.byteplus.com/en/docs/byteplus-cdn/origin-restriction_zh-tw) |根據 Origin 標頭對請求過濾，僅允許來自特定網域的使用者請求。 |
|[UA存取限制](https://docs.byteplus.com/en/docs/byteplus-cdn/ua-restriction_zh-tw) |根據 User\-Agent 標頭對請求過濾，僅允許包含特定 User\-Agent 標頭的使用者請求。 |
|[IP存取限制](https://docs.byteplus.com/en/docs/byteplus-cdn/ip-restriction_zh-tw) |根據 IP 位址對請求過濾，僅允許來自特定 IP 位址的使用者請求。 |
|[URL 驗證概覽](https://docs.byteplus.com/en/docs/byteplus-cdn/signed-url-authentication-overview_zh-tw) |在用戶端發起請求時，對請求 URL 新增簽章。CDN 收到請求後對請求鑑權，僅允許通過鑑權的使用者請求。 |
|[遠端驗證](https://docs.byteplus.com/en/docs/byteplus-cdn/remote-authentication_zh-tw) |若您有專用的鑑權伺服器對使用者請求進行鑑權，您可以在 CDN 中設定遠端鑑權。 |
|[地理位置存取限制](https://docs.byteplus.com/en/docs/byteplus-cdn/geo-access-control_zh-tw) |根據 IP 位址歸屬地對請求過濾，僅允許來自特定地域的使用者請求。 |
|[禁用的 HTTP 方法](https://docs.byteplus.com/en/docs/byteplus-cdn/disallowed-http-method_zh-tw) |在 CDN 設定禁止的請求方法。如果 CDN 收到使用被禁止請求方法的使用者請求，會拒絕請求並回應 405 狀態碼。 |
|[下載限速](https://docs.byteplus.com/en/docs/byteplus-cdn/data-rate-throttling_zh-tw) |對請求設定資料傳輸速度的上限。您還可以指定該特性的啟用時間段。 |
|[自訂攔截規則](https://docs.byteplus.com/en/docs/byteplus-cdn/custom-restrictions-zh-tw) |根據請求路徑、查詢參數和用戶端 IP 位址對請求過濾，僅允許符合條件的使用者請求。 |
