<span id="計費概述"></span>
# 計費概述

BytePlus CDN 根據從 CDN 向外傳輸數據和 CDN 接收的請求數收費。傳輸的數據也稱為流量。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">對於大流量或者企業客戶，我們提供了定制化報價。請 <a href="https://console.byteplus.com/workorder/create">提交工單</a> 了解定制化報價詳情。</div>


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e5c5d8d0ab834c07b21a0ea6050d4c94~tplv-goo7wpa0wc-image.image) </span>

<span id="計費項目"></span>
## 計費項目

CDN 有以下計費項目：


* CDN 收到的請求數，也就是用戶使用用戶端（例如瀏覽器）訪問您的站點文件時發送的 HTTP 和 HTTPS 請求。

* CDN 向用戶端傳輸的數據。

* CDN 向来源伺服器傳輸的數據。

* 日誌投遞數（離線日誌轉存）

* 日誌投遞數（即時日誌投遞）


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">當前，CDN 不對 Websocket 請求數計費。但是在 Websocket 建連的握手階段，CDN 收到的那個 HTTP 請求還是會作為 HTTP 請求數計費。</div>


<span id="計費方式"></span>
## 計費方式

CDN 使用的計費方式是按量計費後付費，即先用後付。在開通了 CDN 服務後，您無需支付任何事前費用就可以開始使用。

同時，我們提供了預付費資源包。資源包可以用來抵扣傳輸的數據和 CDN 收到的請求數量，以幫助您降低費用支出。

<span id="計費週期"></span>
## 計費週期

默認情況下，CDN 是按小時計費的。

<span id="欠費說明"></span>
## 欠費說明

如前所述，CDN 採用按量計費後付費、按小時結算的方式，帳單會在每個計費週期結束後按小時推送。如您有按月結算的需求，請聯絡我們的銷售或售前支援團隊。


* 當出現以下情形時，可能導致當期帳單無法正常扣款，進而產生欠費：

* 在帳單推送前取消了已綁定的付款方式（例如信用卡）。


帳戶可用餘額不足，不足以支付當期帳單。

對於完成個人認證的帳號，一旦發生欠費，CDN 將即時關停並下線相關服務，且不再另行發送通知。發生欠費後，請您及時結清欠費款項，款項結清後服務將自動恢復上線。為避免再次因欠費而被關停、保障業務的連續性，請您確保帳號綁定的付款方式持續有效，或帳戶餘額充足，使後續帳單能夠正常扣款。

<span id="計費示例"></span>
## 計費示例

在 `2023-09-01 00:00:00` 至 `2023-09-01 01:00:00` 內，中國大陸計費區內傳輸的數據為 `9,960 GB`，歐洲計費區內為 `3,960 GB`。因此，這兩個計費區內當月累積傳輸的數據均處於 `0~10TB` 這個階梯。該時間段內的帳單費用按以下方式計算：

> 9960 \* 0.035 + 3960 \* 0.044 = 522.84，單位是 USD。


然後，在 `2023-09-01 01:00:00` 至 `2021-09-01 02:00:00` 內，中國大陸計費區內傳輸的數據為 `100 GB`，歐洲計費區內為 `1,000 GB`。因此：


* 中國大陸計費區內當月累積傳輸的數據處於 `10~40TB` 這個階梯。在當前時間段所傳輸的 100 GB 數據中，前 40 GB 處於 `0~10TB` 這個階梯，後 60 GB 處於 `10~40TB` 這個階梯。

* 歐洲計費區內當月累積傳輸的數據仍然處於 `0~10TB` 這個階梯。


該時間段內的帳單費用按以下方式計算：

> 40 \* 0.035 + 60 \* 0.033 + 1000 \* 0.044 = 47.38，單位是 USD。


<span id="流量與請求數資源包（預付費）"></span>
# 流量與請求數資源包（預付費）

CDN 為流量和請求數提供了資源包。如果您可以預估每個月 CDN 傳輸的數據或收到的請求數，我們建議您購買資源包以節省開支。資源包的有效期是 30 天。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">對於流量資源包，1 GB = 1,000 MB。</div>


<span id="資源包是如何工作的"></span>
## 資源包是如何工作的


* 結算時，CDN 會優先使用您帳號下的可用資源包。如果您有多個處於可用狀態的資源包，CDN 會優先使用先到期的資源包。

* 如果資源包中的流量或請求數不足以抵扣已傳輸的流量或 CDN 收到的請求數，超出的流量和請求數會按按量計費的價格進行結算。

* 如果出現了以下任意情況，資源包將失效：

   * 資源包已過期。

   * 資源包的額度已被用盡。


已過期的資源包中的流量或請求數無法轉入其他資源包，也無法退款。
