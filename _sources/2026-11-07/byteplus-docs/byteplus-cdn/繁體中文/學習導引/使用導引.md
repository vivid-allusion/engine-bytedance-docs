## 首次使用 CDN（必讀）

如果您首次使用 CDN，您需要先建立並發布一個分發策略，然後新增您的網域名稱。

我們準備了 CDN 快速入門，指導您將網域名稱與 CDN 對接。您可以點擊步驟中的連結查看快速入門中的相關操作。

步驟

1.

   [建立分發策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-set-up-distribution-policy-and-origin_zh-tw)。

2.

   [發布分發策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-set-up-distribution-policy-and-origin_zh-tw)。

3.

   [新增網域名稱並綁定分發策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-add-your-domain-name_zh-tw)。

4.

   [測試對 CNAME 的存取](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-test-domain-name-with-hosts-zh-tw)。

5.

   [設定 CNAME 記錄](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-set-up-cname_zh-tw)。

> **说明**

*

   > 在建立分發策略時，您需要指定您的網站作為來源伺服器。

*

   > 您在 CDN 中新增的網域名稱不能與您指定的來源伺服器相同。因為在第 5 步中，您需要將您 CDN 中新增的網域名稱解析到 CDN 為您網域名稱分配的 CNAME。如果來源伺服器也是該網域名稱，CDN 向來源伺服器發送的請求會被 CDN 自己收到，造成請求死循環。因此，如果您的來源伺服器的確就是您要在 CDN 中新增的網域名稱，您可以將您網域名稱的 IP 位址指定為來源伺服器。

*

   > 第 5 步操作是在您的網域名稱解析服務商處操作的。

## 啟用 HTTPS 加密服務（推薦）

在您為網域名稱啟用 HTTPS 加密服務後，使用者就能使用 HTTPS 協定存取您的網域名稱，以加密使用者與 CDN 之間的通訊。

要啟用 HTTPS，您需要先將一個簽發給您網域名稱的憑證上傳到 CDN。您在 CDN 中上傳的憑證是在 BytePlus 憑證中心託管的。由於 CDN 和 BytePlus 憑證中心是不同的 BytePlus 服務，在上傳憑證前，您需要授權 CDN 存取憑證中心。

步驟

1.

   [授權 CDN 存取憑證中心](https://docs.byteplus.com/en/docs/byteplus-cdn/allow-cdn-access-to-byteplus-service_zh-tw)。

2.

   [上傳憑證](https://docs.byteplus.com/en/docs/byteplus-cdn/upload-certificate_zh-tw)。

3.

   [為網域名稱啟用 HTTPS 加密服務](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-add-domain-name_1_zh-tw)。

4.

   [關聯憑證與網域名稱](https://docs.byteplus.com/en/docs/byteplus-cdn/associate-certificate-with-domain-name_zh-tw)。

> **说明**

> 只有啟用了 HTTPS 加密服務，網域名稱才能與加密策略綁定，使您為網域名稱設定 [HTTPS 相關的 CDN 功能](https://docs.byteplus.com/en/docs/18/36099#https-%E7%9B%B8%E9%97%9C%E7%9A%84-cdn-%E5%8A%9F%E8%83%BD)。

## 修改 CDN 功能設定（推薦）

策略承載了 CDN 中各功能的設定。通過將一個策略與您的網域名稱綁定，您設定的 CDN 功能就會在網域名稱上生效，成為網域名稱的設定。

在 CDN 中，策略有以下兩類：

*

   分發策略：用於設定 [常規的 CDN 功能](https://docs.byteplus.com/en/docs/18/36099#%E5%B8%B8%E8%A6%8F-cdn-%E5%8A%9F%E8%83%BD)。

*

   加密策略：用於設定 [HTTPS 相關的 CDN 功能](https://docs.byteplus.com/en/docs/18/36099#https-%E7%9B%B8%E9%97%9C%E7%9A%84-cdn-%E5%8A%9F%E8%83%BD)。

> **说明**

*

   > 只有已發布的策略才能與網域名稱綁定。

*

   > 如果一個策略已發布，您無法修改策略的設定。

*

   > 要與加密策略綁定，網域名稱必須已啟用了 HTTPS 加密服務。

步驟

由於發布後的策略無法更改，您可以通過複製已綁定的策略來建立一個策略。在新策略中，您可以更改 CDN 功能的設定。發布該新策略後，您將新策略與網域名稱綁定。

1.

   [複製網域名稱綁定的策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-policy_zh-tw#%E8%A4%87%E8%A3%BD%E7%AD%96%E7%95%A5)。

   > **说明**

   *

   > 要修改常規的 CDN 功能，您需要複製已綁定的分發策略。

   *

   > 要修改 HTTPS 相關的 CDN 功能，您需要複製已綁定的加密策略。

   *

   > 如果您要為網域名稱設定 HTTPS 相關的 CDN 功能，但是網域名稱還未綁定加密策略，步驟 1 就不是複製策略，而是建立一個加密策略。

2.

   在新策略中新增或刪除需要設定的 CDN 功能。參見 [功能列表](https://docs.byteplus.com/en/docs/18/36099#%E5%AE%8C%E6%95%B4-cdn-%E5%8A%9F%E8%83%BD%E5%88%97%E8%A1%A8)。

3.

   在新策略中設定 CDN 功能。在 [功能列表](https://docs.byteplus.com/en/docs/18/36099#%E5%AE%8C%E6%95%B4-cdn-%E5%8A%9F%E8%83%BD%E5%88%97%E8%A1%A8) 中點擊功能的連結，了解功能的設定方法。

4.

   [發布策略](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-policy_zh-tw#%E6%AD%A5%E9%A9%9F-3%EF%BC%9A%E7%99%BC%E4%BD%88%E7%AD%96%E7%95%A5)。

5.

   [綁定新策略與網域名稱](https://docs.byteplus.com/en/docs/byteplus-cdn/docs-policy_zh-tw#%E6%AD%A5%E9%A9%9F-4%EF%BC%9A%E7%B6%81%E5%AE%9A%E7%B6%B2%E5%9F%9F%E5%90%8D%E7%A8%B1)。

## 使用邊緣函數（可選）

透過邊緣函數，您可以創建和發布函數來對滿足特定條件的請求進行處理。邊緣函數支援的語言是 JavaScript。

在收到使用者請求時：

* 如果請求滿足您指定的條件，CDN 會將請求交給函數來處理。處理方式可以是對請求回應特定的內容，也可以是將請求轉發到其他服務。

* 如果請求未滿足您指定的條件，CDN 將處理該請求。

步驟

1.

   [授權 CDN 訪問必要的 BytePlus 服務](https://docs.byteplus.com/en/docs/byteplus-cdn/allow-cdn-access-to-byteplus-service_zh-tw)。

2.

   [為網域名稱啟用邊緣函數](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn-zh-tw)。

3.

   [管理函數](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-create-function-cn-zh-tw)。

4.

   [發佈函數](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-create-function-cn-zh-tw)。

5.

   [網域名稱觸發器](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-domain-triggers-cn-zh-tw)。

6.

   [建立轉發規則](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-Configure-Edge-Function-Forwarding-Rules-cn-zh-tw)。

邊緣函數還提供了邊緣 KV。您可以事先在邊緣 KV 中建立鍵值對，然後在函數程式碼中呼叫執行時 API 透過鍵讀取值。鍵值對的值被更新後，在函數程式碼中被讀取的值也會是被更新後的值。您無需重新發布函數。

建立鍵值對的步驟如下：

1.

   [管理儲存空間](https://docs.byteplus.com/en/docs/byteplus-cdn/doc-manage-namespace-cn-zh-tw)。

2.

   [管理資料](https://docs.byteplus.com/en/docs/byteplus-cdn/docs_cn-manage-data-cn-zh-tw)。

## 使用工具（可選）

CDN 提供了以下工具：

*

   清除快取與預取快取

   *

      [清除快取](https://docs.byteplus.com/en/docs/byteplus-cdn/purge-cache_zh-tw)：CDN 將您指定的檔案刪除或者標記為已過期，確保使用者獲取來源伺服器上最新版本的檔案。

   *

      [預取快取](https://docs.byteplus.com/en/docs/byteplus-cdn/file-prefetch_zh-tw)：CDN 將您指定的檔案事先載入到邊緣快取節點，使得這些檔案的首次存取也能受益於資料傳輸加速。

*

   診斷工具：

   *

      [IP 檢測](https://docs.byteplus.com/en/docs/byteplus-cdn/diagnostic-tools_zh-tw#ip-%E6%AA%A2%E6%B8%AC)：檢查一個或者多個 IP 位址是否是 CDN 邊緣節點的 IP 位址。

   *

      [網域名稱對比](https://docs.byteplus.com/en/docs/byteplus-cdn/diagnostic-tools_zh-tw#%E7%B6%B2%E5%9F%9F%E5%90%8D%E7%A8%B1%E5%B0%8D%E6%AF%94)：比較兩個網域名稱設定的差異。對比的設定涵蓋：

      *

         與網域名稱綁定的策略中 CDN 功能的設定。

      *

         網域名稱的基礎屬性，包含網域名稱的建立時間、CNAME、是否開啟了 HTTPS 加密服務等。

   *

      [策略對比](https://docs.byteplus.com/en/docs/byteplus-cdn/diagnostic-tools_zh-tw#%E7%AD%96%E7%95%A5%E5%B0%8D%E6%AF%94)：比較兩個策略中 CDN 功能的設定差異。

## 查看 CDN 指標（推薦）

CDN 提供了以下頁面展示指標資料，使您可以監控 CDN 的使用狀況。

*

   [邊緣監控](https://docs.byteplus.com/en/docs/byteplus-cdn/edge-report_zh-tw)：基於使用者請求，該頁面展示了以下指標的彙總資料和資料趨勢：

   * 頻寬、流量、請求數、QPS、狀態碼、回應時間、平均速度

*

   [來源伺服器監控](https://docs.byteplus.com/en/docs/byteplus-cdn/origin-server-report_zh-tw)：基於来源伺服器請求，該頁面展示了以下指標的彙總資料和資料趨勢：

   * 頻寬、流量、請求數、QPS、狀態碼、回應時間

*

   [命中率](https://docs.byteplus.com/en/docs/byteplus-cdn/traffic-hit-ratio_zh-tw)：基於使用者請求，該頁面展示了流量命中率的指標資料。

*

   [熱門物件排行](https://docs.byteplus.com/en/docs/byteplus-cdn/popular-objects_zh-tw)：基於使用者請求，該頁面展示了以下熱門物件以及這些物件的指標資料：

   * 熱門請求 URL、熱門 Referer 網域名稱、熱門的存取裝置、熱門作業系統、熱門瀏覽器、高頻存取您網域名稱的客戶端 IP 位址、熱門地區

*

   [業務分析](https://docs.byteplus.com/en/docs/byteplus-cdn/insight_zh-tw)：

   *

      該頁面展示各指標按國家和地區劃分的彙總資料、獨立訪客的 IP 位址的數量趨勢、基於各指標彙總資料的網域名稱排行。

   *

      基於来源伺服器請求，該頁面展示了各指標彙總資料的網域名稱排行。

## 完整 CDN 功能列表

在處理使用者請求時，如果請求檔案未被快取或者已在快取中過期，CDN 會經歷以下幾個階段：

* 收到使用者請求 \> 向來源伺服器請求檔案 \> 收到來源伺服器回應 \> 快取請求檔案 \> 回應使用者請求

![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_fb07446b0459838ffcd5d456df17a12a.png)

> **说明**

> 如果請求檔案在快取中未過期，CDN 經歷的階段是：

* > 收到使用者請求 \> 回應使用者請求

每個 CDN 功能對應一個請求處理階段。功能的設定影響 CDN 在特定階段對使用者請求的處理方式。

### HTTPS 相關的 CDN 功能

以下功能在加密策略中設定。

|**階段** |**分類** |**CDN 功能** |**功能說明** |
|---|---|---|---|
|收到使用者請求 |協定管理 |[HTTP/2](https://docs.byteplus.com/en/docs/byteplus-cdn/HTTP2_zh-tw) |設定 CDN 以支援 HTTP/2。 |
|||[QUIC](https://docs.byteplus.com/en/docs/byteplus-cdn/QUIC_zh-tw) |設定 CDN 以支援 QUIC 協定。在您啟用 QUIC 後，CDN 也支援了 HTTP/3。 |
|||[協定重新導向](https://docs.byteplus.com/en/docs/byteplus-cdn/protocol-redirect_zh-tw) |設定 CDN 將使用者的 HTTP 請求重新導向到 HTTPS 請求，或者將 HTTPS 請求重新導向到 HTTP 請求。 |
||加密最佳化 |[OCSP 裝訂](https://docs.byteplus.com/en/docs/byteplus-cdn/ocsp-staping_zh-tw) |設定 CDN 在 TLS 握手階段向客戶端發送伺服器憑證時，將該憑證的 OCSP 回應一併發送，從而縮短 TLS 握手耗時。 |
|||[HSTS](https://docs.byteplus.com/en/docs/byteplus-cdn/HSTS_zh-tw) |設定 CDN 通過在回應中包含 `Strict-Transport-Security` 標頭來指示客戶端瀏覽器始終向 CDN 發送 HTTPS 請求。 |
|||[TLS 版本控制](https://docs.byteplus.com/en/docs/byteplus-cdn/tls-version_zh-tw) |設定 CDN 支援的 TLS 版本。如果一個請求使用的 TLS 版本不被支援，CDN 將拒絕該請求。 |
