根據您指定的 `StartTime`、`EndTime` 和 `Interval`，CDN 收集一系列資料點。`Interval` 表示 CDN 收集這些資料點的時間間隔。例如，對於 `Interval` 是 `5min`，CDN 每 5 分鐘收集 1 個資料點。

下表中的範例展示了 CDN 根據不同的 `Interval` 而收集的資料點數量以及每個資料點所對應的時間區間。


|**StartTime** |**EndTime** |**Interval** |**CDN 收集的資料點數量** |**收集的資料點所分別對應的時間區間** |**實際統計時間區間** |
|---|---|---|---|---|---|
|15:07 |15:21 |5 分鐘 |4 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25) |[15:05,15:25) |
|15:07 |15:25 |5 分鐘 |5 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25)、[15:25,15:30) |[15:05,15:30) |
|15:05 |15:25 |5 分鐘 |5 |[15:05,15:10)、[15:10,15:15)，[15:15,15:20)，[15:20,15:25)、[15:25,15:30) |[15:05,15:30) |
|15:07 |18:21 |1 小時 |4 |[15:00,16:00)、[16:00,17:00)、[17:00,18:00)、[18:00,19:00) |[15:00,19:00) |
|15:07 |19:00 |1 小時 |5 |[15:00,16:00)、[16:00,17:00)、[17:00,18:00)、[18:00,19:00)、[19:00,20:00) |[15:00,20:00) |


由此可見，CDN 收集的資料點所對應的**實際統計時間區間**可能與您指定的統計時間區間有差異。

<span id="細分資料"></span>
#### 細分資料

CDN 根據 `Interval` 收集的資料點就是指定指標的細分資料。細分資料體現了指標資料的趨勢。

<span id="彙總資料"></span>
#### 彙總資料

CDN 根據細分資料統計指標的彙總資料。不同指標的彙總方式不同，請參閱[指標的定義以及統計方式](https://docs.byteplus.com/en/docs/byteplus-cdn/statistics-interval_zh-tw)。

範例：您指定的 `StartTime` 表示 15:07，`EndTime` 表示 15:20，`Interval` 是 `5min`，指定的 `Metric` 是 `traffic`。在這個情況下，CDN 按以下步驟統計流量的彙總資料：


1. 統計以下各時間區間的流量資料：[15:05,15:10)、[15:10,15:15)、[15:15,15:20)、[15:20,15:25)。實際統計時間區間是 [15:05,15:25)。

2. 對這些流量資料進行加總，作為指定統計時間區間內流量指標的彙總資料。
