建立一個規則引擎策略。

<span id="使用限制"></span>
## 使用限制

請求頻率限制：您每秒最多可以提交 20 個 API 請求。

<span id="請求說明"></span>
## 請求說明


* 請求方法：POST

* 請求URL：https://cdn.byteplusapi.com/?Action=CreateRuleEngineTemplate&Version=2021\-03\-01


<span id="請求參數"></span>
## 請求參數

<span id="query"></span>
### Query


|參數 |類型 |必要 |說明 |
|---|---|---|---|
|Action |String |是 |介面名稱。當前 API 的名稱為 `CreateRuleEngineTemplate`。 |
|Version |String |是 |介面版本。當前 API 的版本為 `2021-03-01`。 |


<span id="body"></span>
### Body


|參數 |類型 |必要 |說明 |範例 |
|---|---|---|---|---|
|Title |String |是 |表示您要建立的規則引擎策略的名稱，長度不能超過 100 個字元。 |`my_title` |
|Message |String |否 |表示該分發策略的描述，長度不能超過 120 個字元。 |`my_desc` |
|Project |String |否 |表示該策略所歸屬的專案。該參數的預設值是 'default'，表示 Default 專案。 |`default` |
|Rule |String |否 |關於該參數的配置，參見 [UpdateRuleEngineTemplate](https://docs.byteplus.com/en/docs/byteplus-cdn/UpdateRuleEngineTemplate_zh-tw)。 | |


<span id="回應"></span>
## 回應


|參數 |類型 |說明 |範例 |
|---|---|---|---|
|TemplateId |String |表示建立的規則引擎策略的 ID。 |`tpl-rejjo23` |
