BytePlus SDK 讓您能以程式設計方式與 BytePlus CDN 進行互動。在互動過程中您無需處理複雜的簽章計算。BytePlus SDK 為 PHP、Go、Python 和 Java 提供了相對應的程式庫。BytePlus SDK 也提供了範例程式碼方便您上手。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">目前，邊緣函數的 SDK 暫未提供。關於 WAF SDK，請參閱 <a href="https://docs.byteplus.com/en/docs/waf/web-application-firewall-release-notes">WAF 文档</a> 取得最新動態。</div>
