本文件說明如何呼叫 BytePlus CDN 的 API。

在發送 API 請求前，您需要理解以下內容：


* [請求結構](https://docs.byteplus.com/en/docs/18/46499#%E8%AB%8B%E6%B1%82%E7%B5%90%E6%A7%8B)。

* [公共參數](https://docs.byteplus.com/en/docs/18/46499#%E5%85%AC%E5%85%B1%E5%8F%83%E6%95%B8)。

* [請求驗證](https://docs.byteplus.com/en/docs/18/46499#%E8%AB%8B%E6%B1%82%E9%A9%97%E8%AD%89)。

* [簽章計算方式](https://docs.byteplus.com/en/docs/18/46499#%E7%B0%BD%E7%AB%A0%E8%A8%88%E7%AE%97%E6%96%B9%E5%BC%8F)。


<span id="請求結構"></span>
### 請求結構

API 請求的結構包含以下內容：


* API 服務位址。

* 通訊協定。

* 請求方法。

* 請求參數。


<span id="api-服務位址"></span>
#### API 服務位址

CDN API 服務位址是 `cdn.byteplusapi.com`。

<span id="通訊協定"></span>
#### 通訊協定

您可以使用 `HTTP` 協定或 `HTTPS` 協定發送請求。推薦您使用 `HTTPS` 協定，其安全性更高。

<span id="請求方法"></span>
#### 請求方法

如無特殊說明，您使用 `POST` 方法發送請求。同時，您必須在請求標頭中指定 `Content-Type: application/json`。

<span id="請求參數"></span>
#### 請求參數

請求參數包括公共參數和每個 API 所特有的參數。

<span id="公共參數"></span>
### 公共參數

公共參數是每個 API 請求必須包含的參數。如果一個 API 請求缺失公共參數，請求會失敗。以下表格中的公共參數必須包含在查詢字串（query string）中。


|參數名稱 |資料類型 |是否必選 |參數說明 |範例 |
|---|---|---|---|---|
|Action |string |是 |表示 API 名稱。名稱的正則表達式格式為 [a\-zA\-Z]+。 |`DescribeCdnData` |
|Version |string |是 |表示 API 版本。該參數的取值是 `2021-03-01`。 |`2021-03-01` |
|X\-Expires |int |否 |表示驗證資訊中包含的簽章的有效時間，單位是秒。該參數的預設值是 `900`。 |`900` |


<span id="請求驗證"></span>
### 請求驗證

每個請求中必須包含驗證資訊。該驗證資訊用以驗證請求者的身份。您可以使用以下任一方法提供驗證資訊。推薦您使用方法一。

<span id="（推薦）方法一：在請求標頭中包含驗證資訊"></span>
#### （推薦）方法一：在請求標頭中包含驗證資訊

您需要在請求標頭中包含以下參數：


|**參數名稱** |**資料類型** |**是否必選** |**參數說明** |**範例** |
|---|---|---|---|---|
|X\-Date |string |是 |表示簽章計算的時間，以 UTC 表示。時間精度是秒。<br><br>&nbsp;<br><br>關於該參數，您需要留意以下內容：在請求到達時，CDN 會計算請求到達時間與 X\-Date 之間的差距。如果差距超過 X\-Expires 指定的時間範圍，CDN 判定該請求無效。因此，在計算簽章前，建議您校準系統時間。 |`20210913T081805Z` |
|Authorization |string |是 |該參數表示驗證字串。該參數的虛擬碼如下：<br><br>`HMAC-SHA256 Credential = {AccessKey}/{ShortDate}/{Region}/{Service}/{Request}, SignedHeaders={SignedHeaders}, Signature={Signature}`<br><br>&nbsp;<br><br>該虛擬碼的說明如下：<br><br><br>* 虛擬碼中的 `Signature` 參數表示一個經過計算得到的簽章。關於簽章的計算方式，參見 [簽章計算方式](https://docs.byteplus.com/en/docs/18/46499#%E7%B0%BD%E7%AB%A0%E8%A8%88%E7%AE%97%E6%96%B9%E5%BC%8F)。<br><br>* 關於虛擬碼中其他參數的說明，參見 [虛擬碼中參數的說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E4%B8%AD%E5%8F%83%E6%95%B8%E7%9A%84%E8%AA%AA%E6%98%8E)。 | |


<span id="方法二：在查詢字串中包含驗證資訊"></span>
#### 方法二：在查詢字串中包含驗證資訊

您需要在查詢字串中包含以下查詢參數。


|**參數名稱** |**資料類型** |**參數說明** |**範例** |
|---|---|---|---|
|X\-Date |string |表示簽章計算的時間，以 UTC 表示。時間精度是秒。 關於該參數，您需要留意以下內容：<br><br><br>* 在請求到達時，CDN 會計算請求到達時間與 `X-Date` 之間的差距。如果差距超過 `X-Expires` 指定的時間範圍，CDN 判定該請求無效。因此，在計算簽章前，建議您校準系統時間。 |`20210913T081805Z` |
|X\-Algorithm |string |表示簽章計算所使用的演算法。該參數的值是 `HMAC-SHA256`。 |`HMAC-SHA256` |
|X\-Credential |string |該參數值的虛擬碼如下：<br><br>`{AccessKey}/{ShortDate}/{Region}/{Service}/{Request}`<br><br>&nbsp;<br><br>關於 `X-Credential`虛擬碼中參數的說明，參見 [虛擬碼中參數的說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E4%B8%AD%E5%8F%83%E6%95%B8%E7%9A%84%E8%AA%AA%E6%98%8E)。 |`AKLTMjI2ODVlYzI3ZGY1NGU4ZjhjYWRjMTlmNTM5OTZkYzE/20210913/singapore/CDN/request` |
|X\-SignedHeaders |string |該參數的說明與 [虛擬碼參數說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E5%8F%83%E6%95%B8%E8%AA%AA%E6%98%8E) 中的 `SignedHeaders` 參數是相同的。 |`host;x-content-sha256;x-date` |
|X\-Signature |string |表示一個經過計算得到的簽章。關於簽章的計算方式，參見 [簽章計算方式](https://docs.byteplus.com/en/docs/18/46499#%E7%B0%BD%E7%AB%A0%E8%A8%88%E7%AE%97%E6%96%B9%E5%BC%8F)。 | |


<span id="簽章計算方式"></span>
### 簽章計算方式

本章節主要說明簽章是如何計算的。文件最後提供了 [簽章計算的範例程式碼](https://docs.byteplus.com/en/docs/18/46499#%E7%B0%BD%E7%AB%A0%E8%A8%88%E7%AE%97%E7%9A%84%E7%AF%84%E4%BE%8B%E7%A8%8B%E5%BC%8F%E7%A2%BC)。


* 簽章計算是一個複雜的過程。推薦您使用 [BytePlus SDK](https://docs.byteplus.com/en/docs/byteplus-cdn/cdn-sdk_zh-tw) 與 CDN 進行互動，無需計算簽章。

* 本章節的虛擬碼中的 `HMAC` 方法使用的是 HMAC\-SHA256 演算法。

* 本章節的虛擬碼中的 `HexEncode` 方法將字串轉換為十六進位編碼格式的字串。


簽章參數 `Signature` 是基於 `kSigning` 和 `StringToSign` 參數計算而來的。`Signature` 的虛擬碼如下：

```plain
Signature = HexEncode(HMAC(kSigning, StringToSign))
```


<span id="ksigning"></span>
#### kSigning

`kSigning` 表示用來計算簽章的金鑰。要計算 `kSigning`，您必須先 [取得您帳號的 Access Key Secret](https://console.byteplus.com/iam/keymanage)，然後使用以下虛擬碼生成 `kSigning`。

```plain
kSecret = <Your Access Key Secret>
kDate = HMAC(kSecret, ShortDate)
kRegion = HMAC(kDate, Region)
kService = HMAC(kRegion, Service)
kSigning = HMAC(kService, "request")
```


關於 `kSigning` 虛擬碼中參數的說明，參見 [虛擬碼中參數的說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E4%B8%AD%E5%8F%83%E6%95%B8%E7%9A%84%E8%AA%AA%E6%98%8E)。

<span id="stringtosign"></span>
#### StringToSign

`StringToSign` 表示用來計算簽章的簽章字串。`StringToSign` 的虛擬碼如下：

```plain
// Hash 函數使用 SHA256 演算法
StringToSign = Algorithm + '\n' + RequestDate + '\n' + CredentialScope + '\n' + HexEncode(Hash(CanonicalRequest))
```


關於 `StringToSign` 虛擬碼中 `Algorithm` 和 `RequestDate` 參數的說明，參見虛擬碼中參數的說明。`StringToSign` 虛擬碼中其他參數的說明如下。

**CredentialScope**

`CredentialScope` 表示憑證範圍。`CredentialScope` 的虛擬碼如下：

```plain
{ShortDate}/{Region}/{Service}/{Request}
```


關於 `CredentialScope` 虛擬碼中參數的說明，參見 [虛擬碼中參數的說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E4%B8%AD%E5%8F%83%E6%95%B8%E7%9A%84%E8%AA%AA%E6%98%8E)。

**CanonicalRequest**

`CanonicalRequest` 表示規範的請求。`CanonicalRequest` 的虛擬碼如下：

```plain
HTTPRequestMethod + '\n' + CanonicalURI + '\n' + CanonicalQueryString + '\n' + CanonicalHeaders + '\n' + SignedHeaders + '\n' + HexEncode(Hash(RequestPayload))
```


`CanonicalRequest` 虛擬碼中參數的說明如下：


* `HTTPRequestMethod`：表示請求方法。對於 CDN，該參數的取值是 `POST`。

* `CanonicalURI`：表示請求的 URL。

* `CanonicalQueryString`：表示規範的查詢字串。`CanonicalQueryString` 的值是通過以下規則生成的：

   * 按參數名稱對查詢參數進行升序排序。

* `CanonicalHeaders`：表示規範的請求標頭。`CanonicalHeaders` 是通過以下步驟生成的：

   1. 將參與簽章計算的請求標頭參數的名稱轉化成小寫字母。

   2. 在字元級別對這些名稱進行升序排序。

   3. 以 key\-value 的格式拼接這些請求標頭參數。key 是請求標頭參數的名稱，value 是請求標頭參數的值。

   4. 在每個請求標頭參數後添加換行符（`\n`）。

* `SignedHeaders`：參見 [虛擬碼中參數的說明](https://docs.byteplus.com/en/docs/18/46499#%E8%99%9B%E6%93%AC%E7%A2%BC%E4%B8%AD%E5%8F%83%E6%95%B8%E7%9A%84%E8%AA%AA%E6%98%8E)。

* `HexEncode(Hash(RequestPayload))`：表示一個計算值。該值是通過對請求正文中 `payload` 的值應用 SHA256 雜湊演算法計算得到的。


<span id="虛擬碼中參數的說明"></span>
### 虛擬碼中參數的說明

以下表格包含了本文中多個虛擬碼中參數的說明。


|參數名稱 |資料類型 |參數說明 |範例 |
|---|---|---|---|
|AccessKey |string |表示您帳號的 Access Key ID。參考 [取得 Access Key](https://console.byteplus.com/iam/keymanage)。 |`AKLTMjI2ODVlYzI3ZGY1NGU4ZjhjYWRjMTlmNTM5OTZkYzE` |
|RequestDate |string |該參數與 [請求驗證](https://docs.byteplus.com/en/docs/18/46499#%E8%AB%8B%E6%B1%82%E9%A9%97%E8%AD%89) 章節中 `X-Date` 的定義相同。 |`20210913T081805Z` |
|ShortDate |string |該參數與 `RequestDate` 的定義相同，只不過時間精度是日。 |`20210913` |
|Region |string |該參數用於簽章計算。參數值建議是 `singapore`，也可以是非空的任意字串。 |`singapore` |
|Service |string |表示 CDN 的服務名稱。該參數的取值是 `CDN`。 |`CDN` |
|SignedHeaders |string |表示參與簽章計算的請求標頭參數。多個請求標頭參數使用分號（;）分隔。這些請求標頭參數是根據參數名稱升序排序的。<br><br>&nbsp;<br><br>一般來說，`SignedHeaders` 的值是 `host;x-content-sha256;x-date`。您也可以指定任意請求標頭參數作為 `SignedHeaders` 的值。 |`host;x-content-sha256;x-date` |
|Algorithm |string |表示簽章計算所使用的演算法。該參數的取值為 `HMAC-SHA256`。 |`HMAC-SHA256` |
|Request |string |該參數是一個常數，值是 `request`。 |`request` |


<span id="範例請求"></span>
### 範例請求

```Plain
POST https://cdn.byteplusapi.com/?Action=DescribeCdnConfig&Version=2021-03-01

// Request Headers
X-Date: 20230116T073702Z
Authorization: HMAC-SHA256 Credential=AKLTMjYxYTZmYWU4ZWYzNGI2NDg8NTUxODE1ZGVhNmIxZmQ/20230116/singapore/CDN/request, SignedHeaders=x-content-sha256;x-date, Signature=5a394ce80456c7cdf989c28bd638807c8ead386eb15dd36e39952f405380aef2
Content-Type: application/json

//Request Body
{
    "Domain": "www.example.com"
}
```
