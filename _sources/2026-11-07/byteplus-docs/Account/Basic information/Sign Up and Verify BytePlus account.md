# Create BytePlus Account

Please login into [BytePlus console ](https://console.byteplus.com/auth/signup)to create a BytePlus account.

Please create or provide below information to create a BytePlus account:


* **Email:**  all the notifications from BytePlus will be sent to the email.

* **User name:**  The user name must contain 5\-20 characters and start with a letter. Supported characters are letters, numbers, dash(\-) and underscore(_).

# Add Account Profile

Please provide below information to complete the account profile:


* **Type**: Personal account or bussiness account. [See details](https://docs.byteplus.com/en/docs/byteplus-platform/account_type).

* **Organization name: ** the full registered name of your company or organization.

* **Full name:**  the full name of the contact person

* **Country/Region:**  where your organization was registered.

* **Contact address & Postal code**

* **Phone number:**  will be verified by OTP (One\-Time\-Password)


Account profile completion is a prerequisite to continue product ordering, credit limit application and usage billing, so please provide the required information.

Organization name is the company name, and should be kept the same as which appeared in contract with BytePlus.
