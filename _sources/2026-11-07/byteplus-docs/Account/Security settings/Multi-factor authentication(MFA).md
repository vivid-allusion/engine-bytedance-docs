Multi\-factor authentication (MFA) requires additional forms of identity verification for signing in to the BytePlus Console. BytePlus uses virtual MFA devices (Google Authenticator) to increase account security for all BytePlus users. You can bind MFA devices to the root user or IAM users, thereby requiring both the password and the identification information generated by the authticator app for a sign\-in event.

<span id="6wHqleQd"></span>
## Verification & setup rules

**For the root user:** 


* Only one method is used for identity verification at a time. The system defaults to the following verification methods from high to low priority: the Google Authenticator app (if bound) \> mobile phone (if bound) \> email.

* There is a ten\-minute span between verifications. In other words, once the root user is verified by any of the above methods, BytePlus does not require MFA verification again when the root user is trying to perform any risky actions within 10 minutes.


**For IAM users:** 


* The Google Authenticator app is the only method for identity verification. The root user can enable MFA for IAM users. In addition, IAM users with full access to IAM functionality are able to bind virtual MFA devices for other IAM users but are unable to access the root user's MFA settings.

* There is a ten\-minute span between verifications. This is the same as the rule for the root user.

## Enabling MFA for the root user

Below are the steps to follow:


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. On the top right, click **Username** \> **My account**.


This directs you to the account management screen.


3. From the left navigation pane, select **Security settings**.


This directs you to the security settings screen where the Verifying your identity pane is located.


4. In the MFA device section, click **BInd**.


<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260515090957-1327027104278.png) </span>

The Bind an MFA device pop\-up window appears. BytePlus allows identity verification via the following methods: TOTP authenticator apps installed on mobile phones (such as Google Authenticator, other authenticator apps, or WeChat Mini Programs), terminal devices with built\-in fingerprint and facial recognition capabilities (e.g., Apple Touch ID, Windows Hello), or FIDO Passkey\-enabled terminal devices. Select one verification method in the pop\-up window:

<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260515091012-1487195233873.png) </span>


   1. Choose"**an authenticator app installed on your phone**": 

      1. Launch the Google Authenticator app on your mobile phone.

      2. Scan the QR code or enter the account and key present in the window.A 6\-digit code is then generated by the authenticator app.

      3. Enter the 6\-digit code in the above pop\-up window.

      4. Click **Submit**.

      A virtual MFA device is then bound with the admin account. A pop\-up window asking you to enable account protection appears.

   2. Choose "**Passkey**":

      The browser will pop up a window to create a passkey. Click **Continue**, then follow the browser prompt to complete verification using the fingerprint or facial recognition feature of your current computer or mobile device.

   3. Choose "**A hardware security key or other devices**":

      Click **Confirm**. The browser will launch the passkey creation pop\-up and prompt you to select a hardware type. You may choose **Use phone or tablet** or **USB security key**.

      If you select **Use phone or tablet**, a QR code will be displayed. Use a FIDO Passkey\-supported mobile device to scan the QR code and complete verification. If you select **USB security key**, insert your security key and use it as a credential to finish verification.



&nbsp;

5. Enable account protection, you can:

   * Toggle the Login protection switch on the Enhanced account protection pane.


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">BytePlus will check whether account protection is enabled before requiring MFA authentication information. This means that, to successfully use MFA during a log\-in event, you MUST enable account protection.</div>


MFA setup is complete for the root user.

## Disabling MFA for the root user

You can disable MFA for the root user if necessary. Below are the steps to follow:


1. In the MFA device section, click **Management**.


<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260515095821-666693739815.png) </span>


2. A confirmation pop\-up window appears. Click **Unbind**.

   <span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260515095852-1254640577146.png) </span>


Virtual MFA device is then unbound with the root user.

&nbsp;

&nbsp;

## Enabling MFA for an IAM user

Below are the steps to follow:


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. On the top right, click **Username** \> **IAM**.


This directs you to the IAM configuration screen.


3. From the left navigation pane, select **User management** \> **User**.


This directs you to the user list.


4. Click a username.


This directs you to the user details screen.


5. Click **Login settings**.


The Login settings tab appears.


6. (Optional) Toggle the **Console login permission** switch for the user if you haven't.

7. In the MFA device section, click **Bind**.


<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260727070413-1445343926598.png) </span>

The Bind MFA device pop\-up window appears.


8. Enable account protection, you can:

* Toggle the Login protection switch.


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">BytePlus will check whether account protection is enabled before requiring MFA authentication information. This means that, to successfully use MFA during a log\-in event, you MUST enable account protection.</div>


<div data-tips="true" data-tips-type="default">Virtual MFA device is then bound with this IAM user.</div>

## Disabling MFA for an IAM user

You can disable MFA for an IAM user if necessary. Below are the steps to follow:


1. In the MFA device section, click **Manage resources**.


<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260727070559-583479428864.png) </span>

A manage devices pop\-up window appears.


2. Click **Unbind**.


The virtual MAF device is then unbound with an IAM user.

## What if I am unable to access the Google Authenticator app?

During sign\-in verification, if you are unable to access the Google Authenticator app due to any possible reasons, such as losing your mobile phone, you can [submit a ticket](https://console.byteplus.com/workorder/create), and the BytePlus team will change the database for you.
