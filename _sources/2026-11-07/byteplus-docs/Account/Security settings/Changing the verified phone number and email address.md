You can use the BytePlus Console to change the verified phone number for your BytePlus account.

**To change the verified phone number:** 


1. Sign in to the [BytePlus Console](https://console.byteplus.com/auth/login/).

2. Click **Username** \> **My account**.


<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260514140819-1727496641432.png) </span>

&nbsp;

The **My account** dashboard appears.


3. Click **Security settings**.

4. For Root user and IAM user, 

   1. Root user: In the ** Identity verification** field, click **Change mobile or email**.<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260514140907-1019469285839.png) </span>

   2. IAM user: IAM users can only edit security email here.<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260514141938-722044865529.png) </span>

5. Follow the on\-screen instructions to change the verified phone number.
