You may configure account login session rules according to your enterprise security control requirements:<span>![图片](https://sf-bpcms.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/20260515085801-645596985971.png) </span>


&nbsp;

1. When logged in as a **root user**, the login session settings of the root user will be displayed. When logged in as an **IAM user**, the login session settings of the IAM user will be displayed. You can go to [Access Control - User Management - Security Settings](https://console.byteplus.com/iam/identitymanage/settings) to modify the login session settings for IAM users.

2. You can view the **No\-operation Login Session Retention Period** and **Maximum Login Session Retention Period**.The default value for both settings of the **root user** is 48 hours. For **IAM users**, the default values are 2 hours and 48 hours respectively.
