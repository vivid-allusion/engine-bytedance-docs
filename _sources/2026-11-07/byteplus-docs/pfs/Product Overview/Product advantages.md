This article introduces the product advantages of file storage PFS.

<span id="c740ead5"></span>
#### High throughput, low latency

PFS can support RDMA protocol access, and can support up to TB/s\-level throughput bandwidth, tens of millions of IOPS, and sub\-millisecond latency. Performance increases linearly with capacity, providing ultimate storage performance.

<span id="7afbdd85"></span>
#### High expansion

PFS supports online elastic expansion. Users can expand to the required capacity limit at any time, quickly achieving linear growth in capacity and throughput performance.

<span id="9ddf0885"></span>
#### Stable and easy to use

PFS is based on a multi\-level reliability architecture to ensure efficient and stable operation of the file system, and provides a convenient and easy\-to\-use web interface. Users can manage resources through the console and API.

<span id="6deb48e4"></span>
#### Model training directional optimization

PFS is optimized in conjunction with the AML machine learning platform and GPU computing resources to provide high\-quality storage services for training scenarios.
