<div data-tips="true" data-tips-type="tip">The PFS feature is in the beta stage. If you want to use it, please contact the customer manager.</div>

## 9 December 2024


|Feature |Description |Region |Phase |Document |
|---|---|---|---|---|
|Mount service |The number of file system instances that a single mounting service can bind to has been increased to 10. |All |GA |* [Limits](https://docs.byteplus.com/docs/pfs/Limits)<br><br>* [Binding a file system](https://docs.byteplus.com/docs/pfs/Binding-a-file-system) |

|Feature |Description |Region |Phase |Document |
|---|---|---|---|---|
|Fileset |Support configuring cloud monitoring alarm policies for capacity quota, File quota, IOPS and Bandwidth QoS. When the Fileset capacity, number of files, IOPS QoS, and bandwidth QoS approach the quota threshold, send alarm notifications. |All |GA |[Managing fileset quota](https://docs.byteplus.com/docs/pfs/Managing-fileset-quota) |
|Monitoring alarm |Support configuring cloud monitoring alarm policies for instance bandwidth and IOPS metrics. |All |GA |* [Viewing performance monitoring](https://docs.byteplus.com/docs/pfs/Viewing-performance-monitoring)<br><br>* [Configuring alarm rules](https://docs.byteplus.com/docs/pfs/Configuring-alarm-rules) |
