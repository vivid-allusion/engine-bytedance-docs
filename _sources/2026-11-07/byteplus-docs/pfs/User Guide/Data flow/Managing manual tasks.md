After creating a manual task, you can view its details and perform actions such as copying, canceling, or deleting the task, as well as downloading reports, in the manual task list. This topic introduces how to manage manual tasks.

<span id="JLFMBZHg"></span>
## Prerequisites

The manual task has been created. For detailed steps, see [Creating manual tasks](https://docs.byteplus.com/en/docs/pfs/Creating_manual_tasks).

<span id="PrGWAIKX"></span>
## View details


1. Log in to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region of the file system you want to manage.

3. In the left navigation pane, click **File** **System** \> **File** **System** **List**.

4. On the File System page, click the file system you want to manage.

5. On the **Overview** page, click the **Data flow** tab.

6. On the Data flow tab, click **Data** **Flow** **Task** \> **manual** **task**.

7. View the manual task list. The parameters are described as follows.

   
   |Field |Note |
   |---|---|
   |Task ID |An automatic, unique identifier generated by PFS. |
   |State |Current execution status of the task. |
   |Task type |The type of data operations, which consist of  **Import**, **Export**, and **Inventory** tasks. |
   |File System path |The absolute path of the file system for the task. |
   |Object storage path |Bucket and bucket prefix paths in TOS for the task. |
   |Number of completed files / scanned files |* **Number of completed files**: Number of files that have been warmed up, settled, or reconciled.<br><br>* **Number of scanned files**: Total number of files that need to be warmed up, settled, or reconciled. |
   |Start time |Time when the task is created. |
   |End time |Time when the task is completed. |
   


<span id="1562db8f"></span>
## Cancel manual tasks

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can only cancel manual tasks when they are in the <strong>Running</strong> <strong>State</strong>.</div>


To cancel a running manual task, follow these steps:


1. In the manual task list, click **Cancel** in the **Actions** column of the target manual task.

2. In the dialog box, click **Cancel task**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">When the <strong>State</strong> of the task changes to <strong>Cancelled</strong>, it means the task has been successfully terminated.   </div>
   

<span id="09aa80e6"></span>
## Copy manual tasks

You can copy a manual task to re\-execute it. Steps:


1. In the manual task list, click **Copy** in the **Actions** column of the target manual task.

2. On the **Copy Data Flow Task** page, make any necessary adjustments and click **Confirm**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The copying process begins immediately after initiation, creating and executing a new task. When the <strong>State</strong> of the task changes to <strong>Completed</strong>, it means the task has been created and executed successfully.   </div>
   

<span id="258c5e0a"></span>
## Download Inventory reports

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Inventory reports are only available for manual <strong>Inventory</strong> tasks.</div>


After a Inventory task finishes, you can download the report to view comparison results between PFS and TOS. Steps:


1. In the manual task list, click  **...**  \> **Download** **Inventory** **report** in the **Actions** column of the target manual task.

2. View the Inventory report, which has the following parameters.

   
   |Parameter |Note |
   |---|---|
   |Job_id |Data Flow task ID. |
   |Start_time |Start time of the Data Flow task. |
   |End_time |End time of the Data Flow task. |
   |diff\-with\-tos\-filelist |A list of PFS files that differ from those in TOS. The file list is packaged as a zip file. Unzip the file to view the details. |
   |tos\-based\-filediff\-cnt |Number of PFS files that differ from those in TOS. |
   |diff\-with\-PFS\-filelist |A list of TOS files that differ from those in PFS. The file list is packaged as a zip file. Unzip the file to view the details. |
   |PFS\-based\-filediff\-cnt |Number of TOS files that differ from those in PFS. |
   


<span id="cff98266"></span>
## Download flow reports

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">A maximum of 10,000 failed files will be recorded in the flow report. If there is a large volume of data, consider enabling <strong>Log Analysis</strong> when <a href="https://docs.byteplus.com/en/docs/pfs/Managing_manual_tasks">Managing manual tasks</a> to search and analyze all flow logs.</div>


If the data flow task has failed files, you can download the list report of failed files for analysis and retry. Steps:


1. In the manual task list, click  **...**  \> **Download** **the** **flow** **report** in the **Actions** column of the target manual task.

2. In the **Download the report** dialog, click **Download** next to **list of failed files**.

   The downloaded `.csv` file shows information about failed transfers, including:

   * `file_path`: The full path of the file in the PFS file system.

   * `obj_path`: the full path of the file in the TOS bucket.

   * `err_message`: The error message.

   * `process_time`: The time when file processing ended.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Both <code>file_path</code> and <code>obj_path</code> represent the full path of the file, but this path is based on the Data Flow path defined in the task. It does not include the directory path or the TOS bucket prefix specified in the task. For example, if the actual file path is <code>/fileset/lens/test/test01.txt</code> and the specified directory path is <code>/fileset/lens/</code>, then the <code>file_path</code> will be <code>/test/test01.txt</code>.   </div>
   

<span id="e57fdcad"></span>
## Delete manual tasks

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You cannot delete a manual task while it is in the <strong>Creating</strong>, <strong>Running</strong>, or <strong>Cancelling</strong> state.</div>


To delete a manual task, follow these steps:


1. In the manual task list, click  **...**  \> **Delete** in the **Actions** column of the mount target you want to remove.

2. In the box that appears, click **Delete**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">If the target manual task is no longer on the manual task list, it means the task has been successfully deleted.   </div>
