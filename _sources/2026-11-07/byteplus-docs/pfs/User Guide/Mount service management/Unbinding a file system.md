This topic introduces the steps to unbind storage instances from the mount service.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

After unbinding, all client services associated with the mounting service will be interrupted. Please proceed with caution.

<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region where the target file system is located.

3. Select **File System** \> **Mount Service** in the left navigation bar, and click  **...**  \> **Unbinding storage instances**.

4. In the pop\-up dialog box, click **Unbind** corresponding to the target instance in the operation column.

5. Click **OK** in the pop\-up dialog box to unbind the storage instance.
