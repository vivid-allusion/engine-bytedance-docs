This topic describes the steps to remove a file system mounting service.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Preconditions

Before deleting the mounted service, please make sure that you have unbound all bound instances. For specific operation steps, please refer to [Unbinding a file system](https://docs.byteplus.com/docs/pfs/Unbinding-a-file-system).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

When unmounting the service, the client management node ECS instances will be automatically released.

<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region where the target file system is located.

3. Select **File System** \> **Mount Service** in the left navigation bar, and click  **...**  \> **Delete Mount Service**.

4. In the pop\-up dialog box, click **Delete** to delete the mounted service.
