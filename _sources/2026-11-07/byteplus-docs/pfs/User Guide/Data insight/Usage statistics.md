The usage statistics feature in PFS allows you to view the usage of all PFS file storage resources in the current region, including total capacity and used capacity. This article explains how to view usage statistics.

<span id="3e69e445"></span>
## Important notes


* Usage statistics are not updated in real time and have an estimated delay of two hours.

* Usage statistics are for your reference only and do not represent actual billable usage. Please refer to the billing statement for the actual usage.


<span id="b73479d0"></span>
## Steps


1. Log in to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region of the file system you want to manage.

3. In the left navigation panel, select **Data Insight** \> **Usage Statistics**.

4. In the **Usage statistics** page, view resource usage in the current Region, including total storage capacity, used storage capacity, total file count, and used file count.

   * By default, usage and total amounts from the past hour are shown. You can select a specific time period or customize the range to view the usage data.

   * Click or hover over data points on the usage line chart to view usage and total values at a given time.

   * Click the color block legend for capacity or usage below the chart to hide or show the corresponding line.

5. Optional: After selecting a specific time range, click the export icon in the upper right corner of the page to export the usage statistics as a PNG file for that period.
