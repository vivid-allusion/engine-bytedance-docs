You can view detailed information about the file system in the PFS console. This topic describes the steps to view file system details.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisite

Created file system, for specific steps, please refer to [Creating a file system](https://docs.byteplus.com/docs/pfs/Creating-a-file-system).

<span id=".5pON5L2c5q2l6aqk"></span>
## Operation Steps


1. Log on to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region where the target file system is located.

3. Select **File System** \> **Instances** in the left navigation bar. On the Instance List page, click the name of the target file system.

4. On the **Overview** tab, you can view the details of the file system, including information such as **File name**, **File ID**, **billing method**, and **Specifications**.
