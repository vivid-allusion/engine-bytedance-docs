You can modify the name and description of the file system through the PFS console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Preconditions

File system has been created, please refer to [Creating a file system](https://docs.byteplus.com/docs/pfs/Creating-a-file-system).

<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region where the target file system is located.

3. Select **File System** \> **Instance** in the left navigation bar. On the Instance List page, click the target file system name.

4. On the **Overview** tab, click the Edit button next to the **Name** and **Description** fields to modify the corresponding information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">Tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Naming conventions for names and descriptions, please refer to <a href="https://docs.byteplus.com/docs/pfs/Creating-a-file-system">Creating a file system</a>.   </div>
   

5. Click the finish icon after the modifications are done.
