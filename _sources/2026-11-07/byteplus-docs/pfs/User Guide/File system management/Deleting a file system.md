This topic will provide information on the steps involved in deleting a file system.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisite


* Created file system, for specific steps, please refer to [Creating a file system](https://docs.byteplus.com/docs/pfs/Creating-a-file-system).

* Unbind the corresponding instance from the mounted service. For specific steps, please refer to [Unbinding a file system](https://docs.byteplus.com/docs/pfs/Unbinding-a-file-system).


<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. Log on to the [PFS console](https://console.byteplus.com/pfs).

2. In the top menu bar, select the region where the target file system is located.

3. Select **File System** \> **Instances** in the left navigation bar. On the Instance List page, click **delete** in the **Actions** column of the target file system.

4. In the pop\-up dialog box, click **Delete Instance**.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">Note   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">After deleting the file system, the data cannot be recovered. Please proceed with caution.   </div>
