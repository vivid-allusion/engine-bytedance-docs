To quickly launch a professional live stream for scenarios like E\-commerce, Live marketing, or Online education, you can use pre\-configured BytePlus Live templates. This guide provides a three\-step walkthrough, from activating the service and creating a live room to starting your first broadcast, enabling you to go live with minimal setup.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/afe6e687d12a40128106e44321a91120~tplv-goo7wpa0wc-image.image) </span>

<span id="9fb77530"></span>
## Prerequisite

You have access to a BytePlus account. For more information, see [Signing up for a BytePlus account](https://docs.byteplus.com/en/byteplus-platform/docs/signing-up-your-account).

<span id="a290f87f"></span>
## Step 1: Activate the BytePlus Live service


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/). The following page appears. For new users, BytePlus Live offers a 7\-day free trial with full features.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/51d2b55dee10401ba2cf68a5b72cacc9~tplv-goo7wpa0wc-image.image) </span>

2. Click **Get started for free** to start a 7\-day full\-featured free trial, which offers you up to 3,000 minutes of watch time and 5 GB of media library capacity. For more information about the media library capacity and watch time, see [Subscription billing method](https://docs.byteplus.com/docs/byteplus-livesaas/docs-billing-methods).

   The BytePlus Live service is activated automatically, and you are then navigated to the **Live rooms** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/449fbe4b24404a7783e3758285dd5be9~tplv-goo7wpa0wc-image.image) </span>

3. (Optional) If the BytePlus Live service fails to activate due to reasons such as your location not being in a supported country or region listed [here](https://docs.byteplus.com/en/byteplus-platform/docs/tax-rate-reference), follow the instructions in the dialog box that appears.


<span id="81289f9b"></span>
## Step 2: Create a live room by applying live templates

BytePlus Live provides three system templates, each of which contains preset configurations for different scenarios, including **E\-commerce**, **Live marketing**, and **Online education**. This section uses the **E\-commerce** template to demonstrate how to create a live room.


* **For new users** who have just activated the BytePlus Live service, follow the steps below to create a live room:

   1. On the **Live rooms** page, click the **E\-commerce** template.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4d4d938516f44e5692b6d7d0cca8fc4a~tplv-goo7wpa0wc-image.image) </span>

      The **Quick Start** drawer slides up.

   2. In the **Quick Start** drawer, modify your live room name (optional) and click **Create and start a live stream**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/630e62b97f124c2b924cf55a15bab7ab~tplv-goo7wpa0wc-image.image) </span>

      Now you have created a live room and also started a live stream. You can click or hover over the cards to preview the features. For details on each feature, see the following [Live room feature description](https://docs.byteplus.com/docs/byteplus-livesaas/docs-starting-a-live-stream#27a42058) section.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/459b59474eaa47178fa01337691cb302~tplv-goo7wpa0wc-image.image) </span>

   3. After you have explored the features, click **End the test🎉 See exclusive benefits** to end the live stream and get exclusive benefits for new users.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/999d41e1922a4846bd84e36303831a25~tplv-goo7wpa0wc-image.image) </span>

      You can get the exclusive edition for new users for only $299. For the trial version and the exclusive edition:

      * You can create up to 20 live rooms.

      * Each live room supports up to 100 concurrent viewers.

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/505e024c9a0948b2850577ac9fcf5da6~tplv-goo7wpa0wc-image.image) </span>

         You can also click **Don't buy it yet, check the console** to enter the **Live control** page of the room. You can follow [Step 3: Start a live stream via web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-starting-a-live-stream#862c3ba8) to start a live stream again via web browser.

* For existing BytePlus Live users, follow the steps below to create a live room:

   1. Click **Create live room** on the **Live rooms** page.

      You will be directed to the **Create a live room** page.

   2. On the **Create a live room** page, enter your live room name, select a live template, and click **Save**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/55f2078761b14e4781111c0b82d40488~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You can also find the Live templates page via <strong>Account center</strong> \> <strong>Live templates</strong> on the console and check the configurations of these templates.      </div>
      

      You will be directed to the **Live control** page of the room. Now you have created a live room. Follow the steps below to start a live stream.

## Step 3: Start a live stream via web browser

The following steps show how to start a live stream via web browser. This broadcast method is simple to use and does not require the installation of any clients or tools, which is ideal for solo hosts.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">BytePlus Live provides four methods for livestreaming. For details on each method, see the <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-starting-a-live-stream#0cdf48b8">Live streaming methods</a> section in this topic.</div>


<span id="3dd2a7de"></span>
### Before you begin

Before you start a live stream, your live room may be in **Preview** or **Over** status. The description is as follows:


* **Preview**: Viewers can watch a preview if one has been uploaded; otherwise, they will see the live room's cover image.

* **Over**: The live stream has ended and no playback is published to the viewing page.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3dd1281671594ca093789f2d428ee8f8~tplv-goo7wpa0wc-image.image) </span>

For a live room with the **Over** status, click **Restore to preview** on the **Live control** page of the live room so that you can start a live stream again.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d68a3bf6e4d74c41b4e0def1b1dadf90~tplv-goo7wpa0wc-image.image) </span>

<span id="82466c13"></span>
### Steps


1. On the **Live rooms** page, click the target live room card.

2. On the **Live control** page, click **Web browser** on the **Broadcast method** tab under the player.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/615e160e4d824018b7397066ad9fe084~tplv-goo7wpa0wc-image.image) </span>

3. (Optional) Click **Settings**. In the **Settings** dialog box that appears, turn on the switch to display the corresponding feature on the live streaming page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/93bb3a3059f94be28ae5dd4a675bb130~tplv-goo7wpa0wc-image.image) </span>

4. Click **Go to live streaming page** to enter the live streaming page.

5. In the **Test your device** dialog box that appears, select your camera and microphone.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ac686c3ef3a846c48b42b8a0f7e98606~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Make sure to grant your browser permissions to use your camera and microphone.   </div>
   

6. Move your pointer over **Viewing page** in the upper\-right corner and provide the viewing page address to viewers, which they can use to enter the live room.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Make sure the <strong>Viewing page address</strong> switch is turned on in step 3.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/91f20487bf6e4193811f7ce7a308186c~tplv-goo7wpa0wc-image.image) </span>

7. Click **Start live** to start a live stream.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c5daafbaf5c944b684bebb611485b5f9~tplv-goo7wpa0wc-image.image) </span>


After the live stream ends, a playback is automatically generated. If you turn on the **Release playback** switch when you create the live room or on the **Producer** \> **Basic information** page of the live room, the playback is automatically released to the viewing page after the live stream ends. If the switch is off, the playback appears on the **Playbacks** page within a few minutes of the stream ending. You can then click **Release** to publish it manually. You can also upload a local file or select a video in the video library to release it to the viewing page as a playback.

## Live streaming methods

BytePlus Live provides four methods for live streaming. The following table describes the live streaming methods.


|**Broadcast method** |**Description** |
|---|---|
|Web browser |On the live streaming page in a web browser, you can perform operations such as sharing the screen, interacting with viewers, and sending interactive content. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser). |
|Pull stream |Pull a live stream from an external source into a BytePlus Live room. Supported stream pulling protocols are RTMP, HLS, and FLV. You can use this method if you want to live stream on multiple platforms at the same time. For more information, see [Pulling streams](https://docs.byteplus.com/docs/byteplus-livesaas/docs-pulling-streams). |
|Prerecorded video |Loop multiple videos for live streaming. You can use this method for marketing live streams or scheduling pre\-recorded videos to go live. For more information, see [Starting prerecorded videos](https://docs.byteplus.com/docs/byteplus-livesaas/docs-starting-the-carousel). |
|Push stream |Get the server URL and stream key to push the live stream to the live room of BytePlus Live. You can use this method if external providers want to push live streams to BytePlus Live or hosts want to push live streams from third\-party live streaming tools, such as Open Broadcaster Software (OBS), to BytePlus Live. For more information, see [Pushing streams (Using OBS as an example)](https://docs.byteplus.com/docs/byteplus-livesaas/docs-pushing-streams). |
