To organize and manage your live rooms more efficiently, you can use the tagging feature. This guide provides step\-by\-step instructions on how to create category and text tags, apply them to your live rooms, and use the tags to filter your room list or add notes.

<span id="c1f3b7d6"></span>
## Prerequisites

You must have a BytePlus account or be an IAM user with the super administrator role to create tags. For more information on how to add IAM users, see [Managing IAM users and roles](https://docs.byteplus.com/byteplus-livesaas/docs/managing-iam-users-and-roles).

<span id="be76c5cc"></span>
## Creating tags


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/) by using a BytePlus account or an IAM user with the super administrator role.

2. On the live room list, click **Tag library**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/67f724aa193b43318a46056d77569fe9~tplv-goo7wpa0wc-image.image) </span>

3. In the **Tag library** dialog box that appears, create category tags or text tags.

   * Category tags

      Complete the following steps to create category tags:

      1. Click **Create** on the **Category tags** tab.

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f0bfe4ea6f684baa855ed017afef79cf~tplv-goo7wpa0wc-image.image) </span>

      2. Click **Add**.

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1d73ac1ba47542f9bc0143e0cea9c8d0~tplv-goo7wpa0wc-image.image) </span>

      3. Enter a tag name and one or more optional tag values. Each tag value can be up to 20 characters long.

      4. Click **OK**.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Press <strong>Enter</strong> on your keyboard to generate tag values. You can add up to 100 tag values for each tag.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">After creating tags, you can drag them to adjust their display order. This order is reflected in both the <strong>Category tag</strong> drop\-down list on the <strong>Producer</strong> \> <strong>Basic information</strong> page and the tag selection drop\-down list on the live room list.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">When you delete a tag or tag value, it is also removed from any live rooms that use it.      </div>
      

   * Text tags

      Complete the following steps to create text tags:

      1. Click **Create** on the **Text tags** tab.

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2477978c9fb1457c8f731b6d6b4513aa~tplv-goo7wpa0wc-image.image) </span>

      2. Click **Add**.

      3. Enter the tag name and then click **OK**.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">After creating tags, you can drag a tag to adjust the display order of text tags on the <strong>Producer</strong> \> <strong>Basic information</strong> page in your live rooms.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">When a tag is deleted, it is also removed from any live rooms that use it.      </div>

## Tagging live rooms

When creating a live room or updating the information of a live room, you can tag the live room as needed.


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click **Create live room** or click the name of an existing live room to open it.

3. You can tag a live room in the following ways:

   * When creating a live room, select category tag values or enter text tag values.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e5ae94c8a1d4466abef49bb6c4f433f0~tplv-goo7wpa0wc-image.image) </span>

   * When creating multiple live rooms at a time, select category tag values.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a0caba98ae6a48618b246bd79a920a45~tplv-goo7wpa0wc-image.image) </span>

   * For an existing live room, go to the **Producer** \> **Basic information** page to select or enter tag values.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8b1ab4df26d2453fb55bb86702f7f544~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can only select one tag value for a category tag.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can enter a keyword to search for specific category tags and tag values. Fuzzy search is supported.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Text tags are not supported when you create multiple live rooms at a time.   </div>
   

4. (Optional) You can view the tag values added to your live rooms on the live room list.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/af568fa3c3c24178b53a44a966e11c4c~tplv-goo7wpa0wc-image.image" width="842px" />   </div>

## Filtering live rooms

On the live room list, you can filter live rooms based on category tag values.


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, select one or more category tag values from the tag selection drop\-down list.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b24ed75f0c3f44d6b176adb2395af0ba~tplv-goo7wpa0wc-image.image" width="842px" />   </div>
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can enter a keyword to search for specific category tags and tag values. Fuzzy search is supported.   </div>
   

3. Click outside the drop\-down list to apply the filter and view the live rooms with the selected tags.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3ca22546b47c4ccdab1c321cb5048028~tplv-goo7wpa0wc-image.image" width="842px" />   </div>
