You can send a check\-in to monitor your viewers' attendance and participation.

<span id="5101572e"></span>
## Scenarios

The check\-in feature is widely applicable to teaching and training scenarios.


* Teachers can use this feature to understand students' attendance conveniently and quickly.

* Corporate trainers or meeting hosts can use this feature to understand the participation of employees in training or meetings in a timely manner.


<span id="6d368602"></span>
## Prerequisites


* Make sure the menu for interaction tools is added. For more information, see [Configuring the menu for interaction tools](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-interaction-area#f1b04790).

* Send a check\-in on the console

   Make sure you have a BytePlus account or an IAM user with Live control \> Edit permission.

* Send a check\-in on the live streaming page in a web browser

   * We recommend that you use devices and browsers that meet the specified requirements for live streaming to ensure you can have a smooth live streaming experience. For more information, see [Environmental requirements to start a live stream](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#d66d12ba).

   * If you enter the live streaming page through the console, make sure you have a BytePlus account or an IAM user with Live control \> Edit permission.

   * If you use a link to enter the live streaming page without the need for logging in, no console permissions are required to send a check\-in.

<div data-tips="true" data-tips-type="tip">For more information on how to add IAM users, see <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles">Managing users, organizations, and roles</a>.</div>

## Procedure

<span id="88aa5a28"></span>
### Step 1: Enter the **Create check\-in** dialog box


* Console

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. On the live room list, click to open a live room.

   3. On the **Live control** page, click **Check\-in** under the menu for interaction tools.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9ab02ed194184d56bc291e17d72f3b00~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">For a better viewing experience, we recommend that you turn on the <strong>Display menu</strong> switch in the lower\-right corner to display the menu on the viewing page.      </div>
      

   4. Click **Create check\-in** in the dialog box that appears.

* Live streaming page in a web browser

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. Select **Web browser** as the broadcast method and go to the live streaming page. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser).

   3. On the tab for interaction tools, click **Check\-in**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e8b751ff07bc46ce8f63f9b47ac4709b~tplv-goo7wpa0wc-image.image) </span>


<span id="bc3d0c1d"></span>
### Step 2: Configure and send a check\-in

The operations are similar on the console and the live streaming page in a web browser. In this step, take the console as an example.


1. In the **Create check\-in** dialog box that appears, complete the following configurations and then click **Confirm**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4a03407582114532bee204f584968562~tplv-goo7wpa0wc-image.image) </span>

   * **Check\-in title**: Enter the title of the check\-in.

   * **Check\-in duration**: Configure the time duration within which viewers can check in.

   * **Send method**: Select either **Send manually** or **Send at scheduled time**. If **Send at scheduled time** is selected, configure the time, and then the check\-in will be sent automatically at the specified time.

   * **Check\-in information**: Configure whether viewers must enter specific information to check in.

   * **Prompt text**: Enter the text to guide viewers to enter specific information to check in.

   * **Kick out viewers**: If enabled, viewers who fail to check in on time will be kicked out of the live room. However, such viewers can re\-enter the live room with the viewing page address after being kicked out.

2. Click **Check\-in** under the menu for interaction tools and select the check\-in to be sent in the dialog box that appears. Click **Send** to send the check\-in to the viewing page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/41e076975bde489092b7ead54d9e91ae~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">On the live streaming page in a web browser, click <strong>Start check\-in</strong> directly in the <strong>Create check\-in</strong> dialog box to send the check\-in to the viewing page.   </div>
   

3. (Optional) You can edit or delete unsent check\-ins, as well as delete sent check\-ins.

4. (Optional) Under the menu for interaction tools, you can perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e8270e7b2c54d4198c58bda4560334f~tplv-goo7wpa0wc-image.image) </span>

   * Click the **Withdraw** icon to withdraw a sent check\-in.

   * View the number of viewers who have checked in.

   * Click **View** to view check\-in results. In the **Check\-in results** dialog box that appears, you can perform the following operations.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a627af7a7bba4b24897f06225a5a7461~tplv-goo7wpa0wc-image.image) </span>

      * View the number, nicknames, check\-in information, and check\-in time of viewers who have checked in.

      * View the time remaining for viewers to check in.

      * Click **Stop check\-in** to end the check\-in before the remaining time runs out.

      * Click **Refresh** to refresh the check\-in results.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can also view the check\-in data on the <strong>Insights</strong> \> <strong>Check\-in data</strong> page of the console. For more information, see <a href="https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-data-statistics">Data statistics</a>.</div>


<span id="e12b5b7a"></span>
## What your viewers see

Viewers can only open the check\-in most recently sent by clicking the **Check\-in** icon. However, they can open all the check\-ins sent in the live room under the menu for interaction tools.

Viewers must participate in the check\-in in time. Otherwise, they cannot check in after the countdown ends.

Viewers can check in in any of the following ways:


* In the check\-in dialog box that automatically appears, click **Check in**.

* Click the **Check\-in** icon and then click **Check in** in the dialog box that appears.

* Click **Participate** under the menu for interaction tools and then click **Check in** in the dialog box that appears.
