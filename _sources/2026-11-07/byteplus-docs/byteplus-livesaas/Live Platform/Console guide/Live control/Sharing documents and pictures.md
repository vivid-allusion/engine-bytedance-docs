On the live streaming page in your web browser, you can share documents and pictures meeting the following requirements and draw on them as needed. This feature applies to teaching and training scenarios.


* Documents

   * Format: PPT, PPTX, DOC, DOCX, and PDF.

   * Page number: Less than 500 pages.

   * File size: No greater than 200 MB.

* Pictures

   * Format: JPG, PNG, and BMP.

   * File size: No greater than 100 MB.

## Prerequisites


* We recommend that you use devices and browsers that meet the specified requirements for live streaming to ensure you can have a smooth live streaming experience. For more information, see [Environmental requirements to start a live stream](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#d66d12ba).

* If you enter the live streaming page through the console, make sure you have a BytePlus account or an IAM user with Live control \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

* If you use a link to enter the live streaming page without the need for logging in, no console permissions are required to share documents and pictures.

## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. Select **Web browser** as the broadcast method and go to the live streaming page. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser).

3. Click **Document**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/674e106c85ac4d0eb1d89b1ef11bd945~tplv-goo7wpa0wc-image.image) </span>

4. (Optional) Click **Add document** on the left if existing documents or pictures are opened by default.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/09ab537600134f778ce3d6ab62c38e16~tplv-goo7wpa0wc-image.image) </span>

5. In the **Cloud document** dialog box that appears, click **Upload** to upload a document or picture to the live room.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/703d9ce01d9a4c07aaa556e7cd97a87b~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">All the people will see the same uploaded documents and pictures in the <strong>Cloud document</strong> dialog box on the live streaming page of this live room.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can upload at most 100 documents and pictures.   </div>
   

6. Click **Open** to open a document or picture. The opened document or picture is displayed in the file list on the left of the page.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Documents and pictures must be transcoded before you can open them. If the transcoding fails, click <strong>Start transcoding</strong> in the <strong>Actions</strong> column to try transcoding again.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can open at most 8 documents and pictures at the same time.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">In this live room, when a presenter uses the document feature again, or when different presenters use the document feature respectively, all previously opened documents and pictures will be opened by default and set to the last opened page. For example, if a presenter opens documents A, B, and C, and is on page 5 of document B. Then, the presenter switches to another person and the new presenter uses the document feature. Documents A, B, and C will be opened by default and the new presenter will be on page 5 of document B.   </div>
   

7. (Optional) You can draw on the document or picture as needed. For more information, see [Page overview](https://docs.byteplus.com/docs/byteplus-livesaas/sharing-documents-and-pictures#144d6a7c).

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The same live room shares the uploaded documents and pictures. In other words, the new presenter can see the content drawn by the previous presenter on documents and pictures, and continue drawing based on this.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The content drawn on documents and pictures will be retained until the live stream ends. If you start a co\-host, the content drawn will be retained until both the live stream and co\-host have ended.   </div>
   

8. If the live stream has not yet started, click **Start live** and then viewers will see the shared documents and pictures on the viewing page.
