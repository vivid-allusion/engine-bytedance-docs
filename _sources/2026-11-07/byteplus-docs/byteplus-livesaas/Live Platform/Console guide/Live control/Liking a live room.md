After enabling the like feature, viewers can like the live room, thereby enhancing the interaction of the live room. This topic introduces how to enable the like feature, configure the like icon, and set whether to display the number of likes on the viewing page.

## Prerequisite

A BytePlus account or an IAM user with Producer \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

<span id="f1e16f6a"></span>
## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the left navigation pane, click **Producer** \> **Basic information**.

4. In the **Advanced settings** section, turn on the **Like** switch and perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/826076fc306546c79ace9d657993b0f7~tplv-goo7wpa0wc-image.image) </span>

   * Click **Replace** to replace the like icon in the lower\-right corner of the viewing page. You can also click **Reset to default** to restore to the default like icon.

   * Turn on the **Number of likes** switch to display the number of likes above the like icon.

5. (Optional) On the **Live control** page, click the **Like** tab on the **Interaction popularity** tab under the player. You can perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ebe9bad8803c415aa12ec0c1f45c4404~tplv-goo7wpa0wc-image.image) </span>

   * Configure the initial number of likes, which can be set to a positive integer from 1 to 100,000. Default value: 0.

   * View the actual number of likes in the live room.

   * View the number of viewers who liked the live room.
