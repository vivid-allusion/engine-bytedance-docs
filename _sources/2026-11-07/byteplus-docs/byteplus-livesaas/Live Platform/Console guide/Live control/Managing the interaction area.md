You can send the following interactive content in the interaction area under the menu for interaction tools: pictures, documents, questionnaires, votes, check\-ins, quizzes, announcements, and lucky draws.

<span id="32813a50"></span>
## Prerequisites


* Configure the menu for interaction tools or send interactive content on the console

   A BytePlus account or an IAM user with the following permissions.

   * Producer \> Edit permission: Used to configure the menu for interaction tools.

   * Live control \> Edit permission: Used to send interactive content.

* Send interactive content on the live streaming page in a web browser

   * We recommend that you use devices and browsers that meet the specified requirements for live streaming to ensure you can have a smooth live streaming experience. For more information, see [Environmental requirements to start a live stream](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#d66d12ba).

   * If you enter the live streaming page through the console, make sure you have a BytePlus account or an IAM user with Live control \> Edit permission.

   * If you use a link to enter the live streaming page without the need for logging in, no console permissions are required to send interactive content .


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For more information on how to add IAM users, see <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles">Managing users, organizations, and roles</a>.</div>

## Configuring the menu for interaction tools


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the left navigation pane, click **Producer** \> **Menus**.

4. Add the menu for interaction tools.

   1. Click **Edit** **menu**.

   2. Click **Add** in the dialog box that appears.

   3. Enter the menu name and select **Interaction tools** from the **Menu type** drop\-down list.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7209c03a353c4f22be84fb29ccb13daf~tplv-goo7wpa0wc-image.image) </span>

   4. (Optional) Drag to adjust the order of menus.

   5. Click **Confirm**.

   6. Click **Save** on the **Menus** page.

5. Under the menu for interaction tools, complete the following configurations and then click **Save**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a0c795d939745b3bca64df856700371~tplv-goo7wpa0wc-image.image) </span>

   * **Display menu**: Configure whether to display this menu on the viewing page. The switch is turned off by default.

      * Turn on the switch: Display this menu and icons of interactive content on the viewing page.

      * Turn off the switch: Only display icons of interactive content on the viewing page.

   * **Display mode on PCs**: Select the display mode of this menu on the viewing page for PCs.

## Entering the menu for interaction tools


* Console

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. On the live room list, click to open a live room.

   3. On the **Live control** page, click the menu for interaction tools.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/843f554ea38f410d951f1cde86d0a089~tplv-goo7wpa0wc-image.image) </span>

* Live streaming page in a web browser

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. Select **Web browser** as the broadcast method and go to the live streaming page. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser).

   3. Click the menu for interaction tools on the right of the page.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/89445ca9344343f4b6de18ff7f24ee22~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Currently, you cannot send pictures or votes here.   </div>

## Sending interactive content

The operations are similar on the console and the live streaming page in a web browser. In this step, take the console as an example.


1. Send the following types of interactive content as needed:

   * Picture: Click **Image** to send a JPG or PNG file no more than 8 MB. You can also click the **Withdraw** icon to withdraw a sent picture.

   * Document: Click **Document** and then upload a document in the dialog box that appears. To allow viewers to download the document, turn on the **Allow download** switch. Click **Add to send area** and then click **Send** under the menu for interaction tools to send the document to the viewing page.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d6e403f706fe4c32bbc8b10df3a5e87b~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">On the live streaming page in a web browser, click <strong>Send document</strong> in the <strong>Document</strong> dialog box to send the document to the viewing page.      </div>
      

      In addition, you can also perform the following operations under the menu for interaction tools.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/801e57278032416c9d871cf4a2e1df5a~tplv-goo7wpa0wc-image.image) </span>

      * Click the **Withdraw** icon to withdraw a sent document.

      * Click the **Preview** icon to preview the document.

      * View the document size.

      * Select whether to allow viewers to download the document.

   * Questionnaire: Click **Questionnaire** to create and send a questionnaire. For more information, see [Sending a questionnaire](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-questionnaire).

   * Vote: Click **Vote** to create and send a vote. For more information, see [Sending a vote](https://docs.byteplus.com/docs/byteplus-livesaas/docs-initiating-a-vote).

   * Check\-in: Click **Check\-in** to create and send a check\-in. For more information, see [Sending a check-in](https://docs.byteplus.com/docs/byteplus-livesaas/sending-a-check-in).

   * Quiz: Click **Quiz** to create and send a quiz. For more information, see [Sending a quiz](https://docs.byteplus.com/docs/byteplus-livesaas/sending-a-quiz).

   * Announcement: Click **Announcement** to create and send an announcement. For more information, see [Sending an announcement](https://docs.byteplus.com/docs/byteplus-livesaas/sending-an-announcement).

   * Lucky draw: Click **Lucky draw** to create and send a lucky draw. For more information, see [Sending a real-time lucky draw](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-real-time-lucky-draw).

   * Text: Send texts if the **Display menu** switch is turned on.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For a better viewing experience, we recommend that you turn on the <strong>Display menu</strong> switch in the lower\-right corner of the console to display the menu on the viewing page.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can only send texts on the console.   </div>

## What your viewers see

This topic only provides examples of pictures and documents on the viewing page. For other interactive content, see the corresponding documentation.

Viewers can only open the picture or document most recently sent by clicking the **Picture** or **Document** icon. However, they can open all the pictures or documents sent in the live room under the menu for interaction tools.
