On the live streaming page in your web browser, you can share the whiteboard and draw on the whiteboard page to present information and visualize concepts.

<span id="70e21c5d"></span>
## Scenarios

The whiteboard feature is widely applicable to teaching and training scenarios:


* Teachers of open courses can use the whiteboard to effectively and quickly convey knowledge, enhancing the viewing experience and increasing the course conversion rate.

* Online course instructors can use the whiteboard to visually demonstrate and explain examples, thereby enhancing teaching efficiency.

* Training lecturers in enterprises can use the whiteboard to visually present training content, which facilitates employees' comprehension of the training content.

## Prerequisites


* We recommend that you use devices and browsers that meet the specified requirements for live streaming to ensure you can have a smooth live streaming experience. For more information, see [Environmental requirements to start a live stream](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#d66d12ba).

* If you enter the live streaming page through the console, make sure you have a BytePlus account or an IAM user with Live control \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

* If you use a link to enter the live streaming page without the need for logging in, no console permissions are required to share the whiteboard.

## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. Select **Web browser** as the broadcast method and go to the live streaming page. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser).

3. The whiteboard page is displayed by default. You can perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/26f53bcd89394f729154e9ff1d2bcd06~tplv-goo7wpa0wc-image.image) </span>

   * Draw on the whiteboard page. For more information, see [Page overview](https://docs.byteplus.com/docs/byteplus-livesaas/sharing-the-whiteboard#ac1f770a).

   * Click **Add whiteboard** on the left to add more whiteboard pages. You can have at most 10 whiteboard pages, including the 3 pages automatically added by the system.

   * Move your pointer over the whiteboard page on the left and click the delete button to delete the page.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The same live room shares the whiteboard pages. In other words, the new presenter by default enters the whiteboard page displayed when the previous presenter exits, sees the content drawn by the previous presenter on the whiteboard page, and can continue drawing.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The content drawn on the whiteboard page will be retained until the live stream ends. If you start a co\-host, the content drawn will be retained until both the live stream and co\-host have ended.   </div>
   

4. If the live stream has not yet started, click **Start live** and then viewers will see the shared whiteboard on the viewing page.
