An announcement in a live room is an important way for viewers to understand information such as live content. You can send an announcement to preview the live content, remind viewers to watch the live stream, or introduce promotional activities during the live stream.

<span id="f6f52e05"></span>
## Prerequisites


* Make sure the menu for interaction tools is added. For more information, see [Configuring the menu for interaction tools](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-interaction-area#f1b04790).

* Send an announcement on the console

   Make sure you have a BytePlus account or an IAM user with Live control \> Edit permission.

* Send an announcement on the live streaming page in a web browser

   * We recommend that you use devices and browsers that meet the specified requirements for live streaming to ensure you can have a smooth live streaming experience. For more information, see [Environmental requirements to start a live stream](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#d66d12ba).

   * If you enter the live streaming page through the console, make sure you have a BytePlus account or an IAM user with Live control \> Edit permission.

   * If you use a link to enter the live streaming page without the need for logging in, no console permissions are required to send an announcement.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For more information on how to add IAM users, see <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles">Managing users, organizations, and roles</a>.</div>


<span id="b7acdf4e"></span>
## Procedure

<span id="73b6f661"></span>
### Step 1: Enter the Announcement dialog box


* Console

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. On the live room list, click to open a live room.

   3. On the **Live control** page, click **Annoucement** under the menu for interaction tools.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ae2b47823cbe406094814565887f0ca6~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">For a better viewing experience, we recommend that you turn on the <strong>Display menu</strong> switch in the lower\-right corner to display the menu on the viewing page.      </div>
      

   4. Click **Create announcement** in the dialog box that appears.

* Live streaming page in a web browser

   1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

   2. Select **Web browser** as the broadcast method and go to the live streaming page. For more information, see [Live streaming from your web browser](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser).

   3. On the tab for interaction tools, click **Announcement**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ceab1a63e756434195a707df7acb1837~tplv-goo7wpa0wc-image.image) </span>


<span id="c50d5ca6"></span>
### Step 2: Configure and send an announcement

The operations are similar on the console and the live streaming page in a web browser. In this step, take the console as an example.


1. In the **Announcement** dialog box that appears, enter the title and content of the announcement, and then click **Save**.

   If this is not the first announcement in the live room, click **Create** and then enter the title and content of the announcement.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0c9b08119b1f40729ae1aa3ac4244b9f~tplv-goo7wpa0wc-image.image) </span>

2. Click **Add to send area** and then click **Send** under the menu for interaction tools to send the announcement to the viewing page.

   If you have multiple unsent announcements, select the announcement on the left first and then click **Add to send area**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4c5c7c3af4084d27967881c37a7f4b48~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">On the console, you can also click <strong>Announcement</strong> under the menu for interaction tools and select the announcement to be sent in the dialog box that appears. Click <strong>Send</strong> to send the announcement to the viewing page.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">On the live streaming page in a web browser, select the announcement and click <strong>Send</strong> in the <strong>Announcement</strong> dialog box to send the announcement to the viewing page.   </div>
   

3. (Optional) You can copy, preview, edit, or delete unsent announcements, as well as copy or delete sent announcements.

4. (Optional) Under the menu for interaction tools, you can withdraw or view a sent announcement.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/00e99e6a9b23424799c08d0482e92d79~tplv-goo7wpa0wc-image.image) </span>

## **What your viewers see**

Viewers can only open the latest manually sent announcement by clicking the announcement icon. However, they can open all the manually sent announcements in the live room under the menu for interaction tools.
