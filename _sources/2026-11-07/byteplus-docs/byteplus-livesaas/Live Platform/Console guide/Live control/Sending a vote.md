You can send a vote to increase the interaction between the host and viewers.

<span id="12efeca0"></span>
## Prerequisite


* Make sure the menu for interaction tools is added. For more information, see [Configuring the menu for interaction tools](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-interaction-area#f1b04790).

* A BytePlus account or an IAM user with Live control \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).


<span id="a46878c8"></span>
## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the **Live control** page, click **Vote** under the menu for interaction tools.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31ccfc758b754d98987b58036812a5be~tplv-goo7wpa0wc-image.image" width="1826px" />   </div>
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For a better viewing experience, we recommend that you turn on the <strong>Display menu</strong> switch in the lower\-right corner to display the menu on the viewing page.   </div>
   

4. Click **Create vote** in the dialog box that appears.

5. In the **Create vote** dialog box that appears, complete the following configurations and then click **OK**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5c3ec1c607434162b53288d311887d50~tplv-goo7wpa0wc-image.image) </span>

   * **Voting type**: Select **Choose one** or **Choose all that apply** to configure whether viewers can select more than one option in the vote.

   * **Vote title**: Enter the title of the vote.

   * **Vote options**: Enter the options in the vote.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You can configure at most 8 options in a vote.      </div>
      

   * **Deadline**: Configure the deadline for viewers to submit the vote. By default, the deadline is 7 days after the current time.

   * **View results**: Select the timing to view the voting results.

      * **Immediately after voting**: Viewers can view the results immediately after they vote. Therefore, viewers may view results at different times.

      * **Before voting**: Viewers can view the results before they vote.

6. Click **Vote** under the menu for interaction tools and select the vote to be sent in the dialog box that appears. Click **Send** to send the vote to the viewing page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1ecee8654eda42b59716664a4d1b24e8~tplv-goo7wpa0wc-image.image) </span>

7. (Optional) You can edit or delete unsent votes, as well as delete sent votes.

8. (Optional) Under the menu for interaction tools, you can perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/baed5630c70347fd932f32d824cbbe6a~tplv-goo7wpa0wc-image.image) </span>

   * Click the **Withdraw** icon to withdraw a sent vote.

   * Click the **View results** icon to view the voting results in real time.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can also view the voting data on the <strong>Insights</strong> \> <strong>Voting data</strong> page. For more information, see <a href="https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-data-statistics">Data statistics</a>.</div>

## What your viewers see

Viewers can only open the vote most recently sent by clicking the **Vote** icon. However, they can open all the votes sent in the live room under the menu for interaction tools.
