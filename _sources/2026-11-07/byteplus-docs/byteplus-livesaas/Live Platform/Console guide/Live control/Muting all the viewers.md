After muting all the viewers in a live room, they will be prevented from sending comments. This not only increases their focus on live content but also avoids behaviors such as spamming, thereby creating a better streaming atmosphere.

<span id="118c39b0"></span>
## Prerequisites


* The menu for chat interaction. For more information, see [Managing the chat area](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-chat-area).

* A BytePlus account or an IAM user with Live control \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).


<span id="d026114f"></span>
## Context

In scenarios where solely concentrating on live content is preferable for viewers, you can mute all the viewers. For example, if a teacher is teaching new knowledge and needs students to listen attentively, muting all the viewers will stop them from chatting in the chat area. As a result, they can focus more on the lecture.

<span id="c82253df"></span>
## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the **Live control** page, you can mute all the viewers in any of the following ways as needed:

   * Mute all the viewers both before a live stream starts and after a live stream ends.

      1. Click the settings icon.

      2. Under the menu for chat interaction in the **Settings** dialog box that appears, turn on the **Chat only during live stream** switch. This allows viewers to send comments only during a live stream.

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eb75529fcbf64810afffbe948464a7c0~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You can also turn on the switch on the <strong>Producer</strong> \> <strong>Menus</strong> page. If you log in to the console with an IAM user, make sure the IAM user has the Producer \> Edit permission.      </div>
      

   * Mute all the viewers instantly.

      Click the icon to stop viewers from sending comments. To unmute viewers, click the icon again.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/28e36e07362a4a0499b515ba7c00534c~tplv-goo7wpa0wc-image.image) </span>
