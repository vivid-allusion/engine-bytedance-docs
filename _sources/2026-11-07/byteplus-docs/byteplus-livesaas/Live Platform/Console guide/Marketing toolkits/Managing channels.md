Using the channel feature, you can generate different viewing page addresses for various channels in the same live room. This allows you to get statistical data for each channel and evaluate their promotional effectiveness based on the data.

<span id="f7432730"></span>
## Scenarios


* Data statistics for different channels

   When the same live stream is distributed on multiple platforms simultaneously, use the channel feature to generate different viewing page addresses for each platform. This enables the collection of data such as viewer behavior, live booking, and marketing from different platforms.

* Promotion and traffic conversion statistics for activities conducted by multiple sales representatives

   For the same live room, use the channel feature to generate and assign different viewing page addresses and exclusive invitation posters to each sales representative. This enables the collection of data such as traffic conversions for different representatives.


<span id="06acf0a6"></span>
## Prerequisites

A BytePlus account or an IAM user with **Marketing toolkits** \> **Edit** permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

<span id="be1ab3d3"></span>
## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the left navigation pane, click **Marketing toolkits** \> **Channels**.

4. Click **Create channel**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/975e1973166c4386a3634180765753e0~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The system creates a primary channel by default, which cannot be modified or deleted.   </div>
   

5. In the **Create channel** dialog box, enter the **Channel name** and **Channel identifier**, then click **OK**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a8205da68bde47948de59e1905c1a9f9~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The channel identifier must be unique in a live room.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">All English letters in the channel identifier are displayed in lowercase.   </div>
   

6. (Optional) In the **Actions** column of the channel list, you can perform the following operations.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7ea35e089e78454a9063b0965e8a2715~tplv-goo7wpa0wc-image.image) </span>

   * Click **Edit** and modify the name of a specific channel in the displayed **Edit channel** dialog box.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You cannot modify the channel identifier after channels are created.      </div>
      

   * Click **Share** and get the viewing page addresses on PCs and mobile devices, and the invitation poster of a specific channel in the displayed **Share channel** dialog box.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8e4504d03e84445799baaa1cf564ad25~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">You must enable the invitation poster feature to view the invitation poster. For more information on how to configure the invitation poster, see <a href="https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-sharing-and-postering">Sharing a live room</a>.      </div>
      

   * Click **Data**, and then the **Insights** \> **Basic data** page appears. You can view the basic data, marketing data, viewer behavior data, and live booking data of a specific channel under the **Insights** tab. For more information, see [Viewing data of a live room](https://docs.byteplus.com/docs/byteplus-livesaas/docs-data-statistics).

   * Click **Delete** to delete a specific channel.

7. (Optional) Perform a fuzzy search for channels based on the channel name or identifier.
