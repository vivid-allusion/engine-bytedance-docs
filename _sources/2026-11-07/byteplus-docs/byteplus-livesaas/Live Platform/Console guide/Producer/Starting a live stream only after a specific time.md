By enabling the feature of live stream start time, you can only start a live stream after the specified start time.

<span id="b80f784c"></span>
## What the host sees

A countdown timer to the configured live stream start time appears on the live streaming page in a web browser.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de233eebfecf4cf68238fe0473cfa9f7~tplv-goo7wpa0wc-image.image) </span>

<span id="ebcd4f9e"></span>
## Prerequisite

A BytePlus account or an IAM user. To enable the feature in an existing live room, the IAM user must have the Producer \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

<span id="7a8be3e0"></span>
## Procedure

You can enable the feature of live stream start time in one of the following ways.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You cannot enable or disable the feature, or modify the live stream start time during a live stream.</div>


<span id="0e9cfdf1"></span>
### Method 1: Create a live room with the feature enabled


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. Click **Create live room** on the **Live rooms** page.

3. On the **Create live room** page, choose to create one or more live rooms at a time.

   * Create a live room: On the **Create a live room** tab, turn on the switch under **Start time**. Complete the other configurations as indicated and click **Save**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2e843fe975f422d9692c97ef726fbde~tplv-goo7wpa0wc-image.image) </span>

   * Create multiple live rooms at a time: On the **Create multiple live rooms** tab, click **Add live** or **Add recording**. Turn on the **Start live after start time** switch. Complete the other configurations as indicated and click **Save**.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd1037fd65894a289ad3002d6e578723~tplv-goo7wpa0wc-image.image) </span>


<span id="9f5750b8"></span>
### Method 2: Enable the feature in an existing live room


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the left navigation pane, click **Producer** \> **Basic information**.

4. In the **Basic settings** section, turn on the switch under **Start time** and then click **Save**.
