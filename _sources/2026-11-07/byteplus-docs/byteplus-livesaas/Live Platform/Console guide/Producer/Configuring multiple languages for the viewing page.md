With multiple languages configured for the viewing page, viewers can switch to a language they are familiar with.

<span id="c320b947"></span>
## What your viewers see

By default, the viewing page language is the same as the default browser language on PCs or system language on mobile devices. Viewers can manually switch the viewing page language to view content in other languages.

## Prerequisite

A BytePlus account or an IAM user with Producer \> Edit permission. For more information on how to add IAM users, see [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles).

<span id="49214a37"></span>
## Procedure


1. Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).

2. On the live room list, click to open a live room.

3. On the left navigation pane, click **Producer** \> **Basic information**.

4. Turn on the **Languages** switch under **Advanced settings**.

5. Select the desired languages and then click **Save**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Up to 13 languages can be selected simultaneously.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0e2e951305c54932a50b40ea750e628c~tplv-goo7wpa0wc-image.image) </span>

6. Configure the text in different languages.

   In fields that support multi\-language text configuration, enter content in different languages in the following order, separated by vertical bars (|).

   
   |**Number** |**Language** |
   |---|---|
   |1 |Simplified Chinese |
   |2 |English |
   |3 |Japanese |
   |4 |Traditional Chinese |
   |5 |Korean |
   |6 |Thai |
   |7 |Vietnamese |
   |8 |Arabic |
   |9 |Turkish |
   |10 |Spanish |
   |11 |Indonesian |
   |12 |Portuguese |
   |13 |Russian |
   |14 |Tagalog |
   |15 |Khmer |
   |16 |Lao |
   |17 |Burmese |
   |18 |Malay |
   |19 |Hindi |
   |20 |French |
   |21 |German |
   |22 |Italian |
   

   For example, if **English**, **Japanese**, and **Simplified Chinese** are selected in step 5, then in the **Host's nickname** field, you can enter `主持人|Host|ホスト`.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7368428edf4a4497b6dc4d1cf5e82f51~tplv-goo7wpa0wc-image.image) </span>

   You can configure the text in different languages for the following features and pages.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You must have edit permission for the corresponding page when configuring the text in different languages.   </div>
   

   * The menu name

   * The menu for product cards

   * The menu for chat interaction

   * The menu for Q&A

   * Basic information

   * Questionnaires

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Viewers cannot switch the language on the viewing page if the send time of the questionnaire is <strong>When viewers enter the live room</strong>. For more information, see <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-questionnaire">Sending a questionnaire</a>.      </div>
      

   * Votes

   * Check\-ins

   * Real\-time lucky draws

   * Watch time\-based lucky draws

   * Gift rewards

   * Playbacks

   * Live sources

   * Prerecorded video: program list name

   * Invitation poster

   * Host account

   * Viewing restrictions: password, invitation code, allowlist, phone number

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Viewers cannot switch the language on the viewing page.      </div>
