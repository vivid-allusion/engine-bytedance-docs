You can use tokens or user verification to limit access to your live stream. You can use both methods simultaneously or just one of them.

<span id="Token"></span>
## Token

The token can be a password or an invitation code. You can use it in private live streaming.

<span id="User account"></span>
## User account

Only viewers that log in with their phone number or are verified with your own account system can view the live stream. You can also choose to allow everyone to view the live stream, but allow only those logged in to post comments.
