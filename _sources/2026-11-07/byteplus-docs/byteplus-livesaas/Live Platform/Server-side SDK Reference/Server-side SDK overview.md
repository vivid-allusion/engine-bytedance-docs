You can use the server\-side SDK to call BytPlus Live's APIs, making it easy to use BytPlus Live's features without the need for complex programming.

<span id="39135b60"></span>
## Features


* The server\-side SDK encapsulates API calls and responses, eliminating the need for API authentication.

* The server\-side SDK encapsulates common APIs and provides corresponding sample codes.

* The server\-side SDK encapsulates common processes, such as generating temporary security credentials on the server side.


<span id="878ffd42"></span>
## Installation and usage

After installing the server\-side SDK, you can use sample codes to call APIs.

Currently, BytePlus Live only supports the SDK for Go.
