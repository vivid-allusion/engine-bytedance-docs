This topic describes how to install the SDK for Go.

<span id="6eacdad8"></span>
## Prerequisites


* Download and install [Go](https://go.dev/) based on your operating system. Version 1.13.1 or later is recommended.

* Make sure your environment meets the requirements to run Go commands.


<span id="4a8e2853"></span>
## Installing SDK

Run the `go get` command to install the SDK for Go.

```Plain
go get -u github.com/byteplus-sdk/byteplus-sdk-golang
```
