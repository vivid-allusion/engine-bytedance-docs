## GiftInfo

Type: `interface`

Information about a received gift and the user who sent it.

<span id="07b22632"></span>
### GiftCount

Type: `number`

Number of gifts.

<span id="ffbb1454"></span>
### GiftId

Type: `number`

The unique ID for this type of gift.

<span id="44599d90"></span>
### GiftName

Type: `string`

Name of the gift.

<span id="33ef5903"></span>
### GiftImage

Type: `string`

URL of the gift image.

<span id="4fbdafa4"></span>
### GiftPrice

Type: `string`

Unit price of the gift.

<span id="68fabcb4"></span>
### Index

Type: `number`

The display index of the gift on the page.

<span id="2865d672"></span>
### Nickname

Type: `string`

Nickname of the user who sent the gift.

<span id="24e8fc86"></span>
### UserId

Type: `number`

User ID of the user who sent the gift.

<span id="e7422330"></span>
### Email

Type: `string`

Email of the user who sent the gift.

<span id="fe534689"></span>
## ProductInfo

Type: `interface`

Information about a product.

<span id="94866faf"></span>
### Id

Type: `number`

Unique ID of the product card.

<span id="1d48152e"></span>
### Title

Type: `string`

Name of the product.

<span id="22be6126"></span>
### Highlight

Type: `string`

Selling price of the product.

<span id="aeeebc42"></span>
### Strikethrough

Type: `string`

Reference price of the product.

<span id="f32080e7"></span>
### IntroduceImage

Type: `string`

The absolute URL of the product image.

<span id="99783364"></span>
### RedirectImage

Type: `string`

The absolute URL of the product redirect image.

<span id="892c194d"></span>
### ExternalProductId

Type: `string`

The external product ID. This ID ensures that once the product is added to the menu for product cards, it cannot be added again to the same menu.
