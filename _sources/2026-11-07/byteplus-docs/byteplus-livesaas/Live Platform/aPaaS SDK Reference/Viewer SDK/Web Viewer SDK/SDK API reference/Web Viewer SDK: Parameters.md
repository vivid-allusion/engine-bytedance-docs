## SDKconf

These parameters configure the SDK for displaying live rooms on the viewing page.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The SDK configuration takes precedence over the settings configured in BytePlus Live console and the server\-side OpenAPI.</div>



|Name |Type |Required |Default Value |Description |
|---|---|---|---|---|
|activityId |Integer |Yes |Not applicable |The activity ID of the live room.<br><br>A live room corresponds to one activity ID.<br><br>To get the activity ID, you can use one of the following methods:<br><br><br>* Call [CreateActivityAPIV2](https://docs.byteplus.com/docs/byteplus-livesaas/docs-createactivityapiv2).<br><br>* Log in to the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/) and find the ID in the upper\-left corner of the live room. |
|service |String |Yes |Not applicable |The service name, which is only used for marking.<br><br>After configuring the allowlist of BytePlus Live, the technical support will synchronize this parameter value to you. |
|mode |Integer |Yes |Not applicable |The authentication mode.<br><br><br>* `1`: Public mode. Viewers enter the live room in guest mode, and must enter their nicknames or log in to the live room by using their phone number to complete guest registration in scenarios where user information is required, such as clicking the comment text box and participating in lucky draws.<br><br>* `2`: Custom mode. Viewers enter the live room using their user information in your Web app, thus they can directly perform operations such as sending comments and participating in lucky draws. |
|token |String |Yes |Not applicable |The user token.<br><br><br>* If the value of `mode` is `1`, get the user token by calling [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi) or navigating to the **Producer** \> **Page embedding** \> **Web SDK embedding** page of the live room on the [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/).<br><br>* If the value of `mode` is `2`, get the user token by calling [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi). |
|modules |[Module](https://docs.byteplus.com/docs/byteplus-livesaas/parameters#b56510d0)[] |Yes |Not applicable |The configurations of modules. |
|options |Partial<[Options](https://docs.byteplus.com/docs/byteplus-livesaas/parameters#b6fb0c34)\> |No |Not applicable |The optional parameters. |

## Module


|Name |Type |Required |Default Value |Description |
|---|---|---|---|---|
|id |String |Yes |Not applicable |The page element ID, which is used to specify the location and size of the module to be rendered. |
|mode |String |Yes |Not applicable |The module name.<br><br><br>* `player`: The player module. We recommend a minimum width of 640 px for PCs.<br><br>* `menu`: The menu module. The SDK supports rendering multiple menu types: chat interaction, graphics, product cards, interaction tools, Q&A, and embedded link. We recommend a minimum width of 320 px for PCs.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The menu for interaction tools can be displayed on the viewing page only when the <strong>Display menu</strong> switch is turned on on the <a href="https://console.byteplus.com/livesaas/liveManagement/">BytePlus Live console</a>.   </div><br>   <br><br>* `lines`: The multi\-line module, which is used for live sources and the playback list. There is no need to specify the height, as the module is height\-adaptive.<br><br>* `mobile`: The full\-page module for the landscape mode of mobile devices, which contains the player, multi\-line, and menu modules. This module only supports mobile devices and cannot be used with other modules. For more information about the effect, see the [demo](https://live.byteplus.com/demo/sdk/index.mobile.all.html).<br><br>* `mobile-portrait`: The full\-page module for the portrait mode of mobile devices, which contains the player, multi\-line, and menu modules. This module only supports mobile devices and cannot be used with other modules. For more information about the effect, see the [demo](https://live.byteplus.com/demo/sdk/index.mobile.all-portrait.html).<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When the parameter value is set to <code>player</code>, <code>menu</code>, or <code>lines</code>, you can only integrate features specific to those modules. To integrate features that are not specific to any modules on mobile devices, such as booking, host account, and header image, you can set the parameter value to <code>mobile</code> or <code>mobile-portrait</code> to integrate the full\-page module.</div><br> |
|menu |String[] |No |None |This parameter only works when the value of `modules.mode` is `menu`.<br><br>Use this parameter to configure the menu types to be displayed. For example, you can set it to`["comment", "imagetext"]`. If not specified, all the menu types are displayed.<br><br><br>* `comment`: The menu for chat interaction.<br><br>* `imagetext`: The menu for interaction tools.<br><br>* `cardlist`: The menu for product cards.<br><br>* `bandcontent`: The menu for graphics.<br><br>* `session`: The menu for Q&A.<br><br>* `embeddedurl`: The menu for embedded link. |
