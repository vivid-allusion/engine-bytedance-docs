The Viewer SDK provides your mobile app with the capabilities to watch a live stream, post comments, interact with the host, and more. By integrating the Viewer SDK, you can quickly embed a live room with a rich set of features in your mobile apps.

<span id="Features"></span>
## Features

For more information, see [Feature comparison between SaaS and aPaaS](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-comparison-between-saas-and-apaas).

<span id="Scenarios"></span>
## **Scenarios**

<span id="E-commerce"></span>
### E\-commerce

Helps small and medium\-sized e\-commerce enterprises get started with live streaming by providing lightweight solutions with which enterprises can quickly and easily verify the result of selling products online.

<span id="Marketing"></span>
### Marketing

Helps enterprises promote their brands and run interactive marketing campaigns. Supports a rich set of components for interactive marketing, such as floating advertisements and in\-page banners. Allows for overall page customization for brands.

<span id="Finance"></span>
### Finance

Provides powerful customized solutions for products in the financial field. Supports displaying products in cards, allowing viewers to shop while watching a live stream, and starting a voice chat during a live stream.
