## Why is the playback content incomplete?

<span id="8582b935"></span>
### Possible reasons

Multiple playbacks can be generated during a live stream due to the following reasons. However, only the last generated playback, which does not contain the complete live content, will be automatically released to the viewing page.


* During the live stream, if there are network fluctuations or device\-related issues which interrupt the stream, a playback is generated each time such an interruption occurs.

* The maximum duration for a playback is 12 hours. If a live stream lasts longer than this, for example, 15 hours, a 12\-hour playback and a 3\-hour playback will be generated.


<span id="99a8e81a"></span>
### Solutions

Manually release multiple playbacks to the viewing page on the **Playbacks** page of the live room, or merge multiple playbacks into a single video and then release the video as a playback to the viewing page.
