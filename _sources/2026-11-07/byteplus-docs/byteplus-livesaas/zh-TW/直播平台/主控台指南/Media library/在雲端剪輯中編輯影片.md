若要在線上編輯您的影片而無需下載軟體，您可以使用雲端剪輯功能。本指南提供逐步操作說明，協助您完成基本編輯工作，例如分割並刪除直播回放中不需要的片段、將多個剪輯合併為單一影片，以及匯出最終成品以供下載或作為新的回放使用。

<span id="c8f8cf5c"></span>
## 背景

透過雲端剪輯，您可以在雲端編輯影片，無需下載任何軟體，操作簡便且節省時間。此外，雲端剪輯功能可與回放無縫配合。回放生成後，您可以根據需求在雲端剪輯中編輯該回放。

## 先決條件

需有 BytePlus 帳戶或具備 **Cloud clips** \> **Edit** 權限的 IAM 使用者。如需新增 IAM 使用者的詳細資訊，請參閱 [Managing users, organizations, and roles](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

## 操作流程


1. 登入 [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/)。

2. 您可以透過以下方式進入 **Cloud clips** 頁面。

   * 在 BytePlus Live 的選單列中，點擊 **Media library**。於左側導覽窗格中，點擊 **Videos** \> **Video library** 或 **Temporary storage**。在目標影片右側的 **Actions** 欄位中，點擊 **Clip**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aecf06a6102c4095a603b240d7a76608~tplv-goo7wpa0wc-image.image) </span>

   * 在 BytePlus Live 的選單列中，點擊 **Media library**。於左側導覽窗格中，點擊 **Cloud clips**。於現有剪輯專案中，點擊 **New clip** 或 **Enter the Cloud clips page**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/55ee18dcf5d84071acb3bafd5c041573~tplv-goo7wpa0wc-image.image) </span>

   * 在直播間列表中，點擊以開啟直播間。於左側導覽窗格中，點擊 **Playbacks**。在目標影片右側的 **Actions** 欄位中，點擊 **Clip**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cc6ea59201ac4edeb07aab884ca124a1~tplv-goo7wpa0wc-image.image) </span>

3. 於素材區選擇並拖曳影片至工作區的軌道。

4. 根據您的需求編輯影片。本主題提供兩個範例情境。

   * 修剪影片開頭與結尾：回放通常包含直播開始前的測試內容。使用 Cloud clips 刪除回放的開頭與結尾，以移除測試內容。

      1. 定位至您希望分割影片的回放開頭處，並點擊 **Split** 圖示，將選取的影片分割為兩部分。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2c5394b5e47b43cb8478c6d6d641f1f3~tplv-goo7wpa0wc-image.image) </span>

      2. 選擇欲刪除的部分，並點擊 **Delete** 圖示，或在鍵盤上按下 Delete 或 Backspace。

      3. 定位至您希望分割影片的回放結尾處，並點擊 **Split** 圖示。

      4. 選擇欲刪除的部分，並點擊 **Delete** 圖示，或在鍵盤上按下 Delete 或 Backspace，以刪除回放結尾。

   * 合併影片：使用雲端剪輯將多個回放合併為一部影片。您也可以將本地影片加入合併後的回放作為過渡片段。

      1. 於素材區選擇並拖曳多部影片至工作區的軌道。影片會自動合併。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9ea3082a784440f18bae71eba1dee45e~tplv-goo7wpa0wc-image.image) </span>

      2. （可選）於軌道上選擇並拖曳影片以調整順序。

5. （可選）你可以將目前的編輯進度儲存至**媒體庫** \> **雲端剪輯**。在頁面右上角點擊**儲存**，並於彈出的對話框中輸入專案名稱。然後，點擊**確認**。之後你可以選擇該專案以繼續編輯。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/26faa9adb8fb4cfb97c94bda7edb31f5~tplv-goo7wpa0wc-image.image) </span>

6. 在頁面右上角點擊**匯出至影片庫**，將影片剪輯匯出至影片庫以永久保存。於彈出的**匯出至影片庫**對話框中，輸入影片名稱、選擇影片品質，然後點擊**確認**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0338205fbeb241b2a9050760a1322763~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">我們建議將影片長度控制在三小時以內，以避免導出時間過長。   </div>
   

7. （可選）影片剪輯匯出至影片庫後，你可以下載影片剪輯或將其發布為直播間回放。

   * 下載影片剪輯

      1. 在 BytePlus Live 的選單列上，點擊**媒體庫**。

      2. 在左側導覽窗格，點擊**影片** \> **影片庫**。

      3. 在影片剪輯右側的**操作**欄位中，點擊**下載**。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/77cf40c2f5234c689a3916fab0c3480a~tplv-goo7wpa0wc-image.image) </span>

   * 發布影片剪輯

      1. 在直播間列表中，點擊以開啟一個直播間。

      2. 在左側導覽窗格，點擊**回放**。

      3. 在右上角點擊**從影片庫選擇**。

      4. 選擇影片剪輯並點擊**確定**。

      5. 在影片剪輯右側的**操作**欄位中，點擊**發布**。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5bc3164ff0e34d41b10a48d8fd2df593~tplv-goo7wpa0wc-image.image) </span>
