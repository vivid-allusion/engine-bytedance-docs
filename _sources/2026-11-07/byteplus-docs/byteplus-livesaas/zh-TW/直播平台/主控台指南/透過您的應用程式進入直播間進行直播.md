整合 Live Streaming SDK 後，下一步是取得進入直播間所需的憑證。本指南說明如何取得所需的活動 ID 和密鑰，您可以透過呼叫 API 或從 BytePlus Live 控制台取得。

可透過以下方法之一取得直播間的活動 ID 和密鑰：


* 呼叫 [CreateActivityAPIV2](https://docs.byteplus.com/docs/byteplus-livesaas/docs-createactivityapiv2) 或 [ListActivityAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-listactivityapi) 以取得活動 ID，並呼叫 [GetTemporaryLoginTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-gettemporarylogintokenapi) 以取得密鑰。

* 登入 [BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/)，然後取得直播間的活動 ID 和密鑰。請參閱下方螢幕截圖。

如需有關整合 Live Streaming SDK 的更多資訊，請參閱 [Integrating the Live Streaming SDK for iOS](https://docs.byteplus.com/docs/byteplus-livesaas/docs-integrating-the-live-streaming-sdk-for-ios) 和 [Integrating the Live Streaming SDK for Android](https://docs.byteplus.com/docs/byteplus-livesaas/docs-integrating-the-live-streaming-sdk-for-android)。
