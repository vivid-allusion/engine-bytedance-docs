你可以使用**Insights**模組來檢視直播間的數據詳情，例如基礎數據、行銷數據和觀眾行為數據。

<span id="0a53b0b1"></span>
## 步驟


1. 登入[BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊直播間以開啟。

3. 在左側導覽窗格中，點擊**Insights**，進入頁面並檢視數據。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/07456f6dd4604892806cf022236d8a8c~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">頁面上的資料不會自動刷新。您可以手動刷新頁面以獲取即時資料。   </div>

### 基礎數據

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d68d2bd0b44b4c5da403d03cc990e8d7~tplv-goo7wpa0wc-image.image) </span>


* 指標牆：數據每5分鐘更新一次。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d921a65f56ec460e8ccd6ec99ffe64bd~tplv-goo7wpa0wc-image.image) </span>

   可執行以下操作。

   * 根據數據統計範圍和渠道篩選數據。

      * 數據統計範圍：在右上角下拉列表中選擇**Total viewing**、**Live viewing**、**Preview viewing**、**Playback viewing**或**Page visit**。

         * Total viewing：當直播間處於**Live**、**Preview**或**Playback**狀態時產生的數據都會返回，即使在觀看頁面沒有播放預覽或回放。

         * Live viewing：當直播間處於**Live**狀態時產生的數據會返回。

         * Preview viewing：當直播間處於**Preview**狀態時產生的數據會返回，即使在觀看頁面沒有播放預覽。

         * Playback viewing：當直播間處於**Playback**狀態時產生的數據會返回，即使在觀看頁面沒有播放回放。

         * Page visit：當直播間處於**Live**、**Preview**、**Playback**或**Over**狀態時產生的數據都會返回，即使在觀看頁面沒有播放預覽或回放。

      * 頻道：請於頁面右上角的**頻道**下拉清單選擇頻道。然後會返回所選頻道的資料。預設會返回所有頻道的資料。

### 觀眾行為數據

在**Viewer behavior data**頁面，你可以執行以下操作。


* 根據渠道、暱稱，以及觀眾進入和離開直播間的時間篩選數據。

   在頁面右上角的**Channel**下拉列表中選擇渠道。然後會返回所選頻道的資料。預設會返回所有頻道的資料。

* 請勾選**合併相同裝置**或**合併相同觀眾**選框，分別根據裝置 ID 或用戶 ID 合併同一裝置或觀眾的多筆紀錄。

   若需登入以獲得更精確的紀錄，請選擇**合併相同觀眾**。若無需登入，請選擇**合併相同裝置**。

* 將篩選後的數據匯出至本地存儲。

* 檢視篩選後的資料。

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">你僅能查看最近 60 天內的資料。   </div>
