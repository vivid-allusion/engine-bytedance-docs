本主題介紹兩種推廣你的直播並增加觀眾人數的方法：


* 允許觀眾透過 Facebook、WhatsApp 及其他社交媒體平台分享你的直播連結。

* 為你的直播配置海報，並允許觀眾生成、儲存及分享該海報。


<span id="allowing-link-sharing"></span>
## 允許連結分享

若要允許觀眾透過社交媒體平台分享你的直播連結：


1. 登入[BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播列表中開啟你的直播。

3. 前往**Marketing toolkit** \> **Share Poster**，並啟用**Live Share**。

4. 點擊**Save**。

<span id="configuring-a-poster"></span>
## 配置海報


1. 登入[BytePlus Live console](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播列表中開啟你的直播。

3. 前往**Marketing toolkit** \> **Share Poster**，並啟用**Invitation Poster**。

4. 配置海報的標題、封面及其他資訊。
