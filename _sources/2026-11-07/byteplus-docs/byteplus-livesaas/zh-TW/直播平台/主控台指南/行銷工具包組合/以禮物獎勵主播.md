為提升直播間觀眾的參與度與互動性，您可以設定禮物獎勵功能。本指南提供逐步操作說明，協助您啟用並自訂直播間禮物，涵蓋免費禮物及透過 OpenAPI 整合自訂積分系統。您也將學習如何管理禮物排行榜與通知，以提升觀賞體驗。

觀眾可於直播間處於以下任一狀態時，使用免費禮物或兌換積分禮物來獎勵主播：**直播中**、**回放**及**結束**。

## 先決條件


* 需有 BytePlus 帳戶或具備 Marketing toolkits \> Edit 權限的 IAM 使用者。如需新增 IAM 使用者的詳細資訊，請參閱[管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

* 必須啟用聊天互動選單。如需詳細資訊，請參閱[管理聊天區域](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-liao-tian-qu-yu-zh-TW)。

* 如需讓觀眾兌換積分禮物，您需透過開發查詢與更新積分的 OpenAPI，將您的積分系統整合至 BytePlus Live。如需詳細資訊，請參閱[將你的積分系統整合至 BytePlus Live](https://docs.byteplus.com/docs/byteplus-livesaas/yi-li-wu-jiang-li-zhu-bo-zh-TW#fdaa49e4)。

## 背景

獎勵主播可提升推廣效果、互動性及直播整體品質。建議您在電商直播、行銷直播及教育培訓等直播場景中使用禮物獎勵功能。

<span id="696e99e5"></span>
## 設定禮物獎勵功能


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 於直播間列表中，點擊開啟直播間。

3. （可選）如需讓觀眾兌換積分禮物，請於左側導覽欄點擊**製作人** \> **觀看限制**，並選擇**自訂**作為驗證類型或評論限制。如需詳細資訊，請參閱[自訂驗證登入](https://docs.byteplus.com/docs/byteplus-livesaas/zi-ding-yan-zheng-deng-ru-zh-TW)。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">對於 Web Viewer SDK、iOS Viewer SDK、Android Viewer SDK 及 Flutter Viewer SDK，請確保驗證模式為自訂模式。   </div>
   

4. 於左側導覽欄點擊**Marketing toolkits** \> **Gift rewards**。

5. 開啟**Gift rewards**開關。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e17d68aa306141fb92647ac3b3ce8634~tplv-goo7wpa0wc-image.image) </span>

6. 選擇禮物獎勵模式：

   * 如需讓觀眾使用免費禮物，請選擇**Free**作為模式。

   * 如需讓觀眾兌換積分禮物，請選擇**Points**作為模式。

7. （可選）於**Points**模式下，請輸入以下資訊：查詢與更新積分 OpenAPI 的網址（例如：`https://test.com/get`及`https://test.com/post`）；API 呼叫失敗或積分不足時顯示的訊息；以及積分單位名稱（例如：寶石、珍珠）。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/63cb62d498f244ccba503c70451f3eac~tplv-goo7wpa0wc-image.image) </span>

8. （可選）系統預設提供多種內建禮物。您可執行多項操作：編輯禮物名稱、圖片及單價；設定其於直播間的可用性；啟用更顯眼的效果；並透過拖曳圖示至左側調整顯示順序。

9. （可選）建立自訂禮物。

   1. 點擊**建立禮物**。

   2. 於**建立禮物**對話框中完成以下設定，然後點擊**確定**。

      
      |**欄位** |**說明** |
      |---|---|
      |禮物名稱 |輸入禮物名稱。每種語言的最大字元限制為 50。 |
      |禮物圖片 |請上傳不超過 2 MB 的 JPG、PNG 或 GIF 格式圖片。 |
      |單價 |若選擇**Points**作為模式，請設定禮物單價。 |
      |效果 |勾選**Highlighted**選框，使禮物效果更加顯著。 |
      

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90b4c0e6bfeb4603b6fce86c36937cf2~tplv-goo7wpa0wc-image.image) </span>

10. （可選）開啟**Gift leaderboard**開關，以在直播間顯示禮物排行榜。輸入排行榜名稱及排行榜顯示的最大觀眾數。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">此功能僅於觀眾在直播期間兌換積分贈送禮物獎勵主播時可用。   </div>
   

11. 點擊**儲存**。

12. （可選）啟用禮物通知。然後，已送出的禮物通知將同時顯示在觀看頁面和控制台。

   1. 在**Live control**頁面，於聊天互動選單下點擊**Manage notifications**圖示。

   2. 在出現的**Manage system notifications**對話框中，開啟**Gift**開關並點擊**OK**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4f6e04ce3df84450b5f7468d4269c3d5~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若以 IAM 用戶登入控制台，請確保該 IAM 用戶擁有 Live Control \> Edit 權限。   </div>
   

13. （可選）你也可以在**Insights** \> **Gift details**頁面查看禮物數據。如需更多資訊，請參閱[檢視直播間的數據](https://docs.byteplus.com/docs/byteplus-livesaas/jian-shi-zhi-bo-jian-de-shu-ju-zh-TW)。

## 停用禮物效果與通知

你可以停用其他用戶禮物的高亮效果，以及已送出禮物的通知。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">若僅需在控制台停用禮物效果與通知，需 BytePlus 帳戶或具備 Live control \> View only 或 Edit 權限的 IAM 用戶。若需同時在控制台與觀看頁面停用禮物通知，需 BytePlus 帳戶或具備 Live control \> Edit 權限的 IAM 用戶。如需新增 IAM 用戶的詳細資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW">管理使用者、組織與角色</a>。</div>

## 將你的積分系統整合至 BytePlus Live

在允許觀眾兌換積分以贈送禮物獎勵主播之前，你必須根據規範開發以下兩個 OpenAPI，以將你的積分系統整合至 BytePlus Live。

若對整合有任何疑問，請聯繫你的業務代表。若你沒有業務代表，請點擊[here](https://www.byteplus.com/en/contact)填寫表單，以便 BytePlus 業務團隊稍後與你聯繫。

<span id="d1141f95"></span>
### 查詢積分

說明：BytePlus Live 會呼叫此 OpenAPI，從你的帳戶系統查詢用戶剩餘積分，並在觀看頁面顯示積分。

方法：GET

<span id="469a28b0"></span>
#### 請求參數

<span id="3884ac2c"></span>
##### **查詢**


|參數名稱 |資料型別 |必填 |範例值 |說明 |
|---|---|---|---|---|
|UserId |String |是 |`8erwwdfthf6e****` |您自有帳號系統中的使用者 ID。 |
|UserName |String |是 |`UserA` |您自有帳號系統中的使用者名稱。 |
|Ts |Integer |是 |`1650778541` |呼叫 OpenAPI 時的系統時間，Unix 時間戳格式。單位：秒。 |
|ActivityId |Integer |是 |`172982551195****` |直播間的活動 ID。 |
|Sign |String |是 |`2625701639ccf0081d3862ab6815****` |驗證用的簽名。<br><br>要取得 `Sign` 的值，必須完成以下步驟：<br><br><br>1. 將所有請求參數及其值依參數名稱字母順序排序。<br><br>2. 以 `ParameterNameParameterValueParameterNameParameterValue` 格式串接字串。<br><br>3. 在字串開頭與結尾分別加入 `accountSecret` 的值。如需取得 `accountSecret` 的值，請聯絡您的業務代表。<br><br>4. 將串接後的字串以 MD5（32 位小寫）加密。<br><br><br>本範例假設 `accountSecret` 的值為 `abc`。串接後的字串為 `abcActivityId172982551195****Ts1650778541UserId8erwwdfthf6e****UserNameUserAabc`，`Sign` 的值為 `2625701639ccf0081d3862ab6815****`。 |


<span id="ab938545"></span>
#### 回應參數

<span id="f6b17ba6"></span>
##### **主體**


|參數名稱 |資料型別 |範例值 |說明 |
|---|---|---|---|
|Code |Integer |`200` |HTTP 狀態碼。 |
|Status |Integer |`0` |服務狀態。<br><br><br>* `0`：成功。<br><br>* `1`：使用者積分不足。<br><br>* `2`：其他錯誤。 |
|Message |String |`-` |若 `Status` 的值為 `2`，會返回詳細錯誤訊息。 |
|Data |Integer |`123` |使用者剩餘積分。 |


<span id="986233ef"></span>
#### 範例

<span id="be7bd4e6"></span>
##### **範例請求**

```Plain
GET https://test.com/get?UserId=8erwwdfthf6e****&UserName=UserA&Ts=1650778541&ActivityId=172982551195****&Sign=2625701639ccf0081d3862ab6815****
```


<span id="ac01c937"></span>
##### **範例回應**

```JSON
{
        "Code": 200, 
        "Status": 0, 
        "Message": "", 
        "Data": 123 
    }
```

### 更新積分

說明：BytePlus Live 會呼叫此 OpenAPI，將用戶為禮物獎勵所消耗的積分更新至你的帳戶系統。

方法：POST

<span id="3f752430"></span>
#### 請求參數

<span id="a5dc2ed7"></span>
##### **主體**


|參數名稱 |資料型別 |必填 |範例值 |說明 |
|---|---|---|---|---|
|UserId |String |是 |`8erwwdfthf6e****` |您自有帳號系統中的使用者 ID。 |
|UserName |String |是 |`UserA` |您自有帳號系統中的使用者名稱。 |
|Ts |Integer |是 |`1650778541` |呼叫 OpenAPI 時的系統時間，Unix 時間戳格式。單位：秒。 |

|GiftPrice |Integer |是 |`1` |使用者兌換積分的禮物價格。 |
|GiftCount |Integer |是 |`100` |使用者兌換積分的禮物數量。 |
|Amount |Integer |是 |`100` |使用者兌換禮物的總積分數。 |
|ActivityId |Integer |是 |`172982551195****` |直播間的活動 ID。 |
|Sign |String |是 |`89827f98fadbd7f3183cb4008f80****` |驗證用的簽名。<br><br>要取得 `Sign` 的值，必須完成以下步驟：<br><br><br>1. 將所有請求參數及其值依參數名稱字母順序排序。<br><br>2. 以 `ParameterNameParameterValueParameterNameParameterValue` 格式串接字串。<br><br>3. 在字串開頭與結尾分別加入 `accountSecret` 的值。如需取得 `accountSecret` 的值，請聯絡您的業務代表。<br><br>4. 將串接後的字串以 MD5（32 位小寫）加密。<br><br><br>本範例假設 `accountSecret` 的值為 `abc`。串接後的字串為 `abcActivityId172982551195****Amount100GiftCount100GiftNameLikeGiftPrice1Ts1650778541UserId8erwwdfthf6e****UserNameUserAabc`，`Sign` 的值為 `89827f98fadbd7f3183cb4008f80****`。 |
