為了提升觀眾參與度、收集回饋或管理直播期間的註冊，您可以使用問卷功能。本指南提供逐步操作說明，協助您手動發送問卷以進行即時互動，或設定問卷在觀眾進入直播間或直播結束後自動發送。

<span id="9b312f6a"></span>
## 使用場景

您可以根據需求設定問卷的發送時間如下。發送時間設定為**觀眾進入直播間時**或**直播結束時**的問卷將自動發送。


* **觀眾進入直播間時**：適用於簽到、註冊等場景。觀眾必須在觀看直播前提交問卷。如需更多資訊，請參閱[自動發送問卷](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-questionnaire#964c76bd)。

* **直播結束時**：適用於收集觀眾對直播的回饋與意見等場景。觀眾可自行選擇是否提交問卷。如需更多資訊，請參閱[自動發送問卷](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-questionnaire#964c76bd)。

* **手動發送**：適用於直播期間與觀眾即時互動的場景。如需更多資訊，請參閱[手動發送問卷](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sending-a-questionnaire#01784943)。


<span id="38aa96f9"></span>
## 前置條件


* 請確保互動工具選單已啟用。如需更多資訊，請參閱[設定互動工具選單](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-hu-dong-qu-yu-zh-TW#f1b04790)。

* 要手動發送問卷，您需擁有 BytePlus 帳號或 IAM 使用者，並具備 Live control \> Edit 權限。

* 自動發送問卷：需擁有 BytePlus 帳號或 IAM 使用者，並具備 Marketing toolkits \> Edit 權限。

<div data-tips="true" data-tips-type="tip">如需新增 IAM 用戶的詳細資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles">管理用戶、組織與角色</a>。</div>

## 手動發送問卷


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點選直播間以開啟。

3. 於**Live control**頁面，在互動工具選單下點選**問卷**。

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f289ccd4770c48ef8c72b0a70b6001a0~tplv-goo7wpa0wc-image.image" width="1831px" />   </div>
   

   為提升觀看體驗，建議開啟右下角的**顯示選單**開關。

4. 於彈出對話框中點選**建立問卷**。

5. 在出現的**問卷**對話框中，完成以下設定並點選**儲存**。

   若此直播間已有問卷，請點選**建立**，然後完成以下設定。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/803a437aa48742cebaf7f092c30beb87~tplv-goo7wpa0wc-image.image) </span>

   * 輸入問卷標題與描述。

   * 新增至少一個問題。

6. 點選**加入發送區**，再於互動工具選單下點選**發送**，將問卷發送至觀看頁面。

   若有多份未發送問卷，請先於左側選擇問卷，再點選**加入發送區**。

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a718f757e76a4a18a393ded6582a9325~tplv-goo7wpa0wc-image.image" width="1193px" />   </div>
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">你也可以在直播間的互動工具選單下點擊<strong>問卷</strong>，並在出現的對話框中選擇要發送的問卷。點擊<strong>發送</strong>，將問卷發送至檢視頁面。   </div>
   

7. 對於未發送問卷，您可複製、預覽、編輯或刪除。對於已發送問卷，您可複製、預覽、分享或刪除。

8. （可選）在互動工具選單下，您可執行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/60f18e86705d497da9e728c27cb3a2f5~tplv-goo7wpa0wc-image.image) </span>

   * 點選**撤回**圖示以撤回已發送問卷。

   * 點選**預覽**圖示以預覽問卷。

   * 點選**分享**圖示，透過複製或下載 QR code 分享問卷。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">你也可以在<strong>洞察</strong> \> <strong>問卷資料</strong>頁面查看問卷資料。如需更多資訊，請參閱<a href="https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-data-statistics">資料統計</a>。</div>

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a44b4a9babf4986859f5785c5f15004~tplv-goo7wpa0wc-image.image) </span>

   * 根據需要選擇問卷的發送時間。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>

## 最佳實踐

<span id="c86e4f3c"></span>
### 發布簽到問卷

若觀眾在提交問卷前未輸入暱稱，問卷將為匿名，且資料在某些場景下可能無效。為避免此情況，你可以發布簽到問卷，要求觀眾進入直播間時輸入暱稱。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f191b228a730471d8df46f04a203bc35~tplv-goo7wpa0wc-image.image) </span>

觀眾在簽到問卷中輸入的暱稱，將與直播期間使用的暱稱一致。例如，觀眾在簽到問卷中輸入暱稱 User A，則在聊天區域會自動獲得相同暱稱 User A。你可以認為簽到問卷中暱稱為 User A 的觀眾，與聊天區域暱稱為 User A 的觀眾為同一人。對於暱稱相同的觀眾，你可以透過用戶 ID 進一步區分。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3dd3ce2f53964ab69b406e003a81c819~tplv-goo7wpa0wc-image.image) </span>


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊一個直播間以開啟。

3. 於左側導覽窗格，點擊**行銷工具組** \> **問卷**。

4. 點擊**建立問卷**。

5. 在**建立問卷**對話框中，選擇**觀眾進入直播間時**作為發送時間。點擊**新增問題**，並選擇**個人資訊** \> **暱稱**作為問題類型。完成其他設定後，點擊**確定**。

6. 點擊**發布**，於**操作**欄發布簽到問卷。


<span id="84e7a6af"></span>
### 直播報名

你可以透過發布問卷讓觀眾報名直播。換言之，觀眾進入直播間時必須輸入手機號碼與電子郵件。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e6003d6a5f7f4e0ebd0653a11c0daf85~tplv-goo7wpa0wc-image.image) </span>


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊以開啟直播間。

3. 於左側導覽窗格，點擊**行銷工具組** \> **問卷**。

4. 點擊**建立問卷**。

5. 在**建立問卷**對話框中，選擇**觀眾進入直播間時**作為發送時間。點擊**新增問題**以新增兩個問題。分別將其類型設為**個人資訊** \> **手機號碼**與**個人資訊** \> **電子郵件**。完成其他設定後，點擊**確定**。

6. 點擊**發布**，於**操作**欄發布簽到問卷。
