## 先決條件

需要 BytePlus 帳戶或具備以下權限的 IAM 使用者。如需新增 IAM 使用者的詳細資訊，請參閱 [管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。


* Producer \> 編輯權限：用於新增及設定商品卡片的選單。

* Live control \> 編輯權限：用於在 **Live control** 頁面設定商品卡片。

## 操作流程

本操作流程說明如何新增商品卡片選單、如何從自有系統或 Shopify 新增商品庫，以及最後如何新增商品。

<span id="e2390d98"></span>
### Step 1: 新增商品卡片選單


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊以開啟直播間。

3. 於左側導覽窗格，點擊 **Producer** \> **Menus**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/001115ee5891477097220e74c0b79d7c~tplv-goo7wpa0wc-image.image) </span>

4. 新增商品卡片選單。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8035397ebb184ab2bd1c2ffcbc487b0a~tplv-goo7wpa0wc-image.image) </span>

   1. 點擊 **Edit menu**。

   2. 在出現的 **Edit menu** 對話框中，點擊 **Add**。

   3. 於 **Menu type** 下拉清單中選擇 **Product cards**，並於 **Menu name** 欄位輸入選單名稱。

   4. （可選）拖曳以調整選單順序。

   5. 點擊 **Confirm**。

      每個直播間最多可新增 5 個商品卡片選單。


<span id="0b085a3d"></span>
### Step 2: 設定商品選單

依需求設定選單的基本資訊。


* 若需讓不同平台的觀眾在點擊商品卡片後導向不同網址，請啟用直接網址功能。您最多可設定 5 個環境，每個環境以 User Agent 識別，並可在每張商品卡片上為每個環境設定不同的直接網址。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">此功能僅支援行動裝置。   </div>
   

   1. 開啟 **Direct URL** 開關。

   2. 於 **User Agent for specific environments** 欄位新增最多 5 個環境。針對每個環境，請設定以下內容：

      * **Environment name**：用於識別環境的名稱，最多 20 字元。此名稱將標示您設定商品卡片時對應的直接網址。

      * **User Agent**：目標環境的 User Agent 字串，最多 500 字元。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ad83d9bb26854dcf874a5b5db6c53ccf~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在此功能升級前建立的直接 URL 配置，會自動遷移至名為<strong>Env1</strong>的單一環境。   </div>
   

   3. 設定商品卡片資訊時，請為每個環境輸入直接網址。

      當觀眾於 User Agent 包含 **User Agent for specific environments** 欄位所設定值的平台上點擊商品卡片時，將導向該商品卡片所設定環境的直接網址。若觀眾於未符合任何已設定環境的平台上點擊商品卡片，則將導向商品卡片的商品網址。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0a331c10c50045e1aeb3283cfd195775~tplv-goo7wpa0wc-image.image) </span>

* 選擇浮動商品卡片在 PC 端觀看頁面上的顯示位置。預設情況下，浮動商品卡片顯示於播放器右上角。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a733b20a33c4c64bae6a835d3026843~tplv-goo7wpa0wc-image.image) </span>

* 選擇商品詳情頁的顯示方式。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7e11f14b095f4dd1a3b3e73c7ca42f79~tplv-goo7wpa0wc-image.image) </span>

   * 在新頁面顯示：於新的瀏覽器分頁開啟商品詳情頁。觀眾無法同時觀看影片與查看商品詳情。

   * 在直播間浮動頁面顯示：觀眾點擊商品卡後，直播間會開啟浮動頁面以顯示商品詳情頁。觀眾可以同時觀看影片與查看商品詳情頁。此選項僅於行動裝置生效。


<span id="9ad7b1af"></span>
### （可選）Step 3: 新增自有系統或 Shopify 的商品庫

新增自有系統或 Shopify 的商品庫。然後，您可以將商品庫中的商品新增至直播間。


1. 點擊\*\*+新增商品庫\*\*。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/39859dfdfe9f4703b1776408365b0d14~tplv-goo7wpa0wc-image.image) </span>

2. 於出現的**商品庫**對話框中，新增一個或多個商品庫。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21bf3b3d572c4f8f9be7704468647d82~tplv-goo7wpa0wc-image.image) </span>

   1. 修改商品庫名稱。請確保名稱在直播間中唯一。

   2. 選擇商品庫類型，以新增自有系統或 Shopify 的商品庫。

      * **自有系統**：輸入用於從商品庫獲取商品的請求 URL。

         <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="3">warning         </div>
         

         <div data-tips="true" data-tips-type="warning" data-wrapper-indent="3">您必須依照規範開發 API，將您的系統與 BytePlus Live 整合後，才能新增自有系統的產品庫。如需更多資訊，請參閱<a href="https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-chan-pin-ka-pian-zh-TW#f4985fe1">將您的系統整合至 BytePlus Live</a>。         </div>
         

      * **Shopify**：輸入網域名稱與公開存取權杖。

         * **網域名稱**：您的 Shopify 商店的網域名稱。

            要取得網域名稱，請於 Shopify 商店左側導覽窗格點擊「設定」，於商店名稱下方查看網域名稱。您也可以點擊「設定」\>「網域」，於網域頁面查看網域名稱。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0aa4e1b2fc5349e184af839897ce7db9~tplv-goo7wpa0wc-image.image) </span>

         * **公開存取權杖**：您的 Shopify 商店 Storefront API 的公開存取權杖。

            要取得權杖，請於 Shopify 商店導覽至**Headless sales channel**頁面。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fcc45a5e3e8b4813b7218b86c6e766be~tplv-goo7wpa0wc-image.image) </span>

            點擊**管理**，於 Storefront API 頁面查看公開存取權杖。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/084b594a5b10486f8af763fe4f1fddfc~tplv-goo7wpa0wc-image.image) </span>

            點擊儲存圖示。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f44dec36f7a94a829864eecee2d0441d~tplv-goo7wpa0wc-image.image) </span>


<span id="4815086b"></span>
### Step 4: 從商品庫或手動新增商品卡

每個商品卡選單下最多可新增 500 張商品卡。


* 從商品庫新增商品卡

   1. 點擊**從庫新增**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3bd3471936c44ebb97f1e5dc70c37725~tplv-goo7wpa0wc-image.image) </span>

   2. 於出現的「從庫新增」對話框中，選擇於 Step 3 新增的商品庫中的商品，然後點擊「新增」。搜尋特定商品時支援模糊搜尋。

      若要隱藏 Shopify 商品庫中的特定商品，必須於 Shopify 新增特定商品 metafield 並設為 True。更多資訊請參見[在 Shopify 商品庫中隱藏特定商品](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-chan-pin-ka-pian-zh-TW#bd977a0e)。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/05e26384d1e04d0fa88f60d9c7308170~tplv-goo7wpa0wc-image.image) </span>

   3. 點擊**新增**。

* 手動新增商品卡

   * 一次新增多張商品卡

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/107dc3bbd8a34b40a23ee8a438c4d9ac~tplv-goo7wpa0wc-image.image) </span>

      1. 點擊**匯入**。

      2. 於出現的**匯入**對話框中，點擊**下載範本**。

      3. 依指示編輯範本，然後上傳已更新的範本。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">您只能在範本中輸入文字。圖片僅能在控制台上傳。      </div>
      

   * 一次新增一張商品卡

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1403fe0cd09941d7b5354eb61a5eb348~tplv-goo7wpa0wc-image.image) </span>

      點擊**新增**並完成以下設定。

      
      |欄位 |說明 |
      |---|---|
      |**產品名稱** |您的產品名稱。 |
      |**產品描述** |您產品的其他資訊，例如行動裝置的容量。 |
      |**產品類別** |您的產品類別，例如服裝。 |
      |**零售價格** |您的產品零售價格。 |
      |**標價** |您的產品標價。 |
      |**產品圖片** |產品卡片左側的產品圖片。您可以上傳不超過 2 MB 的 JPG 或 PNG 檔案。 |
      |**按鈕圖片** |產品卡片右下角的按鈕圖片。觀眾點擊按鈕後將被導向產品 URL 或直接 URL。<br><br>您可以點擊**替換**，將預設圖片替換為不超過 2 MB 的 JPG 或 PNG 檔案。此操作會更新所有現有及未來產品卡片的按鈕圖片。建議解析度為 160×60。 |
      |**產品 URL** |產品詳細頁面的 URL。 |
      |**直接 URL** |產品詳細頁面的直接 URL。當在第 2 步啟用直接 URL 功能時，每個已配置環境都會出現一個**直接 URL**欄位，並以環境名稱標示（例如**Env1**）。請根據需要為每個環境輸入直接 URL。 |
      


<span id="3705e36a"></span>
### （可選）Step 5: 按需管理商品卡


* 切換商品卡右側的「列表」開關，以在觀看頁面顯示或隱藏商品卡。

* 點擊**匯出**以匯出所有商品卡資訊。

* 點擊商品卡右側的**刪除**以刪除商品卡。

* 點擊商品卡右側的**置頂**以將商品卡置頂。

* 拖曳以調整商品卡片的順序。


（可選）在左側導覽窗格中，點擊**Live control**。在商品卡片的選單下，您可以執行以下操作。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/859e93898702476fabe95e3b8fd99052~tplv-goo7wpa0wc-image.image) </span>


* 點擊**Pin product**，即可將商品卡片釘選至選單頂端，並於控制台及觀看頁面顯示，同時在觀看頁面以浮動視窗展示商品卡片。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">請確保產品卡片已配置產品圖片。   </div>
   

* 點擊**Unpin product**，即可將商品卡片恢復至原始位置，並於控制台及觀看頁面顯示，且停止在觀看頁面以浮動視窗展示商品卡片。

* 點擊**List**或**Unlist**，即可在觀看頁面即時上架或下架商品卡片。

* 點擊**Pin**圖示，將商品卡片釘選至選單頂端，並於控制台及觀看頁面顯示。

* 拖曳以調整商品卡片在控制台及觀看頁面的顯示順序。

* 根據商品標題或序號搜尋商品卡片。您可以對商品標題進行模糊搜尋。


<span id="bd977a0e"></span>
### 在 Shopify 商品庫中隱藏特定商品

要在 Shopify 商品庫中隱藏特定商品，您必須在 Shopify 新增特定商品 metafield 並設為 True。

完成以下步驟以新增商品 metafield。


1. 在 Shopify 商店的左側導覽窗格中，點擊**Settings**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/72c09822780247e6a47feea143046604~tplv-goo7wpa0wc-image.image) </span>

2. 在左側導覽窗格中點擊**Metafields and metaobjects**，然後點擊**Products**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe5942dbdf284be4a9571f7f2eb3f7ea~tplv-goo7wpa0wc-image.image) </span>

3. 在右上角點擊**Add definition**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31fb82011ab94018853e139082cd71d6~tplv-goo7wpa0wc-image.image) </span>

4. 選擇**Other** \> **True or false**作為資料類型，並輸入**forbid_show_in_byteplus_live**作為名稱。請確保**Namespace and key**欄位值以`custom.`開頭。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c2f631d91c9a417db06d83e60ed1c530~tplv-goo7wpa0wc-image.image) </span>


若 Shopify 商店中的商品已將**forbid_show_in_byteplus_live**欄位設為**True**，則該商品將不會顯示於新增至 BytePlus Live 的 Shopify 商品庫中。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e71c99b925654c8e8d4c8ca6671df8c9~tplv-goo7wpa0wc-image.image) </span>

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在 Shopify 中修改欄位值後，可能會有最多一分鐘的延遲，才能從 Shopify 產品庫取得最新產品列表。</div>


<span id="230f07c9"></span>
### 為 Shopify 商品設定直連網址

若已啟用直連網址功能，且您已為每個商品的各環境設定多個直連網址（請參閱[Step 2: 設定商品選單](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-chan-pin-ka-pian-zh-TW#0b085a3d)），即可依下方方式在 Shopify 新增商品 metafield，為每個環境設定 Shopify 商品的直連網址。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/15d642b7ad4e4a6ca0fb9b5bad485a94~tplv-goo7wpa0wc-image.image) </span>

完成以下步驟以新增直連網址 metafield。


1. 在 Shopify 商店的左側導覽窗格中，點擊**Settings**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/72c09822780247e6a47feea143046604~tplv-goo7wpa0wc-image.image) </span>

2. 在左側導覽窗格中點擊**Metafields and metaobjects**，然後點擊**Products**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe5942dbdf284be4a9571f7f2eb3f7ea~tplv-goo7wpa0wc-image.image) </span>

3. 在右上角點擊**Add definition**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31fb82011ab94018853e139082cd71d6~tplv-goo7wpa0wc-image.image) </span>

4. 選擇**Single line text**作為資料類型，並輸入`direct_url_1`作為第一個環境的名稱。請確保**Namespace and key**欄位值以`custom.`開頭。如有需要，請依各環境重複此步驟，分別設定`direct_url_2`至`direct_url_5`。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a5cc66ff0c31473bbbc6cb8daedd796f~tplv-goo7wpa0wc-image.image) </span>

5. 現在您可以前往商品頁面，於每個商品的對應 metafield 輸入各環境的直連網址。

## 深入了解

<span id="f4985fe1"></span>
### 將您的系統整合至 BytePlus Live

在將自有系統的商品庫新增至 BytePlus Live 的直播間前，您必須依照規範開發下列 API，以整合您的系統與 BytePlus Live。

如果您對整合有任何疑問，請聯繫 BytePlus Live 技術支援。

<span id="32f5a471"></span>
#### 流程

如果您的系統中產品數量超過指定的上限，建議您聯繫 BytePlus Live 技術支援，將您的 BytePlus 帳戶加入 allowlist。否則，當您調用此 API 時將不會返回任何產品。

根據您的帳戶是否在 allowlist 上，流程會有所不同。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/66eb68e3023b4fd195f2d92f77cffb5e~tplv-goo7wpa0wc-image.image) </span>


1. 您需要在 BytePlus Live 控制台上配置自有系統的請求 URL。此 URL 用於接收 API 調用。

2. BytePlus Live 控制台會將已配置的請求 URL 發送至 BytePlus Live 伺服器。

3. BytePlus Live 伺服器會將 URL 配置狀態返回給 BytePlus Live 控制台。

4. 您在 BytePlus Live 控制台或整合了 iOS 或 Android 版 Live Streaming SDK 的應用中點擊**Add from library**。

   如果您的帳戶已在 allowlist 上，BytePlus Live 伺服器將不會調用此 API。

   如果您的帳戶未在 allowlist 上，流程如下：

   1. 當您首次在 BytePlus Live 控制台或應用中點擊**Add from library**時，BytePlus Live 伺服器會調用此 API 以載入產品。

   2. 您的伺服器會返回系統中的所有產品。

   3. BytePlus Live 伺服器會將這些產品返回給 BytePlus Live 控制台或應用。

5. 您在 BytePlus Live 控制台或整合了 iOS 或 Android 版 Live Streaming SDK 的應用中的**Add from library**對話框內輸入關鍵字。

   如果您的帳戶已在 allowlist 上，流程如下：

   1. BytePlus Live 會在 BytePlus Live 伺服器上搜尋名稱包含該關鍵字的產品。

   2. BytePlus Live 會調用此 API，在您的系統中搜尋名稱包含該關鍵字的產品。

      <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="2">warning      </div>
      

      <div data-tips="true" data-tips-type="warning" data-wrapper-indent="2">為避免超時或其他 API 錯誤，建議 API 回傳結果不超過 5000 筆。      </div>
      

   3. 您的伺服器會將搜尋結果返回給 BytePlus Live 伺服器。

   4. BytePlus Live 伺服器會將搜尋結果返回給 BytePlus Live 控制台或應用。

      如果您的帳戶未在 allowlist 上，BytePlus Live 會在步驟 4 返回的產品中搜尋名稱包含該關鍵字的產品，然後在 BytePlus Live 控制台或應用中顯示搜尋結果。
