你可以在直播間新增敏感詞，以避免出現這些詞語。


* 包含敏感詞的評論僅對發送者可見。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">此功能適用於聊天互動與問答菜單。   </div>
   

* 觀眾與嘉賓無法輸入包含敏感詞的暱稱。


<span id="7c495438"></span>
## 先決條件

需有 BytePlus 帳戶或具備 Producer \> Edit 權限的 IAM 使用者。如需瞭解如何新增 IAM 使用者，請參閱[管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

<span id="a26dda79"></span>
## 操作流程


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊以開啟直播間。

3. 於左側導覽窗格，點擊**Producer** \> **敏感詞**。

4. 點擊**新增敏感詞**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e253c119d3934bedb74ace24797d8d3a~tplv-goo7wpa0wc-image.image) </span>

5. 在**新增敏感詞**對話框中，透過以下方式新增一個或多個敏感詞，然後點擊**確定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a24ca84215004639868d064e8c6dda1e~tplv-goo7wpa0wc-image.image) </span>

   * 直接在對話框中輸入敏感詞。新增多個敏感詞時，請以逗號（,）或按 Enter 鍵分隔。

   * 點擊**下載範本**，依範本指示新增敏感詞，並點擊**匯入**以上傳更新後的範本。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">由於逗號（,）用作分隔符，單一敏感詞不可包含逗號。   </div>
   

6. （可選）開啟**模糊匹配**開關，然後：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/33cb134161aa4d6ab41073d87268f590~tplv-goo7wpa0wc-image.image) </span>

   * 敏感詞不區分大小寫。例如，若敏感詞為**abc**，則包含**Abc**的評論與暱稱也會被封鎖。

   * 匹配敏感詞時，評論與暱稱中的空格及以下特殊字元會被忽略：

      `\* # @ ., ? !: ; “ ” ‘’ () — \- … / ' _ + | & % $ ^ ~ < \> = ～ [ ] \ · ¥ { } ！｜「 」（ ）〈 〉：【 】、；，。"《 》 ？``

      例如，若敏感詞為**abc**，則包含\*\*a b@c\*的評論與暱稱也會被封鎖。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">若需將更多特殊字元加入匹配規則，請聯絡您的業務代表。      </div>
      

   * 你新增的敏感詞不可包含空格或上述特殊字元。例如，若新增敏感詞時輸入**a b@c\*，則實際新增的敏感詞為**abc\*\*。

7. （可選）開啟**電話號碼封鎖**開關，然後：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/002d596b9a5e471796a2a22d25c7cc00~tplv-goo7wpa0wc-image.image) </span>

   * 包含電話號碼的評論僅對發送者可見。

   * 觀眾與嘉賓無法輸入包含電話號碼的暱稱。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">目前，此功能僅適用於新加坡、日本、韓國、印尼、泰國及中國的電話號碼。   </div>
   

8. （可選）在搜尋框中輸入值以搜尋特定敏感詞。支援模糊搜尋。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ffd46ee2b71e48a7b4ece59224adafe2~tplv-goo7wpa0wc-image.image) </span>

9. （可選）於**操作**欄點擊**刪除**以刪除敏感詞。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b5d00a0cd5df4ed1a018875a6ee86e5e~tplv-goo7wpa0wc-image.image) </span>
