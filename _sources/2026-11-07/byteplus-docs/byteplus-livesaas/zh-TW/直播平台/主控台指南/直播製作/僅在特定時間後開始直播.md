若要排程直播並防止其在指定時間前啟動，可啟用直播開始時間功能。本指南提供針對新建及現有直播間配置此功能的逐步操作說明。

<span id="b80f784c"></span>
## 主持人所見

直播頁面會顯示預定開始時間的倒數計時器。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de233eebfecf4cf68238fe0473cfa9f7~tplv-goo7wpa0wc-image.image) </span>

<span id="ebcd4f9e"></span>
## 先決條件

您必須擁有 BytePlus 帳戶或 IAM 使用者。若要在現有直播間啟用此功能，IAM 使用者必須具備 Producer \> Edit 權限。如需新增 IAM 使用者的詳細資訊，請參閱 [管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

<span id="7a8be3e0"></span>
## 操作流程

您可透過以下方式之一啟用此功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">您無法啟用或停用此功能，或於直播進行期間修改直播開始時間。</div>


<span id="0e9cfdf1"></span>
### 方法一：建立已啟用此功能的直播間


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在 **直播間**頁面，點擊**建立直播間**。

3. 於**建立直播間**頁面，選擇建立單一直播間或多個直播間。

   * 建立直播間：於**建立直播間**標籤頁，開啟**開始時間**開關。按需配置其餘設定，然後點擊**儲存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2e843fe975f422d9692c97ef726fbde~tplv-goo7wpa0wc-image.image) </span>

   * 一次建立多個直播間：於**建立多個直播間**標籤頁，點擊**新增直播**或**新增錄製**。開啟**於開始時間後啟動直播**開關。按需配置其餘設定，然後點擊**儲存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd1037fd65894a289ad3002d6e578723~tplv-goo7wpa0wc-image.image) </span>


<span id="9f5750b8"></span>
### 方法二：在現有直播間啟用此功能


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 於直播間列表中，點擊直播間以開啟。

3. 在左側導覽窗格，點擊**Producer** \> **基本資訊**。

4. 於**基本設定**區域，開啟**開始時間**開關，然後點擊**儲存**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6c6a63933ab549d2af25edf298b0f74f~tplv-goo7wpa0wc-image.image) </span>
