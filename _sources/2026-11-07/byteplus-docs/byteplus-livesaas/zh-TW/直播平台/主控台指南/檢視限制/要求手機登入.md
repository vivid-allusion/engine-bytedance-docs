為了限制對您的直播的存取，您可以要求觀眾以手機號碼登入。這可確保只有經過驗證的使用者才能加入。本指南提供啟用手機號碼登入限制的步驟，並可選擇性地設定允許名單，以進行更細緻的存取控制。


1. 登入[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 從直播列表中開啟您的直播。

3. 點擊**Producer** \> **Viewing Restrictions**。

4. 選擇**Phone number**。

5. （可選）啟用**Whitelist mode**，以限制只有允許名單上的觀眾可以存取。

   * 點擊**Add**，手動將觀眾加入允許名單。

   * 點擊**Batch import from Excel**，批量上傳觀眾至允許名單。

6. 確認後點擊**Save**。
