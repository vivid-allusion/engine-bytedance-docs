為了管控直播串流的存取權限，你可以透過自訂驗證方式，將你自己的帳號系統整合至 BytePlus Live。這要求觀眾必須先透過你的系統登入，才能觀看內容或進行互動。本指南詳細說明兩種實作方案：一種是將未經驗證的使用者導向你的登入頁面，另一種則允許已預先驗證的使用者透過帶有驗證參數的 URL 直接進入。內容涵蓋端到端流程、所需參數，以及主控台設定步驟。

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">使用此功能前，請確保您擁有開發者資源。</div>


<span id="bec9a05f"></span>
## 先決條件

你必須擁有 BytePlus 帳號或具備 Producer \> Edit 權限的 IAM 使用者。如需新增 IAM 使用者的詳細資訊，請參閱[管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

<span id="3a98c42f"></span>
## 使用場景


* [方案 A](https://docs.byteplus.com/docs/byteplus-livesaas/zi-ding-yan-zheng-deng-ru-zh-TW#71eea3ee)：此方案適用於有保密需求的直播場景或產品推廣場景。若使用者未登入即進入直播間，可將其導向你自有帳號系統的登入頁面。使用者登入你自有帳號系統後，可被導向觀看頁面，進行直播觀看、發送評論等操作。

* [方案 B](https://docs.byteplus.com/docs/byteplus-livesaas/zi-ding-yan-zheng-deng-ru-zh-TW#29214805)：此方案適用於希望使用者登入你自有帳號系統後，避免再次登入的場景。使用者登入你的帳號系統後，可點擊相應的 URL 進入直播間。此 URL 為附加所需驗證參數的觀看頁面地址。


<span id="a5b00644"></span>
## 注意

若你的直播間透過 iframe 嵌入至自有頁面，必須透過新增別名紀錄（CNAME 紀錄）自訂觀看頁面的網域名稱，確保你的頁面網域名稱與觀看頁面網域名稱一致。這有助於避免瀏覽器禁止寫入第三方 Cookie 的問題。如需新增 CNAME 紀錄，請聯絡你的業務代表。

<span id="5dd85fad"></span>
## 流程

<span id="71eea3ee"></span>
### 方案 A

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a96b8fae4fd04bcc827b6c5d3f8b2ef8~tplv-goo7wpa0wc-image.image) </span>


1. 使用者訪問 BytePlus Live 的觀看頁面。

2. BytePlus Live 帶有`ActivityId`、`Timestamp`、`RedirectUrl`等參數，將使用者導向你自有帳號系統的登入頁面（在[操作流程](https://docs.byteplus.com/docs/byteplus-livesaas/zi-ding-yan-zheng-deng-ru-zh-TW#447f1c83)配置的登入連結）。

   * 若驗證類型設為**Custom**：使用者訪問觀看頁面後，BytePlus Live 帶上述參數將使用者導向你自有帳號系統的登入頁面。

   * 若評論限制設為**Custom**：使用者在觀看頁面發送評論或參與抽獎等互動活動時，BytePlus Live 帶上述參數將使用者導向你自有帳號系統的登入頁面。

3. 使用者在系統登入頁面登入你自有帳號系統。

4. 您的自有帳號系統在驗證用戶身份後，使用相關參數計算簽名。

5. 你自有帳號系統將 `UserId`、`Nickname`、`Timestamp`、`Sign` 等參數（以及其他參數）一併帶入，重定向至 BytePlus Live 的驗證頁面（`RedirectUrl`）。

6. BytePlus Live 會在驗證頁面上驗證簽名（`Sign` 值），以判斷是否允許用戶觀看直播、發送評論等。

7. 若驗證成功，即 BytePlus Live 計算出的簽名與您自有帳號系統攜帶的 `Sign` 值相同，則用戶即可觀看直播、發送評論等。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若驗證未通過，將顯示自定義驗證失敗頁面。   </div>
   

<span id="29214805"></span>
### 方案 B

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5ab6141b635541edab7cea45d39ef37c~tplv-goo7wpa0wc-image.image) </span>


1. 用戶在系統登入頁面登入您的自有帳號系統。

2. 您的自有帳號系統在驗證用戶身份後，使用相關參數計算簽名。

3. 將 `Sign`、`Nickname`、`UserId`、`Timestamp` 等參數以及其他參數作為驗證參數，添加至觀看頁面地址。例如，`https://live.byteplus.com/xxx/xxx?Sign=xx&Nickname=xx&UserId=xx&Timestamp=xxx`。

   您也可以將 `Sign`、`Nickname`、`UserId`、`Timestamp` 參數添加至您的 cookies。然後，用戶在訪問觀看頁面地址後即可直接觀看直播、發送評論等。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若 <code>extra</code> 和 <code>forceCheck</code> 參數非必需，您可忽略步驟 4 至 6。否則，必須將其作為驗證參數添加至觀看頁面地址，然後按照步驟 4 至 6 操作。   </div>
   

   以下是將參數添加至 cookies 的範例。

   ```Plain
   Cookie: Sign=98d3e2f51c0a8a452be60484aed15ca0; Nickname=ZGFkYQ%3D%3D; Timestamp=1714307542226; UserId=222
   ```
   

4. 用戶攜帶上述驗證參數訪問觀看頁面地址。

5. BytePlus Live 根據驗證參數中的資訊驗證簽名（`Sign` 值），以判斷是否允許用戶觀看直播、發送評論等。

6. 若驗證通過，即 BytePlus Live 計算出的簽名與驗證參數中的 `Sign` 值相同，則用戶即可觀看直播、發送評論等。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若驗證類型 設為 <strong>Custom</strong> 且驗證未通過，將顯示自定義驗證失敗頁面。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">若評論限制設為自定義\*\*，且驗證未通過，\*\*自定義身份驗證失敗頁面將不顯示。用戶可在觀看頁面觀看直播、預告及回放，無需登入直播間，但無法發送評論或參與抽獎等互動活動。   </div>

## 操作流程


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊開啟直播間。

3. 在左側導航欄，點擊 **Producer** \> **觀看限制**。

4. 將驗證類型或評論限制設為 **Custom**，並完成以下配置。

   * 將驗證類型設為 **Custom**：用戶必須登入您的自有帳號系統後，才能進入直播間觀看直播等。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90c6142a0b3a4107add065e34f8b1053~tplv-goo7wpa0wc-image.image) </span>

   * 將評論限制設為 **Custom**：用戶必須登入您的自有帳號系統後，才能發送評論或參與抽獎等互動活動。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/df19b2bc674f42928af2d888ec04fe60~tplv-goo7wpa0wc-image.image) </span>
