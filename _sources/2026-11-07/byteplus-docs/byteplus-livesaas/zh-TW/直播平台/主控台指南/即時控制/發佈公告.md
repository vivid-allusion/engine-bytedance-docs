為了與觀眾分享重要資訊，例如內容預覽或促銷活動，您可以在直播期間發送公告。本指南提供從 BytePlus Live 控制台及網頁瀏覽器中的直播頁面創建、配置及發送公告的逐步操作說明。

<span id="f6f52e05"></span>
## 先決條件


* 請確保已新增互動工具選單。如需更多資訊，請參閱 [設定互動工具選單](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-hu-dong-qu-yu-zh-TW#f1b04790)。

* 在控制台發送公告

   請確保您擁有 BytePlus 帳戶或具有 Live control \> Edit 權限的 IAM 使用者。

* 在網頁瀏覽器的直播頁面發送公告

   * 建議您使用符合直播指定要求的裝置及瀏覽器，以確保直播體驗順暢。如需更多資訊，請參閱 [啟動直播的環境要求](https://docs.byteplus.com/docs/byteplus-livesaas/cong-nin-de-wang-ye-liu-lan-qi-jin-xing-zhi-bo-zh-TW#d66d12ba)。

   * 若您透過控制台進入直播頁面，請確保您擁有 BytePlus 帳戶或具有 Live control \> Edit 權限的 IAM 使用者。

   * 若您使用連結進入直播頁面且無需登入，則發送公告不需控制台權限。


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">如需新增 IAM 使用者的詳細資訊，請參閱 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW">管理使用者、組織與角色</a>。</div>


<span id="b7acdf4e"></span>
## 操作流程

<span id="73b6f661"></span>
### Step 1: 進入公告對話框


* 控制台

   1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

   2. 在直播間列表中，點擊以開啟直播間。

   3. 於 **Live control** 頁面，於互動工具選單下點擊 **Announcement**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ae2b47823cbe406094814565887f0ca6~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">為提升觀看體驗，建議您開啟右下角的 <strong>Display menu</strong> 開關，於觀看頁面顯示選單。      </div>
      

   4. 在出現的對話框中點擊 **Create announcement**。

* 網頁瀏覽器中的直播頁面

   1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

   2. 選擇 **Web browser** 作為直播方式並進入直播頁面。如需更多資訊，請參閱 [從您的網頁瀏覽器進行直播](https://docs.byteplus.com/docs/byteplus-livesaas/cong-nin-de-wang-ye-liu-lan-qi-jin-xing-zhi-bo-zh-TW)。

   3. 在互動工具標籤頁中，點擊 **Announcement**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ceab1a63e756434195a707df7acb1837~tplv-goo7wpa0wc-image.image) </span>


<span id="c50d5ca6"></span>
### Step 2: 配置並發送公告

在控制台及網頁瀏覽器的直播頁面操作方式相似。本步驟以控制台為例。


1. 在出現的 **Announcement** 對話框中，輸入公告標題及內容，然後點擊 **Save**。

   若這不是直播間的第一則公告，請點擊 **Create**，然後輸入公告標題及內容。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0c9b08119b1f40729ae1aa3ac4244b9f~tplv-goo7wpa0wc-image.image) </span>

2. 點擊 **Add to send area**，再於互動工具選單下點擊 **Send**，將公告發送至觀看頁面。

   若您有多則未發送公告，請先選擇左側的公告，再點擊 **Add to send area**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4c5c7c3af4084d27967881c37a7f4b48~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">或者，在主控台的互動工具選單中點擊<strong>公告</strong>，於對話框中選擇所需公告，然後點擊<strong>發送</strong>。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在直播頁面，於<strong>公告</strong>對話框中選擇公告並點擊<strong>發送</strong>。   </div>
   

3. （可選）您可以複製、預覽、編輯或刪除未發送公告，也可複製或刪除已發送公告。

4. （可選）在互動工具選單下，您可以撤回或查看已發送公告。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/00e99e6a9b23424799c08d0482e92d79~tplv-goo7wpa0wc-image.image) </span>
