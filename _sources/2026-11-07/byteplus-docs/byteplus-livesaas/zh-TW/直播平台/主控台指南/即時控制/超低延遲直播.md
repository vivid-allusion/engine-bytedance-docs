為了將直播延遲降低至 1\-2 秒，以適用於高互動場景（如電商或線上課程），你可以在 BytePlus Live 啟用超低延遲功能。本文檔說明超低延遲串流的優勢，並提供針對新建或現有直播間啟用該功能的逐步操作指引。

<span id="c0e8a860"></span>
## Context

隨著「直播+」模式在各行業的快速發展，電商、線上課程、體育賽事、互動娛樂等多種形式的互動直播越來越普遍。隨著用戶對直播實時互動需求的提升，端到端毫秒級延遲的時代已經到來。超低延遲直播串流能顯著提升電商、線上課程等直播場景中主辦方與觀眾的體驗。延遲越低，直播的即時性與互動性就越強。因此，降低延遲對於提升直播體驗至關重要。

<span id="cd0cd3c9"></span>
## Scenarios

超低延遲直播串流非常適合以下需要低網路延遲及強互動的直播場景。


* 電商：主辦方在上架商品後可即時看到觀眾評論及銷售反饋，從而提升主辦方與觀眾的互動，以及商品轉換率。

* 線上課程：若學生對老師講解的內容有疑問並在聊天區提問，老師可即時回應，從而提升教學品質。

* 體育賽事：觀眾可即時獲得場館動態更新。

* 互動娛樂：觀眾送禮時，主辦方可即時回饋，從而增強主辦方與觀眾的互動。

* 醫療診斷：在醫學網路研討會或醫療直播場景中，觀眾可即時收到回覆或診斷。


<span id="1e6289dc"></span>
## Prerequisites


* 需具備 BytePlus 帳戶或擁有 Live control \> Edit 權限的 IAM 使用者。如需了解如何新增 IAM 使用者，請參閱 [管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

* 使用以下瀏覽器的觀眾可觀看超低延遲直播串流：

   * Google Chrome

   * Safari

   * Lark

   * WeChat

<span id="438a3e77"></span>
## Notes


* 與普通延遲直播相比，超低延遲直播的觀看時長以 1:2 比例計算。例如，若有 1,000 名觀眾，每人觀看 30 分鐘的普通延遲直播、預覽或回放，以及 20 分鐘的超低延遲直播，則總共使用 70,000 分鐘（1,000x30+1,000x20x2）的觀看時長。

* 目前無法透過拉流播出方式拉取超低延遲直播串流。

## Procedure

你可以透過以下兩種方式啟用超低延遲功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在直播過程中無法啟用或停用超低延遲功能。</div>


<span id="05ea83b2"></span>
### 方法一：新建超低延遲直播間


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在 **直播間**頁面，點擊 **新建直播間**。

3. 於 **新建直播間**頁籤的 **新建直播間**頁面，選擇 **超低延遲**作為直播延遲類型。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1541020d106648b880197745219aa65e~tplv-goo7wpa0wc-image.image) </span>

4. 按指引完成其他配置，並點擊 **保存**。


<span id="438f2c1b"></span>
### 方法二：在現有直播間啟用超低延遲功能


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊一個直播間以開啟。

3. 在播放器介面上的**串流方式**標籤頁，點擊**管理直播來源**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cc836721eed3407eaeaf48cae3bf2c19~tplv-goo7wpa0wc-image.image) </span>

4. 在出現的**管理直播來源**對話框中，開啟一個或多個直播來源的**超低延遲**開關，以啟用這些來源的超低延遲功能。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5297e47a59fd4cf987d7f7c98e0bd5c8~tplv-goo7wpa0wc-image.image) </span>

5. 點擊**確認**。
