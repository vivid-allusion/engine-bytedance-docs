本主題說明如何從您的網頁瀏覽器啟動直播。此直播方式操作簡便，無需安裝任何客戶端或工具，適用於單人主播。

<span id="4db24b10"></span>
## 限制

此方法僅支援 PC 平台，且不適用於 H5 頁面。

<span id="f0338064"></span>
## 先決條件

需有 BytePlus 帳戶或具備 Live control \> Edit 權限的 IAM 使用者。如需瞭解如何新增 IAM 使用者，請參閱 [管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

<span id="d66d12ba"></span>
## 啟動直播的環境要求


* 為順利使用基本功能（如攝影機、麥克風、分享、互動工具、聊天及觀眾列表）並獲得流暢的直播體驗，建議您使用符合以下條件的裝置。

   * 記憶體：8 GB 或以上

   * CPU：Core i3 或以上

   * 顯示卡：整合型顯示卡

* 若需使用進階功能（如視訊聊天、美顏 AR 及 AI 降噪），為獲得流暢的直播體驗，建議您使用符合以下條件的裝置。

   * 記憶體：8 GB 或以上

   * CPU：Core i5 或以上

   * 顯示卡：獨立顯示卡（具備 4 GB 顯示記憶體）

* 建議瀏覽器及版本：Google Chrome 瀏覽器，版本 96.0.4664 或以上。

* 建議網路頻寬：上傳及下載頻寬 5 Mbps 或以上。點擊 [此處](https://www.speedtest.net/)測試您的網路頻寬。

* 請檢查目前裝置是否開啟過多瀏覽器分頁，以避免因瀏覽器效能消耗過多而導致直播異常。

* 建議您在安靜環境下進行直播，以便觀眾能清楚聽到您的聲音。


<span id="0593e5fe"></span>
## 注意

直播期間除非必要，請勿更換音訊輸入裝置，否則可能導致觀看頁面出現聲音中斷或突然消失。

## 操作流程


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊開啟直播間。

3. 於 **Live control** 頁面，於播放器下方的 **Broadcast method** 標籤中點擊 **Web browser**。

4. （可選）點擊 **設定**。在出現的 **設定**對話框中，開啟開關以在直播頁面顯示對應功能。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a282b36f730d4f73b4b907be0ca05a16~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">僅當直播間新增互動工具選單後，<strong>互動工具</strong>欄位才會顯示。   </div>
   

5. 您可根據需求以以下任一方式進入直播頁面。

   * 點擊 **前往直播頁面**。

   * 點擊 **點擊複製連結以啟動直播**，複製連結並發送給對應主播。主播即可使用該連結進入直播頁面，無需登入。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">BytePlus Live 提供 API <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-getwebpushliveclientapi-zh-TW">GetWebPushLiveClientAPI</a>，可取得直播間直播頁面的 URL，讓主持人無需登入即可從網頁瀏覽器啟動直播。您可先於 BytePlus Live 控制台建立直播間，待主持人需要直播時，再呼叫<code>GetWebPushLiveClientAPI</code>取得 URL。      </div>
      

6. 在出現的 **測試您的裝置**對話框中，選擇您的攝影機及麥克風。當攝影機、麥克風、網路及瀏覽器檢測正常後，點擊 **開始直播**。

   您也可於 **選擇攝影機**下拉列表中選擇 **OBS Virtual Camera**，將 OBS 資源同步至直播間。音訊同步功能不支援。如需更多資訊，請參閱 [如何使用 OBS 虛擬攝影機？](https://docs.byteplus.com/docs/byteplus-livesaas/zhi-bo-chang-jian-wen-ti-zh-TW#45b1e9c3)。

      * 將觀眾靜音或取消靜音。將滑鼠移至問題或回覆旁的省略號圖示，並選擇**靜音**以將發送者靜音。被靜音的觀眾無法發佈或回覆問題。若要取消靜音，將滑鼠移至該觀眾發送的問題或回覆旁的省略號圖示，並選擇**取消靜音**。

         <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="3">tip         </div>
         

         <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">觀眾會根據其 UID 被靜音，UID 會因登入方式而異。例如，你將僅以暱稱登入直播間的觀眾靜音。該觀眾隨後選擇以手機號碼登入直播間。如此一來，該觀眾的 UID 與被靜音的 UID 不同，並可發佈及回覆問題。         </div>
         

      * 點擊文字框上方由左數第二個圖示，可禁止觀眾發佈問題或允許觀眾發佈問題。

      * 點擊文字框上方由左數第三個圖示，可啟用或停用人工審核功能。啟用此功能後，問題及回覆僅對發送者可見。點擊問題或回覆旁的 **√** 以核准。核准後，該問題或回覆將於觀看頁面對所有人可見。

      * 點擊**匯出資料**圖示，將問答資料匯出至本地儲存。

      * 點擊**清除留言**圖示，清除觀看頁面的問答區。

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">請確保已新增問答選單。有關如何新增選單，請參閱<a href="https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-q-a-qu-yu-zh-TW">管理 Q&A 區域</a>。      </div>
      

   * 在協同主持標籤頁中，邀請嘉賓加入協同主持。如需更多資訊，請參閱[開始與來賓共同主持](https://docs.byteplus.com/docs/byteplus-livesaas/kai-shi-yu-lai-bin-gong-tong-zhu-chi-zh-TW)。

   * 在觀眾列表標籤頁中，查看觀眾資訊。
