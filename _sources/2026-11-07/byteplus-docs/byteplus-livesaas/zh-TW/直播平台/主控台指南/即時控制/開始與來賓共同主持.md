為了打造更具互動性和吸引力的直播，您可以使用協同直播功能，邀請最多 25 位來賓加入您的直播。本指南為主持人提供詳細操作說明，包括如何啟動協同直播、邀請來賓、管理不同視窗佈局，以及控制參與者權限。同時也說明演示者和來賓在直播期間可使用的具體功能。

<span id="Before you start"></span>
## 先決條件


* 主持人必須擁有 BytePlus 帳戶，或是具有 Live control \> Edit 權限的 IAM 使用者。如需新增 IAM 使用者的詳細資訊，請參閱 [管理使用者、組織與角色](https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-shi-yong-zhe-zu-zhi-yu-jue-se-zh-TW)。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">主持人若是透過網址在網頁瀏覽器進入直播頁面，則無需此前置條件，可直接進入無需登入。   </div>
   

* 我們建議主持人與來賓在協同直播期間，使用符合 [從網頁瀏覽器進行直播](https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#environmental-requirements-to-start-a-live-stream) 所述要求的裝置與瀏覽器。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">來賓在聯合主持期間可使用整合型或獨立顯示卡。   </div>
   

<span id="369ac5d3"></span>
## 角色


|角色 |說明 |
|---|---|
|主持人 |啟動聯合主持會議及直播的人員。主持人擁有完整控制權，包括設置主講人、鎖定來賓鏡頭，以及將來賓移出聯合主持會議。 |
|主講人 |聯合主持中的主要參與者。預設由主持人擔任主講人。主持人可隨時將來賓設為主講人，並可撤銷或轉移主講人角色。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">一場協同主持會議同時僅能有一位簡報者，且只有簡報者可以使用分享、白板或文件功能。</div><br> |
|來賓 |聯合主持會議中的參與者。 |


<span id="4f21ea9e"></span>
## 主持人

主持人可於直播開始前或開始後與來賓協同直播。


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 選擇 **網頁瀏覽器** 作為直播方式，並進入直播頁面。如需更多資訊，請參閱 [從您的網頁瀏覽器進行直播](https://docs.byteplus.com/docs/byteplus-livesaas/cong-nin-de-wang-ye-liu-lan-qi-jin-xing-zhi-bo-zh-TW)。

3. 點擊 **與來賓協同直播**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/689c7ad2fec34948a25ad0cd4b528604~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">來賓也可在聯合主持開始前被邀請，但僅能在聯合主持開始後加入。   </div>
   

4. 選擇主持人與來賓視窗的佈局。預設選擇「演示者視圖」。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/482851ca634d4284ae44ae4d26def8df~tplv-goo7wpa0wc-image.image) </span>

   * Focus 視圖：將演示者的攝影機畫面顯示為主畫面。此視圖適合單人演示。

      若主持人鎖定嘉賓的攝影機，主畫面將顯示該嘉賓的攝影機。

   * 演示者視圖：顯示演示者分享的內容，以及演示者的攝影機畫面作為主畫面。此視圖適用於演示者使用 **分享**、**白板** 或 **文件**功能時。

      如果主持人鎖定了來賓的攝影機，主畫面將會顯示該來賓的攝影機畫面以及簡報者正在分享的內容。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">只有當簡報者或被鎖定來賓的攝影機已開啟時，才會顯示其攝影機畫面。      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">顯示的攝影機畫面可以拖曳至所需位置。      </div>
      

   * Gallery 視圖：顯示多位參與者的攝影機畫面及演示者分享的內容。此視圖適合多方會議及多站點連線。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">來賓可自行選擇主持人及來賓視窗的版面配置。即使主持人更改版面配置，來賓所選的配置也不會被更改。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">直播開始後，觀看頁面的版面配置與主持端一致，但在焦點視圖下，主持人及來賓的視窗不會顯示於觀看頁面。   </div>
   

5. 邀請來賓。

   1. 點擊 **邀請來賓**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fa817f2751b944b79abae76ee2ef550c~tplv-goo7wpa0wc-image.image) </span>

   2. 在出現的 **邀請來賓**對話框中，選擇是否開啟 **密鑰**開關。預設情況下，該開關為開啟狀態。若開啟，來賓必須輸入密鑰才能加入協同直播。

      主持人也可點擊 **更新密鑰**，即時更新密鑰。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">在金鑰更新後，現有嘉賓可繼續協同主持，而新嘉賓必須使用更新後的金鑰才能加入。      </div>
      

   3. 點擊 **複製邀請資訊**，並將複製的資訊發送給欲邀請的來賓。來賓可使用 Chrome 瀏覽器加入協同直播。如需更多資訊，請參閱 [來賓](https://docs.byteplus.com/docs/byteplus-livesaas/kai-shi-yu-lai-bin-gong-tong-zhu-chi-zh-TW#98b43ebc)。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">複製的資訊包含活動 ID、直播間名稱、登入網址及協同主持金鑰。若金鑰開關關閉，複製的資訊中將不包含金鑰。      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">主持人亦可分別點擊以複製登入網址或金鑰。      </div>
      

6. 在協同直播列表中，根據需要執行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bca79f9ca9cc4e94a51c665b998349f5~tplv-goo7wpa0wc-image.image) </span>

   * 點擊 **全部靜音**，將除主持人與演示者外所有參與者的麥克風設為靜音。新加入的參與者在進入協同直播時也會被靜音。參與者可自行解除靜音。

   * 點擊來賓右側的攝影機圖示，要求來賓開啟攝影機，或直接關閉攝影機。來賓可根據收到的提示選擇是否開啟攝影機。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/25a5f06e9bd647838c15ac1bf8d7fc67~tplv-goo7wpa0wc-image.image) </span>

   * 點擊來賓右側的麥克風圖示，要求開啟或直接關閉來賓的麥克風。來賓可根據收到的提示選擇是否開啟麥克風。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/706d241798664e379c64653d894d3e6f~tplv-goo7wpa0wc-image.image) </span>

   * 點擊來賓右側的**更多**圖示以執行以下操作。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f31c73731503419186f02db8d8fc92db~tplv-goo7wpa0wc-image.image) </span>

      * 點擊**設為主講人**，將該來賓設為主講人。

         <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="3">tip         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">若未將任何嘉賓設為主講者，則主持人將成為主講者。         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">若主講者因突發狀況退出協同主持，主講者角色將自動回復為主持人。         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">當主講者變更時，系統會自動保存原主講者所分享的白板、文件及螢幕（包含整個螢幕、視窗及 Chrome 分頁）。若原主講者於同一協同主持會議中再次被設為主講者，可選擇繼續分享先前已分享的內容。         </div>
         

      * 點擊**撤銷主講人**，撤銷主講人角色。主持人也可點擊另一位來賓右側的**更多**圖示，並選擇**設為主講人**以更換主講人。

      * 點擊**更改名稱**以更改來賓的暱稱。

         <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="3">tip         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">暱稱不得超過 60 個字元。         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">主持人亦可點擊自身右側的 <strong>更多</strong> 圖示，並選擇 <strong>更改名稱</strong> 以修改自己的暱稱。         </div>
         

         * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="3">當主持人的暱稱變更時，會自動於控制台、觀眾頁面及直播頁面的聊天介面中更新。         </div>
         

      * 點擊**鎖定鏡頭**，將來賓的鏡頭鎖定在主畫面。

      * 點擊解鎖以解除來賓鏡頭的鎖定。若要鎖定其他來賓的鏡頭，主持人可點擊該來賓姓名旁的更多圖示，並選擇鎖定鏡頭。

      * 點擊**移除**以將來賓移出聯合主持。

   * 點擊**結束與來賓聯合主持**。所有來賓將自動退出聯合主持。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/db42c2a1d45540d78d8faea7a8a10c0e~tplv-goo7wpa0wc-image.image) </span>


<span id="b1185902"></span>
## 主講人

主講人可以是主持人，也可以是加入聯合主持的來賓之一。


* 主持人：若未設置來賓為主講人，則由主持人擔任主講人。

* 來賓：主持人可將來賓設為主講人。


主講人使用 Chrome 瀏覽器加入聯合主持後，可使用**分享**、**白板**或**文件**功能。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">僅主持人可作為主講者使用 <strong>白板</strong> 及 <strong>文件</strong> 功能。如需瞭解這些功能的使用方式，請參閱 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/gong-xiang-bai-ban-zh-TW">共享白板</a> 和 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/fen-xiang-wen-jian-yu-tu-pian-zh-TW">分享文件與圖片</a>。</div>


* <div data-tips="true" data-tips-type="tip">使用 <strong>分享</strong> 功能分享整個螢幕、視窗或 Chrome 分頁時，建議分享 Chrome 分頁以獲得同步音訊及更高畫質的觀看體驗。分享視窗時，建議不要將視窗最小化，以免影響觀眾體驗。</div>

## 來賓

來賓收到主持人邀請資訊後，可在 Chrome 瀏覽器地址列輸入登入網址，進入聯合主持登入頁面。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">嘉賓無法使用行動裝置加入協同主持。</div>


* <div data-tips="true" data-tips-type="tip">嘉賓可於主持人開始直播前或後加入協同主持會議。</div>



來賓可在聯合主持列表中點擊**更改名稱**圖示以更改暱稱。
