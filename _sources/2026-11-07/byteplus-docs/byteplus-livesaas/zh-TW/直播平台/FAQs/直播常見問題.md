## 從網頁瀏覽器進行直播

<span id="7ce8a98e"></span>
### 為什麼我無法在 Mac 上分享螢幕？

針對 macOS 10.15 或更高版本，請依照以下步驟手動允許 Google Chrome 錄製您的螢幕。


1. 點擊 Apple 圖示 \> **系統偏好設定**，然後點擊 **安全性與隱私**。

2. 在左側點擊 **螢幕錄製**。

3. 在右側勾選 **Google Chrome**。


<span id="3a18e309"></span>
### 為什麼我的 CPU 和記憶體使用率這麼高？


* 請確保您的電腦為 Windows PC，且至少擁有 8 GB 記憶體、Core i5 處理器、獨立顯示卡，以及 4 GB 顯示記憶體。否則，您的 CPU 和記憶體使用率可能會偏高，因為基於網頁的直播會大量消耗資源。

* 檢查您的 Google Chrome 是否已開啟 **可用時啟用硬體加速**開關，這可讓瀏覽器使用 GPU 資源。停用此選項可能會導致 CPU 使用率過高。


<span id="9c940194"></span>
### 我的音訊有時會對觀眾中斷。為什麼會發生這種情況？

這是在直播過程中切換音訊輸入裝置時發生，例如從藍牙耳機切換到電腦麥克風。為解決此問題，切換裝置後請重新整理直播頁面。

<span id="45b1e9c3"></span>
### 如何使用 OBS 虛擬攝影機？

[Open Broadcaster Software (OBS)](https://obsproject.com/)，支援 Windows、macOS 和 Linux，是一款免費且開源的錄影與直播軟體。如需更多資訊，請參閱 [OBS 使用者指南](https://obsproject.com/help)。

您可以在從網頁瀏覽器直播時選擇 [OBS 虛擬攝影機](https://obsproject.com/kb/virtual-camera-guide)作為您的攝影機。請依照以下步驟操作。

<span id="00c945b8"></span>
#### Step 1: 下載並安裝 OBS

點擊 [此處](https://obsproject.com/download)下載並安裝 OBS。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">請確保版本為 26.0 或更高。</div>


* <div data-tips="true" data-tips-type="tip">請確保您的電腦符合 OBS 的相應系統需求。如需更多資訊，請參閱<a href="https://obsproject.com/kb/system-requirements">系統需求</a>。</div>



<span id="e0b23598"></span>
#### Step 2: 設定伺服器 URL 與串流金鑰


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播間列表中，點擊以開啟直播間。

3. 在 **直播控制**頁面，於播放器下方的 **推流方式**標籤中點擊 **推流**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/066ac95fff29473b806bf6e1bcca0d84~tplv-goo7wpa0wc-image.image) </span>

4. 複製伺服器 URL 與串流金鑰。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">請妥善保管您的伺服器 URL 和串流金鑰。任何擁有伺服器 URL 和串流金鑰的人都可以將直播內容推送到您的直播間。   </div>
   

5. 開啟您的 OBS，並在左上角點擊 **檔案** \> **設定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/826f32e64d6340a28d0489136545d635~tplv-goo7wpa0wc-image.image) </span>

6. 在 **設定**對話框中，於左側導覽窗格點擊 **串流**，並選擇 **自訂...** 從 **服務**下拉清單中選擇。

7. 將第 2 步複製的伺服器 URL 與串流金鑰輸入至 **伺服器**與 **串流金鑰**欄位。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6883c5c7b1024a238d7d1cc39d42ecb4~tplv-goo7wpa0wc-image.image) </span>

8. 點擊 **確定**。


<span id="91dde1c2"></span>
#### Step 3: 新增來源

新增您希望觀眾在直播時觀看的來源。本範例中，新增顯示擷取來源以直播您的螢幕。


1. 在 OBS 底部的 **來源**區塊點擊 +。

2. 從下拉清單中選擇 **顯示擷取**。

3. 輸入名稱，並在出現的 **建立/選擇來源**對話框中點擊 **確定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21275bbaf230430dbdefdb1cd09e9360~tplv-goo7wpa0wc-image.image) </span>

4. （可選）在出現的對話框中，根據需求調整設定，例如是否擷取游標。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f01284a7d1364c828f08b7ebed9024ac~tplv-goo7wpa0wc-image.image) </span>

5. 點擊 **確定**。


<span id="1e594a77"></span>
#### Step 4: 使用虛擬攝影機將 OBS 串流至直播間


1. 在 OBS 右下角點擊 **啟動虛擬攝影機**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5d94897c1b974961a88089e0018c614c~tplv-goo7wpa0wc-image.image) </span>

2. 在網頁瀏覽器中前往您的直播間直播頁面。

3. 在出現的**測試您的裝置**對話方塊中，於**選擇攝影機**下拉清單中選擇**OBS Virtual Camera**。然後，直播間將顯示來自您的 OBS 來源的影片。然而，此方法不會串流來源的音訊。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/92e9f3d41f6a44819397396b7dafaac1~tplv-goo7wpa0wc-image.image) </span>

   若您進入直播頁面時未選擇 OBS Virtual Camera，也可以點擊**媒體設定**圖示，並將攝影機切換為 OBS Virtual Camera。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c12b507f55cd4326af5a4cb491bc9268~tplv-goo7wpa0wc-image.image) </span>
