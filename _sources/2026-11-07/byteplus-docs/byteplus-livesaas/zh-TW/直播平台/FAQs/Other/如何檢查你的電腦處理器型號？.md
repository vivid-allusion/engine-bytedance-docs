透過以下方式檢查 Windows 或 macOS 電腦的處理器型號：


* Windows

   1. 在 **This PC** 上按右鍵，然後選擇 **Properties**。

   2. 在開啟的頁面中找到你的處理器型號。

* macOS

   1. 點擊 Apple 標誌，然後選擇 **About This Mac**。

   2. 在 **Overview** 標籤頁中找到你的處理器型號。
