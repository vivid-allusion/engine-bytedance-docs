BytePlus Live 伺服器端 SDK 是一個用於簡化從您的伺服器與 BytePlus Live API 互動的程式庫。它封裝了常見的 API 調用、驗證，以及如產生臨時安全憑證等流程，使您能夠輕鬆將強大的直播功能整合到您的應用程式中，而無需複雜的程式設計。

<span id="39135b60"></span>
## 功能


* 伺服器端 SDK 封裝了 API 調用與回應，無需進行 API 驗證。

* 提供常見 API 的程式碼範例。

* 伺服器端 SDK 封裝了常見流程，例如產生臨時安全憑證。


<span id="878ffd42"></span>
## 安裝與使用

安裝伺服器端 SDK 後，您可以使用程式碼範例來調用 API。

目前，BytePlus Live 提供 Go SDK。
