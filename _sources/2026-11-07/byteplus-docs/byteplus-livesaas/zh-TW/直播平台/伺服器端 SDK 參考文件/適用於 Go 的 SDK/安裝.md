若要在 Go 應用程式中開始使用 BytePlus 服務，您必須先安裝官方 SDK。本指南提供新增 BytePlus SDK for Go 至您的開發環境所需的先決條件及 `go get` 指令。本主題說明如何安裝 Go SDK。

<span id="6eacdad8"></span>
## 先決條件


* 請根據您的作業系統下載並安裝 [Go](https://go.dev/)。建議使用 1.13.1 或更高版本。

* 請確保您的環境符合執行 Go 指令的需求。


<span id="4a8e2853"></span>
## 安裝 SDK

執行 `go get` 指令以安裝 SDK。

```Plain
go get -u github.com/byteplus-sdk/byteplus-sdk-golang
```
