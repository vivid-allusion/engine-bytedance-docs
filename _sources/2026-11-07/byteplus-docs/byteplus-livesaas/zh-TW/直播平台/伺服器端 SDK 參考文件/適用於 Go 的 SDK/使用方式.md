若要以程式方式管理您的 BytePlus LiveSaaS 活動，您可以使用 Go 的 SDK。本指南提供關鍵操作的範例程式碼，包括建立、更新及列出直播活動，以及取得臨時登入與 SDK 權杖。這些範例旨在協助您快速將 LiveSaaS 功能整合至 Go 應用程式。

<span id="f44e5318"></span>
## 先決條件


* BytePlus 帳戶或 IAM 使用者。如需更多資訊，請參閱[註冊 BytePlus 帳戶](https://docs.byteplus.com/en/byteplus-platform/docs/signing-up-your-account)或[管理 IAM 使用者與角色](https://docs.byteplus.com/byteplus-livesaas/docs/managing-iam-users-and-roles)。

* 您已取得驗證所需的 AccessKey ID（AK）與 Secret Access Key（SK）。

   * 若要取得 BytePlus 帳戶的 AK 與 SK，請前往[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/) \> 使用者檔案 \> **IAM** \> **金鑰管理**。

   * 若要取得 IAM 使用者的 AK 與 SK，請完成以下步驟：

      1. 前往[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/) \> 使用者檔案 \> **IAM** \> **身分管理** \> **使用者**。

      2. 找到該使用者後，點擊**檢視詳細資料**。

      3. 在**存取金鑰**分頁中，點擊**建立新存取金鑰**。


<span id="4111dac6"></span>
## 使用 SDK

開啟`BYTEPLUS-SDK-GOLANG`資料夾，並將您的 AK 與 SK 加入`example\demo_livesaas\demo_livesaas_test.go`檔案。

```Go
package demo_livesaas

import (
        "encoding/json"
        livesaas "github.com/byteplus-sdk/byteplus-sdk-golang/service/livesaas"
        "net/url"
        "strconv"
        "testing"
        "time"
)

const (
        testAk = "your AK"
        testSk = "your SK"
)
```
