為了構建自訂功能並回應用戶在直播播放器中的互動，您可以訂閱各種事件。本參考指南提供所有可用事件的完整清單，包括其觸發條件、型別簽名及資料負載。這些事件分為播放器相關操作（如播放、暫停及全螢幕切換）和非播放器相關互動（如留言、按讚及抽獎參與），讓您能打造完整互動體驗。

以下範例程式碼展示如何監聽事件。

```JavaScript
 window.addEventListener('message', (event) => {
        try {
          if (event.origin.includes('byteoc.com')) {
              const data = JSON.parse(event.data);
              switch (data.action) {
                case 'player.play': // Replace player.play with a specific event.
                  // 偵測到事件後執行自定義後續操作。
                  console.log('====== ', data.action, ' -- ', data.payload, ' ======' );
                  break
                default:
                  return;
              }
          }
        } catch (e) {
        }
      });
```

### player.vodConfigChange

用於從儲存位置（斷點）恢復播放的事件。

當播放器正在播放預覽或回放時，於下列情況會觸發此事件：


* 觀眾在電腦端關閉嵌入頁面。

* WebView 的`pagehide`事件被觸發，或觀眾於行動裝置手動拖曳進度條。


**型別**

```TypeScript
(VodInfo: { vid: string; currentTime: number; duration: number;}) => void
```


**參數**


|名稱 |類型 |描述 |
|---|---|---|
|VodInfo |\- |影片（預覽或回放）資訊。 |
|vid |string |影片 ID，即影片的唯一識別碼。 |
|currentTime |number |目前播放時間，單位為秒。 |
|duration |number |影片總長度。單位：秒。 |
