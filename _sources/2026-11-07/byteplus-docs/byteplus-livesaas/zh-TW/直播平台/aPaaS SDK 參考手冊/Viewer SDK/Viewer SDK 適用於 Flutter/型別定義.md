## BdlActivityConfig

```Dart
class BdlActivityConfig {
    final int activityId;
    final String token;
    final BdlViewerAuthMode authMode;
    final bool isPortrait;
}
```


加入直播間所需的資訊。

**輸入參數**


|名稱 |型別 |說明 |
|---|---|---|
|activityId |Integer |直播間的活動 ID。可透過呼叫 [ListActivityAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-listactivityapi-zh-TW)取得 ID。 |
|token |String |加入直播間所需的授權 token。可透過呼叫 [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-TW)取得 token。 |
|authMode |BdlViewerAuthMode |直播間的驗證模式。更多資訊請參見 [BdlViewerAuthMode](https://docs.byteplus.com/docs/byteplus-livesaas/xing-bie-ding-yi-1-zh-TW#415010a6)。 |
|isPortrait |Boolean |直播間是否為直式模式。<br><br><br>* `true`：直式模式。<br><br>* `false`：橫式模式。 |

## BdlViewerOpenUrlType

```Dart
enum BdlViewerOpenUrlType {
    pageHeaderAd,
    pageAd,
    floatingAd,
    cardAd,
}
```


嵌入連結所屬的內容類型。

**列舉值**


|型別 |值 |說明 |
|---|---|---|
|pageHeaderAd |0 |頁首廣告。 |
|pageAd |1 |頁面內廣告。 |
|floatingAd |2 |浮動廣告。 |
|cardAd |3 |商品卡片，包括顯示於選單下方及浮動商品卡片。 |


<span id="415010a6"></span>
## BdlViewerAuthMode

```Dart
enum BdlViewerAuthMode {
    public,
    custom,
}
```


直播間的驗證模式。

**列舉值**


|型別 |值 |說明 |
|---|---|---|
|public |0 |公開模式。觀眾以訪客身分加入直播間。在執行需用戶資訊的操作（如留言或按讚留言）前，必須輸入暱稱註冊。 |
|custom |1 |自訂模式。觀眾使用您的 App 的用戶資訊加入直播間，可直接留言及按讚留言。 |

<span id="b4ff383c"></span>
## BdLivePlayerConfig

```Dart
class BdLivePlayerConfig {
  bool liveAutoPlay = true;
  bool replayAutoPlay = true;
  bool previewAutoPlay = true;
  bool enablePIP = true;
  bool enablePIPWhenExit = true;
}
```


播放器配置。

**輸入參數**


|名稱 |型別 |說明 |
|---|---|---|
|liveAutoPlay |Boolean |若直播間處於**直播**狀態，是否自動播放直播影片。預設值：`true`。有效值：<br><br><br>* `true`：自動播放。<br><br>* `false`：不自動播放。 |
|replayAutoPlay |Boolean |若直播間處於**回放**狀態，是否自動播放回放影片。預設值：`true`。有效值：<br><br><br>* `true`：自動播放。<br><br>* `false`：不自動播放。 |
|previewAutoPlay |Boolean |若直播間處於**預覽**狀態且有預覽可用時，是否自動播放預覽影片。預設值：`true`。有效值：<br><br><br>* `true`：自動播放。<br><br>* `false`：不自動播放。 |
|enablePIP |Boolean |當觀眾離開直播間、點擊 URL（包含商品卡片及廣告中的嵌入連結）開啟新頁面，或將 App 移至背景時，是否啟用 PiP 功能。預設值：`true`。有效值：<br><br><br>* `true`：啟用。<br><br>* `false`：停用。 |
|enablePIPWhenExit |Boolean |僅於觀眾離開直播間時，是否啟用 PiP 功能。預設值：`true`。有效值：<br><br><br>* `true`：啟用。<br><br>* `false`：停用。 |
