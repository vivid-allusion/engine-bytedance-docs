Viewer SDK 為您的行動應用程式提供觀看直播、發表評論、與主持人互動等功能。透過整合 Viewer SDK，您可以快速在行動應用程式中嵌入具備豐富功能的直播間。

<span id="Features"></span>
## 功能

如需更多資訊，請參閱[SaaS 與 aPaaS 功能比較](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-comparison-between-saas-and-apaas)。

<span id="Scenarios"></span>
## **應用場景**

<span id="E-commerce"></span>
### 電子商務

協助中小型電子商務企業以輕量化方案快速開展直播業務，企業可輕鬆測試線上銷售的成效。

<span id="Marketing"></span>
### 行銷

協助企業推廣品牌並舉辦互動行銷活動。支援豐富的互動行銷組件，例如浮動廣告和頁內橫幅。支援全頁自訂，以符合品牌識別。

<span id="Finance"></span>
### 金融

為金融產品提供強大的客製化解決方案。支援以卡片方式展示產品，讓觀眾在觀看直播時購物，並可於直播期間發起語音聊天。
