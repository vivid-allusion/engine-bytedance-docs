## GiftInfo

型別：`interface`

有關收到的禮物及其贈送者的資訊。

<span id="07b22632"></span>
### GiftCount

型別：`number`

禮物數量。

<span id="ffbb1454"></span>
### GiftId

型別：`number`

此類禮物的唯一 ID。

<span id="44599d90"></span>
### GiftName

型別：`string`

禮物名稱。

<span id="33ef5903"></span>
### GiftImage

型別：`string`

禮物圖片的 URL。

<span id="4fbdafa4"></span>
### GiftPrice

型別：`string`

禮物的單價。

<span id="68fabcb4"></span>
### Index

型別：`number`

禮物在頁面上的顯示索引。

<span id="2865d672"></span>
### Nickname

型別：`string`

贈送禮物用戶的暱稱。

<span id="24e8fc86"></span>
### UserId

型別：`number`

贈送禮物用戶的用戶 ID。

<span id="e7422330"></span>
### Email

型別：`string`

贈送禮物用戶的電子郵件。

<span id="fe534689"></span>
## ProductInfo

型別：`interface`

有關產品的資訊。

<span id="94866faf"></span>
### Id

型別：`number`

產品卡片的唯一 ID。

<span id="1d48152e"></span>
### Title

型別：`string`

產品名稱。

<span id="22be6126"></span>
### Highlight

型別：`string`

產品的銷售價格。

<span id="aeeebc42"></span>
### Strikethrough

型別：`string`

產品的參考價格。

<span id="f32080e7"></span>
### IntroduceImage

型別：`string`

產品圖片的絕對 URL。

<span id="99783364"></span>
### RedirectImage

型別：`string`

產品跳轉圖片的絕對 URL。

<span id="892c194d"></span>
### ExternalProductId

型別：`string`

外部產品 ID。此 ID 可確保產品一旦被加入產品卡片菜單後，無法再次加入同一菜單。
