為了打造獨特且具品牌識別的觀看體驗，你可以使用 Web Viewer SDK 來自訂你的直播間。本指南提供進階功能的實作說明與程式碼範例，包括自訂用戶驗證流程、UI 元素（如圖示與留言框）的樣式設計，以及個性化 PCU 限制錯誤頁面。

<span id="c5d19ee4"></span>
## 先決條件

你已整合 Web Viewer SDK。如需更多資訊，請參閱 [整合 Web Viewer SDK](https://docs.byteplus.com/docs/byteplus-livesaas/zheng-he-web-viewer-sdk-zh-TW)。

<span id="065efa57"></span>
## 使用自訂模式進行驗證

若觀眾可透過你的帳號系統（例如公司官方網站）登入，你可以使用自訂模式進行驗證，讓觀眾以你的帳號系統的身份資訊加入直播間。你可以自行決定觀眾何時登入你的帳號系統。

<span id="645e07bd"></span>
### 支援平台

自訂驗證模式同時支援 PC 與行動裝置平台。

### **方法一：進入直播間前登入**

此方法要求觀眾在進入直播間前先登入，登入後即可觀看直播或參與互動。

<span id="45ae575b"></span>
#### 適用場景

此方法適用於需要身份驗證、存取控制或資料追蹤的場景，例如會員專屬活動、企業內部培訓或付費課程。此方式提供更高的安全性與明確的用戶識別，但可能提高觀眾的進入門檻。

<span id="c302c753"></span>
#### 程式碼範例

初始化 SDK 時，將 `mode` 參數設為 `2`，並將 token 參數設為 [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-TW) 回傳的授權 token。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">觀眾登入你的帳號系統後，請使用觀眾的暱稱和 ID 呼叫<a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-TW">GetSDKTokenAPI</a>以取得授權憑證。本次呼叫時，請確保<code>mode</code>參數設為<code>2</code>。</div>


程式碼範例如下。

```JavaScript
  var webSDK = new window.ByteLiveWebSDK({
    activityId: 172291833994****,
    token: 'ak3T%2FdaGJDL5zSFD7%2F1GPGP****',
    service: 'liveDemo',
    mode: 2, 
    ...
```

### **方法二：進入直播間後登入**

此方法允許觀眾先進入直播間觀看直播與瀏覽留言，無需登入。只有當觀眾嘗試發表留言、點讚內容或參與其他互動時，才會觸發自訂登入流程。

<span id="2b8319b1"></span>
#### 適用場景

此方法適用於公開活動、開放課程或以提升流量與用戶轉化為目標的行銷直播。此方式降低初始進入門檻並提升觀看體驗，但部分功能對匿名用戶仍有限制。

<span id="14ca81e0"></span>
#### 實作流程

實作流程如下：


1. 初始化 SDK 時，將 `mode` 參數值設為 `1`，停用 BytePlus Live 內建登入系統，並監聽 [permission.need](https://docs.byteplus.com/en/docs/byteplus-livesaas/events#permission-need) 事件。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">當<code>mode</code>的值設為<code>1</code>時，你可以透過以下任一方式取得授權憑證：   </div>
   

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">登入<a href="https://console.byteplus.com/livesaas/liveManagement/">BytePlus Live 控制台</a>，於直播間的<strong>製作端</strong> \> <strong>頁面嵌入</strong>頁面下的<strong>Web SDK 嵌入</strong>分頁取得憑證。   </div>
   

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">呼叫<a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-TW">GetSDKTokenAPI</a>以取得憑證。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">目前，<code>permission.need</code>事件僅適用於此情境。   </div>
   

2. 你需實作觀眾登入邏輯，以及取得 `mode: 2` 授權 token 的邏輯。

3. 當觀眾執行以下需用戶資訊的操作時，SDK 會觸發 `permission.need` 事件：

   * 點擊留言文字框（包含聊天互動與問答選單下的留言框）

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">問答選單僅支援 PC 端及橫屏模式的行動裝置。      </div>
      

   * 點讚留言

   * 送禮給主播

   * 簽到

   * 參與答題

   * 參與投票

   * 參與抽獎

   * 參與非匿名問卷

   * 預約直播（僅當預約簡訊提醒功能停用時才會觸發 `permission.need` 事件）

   * 點讚直播間（僅當點讚直播間需要登入時才會觸發 `permission.need` 事件，即 `loginInToThumbUp` 的值設為 `true` 時）

4. 偵測到 `permission.need` 事件後，需觸發自定義登入流程。

5. 觀眾登入你的帳號系統。

6. 當 `mode` 的值設為 `2` 時，呼叫 [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-TW) 並傳入觀眾的暱稱與 ID，以取得授權令牌。

7. 呼叫 SDK 的 [updateMode2Token](https://docs.byteplus.com/en/docs/byteplus-livesaas/api#updatemode2token) 方法，將臨時 `mode: 1` 令牌替換為新的 `mode: 2` 令牌。


範例程式碼如下。

```JavaScript
  var webSDK = new window.ByteLiveWebSDK({
    activityId: 172291833994****,
    token: 'ps****',
    service: 'liveDemo',
    mode: 1,
    options: {
      saveUserInfo: true, // 可選。當 mode 的值為 1 時，用於快取使用者資訊。
      disabledLogin: true, // 停用 BytePlus Live 內建登入系統。
    }
  })
  
    const login = () => {
    // 自行實作登入邏輯。
    return {
      Nickname: 'Viewer A',
      UserIdStr: '57584'
    }
  }

  const getSDKToken = () => {
    //  當 mode 的值為 2 時，自行實作取得憑證的邏輯。
    return {
      Token: 'hdsh****'
    }
  }
  // 偵測到 permission.need 事件後執行 handleLogin 函式。
  const handleLogin = async () => {
      // 觸發自訂登入流程，觀眾必須登入你的帳號系統。
      const userInfo = await login();
      // 使用登入的使用者資訊呼叫 GetSDKTokenAPI 以在 mode 為 2 時取得憑證。
      const res = getSDKToken(userInfo);
      // 當 mode 的值從 1 變更為 2 時，呼叫 SDK 的 updateMode2Token 方法以更新憑證。
      webSDK.updateMode2Token(res.Token);
  }
  // 監聽 permission.need 事件。
  webSDK.on('permission.need', handleLogin);
```

### 範例程式碼

配置 `disabledCommentConfig` 參數的範例程式碼如下。有關參數的更多資訊，請參見 [Web Viewer SDK：參數](https://docs.byteplus.com/docs/byteplus-livesaas/web-viewer-sdk-can-shu-zh-TW)。

```JavaScript
var webSDK = new window.ByteLiveWebSDK({
  activityId: 180025****643845, 
  token: 'AB**nK', 
  service: 'Demo', 
  mode: 1, 
  modules: [
    {
      id: 'player', // The page element ID.播放器模組將嵌入至此元素。
      mode: 'player',
    },
    {
      id: 'menu', // The page element ID.選單模組將嵌入至此元素。
      mode: 'menu',
    },
  ],
  options: {
    disabledCommentConfig: {
      disabled: true, // Disables the comment text box.觀眾點擊留言文字框時，無法輸入內容。
      placeholder: "Muted" // The placeholder text for the disabled comment text box.若要設定多語言的預設提示文字，請先透過 BytePlus Live 控制台或伺服器端 OpenAPI 啟用觀看頁面語言。接著，請依照「簡體中文|英文|日文|繁體中文|韓文|泰文|越南文|阿拉伯文|土耳其文|西班牙文|印尼文|葡萄牙文|俄文」的順序，並以「|」分隔各語言的預設提示文字。例如，若啟用的語言為簡體中文與英文，則參數值為「禁言中|Muted」。
    }
  },
});

webSDK.on('error', console.log);
```

## 自定義錯誤頁面

若你已訂閱直播並發觀看人數方案，當所有啟用中的直播間的總峰值並發用戶數（PCU）超過你的方案並發上限時，新的觀眾將會看到錯誤頁面。

例如，你訂閱的直播並發觀看人數方案為 300 人。目前你的帳號下共有 3 個處於 **Live** 狀態的直播間，PCU 分別為 100、150 和 200。總 PCU 為 450（100+150+200），已超過你的方案並發上限 300。當總 PCU 超過 300 時，若有觀眾嘗試進入觀看頁面，將會顯示錯誤頁面。

此自定義功能支援 PC 與行動平台。
