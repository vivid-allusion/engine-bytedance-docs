本主題列出了 BytePlus Live 的基本概念。


|**術語** |**說明** |
|---|---|
|SaaS（軟體即服務）方案 |SaaS 是一種基於雲端運算的服務模式。您可以根據需求使用 BytePlus Live 服務，快速搭建自有直播平台，無需自行建置、維護及更新軟體，顯著降低企業的投資與運營成本。BytePlus Live 控制台是 BytePlus Live 提供的 SaaS 方案。 |
|aPaaS（應用平台即服務）方案 |BytePlus Live 為具備開發能力的客戶提供的高性價比端到端整合方案。該方案涵蓋主播端、控制台及觀眾端，讓客戶可按需訂閱服務，並快速建立自有品牌的直播服務系統。 |
|推流 |通過網際網路即時將直播內容傳輸到直播平台的過程。例如，將如 OBS 等直播工具的直播內容傳輸到 BytePlus Live 的直播間。 |
|推流地址 |用於指示將直播內容傳輸到哪裡的字串。通常，該字串由直播平台自動生成。您可以將該字串複製到如 OBS 等直播工具，將直播內容同步到產生該字串的直播平台。 |
|拉流 |從直播平台獲取直播內容並播放的過程。例如，當觀眾觀看直播時，他們的裝置會從直播平台獲取直播內容，並在螢幕上顯示內容。BytePlus Live 從其他平台獲取直播內容並播放內容的情況也適用於此。 |
|拉流地址 |用於指示從哪裡獲取直播內容的字串。通常，該字串由直播平台自動生成。您可以使用這類字串，將其他直播平台的直播內容同步到 BytePlus Live，讓觀眾能在單一平台上觀看來自多個平台同步的直播內容。 |
|直播間 |一個虛擬空間，觀眾可以觀看影片、與其他觀眾及主持人互動，並參與如抽獎等互動活動。 |
|觀看頁面 |用於觀看影片、互動及顯示特定內容的頁面。 |
|觀看頁面網址 |觀眾用於觀看直播影片、預覽及回放的網址。 |
|直播流 |即時透過網際網路傳送至觀眾裝置、供即時觀看的直播內容。 |
|回放 |直播結束後產生的直播錄影，可釋出至觀看頁面供觀眾觀看。 |
|直播間狀態 |直播間具有以下其中一種狀態：<br><br><br>* 直播：觀眾可觀看直播影片。<br><br>* 預覽：若已上傳預覽，觀眾可觀看預覽，否則觀看直播間封面。<br><br>* 回放：觀眾可觀看回放內容。<br><br>* 結束：直播已結束，但尚未將回放釋出至觀看頁面。 |
|直播間封面 |當直播間處於**預覽**狀態但未上傳預覽，或處於**結束**狀態時，播放器所顯示的圖片。 |
|OBS（Open Broadcaster Software） |一款免費且開源的錄影與直播軟體，支援 Windows、macOS 及 Linux 作業系統。 |
|活動 ID |直播間的唯一識別碼。您可於 BytePlus Live 控制台直播間左上角取得該 ID。 |
|拉流協定 |用於將其他平台的直播內容經由網際網路傳輸至特定平台（如 BytePlus Live），實現跨平台同步播放的協定。例如，BytePlus Live 支援使用 RTMP、HLS 或 FLV 協定拉流。 |
|直播協定 |用於傳輸直播內容的協定，確保傳輸與觀看品質的穩定。不同的直播平台與裝置可能會使用不同的直播協定。例如，BytePlus Live 的 Viewer SDK for Android、Viewer SDK for iOS 及 Web Viewer SDK（PC 端）使用 HTTP\-FLV 協定，而 Web Viewer SDK（行動端）則使用 HLS 協定。 |
|Vid |影片 ID，即影片檔案的唯一識別碼。 |
|BytePlus 帳號 |用於註冊 BytePlus 的帳號，擁有完整的管理員權限，並可完全控制整個帳號的資源與權限。 |
|IAM 使用者 |由 BytePlus 帳號建立並用於管理資源的帳號。但通常僅具有限定權限。 |
|角色 |功能權限的集合。例如，將 Operation 角色指派給 IAM 使用者，即可授予該使用者在 BytePlus Live 控制台檢視直播間與頁面的權限。 |
|組織 |IAM 使用者的集合。企業的部門或子公司可以劃分為不同的組織，這樣可隔離各組織間的資源，並允許獨立管理各組織內使用者所建立的資源。 |
|彈幕 |動態的即時評論，會在在線觀看影片或直播時於螢幕上浮現。這些評論為觀眾提供一種互動且有趣的方式，在觀看內容時表達他們的想法、反應或問題。 |
