### 授權


|參數名稱 |資料型態 |說明 |範例 |
|---|---|---|---|
|AccessKeyId |String |用於 API 請求驗證的 AccessKey ID。 |AKAPY2RhYmQzODhhYTg4NGZmNTk3ZGUxODk3ODgzYTA\*\*\*\* |
|ShortDate |String |API 請求發送時的 UTC 時間。單位：天。格式：`YYYYMMDD`。<br><br>此值必須與 `YYYYMMDD` 在 `X-Date` 中的值相同。 |20201230 |
|Region |String |API 請求的區域。此值必須為 `ap-singapore-1`。 |ap\-singapore\-1 |
|Service |String |API 請求的服務名稱。對於 BytePlus Live，此值必須為 `livesaas`。 |livesaas |
|SignedHeaders |String |要納入簽名的請求標頭，以分號分隔的清單。此流程可確保驗證時忽略代理新增的額外標頭。若請求中包含 `host` 與 `x-date` 標頭，則必須將其納入此清單。 |content\-type;host;x\-content\-sha256;x\-date |
|Signature |String |計算出的簽名。 |11a2e7bb9db7ee7ea2e4d7f3d6989a65dc3bb5feedf3aae50ba1b3313fe0093a |

## 共用回應參數

以下為共用回應參數。


|參數名稱 |資料型態 |說明 |範例 |
|---|---|---|---|
|RequestId |String |API 請求的唯一 ID。 |202201201826170101501312091D1C09D2 |
|Action |String |所請求的 API 操作名稱。 |CreateActivityAPIV2 |
|Version |String |所請求的 API 操作版本。目前版本：`2020-06-01`。 |2020\-06\-01 |
|Service |String |所請求的 API 服務名稱。對於 BytePlus Live，此值為 `livesaas`。 |livesaas |
|Region |String |所請求的 API 服務區域。此值為 `ap-singapore-1`。 |ap\-singapore\-1 |
|SystemTime |Integer |API 操作呼叫時的系統時間（Unix 時間戳格式）。單位：秒。 |1656067132 |
