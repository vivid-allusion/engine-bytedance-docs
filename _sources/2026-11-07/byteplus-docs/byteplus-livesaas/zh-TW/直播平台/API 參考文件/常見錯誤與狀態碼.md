本主題記錄了常見的錯誤與狀態碼。

## BytePlus 常見錯誤


|名稱 |訊息 |描述 |狀態碼 |
|---|---|---|---|
|MissingParameter |請求缺少 %s 參數。 |缺少必要的關鍵參數，例如 Action 和 Version。 |400 |
|MissingAuthenticationToken |請求缺少驗證令牌。 |缺少必要的驗證資訊。 |401 |
|MissingRequestInfo |請求缺少 %s 資訊。 |請求缺少必要資訊，例如 Access Key、Service 或 Region。 |400 |
|MissingSignature |請求缺少簽名。 |請求簽名缺失。 |401 |
|InvalidTimestamp |請求的簽名已過期。 |請求簽名已過期或簽名時間無效。 |400 |
|ServiceNotFound |未找到服務 '%s'。 |請求的服務不存在，或指定的服務名稱不正確。 |404 |
|InvalidActionOrVersion |無法找到版本 %s 的操作 %s。 |請求的 API 操作不存在，或指定的操作名稱不正確。 |404 |
|InvalidAccessKey |請求中包含的 Access Key [%s] 無效。 |請求中包含的 Access Key 不正確。 |401 |
|SignatureDoesNotMatch |我們計算的請求簽名與您提供的簽名不一致。請檢查您的 Secret Access Key 及簽名方式。請參閱服務文件以獲取詳細資訊。 |產生的簽名無效。 |401 |
|LackPolicy |因權限不足，請求被拒絕。 |子帳號無權訪問資源。 |403 |
|AccessDenied |使用者無權對資源 %s 執行操作：%s。 |子帳號無權執行該請求。 |403 |
|InternalError |服務發生內部錯誤。請聯繫管理員。 |內部錯誤。 |500 |
|FailToConnect |Top 無法連接到內部服務。 |使用者授權已驗證，但服務連線失敗。 |502 |
|InternalServiceTimeout |內部服務逾時。請聯繫管理員。 |內部服務逾時。 |504 |
|FlowLimitExceeded |請求被拒絕，因為此 openAPI 的請求速度超過目前流量控制限制。 |請求超過流量控制限制。 |429 |
|ServiceUnavailableTemp |服務繁忙，請稍後再試。 |服務繁忙。請稍後再試。 |503 |
|MethodNotAllowed |HTTP 方法不允許。 |不支援此 HTTP 方法。 |405 |
|InternalServiceError |服務發生內部錯誤。請聯繫管理員。 |服務發生內部錯誤。請聯繫技術支援。 |502 |
|InvalidAuthorization |'Authorization' 標頭無效，請檢查授權標頭。 |Authorization 標頭格式不正確。 |400 |
|InvalidCredential |'Authorization' 中的憑證無效，請檢查授權標頭中的憑證。 |Authorization 標頭中的 Credential 格式不正確。 |400 |
|InvalidSecretToken |Secret token 無效，訊息：%s。 |Secret token（STS 或 STS2）因簽名錯誤或過期而無效。 |401 |


<span id="01cd9782"></span>
## BytePlus Live 常見錯誤


|狀態碼 |錯誤碼 |錯誤訊息 |描述 |
|---|---|---|---|
|400 |InvalidParameter.%sInvalid |指定的參數 %s 無效。 |參數無效。請根據規範修改值後再試。 |
|400 |InvalidParameter.ActivityHasBeenDeleted |指定的參數 ActivityId 無效。 |直播間已被刪除。請修改 `ActivityId` 參數的值後再試。 |
|400 |InvalidParameter.ActivityNotExist |指定的參數 ActivityId 無效。 |直播間不存在。請修改 `ActivityId` 參數的值後重試。 |
|500 |InternalError.InternalError |請求因未知錯誤而失敗。 |在處理請求時發生未知錯誤。請聯絡技術支援以獲取協助。 |
