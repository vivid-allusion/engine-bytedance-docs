尊敬的 BytePlus Live 用戶：

為提升 BytePlus Live API 服務的辨識度與使用體驗，BytePlus Live 產品已更新 API Endpoint 網域名稱。具體調整如下：

**更新說明**

BytePlus Live API 建議使用新的 Endpoint：`https://livesaas.byteplusapi.com`

原 Endpoint：`https://open.byteplusapi.com` 仍可正常使用，目前不會影響現有業務調用。

**其他資訊**

已接入原 Endpoint 的用戶無需立即調整，現有調用鏈路仍可正常使用；

為方便後續服務辨識、問題排查及能力演進，建議您在新接入或後續版本迭代時，優先使用新的 Endpoint：`https://livesaas.byteplusapi.com`；

在持續使用 BytePlus Live 服務期間，請遵守 BytePlus Live 服務使用協議。

若您對本次調整有任何疑問，請聯繫 BytePlus Live 技術支援諮詢。
