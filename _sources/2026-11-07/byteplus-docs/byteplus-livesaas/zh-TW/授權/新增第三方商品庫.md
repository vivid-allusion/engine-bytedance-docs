BytePlus Live 支援從 TikTok Shop、Shopify 或其他店鋪系統等外部平台新增商品，讓您的 AI 虛擬主播能在直播期間推廣並講解商品。本指南提供逐步操作說明，協助您設定並授權來自 TikTok Shop、Shopify 或自有系統的平台商品庫。

<span id="8ee628bc"></span>
## 先決條件

訂閱 AI Live 服務：請參閱 [訂閱計費方式](https://docs.byteplus.com/docs/byteplus-livesaas/subscription-billing-method-zh-TW) 並聯繫銷售人員以訂閱 AI Live 服務。

<span id="187bcea3"></span>
## 操作流程

請依照以下步驟設定您的商品庫。


1. 登入 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 點擊頂部導覽列的 **Authorization** 。

3. 在左側導覽列，點擊 **Integrations** \> **Product Library** 開啟頁面。

4. 於 **Product Library** 頁面，點擊 **Product library management**。

   **Product library management** 面板將於右側開啟。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d5994cec42d74a01983101dceb49c279~tplv-goo7wpa0wc-image.image) </span>

5. 點擊  **+Add product library** 並輸入 **Product Library Name**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/33dd68758fc34113bd01a82cb4b96fa9~tplv-goo7wpa0wc-image.image) </span>

6. 選擇 **Product library type**。類型設定後將無法更改。

   
   <Tabs>
   <Tab zoneid="ll0s9F0xIR" title="TikTok Shop">
   <TabTitle>TikTok Shop</TabTitle>
   
   點擊 **Go to authorize**。選擇您的區域及授權店鋪。
   
   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de817af0167e46d788639e1791d30e2d~tplv-goo7wpa0wc-image.image) </span>
   
   
   </Tab>
   <Tab zoneid="GzhmtpsEYi" title="Shopify">
   <TabTitle>Shopify</TabTitle>
   
   輸入您的網域名稱及公開存取權杖：
   
   
      * **Domain name**：您的 Shopify 店鋪網域名稱。
   
         如需取得網域名稱，請於 Shopify 店鋪左側導覽窗格點擊「設定」，即可在店鋪名稱下方查看網域名稱。您也可點擊「設定」\>「網域」，於「網域」頁面查看網域名稱。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0aa4e1b2fc5349e184af839897ce7db9~tplv-goo7wpa0wc-image.image) </span>
   
      * **Public access token**：您的 Shopify 店鋪 Storefront API 的公開存取權杖。
   
         如需取得權杖，請前往 Shopify 店鋪的 **Headless sales channel** 頁面。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fcc45a5e3e8b4813b7218b86c6e766be~tplv-goo7wpa0wc-image.image) </span>
   
         點擊 **Manage**，即可於 Storefront API 頁面查看公開存取權杖。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/084b594a5b10486f8af763fe4f1fddfc~tplv-goo7wpa0wc-image.image) </span>
   
         點擊儲存圖示。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f44dec36f7a94a829864eecee2d0441d~tplv-goo7wpa0wc-image.image) </span>
   
   
   </Tab>
   <Tab zoneid="ebb1TE1OVM" title="自有系統">
   <TabTitle>自有系統</TabTitle>
   
   輸入用於從商品庫擷取商品的請求 URL。

   <div data-tips="true" data-tips-type="warning">在從自有系統新增商品庫前，您必須依照規範開發 API，以便將您的系統與 BytePlus Live 整合。如需更多資訊，請參閱 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/guan-li-chan-pin-ka-pian-zh-TW#f4985fe1">將您的系統整合至 BytePlus Live</a>。</div>
