BytePlus Live 提供一套完善的權限管理系統，使你能夠授予用戶特定權限，讓多位人員能夠協同管理你的直播平台變得更加容易。此功能特別適用於需要在企業內不同部門或員工之間靈活分配和管理資源存取權限的情境。

具體而言，BytePlus Live 支援管理 IAM 用戶、組織及角色，包括將用戶分配至組織和角色。這可實現對 IAM 用戶權限更細緻且靈活的管理，確保用戶能夠獲得所需資源的適當存取權限。本文將說明授權的主要概念。

<span id="6d6910f8"></span>
## 管理員帳號

在 BytePlus 中，管理員帳號被識別為 root 用戶。管理員帳號是所購買 BytePlus 雲端資源的擁有者，並負責資源計量與資源計費。預設情況下，管理員帳號擁有所有權限。

<span id="31a80d12"></span>
## 子帳號（IAM 用戶）

用戶，也稱為 IAM 用戶，由管理員帳號或已獲授權限的用戶建立。若用戶被分配多個角色，則擁有這些角色中定義的所有權限。具體說明如下：


* 若角色之間沒有重疊的權限，則用戶擁有這些角色中定義的所有權限。例如，A 用戶被分配了具有「Live control \> Edit」權限的 A 角色，以及具有「Producer \> View only」權限的 B 角色。則 A 用戶同時擁有「Live control \> Edit」和「Producer \> View only」兩項權限。

* 若角色之間存在重疊的權限，則用戶將擁有這些角色中最高的權限。例如，A 用戶被分配了具有 Live control \> Edit 權限的 A 角色，以及具有 Live control \> View only 權限的 B 角色。則 A 用戶將擁有 Live control \> Edit 權限。

## 組織

用戶的集合。企業的部門或子公司可劃分為不同的組織，各組織間資源相互隔離，並可獨立管理各組織內用戶所建立的資源。

組織內用戶所建立的所有直播間均歸屬於該組織。例如，若 A 用戶擁有「Live control \> Edit」權限，且將組織 1 設為可見範圍，則 A 用戶將擁有組織 1 內所有用戶所建立直播間的 Live control 頁面編輯權限。

<span id="680af609"></span>
## 角色

權限的集合。你可以在一個角色中定義不同的權限，且每個角色可分配給多個用戶。
