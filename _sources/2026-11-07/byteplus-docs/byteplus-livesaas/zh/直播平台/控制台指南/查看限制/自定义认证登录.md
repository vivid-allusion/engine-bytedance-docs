要控制对您的在线流的访问，您可以通过自定义认证方式，将您自己的账号系统与 BytePlus Live 集成。这要求观众在观看内容或进行互动前，必须通过您的系统登录。本指南详细介绍了两种实现方案：一种是将未认证用户重定向到您的登录页面，另一种是允许已预先认证的用户通过带有认证参数的 URL 直接进入。内容涵盖端到端流程、所需参数以及控制台配置步骤。

要使用此功能，请确保您拥有开发者资源。

<span id="prerequisite"></span>
## 前提条件

您必须拥有 BytePlus 账号或具备 Producer \> Edit 权限的 IAM 用户。有关如何添加 IAM 用户的更多信息，请参见 [管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

<span id="scenarios"></span>
## 应用场景


* [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)：该方案适用于有保密需求的直播场景或产品推广场景。如果用户未登录进入直播间，可以被重定向到您自有账号系统的登录页面。用户登录您自有账号系统后，可以被重定向到观看页，进行观看直播流、发送评论等操作。

* [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)：该方案适用于用户登录您自有账号系统后，避免二次登录的场景。用户登录您的账号系统后，可点击对应 URL 进入直播间。该 URL 即为附加了所需认证参数的观看页地址。


<span id="note"></span>
## 说明

如果您的直播间通过 iframe 嵌入到自有页面中，您必须通过添加别名记录（CNAME 记录）自定义观看页的域名，从而确保您的页面域名与观看页域名一致。这样可以避免浏览器禁止写入第三方 Cookie 的问题。如需添加 CNAME 记录，请联系您的销售代表。

<span id="process"></span>
## 流程

<span id="solution-a"></span>
### 方案 A

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a96b8fae4fd04bcc827b6c5d3f8b2ef8~tplv-goo7wpa0wc-image.image) </span>


1. 用户访问 BytePlus Live 的观看页。

2. BytePlus Live 携带 `ActivityId`、`Timestamp` 和 `RedirectUrl` 参数，将用户重定向到您自有账号系统的登录页面（在 [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN) 配置的登录链接）。

   * 若认证类型设置为 **Custom**：用户访问观看页后，BytePlus Live 携带上述参数，将用户重定向到您自有账号系统的登录页面。

   * 若评论限制设置为 **Custom**：用户在观看页发送评论或参与抽奖等互动活动时，BytePlus Live 携带上述参数，将用户重定向到您自有账号系统的登录页面。

3. 用户在系统登录页面登录您自有账号系统。

4. 您自有账号系统在验证用户身份后，使用相关参数计算签名。

5. 您自有账号系统在重定向到 BytePlus Live 的认证页面（`RedirectUrl`）时，包含 `UserId`、`Nickname`、`Timestamp`、`Sign` 参数及其他参数。

6. BytePlus Live会在认证页面验证签名（`Sign`值），以判断是否允许用户观看直播流、发送评论等操作。

7. 如果验证成功，即BytePlus Live计算的签名与你自有账号系统携带的`Sign`值一致，用户即可观看直播流、发送评论等操作。

   如果验证未通过，则会显示自定义认证验证失败页面。


<span id="solution-b"></span>
### 方案B

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5ab6141b635541edab7cea45d39ef37c~tplv-goo7wpa0wc-image.image) </span>


1. 用户在系统登录页面登录你自有账号系统。

2. 你自有账号系统在验证用户身份后，使用相关参数计算签名。

3. 将参数`Sign`、`Nickname`、`UserId`、`Timestamp`及其他参数作为认证参数添加到观看页地址。例如，`https://live.byteplus.com/xxx/xxx?Sign=xx&Nickname=xx&UserId=xx&Timestamp=xxx`。

   你也可以将`Sign`、`Nickname`、`UserId`和`Timestamp`参数添加到你的Cookie中。随后，用户访问观看页地址后即可直接观看直播流、发送评论等操作。

   如果不需要`extra`和`forceCheck`参数，可以忽略第4至第6步。否则，必须将其作为认证参数添加到观看页地址，并按照第4至第6步操作。

   以下是将参数添加到你的Cookie的示例。

   ```Plain
   Cookie: Sign=98d3e2f51c0a8a452be60484aed15ca0; Nickname=ZGFkYQ%3D%3D; Timestamp=1714307542226; UserId=222
   ```
   

4. 用户携带上述认证参数访问观看页地址。

5. BytePlus Live会根据认证参数中的信息验证签名（`Sign`值），以判断是否允许用户观看直播流、发送评论等操作。

6. 如果验证通过，即BytePlus Live计算的签名与认证参数中的`Sign`值一致，用户即可观看直播流、发送评论等操作。

   * 如果认证类型设置为**Custom**且验证未通过，则会显示自定义认证验证失败页面。

   * 如果评论限制设置为**Custom**且验证未通过，则不会显示自定义认证验证失败页面。用户无需登录直播间即可在观看页观看直播视频、预告和回放，但无法发送评论或参与抽奖等互动活动。


<span id="parameters"></span>
## 参数

<span id="redirect-parameters"></span>
### 重定向参数

BytePlus Live会携带以下参数，将用户从观看页重定向到你自有账号系统的登录页面。

仅[自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)需要这些参数。


|名称 |数据类型 |接口行为 |示例值 |
|---|---|---|---|
|ActivityId |整数 |直播间的活动 ID。 |17475526787325 |
|Timestamp |整数 |当前时间的 Unix 时间戳格式。单位：毫秒。 |1669808399000 |
|RedirectUrl |字符串 |BytePlus Live 的鉴权页面地址。在此页面，BytePlus Live 会校验签名（`Sign`值），以判断是否允许用户观看直播流、发送评论等。 |liveDomain/xxx/xxx |


<span id="callback-parameters"></span>
### 回调参数


* [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)：你自有账号系统会携带以下参数，将用户从系统登录页面重定向到BytePlus Live的认证页面。

* [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)：你可以将以下参数作为认证参数添加到观看页地址。



|名称 |数据类型 |必填 |接口行为 |示例值 |
|---|---|---|---|---|
|UserId |字符串 |是 |用户在您自有账号系统中的唯一标识。该参数仅用于将您自有账号系统与 BytePlus Live 关联，不用于数据分析。<br><br>建议不要使用如手机号等信息作为用户在您自有账号系统中的唯一标识，以避免个人信息泄露。 |`14039` |
|Nickname |字符串 |是 |用户在您自有账号系统中的昵称。您需要先进行 UTF\-8 编码，再进行 Base64 编码，最后进行 URL 编码昵称。例如，若昵称为 Employee😁 ABC，则参数值为 `RW1wbG95ZWXwn5iBIEFCQw%3D%3D`。<br><br>建议不要使用如手机号等信息作为用户在您自有账号系统中的昵称，以避免个人信息泄露。 |`RW1wbG95ZWXwn5iBIEFCQw%3D%3D` |
|Timestamp |整数 |是 |当前时间的 Unix 时间戳格式。单位：毫秒。 |`1669808499000` |
|Sign |字符串 |是 |用于校验的签名。<br><br>要获取`Sign`值，需完成以下步骤：<br><br><br>1. 按`SecretKeyUserIdTimestamp`格式拼接字符串。您可以在BytePlus Live控制台获取密钥。欲了解更多信息，请参见[自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)。<br><br>2. 生成拼接字符串的 32 位小写 MD5 哈希值。<br><br><br>在本示例中，假设`SecretKey`的值为`h/macd/b/a`。此时拼接字符串为`h/macd/b/a140391669808499000`，`Sign`的值为`2708f2f2969e38ff5d1863fde50e7b64`。 |`2708f2f2969e38ff5d1863fde50e7b64` |
|extra |字符串 |否 |该额外参数会同步至BytePlus Live，可用于与用户关联更多数据。例如，您可以将自有账号系统中的用户部门同步至BytePlus Live。 |`销售部门` |
|forceCheck |布尔值 |否 |指定是否清除上次登录状态。默认值：`false`。<br><br><br>* `true`：清除上次登录状态。适用于多个用户使用同一浏览器或设备的场景。例如，用户A和用户B在同一设备的同一浏览器访问观看页时，用户B需在用户A访问观看页后重新登录您的自有账号系统，以确保身份正确识别。<br><br>* `false`：不清除上次登录状态。适用于每个用户使用各自浏览器或设备的场景。例如，用户A在同一设备的同一浏览器多次访问观看页，只要浏览器Cookie未被清除，则无需再次登录您的自有账号系统。 |`true` |


<span id="procedure"></span>
## 操作流程


1. 登录[BytePlus Live控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击打开直播间。

3. 在左侧导航栏，点击**Producer** \> **观看限制**。

4. 将认证类型或评论限制设置为**Custom**，并完成以下配置。

   * 将认证类型设置为**自定义**：用户必须先登录您的自有账号系统，才能进入直播间观看直播流及更多内容。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90c6142a0b3a4107add065e34f8b1053~tplv-goo7wpa0wc-image.image) </span>

   * 将评论限制设置为**自定义**：用户必须先登录您的自有账号系统，才能发送评论或参与抽奖等互动活动。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/df19b2bc674f42928af2d888ec04fe60~tplv-goo7wpa0wc-image.image) </span>

      在设置评论限制为**自定义**之前，必须先将认证类型设置为**无**。

   
   |配置 |接口行为 |
   |---|---|
   |用于账号登录的应用 |您的自有账号系统的名称。 |
   |登录链接 |您的自有账号系统的登录页面地址。链接必须包含协议头，例如`https://myDomain/auth`。<br><br><br>* 将认证类型设置为**自定义**：BytePlus Live会携带`ActivityId`、`Timestamp`和`RedirectUrl`参数，在用户访问观看页后重定向至该链接。<br><br>* 将评论限制设置为**自定义**：BytePlus Live会携带`ActivityId`、`Timestamp`和`RedirectUrl`参数，在用户发送评论或参与抽奖等互动活动后重定向至该链接。<br><br><br>对于[自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)，用户无需重定向至该链接。 |
   |密钥 |在进入用于账号登录和登录链接的应用并保存配置后，密钥会自动生成。密钥用于计算签名（`Sign`值）。关于签名的计算方法，请参见[自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)。 |
   |全屏水印 |指定是否在直播间以全屏水印形式显示用户昵称。 |
   |昵称修改 |指定是否允许用户在直播间修改昵称。<br><br><br>* 用户在直播间内七天内只能修改一次昵称。<br><br>* 修改后的昵称仅适用于本直播间。 |
