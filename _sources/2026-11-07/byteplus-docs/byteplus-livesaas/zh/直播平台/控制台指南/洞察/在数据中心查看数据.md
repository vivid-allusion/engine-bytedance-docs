要分析你的直播活动表现并了解你的观众，请在 BytePlus Live 控制台中使用数据中心。本指南说明如何访问和解读聚合的直播间数据和详细的用户画像关键指标，帮助你获得有关活动成功和观众行为的可操作洞察。

<span id="live-room-data"></span>
## 直播间数据


1. 登录 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 点击 **数据中心** \> **直播间数据**。

3. 在 **直播间数据** 页面，你可以在指标墙和直播间列表中查看数据。

   * 指标墙：数据每日更新。

      你可以执行以下操作。

      * 根据时间范围筛选数据。

      * 将筛选后的数据导出到本地存储。

      * 查看筛选后的数据。

         
         |指标 |接口行为 |颗粒度 |单位 |
         |---|---|---|---|
         |总直播间数量 |在所选时间范围内，BytePlus 账号下创建的直播间总数。 |累计 |房间 |
         |总观看次数 |在所选时间范围内，BytePlus 账号下所有直播间的总观看次数。<br><br>例如，一名观众访问观看页两次，另一名观众访问观看页一次，则观看次数增加 3。<br><br>如果观众刷新观看页一次，则观看次数增加 1。 |累计 |次数 |
         |总唯一观众数 |在所选时间范围内，BytePlus 账号下所有直播间的总唯一观众数。<br><br>具有相同设备 ID 的设备视为同一设备，使用同一设备的观众在一个直播间中只计为一名观众。<br><br>例如，一名观众使用设备 A 两次访问观看页，另一名观众使用设备 B 一次访问观看页，还有一名观众使用设备 C 三次访问观看页，则唯一观众数增加 3。 |累计 |观众 |
         |平均直播间数量 |在所选时间范围内，BytePlus 账号下每位观众访问的平均直播间数量，即所有直播间的唯一观众总和除以总唯一观众数。<br><br>“所有直播间的唯一观众总和”指观众每访问一个房间就计一次。相比之下，“总唯一观众数”无论观众访问多少房间，都只计一次。<br><br>具有相同设备 ID 的设备视为同一设备。 |累计 |房间 |
         |平均观看时长 |在所选时间范围内，BytePlus 账号下每位观众的平均观看时长，即所有直播间的总观看时长除以所有直播间的总唯一观众数。 |累计 |分钟 |
         |平均观看次数 |在所选时间范围内，BytePlus 账号下每位唯一观众的平均观看次数。此指标通过将所有直播间的总观看次数除以所有直播间的总唯一观众数得出。 |累计 |次数 |
         |总观看时长 |在所选时间范围内，BytePlus 账号下所有直播间的总观看时长。<br><br>此数据仅在导出的`.xlsx`文件中可用。 |累计 |分钟 |
         

   * 直播间列表

      你可以执行以下操作。

      * 根据直播间名称和数据统计范围筛选数据。

         * 直播间名称：支持模糊搜索。

         * 数据统计范围：在 **平均观看时长（分钟）**  或 **平均访问时长（分钟）**  列右侧选择一个选项。

            * 总观看：包括直播间处于 **直播**、**预告** 或 **回放** 状态时产生的数据，即使在观看页未播放预告或回放。

            * 直播观看：返回直播间处于 **直播** 状态时产生的数据。

            * 预告观看：返回直播间处于 **预告** 状态时产生的数据，即使在观看页未播放预告。

            * 回放观看：返回直播间处于 **回放** 状态时产生的数据，即使在观看页未播放回放。

            * 页面访问：返回直播间处于 **直播**、**预告**、**回放** 或 **结束** 状态时产生的数据，即使在观看页未播放预告或回放。

      * 将筛选后的数据导出到本地存储。

      * 点击 **查看详情**，在 **数据详情** 列进入该直播间的 **洞察** \> **基础数据** 页面。更多信息，请参见 [查看直播间数据](https://docs.byteplus.com/docs/byteplus-livesaas/docs-data-statistics-zh-CN)。

      * 查看筛选后的数据。

         
         |指标 |接口行为 |颗粒度 |单位 |
         |---|---|---|---|
         |活动 ID |直播间的活动 ID。<br><br>此数据仅在导出的`.xlsx`文件中可用。 |固定值 |不适用 |
         |直播间名称 |直播间名称。 |不适用 |不适用 |
         |直播流时间 |这是在直播间 **Producer** \> **基本信息** 页面配置的直播流时间。 |不适用 |不适用 |
         |总直播时长（分钟） |直播间的总直播时长，包括超低延时直播和普通延时直播。 |累计 |分钟 |
         |总观看次数/总访问次数 |直播间内的总观看次数或访问次数。<br><br>观众或访客刷新观看页一次，观看次数或访问次数就增加 1。 |累计 |次数 |
         |唯一观众/唯一访客 |直播间内唯一观众或访客的总人数。<br><br>设备 ID 相同的设备视为同一设备，使用同一设备的观众或访客视为同一人。<br><br>例如，若一位访客使用设备 A 两次访问观看页，另一位访客使用设备 B 一次访问观看页，还有一位访客使用设备 C 三次访问观看页，则唯一访客数增加 3。 |累计 |人数 |
         |峰值并发观众/峰值并发访客 |直播间内观众或访客的峰值并发人数。<br><br>设备 ID 相同的设备视为同一设备，使用同一设备的观众或访客视为同一人。 |实时 |人数 |
         |评论数 |直播间内由主播、观众、嘉宾和机器人发送的评论总数，包括已删除评论和审核中的评论。 |累计 |不适用 |
         |平均观看时长（分钟）/平均访问时长（分钟） |直播间内每位观众的平均观看时长或访问时长，计算方式为总观看时长或访问时长除以唯一观众或访客人数。 |累计 |分钟 |
         |总观看时长（分钟）/总访问时长（分钟） |直播间内观众或访客的总观看时长或访问时长。<br><br>该数据仅在导出的 `.xlsx` 文件中可用。 |累计 |分钟 |

## 用户画像


1. 登录 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 点击 **数据中心** \> **用户画像**。

3. 在 **用户画像** 页面，你可以执行以下操作。

   * 根据观众的昵称、手机号以及直播间的分类标签值筛选数据。

      每次最多可选择 20 个标签值。

   * 将筛选后的数据导出到本地存储。

   * 查看筛选后的数据。

      * 如果观众未登录直播间或仅在直播间填写昵称，则不会显示该观众的用户画像。

      * 以下指标可实时生成数据，其余指标将在观众离开直播间 5 分钟后生成数据：

         * 预约

         * 投票

         * 问卷

         * 抽奖参与

         * 中奖

      
      |指标 |Description |颗粒度 |单位 |
      |---|---|---|---|
      |昵称 |观众的昵称。 |不适用 |不适用 |
      |用户 ID |观众在 BytePlus Live 中的唯一标识符。 |不适用 |不适用 |
      |关联用户 ID |观众在第三方平台上的唯一标识。你可以使用此关联用户 ID 来识别组织内观众的身份，从而按需实现用户洞察和数据分析。<br><br>观众的关联用户 ID 会根据其登录直播间的方式而有所不同。<br><br><br>* 自定义账号：自定义登录时通过 `UserId` 参数传递的值。更多信息，请参见 [自定义认证登录](https://docs.byteplus.com/docs/byteplus-livesaas/docs-applying-advanced-viewing-restrictions-zh-CN)。<br><br>* 手机号：观众使用手机号注册 BytePlus Live 时生成的 `passport_id`。<br><br>* OAuth 2.0：对应于您自有账号系统中的用户 ID 字段。<br><br>* allowlist：观众输入的 allowlist 校验信息。<br><br><br>仅当观众通过上述方式登录直播间时，该字段才有值。 |不适用 |不适用 |
      |手机号 |观众用于登录直播间的手机号。 |实时 |不适用 |
      |登录账号 |该指标与观众登录直播间的方式有关。例如，观众使用手机号登录直播间时，该指标值为**手机号**。观众通过自有账号系统登录直播间时，该指标值为账号登录应用名称。 |实时 |不适用 |
      |超低延时观看时长（分钟） |该指标表示观看超低延时直播的总时长。 |累计 |分钟 |
      |总观看时长（分钟） |数据会根据本列右侧所选项而变化。<br><br><br>* 总观看：观看超低延时直播、普通延时直播、预告和回放的时长。<br><br>* 直播观看：观看超低延时直播和普通延时直播的时长。<br><br>* 预告观看：观看预告的时长。<br><br>* 回放观看：观看回放的时长。<br><br>* 页面访问：在观看页停留的时长。 |累计 |分钟 |
      |直播间总数 |观众访问的直播间总数。 |累计 |次数 |
      |评论数 |观众发送的评论次数，包括已删除评论和审核中的评论。 |累计 |不适用 |
      |地区 |观众的地区。 |实时 |不适用 |
      |IP地址 |观众的IP地址。 |实时 |不适用 |
      |预约 |观众预约在线流的次数。 |累计 |次数 |
      |投票 |观众提交投票的次数。 |累计 |次数 |
      |问卷 |观众提交问卷的次数。 |累计 |次数 |
      |抽奖参与 |观众参与实时抽奖的次数。 |累计 |次数 |
      |中奖 |观众在实时抽奖中中奖的次数。 |累计 |次数 |
      

   * 点击 **详情**，在 **画像** 列查看观众的基础数据、观看历史和互动数据。如果你根据直播间的分类标签值筛选数据，也可以查看筛选前后的数据。

      
      |指标 |接口行为 |颗粒度 |单位 |
      |---|---|---|---|
      |基础数据 |观众的基本信息，包括用户ID、登录账号、手机号、设备、地区和IP地址。 |不适用 |不适用 |
      |观看足迹 |观众活动摘要，包括访问的房间数量、总访问时长、在特定房间观看直播视频和回放的时长，以及每个房间的进入时间。 |累计 |直播间总数：房间<br><br>总访问时长、观看直播、观看回放：分钟 |
      |互动数据 |观众预约在线流、提交投票、提交问卷、参与实时抽奖、在实时抽奖中中奖，以及观众发送的评论次数（包括已删除评论和审核中的评论）。 |累计 |预约、投票、问卷、抽奖参与和中奖次数：次数<br><br>评论数：不适用 |
