你可以在直播间添加敏感词，以确保直播间不出现这些词。


* 包含敏感词的评论仅对发送评论的观众可见。

   此功能适用于聊天互动菜单和问答菜单。

* 观众和嘉宾无法输入包含敏感词的昵称。


<span id="prerequisite"></span>
## 前提条件

需要 BytePlus 账号或具有 Producer \> Edit 权限的 IAM 用户。如需了解如何添加 IAM 用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

<span id="procedure"></span>
## 操作流程


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击打开一个直播间。

3. 在左侧导航栏，点击**Producer** \> **敏感词**。

4. 点击**添加敏感词**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e253c119d3934bedb74ace24797d8d3a~tplv-goo7wpa0wc-image.image) </span>

5. 在**添加敏感词**对话框中，通过以下方式添加一个或多个敏感词，然后点击**确定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a24ca84215004639868d064e8c6dda1e~tplv-goo7wpa0wc-image.image) </span>

   * 直接在对话框中输入敏感词。添加多个敏感词时，可用逗号（,）或按回车键分隔。

   * 点击**下载模版**，按照模版指引添加敏感词，然后点击**导入**上传更新后的模版。

      由于逗号（,）作为分隔符，单个敏感词不能包含逗号。

6. （可选）开启**模糊匹配**开关，然后：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/33cb134161aa4d6ab41073d87268f590~tplv-goo7wpa0wc-image.image) </span>

   * 敏感词不区分大小写。例如，若敏感词为**abc**，则包含**Abc**的评论和昵称也会被屏蔽。

   * 匹配敏感词时，评论和昵称中的空间以及以下特殊字符会被忽略：

      `\* # @ ., ? !: ; “ ” ‘’ () — \- … / ' _ + | & % $ ^ ~ < \> = ～ [ ] \ · ¥ { } ！｜「 」（ ）〈 〉：【 】、；，。"《 》 ？``

      例如，若敏感词为**abc**，则包含\*\*a b@c\*的评论和昵称也会被屏蔽。

      如需将更多特殊字符添加至匹配规则，请联系您的销售代表。

   * 你添加的敏感词不能包含空间或上述特殊字符。例如，添加敏感词时输入**a b@c\*，则实际添加的敏感词为**abc\*\*。

7. （可选）开启**手机号屏蔽**开关，然后：

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/002d596b9a5e471796a2a22d25c7cc00~tplv-goo7wpa0wc-image.image) </span>

   * 包含手机号的评论仅对发送评论的观众可见。

   * 观众和嘉宾无法输入包含手机号的昵称。

      目前，该功能支持新加坡、日本、韩国、印度尼西亚、泰国和中国的手机号。

8. （可选）在搜索框中输入内容以搜索指定敏感词。支持模糊搜索。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ffd46ee2b71e48a7b4ece59224adafe2~tplv-goo7wpa0wc-image.image) </span>

9. （可选）点击**删除**，在**操作**列删除敏感词。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b5d00a0cd5df4ed1a018875a6ee86e5e~tplv-goo7wpa0wc-image.image) </span>
