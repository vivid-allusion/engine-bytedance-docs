要安排你的直播流并防止其在指定时间前开始，可以启用直播流开始时间功能。本指南为新建和已有直播间提供配置此功能的分步说明。

<span id="what-the-host-sees"></span>
## 主播看到的内容

直播页面会显示计划开始时间的倒计时。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de233eebfecf4cf68238fe0473cfa9f7~tplv-goo7wpa0wc-image.image) </span>

<span id="prerequisites"></span>
## 前提条件

你必须拥有一个 BytePlus 账号或 IAM 用户。要在已有直播间启用此功能，IAM 用户必须拥有 Producer \> Edit 权限。有关如何添加 IAM 用户的更多信息，请参见 [管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

<span id="procedure"></span>
## 操作流程

你可以通过以下方式之一启用此功能。

在直播流过程中，无法启用或禁用该功能，也无法修改直播流开始时间。

<span id="method-1-create-a-live-room-with-the-feature-enabled"></span>
### 方法一：创建已开启该功能的直播间


1. 登录 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在 **直播间**页面，点击**创建直播间**。

3. 在**创建直播间**页面，选择创建单个直播间或多个房间。

   * 创建直播间：在**创建直播间**标签页，打开**开始时间**开关。根据需要配置其他设置，然后点击**保存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2e843fe975f422d9692c97ef726fbde~tplv-goo7wpa0wc-image.image) </span>

   * 批量创建直播间：在**批量创建直播间**标签页，点击**添加直播**或**添加录制**。打开**按开始时间后开播**开关。根据需要配置其他设置，然后点击**保存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd1037fd65894a289ad3002d6e578723~tplv-goo7wpa0wc-image.image) </span>


<span id="method-2-enable-the-feature-in-an-existing-live-room"></span>
### 方法二：在已有直播间启用该功能


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在左侧导航栏，点击**Producer** \> **基本信息**。

4. 在**基本设置**部分，打开**开始时间**开关，然后点击**保存**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6c6a63933ab549d2af25edf298b0f74f~tplv-goo7wpa0wc-image.image) </span>
