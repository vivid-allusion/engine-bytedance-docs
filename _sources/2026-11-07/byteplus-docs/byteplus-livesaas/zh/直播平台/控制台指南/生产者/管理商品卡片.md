## 前提条件

需拥有 BytePlus 账号或具备以下权限的 IAM 用户。如需了解如何添加 IAM 用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。


* Producer \> 编辑权限：用于添加和配置商品卡片菜单。

* Live control \> 编辑权限：用于在**Live control**页面配置商品卡片。

## 操作流程

本流程介绍如何添加商品卡片菜单、如何从自有系统或 Shopify 添加商品库，以及最终如何添加商品。

<span id="e2390d98"></span>
### 步骤1：添加商品卡片菜单


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击打开一个直播间。

3. 在左侧导航栏，点击**Producer** \> **Menus**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/001115ee5891477097220e74c0b79d7c~tplv-goo7wpa0wc-image.image) </span>

4. 添加商品卡片菜单。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8035397ebb184ab2bd1c2ffcbc487b0a~tplv-goo7wpa0wc-image.image) </span>

   1. 点击**Edit menu**。

   2. 在弹出的**Edit menu**对话框中，点击**Add**。

   3. 在**Menu type**下拉列表中选择**Product cards**，并在**Menu name**字段中输入菜单名称。

   4. （可选）拖动以调整菜单顺序。

   5. 点击**Confirm**。

      每个直播间最多可添加 5 个商品卡片菜单。


<span id="0b085a3d"></span>
### 步骤2：配置商品菜单

按需配置菜单的基本信息。


* 为使不同平台的观众在点击商品卡片后跳转到不同链接，请启用直达链接功能。你最多可配置 5 个环境，每个环境通过 User Agent 标识，并可在每个商品卡片上为每个环境设置独立的直达链接。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">该功能仅支持移动端。   </div>
   

   1. 开启**直达链接**开关。

   2. 在**特定环境的 User Agent**字段中最多添加 5 个环境。针对每个环境，配置以下内容：

      * **环境名称**：用于标识环境的名称，最多 20 个字符。配置商品卡片时，该名称用于标注对应的直达链接。

      * **User Agent**：目标环境的 User Agent 字符串，最多 500 个字符。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ad83d9bb26854dcf874a5b5db6c53ccf~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">在该功能升级前创建的直达链接配置会自动迁移至名为 <strong>Env1</strong> 的单一环境。   </div>
   

   3. 配置商品卡片信息时，为每个环境输入直达链接。

      当观众在 User Agent 包含**特定环境的 User Agent**字段中配置值的平台上点击商品卡片时，将跳转至该商品卡片为该环境配置的直达链接。若观众在未匹配任何已配置环境的平台上点击商品卡片，则将跳转至商品卡片的商品链接。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0a331c10c50045e1aeb3283cfd195775~tplv-goo7wpa0wc-image.image) </span>

* 选择商品浮窗在 PC 端观看页的显示位置。默认情况下，商品浮窗显示在播放器右上角。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3a733b20a33c4c64bae6a835d3026843~tplv-goo7wpa0wc-image.image) </span>

* 选择商品详情页的展示方式。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7e11f14b095f4dd1a3b3e73c7ca42f79~tplv-goo7wpa0wc-image.image) </span>

   * 在新页面显示：在新的浏览器标签页中打开产品详情页。观众无法同时观看视频和查看产品详情。

   * 在直播间以浮动页面显示：观众点击商品卡片后，直播间会弹出浮动页面显示产品详情页。观众可以同时观看视频和查看产品详情页。此选项仅在移动设备上生效。


<span id="9ad7b1af"></span>
### （可选）Step 3: 添加自有系统或 Shopify 的产品库

添加自有系统或 Shopify 的产品库。然后，你可以将产品库中的产品添加到直播间。


1. 点击\*\*+添加产品库\*\*。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/39859dfdfe9f4703b1776408365b0d14~tplv-goo7wpa0wc-image.image) </span>

2. 在弹出的**产品库**对话框中，添加一个或多个产品库。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21bf3b3d572c4f8f9be7704468647d82~tplv-goo7wpa0wc-image.image) </span>

   1. 修改产品库名称。确保该名称在直播间中唯一。

   2. 选择产品库类型，以添加自有系统或 Shopify 的产品库。

      * **自有系统**：输入用于从产品库获取产品的请求 URL。

         <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="3">warning         </div>
         

         <div data-tips="true" data-tips-type="warning" data-wrapper-indent="3">你必须按照规范开发 API，将你的系统与 BytePlus Live 集成后，才能添加自有系统的商品库。更多信息，请参见 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#f4985fe1">将你的系统集成至 BytePlus Live</a>。         </div>
         

      * **Shopify**：输入域名和公共访问令牌。

         * **域名**：你的 Shopify 商店的域名。

            获取域名时，点击 Shopify 商店左侧导航栏的 Settings，在商店名称下方查看域名。你也可以点击 Settings \> Domains，在 Domains 页面查看域名。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0aa4e1b2fc5349e184af839897ce7db9~tplv-goo7wpa0wc-image.image) </span>

         * **公共访问令牌**：你的 Shopify 商店 Storefront API 的公共访问令牌。

            获取令牌时，进入 Shopify 商店的**Headless sales channel**页面。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fcc45a5e3e8b4813b7218b86c6e766be~tplv-goo7wpa0wc-image.image) </span>

            点击**Manage**，在 Storefront API 页面查看公共访问令牌。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/084b594a5b10486f8af763fe4f1fddfc~tplv-goo7wpa0wc-image.image) </span>

            点击保存图标。

            <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f44dec36f7a94a829864eecee2d0441d~tplv-goo7wpa0wc-image.image) </span>


<span id="4815086b"></span>
### Step 4: 从产品库或手动添加商品卡片

在商品卡片菜单下最多可添加 500 个商品卡片。


* 从产品库添加商品卡片

   1. 点击**从产品库添加**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3bd3471936c44ebb97f1e5dc70c37725~tplv-goo7wpa0wc-image.image) </span>

   2. 在弹出的从产品库添加对话框中，选择在 Step 3 添加的产品库中的产品，然后点击添加。在搜索具体产品时支持模糊搜索。

      要隐藏 Shopify 产品库中的某些产品，必须在 Shopify 中添加指定的产品 metafield，并设置为 True。更多信息，请参见[在 Shopify 商品库中隐藏指定商品](https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#bd977a0e)。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/05e26384d1e04d0fa88f60d9c7308170~tplv-goo7wpa0wc-image.image) </span>

   3. 点击**添加**。

* 手动添加商品卡片

   * 一次添加多个商品卡片

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/107dc3bbd8a34b40a23ee8a438c4d9ac~tplv-goo7wpa0wc-image.image) </span>

      1. 点击**导入**。

      2. 在弹出的**导入**对话框中，点击**下载模版**。

      3. 按照指引编辑模版，然后上传已更新的模版。

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">你只能在模版中输入文本。图片只能在控制台上传。      </div>
      

   * 一次添加一个商品卡片

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1403fe0cd09941d7b5354eb61a5eb348~tplv-goo7wpa0wc-image.image) </span>

      点击**添加**，并完成以下配置。

      
      |字段 |接口行为 |
      |---|---|
      |**商品名称** |你的商品名称。 |
      |**商品描述** |你的商品的附加信息，例如移动设备的容量。 |
      |**产品分类** |您的产品分类，例如服装。 |
      |**零售价** |您的产品零售价。 |
      |**刊例价** |您的产品刊例价。 |
      |**产品图片** |商品卡片左侧的产品图片。您可以上传不超过 2 MB 的 JPG 或 PNG 文件。 |
      |**按钮图片** |商品卡片右下角的按钮图片。观众点击按钮后将跳转至产品 URL 或直达链接。<br><br>您可以点击**替换**，将默认图片替换为不超过 2 MB 的 JPG 或 PNG 文件。此操作会更新所有现有和未来商品卡片的按钮图片。推荐分辨率为 160×60。 |
      |**产品 URL** |产品详情页的 URL。 |
      |**直达链接** |产品详情页的直达链接。在第 2 步已开启直达链接功能后，每个已配置环境会出现一个**直达链接**字段，并以环境名称标记（例如，**Env1**）。请根据需要为每个环境填写直达链接。 |

### （可选）Step 5: 按需管理商品卡片


* 切换商品卡片右侧的列表开关，可在观看页显示或隐藏该商品卡片。

* 点击**导出**，导出所有商品卡片的信息。

* 点击商品卡片右侧的**删除**，删除该商品卡片。

* 点击商品卡片右侧的**置顶**，将该商品卡片置顶。

* 拖动以调整商品卡片的顺序。


（可选）在左侧导航栏，点击**Live control**。在商品卡片菜单下，你可以执行以下操作。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/859e93898702476fabe95e3b8fd99052~tplv-goo7wpa0wc-image.image) </span>


* 点击**Pin product**，可将商品卡片置顶于菜单，在控制台和观看页均显示，并在观看页以悬浮窗形式展示商品卡片。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">请确保商品卡片已配置产品图片。   </div>
   

* 点击**Unpin product**，可将商品卡片恢复至控制台和观看页的原始位置，并停止在观看页以悬浮窗形式展示商品卡片。

* 点击**List**或**Unlist**，可实时在观看页上上架或下架商品卡片。

* 点击**Pin**图标，可将商品卡片置顶于菜单，在控制台和观看页均显示。

* 拖动以调整商品卡片在控制台和观看页的显示顺序。

* 可根据商品标题或序列号搜索商品卡片。你可以对商品标题进行模糊搜索。

### 在 Shopify 商品库中隐藏指定商品

要在 Shopify 商品库中隐藏指定商品，必须在 Shopify 中添加特定商品元字段，并将其设置为 True。

完成以下步骤以添加商品元字段。


1. 在 Shopify 店铺的左侧导航栏，点击**Settings**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/72c09822780247e6a47feea143046604~tplv-goo7wpa0wc-image.image) </span>

2. 在左侧导航栏点击**Metafields and metaobjects**，然后点击**Products**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe5942dbdf284be4a9571f7f2eb3f7ea~tplv-goo7wpa0wc-image.image) </span>

3. 在右上角点击**Add definition**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31fb82011ab94018853e139082cd71d6~tplv-goo7wpa0wc-image.image) </span>

4. 选择**Other** \> **True or false**作为数据类型，并输入**forbid_show_in_byteplus_live**作为名称。确保**Namespace and key**字段值以`custom.`开头。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c2f631d91c9a417db06d83e60ed1c530~tplv-goo7wpa0wc-image.image) </span>


如果 Shopify 店铺中的某个商品的**forbid_show_in_byteplus_live**字段设置为**True**，该商品将不会在添加到 BytePlus Live 的 Shopify 商品库中显示。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e71c99b925654c8e8d4c8ca6671df8c9~tplv-goo7wpa0wc-image.image) </span>

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">在 Shopify 中修改字段值后，最多可能需要 1 分钟，您才能从 Shopify 产品库获取最新的产品列表。</div>

### 为 Shopify 商品配置直达链接

若已开启直达链接功能，并已为每个商品的各环境配置多个直达链接（参见[步骤2：配置商品菜单](https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#0b085a3d)），你可以按照如下方式在 Shopify 中添加商品元字段，为每个环境设置 Shopify 商品的直达链接。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/15d642b7ad4e4a6ca0fb9b5bad485a94~tplv-goo7wpa0wc-image.image) </span>

完成以下步骤以添加直达链接元字段。


1. 在 Shopify 店铺的左侧导航栏，点击**Settings**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/72c09822780247e6a47feea143046604~tplv-goo7wpa0wc-image.image) </span>

2. 在左侧导航栏点击**Metafields and metaobjects**，然后点击**Products**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe5942dbdf284be4a9571f7f2eb3f7ea~tplv-goo7wpa0wc-image.image) </span>

3. 在右上角点击**Add definition**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31fb82011ab94018853e139082cd71d6~tplv-goo7wpa0wc-image.image) </span>

4. 选择**Single line text**作为数据类型，并输入`direct_url_1`作为第一个环境的名称。确保**Namespace and key**字段值以`custom.`开头。根据需要，针对每个环境重复此步骤，分别为`direct_url_2`至`direct_url_5`。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a5cc66ff0c31473bbbc6cb8daedd796f~tplv-goo7wpa0wc-image.image) </span>

5. 现在你可以进入商品页面，在每个商品对应环境的匹配元字段中输入直达链接。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0a4cc31c79274f4b9663b3b1e8a9b9b2~tplv-goo7wpa0wc-image.image) </span>


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Shopify 中的<code>direct_url_1</code> 到 <code>direct_url_5</code> 元字段，必须与 BytePlus Live 控制台<strong>特定环境的 User Agent</strong> 字段中配置的环境一一对应且顺序一致。例如，<code>direct_url_5</code> 仅对应控制台上为该产品配置的第五个环境（及其直达链接）。顺序不一致会导致观众跳转到错误的链接。</div>

### 将你的系统集成至 BytePlus Live

在将你自有系统的商品库添加到 BytePlus Live 的直播间前，必须按照规范开发以下 API，以实现系统与 BytePlus Live 的集成。

如有关于集成的任何疑问，请联系 BytePlus Live 技术支持。

<span id="32f5a471"></span>
#### 流程

如果你的系统中的商品数量超过指定上限，建议联系 BytePlus Live 技术支持，将你的 BytePlus 账号加入白名单。否则，在调用此 API 时将不会返回任何商品。

流程会根据你的账号是否在白名单中而有所不同。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/66eb68e3023b4fd195f2d92f77cffb5e~tplv-goo7wpa0wc-image.image) </span>


1. 你在 BytePlus Live 控制台配置自有系统的请求 URL。该 URL 用于接收 API 调用。

2. BytePlus Live 控制台会将配置的请求 URL 发送至 BytePlus Live 服务器。

3. BytePlus Live 服务器会将 URL 配置状态返回给 BytePlus Live 控制台。

4. 你在 BytePlus Live 控制台或集成了 iOS 开播 SDK 或 Android 的应用中点击 **从库中添加**。

   如果你的账号在白名单中，BytePlus Live 服务器不会调用此 API。

   如果你的账号不在白名单中，流程如下：

   1. 当你首次在 BytePlus Live 控制台或应用中点击 **从库中添加** 时，BytePlus Live 服务器会调用此 API 加载商品。

   2. 你的服务器会返回系统中的所有商品。

   3. BytePlus Live 服务器会将这些商品返回给 BytePlus Live 控制台或应用。

5. 你在 BytePlus Live 控制台或集成了 iOS 开播 SDK 或 Android 的应用的 **从库中添加** 对话框中输入关键词。

   如果你的账号在白名单中，流程如下：

   1. BytePlus Live 会在 BytePlus Live 服务器上搜索名称包含该关键词的商品。

   2. BytePlus Live 会调用此 API，在你的系统中搜索名称包含该关键词的商品。

      <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="2">warning      </div>
      

      <div data-tips="true" data-tips-type="warning" data-wrapper-indent="2">为避免超时或其他 API 错误，建议 API 返回结果不超过 5000 条。      </div>
      

   3. 你的服务器会将搜索结果返回给 BytePlus Live 服务器。

   4. BytePlus Live 服务器会将搜索结果返回给 BytePlus Live 控制台或应用。

      如果你的账号不在白名单中，BytePlus Live 会在第 4 步返回的商品中搜索名称包含该关键词的商品，并在 BytePlus Live 控制台或应用中展示搜索结果。

#### 从自有系统查询商品

**接口行为**：BytePlus Live 可调用此 API 从你的自有系统获取商品，并在 BytePlus Live 控制台展示商品。

**Method**：GET

**请求参数**

**Query**


|参数名称 |数据类型 |是否必填 |示例值 |接口行为 |
|---|---|---|---|---|
|AccountId |Integer |是 |`<YOUR_ACCOUNT_ID>` |您的 BytePlus 账号的账户 ID。您可以点击 BytePlus Live 控制台右上角头像获取该 ID。 |
|Ts |Integer |是 |`1650778541` |调用 API 时的系统时间，Unix 时间戳格式。单位：秒。 |
|FilterName |String |否 |Cola |在**从库中添加**对话框中输入的关键词。通过该参数，您只能返回系统中名称包含该关键词的产品。<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">此参数为必填项，且仅在你的 BytePlus 账号按照 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#32f5a471">流程</a>中的说明加入 allowlist 后才生效。</div><br> |
|Sign |String |是 |`c604c2d2df****************ed2f5` |用于校验的签名。<br><br>要获取`Sign`的值，您需完成以下步骤：<br><br><br>1. 按参数名称的字典序对所有参数及其值进行排序。<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">仅在你的 BytePlus 账号按照 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#32f5a471">流程</a>中的说明加入 allowlist 后，才需包含参数 <code>FilterName</code>。   </div><br>   <br><br>2. 以`ParameterNameParameterValueParameterNameParameterValue`的格式拼接字符串。<br><br>3. 在字符串开头和结尾分别添加`accountSecret`的值。如需获取`accountSecret`的值，请联系 BytePlus 技术支持。<br><br>4. 将拼接后的字符串以 MD5（32 位小写）加密。<br><br><br>本例中，假设`accountSecret`的值为`abc`。拼接后的字符串为`abcAccountId310000009Ts1650778541abc`，`Sign`的值为`c604c2d2df0e982b9506868a891ed2f5`。<br><br>如果你的 BytePlus 账号已按照 [流程](https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#32f5a471) 中的说明添加至白名单，则拼接后的字符串为 `abcAccountId310000009FilterNameColaTs1650778541abc`，`Sign` 的值为 `07be033db13866fcea72503355dd3431`。 |
