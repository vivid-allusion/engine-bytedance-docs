为提升直播流期间观众互动体验，您可以使用问答功能。本指南提供逐步操作说明，帮助您添加问答菜单、配置相关设置，并实时管理讨论。您将学习如何管理包括问题数量限制、用户权限，以及置顶、禁言和导出问答数据等实时操作。

<span id="prerequisite"></span>
## 前提条件

您必须拥有 BytePlus 账号或具备以下权限的 IAM 用户。如需了解如何添加 IAM 用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。


* Producer \> 编辑权限：用于配置问答菜单。

* Live control \> 编辑权限：用于执行发布和回复问题等操作。


<span id="procedure"></span>
## 操作流程


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 按以下步骤添加问答菜单：

   1. 在左侧导航栏，点击**Producer** \> **Menus**。

   2. 点击**Edit menu**。

   3. 在弹出的对话框中点击**Add**。

   4. 输入菜单名称，并在**Menu type**下拉列表中选择**Q&A**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/83e67d33653a4e9fa29cdc32d26bc06a~tplv-goo7wpa0wc-image.image) </span>

   5. （可选）拖动以调整菜单顺序。

   6. 点击**Confirm**。

   7. 在**Menus**页面点击**Save**。

4. 在问答菜单下，您可以配置以下设置。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d7d1d38fe1c44cb8a5c051c57c4842fb~tplv-goo7wpa0wc-image.image) </span>

   * 开启**观众提问**开关，允许观众在观看页发布问题。若关闭该开关，观众仅可回复主播发布的问题。

   * 在**每位观众最多提问数**字段中，设置每位观众可发布问题的最大数量。

   * 在**最短发送间隔**字段中，设置用户连续评论的最短时间间隔。取值范围：[1,300]。例如，若设置为 3，则无论主播还是观众，距离上次提交不足 3 秒时无法发布或回复。

   * 在**输入框占位符**字段中，自定义问答输入框显示的占位文本。

   * 在**主播昵称**字段中，修改问答区域的主播显示名称。

   * 选择问答区域在 PC 端的显示模式。

5. 在**Live control**页面的问答面板，您可以执行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9052fa9f05d4411e9554486de6ac6eaa~tplv-goo7wpa0wc-image.image) </span>

   * 按状态或内容筛选问题。支持模糊搜索。

   * 按时间或热度排序问题及回复。

   * 发布问题。

   * 回复问题。

   * 将问题或回复置顶。

   * 点赞问题或回复。

   * 从观看页删除问题或回复。删除某个问题时，其所有回复也会从观看页移除。

   * 对观众进行禁言或解除禁言。将鼠标悬停在问题或回复旁的省略号图标上，选择**Mute**以禁言该观众。被禁言的观众无法发布或回复问题。如需解除禁言，请将鼠标悬停在该观众发布的问题或回复旁的省略号图标上，选择**Unmute**。

      观众的禁言依据其 UID，不同登录方式对应的 UID 也不同。例如，你将仅通过输入昵称登录到直播间的观众禁言。该观众随后选择通过手机号登录到直播间。这样，观众拥有一个与被禁言的 UID 不同的 UID，并且可以发布和回复问题。

   * 点击输入框上方从左数第二个图标，切换观众是否可以发布问题。

   * 点击输入框上方从左数第三个图标，启用或禁用人工审核功能。当该功能已开启时，新的问题和回复仅作者可见，直到审核通过。点击问题或回复旁的 **√** 以通过审核。审核通过后，问题或回复将在观看页对所有人可见。

   * 点击**导出数据**图标，将问答数据导出到本地文件。

   * 点击**清除评论**图标，清空观看页的问答区。
