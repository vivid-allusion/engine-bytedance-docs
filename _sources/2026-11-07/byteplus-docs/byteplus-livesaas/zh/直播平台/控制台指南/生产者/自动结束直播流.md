要在指定时间自动结束你的直播流，可以启用直播流结束时间功能。本指南将介绍如何在创建新的直播间或现有直播间时启用该功能。启用后，直播页面会显示倒计时计时器，直播流将在配置的时间自动停止，非常适用于在线课程或培训等场景。

<span id="what-the-host-sees"></span>
## 主播所见

倒计时计时器显示在直播页面顶部，并在最后5分钟内更加醒目。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5dbaf059519845edba078044978fa042~tplv-goo7wpa0wc-image.image) </span>

<span id="prerequisite"></span>
## 前提条件

一个 BytePlus 账号或 IAM 用户。要在现有直播间启用该功能，IAM 用户必须拥有 Producer \> Edit 权限。关于如何添加 IAM 用户的更多信息，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

<span id="procedure"></span>
## 操作流程

你可以通过以下方式之一启用自动结束时间功能。


* 直播流结束时间必须晚于开始时间，最大时差为72小时。

* 在直播流进行期间，无法启用或禁用该功能，也无法修改直播流结束时间。

* 直播流自动结束后，必须重新设置新的直播时间才能再次开始直播。


<span id="method-1-create-a-live-room-with-the-feature-enabled"></span>
### 方法一：创建已开启该功能的直播间


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在**直播间**页面，点击**创建直播间**。

3. 在**创建直播间**页面，可以选择一次创建一个或多个直播间。

   * 创建单个直播间：在**创建直播间**标签页，打开**结束时间**开关并设置结束时间。根据需要完成其他配置，并点击**保存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4ac3050042e342e788b6dc0fc2ade6df~tplv-goo7wpa0wc-image.image) </span>

   * 批量创建直播间：在**批量创建直播间**标签页，点击**添加直播**或**添加录播**。打开**结束时间**开关并设置结束时间。根据需要完成其他配置，并点击**保存**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5a7498401bd2413da41f838b442b8099~tplv-goo7wpa0wc-image.image) </span>


<span id="method-2-enable-the-feature-in-an-existing-live-room"></span>
### 方法二：在现有直播间启用该功能


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在左侧导航栏，点击**Producer** \> **基本信息**。

4. 在**基础设置**部分，打开**结束时间**开关并设置结束时间。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/59d0b707405141b7b1ad91f86993a88b~tplv-goo7wpa0wc-image.image) </span>
