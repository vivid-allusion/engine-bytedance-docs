为了在直播流期间吸引观众、收集反馈或管理报名，您可以使用问卷功能。本指南提供逐步操作说明，帮助您手动发送问卷以实现实时互动，或配置问卷在观众进入直播间或直播流结束后自动发送。

<span id="scenarios"></span>
## 适用场景

您可以根据需要配置问卷的以下发送时间。将问卷的发送时间设置为**观众进入直播间时**或**直播流结束时**，问卷将自动发送。


* **观众进入直播间时**：适用于签到、报名等场景。观众必须在观看直播流前提交问卷。更多信息，请参见[Sending a questionnaire automatically](https://docs.byteplus.com/docs/byteplus-livesaas/docs-send-questionnaire-zh-CN#964c76bd)。

* **直播流结束时**：适用于收集观众对直播流的反馈和意见等场景。观众可选择是否提交问卷。更多信息，请参见[Sending a questionnaire automatically](https://docs.byteplus.com/docs/byteplus-livesaas/docs-send-questionnaire-zh-CN#964c76bd)。

* **手动发送**：适用于直播流期间与观众实时互动的场景。更多信息，请参见[Sending a questionnaire manually](https://docs.byteplus.com/docs/byteplus-livesaas/docs-send-questionnaire-zh-CN#01784943)。


<span id="prerequisites"></span>
## 前提条件


* 请确保已开启互动工具菜单。更多信息，请参见[管理互动区域](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-interaction-area-zh-CN)。

* 要手动发送问卷，您需要拥有 BytePlus 账号或具备 Live control \> Edit 权限的 IAM 用户。

* 自动发送问卷：需要 BytePlus 账号或具备 Marketing toolkits \> Edit 权限的 IAM 用户。


关于如何添加 IAM 用户的更多信息，请参见[用户、组织和角色管理](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

<span id="sending-a-questionnaire-manually"></span>
## 手动发送问卷


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击一个直播间以打开。

3. 在**Live control**页面，点击互动工具菜单下的**问卷**。

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f289ccd4770c48ef8c72b0a70b6001a0~tplv-goo7wpa0wc-image.image" width="1831px" />   </div>
   

   为获得更佳观看体验，建议您打开右下角的**显示菜单**开关。

4. 在弹出的对话框中点击**创建问卷**。

5. 在弹出的**问卷**对话框中，完成以下配置并点击**保存**。

   若该直播间已有问卷，点击**创建**，然后完成以下配置。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/803a437aa48742cebaf7f092c30beb87~tplv-goo7wpa0wc-image.image) </span>

   * 输入问卷标题和描述。

   * 至少添加一个问题。

6. 点击**添加至发送区**，然后在互动工具菜单下点击**发送**，将问卷发送至观看页。

   如有多个未发送问卷，请先在左侧选择问卷，再点击**添加至发送区**。

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a718f757e76a4a18a393ded6582a9325~tplv-goo7wpa0wc-image.image" width="1193px" />   </div>
   

   您也可以在互动工具菜单下点击**问卷**，在弹出的对话框中选择要发送的问卷。点击**发送**，将问卷发送至观看页。

7. 对于未发送的问卷，您可以复制、预告、编辑或删除。对于已发送的问卷，您可以复制、预告、分享或删除。

8. （可选）在互动工具菜单下，您可以执行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/60f18e86705d497da9e728c27cb3a2f5~tplv-goo7wpa0wc-image.image) </span>

   * 点击**撤回**图标，撤回已发送的问卷。

   * 点击**预告**图标，预告问卷。

   * 点击**分享**图标，通过复制或下载二维码分享问卷。


你也可以在**洞察** \> **问卷数据**页面查看问卷数据。更多信息，请参见[数据统计](https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-data-statistics)。

<span id="sending-a-questionnaire-automatically"></span>
## 自动发送问卷


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在左侧导航栏，点击**营销工具包** \> **问卷**。

4. 点击**创建问卷**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5fa4935c45794a8d94bf43217c94e3fe~tplv-goo7wpa0wc-image.image) </span>

5. 完成以下配置后，点击**确定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a44b4a9babf4986859f5785c5f15004~tplv-goo7wpa0wc-image.image) </span>

   * 根据需要选择问卷的发送时间。

      你也可以在**直播控制**页面配置发送时间为**手动发送**的问卷。更多信息，请参见[Sending a questionnaire manually](https://docs.byteplus.com/docs/byteplus-livesaas/docs-send-questionnaire-zh-CN#01784943)。

   * 输入问卷的标题和描述。

   * 添加至少一个问题。

6. 在**操作**列点击**发布**，将问卷发送到观看页。随后，具有相同发送时间的现有问卷将被此新发布的问卷覆盖。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/29c5161353d7420d9efd25d3ccf08088~tplv-goo7wpa0wc-image.image) </span>

7. （可选）你可以复制、发布、预览、编辑或删除未发送的问卷，也可以复制、撤回或预览已发送的问卷。


你也可以在**洞察** \> **问卷数据**页面查看问卷数据。更多信息，请参见[数据统计](https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-data-statistics)。

<span id="best-practices"></span>
## 最佳实践

<span id="publishing-a-sign-in-questionnaire"></span>
### 发布签到问卷

如果观众在提交问卷前未输入昵称，则问卷为匿名，数据在某些场景下可能无效。为避免此情况，你可以发布签到问卷，要求观众在进入直播间时输入昵称。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f191b228a730471d8df46f04a203bc35~tplv-goo7wpa0wc-image.image) </span>

观众在签到问卷中输入的昵称与直播流期间使用的昵称一致。例如，观众在签到问卷中输入昵称 User A，则在聊天区域会自动获得相同昵称 User A。你可以认为签到问卷中昵称为 User A 的观众与聊天区域昵称为 User A 的观众为同一人。对于昵称相同的观众，你可以通过用户 ID 进一步区分。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3dd3ce2f53964ab69b406e003a81c819~tplv-goo7wpa0wc-image.image) </span>


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在左侧导航栏，点击**营销工具包** \> **问卷**。

4. 点击**创建问卷**。

5. 在**创建问卷**对话框中，选择**观众进入直播间时**作为发送时间。点击**添加问题**，并选择**个人信息** \> **昵称**作为问题类型。完成其他配置后，点击**确定**。

6. 在**操作**列点击**发布**，发布签到问卷。


<span id="signing-up-for-a-live-stream"></span>
### 报名直播流

你可以通过发布问卷允许观众报名直播流。换句话说，观众在进入直播间时必须输入手机号和邮箱。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e6003d6a5f7f4e0ebd0653a11c0daf85~tplv-goo7wpa0wc-image.image) </span>


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击以打开直播间。

3. 在左侧导航栏，点击**营销工具包** \> **问卷**。

4. 点击**创建问卷**。

5. 在**创建问卷**对话框中，选择**观众进入直播间时**作为发送时间。点击**添加问题**，添加两个问题。分别将问题类型设置为**个人信息** \> **手机号**和**个人信息** \> **邮箱**。完成其他配置后，点击**确定**。

6. 在**操作**列点击**发布**，发布签到问卷。
