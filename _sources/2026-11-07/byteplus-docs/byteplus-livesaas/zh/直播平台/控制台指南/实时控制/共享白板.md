在网页浏览器的直播流页面上，你可以共享白板，并在白板页面上绘制内容，以展示信息和可视化概念。

<span id="scenarios"></span>
## 适用场景

白板功能广泛适用于教学和培训场景：


* 公开课教师可以使用白板高效快速地传递知识，提升观看体验并增加课程转化率。

* 在线课程讲师可以通过白板直观演示和讲解案例，从而提升教学效率。

* 企业培训讲师可以利用白板直观展示培训内容，帮助员工更好地理解培训内容。

|10 |撤销 |点击图标可撤销当前白板页面上的最后一次操作。要撤销多次操作，可重复点击该图标。最多可撤销 30 次操作。<br><br>你也可以在键盘上按下 Mac 的 command + z 或 Windows 的 ctrl + z，撤销当前白板页的上一步操作。 |
|11 |重做 |点击图标可恢复当前白板页面上最后一次撤销的操作。要恢复多次操作，可重复点击该图标。最多可恢复30次操作。<br><br>你也可以在Mac上按command + shift + z，或在Windows上按ctrl + shift + z，通过键盘恢复当前白板页面上被撤销的操作。 |
|12 |清除 |点击图标可清除当前白板页面上的所有标记。 |


<span id="prerequisites"></span>
## 前提条件


* 建议你使用符合直播流指定要求的设备和浏览器，以确保获得流畅的直播流体验。更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)。

* 如果你通过控制台进入直播流页面，请确保你拥有BytePlus账号或具备Live control \> Edit权限的IAM用户。关于如何添加IAM用户的更多信息，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

* 如果你通过链接进入直播流页面且未登录，则无需控制台权限即可共享白板。


<span id="procedure"></span>
## 操作流程


1. 登录[BytePlus Live控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 选择**网页浏览器**作为推流方式，进入直播流页面。更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)。

3. 白板页面默认显示。你可以执行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/26f53bcd89394f729154e9ff1d2bcd06~tplv-goo7wpa0wc-image.image) </span>

   * 在白板页面上绘制。更多信息，请参见[共享白板](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sharing-documents-and-pictures-zh-CN)。

   * 点击左侧的**添加白板**，可新增更多白板页面。最多可拥有10个白板页面，包括默认的3个页面。

   * 将鼠标指针移至左侧的白板页面，并点击删除按钮以删除该页面。

   * 直播间内所有演讲者共享同一组白板页面。这意味着新演讲者加入时，会看到前一位演讲者正在查看的同一白板页面及内容，并可继续在其上绘制。

   * 白板页面上绘制的内容会保留至直播流结束。如果添加了连麦（主播与主播），绘制内容会保留至主直播流和连麦环节均结束。

4. 若直播流尚未开始，点击**开始直播**，观众即可在观看页看到共享的白板。
