为了打造更具互动性和吸引力的直播流，您可以使用连麦（主播与主播）功能，邀请最多25位嘉宾加入您的直播。本指南为主播提供详细操作说明，包括如何开启连麦（主播与主播）会话、邀请嘉宾、管理不同布局以及控制参与者权限。同时还概述了会话期间演讲者和嘉宾可用的具体功能。

<span id="prerequisites"></span>
## 前提条件


* 主播必须拥有BytePlus账号，或是具有Live control \> Edit权限的IAM用户。如需了解如何添加IAM用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

   对于通过URL在网页浏览器中进入直播流页面的主播，无需满足此前提条件，可直接访问，无需登录。

* 我们建议主播和嘉宾在连麦（主播与主播）过程中使用符合[通过网页浏览器进行直播流](https://docs.byteplus.com/en/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser#environmental-requirements-to-start-a-live-stream)要求的设备和浏览器。

   嘉宾在连麦（主播与主播）过程中可使用集成或独立显卡。


<span id="roles"></span>
## 角色


|角色 |接口行为 |
|---|---|
|主播 |发起连麦（主播与主播）会话和直播流的人。主播拥有完全控制权限，包括设置演示者、锁定嘉宾摄像头以及将嘉宾移出连麦（主播与主播）会话。 |
|演示者 |连麦（主播与主播）中的主要参与者。默认情况下，主播即为演示者。主播可以将嘉宾设置为演示者，并可随时撤销或转移演示者角色。<br><br>连麦（主播与主播）会话每次仅允许一名演示者，且只有演示者可以使用共享、白板或文档功能。 |
|嘉宾 |连麦（主播与主播）会话中的参与者。 |


<span id="host"></span>
## 主播

主播可在直播流开始前或开始后与嘉宾连麦（主播与主播）。


1. 登录[BytePlus Live控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 选择**网页浏览器**作为直播方式，并进入直播流页面。如需了解更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)。

3. 点击**与嘉宾连麦（主播与主播）** 。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/689c7ad2fec34948a25ad0cd4b528604~tplv-goo7wpa0wc-image.image) </span>

   嘉宾也可以在连麦（主播与主播）开始前被邀请，但仅能在连麦（主播与主播）开始后加入。

4. 选择主播和嘉宾窗口的布局。默认选择演讲者视图。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/482851ca634d4284ae44ae4d26def8df~tplv-goo7wpa0wc-image.image) </span>

   * 焦点视图：将演讲者摄像头显示为主屏幕。该视图适用于单人演讲场景。

      如果主播锁定某位嘉宾的摄像头，主屏幕将显示该嘉宾的摄像头。

   * 演讲者视图：显示演讲者正在分享的内容，并将演讲者摄像头作为主屏幕。该视图适用于演讲者使用**分享**、**白板**或**文档**功能时。

      如果主播锁定某位嘉宾的摄像头，主屏幕将同时显示该嘉宾的摄像头和演讲者正在分享的内容。

      * 仅当演讲者或被锁定嘉宾的摄像头开启时，才可显示其摄像头。

      * 已显示的摄像头可拖动至所需位置。

   * 画廊视图：显示多个参与者的摄像头以及演讲者正在分享的内容。该视图适用于多方会议和多站点连线场景。

   * 嘉宾可自行选择主播和嘉宾窗口的布局。即使主播更改布局，嘉宾所选布局不会被更改。

   * 直播流开始后，观看页上的布局与主播端一致，但在焦点视图下，观看页不会显示主播和嘉宾的窗口。

5. 邀请嘉宾。

   1. 点击**邀请嘉宾**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fa817f2751b944b79abae76ee2ef550c~tplv-goo7wpa0wc-image.image) </span>

   2. 在弹出的**邀请嘉宾**对话框中，选择是否开启**密钥**开关。默认情况下，开关为开启状态。若开启，嘉宾必须输入密钥才能加入连麦（主播与主播）。

      主播也可以点击**更新密钥**，实时更新密钥。

      密钥更新后，现有嘉宾可以继续连麦（主播与主播），新嘉宾必须使用更新后的密钥才能加入。

   3. 点击**复制邀请信息**，并将复制的信息发送给待邀请的嘉宾。嘉宾随后可通过 Chrome 浏览器加入连麦（主播与主播）。更多信息，请参见[与嘉宾开启连麦（主播与主播）](https://docs.byteplus.com/docs/byteplus-livesaas/docs-starting-a-video-chat-zh-CN)。

      * 复制的信息包括活动 ID、直播间名称、登录 URL 和连麦（主播与主播）密钥。如果 Key 开关关闭，复制的信息中不包含密钥。

      * 主播也可以分别点击复制登录 URL 或密钥。

6. 在连麦（主播与主播）列表中，根据需要执行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bca79f9ca9cc4e94a51c665b998349f5~tplv-goo7wpa0wc-image.image) </span>

   * 点击**全部静音**，将除主播和主讲人外所有参与者的麦克风静音。新加入的参与者在连麦（主播与主播）时也会被静音。参与者可以自行解除静音。

   * 点击嘉宾右侧的摄像头图标，可请求嘉宾开启摄像头，或直接关闭摄像头。嘉宾可根据收到的提示选择是否开启摄像头。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/25a5f06e9bd647838c15ac1bf8d7fc67~tplv-goo7wpa0wc-image.image) </span>

   * 点击嘉宾右侧的麦克风图标，可请求开启或直接关闭嘉宾的麦克风。嘉宾可根据收到的提示选择是否开启麦克风。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/706d241798664e379c64653d894d3e6f~tplv-goo7wpa0wc-image.image) </span>

   * 点击嘉宾右侧的**更多**图标，执行以下操作。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f31c73731503419186f02db8d8fc92db~tplv-goo7wpa0wc-image.image) </span>

      * 点击**设为主讲人**，将该嘉宾设为主讲人。

         * 如果未设置嘉宾为主讲人，则主播为主讲人。

         * 若主讲人因异常退出连麦（主播与主播），主讲人角色将自动回归主播。

         * 更换主讲人时，系统会自动保存原主讲人共享的白板、文档和屏幕（包括整个屏幕、窗口和 Chrome 标签页）。若原主讲人在同一连麦（主播与主播）会话中再次被设为主讲人，可选择继续共享之前的内容。

      * 点击**撤销主讲人**，撤销主讲人角色。主播也可以点击另一嘉宾右侧的**更多**图标，并选择**设为主讲人**，更换主讲人。

      * 点击**修改昵称**，修改嘉宾昵称。

         * 昵称不得超过 60 个字符。

         * 主播也可以点击自己右侧的**更多**图标，并选择**修改昵称**，修改自己的昵称。

         * 主播昵称修改后，会自动同步到控制台、观众页面和直播流页面的聊天界面。

      * 点击**锁定摄像头**，将嘉宾摄像头锁定在主画面。

      * 点击解锁，解除嘉宾摄像头锁定。如需锁定其他嘉宾的摄像头，主播可点击该嘉宾姓名旁的更多图标，并选择锁定摄像头。

      * 点击**移除**，将嘉宾移出连麦（主播与主播）。

   * 点击**结束与嘉宾连麦**。所有嘉宾将自动退出连麦（主播与主播）。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/db42c2a1d45540d78d8faea7a8a10c0e~tplv-goo7wpa0wc-image.image) </span>


<span id="presenter"></span>
## 主讲人

演示者可以是主播，也可以是加入连麦（主播与主播）的嘉宾之一。


* 主播：如果没有嘉宾被设为演示者，则主播作为演示者。

* 嘉宾：主播可以将嘉宾设为演示者。


通过 Chrome 浏览器加入连麦（主播与主播）后，演示者可以使用**分享**、**白板**或**文档**功能。


* 只有主播作为演示者时，才能使用**白板**和**文档**功能。有关如何使用这些功能的详细信息，请参见[共享白板](https://docs.byteplus.com/docs/byteplus-livesaas/docs-sharing-documents-and-pictures-zh-CN)和[共享文档和图片](https://docs.byteplus.com/docs/byteplus-livesaas/share-doc-and-pic)。

* 使用**分享**功能分享整个屏幕、窗口或 Chrome 标签页时，建议选择分享 Chrome 标签页，以实现音频同步和更高清的观看体验。分享窗口时，建议不要最小化窗口，以避免影响观众体验。

<span id="guests"></span>
## 嘉宾

嘉宾收到主播的邀请信息后，在 Chrome 浏览器地址栏输入登录 URL，即可进入连麦（主播与主播）登录页面。


* 嘉宾无法通过移动设备加入连麦（主播与主播）。

* 嘉宾可以在主播开始或未开始直播流前后加入连麦（主播与主播）会话。


嘉宾可在连麦（主播与主播）列表中点击**修改昵称**图标，修改昵称。
