要将直播延时降低至1\-2秒，以适应电商或在线课堂等高度互动的场景，可以在BytePlus Live中启用超低延时功能。本文档将说明超低延时直播的优势，并提供针对新建或已有直播间启用该功能的详细操作步骤。

<span id="context"></span>
## 背景

随着“直播+”模式在各行业的快速发展，电商、在线课堂、体育赛事、互动娱乐等多种形式的互动直播日益普及。随着用户对直播实时互动需求的增长，端到端秒级延时时代已经到来。超低延时直播显著提升了电商和在线课堂等直播场景中主播与观众的体验。延时越低，直播的即时性和互动性就越强。因此，降低延时对于提升直播体验至关重要。

<span id="scenarios"></span>
## 适用场景

超低延时直播非常适用于以下需要低网络延时和强互动的直播场景。


* 电商：主播在上架商品后可以即时看到观众的评论和销售反馈，从而增强主播与观众的互动，提高商品转化率。

* 在线课堂：学生针对老师讲解的内容在聊天区域提问时，老师可以及时回复，提升教学质量。

* 体育赛事：观众可以实时获取现场动态。

* 互动娱乐：观众送出礼物时，主播能够即时反馈，增强主播与观众的互动。

* 医疗诊断：在医疗研讨会或医疗直播场景中，观众可以获得即时回复或诊断。


<span id="prerequisites"></span>
## 前提条件


* 需要拥有BytePlus账号或具备Live控制 \> 编辑权限的IAM用户。关于如何添加IAM用户的更多信息，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

* 使用以下浏览器的观众可以观看超低延时直播：

   * Google Chrome

   * Safari

   * Lark

   * WeChat

      建议使用最新版本以确保流畅的观看体验。


<span id="notes"></span>
## 注意事项


* 与普通延时直播相比，超低延时直播的观看时长按1:2比例统计观看时长。例如，若有1,000名观众，每人观看30分钟的普通延时直播、预告或回放，以及20分钟的超低延时直播，则总计消耗70,000分钟（1,000x30+1,000x20x2）的观看时长。

* 目前无法通过拉流播方式拉取超低延时直播流。


<span id="procedure"></span>
## 操作流程

您可以通过以下两种方式启用超低延时功能。

直播过程中无法启用或关闭超低延时功能。

<span id="method-1-create-an-ultra-low-latency-live-room"></span>
### 方式一：创建超低延时直播间


1. 登录[BytePlus Live控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在**直播间**页面点击**创建直播间**。

3. 在**创建直播间**页面的**创建直播间**标签页，选择**超低延时**作为直播延时。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1541020d106648b880197745219aa65e~tplv-goo7wpa0wc-image.image) </span>

4. 根据指引完成其他配置后，点击**保存**。


<span id="method-2-enable-the-ultra-low-latency-feature-in-an-existing-live-room"></span>
### 方法二：在已有直播间中启用超低延迟功能


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击一个直播间以打开它。

3. 在播放器下方的**推流方式**标签页，点击**管理直播源**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cc836721eed3407eaeaf48cae3bf2c19~tplv-goo7wpa0wc-image.image) </span>

4. 在弹出的**管理直播源**对话框中，开启一个或多个直播源的**超低延迟**开关，以为这些直播源启用超低延迟功能。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5297e47a59fd4cf987d7f7c98e0bd5c8~tplv-goo7wpa0wc-image.image) </span>

5. 点击**确认**。
