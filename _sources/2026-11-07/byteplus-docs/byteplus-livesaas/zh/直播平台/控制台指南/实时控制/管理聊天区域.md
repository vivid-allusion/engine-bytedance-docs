为提升互动性并维护直播间秩序，你可以使用聊天互动菜单。本指南提供了逐步操作说明，帮助你配置如置顶评论、弹幕和自动翻译等聊天功能，以及执行实时管理操作，如置顶评论、禁言观众和管理被举报内容。

<span id="prerequisites"></span>
## 前提条件

具备 BytePlus 账号或拥有以下权限的 IAM 用户。如需了解如何添加 IAM 用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。


* Producer \> 编辑权限：用于配置聊天互动菜单。

* Live control \> 编辑权限：用于执行查看和回复观众评论等操作。


<span id="context"></span>
## 背景信息

聊天互动菜单是直播间的常用功能，提供多种工具以提升互动性并维护秩序。

<span id="procedure"></span>
## 操作步骤


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在左侧导航栏，点击**Producer** \> **Menus**。

4. 添加聊天互动菜单。

   1. 点击**Edit menu**。

   2. 在弹出的对话框中点击**Add**。

   3. 输入菜单名称，并在**Menu type**下拉列表中选择**Chat interaction**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d8a7ebb076bc465abc32fb8a28046c99~tplv-goo7wpa0wc-image.image) </span>

   4. （可选）拖动以调整菜单顺序。

   5. 点击**Confirm**。

   6. 在**Menus**页面点击**Save**。

5. 在聊天互动菜单下，完成以下配置后点击**Save**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2a93f92341174075985c1f1fd15f6a16~tplv-goo7wpa0wc-image.image) </span>

   * 开启**Hot list**开关以启用置顶评论功能。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/046854a302cc499ca355e080b9be39ee~tplv-goo7wpa0wc-image.image) </span>

      功能启用后，你可以：

      * 更改置顶评论菜单的名称。

      * 开启**Manually select top comments**开关。此时，观看页展示的置顶评论为你手动选择的内容，而非按点赞数排序。

      * 开启**Like**开关。此操作将在聊天互动和置顶评论菜单下显示点赞图标，并在观看页的置顶评论菜单下显示点赞数量。

      * 配置置顶评论菜单下可展示的评论最大数量。

         在移动设备上，置顶评论菜单仅在横屏模式下显示。

   * 在**Minimum sending interval**字段中，设置用户发送评论的最小间隔时间。取值范围：[1,300]。例如，若输入 3，则无论是主播还是观众，在上一次发送评论后 3 秒内均无法再次发送评论。

   * 在**Text box placeholder**字段中，编辑观看页聊天输入框中显示的占位文本。

   * 在**Host's nickname**字段中，修改主播昵称。

   * 开启**Bullet comments**开关。此后，在直播流过程中，评论会在观看页上滚动显示。观众可开启或关闭弹幕，并配置其透明度、显示区域、速度和字体大小。

   * 开启**Comment translation**开关。

      如需使用该功能，需先开启**Languages**开关，并在**Producer** \> **Basic information**页面选择相应语言。例如，如果大多数评论为英文，且你希望帮助不懂英文的观众跟进对话，可以开启**语言**开关，并选择目标语言，如**日语**。对于默认浏览器语言（PC端）或系统语言（移动设备）为日语的观众，评论会自动翻译为日语。观众也可以在观看页手动切换页面语言为日语，以便查看日语评论。

      目前支持以下语言之间的互译：

      * 简体中文

      * 英文

      * 日语

      * 繁体中文

      * 韩语

      * 泰语

      * 越南语

      * 阿拉伯语

      * 土耳其语

      * 西班牙语

      * 印尼语

      * 葡萄牙语

      * 俄语

      * 塔加洛语

      * 高棉语

      * 老挝语

      * 缅甸语

      * 马来语

      * 印地语

      * 法语

      * 德语

      * 意大利语

   * 开启**机器人评论**开关，允许机器人根据已配置的发送规则和内容自动发送评论。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6ef4e99074f5420ab7cd29782670b7c3~tplv-goo7wpa0wc-image.image) </span>

      * 最多支持2,000条机器人评论。

      * 该功能仅在直播间处于**直播**状态且未将所有观众静音时可用。

   * 开启**欢迎消息**开关，并按需配置欢迎消息的标题和内容。你可以通过欢迎消息告知观众重要信息，例如直播间的聊天规则。

   * 开启**仅直播时可聊天**开关。此后，观众只能在直播流期间发送评论。更多信息请参见[将所有观众静音](https://docs.byteplus.com/docs/byteplus-livesaas/docs-muting-viewers-zh-CN)。

6. 在**直播控制**页右侧的聊天互动菜单下，你可以执行以下操作。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c6a20bfb192844b988f3057cc4f386cc~tplv-goo7wpa0wc-image.image) </span>

   * 按状态或内容筛选评论。支持模糊搜索。

   * 若在第5步已开启置顶评论功能，可在**热门**标签页查看置顶评论。

   * 发送文本评论和表情。

   * 点击图标可禁止观众发送评论或允许观众发送评论。更多信息请参见[将所有观众静音](https://docs.byteplus.com/docs/byteplus-livesaas/docs-muting-viewers-zh-CN)。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5bb3c66407f24239aaea6da86bf321f0~tplv-goo7wpa0wc-image.image) </span>

   * 点击**聊天设置**图标，并按需执行以下操作。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1d73db8d30684127a6c21e599931d514~tplv-goo7wpa0wc-image.image) </span>

      * 配置主播昵称。

      * 启用或禁用聊天审核功能。

         启用该功能后，评论仅对发送评论的观众可见。将鼠标悬停在评论上，点击**通过**以审核通过该评论。审核通过后，评论将在观看页对所有人可见。

      * 启用或禁用聊天机器人功能。

         使用该功能前，请确保已在第5步配置发送规则和内容。

      * 在控制台和网页直播页启用或禁用观众进场及礼物的系统通知。

      * 在控制台启用或禁用礼物特效。

         仅在已开启礼物奖励功能时，才会显示**礼物特效**开关。有关如何启用该功能，请参见[通过礼物奖励主播](https://docs.byteplus.com/docs/byteplus-livesaas/docs-rewarding-hosts-with-gifts-zh-CN)。

      * 点击**配置**，在**管理系统通知**对话框中启用或禁用抽奖、动态表情、礼物和观众进场的通知。

      * 点击**导出评论**，将评论数据导出到本地存储。

      * 点击**清空评论**，清空观看页的聊天区域。

   * 点击评论右侧的省略号图标后，可执行以下操作。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a869b9eb0047403aa5e080709a3d71ab~tplv-goo7wpa0wc-image.image) </span>

      * 回复评论。

      * 点赞评论。

      * 将评论置顶到聊天区域。

      * 将观众静音或取消静音。选择**静音**后，发送该评论的观众会被静音，评论会从观看页删除。被静音的观众仍可发送评论，但其消息仅对自己可见。要取消观众静音，请点击其评论旁的省略号图标，并选择**取消静音**。

         观众是根据其 UID 被静音的，UID 会因登录方式不同而变化。例如，你将仅通过输入昵称登录直播间的观众静音。该观众随后选择通过手机号登录直播间。这样观众会获得新的 UID，可以再次发送评论。

      * 从观看页删除评论。

      * 封禁或解除封禁观众的 IP 地址。更多信息，请参见[将观众踢出或屏蔽观众的 IP 地址](https://docs.byteplus.com/docs/byteplus-livesaas/docs-kick-out-or-block-zh-CN)。

      * 将观众踢出直播间或允许其重新加入。更多信息，请参见[将观众踢出或屏蔽观众的 IP 地址](https://docs.byteplus.com/docs/byteplus-livesaas/docs-kick-out-or-block-zh-CN)。

      * 若已开启**手动选择置顶评论**开关（见第 5 步），请选择**热门**，并在对话框中设置点赞数，将评论在置顶评论菜单中展示。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/521c66be715f47f99d05e2c4600932a8~tplv-goo7wpa0wc-image.image) </span>

   * 通过以下任意方式查看评论被举报的原因。

      根据举报内容，你可以决定是否删除评论或静音发送该评论的观众。

      * 点击**已举报**标签查看举报原因。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/855e7cb33d0d4179843115ce29d15326~tplv-goo7wpa0wc-image.image) </span>

      * 点击**消息**图标查看评论举报消息。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e0fbb58a2dd54b34a14c269e40f226ff~tplv-goo7wpa0wc-image.image) </span>

         你还可以在**消息列表**页面执行以下操作：

         * 要查看所有评论举报消息，请点击**类型**列旁的筛选图标，并在对话框中选择**评论举报**。

         * 点击直播间链接，查看该评论在对应直播间中的内容。

            要使用此功能，必须在**Producer** \> **Security control**页面开启**评论举报**开关。更多信息，请参见[配置安全控制](https://docs.byteplus.com/docs/byteplus-livesaas/docs-configuring-security-control-zh-CN)。
