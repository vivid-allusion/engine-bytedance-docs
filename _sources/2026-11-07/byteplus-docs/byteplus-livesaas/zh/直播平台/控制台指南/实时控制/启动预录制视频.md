要安排预录制视频上线，可以使用预录制视频推流方式，将视频循环播放为直播流。本指南提供如何添加视频、管理视频列表以及启动流的分步操作说明。

预录制视频不支持[多平台推流](https://docs.byteplus.com/zh-CN/docs/byteplus-livesaas/docs-synchronizing-a-live-stream-from-byteplus-live-to-third-party-platforms)功能。要将 BytePlus Live 的直播流同步到第三方平台，请选择其他推流方式。更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)、[拉流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-pulling-streams-zh-CN)、[推流（以 OBS 为例）](https://docs.byteplus.com/docs/byteplus-livesaas/docs-pushing-streams-zh-CN)、[从 iOS 手机进行直播](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-an-ios-phone-zh-CN)或[使用 Android 手机进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-an-android-phone-zh-CN)。

节目单功能仅支持 PC 和移动设备的横屏模式。

<span id="prerequisite"></span>
## 前提条件

您必须拥有 BytePlus 账号或具备**直播控制** \> **编辑**权限的 IAM 用户。关于如何添加 IAM 用户的更多信息，请参见[用户、组织和角色管理](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

<span id="procedure"></span>
## 操作步骤


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以打开。

3. 在播放器下方的**推流方式**标签页，点击**预录制视频**。

4. 点击**编辑视频列表**。

   如果直播间有多个直播源，请在完成此步骤前，从**切换源**下拉列表中选择对应源。关于如何配置直播源的更多信息，请参见[管理直播源](https://docs.byteplus.com/docs/byteplus-livesaas/docs-setting-multi-source-live-streaming-zh-CN)。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef61ee4752da473baada1a789defbdc6~tplv-goo7wpa0wc-image.image) </span>

5. 在**编辑视频列表**对话框中，可通过以下方式添加视频。最多可添加 50 个视频，且视频总大小不得超过 200 GB。

   * 点击**从视频库选择**，从库中添加视频。

   * 点击**上传视频**，上传 MP4 视频。

6. （可选）配置以下设置后，点击**确认**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ba352b1e66ba40b78ae328d14b6269ee~tplv-goo7wpa0wc-image.image) </span>

   * 拖动以调整视频列表中的视频顺序。

   * 修改视频名称。

   * 点击 ID 旁的**复制**图标，复制视频 ID。

   * 在**开始时间**列点击**编辑**，修改视频的开始时间。预录制视频启动后，视频将从该开始时间播放。

   * 删除指定视频。

   * 若添加了两个或以上视频，可开启**显示节目单**开关，并输入节目单名称。预录制视频启动后，节目单会在 PC 和移动设备横屏模式的观看页上显示给观众。

7. 点击**开始流**，在观看页循环播放视频。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/286da75be2664f6dac2ad991d7fe289e~tplv-goo7wpa0wc-image.image) </span>

   如果直播间有多个直播源，点击**开始流**后会弹出确认消息。点击**确定**以为所有源启动流，或点击**单源**仅为当前源启动。关于如何配置多个直播源的更多信息，请参见[管理直播源](https://docs.byteplus.com/docs/byteplus-livesaas/docs-setting-multi-source-live-streaming-zh-CN)。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a1e07d69e0a947238e026c1deacfdfe5~tplv-goo7wpa0wc-image.image) </span>

   * 支持主流和备流，保障流畅的观看体验。关于如何启用主流和备流的更多信息，请参见[管理直播源](https://docs.byteplus.com/docs/byteplus-livesaas/docs-setting-multi-source-live-streaming-zh-CN)。

   * 您可以为预录制视频配置自动启动。欲了解更多信息，请参见[设置自动启动](https://docs.byteplus.com/docs/byteplus-livesaas/docs-setting-auto-start-zh-CN)。

   * 视频添加后会自动开始预热。为确保更好的直播流质量，建议在预热完成后再启动预录视频。

   * 预热状态会保留一天。一天后，您需在**预热进度**列手动点击**预热**，以预热当前直播源中的所有视频。

8. 点击**结束流**以结束预录视频流。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/71fb1cabf86b431a8971eff5fc3bac8d~tplv-goo7wpa0wc-image.image) </span>

   若直播间中有多个直播源，点击**结束流**后会弹出确认消息。点击**确定**可结束所有源，或点击**单个源**仅结束当前源。关于如何配置多个直播源的更多信息，请参见[管理直播源](https://docs.byteplus.com/docs/byteplus-livesaas/docs-setting-multi-source-live-streaming-zh-CN)。
