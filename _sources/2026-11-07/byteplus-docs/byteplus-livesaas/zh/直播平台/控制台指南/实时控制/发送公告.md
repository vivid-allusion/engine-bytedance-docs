为了向观众分享重要信息，例如内容预告或促销活动，您可以在直播流期间发送公告。本指南提供了从 BytePlus Live 控制台和网页浏览器中的直播页面创建、配置和发送公告的分步操作说明。

<span id="prerequisites"></span>
## 前提条件


* 请确保已添加互动工具菜单。更多信息，请参见[管理互动区域](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-interaction-area-zh-CN)。

* 在控制台发送公告

   请确保您拥有 BytePlus 账号或具有 Live control \> Edit 权限的 IAM 用户。

* 在网页浏览器的直播页面发送公告

   * 建议您使用符合直播流指定要求的设备和浏览器，以确保获得流畅的直播流体验。更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)。

   * 如果您通过控制台进入直播页面，请确保您拥有 BytePlus 账号或具有 Live control \> Edit 权限的 IAM 用户。

   * 如果您通过链接进入直播页面且无需登录，则无需控制台权限即可发送公告。


有关添加 IAM 用户的更多信息，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。

<span id="procedure"></span>
## 操作流程

<span id="step-1-enter-the-announcement-dialog-box"></span>
### Step 1: 进入公告对话框


* 控制台

   1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

   2. 在直播间列表中，点击打开一个直播间。

   3. 在**Live control**页面，点击互动工具菜单下的**公告**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ae2b47823cbe406094814565887f0ca6~tplv-goo7wpa0wc-image.image) </span>

      为了获得更好的观看体验，建议您打开右下角的**显示菜单**开关，在观看页显示菜单。

   4. 在弹出的对话框中点击**创建公告**。

* 网页浏览器中的直播页面

   1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

   2. 选择**Web browser**作为推流方式并进入直播页面。更多信息，请参见[通过网页浏览器进行直播流](https://docs.byteplus.com/docs/byteplus-livesaas/docs-live-streaming-from-your-web-browser-zh-CN)。

   3. 在互动工具标签页中，点击**公告**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ceab1a63e756434195a707df7acb1837~tplv-goo7wpa0wc-image.image) </span>


<span id="step-2-configure-and-send-an-announcement"></span>
### Step 2: 配置并发送公告

在控制台和网页浏览器的直播页面上的操作基本相同。本步骤以控制台为例。


1. 在弹出的**公告**对话框中，输入公告标题和内容，然后点击**保存**。

   如果这不是直播间中的第一条公告，请点击**创建**，然后输入公告标题和内容。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0c9b08119b1f40729ae1aa3ac4244b9f~tplv-goo7wpa0wc-image.image) </span>

2. 点击**添加到发送区**，然后在互动工具菜单下点击**发送**，将公告发送到观看页。

   如果您有多条未发送的公告，请先在左侧选择公告，然后点击**添加到发送区**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4c5c7c3af4084d27967881c37a7f4b48~tplv-goo7wpa0wc-image.image) </span>

   * 或者，您也可以在控制台的互动工具菜单中点击**公告**，在对话框中选择所需公告，然后点击**发送**。

   * 在直播页面中，在**公告**对话框中选择公告并点击**发送**。

3. （可选）您可以复制、预览、编辑或删除未发送的公告，也可以复制或删除已发送的公告。

4. （可选）在互动工具菜单下，你可以撤回或查看已发送的公告。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/00e99e6a9b23424799c08d0482e92d79~tplv-goo7wpa0wc-image.image) </span>
