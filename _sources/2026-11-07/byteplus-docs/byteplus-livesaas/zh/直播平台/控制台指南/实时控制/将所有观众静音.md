为提升观众专注度并防止直播间出现垃圾信息，你可以将所有观众静音。本指南提供了分步说明，帮助你在流期间即时静音观众，或在非直播流时段自动静音观众。

<span id="prerequisites"></span>
## 前提条件


* 聊天互动菜单已开启。如需了解更多信息，请参见[管理聊天区域](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-the-chat-area-zh-CN)。

* 具备 BytePlus 账号或拥有 Live control \> Edit 权限的 IAM 用户。如需了解如何添加 IAM 用户，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles-zh-CN)。


<span id="context"></span>
## 背景

为帮助观众专注于直播内容，你可以将所有观众静音。例如，当教师正在讲授新内容并需要学生专心听讲时，将所有观众静音可以阻止他们在聊天区域发言。这样，他们可以更加专注于课程。

<span id="procedure"></span>
## 操作步骤


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击某个直播间以进入。

3. 在**Live control**页面，你可以通过以下任一方式将所有观众静音：

   * 仅在直播流期间允许聊天

      1. 点击设置图标。

      2. 在**设置**对话框的**聊天互动**部分，开启**仅在直播流期间聊天**开关。此设置允许观众仅在直播流期间发送评论。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eb75529fcbf64810afffbe948464a7c0~tplv-goo7wpa0wc-image.image) </span>

         你也可以在**Producer** \> **Menus**页面开启该开关。如使用 IAM 用户登录控制台，请确保该 IAM 用户具备 Producer \> Edit 权限。

   * 立即将所有观众静音。

      点击该图标以阻止观众发送评论。如需取消静音，再次点击该图标。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/28e36e07362a4a0499b515ba7c00534c~tplv-goo7wpa0wc-image.image) </span>
