要在线编辑视频而无需下载软件，可以使用云剪辑功能。本指南提供了逐步操作说明，介绍如何执行基本编辑任务，例如从直播流回放中拆分和删除不需要的片段、将多个剪辑合并为一个视频，以及导出最终成品以供下载或作为新的回放使用。

<span id="context"></span>
## 背景

通过使用云剪辑，无需下载任何软件即可在云端编辑视频，操作简单且节省时间。此外，云剪辑功能可与回放无缝配合使用。回放生成后，可以根据需求在云剪辑中编辑该回放。

|9 |调整音量 |调整视频的音量。 |

<span id="prerequisite"></span>
## 前提条件

具备 BytePlus 账号或拥有**云剪辑** \> **编辑**权限的 IAM 用户。关于如何添加 IAM 用户的更多信息，请参见[管理用户、组织和角色](https://docs.byteplus.com/docs/byteplus-livesaas/docs-managing-iam-users-and-roles)。

<span id="procedure"></span>
## 操作流程


1. 登录[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 可以通过以下任一方式进入**云剪辑**页面。

   * 在 BytePlus Live 的菜单栏，点击**媒体库**。在左侧导航栏，点击**视频** \> **视频库**或**临时存储**。在目标视频右侧的**操作**列，点击**剪辑**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aecf06a6102c4095a603b240d7a76608~tplv-goo7wpa0wc-image.image) </span>

   * 在 BytePlus Live 的菜单栏，点击**媒体库**。在左侧导航栏，点击**云剪辑**。点击**新建剪辑**，或在已有剪辑项目上点击**进入云剪辑页面**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/55ee18dcf5d84071acb3bafd5c041573~tplv-goo7wpa0wc-image.image) </span>

   * 在直播间列表中，点击打开一个直播间。在左侧导航栏，点击**回放**。在目标视频右侧的**操作**列，点击**剪辑**。

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cc6ea59201ac4edeb07aab884ca124a1~tplv-goo7wpa0wc-image.image) </span>

3. 在素材区选择并拖拽一个视频到工作区的轨道上。

4. 根据需求编辑视频。本主题提供两个示例场景。

   * 裁剪视频的开头和结尾：回放通常包含直播流开始前的测试内容。使用云剪辑删除回放的开头和结尾，以去除测试内容。

      1. 定位到需要在回放开头拆分视频的位置，点击**拆分**图标，将所选视频拆分为两部分。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2c5394b5e47b43cb8478c6d6d641f1f3~tplv-goo7wpa0wc-image.image) </span>

      2. 选择需要删除的部分，点击**删除**图标，或在键盘上按 Delete 或 Backspace。

      3. 定位到需要在回放结尾拆分视频的位置，点击**拆分**图标。

      4. 选择需要删除的部分，点击**删除**图标，或在键盘上按 Delete 或 Backspace，以删除回放结尾。

   * 合并视频：使用云剪辑将多个回放合并为一个视频。还可以将本地视频添加到合并后的回放中作为过渡。

      1. 在素材区选择并拖拽多个视频到工作区的轨道上。视频会自动合并。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9ea3082a784440f18bae71eba1dee45e~tplv-goo7wpa0wc-image.image) </span>

      2. （可选）在轨道上选择并拖拽视频以调整顺序。

5. （可选）你可以将当前编辑进度保存到**媒体库** \> **云剪辑**。点击页面右上角的**保存**，在弹出的对话框中输入项目名称。然后，点击**确认**。之后你可以选择该项目继续编辑。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/26faa9adb8fb4cfb97c94bda7edb31f5~tplv-goo7wpa0wc-image.image) </span>

6. 点击页面右上角的**导出到视频库**，将视频剪辑导出到视频库进行永久保存。在弹出的**导出到视频库**对话框中，输入视频名称，选择转码档位，然后点击**确认**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0338205fbeb241b2a9050760a1322763~tplv-goo7wpa0wc-image.image) </span>

   建议视频时长控制在三小时以内，以避免导出时间过长。

7. （可选）视频剪辑导出到视频库后，你可以下载该视频剪辑或将其发布为直播间的回放。

   * 下载视频剪辑

      1. 在 BytePlus Live 的菜单栏中，点击**媒体库**。

      2. 在左侧导航栏，点击**视频** \> **视频库**。

      3. 在视频剪辑右侧的**操作**栏中，点击**下载**。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/77cf40c2f5234c689a3916fab0c3480a~tplv-goo7wpa0wc-image.image) </span>

   * 发布视频剪辑

      1. 在直播间列表中，点击打开一个直播间。

      2. 在左侧导航栏，点击**回放**。

      3. 在页面右上角点击**从视频库选择**。

      4. 选择视频剪辑并点击**确定**。

      5. 在视频剪辑右侧的**操作**栏中，点击**发布**。

         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5bc3164ff0e34d41b10a48d8fd2df593~tplv-goo7wpa0wc-image.image) </span>
