为了构建自定义功能并响应直播播放器内的用户交互，您可以订阅多种事件。本参考指南提供了所有可用事件的完整列表，包括其触发条件、类型签名和数据负载。事件分为与播放器相关的操作（如播放、暂停和全屏切换）和非播放器相关的交互（如评论、点赞和抽奖参与），帮助您打造完整的互动体验。

以下示例代码展示了如何监听事件。

```JavaScript
 window.addEventListener('message', (event) => {
        try {
          if (event.origin.includes('byteoc.com')) {
              const data = JSON.parse(event.data);
              switch (data.action) {
                case 'player.play': // Replace player.play with a specific event.
                  // 检测到事件后执行你自己的后续操作。
                  console.log('====== ', data.action, ' -- ', data.payload, ' ======' );
                  break
                default:
                  return;
              }
          }
        } catch (e) {
        }
      });
```

### player.vodConfigChange

用于从保存位置（断点）恢复回放的事件。

当播放器正在播放预告或回放时，在以下情况下会触发该事件：


* 观众在 PC 上关闭嵌入页面。

* WebView 的`pagehide`事件被触发，或观众在移动设备上手动拖动进度条。


**类型**

```TypeScript
(VodInfo: { vid: string; currentTime: number; duration: number;}) => void
```


**参数**


|名称 |类型 |接口行为 |
|---|---|---|
|VodInfo |\- |视频（预告或回放）信息。 |
|vid |string |视频 ID，即视频的唯一标识符。 |
|currentTime |number |当前回放时间，单位为秒。 |
|duration |number |视频总时长。单位：秒。 |
