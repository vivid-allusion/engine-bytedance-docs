为了打造独特且具有品牌特色的观播体验，你可以使用 Web 观播 SDK 对直播间进行自定义。本指南提供了实现高级功能的操作说明和代码示例，包括自定义用户认证流程、UI 元素（如图标和输入框）的样式定制，以及个性化 PCU 限制错误页面。

<span id="c5d19ee4"></span>
## 前提条件

你已集成 Web 观播 SDK。更多信息，请参见 [集成 Web 观播 SDK](https://docs.byteplus.com/docs/byteplus-livesaas/docs-integrating-the-viewer-sdk-for-web-zh-CN)。

<span id="065efa57"></span>
## 使用自定义模式进行认证

如果观众可以通过你自有的账号系统（如公司官网）登录，你可以使用自定义模式进行认证，使观众能够使用你账号系统中的身份信息加入直播间。你可以选择观众在何时登录你的账号系统。

<span id="645e07bd"></span>

自定义认证模式支持 PC 和移动端平台。

### **方法一：进入直播间前登录**

采用此方法时，观众需在进入直播间前完成登录，之后即可观看直播流或参与互动。

<span id="45ae575b"></span>
#### 适用场景

该方法适用于需要身份验证、访问控制或数据追踪的场景，如会员专属活动、企业内部培训或付费课程。此方式安全性更高，用户身份更明确，但可能会增加观众的进入门槛。

<span id="c302c753"></span>
#### 代码示例

初始化 SDK 时，将 `mode` 参数设置为 `2`，token 参数设置为 [GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-CN) 返回的授权 token。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">观众登录你的账号系统后，调用<a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-CN">GetSDKTokenAPI</a>并传入观众昵称和ID以获取授权token。本次调用需确保<code>mode</code>参数设置为<code>2</code>。</div>


代码示例如下。

```JavaScript
  var webSDK = new window.ByteLiveWebSDK({
    activityId: 172291833994****,
    token: 'ak3T%2FdaGJDL5zSFD7%2F1GPGP****',
    service: 'liveDemo',
    mode: 2, 
    ...
```

### **方法二：进入直播间后登录**

采用此方法时，观众可先进入直播间观看直播流和浏览评论，无需登录。仅当观众尝试发表评论、点赞内容或参与其他互动时，才会触发自定义登录流程。

<span id="2b8319b1"></span>
#### 适用场景

该方法适用于公开活动、开放课程或以提升流量和用户转化为目标的营销直播。此方式降低了初始进入门槛，提升观播体验，但部分功能对匿名用户仍有限制。

<span id="14ca81e0"></span>
#### 实现流程

实现流程如下：


1. 初始化 SDK 时，将 `mode` 参数值设置为 `1`，关闭 BytePlus Live 内置登录系统，并监听 [permission.need](https://docs.byteplus.com/en/docs/byteplus-livesaas/events#permission-need) 事件。

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">当<code>mode</code>参数值设置为<code>1</code>时，可以通过以下任一方式获取授权token：   </div>
   

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">登录<a href="https://console.byteplus.com/livesaas/liveManagement/">BytePlus Live 控制台</a>，在直播间的<strong>Producer</strong> \> <strong>页面嵌入</strong>页面，切换到<strong>Web SDK 嵌入</strong>标签页获取token。   </div>
   

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">调用<a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-CN">GetSDKTokenAPI</a>获取token。   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">当前，<code>permission.need</code>事件仅适用于此场景。   </div>
   

2. 你需要实现观众登录逻辑，以及获取 `mode: 2` 授权 token 的逻辑。

3. 当观众执行以下需要用户信息的操作时，SDK 会触发 `permission.need` 事件：

   * 点击评论输入框（包括聊天互动和问答菜单下的输入框）

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">问答菜单仅在PC端和横屏模式下的移动设备上支持。      </div>
      

   * 点赞评论

   * 为主播送礼

   * 签到

   * 参与答题

   * 参与投票

   * 参与抽奖

   * 参与非匿名问卷

   * 预约直播流（仅当预约短信提醒功能未开启时会触发 `permission.need` 事件）

   * 点赞直播间（仅当点赞直播间需要登录时才会触发`permission.need`事件，即`loginInToThumbUp`的值设置为`true`时）

4. 检测到`permission.need`事件后，需要触发自定义登录流程。

5. 观众登录到你的账号系统。

6. 在调用[GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-CN)获取授权 token 时，当`mode`的值设置为`2`时，需传递观众的昵称和 ID。

7. 调用 SDK 的[updateMode2Token](https://docs.byteplus.com/en/docs/byteplus-livesaas/api#updatemode2token)方法，将临时`mode: 1` token 替换为新的`mode: 2` token。


示例代码如下。

```JavaScript
  var webSDK = new window.ByteLiveWebSDK({
    activityId: 172291833994****,
    token: 'ps****',
    service: 'liveDemo',
    mode: 1,
    options: {
      saveUserInfo: true, // 可选。当mode值为1时，用于缓存用户信息。
      disabledLogin: true, // 禁用BytePlus Live内置登录系统。
    }
  })
  
    const login = () => {
    // 自行实现登录逻辑。
    return {
      Nickname: 'Viewer A',
      UserIdStr: '57584'
    }
  }

  const getSDKToken = () => {
    //  当mode值为2时，自行实现获取token的逻辑。
    return {
      Token: 'hdsh****'
    }
  }
  // 检测到permission.need事件后执行handleLogin函数。
  const handleLogin = async () => {
      // 触发自定义登录流程，观众需登录你的账号系统。
      const userInfo = await login();
      // 使用登录用户信息调用GetSDKTokenAPI，在mode值为2时获取token。
      const res = getSDKToken(userInfo);
      // 调用SDK的updateMode2Token方法，将mode值为1时的token更新为mode值为2时的token。
      webSDK.updateMode2Token(res.Token);
  }
  // 监听permission.need事件。
  webSDK.on('permission.need', handleLogin);
```

### 示例代码

配置`disabledCommentConfig`参数的示例代码如下。关于参数的更多信息，请参见[Web 观播 SDK：参数](https://docs.byteplus.com/docs/byteplus-livesaas/docs-parameter-the-viewer-sdk-for-web-zh-CN)。

```JavaScript
var webSDK = new window.ByteLiveWebSDK({
  activityId: 180025****643845, 
  token: 'AB**nK', 
  service: 'Demo', 
  mode: 1, 
  modules: [
    {
      id: 'player', // The page element ID.播放器模块将嵌入到该元素中。
      mode: 'player',
    },
    {
      id: 'menu', // The page element ID.菜单模块将嵌入到该元素中。
      mode: 'menu',
    },
  ],
  options: {
    disabledCommentConfig: {
      disabled: true, // Disables the comment text box.观众点击评论输入框时无法输入内容。
      placeholder: "Muted" // The placeholder text for the disabled comment text box.要配置多语言占位文本，需先通过 BytePlus Live 控制台或服务端 OpenAPI 开启观看页语言。然后，按照“简体中文|英文|日文|繁体中文|韩文|泰文|越南文|阿拉伯文|土耳其文|西班牙文|印尼文|葡萄牙文|俄文”的顺序，用“|”分隔每种语言的占位文本。例如，若已开启的语言为简体中文和英文，则参数的值为“禁言中|Muted”。
    }
  },
});

webSDK.on('error', console.log);
```

## 自定义错误页

如你已订购直播并发观众套餐，当所有正在直播的直播间总的峰值并发用户数（PCU）超过套餐并发上限时，新观众会看到错误页。

例如，你已订购支持 300 名观众的直播并发观众套餐。现在，你账号下有 3 个处于**Live**状态的直播间，PCU 分别为 100、150 和 200。此时总 PCU 为 450（100+150+200），已超过套餐的 300 并发上限。当总 PCU 超过 300 时，观众尝试进入观看页会显示错误页。

<span id="df37fe88"></span>

该自定义功能支持 PC 端和移动端平台。

此外，你可以监听`activity.pcu`事件并执行自定义逻辑，例如将观众重定向到你的自定义页面，而不是在PCU超过并发上限时显示默认错误页。

<span id="dad45aa8"></span>
### 示例代码

示例代码如下。

```JavaScript
options: {
    pcuConfig:{
      text:'The event is so popular', // Your custom text.
      img:'https://example.com/image.image', // Your custom image.
    },
}
// Listen to the event that is triggered when a viewer enters the viewing page.将 console.log 替换为你的自定义逻辑。当 PCU 超过并发上限时，将执行你的自定义逻辑。
webSDK.on('activity.pcu', console.log); 
```


有关该参数和事件的更多信息，请参见[Web 观播 SDK：参数](https://docs.byteplus.com/docs/byteplus-livesaas/docs-parameter-the-viewer-sdk-for-web-zh-CN)和[activity.pcu](https://docs.byteplus.com/docs/byteplus-livesaas/docs-bdlliveengine-zh-CN#75c92017)。
