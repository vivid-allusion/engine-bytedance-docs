类型：`枚举`


|值 |属性 |接口行为 |解决方案 |
|---|---|---|---|
|101 |INIT_FAIL |* 错误信息：初始化失败，缺少必要参数。<br><br>* 回调参数：提供的初始化配置。 |请确保`activityId`、`token`、`service`、`mode`和`modules`参数已设置值。 |
|102 |TOKEN_FAIL |* 错误信息：token校验失败。<br><br>* 回调参数：API错误信息。 |请确保`token`的值有效。 |
|103 |DIV_NOT_FOUND |* 错误信息：未找到对应渲染的父节点。<br><br>* 回调参数：父节点ID。 |请确保`modules`下的每个`id`都对应一个DOM节点。 |
|104 |RENDER_ERROR |* 错误信息：模块渲染失败。<br><br>* 回调参数：模块名称、错误堆栈和错误信息。 |无。 |
|105 |COMP_NOT_FOUND |* 错误信息：未找到对应组件。<br><br>* 回调参数：父节点ID。 |请确保`modules.mode`参数的值有效。 |
|106 |MOBILE_ALL_ERROR |* 错误信息：`mobile`或`mobile-portrait`模块不能与其他模块同时使用。<br><br>* 回调参数：无。 |请确保`mobile`和`mobile-portrait`模块未与其他模块同时使用。 |
|201 |LIVE_INFO_FAILED |* 错误信息：获取直播间信息失败。<br><br>* 回调参数：请求数据。 |无。 |
|204 |LIVE_DUPLICATE_LOGIN |* 错误信息：检测到重复登录。<br><br>* 回调参数：无。 |无。 |
|206 |IP_BANNED |* 错误信息：当前观众的IP已被封禁。<br><br>* 回调参数：无。 |无。 |
|207 |KICK_OUT |* 错误信息：当前观众已被踢出。<br><br>* 回调参数：无。 |无。 |
