DynamicCustomSettings 类提供用于动态配置直播间用户界面的方法。你可以使用此类自定义关键交互元素的外观和行为，例如关注按钮和评论输入框。这包括设置文本、颜色、背景，以及为如关注主播或编辑评论等用户操作注册监听器。

```Java
public class DynamicCustomSettings
```
