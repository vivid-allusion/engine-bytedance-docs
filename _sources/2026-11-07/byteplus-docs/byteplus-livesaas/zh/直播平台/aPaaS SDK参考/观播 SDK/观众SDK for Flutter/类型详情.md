## BdlActivityConfig

```Dart
class BdlActivityConfig {
    final int activityId;
    final String token;
    final BdlViewerAuthMode authMode;
    final bool isPortrait;
}
```


加入直播间所需的信息。

**输入参数**


|名称 |类型 |接口行为 |
|---|---|---|
|activityId |Integer |直播间的活动 ID。可通过调用[ListActivityAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-listactivityapi-zh-CN)获取 ID。 |
|token |String |加入直播间所需的授权 token。可通过调用[GetSDKTokenAPI](https://docs.byteplus.com/docs/byteplus-livesaas/docs-getsdktokenapi-zh-CN)获取 token。 |
|authMode |BdlViewerAuthMode |直播间的认证模式。更多信息请参见[BdlViewerAuthMode](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#415010a6)。 |
|isPortrait |Boolean |直播间是否为竖屏模式。<br><br><br>* `true`：竖屏模式。<br><br>* `false`：横屏模式。 |

## BdlViewerOpenUrlType

```Dart
enum BdlViewerOpenUrlType {
    pageHeaderAd,
    pageAd,
    floatingAd,
    cardAd,
}
```


内嵌链接所属内容的类型。

**枚举值**


|类型 |取值 |接口行为 |
|---|---|---|
|pageHeaderAd |0 |页头广告。 |
|pageAd |1 |页中广告。 |
|floatingAd |2 |浮标广告。 |
|cardAd |3 |商品卡片，包括菜单下方展示的商品卡片和商品浮窗。 |


<span id="415010a6"></span>
## BdlViewerAuthMode

```Dart
enum BdlViewerAuthMode {
    public,
    custom,
}
```


直播间的认证模式。

**枚举值**


|类型 |取值 |接口行为 |
|---|---|---|
|public |0 |公开模式。观众以嘉宾身份加入直播间。在执行如评论、点赞等需要用户信息的操作前，必须输入昵称进行注册。 |
|custom |1 |自定义模式。观众通过应用中的用户信息加入直播间，可直接进行评论和点赞。 |

<span id="b4ff383c"></span>
## BdLivePlayerConfig

```Dart
class BdLivePlayerConfig {
  bool liveAutoPlay = true;
  bool replayAutoPlay = true;
  bool previewAutoPlay = true;
  bool enablePIP = true;
  bool enablePIPWhenExit = true;
}
```


播放器配置。

**输入参数**


|名称 |类型 |接口行为 |
|---|---|---|
|liveAutoPlay |Boolean |当直播间处于**直播**状态时，是否自动播放直播视频。默认值：`true`。可选值：<br><br><br>* `true`：自动播放。<br><br>* `false`：不自动播放。 |
|replayAutoPlay |Boolean |当直播间处于**回放**状态时，是否自动播放回放。默认值：`true`。可选值：<br><br><br>* `true`：自动播放。<br><br>* `false`：不自动播放。 |
|previewAutoPlay |Boolean |当直播间处于**预告**状态且有预告内容时，是否自动播放预告。默认值：`true`。可选值：<br><br><br>* `true`：自动播放。<br><br>* `false`：不自动播放。 |
|enablePIP |Boolean |当观众离开直播间、点击 URL（包括商品卡片和广告中的 URL）打开新页面，或将应用切换到后台时，是否启用画中画（PiP）功能。默认值：`true`。可选值：<br><br><br>* `true`：启用。<br><br>* `false`：禁用。 |
|enablePIPWhenExit |Boolean |仅当观众离开直播间时，是否启用画中画（PiP）功能。默认值：`true`。可选值：<br><br><br>* `true`：启用。<br><br>* `false`：禁用。 |
