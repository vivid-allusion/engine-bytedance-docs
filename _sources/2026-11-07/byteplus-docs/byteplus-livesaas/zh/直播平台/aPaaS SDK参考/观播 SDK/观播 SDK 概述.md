观众 SDK 为你的移动应用提供观看直播流、发表评论、与主播互动等功能。通过集成观众 SDK，你可以在移动应用中快速嵌入功能丰富的直播间。

<span id="Features"></span>
## 功能

更多信息，请参见[SaaS 与 aPaaS 功能对比](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-comparison-between-saas-and-apaas)。

<span id="Scenarios"></span>
## **应用场景**

<span id="E-commerce"></span>
### 电商

通过提供轻量级解决方案，帮助中小型电商企业快速开展直播流业务，使企业能够便捷地测试线上销售的效果。

<span id="Marketing"></span>
### 营销

帮助企业推广品牌并开展互动营销活动。支持丰富的互动营销组件，如浮动广告和页面内横幅。支持页面全自定义，以契合品牌形象。

<span id="Finance"></span>
### 金融

为金融产品提供强大的定制化解决方案。支持以卡片形式展示产品，观众可在观看直播流时购物，并在直播流过程中发起语音聊天。
