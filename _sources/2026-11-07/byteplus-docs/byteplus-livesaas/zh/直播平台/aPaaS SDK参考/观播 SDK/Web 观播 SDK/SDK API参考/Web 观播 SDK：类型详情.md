## GiftInfo

类型：`interface`

关于收到的礼物及其发送用户的信息。

<span id="07b22632"></span>
### GiftCount

类型：`number`

礼物数量。

<span id="ffbb1454"></span>
### GiftId

类型：`number`

该类型礼物的唯一 ID。

<span id="44599d90"></span>
### GiftName

类型：`string`

礼物名称。

<span id="33ef5903"></span>
### GiftImage

类型：`string`

礼物图片的 URL。

<span id="4fbdafa4"></span>
### GiftPrice

类型：`string`

礼物的单价。

<span id="68fabcb4"></span>
### Index

类型：`number`

页面上礼物的显示索引。

<span id="2865d672"></span>
### Nickname

类型：`string`

发送礼物用户的昵称。

<span id="24e8fc86"></span>
### UserId

类型：`number`

发送礼物用户的用户 ID。

<span id="e7422330"></span>
### Email

类型：`string`

发送礼物用户的邮箱。

<span id="fe534689"></span>
## ProductInfo

类型：`interface`

关于商品的信息。

<span id="94866faf"></span>
### Id

类型：`number`

商品卡片的唯一 ID。

<span id="1d48152e"></span>
### Title

类型：`string`

商品名称。

<span id="22be6126"></span>
### Highlight

类型：`string`

商品的销售价格。

<span id="aeeebc42"></span>
### Strikethrough

类型：`string`

商品的参考价格。

<span id="f32080e7"></span>
### IntroduceImage

类型：`string`

商品图片的绝对 URL。

<span id="99783364"></span>
### RedirectImage

类型：`string`

商品跳转图片的绝对 URL。

<span id="892c194d"></span>
### ExternalProductId

类型：`string`

外部商品 ID。该 ID 可确保商品添加到商品卡片菜单后，无法再次添加到同一菜单。
