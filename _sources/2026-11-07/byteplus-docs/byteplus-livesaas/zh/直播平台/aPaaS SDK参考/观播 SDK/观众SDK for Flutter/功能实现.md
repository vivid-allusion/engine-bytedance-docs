要将完整直播间集成到你的 Flutter 应用中，可以使用 Viewer SDK。本指南提供了核心操作的详细说明和代码示例，包括加入和离开房间，以及设置状态回调。本指南涵盖两种主要实现方式：使用默认原生页面实现快速搭建，或使用 Flutter 组件实现更个性化的用户界面。


* 如需使用原生页面，请参考 [创建默认完整直播间](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#a3d73eee)。

* 如需展示自定义 Flutter 组件（如购物车图标），请参考 [创建用于展示 Flutter 组件的直播间](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#2cfaa0a8)。

### 设置直播间状态回调

设置直播间状态回调，以监听完整直播间页面上的事件。

```Dart
Future<void> setLiveRoomStatusListener(BdlLiveRoomStatusListener listener);
```


本实现的回调如下。

```Dart
class BdlLiveRoomStatusListener {
  /**
   *回调将在the直播间切换时触发to the foreground.
   * @paramactivity：用于required加入房间的信息live room.
   */
  void Function(BdlActivityConfig activity)? onLiveRoomActivityResume;

  /**
   *回调将在the直播间切换时触发to the background.
   * @paramactivity：用于required加入房间的信息live room.
   */
  void Function(BdlActivityConfig activity)? onLiveRoomActivityPause;

  /**
   *回调将在the悬浮播放器about to appear.
   * @paramactivity：用于required加入房间的信息live room.
   */
  void Function(BdlActivityConfig activity)? onFloatViewWillAppear;

  /**
   *回调将在the悬浮播放器about to disappear.
   * @paramactivity：用于required加入房间的信息live room.
   */
  void Function(BdlActivityConfig activity)? onFloatViewWillClose;
  
    /**
   * 回调将在both直播间page和悬浮播放器are destroyed.
   * @param activity：用于required加入房间的信息live room.
   */
  void Function(BdlActivityConfig activity)? onLiveRoomFullDestroyed;

    /**
     *当观众tap商品卡片展示时触发under the menu, floating product cards, header ads, in-page ads, or浮标广告contain linked content.
     * @param url             The URL与product card or ad.
     * @param type内容类型of the linked URL. See BdlViewerOpenUrlType.
     * @param enableFloating  A由the BytePlus直播服务器返回的设置indicates判断内容should be displayed as悬浮层上the viewing page.
     *                        true  — Display as a floating layer.
     *                        false —在new page.
     */
  void Function(String url, BdlViewerOpenUrlType type, bool enableFloating)? onOpenUrlCallback;
}
```


更多信息，请参见 [BdlActivityConfig](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#5ed875e7)、[BdlViewerOpenUrlType](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#0c2adc1a) 和 [加载商品卡片和广告中的内嵌链接](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#0257277a)。

```Dart
  /**
   * Implement the BdlLiveRoomStatusListener. For details,参考following section.
   */
class BdlLiveRoomStatusListenerExampleImpl implements BdlLiveRoomStatusListener {

  /**
   *当logical进入live房间完成时触发
   * or当用户taps the PiP.
   *
   *实现此回调to display the LivePullView.
   */
  void Function(BdlActivityConfig activity)? showLivePullView;

  /**
   *当close直播间内按钮live room is clicked.
   *
   *实现此回调to hide the LivePullView.
   */
  void Function(BdlActivityConfig activity)? hideLivePullView;

  /**
   * Triggered when an ad or直播间内商品卡片the直播间clicked.
   *
   *实现此回调to执行自定义跳转logic.
   */
  void Function(String url, BdlViewerOpenUrlType type, bool enableFloating)?
      onOpenUrlCallback;
}


// Create BdlActivityConfig
BdlActivityConfig activity = BdlActivityConfig(
  activityId: activityId,
  token: token,
  authMode: _authMode,
  isPortrait: _isPortrait,
);

// Create the BdlLiveRoomStatusListener
BdlLiveRoomStatusListenerExampleImpl bdlistener = BdlLiveRoomStatusListenerExampleImpl();

// Set the Listener
BdliveViewerApi.instance.setLiveRoomStatusListener(bdlistener);

// Logically enter the live room
BdliveViewerApi.instance.enterLiveRoomLogically(activity);

// If logical entry is successful
if (isPreLoadSuccess) {
  // showLivePullView of BdlLiveRoomStatusListener will be triggered.
  // Navigate to the live room page in showLivePullView.
} else {
  // Notify user of entry failure
  Fluttertoast.showToast(
    msg: "Join room failed",
  );
}
```

#### 展示直播间页面

当enterLiveRoomLogically成功或用户点击画中画图片时，SDK会触发showLivePullView回调。当该回调被触发时，必须展示直播间页面。

同时，为防止多次启动直播间页面，需先通过`isLiveRoomRouteInStack`检查当前直播间页面是否已存在于导航回退栈中。关于`isLiveRoomRouteInStack`的详细信息，请参见[isLiveRoomRouteInStack()](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#0e6a994e)。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c3e4b68149134a07b02d9f3bde0b33a0~tplv-goo7wpa0wc-image.image) </span>

展示直播间页面的示例代码如下：

```Dart
// Check whether the live room page exists in the back stack
if (isLiveRoomRouteInStack()) {
    // If the live room page is in the back stack, directly popUntil the live room page
    navigatorKey.currentState!.popUntil((route) {
        return route.settings.name == 'LiveRoomPage';
    });
    return;
}


// If the live room page is not in the back stack, create the live room page
// Initialize the full live room page
_livePullRoute = MaterialPageRoute(
    builder: (context) {
        // Initialize the BuildContext of the full live room page
        _liveRouteContext = context;
        return const LiveRoomPage();
    },
    settings: const RouteSettings(name: 'LiveRoomPage'),
);


// Push the live room page onto the navigation stack
navigatorKey.currentState!.push(_livePullRoute!);
```

#### 隐藏直播间页面

当用户离开当前直播间页面时，SDK会触发`hideLivePullView`回调。当该回调被触发时，必须隐藏直播间页面。请参考以下工作流和示例代码来隐藏直播间页面。详细信息请参见[isLiveRoomRouteInStack()](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#0e6a994e)和[isLiveRoomRouteAtTop()](https://docs.byteplus.com/docs/byteplus-livesaas/docs-feature-the-viewer-sdk-for-flutter-zh-CN#b1402c5d)。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/decdcb7d60a642eca90c2a5a43acf4eb~tplv-goo7wpa0wc-image.image) </span>

```Dart
// Check if the current live room page exists
if (_livePullRoute != null) {
  try {
    // If the current live room is at the top (currently displayed page)
    if (isLiveRoomRouteAtTop()) {
      // Pop directly to exit the live room page
      navigatorKey.currentState!.pop();

    // If the live room page exists in the navigation stack
    } else if (isLiveRoomRouteInStack()) {
      // Remove the live room page from the stack
      navigatorKey.currentState!.removeRoute(_livePullRoute!);
    }

    // Reset the BuildContext of the current live room page
    _liveRouteContext = null;

    // Reset the current live room page route
    _livePullRoute = null;

  } catch (e) {
    debugPrint('Failed to remove LiveRoom route: $e');

    // Ensure references are reset even on error
    _liveRouteContext = null;
    _livePullRoute = null;
  }
}
```


以下示例展示如何在`hideLivePullView`回调中从`Navigator`移除`BdlLivePullView`。

```Dart
hideLivePullView: (activity) {

},
```

#### `isLiveRoomRouteInStack()`

该函数用于检查LiveRoom路由是否在导航栈中。

```Dart
  // Check if the LiveRoom route is in the navigation stack
  bool isLiveRoomRouteInStack() {
    try {
      // Use ModalRoute.of to get the route associated with the context
      final modalRoute = ModalRoute.of(_liveRouteContext!);
      // If modalRoute is not null and isActive is true, the route is in the stack
      return modalRoute != null && modalRoute.isActive;
    } catch (e) {
      // Catch possible exceptions, such as context being invalid
      debugPrint('Error checking if LiveRoom route is in stack: $e');
      return false;
    }
  }
```

## 自定义配置

<span id="2519a643"></span>
### 自动播放

默认情况下，当观众加入完整直播间，且直播间处于**Live**、**预告**或**回放**状态时，播放器会自动播放视频。

使用以下示例代码可关闭自动播放功能。

```Dart
BdLiveViewerConfig config = BdliveViewerApi.instance.getLiveRoomConfig();
// 若直播间处于 Live 状态时，不自动播放直播视频.
config.playerConfig.liveAutoPlay = false;
// 若直播间处于 Preview 状态且有预告时，不自动播放预告。如果直播间处于 Preview 状态且有预告，则不自动播放预告。
config.playerConfig.previewAutoPlay = false;
// 若直播间处于 Playback 状态时，不自动播放回放。
config.playerConfig.replayAutoPlay = false;
BdliveViewerApi.instance.setLiveRoomConfig(config);
```


更多信息，请参见[BdLiveViewerConfig](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#4b59aa3f)。

### 画中画

默认情况下，当观众离开直播间、通过点击URL（包括商品卡片和广告中的URL）打开新页面，或将应用移至后台时，视频会以画中画模式显示。

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">观众必须在 Android 设备上启用悬浮窗权限才能使用 PiP 功能。</div>


使用以下示例代码可配置画中画功能。你可以仅在观众离开房间时禁用该功能，或在所有场景（离开房间、打开新页面、应用移至后台）下禁用。

```Dart
BdLiveViewerConfig config = BdliveViewerApi.instance.getLiveRoomConfig();
// 当观众离开直播间、通过点击URL（包括商品卡片和广告中嵌入的 URL）打开新页面，或将应用切换到后台时，禁用 PiP 功能。
config.playerConfig.enablePIP = false;
// 仅在观众离开直播间时禁用 PiP 功能。
config.playerConfig.enablePIPWhenExit = false;
BdliveViewerApi.instance.setLiveRoomConfig(config);
```


更多信息，请参见[BdLiveViewerConfig](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#4b59aa3f)。

### 加载商品卡片和广告中的内嵌链接

当观众点击菜单下展示的商品卡片、商品浮窗、页头广告、页中广告或带有内嵌链接的浮标广告时，SDK会触发`onOpenUrlCallback`。如需加载这些链接，请参考以下步骤和代码。


1. 使用`onOpenUrlCallback`监听观众点击操作。

2. 可实现自定义跳转逻辑，或调用SDK的`openUrl` API以执行默认跳转行为。更多信息，请参见[BdlViewerOpenUrlType](https://docs.byteplus.com/docs/byteplus-livesaas/docs-type-the-viewer-sdk-for-flutter-zh-CN#0c2adc1a)。


```Dart
// Use the onOpenUrlCallback to listen to viewer taps
onOpenUrlCallback = (url, type, enableFloating) {
  // Implement custom redirection logic
  if (usingCustomPage) {
    // Navigate to the custom product detail page
    navigator.push(
      ProductDetailPage(
        url: url,
        type: type,
        enableFloating: enableFloating,
      ),
    );
  } else {
    // Use the SDK built-in API to open the URL
    BdliveViewerApi.instance.openUrl(url, type, enableFloating);
  }
};
```


`onOpenUrlCallback`的接口行为如下：

`openUrl`的接口行为如下：

```Dart
/**
 *打开内容associated与嵌入的link配置为product card or ad.
 *
 * @param url             The embedded URL配置为product card or ad.
 * @param type内容类型of the embedded URL. See BdlViewerOpenUrlType.
 * @param enableFloating内容是否should be displayed as悬浮层on the viewing page.
 *                        true  —展示内容as a floating layer, i.e., open a WebView窗口内full-featured直播间页面to展示关联content.
 *                        false —打开内容in新页面using the app’s DeepLink跳转机制to the appropriate page.
 */
Future<void> openUrl(String url, BdlViewerOpenUrlType type, bool enableFloating);
```
