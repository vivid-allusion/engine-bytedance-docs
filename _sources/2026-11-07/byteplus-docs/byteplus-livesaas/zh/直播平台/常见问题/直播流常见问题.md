<span id="live-streaming-from-your-web-browser"></span>
## 通过网页浏览器进行直播流

<span id="why-am-i-unable-to-share-my-screen-on-mac"></span>
### 为什么我无法在 Mac 上共享屏幕？

对于 macOS 10.15 或更高版本，请按照以下步骤手动允许 Google Chrome 录制您的屏幕。


1. 点击 Apple 图标 \> **系统偏好设置**，然后点击 **安全性与隐私**。

2. 在左侧点击 **屏幕录制**。

3. 在右侧勾选 **Google Chrome** 复选框。


<span id="why-are-my-cpu-and-memory-usage-so-high"></span>
### 为什么我的 CPU 和内存占用率很高？


* 请确保您的计算机为 Windows PC，且至少拥有 8 GB 内存、Core i5 处理器、独立显卡和 4 GB 显存。否则，由于基于网页的直播流资源消耗较大，您的 CPU 和内存占用率可能会很高。

* 检查您的 Google Chrome 是否已开启 **可用时使用硬件加速** 开关，该选项允许浏览器使用 GPU 资源。禁用此选项可能导致 CPU 占用率过高。


<span id="my-audio-sometimes-cuts-out-for-viewers-why-does-this-happen"></span>
### 我的音频有时会对观众出现断断续续的情况。为什么会发生这种情况？

当您在直播流过程中切换音频输入设备（例如从蓝牙耳机切换到电脑麦克风）时，会出现此问题。为解决该问题，在切换设备后请刷新直播流页面。

<span id="how-to-use-the-obs-virtual-camera"></span>
### 如何使用 OBS 虚拟摄像头？

[Open Broadcaster Software (OBS)](https://obsproject.com/) 是一款适用于 Windows、macOS 和 Linux 的免费视频录制与直播流开源软件。欲了解更多信息，请参见 [OBS 用户指南](https://obsproject.com/help)。

通过网页浏览器进行直播流时，您可以选择 [OBS 虚拟摄像头](https://obsproject.com/kb/virtual-camera-guide) 作为您的摄像头。请按照以下步骤操作。

<span id="step-1-download-and-install-obs"></span>
#### Step 1: 下载并安装 OBS

点击 [此处](https://obsproject.com/download) 下载并安装 OBS。


* 请确保版本为 26.0 或更高。

* 请确保您的计算机满足 OBS 的相应系统要求。欲了解更多信息，请参见 [系统要求](https://obsproject.com/kb/system-requirements)。


<span id="step-2-configure-the-server-url-and-stream-key"></span>
#### Step 2: 配置服务器 URL 和流密钥


1. 登录 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 在直播间列表中，点击打开一个直播间。

3. 在 **直播控制** 页面，播放器下方的 **推流方式** 标签页中点击 **推流**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/066ac95fff29473b806bf6e1bcca0d84~tplv-goo7wpa0wc-image.image) </span>

4. 复制服务器 URL 和流密钥。

   请妥善保管您的服务器 URL 和流密钥。任何拥有服务器 URL 和流密钥的人都可以向您的直播间推送直播内容。

5. 打开 OBS，点击左上角的 **文件** \> **设置**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/826f32e64d6340a28d0489136545d635~tplv-goo7wpa0wc-image.image) </span>

6. 在 **设置** 对话框中，点击左侧导航栏的 **流**，并在 **服务** 下拉列表中选择 **自定义...** 。

7. 将第 4 步中复制的服务器 URL 和流密钥分别粘贴到 **服务器** 和 **流密钥** 字段中。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6883c5c7b1024a238d7d1cc39d42ecb4~tplv-goo7wpa0wc-image.image) </span>

8. 点击 **确定**。


<span id="step-3-add-sources"></span>
#### Step 3: 添加信号源

添加您希望观众在直播流过程中观看的信号源。本例中，添加一个显示捕获信号源以直播您的屏幕。


1. 在 OBS 底部的 **信号源** 区域点击 +。

2. 在下拉列表中选择 **显示捕获**。

3. 在弹出的 **创建/选择信号源** 对话框中输入名称并点击 **确定**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21275bbaf230430dbdefdb1cd09e9360~tplv-goo7wpa0wc-image.image) </span>

4. （可选）在弹出的对话框中，根据需要调整设置，例如是否捕捉你的光标。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f01284a7d1364c828f08b7ebed9024ac~tplv-goo7wpa0wc-image.image) </span>

5. 点击**OK**。


<span id="step-4-stream-from-obs-to-the-live-room-using-the-virtual-camera"></span>
#### 步骤4：使用虚拟摄像头将 OBS 的流推送到直播间


1. 在 OBS 右下角点击**Start Virtual Camera**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5d94897c1b974961a88089e0018c614c~tplv-goo7wpa0wc-image.image) </span>

2. 在网页浏览器中进入你的直播间的直播页面。

3. 在弹出的**Test your device**对话框中，从**Select camera**下拉列表中选择**OBS Virtual Camera**。此时，直播间将显示来自你 OBS 源的视频。但该方法不会将源的音频流推送到直播间。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/92e9f3d41f6a44819397396b7dafaac1~tplv-goo7wpa0wc-image.image) </span>

   如果进入直播页面时未选择 OBS Virtual Camera，也可以点击**Media settings**图标，将摄像头切换为 OBS Virtual Camera。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c12b507f55cd4326af5a4cb491bc9268~tplv-goo7wpa0wc-image.image) </span>
