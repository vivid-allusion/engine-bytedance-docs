可以通过以下方式检查你的 Windows 或 macOS 电脑的处理器型号：


* Windows

   1. 右键点击**This PC**，并选择**Properties**。

   2. 在打开的页面中找到你的处理器型号。

* macOS

   1. 点击苹果标志，并选择**About This Mac**。

   2. 在**Overview**标签页中找到你的处理器型号。
