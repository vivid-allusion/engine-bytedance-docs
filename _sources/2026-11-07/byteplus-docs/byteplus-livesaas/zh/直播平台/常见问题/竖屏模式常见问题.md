## 为什么竖屏模式下直播间评论区的背景色、文字颜色和主播评论颜色与我在 BytePlus Live 控制台配置的颜色不同？

默认情况下，竖屏模式下直播间评论区的观众评论为黑色背景白色文字，主播评论为黑色背景黄色文字。此默认配置旨在适应大多数场景，因为竖屏模式下直播间的背景为直播视频、预告或回放。

如需自定义竖屏模式下直播间评论区的颜色配置，请在直播间的**制作端** \> **外观**页面，打开**颜色配置同步**开关。

## 为什么当视频宽度小于高度时，竖屏模式下直播间的预告或回放没有填满整个播放器？

如果视频宽度小于高度，视频会按如下方式填满整个播放器。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b646536ffc4d4668a4b1fdec7c6b8373~tplv-goo7wpa0wc-image.image) </span>

但如果在 iOS 观播 SDK 集成过程中 TTSDK 初始化出现错误，例如 VOD 许可证设置失败，视频将无法如图所示填满整个播放器。

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/551d61dc8b184ada99d0edff4faba32b~tplv-goo7wpa0wc-image.image) </span>

<span id="solution"></span>
### 解决方案

在 Xcode 的应用目标中，打开`AppDelegate.m`文件初始化 TTSDK。

```objectivec
#import <TTSDKFramework/TTSDKManager.h>
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    [self initTTSDK];
    return YES;
}

- (void)initTTSDK {
    TTSDKConfiguration *configuration = [TTSDKConfiguration defaultConfigurationWithAppID:@"APP_ID"]; // Replace APP_ID with the app ID returned after the successful license application.请联系销售代表获取应用 ID。
    configuration.appName = @"APP_NAME"; // Replace APP_NAME with the app name used to apply for the license.请联系销售代表获取应用名称。
    configuration.channel = @"CHANNEL_NAME"; // Replace CHANNEL_NAME with the app's download channel, such as "App Store".
    configuration.bundleID = @"BUNDLE_ID"; // Replace BUNDLE_ID with the bundle identifier of the app.
    
    // Set the VOD license and live streaming license.
    // VOD license.
    configuration.licenseFilePath = [[NSBundle mainBundle] pathForResource:@"VOD_LICENSE_NAME" ofType:@"lic"]; // Replace VOD_LICENSE_NAME with the name of the VOD license file.
    [TTSDKManager startWithConfiguration:configuration];
    
    // Live streaming license.
    configuration.licenseFilePath = [[NSBundle mainBundle] pathForResource:@"LIVE_LICENSE_NAME" ofType:@"lic"]; // Replace LIVE_LICENSE_NAME with the name of the live streaming license file.
    [TTSDKManager startWithConfiguration:configuration];
}
```
