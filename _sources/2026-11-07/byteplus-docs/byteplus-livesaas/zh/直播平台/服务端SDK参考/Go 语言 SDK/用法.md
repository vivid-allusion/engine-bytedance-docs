要以编程方式管理您的 BytePlus LiveSaaS 活动，您可以使用 Go 语言的 SDK。本指南提供了关键操作的示例代码，包括创建、更新和列出直播活动，以及获取临时登录和 SDK 令牌。这些示例旨在帮助您快速将 LiveSaaS 功能集成到您的 Go 应用程序中。

<span id="f44e5318"></span>
## 前提条件


* 一个 BytePlus 账户或 IAM 用户。如需了解更多信息，请参见[注册 BytePlus 账户](https://docs.byteplus.com/en/byteplus-platform/docs/signing-up-your-account)或[管理 IAM 用户和角色](https://docs.byteplus.com/byteplus-livesaas/docs/managing-iam-users-and-roles)。

* 您已获取用于身份验证的 AccessKey ID（AK）和 Secret Access Key（SK）。

   * 要获取 BytePlus 账户的 AK 和 SK，请前往[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/) \> 用户信息 \> **IAM** \> **密钥管理**。

   * 要获取 IAM 用户的 AK 和 SK，请完成以下步骤：

      1. 前往[BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/) \> 用户信息 \> **IAM** \> **身份管理** \> **用户**。

      2. 找到该用户，然后点击**查看详情**。

      3. 在**访问密钥**标签页，点击**创建新访问密钥**。


<span id="4111dac6"></span>
## 使用 SDK

打开`BYTEPLUS-SDK-GOLANG`文件夹，并将您的 AK 和 SK 添加到`example\demo_livesaas\demo_livesaas_test.go`文件中。

```Go
package demo_livesaas

import (
        "encoding/json"
        livesaas "github.com/byteplus-sdk/byteplus-sdk-golang/service/livesaas"
        "net/url"
        "strconv"
        "testing"
        "time"
)

const (
        testAk = "your AK"
        testSk = "your SK"
)
```
