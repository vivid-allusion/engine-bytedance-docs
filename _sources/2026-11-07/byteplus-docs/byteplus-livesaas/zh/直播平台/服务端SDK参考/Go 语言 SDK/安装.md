要在 Go 应用中开始使用 BytePlus 服务，您必须先安装官方 SDK。本指南将介绍添加 BytePlus SDK for Go 到开发环境所需的前提条件以及使用的 `go get` 命令。本主题介绍如何安装 Go 的 SDK。

<span id="6eacdad8"></span>
## 前提条件


* 请根据您的系统类型下载并安装 [Go](https://go.dev/)。建议使用 1.13.1 或更高版本。

* 请确保您的环境满足运行 Go 命令的要求。


<span id="4a8e2853"></span>
## 安装 SDK

运行 `go get` 命令以安装 SDK。

```Plain
go get -u github.com/byteplus-sdk/byteplus-sdk-golang
```
