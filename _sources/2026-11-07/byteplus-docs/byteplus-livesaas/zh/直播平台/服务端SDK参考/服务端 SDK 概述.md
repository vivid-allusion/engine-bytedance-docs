BytePlus Live 服务端 SDK 是一个库，旨在简化服务器与 BytePlus Live API 的交互。它封装了常用的 API 调用、鉴权以及如生成临时安全凭证等流程，使你能够轻松将强大的直播功能集成到应用中，无需复杂编程。

<span id="39135b60"></span>
## 功能


* 服务端 SDK 封装了 API 调用和返回调用结果，无需进行 API 鉴权。

* 提供常用 API 的代码示例。

* 服务端 SDK 封装了常见流程，如生成临时安全凭证。


<span id="878ffd42"></span>
## 安装与使用

安装服务端 SDK 后，你可以通过代码示例调用 API。

目前，BytePlus Live 提供 Go SDK。
