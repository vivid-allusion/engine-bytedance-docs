本主题记录了常见错误和状态码。

<span id="common-errors-for-byteplus"></span>
## BytePlus 常见错误


|名称 |消息 |接口行为 |状态码 |
|---|---|---|---|
|MissingParameter |请求缺少 %s 参数。 |缺少必要的关键参数，例如 Action 和 Version。 |400 |
|MissingAuthenticationToken |请求缺少身份验证令牌。 |缺少必要的身份验证信息。 |401 |
|MissingRequestInfo |请求缺少 %s 信息。 |请求缺少必要信息，例如 Access Key、Service 或 Region。 |400 |
|MissingSignature |请求缺少签名。 |请求签名缺失。 |401 |
|InvalidTimestamp |请求签名已过期。 |请求签名已过期或签名时间无效。 |400 |
|ServiceNotFound |未找到服务 '%s'。 |请求的服务不存在，或指定的服务名称错误。 |404 |
|InvalidActionOrVersion |无法找到版本 %s 的操作 %s。 |请求的 API 操作不存在，或指定的操作名称错误。 |404 |
|InvalidAccessKey |请求中包含的 Access Key [%s] 无效。 |请求中包含的 Access Key 无效。 |401 |
|SignatureDoesNotMatch |我们计算的请求签名与您提供的签名不匹配。请检查您的 Secret Access Key 和签名方法。详情请参阅服务文档。 |生成的签名无效。 |401 |
|LackPolicy |请求因权限不足被拒绝。 |子账号无权限访问资源。 |403 |
|AccessDenied |用户无权在资源 %s 上执行操作: %s。 |子账号无权限执行该请求。 |403 |
|InternalError |服务发生内部错误。请联系管理员。 |内部错误。 |500 |
|FailToConnect |无法连接到内部服务。 |用户授权已验证，但服务连接失败。 |502 |
|InternalServiceTimeout |内部服务超时。请联系管理员。 |内部服务超时。 |504 |
|FlowLimitExceeded |请求被拒绝，因为该 openAPI 的请求速度超出当前流量控制限制。 |请求超出流量控制限制。 |429 |
|ServiceUnavailableTemp |服务繁忙，请稍后重试。 |服务繁忙。请稍后重试。 |503 |
|MethodNotAllowed |HTTP 方法不允许。 |不支持该 HTTP 方法。 |405 |
|InternalServiceError |服务发生内部错误。请联系管理员。 |服务发生内部错误。请联系技术支持。 |502 |
|InvalidAuthorization |Authorization 头无效，请检查授权头。 |Authorization 头的格式无效。 |400 |
|InvalidCredential |Authorization 中的凭证无效，请检查授权头中的凭证。 |Authorization 头中的 Credential 格式无效。 |400 |
|InvalidSecretToken |密钥令牌无效，消息: %s。 |由于签名错误或过期，密钥令牌（STS 或 STS2）无效。 |401 |


<span id="common-errors-for-byteplus-live"></span>
## BytePlus Live 常见错误


|状态码 |错误码 |错误信息 |接口行为 |
|---|---|---|---|
|400 |InvalidParameter.%sInvalid |指定的参数 %s 无效。 |参数无效。请根据规范修改参数值后重试。 |
|400 |InvalidParameter.ActivityHasBeenDeleted |指定的参数 ActivityId 无效。 |直播间已被删除。请修改 `ActivityId` 参数的值后重试。 |
|400 |InvalidParameter.ActivityNotExist |指定的参数 ActivityId 无效。 |直播间不存在。请修改 `ActivityId` 参数的值后重试。 |
|500 |InternalError.InternalError |请求因未知错误而失败。 |请求处理过程中发生未知错误。请联系技术支持寻求帮助。 |
