为简化您与 BytePlus Live API 的集成，本文档集中提供所有共享请求参数和返回调用结果参数的参考。您可以参考本指南，了解每次 API 调用所需的通用参数。

<span id="common-request-parameters"></span>
## 通用请求参数

以下是通用请求参数。


|参数名称 |数据类型 |必填 |位置 |接口行为 |示例 |
|---|---|---|---|---|---|
|Host |字符串 |是 |Header |终端节点。请将该值设置为 `livesaas.byteplusapi.com`。 |livesaas.byteplusapi.com |
|Content\-Type |字符串 |是 |Header |多用途互联网邮件扩展（MIME）资源类型。请将该值设置为 `application/x-www-form-urlencoded; charset=utf-8`。 |application/x\-www\-form\-urlencoded; charset=utf\-8 |
|X\-Content\-Sha256 |字符串 |是 |Header |使用 HTTP 或 HTTPS 请求体中的 payload 作为哈希函数输入生成的字符串。该字符串采用小写十六进制字符。如果 payload 为空，则使用空字符串作为哈希函数的输入。此参数用于签名目的。更多信息请参见 [API 认证](https://docs.byteplus.com/docs/byteplus-livesaas/docs-API-authentication-zh-CN)。 |e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855 |
|X\-Date |字符串 |是 |Header |API 请求发送时的 UTC 时间。<br><br>单位：秒。<br><br>格式：`YYYYMMDD'T'HHMMSS'Z'` |20201230T081805Z |
|X\-Security\-Token |X\-Security\-Token |字符串 |否 |使用长期访问密钥时无需此参数。Header |由安全令牌服务（STS）颁发的临时会话令牌。 |
|[通用参数](https://docs.byteplus.com/docs/byteplus-livesaas/docs-shared-parameters-zh-CN) |字符串 |是 |Header |格式：`HMAC-SHA256 Credential={AccessKeyId}/{ShortDate}/{Region}/{Service}/request, SignedHeaders={SignedHeaders}, Signature={Signature}`。更多信息请参见 [API 认证](https://docs.byteplus.com/docs/byteplus-livesaas/docs-API-authentication-zh-CN)。 |HMAC\-SHA256 Credential=AKAPY2RhYmQzODhhYTg4NGZmNTk3ZGUxODk3ODgzYTA\*\*\*\*/20201230/ap\-singapore\-1/livesaas/request, SignedHeaders=content\-type;host;x\-content\-sha256;x\-date, Signature=11a2e7bb9db7ee7ea2e4d7f3d6989a65dc3bb5feedf3aae50ba1b3313fe0093a |
|Action |字符串 |是 |查询字符串 |API 操作。 |CreateActivityAPIV2 |
|Version |字符串 |是 |查询字符串 |API 操作的版本。当前版本：`2020-06-01`。 |2020\-06\-01 |
|X\-Expires |整数 |否 |Header |签名的有效期。单位：秒。默认值：`900`。 |900 |


<span id="authorization"></span>
### 授权


|参数名称 |数据类型 |接口行为 |示例 |
|---|---|---|---|
|AccessKeyId |字符串 |用于 API 请求认证的 AccessKey ID。 |AKAPY2RhYmQzODhhYTg4NGZmNTk3ZGUxODk3ODgzYTA\*\*\*\* |
|ShortDate |字符串 |API 请求发送时的 UTC 时间。单位：天。格式：`YYYYMMDD`。<br><br>该值必须与 `X-Date` 中的 `YYYYMMDD` 保持一致。 |20201230 |
|Region |字符串 |API 请求的区域。该值必须为 `ap-singapore-1`。 |ap\-singapore\-1 |
|Service |字符串 |API 请求的服务名称。对于 BytePlus Live，该值必须为 `livesaas`。 |livesaas |
|SignedHeaders |字符串 |用于签名的请求头列表，使用分号分隔。此过程确保在验证时忽略代理添加的额外头部。如果请求中包含 `host` 和 `x-date` 头，则必须将其包含在此列表中。 |content\-type;host;x\-content\-sha256;x\-date |
|Signature |字符串 |计算得到的签名。 |11a2e7bb9db7ee7ea2e4d7f3d6989a65dc3bb5feedf3aae50ba1b3313fe0093a |


<span id="common-response-parameters"></span>
## 通用返回调用结果参数

以下是通用返回调用结果参数。


|参数名称 |数据类型 |接口行为 |示例 |
|---|---|---|---|
|RequestId |字符串 |API 请求的唯一 ID。 |202201201826170101501312091D1C09D2 |
|Action |字符串 |请求 API 操作的名称。 |CreateActivityAPIV2 |
|Version |字符串 |请求 API 操作的版本。当前版本：`2020-06-01`。 |2020\-06\-01 |
|Service |字符串 |请求 API 服务的名称。对于 BytePlus Live，该值为 `livesaas`。 |livesaas |
|Region |字符串 |请求 API 服务的区域。该值为 `ap-singapore-1`。 |ap\-singapore\-1 |
|SystemTime |整数 |API 操作调用时的系统时间，采用 Unix 时间戳格式。单位：秒。 |1656067132 |
