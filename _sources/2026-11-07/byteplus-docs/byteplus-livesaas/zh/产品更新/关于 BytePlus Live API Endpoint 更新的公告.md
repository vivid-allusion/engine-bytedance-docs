尊敬的 BytePlus Live 用户：

为提升 BytePlus Live API 服务的识别度与使用体验，BytePlus Live 产品已更新 API Endpoint 域名。具体调整如下所示。

**更新说明**

BytePlus Live API 推荐使用新的 Endpoint：`https://livesaas.byteplusapi.com`

原 Endpoint：`https://open.byteplusapi.com` 仍可继续正常使用，当前不会影响已有业务调用。

**其他信息**

已接入原 Endpoint 的用户无需立即调整，现有调用链路仍可正常使用；

为便于后续服务识别、问题排查和能力演进，建议您在新接入或后续版本迭代时，优先使用新的 Endpoint：`https://livesaas.byteplusapi.com`；

继续使用 BytePlus Live 服务期间，请遵守 BytePlus Live 服务使用协议。

如果您对此次调整有任何疑问，请联系 BytePlus Live 技术支持咨询。
