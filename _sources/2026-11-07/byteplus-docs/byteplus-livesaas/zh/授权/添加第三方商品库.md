BytePlus Live 支持添加来自 TikTok Shop、Shopify 或其他店铺系统等外部平台的商品，使您的 AI 虚拟主播能够在直播过程中推广和讲解商品。本指南提供如何配置并授权来自 TikTok Shop、Shopify 或您自有系统的商品库的分步操作说明。

<span id="8ee628bc"></span>
## 前提条件

订阅 AI Live 服务：请参阅 [订阅计费情况](https://docs.byteplus.com/docs/byteplus-livesaas/digital-human-subscription-billing-method-zh-cn) 并联系销售订阅 AI Live 服务。

<span id="187bcea3"></span>
## 操作流程

请按照以下步骤设置您的商品库。


1. 登录 [BytePlus Live 控制台](https://console.byteplus.com/livesaas/liveManagement/)。

2. 点击顶部导航栏中的 **Authorization** 。

3. 在左侧导航栏，点击 **Integrations** \> **Product Library** 打开页面。

4. 在 **Product Library** 页面，点击 **Product library management**。

   **Product library management** 面板将在右侧打开。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d5994cec42d74a01983101dceb49c279~tplv-goo7wpa0wc-image.image) </span>

5. 点击  **+Add product library** 并输入 **Product Library Name**。

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/33dd68758fc34113bd01a82cb4b96fa9~tplv-goo7wpa0wc-image.image) </span>

6. 选择 **Product library type**。类型设置后不可更改。

   
   <Tabs>
   <Tab zoneid="OVAHgJwKPN" title="TikTok Shop">
   <TabTitle>TikTok Shop</TabTitle>
   
   点击 **Go to authorize**。选择您的地区和授权店铺。
   
   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de817af0167e46d788639e1791d30e2d~tplv-goo7wpa0wc-image.image) </span>
   
   
   </Tab>
   <Tab zoneid="NC1zwWCp0H" title="Shopify">
   <TabTitle>Shopify</TabTitle>
   
   输入您的域名和公共访问令牌：
   
   
      * **Domain name**：您的 Shopify 店铺的域名。
   
         获取域名，请在 Shopify 店铺左侧导航栏点击“设置”，在店铺名称下方查看域名。您也可以点击“设置” \> “域名”，在“域名”页面查看域名。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0aa4e1b2fc5349e184af839897ce7db9~tplv-goo7wpa0wc-image.image) </span>
   
      * **Public access token**：您的 Shopify 店铺 Storefront API 的公共访问令牌。
   
         获取令牌，请在 Shopify 店铺导航至 **Headless sales channel** 页面。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fcc45a5e3e8b4813b7218b86c6e766be~tplv-goo7wpa0wc-image.image) </span>
   
         点击 **Manage**，在 Storefront API 页面查看公共访问令牌。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/084b594a5b10486f8af763fe4f1fddfc~tplv-goo7wpa0wc-image.image) </span>
   
         点击保存图标。
   
         <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f44dec36f7a94a829864eecee2d0441d~tplv-goo7wpa0wc-image.image) </span>
   
   
   </Tab>
   <Tab zoneid="tF9SnmFFak" title="自有系统">
   <TabTitle>自有系统</TabTitle>
   
   输入用于从商品库获取商品的请求 URL。
   
   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>
   
   
   <div data-tips="true" data-tips-type="warning">在从自有系统添加商品库前，您必须根据规范开发 API，将您的系统与 BytePlus Live 集成。更多信息请参见 <a href="https://docs.byteplus.com/docs/byteplus-livesaas/docs-adding-product-cards-to-your-live-stream-zh-CN#f4985fe1">将你的系统集成至 BytePlus Live</a>。</div>
   
   
   
   </Tab>
