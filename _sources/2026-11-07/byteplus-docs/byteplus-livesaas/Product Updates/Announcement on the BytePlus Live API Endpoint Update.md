Dear BytePlus Live users,

To improve the recognizability and user experience of the BytePlus Live API service, BytePlus Live has updated its API Endpoint domain name. The changes are as follows:

**Update details**

The new recommended Endpoint for the BytePlus Live API is: `https://livesaas.byteplusapi.com`. The original Endpoint, `https://open.byteplusapi.com`, can still be used and will not affect existing service calls.

**Other information**

Users who have already integrated the original Endpoint do not need to make immediate changes. Existing call paths will continue to function normally.

To facilitate service identification, troubleshooting, and feature evolution, we recommend that you prioritize using the new Endpoint, `https://livesaas.byteplusapi.com`, for new integrations or future version updates.

As you continue to use BytePlus Live services, please adhere to the BytePlus Live Terms of Service.

If you have any questions about this change, please contact BytePlus Live technical support.
