Torch Log Service (TLS) SDK for Android encapsulates the data collection API actions of TLS. In your Android application, you can use the SDK to collect the log data of the application.

<span id="版本说明"></span>
## Release notes

TLS SDK for Android 1.1.4 and later can call TLS API actions in a stable manner. We recommend that you use the latest version of the SDK to use the product capabilities and services. To view the list of versions, visit [Maven](https://search.maven.org/artifact/com.volcengine/volc-tls-android-sdk).

<span id="源码与示例项目"></span>
## Source code and sample project

TLS SDK for Android offers sample projects for your reference, including log collection and resource management. For more information, refer to the source code on GitHub.
