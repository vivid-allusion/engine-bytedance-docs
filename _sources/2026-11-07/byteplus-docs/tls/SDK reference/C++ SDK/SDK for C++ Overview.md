Torch Log Service (TLS) SDK for C++ encapsulates the data collection and topic management API actions of TLS. In your C++ application, you can call the API actions to collect log data and manage topics.

<span id="版本说明"></span>
## Release notes

To view the source code of TLS SDK for C++, refer to [TLS SDK for C++](https://github.com/volcengine/ve-tls-cpp-sdk). For information on the update logs and release notes of TLS SDK for C++, visit [GitHub](https://github.com/volcengine/ve-tls-cpp-sdk/tags). We recommend that you use the latest version of the SDK to use the latest product capabilities and more stable services.
