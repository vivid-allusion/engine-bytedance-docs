Torch Log Service (TLS) SDK for Node.js encapsulates commonly used API actions of TLS. You can use TLS SDK for Node.js to call server\-side API actions to implement features such as collecting and querying logs.

<span id="版本说明"></span>
## Release notes

For information on the update logs and release notes of TLS SDK for Node.js, visit [GitHub](https://github.com/volcengine/volc-sdk-nodejs/tags). We recommend that you use the latest version of the SDK to use the latest product capabilities and more stable services.

<span id="示例项目"></span>
## Sample projects

TLS SDK for Node.js offers sample projects for your reference, including log collection and resource management. For more information, refer to the source code on GitHub.
