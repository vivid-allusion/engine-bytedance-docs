This topic introduces the main billing information for Torch Log Service(TLS), including billing methods and billing cycles.

<span id="35cd37c6"></span>
## Billing method

TLS adopts pay\-as\-you\-go billing method. You can use it first and pay later. That is to say, TLS charges based on your actual usage. There is no refund involved.

The billing model for TLS calculates charges at the topic level and supports **pay by feature** and **pay by ingested data.** 

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip"><strong>Pay by ingested data</strong> is a beta feature. If you have relevant need, contact your account manager for allowlist access.</div>



|**Billing method** |Basic concepts |Comparison of advantages |
|---|---|---|
|**Pay by feature** |Charges are based on product feature module. The billing items are divided into three categories: storage space, traffic, and other items. These include 14 subcategories such as internal network read traffic, data transformation traffic, log storage space, and log shard count. |The billing items are more detailed and flexible. You can pay separately for needed functions to optimize cost control.<br><br>It is suitable for scenarios with diverse business and flexible functions. |
|**Pay by ingested data** |Charges are based solely on the amount of data that is written. Billing items are classified into three types: ingested data fees for uploaded data, storage fees for stored data, and traffic fees for public network data reads. |No index traffic, data delivery/processing, shards count, or other billing items. Fewer billing items and simpler billing methods. Plus, a 30\-day free storage quota is included.<br><br>It is suitable for scenarios where dynamic business data fluctuates, temporary resource demand spikes, and full\-link data function support is required. |


<span id="fdc8b02d"></span>
## Billing cycle

The TLS calculates the usage of all resources on a daily basis and settles the fees based on resource usage. The fees generated on the current day will be settled at 00:00 the next day.

<span id="12ac04a4"></span>
## Billing item

Each billing item in TLS is charged separately. For example, if you choose pay\-by\-feature mode, TLS charges based on the **billing item for number of log shards** after you configure shards. For detailed descriptions of billing items, see [Pay by feature](https://docs.byteplus.com/docs/tls/Billing_items_based_on_pay-by-feature_mode).

## Usage query

You can view the usage of billing resources in the following two ways.


* View the total usage of billing resources from the previous calendar day on the **Overview** page on [Torch log service console](https://console.byteplus.com/tls).

* View billable resource usage through CloudMonitor. For details, see [View Cloud monitoring data](https://docs.byteplus.com/docs/tls/view_monitore_data).

## Bill query

<span id="2dd5c73f"></span>
### Bill details

For specific billing information, you can go to BytePlus console, and click [Billing center ](https://console.byteplus.com/finance/account-overview/) \> **Bill management \>**  **Bill details**. For detailed steps, see [Bill management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-having-an-overview-of-bills).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The <strong>extra specs</strong> column in the billing detail table displays the log topic name and ID that is tied to each billing item. You can filter by <strong>extra specs</strong> to get all billing items generated by the target log topic.</div>


<span id="2b290eeb"></span>
### Split bills

To view split bills of TLS, you can go to BytePlus. First click [Billing center ](https://console.byteplus.com/finance/account-overview/)  **\> Bill management \>**  **Split bills** and then filter **Torch Log Service** in **Product** column. For detailed steps, see [Split bills](https://docs.byteplus.com/en/docs/byteplus-platform/SplitBills).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">In split bill table, the <strong>Split item ID</strong> column displays the project ID that is tied to the billing item. The <strong>Split item name</strong> displays the project name. You can download this table locally and analyze billing details at project level based on <strong>Split item ID</strong> and <strong>Split item name</strong>.</div>
