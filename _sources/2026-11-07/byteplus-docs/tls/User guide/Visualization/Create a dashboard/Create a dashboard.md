A dashboard is one of the tools offered by Torch Log Service (TLS) for visualizing query results. A dashboard is a collection of charts for displaying and monitoring log analysis results. Multiple charts of the same project can be displayed on the same dashboard. This topic describes how to create a dashboard in the TLS console.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">In this topic, the procedure for creating a dashboard on the <strong>Dashboard</strong> page is described. You can also configure a new dashboard to save the analysis results after you execute a log query. For more information, refer to <a href="https://docs.byteplus.com/docs/tls/Adding_charts_to_a_dashboard">Add charts to a dashboard</a>.</div>

## Before you begin


* Create a project and a topic, and configure them for saving log data.

* Enable the indexing feature.


<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* Up to 50 dashboards can be added to a project.

* Up to 50 charts can be added to a dashboard.


<span id=".5pON5L2c5q2l6aqk"></span>
## Create a blank dashboard


1. Log on to the [TLS console](https://console.byteplus.com/tls).

2. In the left\-side navigation pane, choose **Common Functions** \> **Dashboard**.

3. On the **Dashboard** page, choose  **+** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e976a12a715749a58ff652791c16d892~tplv-goo7wpa0wc-image.image) </span>

4. Click **Create a blank dashboard** , and then click **Next: configure dashboard**.

5. Configure the basic information about the dashboard, and then click **Create dashboard**.

   
   |Parameter |Description |
   |---|---|
   |Dashboard name |Set a name for the dashboard. |
   |Description |Enter a brief description of the dashboard. |
   |Project |Select the target project. |

## Import a dashboard

TLS supports importing dashboards across regions and projects by adding JSON scripts or configuration forms, please refer to [Import a dashboard](https://docs.byteplus.com/docs/tls/Import_dashboard).
