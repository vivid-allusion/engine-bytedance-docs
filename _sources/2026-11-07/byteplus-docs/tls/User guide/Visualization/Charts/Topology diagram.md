TLS supports topology diagrams for displaying query and analysis results. This topic describes how to create a topology diagram.

<span id="9fdc6517"></span>
## Chart description

A topology diagram is a diagram used to visualize the layout and dependencies between different elements (such as modules, services and so on).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Before you configure a chart, read <a href="https://docs.byteplus.com/docs/tls/chart_overview#%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A1%B9">Precautions</a>.</div>


<span id="08ce9217"></span>
## Common configuration

Configure the global settings that apply to the entire chart. The basic settings of a topology diagram are as follows:


|Parameter ||Description |
|---|---|---|
|Panel configuration |Title |Enter a title for the topology diagram. |
||Show chart title bar |Specify whether to display the chart title on the dashboard. |
|Query and analysis field |sub\-node ID |Select the field representing the sub\-node. |
||Parent node ID |Select the field representing the parent node. |
|Topology configuration |Layout type |The layout of the topology diagram includes force guide layout, layout, and ring layout. |
