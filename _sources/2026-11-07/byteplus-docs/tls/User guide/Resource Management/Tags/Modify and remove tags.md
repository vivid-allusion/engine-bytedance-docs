You can modify the tag keys and tag values of existing tags at any time based on your business requirements. If you want to change the category of a project or topic, remove the existing tags that are attached to the project or topic. This topic describes how to modify tags and remove tags from projects.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can remove up to 20 tags from cloud resources at a time.</div>


<span id="为单个资源修改或解绑标签"></span>
## Modify tags or remove tags from a project


1. Log on to the [TLS console](https://console.byteplus.com/tls).

2. In the top menu bar, select the Region where the projects that you want to view are located.

3. In the left\-side navigation pane, choose **Resource management** \> **Project**.

4. Find the target project, and click the Edit icon in the **Tag** row.

   You can also click the name of the project. In the **Basic information** section of the page that appears, click the Edit icon in the **Tag** row .

5. Modify or remove tags based on your business requirements.

   * Modify a tag: set a new value in the **Tag Key** or **Tag Value** field. Follow the tag setting rules to set a tag. For more information, refer to [Rules for setting tags](https://docs.byteplus.com/docs/tls/Add_tags#%E6%A0%87%E7%AD%BE%E8%AE%BE%E7%BD%AE%E8%A7%84%E5%88%99).

   * Remove a tag: find the key of the tag that you want to remove and click **Delete**.

6. Click **OK**.


<span id="批量解绑标签"></span>
## Remove tags from multiple projects


1. Log on to the [TLS console](https://console.byteplus.com/tls).

2. In the top menu bar, select the Region where the projects that you want to view are located.

3. In the left\-side navigation pane, choose **Resource management** \> **Project**.

4. Select the projects from which you want to remove tags, then click **Remove Tag** on the bottom\-left corner of the page.

5. Select the tag keys that you want to remove from the drop\-down list, or enter tag keys in the field to filter tag keys.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The number of selected projects to which each selected tag is attached is displayed on the page. This operation removes the specified tags from the selected projects, but does not remove the tags from the projects that are not selected.   </div>
   

6. Click **OK**.
