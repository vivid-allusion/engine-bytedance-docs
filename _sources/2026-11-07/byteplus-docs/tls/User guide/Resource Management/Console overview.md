The Torch log service (TLS) console overview page provides an efficient workspace, including quick access to various functional modules, such as starred resources, usage statistics, and help documentation.

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_cc8a0d3b853e7134df19b90efbacb7a6.png) </span>

&nbsp;


|<ins>Serial number</ins> |Description |
|---|---|
|1 |Used to select the IAM project and region where TLS is located.<br><br>After you select the region, the system displays TLS resources for the corresponding IAM project and region. |
|2 |Shows features of TLS. You can click a feature to quickly access its page. |
|3 |Displays your starred resources and recently viewed resources for fast access. |
|4 |Displays a list of all projects under the current IAM project and region. |
|5 |Displays usage of billing resources for TLS on the previous day.  |
|6 |Provides quick access for log collection.<br><br>You can click **Log collection** and select the log source to collect. For details, see [Collection overview](https://docs.byteplus.com/docs/tls/data_collection_overview). |
|7 |Provides a quick access to product documentation |
|8 |Displays the latest product updates. |
