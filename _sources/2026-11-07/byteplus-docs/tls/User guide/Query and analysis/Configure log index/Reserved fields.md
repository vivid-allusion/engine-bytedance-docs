When log data is written to Torch Log Service (TLS), TLS automatically adds some metadata fields for each log entry to record information such as the log source and timestamp. These metadata fields are referred to as reserved fields. This topic describes the names, data types, and index configurations of reserved fields.

> **tip**

* > When you create a collection rule or call PutLogs to write log data, do not use the names of the following reserved fields as field names. Otherwise, issues such as duplicate field names and inaccurate query results may occur.

* > TLS charges you for adding these metadata fields to log data based on the storage volume. If you enable indexing for these fields, a small index storage fee is incurred.

## Common fields

|Reserved Field |Data Type |Index Configuration |Description |
|---|---|---|---|
|`raw` |Text |* Index setting: By default, indexing is disabled. You cannot configure indexes for the field. After you manually enable full\-text indexing, you can use the full\-text search syntax to search for the field content.<br><br>* Statistics setting: By default, the statistics feature is disabled. You cannot manually enable statistics for the field. |If enabled, raw log data is encapsulated in the `raw` field and uploaded to TLS with the parsed log data.<br><br>This field can be queried but cannot be analyzed. |
|`__tag____client_ip__` |Text |* Index setting: By default, indexing is disabled. You can configure indexes as needed.<br><br>* Statistics setting: By default, the statistics feature is disabled. You can configure statistics as needed. |The public IP address of the host from which logs were collected. After you enable the public IP address recording feature for a topic, TLS adds this field to the collected log content.<br><br>This field can be queried and analyzed.<br><br>> **tip**<br><br><br>> When logs are written through web tracking, TLS uses clientAddr to record the public IP addresses of source devices.<br> |
|`__tag____receive_time__` |Text |* Index setting: By default, indexing is disabled. You can configure indexes as needed.<br><br>* Statistics setting: By default, the statistics feature is disabled. You can configure statistics as needed. |The time when the server received a log. It is a 10\-bit Unix timestamp. After you enable the public IP address recording feature for a topic, TLS adds this field to the collected log content.<br><br>This field can be queried and analyzed. |

## Host log collection

|Reserved Field |Data Type |Index Configuration |Description |
|---|---|---|---|
|`__time__` |Long |* Index setting: After you manually enable indexing, TLS creates key\-value indexes for `__time__` by default. The data type of the index field is long, and no delimiters are available. For example, `__time__:1693193760`.<br><br>* Statistics setting: After you enable indexing, the statistics feature is enabled by default. You can use the TLS SQL analysis syntax. Example: `* \| select __time__`. |The time when log data was written to TLS.<br><br>This field can be queried and analyzed. |
|`__content__` |Text |* Index setting:<br><br>   * After you manually enable indexing, TLS creates key\-value indexes for `__content__` by default. The data type of the index field is text, and the delimiters include `!@#%^&*"()-_=', <>/?\|;:\n\t\r[]{}\`.<br><br>   * If you disable full\-text indexing and enable key\-value indexing, you can modify the key\-value index configurations of this field.<br><br>* Statistics setting: By default, the statistics feature is disabled. If you disable full\-text indexing and enable key\-value indexing, you can manually enable statistics. |This field is used to encapsulate raw log data. This field does not have a preset index. To query logs based on this field, manually enable full\-text indexing.<br><br>This field can be queried and analyzed.<br><br>> **tip**<br><br><br>> If the data type of `__content__` in key\-value indexing is set to JSON, the data type of other fields cannot be set to JSON. Otherwise, error `Function [QUERY_STRING] cannot be found or used here` is reported when you query these fields.<br> |
|`__path__` |Text |* Index setting: After you enable full\-text indexing, TLS creates indexes for `__path__` by default. The data type of the index field is text, and no delimiters are available. When you query logs, type `__path__:/infcs/log`.<br><br>* Statistics setting: After you enable indexing, the statistics feature is enabled by default. You can use the TLS SQL analysis syntax. Example: `*\|select __path__`. |The source directory and filename of a log file.<br><br>This field can be queried and analyzed. |
|`__source__` |Text |* Index setting: After you enable indexing, TLS creates indexes for `__source__` by default. The data type of the index field is text, and no delimiters are available. When you query logs, type `__source__:10.0.0.1`.<br><br>* Statistics setting: After you enable indexing, the statistics feature is enabled by default. You can use the TLS SQL analysis syntax. Example: `*\|select __source__`. |The IP address of the log source server.<br><br>This field can be queried and analyzed. |
