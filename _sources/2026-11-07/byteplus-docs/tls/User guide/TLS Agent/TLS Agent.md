TLS Agent, provided by TLS, is an intelligent AI tool that enables fast data queries and intelligent insights for logs, metrics, and trace data using natural language interactions. This topic describes how to use TLS Agent.

## How it works

TLS Agent has a in\-depth understanding of the TLS console, and it is fully integrated with documentation, best practices, FAQs, and other knowledge sources to form a unified foundation. 

You can interact with TLS Agent using natural language for multi\-turn conversations. TLS Agent can not only answer TLS\-related questions but also invoke TLS CLI directly for task creation, enabling data integration, insights, query and analysis, and resource management. 

During task creation or result analysis, you can save relevant context or preferences as long\-term memory in the unified knowledge base. This helps TLS Agent to self\-evolve and become a practical intelligent assistant in real workflows.


|Feature |Description |
|---|---|
|Unified knowledge base |It has an in\-depth understanding of the TLS console and product documentation. |
|Long\-term memory |Supports the conversion of business contexts, FAQs, resource preferences, and troubleshooting workflows into long\-term memory. |
|Product capability guide |Support understanding context and user intent, and provide guidance for subsequent actions. |
|Executable work environment |Support calling TLS CLI for queries, result analysis, chart generation, and link analysis. |

## Use cases

TLS Agent offers a variety of use cases, including but not limited to:


|Use cases |Description |
|---|---|
|Product consultation |* Handles questions about TLS features, query syntax, and data transformation functions. <br><br>* Explains console field meanings, index configuration effectiveness, and next steps. |
|Getting started |Guides new users through the process of data integration, log querying, statistical analysis, and troubleshooting, helping them learn TLS step by step. |
|Observability analysis |* Visualizes log data to help users quickly understand trends, distributions, and exceptions. <br><br>* Enables users to pinpoint system phenomena from individual logs, interpret exceptions with indexes and query results, and proceed to aggregation, analysis, and impact assessment. |
|Log troubleshooting |* Performs automatic analysis of current log exceptions and auto generation of troubleshooting reports, helping users quickly locate issues. <br><br>* Used for integrating troubleshooting materials and historical cases into long\-term memory for unified management, making the agent more comprehensive and professional. |
