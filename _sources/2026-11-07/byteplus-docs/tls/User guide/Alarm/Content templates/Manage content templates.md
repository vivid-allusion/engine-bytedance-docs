This article introduces common operations for alarm notification content templates, including viewing, copying, editing, and deleting content templates.

<span id="893df06c"></span>
## View content templates


1. Log in to the [Torch Log Service console](https://console.byteplus.com/tls).

2. On the top navigation bar, select the region where the log service is located.

3. In the left navigation bar, select **Common functions** \> **log alarm** \> **notification management**.

4. Under the **content templates** tab, view all content templates in the current region.

   You can also click the target content template to view its details.


<span id="868172c3"></span>
## Copy content templates

When creating multiple similar content templates, use the copy function to create them quickly.


1. Log in to the [Torch Log Service console](https://console.byteplus.com/tls).

2. On the top navigation bar, select the region where the log service is located.

3. In the left navigation pane, select **Common Functions** \> **log alarm** \> **notification management**.

4. Under the **Content Template** tab, find the specified content template, then click **Copy** in the corresponding **Actions** column.

5. Set the template name and the notification content for each notification channel, then click **Confirm**.

## Edit Content Template

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Editing the default template is not supported.</div>



1. Log in to the [Torch Log Service console](https://console.byteplus.com/tls).

2. On the top navigation bar, select the region where the log service is located.

3. In the left navigation pane, select **Common Functions** \> **log alarm** \> **notification management**.

4. Under the **content template** tab, find the specified content template, then click **edit** in its corresponding **action** column.

5. Reset the template name and notification content for each channel, then click **confirm**.

## Delete content template

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Deleting the default template is not supported.</div>



1. Log in to the [Torch Log Service console](https://console.byteplus.com/tls).

2. On the top navigation bar, select the region where the log service is located.

3. In the left navigation bar, select **common functions** \> **log alarm** \> **notification management**.

4. Under the **content template** tab, find the specified content template, then click **delete** in its corresponding **action** column.

5. In the **confirm delete template** dialog, click **delete**.
