Torch Log Service (TLS) can collect container logs and access logs from various cloud services. The collected logs include Audit logs and access logs. In TLS, you can view the collected log data, query and analyze log data statistics in real time, build real\-time data visualization dashboards, configure monitoring and alarming for status monitoring, and perform other log data processing operations.

TLS can collect logs from the following cloud services:


|Category |Product Name |Type |Reference |
|---|---|---|---|
|Network |[Cloud Load Balancer (CLB)](https://docs.byteplus.com/en/docs/clb) |Health check log |[CLB health check logs](https://docs.byteplus.com/en/docs/clb/Health-check-log) |
||[Application Load Balancer (ALB)](https://docs.byteplus.com/en/docs/alb) |* Health check log<br><br>* Access log |* [ALB health check logs](https://docs.byteplus.com/en/docs/alb/Health-check-logs)<br><br>* [ALB access logs](https://docs.byteplus.com/en/docs/alb/Sending-access-logs-to-TLS) |
||[VPN Connection](https://docs.byteplus.com/en/docs/vpn) |IPsec\-VPN connection log |[Viewing IPsec-VPN connection logs](https://docs.byteplus.com/en/docs/vpn/Viewing-IPsec-VPN-connection-logs) |
|Elastic Computing |[Elastic Compute Service (ECS)](https://docs.byteplus.com/en/docs/ecs) |All log types |[Data collection overview](https://docs.byteplus.com/docs/tls/data_collection_overview). |
