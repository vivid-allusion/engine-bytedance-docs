This topic introduces how to get started with Torch Log Service (TLS), using BytePlus Elastic Compute Service (ECS) log collection as an example.

<span id="procedure"></span>
## Procedure


1. [Create resources](https://docs.byteplus.com/docs/tls/getting_started_creating_resources)

   After creating a BytePlus account and completing enterprise real\-name verification, create basic resources in the TLS console: projects and topics. The logs collected later are stored in the topics.

2. [Collecte logs](https://docs.byteplus.com/docs/tls/getting_started_collecte_logs)

   This topic uses the collection of BytePlus ECS logs as an example to introduce how to install LogCollector and create collection rules in the TLS console.

3. [Configure indexes](https://docs.byteplus.com/docs/tls/getting_started_configure_indexes)

   After creating collection rules, you must configure log indexes to preview logs in real time or query and analyze logs in the console.

4. [Query and analyze logs](https://docs.byteplus.com/docs/tls/getting_started_query_and_analyze_logs)

   TLS offers log query and analysis features, allowing you to filter and select log data through search and analysis statements. The results can then be displayed in charts and used for statistical analysis and computing.
