This article introduces the region IDs and connection addresses of different regions for the log service.

Byteplus TLS provides service addresses (Endpoints) of various network types and regions to access log projects and their internal data, as well as to write log data. Among them, the region refers to the geographical area where the physical resources corresponding to the service are located. You can choose a region closer to your business's business scenario and geographical location according to your needs, reducing the delay of log writing, query, and other operations.

The service address is related to the region and network type where the log project is located. You can view the service address of the specified log project on the console, or quickly view the corresponding service address in this document according to the region and network type of the project.

<span id="view-endpoints"></span>
## View endpoints

Log in the TLS console,and click the name of the project that you want to manage. On the Project Overview page of the project, view the endpoints for the region where the project resides.

<span id="select-an-endpoint"></span>
