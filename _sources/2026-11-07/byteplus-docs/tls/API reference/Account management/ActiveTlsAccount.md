This API allows you to activate TLS.

<span id=".6K-35rGC6K-05piO"></span>
## Request instructions


* Request method: POST

* Request URL: https://{tls\-endpoint}/ActiveTlsAccount


<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters

This API does not require any specific request or common parameters. For more information, see [Common Parameters](https://docs.byteplus.com/en/docs/tls/common-parameters).

<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameters

This API does not have any specific response parameters. For more information, see [Return Structure](https://docs.byteplus.com/en/docs/tls/response-message).
