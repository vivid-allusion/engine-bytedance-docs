<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">Log projects and log topics related to service logs are not supported for deletion. For more information, please refer to <a href="https://docs.byteplus.com/docs/tls/service_logs_overview">Service logs Overview</a>.</div>


* <div data-tips="true" data-tips-type="tip">For log projects and log topics related to cloud product logs, including the following scenarios, please make judgments based on actual circumstances:</div>


   * <div data-tips="true" data-tips-type="tip">It is recommended to enable the logging feature in the corresponding cloud product console before deleting the associated log projects and log topics in the TLS console.</div>


   * <div data-tips="true" data-tips-type="tip">You must enable logging in the corresponding cloud product console before you can delete the corresponding log projects and log topics in the TLS console.</div>


   * <div data-tips="true" data-tips-type="tip">After the log logging is enabled in the corresponding cloud product console, the system will automatically delete the corresponding log projects and log topics.</div>


1. Delete a project. For more information, please refer to [Delete a project](https://docs.byteplus.com/docs/tls/Managing_projects#%E5%88%A0%E9%99%A4%E6%97%A5%E5%BF%97%E9%A1%B9%E7%9B%AE).

2. Delete a topic. For more information, please refer to [Delete a topic](https://docs.byteplus.com/docs/tls/Managing_topics#%E5%88%A0%E9%99%A4%E6%97%A5%E5%BF%97%E4%B8%BB%E9%A2%98).
