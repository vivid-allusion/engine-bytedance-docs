Torch Log Service (TLS) and Datasail are both data services offered by BytePlus. The following table describes their differences in positioning, core features, and data collection capabilities. You can select one of them based on your business needs and scenarios.


|Item |TLS |Datasail |
|---|---|---|
|Definition |TLS is a one\-stop platform offered by BytePlus for log data. It allows you to collect, store, query, analyze, monitor, and visualize massive data, suitable for scenarios such as application O&M, service monitoring and alarms, and classified protection compliance. It helps you improve R&D and O&M efficiencies. |Datasail is an end\-to\-end solution that receives, processes, and distributes data in real time based on the trillion\-level data integration and processing capabilities of Douyin Group. It supports more than 20 heterogeneous data sources to quickly and stably synchronize full or incremental batch data and streaming data in complex network environments. |
|Use scenarios |It is suitable for scenarios of business O&M and monitoring, cloud service log monitoring, real\-time log queries and analysis, and data lake analysis and computing. |It is suitable for scenarios of client data collection for event tracking, offline data synchronization, and streaming data synchronization. |
|Core features |It offers features such as log data collection, queries and analysis, data transformation and processing, consumption and shipping, visualization, and monitoring and alarming. |It offers capabilities such as the data reporting SDK, offline data integration, and streaming data integration. |
|Data collection |It offers various methods such as the log collection agent, API, and SDK to help you collect logs from different data sources such as OSs. For more information, refer to [Data transformation overview](https://docs.byteplus.com/docs/tls/data_transformation_overview) |It offers capabilities such as using the data reporting SDK and API for data integration. |
