---
title: "Why can't I delete the log topic?"
product: "Torch Log Service"
product_code: "tls"
source: "https://docs.byteplus.com/en/docs/tls/Why-can-not-I-delete-the-log-topic"
---

When there is a LogCollector collection configuration in a log topic, the log topic does not support being deleted. In addition, some exclusive log topics do not support being deleted. You can troubleshoot in the following ways.


1. Check whether there is a LogCollector collection configuration in the log topic.

   On the **LogCollector** tab of **Log collection** page, check whether there is a LogCollector collection configuration related to the current log topic. If it exists, please delete the collection configuration first. For more information, please refer to [View collection rule information](https://docs.byteplus.com/docs/tls/logcollector_collection_rule_management#%E6%9F%A5%E7%9C%8B%E9%87%87%E9%9B%86%E9%85%8D%E7%BD%AE%E4%BF%A1%E6%81%AF), [Delete collection rules](https://docs.byteplus.com/docs/tls/logcollector_collection_rule_management#%E5%88%A0%E9%99%A4%E9%87%87%E9%9B%86%E9%85%8D%E7%BD%AE).

2. Check whether the log topic is an exclusive log topic.

   Exclusive log topics related to Trace services, service logs, and some cloud product logs do not support deletion.

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The log resources generated by service logs will not incur any storage costs.   </div>
