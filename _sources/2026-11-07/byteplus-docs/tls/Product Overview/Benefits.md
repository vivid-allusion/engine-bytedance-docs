This topic describes the benefits of Torch Log Service (TLS).

<span id="a457061f"></span>
## Second\-level query


* Writes and streams logs nearly in real time and displays the data in seconds.

* Transforms and processes data with ultra\-low latency, which helps you efficiently manage massive data from multiple sources.


<span id="e34280be"></span>
## High scalability


* Adopts a distributed architecture and supports auto scaling to meet your business needs. By adding nodes and resources, you can seamlessly expand the storage capacity and capability to handle the increasing volume of log data and query workload.

* Allows you to manage data by shard. To process large\-scale data read, write, and query requests, you can split shards. TLS can dynamically adjust the number of shards in response to the growth in data volume.

* Supports connecting to cloud\-native ecosystems. TLS can work with services such as cloud\-native computing and storage to fully leverage the resources and capabilities of cloud platforms, achieving high scalability.


<span id="018938b2"></span>
## Security and reliability


* Uses the HTTPS protocol to encrypt data to be transmitted, securing data transmission.

* Adopts a high availability distributed architecture to ensure persistent and reliable data.

* Leverages an underlying architecture with high performance and high reliability to offer 100% serverless services and ensure 99.9% service availability.


<span id="34fb1a0d"></span>
## Ease of use


* Offers fully\-managed services. You do not have to set up open\-source log systems such as the ELK stack or develop a complex resource plan. Just pay for what you use.

* Offers flexible data collection methods. TLS allows you to integrate trace and log data through the Agent, API, SDK, Kafka protocol, open\-source products, and cloud products. The data comes from dozens of data sources such as servers, mobile apps, web pages, and cloud products.
