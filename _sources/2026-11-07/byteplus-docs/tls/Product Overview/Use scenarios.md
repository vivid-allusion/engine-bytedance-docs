This topic describes the main use scenarios of Torch Log Service (TLS).

<span id="814ba9d9"></span>
## Operations and maintenance (O&M) and monitoring

Enterprises can build log platforms based on TLS to implement business monitoring and O&M. Details are as follows:


* Issue locating: TLS offers the data integration, data processing, and query and analysis capabilities. Development and O&M departments can build an intelligent O&M platform based on TLS in response to multiple scenarios such as high concurrency, complex data types, and multiple data sources. This helps you locate and solve issues in time.

* Visualized charts: TLS allows you to analyze data in multiple dimensions and create interactive dashboards to view the system status and user experience. The data helps business teams improve user experience.

* Monitoring and alarming: TLS allows you to collect and analyze security events and behavior data in business systems to detect and respond to potential security threats in real time.


<span id="3eedbe57"></span>
## Statistical analysis

TLS supports multiple query methods such as key\-value search, fuzzy search, phrase search, context search, and standard SQL\-92 functions. These methods allow you to search massive data in seconds. TLS also offers various types of visualized charts and interactive dashboards to display the status and trend of key business metrics in real time, so decision makers are informed of updates.

<span id="41a6f3e9"></span>
## Data lake and stream computing

TLS is widely applied in big data, data lake, and stream computing solutions. TLS offers flexible data collection capabilities to integrate dozens of data sources and powerful data transformation capabilities to clean and wrangle data. With the consumption and shipping features, TLS can seamlessly connect to real\-time computing services and stream computing engines.

<span id="21728831"></span>
## Monitoring of cloud service logs

After you migrate your enterprise application to the cloud, you can use TLS to collect and analyze BytePlus service logs in real time. TLS offers out\-of\-the\-box visualized applications of log analysis and best practices in cloud product log scenarios.

<span id="40ffae4c"></span>
## Classified protection compliance

TLS can help your enterprise meet classified protection compliance requirements. TLS offers comprehensive log collection and storage features to help your enterprise collect and store information system logs in an efficient manner. Moreover, TLS offers strong log analysis and audit capabilities to help your enterprise detect potential security threats and violation behaviors. In addition, TLS offers the log monitoring and alarming feature to help your enterprise monitor the security and compliance of the system.
