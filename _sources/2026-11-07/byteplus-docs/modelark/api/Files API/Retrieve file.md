`GET https://ark.ap-southeast.bytepluses.com/api/v3/files/{file_id}`

Query detailed information about a specified file by file ID.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

* API Key authentication. Go to the [API Key Management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

---

## Request parameters

### Path parameters

**file_id** `string` `Required`  |  File ID

ID of the file to query.

## Response parameters

**created_at** `integer`  |  Creation time

The Unix timestamp (in seconds) of the file upload time.

**expire_at** `integer`  |  Expiration time

The Unix timestamp (in seconds) of the file expiration time. After the file expires, it cannot be accessed and must be uploaded again.

**filename** `string`  |  Original file name

Original file name at upload time.

**id** `string`  |  File ID

Unique identifier of the file.

**object** `string`  |  Object type

Object type. Fixed to `file`.

**purpose** `string`  |  The file purpose

The file purpose.

* `user_data`: A file that can be used for any purpose flexibly.

* `agent`: Files used by agents.

**status** `string`  |  File status

The file processing status. Common values: `active` (processing complete and available for inference), `processing` (processing), and `failed` (processing failed).

**bytes** `integer`  |  File size

File size, in bytes.

> **Note**

> Returned only when the file processing `status` is `active`.

**download_url** `string`  |  Download URL

A temporary presigned URL generated by the server for downloading the original uploaded file.

* When `purpose` is `agent`, `download_url` is returned by default.

* `download_url` is valid for 24 hours and can be used for up to 100 downloads.

* The retrieve file details and list files operations return the same saved `download_url`; reading file metadata does not refresh the link validity period or reset the download count.

* The validity period of `download_url` is independent of the file storage validity period `expire_at`. Even if the file is still within its storage validity period, `download_url` may become unavailable because the link has expired or the download limit has been reached.

> **Note**

> This URL contains temporary access credentials. Provide it only to authorized users, and avoid writing it to logs, caching it long term, or sharing it publicly.

**error** `object`  |  Error information

Error information object returned when file upload or processing fails. It contains parameters such as the error code and error message.

> **Note**

> Returned only when the file processing status `status` is `failed`.

**code** `string`  |  Error code

`error.code`

**message** `string`  |  Error description

`error.message`

**mime_type** `string`  |  MIME type

MIME type of the file, such as `video/mp4` or `image/jpeg`.

**preprocess_configs** `object`  |  Preprocessing configuration

Preprocessing rule configuration set when the file is uploaded, grouped by file type (such as video frame sampling rules).

**video** `object`  |  Video preprocessing configuration

`preprocess_configs.video`

Preprocessing configuration for video files.

**fps** `number`  |  Frame sampling rate

`preprocess_configs.video.fps`

The frame sampling frame rate (frames per second) for video, used to set the number of video frames sampled per second during video preprocessing.

**model** `string`  |  Preprocessing model

`preprocess_configs.video.model`

Model identifier used for video preprocessing (optional).

**scope** `object`  |  Information about the scope to which the file belongs

The scope information of the file, used to identify the session context that the file belonged to when it was created.

**id** `string`  |  Scope ID

`scope.id`

The scope ID, which returns the corresponding session ID.

**type** `string`  |  Scope type

`scope.type`

The scope type, which is currently fixed to `session`.
