`POST https://ark.ap-southeast.bytepluses.com/api/compatible/v1/messages/count_tokens`

Count the number of input tokens in a Messages request. This can be used for request estimation, quota control, and cost calculation. Actual usage is subject to the real request result.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

* API Key authentication. Go to the [API Key Management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

---

**max_tokens** `integer`  |  Maximum number of output tokens.

**output_config** `object`  |  Output configuration.

**effort** `string`  |  Reasoning effort

`output_config.effort`

Limits the amount of reasoning work. Reducing the reasoning depth can increase speed and reduce token consumption.

* `none`: Turn off reasoning.

* `minimal`: Turns off reasoning and answers directly.

* `low`: Light reasoning, focused on fast responses.

* `medium`: Balanced mode, considering both speed and depth.

* `high`: Deep analysis for handling complex problems.

* `xhigh`: Higher level of reasoning.

* `max`: Maximum level of reasoning, suitable for highly difficult reasoning tasks.

> **Note**

> For models that support this parameter, default values, parameter compatibility mapping rules, and the relationship with the `thinking.type` parameter, see [Deep reasoning](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/deep-thinking).

**service_tier** `string` `Default default`  |  Inference mode

Controls the online inference mode used.

* `default`: Uses the [Online inference (standard)](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/online-inference-standard) mode.

* `flex`: Uses the [online inference (flex)](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/online-inference-flex) mode.

**stop_sequences** `string / string[]`  |  Stop sequences

When the model encounters the string specified by the `stop_sequences` parameter, it will stop generating further content, and the string itself will not be output.

* By default, up to `4` stop sequences are supported.

* DeepSeek V4 series models support up to `16` stop sequences.

* Kimi series (not available for BytePlus users) models support up to `5` stop sequences.

Example: `["hello", "weather"]`.

> [Deep reasoning models](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/model-list#32e9e053) do not support this parameter by default, except for DeepSeek V4 models mentioned above.

* `false`: The model returns the result all at once after the generation is complete.
