`GET https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks?page_num={page_num}&page_size={page_size}&filter.status={filter.status}&filter.task_ids={filter.task_ids}&filter.model={filter.model}` [Try](https://api.byteplus.com/api-explorer/?action=ListContentsGenerationsTasks&groupName=Video%20Generation%20API&serviceCode=ark&version=2024-01-01)

You can pass in filter parameters to return matching tasks.

> **Tip**

* > Video task IDs have a validity period, measured from the `created_at` timestamp. An ID automatically becomes invalid when this period expires.

   * > **Draft video task IDs:** IDs created at or after 10:00 on October 28, 2026 (UTC+8) are valid for 14 days. IDs created before this time remain valid for seven days. After a Draft video task ID expires, it cannot be used to generate a final video.

   * > **Other video task IDs:** Valid for seven days.

* > Video URLs are valid for 24 hours. Download or transfer generated videos before the URL expires.

* > An output URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

## Request parameters

### Query parameters

> **Tip**

> The following parameters are Query String Parameters, passed in the URL string.

**page_num** `integer / null` `Default value: 1`  |  Page number

Value range: [1, 500]

Page number of the returned results.

**page_size** `integer / null` `Default value: 20`  |  Results per page

Value range: [1, 500]

Number of results per page in the returned results.

**filter.status** `string / null` `Optional`  |  Task status filter

Filter tasks by status. Supported statuses and related information:

* `queued`: Task is queued.

* `running`: Task is running.

* `cancelled`: Task has been canceled. Canceled task records are automatically deleted after 24 hours. Only tasks in the `queued` state can be canceled.

* `succeeded`: Task succeeded.

* `failed`: Task failed.

* `expired`: Task timed out.

**filter.task_ids** `string[] / null` `Optional`  |  Task ID filter

Video generation task ID for exact search, supports batch search. Multiple task IDs are connected with `&`.

Example: `filter.task_ids=id1&filter.task_ids=id2`.

**filter.model** `string / null` `Optional`  |  Inference endpoint ID filter

Model ID or endpoint ID for exact search. Only one input is supported.

When the permission of your API key is **Custom**, you must manually enter the model ID or endpoint ID to query.

> **Note**

> A model resource generally corresponds to one preconfigured inference endpoint and multiple custom inference endpoints. Model ID is bound to the preconfigured inference endpoint. When a model ID is entered, video generation tasks initiated by calling this preconfigured inference endpoint will be returned.

**filter.service_tier** `string / null` `Default value: default`  |  Service tier filter

Service tier used for task processing.

* `default`: Online inference mode.

* `flex`: Offline inference mode.

## Response parameters

**items** `object[]`  |  Task list

List of found video generation tasks. The scope of returned video generation tasks is consistent with the permission scope of the API key you use, that is, video generation tasks initiated by inference endpoints that you have permission for under the corresponding project are returned.

**id** `string`  |  Task ID

`items.id`

Video generation task ID.

**model** `string`  |  Model name and version

`items.model`

Model name and version used for this task in the format of `model name-version`.

**status** `string`  |  Task status

`items.status`

Task status and related information:

* `queued`: Task is queued.

* `running`: Task is running.

* `cancelled`: Task has been canceled. Canceled task records are automatically deleted after 24 hours. Only tasks in the `queued` state can be canceled.

* `succeeded`: Task succeeded.

* `failed`: Task failed.

* `expired`: Task timed out.

**error** `object / null`  |  Error information

`items.error`

Error message. Returns `null` if the task succeeds; returns error data if the task fails. For details of error messages, see [Inference error codes](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/error-codes#common-error-codes-agent).

> **Note**

> For certain Dreamina Seedance 2.5 task types, an error is returned only after the queued task is consumed. For details, see [Error handling](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/seedance-2-5#2.5_error_handling).

**code** `string`  |  Error code

`items.error.code`

Error code.

**message** `string`  |  Error message

`items.error.message`

Error message.

**created_at** `integer`  |  Creation time

`items.created_at`

Unix timestamp (in seconds) of the task creation time.

**draft** `boolean`  |  Whether the video is a draft

`items.draft`

Whether the generated video is a Draft video. `true` indicates a Draft video, and `false` indicates a final video.

**Supported models:**

* `Dreamina Seedance 2.5`

* `Seedance 1.5 pro`

**updated_at** `integer`  |  Update time

`items.updated_at`

Unix timestamp (in seconds) of the last update time of the task's current status.

**content** `object`  |  Output content

`items.content`

This parameter is output when the video generation task is completed, including the download URL of the generated video.

**video_url** `string`  |  Video URL

`items.content.video_url`

URL of the generated video. It is valid for 24 hours.

A URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

> **tip**

> We recommend configuring [BytePlus TOS data subscription](https://docs.byteplus.com/en/docs/tos/Data_subscription) to automatically transfer model outputs to your own TOS bucket for long\-term backup or further processing.

**last_frame_url** `string`  |  Last\-frame image URL

`items.content.last_frame_url`

URL of the last frame image of the video. It is valid for 24 hours. Please save it to your own storage in time.

A last\-frame URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

Note: This parameter is returned when `"return_last_frame": true` is set when [creating a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api).

**seed** `integer`  |  Random seed

`items.seed`

Seed integer value used for this request.

**resolution** `string`  |  Resolution

`items.resolution`

Resolution of the generated video.

**ratio** `string`  |  Aspect ratio

`items.ratio`

Aspect ratio of the generated video.

**duration** `integer`  |  Video duration (seconds)

`items.duration`

Duration of the generated video, in seconds.

**Note**: Only one of **duration** and **frames** is returned. If **frames** was not specified when [creating a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api), **duration** is returned.

**frames** `integer`  |  Video frame count

`items.frames`

Frame count of the generated video.

**Note**: Only one of **duration** and **frames** is returned. If **frames** was specified when [creating a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api), **frames** is returned.

**framespersecond** `integer`  |  Video frame rate

`items.framespersecond`

Frame rate of the generated video.

**generate_audio** `boolean`  |  Whether to generate synchronized audio

`items.generate_audio`

Controls whether the generated video includes sound synchronized with the footage.

This parameter is returned for Dreamina Seedance 2.5, Dreamina Seedance 2.0 series, and Dreamina Seedance 1.5 pro.

* `true`: The video output by the model includes synchronized audio.

* `false`: The video output by the model is a silent video.

**output_formatnew** `string`  |  Output format

`items.output_format`

The actual container format of the generated video: `mp4` or `mov`. This parameter is returned for Dreamina Seedance 2.5.

**safety_identifier** `string`  |  End\-user identifier

`items.safety_identifier`

Unique identifier of the end user. If this parameter is set when [creating a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api), the API returns it unchanged.

**priority** `integer`  |  Execution priority

`items.priority`

The execution priority of the current task, consistent with the `priority` value set when the task was created. The value ranges from 0 to 9. A larger value indicates a higher priority.

**Supported models:**

* `Dreamina Seedance 2.5`

* `Dreamina Seedance 2.0 series`

**draft_task_id** `string`  |  Draft task ID

`items.draft_task_id`

Draft video task ID. This parameter is returned when a final video is generated based on a draft video.

**service_tier** `string`  |  Service tier

`items.service_tier`

Service tier actually used for task processing.

**execution_expires_after** `integer`  |  Task expiration threshold (seconds)

`items.execution_expires_after`

Task timeout threshold, in seconds.

**usage** `object`  |  Token usage

`items.usage`

Token usage of this request.

**completion_tokens** `integer`  |  Tokens consumed for video generation

`items.usage.completion_tokens`

Number of tokens consumed for the model to output the video, which can be used as the basis for billing reconciliation.

> **warning**

> Dreamina Seedance 2.0 series models have a minimum token usage. If the actual token usage is lower than the minimum, this field returns the minimum token usage and billing is based on that minimum.

**total_tokens** `integer`  |  Total tokens

`items.usage.total_tokens`

Total number of tokens consumed by this request. Video generation models do not count input tokens, so input tokens are 0, namely **total_tokens** = **completion_tokens**.

**total** `integer`  |  Total tasks

Number of tasks that meet the filter conditions.
