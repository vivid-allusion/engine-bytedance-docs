`GET https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks/{id}` [Try](https://api.byteplus.com/api-explorer/?action=GetContentsGenerationsTask&groupName=Video%20Generation%20API&serviceCode=ark&version=2024-01-01)

Retrieves the information of a video generation task.

> **tip**

* > Video task IDs have a validity period, measured from the `created_at` timestamp. An ID automatically becomes invalid when this period expires.

   * > **Draft video task IDs:** IDs created at or after 10:00 on October 28, 2026 (UTC+8) are valid for 14 days. IDs created before this time remain valid for seven days. After a Draft video task ID expires, it cannot be used to generate a final video.

   * > **Other video task IDs:** Valid for seven days.

* > Video URLs are valid for 24 hours. Download or transfer generated videos before the URL expires.

* > A video URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

## Request parameters

### Path parameters

**id** `string` `Required`  |  Task ID

The ID of the video generation task to query.

## Response parameters

**id** `string`  |  Task ID

The ID of the video generation task.

**model** `string`  |  Model name and version

The name and version of the model used by the task (`Model name-Version`)

**status** `string`  |  Task status

Task status and related information:

* `queued`: Task is queued.

* `running`: Task is running.

* `cancelled`: Task has been canceled. Canceled task records are automatically deleted after 24 hours. Only tasks in the `queued` state can be canceled.

* `succeeded`: Task succeeded.

* `failed`: Task failed.

* `expired`: Task timed out.

**content** `object`  |  Output content

The output after the video generation task is completed.

**last_frame_url** `string`  |  Last\-frame image URL

`content.last_frame_url`

URL of the last frame of the generated video. Valid for 24 hours. Be sure to save it in time.

A last\-frame URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

Note: If you set `"return_last_frame": true` in the [Create a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api) request, the parameter will be returned.

**video_url** `string`  |  Video URL

`content.video_url`

The URL of the output video. It is valid for 24 hours.

A URL generated by Dreamina Seedance 2.5 can be downloaded up to 100 times.

We recommend configuring [BytePlus TOS data subscription](https://docs.byteplus.com/en/docs/tos/Data_subscription) to automatically transfer model outputs to your own TOS bucket for long\-term backup or further processing.

**created_at** `integer`  |  Creation time

The time when the task was created. The value is a Unix timestamp in seconds.

**draft** `boolean`  |  Whether the video is a draft

Whether the generated video is a Draft video. `true` indicates a Draft video, and `false` indicates a final video.

**Supported models:**

* `Dreamina Seedance 2.5`

* `Seedance 1.5 pro`

**draft_task_id** `string`  |  Draft task ID

Draft video task ID. This parameter is returned when generating a final video based on a draft video.

**duration** `integer`  |  Video duration (seconds)

The length of the generated video in seconds.

**Note**: Only one of **duration** and **frames** is returned. If **frames** was not specified when the video generation task was created, **duration** is returned.

**error** `object / null`  |  Error information

The error information. If the task succeeds, `null` is returned. If the task fails, the error information is returned. For more information, refer to [Inference error codes](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/error-codes#common-error-codes-agent).

> **Note**

> For certain Dreamina Seedance 2.5 task types, an error is returned only after the queued task is consumed. For details, see [Error handling](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/seedance-2-5#2.5_error_handling).

**code** `string`  |  Error code

`error.code`

The error code.

**message** `string`  |  Error message

`error.message`

The error message.

**execution_expires_after** `integer`  |  Task expiration threshold (seconds)

The expiration threshold for the task, in seconds. If the task is not completed within this period, it is automatically terminated and marked as `expired`.

**frames** `integer`  |  Video frame count

Number of frames for the generated video.

**Note**: Only one of the **duration** and **frames** parameters will be returned. If **frames** is specified in the video generation request, **frames** will be returned.

**framespersecond** `integer`  |  Video frame rate

The frame rate of the generated video.

**generate_audio** `boolean`  |  Whether to generate synchronized audio

Whether the generated video includes audio synchronized with the visuals.

This parameter is supported by Dreamina Seedance 2.5, Dreamina Seedance 2.0 series, and Dreamina Seedance 1.5 pro.

* `true`: The model outputs a video with synchronized audio.

* `false`: The model outputs a silent video.

**output_formatnew** `string`  |  Output format

The actual output video format: `mp4` or `mov`. This parameter is supported by Dreamina Seedance 2.5.

**priority** `integer`  |  Execution priority

The execution priority of the current task, consistent with the `priority` value set when the task was created. The value ranges from 0 to 9. A larger value indicates a higher priority.

**Supported models:**

* `Dreamina Seedance 2.5`

* `Dreamina Seedance 2.0 series`

**ratio** `string`  |  Aspect ratio

The width\-to\-height ratio of the generated video.

**resolution** `string`  |  Resolution

The resolution of the generated video.

**safety_identifiernew** `string`  |  End\-user identifier

A unique identifier for the end user. If you set this parameter when [creating a video generation task](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/create-video-generation-task-api), the API returns this parameter unchanged.

**seed** `integer`  |  Random seed

The seed value (integer) used for this request.

**service_tier** `string`  |  Service tier

The service tier actually used to process the task.

**updated_at** `integer`  |  Update time

The time when the task was last updated. The value is a Unix timestamp in seconds.

**usage** `object`  |  Token usage

The token usage for the request.

**completion_tokens** `integer`  |  Tokens consumed for video generation

`usage.completion_tokens`

The number of tokens consumed for the video output by the model.

> **warning**

> Dreamina Seedance 2.0 series models have a minimum token usage. If the actual token usage is lower than the minimum, this field returns the minimum token usage and billing is based on that minimum.

**total_tokens** `integer`  |  Total tokens

`usage.total_tokens`

Total tokens for this request. For video models, input tokens are always 0, therefore **total_tokens = completion_tokens**.
