`POST https://ark.ap-southeast.bytepluses.com/api/v3/responses`

Create a response with the Responses API. This topic describes the input and output parameters of the API.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

* API Key authentication. Go to the [API Key Management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

---

## Request parameters

### Body parameters

**input** `string / object[]` `Required`  |  Input content

The input content that the model needs to process. It can be a text string, which is equivalent to a single text input with the `user` role, or a list of input elements, which supports multiple types such as messages, function calls, and reasoning.

Text input `string`

Text information input to the model. This is equivalent to text information input using the `user` role.

List of input elements `object[]`

Information elements input to the model, which can include different information types.

Input message `object`

Messages sent to the model, where roles indicate the priority level for following instructions. Instructions given by the `developer` or `system` role take precedence over instructions given by the `user` role. Messages from the `assistant` role are usually considered replies generated by the model in previous interactions.

**content** `string / object[]` `Required`  |  Message content

`input.content`

Text, image, video, or file input used to generate a reply. It can also contain previous assistant reply content.

Text input `string`

Text message content. Pass in a string directly.

Input content list `object[]`

A list of content elements. It can contain multimodal inputs such as text, images, videos, files, and audio.

Text input to the model `object`

Text content input to the model.

**text** `string` `Required`  |  Text only

`input.content.text`

Text content.

**type** `string` `Required`  |  Type

`input.content.type`

Content type identifier.

Value is fixed to `input_text`.

**translation_options** `object`  |  Translation options

`input.content.translation_options`

Text translation options. Specify the source language and target language to enable translation.

Image input to the model `object`

Image content input to the model. Supports passing in content through `file_id`, `image_url`, or a Base64 string.

**type** `string` `Required`  |  Type

`input.content.type`

Content type identifier.

Value is fixed to `input_image`.

**detail** `string`  |  Precision

`input.content.detail`

Image parsing precision, which controls the clarity and detail level used by the model to process images. Options: `auto`, `low`, `high`, `xhigh`.

> **Tip**

> For default values for different models and corresponding specific pixel ranges, see [Precision control of image understanding](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/image-understanding#bf4d9224).

**file_id** `string`  |  File ID

`input.content.file_id`

File ID.

* The file ID is the ID returned after you upload a file through the [Files API](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/upload-files-api).

* The file type corresponding to **file_id** must be consistent with **type**, and the file status must be **active**.

* The project that the **API key** belongs to must be the same as the project used to upload **file_id**.

**image_pixel_limit** `object` `Default null`  |  Pixel limit

`input.content.image_pixel_limit`

Pixel range of the image input to the model. If it is not within this range, the image will be scaled proportionally to fit this range.

> **Note**

> The image pixel value must fall in the range of `[196, 36000000]` px; otherwise, an error will be reported.

* > Priority: It has higher priority than `detail`. That is, when both `detail` and `image_pixel_limit` are configured, `image_pixel_limit` takes effect.

* > Default rule: If `image_pixel_limit` is not set, the `min_pixels` / `max_pixels` value corresponding to the value configured in `detail` will be used.

**max_pixels** `integer`  |  Maximum pixels

`input.content.image_pixel_limit.max_pixels`

Maximum pixel limit for uploaded images. If the image pixel count exceeds this value, it will be scaled down proportionally to below the value of `max_pixels`. If not set, the value will be the `max_pixels` value corresponding to the configured `detail` value.

**Max**: `9031680`

**min_pixels** `integer`  |  Minimum pixels

`input.content.image_pixel_limit.min_pixels`

Minimum pixel limit for uploaded images. If the image pixel count is lower than this value, it will be scaled up proportionally to above the value of the `min_pixels`. If not set, the value will be the `min_pixels` value corresponding to the configured `detail` value.

**Min**: `1764`

**image_url** `string`  |  Image URL

`input.content.image_url`

Image URL or Base64 string (format: `data:image/{format};base64,{encoding}`).
