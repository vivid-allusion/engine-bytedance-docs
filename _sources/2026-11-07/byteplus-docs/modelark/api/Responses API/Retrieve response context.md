`GET https://ark.ap-southeast.bytepluses.com/api/v3/responses/{responseId}/input_items`

Queries all input items for a response with pagination, and returns the input content passed when the response was created, as well as historical input items associated through `previous_response_id`.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

* API Key authentication. Go to the [API Key Management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

---

## Request parameters

### Path parameters

**responseId** `string` `Required`  |  Response ID

The response ID whose input items you want to query.

### Query parameters

> Passed as URL query string.

**after** `string`  |  Start cursor

Returns input items after this ID, used to page backward.

**before** `string`  |  End cursor

Returns input items before this ID, used to page forward.

**include** `string[]`  |  Additional returned parameters

Specifies the parameters to include additionally in the response. Some APIs return basic parameters by default. You can use `include` to have the server return more information.

Value is fixed to `message.input_image.image_url`.

> **Note**

> Valid values:

* > `message.input_image.image_url`: Includes the image URL in the input message. If the image is a URL, the URL is returned. If the image is Base64\-encoded, the Base64 string information is returned.

**limit** `integer` `Default 20`  |  Items per page

Controls the maximum number of items returned per request.

**Range**: `[1, 100]`

**order** `string` `Default desc`  |  Sort order

Controls the sort order of input items.

* `asc`: Sort in ascending order.

* `desc`: Sort in descending order.
