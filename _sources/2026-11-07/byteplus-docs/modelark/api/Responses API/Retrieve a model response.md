`GET https://ark.ap-southeast.bytepluses.com/api/v3/responses/{responseId}`

Retrieve response details by ID. If the response is completed, the API returns the complete response object; if the response is still being generated, the API returns an error code.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

* API Key authentication. Go to the [API Key Management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

---

## Request parameters

### Path parameters

**responseId** `string` `Required`  |  Response ID

The ID of the response to retrieve.

### Query parameters

> Passed as URL query string.

**include** `string[]`  |  Additional parameters

Specify the additional parameters to include in the response.
