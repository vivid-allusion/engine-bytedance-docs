Streaming events related to the output item structure, text deltas, and chain\-of\-thought reasoning.

## Text response

### response.content_part.added

> Triggered when a new content part is added.

**content_index** `integer`  |  Content block index

`response.content_part.added.content_index`

Index of the content part.

**item_id** `string`  |  Output item ID

`response.content_part.added.item_id`

ID of the output item to which the content part is added.

**output_index** `integer`  |  Output item index

`response.content_part.added.output_index`

Index of the output item to which the content part is added.

**part** `object`  |  Content part

`response.content_part.added.part`

The added content part.

Model response text `object`

The final answer text generated by the model.

**type** `string` `Default output_text`  |  Type

`response.content_part.added.part.type`

The content type discriminator parameter is used to distinguish union variants.

Value is fixed to `output_text`.

**annotations** `object[]`  |  Annotation list

`response.content_part.added.part.annotations`

List of annotation information attached to the text (such as citation sources).

**text** `string`  |  Text content

`response.content_part.added.part.text`

Text content generated by the model.

Chain\-of\-thought text generated by the model.

**type** `string`  |  Type

`response.content_part.added.part.type`

Content type identifier used to distinguish union variants.

Value is fixed to `reasoning_text`.

**annotations** `object[]`  |  Annotation list

`response.content_part.added.part.annotations`

List of annotation information attached to the chain\-of\-thought.

**text** `string`  |  Text content

`response.content_part.added.part.text`

The text content of the model's chain\-of\-thought.

**sequence_number** `integer`  |  Sequence number

`response.content_part.added.sequence_number`

Sequence number of the event.

**type** `string`  |  Event type

`response.content_part.added.type`

The event type, fixed as `response.content_part.added`.

## Output item skeleton

### response.output_item.added

> Indicates that a new output item has been added.

**item** `object`  |  Output item

`response.output_item.added.item`

Content of the newly added output item.

Message output `object`

Message output generated by the model, including text content.

**content** `object[]`  |  Output content

`response.output_item.added.item.content`

Output content list.

Model response text `object`

The final answer text generated by the model.

**type** `string` `Default output_text`  |  Type

`response.output_item.added.item.content.type`

The content type discriminator parameter is used to distinguish union variants.

Value is fixed to `output_text`.

**annotations** `object[]`  |  Annotation list

`response.output_item.added.item.content.annotations`

List of annotation information attached to the text (such as citation sources).

**text** `string`  |  Text content

`response.output_item.added.item.content.text`

Text content generated by the model.

Model chain\-of\-thought text `object`

Chain\-of\-thought text generated by the model.

**type** `string`  |  Type

`response.output_item.added.item.content.type`

Content type identifier used to distinguish union variants.

Value is fixed to `reasoning_text`.

**annotations** `object[]`  |  Annotation list

`response.output_item.added.item.content.annotations`

List of annotation information attached to the chain\-of\-thought.

**text** `string`  |  Text content

`response.output_item.added.item.content.text`

The text content of the model's chain\-of\-thought.

**id** `string`  |  Item ID

`response.output_item.added.item.id`

Unique identifier of the output item.

**role** `string`  |  Role

`response.output_item.added.item.role`

Role of the message sender.

Value is fixed to `assistant`.

**status** `string`  |  Status

`response.output_item.added.item.status`

The current status of the message output item.

* `completed`: The message generation is completed.

* `in_progress`: The message is being generated (in streaming scenarios).

* `incomplete`: The message was not fully generated (for example, because the `max_output_tokens` limit was reached).

* `failed`: The message generation failed.

**type** `string`  |  Type

`response.output_item.added.item.type`

Type identifier of the output item.

Value is fixed to `message`.

**partial** `boolean`  |  Incremental chunk

`response.output_item.added.item.partial`

Whether this is a streaming incremental chunk.

**phase** `string`  |  Message phase

`response.output_item.added.item.phase`

Indicates whether an assistant message is intermediate commentary or the final answer. When replaying historical assistant messages, we recommend preserving this parameter and passing it back unchanged. Options: `commentary`, `final_answer`.

Function call output `object`

A function call request initiated by the model.

**type** `string`  |  Type

`response.output_item.added.item.type`

Output item type identifier, used to distinguish OutputItem variants.

Value is fixed to `function_call`.

**arguments** `string`  |  Parameter

`response.output_item.added.item.arguments`

JSON string of the function parameters.

**call_id** `string`  |  Call ID

`response.output_item.added.item.call_id`

The unique ID of the function call, used to associate and match this `function_call` output with the subsequently returned `function_call_output`.

**id** `string`  |  Item ID

`response.output_item.added.item.id`

Unique identifier of the output item.

**name** `string`  |  Function name

`response.output_item.added.item.name`

Name of the called function.

**status** `string`  |  Status

`response.output_item.added.item.status`

The current status of the function call item.

* `completed`: The function call request has been fully generated.

* `in_progress`: The function call request is being generated (streaming scenario).

* `incomplete`: The function call request was not fully generated (for example, the `max_output_tokens` limit was reached).

* `failed`: Function call generation failed.

Output of the model's deep reasoning process.

**status** `string`  |  Status

`response.output_item.added.item.status`

The processing status of the reasoning item, used to determine whether the chain\-of\-thought has been generated. Options: `completed`, `failed`, `in_progress`, `incomplete`.

**summary** `object[]`  |  Reasoning summary

`response.output_item.added.item.summary`

List of inference summary content.

**type** `string`  |  Type

`response.output_item.added.item.summary.type`

Summary segment type identifier.

Value is fixed to `summary_text`.

**text** `string`  |  Summary text

`response.output_item.added.item.summary.text`

Chain\-of\-thought summary text content.

**type** `string`  |  Type

`response.output_item.added.item.type`

Output item type identifier, used to distinguish OutputItem variants.

Value is fixed to `reasoning`.

**content** `object[]`  |  Reasoning content

`response.output_item.added.item.content`

A list of content elements in the chain\-of\-thought reasoning process.

Model response text `object`

The final answer text generated by the model.

**type** `string` `Default output_text`  |  Type

`response.output_item.added.item.content.type`

Value is fixed to `output_text`.

**annotations** `object[]`  |  Annotation list

`response.output_item.added.item.content.annotations`

**text** `string`  |  Text content

`response.output_item.added.item.content.text`

Text content generated by the model.

Model chain\-of\-thought text `object`

**type** `string`  |  Type

`response.output_item.added.item.content.type`

Value is fixed to `reasoning_text`.

**annotations** `object[]`  |  Annotation list

`response.output_item.added.item.content.annotations`

List of annotation information attached to the chain\-of\-thought.

**text** `string`  |  Text content

`response.output_item.added.item.content.text`

The text content of the model's chain\-of\-thought.

**encrypted_content** `string`  |  Encrypted chain\-of\-thought

`response.output_item.added.item.encrypted_content`

Encrypted reasoning content. Original reasoning content that has been encrypted and compressed.

> **Tip**

> In streaming output scenarios, the encrypted reasoning content is delivered through related events such as `response.output_item.added`, `response.output_item.done`, and `response.completed`. You need to obtain it by filtering for events where the `encrypted_content` parameter is not empty.

**Supported models**:

* ``seed\-2\-0\-lite\-260228`and later versions`

**id** `string`  |  Item ID

`response.output_item.added.item.id`

Unique identifier of the output item.

MCP tool call `object`

`response.output_item.added.item.id`

**output** `string`  |  Returned result
