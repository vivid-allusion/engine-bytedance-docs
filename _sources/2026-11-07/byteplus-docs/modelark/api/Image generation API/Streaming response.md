When you set `stream: true` in a request, the image generation API pushes the generation result of each image in real time through Server\-Sent Events (SSE). This section describes the types of events that the server pushes.

> **tip**

> For sample code and responses, see the [Streaming output](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/image-generation-tutorial#e5bef0d7) tutorial.

## error

> Top\-level error event schema, returned when the request fails as a whole (such as a missing required parameter or authentication failure).

**error** `object`  |  Error information

`error.error`

The error object for this request, including an error code and readable message.

**code** `string`  |  Error code

`error.error.code`

The error code. For details, see [Error codes](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/error-codes).

**message** `string`  |  Error message

`error.error.message`

The error message used for troubleshooting.

error response example

```Plain Text
"error": {
  "code": "BadRequest",
  "message": "The request failed because it is missing one or multiple required parameters. Request ID: {id}"
}
```

## image_generation.completed

> Streaming response completion event schema, carrying summary information for the request.

**created** `integer`  |  Event time

`image_generation.completed.created`

The Unix timestamp in seconds when this event was created.

**model** `string`  |  Model ID

`image_generation.completed.model`

The model ID used for this request, in the format `<model_name>-<version>`.

**type** `string`  |  Event type

`image_generation.completed.type`

Event type.

Value is fixed to `image_generation.completed`.

**usage** `object`  |  Usage information

`image_generation.completed.usage`

Usage information for this request, including the number of generated images and consumed tokens.

**generated_images** `integer`  |  Successfully generated images

`image_generation.completed.usage.generated_images`

The number of images successfully generated by the model, excluding failed images. Billing is based only on successfully generated images.

**input_imagesnew** `integer`  |  Input images

`image_generation.completed.usage.input_images`

The number of images input to the model.

**Supported models**:

* `Seedream 5.0 pro`

* `Seedream 5.0 flash`

**output_tokens** `integer`  |  Output tokens

`image_generation.completed.usage.output_tokens`

The number of tokens consumed for images generated by the model. The value is calculated by rounding `sum(image width × image height) / 256` to an integer.

**total_tokens** `integer`  |  Total tokens

`image_generation.completed.usage.total_tokens`

The total number of tokens consumed by this request. Input tokens are not currently calculated, so this value is the same as `output_tokens`.

image_generation.completed response example

```Plain Text
{
  "type": "image_generation.completed",
  "model": "seedream-5-0-260128",
  "created": 1589478378,
  "usage": {
    "generated_images": 2,
    "output_tokens": 16280,
    "total_tokens": 16280
  }
}
```

## image_generation.partial_failed

> Schema for the streaming event emitted when a single image fails to generate.

**created** `integer`  |  Event time

`image_generation.partial_failed.created`

The Unix timestamp in seconds when this event was created.

**model** `string`  |  Model ID

`image_generation.partial_failed.model`

The model ID used for this request, in the format `<model_name>-<version>`.

**type** `string`  |  Event type

`image_generation.partial_failed.type`

Event type.

Value is fixed to `image_generation.partial_failed`.

**error** `object`  |  Error information

`image_generation.partial_failed.error`

The specific error information for this image generation failure.

**code** `string`  |  Error code

`image_generation.partial_failed.error.code`

The error code. For details, see [Error codes](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/error-codes).

**message** `string`  |  Error message

`image_generation.partial_failed.error.message`

The error message used for troubleshooting.

**image_index** `integer`  |  Image index

`image_generation.partial_failed.image_index`

The position of the failed image in the image group. The index starts from `0`.

image_generation.partial_failed response example

```Plain Text
{
  "type": "image_generation.partial_failed",
  "model": "seedream-5-0-260128",
  "created": 1589478378,
  "image_index": 2,
  "error": {
    "code": "OutputImageSensitiveContentDetected",
    "message": "The request failed because the output image may contain sensitive information."
  }
}
```

## image_generation.partial_succeeded

> Schema for the streaming event emitted when a single image is generated successfully.

**created** `integer`  |  Event time

`image_generation.partial_succeeded.created`

The Unix timestamp in seconds when this event was created.

**model** `string`  |  Model ID

`image_generation.partial_succeeded.model`

The model ID used for this request, in the format `<model_name>-<version>`.

**type** `string`  |  Event type

`image_generation.partial_succeeded.type`

Event type.

Value is fixed to `image_generation.partial_succeeded`.

**b64_json** `string`  |  Image Base64 data

`image_generation.partial_succeeded.b64_json`

The Base64\-encoded string of this image. This field is returned only when the request parameter `response_format=b64_json` is set.

**image_index** `integer`  |  Image index

`image_generation.partial_succeeded.image_index`

The position of the image corresponding to the current event in the image group. The index starts from `0`.

**size** `string`  |  Image size

`image_generation.partial_succeeded.size`

The actual generated image size, in the format `<width>x<height>`, such as `2048x2048`.

**url** `string`  |  Image URL

`image_generation.partial_succeeded.url`

The download URL of this image. This field is returned only when the request parameter `response_format=url` is set. The URL is valid for **24 hours** after generation. Download or persist the image promptly.

image_generation.partial_succeeded response example

```Plain Text
{
  "type": "image_generation.partial_succeeded",
  "model": "seedream-5-0-260128",
  "created": 1589478378,
  "image_index": 0,
  "url": "https://...",
  "size": "2048x2048"
}
```
