`GET https://ark.ap-southeast.bytepluses.com/api/v3/memory_stores/{memory_store_id}/memories/{memory_id}`

Query the complete information of a single memory by ID, including the `content` body.


* Use the list memories API when browsing paths and concise metadata.

* Use this API when retrieving the full content of a memory, and pass the full memory ID in the same memory store.


A memory store and memory entry must have been created before you call this API.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">Tip</div>


<div data-tips="true" data-tips-type="tip">If the memory store does not exist or is inaccessible, 404 <code>InvalidMemoryStore.NotFound</code> is returned; if the memory does not exist, 404 <code>ResourceNotFound</code> is returned.</div>


<span id="authentication"></span>
## Authentication

This API supports the following authentication methods. For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).


* API Key authentication. Go to the [API Key management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

<span id="request-parameters"></span>
## Request parameters

<span id="path-parameters"></span>
### Path parameters


**memory_id** `string` `Required`  |  Memory ID

Used to specify the memory to query. It starts with `mem-`. Pass the full ID returned by the create, list, or update API. Do not concatenate it yourself.



**memory_store_id** `string` `Required`  |  Memory store ID

Used to specify the memory store to which the memory belongs. It starts with `memstore-`. Pass the full ID returned by the create or list API. Do not concatenate it yourself.


&nbsp;

<span id="response-parameters"></span>
## Response parameters


**content** `string`  |  Memory content

The memory content, as UTF\-8 text. This API returns `content`; you can use it together with `content_sha256` and `content_size_bytes` to verify integrity.



**content_sha256** `string`  |  Content digest

The SHA\-256 digest of the memory content, represented as a lowercase hexadecimal string. It can be used to verify content integrity.



**content_size_bytes** `integer`  |  Content size in bytes

The number of bytes in the memory content after UTF\-8 encoding.



**created_at** `string`  |  Creation time

The time when the memory was created, in RFC 3339 UTC format.



**created_by** `object`  |  Creator

Information about the operator who created the memory.


**type** `string`  |  Operator type

`created_by.type`

Operator type.`user_actor` indicates that the memory was written with a user identity, and `session_actor` indicates that it was written by an agent in a session.



**session_id** `string`  |  Session ID

`created_by.session_id`

The ID of the session that wrote this memory. Returned only when `type` is `session_actor`.



**user_id** `string`  |  User ID

`created_by.user_id`

The ID of the user who wrote this memory. Returned only when `type` is `user_actor`.




**id** `string`  |  Memory ID

The memory ID generated by the server, starting with `mem-`. Pass it as the `memory_id` path parameter when subsequently querying, updating, or deleting the memory.



**memory_store_id** `string`  |  Memory store ID

The ID of the memory store to which this memory belongs.



**memory_version_id** `string`  |  Version ID

The current version identifier of the memory entry. This value changes after the content or path is successfully updated.



**path** `string`  |  Memory path

The file path of the memory in the memory store.



**type** `string`  |  Object type

Object type. Fixed to `memory`.



**updated_at** `string`  |  Update time

The time when the memory was last updated, in RFC 3339 UTC format.
