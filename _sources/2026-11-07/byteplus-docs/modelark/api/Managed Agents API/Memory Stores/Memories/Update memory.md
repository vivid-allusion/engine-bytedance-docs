`POST https://ark.ap-southeast.bytepluses.com/api/v3/memory_stores/{memory_store_id}/memories/{memory_id}`

Update the memory content, path, or both based on the provided parameters; parameters that are not passed remain unchanged. After `path` is updated, the response returns a new memory ID, and the old ID becomes invalid immediately. Continuing to use the old ID to query, update, or delete returns 404 `ResourceNotFound`; subsequent requests must use the new ID in the response.

> **Tip**

* > If concurrent modifications cause a conflict, query the latest memory again and then retry.

* > The update response does not return the memory content (`content`). To confirm the updated content, call the query memory details API.

* > If only the same `path` as the current value is passed and `content` is not passed, no actual update is made, and the ID, version identifier, and update time remain unchanged.

* > **Common failure causes include**: the memory store or memory does not exist, the path or content is invalid, the target path already exists, the content exceeds 100 KiB, and concurrent modification conflicts.

## Authentication

This API supports the following authentication method(s). For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).

## Request parameters

### Path parameters

**memory_id** `string` `Required`  |  Memory ID

Used to specify the memory to update. It starts with `mem-`. Pass the full ID returned by the create, list, or update API. Do not concatenate it yourself.

**memory_store_id** `string` `Required`  |  Memory store ID

Used to specify the memory store to which the memory belongs. It starts with `memstore-`. Pass the full ID returned by the create or query memory store API. Do not concatenate it yourself.

### Body parameters

**content** `string`  |  Memory content

Used to replace the existing content of the memory. If omitted, the existing content remains unchanged.

> **Note**

> Memory content must be valid UTF\-8 text, and the content must not exceed 102400 bytes (100 KiB). Provide at least one of `content` and `path`.

**path** `string`  |  Memory path

The file path used to rename the memory. If omitted, the existing path remains unchanged.

> **Note**

> The path must start with `/` and end with `.md` or `.txt`. It must not exceed 1024 bytes after UTF\-8 encoding, and must not contain control characters, `%`, `;`, or `?`. Path segments must not be empty, `.`, or `..`. Provide at least one of `content` and `path`.

## Response parameters

**content_sha256** `string`  |  Content digest

The SHA\-256 digest of the memory content, represented as a lowercase hexadecimal string. It can be used to verify content integrity.

**content_size_bytes** `integer`  |  Content bytes

The number of bytes in the memory content after UTF\-8 encoding.

**created_at** `string`  |  Creation time

The time when the memory was created, in RFC 3339 UTC format.

**created_by** `object`  |  Creator

Information about the operator who created the memory.

**type** `string`  |  Operator type

`created_by.type`

Operator type.`user_actor` indicates that the memory was written with a user identity, and `session_actor` indicates that it was written by an agent in a session.

**session_id** `string`  |  Session ID

`created_by.session_id`

The ID of the session that wrote this memory. Returned only when `type` is `session_actor`.

**user_id** `string`  |  User ID

`created_by.user_id`

The ID of the user who wrote this memory. Returned only when `type` is `user_actor`.

**id** `string`  |  Memory ID

The memory ID generated by the server, starting with `mem-`. Pass it as the `memory_id` path parameter when subsequently querying, updating, or deleting the memory.

**memory_store_id** `string`  |  Memory store ID

The ID of the memory store to which this memory belongs.

**memory_version_id** `string`  |  Version ID

The current version identifier of the memory entry. This value changes after the content or path is successfully updated.

**path** `string`  |  Memory path

The file path of the memory in the memory store.

**type** `string`  |  Object type

Object type. Fixed to `memory`.

**updated_at** `string`  |  Update time

The time when the memory was last updated, in RFC 3339 UTC format.
