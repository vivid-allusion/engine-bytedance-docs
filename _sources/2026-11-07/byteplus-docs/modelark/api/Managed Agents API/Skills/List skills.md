`GET https://ark.ap-southeast.bytepluses.com/api/v3/skills`

Queries the list of preset skills or custom skills on ModelArk.

<span id="authentication"></span>
## Authentication

This API supports the following authentication methods. For details, see [Base URL and authentication](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/base-url-and-authentication).


* API Key authentication. Go to the [API Key management](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey) page. Obtain a long\-lived API key.

<span id="request-parameters"></span>
## Request parameters

<span id="query-parameters"></span>
### Query parameters

> Passed as URL query string.



**limit** `integer` `Default 20`  |  Items per page

Sets the maximum number of records returned on a single page.

**Range**: `[1, 100]`



**name** `string`  |  Skill name

Filters skills by the skill name in `SKILL.md`.



**page** `string`  |  Next page identifier

Omit this parameter for the first request. For subsequent requests, pass in the `next_page` value from the previous response as is.

This value is generated by the server and is not a page number. Do not parse, generate, or modify this value.



**source** `string`  |  Source of the skill

Filters skills by skill source:


* `custom`: Returns custom skills from the current account.

* `ark`: Returns preset skills on ModelArk.


If omitted, the server returns both types of skills. This endpoint does not support querying Skill Hub skills. If `skill_hub` is passed in, a parameter error is returned.


&nbsp;

<span id="response-parameters"></span>
## Response parameters


**data** `object[]`  |  Skill list

Contains the list of skills returned on the current page.


**created_at** `integer`  |  Creation time

`data.created_at`

The skill creation time, as a Unix timestamp in seconds.



**display_title** `string`  |  Display name

`data.display_title`

Display name of the skill. If it is not configured, the server returns the `name` from `SKILL.md`.



**id** `string`  |  Skill ID

`data.id`

The unique identifier of the skill. The IDs of both custom skills and ModelArk platform preset skills returned by the server start with `skill-`.



**latest_version** `string`  |  Latest version

`data.latest_version`

The latest version number of the skill.



**object** `string`  |  Resource type.

`data.object`

Used to identify the resource type of the response object, fixed as `skill`.



**protection_enabled** `boolean`  |  Content protection switch

`data.protection_enabled`

Indicates whether content protection is enabled for the skill.`true` indicates that it is enabled, and `false` indicates that it is not enabled.



**source** `string`  |  Source of the skill

`data.source`

This parameter indicates the skill source:


* `custom` indicates a custom skill uploaded or imported by the current account.

* `ark` indicates a preset skill on ModelArk.



**updated_at** `integer`  |  Skill update time.

`data.updated_at`

The last update time of the skill, as a Unix timestamp in seconds.



**description** `string`  |  Skill description

`data.description`

The skill description parsed by the ModelArk platform from `SKILL.md`.



**name** `string`  |  Skill name

`data.name`

The skill name defined in `SKILL.md`.




**has_more** `boolean`  |  Has next page

Indicates whether there is another page of data:


* `true`: More data is available, and you can continue paginated queries.

* `false`: The last page has been returned.



**next_page** `string`  |  Next page identifier

The next page identifier is generated by the server. When `has_more` is `true`, pass this value as is to `page` in the next request; when there is no next page, this parameter is not returned.
