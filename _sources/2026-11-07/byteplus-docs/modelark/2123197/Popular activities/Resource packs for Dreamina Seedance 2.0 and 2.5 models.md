This topic introduces the purchase rules, deduction rules, and considerations for resource packs for Dreamina Seedance 2.5 (hereafter referred to as Seedance 2.5) and Dreamina Seedance 2.0 series models (hereafter referred to as Seedance 2.0). A resource pack is a **prepaid** resource that offsets token consumption generated by online inference requests. You can purchase one or more resource packs on the [Seedance resource pack purchase](https://console.byteplus.com/common-buy/ModelArk%7C%7Cd7d6aanpgiftptb9ajcg) page.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Note</div>



1. <div data-tips="true" data-tips-type="warning">Resource packs are non\-refundable. Check your required quota before purchasing.</div>


2. <div data-tips="true" data-tips-type="warning">If all resource packs expire or their quotas are fully used, any excess consumption will automatically be billed on a pay\-as\-you\-go basis. Estimate the required resource pack quota before purchase.</div>


3. <div data-tips="true" data-tips-type="warning">To avoid unexpected interruptions during API calls, the 1\-million\-token resource pack has a minimum purchase quantity. To obtain a quota of 7 million tokens, purchase seven 1\-million\-token resource packs. For a higher quota, purchase additional 1\-million\-token, 10\-million\-token, or 100\-million\-token resource packs.</div>

# Token deduction rules

Resource packs directly offset model token consumption. Because Seedance 2.5 and Seedance 2.0 have different unit prices depending on whether the input includes video, the corresponding deduction ratios also differ.

For video input, 1 resource pack token is deducted for every token consumed at a 1:1 ratio. For non\-video input, more than 1 resource pack token is deducted for every token consumed according to the specified ratio because the unit price is higher.


|Model |Input type |Video resolution |Token unit price (USD/K tokens) |Deduction ratio |Deduction rule |
|---|---|---|---|---|---|

# Relationship between model activation, usage, and resource pack purchase

<span id="activation-of-seedance-2-5-and-seedance-2-0-models"></span>
## Activation of Seedance 2.5 and Seedance 2.0 models

Seedance 2.5 and Seedance 2.0 models can be activated if any of the following conditions are met:


1. You have purchased a Seedance 2.0 resource pack and currently have remaining quota.

2. You have purchased a Seedance 2.0 fast resource pack and currently have remaining quota.

3. You have purchased a Seedance 2.0 mini resource pack and currently have remaining quota.

4. You have purchased a Seedance 2.5 resource pack and currently have remaining quota.


After activation, pay\-as\-you\-go usage is enabled for these models. To purchase a resource pack, go to the [Seedance resource pack purchase](https://console.byteplus.com/common-buy/ModelArk%7C%7Cd7d6aanpgiftptb9ajcg) page.

<span id="usage-of-seedance-2-5-and-seedance-2-0-models"></span>
## Usage of Seedance 2.5 and Seedance 2.0 models

After activation, each call is billed according to the model used. Each resource pack can offset consumption only for its corresponding model:


|Model |Available billing sources |
|---|---|
|Seedance 2.5 |Seedance 2.5 resource pack remaining quota / BytePlus account balance |
|Seedance 2.0 |Seedance 2.0 resource pack remaining quota / BytePlus account balance |
|Seedance 2.0 fast |Seedance 2.0 fast resource pack remaining quota / BytePlus account balance |
|Seedance 2.0 mini |Seedance 2.0 mini resource pack remaining quota / BytePlus account balance |

# Instructions


1. **Activation time**: The resource pack is activated immediately after purchase. No manual activation or binding is required. The validity period is 90 days. After it expires, the remaining tokens in the resource pack will be automatically invalidated.

2. **Purchase rules**: Resource packs cannot be purchased with vouchers. The price displayed on the page is for reference only. Please refer to the final transaction price at the time of settlement.

3. **Cancellation and refunds**: Resource packs cannot be canceled or refunded after purchase. Evaluate your business requirements carefully and select an appropriate specification before payment.

4. **Deduction priority**: Resource packs \> Pay\-as\-you\-go by token. If you have multiple resource packs of the same type, the resource pack that expires first is used first. If they expire at the same time, the resource pack purchased first is used first.

5. **Exhaustion policy**: If all resource packs expire or their quotas are fully used, any excess consumption will automatically be billed on a pay\-as\-you\-go basis.

# Usage guide

<span id="8013cd21"></span>
## 1. Activate the models

After purchasing a resource pack, follow these steps:


* **Activate the models**: Go to the [Model activation](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement) page to activate the corresponding models.

* **Make API calls**: After [obtaining an API key](https://ai.byteplus.com/ark/region:ap-southeast-1/apiKey), you can initiate online inference requests.

* **Deduction logic**: The purchased resource pack **automatically offsets token consumption from online inference requests made to the corresponding model**.


<span id="127b6922"></span>
## 2. Management and monitoring

You can track resource pack usage in real time:


* **Path**: Go to [Billing center > Resource package](https://console.byteplus.com/finance/resource-package).

* **Function**: View the status and remaining quota of each resource pack instance.
