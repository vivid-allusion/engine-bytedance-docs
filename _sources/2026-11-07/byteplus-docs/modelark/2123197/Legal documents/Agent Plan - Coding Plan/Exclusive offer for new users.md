## Rules


1. Purchase eligibility: Only new users who have never subscribed to any ModelArk Coding Plan package are eligible to participate. Each user can enjoy the discount only once.

2. Purchase limit: A single account can subscribe for up to 6 consecutive months.

3. Package selection: The same account can select only one package type (Lite or Pro). Please select the appropriate package according to your usage needs.

4. Activation rules: The package subscription will take effect immediately after purchase. Only one package can be active at a time. After the current package expires, any subsequent package (if available) will automatically take effect.

5. Renewal rules:

   * Automatic renewal: If you select Automatic renewal when placing the order, the subscription will be renewed monthly by default. The next month's package fee will be automatically deducted upon expiration.

   * Manual renewal: If you do not select Automatic renewal when placing the order, you can renew from [activation management](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement?LLM=%7B%7D&advancedActiveKey=subscribe).

6. Upgrade rules: The validity period remains unchanged. Pay the price difference to upgrade the package. You can upgrade from [activation management](https://ai.byteplus.com/ark/region:ap-southeast-1/openManagement?LLM=%7B%7D&advancedActiveKey=subscribe).

   **Note**: Downgrades are not supported.

7. Cancellation policy: Refunds are not supported after purchasing a plan. You may use the service within the current billing cycle. It is recommended to select a suitable plan and billing cycle based on your usage needs.
