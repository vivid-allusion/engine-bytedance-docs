**Release date: September 7, 2026**

The official Ark SDK provides unified dependencies and consistent model invocation interfaces for Python, Go, and Java. New integrations and migration projects should use the latest stable release to receive current API coverage and fixes.

Legacy SDKs will gradually stop receiving updates. The specific timeline will be announced separately.

You do not need to remove the legacy SDK in one step. Prefer the new SDK, and keep using the legacy SDK or the corresponding REST API when the current release does not yet cover a required API. Migrate those calls after support becomes available.

For installation commands, dependency replacement, code updates, the migration checklist, and compatibility guidance, see [Migrate to the official Ark SDK](https://ai.byteplus.com/ark/region:ap-southeast-1/docs/ModelArk/2663772).
