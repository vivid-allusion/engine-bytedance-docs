On the Monitoring page, you can clearly view the total number of tokens called, input, and output for all accounts.

In addition, you can count the usage of these dimensions separately according to the dimensions of playground, online reasoning, batch reasoning, etc.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c63b7ba2262a4c18b176f66f5ebf58fc~tplv-goo7wpa0wc-image.image) </span>

Currently, the following dimensions are supported for viewing usage:


* Total number of tokens called, total number of input tokens, and total number of output tokens.

* View usage by dimension of preset inference endpoint (Model ID)/custom inference endpoint.

* Endpoint details: All, model input, model output dimensions.

* Endpoint security monitoring: security protection capabilities, security risk events, security risk trends, and risky endpoints

* Plug\-call volume: the number of calls of all and specific plugins.
