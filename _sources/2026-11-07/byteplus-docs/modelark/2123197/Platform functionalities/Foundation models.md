The [Foundation models](https://ai.byteplus.com/ark/region:ap-southeast-1/model?groupType=ModelGroups&vendor=Bytedance&view=DEFAULT_VIEW) page brings together mainstream large models, allowing users to freely view and experience the models' inference capabilities in language, vision, and other areas.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f62040f445048a1b1b0c7116ab4ef66~tplv-goo7wpa0wc-image.image) </span>

The Foundation models page provides two views: **Default** and **Card**, which can be switched in the upper right corner of the interface.


* Default view: Quickly view the currently featured models; view models by model type, whether it's an open source model, etc.

* Card view: Use the filters to search for models by provider, inference method, supported features, context length, and more dimensions.


<span id="model-card"></span>
# Model profile page

Each model has a dedicated model card, which displays information such as the name, description, provider, whether it is available to try online, scenarios, etc.

You can also click **Access API** to quickly test the API calls, or go to the **Playground** to directly try the model's capabilities.

<span id="a48f9890"></span>
# Model comparison

The model comparison page supports comparing models by model performance, model capabilities, model pricing, token limits, task type, and other dimensions.
