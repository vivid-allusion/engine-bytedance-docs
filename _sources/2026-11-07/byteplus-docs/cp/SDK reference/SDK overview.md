This document describes the SDK language versions provided by Code Pipeline (CP), and lists the addresses for obtaining the latest version of the SDK.

<span id="GXiKOX2m"></span>
## SDK introduction

The Code Pipeline SDK encapsulates all Code Pipeline API interfaces ([API overview](https://docs.byteplus.com/en/docs/cp/API_list)). It uses the access key (AccessKey) to identify the caller, provides automatic signing and other features, and allows you to easily create and manage resources through the API.
