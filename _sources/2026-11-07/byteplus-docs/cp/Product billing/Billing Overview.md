## Billing description

This article mainly introduces the billing rules for the Code Pipeline basic edition.

<span id=".6K6h6LS557uE5oiQ"></span>
## Billing Components

The billing model for Code Pipeline is Prepaid and Postpaid, with the specific components as follows:


|Billing Item |Descriptions |Billing method |
|---|---|---|
|[Code Pipeline basic edition](https://docs.byteplus.com/en/docs/cp/Code_Pipeline_Basic_Edition) |Code Pipeline Basic Edition is a prepaid subscription instance. When a new user activates the service, a default order for one\-year\-free Code Pipeline Basic Edition will be placed. You can use the Code Pipeline Product only after your order is successful. The Code Pipeline Product includes pipeline and application delivery features. |Subscription |
|[Pipeline execution time](https://docs.byteplus.com/en/docs/cp/Pipeline_run_duration) |The pipeline provides continuous integration and continuous deployment services and charges based on execution time. The pipeline execution time is charged as a postpaid, pay\-as\-you\-go instance. When new users activate the service, this instance is provisioned by default. Resource consumption tasks in the pipeline that use the public resource pool can only run normally after the order is placed successfully, and billing is based on the specifications of the computing resources and the time of execution. |Pay\-as\-you\-go Billing |
