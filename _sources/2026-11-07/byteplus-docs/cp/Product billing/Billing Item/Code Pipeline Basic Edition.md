This article introduces the detailed billing rules for the Code Pipeline basic edition.

<span id=".6K6i6LSt5pa55byP"></span>
## **Ordering methods**

Log in to the Code Pipeline console and request activation of this service. When you apply to activate the service, the system will automatically create a prepaid order with a total of zero yuan for you. You must complete the payment before you can begin using the service.

<span id=".6K6h6LS55LuL57uN"></span>
## **Billing overview**

Code Pipeline Basic Edition is a subscription\-based instance that currently supports prepaid annual subscriptions, with each purchase period being 12 months.


|Billing Item |Billing Methods |Unit Price |
|---|---|---|
|Code Pipeline |Subscription |0 USD per year |


<span id=".57ut6LS56K-05piO"></span>
## **Renewal Description**

Code Pipeline Basic Edition provides the automatic renewal feature. Seven days before expiration, the system will automatically deduct the renewal fee from your balance. The duration of each renewal is 12 months.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">If your account is in arrears, automatic renewal will fail. After automatic renewal fails, the Code Pipeline console will remind you to renew manually. Please follow the instructions to go to <strong>Billing Center \> Renewal Management</strong> to complete the renewal.</div>


<span id=".6YCA6K6i6K-05piO"></span>
## **Unsubscription instructions**

Code Pipeline does not currently support unsubscription.

<span id=".5Yiw5pyf5YWz5YGcLeWbnuaUtg=="></span>
## **Expiration shutdown and reclamation**

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">Once Code Pipeline Basic Edition resources are reclaimed, all associated configuration and data will be permanently deleted and cannot be restored. Please renew your subscription promptly to avoid any impact on your service.</div>



* **Shutdown at expiration**

   If automatic renewal fails and you do not renew in time, Code Pipeline Basic Edition will be shut down at noon on the day after expiration. At that time, you will no longer be able to use this service.

* **Maturity collections**

   After the subscription expires, Code Pipeline provides a 30\-day resource reclamation grace period. All service configurations and data are retained during the buffer period.

   * If you renew your subscription within 30 days of expiration, you can continue to use this service.

   * If you have not successfully renewed by 30 days after expiration, the resources of Code Pipeline Basic Edition will be reclaimed. After the resource is reclaimed, all historical data will be lost. To use Code Pipeline again, you must reactivate this service.
