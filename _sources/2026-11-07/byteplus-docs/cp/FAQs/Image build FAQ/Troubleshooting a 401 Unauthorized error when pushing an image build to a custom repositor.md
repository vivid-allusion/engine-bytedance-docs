Please check whether the username and password for the image repository to be pushed are entered correctly.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When pushing to the BytePlus image repository, please ensure that the username is in the correct format: <code>[account name]@[account id]</code>. It is recommended that you log in directly to the image repository console, go to the Overview page of the relevant repository instance, and copy the instance's login username to avoid entering incorrect information.</div>
