The number of image tags stored in the target repository has exceeded the maximum limit. It is recommended that you delete unnecessary image tags from the repository or push to a different repository. For methods to clean up images, see [Managing version retention rules](https://docs.byteplus.com/en/docs/cr/create-a-tag-retention-rule).
