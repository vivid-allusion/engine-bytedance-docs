This article explains how to create a Token on GitHub and obtain that Token.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to GitHub, select **Settings \> Developer settings \> Personal access tokens**, then click **Generate new token** in the right section to create a new token.

2. Enter the required parameters to complete the creation of the Token.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For the token's permission scope, you must check <strong>repo</strong>; select other permissions as needed.   </div>
   

3. After successful creation, copy this Token to create the code source.
