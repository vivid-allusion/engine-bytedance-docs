This article explains how to create and obtain a token in GitLab.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the GitLab code repository, select **Edit profile \> Access Tokens**, and in the **Add a personal access token** area on the right, add a new token.

2. Enter the required parameters to complete token creation.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You must select <strong>read_api</strong> for the token's permission scope; select other permissions as needed.   </div>
   

3. Once created, copy the Token for use in creating the code source.
