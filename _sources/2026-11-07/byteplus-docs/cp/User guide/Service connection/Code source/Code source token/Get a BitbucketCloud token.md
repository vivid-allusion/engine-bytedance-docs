This article explains how to create a token in BitbucketCloud and obtain it.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to your Bitbucket Cloud repository, and select **Repository settings \> Access tokens**.

2. On the Access tokens page, click **Create Repository Access Token**.

3. Fill in the parameters as required to create the Token.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Ensure that the token has <strong>Read</strong> permission under Pull requests and <strong>Read and write</strong> permission under Webhooks. Other permissions can be selected as needed.</div>



4. After successful creation, copy the Token. You will need it to create a code source.
