The Code Pipeline Overview provides a product introduction and usage guide for the Code Pipeline service, aggregates and displays the current user's related tasks, and offers a unified perspective to help users manage Code Pipeline\-related work.

Log in to the [Code Pipeline console](https://console.byteplus.com/cp), select **Overview** from the navigation bar on the left to enter the Overview. You can view the resource overview, my tasks, pipeline usage process, common features, help documentation, and other content.


|**Display items** |**Descriptions** |
|---|---|
|Resource overview |Displays the number of all resources under the current BytePlus account (root user), including workspaces, pipelines, and applications, to help users understand the resource status of their account. |
|My task |Aggregates and displays all pipeline approval\-type tasks for the current user, currently including **Manual checkpoint** and **Selectors** tasks.<br><br><br>* **Pending my approval**: Displays all pipeline approval tasks pending for the current user, and provides quick action buttons to facilitate approval or selection.<br><br>* **Approved by me**: Displays all pipeline approval tasks that have been approved by the current user, including the pipeline name, task name, associated run records, and other details, to facilitate audit and traceability. |
|Pipeline usage procedure |Introduce the basic usage process and main steps of the pipeline, and provide a getting started tutorial to help new users get started quickly. |
|Common features |Provide quick links to the cost center and introduction to product capabilities. |
|Help document |Provide commonly used help documentation in the release notes, getting started, and best practices categories to make it convenient for users to access. |
