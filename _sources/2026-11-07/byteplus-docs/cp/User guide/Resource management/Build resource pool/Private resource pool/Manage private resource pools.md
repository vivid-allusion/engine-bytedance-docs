After creating a private resource pool, you can manage it. This article introduces operations related to managing private resource pools.

<span id=".5L-u5pS556eB5pyJ6LWE5rqQ5rGg"></span>
## Modify private resource pools

You can modify the Name, Description, and Shared Workspace of the private resource pool.


1. Log in to the [Code Pipeline Console ](https://console.byteplus.com/cp).

2. In the left navigation bar, select **Resource management**.

3. On the Resource management page, switch to the **Build resource pool** tab.

4. In the private resource pool list, choose the private resource pool to modify, click the **Actions** column and then the **Modify** button to enter the **Modify private resource pool** page.

5. Modify the Name, Description, and Shared Workspace as needed.

6. Click **Confirm** to complete the modification of the private resource pool.

## Delete private resource pools

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">Before deleting a private resource pool, please first disassociate it from any pipelines.</div>


* <div data-tips="true" data-tips-type="warning">After deleting the private resource pool, pipelines that use this private resource pool will not run normally. Please proceed with caution.</div>


1. In the private resource pool list, choose the private resource pool to delete, click the **Actions** column and then the **Delete** button. A confirmation box will pop up.

2. Check the private resource pool information, and after confirmation, click **Delete** to delete the private resource pool.
