Each stage and step of the pipeline supports using variables as dynamically changing parameters, enhancing the pipeline's flexibility and generality. The pipeline currently provides the following variables:


* **Preset variables**

   Preset variables are system\-defined variables that help customize pipeline processes.

* **Custom variables**

   In addition to preset variables, Code Pipeline supports variables in custom pipelines to support more customized scenarios. The scope of custom variables defined within a pipeline is limited to that pipeline.

* **Pipeline variable groups**

   A pipeline variable group is a collection of user\-defined global variables for pipelines. Pipeline variable groups support use across workspaces or pipelines, allowing users to avoid repeatedly defining and maintaining the same variables in multiple pipelines. This enhances variable reusability and reduces configuration costs.
