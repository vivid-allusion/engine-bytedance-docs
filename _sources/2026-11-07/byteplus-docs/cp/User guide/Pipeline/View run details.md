This article explains how to view the details of a pipeline run and what information these details include.

<span id=".5Yqf6IO95YWl5Y-j"></span>
## Feature entry points


1. Log in to the [Code Pipeline console](https://console.byteplus.com/cp).

2. In the left navigation bar, select **workspace**.

3. Click the name of the target workspace to enter it.

4. Select **pipeline** in the left navigation bar to enter the **pipeline** page.

5. Click the name of the target pipeline to go to the Run Records tab for the current pipeline.

6. In the run record list, click the target serial number to enter the details page for this run.


<span id=".6L-Q6KGM6K-m5oOF"></span>
## Operation details

This section provides a detailed explanation of the information contained in the pipeline operation details.


|No. |Descriptions |
|---|---|
|1 |Displays information related to this pipeline run, including code source details, trigger type, user who initiated the run, code branch pulled, execution time, variables used, notification details, and execution notes.<br><br>Click **view details** in the notification area to view the pipeline notification details and notification records. |
|2 |Switch the display mode for pipeline details, supporting both simplified and detailed modes. |
|3 |Streamlined mode: Pipeline tasks are displayed as cards, emphasizing the task flow and execution status. The card contains information such as task logs, reports, image addresses, and other related information. |
|4 |Details mode: Focuses on displaying the running logs and related information for the selected task, enabling operations and maintenance personnel to view logs, task configuration, deployment details, and related information. |
|5 |Display the run log of the selected task in detail. Supports keyword search, zoom in/out, and theme color switching. |
|6 |Display detailed basic information and task configuration for the selected task. Depending on the task, additional information such as artifacts, deployment details, and more may be shown. |
|7 |Click the step name to view the parameter configuration information for the selected step. |
