The unit test Step is used to run automated code tests in the pipeline and collect quality metrics such as coverage, success rate, and so on. Supports configuring quality gate (qualityGate) for automatic checkpoints.

<span id="suTnktNP"></span>
## Python unit test

Run unit tests in the specified Python environment and parse reports generated by pytest or other test frameworks.


* **Addon**: python\-test@1.0.0

* **Parameter:** 

   
   |**Parameter** |**Data type** |**Required** |**Default value** |**Description** |
   |---|---|---|---|---|
   |version |string |Yes |\- |Specify Python version, supported versions: Python 2.7, 3.6, 3.8, 3.10. |
   |cmd |string |Yes |\- |Command to execute unit tests and generate report. |
   |reportDir |string |Yes |\- |Directory path where the test report is located (relative path). |
   |reportHtml |string |Yes |\- |Entry file name of test report in HTML format. |
   |qualityGate |object |No |\- |Quality gate configuration. For detailed configuration instructions, see [quality gate](https://docs.byteplus.com/en/docs/cp/Unit_test#SJuUDYsh). |
   

* **Example:** 

   ```YAML
   tasks:
     - task: task-python-test
       displayName: Python Unit Test
       steps:
         - step: step-python-test
           displayName: Python Unit Test
           component: python-test@1.0.0
           inputs:
             version: '3.10'
             cmd: |
               coverage run --source=. -m pytest --html=report/index.html
               coverage html -d report
             reportDir: report
             reportHtml: index.html
             qualityGate:
               strategy: and
               rules:
                 - key: LineCoverage
                   type: GE
                   value: '80'
                 - key: FailedCount
                   type: LE
                   value: '0'
   ```

## Go unit test

Run unit tests in the specified Go environment and parse JSON and HTML reports generated by go test.


* **Addon**: golang\-test@1.0.0

* **Parameter**:

   
   |**Parameter** |**Data type** |**Required** |**Default value** |**Description** |
   |---|---|---|---|---|
   |version |string |Yes |\- |Specify Go version, supported versions: Go 1.12.4, 1.15.1, 1.16.13, 1.17.3, 1.18.8, 1.20, 1.21.4, 1.22.0, 1.23.7, 1.24.0 |
   |cmd |string |Yes |\- |Command to execute unit tests and generate report. |
   |reportDir |string |Yes |\- |Directory path where the test report is located. |
   |reportFile |string |Yes |\- |File name of test result in JSON format. |
   |reportHtml |string |Yes |\- |Entry file name of the test report in HTML format. |
   |qualityGate |object |No |\- |Quality gate configuration. For detailed configuration instructions, see [quality gate](https://docs.byteplus.com/en/docs/cp/Unit_test#SJuUDYsh). |
   

* Example:

   ```YAML
   tasks:
     - task: task-go-test
       displayName: Go Unit Test
       steps:
         - step: step-go-test
           displayName: Go Unit Test
           component: golang-test@1.0.0
           inputs:
             version: '1.18.8'
             cmd: |
               mkdir -p report
               go test -v -cover -json -coverprofile=cover.out ./... > ./report/report.jsonl
               go tool cover -html=cover.out -o ./report/report.html
             reportDir: report
             reportFile: report.jsonl
             reportHtml: report.html
             qualityGate:
               strategy: and
               rules:
                 - key: LineCoverage
                   type: GE
                   value: '75'
   ```

## Java unit test

Run unit tests in the specified Java environment, supporting reports generated by Maven (Surefire) and Gradle.


* **Addon**: java\-test@1.0.0

* **Parameter**:

   
   |**Parameter** |**Data type** |**Required** |**Default value** |**Description** |
   |---|---|---|---|---|
   |version |string |Yes |\- |Specify JDK version, supported versions: JDK 7, 8, 11, 17, 21 |
   |cmd |string |Yes |\- |Command to execute unit tests and generate report. |
   |reportDir |string |Yes |\- |Directory path where the test report is located. |
   |reportHtml |string |Yes |\- |Entry file name of test report in HTML format. |
   |qualityGate |object |No |\- |Quality gate configuration. For detailed configuration instructions, see [Quality gate](https://docs.byteplus.com/en/docs/cp/Unit_test#SJuUDYsh). |
   

* Example:

   ```YAML
   tasks:
     - task: task-java-test
       displayName: Java Unit Test
       steps:
         - step: step-java-test
           displayName: Java Unit Test
           component: java-test@1.0.0
           inputs:
             version: '11'
             cmd: |
               mvn -B test -Dmaven.test.failure.ignore=true
               mvn surefire-report:report
             reportDir: target/site
             reportHtml: surefire-report.html
             qualityGate:
               strategy: and
               rules:
                 - key: PassRate
                   type: GE
                   value: '60'
   
   ```

## Quality gate description

qualityGate is an optional parameter used to set checkpoints for code quality:


* strategy: Logical relationship among multiple rules.

   * and: All rules must be satisfied simultaneously.

   * or: Satisfying any one rule is sufficient.

* rules: Rule list, each rule includes the following parameters.

   * key: Rule type.

      * LineCoverage: Line coverage.

      * FailedCount: Number of failed cases.

      * PassRate: Pass rate.

   * type: Type of comparison operator.

      * GE: Greater than or equal to.

      * LE: Less than or equal to.

   * value: Threshold of the rule.
