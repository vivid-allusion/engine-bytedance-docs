To perform SonarQube code scanning using Code Pipeline, you need to obtain the SonarQube token in advance. This article introduces how to obtain a SonarQube token.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to your SonarQube server.

2. Go to **Administration \> Security \> Global Permissions**, and for the current user, check the **Administer System**, **Administer**, **Execute Analysis**, and **Create** permissions.

3. Click the Avatar dropdown in the upper right corner, select **My Account \> Security**, and create a Token.
