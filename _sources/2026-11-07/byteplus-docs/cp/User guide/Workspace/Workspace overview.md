A workspace is a virtual environment for organizing and managing your work. Each workspace operates independently, allowing companies to organize different projects in separate workspaces for management. Team members collaborate within the workspace to jointly complete a project.


* The workspace allows you to set the visibility scope for permission management.

* Within a workspace, you can create code sources, pipelines, and application delivery to enable continuous integration and continuous delivery for your product.
