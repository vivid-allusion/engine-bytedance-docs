Only application administrators have permission to delete managed applications (ECS).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">After the application is deleted, you will not be able to manage the application through Code Pipeline. However, the actual host application process has not been deleted.</div>



1. Log in to the application management page.

   1. Log in to the [Code Pipeline Console](https://console.byteplus.com/cp).

   2. In the left navigation bar, select **workspace**.

   3. Click the name of the target workspace to enter that workspace.

   4. In the left navigation bar, select **Application Delivery \> Application Management**.

2. On the application management page, select the target hosted application, and click  **`...`**   **\> delete**.

3. In the pop\-up secondary confirmation dialog, verify the name of the application to be deleted. After confirming that there are no errors, enter the application name in the delete confirmation dialog box.

4. Click **OK** to delete the current application.
