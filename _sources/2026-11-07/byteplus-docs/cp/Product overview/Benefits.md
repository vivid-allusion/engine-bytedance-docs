This article introduces the product advantages of Code Pipeline.

<span id=".54G15rS75piT55So"></span>
## Flexible and easy to use

Provides visual process orchestration, supports three\-layer task orchestration, and enables flexible drag\-and\-drop adjustment of task order to simplify complex processes and significantly enhance the user experience.

<span id=".5b-r5o236auY5pWI"></span>
## Fast and efficient

Preset multilingual templates and rapid process orchestration enable pre\-deployment within minutes, helping enterprises deliver services with high quality and efficiency.

<span id=".5LqR5Y6f55Sf5bqU55So5Lqk5LuY"></span>
## Cloud\-native application delivery

Supports native Kubernetes orchestration and the Open Application Model (OAM), providing a non\-intrusive application deployment architecture. Enables import or export of application definitions in native YAML format or Helm Chart format, allowing worry\-free cross\-cloud deployment.

<span id=".5Liq5oCn5YyW5a6a5Yi2"></span>
## Personalized customization

Code Pipeline provides robust personalization capabilities, supporting custom build environments, custom atomic steps, and integration with custom deployment clusters to meet the personalized build and deployment requirements of enterprises.
