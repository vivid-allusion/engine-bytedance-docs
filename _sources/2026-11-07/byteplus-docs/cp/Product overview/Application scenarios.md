This article introduces Code Pipeline application scenarios.

<span id=".5aSa57u05bqm5raI5oGv6Kem6L6-"></span>
## Multi\-dimensional message delivery

Task messages are promptly sent to users via multiple channels, including, email, site message and Webhook, enabling users to quickly understand build and deployment results and collaborate more efficiently.

<span id=".5Y2P5ZCM5byA5Y-R5b-r6YCf6ZuG5oiQ"></span>
## Collaborative development and rapid integration

After individual coding is completed, submitting a merge request automatically triggers pipeline compilation, building, and testing. Once these steps are finished, the code is merged to achieve rapid integration.

<span id=".6ZmN5L2O6YOo572y5YmN572u5pe26Ze0"></span>
## Reduce deployment lead time

After coding is completed and before release, pre\-deployment is performed within minutes by automatically triggering the pipeline.

<span id=".5LqR5Y6f55Sf5bqU55So5Lqk5LuY"></span>
## Cloud\-native application delivery

Provides a comprehensive change management workflow covering application definition, application build, environment management, and application release, helping enterprises establish a comprehensive end\-to\-end application delivery solution.
