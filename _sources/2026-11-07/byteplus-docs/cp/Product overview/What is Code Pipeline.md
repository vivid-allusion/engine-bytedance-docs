Code Pipeline (CP) provides a developer\-friendly, cloud\-native application delivery platform and a flexible, easy\-to\-use one\-stop pipeline, helping enterprises connect every stage of development and operations engineering to enable high\-quality and efficient continuous integration, validation, and release of business applications.

<span id=".5Yqf6IO954m55oCn"></span>
## Functional Features

This section introduces the core features of Code Pipeline. For detailed Product features, see [Product features](https://docs.byteplus.com/en/docs/cp/Features).


* **One\-stop pipeline**

   Provide simple and easy\-to\-use capabilities for continuous integration, continuous testing, and continuous deployment to help enterprises complete business delivery quickly, securely, and efficiently.

* **Application delivery**

   An application\-centric, cloud\-native application delivery platform that provides out\-of\-the\-box, one\-stop capabilities such as application access, configuration management, and application release, helping enterprises build a comprehensive Code Pipeline solution for continuous application delivery.

* **Environmental management**

   Provides comprehensive environment lifecycle management, including environment creation, operations and maintenance, locking, and destruction. This enables enterprises to set up environments with one click and quickly verify that Product features meet expectations.
