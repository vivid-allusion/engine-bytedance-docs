You can stop the workflow to terminate data migration. This topic describes how to stop a workflow.

<span id="2lXO9uyx"></span>
## Prerequisites

Workflow created with **Starting** or **Running** state. For specific steps, refer to [Create workflow](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_workflow).

<span id="4SPz4FYF"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the upper left corner of the top menu bar, select the region to which the workflow belongs.

3. Click **Data migration** in the left navigation bar.

4. On the **Data migration** page, locate the target workflow, then click **Stop** in the **Actions** column.

5. In the popup dialog, click **OK**.
