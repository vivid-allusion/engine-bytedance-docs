The instance list in Milvus for VectorDB provides multiple workflow details, such as workflow name, source, destination, state, creation time, start time, and end time. This topic describes how to view the workflow list.

<span id="WSrF5p9L"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. Select the region to which the workflow belongs in the upper left of the top menu bar.

3. Click **Data migration** in the left navigation bar to view the workflow list for the specified region.
