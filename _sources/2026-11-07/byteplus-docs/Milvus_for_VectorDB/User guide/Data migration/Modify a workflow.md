After creating a workflow, you can modify its information according to business needs. This topic describes how to modify a workflow.

## Prerequisites

A workflow is created. For specific steps, refer to [Create a workflow](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_workflow).

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the upper left corner of the top menu bar, select the region to which the workflow belongs.

3. Click **Data migration** in the left navigation pane.

4. On the **Data migration** page, find the target workflow, then click **Edit** in the **Actions** column.

5. On the **Edit workflow** page, configure the following parameters according to business needs.

6. Click **Save** or **Save and start** as needed.

   * **Save**: Save the workflow without running it. After you click Save, the system returns to the **Data migration** page. In the workflow list, click **Start** in the **Actions** column of the target workflow to start the data migration workflow.

   * **Save and start**: Complete editing and begin running the data migration workflow.
