This topic describes how to view detailed information of workflows in Milvus for VectorDB and the details on the workflow detail page.

## Prerequisites

A workflow is created. For specific steps, refer to [Create a workflow](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_workflow).

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. Select the region of the workflow from the top menu bar.

3. Click **Data migration** in the left navigation pane.

4. On the **Data migration** page, click the target workflow’s name to enter the **workflow details** page.

   On the **Overview** tab, you can view the following information about the workflow.

   |**Information** |**Description** |
   |---|---|
   |Basic information |Includes the workflow name, workflow ID, Flink project, Flink resource pool, status, creation time, start time, end time, and time consumed. |
   |Workflow |Includes all nodes and task modes within the workflow. You can click a node to view its details below the workflow. |
