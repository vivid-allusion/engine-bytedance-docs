You can delete a workflow that is no longer needed. This topic describes how to delete a workflow.

<span id="nIost7dv"></span>
## Prerequisites

The workflow is created and its state is neither **Starting** nor **Running**. For specific steps, refer to [Create a workflow](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_workflow).

<span id="UE98iNzz"></span>
## Notice

Once deleted, workflows cannot be recovered. Proceed with caution.

<span id="UE98iNzz"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the upper left corner of the top menu bar, select the region to which the workflow belongs.

3. Click **Data migration** in the left navigation pane.

4. On the **Data migration** page, find the target workflow, then select  **...**  \> **Delete** in the **Actions** column.

5. In the popup dialog, click **OK**.
