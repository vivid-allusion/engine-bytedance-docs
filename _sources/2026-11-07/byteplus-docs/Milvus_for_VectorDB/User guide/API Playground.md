You can quickly call APIs for data addition, deletion, modification, and query operations through API Playground. This topic describes how to use API Playground.

<span id="ZVm5UggS"></span>
## Prerequisites

Created a Milvus for VectorDB instance and completed authorization. For specific steps, refer to [Create Instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance) and [Authorize instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Authorize_to_use_an_instance).

<span id="IscgXDsL"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for API Playground usage.

3. In the left navigation bar, select **API Playground.** 

4. On the **API Playground** page, select the **Dedicated**, **Serverless**, or **On\-Demand** tab, choose the instance with completed authorization, then click **view**.

5. In the left navigation bar, select the API you want to call, adjust the request parameters in the right **Body** section as needed, then click **Execute**.

6. View the API response in the **Execution results** section.


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



<div data-tips="true" data-tips-type="default">You can also click <strong>Generate client code</strong> at the top right of the page, select the appropriate language, and generate code to call the API from other clients.</div>
