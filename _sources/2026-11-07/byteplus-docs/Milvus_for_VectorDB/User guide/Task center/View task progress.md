Milvus for VectorDB offers a task center that records important, non\-real\-time instance operations such as creating instances, changing instances, modifying configurations, upgrading kernel versions, and more. You can view basic task information, task details, and change status in the task center. This topic describes how to view task progress.

<span id="xNBsthmo"></span>
## View basic task information


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for the tasks you want to view.

3. In the left navigation bar, select **Task center**, and choose the **Dedicated**, **Serverless**, or **On\-Demand** tab as needed.

4. View the task list.

   * **Task start time**: Supports setting start and end times to view the task list within this period.

   * **Instance name/ID**: supports setting the target instance name/ID and viewing the task list of the target instance.

5. Click the plus button before the task to view information such as the progress, time consumed, and completion time of different stages of the task.


<span id="hx4iPrgH"></span>
## View task details


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region to view tasks.

3. In the left navigation bar, select **Task center**, and choose the **Dedicated**, **Serverless**, or **On\-Demand** tab as needed.

4. In the task list, click **details** in the **Actions** column of the target task.

5. In the **Task details** info box, view the information before and after the changes of objects involved in the task.
