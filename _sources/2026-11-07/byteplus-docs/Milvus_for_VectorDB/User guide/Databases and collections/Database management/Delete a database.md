You can delete a database when you no longer need it. This topic describes explains how to delete a database.

<span id="Y8TqLD4N"></span>
## Prerequisites


* Created a Milvus for VectorDB instance and completed authorization. For specific steps, refer to [Create Instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance) and [Authorize instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Authorize_to_use_an_instance).

* Database created. For more information, see [Create a database](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_database).

* All collections are deleted from the database. For information, see [Delete a collection](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Delete_a_collection).


<span id="swf0rrUt"></span>
## Precautions


* Only Dedicated instances support deleting databases.

* Once the database is deleted, it cannot be recovered. Proceed with caution.


<span id="swf0rrUt"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for collections management.

3. Select **Collections** in the left navigation bar.

4. On the **Collections** page, select the **Dedicated** tab, choose the instance with Completed authorization, then click **View**.

5. On the **Collections** page, select  **... \> Delete** on the right side of the target database.

6. In the popup dialog, click **OK**.
