After creating a database, you can view the created database. This topic describes how to view a database.

<span id="w6rfy8nE"></span>
## Prerequisites


* Created a Milvus for VectorDB instance and completed authorization. For specific steps, refer to [Create Instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance) and [Authorize instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Authorize_to_use_an_instance).

* Database created. For specific steps, refer to [Create a database](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_database).


<span id="sR6Ob1ub"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for collections management.

3. Select **Collections** in the left navigation bar.

4. On the **Collections** page, choose the **Dedicated**, **Serverless**, or **On\-Demand** tab, select an authorized instance, then click **View**.

5. On the **Collections** page, click the target database and view its details in the right panel, including the following tabs.

   
   |Tab |Description |
   |---|---|
   |Collection |Display the list of Collections in the current database, including Collection name, status, number of entities, description, creation time, and actions. |
   |Property |Display the current database configuration, which you can modify according to business needs. For detailed operations, see [Modify the database configuration](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Modify_the_database_configuration).<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Only Dedicated instances support the <strong>Property</strong> tab.</div><br> |
   |Collection copy |Display the current database's Collection clone tasks. For details, see [Clone collection schema and data](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Clone_a_Collection_schema_and_data).<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Only Dedicated edition instances and Serverless edition instances support the <strong>Collection copy</strong> tab.</div><br> |
