Using the collections feature requires authorization to use an Milvus for VectorDB instance. This topic describes how to authorize an instance.

<span id="bpWNw0jA"></span>
## Prerequisites

A Milvus for VectorDB instance has been created. For more information, see [Create an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance).

<span id="t3TrFv59"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for collections management.

3. Select **Collections** in the left navigation bar.

4. On the **Collections** page, select the **Dedicated**, **Serverless**, or **On\-Demand** tab as needed, choose the Milvus for VectorDB instance to authorize, enter the username and password, select the authorization duration, then click **Authorize**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">You can enter the username and corresponding password created when creating the instance, or use other usernames and passwords created via SDK or API.   </div>
