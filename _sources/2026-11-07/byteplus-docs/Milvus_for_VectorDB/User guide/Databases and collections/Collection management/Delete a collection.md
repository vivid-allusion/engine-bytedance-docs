You can delete a collection when you no longer need it. This topic describes how to delete a collection.

<span id="r8Yz4oIa"></span>
## Prerequisites


* Created a Milvus for VectorDB instance and completed authorization. For more information, see [Create an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance) and [Authorize to use an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Authorize_to_use_an_instance).

* Collection has been created. For detailed steps, see [Create a collection](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_a_collection).


<span id="18nkMCvR"></span>
## Precautions

Deleted collections cannot be recovered. Proceed with caution.

<span id="DlLiSsvr"></span>
## Delete a single Collection


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for collections management.

3. Select **Collections** in the left navigation bar.

4. On the **Collections** page, select the **Dedicated**, **Serverless**, or **On\-Demand** tab, choose the authorized instance, then click **view**.

5. On the **Collections** page, expand the database containing the target Collection, then select  **... \> Delete** on the right of the target Collection.

6. In the popup dialog, click **OK**.


<span id="ubGgr7gJ"></span>
## Bulk delete Collection


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. In the top navigation bar, select the project and region for collections management.

3. Select **Collections** in the left navigation bar.

4. On the **Collections** page, select the **Dedicated**, **Serverless**, or **On\-Demand** tab, choose the authorized instance, then click **View**.

5. On the **Collections** page, expand the database containing the target Collection.

6. On the right **Collection** tab, check the Collections to delete, then click **Batch delete**.

7. In the pop\-up dialog, click **Delete**.
