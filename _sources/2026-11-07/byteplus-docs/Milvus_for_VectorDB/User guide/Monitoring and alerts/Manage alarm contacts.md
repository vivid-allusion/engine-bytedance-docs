When configuring an alarm policy, if you need to receive notification messages through channels such as email, phone, or SMS, you must create contacts and link them to alarm contact groups. This topic describes how to manage alarm contacts.

<span id="O0tf1gcY"></span>
## Precautions

Only Dedicated and Serverless instances support managing alarm contacts.

<span id="Oppbvs7M"></span>
## Procedure


1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. On the top navigation bar, select the target project and region.

3. Click **Alarm management** in the left navigation pane.

4. At the top of the page, click the **Alarm policy** tab.

5. On the **Alarm policy** page, select **Dedicated** or **Serverless** as needed, then click **Manage alarm contacts** to access the **Alarm contacts** page in Cloud Monitor. For more details about alarm contacts, see [Contact](https://docs.byteplus.com/en/docs/cloudmonitor/Alarm-contacts).
