Milvus for VectorDB allows you to add instances to projects to manage instance resources at the project level. This topic describes how to change the project of an instance.

## Background

For new instances, you can select the project during creation. For existing instances, you can follow instructions in this topic to change the project of an instance.

### Prerequisites

* The instance ID is obtained.

* The region of the instance is obtained.

* The ID of the account to which the resource belongs is obtained.

## Procedure

1. Log on to the [Project console](https://console.byteplus.com/iam/resourcemanage/project).

2. On the project list page, click the target project name.

3. On the **Manage resources** tab, click **Resource transfer in**.

4. In the pop\-up **Resource transfer in** panel, select the Milvus instance to transfer in by filtering the project, resource type, region, tags, and resource ID, then click **Next**.

   > **tip**

   > For a Milvus instance, the resource ID is the instance ID.

5. In the Confirm transfer\-in step, confirm the project and resource information and click **OK**.
