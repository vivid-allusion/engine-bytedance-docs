Milvus for VectorDB provides running log query functionality for Dedicated instances. You can quickly locate target instance running log content by filtering conditions such as log level, role, node, time, and keywords, which assists in instance operations and maintenance. This document describes how to query running logs.

## Prerequisites

Dedicated edition instance created. For more information, see [Create an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance).

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. in the top menu bar, select the project and region for the instance.

   > **tip**

   > If the instance is not configured with a project, select **All resources**.

3. Click **Instance list** in the left navigation pane.

4. In the **Instance list**, select the **Dedicated** tab, then click the target instance name.

5. Select the **Logs** tab, then the **Running logs** subtab to view the instance’s running logs. You can quickly locate the logs you want to query by filtering with log level, role, node, time, keywords, and other criteria.

   > **tip**

   > Currently, only running logs from the past 7 days are supported for viewing.
