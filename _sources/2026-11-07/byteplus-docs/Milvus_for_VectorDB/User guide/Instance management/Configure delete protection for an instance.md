Deletion protection is a feature provided by Milvus for VectorDB to prevent accidental deletion of instances. You can enable deletion protection when you create or use an instance. This topic describes how to enable deletion protection when you use an instance.

## Prerequisites

An instance is created and is in **Running** state. For more information about how to create an instance, see [Create an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Create_an_instance).

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. in the top menu bar, select the project and region for the instance.

   > **tip**

   > If the instance is not configured with a project, select **All resources**.

3. Click **Instance list** in the left navigation pane.

4. In **Instances**, select the **Dedicated**, **Serverless**, or **On\-Demand** tab as needed, then click the instance name of the target instance.

5. On the **Instance details** page, you can view the status of the deletion protection feature for the instance. Click **Enable** or **Disable**, then click **OK** in the pop\-up dialog box to enable or disable the delete protection feature for the instance.
