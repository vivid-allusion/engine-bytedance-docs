You can delete backups when they are no longer needed. This article explains how to delete backups.

## Prerequisites

Backups have been completed automatically or manually, or imported from TOS. Related documents: see [Manually create a backup](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Manually_create_a_snapshot), [Automatically create a backup](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Automatically_create_a_snapshot), and [Import a backup from TOS](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Import_a_snapshot_from_TOS).

## Precautions

* Backups automatically created for deleted instances cannot be deleted.

* Deleted backups cannot be recovered. Proceed with caution.

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. Select the region to delete the backup from the top menu bar.

3. Select **Backup management** in the left navigation bar, filter backups by **Backup name**, **Instance name**, and **Instance ID**, then choose  **... \> Delete** in the **Actions** column of the target backup.

4. In the popup dialog, click **OK**.
