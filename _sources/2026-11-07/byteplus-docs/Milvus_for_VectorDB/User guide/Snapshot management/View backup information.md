After creating or importing a backup, you can view backup information, including backup name, backup status, bucket, storage path, and data included in the backup. This article explains how to view backup information.

## Prerequisites

Completed automatic backups, manual backups, backups imported from TOS, or backups automatically created by the system for deleted instances. For related documents, see [Manually create a backup](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Manually_create_a_snapshot), [Automatically create a backup](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Automatically_create_a_snapshot), [Import a backup from TOS](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Import_a_snapshot_from_TOS), and [Delete an instance](https://docs.byteplus.com/en/docs/Milvus_for_VectorDB/Delete_an_instance).

## Procedure

1. Log on to the [Milvus for VectorDB console](https://console.byteplus.com/milvus).

2. Select the region for viewing backup information from the top menu bar.

3. Select **Backup management** in the left navigation bar, filter backups by **Backup name**, **Instance name**, and **Instance ID**, then click the target backup name.

4. On the backup details panel, view backup details and recovery tasks on the **Details** and **Recovery list** tabs respectively.
