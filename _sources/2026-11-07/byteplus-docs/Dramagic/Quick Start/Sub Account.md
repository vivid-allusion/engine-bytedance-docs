In addition to using their registered account on BytePlus (i.e., the main account) to log in to the Dramagic platform, users can also create several sub\-accounts, allowing relevant personnel to log in using sub\-accounts. The steps to create sub\-accounts are as follows:

<span id="1ca6534f"></span>
## Create sub\-account


1. Use the main account to log in to the [BytePlus Access Control page](https://console.byteplus.com/iam/identitymanage/user).

2. In the left navigation bar, click **User**.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/55f6ee5f1104422e8b20e27a8f573053) </span>


3. On the **User** page, click **Create New User**.



&nbsp;

4. Complete the following steps:


<span id="db3e7bb7"></span>
### Set user basic information

In the **Basic information settings** step, set the basic information for the sub\-user according to the field description in the table.

&nbsp;

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/76771fd9e64843d3b7b5fd3b99a88425) </span>

&nbsp;

<span id="3298c50d"></span>
#### Field description


|**Fields** |**Yes** |**Field Description** |**Example** |
|---|---|---|---|
|Username |Yes |Enter the username of the sub\-user. When logging in to the Volcano Engine Console, use the username to log in. |john_smith |
|Display Name |No |Enter the name displayed for the sub\-user in the console. If no display name is specified, the username will be shown. |John Smith |
|Reason |No |Enter a reason for the sub\-user. |\- |
|Mobile Number |No |Enter the mobile number of the sub\-user. The mobile number can be used to retrieve passwords or receive messages. |12345678910 |
|Email |No |Enter the email address of the sub\-user. The email address can be used to retrieve passwords or receive messages. |abc.example.com |


Below **Login settings**, you are required to check the **Console Access** option


* **Console Access**: Specify whether to allow the sub\-user to log in to the Volcano Engine console. **You are required to check this setting**, and set a console login password for the sub\-user.


<span id="46b083cf"></span>
### Permission settings

You are required to select **DramartFullAccess**, then click **Next**.

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/7380d522280541629b71c4212c13dc35) </span>

&nbsp;

&nbsp;

<span id="f021d8ce"></span>
### Verify information

In the **Review** step, verify whether the information for the sub\-user is correct. If correct, click **Next** to complete the sub\-user creation.

&nbsp;

<span id="2e983575"></span>
## Sub\-account Dramagic platform authorization


1. After successfully creating a sub\-account, the main account can view the newly created sub\-account in the Team Management \- Sub\-account Management page. At this time, the status is not yet authorized. **You must authorize the sub\-account and add it to a team before it can log in to the Dramagic platform.** 


&nbsp;

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/59789b0d634f4c0b94bcd7e4280ac09e) </span>

&nbsp;


&nbsp;

2. Authorization: To grant login access to the sub\-account, click **Authorize.**  on the right side of the sub\-account.


&nbsp;

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/cdceed04cd1b451e9343a0a95b8db315) </span>

&nbsp;


&nbsp;

3. Join team: After authorization, an account information pop\-up will appear. You need to add the sub\-account to a team. **You must authorize the sub\-account and add it to a team before it can log in to the Dramagic platform.** 


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/a453ceba738e4a959504c44f51512ece) </span>

&nbsp;

## Log in to sub\-account

<span id="9ec83372"></span>
### Use IAM users to access Dramagic Console


1. Open [ Login Page](https://console.byteplus.com/dramagic/).

2. Select **IAM User**, and open the **IAM Sub\-user Login** page.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/08547541be1947ba91e95fe1ff07cdc5) </span>


3. After entering the main account and sub\-account information, click **Sign in**.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/58107ae933a54a66ab37b36beb82ec4f) </span>


4. In the Products and Services Center, select Dramagic and enter the [Dramagic Console](https://console.byteplus.com/dramagic/).


&nbsp;
