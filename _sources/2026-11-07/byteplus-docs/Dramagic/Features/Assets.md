“Dramagic” **Assets** function

At the lower part of the left sidebar, locate **Assets** and click to access the asset management page.

<span id="d3550a6f"></span>
# Core concepts


1. My assets: Private assets visible only to the User.

2. Team assets: Shared and visible to all team members.

3. Portrait: Stores real portrait materials.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Notice</div>


<div data-tips="true" data-tips-type="warning">When the user switches teams, <strong>My</strong><strong> assets</strong> follow the account and remain unchanged, but <strong>T</strong><strong>eam</strong><strong> assets</strong> and <strong>Portrait</strong> data are strictly isolated.</div>


<span id="ec1dbd92"></span>
# My assets

The User enters **My** ** assets** and can select specific asset categories, including: Character, Prop, and Scene.

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/dd11ec4e643a4f77832be92f8324da44) </span>


&nbsp;

1. Create folder: **My assets** \- Character. In the character library category, the user clicks **New folder**, enters the folder name, and completes folder creation.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/fa74e4dd458d4d13bcd89ce86b4770d4) </span>


&nbsp;

2. Add asset: Select the corresponding asset category. The user uploads materials locally (upload images or directly upload compressed packages) to Personal asset.

* Upload image: **My assets** \- Character. In the character library category, the user clicks **Upload** selects a file, then chooses the local image to upload, completing asset addition.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/177416f6fa3048f3b2279c33ba09f455) </span>


&nbsp;

* Direct upload of compressed package: **My assets** \- Character. In the character library category, the user clicks **Upload**, selects a file, then chooses the compressed package to upload, completing asset addition. (Compressed package must not exceed 1G, and the number of images inside must not exceed 200.)


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/bb8c930c63f8493fb58630dd695d9b00) </span>


3. Asset management: The user clicks the upper right corner of the image to perform operations such as rename, move to other folders, copy to other folders, delete, and share with the team.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/537bd7e2958a4c06aa7089760d271da0) </span>

# Team asset

After the team member uses the upper left box **Select the corresponding team** and enters **Team Assets**, specific asset categories can be selected, including: Character, Prop, and Scene.

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/8a67080da74e43ec8eeac310e4081b98) </span>


&nbsp;

1. Add asset

* Project creation: In the Project \- Settings of script\-based short drama, the User saves the asset details page for Role, Prop, and Scene. After clicking Save, the asset will be automatically saved to Team asset. Once a team member has saved, cancellation is not permitted within the Project (maintenance can be performed in Asset Management \- Team Assets \- Project folder). View the corresponding asset in the project file under Team Assets \- Project Create.


&nbsp;

<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/c54338a62eae4934aa96b191ef79ca60) </span>

&nbsp;

* Local Upload: Select the appropriate asset category. The User uploads local materials to Team Assets, supporting two methods: direct image upload and direct compressed package upload. All assets uploaded by team members can be viewed in **Team Assets \- Upload**.

* Filter \- By material type added: Optional choices include All assets, From Upload, and From Project.

# Portrait

The Real Person Portrait Library is used to store **real person portrait** materials. If there are naturally existing real person images required for creating a short drama, these real person images can be uploaded to the Real Person Portrait Library for the User to select and use when creating a Project. The process is as follows:

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Attention</div>


<div data-tips="true" data-tips-type="warning">The realistic portrait library only supports saving portrait images of real people. Portrait materials in the realistic portrait library can be selected and used by all teams under the main account.</div>



1. In the Realistic Portrait Library, enter the Real Person Portrait Library and select **New portrait group**. A portrait group is a collection of all real person portrait images under a single real person.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/4a08e8a026304ed09987eb091f7e8f73) </span>


&nbsp;

2. Enter the Character name and the Authorization Time for Use of this real person portrait, read and agree to the agreement, then click **Create** to complete the creation of the portrait group for this person.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/ec7331b8a36e42e2b88e80b6aae8ab1f) </span>


&nbsp;

3. After the portrait group is created, a QR code will pop up. The real person corresponding to this portrait group Role needs to scan the code using a mobile device for liveness detection to complete the final Authorization. The QR code is valid for 120 seconds. Please complete liveness authentication within the specified time. If the time is exceeded, click to generate a new QR code.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/404d906418dc4bb987496103b4125705) </span>


&nbsp;

4. After the real person corresponding to the portrait group scans the code, liveness authentication must be completed on the mobile device. Upon success, the portrait group is successfully created.

If the material is determined not to be the same portrait, it cannot be successfully stored in the library.

   * If the portrait image contains multiple faces, it cannot be stored in the library.

# Asset usage

Users save and maintain assets in the asset library (Personal Assets/Team Assets/Realistic Portrait Library), which can be selected and used in created projects. For example, in role settings:


1. The user selects a role in the project, enters the role details, selects the main image/outfit image, and clicks **Select from the character library.** 


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/b5add45746d84b28b6ecbd8a9f0e2bf0) </span>


&nbsp;

2. The user can select assets from personal assets or team assets as the main image/outfit image setting picture for the role.


<span>![图片](https://p9-arcosite.byteimg.com/obj/tos-cn-i-goo7wpa0wc/fd7525880a6d45999cb5249fbfe25c98) </span>
