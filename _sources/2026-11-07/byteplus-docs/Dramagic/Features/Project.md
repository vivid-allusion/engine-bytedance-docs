“Dramagic” **Projects** features

At the bottom of the left sidebar, find **Projects** and click to enter the project management page.

&nbsp;

<span id="5bee7fdd"></span>
# Core concepts


1. **Projects**: The central workspace for users to create short dramas on the Dramagic platform. From importing scripts, shaping characters, generating storyboards, to finally exporting the finished video, all creation and team collaboration are seamlessly conducted within the “Projects”.

2. **Project ownership**: **Projects created by users belong to the team, not to individuals**. Users can switch team names to create or view projects under that team.

# Project management


1. **Create project**

* On the “Script to video” start page, users upload a new script to create a new project.

* On the “Projects” page, clicking the **Create project ** button redirects to the “Script to video” start page, where users upload a new script to create a new project.

2. **View and find projects**

* On the “Projects” page, team members can view the project list for all projects under the team. Clicking a project card allows entry into the project for collaborative creation.

* On the “Projects” page, supports searching by project name; supports filtering by created time and creator (all members/by me).

3. **Edit project**

* On the “Project” page, supports editing by team management and project creator, including: Edit name, Delete.

## Account levels and access


|Account type |Account level |Project management access |
|---|---|---|
|Main account |Super admin access |Has the highest access; can view, collaborate, and manage all projects globally. |
|Sub account |Team admin access |Can view, collaborate, and manage projects within the team. |
||Member access |Can view and collaborate on projects within the team.<br><br>Can manage projects created by oneself. |
