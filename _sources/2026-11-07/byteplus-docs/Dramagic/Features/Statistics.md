# Account Levels and Access

As an enterprise\-level platform, Volcano Short Drama Creation allows custom team creation, enabling multiple sub\-accounts to collaborate and complete short drama projects. For convenient management, the main account can set different access levels for accounts of various ranks on the [Team Management](https://www.volcengine.com/docs/87744/2261817?lang=zh) page. The specific access for each level under Usage Statistics is as follows:


|Account type |Account level |Description |Usage statistics access |
|---|---|---|---|
|Main account |Super admin access |Has the highest access, can view and edit global projects and data |1. Balance statistics<br><br>2. Resource details<br><br>3. Points consumption trend |
|Sub\-account |Team admin access |Can view and edit projects and data within the team |Points consumption trend for managed teams |
||Member access |Can view and edit projects within the team |N/A |

## Statistics

Users can view the points balance and sub\-account balance under the main account within the validity period on the **Statistics** page:


1. Points Balance:

   1. Total Points: Under the main account, the sum of all points in valid benefit packages and points resource bundles within the validity period.

   2. Points Balance: Under the main account, the sum of all remaining points in valid benefit packages and points resource bundles within the validity period.

2. Sub\-Account Balance:

   1. Total Sub\-Accounts: Under the main account, the number of sub\-accounts supported by benefit packages within the validity period.

   2. Sub\-Account Balance: Under the main account, the remaining number of supported sub\-accounts in benefit packages within the validity period.

## Packages

Users can view the actual consumption of benefit packages and points resource packages under the main account within the validity period on the **Statistics** page:


1. Benefit Packages:

   1. View the specifications of benefit packages (currently only the Basic version), the remaining points gifted by the package, the total points gifted by the package, whether it is in use (whether points or sub\-accounts in the package are being used), effective time and expiration time.

   2. Point Deduction Logic: Points within the Privilege Package are deducted first. After the points in the Privilege Package are exhausted, points from the Points Resources Package will be deducted.

2. Points Packages:

   1. View the specifications of the Points Package (100,000, 1,000,000, 10,000,000), points, total points, whether in use (whether the points in the Resources Package are being used), effective time, and expiration time.

   2. Point Deduction Logic:

      1. If, at the same time, an account has remaining points in both the Privilege Package and the Points Resources Package, the remaining points in the Privilege Package are deducted first.

      2. If, at the same time, the remaining points in the Privilege Package for an account are zero and multiple Points Resources Packages are available, the package with the earliest expiration time is deducted first.

## Points statistics

Users can view the actual point consumption under the main account on the **Statistics** page:

Filter Dimensions:


   1. Team: View consumption by team name

   2. Consumption category: View consumption by scenario, including role generation, scene generation, prop generation, and storyboard video generation

   3. Time: View consumption by day, with a maximum selection of up to 30 days

## Export point usage details

Users can click the **Export details** button in the upper right corner to download data in Excel format for further analysis. The details include point deduction information, such as:

   2. Total Point Consumption

   3. Team Point Consumption

   5. Project Point Consumption

# Sub\-account Users (Team Admin Access)

Users can view the actual points statistics under the managed team on the **Statistics** page:


1. Filter Dimensions:

   1. Team: View consumption by team name

   2. Consumption category: View consumption by scenario, including role generation, scene generation, prop generation, and storyboard video generation

   3. Time: View consumption by day, with a maximum selection of up to 30 days

2. You can click the **Export details** button in the upper right corner to download data in Excel format for further analysis. The file contains detailed points deduction data, including:

   1. Points consumption details

   2. Total points consumption

   3. Team points consumption (managed teams)

   4. Sub\-account points consumption

   5. Project points consumption
