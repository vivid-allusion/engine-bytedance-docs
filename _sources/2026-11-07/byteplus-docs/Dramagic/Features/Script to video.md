“Dramagic” **Script to video** feature

At the bottom of the left sidebar, locate **Script to video** and click to access the page. The Short drama feature provides a complete AI Short drama production process, covering script parsing, asset configuration, storyboard generation, and final preview. **Script to video** offers two modes: Agent mode and Manual mode:


* Agent mode: The user uploads the script, the Agent automatically parses the script, identifies roles and scenes, and performs storyboard auto\-generation. The overall process consists of 4 steps: Script \-\> Configuration \-\> Storyboard \-\> Videos. Supports two creation types: AI Short drama and AI Commentary Drama.

* Manual mode: In this mode, uploading a script is not required. After creating a project, all steps can be edited independently without Agent assistance. The overall process consists of 3 steps: Configuration \-\> Storyboard \-\> Videos.

## Script parsing

After script upload is complete, click **Create project,**  and the system will automatically begin parsing the script content. Script parsing consists of 4 steps: Global plot understanding \-\> Intelligent episode segmentation \-\> Episode summary extraction \-\> Role and scene identification. The parsing process displays the progress of each step.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/16dd4841024d48868e959011e569c838~tplv-goo7wpa0wc-image.image) </span>

**Script Type:**  The system automatically recognizes the script type based on the script, including: AI Short drama, AI Commentary Drama. The user can select the script type.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f3b87499e4544813b6a87ef3adf9d835~tplv-goo7wpa0wc-image.image) </span>

**Script Storyboard Style:**  The storyboard parsing Agent determines the style for script parsing. Click to select different storyboard parsing styles.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e783eb9cdb504ebba18d4afb20786338~tplv-goo7wpa0wc-image.image) </span>

**Script Modification:**  After script analysis is complete, the following structured information is generated as the foundation for subsequent asset configuration and storyboard generation. The user can make modifications:


* Script type tags / Script outline character bios / Episode plot


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/99e593c7b8744e59bf57659421b7bd33~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/218d7f4854e042b79cf4df7d086c0756~tplv-goo7wpa0wc-image.image) </span>

Once the script content is confirmed, click “**Confirmed, proceed to next step”** . At this point, two modes are available for the user to choose from:


* Manual configuration: The user can select the project's default image generation model. In the configuration step, the user is required to manually configure images for roles, scenes, etc. This mode is the default.

* Intelligent generation: The user can select the project's default image generation model and related parameters. In the configuration step, the agent will automatically generate images for roles, scenes, etc. with one click.

## Storyboard Generation

After asset setup is complete, proceed to the storyboard generation phase. The system automatically breaks down the script by episode and scene. Users can generate individual storyboards one by one or generate them in batches.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">To ensure the accuracy of storyboard generation, it is recommended that users review and confirm all storyboards before selecting batch generate videos.</div>


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/409dd30ea60c44daa94f10f9ef6d0daa~tplv-goo7wpa0wc-image.image) </span>


* Batch switch model: Click the model button in the upper right corner, select another model, and replace all video generation models for this episode's storyboards with the selected model.

* Batch generate videos: Click the batch generate videos button in the upper right corner to start batch generation of storyboard videos for this episode.

* Quickly associate storyboard reference images: Copy the text content into the prompt editor for storyboard video generation. The system will match by name and automatically associate role, scene, and prop images in the storyboard.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b759d7f10874fed81b8a1475211a217~tplv-goo7wpa0wc-image.image) </span>

Association rules (only images or audio already added in this storyboard can be associated):


* Role, scene, and prop images: When the text contains content matching the name of the main image or costume image, the corresponding image will be automatically associated. For example, if the text is “Elderly Man”, the role image for Elderly Man will be automatically associated.

* Audio: When the text contains “*Character name*'s audio”, the audio for this role will be automatically associated. For example, if the text is “Elderly Man's audio”, the audio for Elderly Man will be automatically associated.

* Dialogue: When the text contains dialogue enclosed in double quotation marks (“”), roles, scenes, prop images, and timbre will not be attached based on the text content.

2. Export Jianying draft: Supports exporting selected segmented shot videos as Jianying drafts, making it convenient for users to perform secondary editing in Jianying. Method for importing Jianying drafts into Jianying:

* Step 1: In the video preview interface, click “Export Jianying Draft” to automatically download a Zip file named “export_capcut_Short drama name”.

* Step 2: Extract the Zip file locally to obtain a folder named “export_capcut_Short drama name”, for example, export_capcut_Pearl and Slap.

* Step 3: Open Jianying, click the settings button in the upper right corner, and find the folder location for drafts, or create a new folder.

* Step 4: Outside Jianying, open the Jianying draft folder and copy the folder extracted in Step 2 into the Jianying draft folder.

* Step 5: Reopen Jianying to see the draft named “export_capcut_Short drama name”. You can then start editing and using it. All videos are sorted according to the segmented shot timeline.

The association rule is (only images or audio already added in this storyboard can be associated):


* Role, scene, and prop images: When the Text contains content that matches the name of the main image or costume image, the corresponding image will be automatically attached. For example, if the Text is 'Elderly Man', the Elderly Man's Role image will be automatically attached.

* Timbre: When the Text contains content such as '*Character name* timbre', the corresponding Role's timbre will be automatically attached. For example, if the Text is 'Elderly Man timbre', the Elderly Man's timbre will be automatically attached.

* Dialogue: When the Text contains dialogue content enclosed in double quotation marks (“”), Role, scene, prop images, and timbre will not be automatically attached based on the Text content.
