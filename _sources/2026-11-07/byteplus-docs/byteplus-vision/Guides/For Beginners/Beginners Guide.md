Hi developers! Welcome to use Vision AI documentation centre! We are here to provide you with a diverse set of openAPIs related to visual content (i.e. images and videos). The following is a basic introduction to your access to Vision AI openAPI services, where you can access hundreds of AI technology capabilities. Thank you for choosing Vision AI.

If you have any problems or want to learn more about the values of Vision AI APIs, please send an email to **ai2b\-service\-support@bytedance.com**.

<span id="Step 1: Become developers"></span>
# Step 1: Become developers

Please use your BytePlus account to access [Vision AI](https://console.byteplus.com/ai). If you do NOT have a BytePlus account yet, please [sign up](https://console.byteplus.com/auth/signup) to have one.

Please follow the below steps to finish the BytePlus account process:


1. [Managing BytePlus Accounts](https://docs.byteplus.com/byteplus-platform/docs/overview)

2. [Managing BIlling Information](https://docs.byteplus.com/byteplus-platform/docs/managing-billing-information)


<span id="Step 2: Enter Vision Console"></span>
# Step 2: Enter Vision AI Console

You can access the Vision AI via the link: https://console.byteplus.com/ai

<span id="Step 3: Create a new application"></span>
# Step 3: Create a new application

<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/dd5d94f-G6ZsN60Gus.png) </span>


1. Click [Application Management] in the left navigation bar, and click [Create Application] in the upper left corner of the page.

2. Enter the [Create API application] interface, fill in the information and select the services (capabilities) you would like to integrate.

3. Click [Save] to create the application successfully.

4. You can select more services to integrate after the application creation process is finished.


<span id="Step 4: Obtain credentials (AK/SK)"></span>
# Step 4: Obtain credentials (AK/SK)

Before calling the openAPI services from Vision AI, please make sure you have generated an AccessKey.

AccessKey consists of AccessKeyID (AK) and AccessKeySecret (SK), where:


* AccessKeyID is used to identify the user;

* AccessKeySecret is used to verify the user's key,


Please make sure you protect this information. You can obtain AK/SK by following the [guide](https://docs.byteplus.com/en/translate/docs/generating-account-tokens).

<span id="Step 5: Start development"></span>
# Step 5: Start development

**Note: If you are doing a free POC integration, there is no need to activate services.** 

Before you integrate with openAPI services from Vision AI, you can read the integration guide for each service to understand the integration details and parameters. There are two ways to find those integration guide documentation:


1. By clicking [Integration Guide] from the openAPI service list, you can directly access the integration guide for each corresponding service.

2. Use the [link](https://docs.byteplus.com/byteplus-vision/docs/beginners-guide) to check the integration guide for all services (https://docs.byteplus.com/byteplus\-vision/docs/beginners\-guide).


<span id="Step 6: Service activation/billing"></span>
# Step 6: Service activation/billing

**Note: If you are doing a free POC integration, there is no need to activate services. Billing will start once you complete the service activation.** 


1. After you select (tick) openAPI services in the application, you will be able to activate the service. You can activate services in the service list of Vision AI. After you activate the service, billing will start upon usage.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/b5d8ce7-AMhIQcoGbX.png) </span>

2. Click the [Activate] button to activate services, and then you will be redirected to the payment page. Click [Confirm Activation] to complete.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/4b7c2b9-O7C6UAPqfg.png) </span>

3. After service activation, you can purchase QPS and resource packages for each service.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/ef8ae44-nEbE6w0cJc.jpg) </span>

   **QPS purchase page**

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/c2aa509-Screen_Shot_2022-08-30_at_15.38.57.png) </span>

   **Resource package purchase page**

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/2e94ddd-Screen_Shot_2022-08-30_at_15.37.26.png) </span>

4. After service activation, you can use your obtained AK/SK and integration guide to make integration.
