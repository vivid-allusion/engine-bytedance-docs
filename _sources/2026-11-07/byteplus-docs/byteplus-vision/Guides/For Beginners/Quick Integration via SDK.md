# Overview

To integrate with the Vision service, you can use our server\-side SDKs. This document provides access to SDKs and code examples for Python, Golang, PHP, and Java. For languages that do not yet have a dedicated SDK, you can find signature examples to assist with your integration.


* The SDK handles the signing for the TOP gateway layer to avoid cumbersome manual calculation.

* The SDK handles API calls, including requests and responses, and provides corresponding examples.


<span id="SDK"></span>
# SDK
