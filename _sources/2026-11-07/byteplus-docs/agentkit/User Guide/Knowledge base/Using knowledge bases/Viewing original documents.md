This topic describes how to view the original documents of a knowledge base.

<span id="TVDgIymw"></span>
## Procedure


1. Log in the [AgentKit console](https://console.byteplus.com/agentkit).

2. In the left\-side navigation pane, select "Knowledge Base".

3. Click the name of the target knowledge base to open the details page of the knowledge base.

4. Click the "Knowledge retrieval" button in the upper right corner of the page.

5. Click the "Original documents" tab to view the list of documents uploaded to the knowledge base, as well as document status, importing method, and other information.
