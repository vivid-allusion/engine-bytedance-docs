In AgentKit, calls to MCP toolsets and MCP services generate request counts based on the respective metering rules, and these counts are included in usage statistics and billing. This topic describes the counting rules for MCP requests. It explains how requests are counted on both the MCP toolset side and the MCP service side when a toolset calls an MCP service; how gateway\-side request counts are multiplied in dedicated gateway scenarios; and how requests generated by periodic connections from MCP toolsets to MCP services are counted toward the corresponding service's billing item based on the protocol version used.

<span id="imxwU8WK"></span>
## Request counting rules for MCP toolsets and MCP services

After a request is sent to an MCP toolset, the MCP toolset accesses the associated MCP service to call a tool. The generated requests ** are counted in the usage statistics of both the MCP toolset and the MCP service.** 

In scenarios where a **dedicated gateway** is connected, the same request is counted once on the MCP toolset side and once on the MCP service side. Therefore, the actual number of requests on the gateway side is ** twice** the tool call QPS. For example, if the QPS at which an MCP toolset accesses an MCP service is 10, the number of requests actually processed by the dedicated gateway instance is **20 ** requests per second.

<div data-tips="true" data-tips-type="default">The request counting logic is the same for<strong> shared gateways</strong> and <strong>dedicated gateways</strong>.<strong> A dedicated gateway </strong>also provides gateway\-level monitoring data and QPS configuration for gateway specifications.</div>

## Periodic connections from an MCP toolset to an MCP service

An MCP toolset periodically initiates connections with the associated MCP service to obtain the latest information about MCP tools. The requests generated by these connections are counted toward the billing item usage of the corresponding MCP service.

The hourly number of requests for a single MCP service varies with the protocol version in use, as follows:


|**Protocol version** |**Request count** |
|---|---|
|Stateful MCP protocol |60 times/h |
|Stateless MCP\-0728 protocol |24 times/h |
