You can go to the credential details page to view basic information, resource bindings, and advanced configuration of a credential. This lets you confirm the current credential status, review credential usage, troubleshoot call issues, or perform subsequent management actions such as associating and disassociating.

> **tip**

> The management capabilities available vary by credential type. The tabs and fields shown on the credential details page may vary by credential type, such as**API Key**, **OAuth connection**, or**BytePlus cloud role**. The actual console page prevails.

## Procedure

1. Log in to[ the AgentKit console](https://console.byteplus.com/agentkit).

2. In the left navigation pane, select "Identity and Permission ** \>**  Credential management".

3. Click the target credential name to view the following information.

   |Tab |Description |
   |---|---|
   |Overview |View the basic information and core configuration of the credential, such as the provider, the associated project, and the last update time.<br><br>> **tip**<br><br><br>> The displayed fields vary by credential type. The actual console page prevails.<br> |
   |Associate resource |View the agents associated with the current credential, along with the resource type, last accessed time, and access count. You can also associate additional agents or remove existing associations as needed.<br><br>> **tip**<br><br><br>> Only API Key and OAuth connection credentials support associating and disassociating agents, as well as associating resources. [Learn more](https://docs.byteplus.com/en/docs/agentkit/associating-and-disassociating-agents?lang=en)<br> |
   |Advanced settings |View the advanced configuration of the credential. The configuration items vary by credential type. The actual console display prevails. |
