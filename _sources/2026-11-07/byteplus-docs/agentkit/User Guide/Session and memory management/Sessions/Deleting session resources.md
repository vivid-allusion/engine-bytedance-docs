<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">When you delete a created session resource, all related data will be deleted. This operation is irreversible. Proceed with caution.</div>


* <div data-tips="true" data-tips-type="default">When you delete an imported session resource, only the association established by the import is removed. The actual resource on the original platform will not be deleted. To delete such session resources, go to the platform where they were created.</div>



<span id="Jj9ZnXjQ"></span>
## Procedure


1. Log in to the [AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Sessions".

3. In the resource list, click the "Delete" button in the "Actions" column for the target resource.

4. In the confirmation dialog that appears, click the "Delete" button to complete the operation.
