This topic describes how to update a memory retrieval strategy.

<span id="tFWFUHCV"></span>
## Procedure


1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Memory" to open the Memory page.

3. Click the target memory ID to open the "Basic information" tab.

4. In the "Memory retrieval strategy" section, click the "Edit" button to update the memory retrieval strategy.

5. Click the "Confirm" button to complete the operation.
