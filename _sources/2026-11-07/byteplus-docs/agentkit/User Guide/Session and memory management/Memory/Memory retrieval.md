When you need to verify whether a memory has been successfully written, or troubleshoot why an agent retrieved a certain piece of historical information, you can quickly locate the stored memory content through memory retrieval. This topic describes how to retrieve existing memories from a memory in the AgentKit console.

<span id="TKFn8qT0"></span>
## Prerequisites

You have already integrated and used a memory in your agent. For integration steps, see [Integrating a memory into an agent](https://docs.byteplus.com/en/docs/agentkit/Integrating_memories_in_agent).

<span id="TKFn8qT0"></span>
## Procedure


1. Log in to the [AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Memory" to open the Memory page.

3. Click the target memory ID.

4. Click on the "Memory retrieval" tab.

5. Configure the retrieval conditions in the left sidebar.

   
   |**Parameter​**  |**Description** |**Sample value** |
   |---|---|---|
   |User ID |The unique identifier for the end user (user_id), who is the owner of the memory data. Used to narrow the retrieval scope to the specified user's memories, preventing irrelevant results from being returned across different users. |agentkit_user |
   |Agent ID |The unique identifier of the agent (agent_id), used for memory isolation. If specified, only memories generated by that agent for the user will be queried. If left empty, memories generated by all agents under that user will be queried. |\-\- |
   |Memory strategy types |Used to filter the memory types for retrieval, e.g., long\-term preference memories or conversation summary memories. You can view the configured policy types on the "Basic information" page of the target memory. |Session summary |
   |Time range |The time range during which the memories were generated and stored. If selected, only data written to the memory within that time period will be queried. If not selected, no time filter will be applied, and all memories of that user will be queried. |\-\- |
   |Number of results returned |The maximum number of memory entries returned by this retrieval. It corresponds to the Top\-K parameter in vector search. The system sorts memories by relevance score in descending order and returns the top N results with the highest matching scores. The default value is 10. |10 |
   

6. Enter a query or keyword in the search box. The platform will return the text snippets most relevant to that query.
