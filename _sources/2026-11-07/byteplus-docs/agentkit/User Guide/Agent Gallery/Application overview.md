AgentKit [Agent Gallery](https://console.byteplus.com/agentkit/application) offers a full spectrum of resources. These include agent quick\-start guides and AgentKit/VeADK SDK tutorials. It also provides best practice templates for various industries, such as finance, retail, automobile, gaming, and the Internet. Every application template's source code is open\-source and supports custom development. These resources help enterprises learn agent development, explore real\-world agent implementation, and accelerate their digital and intelligent transformation.


* Scenario\-based templates: **Focused on** popular **agent application scenarios** across industries, these templates allow users to quickly experience the basic performance of agents in industry\-specific contexts. They also enable developers to easily replicate the code for secondary development, expediting business implementation.

* Quick\-start templates: Offer reusable, highly customizable quick\-start tutorials for agent development, lowering the entry barrier.
