The skill workspace centrally displays **recently accessed skills** and ** skill to\-dos requiring attention**. It serves as a quick entry point for checking skill status, performing common operations, and handling governance tasks. On this page, you can quickly locate skills you recently worked on and centrally review to\-dos related to quality, security, and evaluation. This reduces the overhead of searching and filtering items one by one on the skill list page.

### Application scenarios

* **Fast access to recent skills**

   To continue viewing, editing, updating, or deleting skills you recently worked on, you can quickly locate the target skill in the "Recent visits" area, eliminating the need for repeated searching and filtering.

* **Routine skill asset governance**

   Regularly review skill assets and uniformly verify skill status, quality check results, security risks, and evaluation coverage for ongoing asset management.

## Instructions

The "**Recent visits**" area displays up to **5** most recently accessed skills. To view more skills, go to the "Skill" list to search or filter. [Learn more](https://docs.byteplus.com/en/docs/agentkit/Viewing_version_details_of_Skills?lang=en)

## Procedure

1. Log in to[ the AgentKit console](https://console.byteplus.com/agentkit).

2. In the left\-side navigation pane, select "Skills".

3. Click the "Workspace" tab to view your recently accessed skills and items requiring your attention.

   * **Recent visits**

      This area displays recently accessed skills or skills you worked on so you can quickly return to a target skill. In the row of the target skill, click the "Details" button to [view skill details](https://docs.byteplus.com/en/docs/agentkit/Viewing_version_details_of_Skills?lang=en); click the "Update" button to[ update the skill](https://docs.byteplus.com/en/docs/agentkit/Updating_Skills?lang=en); or click the "Delete" button to delete the skill.

   * **Requires your attention**

      The "Requires your attention" area centrally displays skill items that currently need to be handled, helping you quickly identify and resolve issues related to skill quality, security, and evaluation. To\-dos fall into the following three categories:

      > The "Requires your attention" area aggregates current skill to\-dos only. If there are no skill to\-dos under a certain category, the page displays "No skills require attention".

      > **warning**

      > The quality issues, security risks, and evaluation status displayed in this area apply only to the**latest version** of each skill.

      * **Quality check**: Displays skills whose latest version contains P0\- or P1\-level quality issues. You can click "Optimize to improve quality" to go to the quality check page for the target skill, where you can[ view and fix quality check issues](https://docs.byteplus.com/en/docs/agentkit/Viewing-and-fixing-quality-check-issues?lang=en).

      * **Security scan**: Displays skills whose latest version contains blocking security risks. You can click "Identify and troubleshoot risks" to go to the security scan page for the target skill. Then, follow the repair suggestions to [view and fix security scan issues](https://docs.byteplus.com/en/docs/agentkit/Viewing-and-fixing-security-scan-issues?lang=en).
