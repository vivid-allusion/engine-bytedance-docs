Skills provide a version comparison feature that allows you to compare the current version against any historical version. You can go to the skill details page to view the differences between versions and get a clear view of the specific changes.

<span id="WskZ1Ug1"></span>
## Prerequisites

A skill has been updated and published. For more information, see [Updating skills](https://docs.byteplus.com/en/docs/agentkit/Updating_Skills) and [Publishing skills](https://docs.byteplus.com/en/docs/agentkit/Publishing_Skills).

<span id="5SZfw55T"></span>
## Procedure


1. Log in to the [AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Skills Center".

3. Select "Skills  **\>**  Custom".

4. In the "Actions" column of the target skill, click the "Details" button.

5. On the skill details page, click <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_82f2c7ccb4216ac709026b8b0c79c7ea.png) </span> to enable Diff, and select a historical version to compare with the current version.

6. In the "Project files" section, click the target file to view its content changes. The system uses different colors to indicate the status of each change, making version differences easy to identify:

   * Light green: New content.

   * Dark green: Content differences between versions.

   * Red: Deleted content.
