A skill can be called or queried by agents only after it is added to a skills space. You can create a dedicated skills space as a storage container for skills to manage business capabilities by category.

## Background information

A **skills space** is a logically isolated space in AgentKit used to organize and manage multiple skill versions. Each skill can be published to multiple skills spaces. Agents discover and call skills based on the skills spaces they belong to. Spaces are isolated from each other ** and do not support direct cross\-space calls**. An agent can only use skills in its associated space and cannot directly access skills in other skills spaces.

## Prerequisites

If you want to ** add a custom skill (not a preset skill) while creating a skills space**, [create the skill](https://docs.byteplus.com/en/docs/agentkit/create_skills) in advance.

> **tip**

> You can also create a skills space without adding any skills. You can add skills to the space at any time later. For details, see [Adding/Removing skills](https://docs.byteplus.com/en/docs/agentkit/Adding_and_Removing_Skills?lang=en).
