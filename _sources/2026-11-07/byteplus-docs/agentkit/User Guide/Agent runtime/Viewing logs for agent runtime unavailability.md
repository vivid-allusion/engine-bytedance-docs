This topic describes how to view logs for agent runtime unavailability.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">When the agent runtime status is <strong>Unavailable</strong>, you can view the agent startup failure logs.</div>



1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click "Unavailable" in the "Status" column of the target agent runtime, and then click the "View log" button.

4. In the pop\-up "Agent log" dialog box, view the cause of the agent startup failure.
