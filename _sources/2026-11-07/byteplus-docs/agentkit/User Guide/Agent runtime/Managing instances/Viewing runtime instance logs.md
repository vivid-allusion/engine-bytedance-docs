Runtime instance logs record key runtime information during instance startup, initialization, task execution, and shutdown. They are useful for troubleshooting when an instance fails to start, a task encounters an error, or an instance remains in the **Starting** state for an extended period or enters the **Failed** state. 

<span id="DVhBSiGA"></span>
## Procedure


1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click the name of the target agent runtime.

4. Select the "Instance management" tab, and click the "View log" button in the "Actions" column for the target instance **.** 

5. In the instance log dialog box that appears, enter a keyword in the search box to locate the issue.
