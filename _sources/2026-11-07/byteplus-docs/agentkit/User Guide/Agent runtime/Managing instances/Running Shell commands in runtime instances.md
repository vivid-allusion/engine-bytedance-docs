This topic describes how to access the WebShell page for a runtime instance and run Shell commands in the runtime instance environment to view files, create tasks, and troubleshoot issues.

<span id="A1yAUYZ1"></span>
## Procedure


1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click the name of the target agent runtime.

4. Select the "Instance management" tab, and then click "WebShell" in the Actions column for the target instance **.** 

5. On the WebShell page, run Shell commands in the runtime instance environment to view the directories and files in the ** current ** directory, create tasks, or troubleshoot issues.
