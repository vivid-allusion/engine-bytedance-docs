Release records are used to manage all release tasks of a runtime, facilitating release traceability and auditing. This topic describes operations related to release records.

<span id="RNSZlZJ3"></span>
## View release records

You can view the release records of a runtime and the change details of each release task.


1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click the name of the target agent runtime.

4. Select "Version management \> Release history" to view the release records of the current runtime.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b480119b6235c2423c388c6e54a8b6c7.png) </span>

5. Select the target release record and click "Release ID" to view the change details of this release.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_03017c4a7d230e5e406088c373ff4d83.png) </span>
