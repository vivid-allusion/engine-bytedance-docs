After an agent runtime is created, the system automatically creates version V1. Each release creates a new version with complete and independent configurations. This topic describes how to view the version details of an agent runtime.

<span id="3B1ldcyF"></span>
## View the version list


1. Log in to the [AgentKit console](https://console.byteplus.com/agentkit).

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click the name of the target agent runtime.

4. Select "Version management \> Version information" to view all versions of the current runtime.

5. In the "Actions" column of the target version number, click "View" to view the basic information, model configuration, permission and access control, environment variable information, and associated components of the target version.

   > To use the current version, click "Roll back to this version" in the upper right corner of the page to roll back the version.   
   

<span id="GZ1hyevW"></span>
## Roll back to this version

To use a specific version, click "Roll back to this version" in the "Actions" column of the target version in the **Version information** list.
