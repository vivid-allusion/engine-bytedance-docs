<div data-tips="true" data-tips-type="warning">After you delete an agent runtime, all instances associated with the agent runtime will be automatically reclaimed simultaneously. This operation is irreversible. Proceed with caution.</div>


<span id="9gU19GYE"></span>
## Procedure


1. Log in to [the AgentKit console](https://console.byteplus.com/agentkit). 

2. In the left\-side navigation pane, select "Agent Runtime".

3. In the agent runtime list, click "More \> Delete" in the "Actions" column of the target agent runtime.

4. In the confirmation dialog box that appears, click "Delete" to complete the operation.
