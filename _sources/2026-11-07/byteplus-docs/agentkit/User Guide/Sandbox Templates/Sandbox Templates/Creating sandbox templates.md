To enable multiple agents to reuse the same runtime environment, dependency configuration, or tool capabilities, and run various AI tasks in a single comprehensive environment, you can create a sandbox template first. Then, you can use it directly when creating or managing agents. This topic describes how to create a sandbox template.

## Prerequisites

* (Optional) If you need to use TOS to store sandbox template data, confirm the following:

   * You[ have activated TOS](https://console.byteplus.com/tos).

   * You have created a TOS bucket in the region where you want to create the sandbox template. For details, see [Creating buckets](https://docs.byteplus.com/en/docs/tos/docs-create-a-bucket).

   * You have logged in to the platform console and [obtained the AK/SK](https://docs.byteplus.com/en/docs/byteplus-platform/docs-creating-an-accesskey). You can create and obtain an ** Access Key ID** and **Secret Access Key** on the [Access Key Management ](https://console.byteplus.com/iam/keymanage/)page.

* (Optional) To view the service runtime logs, make sure that [you have activated Observability Platform](https://console.byteplus.com/observe/dashboard/dashboard?).

* (Optional) To use a model from the AgentKit model service, go to the Model service console to [create a model service first](https://docs.byteplus.com/en/docs/agentkit/Creating_model_service).

* (Optional) If you need to access the sandbox template over a VPC, confirm that BytePlus VPC has been activated and that a VPC and subnet have been created in the region where you want to create the sandbox template. For more information, see [Creating VPCs](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC) and [Creating subnets](https://docs.byteplus.com/en/docs/vpc/Creating-a-subnet).

## Limits

* A sandbox template supports a maximum of 2 TOS mount points, and only TOS buckets in the same region can be mounted.

* When multiple TOS mount points are configured for the same sandbox template, you can select the same TOS bucket and specify the same bucket subdirectory, but you cannot specify the same local directory.

## Procedure

Use platform\-preset sandbox templates. The platform has preset **ArkClaw Sandbox**, **Hermes Sandbox, ** **AIO Sandbox**, **Skills Sandbox, ** **Code Sandbox** for your direct use.

1. Log in to[ the AgentKit console](https://console.byteplus.com/agentkit).

2. In the left\-side navigation pane, select "Sandbox Template".

## What to do next

After the sandbox template is created, you can test it or integrate it into your agent code. This allows the agent to invoke an isolated environment for complex tasks such as code execution and browser operations.

* **Agent integration**: After an AIO Sandbox or Skill Sandbox is created, use the integration code provided by the platform to integrate the sandbox template into your agent. When the agent processes a task and launches a sandbox instance, it uses the sandbox's code execution capability (code server) via tool calls by default. For more information, see [Integrating sandbox templates in agents](https://docs.byteplus.com/en/docs/agentkit/Integrating_tools_in_agent).

* **Manual testing**: After the sandbox template is created, you can manually create a sandbox instance based on the template configuration. Obtain the public network access URL or WebChat URL of the sandbox instance. Then enter the instance to perform troubleshooting, testing, and other operations. For more information, see [Creating sandbox instances](https://docs.byteplus.com/en/docs/agentkit/Creating_tool_instances).
