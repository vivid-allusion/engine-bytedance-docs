Shared public network access controls whether a sandbox instance can access external networks through shared public network egress. When private network access is configured for a sandbox template, you can use this feature to enable or disable shared public network egress to meet network access and security requirements in different scenarios. This topic describes how to enable or disable shared public network access.

## Prerequisites

**Private network access** has been configured for the sandbox template. Shared public network access can be enabled or disabled only for sandbox templates with private network access configuration.

## Procedure

1. Log in to the [AgentKit console](https://console.byteplus.com/agentkit).

2. In the left\-side navigation pane, select "Sandbox Template".

3. In the "Sandbox templates" list, click the target template name. In the "Network configuration" section of the "Configuration information" tab, find the shared public network access setting and click ![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1a5bf12c121e79c81297d621ca1c2dd4.png) **.**

   > For detailed parameter descriptions, refer to [Creating sandbox templates](https://docs.byteplus.com/en/docs/agentkit/Creating_tools).

4. In the pop\-up dialog box, enable or disable shared public network egress to complete the operation.
