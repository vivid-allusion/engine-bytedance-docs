This topic uses [VeADK](https://docs.veadk.xyz/productions/veadk/preview/en) as an example to describe how to integrate preset Skills in agent code.

## Prerequisites

* Python 3.10 or later is installed.

* You have [created a Skills Sandbox template ](https://docs.byteplus.com/en/docs/agentkit/Creating_tools)and obtained the tool ID.

* You have created and obtained an **Access Key ID** and a **Secret Access Key**. For detailed instructions, see [Obtaining AK/SK](https://docs.byteplus.com/en/docs/byteplus-platform/docs-creating-an-accesskey).

## Procedure

1. Configure environment variables.

   ```Bash
   export BYTEPLUS_ACCESS_KEY=<your_access_key>
   export BYTEPLUS_SECRET_KEY=<your_secret_key>
   # The Tool ID of the Skills Sandbox created on the AgentKit platform.
   export AGENTKIT_TOOL_ID=t-yebe3edjwgntl8dn****
   ```

2. Install Python dependencies.

   ```Bash
   pip install --upgrade veadk-python
   ```

3. Integration example.

   ```Python
   from veadk import Agent, Runner
   from veadk.tools.builtin_tools.execute_skills import execute_skills
   
   root_agent = Agent(
       name="skill_agent",
       instruction="Call the execute_skills tool to execute the skills based on user needs.",
       tools=[execute_skills],
   )
   
   runner = Runner(agent=root_agent)
   
   async def main(prompt: str) -> str:
       response = await runner.run(messages=prompt)
       return response
   
   if __name__ == "__main__":
       import asyncio
   
       # Use the built-in skill-creator Skill to implement a simple PDF processing Skill
       your_bucket_name = "agentkit-platform-xxxx" # Use the TOS bucket auto-generated by Agentkit, in the format agentkit-platform-xxxx*
       user_input = f"""
   Run the following workflow:
   1. Use the skill-creator skill to help me write a simple PDF processing skill that only needs to support PDF loading and editing.
   2. Use the tos-file-access skill to upload the directory storing the written skill to the {your_bucket_name} bucket.
   """
   
       response = asyncio.run(main(user_input))
       print(response)
   ```

## What to do next

After local development and testing are complete, you can deploy the tool\-integrated agent to the agent runtime. For operation details, see [the guide on deploying an agent to the cloud-based production environment](https://docs.byteplus.com/en/docs/agentkit/Code_sandbox_tool_example#mBP3N57n).
