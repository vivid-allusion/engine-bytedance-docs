This topic uses [VeADK](https://docs.veadk.xyz/productions/veadk/preview/en) as an example to describe how to use custom skills in an agent.

## Prerequisites

* Python 3.10 or later is installed.

* You [have created a Skills Sandbox template](https://docs.byteplus.com/en/docs/agentkit/Creating_tools) and obtained the tool ID.

* You have created and obtained an **Access Key ID ** and ** a Secret Access Key**. For detailed instructions, see [Obtaining AK/SK](https://docs.byteplus.com/en/docs/byteplus-platform/docs-creating-an-accesskey).

* Replace` your_bucket_name` with the name of the TOS bucket that AgentKit creates for you by default. The naming format is `agentkit-platform-{your_account_id}`. If a TOS bucket with this name does not exist, create one based on this format.

* Within the TOS bucket named `agentkit-platform-{your_account_id}`, create a new folder for skills and upload the required skills to this folder.

* To use custom skills to complete a task, modify only the `user_input `part in the code example to specify the name of the custom skill and the corresponding task.

## Sample code

```Bash
from veadk import Agent, Runner
from veadk.tools.builtin_tools.execute_skills import execute_skills

root_agent = Agent(
    name="skill_agent",
    instruction="Call the execute_skills tool to execute the skills based on user needs.",
    tools=[execute_skills],
)

runner = Runner(agent=root_agent)

async def main(prompt: str) -> str:
    response = await runner.run(messages=prompt)
    return response

if __name__ == "__main__":
    import asyncio

    # In this example, the customer has uploaded a custom Skill named healthy-meal-planner Skill and uses it with the pre-configured tos-file-access Skill to handle recipe recommendation tasks
    your_bucket_name = "xxx" # Use the TOS bucket auto-generated by Agentkit, in the format agentkit-platform-*
    user_input = f"""
Run the following workflow: 1. I need a plant-based high-protein recipe for 2 people with the goal of muscle gain. The weekly budget is USD 350, and I prefer quick and easy dishes that can be made within 30 minutes. I do not like mushrooms. Use the healthy-meal-planner skill to create a one-week meal plan for me. 2. Write the created meal plan into the recipe.md file, use the tos-file-access skill to upload this file to the {YOUR_TOS_BUCKET_NAME} bucket, and then send me the link of the uploaded file.
"""

    response = asyncio.run(main(user_input))
    print(response)
```
