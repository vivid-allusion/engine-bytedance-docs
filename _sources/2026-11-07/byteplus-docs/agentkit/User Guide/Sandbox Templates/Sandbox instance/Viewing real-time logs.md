Real\-time logs allow you to view the standard output and standard error generated by a sandbox instance during runtime. You can use real\-time logs to troubleshoot instance issues, monitor task execution status, or debug applications running inside sandboxes. This topic describes how to view sandbox instance logs.

## Procedure

1. Log in to[ the AgentKit console](https://console.byteplus.com/agentkit).

2. In the left navigation pane, click "Sandbox Templates". Click the target tool name, and on the "Log" tab, view the real\-time logs of the instance.

3. To perform more detailed log analysis, you can use the [observability service](https://docs.byteplus.com/en/docs/agentkit/Observability_overview) to view monitoring metrics and historical logs. If an instance is abnormal, you can extend its lifetime by [updating its lifecycle](https://docs.byteplus.com/en/docs/agentkit/Modify_the_lifecycle_duration_of_a_tool_instance?lang=en) to troubleshoot the issue, or [delete the tool instance](https://docs.byteplus.com/en/docs/agentkit/Delete_a_tool_instance?lang=en) to release resources.
