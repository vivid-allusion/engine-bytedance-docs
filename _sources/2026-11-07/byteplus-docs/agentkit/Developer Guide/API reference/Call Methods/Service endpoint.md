For lower latency, we recommend that you select the appropriate service endpoint based on the region where your resource is located.


|**Region name** ||**Region ID** |**Service endpoint** |
|---|---|---|---|
|Other regions |Asia Pacific (Johor) |ap\-southeast\-1 |`IPv4`https://agentkit.ap\-southeast\-1.byteplusapi.com |


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">For latency\-sensitive businesses, it is recommended to specify the region in the request header. For more information, refer to <a href="https://docs.byteplus.com/en/docs/agentkit/Common_parameters">Common parameters</a>.</div>


* <div data-tips="true" data-tips-type="default">The domain name is the access point of the API and does not represent the region where the product provides services.</div>
