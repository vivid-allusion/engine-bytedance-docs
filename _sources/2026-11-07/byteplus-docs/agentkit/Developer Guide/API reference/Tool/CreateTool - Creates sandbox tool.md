You can call this operation to create a sandbox tool. For operation instructions and precautions, refer to [Creating sandbox tool](https://docs.byteplus.com/en/docs/agentkit/Creating_tools).

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters

Only the request parameters specific to this operation and some common parameters are listed below. For more information, refer to [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action ** <span data-label="purple">string </span><span data-api-tag="require|PQMGZx">必选</span> `Sample value: CreateTool`

The action that you want to perform. Value: CreateTool.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|Dj9gK1">必选</span> `Sample value: 2025-10-30`

The API version. Value: 2025\-10\-30.



**AuthorizerConfiguration.KeyAuth.ApiKey ** <span data-label="purple">string </span>`Optional Sample value: 22243eefff**`

The value of the passed API Key when API Key is used for inbound identity authentication. This parameter can be empty. If this parameter is left empty, a random string will be generated by default. Users must provide this key to access the runtime.



**ApmplusEnable**<span data-label="purple"> boolean</span>` Optional Sample value: true`

Whether to enable TLS. Valid values:


* true (default): Enable.

* false: Disabled.



**Description ** <span data-label="purple">string </span>`Optional Sample value: this is a tool`

Tool description. Value:


* The text length can not exceed 200 Unicode characters.

* If left blank, the parameter defaults to an empty value.



**AuthorizerConfiguration.KeyAuth.ApiKeyLocation**<span data-label="purple"> string </span>`Optional Sample value: Header`

The location where the API Key is passed when API Key is used for inbound identity authentication.


* Header: Currently, only Header is supported.



**Name ** <span data-label="purple">string </span><span data-api-tag="require|N5JfNx">必选</span> `Sample value: tool-test`

The name of the tool. Value:


* Can contain uppercase and lowercase English letters, numbers, hyphens (\-), and underscores (_).

* Length limit: 4–64 characters.



**AuthorizerConfiguration.KeyAuth.ApiKeyName**<span data-label="purple"> string</span>` Optional Sample value: test-key`

The name of the passed API Key when API Key is used for inbound identity authentication. Valid values:


* When this parameter is passed in, it cannot be empty. The parameter value is a string containing 4 to 64 characters.

* Consists of letters, numbers, hyphens (\-), and underscores (_).



**ToolType ** <span data-label="purple">string </span><span data-api-tag="require|EV2Bem">必选</span> `Sample value: All-in-one`

Tool type. Valid values:


* All\-in\-one: An integrated toolset, i.e., the preset tool AIO Sandbox.

* Skill: Skill tool image, which is the preset tool Skills Sandbox.

* Private: Custom tool.

* CodeEnv: preset tool Code Sandbox.



**Command ** <span data-label="purple">string </span>`optional` `Sample value: ./run.sh`

The command to start the tool.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When <code>ToolType</code> is set to Private, you need to configure this parameter. Default value: ./run.sh.</div>




**NetworkConfiguration.EnablePrivateNetwork ** <span data-label="purple">boolean </span>`Optional Sample value: false`

Whether to enable private network access for the tool. Value:


* true: Enabled.

* false (default): Disabled.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">One of the <code>EnablePrivateNetwork</code> or <code>EnablePublicNetwork</code> parameters must be provided.</div>




**CpuMilli ** <span data-label="purple">integer </span>`Optional` `Sample value: 2000`

The vCPU specification of the instance. Unit: milli cpu.


* All\-in\-one and Skill: 2000



**NetworkConfiguration.EnablePublicNetwork ** <span data-label="purple">boolean </span>`Optional Sample value: true`

Whether to enable the tool's public network access capability. Values:


* true: Enabled.

* false (default): Disabled.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">One of the <code>EnablePrivateNetwork</code> or <code>EnablePublicNetwork</code> parameters must be provided.</div>




**Envs.N.Key ** <span data-label="purple">string[] </span><span data-api-tag="require|hpQ7Qn">必选</span> `Sample value: Envs.1.Key=k1`

The key of the tool's environment variable.


* Parameter \- N: Specifies the serial number of the environment variable. Valid value: 1\-30.

* Value: Can only contain letters, numbers, and underscores, and start with an underscore or a letter. The length is 1 to 63 characters.



**NetworkConfiguration.VpcConfiguration.VpcId ** <span data-label="purple">string </span><span data-api-tag="require|5C900P">必选</span> `Sample value: vpc-257gqcdfvx6n****`

VPC ID.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Required when <code>NetworkConfiguration.EnablePrivateNetwork</code> is set to true.</div>




**Envs.N.Value ** <span data-label="purple">string[] </span>`Optional` `Sample value: Envs.1.Value=v1`

The value of the tool's environment variable.


* Parameter \- N: Specifies the serial number of the environment variable. Valid value: 1\-30.



**NetworkConfiguration.VpcConfiguration.SecurityGroupIds.N ** <span data-label="purple">string[] </span>`Optional Sample value: SecurityGroupIds.1=sg-w08tvkc3e****`

List of security group IDs.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This parameter is required when <code>EnablePrivateNetwork</code> is set to true.</div>




**ImageUrl ** <span data-label="purple">string </span>`Optional` `Sample value: http://***`

The tool image URL.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Required when <code>ToolType</code> is set to Private.</div>




**EnableSnapshot ** <span data-label="purple">boolean </span>`Optional` `Sample value: true`

Whether to automatically create a snapshot before the instance expires.

**NetworkConfiguration.VpcConfiguration.SubnetIds.N ** <span data-label="purple">string[] </span>`Optional Sample value: SubnetIds.1=subnet-ye7s6jatq8rxg218****`

Subnet ID list. Only one Subnet ID can be specified for each availability zone.


* Parameter N: Value range: 1\-5.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This parameter is required when <code>EnablePrivateNetwork</code> is set to true.</div>




**ProjectName ** <span data-label="purple">string </span>`Optional` `Sample value: default`

The name of the associated project.



**MemoryMb ** <span data-label="purple">integer </span>`Optional` `Sample value: 550`

**RoleName**<span data-label="purple"> string </span>`Optional Sample value: AgentKit-Runtime-Default-ServiceRole-xbv8s36`

The name of the IAM role associated with the tool.



**ModelAgentName ** <span data-label="purple">string </span>`Optional` `Sample value: doubao-seed-1.6`

The access point for the inference model.



**Tags.N.Key ** <span data-label="purple">string[] </span><span data-api-tag="require|tWBcXw">必选</span> `Sample value: Tags.1.Key=k1`

The key of the tag associated with the resource.


* Parameter \- N: Indicates the serial number of the tag key. Valid range: 1–20.

* Separate multiple tag keys with ampersands (&).


Naming rules:


* It cannot start with` volc: `or `sys:` in any case form.

> Tag keys that start with `volc:` or `sys: `are reserved for the system. You cannot create tags starting with them.


* Only letters, digits, spaces, and the following symbols are allowed: "_", ".", ":", "/", "=", "+", "\-", and "@".

* It must be 1 to 128 characters in length.



**Tags.N.Value**<span data-label="purple"> string[] </span>`Optional` `Sample value: Tags.1.Value=v1`

The value of the tag associated with the resource.


* Parameter \- N: specifies the serial number of the tag value. Valid range: 1–20.

* Separate multiple tag values with &.


Naming rules:


* Only letters, digits, spaces, and the following symbols are allowed: "_", ".", ":", "/", "=", "+", "\-", and "@".

* It can be empty. Length limit: 0\-256 characters.



**NetworkConfiguration.VpcConfiguration.EnableSharedInternetAccess ** <span data-label="purple">boolean </span>`Optional` `Sample value: true`

The public network egress configuration. Valid values:


* true (default): Enabled. This value indicates that the tool uses the public network egress provided by the platform to access the public network.

* false: Not enabled. This value indicates that the tool uses the public network NAT gateway egress configured in the private network to access the public network.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This parameter is valid only when <code>NetworkConfiguration.EnablePrivateNetwork</code> is set to true.</div>
