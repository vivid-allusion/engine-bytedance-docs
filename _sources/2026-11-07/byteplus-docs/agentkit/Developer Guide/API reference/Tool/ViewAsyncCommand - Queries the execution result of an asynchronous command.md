Obtain the execution status, output, and exit code of the asynchronous task started by [AsyncExecCommand](https://docs.byteplus.com/en/docs/agentkit/AsyncExecCommand_-_Asynchronously_executes_a_Shell_command_in_a_tool).

<span id="ah5s5S17"></span>
## Instruction

We recommend that you call this operation in polling mode until the task status changes to Succeeded or Failed.

**Polling policy**: We recommend that you set an appropriate polling interval (such as 1–3 seconds), and set the maximum number of queries or a timeout period to prevent infinite polling.

<span id="34yev54X"></span>

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>

Use the region\-specific service address <code>https://agentkit.ap-southeast-1.bytepluses.com</code>.</div>

## Request parameters

Only the request parameters specific to this operation and some common parameters are listed below. For more information, refer to [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).


|**Parameter​**  |**Type** |**Required** |**Sample value** |**Description** |
|---|---|---|---|---|
|ToolId |String |Yes |t\-yebi0bt\*\*\*\* |Tool ID. |
|TaskId |String |Yes |task\-e8a4g\*\*\*\* |The ID of the asynchronous task to query, sourced from the response of the [AsyncExecCommand](https://docs.byteplus.com/en/docs/agentkit/AsyncExecCommand_-_Asynchronously_executes_a_Shell_command_in_a_tool) operation. |
|UserSessionId |String |No |s\-yecrbt\*\*\*\* |Specifies the session ID for the request execution. We recommend that you keep it consistent with the corresponding [AsyncExecCommand](https://docs.byteplus.com/en/docs/agentkit/AsyncExecCommand_-_Asynchronously_executes_a_Shell_command_in_a_tool) call. |
|SessionId |String |No |Specifies the session ID for the request execution. |Specify the user session information of the execution request. We recommend that you keep it consistent with the corresponding [AsyncExecCommand](https://docs.byteplus.com/en/docs/agentkit/AsyncExecCommand_-_Asynchronously_executes_a_Shell_command_in_a_tool) call. |
|Ttl |Integer |No |1,800 |The time to live (TTL) of the sandbox instance, in seconds.<br><br><br>* Unit: second.<br><br>* Value range: 60–86400.<br><br>* Default value: 1800. |

## Response parameters

Only the response parameters specific to this operation are listed below. For more information, refer to the [response structure](https://docs.byteplus.com/en/docs/byteplus-platform/reference-request-response).


|**Parameter​**  |**Type** |**Sample value** |**Description** |
|---|---|---|---|
|ToolId |String |t\-yebi0bt\*\*\*\* |The tool ID. |
|UserSessionId |String |session\-1 |The user session information of the execution request. |
|SessionId |String |s\-yecrbt\*\*\*\* |The session ID for the execution request. |
|TaskId |String |task\-e8a4g\*\*\*\* |The task ID for this asynchronous execution. |
|Status |String |Succeeded |The current status of the task. Valid values:<br><br><br>* Running: The command is still executing.<br><br>* Succeeded: The command was executed successfully.<br><br>* Failed: The command execution failed.<br><br>* Unknown: The task status is unknown. The task ID may not exist or may have expired. |
|Output |String |Hello, World!\n |The combined content of standard output (stdout) and standard error output (stderr) generated by the command. |
|Command |String |sleep 5 && echo 'Hello, World!' |The Shell command executed. |
|ExitCode |Integer |0 |The exit code after command execution. Valid values:<br><br><br>* 0: The command was executed successfully.<br><br>* Non\-zero: An error occurred during command execution. The specific value depends on the executed command and program.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">This field is meaningless when Running is returned for <code>Status</code>.</div><br> |

## Sample request

```JSON
POST https://agentkit.ap-southeast-1.bytepluses.com?Action=ViewAsyncCommand&Version=2025-10-30 HTTP/1.1
Content-Type: application/json

{
    "ToolId": "t-yebi0bt****",
    "UserSessionId": "session-1",
    "TaskId": "task-e8a4g****"
}
```
