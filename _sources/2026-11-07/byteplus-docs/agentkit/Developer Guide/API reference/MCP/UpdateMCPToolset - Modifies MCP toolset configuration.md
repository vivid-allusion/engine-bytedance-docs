You can call this operation to modify MCP toolset configuration.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters

Only the request parameters specific to this operation and some common parameters are listed below. For more information, refer to [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action**<span data-label="purple"> string </span><span data-api-tag="require|QXqgvk">必选</span> `Sample value: UpdateMCPToolset`

The action that you want to perform. Value: UpdateMCPToolset.



**Version ** <span data-label="purple">string </span><span data-api-tag="require|fCbrQm">必选</span>`Sample value: 2025-10-30`

The API version. Value: 2025\-10\-30.



**AuthorizerConfiguration.Authorizer.KeyAuth.ApiKeyLocation**<span data-label="purple"> string </span>`Optional Sample value: HEADER`

The location where the API Key is passed when API Key is used for inbound identity authentication. Valid values:


* HEADER: Currently, only Header is supported.



**AuthorizerConfiguration.Authorizer.CustomJwtAuthorizer.DiscoveryUrl ** <span data-label="purple">string </span><span data-api-tag="require|k5B2Le">必选</span> `Sample value: -`

Default parameter description



**AuthorizerConfiguration.Authorizer.KeyAuth.ApiKeys.N.Name**<span data-label="purple"> string[] </span><span data-api-tag="require|U5wZvc">必选</span> `Sample value: ark-authkey`

The name of the passed API Key when API Key is used for inbound identity authentication.


* Parameter \- N: Indicates the serial number of the APIKey name. Value range: 1\-5.

* Separate multiple field names with ampersands (&).

* A string of 4 to 64 characters.

* Consists of letters, numbers, hyphens (\-), and underscores (_).



**AuthorizerConfiguration.Authorizer.CustomJwtAuthorizer.AllowedClients.N ** <span data-label="purple">string[] </span>`Optional` `Sample value: -`

Default parameter description



**AuthorizerConfiguration.Authorizer.KeyAuth.ApiKeys.N.Key**<span data-label="purple"> string[] </span>`Optional Sample value: 8b02f2e2-ae83-11f0-b6e5-******`

The value of the passed API Key when API Key is used for inbound identity authentication.


* Parameter \- N: Indicates the serial number of the APIKey value. Value range: 1\-5.

* Separate multiple field names with ampersands (&).

* If not specified, a random string is generated by default.



**AuthorizerConfiguration.Authorizer.KeyAuth.Parameter ** <span data-label="purple">string</span>` Optional Sample value: Authorization`

The name of the Header that carries the APIKey required for inbound authentication when API Key is used for inbound identity authentication to access the MCP toolset.



**AuthorizerConfiguration.AuthorizerType ** <span data-label="purple">string </span><span data-api-tag="require|I7yYYX">必选</span> `Sample value: ApiKey`

Authentication type used when the MCP service accesses the backend service. Value:


* ApiKey: Currently, only API Key is supported.



**ClientToken ** <span data-label="purple">string</span>` Optional Sample value: 65a075a2-aeff-11f0-****-00163e72f914`

The ClientToken is used to ensure request idempotency. The client can automatically generate a token, but you need to ensure that it is unique across requests. This prevents duplicate operations caused by multiple retries when the API request times out or an internal server error occurs.

Value: Only ASCII characters are supported. The length is no more than 64 ASCII characters.



**MCPServiceIds.N ** <span data-label="purple">string[] </span>`Optional Sample value: m-ye7f4f7gu8q7oi5cu***`

MCP service.


* Parameter \- N: Indicates the serial number of the MCP service. Value range: 1–100.

* Separate multiple field names with ampersands (&).



**MCPToolsetId ** <span data-label="purple">string </span><span data-api-tag="require|K2yr5d">必选</span> `Sample value: mt-ye7f6gd7nktv3gi6c***`

MCP toolset ID.



**MCPServices.N.IsAllTools ** <span data-label="purple">boolean[]  </span><span data-api-tag="require|e0V2Bi">必选</span>`Sample value: true`

Whether the toolset includes all tools under the MCP services.



**MCPServices.N.MCPServiceId**<span data-label="purple"> string[]</span><span data-api-tag="require|HTc2Bg">必选</span>  `Sample value: m-ye7f6gd7nktv3gi6c***`

MCP service ID.



**MCPServices.N.MCPTools.N.Name**<span data-label="purple"> string[]</span>  <span data-api-tag="require|BK1n6V">必选</span>`Sample value: add-comments`

Name of the MCP tool.



**MCPServices.N.MCPTools.N.Description ** <span data-label="purple">string[] </span>`Optional` `Sample value: add comments`

Description of the MCP tool.



**MCPServices.N.MCPTools.N.Tags.N ** <span data-label="purple">string[] </span>`Optional` `Sample value: 1`

Tags of MCP tools.



**Mode ** <span data-label="purple">string </span>`Optional` `Sample value: AllTools`

The retrieval mode used to call tools from the toolset.


* AllTools: Return all tools.

* SemanticSearch: Semantic retrieval. Match tools based on semantics.

* TagSearch: Tag retrieval. Accurately search for tools by tag.
