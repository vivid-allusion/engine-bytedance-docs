## Which programming languages do sandbox tools support?

Currently, only mainstream languages are supported, such as Python3 and Node.js.

<span id="fpGUg8d0"></span>
## Will data be retained after the lifecycle of the associated instance expires?

No. After the lifecycle expires, the tool instance and all its data will be cleared. A new instance will be created for subsequent requests.

<span id="oZCTVlQe"></span>
## Which tools are supported by sandbox tools?

Preset tools, including AIO Sandbox and Skills Sandbox, and custom tools, are provided. For more information, refer to [Sandbox tool overview](https://docs.byteplus.com/en/docs/agentkit/Tool_overview).
