If the current specifications of your dedicated gateway instance cannot meet your application requirements, you can upgrade or downgrade the instance configuration.

Real\-time upgrades and downgrades are available for dedicated gateway instances. After the change, the new instance configuration remains in effect until the next change or until the resource is released.


* Upgrade: The listed price of the new configuration (hourly listed price) ≥ the listed price of the original configuration (hourly listed price).

* Downgrade: The listed price of the new configuration (hourly rate) < the listed price of the original configuration (hourly listed price).


<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Upon successful change, the platform generates a "Change config" order to indicate the successful configuration change. Then, the instance starts running with the new configuration.</div>



|Module |Pay\-as\-you\-go |
|---|---|
|Billing rules |The configuration change cost is based on the current price of the target specification. Charges are settled in real time based on the actual configuration change. The actual charge depends on the actual configuration change (coupons can be used for deductions). |
|Operation guide |Refer to [Changing gateway instance specifications](https://docs.byteplus.com/en/docs/agentkit/Changing_gateway_instance_specifications). |
|Billing |The fees displayed in the console shall prevail. |
|Effective time |After the action succeeds, the system immediately restarts, and the new configuration takes effect in real time. |
