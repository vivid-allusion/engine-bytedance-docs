Users need to register the data sources required for subsequent tagging, audience targeting, and insights in this module, currently supporting user attribute data, detailed data, and behavioral data.

<span id="_1-数据集开发"></span>
# 1. Data Set Development


1. Hover over the **Data Fusion** module, and select **Visual Modeling** from the pop\-up menu.

2. After entering the visual modeling page, click on the top left **New**, choose **New Folder**, and create a folder named "User Attribute Task".

3. Click on the right side of the folder, select **New Task**, enter the task name "User Basic Attributes" in the popup window, click OK to create a new task.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_5d67f0036a70f9a7bbba5a3b32ae3779.png) </span>


4. Click on the right side of the data connection "+", choose the data source, add a data connection, drag the table "user_profile" from the left directory to the canvas. Subsequent steps are consistent with the third article on visual modeling.

5. Click on the "+" on the right side of the operator, select the "Offline ID Mapping" operator from the operator list, and configure the IDM association information.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c0acaa849c7b77df722943bc38ac829b.png) </span>


6. Under the output, select the "Output" operator, rename the operator name to the output dataset name **Attribute_User Basic Attributes_Offline_CK**, then create a new dataset.

   1. The lifecycle is configured based on the actual environment, defaulting to 7 days.

   2. For dataset segmentation and sampling field selection, the base_id is confirmed to be of type long.

   3. The partition field is selected as p_date, confirmed to be of type date.

   4. After selection, click the "Confirm" button to save.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_22d5e789ad102099b00b90bafdc405ec.png) </span>


7. After verifying, click the **Save** button in the top right corner to save the task. After successful saving, click the  **<**  button in the top left corner to exit the task canvas.


<span id="_2-元数据配置"></span>
# 2. Metadata Configuration


1. Hover over the **Data Fusion** module, and select **Metadata Management** from the menu that pops up.

2. After entering the metadata page, select **Data Source,**  click on **Create New Data Source** in the top left corner to enter the configuration page.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1eefc523a85a6e37ae2950e2be417644.png) </span>


3. In the configuration page, enter the data source name and description information. Select the dataset "Attribute_User Attribute Data Set_Offline_CK" in the dataset, check for accuracy, and then click the "Apply This Table" button.


Note: Version 1.15 added metadata lifecycle settings. This configuration value will intersect with the dataset's lifecycle based on the actual project situation.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_6d8c4a9fce47c493163ae35493f9b7cb.png) </span>


4. Wait for the system to successfully create the table and proceed with the next configuration. After confirming the accuracy, click the "Save" button to exit the configuration page.

   1. Choose the data table type: Attribute Data.

   2. Select the associated entity: Subject 1/Person (selected based on the entity name when constructing the ID graph, which here is "Person").

   3. ID type: in the attribute data set, select the ID used to identify users and choose the base ID.

   4. Corresponding base ID field: base_id field.

> Note: the ID type here is consistent with the ID type used in constructing the ID graph. When generating the data table, pay attention to the data type of the ID in the table, which should be consistent with the data type (numeric, character) of the ID in the ID graph construction, to be able to search in "corresponding type".


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_61737219b906f0aeea288289c0f5e864.png) </span>


5. You can see the **User Attributes** just configured in the data source list. Hover over the **data production task** to view the corresponding scheduled task.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_100c0a8766f7bd09d7ad6fe9f163819a.png) </span>


6. Batch upload attribute names, click on the menu **Subject Attributes**, and then click on the **Display Name Batch Upload** button.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b267b319fa4c83e95da017783b6d69f6.png) </span>


7. Download the template, make the required modifications, click on upload, select the modified file, and click save.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_335bfaeeb09e7fde2db625612152331a.png) </span>Sample data:


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_6cf01ea00b01ed93682ba97546511349.png) </span>


8. After saving, check the upload results, and the display name will be successfully changed.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_0f76d7213faee98cd9b011bf2b8c94d8.png) </span>After completing the above settings, you can build the labeling system, select the target audience package, analyze group portraits, and perform other operations in the system.
