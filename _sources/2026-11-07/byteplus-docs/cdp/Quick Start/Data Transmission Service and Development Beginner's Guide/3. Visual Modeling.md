<div data-tips="true" data-tips-type="tip">In CDP's visual modeling, we provide you with built\-in lightweight data cleaning and visual modeling functions.</div>


<div data-tips="true" data-tips-type="tip">You can easily filter, deduplicate, replace data, ensuring accuracy and consistency. After data cleaning, you can output the cleansed data to databases like Hive, Clickhouse, or directly output as labels for future use.</div>


<div data-tips="true" data-tips-type="tip">:::Since the original data cannot be directly used after accessing CDP, next we need to edit the data source and clean the data.</div>


<div data-tips="true" data-tips-type="tip">In this section, we will create a data source partitioned "by day" through visual modeling. Each partition will contain complete original data for building the latest labels daily. From data source editing to cleaning to partition building, let's get started~</div>


<span id="_1-创建任务"></span>
# <div data-tips="true" data-tips-type="tip">1. Create Task</div>



1. <div data-tips="true" data-tips-type="tip">Hover over the <strong>Data Integration</strong> module, and select <strong>Visual Modeling</strong> from the pop\-up menu.</div>


2. <div data-tips="true" data-tips-type="tip">After entering the visual modeling page, click on <strong>new,</strong> select <strong>create a new folder</strong>, and create a folder named "IDMapping Pre\-Task".</div>

3. <div data-tips="true" data-tips-type="tip">Click on the right side of the folder, select <strong>create a new task</strong>, enter the task name "UserID_IDMapping" in the pop\-up window, click OK to create a new task.</div>



<div data-tips="true" data-tips-type="tip"><img src="https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b67a3e8d3b0d69e9974173e71e1c251b.png" width="2878px" /></div>


<div data-tips="true" data-tips-type="tip"><img src="https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_bcfbffd4ddaad1adbcadc56513d7988b.png" width="1104px" /></div>


<span id="_2-添加数据连接和节点数据"></span>
# <div data-tips="true" data-tips-type="tip">2. Adding data connections and node data</div>


<div data-tips="true" data-tips-type="tip">Once the task is successfully created, the system will automatically open the task canvas.</div>



1. <div data-tips="true" data-tips-type="tip">Click the "<strong>+</strong>" button next to the data connection to open the dialog and select the previously created <strong>data connection</strong>.</div>



<div data-tips="true" data-tips-type="tip"><img src="https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c4ad9fa4624aca02477aa58716f52150.png" width="2878px" /></div>



2. <div data-tips="true" data-tips-type="tip">In the left directory panel, expand the "test_data" folder that was just uploaded, locate the table "user_profile," left\-click on the table, drag it directly onto the canvas to add input node data.</div>



<div data-tips="true" data-tips-type="tip"><img src="https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_74039a8ad7b887027b1a6cbd802cbd2a.png" width="2878px" /></div>



3. <div data-tips="true" data-tips-type="tip">Click the <strong>Run</strong> button in the lower right corner, wait for the execution to be successful, then click <strong>Preview Exploration</strong> to see the table structure.</div>


4. <div data-tips="true" data-tips-type="tip">Click on the Data Preview button on the right to toggle detailed data and observe the data content after execution. The amount of data reviewed by the platform by default is "10000", which can be modified in the operator setting panel.</div>

<span id="_3-添加算子"></span>
# <div data-tips="true" data-tips-type="tip">3. Add Operator</div>


<div data-tips="true" data-tips-type="tip">tip</div>


<div data-tips="true" data-tips-type="tip">Data cleansing execution</div>



1. Click "+"" on the right side of the node, select Compute Column in the popped\-up operator list, and add a data cleansing operator.

2. Double\-click on the operator name and rename it to "Add Partition Date".


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8f37f6969485dd1a4891e43ee900c841.png) </span>


3. In the operator's configuration panel, configure the expression:

   1. Enter the field name "p_date" in Compute Col**p_date" in Compute Column Details**, and select the field type as "**string**".

   2. In the search bar on the right side of the panel under **Common Functions**, enter "TASK", double\-click on " **{TASK_DATE}** ", and the corresponding content will be filled in the input box on the left side of the expression.

   3. Click the **Confirm** button to complete the addition of this operator.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1e65aa4a094db50ccc27872bec6fca5c.png) </span>

<span id="_4-输出数据集"></span>
# 4. Output Dataset

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Save data to dataset</div>



1. Click " **+** "" on the right side of the "Add Partition Date" operator, select **Output** in the popped\-up operator list, and add an output operator.

2. Double\-click on the operator name and rename it to "IDMapping_UserID_Offline_HIVE".


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_7012ceec75c2907246882ee036da6f2c.png) </span>


3. Click on **Add Dataset** in the operator configuration panel to configure a new data source.

   1. Input Data Set Name: IDMapping_UserID_Offline_HIVE

   2. Add Description: Created by: demo; Created on: 20xx\-xx\-xx

   3. Set Open Project: Select "Default Project" or the newly created project

   4. Type: Hive

   5. Lifecycle Days: 7 days

   6. Partition Field: p_date

4. Click the **Confirm** button in the lower right corner after completion to save the dataset.

5. Wait for the platform to create the corresponding data table; do not close the popup window. The popup window will automatically close after successful dataset creation.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_eb265b58beb900f471b05e578c242466.png) </span>

<span id="_5-任务运行配置"></span>
# 5. Task Execution Configuration


1. Click on the upper right **Run** button to configure the task run type and frequency.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ba761de65a18e4cfbf14af4ce84f8c14.png) </span>


2. After verifying, click on the **Save** button in the top right corner to save the task. After saving successfully, click the  **<**  button in the upper left corner to exit the task canvas.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_3f869423ea672aa0eae708c16ef1e040.png) </span>


3. On the task overview page, you can view the processing flow, data preview, and operation records.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b84521c1b7a1f14146d7678e72077762.png) </span>


4. Enter the **Run Records** tab to view the task's running frequency and running history. Click the **Run** button on the right side, select the date range to run the modeling task, and confirm in the pop\-up window.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f38225e0c73bf56b4c9509428ebca426.png) </span>


5. The operation log page will record all operation history, refreshing the page or switching tabs will refresh the operation record. Observe and wait for the operation status to update to **successful execution**, at this point, the task is completed.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_63c754503c07bfd52895686a1c381fa9.png) </span>

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_69ebb53abc350f05f06d89b91c0a50db.png) </span>
