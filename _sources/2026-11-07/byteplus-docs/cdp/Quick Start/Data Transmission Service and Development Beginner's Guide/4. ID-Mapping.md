<div data-tips="true" data-tips-type="tip">The ID Graph Construction function can link fragmented data of multiple accounts of the same user based on user IDs, phone numbers, device IDs, and other ID information.</div>


<span id="_1-新建-id-类型"></span>
# 1. New ID Types


1. Hover over the **Data Fusion** module, select **ID Graph Construction** from the pop\-up menu.

2. After entering the ID Graph Construction page, click the **Configure** button in the upper left corner.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f9679fc2d0394ec61778e93f4dc8d281.png) </span>


3. On the configuration page, click the **New ID Type** button.

4. In the newly added **Unnamed ID Type**, fill in the ID type information:

   1. Basic ID type information:

      * ID Name: User ID

      * ID Identification Code: user_id

      * ID data type: Character type

      * Channel Identification: PrivateID

   2. Configure all ID data:

      * Is Data Configured: Yes

      * Data Source: Offline + Real\-time

      * Dataset: IDMapping_UserID_Offline_HIVE (dataset created by pre\-task)

      * Update Method: Full

      * Field Corresponding to ID Type: user_id (field corresponding to User ID in the dataset)

      * Date Partition Field: p_date

      * Date Partition Format: yyy\-MM\-dd


Click the **Save** button above after completion to add a new job of the user ID type.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_a7fe043353d2d9fc78355d72d57b886b.png) </span>


5. Perform the same operation to add the ID type "Mobile Number" with the following configurations:


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_81d545d017e23a93b659fcd3426cdc23.png) </span>

<span id="_2-配置-oneid"></span>
# 2. Configure the OneID


1. On the ID type configuration page, click on **OneID Configuration** above to enter the OneID configuration page.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_03a8883d20afc9d42b1404257df71fd5.png) </span>

<span id="_2-1-配置oneid识别参考关系"></span>
## 2.1 Configure the OneID Recognition Relationship

Go to **Offline OneID Generation Strategy \> OneID Recognition Relationship**, click the **Add Relationship** button below, and add the relationship of **User ID** and **Mobile Number** in the configuration interface on the right. Configurations are as follows:


* Relationship Dataset: IDMapping_UserID_Offline_HIVE

* Date Partition Field: p_date

* Date Partition Format: yyyy\-MM\-dd

* Update Method: Full Update

* Build Relationship ID:

   * User ID, corresponding field `user_id`

   * Phone number, corresponding field `reserv_phone`

* Reference Strategy: Not Configured


Click Save to complete the reference relationship configuration.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_28d741a2a3ee73b88e53e23d0c5e9394.png) </span>

<span id="_2-2-配置oneid识别优先级"></span>
## 2.2 Configure OneID Recognition Priority

Go to **Offline OneID Generation Strategy \> OneID Recognition Priority,**  click **Edit** button to go to the edit page.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_5ad7c9b4f2743d6f59e6814b566a21a5.png) </span>


1. OneID Generation Algorithm: Choose **Enhanced Segmented Algorithm**.

2. Priority: Click **Add Priority** to configure the OneID priority.

   1. In the newly added priority, select **user** as the ID type, drag the user priority to the top priority, and open OneID for changeability.

   2. Continue to click **add priority**, select **phone number** as the ID type, drag the phone number to the second priority, and open OneID for changeability.

      <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_7b514f027a852f644de8ed247848d89f.png) </span>

   3. Click the **configure** button on the right side of the phone number, click **add reference relationship**, choose the **user <\-\> phone number** relationship, then click OK to save the reference relationship settings.

      <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_35c4506923ae9b766c91def8900acc1d.png) </span>

   4. Click the **save** button at the top to save the OneID recognition priority settings. After completion, click the close button in the upper right corner to close the configuration interface.

      <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e7ac1363aeabd84dafaf1b852c20f9d7.png) </span>


<span id="_3-运行-id-mapping"></span>
# 3. Run ID\-Mapping.


1. After verifying the configuration, refresh the page, click run in the upper right corner, run the IDMapping task, and generate the base_id.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d3741bf46e402dc9592f1048c49595a3.png) </span>


2. You can view the operation records of ID\-Mapping in **task information**. After waiting for 5\-10 minutes, observe that the task status updates to **success**. If it continues to be in **waiting for upstream dependencies to be ready**, you need to check if the visual modeling configured earlier has run successfully.
