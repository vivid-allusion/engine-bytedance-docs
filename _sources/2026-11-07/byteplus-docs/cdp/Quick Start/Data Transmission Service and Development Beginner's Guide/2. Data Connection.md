<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">CDP supports 30+ types of data connection methods, making it easy for enterprises to integrate one\-way data into the CDP system for use.</div>



1. When hovering over the **Data Fusion** module, select **Data Connection** from the pop\-up menu (where you can find the completed data connection).


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c60ca1cb5eb7ffd83290283b3af4def1.png) </span>


2. After entering the data connection page, click on **Create Data Connection** at the top left of the new page, select the **CSV** data connection method, and upload the CSV file you just downloaded.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_935f6455cad836ec9653c81b0e25f058.png) </span>


3. In the pop\-up **Upload CSV Data** wizard, click the **Continue Upload** button to upload the remaining two CSV files. After completion, click Next, preview the data, make minor adjustments to the data types, and finally click OK to complete the data connection process.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_a77c544967b430815d0a4b50d8fa34ac.png) </span>

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ea1aff96812b6d75a5796ab197a9dbd0.png) </span>


4. On the successfully created data connection page, you can view its **Basic Information** and **Lineage View.** 


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e2906221fe6cf4a27a9e4bcbde080d65.png) </span>
