## 2.2 Creating a New Project

The **project** is the logical concept for the basic task management and resource isolation in VeCDP.

Often, after deployment, the system will automatically create a **default project**. We can directly operate within this default project or create a new project for better resource and operation isolation and management.

**Creation Steps**


1. Log in to the master account and [access the console](https://console.volcengine.com/iam/identitymanage/user).

2. Go to **Resource Management \> Projects**, click on **Create New Project**, fill in the basic project information to complete the creation.

3. Go to the [Customer Data Platform](https://console.volcengine.com/cdp/2113889/project-center/permission-management/user/auth-list), on the drop\-down box in the upper right corner, you can see the current project, or switch to a new project.
