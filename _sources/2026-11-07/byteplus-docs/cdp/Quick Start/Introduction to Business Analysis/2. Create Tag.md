# 1. Create AIPL tag


1. Hover over the **Labeling System** module and select **Labeling System**.

2. After entering the labeling system page, click on **Create new tag** at the top left of the new page, select **lifecycle tag,**  and choose the **AIPL** model.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_91b011e9d4438f3cb8cc5c515999b61b.png) </span>


3. Fill in the tag name, choose the storage path for the tag, select the update type according to requirements, and set the execution frequency.

4. If you need to output the tag in API form outside of CDP, you need to simultaneously turn on the **online service switch**.

5. Set tag rules for different stages based on business requirements. In this case, the rules for each stage are as follows:

   1. Awareness: Users who have clicked on ad spaces ≥1 time in the last six months

   2. Interest: Users with a shopping cart addition frequency ≥1 in the last six months

   3. Purchase: Users with transaction frequency ≥1 in the last six months

   4. Repurchase: Users with transaction frequency ≥2 in the last six months

6. When there are multiple conditions in a phase, you can freely choose **AND, OR** relationships between conditions.

7. After setting up rules for all tag values, click on the top right corner **Estimated Audience** to view the coverage of each tag value.

8. Click **Create Complete** to finish creating the tag.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e839944fabf53b4bdb747788bd66c5a5.png) </span>

# 2. Create Rule Tags


1. Click **Create New Tag**, select **Rule Tags** in the pop\-up, and create a **Unit Price Amount type** tag.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ba175673100bad09532f1f36f8be3747.png) </span>


2. Fill in the tag name, choose the storage path for the tag, select the update type based on requirements, and set the execution frequency.

3. If you need to output the tag in API form outside the CDP, you need to simultaneously turn on the **Online Service Switch**.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f99853b4884f58d3c6c88a309c59aa15.png) </span>


4. Set tag rules according to business needs. In this case, the desired effect is to **segment based on unit price**, so the rules for each phase are as follows:

   1. High: Customers with an average unit price of over 1000 yuan in the past 6 months

   2. In the past 6 months, the average customer unit price was between 500 yuan and 1000 yuan.

   3. Low: In the past 6 months, the average customer unit price was below 500 yuan.

5. Click on **User Data**, select **User Order Summary Table** as the data source, and the **average customer unit price of the past 6 months** field, then set the corresponding conditions. When a rule contains multiple conditions, you can freely choose the **AND** or **OR** relationship between the conditions.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9ceb1303b7a780bcab72f572965ae339.png) </span>

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b3c9c94f7f8f5c2e65b0ea414678ea06.png) </span>

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ecc77de2a9de3e1adc83cc7b5d1d55c7.png) </span>


6. After setting rules for all tag values, click on the upper right corner **Estimated Number** to view the quantity covered by each tag value.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_fae3719328991c6bf91e32514f1ad352.png) </span>


7. Click on **Finish Creation** to complete the creation of the tag.
