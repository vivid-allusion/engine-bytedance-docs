<span id="_1-产品概述"></span>
# 1. Product Overview

Supports the creation of import tags.

<span id="_2-操作步骤"></span>
# 2. Operation Steps

Go to the **Labeling System** module, click the **Create New Tag** button, select **Import Tags** to enter this functional module.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_36c92599937ea38a8151e4e1c28ff65f.png) </span>

<span id="_2-1-创建导入标签"></span>
## 2.1 Create Import Tags


* First, select the data source, then select the specific fields that need to be imported below.

* After checking, you can edit the fields on the right side. The first position can configure the hierarchical level of the tag; the second position can configure the tag's data type, supporting forced data type conversion.

* The synchronization cycle of importing tags defaults to be consistent with the dataset synchronization frequency.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_96b64243c793e95db652a45a3482b9ff.png) </span>

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The system supports a total of 5 types of tags: text, integer, decimal, multi\-value, and date.</div>



* <div data-tips="true" data-tips-type="tip">Text: Used for tags with text values, common examples include names, usernames, cities, etc.</div>


* <div data-tips="true" data-tips-type="tip">Integer: Used for tags with integer values, common examples include age, click counts, store visits, etc.</div>


* <div data-tips="true" data-tips-type="tip">Decimal: Used for tags with decimal values, common examples include costs, percentages, etc.</div>


* <div data-tips="true" data-tips-type="tip">Multi\-value: Used when a tag has multiple values, common examples include interests, favorite topics, etc.</div>


* <div data-tips="true" data-tips-type="tip">Date: Used for tags with date values, common examples include birthdates, update dates, etc.</div>



<span id="_2-2-查看标签详情"></span>
## Check tag details

Click **Complete Creation** to complete the creation of the current tag. You can view the current tag's distribution of people, historical details, operation records, etc. on the tag details page.
