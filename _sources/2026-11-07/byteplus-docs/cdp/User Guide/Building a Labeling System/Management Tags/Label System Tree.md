<span id="_1-功能概述"></span>
# 1. Function Overview

In the labeling system, you can use the structured way of the label tree to build a label system that meets business needs.

<span id="_2-使用限制"></span>
# 2. **Usage Restrictions**

Users must have the **View Tag System** and **Edit Tag Tree** permissions (Project administrators can grant these permissions to users in Project Center \- Permissions).

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b24ab610e28e84ec8a116d78f1ec6507.png) </span>

<span id="_3-操作步骤"></span>
# 3. **Operating Steps**

<span id="_3-1-创建标签树"></span>
## 3.1 Create a Label Tree


1. Click the operation button next to the system label, select **Create New Category on the Same Level**, and create a category at the same level as the currently selected category.

   1. **Create Subcategory:**  When adding levels, click the operation button next to the label folder and select create a subcategory.

   2. **Rename:**  If you need to modify the name of the label folder, click on rename.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b7c36db2e2da456af01a89c7c54912bf.png) </span>
