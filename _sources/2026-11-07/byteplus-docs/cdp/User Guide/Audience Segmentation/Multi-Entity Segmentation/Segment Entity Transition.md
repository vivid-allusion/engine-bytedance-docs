<span id="_1-功能概述"></span>
# 1. Function Overview

Supports converting segmentation files for any subject into segmentation files for another subject, achieving multiple matching and pairing scenarios.

**Marketing Application Scenarios, such as Car Matching with Users**

> A certain car company wants to promote a certain type of car in a specific color. By pulling target users with a relationship of [Person<\-\>Car = Follow Relationship], it can send marketing promotions to achieve scenarios where users click to follow or when the algorithm predicts follow\-up and immediately push corresponding marketing information.


<span id="_2-使用前提"></span>
# 2. Prerequisites


* The multi\-subject segmentation function requires separate payment. Please contact your account manager if necessary.

* Users with authorization to the **Segmentation** module can make use of this function.

<span id="_4-操作步骤"></span>
# 4. Operating Steps


1. Click **User Segmentation\>Segmentation Subject Conversion** to enter the configuration page.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e67c038b8809cdcfb43d74c63c962870.png) </span>2. **Create Subject Conversion Rules**.

* Segmentation File: Select the segmentation package that needs to be converted.

* Output Subject: Select the subject to be output (Note: it cannot be the same as the subject of the segmentation file)

* ID Type: Select the ID type of the output subject.

* Relationship Model: Select the relationship between subjects, such as person <\-\> car (purchase relationship)


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1072801586b7d8027b21823078efdb08.png) </span>3. **Configure** **Segment Basic Information**.


* Fill in the group name, description, etc., and authorize the current group to users within the system, supporting adding the current group to the corresponding group.

* Update frequency: Supports on\-demand or daily updates.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">On\-demand update: Not updated daily. Manually update the segment when needed.</div>


* <div data-tips="true" data-tips-type="tip">Daily updates: Daily updates may block the cluster queue, leading to slower update speeds.</div>
