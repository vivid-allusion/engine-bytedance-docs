<span id="_1-产品概述"></span>
# 1. Product Overview

In this Functional Modules, support viewing the lineage details of the segment, displaying the data source, segment, and label resources related to it with upstream and downstream dependencies.

<span id="_2-使用限制"></span>
# 2. Usage Restrictions

Requires the permission of **Project Center\-Permissions\-Modules\-Private Domain Segment\-View** to use this function.

<span id="_3-操作步骤"></span>
# 3. Operating Steps

On the segment list page, click on "More"\-"View Details".

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f2e8065c538f239249d90377593582e9.png) </span>After jumping to the page, select the "Data segment Lineage" tab to view the upstream and downstream dependencies of the segment (upstream and downstream are limited to showing a maximum of 7 layers each).


* Switch between graph or list view

* Can restrict upstream/downstream dependencies

* The selectable dependent asset types (label, segment, data sources)

* Click the "Download" button to download the data lineage chart in different formats
