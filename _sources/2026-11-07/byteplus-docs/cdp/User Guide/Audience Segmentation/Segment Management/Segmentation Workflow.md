# 1. Product Overview

In this Functional Modules, support to view the workflow application details of crowd packs, displaying push tasks, advertising tasks, and insight tasks related to crowd packs, making the data flow trajectory clear at a glance.

<span id="_2-使用限制"></span>
# 2. Usage Restrictions

You need to have permission in the project center\-module, private domain segmentation\-crowd workflow to use this function.

<span id="_3-操作步骤"></span>
# 3. Operating Steps

**Step One:**  Click [User Segmentation]\-[Workflow Application] to enter the application details page.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9d7b6981e8aaf58f5120484af677f266.png) </span>

**Step Two:**  On the application details page, the system displays push channels, advertising platforms, and insight analysis centered on the segment, supporting the configuration of corresponding push tasks or jumps for analysis


1. **Display crowd pack information.**  Hover over the exclamation mark next to the segmentation name to display the information of the crowd pack, including the update method, segmentation type, latest update time. Click "View Details" to jump to the crowd pack creation details page.

2. **Configure workflow tasks.** 

* If you need to push the audience package to the marketing platform or advertising platform, you can select the specific platform identification, click to jump to the task push page for configuration

* If you need to analyze the segment, you can click on the specific analysis type to jump to the corresponding analysis page for insight.

3. **Switch Display View**


defaults to the card view of the workflow. Click on "List View" to switch to the workflow list, and click on the corresponding platform's jump button to go to the corresponding page for configuring push tasks or insight analysis.
