<span id="_1-产品概述"></span>
# 1. Product Overview

The operation records page displays the operating records, historical performance, trends, etc., of this segment for you to promptly understand the latest situation of the segment tasks. This article introduces the relevant content of the segment operation records for you.

<span id="_2-常见应用场景举例"></span>
# 2. Common Application Scenarios

<span id="_2-1-了解分群历史表现"></span>
## **2.1 Understand the historical performance of the** segment

User A create a segment of "recently purchased product A within 30 days with an amount greater than 5k," sets the current segment to update daily. User A can view the historical performance and trends of the segment in different time periods uniformly on the operation records page, further formulating and optimizing operation strategies.

<span id="_2-2-监控分群任务状态"></span>
## **2.2 Monitor the status of** segment **tasks**

On the operation records page,we provide visual monitoring management of historical task statuses to help enterprise employees understand and monitor task statuses, ensuring more timely problem resolution.

<span id="_3-使用限制"></span>
# 3. Usage Restrictions


* Project administrators are able to view the operation records of all segments by default;

* Regular users can only view the operation records of the segment if they have the permission to view the current segment.


<span id="_4-操作步骤"></span>
# 4. Operation Steps

<span id="_4-1-功能入口"></span>
## 4.1 Function Entrance

Go to the **Segmentation** module, select the segmentation package, click on **Segmentation Quantity.**

<span id="_4-2-查看运行记录"></span>
## 4.2 View Execution Records

On the redirected execution records page, manual updates by users are supported, viewing segmentation historical details and execution records are available.

**Segmentation Historical Details:** 


* Displays the number of segmentations within the filtering time and its trend over time

* Supports filtering by time period, downloading historical segmentation packages


**Execution Records:** 


* Displays detailed execution records of historical segmentation tasks, including start time, end time, execution status, etc.

* Support filtering by operating status, downloading operation records, viewing operation views, and downloading historical segmentation packages.
