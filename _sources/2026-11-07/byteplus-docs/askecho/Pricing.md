AskEcho offers multiple service versions with separate pricing.

<span id=""></span>
## AskEcho Search Agent


1. Billing Rules


  Billed based on the number of search agent API calls.


|**Service **  | **Service Configuration** | **Billing Method** | **Payment Method** | **Price** | **Refund Policy** | **Service Suspension Time (Overdue)**  | **Data Recovery Time (Overdue)**  |
|---|---|---|---|---|---|---|---|
|AskEcho search agent |AskEcho\-Lite |Pay\-as\-you\-go (by usage) | Postpaid |$0.03/request | No refunds | 24 hours | 168 hours |



2. Billing Details


  View AskEcho Search Agent API requests and token usage in the AskEcho console under AskEcho API Request and AskEcho Tokens. View charges in the BytePlus Billing Center.
