The Security Overview page is a centralized dashboard in the LLM Application Firewall that helps you monitor your application's security status. It displays key statistical data on LLM protection, such as request volumes, protection triggers, request trend charts, and attack distribution ratios. These multidimensional metrics allow you to quickly understand the security posture of your business.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

You have connected the assets that require protection to the LLM Application Firewall platform. For details, see [Introduction to assets integration](https://docs.byteplus.com/docs/LLM-Application-Firewall/introduction_to_assets_integration).

<span id=".5p-l55yL57u05bqm"></span>
## LLM protection statistics


* Prompt: Displays the number of user inputs sent by the client to the LLM application within the last 30 days and the last hour.

* Response: Displays the number of responses from large model applications within the last 30 days and the last hour.

* Number of protections for different policies: Displays the number of times protection was triggered for each policy: resource exhaustion mitigation, prompt injection protection, model abuse prevention, sensitive data disclosure prevention, and topic control.

* Request count by execution action:

   * **Valid**: The number of requests that did not trigger any protection policies.

   * **Observe**: The number of requests that triggered a policy with the `Observe` action.

   * **Block**: The number of requests that triggered a policy with the `Block` action.

   * **Data masking**: The number of requests that triggered a policy with the `Data masking` action.

   * **Secure reply**: The number of requests that triggered a policy with the `Secure reply` action.

## Security data

Security data refers to security event data generated by the LLM Application Firewall as it protects your domain names, including request trends, distribution of attack types and detection categories, and the top 5 attack IP addresses.

<span id="de8dfd4c"></span>
### Request trends


* **Total requests**: The total number of requests inspected by the LLM Application Firewall.

* **Matched rules**: The number of requests that triggered a protection rule.


<span id="6b351f51"></span>
### Attack distribution


* **Overall**: The number and proportion of attacks for each protection policy type.

* **Resource exhaustion/Prompt injection/Model abuse/Sensitive data disclosure/Topic control**: The number and proportion of attacks detected for each detection category associated with each protection policy.
