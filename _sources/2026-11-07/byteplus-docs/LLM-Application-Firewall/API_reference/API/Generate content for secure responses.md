This interface is used to generate the reply content for a specified message and return the result as a stream. You can use the secure response results to respond to client requests, in order to reduce potential security risks.

<span id="cf8ced12"></span>
## Prerequisites


* You have completed asset integration and protection policy configuration using the SDK. For instructions, refer to [Integrate LLM Application Firewall into your SDK](https://docs.byteplus.com/docs/LLM-Application-Firewall/Integrate_LLM_Application_Firewall_into_your_SDK).

* You have called [Check whether input or output content is compliant](https://docs.byteplus.com/docs/LLM-Application-Firewall/Check_whether_input_or_output_content_is_compliant) and get the message ID via the interface.


<span id="02231bba"></span>
## Request description


* Request method: POST

* Request URL: https:// **`{region}`**  **`.sdk.access-bp.llm-shield.omni-shield.ai`**/v2/generate?Action=Generate&Version=2025\-08\-31

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">\*Caution   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">When calling the API, replace <code>{region}</code> with the actual region ID. For region details, refer to <a href="https://docs.byteplus.com/docs/LLM-Application-Firewall/API_HTTP_request#8d79aaa3">Regional information</a>.   </div>
   

<span id="8c450bea"></span>
## Request parameters


|Parameters |Type |Required |Example value |Description |
|---|---|---|---|---|
|MsgID |String |Yes |19de789baf324b4480e25c9616aa\*\*\*\* |A unique identifier for the message to be queried. You can obtain this ID from  [Check whether input or output content is compliant](https://docs.byteplus.com/docs/LLM-Application-Firewall/Check_whether_input_or_output_content_is_compliant). |


<span id="7055a33d"></span>
## Return parameters


|Parameters |Type |Example value |Description |
|---|---|---|---|
|Message |Object of[Message](https://docs.byteplus.com/docs/LLM-Application-Firewall/Generate_content_for_optimized_answers#230fbf5e) |We are very sorry, your question involves illegal and harmful content... |Secure response generated by the LLM Application Firewall. |
|IsFinished |Boolean |false |Indicates whether this is the last segment of the streamed response.<br><br><br>* true: The current content is the last segment<br><br>* false: The current content is not the last section |


<span id="230fbf5e"></span>
### Message


|Parameters |Type |Example value |Description |
|---|---|---|---|
|Role |String |assistant |Indicates the source of the content.<br><br><br>* User: The user's input prompt<br><br>* Assistant: The model's response |
|Content |String |We are sorry, but your question involves illegal and harmful content... |Results of the LLM Application Firewall's delegated answers. |
|ContentType |Integer |1 |Content type: the current version supports only text |
