To analyze security threats and audit network access behavior, you can view the logs generated by Network Detection and Response (NDR). This guide provides step\-by\-step instructions for accessing and viewing both alert logs and network traffic logs in the NDR console.


* Alert log: A log of all alerts for network attack traffic identified by the NDR system.

* Network traffic log: NDR logs the inbound and outbound internet access activity of all cloud assets.


<span id="c65d43e8"></span>
## **Viewing alert log**

The alert log contains the following content: time of the last occurrence, threat type, attack status, risk level, source IP address, destination IP address, port, protocol, attack direction, and other information.


1. Log in to the NDR console.

2. Select **Analysis center** ＞ **Log analysis** in the left navigation pane.

3. Select the **Alert log** tab to view a log of the alerts that occurred.


<span id="65f5db2f"></span>
## **Viewing network traffic log**

The traffic log contains the following content: access time, source IP address, source port, protocol, application, destination port, domain name, direction, traffic, number of packets, and other information.


1. Log in to the NDR console.

2. Select **Analysis center** ＞ **Log analysis** in the left navigation pane.

3. Select the **Network traffic log** tab to view a log of the network traffic that occurred.
