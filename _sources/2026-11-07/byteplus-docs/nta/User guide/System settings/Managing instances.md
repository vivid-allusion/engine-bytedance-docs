To effectively manage your Network Detection and Response (NDR) instances, you can view their details, upgrade specifications for more resources, and renew subscriptions to ensure service continuity. This guide provides step\-by\-step instructions for viewing, upgrading, and renewing your instances.

<span id="8cfcaf59"></span>
## Prerequisites

You have already purchased an NDR instance.

<span id="b4a30ac7"></span>
## Viewing instance information

The Instance management page displays details for your cloud firewall subscription, including its version, specifications, status, billing mode, auto\-renewal status, subscription start time, and expiration time. You can view instance specification details, such as the number of protected assets, service bandwidth, log service, log retention period, and the number of access control rules.


1. Log in to the NDR console.

2. Select **System settings** ＞ **Instance management** on the left side of the page.

3. View the basic information and specification of the instance.


<span id="450fa964"></span>
## Upgrading instance specification

If the current instance specification no longer meets your service needs, upgrade it to access more resources.


1. Log in to the NDR console.

2. Select **System settings** ＞ **Instance management** on the left side of the page.

3. In the specification information section, click **Upgrade specification**.

4. Select the desired specifications.

5. Select the checkbox to accept the service agreement, then review and confirm the cost.

   The upgrade takes effect after the payment is completed.


<span id="6d07001a"></span>
## Renewing instance subscription

If your instance is about to expire, renew the subscription to avoid service interruption. You can also enable the auto\-renewal feature.


1. Log in to the NDR console.

2. Select **System settings** ＞ **Instance management** on the left side of the page.

3. In the instance basic information section, click Renewal.

4. Select the desired renewal period.

5. Select the checkbox to accept the service agreement, then review and confirm the cost.

   The renewal takes effect upon successful payment.

6. (Optional) You can also enable the auto\-renewal feature to prevent service disruption.
