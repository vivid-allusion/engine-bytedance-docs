The Detection and Defense Configuration page displays all the detection capabilities of the NDR system, including intrusion detection, vulnerability attack detection, intelligent detection, file threat detection, and email data analysis.

<span id="fd5bf42a"></span>
## Procedure


1. Log in to the NDR console.

2. Select **Response Center** ＞ **Detection and Defense Configuration** on the left side of the page.

3. View the supported types.

   * Intrusion detection: NDR can identify common network attack types, with a high recognition rate and a low false alarm rate.Detectable items include: SQL injection, command injection, web backdoors, weak passwords, proxy tunneling, domain names from a domain generation algorithm (DGA), and other types of threats.

   * Vulnerability attack detection: NDR is capable of detecting exploits of common and high\-risk vulnerabilities, including deserialization, system, and software vulnerabilities.

   * Intelligent detection: This feature uses big data analysis technologies, such as machine learning algorithms and behavioral analysis models, to identify potential risks.

   * File threat detection: Supports file auditing and restoration over the HTTP protocol and identifies various types of malicious files such as exe, dll, zip, rar, elf, and gzip.

   * Email data analysis: Supports auditing and restoration of email protocols such as SMTP and identifies security risks such as emails containing viruses, phishing emails, and email leaks.

4. Click **Detail** to check the specific outputs of the detection function.

5. The detection function can be enabled or disabled as needed.
