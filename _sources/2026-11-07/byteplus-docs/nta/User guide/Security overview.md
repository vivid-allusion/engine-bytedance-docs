The Security Overview page is a centralized dashboard that provides a comprehensive, real\-time view of your network's security posture. This page aggregates key metrics from the Network Detection and Response (NDR) system, including protected asset counts, security event statistics, top attack sources, and threat trends. You can use this overview to quickly assess overall risk and identify the most critical security issues requiring attention.

<span id="c5b85650"></span>
## **Security overview**

The security overview displays the overall Network Detection and Response (NDR) status for a specific time period. You can select a time range in the upper\-right corner to show the corresponding data. Data for the last 24 hours is displayed by default. Overview data includes: Number of assets with protection enabled, the number of security events, the number of risky ports on internet\-exposed assets, the current peak bandwidth, the current log capacity, and a list of risky assets that recorded the most security events.

<span id="4625623b"></span>
## Asset risk data

The risk statistics of all assets are displayed by default. You can filter assets in the upper\-left corner.


* Distribution of event sources: This section displays the distribution of security event sources, including the intrusion detection engine, the intelligent detection engine, vulnerability attack detection, and threat intelligence.

* Top 5 attacking IP addresses: This section displays the top 5 IP addresses with the most attacks on the current network.

* Top 5 threat events: This section displays the top 5 most frequent threat event types on the current network.

* Trend of threats: This section displays the trend of alerts on inbound attacks and suspicious outbound traffic from the current network.

* Trend of traffic: This section displays the trend of traffic between the current network and external sites.

* Trend of sessions: This section displays the numbers of concurrent and new sessions between the current network and the internet.
