## What is Network Detection and Response (NDR)?

NDR is an SaaS\-based full\-data\-flow threat detection system based on by\-pass traffic revolving around attacks and defenses in actual combat. Leveraging behavioral analysis, feature detection, correlation analysis, threat intelligence, machine learning, and other technologies, NDR can accurately identify known, advanced cyberattacks and unknown, novel intrusion threats on your network.

<span id="NTA"></span>
## Advanced Threat Detection

Powered by a feature rule engine, behavior analysis engine, threat intelligence, correlation analysis, machine learning, and other technologies, NDR can detect and discover advanced network attacks and novel intrusion threats. Detectable threats include: ransomware, cryptomining malware, botnets, APT attacks, and worms and Trojans. NDR also supports security visualizations to display all network threats.

<span id="Abnormal behavior detection"></span>
## Abnormal behavior detection

NDR supports 20\-plus protocols for IP address resolution. It uses machine learning and big data analysis technologies to build models for abnormal behavior detection that identify cryptomining activity, covert tunnel communication, abnormal login, DGA domain names, proxy penetration, and other advanced threats to surface novel attacks.

<span id="Attack traceability analysis"></span>
## Attack traceability and analysis

NDR stores alert data packets and network access records to locate compromised hosts. It reconstructs the complete attack chain based on alerts, behaviors, timestamps, and other information to help users trace and hunt network attacks.

<span id="Closed-loop collaborative handling"></span>
## Closed\-loop collaborative response

NDR integrates with the cloud firewall to block any detected threats immediately and automatically locate malicious programs and their execution processes in collaboration with the cloud security center.
