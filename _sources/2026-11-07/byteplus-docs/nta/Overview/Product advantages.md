<span id="Focusing on real threats"></span>
## Focusing on real threats

Based on ByteDance's intrusion check rules accumulated and honed through long\-term attack and defense practices, NDR applies correlation analysis and machine learning technologies to detect common types of network attacks, with a higher detection and recognition rate and a low false alarm rate.

<span id="Encrypted traffic detection"></span>
## Encrypted traffic detection

This feature detects network attacks within encrypted traffic by analyzing traffic fingerprints and applying flow correlation technology.

<span id="Non-intrusive detection"></span>
## Non\-intrusive detection

NDR performs non\-intrusive detection by analyzing mirrored traffic, which does not interrupt user services.

<span id="Rapid deployment, elastic scaling"></span>
## Rapid deployment, elastic scaling

The SaaS\-based NDR requires no additional equipment for deployment. Instead, it is deployed as clusters and supports smooth scaling of performance, eliminating the need for complex network infrastructure changes as your services grow.

<span id="Collaborative response"></span>
## Collaborative response

NDR works with cloud firewalls and the cloud security center to help users quickly locate compromised hosts, block threats, and find malicious programs to respond to threats instantly and ensure network security.
