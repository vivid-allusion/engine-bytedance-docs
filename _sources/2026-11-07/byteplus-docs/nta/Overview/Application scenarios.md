<span id="AI Intelligent Detection to discover any advanced threats"></span>
## Intelligent detection of advanced threats

The traditional static defense mechanisms may find it hard to combat advanced or unknown threats. To this end, Network Detection and Response (NDR) applies behavioral analysis and machine learning technologies to quickly pinpoint advanced network attacks.

<span id="All-data-flow detection - Visualized security across network"></span>
## All\-data\-flow detection \- Visualized security across network

It collects, detects, and analyzes all north\-south and east\-west traffic. It supports resolution detection and anomaly discovery for over 20 mainstream protocols and presents alerts and assets from multiple perspectives to help users visualize threats across the entire network.

<span id="Packet forensics for threat traceability analysis"></span>
## Packet forensics for threat traceability analysis

This tool retains the original alerting traffic and performs packet\-level forensic analysis for event traceability analysis and forensic investigation.

<span id="Security compliance to meet regulatory requirements"></span>
## Security compliance to meet regulatory requirements

NDR enables quick log auditing for cloud services and intrusion checks to meet compliance and classified information protection requirements.
