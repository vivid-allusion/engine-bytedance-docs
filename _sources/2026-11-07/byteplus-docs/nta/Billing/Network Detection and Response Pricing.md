This topic introduces how you will be charged for the use of BytePlus Network Detection and Response service. A pricing example will also be given for your reference.

<span id="12904552"></span>
### Billing model

Network Detection and Response supports monthly or yearly subscriptions. You are charged for the items you select on the purchase page.

<span id="90af4e47"></span>
### **Billable items**


|**Feature or billable item** |**Premium Edition** |**Enterprise Edition** |**Description** |
|---|---|---|---|
|Basic price |USD 420 per month. |USD 1,450 per month. |The basic price covers only the default specifications. Additional quotas or value\-added items are not covered. |
|Protected Internet Traffic |The basic price covers 20 Mbit/s of bandwidth. |The basic price covers 50 Mbit/s of bandwidth. |The peak Internet traffic that can be protected. Metering metric: the peak sum of outbound and inbound Internet traffic.<br><br>Extra fee: USD 7 per month for each 1 Mbit/s of additional bandwidth. |
|Protected Public IP Addresses |The basic price covers 20 public IP addresses. |The basic price covers 50 public IP addresses. |The number of public IP addresses that can be protected.<br><br>Extra fee: USD 7 per month for each additional public IP address that you want to protect. |
|Allowlist policies |The basic price covers 50 Allowlist policies |The basic price covers 150 Allowlist policies |None. |
|Storage capacity for log analysis |The basic price does not cover this specification. Valid values: 1000 to 500000. Unit: GB. |The basic price does not cover this specification. Valid values: 1000 to 500000. Unit: GB. |Extra fee: USD 80 per 1,000 GB\-month. |
|Intrusion detection |Supported |Supported |None. |
|Intelligent detection |Supported |Supported |None. |
|Vulnerability attack detection |Supported |Supported |None. |

### **Pricing example**

For example, consider a Premium Edition subscription with the following configuration: The number of protected public IP addresses is 30. The protected internet traffic bandwidth is 30 Mbit/s. Storage capacity for log analysis is 2000GB. The total monthly cost for this configuration is $720, calculated as follows:


* USD $420 for Premium Edition

* USD $70 for 10 Protected Public IP Addresses: (30\-20) \* USD $7 = USD $70

* USD $70 for 10 Mbit/s of additional bandwidth: (30\-20) \* USD $7 = USD $70

* USD $160 for 2000GB storage capacity for log analysis: 2 \* USD $80 = USD $160
