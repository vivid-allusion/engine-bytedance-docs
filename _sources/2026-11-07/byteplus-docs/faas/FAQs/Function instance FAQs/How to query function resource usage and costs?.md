The following two methods are supported for querying function resource usage and costs.


* **Query recent usage trends**: In the Function Service Console, go to **Overview ** \> **Resource usage statistics **  module to view resource usage statistics and trend charts for the past 31 days.

* **Query complete bill details**: On the [Billing Center ](https://console.byteplus.com/finance/bill/detail) **Bill details **  page, filter resources as needed to query resource usage and cost details. For details about resource filter actions, see [Bill management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-billing-management).
