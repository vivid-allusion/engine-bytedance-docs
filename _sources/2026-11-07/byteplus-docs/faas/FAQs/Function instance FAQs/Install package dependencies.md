<div data-tips="true" data-tips-type="default">After dependencies are installed, you must release the function for them to take effect in the application. For details about releasing the function, see <a href="https://docs.byteplus.com/en/docs/faas/Release_function">Release function</a>.</div>


Functions running in the Python and Node.js runtime automatically recognize dependency configurations in `package.json` or `requirements.txt` files. They retrieve the corresponding dependency package information and complete the installation. For details about installing dependencies, see [Python Dependency Installation](https://docs.byteplus.com/en/docs/faas/Python_runtime_Dependency_Installation) and [Node.js Dependency Installation](https://docs.byteplus.com/en/docs/faas/Node_js_runtime_Dependency_Installation).
