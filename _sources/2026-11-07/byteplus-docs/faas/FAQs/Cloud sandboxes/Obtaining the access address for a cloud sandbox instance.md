When creating a cloud sandbox application, if you have already configured the **gateway route configuration,**  you can view the instance's access address in the **Sandbox Instance** tab of the sandbox application, under the **Access Address column** in the instance list.


* For the configuration method of gateway routing, see [Sandbox Application](https://docs.byteplus.com/en/docs/faas/Sandbox_applications).

* For a detailed description of the access address for sandbox instances, see [Access Sandbox Instance](https://docs.byteplus.com/en/docs/faas/Sandbox_instances#B23f5ldJ).
