Some features of Function Service (FaaS) are currently available in beta. To try these features, submit application.

<span id="usage-notes"></span>
## Usage notes


* For information on the released features and feature availability of FaaS, refer to [Release notes](https://docs.byteplus.com/en/docs/faas/Release_notes).

* When product features are available in beta, allowlists are used to control access to the corresponding product documentation. To view the documentation, request the permissions.


<span id="procedure"></span>
## Procedure

Contact your BytePlus business account manager to obtain beta feature trial permissions.

To facilitate a quick trial, you can provide:


* Your BytePlus Account ID.

* Authenticated corporate entity name.

* The beta feature name you wish to apply for trial.

* The scenarios and requirements for using this feature.
