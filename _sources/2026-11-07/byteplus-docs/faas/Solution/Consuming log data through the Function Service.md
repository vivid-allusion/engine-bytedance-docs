This article introduces the advantages, application scenarios, and related documentation collections of consuming Torch Log Service (TLS) through Function Service (FaaS).

<span id=".5LyY5Yq_"></span>
## Advantages

FaaS is an event\-driven, fully managed Serverless computing platform. You need to simply submit the log configuration information through the TLS Trigger provided by the FaaS, then you can consume log data in real time through Serverless architecture, and implement data processing, analysis, and delivery of any custom logic, thus to meet the demands of application scenarios including log processing, cleaning, and delivery.


* You can customize log processing logics, which can be applied in flexible business scenarios.

* Fully managed log processing tasks allow you to consume log data in real time and support automatic retries.

* Built\-in function templates reduce the costs of log processing and development under mainstream demands.

* The Serverless computing engine is event\-triggered, automatically flexible, maintenance\-free, and pay\-as\-you\-go.


<span id=".5L2_55So5Zy65pmv"></span>
## Application scenarios


* **Data cleaning and processing scenario**

   Implement cleaning, processing, and format conversion, and other operations of log data through the FaaS.

* **Data delivery scenarios**

   Supports data destinations and build on\-cloud, off\-cloud, and cross\-cloud data pipelines.

* **Operation and maintenance scenario**

   Automated alerts in operation and maintenance allow you to process log alerts through the FaaS and customize operation and maintenance based on business scenarios.
