Version control is used to manage all version information of the current function, facilitating your version auditing.

<span id="view-code-and-configuration-of-each-version"></span>
## View code and configuration of each version

Supports viewing code and configuration information of historical versions.


1. Log in to the [Function Service console](https://console.byteplus.com/vefaas).

2. On the top navigation bar, select the target region.

3. On the function list page, search for the target function. Click the function name to enter the basic information tab of the current function.

4. The function by default displays the basic information and code of the **Latest** version. In the top right corner, switch versions using the version selection box to view the basic information and code of other versions.


<span id="view-version-list"></span>
## View version list

View all version information of the current function.


1. Log in to the [Function Service console](https://console.byteplus.com/vefaas).

2. On the top navigation bar, select the target region.

3. On the function list page, search for the target function. Click the function name to enter the basic information tab of the current function.

4. Switch to the release management tab. Click **Version Information** to view all version information of the current function.


<span id="overwrite-latest"></span>
## **Overwrite latest**

The code and configuration of the Latest historical version can only be viewed. If you wish to edit the content of a certain historical version, you can do so by using the overwrite Latest feature.


1. In the version information table of the current function, select the target version and click **Overwrite latest** in the operation column.

2. In the pop\-up confirmation box, click **Confirm**. The code and configuration of the Latest version will be overwritten by the selected version.
