To meet the storage and file access needs of different scenarios, FaaS provides various types of storage. This topic introduces the applicable scenarios and differences of each type, to assist you in technical selection.


|**Comparison Item** |[FileNAS](https://docs.byteplus.com/en/docs/nas/What-is-FileNAS) |[Torch Object Storage TOS](https://docs.byteplus.com/en/docs/tos/docs-what-is-tos) |**Temporary hard drive** |
|---|---|---|---|
|Introduction |FileNAS provides a cost\-effective cloud storage service for BytePlus elastic computing, container services, and AI smart applications. It offers high\-performance shared access, continuous online presence, scalable resources, and cross\-regional access. |TOS offers massive secure, low\-cost, user\-friendly, highly reliable, and highly available distributed cloud storage services. |Temporary disk space is consistent with the life cycle of the underlying function container, and data will be deleted when the container is deleted. |
|Applicable scenarios |Log and business file storage |Log and business file storage |Temporary files generated by the service |
|Maximum Space |Elasticity |Elasticity |512 MiB |
|Persistence |Persistent |Persistent |Temporary storage |
|Shared across calls |Yes |Yes |Disabled |
|Storage content |Writable |Writable |Writable |
|Storage type |File system |Object |File system |
|Event Source Integration |Disabled |Yes |Disabled |
|Function access speed |Faster |Fast |Fastest |
|Billing |[FileNAS Billing](https://docs.byteplus.com/en/docs/nas/Billing-overview) |[TOS Billing](https://docs.byteplus.com/en/docs/tos/docs-billing-overview) |Free |
