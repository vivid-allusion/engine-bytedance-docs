The Quota page displays the usage of function resources within the current root user.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c09bb0a02c20556cc1a34d710a049c38.png) </span>


|Feature module |Description |
|---|---|
|Resource overview |Displays an overview of resource usage within the current root user.<br><br><br>* Total memory: the total amount of memory<br><br>* Total graphics memory: the total amount of video memory<br><br>* Released functions: the number of released functions<br><br>* Use memory resource statistics: displays the proportion of memory occupied by each function, allocated resources, and available resources within the current account in a pie chart.<br><br>* Function Memory Top5 resource usage: displays the top five functions that use the most memory resources. |
|Usage ratio |Displays the proportion of function resources within the current root user.<br><br><br>* Memory usage: the usage and utilization of memory<br><br>* Graphics memory usage: the usage and utilization of video memory<br><br>* Function release ratio: the number and proportion of released functions |
|Allocation details |Displays the specific resource allocation specifications and resource utilization of each function. |
