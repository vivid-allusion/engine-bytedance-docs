The function overview page provides a product introduction and usage guide for veFaaS, and visually displays function\-related metrics under the current account, allowing you to view the overall function usage of the current account.

Login to the [Function Service Console](https://console.byteplus.com/vefaas), select **Overview** in the left navigation bar to enter the overview page. You can view the usage guide, service data, resource package and quota usage, and best practices documentation.


|Display items |Description |
|---|---|
|Usage guide |Introduce the basic procedure and main steps for using veFaaS, helping new users get started quickly and providing a shortcut to create functions. |
|Service data |* Overview data: display the number of applications, functions, and cloud sandboxes created under the current account.<br><br>* Resource usage statistics: display detailed resource usage under the current account, as well as the usage of other instance\-type cloud resources. |
|Resource package |* Resource package usage: display the usage of resource packages under the current account. For a detailed description of resource packages, see [resource package](https://docs.byteplus.com/en/docs/faas/Resource_package). |
|Best Practices |Display best practices related to using veFaaS. For more best practices documentation, see [best practices](https://docs.byteplus.com/en/docs/faas/Best_Practices). |
