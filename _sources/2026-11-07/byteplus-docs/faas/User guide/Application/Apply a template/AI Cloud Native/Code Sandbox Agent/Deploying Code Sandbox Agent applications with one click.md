This article introduces to you how to deploy your own Code Sandbox Agent applications with one click through Function Service Application Center.

<span id="background-information"></span>
## Background information


* **Application introduction**

   Code Sandbox Agent is a code sandbox service offered by BytePlus Function Service based on the open\-source SandboxFusion project, while facing end users and AI suite developers. The user enters the programming task, then the programming task can be analyzed by Doubao large model, generating the program code for the corresponding language, and at last the user submits running request, and Sandbox runs the code and output execution result. The whole use process can be seen as follows: The large model helps solve the programming issues and output programs, and the Sandbox helps execute the programs and verify the correctness of codes.

* **Runtime**

   Native Runtime.

* **Associated Cloud Services**

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Using associated cloud services generates corresponding usage fees. For billing details, refer to the billing documentation of the associated cloud services.   </div>
   

   Code Sandbox Agent backend:

   * [Function Service](https://www.byteplus.com/en/product/faas): Provides the service interface that calls the large model to generate codes, and provides the service interface that requests code execution.

   * [API Gateway](https://docs.byteplus.com/en/docs/apig/What_is_an_API_Gateway): Expose the interface through the API Gateway.


<span id="prerequisites"></span>
## Prerequisites


* All the cloud services associated with this application have been activated.

* IAM users need to ensure that they have authorized the **VeFaaSFullAccess**, **APIGFullAccess**, and **STSAssumeRoleAccess** policies. If any of the above policies is missing, contact the root user or the administrator for authorization. For specific operations, refer to [Editing a user](https://docs.byteplus.com/en/docs/byteplus-platform/docs-editing-a-user).

* An API gateway instance of the Serverless gateway type has been created. For detailed operations, refer to [Creating an instance](https://docs.byteplus.com/en/docs/apig/Creating_an_instance).

* When using Function Service for the first time, make sure that the cross\-service authorization is completed. If authorization is not done, the console will pop up the cross\-service authorization page to guide you to complete authorization.


<span id="procedure"></span>
## Procedure


1. Log in to the [Function Service console](https://console.byteplus.com/vefaas).

2. On the top navigation bar, select the target region.

3. In the left navigation bar select **Application** \> **App Square**.

4. On the **App Square** page, select **Code Sandbox Agent** template, and click **Create applications**.

5. On the **Creating Applications** page, configure application parameters.

<span id="call-agent-via-api"></span>
## Call Agent via API

This section mainly introduces the methods of calling API to experience Code Sandbox Agent through the local curl command.

```bash
curl 'https://****.com/run_code' \
  -H 'accept: application/json, text/plain, */*' \
  -H 'accept-language: zh-CN,zh;q=0.9' \
  -H 'content-type: application/json' \
--data '{
    "code": "ls",
    "language": "bash",
    "files":{}
}'
```


Among which:


* Replace `https://****.com` with the access address of your own Code Sandbox Agent.

* According to the actual situation, replace the parameter value under data. For related parameter description and examples, refer to the open\-source document [Sandbox Fusion](https://bytedance.github.io/SandboxFusion/zh-Hans/docs/api/run-code-run-code-post/).
