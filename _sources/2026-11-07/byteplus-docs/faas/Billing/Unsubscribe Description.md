This topic introduces the unsubscription conditions for the Function Service.

<span id="unsubscribe-function"></span>
## Unsubscribe Function

Deleting a function is equivalent to unsubscribing, and the function Instance will be released/destroyed immediately, at which time you will receive a unsubscription notification from the platform.
