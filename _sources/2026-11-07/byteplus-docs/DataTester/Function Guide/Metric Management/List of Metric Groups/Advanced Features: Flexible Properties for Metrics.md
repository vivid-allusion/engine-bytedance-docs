DataTester provides you with flexible properties for experimental metrics. When creating event metrics and retaining metrics, flexible properties for setting metric events are added. After opening and adding flexible properties, you can specify the selected metrics to define, calculate and display the experimental results according to the selected properties and property values through flexible properties when experimentally creating and selecting metrics.

<span id="2e0f9783"></span>
# Application scenario

In the experimental process of some scenarios (e.g. operating experiments), it is necessary to create a large number of similar metrics for experimental evaluation, such as the same events selected by the metrics and the same calculation caliber, but the filtering properties are different. For each experiment, a batch of such metrics/metric groups needs to be created, which will accumulate a large number of similar metrics in the long run, resulting in confusion in metric management and not conducive to the establishment of a benign experimental evaluation metric system.

The flexible property function of experimental metrics is hoped to solve the above problems, increase the reusability of metrics, and establish a healthier customer metric system.
