## Brief introduction

Intelligent operation(Campaigns) is a set of marketing automation tools to support the operation staff to carry out user accurate reach, in order to improve user operation efficiency.

<span id="主要功能"></span>
## Main function


* **Accurate user segmentation:**  Support to delineate target users in various ways such as user grouping, user properties, and behavioral conditions;

* **Precise access timing:**  according to preset rules, marketing actions can be automatically triggered by user behavior, and support regular access, routine access and other methods;

* **Process canvas:**  Automated processes can be designed and arranged to automatically remind users during the user journey to promote user conversion;

* **Multi\-task triage and “horse\-race” internal competition mechanism:**  use multiple sets of content to reach users at the same time in one task, and manually or automatically select the best solution according to the reach effect;

* **Cross\-channel reach:**  The system merges and connects the user's behavior at each touchpoint through user_unique_id, and also supports cross\-channel reach;

* **Real\-time effect monitoring:**  The system provides push real\-time data reports to help operators monitor the reach effect.


<span id="入口"></span>
## Entrance

In the BytePlus A/B test, click Scenario Capability/Intelligent Operation to enter the Intelligent Operation module. It is divided into the following sections: push task management, process canvas, push channel management, and general settings. For details, please refer to the introduction of each module.
