### What is FeatureFlag?

Feature Flag is an agile development technology that combines function switch + dynamic configuration + grey release + configuration management. Based on the advanced Feature flag engine and one\-stop configuration hosting capabilities, it can meet different application scenarios such as grey release, A/B experiment to full volume, and crowd\-oriented release. Help development, product, and operations personnel iterate on new features in a low\-risk environment to achieve lean and agile development.

FeatureFlag decouples the development, deployment, and release of features through an If/else or more complex decision tree declaration, thus achieving:


1. **Improve development efficiency:**  Multiple Features can be developed in parallel, deployed online at any time, and released when ready.

2. **Reduced release risk:**  Feature fine grain\-based progressive grey release, Feature second version rollback.


Feature flags have many uses, and their technical essence is to issue different functional parameters according to user\-specified rules in order to achieve the use effect of agile publishing. In addition to the most common and commonly used "function switches", it can also realize the ability to dynamically issue "application configuration", "business configuration", "environment configuration", "security configuration" and many other parameters. Of course, they are ultimately reflected in the product/application, and they are all functions one by one.

### Why you need FeatureFlag

In the red ocean era of intense competition on the Internet, lean development and efficient iteration have increasingly become a powerful tool for product competition. In the process of product iteration, how to ensure the safe launch of efficient function iteration and how to quickly realize the fine operation of different groups of people have become new challenges for product and R & D personnel. In order to help enterprises solve such iteration pain points, Feature Flag came into being.


* **R & D:** 

   * New feature release, how to ensure safe online?

   * After the A/B experiment, how to correct the full amount?

* **Operation:** 

   * Want to do an operation activity, how to conveniently implement different strategies in different cities?

   * The event should be launched on time on Double Eleven. How to automatically go online and offline?

* **Operation and maintenance:** 

   * APP, H5, Mini Program, how to manage multi\-terminal configuration?

   * More and more redundant code, how to do configuration governance?

* **QA：** 

   * New features are released, how can we detect anomalies in a timely manner?

   * How to quickly locate abnormal problems? How can we minimize losses?
