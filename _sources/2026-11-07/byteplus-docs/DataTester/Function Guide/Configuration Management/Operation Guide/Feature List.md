# Introduction to functions

The Feature list shows the basic information of all Features, and all Features under the corresponding APP can be filtered according to the application. You can view the basic information and release status of all features under each app on the list page.

<span id="二、如何使用"></span>
# How to use

**List filter**


* Filter by Application, Update Time, Release Status, Features/keys, and Tags.

* Click "Mine & Favorites" on the right to filter out the Features I created or collected.

* Click the Favorite button next to the list Feature name to bookmark the Feature.


**List content**


* Display the name, key, owners, applicable APP, switch status, release status, associated experiments, operations, etc. of the selected Feature.

* Click on the Feature name to go to the Feature's version management details page.
