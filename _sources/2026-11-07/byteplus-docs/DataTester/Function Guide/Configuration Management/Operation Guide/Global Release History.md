<span id="一、功能简介"></span>
# Introduction to functions

Experiments and Features control the effectiveness of certain functions and policies, so Feature releases and experimental activation/expansion will affect online users. If there is an abnormality online, it is necessary to investigate which experiments or feature changes are caused. Global Release History provides release actions for all Features, which can help troubleshoot which releases took place over a period of time, reducing the cost of troubleshooting issues.

<span id="二、如何使用"></span>
# How to use


* Entrance: Feature list, left navigation click "Release History"

* Support search by: application, release status, release time, label/name/key
