<span id="一、概述"></span>
# 1. Overview

Visual Editor is a WYSIWYG tool that **modifies** the content design layout of website pages; supports visual editing for any webpage, including: **editing elements and properties, adding widgets components, deleting elements** and other capabilities.

**Solve the following problems:** 

 **(1) Basic visual changes**

With a visual editor, you can make basic visual changes on your website without writing a single line of code. The visual editor's intuitive interface makes it easy to use, even for people with no web technology or coding experience.

 **(2) Advanced modifications**

With the AB visual editor, you can modify elements on a webpage, add targets to track, choose a code editor if you want to make some advanced changes, add widgets base components, and more.

<span id="二、基本概念"></span>
# 2. Basic concepts


|**Concept** |**Description** |
|---|---|
|No code |No need to write a programming language |
|Page design |Contains content, fonts, styles, and layouts |
|Element |DOM element |
|Property |Properties of DOM elements |
|Interactive element |Refers to elements in a web page or application that users can interact with, such as drop\-down menus, opening navigation bars, opening dialog boxes, text boxes, buttons, links, etc |
|Edit the authentication page |Pages that need to be logged in or authenticated before they can be accessed |
|**Widgets** |Contains basic components (text, links, images, videos, pop\-ups, etc.), business components (announcements, carousel, countdown), etc |
|AI text suggestions |Text generation of existing content through AIGC |


<span id="三、应用场景"></span>
# 3. Application scenarios

The usage scenarios of the AB visual editor include:


1. **Interface design optimization:**  With the AB visual editor, product operators can easily create and manage different versions of the interface design to determine which version is more appealing to users, improving user retention and conversion rates.

2. **Content optimization:**  With the AB visual editor, product operators can easily create and manage different versions of content to determine which version is more engaging to users, improving user retention and conversion rates.

3. **Feature optimization:**  Through the AB visual editor, product operators can easily create and manage different versions of features to determine which version better meets user requests, improving user retention and conversion rates.

4. **Marketing Strategy Optimization:**  With the AB visual editor, product operators can easily create and manage different versions of marketing strategies to determine which version is more engaging to users, improving user retention and conversion rates.


<span id="四、快速开始（2步）"></span>
# 4. Quick Start (2 Steps)

Recommended Chrome browser version \> = 90.0.0.0, mainly divided into **2** steps, the overall process is:


* [1. Add in Chrome mall/add by offline download]

   * Method 1: Add in Chrome App Store, search for "VisualEditor", and add to Chrome.

   * Method 2: Or download and add directly, in the extension list, fix the extension.

* [2. Direct use/combined with AB use]

   * **Method 1:**  Open the switch of the visual editor in the extension, and then save the visual operation of the page.

   * **Method 2:**  Visual experiment in DataTester/BytePlus Optimize, click to enter the editor, open a new page, **automatically turn on** the switch, and then visualize the page and save it.
