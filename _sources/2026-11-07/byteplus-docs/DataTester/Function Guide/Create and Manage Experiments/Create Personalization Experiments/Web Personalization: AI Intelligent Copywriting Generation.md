Web personalized experiments combined with large model capabilities provide you with AI intelligent copywriting advice capabilities. For scenarios where there is no idea for text modification, the choice of the best version of the copywriting is difficult, and there are thousands of people and thousands of articles in the Web copywriting, you can use AI intelligent copywriting capabilities to efficiently and intelligently generate copywriting and improve experimental efficiency. This article introduces you to the use of AI intelligent copy generation.

<span id="377e9d48"></span>
# Application scenario

It is recommended that existing content based on web or H5 pages, such as slogans, titles, descriptions, CTA buttons, etc., can be used for **intelligent copywriting suggestions**. Efficiently generate copy through large models to solve the following painpoints:


* Copywriting suggestions. For the modification of the text, there is no idea, there is no senior content operation expert guidance, you can use the intelligent copywriting suggestion of the visual editor, it is a senior expert, he helps you think of more text, you only need to do multiple choice questions on the line.

* I don't know which copy is the best. In the visualization experiment or the multivariate experiment, one copy generates multiple copies to form multiple experimental versions; in the multivariate experiment, multiple elements and multiple copy suggestions form multiple versions. Run a copywriting horse race to see which is the best and find the global optimum.

* If you want to personalize AB for different groups of people, you can use web personalization to personalize different copywriting according to different Demographics, and find the absolute optimal solution for the effects of various copywriting under different groups of people.

# Instructions for use


1. After completing the trial application, after you log in to the DataTester console, click **Personalization** \> **Web Personalization** in the left navigation bar to enter the Web Personalization page.

2. When you enter the web personalization page for the first time, the intelligent copy generation switch prompt pop\-up window of the AI visual editor will appear on the page, and you can turn on the switch.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e1add1ff207548e79135c5647c4b6300~tplv-goo7wpa0wc-image.image) </span>

3. After turning on the switch, you can use the intelligent copy generation capability when you edit the Web personalization experiment and enter the visual editor.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b141e9b2ea0b45c69252ab9219ebe131~tplv-goo7wpa0wc-image.image) </span>

4. Generate copy intelligently through large models.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c6603c9b7d774404be6d938e0ae16a32~tplv-goo7wpa0wc-image.image) </span>

   * For editable text content on the page: When you click on the text content, multiple optimized versions of smart copy will be automatically generated for you at the top right, and you can choose a better copy to apply with one click.

   * Intelligent optimization of overly long text is not currently supported.
