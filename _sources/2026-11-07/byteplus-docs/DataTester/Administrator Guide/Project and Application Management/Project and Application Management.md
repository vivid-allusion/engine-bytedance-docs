Projects are a resource group management method provided by BytePlus, which allows you to manage data resources used by different businesses or projects in groups, isolate and authorize projects based on projects, and perform operations such as application access and user permission management in projects. This article provides you with the main operational guidance for DataTester's project management.

<span id="f12fb941"></span>
# Precautions


* Only accounts with project management privileges can create/edit/modify projects and bind applications to projects.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1d068f226f554057b6bf008f02eff670~tplv-goo7wpa0wc-image.image) </span>

* Only roles with project permissions open can enter the DataTester project to perform A/B experiments and other operations on the application.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dab7c329211e4c73873ec7afa72a9b35~tplv-goo7wpa0wc-image.image) </span>

# Create and manage projects

You can create a new project in the **Management Center** \> **Project Management** page, or edit and delete the created project.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/600dbb0385e249919e0e9dbd2032227e~tplv-goo7wpa0wc-image.image) </span>

# Bind app

<span id="81c48a52"></span>
## Bind the first application

If your project has never been bound before, you need to bind the application before you can conduct A/B experiments on the application.


1. Go to the project access page.

   * You can find the corresponding project in the **Management Center** \> **Project Management** page and click "**Enter Product**" under A/B Test to enter the project access page.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0ed3990bca2e45449313d6fcd76407f1~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">If an application has been bound to a previous project, clicking <strong>Go to Product</strong> takes you directly to the DataTester product console.      </div>
      

   * You can also find the project that has not been bound to the application directly in the project drop\-down box in the upper right corner of the DataTester console, and click the **project access** in the back to enter the project access page.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/04c8bc364a1c409dbf5e90fe4a4d6394~tplv-goo7wpa0wc-image.image) </span>

2. After entering the project access page of DataTester, click **Bind Application** and configure the bound application information according to the interface prompts, as shown below:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c9ec724319ed4213b5e1613f7b80dda9~tplv-goo7wpa0wc-image.image) </span>


<span id="beb47446"></span>
## Add multiple applications

Projects that have bound applications also support binding multiple applications in the future.


1. You can click **Project Management** in the lower left corner of the DataTester console, enter the project list page, click the **details** button of a project, enter the project details, and click **Edit** to enter the Edit Existing Project page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/52ad6430955b44909c02d9307e3a53d9~tplv-goo7wpa0wc-image.image) </span>

2. Click **Bind Application** again to bind multiple apps to your project.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cd93511f972e446099ae7ef6987f9033~tplv-goo7wpa0wc-image.image) </span>

# View AppID, Appkey, and other information


1. After entering the DataTester console, click Project Management in the lower left corner of the page, and click Details after the project list to enter the project details page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0d1251b83fbb42e38198a13d8f4880f6~tplv-goo7wpa0wc-image.image) </span>

2. In the application list of the project details, you can view the application information such as the AppID and App Key of the corresponding application.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e9069b67946e43d0934e170a5beb81d1~tplv-goo7wpa0wc-image.image) </span>
