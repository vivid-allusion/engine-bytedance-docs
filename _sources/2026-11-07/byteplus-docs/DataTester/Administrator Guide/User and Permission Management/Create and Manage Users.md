The administrator can create a new user account and authorize the account according to the business plan. After completion, the account, password, and login address can be synchronized to the corresponding user, who can log in with the created account and use DataTester. This article introduces you to the main points for administrators to create and manage users.

<span id="832b2ed3"></span>
# Precautions

Only the administrator account with **manageable** privileges of the **user management** module can operate to add users.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ddf4eb10f9da44c69d1a74f5020e8259~tplv-goo7wpa0wc-image.image) </span>

<span id="b983c8a8"></span>
# Enter the management center

The operation of creating and managing users is handled in the Administration Center page of the privatized environment. You can enter the Administration Center in the following entrance.


* First login to a privatized environment

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/61ef9dba9c5b4a9aa57f818ba101c43b~tplv-goo7wpa0wc-image.image) </span>

* Other entrances

   You can hover the mouse over the account name logged in in the upper right corner, click **Management Center** in the displayed window, and enter the Management Center page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d3ace6c017fb4b388d82a3b97f55abf4~tplv-goo7wpa0wc-image.image) </span>


On the management center page, you can see the basic information of the current group, and perform all project management, user and permission management operations at the group level.

<span id="_1-1-账号注册"></span>
# Add user


* Single Add: After entering the Admin Center page, click **Add User** to create one user at a time.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/899538d621ff4c83b3f86364569f73fc~tplv-goo7wpa0wc-image.image) </span>

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b2233a19f7e460fa75c586545baf577~tplv-goo7wpa0wc-image.image) </span>

   * Configure the account name on the created pop\-up window, and get the randomly generated user account password.

   * Click Copy to copy the account name, password, login address and other information at the same time. You can send the corresponding information to the corresponding user, who can log in to the privatized environment with their account and password to enter the DataTester console.

* Batch Add: After entering the management center page, click **Batch New** to create multiple users at once.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/12c3783ab17a4eb19388a699184d4d6a~tplv-goo7wpa0wc-image.image) </span>

   * Download the template and fill in the account information, among which the account number and username are required.

   * Upload the template, create the user, and return the creation result.

   * Password acquisition: After the system deployment is completed, contact your project manager/operations staff to obtain it.


<span id="60b45326"></span>
# Reset password

After the user is created, you can use the created user to log in to the privatization environment. The initial account password is a randomly generated password. You can modify the initial password to facilitate subsequent login operations.


* Administrator directly reset password: Administrators can directly reset the password of the created user account on the **system configuration** page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f325df85bc9240b2aee6caa13b3e760b~tplv-goo7wpa0wc-image.image) </span>

* After logging in with this initial password, change the login password: You can log in with the initial password, and then modify the password and bind the MFA device to **personal center**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1b73c492bc8842f6a1171c3ab0e41767~tplv-goo7wpa0wc-image.image) </span>
