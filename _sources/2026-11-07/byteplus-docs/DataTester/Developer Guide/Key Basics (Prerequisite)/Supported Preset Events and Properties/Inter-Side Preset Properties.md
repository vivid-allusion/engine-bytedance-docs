Inter\-side preset properties are preset events and preset properties that are available on all endpoints.


|**Event name** |**Event display name** |**Property** |**Property display name** |**Property value type** |**Property value example or description** |**Trigger timing** |
|---|---|---|---|---|---|---|
|any_event |arbitrary event |param/$app_version |Event production version number information |string |This event is a reserved event and does not represent any true event. |without |
|any_active_event |arbitrary active event |param/$app_version |Event production version number information |string ||without |


For details of preset events and preset properties specific to each end, please refer to the preset event/property document of the corresponding end.
