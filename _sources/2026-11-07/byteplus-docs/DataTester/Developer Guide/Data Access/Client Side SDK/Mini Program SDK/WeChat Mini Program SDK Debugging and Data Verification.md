Before the experiment is launched, it is necessary to ensure that the previous integration process is correct, and only after the experiment is launched can the scientific and effective results be guaranteed! The debugging and data verification ideas of the Mini Program SDK are consistent. The following is an example of the WeChat Mini Program SDK to introduce the core process and operation points of debugging and verification.

<span id="6fcc68a6"></span>
## **1. Turn on the debugging state**

Refer to the [Programming Experiment](https://docs.byteplus.com/docs/DataTester/Programming-Experiment) section to put the experiment in the "debugging" state, as shown in the following figure:


* The experimental status is divided into three categories: debugging, running, and completed.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/681e7dd34bad4e0a88b381afeb2334f5~tplv-goo7wpa0wc-image.image) </span>

<span id="de7183d8"></span>
## **2. Obtain the statistical caliber of the debugging equipment through the interface**


* Turn on the log and A/B Test switches in the WeChat Mini Program SDK init and config respectively, and complete the initialization, see for details [WeChat Mini Program SDK Integration (Universal)](https://docs.byteplus.com/docs/DataTester/WeChat-Mini-Program-SDK-Integration-Universal).

* Through the [4.6 Obtaining various IDs generated by the platform](https://docs.byteplus.com/docs/DataTester/WeChat-Mini-Program-SDK-Event-Tracking-and-Properties#9d8a22ed)method to obtain the corresponding ssid.


<span id="8686091c"></span>
## **3. Add to whitelist**

When creating an experiment, add your test device SSID to the whitelist and click the "Save" button in the lower right corner.

<span id="15a3d791"></span>
## **4. WeChat Mini Program parameter debugging**

After setting up the above steps, clear the cache and compile, and observe whether the ab data packet (that is, the experimental data returned by the abtest_config interface) obtains the configuration in Tester. The following figure shows the successful acquisition of experimental parameters:

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b116a0dc3025f69cc461a33c00563eba.png) </span>

If your WeChat Mini Program has not issued an experiment request, or the experiment request is empty, please follow the steps below to check:


* Is enable_ab_test: true correctly set during initialization?

* Whether the WeChat Mini Program adds "A/B Test Domain Name" and "Incident Report Domain Name" to the WeChat Developer Background/Development/Developer Settings/Server Domain Name "Request Legal Domain Name", please refer to Sections 1.2~ 1.4 for the specific domain name.


After triggering the experimental event, you can observe ab_sdk_version fields and content in the event packet header (the following figure is an example of ab_exposed event, other events, and so on):

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ceb652719d7e57b2ce5d8758973e46ca.png) </span>

<span id="443f83f8"></span>
## **5. Real machine or emulator experimental scene debugging**

In the case of normal debugging of experimental parameters, development or QA/PM/operation, students need to observe whether the page where the experiment is located meets the expectations of the previous experimental design.


* For experimental design and preparation, please refer to the [Programming Experiment](https://docs.byteplus.com/docs/DataTester/Programming-Experiment) section.
