# 1. Overview

As the "golden standard" for causal inference, A/B Testing is a powerful tool for evaluating effectiveness.

BytePlus A/B Testing DataTester is an A/B testing and intelligent optimization platform launched by BytePlus Digital Intelligence Platform (VeDI) to help enterprises make scientific decisions. DataTester was born out of ByteDance and has served hundreds of millions of users for a long time. Through scientific diversion, advanced algorithms and rich experimental functions, it provides scientific decision\-making basis for business growth, user conversion, product iteration, strategy optimization, operation efficiency and other aspects, so that the business can truly be data\-driven.

<span id="四-应用场景"></span>
# 4. Application scenario

<span id="_1-产品"></span>
## **1. Products**


* **Product function iteration:**  headache product upgrade core function which version should be used? Using small portions of traffic for mutual exclusion A/B testing allows you to find the best solution from a variety of scenarios without affecting the user experience.

* **User path design:**  A variety of user path design solutions, which version of the conversion effect is better? Establish A/B testing, focus on observing the conversion funnel indicators, calculate the conversion rate of each link in the conversion process of the user path, and release the best conversion scheme to the general public online.

* **UI & interaction optimization:**  Which is the ideal solution for different page layouts and interface interactions? UI & Interaction major revision, through A/B testing, by comparing the click, conversion, retention and other indicators under different schemes, to find the best iterative version.


<span id="_2-运营"></span>
## **2. Operations**


* **Activity page optimization:**  Continuously optimize the copy, pictures, buttons, colors, etc. of the activity landing page, so that all elements can maximize activity conversion and paid retention, and help operators improve the overall input\-output ratio.

* **Push scheme selection:**  choose push copy/landing page, relying on experience to judge the inevitable bias. Open push testing, small traffic prior, and make scientific choices based on analysis reports. At the same time, it can be set to cycle copy/landing pages to push from time to time to reduce monotony.

* **Visual editing:**  Want to do A/B testing but don't have the support of a developer? You can use visual editing to complete page image/text replacement and editing, element displacement and other operations with simple drag and drop operations, and generate experimental plans. No more code work is required.


<span id="_3-研发"></span>
## **3. Research and development**


* **Recommendation algorithm optimization:**  Can the optimized algorithm improve the data indicators of the corresponding business? It can be verified on a small scale through A/B experiments to avoid large\-scale impact of negative performance, and is suitable for various recommendation algorithm optimization based on content, collaborative filtering and association rules. Algorithms include content\-based recommendation algorithms (recommending similar content based on users' historical records), collaborative filtering\-based recommendation algorithms (recommending relevant content based on the behavior of users with similar interests), and association rule\-based recommendation algorithms (recommending to users based on the relevance of the content itself), ultimately improving user stickiness.

* **Grey release:**  The blind spot of functional/performance testing before release is very likely to leave hidden problems, affecting the user experience and even causing user churn. BytePlus A/B test is connected with the intelligent operation module, providing grey release function, allowing developers to gradually increase the volume during function iteration, one\-click rollback if there is a problem, and stop losses in time.


<span id="_4-市场营销"></span>
## **4. Marketing**


* **Delivery landing page optimization:**  advertising consumption is high, but lead conversion is very low, how to solve it? Through visual A/B testing, the title, picture, copy, form field and overall layout of the landing page can be visually edited, multiple versions can be placed, and the best selection can be selected to improve marketing efficiency.

* **Placing multiple pages with a single link:**  multiple landing pages are placed through different advertising plans, traffic distribution is uneven, data comparison is difficult, and there is no way to choose the best. Establish a multi\-link test, and users visiting the same link can be redirected to different versions of landing pages, thus scientifically selecting the best placement page.

* **Delivery traffic:**  manual deployment of delivery traffic is time\-consuming and labor\-intensive, and the effect is difficult to achieve the best. You can turn on intelligent traffic tuning, which applies Bayesian statistical principles to compare multi\-page metrics in real time, automatically tilt traffic to the best performing page, dynamically update traffic configuration, and stably maximize ROI.
