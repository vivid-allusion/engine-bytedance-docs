Intelligent patrol is a preventive maintenance measure used to regularly check the state of systems and clusters, and promptly identify potential problems. Intelligent patrol generates reports based on patrol items, allowing you to identify and solve problems in advance, reduce system failures and downtime, and ensure system stability and reliability. This tutorial introduces the status and features of intelligent patrol, explains how to create patrol tasks and manage patrol reports, and provides troubleshooting and optimization suggestions for abnormal patrol metrics.

<span id="d34d11bf"></span>
## Function overview

The description of the intelligent patrol function is as follows.


|Sub\-item |Description |
|---|---|
|Patrol item |The current smart patrol checks the system from the aspects of system load and cluster load, with the following specific contents:<br><br><span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4dbdeea8a7fa4ed695805cba913be062~tplv-goo7wpa0wc-image.image) </span> |
|Patrol type |* Manual patrol: Manually triggered.<br><br>* Scheduled patrol: Automatically executed at scheduled times, with options to perform patrol tasks daily, weekly, or monthly. |
|Patrol results |After the patrol task is completed, the system outputs a report that helps users analyze cluster issues from perspectives such as patrol items and their severity levels, abnormal impact, etc., and provides handling suggestions. |
|Resource usage |Intelligent patrols will use the current cluster's resources and may affect performance. It is recommended to perform these during off\-peak hours to avoid impacting operations. |

## Create patrol task


1. Log in to the ByteHouse Console, go to the **Diagnostic** tab, enter the **Intelligent patrol** page, click the **Patrol task** tab, and click **New patrol task**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1148afc2bb574917bfbd64be90ea1519~tplv-goo7wpa0wc-image.image) </span>

2. On the Create patrol task page, fill in the basic information, select the patrol type, and view the patrol contents.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/61af4f6a92b942d685c4c826e71a7918~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Intelligent patrol will consume the current cluster's resources. It is advisable to carry them out during off\-peak hours to avoid affecting operations.   </div>
   

   * Patrol task configuration

      
      |Parameter Items |Parameter Description |
      |---|---|
      |Patrol task name |Supports customizing the patrol task name. |
      |Cluster |Select the cluster for patrol. |
      |Patrol type |Supports manual patrol and regular patrol.<br><br><br>* Manual patrol: After creating the patrol task, you will need to manually trigger the execution from the patrol task list.<br><br>* Scheduled patrol: You can configure the patrol cycle, and within the patrol cycle, the system will automatically run the patrol tasks. |
      

   * Patrol content: For details, please refer to [References: Patrol content description](https://docs.byteplus.com/docs/bytehouse/intelligent-patrol#b568b804).

3. Click **Confirm**. The system will create a patrol task.

4. You can view the created tasks in the patrol task list. You can also select a cluster or input the task name in the patrol task list to view the patrol tasks.


<span id="c6300d6d"></span>
## Manually execute patrol task

For patrol tasks set to manual patrol, you can manually trigger the task execution as needed.

In the patrol task list, click the **Run Immediately** button in the action column, then click **OK** in the popup window, and the system will perform patrol for the cluster.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d739003097d545df8bb60c56ad9cce31~tplv-goo7wpa0wc-image.image) </span>

After the system prompt "**The task was successfully executed**", you can view the results of the patrol task on the patrol report page.

<span id="eb63d539"></span>
## Manage patrol reports

You can view the generated patrol report on the report page, where you can check the patrol results, the impact on the cluster, and handling recommendations.

<span id="db396f3f"></span>
### View the patrol report

On the patrol report page, you can view the list of generated patrol reports and filter them based on the cluster name and patrol report name.

You can click on **patrol report ID** or the **View report** button in the action column to view the report details.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/289d229a298149908e31e2dbe4b3eda2~tplv-goo7wpa0wc-image.image) </span>

The patrol report displays detailed patrol information, including patrol items, patrol values, severity levels, patrol categories, impacts, and suggestions. You can decide whether to address the anomaly based on patrol values, severity levels, and abnormal impacts.

<span id="103e7525"></span>
### Download the patrol report

On the patrol report page, click the **Download report** button in the action column to download the current report.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e7a89f6921bb46188fbb857cb0631149~tplv-goo7wpa0wc-image.image) </span>

You can also click on **patrol report ID**, enter the detail page, and then click **Download report**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b57e960316244e02af6c592f7673f436~tplv-goo7wpa0wc-image.image) </span>

<span id="c401a46f"></span>
### (Optional) Delete the patrol report

To delete a patrol report, go to the patrol report page and click the **Delete** button in the operation column to delete the current report.
