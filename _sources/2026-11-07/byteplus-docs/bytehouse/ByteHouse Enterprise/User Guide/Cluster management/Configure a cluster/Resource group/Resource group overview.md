ByteHouse Resource Group provides a mechanism for isolating and efficiently utilizing resources between multiple tenants.

ByteHouse limits resource use for each group through configuring different parameters for different resource groups, such as maximum CPU usage Proportion, maximum memory usage Proportion, and maximum concurrency, achieving the purpose of resource isolation. ByteHouse Resource Group resolves the issue that users face when using traditional open\-source data warehouses regarding Size queries impacting each other, by isolating resource use between different users or queries, enhancing the system's stability and concurrency capacity.
