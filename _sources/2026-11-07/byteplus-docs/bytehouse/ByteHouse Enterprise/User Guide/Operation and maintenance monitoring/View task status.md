The current ByteHouse Enterprise edition supports viewing ongoing and completed DataRanger's Technical Support missions, including creating database and table, cluster level upgrade rollback, and vertical reconfiguration actions, facilitating the view, filter, and retry of historical actions for tracking and backing up Action history.

You can access Task Center \-\> Maintenence center to view details.
