The system table `ha_queue` displays the status of unfinished log entry for the HaMergeTree table.

<span id="b6520968"></span>
## Column name


|**Field name** |**Data types** |**Field definitions** |
|---|---|---|
|type |String |The types associated with a log entry, such as clone_part, get_part, merge_parts, and more. |
|lsn |UInt32 |The LSN corresponding to the log entry. |
|create_time |DateTime |The creation time of a log entry. |
|source_replica |String |The replica who created the log entry. |
|new_part_name |String |The name of the new part generated by the log entry. |
|parts_to_merge |Array(String) |If the type is merge_parts, it specifies the source part to be merged. |
|total_rows |UInt64 |The total number of lines in the source part corresponding to merge_parts/mutate_part. |
|total_size |UInt64 |The total size of the source part corresponding to merge_parts/mutate_part. |
|is_currently_executing |UInt8 |Whether this queue is currently executing. |
|num_tries |UInt32 |The times that the log entry has already run. |
|first_attempt_time |DateTime |The time of the first run. |
|last_attempt_time |DateTime |Last run time. |
|last_exception_time |DateTime |The time when the last exception was encountered. |
|last_exception |String |Information about the last encountered exception. |
