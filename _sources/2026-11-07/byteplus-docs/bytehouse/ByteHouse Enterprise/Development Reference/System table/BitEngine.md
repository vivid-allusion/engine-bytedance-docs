The system table BitEngine is a self\-developed 64\-bit bitmap processing solution by ByteHouse, implemented based on the CRoaring open\-source library. The core consists of three parts:


* BitMap64 is a ByteHouse basic analysis data type.

* The dictionary encoding optimization system, based on the BitMap64 type, improves computational performance by increasing BitMap64 density.

* A set of efficient UDF/UFAF is provided based on business scenarios.


<span id="7656931c"></span>
## Column name


|**Name** |**Data type** |**Description of field meanings** |
|---|---|---|
|database |String |Database name corresponding to tables that use the BitEngine function. |
|table |String |Table names for tables that use the BitEngine function. |
|engine |String |Tables use storage engines, such as MergeTree and HaMergeTree. |
|encoded_columns |Array(String) |Which BitMap64 fields have enabled the BitEngine enhanced function. |
|encoded_columns_size |Array(String) |The dictionary size generated by BitMap64 in the encoding task. |
|uniqExact_keys_size |Array(String) |The deduplication dictionary size generated by BitMap64 during the encoding task (normally equal to encoded_columns_size). |
|version |UInt64 |Local dictionary version number. |
|zookeeper_version |UInt64 |The version number for the local dictionary, which is stored in Zookeeper, is used to synchronize dictionary data between multiple copies. |
|is_valid |UInt64 |Whether the dictionary state is normal. |
|shard_id |UInt64 |The shard numbers for this node, starting from 0. |
|shard_base_offset |UInt64 |The start encoding value pre\-assigned to each node. |

## Example

```SQL
show create test.test_bitmap; 

SELECT * FROM system.bitengine where database = 'test' and table = 'test_bitmap';
```


```SQL
-- show create test.test_bitmap 
CREATE TABLE test.test_bitmap
(
    `tag_id` Int32,
    `tag_value` String,
    `uids` BitMap64 BitEngineEncode,
    `p_date` Date
)
ENGINE = HaMergeTree('/clickhouse/test/test_bitmap_dfadx/{shard}', '{replica}')
PARTITION BY p_date
ORDER BY (tag_id, tag_value)
SETTINGS index_granularity = 128
```
