The module of Geographic Information System (GIS) includes geometric types such as points, lines, and surfaces, as well as the spatial position relationship between geometries and the surrounding ecology.
For compatibility, the [Open Geospatial Consortium (OGC)](https://en.wikipedia.org/wiki/Open_Geospatial_Consortium) Standard to meet user needs, the complete GIS module can be found in the figure below.
<div style="text-align: center"><img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0cf1d0dc7efc4ac78d4718db6dbe630f~tplv-goo7wpa0wc-image.image" width="740px" /></div>

The current ByteHouse Enterprise Edition supports three types: Point, LineString, and Polygon. It is recommended to upgrade to the latest engine for a better experience.
On the basis of supporting the above geometric types, we also need to define basic spatial function operations, including spatial positional relationships (equality, intersection, covering, crossing, etc.), distance calculations, geometric operations, etc.
