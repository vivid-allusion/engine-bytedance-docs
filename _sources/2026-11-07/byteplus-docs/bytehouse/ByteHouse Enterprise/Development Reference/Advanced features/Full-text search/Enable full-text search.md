## Enable when creating cluster

When creating a cluster, you can enable the full\-text search function. You can enable the **full\-text search** function in the advanced features module. For detailed charges, refer to the charging description.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9b4e2b38eb2649c2ba90b6e51d5c86a6~tplv-goo7wpa0wc-image.image) </span>

<span id="9ce29bb3"></span>
## Enable on the console


1. On the ByteHouse console, go to the **Cluster management** \> **Cluster list** page, click **Advanced features**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b0ff17f6c0b14f779d0d4ea559ea9f3d~tplv-goo7wpa0wc-image.image) </span>

2. Select the applicable cluster and activate the full\-text search function.

3. Click **Submit**. The system will automatically activate the full\-text search function.
