## evalMLMethod (Predict)
To predict using a regression model, please use the `evalMLMethod` function. Please refer to the link in `linearRegression`.
<span id="912d137b"></span>
## Stochastic Linear Regression
The `stochasticLinearRegression` aggregate function uses a linear model and MSE loss function to implement stochastic gradient descent. Use `evalMLMethod` to predict new data.
<span id="0ca75c50"></span>
## Stochastic Logistic Regression
The `stochasticLogisticRegression` aggregate function implements stochastic gradient descent for binary classification problems. Use `evalMLMethod` to predict new data.
