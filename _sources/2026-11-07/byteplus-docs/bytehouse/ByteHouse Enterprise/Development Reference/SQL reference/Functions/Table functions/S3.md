The S3 table function provides an interface similar to a table to search with Select or insert files into S3. This table function is similar to HDFS but provides features unique to S3.
**Grammar**
```SQL
s3(path [,access_key_id, secret_access_key [,session_token]] ,format, structure, [compression])
```

**Param**

* `Path` — URL containing the file path of the Bucket. In read-only mode, the following wildcard characters are supported: `*`, `?`, `{abc,def}`, and `{N..M}`, of which `N`, `M` are numbers, `'abc'`, `'def'` are strings.
* `Format` — the Format of the File.
* `Structure` — the structure of the table. The format is `'column1_name column1_type, column2_name column2_type, ...'`.
* `Compression` - Compression Type. Supported values: `none`, `gzip/gz`, `brotli/br`, `xz/LZMA`, `zstd/zst`. Params are optional. By default, the compression type is automatically detected by the file extension.

**Return Value**
A table with a specified structure used to read or write data in a specified file.
**Example**
Select the first two rows of the table from the S3 file `https://storage.yandexcloud.net/my-test-bucket-768/data.csv`:
```SQL
SELECT *
FROM s3('https://storage.yandexcloud.net/my-test-bucket-768/data.csv', 'CSV', 'column1 UInt32, column2 UInt32, column3 UInt32')
LIMIT 2;
```

```Plain
┌─column1─┬─column2─┬─column3─┐
│       1 │       2 │       3 │
│       3 │       2 │       1 │
└─────────┴─────────┴─────────┘
```

Similar case, but the source is a `gzip` compressed file:
```SQL
SELECT *
FROM s3('https://storage.yandexcloud.net/my-test-bucket-768/data.csv.gz', 'CSV', 'column1 UInt32, column2 UInt32, column3 UInt32', 'gzip')
LIMIT 2;
```

```Plain
┌─column1─┬─column2─┬─column3─┐
│       1 │       2 │       3 │
│       3 │       2 │       1 │
└─────────┴─────────┴─────────┘
```

## Usage
Suppose we have several files on S3, the URIs are as follows:

* '[https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_1.csv'](https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_1.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_2.csv'](https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_2.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_3.csv'](https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_3.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_4.csv'](https://storage.yandexcloud.net/my-test-bucket-768/some_prefix/some_file_4.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_1.csv'](https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_1.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_2.csv'](https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_2.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_3.csv'](https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_3.csv')
* '[https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_4.csv'](https://storage.yandexcloud.net/my-test-bucket-768/another_prefix/some_file_4.csv')

Calculate the total number of rows for files ending with the numbers 1 to 3:
```SQL
SELECT count(*)
FROM s3('https://storage.yandexcloud.net/my-test-bucket-768/{some,another}_prefix/some_file_{1..3}.csv', 'CSV', 'name String, value UInt32')
```

```Plain
┌─count()─┐
│      18 │
└─────────┘
```

Calculate the total number of lines in all files within these two directories:
```SQL
SELECT count(*)
FROM s3('https://storage.yandexcloud.net/my-test-bucket-768/{some,another}_prefix/*', 'CSV', 'name String, value UInt32')
```

```Plain
┌─count()─┐
│      24 │
└─────────┘
```

!!! warning "Warning" If the file list contains numbers starting with zero, use a bracketed structure for each number or use `?`.
Calculate the total number of lines in files named `file-000.csv`, `file-001.csv`, … , `file-999.csv`:
```SQL
SELECT count(*)
FROM s3('https://storage.yandexcloud.net/my-test-bucket-768/big_prefix/file-{000..999}.csv', 'CSV', 'name String, value UInt32');
```

```Plain
┌─count()─┐
│      12 │
└─────────┘
```

Insert data into the `test-data.csv.gz` file:
```SQL
INSERT INTO FUNCTION s3('https://storage.yandexcloud.net/my-test-bucket-768/test-data.csv.gz', 'CSV', 'name String, value UInt32', 'gzip')
VALUES ('test-data', 1), ('test-data-2', 2);
```

Insert data from an existing table into the `test-data.csv.gz` file:
```SQL
INSERT INTO FUNCTION s3('https://storage.yandexcloud.net/my-test-bucket-768/test-data.csv.gz', 'CSV', 'name String, value UInt32', 'gzip')
SELECT name, value FROM existing_table;
```
