# stddevPop {#stddevpop}
The result is equal to the square root of [varPop](../../../sql-reference/aggregate-functions/reference/varpop.md).
:::tip
This function uses numerically unstable algorithms. If you need [numerical stability](https://en.wikipedia.org/wiki/Numerical_stability) in calculations, use the `stddevPopStable` function. It operates slower but provides lower calculation errors.
:::
