# Sum
Calculate the sum. Applicable only to numbers.
<span id="sumwithoverflow"></span>
# sumWithOverflow
Calculate the numerical sum using the same data type as the input parameters. If the sum exceeds the maximum value of this data type, calculate using overflow.
Applicable only to numbers.
