This article introduces the use scenarios of the funnel analysis function and its basic usage.
Business scenario of the funnel analysis function: Select a time period and observe the funnel layer summary of each time unit (day) within this time period divided by a certain time limit.
<span id="f8805140"></span>
## finderFunnel()
Use **finderFunnel** to calculate the performance of **every user** within a time window.
```Python
finderFunnel(window, start_timestamp, check_granularity, watch_numbers)(server_timestamp, client_timestamp, check_event1, check_event2...)
```


* `window`: The total duration of the observation window, with the same unit as `client_timestamp`, usually in milliseconds, with the example below being 86400 * 7 * 1000 milliseconds, which is 7 days.
* `start_timestamp`: Analysis start timestamp, such as analysis starting from 2022-06-01, so the start timestamp is `toUInt64(toUnixTimestamp('2022-06-01')) = 1654012800`
* `check_granularity`: An observation step duration, how large a granularity inside to calculate conversion analysis, with the unit consistent with `client_timestamp`, such as 1 day, then is 86400 (unit: seconds).
* `watch_numbers`: how many steps to observe, if `check_granularity` is 86400 (1 day), `watch_numbers = 7`, indicating watching the funnel situation every day for 7 days starting from `start_timestamp`
* `server_timestamp`: Server time stamp of when the event occurred, needs to be converted to UInt64 type, used to calculate the event time slot/step during function runtime, usually in seconds.
* `Client_timestamp`: Event occurrence client timestamp column, needs to be converted to UInt64 type for sorting the data during function execution, usually in milliseconds.
* `Check_event`: List of conversion events, those meeting the conditions within the defined duration scope of `window` will be considered effective event triggers. If there are 3 events, then input: EventName = 'E0001', EventName = 'E0002', EventName = 'E0003'

<span id="2c564d9b"></span>
## funnelRep()
Use funnelRep aggregate the results of finderFunnel, forming a summary of all users at every layer of the funnel.
```Python
funnelRep(number_steps, evnet_count)(funnel_res)
```


* `Number_steps`: UInt type number, includes the quantity of time slots, usually consistent with `finderFunnel` function’s `watch_numbers`.
* `Event_count`: UInt type number, represents the total number of events in the conversion chain, usually consistent with the event quantity in `finderFunnel` function’s `check_event`.
* `Funnel_res`: Conversion step list, produced by the `finderFunnel` sub-query, containing all conversion steps generated by each user.

Return results:

* Return a two-dimensional array, in which there is a total of 1 summary result + `number_steps`sub-arrays. The first sub-array is the summary result, and the second sub-array is the funnel calculation result within the defined duration scope of `window` for the first time slot, and so on.

<span id="b1ef957a"></span>
## Funnel analysis SQL examples
The following example refers to the conversion funnel of 3 events 'E0001', 'E0002', 'E0003' over 7 days from 2022/6/1 to 2022/6/8:
```SQL
SELECT funnelRep(7, 3)(funnel_res)
FROM
(
 SELECT finderFunnel(7 * 86400 * 1000, 1654012800, 86400, 7)(toUInt64(toUnixTimestamp(LOG.EventTime)), toUInt64(toUnixTimestamp(LOG.EventTime)) * 1000, LOG.EventName = 'E0001', LOG.EventName = 'E0002', LOG.EventName = 'E0003') AS funnel_res
 FROM LOG
 LEFT JOIN
 (
 SELECT *
 FROM User AS t
 ) AS U ON LOG.Visitor = U.Visitor
 WHERE (EventTime >= '2022-06-01 00:00:00') AND (EventTime <'2022-06-08 00:00:00') AND (EventName IN ('E0001', 'E0002', 'E0003'))
 GROUP BY Visitor
)
SETTINGS distributed_product_mode = 'local', distributed_group_by_no_merge = 1
```

The example SQL above returns as follows:
```SQL
┌─funnelRep(7, 3)(funnel_res)─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [[5994501,5944849,56423],[3791527,3780488,39431],[3792876,3767458,33024],[3792031,3733089,26709],[3791519,3656585,20668],[3791859,3480158,14385],[3793389,3077233,8691],[3792344,2143108,3641]] │
```


* Thus, the overall funnel (E0001->E0002->E0003) is: [5994501,5944849,56423]
* The funnel on day 1 is: [3791527,3780488,39431]
* ...
* The funnel on day 7 is: [3792344,2143108,3641]
