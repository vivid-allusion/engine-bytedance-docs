ByteHouse offers **Enterprise Edition** and **Cloud Data Warehouse Edition**, allowing users to choose on the BytePlus official website according to their needs. Besides being hosted on BytePlus, the Enterprise Edition can also meet the scenario of private deployment for users.

The differences between versions are shown in the table below.


| |ByteHouse Enterprise Edition \- Private Deployment |ByteHouse Enterprise Edition \- BytePlus |ByteHouse Cloud Data Warehouse Edition |
|---|---|---|---|
|Product Form |Private deployment in customer environment |Public cloud PaaS Product |Public cloud SaaS product |
|Product architecture |MPP architecture |MPP architecture |Storage\-compute decoupling (cloud\-native) architecture |
|Billing model |License fees charged per core, or one\-time purchase |Annual or monthly leasing |Pay\-as\-you\-go billing |
|Interface feature comparison |* Operations management<br><br>* User management<br><br>* Database and table management<br><br>* Data import<br><br>* Query management |* Self\-service application<br><br>* Operations management<br><br>* User management<br><br>* Database and table management<br><br>* Data import<br><br>* Inquiry management |* Self\-service application<br><br>* Elastic scaling<br><br>* User management<br><br>* Database and table management<br><br>* Data import<br><br>* Inquiry management |
|* Product Advantages |* White screen operation and maintenance<br><br>* Extreme performance<br><br>* Compatible with open source ClickHouse |* White screen maintenance<br><br>* Immediate application<br><br>* Ultimate performance<br><br>* Compatible with open source ClickHouse |* White screen maintenance<br><br>* Storage\-compute decoupling<br><br>* Resource isolation<br><br>* Flexible expansion |
|Product Entry |[Test Application](https://www.byteplus.com/en/contact) |[BytePlus](https://console.byteplus.com/auth/login?redirectURI=%2Fbytehouse-ce) |[BytePlus](https://console.byteplus.com/auth/login?redirectURI=%2Fbytehouse-ce) |
