Engine branches of higher versions include all the features of lower\-version branches; it is recommended that new projects use the latest released engine branch.


|**Engine Branch** |**Features** |**Branch Release Date** |**Recommended Version** |
|---|---|---|---|
|**ce\-2.7** |* General table creation functionality<br><br>* Bucket table engine<br><br>* Query optimizer enhancements, including automatic statistics collection<br><br>* Resource group isolation capabilities<br><br>* Enhancements to GIS spatiotemporal analysis, full\-text search, and vector search<br><br>* Read\-only copy<br><br>* WAL batch write capability<br><br>* Support for Lakehouse features, such as external data access |November 2024 |2.7.2.152 |
|**ce\-2.6** |* Asynchronous materialized view<br><br>* GIS spatiotemporal analysis, full\-text search, and vector search |May 2024 |2.6.1.184 |
|**ce\-2.4** |* HaMergeTree and HaUniqueMergeTree high availability table engines<br><br>* S3 cold storage capability<br><br>* MaterializedMySQL<br><br>* BitEngine dictionary table<br><br>* Optimizer query |October 2023 |2.4.1.308 |
