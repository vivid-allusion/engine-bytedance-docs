## Getting started with ByteHouse

<span id="1272f6ad"></span>
### 1. Start the service

Click the upper left corner of the BytePlus console to display the **Products and Services** list, then select "**ByteHouse Enterprise Edition**".

When you first enter ByteHouse Enterprise Edition through a BytePlus account, the ByteHouse service will be activated, and the system will automatically generate an initial service password for ByteHouse.

Click the user icon at the top right corner of the interface. In the dropdown menu, click "Account management" to copy the temporary service password generated by the system for the user.

### 2. Create a cluster

To use the ByteHouse Enterprise Edition, you first need to create a ByteHouse cluster. The cluster provides the complete ByteHouse service.

Let's start creating a new cluster:


1. Log in to BytePlus and enter the [ByteHouse Enterprise Edition Console](https://console.byteplus.com/bytehouse-ce/region:bytehouse-ce+ap-southeast-1/dashboard/cluster/overview).

2. Click the **Create Cluster** button to enter the new cluster configuration interface.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/98159536730b43bfbf44cd85ac80c752~tplv-goo7wpa0wc-image.image) </span>

3. Select the options for creating a new cluster. You need to choose the appropriate computing and storage resources based on your actual data volume:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a1251cca0b814435b369d2c09494eaeb~tplv-goo7wpa0wc-image.image) </span>

   
   |Parameters |Description |
   |---|---|
   |**Region** ||
   |Region |The location of theBytePlus Data Center is divided into different regions based on different geographic locations. After an instance is created, the region of the instance cannot be changed.<br><br>For more information, please refer to @ |
   |Availability Zone |It is a collection of one or more physical data centers. In the same region, the power networks of the availability zones are independent of each other, meaning that the failure of one availability zone does not affect other availability zones in the same region. Availability zones from different regions are isolated from each other, while those in the same region can communicate with each other. |
   |**Pricing Information** ||
   |Billing Type |ByteHouse Enterprise currently only supports annual and monthly billing models. Billing details, see: [Billing method](https://docs.byteplus.com/docs/bytehouse/billing-method). |
   |**Computational Resources** ||
   |Specifications |The specification of a single compute node ranges from 4 Cores 16 GB to 64 Cores 256 GB. Compute specifications are directly correlated with cluster performance. |
   |Replication Mode |* **Single Replica:**  refers to a shard of the ByteHouse cluster containing only one node. The cluster becomes unqueryable and data cannot be imported during node failures or cluster reboots.<br><br>* **Dual Replica:**  refers to a shard of the ByteHouse cluster containing two nodes, ensuring high availability.    |**Storage resources** ||
   |Single node storage space |Single node's data disk space, which is the space available to ByteHouse.<br><br><br>* In a single replica setting, the total storage of the cluster is `single node storage space * number of nodes`, with a capacity of `single node storage space * number of nodes`.<br><br>* In a dual replica setting, the total storage of the cluster is `single node storage space * number of nodes`, with a capacity of `single node storage space * number of nodes/2`. |

Cold storage is billed separately, and you can also enable this feature later. See details [Cold-hot storage](https://docs.byteplus.com/docs/bytehouse/cold-hot-storage). |

   |Subnet |A subnet is an IP address block within a private network; after creating a private network, subnets can be created to divide the private network into one or more network modules. See [Subnet Documentation](https://docs.byteplus.com/en/docs/vpc/Creating-a-subnet). |
   |Security Group |A security group is a logical grouping meant to provide access policies for cloud servers within the same private network that have similar security needs and trust each other; it is an important means of network security isolation. 4. After selecting all the information, check the "**I have read and agree to**" the related agreement, click **confirm order**, and the creation of the cluster is completed.

5. Once the cluster enters the "running" state, it can be accessed normally.

### 3. Import users

If you need to activate ByteHouse Enterprise Edition for sub\-users as well, the following operations are required:


1. **Use major account** to associate the ByteHouse Enterprise edition IAM policy to the sub\-user.

   1. Login to the [Access Control IAM Console](https://console.byteplus.com/iam).

   2. In the left\-side navigation panel, select **Identity Management** \> **Users**.

   3. In the **User List**, locate the username for which permissions need to be set, and click the **Operations** column under **Manage**.

   4. On the **User Details** page, select **Permissions** \> **Global Permissions** tab and click **Add Permission**.

   5. In the **Add Permission** panel's search box, enter **ByteHouseCEFullAccess** and add it.

   6. Once completed, click **Confirm**.

2. The **sub\-user** can enter the ByteHouse Enterprise edition console through the IAM login page.

### 4. Access cluster by GUI

Click Create cluster to start managing your data.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fee7471c6e6c47ee9118bb448c535408~tplv-goo7wpa0wc-image.image) </span>

After creating a cluster, you can perform the following operations on the cluster through the GUI:


* [Create a new database/table](https://docs.byteplus.com/docs/bytehouse/create-a-new-database-table): Supports the creation of libraries and tables, and partition management.

* [Concept](https://docs.byteplus.com/docs/bytehouse/import-data-concept): Supports importing data into ByteHouse from [Streaming import](https://docs.byteplus.com/docs/bytehouse/streaming-import)/[Batch import](https://docs.byteplus.com/docs/bytehouse/batch-import).

* [Query window](https://docs.byteplus.com/docs/bytehouse/query-window): Supports initiating queries on the cluster, browsing query history, and diagnosing large queries.


<span id="b1cbfc33"></span>
### 5. Access to the cluster by Client

On any cloud server connected to the ByteHouse cluster network, [install clickhouse-client](https://clickhouse.com/docs/en/integrations/sql-clients/cli/) and execute commands to connect to the cluster:

```bash
clickhouse-client --host <HOSTNAME> \
                  --user <USERNAME> \
                  --password <PASSWORD>
```


Refer to the following for steps and parameter configuration: [ClickHouse Client](https://docs.byteplus.com/docs/bytehouse/clickhouse-client).
