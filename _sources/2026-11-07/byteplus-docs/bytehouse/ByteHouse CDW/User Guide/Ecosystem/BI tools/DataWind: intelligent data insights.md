## Intro

Intelligent Data Insights [DataWind](https://www.volcengine.com/product/datawind) is an enhanced ABI platform based on granular big data analysis. It offers trillions of data points, sub\-second query performance, supports rich visualization effects and simple drag\-and\-drop operations, and integrates AI technology for intelligent data insights. DataWind is a product of BytePlus.

<span id="创建bytehouse帐户"></span>
## Create a ByteHouse Account

You need to create a **BytePlus account** to use Intelligent Data Insights DataWind. For the creation procedure, please refer to ["BytePlus Account Registration and Verification Guide"](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).
