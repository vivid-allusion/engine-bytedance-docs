ByteHouse Cloud Warehouse Edition supports user activities related audit log capabilities. You can view detailed user behavior logs, including user behavior audit, search logs, and permission audit through user activity audit logs. This article provides an overview of the user activity audit function.

<span id="20e35a41"></span>
# Function Overview

After logging in and entering the ByteHouse Cloud Warehouse Edition Console, click on **audit logs** at the top to enter the audit log page, and click **User Activities** on the left navigation bar to enter the user activity audit page.


* User activity audit logs support viewing of actions for objects including: **Backup & Restore**, **Environment**, **Network**, **Dedicated Server**, **User & Roles**. You can view the details of add, delete, and modify logs for corresponding action objects.

* You can quickly filter and find user activity audit logs using filters such as time scope, action state, operating user, or user role in the top filter bar.
