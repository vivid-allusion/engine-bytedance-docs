Through the "ByteHouse Console \- Audit Log \- Permission Audit" page, we can search for the list of logs related to permission changes and filter historical records using filter conditions.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d962034535444df594230c93d20d9a56~tplv-goo7wpa0wc-image.image) </span>

The historical list of permission logs includes the following information:


* Start Time: The specific date and time of the event.

* User Account: The User ID number of the user who performed the action.

* User Name: The name of the user who performed the action.

* Type of Authorization: "User" or "Role".

* Authorized Object: The "User Name" or "Role Name" that has been authorized.

* Operation Type: Grant "GRANT" or revoke "REVOKE".

* Permission: The resource or data permissions that have been granted or revoked.

* Data Type: The type of objects involved in the operation, such as resources, databases, tables, and others.

* Name: The specific name or path of the object involved in the operation.

* State: The completion status of the event, such as "Success" or "Failed".

* Details: Detailed description of how the event was completed.
