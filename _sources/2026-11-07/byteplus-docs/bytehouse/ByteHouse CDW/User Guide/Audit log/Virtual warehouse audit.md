Through the "ByteHouse Console \- Audit Log \- VW Audit" page, you can search for logs on the use and changes in the compute group and filter historical records through filter conditions.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/29beee51c4e4483b887333d5ab2ab8e5~tplv-goo7wpa0wc-image.image) </span>

The compute group log history list contains the following information:


* Start Time: The specific date and time of the event.

* User Account: The User ID of the user performing the action.

* User name: Name of the user performing the action.

* User Role: Role of the user performing the action.

* Operation Type: The type of operation performed, such as launch, suspend, add, view, edit, delete, renew, unsubscribe, execute, and others.

* Compute Group Name/ID: Name of the compute group involved in the operation.

* Source: "System" or "User".

* Status: Event completion status, such as "Success" or "Failed".

* Details: Detailed explanation of the event completion.
