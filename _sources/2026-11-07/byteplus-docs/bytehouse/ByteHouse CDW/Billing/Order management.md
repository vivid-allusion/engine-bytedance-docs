Log in to the BytePlus console, enter the **Cost Center \- Order Management** page, where you can view all created order information and also purchase or cancel orders that have been created but are pending payment.

**1. Search and Filter Conditions**

Orders can be searched based on the following criteria.


* Order Number: Input the order number to view a specific order.

* Created at: Select a start and end date to view orders created during this time frame. Default search is for orders from the past month.

* Products: Select a product to filter orders for the chosen product.

* Order Type: Choose an order type to filter different types of orders.

* Order Status: Choose an order status to filter orders under different statuses.


**Table Field Description**

The order list displays order numbers, products, types, created time, last updated time, status, original price, and payable amount.


* Order number: The unique identifier for an order.

* Product: Displays the name of the product corresponding to the order.

* Type: Indicates the type of order, which can be "new purchase, trial, confirmed, renewal, upsell, unsubscribed, reserved instance adjustment, temporary upgrade" \- eight types in total.

* Created at: Represents the time when the order was created.

* Last updated: Represents the time when the status was updated.

* Status: Represents the current status of the order, which includes "pending payment, paid, cancelled, refunded, partially refunded, refunding, refund failed" \- seven types in total.

* Original price: Represents the original price of the order.

* Payable: Represents the cash amount payable in the order.

* Actions: For orders with a "Pending Payment" state, the available actions are "Purchase" or "Cancel"; for orders in other states, only the order number can be clicked to "View Details".
