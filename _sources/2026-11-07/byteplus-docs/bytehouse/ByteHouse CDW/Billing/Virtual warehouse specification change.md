## Billing mode switch

For users who activate the ByteHouse cloud data warehouse service in May 2024 and afterwards, they can change the billing type of the virtual warehouses they created at any time.


1. On the **Virtual Warehouse** page, we can see all the opened virtual warehouses and their corresponding billing types.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cd88f9e3d33d453babe48b1619d3a9cf~tplv-goo7wpa0wc-image.image) </span>

2. Click the "..." button on the far side of the virtual warehouse you want to switch billing types for, where you can see the "Switch to Pre\-paid" or "Switch to Post\-paid" options.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3168787420bf4d66b2074e51250e6271~tplv-goo7wpa0wc-image.image) </span>

3. On the pop\-up page, confirm the payment information is correct, click the "Confirm" button, then click "Confirm" to confirm the order. Wait a moment and then the payment mode switch is complete.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/de38bfe30aa8425581d224c415b10868~tplv-goo7wpa0wc-image.image) </span>

## Billing configuration change

<span id="aa91a4f5"></span>
### Pre\-paid configuration change


1. On the **Virtual Warehouse** page, we can see all the opened virtual warehouses, as well as their corresponding models.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cd88f9e3d33d453babe48b1619d3a9cf~tplv-goo7wpa0wc-image.image) </span>

2. Click the "Edit" button after selecting the virtual warehouse whose billing type you want to change.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a1042e7ddb214a82818ce164252f3bff~tplv-goo7wpa0wc-image.image) </span>

3. Select a new annual/monthly package model and click confirm.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c8af33c2948c45d4887b1a3d07a136cd~tplv-goo7wpa0wc-image.image) </span>

4. On the pop\-up page, confirm the order information, click "Next," and wait a moment for the virtual warehouse configuration to activate.


<span id="1db3360b"></span>
### Post\-paid configuration change


1. On the **Virtual Warehouse** page, we can see all the opened virtual warehouses and corresponding models.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cd88f9e3d33d453babe48b1619d3a9cf~tplv-goo7wpa0wc-image.image) </span>

2. Click the "Edit" button after selecting the virtual warehouse whose billing type you want to change.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/264e1d6e07584f9c8c441a94a57acc6d~tplv-goo7wpa0wc-image.image) </span>

3. Select a new pay\-as\-you\-go model and click "Confirm".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cfa926a9f534429db0a56073aef6be52~tplv-goo7wpa0wc-image.image) </span>

4. The system prompts "virtual warehouse successfully updated," meaning the model change has activated.
