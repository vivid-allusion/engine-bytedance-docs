If you need to unsubscribe from the ByteHouse services you have purchased, you can unsubscribe from the compute group and storage resources separately.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning"><strong>After unsubscribing from the compute group, the storage resources in use will continue to incur charges.</strong></div>


<div data-tips="true" data-tips-type="warning">If you no longer use ByteHouse cloud warehouse in the future, please unsubscribe from <strong>compute groups</strong> and <strong>storage</strong> resources.</div>


<span id="94a3657a"></span>
## Virtual warehouse unsubscription

<span id="b88124af"></span>
### Pre\-paid subscription

For instances with annual and monthly subscriptions (prepaid) that are not yet expired, if you wish to release them early, you can apply for a cluster unsubscription. After unsubscribing, the cluster usage can be restored by renewing it.

If you have product unsubscription needs, you can log in to **BytePlus Console \- Cost Center \- Unsubscription Management** to perform this action.

Currently, instances with annual and monthly subscriptions support **Not No\-Reason Return within Seven Days**. Not No\-Reason Return within Seven Days will charge the actual usage duration of the resources and refund the remaining actual payment of the order. The specific refund amount should be based on the Console display. For more cancellation rules, please refer to [Non-Seven Days No Reason Cancellation Rules](https://docs.byteplus.com/en/docs/byteplus-platform/docs-unsubscription-management#ii-non-seven-day-refund-policy).

<span id="d2794b56"></span>
### Post\-paid method

Post\-paid users can view the currently opened compute groups and storage resources on the **Tenant Management\-Basic Information** page.


* Click "Virtual Warehouse Management", and on the new page, choose to deactivate and delete specified compute groups;

* For the cancellation of storage resources, refer to the later text.

<span id="16a0000d"></span>
## Storage resource cancellation

You can view the current storage resource subscription on the **Tenant Management\-Basic Information** page. Before unsubscribing from storage resources, please unsubscribe from all compute groups first, then clicking the **Unsubscribe** button can complete the operation.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f3acd82ed9444aa5bb196d3aad51cb13~tplv-goo7wpa0wc-image.image) </span>

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">After unsubscribing, the current databases and existing data will be cleared, and you will log out of ByteHouse service; if you want to continue using Bytehouse, you need to reactivate ByteHouse service.</div>
