ByteHouse Open API meets REST specification, supports resource\-oriented URLs, and can support HTTP requests and responses in JSON format. Furthermore, Open API uses standard HTTP response codes and authentication, among others. The tutorial includes parameter descriptions, request examples, and response codes for each interface.

<span id="1be1d8cf"></span>
## **API reference address**

The API reference website address format is as follows:

```Bash
https://your_public_domain/docs

# Example
https://tenant-30006xxxxx-cn-hongkong-public.bytehouse.bytepluses.com/docs
```


You can obtain your public domain by going to the ByteHouse console, click **Tenant management** at the top, and click **Basic information**, and find and copy your public domain in the **Network information**.

## Caution

Due to interface optimization, when using the `Queries-V2` interface, it is necessary to add the port number "8123" in the URL.
