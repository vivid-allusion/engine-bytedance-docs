## Diverse source platforms and non\-stop migration

SMC enables non\-stop migration of source servers to the target platform. These source servers can be on\-premises virtual machines, cloud servers from various platforms, and servers from self\-built data centers. This capability addresses diverse migration needs without disrupting business operations on the source servers.

<span id=".5aKe6YeP6L-B56e777yM6YG_5YWN6YGX5ryP"></span>
## Incremental migration to prevent data loss

SMC supports the automatic incremental synchronization feature, ensuring that all data generated during non\-stop migration is fully migrated.

<span id=".5Lyg6L6T6ZmQ6YCf77yM56iz5a6a6L-Q6KGM"></span>
## Bandwidth throttling for stable operations

SMC allows you to customize the bandwidth upper limit for migration tasks. This prevents migration processes (such as non\-stop migration) from impacting normal business operations.

<span id=".5YaF572R5Lyg6L6T77yM56iz5a6a5b-r6YCf"></span>
## Intra\-network transmission for stability & high speed

SMC supports data transmission via the intra\-network mode. Compared with public network transmission, intra\-network transmission is faster and more stable, which improves migration efficiency.

<span id=".55m95bGP5YyW5pON5L2c77yM6ZuG5Lit566h55CG"></span>
## Visualized operations and centralized management

All migration sources and tasks are displayed in a visualized manner in the SMC console. You can not only intuitively view the status, progress, and execution logs of migration sources and tasks in the console, but also perform centralized management.

<span id=".6Lqr5Lu95qCh6aqM77yM5a6J5YWo5L-d6Zqc"></span>
## Identity verification for security assurance

SMC verifies the identity of the migration tool Agent using the Access Key generated by the platform. This ensures that migration sources are from trusted origins and safeguards your data.
