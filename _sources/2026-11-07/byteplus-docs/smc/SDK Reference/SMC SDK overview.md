This topic describes the SDK programming language versions provided by Server Migration Center (SMC) and lists the addresses of the latest SDK​s.

<span id=".U0RL5LuL57uN"></span>
## SDK introduction

SMC SDKs encapsulate all SMC API operations ([SMC API overview](https://docs.byteplus.com/en/docs/smc/smc_api_overview)), and authenticate the identity of the callers via the AccessKey. SMC SDKs offer features such as automatic signature, making it easier to create and manage resources by calling API operations.

<span id=".U0RL5YiX6KGo"></span>
