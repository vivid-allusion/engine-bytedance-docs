This topic describes the characteristics and applicable scenarios of different migration source import methods. You can select one option based on your needs.


|Method |Feature |Applicable scenarios |Process overview |
|---|---|---|---|
|[Manually installing migration tool Agent and importing migration sources](https://docs.byteplus.com/en/docs/smc/Step-1-Import-Migration-Sources) |* Requires manual installation and operation of the migration tool Agent. No dependency on cloud assistant or similar O&M tools.<br><br>* Supports a wide range of migration source platforms, but does not support batch import. |Applicable to migration scenarios involving any type of server, such as on\-premises servers from data centers and servers from various cloud service providers. |<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_95dcf025681273e984d88db4340c1422.png) </span> |
|[One-click import of migration source in the console](https://docs.byteplus.com/en/docs/smc/One-click_import_from_the_console) |* No need to log in to source servers one by one. The migration tool Agent is installed automatically via the cloud assistant or similar O&M tools provided by the cloud service provider.<br><br>* Supports server migration from cloud service providers and batch import. |Applicable to migration scenarios involving servers from cloud service providers that provide cloud assistant or similar O&M tools. |<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_abbcd3164dbac1a231ee21b387113342.png) </span> |
