This topic provides a summary of the check items supported by the pre\-check feature for migration sources, corresponding repair solutions, and related information.


|Exception type |Check item/CheckCode |Description |Repair suggestion |
|---|---|---|---|
|Severe |OS type/OSSupport |Checks whether the operating system type of the source server supports migration. Make sure that the operating system of your source server meets the migration requirements. For details, follow the guidance in [source server configuration](https://docs.byteplus.com/en/docs/smc/Preparations#.6YWN572u6L-B56e75rqQ). |If the operating system of the source server is not supported, it is recommended that you migrate using the [custom image import ](https://docs.byteplus.com/en/docs/ecs/Importing-custom-images-1)method or contact your account manager to apply for support. |
||Virtio driver status/Virtio |Checks whether the Virtio driver is installed on the source server. |Install the Virtio driver according to the guidance in the [solution](https://docs.byteplus.com/en/docs/smc/checkVirtioInstall-failed-or-Check-initramfs-failed). |
||Virtio driver status in Initramfs/Initramfs |Checks whether the Virtio driver is installed in the initramfs of the source server. |Install the Virtio driver in initramfs according to the guidance in the [solution](https://docs.byteplus.com/en/docs/smc/checkVirtioInstall-failed-or-Check-initramfs-failed). |
||SELinux status/SELinux |Checks whether the SELinux service is disabled on the source server. |Disable the SELinux service according to the guidance in the [solution](https://docs.byteplus.com/en/docs/smc/Disable_SELinux). |
||Whether the required system tools are installed/SystemTools |Checks whether the system tools required for migration on the source server are complete.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">If a required tool for migration is missing, this item will be diagnosed as <strong>Serious</strong>, and you need to install the corresponding tool based on the instructions.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If the missing tool is not required for migration operations, this item will be diagnosed as <strong>Warning</strong>, and you can install the corresponding tool as needed based on the instructions.</div><br> |Install the required system tools based on the error message. |
|Warning |Total count of disks/DiskNumber |Checks whether the number of volumes (system volume and data volume) on the source server exceeds 15. |* You can reduce the number of disks mounted on the source server (no more than 15 disks).<br><br>* You can select partial disks (no more than the number of disks on the destination instance) for migration during the migration process.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The feature of specifying disks to be migrated is in Beta. If you need a trial, please contact your account manager.   </div><br>    |
||Rsync status/RsyncVersion |Checks whether the installed Rsync on the source server meets the migration requirements. |It is recommended that you install Rsync version 3.1 or higher.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">If you refuse to install Rsync version 3.1 or higher, you can only migrate using the block replication method.</div><br> |
||AppArmor status/AppArmor |Checks whether the AppArmor service is disabled on the source server. |It is recommended that you disable the AppArmor service according to the guidance in the [solution](https://docs.byteplus.com/en/docs/smc/Disable-AppArmor-Services). |
||UAC status/UAC |Checks whether the UAC service is disabled on the source server. |It is recommended that you disable the UAC service according to the guidance in the [solution](https://docs.byteplus.com/en/docs/smc/Disable-UAC). |
||File system type/FilesystemType |Checks the file system type of the source server. |If you need to migrate using the file replication method, format the file system of the source server to one of the following types: Ext2, Ext3, Ext4, FAT, MINIX, MSDOS, VFAT, XFS, or Btrfs. Otherwise, use block replication for migration. |
||LVM status/LVM |Checks whether LVM (Logical Volume Manager) is enabled on the source server. |Source servers that use LVM can only be migrated using the block replication method. |
||CPU utilization/CPUUsage |Checks whether the CPU utilization of the source server exceeds 80%. |It is recommended that you reduce CPU utilization to ensure that CPU utilization does not exceed 80% before migration, to avoid affecting the stable operation of services on the source server. |
||Memory utilization/MemoryUsage |Checks whether the memory utilization of the source server exceeds 80%. |It is recommended that you reduce memory utilization to ensure that it does not exceed 80% before migration, to avoid affecting the stable operation of services on the source server. |
||Remaining memory/MemoryRemaining |Checks whether the free memory of the source server is less than 100 MiB. |It is recommended that you free up some memory to ensure that the free memory is at least 100 MiB before migration, to avoid affecting the stable operation of services on the source server. |
||Disk read/write IOPS/DiskThroughput |Checks whether the disk read/write IOPS of the source server exceed 100 MiB/s. |It is recommended that you limit the disk read/write IOPS to no more than 100 MiB/s before migration to avoid migration failure. |
||Disk write IOPS/DiskIOPS |Checks whether the disk write IOPS of the source server exceeds 1000. |It is recommended that you reduce disk write speed to ensure that the disk write IOPS does not exceed 1000 before migration, to avoid migration failure. |
||File system inode utilization/FilesystemInodeUsage |Checks whether the file system inode utilization of the source server exceeds 80%. |It is recommended that you delete unnecessary files to free up inodes. Ensure that the file system inode utilization does not exceed 80% before migration to avoid migration failure. |
||File system space utilization/FilesystemUsage |Checks whether the file system space utilization of the source server exceeds 80%. |It is recommended that you delete unnecessary files to free up file system space. Ensure that the file system utilization rate does not exceed 80% before migration to avoid migration failure. |
||Software that may affect migration/RunningApplications |Checks whether there is any software on the source server that may affect the migration process. |Close the software that affects the migration as prompted, or use the recommended migration method to improve the migration success rate. |
