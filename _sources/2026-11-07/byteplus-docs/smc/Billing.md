SMC is a free service, but a small amount of resource costs may be incurred during the migration process.


|**Billing item** |**Billing method** |**Billing note** |**Related documents** |
|---|---|---|---|
|Target instance |Pay\-as\-you\-go/Subscription |When you migrate a source server to a platform ECS instance, you need to specify a Pay\-as\-you\-go or Subscription instance as the target instance. |[ECS instance billing](https://docs.byteplus.com/en/docs/ecs/Instance-type-billing) |
|Relay instance |Pay\-as\-you\-go |When you migrate a source server to an ECS instance image, the platform will create a relay instance to transfer the source data, and will automatically release the instance after the migration is complete. ||
|Relay volume |Pay\-as\-you\-go/Subscription |During the migration process, the platform will create a relay volume to store source server data. The following rules apply (using the creation of a migration task as an example):<br><br><br><Tabs><br><Tab zoneid="tlDS3Dqa" title="Migrate to "an ECS instance""><br><TabTitle>Migrate to "an ECS instance"</TabTitle><br><br>* Billing method: Pay\-as\-you\-go<br><br>* Quantity and specification:<br><br>   * Quantity: 1<br><br>   * Type: Same as the system volume type of the target instance<br><br>   * Capacity: Same as the system volume size of the target instance<br><br><br></Tab><br><Tab zoneid="MSjfOxCj" title="Migrate to "an ECS instance image""><br><TabTitle>Migrate to "an ECS instance image"</TabTitle><br><br>* Billing method: Pay\-as\-you\-go<br><br>* Quantity and specification:<br><br>   * System volume:<br><br>      * Quantity: 1<br><br>      * Type: ESSD PL0<br><br>      * Capacity: Same as the system volume size of the target instance<br><br>   * Data volume:<br><br>      * Quantity: Number of source server data disks to be migrated + 1<br><br>      * Type: ESSD PL0<br><br>      * Capacity: Matches the system disk and data disks of the source server to be migrated on a one\-to\-one basis, with the same sizing.<br><br><br></Tab><br></Tabs><br> |[Volume billing](https://docs.byteplus.com/en/docs/ecs/Volume-billing) |
|Snapshot |Free |For the target instance, volume data will be backed up by using snapshots. |\- |
|Internet bandwidth |Free |For the target instance, the main traffic generated by migration is inbound traffic, which is free. |\- |
|Custom image |Free |For the target instance, a custom whole image will be created for data backup and migration. If you subsequently use this image to create an instance, charges may apply.<br><br><br>* For custom images generated by migrating Linux source servers, no charges will be incurred for subsequent use of the images.<br><br>* For custom images generated by migrating Windows source servers, only the official licenses of the BytePlus platform are currently supported. Subsequent use of the images to create instances may incur certain license fees, subject to the information displayed at the time of instance creation. |\- |
