Call the DescribeDBInstanceVersion API to query the version of the target instance.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".6LCD6K-V"></span>
## Debug

[去调试](https://api.byteplus.com/api-explorer/debug?action=DescribeDBInstanceVersion&serviceCode=vedbm&version=2022-01-01&groupName=)


<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Name** |**Type** |**Required** |**Example** |**Description** |
|---|---|---|---|---|
|InstanceId |String |Yes |vedbm\-r3xq0zdl\*\*\*\* |Instance ID.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">You can call the <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/DescribeDBInstances">DescribeDBInstances</a> API to query the Instance ID.</div><br> |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter


|**Name** |**Type** |**Example** |**Description** |
|---|---|---|---|
|DBMinorVersion |String |3.0 |Minor version of the instance.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">For a detailed description of version numbers, see <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Version_number_management">Version management</a>.</div><br> |
|DBRevisionVersion |String |3.0.1.1 |The kernel version of the instance. |
|DBEngineVersion |String |MySQL_8_0<br><br> |The compatible version of the instance. Value range:<br><br><br>* `MySQL_8_0`: Compatible with MySQL version 8.0.<br><br>* `MySQL_5_7`: Compatible with MySQL version 5.7. |
