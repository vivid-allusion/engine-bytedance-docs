Call the ModifyBackupPolicy to modify the data backup policy of the instance.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".6LCD6K-V"></span>
## Debug

[去调试](https://api.byteplus.com/api-explorer/debug?action=ModifyBackupPolicy&serviceCode=vedbm&version=2022-01-01&groupName=)


<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Name** |**Type** |**Required** |**Example** |**Description** |
|---|---|---|---|---|
|InstanceId |String |Yes |vedbm\-gzwdsf9b\*\*\*\* |Instance ID. |
|BackupTime |String |Yes |00:00Z\-02:00Z |The interval window for executing backup tasks is 2 hours, and it must be an even\-numbered hour. Format: HH:mmZ\-HH:mmZ (UTC time). |
|FullBackupPeriod |String |Yes |Monday,Wednesday |Full backup cycle. We recommend performing a full backup at least two days a week. Separate multiple values with a comma (,). Value:<br><br><br>* `Monday`: Monday.<br><br>* `Tuesday`: Tuesday.<br><br>* `Wednesday`: Wednesday.<br><br>* `Thursday`: Thursday.<br><br>* `Friday`: Friday.<br><br>* `Saturday`: Saturday.<br><br>* `Sunday`: Sunday. |
|BackupRetentionPeriod |Integer |Yes |7 |Number of days to retain data backup, value range: 7~365 days. |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter

null
