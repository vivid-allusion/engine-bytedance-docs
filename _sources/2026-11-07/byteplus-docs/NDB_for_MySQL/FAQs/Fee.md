### What is included in NDB for MySQL fee?

Charging items include compute nodes, storage space and backups (currently free). For details, refer to [Charging items and prices](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Billing_items_and_prices).

<span id=".5a2Y5YKo56m66Ze055qE6LS555So6YO95YyF5ZCr5ZOq5Lqb5YaF5a6577yf"></span>
### What is included in storage fees?

Charging items include database tables and files, index files, log files (undo log, redo log, binlog, slowlog, etc.) and minor system files.

<span id=".dmVkYi1teXNxbC3nmoTlpIfku73mlLbotLnlkJfvvJ8="></span>
### Does NDB for MySQL incur backup charges?

Backup storage is currently free, with future charges based on actual usage.

### Why are there additional charges for subscription instances?

Check storage utilization against your allocated capability. For subscription instances, storage usage exceeding the prepaid capacity will incur hourly pay\-as\-you\-go charges to your BytePlus account. For details, refer to [Subscription](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Yearly_or_monthly_subscription).

### After payment cancellation, how to handle instances stuck in pending payment state that can not be deleted?

An instance in pending payment state indicates an inactive order, which will be automatically canceled after 24 hours.
