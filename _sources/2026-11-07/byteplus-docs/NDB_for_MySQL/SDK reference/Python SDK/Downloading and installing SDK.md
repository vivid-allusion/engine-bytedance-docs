This topic describes how to download and install the Python SDK of NDB for MySQL.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

Python 2.7 or above is installed.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can run the <code>python --version</code> command to check the current Python version.</div>


<span id=".c2RrLeS4i-i9veWcsOWdgA=="></span>
## SDK download address

For the source code address of the Python SDK, see [BytePlus SDK for Python](https://github.com/byteplus-sdk/byteplus-python-sdk-v2/tree/main/byteplussdkvedbm).

<span id=".5a6J6KOFLXNkaw=="></span>
## Install the SDK

You can install the SDK in any of the following ways:


* Run the following command to install the SDK for the specified user.

   ```shell
   python setup.py install --<username>
   ```
   

* Run the following command to install the SDK for all users.

   ```shell
   sudo python setup.py install
   ```
