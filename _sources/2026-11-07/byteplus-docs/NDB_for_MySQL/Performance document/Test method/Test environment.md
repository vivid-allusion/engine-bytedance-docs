This article describes the environment information used for NDB for MySQL performance testing.

<span id="测试环境"></span>
## Test Environment


* **Location:**  ap\-southeast\-1

* **Availability Zone:**  ap\-southeast\-1a

* **Elastic Compute Service: ** Universal Balanced Enhanced g1ie 32C128G (Specification Code: ecs.g1ie.8xlarge)

* **Operating system image: ** CentOS 7.6 64\-bit version

* **MySQL version**: MySQL 8.0


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Because you must install additional compilation tools for the stress test tools, we recommend you bind the ECS instance to an EIP.</div>
