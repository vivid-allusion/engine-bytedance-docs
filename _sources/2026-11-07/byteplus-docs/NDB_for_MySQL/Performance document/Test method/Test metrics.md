This topic describes the test indexes used to stress test NDB for MySQL.


* Read\-only QPS (Query Per Second): The number of SQL executed per second when the database is read\-only (Select only).

* Read\-write QPS: The number of SQL (including Insert, Select, Update) executed per second while reading and writing to the database.
