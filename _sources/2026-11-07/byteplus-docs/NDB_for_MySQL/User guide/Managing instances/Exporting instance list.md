You can view instance resources on the cloud offline, and this article describes how to export a list of instances.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

The instance has been created and is in the **Running** status. For specific operations, refer to [Creating an instance](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Creating_an_instance_1).

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.

3. On the **Instances** page, click<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_377e7792dbf7e98a37920450f5f2bf23.png)<sub> </sub></span>icon in the upper\-right corner.

4. In the pop\-up **Export instances list** dialog box, select the information you want to export.

   The information that supports export includes **Instance name/ID** (required), **State**, **Availability zone**, **Virtual private cloud, Compatible version**, **Tag**, **Instance specification**, **Specification type**, **Storage type**, **Used storage space**, **Storage space**, **Calculate billing type**, **Storage billing type**, **Affiliated project**, and **Creation time**.

5. Click **OK**.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">After exporting, the instance information will be output as a CSV file that you can view locally using a text editing tool.</div>
