Database Workshop (DBW) is a cloud\-based management platform that allows you to uniformly manage the lifecycle of various databases. As a database SaaS product, DBW integrates the graphical user interface (GUI), troubleshooting, and auditing of databases. DBW allows you to manage endpoints on web screens through comprehensive observational analysis, intelligent risk detection, and autonomous operation and maintenance. You can manage databases using a stable, secure, and efficient cloud\-based service.

NDB for MySQL is integrated with the DBW, providing operational and maintenance features such as slow log analysis, audit logs, session management, SQL throttling, ticket list, and database inspection.

## Function introduction

<div data-tips="true" data-tips-type="default">In addition to the following operation and maintenance related capabilities, DBW also provides instance management, data management, and ticket management. * **Session information: ** Supporting the viewing of session statistics and real\-time session information for both primary and read\-only nodes of an instance. For more information, see [Session information management](https://docs.byteplus.com/en/docs/DBW/Session_information_management).

* **SQL throttling ** : You can use this feature to control the request volume and SQL concurrency of the database, ensuring service availability. For more information, see [SQL throttling management](https://docs.byteplus.com/en/docs/DBW/SQL_throttling_management).

* **Slow log diagnosis**: The Database Workshop (DBW) provides a slow log diagnosis feature, which analyzes the top 200 slow logs generated the previous day and offers diagnostic results and optimization suggestions to help improve database performance and stability. For more information, see [Log management](https://docs.byteplus.com/en/docs/DBW/Log_management).

* **Database audit**: Record all operations to facilitate backtracking, querying, and analyzing historical operations, helping you always understand product safety and performance and improve database security. For more information, see [Database audit management](https://docs.byteplus.com/en/docs/DBW/Database_audit_management).

* **Full SQL insight**: Database Workshop (DBW) provides the Full SQL insight feature, which captures, reviews, and analyzes all SQL statements to help improve database performance and stability. For more information, see [Full SQL insight management](https://docs.byteplus.com/en/docs/DBW/Full_SQL_insight_management).

* **Spatial analysis ** : The Database Workshop (DBW) provides space analysis functionality, allowing you to visually view the space usage of an instance, such as table space analysis. For more information, see [Space analysis management](https://docs.byteplus.com/en/docs/DBW/Space_analysis_management).

* **Transaction and lock**: Using the transaction and lock features, you can view and analyze all locks occurring within the database. For more information, see [Transaction and lock management](https://docs.byteplus.com/en/docs/DBW/Transaction_and_lock_management).

* **One\-click diagnosis**: Database Workshop (DBW) provides a one\-click diagnosis feature, allowing you to intuitively view the overall performance of your database and quickly confirm if there are any anomalies in the instance. For more information, see [One-click diagnosis management](https://docs.byteplus.com/en/docs/DBW/One-click_diagnosis_management).

* **Performance monitoring**: The Database Workshop (DBW) supports performance monitoring, providing a wide range of performance metrics. These metrics allow you to view the performance trends of database instances and promptly identify potential risks. For more information, see [Performance monitoring management](https://docs.byteplus.com/en/docs/DBW/Performance_monitoring_management).

* **Online DDL**: OnlineDDL tickets help you avoid DDL or query blocking issues caused by database table locks. For more information, see [Creating a lock-free schema change ticket (OnlineDDL)](https://docs.byteplus.com/en/docs/DBW/creating-a-lock-free-schema-change-ticket-OnlineDDL).

* **Database inspection management**: The Database Workshop (DBW) provides a database inspection feature that can periodically and automatically perform health checks and risk assessments on database instances, helping you understand the operational status of your database instances. For more information, see [Database inspection management](https://docs.byteplus.com/en/docs/DBW/Database_inspection_management).

* **Database intelligent assistant (DBCopilot)** : The Database Workshop (DBW) offers the DBCopilot feature, which assists you in handling issues related to databases and database instances. The intelligent assistant significantly improves the efficiency and security of database management, reduces the workload of administrators, and enhances the management level of database systems. For more information, see [Database intelligent assistant (DBCopilot)](https://docs.byteplus.com/en/docs/DBW/database-intelligent-assistant-dbcopilot).
