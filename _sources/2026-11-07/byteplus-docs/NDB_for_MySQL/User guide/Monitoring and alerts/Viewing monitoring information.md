NDB for MySQL has been connected to CloudMonitor. During the daily operation of the instance, you can directly view various monitoring indicators in the NDB for MySQL console or Cloud Monitor console to analyze the running status of the instance in real time.

<span id="操作步骤"></span>
## Procedure


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click the name of the target instance.

4. Click the **Monitoring** tab at the top of the page.

5. Click **Instance** or **Compute node monitoring** to view the monitoring data for the instance and node dimensions.
