This article describes how to delete a custom parameter template.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

Parameter templates cannot be restored after deletion, please proceed with caution.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. Click **Parameter templates** in the left\-side navigation bar.

4. In the **Customized template** subtab, click **Delete** for the target template **Actions** column.

5. In the **Are you sure to delete** dialog box that pops up, click **Delete**.
