Through the instance topology, you can obtain the node information, connection endpoint information, and the association between the nodes and connection endpoints of the instance. This article describes how to view topology information for an instance.

<span id="前提条件"></span>
## **Prerequisites**

The instance has been created and is in the **Running** status. For specific operations, refer to [Creating an instance](https://www.byteplus.com/en/docs/NDB_for_MySQL/Creating_an_instance_1).

<span id="操作步骤"></span>
## **Procedure**


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click the name of the target instance.

4. On the **Connectivity** tab, you can view node information, topology information, and connection endpoint information for your instance.
