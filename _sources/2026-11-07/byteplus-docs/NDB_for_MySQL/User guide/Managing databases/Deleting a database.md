This article mainly describes the specific operation of deleting a database.

<span id="前提条件"></span>
## Prerequisites


* The instance has been created and is in the **Running** status. For specific operations, refer to [Creating an instance](https://www.byteplus.com/en/docs/NDB_for_MySQL/Creating_an_instance_1).

* A database has been created. For specific operations, refer to [Creating a database](https://www.byteplus.com/en/docs/NDB_for_MySQL/Creating_a_database).


<span id="操作步骤"></span>
## Procedure


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click the name of the target instance.

4. At the top of the page, click **Databases**.

5. On the **Databases** tab, click **Delete** under the **Actions** column of the target database.

6. Click **OK** in the pop\-up dialog box.
