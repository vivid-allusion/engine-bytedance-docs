Creating an instance is the first step for using NDB for MySQL. This topic describes how to create NDB for MySQL instance.

<span id="neodc78Q"></span>
## Prerequisites


* A BytePlus account has been registered. For account registration, refer to [How to Register an Account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* VPC service access authorization has been completed. For the authorization method, refer to [Cross-service access authorization](https://docs.byteplus.com/en/docs/RDS_for_MySQL/cross-service_access_authorization). 


<span id="xLbNHm0U"></span>
## Procedure


1. Log on to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click **Create instance**.

4. On the **Create instance** page, set the following instance parameters.

   
   |Type |Parameter |Description |
   |---|---|---|
   |Database type ||The type of database, the default is **NDB for MySQL**. |
   |**Basic information** |Instance name |Instance name. The naming convention is as follows:<br><br><br>* Cannot start with digits or hyphen (\-).<br><br>* It can contain only Chinese characters, letters, digits, underscores ( _ ), and hyphens ( ).<br><br>* The length is 1~128 characters.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">If the instance name is not set, the instance is named with the instance ID.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If no instance name is filled in, the instance name is the instance ID.</div><br> |
   ||Compatible version |The MySQL version that the instance is compatible with. **MySQL 8.0** is supported. |
   ||Minor version |The compatible version is **MySQL 8.0**, and the minor version defaults to **NDB for MySQL 3.0**. |
   |**Specifications** |Specification type |Please select the specification type.<br><br><br>* **Exclusive type** (default): Completely exclusive CPU and memory, long\-term stable performance, will not be affected by the behavior of other instances on the physical machine. The top of the exclusive specification is exclusive TCE\-metal, completely monopolizing all the resources of a TCE\-metal.<br><br>* **General type**: Exclusive access to allocated memory, sharing CPU resources with other generic instances on the same physical machine. Enjoy scale dividends through resource reuse, with high cost performance. |
   ||Node specification |Each specification has a corresponding number of cores and memory, and you can choose according to your business requirements. For more information on node specifications, see[ ](https://www.volcengine.com/docs/6357/73614)[Product specifications](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Product_specifications). |
   ||Primary instance availability zone |The region and availability zone where the instance is located, that is, the geographical location where the instance is located.<br><br>Geographies and availability zones cannot be changed after purchase. Please select the nearest region according to the geographical location where your business is located to improve access speed.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Please ensure that the instance is created in the same region as the ECS instance that needs to be connected, otherwise they cannot be connected through the private network, only through the public network, and will not perform at their best.</div><br> |
   ||Storage type |Select a storage type based on your business requirements.<br><br><br>* **IO performance**: The default storage type for the instance. It provides good performance and enhanced reliability and availability.<br><br>* **Intelligent compression**: A new storage type that uses intelligent compression algorithms to compress and decompress data at the physical SSD disk level. This lowers the storage cost per unit of capacity while keeping performance impact manageable.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">Tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="default">For details about the two storage types and their price differences, refer to <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Storage">Storage type comparison</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="default">Upgrading the storage type from intelligent compression to IO\-performance is supported. For detailed instructions, refer to <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Upgrading_storage_type">Upgrading storage type</a>.</div><br> |
   ||Number of primary instance nodes |Each instance supports 2 to 16 nodes, and at least two nodes are selected to ensure high availability of the cluster (one primary node and one read\-only node).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">If the primary node fails, the system automatically switches the read\-only node to the new primary node.</div><br> |
   |**Network configuration** |Virtual private cloud |Select the target VPC from the drop\-down list, and depending on the item you selected in the upper left corner of the console, the following will happen:<br><br><br>* If you select **All resources**, you can select the VPC of all accessible items under the current account.<br><br>* If you select any specific project, you can only select the VPC under that project.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">After the instance is successfully created, the VPC cannot be changed. Please choose reasonably according to the business situation.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">A Virtual Private Cloud (VPC) A VPC is an isolated network environment with higher security and performance than a classic network. For detailed steps, refer to <a href="https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC">Creating a VPC</a>.</div><br> |
   ||Subnet |Select an available subnet in the current VPC from the drop\-down list.<br><br>A subnet is an IP address block within a VPC. All cloud resources in the VPC must be deployed within a subnet. The subnet allocates private IP addresses to cloud resources. For detailed steps, refer to [Creating a subnet](https://docs.byteplus.com/en/docs/vpc/Creating-a-subnet). |
   ||Database port |Specifies the port number for the connection endpoint that the instance creates by default. The default value is 3306, and the range is 1000 to 65534.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">This configuration item is only valid for <strong>Primary node endpoint</strong>, <strong>Default endpoint</strong>. That is, after the instance is successfully created, the newly created custom endpoint, the port number still defaults to 3306.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">After the instance is successfully created, you can also modify the port number at any time. For activity details, see <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Modifying_address_prefix_and_port">Modifying address prefix and port</a>.</div><br> |
   |**Account settings** |Set password |To set the instance super account and password, you can choose to **Set up now** or **Set up later**, where:<br><br><br>* If you choose **Set up now**, you need to set the **super account** and enter the **Super account passwords** and **Confirm password**.<br><br>* If you choose to ** Set up later**, the system will automatically create a normal user named root. You can create a super account or a normal account for instance after the instance is successfully created. For activity details, see [Creating and deleting accounts](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Creating_and_deleting_accounts). |
   ||Super account |Fill in the super account name. The naming convention is as follows:<br><br><br>* It starts with a letter and ends with a letter or a digit.<br><br>* It must consist of letters, numbers, underscores (_) and hyphens (\-).<br><br>* The length is 2~32 characters.<br><br>* Account names cannot use certain reserved words, see [List of forbidden keywords](https://docs.byteplus.com/en/docs/NDB_for_MySQL/List_of_forbidden_keywords).<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The super account has all permissions for all databases in the instance. An instance can only have one super account, which can manage all normal accounts and databases.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Open more permissions to meet personalized and granular rights management requirements, such as assigning permissions to different databases.</div><br> |
   ||Super account password |Set a super account password. The requirements are as follows:<br><br><br>* The length is 8~32 characters.<br><br>* It contains at least three of the following: uppercase letters, lowercase letters, digits, and special characters.<br><br>* Special characters are `~!@#$%^&*_-+=`\|\(){}[]:;'<>,.?/`. |
   ||Confirm password |The password must be the same as the super account password. |
   |**Advanced configuration** |Parameter configuration |Select the parameter template for the instance. If not, the system template is used by default.<br><br>You can click **View parameter template** to go to the **Parameter templates** page to create a custom parameter template, see [Creating a parameter template](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Creating_a_parameter_template).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">If the <strong>Time zone</strong> is set on the create instance page and the <code>time_zone</code> parameter is set in the parameter template, the value of the <strong>Time zone</strong> on the create page shall prevail. Similarly, if the <strong>Lower case table names</strong> are set on the create instance page, and the <code>lower_case_table_names</code> parameter is set in the parameter template, the value of the <strong>Lower case table names</strong> in the create page shall prevail.</div><br> |
   ||Time zone |The time zone of the instance. The default time zone for all regions in China is UTC + 08:00. The time zone of the original instance will be used when restoring data, and changes are not supported. |
   ||Lower case table names |Please select whether to distinguish upper and lower case of table names.<br><br><br>* Case insensitive: Table names are case\-insensitive. Even if uppercase letters are specified when the table is created, all lowercase letters are handled uniformly by backend storage.<br><br>* Case sensitive: Table names are case sensitive, and the backend stores them according to the actual table name specified.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">After creating an instance, it is not supported to modify this rule. Please set it reasonably according to business requirements.</div><br> |
   ||Affiliated project |Select the item to which the instance belongs, and depending on the item you selected in the upper left corner of the console, the following defaults will apply:<br><br><br>* If you select **All resources**, the newly created instance will be added to the **default** project by default, and other projects can also be selected according to business needs.<br><br>* If you select any specific project, such as **Game**, the newly created instance will be added to that project by default. You can also select other projects based on business needs.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">A project is a virtual concept that includes a set of resources, users, and roles. A project allows you to view and manage a group of resources in a unified manner and control the permissions of users and roles to these resources. For more details, see <a href="https://docs.byteplus.com/en/docs/byteplus-platform/docs-managing-projects">Managing projects</a>.</div><br> |
   ||Tag |Click **Add tag** and select an existing tag key and tag value from the drop\-down list or enter a new tag key and tag value based on your business needs. For tag key setting rules, see [Tag overview](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Tag_overview).<br><br>A tag consists of a key\-value object that identifies cloud resources. It can help you classify cloud resources with the same characteristics (such as use, owner, or environment) for easy filtering and aggregation, so that you can easily manage the cloud resources. For more information, refer to [Managing tags](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Managing_tags).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">If you use IAM user management instances, you need to add a globally <code>TagFullAccess</code> permission policy for IAM user, so that all existing tag under the main account can be viewed in the drop\-down list, otherwise the drop\-down list is empty. Whether IAM user has <code>TagFullAccess</code> does not affect adding new tags to the instance. Add permissions for IAM users see <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Using_veDB_MySQL_with_IAM_users">Using NDB for MySQL with IAM users</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">You can also bind tags to an instance after it is successfully created. See <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Associating_or_adding_tag">Associating or adding tag</a>.</div><br> |
   ||Deletion protection |Select whether to enable instance **Deletion protection**. Once turned on, the instance cannot be deleted. To delete an instance, you need to turn off the feature first. For more information about removal protection, see [Instance deletion protection](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Instance_deletion_protection). |
   |**Billing information** |Calculate billing type |NDB for MySQL computing nodes support two billing methods: **Pay\-as\-you\-go** and **Subscription**.<br><br><br>* **Pay\-as\-you\-go**: If you plan to use instance for a short period of time, choose pay\-as\-you\-go (hourly rate). You can save money by releasing the instance when you no longer need it.<br><br>* **Subscription**: If you plan to use instance for a long period of time, please select Subscription (one\-time payment). Subscription is more affordable than Pay\-as\-you\-go, and the longer you buy, the more discounts you get.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">You can also create a Pay\-as\-you\-go instance first and confirm that the instance meets the requirements before switching to a yearly/monthly subscription. For more information about billing, see <a href="https://docs.byteplus.com/en/docs/NDB_for_MySQL/Billing_overview">Billing overview</a>.</div><br> |
   ||Storage billing type |Storage billing type supports two billing methods: **Pay\-as\-you\-go** and **Subscription**, including:<br><br><br>* When **Calculate billing type** selects **Pay\-as\-you\-go**, the **Storage billing type** only supports selecting **Pay\-as\-you\-go**.<br><br>* When the Calculate billing type selects the Subscription, the Storage billing type supports selecting Pay\-as\-you\-go or Subscription. |
   ||Storage space |* If you choose the storage billing type of **Pay\-as\-you\-go**, there is no need to select the storage capacity. The storage capacity will automatically scale elastically with the increase or decrease of the amount of data, and will be billed by the hour according to the actual usage.<br><br>* If you choose the storage billing type of **Subscription**, you need to enter the storage space size, the default is 50GiB, and the step size is 10GiB.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the actual storage space used exceeds the storage space size selected at the time of purchase, the excess will be billed by the hour based on the usage.   </div><br>   <br><br>   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Different node specifications have different storage space value ranges. For details, please refer to the actual display of the console.   </div><br>    |
   ||Purchase duration |When the Calculate billing type selects the subscription, you need to select the purchase duration. Support monthly purchases (can purchase 1~9 months) and yearly purchases (can purchase 1~3 years). |
   ||Automatic renewal |If the calculate billing type is selected as subscription, you can check the box of **Auto\-renewal on expiration**, and the platform will automatically renew the subscription on a monthly basis before the expiration of the instance, so there is no need to renew the subscription manually. You can also modify the renewal configuration after successful creation. For details, see [Renewal management](https://docs.byteplus.com/en/docs/NDB_for_MySQL/Renewal_management). |
   |Quantity ||Enter the number of instances to create, up to 50 instances can be created simultaneously at a time. |
   

6. Click **Confirm order**.

7. Complete the subsequent steps based on the billing type selected.

   * If **Pay\-as\-you\-go** is selected:

      on the **Confirm order** page, confirm the order details, read and check the terms, and click **Buy now**.

   * If **Subscription** is selected:

      1. on the **Confirm order** page, confirm the order details, read and check the terms, and click **Submit the order**.

      2. On the **Confirm order information** page, reconfirm the order information, and click **Next step**.

      3. On the **Submit payment information** page, confirm the payment details and select the payment method, click **Go to payment**.
