To provide you with a more reliable and stable service, we will no longer support creating new MySQL version 5.7 instances.

<span id="OqKuLLMP"></span>
## Effective time

August 10, 2026, 00:00:00 (Beijing Time).

<span id="sGO0qLdt"></span>
## Plan details

Starting from August 10, 2026 (Beijing Time):


* NDB for MySQL will no longer support creating MySQL version 5.7 instances.

* NDB for MySQL will also stop feature updates for existing MySQL version 5.7 instances. If you are using MySQL version 5.7 instances, evaluate whether they are still necessary. If an instance is no longer needed, log in to the [NDB for MySQL console](https://console.byteplus.com/db/vedb-mysql) to Unsubscribe or Delete it. If you still need the instance, migrate it to MySQL version 8.0 to prevent business impact from the discontinuation of feature updates for MySQL version 5.7. For the procedure, refer to [Migrating to BytePlus NDB for MySQL](https://docs.byteplus.com/en/docs/DTS/Migrating_to_Volcano_Engine_veDB_for_MySQL).
