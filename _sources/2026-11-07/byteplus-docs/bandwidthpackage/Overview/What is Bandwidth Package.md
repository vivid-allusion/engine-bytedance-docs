Bandwidth Package is a cloud resource for sharing and reusing bandwidth. Add multiple elastic IP addresses (EIPs) in a single region to a Bandwidth Package instance to share one bandwidth, which helps you reduce Internet bandwidth costs.

## Benefits


* **Cost reduction**

   You do not need to purchase bandwidth for each EIP or IPv6 Internet bandwidth separately. Simply purchase a Bandwidth Package instance and add multiple EIPs or IPv6 Internet bandwidth to it. This converts multiple bandwidths into one shared bandwidth, improving bandwidth utilization and reducing internet usage costs.

* **Ease of management**

   Instead of managing and monitoring bandwidth for each EIP or IPv6 Internet bandwidth individually, you manage and monitor the bandwidth of a single Bandwidth Package instance, reducing your management workload.

* **Flexible adjustment**

   Bandwidth Package supports adjusting the maximum bandwidth at any time, as well as adding or removing an EIP or IPv6 Internet bandwidth at any time, meeting your diverse usage requirements.
