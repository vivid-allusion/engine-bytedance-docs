You can enable dual\-stack and convert the protocol type of the Bandwidth Package from **IPv4** to **Dual\-stack** based on your business requirements. Dual\-stack Bandwidth Package supports adding both IPv4 elastic IP addresses (EIPs) and IPv6 Internet bandwidth simultaneously, allowing IPs of different protocol types to share bandwidth. This further reduces your internet bandwidth costs.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The feature of enabling dual\-stack is in the beta stage. If you need a trial, please contact your account manager.</div>


<span id=".5pON5L2c6K-05piO"></span>
## Instructions


* Bandwidth Packages of the **default security protection** and IPv4 protocol support enabling Dual\-stack.

* Once enabled, dual\-stack can neither be disabled, nor be converted to IPv4 for the Bandwidth Package instance. Proceed with caution.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to [the Bandwidth Package console](https://console.byteplus.com/eip/cbwps).

2. In the top menu bar, select a target region and project.

3. Click  **··· \> Enable dual\-stack** to the right of the target Bandwidth Package.

4. Click **OK** to complete the action.
