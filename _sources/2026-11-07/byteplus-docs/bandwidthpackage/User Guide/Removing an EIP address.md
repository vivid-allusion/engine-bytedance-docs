This topic describes how to remove elastic IP addresses (EIPs) from a Bandwidth Package instance.

> You can also refer to [Removing EIPs from a Bandwidth Package](https://docs.byteplus.com/en/docs/eip/Removing-an-EIP-address-from-a-bandwidth-package).


<span id="procedure"></span>
## Procedure


1. Log on to the [Bandwidth Package console](https://console.byteplus.com/eip/cbwps).

2. In the top navigation bar, select the region and project to which the target Bandwidth Package belongs.

3. In the Bandwidth Package list, click **Manage EIP** next to the target Bandwidth Package.

4. Click **Remove Bandwidth Packages** next to a target EIP. A confirmation pop\-up window appears.

5. After confirming the information, click **OK**.


<span id="operation-results"></span>
## Operation results


* The maximum bandwidth of the EIP is restored to the previous value.

* The bandwidth and traffic fees of the EIP are restored, and the EIP is billed for bandwidth and traffic fees immediately.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">Note   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After an EIP applied for from the Bandwidth Package console is removed from a Bandwidth Package, the billing method is <a href="https://docs.byteplus.com/en/docs/eip/Pay-as-you-go#pay-by-data-transfer">Pay\-by\-data\-transfer</a>, and the maximum bandwidth is 100 Mbps.   </div>
