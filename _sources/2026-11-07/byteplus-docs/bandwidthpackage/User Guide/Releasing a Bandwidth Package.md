When you no longer need a Bandwidth Package, you can release it through the procedure below.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* The target Bandwidth Package is a Pay\-as\-you\-go instance or an expired Subscription instance. To release an unexpired Subscription Bandwidth Package, see [Unsubscription](https://docs.byteplus.com/en/docs/bandwidthpackage/Unsubscription).

* No Elastic IP Addresses (EIPs) or IPv6 Internet bandwidth are added to the Bandwidth Package. If added, [remove the EIP or IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/bandwidthpackage/Managing_resources_in_a_Bandwidth_Package#9HNP4wLa).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to [the Bandwidth Package console](https://console.byteplus.com/eip/cbwps).

2. In the top menu bar, select the region and project of your target Bandwidth Package.

3. In the Bandwidth Package list, click  **··· \> Delete** to the right of the target Bandwidth Package. A dialog box appears to confirm your request.

4. Click **Delete** to complete the action.
