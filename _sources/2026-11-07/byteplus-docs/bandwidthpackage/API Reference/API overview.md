The following table describes Bandwidth Package open APIs.


|**API** |**Function** |
|---|---|
|[CreateBandwidthPackage](https://docs.byteplus.com/en/docs/bandwidthpackage/CreateBandwidthPackage) |Creates a Bandwidth Package. |
|[ModifyBandwidthPackageAttributes](https://docs.byteplus.com/en/docs/bandwidthpackage/ModifyBandwidthPackageAttributes) |Modifies the name or description of a Bandwidth Package. |
|[ModifyBandwidthPackageSpec](https://docs.byteplus.com/en/docs/bandwidthpackage/ModifyBandwidthPackageSpec) |Modifies the bandwidth of a Bandwidth Package. |
|[DescribeBandwidthPackages](https://docs.byteplus.com/en/docs/bandwidthpackage/DescribeBandwidthPackages) |Queries Bandwidth Packages that meet specified conditions. |
|[DeleteBandwidthPackage](https://docs.byteplus.com/en/docs/bandwidthpackage/DeleteBandwidthPackage) |Deletes a Bandwidth Package. |
|[AddBandwidthPackageIp](https://docs.byteplus.com/en/docs/bandwidthpackage/AddBandwidthPackageIp) |Adds elastic IP addresses (EIPs) to a Bandwidth Package. |
|[RemoveBandwidthPackageIp](https://docs.byteplus.com/en/docs/bandwidthpackage/RemoveBandwidthPackageIp) |Removes EIPs from a Bandwidth Package. |
