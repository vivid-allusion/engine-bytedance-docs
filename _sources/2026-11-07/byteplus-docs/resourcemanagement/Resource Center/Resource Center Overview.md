The resource center provides you with a unified resource view and resource search capabilities across products and regions, making resource management on the cloud more efficient and convenient.

<span id="features-and-benefits"></span>
## Features and benefits


1. Resource overview


Displays managed resource information by product and region so that you can have a clear picture of the resources on the cloud.


2. Resource search


Supports global searches for resources by region, resource type, resource ID, resource name, resource item, and resource tag.


3. Unified resource O&M


Supports custom export of the list of managed resources, without the need for frequent switching between different product consoles, improving O&M management efficiency.

<span id="data-timeliness-of-the-resource-center"></span>
## Data timeliness of the resource center

When resource changes are involved, some resources are expected to take some time to complete the data updates.

<span id="resource-types-that-support-the-resource-center"></span>
## Resource types that support the resource center

Only cloud services and resource types that support the resource center can be viewed and queried in the resource center.
