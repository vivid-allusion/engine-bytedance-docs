The resource center provides you with a unified resource view and resource search capabilities across products and regions. You can view the list of global resources under your current account and search for resources using filter conditions.

<span id="viewing-resource-list"></span>
## Viewing resource list


1. Log in to Resource management and go to the resource center.

2. By default, the resource information of all regions and all resource types is displayed.

> The supported regions and resource types are listed in the relevant drop\-down lists.


3. You can filter resources by region, resource type, project, tag, resource ID, and resource name and click Search to view the filtered resources.

4. You can specify the columns to display in the list.


<span id="exporting-resource-list"></span>
## Exporting resource list

You can export the displayed resource list as a CSV file. You may need to wait a while if the list contains a large number of resources.
