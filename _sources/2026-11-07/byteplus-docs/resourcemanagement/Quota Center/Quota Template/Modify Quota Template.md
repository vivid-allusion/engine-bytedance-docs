You can modify the existing quota template. The modification will only apply to new members, and the existing members will not be affected.

<span id="procedure"></span>
## Procedure


1. Log in to [Quota center](https://console.byteplus.com/quota/productList).

2. Go to Quota template.

3. Select the quota template you want to modify and click Edit in the Actions column.

4. Modify the quota and click Submit.
