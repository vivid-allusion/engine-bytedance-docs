You can delete the existing quota template. After deletion, no change application for the deleted quota item will be automatically submitted for new members, and the existing members will not be affected.

<span id="procedure"></span>
## Procedure


1. Log in to [Quota center](https://console.byteplus.com/quota/productList).

2. Go to Quota template.

3. Select the quota template you want to delete and click Delete in the Actions column.

4. Click OK to delete the quota template.
