# Create Quota Template

You can create a quota template for a quota item. After creation, change applications for the quota item will be automatically submitted for new members, and the existing members will not be affected.

<span id="procedure"></span>
## Procedure


1. Log in to [Quota center](https://console.byteplus.com/quota/productList).

2. Select the product and enter the quota management page.

3. Select the quota item and click Create quota template in the Actions column.

4. Specify the target quota for the quota template and click Submit.
