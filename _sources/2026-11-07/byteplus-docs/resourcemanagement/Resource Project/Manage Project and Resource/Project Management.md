This topic introduces how to manage resource projects, including creating, querying, and deleting projects. This topic also covers the management of hierarchical projects.

<span id="creating-project"></span>
## Creating project


1. Log in to [Resource project > Project](https://console.byteplus.com/iam/resourcemanage/project).

2. Click Create project.

3. Enter the project name, display name, and description, and click OK to complete the creation.

   1. The project name can be 1 to 64 characters in length and can contain letters, digits, and symbols. It is case\-insensitive and cannot be modified after the project is created.

   2. The display name is an alias of the project. It can be 0 to 64 characters in length and can contain letters, digits, and symbols.

   3. The description is a brief note about the project. It can be up to 128 characters in length and can contain letters, digits, and symbols.

> Note: By default, users can create up to 100 projects for each account. To request a quota increase, submit a work order in Work order center.


<span id="creating-subproject"></span>
## Creating subproject

You can establish a hierarchical project structure based on business needs.


1. Log in to [Resource project > Project](https://console.byteplus.com/iam/resourcemanage/project).

2. Click Create project.

3. Enter the project name, display name, and description.

4. Turn on the subproject switch.

5. Select a parent project and click OK to complete the creation.

> Attention: A maximum of five hierarchical levels are allowed for projects.


<span id="viewing-project-list"></span>
## Viewing project list


1. Log in to [Resource project > Project](https://console.byteplus.com/iam/resourcemanage/project).

2. View the list of projects, including details of each project such as the project name, display name, description, number of resources, and number of permissions.

3. If hierarchical levels exist, hover over the icon next to a project name to check its associated projects. The hierarchy depth indicates the position of the project in the tree structure.


<span id="modifying-project-information"></span>
## Modifying project information


1. Log in to [Resource project > Project](https://console.byteplus.com/iam/resourcemanage/project).

2. Click the name of a project to go to the project details page.

3. Click Edit to go to the project edit page.

4. Modify the display name or description and click OK to save the edits.


<span id="deleting-project"></span>
## Deleting project


1. Log in to [Resource project > Project](https://console.byteplus.com/iam/resourcemanage/project).

2. You can delete a project in one of the following ways:

   1. In the project list, click Delete in the Actions column of the target project.

   2. Click the name of the target project to go to its details page. Then, click Delete.

> Note: If a project is the default project, contains resources, or has subprojects with resources, the project cannot be deleted.
