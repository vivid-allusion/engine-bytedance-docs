## What is resource management?

Resource Management is a cloud resource management system provided by BytePlus. It helps enterprises manage their cloud resources using a suite of IT governance tools and services. This system is commonly used in scenarios such as financial accounting and resource grouping for O&M.

<span id="key-features"></span>
## Key features

<span id="resource-center"></span>
### Resource center

Provides a unified resource view and resource search capabilities across products and regions, making resource management on the cloud more efficient and convenient. The details are as follows:


* Provides the resource overview feature, which displays information of managed resources by product and region, so that you can have a clear picture of the resources on the cloud.

* Provides the resource search feature, which supports global searches for resources by region, resource type, resource ID, resource name, resource project, and resource tag.

* Enables unified resource O&M, which supports custom export of the list of managed resources, without the need for frequent switching between different product consoles, improving O&M management efficiency.


<span id="project-management"></span>
### Project management

Solves the complexity of resource grouping and user authorization across multiple projects and applications within a single account. The details are as follows:


* Centrally manages cloud resources across multiple regions and resource types within a single account. Users can assign resources to specific projects during the resource creation and management stages.

* Supports IAM\-based authorization at the project level. Projects act as resource boundaries for IAM policies, restricting the application scope of policies to designated projects. Any request for resources outside the project is denied.

* Enables resource bill management by project, allowing users to allocate costs for different business operations.


<span id="tag-management"></span>
### Tag management

Facilitates the classification, search, and aggregation of cloud resources from different dimensions. The details are as follows:


* Uses resource tags to identify and categorize cloud resources across different regions and resource types within a single account. Tags can be attached to resources during resource creation and management.

* Supports IAM\-based authorization using tags as matching conditions for IAM policies, allowing for fine\-grained permission control over cloud resources.

* Enables resource bill management by tag, allowing users to allocate costs for different business operations.


<span id="resource-sharing"></span>
### Resource sharing

In a multi\-account scenario, provide the ability to share resources under an account to other accounts, and limit the usage permissions of the shared resources. The details are as follows:


* Create resource instances in one account and share them among other accounts, avoiding the need to repeatedly create and configure resources in each account, thereby reducing the complexity of resource management.

* The service incorporates sharing policies for different types of resources, ensuring that shared resources meet business needs while limiting shared users to access resources within their permissions, enhancing the security of resource management.

* When sharing resources under an enterprise organization, the resources can be shared with the entire organization or OU, and automatically grant or revoke the shared access permissions of the corresponding accounts based on the changes in the accounts under the organization or OU.


<span id="quota-management"></span>
### Quota management

Provides a centralized platform for managing cloud resource quotas, allowing users to query and adjust resource quotas online. The details are as follows:


* Allows users to submit quota change requests online based on actual business needs. Once approved, the new quotas take effect automatically.

* Supports quota monitoring and alerting, and notifies users when resource consumption reaches a specified threshold, facilitating proactive quota change applications.

* After quota templates are enabled for an account group, multiple quota change applications will be automatically submitted at a time for new members, enhancing the efficiency and automation of quota management across the organization.
