This article describes the API endpoints and features provided by the Data Migration Service.


|**API** |**Functionality** |
|---|---|
|[CreateDataMigrateTask](https://docs.byteplus.com/en/docs/dms/CreateDataMigrateTask_-_Create_migration_task) |Create a migration task. |
|[CreateFailureDataMigrateTask](https://docs.byteplus.com/en/docs/dms/CreateFailureDataMigrateTask_-_Failed_to_create_new_task_migration_object) |Create a new migration task for failed objects. |
|[QueryDataMigrateTask](https://docs.byteplus.com/en/docs/dms/QueryDataMigrateTask_-_query_migration_task) |Query migration tasks. |
|[ListDataMigrateTask](https://docs.byteplus.com/en/docs/dms/ListDataMigrateTask_-_List_migration_tasks) |List migration tasks. |
|[StopDataMigrateTask](https://docs.byteplus.com/en/docs/dms/StopDataMigrateTask_-_Pause_migration_task) |Pause migration tasks. |
|[ResumeDataMigrateTask](https://docs.byteplus.com/en/docs/dms/ResumeDataMigrateTask_-_Resume_migration_task) |Continue migrating tasks that have failed or been paused. |
