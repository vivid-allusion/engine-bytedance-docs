This article introduces the features of storage migration service.

<span id="caff6717"></span>
### Support multiple types of source data

It supports migrating files from multiple mainstream vendors' object storage or URL lists to TOS.

<span id="c7b6a347"></span>
### Provide flexible migration methods


* It supports both full migration and incremental migration, and allows selecting the starting time of migration files.

* During the migration process, it supports different coverage strategies such as full coverage or coverage based on modification time.

* It supports setting flow control periods and maximum migration rates for migration tasks.


<span id="ed442025"></span>
### Provides intuitive migration progress and migration reports


* It provides intuitive migration data, including migration storage volume, migration file quantity, estimated remaining migration time, and other information.

* After migration is completed, it supports downloading migration reports.
