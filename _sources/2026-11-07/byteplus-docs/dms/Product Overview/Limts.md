This article introduces the limitations and explanations of the storage migration service.


|Limitations |Explanation |
|---|---|
|Migration Task Quantity |Each account can have a maximum of 5 tasks executing simultaneously in each region. |
|Migration Bandwidth |The default migration bandwidth is 100MB/s, which can be modified when creating a task. It supports a range of 1 to 1024MB/s. |
