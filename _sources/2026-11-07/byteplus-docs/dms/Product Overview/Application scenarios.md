This article introduces the scenarios applicable to storage migration services.

<span id="a56a49bc"></span>
### Data migration

Migrate object storage data stored with other cloud service providers or self\-built object storage data to BytePlus torch object storage through online migration.

<span id="cc46bdcb"></span>
### Data backup

Backup data stored in object storage services of other cloud service providers through migration; or migrate BytePlus torch object storage buckets to another object storage bucket in the same region for data backup.
