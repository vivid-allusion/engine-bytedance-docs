This article explains how to create migration tasks using dedicated networks in the DMS console.

<span id=".6IOM5pmv5L-h5oGv"></span>
## Background information

DMS supports the following source cloud service providers and data source types:


* Aliyun

* Tencent Cloud

* Huawei Cloud

* Qiniu Cloud

* Kingsoft Cloud

* Google Cloud

* Other S3 protocol object storage

* Object Storage \- BytePlus

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The DMS only supports data migration between BytePlus buckets in the same region.   </div>
   

When migrating files, HTTP standard attributes are supported by default, including Content\-Type, Content\-Disposition, Content\-Encoding, Content\-Language, Cache\-Control, and Expires.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* Before using DMS, make sure that you have signed up for BytePlus. For more information, refer to [Signing up for BytePlus accounts](https://docs.byteplus.com/byteplus-platform/docs/signing-up-your-account).

* Information about the data source has been obtained, such as AccessKey ID, AccessKey Secret, Endpoint, and bucket name.

* You have created a bucket in Object Storage. For more information, see [Create Bucket](https://docs.byteplus.com/en/docs/tos/docs-create-a-bucket).

* A data center (IDC) has been set up as a relay for data migration.


<span id=".5rOo5oSP5LqL6aG5"></span>
## Notes


* Currently, only China (Beijing), China (Guangzhou), China (Shanghai), China (Hong Kong), Asia Pacific (Johor), and Asia Pacific (Jakarta) support dedicated line migration tasks.

* When migrating data using a dedicated network, the source type does not support a URL list.

* If the source cloud service provider uses Object Storage on BytePlus, data migration is only supported between buckets within the same region.

* If versioning is enabled on the source bucket, object migration with DMS only transfers the latest version objects to the target bucket. Historical version objects will not be migrated.
