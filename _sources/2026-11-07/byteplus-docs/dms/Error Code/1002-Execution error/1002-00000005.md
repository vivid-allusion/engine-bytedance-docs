### Problem description

Task Verification Failed.

<span id="fba7281f"></span>
### Solution

Possible source access errors or destination access errors, troubleshooting steps are as follows:


* Source access error: Check if the network link to the source end is smooth, or check if the access rights of the source key's account in the migration task to the source end data are correct.

* Destination access error: Check if the access rights of the destination key's account to the destination bucket in the migration task are correct.
