### Problem description

The task failed to execute.

<span id="36a7d855"></span>
### Solution

Possible causes include an access error on the source side or the destination side. Troubleshooting measures for different errors are as follows:


* Source access error: Check whether the network link to the source is unobstructed, or check if the access permission to the source data is correct for the account associated with the source key in the migration task.

* Destination access error: Check whether the access permission to the destination bucket is correct for the account associated with the destination key used in the migration task.
