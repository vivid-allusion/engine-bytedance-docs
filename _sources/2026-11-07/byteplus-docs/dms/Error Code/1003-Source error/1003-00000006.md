### Problem description

Failed to retrieve source endpoint symbolic link object.

<span id="6ee8c073"></span>
### Solution

Check if the network link to the source endpoint is clear, or check if the account that owns the source endpoint key in the migration task has permission to retrieve the source endpoint symbolic link object.
