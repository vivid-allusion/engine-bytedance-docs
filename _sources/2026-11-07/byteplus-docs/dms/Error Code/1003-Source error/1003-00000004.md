### Problem description

Failed to retrieve source endpoint object Tag.

<span id="65dc2ca2"></span>
### Solution

Check whether the network link to the source endpoint is clear, or verify if the account associated with the source endpoint key in the migration task has permission to retrieve the source endpoint object Tag.
