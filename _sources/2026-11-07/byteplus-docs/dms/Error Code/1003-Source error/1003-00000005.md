### Problem description

Failed to retrieve source endpoint object ACL.

<span id="f15456dc"></span>
### Solution

Check if the network link to access the source endpoint is clear, or check if the account associated with the source endpoint key in the migration task has permissions to obtain the source endpoint object ACL.
