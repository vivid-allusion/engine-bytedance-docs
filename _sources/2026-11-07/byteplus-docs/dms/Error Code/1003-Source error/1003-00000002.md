### Problem description

Failed to query the metadata of the source\-end object.

<span id="5bb7dd12"></span>
### Solution

Check if the network link to the source side is unobstructed, or verify if the account associated with the source\-end key in the migration task has the permission to query the metadata of the source\-end object.
