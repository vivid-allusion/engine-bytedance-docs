### Problem description

Failed to retrieve source endpoint object data.

<span id="ec1b2f6d"></span>
### Solution

Check if the network link to access the source endpoint is open, or verify if the account associated with the source endpoint key in the migration task has the permissions to retrieve source endpoint object data.
