During the storage migration process, API requests, data uploads, and downloads are involved, which incur TOS usage fees. The details of the charges can be found in the [request fee](https://docs.byteplus.com/en/docs/tos/docs-request-fee) and [traffic fee](https://docs.byteplus.com/en/docs/tos/docs-traffic-fee). However, migration services are no longer charged separately.
