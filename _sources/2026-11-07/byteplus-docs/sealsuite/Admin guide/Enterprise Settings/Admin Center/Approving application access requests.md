When employees request access permissions for applications, their applications will be submitted to the Application Approval section in the SealSuite Admin Console. You can either approve or reject these requests based on the business need. Additionally, you can view the history of approvals that have already been completed.

<span id="d4a7a4f7"></span>
# Prerequisites

Employees must request access permissions before you can approve them in the SealSuite Admin Console. The specific instructions regarding application of access permissions are as follows:

Adminsitrator needs to configure if the application is open for request. When the application authorization is set to **Restricted**, enabling the feature to **Allow employees to apply** allows employees with access permissions to share the application link with colleagues who do not have permission. Upon accessing the link, these employees can then request application access permissions.

# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, select **Enterprise Settings** \> **Admin Center**.

3. Switch to the **Approval Center** tab, view the requested Information.

4. In the **Action** column, click **Approve** or **Reject**.

   When there are multiple requests, you can select multiple checkboxes before approval and then **Batch approve** or **Batch reject**.

   After approval, employees are granted application access permission.

5. Click the **Processed** or **All** tab to view the approval history.
