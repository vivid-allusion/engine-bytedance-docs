The **Endpoint Control** module provides a comprehensive toolset for establishing and enforcing your enterprise's endpoint security policies. Through this module, administrators can define security baselines, manage system patches, and monitor endpoint risk events to ensure that all devices connected to the network comply with corporate security and compliance requirements.

<span id="2adf444f"></span>
# Function introduction

The Endpoint Control functionality consists of the following parallel modules, which you can switch between using the tabs at the top:


|**Feature** |**Description** |**Related Documents** |
|---|---|---|
|**Endpoint Baseline** |Defines and monitors the security compliance standards for endpoint devices, including the following core capabilities:<br><br><br>* **Risk Alerts**: Centrally view all risk alert events generated by violations of baseline policies.<br><br>* **Policy Management**: Create and manage endpoint baseline policies and define detection rules. When a rule is triggered, a corresponding alert event is generated.<br><br>* **Scanning Configuration**: Customize baseline, application, and process detection items. |[Viewing risk alerts](https://docs.byteplus.com/docs/sealsuite/docs-event-list)<br><br>[Configuring endpoint control policy](https://docs.byteplus.com/docs/sealsuite/docs-control-rules)<br><br>[Configuring device scanning items](https://docs.byteplus.com/docs/sealsuite/docs-configure-detection-items) |

# Recommended Configuration Workflow

When using the Endpoint Control modules, we recommend following these steps:


1. **Configure Detection Items**

   Before configuring control policies for your enterprise endpoints, you must first configure baseline and application detection items according to your corporate security requirements.

2. **Add Control Policies**

   Add endpoint control policies based on your security requirements. Once a policy takes effect, SealSuite will continuously monitor employee endpoints according to the policy and collect any risk events.

3. **View the Event List**

   SealSuite displays all collected endpoint risk events in the event list, allowing you to review each risk item and take timely action.
