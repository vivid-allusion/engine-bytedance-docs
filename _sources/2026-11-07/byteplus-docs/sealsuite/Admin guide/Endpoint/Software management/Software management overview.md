In software management, you can view software installation statistics on user devices, manage authorized licenses for commercial software, distribute specific software for your target devices and add required enterprise software in the software library where users can download their desired softwares. This article introduces the functions included in software management.

<span id="ac3b8fb6"></span>
# Software Statistics

When you enable the software statistics function, SealSuite will collect software installation information on the user devices that have SealSuite clients installed and display this information uniformly in the software statistics list. In the list, you can view basic software\-related information, such as the software name, software version, operating system, and Bundle ID/Manufacturer. Besides, you can get software statistics, such as the number of devices with specific software installed, the number of users relating to the devices, the ratio of software installation, and more. You can also view and manage the status of software licenses in the list.

With the software statistics function, you can:


* Get software usage information, such as the frequently used enterprise software or uncompliant software on user devices. With so much more software\-related information here, you can effectively manage enterprise software based on your operational needs. For example, you can make procurement plans for commercial software needs based on the number of devices with specific software installed, and the number of users relating to the devices.

* After your enterprise purchases authorized software, you can enable the software license function to ensure the authorized use of software within the enterprise. With this function enabled, you can prevent the security risk associated with license overages by limiting the usage scope of software licenses and enabling the alert notification capability.


For more information on the software statistics function, please refer to [Viewing software statistics](https://docs.byteplus.com/docs/sealsuite/docs-viewing-software-statistics).

<span id="c85d11f3"></span>
# License Management

The software license function is used to manage authorized software purchased by your enterprise. It provides control and visibility into the usage of your software licenses, enabling you to limit the usage scope of licenses by devices or users. It also offers the alert notification capability and usage prohibition capability. When SealSuite detects unauthorized use of enterprise software on a particular device or by a specific user, it will send alert information to a designated administrator, who can choose to distribute required licenses or restrict the use of the specific software for the particular device or user.

<span id="d2cff14d"></span>
# Software Distribution

With the software distribution function, you can distribute required software for Windows or Mac to specific user devices in batch.

For more information on the software distribution function, please refer to [Distributing software to user devices](https://docs.byteplus.com/docs/sealsuite/docs-distributing-software-to-user-devices).

<span id="952c3333"></span>
# Software Library

You can add frequently used enterprise software to the software library in the Admin Portal, which will synchronize all the software within the library to the software library on the SealSuite client. This allows users to download their desired enterprise software though SealSuite clients.

For more information on the software library function, please refer to [Configuring software library for client](https://docs.byteplus.com/docs/sealsuite/docs-configuring-software-libraries-for-client).
