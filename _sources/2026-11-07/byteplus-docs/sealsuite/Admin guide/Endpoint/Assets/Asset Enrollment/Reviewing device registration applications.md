If manual approval is enabled for a device registration rule, you must manually approve users' device registration application in the **Device Registration** page. From there, you can also view the approval results and historical approval records.

<span id="Procedure"></span>
# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, click **Endpoint** \> **Assets** \> **Enrollment**.

3. (Optional) Under the **Approval List** tab, search for target applications by using filters.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c4dbde21b89d4534a1fe37e793f7e026~tplv-goo7wpa0wc-image.image) </span>

4. In the application list, locate your target application and then:

   * In the **Action** column, click **Pass** or **Reject** to approve or reject applications individually.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4814b529191948cd843ed5ac9e4bf8d2~tplv-goo7wpa0wc-image.image) </span>

   * Select multiple applications and pass or reject them in batch.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/192b745f36884684be7ba391cbc6b164~tplv-goo7wpa0wc-image.image) </span>

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">If you choose to pass or reject applications in batch, you need to set a denial reason that will be synced to the users' SealSuite clients.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">The <strong>Action</strong> column will display the approval results.      </div>
      

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fe84b642b50c475ca17838be745f8c93~tplv-goo7wpa0wc-image.image) </span>
