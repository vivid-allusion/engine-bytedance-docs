The Assets module provides a unified platform for comprehensively managing all endpoint devices connected to SealSuit. When an employee logs into the SealSuit Client, the system automatically collects and syncs device information to the admin console, enabling centralized visibility, security assessment, and remote management of endpoint assets.

<span id="ec817e90"></span>
# Core Features


|**Feature** |**Description** |**Related** **documentation** |
|---|---|---|
|Asset List |Centrally displays and manages all endpoint devices, offering the following capabilities:<br><br><br>* Create groups to categorize and manage endpoints.<br><br>* View detailed device information and perform remote management actions.<br><br>* Add extended, business\-required information to devices through custom fields. |[Asset List](https://docs.byteplus.com/en/docs/sealsuite/Asset_List) |
|Security Posture |Once the organizational structure is configured and employee endpoints are connected to the SealSuit admin console via the SealSuit Client, you can use this feature to view endpoint information. SealSuit dynamically updates risk events and dynamic response records for each endpoint, allowing you to maintain a comprehensive understanding of the risk status of all employee endpoints. |[Viewing security posture](https://docs.byteplus.com/docs/sealsuite/docs-risk-events) |
|Asset Enrollment |This feature is designed to differentiate between corporate and personal devices and to tag device attributes. You can create one or more enrollment policies to configure registration content for different types of endpoints. Once a policy takes effect, employees within its effective scope can proactively register device groups or attributes through the SealSuit Client. |[Asset Enrollment](https://docs.byteplus.com/en/docs/sealsuite/Asset_Enrollment) |

# Related operations

The Endpoint module in the admin console's **Dashboard** provides a global statistical view of the enterprise's endpoint hardware and software assets. For more information, please refer to [Viewing the Dashboard](https://docs.byteplus.com/docs/sealsuite/viewing-the-dashboard).
