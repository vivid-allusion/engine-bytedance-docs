To efficiently manage the data of resigned employees, you can use the Manage Terminated Employees feature. This guide provides instructions on how to bulk delete accounts, configure automatic data\-cleaning policies, and rehire or delete individual members to maintain data hygiene.

<span id="9d9d6e52"></span>
## Use case

To improve information management efficiency, you can effectively process the data of terminated employees using the Manage Terminated Employees feature. For instance, the Batch Delete feature can be used to remove the user information of employees who resigned during a specific period and free up storage space.

<span id="1472f47f"></span>
## Bulk deleting terminated employee accounts


1. Log in to the SealSuite Admin Console.

2. In the left navigation bar, select **Identity** \> **Directory**.

3. On the **Directory** page, click the **Manage Terminated Employees** link.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/581da7fcc7c746c6bb16287f0cd1b122~tplv-goo7wpa0wc-image.image) </span>

4. Above the employee list, set the **Termination Date**, select the employees you want to delete, and click **Batch Delete.** 

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The employee name search only supports searching for one employee at a time. Use this to find a specific terminated user.   </div>
   

5. In the confirmation popup, click **Confirm.** 

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Before you confirm deletion, please review the selected data carefully. This action cannot be undone.   </div>
   

<span id="0ed76daf"></span>
## Configuring an automatic cleanup policy


1. Log in to the SealSuite Admin Console.

2. In the left navigation bar, select **Identity** \> **Directory**.

3. On the **Directory** page, click the **Manage Terminated Employees** link.

4. On the **Manage Terminated Employees** page, click the **More cleaning strategies** link.

5. In the **More cleaning strategies** popup, select the termination expiration period and select the types of data to be cleaned.

   The supported retention periods are 7, 30, and 90 days.

6. In the **More cleaning strategies** popup, click **Confirm**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Once the policy is active, the Admin Console automatically deletes the selected data for terminated employees after the specified retention period ends.   </div>

## Managing a specific terminated employee


1. Log in to the SealSuite Admin Console.

2. In the left navigation bar, select **Identity** \> **Directory**.

3. On the **Directory** page, click the **Manage Terminated Employees** link.

4. On the **Manage Terminated Employees** page, search for the target terminated employee, and in the employee's row, select **Rehire** or **Delete**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After the <strong>Rehire</strong> operation is successful, the employee data will be removed from the <strong>Manage Terminated Employees</strong> page and transferred to the designated department. You can manage the employee's information in <strong>Directory</strong>.   </div>
