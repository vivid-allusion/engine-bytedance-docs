SealSuite collects all remediation results of risk detections that satisfy the corresponding rule groups through the processing record function. Using the function, you can search for target remediation history and view detailed information such as device information, remediation actions, and source data.

<span id="454e4a0d"></span>
# Procedure


1. Log in to the Admin Portal.

2. In the left navigation bar, click **Dynamic Control** \> **Security Alerts** \> **Remediation Logs**.

3. On the **Remediation Logs** page, locate your target record and view the details.

   Filter your target remediation record by using the filter criteria at the top of the page.
