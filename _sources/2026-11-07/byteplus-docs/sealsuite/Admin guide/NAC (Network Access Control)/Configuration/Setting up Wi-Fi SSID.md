When configuring a RADIUS server and wireless router, you need to set the corresponding SSID for Wi\-Fi. The Wi\-Fi SSID is the name displayed on user devices and should match the WLAN name on the wireless controller. If you want to prevent unknown devices from connecting to the staff Wi\-Fi, you can choose to hide the SSID.

<span id="8fd2a941"></span>
# Instructions for use

The Wi\-Fi SSID setting includes both staff and guest Wi\-Fi. If both are enabled on the wireless router, you will need to set a unique SSID for each network.

<span id="6e4a2ba9"></span>
# Adding a Wi\-Fi SSID


1. Log in to the Admin Console.

2. In the left navigation bar, click **NAC** \> **Config**.

3. Under the **SSID** tab, locate your target router and click.

4. Click  **+Add** to add a SSID for **Staff Wi\-Fi** or **Guest Wi\-Fi**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/91d94ad8c1314979ad099c708e3ee1df~tplv-goo7wpa0wc-image.image) </span>

5. Enter the SSID in the text box and click the checkmark to save.


<span id="eba47a3b"></span>
# Editing or deleting Wi\-Fi SSID

Click  **···**  (the three\-dot menu) in the SSID card to edit, or delete the SSID.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a6e8e50066f479691e2853e1b3cfbf3~tplv-goo7wpa0wc-image.image) </span>

<span id="5c85ddaa"></span>
# Hiding staff Wi\-Fi SSID

If you have hidden the staff Wi\-Fi SSID on the wireless controller, you also need to hide it in the Admin Console. Otherwise, staff cannot connect to the Wi\-Fi with one click through the client.


1. Locate the staff Wi\-Fi SSID card that needs to hide the SSID.

2. Click  **···**  (the three\-dot menu) in the SSID card, and click **Tag Hide SSID**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d5b8ab1bbe2a430282bc931509600128~tplv-goo7wpa0wc-image.image) </span>

3. In the **Confirm tag hide SSID** dialog box, click **OK**.
