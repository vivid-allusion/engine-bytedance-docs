On the **Network Device** page, you can manage wireless routers or switches in a unified manner.

<span id="ca282409"></span>
# Editing or deleting a router


1. Log in to the Admin Console.

2. In the left navigation bar, click **NAC** \> **Config**.

3. Under the **Network Device** tab, locate your target router and click.

4. In the router card, you can:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/991b9fad7de849b2a1d41574fabeaf82~tplv-goo7wpa0wc-image.image) </span>

   * Turn on or off **Staff Wi\-Fi** and **Guest Wi\-Fi**.

   * Click **Edit**: In the **Edit Wireless controller** dialog box, modify the information of the router.

   * Click **Delete**: Delete the router, and the Wi\-Fi network will be automatically disconnected after deletion.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Please proceed with caution when deleting the routers, because they cannot be restored after being deleted.      </div>
      

5. Click on the router card to go to the details page, where you can:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ae6d4b8e5c8843a68073bab7172641ba~tplv-goo7wpa0wc-image.image) </span>

   * At the top of the page, switch to the details page of the other router.

   * View or edit the following information about the router.

      
      |**Configuration Item** |**Description** |
      |---|---|
      |**Brand** |Edit the brand name of the router. |
      |**IP address** |Edit the source IP address of the router. The following IP address formats are supported:<br><br><br>* IP address, such as 10.10.0.0<br><br>* IP address range, such as 10.10.0.0 \- 10.10.0.5<br><br>* CIDR. |
      |**MAC Address** |Edit the MAC address of the router. |
      |**CoA port** |CoA allows you to modify employees' permissions or re\-authenticate them using RADIUS after their successful authentication. This configuration should be consistent with the CoA port of the wireless router. The default value is 3799. |
      |**Shared key** |A shared key is used to confirm the legitimacy of the identity of the other party by determining whether they have the same password. The shared key here refers to the shared key created when setting up the RADIUS server for this device, which is randomly generated by SealSuite, and you can:<br><br><br>* Show or hide the key.<br><br>* Copy the key.<br><br>* Reset the key.<br><br>* Edit the key.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">After the key is reset and edited, the network device needs to update the shared key. Please proceed with caution, because employees cannot connect to the network after the key is modified.</div><br> |
      |**Staff Wi\-Fi** Tab |View the staff Wi\-Fi SSID and corresponding RADIUS server information. |
      |**Guest Wi\-Fi** Tab |* View or edit guest authentication information.<br><br>   * **Visitor Authentication Protocol Type**: Selecting **Portal** or **PEAP** authentication.<br><br>      * **Portal**: The client supports selecting username and password or employee QR code scan for guest authentication. This authentication method also requires configuring the following information:<br><br>         * **Visitor authentication information receiving address**: The external docking address provided by the wireless router for external Portal authentication, and external portal services use this address to submit guest usernames and passwords.<br><br>         * **Visitor Authentication User Name Field**: The username field used by the wireless router, and field value may vary across different device manufacturers.<br><br>         * **Visitor Authentication Password Field**: The password field used by the wireless router, and field value may vary across different device manufacturers.<br><br>         * **Custom visitor authentication information**: When guest authentication requires additional fields, you need to input customized data through custom JSON\-based format to meet requirements of different device brands.<br><br>            <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="4">tip            </div><br>            <br><br>            <div data-tips="true" data-tips-type="tip" data-wrapper-indent="4">If the corresponding wireless router needs to configure a guest portal server to achieve portal authentication, please refer to <a href="https://docs.byteplus.com/docs/sealsuite/docs-managing-guest-portal-server">Managing guest portal server</a>.            </div><br>            <br><br>      * **PEAP**: The client only supports guest access through account password authentication. With PEAP chosen, you cannot deactivate accounts in the Application List of Guest Wi\-Fi.<br><br>* View the guest Wi\-Fi SSID and corresponding RADIUS server information. |
      

   * In the upper right corner of the page, click **Delete** to delete the wireless router.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">The Wi\-Fi network will be automatically disconnected after deletion.      </div>

# Editing or deleting a switch


1. Log in to the Admin Console.

2. In the left navigation bar, click **NAC** \> **Config**.

3. Under the **Network Device** tab, locate your target switch and click.

4. In the switch card, you can:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/884cdccf7e794a5aad076c121861c113~tplv-goo7wpa0wc-image.image) </span>

   * Click **Edit**: In the **Edit Wired switch** dialog box, modify the information of the switch.

   * Click **Delete**: Delete the switch, and the wired network will be automatically disconnected after deletion.

5. Click on the switch card to go to the details page, where you can:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a4263134747f413ab48abc8d1ab0e62c~tplv-goo7wpa0wc-image.image) </span>

   * At the top of the page, switch to the detail page of the other switch.

   * View or edit the following information about the switch.

      
      |**Configuration Item** |**Description** |
      |---|---|
      |**Brand** |Edit the brand name of the switch. |
      |**IP address** |Edit the source IP address of the switch. The following IP address formats are supported:<br><br><br>* IP address, such as 10.10.0.0<br><br>* IP address range, such as 10.10.0.0 \- 10.10.0.5<br><br>* CIDR. |
      |**MAC Address** |Edit the MAC address of the switch. |
      |**CoA port** |CoA allows you to modify employees' permissions or re\-authenticate them using RADIUS after their successful authentication. This configuration should be consistent with the CoA port of the local switch. The default value is 3799. |
      |**Shared key** |A shared key is used to confirm the legitimacy of the identity of the other party by determining whether they have the same password. The shared key here refers to the shared key created when setting up the RADIUS server for this device, which is randomly generated by SealSuite, and you can:<br><br><br>* Show or hide the key.<br><br>* Copy the key.<br><br>* Reset the key.<br><br>* Edit the key.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">After the key is reset and edited, the network device needs to update the shared key. Please proceed with caution, because employees cannot connect to the network after the key is modified.</div><br> |
      

   * In the upper right corner of the page, click **Delete** to delete the switch.

      The wired network will be automatically disconnected after deletion.
