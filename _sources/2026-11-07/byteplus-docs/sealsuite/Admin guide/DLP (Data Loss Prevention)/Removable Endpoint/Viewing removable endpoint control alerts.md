When an active Removable Endpoint Control policy exists in the Admin Console and a removable endpoint connected to a device triggers this policy, an alert event is recorded in the alert event list of the SealSuite Admin Console. This article describes how to view Removable Endpoint Control alert events.

<span id="7de4faa8"></span>
# Prerequisite

The Removable Endpoint policy has been configured and implemented, and a user device has triggered the policy by connecting a Removable Endpoint. For policy configuration operations, please refer to [Configuring removable endpoint control policies](https://docs.byteplus.com/docs/sealsuite/docs-configuring-peripheral-control-rules).

<span id="82b17b76"></span>
# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, click **DLP** \> **Removable Endpoint**.

3. On the **Removable Endpoint** page, click the **Alerts** tab.

4. In the **Alerts** tab, view alert event details.

   * At the top of the alert event list, you can use filters or keywords to retrieve specific alert alerts. To search specified alert alerts by filters, you can choose from **Alert Creation Time**, **Access Type**, **Operating Systems(OS)** , and **Device Type**. To search specific alerts by keywords, you can select **Policy Name**, **VID**, **PID**, or **Serial Number**.

   * On the right side of the alert event list, click **three\-dot menu (···)**  to adjust the column fields displayed in the list.

   * In the alert event list, you can view the alert creation time, device type, policy, access control, device information, operating system, and user information of Removable Endpoints.
