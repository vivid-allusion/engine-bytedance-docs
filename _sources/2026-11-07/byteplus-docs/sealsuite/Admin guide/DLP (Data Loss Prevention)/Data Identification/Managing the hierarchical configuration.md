SealSuite provides four built\-in standard data sensitivity levels, L1 to L4, and allows extension to up to 9 levels (L5 to L9). You can customize the name, description, and color of each level, and specify whether to enable it.

 &nbsp;

<span id=".5qC45b-D6YC76L6R5LiO57qm5p2f"></span>
# Feature logic

Before configuring, understand the following system logic and constraints:


* **Multiple\-level match logic**: The system determines the sensitivity level by the **level number**. A larger number indicates a higher sensitivity level. If a file matches multiple classification and sensitivity rules, the system uses the **highest sensitivity level with the largest number** as the final sensitivity level of the file.

* **File classification rules**: The system provides preset level information for L1 to L4, which can be further edited. L5 to L9 sensitivity levels must be configured manually. Each sensitivity level can be enabled or disabled. The order cannot be adjusted, and levels cannot be deleted.


 &nbsp;

<span id=".5YmN5o-Q5p2h5Lu2"></span>
# Prerequisites

The Administrator must have the required menu and operation permissions. For more information, see [Configure Administrator permissions](https://docs.byteplus.com/en/docs/sealsuite/docs-adding-administrator_1):


* Menu permission: **Security** \> **DLP** \> **Data identification** \> **hierarchical configuration**.

* Operation permission: **DLP** \> **Data identification** permission points.

## Edit data sensitivity levels

Customize existing sensitivity level attributes based on your enterprise data security standards.


1. Log in to the Admin Console.

2. In the left navigation pane, choose **DLP** \> **Data identification** \> **hierarchical configuration**.

3. In the settings list, find the sensitivity level to adjust, and click **Edit** on the right.

4. In the **Edit data level** window, configure the following parameters:

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a09ec39e64984d05ba4c519807e1b09d~tplv-goo7wpa0wc-topic.webp) </span>

&nbsp;

   
   |**Configuration item** |**Description** |
   |---|---|
   |**Level Number** |Automatically generated by the system (1 to 9). It represents the order and sensitivity of the level. A larger number indicates a higher sensitivity level. **Modification is not supported**. |
   |**Grading name** |(Required) The public display name of the level, such as Public, Internal, Confidential, or Top Secret. |
   |**Graded Description (Chinese)**  |(Optional) A detailed Chinese description of the scenarios where this sensitivity level applies, such as executive confidential data or core data. Up to 10 characters are supported. |
   |**Classification Description (English)**  |(Optional) A detailed English description of the scenarios where this sensitivity level applies, such as level_7 or Confidential. Up to 15 characters are supported. |
   |**Grading color** |Defines the dedicated visual color of this sensitivity level in the system frontend. After you change the color, you can view the latest style in real time in **Preview** below. |
   

5. Click **Confirm** to save the configuration.

## Enable or disable data sensitivity levels

You can use the toggle to control the status of the built\-in L1 to L4 sensitivity levels and extended L5 to L9 sensitivity levels.


1. Log in to the Admin Console.

2. In the left navigation pane, choose **DLP** ＞ **Data identification** ＞ **hierarchical configuration**.

3. Use the toggle for the target sensitivity level to enable or disable that level.

   * **Enable**: After you turn on the toggle, this level is added to the data levels. Administrators can select and apply this sensitivity level when creating policies such as "Classification and grading rules" and "Document outgoing control policies".

   * **Disable**: After you turn off the toggle, this level is removed from the data levels and no longer participates in new policy matching. Existing historical audit data retains the original sensitivity level identifier.
