SealSuite provides logs for services such as identity, network, and endpoints. These logs help Administrators understand employee activities, troubleshoot issues, and trace operations. You can also use **log forwarding** to send logs to your enterprise\-owned Syslog server or Elasticsearch cluster for centralized analysis and long\-term retention.

The following sections list the recorded content, view location, retention period, and log forwarding support for each log type by service module.
