SealSuite provides SD\-WAN capability based on the software\-defined wide area network (SD\-WAN), which applies to diverse scenarios, including teleworking. Using this feature, you can easily achieve network interconnection for branch offices, allowing users who work remotely to securely access enterprise resources.

<span id="745aa3ce"></span>
# Function introduction

<span id="28162503"></span>
## Efficient office network setup

With SD\-WAN, SealSuite’s SD\-WAN function helps you set up your corporate network in a cost\-effective way, reducing the complexity of network deployment, operation, and maintenance associated with the use of conventional networking methods. Using this function, you simply need to configure branch gateways to establish connections between SealSuite’s public cloud and your target networks, such as the networks of your branch offices, your headquarters, your internet data center (IDC), your cloud server, and more. SealSuite uniformly manages these networks by using the intelligent network traffic scheduling method, enabling network interconnection for your enterprise.

The following diagram shows SealSuite’s network architecture:

* The branch gateway can be added by the administrator according to the corporate network situation.

   The branch gateway is used to create connections between SealSuite's network and your enterprise's networks established in branch offices, headquarters, IDC, and other locations.

* SealSuite's public cloud provides intelligent scheduling capabilities to help your enterprise achieve low\-cost and lightweight deployment of SD\-WAN.

   SealSuite public cloud functions as a central SD\-WAN controller, which uniformly manages the SealSuite inbound nodes (that is, POP nodes) and, through intelligent scheduling, routes network traffic from each branch gateway to nearby POP nodes, providing optimal network experience for your enterprise.

## Teleworking powered by the cloud

After setting up the office network through the configuration of the branch gateway, you can choose to enable SealSuite's teleworking under the SD\-WAN module. When turned on, SealSuite will automatically generate cloud access gateways and cloud application gateways. You can choose to enable the teleworking capability using one or more of the following teleworking methods according to the actual business situation:


* Method 1: Users who work remotely can access the corporate intranet by connecting to the VPN via the SealSuite client.

   The enterprise provides users with a cloud VPN node by configuring a cloud access gateway automatically generated by SealSuite, and users can access the enterprise intranet via SealSuite client connection to this VPN node later.

* Method 2: Users who work remotely can access internal applications through Web browsers in situations where the SealSuite client isn’t installed.

   By configuring SealSuite's automated cloud application gateway, users can access internal applications directly on the Web without the need for users to connect to a VPN.

# Branch gateway introduction

SealSuite's branch gateway is divided into two versions: software version and hardware version. The details of different versions are as follows:


* **The software\-based branch gateway**

   To use the software\-based branch gateway, you need to deploy SealSuite's branch gateway components to local servers or virtual machines in each branch office. This branch gateway applies to networking scenarios where enterprises have already required IT infrastructures for SealSuite's branch gateway components to be deployed and configured. This option allows enterprises to quickly establish an interconnected network across branch offices.

* **The hardware\-based branch gateway**

   SealSuite offers a physical network device named FLG, which has built\-in branch gateway capability. After your enterprise purchases a FLG, you simply need to complete the initial configuration of powering the device, connecting it to the Internet, and associating it with the Admin Portal. After that, you can configure branch gateways. FLG eliminates the need for local management of servers or virtual machines in the enterprise, allowing for the establishment of an enterprise office network through simple and flexible deployment. At the same time, FLG can be managed as a unified fixed asset for the enterprise.

# Functional advantages

Using SealSuite's SD\-WAN function enables your enterprise to:


* Uniformly manage, operate and maintain networks with the help of intelligent network monitoring capabilities

   Networking resources are centrally managed on SealSuite's public cloud, and the status of each branch gateway can be easily monitored and managed with the Usage Monitoring capability provided by SealSuite.

* Use load balancing techniques and implement failover in seconds

   SealSuite's intelligent routing capability and branch gateways can be used to maintain high network availability when failures occur.

* Optimize network performance and bandwidth usage

   SealSuite's intelligent routing capability enables you to lower bandwidth usage through dynamic bandwidth allocation, providing a streamlined user experience with better network connectivity.

* Enable the teleworking capability

   With the teleworking capability, users can securely access enterprise resources using SealSuite's cloud\-based services and work in an effective and efficient way.

# Basic concepts

This section introduces important concepts associated with the SD\-WAN function.


|**Concept** |**Description** |
|---|---|
|SD\-WAN |A software\-defined wide area network (SD\-WAN) is a virtual network architecture that establishes a software\-defined network to optimize the utilization of wide area networks (WANs) . This is enabled by the use of a SD\-WAN controller that abstracts and centralizes the management of physical WAN networks, allowing an enterprise to optimize WANs performance through efficient bandwidth management. The SD\-WAN architecture is widely applicable to networking scenarios, enabling network interconnection for branch offices of an enterprise. |
|Branch gateway |Branch gateway refers to a gateway that facilitates network connectivity between SealSuite’s public cloud and your enterprise's networks established in different locations. By configuring branch gateways for these locations, you can connect SealSuite’s public cloud with on\-premises networks, including the networks of branch offices, the headquarter, the internet data center, and cloud servers, allowing users to access enterprise resources across premises. |
|Cloud access gateway |Cloud Access Gateway refers to a cloud\-based VPN node created by SealSuite, which allows users who work remotely to access the corporate intranet through the SealSuite client. |
|Cloud application gateway |Cloud Application Gateway refers to a cloud\-based gateway created by SealSuite to proxy requests between users and enterprise applications hosted on the backend server. It is used to enable users who work remotely to access internal applications in situations where the SealSuite client isn’t installed. |
