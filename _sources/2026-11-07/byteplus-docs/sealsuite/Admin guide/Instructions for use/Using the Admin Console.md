The SealSuite Admin Console is the central hub for managing your enterprise's security and endpoint policies. This document provides a comprehensive overview of all available functional modules, from Identity and Endpoint management to Data Loss Prevention (DLP) and Zero Trust Access. Use this guide to quickly understand the purpose of each module and navigate to detailed operational instructions.

<span id="fa3b6935"></span>
# Introduction to SealSuite's Admin Console


* The functional modules in the Admin Console will be displayed according to the actual SealSuite functions purchased by your enterprise.

* All operations in the user guide must be completed by the enterprise administrator, and enterprise users do not have access to the Admin Console. If you need to set up SealSuite administrator permissions for enterprise users, you need to log in to the Admin Console for configuration. For more information, please refer to [Configuring Administrator Access](https://docs.byteplus.com/docs/sealsuite/docs-adding-administrator_1).

# Function Overview


|**Functional Module** |**Description** |**Related Documents** |
|---|---|---|
|**Identity** |The **Identity** management module lets you manage the company's subsidiaries, departments, members, and roles. A single platform integrates with the company's internal office systems. By establishing a unified employee identity system, this module provides fine\-grained, end\-to\-end lifecycle management for employees and automates authorization adjustments to prevent security risks. |[Identity overview](https://docs.byteplus.com/docs/sealsuite/docs-what-is-iam-) |
|**Endpoint** |Manages the entire lifecycle of corporate endpoints. This includes features like **Assets** inventory, endpoint baseline policies, patch management, **Software** distribution and control, and **MDM**, ensuring that all devices accessing the network are compliant and controllable. |[Endpoint](https://docs.byteplus.com/en/docs/sealsuite/endpoint) |
|**AI security** |Provides security management capabilities for AI Agent and Skill usage risks within the enterprise, including Asset inventory and disabling, Skill security detection, Agent Behavior Guardrails, and Agent Full Link Audit. This helps administrators identify and control high\-risk AI tools and extensions. |[AI Security overview](https://docs.byteplus.com/docs/sealsuite/agent-security-overview) |
|**Endpoint Security** |Focuses on endpoint security. It provides features such as **Anti\-Virus**, **Endpoint Firewall**, and **Threat Intelligence** integration to protect endpoints from malware and network attacks. |[Anti-Virus overview](https://docs.byteplus.com/docs/sealsuite/docs-overview) |
|**DLP** |Protects core corporate data assets using Data Loss Prevention (**DLP**). This includes identifying **Risk Employees**, monitoring data flow trends (**eDiscovery**), controlling file transfers and outbound channels (**File Transfer Control** & **Channel Block Control**), managing watermarks (**Watermark**), and controlling removable devices (**Removable Endpoint**) to prevent sensitive data leakage. |[Data Loss Prevention (DLP) overview](https://docs.byteplus.com/docs/sealsuite/docs-dlp-overview) |
|**NAC** |Performs identity authentication and authorization management for devices accessing the corporate network. It supports configuring differentiated network access policies for different types of users and devices, such as employees (**Staff Network**), visitors (**Guest Network**), and dumb terminals (**Dumb Terminals**), to ensure the security of the internal network environment. |[Network Access Control (NAC) overview](https://docs.byteplus.com/docs/sealsuite/docs-wi-fi-management-overview) |
|**Zero Trust Access** |Based on the zero\-trust security model, it provides a secure remote access portal for enterprise applications. It centrally manages access gateways (**Gateway Config**), application resources (**Application**), and access policies, ensuring that every user and device undergoes strict identity authentication and authorization checks before accessing internal services. |[Zero Trust Access](https://docs.byteplus.com/en/docs/sealsuite/zero-trust-access) |
|**SD\-WAN** |Provides a Software\-Defined Wide Area Network (**SD\-WAN**) solution to build an efficient, stable, and secure interconnected network between corporate headquarters and branch offices. It supports application routing policies (**Routing Policy**) and centralized monitoring of network status (**Monitoring**). |[SD-WAN overview](https://docs.byteplus.com/docs/sealsuite/docs-office-networking-overview) |
|**Dynamic Control** |This module is a continuous verification and dynamic decision engine within the zero\-trust framework. It assesses risks in real\-time based on contextual information such as device status and user behavior, and automatically executes predefined **Control Policies** (e.g., alerts, blocking) to achieve an adaptive, closed\-loop security system. |[Dynamic control overview](https://docs.byteplus.com/docs/sealsuite/docs-overview-of-dynamic-control) |
|**Enterprise Settings** |This is a global management and configuration center at the enterprise level. It includes features such as general company information (**Company General**), administrator access models (**Admin Access**), approval center, workflow configuration (**Workflow**), and product version release management (**Versions**). |[Enterprise Settings](https://docs.byteplus.com/en/docs/sealsuite/enterprise-settings) |
|**Branding** |Supports brand customization for the **SealSuite** portal and client, such as configuring the corporate logo and login page background to align with the company's brand image. |[Branding](https://docs.byteplus.com/en/docs/sealsuite/branding) |
|**Audit Logs** |Provides comprehensive operation logs and system event records. Administrators can query and audit all management operations and critical system activities here to meet security compliance requirements and to provide data for event forensics. |[Log Export and Auditing](https://docs.byteplus.com/docs/sealsuite/docs-zk9yxy9szc) |
|**System Settings** |This module is responsible for the underlying technical configuration and integration of the **SealSuite** system. This includes API management, event subscription, notification settings, general client settings, **Resources** management, and a built\-in **IT Tools** toolkit. |[System Settings](https://docs.byteplus.com/en/docs/sealsuite/docs-system-settings) |
