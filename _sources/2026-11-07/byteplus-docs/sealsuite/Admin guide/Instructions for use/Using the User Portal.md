The SealSuite Admin Console includes a user\-facing portal that is accessible to all employees with a SealSuite account. The portal serves as a central hub, providing quick access to corporate applications, personal account management, and SealSuite client downloads. Administrators can also use the portal as a convenient entry point to the Admin Console.

<span id="c237a91c"></span>
# Important Note for Administrators

We recommend that you distribute the user portal's URL to all employees. The portal empowers them to self\-manage their SealSuite accounts, access their applications, and view corporate announcements.

<span id="6d9d1179"></span>
# How to Access and Use the Portal


1. Log in to the SealSuite portal through the access link of the portal website.

   You need to use the SealSuite administrator account and password to log in.

2. From the portal, select the action you want to perform.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/720d3f6e02f248b9a6b2f614a99328eb~tplv-goo7wpa0wc-image.image) </span>

   The instructions are as follows:

   * Area ① in the screenshot displays the current user's name and allows you to search for enterprise applications using keywords.

   * In the area ② circled in red in the screenshot, it provides access to functions such as client downloads and personal information management.

      * For details on managing SealSuite client versions (desktop and mobile), see [Managing Client Versions and Patches](https://docs.byteplus.com/docs/sealsuite/docs-versions).

      * Click the icon to view personal information. On the personal information page, you can adjust the avatar of the current account or change the mobile phone number.

      * Click the icon to adjust the page language (Simplified Chinese or English).

      * Click the icon to select whether the current account will only **Log out of SealSuite** or **Log out of all applications**.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">If you configure enterprise applications in the SealSuite Admin Console later, SealSuite will directly access enterprise applications through single sign\-on, so you can select the effective range of account information when logging out.      </div>
      

   * In the area ③ circled in red in the screenshot, applications recommended by the enterprise are displayed by default. For details on configuring applications, see [Managing Web App](https://docs.byteplus.com/docs/sealsuite/managing-web-app).

      You can also add an application as a recommended application (this method only supports quick addition through the application access address).

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c923bcf26257433185be6602b0a1a0b5~tplv-goo7wpa0wc-image.image) </span>

   * Area ④ in the screenshot contains the following options:

      * **Device**: View the information of the device currently logged into SealSuite, including the device name, operating system, last login IP, and time of last activity. You can also click **Logout** to sign out from a specific device.

      * **Logs**: View the operation log of the current logged\-in user, including the action type, device, log details, IP address, and timestamp.

      * **Security**: Change the login password or mobile phone number.

      * **Admin**: This option is only visible to SealSuite administrator accounts and provides a shortcut to the SealSuite Admin Console.

   * In the area ⑤ circled in red in the screenshot, it displays the enterprise applications that have been added to the SealSuite Admin Console.

      For specific instructions on adding an application, please refer to [Managing Web App](https://docs.byteplus.com/docs/sealsuite/managing-web-app).

   * As shown in area ⑥ above, it is a custom information display area. Enterprise administrators can configure this area in the **Branding** section of the SealSuite Admin Console. For specific instructions, please refer to [Customizing SealSuite Portal](https://docs.byteplus.com/docs/sealsuite/docs-customizing-sealsuite-portal).
