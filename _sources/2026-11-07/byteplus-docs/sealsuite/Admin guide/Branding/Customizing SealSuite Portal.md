In the Branding function of the SealSuite Admin Console, you can adjust the external display style of the SealSuite portal website. In addition, SealSuite has reserved a custom area within the portal website, which supports displaying enterprise\-related information in the form of images or text such as enterprise announcements, important notices, or help documents.

<span id="7bf0eeb4"></span>
# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, click **Branding**.

3. In the **Function Configuration** section, click the **Portal Appearance** card.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/32288f7b72a6484896cf7cbcabd1dac9~tplv-goo7wpa0wc-image.image) </span>

4. On the customization page, select the page type according to actual needs, either **Management** **Console type** or **Notification type** is optional, and complete the relevant configurations.

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">You can see a live preview of your changes on the right side of the screen.   </div>
   

   Taking **Management** **Console type** configuration as an example, the description is as follows:

   |**Configuration Item** |**Description** |
   |---|---|
   |**Logo** |Replace the default SealSuite logo on the login page with your own. You can use the multi\-language icon to upload different logos for different languages. If a language\-specific logo is not provided, the default one will be used. |
   |**Header background** |Set the background image of the portal website page header. |
   |**Favicon** |Customize the favicon that appears in the browser tab. |
   |**Tab title** |Change the default text that appears in the browser tab. Use the multi\-language icon to provide different titles for different languages |
   |**Theme color** |Select the primary accent color for buttons and links within the login card |
   |**Footer** |Enable this to add custom footer text to the login page. You can provide multi\-language versions. If a specific language is not configured, the default language text will be displayed. |
   |**Custom area** |Set **Area name** and **Display method**. The **Display method** supports configuring either **Picture** or **Text**. 5. Click **Save as Draft** or **Save and Publish**.

   * **Save as Draft**: Only save the current configuration, but it will not take effect immediately. You need to continue to the next step and turn on the effective status switch.

   * **Save and Publish**: Save the current configuration and take effect immediately.

6. (Optional) Turn on the effective switch.

   If your portal configuration effective switch is not turned on, or if you have selected **Save as draft** when customizing the portal, you need to turn on the configuration effective switch in the **Portal** **Apperance** card on the **Branding** page.
