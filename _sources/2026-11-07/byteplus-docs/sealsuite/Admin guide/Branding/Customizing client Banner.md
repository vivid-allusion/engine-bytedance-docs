The client banner refers to a banner image displayed within the SealSuite client, usually used to display the enterprise logo or a unified enterprise style image.

<span id="bed07f4c"></span>
# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, click **Branding**.

3. In the **Function Configuration** section, click the **Banner** card.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c05312fd015044d1b249cd75029a974a~tplv-goo7wpa0wc-image.image) </span>

4. On the **Banner** page, click **Add Banner**.

5. On the **Add Banner** page, complete the following configurations.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After filling in the configuration items in the <strong>Configure Banner</strong> area on the left side of the page, you can preview the effects of <strong>Mobile</strong> and <strong>Desktop</strong> devices in real\-time in the <strong>Preview</strong> area on the right side of the page.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8fb488842e9e43548a9c775c5076fe00~tplv-goo7wpa0wc-image.image) </span>

   The description of configuration items is as follows:

   
   |**Configuration Item** |**Description** |
   |---|---|
   |**Name** |The name of Banner. It is only used to identify the current Banner in the Admin Console and will not be displayed on the SealSuite client. |
   |**Environment to Display** |You can select **Mobile** or **Desktop**. Multiple selections are supported. The configuration instructions are as follows:<br><br><br>* **Mobile**<br><br>   1. Select the **Mobile** checkbox.<br><br>   2. Add **Image**, fill in the corresponding link for the image optionally.<br><br>   3. (Optional) Click **Add image**. Multiple images can be added.<br><br>   4. (Optional) After adding multiple images, they will be displayed in a carousel format on the client. The **Carousel Timer** needs to be set.<br><br>* **Desktop**<br><br>   1. Select the **Desktop** checkbox.<br><br>   2. Add **Image**, fill in the corresponding link for the image optionally.<br><br><br>Redirect link description:<br><br><br>* If a redirect link is set, clicking Banner in the client will redirect access to the link after the configuration takes effect.<br><br>* If redirect link is not set, only Banner will be displayed in the client after the configuration takes effect. |
   |**Scope** |To set the effective scope of the current Banner configuration, you need to set the effective employee range based on **Department** or **Role** dimensions. |
   

6. Click **Save as Draft** or **Save and Publish**.

   * **Save as Draft**: Only save the current configuration, but will not take effect immediately. You need to continue to the next step and turn on the effective status switch.

   * **Save and Publish**: Save the current configuration and take immediate effect.

7. (Optional) Turn on the effective switch.

   If your client Banner configuration effective switch is not turned on, or if **Save as draft** is selected when adding client Banner configuration, you need to turn on the corresponding configuration effective switch in the client Banner list.
