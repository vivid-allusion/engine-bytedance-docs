After setting up your guest Wi\-Fi network, you can customize the appearance of the authentication page to match your corporate branding, including the logo and background image.

<span id="8cf04259"></span>
# Procedure


1. Log in to the Admin Console.

2. In the left navigation bar, click **Branding**.

3. In the **Function Configuration** section, click the **Guest Network Access Page** card.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/54e775ec720645eabcb86c8b965ec30b~tplv-goo7wpa0wc-image.image) </span>

4. On the customization page, adjust the following settings. You can see a live preview of your changes on the right side of the screen.

   
   |**Configuration item** |**Description** |
   |---|---|
   |**Color scheme of the card (PC&H5)**  |Select **Default style** or **Dark style**. |
   |**Favicon (PC)**  |The favicon displayed on the browser tab. The default is the SealSuite logo. You can upload a custom image to replace it. |
   |**Tab title (PC)**  |The title displayed on the browser tab. The default is **Login**. You can customize this title. Click the **Multi\-language configuration** icon to set different titles for different languages. If a language's title is empty, the title in the **Default display** area applies. |
   |**Theme color (PC & H5)**  |The theme color of the login card. Select **Default**, **Green**, **Purple**, **Red**, **Orange**, or **Custom**. |
   |**Background (PC & H5)**  |The background of the SealSuite login page. Configuration options:<br><br><br>* **Color**: Select the default color or a custom color.<br><br>* **Image**: Upload a custom photo as the background image. Click the **Multi\-language configuration** icon to set different background images for different languages. If a language's background image is empty, the image in the **Default display** area applies. |
   |**Layout (PC)**  |Select the **Center** (default) or **Right** layout. |
   |**Logo (PC & H5)**  |The icon displayed on the SealSuite login page. The default is the SealSuite logo. You can upload a custom image to replace it. This setting supports multi\-language configuration. |
   |**Footer (PC)**  |Set to **Do not show** by default. Select **Display** to add footer information (such as your corporate website link or MIIT filing number) to the bottom of the PC page.<br><br><br>* The system provides sample footer content on the **Default language** tab. You can modify it as needed.<br><br>* Click **Add language** to configure footers for multiple languages. If a language's content is empty, the **Default language** content applies. |
   |**Promotion space (PC)**  |Set to **Do not show** by default. When the page layout is set to **Right**, select **Display** to add corporate promotional content to the left side of the login card:<br><br><br>* **Image**: Upload up to 10 images. Multiple images play in a carousel based on the automatic carousel interval (the default interval is 5 seconds). You can add hyperlinks to the images.<br><br>* **Text**: Use HTML to write styled welcome messages, promotional slogans, or notifications.<br><br>* **Image and text**: Display the image carousel and custom text simultaneously. |
   

5. Click **Save as Draft** or **Save and Publish**.

   * **Save as Draft**: Only save the current configuration, but it does not take effect immediately. You need to continue to the next step and turn on the effective status switch.

   * **Save and Publish**: Save the current configuration and take immediate effect.

6. (Optional) Turn on the effective switch.

   If guest Wi\-Fi authentication page configuration effective switch is not turned on, or if **Save as Draft** is selected when customizing the guest Wi\-Fi authentication page, you need to turn on the configuration effective switch in the **Guest Network Access Page** card on the **Branding** page.
