## Network diagnostics

If network access fails, the VPN connection fails, or messages cannot be received, go to **Labs** ＞ **Network diagnostics** in the client to check the network connection, DNS service, API reachability, and VPN service.

If an issue occurs, the check result describes the exception. For example, if the VPN network is abnormal, the system displays the **Unable to obtain the VPN node list** message. Users can follow the prompt to fix the issue or submit feedback with one click.

If an IT Administrator needs to view computer information, go to **Labs** ＞ **Local device information**, copy the device or network information on the details page, and send it to the IT Administrator.

If network diagnostics pass but the device network still has issues, click **Still having issues**, enter the inaccessible URL, and click **Submit feedback to Administrator**. The feedback information is then reported to the Admin Console. Users can contact the Administrator to view data in the Admin Console, or wait for the Administrator to resolve the issue.

## **DNS reset**

If DNS must be reset because of a network issue, go to **Labs** ＞ **DNS reset** to reset DNS manually or automatically.

* Select **Automatic reset**. The system automatically assigns an available DNS server address based on the local network environment.

* Select **Manual reset**. Manual reset supports two methods: ① directly enter a known DNS server address. Consult the enterprise IT Administrator if needed. ② If the Administrator has configured system\-recommended addresses, select a server with lower latency. Click **Retest** to test the latency of the system\-recommended server addresses.

## **Local device information**

If a network issue requires troubleshooting by an IT Administrator, the Administrator may ask for information about the Endpoint device. This page displays device information, network information, routing information, and VPN connection information. Click the copy icon on the information details page to copy information in that section.
