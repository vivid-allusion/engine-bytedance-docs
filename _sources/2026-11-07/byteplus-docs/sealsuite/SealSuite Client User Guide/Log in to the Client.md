# Account Login

<span id="6639b99b"></span>
## SealSuite Account Login

Open the SealSuite desktop client and click **Account Login**. Enter your phone number or email address, read and agree to the **User Agreement** and **Privacy Policy**, and click **Next** to obtain a verification code and log in.

If secondary authentication is enabled for the current account, you need to obtain a verification code or a dynamic password to log in after entering your password. When you log in for the first time, you need to set a password. ## QR Code Login

You can also log in to the desktop client by scanning a QR code with the mobile client. Open **Scan** in the SealSuite mobile client, scan the QR code on the PC login page, and tap **Allow Login** once the scan is successful.

## Third\-party Platform Authorization Login

SealSuite supports authorization login through third\-party platforms. The following example describes how to log in with **Lark**.

Read and agree to the **User Agreement** and **Privacy Policy**. Then, in **Or sign in with**, click the **Lark** icon. The browser automatically opens the Lark QR code login page. Use the Lark mobile app to scan the QR code, and then return to the application. You will be logged in automatically.

# Forgot Password

If you forget your password, you can contact the administrator for assistance in resetting it.

After the administrator resets the password, you can enter your phone number or email address again, and then enter the verification code. If secondary authentication is enabled for the current account, you will be prompted to set a new password before you can log in.

<span id="4110d8b3"></span>
# Reset Password

Go to the portal platform. In **Toolbox**, click **Security**. You can change your password on this page.

# Full Disk Access

Starting from v2.0.11, the SealSuite client supports pop\-up guidance for enabling Full Disk Access. On macOS 10.15 or later, after you log in, if the system detects that you are within the effective scope of any policy related to **baseline**, **application**, **process**, **anti\-uninstall**, **data loss prevention**, **endpoint antivirus**, or **peripheral control**, a pop\-up that cannot be closed appears. You must grant Full Disk Access before you can continue using related features.

<span id="b3ea3ba7"></span>
## Procedure


1. Open **Privacy & Security** \> **Privacy** \> **Full Disk Access**.

2. Select **corplink\-service** and **Corplink System Extension**.
