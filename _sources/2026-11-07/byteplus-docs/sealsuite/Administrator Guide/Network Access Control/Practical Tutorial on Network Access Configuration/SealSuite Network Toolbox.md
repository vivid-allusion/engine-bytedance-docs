SealSuite Network Toolbox generates switch configurations, deploys configurations or custom commands to test network devices, and tests RADIUS services. This document describes how to open the tool and use each feature.

> **Note**: Commands generated by the tool are for reference only. Before execution, verify the commands against the network device model, software version, and actual configuration. If an issue occurs due to model or version differences, contact the network device vendor first to troubleshoot the issue together.

## Download and open the tool

SealSuite Network Toolbox provides installation packages for macOS and Windows. On first use, download and extract the installation package for your operating system, then open the tool. After the tool opens, select a task to generate switch configurations, deploy configurations, issue custom commands, or test a RADIUS service.

### macOS

To use the tool on macOS, download and extract the following installation package. When you open the tool for the first time, Apple may display a prompt that it cannot check the software for malicious software. If this prompt appears, follow these steps to allow the tool in System Settings.

[Download feilian_toolbox_macos_20221202 (3).tar.gz](https://lf3-static.bytednsdoc.com/obj/eden-cn/809eh7uhkbd/feilian/toolbox-20261010/feilian_toolbox_macos_20221202%20%283%29.tar.gz)

1. Double\-click the installation package to extract it.

2. Double\-click `feilian_toolbox` to open it.

   If the message "feilian_toolbox cannot be opened because Apple cannot check it for malicious software" appears, go to **System Preferences** \> **Security & Privacy** \> **General** , then click **Open Anyway** .

3. Open the tool again.

### Windows

To use the tool on Windows, download the following ZIP installation package, decompress it, and then open the extracted tool. After this, select the feature that you need.

[Download feilian_toolbox_windows_20221202.zip](https://lf3-static.bytednsdoc.com/obj/eden-cn/809eh7uhkbd/feilian/toolbox-20261010/feilian_toolbox_windows_20221202.zip)

1. Download and decompress the installation package.

2. Open the extracted tool.

## Generate switch configurations

During the SealSuite POC phase, use the configuration generation feature to prepare SealSuite\-recommended Network Access Control (NAC) configurations for test switches. Configuration generation does not require an internet connection. After generation, copy the configurations to the clipboard, save them locally, or use automatic deployment to deploy them to devices.

Configuration generation supports the following device versions:

* Huawei unified mode.

* Huawei traditional mode.

* H3C v3, v5, and v7.

After you confirm that the switch type is within the supported scope above, follow these steps to generate Network Access Control (NAC) configurations.

1. Open the **Configuration Generation** page of the tool and select a switch type.

2. Enter key configuration information for the test environment.

3. Click **Generate** to view the generated configuration commands.

4. Based on your needs, **Copy to Clipboard** or **Save Locally** the configurations. To deploy them directly to a test device, continue with the next section.

## Deploy generated configurations

After generating the SealSuite\-recommended configurations, use automatic deployment to deploy the configurations to specified ports on specified devices. Then perform SealSuite Network Access Control (NAC) testing.

1. On the generated configuration page, click **Auto\-configure to Device** .

2. Enter the information required for deployment based on the target test device.

3. Click **Deploy** and view the configuration deployment result in the **Execution Result** area.

## Issue custom commands

To issue commands other than SealSuite\-recommended configurations, use custom commands to apply the required configurations to the corresponding device.

1. Open the **Custom Command Issuance** page and enter the commands to issue in the command input area.

2. Enter the information required to issue the commands based on the target device.

3. Click **Deploy** and view the command execution result in the **Execution Result** area.

## Test the RADIUS service

When troubleshooting Network Access Control (NAC) issues, use RADIUS service testing to help determine whether the current SealSuite RADIUS service has issues. The result provides a reference for identifying the source of the failure.

1. Open the **RADIUS Service Test** page.

2. Enter test information based on the RADIUS service to be tested.

3. Click **Test** to view the test result.
