SealSuite IT tools help employees troubleshoot network issues, get enterprise IT support, and view security alerts. After an administrator configures detection targets, servers, service links, or users or devices in scope in the Admin Console, employees can use the corresponding tools in the client. Select the features to configure based on your enterprise network environment and IT service plans.

|Tool |Purpose and scenarios |
|---|---|
|[DNS reset](https://docs.byteplus.com/docs/sealsuite/docs-k86j4knvfd) |Provides automatic reset, manual reset, and DNS optimization. Use it when DNS configurations are abnormal or when employees need to select an available DNS server. |
|[Network diagnostics](https://docs.byteplus.com/docs/sealsuite/docs-managing-network-diagnosis) |Checks network connectivity, proxies, VPNs, and URL access. Use it when employees cannot connect to the internet or access business websites and need self\-service troubleshooting. |
|[Network monitoring](https://docs.byteplus.com/docs/sealsuite/docs-configuring-network-monitoring) |Monitors network quality from devices to routers, VPNs, and applications. Use it to identify network quality issues based on packet loss rate and latency thresholds. |
|[Internet proxy](https://docs.byteplus.com/docs/sealsuite/configuring-internet-proxies) |Centrally configures proxy servers and excluded domains for employees to select in the client. Use it when your enterprise uses a specified proxy for network access. |
|[Expert service](https://docs.byteplus.com/docs/sealsuite/docs-configuring-expert-services-) |Displays enterprise\-specified service links in the client. Use it to connect employees to human support channels, such as IT on\-call groups or service desks. |
|[Alert center](https://docs.byteplus.com/configure-alert-center) |Controls client alert display by alert type and effective object. Use it to display file, desktop app, or peripheral blocking alerts to specified employees. |
|[Feedback](https://docs.byteplus.com/configure-feedback) |Provides a feedback entry point in the client for employees to submit issues, which administrators can view and handle in user feedback. |
