While using the SealSuite anti\-virus control module, if you encounter any issues or have questions, refer to the following frequently asked questions and its provided solution for assistance.

<span id="08829d9e"></span>
## Is the current antivirus engine of SealSuite self\-developed or OEM from other manufacturers?

The current antivirus engine of SealSuite is collaborating with Bitdeferer.

<span id="ed6ff26c"></span>
## Will the device still report virus events during this period when the network is restored, even if it detects virus events without internet connection?

After the network is restored, the event will be reported automatically.
