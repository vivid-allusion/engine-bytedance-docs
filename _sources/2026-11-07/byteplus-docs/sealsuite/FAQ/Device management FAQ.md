While using the SealSuite device management module, if you encounter any issues or have questions, refer to the following frequently asked questions and its provided solution for assistance.

<span id="93fe4011"></span>
## What information will the SealSuite client collect from the device?

You can log in to the SealSuite Admin Portal. In the **Device Assets** \> **Devices List**, click device name to view the detailed information.

<span id="50350f43"></span>
## What is the frequency of reporting software statistics?

The frequency of reporting data on the statistical page of the software is once per hour.

<span id="7b40e3de"></span>
## After uninstalling the software, reinstalling the system, and disconnecting the computer from SealSuite, will the relevant software data on the software statistics page be cleared?


* Uninstalling software: Report software information once an hour, and the Admin Portal will automatically clear uninstalled software.

* Reinstalling the system: Devices that have been reinstalled may be identified as new devices. If identified as new devices, the relevant software information will not be cleared.

* No network: If the computer is disconnected from the SealSuite network, it indicates that software information has not been uploaded, and the software data in this situation will not be cleared.


<span id="1ba8383c"></span>
## If the ex\-employee cancels the account but the computer device does not uninstall the SealSuite client, will the device list page still update the device?

Currently, device information is retained, and the configuration of device clearance rules is supported to clear device information.

<span id="6636fbdd"></span>
## After the device manually modifies the process name, the process cannot be detected. After the members change the sunflower process to ewan.exe, what should I do if the sunflower is not recognized as an illegal process?

For process name changes, you can use signature information to add rules.

<span id="97cd61ed"></span>
## Can the SealSuite detection lock screen password function detect password complexity?

No. SealSuite is unable to obtain the specific password of the members. SealSuite can only check if a password has been set.

<span id="bb2bfcf8"></span>
## Will device baseline checks and dynamic decisions still take effect after exiting the SealSuite program within the device?

The rule will still take effect, and exiting SealSuite will not affect the device baseline check and dynamic decision\-making.
