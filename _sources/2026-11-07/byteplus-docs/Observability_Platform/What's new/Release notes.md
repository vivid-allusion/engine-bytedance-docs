This topic describes the latest updates for the feature modules related to Observability Platform. New features will be rolled out across regions. We are looking forward to your hands\-on experience.

> **tip**

> The **Regions** column lists the regions where the feature change applies at the time of the release. The actual supported regions are subject to those displayed in the console. Supported regions vary by module. **All** indicates all regions where the current module is available.
