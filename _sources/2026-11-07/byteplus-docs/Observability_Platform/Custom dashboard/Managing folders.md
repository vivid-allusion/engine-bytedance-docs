This topic describes folder lifecycle management operations.


1. Log in to the[ Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard), and in the left navigation bar, select **Custom Dashboard**.

2. On the dashboard management page, switch to **Folder view** to manage the folders you have created.



|Action |Descriptions |
|---|---|
|Create a folder |Create a folder with a custom name to manage dashboards. |
|Delete a folder |Delete the folders that you no longer use.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Folders in which dashboards exist cannot be deleted. Move or delete the dashboards and try again.</div><br> |
