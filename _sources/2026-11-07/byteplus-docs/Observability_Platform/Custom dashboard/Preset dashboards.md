Observability Platform provides preset dashboards for specific scenarios, delivering out\-of\-the\-box observability capabilities. This topic describes how to use preset dashboards.

<span id="4XIJqli2"></span>
## Limits

Preset dashboards are associated with cloud products. You can view the preset dashboards related to a cloud product only after you activate the corresponding cloud product.

<span id="slEZcE5i"></span>
## Procedure


1. Log in to the[ Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard), and in the left navigation bar, select **Custom Dashboard**.

2. Click the **Preset dashboard** tab to go to the preset dashboard management page. Click the target preset dashboard to view its details.

   
   |Serial number |Action |Description |
   |---|---|---|
   |1 |List view |The display view of the preset dashboard list. Options: tile view and folder view. |
   |2 |Show favorites |Quick filter. If it is selected, only favorite preset dashboards are displayed. |
   |3 |Search dashboard |Enter the name of the preset dashboard to search. |
   |4 |View dashboard |Click the name of the target preset dashboard to view the preset charts and metric details of the dashboard. |
   


<span id="UH3FrLMY"></span>
## What to do next


* You can perform the following operation on preset dashboards:

   
   |Action |Description |
   |---|---|
   |Favorite |Click the star icon next to a preset dashboard name to mark the preset dashboard as a favorite. This allows you to quickly filter commonly used preset dashboards. |
   

* On the dashboard details page, you can perform the following basic operations:

   
   |Action |Description |
   |---|---|
   |Export |Export the dashboard configuration file in "Observability JSON" or "Grafana JSON" format. |
   |Select a data source |Filter the data sources for the dashboard, such as region, resource list, and workspace. |
   |Configure the data time range |Configure the time range for filtering dashboard data. Both relative and absolute time ranges are supported. |
   |Configure a refresh method |You can refresh the dashboard manually or automatically. Automatic refresh supports multiple preset intervals, such as refreshing every 1 minute or every 5 minutes. |
   |Filter chart data |Click the legend at the bottom of the chart to filter data sources in the chart.<br><br><br>* Click the name of a specific data source to display or hide the graph of the data source in the chart.<br><br>* Click the icon next to the name of a specific data source <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_121d43c534f90353b5ddce79208da3c6.png) </span>to display only the graph of the data source and hide the graphs of all other data sources. |
