JSON Model displays the current dashboard configuration in the form of a JSON script. This topic describes how to use JSON Model.

<span id="idP8beM0"></span>
### View and edit


1. Log in to the [Observability Platform ](https://console.byteplus.com/observe/dashboard/dashboard)console, and in the left navigation bar, select **Custom Dashboard**.

2. On the dashboard management page, click the name of the target dashboard to go to the dashboard details page.

3. Click the ** Edit ** button, then click **Settings**, and select the **JSON Model ** tab. You can then view and edit the JSON configuration of the current dashboard.

4. After editing the JSON script, click the **Apply JSON Model** button. The system validates the JSON script syntax and changes to the current dashboard after validation passes.
