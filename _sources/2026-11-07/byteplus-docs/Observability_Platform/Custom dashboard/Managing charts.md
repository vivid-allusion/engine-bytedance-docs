This topic describes chart lifecycle management and other supported operations.

1. Log in to the [Observability Platform ](https://console.byteplus.com/observe/dashboard/dashboard)console, and in the left navigation bar, select **Custom Dashboard**.

2. On the dashboard management page, click the name of the target dashboard.

3. Click the ** edit** button in the upper\-right corner of the dashboard to manage charts you have created.

|Actions |Description |
|---|---|
|Add chart |Add one or multiple charts based on your needs. Currently, various chart types are available, including time series chart, metric card, table, pie chart, and bar chart. Five data sources are supported: Server\-side Monitoring \- server side, VMP, Cloud Monitor, TLS, and Metrics. |
|Zoom in |Expand a selected chart to view it in full\-screen mode. |
|Edit chart |Modify the configuration details of an existing chart, including[ chart settings](https://docs.byteplus.com/en/docs/Observability_Platform/Chart_settings), [data query](https://docs.byteplus.com/en/docs/Observability_Platform/Data_query), and [data transformation](https://docs.byteplus.com/en/docs/Observability_Platform/Data_conversion). |
|Copy chart |Copy the current chart and its configuration to quickly create a new one. |
|Inspect |View the query statement and Panel JSON configuration of the specified chart to help troubleshoot data issues or reuse the configuration. |
|Compare |For time series charts, compare current data with data from 1 day ago, 3 days ago, 7 days ago, or a custom period. This helps with data comparison. |
|Delete chart |Delete charts that are no longer needed.<br><br>> **warning**<br><br><br>> Deleted charts and all related configurations cannot be restored. Proceed with caution.<br> |
