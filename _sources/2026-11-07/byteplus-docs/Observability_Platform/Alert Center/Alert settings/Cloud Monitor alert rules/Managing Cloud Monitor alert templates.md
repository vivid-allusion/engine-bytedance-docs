This topic describes the operations that you can perform on Cloud Monitor alert templates.

<span id="GRFbUbPO"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the Alert Configuration page.

3. In the alert configuration section on the left, select **Cloud Monitor** and click the **Alert template** tab.

4. Click a button in the "Actions" column that corresponds to the target Cloud Monitor alert template to perform the corresponding operation. The currently supported management operations are as follows:

   
   |Actions |Description |
   |---|---|
   |Apply to object group |Apply an alert template to an object group. Alert rules will be generated based on this template for resource monitoring. For instructions, see [Applying alert templates to object groups](https://docs.byteplus.com/en/docs/Observability_Platform/Applying_alert_templates_to_object_groups). |
   |Edit |Modify the configuration of an existing Cloud Monitor alert template. For detailed descriptions of parameters, see [Creating Cloud Monitor alert templates](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_Cloud_Monitor_alert_templates). |
   |Delete |Delete Cloud Monitor alert templates that are no longer needed.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><br>* <div data-tips="true" data-tips-type="warning">Deleting a Cloud Monitor alert template will also delete the alert rules associated with the template.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">Deleted Cloud Monitor alert templates cannot be recovered. Proceed with caution.</div><br> |
