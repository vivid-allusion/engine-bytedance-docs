This topic describes various operations supported by Cloud Monitor alert rules.

<span id="iksAdTrD"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the "Alert Configuration" page.

3. In the alert configuration section on the left, select **Cloud Monitor** and click the **Alert Rule** tab.

4. Click a button in the "Actions" column that corresponds to the target Cloud Monitor alert rule to perform the corresponding operation. The currently supported management operations are as follows:

   
   |Actions |Description |
   |---|---|
   |Edit |Modify the configuration of an existing Cloud Monitor alert rule. For detailed descriptions of parameters, see [Creating Cloud Monitor alert rules](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_Cloud_Monitor_alert_rules).<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">For alert rules that are associated with alert templates, they will automatically adopt changes made to the associated templates, and you cannot modify their configurations.</div><br> |
   |Unbind |Disassociate the current Cloud Monitor alert rule from the alert template.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><br>* <div data-tips="true" data-tips-type="warning">After disassociating the alert rule from the alert template, you can edit the alert rule again, but updates to the alert template will no longer be synchronized to the alert rule.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">If only one alert rule is generated by the object group and alert template, disassociating the alert rule from the alert template will also disassociate the object group from the alert template.</div><br> |
   |Enable/Disable |The switch for detecting monitoring metric data, which can be manually enabled or disabled based on actual scenarios.<br><br><br>* **Enable**: You can re\-enable a rule that is in the "Disabled" state. After a rule is re\-enabled, it will continue monitoring and delivering Cloud Monitor alerts based on the configured effective period, delivery channel, and other conditions.<br><br>* **Disable**: You can disable a rule that is in the "Enabled" state. After a rule is disabled, it will no longer take effect and will not deliver Cloud Monitor alerts. |
   |Delete |Delete a Cloud Monitor alert rule that is no longer needed.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><br>* <div data-tips="true" data-tips-type="warning">Deleted Cloud Monitor alert rules cannot be recovered. Proceed with caution.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">To delete an alert rule that is associated with an alert template, disassociate it from the template first and then delete the rule.</div><br><br><br>* <div data-tips="true" data-tips-type="warning">Alert rules created from preset alert templates are automatically deleted when the templates are disabled. You cannot manually delete these alert rules.</div><br> |
