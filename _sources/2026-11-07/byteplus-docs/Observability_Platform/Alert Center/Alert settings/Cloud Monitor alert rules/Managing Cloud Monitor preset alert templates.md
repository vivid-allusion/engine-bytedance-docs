This topic describes the operations that you can perform on Cloud Monitor preset alert templates.

<span id="PrmBlyMe"></span>
## Modify notification policy configuration

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">You can modify notification policies for enabled preset alert templates.</div>



1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the Alert Configuration page.

3. In the alert configuration section on the left, select **Cloud Monitor** and click the **Preset alert template** tab.

4. Click **Configure notification policy** in the Actions column that corresponds to the target preset alert template. Change the notification policy in the pop\-up dialog box and then click **Confirm**.


<span id="zmAE9WbO"></span>
## Disable a preset alert template

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">After you disable a preset alert template, alert rules created based on this template will be synchronously deleted.</div>



1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the Alert Configuration page.

3. In the alert configuration section on the left, select **Cloud Monitor** and click the **Preset alert template** tab.

4. In the Actions column that corresponds to the target preset alert template, click the<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d334eedc2fc4a10d568b2633b904fbd4.png) </span>icon to disable the preset alert template and delete associated resources.
