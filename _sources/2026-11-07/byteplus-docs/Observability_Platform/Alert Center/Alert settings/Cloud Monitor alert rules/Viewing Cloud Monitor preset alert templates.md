Cloud Monitor provides preset alert rule templates for common cloud products, allowing you to configure alert rules quickly. This topic describes how to view preset alert templates.

<span id="sH0BczKI"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the Alert Configuration page.

3. In the alert configuration section on the left, select **Cloud Monitor** and click the **Preset alert template** tab.

4. On the Preset alert template tab, you can view all system\-preset alert templates and search by resource type or name.

5. Click the name of the target preset alert template to view its detailed information, including basic information such as the alert level, notification cycle, and notification aggregation policy, as well as alert configurations for specified cloud services, such as the trigger conditions and associated alert rules.
