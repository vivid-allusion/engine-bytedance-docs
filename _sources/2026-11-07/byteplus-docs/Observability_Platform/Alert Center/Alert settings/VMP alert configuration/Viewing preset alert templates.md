VMP provides preset alert rule templates for common cloud products, allowing you to configure alert rules quickly. This topic describes how to view preset alert templates.

<span id="b8d4zvp7"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click ** Alert Center \> Alert Configuration** to go to the Alert Configuration management page.

3. In the Alert Configuration section on the left, select **VMP ** and click the **Preset alert template ** tab.

4. On the Preset alert template tab, you can view all system\-preset alert templates and search by region, template category, or name.

5. Click the name of the target template to view the basic information, variable information, and alert rules of the template.
