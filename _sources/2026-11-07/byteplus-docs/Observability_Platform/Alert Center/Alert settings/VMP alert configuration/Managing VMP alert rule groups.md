This topic describes the operations that you can perform on VMP alert rule groups.

<span id="ftxJ36zW"></span>
## View an alert rule group


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard).

2. In the left navigation pane, click **Alert Center \> Alert Configuration ** to go to the Alert Configuration management page.

3. In the Alert Configuration section on the left, select ** VMP** and click the **Alert rule group**. You can then view the list of alert rule groups and key information.

4. Click the name of the target alert rule group to go to its details page. On this page, you can view the basic information, the list of associated alert rules, and the details of each rule.


<span id="zOZhjzKr"></span>
## Edit an alert rule group

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">After you edit the alert rule group, the status of existing alert events in the group changes to <strong>Manually resolved</strong>.</div>



1. Log in to the [Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard).

2. In the left navigation pane, click **Alert Center \> Alert Configuration** to go to the Alert Configuration management page.

3. In the Alert Configuration section on the left, select **VMP ** and click the ** Alert rule group ** tab.

4. Click **Edit** in the "Actions" column to the right of the target alert rule group. You can modify the configuration of the alert rule group and its associated alert rules.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">For detailed descriptions of parameters, see <a href="https://docs.byteplus.com/en/docs/Observability_Platform/Creating_VMP_alert_rule_groups">Creating VMP alert rule groups</a>.   </div>

## Delete an alert rule group

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">Deleted alert rule groups cannot be recovered. Proceed with caution.</div>


* <div data-tips="true" data-tips-type="warning">When you delete an alert rule group, its associated alert rules are also deleted.</div>


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard).

2. In the left navigation pane, click ** Alert Center \> Alert Configuration** to go to the Alert Configuration management page.

3. In the Alert Configuration section on the left, select **VMP** and click the ** Alert rule group tab**.

4. Click **Delete** in the "Actions" column to the right of the target alert rule group to delete the alert rule group that you no longer need.
