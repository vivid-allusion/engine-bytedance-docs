Server\-side Monitoring has preset common alert rule templates to facilitate rapid configuration of alert rules. This topic describes how to view preset alert templates.

<span id="T62FGGQM"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, select **Alert Center \-\> Alert settings** to open the "Alert settings" page.

3. In the alert configuration section on the left, select **Server\-side Monitoring**, and go to the **Preset alert template** tab.

4. On the preset alert template tab, you can view all system\-preset alert templates and search by region or name.

5. Click the target template name to view the template's basic information, alert rules, and application scope.
