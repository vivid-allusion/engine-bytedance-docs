This topic describes the various operations supported for Server\-side Monitoring alert rules.

<span id="XeBq2Kbd"></span>
## Enable/disable alert rules


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert settings** to open the "Alert settings" page.

3. In the alert configuration section on the left, select **Server\-side Monitoring** and go to the **Alert rule** tab.

4. Click the toggle switch in the **Status** column to enable or disable the target alert rule.

   * **Enable**: Enable a rule. Once enabled, the rule resumes monitoring according to the configured conditions.

   * **Disable**: Disable a rule. Once disabled, the rule will no longer take effect.

## Managing alerting rules


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe).

2. In the left navigation pane, click **Alert Center \> Alert settings** to open the "Alert settings" page.

3. In the alert configuration section on the left, select **Server\-side Monitoring** and go to the **Alert rule** tab.

4. Click the button in the "Actions" column for the target Server\-side Monitoring alert rule to perform the corresponding action. The currently supported management operations are as follows:

   
   |Actions |Description |
   |---|---|
   |Alert history |View the alert records and detailed information triggered by the current alert rule. For more detailed information, see [Viewing Server-side Monitoring alert events](https://docs.byteplus.com/en/docs/Observability_Platform/Alert_event). |
   |Notification history |View the notification message records and detailed information triggered by the current alert rule. For more detailed information, see [Viewing Server-side Monitoring notification history](https://docs.byteplus.com/en/docs/Observability_Platform/Notification_history). |
   |Edit |Modify the configuration of an existing Server\-side Monitoring alert rule. For detailed configuration descriptions, see [Creating Server-side Monitoring alert rules](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_Server-side_Monitoring_alert_rules). |
   |Copy |Quickly create a new alert task based on an existing one. After clicking the copy button, you will be redirected to the create alert task page with the existing configuration preserved. You can modify the configuration and save it as a new alert task. |
   |Delete |Delete Server\-side Monitoring alert rules that are no longer needed.<br><br><div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div><br><br><br><div data-tips="true" data-tips-type="warning">Deleted Server\-side Monitoring alert rules cannot be recovered. Proceed with caution.</div><br> |
