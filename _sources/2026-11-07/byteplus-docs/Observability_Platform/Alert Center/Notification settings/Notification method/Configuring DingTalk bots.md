This topic describes how to configure a DingTalk bot.

<span id="EpQNTLAE"></span>
## Procedure


1. Log in to DingTalk, and create or find a group that needs to receive alerts. Click the group settings icon in the upper\-right corner of the group<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f53ca395ce9b85f8353fdcb05a479a96.png) </span>。

2. In the settings pop\-up window, select **Bot**.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_eed458b4955f401c6bcf55f1aace830d.png) </span>

3. In the **Bot Management** window, click **Add bot**.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_2eaa7d913a5a72747cacb628f4086551.png) </span>

4. In the bot list, click **Custom**.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_79174b3b86aaadc1fbb3f8851d7f21a3.png) </span>

5. Click **Add** to configure the custom bot.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_4993b0a503c1e4e41f8a166d7b57e59e.png) </span>

6. Configure the relevant information for the bot, select the terms of service, and then click **Finished**.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The "Additional Signature" option in "Security Setting" corresponds to the DingTalk Secret in the alert settings. If "Additional Signature" is selected here, the DingTalk Secret must be provided when you configure the callback URL for the DingTalk channel. If "Additional Signature" is not selected here, the DingTalk Secret is not required when you configure the callback URL for the DingTalk channel.   </div>
   

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_84e75af3316d10e1be0686baf01c6fdb.png) </span>

7. Copy the **webhook address** generated by the DingTalk bot, which will be used in the subsequent configuration.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e7c96e8a0df874a0f373a9f89e1dd4c6.png) </span>

8. Click **Finished** to add the DingTalk bot.


<span id="2yZ3DmYZ"></span>
## What to do next

After a DingTalk bot is configured, you can use the callback URL and Secret obtained from the bot to add a DingTalk channel in the callback URL configuration. For information about how to create a callback URL, see [Callback URLs](https://docs.byteplus.com/en/docs/Observability_Platform/Callback_URL).
