This topic describes how to configure a Feishu application bot.

<span id="JX77kc3p"></span>
## Prerequisites

Enterprise administrators and employees have been granted permission to use the "BytePlus Observability Alerting" Feishu application bot. For more information, see [Feishu user authentication and authorization](https://docs.byteplus.com/en/docs/Observability_Platform/Feishu_user_authentication_and_authorization).

<div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="0">tip</div>


<div data-tips="true" data-tips-type="default" data-wrapper-indent="0">The permission to use the "BytePlus Observability Alerting" application only needs to be obtained or requested once and remains permanently valid.</div>


<span id="lCxnUTGj"></span>
## Procedure


1. Log in to Feishu, and create or find a group that needs to receive alerts. Click the `...` icon in the upper right corner of the group, and click **Settings** on the drop\-down menu.

2. In the "Settings" pop\-up window, select **Bots**, and click **Add Bot**.

3. In the bot list, select **BytePlus Observability Alerting** and click **Add** to add the bot to the Feishu group.


<span id="80BpcP0Z"></span>
## What to do next

After the Feishu application bot is configured, you can use the group with the "BytePlus Observability Alerting Bot" added to configure the Feishu application bot channel. For information about how to create a callback URL, see [Callback URL](https://docs.byteplus.com/en/docs/Observability_Platform/Callback_URL).
