A notification policy defines the recipients, delivery channels, and content display format for alert notifications when alerts of different levels are triggered or resolved. This topic describes how to create an alert notification policy.

<span id="UWsymFel"></span>
## Prerequisites


* You have selected an appropriate notification method based on the actual scenario. Supported notification methods vary by cloud service. For more details, see the descriptions of notification methods in [Alert Center overview](https://docs.byteplus.com/en/docs/Observability_Platform/Alert_Center_overview).

* Create notification objects based on the selected notification method, such as contacts, contact groups, callback addresses, and on\-call schedules. For more information, see [Notification objects](https://docs.byteplus.com/en/docs/Observability_Platform/Notification_objects) and [Creating on-call schedules](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_on-call_schedules).

* Create a notification template based on the selected notification method, such as notification templates for phone calls, email, Feishu bot, DingTalk, and a general callback address. For more details, see [Creating notification templates](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_notification_templates).


<span id="Kkj4I1nv"></span>
## Limits


* You can create up to 1,000 notification policies.

* You can add up to 10 contacts, 10 contact groups, 10 on\-call schedules, and 10 webhook URLs for each notification policy.

* You can add up to 10 orchestration plans, 10 message queues, and 10 log services.


<span id="M4DLoC5c"></span>
## Procedure


1. Log in to the [Observability Platform console](https://console.byteplus.com/observe/dashboard/dashboard).

2. In the left navigation pane, select "**Alert Center \-\> Notification configuration**" to go to the "Notification configuration" page.

3. Select the **Notification Policy** tab, click **Create notification policy**, and configure the notification policy parameters as needed.

## What to do next


* You can use the created notification policies for each product in alert tasks or alert policies. When an alert is triggered, notification messages are sent to the contacts in the display style specified by the notification policy. For configuration examples of alert tasks or alert rules, see [Creating Cloud Monitor alert rules](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_Cloud_Monitor_alert_rules), [Creating cloud service event rules](https://docs.byteplus.com/en/docs/Observability_Platform/Creating_cloud_service_event_rules), and [Creating Server-side Monitoring alert tasks](https://docs.byteplus.com/en/docs/apmplus/Alert_tasks).

* For the management operations supported for notification policies, see [Managing notification policies](https://docs.byteplus.com/en/docs/Observability_Platform/Managing_notification_policies).
