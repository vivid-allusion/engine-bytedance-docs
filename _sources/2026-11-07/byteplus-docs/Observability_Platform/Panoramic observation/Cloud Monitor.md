Cloud Monitor service offers an all\-in\-one cloud monitoring and alerting solution. It collects and visualizes the status of your various cloud resources, helping you gain comprehensive insight into resource health conditions. For example, resource utilization, key metric performance data, and running status. The service promptly detects exceptions and sends alert notifications to ensure smooth business operations and improve O&M efficiency. For detailed descriptions and guides, see [Cloud Monitor usage guide](https://docs.byteplus.com/en/docs/cloudmonitor/What-is-Vitality-Cloud-Monitor).
