Server\-side Monitoring is an end\-to\-end backend monitoring service for server\-side applications. It provides capabilities ranging from monitoring basic resource performance to service and code\-level monitoring, and to online application health monitoring. For detailed descriptions and guides, see [Usage guide for Server-side Monitoring](https://docs.byteplus.com/en/docs/apmplus/What_is_server_monitoring).
