If a custom expert agent no longer meets your requirements, you can delete it to release resources. This topic describes how to delete an expert agent.

## Limits

Official agents preset by the system cannot be deleted.

## Procedure

> **warning**

* > When an expert agent is deleted, automated tasks associated with this agent will not run as expected.

* > Deleted expert agents cannot be recovered. Proceed with caution.

1. Log in to the [Intelligent O&M platform](https://console.byteplus.com/observe/devops).

2. In the left navigation pane, select **Expert Agent**.

3. Click **View details** in the target expert agent card.

4. On the expert agent details page, click "**Delete**" in the upper\-right corner. Confirm the deletion in the dialog box and click "**Delete**" to delete the agent.
