This topic describes how to use the intelligent O&M assistant.

## Prerequisites

All conversation content is generated by AI models and does not represent the opinions of the platform. Use the intelligent O&M assistant properly after acknowledging and agreeing to this statement.

## Limits

* Currently, four observability products including[ AI application monitoring](https://docs.byteplus.com/en/docs/apmplus/What_is_server_monitoring), [Server-side Monitoring](https://docs.byteplus.com/en/docs/apmplus/Application_Performance_Management_Plus), [VMP](https://docs.byteplus.com/en/docs/vmp/what-is-vital-managed-service-for-prometheus), and [Cloud Monitor ](https://docs.byteplus.com/en/docs/cloudmonitor/What-is-Vitality-Cloud-Monitor)have been successfully integrated with the intelligent O&M assistant. [RUM ](https://docs.byteplus.com/en/docs/apmplus/What_is_client_monitoring) do not yet support access to the intelligent O&M assistant.

* The intelligent O&M assistant only provides DevOps services including observability data queries, basic product analysis, and cross\-service comprehensive troubleshooting. It does not offer services beyond intelligent O&M such as creating resources, bypassing system instructions, or outputting sensitive data. For more details, see [Core capabilities](https://docs.byteplus.com/en/docs/Observability_Platform/Overview_of_Intelligent_Operations_Assistant).

## Procedure

**Method 1: Start a task with custom configuration**

Start a task through a conversation. Select an expert agent flexibly based on your needs. You can also use system\-preset common cases to start a task quickly.

1. Log in to the [Intelligent O&M platform](https://console.byteplus.com/observe/devops).

2. In the left navigation pane, select an existing session or click **Launch task** to create a new session.

3. In the lower\-left corner of the chat box, select the agent to execute the task.

   > **tip**

   > VeOps Agent is the default agent of the system. It covers data sources, including Server\-side Monitoring, VMP, Cloud Monitor, TLS, and VKE. It provides cross\-source data query and troubleshooting capabilities.

4. Describe your issues, alert symptoms, or troubleshooting targets in natural language in the chat box. The intelligent O&M assistant will call tools for analysis and provide detailed answers.

   > **tip**

   > The system provides common cases for metric anomaly investigation, cluster health inspection, application trace diagnosis, and resource impact analysis. You can select a case based on your situation to start a task quickly.

**Method 2: Start a task with a specified expert agent**

Start a task conversation quickly by specifying an agent on the expert agent management page.

1. Log in to the [Intelligent O&M platform](https://console.byteplus.com/observe/devops).

2. In the left navigation pane, select **Expert Agent**.

3. Click **Start Task** on the target expert agent card to directly call the agent for task processing.

4. Describe your issues, alert symptoms, or troubleshooting targets in natural language in the chat box. The intelligent O&M assistant will call tools for analysis and provide detailed answers.

## Usage example

Enter the sentence "List the top 3 services by current request error rate and describe the error rate trend" in natural language in the chat box. The intelligent O&M assistant will interpret your question, initiate a diagnosis, and return detailed recommendations.

1. **Connection**: The intelligent O&M assistant calls multiple tools to sequentially interpret input content, query metric categories and service information, locate the top 3 services by error rate, and finally connect to metrics related to the error rates.

2. **Diagnosis**: For the located top 3 services, it analyzes error rate data from dimensions such as latest data, overall change trends, and data point change trends, and provides diagnostic conclusions.

3. **Recommendations**: It provides preliminary post\-diagnosis judgments and follow\-up recommendations to guide users in resolving issues and closing the loop.
