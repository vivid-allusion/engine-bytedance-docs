This topic describes the operations supported for automated tasks.

## Procedure

1. Log in to the [Intelligent O&M platform](https://console.byteplus.com/observe/devops).

2. In the left navigation pane, select **Automation**.

3. Click an action button in the "Actions" column on the right of the target automated task to perform the corresponding action.

   |Actions |Description |
   |---|---|
   |Enable/Disable |Enable or disable the automated task.<br><br><br>* **Enable**: The automated task enters a listening state. The task is triggered automatically and executed according to the prompt when the scheduled time arrives.<br><br>* **Disable**: The automated task is not triggered even when the scheduled time arrives. |
   |Execute Now |Manually trigger the task once. |
   |Details |Display detailed information about the automated task, including task configuration, execution history, and details. Click **Enter Conversation** in the "Actions" column to the right of an execution history entry to view the details of this conversation. |
   |Edit |Modify the configuration of the current automated task. For parameter configuration description, refer to [Creating automated tasks](https://docs.byteplus.com/en/docs/observability/Configuring_automated_tasks). |
   |Delete |Delete the automated task if you no longer need it.<br><br>> **warning**<br><br><br>> Deleted automated tasks cannot be recovered. Proceed with caution.<br> |
