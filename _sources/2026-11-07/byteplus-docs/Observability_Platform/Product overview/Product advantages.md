Observability Platform aggregates multiple independent services and general modules to provide you with an easy\-to\-use observability access and query portal. This topic describes the advantages of Observability Platform in detail.

<span id="K34AzgAd"></span>
## Centralized user experience

A single console is created to deliver a seamless observability experience, which aggregates scattered observability tools into a complete service matrix to form a one\-stop solution. It consolidates a wide range of observability services—covering infrastructure monitoring, application performance tracing, and front\-end user experience analysis—into a single, unified portal. This achieves full\-stack data profiling and analysis without the need to repeatedly switch between multiple tabs and systems.


* Reduced cognitive load: A unified interface prevents users from frequently switching platforms, which reduces operational complexity and learning costs. This significantly reduces the difficulty of getting started with the service for new users and the mental burden for experienced users.

* Improved collaboration efficiency: Teams no longer need to manage multiple contact and permission lists across different platforms. A single configuration applies to all members, which greatly enhances collaboration among operation and maintenance, development, and business teams.

* Consistent operations: A complete troubleshooting or performance analysis process can be seamlessly carried out in a single system, which prevents information gaps and interruptions in thought caused by system switching.


<span id="uGDqLS3n"></span>
## Enhanced ease of use

With unified service and help documentation entry points, users can quickly find the required features and information, which significantly improves efficiency in troubleshooting and system monitoring.


* Quick issue resolution: When a fault occurs, engineers can use clear navigation and integrated documentation to quickly locate analysis tools and configuration methods, which minimizes service downtime.

* Unified knowledge transfer: Consistent terminology and operation logic ensure accurate knowledge transfer within teams and reduce misconfigurations and communication costs caused by misinterpretations.


<span id="XdIzwz5E"></span>
## Centralized management of general features

General modules, such as alerting and dashboards, are managed in a centralized manner, which provides users with a consistent configuration and usage experience. This facilitates users in performing data analysis and monitoring across services.


* Economies of scale: After users know the configuration methods for alerts or dashboards, they can reuse the methods in multiple scenarios, such as infrastructure monitoring and application performance management.

* Simplified operation and maintenance management: Administrators can manage alerting policies, permissions, and dashboard directories for all monitored objects in a centralized manner, which achieves standard operation and maintenance.

* Strengthened correlation analysis: Unified custom dashboards support easy correlation, queries, and visualization of data from different data sources, which provide unprecedented convenience for root cause identification. For example, associate and query APM trace data and Prometheus system metrics for root cause analysis.
