Observability Platform functions as a centralized observability solution for cloud\-native environments. It aims to aggregate cloud\-native observability services and build a complete observability ecosystem that systematically displays all observability services. This simplifies user operations, enhances user experience, and improves integration among services. Observability Platform provides you with an easy\-to\-use portal for observability access and query. It achieves this by aggregating a series of services, such as AI application monitoring, Server\-side Monitoring, VMP, Cloud Monitor, RUM, and CloudDetect, and integrating general modules, such as custom dashboards, Alert Center, and Integration Center.
