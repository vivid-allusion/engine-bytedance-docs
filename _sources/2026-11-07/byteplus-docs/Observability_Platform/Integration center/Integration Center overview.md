Integration Center is the unified integration entry point provided by Observability Platform for observability data ingestion. It supports rapid integration of server\-side applications, client\-side applications, logs, and components such as custom monitors, middleware, and AI into Observability Platform for data collection. Integration Center also centralizes data source discovery, integration configuration, collection tasks, probe management, preset content, and integration health status. This reduces the configuration overhead caused by fragmented integration workflows across products such as VMP and Server\-side Monitoring.

<span id="ATvfDazM"></span>
## Core features

Integration Center is built around the workflow of "discover, configure, collect, manage, and validate." It provides data source integration capabilities and consolidates the fragmented integration entry points, collection configurations, and probe management spread across different products into a single location.


|Feature |Description |
|---|---|
|[Integration marketplace](https://docs.byteplus.com/en/docs/Observability_Platform/Integration_marketplace) |Provides integration templates for various applications, services, and components and supports one\-click deployment and flexible scaling by following the provided instructions. |
|[Integration management](https://docs.byteplus.com/en/docs/Observability_Platform/Integration_management) |Manages integration tasks throughout their lifecycle. |
|[Probe management](https://docs.byteplus.com/en/docs/Observability_Platform/Probe_management) |Centrally manages collection components, such as host probes, cluster probes, and managed probes, to ensure stable, reliable, and trustworthy observability data collection from large\-scale distributed systems. |

## Procedure


1. **Create an integration task**: Integrate applications or components from BytePlus or third\-party cloud providers into Observability Platform for data collection. For an integration example, see [Integrating server-side applications in VKE](https://docs.byteplus.com/en/docs/Observability_Platform/Integrating_server-side_applications_in_VKE).

2. **Analyze observability data**: Leverage the observability capabilities provided by [VMP](https://docs.byteplus.com/en/docs/vmp/what-is-vital-managed-service-for-prometheus) and [Server-side Monitoring](https://docs.byteplus.com/en/docs/apmplus/Application_Performance_Management_Plus) to analyze and process data, improving the efficiency of troubleshooting and resolving issues.
