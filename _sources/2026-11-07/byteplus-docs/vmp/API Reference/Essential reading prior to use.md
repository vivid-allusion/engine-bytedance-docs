This topic lists important considerations that you should know before you call VMP APIs.

<span id=".5pGY6KaB"></span>
## Summary

VMP is a next\-generation cloud\-native monitoring engine that fully inherits from and is compatible with the open\-source ecosystem, providing zero\-maintenance and high\-availability capabilities.

<span id=".6LCD55So6K-05piO"></span>
## API calling instructions

VMP supports API calls over HTTPS. See [Calling methods](https://docs.byteplus.com/en/docs/vmp/Request-structure) for details.

<span id=".5L2_55So6ZmQ5Yi2"></span>
## Limits 

Ensure the following requirements have been met before getting started:


* Complete the preparations, including registering a BytePlus console account, completing enterprise real\-name verification, and adding funds to your account.

* Ensure the account balance is not less than 100 yuan (which can include vouchers, but not just vouchers), so that the Pay\-as\-you\-go resources can be created.

* Log in to the [VMP console](https://console.byteplus.com/observe/prometheus) and enable VMP for your account.


<span id=".6LS555So6K-05piO"></span>
## Tips on billing

When you call the APIs to create workspace resources, fees vary based on the workspace type that you select. For details, see [Billing Overview](https://docs.byteplus.com/en/docs/vmp/billing-overview).
