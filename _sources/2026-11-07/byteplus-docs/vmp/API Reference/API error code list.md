This topic describes how to query information about all error codes that may be returned when you call VMP APIs.

<span id="s8SYJMad"></span>
## Error code type

The platform supports the following two error code types.

<span id="22pVvTCm"></span>
### Common error codes of the platform

CodeN starts with `1000`. Please refer to [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes) for details.

<span id="PrM4HcIZ"></span>
### Product error codes

Error codes specific to a cloud product include public error codes of the cloud product and API\-specific error codes. 

The HTTP status codes include `4xx` and `5xx`. See [OpenAPI Center](https://api.volcengine.com/api-docs/view/errorcode?serviceCode=vmp&version=2021-03-03) for details.

To the right of "Error code", click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_65183e460835e9b275060a725a2d4df0.png) </span> button to query information.
