rdma\-device\-plugin serves as a Remote Direct Memory Access (RDMA) device add\-on of the Vital Kubernetes Engine (VKE) cluster. rdma\-device\-plugin manages RDMA network interface controllers (NICs) and enables Pod containers to use RDMA devices. This topic describes the common metrics of rdma\-device\-plugin in the VKE cluster.

Vital Managed Service for Prometheus (VMP) classifies the metrics reported by VKE clusters into the following types: **basic metrics**, **other metrics**, and **custom metrics**. Billing methods vary based on different metric types.
