katalyst serves as a resource management add\-on of the Vital Kubernetes Engine (VKE) cluster. It provides fine\-grained resource management capabilities, such as the reporting of RDMA topologies and core binding in NUMA\-aware scheduling. This topic describes the common query metrics in katalyst.

Vital Managed Service for Prometheus (VMP) classifies the metrics reported by VKE clusters into the following types: **basic metrics**, **other metrics**, and **custom metrics**. Billing methods vary based on different metric types.
