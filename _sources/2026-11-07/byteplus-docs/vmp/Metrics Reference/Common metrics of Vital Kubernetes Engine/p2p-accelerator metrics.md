p2p\-accelerator serves as a P2P container image acceleration add\-on of the Vital Kubernetes Engine (VKE) cluster. It accelerates the massive concurrent pulling of container images based on the P2P technology. This topic describes the common query metrics of p2p\-accelerator.

Vital Managed Service for Prometheus (VMP) classifies the metrics reported by VKE clusters into the following types: **basic metrics**, **other metrics**, and **custom metrics**. Billing methods vary based on different metric types.
