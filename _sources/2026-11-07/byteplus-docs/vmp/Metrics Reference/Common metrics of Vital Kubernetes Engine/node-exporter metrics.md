Provided by Prometheus, node\-exporter is mainly used to collect information and running metrics of Linux\-type nodes, such as the CPU, memory, load, file system, and network of the host. This topic describes the common metrics of node\-exporter in the Vital Kubernetes Engine (VKE) cluster.

Vital Managed Service for Prometheus (VMP) classifies the metrics reported by VKE clusters into the following types: **basic metrics**, **other metrics**, and **custom metrics**. Billing methods vary based on different metric types.
