The package can be deemed as a prepaid pay\-as\-you\-go payment method for the Vital Managed Service for Prometheus Standard Edition workspace, and supports the deduction of fees generated by the paid metrics in the Standard Edition workspace. This article introduces the types and specifications of the package.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">You can purchase resource packages to offset fees for standard workspaces billed by reported metric volume. The resource package to apply to a workspace must have the same duration as the storage retention period of the workspace.</div>


<span id=".6K6h6LS56aG5"></span>
## Billing Items

The package deducts according to the **Reported Metric Volume**. Here, the reported metric volume refers to the total volume of collected and reported metric data, that is, the total number of collected and reported samples. A sample data contains the metric name, label set, sampling timestamp, and value. For more details on Prometheus data formats, please refer to [Prometheus Time Series Format](https://docs.byteplus.com/en/docs/vmp/Format-of-Prometheus-time-series-data).

## Package Types

The package for the Vital Managed Service for Prometheus can be used to deduct the fees generated by the paid metrics in the workspace. That is, from the date of purchase, within the validity period, the paid metrics written into the Vital Managed Service for Prometheus workspace will directly deduct from the package without additional payment.

The Vital Managed Service for Prometheus product package specifications correspond with the workspace storage days one by one.

## Deduction Description


* Resource packages apply to cost offsetting only for the current  within the same region. Cross\-account or cross\-service offsetting is not supported.

* The package applies to the fees deduction for the workspaces in the same region with the same storage duration. For example: When you purchase a 15\-day specification package, all the workspaces with a storage duration of 15 days in the same region can deduct resources from this package.

* The package applies to a prepaid payment model, and is only used to deduct the fees generated after you purchase the package. For the fees generated before you purchase the package still adopts a pay\-as\-you\-go payment method.

* The package deducts once per hour. After the package is fully deducted or expires, any excess usage will be automatically billed according to the pay\-as\-you\-go method. For more details, please refer to [Pay-as-you-go](https://docs.byteplus.com/en/docs/vmp/pay-as-you-go).

* The package has a valid period and only supports deductions within the validity period. Any unused resources after expiration will be automatically voided and cannot be carried over to the next cycle. For detailed description and examples of package validity period, please refer to [Package Validity Period](https://docs.byteplus.com/en/docs/vmp/Resource-package-overview#.6LWE5rqQ5YyF5pyJ5pWI5pyf). You can select to renew the pacakge before the package expires. For details please refer to [Renew Package](https://docs.byteplus.com/en/docs/vmp/Renewing-a-resource-package). 

* When using packages to deduct usage, the actual usage and the deduction usage are not exactly the same and depend on the **Deduction Coefficient**. The deduction usage calculation formula is `Actual usage ✖️ deduction coefficient = deduction usage`. The system will deduct the corresponding metric amount from the package based on the calculated deduction usage. For example: When the actual usage is 10,000 and the deduction coefficient is 0.7, the actual metric deduction from the package is 7,000. You can view the deduction coefficient of the specific package in [Cost Center > Package Management](https://console.byteplus.com/finance/resource-package).

## Package Validity Period


* The validity period of the package is one month, and the package can only be deducted within the validity period. The package will be automatically voided after expiration. The validity period of the package will be default till 23:59:59 on the same date of the next month. If the target month does not have this date, then the default will be 23:59:59 of the last day of the target month.

* You can select to renew the package before it expires to extend the validity period of the package. 


The examples of the validity period of the package after purchasing and renewing are as follows.


|Purchase Duration |Purchase Duration |Effective time |Due Time |
|---|---|---|---|
|10:00:00, May 20, 2023 |one month |10:00:00, May 20, 2023 |23:59:59, June 20, 2023 |
|00:00:00, May 20, 2023 |one month |00:00:00, May 20, 2023 |23:59:59, June 19, 2023 |
|10:00:00, May 31, 2023 |one month |10:00:00, May 31, 2023 |23:59:59, June 30, 2023 |
