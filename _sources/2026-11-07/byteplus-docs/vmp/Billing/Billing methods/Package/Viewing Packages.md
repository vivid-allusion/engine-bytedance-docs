This article introduces how to view the used time and used resources of the package.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

You have purchased the package. For details, please refer to [Purchase Package](https://docs.byteplus.com/en/docs/vmp/Purchasing-a-resource-package).

<span id=".5pON5L2c5q2l6aqk"></span>
## Operation Procedures


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. In the top navigation bar, select the target region.

3. Click **Usage Guide** in the left navigation bar, then the used time and used resources of the package can be viewed on the right side of the interface.

4. Click **More package details** on the package card to view package details. You can manage package auto\-renewals or cancel a package.



|Actions |Description |
|---|---|
|Turn off Automatic renewal |For purchased packages, you can enable or disable automatic renewal as needed. |
|unsubscribe |Unused packages can be unconditionally cancelled and refunded. Once cancelled, they cannot be restored. |
