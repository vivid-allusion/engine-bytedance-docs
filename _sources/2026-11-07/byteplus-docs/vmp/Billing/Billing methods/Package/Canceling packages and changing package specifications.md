## Cancellation

Unused resource packages qualify for unconditional cancellation and refund. Used resource packages are not eligible for cancellation and refund. 

You can cancel a package subscription by using one of the following methods:


<Tabs>
<Tab zoneid="KG7t0eBBL3" title="Using the VMP console">
<TabTitle>Using the VMP console</TabTitle>

1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. In the top navigation bar, select the target region.

3. In the left navigation bar, click **Instructions for use**. On the page that appears, click **More package details** on the right package card.

4. Click **unsubscribe** in the Actions column on the right side of the row for the package to be unsubscribed. In the confirmation dialog box, click **OK**.


</Tab>
<Tab zoneid="wVokFTl3fU" title="Using the Billing center">
<TabTitle>Using the Billing center</TabTitle>

1. Log in to [Billing center](https://console.byteplus.com/finance/account-overview/).

2. In the left menu bar, click **Cancellation**. On the page that appears, click the **Unsubscription (7\-day no reason)**  or **Regular unsubscription** tab, and find the package to cancelled.

3. According to the actual situation, you can cancel the order instance or execute batch cancellation of instances.

   * **Cancel Order Instance**: Select the instance to be canceled, click **Operation** column's **Cancel**, to enter the cancellation information confirmation page. View the refundable amount of the instance to be canceled, check the pre\-cancellation confirmation prompt (if any), and then click **Confirm Cancellation**.

   * **Batch Cancellation**: check multiple instances to be canceled in the cancellation list, click **Batch Cancellation** at the bottom left of the list to enter the cancellation information confirmation page. View the refundable amount of the instance to be canceled, check the pre\-cancellation confirmation prompt (if any), and then click **Confirm Cancellation**.

4. The cancellation request is successful. Click the order to go to the canceled order detail page.


</Tab>
</Tabs>

## Configuration Change Description

The package currently does not support configuration change. If needed, you can cancel the renewal, and select packages of other specifications after the due time.
