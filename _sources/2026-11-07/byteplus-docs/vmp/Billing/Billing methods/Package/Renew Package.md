The package supports both automatic renewal and manual renewal. This article introduces how to renew the package.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

The package has been purchased. For details, please refer to [Purchase Package](https://docs.byteplus.com/en/docs/vmp/Purchasing-a-resource-package).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Considerations

If you have renewed the package, the system will automatically purchase the package at the beginning of the next period.

<span id=".6Ieq5Yqo57ut6K6i"></span>
## Automatic Renewal

You can manage automatic renewal by using one of the following methods:


<Tabs>
<Tab zoneid="HtrOzD9UY3" title="Using the VMP console">
<TabTitle>Using the VMP console</TabTitle>

* When purchasing a package, you can enable automatic renewal of the package. For details, see [Purchasing packages](https://docs.byteplus.com/en/docs/vmp/Purchasing-a-resource-package).

* For a purchased package, you can enable or disable automatic renewal on the details page of the package. For details, see [Viewing packages](https://docs.byteplus.com/en/docs/vmp/Viewing-resource-packages).


</Tab>
<Tab zoneid="EQQP9ImXOf" title="Using the Billing center">
<TabTitle>Using the Billing center</TabTitle>

For a purchased package, you can enable or disable automatic renewal in the [Billing center console](https://console.byteplus.com/finance/renew). 


</Tab>
</Tabs>


<span id=".5omL5Yqo57ut6K6i"></span>
## Manual Renewal


1. Log in to [VMP console](https://console.byteplus.com/observe/prometheus).

2. In the top navigation bar, select the target region.

3. Click **Usage Guide** on the left navigation bar to renew the package on the interface.

   * Packages with **Renewal** turned on at purchase are shown as **Automatic Renewal** and do not require manual renewal.

   * For packages without **Renewal** turned on at purchase, click **Renew** to go to the **Cost Center** for renewal. 


<span id=".5Y-W5raI57ut6K6i"></span>
## Cancel Renewal

You can disable automatic renewal of packages by using one of the following methods:


<Tabs>
<Tab zoneid="gZjUXNQnyV" title="Using the VMP console">
<TabTitle>Using the VMP console</TabTitle>

On the details page of a package, disable automatic renewal. For details see [Viewing packages](https://docs.byteplus.com/en/docs/vmp/Viewing-resource-packages).


</Tab>
<Tab zoneid="rFRavzbSFU" title="Using the Billing center">
<TabTitle>Using the Billing center</TabTitle>

You can disable automatic renewal of a package in the [Billing center Console](https://console.byteplus.com/finance/renew). 


</Tab>
</Tabs>
