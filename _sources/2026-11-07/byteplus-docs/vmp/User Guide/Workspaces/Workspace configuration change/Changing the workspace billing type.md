After a VMP workspace is created, you can change its billing type once. This topic describes how to change the billing type of a workspace.

<span id="03LJqzGd"></span>
## Limits

The billing type of a workspace can be changed only once.

<span id="UYGWedne"></span>
## Prerequisites

A workspace has been created. For details, see [Create common workspaces](https://docs.byteplus.com/en/docs/vmp/Creating-workspaces).

<span id="aelWS7dA"></span>
## Procedure


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus). 

2. In the left navigation pane, click **Workspace** to enter the workspace management page.

3. Click the name of the target workspace to open the workspace details page. Then go to the "Configuration information" section.

4. Click the edit icon to the right of the existing billing type, change the billing type as needed, and click **Confirm**.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">After you change the billing type, the new billing method takes effect immediately. This change is irreversible, so proceed with caution.</div>
