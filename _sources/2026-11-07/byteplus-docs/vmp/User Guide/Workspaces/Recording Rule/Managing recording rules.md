After you create a recording rule, you can view, export, edit, or delete the created recording rule on the recording rule management page based on your business requirements. This topic describes how to manage recording rules.

<span id=".5p-l55yLIFJlY29yZGluZyBSdWxl"></span>
## View a recording rule


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. Click **Workspace** on the left navigation bar and click the **name** of the target workspace in the list to go to the Overview page of the workspace.

3. Click **Recording Rule Management** on the left navigation bar. In the rule file list, click the  **+**  icon before the rule whose details you want to view.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_eb2151cc3b7d54f50fb2c1e0322bb077.png) </span>


<span id=".5a-85Ye6IFJlY29yZGluZyBSdWxl"></span>
## Export a recording rule


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. Click **Workspace** on the left navigation bar and click the **name** of the target workspace in the list to go to the Overview page of the workspace.

3. Click **Recording Rule Management** on the left navigation bar. In the rule file list, find the rule file that you want to export and click **Export** in the **Actions** column to export the YAML file of the rule.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_aaa890d951b091a47369403fb8f1e8bd.png) </span>


<span id=".57yW6L6RIFJlY29yZGluZyBSdWxl"></span>
## Edit a recording rule


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. Click **Workspace** on the left navigation bar and click the **name** of the target workspace in the list to go to the Overview page of the workspace.

3. Click **Recording Rule Management** on the left navigation bar. In the rule file list, find the rule file that you want to edit and click **Edit** in the **Actions** column to modify the rules of the rule file.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_aac83302a980cb3c44acd5d5340518de.png) </span>


<span id=".5Yig6ZmkIFJlY29yZGluZyBSdWxl"></span>
## Delete a recording rule

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">A recording rule cannot be restored after deletion. Proceed with caution.</div>



1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. Click **Workspace** on the left navigation bar and click the **name** of the target workspace in the list to go to the Overview page of the workspace.

3. Click **Recording Rule Management** on the left navigation bar. In the rule file list, find the rule file that you want to delete and click **Delete** in the **Actions** column.

4. In the confirmation dialog box that appears, click **Delete** to delete the rule.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_45add8bf970ff55673e3ea8d58071365.png) </span>
