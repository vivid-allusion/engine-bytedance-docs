You can edit and delete alerting rule groups based on your business requirements. This topic describes how to manage alerting rule groups.

<span id=".57yW6L6R5ZGK6K2m6KeE5YiZ57uE"></span>
## Edit an alerting rule group

You can edit a created alerting rule group. To do so, perform the steps below:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, choose **Alert center \> Alerting rule**. Click the **Alerting rule group** tab. In the alerting rule groups list, find the target group and click **Edit** in the Actions column.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After you edit the alerting rule group, the status of the original alerts in the group will change to <strong>Manually resolved</strong>.   </div>
   

<span id=".5Yig6Zmk5ZGK6K2m6KeE5YiZ57uE"></span>
## Delete an alerting rule group

You can delete a created alerting rule group. To do so, perform the steps below:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, choose **Alert center \> Alerting rule**. Click the **Alerting rule group** tab. In the alerting rule group list, find the alerting rule group that you want to delete and click **Delete** in the **Actions** column.

4. In the message that appears, click OK to delete the alerting rule group.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After you delete the alerting rule group, the status of the alerts in the group will change to <strong>Disabled</strong>.   </div>
   

<span id=".57yW6L6R5ZGK6K2m6KeE5YiZ"></span>
## Edit an alerting rule

After you configure an alerting rule group, you can edit a created alerting rule. To do so, perform the steps below:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the left navigation bar, choose **Alert center \> Alerting rule**. Click the **Single alerting rule** tab. In the list of alerting rules, find the alerting rule that you want to edit, and click **Edit** in the **Actions** column to edit the alerting rule.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">After you edit the alerting rule, the status of the original alerts in this rule will change to <strong>Manually resolved</strong>.   </div>
   

<span id=".5ZCv55SoL-emgeeUqOWRiuitpuinhOWImQ=="></span>
## Enable or disable an alerting rule

After you configure an alerting rule group, you can disable or enable a single alerting rule in the group. To do so, perform the steps below:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, choose **Alert center \> Alerting rule**. Click the **Single alerting rule** tab. In the list of alerting rules, find the alerting rule that you want to enable or disable, and turn on or off the Enable/Disable switch in the **Actions** column to enable or disable the alerting rule.
