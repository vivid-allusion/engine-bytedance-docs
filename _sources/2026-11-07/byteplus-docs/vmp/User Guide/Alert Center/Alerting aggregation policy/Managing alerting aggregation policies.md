You can edit or delete alert aggregation policies based on your business requirements. This topic describes how to manage alert aggregation policies.

<span id=".57yW6L6R5ZGK6K2m6IGa5ZCI562W55Wl"></span>
## Edit an alert aggregation policy

You can edit a created alert aggregation policy. You can perform the following steps to edit a policy:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Alerting aggregation policy**. In the alert aggregation policy list, find the policy you want to edit and click **Edit** in the **Actions** column to edit the alert aggregation policy.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_52423b76c9dce721ed5b346864ae7e0f.png) </span>

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You cannot edit and delete the default alert aggregation policy named default of the system.</div>


<span id=".5Yig6Zmk5ZGK6K2m6IGa5ZCI562W55Wl"></span>
## Delete an alert aggregation policy

You can delete a created alert aggregation policy. You can perform the following steps to delete a policy:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Alerting aggregation policy**. In the alert aggregation policy list, find the policy you want to delete and click **Delete** in the **Actions** column to delete the alert aggregation policy.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">If an alert rule is associated with the alert aggregation policy, the system will prompt a deletion failure when you attempt to delete the alert aggregation policy. You need to first disassociate the alert rule from the alert aggregation policy. In this way, you can delete the alert aggregation policy.</div>


* <div data-tips="true" data-tips-type="tip">You cannot edit and delete the default alert aggregation policy named default of the system.</div>
