After you create a notification template, you can view, edit, or delete the template. This topic describes how to manage notification templates.

<span id=".5p-l55yL6YCa55-l5raI5oGv5qih5p2_"></span>
## View a notification template

You can view the details of a created notification template, including basic information and associated notification policies. You can perform the following steps to view the details:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Notification template**. In the template list, find the target template and click the template name to view the template.

   * Click the **Basic information** tab to view the basic information and configuration details of the template.

      <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b228b8e532af14491b2e3bdfedf29c33.png) </span>

   * Click the **Associated notification policy** tab to view the notification policies associated with the template.

      <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_4e98a0a260993e84b65a268e6bb5be58.png) </span>


<span id=".57yW6L6R6YCa55-l5raI5oGv5qih5p2_"></span>
## Edit a notification template

You can edit a created notification template. You can perform the following steps to edit a template:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Notification template**. In the template list, find the target template and click **Edit** in the **Actions** column to edit the template content.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d4336a9145956f13c5f5fb0edd695615.png) </span>

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When you edit the template, you can modify only the name, description, and configuration details of the template, but you cannot modify the template type.</div>


<span id=".5Yig6Zmk6YCa55-l5raI5oGv5qih5p2_"></span>
## Delete a notification template

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">You can delete a notification template even if it is associated with an alert notification policy. After the template is deleted, the alert notification policy will use the system default notification template to send alert notifications.</div>


You can delete a created notification template. You can perform the following steps to delete a template:


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Notification template**. In the template list, find the target template and click **Delete** in the **Actions** column.

4. Click OK in the message that appears to delete the template.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_3174104872d03595a28f0d8f8e79bc5c.png) </span>
