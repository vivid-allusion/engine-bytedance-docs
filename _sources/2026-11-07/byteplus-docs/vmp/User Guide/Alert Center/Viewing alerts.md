After you configure an alert rule, the system will generate a corresponding alert if the monitored resource reaches a threshold specified in the rule. This topic describes how to view alerts.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* A BytePlus root user has been created, and the VMP service has been activated.

* An alert rule is created. For more details, refer to [Creating an alert rule](https://docs.byteplus.com/en/docs/vmp/Creating-alerting-rules).


<span id=".5p-l55yL5ZGK6K2m5YiX6KGo"></span>
## View the alert list


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. On the left navigation bar, click **Alert center \> Alerting event**. On the **Alerting event** page, you can view the list of alerts that are being triggered.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_10b51e981d63bca5c87fbc91a21870ac.png) </span>

<span id=".5p-l55yL5ZGK6K2m6K-m5oOF"></span>
## View alert details

In the alert list, click the target alert ID to view its details.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_144a9ea532f70be77e88d5ea56745bc5.png) </span>

<span id=".5YW25LuW5pON5L2c"></span>
## Other operations

In the alert list, you can also perform the following operations:


* Click a rule name in the **Alerting Rule** column in the alert list to view the rule associated with the corresponding alert.

* Hover over a number in the **Alert resources** column to view the resource associated with the corresponding alert.
