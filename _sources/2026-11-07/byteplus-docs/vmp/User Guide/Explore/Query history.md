The query history refers to a list of query statements that you have used in Explore. You can quickly find commonly used query statements by using the query history. This topic describes how to use the query history feature.


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. Click **Explore** on the left navigation bar to go to the Explore page.

4. Select a workspace for which you want to query data from the Workspace list in the upper right corner of the Explore page. Click **Metric search** to go to the metric search page.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9d203e7b2db4bd7bce184fa2d40ed9ea.png) </span>

5. Click the **Historical query** tab.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_48994bd426a1b03f6c50573eedbb9fe0.png) </span>

6. In the historical query statement list, click the desired PromQL statement to add it to the query dialog box, then click **Query** to query the relevant metrics.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_41619a8dd35b253562685dd9e170e960.png) </span>
