VMP allows you to create independent workspaces under different projects, enabling unified management of multi‑project resources. Resources and billing of each workspace are isolated from each other. Project management is a group\-based resource management method provided by the platform. It allows you to categorize resources by business or project and configure IAM permissions at the project level to maintain resource independence and data security.

<span id="2p1x7mk2"></span>
## **Considerations**


* A workspace can belong to only one project, but multiple workspaces can be created under one project.

* The only resource type that supports project management in VMP is the workspace.

* If you need to assign independent management permissions for different workspaces, you can achieve decentralized access control by using IAM policies to limit the resource scope on which the permissions take effect.


<span id="LRNGv3HL"></span>
## **Project management procedure**


1. Create a project: Used for managing VMP workspace by project.

2. [Create a workspace](https://docs.byteplus.com/en/docs/vmp/Creating-workspaces): Create a workspace under the target project.

3. [Configure project-level permissions](https://docs.byteplus.com/en/docs/vmp/Configuring_project-level_permissions?lang=en): Grant operation permissions to IAM users on the workspace under the specified project.

4. [View bills by project](https://docs.byteplus.com/en/docs/byteplus-platform/docs-bill-details): Filter and view resource bills by project.


<span id="2FzQujA3"></span>
## View project resource information

You can view the project to which the current workspace belongs on the **Overview** page of the workspace.
