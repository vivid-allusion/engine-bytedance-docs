The built\-in monitoring dashboard of Vital Managed Service for Prometheus (VMP) supports configuring items such as data sources, query time ranges, and refresh methods. This topic describes the basic usage of the built\-in dashboard.

<span id=".6YCJ5oup5pWw5o2u5rqQ"></span>
## Select a data source

When you use the dashboard, you need to select a VMP workspace, which is the correct data source.


1. Log in to the [VMP console](https://console.byteplus.com/observe/prometheus).

2. On the top navigation bar, select the target region.

3. Click **Monitor dashboard** on the left navigation bar to go to the Monitor dashboard page.

4. Select a workspace from the **Workspace** list in the upper right corner of the **Monitor dashboard** page.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_08f34cce88f08c3735f86510d3185cbf.png) </span>

<span id=".6YWN572u5pWw5o2u5pe26Ze05q61"></span>
## Configure a data time range

In the upper right corner of the **Monitor dashboard** page, configure the time range of the dashboard. You can use predefined time ranges, such as the last 30 minutes, the last 1 hour, the last 6 hours, and the last 24 hours.

Click **Select time** to specify custom start and end time for query.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_af354ae961df6869a663171030b67630.png) </span>

<span id=".6YWN572u5Yi35paw5pa55byP"></span>
## Configure a refresh method

The dashboard supports manual or automatic refresh. You can select a built\-in interval at which the dashboard is automatically refreshed such as 1 minute and 5 minutes. In the upper right corner of the **Monitor dashboard** page, specify a refresh method of the dashboard.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_6ea5115a2a350fb6ed98755cfda660af.png) </span>
