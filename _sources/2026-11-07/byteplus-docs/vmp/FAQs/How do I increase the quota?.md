When using Vital Managed Service for Prometheus, if the ResourceQuota exceeds the limit, prompts such as **ExceededQuota** will appear on the page. At this time, if you need to increase the quota, please apply for a quota increase following the operation procedure in this article.

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">For the quota description of various resources of Vital Managed Service for Prometheus, please refer to <a href="https://docs.byteplus.com/en/docs/vmp/Limits">Usage Limit</a>.</div>


<span id="Wb3naZUC"></span>
## Operation Procedure


1. Log in to the [Quota Center](https://console.byteplus.com/quota/productList).

2. On the **Product List** page, search for **Vital Managed Service for Prometheus**, and click **Vital Managed Service for Prometheus**.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_b92069c1c3b4670ad5cf0ebe130d2ed5.png) </span>

3. On the quota page, view the quota parameters relevant to Vital Managed Service for Prometheus. You can submit a quota increase application for resources that support quota increase according to the actual situation.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_515ae94b39d9b708bc115d062d4bbe03.png) </span>
