As a built\-in data query language of Prometheus, Prometheus Query Language (PromQL) can be used to query, aggregate, and perform logical operations on time series data. PromQL is widely used in the daily application scenarios of Prometheus, including data query, visualization, and alert handling. PromQL is also prevalent in monitoring systems built around Prometheus, where it filters data stored in databases. In actual application scenarios, PromQL is indispensable in Grafana dashboard configuration, recording rule configuration, and alerting and monitoring configuration. PromQL has the following characteristics:


* Multidimensional query: PromQL supports multidimensional queries, which enable you to organize and filter your metric data by using multiple labels. This makes data analytics more flexible and fine\-grained.

* Built\-in functions: PromQL offers many built\-in functions, such as sum, average, and count, which can be used to easily process and aggregate metric data.

* Visualization: PromQL can easily generate visual charts, which makes data analytics more intuitive and comprehensible.
