This topic describes the SDK language versions provided by Vital Managed Service for Prometheus (VMP) and lists the addresses to obtain the latest SDK versions.

<span id="sKzFR3aF"></span>
## SDK introduction

VMP SDKs encapsulate the APIs of the 2021\-03\-03 version, use the access key to identify the caller, and provide features such as automatic signing, which helps you create and manage resources by using the APIs.

<span id="OvLrO4dC"></span>
## SDK list

The following table lists the SDKs supported by VMP. You can view the SDK update history, obtain installation packages, and view user guides in the GitHub repository.
