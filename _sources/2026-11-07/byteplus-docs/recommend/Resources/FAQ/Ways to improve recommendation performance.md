# How do UserEvent.rec_info and UserEvent.traffic_source affect recommendation performance?

UserEvent.rec_info and UserEvent.traffic_source are additional UserEvent data fields that provide information about the recommendation results generated by BytePlus Recommend. When BytePlus Recommend produces a recommendation result, it is associated with a UserEvent. You can provide information for UserEvent.rec_info and UserEvent.traffic_source to improve future performance.


|**Data field** |**Description** |**Data input** |
|---|---|---|
|UserEvent.rec_info |This field is used to track the BytePlus Recommend strategy and model used to produce that particular recommendation. |You can pass PredictResult.ResponseProduct.rec_info to UserEvent.rec_info for the corresponding UserEvent. |
|UserEvent.traffic_source |This field indicates where the recommendation is coming from. |At minimum, you should fill in this field for impression and click events. |


<span id="How does AckServerImpressions API affect recommendation performance?"></span>
# How does AckServerImpressions API affect recommendation performance?

Accurate impression information helps with model performance. However, since you might have custom post\-processing filters in place, our recommendation results may not accurately reflect the list of products that your server has returned to the end\-users. The AckServerImpressions API informs BytePlus Recommend of the actual recommendations shown to the users, which can help to improve model logic and performance.

**EXAMPLE**

The Predict API returns a list of items [1, 2, 3, 4]. Custom filters have excluded product_3 because it has been sold out and then inserted product_10 in front of product_2 based on a promotion rule. The AckServerImpressionsRequest will look like the following:

```JSON
[
  {id:1, altered_reason: "kept", rank:1},
  {id:10, altered_reason: "inserted", rank:2},
  {id:2, altered_reason: "kept", rank:3},
  {id:4, altered_reason: "kept", rank:4},
  {id:3, altered_reason: "filtered", rank:0},
].

```


<span id="How does data recency affect recommendation performance?"></span>
# How does data recency affect recommendation performance?

Recency of UserEvent and Product data may greatly impact model performance.

Our recommendation system is capable of using real\-time UserEvent and Product data to update our model to provide better recommendations. Therefore, if data is sent to us via WriteAPIs, it will be fed into the model after 10 seconds and reflected to the next recommendation call. For the greatest real\-time model accuracy, we recommend sending real\-time data updates using WriteAPIs.
