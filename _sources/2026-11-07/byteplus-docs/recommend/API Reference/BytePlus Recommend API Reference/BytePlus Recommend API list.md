This topic lists all APIs provided by BytePlus Recommend and provides all related topic links.

# Retail/E\-commerce industry—SaaS


|**API** |**Description** |
|---|---|
|[WriteUsers](https://docs.byteplus.com/recommend/reference/retail_saas_writeusers) |Call WriteUsers to upload new user data or update the current user data in the Retail/E\-commerce industry for the SaaS platform. |
|[WriteProducts](https://docs.byteplus.com/recommend/reference/retail_saas_writeproducts) |Call WriteProducts to upload new product data or update the current product data in the Retail/E\-commerce industry for the SaaS platform. |
|[WriteUserEvents](https://docs.byteplus.com/recommend/reference/retail_saas_writeuserevents) |Call WriteUserEvents to upload real\-time UserEvent data in the Retail/E\-commerce industry for the SaaS platform. |
|[Predict](https://docs.byteplus.com/recommend/reference/retail_saas_predict) |Call Predict to update and rank the Retail/E\-commerce industry product list for the SaaS platform. |
|[AckServerImpressions](https://docs.byteplus.com/recommend/reference/retail_saas_ackserverimpressions) |Call AckServerImpressions to modify the actual product list shown to the users based on their preferences in the Retail/E\-commerce industry for the SaaS platform. |
