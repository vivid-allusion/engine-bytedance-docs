There are several reasons leading to imported data errors. You can refer to the following list for more information and how to resolve them before proceeding to re\-import your **Trial** or **Live Mode** data.

For more information on re\-importing data, refer to the following:


* [Trial Mode data](https://docs.byteplus.com/recommend/docs/re_importing_content_industry_trial_mode_data).

* [Live Mode data](https://docs.byteplus.com/recommend/docs/re_importing_content_industry_live_mode_data).
