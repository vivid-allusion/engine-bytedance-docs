The API Integration Dashboard offers comprehensive instructions for integrating the WriteUsers API for data upload to BytePlus Recommend. It also provides guidance on integrating the Predict API and Ackserverimpression API to obtain recommendation predictions and server impressions for your applications. The page includes essential parameters and sample code in popular programming languages such as Golang, Python, and Java, facilitating seamless integration and implementation.

Users can leverage this dashboard to experiment with the sample codes, customize the parameters, and obtain responses, facilitating a seamless testing and integration experience.

For more information on the BytePlus Recommend APIs, refer [here](https://docs.byteplus.com/recommend/reference/getting_started_with_byteplus_recommend_apis).

# Accessing the API Integration dashboard

Access the API Integration dashboard for comprehensive instructions, parameters, and sample codes to seamlessly integrate and leverage the functionalities of BytePlus Recommend APIs.

**To access the API Integration dashboard:** 


1. Sign in to [BytePlus Recommend](https://console.byteplus.com/recommend/home).

   The Recommendation Projects screen appears.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/d6919d0-RecommendProjects.png) </span>

2. Click on the project you want to access.

3. Click **Integration**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/893ce976c0da40278a8864cba444c784~tplv-goo7wpa0wc-image.image) </span>

   The API Integration dashboard appears.

    &nbsp;

# API Integration dashboard features

The API Integration dashboard has a few features that you can use.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d8d2035afd8a4d5faf423a5d5501e40a~tplv-goo7wpa0wc-image.image) </span>


|**Number** |**Feature** |**Description** |
|---|---|---|
|1 |Body Params |The Body Params feature in the API Integration dashboard allows you to specify the necessary parameters and data to be included in the request body when making API calls. It provides a convenient way to customize and control the input data for your API requests. |
|2 |Sample Request |The Sample Request feature provides you with preconfigured code snippets or examples that demonstrate how to structure and format your API requests. It serves as a helpful reference for understanding the correct syntax and usage of the API endpoints.<br><br>You can choose between the different languages or copy the code directly into your own system to test it out. |
|3 |Response |The Response feature displays the output or response received from the API after making a request. It provides insights into the data format, structure, and any relevant information returned by the API endpoint. Analyzing the response helps you interpret the results and extract the desired information for further processing. |
|4 |Request History |The Request History feature logs and stores the history of your API requests made through the integration dashboard. It allows you to review and track the details of past requests, including the request parameters, response status, and timestamps. This feature helps you keep a record of your API interactions and facilitates troubleshooting or auditing activities if needed. |

# Calling sample API requests

You can use the API Integration dashboard to start requests for each of our BytePlus Recommend APIs. The dashboard has sample values included in the parameters and you can modify them to whatever value you prefer.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The greyed\-out parameters cannot be modified.</div>


**To call a sample API request:** 


1. Sign in to [BytePlus Recommend](https://console.byteplus.com/recommend/home).

   The Recommendation Projects screen appears.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/doc-center/d6919d0-RecommendProjects.png) </span>

2. Click on the project you want to access.

3. Click **Integration**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/893ce976c0da40278a8864cba444c784~tplv-goo7wpa0wc-image.image) </span>

   The API Integration dashboard appears.

4. Navigate to the sample API request you want to call.

5. Modify the parameter values if necessary.

6. In the Response section, toggle the **Mock** button on.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/790837e063ec44308ea88061e1095bfc~tplv-goo7wpa0wc-image.image) </span>

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The Mock button allows you to choose between the different statuses, generating different sample responses for each request. If you want to send a real request to the server, toggle the <strong>Mock</strong> button off.   </div>
   

7. Click **Try it out**.

   The request is called and the response appears.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef22345c7fbf4ebe8e3227c11dcdb425~tplv-goo7wpa0wc-image.image) </span>

   **Mock button off:**
