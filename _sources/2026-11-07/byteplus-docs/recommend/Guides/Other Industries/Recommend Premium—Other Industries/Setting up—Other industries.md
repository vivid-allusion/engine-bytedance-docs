There are three main steps that users have to complete during the setup phase:


* Filling in the questionnaire

* Filling in the data requirement sheet

* Obtaining API or SDK credentials


<span id="Filling in the questionnaire"></span>
# Filling in the questionnaire

The BytePlus Recommend team has prepared a customized questionnaire to better understand the needs of our users and their businesses. Through this questionnaire, the BytePlus Recommend team gain deeper insight into the following:


* Current recommendation system and performance

* Requirement for BytePlus Recommendation

* A/B testing capability

* Deployment preference


<span id="Filling in the data requirement sheet"></span>
# Filling in the data requirement sheet

The BytePlus Recommend team has prepared this sheet to get a deeper look into our client's data availability and whether it fits into our data schema. It consists of the following:


* User, Product, and UserEvent data schema and description

* Data validation criteria


<span id="Obtaining API or SDK credentials"></span>
# Obtaining API or SDK credentials

After the BytePlus Recommend team has consolidated and analyzed the information sent to us, we will create and provide the token, tenant_id, and tenant for your API or SDK integration.
