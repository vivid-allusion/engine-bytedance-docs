The Retail industry **Configuration** dashboard consists of the following sections:


|**Section** |**Description** |
|---|---|
|Schema |Structure or format of data supported in BytePlus Recommend system. You will import your trial, historical, and incremental data following this defined data schema. |
|Scene |A scene is defined as the location with which the user interacts. This includes the home page, promotion page, details page, search page, and many others. BytePlus Recommend builds the recommendation models based on the data collected from these scenes. Through the data sent, our team uses a combination of `scene` and `UserEvent.event_type` to analyze the flow of the user's impression. |
|Attribution |The way the Recommendation system determines how recommendations contribute to sales, conversions, or other goals. Attribution is key in optimizing the recommendation objectives and results. |
|Metrics |The quantitative measurement to reckon the success of recommendations. |
