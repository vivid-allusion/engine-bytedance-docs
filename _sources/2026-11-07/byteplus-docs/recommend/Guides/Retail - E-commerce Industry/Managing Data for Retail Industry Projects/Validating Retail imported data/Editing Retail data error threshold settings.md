Editing the data error threshold settings refers to the process of changing the predefined limit or criteria for data acceptance during the import process. In technical terms, it involves adjusting the specific parameters or values that determine whether data is considered valid or not. This adjustment can help ensure that the imported data meets the desired quality standards and reduces errors in the dataset.

To minimize data errors when importing, you have two options: you can adjust the default threshold, or you can review and modify your attribution or core metrics setup to fix the errors. While the BytePlus Recommend team suggests the latter approach, you can also edit the data threshold if needed to resolve the error.

**To edit the data threshold settings:** 


1. Sign in to [BytePlus Recommend](https://console.byteplus.com/recommend/home).

2. Click on the project you want to view the data validation.

3. On the Configure screen, click **Next**.

4. On the Import screen, click **Next**.

   The Data Validate screen appears.

7. Using the Error threshold slider, modify the **data threshold**.

8. To view the data file sample, click **View sample**.

9. If required, **Skip** using the imported data file.

10. Click **Save configuration**.

   The data threshold is modified.
