To provide you with more professional and stable vector data storage and retrieval services, we plan to start billing for the vector bucket feature of the BytePlus AI Native BaaS for Supabase (AIDAP) from 00:00:00 Beijing time on August 20, 2026. The billing policy details are as follows.

<span id="vzmbVy1r"></span>
## Billing region

China (Beijing), China (Shanghai), and Asia Pacific (Johor).

<span id="ZxDyBowi"></span>
## Vector bucket billing policy description

Vector bucket is a logical container provided by AI Native BaaS for Supabase for vector data management, suitable for business scenarios requiring storage, management, and retrieval of vector data. After billing starts, the resource usage generated by users creating and using vector buckets will be charged according to the corresponding billing items and standards.

<span id="CfCR3XYO"></span>
### Free vector bucket resources

Vector bucket does not offer free quota.

<span id="oSpX8mv9"></span>
### Charged vector bucket resources

Vector bucket uses a postpaid payment method, billed by total hour accumulation. The specific billing items include storage vector bucket storage capacity, storage vector bucket data queries, and storage vector bucket data updates.


|**Billing items** |**Billing unit**<br><br> |**Price** |
|---|---|---|
|||Asia Pacific (Johor) |
|Storage vector bucket capacity |USD/Hour/GiB |0.00018 |
|Storage vector bucket data query |USD/Hour/vCU |0.00009 |
|Storage vector bucket data update |USD/Hour/vCU |0.00002 |


For detailed information on Vector Bucket billing standards, refer to [Billing items and price](https://docs.byteplus.com/en/docs/aidap/Billing_items_and_prices?lang=zh).

<span id="kR0Ydx0z"></span>
## Service activation notice

We will add vector bucket related billing items to the accounts of AI Native BaaS for Supabase users. During the period, you may receive notifications related to service activation. Be aware that receiving the notification only indicates that the related billing items are activated, and vector bucket features will not be charged before 00:00:00 Beijing time on August 20, 2026.

<span id="tIQGkg2G"></span>
## Usage suggestion

Confirm whether vector bucket  has been created in the current workspace or project and assess whether business still requires related vector storage capabilities before billing takes effect. If no longer needed, delete unused vector bucket before billing takes effect to avoid unnecessary fees.

To create or manage vector bucket, refer to [creating Vector Buckets](https://docs.byteplus.com/en/docs/aidap/Creating_a_vector_bucket?lang=zh).
