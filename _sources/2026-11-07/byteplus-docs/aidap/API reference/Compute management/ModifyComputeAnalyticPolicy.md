Call the ModifyComputeAnalyticPolicy API to enable the primary compute's AP acceleration function.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Asynchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

This API only supports operations on workspaces using the PostgreSQL engine.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Name** |**Type** |**Required** |**Sample value** |**Description** |
|---|---|---|---|---|
|WorkspaceId |String |Yes |ideal\-fir\-9fc8\*\*\*\* |ID of the workspace. |
|ComputeId |String |Yes |cp\-cute\-fresh\-0e7d\*\*\*\* |Compute ID.<br><br><div data-tips="true" data-tips-type="default">Decscription</div><br><br><br><div data-tips="true" data-tips-type="default">Only the ID of the primary compute of the branch can be passed in.</div><br> |
|EnableAnalytic |String |Yes |Enabled |Workspace AP acceleration status. Currently only supports the value `Enabled`, which means enabling AP acceleration.<br><br><div data-tips="true" data-tips-type="default">Decscription</div><br><br><br><div data-tips="true" data-tips-type="default">Currently, only enabling AP acceleration is supported, and disabling it after enabling is not supported.</div><br> |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameters

None.
