Call the ModifyWorkspacePublicConnectionPolicy API to enable or disable the workspace's shared public network.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

This API only supports operations on workspaces using the PostgreSQL engine.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Name** |**Type** |**Required** |**Example** |**Description** |
|---|---|---|---|---|
|WorkspaceId |String |Yes |noble\-heath\-3a48\*\*\*\* |ID of the workspace. |
|PublicConnection |String |Yes |Disabled |Public network access policy of the workspace (whether to enable shared public network). Values:<br><br><br>* `Enabled`: enabled.<br><br>* `Disabled`: disabled. |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameters

null
