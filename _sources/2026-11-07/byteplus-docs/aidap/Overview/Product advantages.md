AI Native BaaS for Supabase relies on the AI Native Database Platform (AIDAP) and provides services through three database engines: Supabase, PostgreSQL, and veDB MySQL. This topic details the advantages of the AI Native BaaS for Supabase.

<span id="oaE7GAdC"></span>
## More comprehensive BaaS functions


* Functions are fully compatible with Supabase open\-source usage. Based on Object Storage, veFaaS, Doubao large models, and other BytePlus cloud\-native services, it delivers BaaS functions fully compatible with Supabase open\-source standards and features high elasticity at a low cost. It includes Database, Authentication, Storage, Edge Function, Realtime, AI assistant, and API Docs.

* Multiple integration methods. Use Supabase service quickly by integrating the SDK, improving development efficiency by 3 to 5 times.


<span id="VToAsacx"></span>
## Higher cost performance


* "True" Serverless. Not only the Supabase service layer, but also the Database layer can automatically scale resources on demand, helping businesses start smoothly with small specifications and handle traffic peaks seamlessly.

* Complete suspension, "zero" charges. Moreover, when the business has no access, it can completely suspend compute, fully releasing compute resources. During suspension, there are "zero" charges, which can help businesses **save tens to hundreds of times in costs**.


<span id="OVID6sOr"></span>
## More powerful database core


* BytePlus cloud\-native PostgreSQL foundation. In addition to the industry\-leading serverless capability, it integrates BytePlus's years of experience in building a highly available, highly reliable, and richly controlled PostgreSQL database foundation, allowing users to use BytePlus Supabase with greater confidence.

* Data as Git (Branch and Timetravel). AI businesses using Supabase are highly uncertain and require continuous data modifications and debugging. To address this, BytePlus Supabase’s underlying database foundation provides Data as Git capabilities, including branching and instant timetravel functions. This allows creating copies based on production data for AI Agent use, isolating it from production environment data to ensure online safety. It also enables fast and instant querying of historical data.


<span id="gQY1KaBw"></span>
## More user\-friendly AI Native interaction platform


* Minimalist interaction. Optimizes visual and interactive logic through interface redesign, compressing complex workflows into 2\-3 steps. Combined with natural language interaction capabilities, it improves operational efficiency by over 80%.

* AI native capabilities. Leveraging AI technology to achieve intelligent monitoring and prediction, automatic tuning, data security governance, and intelligent management of instance lifecycle, comprehensively improving fault management and service levels.
