AI Native BaaS for Supabase relies on the AI Native Database Platform (AIDAP) and provides services through three database engines: Supabase, PostgreSQL, and veDB MySQL. This topic introduces the application scenarios of the AI Native Database Platform for Supabase.

<span id="tjhmBl7B"></span>
## Startups/Independent developers

Quickly validate product ideas without building a backend team, reducing trial\-and\-error costs.

<span id="7gDpxzDJ"></span>
## SaaS applications

Multi\-tenant data isolation (based on PostgreSQL row\-level permissions), flexible pricing models (charged by number of users/storage), and low\-latency global access.

<span id="MPOb8Mg0"></span>
## AI agent applications

Vector storage (pgvector), authentication and authorization, edge function inference, and real\-time data synchronization.

<span id="AnWHvFeR"></span>
## Internal tools/low\-code platforms

Visual database design, rapid API generation, and access control, suitable for non\-professional backend developers.

<span id="wL5tzEUJ"></span>
## Real\-time collaboration applications

Document collaboration, chat tools, and real\-time data analysis, with millisecond\-level synchronization based on WAL.

<span id="wllcQDwC"></span>
## Enterprise applications (private deployment)

Complies with regulations (such as finance and healthcare), stores data locally, and enjoys the zero\-maintenance benefits of BaaS.
