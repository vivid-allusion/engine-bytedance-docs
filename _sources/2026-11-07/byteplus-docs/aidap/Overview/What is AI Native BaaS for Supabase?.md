AI Native BaaS for Supabase, relying on the AI Native Database Platform (AIDAP), is built upon minimalist interaction design, AI\-native capabilities (NL2Everything), and integrated multi\-database type management. By deeply incorporating second\-level Serverless capabilities and data branch management, it reshapes the technical paradigm and user experience of database management platforms, delivering reliable, stable, and high\-speed database services for systems in the AI era.

<span id="61FDeuyx"></span>
## Product features

The AI Native Database Platform offers the following notable features:


* **Minimalist interaction**: optimizes visual and interactive logic through interface redesign, compressing complex workflows into 2\-3 steps. Combined with natural language interaction capabilities, it improves operational efficiency by over 80%.

* **AI\-native capability**: provides natural language interaction, enabling most database operations to be completed through natural language. It leverages AI technology to deliver intelligent monitoring and prediction, automated tuning, data security governance, and full\-lifecycle intelligent management of workspaces, comprehensively enhancing service quality.

* **Integration**: unified management of multiple database types and standardized full\-lifecycle processes. It combines with Kubernetes to implement resource pooling and load balancing, improving global data visibility and management efficiency.

* **Second\-level Serverless**: features simple O&M and low\-latency second\-level elasticity. It supports automatic scaling and Scale to Zero with pay\-as\-you\-go pricing. Fees only cover storage space and computing resources.

* **Data branch management**: manages data like code with Git. By creating independent and fully isolated data environments through branches, it protects primary data security while enabling easy experimentation, rollback, and parallel validation of multiple solutions.

## Engine matrix

The AI Native Database Platform includes two database engines: [AI Native Database Platform Supabase version](https://docs.byteplus.com/en/docs/aidap/Supabase_Engine_user_guide)and [AI Native Database Platform AIDAP PostgreSQL version](https://docs.byteplus.com/en/docs/aidap/PostgreSQL_Engine_user_guide).

<span id="RM3qDAaN"></span>
### AI Native Database Platform for Supabase

The AI Native Database Platform for Supabase is built on the open\-source Supabase, fully compatible with Supabase open\-source usage, including PostgreSQL Database, Authentication, Storage, Edge function, Realtime, AI assistant, and API Docs. It features the high elasticity and low price characteristics unique to cloud\-native services. Based on the Volcengine database Serverless architecture, it achieves better availability, performance, and cost advantages. It can cost\-effectively and comprehensively meet demands in scenarios such as AI agent development, SaaS service development, and rapid prototyping.

<span id="frM5CWT4"></span>
### AI Native Database Platform PostgreSQL version

The AI Native Database Platform PostgreSQL version is a next\-generation database service based on a storage\-compute separation architecture, featuring extreme elasticity and AI\-enhanced capabilities. It offers developers highly cost\-effective, autonomous, and AI\-friendly data infrastructure through **serverless elastic scaling**, **second\-level automatic start and stop** (scale to zero), **data as git** branch capabilities, **time travel** instant recovery capabilities, and **vector/AI functions**. Provides AI Agent business with more cost\-effective, faster build and recovery, open ecosystem, and intelligent linkage database capabilities.
