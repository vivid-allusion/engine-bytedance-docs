This topic describes how to view the Workspace list in the AI Native Database Platform.

## Procedure

1. Log in to the [AI Native Database Platform](https://console.byteplus.com/aidap).

2. In the top navigation bar, select the target project and target region.

3. In the middle navigation bar, click ![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e37bb3bc4acc38cf3cc3d4cbd15b26ec.png)**Workspaces** to enter the workspace list.

   * Filter workspaces by keyword, status, and engine in the upper left corner of the Workspace list.

      > **tip**

      > Search by keyword across workspace Name, workspace ID, and branch ID.

   * In the upper right corner of the Workspace list, you can sort Workspaces by update time or creation time in ascending or descending order. You can also sort by Workspace name in ascending or descending order.

## Related APIs

|**API** |**Decscription** |
|---|---|
|[DescribeWorkspaces](https://docs.byteplus.com/en/docs/330/DescribeWorkspaces) |Call the DescribeWorkspaces API to query the list of Workspaces. |
|[DescribeAccountUsage](https://docs.byteplus.com/en/docs/330/DescribeWorkspaceDetail) |Call the DescribeAccountUsage API to query resource usage information under the tenant account. |
|[ListWorkspaceUsageTop](https://docs.byteplus.com/en/docs/330/ListWorkspaceUsageTop) |Call the ListWorkspaceUsageTop API to query resource usage of all Workspaces under the tenant account in descending order. |
|[DescribeWorkspaceOverview](https://docs.byteplus.com/en/docs/330/DescribeWorkspaceOverview) |Call the DescribeWorkspaceOverview API to query the overview of created Workspaces. |
