This topic describes the connection addresses supported by RDS for PostgreSQL. You can select an address type for accessing and managing PostgreSQL instances according to your service requirements.


|Type of address ||Note |Precautions |
|---|---|---|---|
|Private network access |Private network address |Accessing the RDS for PostgreSQL instance through a private network address maximizes security and performance. |* A private address is generated by default when you create a PostgreSQL instance.<br><br>* Deleting the private network address of PostgreSQL is not supported.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information about how to access a PostgreSQL instance through a private address, refer to <a href="https://docs.byteplus.com/en/docs/RDS_for_PG/viewing_access_address_and_port">Connecting to an instance via private address</a>.</div><br> |
|Public network access |Public network address |You can apply for a public network address for your PostgreSQL instance to allow devices outside the VPC to access the instance. |* Public network connections pose security risks. By default, a public network address is not enabled for RDS for PostgreSQL, but you can apply for one manually in the console. For more information about how to apply, refer to [Enabling public network access](https://docs.byteplus.com/en/docs/RDS_for_PG/enabling_internet_access).<br><br>* If the device outside of the VPC does not need to access the PostgreSQL instance, you are recommended to release the public address in good time. For more information about how to release a public address, refer to[ Disabling internet access](https://docs.byteplus.com/en/docs/RDS_for_PG/disabling_internet_access).<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">For more information about how to access a PostgreSQL instance through a public address, refer to <a href="https://docs.byteplus.com/en/docs/RDS_for_PG/enabling_internet_access">Connecting to an instance via internet</a>.</div><br> |
