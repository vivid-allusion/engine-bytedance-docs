This topic describes how to create and delete accounts for databases run on an RDS for PostgreSQL instance.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* You have [Creating an instance](https://docs.byteplus.com/en/docs/RDS_for_PG/create_instance), and the instance is in the **Running** status.

* An account has been created for the instance.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Login to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.   </div>
   

3. On the **Instances** page, click on the target instance name.

4. Click the **Accounts** tab on top of the page.

5. On the **Accounts** tab, click  **... \> Delete** in the **Actions** column of the target account.

6. Click **Delete** in the pop\-up dialog box.
