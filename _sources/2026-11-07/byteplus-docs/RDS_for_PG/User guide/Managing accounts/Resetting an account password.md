This topic describes how to reset database accounts and passwords.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

[An account has been created](https://docs.byteplus.com/en/docs/RDS_for_PG/creating_and_managing_an_account) for the instance.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Login to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.   </div>
   

3. On the **Instances** page, click on the target instance name.

4. Click **Accounts** at the top of the page.

5. On the **Accounts** tab, click  **... \> Reset password** in the **Actions** column of the target account.

6. Enter the password and confirm it in the pop\-up dialog box, and click **OK**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Password requirements are listed as follows:   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The password length is limited to 8~32 characters.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The password consists of any three types of characters as follows: uppercase letters, lowercase letters, digits, and special characters.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Special characters are <code>!@#$%^&amp;\*()_+-=</code>.   </div>
