RDS for PostgreSQL has been integrated with Database Workshop (DBW) and provides observation diagnosis functions in DBW.

<span id=".5Yqf6IO95LuL57uN"></span>
## Function introduction


* **Session management**

   Session management capabilities enable viewing session statistics and real\-time session information for instances.

* **Transactions and locks**

   With the transactions and locks feature, you can view and analyze all locks that occur within an instance of RDS for PostgreSQL.

* **Spatial analysis**

   The spatial analysis function allows you to intuitively view the storage space usage of an instance, such as data space, log space, WAL log space, etc.

* **Logs**

   The slow log analysis function supports viewing the development trends, statistics, and details of slow queries on instances, and can further analyze the slow log information to help you quickly locate problems.

* **Diagnosis**

   Through the diagnostic function, you can more intuitively view the full picture of database performance and quickly confirm whether there are any abnormalities in the instance.

* **Database audit**

   Database audit The database audit function records all operation records, making it easy for you to trace back, query and analyze historical operations, helping you to keep track of product security and performance and improve database security.

* **Full SQL insight**

   Full SQL insights enable you to capture, review, and analyze all SQL statements to help you improve database performance and stability.

* **Automatic operation**

   Automatic operation provides an automatic scale\-out feature. This helps you quickly respond and scale out when your business grows sharply, ensuring your system runs stably and meets rising business demands.

## Usage


1. Login the DBW console.

   * Log on to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg), click the target instance name in **Instances** to enter the instance information page, and then click **Database Workshop** in the upper right corner of the page to enter the DBW console.

   * Login directly to [Database Workshop](https://console.byteplus.com/dbw).

2. Use the corresponding functions in DBW. For more information, see [Session management](https://docs.byteplus.com/en/docs/DBW/session-management), [Slow log analysis](https://docs.byteplus.com/en/docs/DBW/slow-log-analysis-management-for-PG), [Audit log management](https://docs.byteplus.com/en/docs/DBW/database-audit-management-for-PG), [Spatial analysis management](https://docs.byteplus.com/en/docs/DBW/spatial_analysis_management), [Performance monitoring management](https://docs.byteplus.com/en/docs/DBW/performance-monitoring-management), [One-click diagnostic management](https://docs.byteplus.com/en/docs/DBW/one-click-diagnosis-management), [Transaction and lock](https://docs.byteplus.com/en/docs/DBW/transaction-and-lock-management), and [Storage space expansion management](https://docs.byteplus.com/en/docs/DBW/Storage_expansion_management_pg).
