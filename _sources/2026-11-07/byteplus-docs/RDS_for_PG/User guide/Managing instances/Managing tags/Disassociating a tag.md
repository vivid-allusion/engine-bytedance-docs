After you associate a tag with an instance, you can remove it at any time to meet your business needs. This topic describes how to disassociate tags.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can disassociate 20 tags at the maximum from instances at a time.</div>


<span id=".5Li65Y2V5Liq5a6e5L6L6Kej57uR5qCH562-"></span>
## **This topic describes how to disassociate tags.** 


1. Login to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.   </div>
   

3. On the **Instances** page, locate the target instance and click the edit icon in the corresponding **Tag** column. You can also click the name of the target instance, and click the edit icon in the **Tag** row under the **Basic information** section.

4. Find the specified tag key in the **Edit tag** pop\-up window and click **Delete**.

5. Click **OK**.

## **This topic describes how to disassociate tags.** 


1. Login to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.   </div>
   

3. Select all the target instances in **Instances** and click **Remove tag** in the lower\-left corner of the page.

4. Select the tag key to delete from the drop\-down list of the **Remove tag** pop\-up window or enter a tag key to filter the tags.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The number of selected instances matching the specified tag is displayed, that is, the number of instances associated with the tag in the instance list. If you disassociate a tag, all the tags matching the specified tag key in the selected instance list will be disassociated, while those on unselected instances will not be affected.   </div>
   

5. Click **OK**.
