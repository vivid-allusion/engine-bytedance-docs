After associating tags with an instance, you can enable tags in the bill and apply the corresponding tags to the bill details. This topic introduces the procedure for filtering and splitting bills for instances based on tags.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## **Prerequisites**

Tags have been added to the instance. For more information, refer to [Adding a tag](https://docs.byteplus.com/en/docs/RDS_for_PG/associating_a_tag).

<span id=".5rOo5oSP5LqL6aG5"></span>
## **Precautions**

You can enable 100 custom tags at the maximum in Expense Center.

<span id=".5pON5L2c5q2l6aqk"></span>
## **Procedure**


1. log in to the [cost center console](https://console.byteplus.com/finance/account-overview/).

2. Choose **Bill management** \> **Fee tag** on the left\-side navigation bar to open the **Fee tag** page.

3. Find the target tag in the tag list on the **Fee tag** page.

4. Click on the switch in the Actions column of the target tag to enable the tag.
