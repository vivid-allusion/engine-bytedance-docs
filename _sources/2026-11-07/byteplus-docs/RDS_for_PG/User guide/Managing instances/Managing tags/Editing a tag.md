After associating a tag for a specified instance, you can modify the tag key or tag value at any time according to business needs. This topic describes how to edit tags.

<span id=".5Li65Y2V5Liq5a6e5L6L5L-u5pS55qCH562-"></span>
## Modifying tags for a single instance


1. Login to the [RDS for PostgreSQL console](https://console.byteplus.com/db/rds-pg).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If the project of the instance has not been set, the project should be selected as <strong>All resources</strong>.   </div>
   

3. Find the target instance in **Instances** page and click on the edit icon in the **Tag** column. You can also click the name of the specified instance and then click the edit icon in the **Tag** row in the **Basic information** section.

4. Set the **Tag key** or **Tag value** in the **Edit tag** pop\-up window. Follow the tag setting rules. For details, refer to [Tag setting rules](https://docs.byteplus.com/en/docs/RDS_for_PG/associating_a_tag#.5qCH562-6K6-572u6KeE5YiZ).

5. Click **OK**.
