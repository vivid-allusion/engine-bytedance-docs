This topic introduces the billing methods, instance life cycle, and price\-related instructions supported by RDS for PostgreSQL.

<span id=".6K6h6LS557G75Z6L"></span>
## Billing method


|Billing method |Note |
|---|---|
|Subscription |* Subscription means prepaying fees when creating a new instance.<br><br>* It is suitable for long\-term needs, with a price more affordable than the pay\-as\-you\-go billing method.<br><br>* Subscription instances cannot be released and cannot be unsubscribed temporarily. |
|Pay\-as\-you\-go |* A billable order is generated every hour, and your BytePlus account is charged based on the instance specifications at the time the order is generated.<br><br>* Instances can be released immediately after use to save costs, suitable for short\-term needs. |

## Instance life cycle

The billing method determines how the instance life cycle of a PostgreSQL instance is calculated, where:


* **Pay\-as\-you\-go**: The instance life cycle starts counting after you successfully create it and stops when you release the instance.

* **Subscription**: The instance life cycle starts counting after you successfully create it, and the instance is automatically released when expired.
