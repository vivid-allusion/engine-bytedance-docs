## Finance scenarios

A primary/secondary switchover system is adopted to ensure high availability of services, with a sound backup recovery mechanism in place to meet data consistency and reliability requirements in finance scenarios.

## Map business scenarios

Map\-based positioning service requires real\-time access to current location coordinates. RDS for PostgreSQL provides a PostGIS geographical database extension and other extensions to provide basic services such as optimal path calculation, path planning, and geographical location information storage and processing.

## Traditional enterprise transformation scenarios

Traditional enterprises encounter data types such as JS and JSON in their transformation to the Internet, Internet of Things, and mobile end. It is important to quickly iterate the code and complete new functions with minimal changes on the existing basis. With foreign data wrappers (FDW) breaking down the barriers between NoSQL and BigData, RDS for PostgreSQL implements SQL development to quickly enter new fields and bring greater agility to database architectures.
