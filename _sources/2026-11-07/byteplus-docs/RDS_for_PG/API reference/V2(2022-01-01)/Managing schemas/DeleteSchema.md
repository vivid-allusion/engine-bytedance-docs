Call the DeleteSchema API to delete a schema.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Parameter** |**Type** |**Required?**  |**Example** |**Description** |
|---|---|---|---|---|
|InstanceId |String |Yes |postgres\-21a3333b\*\*\*\* |Instance ID. |
|DBName |String |Yes |db1 |Database name. |
|SchemaName |String |Yes |aaa |Name of the schema under the database. |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter

null
