Call the UnifyNewAllowList API to merge some allowlists of multiple instances into a new allowlist.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* Supports merging up to 300 instances' allowlists.

* The merged allowlist can contain up to 300 IP addresses or IP address segments. Before merging, confirm that the IP addresses or CIDR blocks in the allowlists to be merged do not exceed the quantity limit.


<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Parameter** |**Type** |**Required?**  |**Example** |**Description** |
|---|---|---|---|---|
|InstanceIds |Array of String |Yes |["postgres\-4b38053d\*\*\*\*","postgres\-5efe96ae\*\*\*\*"] |ID of the instance for merging to generate an allowlist.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Supports merging up to 300 instances' allowlists.</div><br> |
|AllowListName |String |Yes |Test allowlists |Name of the allowlist generated by merging. Naming rules are as follows:<br><br><br>* Within the current region, the allowlist name is unique.<br><br>* Begin with Chinese, a letter, or an underscore (_).<br><br>* It can contain only Chinese characters, letters, digits, underscores (_), and hyphens (\-).<br><br>* The name length is limited to 1\-128 characters. |
|AllowListDesc |String |No |This is a description for merging to generate an allowlist. |Description of the allowlist. Length is within 200 characters. The default value is an empty string. |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter


|**Parameter** |**Type** |**Example** |**Description** |
|---|---|---|---|
|AllowListId |String |acl\-61778b8b39a048fa969ca50bb020\*\*\*\* |Allowlist ID |
