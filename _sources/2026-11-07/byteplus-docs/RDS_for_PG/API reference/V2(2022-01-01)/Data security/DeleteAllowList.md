Call the DeleteAllowList API to delete an allowlist.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

Deleting allowlists associated with instances is not supported.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Parameter** |**Type** |**Required?**  |**Example** |**Description** |
|---|---|---|---|---|
|AllowListId |String |Yes |acl\-2b7d64502b0a4210a24c58e739de\*\*\*\* |Allowlist ID |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter

null
