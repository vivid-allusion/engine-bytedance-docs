Call the ModifyDBInstanceConfig API to set whether to enable the global read\-only mode for the instance.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Asynchronous request.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions

Enabling global read\-only will set the database to read\-only mode, which only supports query operations and doesn't support any update, write, delete or other update operations. Operate carefully.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Parameter** |**Type** |**Required?**  |**Example** |**Description** |
|---|---|---|---|---|
|InstanceId |String |Yes |postgres\-ca7b7019\*\*\*\* |Instance ID. |
|GlobalReadOnly |Boolean |No |true |Whether to enable instance global read\-only.<br><br><br>* `true`: Indicates that this feature is enabled.<br><br>* `false`: disabled.<br><br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">No default value. The request is ignored if no value is passed.</div><br> |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter

null
