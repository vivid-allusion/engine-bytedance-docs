Call the ModifyDBInstanceName API to modify the instance name.

<span id=".6K-35rGC57G75Z6L"></span>
## Request type

Synchronous request.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters


|**Parameter** |**Type** |**Is it required?**  |**Example** |**Description** |
|---|---|---|---|---|
|InstanceId |String |Yes |postgres\-21a3333b\*\*\*\* |Instance ID. |
|InstanceNewName |String |Yes |Name123 |New instance name. The rules for setting the new instance name are as follows:<br><br><br>* It cannot start with a digit or hyphen.<br><br>* Can only contain Chinese characters, letters, digits, underscores, and hyphens.<br><br>* Length must be between 1 and 128. |


<span id=".6L-U5Zue5Y-C5pWw"></span>
## Response parameter

null
