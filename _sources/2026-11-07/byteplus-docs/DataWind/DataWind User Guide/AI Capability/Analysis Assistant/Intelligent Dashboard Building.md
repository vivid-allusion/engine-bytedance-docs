The intelligent data insight analysis assistant helps users build dashboards, modify dashboards, and interpret dashboards intelligently. This article introduces how to use the analysis assistant's intelligent dashboard feature to build and modify dashboards.

<span id="f31d71a6"></span>
# Feature overview

The intelligent dashboard building feature of the intelligent data insight analysis assistant includes intelligent building and intelligent modification. Users can describe their dashboard building or modification requirements in natural language, and the intelligent dashboard can quickly generate dashboards, improve building efficiency, optimize dashboard layouts, and enable agile and efficient data insights.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">This feature is a sub\-feature under the value\-added module "Analysis Assistant" and is disabled by default. To use this feature, contact Volcano Engine technical support for consultation. After purchasing and enabling this feature, it can be used.</div>


<span id="d4a85d83"></span>
## Specific features


* Intelligent building: Supports generating dashboards using natural language, helping users quickly build dashboards.

* Intelligent modification: Supports switching dimensions, metrics, or chart types, modifying period\-over\-period or year\-over\-year comparisons, adjusting layouts, and other operations.


<span id="b0c1c9ce"></span>
## Applicable scenarios


* **Enterprise data visualization analysis**: Supports quickly generating multi\-dimensional dashboards such as core metrics, regional distribution, and industry trends through natural language. This is suitable for management to monitor business data in real time (such as GMV, redemption rate, and other key metrics) and for operations teams to gain data insights.

* **Intelligent dashboard optimization and iteration**: Allows dynamic adjustment of dimensions, metrics, layouts, or chart types (such as converting a line chart to a bar chart) for existing charts. This is suitable for data analysts to iteratively optimize dashboards based on business needs and improve data presentation efficiency.
