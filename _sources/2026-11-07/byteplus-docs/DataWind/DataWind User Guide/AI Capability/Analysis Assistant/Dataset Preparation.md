The Intelligent Data Insight Analysis Assistant (hereinafter referred to as the DataWind analysis assistant, analysis assistant, or AI assistant) is a self\-service analysis intelligent assistant. This article explains how to use the DataWind analysis assistant in the dataset preparation phase, including intelligent optimization of dimensions/metrics, intelligent field description completion, intelligent field name completion, and intelligent field expression generation.

<span id="36bcbe81"></span>
# Feature overview

In the data source integration and data preprocessing phases, the dataset module plays an important role. Rapid completion of the data processing process is the foundation of self\-service analysis.

AI provides the following features in the dataset preparation phase:


* Intelligent optimization of dimensions/metrics: The AI assistant helps users optimize the selection of dataset field dimensions or metrics.

* Intelligent field name/description completion: One\-click generation of multilingual display names and descriptions for fields (requires multilingual configuration).

* Intelligent field expression generation: By describing requirements in natural language, AI automatically generates field calculation expressions.


<span id="debe49a0"></span>
# Notes


* The Intelligent Data Insight Analysis Assistant is a value\-added module that supports both SaaS and on\-premises deployment versions. To purchase or try it, please contact the sales personnel for consultation.

* The analysis assistant feature can only be enabled when the account has dataset management permissions. If you only have editing permissions, please apply for management permissions or ask the corresponding administrator to enable it.

# Special statement

(1) All content output by this service is generated by artificial intelligence models.

(2) Intended users of this feature: This feature is limited to customers for internal use, their own business operations, and use by the customer only. Customers are not permitted to provide generative artificial intelligence services to the public through the Analytics Assistant.

(3) This feature is a value\-added module and supports both SaaS and self\-hosted deployment versions of the product. To purchase or request a trial, please contact the sales team for consultation.

(4) Currently, the types of datasets supported by the AI capabilities of DataWind Intelligent Data Insights are as follows:


* Supports extracted datasets and supports datasets uploaded as Excel/CSV files.

* Supports direct connection datasets, currently including only: ClickHouse / ByteHouse, Doris / selectdb.
