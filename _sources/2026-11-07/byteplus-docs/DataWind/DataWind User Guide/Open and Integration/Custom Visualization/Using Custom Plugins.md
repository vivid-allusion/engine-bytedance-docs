# 1. Overview

Custom visualization is one of the open capabilities provided by this product. It allows users to create personalized data displays according to their needs. This article introduces how to use custom plugins. (Currently, the custom visualization feature is still in the internal testing phase. To obtain more details about purchasing and cooperation, please contact the Volcano Engine business team.)

**Caution: Before using custom plugins, you need to complete the relevant configurations in** [Custom Visualization Overview](https://docs.byteplus.com/docs/DataWind/Custom_Visualization_Overview) **,**  [Structure and Development of Custom Chart Plugins](https://docs.byteplus.com/docs/DataWind/Structure_and_Development_of_Custom_Chart_Plugins) **,**  [Custom Chart Data Structure and Plugin Property Configuration](https://docs.byteplus.com/docs/DataWind/Custom_Chart_Data_Structure_and_Plugin_Property_Configuration) **, and** [Publishing Custom Plugin Packages and Plugin Package Resources](https://docs.byteplus.com/docs/DataWind/Publishing_Custom_Plugin_Packages_and_Plugin_Package_Resources) **in sequence.**

# 2. Specific operations

First, open the visualization query page of this product. You will see the option to add plugins.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8fd837cd3f37449eb312842c8392420e~tplv-goo7wpa0wc-image.image) </span>

Next, after clicking, the plugin marketplace will pop up.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a8c0427120ab4481bc8b44cfde2124e1~tplv-goo7wpa0wc-image.image) </span>

> The content of this page is for demonstration purposes only. Please select the actual resource package based on your development needs.


Then, click the blue Add button to add the corresponding plugin.

After adding, the plugin will be displayed next to the add plugin entry:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7a899d3f3a7e4db89d94410efb98e2bf~tplv-goo7wpa0wc-image.image) </span>

Finally, click the icon to use the corresponding plugin, then drag the dimensions and metrics into the chart as prompted to complete the chart query and display.
