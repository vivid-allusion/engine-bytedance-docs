# Overview

As Lark's efficient office approach and DataWind's data\-driven methodology become increasingly integrated into the daily operations of enterprises, we have launched the Lark + DataWind joint solution based on the features of both products. This solution achieves integration of product features across multiple stages, including data ingestion, data delivery, and data sharing, providing users with a more convenient collaborative office experience and supporting organizational transformation. This article will systematically introduce the capabilities and effects of the deep integration between DataWind and Lark. For details on each capability, you can click to view the corresponding documentation for specific operations.

<span id="_2-飞书数据接入"></span>
# Lark data ingestion

<span id="_2-1-接入飞书表格数据"></span>
## Ingest Lark sheet data

DataWind supports uploading Lark sheets to create datasets. For data update methods, scheduled offline data updates are supported. For detailed steps, see "[Lark Sheets](https://docs.byteplus.com/docs/DataWind/Lark_Sheets)".

<span id="_2-2-接入飞书多维表格数据"></span>
## Ingest Lark multi\-dimensional sheet data

DataWind supports uploading Lark multi\-dimensional sheets to create datasets. For data update methods, scheduled offline data updates are supported. For detailed steps, see "[Lark Base Table](https://docs.byteplus.com/docs/DataWind/Lark_Base_Table)".

<span id="_3-飞书数据触达"></span>
# Lark data delivery

<span id="_3-1-飞书开放平台获取datawind"></span>
## Obtain DataWind from the Lark open platform

In the Lark app marketplace, DataWind has already been listed as an application. New customers can find the application by searching and can try it out.

<span id="_3-2-飞书工作台小程序设置"></span>
## Lark Workbench mini program setup

On the Lark open platform, application administrators can create custom mini programs or applications for DataWind. Organization administrators can set permissions and configure application visibility in the Lark admin console, enabling users within the enterprise to directly access the mobile version of DataWind from the Lark Workbench or push daily, weekly, or monthly reports to individual Lark users or groups, and more. For detailed steps, see [Basic Configuration for Lark Integration](https://docs.byteplus.com/docs/DataWind/Basic_Configuration_for_Lark_Integration).

<span id="_3-3-飞书接收订阅预警提醒"></span>
## Receive subscription alert notifications in Lark

After the administrator completes the basic configuration, subscription and alert rules can be set in DataWinds, enabling dashboards and data anomaly notifications to be pushed to Lark and Lark groups. For detailed steps, refer to [How to push Lark Messages](https://docs.byteplus.com/docs/DataWind/How_to_push_Lark_Messages) and [Data Subscription](https://docs.byteplus.com/docs/DataWind/Data_Subscription), among others.

<span id="_3-4-飞书聊天窗口标签页设置"></span>
## Lark chat window tab settings

You can configure the dashboard link from DataWinds in the tab position of the Lark chat window, so that data can be accessed at any time. For detailed steps, refer to [Overview of Embedded Analytics](https://docs.byteplus.com/docs/DataWind/Overview_of_Embedded_Analytics) to learn how to obtain the embedded link for the dashboard.

<span id="_3-5-飞书左侧标签栏打开仪表盘"></span>
## Open dashboards from the Lark left sidebar

You can open dashboards from DataWinds directly in the Lark left sidebar, allowing you to view data without switching to a browser, making business analysis and communication faster and more efficient. The detailed steps and effects can be experienced after Lark releases the new version. Supported versions: Lark V7.0 and above; DataWinds V2.56.1 and above.

<span id="_4-飞书数据协作"></span>
# Lark data collaboration

<span id="_4-1-飞书账号互通"></span>
## Lark account integration

Users in DataWinds can bind their accounts with Lark accounts, either individually or in batches. For detailed steps, see [How to Bind Lark Accounts and Batch Create sers](https://docs.byteplus.com/docs/DataWind/How_to_Bind_Lark_Accounts_and_Batch_Create_sers).

<span id="_4-2-权限与飞书审批打通"></span>
## Permission and Lark approval integration

Lark approval workflows are supported, allowing users to independently apply for permissions from resource owners. Once approved by the owner, the applicant will receive the corresponding permissions for the requested resources. This lowers the threshold for data usage and shortens the time required for data or IT personnel to authorize data access. For detailed steps, refer to [Permission Approval Integration with Lark](https://docs.byteplus.com/docs/DataWind/Permission_Approval_Integration_with_Lark).

<span id="_4-3-仪表盘评论提醒"></span>
## Dashboard comment notifications

Starting from version 2.48.0, DataWinds supports users in commenting on dashboards. Users involved in the comments can also reply. If integrated with Lark, it also supports pushing messages to commenters via message bots. For detailed steps, refer to [Dashboard Comments](https://docs.byteplus.com/docs/DataWind/Dashboard_Comments).

<span id="_4-4-一键联系图表负责人的飞书"></span>
## One\-click Lark contact for chart owners

After completing Lark integration and binding the chart creator to a Lark account, you can contact the chart owner with one click. Click the contact button next to the chart name to see the Lark icon. Clicking it allows you to view the owner's Lark contact information in Lark and get in touch with them.

<span id="_4-5-一键授权发送飞书通知"></span>
## **One\-click authorization to send Lark notifications**

Smart Data Insight provides authorization operations through two entry points: the "Authorize" button in the upper right corner of the dashboard, and the "Authorize" option in the menu that appears when you right\-click a dashboard or folder in the dashboard directory on the left. Click the authorize button, select the authorization target and permission level in the pop\-up window, and the system will send the dashboard link to the sharing target and grant the corresponding permissions. This step supports sending Lark notifications to the sharing target. This feature is checked by default, but users can opt out. For detailed steps, see [Authorization and Sharing](https://docs.byteplus.com/docs/DataWind/Authorization_and_Sharing).

# Lark data accumulation

With the embed dashboard feature, you can embed data reports into cloud documents with one click. You can also view the specific effect of [Chart Embedding](https://docs.byteplus.com/docs/DataWind/Chart_Embedding).

More Lark integration capabilities are being gradually rolled out. Please stay tuned.
