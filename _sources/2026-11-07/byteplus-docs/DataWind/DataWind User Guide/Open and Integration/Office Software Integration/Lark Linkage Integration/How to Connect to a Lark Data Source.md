# Overview

DataWind supports uploading Lark spreadsheets and Lark multi\-dimensional spreadsheets to create datasets. Offline scheduled data updates are supported. To connect to a Lark data source, you need to complete the basic configuration for connecting to the Lark application and perform the following actions.

<span id="_2-开启飞书文档相关权限"></span>
# Enable permissions related to Lark documents

On the permission management page, make sure to enable the following permissions. "View, comment, edit, and manage multi\-dimensional spreadsheets" and "View, comment, and export multi\-dimensional spreadsheets" are permission settings for multi\-dimensional spreadsheets. "View, comment, edit, and manage spreadsheets" and "View, comment, and export spreadsheets" are permission settings for spreadsheets. It is recommended to select all permissions related to cloud documents. The permission configuration interface of the Lark open platform may be updated periodically. Please note that you should refer to the latest permission configuration interface, and it is also recommended to select all permissions related to cloud documents.

<span id="_3-连接飞书数据源测试"></span>
# Test the connection to the Lark data source

To confirm whether the configuration is successful, go to the DataWind product, click Data Management \-\-\> Dataset, and you will see options for Lark spreadsheets and Lark multi\-dimensional spreadsheets (Lark multi\-dimensional spreadsheets are supported in V2.42 and above). [Lark Sheets](https://docs.byteplus.com/docs/DataWind/Lark_Sheets)If you can complete the subsequent steps, the configuration is successful. Otherwise, please check the configuration according to the steps above.
