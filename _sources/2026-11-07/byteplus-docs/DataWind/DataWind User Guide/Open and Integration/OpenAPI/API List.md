This article provides a detailed list of all APIs of DataWind.


|API |Description |
|---|---|
|[Dataset operation API](https://www.volcengine.com/docs/4726/1225207) |Users can use the API to update, move, and delete datasets, as well as check and move datasets to the recycle bin, among other operations. |
|[Dataset information API](https://www.volcengine.com/docs/4726/1225558) |Users can use the API to view basic information on the dataset details page and edit page, update basic information, set tags, and perform other operations. |
|[Dataset synchronization task API](https://www.volcengine.com/docs/4726/1225560) |Users can use the API to view and update dataset synchronization task settings, submit dataset synchronization task backtracking, and terminate dataset synchronization task instances, among other operations. |
|[Dataset model canvas and operations tools API](https://www.volcengine.com/docs/4726/1225562) |Users can use the API to view the dataset model canvas and refresh base table metadata, among other operations. |
|[Project datasets API](https://www.volcengine.com/docs/4726/1225573) |Users can use the API to obtain, create, and update information on datasets and folders under a project, as well as obtain, add, and delete users in the private cluster write user list, among other operations. |
|[External trigger for data synchronization tasks](https://www.volcengine.com/docs/4726/67307) |Users can provide the API for external users to trigger visual modeling or dataset synchronization tasks. |
|[Dataset visualization query parameter API](https://www.volcengine.com/docs/4726/1225561) |Users can use the API to view and update visualization query parameter configurations. |
|[Embedded link encryption](https://www.volcengine.com/docs/4726/1179600) |Users can use OpenAPI to add, delete, update, and query encrypted links for embedded charts or dashboards, as well as apply encrypted links and perform other operations. |
|[Visualization - data subscription Open API](https://www.volcengine.com/docs/4726/152560) |Users can use the API to create, update, delete, and unsubscribe from subscriptions. |
|[Visualization - dashboard & chart Open API](https://www.volcengine.com/docs/4726/65223) |When embedding dashboards externally, users can use OpenAPI authentication, allowing the embedding party to control the application for OpenAPI tokens to achieve custom permission control. |
|[Subscription push Feishu message recall](https://www.volcengine.com/docs/4726/1181824) |Users can use the API to recall related Feishu messages. |
|[User, user group, and permission Open API](https://www.volcengine.com/docs/86403/1830385?lang=zh) |Users can use the API to create, manage, and delete users or user groups, and manage row and column permissions. |
|[Metadata information API](https://www.volcengine.com/docs/4726/152721) |Users can obtain metadata such as datasets and dashboards via the API |
|[Project center - user attribute management open API](https://www.volcengine.com/docs/86403/1830114?lang=zh) |Users can update attributes, update attribute values, and delete attributes via the API |
