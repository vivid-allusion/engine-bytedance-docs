This article explains how to upload Access files as data sources to create datasets.

<span id="c3e2382b"></span>
# Caution


* Uploading local Access database files (.mdb, .accdb) is supported, with a maximum file size of 4 GB.


<span id="e9718caa"></span>
# Create from data connection


1. Log in to Volcano Engine, navigate to a specific project, click Data Preparation, find Data Connection in the dropdown list, and click Data Connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b9656a5ed4ef44509dc16dd9163db39c~tplv-goo7wpa0wc-image.image) </span>

2. Select Access on the page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/80d69c293aa04d4287aad56e6208648f~tplv-goo7wpa0wc-image.image) </span>

3. After uploading the file, enter the basic information. Uploading local Access database files (.mdb, .accdb) is supported, with a maximum file size of 4 GB.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9244184f4c5548d3986273d163b259a4~tplv-goo7wpa0wc-image.image) </span>

4. Select a table and click "Next".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/203a1528e76d4ceaaa2919521c7a61a4~tplv-goo7wpa0wc-image.image) </span>

5. After confirming the preview content is correct, click Finish.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/47bb74bd106b4e81a01d918c49aa49d0~tplv-goo7wpa0wc-image.image) </span>


<span id="d044ace1"></span>
# Create from dataset


1. Log in to Volcano Engine, click Data Preparation \-\-\> Dataset, select the "Create" button in the upper left corner to create a new dataset.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1a122b624fe7494684d19c0ccea499a3~tplv-goo7wpa0wc-image.image) </span>

2. When selecting a data connection, click Create Configuration.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7bec62a90dee4092a2f3f0cf39123ea3~tplv-goo7wpa0wc-image.image) </span>

3. The subsequent steps are the same as steps 2 and 3 in **Create from data connection**. After completing the configuration, you will remain in the pop\-up window for selecting a data connection for the dataset, and you can proceed directly to the next step to create the dataset.

<span id="ed665657"></span>
## Update Access file


1. Go to the "Data Connection" page, select the Access data source, and click "Update File".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b4228be171bd4ce69d95e07767fd38d7~tplv-goo7wpa0wc-image.image) </span>

2. Upload a new Access file.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0dbbca1ae7eb408fbf8aba3913631f85~tplv-goo7wpa0wc-image.image) </span>

3. Select a table to preview and complete the update.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/301388f0af6d473ca269d7655639df32~tplv-goo7wpa0wc-image.image) </span>
