# 1. Overview

Intelligent Data Insight supports connecting to the lakehouse analytics service LAS to obtain data, create datasets, and perform further analysis.

If your Volcano Engine account has purchased LAS resources, a default LAS storage data connection will appear when creating a new dataset, which can be used for modeling and data extraction.

## 3.5 Recommended dependencies

This product provides flexible **task scheduling dependency configuration** functionality. Scheduling dependencies usually refer to the upstream and downstream relationships between periodic scheduling nodes during data synchronization and data development. By scheduling tasks in order according to node dependencies, downstream nodes will only start running after upstream nodes have successfully run, ensuring timely production of valid business data.

**Recommended dependency** refers to the system's ability to automatically construct data source partition detection tasks and automatically configure scheduling dependencies in LAS data sources with **partitions**. **The task instance for the day will only be triggered when the detection task confirms that the upstream partition is ready.**  (Recommended dependency configuration is not supported for data sources without partitions.)

Note: After the system wakes up the Sensor task at the scheduled time, it checks every 5 minutes whether the specified partition table of the data source has been generated. If the partition table is generated, the current task will be executed immediately. If the partition has not been produced after more than 50 hours, the Sensor task will be marked as failed.

> Sensor definition: Sensor tasks mainly refer to scheduled tasks generated by the system to discover partitions, not the current task. For user settings, the system will automatically **detect and probe** whether the required partition table for the task exists in the user's data source. If it exists, it means that the preparation of upstream data is complete and downstream data can start running.


The system will automatically detect dependency Sensors that have already been created for the current table, and then recommend options. If there are no recommendations, the list will be empty, and users can choose to configure custom settings.

**Configuration method**: Confirm that the data source is a partitioned table, set the partition data filtering criteria in the model configuration, and in Synchronization Settings \> Dependency Configuration \> System Automatic Configuration, you will see recommended dependencies.
