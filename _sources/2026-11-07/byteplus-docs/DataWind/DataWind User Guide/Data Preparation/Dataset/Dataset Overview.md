# 1. Dataset overview

A dataset serves as the foundation for storing and managing data in DataWind, and is also the basis for visual queries and analysis. In simple terms, you can think of it as a type of data table. Users need to create datasets from the data source tables to be analyzed before proceeding with subsequent modeling, visualization chart creation, dashboard creation, and other tasks. In the dataset module, you can create, edit, query, and manage datasets.

<span id="_2-使用场景"></span>
# 2. Use cases

After completing [Data Connections Overview](https://docs.byteplus.com/docs/DataWind/Data_Connections_Overview), users can create datasets, supporting direct creation from original tables, generating datasets through multi\-table join/union, or creating datasets using custom SQL.
