# 1. Overview

On the lineage view of a dataset, you can directly see how the dataset has been used for analysis. You can quickly check how it has been referenced and used for analysis in the past 30 days, making it easier to manage the dataset.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e4ceef2ad48427fb6f8f58cfbe8d46f~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-快速入门"></span>
# 2. Quick start

(1) Click Data Management \-\- Dataset, and select the dataset whose reference usage you want to view.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1997577290214f57a763ceea87b0ca16~tplv-goo7wpa0wc-image.image) </span>

(2) Click the corresponding dataset and select "Lineage View" to view the upstream and downstream relationships of the dataset. The dataset lineage supports displaying the following upstream and downstream objects:


* Upstream: Dataset, visual modeling.

* Downstream: Dashboard, chart, dataset, visual modeling, and big screen dashboard.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/889e87aeee4b4df79556f949f9dea553~tplv-goo7wpa0wc-image.image) </span>


(3) Click "Access Statistics" to jump to the access details of the resource.
