# 1. Overview

The official dataset feature allows the creation of business lines within the current project and enables moving the corresponding datasets under the relevant business line, designating them as the official datasets for that business line. This makes it easier for users to quickly locate the required datasets and manage official assets, eliminating the need to manually maintain the official dataset directory.

<span id="e4fc6ca3"></span>
# 2. Quick start

<span id="b28e4727"></span>
## 2.1 Create a business line

Before using the official dataset, you need to create a business line within the project. The structure of the business line will serve as the folder directory structure for the official dataset.

**Step 1**: Go to the Asset Management page in the Project Center and select "Business Line".

**Step 2**: On the business line page, select Create Business Line.

**Step 3**: Enter the business line name and other relevant information, then click Confirm to create the business line.

## 2.2 Move datasets to the official dataset

After creating the business line structure as described in Step 1, the corresponding structure will appear in the "Official Dataset" directory on the "Dataset" page. At this point, you can move datasets into these directories in the same way as moving datasets between regular folders.

**Step 1**: On the Dataset page, locate the dataset you want to move, expand the dataset operation options, and select Move (moving from other entry points is also supported).

<div style="text-align: center">

**Step 2**: In the pop\-up window, select the path for the official dataset and click Confirm.

**Step 3**: The dataset will then be added to the official dataset directory of the selected business line.

# 3. Permission requirements


* Creating business lines: Only project administrators are allowed to create business lines.

* Adding/removing official datasets: Currently, only project administrators can maintain official datasets.
