# 1. Overview

If you have also purchased the BytePlus VeCDP product, the "Output real\-time tag" operator will be visible and available for use in the Output Operators category within the Visual Modeling module of Intelligent Data Insights; otherwise, this operator will not be visible. The Output real\-time tag operator outputs data to the tag system, supports custom pipeline processing, and sends the results to tags.

<span id="_2-功能介绍"></span>
# 2. Feature introduction

<span id="_2-1-添加“输出实时标签”"></span>
## 2.1 Add "Output real\-time tag"

In a real\-time modeling task within Visual Modeling, click the Add Operator button to view the Output Operators category, where you can select "Output real\-time tag".

<span id="_2-2-配置“输出实时标签”"></span>
## 2.2 Configure "Output real\-time tag"

As shown in the figure above, after adding the "Output real\-time tag" operator, users can configure the target entity, tag settings, advanced settings, and other options. The explanations for each configuration item are as follows:

 **(1) Target entity**

Entity: The profile entity in CDP, that is, the target object of ID\-Mapping OneID.

 **(2) ID\-Mapping type**

A. **Real\-time conversion**: Based on the field data corresponding to the ID type, the ID\-Mapping service is used to query in real time for an existing One\-ID (that is, the base ID BaseID). If it is a completely new ID, meaning it has never participated in the generation of a One\-ID (that is, the base ID BaseID), then no One\-ID (that is, the base ID BaseID) data can be found.

B . **Real\-time generation**: Based on the field data corresponding to the ID type, the ID\-Mapping service generates the OneID in real time. If a One\-ID (that is, the base ID BaseID) already exists, it can be directly queried; if it is a completely new ID, a new One\-ID (that is, the base ID BaseID) will be generated by the ID\-Mapping service. The One\-ID (that is, the base ID BaseID) can be used across all CDP product features. For detailed generation strategies, refer to CDP [Data Fusion \- ID Graph Construction \- Real\-Time OneID Generation Strategy].

Note: Real\-time generation of ID\-Mapping will affect the use of all entity data within CDP and is only available to group administrators.

 **(3) ID type and associated fields**


* **ID type**: The ID code for a specific type of ID of the entity in the ID\-Mapping graph. For details, refer to CDP [Data Fusion \- ID Graph Construction \- ID Type Settings];

* **ID\-type field**: Select the field in the operator's input data source that corresponds to the ID\-Mapping ID type as the data input.


 **(4) Label configuration**

Label configuration: After label submission, relevant labels will be automatically constructed in the label system. The labels take effect only after the task is saved. Label field: Please select the field name to be defined as a label. Special field types such as Map are not supported.

Label name: Please define a name for the label that is easy to understand, either in Chinese or English.

Label description: Please define a description for the label that is easy to understand. Online service: When enabled, the label can be queried for relevant data in the high\-speed OpenAPI, supporting high\-concurrency queries.
