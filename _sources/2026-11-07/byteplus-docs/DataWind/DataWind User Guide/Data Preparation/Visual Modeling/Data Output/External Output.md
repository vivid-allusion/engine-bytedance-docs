<span id="_1-产品概述"></span>
# 1. Product overview

Visual modeling has external output capabilities, supporting the return of offline tables generated by intelligent data insights to the native system for secondary data production and mining, enabling more flexible data output and application. Currently supported external storage: MaxCompute, OceanBase Oracle, Mysql, LAS (public cloud), Transwarp Inceptor, Oracle, BytehouseCE.

<span id="_2-使用条件"></span>
# 2. Usage requirements

This feature is a value\-added function for the private deployment version and requires a paid purchase. If needed, please contact your account manager. After purchase, users must have **Project Center \- Data Preparation \- Visual Modeling \- Create Task** permissions, and on the customer side, table creation and data writing must be allowed.

<span id="_3-3-操作步骤"></span>
## 3.3 Operating steps

(1) Click **Data Preparation \> Data Connection**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/82978a1acd5b48c7a39befec18d26496~tplv-goo7wpa0wc-image.image) </span>

(2) In the upper left corner of the data connection directory, click the **New Data Connection** button. Using MaxCompute as an example, select the **Data Warehouse \- MaxCompute** data connection.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef6de0e04833486d90041e6ba82cf4ae~tplv-goo7wpa0wc-image.image) </span>

(3) On the edit page, fill in the corresponding server and key information, enable **Write** permission in the permission mode, and after the connection test is successful, click **Save**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f7fecae284f049d291d2088e8362e14d~tplv-goo7wpa0wc-image.image) </span>

(4) Click **Visual Modeling \- Create Task**;

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aaf44918fa6d494d96adc388f1e1a6c1~tplv-goo7wpa0wc-image.image) </span>

(5) On the task editing page, you can freely perform data cleaning and processing. After completion, add the **External Output** operator;

(6) In version V2.62.0, the process for creating and viewing tables has been simplified. Related content can be displayed directly in the operation bar, improving operational efficiency.


* Create an output table and fill in the relevant information.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/413aa2da5b294a06a94e5f388f224a5a~tplv-goo7wpa0wc-image.image) </span>


* You can view the output table directly in the operation bar, and also preview the table structure.
