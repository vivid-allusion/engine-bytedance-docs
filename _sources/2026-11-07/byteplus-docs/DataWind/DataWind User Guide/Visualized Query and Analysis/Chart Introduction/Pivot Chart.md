<span id="_1-概述"></span>
# 1. Overview

Pivot charts aggregate and display data based on column and row dimensions.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/720f537bef8646a194f760fbd7aaf7e5~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-常见使用场景"></span>
## 2.1 Common use cases

Pivot tables categorize and summarize charts, and perform cross\-analysis using different combinations. For example, compare the performance of prices in each quarter across different regions and product categories.

<span id="_2-2-使用过程示例"></span>
## Usage example

**Step 1: Configure the chart**

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/92d665f996fa4b5b87ad11559fed745a~tplv-goo7wpa0wc-image.image) </span>

**Step 2: Configure classification dimensions**

The configured column dimensions display the chart for each item of the column dimension in columns, and the configured row dimensions display the chart for each item of the row dimension in rows.

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_95cf6a52ac96f9a2f64131074fce0444.png) </span>

**Step 3: Set the pivot style (whether to show row and column headers) and display mode**

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/46c1031ca63947e0b0bb3be518d71bca~tplv-goo7wpa0wc-image.image) </span>

When there are many pivot dimension items, the chart may exceed the screen display range. You can select from standard, adaptive width, adaptive height, or adaptive window.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/427e0f745752464e8da1a081b8e52cbf~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-功能介绍"></span>
# 3. Features

**Supported chart types**: Column chart, bar chart, line chart, area chart, dual\-axis chart, combination chart

**Configure column dimensions**: You can configure one or more column dimensions. Drag dimensions into the pivot's column dimensions.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4572fc90434e44cdb997204ca57e7ca4~tplv-goo7wpa0wc-image.image) </span>

**Configure row dimensions**: You can configure one or more row dimensions. Drag dimensions into the pivot's row dimensions.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9f255e65804a42278a4003abd262fdf5~tplv-goo7wpa0wc-image.image) </span>
