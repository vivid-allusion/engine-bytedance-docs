<span id="_1-概述"></span>
# 1. Overview

A word cloud is a visual representation of text data, consisting of a colorful cloud\-like graphic made up of words, used to display large volumes of text data. The importance of each word is shown by its font size. The product provides a word cloud component with a variety of color, shape, and style options.

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-常用使用场景"></span>
## 2.1 Common usage scenarios

Word clouds are used to visualize large volumes of text data, quickly identify the most prominent words, and show the importance of each word. For example, quickly find the product with the highest revenue, the subject with the highest score, and more.
