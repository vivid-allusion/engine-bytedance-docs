<span id="_1-概述"></span>
# 1. Overview

Indicator cards can be used to visually display core indicator values. They support displaying a single indicator, one primary indicator with multiple secondary indicators, and indicators for different dimension items.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3d4dd87edde44315b24f5e1f8dbc5d4e~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-使用过程示例"></span>
## 2.1 Usage example

Step 1: Select the indicator card in the chart type options.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/db59c0ee0499415ab6e0f0334617c78b~tplv-goo7wpa0wc-image.image) </span>

Step 2: Configure the indicators to be displayed and set filter conditions. The first item in the indicator bar is the primary indicator, and the rest are secondary indicators. Virtual indicators generated by features such as period\-over\-period comparison and other comparison features can be used as display indicators.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d31c876e0b7c4a549c7267f84caeee9c~tplv-goo7wpa0wc-image.image) </span>

Step 3: To display indicators for different dimension items side by side, drag the dimension into the dimension bar. Only one dimension can be added.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5009902a732a42da856e0ae3f4639c7f~tplv-goo7wpa0wc-image.image) </span>

Step 4: Adjust the indicator card style according to display requirements, including alignment, dimension item font size, indicator style, and so on.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ccfb4b28080a46cc8106d12ab01012b5~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-功能介绍"></span>
# 3. Feature introduction

<span id="_3-1-配置规则"></span>
## 3.1 Configuration rules

**Dimension**: Supports 0 to 1 dimensions.

**Indicator**: Supports one or more indicators. Derived indicators generated by analysis features are supported.

<span id="_3-2-样式配置"></span>
## 3.2 Style configuration

<span id="_3-2-1-对齐方式"></span>
### 3.2.1 Alignment

The alignment of the indicator card can be adjusted.


* You can select the alignment of the chart content.

* When there are many indicator cards to display, you can select the maximum number of indicator cards displayed per row.

* You can set whether to display the indicator card border.

* You can adjust the indicator spacing mode to compact, moderate, or comfortable. In compact mode, the data spacing is reduced; in comfortable mode, the spacing is more relaxed.


For example: set center alignment, display up to 2 indicator cards per row, show indicator card borders, and set the spacing mode to moderate.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8474a0344e4845e79bcb20d7fbc57b65~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-2-2-维度项"></span>
### 3.2.2 Dimension items

Display name: Checked by default. If unchecked, the dimension item name will not be displayed. Supports font size and color configuration.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/381d9c788dc64e22851447588207f5e0~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-2-3-指标样式"></span>
### 3.2.3 Indicator style

Supports settings for primary and secondary indicators.

Display name: Checked by default. If unchecked, the indicator field name will not be displayed. Supports font size and color configuration.

Indicator value: Supports font size and color configuration.

<span id="_3-2-4-图表切换"></span>
### 3.2.4 Chart switching

<span id="_3-2-5-从表格切换到指标卡"></span>
### 3.2.5 Switch from table to indicator card


* Dimensions and metrics remain unchanged. If there are multiple dimension fields, the metric card will not be effective. You need to remove extra dimension fields until the requirements are met; only then will the system render the metric card.

* Filter content remains unchanged.

* Analysis panel remains unchanged.


<span id="_3-2-6-从指标卡切换到表格"></span>
### 3.2.6 Switch from metric card to table


* Metrics remain unchanged.

* Filter content remains unchanged.

* Analysis panel remains unchanged.


<span id="_3-2-7-条件格式"></span>
### 3.2.7 Conditional formatting

You can set conditional formatting for specified metrics. The style supports the default format, or you can click [Custom Conditional Formatting] to customize it.

<span id="_3-3-对比指标卡"></span>
## 3.3 Comparison metric card

Hover over the metric card option to switch to the comparison metric card. The configuration rules for the comparison metric card are as follows:

Dimensions: 0 or 1 dimension

Metrics: 2 to 10 metrics

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/467449b680de476a9aac38528e375e40~tplv-goo7wpa0wc-image.image) </span>

Other configurations are the same as those of the basic metric card.
