<span id="_1-概述"></span>
# 1. Overview

Query history allows users to view the previous query statuses of the current dataset in the visual query editor, as well as perform operations such as viewing historical logs.

<span id="_2-功能介绍"></span>
# 2. Feature overview

<span id="_2-1-打开查询历史"></span>
## 2.1 Open query history

In the visual query editor, click the button in the upper left corner to open the query history pop\-up window, as shown below.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a16c8ed0834a4b19a134a85a1d1ee6f6~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/75a0d66eb61a47a1b612b24b2242f577~tplv-goo7wpa0wc-image.image) </span>

You can view information such as ID, query time, query status, visualization chart, and operations.

<span id="_2-2-查看查询历史操作详情"></span>
## 2.2 View details of query history operations

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/138ac6cb547248158547f6c2ad1d4b45~tplv-goo7wpa0wc-image.image) </span>

First, in query history, you can click "Enter query" to access the specific visual query interface and further perform editing operations.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d57e6492dd254d3280b6d6854067ae8a~tplv-goo7wpa0wc-image.image) </span>

Second, you can also click "SQL details" to view the SQL details of the current visual query.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eef38486c630403fb601c6c9517c7fe4~tplv-goo7wpa0wc-image.image) </span>

Additionally, you can click "Log" to view the specific log information for this visual query.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/df1e96fb655d4eb785b9ef668dfe2e05~tplv-goo7wpa0wc-image.image) </span>
