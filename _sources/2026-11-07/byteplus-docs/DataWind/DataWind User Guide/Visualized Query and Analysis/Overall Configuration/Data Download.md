# 1. Overview

Data download allows users to download the results of visual queries to their local device. Currently, CSV, XLSX, and image formats are supported.

<span id="_3-功能介绍"></span>
# 3. Feature introduction

<span id="_3-1-下载数据"></span>
## 3.1 Download data

<span id="_3-1-1-文件类型"></span>
### 3.1.1 File types


* GBK\-encoded CSV: Number of rows <= 1,000,000; file size <= 500 MB.

* UTF\-8\-encoded CSV: Number of rows <= 1,000,000; file size <= 500 MB.

* XLSX: Number of rows <= 1,000,000; file size <= 200 MB. If the number of rows is large, file generation may take longer. Please wait patiently.


<span id="_3-1-2-下载行数"></span>
### 3.1.2 Number of rows to download

Users can modify the number of rows to download, subject to the maximum number of rows and file size allowed for each file type. It is recommended not to set the number of rows to the maximum, as this may slow down the download speed.

<span id="_3-1-3-科学计数"></span>
### 3.1.3 Scientific notation

To prevent issues with scientific notation due to excessively long data, if a numeric field in any row exceeds 11 digits, the field will be automatically converted to text type during download.

<span id="_3-1-4-高级功能-抽样下载"></span>
### 3.1.4 Advanced feature \- sample download

(1) Click Advanced Settings to expand the advanced feature settings.

(2) Sample download description: Evenly sample N rows from the visual query result set. For example, if the visual query result contains 200,000 rows and you download a sample of 10,000 rows, then one row is sampled for every 20 rows.

(3) Sampling download feature: Performance is relatively slow; if the query conditions and the number of rows to download remain unchanged, the download result will be the same each time.

<span id="_3-1-5-高级功能-排序-过滤"></span>
### 3.1.5 Advanced features \- sorting & filtering

**Functions**


* For any query, filter based on the list uploaded by the user, sort according to the uploaded order, and generate a file.

* Restriction priority: Download row limit \> user input \> query result.


**Usage steps**

First, enable sorting & filtering.

Second, select the column(s) to sort and filter.

Then, enter or upload the sorting list.

**Caution**

(1) Dimension filter options only support dimensions in the data panel.

(2) The query result will be re\-sorted (if sorting has already been applied, the previous sorting will become invalid).

(3) The uploaded list is only effective for this download.

**Special case description**

**Special case 1**. The query result contains only 50 rows, the user entered 100 IDs, and the download row limit was not changed, remaining at the default of 100,000 rows.

Download result: The output contains 100 rows, sorted according to the user input. If a corresponding query result is not matched, the other columns in that row will be empty.

**Special case 2**. The query result contains 100 rows, the user entered 50 IDs, and the download row limit is the default 100,000.

Download result: The file is generated by matching and sorting according to the 50 IDs entered by the user. Data outside the range of user input is not included in the downloaded data.

**Special case 3**. The query result contains 5,000 rows (one ID appears twice), the user entered 5,000 IDs, and the download row limit is the default 100,000.

Download result: The output contains 5,001 rows, sorted according to the user input, with one entry appearing twice.

**Special case 4**. The query result contains 50 rows, the user entered 100 IDs, and the download row limit is set to 50 rows.

Download result: Sorted according to the first 50 rows entered by the user. If one entry appears twice in the query result, only the first 49 rows entered by the user will be displayed.

### 3.1.6 Advanced features \- data format

Select the decimal format when downloading data to ensure that the downloaded data matches the data format set in the chart, which can reduce secondary processing after exporting data and improve efficiency.

**Caution**


* Supported in version V2.91.0 and above

* If the option to apply scientific notation is selected in the download settings, scientific notation will be used for display by default, and the configuration item for retaining data format below will be hidden.

# 4. Troubleshooting common issues

<span id="_4-1-下载的-csv-是科学计数法"></span>
## 4.1 Downloaded CSV uses scientific notation

If the downloaded CSV file displays garbled text or long numbers (such as uid) in scientific notation when opened directly as a table, try the following steps:

Step 1 Go to the download folder, right\-click the file, and select Open With \- Text Editor.

Step 2 Press ctrl (cmd on iOS) + A to select all and copy the content.

Step 3 Open Excel, paste the content, click Paste Options, select (Use Text Import Wizard), and choose comma as the delimiter. To avoid scientific notation for long number fields, select the column in Step 3 and set it as text format.

Step 4 Click Finish and save the file.

<span id="_4-2-提取文件转圈"></span>
## 4.2 File extraction spinning

When CSV downloads exceed 100,000 rows, file extraction may keep spinning. It is recommended to narrow the download range.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/73241fcf69b54caabacbd58a02857f60~tplv-goo7wpa0wc-image.image) </span>

More improvement methods:

(1) Download using the browser's incognito mode, as some plugins may cause download issues in the browser.

(2) Refresh the page, upgrade the browser, and clear the cache.

(3) Switch browsers; you can try using Firefox for this operation.

<span id="_4-3-excel-下载的数据带有-号"></span>
## 4.3 Downloaded data in Excel contains = sign

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e3a950bdadc54f7ba676acffbbdc124d~tplv-goo7wpa0wc-image.image) </span>

This issue is caused by scientific notation. In Excel, numbers greater than one billion are displayed in scientific notation. Therefore, add an equal sign (=) to force conversion to a string type. It is recommended to disable scientific notation. Alternatively, after downloading the CSV, open it with Excel and refer to case 1 above; or download the Feishu format, then download the Excel file from the Feishu spreadsheet.
