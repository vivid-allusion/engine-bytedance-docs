<span id="_1-概述"></span>
# 1. Overview

Indicator filtering can be used to filter based on the calculated indicator values displayed on charts, or based on the detailed data in the dataset.

<span id="_2-快速入门"></span>
# 2. Quick start

**Step 1** Drag the filter field into the filter configuration bar

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f1e6f3c565e343c9beb2706c7aec4de2~tplv-goo7wpa0wc-image.image) </span>

**Step 2** Select the filtering method: "Result filtering" or "Detail filtering"

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0d179c442ceb45d6a9060fc9ad3b9912~tplv-goo7wpa0wc-image.image" width="610px" /></div>


**Step 3** Set the filter conditions and click OK to apply

<span id="_3-功能介绍"></span>
# 3. Feature overview

<span id="_3-1-结果筛选"></span>
## 3.1 Result filtering

**Feature description**: Filtering is based on the aggregated indicator results, that is, the **aggregated indicator values** displayed on the chart are filtered.

**Example**: Filter data where the order quantity is greater than 2,000

Drag the order quantity into the filter bar, select result filtering, and click OK to apply

<span id="_3-2-明细筛选"></span>
## 3.2 Detail filtering

**Feature description**: Filtering is based on the original indicator values, that is, the **original detail data** in the dataset are filtered.

**Example**: Filter orders where the order quantity is not equal 3.

Drag the order quantity into the filter bar, select detail filtering, and click OK to apply
