<span id="_1-概述"></span>
# 1. Overview

The product supports multi\-level OR/AND filtering to meet filtering needs under complex conditions.

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-配置过程"></span>
## 2.1 Configuration process

(1) After configuring the chart, click "Filter" in the filter bar to enter the combination filter configuration page.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d9569b9378e14cdb9eaa8a3c217d1c53~tplv-goo7wpa0wc-image.image) </span>

(2) Click "Filter" to add a combination filter as needed. You can add filter items or filter groups according to your requirements.


* For example, the current requirement is to filter data where "Province" is Jiangsu Province and "Primary Channel" is Marketing Activity **or** "City" is Hangzhou and "Secondary Channel" is Personalized Poster.

* According to the above requirement, you need to add two filter groups, each with two filter items.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b462b3c24e443b59d9af0ed17c98ec0~tplv-goo7wpa0wc-image.image) </span>


(3) Configure the filter conditions as required.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/44741192438f444eb47e26a76d21d4ca~tplv-goo7wpa0wc-image.image) </span>

(4) Click AND or OR to switch the logical relationship.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9676d912938540f484f492c9ef218fbd~tplv-goo7wpa0wc-image.image) </span>

(5) After completing the configuration, click Confirm to activate the combination filter. At the same time, a new combination filter will be added to the filter bar. Click the combination filter to reconfigure it as needed.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d0e227e8de8e42d8961bc1b6a58b35ac~tplv-goo7wpa0wc-image.image) </span>

(6) Click "Filter" again to add multiple combination filters.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b1687377d3c449a2be7bb79881e692ea~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-2-取消筛选"></span>
## 2.2 Remove filters

When you hover the mouse over the combination filter capsule, a close icon will appear on the right side of the capsule. Click it to remove the filter condition.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6d0bf9ba595b4271a40d5f8bcf5ad807~tplv-goo7wpa0wc-image.image) </span>
