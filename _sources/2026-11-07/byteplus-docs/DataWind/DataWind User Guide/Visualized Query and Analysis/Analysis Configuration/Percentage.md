<span id="_1-概述"></span>
# 1. Overview

A percentage indicates how much one value is as a percentage of another value. It is also known as a percentage rate or percent. DataWind provides a percentage analysis component that supports quickly calculating the proportion of specified data in the total.

<span id="_3-功能介绍"></span>
# 3. Feature introduction

<span id="_3-1-计算依据"></span>
## 3.1 Calculation basis

You can set the calculation basis to all data or currently displayed data.


* All data: Calculate the proportion based on all data, that is, percentage = cell value / sum of all data in the column. The calculation is not limited by top N or limit N.

* Currently displayed data: Calculate the proportion based on currently visible data, that is, percentage = cell value / sum of the data currently displayed in the column.


<span id="_3-2计算指标"></span>
## 3.2 Calculation metric


* Select the metric(s) for percentage calculation; multiple selections are supported.
