<span id="_1-概述"></span>
# 1. Overview

To make data charts clearer and easier to understand, it is often necessary to add reference lines such as target lines, control lines, and average lines to charts, thereby assisting with analysis and improving the readability of the graphics. The reference line component provided by the product supports configuring reference lines for column charts, bar charts, line charts, area charts, dual\-axis charts (currently not supported), combo charts, and scatter plots.

<span id="_2-快速入门"></span>
# 2. Quick start

<span id="_2-1-普通参考线"></span>
## 2.1 Standard reference line

**Step 1**: Click Add Reference Line, move the mouse to the desired position in the chart, and click to add.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4fe3263dd9f14abfb0623561a1419e58~tplv-goo7wpa0wc-image.image) </span>

**Step 2**: Set the calculation method to Average, and click Apply.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/81da279d55514c1a980e2cb34a2c0eb8~tplv-goo7wpa0wc-image.image) </span>

**Step 3**: Click Add Reference Line. You can set multiple reference lines.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f7a8b735c38e40b788b725f31465bf70~tplv-goo7wpa0wc-image.image) </span>

**Step 4**: Click a reference line to edit or delete it.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fd02dcd70dca49f0ac26acc05a3731e1~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-功能介绍"></span>
# 3. Feature introduction

<span id="_3-1-参考线名称设置"></span>
## 3.1 Reference line name settings

Supports modifying the display name of the reference line

<span id="_3-2-计算方式设置"></span>
## 3.2 Calculation method settings

Calculated value: Calculate based on a specific metric. Supports average, maximum, minimum, and sum. Fixed value: Enter any fixed value as the reference line size.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a48df2eb4234054a1687a630d2f0f42~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-3-样式设置"></span>
## 3.3 Style settings


* Line style: Supports modifying color, thickness, and line type.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b9049f9320784584aa7124b66e105e56~tplv-goo7wpa0wc-image.image) </span>


* Label display: Supports displaying the name and value, and configuring the data format.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/df44b0c4f7e04a388cc2ab19fbe1c5c2~tplv-goo7wpa0wc-image.image) </span>

Data format: The default is Auto, which is consistent with the metric capsule format. You can manually set it to number, percentage, per mille, or raw value.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9c9c9ad9ce5d4ce9982f891ceabcfcc1~tplv-goo7wpa0wc-image.image) </span>


* Label font: You can set the font size and color of the label.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/74148b15f4e842189997047ad79b5374~tplv-goo7wpa0wc-image.image) </span>
