# Feature overview

In the dashboard viewing area, users can quickly preview and view dashboard content, as well as perform collaborative sharing, subscription, and alert operations. Specific operations include: refresh, full screen, authorize, share, edit, subscribe, alert settings, and exploration and analysis based on charts.

# Dashboard viewing operations

<span id="_2-1-整体操作"></span>
## Overall operations

The overall operation buttons in the viewing area are located in the upper right corner of the interface, and only functions that the current user has permission to access are displayed here.

<span id="_2-1-1-刷新"></span>
### Refresh

Click "Refresh" to manually refresh the charts and data content within the dashboard.

<span id="_2-1-2-全屏"></span>
### Full screen

Click "Full screen" to enter full screen mode to view the dashboard. In advanced dashboards, the button in the lower right corner of full screen mode allows you to adjust between "Adaptive width" or "Actual size" display.

Note: This feature is supported from V2.50.0 and later.

### Authorize

For details, see [Dashboard Viewing Operations](https://docs.byteplus.com/docs/DataWind/Dashboard_Viewing_Operations).

<span id="_2-1-4-分享"></span>
### Share

**Usage scenario**


* To quickly share dashboard content with other users in the group for immediate access.

* When sharing a dashboard, it is desirable to retain the filter settings to ensure that both the sharer and the recipient see the same content.


**Feature description**

Click "Share" and share the access link with other users.

<span id="_2-1-5-编辑"></span>
### Edit

Click "Edit" to recreate, modify, or adjust the layout of the dashboard.

## Collaborative sharing settings

<span id="_2-2-1-书签"></span>
### Bookmark

**Usage scenario**


* Supports saving commonly used filter criteria as bookmarks for quick access.

* Supports publicly displaying common filter criteria within the department for use by all users in the project.


**Create a new bookmark**


1. Open the dashboard where you want to set a bookmark, and click the "Bookmark" option in the drop\-down menu in the upper right corner.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cd07513c71824f11ad11d933af68ba23~tplv-goo7wpa0wc-image.image) </span>

2. On the bookmark management page, click "New bookmark."

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bc20476d61c34ba8b3ae9460998adcf9~tplv-goo7wpa0wc-image.image) </span>

* Set as default: Select "Set as default" to automatically display the filter criteria defined by this bookmark when opening the dashboard.

* Set as public: Select "Set as public" to make the bookmark a public bookmark, allowing all users with dashboard viewing permissions in the project to view and use this bookmark.


(3) Click "Save" to save the current view's filter criteria as a bookmark.

**Modify bookmark settings**


* Personal bookmarks: Users can set a specific bookmark as default, make it public, rename, or delete it.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/653f80a735304c82b0e6eb92cb15ac6a~tplv-goo7wpa0wc-image.image) </span>

* Public bookmarks

   * Public bookmarks created by the user: You can set as default, make public, rename, or delete.

   * Public bookmarks created by others: Only setting as default is supported.


**Apply bookmarks**

Double\-click the bookmark you want to apply to set its filter criteria in the dashboard.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a0012e4364d14ccca498a4dab2d439b8~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-2-8-公告配置"></span>
### Announcement configuration

The announcement feature supports displaying announcement pop\-ups in both the visual query panel and the dashboard panel. Users can set up and view announcements to improve the delivery of key information.

This section introduces the announcement configuration operations for the dashboard. For the announcement configuration operations of visual queries, see [Announcement Configuration](https://docs.byteplus.com/docs/DataWind/Announcement_Configuration).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2026ae41527b466d8eb3ce4d61287a18~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/976a2344887e4090ada6d401063f52b0~tplv-goo7wpa0wc-image.image) </span>


1. **Announcement display**


Announcement display provides two style types: normal and alert.

Announcements provide two reminder methods: floating window (top right) and pop\-up window (centered).


* After you manually close the pop\-up window, it will not be displayed again on your next visit.

* When the content of the announcement (title or body) is updated, this rule will be reset.

2. **Viewing announcements**


After you close an announcement, you can view it in the More menu.


* The "View announcement" entry is displayed only when announcements are enabled on the dashboard and within the validity period.

* Entry permission: view\-only permission for the dashboard.

3. **Announcement settings**


You can set announcements in the More menu.


* Entry permission: edit permission for the dashboard.


Please complete the following configuration items:


* Title: up to 30 Chinese characters

* Body: up to 300 Chinese characters

   * Supports undo and redo

   * Supports bold, italic, underline, and inserting hyperlinks

* Reminder methods: supports two styles, floating window (top left) and pop\-up window (centered)

* Style types: normal and alert

* Reminder frequency: supports only once, once every 7 days, or once every 30 days

* Validity period: disabled by default

   * After enabling, you can set a date range. (The default is from 00:00 on the current day to 23:59:59 seven days later.)

   * After enabling, the announcement will be displayed only when users access within the validity period.

4. **Other notes**

* The announcement will also appear in embedded mode.

* Copying or importing/exporting dashboards does not include announcements.

# Chart operations within dashboards

A dashboard can be composed of various components, with the most critical component being the data chart. Charts within the dashboard also support related operations.

The core operations include four categories:


1. Add comments

2. Quick query

3. Chart editing

4. Other operations. Operation button entry: Hover the mouse over the upper right corner of a chart, and when the "More" button appears, click it to open the pop\-up window.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1402539af07340c296e4d38ba7e47b55~tplv-goo7wpa0wc-image.image) </span>

Note: For table\-type charts, when you hover the mouse over a header cell, the "Header sort" and "Freeze" buttons will appear.

<span id="_3-1-添加评论"></span>
## Add comments

After clicking the comment operator in the upper right corner of a chart, the comment panel on the right will open. You can mention a colleague's Lark name in the comment (provided Lark integration has been completed) for quick and convenient interaction.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9e6b7089ce934be5a9777ec84fbbf986~tplv-goo7wpa0wc-image.image) </span>

<span id="76691c8f"></span>
## Quick query

To temporarily modify filters, change granularity, or adjust aggregation methods for a chart for ad hoc viewing, use quick query to operate on the chart. Quick query only takes effect temporarily on the current page and does not affect the original chart. When you refresh the page or re\-enter the dashboard, the chart will revert to its original state.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7ba2382ddf584e04a97a7299ed2d8e3b~tplv-goo7wpa0wc-image.image) </span>

Operation steps: Click Quick Query, locate the operation item, select the desired operation, and then click "Apply" to perform a quick query.


* **Supported quick query operations**: Modify filter, add filter, switch chart style, change date granularity, add dimension, replace dimension, add metric, change aggregation method, replace metric, drill down

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b43a821c86849d2a580f5e853a46e3d~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-3-3-复制到仪表盘"></span>
### Copy to dashboard

**Usage scenarios**


* To make minor modifications to a chart in a public dashboard and add it to your own dashboard

* To add the current content (metric definitions and chart configuration) of a chart in the dashboard to your own dashboard


**Feature description**


* First, hover the mouse over the "More" button to open the function menu, and click "Copy to dashboard".

* Next, you need to give this chart a new name; if you keep the default, it will be the same as the original. Then select which dashboard to copy it to, check "Chart style follows dashboard theme", and then click Confirm.

* Finally, the system will create a new chart and add it to the dashboard you specified.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d2777e38e3fc4687b110e636fb6d1f21~tplv-goo7wpa0wc-image.image) </span>


**Permission requirements**

To complete this operation, you need at least view permission for the dataset to which the chart belongs, and edit permission for the new dashboard.

<span id="_3-3-4-新建监控"></span>
### Create monitoring

The user can click to monitor fluctuations in specified dimensions or metrics of a chart.

⚠️Caution: Only dashboard charts that meet the following conditions will display the entry for creating monitoring.


* The user must have view or higher permission for the dashboard.

* The specified chart must meet the prerequisites required for monitoring: (1) The underlying table must be updated regularly; (2) The date filter must be set to 'recent' or 'recent with data'.
