<span id="_1-概述"></span>
# 1. Overview

In the dashboard list area (directory area), users can create dashboards, add dashboards to favorites, authorize, and perform other operations, enabling flexible management and maintenance of dashboards.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/42bca442dfcf4e14a9fc3436d4706899~tplv-goo7wpa0wc-image.image) </span>

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Different permissions are required for different operations on dashboards. For details, refer to <a href="https://docs.byteplus.com/docs/DataWind/Detailed_Explanation_of_Permission_Features">Detailed Explanation of Permission Features</a>.</div>


<span id="_2-功能介绍"></span>
# 2. Feature overview

<span id="_2-1-新建仪表盘"></span>
## 2.1 Create a dashboard

**Steps**

(1) Click the "+" icon at the top of the dashboard directory area to create a dashboard or folder.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a8935ca5c7b94318a440289360d3fdd1~tplv-goo7wpa0wc-image.image) </span>

(2) Enter the required information for the new item:


* To create a dashboard: Enter a name and select a path. (The path refers to the location where the item is stored in the directory or list.)

* To create a folder: Enter a name and select a path. (The path refers to the location where the item is stored in the directory or list.)


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">By default, content in a personal dashboard is only visible to the user, while content in a public dashboard can be shared and collaborated on with others.</div>


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/882cf07523424243bbe7b88112cb2e76~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-2-收藏仪表盘"></span>
## 2.2 Add a dashboard to favorites

**Usage scenario**

Add key dashboards to favorites: Mark dashboards that require special attention as favorites, and click "Show only my favorites".

**Steps**

(1) Hover the mouse over the name of a dashboard, then click the star icon after the dashboard name to add it to favorites.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5967fe6b55b243869b08d9f11370f285~tplv-goo7wpa0wc-image.image) </span>

(2) Select "My favorites" at the top of the list area to display all dashboards you have added to favorites.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/789372c8575243cfad0e19c1b23a49d1~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-3-重命名仪表盘"></span>
## 2.3 Rename a dashboard

**Steps**

Hover the mouse over the "More" button to open the function menu, and click "Basic information". In the pop\-up window, modify the dashboard name to complete the renaming.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a2261c3f5c6841b68ee4a7f7b3d5ca6d~tplv-goo7wpa0wc-image.image) </span>

## 2.4 Dashboard tags

You can set tags for dashboards to categorize them, and search by tags is supported on both PC and mobile devices.

**Set tags:** 

Hover the mouse over the "More" button to open the function menu, and click "Basic information". In the pop\-up window, click "Tags" and select the desired tags to set them.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/89884b1285b147138aed13fd80d82a77~tplv-goo7wpa0wc-image.image) </span>

**Manage/Create tags:** 

Click "Tag management" in the lower right corner of the pop\-up window to edit, delete, or create tags.

<span id="0786c3cc"></span>
## 2.5 Edit a dashboard

In V2.91.0 and later versions, hovering over the "More" button brings up the function menu. Clicking "Edit" allows you to enter the dashboard editing page, which has the same functionality as the edit button in the upper right corner of the viewing area. If another user is currently editing, the "Edit" entry will be grayed out, and hovering will prompt the user: "xxx is editing the dashboard." For detailed editing instructions, please refer to [Dashboard Editing Overview](https://docs.byteplus.com/docs/DataWind/Dashboard_Editing_Overview).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f2c68036c6b140b598ea5af394b4a1b3~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-4-移动仪表盘"></span>
## 2.6 Move dashboards

**Operation steps**

The following two methods for moving dashboards are supported:


* Select the dashboard and drag it;

* Hover over the "More" button to bring up the function menu, click "Move", modify the path of the dashboard or folder, and complete the move.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">The path between a personal dashboard and a public dashboard can only be modified by moving, but the order and path within each dashboard can be adjusted by dragging and dropping.</div>


<div data-tips="true" data-tips-type="warning">Only dashboards for which the user is the creator can be moved into their own personal dashboard.</div>


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d681db37484d4c6aad26dbf37e48a440~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-5-复制仪表盘"></span>
## 2.7 Copy dashboards

**Usage scenarios**


* Each business line or country/region often needs to view the same reports, but to ensure that each views only their own data range, it is necessary to copy them into different dashboards to meet this requirement.

* If you see a dashboard created by someone else that you need, but require some minor modifications, you can copy it to your own dashboard and then make changes.


**Function description**

Hover over the "More" button to bring up the function menu, and click "Copy Dashboard". You can modify the name of the new dashboard in the pop\-up window.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/68382c8dfd0043baad7e7a188bb0af6c~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5b164ba6859d4ab5899b30b6f2158c08~tplv-goo7wpa0wc-image.image) </span>

**Permission control**

(1) Permissions required to copy a dashboard: management permissions for the dashboard to be copied

(2) Permissions required to copy chart content: view permissions for the datasets to which the charts in the dashboard belong

(3) Permissions required to create a new dashboard/chart: project permissions

## 2.11 Set redirection

In V2.91.0 and later versions, click "More" \> "Set redirect" on the dashboard to configure a redirect address for dashboards with edit permissions. Only view\-mode URLs will be redirected; edit\-mode URLs, third\-party embedded URLs, and mobile access will not be redirected. When a user accesses the dashboard view page, the system will automatically redirect to the preset redirect address; if the current dashboard is offline, the system will guide users to the new dashboard address.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/15ff9de0e86a43b39855c0396e606f87~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-仪表盘分组说明"></span>
# 3. Dashboard grouping overview

<span id="_3-1-个人仪表盘"></span>
## 3.1 Personal dashboards

**Usage scenarios**

(1) Content of personal interest that is not suitable to be placed in public dashboards.

(2) Documents that are partially edited and not yet ready to be placed in public dashboards.

**Usage restrictions**

Can be shared with other users, but other users cannot edit them. After sharing, they will appear in shared dashboards.

<span id="_3-2-与我共享（共享仪表盘）"></span>
## 3.2 Shared with me (shared dashboards)

**Usage scenarios**

Dashboards shared with you.

**Usage restrictions**

Can only be viewed; dashboards cannot be modified or moved.

<span id="_3-3-公共仪表盘"></span>
## 3.3 Public dashboards

**Usage scenarios**

Dashboards built by data analysts, data BPs, business analysts, and other professionals, suitable for systematic report building and for regular users to view.

**Usage restrictions**

To collaboratively edit or manage dashboards with others, place the folder or dashboard under "Public dashboards" and grant the corresponding permissions.
