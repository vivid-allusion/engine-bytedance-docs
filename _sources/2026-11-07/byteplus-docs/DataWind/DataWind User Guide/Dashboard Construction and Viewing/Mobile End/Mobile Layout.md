# 1. Overview of mobile layout

This product provides mobile functionality, allowing users to flexibly configure mobile layouts. If mobile layout optimization is not performed, dashboards created on the PC will, by default, use a **fixed\-size, fluid layout** when viewed directly on a mobile device. To provide a better user experience and achieve more varied presentation effects on mobile devices, this product offers mobile layout configuration capabilities, enabling users to independently design the presentation layout and effects of dashboards specifically for mobile devices.

**Common application scenarios**


* **Enhance the mobile data consumption experience**: Avoid issues such as oversized metric cards or charts that are too wide and scaled down, which can reduce chart readability in the default layout, and improve the sense of design and aesthetics on mobile devices.

* **Build a management dashboard**: Fine\-tuned mobile layout configuration enhances the experience for managers, making it easier for multiple management levels to focus on key metrics. Key metrics and specific charts are arranged logically, enabling targeted information delivery and improving the efficiency of obtaining critical information.


<span id="_2-快速入门"></span>
# 2. Quick start

**Step 1:**  On the PC, open the dashboard that requires layout adjustment and enter edit mode.

**Step 2:**  On the edit page, click the mobile phone icon in the upper right corner to enter mobile layout mode.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/71515d5e35d5487385f92a39622bddf5~tplv-goo7wpa0wc-image.image) </span>

**Step 3:**  On the PC, you can manually drag and adjust the layout on the canvas. After making adjustments, click Save to view the presentation effect on the mobile device.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/da0b0138347e4d499054bacae3bdb6c3~tplv-goo7wpa0wc-image.image) </span>

Caution: After saving the mobile configuration, any operations performed on the advanced dashboard on the PC (including format adjustments and chart deletions) will not take effect on the mobile side. To apply these changes to the mobile side, you must manually enter the mobile layout page and add them from the left panel.

# 3. Feature details

<span id="_3-1-图表编辑"></span>
## 3.1 Chart editing

In the editing canvas in the middle of the page, users can adjust the format of charts.


* Select the chart and drag it to adjust its placement.

* Click the border and drag to adjust the chart size.


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_f0443e1ce6329fdc7cd4cfec796d2194.png) </span>

<span id="_3-2-图表-图片设置"></span>
## 3.2 Chart/image settings

The user can format the currently selected chart.


* Chart title: When "Show title" is selected, the chart name will be displayed, and the title font size and color can be adjusted.

* Indicator style, line style, display mode, and other options: Depending on the chart type, configuration options specific to the chart will be available for adjustment.

* Transform: Adjust the chart position (X, Y) as well as the chart's width and height.

* Appearance: Adjust the chart background color, corner radius, border color, and border thickness.

* Anchor: After enabling, you can set the chart's position as an anchor point, making it easier to locate the corresponding position on mobile devices.

<span id="_3-3-图层调整"></span>
## 3.3 Layer adjustments

The user can drag to adjust the order of component layers.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b83329da0e3643869dd508f9a4918e91~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-4-组件删除与恢复"></span>
## 3.4 Component deletion and restoration

The system provides two ways to delete components:


* Select the desired component on the editing canvas and click the delete button in the upper right corner.

* In the layer list on the left, click the preview button to hide the component.


The user can click the preview button again in the layer list on the left to restore the hidden component.

<span id="_3-5-锚点设置"></span>
## 3.5 Anchor settings

Set up quick\-jump anchors within the page to improve reader navigation efficiency. Click the chart that needs to be set as an anchor, enable the anchor in the chart settings area on the right, and an anchor will be generated on the page. When the user selects this anchor, the page will automatically jump to the current chart's position.

## **3.6 Tab page settings**

To adjust the mobile layout, use the tab page component and click the "dropdown" button to view all current tab pages. When the target tab page is clicked, the selection panel will collapse and switch to the corresponding tab page.

<span id="fa101819"></span>
## 3.7 Pager settings

Users can configure the pagination control for the table. After enabling the pagination control, click the "Left" or "Right" icon to select the previous or next page, or click the page number area to bring up the pagination overlay, where you can select and jump to the corresponding page.
