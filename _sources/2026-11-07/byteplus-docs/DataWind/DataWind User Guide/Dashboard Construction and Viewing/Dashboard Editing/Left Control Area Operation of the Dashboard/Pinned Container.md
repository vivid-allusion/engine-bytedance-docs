# 1. Overview

In the dashboard module, the "Pinned container" is provided to support pinning components for display at the top. When scrolling through the report page, pinned components will always be displayed at the top of the page, allowing users to quickly access important content and improving the efficiency of information browsing and usage.

<span id="e10fe6fe"></span>
# 2. Quick start


* **Step 1:**  Go to the dashboard editing page and select the pinned container component from the component panel on the left.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e2cd101ca2e041678db3a33c910399b6~tplv-goo7wpa0wc-image.image) </span>


* **Step 2:**  Select the component you want to pin (either an existing component on the canvas or a newly created component from the left toolbar), then drag and drop it into the pinned container. The component will be pinned successfully.

# 3. **Feature overview**

<span id="7ae04a82"></span>
## 3.1 Height and width adjustment

You can adjust the height of the pinned container by dragging, or manually enter an exact height value. The width of the pinned container follows the width of the canvas.


* When the height of the pinned container is less than the height of the content inside the container, a vertical scrollbar will appear in the pinned container.


<span id="c4a3e7f9"></span>
## 3.2 Layout mode

The layout mode of the pinned container follows the layout mode of the canvas.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ba663ec164614aab90015d8cc04ef939~tplv-goo7wpa0wc-image.image) </span>

<span id="a272e4fe"></span>
## 3.3 Usage restrictions

Only one pinned container can be added to the page. If there is already a pinned filter (or parameter/query container/dynamic dimension metric) on the page, adding another pinned container is not supported. Please unpin or delete the existing one first.
