# 1. Overview

The new dashboard editing interface is divided into the top navigation area, the left widget area, the central canvas area, the right page configuration area, and the bottom multi\-page editing area.

This article introduces the top navigation area. As shown in the figure below, the area marked in green at the top is the top navigation area. The specific operations will be introduced below from left to right:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/80564cafbb974a9dad853dda3d146f88~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-操作说明"></span>
# 2. Operation instructions

<span id="_2-1-仪表盘重命名"></span>
## 2.1 Rename the dashboard

After creating a new dashboard, you can modify the dashboard name in the editing interface by clicking the name.

<span id="_2-2-步骤撤销与前进"></span>
## 2.2 Undo and redo steps

You can undo to the previous step or redo to the next step according to the operation steps on the dashboard page.

<span id="_2-3-图层顺序"></span>
## 2.3 Layer order

When you need to stack widgets, you can adjust the layer order to determine the vertical hierarchy of each widget.

In addition to clicking in the interface, you can also use keyboard shortcuts. The specific shortcuts are described in the figure below.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4f0fbe2fd1db46ce82516447f744e43b~tplv-goo7wpa0wc-image.image) </span>

The operations and effects are as follows:

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_333eef57ef23800280a1a78488995c90.gif) </span>

<span id="_2-4-控件组合"></span>
## 2.4 Widget grouping

You can group multiple chart widgets into one to move them together, configure colors, and perform other operations. Select multiple widgets at the same time, then click the "Group" button in the widget area or use the shortcut Ctrl+G to group them.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8bd1e88b5cd9428599d8c9b53f732b95~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-5-对齐方式"></span>
## 2.5 Alignment methods

When selecting multiple widgets at the same time or holding down the command/ctrl key to select multiple widgets, the alignment function will be enabled.


* The widget spacing setting can adjust the spacing to make three or more elements equally spaced, including horizontal and vertical distribution.

* The widget alignment setting can align two or more elements, including three types of alignment in both the vertical and horizontal directions: left alignment, vertical center alignment, right alignment; top alignment, horizontal center alignment, and bottom alignment.


<span id="_2-6-页面缩放"></span>
## 2.6 Page zoom

Click the plus or minus sign for zoom to control the scale of the content on the canvas.

<span id="_2-7-替换数据集"></span>
## 2.7 Replace dataset

The data set behind the chart in the dashboard can be replaced. For detailed instructions, see [Replace Dataset](https://docs.byteplus.com/docs/DataWind/Replace_Dataset).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/347482b0e95f4f2389f5c0aef30bf6e7~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-8-页面配置"></span>
## 2.8 Page configuration

Click to access the overall page configuration. The detailed feature descriptions and operations are consistent with those of the central canvas area in dashboard editing.

<span id="_2-9-移动端布局"></span>
## 2.9 Mobile layout

When the PC configuration is displayed on mobile, there is a default layout. Click Mobile layout to set the chart layout for mobile. For detailed feature descriptions, see [Mobile Layout](https://docs.byteplus.com/docs/DataWind/Mobile_Layout).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f9dcc9bf136d4a709074d7f684dd40f2~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-10-预览与保存"></span>
## 2.10 Preview and save

Click Preview to enter the preview page of the dashboard. Click Save to save all page configurations. If you reopen the page, the "Previous" and "Next" functions will not work. If you click Save and remain on the page, the "Previous" and "Next" functions will still work.
