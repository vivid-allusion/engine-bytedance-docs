# 1. Overview

The new dashboard editing interface is divided into the top navigation area, the left widget area, the central canvas area, the right page configuration area, and the multi\-page editing area at the bottom.

This document will introduce the multi\-page editing area at the bottom. Multi\-page is also referred to as multi\-sheet page or multi\-tab page. As shown in the figure below, the unmarked area at the bottom is the multi\-page editing area. The specific operations for multi\-page editing are as follows:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/20c2c89b5ced462e947582e597d668eb~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-操作说明"></span>
# 2. Operating instructions

Users can add new pages within the dashboard and view data content on different pages of the same dashboard by switching the page navigation bar.

<span id="_2-2-添加页面"></span>
## 2.1 Add page

On the dashboard editing page, click the "Add" button in the page navigation bar below the canvas to add multiple pages to the dashboard (it is allowed to add the same chart to different pages within the same dashboard).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3da7f5bcbc5c45e6b1435aeb63b28dc0~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-3-复制页面"></span>
## 2.2 Copy page


* Copying sheet pages within the same dashboard: Dashboard editors can directly copy a page, generating a new page with an identical layout and arrangement next to the original page.

* Copying sheet pages across dashboards is supported in version V2.50.0 and later.

   * While in dashboard editing mode, dashboard administrators can choose to copy this sheet page to another dashboard.

   * In editing mode, click "Copy to another dashboard", fill in the name of the copied page in the pop\-up window, select the target dashboard for copying, and choose whether to generate a copy of the pasted chart (a copy is generated by default).

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ea7a2f6e1c334dbeb144418254d58dae~tplv-goo7wpa0wc-image.image) </span>


<span id="_2-4-跨页面复制-剪切"></span>
## 2.3 Copy/cut across pages

Copying and cutting widgets across pages is supported, including charts, text, web pages, images, and more. Users can select a widget by clicking with the mouse, then right\-click to copy or cut, or use keyboard shortcuts to copy or cut.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d0065b8e610043e98817eb78261aed45~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-5-修改页面名称"></span>
## 2.4 Rename page

You can double\-click the page name to modify it, or right\-click and select Rename.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/185b160a4bbf4ab39624ae5e2ee38974~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-6-改变页面顺序"></span>
## Change page order

When there are multiple sheet pages, you can drag and drop pages directly to change their order in edit mode. In view mode, the page on the far left will open by default

<span id="_2-7-隐藏页面"></span>
## Hide pages

When there are multiple sheet pages, dashboard editors can choose which pages to display to viewers and temporarily hide pages they do not want to display.


* Right\-click and select Hide. The page will no longer be displayed in view mode.

* To unhide a page, right\-click and select Unhide.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd9e6b9674a94318be5cc808705cfafc~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-8-删除页面"></span>
## Delete pages

When there are multiple sheet pages, you can delete a page by right\-clicking and selecting Delete. Text, charts, and other content on the page will also be deleted. Charts will be removed from the page but can be selected and added again.
