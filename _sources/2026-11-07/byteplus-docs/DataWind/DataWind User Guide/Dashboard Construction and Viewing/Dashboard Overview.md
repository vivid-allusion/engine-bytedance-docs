This article provides an introduction to the overall functionality of dashboards. Here, you can view the dashboard feature list, use cases, quick start, and page layout.

<span id="c9133646"></span>
# Functionality overview

A dashboard can be understood as a blank canvas where charts created from visual queries can be displayed together on a single dashboard.


* It supports adding other components to the dashboard, such as rich text, images, tabs, web pages, and more, allowing you to create a dashboard with rich content.

* It supports enhancing the functionality and usability of the dashboard by using public filters, global parameters, and global dynamic dimensions within the dashboard.

**Use cases**:


* Data analysts can consolidate their data analysis approaches into public dashboards for team members within the project to monitor product and business progress.

* Project owners can regularly review project reports and use data to drive business operations.

* Operations team members can query detailed data from summary dashboards to carry out operational activities.

# Quick start


1. Click "Dashboard" in the system navigation bar to enter the dashboard module.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/89c6ac452ecf48f8a2e3f224d122df6d~tplv-goo7wpa0wc-image.image) </span>

2. On the dashboard viewing page, select the dashboard to view from the directory area on the left, and view the specific content of the dashboard in the viewing area on the right.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f0548799f92b4c56addee431f7df0ff7~tplv-goo7wpa0wc-image.image) </span>

3. For existing dashboards, you can click the "Edit" button in the upper right corner of the dashboard preview page to enter the dashboard editing page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/59dccd6b7f1748ac9ae5801fc755a537~tplv-goo7wpa0wc-image.image) </span>

4. You can also click the "+" icon in the upper right corner of the directory page to create a new dashboard.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/47d4b734e0da4bf4b75f2cbc65904438~tplv-goo7wpa0wc-image.image) </span>

# Page layout

<span id="3f81f688"></span>
### Dashboard directory page

Entry: Click the "Dashboard" tab in the system navigation bar; the dashboard directory page is on the left.

Functionality: You can create, favorite, authorize, move, and rename dashboards within the project. For detailed operation instructions, see [Dashboard List Operations](https://docs.byteplus.com/docs/DataWind/Dashboard_List_Operations).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/22d7611fee204c86abc02ce7bdf4b6d9~tplv-goo7wpa0wc-image.image) </span>

<span id="30b9abbc"></span>
### Dashboard viewing page

Entry: Click the "Dashboard" tab in the system navigation bar; the dashboard viewing page is on the right.

Function: Allows previewing, subscribing, authorizing, and other operations for the selected dashboard. For detailed instructions on these operations, see [Dashboard Viewing Operations](https://docs.byteplus.com/docs/DataWind/Dashboard_Viewing_Operations).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ddb2b1ace54c4a89b9e4eafc178bb5e3~tplv-goo7wpa0wc-image.image) </span>

<span id="53734a97"></span>
### Dashboard editing page

Entry: On the dashboard viewing page, view the dashboard and click the "Edit" button in the upper right corner to enter the dashboard editing page.

Function: Select charts and other widgets, set the dashboard layout and style. For details, refer to [Dashboard Editing Overview](https://docs.byteplus.com/docs/DataWind/Dashboard_Editing_Overview).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6e3b9a9651384857ad5613bdee608dff~tplv-goo7wpa0wc-image.image) </span>
