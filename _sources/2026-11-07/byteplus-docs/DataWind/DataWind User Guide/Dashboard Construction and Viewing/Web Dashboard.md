# 1. Overview

As a type of dashboard, the web dashboard allows embedding and displaying the URLs of other dashboards or web pages, and **does not include an operation bar**, providing more display space for the embedded content. Users can copy the embed link of a dashboard under a specific project and then create a web dashboard in another project, enabling a dashboard to appear in the public dashboard lists of multiple projects without switching between projects to view dashboards. It is also possible to embed different web page URLs, Feishu documents, and multi\-dimensional spreadsheets.

**Supported web page types**: dashboards, web pages, cloud documents

**Display effects**: Embedded dashboards support interaction and filtering, and **embedded web pages also support direct interactive operations within the dashboard**, such as searching for information on the website or clicking hyperlinks to navigate to content. Feishu documents or multi\-dimensional spreadsheets can be edited and collaboratively worked on with colleagues.

**Value**: The design without an operation bar allows users to focus entirely on the embedded content, whether it is key data charts from other dashboards or important information from specific web pages, presenting them in the purest form, reducing distractions, and improving the efficiency of information acquisition. Integrating key information from multiple sources eliminates the need to frequently switch between pages, enabling one\-stop information access and greatly enhancing work efficiency.

# 3. Feature introduction

<span id="70551866"></span>
## 3.1 Embed a dashboard using a web dashboard

**Step 1**, select the dashboard to be embedded, click More in the upper right corner \- Embed dashboard, and copy the embed link.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b957d4fc374e46c084b238c89b6ecfba~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b7e962b967146faa219da3c2dce3955~tplv-goo7wpa0wc-image.image) </span>

**Step 2**, click the plus sign above the dashboard list and select **Create a new web dashboard**. Enter a name, select a path, paste the dashboard's embed link into the web address field, and click Confirm to create it.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f212f375fedc44a591a258644c6702fa~tplv-goo7wpa0wc-image.image) </span>


* The content of the web dashboard mirrors the embedded dashboard. Therefore, if the original dashboard is modified, the web dashboard will be updated accordingly. If the original dashboard is deleted, the web dashboard will display "Dashboard has been recycled."

* In the web dashboard, the dashboard still supports interaction and filtering features. However, users cannot edit the dashboard content in the web dashboard, nor can they embed or copy the web dashboard again.

* The name of the web dashboard is only used in the dashboard list. In the dashboard display interface on the right, the dashboard name shown remains the name of the original embedded dashboard.


<span id="9ea0e934"></span>
## 3.2 Embed a website using a web dashboard

Steps: Click the plus sign above the dashboard list and select **Create a new web dashboard**. Enter a name, select a path, paste the website link into the web address field, and click Confirm to create it.


* In the web dashboard, users can search, navigate, and browse the web content as usual.


<span id="9c92890d"></span>
## 3.3 Embed Feishu Docs using a web dashboard

Users can also embed links to Feishu Docs, multi\-dimensional tables, PPT files, and other documents into the dashboard, enabling document reading and collaboration within DataWind.

**Step 1**, open the file to be embedded, click "Share," set the link sharing scope, and then copy the link.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c72ea05ab15f4390a439542f22bfc6c2~tplv-goo7wpa0wc-image.image) </span>

**Step 2**, click the plus sign above the dashboard list and select **Create a new web dashboard**. Enter a name, select a path, paste the link into the web address field, and click OK to create it.


* Users with read permission for the document can view the document content after entering the dashboard; users with edit permission for the document can edit the document directly in the web dashboard, and the edits will be synchronized in real time.

## 3.4 Web dashboard editing operations

<span id="17215896"></span>
### 3.4.1 Rename the dashboard

In the dashboard list, click the three dots on the right and select "Basic Information" to rename the web dashboard. The rename operation only affects the display name of the dashboard in the list; in the dashboard display area on the right, the dashboard name remains the original name of the embedded dashboard.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5b73a5bec3b64e48b54604294243aa40~tplv-goo7wpa0wc-image.image) </span>

<span id="ceb42a69"></span>
### 3.4.3 Other operations


* Ownership of the web dashboard can be transferred

* The dashboard can be authorized to users, user groups, Feishu groups, and more

* The dashboard can be set as default

* You can view access statistics for the web dashboard

* The web dashboard can be deleted; after deletion, the dashboard will be moved to the recycle bin
