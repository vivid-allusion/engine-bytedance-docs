<span id="_1-概述"></span>
# 1. Overview

In the project center, administrators can configure multilingual settings separately for datasets, charts, and dashboards, allowing colleagues who work in multiple languages to intuitively understand relevant information.

<span id="_2-功能介绍"></span>
# 2. Feature introduction

<span id="_2-1-开启多语言设置"></span>
## 2.1 Enable multilingual settings

First, administrators can go to project settings in the project center and click to enable multilingual display configuration. Currently, only Chinese and English are supported.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/974d7362e2cc4de589724d58a75f61a1~tplv-goo7wpa0wc-image.image) </span>

**What is the project default language?** 


1. For the same resource, it is possible to set names in different languages for display under different system languages. If a display name is not configured for the current system language, the display name configured under the "project default language" will be shown for this resource. Example: If the project default language is "English" and the system language is switched to "Chinese", but a resource does not have a Chinese name configured, the name configured under "English" will be displayed for this resource.

2. For international projects, it is recommended to set the "project default language" to "English"; for projects in China, it is recommended to set the "project default language" to "Chinese".

3. Please try to ensure that the resource information under the "project default language" is accurate and regularly maintained.


<span id="_2-2-应用多语言"></span>
## 2.2 Apply multilingual settings

After enabling multilingual settings, a "Multilingual" operation item will appear at the bottom of the left sidebar in the project center. Administrators can find the corresponding resource by viewing the owner or searching by keyword, and then configure settings as needed.


* Dataset: Supports configuring basic information, field information, and field value aliases.

* Chart: Supports configuring chart information.

* Dashboard: Supports configuring dashboard information and dashboard charts.
