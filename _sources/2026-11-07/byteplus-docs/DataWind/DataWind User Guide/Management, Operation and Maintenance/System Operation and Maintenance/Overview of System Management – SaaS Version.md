# 1. Overview of SaaS system management

System management refers to the ability for system administrators to access the system management module, view system information, manage system users, operate office platform integration, configure security settings, and perform data operations and maintenance configuration, among other tasks.

Depending on the product version deployed by your company, such as the SaaS version or the on\-premises deployment version, the entry point and interface for system management may differ slightly, but the overall capabilities remain consistent and include the modules mentioned above. This document introduces the system management features of the SaaS version deployed in the cloud. If you have deployed the on\-premises version, refer to the following document: [System Management Overview – Private Deployment Version](https://docs.byteplus.com/docs/undefined/69c3469a50cba904c1f57dd6).

# 2. Feature introduction

<span id="_2-1-系统信息"></span>
## 2.1 System information

On the DataWind product page, click Settings in the upper right corner to access and view system information. Users can view the current system version, status, number of users, expiration date, and the number of days remaining until expiration.
