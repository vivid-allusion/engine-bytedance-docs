# 1. Overview

In the Non\-BytePlus Console (Portal) for private domains, you can manage the system in sections such as enterprise domain information, project management, resource permissions, user management, user deletion, office platform integration, and security settings. Depending on the product version deployed by your company, the entry points and interfaces for system management may differ slightly.

# 2. Feature introduction

<span id="1ec1ad85"></span>
## 2.1 Enterprise domain information

You can view basic information about the enterprise domain, such as version, status, maximum number of users, expiration time, and countdown.

You can add specific users as enterprise domain administrators to manage users and resources across different projects.

<span id="eb3cdff8"></span>
## 2.2 Project management

Users can view information about projects created in the system (creation time, administrator, number of users) and add or edit projects.

This page supports adding project administrators for specific projects.

<span id="545a33c4"></span>
## 2.3 Resource permissions

For details, see [Resource Authorization](https://docs.byteplus.com/docs/DataWind/Resource_Authorization).

If you have purchased multiple products, you can search for resources under specific sub\-products.

<span id="c2234779"></span>
## 2.4 User management

For customers who require office platform integration, refer to the documentation to complete the prerequisite configuration, and then configure account association on this page.

[Lark](https://www.volcengine.com/docs/4726/67236), [WeCom](https://www.volcengine.com/docs/4726/69225), [Webex](https://www.volcengine.com/docs/4726/69811), [DingTalk](https://www.volcengine.com/docs/4726/71722)

(1) Click to complete account binding.

(2) Using DingTalk as an example, set the matching method and automatic matching conditions. The system supports setting the update cycle.

Matching methods: mobile phone number, IM ID (username), and email are supported.

After setting the matching method, the system will automatically identify and complete the matching. For users who fail to match, administrators need to perform manual matching.

(3) Click the icon to manually complete the matching.

(4) To perform manual matching, enter the username to be matched and click Confirm. If there are newly registered upstream users, click the Refresh button to update the data and try again.

<span id="8bf1a332"></span>
## 2.5 Delete users

On the user account matching page, click the operation button on the far right of the corresponding user to delete the user.

<span id="bfdd123b"></span>
## 2.6 Security settings

(1) Supports configuring PC\-side watermarks.

(2) Supports configuring system\-wide copy and download permissions.
