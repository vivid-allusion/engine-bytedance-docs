# 1. Overview

The system management section provides a user management module. Administrators can view all user information in the current system, including username, name, associated projects, and status, and can disable or delete users. You can temporarily restrict certain users' project permissions by disabling their status. When the number of users approaches the system's maximum user limit, you can also delete or disable some users to free up the number of user licenses.

# 2. Feature overview

<span id="fcf99162"></span>
## 2.1 User information

On the user management page, administrators can view detailed user information.


* Username

* Name

* Associated projects: Displays all projects that the user has permission to access.

* Status: Enabled/Disabled. When the status is disabled, the user will no longer be able to perform any operations, and the user will not count toward the system's user count.


<span id="10f172a5"></span>
## 2.2 Edit user

Administrators can edit a user's status to disable or enable the user's operation permissions. After a user is disabled, they will no longer be able to perform any operations on their associated projects. Disabled users will no longer count toward the system's number of user licenses. (The system user count only includes users whose status is enabled.)

Operation method: Click the settings icon in the upper right corner, select "User Management" in the left sidebar, select the user whose status you want to edit, click the edit icon, and modify their status.

## 2.3 Delete user

<span id="9d660d8b"></span>
### 2.3.1 Delete a single user

Open user management, and in the user list, click the "Delete" button to delete the user.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a375d19cca904e90808cc539ccea841e~tplv-goo7wpa0wc-image.image) </span>

<span id="bf05c885"></span>
### 2.3.2 Batch delete users

Batch deletion of multiple users is supported. Select the users to be deleted on the left side of the user list, click "Batch Delete" at the bottom, and you can batch delete multiple users.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/63debf791acd494abd7ff9676fdfbd57~tplv-goo7wpa0wc-image.image) </span>

## 2.4 Add user

This page does not currently support adding users. To add a user, go to Project Center \> User Management \> Add User. For details, see [User Management](https://docs.byteplus.com/docs/DataWind/Users_Management).
