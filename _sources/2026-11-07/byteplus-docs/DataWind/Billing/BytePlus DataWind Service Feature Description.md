|**Features** |**Feature descriptions** |**Remark** |
|---|---|---|
|Data source integration |Supports multiple data sources, including Hive, Mysql, Oracle, Impala, ADB, ClickHouse, local Excel/CSV, Kafka, Maxcompute, Douyin Store, BytePlus, Qianchuan, Amazon Athena, and many others |✅ |
||Supports Restful API, DataFinder, and advertising data source connection methods; supports data source aggregation acceleration |✅ |
||Supports integration of Lark Sheets and Lark Multidimensional Sheets data |✅ |
|Dataset |Supports creating datasets, customizing dataset fields, synchronizing and tracing data, monitoring configuration, and metadata connection |✅ |
|Thematic dataset |Supports integration of data from VeCDP, GMP, and DataFinder, which are three growth marketing series products of the BytePlus intelligent platform, to build marketing thematic datasets |Supports additional purchase |
|High\-performance engine |Supports built\-in high\-performance query engine to meet scenarios requiring analysis and insight based on large volumes of detailed data |✅ |
|Visual modeling |Supports extracting data from data sources and adding data processing nodes by dragging and dropping; supports field settings, cross\-source data association, join/union, row\-column transformation, data splitting, top K values, Cartesian product, prediction, classification, regression, time series, data evaluation, natural language processing, and many other data modeling operations; supports outputting datasets and split output; supports viewing visual modeling tasks |✅ |
|Visual query and analysis |Supports visual queries to generate line charts, tables, pie charts, histograms, and many other chart types; supports sorting, period\-over\-period comparison, comparison, and many other common analytical calculations; query filter configuration; supports LOD expressions, replacing datasets, field list management, and other field configurations; supports downloading data/charts and setting announcements |✅ |
|Dashboard |Supports combining charts on the canvas, and allows repositioning via mouse drag\-and\-drop. Supports adding a variety of controls such as filters, charts, rich text, and images to enrich data storytelling. Supports dynamic interactive analysis, including pivot tables, custom tooltips, drill up and down, linkage, and navigation. Supports authorization and embedding operations. |✅ |
||Supports dashboard comments. |✅ |
||Supports dashboard subscriptions. |✅ |
||Supports interactive analysis, with data instantly calculated based on drag\-and\-drop layout and filter results. |✅ |
|Subscription monitoring |Supports creating subscription push, monitoring alerts, and metric broadcasting. Supports monitoring management and subscription management. |✅ |
|Mobile |Supports integration with Lark, DingTalk, WeCom, and Webex to meet mobile data viewing needs via lightweight applications. |✅ |
|Embedded analytics |Supports embedding Smart Data Insight pages (including visualization queries, dashboards, and charts) via iframe. Supports controlling data switching via URL parameters, including language, hiding the header menu, and configuring public filters. |✅ |
|Office software integration |Supports connecting to Lark, WeCom, Webex, and DingTalk office systems, allowing users to conveniently view reports in DataWind within the office system. |✅ |
|OpenAPI |Supports managing user groups, setting dataset/dashboard/row and column permissions, viewing operation and maintenance information and lineage analysis, synchronizing datasets, obtaining datasets/dashboards/charts, performing visual modeling, creating or deleting fields, and more via OpenAPI calls. |✅ |
|Attribution decision |Supports real\-time attribution, enabling automatic identification of key factors behind data fluctuations. Supports custom monitoring and alert rules, triggering alerts. Supports notifications via Lark, DingTalk, WeCom, Webex, SMS, and email. |✅ |
||Supports routine attribution, anomaly analysis, dimension attribution, and metric attribution, and generates metric analysis trees. |Not supported yet, coming soon |
|Project center \- project overview |Supports various administrator management features, including project, resource, and access statistics management. Supports viewing end\-to\-end lineage analysis. |✅ |
|Project center \- permission management |Supports configuration and management of user and user group permissions. Supports role configuration and management. Supports resource permission management. Supports viewing deleted resources in the recycle bin. Permission types include: view, edit, and manage. |✅ |
|Project center \- approval workflow integration |Supports integration with Lark approval workflows. |✅ |
|Number of projects |/ |No limit |
