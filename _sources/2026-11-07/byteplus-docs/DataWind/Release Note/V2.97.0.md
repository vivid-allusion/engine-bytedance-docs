# Introduction to new features

<span id="a45c1b21"></span>
## Dataset\-related

<span id="507a2207"></span>
### [Optimization] The dataset list now supports filtering by label

The overview page adds a single\-selection filter label, and labels are displayed on the dataset details page. You can also label or unlabel datasets, making data label management more flexible and convenient.

Operation path: Data preparation \- Dataset \- List filter

## Visualization query\-related

<span id="9edf3c6b"></span>
### [Optimization] Added data retrieval mode configuration for the pivot table tree view

A new data retrieval mode configuration is added to the pivot table tree view, supporting both full and incremental data retrieval modes. The default is full data retrieval, making it easier to control the data loading range as needed.

Operation path: Visualization query \- Chart \- Pivot table \- Basic format
