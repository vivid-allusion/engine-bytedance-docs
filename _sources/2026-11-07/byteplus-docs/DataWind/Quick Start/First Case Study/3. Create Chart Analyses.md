Create four types of charts in visualization queries: metric card, line chart, bar chart, and table, and configure the chart styles.

<span id="_1-制作指标卡"></span>
# 1. Create a metric card

<span id="d4ce20cd"></span>
## **1.1 Enter the visualization query page**

On the dataset page, select the Sales GMV analysis dataset and click Visualization Query in the upper right corner.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b6d1b6e8ffe4773a66bc1b2666d2a0d~tplv-goo7wpa0wc-image.image) </span>

Alternatively, you can click Visualization Query directly to use the Sales GMV analysis dataset.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21b9db76f62940dfbec63850353983ca~tplv-goo7wpa0wc-image.image) </span>

<span id="0008b424"></span>
## **1.2 Create a field**


* Click the  **⋮**  icon next to the dataset in the upper left corner, and select Add Field to enter the Add Field menu.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f51057e507c04d9fb5331599210f3b2d~tplv-goo7wpa0wc-image.image) </span>


* Select order_count and sale_price from **Dataset Fields**, double\-click to add them to the expression on the right, name the field GMV, set the type to **Metric**, select **Save to Dataset**, and click the **OK** button.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eb5d75ad06444e068b80b12a9b272dc3~tplv-goo7wpa0wc-image.image) </span>

<span id="727977c4"></span>
## **1.3 Create a metric card**


* Select the chart type as **Metric Card**.

* Drag the GMV metric into the metric bar, drag the order_date dimension into the filter bar, set the filter to the fixed date "2016\-06\-01~2016\-06\-30".

* In chart analysis, select the **year\-on\-year and month\-on\-month comparison** method for analysis.


<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7a432ed7fda6457f81cb9f144b269cd3~tplv-goo7wpa0wc-image.image" width="610px" /></div>


<span id="5a5fe21f"></span>
## **1.4 Adjust the style and save**


* The **Metric Style** in chart configuration can adjust the font size of the metric.

* The **Conditional Formatting** in chart configuration can adjust the display format of the growth rate.

# 2. Create a line chart

<span id="b420b45f"></span>
## **2.1 Create a line chart**


* Select the chart type as **Line Chart**.

* Drag the order_date dimension into the dimension bar and click the field, set the date type to **Year\-Month**, and drag the GMV metric into the metric bar.

* In chart analysis, select the **Reference Line** method and configure it to obtain the following chart.


<span id="3211f05d"></span>
## **2.2 Adjust the style and save**


* The **Legend** in chart configuration can be turned off.

* In chart analysis, sequentially select **Sort**, **Top N**, and **Reference Line** to configure the chart, resulting in the following chart.

# 4. Create a table

<span id="b134b0d8"></span>
## **4.1 Create fields**

Add three new fields as follows:


* Field name: Sales Year, dimension, field expression: year(order_date), save to dataset.

* Field name: Current Year GMV, metric, field expression: {fixed [Sales Year]: sum([GMV])}, save to dataset.

* Field name: Current Month as Percentage of Current Year GMV, metric, field expression: [GMV]/[Current Year GMV], save to dataset.


Select Table as the chart type, drag the GMV metric into the metrics panel, and drag the order_date dimension into the dimensions panel.

<span id="1449b8fe"></span>
## **4.2 Create a table**


* Select **Table** as the chart type.

* Drag the GMV metric into the metrics panel and drag the order_date dimension into the dimensions panel.

* In chart analysis, select **Period\-on\-Period Comparison**, add one **Period\-on\-Period** and one **Year\-on\-Year**, select the calculation metric as sum(GMV), and check the calculation type as original value to obtain the following chart.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6add122b26d44fc28f00b1d12f541d10~tplv-goo7wpa0wc-image.image) </span>

<span id="a9759a83"></span>
## **4.3 Adjust style and save**


* Use **Set Field Information** to modify each column header name.

* Use **Set Data Format** to display large values in units of ten thousand, and display growth rates and proportions as percentages.

* Enable the **Pagination** to control the number of rows displayed per page.

* Set the table background style by configuring **Conditional Formatting \- Color Scale/Data Bar**.
