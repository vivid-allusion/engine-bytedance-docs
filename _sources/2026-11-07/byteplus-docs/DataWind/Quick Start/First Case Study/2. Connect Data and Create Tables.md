Upload data through a data connection and use the uploaded data to create a dataset.

<span id="_1-上传数据"></span>
# 1. Upload data

Hover over the **Data preparation** module, and select **Data connection** from the pop\-up menu (here, completed data connections can be displayed).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/83700b42f4674464841a8e7e5123b21e~tplv-goo7wpa0wc-image.image) </span>

After entering the data connection page, click **New data connection** in the upper left corner or in the middle of the page.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5ee17aeb52e740db92c92892d75ce0a2~tplv-goo7wpa0wc-image.image) </span>

In the pop\-up menu, select the Excel icon and upload the sample file [Sales GMV analysis_V3].

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/62a5c0f6799145cfb9f889ddcc14c917~tplv-goo7wpa0wc-image.image) </span>


* You can select the sheets to upload. Here, select all:


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/998b8829dd7b44e792546c9fa529a17d~tplv-goo7wpa0wc-image.image) </span>


* On the data preview page, you can modify the field types and names if needed.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0e8cd83b9b594573863f746ef4c99884~tplv-goo7wpa0wc-image.image) </span>

<span id="_2-新建数据集"></span>
# 2. Create a new dataset

Hover over the **Data preparation** module, and select **Dataset** from the pop\-up menu (here, completed datasets can be displayed).

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a3b25277044f4f028c91fb9265237643~tplv-goo7wpa0wc-image.image) </span>

Hover over the  **+ New** button in the upper left corner, and select **New dataset** from the pop\-up menu.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4f9ef81c1dd64659850ce0a41afe4564~tplv-goo7wpa0wc-image.image) </span>

In the pop\-up menu, select the established data connection Sales GMV analysis_V3 to enter the dataset configuration page.

<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/adae717bf69a4bc8a810ba7144fc3e61~tplv-goo7wpa0wc-image.image" width="610px" /></div>


Follow these steps to build the dataset model:

(1) Expand the Excel data connection and drag the table into the configuration panel on the right;

(2) Change the dataset connection mode to "Extract";

(3) Save the dataset, name it "Sales GMV analysis", and wait for data synchronization to complete.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e43810960eaf4ba1893d66a0227df00a~tplv-goo7wpa0wc-image.image) </span>

***To create a dataset with multiple related tables, use the multi\-table join relationship method:* ** 

Drag two related tables into the configuration interface on the right, select the required connection mode and connection fields, and establish the connection.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b00db24b3a58438080744fee4df9c5dc~tplv-goo7wpa0wc-image.image) </span>
