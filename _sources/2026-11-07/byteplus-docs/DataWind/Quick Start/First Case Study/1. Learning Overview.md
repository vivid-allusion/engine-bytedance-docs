# 2. Case analysis

The report in this case focuses on GMV analysis and consists of two tab pages: Page 1: Data overview and Page 2: Comparative analysis. The report is broken down as follows:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f6aa88a30fe1479cb78692ea21650c08~tplv-goo7wpa0wc-image.image) </span>


* **Page 1: Data overview \- GMV trend analysis**

   『**Indicator card**』GMV summary analysis, which needs to display the GMV value and the month\-over\-month growth rate

   『**Text**』Trend analysis, describing the GMV changes

   『**Line chart**』GMV monthly fluctuation trend, which needs to display the GMV value by month and add an "average" reference line. GMV dimension comparison.

   『**Text**』Dimension comparison analysis, summarizing GMV by "province" and "product type"

   『**Bar chart**』Multi\-dimensional GMV analysis, displaying the top 10 GMV values in descending order by "province" and "product type" dimensions, and adding an "average" reference line

* **Page 2: Comparative analysis table**

   『**Table**』GMV comparative analysis, which needs to display, by month, the current month's GMV, month\-over\-month GMV growth rate, last year's GMV, year\-over\-year GMV growth rate, total GMV for the year, and the proportion of GMV for the year. Among them, the month\-over\-month and year\-over\-year growth rates are displayed using data bars, and the proportion of GMV for the year is displayed using color scales.
