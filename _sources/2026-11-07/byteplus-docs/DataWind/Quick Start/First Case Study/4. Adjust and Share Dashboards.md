After saving charts to the dashboard, adjust the layout and style to generate the final report and share it.

<span id="_1-图表联动"></span>
# 1. Chart linkage

<span id="_1-1-联动原理"></span>
## 1.1 Linkage principle

After linking chart A to chart B, selecting a dimension in chart A will automatically update chart B to display the corresponding results for the same dimension.

<span id="_1-2-联动设置"></span>
## 1.2 Linkage settings

On the dashboard editing page, to associate the Multidimensional GMV Analysis chart with the GMV Comparison Analysis chart, click the  **⋮**  icon in the upper right corner of the Multidimensional GMV Analysis chart, select Linkage Settings, and in the pop\-up page, select the GMV Comparison Analysis chart.

## 1.3 Linkage effect

On the dashboard, click Guangdong Province in the Multidimensional GMV Analysis chart, and you will notice that the current month's GMV data in the GMV Comparison Analysis chart changes.

<span id="_2-布局调整"></span>
# 2. Layout adjustment

On the dashboard editing page, use **tabs, text, query containers, layout methods, media\-images**

and other features to adjust the dashboard layout.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f19f736b00a04fc29052f0d6bc868114~tplv-goo7wpa0wc-image.image) </span>

<span id="_3-对外分享"></span>
# 3. External sharing

There are two ways to share externally:

Method 1: On the dashboard page, select the "Share" button in the upper right corner to copy the dashboard link to the clipboard for easy sharing with others. Note that the recipient must have the appropriate dashboard permissions.

Method 2: On the dashboard page, select the  **⋮**  icon in the upper right corner, then in the pop\-up menu, choose to export as an "image file" or PDF file, and then share it with others.
