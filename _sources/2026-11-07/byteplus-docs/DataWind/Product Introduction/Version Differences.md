# 1. Personal edition

<span id="_1-1-个人版概述"></span>
## 1.1 Overview of the personal edition

The Smart Data Insight personal edition is a product version of Smart Data Insight designed specifically for individual users, enabling more people to conduct data analysis at a low cost, unlock the value of data, and embark on the journey of intelligent insight. The standard edition and professional edition are suitable for enterprises or organizations, offering enhanced office integration and collaboration capabilities. The personal edition is intended for individual users, enabling rapid self\-service analysis.

<span id="_1-2-个人版功能说明"></span>
## 1.2 Description of personal edition features

The product features of the Smart Data Insight personal edition are generally consistent with those of the standard edition and professional edition, **with differences in certain modules, which are introduced below.** 


|**Serial number** |**Product module** |**Description of personal edition differences** |
|---|---|---|
|1 |Module |The personal edition does not support the use of visual modeling or digital dashboard features. |
|2 |Account, storage, project |The personal edition is limited to 1 account, 5 GB, and a single project.<br><br>Note: Additional accounts and storage cannot be purchased. |
|3 |Data access |The personal edition supports all basic data sources.<br><br>Unsupported data sources include: Restful API, DataFinder data source, and advertising data source. |
|4 |Data connection method |The personal edition does not support aggregation acceleration. |
|5 |Monitoring<br><br>Alerting<br><br>Metric reporting<br><br>Comments |1. Personal edition does not support creating subscriptions, subscription management, or metric reporting<br><br>2. Personal edition does not support monitoring management<br><br>3. Personal edition does not support the comments feature for dashboards |
|6 |Integration with office platforms |Personal edition does not support integration with office platforms |
|7 |Third\-party and OpenAPI |Personal edition does not support dashboard embedding<br><br>Personal edition does not support user\-generated links in OpenAPI |
|8 |Mobile |Personal edition does not support mobile features |

# 2. Standard edition

<span id="_2-1-标准版概述"></span>
## 2.1 Overview of the standard edition

The Smart Data Insight standard edition is a product version of Smart Data Insight designed specifically for small and medium\-sized enterprises, enabling more businesses to conduct data analysis at a relatively low cost, unlock the value of data, and embark on the journey of intelligent insight.

<span id="_2-2-标准版功能说明"></span>
## 2.2 Description of standard edition features

The product features of the Smart Data Insight standard edition are generally consistent with those of the professional edition, **with differences in certain modules, which are introduced below.** 


|**Serial number** |**Product module** |**Standard edition difference description** |
|---|---|---|
|1 |Visual modeling |Standard edition does not support the visual modeling feature |
|2 |Digital dashboard |Standard edition does not support the digital dashboard feature |
|3 |Mobile |Standard edition does not support mobile features |


<span id="_3-专业版"></span>
# 3. Professional edition

The Smart Data Insight professional edition is a product version of Smart Data Insight designed specifically for enterprises, enabling more businesses to conduct professional data analysis, unlock the value of data, and embark on the journey of intelligent insight. The professional edition includes all feature modules and offers the most comprehensive product capabilities among all versions.
