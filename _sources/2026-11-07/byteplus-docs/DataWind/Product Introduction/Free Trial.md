<span id="_1-免费试用概述"></span>
# 1. Overview of the free trial

The DataWind product in BytePlus DataWind supports a 30\-day free online trial, with the period starting from your first registration and login. To request a longer trial period, submit an application to your business manager.

**Prerequisites:** 

(1) Apply for a [BytePlus account](https://console.byteplus.com/auth/signup?redirectURI=https%3A%2F%2Fwww.byteplus.com%2Fen&skipAccountProfile=true). Both personal and enterprise accounts are eligible for the DataWind free trial.

(2) Complete identity verification. For steps, refer to [Identity Verification](https://www.volcengine.com/docs/6261/64935).

(3) Use this account to perform the following operations.

<span id="_2-如何开通试用"></span>
# 2. How to activate the trial

(1) Open the DataWind official website, or open BytePlus, locate DataWind as shown below, and click to open it.

(2) Click "Enter Product" or "Free Trial" to directly activate a 30\-day product trial.

(3) The steps to activate the trial are shown in the following figure.

Step 1: Understand the differences between the Standard and Professional editions. See [BytePlus DataWind Service Feature Description](https://docs.byteplus.com/docs/DataWind/BytePlus_DataWind_Service_Feature_Description).

Step 2: Read and confirm the agreement.

Step 3: Click the white [Free Trial Professional Edition] button to **activate a one\-month free trial**.

> The Professional Edition trial is activated by default. The Standard Edition trial is not available at this time.


Frequently asked questions and tips:

(1) If the following prompt appears on the trial activation page, [identity verification](https://www.volcengine.com/docs/6261/64935) is required.

(2) If the following prompt appears, first check whether the login account is a sub\-account. The product free trial is only available for the primary account. Switch to the primary account and follow the steps above to activate the trial again.

<span id="_3-试用过程操作介绍"></span>
# 3. Introduction to trial operations

After registering and logging in to DataWind with the primary account, you can start using DataWind. There are no permission restrictions on the functional modules. (When acting as a system administrator during the trial or initial use of this product, the default username and password are those of the BytePlus registration and login account.) You can create new users in Access Control to provide trial accounts for colleagues or classmates.

<span id="_3-1-新建智能数据洞察用户"></span>
## 3.1 Create a new DataWind user

First, you can click the avatar in the upper right corner of the product's main interface to enter "Access Control," and then create a new user under "User." The specific steps are as follows: (1) Add a sub\-account first: Click the avatar in the upper right corner, click Access Control, and you can create a new user; for example, you can create a user named "demo\-test" here. (Caution: The sub\-account created here is essentially a user created in the BytePlus console.)

(2) Next, enter DataWind. For a brand new DataWind, you can first create a "project" as shown in the following figure:

After creating a new project, you will enter the project's dataset interface, where you can upload sample or practice datasets to try out the product. As shown in the following figure:

Follow the interface instructions, upload an Excel file, then drag the dataset onto the model configuration canvas or perform field configuration and other operations, and click Save.

<span id="_3-2-增加系统管理员（saas）"></span>
## 3.2 Add a system administrator (SaaS)

As a system administrator, you have the primary account for the entire system. To delegate permissions to others and allow a designated sub\-user to add more sub\-accounts and perform management operations, you need to go to "Access Control" under "Policy Management," search for "Access Control (IAM) Full Management Permissions," and then click Manage. As shown in the following figure:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6da2cdd7879648899d12b2d163da8dc2~tplv-goo7wpa0wc-image.image) </span>

After entering the "Management" interface, click "Add Authorization", select a specified user, and click Confirm. This will grant global management permissions to that user. In other words, this user can act as the system administrator to add sub\-users to the system and perform more global management operations. As shown in the following figure:

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/41a155609228406eaaa8eaa292aa8e4b~tplv-goo7wpa0wc-image.image) </span>
