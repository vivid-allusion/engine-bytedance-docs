The BytePlus SDK lets you programmatically interact with the BytePlus DNS. You don't need to deal with complex signature calculations during the interaction. The BytePlus SDK provides libraries for Go. The BytePlus SDK also provides sample code for you to get started.


* Go

   * [BytePlus SDK for Go](https://github.com/byteplus-sdk/byteplus-sdk-golang)

   * [Sample code](https://github.com/byteplus-sdk/byteplus-sdk-golang/tree/master/example/dns)
