Before using BytePlus DNS, you must first activate BytePlus DNS.

<span id="steps"></span>
## Steps

Follow the steps below to activate BytePlus DNS.


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns).

2. Check the **Agreement** and then click **Submit order**.

3. On the **Confirm order information** page, click **Next step**.


<span id="next-steps"></span>
## Next steps

You can now create your domain in BytePlus DNS. See [Create a Domain](https://docs.byteplus.com/docs/byteplus-dns-suite/docs-adding_a_domain).
