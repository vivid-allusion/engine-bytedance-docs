If you want to use BytePlus DNS to provide DNS services for your domain name, you need to add your domain name to BytePlus DNS.

<span id="steps"></span>
## Steps

Follow the steps below to add your domain in BytePlus DNS.


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns).

2. On the **Domain management** page, click **Add domain**.

3. In the **Add domain** dialog box, enter your domain name. You need to enter the second\-level domain, such as `example.com`. BytePlus DNS will validate the domain. If the validation passes, click **OK** to add the domain.

4. The successfully added domain will be displayed in the domain list. At this point, the DNS status of the domain is `Not using BytePlus DNS servers` because the DNS service for this domain is not provided by BytePlus DNS. In the following steps, you need to add all the DNS servers of BytePlus DNS in your domain registrar.


<span id="next-steps"></span>
## Next steps

Set DNS servers at your domain registrar. See [Add DNS Servers to Your Domain's Registrar](https://docs.byteplus.com/docs/byteplus-dns-suite/docs-adding-dns-servers-to-your-domain-s-registrar)
