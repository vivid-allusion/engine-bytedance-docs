This document introduces how to create a line group.

Each BytePlus account can create up to 10 line groups.

<span id="steps"></span>
## Steps

Follow the steps below to create a line group.


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns).

2. On the **Line management** page, click **Create line group**.

3. In the **Create line group** window, set the following parameters:

   
   |Parameter |Description |
   |---|---|
   |**Group name** |The name of the line group. UTF\-8 format, with a maximum length of 32 UTF\-8 characters. |
   |**Select lines** |The lines included in the line group, such as ISP lines, secondary ISP lines, cloud vendor lines, and geolocation lines. You can select up to 20 items, i.e., combine up to 20 lines. For ISP lines, secondary ISP lines, and cloud vendor lines, each item can be specified down to the region and province. For geolocation lines, each item can be specified down to the province/country or region. |
   

4. After you set the **Select lines** parameter, the **Supported edition** parameter will display the edition applicable to your current line group configuration. Click **Confirm**. You can then see the created line group on the **Line management** page.
