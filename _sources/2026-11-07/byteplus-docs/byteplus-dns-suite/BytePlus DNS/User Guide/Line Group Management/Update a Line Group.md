This document introduces how to update a line group.

<span id="steps"></span>
## Steps

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">Before updating a line group, you need to consider carefully. If you update a line group, all DNS records in BytePlus DNS that use this line group will be affected. You cannot roll back this operation.</div>


Follow the steps below to update a line group.


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns/publiczone).

2. On the **Line management** page, find the line group you need to update, and click **Edit** in the **Actions** column.

3. In the **Edit line group** window, update the **Group name**, **Remarks**, and **Select lines** as needed.

4. After completing the updates, click **Confirm**.
