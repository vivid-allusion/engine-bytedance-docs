A line group allows you to combine multiple ISP lines, secondary ISP lines, cloud vendor lines, or geolocation lines together and use them as a single DNS line. Line groups can simplify the management and configuration of lines and is suitable for scenarios where you need to configure multiple lines for a single DNS record set.
