This document describes how to update DNS records in BytePlus DNS.

BytePlus DNS uses record sets (RRSets) to manage one or more DNS records with the same domain, line, and type. You can set weights for multiple records in a record set to implement DNS\-based load balancing. See [RFC 7719](https://www.rfc-editor.org/rfc/rfc7719.html) for more information.

<span id="steps"></span>
### Steps

Complete the following steps to update DNS records.


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns/publiczone).

2. On the **Record management** tab, find the record set that you want to update.

3. In the **Actions** column, click **Manage**.

4. In the **View record set** page:

   * In the **Basic information** section, Click **Edit** to update domain prefix, record type, TTL, and line.

   * In the **Record value** section, update the records.

5. After you complete the update, click **Submit**.
