This document describes how to delete your domain in BytePlus DNS.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">You cannot update an existing domain name. You can add a new domain name instead.</div>


* <div data-tips="true" data-tips-type="tip">You can only delete domain names in the free edition. You cannot delete domain names in other editions.</div>



<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Please consider carefully before deleting a domain name. Once a domain name is deleted, both the domain name and all its DNS records will be permanently deleted and cannot be recovered.</div>


<span id="steps"></span>
## Steps

Follow the steps below to delete your domain name:


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns).

2. On the **Domain management** page, find the domain name you want to delete. Click the checkbox on the left side of the **Domain** column. Then, click the **Delete** button below the domain name list.

3. A dialog box will pop up to confirm your deletion. Enter **delete** in the input box in the dialog box. Click **Delete**.
