If you know the IP address range of your users, you can create an IP\-based line in BytePlus DNS. An IP\-based line represents a CIDR address block. With IP\-based lines, BytePlus DNS can route user traffic from different IP address ranges to different IP addresses of your service.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can only set IP\-based lines for the DNS records of your domain if the <a href="https://docs.byteplus.com/docs/byteplus-dns-suite/docs-what-is-an-ip-based-line">edition</a> of your domain is ultimate edition or exclusive edition.</div>
