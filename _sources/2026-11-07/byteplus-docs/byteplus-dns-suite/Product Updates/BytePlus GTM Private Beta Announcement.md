BytePlus Global Traffic Management (GTM) enters its private beta phase on June 4, 2024. To use BytePlus GTM, you need to [submit a support request](https://www.byteplus.com/en/support) to contact technical support.

BytePlus GTM is a DNS\-based traffic management service that help reduce user access latency, distribute user requests based on the capacity of data centers, and perform failover across multiple data centers.

See [What is BytePlus GTM](https://docs.byteplus.com/docs/byteplus-dns-suite/U-qFtN).
