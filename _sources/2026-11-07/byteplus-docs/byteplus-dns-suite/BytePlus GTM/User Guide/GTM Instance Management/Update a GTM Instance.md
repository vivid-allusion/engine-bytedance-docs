This document describes how to update a GTM instance in BytePlus GTM. You may modify the TTL and remark of the GTM instance.

<span id="prerequisites"></span>
## Prerequisites

Before updating a GTM instance, you must ensure that the status of the GTM instance is **stopped**. See [Start or Stop a GTM Instance](https://docs.byteplus.com/docs/byteplus-dns-suite/U5nvpy).

<span id="steps"></span>
## Steps

Complete the following steps to update a GTM instance.


1. Find the GTM instance you need to update on the [Instance management page](https://console.byteplus.com/dns-suite/gtm/instances).

2. In the **Domain** column, click the domain of the GTM instance.

3. Select the **Instance configuration** tab. You can click **Edit** to edit the TTL or remarks of the GTM instance.

4. After making modifications, click **Confirm**.


You can see the updated configuration on the **Instance configuration** tab.
