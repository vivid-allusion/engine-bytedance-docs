This document describes how to delete rules in BytePlus GTM.

<div data-tips="true" data-tips-type="danger" data-tips-is-title="true">danger</div>


<div data-tips="true" data-tips-type="danger">Please consider carefully before deleting a rule. Deleted rules cannot be recovered and can only be recreated. If you only want to temporarily disable the rule, you can set the <strong>Enabled</strong> parameter of the rule to <strong>Disable</strong>. See <a href="https://docs.byteplus.com/docs/byteplus-dns-suite/T849Eo">Update a Rule</a>.</div>


Before deleting a rule, you must stop the GTM instance where the rule is included.

<span id="steps"></span>
## Steps

Complete the following steps to delete a rule.


1. On the [Instance management page](https://console.byteplus.com/dns-suite/gtm/instances), find your GTM instance. Click the domain name in the **Domain** column.

2. In the **Policy management** tab, click the **Configure** button of your currently configured scheduling policy.

3. In the **Rules** tab, find the rule you need to configure. Click **Delete** in the **Actions** column.

4. In the pop\-up dialog box, click **OK** to delete the rule.
