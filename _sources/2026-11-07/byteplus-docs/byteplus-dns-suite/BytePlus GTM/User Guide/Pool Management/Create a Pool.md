This document describes how to create a pool for a GTM instance in BytePlus GTM.

A pool can contain addresses with the same attributes, such as geolocation or ISP. For example, a pool can include the IP addresses of all IDCs located in the same region or availability zone.

<span id="prerequisites"></span>
## Prerequisites

Before creating a pool for a GTM instance, you must [configure the GTM instance](https://docs.byteplus.com/docs/byteplus-dns-suite/0_OA55).

<span id="steps"></span>
## Steps

Complete the following steps to create a pool.


1. On the [Instance management](https://console.byteplus.com/dns-suite/gtm/instances) page, find the GTM instance to configure. Click **Configure** in the **Actions** column.

2. On the **Pool management** page, click **Create pool**.

3. On the **Create pool** page, set the parameters of the pool. Refer to [Configure a GTM Instance](https://docs.byteplus.com/docs/byteplus-dns-suite/0_OA55) to learn how to set the parameters. Then, click **OK** to create the pool.


You can see the pool you create on the **Pool management** page.
