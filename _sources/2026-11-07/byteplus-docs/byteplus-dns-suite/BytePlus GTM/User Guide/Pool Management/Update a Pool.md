This document describes how to update a pool in BytePlus GTM.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



* <div data-tips="true" data-tips-type="warning">If the GTM instance where the pool is included is running, you need to stop the GTM instance before updating the pool.</div>


* <div data-tips="true" data-tips-type="warning">A pool may be included by multiple pool sets or rules simultaneously. Before updating the pool, you need to ensure that you know all the pool sets or rules affected by the update operation.</div>



<span id="steps"></span>
## Steps

Follow the steps below to update a pool.


1. On the [Instance management](https://console.byteplus.com/dns-suite/gtm/instances) page, find the GTM instance. Click the domain name of the GTM instance in the **Domain** column.

2. On the **Address management** page, click the pool you need to update.

3. On the **Edit pool** page, click **Edit**. Then, you can update the parameters of the pool. For detailed parameter descriptions, refer to [Create a Pool](https://docs.byteplus.com/docs/6758/202242).

4. After updating, click **Confirm**.
