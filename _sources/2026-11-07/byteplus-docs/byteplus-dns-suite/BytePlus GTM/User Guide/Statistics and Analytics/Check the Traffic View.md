This document describes how to check the traffic view in BytePlus GTM. BytePlus GTM uses Sankey diagrams to display traffic view.

<span id="check-the-expected-traffic-view"></span>
## Check the expected traffic view

Follow these steps to check the expected traffic view of a GTM instance. The expected traffic view is generated based on the configuration of the GTM instance and does not represent the actual traffic routing status.


1. On the [Instance management](https://console.byteplus.com/dns-suite/gtm/instances) page of BytePlus GTM, find your GTM instance. Click **Configure** in the **Actions** column.

2. On the **Policy management** tab, click the **Configure** button for the policy you need to update.

3. Select the **Expected traffic view** tab to view your expected traffic view.


<span id="check-the-actual-traffic-view"></span>
## Check the actual traffic view

Follow these steps to view the actual traffic view of a GTM instance.


1. Open the [DNS query metrics](https://console.byteplus.com/dns-suite/gtm/statistics) page of BytePlus GTM.

2. In the search box at the top right of the **DNS query metrics** page, enter the domain name of the GTM instance you want to check. On the left side of the page, select **ISP** or **Geolocation**, and then select **Traffic view**. You can then see the actual traffic view based on ISP or geolocation.
