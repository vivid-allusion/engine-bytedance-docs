Welcome to the BytePlus Global Traffic Manager (GTM). You can perform the following operations using the OpenAPI described in this document:


* Read, update, enable, disable, or delete a GTM instance.

* Update or read a policy.

* Create, read, update, or delete rules.

* Read or update health check parameters.

* Create, read, update, or delete pools.


<span id="instance-management-apis"></span>
## Instance management APIs


|API name |Description |
|---|---|
|[ListGtms](https://docs.byteplus.com/docs/byteplus-dns-suite/CrGpNh) |Gets a list of GTM instances. |
|[GetGtm](https://docs.byteplus.com/docs/byteplus-dns-suite/CHmr_V) |Gets information on a GTM instance. |
|[UpdateGtm](https://docs.byteplus.com/docs/byteplus-dns-suite/SYFqCs) |Updates a GTM instance. |
|[StartRouting](https://docs.byteplus.com/docs/byteplus-dns-suite/StartRouting) |Starts a GTM instance. |
|[StopRouting](https://docs.byteplus.com/docs/byteplus-dns-suite/StopRouting) |Stops a GTM instance. |
|[DeleteGtm](https://docs.byteplus.com/docs/byteplus-dns-suite/DeleteGtm) |Deletes a GTM instance. |
|[ListQueryStats](https://docs.byteplus.com/docs/byteplus-dns-suite/ListQueryStats) |Gets DNS query statistics of an GTM instance. |
