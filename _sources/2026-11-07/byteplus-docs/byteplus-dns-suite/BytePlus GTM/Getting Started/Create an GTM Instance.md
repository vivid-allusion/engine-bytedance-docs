To use BytePlus GTM for DNS\-based routing, you first need to create a GTM instance.

This tutorial assumes that the DNS service provider for your domain `example.com` is BytePlus DNS. You can create a GTM instance directly in the BytePlus DNS console.

<span id="prerequisites"></span>
## Prerequisites

Before starting this tutorial, ensure that you have registered a [BytePlus account](https://console.byteplus.com/).

<span id="steps"></span>
## Steps

You can follow these steps to enable BytePlus GTM for your domain:


1. Open the [BytePlus DNS console](https://console.byteplus.com/dns-suite/dns).

2. On the **Domain management** page, find the domain **example.com** for which you need to enable BytePlus GTM. Click **Manage** in the **Action** column.

3. On the **Record management** tab, click **Create GTM instance**.

4. In the **Create instance** dialog box, set the **Domain prefix** to `www` and the **Edition** to **Ultimate edition**. Check the agreement and click **Confirm order**.

5. After the order is submitted successfully, click **Go to Console** to navigate to the **Instance management** page of BytePlus GTM. You can see the created BytePlus GTM instance on this page.


At this point, the instance you created will be displayed in the list on the **Instance management** page.
