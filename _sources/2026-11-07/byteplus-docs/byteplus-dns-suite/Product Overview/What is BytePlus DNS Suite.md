The BytePlus DNS Suite provides domain name resolution services and DNS\-based traffic routing services, including:


* BytePlus DNS: authoritative DNS service for public domain names.

* BytePlus PrivateZone: DNS service for [BytePlus Virtual Private Cloud (VPC)](https://www.byteplus.com/en/product/vpc).

* BytePlus GTM (Private Beta): DNS\-based traffic routing service. BytePlus GTM resolves your domain name to an IP address based on factors such as geolocation, user access latency, load balancing, and failover.
