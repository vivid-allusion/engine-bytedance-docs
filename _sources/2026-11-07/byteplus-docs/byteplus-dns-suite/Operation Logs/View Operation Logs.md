This document describes how to view operation logs for the TrafficRoute DNS Suite.

Operation logs record the actions performed by your Volcano Engine account in the TrafficRoute DNS Suite. You can query operation logs for BytePlus DNS, BytePlus Global Traffic Management (GTM), and BytePlus PrivateZone.

<span id="steps"></span>
## Steps

Follow these steps to view operation logs for the TrafficRoute DNS Suite.


1. Open the [Operation logs](https://console.byteplus.com/dns-suite/dns/logs) page.

2. On the **Operation logs** page, select the service you want to view.

   * DNS: You can specify a time range and query operation logs within that range. You can also use **Advanced search** to filter operation logs. In the **Action** column, you can click **Details** to view operation details and the API request and response bodies.

   <span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6c51ecaae3373cb7beec717e7a6b808e.png) </span>

   * Global Traffic Management (GTM): You can specify a time range and query operation logs within that range. You can also use **Advanced search** to filter operation logs. In the **Action** column, you can click **Details** to view operation details and the API request and response bodies.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">In the operation logs of Global Traffic Manager (GTM), operations automatically completed by GTM such as <strong>Health status change</strong>, <strong>Distribute DNS records</strong>, and <strong>Trigger an alarm</strong> are categorized as <strong>Automatic</strong>.      </div>

   * BytePlus PrivateZone: You can specify a time range and query operation logs within that range. You can also use **Advanced search** to filter operation logs. In the **Action** column, you can click **Details** to view operation details and the API request and response bodies.
