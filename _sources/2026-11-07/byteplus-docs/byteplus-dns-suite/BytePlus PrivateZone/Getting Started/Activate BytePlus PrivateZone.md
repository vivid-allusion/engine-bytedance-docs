Before using BytePlus PrivateZone for DNS resolution, you must activate the service.

<span id="steps"></span>
## Steps

Complete the following steps to activate BytePlus PrivateZone.


1. Open the [BytePlus PrivateZone console](https://console.byteplus.com/dns-suite/dns/privatezone/zones).

2. On the **Activate** page, check the **User agreement** checkbox. Click **Submit order**.

3. On the **Confirm order information** page, confirm the order details and click **Next step**.


You have now successfully activated BytePlus PrivateZone.

Next, you need to create a domain. See [Create a Domain](https://docs.byteplus.com/docs/byteplus-dns-suite/YBQ0UN?type=preview).
