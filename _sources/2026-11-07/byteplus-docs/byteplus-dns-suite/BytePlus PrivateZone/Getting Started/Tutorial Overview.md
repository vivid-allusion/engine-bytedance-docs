This tutorial demonstrates how to use BytePlus PrivateZone.

<span id="business-scenario"></span>
### Business Scenario

In this quick start, let's assume you have the following business needs:


* You have created a [BytePlus Virtual Private Cloud (VPC)](https://www.byteplus.com/en/product/vpc). The VPC is named `vpc01`, with an ID of `vpc-xxxxx`.

* You have added a [BytePlus Elastic Compute Server(ECS) instance](https://www.byteplus.com/en/product/ecs) within the VPC. The private IP address of the ECS instance is `10.0.1.128`.


You want resources within the VPC to be able to access the ECS instance, which has an IP address of `10.0.1.128`, via the domain name `ecs.example.com`.
