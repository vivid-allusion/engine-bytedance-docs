This document introduces how to verify whether DNS requests are forwarded to the resolver according to forwarding rules.

<span id="steps"></span>
## Steps

Send a DNS query from your on\-premise IDC. The domain name in the DNS query should be the one you set in the forwarding rule of your on\-premise IDC's DNS server. If you receive the resolution result returned by the resolver, it indicates that DNS inbound forwarding is effective.
