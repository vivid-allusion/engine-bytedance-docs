This document introduces how to create an inbound VPC. The inbound VPC is used to establish a network connection with an on\-premise IDC/third\-party cloud service.

<span id="steps"></span>
## Steps

Follow the steps below to create an inbound VPC.


1. In the region of your choice, create a VPC. For the creation method, refer to [Creating a VPC](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC).

2. Establish a network connection between the inbound VPC and the on\-premise IDC/third\-party cloud service. You can use the following products to achieve connectivity between the inbound VPC and the on\-premise IDC/third\-party cloud service.

   * [BytePlus Cloud Enterprise Network](https://www.byteplus.com/en/product/cen)

   * [BytePlus Direct Connect](https://www.byteplus.com/en/product/directconnect)

   * [BytePlus Transit Router](https://www.byteplus.com/en/product/tr)

   * [BytePlus Virtual Private Network](https://www.byteplus.com/en/product/vpn)
