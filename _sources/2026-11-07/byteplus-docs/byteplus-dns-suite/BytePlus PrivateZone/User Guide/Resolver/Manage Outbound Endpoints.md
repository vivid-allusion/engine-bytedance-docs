This document describes how to create, update, or delete outbound endpoints.

<span id="create-an-outbound-endpoint"></span>
## Create an outbound endpoint

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">After you create an outbound endpoint, BytePlus PrivateZone will charge for the outbound endpoint. See <a href="https://docs.byteplus.com/docs/byteplus-dns-suite/43T5hU">Billing</a>.</div>


* <div data-tips="true" data-tips-type="tip">If you no longer need an outbound endpoint, you can delete it. An outbound endpoint will continue to be billed until it is deleted.</div>



Follow these steps to create an outbound endpoint.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Outbound endpoint** tab.

2. Click **Create outbound endpoint**. On the **Create outbound endpoint** page, configure the parameters for the outbound endpoint. See [Step 3: Create an outbound endpoint](https://docs.byteplus.com/docs/byteplus-dns-suite/OxDblm).

3. After configuring the parameters, click **OK**. It takes about 30 seconds for the outbound endpoint to be successfully created.


<span id="updating-an-outbound-endpoint"></span>
## Updating an outbound endpoint

Follow these steps to update an outbound endpoint.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Outbound endpoint** tab.

2. Find the outbound endpoint you want to update. Click **Edit** in the **Actions** column.

3. On the **Edit outbound endpoint** page, update the parameters of the outbound endpoint. See [Step 3: Create an outbound endpoint](https://docs.byteplus.com/docs/byteplus-dns-suite/OxDblm).

4. After updating the parameters, click **OK**.


<span id="delete-an-outbound-endpoint"></span>
## Delete an outbound endpoint

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">If an outbound endpoint is associated with one or more rules, you cannot delete that outbound endpoint. You need to disassociate it from the rules before you can delete the outbound endpoint.</div>


Follow these steps to delete an outbound endpoint.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Outbound endpoint** tab.

2. Find the outbound endpoint you want to delete. Click **Delete** in the **Actions** column. Click **OK** in the pop\-up window.
