## Example scenarios

<span id="multi-region-hybrid-cloud"></span>
### Multi\-region hybrid cloud

Your service uses a multi\-region hybrid cloud architecture based on BytePlus Cloud Enterprise Network and BytePlus Direct Connect. To achieve disaster recovery, your on\-premise IDC is deployed in multiple regions. When a on\-premise IDC in a certain region fails, you need to switch the traffic to an available on\-premise IDC to ensure service availability. To achieve this goal, you need to ensure that BytePlus public cloud services in all regions can access the resources of the on\-premise IDC through domain names.
