This document describes how to create, update, or delete rules.

<span id="create-a-rule"></span>
## Create a rule

Follow these steps to add a rule.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Rules** tab.

2. Click **Create rule**. On the **Create rule** page, configure the parameters for the rule. See [Step 4: Create a Rule in the Resolver](https://docs.byteplus.com/docs/byteplus-dns-suite/Zd7JQO).

3. After configuring the parameters, click **OK**. The rule you added takes effect immediately.


<span id="update-a-rule"></span>
## Update a rule

Follow these steps to update a rule.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Rule** tab.

2. Find the rule you want to update. Click **Edit** in the **Actions** column.

3. On the **Edit rule** page, update the parameters of the rule. See [Step 4: Create a Rule in the Resolver](https://docs.byteplus.com/docs/byteplus-dns-suite/Zd7JQO).

4. After updating the parameters, click **OK**. The update takes effect immediately. BytePlus PrivateZone does not cache rules.


<span id="delete-a-rule"></span>
## Delete a rule

Follow these steps to delete a rule.


1. Open the [Resolver](https://console.byteplus.com/dns-suite/privatezone/resolver) page. Select the **Rules** tab.

2. Find the rule you want to delete. Click **Delete** in the **Actions** column. Click **OK** in the pop\-up window. The deletion takes effect immediately.
