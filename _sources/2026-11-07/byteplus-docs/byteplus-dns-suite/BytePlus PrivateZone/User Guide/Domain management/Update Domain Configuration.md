This document introduces how to update your domain configuration in BytePlus PrivateZone.

<span id="prerequisites"></span>
## Prerequisites

You have [created a domain](https://docs.byteplus.com/docs/byteplus-dns-suite/PU6MMV).

<span id="steps"></span>
## Steps

Complete the following steps to update your domain configuration.


1. Open the [BytePlus PrivateZone console](https://console.byteplus.com/dns-suite/dns/privatezone/zones).

2. On the **Domain management** page, find the domain you wish to update. Click **Manage**.

3. Select the **Domain information** tab. Click **Modify** on the page.

4. In the **Modify basic information** window that pops up, update the basic information of the domain. After updating, click **Confirm**. You can modify the following information:

   * Basic information:

      * Remarks for the domain

      * The status of recursive resolution

      * The status of load balancing

   * VPC information

      * The VPC associated with the domain

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you enabled intelligent DNS when creating the domain, you cannot change the status of <strong>Intelligent DNS</strong> in <strong>Basic information</strong>. Also, you cannot modify <strong>VPC information</strong>. See <a href="https://docs.byteplus.com/docs/byteplus-dns-suite/-Gvd2s">Implement Intelligent DNS</a>.   </div>
