Table Storage for HBase supports custom alert policies, allowing you to use the Cloud Monitor service to monitor the performance and health of HBase instances. This topic describes how to create alert policies for HBase instances.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [HBase console](https://console.byteplus.com/db/hbase).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click the name of the target instance.

4. At the top of the page, click **Monitoring**.

5. In the upper\-right corner of the **Monitoring** tab, click **Create alert strategy**.

6. On the **Create alarm strategy** page, configure the parameters based on your business needs. For details on parameter configuration, see [Create an alert policy.](https://docs.byteplus.com/en/docs/cloudmonitor/Creating-an-alarm-strategy)

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">When configuring the <strong>Alarm object</strong> on the <strong>Create alarm strategy</strong> page, select <strong>Database \> Table Storage for HBase</strong> as the <strong>Resource type</strong>.   </div>
