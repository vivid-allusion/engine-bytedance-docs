Table Storage for HBase supports viewing performance monitoring data for instance, RegionServer nodes, and tables in graphical charts. You can use monitoring data to fully understand the operating status of your instance and quickly locate problems. This topic describes how to view monitoring data for an HBase instance.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [HBase console](https://console.byteplus.com/db/hbase).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. On the **Instances** page, click the name of the target instance.

4. At the top of the page, click **Monitoring**.

5. On the **Monitoring** tab, you can select the **Instance**, **RegionServer**, or **Table** tab to view detailed data for each monitoring metric within a specified time range, such as the last hour.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">For details on each monitoring metric, see <a href="https://docs.byteplus.com/en/docs/HBase/Monitoring_metrics">Monitoring metrics</a>.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">When viewing table\-level monitoring, you can select up to 8 tables at a time to view their detailed monitoring data.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">In the upper\-right corner of the <strong>Monitoring</strong> tab, you can click <strong>View more metrics</strong> to go to the Cloud Monitor page. You can also click <strong>Create alert strategy</strong> to create alerts. For detailed instructions, see <a href="https://docs.byteplus.com/en/docs/HBase/Creating_alert_policies">Creating alert policies</a>.   </div>
