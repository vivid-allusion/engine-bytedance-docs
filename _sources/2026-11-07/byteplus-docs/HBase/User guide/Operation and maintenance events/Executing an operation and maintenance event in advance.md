Table Storage for HBase allows you to execute some pending maintenance events in advance. This topic describes how to execute an operation and maintenance event in advance.

<span id="DGhMHAS1"></span>
## Prerequisites

The maintenance event is in the **Waiting for execution** state.

<span id="4QnSKPJN"></span>
## Procedure


1. Log on to the [HBase console](https://console.byteplus.com/db/region:db+cn-beijing/hbase).

2. In the upper\-left corner of the top menu bar, select the project and region for the instance.

3. In the left\-side navigation pane, select **Operation and maintenance event**.

4. On the **Operation and maintenance event** page, click **Execute now** in the **Actions** column for the target maintenance event.

5. In the pop\-up dialog box, confirm the effects of the operation and click **OK**.
