Reserved keywords are special character strings reserved by the database system. They have specific meanings and uses, so these reserved keywords cannot be used as account names. This article summarizes the reserved keywords for Table Storage for HBase.


|Parameter |Keyword description |
|---|---|
|AccountName |When creating a database account, the following reserved keywords cannot be used:<br><br><br>* `system`<br><br>* `anonymous`<br><br>* `__admin__`<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Reserved keywords are case\-insensitive, meaning you cannot use any uppercase or lowercase reserved keywords, such as <code>SYSTEM</code>, <code>Anonymous</code>, and <code>__ADmin__</code>.</div><br> |
