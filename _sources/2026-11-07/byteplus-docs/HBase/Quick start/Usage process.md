Table Storage for HBase is a database compatible with the standard HBase access protocol. This document describes the overall process of creating, configuring, and connecting to an instance of Table Storage for HBase to help you get started quickly.

<span id=".5YeG5aSH5bel5L2c"></span>
## Prerequisites


* A BytePlus account has been registered. For account registration, refer to [Sign Up and Verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* VPC and subnet have been created. See [Creating VPC](https://docs.byteplus.com/en/docs/vpc/Building-an-IPv4-VPC).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


|Steps |Notes |
|---|---|
|Create instance |The first step to using Table Storage for HBase is to determine the node specifications and storage capacity for your instance. For instructions on how to create an instance, see [Creating an instance](https://docs.byteplus.com/en/docs/HBase/Creating_an_instance). |
|Set allowlist |Add the IP addresses of devices that need to connect to the instance to the allowlist. Only devices in the allowlist can access the instance. For instructions on how to set the allowlist, see [Configuring an allowlist](https://docs.byteplus.com/en/docs/HBase/Configuring_an_Allowlist). |
|Connect Instance |You can use the following methods to connect to the instance:<br><br><br>* [Connecting to the instance using the Java API](https://docs.byteplus.com/en/docs/HBase/Connecting_to_the_instance_using_the_Java_API)<br><br>* [Connecting to the instance using the HBase Shell](https://docs.byteplus.com/en/docs/HBase/Connecting_to_the_instance_using_the_HBase_Shell) |
