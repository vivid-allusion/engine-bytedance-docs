## Data storage for IoV scenarios

Provides low\-cost storage for massive data, ensures acceptable read latency in high\-concurrency write scenarios, and efficiently supports the storage and analysis of massive data for IoV. 

Architectural Advantages:


* High throughput, high performance, and high reliability.

* Decoupled storage and compute architecture supports independent and elastic horizontal scaling.

* High compression ratio and hot/cold data separation to reduce storage costs.

* Interoperability with the big data ecosystem provides high\-speed data processing and analysis.
