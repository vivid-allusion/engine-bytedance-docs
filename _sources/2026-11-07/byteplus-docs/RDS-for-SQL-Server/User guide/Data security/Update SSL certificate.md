An SSL certificate automatically generated by BytePlus is valid for 1 year by default; the validity of a custom certificate is determined by its own settings. If a certificate is not updated after it expires, clients or applications will be unable to connect to the RDS for SQL Server instance through an SSL\-encrypted connection. This topic describes how to update SSL certificates in the RDS for SQL Server console.

<span id="p84cOTMQ"></span>
## Prerequisites


* You have [Created an instance](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/creating-instance-for-user-guide?lang=en), and it is **Running**.

* SSL encryption is enabled. For details, see [Set up SSL encryption](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/setting-ssl-encryption?lang=en).


<span id="IUldIRHe"></span>
## Precautions


* Updating the SSL certificate will restart the RDS for SQL Server instance. Proceed with caution.

* SSL certificates automatically generated by BytePlus are valid for 1 year. You can update the certificate at any time without affecting your business. After the update, the certificate will be valid for another year. The validity period of a custom certificate is determined by your certificate's settings.

* **Update the SSL certificate's validity period and re\-download and configure the CA certificate before it expires. Failure to update it on time will result in the following:** 

   * **The RDS for SQL Server instance will fail to restart, which will affect normal business operations.** 

   * **Applications or clients using SSL\-encrypted connections will be unable to connect to the SQL Server instance.**  You can add the trust server certificate parameter to the connection string to temporarily restore service connectivity.


<span id="n199KFSZ"></span>
## Procedure

After enabling SSL encryption, you can determine the validity of the **SSL** certificate and whether it needs to be updated by checking the **SSL certificate validity** status and the **SSL certificate validity period** on the SSL tab. Update the SSL certificate before it expires.

<div data-tips="true" data-tips-type="danger">If the <strong>SSL certificate validity period</strong> section displays the prompt <strong>"The certificate is about to expire, please update it."</strong>, update the certificate immediately.</div>


The update steps for different certificate types are as follows:


<Tabs>
<Tab zoneid="TpMElZ4O8L" title="The certificate is auto-generated by BytePlus.">
<TabTitle>The certificate is auto-generated by BytePlus.</TabTitle>

1. Log on to the [RDS for SQL Server console](https://console.byteplus.com/db/sql-server).

2. In the upper\-left corner of the top menu bar, select the project and region where the instance is located.

3. On the **Instances** page, click the name of the target instance.

4. On the Instance details page, click **Security**.

5. On the **Data Security** tab, click the **SSL tab**.

6. On the SSL tab, click **Update certificate**.

7. In the pop\-up window, click **Confirm**.

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="default" data-wrapper-indent="1">The SSL certificate update is complete when the instance status changes from <strong>SSL changing</strong> back to <strong>Running</strong>.   </div>
   

8. After the update is complete, download and reconfigure the SSL CA certificate. For more information, see steps b~d in [Set up SSL encryption](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/setting-ssl-encryption?lang=en).
