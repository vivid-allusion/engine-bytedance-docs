After binding a tag to a specified instance, the tag key or tag value can be modified at any time according to business requirements. This document describes the steps for editing tags.

<span id="operation-steps"></span>
## Operation steps


1. Log in to [RDS for SQL Server console](https://console.byteplus.com/db/sql-server).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.

3. Locate the target instance on the **Instance List** page and click the Edit icon in the **Tag** column. You can also click the name of the specified instance and click the edit icon in the tab line of the basic information area.

4. In the pop\-up **Edit Tag** window, reset the **Tag key** or **Tag value**. tag setting rules should be followed when setting tags, please refer to the [label setting rules](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/associating-tag) for details.

5. Click **OK**.
