The cloud database SQL Server version has been connected to the cloud monitoring service, and the alarm rules are managed through the cloud monitoring service.

<span id="operation-steps"></span>
## Operation steps


1. Log in to [RDS for SQL Server console](https://console.byteplus.com/db/sql-server).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.

3. Click **Instance List** in the left navigation bar.

4. On the **instance list** page, click the target instance name.

5. At the top of the page, click the **Monitor Alerts** tab.

6. Click **Create Alert Rule** to go to the Create Alert Policy page of the Cloud Monitoring Service.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When configuring an alert object on the Create Alert Policy page, you need to select the resource type <strong>Cloud Database RDS SQL Server Edition</strong> . For more information, see <a href="https://docs.byteplus.com/en/docs/cloudmonitor/Creating-an-alarm-strategy">Create an alert policy</a>.</div>
