In the Historical Events menu, operations on RDS for SQL Server resources are recorded. This article describes how to view historical events.

<span id="operation-steps"></span>
## **Operation steps**


1. Log in to [RDS for SQL Server console](https://console.byteplus.com/db/sql-server).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.

3. On the **Historical Events** page, you can view a list of historical events.

   * The event list displays event information for the last 24 hours by default.

   * The event list displays the event time, event name, operation time, event status, resource type, instance ID and other information of the historical event. By setting the instance ID, event name, event status (success, running, timeout, failure), start time, end time, and other conditions, the event list can be filtered and displayed.

   * In the event list, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1418f99f9dae68ecb49204118bdbec2e.png) </span> of the target event to view the details of the event. Details include user ID, event ID, event name, resource type, instance ID, event status, start time, finish time, and event parameters.
