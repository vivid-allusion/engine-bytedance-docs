This article describes how to delete a database in the RDS for SQL Server console.

<span id="prerequisite"></span>
## prerequisite

The database has been created. For more information, see [Creating Database](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/creating-database).

<span id="precautions"></span>
## Precautions


* After deleting the database, the data in the database will be lost, and caution is required.

* Only one database can be deleted at a time.


<span id="operation-steps"></span>
## Operation steps


1. Log in to [the RDS for SQL Server console](https://console.byteplus.com/db/sql-server).

2. In the upper left corner of the top menu bar, select the project and region to which the instance belongs.

3. On the **instance list** page, click the target instance name.

4. At the top of the page, click the **Database Administration** tab.

5. On the **Database Administration** tab, click Delete of the Target Database Operations column.

6. Are **you sure to delete?**  Dialog box, click **Delete** .
