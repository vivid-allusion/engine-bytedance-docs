RDS for SQL Server has the following features to help you build the ideal application.

**Powerful hardware guarantees performance**

The powerful IO performance of the extremely fast SSD cloud disk guarantees the read and write access of the database, providing 99.99999% data durability.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">A service cycle is one natural month, and data persistence = (total data in the service cycle \- the amount of data lost in the service cycle)/total data in the service cycle \* 100%.</div>


**Support for high\-availability architectures**

Provide online master and standby high availability architecture to ensure service availability. After the master node fails, it will automatically detect and switch between master and standby in seconds.

**Support backup recovery**

Based on full database backup, incremental backup, and log backup, it can support lossless recovery within 7 days to 1 year to ensure data reliability.

**Support read and write separation**

RDS for SQL Server of Enterprise Cluster Edition instances supports the creation of read\-only instances, which are used to disperse the read and write operations of the database to different nodes, helping you reduce the read pressure on the primary instance and thus improve the overall processing power of the system.
