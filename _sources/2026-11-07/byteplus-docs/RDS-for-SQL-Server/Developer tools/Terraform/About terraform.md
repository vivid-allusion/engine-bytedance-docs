Terraform is an open\-source IT infrastructure orchestration tool that supports the use of configuration files to define infrastructure or applications. With Terraform, you can easily orchestrate and version Volcano Engine cloud resources, such as creation, management, maintenance, and more.

<span id="advantage"></span>
## advantage


* Infrastructure is code, and it is described in a high\-level configuration language to enable it to be coded and versioned for easy sharing and reuse.

* Multi\-cloud deployment allows you to deploy similar infrastructure to Volcano Engine, other cloud providers, or on\-premises data centers, and manage cloud resources from different cloud providers simultaneously through the same profile.

* Execution plan Terraform supports generating an execution plan that displays the state of Terraform when apply is called to avoid accidents when Terraform operates on the infrastructure.

* Resource Graph Terraform supports building a graph of all resources, creating and modifying any non\-dependent resources in parallel, and building the infrastructure as efficiently as possible. Operators can gain insight into the dependencies in the infrastructure.
