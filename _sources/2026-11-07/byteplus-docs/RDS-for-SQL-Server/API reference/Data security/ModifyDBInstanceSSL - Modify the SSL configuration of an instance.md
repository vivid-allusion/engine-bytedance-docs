## Request parameters

This section describes only the request parameters specific to this API and some common parameters. For more information, refer to [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action** <span data-label="purple">string</span><span data-api-tag="require|WCCGb3">必选</span> `Example value: ModifyDBInstanceSSL`

The operation to perform. The value is `ModifyDBInstanceSSL`.



**Version** <span data-label="purple">string</span><span data-api-tag="require|Ih6q3Y">必选</span> `Example value: 2022-01-01`

The API version is 2022\-01\-01.



**InstanceId** <span data-label="purple">string</span> <span data-api-tag="require|ZYnzkb">必选</span>`Example value: mssql-6474c9******`

Instance ID.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can call the DescribeDBInstances operation to query the instance ID.</div>




**Type** <span data-label="purple">string</span> <span data-api-tag="require|B666Yh">必选</span>`Example value: Enable`

Configures SSL encryption. The values are as follows:


* `Enable`: Enables SSL encryption.

* `Disable`: Disables SSL encryption.

* `Renew`: Renews the SSL certificate.

* `Change`: Modifies the SSL configuration.



**ForceEncryption ** <span data-label="purple">boolean </span>`Optional` `Example value: true`

Specifies whether to enable forced SSL encryption for the instance. Valid values:


* `true`: Indicates that this feature is `enabled`.

* `false`: (Default) Indicates that this feature is disabled.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">This parameter is required when Type is set to <code>Change</code>.</div>


* <div data-tips="true" data-tips-type="tip">This parameter is optional when Type is set to <code>Enable</code> or <code>Renew</code>.</div>


* <div data-tips="true" data-tips-type="tip">This parameter is invalid when Type is set to any other value.</div>




**Certificate ** <span data-label="purple">string </span>`Optional` `Example value: tos-cn-beijing.volces.com:mssql-test**:cert/ssl_***.pfx`

If this parameter is not specified, a certificate automatically generated by BytePlus is used. If specified, you must provide the TOS address of the custom SSL certificate (.pfx format) in the format `<endpoint>:<bucket>:<object>`.



**Password ** <span data-label="purple">string </span>`Optional` `Example value: *********`

The password for the custom SSL certificate ( .pfx format). The password must meet the following requirements:


* It must be 8 to 32 characters long.

* It must contain at least three of the following character types: uppercase letters, lowercase letters, numbers, and special characters.

* Special characters are `!@#$%^&*()_+-=`.
