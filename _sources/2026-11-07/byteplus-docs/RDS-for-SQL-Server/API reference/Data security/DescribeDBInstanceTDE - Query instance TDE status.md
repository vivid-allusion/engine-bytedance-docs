## Response parameters

This section describes only the response parameters specific to this API. For more information, refer to [Return structure](https://docs.byteplus.com/en/docs/byteplus-platform/reference-request-response).



**InstanceId ** <span data-label="purple">string </span>`Example value: mssql-6474c9******`

Instance ID.



**TDEStatus ** <span data-label="purple">string </span>`Example value: Enable`

The TDE status of the instance.


* `Enable`: The TDE status for the instance is enabled.

* `Disable`: The TDE status for the instance is disabled.



**TDEMode ** <span data-label="purple">string </span>`Example value: MSSQL_Default`

The TDE encryption certificate generation mode for the instance.


* `MSSQL_Default`: An encryption certificate generated by SQL Server.

* `User_Default`: A custom certificate uploaded by the user.



**DBStatus ** <span data-label="purple">object[] </span>`Example value: [ { "DBName": "test_db", "Enable": true } ]`

Database encryption status.


**DBName ** <span data-label="purple">string </span>`Example value: db1`

Database name.



**Enable ** <span data-label="purple">boolean </span>`Example value: true`

Specifies whether to enable encryption. Possible values:


* `true`: The database is encrypted.

* `false`: The database is not encrypted.
