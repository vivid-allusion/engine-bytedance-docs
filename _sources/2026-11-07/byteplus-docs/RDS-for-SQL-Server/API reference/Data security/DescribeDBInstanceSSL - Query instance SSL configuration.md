## Response parameters

This section describes only the response parameters specific to this API. For more information, refer to [Return structure](https://docs.byteplus.com/en/docs/byteplus-platform/reference-request-response).



**InstanceId ** <span data-label="purple">string </span>`Example value: mssql-6474c95******`

Instance ID.



**SSLEnable ** <span data-label="purple">boolean </span>`Example value: true`

The status of the SSL encryption feature, with the following values:


* `true`: Enabled.

* `false`: Disabled.



**ForceEncryption ** <span data-label="purple">boolean </span>`Example value: true`

Indicates whether forced SSL encryption is enabled for the instance. The possible values are:


* `true`: Indicates that this feature is `enabled`.

* `false`: Disabled.



**IsValid ** <span data-label="purple">boolean </span>`Example value: false`

Indicates whether the certificate is valid. Possible values:


* `true`: Valid.

* `false`: Invalid.



**SSLExpireTime ** <span data-label="purple">string </span>`Example value: 2026-02-10T12:45:48Z`

The certificate expiration time in UTC, formatted according to RFC3339: yyyy\-MM\-ddTHH:mm:ssZ.



**TLSVersion ** <span data-label="purple">string </span>`Example value: 1.2`

Supported TLS version.



**Address ** <span data-label="purple">string </span>`Example value: mssql6474c95******.rds-mssql.ivolces.com`

The protected address.



**RequireUpdate ** <span data-label="purple">boolean </span>`Example value: false`

Specifies whether an update is required. Valid values:


* `false`: No update is required.

* `true`: An update is required.



**CertType ** <span data-label="purple">string </span>`Example value: Volc_SSL`

The type of the SSL certificate. The value can be one of the following:


* `Volc_SSL`: A certificate automatically generated by BytePlus,

* `Custom_SSL`: A user\-uploaded custom certificate.
