Asynchronous request

## Request parameters

This section describes only the request parameters specific to this API and some common parameters. For more information, refer to [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).



**Action** <span data-label="purple">string</span><span data-api-tag="require|MrbLVD">必选</span> `Example value: ModifyDBInstanceTDE`

The action to perform. Set the value to `ModifyDBInstanceTDE`.



**Version** <span data-label="purple">string</span><span data-api-tag="require|QLIgZV">必选</span> `Example value: 2022-01-01`

The API version is 2022\-01\-01.



**InstanceId** <span data-label="purple">string</span><span data-api-tag="require|L9qnpY">必选</span> `Example: mssql-123abc******`

Instance ID.



**TDEStatus** <span data-label="purple">string</span><span data-api-tag="require|qe5pgX">必选</span> `Example value: Enable`

Whether to enable TDE encryption for the instance. Currently, only the value `Enable` is supported.



**TDEMode** <span data-label="purple">string</span><span data-api-tag="require|SRKDax">必选</span> `Example value: MSSQL_Default`

The instance's TDE encryption mode.


* `MSSQL_Default`: automatically generated by the Volcano SQL Server kernel.

* `User_Default`: the user uploads a custom certificate.



**DBStatus ** <span data-label="purple">object[] </span>`Optional` `Example: [ {"DBName":"db1", "Enable": true}, {"DBName":"db2", "Enable": false} ]`

The status description for databases to be encrypted or decrypted.


**DBName** <span data-label="purple">string</span><span data-api-tag="require|QmoA6r">必选</span> `Example: db1`

Database name.



**Enable ** <span data-label="purple">boolean </span><span data-api-tag="require|pkbmte">必选</span> `Example value: true`

Specifies whether to enable encryption. Possible values:


* `true`: The database is encrypted.

* `false`: The database is not encrypted.




**Certificate ** <span data-label="purple">string </span>`Optional` `Example: tos-cn-beijing.volces.com:mssql-test:my.cer`

The certificate file for TDE encryption, provided as a TOS path in the format `<endpoint>:<bucket>:<xxx.cer>`. The certificate length is affected by the content complexity of the Subject field and must be within the range of 1,866 to 2,922 bytes.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This is valid only when the TDEMode parameter is set to <code>User_Default</code>.</div>




**PrivateKey ** <span data-label="purple">string </span>`Optional` `Example: tos-cn-beijing.volces.com:mssql-test:mycert.pvk`

The private key for the TDE encryption certificate. You can enter it as a TOS path in the format `<endpoint>:<bucket>:<xxx.pvk>`. The private key must match the public key of the configured certificate.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">This is valid only when the TDEMode parameter is set to <code>User_Default</code>.</div>




**Password ** <span data-label="purple">string </span>`Optional` `Example value: Key*******`

The private key password of the certificate for TDE encryption. The private key password of the certificate must meet the following requirements:


* It can only be uppercase and lowercase letters, numbers, and the following special characters `~!@#$%^&\\*()-_+=?`.

* The length must be between 8 and 32 characters.

* Contain at least three of the following: uppercase letters, lowercase letters, numbers, or special characters.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Effective only when the TDEMode parameter is set to <code>User_Default</code>.</div>
