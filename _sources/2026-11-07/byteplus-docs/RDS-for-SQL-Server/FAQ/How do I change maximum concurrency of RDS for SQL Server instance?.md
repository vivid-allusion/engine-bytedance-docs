This article describes how to modify the maximum concurrency of a SQL Server instance.


1. Connect the instance via SSMS. For more details, see [Connection instance](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/connect-instance).

2. In the left navigation bar, right\-click the instance and select **Properties**.

3. In the **Server Properties** dialog box, click **Advanced**.

4. Set the value of **Max Degree of Parallelism**.

5. Click **OK**.
