RDS for SQL Server is a stable, reliable and scalable online database service created by BytePlus based on the world\-class commercial database product Microsoft SQL Server. This topic describes the overall process of creating, configuring, and connecting instances of BytePlus RDS for SQL Server, helping you get started quickly with RDS for SQL Server.

<span id="preparation"></span>
## **Preparations**


* A BytePlus account has been registered and completed verification. For the detailed method, refer to [Sign Up and Verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* As per the regulations in the Chinese mainland, you must have completed real name registration before you can activate and use cloud services on nodes in the Chinese mainland through BytePlus.  For more details, refer to [Real name registration](https://docs.byteplus.com/en/docs/byteplus-platform/docs-real-name-registration).


<span id="usage-flow"></span>
## Usage process


1. **Selecting architecture type**: RDS for SQL Server supports high\-availability instance types, adopting a classic high\-availability architecture with one primary and one secondary node. It is suitable for industries such as the Internet, Internet of Things, retail e\-commerce, logistics, and gaming.

2. **Selecting instance specification**: The parameters of the instance specification include the number of CPU cores, memory size, and maximum number of connections. You can choose the appropriate specifications according to your business needs, see [Primary instance specification](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/master-instance-specification) for details.

3. **Creating** ** an instance**: For the method of creating an instance, please refer to [Creating an instance](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/creating-instance).

4. **Creating an allowlist**: A device is authorized to access the instance only if its IP address has been added to an allowlist, and that allowlist has been associated to the instance. For details, please refer to [Creating an allowlist](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/create-allowlist) and [Associating instances to allowlists](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/associating-instances-to-allowlists).

5. **Connecting an instance**: Connect an instance through RDS for SQL Server client. For more details, see [Connecting an instance](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/connect-instance).
