The annual package helps you save money to a greater extent, which is suitable for long\-term use scenarios. This article introduces the billing introduction and billing cycle for purchasing RDS for SQL Server instances on a monthly basis.

<span id="brief-introduction"></span>
## brief introduction

In scenarios where you need to use the RDS for SQL Server for a long time, you can purchase the RDS for SQL Server of the annual subscription type by prepaying for several months or up to three years, which is more favorable than the billing type instance. On the Volcano Engine platform, when you purchase the cloud database SQL Server version for more than one year, you can enjoy the annual discount given by the platform. For long\-term stable business, the annual and monthly cloud database SQL Server version is your best choice.

<span id="billing-introduction"></span>
## Billing introduction

The annual monthly subscription example supports monthly purchase (can be purchased for 1 to 9 months) and annual purchase (can be purchased for 1 to 3 years) respectively. For specific discounts, please refer to the actual order settlement page.

<span id="settlement-cycle"></span>
## settlement cycle

The billing cycle of the monthly RDS for SQL Server instance is the duration of your purchase (subject to UTC + 8 time). The starting point of a billing cycle is the time when the resource is opened (accurate to seconds), and the ending point is 23:59:59 on the expiration date.

For example, if an annual subscription instance is created at 14:00:00 on July 1, 2021, and the purchase period is 1 month, the billing period is: July 1, 2021 14:00:00 to August 1, 2021 23:59:59.

<span id="precautions"></span>
## Precautions

If the account is in arrears, you can still use the purchased SQL Server instance normally. However, you cannot make a new purchase or renew the fee until the outstanding fee is paid. For more details, see [Arrears and expiration](https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/arrears-and-expiration).
