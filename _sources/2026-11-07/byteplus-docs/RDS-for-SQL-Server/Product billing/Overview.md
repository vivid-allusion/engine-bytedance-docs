This article describes the billing types, instance lifecycles, and pricing supported by RDS for SQL Server.

<span id="billing-type"></span>
## Billing type


|Billing type |explain |
|---|---|
|year and month |That is, you pay in advance when you create a new instance. Prices are more affordable than per\-volume billing, suitable for long\-term demand. |
|billing by volume |That is, a paid order is generated every hour, and the fee is deducted from the Byteplus account according to the instance specification when the order was generated. Instances can be released immediately after use, saving costs and suitable for short\-term needs. |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For more information on pricing, see <a href="https://docs.byteplus.com/en/docs/RDS-for-SQL-Server/charge-items-and-price">Billing Items and Prices</a>.</div>


<span id="instance-lifecycle"></span>
## instance lifecycle

The billing type determines how the SQL Server instance lifecycle is calculated, where:


* **Billing by volume**: The instance lifecycle starts when you create it successfully and stops when you release the instance.

* **Package Year Package Month**: The instance life cycle starts after you create it successfully, and the instance will be automatically released after expiration.
