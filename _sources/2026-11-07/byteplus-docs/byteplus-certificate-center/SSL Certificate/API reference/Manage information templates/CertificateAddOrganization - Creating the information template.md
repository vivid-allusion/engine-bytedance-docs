Call this API to create an information template.

## Precautions

* Each tenant can have up to 200 information templates at the same time (covering both enterprise and personal types).

* Request frequency: Up to 20 requests per second per tenant.

## Request parameters

The table below lists only the request parameters unique to this API and some common parameters. For more information, see [Common parameters](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-parameters).

### Query

**Action ** string必选 `Example: CertificateAddOrganization`

Action to execute. Set the value to CertificateAddOrganization.

**Version ** string必选 `Example: 2024-10-01`

Current API version is 2024\-10\-01.

### Body

**Type ** string必选 `Example: Enterprise`

The type of the information template to be created. This parameter can take the following values:

* `Individual`: Personal type template, which can only be used to apply for DV certificates

* `Enterprise`: Enterprise type template, which can be used to apply for DV, OV, and EV certificates

**Tag ** string必选 `Example: doc-test`

Set the name of the information template.

**Name ** string`optional` `Example: Test Enterprise`

Set the enterprise name.

> This parameter is required when Type is `Enterprise`.

**Address ** string`optional` `Example: 10 Anson Road, #20-01`

Set the enterprise address.

> This parameter is required when Type is `Enterprise`.

**City ** string`optional` `Example: Singapore`

Set the city where the enterprise resides.

> This parameter is required when Type is `Enterprise`.

**Province ** string`optional` `Example: Singapore`

Set the province or state where the enterprise is located.

> This parameter is required when Type is `Enterprise`.

**Country ** string`optional` `Example: SG`

Set the two\-letter country code of the enterprise, e.g., CN for China and US for the United States.

> This parameter is required when Type is `Enterprise`.

**PostalCode ** string`optional` `Example: 079903`

Set the postal code of the enterprise location. (Only applicable to enterprises located in Mainland China.)

**Department ** string`optional` `Example: System department`

Set the enterprise department.

**Email ** string`optional` `Example: doc-test@example.com`

Set the enterprise email.

**BusinessLicenseNo ** string`optional` `Example: 11100000000000000R`

Set the enterprise's Unified Social Credit Code.

**Contact ** object必选 `Example: `

Set the certificate contact information.

**FirstName ** string必选 `Example: San`

Contact's first name.

**LastName ** string必选 `Example: Zhang`

Contact's last name.

**Email ** string必选 `Example: zhangsan@example.com`

Contact e\-mail.

**Phone ** string必选 `Example: +6581234567`

Contact phone number.

**IdCardNo ** string`optional` `Example: 310000202010202020`

Contact ID card number.

**ProjectName ** string`optional` `Example: default`

Set the name of the BytePlus project to which the information template belongs.

> If this parameter is not specified, the information template will be added to the `default` project.

**Tags ** object[]`optional` `Example: [{"Key":"env","Value":"test"}]`

List of resource tags bound to the information template. Each element is a set of tag key\-value pairs, used to classify and manage information templates.

**Key ** string必选 `Example: env`

The tag key.

**Value ** string必选 `Example: test`

The tag value.

## Response parameters

Only the unique response parameters of this interface are listed in the table below. For more information, see [Response structure](https://docs.byteplus.com/en/docs/byteplus-platform/reference-request-response).

**OrganizationId ** string`Example: `org\-879f6502723b4e0f8762cf3528f4\*\*\*\*

The ID generated by the certificate center for the information template created for you.
