## Operation process


1. [Order an SSL certificate](https://docs.byteplus.com/byteplus-certificate-center/docs/creating-certificate-order).

   Order an SSL certificate that meets your business requirements from BytePlus Certificate Center. We provide DV/OV/EV certificates from mainstream CAs, suitable for different types of domains. By ordering an SSL certificate, you create a certificate instance. The certificate instance is the entry point for all related operations of the SSL certificate. For example, submitting a certificate request, downloading the certificate after it is issued, etc.

2. [Submit SSL certificate request](https://docs.byteplus.com/byteplus-certificate-center/docs/requesting-a-certificate).

   The CA is the authoritative organization that issues certificates. You can submit an SSL certificate request to the CA through your certificate instance. We recommend using the quick purchase method to directly submit the certificate request after placing the order.

   When submitting the certificate request, you need to provide the protected domain name, contact information, and other relevant information.

3. [Complete domain and organization validation](https://docs.byteplus.com/byteplus-certificate-center/docs/understanding-the-review-process-for-certificate-requests).

   The CA will issue the certificate only after verifying the authenticity and validity of your request information. You need to prove ownership of the domain. For OV/EV certificate requests, you also need to cooperate with the CA to complete organization validation, which may involve manual confirmation and require relevant personnel from the organization to answer phone calls.

4. [Download and install certificate](https://docs.byteplus.com/byteplus-certificate-center/docs/downloading-certificates).

   The certificate needs to be correctly installed on the web server in order to achieve HTTPS communication between the client and the server. Since the configuration methods for different types of web servers are different, you need to install the certificate based on the actual server type after the certificate is issued. We provide guidance on installing certificates on common web servers for your reference.
