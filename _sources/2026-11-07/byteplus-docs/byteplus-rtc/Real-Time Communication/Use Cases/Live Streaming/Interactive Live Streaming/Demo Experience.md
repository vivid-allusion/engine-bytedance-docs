## Instruction

For a better experience, prepare at least 2 mobile phones:


1. Download and install the trial package.

2. Log in \-\> select [Interactive Live Streaming]

3. The host can tap [Create a LIVE], and enter the preview page where you can switch between front\- and back\-facing cameras, select image enhancement video effects, and configure settings. Then, the host can tap [Go LIVE] to enter the live streaming room. Viewers can tap a room on the list page to join and watch the live stream.

4. The host can tap the [PK] icon to invite other hosts to co\-host. The host can tap the [Disconnect PK] icon to end co\-hosting.

   The host and co\-host can see each other's network status and microphone/camera status, and can mute one another.

5. The host can tap the [Request] icon, invite audiences in the room to be a guest, and manage their status, including muting them, disabling their camera, and disconnecting them; Audiences can tap the [Request] icon to request to be a guest. After becoming a guest, they can also control their own microphone and camera.
