## Instruction

For a better experience, prepare at least 2 mobile phones:


1. Download and install the app.

2. Log in \> select the Scenario module and enter the [Game Room].

3. Tap [Select Game] to select a mini\-game and tap [Create Room] to create a room.

4. You can play a game directly in the game box on the screen.

5. To become a co\-host, tap any open co\-host seat or the Request icon at the bottom of the room. You can remove guests from the co\-host seat via seat management.
