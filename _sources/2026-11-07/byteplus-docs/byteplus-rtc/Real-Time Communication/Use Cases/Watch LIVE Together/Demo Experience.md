## Instruction

For a better experience, prepare at least 2 mobile phones:


1. Download and install the app.

2. Log in.

3. Tap [Watch LIVE together] \> Enter Room ID \> Tap [Join Room]. Users can set Image Enhancement video effects before joining the room; users with the same Room ID will join the same call.

4. The room owner can tap the [Watch together] icon in the lower right corner and enter the LIVE source link to open the Watch LIVE together interface. While watching, the room owner can change the live content by entering a new link.

5. All users can adjust the video and voice call volumes, enable audio ducking, and play the video in full screen.

6. The room owner can tap [Close] at the upper right corner to return to the video chat interface; other users can tap [Close] to exit the current room.
