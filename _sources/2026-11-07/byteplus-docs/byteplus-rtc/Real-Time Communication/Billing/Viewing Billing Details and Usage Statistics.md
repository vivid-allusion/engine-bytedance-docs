## Viewing bills


* **Entry**: [Billing center-Bill management](https://console.byteplus.com/finance/bill/detail)。

* **Billing types**: You can view various types of billing information as needed, such as bill overviews, unpaid bills, and detailed statements. For detailed instructions, see [Managing bills](https://docs.byteplus.com/en/docs/byteplus-platform/docs-billing-management).


<span id="viewing-usage-statistics"></span>
## Viewing usage statistics

You can view the usage statistics for various services generated by RTC applications (such as audio and video calls, cloud recording). For specific operations, see [Viewing usage statistics](https://docs.byteplus.com/docs/byteplus-rtc/docs-1392586#viewing-usage-statistics).
