During a conversation with the AI, you can send custom text at any time for the AI to broadcast, and you can set the broadcast priority to precisely control whether it is played immediately or queued for later playback. This feature can be used to guide user interaction, remind users of important notes, or comfort users in scenarios where the system is delayed.

## Use Cases

&nbsp;


|Scenario |Description |Example |
|---|---|---|
|AI companion practice |When the user does not speak for a long time, the AI plays content to encourage the user to continue interacting. |"I noticed you have not spoken for a while. Would you like me to explain the previous content?" |
|Board game host |The AI acts as the host, guiding users through the game process. |"It is now player A's turn to speak. Please begin." |
|Safety supervision |When user questions or content generated by the large model are non\-compliant, the AI guides the user to adjust the conversation content. |"Sorry, the conversation content does not comply with community guidelines." |
|Delay mitigation |When Function Calling or network connectivity causes significant AI response delays, guide the user to wait patiently. |"Processing, please wait." |

## Implementation Method

<span id=".6YCa6L-H5pyN5Yqh56uv5a6e546w"></span>
### Server\-Side Implementation

Call the `UpdateVoiceChat` API, set `Command` to `ExternalTextToSpeech`, and pass the content to be played. The API also supports the following capabilities:


* **Control the AI playback priority**: Use the `InterruptMode` field to set playback priority. `1` means interrupt the current interaction and play immediately. `2` means wait until the current interaction ends, then play. `3` means low priority. If the AI is interacting, the system discards the text.

* **Pass custom business information**: Use the `AdvanceConfig.CustomInfo` field to pass custom business information in key\-value format. The system transparently forwards this information to the client or server together with subtitles from the same round through `customInfo`. This field supports subtitle modes where `SubtitleMode` is `0`, `1`, or `3`. For subtitle format details, see [Real-time subtitles (conversation records)](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-1337284). Pass only information required for business association. Do not pass sensitive data, and keep the object small to avoid oversized subtitle messages.


```JSON
{
   "AppId": "YOUR_AppId", // Consistent with StartVoiceChat
  "RoomId": "YOUR_RoomId", // Consistent with StartVoiceChat
  "TaskId": "YOUR_TaskId", // Consistent with StartVoiceChat
    "Command": "ExternalTextToSpeech", // Must be this value
    "Message": "That was a great story. Can you tell another one?", // Text content to be broadcast, maximum 200 characters.
    "InterruptMode": 1   // Select playback priority as needed, can be 1, 2, or 3
}
```

### Client\-Side Implementation

On the client side, call the RTC SDK API [sendUserBinaryMessage (using Android as an example)](https://docs.byteplus.com/en/docs/byteplus-rtc/docs-70080#RTSRoom-senduserbinarymessage) to send the custom text to be broadcast to the specified AI. Specifically, configure the following parameters:


* `userId`: Enter the Bot's ID (that is, the `StartVoiceChat` configuration's `AgentConfig.UserId`).

* `buffer`: Must follow the format below:

    const std::string& user_id,
    const std::string& content,
    int interrupt_mode,
    int round_id,
    const nlohmann::json& custom_info
) {
    nlohmann::json json_data;
    json_data["Command"] = "ExternalTextToSpeech";
    json_data["Message"] = content;
    json_data["InterruptMode"] = interrupt_mode; // Supported values for InterruptMode: 1, 2, and 3

        {"CustomInfo", custom_info}
    };
    sendUserBinaryMessage(user_id, json_data.dump());

void buildBinaryMessage(const std::string& magic_number, const std::string& message, size_t& binary_message_length, std::shared_ptr<uint8_t[]>& binary_message) {
    auto magic_number_length = magic_number.size();
    auto message_length = message.size();

    binary_message_length = magic_number_length + 4 + message_length;
    binary_message = std::shared_ptr<uint8_t[]>(new uint8_t[binary_message_length]);
    std::memcpy(binary_message.get(), magic_number.data(), magic_number_length);
    binary_message[magic_number_length] = static_cast<uint8_t>((message_length >> 24) & 0xFF);
    binary_message[magic_number_length+1] = static_cast<uint8_t>((message_length >> 16) & 0xFF);
    binary_message[magic_number_length+2] = static_cast<uint8_t>((message_length >> 8) & 0xFF);
    binary_message[magic_number_length+3] = static_cast<uint8_t>(message_length & 0xFF);
    std::memcpy(binary_message.get()+magic_number_length+4, message.data(), message_length);
}

int sendUserBinaryMessage(const std::string &uid, const std::string& message) {
    if (rtcRoom_ != nullptr)
    {
        size_t length = 0;
        std::shared_ptr<uint8_t[]> binary_message = nullptr;
        buildBinaryMessage("ctrl", message, length, binary_message);
        return rtcRoom_->sendUserBinaryMessage(uid.c_str(), static_cast<int>(length), binary_message.get());
    }
    return -1;
}

// Send a text-to-speech (TTS) command so the agent plays the specified text and transparently forwards custom business information.
public void sendTTSMessage(
        String userId,
        String content,
        int interruptMode,
        int roundId,
        JSONObject customInfo
) {
    JSONObject json = new JSONObject();
    try {
        json.put("Command", "ExternalTextToSpeech");
        json.put("Message", content);
        json.put("InterruptMode", interruptMode); // Supported values for InterruptMode: 1, 2, and 3

        JSONObject advanceConfig = new JSONObject();
        advanceConfig.put("RoundID", roundId);
        advanceConfig.put("CustomInfo", customInfo);
        json.put("AdvanceConfig", advanceConfig);
    } catch (JSONException e) {
        throw new RuntimeException(e);
    }
    String jsonString = json.toString();
    byte[] buildBinary = buildBinaryMessage("ctrl", jsonString);
    sendUserBinaryMessage(userId, buildBinary);
}


private byte[] buildBinaryMessage(String magic_number, String content) {
    byte[] prefixBytes = magic_number.getBytes(StandardCharsets.UTF_8);
    byte[] contentBytes = content.getBytes(StandardCharsets.UTF_8);
    int contentLength = contentBytes.length;

    ByteBuffer buffer = ByteBuffer.allocate(prefixBytes.length + 4 + contentLength);
    buffer.order(ByteOrder.BIG_ENDIAN);
    buffer.put(prefixBytes);
    buffer.putInt(contentLength);
    buffer.put(contentBytes);
    return buffer.array();
}

public void sendUserBinaryMessage(String userId, byte[] buffer) {
    if (rtcRoom_ != null) {
        rtcRoom_.sendUserBinaryMessage(userId, buffer, MessageConfig.RELIABLE_ORDERED);
    }
}

// Example call. Replace with your actual business variables.

customInfo.put("finish", true); // Replace with the actual business status
customInfo.put("biz", "demo"); // Replace with the actual business field

const COMMAND_KEY = 'ctrl';
const engine = VERTC.createEngine('Your AppID'); // Your RTC application AppID

/**
 * @brief Command type

enum COMMAND {
  /**
   * @brief Send a text-to-speech (TTS) command so the agent plays the specified text.
   */
  EXTERNAL_TEXT_TO_SPEECH = 'ExternalTextToSpeech',
};

/**
 * @brief Interruption priority type
 */
enum INTERRUPT_PRIORITY {
  /**
   * @brief Placeholder
   */
  NONE,
  /**
   * @brief High priority. The agent terminates the current interaction and directly plays the provided text.
   */
  HIGH,
  /**
   * @brief Medium priority. The agent plays the provided text after the current interaction ends.
   */
  MEDIUM,
  /**
   * @brief Low priority. If the agent is interacting, it discards the provided text. If no interaction is in progress, it plays the provided text.
   */
  LOW,
};

/**
 * @brief Wrap a string as TLV
 */
function stringToTLV(inputString: string, type = '') {
  const typeBuffer = new Uint8Array(4);

  for (let i = 0; i < type.length; i++) {
    typeBuffer[i] = type.charCodeAt(i);
  }

  const lengthBuffer = new Uint32Array(1);
  const valueBuffer = new TextEncoder().encode(inputString);

  lengthBuffer[0] = valueBuffer.length;

  const tlvBuffer = new Uint8Array(typeBuffer.length + 4 + valueBuffer.length);

  tlvBuffer.set(typeBuffer, 0);

  tlvBuffer[4] = (lengthBuffer[0] >> 24) & 0xff;
  tlvBuffer[5] = (lengthBuffer[0] >> 16) & 0xff;
  tlvBuffer[6] = (lengthBuffer[0] >> 8) & 0xff;
  tlvBuffer[7] = lengthBuffer[0] & 0xff;

  tlvBuffer.set(valueBuffer, 8);

  return tlvBuffer.buffer;
};


/**
 * @brief Send a text-to-speech (TTS) command so the agent plays the specified text and transparently forwards custom business information
 */
function sendTTSMessage({
  botName,
  message,
  interruptMode = INTERRUPT_PRIORITY.HIGH,
  roundId,
  customInfo,
}: {
  botName: string;
  message: string;
  interruptMode?: INTERRUPT_PRIORITY;
  roundId?: number;
  customInfo?: Record<string, unknown>;
}) {
  engine.sendUserBinaryMessage(
    botName,
    stringToTLV(
      JSON.stringify({
        Command: COMMAND.EXTERNAL_TEXT_TO_SPEECH,
        Message: message,
        InterruptMode: interruptMode,
        ...(roundId || customInfo
          ? {
              AdvanceConfig: {
                ...(roundId ? { RoundID: roundId } : {}),
                ...(customInfo ? { CustomInfo: customInfo } : {}),
              },
            }
          : {}),
      }),
      COMMAND_KEY,
    ),
  );
}

## Application Practice: Pass Custom Text and Transparently Forward Business Information

When you need to play a large amount of custom text as an AI reply, such as a streaming reply from an external large model or long business scripts, you may also need to know which business reply the playback belongs to, whether the current reply has ended, and whether you should continue waiting. In this case, you can write your business protocol into `CustomInfo`, and the system transparently forwards it to the client or server together with subtitles.

The following example shows how to split a long reply from an external large model into multiple playback segments. To reduce first\-packet latency, you can split custom text into multiple complete sentences and send them in sequence. The process is as follows:


1. Split the external text into complete sentences.

2. For each segment that belongs to the same complete content, such as the same LLM reply, use the same `AdvanceConfig.RoundID` and send `ExternalTextToSpeech` in sequence, either by calling `UpdateVoiceChat` on the server side or `sendUserBinaryMessage` on the client side.

3. Include `CustomInfo.finish` in every request. Set it to `false` for intermediate segments and `true` for the final segment.

4. Aggregate subtitles on the client by `roundId`. Even if you receive `paragraph: true`, continue waiting for later segments. Mark the complete external content as finished only after you receive `customInfo.finish: true` under the same `roundId`, for example when you render one complete conversation bubble in the UI.

5. If playback is interrupted and a new round starts, stop waiting for the end marker of the old `roundId` and discard the pending state of the old round.


For example, if you split a long text into two segments and use the server\-side implementation, your business server can send the following requests in sequence.

The first request passes an intermediate segment:

```JSON
{
    "AppId": "YOUR_AppId",
    "RoomId": "YOUR_RoomId",
    "TaskId": "YOUR_TaskId",
    "Command": "ExternalTextToSpeech",
    "Message": "For a three-day trip to Beijing, you can first visit the Forbidden City and Jingshan Park.",
    "InterruptMode": 2,
    "AdvanceConfig": {
        "RoundID": 11,
        "CustomInfo": {
            "finish": false
        }
    }
}
```


The second request passes the final segment and sets the end marker:

```JSON
{
    "AppId": "YOUR_AppId",
    "RoomId": "YOUR_RoomId",
    "TaskId": "YOUR_TaskId",
    "Command": "ExternalTextToSpeech",
    "Message": "On the last day, you can visit the Summer Palace. Have a pleasant trip.",
    "InterruptMode": 2,
    "AdvanceConfig": {
        "RoundID": 11,
        "CustomInfo": {
            "finish": true
        }
    }
}
```


The client receives two subtitle segments, and both include `paragraph: true`. However, only the second subtitle carries `customInfo.finish: true`. Therefore, use `customInfo.finish` to determine that this long\-text playback has ended, rather than `paragraph`.

Example client\-side processing logic (pseudocode):

```TypeScript
type SubtitleItem = {
  text: string;
  roundId?: number;
  sequence?: number;
  customInfo?: Record<string, unknown>;
};

function handleSubtitleMessage(message: SubtitleMessage) {
  for (const item of message.data as SubtitleItem[]) {
    if (typeof item.roundId !== 'number') {
      continue;
    }

    // Use roundId to aggregate multiple text segments that belong to the same complete content, such as one LLM reply.
    appendSubtitle(item.roundId, item.text);

    // paragraph only indicates that the current ExternalTextToSpeech input has ended.
    // The business convention finish=true indicates that the complete long text, or full reply, has been fully delivered.
    if ((item.customInfo as { finish?: boolean } | undefined)?.finish === true) {
      markResponseFinished(item.roundId);
    }
  }
}

function handleInterruptOrNewRound(activeRoundId: number) {
  // This indicates that your business logic has already received an interruption event or switched to a new active roundId.
  // The old round may never receive finish=true, so clear the pending state of the old round.
  discardPendingResponsesBefore(activeRoundId);
}
```

## FAQ


* **Q1: If the AI is set to support voice interruption and the custom text content does not interrupt the AI's output, and this interaction is interrupted by voice, when will the custom text content be played?** 

   In this case, the custom text content will be discarded.

* **Q2: Will the played custom text content be included in the conversation history?** 

   Yes.

* **Q3: If the AI is set to support voice interruption, the custom text content does not interrupt the AI's output. If custom text content playback is interrupted, will this text content be included in the conversation history?** 

   The content that has already been output will be included in the conversation history.
