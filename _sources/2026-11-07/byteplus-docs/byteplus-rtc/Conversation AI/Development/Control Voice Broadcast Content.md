If the text generated by the large model contains non\-dialogue content (such as narration or status words), Markdown symbols, or LaTeX formulas, direct speech synthesis will result in broadcasts that sound unnatural and are difficult to understand. The system supports filtering or converting the above text before synthesis to ensure that AI voice responses sound natural to human listeners.

&nbsp;


|Features |Note |
|---|---|
|**Filter non\-dialogue content** |Instructs the LLM to encapsulate custom non\-dialogue information (actions, emotions, business instructions) within specific brackets. The TTS engine will skip bracketed content during synthesis, while the client can still obtain this information via complete subtitle callbacks, enabling business logic triggers. |
|**Filter Markdown tags** |Automatically removes Markdown formatting symbols such as `**` and `#` to ensure fluent speech playback. |
|**LaTeX formula reading** |Converts LaTeX formulas (such as `a^2 + b^2 = c^2`) into natural language that can be read aloud. |

## **Filter Non\-Dialogue Content (using brackets)** 

You can use the `IgnoreBracketText` configuration to instruct the LLM via prompt to encapsulate custom non\-dialogue information (such as action descriptions, emotion tags, or business instructions) within specific brackets. When the system performs speech synthesis, it will automatically skip the content inside the brackets to ensure the broadcast is natural and fluent. Meanwhile, the client can obtain the information inside the brackets via subtitle callbacks, which can be used to trigger UI updates, control AI playback emotions, and other local business logic.


* **User question**: `I heard you are going to the Dragon Palace of the East Sea tomorrow. What treasure do you want to take from the Dragon King?`

* **LLM response**: `I, Old Sun, will go to the Dragon Palace of the East Sea tomorrow (excited), and I have long been craving the Golden Cudgel. How could I easily let such a treasure slip away (thrilled)! Haha!`

* **AI broadcast**: `I, Old Sun, will go to the Dragon Palace of the East Sea tomorrow, and I have long been craving the Golden Cudgel. How could I easily let such a treasure slip away! Haha!`

* **Subtitle display**: `I, Old Sun, will go to the Dragon Palace of the East Sea tomorrow (excited), and I have long been craving the Golden Cudgel. How could I easily let such a treasure slip away (thrilled)! Haha!`


<span id="3ed377cf"></span>
### Important notes

Filtered content is usually displayed in subtitles. If the bracketed content is at the very end of the reply and is determined to be an independent sentence (with no real semantic content following it), the content inside the brackets will not be displayed in subtitles. For example:


* `...I will speak without reservation! (full of confidence).` → `(full of confidence).` Will not be displayed in subtitles.

* `...I will speak without reservation (full of confidence)!` → `(full of confidence)!` Will be displayed in subtitles.


<span id="3db7bf8d"></span>
### Step 1: Set the prompt

In the system prompt of the LLM, guide the LLM to place content that does not need to be read aloud (such as psychological activities or actions) into the specified brackets.

> For Ark or third\-party large models, you need to write the prompt in `LLMConfig.SystemMessages`.


* **Supported brackets**: Chinese parentheses `（）`, English parentheses `()`, Chinese square brackets `【】`, English square brackets `[]`, and English curly brackets `{}`.

* **Content length limit**: The content within a single set of brackets must not exceed 500 characters, otherwise it may not be filtered.


**Prompt example**

```Plain
## Role 
You are Sun Wukong from 'Journey to the West'. Please answer questions in the tone of Sun Wukong.
## Skill
If you have descriptions of inner emotions or actions in your responses, mark them with (), and the content within a single pair of () must not exceed 500 characters.
```


<span id=".5q2l6aqkLTLvvJrlvIDlkK_ov4fmu6Tlip_og70="></span>
### Step 2: Enable the filtering feature

Call the `StartVoiceChat` API and configure the types of brackets to be filtered in the `Config.TTSConfig.IgnoreBracketText` field.

```JSON

{
    "TTSConfig": {
        // 1:（）, 2: (), 3:【】, 4: [], 5: {}
        "IgnoreBracketText": [1, 2],  // Filters content inside Chinese brackets （） and English brackets ()
        // Other TTS configurations...
    }
}
```


<span id="58d18cb7"></span>
### Obtain information inside brackets (optional)

To transmit business instructions using this feature, the client needs to listen for subtitle callbacks and extract information inside the brackets. For specific implementation methods, see [Real-time Subtitles (Dialog Records)](https://docs.byteplus.com/docs/byteplus-rtc/docs-1337284).

## Filter Markdown Tags

This feature automatically filters Markdown symbols (such as `**`, `#`, and so on) in the text returned by the LLM to prevent the AI from reading them as ordinary text, ensuring smooth and natural voice broadcast.


* **LLM output**: `Please execute the **grep** command to view the logs.`

* **AI voice broadcast**: `Please execute the grep command to view the logs.`

* **Subtitles**: `Please execute the **grep** command to view the logs.`


<span id="c53ec333"></span>
### Limitation

This feature is only supported when using the BytePlus TTS service.

<span id="e7ae46fd"></span>
### Configuration

When calling the `StartVoiceChat` API, set `disable_markdown_filter` in `ProviderParams.Additions` to `true`.

```JSON
{
    "TTSConfig": {
        "Provider": "volcano_bidirection",
        "ProviderParams": {
            "Additions": {
                "disable_markdown_filter": true
            }
        }
    }
}
```

## Read Aloud LaTeX Formulas

This feature converts LaTeX formulas in the text returned by the LLM into natural language suitable for voice broadcast before performing speech synthesis.


* **LLM output**: `According to the formula a^2 + b^2 = c^2 ...`

* **AI voice broadcast**: `According to the formula a squared plus b squared equals c squared ...`

* **Subtitles**: `According to the formula a^2 + b^2 = c^2 ...`


<span id="5ebf55b2"></span>
### Limitation

This feature is only supported when using the BytePlus TTS service.

<span id="e9b46325"></span>
### Configuration

When calling the `StartVoiceChat` API, you need to configure the following parameters in `ProviderParams.Additions`:


* `disable_markdown_filter`: Must be set to `true`.

* `enable_latex_tn`: Set to `true`.


```JSON
{
    "TTSConfig": {
        "Provider": "volcano_bidirection",
        "ProviderParams": {
            "Additions": {
                "disable_markdown_filter": true, // Must be enabled
                "enable_latex_tn": true          // Enable formula reading
            }
        }
    }
}
```
