You can control the AI's speaking tone (e.g., cheerful, sad), speech rate, and volume using instruction tags (automatically generated by the LLM or injected by your business logic in real time). Additionally, passing the user's question as context to the TTS enables the AI to deliver replies with emotions that better fit the conversation scenario, achieving more empathetic and human\-like interaction.

<span id="fbdc673e"></span>
## Limitation

This feature is only available when using BytePlus TTS models:

&nbsp;


|Supported Model |BytePlus TTS 2.0 |BytePlus TTS 1.0 |
|---|---|---|
|Implementation |Natural Language Instruction Tags `{{"additions":...}}` |Structured Parameter Tags `{{"audio_params":...}}` |
|Controllable Dimensions |Emotion, speech rate, volume, etc. |Only preset emotions and intensity |
|Scope of Effect |The entire response. The instruction applies to the whole text segment. |The tag’s clause and all subsequent clauses until a new tag. |


<span id="57dad46f"></span>
## How It Works


1. **Tag Embedding (LLM or Business Logic)**  :

   * **LLM Auto\-generation**: The LLM analyzes the conversation context in real time and automatically inserts tags in a specified format into the response text.

   * **Real\-time Business Injection**: During the conversation, your business logic dynamically sends instructions based on specific events (such as user complaints or telling a joke) to inject instruction tags for the AI's next response.

2. **Tag Parsing (Platform)**  : The system recognizes double\-brace `{{ }}` tags and converts them into TTS parameters.

3. **Emotion Rendering & Expression (TTS)**  :

   * **BytePlus TTS 2.0**: Understands the "requirements" expressed in the tags as natural language and adjusts the speech accordingly.

   * **BytePlus TTS 1.0**: Strictly executes the "values" specified in the tags to adjust the speech.


<span id="f48f8fa6"></span>
## Implementation

<span id="9162ffb7"></span>
### Step 1: Enable Parsing and Context

When calling `StartVoiceChat`, configure `TTSConfig.Context`:

> `QuoteUserQuestion`: Only effective when using BytePlus TTS 2.0, and has lower priority than instruction tags.


```JSON
"TTSConfig": {
  "Provider": "BytePlus",
  //...other configurations
  "Context": {
    "TagParse": true,           // Set to true to enable tag parsing
    "QuoteUserQuestion": true   // Defaults to true. Passes the user's question to the TTS so the model can automatically match an appropriate response tone based on the conversation context. Only supported by BytePlus TTS 2.0.
  }
}
```


<span id="bc5f1596"></span>
### Step 2: Pass Instruction Tags

<span id="c888f395"></span>
#### Method 1: Write a Prompt to Guide the LLM to Generate Tags

Guide the LLM to automatically generate instruction tags in the standard format based on the conversation context through system prompts.


<Tabs>
<Tab zoneid="t7iqshbjeS" title="BytePlus TTS 2.0">
<TabTitle>BytePlus TTS 2.0</TabTitle>

Control the AI's emotion, speech rate, volume, etc., using natural language instruction tags.

<span id="673fcad1"></span>
#### Tag Requirements


* **Format**:

   ```Plain
   {{"additions":{"context_texts":["Natural language description"]} }}
   ```
   

   A space must be left before closing `}}`. The system parses tags using `{{` and `}}` as boundaries, and missing the space will cause parsing to fail.

* **Tag Placement & Scope of Effect**:

   * The `context_texts` tag governs the entire paragraph. By default, it is recommended to place the tag at the beginning of the text or before the first sentence.

   * However, to optimize the time\-to\-first\-frame (TTFT), it is recommended that the first sentence of a response remain plain text (without tags). Add tags starting from the second sentence as needed.


<span id="6c436ba4"></span>
#### Prompt Writing Example

```Plain
- Task: Analyze the user's emotions in the conversation and embed emotion instruction tags in the response text to guide the downstream TTS to broadcast with a matching tone, emotion, and rhythm.
- Tag Format: {{"additions":{"context_texts":["Description"]} }}
- Common Controls:
  - Speech Rate: ["Speak a bit slower"]
  - Emotion: ["In a particularly sad tone"]
  - Volume: ["Lower your voice a bit"]
- Constraints:
  - The tag affects the entire response. Provide a single, consistent emotional direction.
  - To optimize TTFT, keep the first sentence as plain text and add tags starting from the second sentence.
  - Tags must be placed before the sentence they affect, and a space must be left before the closing `}}`. For example: `Hello! {{"additions":{"context_texts":["Be more cheerful"]} }} Nice to meet you.`.
```



* **Expected LLM Output**: `{{"additions":{"context_texts":["Make your tone even more cheerful"]} }}That's awesome, congratulations!`

* **AI Speech** (cheerful tone): `That's awesome, congratulations!`

* **Subtitle Display**: `That's awesome, congratulations!`


</Tab>
<Tab zoneid="rYmnneVBeZ" title="BytePlus TTS 1.0">
<TabTitle>BytePlus TTS 1.0</TabTitle>

Precisely control the AI's speech emotion and intensity using structured parameter tags.

<span id="9b3ecb5d"></span>
#### Tag Requirements


* **Format**:

   ```Plain
   {{"audio_params":{"emotion":"Emotion_Code","emotion_scale":Intensity_Value} }}
   ```
   

   * **Field Descriptions**:

      * `emotion`: Must be in English. Support for emotion tags is limited to specific TTS 1.0 voices. For available values and their corresponding emotions, refer to [TTS 1.0 Voices](https://docs.byteplus.com/en/docs/byteplusvoice/voicelist#P5jIFQum).

      * `emotion_scale`: Emotion intensity, ranging from 1 to 5, with a default value of 4.

   * **Note**: A space must be left before the closing `}}`. The system parses tags using `{{` and `}}` as boundaries, and missing the space will cause parsing to fail.

* **Tag Placement & Scope of Effect**:

   * Tags must be placed before the sentence they are intended to affect. A tag applies to the clause it immediately precedes and all subsequent clauses until a new tag is encountered.

   * To optimize TTFT, it is recommended that the first sentence of a response remain plain text (without tags). Add tags starting from the second sentence as needed.


<span id="48ea7845"></span>
#### Prompt Example

> You need to list all the emotion values you intend to use in the prompt. Support for emotion tags is limited to specific TTS 1.0 voices. For available values and their corresponding emotions, refer to [TTS 1.0 Voices](https://docs.byteplus.com/en/docs/byteplusvoice/voicelist#P5jIFQum).


```Plain
- Task: Analyze the user's emotions in real time during the conversation and embed emotion instruction tags in the response text to guide the downstream TTS to broadcast with a matching emotion.
- Tag Format: `{{"audio_params":{"emotion": "Emotion code","emotion_scale": Emotion intensity value} }}`.
    - Supported emotion codes (`emotion`): happy, sad, angry, excited, fear.
    - Emotion intensity (`emotion_scale`): Ranges from 1 to 5. The default value is 4.
- Constraints:
  - To optimize TTFT, keep the first sentence as plain text and add tags starting from the second sentence.
  - Tags must be placed before the sentence they affect, and a space must be left before the closing `}}`.
```



* **Expected LLM Output**: `Nice weather out there!{{"audio_params":{"emotion":"happy","emotion_scale":5} }}Let's go out and play!`

* **AI Speech** (in a happy tone): `Nice weather out there! Let's go out and play!`

* **Subtitle Display**: `Nice weather out there! Let's go out and play!`

<span id="95d4b0f7"></span>
#### Method 2: Manually Pass Tags

During the conversation, you can dynamically inject instruction tags for the AI's next response based on real\-time events detected by your backend (such as the user telling a joke or expressing dissatisfaction). The tag applies globally to the next response.


1. In your backend business logic, identify triggers for changing the AI's emotion (such as recognizing keywords via ASR or triggering business logic).

2. Call the `UpdateVoiceChat` API:

   * `Command`: Set to `SetTTSContext`

   * `Message`: Pass a serialized JSON string. The instruction differs by model:

      * BytePlus TTS 2.0

         ```Plain
         "{\"Tag\":{\"additions\":{\"context_texts\":[\"Make the tone more cheerful\"]}}}"
         ```
         

      * BytePlus TTS 1.0

         ```Plain
         "{\"Tag\":{\"audio_params\":{\"emotion\":\"happy\",\"emotion_scale\":5}}}"
         ```
         

   For detailed instruction tag descriptions, refer to [Method 1: Write a Prompt to Guide the LLM to Generate Tags](https://docs.byteplus.com/docs/byteplus-rtc/docs-2139328#c888f395).


**Example**: using BytePlus TTS 2.0.

> Replace `YOUR_APP_ID`, `YOUR_ROOM_ID`, and `YOUR_TASK_ID` with your actual App ID, Room ID, and Task ID.


```JSON
{
  "AppId": "YOUR_APP_ID",
  "RoomId": "YOUR_ROOM_ID",
  "TaskId": "YOUR_TASK_ID",
  "Command": "SetTTSContext",
  "Message": "{\"Tag\":{\"additions\":{\"context_texts\":[\"Make the tone more cheerful\"]}}}"
}
```


<span id="7586739e"></span>
## Priority of Effect

The system follows this priority order:


1. **Instructions sent via UpdateVoiceChat.** 

2. **LLM Text Tags**: Inline tags automatically generated by the LLM.

3. **QuoteUserQuestion**: Passing the user's question as context.


For example, if the LLM returns a tag with a "sad" emotion, but you send a "happy" instruction via the `UpdateVoiceChat` API, the AI will ultimately broadcast in a "happy" tone.
