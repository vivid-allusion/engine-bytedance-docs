This topic lists the OpenAPIs for Vortex IP as follows.

|API name |Feature |
|---|---|
|[CreateVortexIP](https://docs.byteplus.com/en/docs/gavi-sept-test1/CreateVortexIP) |Apply for a Vortex IP instance. |
|[ModifyVortexIPAttributes](https://docs.byteplus.com/en/docs/gavi-sept-test1/ModifyVortexIPAttributes) |Modify the name and description of a Vortex IP. |
|[DescribeVortexIPs](https://docs.byteplus.com/en/docs/gavi-sept-test1/DescribeVortexIPs) |Query Vortex IP instances that meet the specified conditions. |
|[DescribeVortexIPAttributes](https://docs.byteplus.com/en/docs/gavi-sept-test1/ModifyVortexIPAttributes) |View the details of a Vortex IP. |
|[DescribeAutoRouteRules](https://docs.byteplus.com/en/docs/gavi-sept-test1/DescribeAutoRouteRules) |Query all supported Intelligent routing domains. |
|[AddVortexIPWhiteListEntries](https://docs.byteplus.com/en/docs/gavi-sept-test1/AddVortexIPWhiteListEntries) |Add allowlist entries for a Vortex IP in Internet mode. |
|[RemoveVortexIPWhiteListEntries](https://docs.byteplus.com/en/docs/gavi-sept-test1/RemoveVortexIPWhiteListEntries) |Delete allowlist entries for a Vortex IP in Internet mode. |
|[EnableVortexAccessLog](https://docs.byteplus.com/en/docs/gavi-sept-test1/EnableVortexAccessLog) |Enable access log for Vortex IP. |
|[DisableVortexAccessLog](https://docs.byteplus.com/en/docs/gavi-sept-test1/DisableVortexAccessLog) |Disable Vortex IP access log. |
|[DeleteVortexIP](https://docs.byteplus.com/en/docs/gavi-sept-test1/DeleteVortexIP) |Delete a VortexIP instance. |
