The Vortex IP log service records traffic data generated by internet access. Vortex IP delivers network access logs to [BytePlus Torch Log Service (TLS)](https://docs.byteplus.com/en/docs/6470/), helping you track business operation status and troubleshoot issues.​

## Instructions

* Vortex IP does not charge for log service. For log service billing rules, see [TLS Billing](https://docs.byteplus.com/en/docs/tls/billable_items).​

* If the selected log topic has no index configured, Vortex IP creates one by default. We recommend that you do not deliver Vortex IP access logs to the same log topic as other logs to avoid inconsistent search fields.​

* The parameters in the logs are shown in the following table.​

   |Parameter |Description |
   |---|---|
   |time |The request time. |
   |session_id |The client session identifier. |
   |session_timeout |The session persistence duration, in seconds.<br><br><br>* `0`: Disable session persistence.<br><br>* `&gt;0`: Enable session persistence and set its duration. |
   |client_ip |The client access IP. |
   |client_port |The client access port. |
   |protocol |The output format of the Egress IP. |
   |instance_id |The Vortex IP instance ID. |
   |service_type |The Vortex IP instance type.<br><br><br>* DataCenter: Dynamic data center proxy.<br><br>* ResidentialQuarter: Dynamic residential proxy.<br><br>* VideoOnly: Video\-specific proxy. |
   |exit_ip |The actual egress IP.<br><br>This parameter is returned only for Vortex IP instances with **Dynamic data center proxy**. |
   |country |The country code of the public egress IP. |
   |city |The city of the public egress IP. |
   |target_host |The target site hostname. |
   |request_time |Total time spent on the access connection, in seconds. |
   |status |The HTTP status code. |

## Before you begin

* You have enabled BytePlus TLS.

* You must configure the cross\-service permission over TLS for your target account.

   * First authorization: When enabling TLS, follow the guidance to complete cross\-service authorization.​

      > **tip**

      * > The authorized role will be displayed in the role list of the Identity and Access Management (IAM) console. Deleting the authorized role may cause cross\-service access failures. Proceed with caution.

      * > After deleting the authorized role, you must re\-authorize to continue using TLS.

   * Re\-authorization: In the **IAM \> Permission policy** page, [grant](https://docs.byteplus.com/en/docs/6257/65058#%E6%8E%88%E6%9D%83%E6%93%8D%E4%BD%9C%E6%96%B9%E6%B3%95) the account the cross\-service role access permission of **Vortex IPAccessTLSRole**.​

## Enable log service

1. Log in to the [Vortex IP console](https://console.byteplus.com/eip/region:eip+ap-southeast-1/vortexips).

2. In the top menu bar, select the region.

3. Click the name of the target Vortex IP instance in the Instances list.

4. Click the **Log Service** tab.

5. Click the button to the right of **Access log**![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_8979a605207f31b713bdab186e41a9b2.png).

6. Configure the log project and log topic.

   * Log project: Create or select a project used to manage Vortex IP traffic logs.​ A [log project](https://docs.byteplus.com/en/docs/tls/Managing_projects) is a fundamental unit for TLS resource management, enabling log resource isolation and access control between multiple users, projects, or products.

   * Log topic: Create or select a topic used to store Vortex IP traffic logs.​ A [log topic](https://docs.byteplus.com/en/docs/tls/Managing_topics) is a fundamental unit for TLS to manage logs. Features such as log ingestion, search and analysis, and consumption are performed at the granularity of log topics.

7. Click **OK** to complete the action.

## Disable log service

After you disable the Vortex IP log service, the log project and log topic are retained. To delete them, see [Delete topic](https://docs.byteplus.com/en/docs/tls/Managing_topics#.5Yig6Zmk5pel5b-X5Li76aKY) and [Delete project](https://docs.byteplus.com/en/docs/tls/Managing_projects#.5Yig6Zmk5pel5b-X6aG555uu).

1. Log in to the [Vortex IP console](https://console.byteplus.com/eip/region:eip+ap-southeast-1/vortexips).

2. In the top menu bar, select the region.

3. Click the name of the target Vortex IP instance in the Instances list.

4. Click the **Log Service** tab.

5. Click **Edit**.

6. In the pop\-up dialog box, click the button to the right of **Access log**![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_7221c162195f746c6ccc293c5a637401.png).

7. Click **OK** to complete the action.
