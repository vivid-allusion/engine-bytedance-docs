## Viewing from the Vortex IP console


1. Log in to the [Vortex IP console](https://console.byteplus.com/eip/region:eip+ap-southeast-1/vortexips).

2. In the top menu bar, select the region.

3. In the Vortex IP list, click the **monitoring** icon next to the target Vortex IP to enter the **Data Monitoring** tab.

4. On the **Data Monitoring** page, you can view the monitoring metric data of the current Vortex IP.

## View in the cloud monitor console  

View the monitoring data of the Vortex IP in the cloud monitor console. For more detailed steps, please refer to [Viewing the monitoring data of a cloud product](https://docs.byteplus.com/en/docs/cloudmonitor/Viewing-Cloud-Service-Monitor).
