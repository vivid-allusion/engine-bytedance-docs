When the Vortex IP is no longer needed, you can release the Vortex IP through this action.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">After releasing the Vortex IP, if the Elastic Compute Service (ECS) configured with it is associated with an Elastic IP (EIP), the target website can be accessed via the internet; otherwise, the target website cannot be accessed.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Vortex IP console](https://console.byteplus.com/eip/region:eip+ap-southeast-1/vortexips).

2. In the top menu bar, select the region.

3. In the Vortex IP list, click the **Release** button in the row of the target Vortex IP to open the confirmation dialog box for releasing.

4. Confirm the settings and click **Release EIP**.
