## Simple configuration

After applying for a Vortex IP, you only need to configure the service IP for the Elastic Compute Service (ECS) to automatically allow the ECS to access the target website through the access IP.

<span id=".5a6J5YWo56iz5a6a"></span>
## Secure and stable

Dynamically switch the access IP to avoid service unavailability caused by high\-frequency access.

<span id=".5a6e5pe255uR5o6n"></span>
## In real time monitoring

You can connect EIPs to the CloudMonitor service to monitor business metrics in real time. You can define metric thresholds and alert notifications to learn about exceptions in a timely manner.
