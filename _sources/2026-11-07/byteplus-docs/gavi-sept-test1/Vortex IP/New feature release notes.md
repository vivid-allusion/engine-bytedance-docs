This topic introduces the feature release and corresponding documentation updates for each version of Vortex IP.

## September 2026

|No. |Feature |Description |Stage |Documentation |
|---|---|---|---|---|
|1 |Session log support for Vortex IP |Vortex IP delivers network access logs to [BytePlus Torch Log Service (TLS)](https://docs.byteplus.com/en/docs/6470/) to record traffic data generated by public access. This helps you track business operation status and troubleshoot issues.​ |Invite\-only Beta |[Managing log service](https://docs.byteplus.com/en/docs/gavi-sept-test1/Managing-log-service) |
|2 |Feature enhancement |Vortex IP supports custom session persistence duration. |Invite\-only Beta |[Configuring endpoint generator](https://docs.byteplus.com/en/docs/gavi-sept-test1/Configure_the_endpoint_generator) |
