In order to meet the security protection needs in different scenarios, Cloud Security Center provides basic services and value\-added services. By reading this article, you can quickly understand the billing method, billing composition, billing formula and other billing information of Cloud Security Center.

**Billing method**

Cloud Security Center supports the billing method of annual and monthly prepayment. Annual and monthly prepayment is a billing method that pays first and then uses.


|**explain**<br><br>●The resource billing cycle of the annual and monthly package is the purchase cycle of the order (subject to UTC + 8 time). The starting point of a billing cycle is the time to open or renew the resource (accurate to seconds), and the ending point is 23:59:59 the day after the expiration date. The specific time is subject to the platform records.<br><br>●When the purchased service expires, if there is any remaining unused quota, you are not supported to continue using the service, and no refund of any kind is supported. |
|---|


**billing component**

Cloud Security Center billing is divided into:**Basic service billing**+**value\-added service billing**

●Basic service billing: The basic protection function package provided by the Cloud Security Center by version, such as vulnerability scanning, baseline inspection, intrusion alarm and other capabilities of host assets, are all basic services. Different versions support different basic services, and you can choose the appropriate version according to your needs. For details of functional differences between versions, please refer to functional characteristics.

●Value\-added service billing: Support services purchased and used separately. For example, application protection, mirror scanning, log analysis, etc.

**Renewal Instructions**

In order to ensure uninterrupted service, please renew the annual subscription and monthly instance in time. For more renewal rules, please refer to [Overview of renewal rules](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-of-renewal-rules).

**Expiration Note**

●After the prepaid instance of Cloud Security Center expires, you can no longer use the functions corresponding to the instance.

●For 15 days after expiration, keep the data and configuration, during which you can choose to renew the fee and continue to use it.

●If the expiration date exceeds 15 days and you do not renew (or purchase), your data and configuration will be released, and the released data and configuration cannot be recovered.

**Unsubscribe instructions**

Cloud Security Center supports "non\-7\-day no reason to unsubscribe". For more unsubscribe rules, please refer to [Unsubscription Management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-unsubscription-management).

●After successfully unsubscribing from a prepaid instance, all configuration and data for your corresponding function will be released and cannot be recovered.

●Vouchers and other discounts used for purchase, renewal, distribution, etc. will not be refunded when unsubscribing.

●For the instance of participating in the event purchase, if the product unsubscribe rule conflicts with the event rule, the event rule shall prevail.

**Arrears description**

Prepaid instances, no arrears.
