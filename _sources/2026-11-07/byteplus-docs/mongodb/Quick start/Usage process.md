BytePlus Document Database for MongoDB is a high\-performance NoSQL database that is 100% compatible with the open\-source MongoDB protocol. This topic describes the whole process of configuring, creating, connecting to, and using BytePlus Document Database for MongoDB instances to help you quickly get started with the Document Database for MongoDB.

<span id=".5YeG5aSH5bel5L2c"></span>
## Preparation


* A BytePlus account has been registered and completed verification. For the detailed method, refer to [Sign up and verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* As per the regulations in the Chinese mainland, you must have completed real name registration before you can activate and use cloud services on regions in the Chinese mainland through BytePlus. For more details, refer to [Real name registration](https://docs.byteplus.com/en/docs/byteplus-platform/docs-real-name-registration).

* Cross\-service access has been authorized to allow MongoDB to access other services (such as VPC and EIP). For specific procedures, refer to [Cross-service access authorization](https://docs.byteplus.com/en/docs/mongodb/cross-service-access-authorization).


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure

To get started with Document Database for MongoDB, complete the following actions.


|Procedure |Description |
|---|---|
|[1. Creating instance](https://docs.byteplus.com/en/docs/mongodb/create-instance) |The first step to get started with Document Database involves determining the instance architecture, database version, and configuration, then setting the account and password for connecting to the instance during its creation. |
|[2. Setting allowlist](https://docs.byteplus.com/en/docs/mongodb/set-allowlist) |Add the IP addresses of external devices that need to connect to the instance to the allowlist. Only devices in the allowlist can access the instance. |
|[3. Applying for public address](https://docs.byteplus.com/en/docs/mongodb/apply-public-address) (Optional) |MongoDB provides private network access to the database by default. You can also manually apply for a public address to allow devices outside the VPC to access the MongoDB instance. |
|[4. Connecting to instance](https://docs.byteplus.com/en/docs/mongodb/connect-instance-via-mongo-shell) |Use the Mongo shell tool to connect to the instance via private or public network access and perform various management actions. |
