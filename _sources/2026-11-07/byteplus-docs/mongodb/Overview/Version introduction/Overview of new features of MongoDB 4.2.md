This topic introduces the main new features of MongoDB version 4.2.

## Wildcard indexes

MongoDB 4.2 introduces the Wildcard Indexes feature, which allows you to query undetermined fields in documents. For more details on Wildcard Indexes, refer to [Wildcard Indexes](https://www.mongodb.com/docs/v4.4/core/index-wildcard/).

<span id=".5YiG5biD5byP5LqL5Yqh77yIZGlzdHJpYnV0ZWQtdHJhbnNhY3Rpb25z77yJ"></span>
## Distributed transactions

Starting with MongoDB 4.2, multi\-document transactions are also referred to as distributed transactions. With the distributed transactions feature, you can perform transactions across multiple operations, collections, databases, documents, and shards while ensuring transaction atomicity. For more details on distributed transactions, refer to [Distributed Transactions](https://www.mongodb.com/docs/v4.2/release-notes/4.2/#distributed-transactions).

<div data-tips="true" data-tips-type="tip">Document Database for MongoDB  and sharding cluster instances support distributed transactions starting from MongoDB 4.4.</div>
