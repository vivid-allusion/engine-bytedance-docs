This topic describes the common application scenarios of Document Database for MongoDB.

<span id=".5ri45oiP5pyN5Yqh6KGM5Lia"></span>
## Game service industry

The gaming industry is characterized by rapid user growth, a demand for overseas expansion, and often requires operations such as launching, separating, and combining game servers. Document Database for MongoDB offers various features that can conveniently and quickly meet the needs of scenarios such as launching, separating, and combining game servers. For example, based on the JSON document data object model, it can quickly support development iterations, create instances, and import data to facilitate game launch and operation. In addition, you can use Document Database for MongoDB as a cache server to reasonably plan hot data. MongoDB performance is comparable to other common cache servers, while also providing richer query methods.

<span id=".5LqS6IGU572R6KGM5Lia"></span>
## Internet industry

The internet industry is characterized by rapid business growth, large data volumes, and fast\-growing access traffic, demanding high horizontal scalability for data storage. Document Database for MongoDB supports changing configurations such as instance specifications, storage space, and number of nodes, allowing it to flexibly adapt to business peak changes.

<span id=".54mp6IGU572R6KGM5Lia"></span>
## IoT industry

Terminal devices in the IoT industry, such as medical devices and GPS devices on transportation vehicles, can easily generate terabytes of data in a continuous stream. Document Database for MongoDB supports building distributed database clusters to achieve unlimited capacity storage, while also facilitating online expansion. The native map\-reduce aggregation framework can help you extract immense hidden value from this data.
