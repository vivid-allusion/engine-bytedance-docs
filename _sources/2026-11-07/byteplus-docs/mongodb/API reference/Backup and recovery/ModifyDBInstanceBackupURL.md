Call the ModifyDBInstanceBackupURL API to obtain the download address of the specified backup file in the target MongoDB instance.

## Request type

Asynchronous request.

## Precautions

> **说明**

> For backups generated by physical backup, since these backup files are stored in a sharded form in the TOS. After you obtain the backup file download address through the ModifyDBInstanceBackupURL API, you need to call the [DescribeDBInstanceBackupURL](https://docs.byteplus.com/en/docs/mongodb/describedinstancesbackupurl) API to view the download address of the backup file before you can download the specified backup file.

## Request parameters

|Name |Type |Required |Example |Description |
|---|---|---|---|---|
|InstanceId |String |Yes |mongo\-shard\-f9e5d782\*\*\*\* |Instance ID.<br><br>tip<br><br>You can call the [DescribeDBInstances](https://docs.byteplus.com/en/docs/mongodb/describedbinstances) API to query the basic information of all MongoDB instances in the target region, including the instance ID. |
|BackupId |String |Yes |c89103a4821f47dfb9384b324aa0\*\*\*\* |The backup ID for obtaining the backup file download address.<br><br>tip<br><br>Only the backups generated through the physical backup method require the use of the ModifyDBInstanceBackupURL interface to obtain the backup file download address. You can call the [DescribeBackups](https://docs.byteplus.com/en/docs/mongodb/describebackups) API to query the backup file ID under the specified instance and find the backup file in the returned results that simultaneously meets the following conditions:<br><br><br>* The backup status is successful, that is, the value of `BackupStatus` is `Success`.<br><br>* The backup method is physical backup, that is, the value of `BackupType` is `Physical`.<br><br>* The download status of the backup file is that the backup file has not been obtained yet, that is, the value of `BackupDownloadStatus` is `NotDownLoad`. |

## Response parameters

The current API has no specified response parameters. For more information, see [Response structure](https://docs.byteplus.com/en/docs/mongodb/response-structure).
