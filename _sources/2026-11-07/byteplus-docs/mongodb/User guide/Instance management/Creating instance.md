Creating instance is the first step to getting started with the Document Database for MongoDB. This topic describes how to create a MongoDB instance.

<span id="x0Pzwwua"></span>
## Prerequisite


* A BytePlus account has been registered and completed verification. For the detailed method, refer to [Sign up and verify BytePlus account](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* As per the regulations in the Chinese mainland, you must have completed real name registration before you can activate and use cloud services in regions in the Chinese mainland through BytePlus. For more details, refer to [Real name registration](https://docs.byteplus.com/en/docs/byteplus-platform/docs-real-name-registration).

* Cross\-service access has been authorized to allow MongoDB to access other services (such as VPC and EIP). For specific procedures, refer to [Cross-service access authorization](https://docs.byteplus.com/en/docs/mongodb/cross-service-access-authorization).


<span id="wffEmfH2"></span>
## Procedure


1. Log in to the [MongoDB console](https://console.volcengine.com/db/mongodb).

2. In the upper\-left corner of the top menu bar, select the project and region for instance.

3. Select either **Replica set instances** or **Sharding instances** in the left navigation bar depending on the instance type.

4. On the target instance type list page, click **Create instance**.

5. On the **Create instance** page, set the following parameters.
