This topic summarizes all possible instance status and their details for Document Database for MongoDB.


|Instance status |Status code |Triggering operation |Description or impact |
|---|---|---|---|
|Creating |Creating |Creating instance. |The instance is being created, and database services are not yet available. The next status is **Running**. |
|Running |Running |The instance is successfully created. |Database services are operating normally. |
|Allowlist maintaining |AllowListMaintaining |Modify the association between instances and allowlists, including:<br><br><br>* Associate instances and allowlists.<br><br>* Disassociate instances from allowlists. |When associating and disassociating instance to allowlist, the status of the instance will become **AllowList maintaining**. For specific procedures, refer to [Associating instances and allowlists](https://docs.byteplus.com/en/docs/mongodb/associate-allowlist) and [Disassociating instances from allowlists](https://docs.byteplus.com/en/docs/mongodb/disassociate-allowlist). |
|Network maintaining |NetworkMaintaining |Modify the instance's network connection settings, including:<br><br><br>* Apply for or release private network addresses.<br><br>* Apply for or release public network addresses.<br><br>* Enable or disable public network resolution.<br><br>* Modify port.<br><br>* Modify connection address. |When applying for or releasing private network address or public network access, enabling or disabling public network resolution, modifying port number, or modifying connection address domain name, the instance enters the **Network maintaining** status. For more information about network and connection addresses, see [Network and connection management](https://docs.byteplus.com/en/docs/mongodb/network-connection-management). |
|Configuration modifying |Scaling |Modify instance specifications. |After performing and confirming the **change configuration** operation, this status appears during the modification. For specific procedures, refer to [Modifying instance specifications](https://docs.byteplus.com/en/docs/mongodb/solutions-for-spec-modification). |
|Restarting |Restarting |Restart instance. The following operations will cause the instance to restart:<br><br><br>* Manually restart instance.<br><br>* Modified parameters that require a restart to take effect. |In the process of restarting an instance, access to some services will be affected for a short time. Be cautious with this operation. We recommend you restart instances during off\-peak hours and ensure that applications have an automatic reconnection mechanism. For more details, refer to [Restarting instances](https://docs.byteplus.com/en/docs/mongodb/restart-instance). |
|Restoring |Restoring |Restore instance backup data. |When performing the operation of restoring backup data of an instance, the original instance will enter the **Recovering** status. When the instance is in the **Recovering** status, you can still restore data from this instance to other instances. For more details, refer to [Backup and recovery](https://docs.byteplus.com/en/docs/mongodb/backup-overview). |
|Upgrading minor version |Upgrading |Upgrade instance kernel or related component versions. |Only during kernel version upgrades will read/write connections be interrupted. Ensure your applications have an auto\-reconnect mechanism. Upgrades of other components are transparent to applications and do not cause connection interruptions or similar impacts. |
|Unavailable |Unavailable |The instance (cluster) is abnormal, preventing connection or database service provision. |[Submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical support. |
|Shutting down |Closing |The following operations will cause the instance to release:<br><br><br>* The account associated with a pay\-as\-you\-go instance is in arrears.<br><br>* A subscription instance has expired. |This is an intermediate status during instance releasing. When a subscription instance expires or the account of a pay\-as\-you\-go instance is in arrears, the instance enters the **Closing** status, and you should wait for the system to perform relevant processing. After the system handles the event, the instance enters the **Closed** status. |
|Deleting |Deleting |Delete Pay\-as\-you\-go instance. |Delete all resources and data of the instance, and the action cannot be undone. You can also choose to **Create a final backup** when deleting an instance. The system will automatically initiate a backup to save all your data before deletion. For more details, refer to [Delete Pay-as-you-go instance](https://docs.byteplus.com/en/docs/mongodb/delete-instance). |
|Closed |Closed |The following operations will cause the instance to release:<br><br><br>* The account associated with a pay\-as\-you\-go instance is in arrears.<br><br>* A subscription instance has expired. |When a subscription instance expires or the account of a pay\-as\-you\-go instance has arrears, the instance enters the **Closed** status. The instance cannot provide services in this status.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">You can enable automatic renewal or manually renew the instance before it expires. For specific procedures, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/automatic-manual-renewal">Automatic and manual renewal</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">You can recharge your account in the <a href="https://console.byteplus.com/finance/account-overview/">Billing center</a> before it goes into arrears.</div><br> |
|SSL modifying |SSLUpdating |The following operations will change the SSL encryption settings of the instance:<br><br><br>* Enable SSL encryption.<br><br>* Disable SSL encryption.<br><br>* Update SSL certificate validity period. |Enabling, disabling SSL encryption, or updating SSL certificate validity period will cause the instance to restart. Perform this during off\-peak hours and ensure your business has a reconnection mechanism. For more details, refer to [Setting SSL encryption](https://docs.byteplus.com/en/docs/mongodb/setup-ssl). |
|Primary node switching |SwitchMastering |Manually switch primary node |When performing the operation of switching primary node, the instance will enter **Primary node switching** status. For more information, refer to [Switching primary node](https://docs.byteplus.com/en/docs/mongodb/switch-primary-node). |
|Role switching |RoleChanging |Manually switch node roles |When performing the operation of switching node role, the instance will enter the **Role switching** status. For more information, refer to [Switching node roles](https://docs.byteplus.com/en/docs/mongodb/switching_node_roles). |
|Migrating |Migrating |In cases such as hardware failures or abnormal increases in disk space usage, it is necessary to migrate instances or nodes to a new machine. |When migrating an instance or nodes involved in a switch within an instance to a new machine, the instance will enter the **Migrating** status. During this period, the instance or nodes involved in a switch within the instance may experience temporary connection interruptions and a read\-only status lasting up to 30 seconds (to await full data synchronization). Ensure the instance's maintenance period is set during off\-peak business hours and that the application has a reconnection mechanism. |
|Parameter updating |ParameterUpdating |Modify or batch modify the parameter configuration of instances.<br><br> |When switching parameter configurations, the instance enters the **ParameterUpdating** status. After modifying some parameters, the instance needs to be restarted for the new parameter values to take effect. During the restart, 1 to 2 temporary disconnections may occur. Proceed with caution. It is recommended to perform this during off\-peak hours and ensure that applications have an automatic reconnection mechanism. For the specific procedure, see [Modifing instance parameters](https://docs.byteplus.com/en/docs/mongodb/modify-parameter?lang=en) and [Batch modifying instance parameters](https://docs.byteplus.com/en/docs/mongodb/modifying_instance_parameters_in_batches). |
