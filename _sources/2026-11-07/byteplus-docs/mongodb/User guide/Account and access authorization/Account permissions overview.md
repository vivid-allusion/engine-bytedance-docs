Document Database for MongoDB provides different types of database accounts. You can customize database accounts according to business scenarios and assign corresponding permissions to achieve operations such as separating databases and decentralizing powers, meeting the needs of refined management of database permissions. This topic introduces the account types supported by MongoDB and the details of database account permissions.

<span id=".6LSm5Y-357G75Z6L"></span>
## Account type

Document Database for MongoDB provides three types of accounts: super administrator account, high\-privileged account, and normal account.

Detailed descriptions of the different account types are provided in the table below.


|Account type |Account description |Precautions |
|---|---|---|
|Super administrator account |Namely, the root account. When a MongoDB instance is successfully created, the system by default creates a super administrator account in the admin database. |* Only one super administrator account is allowed in each MongoDB instance.<br><br>* **Cannot** delete or rename the root account.<br><br>* Support resetting the root account, including resetting the account password and completing the root account permissions. For specific procedures, refer to [Resetting root account](https://docs.byteplus.com/en/docs/mongodb/reset-root-account). |
|High\-privileged account |An account with any permission to the admin database is a high\-privileged account. |* There are no quantity limits for both high\-privileged accounts and normal accounts.<br><br>* All support [creation](https://docs.byteplus.com/en/docs/mongodb/create-account), [password modification](https://docs.byteplus.com/en/docs/mongodb/reset-password), [permission modification](https://docs.byteplus.com/en/docs/mongodb/modifying_account_privileges), and [deletion](https://docs.byteplus.com/en/docs/mongodb/delete_account) operations.<br><br>* You can convert between high\-privileged and normal account types by modifying permissions on the admin database. |
|Normal account |An account without any permissions for the admin database is a normal account. ||

### Account permissions

The following table lists the supported account permissions and their descriptions for Document Database for MongoDB.


|Permission type |Permission name |Permissions description |
|---|---|---|
|Administrator operation permission |dbAdmin |Permission to perform management operations on database objects, but not read/write operations on the database. |
||userAdmin |Permission to create users on this database. |
||dbOwner |Permission to perform all operations on this database. |
|Cluster operation permission |clusterMonitor |Permissions to query clusters and replica sets. |
|Ordinary operation permission |read |Permission to perform query operations on this database. |
||readWrite |Permission to perform add, delete, modify, query operations on this database. |
|Instance operation permission |readAnyDatabase |Permission to query all databases in this instance. |
||readWriteAnyDatabase |Permissions to create, delete, modify, and query all databases in this instance. |
||userAdminAnyDatabase |Permissions to create users on all databases in this instance. |
||dbAdminAnyDatabase |dbAdmin permissions for all databases in this instance. |
|Backup operation permission |backup |Permission to perform backup operations on all databases in this instance. |

### Permissions allowed for different databases

The following table lists the permissions that Document Database for MongoDB allows to grant for different databases.


|Database type ||Description |Permissions to grant |
|---|---|---|---|
|System database |admin |This database stores critical management information. |* read<br><br>* userAdmin<br><br>* readAnyDatabase<br><br>* readWriteAnyDatabase<br><br>* userAdminAnyDatabase<br><br>* dbAdminAnyDatabase<br><br>* clusterMonitor<br><br>* backup |
||config |This database mainly stores the configuration data of MongoDB. For more details, refer to [config database](https://www.mongodb.com/docs/v5.0/reference/config-database/). |read |
||local |This database stores data used during replication and other specific data. For more details, refer to [local database](https://www.mongodb.com/docs/v5.0/reference/local-database/). |read |
|Custom database ||Databases you created yourself in your MongoDB instance. |* read<br><br>* readWrite<br><br>* dbAdmin<br><br>* userAdmin<br><br>* dbOwner |
