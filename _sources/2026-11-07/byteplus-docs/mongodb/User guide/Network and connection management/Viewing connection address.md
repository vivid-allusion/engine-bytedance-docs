This topic introduces the address types supported by MongoDB. You can select proper addresses to access and manage MongoDB instances.

## Connection address type

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For more information about how to connect to a MongoDB instance by using a public or private address, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/connect-instance-via-mongo-shell">Connecting to instance via Mongo shell</a>.</div>



|Address type |Description |Precautions |
|---|---|---|
|Private network address |Using a private address to access a MongoDB instance can maximize security and performance. |* The system provides a private address by default when you create a MongoDB instance.<br><br>   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div><br>   <br><br>   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The MongoDB console allows you to view and download <strong>Private network address</strong> provided for the instance on the instances page. To view the private address information, in the upper\-right corner of Instances, click<img src="https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_0bcd2370f0fbd68a13767598ee94da7f.png" width="14px" />icon and then select <strong>Private network address</strong> from the drop\-down list. For more information, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/download-instance-list">Downloading instance list</a>.   </div><br>   <br><br>* You can also apply for or release private addresses for sharding cluster instances based on business requirements. For more information, refer to [Applying for private address](https://docs.byteplus.com/en/docs/mongodb/apply-private-address) and [Releasing private address](https://docs.byteplus.com/en/docs/mongodb/release-private-address). |
|Public network address |You can apply for a public address for a MongoDB instance, so that the devices outside the Virtual Private Cloud (VPC) can access the MongoDB instance. |* Connection over the Internet is risky. The public address function is disabled for MongoDB by default. You can apply for a public address on the console. For more information about how to apply for a public address, refer to [Applying for public address](https://docs.byteplus.com/en/docs/mongodb/ug-apply-public-address).<br><br>* When devices outside the VPC do not need to access the MongoDB instance, release the public address in time. For more information about how to release a public address, refer to [Releasing public address](https://docs.byteplus.com/en/docs/mongodb/release-public-address).<br><br>* When you apply for a public address, the public address will be associated with your Elastic IP Address (EIP) and charged by EIP. For more information, refer to [EIP billing overview](https://docs.byteplus.com/en/docs/eip/Billing-overview). |

## Viewing connection address


1. Log in to the [MongoDB console](https://console.byteplus.com/db/mongodb).

2. In the upper\-left corner of the top menu bar, select the project and region for instance.

3. Select either **Replica set instances** or **Sharding instances** in the left navigation bar depending on the instance type.

4. On the target instance type list page, click the target instance name.

5. On the instance details page, click on the **Connectivity** tab.

6. Under the **Connectivity** tab, you can view the following information.

   
   |Instance or component type |Information supported to view |
   |---|---|
   |Replica set instance |On the **Connectivity** tab, you can view relevant information in the corresponding area.<br><br><br>* **Network information**<br><br>   Include virtual private cloud, subnet, network protocol and database port information of the instance.<br><br>* **Private network access**<br><br>   Include the domain name of the complete private network connection address of the instance, as well as the single\-node connection address domain name and the IP address corresponding to the single\-node connection address of the primary, secondary, hidden, and read\-only nodes.<br><br>* **Public network address**<br><br>   Include the domain name of the complete public network connection address of the instance‘s primary and secondary nodes, as well as the single\-node connection address domain name and the IP address corresponding to the single\-node connection address of the primary and secondary nodes.<br><br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The Document Database for MongoDB does not provide a public network address by default. If you need to view public network address information, please manually apply for a public network address first. For specific procedures, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/ug-apply-public-address">Applying for public address</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Only when there is a read\-only node in the instance will the connection address information of the read\-only node be displayed. For more information about read\-only nodes, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/managing_read_only_nodes">Managing read\-only nodes</a>.</div><br> |
   |Sharding cluster instance |On the **Connectivity** tab, you can view relevant information in the corresponding area.<br><br><br>* **Network information**<br><br>   Include virtual private cloud, subnet, network protocol and database port information of the instance.<br><br>* **Connect to Mongos**<br><br>   Include the complete public and private network connection address domain names of Mongos, as well as the single\-node connection address domain names and the corresponding IP addresses of each Mongos node.<br><br>* **Connect to Shard**<br><br>   Include the complete public and private network connection address domain names of each Shard. For specific procedures, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/apply-private-address">Applying for private address</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">The Document Database for MongoD does not provide a public network address by default. If you need to view the public network address information of Mongos, Shard, or ConfigServer nodes, please manually apply for a public network address first. For specific procedures, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/ug-apply-public-address">Applying for public address</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Only when there is a read\-only node in the instance will the connection address information of the read\-only node be displayed.
