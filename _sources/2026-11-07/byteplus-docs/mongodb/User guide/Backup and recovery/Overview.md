Document Database for MongoDB provides various backup methods and types for data recovery after accidental updates or deletions, ensuring reliable data security.

<span id=".5aSH5Lu9562W55Wl"></span>
## Backup policy


* **Automatic backup**

   Data is automatically backed up based on the default backup policy. You can configure a backup policy based on business needs and then the instance automatically backs up the MongoDB data based on the configured backup policy. For specific procedures, refer to [Modifying automatic backup policy](https://docs.byteplus.com/en/docs/mongodb/automatic-backup).

* **Manual backup**

   MongoDB allows you to manually back up data replicas in either a logical manner or a physical manner. Backup methods vary depending on the instance's storage type. Local disk instances support physical and logical backups, while FlexPL volume instances only support physical backup (volume snapshot). For more information on manual backup, refer to [Manual backup](https://docs.byteplus.com/en/docs/mongodb/manual-backup).


<span id=".5aSH5Lu95pa55byP"></span>
## Backup method

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Backup files generated by local disk instances can be downloaded, while backup files generated by FlexPL volumes instances cannot be downloaded. For more information on downloading backup files, refer to <a href="https://docs.byteplus.com/en/docs/mongodb/manage-backup-file#OQemzRNR">Downloading backup files</a>.</div>



* **Physical backup**

   You can use physical backup to copy all physical files of a MongoDB database. Physical backup generally offers higher efficiency.

   By default, MongoDB uses physical backups for automatic backup. For more details, refer to [Modifying automatic backup policy](https://docs.byteplus.com/en/docs/mongodb/automatic-backup).

* **Logical backup**

   You can export database objects and save them to binary files using logical backup. Backup with logical backups is less efficient.

   You can select either physical backups or logical backups for manual backup. For more information, refer to [Manual backup](https://docs.byteplus.com/en/docs/mongodb/manual-backup).


<span id=".5aSH5Lu95a-56LGh"></span>
## Backup object

By default, the Document Database for MongoDB enables the automatic backup function. The backup objects include database data and oplog logs. Among them:


* Data backup: Allows custom configuration of backup cycles, start times, and other backup settings. For specific procedures, refer to [Modifying automatic backup policy](https://docs.byteplus.com/en/docs/mongodb/automatic-backup).

* Log backup: The system automatically performs streaming backups of oplog logs at a frequency of once per 5 minutes without configuration.
