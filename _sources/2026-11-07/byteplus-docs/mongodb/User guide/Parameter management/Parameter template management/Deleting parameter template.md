This topic describes how to delete parameter templates that are no longer in use.

<span id=".5L2_55So6ZmQ5Yi2"></span>
## Limits

Only **Customized templates** can be deleted; **System templates** cannot be deleted.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [MongoDB console](https://console.byteplus.com/db/mongodb).

2. In the upper\-left corner of the top menu bar, select the project and region for instance.

3. In the left navigation bar, choose **NoSQL Database\> MongoDB \> Parameter templates**.

4. On the **Customized template** sub\-tab of the Parameter templates page, locate the target template to be deleted, and in the **Actions** column on the right, select  **... \> Delete**.

5. In the pop\-up dialog box, click **Delete**.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">The template cannot be recovered after deletion. Proceed with caution.   </div>
