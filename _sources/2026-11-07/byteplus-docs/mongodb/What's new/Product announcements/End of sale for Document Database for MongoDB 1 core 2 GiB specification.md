As business scenarios evolve, the 1 core 2 GiB specification for Document Database for MongoDB can no longer fully meet actual production requirements in terms of performance, stability, and resource utilization efficiency. To guide the selection of specifications better suited for business development and ensure system reliability and scalability, MongoDB will soon discontinue sales of the 1 core 2 GiB specification.

<span id="2DFnfcTY"></span>
## End of sale regions and time

Document Database for MongoDB will discontinue sales of the 1 core 2 GiB specification in all service regions starting from April 27, 2026.

## **End of sale impact**


* **New instance creation and specification modification restrictions**

   After the 1 core 2 GiB specification is discontinued, all MongoDB instance and component types (including replica set instances, and Mongos, Shard, and ConfigServer components in sharding cluster instances) will no longer support selecting the 1 core 2 GiB specification in the following scenarios:

   * [Creating instance](https://docs.byteplus.com/en/docs/mongodb/create-instance).

   * Downgrading the node specifications for [replica set instances](https://docs.byteplus.com/en/docs/mongodb/modify-replica-set-instance-spec), [Mongos](https://docs.byteplus.com/en/docs/mongodb/modify-mongos-config), [Shard](https://docs.byteplus.com/en/docs/mongodb/modify-shard-config), and [ConfigServer](https://docs.byteplus.com/en/docs/mongodb/modify-configserver-config).

* **Existing instances unaffected**

   Already purchased 1 core 2 GiB specifications can continue to be used and renewed normally until you proactively delete or unsubscribe from the instance. BytePlus will not perform forced migration or service suspension for existing instances.
