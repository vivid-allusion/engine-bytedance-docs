This topic describes how to download and install the MongoDB Go SDK.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
### Prerequisite

GO v1.5 or higher is required, and GO v1.12 or higher is recommended.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">You can check the Go version information with the <code>go version</code> command.</div>


<span id=".c2RrLeS4i-i9veWcsOWdgA=="></span>
### SDK download link

For the MongoDB Go SDK source code address, refer to [MongoDB Go SDK](https://github.com/byteplus-sdk/byteplus-go-sdk-v2/tree/main/service/mongodb).

<span id=".5a6J6KOFLXNkaw=="></span>
### Install SDK

Run the following command in the target Go project to install the Go SDK.

```Go
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/service/mongodb
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/byteplus/credentials
go get github.com/byteplus-sdk/byteplus-go-sdk-v2/byteplus/byteplusutil
```
