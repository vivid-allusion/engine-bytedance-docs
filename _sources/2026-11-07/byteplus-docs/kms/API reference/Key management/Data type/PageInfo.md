**PageInfo**


|**Name** |**Type** |**Example Value** |**Description** |
|---|---|---|---|
|TotalCount |Int |100 |The total number of projects found in the pagination query. |
|PageSize |Int |10 |The number of entries returned on each page. |
|CurrentPage |Int |2 |The page number of the returned page. The value starts from 1. |
|Count |Int |5 |The number of items on the current page. |
