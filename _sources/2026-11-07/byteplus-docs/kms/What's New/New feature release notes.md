## December 2025


|Feature |Description |Release Time |Release Region |Related Documents |
|---|---|---|---|---|
|Support for FIPS 140\-3 Level 3–Compliant Keys in Non–Mainland China Regions |The Hardware Security Modules (HSMs) used by the Key Management Service (KMS) in regions outside Mainland China have achieved FIPS 140\-3 Level 3 certification. Effective immediately, all cryptographic operations for newly created HSM\-backed keys in KMS are performed entirely within HSMs that meet this industry\-recognized security standard. This ensures that cryptographic keys never leave the hardware security boundary and fully satisfies high\-level security and compliance requirements, providing robust protection for critical data and core business workloads. |December 24, 2025 |Johor, Jakarta, Hong Kong (China) |[What is Key Management Service](https://docs.byteplus.com/en/docs/kms/What_is_Key_Management_Service) |
