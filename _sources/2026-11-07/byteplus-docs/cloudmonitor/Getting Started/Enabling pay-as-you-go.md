If you want to receive SMS or voice notifications from Alert Center and Event Center, first enable pay\-as\-you\-go billing for Cloud Monitor.

<span id="51b1f7ed"></span>
## Prerequisites

Enterprise authentication has been completed. 

<span id="6704f47c"></span>
## Procedure


1. Log in to the [Cloud Monitor console](https://console.byteplus.com/observe/cloud-monitor/overview).

2. On the **Overview** page, click **Enable Pay\-as\-you\-go**.

3. In the **Pay\-as\-you\-go price description of Cloud Monitor** dialog box, select **I have read and agree Cloud Monitor Billing Rules|Terms of Service on Cloud Monitor**. Then, click **Apply**.

   The page will display the **Success** message. Refresh the page. A few minutes later, you will view an SMS message notification or a voice notification about billing information.
