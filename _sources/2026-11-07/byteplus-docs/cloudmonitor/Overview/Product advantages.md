## Automatic activation

After you create an account, you can directly use the Cloud Monitor service without the need to purchase or activate it.

After you purchase a cloud service, basic metric monitoring is automatically enabled for the service. In this way, you can view resource running status and configure alert policies without manual configuration.

<span id=".5a6e5pe257uG57KS5bqm55uR5o6n"></span>
## Real\-time fine\-grained monitoring

The metric data of each service is collected every 30 seconds or 1 minute, which helps you learn about resource running status in real time.

<span id=".5Yqo5oCB5Y-v6KeG5YyW"></span>
## Dynamic visualization

Cloud Monitor provides visual monitoring dashboards that display various metric data through dynamic charts. This meets your monitoring requirements across multiple business scenarios.

<span id=".54G15rS75ZGK6K2m6K6-572u"></span>
## Flexible alert configuration

You can select different metrics for different cloud services and set thresholds. When metric data reaches the threshold, an alert is triggered, which enables you to promptly handle exceptions.

You can also flexibly change alert conditions at any time, such as metrics and thresholds. This meets the personalized requirements of different scenarios, such as business peak hours or normal operations.

<span id=".55uR5o6n5oyH5qCH5Liw5a-M"></span>
## Rich metrics

In addition to collecting basic metrics related to CPU, memory, disk, and network, you can also install an agent process in instances to collect metric data within the operating system. This helps you obtain more accurate and detailed information about the running status of resources.
