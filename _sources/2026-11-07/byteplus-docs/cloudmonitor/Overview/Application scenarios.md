## ECS instance monitoring

Cloud Monitor can automatically obtain all ECS instances within your current account. You can view key metrics for each instance, such as CPU utilization and network traffic, which allows you to confirm the working status of your ECS instances at any time.

<span id=".5LqR5pyN5Yqh5Zmo5pON5L2c57O757uf55uR5o6n"></span>
## ECS operating system monitoring

You can install an agent process on an ECS instance to collect operating system metrics, which helps you have a deeper understanding of the resource status.

<span id=".5byC5bi45Zy65pmv"></span>
## Abnormal scenarios

You can configure a custom threshold alert rule for any metrics. When an ECS instance reaches the threshold, alert notifications are automatically sent, which allows you to promptly obtain information about resource exceptions and perform corresponding operations.

<span id=".5omp5a655Zy65pmv"></span>
## Scale\-out scenarios

After you configure alert rules for metrics, such as CPU utilization, network traffic, and disk utilization, you can receive alert notifications in a timely manner during peak hours and perform scale\-out or other operations to adjust business capacity. This achieves elasticity during peak hours.
