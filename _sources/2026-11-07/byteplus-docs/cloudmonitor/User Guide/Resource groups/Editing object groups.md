You can modify the information about an object group, including the cloud service, resources, or region, based on your business requirements.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Cloud Monitor console](http://console.volcengine.com/cloud-monitor/overview). 

2. In the left navigation bar, click **Object Group**.

3. Find the target object group in the object group list and click **Edit** in the **Actions** column.

4. On the **Edit an object group** page, modify the configurations of the object group, and click **Save**.

   For object group parameters, see [Creating object groups](https://docs.byteplus.com/en/docs/cloudmonitor/Creating-a-resource-group).

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The updated configurations of the object group will be synchronized to the associated alert policy.   </div>
