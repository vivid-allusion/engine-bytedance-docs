You can delete an unnecessary object group to remove an unrelated option from the object group drop\-down list.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Cloud Monitor console](http://console.volcengine.com/cloud-monitor/overview). 

2. In the left navigation bar, click **Object Group**.

3. In the object group list, find the target object group and, in the **Actions ** column on the right side, click **Delete**.

4. In the message that appears, click **OK**.
