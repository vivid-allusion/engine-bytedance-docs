You can copy an object group and modify the configuration items of the object group such as the name, resource type, resource range, region, and dimension. The new configurations of the object group take effect after modification.

<span id="48d6e5f3"></span>
## Procedure


1. Log in to the [Cloud Monitor console](http://console.volcengine.com/cloud-monitor/overview). 

2. In the left navigation bar, click **Object group**.

3. In the object group list, click **Copy** in the Actions column that corresponds to the target object group.

4. In the Copy Object Grouping dialog box, specify the name of the object group and click **OK**.

5. After you create the object group, find it in the object group list and click **Edit** in the Actions column.

6. On the Edit object group page, configure the parameters of the object group. For parameter configuration, see [Creating object groups](https://docs.byteplus.com/en/docs/cloudmonitor/Creating-a-resource-group).

7. After you confirm that the information is correct, click **Save** to complete the configuration.
