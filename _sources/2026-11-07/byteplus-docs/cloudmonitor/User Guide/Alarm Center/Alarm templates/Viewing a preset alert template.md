You can view the details of a preset alert template in the Cloud Monitor console.

<span id=".5pON5L2c5q2l6aqk"></span>
## View a preset alert template


1. Log in to the [Cloud Monitor console](http://console.volcengine.com/cloud-monitor/overview). 

2. In the left navigation bar, click **Alert Center** \> **Alert Template**.

3. Click the **Preset alert template** tab.

4. In the **preset alert template** list, click the name of the target template to go to the **Overview** page to view the details of the template.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_e6b38d17566a631d7a2e9d9d9f958736.png) </span>

   The Overview page displays the basic information and cloud service of the preset alert template.

   * **Basic information**: displays information about the preset alert template, including the name, ID, description, alert level, and alert sending interval.

   * **Cloud Service**: displays the subnamespace of the cloud service and the description of the trigger condition.
