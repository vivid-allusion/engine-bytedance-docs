After an alert is triggered, you can go to the details page of the corresponding resource instance to obtain the detailed metric data of the instance and handle the alert in a timely manner.

<span id=".5pON5L2c5q2l6aqk"></span>
## View resources with active alerts


1. Log in to the [Cloud Monitor console](http://console.volcengine.com/cloud-monitor/overview). 

2. In the left navigation bar, click **Alert Center** \> **Alert History**.

3. You can filter for the target alert record by specifying a time period and filter conditions above the alert record list.

4. In the alert record list, click the name of the target instance to go to the instance details page.

5. Take an Elastic Compute Service (ECS) instance as an example. You can click the **BaseMonitor** or **OperateSystemMonitor** tab to view the metric data of the instance.
