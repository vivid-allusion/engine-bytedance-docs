## Overview

After you activate Cloud Monitor and [integrate cloud services with Cloud Monitor](https://docs.byteplus.com/en/docs/cloudmonitor/Cloud-service-metrics), when you create an instance of one of the cloud services (excluding ECS), the instance will be automatically integrated with Cloud Monitor in the same region by default. Then, you can view the corresponding monitoring information in the console of the cloud service or the Cloud Monitor console.
