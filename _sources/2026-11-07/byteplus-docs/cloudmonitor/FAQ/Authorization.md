## User is not authorized to perform: cloudmonitor:GetMetricsData on resource

After you grant the read\-only permission **CloudMonitorReadOnlyAccess** on Cloud Monitor to an IAM user, the IAM user can access Cloud Monitor as expected. For detailed steps, see [Authorizing IAM users](https://docs.byteplus.com/en/docs/cloudmonitor/Granting_permissions_to_an_IAM_user).
