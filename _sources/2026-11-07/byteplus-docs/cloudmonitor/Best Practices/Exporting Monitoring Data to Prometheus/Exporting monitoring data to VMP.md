VMP serves as a standard Prometheus service managed on the cloud. It is compatible with open source Prometheus APIs and the community Exporter ecosystem. VMP provides you with an integrated Prometheus environment without the need for setup or O&M, which reduces development and O&M costs.

You can export cloud product monitoring data from Cloud Monitor to VMP in real time and merge the data with business monitoring data in your clusters to achieve centralized monitoring of business data and basic resource data. For detailed instructions, see [Cloud Monitor integration](https://docs.byteplus.com/en/docs/vmp/Monitoring-cloud-services).
