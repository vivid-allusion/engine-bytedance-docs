Query the alert history of the specified resource.

## Request descriptions

* Request method: POST

* Request URL: https://cloudmonitor.cn\-beijing.byteplusapi.com.cn?Action=ListAlertGroup&Version=2018\-01\-01

## Debugging

[去调试](https://api.byteplus.com/api-explorer/debug?action=ListAlertGroup&serviceCode=Volc_Observe&version=2018-01-01&groupName=)

## Request descriptions

|Parameters |Type |Required |Sample value |Description |
|---|---|---|---|---|
|Action |String |Yes |ListAlertGroup |The name of the API. The API name is `ListAlertGroup`. |
|Version |String |Yes |2018\-01\-01 |The API version. The API version is `2018-01-01`. |
|StartAt |Integer |No |1664176020 |The earliest time when the alert message occurred. It is a timestamp in seconds.<br><br>If it is not specified, the time defaults to 7 days before the current time. |
|EndAt |Integer |No |1664262420 |The latest time when the alert message occurred. It is a timestamp in seconds.<br><br>If it is not specified, it defaults to the current time.<br><br>> **tip**<br><br><br>> The gap between `StartAt` and `EndAt` must be greater than or equal to 1 minute. If it is less than 1 minute, data with the past 7 days is queried by default.<br> |
|RuleIds |Array of String |No |["15753124985155\*\*\*\*\*"] |Query alert messages generated by the alert policy specified by RuleId. You can specify multiple IDs.<br><br>If RuleId is used, the filter parameters `Namespaces`, `Levels`, and `RuleName` will not be applied. |
|ResourceId |String |No |kafka\-cn\-4ia\*\*\*xia |ID of the resource on which the alert is triggered. |
|Namespaces |Array of String |No |["VCM_Kafka"] |Alert messages generated by alert policies whose resource type is the specified Namespace. Multiple options can be selected. |
|Levels |Array of String |No |["warning","notice"] |Alert messages generated by alert policies with the specified alert level. Multiple options can be selected. |
|RuleName |String |No |test |Query alert messages generated by the alert policy with the specified name. Fuzzy matching is applied. |
|AlertStates |Array of String |No |["normal"] |Query alert messages generated by the alert policy with the specified alert status. Multiple options can be selected.<br><br><br>* **alerting**: Alerting<br><br>* **normal**: Recovered |
|PageNumber |Integer |No |1 |Page number of the list. The value must be greater than 0. The default value is 1. The list range to be queried is:<br><br><br>* Actual start position = (PageNumber\-1) \* PageSize<br><br>* Actual end position = PageNumber \* PageSize |
|PageSize |Integer |No |10 |Number of rows per page for a pagination query. The default value is 10. |
