Query alert templates.

## Request descriptions

Cloud Monitor is deployed across multiple regions worldwide to deliver more stable and low\-latency access. You can refer to the [Service addresses](https://docs.byteplus.com/en/docs/cloudmonitor/Service_address) topic to choose an access point that is the most optimal for the region of your services.

* Request method: POST

* Request URL: https://cloudmonitor.cn\-beijing.byteplusapi.com.cn?Action=ListAlertTemplates&Version=2018\-01\-01

## Debugging

[去调试](https://api.byteplus.com/api-explorer/debug?action=ListAlertTemplates&serviceCode=Volc_Observe&version=2018-01-01&groupName=)

## Request parameters

|Parameters |Type |Required |Sample value |Description |
|---|---|---|---|---|
|Action |String |Yes |ListAlertTemplates |The name of the API. The API name is `ListAlertTemplates`. |
|Version |String |Yes |2018\-01\-01 |The API version. The current API version is `2018-01-01`. |
|Name |String |No |alert\-template\-demo |Filter alert templates by template name.<br><br><br>* It is a string that can contain Chinese characters, uppercase letters, lowercase letters, and special characters.<br><br>* It cannot start with a digit, a hyphen (`-`), or other special characters.<br><br>* It must be 1 to 128 characters in length. |
|TemplateIds |Array of String |No |["1354766247190\*\*\*\*\*\*"] |Filter alert templates by template ID. |
|Namespaces |Array of String |No |["VCM_ECS"] |Filter alert templates by cloud product specified in templates. For details, see the **Namespace** field on the [Cloud Monitor metric query](https://docs.byteplus.com/en/docs/cloudmonitor/Cloud-service-metrics) page for each cloud product. |
|PageNumber |Integer |No |1 |The page number for a pagination query. The default value is 1.<br><br><br>* Actual start position = (PageNumber\-1) \* PageSize<br><br>* Actual end position = PageNumber \* PageSize |
|PageSize |Integer |No |30 |The number of rows per page for a pagination query. The default value is 30. |
|ObjectGroupIds |Array of String |No |['196349165826\*\*\*'] |Object group IDs. You can perform the query with object group IDs as a filter. |
