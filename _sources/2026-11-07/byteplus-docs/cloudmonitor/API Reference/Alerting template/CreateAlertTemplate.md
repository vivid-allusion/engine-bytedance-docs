Create an alert template.

<span id=".5L2_55So6ZmQ5Yi2"></span>
## Limits


* Each root user can have up to 1,000 alert templates.

* Each alert template can contain up to 100 alert policies.


<span id=".6K-35rGC6K-05piO"></span>
## Request descriptions

Cloud Monitor is deployed across multiple regions worldwide to deliver more stable and low\-latency access. You can refer to the [Service addresses](https://docs.byteplus.com/en/docs/cloudmonitor/Service_address) topic to choose an access point that is optimal for the region of your services.


* Request method: POST

* Request URL: https://cloudmonitor.cn\-beijing.byteplusapi.com.cn?Action=CreateAlertTemplate&Version=2018\-01\-01

## Sample request

```json
POST https://cloudmonitor.cn-beijing.byteplusapi.com.cn?Action=CreateAlertTemplate&Version=2018-01-01
Content-Type: application/json
{
    "Description": "this is an alert template demo",
    "Name": "alert-template-demo",
    "NoData": {
        "Level": "notice",
        "Enable": true,
        "EvaluationCount": 10
    },
    "NotifyMode": "rule",
    "RecoveryNotify": {
        "Enable": true
    },
    "SilenceTime": 5,
    "TemplateRules": [
        {
            "Name": "CPU useage",
            "Namespace": "VCM_ECS",
            "LevelConditions": [
                {
                    "Level": "warning",
                    "Conditions": [
                        {
                            "Threshold": "100",
                            "MetricName": "Instance_CpuBusy",
                            "MetricUnit": "Percent",
                            "Statistics": "avg",
                            "EvaluationWindow": 1,
                            "ComparisonOperator": "\\>"
                        }
                    ]
                }
            ],
            "EvaluationCount": 1,
            "SubNamespace": "GPU",
            "NoData": {
                "Level": "notice",
                "Enable": true,
                "EvaluationCount": 10
            },
            "ConditionOperator": "&&",
            "EvaluationInterval": 1,
            "MultipleConditions": true
        }
    ]
}
```
