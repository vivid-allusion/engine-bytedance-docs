This topic describes how to query all error codes for Cloud Monitor APIs.

<span id="8c8xy6O4"></span>
## Error code types

The platform supports two types of error codes.

<span id="BSJVxgS5"></span>
### Platform\-level public error codes

CodeN starts with `1000`. For details, see [Public error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).

<span id="Br57dbBk"></span>
### Cloud product error codes

Error codes specific to a cloud product include public error codes of the cloud product and API\-specific error codes. The HTTP status codes include `4xx` and `5xx`. See [OpenAPI Center](https://api.volcengine.com/api-docs/view/errorcode?serviceCode=Volc_Observe&version=2018-01-01) for details.

On the right side of "Error code", click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_65183e460835e9b275060a725a2d4df0.png) </span> icon to query the desired information.
