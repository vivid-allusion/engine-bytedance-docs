This topic introduces the language versions of the SDK provided by Direct Connect (DC) and lists the access addresses for the latest SDK versions.

<span id=".U0RL5LuL57uN"></span>
## SDK overview

DC SDK encapsulates all APIs of Direct Connect ([Direct Connect API reference](https://docs.byteplus.com/en/docs/directconnect/Direct-Connect-API-overview)), uses the access key (AK) to identify the caller's identity, and provides features like automatic signature, making it convenient for you to create and manage resources through API calls.

<span id=".U0RL5YiX6KGo"></span>
