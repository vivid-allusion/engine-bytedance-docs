This article introduces the public error codes for Direct Connect\-related API calls. For platform error codes, refer to [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).


|HTTP Code |Error Codes |Error Message |Description |
|---|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported, or cannot be used. |A parameter specified in the request is not valid, is unsupported or cannot be used. |
|400 |MissingParameter |The request is missing a required parameter. |A required parameter is missing in the request. Please ensure that all required parameters are provided in the request. |
|409 |InvalidOperation.Conflict |The specified resource operation conflicts. |The specified resource operation conflicts with another operation. |
|500 |InternalError |An internal error has occurred. |An internal error has occurred. |
