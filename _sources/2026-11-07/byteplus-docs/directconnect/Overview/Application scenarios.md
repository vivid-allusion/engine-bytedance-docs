## Cross\-region access between on\-premises data centers and multiple VPCs

Interconnect multiple Virtual Private Clouds (VPCs) with on\-premises data centers across regions through Direct Connects (DCs) and Cloud Enterprise Networks (CENs), enabling robust multi\-region disaster recovery and enhancing network security.

<span id=".5re35ZCI5LqR6YOo572y"></span>
## Hybrid cloud deployment

Interconnect an on\-premises data center with a VPC through a DC, leveraging the cloud's features (such as elastic computing and instant effect) to flexibly and conveniently expand your data center's application capabilities.

<span id=".5pWw5o2u5aSH5Lu95a6554G-"></span>
## Data backup and disaster recovery

Based on hybrid cloud deployment, build fast and reliable transmission channels between an on\-premises data center and a VPC, facilitating data migration and backup disaster recovery.

<span id=".5aSaSURD5LqS6YCa"></span>
## Interconnection between multiple data centers

Interconnect data centers in the same region and across regions via DCs and CENs, offering efficient, secure, and fast network transmission capabilities.
