This topic describes cloud services related to Direct Connect (DC).

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ea96d33822624e174b5248f2edb84820.png) </span>

The related cloud services in the above diagram are detailed in the following table.


|Service name |Relationship description |Documentation |
|---|---|---|
|Virtual Private Cloud |Through a DC Gateway, establish a private network link between your data center and a Virtual Private Cloud (VPC). |[Virtual Private Cloud overview](https://docs.byteplus.com/en/docs/vpc/What-is-VPC) |
|Cloud Enterprise Network |After establishing a DC link between a data center and a VPC, load multiple VPC instances to a Cloud Enterprise Network (CEN) for interconnecting multiple data centers across regions. |[Cloud Enterprise Network overview](https://docs.byteplus.com/en/docs/cen/Product-Overview-01) |
|Transit Router |The Transit Router (TR) flexibly defines routing rules for interconnection and isolation between networks. It enables private network interconnection and isolation among cloud resources in complex networking scenarios, as well as between VPCs and on\-premises data centers. |[Transit Router overview](https://docs.byteplus.com/en/docs/transitrouter/Product-Overview-01) |
|Identity and Access Management |Control access permissions for different accounts to DC resources, enabling decentralized management. |[IAM overview](https://docs.byteplus.com/en/docs/byteplus-platform/docs-overview-3) |
|Quota management |Manage DC resource quotas under the account centralizedly, view quota limits and resource usage, and request online quota adjustment and alarm strategy configuration as needed. |[Quota overview](https://docs.byteplus.com/en/docs/resourcemanagement/Quota_Overview) |
|Tag management |You can classify and manage resources related to DC connections by tags. |[Tag overview](https://docs.byteplus.com/en/docs/resourcemanagement/Tag_Overview) |
|Cloud Monitor |You can use Cloud Monitor to view real\-time data of resources and business metrics, such as DC Gateways and DC Virtual Interfaces. Through customizable metric thresholds and alert notifications, anomalies are detected promptly to ensure stable business operations. |[Cloud Monitor overview](https://docs.byteplus.com/en/docs/cloudmonitor/What-is-Vitality-Cloud-Monitor) |
|CloudTrail |You can track and record actions on DC resources by different accounts through CloudTrail. Operation logs help with issue troubleshooting and attribution. |[CloudTrail overview](https://docs.byteplus.com/en/docs/7015/166036) |
