You can enable IPv6 after completing the creation of a Direct Connect (DC) Gateway. A DC Virtual Interface can use the IPv6 feature only after its associated DC Gateway has IPv6 enabled.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Currently, IPv6 cannot be disabled once enabled.</div>



1. Log in to [the Direct Connect Gateway console](https://console.byteplus.com/dc/DirectConnectGateway).

2. In the top menu bar, select your target region.

3. In the DC Gateway list, click the name of the target DC Gateway to enter the details page.

4. In the **Overview** tab, click the IPv6 switch to enable the IPv6 feature.

5. In the pop\-up dialog box, click **Enable** to complete the action.
