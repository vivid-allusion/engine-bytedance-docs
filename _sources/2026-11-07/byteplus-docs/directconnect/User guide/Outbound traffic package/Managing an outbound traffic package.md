## View an outbound traffic package

You can view the status and deduction details of the outbound traffic package anytime in the console.

<span id="G1ylL0LH"></span>
### Procedure


1. Log in to the [Outbound Traffic Package console](https://console.byteplus.com/dc/OutboundTrafficPacket).

2. In the top menu bar, select your target region.

3. View the usage status of the outbound traffic package in the console.

   * Status: The current status of the outbound traffic package, such as **In effect**, **Expired**, **Used up**, **Refunded**, **Reclaimed**, and **Creation failed**.

   * Used/Total: The used volume and total volume of the outbound traffic package. Round the number to three decimal places using the round\-half\-up method.

4. Click **Deduction details** to the right of the target outbound traffic package to redirect to the instance management interface. View usage details of the outbound traffic package in the **Resource Package** tab:

   * **Deduction details**: View the deduction details of the target outbound traffic package on the **Deduction details** tab.

      > Support searching by Instance ID to view deduction details of other outbound traffic packages. For parameter details, see [Managing coupons](https://docs.byteplus.com/en/docs/byteplus-platform/docs-managing-coupons).      
      

   * **Overview**: Select the **Overview** tab to view the specification and usage status of all outbound traffic packages under the current account.

## Unsubscribe an outbound traffic package

<span id="EEb4dtiU"></span>
### Action notes


* Only support unsubscribing outbound traffic packages that have no traffic deductions in post\-purchase 7 days.

* Unsubscription is irreversible. Proceed with caution.


<span id="OPwBnU67"></span>
### Procedure


1. Log in to the [Outbound Traffic Package console](https://console.byteplus.com/dc/OutboundTrafficPacket).

2. In the top menu bar, select your target region.

3. Click **Unsubscribe** to the right of the target outbound traffic package.

4. Click **Unsubscribe**.

5. In the pop\-up dialog box, click **Unsubscribe** to complete the action.
