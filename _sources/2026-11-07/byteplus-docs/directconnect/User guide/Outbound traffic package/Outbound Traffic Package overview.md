## What is Outbound Traffic Package

An outbound traffic package is a prepaid traffic package provided by Direct Connect (DC). After purchase, it automatically offsets the outbound traffic fee generated by your DC gateway, offering a more cost\-effective solution compared to Pay\-as\-you\-go. You can select packages in different specifications based on your actual needs, and also specify their effective time. When the traffic package expires or is used up, the DC Gateway will revert to Pay\-as\-you\-go billing and generate charges normally. For details, see [Outbound traffic fees](https://docs.byteplus.com/en/docs/directconnect/Billing-overview).

<div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="default">Currently, the outbound traffic package does not support offsetting the outbound traffic fee of DC Gateways in China (Hong Kong), Asia Pacific (Johor), and Asia Pacific (Jakarta).</div>

## Billing notes

The outbound traffic package is a prepaid service, paying at one time. Supports monthly purchase and stacking multiple outbound traffic packages for use.


|Related actions |Notes |
|---|---|
|After purchase |Instant effect or Effect at specified time. It automatically applies to and consumes outbound traffic usage within the same region where it is purchased. Deductions are prioritized by expiration date, using the package with the earliest expiry first. |
|After expiration |The validity period is 1 month. No refunds will be issued upon expiration. Any unused traffic will be cleared. |
|Modify Spec |Unsupported. |
|Renew |Unsupported. |
|Unsubscribe |Currently, only outbound traffic packages completely unused support 7\-day free cancellation. Partially used traffic packages are non\-refundable. The payments will be fully refunded to your available balance. The coupons used are non\-refundable. |
|Effective target |The outbound traffic of the DC Gateway. |
|Unit conversion |The conversion factor between units is 1024, that is: 1 TB = 1024 GB, and 1 PB = 1024 TB. |
