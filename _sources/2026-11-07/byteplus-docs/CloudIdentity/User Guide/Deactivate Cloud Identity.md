# Deactivate Cloud Identity

<span id="scenarios"></span>
## Scenarios

Cloud Identity is a free service. No bills are generated when you activate or use it. You can deactivate Cloud Identity as needed.

<span id="prerequisites"></span>
## Prerequisites


1. You have activated Cloud Identity. Otherwise, you must [activate Cloud Identity](https://console.byteplus.com/cloudidentity/region:ap-southeast-1/ServiceOpen/).

2. You are an organization administrator, such as the root user or an authorized IAM sub\-user.


<span id="procedure"></span>
## Procedure


1. Log in to the BytePlus console and go to the [Settings](https://console.byteplus.com/cloudidentity/region:ap-southeast-1/setting/) page in Cloud Identity.

2. If you no longer need to retain Cloud Identity user data, require SSO permissions for employees to access various accounts, or maintain any other data within Cloud Identity, and you want to proceed with deactivating Cloud Identity and deleting the service instance, click **Deactivate Cloud Identity**. Cloud Identity will automatically delete all historical authorization tasks and user data, disable the trusted service between Cloud Identity and your organization, and remove the Cloud Identity service instance.


<span id="what-to-do-next"></span>
## What to do next

If you want to activate Cloud Identity again, refer to [Activate Cloud Identity](https://console.byteplus.com/cloudidentity/region:ap-southeast-1/ServiceOpen/).

<span id="faqs"></span>
## FAQs

<span id="can-the-cloud-identity-deactivation-process-be-canceled-can-deleted-data-be-restored"></span>
#### Can the Cloud Identity deactivation process be canceled? Can deleted data be restored?

Once you confirm deactivation, the system will automatically clear all service\-related data. This process cannot be canceled, and deleted data cannot be restored. Ensure that you no longer require related data before proceeding with deactivation.

<span id="can-cloud-identity-be-used-during-the-deactivation-process"></span>
#### Can Cloud Identity be used during the deactivation process?

No. During deactivation, all operations performed on Cloud Identity will not take effect, and no related data will be recorded.
