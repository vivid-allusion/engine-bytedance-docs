If a synchronization task encounters issues or failures that interrupt the task, you can continue the data synchronization by retrying the task after diagnosing and resolving the problem. This topic describes how to retry a synchronization task on the Database Transmission Service (DTS) console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A data synchronization task has been created, and the task status is **Failed**. Refer to [Task status instructions](https://docs.byteplus.com/en/docs/DTS/managing_synchronization_task_tags) for details about the synchronization task status.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* When the synchronization task is a bidirectional synchronization task, you can retry the forward and reverse synchronization task separately.

* When a synchronization failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If synchronization failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".6YeN6K-V5oyH5a6a5Lu75Yqh"></span>
## Retry a specified task


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data synchronization**.

4. On the **Data synchronization list** page, to the right of the target forward or reverse task progress, select  **...**  \> **Retry**.

5. In the **Confirm retry selected synchronization task** dialog box, click **Retry**.


<span id=".5om56YeP6YeN6K-V5Lu75Yqh"></span>
## Batch retry tasks


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data synchronization**.

4. On the **Data synchronization list** page, select the tasks to be retried, and click **Batch retry** in the bottom menu bar.

5. In the **Retry task** dialog box, click **OK**.

   Confirm the tasks to be retried in the **Retry task** dialog box. To exclude any tasks, click **Remove** in the **Actions** column to delete them.
