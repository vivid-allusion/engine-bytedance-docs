After creating a synchronization task, you can view the details of the synchronization task on the console, including the basic information, source and target database information of the synchronization task. This topic describes how to view synchronization task details.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A migration task has been created. For the method to create a migration task, refer to [Creating a synchronization task](https://docs.byteplus.com/en/docs/DTS/creating_and_initiating_a_synchronization_task).

<span id="EHaVTvfT"></span>
## Precautions


* When a synchronization failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If synchronization failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.


3. In the left navigation bar, click **Data synchronization**.


4. On the **Data synchronization list** page, you can view the following information.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If your list contains many tasks, you can quickly filter and query forward or reverse tasks that meet the criteria by using the task status, task billing method, task name, task ID, database instance ID, database instance IP Address, database instance domain name, or Tag in the search box above the list.   </div>
   

   
   |**View details** |**Description** |
   |---|---|
   |Task basic information |On the **Data synchronization list** page, you can view the task name, ID, state, and synchronization progress of the task in each synchronization process.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The synchronization process depends on the synchronization type you selected when creating the task, including user synchronization, schema synchronization, full synchronization, incremental synchronization, pre\-trigger synchronization, and post\-schema synchronization.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">During incremental synchronization, the displayed delay represents the sum of the source Binlog latency and the task latency. That is, the time difference between incremental data generation from the source end and writing to the destination.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When a synchronization failure occurs, you can hover over the failed status to view the failure reason. You can click <strong>Task one\-click diagnosis</strong> or <strong>AI analysis</strong> to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click <strong>Retry</strong>. If synchronization failure persists after retrying, you can <a href="https://console.byteplus.com/workorder/create/">submit a ticket</a> to contact technical staff for further diagnosis.</div><br> |
   |Start time, End time |On the task list page, view the **Start time** and **End time** of the target task:<br><br><br>* Start time: The time when the task starts executing.<br><br>* End time: The time when the task execution completes. |
   |Source end or destination |On the task list page, hover the cursor over the source or target database to view the database type, access method, region, instance ID, instance IP domain name, DBName or connection address and port information of the source and target ends.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance ID: When the source or target end is a BytePlus instance, such as BytePlus RDS for MySQL, you can hover over the database name to display the instance ID in a pop\-up tooltip. You can also click the ID to navigate to the instance information tab of the corresponding instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance IP domain name: When the source or target end is connected over public network, on BytePlus ECS, or connected over express network, you can hover over the database name to display the instance's IP domain name in the pop\-up tooltip.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Connection address and port: When the source or target end is connected over public network, on BytePlus ECS, or connected over express network, you can hover over the database name to see the connection address and port of the corresponding instance in the pop\-up tooltip.</div><br> |
   |Task project information |In the task list, you can view the project to which a task belongs under the project column of the target task. You can also hover over the project name and click the project name in the pop\-up tooltip to navigate to the project details page in IAM. |
   |Task tag |In the task list, you can view the tags bound to a task under the project of the target task. You can also hover over the tag name to view all tags bound to the task. Click the pencil icon after **Tag** to associate or disassociate tags for the current task. For more information, refer to [Managing synchronization task tags](https://docs.byteplus.com/en/docs/DTS/managing_synchronization_task_tags). |
   |Task billing information |In the task list, you can view the billing method of a task under the billing type of the target task. When the task billing method is subscription, hovering on subscription displays the task expiration time, allowing renewal if needed. For renewal steps, refer to [Renewal management](https://docs.byteplus.com/en/docs/DTS/renewal_management). |
   

5. On the **Synchronization task list** page, click the target task name.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If your list contains many tasks, enter filter criteria (e.g., task status, billing method, task ID and task name) in the search box above the list to quickly find the target task that meets the criteria.   </div>
   

6. On the **Task details** tab, you can view the following information:

   
   |**Region** |**Description** |
   |---|---|
   |**Basic information** |In the **Basic information** area, you can view the **Task ID**, **Task name**, **Task status**, **Link specifications**, **Project**, **Synchronization data type**, **Synchronization scope**, **Primary key conflict handling**, **Start time**, **End time**, and **Tag**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">In the <strong>Basic information</strong> area, you can also perform the following actions:</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Modify task name: Click the pen icon next to the task name to change the task name.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Modify primary key conflict handling: Click the pen icon next to <strong>Primary key conflict handling</strong>, and select the primary key conflict handling method of the task as required in the drop\-down list.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Edit tags: click the pen icon next to <strong>Tag</strong> to add, delete, modify, or view tags in the <strong>Edit tags</strong> dialog box. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/configuring_synchronization_delay_isolation">Managing synchronization task tags</a>.</div><br> |
   |**Source database information** |In the **Source database information** area, you can view details such as **Instance type**, **Access method**, **Availability zone**, **Host address**, **Port**, **Instance ID**, or **Database account**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">In the <strong>Source database information</strong> area, if you have changed the database account password on the source end, you can synchronize the password update on the DTS console. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/modifying_the_account_password_of_source_database_or_destination_database_of_a_synchronization_t">Modifying the database account password for the synchronization task</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When the source database is a BytePlus instance, such as BytePlus RDS for MySQL, you can click the instance ID to navigate to the instance information tab and view more details about the instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If you are synchronizing to RDS for MySQL read\-only node data, the <strong>Source database information</strong> area displays the read\-only node ID.</div><br> |
   |**Target database information** |In the **Target database information** area, you can view details such as the target database’s **Instance type**, **Access method**, **Availability zone**, **Host address**, **Port**, **Instance ID**, or **Database account**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">In the <strong>Target database information</strong> area, if you have changed the database account password on the target end, you can synchronize the password update on the DTS console. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/modifying_the_account_password_of_source_database_or_destination_database_of_a_synchronization_t">Modifying the database account password for the synchronization task</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When the target database is a BytePlus instance, such as BytePlus RDS for MySQL, you can click the instance ID to navigate to the instance information tab and view more details about the instance.</div><br> |
   |**Billing information** |In the **Billing information** area, you can view the task's **Billing method** and **Creation time**. |
   

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">When the instance type of <strong>Source database information</strong> is Cache for Redis, you can view the selected databases for synchronization in the <strong>Basic information</strong> area, with support for displaying up to 256 databases.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">When the source or target is on BytePlus ECS, connected over public network, or connected over express network, you can view the host address and port information of the database.   </div>
