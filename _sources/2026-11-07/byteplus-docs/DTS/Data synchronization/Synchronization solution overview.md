BytePlus Database Transmission Service (DTS) supports data synchronization between data sources through structure initialization, full initialization, and incremental synchronization synchronize types. This topic introduces the synchronize type, synchronization solution, and task status of data synchronization tasks.

## Synchronize type instructions

|**Synchronization type** |**Description** |
|---|---|
|**User initialization** |Migrates specified non\-system accounts and their associated permissions from the source database to the target database. |
|**Schema initialization** |Reads the source database and table schema definition syntax and reassembles it into the syntax format of the target database. |
|**Full initialization** |Fully read the source table content and write it to the target database. |
|**Incremental synchronization** |Parses and replays the target database incremental log to achieve online data synchronization. |

## Task status description

|**Task status** |**Description** |
|---|---|
|**To be started** |The status that a synchronization task enters after the configuration object is completed or the pre\-check is finished, and save is selected during task creation. |
|**In progress** |The status of the synchronization task that is in progress. |
|**Paused** |The state a task enters after you actively pause it. |
|**Synchronize failed** |The state that a synchronization task enters when issues or faults occur during the synchronization process, resulting in task interruption or abnormality. |
|**Synchronization completed** |The state the task enters after performing the following operations:<br><br><br>* The state the data synchronization task enters after it is complete.<br><br>* After a task in progress or paused is terminated, the task status will first change to terminating, and then to synchronization completed. |
