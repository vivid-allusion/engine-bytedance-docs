Database Transmission Service (DTS) provides streaming data ETL (Extract Transform Load) data processing capabilities. When creating a synchronization or subscription task, you can define data processing logic by editing DSL scripts to extract, transform, process, and load source database data. This topic describes how to configure ETL in a DTS data synchronization or subscription task.

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* When you perform an operation to add a column in the ETL script, you need to manually add the column to the table in the target database. Otherwise, the ETL rules will not take effect.

* When you convert the attribute of a column in the ETL script, such as converting bigint to vachar, you need to manually modify the attribute of the target column in the table of the target database. Otherwise, the ETL rules will not take effect.

* In the ETL assistant, ETL statements are generated by the AI model. A small number of conversion results may be inaccurate and are for reference only.

## Configure ETL when creating a data synchronization or subscription task.

This topic uses the creation of a data synchronization task as an example to explain how to configure ETL rules during task creation. Modifying ETL for existing tasks includes the following two methods:


* If ETL is already enabled for an existing task, modifying the DSL script for the task's ETL is supported.

* If ETL is not enabled for an existing task, you can enable ETL for the task, and you also have the option to disable ETL for the task. This feature is only available for data synchronization tasks from MySQL to Elasticsearch.


<span id=".5pON5L2c5q2l6aqk"></span>
### Procedure


1. Create a synchronization task For more information, refer to [Creating and starting a synchronization task](https://docs.byteplus.com/en/docs/DTS/creating_and_initiating_a_synchronization_task).

2. In the **Configure synchronization objects** step, when performing ** Advanced configuration**, select **Yes** for **Enable ETL configuration**.

3. Enter the data processing ETL rules, which are DSL scripts, in the **Enter ETL statement or use ETL assistant to generate statements…**  text box. For more information about data processing statements, refer to [DSL syntax](https://docs.byteplus.com/en/docs/DTS/dsl_syntax).

   Database Transmission Service (DTS) supports a natural language\-to\-ETL feature, which can help you generate standard ETL statements from natural language and lower the threshold for ETL writing and learning. The following describes how to generate ETL statements using natural language.

   1. In the upper\-right corner of the ETL statement text box, click **ETL assistant**.

   2. In the **ETL assistant** dialog box, enter the ETL requirements, and then press Enter. The ETL assistant offers a variety of ETL capabilities. For more information, refer to [ETL assistant capabilities](https://docs.byteplus.com/en/docs/DTS/configuring_etl_in_dts_synchronization_task?lang=zh#.5pSv5oyB55qE5pWw5o2u5bqT).

   3. After the ETL is generated, you can copy the ETL statement to the ETL text box.

4. Click **Syntax verification** to verify that the data processing statement is correct.

## Modifying ETL configuration in existing synchronization or subscription tasks

This topic uses modifying ETL configuration in a synchronization task as an example to describe how to modify ETL rules in a task.

<span id=".5rOo5oSP5LqL6aG5"></span>
### Precautions


* When you modify an existing ETL rule, you need to move the synchronization objects from the selected object to the synchronization objects, then re\-add them to the selected object, and then modify the ETL rule.

* Modifying ETL configuration on an existing synchronization task does not currently support changing the table structure of the target table. To change it, you need to change the table structure at the destination before starting the synchronization task.

* The modification of ETL rules only takes effect for incremental data after the synchronization task is started, and does not take effect for historical data before the ETL configuration is modified.

* The fields configured in the DSL script of the ETL rule can not be those filtered by the filter condition. Otherwise, the task will be abnormal.

* The DSL scripts of ETL rules are case\-sensitive. The database name, table name, and field name must be exactly the same as those in the source database.

* The DSL script of ETL rules does not support multi\-line expressions. You can use the `e_compose` function to combine multiple expressions into one expression.


<span id=".5L-u5pS5LWV0bC3phY3nva4="></span>
### Modify ETL configuration


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data synchronization**.

* ETL is enabled for the current task.

   1. On the **Data synchronization list** page, click the name of the target task.

   2. On the task details page, click **Task configuration**.

   3. On the **Task configuration** tab, locate the **Advanced configuration** area, click **Edit**.

   4. In the **ETL rules debugging and updating** control panel, configure ETL rules.

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">To verify whether the ETL rules you configured can achieve the expected results in the target table, you can click <strong>Debug</strong> for verification. For detailed configuration information, refer to <a href="https://docs.byteplus.com/en/docs/DTS/debugging-ETL-rules-with-ETL-Playground-tool">Verifying ETL rules using the ETL Playground tool</a>.      </div>
      

   5. Click **Validate syntax** to verify the accuracy of the ETL rules. When an error message is displayed, you need to modify the data processing statement based on the error message.

   6. Click **Update ETL**.

* ETL is disabled for the current task.

   1. Click **Configure** for the target unidirectional synchronization task.

   2. On the modify synchronization task page, locate the **Advanced configuration** area, set **Enable ETL configuration** to **Yes** to enable the ETL function.

      * After enabling ETL rules, click **Quick configuration field mapping/filtering rules**, configure synchronization objects in the **Quick configuration field mapping/filtering rules** dialog box, and click **OK** to quickly generate ETL statements.

      * After enabling the ETL function, you can configure data processing ETL rules by referring to the [DSL syntax](https://docs.byteplus.com/en/docs/DTS/dsl_syntax). Enter the data processing ETL rules, i.e., the DSL script, in the **Enter ETL statements or use ETL assistant to generate statements...** text box, and click ** Validate syntax** to verify whether the data processing statements are correct.

      * You can also use the ETL assistant to generate ETL statements in natural language. In the upper\-right corner of the ETL statement text box, click **ETL assistant** to input ETL requirements, and press Enter. After generating the ETL, copy the generated ETL statements into the ETL text box. The ETL assistant offers a variety of ETL statement generation capabilities. For more information, refer to [ETL assistant capabilities](https://docs.byteplus.com/en/docs/DTS/configuring_etl_in_dts_synchronization_task?lang=zh#.5pSv5oyB55qE5pWw5o2u5bqT).

      * Click **Debug** to test the effects of the ETL rules you created. For details on debugging, refer to [Verifying ETL rules via ETL Playground tool](https://docs.byteplus.com/en/docs/DTS/debugging-ETL-rules-with-ETL-Playground-tool).

   3. Click **Start task**.


<span id=".5YWz6ZetLWV0bC3phY3nva4="></span>
### Disable ETL configuration

Currently, only disabling ETL configuration for synchronization tasks from MySQL to Elasticsearch is supported.


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data synchronization**.

4. Click **Configure** for the target unidirectional synchronization task.

5. On the modify synchronization task page, locate the **Advanced configuration** area, set **Enable ETL configuration** to No to disable the ETL function.

6. Click **Start task**.
