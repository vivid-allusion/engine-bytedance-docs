---
title: "Does DTS support synchronizing data from read-only nodes of the source MongoDB database?"
product: "Database Transmission Service"
product_code: "DTS"
source: "https://docs.byteplus.com/en/docs/DTS/Does_DTS_support_synchronizing"
---

* If the source MongoDB is connected over the public or express network, data synchronization from read\-only nodes is supported.

* If the source MongoDB is Volcengine Database for MongoDB, data synchronization from read\-only nodes is not supported.
