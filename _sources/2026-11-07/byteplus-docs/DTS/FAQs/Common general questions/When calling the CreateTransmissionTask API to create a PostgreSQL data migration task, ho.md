product: "Database Transmission Service"
product_code: "DTS"

Currently, DTS does not support creating PostgreSQL data migration tasks via the `CreateTransmissionTask` API. It is recommended that you use the [DTS console](https://console.byteplus.com/dts) or the [DTS Python SDK](https://docs.byteplus.com/en/docs/DTS/code_examples) to create a PostgreSQL data migration task.
