You can use the full\-incremental feature to migrate or synchronize large amounts of MySQL data. The full\-incremental feature is currently in beta testing. To use it, [submit a ticket ](https://console.byteplus.com/workorder/create/)for technical support. For more information, refer to [What is the full-incremental feature?](https://docs.byteplus.com/en/docs/DTS/architecture_principles).
