---
title: "Why are some migration types not visible on the Task progress tab?"
product: "Database Transmission Service"
product_code: "DTS"
source: "https://docs.byteplus.com/en/docs/DTS/why_are_some_migration_types_not_displayed_under_the_migration_progress_tab"
---

If you can not see the tab for a specific migration type, it may be because the type was not selected during migration task configuration, or the database being migrated does not support that type. For more details, refer to [View migration progress](https://docs.byteplus.com/en/docs/DTS/viewing_migration_progress).
