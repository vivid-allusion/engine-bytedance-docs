After successfully creating a migration task, you can view the details of the migration task on the console, including the basic information, source and target database information of the migration task. This topic introduces how to view migration task details.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A migration task has been created. For the method to create a migration task, refer to [Creating a migration task](https://docs.byteplus.com/en/docs/DTS/creating_and_initiating_a_migration_task).

<span id=".5pON5L2c5q2l6aqk"></span>
## Precautions


* When a migration failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If migration failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data migration**.

4. On the **Migration task list** page, you can view the following information.

   
   |**View details** |**Description** |
   |---|---|
   |Task basic information |On the **Data migration list** page, you can view the task name, ID, state, and migration progress of the task during each migration process.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The migration process depends on the migration type you select when creating the task. Migration types include user migration, schema migration, full migration, incremental migration, pre\-trigger migration, and post\-schema migration.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">During incremental migration, the displayed delay represents the sum of the source Binlog latency and the task latency. That is, the time difference between incremental data generation from the source end and writing to the destination.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When a migration failure occurs, you can hover over the failed status to view the failure reason. You can click <strong>Task one\-click diagnosis</strong> or <strong>AI analysis</strong> to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click <strong>Retry</strong>. If migration failure persists after retrying, you can <a href="https://console.byteplus.com/workorder/create/">submit a ticket</a> to contact technical staff for further diagnosis.</div><br> |
   |Start time, End time |On the task list page, view the **Start time** and **End time** of the target task:<br><br><br>* Start time: The time when the task starts executing.<br><br>* End time: The time when the task execution completes. |
   |Source or target database information |On the task list page, hover the cursor over the source or target database to view the database type, access method, region, instance ID, instance IP domain name, DBName or connection address and port information of the source and target ends.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance ID: When the source or target end is a BytePlus instance, such as BytePlus RDS for MySQL, you can hover over the database name to display the instance ID in a pop\-up tooltip. You can also click the ID to navigate to the instance information tab of the corresponding instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance IP domain name: When the source or target end is self\-managed over the Internet or VPC, you can hover over the database name to see the IP domain name of the corresponding instance in the pop\-up tooltip.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Connection address and port: When the source or target end is self\-managed over the Internet or VPC, you can hover over the database name to see the connection address and port of the corresponding instance in the pop\-up tooltip.</div><br> |
   |Project information |In the task list, you can view the project to which a task belongs under the project column of the target task. You can also hover over the project name and click the project name in the pop\-up tooltip to navigate to the project details page in IAM. |
   |Tag |In the task list, you can view the tags bound to a task under the project of the target task. You can also hover over the tag name to view all tags bound to the task. Click the pencil icon after **Tag** to associate or disassociate tags for the current task. For more information, refer to [Managing migration task tags](https://docs.byteplus.com/en/docs/DTS/managing_migration_task_tags). |
   |Billing information |In the task list, you can view the billing method of a task under the billing type of the target task. |
   

5. On the **Migration task list** page, click the target task name.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If your list contains many tasks, enter filter criteria (e.g., task status, billing method, task ID, task name, database instance ID, database instance IP address, database instance domain name, or tag) in the search box above the list to quickly find the target task that meets the criteria.   </div>
   

6. On the **Task details** tab, you can view the following information:

   
   |**Region** |**Description** |
   |---|---|
   |**Basic information** |In the **Basic information** area, you can view the **Task ID**, **Task name**, **Task status**, **Link specifications**, **Project**, **Start time**, **End time**, **Full consistency**, **GitSet**, and **Tag**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">In the <strong>Basic information</strong> area, you can also perform the following actions:</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Modify task name: Click the pen icon next to the task name to change the task name.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Edit tags: click the pen icon next to <strong>Tag</strong> to add, delete, modify, or view tags in the <strong>Edit tags</strong> dialog box. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/managing_migration_task_tags">Managing migration task tags</a>.</div><br> |
   |**Source database information** |In the **Source database information** area, you can view details such as **Instance type**, **Access method**, **Availability zone**, **Host address**, **Port**, **Instance ID**, or **Database account**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">In the <strong>Source database information</strong> area, if you have changed the database account password on the source end, you can synchronize the password update on the DTS console. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/modifying_the_account_password_of_the_source_database_or_destination_database_of_a_migration_task">Modifying the database account password for migration task</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When the source database is a BytePlus instance, such as BytePlus RDS for MySQL, you can click the instance ID to navigate to the instance information tab and view more details about the instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If you are migrating RDS for MySQL read\-only node data, the <strong>Source database information</strong> area displays the read\-only node ID.</div><br> |
   |**Target database information** |In the **Target database information** area, you can view details such as the target database’s **Instance type**, **Access method**, **Availability zone**, **Host address**, **Port**, **Instance ID**, or **Database account**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">In the <strong>Target database information</strong> area, if you have changed the database account password on the target end, you can synchronize the password update on the DTS console. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/modifying_the_account_password_of_the_source_database_or_destination_database_of_a_migration_task">Modifying the database account password for the migration task</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When the target database is a BytePlus instance, such as BytePlus RDS for MySQL, you can click the instance ID to navigate to the instance information tab and view more details about the instance.</div><br> |
   |**Billing information** |In the **Billing information** area, you can view the task's **Billing method** and **Creation time**. |
   


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">When the instance type of <strong>Source database information</strong> is Cache for Redis, you can view the selected databases for migration in the <strong>Basic information</strong> area, with support for displaying up to 256 databases.</div>


* <div data-tips="true" data-tips-type="tip">When the source or target type is self\-managed over the Internet or VPC, you can view the host address and port information of the database.</div>
