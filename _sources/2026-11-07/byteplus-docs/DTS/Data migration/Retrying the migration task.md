If a migration task encounters issues or failures that interrupt the task, you can continue the data migration by retrying the task after diagnosing and resolving the problem. This topic describes how to retry a migration task on the Database Transmission Service (DTS) console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A data migration task has been created, and the task status is **Migration failed**. For details about migration task status, refer to [Instructions on migration task status](https://docs.byteplus.com/en/docs/DTS/overview_of_migration_solutions#.5Lu75Yqh54q25oCB6K-05piO).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* If source and target instances are in different regions, you need to retry the task at the destination.

* When a migration failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If migration failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".6YeN6K-V5oyH5a6a5Lu75Yqh"></span>
## Retry a specified task


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data migration**.

4. On the **Migration task list** page, click **Retry** at the top right of the target task.

5. In the **Retry selected migration task?**  dialog box, click **Retry**.


<span id=".5om56YeP6YeN6K-V5Lu75Yqh"></span>
## Batch retry tasks


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data migration**.

4. On the **Migration task list** page, select the migration tasks to retry, then click **Batch retry** in the bottom menu bar.

5. In the **Retry task** dialog box, click **OK**.

   Confirm the tasks to be retried in the **Retry task** dialog box. To exclude any tasks, click **Remove** in the **Actions** column to delete them.
