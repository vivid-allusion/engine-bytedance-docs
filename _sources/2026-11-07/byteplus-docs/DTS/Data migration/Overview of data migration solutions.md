BytePlus Database Transmission Service (DTS) supports user migration, schema migration, full migration, and incremental migration modes to help you migrate data between data sources. This topic introduces migration types, migration solutions, and task status for data migration tasks.

## Migration type description

|**Migration type** |**Description** |
|---|---|
|**User migration** |Migrates specified non\-system accounts and their associated permissions from the source database to the target database. |
|**Schema migration** |Reads the source database and table schema definition syntax and reassembles it into the syntax format of the target database. |
|**Post\-schema migration** |To ensure the performance of data migration and the stability of the migration task, some database migration objects will be created after the incremental migration is completed. Objects that require post\-schema migration are as follows:<br><br><br>* MySQL: trigger, event.<br><br>* PostgreSQL: ordinary trigger, event trigger, RULE, exclusive constraint, foreign key constraint, check constraint, Domain constraint, and Sequence value setting. |
|**Full migration** |Fully read the source table content and write it to the target database. |
|**Incremental migration** |Parses and replays the target database incremental log to achieve online data migration. |

## Task status description

|**Task status** |**Description** |
|---|---|
|**To be started** |The task enters this state after you complete object configuration or pre\-check and choose to save during migration task creation. |
|**In progress** |State when the migration task is in progress. |
|**Paused** |The state a task enters after you actively pause it. |
|**Failed** |State entered when the task is interrupted or abnormal due to issues or failures during migration. |
|**Completed** |Task status after the following operations:<br><br><br>* State after the migration task is complete.<br><br>* Terminate tasks that are in progress or paused. The task status will first change to “terminating”, then to “completed”. |
