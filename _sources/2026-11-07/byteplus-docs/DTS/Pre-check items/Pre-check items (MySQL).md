Database Transmission Service (DTS) performs various checks on databases before creating or configuring migration or synchronization tasks for RDS for MySQL. This topic introduces the details of check items.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The pre\-check result levels include Error and Warning, as detailed below:</div>



* <div data-tips="true" data-tips-type="tip">Error: indicates an error\-level check result. When this type of error occurs during task creation pre\-check, it can not be ignored. Relevant information must be modified according to the prompts before re\-running the pre\-check.</div>


* <div data-tips="true" data-tips-type="tip">Warning: indicates a prompt\-level pre\-check result. When this type of error occurs during task creation pre\-check, it can be ignored.</div>
