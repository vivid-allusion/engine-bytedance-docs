Database Transmission Service (DTS) performs various checks on databases before creating or configuring migration or synchronization tasks for RDS for PostgreSQL. This topic introduces the details of check items.

|Item |Database type |Check scope |Level |Check content |Remarks |
|---|---|---|---|---|---|
|Target database connectivity check<br><br> |Target database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check if the data transfer service can connect to the target database. |None |
|Source database connectivity check<br><br> |Source database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check whether the data transmission server can connect to the source database. |None |
|Database connection and structure wildcard rule check<br><br> |Source database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Warning |Database connection and structure wildcard rule verification. |None |
|Target database version check<br><br> |Target database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check whether the source database and database version are PostgreSQL 11 to PostgreSQL 18. |None |
|Source database version check |Source database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check whether the source database and database version are PostgreSQL 11 to PostgreSQL 18. |None |
|Source database `wal_level` check<br><br> |Source database |* Incremental migration<br><br>* Incremental synchronization<br><br>* Data subscription |Error |Check whether source database `wal_level` is `logical`. |None |
|Replication slot count configuration check |Source database |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check if the source database has available replication slots. |None |
|Check the number of source database sending processes<br><br> |Source database<br><br> |* All migrations<br><br>* All synchronization<br><br>* Data subscription |Error |Check if the number of source database sending processes meets migration requirements. |None |
|Source primary database check |Source database |* All migrations<br><br>* All synchronization |Error |Check if data is migrated or synchronized from the primary database during migration or synchronization. |Only data from the primary database supports migration or synchronization. Data from the secondary database is not supported. |
|Source\-end user logical replication privileges check. |Source database |* Incremental migration<br><br>* Incremental synchronization<br><br>* Incremental subscription |Error |Source\-end user logical replication privileges check. |None |
|Source database dependency check<br><br> |Source database |* All synchronization<br><br>* All migrations |Error |Check the migration content selected in the source database for any dependency objects that may cause migration failure. |None |
|Database & table nonexistence check for the target database |Target database |* Incremental migration<br><br>* Incremental synchronization |Warning |For incremental migration, check whether the target database does not exist. |This check item runs only when incremental migration or incremental synchronization is selected, but schema migration or schema synchronization is not selected. |

Migration or synchronization of databases and tables requires only the corresponding permissions on those databases and tables. The migration account requires `pg_catalog usage` privileges. |
|Can a slot be created |Source database |Data subscription |Error |Check whether the source database can create slots. |None |
|Check tables in the same instance and database on the source and target ends |* Source database<br><br>* Target database |* All migrations<br><br>* <br><br><br>Unidirectional synchronization |Error |Check whether the source and target ends are the same instance and database & table. |None |
