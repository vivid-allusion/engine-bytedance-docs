When a subscription task fails due to issues or faults, you can retry the task to continue data subscription after you locate the issues and resolve the faults. This topic describes how to retry a subscription task on the Database Transmission Service (DTS) console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A subscription task has been created, and the task status is **Failed**. For more information, refer to [Subscription solution overview](https://docs.byteplus.com/en/docs/DTS/overview_of_subscription_solutions).

<span id=".5rOo5oSP5LqL6aG5"></span>
## Precautions


* When a subscription failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If subscription failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".6YeN6K-V5oyH5a6a5Lu75Yqh"></span>
## Retry a specified task


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data subscription**.

4. On the **Data subscription list** page, in the upper\-right corner of the target subscription task, select **More operations \> Retry**.

5. In the **Whether to retry the selected task** dialog box, click **Retry**.


<span id=".5om56YeP6YeN6K-V5Lu75Yqh"></span>
## Batch retry tasks


1. Log in to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data subscription**.

4. On the **Data subscription list** page, select the tasks that need to be retried, and click **Batch retry** in the bottom menu.

5. In the **Retry task** dialog box, click **Retry**.

   Confirm the tasks to be retried in the **Retry task** dialog box. To exclude any tasks, click **Remove** in the **Actions** column to delete them.
