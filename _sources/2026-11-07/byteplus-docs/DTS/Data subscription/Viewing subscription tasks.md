After the subscription task is successfully created, you can view the task details on the console, including the basic information, source database information, target database information, and billing information of the subscription task. This topic describes how to view subscription task details.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

A subscription task has been created. For the method to create a subscription task, refer to [Creating a subscription task](https://docs.byteplus.com/en/docs/DTS/overview_of_subscription_solutions).

<span id="vQhDX0i1"></span>
## Precautions


* When a subscription failure occurs, you can hover over the failed status to view the failure reason. You can click **Task one\-click diagnosis** or **AI analysis** to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click **Retry**. If subscription failure persists after retrying, you can [submit a ticket](https://console.byteplus.com/workorder/create/) to contact technical staff for further diagnosis.

* The one\-click diagnosis results, AI analysis results, and optimization suggestions are generated by the AI model and may not be entirely accurate. They are for reference only.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log on to the [DTS console](https://console.byteplus.com/dts/).

2. In the upper\-left corner of the top menu bar, select the project and region.

3. In the left navigation bar, click **Data subscription**.

4. On the **Data subscription list** page, you can view relevant task information as shown below.

   
   |**View details** |**Description** |
   |---|---|
   |Task basic information |On the **Data subscription list** page, you can view the task name, ID, state, and the progress of each subscription process.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="default">The subscription process refers to the subscription type you chose when creating the task, including incremental subscription, schema subscription, and full subscription.</div><br><br><br>* <div data-tips="true" data-tips-type="default">During incremental subscription, the displayed delay represents the sum of the source Binlog latency and the task latency. That is, the time difference between incremental data generation from the source end and writing to the destination.</div><br><br><br>* <div data-tips="true" data-tips-type="default">When a subscription failure occurs, you can hover over the failed status to view the failure reason. You can click <strong>Task one\-click diagnosis</strong> or <strong>AI analysis</strong> to quickly troubleshoot the issue. After modifying the corresponding problem according to the prompt information, click <strong>Retry</strong>. If subscription failure persists after retrying, you can <a href="https://console.byteplus.com/workorder/create/">submit a ticket</a> to contact technical staff for further diagnosis.</div><br> |
   |Start time, End time |On the task list page, view the **Start time** and **End time** of the target task:<br><br><br>* Start time: The time when the task starts executing.<br><br>* End time: The time when the task execution completes. |
   |Source or target information |On the task list page, hover the cursor over the source or target database to view the database type, access method, region, instance ID, instance IP domain name, DBName or connection address and port information of the source and target ends.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance ID: When the source or target end is a BytePlus instance, such as BytePlus RDS for MySQL, you can hover over the database name to display the instance ID in a pop\-up tooltip. You can also click the ID to navigate to the instance information tab of the corresponding instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Instance IP domain name: When the source end is self\-managed over public network, self\-managed on BytePlus ECS, or BytePlus express network, you can hover over the database name to display the instance's IP domain name in the pop\-up tooltip.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Connection address and port: When the source or target end is self\-managed over public network, self\-managed on BytePlus ECS, or BytePlus express network, you can hover over the database name to see the connection address and port of the corresponding instance in the pop\-up tooltip.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When messages are subscribed to the customer's built\-in middleware, viewing information related to the destination is not supported.</div><br> |
   |Project information |In the task list, you can view the project to which a task belongs under the project column of the target task. You can also hover over the project name and click the project name in the pop\-up tooltip to navigate to the project details page in IAM. |
   |Tag |In the task list, you can view the tags bound to a task under the project of the target task. You can also hover over the tag name to view all tags bound to the task. Click the pencil icon after **Tag** to associate or disassociate tags for the current task. For more information, refer to [Managing subscription task tags](https://docs.byteplus.com/en/docs/DTS/managing_subscription_task_tags). |
   |Billing information |In the task list, you can view the billing method of a task under the billing type of the target task. When the task billing method is subscription, hovering on subscription displays the task expiration time, allowing renewal if needed. For renewal steps, refer to [Renewal management](https://docs.byteplus.com/en/docs/DTS/renewal_management). |
   

5. On the **Subscription task list** page, click the target task name.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If your list contains many tasks, enter filter criteria (e.g., task status, billing method, task ID, task name, database instance ID, database instance IP address, database instance domain name, or tag) in the search box above the list to quickly find the target task that meets the criteria.   </div>
   

6. On the **Task details** page, you can view subscription task information:

   * On the **Subscription details** tab, view the following information

      
      |**Region** |**Description** |
      |---|---|
      |**Basic information** |In the **Basic information** area, you can view the information such as **Task ID**, **Task name**, **Data subscription type**, **Subscription scope**, **Subscription format**, **Subscription instance region**, **Task status**, **Project**, **Start time**, **End time**, **Creation time**, or **Tag**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">In the <strong>Basic information</strong> area, you can also perform the following actions:</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">Modify task name: Click the pen icon next to the task name to change the task name.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">Edit tags: click the pen icon next to <strong>Tag</strong> to add, delete, modify, or view tags in the <strong>Edit tags</strong> dialog box. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/managing_subscription_task_tags">Managing subscription task tags</a>.</div><br> |
      |**Database information** |In the **Source database information** area, you can view details such as **Instance type**, **Access method**, **Availability zone**, **Host address**, **Port**, **Instance ID**, or **Database account**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">In the <strong>Source database information</strong> area, if you have changed the database account password on the source end, you can synchronize the password update on the DTS console. For details, refer to <a href="https://docs.byteplus.com/en/docs/DTS/modifying_the_account_password_of_the_source_database_of_a_subscription_task">Modifying the database account password for the subscription task</a>.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">When the source database is a BytePlus instance, such as BytePlus RDS for MySQL, you can click the instance ID to navigate to the instance information tab and view more details about the instance.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">If you are subscribing to RDS for MySQL read\-only node data, the <strong>Source database information</strong> area displays the read\-only node ID.</div><br> |
      |**Target database information** |When messages are subscribed to the Message Queue for Kafka, self\-managed Kafka on BytePlus ECS, or Message Queue for RocketMQ, this area displays the **Target database information**. In this area, you can view information such as **Kafka instance ID** or **RocketMQ instance ID**, and **AccessKey ID**.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">When messages are subscribed to Message Queue for Kafka or Message Queue for RocketMQ, you can click the Kafka or RocketMQ instance in this area to jump to the basic Information tab of the instance and view more details about the instance.</div><br> |
      |**Network information** |When messages are subscribed to the **Virtual private cloud**, this area displays **Network information**. In this area, you can view information such as **Subscription Topic**, **VPC**, **Subnet ID**, and **Private network address**. In this area, you can click VPC to jump to the VPC overview tab and view more information. |
      |**Billing information** |In the **Billing information** area, you can view the task's **Billing method** and **Creation time**. |
      

   * On the **Data consumption** tab, view the following information:

      You can view the consumer group's name, data bit position, current offset, message delay, account, and other information. For how to create a consumer group, refer to [Creating a consumer group](https://docs.byteplus.com/en/docs/DTS/adding_a_consumer_group).

      <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="2">tip      </div>
      

      <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">If data consumption is performed through self\-owned middleware, the consumption information needs to be checked based on the actual situation:      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">BytePlus ECS self\-managed Kafka: If you use the open\-source Kafka SDK to create a consumer group (“Group”), check data consumption information in the open\-source Kafka console.      </div>
      

      * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="2">Message Queue for Kafka: If you use the open\-source Kafka SDK to create a consumer group (“Group”), check data consumption information in the Message Queue for Kafka console. For detailed steps, refer to <a href="https://docs.byteplus.com/en/docs/kafka/Viewing-consumption-status">Viewing Group consumption status</a>.      </div>
