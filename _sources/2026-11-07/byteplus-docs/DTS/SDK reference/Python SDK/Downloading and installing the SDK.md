This topic describes how to download and install the DTS Python SDK.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## **Prerequisites**

Python 2.7 or a later version is installed. For more information, refer to [Python](https://www.python.org/downloads/?spm=a2c4g.198933.0.0.7bd569bd2bLIh3).

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">After the installation is succeeded, you can execute the <code>python --version</code> command to view the Python version.</div>


<span id=".c2RrLeS4i-i9veWcsOWdgA=="></span>
## **SDK download address**

For the DTS Python SDK source code Address, refer to [Python SDK](https://github.com/volcengine/volc-sdk-python/tree/main).

<span id=".5a6J6KOFLXNkaw=="></span>
## **Install the SDK**

Execute the following command to Install the Python SDK:

```python
pip install volcengine
```
