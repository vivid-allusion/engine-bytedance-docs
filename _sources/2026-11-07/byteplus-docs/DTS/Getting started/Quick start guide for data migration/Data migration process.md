This topic introduces the usage process of data migration, helping you quickly master creating and managing data migration tasks.

<span id=".6L-B56e75rWB56iL"></span>
## Migration process

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_1bcaab6d6e189b2d918669407fb62612.png) </span>


|**Procedure** |**Description** |
|---|---|
|[1. Preparations](https://docs.byteplus.com/en/docs/DTS/preparations) |Before using DTS for data migration, you must make some preparations for the source database or target database to meet the environment requirements of DTS. |
|[2. Create a migration task](https://docs.byteplus.com/en/docs/DTS/creating_and_initiating_a_migration_task) |You can create and start a migration task with simple operations in the console. |
|3. Optional. Manage migration tasks |* [View task progress](https://docs.byteplus.com/en/docs/DTS/viewing_migration_progress)<br><br>   After the migration task starts, you can view the progress of the migration task based on the running status on the data migration list page.<br><br>* [Set alerts](https://docs.byteplus.com/en/docs/DTS/setting_alerts)<br><br>   Cloud Monitor allows you to set alert policies. You can monitor DTS's data transmission performance and running status on Cloud Monitor. |
|[4. Business switching](https://docs.byteplus.com/en/docs/DTS/Migrating_on-premises_self-managed_databases_to_the_cloud_via_DTS) |After verifying and confirming that the data of the target database and source database is consistent, switch the business database service to the target database and recover the business. |
|[5. End the migration task](https://docs.byteplus.com/en/docs/DTS/terminating_a_migration_task) |Switch the business database service to the target database and recover the business for a period of time. After confirming there are no abnormalities in the data, you can end the data migration task. |
