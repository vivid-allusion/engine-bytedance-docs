# Prerequisite


* Before creating a configuration agent, you need to complete the purchase activation, project creation, and data preparation operations of iDA.

   * The operation of creating a project can be found in: [Project Information](https://docs.byteplus.com/docs/dataagent/Project_Information), [User Management](https://docs.byteplus.com/docs/dataagent/User_Management).

   * For operations to prepare data, see: [Data Preparation Overview](https://docs.byteplus.com/docs/dataagent/Data_Preparation_Overview_).

* Only the agent administrator user has the authority to create, configure, and manage the agent.


<span id="55890d62"></span>
# Create a General Scenario Agent

operation entrance


1. Enter the configuration page of the Intelligent Analysis Agent, click the **Create Agent** button in the upper right corner, and select Create General Scene Agent to enter the configuration page of the corresponding agent.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/324b466b1b4c4289b9c09c8bc355c798~tplv-goo7wpa0wc-image.image) </span>

2. You can click the **basic information** in the left navigation bar to configure the basic information of the agent, including the agent name, application description and adding members to the agent. Click the **save** button when the configuration is complete.

3. After saving, click the Publish button in the upper right corner to publish the agent.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/830f61c7189c493bb2e20077cba901a4~tplv-goo7wpa0wc-image.image) </span>

# Publish and Downloading Agents

After completing the creation and configuration of the agent, you need to release the agent online before further testing and use; for agents that are no longer in use, you can also go offline. You can deactivate an agent in two ways:


* Click the Take Offline button in the upper right corner of the agent configuration to logoff the agent;

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef24624d65a549c4aa87dcb049b892ec~tplv-goo7wpa0wc-image.image) </span>

* Find the corresponding agent in the agent list, click the More button in the lower right corner, select Log off, and log off the agent.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1126e4c92dc747789bf4d1fc56cdacb6~tplv-goo7wpa0wc-image.image) </span>

# Use Agents

This chapter mainly explains how to use the agent, including function entry, agent selection, task questioning, and related precautions, to help you quickly understand and use the agent's capabilities correctly.


1. After logging in to the iDA with your account password, click the agent to enter the agent list page.

2. You can choose to use the system's default general agent (Data Agent), or choose your newly created agent to use.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e35432ba8f934835abe124e7cf9630e2~tplv-goo7wpa0wc-image.image) </span>


<span id="0abc30bb"></span>
## Use a general agent

The general agent is the official prefabricated agent, also known as the Data Agent (Official), which is ready to use out of the box. You can directly select the corresponding skill or scene in the dialog box to use and answer the agent. The following will describe how to use it


1. In the list of agents, select Data Agent (Official) and click to enter the conversation page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ac1faa1176ab4b04a9972838ea455cab~tplv-goo7wpa0wc-image.image) </span>

2. On the conversation page, you can directly ask questions to the agent, or you can choose different usage scenarios to ask questions to the general agent. The agent will generate corresponding documents/PPT/videos/pictures according to your questions. For different scenario capabilities, please refer to [Quickly Start for iDA](https://docs.byteplus.com/docs/dataagent/Quickly_Start_for_iDA).

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1a263d21f1f44a75b968f5ce08157c53~tplv-goo7wpa0wc-image.image) </span>

3. For agents, the following operations are supported:

   * **Open a New Conversation** : You can click the **New Conversation** option at the top of the left navigation, and the system will jump to the New Conversation page to use the agent.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/44c973a203bf41b59ebb9ad8d215e6e3~tplv-goo7wpa0wc-image.image) </span>

   * **Manage Historical Conversations** : You can move your mouse over the left navigation and click the Manage Historical Conversations button to view all historical conversations. Support for searching historical dialogues by content, and support for editing and deleting historical dialogues.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/80f771b61ce4465880029e30dc966af9~tplv-goo7wpa0wc-image.image) </span>

   * Collapse/Expand Sidebar: Used to control the display and hiding of the left navigation panel. After folding, the view of the main content area can be expanded, and the navigation menu will be fully displayed when expanded.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c1fd6f38cdd240b6ab884d2ac4e509be~tplv-goo7wpa0wc-image.image) </span>

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/32963bb10a1f460fb3b21bf3057d7aaa~tplv-goo7wpa0wc-image.image) </span>

## Use a general scenario Agent

The use of a general scenario agent is roughly the same as that of a Data Agent (Official), except that the agent can be configured. For details of agent configuration, please refer to the documents in the agent directory: basic information, data assets, content configuration, etc.
