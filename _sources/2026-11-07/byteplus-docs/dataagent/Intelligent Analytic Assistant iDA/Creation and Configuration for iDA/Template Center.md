Template management capabilities support unified retrieval, viewing, and maintenance of templates. Users can quickly locate the desired template based on information such as template name and scene, and perform corresponding operations in combination with the different states of the template, such as viewing, editing, starting and stopping, recommending, or adjusting the scope of disclosure. With this ability, you can transform common questioning methods and analysis experiences into retrievable, manageable, and sustainably optimized template assets, enhancing template reuse efficiency and team collaboration.

# Create Template


1. Log in to the agent, select the agent, click to enter the agent use page, click the Create button in the template center below the Q & A, create a new template, and fill in the new template configuration item. The following is the configuration item description:


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b89395acc7442079584a0f18650e6ea~tplv-goo7wpa0wc-image.image) </span>


|Configuration item name |Explain |
|---|---|
|Name |The title of the template for identification and search. |
|Brief introduction |A short description of the template's purpose or applicable scenarios to help other users understand. |
|Scene |Select the business scenario for which the template is applicable, and support multiple selection. Scenario types include: data analytics, index attribution, trend analysis, semantic induction, knowledge Q & A, research analysis, program planning, caliber query, asset search, document writing, data processing, and others. |
|Is it public? |When turned on, the template is visible to all members of the same agent; when turned off, it is visible only to itself. |
|Is it recommended? |After opening, the template will be displayed in the recommended area of the template list, which is convenient for promoting high\-quality templates. |
|User command |Preset question or task instructions. Support manual scribing to add parameter variables (such as marking variable positions with `{{}}`). For example: "Please analyze the sales trend of {{product name}} in recent {{days}} days."<br><br>At the same time, it supports manual selection of skills as user instructions. |
|Parameter variable |The table is used to define variables in user instructions, and each row corresponds to a variable.<br><br><br>* Parameter variable: variable name, which must be the same as the variable marked in the user instruction<br><br>* Type: The data type of a variable, such as string, number, date, etc<br><br>* Default value: A value that is automatically used when the user does not fill in, which improves the ease of use of the template<br><br>* Variable Description: Explain the meaning of the variable or fill in an example, such as "Please enter a specific product name, such as: XX mobile phone".<br><br>* Required: Marks whether the variable is required. If required, the user must provide a specific value when using the template. |

# Use Template

The successfully created template is displayed below the template center, and it supports searching by template name. At the same time, it can be filtered and viewed through three types **of public templates/my favorites/my creations** .

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ca99dfe4d68e4339a06e04ed5229dac2~tplv-goo7wpa0wc-image.image) </span>


1. In the center of the template, mouse into the created template, and click the Use button to directly ask questions about the pre\-made template. The following operations are supported simultaneously:

   * Edit Template: Modify the content, configuration, or style of the current template.

   * Add the template to your personal collection for quick subsequent search and reuse.

   * **Delete template** : Remove the current template from the list and no longer use it;

   * **Share template** : copy the template link to share the template;

   * Copy Template: Copy an identical template in the Template Center.

   * **Enable networking** : Enable the networking capabilities of the template to access external network resources or data.
