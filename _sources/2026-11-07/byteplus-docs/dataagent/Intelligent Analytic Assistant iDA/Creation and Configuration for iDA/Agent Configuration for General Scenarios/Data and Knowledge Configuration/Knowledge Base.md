Knowledge base is the local knowledge configuration area provided by custom agent. Administrators can configure agent\-specific knowledge in this area and share it with all members of the custom agent.

Support to enter the knowledge engine to create a new knowledge base for the agent. The knowledge base entrance is located at the top right of the agent list. Click the button **to go to the knowledge base** to enter the knowledge base. For more information on knowledge base management, see [Create a New Knowledge Base](https://docs.byteplus.com/docs/dataagent/Create_a_New_Knowledge_Base), which can be selected in Knowledge Base Management in Agent Configuration.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">To add a knowledge base, you need to have corresponding knowledge base permissions.</div>



The following are the instructions for configuring the knowledge document:


1. On the agent list page, select the corresponding agent and click the **agent configuration** button to enter the agent configuration page.

2. Side navigation Click **Knowledge Base** to enter the knowledge base, click the **Add Knowledge Base** button above the knowledge base list, click the name of the knowledge base with permissions under the project, and then confirm that the knowledge base is added successfully.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d5cf5c27fcc849ca888a86a067ec4a85~tplv-goo7wpa0wc-image.image) </span>

3. The successful knowledge base created is displayed in the knowledge base list, and different operations can be performed on the knowledge base in the knowledge base list:

   * On or Off: Supports enabling or disabling the Knowledge Base in the Enabled status field.

   * View: Click the operation column view button to enter the knowledge base details to view the knowledge base.

   * Delete: Click the Delete button to delete the knowledge base.
