After purchasing and activating iDA, iDA currently provides you with a universal agent (default name: Data Agent official). You can directly use pre\-made general\-purpose agents for problem consultation. At the same time, you can also create and configure your own analytical agents or general\-purpose scene agents. This article provides you with an overview of the similarities and differences between general\-purpose agents (Data Agents) and general\-purpose scene agents.
