The "My Files" feature helps you efficiently manage and reuse iDA\-generated content, avoid duplication of effort, and deposit valuable digital assets. It is suitable for scenarios such as finding historically generated files, creating based on past artifacts, or archiving important files for a long time. This article details how to view and manage artifacts in "My Files".

# Prerequisites/Precautions

* Logged into iDA and has available seats; the artifact will automatically enter "My File" after the session is generated, no need to upload manually;

* The list is displayed according to the account dimension, and the artifacts of the specified agent can be viewed through the agent filter criteria;

* The types of artifacts that can be archived in the knowledge base are:

   |Document type |supported formats |
   |---|---|
   |Generic document |docx、doc、wps、txt、md |
   |PDF document |pdf、ofd |
   |PowerPoint |ppt、pptx |
   |Image |jpg、jpeg、png |
   |Other |html、json |

# View artifact

1. Log in to the BytePlus console, select iDA to enter the iDA Q&A interface, and click  **"My Files"**  in the side navigation to view the artifact.

2. At the top of the page, you can select and switch the **All** or **Favorites** tab, files are displayed in groups by session, click the arrow to the left of the group to expand or collapse the artifacts under the session; you can view the artifact name, artifact type and update time of each artifact.

3. **Find artifacts**: You can enter the artifact name directly in the search box, or use the top filter to filter by artifact type, agent, and file range.

# Artifact operation

You can perform different operations for specific artifacts. The following are the detailed operation instructions:

|Operation item |Description |
|---|---|
|**Add to favorites** |Add frequently used files to favorites for subsequent search.<br><br><br>1. Find the target artifact in the **full** list. Click the Favorites icon to the right of the artifact.<br><br>2. After Favorites, switch to the **Favorites** tab to view the artifact.<br><br>3. When you need to remove the favorites, click the favorites icon again to cancel the favorites.<br><br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3e933b764b0049cabbc1a6fd4ebd7537~tplv-goo7wpa0wc-image.image) |
|**Start conversation** |Select an existing file to initiate a new session and continue processing without re\-uploading.<br><br><br>1. Locate the artifact in the file list that requires continued processing. Click the **Start conversation** icon to the right of the artifact.<br><br>2. The system redirects to the conversation page and quotes the artifact to the text box.<br><br>3. After entering the specific processing requirements, a message is sent, and the agent executes the task based on the latest content of the artifact.<br><br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8d5dd266430c4493921821d419e5f98c~tplv-goo7wpa0wc-image.image) |
|**Archive to personal knowledge base** |Documents that need to be preserved for a long time can be **saved to the personal knowledge base** through the archive entry.<br><br><br>1. Locate the artifacts in the file list that require long\-term storage. Click the **Save to Personal Knowledge Base** icon on the right side of the artifact.<br><br>2. If the artifact type supports archiving, the system will archive it. You can view it in your personal knowledge base.<br><br><br>> **注意**<br><br><br>> If the artifact line does not show the archive entry, it means that the artifact type does not support archiving to the personal knowledge base for the time being. Please refer to the prerequisites above this document for the types of artifacts that support archiving.<br><br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0b9ce89003e44d629b0b0e276a53b12b~tplv-goo7wpa0wc-image.image) |
