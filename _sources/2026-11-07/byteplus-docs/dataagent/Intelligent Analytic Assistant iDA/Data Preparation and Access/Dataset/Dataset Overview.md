# 1. Dataset overview

A dataset is the foundation for storing and managing data, and also serves as the basis for visual query and analysis. Simply put, you can think of it as a type of data table. Users need to create datasets from the source tables they wish to analyze before proceeding with subsequent modeling and other operations. In the dataset module, you can create, edit, query, and manage datasets.

<span id="_2-使用场景"></span>
# 2. Usage scenarios

After completing [Data Connection Overview](https://docs.byteplus.com/docs/dataagent/Data_Connection_Overview), users can create datasets. You can create datasets directly from original tables, by joining multiple tables, using union operations, or by using custom SQL.
