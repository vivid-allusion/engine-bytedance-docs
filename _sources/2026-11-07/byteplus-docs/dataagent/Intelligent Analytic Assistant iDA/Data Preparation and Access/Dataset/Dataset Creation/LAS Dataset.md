# 1. Overview

The agent supports integration with the unified lakehouse analytics service LAS to obtain data, create datasets, and perform further analysis.

If your Volcano Engine account has purchased LAS resources, a default LAS storage data connection will appear when creating a new dataset, which can be used for modeling and data extraction.

## 3.5 Recommended dependencies

This product provides flexible **task scheduling dependency configuration** functionality. Scheduling dependencies typically refer to upstream and downstream relationships between periodic scheduling nodes during data synchronization and data development processes. By configuring node dependencies, tasks are scheduled to run upstream and downstream nodes sequentially; that is, after an upstream node runs successfully, the downstream node will start running, ensuring timely production of valid business data.

**Recommended dependency** refers to the system's ability to automatically construct data source partition detection tasks and automatically configure scheduling dependencies in LAS data sources with **partitions**. **The task instance for the day will only be triggered when the detection task confirms that the upstream partition is ready.**  (Recommended dependency configuration is not supported for data sources without partitions.)

Note: After the system wakes up the Sensor task at the scheduled time, it checks every 5 minutes whether the specified partition table of the data source has been generated. If the partition is generated, the current task will be executed immediately. If the partition is not produced for more than 50 hours, the Sensor task will be marked as failed.

> Sensor definition: A Sensor task mainly refers to a scheduled task generated by the system script to detect partitions, rather than the current task itself. For user\-configured scenarios, the system will automatically **detect and check** whether the required partition table for the task exists in the user's data source. If it exists, this indicates that the preparation of upstream data is complete and downstream data processing can be started.


The system will automatically discover dependency Sensor tasks that have already been created for the current table and recommend them for selection. If there are no recommendations, the list will be empty, and the user can choose to configure dependencies manually.

**Configuration method**: Confirm that the data source is a partitioned table, set the partition data filtering criteria in the model configuration, and in Synchronization Settings \> Dependency Configuration \> System Automatic Configuration, you will see the recommended dependencies.
