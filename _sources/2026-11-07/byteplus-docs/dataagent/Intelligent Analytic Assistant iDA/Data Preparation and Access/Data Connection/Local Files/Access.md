This article shows you how to upload an Access file as a data source to create a dataset.

<span id="be82fc62"></span>
# Precautions


* Support for uploading local Access database files (.mdb, .accdb), with a maximum file size of 4GB.


<span id="60366e23"></span>
# New from data connection


1. Enter Volcano Engine, click to enter a specific project, click Data Preparation, find Data Connection in the drop\-down list, and click Data Connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0e287890eafc413da40a2405869979c8~tplv-goo7wpa0wc-image.image) </span>

2. Select Access on the page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31993df0a5ab474a80cb5f187622a166~tplv-goo7wpa0wc-image.image) </span>

3. Enter basic information after uploading the file.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Support for uploading local Access database files (.mdb, .accdb), with a maximum file size of 4GB.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9a28603415ba46c6beabb57103858578~tplv-goo7wpa0wc-image.image) </span>

4. Select the table and click Next.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/31065eb0a4b94e83b8610c69b64a8805~tplv-goo7wpa0wc-image.image) </span>

5. Click Finish after the preview content is correct.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3de7b79451bd4b76b34c094f9f4615da~tplv-goo7wpa0wc-image.image) </span>


<span id="6cef2ea0"></span>
# Create a new dataset


1. Enter the Volcano Engine, click "Data Preparation" \- "Dataset", and select the "New" button in the upper left corner to create a new dataset.

   <div style="text-align: center">
   <img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5f8912b6dcc9465db18cf16a29c71ca2~tplv-goo7wpa0wc-image.image" width="2940px" />   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b2700dc012b148d59c714846a310b3cc~tplv-goo7wpa0wc-image.image) </span>

2. When selecting a data connection, click New Configuration.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bec3644887a04889b9a143c74d04a31c~tplv-goo7wpa0wc-image.image) </span>

3. The subsequent steps are consistent with the above\-mentioned 2 and 3 steps of **new data connection from** the above, and will stop in the pop\-up box of data set selection data connection after completing the configuration, and can directly proceed to the next step of dataset creation.

## Update Access Files


1. Go to the "Data Connection" page, select the Access data source, and click "Update File".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/57466a2f3f234cf1968fe37126d087a6~tplv-goo7wpa0wc-image.image) </span>

2. Upload a new Access file.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/00f946bf61fe4b10aada3870ee37a481~tplv-goo7wpa0wc-image.image) </span>

3. Select the table to preview and complete the update.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/70a072fac27e4f72a894b97ca9f02089~tplv-goo7wpa0wc-image.image) </span>
