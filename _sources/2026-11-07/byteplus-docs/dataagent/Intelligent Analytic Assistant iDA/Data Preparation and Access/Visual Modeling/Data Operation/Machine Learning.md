# 1. Overview

Machine learning refers to visual modeling that supports machine learning operators, enabling data processing so that users can perform model training, in\-depth analysis, predictive analysis, and more based on the data. This document introduces the functions of machine learning operators.

# 2. Function overview

<span id="_2-1-预测"></span>
## 2.1 Prediction

The model generated by training the machine learning operator is applied to the data to be predicted, typically linked after the machine learning operator.

**Field settings**

Feature column mapping: Define the mapping between feature columns in the model and those in the data.

Label column: Serves as the basis for classification training.

**Parameter settings**

Name of the prediction column: The name of the column to be predicted.

<span id="_2-2-one-hot-模型应用"></span>
## 2.2 One\-hot model application

The one\-hot model application operator is linked after the one\-hot encoding operator. The one\-hot operator not only supports representing string\-type columns as arrays, but also supports saving the conversion process as a model. Combined with the one\-hot model application operator, similar columns can be re\-encoded.

**Feature column mapping:**  Define the mapping between feature columns in the model and those in the data.

<span id="_2-3-分类"></span>
## 2.3 Classification

The following models are supported. For details, see the feature page.


|Model name |Model overview |
|---|---|
|Logistic regression |Logistic regression is a classic statistical learning classification model. It introduces a nonlinear transformation to the linear regression mapping. First, the sample's features are summed linearly, and then the logistic function maps this value to a range between 0 and 1, representing the probability that the sample belongs to each category. The category with the highest probability is selected as the final predicted category for the sample. This operator supports binary and multi\-class classification problems, supports continuous and categorical features, but categorical features require one\-hot encoding after string indexing. |
|Xgboost |Number of boosting rounds: The number of boosting iterations during training.<br><br>Use the best model: The best model is selected according to the evaluation metric specified for the optimal model.<br><br>Label index sorting method: 'frequency' means sorting by frequency, 'alphabet' means sorting in alphabetical order. |
|Catboost |A GBDT framework based on the oblivious trees algorithm, with few parameters, supports categorical variables, and offers high accuracy. It mainly addresses the challenge of efficiently and reasonably handling categorical features. The name CatBoost comes from 'categorical' and 'boost'. Additionally, it solves issues such as gradient bias and prediction shift, improving the algorithm's accuracy and generalization ability. CatBoost has the following five main features: 1. High model quality can be achieved without parameter tuning. Using default parameters yields excellent results, reducing the time spent on tuning. 2. Supports categorical variables without requiring preprocessing of non\-numeric features. 3. Fast and scalable GPU version. You can train your model using GPU\-based gradient boosting algorithms, with support for multi\-GPU parallelism. 4. Improved accuracy. A new gradient boosting mechanism is proposed to build models and reduce overfitting. 5. Fast prediction. Models can be deployed quickly and efficiently even for tasks with stringent latency requirements. |
|Naive Bayes |Naive Bayes is a classification method based on Bayes' theorem and the conditional independence assumption of features. The Naive Bayes classifier is easy to construct and suitable for large datasets; however, its drawback is that it requires assumptions about the prior distribution. This operator supports binary and multiclass classification problems, supports categorical and non\-negative continuous features, but categorical features must be indexed as strings beforehand. |
|Support vector machine |A statistical learning classification model whose basic idea is to find a separating hyperplane that can correctly classify the training dataset and maximize the geometric margin. |
|Decision tree |One of the commonly used classification algorithms, which often performs well in exploratory knowledge discovery. The principle of decision trees is very simple. They can handle high\-dimensional data and do not require prior knowledge of the model's features. These characteristics make decision trees widely used. Decision trees use a greedy algorithm, and their construction process also requires training data. The core issues of decision trees are determining the branching criteria and identifying the split points. |
|Random forest |In machine learning, a random forest is a classifier that contains multiple decision trees, and the output class is determined by the mode of the classes output by individual trees. In a random forest, the training data for each tree is sampled with replacement from the original training dataset, and a random subset of all features is selected. The optimal feature is chosen from this subset for splitting, rather than always selecting the global optimal point for splitting. This helps prevent overfitting of individual decision trees. |
|Gradient boosting tree |Gradient boosting tree is an ensemble learning model, and the internal models use decision trees. Unlike random forest, it trains only one tree at a time, and each new decision tree gradually corrects the errors made by previous decision trees. As more trees are added, the model's expressive power increases. |


<span id="_2-4-聚类"></span>
## 2.4 Clustering

The following models are supported. For details, see the feature page.


|Model name |Model description |
|---|---|
|K\-means clustering |The K\-means algorithm is a typical distance\-based clustering algorithm that uses distance as the similarity evaluation metric. After specifying K initial cluster centers (initial cluster mean centers), the distance between each sample and the K cluster mean centers is calculated. Each sample is assigned to the cluster whose mean center is closest to it. After each assignment, the cluster mean centers are updated, and the distances between all samples and the cluster mean centers are recalculated. This process continues until all given samples are clustered into K clusters and the cluster mean centers no longer change. |
|Gaussian mixture |Gaussian mixture clustering uses the Gaussian probability density function (normal distribution curve) to precisely quantify samples. Sample points can be clustered into several groups formed based on the Gaussian probability density function (normal distribution curve). In theory, it can fit any continuous function, but its drawback is high computational complexity. |
|Bisecting K\-means |The bisecting K\-means clustering algorithm is a variant of the K\-means clustering algorithm. It is mainly designed to address the issue of uncertainty in clustering results caused by the randomness of selecting initial centroids in the K\-means algorithm. The bisecting K\-means algorithm is less affected by the random selection of initial centroids. |


<span id="_2-5-回归"></span>
## 2.5 Regression

The following models are supported. For details, see the feature page.


|Model name |Model description |
|---|---|
|Linear regression |Linear regression is a type of regression analysis that models the relationship between one or more independent variables and a dependent variable using the least squares function of the linear regression equation. As shown in the figure below, the top section displays the fundamental formula, which is the linear sum of each feature. |
|Decision tree regression |Decision trees can be used for predicting continuous values and often perform well in exploratory knowledge discovery. The principle of decision trees is very simple. They can handle high\-dimensional data and do not require prior knowledge of the model's features. These characteristics have led to the widespread use of decision trees. Decision trees use a greedy algorithm, and their construction also requires training data. The core issues of decision trees are determining the branching criteria and identifying the split points. |
|Random forest regression |Random forest is an ensemble model, where the internal models use decision trees and random attribute selection is introduced during training. Specifically, traditional decision trees select the optimal attribute for splitting from the set of attributes at the current node (assuming there are d attributes). In random forests, for each node of the base decision tree, a subset containing k attributes is randomly selected from the node's attribute set, and then the optimal attribute for splitting is chosen from this subset. This operator supports continuous labels, as well as continuous features and categorical features. |
|Gradient boosting tree regression |An ensemble model, where the internal models use decision trees. Unlike random forests, it trains only one tree at a time, and each new decision tree gradually corrects the errors produced by the previous decision trees. As more trees are added, the model's expressive power increases. |
|Isotonic regression |Isotonic regression is a type of regression algorithm. Isotonic regression is defined as follows: Given a finite set of real numbers Y = {y_1, y_2, ..., y_n}, where Y represents known observed data, and X = {x_1, x_2, ..., x_n} represents unknown values, the goal is to find the minimum of the function f(x) = sum_{i=1}^n w_i(y_i \- x_i)^2, while ensuring that x_1 through x_n are increasing. |


<span id="_2-6-时间序列"></span>
## 2.6 Time series

**ARIMA model**

The data sequence formed by the prediction target over time is treated as a random sequence, and a mathematical model is used to approximate the description of this sequence. Once this model is identified, it can predict future values based on past and present values of the time series. This can help enterprises predict the future and guide their next decisions. Application scenarios: stock market rise and fall prediction and analysis, supermarket market turnover prediction and analysis, housing price rise and fall prediction and analysis, employee turnover prediction and analysis, product sales volume prediction and analysis, weather condition prediction and analysis, and many other scenarios.

<span id="_2-7-评估"></span>
## 2.7 Evaluation

The following evaluation models are supported. For details, refer to the functionality page.


|Model name |Model overview |
|---|---|
|Binary classification evaluation |This performance evaluation operator should be used for classification tasks, that is, when the label attribute is of binary variable type. The input to this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance standard values based on these two attributes. |
|Multi\-class evaluation |This performance evaluation operator should be used for classification tasks, meaning the label attribute has a multi\-class string value type. The input to this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance standard values based on these two attributes. |
|Clustering evaluation |This performance evaluation operator is used to evaluate the performance of clustering models. This operator expects the input to be a test sample set, which contains a column with the prediction role and a column with all features. |
|Regression evaluation |This performance evaluation operator should be used for regression tasks, meaning the label attribute has a numeric value type. The input to this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance standard values based on these two attributes. |
