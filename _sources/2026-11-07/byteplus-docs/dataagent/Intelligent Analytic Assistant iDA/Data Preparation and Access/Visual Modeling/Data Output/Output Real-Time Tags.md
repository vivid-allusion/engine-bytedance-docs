# 1. Overview

If you have also purchased the BytePlus VeCDP product, you can view and use the "Output Real\-Time Tags" operator in the output operator category of the data agent's visual modeling module (if not purchased, this operator will not be visible). The "Output Real\-Time Tags" operator outputs data to the tag system, supports custom processing pipelines, and outputs the results to tags.

<span id="_2-功能介绍"></span>
# 2. Feature overview

<span id="_2-1-添加“输出实时标签”"></span>
## 2.1 Add "Output Real\-Time Tags"

In a real\-time modeling task within visual modeling, click the add button for operators to see "Output Real\-Time Tags" in the output operator category, then click to select it.

<span id="_2-2-配置“输出实时标签”"></span>
## 2.2 Configure "Output Real\-Time Tags"

As shown in the figure above, after the user clicks to add the "Output Real\-Time Tags" operator, the user can configure the target entity, tag configuration, advanced configuration, and more. The definitions of each configuration item are as follows:

 **(1) Target entity**

Entity: The profile entity in CDP, that is, the target object of ID\-Mapping OneID.

 **(2) ID\-Mapping type**

A. **Real\-time conversion**: Based on the ID type field data corresponding to the ID type, the ID\-Mapping service is used to query in real time for an existing One\-ID (that is, the reference ID BaseID). If it is a completely new ID, meaning it has never participated in the generation of a One\-ID (that is, the reference ID BaseID), then the One\-ID (that is, the reference ID BaseID) data cannot be found.

B . **Real\-time generation**: Based on the ID type field data corresponding to the ID type, the ID\-Mapping service is used to participate in the generation of the ID\-Mapping OneID in real time. If a One\-ID (that is, the reference ID BaseID) has already been generated in the past, it will be queried directly; if it is a completely new ID, a new One\-ID (that is, the reference ID BaseID) will be generated by the ID\-Mapping service. The One\-ID (that is, the reference ID BaseID) can be used in all CDP product features. For detailed generation strategies, refer to CDP [Data Fusion \- ID Graph Construction \- Real\-Time OneID Generation Strategy].

Note: Real\-time generation of ID\-Mapping will affect the use of all data of the entity in CDP and is only available to group administrators.

 **(3) ID type and associated fields**


* **ID type**: The ID Code of a certain type of ID for the entity in the ID\-Mapping graph. For details, refer to CDP [Data Fusion \- ID Graph Construction \- ID Type Settings];

* **ID type field**: Select the field in the operator's input data source that corresponds to the ID\-Mapping ID type as the data input.


 **(4) Label configuration**

Label configuration: After a label is submitted, related labels will be automatically constructed in the label system, and the configuration will take effect only after the task is saved. Label field: Please select the field name to be defined as a label. Special field types such as Map are not supported for now.

Label name: Please define a name for the label that is easy to understand, either in Chinese or English.

Label description: Please define a description for the label that is easy to understand. Online service: When enabled, the label can be used to query related data in the high\-speed OpenAPI, supporting high\-concurrency queries.
