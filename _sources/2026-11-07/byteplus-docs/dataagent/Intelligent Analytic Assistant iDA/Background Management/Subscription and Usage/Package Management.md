Package management is used to view the current iDA package status, version information, expiration time, seat usage and resources package usage. Users can quickly find out whether the package is effective, whether the seats are sufficient, and the consumption of Token or Points resources on this page. And users can renew the fee, purchase additional seats, view the usage details, or purchase additional packages as needed.

# Prerequisite

* The administrator logged into the BytePlus console and entered iDA.

# View package information

After entering the package management page, you can view the current package card and dosage details. The following is the description of the package information item:

|Information item |Description |
|---|---|
|Package name |Current package version, team version or flagship version. |
|Deployment method |Current package type, SaaS. |
|Package Status |Whether the package is valid. |
|Expiration Time |Current package valid period. |
|Seat usage |Allocated seats/purchased seats, such as 6/10 seats. Seats remaining = purchased seats − allocated seats. |
|Usage details |Total consumption/total points, monthly basic total points and total points of the plus package.<br><br><br>* **Total Consumption/Total Points:**  The number of points consumed/the total amount of points. The total credit amount includes the plus package amount. If you have not purchased the plus package, the total credit amount = the monthly basic points of the package.<br><br>* **Monthly basic total points:**  The \*\*\*\* total monthly points amount of the package.<br><br>* **Plus package total points**: In addition to the basic package, the amount of points provided by purchasing the plus package. |

# Renewal subscription/additional seat purchase

When the package is about to expire and needs to extend the use period; or you need to open iDA for more members and the current remaining seats are insufficient, you can click the **Renew Now/Buy More Seats** button, the system will redirect to the next single page of the official website, where you can **Renew/Buy More**.

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1cdb4ea11ed44a308c00fa9571b9e174~tplv-goo7wpa0wc-image.image)

> **注意**

> **Renew subscription** related:

* > The renewal fee is only used to extend the valid period of the current package;

* > Renewal does not support modifying the number of seats, purchase time and other configurations of the current order;

* > If you need to reduce the number of seats, you need to wait for the current package to expire and make another purchase;

> **Additional seat purchase** related:

* > The additional purchased seats are used to increase the number of members within enterprises can use iDA.

* > The expiration time of the new seat is the same as the expiration time of the current package.

* > After the purchase is completed, seats need to be allocated to specific members, for details, please see [Invite members](https://docs.byteplus.com/docs/dataagent/member-management#e39bbae1).

# Buy a usage package

When the monthly fixed usage or the public resource pool is insufficient, a supplementary quota can be purchased. Click the Buy add\-on package button above the user details of the package management, and the system will redirect to the official website purchase page , where you can purchase the add\-on package operation.

> **说明**

> The additional package quota will enter the enterprise's public resource pool.
