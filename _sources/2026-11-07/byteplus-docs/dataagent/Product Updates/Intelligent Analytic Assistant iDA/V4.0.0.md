|---|---|---|---|
|Scheduled Task |New |**Added scheduled task management capabilities:** <br><br>It supports the manual creation of scheduled tasks in the iDA agent, and can configure the execution agent, task status, task name, user instruction, running cycle, expiration time, and Lark pushes to automate repetitive tasks such as daily newspaper generation, data query, and industry briefing. |Session flow |Optimize |**Optimize the iDA session flow exception handling experience** :<br><br>For branching scenarios such as session timeout, non\-user active interruption, concurrent/limited viewership of models, model exceptions, tool call failure, context overrun, etc., add more explicit error prompts and guidance actions; support single\-step retry of recoverable exceptions, and lead to open a new session after multiple retry failures, while optimizing the reset session logic, emptying the current session context and preserving the dataset configuration, to help users resume task execution more smoothly after abnormal interruptions. |\-\- |
||Optimize |**Optimize the iDA conversation flow link display experience:** <br><br>It supports the automatic identification and parsing of Lark documents, wikis, and ordinary HTTPS long links in user input or system output, and intelligently folds the original long URL into a rich text link card with type icon and title. It provides a downgrade display strategy for scenarios such as empty title, failed parsing, or no document permissions, and supports clicking the card to jump directly to the target document to improve the readability and access efficiency of conversation content. |\-\- |
||Optimize |**Optimize the iDA session flow exception branch handling experience:** <br><br>For abnormal scenarios such as session timeout, non\-user active interruption, concurrent/limited viewership of models, model abnormalities, tool call failure, context overrun, etc., differentiated error prompts and processing guidance are added; single\-step retry of recoverable exceptions is supported, and a new session is started after multiple retries fail. At the same time, the reset session logic is optimized, the current session context is cleared, and the dataset configuration is preserved, which helps users resume execution more smoothly after a task abnormality is interrupted. |\-\- |
|Model adaptation |Optimize |The image model is adapted to Doubao\-Seedream\-0_pro. |\-\- |
