# V4.2.0

Version number: V4.2.0

Version Adaptation Product: SaaS

Version release time: September 3, 2026


|**Product module** |**Update type** |**Update instructions** |**Product screenshot** |
|---|---|---|---|
|Memory management |New |**Added long\-term memory capacity:** <br><br>Supports users to view, turn on/off, and manually edit long\-term memory according to the Agent dimension in memory management, and can record long\-term valid information such as salutation preferences, reply styles, common terms, resource criteria, and execution guidelines; long\-term memory is turned on by default, and it will no longer take effect after closing and does not retroactively write to closed sessions. At the same time, it supports writing through explicit instructions, and verifies and handles repetitions, conflicts, or content overruns.<br><br>Operation Documentation: [Session Memory](https://docs.byteplus.com/docs/dataagent/Session_Memory_). |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/75085bfd39494349b448f9d970fef2ee~tplv-goo7wpa0wc-image.image) </span> |
|Skill Center |New |**Create skills through dialogue.** <br><br>iDA supports the creation of skills in natural language through "Skill Creation Skills". Users only need to describe the problem they want to solve, the applicable scenario, and the desired effect. The system can assist in sorting out the use purpose, use method, and delivery of skills. It also supports the creation of new skills, the optimization of existing skills, the conversion of existing workflows into skills, the reuse of the built\-in capabilities of the platform, and the automatic search for similar skills to avoid repeated construction. Finally, it generates a skill package that can be published or uploaded.<br><br>Operational Documentation: [Skill Center](https://docs.byteplus.com/docs/dataagent/Skill_Center). |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5b50203a27cd46aeb49c7f5c108c093c~tplv-goo7wpa0wc-image.image) </span> |
||Optimize |**Optimize upload skill creation:** <br><br>It supports setting skills as selected skills, and can be licensed to other agents simultaneously, improving configuration efficiency, distribution flexibility, and reuse scope of skills after uploading.<br><br>Operation Documentation: [Upload skill](https://docs.byteplus.com/docs/dataagent/Skill_Center#e2f12004). |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0eeb4aaa30c1412db706cbfcf56f4bc0~tplv-goo7wpa0wc-image.image) </span> |
||Optimize |**Optimize label management:** <br><br>Tag management is optimized for scene management. Users can mark skills according to the scene, and at the same time optimize the way of scene creation. Support entering the scene name in the search box and then press enter to add the scene successfully. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cbe90f6bbbae42e196b4997df0ee0faa~tplv-goo7wpa0wc-image.image) </span> |
|Skill Market |New |**iDA supports the centralized discovery, addition, and management of skills on the consumer side.** <br><br>Users can browse skills by All, Official, Featured, My, etc., and quickly retrieve them by name or scene; support adding skills as personal skills or configurations to managed agents, while providing skills download, conversation creation, uploading.zip/.skill to create skills; and in the conversation, through `⚡`or @ to call skills to help published skills from platform management into personal and agent use processes.<br><br>Operational Documentation: [Skill Market](https://docs.byteplus.com/docs/dataagent/Skill_Market). |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ddf55d1c5d1e4b108ae1342835a92d06~tplv-goo7wpa0wc-image.image) </span> |
|Connector |New |**Connectors \- Personal Knowledge Base:** <br><br>iDA supports entering the personal knowledge base in the connector, providing a private knowledge workspace of personal dimensions, supporting document upload, search, management, and intelligent Q&A; after activation, personal knowledge base retrieval can be started in agent conversation, and the system will automatically recall the personal knowledge content that the current account has access to in combination with semantic relevance, and use it as a basis for answering to improve the accuracy of personal data reuse and Q&A.<br><br>Operational Documentation: [Connect to Personal Knowledge Base](https://docs.byteplus.com/docs/dataagent/Connect_to_Personal_Knowledge_Base). |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9f11261e15024160ae172cc76929f9a5~tplv-goo7wpa0wc-image.image) </span> |
|Prompt word enhancement |New |**iDA provides prompt word enhancements in the dialog input box:** <br><br>After the user enters the first character, they can click the Enhance button to automatically expand the colloquial and vague requirements into a structured prompt, containing task objectives, input information, thinking steps, and output requirements, and supporting continued editing based on the enhancement results before initiating questions to help novice users lower the threshold for prompt writing, reduce multiple rounds of supplement description, and improve the quality of dialogue output. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/64f37d77500245f68e84dd6ca4fe3a00~tplv-goo7wpa0wc-image.image) </span> |
|Image generation |New |**Image generation provides a quick mode:** <br><br>iDA supports the selection of "standard" and "fast" generation modes in the "Creative Generation \- Image Generation" skill, and the standard mode is used by default; the fast mode corresponds to the fast ability of Seedream 5.0 Pro, which can reduce the waiting time of generating images under the specified image generation skill scenario and improve the efficiency of multi\-image generation and creative output. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/77816c83fdd24e97b3ac8a66152d1210~tplv-goo7wpa0wc-image.image) </span> |
||New |**Picture partial editing:** <br><br>iDA supports the selection of the area to be modified in the preview of the session image, and automatically backfills the selection number to the dialog box; users can enter the editing requirements for multiple selection areas and submit them uniformly. The system will combine the selection location, original image content, and natural language instructions to generate new image results. At the same time, try to keep the unselected area stable, and improve the efficiency of partial image modification, text correction, and multi\-regional fine editing. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/db78495e653941d78049d5d7f109d182~tplv-goo7wpa0wc-image.image) </span> |
|Support for A2A protocol |New |Since the V4.2.0 version, A2A development adaptation is supported. |\-\- |
|Session flow related removal |Offline |**Some functions of conversation flow are removed from the shelves:** <br><br>iDA removes session flow capabilities that are not suitable for the current scenario, including removing the "Global Data Asset Retrieval" entry in the session input and processing it by the backend according to the default retrieval logic, removing the "Reset Session" ability after the session; at the same time, it supplements the ability to synchronously copy uploaded local files when copying session flow, reducing the use interference caused by the difference in migration functions. |\-\- |
