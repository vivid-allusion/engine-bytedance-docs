|Web page generation |New |**Web page generation supports HTML download:** <br><br>The web page generation function adds the ability to download HTML products, allowing users to download the generated HTML files to local storage or use; at the same time, the version management interface adds a download button to support quick access to historical versions of HTML products. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/21979d472bd24f798948a14abb2a3c1d~tplv-goo7wpa0wc-image.image) </span> |
||New |**Web page generation supports partial editing and version rollback preview.** <br><br>Web page generation function adds local editing and version management capabilities. Users can select the partial content of the generated webpage in the session, adjust the selected area through session, and automatically record it as a new version after adjustment; at the same time, it supports quick rollback and preview of historical versions, making it easy to compare the page effects of different versions. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dd7da556e7a745c093fb7d2914ccc978~tplv-goo7wpa0wc-image.image) </span> |
|Scheduled Tasks \- Conversational Creation |New |**Conversational creation of scheduled tasks:** <br><br>iDA supports creating scheduled tasks through natural language in the main session window of the agent, the user only needs to describe the **execution time** and **execution instructions**, the system can automatically identify the task configuration and create the task; the task name can be automatically generated by the model, and the execution agent uses the current session agent by default. After the creation is successful, it will return to the task card, and supports viewing the task information and performing operations such as immediate execution, deactivation, deletion, and viewing details. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a48992c87fc74b768d8586cc861d3fab~tplv-goo7wpa0wc-image.image) </span> |
|Connector |WeCom \- New |**Added connector unified entrance to support WeCom authorization and access:** <br><br>Support users to bind WeCom accounts in iDA agents, and create intelligent robots by scanning the code to authorize; after the authorization is completed, you can chat alone or group chat with iDA in WeCom, and use open capabilities such as messages, documents, schedules, meetings, and to\-do within the scope of authorization. At the same time, it provides guidelines for handling common problems such as connector entrance, authorization process, usage method, and QR code expiration and authorization abnormality to help users access iDA capabilities in WeCom collaboration scenarios. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4b9779d4e8344525bc79c7e95419e6f9~tplv-goo7wpa0wc-image.image) </span> |
||DingTalk \- New |**Added connector unified entrance to support DingTalk authorization and access:** <br><br>Support users to bind DingTalk accounts in iDA agents and create OpenClaw DingTalk robots through the DingTalk authorization process; after authorization is completed, open capabilities such as DingTalk messages, documents, calendars, etc. can be invoked in iDA, and intelligent Q&A, content processing, and collaboration assistance can be completed in DingTalk work scenarios. At the same time, it provides guidelines for handling common problems such as connector entrance, robot creation, device authorization, usage method, authorization timeout, authorization abnormality, etc. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f0ab03bc23f34936a06dd49146f40c02~tplv-goo7wpa0wc-image.image) </span> |
|Agent Q&A \- Upload Local Files |Optimize |**Unlimited file upload types during conversation:** <br><br>The file upload function in the conversation has removed file type restrictions, allowing users to upload files of any format (such as code, logs, compressed packages, etc.), covering richer business scenarios. |<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ace777980a7943f9ada8c96ba62b2359~tplv-goo7wpa0wc-image.image) </span> |
