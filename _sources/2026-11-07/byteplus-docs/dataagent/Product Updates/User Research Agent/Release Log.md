# 2025\-10\-16 first release

<span id="8270fbb7"></span>
## AI Behavior Research


|**function module** |**Update description** |
|---|---|
|AI Behavior Research |The first release of AI behavioral research capabilities supports:<br><br><br>* User portrait analysis: Combined with behavioral requirements, conduct in\-depth analysis of user attributes/tags to unearth valuable clues from user characteristics.<br><br>* Behavioral flow log data enhancement: Semantic processing of collected behavioral log data to enhance the context of a single analysis.<br><br>* User in\-depth analysis: Conduct in\-depth analysis of data such as enhanced behavioral logs to mine behavioral laws and internal logic.<br><br>* Report follow\-up: Generate a research report based on the results of in\-depth analysis, and further explore the conclusions and data in the report through dialogue.<br><br><br>For more feature introductions and usage guidance on AI behavioral research, see [AI Behavior Research](https://docs.byteplus.com/docs/dataagent/AI_Behavior_Research). |
|general purpose |Based on Volcano Engine's growth analysis capabilities such as metadata management and AI capability configuration of DataFinder products, it provides analysis input for AI user research and analysis.<br><br><br>* Metadata management: Support collecting and managing user event tracking data (event and event attribute data) and user attribute data.<br><br>* AI capability configuration: Support uploading knowledge through pdf and other files, extract valuable knowledge from a large number of original data sources, documents or interaction processes, and provide support for the analysis of large models.<br><br>* Project management: Support switching between different project spaces and using event tracking data under different projects; for the time being, project management is only supported through DataFinder. |


<span id="e0ca0e1a"></span>
## AI virtual survey


|**function module** |**Update description** |
|---|---|
|general purpose |The first release of AI group research capabilities supports:<br><br><br>* Crowd management: Provide you with a virtual digital target group for generating target research, and you can select the corresponding target group in the interface.<br><br>* Questionnaire settings: support custom survey questionnaires; also provide the ability to save and reuse questionnaires.<br><br>* Simulation research: Support virtual digital human simulation to fill out questionnaires based on large models.<br><br>* Research details and report generation: Support to view the answer details of the survey questionnaire, provide a reference description of the conclusions of each research question, which can be further viewed retrospectively; at the same time, summarize and generate the final research report for you.<br><br><br>For more information on the function introduction and usage guide of AI virtual research, please see [AI Virtual Survey](https://docs.byteplus.com/docs/undefined/69f06a6ac9abae0523370c91). |
