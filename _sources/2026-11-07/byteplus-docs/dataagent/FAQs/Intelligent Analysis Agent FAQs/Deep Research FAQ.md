#### **Question: Will the configuration of Intelligent Query take effect during the process of generating a Deep Research report?** 

Answer: The configuration of Intelligent Query (semantic model, knowledge base, and global prompt) only takes effect during the data retrieval stage of the analysis report. It does not take effect in other stages, such as the reasoning process, planning, or report generation. The analysis template configuration of the Deep Research report also does not take effect in the Intelligent Query scenario.

<span id="add4a12f"></span>
#### **Question: What is the average time required for the 'Deep Research' function of the Intelligent Analysis Agent?** 

Answer: The 'Deep Research' function is implemented based on the deep reasoning capabilities of large models, which involves a relatively complex reasoning chain. If the data is complex, the overall process from the reasoning stage to the output of the analysis report may be lengthy, with an average duration of 15 minutes.
