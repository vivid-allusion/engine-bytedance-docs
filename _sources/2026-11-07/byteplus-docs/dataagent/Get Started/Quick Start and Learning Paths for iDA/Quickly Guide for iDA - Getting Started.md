After purchasing iDA, you will have access to a powerful data analytics partner. This product is designed to lower the threshold of data analytics, improve decision\-making efficiency, and complete complex data query and analysis tasks through natural language interaction. You can use official general\-purpose agents directly for problem consultation, or you can create custom agents to meet specific business needs. This article will give you a quick start on how to use iDA to complete typical analytical tasks.

<span id="22a99008"></span>
# Prerequisite

To use a general agent, the following conditions must be met:


* **Account and Permissions**: You need to have a valid account on the platform and have successfully [logged in to the system](https://console.byteplus.com/auth/signup?redirectURI=https%3A%2F%2Fwww.byteplus.com%2Fen&skipAccountProfile=true); please make sure your account has been granted permission to use the general iDA. If not, please contact your system admin, for details, see [Quick Guide for iDA - Getting Started with Administrators](https://docs.byteplus.com/docs/dataagent/Intelligent_Analysis_Agent_Administrator_Quick_Start_Guide).

* **Understand data**: Access relevant data or upload files and briefly explain the background or source of the core business data connected behind iDA.

1. Users can click the [BytePlus login page](https://console.byteplus.com/auth/signup?redirectURI=https%3A%2F%2Fwww.byteplus.com%2Fen&skipAccountProfile=true) to sign up or sign in.

   |Field |Fill in the instructions |

   |Main account username |Fill in the main account name or main account ID to identify the enterprise or main account to which the current sub\-user belongs. |

If you forget your password, you can handle it by **Forgot your password**; if you need to switch back to the administrator's main account login page, you can click **Back to root user sign in**.

# iDA Quick Start


1. After logging in, jump to the project page. You can click the New Project button on the right side, fill in the relevant information of the project and create a project. After the creation is completed, click the project name, and the system jumps to the iDA usage interface. For details of the use of the iDA interface, please view the [iDA Interface Introduction](https://docs.byteplus.com/docs/dataagent/iDA_Interface_Introduction).

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e578b23ef31e45fd95db441e60c97bc0~tplv-goo7wpa0wc-image.image) </span>

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b3cff394dafa4316bfff42833b5ab345~tplv-goo7wpa0wc-image.image) </span>

2. In the left navigation bar of the user interface, you can click the drop\-down menu to view all the agents that have permission to access and use under the current region. Click the agent name to enter the agent.

   * The top of the list is iDA.

   * The other agents below the list are your custom\-created agents. To create a custom agent, see the [Overview of Creation and Configuration Procedures](https://docs.byteplus.com/docs/dataagent/Overview_of_Creation_and_Configuration_Procedures).

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3db8775d36184fdeba3639183ac009d6~tplv-goo7wpa0wc-image.image) </span>

3. Use the Q&A service in the dialog box of the agent interface center, and click the Add button in the lower right corner to access resources or upload files. After the upload is complete, enter the task description in the dialog box. In addition to this, the following functions are also available:

   * **Select Skills**: Used to assign professional processing skills to tasks before Q&A. You can choose the appropriate module from the system preset skills to quickly initiate tasks such as data query, data analytics, chart generation, document creation and editing, reducing the cost of natural language description and improving the accuracy and efficiency of task execution.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e17361df35cd4f1c901d73e56ac995d6~tplv-goo7wpa0wc-image.image) </span>

   * **Turn on web search**: After turning on, the agent will actively retrieve the latest and most relevant information through the Internet when answering your question, and combine the retrieved information to generate an answer, rather than relying solely on its own knowledge base.

4. At the same time, it supports multiple types of product generation: web page generation, slide generation, image generation, data search, etc.; see the [Overview of iDA](https://docs.byteplus.com/docs/dataagent/Overview_of_iDA) for details.

5. After completing the above preparations, click the send button and wait for the agent to execute the task.

6. The execution time of the task will increase or decrease according to the complexity of the task, please be patient. After the task is completed, the general agent will return the execution result, and you can view the analysis result through the dialog box. There are two types of analysis results: **web version** and **document version**. You can view different types of analysis results by clicking the corresponding button type.

   
   |Analysis Report Action Items |Description |
   |---|---|
   |Copy |In the upper right corner of the report, copy of the analysis results is supported, and copy supports drop\-down selection. There are the following types of copy content:<br><br><br>* Report content: After drop\-down selection, you can copy the entire content of the report. The copied content is saved to the clipboard in **Markdown format**, which is easy to paste directly into the editor that supports Markdown.<br><br>* Report link: Copy an accessible link to the current analysis report, allowing others to directly open and view the report (with appropriate access permissions).<br><br>* Report ID: A unique identifier that replicates the report and can be used to quickly locate, correlate, or retrieve the analysis within the system. |
   |Export |The report supports exporting to different formats, including the following formats:<br><br><br>* Lark Documentation: Export analysis reports directly into Lark Documentation for online collaboration, commenting, and versioning within the Lark ecosystem.<br><br>* Word document: Export to standard Word (.docx) format for easy local secondary editing, typesetting, or printing.<br><br>* PDF documents: Export to PDF format, suitable for formal sharing, archiving, or printing, to maximize the consistency and immutability of the report format.<br><br>* Image: Export report results to image format (e.g. PNG/JPG) for quick sharing of visual report content in social media and chat windows.<br><br>* Original data source: export the original data source set on which the analysis report is based, which is convenient for secondary analysis, data verification or further processing. |
   |Share |Click the Share button in the upper right corner of the analysis results to support searching for authorized users and selecting the object to share. If you need to authorize multiple users, you can separate them with commas and paste them into the box, such as user1, user2. |

# General Scenario Agent Quick Start

A general scenario agent is a type of agent that you can create yourself, unlike an official iDA. This chapter will guide you on how to create and use a general\-purpose scene agent.

<span id="4c186a33"></span>
## Create an agent

You can create multiple general scenario agents/analytics agents in iDA according to your business data analytics needs.


1. Click the Manage Background button at the bottom left of the iDA page to return to the agent list page to create an agent.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0c4bd57f3e31461990be07269934d471~tplv-goo7wpa0wc-image.image) </span>

2. Create an agent. Go to iDA's agent list page and click the Create Agent button in the upper right corner.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f51dfe6444494bf3bc0ac2a5af3c68d5~tplv-goo7wpa0wc-image.image) </span>

3. Select type for the new agent: Analysis Agent(For legacy version, it is the custom agent.)/General\-Purpose Agent. For the differences between agent types, see [Agent Type Description](https://docs.byteplus.com/docs/dataagent/Agent_Type_Description).

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you have purchased both "Analysis Agent" and "iDA", please select the type as described above when creating the agent.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/338b55f9624e4ca286a3704c0a1b8006~tplv-goo7wpa0wc-image.image) </span>

4. After selecting the general scene agent, enter the agent configuration page to configure the basic information of the agent and other items.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e035b7b6c93b44a69e7d1b8965368958~tplv-goo7wpa0wc-image.image) </span>

   1. Enter the Data Assets module of the agent configuration and click the **Add Dataset button** on the right;

   2. Search for the dataset you need to add. This page supports selecting multiple datasets in batches.

   3. Click the **Next button** and **Confirm button** to add successfully, and you can continue to add or remove other datasets later.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Agent configuration also involves a number of detailed configurations, such as Content Configuration, Prompt configuration, Audit and Knowledge configuration. In actual use, you can configure it according to the scenario. This example is a simple demo for a quick experience, which skips the configuration instructions in other sections. If you want to see the full configuration documentation, see the <a href="https://docs.byteplus.com/docs/dataagent/Overview_of_Creation_and_Configuration_Procedures">Overview of Creation and Configuration Procedures</a>.</div>



5. Publish the agent. After configuring the agent, you need to click the Publish button in the upper right corner before the agent can appear in the list of published agents and be used.


After publishing, users with agent permissions can click on the agent in the published agent list to enter the page, and the authorized agent can be found in the agent list dropdown on the left.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/06afe743ae9746dc9029be6b6385d451~tplv-goo7wpa0wc-image.image) </span>

## Use a general scenario agent


1. After the authorization is completed by the main account, the sub\-account can log in to the agent with the account password, and click "Agent" to enter the agent list page.

2. Click on the published agent to enter the conversation page to use it.

3. Enter the agent dialogue interface, choose to upload local files/access resources and ask questions, or you can directly enter questions to ask questions. At the same time, it supports the use of official pre\-made skills or self\-created skills for questioning and use. To create skills, see the [Skill Center](https://docs.byteplus.com/docs/dataagent/Skill_Center).
