The user research agent provides you with a demo project of trial experience. This article uses a specific example to demonstrate how to quickly experience the main operation process and functional capabilities of the user research agent.

<span id="9c5025bd"></span>
# Prerequisites and preparations


* User Research Agent has pre\-set some experience demos for you, you can experience the results of virtual research without any configuration operations, and be familiar with the running process of virtual research.

* If you want to try out the function of AI virtual research based on your own business data, before using AI virtual research, you need to contact the Volcano Engine technical support staff to prepare a virtual digital target group for you. After completing the preparation of the target group, you can view the corresponding target group on the "Crowd Management" page of the AI virtual research page, and perform functional experience based on the target group.
