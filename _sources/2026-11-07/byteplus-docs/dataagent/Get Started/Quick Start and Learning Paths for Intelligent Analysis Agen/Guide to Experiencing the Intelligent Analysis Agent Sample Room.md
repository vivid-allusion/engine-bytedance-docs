# Feature demonstration

The Intelligent Analysis Agent includes two core capabilities: intelligent data query and in\-depth research. In this experience, you will discover the precise querying and visual presentation of intelligent data query, as well as the ability of in\-depth research to generate professional reports, experiencing the efficiency and convenience of AI\-driven data value realization.

<span id="e7b9e1b3"></span>
## Intelligent data query

Intelligent data query is the data query module of the Intelligent Analysis Agent. It can accurately interpret user intent through natural language conversation, enabling collaborative queries across multiple datasets and in\-depth attribution analysis, supplemented by personalized recommendations and multi\-turn interactions, providing users with efficient, precise, and unified data query services.

<span id="1fa2be1b"></span>
## In\-depth research

In\-depth research is the in\-depth research module of the Intelligent Analysis Agent. It can automatically interpret natural language requirements, build a complete analysis framework, generate SQL and Python code to achieve data insights, and output in\-depth research reports to support efficient enterprise decision\-making.

### Experience in\-depth research

The deep research functionality of the Intelligent Analysis Agent can automatically parse natural language requirements, build a complete analysis framework, generate SQL and Python code to gain data insights, and output deep research reports to help enterprises make efficient decisions.

**Operation steps**:


1. Click the **New conversation** button in the upper left corner to start a new conversation and experience the deep research functionality in the new conversation.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/945f44b89b0f45d7b326272f6e34b867~tplv-goo7wpa0wc-image.image) </span>


2. In the new dialog box, click the mode switch button, select **Deep research**, and experience deep data analysis and the process of generating research reports.

3. In the recommended questions area below, hover the mouse over a recommended question, click the **Copy** button, and the question will be automatically filled into the input box. Click **Send** to start the Q&A. For example, copy "Generate the 2024 Double Eleven Peak Gala event analysis report", click **Send** to start the Q&A.

   Deep research supports the **Web search** functionality. To perform deep analysis of data combined with real\-time network information, enable the **Web search** here. For example, you can enter "Conduct a comparative analysis of the '25 Goddess Festival Pampering Gift' and '24 Sweet Confession Season' events, and analyze the possible reasons for the inconsistent results of the two events based on web information." The intelligent agent will provide a detailed comparative analysis report based on activity\-related information retrieved from the internet.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6fd9f3712ea84d718373ec7877ea97d3~tplv-goo7wpa0wc-image.image) </span>

## Product overview

<span id="d2aa26af"></span>
#### Question: What configurations does the Intelligent Analysis Agent support? How to build an agent?

Answer: The Intelligent Analysis Agent supports custom configuration items such as basic information, dataset configuration, content configuration, Prompt configuration, and knowledge model configuration, enabling adaptation to diverse business scenarios. For those who have never learned about agents and their configuration process, it may take 2–5 days; for those who are already familiar, it may take 1–2 days. The overall workload for building an agent also depends on how well your data is prepared.

The overall process for building and configuring an agent is as follows:


1. **Prerequisites**: Complete project creation, user authorization, and data preparation.

2. **Create an agent**: On the configuration page, click “Create Agent”, configure basic information such as application name, description, and administrator, then save. You can view it on the pending release page.

3. **Configure the agent**:

   * **Basic information**: Edit the application name, description, administrator, and avatar, and manage the PC client member list.

   * **Dataset configuration**: Add authorized datasets to the agent, configure semantic models, knowledge bases, and filter criteria.

   * **Content configuration**: Configure data retrieval recommended questions (choose unified or differentiated configuration methods), analysis recommended questions, and the summary card on the PC client homepage.

   * **Prompt configuration**: Add hint or requirement type prompts to ensure the agent's responses meet user requirements.

   * **Knowledge configuration**: Supports uploading private enterprise documents. Through intelligent matching and structured extraction, internal knowledge is accurately injected into the analysis process.

4. **Release and management**: Agents can be published, modified, taken offline, or deleted.

#### **Question: What is the average duration of the "Deep Research" feature of the Intelligent Analysis Agent?** 

Answer: The "Deep Research" feature is implemented based on the deep reasoning capabilities of large models, resulting in a relatively complex reasoning chain. You can open multiple pages to conduct Q&A simultaneously, allowing you to access the analysis report earlier.

<span id="14916429"></span>
#### **Question: Does the "Deep Research" feature of the Intelligent Analysis Agent support custom configuration of the analysis approach for deep research reports?** 

**Answer:**  Customization of the analysis approach is supported by uploading your own domain\-specific knowledge. Under the current technical architecture, the large model dynamically plans the analysis approach for each session, so customization of the overall framework is supported. When executing specific analysis actions, the model will still define some dynamic reporting approaches based on the business scenario. The model does not strictly define every detail of the analysis report.
