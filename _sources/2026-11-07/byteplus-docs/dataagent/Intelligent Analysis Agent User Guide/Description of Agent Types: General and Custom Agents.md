After purchasing and activating the Intelligent Analysis Agent, the Intelligent Analysis Agent currently provides you with a general agent (default name: Data Agent). You can directly use the preconfigured general agent to consult on issues; you can also create and configure custom agents yourself. This article provides a brief introduction to the similarities and differences between general agents and custom agents.

<span id="4912af8e"></span>
# Comparison overview


|Detailed comparison items |General agent |Custom agent |
|---|---|---|
|Interface display |* After entering the Intelligent Analysis Agent console page, you can see all agents that you have permission to access and use in the current region in the left navigation bar of the agent usage page.<br><br><br><span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5192043b01104e18bec03c7e24cc8bdd~tplv-goo7wpa0wc-image.image) </span><br><br><br>* The Data Agent at the top of the list is the general agent.<br><br>* The other agents listed below are the custom agents you have created.<br><br>* On the agent configuration backend page, you can also check whether the corresponding agent is a general agent in the agent list page; general agents are marked with "General" after their name.<br><br><br><span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3194d72462544a6b915f9222fc66130d~tplv-goo7wpa0wc-image.image) </span> ||
|Visible personnel scope |All project members can view and use them. |When creating a custom agent, you can select agent members. You must have at least the role permissions assigned to agent members to view and use the corresponding custom agent. |
