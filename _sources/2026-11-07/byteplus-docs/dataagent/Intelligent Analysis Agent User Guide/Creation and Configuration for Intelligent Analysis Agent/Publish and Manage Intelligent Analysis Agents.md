After completing the creation and configuration of an Agent, you need to publish it online before you can further test or use it. This article introduces the key points for publishing and managing Agents.

<span id="5e55e479"></span>
# Publish and take Agents offline


* Publish Agents: Agents that have not been published cannot be used directly.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/719ef3aac7134172948e774af10d3d68~tplv-goo7wpa0wc-image.image) </span>

* Take Agents offline: After an Agent is published, if it is no longer needed, you can take it offline.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f87e3fbad9434848b50ba76f36404cda~tplv-goo7wpa0wc-image.image) </span>

# Edit and manage Agents


* Modify existing Agent configuration

   * The user can select an Agent from the Agent list and click "Agent configuration" to enter the configuration page.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3630255d81fd43768f3b7ec8e37547d2~tplv-goo7wpa0wc-image.image) </span>

   * The user can also click "Settings" in the function bar on the left side of the Agent conversation page to enter the configuration page for that Agent.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c0bcb01aecb8467988a16f5407ee740f~tplv-goo7wpa0wc-image.image) </span>
