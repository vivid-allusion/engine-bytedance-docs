# 1. Overview

Machine learning refers to visual modeling that supports machine learning operators for processing data, enabling users to perform model training, in\-depth analysis, predictive analysis, and more based on the data. This document introduces the functions of machine learning operators.

# 2. Introduction to functions

<span id="_2-1-预测"></span>
## 2.1 Prediction

The model generated by training the machine learning operator is applied to the data to be predicted, typically linked after the machine learning operator.

**Field settings**

Feature column mapping: Set the mapping relationship between feature columns in the model and feature columns in the data.

Label column: The label column, which serves as the basis for classification training.

**Parameter settings**

Prediction column name: The name of the column to be predicted.

<span id="_2-2-one-hot-模型应用"></span>
## 2.2 One\-hot model application

The one\-hot model application operator is linked after the one\-hot encoding operator. The one\-hot operator not only supports representing string\-type columns as arrays, but also supports saving the conversion process as a model. Combined with the one\-hot model application operator, similar columns can be encoded and converted again.

**Feature column mapping:**  Set the mapping relationship between feature columns in the model and feature columns in the data.

<span id="_2-3-分类"></span>
## 2.3 Classification

The following models are supported. For details, refer to the functions page.


|Model name |Model overview |
|---|---|
|Logistic regression |Logistic regression is a classic statistical learning classification model. It adds a nonlinear function mapping to the linear regression mapping: first, the features of the sample are linearly summed, then the logistic function is used to map the value to between 0 and 1, representing the probability that the sample belongs to each class. The class with the highest probability is taken as the final predicted class for the sample. This operator supports binary and multi\-class classification problems, and supports both continuous and categorical features. However, after string indexing of categorical features, one\-hot encoding is required. |
|Xgboost |Number of boosting rounds: The number of boosting iterations during training.<br><br>Use the best model: Selects the best model based on the evaluation metric chosen for the optimal model.<br><br>Label index sorting method: 'frequency' means sorting by frequency, and 'alphabet' means sorting by string comparison. |
|Catboost |A GBDT framework based on the oblivious trees algorithm, featuring a small number of parameters, support for categorical variables, and high accuracy. It primarily addresses the challenge of efficiently and reasonably handling categorical features. CatBoost is derived from 'categorical' and 'boost'. Additionally, it addresses issues such as gradient bias and prediction shift, improving the algorithm's accuracy and generalization capability. CatBoost has the following five main features: 1. High model quality can be achieved without parameter tuning; excellent results can be obtained using default parameters, reducing the time spent on tuning. 2. Supports categorical variables, with no need to preprocess non\-numeric features. 3. Fast and scalable GPU version, allowing you to train your model using a GPU\-based gradient boosting algorithm, with support for multi\-GPU parallelism. 4. Improved accuracy, introducing a new gradient boosting mechanism to build models and reduce overfitting. 5. Fast prediction, enabling rapid and efficient model deployment even for latency\-critical tasks. |
|Naive Bayes |Naive Bayes is a classification method based on Bayes' theorem and the assumption of conditional independence of features. Naive Bayes classifiers are easy to construct and suitable for large datasets, but their drawback is the need to make assumptions about the prior distribution. This operator supports binary and multi\-class classification problems, and supports categorical and non\-negative continuous features. However, categorical features require prior string indexing. |
|Support vector machines |are statistical learning classification models. Their basic idea is to find a separating hyperplane that can correctly classify the training dataset and maximize the geometric margin. |
|Multilayer perceptrons |They simulate biological neural networks and are a type of pattern matching algorithm. Each layer consists of a linear transformation followed by a sigmoid activation function, and the output layer applies a softmax transformation. This operator supports binary and multi\-class classification problems, and supports categorical and continuous features. However, categorical features require prior string indexing. |
|Decision trees |are one of the commonly used classification algorithms and often perform well in exploratory knowledge discovery. The principle of decision trees is very simple. They can handle high\-dimensional data and do not require prior knowledge of the model's features. These characteristics make decision trees widely used. Decision trees use a greedy algorithm, and their construction also requires training data. The core issues of decision trees are determining the branching criteria and the splitting points. |
|Random forests |In machine learning, random forest is a classifier consisting of multiple decision trees, and the output class is determined by the mode of the classes output by individual trees. In random forests, the training data for each tree is sampled with replacement from the original training dataset. Additionally, a random subset of all features is selected, and the optimal feature for splitting is chosen from this subset, rather than always selecting the globally optimal splitting point. This helps prevent individual decision trees from overfitting. |
|Gradient boosting tree |The gradient boosting tree is an ensemble learning model, where the internal models use decision trees. Unlike random forest, it trains only one tree at a time, and each new decision tree gradually corrects the errors made by the previous decision trees. As more trees are added, the model's expressive power becomes stronger. |


<span id="_2-4-聚类"></span>
## 2.4 Clustering

The following models are supported. For details, refer to the functions page.


|Model name |Model overview |
|---|---|
|K\-means clustering |The K\-means algorithm is a typical distance\-based clustering algorithm, using distance as the similarity evaluation metric. After specifying K initial cluster centers (initial cluster mean centers), the distance between each sample and the K cluster mean centers is calculated. Each sample is assigned to the cluster whose mean center is closest to it. After each assignment, the cluster mean centers are updated, and the distances between all samples and the cluster mean centers are recalculated. This process repeats until all given samples are clustered into K clusters and the cluster mean centers no longer change. |
|Gaussian mixture |The Gaussian mixture clustering algorithm uses the Gaussian probability density function (normal distribution curve) to accurately quantify data, and can cluster sample points into several clusters formed based on the Gaussian probability density function (normal distribution curve). Theoretically, it can fit any continuous function, but its drawback is a relatively high computational cost. |
|Bisecting K\-means |The bisecting K\-means clustering algorithm is a variant of the K\-means clustering algorithm, primarily designed to address the issue of uncertainty in clustering results caused by the randomness of selecting initial centroids in the K\-means algorithm. The bisecting K\-means algorithm is less affected by the randomness of initial centroid selection. |


<span id="_2-5-回归"></span>
## 2.5 Regression

The following models are supported. For details, refer to the functions page.


|Model name |Model overview |
|---|---|
|Linear regression |Linear regression is a type of regression analysis that models the relationship between one or more independent variables and a dependent variable using the least squares function of the linear regression equation. As shown in the figure below, the top section displays the basic principle formula, which is the linear sum of all features. |
|Decision tree regression |Decision trees can be used for predicting continuous values and often perform well in exploratory knowledge discovery. The principle of decision trees is very simple. They can handle high\-dimensional data and do not require prior knowledge of the model's features, making decision trees widely used. Decision trees use a greedy algorithm, and their construction also requires training data. The core issues of decision trees are determining the branching criteria and the split points. |
|Random forest regression |Random forest is an ensemble model, where the internal models use decision trees and random attribute selection is introduced during training. Specifically, traditional decision trees select the optimal attribute for splitting from the attribute set at the current node (assuming there are d attributes); in random forests, for each node of the base decision tree, a subset containing k attributes is randomly selected from the node's attribute set, and then the optimal attribute for splitting is chosen from this subset. This operator supports continuous labels, as well as continuous features and categorical features. |
|Gradient boosting tree regression |An ensemble model in which the base models use decision trees. Unlike random forests, it trains only one tree at a time, and each new decision tree gradually corrects the errors made by previous decision trees. As more trees are added, the model's expressive power increases. |
|Isotonic regression |Isotonic regression is a type of regression algorithm. Isotonic regression is defined as follows: Given a finite set of real numbers Y = {y_1, y_2, ..., y_n}, where Y represents known observed data, and X = {x_1, x_2, ..., x_n} represents unknown values, the goal is to find the minimum value of the function f(x) = sum_{i=1}^n w_i(y_i \- x_i)^2, while ensuring that x_1, ..., x_n are in increasing order. |


<span id="_2-6-时间序列"></span>
## 2.6 Time series

**ARIMA model**

The data sequence formed by the prediction target over time is regarded as a random sequence, which is approximated using a mathematical model. Once this model is identified, it can predict future values based on past and present values of the time series. This can help enterprises forecast the future and guide their next decisions. Application scenarios: stock market rise and fall prediction and analysis, supermarket market turnover prediction and analysis, housing price rise and fall prediction and analysis, employee turnover prediction and analysis, product sales volume prediction and analysis, weather condition prediction and analysis, and many other scenarios.

<span id="_2-7-评估"></span>
## 2.7 Evaluation

The following evaluation models are supported. For details, refer to the feature page.


|Model name |Model overview |
|---|---|
|Binary classification evaluation |This performance evaluation operator should be used for classification tasks, that is, when the label attribute has a binary value type. The input of this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance metric values based on these two attributes. |
|Multiclass evaluation |This performance evaluation operator should be used for classification tasks, that is, when the label attribute has a categorical value type. The input of this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance metric values based on these two attributes. |
|Clustering evaluation |This performance evaluation operator is used to evaluate the performance of clustering models. This operator expects as input a test sample set, which contains a column with the prediction role and all feature columns. |
|Regression evaluation |This performance evaluation operator should be used for classification tasks, that is, when the label attribute has a numeric value type. The input of this operator is a test sample set, which contains an attribute with the label role and an attribute with the prediction role. This operator calculates and outputs a performance vector containing performance metric values based on these two attributes. |
