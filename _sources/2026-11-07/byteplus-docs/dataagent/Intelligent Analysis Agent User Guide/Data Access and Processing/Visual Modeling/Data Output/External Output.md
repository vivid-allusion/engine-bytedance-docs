<span id="_1-产品概述"></span>
# 1. Product overview

Visualization modeling offers external output capabilities, allowing offline tables generated by intelligent data insights to be sent back to native systems for further data production and mining, enabling more flexible data output and application. Currently supported external storage: MaxCompute, OceanBase Oracle, Mysql, LAS (public cloud), Transwarp Inceptor, Oracle, BytehouseCE.

<span id="_2-使用条件"></span>
# 2. Usage conditions

This feature is an add\-on for the private deployment version and requires a paid purchase. To use this feature, please contact your account manager. After purchase, users must have **Project Center \- Data Preparation \- Visualization Modeling \- Create Task** permissions, and the customer side must allow table creation and data writing.

<span id="_3-3-操作步骤"></span>
## 3.3 Operation steps

(1) Click **Data Preparation \> Data Connection**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b9656a5ed4ef44509dc16dd9163db39c~tplv-goo7wpa0wc-image.image) </span>

(2) In the upper left corner of the data connection directory, click the **Create Data Connection** button. Using MaxCompute as an example, select the **Data Warehouse \- MaxCompute** data connection.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9d99af3ef23f47dd84ee5e1d85f87437~tplv-goo7wpa0wc-image.image) </span>

(3) On the edit page, fill in the corresponding server and key information, enable **Write** permission in the permission mode, and after successfully testing the connection, click **Save**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/baa397af928f4d89acf0def14c6aa610~tplv-goo7wpa0wc-image.image) </span>

(4) Click **Visualization Modeling \- Create Task**.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/864d0ec99a4d46eeb2929c1afac40e3d~tplv-goo7wpa0wc-image.image) </span>

(5) On the task edit page, you can freely perform data cleaning and processing. After completion, add the **External Output** operator.

(6) The process for creating and viewing tables has been simplified, supporting direct display of relevant content in the toolbar to improve your operational efficiency.


* Create a new output table and fill in the relevant information.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c03d1aaba8134525ab69c6738757d326~tplv-goo7wpa0wc-image.image) </span>


* View the output table directly in the toolbar, and preview the table structure if needed.
