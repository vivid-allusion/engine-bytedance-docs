# 1. Dataset overview

A dataset serves as the foundation for storing and managing data, as well as for visualized querying and analysis. In simple terms, you can think of it as a type of data table. Users must create datasets from the source tables they wish to analyze before proceeding with subsequent modeling and other operations. In the dataset module, you can create, edit, query, and manage datasets.

<span id="_2-使用场景"></span>
# 2. Usage scenarios

After completing [Overview of Data Connection](https://docs.byteplus.com/docs/dataagent/Overview_of_Data_Connection), users can create datasets. The system supports creating datasets directly from the original table, generating datasets through multi\-table join/union, or generating datasets using custom SQL.

|**Serial number** |**Module name** |**Meaning** |
|---|---|---|

|Module 2 |[Overview of Dataset Management](https://docs.byteplus.com/docs/dataagent/Overview_of_Dataset_Management) |This is the details page for a single dataset, where you can view detailed configuration information, including basic dataset information, detailed data, table structure, synchronization status, and model information. Users can manage datasets here. |
|Module 3 |[Dataset List Overview](https://docs.byteplus.com/docs/dataagent/Dataset_List_Overview) |This is the dataset list, which includes Overview, List, and Recycle Bin. Users can manage the dataset list here. |
