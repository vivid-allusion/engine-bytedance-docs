<span id="_1-概述"></span>
# 1. Overview

The dataset module supports modifying dataset\-related configurations. Upstream tables support adding new fields, modifying the data types of existing fields, or deleting fields. In the data preview interface, model fields can be quickly modified. Modifying models is also supported.

<span id="_2-功能介绍"></span>
# 2. Feature overview

<span id="_2-1-上游表新增-修改-删除字段"></span>
## 2.1 Add, modify, or delete fields in upstream tables

If "Auto refresh fields" is not enabled, fields must be added manually. See below for details:

For example: Add a field xx to a MySQL table. On the preview page, click "Edit" to enter model editing. Click the capsule\-shaped button in "Model configuration"; a new gray, unchecked field will appear in the model list. Select to retain it to add the field.

For example: Modify the data type of an existing field in a MySQL table. On the preview page, click "Edit" to enter model editing. After confirming the data type change, simply save. The historical data corresponding to the original field type will be deleted.

After modification, previously synchronized data content will not be changed. To update it, please resynchronize.

<span id="_2-3-修改模型"></span>
## 2.3 Modify models

Click the "Edit" button to enter the global editing page, where model adjustments can be made.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9881d051a1fe4963a4090d3f9d0465b1~tplv-goo7wpa0wc-image.image) </span>

When modifying models, replacing the underlying data table is supported. Modifying primary keys, sharding, partitioning, or sampling fields is not supported. To modify the above items, create a new dataset.

<span id="模型配置替换底表"></span>
### Replace the underlying table in model configuration

The product supports editing datasets and replacing the underlying table on the model configuration page. Currently, replacing the underlying table for directly connected datasets is not supported.

Right\-click the data table card, click the "Replace" button, and drag a data table from the left onto the card to complete the replacement.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1216282267cb4d6d953bbcbdb8b8a42e~tplv-goo7wpa0wc-image.image) </span>

Note the following when using this feature:


* Fields with the same name in the new and original tables will directly replace the model fields, without affecting dataset fields. After saving, visual queries will not be affected.

* Fields present in the new table but not in the original table can be added to the model fields, and by default, will be added to the dataset fields.

* For fields present in the original table but not in the new table, please delete the corresponding fields on the field configuration page. If you save while retaining only fields that exist in the original table, the system will prompt that the corresponding fields cannot be found. If you confirm the replacement, the corresponding fields in the original dataset will be permanently deleted.

* Replacing the data table does not affect historical data. To import the replaced data table into the system, historical data for previous dates must be resynchronized.


<span id="_2-4-自定义-sql-修改"></span>
## 2.4 Custom SQL modification

Charts generated by routine SQL queries can be modified.

Click "Edit" to enter the modification interface, then click the "Edit" button in the interface to modify SQL.

<span id="_2-5-调整生命周期"></span>
## 2.5 Adjust lifecycle

Click synchronization status to view the current dataset's lifecycle. Lifecycle: The retention period for data synchronized in the dataset. If the lifecycle is 3 days, partitioned data generated on January 25 will be cleared on January 28. If the data is synchronized daily, only data synchronized within the past three days can be queried.

Click the pencil\-shaped edit button and confirm the changes.

<span id="_2-7-同步类型和-sla-更改"></span>
## 2.7 Synchronization type and SLA changes

Click synchronization status to view the current dataset's synchronization type. Synchronization types: Automatic synchronization—automatically synchronizes daily during system off\-peak hours, aiming to complete synchronization before the SLA; Scheduled synchronization—includes synchronization at hourly, daily, weekly, or monthly intervals; Paused synchronization—the dataset will no longer synchronize automatically.

Click the pencil\-shaped edit button and confirm the changes. If the data source used by the dataset is a hive table, the user editing the dataset must also have permission to view the hive table in order to successfully edit.
