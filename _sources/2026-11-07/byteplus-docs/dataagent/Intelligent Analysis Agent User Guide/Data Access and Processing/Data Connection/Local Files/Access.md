This article describes how to upload Access files as data sources to create datasets.

<span id="cc593194"></span>
# Precautions


* Uploading local Access database files (.mdb, .accdb) is supported, with a maximum file size of 4 GB.


<span id="3ddba999"></span>
# Create from data connection


1. Log in to BytePlus, navigate to a specific project, click Data Preparation, find Data Connection in the dropdown list, and click Data Connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b9656a5ed4ef44509dc16dd9163db39c~tplv-goo7wpa0wc-image.image) </span>

2. Select Access on the page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/eec5a7a442704d5db3963022d0e3bb36~tplv-goo7wpa0wc-image.image) </span>

3. After uploading the file, enter the basic information.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">Uploading local Access database files (.mdb, .accdb) is supported, with a maximum file size of 4 GB.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/35240c4b5c39434c9219574e78446584~tplv-goo7wpa0wc-image.image) </span>

4. Select a table and click "Next".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ea4c9c6a40994cb8b83cecae543cdb1e~tplv-goo7wpa0wc-image.image) </span>

5. After confirming that the preview content is correct, click Finish.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/cada95a2440f4439acea5ec5dd9f0d2d~tplv-goo7wpa0wc-image.image) </span>


<span id="15657f64"></span>
# Create from dataset


1. Log in to BytePlus, click "Data Preparation" \- "Dataset", select the "Create" button in the upper left corner to create a new dataset.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d809056a035b431d8ca2f4c530554168~tplv-goo7wpa0wc-image.image) </span>

2. When selecting a data connection, click Create Configuration.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d38dd103d6d74e6590548b560ce92631~tplv-goo7wpa0wc-image.image) </span>

3. The subsequent steps are the same as steps 2 and 3 in **Create from data connection**. After completing the configuration, you will remain in the pop\-up window for selecting a data connection for the dataset, and you can proceed directly to the next step to create the dataset.

## Update Access file


1. Go to the "Data Connection" page, select the Access data source, and click "Update File".

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b6b44ee8b68644339cac6a2425057894~tplv-goo7wpa0wc-image.image) </span>

2. Upload a new Access file.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2633a14c0d9549daba6b428f8f194c99~tplv-goo7wpa0wc-image.image) </span>

3. Select a table to preview and complete the update.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/35cf620270e741748051cc4c02fd41d8~tplv-goo7wpa0wc-image.image) </span>
