To perform data analysis for routine business scenarios, such as daily, weekly, or monthly reports, and to automatically generate stable and reliable analysis reports based on existing datasets or dashboard charts using large models, use the insight report feature provided by the Intelligent Analysis Agent. This article provides an overview of the insight report features and key operational points.

<span id="87407237"></span>
# Feature overview

The insight report of the Intelligent Analysis Agent supports building report frameworks suitable for business analysis scenarios by flexibly combining content elements via drag\-and\-drop, including existing datasets, charts, knowledge, and analysis conclusions. The current version mainly supports building insight report templates based on three main content modules: text block, AI analysis, and AI summary.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d5f375c44ad941a3a8d326fe883944bd~tplv-goo7wpa0wc-image.image) </span>


* **Text block:**  Supports rich text editing and is used for writing fixed content such as analysis background, conclusion summary, and data scope descriptions.

* **AI analysis:**  The core analysis unit of the report. A data source (dataset or chart) must be bound and an analysis instruction entered. The large model then outputs specific analysis conclusions and insights.

* **AI summary:**  Based on natural language instructions, further summarizes, refines, or compares the content generated by the AI analysis module to form the final conclusion.

# Caution and prerequisites


* To use the insight report feature, which is supported starting from version 3.4.0 (currently in grayscale testing) and is disabled by default, contact Volcano Engine technical support to enable it.

* Before using the insight report feature, you must first create and configure a **custom agent**. The custom agent is the execution entity for the insight report capability. You need to configure it with, but not limited to, basic information (name, description), **associated data source** (providing analysis data for the insight report), and more.

## Practical experience


|Breakdown |Practical experience recommendations |
|---|---|
|Module planning |* It is recommended to split the analysis report into as many analysis modules as possible. The clearer the split, the more stable the quality of the content generation results for each module. |
|Data sources |* When building report templates, use charts as much as possible instead of datasets, because charts provide more stable data compared to retrieving N fields from a dataset. |
|Prompt words |* It is recommended to write prompt words directly in a markdown editor and then copy them into the analysis module, which helps the AI model understand the framework requirements for report content generation.<br><br>* To use the insight report feature after previously using the in\-depth research functionality of the Intelligent Analysis Agent, you can directly reuse the template from prior in\-depth research when writing prompts and modify it based on the template.<br><br>* Whenever possible, write prompts for the analysis approach in the user input box rather than using the knowledge base. |
|Tools |* Each analysis module can select designated tools, such as Python. |

# Advanced features

<span id="b911ec7c"></span>
## Set reference results

The insight report provides the "Set reference results" feature. When editing the insight report template and testing the report generation results, if the quality of the report content is good, you can set the current analysis template configuration as a reference sample. For subsequent report generations, the analysis approach and content structure of the reference sample will be used to generate report results, which can improve the quality of the generated analysis report content.


|Set high\-quality results as reference results in edit mode |View or delete reference details in subsequent report generation results |
|---|---|
|* In edit mode, click the upper right corner to set as "Reference result."<br><br>* After setting, the interface displays "Set as reference result." |* After setting the reference result, subsequent report generation results will indicate that the previously set sample result has been referenced.<br><br>* To stop referencing the set sample result, click "Modify AI instruction" in the report generation results and deselect "Reference result" at the bottom of the analysis description box. |

## Reference DataWind charts

When building the insight report template, it is recommended to use DataWind charts as much as possible instead of datasets, because charts provide more stable data than retrieving multiple fields from a dataset. You can choose to integrate charts when configuring the AI analysis module.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b119780b620b4a6cb3d2e5145277f338~tplv-goo7wpa0wc-image.image) </span>


* The range of charts supported for integration includes DataWind visualization query results and dashboard charts.

* After charts are integrated, the large model will determine whether to directly reference the integrated DataWind visualization charts based on the prompts for the analysis task.

   * In the analysis task prompt input box, you can explicitly require certain charts to be included, which increases the likelihood that the corresponding charts will be displayed in the generated report results.

   * For example, the prompt may include: The report must contain "chart name".

* When directly displaying the referenced chart, only the chart content itself is shown, excluding the chart title and other additional information.

* Caution:

   * To flexibly modify the filter values for DataWind visualization charts when querying your report, you need to use the report variable feature and configure variables to associate with the visualization chart filters. For details, see the **Configure and use report variables** section below.

   * If the visualization chart filters are not associated through variables, then when generating report content by referencing charts, the data source will directly use the data filtered by the default filter values of the visualization chart.

## Configure and use report variables

Reports support global variables. If you have text or numeric variables that may need to be adjusted in different periods or scenarios, you can use the global variable feature.

<span id="5f5ad662"></span>
### Add variables


1. Add variables. You can click the "{n} variables" button at the top of the Insight report configuration page to add global variables.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d4dc4b08fdd74574b3bc4d90c7ffb6da~tplv-goo7wpa0wc-image.image) </span>

Currently, text, date, and numeric variables are supported. For date variables, you can flexibly set dynamic dates (day/week/month time granularity) or fixed date values.

1. Preparation.

   1. In DataWind, configure the DataWind visualization chart filters and select "Auto Query".


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/270f8818c88c4b31bb56a6693e58ca3c~tplv-goo7wpa0wc-image.image) </span>


2. Add referenced DataWind charts in the Intelligent Analysis Agent.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7de13d899abd408694e9a85010d953c2~tplv-goo7wpa0wc-image.image) </span>


2. Configure the association between insight report variables and DataWind visualization chart filters.


<div style="text-align: center">
<img src="https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/184fb4db57df4084bb2626c181840503~tplv-goo7wpa0wc-image.image" width="610px" /></div>


Configure the association between variables and visualization chart filters on the pop\-up page. Each variable can be bound to multiple modules and charts, but the variable type (such as **text, date, numeric**) must match the associated filter type.

\* If the variable type is text, the bound chart filter type must be text.

\* If the variable type is numeric, the bound chart filter type must be numeric.

3. After completing the above configuration, see the following section on referencing variables. When generating an insight report, the referenced visualization chart filter values can be automatically replaced with variable values, and the visualization chart filtered by variable values will serve as the data source for the analysis report.

# Frequently asked questions

<span id="90b991d8"></span>
## Q1. What is the difference between an insight report and an in\-depth study?


|Comparison items |Insight report |In\-depth research |
|---|---|---|
|Applicable scenarios |Routine reports (daily report, weekly report, daily report, fixed topic analysis report) |Free inquiry |
|Data sources |ABI dashboard, ABI dataset |Only ABI datasets are supported |
|Report structure |Users have more customization options, and the report framework is more rigid |Models have greater flexibility, and the report framework may not be rigid |
|Generation time |Similar reports are shorter<br><br>Each module can generate results in parallel |Similar reports are longer<br><br>Results are generated all at once after a question is asked |
