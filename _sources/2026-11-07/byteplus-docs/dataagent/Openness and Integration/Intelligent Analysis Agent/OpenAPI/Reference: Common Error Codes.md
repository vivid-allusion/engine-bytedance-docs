|Error code |Error message |Note |
|---|---|---|
|aeolus/openapiClient/tokenExpired |Token has expired | |
|aeolus/openapiClient/tokenError |Invalid token | |
|aeolus/openapiClient/requestRateExcess |Request rate limit exceeded | |
|aeolus/openapiClient/blocked |Request has been blocked | |
|aeolus/validation/validationFailed |API parameter validation failed; parameters do not meet validation rules |Request parameter error |
|aeolus/user/unauthorized |User does not have permission |User does not have permission for relevant resources (dashboard, subscription) |
