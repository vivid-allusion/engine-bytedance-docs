When the chatCompletion stream returns `[DONE]`, you can call this API to request the chat result. Currently, multi\-turn conversations are not supported.

<span id="5ca2036d"></span>
# **Request description**


* Request method: GET

* Request URL: `/dataAgent/llm/openApi/v2/signed/agent/chatResult?sessionId={sessionId}&historyId={historyId}`


<span id="c51cc1e8"></span>
# **Request parameters**

The body parameters are as follows.


|Parameter |Type |Required |Example value |Description |
|---|---|---|---|---|
|sessionId |int |Yes |12886164 |Session ID. The session ID is returned in sessionInfo when creating a session. For details, see [Create a Session](https://docs.byteplus.com/docs/dataagent/Create_a_Session). |
|historyId |int |Yes |12886163 |The session result ID for this interaction. For example, when a vague question is broken down into multiple sub\-questions for querying, each sub\-question result will have a session result ID.<br><br>It needs to be configured as the `type=result` and `status=success` in the event stream returned by the chatCompletion API. The `result` field in the event contains the `historyId`. For details, see [Session Completion](https://docs.byteplus.com/docs/dataagent/Session_Completion). |


<span id="646b2d59"></span>
# **Response parameters**

The core parameters of the response result are described in detail below.


|Primary parameter |Secondary parameter |Type |Description |
|---|---|---|---|
|disableBookmarkQuestion |Not applicable |boolean |Whether to bookmark the question |
|errorMsg |Not applicable |string |Error message |
|execErrorMsg |Not applicable |string |Execution error message |
|isSuccess |Not applicable |boolean |Whether execution was successful |
|isEmpty |Not applicable |boolean |Whether the result is empty |
|llmResult | | |Large model execution process |
| |code |string |Code generated by the model, including SQL and Python |
| |dataSetIdList |list[int] |Datasets used |
| |execContext |string |Execution context, that is, the SQL before escaping |
| |executeSql |string |SQL actually executed |
| |originSql |string |Original SQL |
| |recallKnowledge |string |Information of the recalled dataset, in markdown format |
| |rewriteSql |string |Rewritten SQL, similar to execContext |
| |sqlList |list[string] |Simplified semantic SQL |
| |thought |string |Large model thought process |
| |total |list[dict] |Entire execution process |
|renderResult | | |Data query result |
| |chartType |string |Chart type (enumeration)<br><br><br>* line: Line chart<br><br>* column_parallel: Bar chart<br><br>* pie: Pie chart<br><br>* measure_card: Metric card<br><br>* table: Table<br><br>* scatter: Scatter plot<br><br>* map: China map<br><br>* double_axis: Dual\-axis chart<br><br>* combination: Combination chart |
| |datasets |list[object] |Query result dataset |
| |dimensions |list[string] |Dimension fields in the result set |
| |metrics |list[string] |Metric fields in the result set |
| |vizSchema |object |Rendering configuration information |
