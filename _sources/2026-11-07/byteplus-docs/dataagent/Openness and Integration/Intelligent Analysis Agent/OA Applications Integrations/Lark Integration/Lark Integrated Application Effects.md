# Overview

As Lark's efficient office approach and Intelligent Data Insight's data\-driven methodology become increasingly integrated into the daily operations of enterprises, we have launched the Lark + Intelligent Data Insight joint solution based on the features of both products. This solution enables product functionality integration across multiple stages, from data access, data reach, to data sharing, providing users with a more convenient collaborative office experience and supporting organizational transformation. This article provides a systematic introduction to the capabilities and effects of the deep integration between Intelligent Data Insight and Lark. For details on each capability, click to view the specific documentation for detailed operations.

<span id="9293780b"></span>
# Lark data access

<span id="237013ca"></span>
## Integrate Lark Sheets data

Intelligent Data Insight supports uploading Lark Sheets to create datasets. For data update methods, offline scheduled data updates are supported. For detailed steps, see [Lark Sheets](https://docs.byteplus.com/docs/dataagent/Lark_Sheets).

<span id="098bdf7c"></span>
## Integrate Lark Bitable data

Intelligent Data Insight supports uploading Lark Bitable to create datasets. For data update methods, offline scheduled data updates are supported. For detailed steps, see [Lark Base Tables](https://docs.byteplus.com/docs/dataagent/Lark_Base_Tables).

<span id="f2050957"></span>
# Lark data reach

<span id="13a71fb7"></span>
## Obtain DataWind from the Lark open platform

In the Lark app marketplace, Intelligent Data Insight has already been listed as an application. New customers can find this application by searching and can try it and experience it.

<span id="5e28ccb3"></span>
## Lark Workbench mini program setup

In the Lark open platform, application administrators can create Intelligent Data Insight mini programs or applications through self\-built apps. Organization administrators can set permissions and configure the application's visibility range in the Lark admin console, enabling users within the enterprise to directly access the mobile version of Intelligent Data Insight from the Lark Workbench or push daily, weekly, or monthly reports to individual Lark users or groups. For detailed instructions, see [Lark Integration](https://docs.byteplus.com/docs/dataagent/Lark_Integration_).

<span id="7d121042"></span>
## Lark receives subscription alert notifications

After the administrator completes the basic configuration, subscription and alert rules can be set in Smart Data Insight so that dashboard and data anomaly notifications can be pushed to Lark and Lark groups. For detailed instructions, see [How to Push Lark Messages](https://docs.byteplus.com/docs/dataagent/How_to_Push_Lark_Messages).

<span id="96b433ba"></span>
## Lark chat window tab settings

You can configure dashboard links from Smart Data Insight in the tab position of the Lark chat window, enabling instant access to data. For detailed instructions, see [JS SDK Integration Solution](https://docs.byteplus.com/docs/dataagent/JS_SDK_Integration_Solution) to learn how to obtain dashboard embed links.

<span id="0050ff6b"></span>
## Open dashboards from the Lark left sidebar

You can directly open dashboards from Smart Data Insight in the Lark left sidebar, allowing you to view data without switching to a browser and making business analysis and communication more efficient. The specific operations and features will be available after Lark releases the new version. Supported versions: Lark V7.0 and above; Smart Data Insight V2.56.1 and above.

# 4. Lark data collaboration

<span id="28b82914"></span>
## 4.1 Lark account connectivity

Users in Smart Data Insight can link their accounts to Lark accounts, either individually or in batches. For detailed instructions, see [How to Bind Lark Accounts and Batch Create Users](https://docs.byteplus.com/docs/dataagent/How_to_Bind_Lark_Accounts_and_Batch_Create_Users).

<span id="4b5b8929"></span>
## 4.2 Permission and Lark approval integration

Lark approval flow is supported, allowing users to independently apply for permissions from resource owners. Once approved, applicants will receive the corresponding permissions for the requested resources. This lowers the threshold for data usage and shortens the time required for data authorization by data or IT personnel. For detailed instructions, see [Permission Approval Integration with Lark](https://docs.byteplus.com/docs/dataagent/Permission_Approval_Integration_with_Lark).

<span id="d0fc73e5"></span>
## 4.3 Dashboard comment notifications

Starting from version 2.48.0, Smart Data Insights supports users in commenting on dashboards. Users involved in comments can also reply. If integrated with Lark, it also supports pushing messages to commenters via a message bot. For detailed instructions, see [Dashboard comments](https://www.volcengine.com/docs/4726/160157).

<span id="e0272154"></span>
## 4.4 One\-click contact with chart owner in Lark

After completing Larkrk integration and binding the chart creator with their Lark account, you can contact the chart owner with one click. Click the contact button next to the chart name to see the Lark ICON. Clicking it will take you to Lark to view the owner's Lark contact information and reach out to them.

<span id="b9f298d8"></span>
## 4.5 **One\-click authorization to send Lark notifications**

The authorization operation provided by Smart Data Insights includes two entry points: the "Authorize" button in the upper right corner of the dashboard, and the "Authorize" option in the menu that pops up from the dashboard or folder in the left dashboard directory. Click the authorize button, select the authorization target and permission level in the pop\-up window. The system will send the dashboard link to the sharing target and grant the corresponding permissions. At this stage, you can send Lark notifications to the sharing target. This feature is selected by default and users can choose to deselect it. For detailed instructions, see [Authorization sharing](https://www.volcengine.com/docs/4726/66643#%E4%B8%80%E9%94%AE%E6%8E%88%E6%9D%83).
