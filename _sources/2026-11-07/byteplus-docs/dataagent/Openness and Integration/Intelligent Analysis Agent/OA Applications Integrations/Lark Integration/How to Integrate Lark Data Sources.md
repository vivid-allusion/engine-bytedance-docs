# Overview

Smart Data Insight supports uploading Lark spreadsheets and Lark multi\-dimensional spreadsheets to create datasets. Offline scheduled updates are supported for data updates. To integrate Lark data sources, you need to complete the basic configuration for integrating the Lark application and perform the following actions.

<span id="f419d115"></span>
# Enable Lark document\-related permissions

On the permissions management page, make sure to enable the following permissions. "View, comment, edit, and manage multi\-dimensional spreadsheets" and "View, comment, and export multi\-dimensional spreadsheets" are permission settings for multi\-dimensional spreadsheets. "View, comment, edit, and manage spreadsheets" and "View, comment, and export spreadsheets" are permission settings for spreadsheets. It is recommended to select all permissions related to cloud documents. The permissions configuration interface of the Lark open platform may be updated periodically. Please note that you should refer to the latest permissions configuration interface, and it is also recommended to select all permissions related to cloud documents.

# Lark data source connection test

To confirm whether the configuration is successful, go to the Smart Data Insight product, click Data Management \-\-\> Dataset, and you will see options for Lark spreadsheets and Lark multi\-dimensional spreadsheets (Lark multi\-dimensional spreadsheets are supported in version V2.42 and above). [Follow the instructions](https://www.volcengine.com/docs/4726/68863) to complete the subsequent steps, which means the configuration is successful. Otherwise, please check the configuration according to the steps above.
