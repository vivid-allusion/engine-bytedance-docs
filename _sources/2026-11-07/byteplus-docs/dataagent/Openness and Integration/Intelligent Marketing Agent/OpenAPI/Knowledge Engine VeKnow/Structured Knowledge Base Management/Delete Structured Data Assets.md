Call this interface to delete the data asset and its OpenSearch index; the same request can be safely retried.

* Caller: Open API application, external agent, or integration service.

* Prerequisites: The caller has knowledge base editing privileges and provides an Idempotency\-Key.

# Interface description

* Interface name: delete_asset_structured_knowledge_v1_kbs__kb_id__assets__asset_id__delete

* Interface address:/structured_knowledge/v1/kbs/{kb_id}/assets/

* Request method: DELETE

# Request parameters

## Header

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|Idempotency\-Key |String |Yes |Write requests generated by the caller are idempotent; the same tenant, operation, and request must remain unchanged when tried |

## Path

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|kb_id |String |Yes |Structured Knowledge Base ID, returned by the Create Knowledge Base or Query Knowledge Base List interface |
|asset_id |String |Yes |Structured data asset ID, returned by the Create Asset or Query Asset List interface |

# Response parameters

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|code |Number |Yes |Response code: 0 = success, non\-0 = failure |
|msg |String |No |Code is not 0, error message is returned |
|message |String |No |error message |
|data |Object |Yes |Data. See the **data** table below for details |

## data

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|resource_id |String |Yes |Deleted Knowledge Base or Data Asset ID |
|status |String |Yes |Delete state, such as DELETING, DELETED, or DELETE_FAILED |
|task_ref |String |No |Removes task references asynchronously; can be empty when synchronization completes |
