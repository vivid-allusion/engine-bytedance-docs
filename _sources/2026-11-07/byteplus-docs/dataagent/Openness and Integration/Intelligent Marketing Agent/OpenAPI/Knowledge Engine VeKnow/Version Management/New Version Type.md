Call this interface to set the version type for the specified version group.

# Interface description

* Interface name: update_version_group_sophon_version_group_update_post

* Interface address:/sophon/version_group/update

* Request method: POST

# **Request parameters**

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|versionGroupId |String |Yes |Version group ID |
|versionType |String |Yes |version type |

# **Response parameters**

Response Result Object Type
