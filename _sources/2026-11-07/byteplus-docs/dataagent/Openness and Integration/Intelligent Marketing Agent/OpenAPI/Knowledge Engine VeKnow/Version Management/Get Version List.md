Call this interface to get the version list and details of the specified version group.

# Interface description

* Interface name: get_version_group_sophon_version_group_get_get

* Interface address:/sophon/version_group/get

* Request method: GET

# **Request parameters**

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|id |String |Yes |Document ID |
|versions |Array |No |List of filtered version numbers |

Response Result Object Type
