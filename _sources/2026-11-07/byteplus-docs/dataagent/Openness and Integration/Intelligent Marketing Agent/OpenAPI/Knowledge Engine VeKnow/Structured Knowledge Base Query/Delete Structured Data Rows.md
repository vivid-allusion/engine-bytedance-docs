Call this interface to delete a row of data according to the stable row_key; still return idempotent successfully when the target row no longer exists.

* Caller: Open API application, external agent, or integration service.

* Precondition: The caller has permission to edit the data asset.

# Interface description

* Interface name: delete_row_structured_knowledge_v1_kbs__kb_id__assets__asset_id__rows__row_key__delete

* Interface address:/structured_knowledge/v1/kbs/{kb_id}/assets/{asset_id}/rows/

* Request method: DELETE

# Request parameters

## Path

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|kb_id |String |Yes |Structured Knowledge Base ID, returned by the Create Knowledge Base or Query Knowledge Base List interface |
|asset_id |String |Yes |Structured data asset ID, returned by the Create Asset or Query Asset List interface |
|row_key |String |Yes |Data row stable unique identifier, generated by row list, import unique identifier field, or write interface |

# Response parameters

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|code |Number |Yes |Response code: 0 = success, non\-0 = failure |
|msg |String |No |Code is not 0, error message is returned |
|message |String |No |error message |
|data |Object |Yes |Data. See the **data** table below for details |

## data

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|row_key |String |Yes |The row of data requested for deletion is stable and unique |
|deleted |Boolean |Yes |Is the data row actually deleted in this request? |
|already_not_exists |Boolean |Yes |Whether the data row no longer exists before deletion; still idempotent when true |
