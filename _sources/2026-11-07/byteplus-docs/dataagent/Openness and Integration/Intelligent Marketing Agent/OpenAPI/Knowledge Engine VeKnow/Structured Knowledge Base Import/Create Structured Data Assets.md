Call this interface to create CSV, Excel, ClickHouse or Hive data assets and field drafts.

* Caller: Open API application, external agent, or integration service.

* Prerequisites: The caller has the permission to edit the knowledge base, the file source has completed the file upload first, and Idempotency\-Key is provided.

# Interface description

* Interface name: create_asset_structured_knowledge_v1_kbs__kb_id__assets_post

* Interface address:/structured_knowledge/v1/kbs/{kb_id}/assets

* Request method: POST

# Request parameters

## Header

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|Idempotency\-Key |String |Yes |Write requests generated by the caller are idempotent; the same tenant, operation, and request must remain unchanged when tried |

## Path

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|kb_id |String |Yes |Structured Knowledge Base ID, returned by the Create Knowledge Base or Query Knowledge Base List interface |

## Request body

The Object type contains the following parameters:

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|asset_name |String |Yes |Structured data asset name, 1 to 255 characters in length |
|folder_id |String |No |Target directory ID; do not pass or pass 0 to indicate the root directory of the knowledge base |
|source_type |String |Yes |file type<br><br><br>* EXCEL<br><br>* CSV<br><br>* CLICKHOUSE<br><br>* HIVE |
|source_config |Object |Yes |Configure. See **source_config** table below for details |
|schema_draft |Object |Yes |Optional field draft; import can be initiated after subsequent field configuration if not passed. See **schema_draft** table below for details |

## source_config

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|source_type |String |Yes |file type<br><br><br>* EXCEL<br><br>* CSV<br><br>* CLICKHOUSE<br><br>* HIVE |
|file_id |String |No |Excel/CSV uploaded file ID |
|dataset_id |String |No |Prep Dataset ID |
|dataset_name |String |No |The name of the Prep dataset recorded when creating the asset |
|database_name |String |No |CK/Hive library name |
|table_name |String |No |CK/Hive table name |
|partition_type |String |No |partition type<br><br><br>* NON_PARTITION<br><br>* FULL_PARTITION<br><br>* INCREMENTAL_PARTITION |
|partition_fields |Array |No |Partition field, up to two |
|task_name |String |No |Prep import task name |
|auto_update_config |Object |No |Prep input operator delta configuration and ScheduleConf timing configuration. See **auto_update_config** table below for details |
|sheet_config |Object |No |Excel/CSV sheet parsing configuration. See **sheet_config** table below for details |

## auto_update_config

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|isIncrement |Boolean |No |Whether to read data in incremental fields; false indicates that the full read is performed by Prep |
|incrementField |String |No |The name of the source table field used for incremental reads, required only when isIncrement = true |
|incrementFieldType |String |No |Incremental field type used by Prep to interpret incremental cursor values |
|timeFormat |String or Object |No |Format configuration of temporal delta fields, the specific format follows the Prep input operator protocol |
|timeRange |Number |No |Incremental read time range traced forward in units interpreted by the Prep input operator configuration |
|batchSize |Number |No |Prep The recommended number of lines to read or write in a single batch must be greater than or equal to 1. |
|writeMode |writeMode |No |Prep write mode: full to replace all, incremental to incremental write |
|scheduleConf |Object |Yes |Prep scheduling configuration. See the **ScheduleConf** table below for details |

## scheduleConf

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|scheduleType |Number |Yes |0 means manual execution, 1 means scheduled execution |
|scheduleTimeType |Number |No |Prep schedule time type, currently fixed at 0 |
|scheduleFrequency |String |No |Timing frequency, currently supports daily/monthly |
|scheduleTimeSettings |Array |No |Daily is [HH: mm], monthly is [date, HH: mm] |
|dependencyNodes |Array |No |Get by Verag calling Prep, the front end can only pass empty arrays |

## sheet_config

|Parameter name |Type |Is it necessary to pass on? |Description |
|---|---|---|---|
|sheet_name |String |No |Excel sheet name |
|header_row_index |Number |No |Header row, starting at 1 |
|data_start_row_index |Number |No |Data starting line, starting from 1 |
