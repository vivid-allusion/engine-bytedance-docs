Task creation refers to the creation process of visual modeling tasks, which usually includes steps such as creating new tasks and data connection. The visual modeling task supports extracting data from the data source, adding data processing nodes by dragging and dropping, and outputting the processed data to the target source. This article shows you how to create a task.

<span id="d3fb5951"></span>
# Prerequisite

The unstructured data to be tagged has been created as a dataset of VeCDP, see here [Data Preparation](https://docs.byteplus.com/docs/dataagent/Data_Preparation).

<span id="ff2613a1"></span>
# Operation steps


1. After logging in to the Intelligent Marketing Agent page with your account password, click "Experience Now" in the "Unstructured Data Marking" card, and the page will jump to VeCDP's "Visual Modeling" page.

2. Click "Task List" in the left navigation bar of the VeCDP page, enter the visual task list page and click "New" to start creating an offline type of visual modeling task.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The current unstructured data marking function only supports label output based on offline visual modeling tasks, so please select "New Offline Task" here.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/484aff9672c44363b1243594d81a66f8~tplv-goo7wpa0wc-image.image) </span>

3. Click "➕" at the top left of the New Task page to add a data connection, and access the unstructured data to the system for marking processing by **connecting database & table** as follows. You can use templates, each of which supports previewing or applying.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d0f813404bd942a4a0f91efbdb77fcd3~tplv-goo7wpa0wc-image.image) </span>

4. Select the created dataset from the "Add Data Connection" page that pops up to add the dataset to the left\-hand list of visual modeling tasks.

5. Select the dataset of unstructured data to be marked and pull it from the left list into the right panel.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b532a4d3f3874600859daeccf9680f0d~tplv-goo7wpa0wc-image.image) </span>

6. If you need to remove a data connection, click the Delete button on the right side of a specific data connection in the data connection list on the visual modeling task creation page to remove the data connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1c804dedcc6147c5a58e33c6362bab95~tplv-goo7wpa0wc-image.image) </span>
