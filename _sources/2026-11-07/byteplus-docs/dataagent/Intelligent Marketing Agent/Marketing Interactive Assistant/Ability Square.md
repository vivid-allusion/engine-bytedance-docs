Marketing Interactive Assistant provides an ability square that aggregates high\-quality Agents, Skills, and MCPs for you to choose from, allowing you to quickly build marketing automation capabilities by discovering and selecting expert agents, skills, and linking services provided by the platform in one stop.

# Operation steps

1. Log into the Marketing Agent console and, at the top of the left navigation bar, select **Marketing Interactive Assistant**.

2. Select **Ability Square** in the left navigation bar of the Marketing Interactive Assistant.

3. In Ability Square, you can view the officially provided Agents, Skills, and MCPs.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c9443e2662e146cea3233d9b7ea62994~tplv-goo7wpa0wc-image.image)

4. Later, when orchestrating agents, support selecting the corresponding tool from the ability square.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a2b63418268845249909112f5346b977~tplv-goo7wpa0wc-image.image)

5. (Optional) Some tools need to configure variables before they can be used. At this time, you need to follow the page guidelines and pass in the variable value.

   For example, as shown in the figure below, when adding official capabilities, you need to fill in the matching API Key and geographical information in combination with actual business needs.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a735dfaaa610423897c99b8882342be9~tplv-goo7wpa0wc-image.image)

   Once the addition is complete, you can view the tools in the Tools list and support editing variables, dynamic function configuration, description, or removal of tools.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/161ec2e0404140a3872ecd23f87a7fdf~tplv-goo7wpa0wc-image.image)
