Intent planning engine is the core module of marketing interactive assistant, which aims to intelligently identify and plan user queries through unified intent configuration and routing mechanism. Creating an intent planning engine involves orchestrating debugging and creating intents. The engine can be published as an API for external system calls. This article shows you how to create an intent planning engine.

# Operation steps

## New intent planning engine

1. Log into the Marketing Agent console and, at the top of the left navigation bar, select **Marketing Interactive Assistant**.

2. In the left navigation bar of the Marketing Interactive Assistant, select **Intent Planning Engine** and click **New Intent Planning Engine** in the upper right corner of the page.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/80af38a2ef2a46c58d5307319b73d75c~tplv-goo7wpa0wc-image.image)

3. On the **Orchestration Debugging** page of **My Intent Planning Engine**, complete the following configuration.

   |**Module** |**Configuration item** |

   |Basic information configuration |Click the **Edit** icon on the right side **of the My Intent Planning Engine** to edit the avatar, name, and description.<br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/95c3301e5a744a8f875c34fb4ac2cd78~tplv-goo7wpa0wc-image.image)<br><br><br>* **Application name:**  Required, can be customized naming, with a character limit of 50.<br><br>* **Application description:**  Required, can customize the description of the intent planning engine Agent, with a character limit of 200.<br><br>* **Avatar:**  Generated by the system by default, you can also click **random selection** to switch the new avatar. |
   |Model configuration |* Support turning on **multi\-modal recognition capability**, after turning on, it will support multi\-modal input of pictures.<br><br>* **Problem Rewriting Model:**  Used to rewrite user queries.<br><br>* **QA Matching Model:**  Questions used to match user input.<br><br>* **Intent recognition model:**  used to identify the intent of user input.<br><br>* **Large Model Reply Model:**  Used to generate replies. Expand the model configuration to enable deep thinking.<br><br>* **Multi\-intent autonomous planning model:**  used to autonomously plan execution steps based on user input intentions.<br><br>* **Dialogue guide question model:**  used to generate dialogue guide questions.<br><br>* **Model cover bottom:** <br><br>   * **Thinking Bottom Model:**  Alternative option when the main thinking model is not available.<br><br>   * **Deep Thinking:**  Once turned on, the model will use Deep Thinking mode.<br><br>   * **Universal Bottom Model:**  A universal alternative when models other than thinking are not available.<br><br>* **Human prompt word:**  Default fill restriction rules, can be changed as needed. For example, set the personal style and the reply range of the agent. |
   |Knowledge |Knowledge can configure **term** and **QA Q&A** to assist intent planning engines in intent recognition<br><br><br>* **Term:**  Support the knowledge base of type [Term Base] in the associated knowledge base, and the professional name\-noun explanation is maintained in the term base. When the user query contains a term noun, the term explanation will be recalled, and the intent planning engine will assist the intent recognition judgment. Term does not rewrite queries and is not given to downstream agents.<br><br>* **QA Q&A:**  Support the knowledge base of type [Q&A base] in the associated knowledge base. The Q&A base maintains the standard QA Q&A pair. If the intention planning engine is associated with the Q&A base, the user query will synchronously perform correlation retrieval in the Q&A base. If there is a match to the corresponding QA pair, it will intercept the intention reasoning and directly reply to the standard Q&A of the QA pair; |
   |Memory |Memory allows users to configure their conversation rounds, short\-term memory, and long\-term memory on demand.<br><br><br>* **Short\-term memory:**  After opening, the original text of the historical session and the overview of the historical session are given to the agent as context input.<br><br>   * Number of dialogue rounds: The number of contextual rounds recalled when intent recognition is rolled, and contextual dialogue information is used as supplementary information during query rewriting and intent recognition.<br><br>* **Long\-term memory:**  Automatically extract and record user portraits, preferences and events, long\-term memory does not support importing own portrait data for the time being.<br><br>   * **Memory:**  Specifies the memory currently required from the session memory.<br><br>   * **Memory usage rules:**  you can choose to **read memory** (allow the agent to read the historical memory in the memory bank), **write global memory** (allow the agent to precipitate the content of this conversation into a global general portrait memory/event memory), support multi\-selection. |
   |Policy rules |Policy rule configuration is the intent recognition strategy and planning strategy of intent planning engine<br><br><br>* **Problem rewriting strategy:**  The user problem is rewritten in context, and different strategies can be selected to balance recognition accuracy and time consumption.<br><br>   * **Close:**  do not rewrite the question directly to identify, the fastest, suitable for questioning standard scenarios.<br><br>   * **Rewrite first and then intent recognition:**  Intent recognition works better and will increase the recognition time (about 1s). Suitable for scenarios with high accuracy in intent recognition.<br><br>   * **Synchronized rewriting and intent recognition:**  Intent recognition is faster, and the accuracy rate will decrease to a certain extent. It is suitable for scenarios where query needs to be rewritten as downstream input and the recognition time is low.<br><br>* **Pass the rewritten question to the downstream whole: Issue rewriting policy non\-closed option** needs to be configured, after it is turned on, the downstream agent will receive the rewritten new question, otherwise it will receive the original question entered by the user.<br><br>* **Agent track memory:**  After opening, you need to configure the **effective memory time** . The agent will remember all the user's original questions and corresponding intentions. Similar problems are directly hit without repeated reasoning, which increases speed and saves computing power costs.<br><br>* **Workflow Memory:**  When turned on, the planning\-action agent will cache the historical planning path, and similar problems can directly hit the cache without re\-planning.<br><br>   * After the switch is turned on, the **workflow generalization memory** switch needs to be configured. After the switch is turned on, the workflow memory matching degree is low, and the LLM further judges whether it can be reused.<br><br>* **Multi\-intent processing strategy:** <br><br>   * **Close:**  No multi\-intent teardown, only the most dominant or single intent is matched.<br><br>   * **Autonomous planning:**  When multiple intents are hit, the large model automatically orchestrates, concatenates, and merges replies. After selecting this option, you need to view or edit the prompt word in the **self\-planning reply prompt word** input box below.<br><br>   * **Clarification guidance:**  When multiple intents are hit and cannot be determined, let the agent actively ask the user to clarify.<br><br>* **Entity Extraction:**  Identify the business object in the user question and pass it through to the downstream agent running context.<br><br>   * You can choose to turn on the automatic injection switch.<br><br>   * Click the **plus sign(+)** , in the new entity pop\-up window, complete the following configuration, add entities.<br><br>      * **Entity Name:**  Custom entity name, such as customer, merchandise, order, store.<br><br>      * **Entity Description:**  Custom descriptive information such as business meaning, acceptable expression, recognition boundaries, etc.<br><br>      * **Extraction instructions:**  The description information extracted by the entity, such as only identifying the order number starting with OD.<br><br>      * **Binding term base:**  Select one or more term bases for binding identification, if not binding, directly identify through the large model. |
   |Voice interaction |The voice interaction includes the following two function switches, which can be turned on as needed.<br><br><br>* **Speech to text:**  When turned on, users can interact with the agent via voice input.<br><br>* **Text To Speech:**  When turned on, the agent replies to support conversion to voice playback.<br><br>   * Support custom timbre.<br><br>   * Support enabling default automatic broadcast.<br><br><br>If the API Key parameter is missing or invalid, please contact the enterprise super administrator to configure the parameters required for automatic speech recognition (ASR) and Text To Speech (TTS).<br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/dc30b8809f8343b8a2c34556232378da~tplv-goo7wpa0wc-image.image) |
   |Dialog configuration |* **Opening remarks:**  The fixed guide content of the opening remarks.<br><br>* **Opener question:**  Configure the fixed question of opener guide, add up to 5.<br><br>* **Dialogue guidance question:**  closed by default, the dialogue guide question is the related question after the answer output. Output rules can be configured by prompts.<br><br>* **Prompt:**  Fixed prompt that can be configured to appear before or after the answer output. It is usually displayed as a risk warning after the answer is output.<br><br>* **Feedback label:**  After opening, support the like and step function, and support the configuration of like labels and click labels. For example, after liking, it is supported to select the forward label for feedback.<br><br>   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9fe3f1107e2d4f2b812fc133e63090d9~tplv-goo7wpa0wc-image.image) |
   |Security policy configuration |Support BytePlus [large model application firewall ](https://www.volcengine.com/docs/84990/1520619)function to ensure that the model input and output content is safe, available and trusted.<br><br><br>* How to obtain parameter configuration information such as AK, SK, server address, firewall ID, region, etc., please refer to the [description of key parameters of large model application firewall ](https://www.volcengine.com/docs/84990/1827490?lang=zh#438128ee).<br><br>* **Whether to verify the request content:**  After opening, the request content will be verified for security compliance.<br><br>* **Whether to verify LLM output:**  After opening, the large model output will be verified for security compliance.<br><br>* **Hit risk control prompt:** <br><br>   * **Content generation using security services:**  Prompts are generated using the internal capabilities of a large model application firewall.<br><br>   * **Use a custom security prompt:**  You need a custom prompt in the input box. |

## Debug and preview

In the **Debug and Preview** area on the right side **of the My Intent Planning Engine** page, ask the Intent Planning Engine agent a question to test the intent configuration.

1. Support switch configuration **replies to hit intent only**, and the debugging process does not actually call downstream agents or other execution actions after turning it on.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/60ac054e5a064f66a9313d564ecc2499~tplv-goo7wpa0wc-image.image)

2. Click **Custom Parameters** to support custom configuration parameters, including the configuration of Header and Body. Configurable input request parameters to simulate calls in real business scenarios.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/608b83958342439988c84f51e463c2f3~tplv-goo7wpa0wc-image.image)

3. (Optional) If the **multi\-modal recognition capability** is enabled, the upload of image attachments is supported, and up to 5 images can be uploaded at a time, and the image size cannot exceed 20 MB.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d26108160b6541a2b5e31fac06d62ab4~tplv-goo7wpa0wc-image.image)

4. (Optional) If the **speech\-to\-text** ability of **voice interaction** is turned on, voice input is supported.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/09c26583e239498196c2ab6e1269e7d4~tplv-goo7wpa0wc-image.image)

5. The response contains the following information.

   1. Hit intent name.

   2. Rewrite query: Rewrite the query.

   3. Selection Basis: Determine the reason for hitting the intent.

   4. Reply result: The return result of the downstream agent. If it is multi\-intent planning, it will return the thought + reply of the sub\-agent, as well as the summary reply.

   5. Function in the lower right corner: The lower right corner of the reply result supports copying; if the Text To Speech function of voice interaction is turned on, reading aloud is supported; if the feedback label of the dialogue configuration is turned on, it supports liking and stepping.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/48f2f452e57047d78ab88ea3eb934383~tplv-goo7wpa0wc-image.image)

## Intent Management

Manage all intents under the intent planning engine agent in **the My Intent Planning Engine** page on the left **Orchestration** \> **Intent Management** area.

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/862d29cc3a23408fb4b2230bb61d58d4~tplv-goo7wpa0wc-image.image)

1. The intent cards are displayed in reverse order of update time, and the display information includes:

   * Intent Name: Intent Name Information

   * Intent ID: The unique identifier of the intent

   * Business scenario: The business scenario that is intended to be configured

   * On state: Only the on intention takes effect. Click the switch to adjust the on state of the intention. The newly created intention defaults to on. After editing, the intention to open the state remains unchanged;

   * Intent description: a description of the intent configuration, **note that when creating a new intent, it is recommended to write in detail what scene hits the current intent, and the large model will refer to this information for reasoning.**

   * Update time: Intended last update time.

   * Creator: Intended creator information.

   * After the mouse is suspended on the card, it supports **editing** and **deleting.**

      > **注意**

      * > Once the intention is deleted, it cannot be restored. Please proceed with caution.

      * > Bottom line intent does not support deletion.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/77c1f8ec075144c9a42f6d62fa12774a~tplv-goo7wpa0wc-image.image)

2. The intent list can be fuzzy searched by [intent name] and [business scenario].

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4ef44b1fe1164e698cc25330302e39b6~tplv-goo7wpa0wc-image.image)

## New intent

Click **New Intent** in the upper right corner of the Intent Management area, or click Card Edit to go to the Intent Edit page.

* > Intent classification is as detailed as possible to cover the complete business scenario.

* > There should be no ambiguity between intentions.

# Version management

In the list of intent planning engines, enter the specified intent planning engine details page, and click the version number in the upper right corner of the page to view the historical version information of the current intent planning engine.

* **Draft version:**  The unpublished version that is currently being edited.

* **Online version:**  The version that has saved the configuration and has been published.

# Edit/Copy/Delete Intent Planning Engine

In the list of intent planning engines, select the specified card to support the following operations:

* **Edit:**  Enter the Intent Planning Engine details page to support modifying agent configuration, debugging agents, and managing intents.

* **Copy:**  Quickly replicate a new intent planning engine based on the current intent planning engine configuration, and support adjusting each configuration item during replication.

* **Delete:**  It is no longer necessary to use the intent planning engine to support deletion.

> **注意**

> Once the intent planning engine is deleted, it cannot be restored. Please proceed with caution.

![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/c7b25e544f574e7e99f39bc56ddc129b~tplv-goo7wpa0wc-image.image)
