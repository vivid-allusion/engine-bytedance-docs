The Marketing Interaction Assistant provides a "My App" function entrance, allowing you to switch between using a published intent planning engine or agent for intelligent Q&A interactions within "My App". This article describes how to use my application.

# Operation steps

1. Log into the Marketing Agent console and select **Marketing Interactive Assistant** at the top of the left navigation bar.

2. Switch to the **Apps** tab in the left navigation bar of the Marketing Interactive Assistant and select **My Apps**.

   > **注意**

   > If the enterprise does not open the **application\-side** function switch, the navigation bar does not distinguish between the application\-side and the management\-side, and only shows a navigation bar.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f584d3229f874c4ca723a4c434e8f94a~tplv-goo7wpa0wc-image.image)

3. Switching apps is supported at the top of the page.

   > **说明**

   > Under the current project, all **published** intent planning engines and agents will be displayed in the application list.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/29991957a98a4ba787c27efa7926fc28~tplv-goo7wpa0wc-image.image)

4. After switching, you can talk to the agent or manage the agent configuration.

   |**Operation** |**Description** |
