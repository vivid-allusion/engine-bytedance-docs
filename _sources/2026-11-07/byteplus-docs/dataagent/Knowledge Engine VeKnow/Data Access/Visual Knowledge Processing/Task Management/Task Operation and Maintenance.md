# **Feature Overview**

In the Visual Knowledge Processing \- Task Operations section, you can view the metrics for the task instances running today. Visual knowledge processing tasks and instances are generally one\-to\-many relationships, and this page displays the statistical results of task instances for which the current user has viewing rights.

<span id="5a723e2c"></span>
# Example overview

On the Instance Overview page, users can view tasks that **ran successfully, failed, running, queued, and terminated** for the day.

In "Today's Mission Overview", you can view the start times of missions in different states.

# Instance management

Click on a different running state to jump to the instance management in its state to view the specific tasks in that state, including task name, owner, output node name, instance status, trigger method, scheduling type, scheduling frequency, and business date.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fa0631d7ab764e01bcabea68666b843d~tplv-goo7wpa0wc-image.image) </span>
