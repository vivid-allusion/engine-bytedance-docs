2. **One\-hot model application**


The one\-hot model applies operator chaining after the one\-hot encoding operator. The one\-hot operator not only supports representing columns of string type as arrays, but also supports saving the conversion process in the form of models. Combined with the one\-hot model application operator, similar columns can be encoded and converted.

3. **Classification**


The following models are supported, see the Features page for details.


|Model name |Model introduction |
|---|---|
|Logistic regression |Logistic regression is a classic statistical learning classification model that adds a layer of nonlinear function mapping to the mapping of linear regression, first sums the characteristics of the sample linearly, and then uses the logistic function to map the value between 0 and 1, indicating that the sample belongs to the probability size of each category, and takes the corresponding category with a larger probability value as the final prediction category of the sample. This operator supports binary classification and multi\-classification problems, and supports continuous and categorical features, but categorical features require one\-hot operator processing after string indexing. |
|Xgboost |Boosting rounds: The number of boosting iterations during training.<br><br>Use the best model: The best model is selected based on the evaluation metrics selected by the best model.<br><br>Tag index sorting method: freq uency means sorting according to frequency, and alphabet means sorting according to string ratio size. |
|Catboost |A GBDT framework based on symmetric decision trees (oblivious trees) algorithm with few parameters, support for categorical variables and high accuracy, the main pain point is to deal with categorical features efficiently and reasonably. CatBoost is composed of catgorical and boost, and it also deals with layer bias and prediction shift to improve the accuracy and generalization ability of the algorithm. CatBoost mainly has the following five characteristics: 1. High model quality can be obtained without parameter tuning, and very good results can be obtained by using default parameters, reducing the time spent on parameter tuning. 2. Supports categorical variables without preprocessing non\-numeric features. 3. Fast and scalable GPU version, which can be implemented with GPU\-based layer lifting algorithms to train your model and support multi\-card parallelism. 4. To improve accuracy, a new layer lifting mechanism is proposed to build models to reduce overfitting. 5. Rapid forecasting allows for the rapid and efficient deployment of models, even in the face of very time\-critical tasks. |
|Naive Bayes |Naive Bayes is a classification method based on Bayes' theorem and independent assumptions of feature conditions. Naive Bayes classifier is easy to build and suitable for large data sets, but its disadvantage is that it needs to make assumptions about the prior distribution. This operator supports binary classification and multi\-classification problems, classification and non\-negative, continuous features, but class features need to be string indexed in advance. |
|Support Vector Machine |A statistical learning classification model, the basic idea is to solve the separation hyperplane that can correctly divide the training data set and maximize the geometric interval |
|Decision tree |One of the commonly used classification algorithms, it often performs well for exploratory knowledge discovery. The principle of decision trees is very simple and can handle large\-dimensional data without prior knowledge of the characteristics of the model, which makes decision trees widely used. Decision trees use greedy algorithms, and their establishment process also requires training data. The core problem of decision tree is the determination of decision tree branching criterion and split point. |
|Random forest |In machine learning, a random forest is a classifier that contains multiple decision trees, and its output class is determined by the mode of the class output by a single tree. The training data for each tree in the random forest is the extracted part of the data from the original training dataset, and a subset is randomly extracted from all the features, and the optimal features are selected from this subset for splitting, rather than the global best. This helps prevent a single decision tree from overfitting. |
|Layered lifting tree |The layer lift tree is an ensemble learning model that uses a decision tree internally. Unlike random forest, it trains only one tree at a time, and each new decision tree gradually corrects the errors generated by the previous decision tree. As the tree is added, the model becomes more expressive. |



4. **Clustering**


The following models are supported, see the Features page for details.


|Model name |Model introduction |
|---|---|
|K\-means clustering |K\-means (K\-means) algorithm is a typical clustering algorithm based on distance, which uses distance as a similarity evaluation index. After specifying the K initial cluster centers (initial cluster mean centers), calculate the distance between each sample and the K cluster mean centers, divide it into the cluster to which the nearest cluster mean center belongs, and update the cluster mean center after each division. Recalculate the distance between each sample and the cluster mean center until the given sample has been clustered to the K clusters and the cluster mean center no longer changes. |
|Gaussian Mixture |Gaussian mixture clustering is to quantify things accurately with Gaussian probability density function (normal distribution curve), and the sample points can be clustered into several clusters formed based on Gaussian probability density function (normal distribution curve). Theoretically, any continuous function can be fitted, but the disadvantage is that it requires a large amount of computation. |
|Binary K\-Mean |The bipartite K\-means clustering algorithm is a variant of the K\-means clustering algorithm, mainly to improve the randomness of the random selection of the initial centroid of the K\-means algorithm, resulting in the uncertainty of the clustering results, while the bipartite K\-means algorithm is less affected by the random selection of the initial centroid. |

It is recommended to preprocess the data before training; the algorithm applied by XGBoost is gradient boosted decision tree (GBDT), which can be used for both classification and regression problems. Order\-preserving regression is a problem where given a finite set of real numbers Y = {y_1, y_2,..., y_n}, Y represents known observations, and X = {x_1, x_2,..., x_n} represents unknown values, our goal is to find the minima of the function f (x) = sum_ {i = 1} ^ n w_i (y_i \- x_i) ^ 2 and guarantee x_1 to x_n. |



6. **Time series**


**The ARIMA model** regards the data sequence formed by the predicted object over time as a random sequence, and uses a certain mathematical model to approximately describe this sequence. Once this model is identified, it can predict future values from past and present values of the time series. It can help enterprises make predictions about the future, thus guiding them to make next decisions.

Application scenarios: stock market forecast and analysis, supermarket market turnover forecast and analysis, house price forecast and analysis, employee turnover forecast and analysis, product sales forecast and analysis, weather forecast and analysis, etc.


7. **Evaluate**


The following evaluation models are supported, see the Features page for details.


|Model name |Model introduction |
|---|---|
|Binary assessment |This performance evaluation operator should be used for classification tasks, i.e. when the label attribute has a binary variable value type. The input to this operator is a test sample set containing an attribute with a label role and an attribute with a prediction role. The operator computes and outputs a performance vector containing performance criteria based on these two properties. |
|Multi\-class evaluation |This performance evaluation operator should be used for classification tasks, i.e. when the label attribute has a (multi\-score) character value type. The input to this operator is a test sample set containing an attribute with a label role and an attribute with a prediction role. The operator computes and outputs a performance vector containing performance criteria based on these two properties. |
|Cluster evaluation |This performance evaluation operator is used to evaluate the clustering model performance. This operator wants to input a test sample set that contains a column with a prediction role and a column with all features. |
|Regression evaluation |This performance evaluation operator should be used for classification tasks, i.e. when the label attribute has a numeric value type. The input to this operator is a test sample set containing an attribute with a label role and an attribute with a prediction role. The operator computes and outputs a performance vector containing performance criteria based on these two properties. |
|Timing evaluation |This performance evaluation operator should be used for time series tasks, i.e. when the label attribute has a numeric value type. The input to this operator is a test sample set that contains an attribute with a label role and an attribute with a prediction role. Based on these two attributes, the operator computes and outputs a performance vector containing performance criteria values. |
