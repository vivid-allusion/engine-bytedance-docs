Enterprise Knowledge Engine supports accessing Lark cloud documents. This article describes how to access Lark cloud documents.

<span id="4aea6ae7"></span>
# Usage restrictions

Currently supports access to Lark cloud documents, but does not include Lark tables, Bitable, and Lark knowledge bases (planned).

<span id="04d2fe14"></span>
# Operation steps


1. In the console, select **Data Access \> Knowledge Access**, then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/14c3d4a96b2e491096bd6c1fb0db8e10~tplv-goo7wpa0wc-image.image) </span>

2. Select **Lark Cloud Documentation** on the Data Connection page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/27dbc3b8e6cd4a27a60b58e4c2c2ddc6~tplv-goo7wpa0wc-image.image) </span>

3. Customize the **data connection name** , authorize and import Lark cloud documents through Lark.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">After Lark is authorized, only Lark cloud documents that authorized users have permissions can be imported (specific permissions follow the permission management logic of Lark cloud documents).   </div>
   

   * **Quick Add** : After the authorization is completed, you can get the Lark cloud document with permission, and then tick the document that needs to be imported.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/98793ca6c3214f00946dae2fbe7460ab~tplv-goo7wpa0wc-image.image) </span>

   * **Link Add** : Enter a cloud document link with permissions to import the document, and support adding multiple.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/98739108d5994f608776b8187b546a12~tplv-goo7wpa0wc-image.image) </span>

4. After selecting the document, click **Test Connection** in the upper right corner of the page to ensure that the data connection is successful.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/90197420fa274a01a06be8145f9908df~tplv-goo7wpa0wc-image.image) </span>

5. Click **Save** in the top right corner of the page.

   After saving, you can view the imported document information and lineage views in the data connection details.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8a23abf2550e4a56aea31277e93019f1~tplv-goo7wpa0wc-image.image) </span>

6. In the upper right corner of the data connection details page, select **Application** \> **Create Visual Modeling** , and one\-click jumping for visual knowledge processing.

   See the specific operation of visual knowledge processing [Data Cleaning](https://docs.byteplus.com/docs/dataagent/Data_Cleaning_).

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e68b6787ea244469a20af4048e06f988~tplv-goo7wpa0wc-image.image) </span>
