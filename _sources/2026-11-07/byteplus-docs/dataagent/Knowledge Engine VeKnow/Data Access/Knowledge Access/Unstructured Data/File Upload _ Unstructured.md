Enterprise Knowledge Engine supports uploading files of unstructured data. This article shows you how to upload files in a data connection in Enterprise Knowledge Engine.

<span id="a78acee0"></span>
# Operation steps


1. In the console, select **Data Access \> Knowledge Access**, then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/14c3d4a96b2e491096bd6c1fb0db8e10~tplv-goo7wpa0wc-image.image) </span>

2. On the Data Connection page, select **Upload file _ Unstructured** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ee3efd8b0cf849a2b3ce52eabdc4049c~tplv-goo7wpa0wc-image.image) </span>

3. Fill in the data connection name and upload the file.

   Files support docx, doc, pptx, ppt and other formats, and are unlimited in number and size.

4. Once the upload is complete, click **Test Connection** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/470556fd027443a8b161a93efd90ce10~tplv-goo7wpa0wc-image.image) </span>

5. Once connected, click **Save** .

6. Click **Apply \> Create Visual Modeling** , and the system will jump to the Visual Modeling interface.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/55cb19db1a044758b1f79d6386758944~tplv-goo7wpa0wc-image.image) </span>

7. In the visual modeling interface, perform data processing configuration. See the specific operation [Data Cleaning](https://docs.byteplus.com/docs/undefined/69e5923241fe2d05219887dc).

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e439fb149fc54520b3597531f67dd6b7~tplv-goo7wpa0wc-image.image) </span>
