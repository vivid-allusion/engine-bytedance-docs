Supports PostgreSQL data connection. This article explains how to access PostgreSQL data.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Before you connect to the data, collect the following information:</div>



* <div data-tips="true" data-tips-type="tip">The IP address and port number of the server where the database is located.</div>


* <div data-tips="true" data-tips-type="tip">The name of the database.</div>


* <div data-tips="true" data-tips-type="tip">Driver information (generally defaults to org.postgresql. Driver, no need to modify it);</div>


* <div data-tips="true" data-tips-type="tip">The username and password for the database.</div>



<span id="a02fa787"></span>
# Premise of use

The user needs to have **project editing** or **permissions \- by user management \- module \- data connection \- new connection** permissions to create a new data connection.

# 3. Operation steps


1. Click on **Data Management \- Data Connections** .

2. Click **New Data Connection** in the upper left corner and select **Relational Database \- PostgreSQL** in the jump page.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8f351cb7339f43918b48dc746c78aed7~tplv-goo7wpa0wc-image.image) </span>

3. Fill in the required basic information and make a **test connection** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/19603ca9184746b7a0aa1ef0a7e3dd35~tplv-goo7wpa0wc-image.image) </span>

4. Click **Save** after successful connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/10067d30970241a9b1327618a2328519~tplv-goo7wpa0wc-image.image) </span>
