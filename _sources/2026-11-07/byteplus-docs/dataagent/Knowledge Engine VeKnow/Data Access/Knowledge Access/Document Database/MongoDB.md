Support MongoDB data connection, this article describes how to access MongoDB.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Before you connect to the data, collect the following information:</div>



* <div data-tips="true" data-tips-type="tip">The IP address and port number of the server where the database is located.</div>


* <div data-tips="true" data-tips-type="tip">The name of the database.</div>


* <div data-tips="true" data-tips-type="tip">The username and password for the database.</div>



<span id="ac041f4a"></span>
# Premise of use

The user needs to have **project editing** or **permissions \- by user management \- module \- data connection \- new connection** permissions to create a new data connection.

# Operation steps


1. In the console, select **Data Access \> Knowledge Access**, then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/14c3d4a96b2e491096bd6c1fb0db8e10~tplv-goo7wpa0wc-image.image) </span>

2. On the Data Connection screen, select **Document Database** \- **MongoDB** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/65b2f668f8944da5a0fe4f0d6ace6fc6~tplv-goo7wpa0wc-image.image) </span>

3. Fill in the required basic information and make a **test connection**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0f7172bfad86424d81cbc69b0ac12ba3~tplv-goo7wpa0wc-image.image) </span>



|name |describe |
|---|---|
|server |The address to deploy the MongoDB BI connector (Mongosqld service). |
|Port |The port of the MongoDB service. |
|database |Customized database name when deploying a MongoDB database. |
|Username and password |The username and password to log in to the MongoDB database. |



4. Click **Save** after successful connection.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f8ddbe02efcd447994f0ac55ab75cb96~tplv-goo7wpa0wc-image.image) </span>
