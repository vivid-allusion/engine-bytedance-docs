Access data connection is supported. This article shows you how to access Access data.

<span id="82646c58"></span>
# Usage Restrictions

Users need to have "Project Edit" or "Permissions \- Manage by User \- Module \- Data Connection \- New Connection" permissions to create a new data connection.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/06cd3d16a74745d99273ddd5d04f9cca~tplv-goo7wpa0wc-image.image) </span>

<span id="a526055f"></span>
# Operation Steps

<span id="0ce56b16"></span>
## New data connection


1. In the console, select **Data Access \> Knowledge Access**, then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/14c3d4a96b2e491096bd6c1fb0db8e10~tplv-goo7wpa0wc-image.image) </span>

2. Select **Local File \- Access**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d8e58daa39ab4e4b8cba73df64c25ec1~tplv-goo7wpa0wc-image.image) </span>

3. Upload data, fill in the **data connection name**, optional **user name** and **password**, click **Next.** 

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Support for uploading local Access database files (.mdb, .accdb), with a maximum file size of 4GB.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/975afe50f03848b387dc5e05ee0216a0~tplv-goo7wpa0wc-image.image) </span>

4. Select the table and click **Next.** 

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2dad009e87714b3da6b56d88871dc079~tplv-goo7wpa0wc-image.image) </span>

5. To preview, click **Finish** after the preview content is correct.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/46dd6ee1f4e8444ebdc4388e9c0e0401~tplv-goo7wpa0wc-image.image) </span>


<span id="9daf5c23"></span>
## Data update

When users need to update an Access file, they can click "Update File" and upload a new Access file, select the table to preview, and complete the update.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fd2683137f154755a6ab23eb0aafe135~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/79b5510f80954090a280bc7f7b37f93a~tplv-goo7wpa0wc-image.image) </span>

## Permission assignment

<span id="94c03653"></span>
### Authorization

Click the authorization button in the upper right corner of the data connection to authorize the data connection to other users. If you need to authorize multiple users, you can separate them with English commas and paste them into the box, such as user1, user2. Authorization items include: viewing, editing, and managing.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/71fa55d251d2432982ceeaf76a6c816b~tplv-goo7wpa0wc-image.image) </span>

<span id="69cfffed"></span>
### Transfer owner

Click on the three points on the data connection to select the "Transfer Owner" button to transfer ownership.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2bb1eb3622004b05ab43e345a2cb8463~tplv-goo7wpa0wc-image.image) </span>

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/854e778975de497d882d8a0b4889fc95~tplv-goo7wpa0wc-image.image) </span>

<span id="7e89bdc0"></span>
## Basic information view

Hover your mouse over the corresponding data connection to view the details of that data connection, including its name, creator, and creation time.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d944204c78b543399f1da54daf7bec54~tplv-goo7wpa0wc-image.image) </span>

<span id="e330f0e7"></span>
## Data source deletion

Click on the three points on the data connection and select the "Delete" button to delete the data connection.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/35e7cc04a054448bba3422634a7c8cba~tplv-goo7wpa0wc-image.image) </span>
