After creating a new enterprise knowledge base, the basic information and member permissions for configuring the knowledge base are supported in the knowledge base details page.

# Usage restrictions

The Structured Data Type Knowledge Base does not currently support membership and permission management.

# Operation steps

1. Log in to the Marketing Agent console.

2. Select **Enterprise Knowledge Engine** in the left navigation bar.

3. In the left navigation bar of Enterprise Knowledge Engine, select **Knowledge Management** \> **Enterprise Knowledge Base**.

4. Go to the specified knowledge base details page and click the **knowledge base settings** icon in the upper right corner of the page.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1d7a8037ad764853965eb42d21467ba3~tplv-goo7wpa0wc-image.image)

5. In the **basic information** tab, support editing name, description.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/34c2723424934b9ca21a779f6e3ca6f6~tplv-goo7wpa0wc-image.image)

6. In the **Members and Permissions** tab, support by **user**, **role**, **department** dimension management users to the current knowledge base of **view**, **edit**, **manage** permission.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e99587334d494664ad4bd37304c23d02~tplv-goo7wpa0wc-image.image)

7. Click **Add Authorization**, on the Authorization page, you can grant permissions to the current knowledge base for the specified objects, and click **Save** when the configuration is complete.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2f65c9043cd140a5ac2df211f8bd7fbb~tplv-goo7wpa0wc-image.image)

   * **Grant permissions:**  radio, you can choose to **view**, **edit**, **manage**.

   * **Authorization scope:**  single selection, you can choose **only current resources** (does not affect downstream content), **current resources and all downstream resources**.

   * **Authorization object:**  Support by **user**, **role**, **department** dimension, batch selection of authorization objects.
