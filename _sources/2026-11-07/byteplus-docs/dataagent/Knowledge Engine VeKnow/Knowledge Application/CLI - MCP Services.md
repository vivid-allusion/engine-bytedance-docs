Enterprise Knowledge Engine provides CLI and MCP methods for your agents to access and use Knowledge Engine services. This article describes how to use the CLI/MCP service.

# Operation steps

1. Log in to the Marketing Agent console.

2. Select **Enterprise Knowledge Engine** in the left navigation bar.

3. In the left navigation bar of Enterprise Knowledge Engine, select **Knowledge Applications** \> **CLI/MCP Services**.

4. On the **CLI/MCP services** page, the following information is available.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/261963c831084237b29a47ca93234c13~tplv-goo7wpa0wc-image.image)

   |**Information item** |**Description** |
   |---|---|
   |Access key |Personal Token, used for MCP authentication. Support copy, view, reset. |
   |CLI |On the **CLI** tab, you can get how to install and log in to the Enterprise Knowledge Engine CLI. You can follow the instructions to complete the installation, login, and verification of the CLI. |
   |Skills |After installing the CLI, on the **Skills** tab, you can get the usage scenarios and operation instructions of each Skills to help you get started with the knowledge engine service in the Agent. |
   |MCP |On the **MCP** tab, you can access the Enterprise Knowledge Engine MCP. You can follow the instructions to connect the MCP Server to the Agent and use the built\-in Enterprise Knowledge Engine tool. |
