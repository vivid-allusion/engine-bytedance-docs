Intelligent Q&A is a knowledge retrieval tool built into the enterprise knowledge engine. Combined with intelligent retrieval and large model capabilities, it can conduct multiple rounds of conversations with users, summarize knowledge and answer questions accurately, and adjust Q&A strategies according to needs.

# Prerequisite

If you need a knowledge base of the specified range of questions and answers, you need to build the corresponding knowledge base first, and you can refer to the specific operation [Create a New Knowledge Base](https://docs.byteplus.com/docs/dataagent/Create_a_New_Knowledge_Base).

# Feature Overview

Intelligent Q&A includes the following features:

* The question\-and\-answer ability based on the knowledge base can also be based on all authorized knowledge content for question\-and\-answer.

* Support for uploading files, online search, and deep thinking.

* Support multi\-round dialogue, regeneration, like, click, copy and other functions.

* Support to view historical question and answer records, knowledge data statistics and other information.

# Usage restrictions

* Global retrieval in Q&A only supports retrieving knowledge bases that the currently logged in user has permissions to.

   Knowledge Base Permissions Description: Personal knowledge bases are visible only by themselves; enterprise knowledge bases can flexibly set permissions, see for details [Manage Enterprise Knowledge Base Permissions](https://docs.byteplus.com/docs/undefined/6ad0b685b0e56c051e6a56ac).

* The intelligent question answering function isolates knowledge by project and does not support cross\-project retrieval of knowledge.

# Operation steps

1. Log into the Marketing Agent console and select **Data Management** \> **Enterprise Knowledge Engine** in the left navigation bar.

2. In the left navigation bar of the **Enterprise Knowledge Engine**, select **Intelligent Q&A**.

   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b3a7020b46b444bebf571057a7851031~tplv-goo7wpa0wc-image.image)

   The following configuration operations are supported:

   |**Operation area** |**Operating instructions** |
   |---|---|
   |In the top left corner of the page |Click the **conversation history** icon to view the conversation history.<br><br>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/887299c1b6194ae89c9b8baa2fb77e82~tplv-goo7wpa0wc-image.image) |
   |In the input box |* Click the **plus sign**( **+** ) to upload the file to the model service for inference.<br><br>   * You can upload up to 10 files, with a single file size of no more than 100MB.<br><br>   * Supported file formats: DOC/DOCX/WPS/TXT/MD, PDF/OFD, PPT/PPTX, CSV/XLSX, JPG/JPEG/PNG.<br><br>* Click the icon shown below to enable **online search** or **deep thinking**.<br><br>   ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/834096242fc64b61862105b5517b60e5~tplv-goo7wpa0wc-image.image)<br><br>* In the **Global Search** drop\-down list, ask questions based on the knowledge base content you configured. Support switching to the specified enterprise knowledge base, personal knowledge base or ontology semantics, Knowledge Graph, and subsequent Q&A will be conducted within the specified scope. |
   |Below the text box |View knowledge statistics, sample questions, and knowledge leaderboard information. |

3. Click the text box and enter the question you want to ask. After completion, click Send to start a conversation with the AI.

   * In the output results, support for viewing source knowledge through corner markers or references, and support for downloading the original text.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9d3b686ffda34732959aabdb5a1c1184~tplv-goo7wpa0wc-image.image)

   * Support for regenerating results.

      In addition, it supports liking or clicking on the feedback of the Q&A results, and supports copying the content of the results.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/360f9bf8032d43c596e85a90bb1a291a~tplv-goo7wpa0wc-image.image)

   * Supports multiple rounds of conversation. During multiple rounds of dialogue, it supports uploading files, enabling or disabling online search or deep thinking functions, and adjusting the scope of the knowledge base.

      ![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/9b867169058849d285658e3df1c66776~tplv-goo7wpa0wc-image.image)

   * In the upper left corner of the page, it supports viewing historical conversations and opening new conversations.
