The visit statistics page displays the number of active users, usage times, and other information under the project to help you understand the usage of project members; supports filtering by users/usage methods/modules/dates, etc.; supports viewing detailed data, such as the number of active users, total visits, etc. This article introduces you to the use of access statistics.

<span id="ddc970e5"></span>
# Function entrance


1. Log into the Marketing Agent console and select **Enterprise Knowledge Engine** in the left navigation bar.

2. In the left navigation bar of the Enterprise Knowledge Engine, select **Project Center** \> **Statistics** \> **Access Statistics** .

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/badda80260ea48dfa3bee9e1a0c8b44d~tplv-goo7wpa0wc-image.image) </span>

# Interface introduction


1. You can filter access to statistics by various fields.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8555dc311e2b4d13b02f07554a033a27~tplv-goo7wpa0wc-image.image) </span>

   
   |filter field |explain |
   |---|---|
   |Select project |You can choose the current project or all projects. Project refers to the project created in the upper right corner of the console.<br><br><span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fef2e5d51c2d40e8ad9292d00698167e~tplv-goo7wpa0wc-image.image) </span> |
   |How to use |* Q & A app: used through intelligent Q & A.<br><br>* API: Used through the API.<br><br>* Search Test: Use by search. |
   |Select Module |* Knowledge base: A specific knowledge base created in knowledge management.<br><br>* Knowledge Graph: A concrete Knowledge Graph created in knowledge management.<br><br>* Ontology semantics: Select the concrete object type and relationship type for the internal or external query. |
   |Select user |Select the user to use. |
   |business date |Filter the date of the visit. |
   |delete users |Exclude users who are not included in the statistics, such as test users. |
   

2. Examine core metrics, including total usage and number of active users.
