Before accessing Lark cloud documents as enterprise knowledge, enterprise administrators need to refer to this article to complete the cloud document access process in the console.

<span id="91f52511"></span>
# Operation steps


1. Log in to the Marketing Agent console.

2. Select **Enterprise Knowledge Engine** in the left navigation bar.

3. In the left navigation bar of Enterprise Knowledge Engine, select **Group Settings** \> **Cloud Document Access**.

4. Select the cloud document access method that needs to be configured in the page, and enter the configuration details page.

5. Follow the page instructions to complete the configuration in sequence.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/907c7d578eb84662a6e0436ef40fd393~tplv-goo7wpa0wc-image.image) </span>

6. After the configuration is complete and saved, confirm that the status of the cloud document access is **connected**.

   Support **modifying configuration** and **deleting configuration**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/87f13f5ee1a542bfbc8bd0a3f2a98bb5~tplv-goo7wpa0wc-image.image) </span>
