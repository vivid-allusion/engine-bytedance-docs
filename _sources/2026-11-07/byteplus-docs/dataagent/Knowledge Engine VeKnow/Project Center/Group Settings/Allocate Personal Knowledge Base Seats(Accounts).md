Enterprise administrators can manage employees' personal knowledge base access seats in the console, and only after assigning seats can corresponding employees create and use personal knowledge bases.

<span id="12f1b097"></span>
# Operation steps


1. Log in to the Marketing Agent console.

2. Select **Enterprise Knowledge Engine** in the left navigation bar.

3. In the left navigation bar of Enterprise Knowledge Engine, select **Group Settings** \> **Personal Knowledge Base Seats**.

4. In the top right corner of the page, click **Assign users** and add one or more users to the pop\-up window.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d7059e0b98fe47e8b2f34042403aeee9~tplv-goo7wpa0wc-image.image) </span>

5. Click Save to view user information in the list to support deleting users.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b4abb20babd54138a4cb036b3b4a3c18~tplv-goo7wpa0wc-image.image) </span>
