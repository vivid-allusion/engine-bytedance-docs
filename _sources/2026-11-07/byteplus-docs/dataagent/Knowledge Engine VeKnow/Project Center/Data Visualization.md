The data lake visualization function is used to view the knowledge of API and intelligent Q & A usage, including the total number of users, the total number of knowledge bases, the total number of intelligent Q & A, and the knowledge leaderboard. This article describes how to view the data lake visualization indicators.

<span id="2ecad953"></span>
# Operation Steps


1. Log in to the Marketing Agent console.

2. Select **Enterprise Knowledge Engine** in the left navigation bar.

3. In the left navigation bar of Enterprise Knowledge Engine, select **Project Center** \> **Statistics** \> **data lake visualization**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1c1bb4f4f1ff44879c2ded5593376f58~tplv-goo7wpa0wc-image.image) </span>

   In the data lake visualization feature, the following information is supported:

   * **Core indicators** **Kanban** : Kanban displays the total number of users, the total number of knowledge bases, the total number of analytical knowledge and the total number of intelligent Q & A.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/54f006fac29a470a8d881b26e8e60a4e~tplv-goo7wpa0wc-image.image) </span>

   * **Knowledge Ranking** : Display the knowledge of the top three recalls.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6f3c115c19a54ff889db70278c56227d~tplv-goo7wpa0wc-image.image) </span>

   * **Knowledge base rankings** and **knowledge rankings** : The rankings display all knowledge bases and knowledge lists in descending order according to the number of recalls. Support setting filter criteria (creator or knowledge base) to filter leaderboard information, and support clicking the knowledge base name or knowledge name to jump to view details.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ba8812da75594997bfb1b0a84d9ab020~tplv-goo7wpa0wc-image.image) </span>
