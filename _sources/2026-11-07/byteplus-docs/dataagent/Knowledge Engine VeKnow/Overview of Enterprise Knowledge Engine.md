Enterprise Knowledge Engine is an enterprise\-level knowledge management platform based on AI big model and big data technology. This article will introduce the function overview, features, and application scenarios of Enterprise Knowledge Engine to help you quickly understand the capabilities of Enterprise Knowledge Engine.

<span id="52a2da9f"></span>
# Function introduction

Relying on Volcano Engine's advanced large\-scale model and big data technology, Enterprise Knowledge Engine is oriented towards various intelligent agent application scenarios in enterprises. It has the ability to manage and apply knowledge of structured and unstructured data from access, processing, modeling, mining to application, etc. It can play a role in intelligent knowledge answering, product recommendation marketing, knowledge summary analysis and other scenarios, helping enterprises to fully explore the value of various types of knowledge in the era of large\-scale models.

The product has rich knowledge access methods, linkage of high\-quality datasets to supplement three\-party knowledge, multi\-type knowledge base management, visual knowledge processing, diversified knowledge slicing strategies, and other basic capabilities. It is also equipped with GraphRAG Knowledge Graph, ontology modeling, and refined authority management and control core capabilities. It supports a variety of sales models, and can be equipped with value\-added functions. It can be purchased on demand, and can be combined with intelligent analysis agents, intelligent marketing agents, and user research agents. It is compatible with the full range of Volcano Ark models and privatized open\-source models at the large model level. Special private models can be evaluated or customized for docking and adaptation.

## Functional features

The functional characteristics of the enterprise knowledge engine are mainly reflected in "complete data, deep understanding, accurate questions, wide use, and manageable". This is a multi\-source and multi\-modal data, using large models and Knowledge Graph to deeply model enterprise knowledge, and then through open and manageable question answering and agent capabilities, it can quickly deliver "landing, scalable, and manageable" intelligent knowledge applications in multi\-industry scenarios.


*  **[Wide coverage: multi\-source and multi\-modal global access]**  Support 40 + data sources and multi\-modal content access, which can uniformly manage internal data, external knowledge, and public domain data to achieve "one\-time access, full scene reuse".

*  **[Deep understanding: strong AI processing and knowledge modeling capabilities]**  With 50 + data processing operators and visualization preprocessing capabilities, support flexible slicing, GraphRAG, Knowledge Graph, ontology modeling and multi\-hop reasoning, so that knowledge can be related, excavated, and reasoning.

*  **[Ask accurately: intelligent Q & A can be configured and optimized]**  Support knowledge classification management, recall testing, multi\-round dialogue, contextual memory, Q & A strategy tuning, greatly reduce illusion, improve answer accuracy and business fit.

*  **[Widely used: open and easy to integrate, suitable for all kinds of agents]**  Provide full\-link API and plug\-in ability, which can quickly connect enterprise systems and various agent platforms, realize permission isolation, multi\-agent sharing of the same knowledge base, and avoid repeated construction.

*  **[Managed: Enterprise\-level security and permission control]**  Support document\-level/field\-level/line\-level permissions, version management, life cycle, operation audit and data desensitization to meet enterprise compliance, confidentiality, security control requirements.

## Data access

In order to meet the daily demands of data access and development, Enterprise Knowledge Engine provides data access modules to assist data developers in data processing, including data sets, data connections, data processing, and other functions.


* Knowledge access: The system provides 40 + data connection methods, including but not limited to relational databases (e.g. MySql, Oracle, SQL Server, DB2, etc.), big data platforms (e.g. Hive, Impala, Clickhouse, etc.), MPP databases (Postgre, etc.), streaming databases (Kafka, etc.), text data (Excel, CSV), API interfaces, etc. It can not only connect with the customer data and business data access of various business companies within the customer (such as membership system, member mid\-platform system, etc.), but also connect with the official website, APP, official account, Mini Program, service number and other data sources.

* Visual data processing: The system has built\-in lightweight data cleaning and visual modeling capabilities, supports adding data processing nodes in the form of drag and drop, and performs cleaning operations such as filtering, deduplicating, and replacing data. After data cleaning is completed, the processed data can be output to the target source, reducing the cost of deep data governance.

* Data Sources: Supports linking relational databases, WeChat libraries, and object stores to the Enterprise Knowledge Engine as data sources.

* Dataset: A dataset is a data model composed of one or more tables, which is the basis for creating labels, clustering, and insights. Before applying data, it is necessary to connect the data to the source data information and output it as a dataset through visual modeling functions.


For more information, please see [Data Access Overview](https://docs.byteplus.com/docs/dataagent/Data_Access_Overview).

## Knowledge Graph

The main Knowledge Graph in the knowledge base displays the logical relationship between knowledge (such as concept subordination, attribute association, causal connection) through visual association to achieve knowledge structuring and deep mining. It is suitable for scenarios where complex knowledge associations need to be clarified and related information can be efficiently located. It is especially suitable for cross\-domain knowledge integration, complex problem traceability analysis, and intelligent recommendation of related knowledge. This article shows you how to create a principal Knowledge Graph in an enterprise knowledge engine.

For more information, please see [Knowledge Graph](https://docs.byteplus.com/docs/dataagent/Knowledge_Graph).

## Agent modeling

Subject modeling automatically extracts subjects (such as people, cars, shops, etc.) and their related entity attributes (such as ID card, geographical location, etc.) from the original document through the combination of knowledge base and Knowledge Graph, and builds the subject base. It is suitable for scenarios such as multi\-scenario knowledge classification of the same document, collection of similar knowledge of multiple documents, and construction of enterprise multi\-subject libraries. It can significantly improve the efficiency of data management, enhance the data support capabilities of upper\-level applications (such as AI Q & A, marketing push), and meet various complex business needs.

# Operation process

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">To avoid compatibility issues, we recommend that you use the latest version of Google Chrome browser to access the platform.</div>


The relevant operations of the enterprise knowledge engine are as follows:


1. **Knowledge Access:** 

   * To create a knowledge base, see [Create a New Knowledge Base](https://docs.byteplus.com/docs/dataagent/Create_a_New_Knowledge_Base).

   * Import knowledge content, please refer to the specific operation [Import Knowledge](https://docs.byteplus.com/docs/dataagent/Import_Knowledge).

2. **Knowledge processing:** 

   * Set labels, valid period and other operations on knowledge content, please refer to the specific operations [Manage Knowledge](https://docs.byteplus.com/docs/dataagent/Manage_Knowledge).

3. **Knowledge recall and debugging:** 

   * Enter keywords, complete the recall of paragraphs, and evaluate the recall accuracy based on various indicators. Please refer to the specific operation [Manage Knowledge](https://docs.byteplus.com/docs/dataagent/Manage_Knowledge).

   * By combining the knowledge base and Knowledge Graph, the subject and its related entity attributes are automatically extracted from the original document, and the subject base is constructed to improve the accuracy of knowledge retrieval.

   * Combining Knowledge Graph and vectorization technology to realize enhanced retrieval and generation capabilities based on graph structure, please refer to the specific operation [Knowledge Graph](https://docs.byteplus.com/docs/dataagent/Knowledge_Graph).

4. **Application of knowledge:** 

   * Zero code to build AI Agent, specific operations see [User Case: Customer Service / Sales Scenarios](https://docs.byteplus.com/docs/dataagent/User_Case_Customer_Service_Sales_Scenarios)and [User Case: Knowledge Q&A Scenario](https://docs.byteplus.com/docs/dataagent/User_Case_Knowledge_Q_A_Scenario).

5. **Intelligent marking:** 

   * Analyze and mark dataset data based on AI large model to help enterprises quickly mine key information of data, please refer to the specific operation [Intelligent Marking Overview](https://docs.byteplus.com/docs/dataagent/Intelligent_Marking_Overview).

6. **Project management:** 

   * Set the user permissions of the knowledge base, functions and other modules, please refer to the specific operation [Authorization Management](https://docs.byteplus.com/docs/dataagent/Authorization_Management__).

   * View model and asset usage, see [Visit Statistics](https://docs.byteplus.com/docs/dataagent/Visit_Statistics), [Data Visualization](https://docs.byteplus.com/docs/dataagent/Data_Visualization), [System Monitoring](https://docs.byteplus.com/docs/dataagent/System_Monitoring).

   * Connect to OpenAPI, please refer to the specific operation [Open API](https://docs.byteplus.com/docs/dataagent/Open_API).
