## Key features

BytePlus SMS supports the following in the current release:


* **API\-based sending capability**: Supports sending text messages directly with SMS APIs available in a variety of popular programming languages and protocols like HTTP, HTTPS, and more.

* **Real\-time monitoring**: Visual charts display key metrics like send volume and delivery rate, with historical record tracking.

* **Business adaptability**: Allows you to create message groups to satisfy different business scenarios. In a message group, you can define the types of text messages that can be sent, which countries or regions the text messages are allowed to be sent to, the signature used, and template available.

## Main benefits

BytePlus SMS offers you the following to power your business:


* **Global reach and massive scale**: Covers more than 230 countries and regions, cooperates with more than 700 global telecom partners, and supports transactional and high\-volume messaging services.

* **Highly stable and secure**: Provides advanced encryption technology to ensure the security of your communications and supplies multi\-mobile carriers that can be intelligently dispatched to maintain stability.

* **Communication flows for every interaction**: Enables you to design and send common types of text messages by using SMS templates and flexible APIs.
