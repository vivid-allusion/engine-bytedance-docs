This topic explains core concepts for BytePlus SMS to help you understand its features and workflows.


* **One\-way SMS**: non\-reply messages where recipients cannot respond, primarily used for system notifications and critical announcements that require no interaction.

* **Bulk messaging**: an application\-to\-person SMS messaging service that sends large numbers of SMS messages to mobile phones of a predetermined group of receipts. Common uses include product promotions, informational communications, and transactional alerts.

* **Conversion rate**: measures how effectively messages drive desired actions (e.g., app sign\-ups, purchases).


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Conversion Rate = (Number of people took desired actions) ÷ (Total recipients) × 100%</div>



* **Delivery receipt (delivery report)** : a status response from mobile carriers/Short Messaging Service Centers (SMSC). Confirms which messages were successfully delivered and which failed.

* **Message group**: defines the types of messages that can be sent, the countries/regions where messages are allowed, the signature used, and the templates available for use.

* **Mobile terminated (MT)** : shows that a text message has been received by cellphone users. This is a type of message that flows from an SMS gateway to a smartphone, mobile device, or cell phone. MT messages are just like campaign messages that are sent to your subscriber’s mobile phones for marketing purposes.

* **Mobile originated (MO)** : initiated by mobile phone users, meaning that mobile phones reply text messages to the gateway.

* **Sender**: indicates the Sender ID, SID for short. The caller ID displayed in the user SMS interface is called Sender ID. Some countries support Alpha, a character type, while some countries support Numeric, a number type.

* **Signature**: the signature in the square brackets placed before or after the text\-message content, used to denote the sending company or business.

* **Template**: a pre\-defined message structure with length limitations.
