Manage and upload materials (e.g., documents, videos, images and audios) for non\-plain text messages sent via channels like WhatsApp. BytePlus provides material hosting with URLs valid for up to 30 days, ensuring reliable message delivery.

<span id="34d296e2"></span>
### Prerequisite

BytePlus Messaging has been activated.

<span id="0d0b7b29"></span>
### Context

BytePlus Messaging allows you to upload materials separately for different message types. Uploaded materials generate unique URLs, which are required when sending rich media messages. You can query, manage, and delete materials in the **Material Management** module.

<span id="4479f92e"></span>
### Procedure


1. Go to [BytePlus Messaging Console](https://console.byteplus.com/sms).

2. In the left navigation pane, click **Messaging** \> **Material Management**.


**Querying Materials**


1. Enter the Material name in the search field.

2. Set the Upload time range (start and end dates).

3. Click Query to filter materials by criteria.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ab472cbeca634a158c48b7213b13b9c7~tplv-goo7wpa0wc-image.image) </span>

**Uploading New Material**


1. Click  **+ Confirm Material** on the page. A pop\-up window will appear.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6e8a2c726dec487eba75633e98c2c186~tplv-goo7wpa0wc-image.image) </span>


2. In the pop\-up, fill in all the required fields.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1ea920d0730e457688b0a91ea8ead087~tplv-goo7wpa0wc-image.image) </span>


3. Click **Submit** to upload the material.


<span id="dbaadfe5"></span>
### Result

The material is uploaded and generates a valid URL for 30 days. Use this URL when sending rich media messages via supported channels.
