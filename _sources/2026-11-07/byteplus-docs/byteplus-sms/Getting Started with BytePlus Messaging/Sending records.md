View and manage sending records of SMS and WhatsApp messages. Query real\-time sends data, export records, and track task statuses to monitor message delivery effectiveness.

<span id="4bc89cc9"></span>
### Prerequisite


1. BytePlus Messaging has been activated.

2. Message sending operations (via SMS or WhatsApp channels) have been carried out. These prior sending activities generate the records that can be viewed and managed in the **Sending Record** module.


<span id="3cb57a17"></span>
### Context

When messages are sent via BytePlus Messaging, corresponding sending records will be generated. These records contain key information like message content, delivery status, recipient details, etc. The Sending Record module is designed to centrally display, query, and manage these records. It helps users track the delivery process of messages, verify whether messages reach recipients as expected, and analyze sending effectiveness.

<span id="bd6e1c42"></span>
### Procedure


1. Go to [BytePlus Messaging Console](https://console.byteplus.com/sms).

2. In the left navigation pane, click **Messaging** \> **Sending Record**.

3. The module has tabs for [SMS sending record](https://console.byteplus.com/sms/record/send?projectName=default&subAccountId=84e01f8f), [WhatsApp sending record](https://console.byteplus.com/sms/record/whatsapp?projectName=default&subAccountId=84e01f8f), and [Export task](https://console.byteplus.com/sms/record/export?projectName=default&subAccountId=84e01f8f) for tracking exports.


**Query Sending Records**


1. Go to the View and manage sending records of SMS and WhatsApp messages. Query real\-time sends data, export records, and track task statuses to monitor message delivery effectiveness.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d03dcbcb6a054a55b2854a84f51ba4fb~tplv-goo7wpa0wc-image.image) </span>

**Export Sending Record**


1. In the \*\*\*\* SMS sending record/WhatsApp sending record tab, click the **Export** button (next to the **Query** button).


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f4c2b794638b44e6a53a75d527a8682f~tplv-goo7wpa0wc-image.image) </span>


2. In the “**Record export**” pop\-up, comfigure export filter settings (e.g., Time zone, Mobile phone number format, ISO Code, etc.).

3. Click **Add** to create the export task. A notification will confirm task creation, and you can track it in the **Export task** tab.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/4c8c111da5954721b8a8c7a54f9bd15f~tplv-goo7wpa0wc-image.image) </span>

**Query Export Tasks**


1. Go to the **Export task** tab.

2. Set query filters (e.g., export date, channel, template, send status, etc.).

3. Click **Query** to view task status.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fac5155b76b74a128124722cecaaaf58~tplv-goo7wpa0wc-image.image) </span>

<span id="3fec9fe6"></span>
### Result

You may now analyze message performance, troubleshoot delivery issues, and optimize sending strategies by leveraging detailed sending records.
