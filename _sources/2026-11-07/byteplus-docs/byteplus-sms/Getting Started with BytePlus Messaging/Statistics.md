Analyze SMS/WhatsApp message\-sending performance over a specific time period.

<span id="09f8e070"></span>
### Prerequisite


1. BytePlus Messaging has been activated.

2. Messages have been sent via SMS/WhatsApp channels (to generate statistical data).


<span id="e5a821bc"></span>
### Context

When messages are sent through BytePlus Messaging, the system tracks metrics like total submissions and delivery failures. The Statistics module aggregates this data into visualizable graphs and exportable reports, helping monitor performance and optimize strategies.

<span id="e59c57b1"></span>
### Procedure


1. Go to [BytePlus Messaging Console](https://console.byteplus.com/sms).

2. In the left navigation pane, click **Messaging** \> **Statistics**.

3. The module has tabs for **SMS sending statistics** and **WhatsApp sending statistics** for tracking performance.


**Query Sending Statistics (SMS)** 


1. Go to **SMS sending statistics** tab.

2. Set filters (e.g., Message Group, Sending date, SMS Signature, Template Type, ISO Code).

3. Click **Query** to view results:

* A table lists data by date, including Total Submissions, No receipt received in 72h, Failure, and Receipt Success.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/bfdf2b8f56be44d1a0a0dcd05bfb6b63~tplv-goo7wpa0wc-image.image) </span>


* A timeline chart displays daily trends for submissions and failures.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5a7f0d3baba44c4095a4c376ec9f65cd~tplv-goo7wpa0wc-image.image) </span>

**Query Sending Statistics (WhatsApp)** 


1. Go to **WhatsApp sending statistics** tab.

2. Set filters (e.g., Message Group, Sending date, WABA account, Template Type, ISO Code).

3. Click **Query** to view results:

* A table lists data by date, including Template Type, Number of conversation, Total of Successfully, and Total of failures.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/17749f8d39794a3ba1cf6722c0be1ed5~tplv-goo7wpa0wc-image.image) </span>

**Export Statistics Result**

After querying, click **Export**. An Excel file that matches the structure and data of the queried table will be downloaded to your device.

<span id="6f0fc038"></span>
### Result

Now you can access real\-time metrics for SMS/WhatsApp sends, including submissions, success, failure and trends.
