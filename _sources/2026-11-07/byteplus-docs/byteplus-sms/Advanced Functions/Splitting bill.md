After [moving the message group into a project](https://docs.byteplus.com/zh-CN/docs/byteplus-sms/project-management), the sub\-accounting can be done according to the project dimensions, which solves the problem of financial cost allocation.

<span id="1fd076d1"></span>
## Basic concepts


* **Split item ID**: In the context of BytePlus SMS, split item ID means the message group ID of the SMS service.

* **Split Item name**: In the context of BytePlus SMS, split item name means the message group name of the SMS service.


<span id="8cece5e9"></span>
## Prerequisites


* Move the message group that needs sub\-accounting into the corresponding project. For details, refer to Managing Project Resources. If each message group needs to be billed separately, this step can be ignored.

* Go to the [Splitting bill page](https://console.byteplus.com/finance/bill/split-bill) to activate sub\-account billing.


<span id="438be0f5"></span>
## View splitting bill

Go to the [Splitting bill page](https://console.byteplus.com/finance/bill/split-bill) where you can query project sub\-account details from different perspectives.


* You can select a specific project to view the detailed bills under the project.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f02fbe83bd7a44e6826dd5adad884e95~tplv-goo7wpa0wc-image.image) </span>


* Select **Split item ID** to view and export the detailed bills under a specific message group ID. The Sub\-Item ID refers to the message group ID of the SMS service, and the Sub\-Item Name refers to the message group name of the SMS service.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/1f188ff392e84a229ebdb55f392a32f0~tplv-goo7wpa0wc-image.image) </span>


* Click **Summary distribution** to view the summary bill by project.
