Use the `CheckSmsVerifyCode` API to check whether a verification code generated by SendSmsVerifyCode API is effective or not. It's recommended you use SDK to call the CheckSmsVerifyCode API.

<span id="Request"></span>
## Request

**HTTP method**: POST

**URL**: `https://sms.byteplusapi.com?Action=CheckSmsVerifyCode&Version=2020-01-01&area=overseas`

**Header parameters**


|**Parameter** |**Type** |**Required** |**Value** |**Description** |
|---|---|---|---|---|
|AccessKey |string |Yes |AKLTNzEzY2\*\*\*\* |The access key ID of your BytePlus account. Click [here](https://console.byteplus.com/iam/keymanage) to obtain it. |
|SecretKey |string |Yes |RGTLuSHvnYxn\*\*\*\* |The secret access key ID of your BytePlus account. Click [here](https://console.byteplus.com/iam/keymanage) to obtain it. |
|ServiceName |string |Yes |volcSMS |The SMS service name. |
|Region |string |Yes |ap\-singapore\-1 |The service region name. |
|Content\-Type |string |Yes |application/json;charset=utf\-8 |The structured format of the request body. The Content\-Type of SMS service is application/json; charset=utf\-8. |


**Query parameters**


|**Parameter** |**Type** |**Required** |**Value** |**Description** |
|---|---|---|---|---|
|Action |string |Yes |CheckSmsVerifyCode |The name of this API. |
|Version |string |Yes |2020\-01\-01 |The version of this API. |


**Request body parameters**


|**Parameter** |**Type** |**Example of value** |**Description** |**Required** |
|---|---|---|---|---|
|SmsAccount |string |049c2666 |The message group ID. One of the primary keys for verification code. You must apply the verification code service first. |Yes |
|Scene |string |Test4 |Scenario for using the verification code. One of the primary keys for verification code. |Yes |
|PhoneNumber |string |+6598620548 |Recipient's mobile number. One of the primary keys for verification code. |Yes |
|Code |string |897665 |The verification code to be checked. Note : International area codes are required. The format must meet E.164 standards. |Yes |


**Example of request payload**

```json
{
    "SmsAccount": "A123****",
    "PhoneNumber": "152********",
    "Scene": "Register a verification code",
    "code": "591005"
}
```


<span id="Response"></span>
## Response

The returned result of checking the code verification result is related to the number of incoming retries. Within the validity period, if the number of retries is 0 and the checking fails, "2" is returned which means expired. If the number of retries is not 0 and the checking fails, "1" is returned, which means an error. Then if the cumulative number of errors exceeds a threshold, "2" is returned, which means expired.

|**Parameter** |**Type** |**Description** |
|---|---|---|
|ResponseMetadata |ResponseMetadata |The parameter values in your request headers |
|ResponseMetadata.RequestId |string |ID number of the request |

|ResponseMetadata.Version |string |The version of the request |
|ResponseMetadata.Service |string |The service requested |
