This topic helps you quickly master how to use SNAT rules for Internet NAT Gateways. You'll create an SNAT rule to enable Elastic Compute Service (ECS) instances to access the Internet through it.

&nbsp;

<span id=".5YeG5aSH5bel5L2c"></span>
## Preparations

Before you begin, complete the following preparations:


* You have registered a BytePlus account and completed real\-name authentication.

* Ensure that the total value of your account's [available balance](https://docs.byteplus.com/en/docs/6269/100429) and coupons applicable to Internet NAT Gateway is not less than 100.00 USD, and the available balance must be no less than 0. For specific operations, see [Recharge](https://docs.byteplus.com/en/docs/6269/100434).

* Create a Virtual Private Cloud (VPC) and subnets, and create multiple ECS instances without Elastic IP Addresses (EIPs) in the subnets. For related actions, see [Creating a VPC](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC) and [Purchasing an ECS](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

* Apply for 1 EIP not bound to any cloud resources. For procedure, see [Applying for an EIP](https://docs.byteplus.com/en/docs/eip/Applying-for-an-EIP).

* If using an IAM user, ensure it has the relevant permissions. If not, please contact the main account to grant the necessary permissions. For more information on the required permissions, see [What permissions an IAM user must have before they can create a NAT gateway](https://docs.byteplus.com/en/docs/natgateway/Identity-and-Access-Management-FAQ#.5a2Q55So5oi35Yib5bu6TkFU572R5YWz5pe277yM6ZyA6KaB5ZOq5Lqb5p2D6ZmQ77yf).

## Procedure


1. [Create NAT gateway](https://docs.byteplus.com/en/docs/51/10044#.5q2l6aqk5LiA77ya5Yib5bu65YWs572RTkFU572R5YWz): Create an Internet NAT gateway.

2. [Associate EIP to Internet NAT Gateway](https://docs.byteplus.com/en/docs/51/10044#.5q2l6aqk5LqM77ya5YWs572RTkFU572R5YWz57uR5a6a5YWs572RSVA=): Associate the pre\-prepared EIP to the newly created Internet NAT Gateway.

3. [Create SNAT rule](https://docs.byteplus.com/en/docs/51/10044#.5q2l6aqk5LiJ77ya5Yib5bu6U05BVOinhOWImQ==): Create an SNAT rule for the pre\-prepared ECS.

4. [Verification](https://docs.byteplus.com/en/docs/natgateway/Accessing-the-internet-using-SNAT#.5q2l6aqk5Zub77ya6aqM6K-B): Log in to an ECS instance and test whether it can access the Internet.


<span id=".5q2l6aqk5LiA77ya5Yib5bu65YWs572RTkFU572R5YWz"></span>
### Step 1: Create an Internet NAT gateway


1. Log in to [the Internet NAT Gateway console](https://console.byteplus.com/nat/nats).

2. In the top menu bar, select the region and project. This example uses **China (Beijing)**  and **default**.

3. Click **Create NAT Gateway**.

4. Configure relevant parameters based on the table below.

   
   |Parameter |Description |Sample value |
   |---|---|---|
   |Billing method |Select the billing method for the internet NAT gateway. |Pay\-as\-you\-go |
   |Region |Select the region where the internet NAT gateway is located. |China (Beijing) |
   |Name |Enter the name of the Internet NAT gateway. |nat\-1 |
   |Metering method |When the billing method is **Pay\-as\-you\-go**, select a metering method for the Internet NAT gateway. Supports [Pay-by-specification](https://docs.byteplus.com/en/docs/natgateway/Pay-as-you-go) and [Pay-by-CU](https://docs.byteplus.com/en/docs/natgateway/Pay-by-CU).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The metering method defaults to Pay\-by\-specification.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">With Pay\-by\-CU, you don't need to specify a specification. Performance scales dynamically based on demand, making it ideal for scenarios with significant traffic fluctuations.</div><br> |pay\-by\-CU |
   |Specification |Select the specification of the Internet NAT gateway. |Small |
   |VPC |Select the pre\-prepared VPC. |vpc01; 172.XX.XX.0/12 |
   |Subnet |Select a subnet from the dropdown list.<br><br>When selecting a subnet, please note the following:<br><br><br>* The subnet contains at least one available private IP. The network interface automatically generated by the system for the Internet NAT Gateway will occupy one private IP address in that subnet.<br><br>* The availability zone where the subnet is located must have Internet NAT Gateway resources deployed. You can view the availability zones with NAT resources at the top of the subnet selection page. |subnet01\|172.XX.XX.0/28 |
   |Affiliated project |Select the project to which the Internet NAT gateway belongs. |default |
   |Gateway mode |Select the mode of the Internet NAT Gateway\-According to your networking scenario. The mode of an Internet NAT Gateway cannot be changed after creation. Proceed with caution.<br><br><br>* Internet egress is an IPv4 Gateway: Please select **Non\-passthrough mode.**  After binding an EIP, you need to assign a separate private IP for each bound EIP. This can be combined with an [IPv4 Gateway](https://docs.byteplus.com/en/docs/vpc/IPv4-Gateway-Overview) to achieve granular management of internet traffic.<br><br>* Internet egress is an EIP: Please select **Pass\-through mode.**  After Associating EIP, a corresponding private IP is assigned simultaneously. In this case, the VPC where the NAT Gateway resides does not support the creation of an IPv4 Gateway. |Pass\-through mode |
   |Configuration mode |Select the configuration method of the Internet NAT gateway. |Manual configuration |
   |Tags |Add one or more user tags to the Internet NAT gateway as needed. |No tags added |
   

5. Click **Confirm order**.

6. Follow the console guidance to review and accept the legal terms, and click **Buy now** to complete the operation.

### Step 2: Associate EIP to the Internet NAT Gateway


1. In the NAT Gateway list, click **Configure EIP** to the right side of the Internet NAT Gateway created in step 1.

2. Click **Associate EIP**.

3. Select the pre\-prepared EIP from the dropdown list.

4. Click **OK** to complete the action.


<span id=".5q2l6aqk5LiJ77ya5Yib5bu6U05BVOinhOWImQ=="></span>
### Step 3: Create SNAT rule


1. In the Internet NAT Gateway List, click the name of the Internet NAT Gateway created in Step 1.

2. On the **SNAT rules** tab, click **Create SNAT rule**.

3. Configure relevant parameters based on the table below.

   
   |Parameter |Description |Sample value |
   |---|---|---|
   |Name |Enter the name of the SNAT entry. |snat\-1 |
   |Granularity |Select the granularity of the SNAT entry. |Subnet<br><br>subnet01\|172.XX.XX.0/28 |
   |EIP |Select the EIP associated with the Internet NAT Gateway. |180.XX.XX.44\|eip\-1 |
   

4. Click **OK** to complete the action.


<span id=".5q2l6aqk5Zub77ya6aqM6K-B"></span>
### Step 4: Verification


1. Log in to any ECS instance within the subnet that does not have an EIP bound.

2. Execute the `ping 8.8.8.8` command in the command line.

   After testing, the ECS instance can access the internet.
