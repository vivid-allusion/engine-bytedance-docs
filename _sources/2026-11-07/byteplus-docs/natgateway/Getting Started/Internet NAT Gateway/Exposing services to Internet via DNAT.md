This topic helps you quickly master the usage of DNAT rules by creating a DNAT rule for an Internet NAT Gateway, enabling a local computer to access the SSH remote login service of an Elastic Compute Service (ECS) through this rule.

<span id=".5YeG5aSH5bel5L2c"></span>
## Preparations

Before you begin, complete the following preparations:


* You have registered a BytePlus account and completed real\-name authentication.

* Ensure that the total value of your account's [available balance](https://docs.byteplus.com/en/docs/6269/100429) and coupons applicable to Internet NAT Gateways is not less than 100.00 USD, and the available balance must be no less than 0. For specific operations, see [Recharge](https://docs.byteplus.com/en/docs/6269/100434).

* Create a Virtual Private Cloud (VPC) and subnet, and create at least one Linux ECS instance without an EIP bound in the subnet. For related actions, see [Creating a Virtual Private Cloud](https://docs.byteplus.com/en/docs/vpc/Creating-a-VPC) and [Purchasing an ECS instance](https://docs.byteplus.com/en/docs/ecs/Using-the-wizard-to-buy-ECS-instances).

* Apply for 1 EIP not bound to any cloud resources. For procedure, see [Applying for an EIP](https://docs.byteplus.com/en/docs/eip/Applying-for-an-EIP).

* If using an IAM user, ensure it has the required permissions. If not, please contact the main account to grant the required permissions. For more information on the required permissions, see [What permissions an IAM user must have before they can create a NAT gateway](https://docs.byteplus.com/en/docs/natgateway/Identity-and-Access-Management-FAQ#.5a2Q55So5oi35Yib5bu6TkFU572R5YWz5pe277yM6ZyA6KaB5ZOq5Lqb5p2D6ZmQ77yf).

## Procedure


1. [Create NAT gateway](https://docs.byteplus.com/en/docs/51/10045#.5q2l6aqk5LiA77ya5Yib5bu65YWs572RTkFU572R5YWz): Create an Internet NAT gateway.

2. [Associate EIP to Internet NAT Gateway](https://docs.byteplus.com/en/docs/51/10045#.5q2l6aqk5LqM77ya5YWs572RTkFU572R5YWz57uR5a6a5YWs572RSVA=): Associate the pre\-prepared EIP to the newly created Internet NAT Gateway.

3. [Create DNAT rule](https://docs.byteplus.com/en/docs/51/10045#.5q2l6aqk5Zub77ya6YWN572u5a6J5YWo57uE): Create a DNAT rule for the pre\-prepared ECS.

4. [Configure security group](https://docs.byteplus.com/en/docs/51/10045#.5q2l6aqk5Zub77ya6YWN572u5a6J5YWo57uE): Allow inbound traffic on the private port specified in the DNAT rule for the ECS security group.

5. [Verify](https://docs.byteplus.com/en/docs/51/10045#.5q2l6aqk5LqU77ya6aqM6K-B): Test whether the local computer can access the SSH remote login service of the pre\-prepared ECS instance using the EIP and port of the DNAT rule.

### Step 1: Create an Internet NAT gateway


1. Log in to [the Internet NAT Gateway console](https://console.byteplus.com/nat/nats).

2. In the top menu bar, select the region and project. This example uses **China (Beijing)**  and **default**.

3. Click **Create NAT Gateway**.

4. Configure relevant parameters based on the table below.

   
   |Parameter |Description |Sample value |
   |---|---|---|
   |Billing method |Select the billing method for the internet NAT gateway. |Pay\-as\-you\-go |
   |Region |Select the region where the internet NAT gateway is located. |China (Beijing) |
   |Name |Enter the name of the Internet NAT gateway. |nat\-1 |
   |Metering method |When the billing method is **Pay\-as\-you\-go**, select a metering method for the Internet NAT gateway. Supports [Pay-by-specification](https://docs.byteplus.com/en/docs/natgateway/Pay-as-you-go) and [Pay-by-CU](https://docs.byteplus.com/en/docs/natgateway/Pay-by-CU).<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><br>* <div data-tips="true" data-tips-type="tip">The metering method defaults to Pay\-by\-specification.</div><br><br><br>* <div data-tips="true" data-tips-type="tip">With Pay\-by\-CU, you don't need to specify a specification. Performance scales dynamically based on demand, making it ideal for scenarios with significant traffic fluctuations.</div><br> |Pay\-by\-CU |
   |Specification |Select the specification of the Internet NAT gateway. |Small |
   |Virtual Private Cloud (VPC) |Select the pre\-prepared VPC. |vpc01; 172.XX.XX.0/12 |
   |Subnet |Select a subnet from the dropdown list.<br><br>When selecting a subnet, please note the following:<br><br><br>* The subnet contains at least one available private IP. The network interface automatically generated by the system for the Internet NAT Gateway will occupy one private IP address in that subnet.<br><br>* The availability zone where the subnet is located must have Internet NAT Gateway resources deployed. You can view the availability zones with NAT resources at the top of the subnet selection page. |subnet01\|172.XX.XX.0/28 |
   |Affiliated project |Select the project to which the Internet NAT gateway belongs. |default |
   |Gateway mode |Select the mode of the Internet NAT Gateway according to your networking scenario. The mode of an Internet NAT Gateway cannot be changed after creation. Proceed with caution.<br><br><br>* Internet egress is an IPv4 Gateway: Please select **Non\-passthrough mode.**  After binding an EIP, you need to assign a separate private IP for each bound EIP.    |Tags |Add one or more user tags to the Internet NAT gateway as needed. |No tags added |
   

5. Click **Confirm order**.

6. Follow the console guidance to review and accept the legal terms, and click **Buy now** to complete the operation.

### Step 2: Associate EIP to the Internet NAT Gateway


1. In the NAT Gateway List, click **Configure EIP** to the right side of the Internet NAT Gateway created in step 1.

2. Click **Associate EIP**.

3. Select the pre\-prepared EIP from the dropdown list.

4. Click **OK** to complete the action.


<span id=".5q2l6aqk5LiJ77ya5Yib5bu6RE5BVOinhOWImQ=="></span>
### Step 3: Create DNAT rule


1. In the Internet NAT Gateway List, click the name of the Internet NAT Gateway created in Step 1.

2. Click the **DNAT rules** tab and then click **Create DNAT rule**.

3. Configure relevant parameters based on the table below.

   
   |Parameter |Description |Sample value |
   |---|---|---|
   |Name |Enter the name for the DNAT rule. |dnat\-1 |
   |Protocol |Select protocol type. The SSH remote login service used in this topic only supports the TCP protocol. |TCP |
   |Private IP |Set the private IP address and port of the pre\-prepared ECS instance. The SSH remote login service used in this topic typically uses port 22. |192.XX.XX.34<br><br>22 |
   |EIP |Specify the EIP associated with the Internet NAT gateway and select a port to receive requests from the internet. The port range is 1–65535. |12.XX.XX.89\|eip\-01<br><br>33 |
   

4. Click **Create** to complete the action.


<span id=".5q2l6aqk5Zub77ya6YWN572u5a6J5YWo57uE"></span>
### Step 4: Configure security group


1. Log in to [the ECS console](https://console.byteplus.com/ecs/instance).

2. In the top menu bar, select the region: **China (Beijing)** .

3. Click the name of the pre\-prepared ECS instance.

4. Select the **Security Group \> Inbound** tab, and check whether the inbound rules allow traffic from the DNAT rule.

   * If already allowed, the configuration is complete and verification can proceed.

   * If not allowed, perform the following steps: add an inbound rule to allow the traffic specified by the DNAT rule.

      1. Click **Configure rule** on the right side of the target security group.

      2. On the Inbound rules tab, click **Add rule** to add the following inbound rules.

         
         |Parameter |Description |Sample value |
         |---|---|---|
         |Priority |Set the priority of the security group rule. Range: 1\-100. Default: 1, which is the highest priority. |1 |
         |Strategy |Select a strategy for the security group, supporting allow or deny. When priorities are equal, the deny policy takes precedence over the allow policy. |Allow |
         |Protocol type |Select the protocol for the security group. Supports TCP, UDP, and ICMP. |TCP |
         |Port range |Limit the port range based on different protocol types. |22 |
         |Source |Type in the IP address or CIDR block allowed to access ECSs within the security group.​​ |0.0.0.0/0 |
         

      3. Click **Confirm** to complete the action.


<span id=".5q2l6aqk5LqU77ya6aqM6K-B"></span>
### Step 5: Verification


1. Open the command line on your local computer and enter `ssh <EIP address set in the DNAT rule> -p <EIP port set in the DNAT rule>`.

2. If the SSH login page is accessible, it indicates that public network users can access the ECS instance's SSH remote login service via the Internet NAT Gateway's DNAT rule.
