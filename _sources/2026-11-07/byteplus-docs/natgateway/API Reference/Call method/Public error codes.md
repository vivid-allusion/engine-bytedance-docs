|HttpCode |**Error Code** |**Error Message** |
|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported or cannot be used. |
|400 |MissingParameter |The request is missing a required parameter. |
|500 |InternalError |An internal error has occurred. |


For more information on common error codes, refer to [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).
