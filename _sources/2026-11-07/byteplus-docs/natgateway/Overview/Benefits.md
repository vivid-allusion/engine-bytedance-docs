## Safe and reliable

When accessing the internet through the Internet NAT Gateway, ECS instances do not need to expose their private IP addresses, which helps protect the security of backend ECS instances to some extent.

<span id=".6ZmN5L2O5oiQ5pys"></span>
## Cost reduction

You do not need to purchase separate EIPs and bandwidth resources for each ECS instance. Using the Internet NAT Gateway allows multiple ECS instances to share EIPs and bandwidth, reducing internet usage costs.

<span id=".54G15rS76YOo572y"></span>
## Flexible deployment

You do not need to build your own internet gateway; the Internet NAT Gateway lets you quickly configure SNAT or DNAT with flexible features that are simple to use and reliable.

<span id=".5aSa5qC35piT55So"></span>
## Diverse and easy to use

The Internet NAT Gateway specifications and EIPs can be configured flexibly and adjusted anytime. After simple configuration of the Internet NAT Gateway, you can use it immediately. It is easy to operate and quickly provisioned.

<span id=".6Leo5Y-v55So5Yy65a6554G-"></span>
## Cross\-AZ disaster recovery

Internet NAT Gateway supports cross\-availability zone disaster recovery. When the primary availability zone fails, the Internet NAT Gateway automatically switches to the secondary availability zone to ensure normal business operation.
