This topic describes how to create a VPC NAT Gateway.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [VPC NAT Gateway console](https://console.byteplus.com/nat/vpcNat).

2. In the top menu bar, select a target region and project.

3. Click **Create VPC NAT Gateway**.

4. Configure relevant parameters based on the table below.

   
   |Parameter |Description |Sample value |
   |---|---|---|
   |Billing method |Select the billing type for the VPC NAT Gateway. Only Pay\-as\-you\-go billing is supported.<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">Here, Pay\-as\-you\-go corresponds to Pay\-by\-CU.</div><br> |Pay\-as\-you\-go |
   |Regions |Select the region where the VPC NAT gateway resides. |China (Beijing) |
   |Name |Enter the name of the VPC NAT Gateway. |vpc\-nat\-1 |
   |VPC |Select the Virtual Private Cloud (VPC) to which the VPC NAT Gateway belongs from the dropdown menu. |vpc01; 172.XX.XX.0/12 |
   |Subnet |Select a subnet from the dropdown list.<br><br>When selecting a subnet, please note the following.<br><br><br>* The subnet contains at least one available private IP. The network interface automatically generated by the system for the VPC NAT Gateway will occupy one private IP address in that subnet.<br><br>* The availability zone where the subnet is located must have VPC NAT Gateway resources deployed. You can view the availability zones with NAT resources at the top of the subnet selection page. The availability zone where the subnet of the VPC NAT Gateway resides will serve as its primary availability zone, and a secondary availability zone will be automatically associated. If the primary availability zone experiences a failure, the VPC NAT Gateway will automatically fail over to the secondary availability zone. |subnet01\|172.XX.XX.0/28 |
   |Specification |No specification is required. For performance cap, see [Billing](https://docs.byteplus.com/en/docs/6404/1158668). |\- |
   |Affiliated project |Select the project to which the VPC NAT Gateway belongs. For more information, see [Project management](https://docs.byteplus.com/en/docs/natgateway/Managing-projects).<br><br><br>* If you select "All Resources" for the account in the top navigation bar before entering the creation page, you can choose an existing project from the dropdown.<br><br>* If you select a specific target project in the top navigation bar, only that target project can be selected.<br><br><br>After the VPC NAT Gateway is created, if you need to change its project, see Moving resources into projects. When a VPC NAT Gateway is moved into or out of a project, its sub\-resources (such as SNAT rules, DNAT rules, secondary network interfaces, and security groups associated with the VPC NAT Gateway) will be moved along with it. |default |
   |Tags |Add one or more user tags to the VPC NAT Gateway as needed.<br><br>A tag consists of a tag key (Key) and a tag value (Value). You can group VPC NAT Gateways by tag. For more information, see [Tag management](https://docs.byteplus.com/en/docs/natgateway/Managing-tags).<br><br>Click the  <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_55bacf13a0c6c2fda7584a5da2b74a9d.png) </span> icon to add multiple tags. |nat:v1 |
   

5. Click **Confirm order**.

6. Follow the console guidance to review and accept the legal terms, and click **Buy now** to complete the action.

## What to do next


* After the VPC NAT Gateway is created, move the pointer over the **To be configured** in the status column. Follow the prompt to [Create SNAT rule](https://docs.byteplus.com/en/docs/natgateway/Managing-SNAT-rules-vpcnat), [Create DNAT rule](https://docs.byteplus.com/en/docs/natgateway/Managing-DNAT-rules-vpcnat), and [Configure routing](https://docs.byteplus.com/en/docs/natgateway/Route-configuration-principles).

* **Network Access Control List (ACL) traffic control** is automatically configured after NAT gateway creation. To modify the Network ACL traffic control settings, please contact your account manager and submit a ticket. [Learn more](https://docs.byteplus.com/en/docs/natgateway/NAT-gateway-FAQ#gQrzZ123)
