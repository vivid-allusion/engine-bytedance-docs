This topic describes how to modify the specification for an Internet NAT Gateway.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

The current account is not in arrears and has sufficient balance to cover subsequent Internet NAT Gateway fees.

<span id=".5pON5L2c6K-05piO"></span>
## Instructions


* The pay\-by\-specification Internet NAT Gateway supports flexible switching of specifications.

* The subscription Internet NAT Gateway only supports upgrading specifications and does not support downgrading. For details, see [Performance](https://docs.byteplus.com/en/docs/natgateway/Specifications).

* Upgrading the specification does not affect business operations but will increase costs.

* If the downgraded specification is lower than what the current running service requires, it will impact the service. Proceed with caution.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Internet NAT Gateway console](https://console.byteplus.com/nat/nats).

2. In the top menu bar, select a target region and project.

3. In the Internet NAT Gateway list, click  **··· \> Modify specification** to the right of the target Internet NAT Gateway.

4. Select the specification of the Internet NAT Gateway, and click **Confirm order**.

5. Follow the console guidance to review and confirm the legal terms, and click **Submit** to complete the action.
