The Internet NAT Gateway supports subscription purchases. Subscription is a prepaid billing method. This topic details the billing items and specification fees for Subscription Internet NAT Gateways.

<span id=".6LSt5Lmw5YmN5o-Q"></span>
## Prerequisites

You have completed enterprise real\-name authentication for your account.

<span id=".6K6h6LS55YWs5byP"></span>
## Formula

Specification configuration fee for a single Internet NAT Gateway (USD) = Specification unit price (USD/month) × Usage duration (months)

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The usage duration is calculated in non\-calendar months. For example, Mr. X bought a Subscription Internet NAT Gateway at 14:12:32 on August 10, 2023, for a duration of two months. Its expiration time is 23:59:59 on October 10, 2023.</div>


<span id=".6LWE5rqQ5Lu35qC8"></span>

You can use the [Pricing calculator](https://www.byteplus.com/en/pricing?product=NAT_Gateway&tab=2) to view specification unit prices. These prices are for reference only. Refer to the [Internet NAT Gateway console](https://console.byteplus.com/nat/nats) for the actual fees.

## Billing example

The following is only an example introduction of fees for the Internet NAT Gateway.

**Before you begin:**  Assume the subscription Internet NAT Gateway unit price is consistent with the above "Gateway unit price".

**Example:**  On March 20, 2021, Mr. A purchases a small specification subscription Internet NAT Gateway in the China (Beijing) region for 2 months.

**Fee calculation:**  When purchasing the Internet NAT Gateway, Mr. A needs to pay a total fee of 306.00 × 2 = 612.00 (USD).

**Expiration time:**  This Internet NAT Gateway expires at 23:59:59 on May 20, 2021.
