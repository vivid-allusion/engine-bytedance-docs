This section introduces the SDK language versions provided by NAT Gateway and lists the access addresses for the latest SDK version.

<span id="xtTQ6OLP"></span>
## SDK instruction

The NAT Gateway SDK encapsulates all API interfaces of the NAT Gateway ([API overview](https://docs.byteplus.com/en/docs/natgateway/API-overview-1)), uses the access key (AK) to identify the caller's identity, and provides automatic signature features, allowing you to create and manage resources conveniently through API calls.

<span id="2i48WUWq"></span>
