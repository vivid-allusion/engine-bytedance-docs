The message center includes five modules: platform messages, basic message receiving configuration, chatbot message receiving configuration, and recipient management.


* Platform messages: Allows you to filter and view platform messages by message type and status.

* Basic message receiving configuration: Allows you to subscribe to message types, message receiving methods (email and platform message), and message recipients as needed.

* Chatbot message receiving configuration: Allows you to subscribe to message types that support chatbots and configure the webhook URL of a chatbot.

* Recipient management: Allows you to add, edit, and delete recipients and manage a recipient's message subscription.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="warning">For important messages, configure email notification methods, which can't be replaced by chatbots.</div>
