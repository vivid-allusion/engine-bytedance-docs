**Adding a message recipient**


* Click Add message recipient. In the pop\-up window, enter the information and select the message types to subscribe to.

* You can add up to 10 message recipients at a time.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_6607a718e1f65e9b9d73173e72b36a50.png) </span>

**Editing a message recipient**


* Click Modify in the Actions column. In the pop\-up window, edit the message recipient.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_b12bb7464c1136b50b9c1828c8a86bf6.png) </span>

**Deleting a message recipient**


* Click Delete in the Actions column to delete a message recipient.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_81f11371b23b9ad7f30a63fca1ea98c6.png) </span>
