You can enter Chatbot message receiving configuration according to the following procedure:


1. Log in to the Byteplus [console](https://console.byteplus.com/auth/login?redirectURI=%2Fhome).

2. Click the message center icon in the top navigation bar to preview platform messages and then click View more or Message receiving management to enter Message center.

3. Click Chatbot message receiving configuration in the left navigation pane.


<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Note</div>


<div data-tips="true" data-tips-type="warning">For important messages, configure email notification methods, which can't be replaced by chatbots.</div>
