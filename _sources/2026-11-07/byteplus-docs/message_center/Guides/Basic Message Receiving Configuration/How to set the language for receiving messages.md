<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>



1. <div data-tips="true" data-tips-type="warning">If the message language is set to Korean but the subscribed message template itself only supports English, the messages you receive will be in English. If you expect the messages to be delivered according to your language setting, you can submit feedback so that this can be supported.</div>


2. <div data-tips="true" data-tips-type="warning">Only users with the appropriate permissions can configure the message language. If you want a user to be able to set the message language, make sure that the user has the MessageCenterFullAccess permission.</div>


3. <div data-tips="true" data-tips-type="warning">After the language setting is changed, it only takes effect for newly received messages and will not affect messages received before the configuration was modified.</div>



**Setting the message language**


* Go to Message Receiving Configuration \-\> Basic Receiving Configuration, then click Configuration in the upper\-right corner and select: Set Message Language.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4a4a1dc87cf8de4dc5e6c9dcea06480e.png) </span>


* Select the language in which you want to receive messages. BytePlus messages support the following languages: English, 日本語, 한국어, Bahasa Indonesia. The default is English, and you can adjust the language setting as needed.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_4afb2008b5bacad2748b5a9f7e13e77a.png) </span>
