**Adding message recipients**


* After selecting one or more message types, click Batch add message recipients to batch add message recipients for the selected message types.

 &nbsp;

**Editing a message recipient**


* Click Edit in the Actions column to edit the message recipient of a message type.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_dadd97be91cd6b29032342ca7694520b.png) </span>

**Deleting message recipients**


* After selecting one or more message types, click Batch delete message recipients to batch delete the message recipients for the selected message types.


<span>![图片](https://sf16-resources.bytepluscdn.com/obj/byteplus-public-aiso/cloud-universal-doc/upload_85bbe88b5bc18daf9c7f29b67e391f0a.png) </span>
