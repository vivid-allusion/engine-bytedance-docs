IAM identity receiving of the message center only applies to chatbot configuration, and this feature requires administrator permissions.

You can enter IAM identity receiving according to the following procedure:


1. Log in to the Byteplus [console](https://console.byteplus.com/auth/login?redirectURI=%2Fhome).

2. Click the message center icon in the top navigation bar to preview platform messages and then click View more or Message receiving management to enter Message center.

3. Click IAM identity receiving in the left navigation pane.


You can view all the long\-term IAM identities in the list, click Edit to enter the edit window, and click Clear to cancel chatbot receiving for an identity.

In the Edit window, select the type of chatbot that needs to be configured, enter the relevant configuration, and click Confirm.
