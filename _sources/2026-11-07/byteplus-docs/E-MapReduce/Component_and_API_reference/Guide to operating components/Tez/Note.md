This article introduces how to use Tez to execute SQL jobs on a Volcano Engine E\-MapReduce (EMR) cluster.

<span id="_1-概述"></span>
## **1 Overview**

TEZ was created primarily to address the inefficiency of MapReduce.

TEZ simplifies the original Map and Reduce operations into a single concept—Vertex; it also breaks down the original computational processing nodes into several components: Vertex Input, Vertex Output, Sorting, Shuffling, and Merging.

Data communication between computational nodes is called Edge. These decomposed primitive operations can be flexibly combined to produce new operations, which, after assembly, form a large DAG job.


* Input: An abstraction of the input data source. It parses the input data format and outputs individual Key/value pairs.

* Output: An abstraction of the output data source. It writes the Key/value pairs generated by the user program to the file system.

* Partitioner: Performs data partitioning, similar to the Partitioner in MR.

* Processor: An abstraction of computation. It obtains data from an Input, processes it, and outputs it through Output.

* Task: An abstraction of a task. Each Task consists of an Input, Output, and Processor.

* Master: Manages the dependencies among Tasks and executes them in order according to their dependencies.


In addition to the six components above, Tez also provides two operators: Sort (sorting) and Shuffle (shuffling). For user convenience, it offers multiple implementations of Input, Output, Task, and Sort.

## **2 prerequisites**


* An EMR cluster with the Hive component service has been created. For details, see [Create clusters (version 3.18.0 and earlier)](https://docs.byteplus.com/docs/E-MapReduce/105456).

<span id="_3-操作指南"></span>
## **3 Operation guide**

<span id="_3-1-使用-hive-提交-tez-任务"></span>
### 3.1 Submit Tez tasks using Hive

To submit Tez tasks using Hive, you must first switch Hive to use Tez as the execution engine:


1. Log in to the [EMR console](https://console.volcengine.com/emr/region:emr_fe+cn-beijing/project/default/home).

2. In the left navigation bar, click to enter the **Cluster Management \> Cluster List \> Cluster Details \> Service List \> Hive \> Service Parameters** page.

3. Modify the Hive parameter `hive.execution.engine` to Tez. In the upper right corner, click the **Service Operations \> Restart** button to restart the Hive service.


<span id="_3-2-登录-emr-master-节点"></span>
### **3.2 Log in to the EMR primary node**


1. Click the **Cluster List \> Cluster Name \> Service List \> Hive \> Deployment Topology** tab to enter the deployment topology page for the Hive component service.

2. Expand the HiveServer2 component name, click the ECS ID of the emr\-primary\-1\-1 host name to jump to the cloud server instance page, and click the **Remote Connection** button in the upper right corner.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_d039b120d78329831cd7906733f83d4f.png) </span>

3. Select a remote connection method (ECS Terminal is recommended), enter the relevant cluster authentication information, and log in to the command\-line environment of the Hive cluster to execute relevant command\-line operations.


<span id="_3-3-连接-hiveserver2"></span>
### **3.3 Connect to HiveServer2**

Run the following command to connect to HiveServer2 using beeline:

```plaintext
beeline -u jdbc:hive2://emr-master-1-1:10000 -n <user> -p <password>
```


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">When logging in for the first time, initialize the account password. You can go to the <strong>Service List \> OpenLDAP Component Service \> Service Parameters</strong> page to obtain Hive login information.</div>


<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_2fcb169cb4780472b23851c42fc89bd5.png) </span>

<span id="_3-4-执行-hive-语句"></span>
### **3.4 Execute Hive statements**

After connecting to HiveServer2, you can execute relevant Hive statements based on your actual scenario. The following is an example:

```plaintext
0: jdbc:hive2://emr-master-1-1:10000> select orderkey,count(*) from lineitem group by orderkey limit 100;
```
