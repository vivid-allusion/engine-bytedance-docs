## 1 Introduction to Ranger

Apache Ranger is a data security management framework for the Hadoop ecosystem. It provides a unified interface for data authorization and management, enabling fine\-grained access control for components such as HDFS, Yarn, and Hive.

<span id="_2-ranger鉴权体系"></span>
## **2 Ranger authentication system**

The Ranger authentication system is divided into three main parts

<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_ef34d327b929a2579e499ca7434cb3f8.png) </span>


1. **Ranger user management**: IAM imports users into OpenLDAP, and then UserSync synchronizes them to Ranger Admin every minute.

2. **Ranger authentication framework**: The Ranger authentication framework consists of two main parts: Ranger Admin is used to manage policies and monitor the plugins of each component. Ranger Plugin is integrated into each component and periodically pulls policies from Ranger Admin for service authentication.

3. **Ranger external storage**: All policies created by Ranger Admin are stored in the database. In addition, audit logs generated by each service plugin are written to Solr/HDFS/ES, and these can be viewed on the audit page of Ranger Admin.

## **3 Accessing the Ranger Admin UI**

<span id="_3-1-进入-ui-登录界面"></span>
### 3.1 Entering the UI login page

In the current EMR, the management platform has added Knox proxy access links. Therefore, users can use the **Access Link** feature on the management platform to enter the login page of the Ranger Admin UI. The usage process is as follows:


1. Cluster management interface \-\> Access Link \-\> Click the access link for Ranger UI \-\> Enter the Ranger Admin UI interface.

### 3.2 Logging in to Ranger Admin

The login access process is as follows:


1. Method for obtaining the Ranger Admin UI login password:

   Service list \-\> Ranger \-\> Service parameters \-\> Enter ranger_admin_password in the search box to search and obtain the admin login password:


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/f882e91b23964ca3a4a761626bb087c4~tplv-goo7wpa0wc-image.image) </span>


2. After a successful login, you will enter the management interface of Ranger Admin. On the Ranger management home page, you can view the permission management plugins for each service that have been integrated with Ranger. Users can set more fine\-grained permissions through the corresponding plugins. For detailed descriptions of the main operation page features, see Table 1.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_9ad5c28448e8a4bd924d19a08abde47e.png) </span>

   **Table 1 Description of operation entry features in the Ranger Admin management interface:** 

   
   |Entry |Feature description |
   |---|---|
   |Access Manager |View the permission management plugins for each service currently integrated with Ranger. Users can set more granular permissions through the corresponding plugins. |
   |Audit |View audit log information related to Ranger's operation and permission control. |
   |Security Zone |Configure security zones. Administrators can divide the resources of each component into multiple zones, and different administrators can set security policies for specified resources of the service to enable better management. |
   |Settings |View Ranger\-related permission settings, such as users, user groups, roles, and more. |
