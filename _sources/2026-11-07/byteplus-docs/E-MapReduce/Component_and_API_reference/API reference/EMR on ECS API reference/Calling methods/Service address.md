To achieve low latency, it is recommended to select the corresponding service address based on the region where your resources are located.


|**Available region** |**RegionId** |**Service access address (new)**  |
|---|---|---|
|Asia Pacific (Jophor) |ap\-southeast\-1 |emr.ap\-southeast\-1.byteplusapi.com |


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">For latency\-sensitive services, it is recommended to specify the region (Region) in the request header. For more information, see <a href="https://docs.byteplus.com/docs/undefined/6a17b59bf7159d0515e911d4">Public parameters</a>.</div>


* <div data-tips="true" data-tips-type="tip">The domain name is the API access point and does not represent the actual region where the product directly provides services.</div>
