To facilitate the automated use of Volcano Engine E\-MapReduce (EMR), we provide an external EMR SDK.

The EMR SDK encapsulates the corresponding EMR OpenAPI, uses an AccessKey to identify the caller, and provides features such as automatic signing, making it easier to create and manage EMR clusters via API.

The EMR SDK is highly compatible with the OpenAPI provided by EMR. For the currently supported API calls, please refer to[ EMR on ECS API Reference](https://docs.byteplus.com/docs/undefined/69a9666710be4d05382fbfd0).
