<span id="_1-简介"></span>
## Introduction

The Python Query SDK helps Serverless Spark users more easily use the Serverless Spark query service with the Python language. The main features currently include task submission and cancellation, task information retrieval, result retrieval, resource upload, and more.

This article provides sample code for the above features for reference.

<span id="_2-概念说明"></span>
## Concepts

<span id="8f6dd050"></span>
### **System concepts**


* Endpoint: Is the API domain name for Serverless Spark external services.

* Region: Is the physical location of the Serverless Spark data center.


The regions and API domain names currently supported by Serverless Spark are shown in the following table:


|**Region (Chinese name)**  |**Region** |**Endpoint** |
|---|---|---|
|North China \- Beijing |cn\-beijing |emr\-serverless.cn\-beijing.volcengineapi.com |
|East China \- Shanghai |cn\-shanghai |emr\-serverless.cn\-shanghai.volcengineapi.com |
|South China \- Guangzhou |cn\-guangzhou |emr\-serverless.cn\-guangzhou.volcengineapi.com |
|Asia Pacific Southeast \- Johor |ap\-southeast\-1 |emr\-serverless.ap\-southeast\-1.volcengineapi.com |



* Access Key / Secret Access Key: The credentials for accessing Volcano Engine APIs. Users can obtain the Access Key and Secret Access Key from the Volcano Engine 'Key Management' page.


<span id="f35536fb"></span>
### **Internal concepts**


* Schema: A conceptual space that contains information such as data tables, resources, UDFs, and more.

* Task: Defines the execution information for a task, including query SQL, execution mode (synchronous/asynchronous), task name, parameters, and other information.

* Job: Represents the task instance generated by executing a Task.

* Result: Represents the execution result of a Job.

* ResultSchema: The schema information of the execution result.

* Record: Represents a row in the result set of the execution result.

## Quick Start

<span id="_3-1-初始化客户端"></span>
### **Initialize the client**

The Python Query SDK currently provides only one static method for client initialization, which is done by configuring the endpoint, region, Access Key, and Secret Access Key:

```python
from serverless.auth import StaticCredentials
from serverless.client import ServerlessClient

ak = 'your ak'
sk = 'your sk'
region = 'cn-beijing'
endpoint = 'emr-serverless.cn-beijing.volcengineapi.com'
service = 'emr_serverless'
connection_timeout = 30
socket_timeout = 30

client = ServerlessClient(credentials=StaticCredentials(ak, sk), 
    region=region, endpoint=endpoint, service=service,
    connection_timeout=connection_timeout, 
    socket_timeout=socket_timeout)
```


`ServerlessClient` is the entry point for subsequent calls to various Serverless Spark features. The current version of ServerlessClient provides the following API interfaces:


|API |Function |
|---|---|
|execute |Execute job |
|cancel_job |Cancel task |
|get_job |Get task instance status |
|get_result |Get job result |


<span id="_3-2-第一个查询"></span>
### The first query

After initializing the client, you can execute relevant Tasks (currently supports SQL and SparkJar task types) to perform task execution.

The following is an example of a simple SQL query:

```python
sql = """
    SELECT * FROM `${your_schema}`.`${your_table}` LIMIT 100
"""

# Execute query synchronously
job = client.execute(task=SQLTask(name="first query task", 
                            query=sql,
                            conf={}),
                    is_sync=True)

# Get query result
if job.is_success():
    result = job.get_result()
    for record in result:
        print(', '.join([col for col in record]))
```

<span id="_4-1-提交-sql-任务"></span>
### **Submit an SQL task**

SQLTask is the interface for executing SQL query tasks. The main parameters provided are as follows:


|Parameter |Type |Required |Description |
|---|---|---|---|
|query |str |Y |SQL statement |
|name |str |N |Task name<br><br><div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="tip">If not specified, it will be generated as SQLTask_$</div><br> |
|conf |dict |N |Used to specify task parameters. Default is empty. |
|queue |str |N |Specify the name of the execution queue. If not specified, the public queue will be used. |


Example:

```python
def execute_sql_task():
    from serverless.client import ServerlessClient
    from serverless.auth import StaticCredentials
    from serverless.task import SQLTask
    from serverless.exceptions import QuerySdkError

    ak = 'xxxx'
    sk = 'xxxx'
    region = 'cn-beijing'
    service = 'emr_serverless'
    endpoint = 'emr-serverless.cn-beijing.volcengineapi.com'
    sql = '${CUSTOM_SQL_STATEMEMT}'

    client = ServerlessClient(credentials=StaticCredentials(ak, sk), service=service, region=region,endpoint=endpoint)

    try:
        job = client.execute(task=SQLTask(name='sql task', query=sql, 
        conf={
              # Compute group name, optional. Default is the Default compute group.
              #"serverless.compute.group.name": "xxx"
        }), is_sync=True)
        if job.is_success():
            result = job.get_result()
            for record in result:
                print(', '.join([col for col in record]))

    except QuerySdkError as e:
        print(
            "Error in executing sql task. code = %s, error = %s" % (
            e.error_code, e.info))


if __name__ == "__main__":
    execute_sql_task()
```


<span id="_4-2-提交-sparkjar-任务"></span>
### **Submit a SparkJar task**

SparkJar tasks provide users with support for customized data analysis requirements by writing Spark applications. See the [SparkJar jobs](https://docs.byteplus.com/docs/E-MapReduce/SparkJar_jobs) documentation for details.

JarTask is the SDK interface for executing SparkJar tasks:


|Parameter |Type |Required |Description |
|---|---|---|---|
|jar |str |Y |SparkJar resource used during task execution. The tos path must be provided, for example: ['tos://bucket/path/to/jar'] |
|main_class |str |Y |Main class of the Spark application |
|main_args |list |N |Parameters for the main function of the Spark application. If not provided, defaults to an empty list. |
|name |str |N |Task name. If not specified, it will be generated as `SparkJarTask_${current_time}`. |
|conf |dict |N |Used to specify task parameters. Default is empty. |
|queue |str |N |Specify the name of the execution queue. If not specified, the public queue will be used. |
|depend_jars |str[ ] |N |Dependent jar files, corresponding to the \-\-jars option of spark\-submit, for example: ['tos://bucket/path/to/jar'] |
|files |str[ ] |N |Dependent files, corresponding to the \-\-files option of spark\-submit, for example: ['tos://bucket/path/to/file'] |
|archives |str[ ] |N |Dependent archive files, corresponding to the \-\-archives option of spark\-submit, for example: ['tos://bucket/path/to/archive'] |


Example:

```python
def execute_spark_task():
    from serverless.client import ServerlessClient
    from serverless.auth import StaticCredentials
    from serverless.task import JarTask

    ak = 'xxxx'
    sk = 'xxxx'
    region = 'cn-beijing'
    service = 'emr_serverless'
    endpoint = 'emr-serverless.cn-beijing.volcengineapi.com'

    client = ServerlessClient(credentials=StaticCredentials(ak, sk), service=service, region=region, endpoint=endpoint)

    jar_resource = 'tos://bucket/path/to/jar'
    main_class = 'com.xxx.xxx'
    main_args = ['arg_xxx', 'arg_yyy']
    job = client.execute(task=JarTask(name="spark task test",
        jar=jar_resource,
        main_class=main_class,
        main_args=main_args,
        conf={'serverless.spark.access.key': '${ak}', 'serverless.spark.secret.key': '${sk}'}
),
    is_sync=True)

    print('The task executed successfully.')
    print('Tracking ui: %s' % job.get_tracking_url())


if __name__ == "__main__":
    execute_spark_task()
```


<span id="_4-3-提交-pyspark-任务"></span>
### Submit a PySpark task

PySpark tasks provide users with support for customized data analysis requirements by writing Python Spark applications. See [PySpark job](https://docs.byteplus.com/docs/E-MapReduce/PySpark_job) for details.

PySparkTask is the interface provided by the SDK for executing PySpark tasks:


|Parameter |Type |Required |Description |
|---|---|---|---|
|script |str |Y |SparkJar resources used during task execution. You must provide a TOS path, for example: ['tos://bucket/path/to/pyfile'] |
|args |list |N |Parameters for the main function of the Spark application. The default is an empty list. |
|name |str |N |Task name. If not specified, it will be generated as `SparkJarTask_${current_time}` |
|conf |dict |N |Used to specify task parameters. The default is empty. |
|queue |str |N |Specifies the name of the execution queue. If not provided, the public queue will be used. |
|depend_jars |[]str |N |Dependent jar files, corresponding to the \-\-jars option of spark\-submit. For example: ['tos://bucket/path/to/jar'] |
|files |[]str |N |Dependent files, corresponding to the \-\-files option of spark\-submit. For example: ['tos://bucket/path/to/file'] |
|archives |[]str |N |Dependent archive files, corresponding to the \-\-archives option of spark\-submit. For example: ['tos://bucket/path/to/archive'] |
|pyfiles |[]str |N |Dependent pyfile files, corresponding to the \-\-pyfiles option of spark\-submit. For example: ['tos://bucket/path/to/pyfile'] |


Example:

```java
def execute_pyspark_task():
    from serverless.client import ServerlessClient
    from serverless.auth import StaticCredentials
    from serverless.task import PySparkTask

    ak = 'xxxx'
    sk = 'xxxx'
    region = 'cn-beijing'
    service = 'emr_serverless'
    endpoint = 'emr-serverless.cn-beijing.volcengineapi.com'

    client = ServerlessClient(credentials=StaticCredentials(ak, sk), service=service, region=region, endpoint=endpoint)

    pyscript_resource = 'tos://bucket/path/to/pyfile'
    main_args = ['arg_xxx', 'arg_yyy']
    files = ['tos://bucket/path/to/dependency_pyfile']
    task = PySparkTask(name='pyspark task test',
        # queue='${queue_name}',
        script=pyscript_resource,
        args=main_args,
        conf={'serverless.spark.access.key': '${tos_ak}',
            'serverless.spark.secret.key': '${tos_sk}'},
        files=files
    )
        
    job = client.execute(task=task, is_sync=True)

    print('The task executed successfully.')
    print('Tracking ui: %s' % job.get_tracking_url())


if __name__ == "__main__":
    execute_pyspark_task()
```

### Submit Ray job

```Python
from serverless import RayJobTask

_job = _client.execute(task=RayJobTask(name="test rayjob task",
        conf={
             # Compute group name, optional. The Default compute group is used by default.
             #"serverless.compute.group.name": "xxx",
             # To use a custom image, add this configuration and replace the image address.
             #"serverless.ray.version":"2.22.0",
            #"serverless.ray.image": "emr-serverless-online-cn-beijing.cr.volces.com/emr-serverless-ray/ray:2.30.0-py3.11-ubuntu20.04-240"
                                         
        },
        head_cpu='4',
        head_memory='16Gi',
        worker_cpu='4',
        worker_memory='16Gi',
        worker_replicas=2,
        # The format of entrypoint_cmd is /home/ray/workdir/{zip package name}/{py file name}
        # /home/ray/workdir is currently a fixed value.
        entrypoint_cmd='python /home/ray/workdir/rayzip.py',
        # TOS file path
        entrypoint_resource='tos://wbw-dev/rayunzip/rayzip.py.zip',
        runtime_env={
            # pip packages required by the runtime
            "pip": ["requests==2.26.0", "pendulum==2.1.2"],
            "env_vars": {
                "counter_name": "test_counter"
            }
        # queue=xxx
        }
    ),
        is_sync=False)
```


Parameter Note:


|Parameter |Description |
|---|---|
|name |Job name |
|head_cpu & head_memory |Set the CPU and memory of the Ray head node. The format is consistent with the k8s resource format, for example `4Gi` |
|worker_cpu & worker_memory |Set the CPU and memory of the Ray worker node. The format is consistent with the k8s resource format, for example `4Gi` |
|worker_replicas |Set the number of Ray worker node instances. |
|entrypoint_cmd |Shell command used as the entrypoint for running the job. |
|entrypoint_resource |Resource file related to running the job. Currently, only one TOS path is supported. The file will be decompressed during job execution. |
|runtime_env |Set the runtime environment for the Ray job. Can be used to specify environment variables, working directory, or pip dependencies. |
|is_sync |Set whether the job is executed synchronously. If set to true, the execute function will block synchronously until the job ends. If set to false, the execute function will return immediately after the task is submitted. |


<span id="_4-4-同步-异步执行"></span>
### **Synchronous/asynchronous execution**

Controlled by the is_sync parameter:


|Parameter |Type |Required |Description |
|---|---|---|---|
|task |Task |Y |Task to be executed |
|is_sync |bool |Y |Whether to execute synchronously |
|timeout |int |N |Timeout for synchronous execution, Unit: s |


```python
# Asynchronous
client.execute(task=SQLTask(name='', sql=sql, conf={}), is_sync=False)

# Synchronous execution, 3-minute timeout
client.execute(task=SQLTask(name='', sql=sql, conf={}), is_sync=True, timeout=180)
```

<span id="_5-3-等待任务"></span>
### **Wait for task**

After asynchronous invocation, to synchronize and block until the task reaches a certain state, try calling the `wait_for()` function:

```python
# Wait for the task to finish
job.wait_for_finished()

# Custom end status
def when_to_exit() -> bool:
    return job.get_tracking_url() is not None

job.wait_for(when_to_exit=_when_to_exit, timeout=180)
```

## **Obtain query results**

Call `get_result()` on the job instance to obtain the query results of the task:

```python
result = job.get_result()

# Or obtained from the serverless client side
result = client.get_result(job)

for record in result:
    print("row: (%s, %s, %s)" % (record[0], record[1], record[2]))
```

## 7 **Execution exceptions**

Task exceptions will be thrown as QuerySdkError, with specific execution error information carried in the exception message.
