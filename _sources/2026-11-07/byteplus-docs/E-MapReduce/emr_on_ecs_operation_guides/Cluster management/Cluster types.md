This document describes the cluster types supported by Volcano Engine E\-MapReduce (EMR) and the operations related to each cluster.


|**Cluster** |**Description** |**Key operations** |
|---|---|---|
|Hadoop |* Core service components of the Hadoop ecosystem: HDFS, YARN, and MapReduce components.<br><br>* Provides offline data analysis with Hive, Spark, and Tez.<br><br>* Provides real\-time data analysis with Flink and SparkStreaming.<br><br>* Provides interactive analysis and queries with Presto and Trino. |* [Create clusters (version 3.18.0 and earlier)](https://docs.byteplus.com/docs/E-MapReduce/105456)<br><br>* [Log in to the cluster](https://docs.byteplus.com/docs/E-MapReduce/104404)<br><br>* [Scale up clusters](https://docs.byteplus.com/docs/E-MapReduce/104396)<br><br>* [Release clusters](https://docs.byteplus.com/docs/E-MapReduce/104399) |
|Flink |Flink is a distributed computing framework for stateful computation on bounded and unbounded streams. Flink clusters provide open\-source messaging engine Flink services, supporting both stream processing and batch processing application types. |* [Basic Flink usage](https://docs.byteplus.com/docs/undefined/69a962388a3fb00506e9840f)<br><br>* [Flink SQL Client usage reference](https://docs.byteplus.com/docs/undefined/69a9622ff1381a04fe141c0b) |
|Kafka |A distributed messaging system coordinated by ZooKeeper, supporting partitions and multiple replicas. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69a968a08f7b90052e455590)<br><br>* [Quickstart](https://docs.byteplus.com/docs/undefined/69a968c7ff63760531155bf5) |
|Pulsar |An open\-source, high\-performance messaging and streaming platform based on **publish/subscribe model**, supporting multi\-tenancy, distributed architecture, and cloud\-native features. It provides **message queue and computation** services, addressing message transmission and queuing between servers. |* [quickstart](https://docs.byteplus.com/docs/undefined/69a968b2f9b5ca050955c7c7) |
|Presto |An open\-source distributed query and analysis engine with MPP architecture, supporting petabyte\-scale data query and analysis, and multiple data sources such as Hive, MySQL, MongoDB, Redis, and more. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69a968b728f81204f9ec4fb3)<br><br>* [Advanced usage](https://docs.byteplus.com/docs/undefined/69a9686710be4d05382fe238) |
|Trino |An open\-source distributed SQL query engine that supports interactive analysis at the petabyte scale. It does not store data itself, but works with cloud storage to naturally form a decoupled compute and storage architecture for elastic data analysis. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69aa3921f1381a04fe1b4573)<br><br>* [Advanced usage](https://docs.byteplus.com/docs/undefined/69aa395a9a87ca05550f7ef7) |
|Doris |A modern MPP analytical database product. Sub\-second response time for queries enables efficient real\-time data analysis, meeting diverse data analysis needs such as fixed historical reports, real\-time data analysis, interactive data analysis, and exploratory data analysis. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69a9626d8252b50542c49af0)<br><br>* [Advanced usage](https://docs.byteplus.com/docs/undefined/69a962128252b50542c4908a)<br><br>* [Doris connects to Tableau](https://docs.byteplus.com/docs/undefined/69a962008a3fb00506e97f53) |
|StarRocks |A new\-generation, high\-speed, all\-scenario MPP (Massively Parallel Processing) database that adopts a fully vectorized engine, making users' data analysis simpler and more agile. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69aa398ad5f8c20564ccdb1e)<br><br>* [StarRocks access TOS](https://docs.byteplus.com/docs/undefined/69aa383b6138ac04f2803fa6)<br><br>* [Near real-time data analysis based on StarRocks](https://docs.byteplus.com/docs/E-MapReduce/105433) |
|ClickHouse |A distributed, real\-time analytical columnar database product that delivers query results with sub\-second response time, enabling efficient real\-time data analysis. Widely used in business scenarios such as user behavior analysis, traffic and monitoring, user profiling, and real\-time BI reports. |* [Overview](https://docs.byteplus.com/docs/undefined/69a952a58a3fb00506e88405)<br><br>* [Basic usage](https://docs.byteplus.com/docs/undefined/69a952de9a03a004ffa82a32)<br><br>* [Advanced usage](https://docs.byteplus.com/docs/undefined/69a952ab6138ac04f27807f9) |
|HBase |The HBase cluster provides a NoSQL database service built on HDFS, offering high\-concurrency random read and write operations, as well as real\-time point queries. |* [Note](https://docs.byteplus.com/docs/undefined/69a9674494abd60513fe93ed)<br><br>* [HBase Shell](https://docs.byteplus.com/docs/undefined/69a968fe9a87ca055508b0bd) |
|OpenSearch |The OpenSearch cluster is a full\-text search and analytics engine that is fully compatible with the open\-source Elasticsearch interface, providing users with multi\-criteria search, statistics, and reporting capabilities for both structured and unstructured text. |* [Usage instructions](https://docs.byteplus.com/docs/undefined/69a9679aa2ab0e050eaf21f8) |
|TensorFlow |An end\-to\-end open\-source machine learning platform that enables researchers to easily build models for machine learning production. |* [Basic usage](https://docs.byteplus.com/docs/undefined/69aa38e410be4d053836b65e) |
