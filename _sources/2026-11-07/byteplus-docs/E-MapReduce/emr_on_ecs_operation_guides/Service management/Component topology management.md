Go to the service list, click a service name, and view the component deployment topology details in the pop\-up panel. The details are as follows:


|Content |Note |
|---|---|
|Component name |Names of components included in the service |
|Component status |The running status of the component, including seven statuses: UNKNOWN (unknown, such as network disconnection), INSTALLING (installing), STOPPED/INSTALLED (stopped/installed), STARTING (starting), STARTED (started), STOPPING (stopping), and INSTALLED_FAILED (installation failed). |
|ECS ID |Information about the ECS where the component is installed. Click the ID to go to the ECS management console and view host details. |
|Host name |Name of the created host |
|Instance type |The role of the installed host, which can be primary, Core, or Task. |
|IP information |Displays the internal IP address |
|Component operations |For server\-type components, the start, stop, and restart operations are supported. |
