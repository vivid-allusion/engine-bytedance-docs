<span id="集群操作日志"></span>
## View operation logs


1. Log in to [E-MapReduce Console](https://console.byteplus.com/emr/region:emr_fe+ap-southeast-1/home?)

2. In the left navigation pane, click **Resources \> on ECS \> Cluster Name \> Cluster Details \> Operation Logs** to go to the page.

3. On the **Operation Logs** page, the historical operation logs of the current cluster and detailed records of configuration changes are displayed.


<span id="查询操作日志"></span>
## **Search operation logs**


1. On the Operation Logs page, search by operation time, operation name, and operator.

2. Click the operation name to display the operation details.


<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="tip">For cluster\-side operations, such as starting, stopping, or restarting services or components, click the operation name to display the operation execution details in the pop\-up panel. The specific execution status and log details are displayed step by step.</div>


* <div data-tips="true" data-tips-type="tip">For configuration change operations in the console, such as saving service configuration parameters or modifying alert rules, click the operation name to display the configuration changes before and after the operation in the pop\-up window. You can compare the information before and after the operation to understand the operation details.</div>


* <div data-tips="true" data-tips-type="tip">Cluster host logs are retained for seven days.</div>
