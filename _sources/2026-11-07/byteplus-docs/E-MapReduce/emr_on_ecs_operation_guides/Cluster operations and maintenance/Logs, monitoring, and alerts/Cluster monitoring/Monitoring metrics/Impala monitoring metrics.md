<span id="_1-节点信息"></span>
## **Node information**


* Total number of healthy Impalad nodes


<span id="_2-impala-信息"></span>
## **Impala information**


* Result set cache size. Unit: byte

* Number of currently running queries. Unit: count

* 99th percentile query latency. Unit: ms

* 70th percentile query latency. Unit: ms

* RSS memory size. Unit: byte

* Memory\-mapped bytes. Unit: byet

* Number of Statestore registered backends. Unit: count

* Number of open Beeswax sessions. Unit: count
