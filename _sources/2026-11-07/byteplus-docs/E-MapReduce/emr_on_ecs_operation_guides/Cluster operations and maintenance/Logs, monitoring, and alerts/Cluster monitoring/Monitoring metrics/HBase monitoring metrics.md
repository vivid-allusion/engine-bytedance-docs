This document provides detailed information about HBase metrics.

HBase metrics include the following sections:


* [Node information](https://docs.byteplus.com/docs/E-MapReduce/105467#_1-%E8%8A%82%E7%82%B9%E4%BF%A1%E6%81%AF)

* [HRegion information](https://docs.byteplus.com/docs/E-MapReduce/105467#_2-hregion%E4%BF%A1%E6%81%AF)


<span id="_1-节点信息"></span>
## Node information


* Number of deployed HBase Master nodes

* Number of active HBase Master nodes

* Number of deployed HBase RegionServer nodes

* Number of live HBase RegionServer nodes

* Number of failed HBase RegionServer nodes


<span id="_2-hregion信息"></span>
## HRegion information


* HBase RegionServer CPU usage

* HBase RegionServer memory usage

* HBase RegionServer IO status
