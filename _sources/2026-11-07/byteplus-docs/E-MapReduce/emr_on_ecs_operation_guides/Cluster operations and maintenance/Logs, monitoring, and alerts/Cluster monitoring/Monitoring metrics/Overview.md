Volcano Engine E\-MapReduce (EMR) cluster monitoring mainly consists of two parts: **Node monitoring** and **Service Monitoring**.


* Service Monitoring: Provides detailed monitoring for the main services installed on the cluster, including HDFS, YARN, Hive, ZooKeeper, and more.

* Node monitoring: Provides monitoring for ECS within the cluster, including CPU monitoring, memory monitoring, and storage monitoring.


<span id="查看服务监控"></span>
## View service monitoring


1. Log in to [E-MapReduce Console](https://console.byteplus.com/emr/region:emr_fe+ap-southeast-1/home?).

2. In the left navigation bar, click **Resources \> on ECS \> Cluster Name \> Service List** to enter the **Service List** page.

3. Select the node or service name you want to monitor. You can filter and view relevant monitoring metrics by node and time range.
