## EMR product advantages

<span id="开源-开放"></span>
### Open source and open platform


* 100% compatibility with mainstream community versions, meeting application development requirements and facilitating overall platform migration;

* Provides a semi\-managed white\-box environment, supporting guided workflows and cluster scripts, as well as other open features.


<span id="stateless云原生湖仓"></span>
### Stateless cloud\-native lakehouse


* Stateless cluster delivery, an elegant architecture for separating storage and compute, maximizing cost reduction and efficiency;

* Flexible elastic scaling strategies, supporting both time\-based rules and cluster load modes;

* An open lakehouse architecture that flexibly meets requirements for building various data platforms.


<span id="引擎企业级优化"></span>
### Enterprise\-level engine optimization


* Performance improvements for core engines such as Spark, Flink, Presto, Trino, Hudi, Iceberg, Doris, and StarRocks;

* Enterprise\-level permission management, BytePlusIAM+Kerberos authentication.


<span id="云上便捷运维"></span>
### Convenient cloud operations and maintenance


* One\-stop cloud hosting, cluster creation/deletion within minutes, offering two billing modes;

* Refined capabilities for cluster operations, maintenance, monitoring, and alerting, supporting a wide range of component operations.

## EMR Serverless product advantages

<span id="a59845bf"></span>
### **Fully managed service**

Out\-of\-the\-box, zero barrier to starting data analysis, no need to build clusters, configure parameters, or perform operations and maintenance, ensuring customers focus on their business requirements.

<span id="27bf6f37"></span>
### **Large\-scale elastic expansion**

Based on a self\-developed scheduling system, achieves second\-level resource scheduling and orchestration capabilities, supports seamless delivery of ultra\-large\-scale resources, supports on\-demand elasticity, and enables payment for resources based on actual business needs.

<span id="0347bf3c"></span>
### **Open source engine enhancement**

Services provided based on the open source community technology stack, fully compatible with open source syntax and runtime modes, enhanced by ByteDance internal optimization features, delivering performance several times higher than open source; engine types such as Spark also support native engine acceleration for underlying performance boost.

<span id="120cbf1d"></span>
### **Enterprise\-level data security**

Provides enterprise\-level multi\-tenant isolation capabilities through technologies such as secure containers (enhanced Kubernetes), achieving efficient resource isolation and robust data isolation.

<span id="a7bbd6f9"></span>
### **EMR integrated architecture**

EMR integrated product ecosystem, providing platform\-level resource control, job management, log analysis, and other capabilities, enabling data inter\-access between multiple clusters (semi\-managed and fully managed) through unified metadata.

<span id="5df53769"></span>
### **Unified technology ecosystem**

Unified metadata services and permission management services are provided through the independent LAS Catalog service, enabling cross\-source query and analysis capabilities and supporting multiple open lakehouse formats.
