## Billing items overview

The E\-MapReduce (EMR) product incurs E\-MapReduce service fees, ECS instance fees, public IP fees, and elastic block storage fees.

<span id="17655306"></span>
## Cost components


|**Billing items** |**Billing and payment methods** |
|---|---|
|EMR service fees |EMR provides comprehensive management services for clusters, including cluster information display, cluster and service management, monitoring and alerting, automated operations and maintenance for the backend, and other such services. EMR costs are divided into the following two types:<br><br><br>* For details about EMR pay\-as\-you\-go billing, see:[Pay-As-You-Go](https://docs.byteplus.com/docs/E-MapReduce/109034)<br><br>* For details about EMR subscription, see:[Subscription](https://docs.byteplus.com/docs/E-MapReduce/109037) |
|ECS instance costs |The billing method for ECS instances depends on the payment type selected when purchasing an EMR cluster. When the payment type for purchasing an EMR cluster is Pay\-As\-You\-Go, the ECS instance fees are also charged in Pay\-As\-You\-Go mode.<br><br><br>* For details about ECS pay\-as\-you\-go billing, see: [Pay-As-You-Go](https://docs.byteplus.com/en/docs/ecs/Pay-as-you-go)<br><br>* For details about ECS Subscription, see [Subscription](https://docs.byteplus.com/en/docs/ecs/Subscription) |
|Public IP costs |A public IP can be bound to an EMR node during the [Create a cluster](https://docs.byteplus.com/docs/undefined/6891f3add609eb05c52ff086) process, enabling access to the EMR cluster's WebUI and allowing you to log in to the master node via the public network.<br><br>For details about public IP costs, see: [Public IP billing overview](https://docs.byteplus.com/en/docs/eip/Billing-overview) |
|Elastic block storage costs |Elastic block storage is mounted to ECS instances during cluster creation to provide a certain amount of storage space.<br><br>For details on Elastic Block Storage costs, see: [Elastic Block Storage billing methods](https://docs.byteplus.com/en/docs/ecs/Billing-overview) |
