### Billing instructions

The EMR Serverless queue consists of one type of billing resource: Compute resource charges.

<span id="e02838e5"></span>
### Billing methods

The EMR Serverless Queue Computing Resource Fee offers three payment methods:


* **Fully elastic queue** : **pay\-as\-you\-go** , this model will open the right to use the public queue, and the billing method is pay\-as\-you\-go.

* **Fully exclusive queue** : **Subscription** , this mode will produce an exclusive queue, billing method is package year monthly.

* **Exclusive queue with flexible resources** : **Hybrid billing** ; the queue generated by this model contains exclusive and elastic parts, and the exclusive part payment method is annual subscription monthly; flexible part payment method pays according to the amount. (The resources below Min are in the exclusive form, and the parts of Min~ Max are in the elastic form).


<span id="4d917be9"></span>
### Billing models

Users can choose the corresponding billing mode according to actual business needs:


* **Fully elastic queues with Pay\-as\-you\-go billing method** : suitable for trial/test purposes, when the job distribution is random and the amount of data is small, it is recommended to use pay\-per\-use method, which has no initial cost and can effectively help users control short\-term costs.

* **Full exclusive queue with subscription billing method** : suitable for production purposes, at this time the job is relatively fixed, recommended to use the package year monthly mode, can monopolize stable computing resources, and can save long\-term costs.

* **Subscription model with flexible resource exclusive queue (recommended)**  : Suitable for production purposes, when the job is relatively fixed, but there are fluctuations in resource utilization. Choosing this method can ensure the lowest resources, and there is no need to configure queue resources according to the Max value, which can save a lot of computing resources.
