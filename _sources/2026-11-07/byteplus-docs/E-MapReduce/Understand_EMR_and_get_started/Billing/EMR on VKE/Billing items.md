## Billing items overview

The Byteplus EMR on VKE product incurs EMR on VKE service fees, container service (VKE) fees, and object storage (TOS) fees. Container service (VKE) fees include VKE cluster hosting fees and cloud infrastructure resource fees. For details, refer to [Billing](https://docs.byteplus.com/zh-CN/docs/vke/Billing).

<span id="153e0ddc"></span>
## **Fee breakdown**


|Billing items |Billing |
|---|---|
|EMR on VKE service fee |EMR provides comprehensive cluster management services, including cluster information display, cluster and service management, monitoring and alerting, and automated backend operations and maintenance on the server side. |
|Container service (VKE) |Big data service components are installed and deployed based on VKE resources and run within containers. For billing details, see [Billing](https://docs.byteplus.com/zh-CN/docs/vke/Billing). |
|Object storage (TOS) |TOS is used to store information such as jobs, logs, and JAR packages. For billing details, see [Billing overview](https://docs.byteplus.com/zh-CN/docs/tos/docs-billing-overview). |
