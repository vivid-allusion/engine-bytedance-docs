This article introduces how to manage EMR Serverless OLAP users, including operations such as adding and deleting users.

<span id="_1-前提条件"></span>
## 1 Prerequisites

The EMR Serverless OLAP instance must be running normally.

<span id="_2-进入-emr-servereless-olap-用户管理页面"></span>
## 2 Access the EMR Serverless OLAP user management page


1. Log in to [EMR Serverless OLAP Console](https://console.byteplus.com/emr/region:emr_fe+ap-southeast-1/serverless/queue_manage).

2. In the menu bar at the top left, select the region as needed.

3. In the instance list, click the target **instance name** to enter the instance details page.

4. In the left navigation bar, click the User managementtab to access the user management page.


<span id="_3-添加用户"></span>
## 3 User and role management

On the user management page, you can control user permissions through user roles, and you can also create users and permissions as needed. For user and role management operations, see [Component permission management: users and roles](https://docs.byteplus.com/docs/E-MapReduce/109102).

<span id="_5-重置密码"></span>
## 4 Reset password

For existing users, you can modify their login password:


1. In the user list, click the **Operation** column, then click the Reset passwordbutton.

2. In the pop\-up dialog box, enter New password and Confirm new password.

3. Click the **Confirm** button to complete the password reset operation.


<span id="_6-删除用户"></span>
## 5 Delete user

If a created user is no longer needed in the instance, you can delete them:


1. In the user list, click the **Operation** column, then click the **Delete** button.

2. After reviewing the important notes for deletion, check "I have read and understood the above information" in the pop\-up window.

3. Click the **Delete** button to complete user deletion.
