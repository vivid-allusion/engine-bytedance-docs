EMR Serverless instances provide a wide range of monitoring metrics and alert metrics, which are essential for ensuring stable database operation and optimizing business decisions. These metrics offer real\-time insights into StarRocks performance, availability, and resource utilization, enabling database administrators to promptly identify and resolve potential performance bottlenecks or failures. They help maintain efficient system operation and ensure that data query and analysis tasks are completed quickly and reliably. In addition, by monitoring these metrics, enterprises can optimize resource allocation, improve operational efficiency, enhance cluster stability, and increase cluster resource utilization.

<span id="76f25ade"></span>
## Prerequisites

An EMR Serverless instance has been successfully created.

<span id="c3c02f29"></span>
## Procedure


1. Log in to [EMR Console](https://console.byteplus.com/emr/region:emr_fe+ap-southeast-1/home).

2. In the left navigation pane, click Resources \> Serverless \> cluster name \> Monitoring and alerts \*\*\*\* to enter the monitoring interface.

3. Select the node or service name for which you want to view monitoring metrics. You can filter and view relevant monitoring metrics by node and time range.
