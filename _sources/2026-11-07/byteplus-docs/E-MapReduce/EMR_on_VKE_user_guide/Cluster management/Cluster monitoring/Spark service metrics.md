This document provides detailed information about Spark service metrics.

The metrics are as follows.


|metric name |Unit |
|---|---|
|Spark Executor Tasks Total |count |
|Spark Executor RddBlocksTotal |count |
|Spark Executor ShuffleReadTotal |Bytes |
|Spark Executor ShuffleWriteTotal |Bytes |
|Spark Executor ActiveTasks |count |
|Spark Executor CompletedTasks |count |
|Spark Executor FailedTasks |count |
|Spark Executor Count |count |
|Spark Driver FGC count |count |
|Spark Driver Max Memory |Bytes |
|Spark Driver Used Memory |Bytes |
|Spark Driver Minor GC Count |count |
|Spark Driver Major GC Count |count |
|Spark Driver Minor GC Time |Time |
|Spark Driver Major GC Time |Time |
|Spark Driver Memory Usage |Percentage |
|Spark Executor Max Memory |Bytes |
|Spark Executor Used Memory |Bytes |
|Spark Executor Minor GC Count |count |
|Spark Executor Major GC Count |count |
|Spark Executor Minor GC Time |count |
|Spark Executor Major GC Time |count |
|Spark Executor Memory Usage |Percentage |
