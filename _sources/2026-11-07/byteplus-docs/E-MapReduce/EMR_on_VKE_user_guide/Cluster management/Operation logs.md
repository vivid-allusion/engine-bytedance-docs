## Operation logs

Go to **cluster details**, click **Operation logs** in the left menu bar to display the list of historical operation logs for the current cluster, as well as records of configuration modification details.

Cluster operation logs are divided into historical records and ongoing unfinished tasks.

<span id="ac72afe2"></span>
## **Query operation logs**

In the search bar, you can perform a fuzzy search by operator or search by log time.

In the list panel, you can filter by operation status. The list is sorted in descending order by operation start time by default, and you can click operation start time to adjust the sorting.

Click the operation name to display the operation execution details in the pop\-up panel. The specific execution status and log details are displayed separately for each step.
