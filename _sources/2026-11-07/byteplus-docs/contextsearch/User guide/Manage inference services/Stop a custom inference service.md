You can stop a custom inference service when you temporarily do not need it. This topic describes how to stop a custom inference service.

<span id="w9JmVMHT"></span>
## Precautions

After stopping the custom inference service, it cannot be called anymore. Please operate carefully. If you need to continue using it, you can restart it. For specific operations, see [Start a custom inference service](https://docs.byteplus.com/en/docs/contextsearch/Start_custom_inference_service).

<span id="s9YxNcqu"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. Select **Model and reasoning \> Inference service** on the left navigation bar, click the **Custom Inference Service** tab, then click **Stop** in the **Actions** column of the target inference service.

4. In the popup dialog, click **OK**.
