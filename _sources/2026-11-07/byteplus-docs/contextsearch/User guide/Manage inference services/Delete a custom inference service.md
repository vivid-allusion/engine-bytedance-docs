When you no longer need a custom inference service, you can delete it to save resources. This topic describes how to delete a custom inference service.

<span id="SuZsqSbm"></span>
## Precautions


* You cannot delete a custom inference service if it is associated with any scenarios. To delete it, first modify the inference service linked to the scenario or delete the scenario. For more information, see [Manage scenarios](https://docs.byteplus.com/en/docs/contextsearch/Manage_scenarios).

* Deleting a custom inference service is irreversible; proceed with caution.


<span id="7qLVqtzx"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, select **Models and reasoning \> Inference service**, click the **Custom inference service** tab, then select  **... \> Delete** in the **actions** column of the target inference service.

4. In the popup dialog, click **OK**.
