If a custom inference service encounters an exception, you can try restarting it to recover. This topic describes how to restart a custom inference service.

<span id="ZJroDfQJ"></span>
## Precautions


* The custom inference service is unavailable during the restart process and will resume after completion.

* Only custom inference services with the **Purchase method** of **By\-token** can be restarted. For details, see [Create a custom inference service](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_inference_service).


<span id="BsaGTHjB"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. Select **Models and reasoning \> Inference service** in the left navigation bar, click the **Custom inference service** tab, then select  **... \> Restart** in the **Actions** column of the target inference service.

4. In the popup dialog, click **OK**.
