After creating a custom inference service, you need to start it before use. This article explains how to start a custom inference service.

<span id="HteGbcLb"></span>
## Prerequisites

A custom inference service has been created, and its status is **Stopped**. For specific steps, refer to [Create a custom inference service](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_inference_service).

<span id="m18lMNlv"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, select **Model and Inference \> Inference Service**, click the **Custom Inference Service** tab, and click **Start** in the **actions** column of the target inference service.

4. In the popup dialog, click **OK**.
