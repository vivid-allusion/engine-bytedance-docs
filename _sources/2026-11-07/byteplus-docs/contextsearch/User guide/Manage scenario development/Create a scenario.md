ContextSearch provides a complete method for scene building, including data preprocessing, retrieval service, and Q&A summary generation. You can quickly build knowledge base, picture search, and video search applications through simple configuration. This topic describes how to create a scenario.

<span id="EgyXJqYl"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, select **My Scene**, then click **Create scene**.

4. In the **Create scene** panel, configure the following parameters and then click **Create**.

   
   |**Parameter** |**Description** |
   |---|---|
   |Select type |Select the type of the scenario. Currently supports **Knowledge Base**, **Image Search**, **Video Search**, **Personalization Search**, **Agentic Search**, and **Multimodal search**.<br><br><div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div><br><br><br><div data-tips="true" data-tips-type="default">Multimodal Search is currently a white\-listed feature. To use it, please <a href="https://console.byteplus.com/workorder/create/?step=1">submit a ticket</a>.</div><br> |
   |Name |Set the name of the scene. Naming rules are as follows:<br><br><br>* Cannot start with a number or a hyphen (\-).<br><br>* Length must be between 1 and 128 characters.<br><br>* Contain letters, digits, underscores (_), and hyphens (\-). |
   |Description (optional) |Description of the scene setup. Length must not exceed 255 characters. |
   |Affiliated project |Project to which the scene belongs. You cannot switch when creating a scene. To switch, close the dialog and modify it from the top navigation bar. |
   |Tag (optional) |Add tags to the scene to identify and manage it more easily. You can click **Add a row** multiple times to add several tags, up to 20 tags in total. |
