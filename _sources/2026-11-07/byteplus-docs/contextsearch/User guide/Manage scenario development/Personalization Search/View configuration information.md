After creating a personalized search scenario, you can view its configuration information and modify related settings according to business needs. This topic describes how to view configuration information for a personalized search scenario.

<span id="K70G0ie1"></span>
## Prerequisites

Personalization search scenarios have been created and initialized. For detailed operation, see [Create a scenario](https://docs.byteplus.com/en/docs/contextsearch/Create_a_scenario) and [Initialize a personalization search scenario](https://docs.byteplus.com/en/docs/contextsearch/Basic_configuration).

<span id="MlfFbDaS"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. Select **My Scene** in the left navigation panel, then click the target personalized search push scenario.

4. Click the top\-right corner on the target personalized search and recommendation scenario page<span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_c0fa3b8ee25f6f32b1a40b6b6f218982.png) </span>Icon, select the **Scenario Configuration** tab to view the personalized search scenario's **Basic information**, **Feature storage configuration**, **Access information**, **Inference service**, and **Model storage**.

   
   |**Category** |**Details** |
   |---|---|
   |Basic information |Includes the ID, name, description, creation time, and tags of the personalized search and recommendation scenario. |
   |Feature store configuration |Includes the storage service and instance name/ID used in the personalized search and recommendation scenario. |
   |Access information |Includes the virtual private cloud, availability zone, and subnet of the personalized search and recommendation scenario. |
   |Inference service |Includes the model and inference service used in the personalized search and recommendation scenario. |
   |Model storage |Includes the buckets and paths used by the personalized search scenario. |
   


<span id="7xprLF4E"></span>
## More operations

You can click **Edit configuration** above the **Configuration management** area, then modify the scenario configuration in the **Basic configuration** dialog box. For details, see [Initialize a personalized search scenario](https://docs.byteplus.com/en/docs/contextsearch/Basic_configuration).
