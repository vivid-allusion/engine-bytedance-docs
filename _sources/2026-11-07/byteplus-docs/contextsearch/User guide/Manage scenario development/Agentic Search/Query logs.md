Agentic Search scenarios provide log query functions. When Agentic Search scenarios encounter exceptions requiring troubleshooting, you can select filter criteria such as log level, start and end time, and keywords to quickly locate the needed log content, facilitating scenario operations and maintenance. The default provides running logs within 7 days for Agentic Search scenarios, displayed in chronological order. This topic describes how to query logs.

<span id="OEA2mzNJ"></span>
## Prerequisites

The Agentic Search scene has been created and initialized. For more information, see [Create a scenario](https://docs.byteplus.com/en/docs/contextsearch/Create_a_scenario) and [Initialize an Agentic Search scenario](https://docs.byteplus.com/en/docs/contextsearch/Initialize_an_Agentic_Search_scenario).

<span id="ULKx9QWr"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, select **My Scene**, then click the target Agentic Search scene.

4. At the top of the page, click the **Logs** tab.

5. On the log query page, select the log level, start and end time, keywords, and other filter criteria as needed. The system automatically filters logs that meet the criteria and displays them in the log list below.
