After configuration of the multimodal search scenario, you can invoke the multimodal search capability through the API. The multimodal search scenario provides call examples to help you understand the interface request format and response results, enabling quick application integration. This article explains how to view call examples.

## Prerequisites

Created and initialized multimodal search scenarios. For detailed operations, see [Create a scenario](https://docs.byteplus.com/en/docs/contextsearch/Create_a_scenario) and [Initialize a multimodal search scenario](https://docs.byteplus.com/en/docs/contextsearch/Initialize_a_multimodal_search_scenario).

## Procedure

1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation pane, select **My Scene**, then click the target multimodal search scenario.

4. Click on the right side of the page![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_77957c2465a295f7c4c33f66bd77ad27.png)the icon to open the **Scene Configuration** panel, then select the **Invocation Example** tab.

5. In the **Invocation Example** tab, under the **Select Capability** step, choose the capability to invoke.

6. In the **Invocation Example** tab, under the **Select API Key** step, click **Quick fill API Key**.

   1. In the pop\-up window, click **Select and fill** under the **Operation** column of the target API Key.

   2. Copy the code below and set the API Key as an environment variable.

7. In the **Invocation Example** tab, under the **Select Invocation Example** step, select the invocation scenario language, then copy the code below to call the scenario.
