Multimodal search scenarios provide log query functionality. When multimodal search scenarios encounter exceptions requiring troubleshooting, you can select filter criteria such as log level, start and end time, file, and keywords to quickly locate the needed log content, facilitating scenario operations and maintenance. By default, the running logs within 1 hour of the multimodal search scenario are provided and displayed in chronological order. This topic describes how to query logs.

## Prerequisites

Created and initialized multimodal search scenarios. For detailed operations, see [Create a scenario](https://docs.byteplus.com/en/docs/contextsearch/Create_a_scenario) and [Initialize a multimodal search scenario](https://docs.byteplus.com/en/docs/contextsearch/Initialize_a_multimodal_search_scenario).

## Procedure

1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation pane, select **My Scene**, then click the target multimodal search scenario.

4. Click on the right side of the page![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_77957c2465a295f7c4c33f66bd77ad27.png)The icon to open the **Scene Configuration** panel, then select the **Log Query** tab.

5. In the **Logs** area, select filter criteria such as log level, start and end time, file, and keywords as needed. The system automatically filters logs that meet the criteria and displays them in the log list below.
