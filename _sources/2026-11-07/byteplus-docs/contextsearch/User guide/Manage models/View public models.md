In ContextSearch, the system provides preset common models, including various types such as Embedding, Rerank, and LLM models, e.g., Doubao 1.6, 1.8, and 2.0 models. You can directly associate common models when you create inference services. This topic describes how to view common models.

<span id="88UTAN7h"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. Select **Model management \> Models and inference** in the left navigation bar, then click the target model under the **Common models** tab.

4. In the model details panel, select the **Model property** or **Performance metrics** tab to view model information.
