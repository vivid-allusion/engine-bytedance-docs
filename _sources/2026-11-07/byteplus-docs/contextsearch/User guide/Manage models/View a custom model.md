After creating a custom model, you can view the created custom model. This topic describes how to view a custom model.

<span id="Ya0XxQYG"></span>
## Prerequisites

custom model created. For specific actions, see [Create a custom model](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_model).

<span id="vrMcOWm4"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation pane, select **Model and reasoning \> Model management**, click the **Custom model** tab, then click the target model.

4. In the model details panel, select the **Model property** or **Performance metrics** tab to view model information.
