You can delete the model when your custom model is no longer needed. This topic describes how to delete a custom model.

<span id="AgDG88sE"></span>
## Prerequisites

A custom model is created. For details, see [Create a custom model](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_model).

<span id="crXQfS0K"></span>
## Precautions


* You cannot delete a model if it has associated inference services. To delete, you must first delete the associated inference services. For details, see [Delete a custom inference service](https://docs.byteplus.com/en/docs/contextsearch/Delete_a_custom_inference_service).

* Custom model deletion cannot be recovered. Proceed with caution.


<span id="crXQfS0K"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, select **Model management \> My models**, click the **Custom model** tab, then click **Delete** in the **actions** column of the target model.

4. In the popup dialog, click **OK**.
