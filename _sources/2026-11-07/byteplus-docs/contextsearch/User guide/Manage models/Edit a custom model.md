After creating a custom model, you can edit the model's configuration information. This topic describes how to edit a custom model.

<span id="Xb8g8C8k"></span>
## Prerequisites

custom model created. For specific actions, see [Create a custom model](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_model).

<span id="pL124X0Q"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. In the left navigation bar, choose **Model and reasoning \> Model management**, click the **Custom model** tab, then click **Edit** in the **actions** column of the target model.

4. In the **Edit model** panel, modify the model's configuration information, then click **Save**. For parameter details, see [Create a custom model](https://docs.byteplus.com/en/docs/contextsearch/Create_a_custom_model).
