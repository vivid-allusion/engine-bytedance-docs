You can delete an API Key promptly when it is no longer needed to avoid security risks. This topic describes how to delete an API Key.

<span id="jJBCLcRE"></span>
## Precautions


* You cannot delete an API Key if there are scenarios associated with it. To delete it, modify the API Key linked to the scenario or delete the scenario first. For more informationetailed steps, see [Manage scenarios](https://docs.byteplus.com/en/docs/contextsearch/Manage_scenarios).

* After deleting an API Key, you cannot continue to use it to call the inference service, nor can it be recovered. Proceed with caution.


<span id="AYXCONON"></span>
## Procedure


1. Log on to the [ContextSearch console](https://console.byteplus.com/context-search).

2. In the top navigation bar, select the target project and region.

3. Select **API Key** in the left navigation bar, then click **Delete** in the Actions column of the target API Key.

4. In the pop\-up dialog, confirm the name of the API Key to delete, then click **Delete**.
