VCI provides log collection capabilities, including keyword search, SQL analysis, and more. It supports second\-level querying and analysis for massive volumes of data, provides efficient and real\-time log processing tools, facilitates the use of log data, and effectively improves operation and maintenance capabilities as well as data analysis efficiency.

VCI logging is implemented based on BytePlus TLS. For details, see [What is TLS?](https://docs.byteplus.com/en/docs/tls/What_is_TLS)
