When you use VCI pods in VKE, try to keep the usage consistent with native pods as much as possible. This topic describes the kubectl commands supported by VCI.


|Command | Support status |Description |
|---|---|---|
|kubectl create |Supported |For details of kubectl commands, see the [official Kubernetes documentation](https://kubernetes.io/docs/reference/kubectl/kubectl/). |
|kubectl run |Supported ||
|kubectl edit |Supported ||
|kubectl delete |Supported ||
|kubectl top |Supported ||
|kubectl drain |Supported ||
|kubectl taint |Supported ||
|kubectl logs |Supported ||
|kubectl exec |Supported ||
|kubectl cp |Supported ||
|kubectl attach |Not supported ||
|kubectl port\-forward |Not supported ||
|kubectl debug node |Not supported ||
|kubectl debug pod |Not supported ||
