VCI provides multiple instance families. Different instance types offer varying virtualization capabilities and support a wide range of application scenarios.

Based on differences in underlying hardware capabilities, instance types are divided into distinct specification families. Each family adopts different processors, CPU/memory ratios, cloud disk types, and network card virtualization methods to deliver differentiated computing, storage, and network performance. According to configurations such as CPU and memory, each instance family has multiple VCI instance specifications. A higher specification indicates stronger performance.
