This topic describes several ways to create VKE clusters and the scenarios each method is suitable for. Select the method that matches your requirements and refer to the corresponding guide.


|Creation method |**Application scenario** |
|---|---|
|[Creating managed clusters](https://docs.byteplus.com/en/docs/vke/Creating-a-cluster) |Creates clusters that support all VKE capabilities. This method lets you control the underlying infrastructure of VKE clusters and perform fine\-grained resource planning and configuration. |
|[Registering existing clusters](https://docs.byteplus.com/en/docs/vke/Register_the_cluster_by_proxy) |Register an existing Kubernetes cluster to the VKE platform for unified management via reverse tunnel technology. This method is mainly applicable to enterprises that simultaneously use services from multiple public cloud providers. |
|[Creating a managed heterogeneous computing cluster](https://docs.byteplus.com/en/docs/vke/Creating_a_managed_heterogeneous_computing_cluster) |A simplified method for creating managed clusters. Based on a preset template, it creates a heterogeneous computing cluster environment with specific configurations and components with one click. It is mainly used for AI inference and AI training scenarios, helping you quickly set up a usable cluster environment while reducing configuration errors and repetitive work. |
|[Creating IPv4/IPv6 dual-stack clusters](https://docs.byteplus.com/en/docs/vke/Deploying-an-IPv4_IPv6-dual-stack-cluster-using-VKE) |[[Beta - Apply for Trial](https://docs.byteplus.com/en/docs/vke/How-do-I-apply-for-beta-features)] Use the IPv4/IPv6 dual\-stack solution to create a Kubernetes cluster. A dual\-stack cluster supports IPv6. |
