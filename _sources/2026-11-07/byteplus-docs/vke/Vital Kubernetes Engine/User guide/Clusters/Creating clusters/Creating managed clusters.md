Vital Kubernetes Engine (VKE) creates and manages master nodes of a cluster. You only need to create worker nodes. This topic describes how to create a VKE cluster in the VKE console.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* You have already registered a BytePlus account and finished the necessary preparations, such as identity verification, account recharge, and authorization. For details, see [Preparations](https://docs.byteplus.com/en/docs/vke/Preparations).

* Your BytePlus account balance is not zero after vouchers are excluded. In this way, you can create pay\-as\-you\-go resources as expected.

* The permissions to use VKE and for VKE to access cloud resources have been granted. For details, see [Cloud service dependencies](https://docs.byteplus.com/en/docs/vke/Dependencies-between-VKE-and-other-cloud-services).

* Check the quota limits for the VKE cluster and the dependent cloud services. For details, see [Limits](https://docs.byteplus.com/en/docs/vke/Limits).

* If you need to create a Linux\-based Elastic Compute Service (ECS) instance and bind an SSH key pair to it, ensure you have a key pair in the target project. For details, see [Creating key pairs](https://docs.byteplus.com/en/docs/ecs/Creating-key-pairs).

* If you want to add an existing ECS instance to a cluster, ensure that the cluster and the ECS instance are in the same Virtual Private Cloud (VPC).

* A VMP workspace has been created. For details, see [Creating workspaces](https://docs.byteplus.com/en/docs/vmp/Creating-workspaces).


<span id=".6LS555So6K-05piO"></span>
## Cost information

Creating a cluster may incur costs for basic cloud resources such as cloud load balancers, NAT gateways, elastic IP addresses, and volumes. You can view the actual fees in the **Configuration fee** section at the bottom of the Create cluster page. For more billing descriptions, see [Product billing](https://docs.byteplus.com/en/docs/vke/Billing).

## Procedure


1. Log in to the [VKE console](https://console.byteplus.com/vke).

   <div data-tips="true" data-tips-type="default" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>

2. In the left navigation bar, click **Cluster**. On the page that appears, click **Create cluster**.

3. In the **Create cluster** dialog box, go to the **Custom managed clusters** section and click **Create now**.

4. On the **Create cluster** page, follow the wizard to configure the cluster.
