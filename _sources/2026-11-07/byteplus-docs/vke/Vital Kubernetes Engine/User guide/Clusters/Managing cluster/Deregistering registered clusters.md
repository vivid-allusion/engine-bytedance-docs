If you no longer need to manage a registered cluster in VKE, you can deregister the cluster to release resources. This topic describes how to deregister a registered cluster.

<span id=".5L2_55So6ZmQ5Yi2"></span>
## Limits

Deregistering a cluster does not delete the cluster. This operation only removes the cluster from VKE.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [VKE console](https://console.byteplus.com/vke).

2. In the left navigation pane, click **Cluster**.

3. On the Cluster page, find the target registered cluster and click **Deregister** in the Actions column on the right side to deregister the cluster.
