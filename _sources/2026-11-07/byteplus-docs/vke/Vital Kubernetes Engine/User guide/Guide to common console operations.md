When using VKE, you may encounter various issues, such as creating different types of clusters, remotely connecting to clusters, as well as configuring networking or storage, observability, or cluster diagnosis and inspections. This topic mainly describes the common features and operations of VKE. This helps you use VKE clusters in a more secure, reliable, flexible, and efficient manner.

* For usage notes and constraints of VKE, see [Usage notes](https://docs.byteplus.com/en/docs/vke/Usage-notes) and [Limits](https://docs.byteplus.com/en/docs/vke/Limits).

* For information you need to understand before creating a VKE cluster, see [Guide for beginners](https://docs.byteplus.com/en/docs/vke/Quick-guide).

|Feature |Application scenario |Operation guide |
|---|---|---|
|IAM permissions |It controls what VKE resources each account, user group, or role can access and what operations they can perform.
