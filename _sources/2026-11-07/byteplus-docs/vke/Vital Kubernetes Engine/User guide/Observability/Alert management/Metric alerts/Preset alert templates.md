Preset alert templates are used to monitor the running status of the VKE cluster control plane, workloads, nodes, and related add\-ons. This topic describes the trigger conditions, PromQL configurations, rule descriptions, and alert handling procedures for each preset alert rule.

## **VKE control plane add\-on**

Check whether all API requests fail, and contact the platform team for processing. |
