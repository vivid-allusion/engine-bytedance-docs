Vital Kubernetes Engine (VKE) supports managed node pools, which significantly improve fault tolerance for GPU\-accelerated computing resources and increase resource utilization of node pools. These pools reduce operational complexity and improve maintenance efficiency.

<span id=".5o6o6I2Q6KeE5YiZ"></span>
## Recommended rules

Managed node pools support self\-healing. VKE provides system\-recommended check and self\-healing rules for ease of use. Recommended rules provide different check items and self\-healing actions depending on whether managed node pools are GPU\-accelerated.

<span id=".Z3B1LeiKgueCueaxoA=="></span>
### GPU\-accelerated node pools

The following table describes the checks and self\-healing actions that are included in recommended rules for GPU\-accelerated node pools.


|Check item |Required |Self\-healing |Self\-healing action |
|---|---|---|---|
|GPU disconnection failure |Yes |Enable |Cordon the node |
|GPU internal failure |Yes |Enable |Cordon the node |
|Recoverable GPU memory failure |Yes |Enable |Cordon the node |
|Unrecoverable GPU memory failure |Yes |Enable |Cordon the node |
|GPU runtime failure |Yes |Enable |Cordon the node |
|GPU runtime warning |Yes |Enable |Cordon the node |
|GPU link failure |Yes |Enable |Cordon the node |
|GPU link performance degradation |Yes |Enable |Cordon the node |
|GPU driver failure |Yes |Enable |Cordon the node |
|GPU driver warning |Yes |Enable |Cordon the node |
|ECS instance failure |No |\- |\- |
|kubelet failure |Yes |Enable |Restart kubelet |
|Runtime failure |Yes |Enable |Restart containerd |
|Time synchronization service error |Yes |Enable |Restart chrony |
|Read\-only node file system |No |\- |\- |
|Node kernel failure |No |\- |\- |
|Node kernel deadlock |No |\- |\- |

## Prerequisites


* The target cluster is in the **Running** state.

* (Optional) To configure the volume encryption feature, ensure that you have activated the KMS service in advance and have completed key creation.


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [VKE console](https://console.byteplus.com/vke).

2. In the left navigation bar, click **Cluster**.

3. In the cluster list, click the name of the target cluster.

4. In the left navigation bar of the cluster management page, click **Nodes** \> **Node pool**.

5. Click **Create node pool** above the node pool list.

6. Configure the relevant parameters by following the on\-screen prompts and referring to the examples below.
