The apmplus\-server\-agent is an application performance monitoring add\-on that collects service and host monitoring data and sends the data to the application performance monitoring service.

<span id="5Nq6hChu"></span>
## Add\-on versions

For information about the historical release records of the add\-on, as well as new features and optimization descriptions for each version, see [Add-on release records](https://docs.byteplus.com/en/docs/apmplus/Apmplus-server-agent_release_notes).

<span id="Io6kkjs6"></span>
## Installing add\-ons


1. Log in to the [VKE console](https://console.byteplus.com/vke).

2. In the left navigation pane, click **Cluster**. In the right part of the page, click the target cluster name to open the management page of this cluster.

3. In the left navigation bar of the cluster management page, click **Addons**. On the page that appears, click the **Monitoring** tab.

4. Move the pointer over the add\-on card and click **Deploy** to install the add\-on.


<span id="JvQ57ujX"></span>
## Upgrading add\-ons

The add\-on is released in new versions at irregular intervals to provide new features or fix known bugs. When the add\-on card displays that a new version is available, we recommend upgrading the add\-on promptly. To ensure a smooth business transition, we recommend upgrading the add\-on during business off\-peak hours. For upgrade procedures and considerations, see [Upgrading the apmplus-server-agent add-on](https://docs.byteplus.com/en/docs/apmplus/apmplus-server-agent_component_upgrade).
