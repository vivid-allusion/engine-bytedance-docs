FSX provides unified policies for access, authentication, and management. It offers a node\-level, unified, and easy\-to\-access file system client for storage systems such as FileNAS, Parallel File Storage, and Torch Object Storage (TOS). This enables Vital Kubernetes Engine (VKE) to use the same FSX client across platforms to support file system mounting, access, and other rich I/O and security features. For details, see [FSX overview](https://docs.byteplus.com/en/docs/tos/Overview).

Compared with using native storage directly, the FSX client delivers more universal high\-performance capabilities, along with greater flexibility and stronger compatibility.
