To achieve low latency, it is recommended that you select the corresponding service address based on the region where your resources are located.


|**Available Regions** |**RegionId** |**New Service Access Address** |**Legacy Service Access Address** |
|---|---|---|---|
|Asia Pacific (Johor) |ap\-southeast\-1 |vke.ap\-southeast\-1.byteplusapi.com |open.byteplusapi.com |
|Asia Pacific (Jakarta) |ap\-southeast\-3 |vke.ap\-southeast\-3.byteplusapi.com ||
|China (Beijing) |cn\-beijing |vke.cn\-beijing.byteplusapi.com.cn ||
|China (Guangzhou) |cn\-guangzhou |vke.cn\-guangzhou.byteplusapi.com.cn ||
|China (Shanghai) |cn\-shanghai |vke.cn\-shanghai.byteplusapi.com.cn ||
|China (Hong Kong) |cn\-hongkong |vke.cn\-hongkong.byteplusapi.com ||

### <div data-tips="true" data-tips-type="default" data-tips-is-title="true">tip</div>



* <div data-tips="true" data-tips-type="default">For latency\-sensitive businesses, we recommend that you specify the Region parameter in the request Header. For more details, please refer to the <a href="https://docs.byteplus.com/en/docs/vke/Common-parameters">Public parameters</a> documentation.</div>


* <div data-tips="true" data-tips-type="default">The domain name serves as the access point for the API and does not necessarily represent the actual region where the service is provisioned.</div>
