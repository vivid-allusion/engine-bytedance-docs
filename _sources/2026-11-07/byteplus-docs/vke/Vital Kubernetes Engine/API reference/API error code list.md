This topic describes how to query the information of all error codes involved when you call VKE APIs.

<span id="VZ0sCxAX"></span>
## Error code type

The platform supports the following two error code types.

<span id="RKSnHTIE"></span>
### Common error codes of the platform

These error codes start with `1000`. Please refer to [Common error codes](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes) for details.

<span id="hOrXdqD4"></span>
### Product error codes

Error codes relate to the business logic of the cloud product. Such error codes include public error codes of the cloud product and API\-specific error codes. HTTP code is `4xx` or `5xx`. You can visit [OpenAPI Center](https://api.volcengine.com/api-docs/view/errorcode?serviceCode=vke&version=2022-05-12) for details.

On the right of **Error code**, click the <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_65183e460835e9b275060a725a2d4df0.png) </span> button to query information.
