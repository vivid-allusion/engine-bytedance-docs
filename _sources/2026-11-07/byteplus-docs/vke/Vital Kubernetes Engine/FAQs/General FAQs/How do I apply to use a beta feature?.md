Some features of VKE and VCI are currently in the beta phase. To use these features, submit an application.

<span id=".5L2_55So6aG755-l"></span>
## Usage notes


* Only accounts that have completed enterprise verification can apply for a trial of beta features. For details, see [Identity authentication](https://docs.byteplus.com/en/docs/byteplus-platform/docs-signing-up-your-account).

* For released features and their availability status, see [VKE release notes](https://docs.byteplus.com/en/docs/vke/Release-notes) and [VCI release notes](https://docs.byteplus.com/en/docs/vke/VCI-Release-notes).

* When service features are provided as beta features, access to the corresponding service documentation are managed through an allowlist. You need to apply for permissions to view the documentation.


<span id=".55Sz6K-35pa55rOV"></span>
## Application method

Contact your **account manager** of BytePlus to apply for a trial of beta features.

For faster access, you can provide the following content:


* The ID of your BytePlus root user.

* The name of the verified enterprise.

* The name of the beta feature that you are applying for a trial.

* The scenarios and requirements for using this feature.
