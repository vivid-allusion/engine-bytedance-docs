## Issue description

After you install an add\-on, update its configuration or version, or uninstall it, the add\-on may remain in the **Installing**, **Updating**, or **Uninstalling ** state for an extended period.

&nbsp;

<span id=".6Kej5Yaz5pa55rOV"></span>
## Solution

In normal scenarios, the add\-on should not remain in the **Installing**, **Updating**, or **Uninstalling** state for more than 5 minutes. If the add\-on remains in one of the preceding states for more than 5 minutes,  [submit a ticket to ](https://console.byteplus.com/workorder/create?step=2&SubProductID=P00000210) and provide a detailed description of the issue and related information, such as logs, to obtain technical support.
