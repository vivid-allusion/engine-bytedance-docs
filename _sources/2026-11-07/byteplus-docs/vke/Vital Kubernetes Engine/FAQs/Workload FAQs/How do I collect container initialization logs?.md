VKE provides log collection based on BytePlus TLS. You can configure collection rules in Log management to query container initialization logs. For details, see [Log management](https://docs.byteplus.com/en/docs/vke/Log-management).

You can also use the Kubernetes API to collect container initialization logs. For more information, see the [Kubernetes documentation](https://kubernetes.io/zh-cn/docs/reference/kubernetes-api/workload-resources/pod-v1/#get-%E8%AF%BB%E5%8F%96%E6%8C%87%E5%AE%9A-pod-%E7%9A%84%E6%97%A5%E5%BF%97).
