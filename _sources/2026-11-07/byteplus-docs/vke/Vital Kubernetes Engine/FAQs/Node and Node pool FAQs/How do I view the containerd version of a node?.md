The containerd runtime version of a node in a cluster may vary based on cluster creation time. You can perform the following steps to view the version:

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For information about the Kubernetes versions supported by VKE and corresponding containerd runtime versions, see <a href="https://docs.byteplus.com/en/docs/vke/Kubernetes-version-release-notes">Kubernetes version release notes</a>.</div>



1. Log in to the [VKE console](https://console.byteplus.com/vke).

2. In the left navigation bar, click **Cluster**. On the page that appears, find the target cluster and click the name of the cluster.

3. In the left navigation bar of the cluster management page, click **Nodes** \> **Node**.

4. Find the target node and click the node name.

5. On the **Overview** tab of the **Node details page**, view **Kubernetes information**.
