You can view node resource usage in the console.


1. Log in to the [VKE console](https://console.byteplus.com/vke). In the left navigation bar, click **Cluster**.

2. Click the name of the target cluster. In the left navigation bar of the cluster management page, click **Node**.

3. On the **Node** page, view information about the target node, such as CPU usage and memory usage.

   You can also click the name of the target node to go to the node details page to view the details of the node.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Nodes reserve part of the CPU and memory resources to run Kubernetes system components and resources. Therefore, the total resources for your nodes are not equal to those available in the cluster. For details, see <a href="https://docs.byteplus.com/en/docs/vke/Node-resource-reservation-policies">Policy for node reserved resources</a>.   </div>
