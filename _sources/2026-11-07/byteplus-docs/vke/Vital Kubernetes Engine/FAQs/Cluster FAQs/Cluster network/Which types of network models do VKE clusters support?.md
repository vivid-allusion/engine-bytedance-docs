VKE supports the following two network (CNI) models:


* Flannel: an independent underlay network solution, based on which a high\-performance network for clusters can be built along with the global routing capabilities of VPCs.

* VPC\-CNI: an underlay network solution implemented based on the elastic network interfaces (ENI) of VPCs, providing high network performance.


For more information and configuration about pod networking, see [Pod networking](https://docs.byteplus.com/en/docs/vke/Container-networks).
