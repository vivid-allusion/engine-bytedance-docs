By default, the EIP of a cluster is the IP address for public access exposed by the cluster API server. The EIP can be obtained only if the public access feature is enabled for the cluster API server.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [VKE console](https://console.byteplus.com/vke).

2. In the left navigation bar, click **Cluster**. On the page that appears, find the target cluster and click the name of the cluster.

3. On the **Overview** tab of the **Overview** page for the cluster, obtain the public access IP address.

   <div data-tips="true" data-tips-type="warning" data-tips-is-title="true" data-wrapper-indent="1">Warning   </div>
   

   <div data-tips="true" data-tips-type="warning" data-wrapper-indent="1">If the public access feature is not enabled for the cluster, switch on Public NAT for internet endpoint. Then, you can obtain the public access IP address.   </div>
