VKE allows you to specify Kubernetes clusters as private resource pools by using CP of BytePlus, which meets the custom build and packaging requirements of enterprises.

You can import a VKE cluster as a private resource pool, and CP accesses the imported cluster by using the KubeConfig of the cluster. For detailed operations, see [Creating private resource pools](https://docs.byteplus.com/en/docs/cp/Create_a_VKE_private_build_resource_pool).
