The Kubernetes version used by a cluster may vary based on cluster creation time. You can perform the following steps to view the version:

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">For the release notes for Kubernetes versions supported by VKE, see <a href="https://docs.byteplus.com/en/docs/vke/Kubernetes-version-release-notes">Kubernetes version release notes</a>.</div>



1. Log in to the [VKE console](https://console.byteplus.com/vke). 

2. In the left navigation bar, click **Cluster**. On the page that appears, find the target cluster and click the name of the cluster.

3. On the **Overview** page of the cluster, view the **Kubernetes version** in the **Basic information** section.
