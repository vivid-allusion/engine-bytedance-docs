When you use VKE, if a resource quota exceeds the upper limit, error messages, such as **ExceededQuota**, will appear on the page. To increase the quota, perform the steps described in this topic to apply for a quota increase.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">Warning</div>


<div data-tips="true" data-tips-type="warning">If the following types of resource quotas exceed the upper limits, you cannot increase the quotas. You can obtain additional quota by creating more clusters or node pools.</div>



* <div data-tips="true" data-tips-type="warning">Cluster resource tags</div>


* <div data-tips="true" data-tips-type="warning">Node pool resource tags</div>


* <div data-tips="true" data-tips-type="warning">Node pool ECS instance tags</div>



<div data-tips="true" data-tips-type="warning">For details about quotas for each VKE resource, see <a href="https://docs.byteplus.com/en/docs/vke/Limits">Limit</a>.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Quota Center](https://console.byteplus.com/quota/productList).

2. On the **Product list** page, search for **vke**, and click **vke**.

3. On the page that appears, view quota parameters related to Vital Container Instance (VCI).

   You can apply for a higher quota for a supported resource based on your business requirements.
