This topic introduces the latest VKE feature updates. New features are rolled out gradually across regions. Feel free to try them when they become available.

> **tip**

* > **Release region** refers to the region where the feature was first released. The release regions added later will not be put in the historical release notes. For the regions where features are actually available, please refer to the information on the console pages.

* > [**Beta**] After a feature becomes generally available, its historical beta records are not updated. For the latest iteration details, refer to the most recent related release note.

* > The release notes on this page cover the records of features released in VKE **this year**. For the historical release notes, see [Historical release notes](https://docs.byteplus.com/en/docs/vke/History_feature_release_notes).
