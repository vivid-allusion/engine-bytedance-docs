Add\-ons are provided by Vital Kubernetes Engine for clusters and include various types, such as network, storage, monitoring, DNS, security, image, and GPU. This document primarily records the release notes, description, impact, and other related information for each add\-on.

Currently, add\-on versions can be in one of the following two states. Please decide whether to upgrade the add\-on(s) based on the version status and the description of changes.


* **Being maintained**: Indicates that the add\-on for this version is being maintained. You can upgrade the add\-on to this version and continue to use it.

* **EOM**: Indicates that this version of the add\-on is no longer maintained. Using this version may affect your Vital Kubernetes Engine service. It is recommended that you upgrade the add\-on to the latest version.
