The p2p\-accelerator add\-on accelerates concurrent container image pulling on a large scale by using the P2P technology. This topic describes the change history of the p2p\-accelerator add\-on.

For more information about the add\-on and how to use it, see [p2p-accelerator](https://docs.byteplus.com/en/docs/vke/p2p-accelerator-add-on).

<span id=".6YWN572u6K-05piO"></span>
## Description


* When you upgrade the add\-on, the configurations displayed in the console will be retained for each version.

* The retention of user\-defined configurations is not guaranteed for each version. For details, see the descriptions in the **Impact** column.
