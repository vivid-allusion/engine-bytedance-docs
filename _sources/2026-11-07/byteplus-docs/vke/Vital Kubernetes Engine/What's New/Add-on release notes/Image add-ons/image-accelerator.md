The image\-accelerator add\-on achieves container image lazy loading by using Nydus, which accelerates image pulling during pod creation. This topic describes the change history of the image\-accelerator add\-on.

For more information about the add\-on and how to use it, see [image-accelerator](https://docs.byteplus.com/en/docs/vke/image-accelerator-add-on?lang=en).
