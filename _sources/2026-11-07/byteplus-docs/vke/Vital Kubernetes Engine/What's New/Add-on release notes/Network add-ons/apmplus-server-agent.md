The apmplus\-server\-agent is an application performance monitoring add\-on that collects service and host monitoring data and sends the data to the application performance monitoring service.

For the release notes of apmplus\-server\-agent add\-on, see [apmplus-server-agent](https://docs.byteplus.com/en/docs/apmplus/Apmplus-server-agent_release_notes). For more information about add\-ons and how to use them, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-overview).
