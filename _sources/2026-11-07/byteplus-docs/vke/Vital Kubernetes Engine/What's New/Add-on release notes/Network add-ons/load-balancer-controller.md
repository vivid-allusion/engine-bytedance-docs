The load\-balancer\-controller add\-on is offered by Vital Kubernetes Engine (VKE) as a controller add\-on for lifecycle management of various load balancers. This topic describes the release notes for the load\-balancer\-controller add\-on.

For more information, refer to [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-overview).
