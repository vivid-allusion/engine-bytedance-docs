The cronhpa add\-on is used to achieve the scheduled scaling of workloads. This topic describes the change history of the cronhpa add\-on.

For more information about add\-ons and how to use them, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-management).
