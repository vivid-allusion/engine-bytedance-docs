The Karpenter add\-on is a real\-time cluster node autoscaling component that scales out nodes in response to events, delivering better elasticity. This topic describes the change history of the karpenter add\-on.

For more information about add\-ons and how to use them, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-management).
