The pod\-identity\-webhook add\-on is an auxiliary add\-on for the IAM Roles for Service Accounts (IRSA) feature, providing automated assistance for using IRSA capabilities in clusters. This topic includes the change logs of the pod\-identity\-webhook add\-on.

For more details on the add\-on, see [Managing add-ons](https://docs.byteplus.com/en/docs/vke/Add-on-overview).
