The security\-scan add\-on provides security baseline inspection for clusters. After the add\-on is uninstalled, all inspection data is automatically deleted. This topic describes the change history of the security\-scan add\-on. For more information about the add\-on and how to use it, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-management).
