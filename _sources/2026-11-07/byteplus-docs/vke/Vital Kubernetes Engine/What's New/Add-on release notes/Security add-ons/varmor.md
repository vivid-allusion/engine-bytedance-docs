varmor is a cloud\-native container sandbox system based on AppArmor/BPF/Seccomp technologies. It provides ‌container hardening and runtime protection‌ for workloads in clusters. This topic provides the change log of the varmor add\-on.

For more information about the add\-on and how to use it, see [varmor](https://docs.volcengine.com/docs/6460/2430927).
