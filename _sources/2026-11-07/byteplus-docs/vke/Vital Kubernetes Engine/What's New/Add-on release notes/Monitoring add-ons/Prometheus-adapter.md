The Prometheus\-adapter is an add\-on designed for the Vital Managed Service for Prometheus (VMP). It converts Prometheus metrics into the format required by the custom metric API. This topic describes the change history of the Prometheus\-adapter add\-on.

For more information about add\-ons and how to use them, see Add\-on management.
