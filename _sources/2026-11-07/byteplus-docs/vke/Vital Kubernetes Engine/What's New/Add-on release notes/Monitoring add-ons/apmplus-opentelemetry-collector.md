The apmplus\-opentelemetry\-collector add\-on is an application performance monitoring add\-on, which collects the OpenTelemetry data and Prometheus metrics, and sends them to the application performance monitoring service.

For the version history of the apmplus\-opentelemetry\-collector add\-on, see  [apmplus-opentelemetry-collector](https://docs.byteplus.com/en/docs/apmplus/apmplus-opentelemetry-collector_component_release_notes). For more information about the add\-on and instructions for using it, see  [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-overview).
