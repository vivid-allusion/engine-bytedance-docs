The event\-collector add\-on is a cluster event collection add\-on that collects cluster events and sends them to Torch Log Service (TLS). This topic describes the change history of the event\-collector add\-on.

For more information about add\-ons, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-management).
