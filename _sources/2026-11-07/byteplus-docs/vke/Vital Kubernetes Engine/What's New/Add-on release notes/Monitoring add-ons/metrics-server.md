The metrics\-server add\-on is a core cluster monitoring add\-on that aggregates key monitoring metrics for resources across the cluster. This topic describes the change history of the metrics\-server add\-on.

For more information about add\-ons, see [Add-on management](https://docs.byteplus.com/en/docs/vke/Add-on-management).
