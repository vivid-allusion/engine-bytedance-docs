The Vital Kubernetes Engine (VKE) will stop the metrics\-collector add\-on service on October 9, 2025, including those installed in existing container clusters. To ensure proper container metrics monitoring, use [Container basic observability](https://docs.byteplus.com/en/docs/vke/Monitoring-overview), and install the Prometheus Agent to collect metrics. With more powerful features, Container basic observability enables the collection, monitoring, and alerting of cluster, resource, and application metrics.

For details on container observability metrics, refer to [Vital Kubernetes Engine metrics](https://docs.byteplus.com/en/docs/vmp/Common-metrics-of-Vital-Kubernetes-Engine).
