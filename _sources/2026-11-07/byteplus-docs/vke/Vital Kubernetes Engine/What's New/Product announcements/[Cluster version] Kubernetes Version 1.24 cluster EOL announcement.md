The Vital Kubernetes Engine (VKE) will no longer provide technical support for Kubernetes version 1.24 as of Beijing time **April 30, 2025**. After the EOM of this version, you cannot create clusters running this end\-of\-maintenance Kubernetes version. We cannot guarantee the quality and effectiveness of technical support for risks like the possible unstable operation and cluster upgrade failures caused by using this discontinued version. To ensure your business runs normally, upgrade the relevant clusters to a supported version as soon as possbile. As for how to upgrade clusters, refer to [Upgrading clusters](https://docs.byteplus.com/en/docs/vke/Upgrading-a-cluster). If you need to learn more about the different versions of VKE, refer to [Kubernetes versions support strategies](https://docs.byteplus.com/en/docs/vke/Kubernetes-version-support-policy).
