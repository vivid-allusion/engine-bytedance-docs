The Vital Kubernetes Engine (VKE) will no longer provide technical support for Kubernetes Version 1.30 as of Beijing time **October 30, 2026**. After the EOM of this version, you can no longer create Kubernetes 1.30 clusters. For risks such as unstable operation and cluster upgrade failures that may arise from this retired version, we cannot guarantee the quality or effectiveness of technical support. To ensure normal business operations, upgrade the relevant clusters to a supported version as soon as possible. As for how to upgrade clusters, refer to [Upgrading clusters](https://docs.byteplus.com/en/docs/vke/Upgrading-a-cluster).

If you want to learn more about VKE version support, see [Kubernetes version support policies](https://docs.byteplus.com/en/docs/vke/Kubernetes-version-support-policy).
