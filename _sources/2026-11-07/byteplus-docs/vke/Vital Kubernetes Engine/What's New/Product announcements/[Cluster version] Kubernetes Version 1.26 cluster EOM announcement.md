The Vital Kubernetes Engine (VKE) will no longer provide technical support for Kubernetes Version 1.26 as of **March 09, 2026 ** (Beijing time). After the EOM of this version, you cannot create a Kubernetes cluster of the end\-of\-maintenance version. Meanwhile, as for the risks covering the possible unsteady operation and cluster upgrade failure caused by this discontinued version, we will not guarantee the quality and effectiveness of our technical support. To ensure normal business operations, upgrade the relevant clusters to a supported version as soon as possible. As for how to upgrade clusters, refer to [Upgrading clusters](https://docs.byteplus.com/en/docs/vke/Upgrading-a-cluster).

If you want to learn more about the VKE version support policy, see [Kubernetes version support policies](https://docs.byteplus.com/en/docs/vke/Kubernetes-version-support-policy).
