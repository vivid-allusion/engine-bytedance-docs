After successfully creating a RabbitMQ instance, you can modify the instance's basic information anytime based on business needs. Currently, you can modify the instance name, description, and tags.

<span id="前提条件"></span>
## Prerequisites

The status of the RabbitMQ instance is **Running**.

<span id="操作步骤"></span>
## Operation steps


1. Log in to the [Message Queue for RabbitMQ console](https://console.byteplus.com/rabbitmq/).

2. On the **Instances** page, click the target instance name to enter the **Instance information** tab.

3. In the **Basic information** area, find the information you want to modify and click the<span>![图片](https://lf3-volc-editor.volccdn.com/obj/tos-cn-v-697126/ac73b9dec6644d919d75e373c08b5997.png) </span> icon to edit the corresponding information.

   You can modify the instance name, description, and tags.

4. Once the modification is complete, click<span>![图片](https://lf3-volc-editor.volccdn.com/obj/tos-cn-v-697126/dc71bd29215a4947ae3059b1df14852e.png) </span>Save to complete.
