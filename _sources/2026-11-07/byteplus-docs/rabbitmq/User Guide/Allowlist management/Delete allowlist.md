We recommend that you regularly maintain the allowlist and IP address list and promptly remove allowlists that are no longer needed. This topic describes the steps to delete an allowlist through the console.

<span id="AyR7hozL"></span>
## Prerequisites  

The allowlist to be deleted is not associated with any RabbitMQ instance; the **Number of associated instances** in the allowlist list is 0, and no instance appears under the **Instances** section on the allowlist details page.

<span id="JfuYBHDi"></span>
## Operation steps


1. Log in to [Message Queue for RabbitMQ Console](https://console.byteplus.com/rabbitmq).

2. Select the region of the instance from the top menu bar.

3. In the left navigation bar, click **Allowlist**.

4. Find the specified allowlist and select  **...**  \> **Delete** from the **Actions** column.

5. Confirm the allowlist name and ID to be deleted in the pop\-up dialog box, then click **OK**.
