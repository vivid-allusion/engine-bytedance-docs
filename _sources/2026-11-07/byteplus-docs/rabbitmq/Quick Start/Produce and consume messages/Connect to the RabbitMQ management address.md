Access the RabbitMQ instance management address via browser to use the open\-source RabbitMQ cluster management tool.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites


* The RabbitMQ instance has been successfully created. For detailed description, please refer to [Create instance](https://docs.byteplus.com/en/docs/rabbitmq/Create_instance).

* The private network address for using the Web UI cannot be accessed directly via browser. Please use the public network address instead. If you did not enable public network access when creating the RabbitMQ instance, enable it first. For instructions, see [Setting public network access](https://docs.byteplus.com/en/docs/rabbitmq/Set_public_network_access). 


<span id=".5pON5L2c5q2l6aqk"></span>
## Operation steps


1. Log in to [Message Queue for RabbitMQ console](https://console.byteplus.com/rabbitmq/).

2. On the **Instances** page, click the target instance name.

3. Copy and record the public network address of the **Web UI Endpoint** in the **Service access** area on the **Instances** details page.

4. Access the Web UI login page through a browser using the Web UI address.

   <span>![图片](https://portal.volccdn.com/obj/volcfe/cloud-universal-doc/upload_eed4b3a3c9883f79458cad0a84c76511.png) </span>

5. Enter your username and password, then click **Login**.

   Enter the RabbitMQ instance administrator username and password here. By default, the username and password are set when the instance is created.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you have changed the administrator username or password in the Web UI, use the updated credentials to log in.   </div>
   

   * <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">If you forget your username or password, reset them to set new credentials.    </div>
   

6. View the Web UI.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/044af004a56142b987d4e9f3253bea4a~tplv-goo7wpa0wc-image.image) </span>
