## Operation steps

The basic steps for getting started with RabbitMQ include setting up the development environment, creating related resources, and connecting to the RabbitMQ instance.


1. [Prepare environment](https://docs.byteplus.com/en/docs/rabbitmq/Prepare_the_environment)

   Register a BytePlus account. Complete enterprise verification. Set up the ECS, VPC, and other environments needed to use RabbitMQ.

2. [Create a RabbitMQ instance](https://docs.byteplus.com/en/docs/rabbitmq/Create_instance)

   Create a RabbitMQ instance on the console. RabbitMQ instances consist of stand alone and cluster versions. For higher business stability, the cluster version is recommended.

3. Connect to the instance, and then produce and consume messages

   * [Connect to the RabbitMQ management address](https://docs.byteplus.com/en/docs/rabbitmq/Connect_to_the_RabbitMQ_management_address)(optional)

      By accessing the management address of the RabbitMQ instance through a browser, you can access the cluster management tool of open\-source RabbitMQ to configure settings such as creating instance mirrored queues.

   * [Produce and consume messages](https://docs.byteplus.com/en/docs/rabbitmq/Produce_and_consume_messages_non_SSL_mode)

      After setting up the development environment and creating related service resources, you can connect to the RabbitMQ instance to send and receive standard messages.
