This section outlines the supported billing method, instance lifecycle, and pricing details for message queue for RabbitMQ.

<span id=".6K6h6LS557G75Z6L"></span>
## Billing method


|Billing method |Description |
|---|---|
|Subscription |Pay fees in advance before creating a new instance. The price is more affordable than pay\-as\-you\-go, suitable for long\-term needs. For details, see [Subscription](https://docs.byteplus.com/en/docs/rabbitmq/Subscriptions). |
|Pay\-as\-you\-go |A charge order is generated every hour, and fees are deducted from the BytePlus account according to the instance specifications at the time of order generation. Instances can be released immediately after use to save costs, suitable for short\-term needs. For details, see [Pay-as-you-go](https://docs.byteplus.com/en/docs/rabbitmq/Pay_as_you_go). |

## Instance lifecycle

The billing method determines the computation method of the lifecycle of the message queue for RabbitMQ, where:


* **Pay\-as\-you\-go**: The instance lifecycle starts from successful creation and stops when the instance is released.

* **Subscription**: The instance lifecycle starts from successful creation and automatically releases upon expiration.
