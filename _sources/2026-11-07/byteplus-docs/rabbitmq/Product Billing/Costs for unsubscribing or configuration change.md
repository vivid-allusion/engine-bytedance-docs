This section explains the costs for configuration changes and unsubscribing of RabbitMQ instances.

<span id=".5Y-Y6YWN6LS555So6K-05piO"></span>
## Cost for configuration changes


* **Pay\-as\-you\-go**

   For pay\-as\-you\-go instances, billing adjusts immediately after the configuration change based on the new specifications, including the current billing cycle during which the change occurs.

* **Subscription**

   The payment calculation for subscription instances upgrading configuration is shown in the table below. The actual amount payable is based on the upgrade page display.

   
   |**Configuration change type** |**Billing description** |
   |---|---|
   |Upgrade now |Total payable amount for upgrade orders<br><br>= New Configuration Cost \- Remaining Value of Old Configuration<br><br>= New Configuration List Price (per hour) × Remaining Duration (hours) × Discount \- Old Configuration List Price (per hour) × Remaining Duration (hours) × Discount |
   


<span id=".6YCA6K6i6LS555So6K-05piO"></span>
## Cost for unsubscribing


* For a pay\-as\-you\-go instance, you can delete it to unsubscribe. There is no refund involved.

* Subscription instance supports unsubscribing without reason within 7 days.
