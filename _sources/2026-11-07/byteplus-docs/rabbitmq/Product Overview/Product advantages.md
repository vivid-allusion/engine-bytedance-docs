## Fully compatible open source

The message queue for RabbitMQ supports the AMQP standard protocol and is fully compatible with open\-source RabbitMQ community components such as Queue, Exchange, and Vhost. It possesses all native RabbitMQ messaging features. It allows businesses to deploy to the cloud swiftly without modifying their code.

<span id="插件生态丰富"></span>
## Diverse extension ecosystem

The message queue for RabbitMQ supports various types of extensions. Through extensions, you can enable message delay function and compatibility with both TCP and WebSocket modes of the MQTT protocol.

<span id="性能稳定"></span>
## Stable performance


* The message queue for RabbitMQ isolates producers and consumers. It serves as a buffer to temporarily store massive volumes of messages produced during high concurrency so as to ensure stable consumption.

* The message queue for RabbitMQ addresses the single queue performance bottleneck seen in open\-source RabbitMQ. It supports a higher quantity of queues, possesses strong scalability, and can automatically scale based on business needs, offering transparency to users.


<span id="数据安全"></span>
## Data security


* We provide account management and authentication mechanisms for the console. The message queue for RabbitMQ interfaces with the BytePlus IAM service and sets different RabbitMQ instance access strategies for different IAM roles. It helps to achieve refined permission management at the RabbitMQ instance level.

* In terms of messaging, we provide SASL (Simple Authentication and Security Layer) authentication. It enhances network access control through a private network (VPC), and offers enterprise\-level security protection.
