The message queue for RabbitMQ provides multiple product functions, including instance management through both console and API. This section introduces basic product functions.

<span id=".5a6e5L6L566h55CG"></span>
## Instance management


|**Function** |**Description** |
|---|---|
|Instance management |* Supports instance\-level resource management, including creating instances, viewing instance information, restarting instances, changing specifications, and deleting instances. Please refer to [Create instance](https://docs.byteplus.com/en/docs/rabbitmq/Create_instance_1) and [iew instance information](https://docs.byteplus.com/en/docs/rabbitmq/View_instance_information) for detailed instructions.<br><br>* Offers a variety of instance specifications and supports upgrading instance specifications. For detailed instructions, please refer to [Upgrade instance specifications](https://docs.byteplus.com/en/docs/rabbitmq/Upgrade_instance_specifications).<br><br>* Supports managing instance resources through project and tags. |
|VPC and public network access |* RabbitMQ instances support VPC and public network access methods to meet access needs in different scenarios. When enabling public network access, synchronize the SSL authentication for enhanced security. For detailed information, please refer to [Set public network parse](https://docs.byteplus.com/en/docs/rabbitmq/Set_public_network_parse).<br><br>* Based on different access methods, RabbitMQ offers you multiple access points. |
|Community version console |We offer the Web UI address for RabbitMQ and support community version console configuration for Vhost, Exchange, Queue, and user permissions. |
|Extension management |Supports enabling or disabling various extensions like rabbitmq_mqtt through console methods. For detailed information, refer to [Enable extension](https://docs.byteplus.com/en/docs/rabbitmq/Enable_extension). |
|Task management |Provides execution records of background tasks. Show the status, details, start, and end times of tasks such as instance reconfiguration and restart. For detailed information, please refer to [Task management](https://docs.byteplus.com/en/docs/rabbitmq/User_Guide). |

## Monitoring and alerts


|**Function** |**Description** |
|---|---|
|Cloud monitoring |Via the BytePlus cloud monitoring service, you can monitor real\-time data such as the instance's operational status, resource levels, and the time consumption of message transmission around the clock. For monitoring items, please refer to [View monitoring data](https://docs.byteplus.com/en/docs/rabbitmq/View_monitoring_data). |
|Alerts |A variety of data monitoring projects and customizable alert strategies enable multi\-scenario and multi\-channel alert notifications. For operation steps, please refer to [Set alarm rules](https://docs.byteplus.com/en/docs/rabbitmq/Set_alarm_rules). |


<span id=".5p2D6ZmQ566h55CG"></span>
## Access management


|**Function** |**Specifications** |
|---|---|
|IAM access control |By integrating with BytePlus IAM services, you can set different RabbitMQ instance access policies for different IAM roles. It achieves fine\-grained permission management at the RabbitMQ instance level. For detailed information, refer to [Manage permissions based on IAM](https://docs.byteplus.com/en/docs/rabbitmq/Manage_permissions_based_on_IAM). |
|Web UI user management |Supports setting up the Web UI administrator account during instance creation, and resetting the administrator password if forgotten. |
