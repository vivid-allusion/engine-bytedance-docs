This section introduces the API service access address and supported region IDs for Message Queue for RabbitMQ. 

The API service access address for Message Queue for RabbitMQ is `https://rabbitmq.volcengineapi.com`. When accessing, Message Queue for RabbitMQ directs users to the nearest region based on their location. Additionally, you can specify the region in the API request for access. For details, refer to [common parameters](https://docs.byteplus.com/en/docs/rabbitmq/Common_parameters). 

Message Queue for RabbitMQ supports the following regions.


|**Region name** |**Region ID** |
|---|---|
|North China 2 (Beijing) |cn\-beijing |
|South China 1 (Guangzhou) |cn\-guangzhou |
|East China 2 (Shanghai) |cn\-shanghai |
|Asia Pacific Southeast (Johor) |ap\-southeast\-1 |
