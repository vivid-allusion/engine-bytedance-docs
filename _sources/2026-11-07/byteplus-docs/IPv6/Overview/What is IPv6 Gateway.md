IPv6 Gateway, also known as IPv6 Internet gateway, manages IPv6 internet traffic for Virtual Private Cloud (VPC). With an IPv6 Gateway, you can flexibly configure IPv6 Internet bandwidth and Egress Only rules to control outbound and inbound internet traffic via IPv6 addresses for a VPC.

## IPv6 Internet bandwidth

An IPv6 address without IPv6 Internet bandwidth enabled supports only private network interconnection. You can enable IPv6 Internet bandwidth for the address as needed for internet interconnection capabilities.

<span id=".5LuF5Li75Yqo5Ye66KeE5YiZ"></span>
## Egress Only rule

After enabling IPv6 Internet bandwidth for IPv6 addresses of Elastic Compute Service (ECS) or network interfaces, you can create Egress Only rules. These rules deny undesired access from IPv6 terminals on the internet to your ECS or network interfaces.
