## Internet access for cloud IPv6 services

When cloud IPv6 services require internet communication, you can use the IPv6 Gateway to enable Internet bandwidth for IPv6 addresses of cloud resources, allowing the resources to interconnect with the internet via IPv6 addresses.

## Egress\-only Internet access for cloud IPv6 services

When an ECS instance with IPv6 address requires actively accessing the internet, but does not want to be accessed by IPv6 terminals on the Internet, you can enable Internet bandwidth for the IPv6 address and then create an Egress Only rule to deny access from IPv6 terminals in the internet to the ECS instance.
