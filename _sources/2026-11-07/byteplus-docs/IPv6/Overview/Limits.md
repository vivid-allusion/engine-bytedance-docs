Before using an IPv6 Gateway, understand its quota and related limits. This topic describes the default quota and limits for IPv6 Gateways.

<span id=".6YWN6aKd6ZmQ5Yi2"></span>
## Quota limits


|Quota parameter |Description |Maximum |Increasable |Adjustable quota limit |
|---|---|---|---|---|
|ipv6_bandwidth |Number of IPv6 Internet bandwidths that can be enabled per account per region |20 |Yes. If the default quota does not meet your needs, go to the [Quota Center](https://console.byteplus.com/quota/productList/coParameterList?ProviderCode=EIP) to request a quota increase. |30 |
|ipv6gateway/ipv6py |Number of Egress Only rules that can be created per IPv6 Gateway instance |200 |Yes. If you need to use resources exceeding the quota limit, contact your account manager. |\-\- |
|vpc/cidr_v6 |Number of IPv6 Gateways that can be associated with one VPC |1 |No |\-\- |
