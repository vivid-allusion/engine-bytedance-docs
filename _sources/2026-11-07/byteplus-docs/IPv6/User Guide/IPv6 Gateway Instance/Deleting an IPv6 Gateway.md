To disable IPv6 for a Virtual Private Cloud (VPC), you need to delete the IPv6 Gateway first. This topic describes how to delete an IPv6 Gateway instance.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

You have not enabled IPv6 Internet bandwidth for IPv6 addresses of the IPv6 Gateway instance. If enabled, [disable IPv6 Internet bandwidth](https://docs.byteplus.com/en/docs/IPv6/Delete_IPv6_Internet_bandwidth) first.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [IPv6 Gateway console](https://console.byteplus.com/eip/ipv6s).

2. In the top menu bar, select your target region.

3. In the IPv6 Gateway instances list, click **Delete** to the right of the target IPv6 Gateway instance. A dialog box appears to confirm deletion.

4. After confirming the information is correct, click **Delete** to complete the action.
