When you no longer restrict Internet IPv6 terminals from accessing the Elastic Compute Service (ECS) or secondary network interface, you can use this action to delete the corresponding Egress Only rule.

<span id="q6Czc5oi"></span>
## Procedure


1. Log in to the [IPv6 Gateway console](https://console.byteplus.com/eip/ipv6s).

2. In the top menu bar, select your target region.

3. In the IPv6 Gateway instances list, click the name of target instance to go to the details page.

4. Select the Egress Only rule tab. Click **Delete** to the right of your target rule. A dialog box appears to confirm deletion.

5. After confirming the information is correct, click **Delete** to complete the action.
