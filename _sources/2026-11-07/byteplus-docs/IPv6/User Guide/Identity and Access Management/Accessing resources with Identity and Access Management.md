You can create multiple users, user groups, or roles and grant them different permissions to implement decentralized resource management, improve management efficiency, and reduce the risk of information leakage. This topic describes how to grant specific permissions to an IAM user as an example.

<span id="procedure"></span>
## Procedure


1. Log on to the [IPv6 Gateway console](https://console.byteplus.com/eip/ipv6s).

2. Click the username on the upper\-right corner, then choose **IAM** to go to the Identity and Access Management (IAM) console.

3. Create an IAM user and grant permissions to the IAM user. For more information, refer to [Creating a user and grant permissions](https://docs.byteplus.com/en/docs/byteplus-platform/docs-user-management).

4. Log on to the Virtual Private Network console as the IAM user.

   * Method 1: Go to the IAM console, and open the **User** page to copy and open the logon link. On the logon page, type the username and password to log on.

   * Method 2: Go to the BytePlus logon page, and click **Sign in as IAM user** right below **Sign in**. Type the BytePlus account name or ID, then type the IAM username and password to log on.
