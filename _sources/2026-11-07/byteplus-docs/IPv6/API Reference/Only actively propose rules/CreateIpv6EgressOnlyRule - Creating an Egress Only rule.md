Call the CreateIpv6EgressOnlyRule API to create an Egress Only rule for a specified IPv6 Internet bandwidth.

<span id=".5L2_55So6K-05piO"></span>
## Instructions

A single IPv6 Gateway supports up to 200 egress‑only rules.

<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters



**Action ** <span data-label="purple">String </span><span data-api-tag="require|cA56qi">必选</span> `Example: CreateIpv6EgressOnlyRule`

The action to perform. Value: **CreateIpv6EgressOnlyRule**.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|Oiynbp">必选</span> `Example: 2020-04-01`

The API version. The current version is **2020\-04\-01**.



**Ipv6GatewayId ** <span data-label="purple">String </span><span data-api-tag="require|cLRyvv">必选</span> `Example: ipv6gw-hp3rwmtmfhgis****`

The ID of the IPv6 Gateway.

You can call the [DescribeIpv6Gateways](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6Gateways) API to query the ID of IPv6 Gateway.



**InstanceId ** <span data-label="purple">String </span><span data-api-tag="require|dL72Y5">必选</span> `Example: eip-hp3nxjkfxn5pnhgl5****`

The IPv6 Internet bandwidth ID to add an Egress Only rule.



**Name ** <span data-label="purple">String </span>`optional` `Example: rulename`

The name of the Egress Only rule.


* Must be 1 to 128 characters.

* Must start with a letter, Chinese character, or digit. May include periods (.), underscores (_), and hyphens (\-).

* If left blank, it defaults to the ID of the Egress Only rule.



**Description ** <span data-label="purple">String </span>`optional` `Example: This rule is for ipv6.`

The description.


* Must be 0 to 255 characters.

* If left blank, this parameter defaults to an empty string.

* Must start with a letter, Chinese character, or digit. May include commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), full\-width commas (，), and full\-width periods (。).



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 0c593ea1-3bea-11e9-b96b-88e9fe63****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If this parameter is not specified, idempotency check is not performed.

```json

Host: vpc.cn-beijing.byteplusapi.com.cn
Region: cn-beijing
Service: vpc
```
