This topic introduces the OpenAPI actions available for IPv6 gateway.

<span id="ipv6-gateway-instance"></span>
## IPv6 gateway instance


|API |Functionality |
|---|---|
|[CreateIpv6Gateway](https://docs.byteplus.com/en/docs/IPv6/CreateIpv6Gateway) |Create an IPv6 gateway instance. |
|[ModifyIpv6GatewayAttribute](https://docs.byteplus.com/en/docs/IPv6/ModifyIpv6GatewayAttribute) |Modify the specified IPv6 gateway instance. |
|[DescribeIpv6GatewayAttribute](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6GatewayAttribute) |Query the details of the specified IPv6 gateway instance. |
|[DescribeIpv6Gateways](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6Gateways) |Query the list of IPv6 gateway instances that meet specified conditions. |
|[DeleteIpv6Gateway](https://docs.byteplus.com/en/docs/IPv6/DeleteIpv6Gateway) |Delete the specified IPv6 gateway instance. |


<span id="ipv6-internet-bandwidth"></span>
## IPv6 Internet Bandwidth


|API |Functionality |
|---|---|
|[AllocateIpv6AddressBandwidth](https://docs.byteplus.com/en/docs/IPv6/AllocateIpv6AddressBandwidth) |Activate IPv6 Internet bandwidth for the specified IPv6 address. |
|[ModifyIpv6AddressBandwidth](https://docs.byteplus.com/en/docs/IPv6/ModifyIpv6AddressBandwidth) |Modify the maximum bandwidth for IPv6 Internet bandwidth. |
|[DescribeIpv6AddressBandwidths](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6AddressBandwidths) |Query the list of IPv6 Internet bandwidths that meet specified conditions. |
|[DescribeIpv6AddressBandwidthAttributes](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6AddressBandwidthAttributes) |Query the details of the specified IPv6 Internet bandwidth. |
|[ReleaseIpv6AddressBandwidth](https://docs.byteplus.com/en/docs/IPv6/ReleaseIpv6AddressBandwidth) |Release the specified IPv6 Internet bandwidth. |


<span id="egress-only-rules"></span>
## Egress Only Rules


|API |Functionality |
|---|---|
|[CreateIpv6EgressOnlyRule](https://docs.byteplus.com/en/docs/IPv6/CreateIpv6EgressOnlyRule) |Create an egress only rule for the specified IPv6 Internet bandwidth. |
|[DescribeIpv6EgressOnlyRules](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6EgressOnlyRules) |View the egress only rules that meet specified conditions. |
|[ModifyIpv6EgressOnlyRuleAttribute](https://docs.byteplus.com/en/docs/IPv6/ModifyIpv6EgressOnlyRuleAttribute) |Modify the name of the specified egress only rule. |
|[DeleteIpv6EgressOnlyRule](https://docs.byteplus.com/en/docs/IPv6/DeleteIpv6EgressOnlyRule) |Delete the specified egress only rule. |
