Call the CreateIpv6Gateway API to create an IPv6 Gateway instance.

<span id=".5L2_55So6K-05piO"></span>
## Instructions


* When you enable IPv6 for a Virtual Private Cloud (VPC), the system creates an IPv6 Gateway for it.

* An IPv6 Gateway can be associated with only one VPC, and a VPC can have only one IPv6 Gateway.


<span id=".6K-35rGC5Y-C5pWw"></span>
## Request parameters



**Action ** <span data-label="purple">String </span><span data-api-tag="require|WIbkci">必选</span> `Example: CreateIpv6Gateway`

The action to perform. Value: **CreateIpv6Gateway**.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|lRWaAQ">必选</span> `Example: 2020-04-01`

The API version. The current version is **2020\-04\-01**.



**VpcId ** <span data-label="purple">String </span><span data-api-tag="require|mge1WR">必选</span> `Example: vpc-bp1opxu1zkhn00gz****`

The VPC ID associated with the IPv6 Gateway instance.

You can call the [DescribeVpcs](https://docs.byteplus.com/en/docs/vpc/DescribeVpcs) API to query the VPC ID.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Each VPC can have only one IPv6 Gateway instance. Ensure that the target VPC is not associated with any other IPv6 Gateway.</div>




**Name ** <span data-label="purple">String </span>`optional` `Example: ipv6GW-01`

The name of the IPv6 Gateway instance.


* Must be 1 to 128 characters.

* Must start with a letter, Chinese character, or digit. May include periods (.), underscores (_), and hyphens (\-).

* If left blank, this defaults to the IPv6 Gateway ID.



**Description ** <span data-label="purple">String </span>`optional` `Example: ipv6gatewayforVPC1`

The description of the IPv6 Gateway instance.


* Must be 0 to 255 characters.

* If left blank, this parameter defaults to an empty string.

* Must start with a letter, Chinese character, or digit. May include commas (,), periods (.), underscores (_), spaces ( ), equal signs (=), hyphens (\-), full\-width commas (，), and full\-width periods (。).



**ProjectName ** <span data-label="purple">String </span>`optional` `Example: Project_1`

The name of the project to which the IPv6 Gateway belongs. If left blank, this parameter defaults to the "default" project.



**Tags.N.Key ** <span data-label="purple">String </span>`optional` `Example: key1`

The tag key of the custom tag.


* N represents the sequence number of a tag key. Valid range: 1–50.

* Separate multiple tag keys with ampersands (&).

* Must not start with `volc:` or `sys:` regardless of case.

* Must be 1 to 128 characters. May include multilingual characters, digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), hyphens (\-), and at signs (@).

* If a tag key starts or ends with spaces, the system automatically deletes the space.

> Tag keys of the same resource must be unique.​



**Tags.N.Value ** <span data-label="purple">String </span>`optional` `Example: value1`

The tag value of the custom tag.


* N represents the sequence number of a tag value. Valid range: 1\-50.

* Separate multiple tag values with ampersands (&).

* Must be 0 to 256 characters. If left blank, this parameter defaults to an empty string.

* Allowed characters: Multilingual characters, digits, spaces ( ), underscores (_), periods (.), colons (:), forward slashes (/), equal signs (=), plus signs (+), hyphens (\-), and the at symbol (@).

* Case\-sensitive.

* If a tag value starts or ends with a space, the system automatically removes the space.

> To pass in this parameter, pass in `Tags.N.Key` first.



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 0c593ea1-3bea-11e9-b96b-88e9fe63****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If this parameter is not specified, idempotency check is not performed.

## Response parameters



**RequestId ** <span data-label="purple">String </span>`Example: 2021062415303301022514515207C4****`

**Ipv6GatewayId ** <span data-label="purple">String </span>`Example: ipv6gw-hp3y0l3ln89j8cdvf****`

## Request example

```json
GET /?Action=CreateIpv6Gateway&Version=2020-04-01&VpcId=vpc-bp1opxu1zkhn00gz****&Name=ipv6GW-01 HTTP/1.1
Host: vpc.cn-beijing.byteplusapi.com.cn
Region: cn-beijing
Service: vpc
```
