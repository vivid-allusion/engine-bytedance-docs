Call the AllocateIpv6AddressBandwidth API to enable IPv6 Internet bandwidth for a specified IPv6 address.

<span id=".5L2_55So6K-05piO"></span>
## Instructions


* Private Dual\-stack Application Load Balancer (ALB) instances do not support enabling IPv6 Internet bandwidth. Public dual\-stack ALB instances are automatically allocated IPv6 Internet bandwidth upon creation.

* The Virtual Private Cloud (VPC) containing the target IPv6 address already has an associated IPv6 Gateway.

   You can call the [DescribeIpv6Gateways](https://docs.byteplus.com/en/docs/IPv6/DescribeIpv6Gateways) API to check whether an IPv6 Gateway is associated. If not, call the [CreateIpv6Gateway](https://docs.byteplus.com/en/docs/IPv6/CreateIpv6Gateway) API to create an IPv6 Gateway and associate it with the VPC.

## Request parameters



**Action ** <span data-label="purple">String </span><span data-api-tag="require|IM6czT">必选</span> `Example: AllocateIpv6AddressBandwidth`

The action to perform. Value: **AllocateIpv6AddressBandwidth**.



**Version ** <span data-label="purple">String </span><span data-api-tag="require|5fQGrx">必选</span> `Example: 2020-04-01`

The API version. The current version is **2020\-04\-01**.



**Ipv6Address ** <span data-label="purple">String </span>`optional` `Example: 2408::153:3921:XX:XX:7b12:1c5f`

The IPv6 addresses pending IPv6 Internet bandwidth activation.



**BillingType ** <span data-label="purple">Integer </span><span data-api-tag="require|WelYCh">必选</span> `Example: 3`

The metering method for the IPv6 Internet bandwidth.


* 2: Pay\-by\-bandwidth\-cap.

* 3: Pay\-by\-data\-transfer.



**Bandwidth ** <span data-label="purple">Integer </span>`optional` `Example: 5`

The bandwidth cap of the IPv6 Internet bandwidth. Unit: Mbps.


* Set `BillingType` to 2: Value ranges from 1 to 500.

* Set `BillingType` to 3: Value ranges from 1 to 200.

* If left blank, it defaults to 1 Mbps.



**BandwidthPackageId ** <span data-label="purple">String </span>`optional` `Example: bwp-2zeo05qre24nhrqpy****`

The ID of the IPv6 Bandwidth Package.

You can call the [CreateBandwidthPackage](https://docs.byteplus.com/en/docs/bandwidthpackage/CreateBandwidthPackage) API to query the ID of the Bandwidth Package.



**Tags.N.Key ** <span data-label="purple">String </span>`optional` `Example: key1`

The tag key of the custom tag.


* N represents the sequence number of a tag key. Valid range: 1\-50.

* Separate multiple tag keys with ampersands (&).

* Must not start with volc: or sys: regardless of case.

* Must be 1 to 128 characters. May include characters (any language), digits, spaces ( ), underscores (_), periods (.), half\-width colons (:), slashes (/), equal signs (=), plus signs (+), hyphens (\-), and at signs (@).

* If a tag key starts or ends with spaces, the system automatically deletes the space.

> Tag keys of the same resource must be unique.​



**Tags.N.Value ** <span data-label="purple">String </span>`optional` `Example: value1`

The tag value of the custom tag.


* N represents the sequence number of a tag value. Valid range: 1\-50.

* Separate multiple tag values with ampersands (&).

* Must be 0 to 256 characters. If left blank, this parameter defaults to an empty string.

* Allowed characters: Multilingual characters, digits, spaces ( ), underscores (_), periods (.), colons (:), forward slashes (/), equal signs (=), plus signs (+), hyphens (\-), and the at symbol (@).

* Case\-sensitive.

* If a tag value starts or ends with a space, the system automatically removes the space.

> To pass in this parameter, pass in Tags.N.Key first.



**ClientToken ** <span data-label="purple">String </span>`optional` `Example: 0c593ea1-3bea-11e9-b96b-88e9fe63****`

The Client Token that is used to ensure the request idempotency.


* This parameter value is auto\-generated by the client. Ensure uniqueness across requests, preventing duplicate actions caused by multiple client retries during API timeouts or server internal errors.

* Must not exceed 64 ASCII characters.

* If this parameter is not specified, idempotency check is not performed.

## Request example

```json
GET /?Action=AllocateIpv6AddressBandwidth&Version=2020-04-01&Ipv6Address=2408::153:3921:XX:XX:7b12:1c5f&BillingType=3&Bandwidth=5 HTTP/1.1
Host: vpc.cn-beijing.byteplusapi.com.cn
Region: cn-beijing
Service: vpc
```
