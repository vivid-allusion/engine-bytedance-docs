To enable internet access for Elastic Compute Service (ECS) instances within a Virtual Private Cloud (VPC) while protecting them from direct exposure, you can create a NAT Gateway. A NAT Gateway is an enterprise\-class service that provides both Source Network Address Translation (SNAT) and Destination Network Address Translation (DNAT). This guide provides step\-by\-step instructions to help you create and configure your NAT Gateway.
