# Procedure

To delete a document from a knowledge base, follow the steps in this guide. You will learn how to navigate to the document list and use the delete operation to remove an item.


1. In the knowledge base list, click the knowledge base card to enter the knowledge base details page.

2. In the document list on the original document page, click "Delete" in the Actions column. A pop\-up window will prompt for confirmation before deletion.
