To populate an existing knowledge base, you can import documents from various sources. This guide provides step\-by\-step instructions for importing documents via local upload, from TOS, or using a public download link. It also details supported formats and how to synchronize document updates to keep your knowledge base current.

<span id="d8318278"></span>
# Steps


1. In the knowledge base list, click [Import documents] on the knowledge base card, or after entering the knowledge base details page, click [Import documents].

The knowledge base supports both structured and unstructured documents. For the specifications supported for each document type, refer to: [Knowledge base quota description](https://docs.byteplus.com/docs/209/Knowledge_base_quota_description)

# Document synchronization

<span id="c1993f05"></span>
## How to synchronize document content updates to the knowledge base

Currently, to update documents in the knowledge base, users need to upload the target document again and use the same doc_id to overwrite the original document.

For specific steps to synchronize updated documents to the knowledge base, refer to the following instructions:


* Upload via the interface


Use a public download link and set the file ID of the new document to the ID of the original document to overwrite it.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/06dc2a64077a4e978e2280b3b7c370a6~tplv-goo7wpa0wc-image.image) </span>


* Upload via API or SDK


When uploading documents using the /api/knowledge/doc/add endpoint, specify doc_id as the ID of the document to be replaced to overwrite both the document and its slices.

Note that when "add_type" == "tos", this field is invalid. You need to define the doc_id in TOS.

<span id="2d984daa"></span>
## How to synchronize incremental document updates in a folder to the knowledge base

Currently, the knowledge base only supports incremental document updates via [Import from TOS].

If you re\-import a TOS directory, the system uploads only the new files. Existing documents are not re\-uploaded. Duplicate documents with the same name will be automatically skipped and will not be uploaded to the knowledge base again.

For specific steps on incremental document updates, refer to the following instructions:

[Method 1] Via the user interface

On the import documents page, select Import from TOS and re\-import the same directory.

[Method 2] Via the API

Using [add](https://docs.byteplus.com/docs/209/doc_add), set add_type to tos, and enter the same directory path for tos_path.
