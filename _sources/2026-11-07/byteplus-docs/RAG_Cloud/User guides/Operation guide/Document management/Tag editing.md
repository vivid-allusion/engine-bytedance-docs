# Procedure


1. When creating a knowledge base, initialize the required tags within the knowledge base.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">Caution: Tags can be modified after the knowledge base is created.   </div>
   

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0b2d10dff29944a6ad239dd6f5aa29d2~tplv-goo7wpa0wc-image.image) </span>

2. In the knowledge base list, click the knowledge base card to enter the knowledge base details page. On the original document page, in the document list, click "Tag" to open the tag pop\-up window for editing.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e79597daca764e03a6bef8694dd9fe13~tplv-goo7wpa0wc-image.image) </span>

3. After configuring tags, the document content can be filtered during retrieval using the corresponding tag options.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3e68d9e86a6047479f6c30de255764b5~tplv-goo7wpa0wc-image.image) </span>

4. During retrieval testing, you can filter documents in the knowledge base by editing the filter criteria, so that retrieval is performed only within the range of documents that meet the criteria.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/d31e45eb413140069d8975a85bf2c0ff~tplv-goo7wpa0wc-image.image) </span>
