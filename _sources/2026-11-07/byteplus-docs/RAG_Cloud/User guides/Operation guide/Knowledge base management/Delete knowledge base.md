# ProcedureTo delete a knowledge base you no longer need, this guide provides step\-by\-step instructions for two methods. You can perform this action either from the main knowledge base list or directly from the details page of the specific knowledge base.


1. On the knowledge base list page, hover over the "···" button in the upper\-right corner of the card for the knowledge base you want to delete, click "Delete", and a pop\-up window appears asking you to confirm the deletion.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/e72fecab9beb4fabb106dff376b28f3b~tplv-goo7wpa0wc-image.image) </span>

2. Alternatively, on the knowledge base details page, click "Delete" in the upper\-right corner to open the same confirmation pop\-up window.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/93468ca630834304b4aa9151517b42b6~tplv-goo7wpa0wc-image.image) </span>
