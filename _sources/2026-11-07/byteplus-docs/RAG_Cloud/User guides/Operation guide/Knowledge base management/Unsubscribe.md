# Steps

To unsubscribe from the knowledge base service, click the [···] button in the upper right corner of the knowledge base list page. After unsubscribing, your knowledge base data will be deleted and resources will be released. Caution: Once unsubscribed, recovery is not possible. Please proceed with caution.
