# Procedure


1. You can view the list of created knowledge bases on the knowledge base page.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/fed5c09591eb43ed811d07c9428e5ad8~tplv-goo7wpa0wc-image.image) </span>

The meanings of each parameter in the knowledge base list are as follows:


|**Parameter name** |**Parameter description** |
|---|---|
|Name |Name of the knowledge base. |
|Creator |Creator of the knowledge base. |
|Creation time |Creation time of the knowledge base. |
|Number of documents |Number of documents imported into the knowledge base. |
|Number of slices |Total number of slices in the knowledge base. |
|Vector model |Vector model used by the knowledge base. |
|Operation |* **Import document**: After clicking 「Import document」, you will enter the import document page.<br><br>* **Edit**: After clicking 「Edit」, you will enter the edit knowledge base page, where you can modify the knowledge base description and CPU.<br><br>* **Delete**: Only datasets without indexes can be deleted. After clicking 「Delete」, a pop\-up window will prompt you to confirm whether to delete. Click Confirm to delete the dataset. |
