This section explains how to add new point content to the knowledge base.

<span id="4c6a80c4"></span>
# Procedure

Under the 「point details」 tab on the knowledge base details page, you can add point content to a specific original document. The default display is in card format; you can click the icon to the right of 「Add slice」 to switch to list format.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/02805a219d604696907aa30e4a50077d~tplv-goo7wpa0wc-image.image) </span>

Click the 「Add a new slice」 button to add slice content.

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Adding a new slice will perform embedding for the slice and incur a fee.</div>



* Unstructured document

   * Associated document: Select the original document. The new slice will be appended to the corresponding document.

   * Slice content: Enter the content of the new slice.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7d28f0adc5844fb9a3dc54ef61ab3fe3~tplv-goo7wpa0wc-image.image) </span>

* Structured document

   * Associated document: Select the original document. The new slice will be appended to the corresponding document.

   * Header fields: Enter the new content under each field.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/41e0b2c2fe184bad992959dbb21d8a21~tplv-goo7wpa0wc-image.image) </span>

* Unstructured FAQ document

   * Associated document: Select the original document. The new slice will be appended to the corresponding document.

   * Question: The question corresponding to the new slice.

   * Answer: The answer to the question corresponding to the new slice.

      <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/70d8a22fb5974281b62efe62820ce307~tplv-goo7wpa0wc-image.image) </span>
