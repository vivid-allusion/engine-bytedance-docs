To perform lifecycle management on your knowledge services, this guide provides step\-by\-step instructions. You will learn how to view service details like call examples and configurations, edit basic information and associated API keys, and safely delete services that are no longer needed.

<span id="df009686"></span>
## 1. View Knowledge Service

There are two ways to view knowledge services:


1. In the knowledge base list, click "Service management" on the knowledge base card.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2825f32bf8664a5294eb2ae209253a7e~tplv-goo7wpa0wc-image.image) </span>


2. On a knowledge base's details page, click "Service management" in the upper\-right corner.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/5a5d52aa528d46f4a7ce1ba8ae8f5667~tplv-goo7wpa0wc-image.image) </span>

After entering the knowledge service, you can view the basic information of the current service, call examples, parameter configurations, and associated API keys.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/02a78ac6b7274225ab82e25c92202101~tplv-goo7wpa0wc-image.image) </span>

<span id="a5f6850d"></span>
## 2. Knowledge service editing

You can edit the basic information of a created knowledge service and its associated API key.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/aeac9eb67d8e4dfab8faccec176e1c8a~tplv-goo7wpa0wc-image.image) </span>

If you want to adjust the parameter configuration, we recommend that you debug with the current parameters and then release a new service.

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/7b31a7ee5cf441ef80803e56fec5ab30~tplv-goo7wpa0wc-image.image) </span>

<span id="afc44e96"></span>
## 3. Delete knowledge services

Be cautious when deleting knowledge services, and check for online traffic before you proceed.
