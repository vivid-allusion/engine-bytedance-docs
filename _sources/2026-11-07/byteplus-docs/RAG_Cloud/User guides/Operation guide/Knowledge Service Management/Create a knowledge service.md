# Create a Knowledge Service

After finding the optimal Q&A parameter combinations in the console, you can save them as a knowledge service to easily integrate them into your business via API. This guide walks you through the process of creating the service and generating API code examples for quick integration.

<span id="af1660cd"></span>
# Procedure


1. Debug parameters on the Knowledge Base Console to achieve the expected results.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/464f151ebb364ad085c9548c62615f78~tplv-goo7wpa0wc-image.image) </span>


2. Click "Create a knowledge service" to configure the basic information of the knowledge service and associate at least one available API key.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/a8faa80e02a542d2b911398a06bb7a07~tplv-goo7wpa0wc-image.image) </span>


3. Click "Create" to complete the creation of the knowledge service. The platform provides invocation examples for multiple common programming languages, which can be copied and integrated with one click.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ce39f889cde54768bd3d193af738888b~tplv-goo7wpa0wc-image.image) </span>

At this point, the exact same effect as in the Console can be achieved through API calls.
