## How to use the Shared Traffic Package after purchase?

After the Shared Traffic Package is activated, it will automatically deduct the Internet traffic fee generated by products billed by traffic in the specified Region, without requiring extra actions. For the products supported for deduction, please refer to [Product specifications](https://docs.byteplus.com/en/docs/Trafficpackage/What_is_Shared_Traffic_Package#product-specifications).

<span id="does-the-shared-traffic-package-support-setting-the-effective-date"></span>
## Does the Shared Traffic Package support setting the effective date?

No, the Shared Traffic Package takes effect immediately after purchase.

<span id="does-the-shared-traffic-package-support-a-seven-day-unconditional-unsubscribe"></span>
## Does the Shared Traffic Package support a seven\-day unconditional Unsubscribe?

Only Shared Traffic Packages without traffic deduction within seven days can be unconditionally unsubscribed, and the number of unsubscriptions is limited. Please refer to [Unsubscribe Instructions](https://docs.byteplus.com/en/docs/Trafficpackage/Unsubscription).

<span id="if-an-expired-shared-traffic-package-has-unused-traffic-can-it-be-accumulated-into-other-available-shared-traffic-packages"></span>
## If an expired Shared Traffic Package has unused traffic, can it be accumulated into other available Shared Traffic Packages?

No, unused traffic will be cleared to zero.

<span id="does-the-shared-traffic-package-support-specifying-it-for-an-eip"></span>
## Does the Shared Traffic Package support specifying it for an EIP?

The Shared Traffic Package does not support taking effect for the bandwidth of a specified EIP instance, but the same Shared Traffic Package can simultaneously deduct multiple instances.

<span id="what-is-the-maximum-number-of-shared-traffic-packages-that-can-be-purchased"></span>
## What is the maximum number of Shared Traffic Packages that can be purchased?

Each Region supports purchasing up to **20** unused Shared Traffic Packages.
