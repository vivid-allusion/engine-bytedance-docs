<span id="constraints-and-limits"></span>
## Constraints and Limits


* The Shared Traffic Package is a Prepaid model that is used after advance payment. Currently, it only supports a seven\-day unconditional Unsubscribe. For detailed Unsubscribe rules, please refer to [Unsubscribe](https://docs.byteplus.com/en/docs/Trafficpackage/Unsubscription).

* The Shared Traffic Package fee is a One\-off payment, taking effect immediately. It does not support specifying an effective date, renewal, or reconfiguration.

* Once the traffic within the Shared Traffic Package is used up during the validity period, the Billing mode of the Shared Traffic Package will revert to Pay\-as\-you\-go and be charged normally.

* The Shared Traffic Package cannot be refunded after expiration, and unused traffic will be cleared.

* The Shared Traffic Package does not support becoming effective for a specified EIP bandwidth; the same Shared Traffic Package can simultaneously be deducted by multiple instances.

* One Shared Traffic Package can only override one Region.

* Purchasing multiple Shared Traffic Packages for combined usage is supported. Deductions are made in the order of expiration, with priority given to the traffic package expiring first.

* The Shared Traffic Package only supports the deduction of Internet traffic generated by products billed by (primary) traffic on the same ISP.

* The unit conversion system for Shared Traffic Package traffic is 1024, i.e., 1TB = 1024GB, 1GB = 1024MB.
