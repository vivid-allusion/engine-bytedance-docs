Shared Traffic Package is a cloud resource that supports sharing traffic. After purchasing the Shared Traffic Package, it will automatically **deduct internet traffic fees** for services such as Elastic Compute Service (ECS), Elastic IP (EIP), Shared Bandwidth Package, Cloud Load Balancer (CLB), and NAT gateway within the same Region with the billing mode of pay\-by\-traffic until the Shared Traffic Package is used up or reaches expiration.

<span id="benefits"></span>
## Benefits


* **Wide override and easy management**


The Shared Traffic Package is applicable to resources within the same Region that support the internet pay\-by\-traffic billing mode, without the need for allocation or association. Supports creating multiple Shared Traffic Packages simultaneously, deducting traffic sequentially (based on expiration time).


* **Reducing costs**


Shared Traffic Packages are cost\-effective, offer a high value for money, come in diverse plans, and help save costs. You can flexibly choose the appropriate Shared Traffic Package according to your actual business needs.
