## Procedure

You can view the status and deduction details of the Shared Traffic Package at any time, and set a balance alert for the Shared Traffic Package.


1. Log in to the [Shared Traffic Package console](https://console.byteplus.com/eip/trafficPackages).

2. In the Shared Traffic Package console, you can view the usage status of the Shared Traffic Package.

   
   |**Parameter** |**Description** |
   |---|---|
   |ID |The unique identifier of the Shared Traffic Package. |
   |Stage |The current status of the Shared Traffic Package includes six statuses: **Active**, **Expired**, **Used up**, **Refunded**, **Reclaimed**, and **Creation failed**.<br><br><br>* Active: The Shared Traffic Package is currently deducting traffic.<br><br>* Expired: The Shared Traffic Package has expired and is no longer valid.<br><br>* Used up: The traffic of the Shared Traffic Package has been fully used.<br><br>* Refunded: The Shared Traffic Package has been Unsubscribed.<br><br>* Reclaimed: The Shared Traffic Package has expired and has been reclaimed.<br><br>* Creation failed: The Shared Traffic Package creation failed, please [create](https://docs.byteplus.com/en/docs/Trafficpackage/Create_a_Shared_Traffic_Package) it again. |
   |Deduction Region |The Shared Traffic Package supports deduction in specific Regions. |
   |Usage/Total amount |The used traffic and remaining traffic of the Shared Traffic Package. If a decimal point is encountered, retain three digits after the decimal point, and round the fourth digit |
   |Purchase time |This refers to the effective time of the Shared Traffic Package |
   |Expiration time |That is, the expiration time of the Shared Traffic Package. |
   

3. Click the **Deduction Details** button on the right side of the target Shared Traffic Package to navigate to the resource instance management interface. In the **Resource Pack** tab, view the usage details of the Shared Traffic Package:

   * **Deduction Details**: In the **Deduction Details** tab, view the deduction details of the target Shared Traffic Package.

   * **Overview**: Select the **Overview** tab to view the specification details and usage status of all Shared Traffic Packages.
