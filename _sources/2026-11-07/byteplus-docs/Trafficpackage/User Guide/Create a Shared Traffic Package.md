<span id="prerequisites"></span>
## Prerequisites


* Complete the VolcanoEngine Account registration and real\-name authentication.

* The number of non\-expired Shared Traffic Packages in this Region is less than 20.


<span id="procedure"></span>
## Procedure


1. Log in to the [Shared Traffic Package console](https://console.byteplus.com/eip/trafficPackages).

2. Click the **Create Shared Traffic Package** button.

3. Configure the basic information of the Shared Traffic Package.



|**Parameter** |**Description** |Example |
|---|---|---|
|Region |Select the Region where the Shared Traffic Package is located. The Shared Traffic Package supports the deduction of Internet traffic fees billed by  **(primary) traffic billing** in the same Region. Once created, the Region cannot be changed. For supported products, please refer to [product specification](https://docs.byteplus.com/en/docs/Trafficpackage/Billing_Description). |ap\-southeast\-1 |
|ISP |Select the ISP of the Shared Traffic Package. Currently, BGP (Multi\-ISP) is supported.<br><br>The Shared Traffic Package supports the deduction of Internet traffic fees generated by products billed by (primary) traffic for the same ISP. |BGP (multi\-line) |
|Validity period |The validity period of the Shared Traffic Package includes **1 month**, **6 months** and **1 year**. |1 month |
|Type |The traffic quota included in the Shared Traffic Package supports different specifications based on different validity periods. Please refer to [billing unit price](https://docs.byteplus.com/en/docs/Trafficpackage/Billing_Description) for specific details. |10GB |
|Quantity |The number of shared traffic packages purchased: each region can purchase up to 20 shared traffic packages that have not reached expiration, and quota upgrades are not supported. |1 Gateway |



4. Please follow the console instructions to review and confirm the Legal, and click **Buy now**.

5. Click the **Next step** button, select the payment method, then click the **Pay** button to proceed with the payment according to the selected method.

> After the payment information is submitted, you must complete the payment within a specified period of time. Otherwise, orders will be canceled.


After the Shared Traffic Package is successfully created, it will take effect immediately and will be deducted in the order of the traffic package expiration time.
