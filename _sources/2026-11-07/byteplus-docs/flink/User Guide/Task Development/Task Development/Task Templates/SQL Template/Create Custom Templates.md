In addition to the preset SQL templates provided by the system, you can also configure custom SQL templates based on your business needs.

<span id="bab919e4"></span>
## Limitations Description

The preset SQL templates in the system are currently only used to create Flink Stream SQL type tasks; however, custom creation of templates for both Stream and Batch types is supported.

<span id="541fc1e5"></span>
## Create Custom Templates


1. Log in to [BytePlus Flink Console](https://console.volcengine.com/flink).

2. Select the target region in the top menu bar.

3. In the left navigation bar, select **Project Management**, then click on the project block to enter the project.

4. In the project's left navigation bar, select **Task Development \> Jupyter lab**.

5. On the **Template Management** page, click the plus button and select **Create SQL Template** to create a custom template.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/40ccba0ab7744a50ac0da6f9d2e885af~tplv-goo7wpa0wc-image.image) </span>

6. In the **Create SQL Template** dialog, first set the template statement in the **Edit SQL** area on the left, then configure the template name, template type, engine version, and associated folder in the **Template Information** area on the right, and finally click **OK**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/0bc8089c59e54e43905f075541e73a3a~tplv-goo7wpa0wc-image.image) </span>
