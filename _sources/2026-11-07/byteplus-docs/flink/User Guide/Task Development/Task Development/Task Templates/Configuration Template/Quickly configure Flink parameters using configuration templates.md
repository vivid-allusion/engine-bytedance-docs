In the task development settings, you can directly use pre\-created configuration templates to quickly configure Flink parameters.

<span id="45ec581e"></span>
## Configure Flink parameters using templates


1. Log in to [BytePlus Flink Console](https://console.byteplus.com/flink).

2. Select the target region from the top menu bar.

3. In the left navigation bar, select **Project Management**, then click on the project block to enter the project.

4. In the project's left navigation bar select **Job Development \> Job Development**.

5. On the **Job Development** page, expand the target task and click **Parameter Configuration** at the top of the task editing page.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/b7b1bd308d9e47ca863264e27d86dc77~tplv-goo7wpa0wc-image.image) </span>


6. In the **Parameter Configuration** panel, click **Configure using template**.


<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/8aa8bdfd1dfa427e9eaafe47f1ad83fa~tplv-goo7wpa0wc-image.image) </span>


7. In the **template selection** dialog, select the target template, review the template content, and then click **OK**.

   <div data-tips="true" data-tips-type="tip" data-tips-is-title="true" data-wrapper-indent="1">tip   </div>
   

   <div data-tips="true" data-tips-type="tip" data-wrapper-indent="1">The system will automatically filter the available configuration templates based on the task type and engine version.   </div>
   

<span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/36c7c9618df14a539c60b27101a3805a~tplv-goo7wpa0wc-image.image) </span>


8. After confirming the template selection, the template configuration content will be automatically applied, and you can modify or add dependent files and custom parameters as needed.
