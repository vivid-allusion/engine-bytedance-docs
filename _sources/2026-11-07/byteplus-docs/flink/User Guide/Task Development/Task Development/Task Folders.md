Streaming computation currently supports the development of various types of tasks including Flink Stream, Flink Batch, Ray, etc. You can create multiple folders for categorized management of tasks.

<span id="66a92807"></span>
## Create a primary folder

The system by default has a **default folder**, but for more convenient task management, you are free to create multiple folders.


1. Log in to [BytePlus Flink console](https://console.byteplus.com/flink).

2. Select the target region in the top menu bar.

3. Select **Project management** from the left navigation bar, perform a fuzzy search using the project name in the search box, and then click on the project block to enter the project.

4. Select **Task development \> Tasks** in the project's left navigation bar.

5. Under the **Tasks** page, click the folder icon.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/ef64adab1eac40b18d6cf26f6b7c3530~tplv-goo7wpa0wc-image.image) </span>

6. In the **Create folder** dialog, set the folder name and then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/2664fe19fa734e10b29c0e700216f5a2~tplv-goo7wpa0wc-image.image) </span>


<span id="0f0e53f6"></span>
## Create Subfolder

You can continue to create subfolders under the primary folder, up to **three levels** of folders.


1. On the **Tasks** page, click the folder icon.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/6e8e4f8323dc41a090c2e1d637c8fe5c~tplv-goo7wpa0wc-image.image) </span>

2. In the **Create folder** dialog, set the folder name, select the parent folder, and then click **Create**.

   <span>![图片](https://p9-arcosite.byteimg.com/tos-cn-i-goo7wpa0wc/3b3d6e336f2b48be99ed8bdd8831e7bd~tplv-goo7wpa0wc-image.image) </span>


<span id="d18d3fbe"></span>
## Other Operations

After creating task management folders, you can perform **rename** and **delete** operations.

Right\-click on the target folder, then choose **Rename** or **Delete**. If there are tasks in the folder, the folder cannot be deleted.
