In the project overview page, you can view the computational resources used in the current project, the number and status of resource pools, the number and status of tasks, and the trend graph of task quantities over the recent period.


1. In the **Project Management** page, search for the target project by name using a fuzzy search.

2. Click on the project block to enter **Project Overview**.

3. View details of the Project Overview.
