The primary account must complete the service initialization when logging in to the Flink console for the first time, otherwise, it is not authorized to use any feature.

<span id="33f91632"></span>
## Prerequisites


* Before using the BytePlus Flink product, you need to register and complete corporate certification through the [BytePlus official website](https://www.byteplus.com/).

* During Flink service initialization, it's necessary to select the associated TOS and VPC, and resource creation should be completed beforehand; see [Create a Bucket](https://docs.byteplus.com/zh-CN/docs/tos/docs-create-a-bucket) and [Create a VPC](https://docs.byteplus.com/zh-CN/docs/vpc/Creating-a-VPC).


<span id="4884d774"></span>
## Operational Steps


1. Primary account login to [BytePlus Flink console](https://console.byteplus.com/flink).

   The default landing on the **Overview** page, which will prompt you to perform the initialization.

2. On the **Overview** page, click **Initialize** at the middle of the page.

3. Wait for the initialization to complete.

   The initialization process will start multiple services, please be patient. When the initialization process disappears, it indicates that the initialization is complete.


<span id="7fe2006d"></span>
## **Sub\-user Authorization**

For users who need to log into the **BytePlus Flink** console and use its features, first create and grant appropriate permissions to sub\-users in **Access Control**:


1. Main account logs into [BytePlus Flink](https://console.byteplus.com/flink) console.

2. In the upper right corner of personal information, click **Access Control ＞ Users,**  to go to the user list interface.

3. Click **Create User** to create a sub\-user, for details see [User Management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-user-management).


Grant users global FlinkFullAccess permissions.
