Files uploaded to the console, which can currently be used to create tasks and as dependent files for tasks.

<span id="c888ad34"></span>
## Create Task


* Create a JAR type task: Requires using a previously uploaded JAR package.

* Create a PyFlink task: Requires using a previously uploaded Python ZIP package.


<span id="e2fe753d"></span>
## Task Dependent Files

In the task development side's parameter configuration, you can add dependent files for a task.


1. In the console navigation bar, select **Jupyter lab**.

2. On the **task development** page, find and click on the target task, then click **parameter configuration** on the right side of the edit area.

3. In the **parameter configuration**'s **dependent files** area, select the resource files that need to be used as dependent files.
