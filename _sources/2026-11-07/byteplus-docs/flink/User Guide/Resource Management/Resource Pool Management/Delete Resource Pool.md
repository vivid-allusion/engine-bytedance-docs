When the resource pool is no longer needed, please delete it promptly to avoid prolonged resource occupancy. Deleting a resource pool is an irreversible operation; please proceed with caution.

<span id="4b0a174f"></span>
## Prerequisites

Before deleting a resource pool, confirm that there are no tasks currently running within the pool.

<span id="e4fd8dfc"></span>
## Procedure Steps


1. In the resource pool list page, click **Delete** behind the target resource pool.

2. In the confirmation dialog, click **Confirm**.
