BytePlus Flink currently uses a pay\-as\-you\-go model, which is a post\-payment system. Hence, deleting the resource pool instance equates to unsubscribing, and does not involve a refund.

When you no longer need to use the resource pool instance, you can delete it at any time. Simply click the **delete** button behind the resource pool and confirm again to unsubscribe that resource pool instance.
