BytePlus Flink for Stream Computing is 100% compatible with open\-source Apache Flink and incorporates plugin\-based enterprise enhancements as well as best practices from the conglomerate. This article outlines the core functional advantages of BytePlus Flink for Stream Computing.


|**Core Advantages** |**Description of Core Advantages** |
|---|---|
|SQL Enhancements |* Window Mini\-Batch<br><br>* Support for Window Offset<br><br>* Dimension Table Delayed Join<br><br>* Support for Dimension Table Keyby<br><br>* Supports Temporal Table Function DDL & Left Outer Join<br><br>* Supports pb format<br><br>* Supports operator\-level Debug output<br><br>* Supports expression reuse<br><br>* Supports newly added aggregation metrics to be recovered from Checkpoint<br><br>* Supports setting parallelism for all Sources and Sinks; supports rate limiting for all Connectors |
|State & Checkpoint enhancements |* Regional Checkpoint<br><br>* HDFS small file merging<br><br>* Multi\-strategy Checkpoint triggering<br><br>* Single\-Point Fast Checkpoint |
|CEP Enhancement |* Single\-Stream Multi\-Rule Capability<br><br>* Dynamic Rule Updating Capability<br><br>* notFollowedBy Semantic Capability<br><br>* Key\-Level Watermark Capability |
|Runtime Enhancement |* Blacklist<br><br>* Single\-Point Recovery<br><br>* Slow Node Startup<br><br>* Speculative Execution<br><br>* Large\-Scale Scheduling Optimization |
