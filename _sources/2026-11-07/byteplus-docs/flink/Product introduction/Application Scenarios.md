This article introduces the typical application scenarios of the cloud\-native messaging engine and its application across various industries.

<span id="6ebd0301"></span>
## Typical Scenarios


* **Real\-time ETL**

   With a range of built\-in Connectors, it comprehensively supports various upstream data sources (e.g., relational databases, message queues) and downstream data storage (e.g., OLAP, HSAP systems); through enterprise\-level SQL capabilities, it assists customers in real\-time data cleansing, transformation, and aggregation, helping enterprises to efficiently build real\-time data processing platforms.

* **Real\-time Monitoring**

   Stream computing with Flink offers state management, rich window support, and built\-in CEP for complex event processing, helping businesses simplify alert configuration rules, enhance alert effects, and reduce monitoring platform maintenance costs.

* **Real\-time Data Warehouse**

   Using stream computing with Flink for real\-time processing of massive data and high concurrency real\-time warehousing, it helps enterprise customers establish a digital operation system, real\-time statistics on various business indicators, real\-time presentation of enterprise production and operation status, providing real\-time data support for management decisions.

* **Real\-time Recommendations**

   Stream computing with Flink offers real\-time sample stitching capabilities, enabling real\-time model training and the creation of real\-time incremental models. Together with offline models, this allows for more precise and timely recommendations of suitable news, videos, games, and products to users.
