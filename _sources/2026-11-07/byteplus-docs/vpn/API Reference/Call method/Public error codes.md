This topic introduces the common error codes that may be returned when you call the Virtual Private Network API. For more information on platform\-specific error codes, refer to [Common error codes of BytePlus OpenAPI](https://docs.byteplus.com/en/docs/byteplus-platform/reference-common-error-codes).


|HttpCode |Error Code |Error Message |
|---|---|---|
|400 |InvalidParameter |A parameter specified in the request is not valid, is unsupported, or cannot be used. |
|400 |MissingParameter |The request is missing a required parameter. |
|409 |InvalidOperation.Conflict |The specified resource operation conflicts. |
|500 |InternalError |An internal error has occurred. |
