This topic describes how to delete a customer gateway that is no longer in use.

<span id=".5pON5L2c5Zy65pmv"></span>
## Scenarios

You can delete customer gateways that are no longer used to release network resources.

<span id=".5YmN5o-Q5p2h5Lu2"></span>
## Prerequisites

The customer gateway to be deleted is not used by any IPsec\-VPN connection. If it is used, first [delete the IPsec-VPN connection](https://docs.byteplus.com/en/docs/vpn/Deleting-an-IPsec-VPN-connection), then delete the customer gateway.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [Customer Gateway console](https://console.byteplus.com/vpn/vpnClient).

2. In the top menu bar, select the target region and project to which the resource belongs.

3. Click **Delete** to the right of the target customer gateway.

4. In the popped\-up dialog box, confirm the information of the customer gateway to be deleted.

5. Click **Delete** to complete the action.
