This topic describes how to delete an SSL\-VPN client certificate that is no longer in use.

<span id=".5pON5L2c6K-05piO"></span>
## Instructions

<div data-tips="true" data-tips-type="warning" data-tips-is-title="true">warning</div>


<div data-tips="true" data-tips-type="warning">Once you delete an SSL\-VPN client certificate, it becomes invalid immediately. All connections that use that certificate will disconnect instantly. Please confirm carefully before proceeding with this action.</div>


<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [SSL VPN Client Certificate console](https://console.byteplus.com/vpn/sslClient). 

2. In the top menu bar, select a target region and project for the resource.

3. In the SSL\-VPN client certificate list, click **Delete** in the **Actions** column of the target SSL\-VPN client certificate.

4. Click **Delete** to complete the action.
