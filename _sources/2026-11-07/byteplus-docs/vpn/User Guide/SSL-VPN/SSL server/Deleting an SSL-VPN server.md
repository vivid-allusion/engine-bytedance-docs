## Limits

Once an SSL\-VPN server is deleted, requests from clients who use the certificate created with the SSL\-VPN server will be rejected.

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to the [SSL VPN Server console](https://console.byteplus.com/vpn/sslServer).

2. In the top menu bar, select a target region and project for the resource.

3. In the SSL\-VPN server list, click **Delete** in the **Actions** column of the target SSL\-VPN server.

4. In the pop\-up dialog box, confirm the information of the SSL\-VPN server to be deleted.

5. Click **Delete** to complete the action.
