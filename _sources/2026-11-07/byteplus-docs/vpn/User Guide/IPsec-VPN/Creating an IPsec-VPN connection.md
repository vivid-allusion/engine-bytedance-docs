## Limits

You can create only one IPsec\-VPN connection when using the same VPN gateway and Remote ID.

## Prerequisites

* You have created a customer gateway. For procedure, see [Creating a customer gateway](https://docs.byteplus.com/en/docs/vpn/Creating-a-customer-gateway1).

* You have created the resource to be associated. For procedures, see [Creating a VPN gateway](https://docs.byteplus.com/en/docs/vpn/Creating-a-VPN-gateway-2) and [Creating a Transit Router instance](https://docs.byteplus.com/en/docs/transitrouter/TransitRouter-instances-01).

## Procedure

1. Log in to [the VPN Connection console](https://console.byteplus.com/vpn/vpnConnect).

2. In the top menu bar, select a target region and project.

3. Click **Create VPN Connection**, and configure the IPsec\-VPN connection based on the table below.

## What to do next

* [Add a VPN gateway route](https://docs.byteplus.com/en/docs/vpn/Adding-a-VPN-gateway-route): If you associate an IPsec\-VPN connection with a VPN gateway, you need to configure VPN gateway routes after you complete configuration for the VPN gateway, customer gateway, and IPsec\-VPN connection.

* [Add a security group rule](https://docs.byteplus.com/en/docs/vpc/Managing-security-group-rules): To access an Elastic Compute Service (ECS) instance in a local Virtual Private Cloud (VPC) from the peer, add the related rules to the security group associated with the ECS instance. These rules will allow the remote subnet.

* [Configure on-premises gateway routing](https://docs.byteplus.com/en/docs/vpn/Overview-1): After the configuration on the VPC side is completed, you need to configure the peer VPN gateway device. You can [download the IPsec-VPN configuration file](https://docs.byteplus.com/en/docs/vpn/Downloading-IPsec-VPN-connection-configurations) and save it to your on\-premises device to facilitate configuring the peer VPN gateway device in special scenarios (e.g., a scenario where on\-premises network is unavailable).
