If you no longer need the IPsec Connection Log feature, you can delete the IPsec Connection Log set.

<span id=".5pON5L2c5Zy65pmv"></span>
## Scenarios

You can delete the IPsec\-VPN connection log set only under the following circumstances. Deletion is not supported in other scenarios:

If you have used the IPsec Connection Log feature (indicating the presence of an IPsec Connection Log set), you can delete the log set when deleting the last IPsec\-VPN connection in the current region.

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">The IPsec\-VPN connection log set is free of charge. You can keep or delete it as needed. Keep it if you need to view historical IPsec\-VPN connection logs within 30 days. Delete it directly if you no longer need these logs.</div>


&nbsp;

<span id=".5pON5L2c5q2l6aqk"></span>
## Procedure


1. Log in to [the VPN Connection console](https://console.byteplus.com/vpn/vpnConnect).

2. In the top menu bar, select the target project and region.

3. Click **Remove Connection Log** in the top notice.

   The related notice only appears in the above operation scenarios. If your console does not display it, it means the conditions for removing IPsec connection logs are not met yet.

4. Click **Remove** to delete the IPsec Connection Log set.
