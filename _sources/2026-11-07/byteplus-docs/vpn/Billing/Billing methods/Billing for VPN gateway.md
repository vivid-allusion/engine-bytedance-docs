Using SSL\-VPN and IPsec\-VPN (associating IPsec\-VPN connections to a VPN gateway) incurs the VPN gateway billing. VPN gateway supports Subscription and Pay\-as\-you\-go. Two different metering methods are suitable for different scenarios. This topic describes these two metering methods in detail.

## Subscription

Subscription is a metering method where you pay in advance and then use the service. It helps you save money to a larger extent. In scenarios where you need to use VPN gateways for a long\-term period, you can purchase VPN gateway instances in Subscription by prepaying for several months or years. This offers more favorable pricing compared to Pay\-as\-you\-go.

<span id=".6K6h6LS55YWs5byP"></span>
### Formula


* **IPsec\-VPN (associating to a VPN gateway)** 

   * VPN gateway only enables IPsec connection capability

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/month) + Unit price for VPN gateway bandwidth (USD/month)) × Usage duration (month)** 

   * Both IPsec\-VPN and SSL\-VPN enabled for VPN gateway

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/month) + Unit price for an SSL\-VPN instance (USD/month) + SSL specification fee (USD/month) + Unit price for VPN gateway bandwidth (USD/month)) × Usage duration (month)** 

* **SSL\-VPN**

   * VPN gateway only enables SSL connection capability

      **Fee of a VPN gateway (USD) = (Unit price for an SSL\-VPN instance (USD/month) + SSL specification fee (USD/month) + Unit price for VPN gateway bandwidth (USD/month)) × Usage duration (month)** 

   * Both IPsec\-VPN and SSL\-VPN enabled for VPN gateway

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/month) + Unit price for an SSL\-VPN instance (USD/month) + SSL specification fee (USD/month) + Unit price for VPN gateway bandwidth (USD/month)) × Usage duration (month)** 


<span id=".57uT566X5ZGo5pyf"></span>
### Settlement cycle

In Subscription mode, the billing cycle is calculated in non\-calendar months. You need to make a full payment for VPN gateway resources when purchasing.

An overdue payment of an account does not affect the unexpired Subscription resources under the account. If your account is in arrears, but the Subscription VPN gateway resources have not reached expiration, you can still use the purchased VPN gateway normally, but you cannot purchase new VPN gateways. To purchase a new VPN gateway, please settle all overdue payments first, and apply after the account status returns to normal. For more information, see [Expiration](https://docs.byteplus.com/en/docs/vpn/Expiration).

## Pay\-as\-you\-go

Pay\-as\-you\-go is a metering method where you activate and release resources on demand at any time without purchasing a large amount of resources in advance.

The VPN gateway in Pay\-as\-you\-go is charged according to a fixed bandwidth cap (i.e., the bandwidth of VPN gateway). The platform calculates the fee based on the actually used bandwidth of your VPN gateway, which truly implements usage\-based payment. The instance fee is billed based on the usage duration, at a second\-level rate. You can delete resources anytime they are not needed. After deletion, the platform immediately stops billing.

<span id=".6K6h6LS55YWs5byP"></span>
### Formula


* **IPsec\-VPN (associating to a VPN gateway)** 

   * The VPN gateway only enables IPsec capability

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/hour) + Unit price for VPN gateway bandwidth (USD/hour) ) × Usage duration (hour)** 

   * Both IPsec\-VPN and SSL\-VPN enabled for VPN gateway

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/hour) + Unit price for an SSL\-VPN instance (USD/hour) + SSL specification fee (USD/hour) + Unit price for VPN gateway bandwidth (USD/hour) ) × Usage duration (hour)** 

* **SSL\-VPN**

   * The VPN gateway only enables SSL connection capability

      **Fee of a VPN gateway (USD) = (Unit price for an SSL\-VPN instance (USD/hour) + SSL specification fee (USD/hour) + Unit price for VPN gateway bandwidth (USD/hour) ) × Usage duration (hour)** 

   * Both IPsec\-VPN and SSL\-VPN enabled for VPN gateway

      **Fee of a VPN gateway (USD) = (Unit price for an IPsec\-VPN instance (USD/hour) + Unit price for an SSL\-VPN instance (USD/hour) + SSL specification fee (USD/hour) + Unit price for VPN gateway bandwidth (USD/hour) ) × Usage duration (hour)** 


<span id=".57uT566X5ZGo5pyf"></span>
### Settlement cycle

In Pay\-as\-you\-go mode, the billing cycle and bill term are both calculated in **natural hours**. Every hour on the hour (UTC+8), a bill is issued and the corresponding amount is deducted from your account. For more information, see [Bill management](https://docs.byteplus.com/en/docs/byteplus-platform/docs-bill-details) .

Overdue payments affect resources in Pay\-as\-you\-go mode, whose status changes depending on how long the payments are overdue. For more information, see [Arrears](https://docs.byteplus.com/en/docs/vpn/Arrears).

## Billing example

<div data-tips="true" data-tips-type="tip" data-tips-is-title="true">tip</div>


<div data-tips="true" data-tips-type="tip">Unit prices in the following examples are for reference only. For actual fees, please check in the console.</div>



* **Scenario 1**: Mr. A purchased one annual subscription VPN gateway in the China (Beijing) region (Huabei 2) with a **10 Mbps** bandwidth specification at 12:00:00 on August 1, 2023. The subscription period is one month. Both IPsec and SSL connection capabilities are enabled, with **5** SSL max connections.

   * **Billing items involved**:

      IPsec\-VPN instance fee, VPN gateway bandwidth fee, SSL\-VPN instance fee, and SSL specification fee

   * Total fee involved:

      The total fee of the VPN gateway for Mr. A was: IPsec\-VPN instance fee + VPN gateway bandwidth fee + SSL\-VPN instance fee + SSL specification fee = (250.00 (USD/month) + 525.00 (USD/month) + 250.00 (USD/month) + 60.00 (USD/month) ) × 1.00 (month) = 1,085.00 (USD). The VPN gateway expired at 23:59:59 on August 31, 2023.

* **Scenario two**: On August 1, 2023, at 12:00:00, Mr. A purchased one pay\-as\-you\-go VPN gateway in the China (Beijing) region with a bandwidth specification of **10 Mbps**. He enabled both IPsec connection and SSL connection capabilities, with an **SSL Max Connections** of 5.

   * Billing items involved:

      IPsec\-VPN instance fee, VPN gateway bandwidth fee, SSL\-VPN instance fee, and SSL specification fee

   * Total fee involved:

      The VPN gateway fees for different usage durations are shown in the table below:

      
      |Usage duration |1 hour |10 hours |24 hours |10 days |31 days |
      |---|---|---|---|---|---|
      |Total fee (USD) |2.53 |25.30 |60.72 |607.20 |1882.32 |
      

      Taking a usage duration of 31 days as an example, the fee calculation process is:

       **[**  Unit price for IPsec\-VPN instance (USD/hour) + Unit price for SSL\-VPN instance (USD/hour) + SSL specification fee (USD/hour) + Unit price for VPN gateway bandwidth (USD/hour)  **]**  × Usage duration (hours) =  **[**  0.42 (USD/hour) + 0.42 (USD/hour) + 0.10 (USD/hour) + 1.59 (USD/hour)  **]**  ×  **[**  31 (days) × 24 (hours/day)  **]**  = 1882.32 (USD)

* In summary: Based on the total fees of Scenario 1 and Scenario 2, Subscription is more cost\-effective for long\-term resource usage. Pay\-as\-you\-go is better suited for short\-term resource usage.
