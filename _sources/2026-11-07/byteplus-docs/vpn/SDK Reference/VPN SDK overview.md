<span id=".U0RL5LuL57uN"></span>
## SDK overview

The VPN SDK encapsulates all API interfaces of the VPN ([API overview](https://docs.byteplus.com/en/docs/vpn/VPN-API-overview)), uses the access key (AK) to identify the caller's identity, and provides automatic signature features, allowing you to create and manage resources conveniently through API calls.

<span id=".U0RL5YiX6KGo"></span>
